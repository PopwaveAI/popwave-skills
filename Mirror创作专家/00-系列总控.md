# Mirror 创作专家 · 系列总控

> **定位**：将镜界（Mirroric 小说创作应用）16 个 AgentSkill 的提示词精华，改造成一个**可直接跑通全创作流程的专家系列**。
> **保真红线（不可违反）**：每个专家文件中的「提示词精华」节 = 镜界对应 skill 文件的**原文逐字直贴，内容未增删改写**。绝不允许任何"升华/改写/去AI味"式的加工。凡新增内容（定位/触发/输入输出/衔接）一律只出现在「专家壳」节，并在醒目处与「精华」节分隔。

## 二、创作链路（专家如何被编排调起）

```
立项(01) ──► 世界观(02)·人设(03) ──► 开篇(04黄金三章)
                                      │
                        ┌──── 每章循环（05规划 + 06节奏 先行）────┐
                        ▼                                          │
                  07 写作专家（渲染正文）                           │
                        │                                          │
                  08 去AI味专家（清洗）                            │
                        │                                          │
                  09 审查专家（一致性/设定/连续性） ── 打回/通过 ──┤
                        └──────────────────────────────► 下一章
                                              │
                                         市场工具(10，按需)
```

- **一次一专家**：同一时刻只有一个执行者，避免方法论混用。
- **每章循环**：规划(05) 出大纲 → 节奏(06) 核对量化尺 → 写作(07) → 去AI味(08) → 审查(09)。审查不通过打回写作。
- **开篇专家(04)** 只在前三章启用；**审查专家(09)** 是创作后的质量闸，不做创作入口。

---

## 三、通用约定

- **输入**：各专家按自身「前置输入」节要求接收（本章事件/人物/设定摘要等），素材不足时不硬写。
- **产出**：各专家直接输出最终版（正文/大纲/审查报告），不附创作说明与元评论。
- **保真**：精华节是权威内容源；专家壳只负责"什么时候调用、喂什么、拿什么、交给谁"。若壳与精华冲突，以精华为准。
- **测试**：本系列先按"专家文档"形态交付试跑，验收满意后再按需转成 popwave skill 规范（SKILL.md + skill.json + CHANGELOG）。
