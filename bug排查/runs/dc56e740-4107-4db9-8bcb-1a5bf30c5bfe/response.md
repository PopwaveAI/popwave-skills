# 第一卷 晨露迷踪

## 第001章 被退稿的编剧

S市，六月，晚九点。

吕宝宝的出租屋只有十二平，书摞到天花板，泡面箱在墙角码成小山，唯一的空地被一台租来的神经接入舱占满。电脑屏幕的光照亮她半张脸，邮件页面停留在最上面那行字：

"您的投稿方案《月下狐影》未通过审核。"

她盯着这行字看了很久，久到屏幕熄了，又亮起来。

退稿理由是标准模板，客气得像群发。真正扎人的是编辑在末尾手打的那行附言：

"宝宝，方案本身没问题。问题是你写得比主线好太多——上线之后玩家一对比，反衬得主线敷衍，上头不批。别灰心，再接再厉。"

比主线好太多，反而成了错。

吕宝宝盯着"再接再厉"四个字，忽然想笑，又笑不出来。

这个方案她熬了三个通宵。她把狐妖族的背景、性格、成长线、隐藏任务全部串成一条能让人又哭又笑的故事线，给每一个NPC都写了小传，连狐妖驻地门口那只卖糖葫芦的老头儿都有三页背景故事——他年轻时爱过一个人类猎户，后来猎户老了，他还在原地卖糖葫芦。写完那三页的时候她自己哭了一场，觉得自己简直是天才。

然后方案被退了。

这已经不是第一次了。她的作品列表像一份完整的"如何被毙掉"教科书：第一支MV脚本被说"太文艺"，第一个广告创意被说"太煽情"，第一部短剧大纲被说"节奏太慢"，改快之后又被说"没有灵魂"。改到最后她自己都分不清，到底是她的问题，还是这行的规矩就是要先把人磨到没脾气。

编辑们倒都挺喜欢她——她交稿快、态度好、从不应酬。可喜欢归喜欢，稿子照退。

只有这一次，退稿信里多了一行不该有的附言。那行字的意思是：你写得很好，好到碍事了。

吕宝宝不知道这算夸奖还是羞辱。她只觉得，自己像一块被反复打磨的石头，磨了三年，终于磨出了一点锋利——然后被人按回土里，说"太尖了，会扎手"。

她点开桌面那个名叫"总有一天"的文件夹，把退稿通知截图拖进去。文件夹里已经躺了十几张类似的截图，最早的一张是三年前——她入行时写的第一支MV脚本，被甲方以"太文艺，观众看不懂"为由退回。

"总有一天"是空的。里面装的全是"总"。

她关掉邮件，把脸埋进膝盖里，闷声骂了一句脏话。

《炎黄》是她今年最看好的项目。全息拟真、神经接入、自由度拉满的东方修真世界，上线一年注册玩家破亿。她那些被毙掉的方案里，有一半是给它的竞品写的——那些竞品她根本没玩过，全靠资料和脑补。而《炎黄》，她连登录界面都没见过。

一个没玩过游戏的人，凭什么替玩家写他们想看的剧情？

她在电脑前坐了很久。退稿邮件开着，屏幕的光把出租屋照成一片惨白。窗外有晚风吹进来，带着夏天夜晚的潮气。

然后她做了个决定。这个决定后来改变了很多东西——只是此刻她还不知道。

吕宝宝抬起头，目光落在墙角那台神经接入舱上。那是她一个月前为写竞品分析报告租的，租金不便宜，续租的时候她肉疼了一整个下午。可这一刻，她忽然不想退了。

写不出让人没法拒绝的剧情方案，是因为不够了解这个世界。那些玩家为什么哭，为什么笑，为什么为一个NPC的一句话在论坛上吵三天三夜——她坐在电脑前想破头也想不明白的事，也许走进去，就全明白了。

她翻出接入舱说明书，按启动流程一步步操作。舱盖缓缓合拢，光线暗下来，只剩耳边系统温和的提示音：

"神经接入即将开始，请放松身体。首次接入用户请注意：全息体验将模拟真实五感，初始阶段可能出现轻微的眩晕或失重感，属正常现象。"

"确认接入。"

嗡——

世界在眼前炸开。

吕宝宝的第一反应是：这根本不是什么"像真的一样"。这就是真的。

她闻到了风。风里带着草木的清气、远处香火的味道，还有一点点说不清的、像晒过的棉被一样的暖意。她听见鸟叫、水声、远远的人声。她甚至感觉到脚底石板的温度——被太阳晒了一整天，还没完全凉下来。

妖狐族驻地。青瓦飞檐，红灯笼。

吕宝宝——不，从这一刻起，她是妖狐族一位光着脚站在石板路上的新弟子——站在驻地入口，仰头看着眼前的世界，足足愣了十秒。

远处是层层叠叠的木质楼阁，檐角挂着红灯笼，在暮色里轻轻摇晃。林间有幽蓝色的狐火游荡，忽明忽灭，像活物一样聚散。空气里有草木和香火混合的气味，脚下的石板被磨得温润光滑。她低头，看见自己赤着的双脚，以及身后一条正不安地摇动的、毛茸茸的橘红色尾巴。

"卧槽。"她小声说，"我长尾巴了。"

头顶还有一对立起来的狐耳。系统贴心地在视野角落弹出提示：【头顶狐耳可通过捏脸界面调整或隐藏；妖狐族可习得化形技能，届时可完全幻化人形。】

她伸手摸了摸自己的耳朵。手感居然是真的——柔软，温热，会因为她指尖的触碰敏感地抖一下。

"这……也太真实了。"

她正想继续研究尾巴的构造，眼前忽然炸开一行金灿灿的全屏公告，还配了音效：

【恭喜您！您是狐妖族第1000位注册弟子，触发稀有特殊词条【溯源之灵】！】

【溯源之灵】（唯一）
描述：您可以通过"品尝"食物，读取该食物制作时刻的数据残留——包括制作者当时的心绪、场景数据的部分快照，以及更深层的、不属于当前版本的底层代码碎片。
注：此词条为隐藏词条，不可更换，不可卸载，不参与任何属性计算。

吕宝宝把说明看了两遍，又看了第三遍。

"品尝食物……读取数据残留？"

她试着理解了一下：相当于她吃一口东西，就能看见做这东西的人当时的心情？还能看到什么"底层代码碎片"？

听起来很酷。然后呢？

她打开属性面板——攻击力：5。防御力：3。血量：100。

"这词条有什么用？"她忍不住嘀咕，"又不能加攻击力。"

弹窗右上角跳出一个闪烁的问号，她点开，系统贴心地补了一行小字：

【提示：词条的实际效果可能需要特定条件触发，建议玩家在游戏中多尝试、多探索。】

等于没说。

吕宝宝关掉面板，决定先把眼前的世界逛明白。她迈开步子，光脚踩在温热的石板上，向驻地深处走去。

驻地的布局比她在资料里见过的任何概念图都精细：左侧是祭堂，飞檐下悬着一排铜风铃，风一过叮叮当当响成一片；右边是灵器坊，门口挂着一块木牌，写着"今日锻造任务已满，明日赶早"；再往前是练武场，几个玩家正在切磋，兵器碰撞声混着叫好声传来，有人被一记扫堂腿放倒，爬起来拍拍灰继续上——围观的人比打的还起劲。

她站在练武场边上看了一会儿，又去集市逛了一圈。NPC摊贩们吆喝得卖力：卖糖葫芦的老头儿朝她招手，"小姑娘，来一串？新蘸的糖，脆！"；卖符纸的道士拉住她推销，"驱邪符，保你今晚不被狐火燎到头发"。

吕宝宝一边逛一边在心里记：这里的NPC是活的。每个都有自己的语气、情绪和脾气，不是那种站桩式复读机。这和她玩过的所有游戏都不一样。

她还在集市角落注意到一件有意思的事：一个玩家蹲在摊子前跟卖糖葫芦的老头儿砍价，砍了半天没成，最后掏出一枚铜板买了两串，一串自己吃，一串递给老头儿——"请你，咱俩聊这么久了"。老头儿愣住，然后笑得胡子直抖，从摊子底下摸出一小包桂花糖塞给他，"拿着，我孙女儿做的，甜得很"。

那个玩家转身朝吕宝宝的方向走来，路过时她听见他小声嘟囔："触发隐藏好感了……桂花糖，回头给队伍里那丫头尝尝。"

吕宝宝站在原地，忽然觉得心跳快了一拍。

她一直以为游戏剧情是写出来的——策划写什么，玩家就看什么。可刚才那一幕告诉她，在这个世界里，故事是玩家和NPC一起长出来的。她写不出来的东西，也许就藏在这些没人注意的角落里。

她抬头，暮色正在褪去，深蓝色的天幕上亮起第一颗星。驻地的红灯笼一盏接一盏亮起来，把整条石板街照得温暖而热闹。

系统适时弹出提示：

【欢迎来到《炎黄》。您当前等级：1级。建议前往驻地祭堂拜谒妖狐族长，领取新手装备，了解本族历史。妖狐族历史源远流长，或对您的创作有所启发。】

吕宝宝看着最后那行字，忍不住笑了。

"连系统都知道我是来干活的。"

她握了握拳，头顶的狐耳精神地立起来，朝祭堂的方向走去。

红灯笼的光在夜色里摇啊摇，像是替她开路。
