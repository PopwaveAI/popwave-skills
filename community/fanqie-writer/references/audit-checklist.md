# 番茄过审自检清单（每章交付前必跑）

> 依据：番茄小说官方 2026 年 5 月《关于加强低质内容治理公告》四类低质违规 + 平台治理案例反推。查证日期 2026-09-20，规则变动时先更新 `fanqie-platform-facts.md` 再同步本文件。
> 用法：写后处理阶段逐项过，**任一 P0 项不过，先修后交**；P1 项连续两章不过须回查节奏规划。

## P0 红线（任一不过不得交付，对应官方四类违规）

> **客观项一律跑 `scripts/chapter_stats.py <章节文件>` 取值，不靠感觉判断**（2026-09-21 首章实测补充：原先「对话占比 ≥30%」这类项无法客观判定，实测出现"脚本算成 0% 但人看着有对白"的情况——真因是正文用了 ASCII 直引号而非全角）。
>
> **2026-09-23 第一次修订**：**「对话占比 ≥30%」硬门槛废除**（样本对白占比 18.6%，会被旧门槛误判）。
>
> **2026-09-23 第二次修订（v1.20.0，用户交付 7 本异风格长篇后）**：**全部风格类阈值一并撤销**——
> 段落粒度（均段长 ≥22）、碎句节奏（短句率 ≤25%／碎句链 ≤12）、短对白链（≤6 行）**均不再判定**。
> **依据**：7 本正例的风格区间是「对白占比 0–94%／均段长 12–149／短句率 0–45%／碎句链 0–15／短对白链 0–15」，
> **《停摆》逐项都落在包络内**（《月光盒子》碎句链 15、短对白链 15，与《停摆》第 3 章同值甚至更极端）。
> 用户原话：「**也有那种专门写对话文的，不能一刀全割掉，这种不同的方式都可以有的**」。
> **新的划界**：**风格不设门槛**（只画像与选档），**只有四类语言错误是通用的**——
> **病句／碎句／跳／上下句描述错误**（用户原话「这种问题是通用不能有的」）。判据见下方**第六组**。

### 一、AI 粗制滥造
- [ ] 无连续 3 段以上句式结构雷同（同长度+同节奏排比视为雷同）→ 脚本项「连续 3 段等长段落」
- [ ] 无 AI 高频词：此外/然而/总而言之/值得注意的是/综上所述/强调/凸显 → 脚本项「AI 高频词」
- [ ] **对白承载达标（2026-09-23 改制，替代原「对话占比 ≥30%」门槛）**——**不设占比门槛**。对白是否合格只看两条：① **遮蔽测试**（见第五组第一项）② **每行对白都让局面动一格**。脚本项「对话占比」**仅作参考值输出，不判 PASS/FAIL**（依据：`benchmark-writing.md` 一·三）
- [ ] 全章经过去 AI 味处理（人工改写或润色技能），不是纯生成直出
- [ ] 章节间无模板化拼接：与相邻章节的段落骨架重复 <30%

### 二、格式混乱
- [ ] 单章仅一个 `#` 主标题，无异常分章（字数 2200-2800，跑 `scripts/check_chapter_wordcount.py` 校验；**只算正文，不含元数据块/章节备注/写后自检清单**）
- [ ] 标点全半角统一、无错乱 —— **对白引号必须是全角 `“”`，正文内不得出现 ASCII `"` `'`**（跑 `scripts/format_chapter.py` 自动成对转换；ASCII 单引号脚本不改，须逐处确认）；正文内不得出现 Markdown 残留（`---`、代码块、**加粗滥用**）
- [ ] **正文内不得混入拉丁字母**（v1.26.0 新增，FAIL；如 `sk`、`OK`、`BOSS` 等——中文正文里混英文对读者是明显出戏，无正当理由，一律改中文写法；确为英文专名须在章节备注写明理由）。**半角数字另计 WARN**（型号/年代/编号如「上海牌 7120」在中文网文里是正常写法，改了更好、不改不判错）
- [ ] 无非长网文体裁内容混入（提纲/报告/说明文段落）

### 三、结构失常
- [ ] 非"提纲式写文"：全章有具体场景、动作与对白，剧情复述/概述性文字 <10%
- [ ] 开头与结尾句式不重复、不堆砌排比
- [ ] 存在完整场景推进，不是"对话转场→对话转场"的骨架文

### 四、空洞水文
- [ ] 本章至少 1 个实质情节推进（新信息/冲突升级/关系变化/伏笔动作，三选一即可）
- [ ] 无流水账叙事（机械罗列时间、动作、对话而无情绪与目的）
- [ ] 单一场景不超过全章 40%，剧情拖沓段（无冲突无信息）全章 <15%
- [ ] 无大段艰涩概念堆砌（世界观解释单次 ≤200 字且需绑定具体事件）

### 五、信息承载与场景具现（v1.18.0 新增，依据 `prose-rules-supplement.md` S3／S4）

> **为什么单列一组**：以上四组查的是"平台会不会判低质"；这一组查的是"**读者读不读得懂**"。用户 2026-09-22 用 4 张截图批的正是这一组——**原文规则全都有，却没有任何可执行动作**，执行者每章自认达标。故本组**全部要求举证或机器判定，禁止打勾**。

- [ ] **遮蔽测试已过（S3.2）**——遮住本章所有含引号的行，只读叙述；仍能读出"这场戏在哪／谁在场／围绕什么物件／局面变了什么"。**做法**：跑 `scripts/chapter_stats.py`，用输出的「遮蔽测试待办段」定位所有连续 ≥3 行纯对白的位置，逐段遮读。**不过即不合格**（信息全压在对话里）
- [ ] **连续短对白：不设行数上限（S3.3，2026-09-23 第二次修订撤销"≤6 行"）**——"短对白行"＝引号内汉字 ≤10。**行数不判**（正例《月光盒子》第 21 章 15 行、《宠宠欲动》第 137 章 12 行均合格）；**判据改走第六组承接测试第 1 问**：连续短对白中每行是否让局面动一格
- [ ] **无信息应答连招 ≤2 行（S3.2，脚本项）**——"够。""在。""没有。"单发不算错；连续 3 行以上是"连招回避"，同一章不得出现两处
- [ ] **文书类文本已"读出来"（S3.4）**——登记本／清单／信件等若故意留空栏，必须写出①它与上一条的**差别**②角色从空白里**读出了什么**③他**因此做了什么**。只留排版效果不算过（撞死线第 12 条）
- [ ] **关键动作可复现（S4.1）**——情节依赖的动作（拆表／拨针／开锁／翻找）写清"用什么／怎么做／到什么程度／结果是什么"；**判据：读者合上眼能不能照着做一遍**
- [ ] **无空句（S4.2）**——无泛指替代（"就这么…"）、无评价替代事实（"他等不了。"）、无抽象命名。判据：换成一句具体动作或读数，若意思不变，原句就是空的
- [ ] **场景三件套已给且只给一次（S4.3）**——每场戏开头给①空间②物件③光／声／温度任一；场景进行中不重复给
- [ ] **风格画像已比对（S5.2／S6.1，脚本项，2026-09-23 第二次修订改制）**——六项风格指标（对白占比／均段长／均句长／短句率／碎句链／短对白链）**一律只报数，不判 PASS/FAIL**。读法：对照 `references/benchmark-writing.md` 第一节档位区间，确认本章落在**所选档位**内。**唯一的硬判据是"档内一致性"**：相邻章对白占比／均句长跳档超一倍且无场景或卷边界 → 读者会觉得**跳**，须修。**明令禁止**：不得以"句子太短／段太短／对白太多"为由改文（用户的指正原话：「不能一刀全割掉」）

### 六、通用硬伤四条（v1.20.0 新增，**所有风格、所有题材都必须过**）

> **来源**：用户 2026-09-23 原话——「那种**病句，碎句，跳，上下句描述错误**，这种问题是**通用不能有的**」。
> **为什么这是唯一该设门槛的一组**：它的四条都是**语言错误**，与"句子长短／对白多少"无关。
> 上一版把"风格"当"硬伤"，误杀了用户交付的正例（《月光盒子》均段长 15.8 会被旧门槛判 FAIL）。**本组是本文件唯一要求逐句举证的部分。**

> **用户 2026-09-23 二次确认（原话）**：「**你看下这些就是通用性错误，任何风格类型的正文里面都不允许出现这些**」——
> 即：**这四条与风格档位无关、与题材无关、与句长对白多少无关，是不可协商底线**（用户把自己这一屏截图发回确认）。

**核心动作：承接测试（逐句四问）**——取连续 3 行为一组，逐问：

| # | 问题 | 不过的样子 | 归属 |
|---|---|---|---|
| 1 | **有信息吗？看得出要干什么吗？** ① 给了上文没有的事实／动作／状态变化吗？② 这一段的**行为意图与逻辑**看得出吗（他在做什么、为什么这样做）？ | ①「表呢？」「在。」「修了吗？」「没有。」——全是上文已知<br>② 一串短句读者拼不出"他要干什么、为什么" | **碎** |
| 2 | **接得上吗？中间那几步在不在？** 上一动作到下一动作跨过的**中间步骤**有没有交代？**照着做一遍**连得上吗？ | 用户原例：「我躺在床上睁开了眼睛，打湿毛巾把脸好好地擦了一下，终于清醒过来了」——躺着→打湿毛巾之间缺**起身／下床／走到水盆边** | **跳** |
| 3 | 「他／她／它／这／那」**指得清**吗？ | 三人同场时用"他"，读者不知指谁 | **跳（指代）** |
| 4 | 事实与前文／物理常识／角色已知状态**对得上**吗？ | 前文"表冠拧不动"，后文"拧了二十多圈"；前文"手里没拿伞"，后文"她收起伞" | **上下句描述错误** |

> **两个词的定死口径（用户 2026-09-23 原话）**：
> * **碎**＝「**句子短且看不出具体是要干什么，看不出行为模式和逻辑**」——**碎 ≠ 句子短**。判据是「意图可见＋逻辑可见」。对照：《停摆》第 3 章 12 行（碎）vs《宠宠欲动》第 137 章 12 行（不碎，因为是审讯、答一句对方脸色黑一分）。
> * **跳**＝「**一个情节到下一个情节是跳跃的，没有链接**」——是**动作级缺环**，不是场景级跳跃。判据动作只有一个：**挑动作密集处照着做一遍，中间步骤在不在**。修法是补中间步骤，不是把原句改长。
> **两者都不可"正则化"**（已试并撤除自动检测：正例 2.4 句/千字 vs 自产 2.4，无区分度）——**但判定不需要"人"来做**：
> 由**跑本技能的模型**按 `prose-rules-supplement.md` **S7.2 自检子流程**逐段判定（脚本给定位材料 → 逐段四问 → 输出举证表 → 就地改 → 复跑）。
> **v1.21.0 写的"只能人工判"是错的**——用户 2026-09-23 即以 *「就是改不掉？然后只能让人工给你一条条指出来？」* 质疑，
> 并给出反证：交付的 `ch001` 由 gemini 3.8 生成，**没有**这些通用性问题。详见 S7 与 `benchmark-writing.md` 第八节（污染测试实测）。

- [ ] **写前两个中间产物已出（S7.1，v1.22.0 新增）**——① **动作链**：逐场戏列关键动作的物理顺序，相邻两步**显式标注四类过渡**（姿态变更／空间位移／取物／时间跳转）；② **信息增量表**：逐场戏列**每一轮**改变了什么。**没有这两个产物直接写正文＝不合格**（治根动作——写前就把"跳／碎"堵住，不靠写后挑错）
- [ ] **承接测试四问已逐段过（S5.3／S7.2）**——**执行者＝跑本技能的模型**（不是用户），**必须输出举证表**，格式：`位置 → 问题类型 → 原句 → 缺失项 → 修法`。**禁止打勾**。做法：跑脚本取定位材料（最长碎句链原文／遮蔽测试待办段／无信息应答连招位置）→ 逐段四问 → **不合格就地改** → 复跑至全过（"碎/跳"正反例见 `benchmark-writing.md` 第二节，污染测试见第八节）
- [ ] **无病句（S6.2）**——成分残缺（缺主／谓／宾）、搭配不当、语序错乱、关联词不配对。**检测法：读出声**，读断气或读不通即病句
- [ ] **无半截句（S6.2，脚本项）**——正文行不得以逗号／顿号／分号收尾，不得无终止标点（排除列表标记与引用块 `>`）
- [ ] **跨章对白未逐字复现（S6.3，脚本项）**——本章末段对白与上一章末段不得有 ≥3 行逐字相同（《停摆》第 2／3 章末三句曾完全复现）

## P1 完读率导向（番茄算法指标，数据复盘时对照）

- [ ] 前 50 字内有即时冲突/反常/危机（决定书架页点击）
- [ ] 章末有钩子，且类型与上一章轮换
- [ ] 单章 ≥3 次情绪变化（压/扬交替）
- [ ] 评论区诱导留白 ≥1 处（两难选择/信息差/误解不解释）

## 执行方式

1. **先跑脚本取数**：`python scripts/chapter_stats.py novels/[书名]/第XX章.md`（或 `--all <目录>`）。脚本把 AI 粗制滥造/格式混乱/空洞水文三组的可量化项直接给出 PASS / WARN / FAIL，**P0 出现 FAIL 即不合格**；退出码非 0 表示有 P0 不通过。
2. 脚本判不了的项（是否有完整场景推进、是否流水账、是否提纲式写文、去 AI 味是否到位、**以及第六组承接测试四问**）**由执行本技能的模型逐项核并给出依据**——**不是交给用户判**（此处的"人工"＝逐个回原文取证，**执行者是模型**；**禁止打勾**）。
3. AI 生成痕迹拿不准时，加跑去 AI 味技能或 pop-editor 文风质感模式复核。
4. 被平台判违规（限流/拒签/下架）后：先按违规类型反查本清单对应分组，修完再申诉。
