# 番茄小说情绪曲线设计

## 核心公式：每3章完成一次“压-小扬-压-爆”循环

| 章节 | 情绪阶段 | 读者心理 | 写作要点 |
|-----|---------|---------|---------|
| 第1章 | 压 | “这主角太惨/太憋屈了，我要看他翻身” | 建立同情，展示困境，暗示主角有独特优点 |
| 第2章 | 小扬 | “果然有反转！我就知道！” | 主角获得小胜利或重要信息，不解决根本问题 |
| 第3章 | 压→爆预告 | “靠！又被打压？下章必须打脸！” | 反派变本加厉，主角获得关键筹码，章末暗示反击 |

**循环应用**：第4-6章重复此模式，爆点规模逐轮扩大。

## 七套情绪标签对应节奏模板

> **为什么从"六大"改叫"七套"（2026-09-23）**：正文实际列了 7 套（1 打脸爽文 / 2 极致虐恋 / 3 爆笑反套路 / 4 悬疑惊悚 / 5 治愈甜宠 / 6 脑洞大开 / 7 现实奋斗），标题却写"六大"——**数目与内容不符**，执行者按"六大"盘点会漏掉第 7 套。

### 1. 打脸爽文（扮猪吃虎/马甲掉落）
- 第1章（压）：主角因隐藏身份被嘲讽/欺负
- 第2章（小扬）：不经意展露实力，但被误认为运气
- 第3章（压→爆预告）：遭遇更强对手，章末暗示即将当众揭穿身份

### 2. 极致虐恋（追妻火葬场）
- 第1章（压）：女主被男主虐心/忽视
- 第2章（小扬）：女主觉醒，做出离开决定
- 第3章（压→爆预告）：男主追悔莫及，章末出现男主后悔的画面

### 3. 爆笑反套路（沙雕吐槽/神转折）｜2026-09-23 扩写

**形态归属**：爽点形态＝**整活兑付类**（2026-09-23 沙雕缺口实测新增的第五类）。**本套适用于爆笑反套路 / 沙雕 / 整活 / 神转折 / 精神病主角 / 现代梗穿越等一切以"做法离谱但成立"为主卖点的题材。**

- 第1章（压）：主角陷入经典套路剧情——**读者以为他要按套路走**（退婚、被逐、废柴、绑定系统）
- 第2章（小扬）：用清奇脑回路破解套路——给出的不是"更强"，而是**一个"做法"**
- 第3章（压→爆预告）：系统/原剧情试图纠正，章末留"这也能行？"悬念

#### ★本类型的引擎：**连锁失控**（2026-09-24 新增 · 本节最要紧的一条）

**笑不来自主角聪明，来自局面失控。**

**参考样本**（用户 2026-09-24 提供的在跑短剧《错位寻音》）：
> 穿越古代后我自带 BGM → **嫡母靠我的歌发现了我爹的小秘密** → **转头就要带我进宫面圣**

**注意这条链里主角一次都没主动做什么**：他只是"自带 BGM"，然后**别人各自按自己的心思行动**（嫡母从歌里听出了东西、嫡母决定带他进宫），局面以荒诞的速度升级。**主角是局面的受害者，不是操盘手。**

**结构模板（四步）**：

| 步 | 内容 |
|---|---|
| 1 | **一个做法**：他那件离谱的事，当场做出来 |
| 2 | **别人各自做出荒唐反应**：**不是统一反应**——每个人从自己的私心出发，反应各不相同 |
| 3 | **反应牵出别的事**：漏话、暴露、误认、抢功、告状 |
| 4 | **局面滚成他管不了的样子**：他从"被瞧不起的人"变成"所有人都在算计的一件东西" |

**判据句（一票否决）**：**这一章结束时，比开头更乱还是更整齐？**
- **更乱 → 对**
- **更整齐 → 错**。写成了"智斗"，读者不笑，而且会滑回打脸爽文。

**⚠️ 配套三条纪律**：
1. **主角必须被动**——他不问，是别人自己漏的。**他一问就不算数了**（一写成"他在审问／他在套话"，本类型就变成权谋）。
2. **每章的"乱"必须比上一章更大**——不只是人多，是**失控更广**（档位链例：一格院子 → 一座台子 → 一个门派 → 一条街 → 七派连演 → 全江湖）。
3. **"漏话／失态"要写成当事人自己先慌**——说完脸色变了、捂嘴、往后退。**慌的是他，读者才笑**；若无其事地说出来，就只是"说了句话"。

**⚠️ 本轮实测的反面案例（必看）**：
沙雕 L1 样本第一版**自检全绿、却形态不对**。写作层把"整活兑付"理解成了"**主角用做法解局**"：他哼曲子 → 人跟着晃 → 管事来问 → **他援引规矩反制** → 被挪去伙房。**走势是"从乱到整齐"**，读起来是智斗。用户当场否掉：「**你这个写的不像搞笑沙雕文啊，然后爆笑反套路的感觉也没有**」。
**根因**：既有的"笑五动作"与"三章循环"**验的是"有没有做法"，验不出"笑不笑"**——缺的正是"失控"这一维。**判据句全绿不等于形态对。**

#### 三章一循环的结构（照此排布，不要只写"好笑"）

| 位置 | 功能 | 必须落到的动作 |
|------|------|--------------|
| 压 | 把**读者以为的套路**摆足 | 一个读者一眼认得的经典桥段（退婚、逐出、废柴、天降系统），且**照套路演到七成**——太早掰弯就没了反差 |
| 小扬 | **整活兑付**（本类型的"爽"就落在这一格） | 主角**做出一个具体做法**（动手、开口、掏东西、改流程），当场把套路掰弯。**⚠️ 2026-09-24 加严**：这一格必须**同时启动失控链**——做法一出，场上至少**两个人各自做出不同的荒唐反应**（不是"大家一起惊呆"） |
| 压 | 套路方（系统／原剧情／反派／围观群众）出招纠正 | **有人当场指出"这不合规矩"**，压力回到主角身上 |
| 爆预告 | 主角**再整一次**，且比上次更大 | 第二次做法**规模更大／更离谱／牵进更多人**，章末留"这也能行？"。**⚠️ 2026-09-24 加严**：此处的"更大"指**失控更广**，不是"人数更多"——每多一层人，就要多一种**不同的**荒唐反应 |

#### "笑"的动作清单（整活兑付的五种可指认动作，每章至少落一种）

| # | 动作 | 判据 |
|---|------|------|
| 1 | **当场动手做了** | 不是吐槽、不是内心 OS，是**一个看得见的动作**（掏／搬／改／烧／唱／打） |
| 2 | **做法"成立"** | 离谱但要**在本书规则内说得通**——读者能自己补上那条逻辑链（说不出逻辑＝胡闹，不是整活） |
| 3 | **有人被整到** | 至少**一个具体的人**当场做出反应（懵／急／破防／跟着干），且这个反应**可指认** |
| 4 | **前提被反过来用** | 用本书**已有的**设定／规则／道具**反向**达成目的（不是新造一项能力） |
| 5 | **代价当场就有** | 整完之后**立刻付一点小代价**（被记恨／被围观／被罚／被盯上）——防"无本万利"式胡闹 |

#### 自查判据（本类型专用，替代"打脸式爆点"检查）

- [ ] 本章的"爽"是否落在**一个做法**上，而不是落在**一句吐槽／一个内心 OS** 上？（吐槽不算整活）
- [ ] 这个做法是否**说得通**？（能否用本书规则补出逻辑链——说不出＝胡闹）
- [ ] 是否有**至少一个人当场被整到**，且反应可指认？
- [ ] 相邻两次整活是否**比上一次规模更大**？（原地重复＝水章）
- [ ] 是否**没有**退化成"碾压"？（一旦主角靠"更强"解决问题，本类型就塌回打脸爽文）
- [ ] **（2026-09-24 新增）本章结尾比开头更乱吗？**——更整齐＝写成了智斗，**本类最容易翻车的一处**
- [ ] **（2026-09-24 新增）"漏话／失态"的人是自己先慌，还是若无其事？**——若无其事就只是"说了句话"，不笑

> **2026-09-23 沙雕缺口实测记录**：本模板此前**只有 3 行**（与第 5 套并列为全库最薄），且**四类爽点形态装不下"笑"**——
> 判定表六行一行不命中、`plot-structures.md` 四套库里无沙雕向配方，导致"沙雕/爆笑反套路"这一现已跑出黑马的赛道
> **在覆盖盘上根本不会出现**。补齐后需在沙雕 L1 样本回跑验证"做法可指认""规模递进""没塌回碾压"三条是否守得住。

### 4. 悬疑惊悚（细思极恐/规则怪谈）
- 第1章（压）：遭遇无法解释的诡异事件
- 第2章（小扬）：找到一点线索或规律
- 第3章（压→爆预告）：发现规律是陷阱，章末留细思极恐钩子

### 5. 治愈甜宠（日常温馨/双向奔赴）

**形态归属**：爽点形态＝**关系兑付类**（2026-09-22 女频验证新增的第四类）。**本套模板同时适用于现代言情 / 古代言情 / 一切以关系推进为主轴的题材。**

- 第1章（压）：主角处于孤独/缺爱状态；**CP 必须在场或在章内出现**（第 2 包必备元素：CP 对象前 3 章内出场）
- 第2章（小扬）：与 CP 产生温暖互动
- 第3章（压→爆预告）：出现小误会或外力，章末 CP 做出心动举动

#### 三章一循环的结构（照此排布，不要只写"甜"）

| 位置 | 功能 | 必须落到的动作 |
|------|------|--------------|
| 压 | 给主角的"不敢"一个具体出处 | 一个她**没做成**的动作（没问出口、没留下、把东西扔了） |
| 小扬 | **关系兑付**（本类型的"爽"就落在这一格） | CP 主动做一件**可指认的事**（来了、喊了名字、把东西留下、记住了细节） |
| 压 | 外力或她的旧伤把刚靠近的一步推回去 | **她先退**（躲、关门、说"我没事"） |
| 爆预告 | CP 的回应把球推回来，且比上次更近一步 | CP 第二次主动，**比第一次更近一档**（从"留东西"到"说出口"到"不走"） |

#### "甜"的动作清单（关系兑付的四种可指认动作，每章至少落一种）

| # | 动作 | 判据 |
|---|------|------|
| 1 | **他主动来了一次** | 不是偶遇，是**为见她而到**（时间 / 路线 / 理由能看出来） |
| 2 | **他记住了细节** | 说出或做出一个"只有留心才知道"的信息（她的口味、旧物、习惯） |
| 3 | **他把某句话说了** | 一句能改变她判断的话，且**当场说出口**（不是事后回想） |
| 4 | **他留在原地没走** | 拒绝、尴尬、雨、麻烦出现了，他仍然在 |

#### 自查判据（本类型专用，替代"打脸式爆点"检查）

- [ ] 每 3 章是否**至少 1 次关系兑付**落在**动作**上（上表四种之一）？
- [ ] 相邻两次兑付是否**比上一次更近一档**？（原地重复＝没推进；"他还是来买花"重复三次＝水章）
- [ ] 本章的"压"是否**由她的旧伤或外力造成**，而不是靠"两人都不说"？（后者是开篇雷区"误会 + 不解释"，判据见 `genre-packs.md` 第 2 包）
- [ ] CP 的动机是否**在本章内可见**？（第 2 包雷区：男主的冷淡没有可理解的动机 → 读者骂掉追读）

> **2026-09-22 女频验证记录**：本模板此前**只有 3 行**（全库最薄），与"认可类双层周期"的完整度差距悬殊，导致言情写作阶段**"甜得够不够"无法自查**。补齐后需在第 2、3 章回跑验证"3 章 1 兑付"与"递进一档"两条是否守得住。

### 6. 脑洞大开（系统流/末日囤货）
- 第1章（压）：获得金手指但面临生存危机
- 第2章（小扬）：利用金手指解决小危机
- 第3章（压→爆预告）：发现金手指有代价，章末出现更大机遇

### 7. 现实奋斗 / 生活流（年代文 / 种田日常 / 都市生活向）｜2026-09-21 新增

> **为什么单列一套**：前 6 套全是"3 章一个压-小扬-压-爆"的**单层周期**，而本类型的爽点形态是**认可类**——"爆"不是打脸式的即时反转，而是**攒出来的可见成绩**，天然是长周期。
> 原规则里 `genre-packs.md` 说"每 5-10 章做出点东西、每 25-30 章生活层级跃升"，与本文件的"每 3 章一个爆"**互相冲突且未定优先级**（2026-09-21 年代文样本实测：执行者无法同时满足两个周期）。
> 现定为**双层周期**：

| 层 | 周期 | 内容 | 写法要求 |
|----|------|------|---------|
| **外环 · 推进** | **每 3 章** | 一次**小推进**——不是"爆"，是**可见的具体得失**：挣到第一笔钱 / 谈成一桩买卖 / 学会一样新做法 / 让人改了一次口 | 得失必须具体（数字、物件、别人的一句话）；**不写"她的日子渐渐好起来了"** |
| **内环 · 跃升** | **每 25-30 章** | 一次**生活层级跃升**：帮工→主事 / 借住→有自己的地方 / 没人认→被邻里当个人物 | 跃升必须**当众发生**且**改变她在这个环境里的位置**，否则读者感觉不到 |

- **本类型的"压"怎么写**：不是被打压，而是**白干 / 不被认 / 差一点**——力气花出去没结果、做对了没人看见、眼看够得着又滑掉。
- **本类型的"扬"怎么写**：不是翻盘，而是**被接住**——有人替她说话、有人记得她做过什么、有人先一步替她想到了。
- **禁止**：把本类型写成打脸结构（对手被羞辱）。一出现"当众打脸"，读者会认为"这书跑偏了，明明说是年代/种田文"。
- **与第 1-6 套的关系**：本套**不替代**核心公式，而是把它**外环化**——"压-小扬-压-爆"的**节奏感**仍保留（每章仍有起伏、有钩子），只是"爆"的兑现周期从 3 章拉到 25-30 章。

## 情绪标签与核心冲突冲突时（实测补充）

六问的**情绪标签**与**核心冲突**不保证同向。实测样本：`爆笑反套路`（喜剧向）× `复仇雪恨` + `老实人黑化`（悲情向）——本文件只按情绪标签定节奏，遇到这种组合会失真。所以两者不同向时，**先裁决、再定节奏**。

**先判「算不算不同向」，再决定要不要裁决（2026-09-23 新增，此前无判据）**

判据只有一句动作——**「照标签写出来的一章，能不能同时把冲突推进一格？」**

- **能 → 同向**，不必裁决，照常往下走。
  （例：`脑洞大开 × 权力争夺`——"用一个新机制搅动权力格局"两者同时成立 → **同向**。）
- **不能 → 不同向**，按下表裁决。

> 旧版**只给了三行组合、没给判据**，执行者只能凭感觉判断"算不算冲突"。2026-09-23 武侠仙侠样本实测撞到：
> `脑洞大开 × 权力争夺` 在旧表三行里**都没有对应项**，也无从判断是否同向——属规则外动作。

| 冲突类型 | 典型组合 | 三条裁决路径（**AI 评估三条 → 定首选并写明理由 ＋ 留 1-2 备选**） |
|---------|---------|--------------------------------|
| 喜剧向标签 × 悲情向冲突 | 爆笑反套路 / 治愈甜宠 × 复仇雪恨 / 生死存亡 | ① **外壳与内核分离**：叙述口吻走标签、情感主线走冲突（笑中带痛，写作要求最高）② 割舍冲突的悲情面（冲突降级为闹剧式对抗）③ 割舍标签的喜剧面（改挂与冲突同向的标签） |
| 悬疑向标签 × 情感向冲突 | 悬疑惊悚 × 爱情阻碍 / 守护保护 | ① 悬念作主线、情感作张力 ② 情感作主线、悬念作背景谜题 |
| 爽文向标签 × 慢热向冲突 | 打脸爽文 × 成长突破 | ① 把成长拆成多个小打脸节点 ② 降低打脸密度，改走代入线 |
| **新奇向标签 × 沉重向冲突**（2026-09-23 新增行） | 脑洞大开 / 爆笑反套路 × 权力争夺 / 生死存亡 | **先过上面那句判据**；判为"不能同时成立"时才走此表：① **套路做骨架、脑洞做局部**——爽感走成熟套路，巧思只放在世界规则与主角手段上 ② **脑洞前置**——世界设定本身就是最大卖点，冲突线先让位 ③ **换标签**——改挂与冲突同向的标签 |

裁决结果写入 `00-大纲.md` 作品基因（如"喜剧外壳 + 悲情内核"），**作为全书节奏基准**；后续若节奏跑偏，回看这条裁决。三路各有代价——**由 AI 选定一条并写明理由，随立项稿交用户过目，用户有异议再改**（2026-09-23 改：原为"属于创作口味决策，必须用户拍板"）。

## 单章内部情绪拐点设计

单章2200-2800字内至少3次情绪变化：

开头50-250字：延续或急转，快速建立本章情绪基调
中间1500-1900字：情绪逐步升级，至少一次小起伏
结尾450-650字：情绪到达本章峰值后急转，留下钩子

### 情绪拐点句式库

> **分两组**（2026-09-21 补充）：**A 组＝对抗型**，适用碾压类与信息兑付类；**B 组＝认可型**，适用认可类（年代 / 种田 / 日常 / 治愈）。
> 原库只有 A 组——给认可类题材的作者看 A 组，会把生活流直接写成爽文腔（2026-09-21 年代文样本实测发现）。

**A 组 · 对抗型（碾压 / 信息兑付）**

**从憋屈到暗爽**：
- “他低着头，嘴角却微微上扬——他们还不知道，自己惹了谁。”
- “所有人都以为她认命了，直到她拿起手机，拨出了一个号码。”

**从震惊到愤怒**：
- “直到看到那张照片，她才发现，这三年的眼泪都流给了骗子。”

**从绝望到希望**：
- “门锁转动的声音响起时，她握紧了水果刀。但进来的，是那张熟悉的脸。”

**从得意到恐惧**：
- “他以为自己赢了，直到转身看见那个人的眼睛。”

**从平静到震惊**：
- “我像往常一样打开门，然后看见了这辈子最不想看见的人。”

**B 组 · 认可型（生活流 / 年代 / 种田 / 治愈｜2026-09-21 新增）**

**从白干到被认**：
- “她忙了半个月，谁也没说什么。直到今天早上，门口那家把碗还回来，碗底压着两个鸡蛋。”

**从疏离到被接住**：
- “她一直以为自己是给这家人做饭的。老太太把碗往桌上一搁，说‘坐下吃’——那张桌子，她来了三年没坐过。”

**从撑着到有人搭把手**：
- “她把手伸进凉水里，想着再快一点就好了。然后身后有人把柴推进了灶膛。”

**从以为没人记得到有人一直记得**：
- “那碗粥她早就忘了。老太太记得——记了三年，记到要在这么多人面前把它说出来。”

**从够不着到够着了**：
- “她数了三遍，还是差七十文。第二天出门，门口放着一把铜钱，用草绳捆着，正正七十。”

## 评论区诱导设计

在以下节点刻意留白：
1. **两难选择**：主角在两个都有道理的选项中犹豫，章末不写决定
2. **信息差**：让读者比主角多知道一点信息，但不全知道
3. **误解不解释**：主角被误解时不立刻解释
4. **配角高光**：给反派或配角一个令人同情的瞬间
5. **规则争议**：主角做出道德灰色地带的选择，不评价对错
