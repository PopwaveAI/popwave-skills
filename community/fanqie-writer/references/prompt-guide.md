# 提示词完善指南

从用户的一句话方向，扩展为完整创作提示词的详细指导。

## 完善原则

### 核心思路

用户给的是"种子"，你要做的是"催化"——补全他没想到但必须有的要素。

### 补全优先级

```
必须补全（缺了写不下去）：
  1. 主角人设 + 金手指
  2. 等级/力量体系
  3. 第一个冲突和爽点

应该补全（缺了质量差）：
  4. 世界观基本规则
  5. 配角框架（至少一个对手、一个盟友）
  6. 前三章节奏规划

可以补全（锦上添花）：
  7. 详细名场面设计
  8. 中后期剧情走向
  9. 风格和语言指南
```

## 主角设定为群像戏时（实测补充）

本指南的补全要点全部按**单主角**设计。六问若选了「群像戏」，先按 SKILL.md 1.2 的三种锚点模式让用户拍板，再按下表补全：

| 要素 | 群像戏下的补全方式 |
|------|-------------------|
| 主角人设 + 金手指 | **主锚点制**：填主锚点人物；金手指挂主锚点，**不分散到多人**（分散会稀释主线立意）。三线并列：每个核心人物各写一份精简人设，金手指可各自独立但需各有代价 |
| 等级/力量体系 | 仍按题材给一套统一体系（群像共用同一世界观），但**只需写清主锚点所用层级**，其余人物标"所在层级"即可 |
| 第一个冲突与爽点 | 冲突必须**同时牵动主锚点与至少一位支线人物**——这是群像戏"人各有事"的第一处证明 |
| 配角框架 | 升级为**人物卷宗**：每人一行（身份 / 诉求 / 与主锚点的关系 / 自己的那条线何时收） |
| 前三章节奏 | 第 1 章主锚点立起来，第 2-3 章各给一位支线人物一个"自己的事情"，避免群像前 3 章变成人物名录 |

**红线**：群像戏不得写成"人物清单 + 主线独角戏"。每个支线人物至少要有一条独立于主线的诉求，并在中段前收束一次。

## 提示词常见问题修正

### 问题1：金手指太强，没有悬念

**修正方法**：
- 添加使用限制（冷却时间/消耗/副作用）
- 添加成长曲线（初期只能用基础功能）
- 设置对手也有特殊能力

### 问题2：开局太平淡

**修正方法（先看 `00-大纲.md`「爽点形态」字段，按形态选）**：
- **对抗形态（碾压类/信息兑付类）**：开局就遭遇危机（被退婚/被追杀/被陷害）；第一章结尾获得金手指；前三章内必须有第一次爽点兑现（打脸/逆转/揭秘任一）
- **认可形态（认可类）**：开局给一个"平静被打破"的小事件（老屋漏水/账本对不上/陌生来客上门）；第一章结尾主角用本事解决了它；前三章内必须有一次"被看见"的具体时刻（手艺被点名夸、第一笔进账、有人记住主角的名字）
- **共同红线**：平淡 ≠ 没有事发生——任何形态下，第一章都必须发生一件让读者想看第二章的事

### 问题3：等级体系模糊

**修正方法**：
- 至少设置 6-8 个明确等级
- 每个等级有具体能力表现（能劈山/能飞/能御剑）
- 明确每个等级的人数稀缺度

### 问题4：爽点单一

**修正方法（形态按 `00-大纲.md`「爽点形态」字段）**：
- 设计 3-5 种不同的爽点兑现方式并轮换：对抗型＝实力碾压/智谋胜出/身份揭秘/财力压制；认可型＝被点名夸赞/手艺破纪录/人情回响/日子可测量的改善
- 每隔几章换一种，兑现方式不得连续两章雷同（雷同检查见 `review-dimensions.md` 第五节）

## 用户方向解析示例

### 示例1：模糊方向

**用户输入**："写个修仙爽文"

**解析 & 补全思路**：
- 题材已明确：修仙
- 需要补全：主角身份（建议废柴灵根）、金手指（建议炼丹系统）、初始冲突（建议宗门大比被嘲笑）、等级体系（标准修仙九境）

### 示例2：半明确方向

**用户输入**："重生回到高中，主角前世是商业大亨"

**解析 & 补全思路**：
- 题材已明确：都市重生
- 金手指已有：前世记忆和商业眼光
- 需要补全：重生时间点（哪一年，有什么历史机遇）、初始冲突（家庭困难/校园霸凌）、第一桶金（怎么来的）

### 示例3：详细方向

**用户输入**："末世来临，主角获得了一个可以升级的随身空间，空间里能种药材和粮食"

**解析 & 补全思路**：
- 题材已明确：末世
- 金手指已有：随身空间 + 种植
- 需要补全：末世类型（丧尸/变异/天灾）、空间升级规则、生存团队组建、势力格局
