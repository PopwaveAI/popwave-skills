## 细纲使用说明

- 本文件是**每卷编排 + 逐章细纲**，可当分卷剧情梗概通读；写作时按章取用。
- **写一章前**：看本章的「关键画面」（至少兑现其中 2 处）、「章末钩子」（必须是最后一段）、「伏笔操作」（该埋的埋、该收的收）。
- **写完一章后**：回 `00-大纲.md` 进度看板更新状态与字数；实际执行与计划的偏差写进**章文件头部元数据**，**不回改本文件**（计划是计划，历史是历史）。
- **卷末三查**：① 最长空档 ≤3 章（不得连续 3 章无看点）② 五型钩子（A/B/C/D/E）都出现过 ③ **关系递进档位逐级递增**，无原地重复。

# 模板自用说明（**交付时整块删除，不得出现在交付文件里**）

## 一、为什么这份模板不长成"七问表"（v1.29.0 纠正）

**2026-09-23 用户验收原话**：「**细纲也是要给用户看的啊，每卷的细纲编排**」。
上一版把本文件定位成"施工图（给 AI 写前填）"，字段写成"事件单元表 / 回合表"——**读者判错了**。
**判据一句话：一份文件给谁看，看它长得像不像故事。** 满篇结构化术语＝AI 视角；"视角｜场景｜关键画面｜章末钩子"＝人读得下去。

## 二、八字段怎么填

| 字段 | 要求 |
|---|---|
| **视角** | 谁的眼睛在看。**本书若规定某角色不进 POV，这里就要守死** |
| **场景** | 地点链（`洞房 → 前堂 → 东厢`），让读者一眼知道这一章走哪几个地方 |
| **核心动作** | 20 字内，**一件具体的事**（"她当众自认替嫁"，不是"她很难过"） |
| **关键画面** | **3 个可拍的画面**（有物件、有动作、有位置）。**它是本章的"事件单元"的可读形态**——写的时候至少兑现 2 处 |
| **情绪曲线** | ≥3 点，允许用符号。**与全书情绪模板同向** |
| **伏笔操作** | `埋【…】` / `收【…】`，与 `00-大纲.md` 悬念线表**双向对齐** |
| **章末钩子** | 五型选一 + **具体内容**。**必须与上一章轮换、强度不降；相邻章不得同型**；四章内五型都要出现过一次 |
| **期待引导** | 读者看完的真实心理活动（"他到底记不记得？"），不是本章小结 |

## 三、事件单元表 / 回合表 / 位置排布 → `.learnings/施工细账_卷N.md`

这三样**是给 AI 写前核对的，不是给人读的**，因此**不进本文件**，写进 `.learnings/施工细账_卷N.md`：

- **事件单元表**（本章发生 2-4 件不同的事；至少 1 件由主角主动发起；**章末单元＝本章最大的一次变化**）
- **回合表**（≥4 回合；逐个写"施压方 → 被压方 → 这一下做了什么 → 局面变了哪一项"；**相邻回合必须写出"和上一回合差在哪"**；**章末回合＝最狠的那一个**）
- **钩子轮换表**（逐章：类型 / 内容 / 强度 vs 上一章）
- **写作状态**（章号 / 标题 / 字数 / 状态）
- 判定方法与形态定义见 `references/scene-beats.md`。

> **验收法**：把交付给用户的 `04-章节细纲.md` 通读一遍——**通篇看不到"事件单元表""回合表""位置排布"任何一个词**，才算合格。

## 四、首章三项硬指标 ＋ 位置排布（**写前定死，写进 `.learnings/施工细账_卷1.md`**）

| # | 指标 | 要求 |
|---|------|------|
| 1 | **爆点 1 个**（矛盾同框／能力现形／代价前置／倒计时，四型任取；**无金手指的题材实际可用三型**） | **前 300 字内**，且**必须在场景里做出来**，不能写在回忆/旁白里 |
| 2 | **爽点 1 个**（碾压／信息兑付／认可／关系兑付／整活兑付，五形态任取） | **前 1/3 内**。**上限＝本章实际字数 × 1/3，当场算出**（如 2429 字 → ≈810），**禁止抄别章的数** |
| 3 | **主角主动行动 ≥1 次** | 没人要求他做的事，他自己做了 |

> **为什么位置必须写前钉死**：**位置是"排"出来的，不是"改"出来的。**
> 实测（2026-09-23 武侠仙侠）：初稿按顺叙写，爆点落在第 872 字（39.4%）、爽点落在第 1108 字（50.0%），**两项全超标**；靠挪句子救不回来（会弄断上下句描述关系），**正确修法是在细纲阶段就决定"第 1 个动作是什么、第几个动作时爽点落地"**。重排后爆点 238 字、爽点 733 字，达标。
> **接近上限＝警报，不是达标**：落在上限 85% 以上时，回一句「**读者在这之前被消耗在哪了？**」——答不出＝前段有该往后挪的内容。
> **超标有三类根因，改法相反，先判类**：① **甲类「读者要的信息来得太晚」→ 信息往前搬**；② **乙类「施压/惩罚内容堆在兑付之前」→ 压力往后挪**（判定问句：「读者在兑付前被消耗在哪了？」）；③ **丙类「爆点句与章末钩子被写成同一句」→ 两句分家**（爆点要"当场就懂、当场解释不了"，钩子要"留问题不给答案"，**不能由同一句承担**）。

## 五、按卷编排的硬要求

- **按卷分节**：`# 卷一《卷名》（第 __-__ 章）` 包住本卷全部章节；**多卷就多个一级标题**。
- **覆盖全书**：不许只写前 3 章就把后面的省掉——**"只看到 1、2、3 章是干什么的"正是用户 2026-09-23 批评的原话**。
- 与 `00-大纲.md` 对齐：**本文件写了几卷 ↔ 大纲第 3.4 节分几幕 ↔ 大纲第 6 节几张每卷章节规划表**，三处章节区间必须一致。
