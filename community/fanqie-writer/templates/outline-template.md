## 2. 主题与立意

> 与第 1 节「核心立意」的分工：那里是一句话**主张**，这里把它拆成**三层**，让写每一章时都知道自己在往哪层落。
> **题材向的书写不出三层就写一层**（类型层），不要硬凑——**硬凑的哲学层会在正文里变成议论，是番茄读者最跑的东西**。

- **题眼**：[一个问句。全书所有事件都是这个问句的不同问法——例："被拆散的人，哪一块才是真的？"]

## 3. 全书剧情脉络

> **⚠️ 这一节回答用户唯一会问的那个问题：「你这篇文到底在说什么？」**
> 2026-09-23 用户验收原话：「**用户不知道你这整篇文在说什么啊，就只看到 1、2、3 章是干什么了**」。
> 病根有两层：① **上游模板**只写到"10-12 章 + 后续章节…"，**整书脉络本就是上游的洞**；
> ② 本模板原有的一段式概括被标成"可选·深化层"，三个类型全跳过。
> **两错叠加 → 交付出去的大纲里，全书只有前 3 章有剧情，其余全是规则。**
>
> **本节四小节的关系（从粗到细，逐级展开）**：
> ```
> 3.0 主线冲突一句话  →  3.1 一段式概括（150-250 字）
>                        ↓
>                     3.2 五句话脊椎（五个结构节点）
>                        ↓
>                     3.3 主要情节点（骨架坐标·按章节）
>                        ↓
>                     3.4 分幕脉络总览（每幕一段话·覆盖全书）
> ```

### 3.0 主线冲突一句话

### 3.1 一段式概括（150-250 字）

[一段话。必须包含六要素：**主角是谁 / 在什么处境 / 要什么 / 谁挡着 / 付出什么代价 / 最后成了什么**。

### 3.2 五句话脊椎（一段话 → 五句话）

> 把 3.1 压成五句，每句对应一个结构节点。**这五句合起来就是全书的脊椎，任何一章写完都应能对上其中某一句。**

1. **起点**：[主角是谁、在哪、日常是什么、缺什么]
2. **第一幕收尾**：[什么事件把他推上无法回头的路]
3. **中点**：[他以为赢了什么；同时发现了什么更根本、更无解的问题]
4. **第二幕收尾（最低谷）**：[他失去了什么、被逼到什么位置、还有什么可赌]
5. **高潮与结局**：[最后的决定是什么、成了什么、代价是什么]

### 3.4 分幕脉络总览（每幕一段话）★ 覆盖全书

> **这是用户最直接要看的东西**：把全书按**幕（大阶段 / 按卷）**切开，每一幕写一段话说清"这一段主角在干什么、对手是谁、走到哪一步、幕尾发生了什么"。

> **⚠️ 与第 6 节「节奏蓝图」的分工（两节都要填，不许互相替代）**：
> - **本节（3.4）＝剧情脉络**：回答"**这一段故事讲了什么**"——是给人看的**故事**。

### 3.5 深化项（道德前提 / 两次两难 / 反复拉扯）

> **本节是深化工具，不是必填项。** 它的价值：把人物动机与主题想透，让长线立得住。
> 写爽文时它不是必需品；**写需要长线立意、多线交织的长篇时它很有用**。
> **判断法：第 3.1～3.4 能不能顺畅填满？能——本节可略；填不顺畅、动机说不清——回来填本节。**
> **唯一硬要求**：若填了本节，它必须与第 6 节对得上（每个情绪单元的功能要能挂到某段升级路径或某次拉扯上）；**对不上时以第 6 节为准**（上游主干优先）。

#### 3.5.3 道德前提

[一句话。句式参考：]
- 「XX 胜于 XX」
- 「XX 导致 XX」
- 「护住 XX 的，从来不是 XX，是 XX」

|---|--------------|-------------------|------|----------------|

| 3 | | | 第 __ 章 | |
