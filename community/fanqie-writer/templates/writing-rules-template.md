# 第二部分 写整体文章的规则（全书级，动笔前必守）

> **下面是骨架条款**。**标 ⚙️ 的是技能死线，不得改动**；其余按本书情况改写。
> 每条都要有**可判定**的落地动作——写不出落地动作的条款，写作期每章都会自行解释一次。

1. **人称与时态**：[正文用第几人称；伪文本／番外各按什么处理；叙述时态］
2. **⚙️ 章首纪律**：每章开头**第一句给新信息或新异常**；禁止承接式回顾（"上回说到"）、禁止天气、禁止"醒来"开场。
3. **⚙️ 章尾纪律**：必须以钩子收尾，类型按 `04-章节细纲.md` 的**钩子轮换表**执行，**强度不低于上一章**；**最后一行尽量短**。
4. **环境描写**：每章 1–3 处，每处必须完成至少一个功能（①暗示 ②伏笔 ③情绪外化）。**纯风景零功能描写禁止。**
5. **心理描写**：以动作与感官外化为主；直接内心独白**每章 ≤3 处、每处 ≤2 句**；本书主角的专属心理节律是 [____]。
6. **台词**：每章对话占比 [__]%；每句台词必须完成"推动情节／揭示人物／制造冲突／传达信息／表达情感／制造悬念"至少一项；潜台词优先于直说。
7. **情感配比（每章硬指标）**：[暖／日常／可爱篇幅 ≥__%（给主情绪做对照组）]。**主情绪不靠堆场面，靠"可爱的东西变质"。**
8. **信息投放**：单章新信息（新规则／新真相／新人物关系）**最多 2 个半**——两个讲透，半个留给下章。禁止一章内把谜底全揭。
9. **规则一致性**：写前必查 `.learnings/STORY_BIBLE.md`（铁律）与 `.learnings/LOCATIONS.md`（区域通行表）；本书的绝对禁忌见 `00-大纲.md` 第 4 节「绝对禁忌」，**逐条复核**。
10. **伏笔台账**：每章写完，把埋/收的伏笔更新到 `00-大纲.md` 第 8 节悬念线表；**>30 章未回收的强制处理**或明确标注"续作引信"。
11. **⚙️ 去 AI 味总纲**：长短句交错；删"然而／此外／不由得／仿佛"类连接腔；删四字格律堆砌；同义表达不连续出现；**每段不超 5 行，一段只讲一件事**。细则见 `references/revision-methods.md`。
12. **⚙️ 标点纪律（死线，不得自造）**：引号一律中文弯引号“”，**禁用「」和英文直引号**；**全书正文禁用破折号**（S1），话被打断用省略号或逗号，揭示用冒号或句号另起；**全篇标点中文全角**，任何半角标点混入即不合格；不用连续感叹号；**省略号每章 ≤3 处**，留给真正的欲言又止。
13. **⚙️ 字数死线**：每章 **2200–2800 字**。**少于 2200 一律不得交付**。**禁止砍内容凑数，也禁止注水超 2800**。
    - **写前排配额，写后只做验收（v1.29.5 改）**——原口径"不够时用扩充技巧补"是**写在写完之后**的，实测第一稿稳定差 18%-35%（三次重写分别是 1486／1822／1475 字）。**正确做法**：写前用 `scripts/plan_word_quota.py` 把总字数分摊到每一场（见写前准备·三）。
    - **差额 > 20% 的场，补的是「场上另外几个人各自的反应」与对白来回，不是形容词**（实测：历次扩写补的全是别人的反应与来回，没有一次是补描写）。
    - 写完用 `scripts/check_chapter_wordcount.py` 校验并记录在看板；**并逐场对账**（甲8），不只报总数。
14. **时间轴纪律（死线）**：常规章节严格顺叙。闪回只允许**整块**出现（一次跳进、内部顺叙、一次跳回）；禁止行文中来回穿插。插叙章须在 `04-章节细纲.md` 预先标注插入点与返回点。
15. **逻辑与推理一致性（死线）**：每个推理链条必须"证据→结论"闭合，禁止自相矛盾。发现型反转动笔前，先列**前文可见性清单**：该信息在前文哪里出现过、角色何时见过、当时如何解读、本章什么新证据催生新解读。**无法闭合的推理，让角色在事实撞墙处收束、矛盾留白，不做伪闭环。**
16. **连续性台账（死线）**：每章交付前核对四类一致性——①人数（在场几人、谁中途离场）②物品（关键道具此刻在谁手上、上次出现的位置）③时间（本章距上章多久、天色时辰、时间状语不打架）④角色知识边界（角色只知道他该知道的）。**新登场／离场／易手的物品与人物状态，当章记入 `.learnings/`。**
17. **行动动机可见性（死线）**：主角的每个重大行动必须有**当章可见的决策链**：触发信息 → 核实或权衡 → 身体动作／心里话锚定 → 决定。**禁止"看见某物就出发"**；配角的关键阻拦、帮助、沉默，至少给半句动机依据。
18. **时代／世界质感一致性（死线）**：[本书的世界层划分是什么？哪层允许哪些词？交界处的冲突怎么给一句可成立的解释？例：现代词不得进入旧制描写，旧俗词不得反向污染现代日常。]
19. **句子主客关系（死线）**：逐句核"谁教谁、谁给谁、谁看谁、谁决定"。代词必须有明确先行词，动作必须有发出者与承受者，半截话必须能判断是省略还是被打断。**主客倒置、悬垂句、无落点的省略句一律改写闭合。**
20. **行文顺畅与细节功能（死线）**：叙述按时间／因果／动作自然流动，**禁止把背景信息切成互不相连的台账短句**；每个细节必须服务人物、氛围、伏笔或动作推进，不做装饰性凑字。**写完朗读一遍，凡需要读者倒回去才明白先后的句子，一律重写。**
21. **句子完整与病句清零（死线）**：不得出现缺主语、缺谓语、缺宾语、搭配不当、半句没收尾、前句后果未闭合的句子。写完逐句做"**谁、做什么、结果怎样**"的补全检查。
22. **道具与人物功能审查（死线）**：新道具／新人物首次登场，必须至少完成一项功能（推进动作／承载已登记伏笔／建立人物关系或动机／制造与主线直接相关的氛围）。**只露面一次且后续无登记功能的一律删去。** 关键道具必须形成"来历→当前位置→知情者/持有者"链条。
23. **规则／警告文本的最小逻辑（死线）**：[本书的规则类文本（须知／手札／遗言／系统提示）至少具备"适用对象 ＋ 触发条件 ＋ 违反后果"中的两项；若故意留白，必须让角色意识到缺项并产生合理追问。]

# 第三部分 写每一章正文的规则（单章操作手册）

## 3.1 单章字数结构（2200–2800 字分配）

| 区块 | 字数 | 任务 | 检查点 |
| --- | --- | --- | --- |
| 开头钩子段 | 0-300 | 承接上章钩子 ＋ 本章新异常；**第一句给信息** | 前 20% 有无即时紧张/反常/冲击 |
| 发展推进 | 300-1900 | 1 个主事件 + 1 个次事件；2-3 个场景；至少一次"安心→破绽"小起伏 | 每场戏是否都在推进？**删掉任何一场故事还成立吗？成立就删** |
| 本章峰值 | 1900-2400 | 情绪最高点（震惊/崩塌/泪点），用最平的语言写 | 峰值句是否可以"划线"？ |
| 收束+钩子 | 2400-2800 | 本章信息落点一句话 ＋ 章末钩子（**最后一行要短**） | 钩子类型是否与上章错开？强度是否 ≥ 上章？ |

> **⚠️ 本表是"分区段"的粗尺，不是写前配额（v1.29.5 补）**：它能告诉你"哪一段该多长"，**不能告诉你要写多少段**——而第一稿写不到字数的根因恰恰是**段数/拍数不够**。**写前一律以 `.learnings/施工细账_卷N.md` 的「字数配额表」为准**（逐场配额，由 `scripts/plan_word_quota.py` 算出）。本表与配额表冲突时，**以配额表为准**。

> **首章另有位置硬指标**（爆点前 300 字 / 爽点前 1/3），见 `04-章节细纲.md` 第 1 章「位置排布」。

## 3.2 环境描写规则

- **位置**：放在场景开头（≤3 行定氛围）或情绪转折点（环境突变＝规则异常的信号），**不放章中腰**。
- **三写法**：① **以人带景**——环境都从视角人物的感官进，不悬空单写；② **景带伏笔**——环境细节里藏一个可回看的伏笔；③ **景随情变**——同一地点第二次出现时环境必须有变化。
- **禁忌**：不堆清单式景物；**一段环境 ≤3 个意象**。

## 3.3 心理描写规则

- **外化七法（按优先级）**：①动作 ②生理反应 ③习惯物 ④对话潜台词 ⑤错觉／通感 ⑥直接独白（限 3 处/章、2 句/处）⑦环境投射。
- **本书主角的专属心理节律**：[例如"先记录后感受"这类职业习惯——这是他与常人不同、也最可爱的地方]。

## 3.4 人物台词规则

**通用**：每章对话占比 [__]%；能辨识说话人（**遮住名字能分清谁说的**）；每句台词带目的；潜台词优先；真实的人话不完整（打断、迟疑、话没说完）。

**角色声音库（写作时对照，保证全书不走音）**：

| 角色 | 句式/用词 | 潜台词习惯 | 参考句 |
| --- | --- | --- | --- |
| [主角] | | | |
| [对手] | | | |
| [配角 A] | | | |

**禁忌**：不让任何角色说作者话（世界观解说、主题总结）；情绪场景禁止角色自己说"好可怕／好爽"。

## 3.5 节奏与情绪曲线规则

**单章内（至少 3 次情绪拐点）**：

```
[开头] 承接上章情绪 → 250 字内完成第一次小转折
[中段] 至少一次"波谷蓄力"：放缓、放暖（给日常篇幅），然后转折升级
[峰值] 本章最高点落在 70%-85% 处，用最平的语言
[钩子] 最后 100-300 字急停，最后一行 ≤15 字
```

**三章单元对齐（每 3 章检查一次）**：本单元在"压-小扬-压-爆"循环中的位置决定本章基调（见 `02-情绪曲线.md` 单元规划表）；爆点章前两章必须各留一个"未爆的引信"；**爆点章后第一章必须"降压"，但降压章的钩子强度不能降**。

**信息密度交替**：高密度（对话多、事件快）与低密度（环境、心理、仪式感）交替；**连续两章不得同为高密度**。

## 3.6 每章写作 SOP（按序执行，不可跳步）

1. **读**（写前必读，一次不漏）：`00-大纲.md`（本章在全书脉络/情绪单元中的位置）→ `04-章节细纲.md`（本章七问）→ `05-文体与写作规则.md`（本文件）→ `.learnings/CHARACTERS.md` → `.learnings/LOCATIONS.md` → `.learnings/PLOT_POINTS.md`（待回收伏笔）→ `.learnings/STORY_BIBLE.md`（铁律）→ **上一章正文**（衔接与钩子兑现）。
2. **析**：确认 ①开头钩子怎么接上一章 ②本章 3 次情绪拐点落点 ③环境写在哪两处 ④台词重头戏是谁 ⑤伏笔埋几个收几个（**写前两产物：动作链治"跳" ＋ 信息增量表治"碎"**，见 `prose-rules-supplement.md` S7.1）。
3. **写**：按 3.1 结构写正文，先不修饰，把事件和台词写顺。
4. **润**：加环境与心理（按 3.2/3.3 限额），把叙述腔改成人话，删 AI 高频词，把"讲述"改成"展示"。
5. **查**：过 3.7 自检清单 + 3.8 承接测试四问（**一票否决**）；跑 `scripts/check_chapter_wordcount.py` 与 `scripts/chapter_stats.py`；不合格回第 4 步。
6. **记**：更新 CHARACTERS / LOCATIONS / PLOT_POINTS / STORY_BIBLE → 回填 `00-大纲.md` 进度看板与摘要区、`02-情绪曲线.md` 钩子记录 → 登记本章埋/收伏笔。

## 3.7 每章自检清单（交付前逐条**举证**，禁止打勾）

> **纪律**：本技能禁止清单式打勾——**每一条都要写清"位置／问题类型／原句／修法"**（见 `prose-rules-supplement.md` S5.3）。

**开头（一票否决）**
- 前 50 字内有新信息或新异常？
- 第一句不是天气/醒来/回顾/风景？
- 看完前三段想继续读吗？

**内容与节奏**
- 单章 ≥3 次情绪拐点？
- 日常／对照组篇幅 ≥ 本书约定值？
- 本章在 3 章单元里的情绪任务完成了吗？
- 信息投放 ≤2 个半？
- 每场戏删掉后故事是否受损？（**都受损才合格**）
- 每个新人物、新物件都能说出明确功能吗？

**描写**
- 环境描写 1-3 处，每处带功能？
- 心理独白 ≤3 处且 ≤2 句/处？
- 对话占比达标，遮住名字能分清谁说的？

**本书类型专项**
- 本书的主情绪是否靠"日常变质"而非堆词实现？
- 禁用词清单全避开了吗？
- 主要角色的出场是否符合 `STORY_BIBLE.md` 的规则？
- 有没有替角色"解释"了不该解释的？

**钩子与伏笔**
- 章末钩子类型与上章错开、强度不降？
- 最后一行 ≤15 字？
- 细纲里标注的伏笔埋/收都执行了？
- 有一处"划线句"（读者会想截图评论的句子）吗？

**格式（死线）**
- 字数 2200-2800？**少于 2200 不得交付**，已用脚本校验并记录？
- 段落 1-3 行为主？无连续感叹号、省略号 ≤3？
- **全文零破折号**？引号全是中文“”？所有标点全角、无半角混入？

## 3.8 承接测试四问与风格档（**一票否决，逐条举证**）

> **这一节是硬伤层的唯一判据**（`prose-rules-supplement.md` S5.3 / S6）。**风格层只画像不判定**（对白占比／均段长／均句长等，因异风格样本包络跨度极大、统计不可分）；**硬伤层只判四类语言错误**。

**四问（逐句/逐段做，写明位置 → 问题类型 → 原句 → 缺失项 → 修法）**

1. **有信息吗？看得出要干什么吗？**（治"碎"——**碎 ＝ 句子短且看不出要干什么、看不出行为模式和逻辑，不是"句子短"**）
2. **接得上吗？中间那几步在不在？**（治"跳"——四类缺环：姿态变更／空间位移／取物／时间跳转。**判据动作：照着做一遍，中间步骤在不在**）
3. **指得清吗？**（代词与指称有明确先行词）
4. **对得上吗？**（上下句描述关系一致，无自相矛盾）

**风格档位（写作前选档，写后核对是否落在档内）**

| 档 | 类型 | 特征 | 适用题材 |
|---|---|---|---|
| **A** | 叙述驱动·意象流 | 对白低，长句铺陈，靠物象承载情绪 | 言情正剧、悬疑、氛围向 |
| **B** | 长句叙述·心理流 | 叙述长句为主，对白夹在叙述行内 | 言情、日常流、种田 |
| **C** | 短句碎切·动作流 | 均句长 11–21，短句率高，但**每句推进一步动作** | 现代言情、快节奏情绪章、**玄幻修真** |
| **D** | 对白驱动·插科打诨 | 对白 20–92%，节奏靠对话推进，笑点/冲突在来回里 | 轻喜、种田、**沙雕/爆笑反套路**、玄幻日常 |
| **E** | 对话驱动·长句对白 | 对白占比高但引号内是长句，一句交代一件事 | 古言、朝堂、权谋 |

> **本书选档**：[__] 档。**选档后写第 1 章并回测**：对白行占比／均句长／短句率是否落在该档样本区间内（区间见 `benchmark-writing.md`）。
> **不在区间内不等于错**——风格层只画像。但**连续三章都明显偏离所选档**，说明档位选错了，回本节改档，不要改正文去凑数。

> **硬伤四类（语言错误，须逐条举证，禁止打勾）**：病句 ／ 碎句 ／ 跳 ／ 上下句描述错误。
> **机器门禁**（`scripts/chapter_stats.py`）只判**确定性错误**：破折号 S1／ASCII 直引号／标点错配／引号不配对／相邻行重复／叠字／半截句（WARN）／跨章对白复现／**正文含拉丁字母（FAIL）**／**半角数字（WARN）**。
> **机器判的与四问判的不是一回事**：前者＝格式规范，后者＝语言质量。**两者不可互证。**
