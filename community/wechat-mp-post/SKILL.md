# 公众号推文成稿

把已经写好的稿子加工成能粘进公众号后台的成稿，并交一份真机风格预览。

## 什么时候用

- 用户手里已有正文，要变成公众号可发布的稿子。
- 用户说"能直接粘贴""粘过去不跑版""按公众号排版"。
- 用户要一份能在浏览器里看效果的预览稿。

不要用在：从零想选题、从零写正文，那属于写作类 skill；也不要用来发布，后台的点按由用户自己完成。用户只贴了一段纯 markdown 说要排版时，先问清正文是否已定稿，稿子在改就等定稿再排。

## 一、四条硬规则

公众号后台会剥掉 `<style>` 标签、class 选择器与嵌套容器，只保留标签自己身上的 `style=""`。下面四条破了就掉样式。

1. 禁用 `<h1>` 到 `<h6>`。后台对语义标签强制定样式，行内 style 覆盖不了。所有标题写成 `<p style="...">`。
2. 禁止依赖继承。后台给 `<p>` 默认 `text-align:left`，会盖住父级。每个元素把自己需要的样式写全。
3. 结构必须扁平。嵌套 `<div>` 会被打平或剥掉。每个可见元素都是独立的顶层 `<p>`，自带全套样式。
4. 动手前就先按扁平写。先铺嵌套再拆开，等于重写一遍。

## 二、能用的属性与禁用的属性

能用：`color` `font-size` `font-weight` `background` `border` `border-radius` `box-shadow` `padding` `margin` `line-height` `text-align` `max-width` `width` `overflow-x` `float` `display:inline-block`。单位优先 `px`。

禁用：class、`<style>` 块、外链 CSS、`var()`、`display:flex`、`position`、`@media`、伪类、`@keyframes`、外链字体、JS。

并排多元素不用 flex，用 `display:inline-block` 加定宽，父级 `font-size:0` 消掉元素间空隙。

## 三、常见版式的写法

下列数值是起点，按内容长短和账号调性上下浮动，不要当成验收线。

- **正文段**：`<p style="font-size:16px;line-height:1.9;color:#2b2b2b;margin:0 0 20px;">`。每段 3 到 6 行手机屏。
- **章节编号**：单独一行 `<p>`，小字、加字距、低对比色，与下面的标题拉开 24 到 32px。
- **章节标题**：`font-size:20px;font-weight:bold`，别用 h 标签。
- **单句成段大字**：一句狠话独立成段、居中、字号放大到 20 到 22px，靠上下留白做重音。一篇用一到两处。
- **局部高亮**：关键术语或数字加底色或变色，一屏最多两处。整篇到处高亮等于没有高亮。
- **引用块**：金句用浅底色或左侧一条细边线，靠 `padding` 与正文拉开，不用 `border-left` 之外的花样。
- **数据卡**：`inline-block` 定宽并排，卡内自己写全字号与内边距。
- **分隔**：用短横线或单独一行符号居中，别用 `<hr>` 加花边。

配色按账号定，全文三到四个颜色封顶：一个底色、一个正文色、一个强调色，其余留给图片。强调色只出现在标注过的地方。

## 四、加工与交付四步

1. 读稿定型。通读正文，标出哪些句子是重音、哪些是章节分界、哪里要配图。稿子结构不清就先跟用户确认分节，不要自己重排逻辑。
2. 定调。问清或从账号既有样子推断三件事：正文色与底色、强调色、字号基调（偏小密还是偏大疏）。用户没说就按上一节的起点走，并在交付时说明用的是默认值。
3. 写扁平 HTML。按第一节四条写，一路扁平到底。
4. 自检后交付。跑第五节的检查，交一个能直接打开的 HTML 文件路径，并说明可粘贴的范围（正文区那部分元素）。

## 五、交付前自检

逐条在成品文件里搜一遍，命中数不为零就改：

- `<h` 命中数为 0。
- `class=` 命中数为 0。
- `<style` 与 `<link` 命中数为 0。
- `display:flex`、`position:`、`var(`、`@media`、`@keyframes` 命中数为 0。
- 随机抽五段正文，每段都自带 `font-size` 与 `line-height`，不靠继承。
- 正文区元素没有包在 `<div>` 里。
- 每张图有 `alt`，宽高比没有被拉伸。
- 预览文件能在浏览器里打开，正文区在手机宽度下不出现横向滚动条。

## 六、与其它 skill 的分工

- 从零写选题与正文：交给写作类 skill，本 skill 只接手成稿。
- 要出竖版长图给截图分享：走 `pop-content-card`。
- 要给小说做推书卡：走 `pop-recommend`。
- 要出的是海报、封面、KV 这类单张视觉成品：走 `visual-image-generator` 那类生图 skill，本 skill 不管出图，只把图排进段落里。
