# 🧭 专家使用百科

> 你不是产品经理，也不需要懂 AI。这份百科是给**作者、漫画人、同人爱好者**看的——想知道"哪些专家能帮我做什么、怎么开口开始"，翻这里就够了。
>
> 和「首次对话引导（onboarding）」的区别：引导是第一次见面时我口头带你走一遍；百科是你随时回来看的**完整使用手册**——每个专家能做什么、有哪些玩法、怎么开始、完整能力清单、常见问题，都在这。

## 怎么选专家？

- 我想**写小说** → 起点 / 番茄专家（想清楚自己更偏哪个平台读者口味）
- 我想**抄爆款的门道** → 拆书专家
- 我想把自己的小说 / 角色 / OC **画出来** → 视觉专家
- 我想**先看看别家怎么写**再动笔 → 拆书专家
- 我**写了一半**，想把前几章做成漫画 → 视觉专家

---

## 通用使用原则（所有专家都适用）

1. **你只要开口说需求，不用懂任何术语。** 什么赛道、节奏、爽点、画风，都不用管原理，交给我的判断。
2. **先小样、再铺开。** 无论是写小说还是画图，我都先出 1-2 章 / 1-2 张样张给你看，你满意了我们再一路往下做，不让你白等。
3. **可以只做起步，也可以一路陪到底。** 哪个阶段卡住了，就从哪个阶段接着来，不用从头跑。
4. **想中断 / 换方向，随时说。** 我不会闷头一口气跑完，关键节点都会先问你。
