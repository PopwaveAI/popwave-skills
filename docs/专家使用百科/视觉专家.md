# 🎨 视觉专家 · 使用百科

> 你写的是文字，这个专家把它变成看得见的作品——封面、人物立绘 / OC、整章漫画。不用你懂任何技术，你只要告诉我书名和想要什么，剩下的我全包。

---

## 我帮你做什么

- **🎨 封面**：给你的小说做一张能一眼抓住人的封面。读者扫过书架，0.3 秒决定要不要点开——这就是"第一眼"的杀伤力。
- **🧑 人物立绘 / OC**：把你想的那个角色画出来。一张能收藏、能当壁纸、能发社交平台的立绘，附人物设定小卡。原创角色、同人 OC 都可以。
- **📖 漫画**：把关键情节、甚至整本书，画成一页页能往下翻的连载。分镜、台词、情绪、氛围都替你排好，**没看过你原著的读者也能看懂**。发出去就是连载。

只做一样可以，全都要也行——封面、立绘、漫画一起上，**一套画风从头到尾不串味**。

---

## 怎么开始

**直接把「书名 + 你想做什么」丢给我就行。**

- 《诡秘之主》，做封面
- 我这本书，画主角的立绘
- 这部写一半了，把前几章做成漫画

我开工前会先确认你想做哪样，然后**先出 1-2 张样张**给你看画风手感，你满意了我们再铺开做整本 / 整章。

## 怎么按你自己的步子走

- **只想做一张封面**：说"做封面"，我先把画风定好，再出封面。
- **想画一个人物**：给角色名 + 一句描述，我出立绘带设定小卡。
- **想做成漫画**：给书名 + 要画的章节，我排出分镜再出页。
- **封面、立绘、漫画都想要**：都行，我保证一套画风不串味。

## 常见疑问

**角色在不同图里会不会"换脸"？**
不会。同一个角色，封面、立绘、漫画用的是同一张脸、同一套风格，因为我们先定了一份"美术设定集"当标准，后面所有图都照着它来。

**我完全不懂画图 / 技术，可以吗？**
可以。你只管给书名 + 想法，流程我全包。

**先小样再开整，具体怎么个流程？**
我先出 1-2 张样张给你看画风手感，你满意了我们再铺开做整本 / 整章。不让你白等。

**做出来的图能拿去用吗？**
能。封面、立绘、漫画页都是能直接发出去的成品。
