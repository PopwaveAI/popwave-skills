# 📖 起点网文专家 · 使用百科

> 你有个"想写本起点小说"的念头，但对着空白页发过愁？这个专家陪你从立项到成文一路走完——定赛道、搭设定、一章章写正文、再自查能不能留住读者。你负责出想法，我负责把想法变成能发出去的文字。

---

## 我帮你做什么

- **从零立项**：先定赛道、标签、参考书，把书的骨架立起来，不绕弯路。
- **搭世界观**：主角、力量体系、世界格局、剧情主干一层层搭清楚，后面写才不会崩。
- **逐章成文**：按起点读者口味，一章章把情节铺开、对白写活、爽点节奏卡准。
- **自查把关**：每章写完，替你照着"读者会不会跳章、爽不爽、有没有坑"过一遍，当场改。

可以只做起步，也可以一直陪你写到完结。哪个阶段卡住，就从哪个阶段接上。

---

## 怎么开始

**直接把「你想写什么」丢给我就行。**

- 我想写本修仙文，帮我立项
- 有个主角设定，帮我搭世界观
- 已写了个开头，帮我把第一章磨出来

我开工前会先和你确认几步（想写给谁看、大概什么风格），然后先出 1-2 章小样给你看手感。

## 完整能力清单

| 能力 | 干什么用 | 什么时候用到 |
|:-----|:---------|:-------------|
| **立项创意** | 定骨架、力量体系、主角、创意方向 | 一开始写书时 |
| **世界构筑** | 把全书设定（力量/地图/势力/危机等）搭成立得住的底子 | 立项之后 |
| **文风定位** | 综合你的笔触偏好 + 世界画风，定下整本书的"味道" | 世界观定好后 |
| **角色库** | 把主要角色立起来，有动机、有成长 | 世界观之后 |
| **卷纲 + 章锚点** | 规划一卷怎么推进、每一章卡在哪几个关键点 | 写正文前 |
| **正文渲染** | 一章章把正文写出来 | 大纲定好后 |
| **审核 + 沉淀** | 写完后自查把关，并把全书最新状态沉淀下来 | 每章写完后 |
| **赛道调研 / 拆书** | 看看对标书怎么写的，为你的书找方向 | 立项时（可复用其他专家） |

## 怎么按你自己的步子走

- **只想试试**：先写 1-2 章小样，满意再铺开整本。
- **已有设定/开头**：直接丢给我，我会先接住你已有的东西再往下走，不用从零重来。
- **写一半接不上**：说一声，我接着你的进度往下写。
- **只想搭骨架**：先立项 + 世界观，正文以后再说。

## 常见疑问

**会用很多专业名词吗？**
不会。什么赛道、节奏、爽点，你只管说想法，判断交给我。

**写出来能直接发吗？**
写的是起点向正文，标题、开头、爽点节奏都按起点读者习惯卡过，是能跟进度的正文。但发不发、改不改，当然由你定。

**写到一半想换方向？**
随时说，我从你想换的地方接着来，不会闷头按原计划跑完。
