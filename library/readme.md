# Popwave 网文百科 · 总索引

> 定位：帮 AI agent 写小说的知识库（机器优先，人可浏览）。所有知识离写作的距离分四层，外加两个动态/成品维度。

## 六库架构

```
library/
├── 赛道设定集/      ← 配方层：某赛道怎么写（18包，去专名+源书锚点）
├── 写作技法库/       ← 技法层：怎么写得好（文风DNA/章型场景/元素卡库54卡/情感张力）
├── 素材原型库/       ← 原型层：用什么料（人设原型/CP模板/金手指原型）
├── 世界知识库/       ← 世界层：写什么背景（IP百科/神话体系/历史资料，带专名·官方源）
├── 知名小说wiki/     ← 成品层：整书深度拆解成品（对齐《深渊主宰》重建标准）
└── 网文动态/         ← 情报层：圈子正在发生什么（编年史/每日简报）
```

| 库 | 回答的问题 | 采源标准 | 专名策略 |
|:--|:--|:--|:--|
| 赛道设定集 | 这个赛道怎么写 | 本赛道最好的小说txt实测拆书 | 去专名（抄机制不抄事件） |
| 写作技法库 | 怎么写得好 | 优秀作品技法蒸馏+权威写作教程 | 跨赛道通用 |
| 素材原型库 | 用什么料 | 爆款作品原型提取 | 半成品可错配 |
| 世界知识库 | 写什么背景 | 官方设定集/权威wiki/公版原文 | **带专名**（事实性知识） |
| 知名小说wiki | 整本书怎么重建 | 章节逐幕拆解，对齐赛道/重建标准 | 源书实名，专名保留 |
| 网文动态 | 圈子现状与走向 | 榜单/新闻/平台公告 | 按日期归档 |

## 全库通用基线（所有分支适用）

1. **单件 ≤15KB**，超限必须拆分；frontmatter 带 `read_policy`（机器优先）
2. **无源不入库**：每件知识必须能回答"凭什么这么写"——源书锚点 / 官方设定 / 公版原文 / 权威教程
3. **采样留痕**：跨书/跨章采样类知识，必须带"书名 + 章节范围 + 件数 + 缺口"留痕块，无留痕=不合格
4. **命名唯一**：中文命名、主题化（`具体事`/`-族`/`-模块`），禁止 `_原文案`/`_HTML源码` 双文件冗余（合并为单一 wiki 页）
5. **禁止百科式散文**：agent 优先，分类唯一维度 = 知识离写作的距离，无"杂项抽屉"

> 各分支深度约束以「入库约束速查表」指向的文件为准，本表基线不与之重复、只兜底。

## 红线（全库通用）

1. **防乱编**：每类知识有采源标准（拆书锚点/官方设定/公版原文），无源内容不入库
2. **agent 优先**：单件≤15KB，frontmatter 带 read_policy，禁止百科式散文
3. **约束单源**：入库约束只存在「入库约束速查表」指向的唯一文件，不双源
4. **分类唯一维度 = 知识离写作的距离**，无"杂项抽屉"
