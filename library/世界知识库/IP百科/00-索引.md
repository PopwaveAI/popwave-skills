## 包结构（六件套·暂定模板，边收边校）

```
{IP名}/
├── readme.md        ← 总纲：这个IP是什么+世界观框架+包组成
├── 力量体系.md      ← 等级/能力/战斗规则（网文最常借用）
├── 种族与阵营.md    ← 角色标签系统+种族原型
├── 位面与生态.md    ← 世界结构+怪物生态+反派档案
├── 叙事装置.md      ← 该IP的结构装置（组队/副本/节奏）
└── 版权指南.md      ← 什么能写什么必须避开
```

> ⚠️ 模板为 DND 首包试行版，后续包（克苏鲁/神话类）按内容特性调整——神话类无统一版权方，"版权指南"或改"版本源流考"。

## 采源标准（硬门禁）

1. **官方优先**：官方设定集/规则书（SRD）> 权威维基 > 社区资料；frontmatter 标 `source_type: official-srd / wiki / public-domain`
2. **禁止凭印象写设定**：阵营写错一格，下游赛道包全歪
3. **每件带 sources 字段**：具体 URL 或出版物名
4. **编辑加工与事实分离**：官方数据为主体，网文转化建议标「编辑建议/写作参考」

## 消费方式

- 赛道包采源：配方层文件（如西幻dnd 力量体系）引用本库原料，去专名转化
- 世界构筑：world skill 的地理/势力/危机档案引用本库结构重命名
- 正文红线：专名进正文前必须过各包版权指南
