# DC 宇宙（DC Universe）· 总纲

> **一句话**：DC 宇宙是 DC 漫画（DC Comics）旗下超级英雄共享宇宙的统称，漫画本体自 1938 年《Action Comics #1》（超人首次登场）绵延至今，历经 1985《无限地球危机》、2011《闪点》/新52、2016《重生》、2021《无限边界》、2024《DC All In》等多轮"危机级"重启；而统治当代大众（尤其中国观众）大脑的，更多是 DCAU 动画、诺兰黑暗骑士三部曲、DCEU 电影宇宙与中文社区梗文化——它没有单一"原典"，漫画与影视两条线既有继承又有大量改写（蝙蝠侠的黑暗人设、超人的神性、哥谭的城市印象在影视层被彻底固化），是"双线并行"的典型。

## 一、双线判定（见 `世界知识库/references/双线范式.md`）

| 判定项 | 结论 |
|:--|:--|
| **类型** | **双线并行（影视主导偏）**——漫画主线宇宙（Prime Earth/Earth-0）是设定源头与压舱石，但大众认知由 DCAU 动画、真人影视、游戏与中文社区梗文化层层叠层统治；"DC=黑暗苦大仇深""蝙蝠侠=钞能力"等影视层印象已与漫画原典分叉 |
| **线1 · 原文考据（压舱）** | DC Comics 主线宇宙正史设定：多元宇宙结构（52 宇宙/黑暗多元宇宙/起源之墙）、抽象实体（至高存在/幽灵/监视者）、众神领域（新创世星/天启星/天堂/地狱）、宇宙七力（神速力/情感光谱）、危机重启史（1985-2024）、核心团队与角色。只认可追溯事实（英文维基/dc.fandom），记版本冲突不压扁 |
| **线2 · 集体无意识印象测绘** | DCAU 动画层（蝙蝠侠TAS/正义联盟动画）、真人影视层（Burton 1989 → Nolan 三部曲 → DCEU 施奈德 → DCU 冈恩 → 小丑 2019）、游戏层（阿卡姆/不义联盟）、中文社区/梗文化层（苦大仇深/钞能力/民风淳朴哥谭）、与漫威对比印象层。独立出「印象测绘」，与原典件显性分家 |
| **关键错位（本包必须先拆开）** | ① **"DC=黑暗苦大仇深"**：多为影视层（Nolan/DCEU）固化印象，漫画里也有阳光超人、乐天闪电侠、Kid 系英雄；② **"蝙蝠侠=有钱/钞能力"**：源自 2017《正义联盟》电影台词 "I am rich"，漫画原典的蝙蝠侠核心是侦探、武术、心理博弈；③ **"超人=无敌红披风"**：忽略氪石弱点与道德困境的设定骨架；④ **"小丑=希斯·莱杰/华金·菲尼克斯"**：漫画小丑起源本就模糊、版本众多，两版电影只是影视层代表节点 |

## 五、两层关系与消费方式

- **线1/线2 分工**：线1（叙事层）回答"DC 漫画设定里这个宇宙客观是什么"；线2（印象测绘）回答"大众/影视观众/中文读者大脑里这宇宙成了什么、哪些被误当原典"；两件分开存放、冲突不压扁。
- **赛道包采源**：本包是带专名的原料层；黑暗英雄流/超英流/共享宇宙类赛道包的「危机重启/起源/组队/镜像反派/多元宇宙/神性vs人性」等配方由此蒸馏（去专名）。
- **world 构筑**：多元宇宙+抽象实体层级、起源之墙/本源、众神领域双星对立（新创世星vs天启星）、神速力类超速机制、情感光谱类情绪能量体系可整体借鉴重命名。
- **消费红线**：任何 DC 专名（超人/蝙蝠侠/神奇女侠/正义联盟/哥谭/小丑/达克赛德等）进正文前过 `版权指南.md`；"超级英雄/起源/组队/镜像反派/危机重启"属思想层可自由化用；"I am rich""民风淳朴哥谭市"等属线2 表达层，用时标注来源属性、不得照搬名场面。

## 六、采源与采样留痕

- **线1 事实**：以 DC Comics 主线宇宙为准——英文维基（DC_Multiverse/Prime_Earth/Crisis_on_Infinite_Earths/DC_Rebirth/Infinite_Frontier/DC_All_In/Speed_Force/The_Source/The_Presence/Spectre/Monitor/Anti-Monitor/Metron/Endless/Apokolips/New_Gods + 六团队六角色）加 dc.fandom（Source_Wall/New_Genesis/Sphere_of_the_Gods/Emotional_Spectrum）交叉。关键点（主线宇宙沿革/52 宇宙与黑暗多元宇宙/起源之墙与本源/众神领域八大域/情感光谱七色/危机重启史/团队成立年份与成员/角色诞生年份与创作者）逐条核验，≥8 处 URL 交叉；"DC=黑暗""蝙蝠侠=有钱""超人=无敌"等易混点已显性拆解。
- **线2 事实**：影视层（DCAU/The_Dark_Knight_Trilogy/Batman_1989/DCEU/DCU/Joker_2019/Aquaman/Flash 2023）英文维基 + 游戏层（Batman:_Arkham/Injustice/Gotham_Knights/Suicide_Squad_Kill_the_JL）+ 中文源（baike.com/萌娘百科/豆瓣/头条/新浪/IT之家/搜狐）+ 票房新闻交叉。
- **采样留痕**：本研究周期实际核验源 ≥50（跨英文维基/dc.fandom/影视词条/版权新闻/中文百科/社区），关键事实点 ≥8 处带 URL 交叉；「民风淳朴哥谭市/人才辈出阿卡姆」等社区对仗句暂无独立 URL，如实标注"社区流传待补证"，不编造出处。
- **禁止凭印象补设定**——「DC=黑暗苦大仇深」「蝙蝠侠=钞能力」「超人=无敌红披风」「小丑=某版演员」「Super Hero 商标仍被 DC/漫威独占」是五处最易带偏网文读者的误认，本包在双线判定与各件中显性标注。
