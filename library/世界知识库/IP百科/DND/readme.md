# DND（龙与地下城）· 总纲

> **一句话**：DND 是1974年诞生的桌上角色扮演游戏（TRPG）鼻祖，由规则手册（玩家手册PHB/地下城主指南DMG/怪物图鉴MM）+ 战役设定（被遗忘的国度等）+ 骰子判定构成，是全球奇幻网文最大的规则语料库。西幻/诡秘流网文的"等级/职业/法术位/阵营/位面"体系几乎全部溯源于此。

## 二、世界观框架（大轮模型 Great Wheel）

```
        外位面（按九阵营分布——天堂山/九层地狱/无底深渊…）
              ↕ 星界 Astral（位面之间的"海"）
        以太位面 Ethereal（贴物质位面的"雾层"）
              ↕
        物质位面 Material（冒险者所在的世界）
              ↕
        内位面（元素/能量——火/水/气/土/正/负能量）
```

- **主世界=物质位面**；星界/以太是"层间通道"；影界（Shadowfell）与妖精荒野（Feywild）是物质位面的明暗两面
- 外位面按**阵营九宫格**分布——灵魂死后的去处由生前的阵营决定（网文"死后审判"装置的源头）
- 深渊（Demon，混乱恶）≠ 九层地狱（Devil，守序恶）：**恶魔毁灭一切，魔鬼订契约收灵魂**——网文借用重灾区，详见 `种族与阵营.md`
