# DND（龙与地下城）· 总纲

> **一句话**：DND 是1974年诞生的桌上角色扮演游戏（TRPG）鼻祖，由规则手册（PHB/DMG/MM）+ 战役设定（被遗忘的国度等）+ 骰子判定构成，是全球奇幻网文最大的规则语料库。西幻/诡秘流网文的"等级/职业/法术位/阵营/位面"体系几乎全部溯源于此。

## 二、世界观框架（大轮模型 Great Wheel）

```
        外位面（按九阵营分布——天堂山/九层地狱/无底深渊…）
              ↕ 星界 Astral（位面之间的"海"）
        以太位面 Ethereal（贴物质位面的"雾层"）
              ↕
        物质位面 Material（冒险者所在的世界）
              ↕
        内位面（元素/能量——火/水/气/土/正/负能量）
```

- **主世界=物质位面**；星界/以太是"层间通道"；影界（Shadowfell）与妖精荒野（Feywild）是物质位面的明暗两面
- 外位面按**阵营九宫格**分布——灵魂死后的去处由生前的阵营决定
- 深渊（Demon，混乱恶）≠ 九层地狱（Devil，守序恶）：**恶魔毁灭一切，魔鬼订契约收灵魂**

## 四、两层关系与消费方式

**两层分工**：规则层回答"这个IP是什么"（表格速查，写作时随查随用）；叙事层回答"这个世界怎么讲故事"（沉浸式叙事百科，世界观构筑与设定扩写时深读）。规则层的 `位面与生态.md` 给位面一张总表，叙事层 02-04 件给每个位面一整篇风土志——总表管广度，叙事管深度。

- **赛道包采源**：西幻dnd 赛道包与本包是配方层↔原料层关系——包内是蒸馏配方（去专名），本包是带专名事实库
- **world 构筑**：因果链推演7维度可直接引用本包设定重命名使用；位面/神系/历史线优先深读叙事层对应件
- **消费红线**：从本包拿走的是**结构与机制**；专名进正文前必须过 `版权指南.md` 规避清单与叙事层各件专名雷达
