# DND 位面与生态

> **一句话**：宇宙是同心轮——物质位面居中，元素为骨（内位面），灵魂为归处（外位面按九阵营排布），正负能量包裹一切。**深渊（恶魔）≠九层地狱（魔鬼）：恶魔毁灭一切，魔鬼订契约收灵魂。**

| 位面 | 一句话定义（官方口径） | 网文用法 |
|:--|:--|:--|
| 物质位面 Material | 一切冒险主世界所在——诸种哲学与元素力量碰撞成凡俗存在 | 主舞台 |
| 妖精荒野 Feywild | 物质位面的"明镜"：地形相似但更奇妙异想、魔法更浓、情绪更烈；精类老家 | 仙境副本/精类交易 |
| 影界 Shadowfell | 物质位面的"暗镜"：更阴郁不祥；死亡与哀恸关联之地 | 暗黑地图/亡灵巢穴 |
| 以太位面 Ethereal | 雾海；边境以太与物质/内位面重叠（每地有对应点），深处为深以太 | 潜行/穿墙/幽身窥探 |
| 星界 Astral | 思想与梦的银海；旅者以离体灵魂形态穿行，通往诸神与外位面 | 灵魂出窍/跨世界航路 |
| 四元素位面 | 火/水/气/土的纯粹国度；内侧似物质世界，外侧渐纯粹敌对，最外溶解为**元素混沌** | 元素之国/火之国等地图 |
| 正/负能量位面 | 生命与死亡的原初力量，包裹整个宇宙 | 生死法则具象化/复活术代价 |

**大轮三定律**：①位面是"层"不是"球"——空间关系可画成地图；②灵魂去处由生前阵营与所事神祇决定——死后审判装置的规则基础；③**位面即阵营的地理化**——去什么位面=进什么道德国境（官方"位面失调"机制：阵营不合者在外位面感到深刻不谐，久居甚至被位面气质同化）。

## 三、恶魔 vs 魔鬼（网文借用重灾区，务必分清）

| 维度 | 恶魔 Demon | 魔鬼 Devil |
|:--|:--|:--|
| 家园 | 无底深渊（混乱恶） | 九层地狱（守序恶） |
| 阵营本质 | "贪婪、仇恨或嗜血驱动的任意暴力"（SRD原句） | "在传统、忠诚或秩序框架内有条不紊地夺取"（SRD原句） |
| 组织度 | 弱肉强食，无纪律，靠魔王个体威压 | 九层科层官僚制，等级森严，有晋升阶梯与成文法 |
| 战术 | 人海+狂暴，**不可谈判** | 规则内行事，先谈后打，契约先行 |
| 灵魂观 | 毁灭/吞噬 | **收灵魂**——灵魂是九狱的货币与兵源 |
| 契约文化 | 基本无契约精神 | 魔鬼契约是核心文化：精确措辞、藏漏洞、等价交换 |
| 血战立场 | 一方：数量近乎无穷 | 另一方：纪律精良 |

### 血战（Blood War）

恶魔与魔鬼自"太古纪元"以来在下位面的**永恒战争**——双方皆欲将对方斩尽杀绝；中立恶的**尤格罗斯（Yugoloths）**受雇双方、两头渔利。主战场在深渊与九狱之间的下位面（九狱第一层阿弗纳斯等），烈度时起时伏，偶尔波及物质位面。官方详述见 Mordenkainen's Tome of Foes（2018）与 Descent into Avernus（2019）——**设定层专名**。

**魔鬼契约的网文用法**（等价交换装置源头）：官方口径——说服九狱之主阿斯莫蒂尔斯（Asmodeus）释放哪怕一个灵魂都要付出天价，传说其曾以恩惠换走整个王国。契约叙事四件套：①愿望精确措辞（措辞即陷阱）②代价延迟揭示 ③契约漏洞反转（乙方读穿条文反杀）④灵魂作抵押。浮士德契约、《钢炼》等价交换、《诡秘》的代价体系皆此系深化。

**写作要诀**：与恶魔战斗，与魔鬼**谈判**。血战=世界观底层冲突引擎——两大恶阵营永恒互咬，正是第三方（主角/人类文明）的生存缝隙："只要血战不停，魔鬼就腾不出手入侵人间"即世界的危险平衡。

## 六、网文转化建议（「编辑建议」）

1. **位面结构→世界构筑分层**：主世界+明暗两镜像+元素底层+灵魂归处=世界的"垂直纵深"——参考西幻dnd赛道包世界观件的做法，把平面地图升级为多层宇宙；妖精荒野/影界一对明暗镜像是低成本异空间副本来源
2. **17外位面=道德地理学**：阵营九宫格直接画进世界地图——"他来自天堂山"="他是守序善"，设定量减半，读者秒懂；万门之城居中的轮辐结构=天然的世界枢纽城设定
3. **血战→世界观底层冲突引擎**：两大恶阵营永恒互咬给主角留出夹缝操作空间，也给世界一个"危险平衡"的解释（为什么魔鬼/恶魔没灭世——它们在互杀）
4. **恶魔vs魔鬼之辨是读者硬核度测试点**：写混会被西幻读者抓住——记忆口诀"恶魔毁灭，魔鬼收魂；恶魔打不过就死，魔鬼打不过就谈"
5. **龙年龄层=力量阶梯可视化**：龙的年龄档即战力档，报龙名即报等级；金/银龙变形人形行走在人间=高人设定标配（扫地僧即远古龙）
6. **CR分档配境界**：把反派库按CR五档对齐主角境界五期，保证每期都有"刚好打得过/刚好打不过"的怪——悬殊感与碾压感交替供爽点
