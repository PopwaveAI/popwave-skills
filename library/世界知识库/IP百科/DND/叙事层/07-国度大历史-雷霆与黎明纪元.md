# 07-国度大历史·雷霆与黎明纪元：爬虫的黄昏，巨龙的白昼

## 序章：从一头17级的红龙说起

在博德之门的故事里，你或许见过主宰红龙从天而降、以压倒性的优势碾碎一队士兵的场面——难度等级高达17级的存在，不用些非常手段几乎无法挑战。龙在如今的费伦是绝对稀有的古老神物。可把时钟倒拨两万六千年：那时的费伦还不叫费伦，而龙，是这片大陆的统治者本身。

这就是本件要讲的两个纪元。约-35,000至-24,000 DR，一万一千年间，托瑞尔先后经历两任主人：先是五个"创造者种族"轮流坐庄的雷霆纪元，后是巨龙与巨人瓜分天地的黎明纪元。前者以一场星球级灾变收场，后者以一场让统治种族集体疯狂的魔法收场。两场灾变，就是两个时代的墓碑——在这个世界，时代从不靠"后来"过渡，只靠灾变定义。

## 先看表：负数开始起作用的两个纪元

计时仍用达勒历（DR，详见05件）。本件覆盖区间挂一条时间轴：**-35,000** 雷霆之日开始（终结了漫长的暗影纪元，见06件），**-31,000** 分裂之日，**-30,000** 黎明纪元开始，**-24,000** 巨龙时代落幕，此后便是精灵的繁盛时代（见08件）。四枚钉子，一万一千年。

请记住这条刻度。雷霆纪元的史料模糊到学者们只能"推测以上所发生的"，对细节各执一词；黎明纪元稍好，但也只剩精灵的二手记载。越古老的年代，叙事者越谦逊——这不是文风，是史料物理性损毁的结果。

## 上篇 雷霆纪元（-35,000 ~ -30,000 DR）

### 为什么叫"雷霆"

暗影纪元里，第一颗太阳被夜蛇丹达尔吞噬，世界陷入黑暗与寒冷（见06件）。创世诸神击败原初者后，又一颗太阳被创造——雷霆般的巨响为新世界带回光明，冰川溶解，海洋退去，超级大陆梅若罗布罗斯露出全貌。此时费伦尚不存在，它只是这块大陆的一部分；精灵、矮人、半身人尚未登场，生命以原始古老的形式绽放。现代学者普遍认同，当时有五个创造者种族统治大陆：爬行的萨鲁克、两栖的巴特拉契、飞行的爱伊利鸟族、栖居林间的精类，以及——还与猿猴一般使用简单工具、缩在洞穴里的人类。前三者将轮流建立帝国；精类从不建国，只在森林中超然物外；人类？此时的他们甚至不能算是历史的一部分。

### 萨鲁克时期：第一个帝国与第一份遗产

雷霆纪元是编年的倾泻场，年份、地名、事件三件套连排，每个数字都是一颗钉子：

- **-35,000**，萨鲁克在今摩尔霍德以南建立奥科斯王国，一百年内统治未来费伦的大部分区域；
- **-34,800**，第二帝国梅尔少克在楚尔特半岛建立；
- **-34,500**，第三帝国伊斯托塞弗辛建立在今安奥罗克沙漠之地；
- **-34,100**，奥科斯亡于长达一个世纪的内乱，大批萨鲁克被逐往异位面；
- **-34,000**，幸存的萨鲁克建立魔法组织贝提斯，专门研究各族的原始魔法形式并保存知识。

贝提斯是本件登记的第一笔跨期存款：该组织日后将造出"世界蛇的黄金皮肤"，**也就是日后在费伦影响力深远、被称为耐色卷轴的圣物**。这套卷轴共五十卷，以金、铂薄片制成，本身不蕴含强大的魔法力量，其中的奥术知识却庞大得超乎想象——日后耐色帝国的法师正是研读它们而力量暴涨，学会制造悬浮空中城市的密塔拉尔，如今费伦大部分魔法理论都奠基于此。一万年后才兑现的利息，在雷霆纪元就已存入。

- **-33,800**，伊斯托塞弗辛亡于一场自导的浩劫：帝国的巫师为消灭敌人，设法改变了海洋的流向，海水西涌形成巨大海啸，反噬了自己的国土。敌人逃入地下深处，从此销声匿迹，其故地后世称为"埋葬之地"——那个敌人的名字，也随之从历史中消失，再没有人提起。

- **-33,500**，梅尔少克衰落，帝国最终落入萨鲁克亲手创造的蛇人之手。第一棒，交出去了。

### 巴特拉契时期：一场自救仪式炸掉了半个星球

巴特拉契是海中演化的两栖种族，上岸后迅速取代萨鲁克，又在至高者周口店的领导下达到全盛。（编辑吐槽：官方给这位两栖至尊起的名字，正是北京猿人遗址"周口店"——Zhoukoudien。顺带一提，杀死他的泰坦名叫奥默，同样是地球上真实的古人类化石产地。远古直立人的幽默，一以贯之。此为编辑判断。）

黄金时代戛然而止。帝国疆域北扩至寒冷平原，撞上了泰坦的领地——这些全知之父安南的子嗣是巨人种族的起源。**-31,500**，至高者战死于泰坦奥默之手。**约-31,000**，节节败退的巴特拉契在绝望之际施展了一场伟大的召唤仪式，从诸神的古老监狱里释放出数名被囚禁的原初者。种族之间的战争，就此升级为神力之间的对抗——黎明之战的幸存诸神大为震惊，迅速围剿古老的敌人（战况详见06件）。

僵持中，被称为"世界塑造者"的龙神阿斯格拉斯做出决断：**得不到这个世界，那就毁掉它。**她召唤一颗巨大的冰冷陨石砸向梅若罗布罗斯大陆中心——大地崩裂，海洋汹涌，火焰与风暴席卷整个星球。内陆四方海洋在陨石落点汇聚，合并成如今的坠星之海。就在世界被彻底摧毁之前，神上神爱欧介入，将阿贝尔-托瑞尔分裂为同一位面中两个不同维度的孪生星球：阿贝尔交予原初者，托瑞尔交予诸神，两者共享日月而互不相扰。这场灾变，史称**分裂之日**（Tearfall）；古老的萨鲁克记载称之为"星辰转变"，精灵语称"落雨"，又因其后漫长的严寒被称为"七转之冬"。

【灾变分型卡·武器反噬型】这不是天灾，是一场自救武器的历史级走火：巴特拉齐想用召唤仪式挽救走向灭亡的文明，引来的却是神力灾难，试图自救者第一个被彻底摧毁。反讽闭环完整——而死亡同时是创生：分裂之日前后，第一批龙蛋（一说数以万计）在托瑞尔各地孵化。龙从何而来？学者分为两派：一派认为冰月引发剧烈气候剧变，使某种原始龙类迅速进化；另一派认为龙蛋正是阿斯格拉斯掷落冰月时的神圣造物。无论真相如何，巨龙都以惊人的速度登上了历史舞台——它们将是雷霆纪元的掘墓人。

【战后清算三联】失败者注明退守地：巴特拉契文明在极端气候与"七转之冬"后终结，许多族人离开托瑞尔，逃往外层位面混沌海，余者退入最深最黑暗的沼泽，被认为已经灭绝。弃守世界换新主：阿贝尔整颗星球划归原初者——这枚棋子要到极其遥远的未来才会被再次翻动。而神学层面的复盘同样冷酷：爱欧为何不在冰月落地前出手？记载只说他在世界毁灭的前一瞬介入分割两界——神上神维持的是法则与混沌之间的平衡，不是某一族的存亡。

分裂之日的归责，至今是罗生门：是针对泰坦傲慢的神罚，是自然灾害，还是龙神争夺世界无果后与敌同归于尽的最后一击？三方归责悬置，无人能裁——但"以此为由"的后果真实发生了：巴特拉契退出历史，龙族入场。

### 爱伊利时期：飞龙军团的瘟疫

**约-31,000**，正当巴特拉契帝国走向衰败，爱伊利鸟族崛起，几百年间统治托瑞尔大部。他们驯化并改造有翼蜥蜴，造出双足飞龙军团，一路扩张。转折来自信仰深渊领主耶诺古的豺狼人：其萨满祭司召唤出恶灵马拉什——来自贫瘠与绝望之地的血翼生物，以携带致命疾病的毒箭攻击。毁灭性的消耗瘟疫在鸟族中蔓延，庄稼枯萎，人口锐减。走投无路的爱伊利转而向另一位恶魔领主帕兹瑞尔寻求拯救——深渊从来不是救生艇，这是对创造者种族的最后一击。与此同时，分裂之日诞生的龙族聚集起来，占据天空、陆地与地下，将崛起未稳的爱伊利帝国彻底摧毁。

### 接力棒总账

纵观雷霆纪元，五个创造者种族轮流坐庄，每棒的灭亡都给下一棒留了遗产或凶手：萨鲁克留下贝提斯与耐色卷轴（遗产）；巴特拉契的召唤招来了神战与灾变，也间接孵出了龙族（爱伊利的凶手）；爱伊利被龙族清算，又把大陆完整地交给了龙。灭绝不是句号，是接力棒的交接。幸存者去向，一族一句带地址：萨鲁克——大部分在人类纪元前数千年就已离开国度世界，少数苟存于远古遗迹与南部丛林深处；巴特拉契——最深最黑暗的沼泽，或混沌海；爱伊利——西迁安克罗姆，最终退化或创造了阿兰寇拉英人，从此消失于史册，只知其后裔仍在远方生存。

五个种族的排布暗藏一条演化链：爬行、两栖、鸟类，然后是与猿猴为伍的人类——人类将在这一切之后登场。历史没有点破这条链，它只是照此推进。

在精灵的口述传承中，那是一个雷霆的时代：一个由冷酷无情、毫无人性的爬行动物、两栖动物和鸟类组成的庞大帝国，统治着温暖富饶的土地。据说他们用玻璃和石头建造高耸入云的城市，用闪亮的道路纵横交错地切开荒野，驯服巨大的恐龙，玩弄当时尚未被驯服的强大魔法。他们掌握的力量可与神明媲美，却也因彼此的仇恨发动无休止的种族灭绝战争；他们玩弄创造新的生命形式，并将最错误、最不自然的那些释放到世界上——许多生物因此死去，但活下来的，足以改变国度世界日后的生命版图。

帝国崩塌，神罚坠落，龙翼蔽日，黎明将至——巨龙与巨人的统治，开始了。

## 下篇 黎明纪元（-30,000 ~ -24,000 DR）

### 这是谁的黎明

黎明纪元又称破晓时代、巨龙时代或巨人时代——名字的物理含义很直白：创造者种族的漫长黑夜结束了，新的白昼属于龙与巨人；而"黎明"二字同时埋着反讽，因为对被奴役的种族而言，这六千年是更深的黑夜。**-30,000**，第一次巨龙之怒：数以万计的龙张开双翼遮云蔽日，迅速占据天空、陆地乃至地下，对爱伊利诸帝国发动毁灭性袭击，几周之内城市相继沦陷。巨龙将军纳加马特一头闯进鸟族的地下洞穴，横冲直撞捣毁孵化场，并宣称这个王国属于他自己。龙族同时与北方巨人争夺领地，迫使巨人放弃土地逃往更寒冷的北方。个体与氏族分治大片疆土，互相竞争——巨龙的时代开始了。

讲龙族史之前，先交代史料是谁写的：龙族长寿却高傲、以自我为中心，且只有口述传统，来自龙族内部的记录天然不可靠；事实上，大多数龙族历史是由最接近其起源、并已形成文明的种族——精灵——记录的。精灵神话汇篇《帕维卡伦》描述了龙族起源与精灵同龙族的第一次互动。一手史料不可靠，二手史料反而是正史——这是黎明纪元的第一课。

### 龙帝国五幕

**第一幕·崛起。**几周灭一国（见上）。崛起只写速度与暴力，不写过程。

**第二幕·鼎盛。**毁灭爱伊利大片领土后，龙族建立了四个名字又长又拗口的龙国——阿格斯提利亚克斯、卡伊斯尼马尔斯维尔、达拉斯特里弗西卡、萨克利克斯冈提克斯（连精灵史官的抄本里都一律用简称）。强大的龙王在各自领地施行强权统治："低等"种族——原始人类与其他类人种族——沦为奴役对象。有人认为金属龙不像彩色龙那般残暴，但在巨龙时代，即便看似温和的金属龙也会展现出不为人知的无情——连"善龙"都参与压迫，鼎盛期自带道德阴影。而阴影深处，裂缝已经在酝酿：龙族是虔诚的信徒，金属龙多信善龙之神巴哈姆特（在国度世界另有其名西莫尔），彩色龙信邪龙女神提亚马特——两种极端对立的信仰，暂时相安无事。

**第三幕·内忧。****-29,500**，一名巴哈姆特的追随者刺杀了信仰提亚马特的巨龙将军纳加马特——一桩刺杀，点燃龙裔战争。信仰之争不断扩大，最终升级为席卷全族的龙族圣战。两位被信仰的龙神亲自下场造兵：提亚马特培育出名为"提亚马特之裔"的奇异生物，大量投入战场；巴哈姆特则创造龙裔武士充当士兵与骑士。神明造兵，是内战烈度的可视化刻度——这场宗教战争持续至今，从未真正停火。

**第四幕·外患。**【战争总纲】千年战争：跨度约-26,000至-25,000；阵营远不止龙族对巨人——龙族内部两大信仰阵营互相拖累，巨人六王国倾国抵御，精类趁乱群起攻龙，被奴役的诸种族冷眼旁观等待变天，神界则由安南对加里克斯压轴；转折是全体龙族被卷入；后果是巨人退守极北。若给这场千年战争配一个现实文学坐标，它是放大千倍的《贝奥武夫》——最早的英雄史诗早已写明：英雄与巨龙互为宿命，且往往同归于尽（编辑判断）。总纲之下，战场展开——混乱、火焰与毁灭的恶龙之神加里克斯化身火焰巨龙，率红龙入侵巨人王国奥斯托利亚，最终全族卷入。巨人一方祭出战争兵器"死亡泰坦"巨像：高八十英尺的人形巨像，几乎完全由金刚石与巨大红宝石构成，戴角盔、持大剑，行动迟缓且受地形限制，却是袭击龙巢的利器——杀死的龙比任何巨人英雄都多。个人英雄的巅峰则属于一位冰霜巨人（其名转写稿存"贺尤奴尔"音，拼写待核）：他把一位古老金龙将军诱入自己挖的窄坑道，让龙群无法围攻，一次面对一头地逐一斩杀金龙及其十二名副官——但坑道既是优势也是劣势，最终他淹死在十三条龙的血液里。杀死他的，正是他自己的战术。史诗与民谣歌颂了这些战斗，最古老的一首出自他的叔叔之手（人名拼写待核）。

巨人节节败退，却被一盘棋救了：关于休战，巨人的历史记载说，全能之父安南介入战争，没有与加里克斯进行神力对抗，而是戏剧性地选择以一局古老的费伦策略棋定胜负——两位神的棋艺同样娴熟，对局以僵局告终，战争就此结束，龙族保留了征服的巨人领土。神明为何不战？答案藏在结果里：僵局本身就是裁决。而千年战争带来了一个更深的后果——龙族智者得出结论：宗教内斗极其无益，允许信徒彼此厮杀的神，不配崇拜。冷漠蔓延数千年，据推测，最初龙族万神殿中的几位神祇，正是因缺乏信仰而消亡。**神，会死于信徒的冷漠。**这是"神靠信仰存活"机制第一次被用作历史的解释引擎——龙帝国的衰落，第一因不是外敌，而是信仰破产。

**第五幕·终结。**没有了巨人这个对手，龙族成为大陆上压倒性的力量，其他种族的奴役与压迫随之加深。精灵与弱小种族迫切需要终结龙族统治的办法。**-25,000**，在一众精灵高级法师的努力与一个周期性天体事件的配合下，精灵们创造出强大到不能称之为魔法、而应称之为奇迹乃至神话的造物——**龙狂秘仪**（Dracorage mythal）：覆盖几乎整个梅若罗布罗斯的高级魔法效应，与那颗淡红色的彗星**弑王星**绑定。每当弑王星出现在托瑞尔上空，目睹它的龙族便逐渐丧失理智，变得如同野兽般盲目嗜血、互相撕咬，甚至波及后代。

【灾变分型卡·武器反噬型（对双方）】对龙族，这是灭顶之灾：第一次龙狂席卷并重创了这个伟大文明。对精灵，这是防御性武器——而武器终将失控。**-24,000**，绝望的龙王们孤注一掷，集体施展远程魔法轰击弑王星，却打偏了：魔法击中赛伦涅之月，轰碎部分月表，飞溅的碎块环绕月亮轨道运行，**形成了赛伦涅之泪——那个至今悬在托瑞尔夜空中的小行星群**。武器误击的伤疤，成了一颗星球的项链。同一年，走投无路的龙族猛攻精灵维持秘仪的领地，英勇的有翼精灵——阿瓦里尔——付出近乎灭族的代价守住了秘仪，残余者从此隐匿行踪。龙族再也无法阻止龙狂，巨龙的时代走向终结。

龙没有死绝，只是切换了模式：幸存者盘踞在巍峨的山峰，或藏进迷宫般的地下洞穴系统，滋养残存的力量，远离凡人与精灵文明日益增长的影响。这种隐居有时长达数千年——等待时局再次转向对他们有利。在日后费伦的传奇里，两族时而为敌，又总会被逼上同一条战壕。

### 灾后并行小传：地底的三方罗生门

主线之下，地底正在并行发生另一个故事。**-24,500**，传说中提亚马特（或一条远古绿龙）创造了第一个龙裔生物库尔图马克；不久，狗头人与有翼狗头人等小体型种族出现，深入地下挖掘矿脉，建立起繁荣的狗头人王国。然后，狗头人矿工闯入一座缀满宝石的洞穴，遇见了第一批原始侏儒。侏儒的起源，三方各执一词：《龙族暴君史论》记载，侏儒与狗头人同时期诞生于山下洞穴的宝石之中；侏儒自己的神话说，守护神加尔·闪金在地下探索时发现宝石，为其注入生命，还给新生的侏儒们讲了一个笑话——从此这个种族有了欢笑与恶作剧的天性；而狗头人的传说声称，加尔·闪金纯粹出于嫉妒才摧毁了狗头人的地底王国，因为他眼红狗头人在地下建立的成就。真相悬置，行为后果却确凿：狗头人奴役了侏儒，还偷走盛有未出生侏儒灵魂的宝石；加尔·闪金救出灵魂宝石，摧毁狗头人王国，其废墟塌陷形成了隐湖；龙神阿斯格拉斯替狗头人出头，将废墟中的库尔图马克与另一名幸存者升格为神——一场神界纠纷，一次死亡，生出两个新神、一个新湖、两个种族的万年恩怨。史料学即性格学：每一方的说法，都完美符合本方的立场。

### 神界的家务事，与精灵的入场券

巨龙时代的诸神并不闲着。全知之父安南在此期间与托瑞尔女神奥西亚结合，生下八个巨人子嗣，建立奥斯托利亚、达查尔、格里恩费斯汀、赫利格海姆、尼德海姆、朗菲尔六大巨人王国——按疆域自极北向南排布。**-25,500**，奥西亚又与极北之神乌卢提乌私通，生下菲尔博格、维尔比格、沃德金、弗莫尔四个类巨人亚种。（编辑吐槽：全知之父的全知，唯独漏了自己的婚姻。这顶绿帽，他许多年后才发觉。）与此同时，精灵神域爆发家庭剧变：精灵主神科瑞隆的第一任妻子阿罗希尼与其子维伦发动叛乱，失败被逐——阿罗希尼堕入无底深渊成为魔后，从此自称罗丝；其女伊利斯翠受累选择自我放逐。**这就是日后皇冠战争与整个卓尔精灵叙事的总开关**（详见09件与13件）。

凡间一侧，**-27,000**，为破坏龙族统治，精类打开连接妖精荒野与托瑞尔的空间之门，第一批精灵移民到来——其中被称为黑暗精灵的伊里瑟尔族裔与龙族谈判，获准在大陆南方定居，以都城阿托纳什为基础建立了南方小国，**也就是未来数千年精灵文明繁荣与堕落的双重起点**（详见08件）。**-25,100**，妖精荒野的太阳精灵王国廷塔吉尔毁于洪水，幸存精灵施展强大的空间魔法举族逃至托瑞尔北部；其王子杜洛希尔在传奇经历后成为银龙骑士——托瑞尔第一个已知的龙骑士——并斩杀红龙领主，但人龙俱殒于那一战。精灵带着龙骑士的传说登上了大陆：他们将在下一个时代里建立自己的第一帝国。

## 时代收束：两份存折与一个待机种族

一万一千年，两个纪元，账目如下。**存折一**：耐色卷轴（贝提斯→耐色帝国）、蛇人（梅尔少克→后世蛇人王国）、埋葬之地（伊斯托塞弗辛浩劫→后世的地下凶地）——雷霆纪元埋的种子，最远的一枚到两万年后才发芽。**存折二**：龙狂秘仪与弑王星（至今仍周期性折磨龙族）、赛伦涅之泪（龙族误击月亮的永久伤疤）、狗头人与侏儒的恩怨、罗丝与伊里瑟尔（皇冠战争的总开关）、隐居待机的龙族（现代费伦每一条龙的来历）——黎明纪元的遗产，一半是伤疤，一半是伏笔。

崛起用几周，鼎盛用千年，毁灭只需一颗星。巨龙用六千年证明自己是大陆史上最强的个体，又用一盘没下完的棋、一场没人敢提的疯狂，把大陆让给了更弱小、也更擅长等待的种族。雷霆的余烬冷却之后，龙族的血还热着——他们只是在山的深处，数着弑王星的周期，等待。而森林边缘，精灵的篝火已经点亮：繁盛时代的花，要开了。

帝国焚尽处，龙血冷成渊；棋局终无胜，星辰自流转。谁还记得创造者种族的玻璃之城？谁又能预见，精灵的花期将至，而花期之后，是王冠的战争？（下一件：《08-国度大历史-繁盛时代》）
