# 魅魔种族·写作料包

## 写作采编摘要（agent 取料第一入口）

**可用赛道**：西幻欲望与堕落 / 堕落与救赎 / 怪物拟人化 / 女性反派 / 非人种族视角 / 世界观经济机关

**可长出的构思**：
- **反派 NPC**：以"自由意志堕落"设局的诱惑者。张力源=受害者自我作恶、无须强迫。
- **主角/女配**：被种族刻板印象禁锢、想挣脱宿命的非人。反写骨=师宠线。
- **世界观机关**：以"灵魂/色欲"为燃料的经济系统。深渊靠原罪造血→灵魂即货币。
- **高冲突桥段**：种族内部的权力倾轧（女王夺位）、跨阵营两栖（深渊女王去九狱任职）。

**硬约束（写角色/世界时不可违）**：
- 武力=非战士、非领主；逃离冲突、利爪仅万不得已，杀伤靠诱发情感。
- 收割凡魂三条件：思想/言语/行动三次背叛，且须受害者**出于自由意志**；无需契约。
- 设计定位三变：恶魔→魔鬼→中立邪魔；五版起游走所有下层位面，为一切邪恶势力服务。
- 不可能靠"直接魅惑"收割——被魅惑者无须负责，未经挣扎的堕落不算数。

**写作禁语**：无（本件已过专名规避，见末节专名雷达）。

## 设定块抽屉（按需深读，不按叙事顺序）

> 四块可独立取用。写"设定兼容性"读②，写"世界观起源"读④，写"角色底色"读①③。

### ① 神话链 / 角色底色
- 词源："魅魔"产自14世纪拉丁语，本义"躺在下面"，指体位而非生物。
- 文学原型=莉莉斯：亚当的第一位妻子，因不愿臣服亚当而念神名、飞离伊甸园，后成魅惑人类、扼杀婴儿的女恶魔；与天使萨麦尔结合诞下莉莉姆。更早源出美索不达米亚夜魔传说。
- **用途**：给魅魔角色"非自愿堕落/被污名化"的性格底色，可挂反派前史或主角身世。

### ② 版本思想史 / 设定兼容性
- 1976《埃德里奇巫术》首获系统描述，蝙蝠翼+尾+诱惑外表由加里·吉盖克斯定型。
- 1977进《怪物图鉴》一版，至3.5版三十年=混乱邪恶塔那里（深渊）。
- 四版大手术：变为九狱守序魔鬼（设计逻辑：毁灭归恶魔、诱惑归魔鬼）。
- 五版折中：中立邪恶邪魔，游走所有下层位面。
- 电子游戏侧：1982《巫术》登场；1994《恶魔战士》莫莉卡抬为封面级主角，影响日式二次元魅魔谱系。
- **用途**：跨版本体系写作时的兼容依据，拍"这个设定该按哪个版本来"。

### ③ 世界内史学 / 种族政治
- 约1479 DR：被归类为九狱魔鬼；1385法术瘟疫后据罗坎说法，魅魔全族决断转投阿斯莫迪斯，流言称正是这一票终结血战。
- 1487第二次分裂后：统称邪魔，遍布所有下层位面，除自选之主外不效忠任何人。
- **用途**：跨阵营/权力倾轧桥段的设定依据（血战详见17）。
   
### ④ 宇宙生成论 / 世界观起源
- 据《伊格威尔伏的恶魔志》：塔那里生生不息之根=凡人罪孽灵魂注入深渊。愤怒有愤怒之恶魔，每罪滋一恶魔品种。
- 对恶魔繁衍最有利的原罪是**色欲**——唯有它与生命诞生直接相连。
- 色欲坠入深渊→深渊给出回答→**魅魔**。魅魔是第一批由凡人原罪**自然孕育**的塔那里（非奥比里斯扭曲），出乎奥比里斯预料。
- 初代崛起后自相残杀夺领地仆从，史称**肉欲之战**；幸存者吞噬姐妹更强大致命，绝大多数名字湮没，只留女王+三手下败将入史册。
- **用途**：写"世界以罪为燃料"的经济/宗教机关，或魅魔族起源神话。

## 形态速查（给"要写魅魔的agent"30秒定位）

- 体型：真身约1.8m/57kg，蝠翼利爪尾刺；外表=可无限期维持的伪装，能精确模仿具体个人。
- 名字：雄性=梦魇(incubus)（数量远逊）；雌雄可随意换（习惯偏好非生理）。
- 变态能力：天生全语言（内心感应但爱开口）；可用以太形态穿墙飘至床边；变身范围半身人~人类，唯独不含随身物品。
- 吻：一吻/一抱吸生命能量，也是暗示术；带来痛苦与空虚，非满足。
- 五版魅惑：30英尺内人形生物，24h控或拒；同时仅控1名。
- 繁殖：与凡人所生分谱系——女儿阿鲁魔/儿子坎比翁（1487后泛指人形×邪魔后代）；魅魔与玛丽斯魔同为魔血提夫林最常见外祖血统。
