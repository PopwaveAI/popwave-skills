# IP百科维护规范 skill

> **定位**：本 skill 是 `library/世界知识库/IP百科/` 的**建包与维护规范唯一真源**。任何 agent 要在此库加一个 IP 百科包、改既有包、补一篇文章、刷新一批文档，都先读本 skill，照规格产出、照门禁入库。
> **基准样本**：DND 首包（最完善包，两层结构对齐标杆）。
> **对齐标杆**：被遗忘的国度 Wiki（forgottenrealms.fandom.com）——颗粒度「一个位面/一场战争/一位神祇=一整件」，单件8K-12K字深叙事。

---

## 一、IP百科包是什么（做什么）

`世界知识库/IP百科/{IP名}/` 下每个文件夹 = 一个**知名IP的官方设定事实库（带专名）**，供赛道包（配方层，去专名）与世界构筑采源。

**本库定位**：**写什么背景**。与赛道设定集库（怎么写/某赛道怎么写）是**原料↔配方**关系——本库是带专名的事实料，赛道包是去专名的蒸馏配方。

**文档质量立身之本**：颗粒度 + 客观性。颗粒度对标 Forgotten Realms Wiki；客观性遵循百科体纪律（§五），**禁口语化**。这是世界知识库IP百科与其它库（叙事写作库）最本质的文风差异。

## 二、包标准结构（对齐DND）

```
{IP}/
├── readme.md              ← 包门面：IP三层结构(规则/设定/文化) + 世界观框架 + 包组成总表 + 两层关系 + 采源与采样留痕
├── CHANGELOG.md           ← 迭代日志：版本号+每次改了什么+为什么
├── 规则层/ 或 规则层文件    ← 表层机制速查（速查表+术语表）：力量体系 / 种族与阵营 / 位面与生态 / 叙事装置 / 版权指南
└── 叙事层/               ← 深度叙事百科（对齐颗粒度标杆）：国度大历史 / 万神殿 / 位面风土 / 传奇人物志 / 种族深传 / 血战史诗……
```

**两层分工**：规则层回答「这个IP是什么」（表格速查、随查随用、文风=说明体）；叙事层回答「这个世界怎么讲历史/战争/神祇」（深读、文风=百科叙事体，客观但可保留少量叙事张力）。**版权指南**（专名规避表）通常归规则层文件，也可独立。

> ⚠️ DND 首包（v2.0.0）规则层采用五件独立文件、叙事层单独目录，为现行模板基准。

## 三、SOP 纲要（怎么产出/怎么维护）

| 步骤 | 场景 | 核心动作 |
|:--|:--|:--|
| **1 立包** | 新增一个IP百科包 | 判定IP复用价值 → 建两层结构 → 先规则层再叙事层 |
| **2 采源** | 收集可信料 | 官方优先(SRD/规则书) > 权威wiki > 社区；转写稿/视频仅作草料不入库 |
| **3 撰写** | 填各层文档 | 规则层=说明体；叙事层=百科叙事体（§五）+ 颗粒度标杆 + frontmatter |
| **4 入库检查** | 包完成后验收 | frontmatter齐全 + 事实核验(≥5点带URL) + 专名雷达 + 洗稿独立性 + 去口语化自检 + 索引同步 |
| **5 刷新** | 既有包升级/改文风 | 定版本号 + CHANGELOG记录 + 逐件过百科体门禁（deadline审批制） |

## 四、line — 红线（违反=不合格=不入库）

1. **禁凭印象写设定红线**：本库是事实库。阵营写错一格、时间线写错一段，下游赛道包全歪。每件: sourcing = 官方SRD/权威wiki，禁凭记忆补设定；无法证实的判断标「编辑判断」。
2. **单件>未标来源红线**：每件 frontmatter 必带 `sources` 字段（具体URL或出版物），正文关键事实点核验≥5处并带URL；无来源=不合格。
3. **专名雷达红线**：叙事层每件末节必带「专名雷达」——穷举本件出现的 Product Identity 专名（中英对照），供版权指南登记规避；缺节=不合格。
4. **洗稿独立性红线**：从解说/文章等二手料取材时，**结构逻辑可采纳，表达必须重写**。UP主/作者的标志性修辞、金句、独创定性句禁照搬（比对脚本见素材/DND字幕采集/）；撞句=不合格。
5. **去口语化红线（v1.0.0 新增，本库文风立身之本）**：本库文档**禁第二人称呼告、禁故事化悬念开场、禁评价腔/煽情/营销词、禁口语叹词**。叙事层允许保留轻度叙事张力（时间线/因果/画面），但主体为客观百科叙事。违反=回炉（详见 §五）。

## 五、百科体文风纪律（去口语化门禁 · v1.0.0）

> 对齐标杆：维基百科五大支柱（中立观点/可查证性/非原创研究）+ Forgotten Realms Wiki 单页纪律。全库统一执行。

### 5.1 层级：三类文风

| 文风 | 用于 | 特征 |
|:--|:--|:--|
| **说明体** | 规则层 | 术语先行、数据表前置、无叙事 |
| **百科叙事体** | 叙事层 | 定义段先行→客观叙事→事件/因果/时间线，去二称去煽情 |
| 速查体 | 索引/版权指南 | 表格优先 |

### 5.2 动词/人称纪律

| ❌ 口语化（回炉示例） | ✅ 百科体（达标示例） |
|:--|:--|
| 「你在博德之门捏一个牧师…」 | 「牧师是费伦万神殿…的神职者，其神职体系源于…」 |
| 「想象你正推开一座地牢的最后一道石门…」 | 「魅魔（Succubus）是诞生于无底深渊的混乱邪恶塔那里恶魔…」 |
| 「她可是个狠角色，全蜘蛛界都怕她！」 | 「罗丝是卓尔神系中地位最高的存在，其神职权柄涵盖…」 |
| 「据说有个叫Iggwilv的巫妖这么写的…」 | 「据《伊格威尔夫的恶魔书》记载…」 |
| 「一句话：提上裤子不认人的浪子反而不是魅魔的菜」 | 删改评价腔，改为中性表述或标「社区代称/民间流传」 |

**五禁**：禁二称（你/我/咱们/玩家/读者）；禁祈使（你应该/请记住）；禁营销腔（必看/天花板/重磅/惊艳、感叹号连用）；禁口语叹词（oh/wow/啧啧）；禁无来源的定性论断（除非标「编辑判断/社区流传」）。

### 5.3 单页组织纲领（叙事层为何不单薄）

```
① 页首信息框(可选，可从frontmatter生成字段/表格)
② 定义段先行：X是什么的Y（one-line客观定义，含领域/身份/阵营）
③ 正文递进：起源(因果)→发展(时间线)→关键事件→现状，第三人称
④ 落点：对世界观/网文创作的意义(允许「编辑建议」分区)
⑤ 附录：专名雷达 + 编辑判断与待核 + sources
```

**对照自检清单**（每条叙事层文档入库前自查）：
- [ ] 首段是「X是……」定义句，非「你在…」
- [ ] 全文无第二人称（你/我/咱们/玩家）
- [ ] 专名首次出现带中英对照
- [ ] 来源以「据…记载/据FR Wiki」归位，不空口判断
- [ ] 事实点≥5带URL；无法证实的标「编辑判断/待核」
- [ ] 末节有专名雷达 + 编辑判断与待核备注
- [ ] 全文无感叹号营销腔、无口语叹词、无祈使句

### 5.4 洗稿后仍口语的识别

文案是否有这些信号：含「告诉你/别忘了/记住/你猜/看好了」类口语引导词；含「就是/无非/说白了」等口语承接；含「（想象）」「（你）会看到」等画面呼告。三者居其一即回炉改百科体。

## 六、采源三级制与采样留痕

1. **官方优先**：官方SRD/规则书 > 权威wiki（FR Wiki/VGM等）> 社区资料；frontmatter 标 `source_type: official-srd / wiki / public-domain`。
2. **转写稿/视频仅作草料**：字幕转写稿、讲解视频不入库，只作采源；叙事层成稿基于转写稿+wiki核验后重写。
3. **采样留痕**：包 `readme.md` 必带「采样留痕」块——采了哪些源、各采多少、产出哪些件、缺口是什么，一览可审计。
