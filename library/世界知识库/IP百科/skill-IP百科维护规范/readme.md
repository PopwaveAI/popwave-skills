# skill-IP百科维护规范 · 内容目录

> 定位：`IP百科/` 库的**建包与维护规范唯一真源**（强门禁 SKILL v1.0.0）——一个 IP 百科包该有哪些文档、各文档什么规格、按什么 SOP 产出、按什么门禁入库。本目录为 skill 载体，SKILL.md 即规范正文。

## 内容清单

- `SKILL.md` —— 强门禁正文：包标准结构（规则层/叙事层两层）+ 五条红线 + 百科体文风纪律（去口语化门禁·五禁）+ 采源三级制 + SOP 纲要。

1. 强门禁定位：入库前必读 SKILL.md；违反红线（禁凭印象写设定 / 无来源 / 缺专名雷达 / 洗稿撞句 / 口语化）= 不合格不入库。
2. 基准样本 DND 首包（两层结构对齐标杆）；所有 IP 百科包统一按此规范生产/维护。
