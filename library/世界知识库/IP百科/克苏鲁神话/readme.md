# 克苏鲁神话（Cthulhu Mythos）· 总纲

> **一句话**：克苏鲁神话是围绕 H.P.洛夫克拉夫特（H.P. Lovecraft）1917-1937 年创作的「宇宙恐怖」小说层叠生长出的一种大众神话，核心是**人类在冷漠浩瀚宇宙中的渺小与被禁忌知识腐蚀的恐惧**。它没有单一真源：洛夫克拉夫特本人称之为「尤格·索托斯奇想(Yog-Sothothery)」，指导体系化的命名、层级与善恶对立则来自整理者奥古斯特·德雷斯（August Derleth）及后作者；而统治当代读者大脑的，更多是 COC 桌游（SAN 值）、影视、电子游戏与中文网文层层叠加后的「集体无意识印象」。中文诡秘流/克苏鲁网文的直接母版。
