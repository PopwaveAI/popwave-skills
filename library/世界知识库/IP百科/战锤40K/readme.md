# 战锤40K（Warhammer 40,000）· 总纲

> **一句话**：战锤40K 是英国 Games Workshop（GW）1987 年起运营的「黑暗中遥远的未来」科幻战棋 IP：人类帝皇的黄金王座帝国横跨百万世界，在银河被亚空间混沌、异形与古老死灵围困的 41 千年里，唯有战争永不停歇。它没有单一"原典文本"，官方设定散布在数十版规则书、黑图书馆数百部小说与历代 Codex 中；而统治当代玩家/读者大脑的，更多是电子游戏（战争黎明/星际战士/暗潮）、同人转正动画（Astartes）与中文社区科普+梗文化层层叠加的「集体无意识印象」。哥特黑暗、信仰帝皇、"为帝皇而战"是最出圈的三张脸。

## 二、世界观框架（双线叠合，先给线1骨架）

```
线1 原典世界观（GW 官方设定）：
   41千年的银河 = 人类帝国（百万世界、帝皇黄金王座、星炬导航）
        │  被四面包围
        ├── 亚空间/混沌四神：恐虐Khorne / 纳垢Nurgle / 奸奇Tzeentch / 色孽Slaanesh
        │      └─ 由凡人情绪投影而生，是"现实的镜像"；与凡人互相供养
        ├── 异形诸族：欧克Orks / 灵族Eldar / 泰伦Tyranids / 死灵Necrons / 钛星T'au
        ├── 帝国支柱：机械教 / 星界军 / 星际战士(基因种子+原铸) / 审判庭 / 国教
        └── 历史：黄金时代(M15-25) → 纷争时代(M25-30) → 大远征(M30) → 荷鲁斯叛乱(M31)
             → 万年后不屈纪元(M42，卡迪亚陷落+大裂痕+基里曼复活+原铸建军)
   规则：技术停滞（STC崇拜）；灵能=危险；信仰帝皇=国教；每一方都无绝对正义

线2 印象层（统治大众大脑，逐层独立测绘见 印象测绘.md）：
   官方桌游层 → 黑图书馆小说层 → 电子游戏层 → 同人动画转正层 → 影视层 → 中文科普/社区层 → 梗文化层
```

## 五、两层关系与消费方式

- **线1/线2 分工**：线1（叙事层）回答"GW 设定里这个宇宙客观是什么"，线2（印象测绘）回答"大众/玩家/中文读者大脑里这东西成了什么、哪些被误当官方"；两件分开，冲突不压扁。
- **赛道包采源**：本包是带专名的原料层；哥特太空/星际战争/帝国征战类赛道包的「信仰/机魂/基因改造/混沌腐化/献祭与忠诚」等配方由此蒸馏（去专名）。
- **world 构筑**：黄金王座帝国、亚空间镜像、四神由情绪而生、基因种子改造、审判庭肃清等机制可整体借鉴重命名。
- **消费红线**：任何 GW 专名（帝皇/黄金王座/星际战士/混沌四神/战团名等）进正文前过 `版权指南.md`；"grimdark/为帝皇而战"属文化层可自由化用；"忠诚梗/四小贩"属线2社区层，用时标注来源属性。

## 六、采源与采样留痕

- **线1 事实**：以 GW 官方站点（warhammer40000.com / warhammer-community.com / blacklibrary.com）+ 英文维基主词条为顶层，粉丝百科（warhammer40k.fandom.com）逐条交叉（Horus Heresy/Great Crusade/Imperium of Man/Emperor of Mankind/Chaos Gods/Space Marines/Era Indomitus 等 7+ 全名为锚）；叛乱伤亡数字、四神名号、大远征年份等关键事实点 ≥5 处带 URL 交叉。
- **线2 事实**：各电子游戏英文维基词条（Dawn of War/Space Marine 2/Darktide/Boltgun/Rogue Trader/Total War: Warhammer）、官方授权 TRPG 报道（ICv2）、中文社区源（百度百科/baike.com/B站科普/贴吧/AcFun）。二手口水文仅作现象登记，不作事实定谳。
- **采样留痕**：本研究周期实际核验源 ≥30（跨官方/维基/游戏/中文社区），关键事实点 ≥6 处带 URL 交叉；「白银之丘」等疑似误传播已如实标注待核，不编造。
- **禁止凭印象补设定**——「40K=奇幻战锤」「忠诚梗=官方设定」「帝皇尸皇=官方真相」是四处最易带着网文读者踩坑的误认，本包在双线判定与各件中显性标注。
