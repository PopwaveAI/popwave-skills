# 战锤40K 版权指南（网文作者速查）

> **用途**：写「哥特太空/星际战争/信仰帝国」类网文落笔前的法务速查。一句话军规：**战锤40K 是 Games Workshop（GW）的专有 IP，所有专名/设定/叙事均为 GW 商标与版权；只能借鉴"设定结构与母题"，专名一律重命名**。本文事实层经官方站点与维基交叉核实；不构成法律意见。

## 二、GW 专有 IP 谱系（不可 lift 清单）

- **商标与世界观**：Warhammer 40,000 / 战锤40K（名称）；帝国（Imperium）、帝皇（God-Emperor）、黄金王座（Golden Throne）、星炬（Astronomican）、亚空间（the Warp）、混沌（Chaos）等核心概念，均为 GW 注册商标/设定（[Warhammer_40,000](https://en.wikipedia.org/wiki/Warhammer_40,000)；[官方社区版权声明](https://www.warhammer-community.com/en-gb/what-is-warhammer-40k/)）。
- **专名**：星际战士（Space Marines/Adeptus Astartes）、基因种子（Gene-seed）、原铸（Primaris）、审判庭（Inquisition）、机械教（Adeptus Mechanicus）、星界军（Astra Militarum）、战斗修女（Adepta Sororitas）、原体（Primarchs）、战团名（极限战士 Ultramarines/血鸦 Blood Ravens 等）、异形名（Orks/Eldar/Tyranids/Necrons/T'au）——**全部禁止照搬**（[Warhammer_40,000](https://en.wikipedia.org/wiki/Warhammer_40,000)；[Space_Marines](https://warhammer40k.fandom.com/wiki/Space_Marines)）。
- **混沌四神专名**：Khorne/Nurgle/Tzeentch/Slaanesh 及其译名恐虐/纳垢/奸奇/色孽，均为设定专名，禁止照搬。

## 三、授权/衍生作品的版权归属（已确证）

1. **GW 本体**：40K 是 GW 1987 年起运营的核心 IP，专名与设定归 GW（[Warhammer_40,000](https://en.wikipedia.org/wiki/Warhammer_40,000)）。
2. **各开发商**：游戏为开发商+GW 授权（如 Relic《Dawn of War》、Saber/Focus《Space Marine 2》、Fatshark《Darktide》），其原创内容（如血鸦战团）归开发商/GW（[Dawn_of_War](https://en.wikipedia.org/wiki/Warhammer_40,000:_Dawn_of_War)；[Space_Marine_2](https://en.wikipedia.org/wiki/Warhammer_40,000:_Space_Marine_2)）。
3. **同人转正**：Astartes 原为粉丝 Syama Pedersen 的同人 CG，后 GW 收编为官方（Warhammer+）——**说明 GW 对同人作品有"收编权"意识**，同人改编商用需谨慎（[Warhammer+](https://en.wikipedia.org/wiki/Warhammer%2B)；[B站转载](https://m.bilibili.com/video/av25030082)）。
4. **授权影视**：Ultramarines 电影为 GW 授权 Codex Pictures 制作（[Ultramarines_Movie](https://en.wikipedia.org/wiki/Ultramarines:_A_Warhammer_40,000_Movie)）；卡维尔剧集为 Amazon×GW 企划（[头条科普](https://m.toutiao.com/group/7189965820121203233/)）。

## 五、中国网文实操建议（编辑建议，非法律意见）

1. **最稳姿势**：把 40K 当「美学与方法论」用——grimdark 暗黑残酷、信仰机器、技术迷信、战争永恒、情绪即神、腐化与忠诚的张力，全部 free lift；至于帝皇/星际战士/四神等专名，用**自造替身**（至高君王/改造战士/邪魔四相），既避开 GW 主张，也更贴合原创。
2. **明确"奇幻战锤 vs 40K"区分**：写 40K 风时勿用《全面战争：战锤》的精灵/魔法奇幻设定混入，两者是不同的 IP 系（[Total_War:_Warhammer](https://en.wikipedia.org/wiki/Total_War:_Warhammer)）。
3. **机制 vs 表达**：借「信仰/腐化/基因改造/星炬导航」这类**机制与概念结构**不受著作权保护；照抄 Codex 数值、翻译黑图书馆小说段落、抄官方站点文案=抄表达。
4. **灰色自检四问**：①这套专名/术语是不是 GW 原创？（查官方 Codex/站点）②这个机构/种族/事件名是不是 GW 设定？③我借的是"世界观方法"还是"专设文本"？④这本书商业野心多大？（自嗨随写，长线严守）。
5. **同人转正警示**：Astartes 案例说明 GW 对粉丝创作的边界敏感；若做 40K 同人商插/设定书，先看 GW 的"粉丝内容政策"（官方社区页有明确声明，[warhammer-community.com](https://www.warhammer-community.com/en-gb/what-is-warhammer-40k/)）。

## 六、公域可放心用的「战锤40K系设计模块」

- 概念模块（全部 free）：**grimdark 暗黑残酷、信仰机器、技术迷信与停滞、星炬式导航圣物、情绪投影成神、腐化与忠诚的张力、每一方皆无绝对正义、战争永恒**。
- 这些是 40K 美学的公共矿藏，写手可自由化用再建自己的帝国与神系。
