# 海贼王（ONE PIECE）· 总纲

> **一句话**：海贼王是尾田荣一郎作、1997 年 7 月 22 日起连载于集英社《周刊少年Jump》的少年漫画，以"大海贼时代"背景下少年路飞组队航海、争夺"大秘宝 ONE PIECE"的长篇冒险为主线，截至 2026-07 单行本已出 115 卷，全球累计销量约 6 亿册，两度刷新吉尼斯"单一作者同一漫画系列出版量之最"（2015/2022），是史上销量最高的漫画系列之一。它同时是一部"无单一影视母版、由漫画原文主导 + 东映动画/剧场版/中文社区层层叠层"的双线 IP——漫画正史是压舱石，但大众（尤其中国观众）的"海贼王=动画/少年热血/路飞大笑/伙伴"认知由动画与社区梗文化喂成。

## 一、双线判定（see 世界知识库/references/双线范式.md）

| 判定项 | 结论 |
|:--|:--|
| **类型** | **双线并行（原文主导偏）**——有明确单作者（尾田荣一郎）单一原典（漫画连载），与原典弱势型不同；线1 漫画正史是设定源头与压舱石，但大众认知由东映动画、剧场版、中文译名乱局、社区梗文化层层叠层，需独立测绘线2 |
| **线1 · 原文考据（压舱）** | 尾田荣一郎《周刊少年Jump》连载正史：蓝星球地理（红土大陆/伟大航路/四海/无风带/颠倒山）、恶魔果实（自然系/动物系/超人系）+霸气（三色）+六式、世界政府/海军/四皇/七武海政治结构、种族构成、空白一百年/历史正文/古代兵器/尼卡/乔伊波伊悬念。只认可追溯漫画原文/权威百科事实，记版本与悬念不压扁 |
| **线2 · 集体无意识印象测绘** | 东映动画层（1999-今）、剧场版层（RED 等）、中文社区/梗文化层（索隆路痴/王路飞/尼卡形态烂尾之争/尾田休刊趋势）、主题认知层（友情/自由/伙伴/"大秘宝是友谊"之争）。独立出「印象测绘」，与原典件显性分家 |
| **关键错位（本包必须先拆开）** | ① **"海贼王"vs"航海王"**：中国大陆正版统一译《航海王》因集英社未注册"海贼王"商标、本名遭抢注；② **动画≠漫画原典**：许多观众只看动画，不知漫画进度/细节差异；③ **路飞果实"橡胶果实"→"人人果实·幻兽种·尼卡形态"**（五档）是 1044 话重揭真名的重包装，非初始设定；④ **"大秘宝=友谊/冒险过程"**之争是粉丝解读，尾田本人多次强调大秘宝是"物理实物"；⑤ **两岸译名与角色译名**差异（索隆/佐罗等） |

## 五、两层关系与消费方式

- **线1/线2 分工**：线1（叙事层）回答"尾田漫画正史里这个世界客观是什么"；线2（印象测绘）回答"大众/动画观众/中文读者大脑里这世界成了什么、哪些被误当原典"；两件分开存放、冲突不压扁。
- **赛道包采源**：本包是带专名的原料层；少年热血流/航海冒险类赛道包的「单元岛冒险/伙伴入伙/大秘宝闭环/空白历史悬念/势力均势」等配方由此蒸馏（去专名）。
- **world 构筑**：蓝星球地理（红土大陆×伟大航路）、恶魔果实+霸气类能力体系、航海世界政治均势、D 之宿命/古代兵器类宏悬念可整体借鉴重命名。
- **消费红线**：任何集英社专名（路飞/索隆/恶魔果实/霸气/伟大航路/大秘宝等）进正文前过 `版权指南.md`；"海贼/少年热血/冒险/伙伴/悬赏/大秘宝"属思想层可自由化用；"我要成为海贼王的男人/索隆路痴"属线2 表达层，用时标注来源属性、不得照搬名场面。

## 六、采源与采样留痕

- **线1 事实**：以尾田漫画正史为准——英文维基（One_Piece 主词条 + World Government/Four Emperors 子词条）+ onepiece.fandom.com（Devil_Fruit/Haki/Poneglyph/Ancient_Weapons/Race/Story_Arcs）+ 官方连载信息交叉核验，≥5 处 URL 交叉；"橡胶果实→尼卡真名""大秘宝=实物""三大势力均势"等易混点已显性拆解。
- **线2 事实**：东映动画/剧场版英文维基 + 中文源（baike.com/萌娘百科/B站专栏/NGA/虎扑/TalkOP/网易/搜狐/3DM）+ 吉尼斯官网中文入口交叉。
