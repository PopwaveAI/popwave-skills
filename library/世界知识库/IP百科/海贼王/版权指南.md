## 二、大陆"海贼王 / 航海王"商标与译名乱局（写手绕开的第一坑）

- **先入为主真相**：大陆正版漫画/动画统一译名是**《航海王》**，而**"海贼王"是粉丝口头俗称**——两者指同一部作品，不是两套 IP。
- **商标根源**：集英社在大陆注册的是"航海王及 ONE PIECE"商标，**未注册"海贼王"这个商标**，导致"海贼王"知名在 2007 年前后被各方抢注，正版只能放弃"海贼王"名（[今日头条](http://m.toutiao.com/group/7228381552281960963/)）。
- **港澳差异**：香港版本、台湾东立《航海王》译名并存；早期港译有《海盗路飞》等旧名（[问答站](http://m.xbtw.com/ask/c6f6624eeb011aab.html)；[网易](http://m.163.com/dy/article/D5NFJAN40517RGS8.html)）。**角色译名也有差异**（如索隆/佐罗、乌索普/乌苏普），写作时须固定采用一套并注明。

## 三、法律基础（什么受保护 / 什么可自由化用）

1. **思想/表达二分法**：版权只保护"表达"，不保护"思想"；"海贼/冒险/寻宝/伙伴"等母题属思想层（[Idea–expression](https://en.wikipedia.org/wiki/Idea%E2%80%93expression_distinction)）。
2. **scènes à faire（流派必然场景）**：少年热血"集结伙伴-打反派-升级"、"航海单元岛冒险"等类型惯例不受保护，可自由重组。
3. **角色版权与商标**：尾田创作的角色（路飞/索隆等）充分展开、受版权保护，专名不可照搬；"ONE PIECE/航海王"为注册商标。
4. **商用红线**：商用网文不适用"非盈利合理使用"豁免。
