# 漫威宇宙（Marvel Universe）· 总纲

> **一句话**：漫威宇宙是 Marvel Comics 旗下超级英雄共享宇宙的统称，漫画本体（主宇宙 Earth-616）自 1939 年（前身 Timely）绵延至今，是"超英共享宇宙"这一范式的开山之作；而统治当代大众（尤其中国观众）大脑的，更多是漫威影业（Marvel Studios）自 2008 年《钢铁侠》起打造的漫威电影宇宙（MCU，官方外编编号 Earth-199999）——它把"超级英雄集结+跨片彩蛋+无限宝石"打成了全球票房现象（《复联4》全球约 27.99 亿美元）。它没有单一"原典"，漫画与影视两条线既有继承又有大量改写（无限宝石的起源、颜色、跨宇宙规则均不同），是"双线并行"的典型。

## 一、双线判定（s§ 世界知识库/references/双线范式.md）

| 判定项 | 结论 |
|:--|:--|
| **类型** | **双线并行（影视主导偏）**——漫画宇宙（Earth-616）是设定源头与压舱石，但大众认知由漫威电影宇宙（MCU）与中文社区梗文化层层叠层统治；两线无限宝石/人物形象已分叉 |
| **线1 · 原文考据（压舱）** | Marvel Comics 正史宇宙（Earth-616）设定：宇宙层级/抽象实体/漫画时代/Gems 体系/团队与大事件。只认可追溯事实（wiki/Marvel 官方出版物），记版本冲突不压扁 |
| **线2 · 集体无意识印象测绘** | MCU 影视宇宙层（无限传奇/多元宇宙传奇阶段）、角色影视形象层、中文社区/梗文化层（我爱你三千遍/瓦坎达万岁/灭霸响指/I am Iron Man）。独立出「印象测绘」，与原典件显性分家 |
| **关键错位（本包必须先拆开）** | ① **"漫威=MCU 影视"**：多数中国观众只知电影，不知漫画 Earth-616 原典；② **无限宝石（MCU Stones）≠无限宝石（漫画 Gems）**：命名、颜色、起源、跨宇宙规则全部不同；③ **Earth-199999 vs Earth-616**：MCU 官方外编编号是 Earth-199999，但剧内自称 Earth-616（与漫画主宇宙编号重合），不能混为一谈；④ **灭霸"网红形象"（紫薯/计划生育委员）**：多是电影/萌娘百科二创标签，漫画原型是陀寂主义宇宙强者 |

## 五、两层关系与消费方式

- **线1/线2 分工**：线1（叙事层）回答"Marvel 漫画设定里这个宇宙客观是什么"；线2（印象测绘）回答"大众/MCU 观众/中文读者大脑里这宇宙成了什么、哪些被误当原典"；两件分开存放、冲突不压扁。
- **赛道包采源**：本包是带专名的原料层；超英流/共享宇宙类赛道包的「起源/组队/镜像反派/多元宇宙/阶段化叙事」等配方由此蒸馏（去专名）。
- **world 构筑**：多元宇宙+抽象实体层级、无限宝石类宇宙神器、超英共享宇宙、内战式阵营分裂等机制可整体借鉴重命名。
- **消费红线**：任何 Marvel 专名（钢铁侠/灭霸/复仇者/无限宝石/瓦坎达等）进正文前过 `版权指南.md`；"超级英雄/起源/组队/镜像反派"属思想层可自由化用；"我爱你三千遍/瓦坎达万岁"属线2表达层，用时标注来源属性、不得照搬名场面。

## 六、采源与采样留痕

- **线1 事实**：以 Marvel Comics 正史宇宙为准——英文维基加 Marvel/Wikia（marvel.fandom.com）+ MCU（marvelcinematicuniverse.fandom.com）交叉。关键点（Earth-616 命名1996/抽象实体职能/无限宝石漫画全貌/漫画时代/五大事件）逐条核验，≥6 处 URL 交叉；"漫威宇宙=MCU""无限宝石两侧一致"等易混点已显性拆解。
- **线2 事实**：各 MCU 阶段电影剧集英文维基词条 + MCU fandom（Multiverse/Sacred Timeline/Infinity Stones）+ 中文源（百度/baike.com/萌娘百科/B站专栏/游民星空/豆瓣）+ 票房（people.cn 中文头条交叉）。
- **采样留痕**：本研究周期实际核验源 ≥50（跨英文维基/Marvel&MCU fandom/中文百科/社区/票房新闻），关键事实点 ≥6 处带 URL 交叉；「灭霸网红形象」「我爱你三千遍」等二创表达已如实标注归属，不编造原典出处。
- **禁止凭印象补设定**——「无限宝石两侧同源同色」「MCU=唯一漫威」「地球-616 编号唯一」是三处最易带偏网文读者的误认，本包在双线判定与各件中显性标注。
