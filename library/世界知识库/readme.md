**全库通用基线**（沿用 `library/readme.md`，以下兜底约束本库适用）：
1. 单件≤15KB，超限拆分；frontmatter 带 read_policy（机器优先）
2. 无源不入库：官方优先（official-srd/wiki/public-domain），sources 字段具体 URL 或出版物，禁止凭印象写设定
3. 采样留痕：带"书名/来源+章节范围+件数+缺口"
4. 命名唯一、主题化；禁止断言与建议混装，编辑建议与事实分层标注
5. 百科体纪律：规则层（说明体）+叙事层（百科叙事体），五禁（禁二称/祈使/营销腔/口语叹词/无来源定性）
