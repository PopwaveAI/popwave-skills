## 一个子体系 = 一个包（禁止合并）

中国神话不是单一体系，而是多套来源独立、内部自洽、又互相冲突的子体系。正确粒度是「来源可切分、谱系自洽」：

| `中国-封神演义/` | ✅ v1.0.0（次包·三层分） | 谱系 / 源流与版本 / 专名物件 / 叙事装置 |

## 相关约束要点

1. 四维度包结构：谱系（速查）/ 源流与版本（事实叙事+冲突表）/ 专名物件（清单+专名雷达）/ 叙事装置（编辑建议·与事实分家）。
2. 版本冲突绝不压扁：同一神祇异源有出入，进 `源流与版本.md` 冲突表分行标源。
3. 多源兼祧对象（财神/灶神/土地/城隍/门神/妈祖/文昌）不入道教仙班主谱，归 `中国-民间信仰`。
4. 执行「五禁」（禁二称/祈使/营销腔/口语叹词/无来源定性）；编辑建议与事实分层标注。
