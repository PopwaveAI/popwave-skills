# skill-神话体系维护规范 · 内容目录

本目录是「世界知识库·神话体系」库的**维护规范集**，供任何 agent 在库内新增/维护子体系包时读取对齐。

| 文件 | 作用 |
|:--|:--|
| `SKILL.md` | 唯一规范源——四维度包结构 / SOP / 红线 / 文风纪律 / 速查表 |
| `templates/子体系包.tpl.md` | 新建一个子体系包时的目录骨架与首页模板 |
| `templates/谱系.tpl.md` | 谱系维度文档模板（速查体） |
| `templates/源流与版本.tpl.md` | 源流与版本维度文档模板（事实叙事体 + 冲突表） |
| `templates/专名物件.tpl.md` | 专名物件维度文档模板（清单体 + 专名雷达） |
| `templates/叙事装置.tpl.md` | 叙事装置维度文档模板（建议体） |
| `references/采源与版本冲突处理.md` | 采源三级制 + 版本冲突处理方法论 |

**强保障**：`SKILL.md` 由 host 层每次 run 强制注入，核心 SOP 与红线自含，不依赖模板/参考文件。
**弱保障**：模板与参考文件需 agent 按 `SKILL.md` 指引主动读取。
