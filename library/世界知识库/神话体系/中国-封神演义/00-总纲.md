# 中国-封神演义 · 总纲

> **一句话锚（先看二创视角，再看原典）**：
> - **当代读者/写手脑里的"封神"是二创堆出来的**——想到的是魔童版哪吒、洪荒流的"圣人/混元大罗金仙/先天至宝/量劫"、封神三部曲的商周史诗。这些**几乎都不是原著 100 回写的**。
> - **原著 100 回只是这套叠层的"最底层锚点"**——它写的是"一场天庭缺神引发的杀劫，借商周改朝换代当战场，三教共签封神榜来结账"。
>
> 所以本包的立场是：**二创是主体，原典是辨伪锚。** 谁把原文考据写成主线、把二创压成边角，谁就从根本上写错了封神。

> **本文档是包入口，不是内容本身**。它回答三个问题：这套知识的主体是什么（二创叠层）、原典摆在什么位置（辨伪锚）、每笔事实按什么标尺分层（红线与标签）。

---

## 一、最重要的一条定位（其余都从它推）

**封神≈七成二创 + 三成原典。** 因为封神的原文影响力早已被层层二创稀释，真正统治读者大脑、真正被网文写手调用的是：

| 二创层（主体） | 它贡献了当代"封神印象"的哪块 | 原典关系 |
|:--|:--|:--|
| 洪荒流（《佛本是道》以降） | "圣人/混元大罗金仙/准圣/先天至宝/量劫/鸿钧=天道"整套宇宙体系——**网文实际在用的封神力量观** | 原典无此体系，是二创新建 |
| 当代影视（魔童/封神三部曲/姜子牙/杨戬） | 哪吒叛逆、妲己报恩、姜子牙怀疑天命等**人设重构** | 人设翻案，偏离原典 |
| 老影视（1990版/2001TVB/1979动画） | 主流视觉模板：姜子牙仙风道骨、妲己艳妃、悲情哪吒 | 影视放大/改编 |
| 民俗（财神赵公明/雷神闻仲/中坛元帅哪吒） | 封神正神回落民间信仰的"现实锚" | 原典给名目，民俗给神格 |

**原典（辨伪锚，占少数）**的价值仅在于：当二创们互相打架、或写手想知道"这东西最原始长什么样"时，回 100 回原文给一个基准。除此之外，正文不围着原典转。

## 二、双线结构（谁是主、谁是锚）

```
线2 渊源谱系（主体，≈7成）          线1 原文考据（辨伪锚，≈3成）
───────────────────────          ───────────────────────
洪荒流体系 / 影视重构 / 民俗印象       封神榜机制 / 剧情脉络 / 势力原貌
力量体系的当代用法 / 人物渊源演变      上榜vs肉身成圣 / 原典名目出处
回答: 大众脑里的封神是什么、怎么用     回答: 辨伪时"最原初的样子"是什么
```

- **线2 是主体**：每个角色/概念，主线是"它如何从原典一路演变成今天读者脑里的样子"。这是封神包真正的交付物。
- **线1 是锚**：只在"给锚/辨伪"处引用原文卷回，不为考据而考据。
- **两线物理分层**：同一对象，"原著设定"与"二创印象"必须分节、标题标注、正文不混（红线 R2）。

| 层 | 准绳 | 用途 |

| **线1 锚** | 公版 100 回原文（维基文库/ctext）逐条标「第N回」 | 封神榜机制、剧情脉络、原典名目 |
| **线1 版本学** | 作者三说、成书、底本链 | IP 演变史的"史前段" |

**分层标签（每笔事实必带其一）**：

| 标签 | 含义 |
|:--|:--|
| `原著可证` | 100 回正文白纸黑字，附卷回（仅当"给锚"时用） |
| `版本异文` | 原著内部两处写法不同（如武当/无当圣母） |
| `学术争议` | 作者、成书先后未定，标"待核/两说并存"不压扁 |
| `佛道借用` | 神名源出佛/道，小说降格或另塑 |
| `民俗演化` | 原典之后民间信仰神格延伸（赵公明→武财神） |
| `洪荒流` / `影视二创` | 二创层，**这是主体，正面整理**，但标清层级 |
| `待核` | 未坐实，诚实标注，不许默认 |

## 四、红线（违反即断裂下游）

| # | 红线 |
|:-:|:-----|
| R1 | **二创是主体、原典是锚，不可颠倒**：凡写"力量体系/人物形象/概念演变"，主线必须是二创渊源；不得把"原典考据"写成正文、把二创压成边角的一小段。 |
| R2 | **二创与原典标清、不混**：二创内容必须显性标 `洪荒流/影视二创/民俗演化`，不得写成"原著设定"。典型陷阱：申公豹=豹妖(魔童)、杨戬劈山救母(宝莲灯)、"道友请留步"(非原文台词)。 |
| R3 | **版本冲突不压扁**：三头八臂(封神)/三头六臂(西游)/三头九眼八臂(搜神大全)分行列；365 vs 371 神数是版本学问题。 |
| R4 | **源优先**：事实须带来源，无两源交叉不得入库；散失处标「待核」不臆造。 |
| R5 | **不越边界**：关羽(三国)、劈山救母(宝莲灯)、西游专属设定不入封神谱系。 |
