# 14 · 力量体系（网文沿用的洪荒流力量观 + 原典的真实规则）

> **本件回答什么**：封神里"谁强谁弱"怎么算？网文写手写封神向作品，沿用的几乎是一套**洪荒流力量观**（等级境界 + 先天至宝 + 成圣），而这套原著 100 回并没有。本件把"网文实际在用的体系"当主体讲清，再给原典"真实规则"当锚。
>
> **本件纪律**：二创是主体（洪荒流是写手真正会调用的）。红线 R1（二创不冒充原典）在本件最危险——因为网文默认"封神有等级境界"，必须反复拆开"这是洪荒流，不是原著"。

---

## 一、先记住一句话

**网文写手写"封神/洪荒"，默认启用公认的洪荒流力量体系**：道祖(鸿钧)→圣人→准圣→大罗金仙→金仙……；成圣靠鸿蒙紫气、斩三尸；宝物分先天至宝/先天灵宝/后天灵宝。**这套体系几乎全是《佛本是道》（2007）之后网文建构的，不是封神原著。** 原著的真实规则朴素得多：**地位有梯度，境界无阶梯；胜负靠法宝 + 根行 + 天数，不靠等级碾压。**

---

## 二、洪荒流力量体系（网文主推，写手可 lift，但要标清来源）

### 2.1 力量阶梯（准主流版，各书有异→标版本异文）

```
圣人 > 准圣 > 大罗金仙 > 金仙 > 玄仙 > 天仙 > 真仙 > 地仙 > 人仙
（各书层级名称不一；此为网文准主流，标 洪荒流·版本异文）
```

- **道祖 = 鸿钧**：洪荒流金字塔顶端，众圣之师、天道化身、紫霄宫传道三千。
- **圣人**：最高果位，证得先天至宝 / 混元不磨；常见"六圣/七圣"席位（老子/元始/通天/女娲/接引/准提）。
- **准圣**：半只脚踏入圣人，受圣人压一头。
- **大罗金仙**：圣人之下绝顶战力（网文主角常备）。

### 2.2 成圣机制（百分百洪荒流二创）

| 机制 | 说明 | 判定 |
|:--|:--|:--|
| **鸿蒙紫气** | 成圣门票，洪荒文抢紫气成圣 | `洪荒流`（原著无） |
| **斩三尸** | 成圣必经三步 | `洪荒流`（原著只有"斩三尸"一词，无成圣机制） |
| **无量量劫** | 宇宙级清算周期 | `洪荒流` |
| **镇压气运** | 先天至宝/教门靠气运 | `洪荒流` |

### 2.3 宝物分级（写手高频用）

| 层级 | 含义 | 代表 | 判定 |
|:--|:--|:--|:--|
| **先天至宝** | 开天辟地前的顶级造化 | 盘古幡/太极图/诛仙四剑（洪荒流定型） | `洪荒流`（原著无此分级；具体宝物归属见 §四） |
| **先天灵宝** | 混沌中孕育 | 山河社稷图/番天印等 | `洪荒流` |
| **后天灵宝** | 后天炼制 | 各种刀剑法宝 | `洪荒流`（原著混称"宝贝/法宝"） |

> **写手取用**：这套分级是网文通用语言，写洪荒流可无缝用；但写"严格忠于原著"的封神，就不能用"先天至宝/后天灵宝"这套标签，原著只称"法宝/宝贝"。

## 三、原典的真实力量观（辨伪锚）

### 3.1 原著：地位有梯度，境界无阶梯

原著没有一个等级境界表。"强"体现在**两处**：

1. **地位梯度（谁大谁小）**：鸿钧（三清之师）→ 三教教主（老子/元始/通天，元首级）→ 燃灯道人/十二上仙 → 三代弟子（哪吒/杨戬/雷震子）→ 散仙。
2. **法宝决定战力**：同一水平下，**法宝相克**决定胜负（番天印被杏黄旗克、打神鞭只打榜上人）。

### 3.2 原文里反复出现的真术语（非等级）

| 词 | 出处 | 含义 |
|:--|:--|:--|
| **混元大罗金仙** | 第84回 | 仅指老子/元始/通天三人（"你三人乃是混元大罗金仙"），非通用果位 |
| **斩三尸** | 第84/99回 | "未曾斩却三尸"原词有，但无"三步成圣"系统 |
| **根行** | 第84回 | 资质根器，决定"成仙或成神" |
| **历劫 / 杀劫** | 第45/84回 | 命中的大劫，非等级 |
| **肉身成圣** | 第100回 | 活着没死没上榜，非更高果位 |

### 3.3 三天无境界：为什么原典没有"升级"

封神是"天命杀劫"驱动，不是"修炼晋级"驱动。人物强弱在出场时就定了（十二上仙永远比三代高一档），胜负靠**布阵/法宝/天数**，不靠临时突破。这与洪荒流的"修炼爬塔"哲学根本不同——写手要清楚自己在写哪种体系。

## 四、法宝 / 阵法的真实归属（纠偏高频区）

### 4.1 法宝归属速查

| 法宝 | 归谁 | 判定 |
|:--|:--|:--|
| 番天印 | 广成子 | `原著` |
| 金蛟剪 | **三霄**（赵公明之妹） | `原著`（旧薄片/大众错给赵公明） |
| 定海珠 | 赵公明 | `原著` |
| 缚龙索/金鞭 | 赵公明 | `原著` |
| 太极图 | 老子/太上老君 | `原著`（老子亦有） |
| 杏黄旗 | 姜子牙（元始赐） | `原著` |
| 打神鞭 | 姜子牙（元始赐） | `原著` |
| 山河社稷图 | 女娲 | `原著` |
| 盘古幡/混沌钟 | 洪荒流传为元始/太一 | `待核`（原著未坐实细节） |
| 诛仙四剑 | 通天教主（洪荒流大书特书） | `原著`有诛仙剑阵，`洪荒流`放大 |

### 4.2 阵法速查

| 阵法 | 设者 | 原著 | 破解 |
|:--|:--|:--|:--|
| 十绝阵 | 金鳌岛十天君 | 第45回 | 阐教联合破之 |
| 诛仙阵(诛仙剑阵) | 通天 | 第82回 | 老子/元始/准提/接引四圣齐破 |
| 万仙阵 | 通天 | 第83-84回 | 诸仙合力，通天兵败 |

> **写手取用**：金蛟剪=三霄的（不是赵公明）是本包高置信纠偏点，写时别踩。

## 五、印象测绘：网文里被二创定型的"封神战力"

| 当代认知 | 来源 | 原著对应 |
|:--|:--|:--|
| 鸿蒙紫气=成圣钥匙 | 洪荒流 | 无 |
| 盘古幡/混沌钟/诛仙四剑=先天至宝 | 洪荒流 | 盘古幡等 `待核`，诛仙四剑原文有剑阵、无"先天至宝"标签 |
| 圣人=最高果位（位格） | 洪荒流 | 原著"混元大罗金仙"仅指三清，非通用果位 |
| 金蛟剪=赵公明 | 大众误解 | 错（是三霄的） |
| "混元大罗金仙等于圣人" | 洪荒流 | 原词只在84回指三清 |
