# 20 · 剧情脉络（百回分幕 + 一条主线矛盾链）

> **本件回答什么**：封神从第1回到第100回，剧情怎么推进？主线矛盾是什么？影视改编把哪条线搬上了银幕、又改了哪几处？

---

## 一、一句话剧情

商纣王荒淫无道，女娲遣妖乱政（妲己惑主）；西伯侯姬昌得姜子牙辅佐、西周崛起；这背后是**天庭缺神、三教签封神榜，借商周改朝换代了却"十二代弟子杀劫"、填满天庭编制**。最终周胜商灭、姜子牙封神、七仙肉身成圣。

---

## 二、主线矛盾链（十一环节）

```
女娲受辱(1回) → 遣三妖乱政 → 纣王失德(酒池肉林) → 比干等忠臣被害
   → 西伯侯被囚/归周 → 姜子牙下山辅周 → 周兴商衰
   → 【暗线】天庭缺神 → 三教签封神榜 → 阐截弟子下山参战(搭上商周战场)
   → 截教大败(诛仙/万仙阵) → 周灭商 → 姜子牙封神 → 七仙肉身成圣
```

**表层**：有道伐无道（周德之承）。**深层**（天门之战）：神仙借商周杀劫了因果、天庭因此满编。两条线互相支撑——人间线提供战场，仙线提供动机。

## 四、影视改编的剧情选择（印象测绘）

| 影视 | 聚焦 | 剧情取舍 | 与原著差异 |
|:--|:--|:--|:--|
| **1990《封神榜》** | 完整主线 | 保留百回主线浓缩 | 妲己/姜子牙双线为主，删仙阵细节 |
| **2001 TVB《封神榜》** | 少年哪吒成长 | 以哪吒为主角、亲情成长线 | 弱化商周大叙事，突出哪吒 |
| **2019《哪吒之魔童降世》** | 哪吒/敖丙双生 | 全新：魔丸天劫 | **彻底脱离原著主线**，仅借人物 |
| **2020《姜子牙》** | 封神战后 | 姜子牙质疑天命 | 翻案线，原著无此质疑 |
| **2023《封神第一部》** | 商周政治史诗 | 质子军团、姬发成长、去神化 | 删仙阵、强化人间权谋 |

> 影视改编总体走向：**去神化→人本化**（把神降成有人性的人），与原著"天命杀劫"是两个路线。写手可从"人本 vs 天道"两套立场择一。
