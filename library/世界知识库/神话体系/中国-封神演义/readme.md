## 归包边界声明

本包为"封神演义"这一个子体系，与 `中国-道教仙班` 是**交叉但不重复**——同名神（元始/老子）在封神的设定与道教的位次不同，取用须以本包判定优先并标「演义设定」。封神分配的民间财神（赵公明等）原属多源兼祧，本包记录其"封神分配"事实，细化归 `中国-民间信仰`。
