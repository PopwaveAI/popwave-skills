# 中国-封神演义 · 专名物件

> 定位：作者可直接拎走的法宝/阵法/神位/角色能力专名。清单体，每条带源。**关键纪律：区分「原著明确」「百科整理」「洪荒流二创」**。

## 一、圣人级至宝（原著层）

| 法宝 | 归属 | 定位/出处 |
|:--|:--|:--|
| 太极图 | 太上老君 | 化万物、定地水火风，卷人入图即化（卷61化殷洪）；**原著只有此图+盘古幡，无混沌钟** |
| 盘古幡 | 元始天尊 | "撕裂鸿蒙混沌、粉碎诸天时空"，用于破太极阵 |
| 诛仙四剑＋诛仙阵 | 通天教主 | 全书唯一圣人级杀阵，四圣（太上老君/元始/接引/准提）齐至不可破（卷78三教会破诛仙阵） |
| 山河社稷图 | 女娲（借杨戬） | 图内自成小世界，困缚袁洪（卷92收七怪） |

> ⚠️ **洪荒流二创强调**：混沌钟/东皇钟、盘古幡"先天至宝"评级、《封神演义》均无此宝、无"先天至宝/先天灵宝"等级划分，系洪荒流二创。[[s6]](https://m.baike.com/wiki/混沌钟/4800734)

## 二、阐教/姜子牙所用专名法宝

| 法宝 | 归属 | 用途 |
|:--|:--|:--|
| 番天印 | 广成子→殷郊 | 翻天即打，被杏黄旗挡住 |
| 杏黄旗 | 元始→姜子牙 | 防御至宝，挡番天印等攻伐 |
| 打神鞭 | 元始→姜子牙 | 木鞭，三尺六寸五、二十一节、八十四符印；**仅能打封神榜上有名者** |
| 捆仙绳 | 惧留孙 | 擒缚道行不深者（土行孙偷用） |
| 定海珠 | 赵公明→燃灯 | 组二十四诸天，赵公明靠其打伤众仙 |
| 金蛟剪 | 三霄 | 两蛟一合断物，剪断燃灯梅花鹿 |
| 混元金斗 | 三霄 | 困十二金仙、"闭顶上三花削胸中五气"（卷50九曲黄河阵） |
| 阴阳镜 | 赤精子 | 照人分生死 |
| 遁龙桩 | 文殊广法天尊 | 套人锁缚 |
| 玲珑塔 | 燃灯授李靖 | 收俘哪吒，"托塔"之名自此 |

> ⚠️ 捆仙绳/阴阳镜/遁龙桩/玲珑塔/定海珠/金蛟剪的具体归属多出自@自媒体转述与卷次锚点，**待核**：以维基文库对应卷原文复核。照妖镜持有者存疑，不标归属。

## 四、角色能力首创专名

| 专名 | 首创属性 | 说明 |
|:--|:--|:--|
| 轩辕坟三妖/九尾狐魅惑 | **封神首创** | "三妖+狐精附身妲己"为小说改创（妲己史有所载但狐化魅惑为创） |
| 八九玄功 | **封神首创** | 杨戬、袁洪修，八九相乘即72，后被《西游记》沿用 |
| 哪吒莲花化身 | **封神首创情节** | "剔骨还父、莲花化身"为封神确立（哪吒原型源自佛教护法） |

## 五、代表神位专名（封神分配，供写作 lift）

雷部闻仲（九天应元雷神普化天尊）、财神赵公明（正一玄坛真君）、三霄（云霄/琼霄/碧霄=感应随世仙姑）、太岁殷郊、斗母金灵圣母、瘟神吕岳。⚠️ 赵公明财神为封神分配，与民间财神脉络另层，细化归 `中国-民间信仰`。
