# 中国-封神演义 · 源流与版本

> 定位：回答「这部戏从哪来、怎么成书、与道教仙班错在哪、洪荒流怎么再传播」。**小说虚构/道教借用/洪荒流衍生三层分**是本文件核心。

## 一、成书过程（世代累积型小说）

定义段：《封神演义》是一部**世代累积型**长篇章回神魔小说，约成书于明隆庆、万历年间（约1567—1619），并非一人一次成稿。[[s1]](https://zh.wikipedia.org/wiki/封神演义)

**演进脉络**：

| 阶段 | 事件 |
|:--|:--|
| 宋元讲史 | 武王伐纣传说长期流传，有白话《吕望兴周平话》等 |
| 元代话本 | 《武王伐纣平话》成，是讲史"总结"，含历史骨架 |
| 明代小说 | 在平话基础上扩编为《封神演义》，叠加神魔封神框架 |

> 承袭与再创造分界：约三分之一内容来自《武王伐纣平话》与《列国志》，第一至三十回几乎据平话改编；但**"封神榜/应劫/三教共签"神魔框架为小说家再创造**，平话本属讲史体、未系统构建神职册。[[s2]](https://m.baike.com/wiki/封神演义/19475229)

## 二、作者与成书年代争议

成书约1567—1619。作者三说并陈，未定论：[[s2]](https://m.baike.com/wiki/封神演义/19475229)

| 说法 | 主张者 | 依据 |
|:--|:--|:--|
| 许仲琳编 | 鲁迅《中国小说史略》首倡 | 现存最早刊本金阊舒载阳本题"钟山逸叟许仲琳编辑" |
| 陆西星作 | 孙楷第、胡适等倾向 | 道士陆西星，书中三教合一宗旨与其身份相符 |
| 李云翔整理 | 章培恒等 | 舒载阳刻本卷首李云翔序称续成其事 |

## 三、与道教仙班的关系与错位（核心层分）

**道教三清原序**：玉清元始天尊（第一位）、上清灵宝天尊（第二位）、太清道德天尊=太上老君（第三位）；三清神名均为道教原有。[[s5]](https://m.baike.com/wiki/三清尊神/682582)

**逐一判定**：

| 神/概念 | 属性 | 说明 |
|:--|:--|:--|
| 太上老君 / 元始天尊 | 道教借用 | 取三清神名，混同历史人物老子，列为鸿钧大弟子 |
| 灵宝天尊 | 道教借用 | 封神中未以"灵宝天尊"出场，其位被原创的通天教主置换 |
| 鸿钧道人 | **小说虚构** | 正统道教神谱并无鸿钧，系作者原创三徒之师；后世道门/民间/洪荒流不断抬高 |
| 通天教主 | **小说虚构** | 作者原创截教教主；原型有"灵宝天尊/祆教"两说 |
| 阐教 / 截教 | **小说虚构** | 源于"一教分阐、截"的想象 |
| 封神榜 | **小说虚构** | 三教共签、姜子牙执掌的核心机构设定 |
| 杀劫 / 量劫 | **小说虚构** | 借用"劫"词，"神仙一千五百年之杀劫"为小说构造 |

**核心错位**：真正改造在两点——把三位道教天尊**降格为同门师兄弟**并列，且用原创通天教主顶替灵宝天尊位，又在道教三清之上**凭空新增最高神鸿钧**。[[s3]](https://m.baike.com/wiki/鸿钧/684344)

**角色来源**：女娲=借上古祭祀原有；姜子牙=史有其人+神化；哪吒=佛教护法源头、封神定型"莲花化身"；杨戬=民间二郎神传说综合；雷震子=小说原创。[[s1]](https://zh.wikipedia.org/wiki/封神演义)

## 四、版本与影响

**主要版本**：现存最早刊本为明金阊舒载阳刊本（二十卷一百回，题"许仲琳编"）；通行本以清四雪草堂订正本（十九卷一百回）为母本，清各本多翻刻自此。[[s2]](https://m.baike.com/wiki/封神演义/19475229)

**影响**：
- 民间信仰：把比干、闻仲（封雷部）等封神化，封神台诸神谱进入民间崇拜。
- **洪荒流再传播**：""封神榜/圣人/量劫/气运"概念经梦入神机《佛本是道》（2006，起点）打通《封神》《西游》与上古神话后成为洪荒流标配，鸿钧也自此成为洪荒文必需存在。[[s3]](https://m.baike.com/wiki/鸿钧/684344)（此点多为网络文学批评层面的二手评述，标注为编辑判断）
