## 版本冲突总览（详见 `源流与版本.md` §三）

| 对象 | 关键分歧 |
|:--|:--|
| 玉皇大帝 vs 昊天上帝 | 教内认同同一 vs 官方祭祀不同一 vs 《玉皇经》中为两神有高下 |
| 元始天尊 vs 盘古 | 学术倾向"元始天王为原型、后与盘古/元始天王互摄" vs 民间直称盘古化身 |
| 太上老君 vs 老子 | 道门称"老子仅其化身之一" vs 历史人物老聃 |
| 四御 vs 六御 | 名单两种：去玉皇+青华得四御 vs 六御含南极长生+东极青华 |
| 十二元辰 | 十二月将系统 vs 值年太岁（六十甲子）系统，易混 |
