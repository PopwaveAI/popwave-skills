# 中国-道教仙班 · 专名物件

> 定位：作者可直接拎走的专名/物件清单。清单体，每条带源；用于连载取用与版权规避登记。多源兼祧神不在此列（归民间信仰包）。

## 一、仙阶与仙人分等（可作境界专名）

| 名称 | 性质 | 描述 | 出处 |
|:--|:--|:--|:--|
| 五仙（鬼仙/人仙/地仙/神仙/天仙） | 道经原有 | 《钟吕传道集》「法有三成、仙有五等」：鬼仙阴中超脱、人仙得法不脱、地仙炼形住世、神仙脱质升仙、天仙受天书任仙官 | [[s1]](https://www.quanxue.cn/ct_daojia/zhongnv/zhongnv01.html) |
| 九等仙（上仙/高仙/大仙/神仙/玄仙/真仙/天仙/灵仙/至仙） | 道经原有 | 《太真科》九品，次序在不同转述有出入 | [[s-ar]](https://www.sichuanpeace.gov.cn/sfzjzs/20240419/2858936.html) |
| 天官/地官/水官（仙官职阶） | 道经原有 | 《钟吕传道集》以天仙受任仙官分下/中/上曰水官/地官/天官，历洞天返三清 | [[s1]](https://www.quanxue.cn/ct_daojia/zhongnv/zhongnv01.html) |
| 大罗神仙 / 大罗天 | 道经原有 | 三十六天最高大罗天的求道境界 | [[s-ro]](https://m.baike.com/wiki/大罗神仙/1975622) |
| 炼气/筑基/金丹/元婴/化神… | **网络修真小说虚构** | 非道经原有等级，系现代网文再创造（多源自《凡人修仙传》等作品及影响）；内丹原典只讲「三关功夫」 | [[s-net]](http://m.toutiao.com/group/7678708820713194007/) |

> ⚠️ 上表末行「五仙/九等（道经原有）」与「炼气/筑基/金丹（网文虚构）」分属两层，写作取用时须分清，不可混作同一体系（规范红线5 事实/建议分层）。

## 二、道教法器（内丹与科仪用器）

| 名称 | 定位 | 出处 |
|:--|:--|:--|
| 法印（含道经师宝印、天师印） | 符箓科仪核心，申制章奏、炼度亡魂、辟邪；道经师宝印代表道/经/师三宝 | 转述，**需以《道法会元》核** |
| 天蓬尺 | 法尺，刻日月宿曜天蓬元帅，镇坛役雷神；《道法会元》「无天蓬不可以役雷神」 | 转述引《道法会元》 |
| 令牌（五雷号令） | 以雷击木制「五雷号令」，役使雷霆，雷法重器 | 转述引《道法会元》 |
| 八卦镜 | 凸/凹/阴阳镜，化煞照妖；源出《抱朴子》「明镜九寸以上，老魅不敢近人」 | 转述引《抱朴子》 |
| 道剑/法剑（桃木剑） | 役使鬼神、斩邪之器 | 民俗常识，来源较弱 |
| 拂尘（云帚） | 象征扫除尘垢、仙风道骨，高功执仪 | 民俗常识，来源较弱 |
| 如意 | 天尊/祖师手执仪仗，象征如意称心、位分尊崇 | 二十四类法器列表转述 |
| 铜钱剑 | 以铜钱串制，辟邪镇宅 | 仅见网络常识，**权威依凭不足** |

> ⚠️ 法器细目道经原文藏于《道法会元》《灵宝玉鉴》《抱朴子》，在线直读少；本件多为基础转述，**均标注为待核**（见「编辑判断与待核」）。
