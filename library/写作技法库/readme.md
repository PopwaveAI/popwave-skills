## 入库约束（对齐总表速查表）

| 唯一规范源 | 入库前必须先读 | 规范强度 |
|:--|:--|:--|
| `写作技法库/00-索引.md` + 各协议（章纲组装协议/文风DNA槽位协议） | 采源标准 / 单件≤15KB / frontmatter | 中（索引约定） |

**全库通用基线**（沿用 `library/readme.md`，以下兜底约束本库适用）：
1. 单件≤15KB，超限拆分；frontmatter 带 read_policy（机器优先）
2. 无源不入库：每件知识能回答"凭什么这么写"（源书锚点/官方设定/公版原文/权威教程）
3. 采样留痕：跨书/跨章采样类知识带"书名+章节范围+件数+缺口"留痕块
4. 命名唯一、主题化；禁止 `_原文案`/`_HTML源码` 双文件冗余（合并为单一 wiki 页）
5. 禁止百科式散文：agent 优先，分类维度=知识离写作的距离，无杂项抽屉
