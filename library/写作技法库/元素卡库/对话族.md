# 对话族·组装卡（v3）

> v3（2026-08-21）：按「元素卡=组装卡」标准重构——节拍序列为主体（每拍=拍义+填法标准），槽位表解散，源书降为溯源行。
> 来源：《深渊主宰》ch001-015，7个对话实例。

## 用法（三步）

1. **选卡**：按情境表对号入座；注意攻守方位（谁主动谁被动决定选哪张）
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准现编

## 选卡情境表

| 情境 | 选卡 |
|---|---|
| 对方主动接触（他攻我守） | 卡1 拦路传话卡 |
| 我方强势立规（我攻他服） | 卡2 送礼慑服卡 |
| 敌方阵营视角议事 | 卡3 敌方议事卡 |
| 借人群侧写主角 | 卡4 群像侧写卡 |
| 交易/托付/合作 | 卡5 托付交易卡 |
| 归家收情报 | 卡6 归家汇报卡 |

**对话三底线**（任何卡不可缺）：交锋推进 · 对方/群像在场 · 情报落料（对话=情报中转站）

## 卡1【拦路传话卡】

**适用**：对方主动接触——传话/招揽/威胁，我方守势（与卡2互为镜像）。

**节拍序列**（7拍）：
1. **环境交代** — 场所生态先行：这是什么地方、什么规矩（帮派/码头/市集）
2. **对方搭话** — 主动接触：拦路/传话/递话，来意半遮半掩
3. **履历插叙** — 对方是谁：背景/实力/伤疤——插叙给对方立档
4. **交锋应答** — 我方冷回：话里带刀的应对，姿态即立场
5. **底牌亮出** — 对方真实来意：招揽+暗胁的最后通牒
6. **杀意压制** — 我方的反应：起杀意但压下（时机未到/有正事），克制即蓄势
7. **战力判定** — 内心评估：他撑不过三招——给对抗定调

**写法要点**：交锋台词要「答非所问」的锋利（例：「头儿已经死了，被巫师杀了」）；插叙档案挂在对话里，不带旁白腔。
**线效果**：威胁线（新对手开线）｜档案线（对方履历+场所生态）
**源书**：ch006拦路（加里斯传话）

---

## 卡2【送礼慑服卡】

**适用**：我方强势期——对方登门服软/送礼/试探，我方立规矩（卡1的镜像）。

**节拍序列**（6拍）：
1. **异动观察** — 前兆信号：陌生人徘徊/反常安静——风起于青萍之末
2. **对方登门** — 服软的姿态：畏惧的肢体语言+进门的犹豫
3. **献礼** — 诚意具象：礼盒/钱财/消息——礼的价值即畏惧的刻度
4. **划界立规** — 我方的价码：什么事管/什么不管——立规矩即立人设
5. **武力威慑** — 红线的可视化：亮一手（兵器/伤疤/战绩）——威慑要「演」不要「说」
6. **慑服应承** — 对方的答复：擦汗/结巴/连连点头——服的程度写身体反应

**写法要点**：威慑用表演不用威胁台词（指尖转匕比「我能杀你」狠）；划界内容=主角行为准则的宣言，读者由此记住底线。
**线效果**：威名资产化｜势力线（新格局定型）
**源书**：ch009送礼（萨维派人）

## 卡3【敌方议事卡】

**适用**：切敌方阵营POV——头目+手下的会议，借敌口侧写主角威名。

**节拍序列**（6拍）：
1. **敌方视角** — 切入对方的处境：刚听说什么/刚失去什么
2. **情绪反转** — 对主角的重新评估：不屑→难看/忌惮——态度转变即威名刻度
3. **情报复盘** — 手下汇报：主角做了什么——读者视角复习+敌方解读
4. **蠢货提议** — 错误方案登场：不知死活的建议——蠢货是流程必备
5. **首领镇压** — 正确认知拍桌子：实力对比讲清楚（正面打=全死）
6. **定策** — 敌方下一步：送礼/观望/结盟——敌方动作=下章压力来源

**写法要点**：敌方对主角的评价=威名的第三方认证，必须借敌口说出（自夸禁用）；蠢货提议的功能是替读者问「为什么不打他」。
**线效果**：威名线（敌方认证）｜威胁线（敌方定策=新压力预告）
**源书**：ch009议事（萨维变脸）

## 卡4【群像侧写卡】

**适用**：借人群侧写——路人窃语/酒馆议论/围观，世界对主角事件的反应。

**节拍序列**（5拍）：
1. **环境生态** — 场所的规矩：什么人来/什么话传/什么钱赚
2. **群体议论** — 人群在说主角：传闻版本+幸灾乐祸/敬畏——传闻会走样
3. **目标在场** — 事件相关者在场：被议论的主角或对手就在人群里
4. **当事人内心** — 目标的真实处境：骑虎难下/硬着头皮——议论与内心的反差
5. **离场动作** — 目标的决定：起身赴死/咬牙行动——议论把他推出去

**写法要点**：议论要「有信息量」（借嘴补世界观/事件背景）；当事人内心与表面议论的反差是张力来源。
**线效果**：威名隐性积累｜档案线（场所生态）
**源书**：ch003出殡（路人窃语）· ch004酒馆（议论+赴死）

## 卡5【托付交易卡】

**适用**：交易/托付/合作谈判——资源换保障，钱与信任的双向流动。

**节拍序列**（6拍）：
1. **托付决策** — 为何要托付：风险不可控→需要更安全的方案
2. **献金动作** — 诚意先行：钱袋/供品递出——交易的硬通货
3. **对方变脸** — 世俗的回应：听钱声变脸/收钱办事——神圣场所的世俗底色
4. **安排落定** — 交易达成：具体安排交代清楚（谁照顾/多久/条件）
5. **人情暗账** — 隐形的账：这笔钱顺便还了谁的人情/结了谁的缘——伏笔埋进交易
6. **告别约定** — 情感收尾：约定+亲昵（接你的时间/额吻）——交易块也要有温度

**写法要点**：变脸拍是本卡的「世界观泄露口」（神殿也认钱=世界底色）；人情暗账不必明说，读者回看才懂。
**线效果**：生存线（-钱+保障）｜感情线（约定倒计时）｜人情线（暗账入账）
**源书**：ch011托付神殿（60银德勒）

## 卡6【归家汇报卡】

**适用**：归家收情报——回家撞见变化/来客/消息，家的日常+情报打包。

**节拍序列**（8拍）：
1. **归家异样** — 直觉先行：闻声/见物，反常即信号
2. **第三者登场** — 家里有客：谁/什么来头/和我家什么关系
3. **背景插叙** — 来者档案：插叙立档（职业/派系/与主角的渊源）
4. **情报汇报** — 事件还原：家人/来客转述发生了什么
5. **杀机迸发** — 我方反应：威胁落到家人身上=底线被碰
6. **当场决策** — 立刻的安排：搬家/反击/托付——反应要快才显重视
7. **温情小拍** — 软的一手：糖果互喂/家常——硬决策后的柔化收尾
8. **人情入账** — 恩怨分明：谁帮过忙记下——恩账也是设定资产

**写法要点**：情报必须借转述（家人看到的和主角知道的有信息差，信息差=张力）；杀机与温情同章混排是「外冷内热」人设的固定写法。
**线效果**：威胁线升级｜感情线｜人情线
**源书**：ch007归家（安亚丽+踩点警报）

## 族级硬规则（3条）

1. **情报借嘴说出**：世界观/事件背景优先从对话泄漏，旁白科普降格（对话族=情报中转站，样本7/7全带情报落料）
2. **对话结束必落决策**：谈出下一步行动（定策/搬家/交易达成），纯聊天块禁用
3. **威名借他口**：主角实力/战绩必须借对方或群像之口认证，主角自评仅限内心
