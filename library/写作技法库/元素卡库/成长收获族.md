# 成长收获族·组装卡（v3）

> v3（2026-08-21）：按「元素卡=组装卡」标准重构——节拍序列为主体（每拍=拍义+填法标准），槽位表解散；「开奖卡+洗劫反转卡」合并为一张卡（得失两走向）。
> 来源：《深渊主宰》ch001-015，11个收获实例。

## 用法（三步）

1. **选卡**：按情境表对号入座；注意福祸锯齿波（连得两块后必配损失/代价）
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准现编

## 选卡情境表

| 情境 | 选卡 |
|---|---|
| 实操攒经验 | 卡1 练级实操卡 |
| 升级/属性全面结算 | 卡2 面板结算卡 |
| 阶段性自我盘点 | 卡3 自检盘点卡 |
| 规划下一步投入 | 卡4 规划立项卡 |
| 发现并获取宝物 | 卡5 得宝开盒卡 |
| 随机结果揭晓（得/失） | 卡6 开奖卡 |

**收获一底线**（任何卡不可缺）：数值/数据落账——数值弹幕是收获块的心跳

---

## 卡1【练级实操卡】

**适用**：实操攒经验——练级/偷窃/拆解的作业流，数值弹幕的主场。

**节拍序列**（5拍）：
1. **实操场景** — 作业环境：在哪/防什么/用什么工具
2. **动作+数值弹幕** — 边做边报数：每个动作对应一笔经验/收获（动作→数字→动作）
3. **难度爬坡** — 递进的挑战：简单→警报陷阱→双飞刀——一卡内难度阶梯
4. **升级/总额结算** — 攒够的兑现：升级播报或日收总结
5. **撤离/规则落账** — 收工：撤退路线或经验规则总结（例：同锁不重复给经验）

**写法要点**：弹幕节奏=数字紧跟动作（「+15」紧跟撬锁成功），延迟播报破坏爽感；难度爬坡必须有，平铺作业降格。
**线效果**：成长线↑｜生存线（收入落账）
**源书**：ch006练级 · ch007日收 · ch013拆弩

---

## 卡2【面板结算卡】

**适用**：升级/属性的全面结算——里程碑时刻，全数据亮相。

**节拍序列**（4拍）：
1. **达成确认** — 升级条件凑齐：经验条满/属性到位——先报达成
2. **全面板罗列** — 数据全亮相：属性/职业/生命/技能逐行陈列
3. **重点解读** — 数据背后的意义：哪项质变了（20=超凡门槛）——关键数字要翻译
4. **伏笔埋设** — 数据行藏钩：封印技能/待觉醒项写进面板——数据本身当伏笔

**写法要点**：全面板每级只晒一次（频繁晒=注水）；重点解读不超过两句（读者要爽不要课）。
**线效果**：成长线里程碑｜金手指线（面板更新）
**源书**：ch002面板首现 · ch010三级面板

---

## 卡3【自检盘点卡】

**适用**：阶段性自我盘点——身体/资产/技能的家底清点。

**节拍序列**（6拍）：
1. **触发动作** — 盘点的契机：换衣/疗伤/洗澡——看到自己才想起盘点
2. **身体盘点** — 硬件现状：伤疤/体征/异相——身体是履历
3. **特征自察** — 天赋确认：血统/特质带来的优势
4. **短板自评** — 缺什么：属性短板/能力缺口——短板=下步方向
5. **潜质发现** — 隐藏的可能性：尚未点亮的苗头（左手灵巧=双武器潜质）
6. **路线展望** — 盘点收束：终极目标/期待（解封之日）

**写法要点**：盘点必含短板块（只有优势=自恋卡）；潜质块是给未来的自己开票。
**线效果**：成长线（自我定位）｜档案线（身体履历）
**源书**：ch005自检（伤疤+短板+潜质）

---

## 卡4【规划立项卡】

**适用**：规划下一步——技能点/资源往哪投，理性的爽点。

**节拍序列**（5拍）：
1. **后果确认** — 上阶段的账：旧路径关闭（仓库进不去）或旧目标完成
2. **目标转向** — 新方向：环境变化逼出新选择
3. **规划落料** — 具体的投入方案：点数分配/资源投向——逐条交代用途
4. **中期目标抛出** — 下一个里程碑：藏宝洞/3级——立项
5. **前瞻预告** — 再远一点的钩：二阶/专长名——给读者期待

**写法要点**：规划必须具体到分配方案（全灌潜行+各技能用途），「变强」这类空话降格；前瞻预告只给名字不给细节（留期待）。
**线效果**：成长线（路线图）｜目标线立项
**源书**：ch007规划（技能点+藏宝洞）

---

## 卡5【得宝开盒卡】

**适用**：发现并获取宝物——探索的兑现时刻，从失望到聚焦的过山车。

**节拍序列**（6拍）：
1. **进入** — 到达藏宝点：推开密室/抵达埋点——期待拉满
2. **环境扫描** — 第一眼的落差：荒废/不值钱——先抑
3. **目标聚焦** — 异常物捕捉：一堆破烂里的那一件（材质/光泽不对劲）
4. **判别确认** — 价值的确认：材质/铭文/直觉——懂行感
5. **安全规程** — 老手的谨慎：试探陷阱/隔离操作（托在手心远离脑袋）——专业感来源
6. **开启/获取** — 到手：开启动作或拾取——悬念兑现

**写法要点**：先抑后扬是固定节奏（直接开门见宝=廉价）；安全规程拍是「老手人设」的展示窗。
**线效果**：装备线/目标线（宝物入账）｜金手指线（物品辨识）
**源书**：ch013开盒（铁木盒+三牌）

---

## 卡6【开奖卡】

**适用**：随机结果揭晓——抽奖/开卡/开箱的命运时刻。**得失两走向**：走向A兑现（爽点直给），走向B清零（喜剧化低谷）。

**节拍序列**（6拍）：
1. **开奖动作** — 启动仪式：滴血/翻牌/开箱——仪式感先行
2. **画面呈现** — 结果的预告：卡面/影像先给画面
3. **期待峰值** — 最好的想象：读者的期待被文字推到顶（宝物卡的幻象）
4. **结果揭晓** — 命运的答案：判定词一出（神偷/苦行者）
5. **走向A（得）** — 兑现型：属性+3/专长觉醒——爽点直给，附稀有度科普
   **走向B（失）** — 清算型：全偷光/掉血——期待崩塌+喜剧化低谷
6. **情绪收束** — 得：欣喜自检（捶胸验货）；失：骂骂咧咧+自嘲

**写法要点**：期待峰值必须推满再揭晓（落差才是喜剧/爽感的燃料）；走向B的损失要具体列出清单（丢了什么一件件数）——损失可视化才有「惨」的喜剧感。
**线效果**：成长线（属性跃升）或 装备线（清零反转）｜福祸锯齿波
**源书**：ch013神偷（走向B）· ch014苦行者（走向A）

---

## 族级硬规则（3条）

1. **数值弹幕必配**：收获块样本10/11带数据落账，无数据的「感觉自己变强了」降格
2. **福祸锯齿波**：收获序列不走直线（得→失→得），连得两块后必配损失/代价（神偷清零垫在苦行跃升前）
3. **双结算机制**：经验（累积慢）+属性（跳跃快）——升级缺席时用属性直加接管跃升感，爽点不空窗
