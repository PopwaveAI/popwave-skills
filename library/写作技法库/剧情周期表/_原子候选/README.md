# 原子候选池

> 中转区，**不是正库**。decon 拆书时 L1 第 8 维「功能位（原子候选）」顺带标注的原始候选，统一归集到这里，等同一功能义攒够 ≥2 本异构血肉后再自动走入库 SOP 上架。

## 一、目录约定

```
_原子候选/
├── README.md        ← 本文件（格式 + 归集规则）
├── 候选池.md         ← 汇总表：功能义 → 已攒书目 → 状态
└── {功能义}.md      ← 一功能义一份，原始候选记录
```

## 二、候选记录格式（`{功能义}.md`）

```
# 【功能义名】

| 源书 | ch锚点 | 干什么活 | 服务爽点 |
|:--|:--|:--|:--|
| 《没钱修什么仙》 | ch005-006 | 主角…… | 成长 |
| 《苟在初圣魔门当人材》 | ch002 | 主角…… | 燃 |
```

- 功能义名 ≤6 字，自带功能义，**不出现人名地名**。
- 每条候选必须可回源（源书名 + ch 锚点），禁止凭空编。

## 三、归集与上架触发

1. decon 拆完一本书，把 L1 第 8 维候选按功能义归集到对应文件。
2. 归集后逐功能义复查：**同一功能义攒够 ≥2 本不同书 → 自动走入库 SOP 上架**（抽功能位 → 定族打 tag → 入库族目录 + 登记索引与溯源）。
3. 仍只 1 本 → 留在候选池待下本书收敛，不上架。

## 四、规则引用

- 入库 SOP + 增长与裂变规则 + 分支 ≤8 条上限 → 见 `../00-建设计划.md`。
