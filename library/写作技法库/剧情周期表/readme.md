# 剧情周期表 · 库说明

网文「剧情原子」库。每个原子 = 一个事件级功能节点（如「被轻视」），可检索、可自由组合成章纲/链。替代旧的「54 张场景节拍卡」。

## 原子卡标准

母版 = `蓄压族/被轻视.md`。每张卡固定三段：

```
frontmatter（id + 族 + 4维tag：功能/爽点/赛道/位置）
→ 一句话功能义（干什么活 + 服务爽点）
→ 功能骨架（N 个功能位，每步 = 干什么 + 合格线，可开分支选择）
```

## 11 族

蓄压 / 施压 / 战斗 / 突破 / 兑底 / 反击 / 情感 / 守护 / 探索 / 钩子 / 转场 —— 一族一文件夹。

## 红线

1. **不凭空编**：每个原子从真实小说剧情提炼（红线中的红线）。
2. **单个节点**：一个卡一个原子，不做锁死链。
3. **族按功能义切**，不按场景切。
4. **卡内不写溯源**：来源统一登记在 `溯源登记.md`。

## 用库方式

见 `00-周期表索引.md`（三入口反查 + 检索流程）。
