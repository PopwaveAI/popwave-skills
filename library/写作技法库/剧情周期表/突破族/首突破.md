# 【首突破】

干什么活：主角把某一维度（修为/功法/肉体）的积累推到临界，一次标志性跃迁兑现成实力抬升，从「差一步」到「成了」。
服务爽点：成长（踏实的进阶感，让读者看见主角真的变强了）。

## 功能骨架（4 功能位）

1. **临界蓄势** —— 主角已把该维度的积累推到「只差最后一步」。
   > 合格线：能数出「差在哪」——练到第 N 遍、气机差一线、只差临门一脚，不是凭空要跳级。

2. **触发补全** —— 一个契机把最后一步补上。
   > 合格线：突破有具体来路，不是「主角光环」硬跳。

   > **A · 练满量化**：金手指给了明码门槛（练满十遍 / 到第 N 级），主角练满即破。选它当书里有面板/系统计数。如「健体三十六式1级（9/10），练满第十遍，数值跳成2级」。

   > **B · 夺人积累**：夺取对方已攒到临界的那股劲，补全自己的最后一步。选它当有采补/吞噬/掠夺类设定。如「反采补玉素真，把她体内差一步炼气的『炁』抽出来，神与气合」。

   > **C · 外力压破**：生死一线、倒计时、危局逼到极限，硬生生压破关。选它当要体现「逼」的痛与爆发。如「邪神倒计时逼到极限，十遍练完，体内那层膜轰然破开」。

3. **质变符号** —— 跨过门槛那一刹的可感标记。
   > 合格线：有一个明确的「成了」信号——面板数字跳变、境界名落地、身体异响异象、明悟灌顶。不能只写「他突破了」四个字带过。

4. **收益对账** —— 突破立刻换成可感收益。
   > 合格线：写清「变强了什么」——认知更深刻 / 数值涨 / 地位升 / 新能力解锁，至少兑现一样。
