# 【被轻视】

干什么活：主角进有评价权的场合，被上位者用「多把标尺」起伏评判，最终落在「不够格」，为反击/打脸攒势。
服务爽点：憋屈（起伏的落差）→ 打脸。

## 功能骨架（6 功能位）

1. **入场关系场** —— 主角进入一个「有人能一锤定音评价他」的场合。
   > 合格线：评他的是有话语权的上位者（长辈/神职/长老/老板），不是路人。

2. **立标尺** —— 评价者端出「主尺」（核心维度，定生死），可带「边缘尺」（次要维度，造起伏）。
   > 合格线：主尺能数出来（根骨/学历/身份/资质）；有没有边缘尺，决定下面走哪条分支。

3. **起伏评判** —— 用尺量主角、量出「不够格」。四条分支按剧情选一（可混用）：

   > **A · 先扬后抑**：边缘维度亮色 → 态度升温 → 主尺露底 → 态度转冷。选它当主角有「看着唬人、实则虚」的外在（认识某人／有名头／行头好）；痛在「热情被抽掉」。如「听说认识周董 → 热络斟酒 → 不熟 → 转头看手机」。

   > **B · 整体可惜**：多方平庸，独有一处亮点，可惜核心维度仍差一截。选它当主角有真本事，却不被这套标尺认可；痛在「可惜了」的惋惜，比全盘否定更诛心。如「剑使得漂亮，但丹田无一丝真气，终究入门无望」。

   > **C · 直接判死**：主尺一次量完，核心维度就死，不给甜头。选它当上位者强势、要快、一巴掌拍死；痛在干脆利落的轻视。如「一身贫民旧衣，还没开口，牧师眼里的鄙夷已定」。

   > **D · 多轮起伏**：升 → 跌 → 升 → 跌，层层加码。选它当关系场人多、要拉长蓄压；痛在反复给希望又掐灭。如「聊家世（尚可）→ 问成绩（不行）→ 提兴趣（有亮点）→ 究核心（彻底无望）」。

   > 合格线：无论走哪支，落点都必须停在「抑」（不够格）；落差越大越扎心。

4. **态度定调** —— 由起伏的落点定调：总体「可惜 / 不济」。
   > 合格线：先热后冷比一路冷更有力——热情被抽掉的那一下，才是痛感。

5. **主角淡然** —— 主角不辩解、不反击，靠真实底牌撑住。
   > 合格线：用「不亢不卑」的反差让读者暗爽（读者知底牌，评者不知）。

6. **下定论** —— 评价者心里/嘴上给「配不上 · 不够格」盖章。
   > 合格线：落一句定论，为后续反转留靶子。
