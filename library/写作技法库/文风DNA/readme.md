# 文风DNA · 内容目录

> 定位：文风DNA = 赛道的"笔触形态层"（怎么写），与内容风味层（写什么词）并列。回答"句子怎么写"。采源：优秀作品笔触蒸馏 + 权威写作教程 + 单书实际采样档案。
> 入库约束唯一来自上级 `../readme.md`（对齐 `library/readme.md` 总速查表）；底层槽位规范见本目录 `文风DNA槽位协议.md`。本文件不重复铺开，只做本目录导航。

## 内容清单
- `文风DNA槽位协议.md` — 本子库约束唯一真源：定义文风DNA/ 归属、三段式产出、三层结构、write 消费协议（含5章滑窗去重）。
- `如何克服华丽AI感提升文笔.md` — 去"华丽 AI 感"改稿指南：删替人物宣布情绪/替读者总结感受的句子。
- `如何写华丽有个人风格的文章.md` — 从"堆词藻"练成"有辨识度个人风格"的句法与取景习惯。
- `提升文笔_全网最实用的教程.md` — 逐句可执行的文笔实操：把含糊感受改成准确证据、结论变动作。
- `女频/` — 女频实际文风采样档案子目录（`宠宠欲动-禾早`、`盛世烟火-夜凰`），详见 `女频/readme.md`。
