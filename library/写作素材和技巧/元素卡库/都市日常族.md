# 都市日常族·组装卡（v3）

> v3（2026-08-21）：按「元素卡=组装卡」标准重构——节拍序列为主体（每拍=拍义+填法标准），槽位表解散，源书降为溯源行。
> 来源：R5跨书扩块——《重生之都市修仙》ch002-005，4个都市日常实例（看房/城市生态/饭局/采购）。西幻书（深渊主宰/遮天）无此族，承担"重生落地感"功能。
> 定位：现代生活质感块——把主角从"超凡身份"拉回"人间烟火"，日常是暖源+参照系+伏笔接口。

## 用法（三步）

1. **选卡**：按情境表对号入座；日常块是呼吸调节位，穿插在修炼/战斗/打脸之间
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准现编

## 卡1【看房安顿卡】

**适用**：安顿住处——长辈/中介带看房，主角落地新环境，亲情暖线+报答承诺。

**节拍序列**（6拍）：
1. **看房引路** — 长辈/中介带看：介绍房源，诚意可见（谁带看=谁在照顾主角）
2. **环境铺陈** — 小区生态：位置/环境/配套，落地感（离学校十分钟/靠湖/绿化好）
3. **设施清点** — 屋内配置：家具/家电，具体到物件（空调/热水/浴缸/电视）
4. **感激前情** — 主角的感恩：回忆对方的好，报答心起（对方前世/此前如何待他）
5. **承诺落账** — 报答承诺：以后要回报，一句定调（不煽情，落一句心里话）
6. **对方认可** — 对方心中评价：主角印象分上升（对比参照系，埋蓄压或暖线）

**写法要点**：设施清点必须具体到物件（数得出名字）；感激前情是暖源核心，承诺是感情线落账；对方认可常带参照对比（"比李易晨放心"），是打脸蓄压的暗线接口。
**线效果**：亲情线↑（报答承诺）｜打脸蓄压线（对方对比参照）｜档案线+（新环境生态）
**源书**：都市修仙ch002看房（湖畔小区）

## 卡2【城市生态卡】

**适用**：城市生态/阶层落差——借车行/闲谈倾倒房价/消费/财富格局，主角的云淡风轻与凡俗价值观碰撞。

**节拍序列**（5拍）：
1. **路过地标** — 车行途中扫到地标：别墅区/商圈，引出话题（自然地标触发）
2. **价格铺陈** — 房价/消费生态：具体数字，阶层落差（7000一平/几千万一栋）
3. **财富参照** — 顶级存在：首富/豪宅，天花板立起（给城市定一个财富上限）
4. **主角豪言** — 主角的云淡风轻：送别墅/买下，反差（对修仙者不算什么）
5. **旁观反应** — 对方反应：羡慕/怀疑/轻视，反差入账（反应决定落哪条线）

**写法要点**：价格必须具体（数字是阶层落差的语言）；主角豪言必须云淡风轻（认真说反而掉价）；旁观反应是双落点——羡慕走暖线、怀疑走蓄压线。
**线效果**：档案线+（城市生态）｜打脸蓄压线（"吹牛"轻视）｜亲情线（养老愿景）
**源书**：都市修仙ch003龙景（云雾山/龙景花园）

## 卡3【家庭饭局卡】

**适用**：家庭聚餐——饭桌日常收束前场，倾倒家庭关系背景，长辈安排推动下一步。

**节拍序列**（5拍）：
1. **饭桌开场** — 家庭聚餐：规矩/氛围，日常质感（食不言寝不语/家常菜）
2. **主角回味** — 主角的内心：家乡味/人情味，暖意（久违的味道，心里一暖）
3. **前情补叙** — 借饭桌倾倒背景：人物关系/前史（借菜/借人自然引出）
4. **长辈安排** — 饭桌上的安排：逛街/采购，推动下一步（饭桌是行动的发令台）
5. **暗流伏笔** — 表面平静下的计划：打发/试探，埋钩（有人心里打着算盘）

**写法要点**：饭桌是家庭关系的微缩舞台（规矩/话题/安排三件套）；前情补叙要自然（借一道菜/一个人引出，不能硬插）；暗流伏笔是饭桌的钩子——表面和乐，底下有算盘。
**线效果**：亲情线（长辈照顾）｜打脸蓄压线（打发计划）｜档案线+（家庭背景）
**源书**：都市修仙ch004饭桌（食不言寝不语）

## 卡4【日常采购卡】

**适用**：日常采购/生活切片——主角办自己的事（吃/买/办），城市切片+顺带埋线。

**节拍序列**（5拍）：
1. **日常行动** — 主角的日常：吃/买/办，落地感（狠狠吃一顿/买生活用品）
2. **场景切换** — 多个生活场景：早餐摊/超市/药店，城市切片（一个场景一个细节，快切）
3. **伏笔埋设** — 顺带埋线：订药材/三人组首现，日常中的异常（异常藏在日常里）
4. **电话打断** — 人际联络：邀饭/未问候，亲情落账（电话是亲情线的固定接口）
5. **独处收束** — 主角独处：怨念/思考，转场（收束+转向下一块）

**写法要点**：场景切换要快（每场景一个细节即走）；伏笔埋设要"日常化"——异常藏在采购清单/擦肩而过里，不显刻意；电话打断是亲情线接口，可带小怨念（"妈还不如唐姨亲"）。
**线效果**：亲情线（邀饭/怨念）｜新线伏笔（三人组首现）｜修炼线（订药材）
**源书**：都市修仙ch005采购（早餐摊/超市/中药店）

## 族级硬规则（3条）

1. **纯日常禁用**：日常必带落点（具体物件/承诺/伏笔），只搬运生活的转场交给场景过渡句
2. **日常是暖源+参照系**：亲情暖线（唐姨/母亲）与阶层参照（房价/豪车）是都市日常的双重功能——西幻书没有，承担"重生落地感"
3. **日常必埋线**：日常中的异常（订药材/三人组/打发计划）是新线/蓄压的伏笔接口——日常块是暗线的伪装层
