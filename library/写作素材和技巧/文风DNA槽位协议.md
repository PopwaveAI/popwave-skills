# 文风DNA槽位协议

> **定位**：文风DNA = 赛道的「笔触形态层」（怎么写），与现有 `赛道特色/`（内容风味层：写什么词）**并列**，各司其职，互不混写。
> **铁律**：只学笔触不学内容——笔触DNA不混入名词表/类型门禁，否则 write 学句式时会被内容带偏。

---

## 一、库结构（与赛道特色并列）

每个赛道包内，`文风DNA/` 与 `赛道特色/` 平级：

```
赛道设定集/{赛道名}/
├── 赛道特色/          ← 内容风味层（写什么词·已有）：类型风味基线 / 名词表 / 命名规则
├── 文风DNA/           ← 笔触形态层（怎么写·本协议）：00-库索引与消费协议 + 三层组件池
│   ├── 00-库索引与消费协议.md   ← 库门面：三层结构+存量映射+消费协议+5章滑窗去重
│   ├── 通用笔触基底/           ← 跨书复用句式/感官/叙事距离三段式维度
│   ├── 场景卡分档/             ← 场景公式按事件分量分档（可逻辑挂接现状有件）
│   └── 卷级演变曲线            ← 卷内笔触爬坡脚本（落本项目卷纲，非库文件）
├── 力量与战斗/ …（表层规则层）
└── 使用手册.md         ← 消费映射需补「文风DNA」槽位
```

**交互规则（两级、永不互相吞并）**：
- `文风DNA`（怎么写）与 `赛道特色`（写什么词）**平级并列，物理不融合**——融合会让 write 学句式时被名词内容带偏。两层的唯一挂接点：`赛道特色` 的「类型门禁」可被 `文风DNA` 的反面教材引用，作为内容护栏附注。
- `文风DNA` 只承载**句式/感官/叙事距离/段落呼吸/对话方式**等笔触约束，不承载名词库。

**存量挂接规则**：某赛道若已有内容层文件实为笔触组件（如 `力量与战斗/战斗表现/` 整组的场景卡/面板叙事/多线叙事），逻辑归属 `文风DNA` 的场景卡分档层。为避免下游相对路径引用断裂，默认**物理留原位、库索引登记归属（逻辑挂接）**；仅当引用面小且可安全改指时才物理迁移。

> **库门面 = `00-库索引与消费协议.md`**，固定命名，是本协议的赛道侧落地入口。

## 二、三段式产出（每个维度的唯一格式）

每个笔触维度/场景卡 = 三要素缺一不可：

| 要素 | 作用 | 形式 |
|:--|:--|:--|
| **操作特征** | 条件式指令（何时启用→写什么→写多长→边界） | 可执行动词，禁"营造/巧妙/让读者"评价词 |
| **完整段落** | 段落内技法组合示范（不切碎） | 1-3段真实原文 blockquote |
| **反面教材** | AI味护栏（功能级禁则+病句族+原书替代） | 禁点破后文/数据文学化包裹/情绪直述/能力科普 |

> AB测试实证：碎片化垫底，完整段落+反面教材凭1/7输入超越原文直灌。凡缺任一要素 = 该维度无效。

## 三、库的第三层：防长更重复的「消费侧」机制

> 老板关切：长更中因 DNA 重复渲染导致的正文重复单调。DNA 约束"怎么写"不驱动"写什么"（内容由章纲供给），故**内容重复不会因DNA起**；但**笔触节奏同频**是真风险。三层防线落地如下：

### 防线1 · 卷级笔触演变曲线（在 `文风DNA` 内建一卷级脚本）
- 把战斗画风扩成「卷内演变曲线」：同是战斗，遭遇战用碎段快杀、决死战用长句铺陈，笔触强度按剧情分量爬坡。
- write 每卷开始时读本卷演变曲线，同属战斗、强度不同，天然不同频。

### 防线2 · 场景卡按事件分量分级
- 每张场景卡按事件分量分档：交锋/大战/决死三层密度。
- write 按本章事件分量选档，避免每场战斗都一个密度。

### 防线3 · write 层 5 章滑窗去重
- write 渲染前回看最近5章已启用的笔触特征（相类喻体/独句段重击/数据句式）：高频者本章自动规避，强制换气。
- 实现于 write 消费协议（见下），非 DNA 文件内。

> 落地优先级：防线1 + 防线3 成本低、对长更防重复最直接；防线2 待战斗集多后再补。建议按 1→3→2 次序推进。

---

## 四、write 消费协议（按需采用）

write 渲染一章时，按序读取 `文风DNA/`：

1. **笔触基底**：取本章命中场景卡的三段式笔触（操作特征+完整段落+反面教材）
2. **卷级演变**：读本卷演变曲线，确定本章笔触强度档
3. **场景卡分档**：按本章事件分量选 交锋/大战/决死 档
4. **5章滑窗去重**：回看最近5章已用特征，高频者本章规避

加载优先级：笔触基底=第一优先级（10万字裁剪不裁）。

## 五、门禁

| 检查项 | 标准 | 不合格处理 |
|:--|:--|:--|
| 并列归属 | 文风DNA/ 与 赛道特色/ 平级 | 调整位置 |
| 三段式完整 | 每维度/场景卡含操作特征+完整段落+反面教材 | 补全缺失段 |
| 只学笔触不学内容 | 无名词表/类型门禁内容混入 | 移出到赛道特色 |
| 消费映射 | 使用手册.md 补「文风DNA」槽位 | 补全 |
