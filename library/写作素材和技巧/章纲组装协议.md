# 章纲组装协议 v1.0.0

> 对标《文风DNA槽位协议》：文风DNA管"句子怎么写"（笔触级），本协议管"这一章怎么拼"（章级组装层）。
> 坐标系：卷纲（幕级：这一幕干什么）→ **章纲（章级：这一章怎么拼块接线）** → 正文（笔触级：句子怎么写）。
> 验证：2026-08-22 格式桥接试点（深渊主宰ch008）全链通过，真章纲骨髓8项命中7项。

---

## 1. 章纲格式 v3.1（叙事原子+线织物+plot锚点区）

```
ch{NNN}《{章名}》

章型：{英文枚举ID}·{中文别名}（POV）
剧情梗概：1-2句
章节目的：形象/压力/伏笔三件套

【叙事原子序列】（经，4-6个，按顺序渲染）
叙事原子{N} {名}【{内部微观弧：如 缺-挤-忍}】
  使命：这个原子为什么存在（一句话）
  内部事件串：事件→事件→事件（因果锁死，含要落料）
  出线口：叙事原子结束时各线的状态变化

【线账本】（纬，独立记账）
{线名}（{线型}）：原子1启 → 原子2{状态} → … → 本章末{悬/收}

【plot锚点区】（从白描卡锚点段直拷，🔒同白描卡约束）
- 爽点🔒：{公式类型+落点}
- 章末钩子🔒：{内容}（L{1-5}）
- POV：{主视角；切换注明对象+目的}
- X耦合：{本章X耦合1处}
- 关键数据🔒：{面板数值/登场退场/不可逆事实}
- 出场人物：{本章全部出场角色，按白描卡}
- 本章线动作：{每线本章 转/收/悬 目标}
- 出章面板：{🔒硬锚=白描卡锁定值；可编区间=组装层可自填范围}
```

**plot锚点区是章纲=白描卡超集的保证**：锚点直拷进章纲，write 只读章纲即得全部 plot 锁定信息，不必回读白描卡（白描卡降为 review 回溯件）。

## 3. 拼装五步（Step2.5 执行流）

| 步 | 动作 | 要点 |
|---|---|---|
| 1 | 读下发 | 白描卡3段（前1衔接+本章+后1钩子指向）+ 线入章状态（首章取幕头/状态快照，余章取前章章纲线账本章末态） |
| 2 | 选族 | 按章型配方从元素卡库（`元素卡库/00-索引.md`）选4-6张卡，排出叙事原子序列；参照索引「章内族配方」 |
| 3 | 填槽 | 白描卡事件锚入位（锚长在哪个原子）；锚点区直拷附尾 |
| 4 | 现编 | 锚外自由编（数字/名字/生态/对白），过三道关（见§4） |
| 5 | 记账+门禁 | 线账本逐线达成「本章线动作」目标；过密度门禁（见§5）；章尾原子必产生线翻转 |

## 4. 现编三道关（料=白描卡锚10%+自由现编90%）

1. **一致关**：不与白描卡事实/前情/设定库冲突；情报断言必须带主角获取渠道（怎么知道的）
2. **审美关**：数字>形容词、有因果、能看见、档案配落差、留钩
3. **密度关**：每原子≥15条料，全章≥40条，量化料占比≥1/3

## 5. 密度验收门禁（章纲出口检查）

- [ ] 叙事原子 4-6 个（超6=密度上限，渲染会被料拽跑）
- [ ] 全章料≥40条，量化料≥1/3
- [ ] 白描卡🔒锚100%落位（逐锚核对表）
- [ ] 线账本达成白描卡「本章线动作」
- [ ] 事件串物理闭合（见红线1）
- [ ] 出章面板与后文不撞车（见红线3）

## 6. 四条红线

1. **事件串物理闭合**：因果链每一步物理可执行（谁的手、什么时机、物件从哪来）——"只锁结果不锁时序"=回炉。试点实证：提尸挡弩未交代尸体如何先于破门到手=渲染层被迫补洞。
2. **判定链自然段内联**：系统数值/判定一律自然段呈现（【】内联格式），禁弹窗式/代码块——plot/write 同一口径。
3. **出章面板必锁**：经验/数值增量必须在「出章面板」标🔒硬锚或可编区间——无锁定值=章内可能升级撞车后文（试点实证：11杀×30经验会在章内破500升级）。
4. **事实校验链**：白描卡事实性字段（年龄/等级术语/人名）产卡前必读状态快照；章纲→正文中事实冲突时**以状态快照/前文为准**，创作记录标注——章纲事实错误会原样传染正文（试点实证："12岁"错误传染三处）。

## 7. 输入输出路径

| 项 | 路径 |
|---|---|
| 输入·白描卡 | `卷纲/卷一-幕N-章白描.md`（3段） |
| 输入·元素卡库 | `library/写作素材和技巧/元素卡库/00-索引.md`（按需开族文件） |
| 输入·线入章状态 | 首章：幕头+`产出/状态快照.md`；余章：前一章章纲线账本 |
| 输出·章纲 | `卷纲/章纲/ch{NNN}-章纲.md`（每章一文件） |
| 消费·write | 章纲读3章（前1+本章+后1），read_policy=3-segments |
| 回溯·review | 白描卡+状态快照（章纲不进review对照，review按白描卡审） |

## 8. 阶段适配警示

元素卡库样本集中开局期（ch001-015）。组装**推进期/高潮期**章纲时：勿强套开局强块型（如恐怖五段式在推进期换挡为战斗+谈判+解谜）；中段新功能类（旅途风土/势力格局/备战升级/支线收编/谈判收编）按需现推骨架，勿硬凑进不适配的族卡。详见《赛道设定集/采样范围验证-前段vs中段.md》与《赛道设定集/中段换挡规律对比-西幻vs灵异.md》。
