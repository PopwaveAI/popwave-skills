**全库通用基线**（沿用 `library/readme.md`，以下兜底约束本库适用）：
1. 单件≤15KB，超限拆分；frontmatter 带 read_policy（机器优先）
2. 无源不入库：source_book 必实名（禁匿名），每件内容能指回原文章节
3. 采样留痕：必带"书名+章节范围+件数+缺口"留痕块，无留痕=不合格
4. 命名唯一、主题化；对齐《深渊主宰》重建标准（剧情/角色势力/力量与战斗/世界观/赛道特色/文风DNA 六模块）
5. 源书实名、专名保留（成品层与素材层不同，这里不禁专名）
