# 地理版图 · 《怪诞国度》

> **一句话总纲**：这是一张**"现实表层 + 怪诞里层 + 过渡层 + 星球地基 + 多元宇宙外延"**的五层叠压地图。主角萧恩的成长=地图的扩张——从多恩市一城，到怪诞国度深渊城，到泰拉星球系，到泰拉天宇晶壁系，**地理版图随力量档位严格阶梯化扩张（逐卷）**。

## 一、地理分层（五层地图）

### 1. 现实表层 · 电气时代大都会

现实世界（多恩王国）是第二次工业革命的大都会，凡人秩序与超凡入侵的交界地：

- **多恩市**：现实世界主舞台，数百万人口，东门区/旧城区/码头区/公园区/大学城/凯撒大学/雾山/湿地镇（12万人口）；有轨电车、报纸、公寓楼、左轮手枪、凯撒大学与亚历山大图书馆；多恩地下存172件封印物。
- **达贡（即大衮）**：现实国度最混乱的三不管地带，野生超凡者最多；暮色镇（数万人口破败小城）与环城（近百万人口，内城区贵族/外城区贫民窟）是窃国舞台；五支守护家族（原13支）各怀鬼胎。
- **德勒地区**：黛西故乡，自然道途圣地，永恒森林所在，食物便宜。
- **其他地区**：那不勒地区（汉克老家）、夏伦地区（半身人菜系起源）、号角岛（休假地）、蓝星/第二地球（平行宇宙地球，太阳熄灭实为穿越）。

### 2. 怪诞里层 · 黑暗超凡文明（即冥界）

怪诞国度是"遥远国度/被遗忘的宇宙"，本身即冥界，与现实重叠，吞噬一切死者力量本质：

- **深渊城**（七座巫王城之一，埃蒙→萧恩）：全城皆超凡者、无普通人、无孩童；迷锁【血战】保护，修罗角斗场（死亡率最高）、血之盛宴酒馆、魔法区、高塔六层（魔导士居所）构成"力量即地位"的恶魔之城秩序。
- **残阳城**（七座巫王城之一）：悬空岛、废弃星港，起源太初术士，达贡窃国线的战略支点。
- **地心世界**：鲁克苏子宫（孕育所有旧日胚胎的母体），血肉之柱巢穴（数百万根），深渊巨口（地心吞噬者巢穴，垂直上千米悬崖）。
- **毒气沼泽**：数千平方公里盆地，黑色森林（自然圣居十多万平方公里）净化后成为自然道途圣地。
- **其他地点**：瓦隆尔大裂谷（血肉之柱活动区，地心世界通道）、软泥深坑（神之血坠落）、梦境森林（大德鲁伊树海界域）、印记城、裂魂之地/龙陨荒野、雾岛/亚兰蒂斯古战场、闪电尖峰。

### 3. 过渡层 · 灵界·以太位面·冥界

死者与知识的国度，位面中转站：

- **灵界**：幽魂之地（灵界大城市，活人少死人多）、烛堡（灵界锚点，黑暗山脉之巅，三个入口六尊传奇巨像，封存三大秘卷）、断头谷、迷宫图书馆（赫卡忒神国）。
- **以太位面**：物质位面与内层位面中转点、灰雾源头；萧恩神国机械之心所在（浮空岛浮空城）。
- **冥界**：遗忘之湖/冥河支流/鬼门关、亡者之城（赫卡忒神国）。

### 4. 星球地基 · 泰拉星球系

- **泰拉星球**：原始大陆被旧日之源鲁克苏撕碎裂成七块，四分之一体积消失、保住四分之三。
- **月球**：人造（神圣泰拉盾牌），地核内藏钟表涅槃十二境门钥，萧恩建60米巫师塔+传送法阵。
- **太阳**：火元素位面通道，永恒炽阳（升12环需定居太阳半年）。
- **园星球**：集群类地星体/12卫星/重力1/2/自然侧法术+2，2.6亿公里灵能信号，殖民目标（人口186万/27城/水晶节点奇观/地脉喷涌/元素洪流传说点）。
- **蛮荒天域**：震旦故乡、黎明神战主战场，苏恩陨落之地。

### 5. 多元宇宙外延 · 泰拉天宇与万神殿

- **泰拉天宇**：泰拉星系被切割成的独立晶壁系，封神时代主场。
- **印记城**：万界枢纽，杀戮之子军团等待大门开启之地。
- **天堂山/巴托地狱/机械境/精灵神系**：万神殿诸神系，远征泰拉天宇。
- **时空中枢**：167头时光龙，时空守护者（最低施法等级35），星界漫游者贡献度体系。
