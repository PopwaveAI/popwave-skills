# 规则总账 · 《怪诞国度》

> 这一件是**世界级运行规则**（剧情/人物必须遵守的硬逻辑），与《力量与战斗/力量体系》互为表里——那边讲"力量怎么长"，这边讲"世界怎么转"。所有数值以🔒标注，无证据处标「原文未展开」。

## 一、世界硬规则账本

### 1. 力量规则（晋升天花板与代价）

- **凡人承受上限**：超凡本质极限100刻度=20个职业等级🔒；污染疯狂极限20刻度🔒；每次晋升仪式+5职业刻度上限🔒。
- **职业序列**：24个职业序列（最初仅6个）🔒，分四阶波动等级（第一阶1-5/第二阶6-10/第三阶11-15/第四阶16-20），第五阶为天命领域🔒。
- **施法位阶**：0环戏法→12环法术上限🔒；法术环上限=超凡等级🔒；掌握3环法术=学徒毕业（约5级）🔒；专精法术每施法位阶选一个、极限12个、不可更换🔒。
- **序列=扭曲的概念法则，领域=正常法则**；只有天命传奇才能修正法则；跨序列晋升污染更重；升阶如信号灯引来不可名状。
- **神格等级体系**：神性生物0 / 半神或微弱神力1-5 / 弱等神力6-10 / 中等神力11-15 / 强大神力16-20 / 神上神或伟大存在21+🔒；职业等级40上限🔒。
- **失控=契合世界扭曲法则**：超凡者失控会变异为怪物（鼹鼠-汉斯变兽人、主母变半人半蜘蛛）。

### 2. 死亡规则（怪诞国度的地基）

- **怪诞国度本身即冥界**，与现实重叠，吞噬一切死者力量本质🔒。
- **怪诞国度无轮回**：灵魂粉碎成源质重凝🔒；堕落灵魂可被收割（灵魂法师榨取、死亡天秤称量）。
- **死亡回溯**：死亡序列最强特异能力，预知死亡未来画面，历史上极少数人拥有；萧恩开发为"提前两三分钟的预言法术"（两次触发间隔<20分钟🔒）。
- **不死意志**：活人却拥有亡灵意志；死亡巡礼者"只杀不渡"。
- **死亡道途**：镇压十二条神话道途🔒；死亡半神由黑暗纪元72位降至如今不到30位🔒；冥河摆渡人体系（遗忘之湖/冥河支流/鬼门关）由赫卡忒祭献双神国演化而来🔒。
- **死亡是人类的庇护所**：五芒星徽记铭刻"死亡是我们的选择，死亡是人类最后的庇护所"。

### 3. 知识规则（燃料与污染双刃剑）

- **知识越多消化超凡本质越快**；知识可吞噬遗物转化为法术（仪式分解约3分钟）🔒。
- **知识活化**：活化的知识会说话、有癫狂自我，需"斩我"才能驾驭（萧恩问道时已斩我）。
- **神格=杀死活化的知识**🔒；0号+1号封印物=人造神格🔒。
- **知识暗网**：精神图书馆（上传知识换贡献度，瑞恩860点🔒）是知识等价交换体系；【知识】领域法则（知识/知识反制/知识镇压三大超凡领域）是萧恩登神核心。

### 4. 信仰规则（神格扩张燃料）

- **信仰供神力、神力反哺赐术**；信徒是神格扩张燃料；百万信徒可出牧师🔒。
- **封神三要素**："立德立言立功"🔒；封神仪式=祈祷言+神像祭坛+信仰/传说度积累。
- **天授神权**：泰拉天宇开辟后神系成立，萧恩获知识/艺术神职法则🔒。
- **传说度**：萧恩3 vs 埃蒙真名562🔒；传说度可转化为领导力，炼狱三途径需传说度。
- **神格=神职法则容器**：无神格神职则神性吸了也存不住——"吸收了力量≠拥有承载它的容器"。

### 5. 时间规则（传奇以上法则）

- **时间系法术谱**：时间加速（6环灵能，6秒时间帧，极限12秒、排异间隔约5分钟🔒）→时间倒退（9环灵能，回溯6秒🔒）→时间跳跃/群体时间跳跃（8环，60米范围🔒）→时间复制术（传奇法术，召唤6秒后的自己）→时间长河十五环→时空乱流十六环（黑洞）。
- **时间线收束**：神上神设定下时间线收束、圣者浩劫、重炼地水风火；时空中枢（167头时光龙🔒，时空守护者最低施法等级35🔒）只针对太古憎恨。
- **时光龙**：位面崩塌唯一安全种族；太古时光龙挑战等级91🔒。

### 6. 空间规则（门途径与位面）

- **门途径**：三把门钥（原住民/异界之魂/外乡人）合一=完整门途径=万物归一者部分法则🔒；门途径领域法则=迅捷动作开任意门锁，施法等级视为两倍（80级施法者）🔒。
- **传送术**：极限3000公里（每级200公里）🔒；解析传送道标可精准传送（误差8厘米🔒）。
- **半位面**：创造半位面（8环），初始直径3米、每天生长约3米🔒；萧恩半位面扩至容纳上限6万人🔒。
- **以太位面**：物质位面与内层位面中转点、灰雾源头；现实由真实梦境转化🔒。
- **超凡神力改变空间**：萧恩旧日形态吞噬众门之钥奥提喀斯后掌握。

### 7. 现实×怪诞规则（双世界运行逻辑）

- **现实世界法则有缺陷，无法晋升天命传奇**；天命传奇驻留需对抗"飞升"排斥力🔒——现实是"刷怪模式"的低魔土壤，怪诞国度才是力量主战场。
- **现实由真实梦境转化**🔒；怪诞国度即冥界与现实重叠。
- **双世界结构=力量地图随成长扩张**：现实低魔、怪诞国度高魔；现实世界"刷怪模式"风险（旧日眷族可跨界）。

## 三、规则与剧情咬合（供拆书/二创）

1. **天花板即剧情**：现实无法晋升天命传奇，逼萧恩的传奇之路必须在怪诞国度/深渊城完成——地理扩张=力量扩张的硬逻辑。
2. **双刃剑即冲突**：知识既是燃料也是污染源、信仰既是燃料也是枷锁、死亡既是庇护也是陷阱（死亡道途"养猪"）——每根支柱都自带反转张力。
3. **量化即爽感**：神格等级、挑战等级、神性值、传说度、魂石/第纳尔——数值系统穿凿整个世界运行逻辑，是"游戏宇宙投影"风格的落地。
4. **法则掠夺即成长**：萧恩掠夺雕塑/绘画/知识领域、吸收恶魔法则/气领域——"领域=世界法则"让每次晋升都是世界规则的改写。
