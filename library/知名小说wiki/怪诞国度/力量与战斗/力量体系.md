# 力量体系 · 《怪诞国度》死亡道途与封神之路

> **一句话总纲**：这是一套**"双世界双途径、死亡道途为锚、知识为燃料、封神为终局"**的克苏鲁式综合力量系统。
> 凡人期由"超凡本质+污染"双刻度定生死，超凡期由"序列+领域法则"定上限，封神期由"神格+神职+信仰"定格局。
> 全书主角萧恩（现实世界挂名"调查员-肖恩"，继承深渊大君真名后亦称"埃蒙"）走的是**异界之魂转生 + 死亡道途**双核路线，最终封神为**知识与心灵之神**。

## 〇、三层总结构（先看全貌）

**凡人/超凡者（现实世界·怪诞国度） →（天命之路衔接）→ 天命传奇/半神 →（封神仪式衔接）→ 真神（泰拉天宇封神体系）**

- 上层由下层承载：凡人可吸神性，但**没有神格神职就存不住神力**——"吸收了力量 ≠ 拥有承载它的容器"，这是本赛道最大的升级天花板设计。
- 三层切换有三个质变点：**超凡者觉醒（凡人→超凡）→ 天命传奇（超凡→概念级，可修正法则）→ 封神（半神→真神，天授神权）**。
- 本书主角萧恩的完整登神轨迹（卷名即勋章）：停尸房复活的异界之魂 → 巫师学徒 → 调查员 → 高阶施法者 → 传奇法师 → 知识与心灵道途半神 → **知识与心灵之神（中等神力）**，终局成为第一位沉睡的真神。

## 一、第一层 · 凡人/超凡者（现实世界·怪诞国度）

### 双世界结构（力量的两块土壤）

- **怪诞国度**（遥远国度/被遗忘的宇宙）与**现实世界**（多恩王国/多恩市，电气时代大都会）并存；怪诞国度本身即**冥界**，与现实重叠，吞噬一切死者力量本质。
- 现实世界法则有缺陷，**无法晋升天命传奇**；传奇驻留需对抗"飞升"排斥力——现实是"刷怪模式"的低魔土壤，怪诞国度才是力量主战场。
- 现实国度由**真实梦境转化**；蓝星/第二地球是平行宇宙地球，太阳熄灭实为穿越。

### 超凡者本质（"超凡者都是窃贼"）

- 力量本质被古老存在夺走，超凡者都是**窃贼**，靠仪式偷窃沉睡者的力量；原始魔力是世界反馈的无意识庞大精神体；**魔网仪式**是晋升第一道仪式。
- 超凡者用的是**怪物晋升序列**（1-12环法术上限）；**序列=扭曲的概念法则，领域=正常法则**；只有**天命传奇**才能修正法则。
- 凡人承受上限：**超凡本质极限100刻度=20个职业等级；污染疯狂极限20刻度**；每次晋升仪式+5职业刻度上限。
- 失控=契合世界扭曲法则；跨序列晋升污染更重；升阶如信号灯引来不可名状。

### 施法位阶与序列（第一层的两条轨道）

- **施法位阶**：0环戏法→1环…→12环上限；巫师途径法术环上限=超凡等级；掌握3环法术=学徒毕业（约5级）。
- **专精法术**：每施法位阶选一个，极限12个，不可更换。
- **职业序列**：24个职业序列（最初仅6个），分四阶波动等级：第一阶1-5/第二阶6-10/第三阶11-15/第四阶16-20，第五阶为天命领域。
- **神话道途**：12条（最初五条，异界之魂开启），是"天命之路"的起点，对应钟表涅槃十二境（十二刻度=十二条神话道途，天蝎座=死亡道途）。

## 二、第二层 · 天命传奇/半神

- **天命传奇/天命**：最高位阶，概念级强者，可扭转/修正法则；第三纪元曾有七十二位天命传奇完成钟表涅槃十二境。
- **半神**：死亡道途半神赫卡忒女士（三首六臂、迷宫图书馆主人）是萧恩导师；半神可开辟神国、有神性+神格、无完整神职。
- 天命之路=登神之路：每掌握一个领域=多一道世界法则；领域是神灵下位权柄；访问领域至少3次。
- 现实世界无法晋升天命传奇，故萧恩的传奇之路必须在怪诞国度/深渊城完成。

- **神格等级体系**：神性生物0 / 半神或微弱神力1-5 / 弱等神力6-10 / 中等神力11-15 / 强大神力16-20 / 神上神或伟大存在21+；职业等级40上限。
- **封神三要素**："立德立言立功"；**神格=杀死活化的知识**；0号+1号封印物=人造神格。
- **半神擢升仪式**：半神之躯黑暗仪式解析出不朽者/夺舍/眷族/神孽四特性。
- **泰拉天宇**：死亡化身+至高圣光+阿斯摩蒂尔斯以三份**太初之契**开辟晶壁系，泰拉星系被切割为独立晶壁系"泰拉天宇"，封神时代开启；**天授神权**+主动封神。
- 终局封神榜：萧恩=**知识与心灵之神**（中等神力，神职=知识/心灵，领域=知识/心灵/时间/艺术/奥术等，神国=以太位面机械之心，信徒仅数万）；赫卡忒=**死亡与魔法女神**（中等神力）；帕斯丁=**战争之神**（中等神力接近强大神力）；蛾母=**晨光与变化之神**（中等神力）；苏=**春天与复苏女神**（弱等神力）；艾登=**游历之神**（微弱神力）；尤金=**半兽人之神**（弱等神力）；弥赛亚=**机械之神**（弱等神力）。
- 番外：萧恩成为**第一位沉睡的真神**，沉睡中一人镇压泰拉天宇活化知识；诸神沉睡后凡人夺回"可依靠自身获取超凡力量"的法则，施法者失控几率降至当年十分之一。

## 五、死亡道途力量体系（主角主修）

死亡道途是全书第一途径，也是萧恩力量体系的锚：

- **道途定位**：死亡道途=天蝎座=钟表涅槃十二境之一；死亡道途高塔/修道院是怪诞国度核心组织；死亡道途**镇压十二条神话道途**。
- **起源**：人类天命们"分食死亡"夺回第一条神话道途，72座死亡半神陵寝升起，最初的钟表涅槃十二境降临；死亡真神被分为70多个死亡半神（黑暗纪元72位→如今不到30位）。
- **死亡序列最强特异能力=死亡回溯**：预知死亡未来画面，历史上极少数人拥有；萧恩将其开发为"提前两三分钟的预言法术"。
- **不死意志**：活人却拥有亡灵意志（萧恩特性）。
- **死亡巡礼者**：只杀不渡、高序列，需第四阶段晋升仪式，现实世界准天花板（杰森-坦格尔、守墓人）。
- **死亡道途半神集团**：首席半神巫妖（任命萧恩为高阶调查员）、赫卡忒女士、古墓王（堕落半神）、至古者、幽影王等；保守派曾提"亡灵天灾计划"（六亿人口转化不死军团）。
- **死亡侧神系**：死亡主宰/死亡之主（神上神）、死亡阁下（异界神灵，赐萧恩【杀戮之子】天赋）、死亡天秤（阿努比斯神器）。
- **冥界演化**：赫卡忒祭献双神国化作幽冥，演化出遗忘之湖、冥河支流、鬼门关，冥河摆渡人体系诞生（汉克-布伦德成为支流摆渡人）。

> **萧恩为何避开死亡道途主线**：赫卡忒早有点醒萧恩避开死亡道途（"养猪陷阱"），萧恩改走【知识】领域避开巫妖化——死亡道途是他的"根"，知识才是他的"路"。

## 六、双途径金手指（异界之魂+死亡道途）

萧恩的力量本质是**异界之魂转生者 + 死亡道途**双核咬合：

- **异界之魂**：萧恩在停尸房死而复生（第168号实验体），骷髅导师称其为"异界之魂"；异界之魂是穿越者/外乡人，主导终结黑暗纪元。
- **死亡回溯**：死亡序列最强特异能力，预知死亡未来画面；萧恩触发多次，冷却极短（两次间隔<20分钟），可当预言法术用。
- **不死意志**：活人拥有亡灵意志。
- **不死囊肿**：萧恩被埃蒙掏心后因体内"不死囊肿"（腐囊母体不死之力、《死灵之书》力量）复活，发现自己自始是"活死人"、是半神巫妖的预定晋升材料。
- **憎恨污泥重塑心脏**：活死人获超强生命力/体质/再生。
- **天赋来源**：赫卡忒揭示萧恩的天赋（灵感+死亡回溯）是"无名之辈的馈赠"；"你身上有他们的馈赠"。

> **合成机制**：异界之魂提供"现代人知识+知识消化加速+过目不忘"，死亡道途提供"预知死亡+不死之身+亡灵意志"——一个管"去哪"，一个管"能不能活"，这是萧恩"又苟又凶"气质的数值地基。
