# 卷七 · 后期集大成·太上（ch1401-1549）

> 卷六末的苏午刚证阳神法性永驻此岸第一峰、推开"空无之天"的上界之门。而这一卷，他把"收束"两个字写到全书尽头——一头扎进原天最大碎片里收摄张五郎、鉴真两位旧友的残缺性意，凭五脏庙硬把死期吞延到七十年后；回到大唐，把生人甲从第一宗霜炼甲一路建成函鬼五等、镇诡局、玄门公署的"天下无诡"工业；在潼华山借雕圣画圣的"人意取代天意"杀鬼佛，又坠入想尔织造的商周因果世界，登极天帝、弑讲尔、证神上完人；最后布"仙芝诱仙"之局夺仙道五相，逆元河破黑棺椁、过"父母之爱"情关而宁择有情，终证**太上（忘情道）**——烹大天、三清尸解、开辟新天，一夜之间落回师父家的婚宴团圆。**苍天已死，新天当立；苏午亲手把"世界凭什么吃人"这道题答完，把答案写成了新的天。**（ch1544 ch1549）

## 一、这一卷讲了一个什么故事

卷七是全书"后期集大成"的收尾卷，也是一头一尾都在"开新天、回人间"的大结局卷。它用四条线把"苏午如何从神上完人走成造物之主"讲透：

1. **空无之天·收摄旧友线**：他二度踏入原天最大碎片，识破其真相、收摄缠绕天根的**张五郎**与**鉴真**残缺性意，黄天敕封鉴真为**金刚执王**；又凭五脏祭庙吞吃渡河催逼之声，把死期由一日硬延到**七十年后**。这条线既铺下"黄天道"正式接引佛门（鉴真成了黄天第一个佛门弟子），也为全书最重的一段牺牲预埋了伏笔。
2. **大唐镇诡·生人甲工业线**：回长安，从吴道子画出第一宗**霜炼甲**、十二幅入墨图、再到无上入墨图《八十八神仙卷》（八十七尊摹画神灵+玄变之仙），黄天法旨收摄画中"玄变之仙"，神工局据此建起**函鬼五等**造甲体系、新设**镇诡局**；他开五狱镇诡、组五支镇诡队，一路因"社稷神器"触怒玄宗，正面碾灭三清之魂投影、化背阴大帝斩五德神龙，剑履上殿逼玄宗低头，最终掌天下法脉为**玄门都领袖**——这是苏午留给人道的镇诡之基。
3. **当代变局·做局收敌线**：现实线的核心是一次"逆天做局"——他定以**陶祖五年寿尽之死**为饵，引想尔/鲁母/鬼佛/三清入局，分派**丹加**寻天后武后、**鉴真**赴华山西天世界对鬼佛、**鼎灵**以有无形道法牵制三清之足，自己登闾山收"后土血脉·闾山神谱"为劫材渡死劫。潼华山上，杨惠之与吴道玄这对师兄弟以"人意取代天意"逼鬼佛降临，杀生石复生众生啃食之，而**鉴真**以完整神韵融化解体、化飞灰牺牲——这条线把全书数条卷级收束线（天后/丹加/鬼佛/想尔/三清）绞到了一处。
4. **证道终极·造物新天线**：坠入想尔以商末织造的"世界陷阱"因果世界，他以**午王**登极天帝、摄回天道轮、习文王易道识破"群诡分食五脏"之局；与帝辛结盟诛妲己（王传贞）、承故始之血重铸元根、登**神上完人**瞬杀想尔并经元河，弑师赤龙唤回诸我；最终布"仙芝诱仙"弑仙夺仙道五相、逆元河破黑棺椁、过"父母之爱"情关宁择有情，**终证太上（忘情道）**，烹大天与元皇合体、三清尸解，开辟新天，落回师父家婚宴团圆。

一句话：**卷七是苏午从"杀死想尔、破世界陷阱"一路顶到"证太上、开新天"的终极一跃，也是全书所有旧友、旧恨、旧诺集中在最后一卷兑现收摊的大结局。**

## 三、支线串联

- **黄天道·佛门接引线**：从收摄鉴真性意、敕封金刚执王，到神秀/慧能/慧可坐镇华山五狱为狱神、慧沼守雷神洞——"黄天道"正式成了可以接引佛门的全新阵营（ch1402-1404/1420）。
- **想尔暗线（借假炼真）**：想尔以太上老君八十一化相凑本尊拼图，自现世裹挟出"二十四名山"入唐时（旅游大巴/失性灵肉身即现代意象之化）；选中安禄山炼"真正生人甲"、于二十四山造甲，二十载后背投幽州张节度（ch1452-1456/1522）。这条线最终在"商末世界陷阱"里摊平，想尔被杀、残存因果藏于安禄山，又在开元末被苏午扫除。
- **"仙"之谜暗线**：从大青骡劫身通"仙门牌坊"、血玉灵芝足印活转，到番外"玄蛇闽江大帝"淫祀——"仙"可能真实存在而非指代，最终由"唯一仙·地仙"（大天血液+元皇脑髓结合）坐实，被"仙芝诱仙"之局击杀（ch1452/1523-1539/番外1）。
- **灶班重逢·寻珠儿线**：苏午以玄黄薪火望见"人初大灶"烟气，欲借此近燧皇寻**珠儿**；青苗/秀秀/李虎自诡胃脱出，灶班于大唐开元盛世重逢（ch1453）。珠儿真灵寄燧皇，是全书情感的一条暖线，最终团圆收进婚宴。
- **旧人因果线（柳飞烟/李黑虎）**：想尔以"旧之生人甲"循环因果抹除旧人踪迹，柳飞烟隐于二十四名山、李黑虎成梁上想尔载体；苏午故始祭目三目重瞳锁定旧之生人甲因果（ch1460/1474），被抹除的旧人身在商周世界被"我名为午"接连唤回（ch1517-1519）。

## 四、伏笔埋设与回收

**本卷埋下（→通下卷/预留）**：
- **空无之天三位一体尸群核心**及"苦海之水何以为苦"之根因（ch1402）——切向全书"天=最大诡"的总题。
- **想尔紫籍天官封押山狱**（ch1404）、**鉴真鬼佛见闻**（ch1420、无间地狱相）、**吴道子日后更巅峰的《地狱变相图》**（ch1424）——均在本卷潼华山线回收兑现。
- **天后武后"五十年之期·武后掌纹"**（ch1450）——指向天后实为"鲁母左眼"的卷级大伏笔（ch1467-68回收）。
- **元河尽头黑棺椁**（ch1525起随祭祀勾召）——全书终极试炼场，ch1544揭棺内实为大天。
- **"只能有一个成仙"**（ch1539仙遗言）——ch1548应于众生尽得杀诡之能与太上唯一。
- **燧皇献祭故始人庙、人初大灶**（ch1516/1520）、**女娲补全伏羲尸骸之约**、**李岳山尸骸"转死为生"**（ch1524）——收进开新天与新世界秩序。

**本卷回收（←上卷/本卷内）**：
- **渡河之期**（卷六锁死一天）→凭吞吃渡河催逼之声硬延至**七十年后**（ch1402）。
- **想尔大天尊**＝想尔残存因果（ch1515）→藏于安禄山，开元末被扫除（ch1522）。
- **性命圭旨**＝三清后门、**三清法剑掩于桃花源**（陈法）→弑师赤龙之战收回（ch1517）。
- **金母心旌/天之五厉/诡皮**→化方天画戟作夺药支点、西王母本形＝脑仁（ch1523-1525）。
- **燧皇/薪火＝此岸根源**（ch1516/1520）→新天同盟、拒新天宙气的孤高。
- **华胥氏之谜**→"华胥氏并不存在"，系伏羲女娲塑造的共同母亲（ch1526）。
- **鉴真身影**（潼华山化飞灰"牺牲"）→ch1476陶祖判定灯盏不灭不盛、鉴真并未真死；ch1516于元河以鬼佛骸骨铸十二品黑玉莲台成彼岸。

**明确未展开（标持留）**：空无之天中央"三具叠合一"尸身真身、创演"仙道"的那位未知存在、故始人庙现址与被遮史学全史、元河是否被彻底浇干、柳飞烟藏于二十四名山的全貌、妲己/皇母/女娲/"唯一仙"是否同源、苏午父母（苏铨郑春芳）情关后生还去向、新世界"不正常人"之规模。

## 卷末钩子与追读点（全书大结局·所有终局如何收束）

本卷为全书大结局，不作连载钩子，记**每一条终局的落点**：

1. **想尔线**：真身在商周世界被苏午以"神上完人"瞬杀（第一尊被杀之厉诡），残存因果逃至安禄山，又在开元末被燕山一笔扫除——想尔彻底灭亡（ch1515/1522）。
2. **鬼佛线**：潼华山被人意代天意逼出、杀生石复生众生啃食，法性跌落；苏午渡元河时以永恒真如法性点杀，助鉴真以其骸骨铸十二品黑玉莲台成彼岸（ch1475/1516）。
3. **三清线**：本尊以三清之魂寄姬昌（鸡卵）、雷祖蚀比干布局，终被"我名为午"诸我归一逼退破碎；全书末三清尸解、化四梁八柱支撑人道宗庙，尊苏午为"师父"（ch1517-20/1547-49）。
4. **大天线**：累卵天地廷议拒鸿蒙金座、黑棺椁内设"父母之爱"情关反自陷情关，最终被证"太上"的苏午以铁钎钉住、投入故始青黑大鼎烹为**新天飨食**（ch1527/1545-49）。
5. **旧友团圆线**：师父家婚宴，陶祖/洪仁坤/李岳山/云霓裳/珠儿/赤龙/柳飞烟/江莺莺/丹加一一登场——全书以"人间烟火"收束（ch1549）。
6. **新世界线（番外1）**：诡异调查局与民宗局合流，苏先生（苏午）摄政、铲除淫祀"玄蛇闽江大帝"（闾山旧号之衍），人间无厉诡、超凡日盛——**封闭式圆满大结局**，作者已预告新书《有诡》。
