# 危机与敌人 · 《深渊主宰》

> **危机法则**：悬在主角头上的刀随时量级升格——**危机范围与主角昇位严格对应**，从"一城邪教案"到"诸神坠凡/位面大战"，越是末尾，世界级绞肉台越呼之欲出。

## 一、全书总危机：圣者浩劫（时间引擎）

- **本质**：混沌之海能量风暴爆发，诸神神位面屏障破裂、神力清零，被迫坠凡为**圣者**（失去神力庇护的猎物）——浩劫前的"保护层"塌成"猎杀场"。
- **多波冲击**：魔鬼军团 → 元素动乱 → 亡灵天灾；地狱之主亲自压阵最后一波；位面屏障破裂使低位阶魔物跨位面涌入凡间。
- **坠落链条**：魔法女神（首坠引魔网崩溃）→ 银月女士 → 强大神力主神 → 波及各神系。
- **主角变量**：索伦救下魔法女神使魔网未崩——**改写原史，把灭城之灾收窄为阵地战**，但浩劫本身仍在倒计时。

## 四、危机设计通则（供拆书/二创）

1. **倒计时不落地**：危机量级随卷升格，但"末日"始终悬而未坠——给成长提供紧迫、不给安全坪。
2. **威胁=神格来源**：每个阶段BOSS都是索伦下一级神性的来源，危机设计与昇位严格勾连。
3. **人性化大敌**：恐惧魔神以"母亲之魂威胁"、阿斯摩蒂尔斯被视作"命运之子"，让世界级危机带欲望与算计，而非单纯数值压顶。
4. **多波推进**：魔鬼→元素→亡灵三波递进制造"一波方平一波又起"的长效紧张。
