# 地理版图 · 《深渊主宰》

> **地理法则**：地图随力量档位严格扩张——主角从贫民窟→琥珀城→白马城→北地→海外→跨位面→神国，**地理范围与主角昇位严格同步**。这是"升级必需开拓新猎场"的绝对值映。

## 一、主战场 · 物质位面五大地域

### 1. 南方大陆（人类文明主舞台）
- **琥珀城**：玛瑙河畔六百年古都，遭八名传奇恐怖骑士屠城（唯神殿区神力护持幸存）——全书开篇灭城之劫。
- **白马城**：西南贸易重镇、市政悬红龙头骨，是索伦前期成长与猎怪的主场。
- **枯叶镇/落叶城**：半精灵领地、德鲁伊议会所在，缩影生态失衡的棋子。

### 2. 南海岸 / 海外群岛（索伦海上帝国）
- 沉没古陆改成的热带岛链；索伦在此建立海上王国，**摩多城为中枢**。
- 黑锚港式法外海岸（税吏看刀/行会/悬赏墙——丛林版秩序）是"割喉者→斩首者"的立名场。

### 3. 冰雪国度 · 阿伦戴尔
- 冰雪女神后裔、女性主导的富庶王国；王室「双明珠」长公主与安娜；天命术士/冰雪化身的主场。

### 4. 东方国度 / 死亡沙漠
- 奥术帝国陨落核心、死魔区与废弃遗迹遍布；城邦制、修道院为强势力量。
- 东方神系与独特职业（东方舞姬/浪人/苦行僧/方士）——蒂（拳法大师）等东方武学来源。

### 5. 幽暗地域（地底世界）
- 卓尔、灰矮人、夺心魔、吉斯洋基人混居；蜘蛛森林为地表精灵的战争前线；蜘蛛神后·萝丝的扩张底色。

## 二、下层位面 · 深渊与地狱

### 无底深渊
- 已知逾六百层，各层恶魔领主割据（魅魔女王、豺狼人之王耶诺古、牛头人之王、亡灵君主、眼魔大主母）。
- **万渊平原**为最顶端、**血战**（守序魔鬼 vs 混乱恶魔的位面战争）是恶魔的上升通道。

### 巴托地狱
- 由九狱之主阿斯摩蒂尔斯**切割深渊而成**，魔鬼大本营、终局大反派策源地。

## 三、跨位面战场（中后期地图拓展）

- **阴影位面/灵界/冥河**：灵魂与死亡规则的主场，位面穿梭的中转层（终局死亡之主重划冥河即在此域）。
- **星界之海**：神国漂浮、陨落古神尸体、半位面与浮空堡垒——跨位面远征/神国经营的中转层。
- **印记城**：多元宇宙传送门枢纽，痛苦女士绝对统治、禁神进入，奥术遗民避难所。
- **魔渊地狱·蜘蛛神后神国**：深渊蛛后位面战的终局战场。
