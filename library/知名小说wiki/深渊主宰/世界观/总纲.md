# 世界观总纲 · 《深渊主宰》

> **一句话总纲**：这是一个《诸神之战》游戏宇宙投影为真实世界的 DND 式西幻——职业属性、角色面板、法术位、经验条与进阶全部体系化，主角凭前世游戏记忆获得预知优势；而悬在这套世界头上的，是一场叫「圣者浩劫」的全书级倒计时。

## 一、世界总架构（双层搭台）

世界按「垂直竖琴 + 水平星界」双层搭建：

- **主舞台·物质位面**：人类繁荣大陆与群岛海国交战之地，凡间势力与信仰角力的舞台。
- **垂直位面链**：物质位面 → 阴影位面（过渡的半物质投影层）→ 灵界（灵魂能量层）→ 冥界（冥河与死神之地）→ 灰色荒野 → 外层（巴托地狱/无底深渊/焦炎地狱）→ 混沌之海。
- **水平星界之海**：几近无限的虚空，漂浮无数神国、陨落古神尸体、浮空堡垒与半位面——诸神放逐地与强者穿梭的中转层。
- **多元宇宙枢纽·印记城**：无数位面传送门交汇处，由痛苦女士绝对统治、拒绝任何神灵进入，是多线剧情与奥术遗民避难所。

## 二、时代与大事线（时间引擎）

全书时间轴由一条主线引擎驱动——**诸神黄昏 / 圣者浩劫**：

- **历史序绳**：黄金序章「英雄时代」→ 诸神黄昏（万神殿陨落三分之一）→ 圣者浩劫（诸神失去神力、坠落凡间化圣者形态）→ 凡人时代。
- **圣者浩劫缘起**：混沌之海的能量风暴爆发，席卷诸神国度，神位面屏障破裂、神力清零，神灵被迫降临凡间。
- **坠落分层推进**：魔法女神（第一个被动坠落，引魔网崩溃）→ 银月女士 → 大批强大神力主神（光辉之主等）→ 波及各神系。
- **多波冲击**：魔鬼军团 → 元素动乱 → 亡灵天灾；地狱之主亲自压阵最后一波；位面屏障破裂，低位阶魔物可跨位面涌入凡间。
- **历史底色**：两大旧文明遗产——**奥术帝国**（浮空城/魔像/魔能科技/塔灵，曾打碎大陆架的顶级魔法文明）与**瑟银时代**（凡人弑杀第一代魔法女神、以文明覆灭为代价，史称「卡萨斯封神术」事件）。
- **主角改写历史**：索伦救下本应坠落的魔法女神，令魔网未崩溃、施法势力战力完整，将原史灭城之灾收窄为阵地战——**全书宏大叙事因此变成"已知未来被一手推翻"的双线博弈**。

## 三、世界设计八原则

1. **游戏宇宙投影**——系统化数值（面板/经验/专长/神格）穿凿整个世界的运行逻辑。
2. **旧文明遗产争夺**——奥术帝国/瑟银时代遗粹（浮空城/魔像/迷锁/魔能科技）充当全书器物与冲突源。
3. **登神硬规则**——神性+神格+神职+祈祷言+传说度的不可绕过的成神门槛。
4. **信仰-神力闭环**——信仰力供给神明、神力反哺赐术，神职是循环关键。
5. **血战上升通道**——杀人取神性、以战赋神，世界在高位均衡中螺旋上升。
6. **位面垂直竖琴**——物质-阴影-灵界-冥界-外层的垂直结构支撑角色穿越的冒险纵深。
7. **圣者浩劫为时间引擎**——多波冲击驱动全书大事节拍。
8. **秩序对欲望**——摩多城（守序建设）与深渊（混乱欲望）的地理对峙，正是主角"秩序要更强"立意的落点。
