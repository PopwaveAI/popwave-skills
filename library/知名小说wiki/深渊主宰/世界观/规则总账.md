# 规则总账 · 《深渊主宰》

> 这一件是**世界级运行规则**（剧情/人物必须遵守的硬逻辑），与《力量与战斗/力量体系》互为表里——那边讲"力量怎么长"，这边讲"世界怎么转"。

## 一、登神硬规则（成神门槛不可绕过）

- **三件套达标**：真神须**神性 + 神格 + 神职**三达标；无容器（神格神职）则神性吸了也存不住。
- **祈祷言必精确**：必须精确诵读，错字引神罚。
- **传说度前置**：声望（有观众/传播决定，非敌人强度）是封神门槛，正常标准≥200。
- **封神仪式**：祈祷言+神像祭坛+信仰/传说度积累；"藏"（隐秘杀）反噬大、"显"（扬名经营）回报高。
- **神位代价**：信徒不足→神格降级；神职不尽责可能陨落；神位挤压=新等级生存赛。

## 二、魔网 / 神网法则

- **魔网**：无形能量网，助施法者构模、储存法术位；同时**限制施法者能力、防止挑战诸神**。
- **魔网崩溃**：可令施法者群体瘫痪（主角预判此劫，规避了"魔网崩溃淘汰凡人巫师"的大坑——他早一步由记忆法术位转法力值体系）。
- **施法转型**：魔网崩溃后施法者皆转**法力值**（转化公式：巫师=智力+等级、牧师=感知+等级、术士=魅力+等级）。

## 三、灵魂 / 冥河法则

- **灵魂**=纯净能量、属死亡规则；亡灵**违背死亡规则**。
- **堕落灵魂**可转生深渊/地狱；放弃自我者入冥河轮回。
- **凡人死后**记忆几近归零；**狂信徒最可能升圣灵**。
- 主角终局重划冥河、册封冥河摆渡人、定生与死界限「中庸」教义——**冥河规则本身成为死亡之主的权柄**。

## 四、位面法则

- 任何位面可凭**无上力量分割**；下层位面互相吞并侵蚀。
- 位面崩塌唯一安全种族为**时光龙**。
- 垂直位面链（物质-阴影-灵界-冥河-外层）支撑角色穿越的冒险纵深；星界是诸神放逐地与强者穿梭的中转层。

## 五、血战法则（世界的战争引擎）

- **血战**：混乱恶魔 vs 守序魔鬼的位面战争，是**凡物吞噬神性、战而上升的通道**。
- **以战赋神**：全书战略以"以战赋神、克制收束"贯穿，终局一场「水漫三千里」一击即收。
- **化身双线**：本体（位面经营）与恶魔化身（武力屠戮）分权，化身击杀给本体约70%杀戮经验——双线把爽点密度结构性翻倍。

## 六、神性/神格/神职三载体经济（登神终极规则）

- **神性**＝本源/血脉/半能量体，主免疫致命背刺与减伤；可击杀抽取、千年自聚、赐予选民。
- **神力**＝可直接消费的能量储备。
- **神格**＝力量上限之钥，后天凝成最难（"深渊诸恶魔有神性众、有神格者寡"）。
- **闭环**：神职产神力、凝神格、养信徒；冲突则不死不休；信仰供神力、神力反哺赐术。
