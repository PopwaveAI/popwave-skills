# 动力引擎 · 为什么人人都在往神位上爬

> **一句话总纲**：这股逼着所有人往上爬的力，源头是一台叫《圣者浩劫》的绞肉机——**诸神即将失去神格、坠落凡间成猎物**。世界在倒数，所以"抢在末日来临前变成猎人"成了众生无处可逃的唯一出路。
> 配《力量体系.md》看：那边定了"力量怎么长、多高算高"，这边回答"凭什么爬、代价是多少、为什么怪兽总在主角头上悬着一把刀"。

---

## 一、世界总驱动力：圣者浩劫这台绞肉机

- **什么是圣者浩劫**：一个笼罩全书、从卷末裂缝露头的全书级倒计时——诸神将被剥离神格、化作"圣者"坠落凡间，失去神力庇护、沦为可被弑杀的对象。它不是预告片，是**重力场**：把一切成长都装进"赶在浩劫来临前爬到食物链被保护的位置"的紧迫感。
- **驱动放大镜（卷一首落）**：主角索伦亲眼确认"诸神将失去神力坠落凡间"的预言，并见识"极地斯通纳得大爆炸（威力约等于 100 颗原子弹、笼罩上千公里）"与"诸神集体沉默（神术仍在、神谕不回）"两道裂缝——机器已经在空转，齿轮已经开始松动。
- **为什么所有人都被拖着走**：浩劫前的世界，**神是天花板、是保护层**；浩劫一到，天花板塌下来，凡人、半神、老神全部回到同一张"谁强谁活"的牌桌。**"往上爬"不是野心，是被倒计时逼出来的一场生存竞赛。**

## 二、运转机制：猎神、登神、守位三台泵

### 泵一 · 猎神泵（越级成长的燃料机）
- **规则**：击杀神性生物→抽取其神性/传说度/神职→填入自身。**"力量第一本金"的底层逻辑是"谁杀得多、杀得高，谁拿得多"**。
- **代价**：无神格神职则神性"吸了也存不住"——猎神者的终点是登神，孤勇猎神只是半程燃料。
- **书证**：卷一藏宝洞首弑蛇魔得神性/卷二苦行融恐惧神性、卷三首弑神、卷六弑神登顶——猎神泵从卷一起就接入主角成长线。

### 泵二 · 登神泵（真神资格的仪式机）
- **规则**：半神→真神需**封神仪式**（祈祷言+神像祭坛+信仰/传说度积累）；前置标准**传说度≥200**（有观众/传播决定，非敌人强度）。
- **代价**：信徒不足→神格降级；神职不尽责可能陨落；"藏"（隐秘杀强）反噬大、"显"（扬名经营）回报高——**封神的门票是"被多少人信"，不是"杀了多少人"**。
- **书证**：卷四伪神时期被诸神当重点打击对象；卷五破晓封神、神职落地，正式拿到万神殿在席资格。

### 泵三 · 守位泵（登顶后的保温箱）
- **规则**：真神后经营神职/神国/信仰三线，信仰回流供神力、神国随神力扩张；神位不是终点，是**新等级生存赛的开场**。
- **代价**：神位挤压（弱小/新神是强者狩猎目标）、神职冲突不死不休、强大神力之间亦有神系吞并。
- **书证**：卷五-六死亡神系争夺、双子封神、血战救世——登顶之上还有王座之争。

## 三、众生攀登分层（谁在爬、爬到哪、掉在哪）

| 层级 | 身份 | 驱动 | 代价/终点 |
|:--|:--|:--|:--|
| 底层 | 平民/盗贼/民兵 | 活着、换顿饱饭 | 经验指数增长→旧猎场收益衰减 |
| 职业者 | 学徒→一阶→二阶| 冒险者工会登记、刷经验 | 本职5级/血脉纯化/进阶门槛 |
| 高手 | 传奇骨干/军团精锐 | 一城一方倚仗 | 二次进阶（技能值+天赋+传奇专长） |
| 传奇 | 大陆顶尖 | 追求"屠龙/弑神"的话事权 | 传奇进阶仪式+血脉纯化（获传奇生命） |
| 半神 | 有神性无神职 | 神战棋子、诸神"猎物" | 容器限制：吸了也存不住 |
| 伪神 | 凝神职未登真神 | 诸神重点打击对象 | 封神前夜最危险 |
| 真神 | 微弱/弱等/中等 | 神国与神系争霸 | 神职冲突、信仰依赖、王座吞并 |
| 强大 | 神系开创者 | 多元宇宙秩序书写 | 仍要防"王座之下皆可猎" |
| 主宰 | 伟大神力（死亡之主） | 全书终点 | 执掌冥河、站上秩序顶端 |

> 主角索伦的攀登轨迹（卷名即勋章）：**割喉者→斩首者→半神→微弱神力→弱等神力→中等神力→强大神力→死亡之主**。读者透过他看完整条"凡→真→主"的天梯，爽感来自"我又走了一格、而头顶那把刀又近了"。

## 四、代价结构：爬得越快，账单越厚

1. **升级经验指数增长** → 旧猎场收益必衰减 → **强制开拓新位面**（地理随力量版图扩张）。主角从贫民窟→琥珀城→白马城→北地→海外→跨位面→神国，地图和力量严格同步涨。
2. **越强越怕** → 越接近神位，越是诸神与王座的靶子（"猎物"与"猎手"身份反复倒置）。
3. **容器/责任双重枷锁** → 神性无容器存不住；神职有责任、信徒不足降格、不尽责陨落——**高位不是free，是永续的债**。
4. **本体×化身双线代价** → 本体（位面经营）与恶魔化身（武力屠戮）争夺精神与时间，但**化身击杀给本体约70%杀戮经验**——双线把爽点密度结构性翻倍，也把主角的时间账越记越紧。

## 五、引擎与全书的咬合（为什么这套动力不因登顶而失效）

- **倒计时后端**：圣者浩劫真正落地的圣者战役（卷五引爆、卷六落幕）——神坠凡间、血战救世，把"登神竞赛"升级成"诸神/凡人/恶魔三方绞肉"，收束全书主线。
- **爽点放大原理**：六引擎里，**末世倒计时的急迫 + 猎神/登神的即时回报**是最强的两根油门。它让"数值在涨 + 身份在跳 + 有人在死 + 神在颤抖"叠加成立。
- **创作取用**：新书若要复刻这套动力，核心是**先立一台"倒计时绞肉机"（神将坠、浩劫近），再立"猎神—登神—守位"三台泵，最后把地图/危机/敌人生态随力量档位严格阶梯化**——动力引擎一开，读者自然会跟着主角往前冲。
