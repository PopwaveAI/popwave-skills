# 盟友深度卡（情感核心 + 神系中坚）

## 薇薇安（恐惧双子 · 至亲/情感主锚）

| 字段 | 内容 |
|:--|:--|
| 定位 | 主角同母异父妹妹、第二主角、全书情感核心 |
| 阵营 | 正派 |
| 攀登方式类型 | 没资源型→血脉觉醒 |
| 等级坐标 | 8岁孤女→魅力21超凡→【恐惧】中等神力 |

- **身份与天赋**：天生术士，超感知极高（魅力突出、感知能判吉凶、对诸神天生排斥）；"天赋比索伦还强"；一朝苏醒即自念"光亮术"。
- **成长弧**：从被守护的孤儿→天赋展开→收复恐惧教会/收编蛇人信众→在恐惧王座直面恐惧魔神本体。
- **恐惧双子**：命运改写关键役——放过另一恐惧神子（原轨迹当死于彼方），挣脱既定语境；一具躯体承载本体与莉莉安（被银月女士杀死的恐惧魔女残魂）两个一模一样人格，姐妹同登神位。
- **情感功能**：索伦一切行为最大的"为什么"；"再也没有人可以把我们分开"收束情感母题。
- **终局**：恐惧魔神陨落中获【恐惧】神职，与莉莉安【纷争】双子封中等神力；收缴恐惧教会（信徒流失约六成）。

## 歌莉娅（女主/正宫 · 北地女巫→法师神）

| 字段 | 内容 |
|:--|:--|
| 定位 | 女主/正宫；前期授业者→后期施法体系主持者 |
| 阵营 | 正派（守序正直·观察应变） |
| 攀登方式类型 | 有资源型（女巫传承） |
| 等级坐标 | 准传奇女巫→摩多城女主人→【预言】【法师】新神 |

- **身份**：北地女巫出身、精灵学院派战斗法师，能施高阶环位法术与超魔；女巫议会高阶成员。
- **功能**：前期领路人与授业者（规劝索伦）、后期主持摩多城浮空塔/迷锁/魔像研究；曾占卜出薇薇安"血与火"预言。
- **情感线**：对索伦有意（"最近总会想起他"）-隐微克制的长者式陪伴，慢炖式正宫。
- **终局**：吸收萨弗拉斯权杖与巫妖之神神职后凭【预言】封神；避魔法女神密丝特拉复活分身之坑，等百年后彻底掌握【预言】+【法师】（未夺魔法神职）。

| 字段 | 内容 |
|:--|:--|
| 定位 | 阿伦戴尔二公主→女王；文治线锚 |
| 阵营 | 正派 |
| 攀登方式类型 | 有资源型（第一顺位继承人） |
| 等级坐标 | 无战力少女→女王（直辖五百多万人口） |

- **成长**：娇生养成→坚韧耐苦（学会洗衣做饭、冻裂手不敢示人）；被托付送返后政治成长、成第一顺位继承人。
- **情感线**：城墙直球告白（"索伦！我喜欢你！你敢不敢娶我！"）→被拒仍宣言→与索伦感情介于男女/兄妹，地位仅次于薇薇安与歌莉娅。
- **终局**：加冕阿伦戴尔女王；愿与索伦在一起、愿留一孩子相伴（情感后续「未展开」）。

- **功能**：全书唯一愿与索伦赤膊上阵迎战奥喀斯/奈落的女神（冰雪领域克制其速度）。
- **行为**：对索伦冷待（闻其"恐惧+厄运+杀戮"不安）仍赏两件传奇装备；对安娜宠爱保护。

| 字段 | 内容 |
|:--|:--|

| 等级坐标 | 伴生残魂→【纷争】中等神力 |

- **功能**：战力倒挂的"柔弱躯壳里的炸雷"——觉醒即时间静止+古老恶魔语+恐惧神域+毁灭魔剑秒杀传奇刺客，宣告去杀光恐惧神子。
- **终局**：与薇薇安双子封神，获【纷争】神职。
