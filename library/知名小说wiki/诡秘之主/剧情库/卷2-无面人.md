# 二卷 · 无面人（ch214-482）

> 全书第二卷。部名"无面人"三义：既指主角晋升的序列6魔药，也指他在雾都贝克兰德戴着一张名为"夏洛克·莫里亚蒂"的假面生存，更指这卷里无数在时代大雾中被抹去姓名的普通人。本卷完成四件事——**立下贝克兰德这座公网大棋盘、立下私营侦探的换身份生存范式、立下序列8小丑→序列7魔术师→序列6无面人这段跃迁期爽点、立下"对外死亡、再起新身"的重生母题**。

## 一、这一卷讲了一个什么故事

**一个死过两次的占卜家，从廷根的墓坑里爬出来，换上一张叫"夏洛克·莫里亚蒂"的侦探假脸，闯进一座五百万人口的雾都，用一次次"表演"把自己从序列8喂到序列6，最后在遮蔽整座城市的毒雾里亲手破坏了邪神降临，然后对自己的旧身份说了声再见。**

故事从一座坟开始。绯红的月光下，挖开廷根郊区拉斐尔墓园的墓碑，克莱恩的尸身坐了起来，心脏的伤口在缓缓愈合。他确认了杀他和队长邓恩的凶手是前黑夜大主教因斯·赞格威尔——那个握着能"注定让事件实现"的封印物"0-08"羽毛笔的人。占卜告诉他，变强的希望在贝克兰德，在霍纳奇斯山脉深处的安提哥努斯宝藏。他把母亲留下的铜哨挖了出来，隔着水仙花街远远望了一眼家人住的房子，自己没有敲门。他要替队长复仇，也知道这仇得藏一辈子。

他坐蒸汽列车在4小时后抵达贝克兰德。这里是鲁恩首都，跨塔索克河，常住超过五百万人口，一年有75天坏天气——雾霾之都。他租下乔伍德区明斯克街15号（周租18苏勒），注册职业"私家侦探"，起了个假名"夏洛克·莫里亚蒂"，在《贝克兰德邮报》上登了30镑一个月的小广告。与此同时，他坐镇灰雾之上经营塔罗会：第一次颁布"献祭-赐予"仪式，让倒吊人献祭七彩蜥龙脑垂体，从灰雾之门递给正义——塔罗会的物资体系就此建立；又利用"诵念我名可拉人入局"的规则，把赏金猎人休拉进灰雾。他的第一单生意是替邻居找猫，报酬5苏勒；第二单是帮大男孩伊恩查前雇主泽瑞尔侦探的失踪，循着被啃咬的尸体、一颗被刻意取走的牙齿，摸进贝克兰德的黑帮暗流，夜里还反杀了一名追来的兹曼格党"处刑人"——用"制式合同"化作的钢制飞镖。最后他被迫在警察的审讯席上硬扛了一轮"仲裁人"的精神鞭笞，靠一位律师10镑保释脱身。他散尽游资、掏200金镑积蓄，把根扎进了这座城市。

开局的乱局很快撞进一条大鱼。因蒂斯驻鲁恩大使贝克朗·让·马丹替大使馆追查伊恩手中的一组手稿——这背后牵出弗萨克间谍、军情九处与两国博弈。克莱恩因为"用真名字真脸租房接案"这个失误，把自己的非凡身份暴露给了大使的猎犬。大使在使馆里摆宴自证清白，同时授意助手罗萨戈"顺手干掉那个小侦探"。危机压顶，克莱恩做了两件事：一件是把从黑市黑蛇手里收来的、被"真实造物主"污染的"全黑之眼"炼成"污秽之语"符咒；另一件是委托塔罗会里的"正义"奥黛丽雇佣刺客解决使者——这笔委托落到了极光会"牧羊人"A先生头上，A先生以黑暗骑士之姿一剑劈杀大使。至于罗萨戈，他在明斯克街15号的房间里用木偶线操控克莱恩，被克莱恩反掷"污秽之语"、以五枪爆头当场击杀。这一夜克莱恩从罗萨戈的通灵残灵里，白捡了占卜家途径序列7"魔术师"、序列6"无面人"、序列5"秘偶大师"三份完整配方——这是他被"安排"的起点，也是他往后越走越高的台阶。

他在灰雾上具现了一张假人，取名"世界"，入会塔罗会跟自己演戏。此后他在贝克兰德双线游走：现实里当侦探，超凡里推动塔罗会敛财集料。他识破连环剖腹案的查访，反手帮玛丽太太捉奸（让保镖隐身相机镜头拍下铁证）；他在波特子爵的第四纪古宅里撞见六神人形雕像和血红大门后的恶灵，怂恿莎伦爆破封死了入口。而那些横流的欲望与愚行，在他眼里渐渐拼出一张新时代的恐怖底牌——东区贫民、童工、码头的落魄，都是邪教酝酿"恐慌"的温床。他配齐了两味主材，用一口铁锅熬出"魔术师"魔药，服下后历尽呓语晋升序列7，获得伤害转移、火焰跳跃、纸人替身等九种"魔术"，从此他管自己叫"要做足准备的表演者"。

晋升后的克莱恩一头扎进连环案与邪教徒的漩涡。他为调查"凶手非初犯"的通盘事，通读王国20年外未破的连环命案，向官方递出"动物世界"的提醒，最终官方顺着流浪黑狗揪出并当街处决了恶魔化的巨犬。他替丰收教堂的主教乌特拉夫斯基治疗人格分裂——在"心魇蜡烛"的心灵世界里一记响指空气弹了结了"过去的主教"，换到封印物"万能钥匙"与"药师"配方。他夜潜王国博物馆，在罗塞尔纪念展里偷走一张夹在创意手稿里的书签，用咒语"贝尔纳黛"开启——那竟是"亵渎之牌·黑皇帝"，完整的"律师→黑皇帝"序列0神之途径自此对他展开。他在地下废教堂邂逅一位被图铎野心困了两千年的恶灵，恶灵泄露出"亵渎之牌·红祭司"的存在，也埋下一个要用三族直系后裔的血才能解封的谜。

高光之后是恶战。他应莎伦、马里奇之邀，参与围杀玫瑰学派追来的序列5"怨魂"史蒂夫。西拜朗船坞的地下仓库里，他布下纸人替身、遍地炸药与"灵性囚笼"，与"活尸"杰森、"狼人"泰尔、"怨魂"史蒂夫捉捉场场硬撼——他用"太阳胸针"净化附体，用阿兹克铜哨里头"门先生"的呓语反噬死灵，最后六连发净化弹加一场火药"烟花"，把半神的残躯炸得粉碎。战后他一口气吞下狼人獠牙等战利品，也为此感染感冒养了几天。稍作喘息，他又掉进贝克兰德最凶险的局：连环案的一众侦探突然全员收到恐吓信，朋友中有人当众拔枪——幕后是序列5"欲望使徒"杰森·贝利亚，一个靠操纵情绪播种的恶魔。他们合力追缉，一度让幕后真凶借"正正得负"的双重治疗侥幸脱身，最终克莱恩在下水道灰雾灵体决战里以无声尖啸和圣光连斩将其秒杀，通灵后问出真正的主使——"黄昏隐士会"。

复仇与阴谋的线在卷末一并收束。克莱恩凑齐"无面人"的三份材料（千面狩猎者脑垂体、血液、深海娜迦头发、人皮幽影特性），在明斯克街15号的厨房里熬药服下，身躯腐烂又复原，晋序列6"无面人"——他能改换全身样貌，却从此不断追问"我是谁"这个他给自己下的套。塔利姆·杜蒙特的猝死牵出三王子埃德萨克·奥古斯都的调查委托，而塔利姆的死因被"0级封印物级力量"完全遮蔽——因为真正的幕后，是一张横跨王室、魔女教派、极光会与因斯·赞格威尔的黑网。克莱恩在被"0-08"编排的陨石灭口局里绝处逢生，被阿兹克救入油画世界，又在逃亡中撞破绝望女士与A先生纵"大雾霾"煽动灾祸、掩护"真实造物主"降临的谋划。他冲进祭祀，把"万能钥匙"扔进祭台光层，引动"门先生"的污染诅咒冲垮仪式；站在他一边的白骨信使被A先生捏碎殒命，他自己跳进塔索克河逃生。东区万人在毒雾中倒下，老科勒抱着火腿病死，问"为什么"；被解救的黛西被拖往教堂。最后，一位秀美的黑发女子像抹橡皮擦一样把A先生与绝望女士逐个抹除，朝克莱恩微笑后消失——那个位格高到让人头皮发麻的存在，为这卷的大雾霾画下一个悬而未决的句号。

卷末，克莱恩对外宣布"夏洛克·莫里亚蒂"死亡，与阿兹克重逢，收下封印手套"蠕动的饥饿"，约定出海寻美人鱼。他把骨灰了、给无名者刻碑烧纸，在班森、梅丽莎进城那天，隔着金边眼镜与兄姐擦肩而过。那座他亲手救下的雾都留在身后，他以"格尔曼·斯帕罗"的新脸登上白玛瑙号，一头扎进苏尼亚海的海风里。第二部，完。

**关键事件要点**：墓中复活定仇 → 化名侦探扎根贝克兰德 → 塔罗会"献祭-赐予"体系成立 → 大使案与反杀罗萨戈（白捡三序列配方） → 造"世界"小号 → 晋升序列7魔术师 → 连环案黑狗被官方处决 → 疗愈主教得"万能钥匙" → 盗得"亵渎之牌·黑皇帝" → 西拜朗船坞围杀怨魂史蒂夫 → 卡平别墅救少女封"侠盗黑皇帝" → 斩杀欲望使徒杰森·贝利亚、问出"黄昏隐士会" → 晋升序列6无面人 → 塔利姆之死牵出王室阴谋 → 大雾霾破"真实造物主"降临 → "夏洛克"对外死亡、化名格尔曼·斯帕罗出海。（ch214-482）

## 二、主线推进（卷内发展链条）

1. **墓中复活 → 定仇立身**：确认凶手因斯·赞格威尔（0-08）→ 化名"夏洛克·莫里亚蒂"、租明斯克街15号、立私家侦探业 → 塔罗会"献祭-赐予"体系建成 → 反杀兹曼格党默尔索（ch214-235）。
2. **大使案 → 得谱晋升**：卷入因蒂斯大使贝克朗与弗萨克手稿博弈 → A先生刺杀大使、反杀秘偶大师罗萨戈（通灵白捡3份配方）→ 造"世界"小号 → 铁锅配药晋升序列7魔术师（ch236-296）。
3. **邪教连环案 → 敛财集料**：连环剖腹案查访、"动物练手"线索递官方 → 治癒主教得"万能钥匙"与药师配方 → 吻合"魔术师守则"，吞"亵渎之牌·黑皇帝"（ch304-330）。
4. **围杀异种 → 西拜朗船坞大战**：应莎伦/马里奇之邀围杀序列5怨魂史蒂夫 → 纸人/炸药/净化/烟花全胜（ch331-351）。
5. **卡平别墅 → 侠盗黑皇帝**：黛西失踪案锁定人口贩子卡平 → 净化煤气爆炸剿四非凡者、救少女 → 市井封号"侠盗黑皇帝" → 总结构"魔术师守则五条"（ch372-390）。
6. **追缉欲望使徒 → 锁黄昏隐士会**：连环案侦探集体遭恐吓 → 序列5恶魔杰森·贝利亚 → 下水道灰雾灵体秒杀 → 通灵问出"黄昏隐士会"（ch411-428）。
7. **晋升无面人 → 大雾霾破降临**：集齐材料服"无面人"魔药晋序列6 → 陨石灭口局 → 撞破王室×魔女×极光会×因斯合谋 → "万能钥匙"破"真实造物主"降临仪式（ch451-479）。
8. **对外死亡 → 新身出海**：送别"夏洛克·莫里亚蒂" → 化名"格尔曼·斯帕罗"登白玛瑙号、踏上寻美人鱼与高序列之路（ch480-482）。

> **本卷主角的"成长方式"定型**：魔药扮演（"魔术师守则五条"消化）+ 灰雾金手指（献祭/小号/高位格显圣/自唤自应灵体）+ 敛财集料（塔罗会调度+黑市交易）三管齐下，把"序列跃迁"写成一场场有准备的"表演"。铁三角在本书第一部确立，本卷首次示范"换身份重生"的高频复用范式。

## 五、卷末钩子与追读点

- **"无面人"新身与"我是谁"之问**：晋升后克莱恩自省「我能成为任何人，但你只能是你自己」，新人格"格尔曼·斯帕罗"能否成为另一层自我？（ch454/483/492）
- **占卜家高序列配方在黑夜教会"宁静教堂"**：晋升序列6后，下一步序列5秘偶大师的出路浮出水面——教会圣堂成他觊觎的宝库（ch483）。
- **班西港潜藏三四百年之久的灵异凶源**：黑船上岸即遇无头活尸、飞头与污染主教的连环杀局，"蠕动的饥饿"放牧初见峥嵘（ch506-510）。
- **"死神的钥匙"与阿兹克四皇之战创伤**：阿兹克自称"常常进了棺材又苏醒"，其死神通途身世与那段惨烈记忆何时揭盅？（ch502）
- **愚者尊名被极光会公开悬赏信徒**："真实造物主"的目光已被引向贝克兰德，塔罗会存亡之危悬在下一卷（ch404-405）。
- **"救赎蔷薇"与八位天使之王名录**：阿蒙、乌洛琉斯、梅迪奇（红天使）渐次浮名，白银城壁画里的六邪黑影指向何方？（ch461/466/486）

## 六、这一卷教会读者的事（创作价值）

- **"换身份重生"是最高效的副本刷新器**：夏洛克·莫里亚蒂对外死亡、格尔曼·斯帕罗接棒，让主角以一个"全新的人"进入新地图（贝克兰德→苏尼亚海），旧身份积压的线索与新身份的自由同时兑现——身份既是伪装也是叙事发动机，可反复复用。
- **"扮演"即人设也是成长刻度**：把"无面人"的消化写成一条需血火淬炼的守则（不做无准备的表演、挑战不可能、主动表演、观众喝彩、掌控注意力），能力成长和人物性格（一个总在给自己"做表演"的谨慎侦探）合二为一，爽点不空洞。
- **每一步晋升用"材料搜集"挂满钩子**：序列6无面人的垂体/血液/娜迦头发/人皮幽影分落黑市、血族、塔罗会、遗迹四条线，读者跟着主角一节节攒齐，把"升级"拆成可持续5-10章的追读动力而非一蹴而就。
- **让灾难落在一张张具体的脸上**：大雾霾不写"死了两万人"的统计数字，而写老科勒抱着火腿病死问"为什么"、黛西被拖往教堂——灾难的重量靠一个无名者的骨灰与一块墓志铭承住，"时代大雾中消失的姓名"成为这卷无声的注脚。
