# 第四卷 · 不死者（ch731-942）

> 全书第四卷。克莱恩自拜亚姆玫瑰学派之险脱身后，以「道恩·唐泰斯」的神秘富翁身份重返贝克兰德，自上流社交切入，一层层嵌入政治、慈善与军火的权力网络，同时把"占卜家"途径从序列5「秘偶大师」一路推到序列4「诡法师」的半神门槛前。本卷完成三件事——**立下"权势型新身份"这套中后期主玩法、立下序列5→4的跃迁分水岭、用「丧钟」亲手了结第一卷的心结因斯·赞格威尔，并在登灰云时撞见全书终极谜团的一角（光门与蚕茧）而被"回家"真相击穿**。

## 一、这一卷讲了一个什么故事

**一个反复死去又活过来的"不死者"，终于不再靠逃跑和搅局求生，而是坐在富丽堂皇的宴会厅里，用身份、金钱、戏剧与傀儡，把杀他队长的仇人圈进一场盛大演出，然后在舞台正中央亲手扣动扳机。**

那盏油灯是在一艘驶入罗思德海域东岸的船上点亮的。克莱恩上一卷从拜亚姆"玫瑰学派"的半神围杀里九死一生——他被"橘光"希拉里昂留下遗言点了名、被天使级存在隔空凝望，手上多了一个奴隶般的长期傀儡"血之上将"塞尼奥尔，兜里揣着一份"成为半神才能掩盖灰雾气息"的残酷医嘱。他决定放弃一边逃一边打的浪人打法，掉头回到鲁恩的心脏贝克兰德，换一张脸活。于是他分三层给自己编了一个身份：迪西海湾的神秘富翁、黑夜女神的虔诚信徒、背景经得起推敲的"道恩·唐泰斯"。伯克伦德街160号的花园别墅租下，三张管家简历摆在桌上，礼仪课、哲学课、饮酒账单一单一单堆起来——他一边心虚地数着仆役年薪账目，一边向圣赛缪尔教堂的奉献箱一遍遍投下五十镑。这卷的故事，从一个想要混进教堂、盗取安提哥努斯家族笔记的外乡富翁，开始向上层社交那扇沉重的镀金大门一点点爬去。

**贝克兰德的棋盘一展开，线头就多得数不清。**克莱恩先以社交破局：第一支舞邀了议员千金海柔尔、在冷餐会认全了考伊姆董事会与大气污染委员会的人、把脚踏车公司的股份在几个买家之间抬价又"克制地"收手；他替前值夜者的遗愿在教堂悄悄埋下安魂、把战友龙泽尔的骨灰葬进风暴教会墓园。可黑夜教会的值夜者也不是瞎子——伦纳德·米切尔在挖完他"自己（克莱恩·莫雷蒂）"的空坟之后，几乎立刻怀疑道恩·唐泰斯就是那个本该死去的旧同事。克莱恩靠借力话术周旋，用"复仇共同体"打动这个同样记恨因斯·赞格威尔的人，又借"渎神者阿蒙"的名字吓退了一头窥视的偷盗者半神。与此同时"权杖与刀"也没闲着：他在舞会间隙甩掉尾巴潜入东区，用魔女特莉丝的线索顺藤摸瓜，锁定了贝克兰德大雾霾的幕后黑手之一"斯特福德子爵"；又暗中把极光会神使"X先生"骗进聚会，靠"秘偶大师+怨魂"的无声组合将其团灭，让"旅行家之门"的传送能力落进自己的手。这些看似零散的进账，都是一件大事的原材料——他要潜进圣赛缪尔教堂的查尼斯门。

**而潜进去的结局，是一场他完全没算到的坠落。**他研究内部看守者的轮值、买通仆役、用安眠药麻醉看守，在昏暗的门外看见挂着1-42等封印物的长廊、循着"霍纳奇斯…弗雷格拉…"的呓语锁定了目标书架——可就在他伸手去拿笔记的瞬间，一道"橡皮擦天使"的身影从天而降，把他整个人从世界上"抹"掉。他再睁眼时，被扔进一座神战残留的迷雾小镇：灰雾被屏蔽、灵界的门被锁死，他的底牌一张张失效。"血之上将"塞尼奥尔在瘟疫追杀里被烧成灰尽，他在"绝望魔女"潘娜蒂亚和极光会神使"A先生"的两面夹击里命悬一线，最后靠一个藏在教堂里的垂死天使——密修会首领、第四纪大贵族查拉图——的交易和恶意，挣出一条生路。他在镇心那座古老宫殿里，透过被咒虫遮掩的巨椅，瞥见了椅子底下躺着一张"序列0：愚者"的牌，那一瞬他几乎想起自己引以为傲的灰雾；最终他在查拉图的符号全部指向死路之后，用一个谁都没想到的"黑暗圣徽"图案撬开逃离之门，落进灵界。"蠕动的饥饿"在吞噬了失控天使的残躯后升级成七格放牧的手套，可笔记没到手、傀儡折了大半、人还困在霍纳奇斯山脉附近。逃出生天的一刻，他心里其实很清楚——这条路走不通了，得换一副棋来下。

**于是他不再当贼，改当"老板"。**灰雾上，他宣布"道恩·唐泰斯"不过是他这个"愚者"放出的一个公共马甲；现实中，他顶着这个马甲吞下考伊姆公司3%的股份、把一万五千镑价值的股份捐给黑夜教会建"鲁恩慈善助学基金"、在东拜朗退伍军官俱乐部里接下往西拜朗走私军火的单子。他又在慈善晚宴上隔着人群认出了"正义"奥黛丽·霍尔，两个塔罗会同僚在现实里互相演戏、又彼此心照不宣地并肩办起基金；他以"复仇共同体"拉拢伦纳德，被视作恩师又视作恩师般的阿兹克相助，处理了"蠕动的饥饿"的封印隐患。他要在七月初登上去南大陆的飞空艇——因为一件他压了三年的事，终于要在这里画句号。

**下半卷，舞台搬到南大陆，复仇与地狱在此交汇。**在狂暴海的码头，他隔着风浪瞥见一张脸，全身发凉——因斯·赞格威尔，那个用"0-08"杀了他队长邓恩、毁掉他整个廷根值夜者人生的男人。复仇线一路收紧：路上他收服了会唱都坦语的秘偶"恩佐"、又借阿兹克之手得了七大海盗将军之首"地狱上将"路德维尔当一年秘偶；阿兹克随他进入狂暴海深处的死神宝库，在神秘兜帽女士（克莱恩几乎确信那是黑夜女神）面前割舍半个灵魂、陷入沉睡；他独自闯进"死者之城"卡尔德隆，用"窃运者"符咒对调命运反杀灵界掠夺者，把序列4「诡法师」的主材料稳稳抓在手里。而最致命的一步，来得克制又冰冷——他通过神谕、通灵、和帕列斯的点拨，终于看穿：因斯·赞格威尔根本不是一个人在行动，他体内盘踞着"红天使"梅迪奇的恶灵。

**真正的收束，发生在西拜朗"复活广场"。**克莱恩布下三幕大戏，用"窃运者"符咒把恶灵从因斯身上转移到作为替身的路德维尔身上、合力把其推入冥界，再于灰雾降下"海神权杖"的闪电风暴封锁因斯，最后回到现实——他亲持"丧钟"左轮，一枪一枪地为戴莉、为伦纳德、为梅高欧丝、为看守者、为黑荆棘酒吧，也为他自己。最后一枪抵住因斯的额头，他低声说:"这一枪，是队长的。"然后他服下魔药，精神体骤然分裂，靠一场盛大戏剧和满场注视的"锚"稳住神性，晋升为序列4「诡法师」，成为真正的半神。

**可就在他以为一切尘埃落定的那一夜，他走上灰云，看见了"光门"。**门上空悬着一条条黑色的细线，每根线都吊着一个装着现代地球穿越者魂体的透明"蚕茧"，其中三个已经破了。他忽然明白——自己不是被什么高维意外送来的，他是被某个存在像货物一样抓来、封进蚕茧、挂在光门上的。那个他一辈子为之筹谋的"回家"，根本是一座他攀不上去的孤峰；"比起空间的距离，时间的阻隔更加让人绝望"。他在心理上塌了下去，幽蓝色深渊张开，直到奥黛丽在灰雾的"忏悔室"里，用一句"祝你快乐"和"睡美人与沉睡家人"的故事，把他一点一点从洞里拽回来。第四卷，止于他重新把目光投向贝克兰德的大雾霾、查穿越者的真相——以及南大陆边境某个仓库外，那两道不请自来的注视。

## 二、主线推进（卷内发展链条）

1. **身份落地与上流渗透** → "道恩·唐泰斯"三层飞雄富翁人设立住，以社交/猎枪/慈善/捐款嵌入贝克兰德风暴与黑夜两大教会的上层圈子，同时逼近圣赛缪尔教堂查尼斯门（ch731-750）。
2. **宝库前的"加减乘除"** → 议会舞会识才、贷款信使追查、窃运者符咒成型；刺X先生获"旅行家之门"传送、联手魔女特莉丝追大雾霾真凶斯特福德子爵；阿尔杰出海晋序列（ch751-780）。
3. **内斗清除副人格、无面人魔药彻底消化** → 借"心魇蜡烛"抹掉污染副人格、"无面人"消化完成、自我认同加深；以格尔曼身份与倒吊人阿尔杰探原始岛、夺"暴君"亵渎之牌（ch781-810）。
4. **盗笔记之败与迷雾小镇死局** → 潜入查尼斯门被"橡皮擦天使"抹入神战遗迹迷雾镇，灰雾/灵界尽封、秘偶折损，靠黑暗圣徽破门入灵界、蠕动的饥饿升七格（ch811-840）。
5. **由"贼"转"老板"** → 公共马甲摊牌"道恩·唐泰斯"、捐股建慈善基金、接军火走私、以"复仇共同体"收编伦纳德、认奥黛丽并肩，筹集诡法师材料、启程南大陆（ch841-870）。
6. **木乃伊、阿蒙与阿兹克之魂** → 盗图坦西斯二世木乃伊呈莎伦、秘偶上限提至2/距离200米、还清信使债、阿蒙分身降临、阿兹克割半魂沉睡（ch871-900）。
7. **南大陆秘偶扩充与复仇落子** → 收恩佐/路德维尔、入死神宝库、独闯卡尔德隆夺诡法师主材、识破因斯被红天使梅迪奇恶灵附身（ch901-930）。
8. **丧钟复仇、晋升半神、真相崩塌** → 复活广场三幕大戏分离恶灵、逐枪爆头因斯、服魔药晋序列4「诡法师」、登灰云见光门蚕茧、"回家"目标崩塌后由奥黛丽引导重建（ch931-942）。

> **本卷主角"成长方式"定型**：从"单兵猎杀/亡灵换皮"彻底切换为"身份-金钱-戏剧-傀儡"四件套的权力型打法——他以"导演"自居藏身幕后，靠无面人扮演、秘偶受众、符咒对调命运与神罚编排一出出"戏剧"，晋升"诡法师"更以"观众注视"为锚。成长的引擎不再是越级杀怪，而是"把死亡与复仇也编排成可操作的一场戏"。

## 六、这一卷教会读者的事（创作价值）

- **"权势型新身份"如何成为叙事主轴**：克莱恩从"打不过就跑"升级为"用身份、钱、戏剧、傀儡布一场局"，整卷最重的几颗爽点（X先生刺杀、盗木乃伊反当老板、复活广场复仇）都建立在"扮演-掌控"而非"蛮力"上——这为中后期网文主角"不能只靠打"的分卷范式提供了可复刻的样板。
- **序列跃迁要用仪式感守住"锚"**：晋升序列4「诡法师」精神体会提前分裂，作者用一个"盛大戏剧+满场观众注视"的意象既做剧情高潮又给了设定抓手——高段晋升不是吃药，而是"认知自己的方式是戏剧"，让力量成长与人物心理同步。
- **复仇线要"跨卷蓄势、单点引爆"**：因斯的仇恨从第一卷埋、中间几卷反复点到，作者刻意把"0-08怕被知道"的设定做成延缓和悬置，最后在复活广场用"逐枪报功名+一枪是队长的"收束——蓄得越久，付出代价越大，爆头那一下的爽感越硬。
- **"真相震撼"是逼主人公换目标的最强引擎**：一句"光门蚕茧、时间比空间更绝望"直接击穿主角毕生执念，迫使他从物理复仇转向心理重建——当"消灭敌人"已经不足以支撑一个人时，用更大的世界观谜团接住读者，是长篇连载最好的续命术。
