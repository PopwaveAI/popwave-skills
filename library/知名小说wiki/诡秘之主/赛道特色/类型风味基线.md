# 类型风味基线 · 《诡秘之主》

> 一句话世界观：**克苏鲁式神秘纪元 + 胜蒸朋克工业时代 + 爽文"序列魔药扮演升级"**——《诡秘之主》把一座维多利亚风格的蒸汽雾都架在克苏鲁不可名状的古老神秘之上，让一个穿越的谨慎大学生爬"占卜家→愚者"的序列阶梯，一路从廷根小城杀到与真神/旧日博弈的半诡秘之主。

## 类型声明

```
【类型声明】当前作品类型：克苏鲁式神秘 + 蒸汽朋克工业时代 + 爽文序列扮演升级。
写作全程保持本书风味：神秘揭示式进度（每次接触禁忌即推进剧情，不可名状之物反复垂钩）、
升级靠"摆脱凡尘/扮演消化"而非打怪数值（服魔药→扮演职业→消化晋升）、
文明压在蒸汽机械与神灵教会的薄壳上，科技当背景板（看不出科技的战斗力，是氛围牌）、
凡人社会的"时代大雾"中湮灭无名者，主角用一具具捏造的身份于夹缝中求活。
社会符号含序列-魔药-扮演法、22途径塔罗牌体系、七神教会、封印物0-x分级、
值夜者/红手套民间化精英小队、塔罗会组织、雾都/黑脏贫民、大雾霾。
禁止漂移到修仙（灵气/元婴/宗门）、纯打怪升级面板流、或把工科科技写活成主要战斗手段。
```

## 三大风味引擎（本书独有，同赛道基准力）

1. **神秘揭示式进度**——升级不是"打怪得经验"，而是"越接近不可言述之物，越被拖入更大的谜"。安提哥努斯笔记、0-08羽毛笔、光门蚕茧、切尔诺贝利——每一步强化的同时抛下一个"必须查清"的钩子，进度=解谜。
2. **换身份伪装玩法**——「对外死亡、再起新身」，主角用克莱恩→夏洛克→格尔曼→道恩→梅林的假面一张张换地图。身份既是伪装也是叙事发动机：旧身份积压的线索与新身份的自由同时兑现，可反复复用。
3. **扮演-消化晋升**——"人设即修行"。魔药名称是消化钥匙，先"当够某个职业"再升下一级；操作同时叠"恐怖片导演""观众注视为锚"等扮演法，把能力成长与人设弧光合并，让升级自带戏。

## 类型门禁（防漂移自检清单）

- [ ] 是否用"序列+职业名"而非数值等级（bp/经验条）
- [ ] 晋升是否走"服魔药→扮演消化→仪式/材料→晋升"闭环，而非单纯变强
- [ ] 是否存在反复的"神秘揭示式"钩子（一件超越主角认知的存在反复压迫+每次只揭一角）
- [ ] 主角是否会用换身份/假面切入新地图，而非直愣愣开新副本
- [ ] 蒸汽机械/工业是否只当氛围背景板，未抢占主干战斗力
- [ ] 凡人社会是否有"时代大雾中消失的姓名"式民生悲怆（非纯爽点叠加）
- [ ] 组织/神尊名是否走宗教化「XX会」与三句尊名格式，禁中式神君叫法
