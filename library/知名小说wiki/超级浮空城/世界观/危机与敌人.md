# 危机与敌人 · 《超级浮空城》

> **危机法则**：悬在主角头上的刀随时量级升格——**危机范围与主角升位严格对应**，从"一城夺权案"到"弑神/反攻星球/多元宇宙秩序"，越是末尾，世界级绞肉台越呼之欲出。

## 一、全书总危机：死兆之星浩劫（时间引擎）

- **本质**：死兆之星是上古憎恶（恶念泛意识集合体），主导意识藏于弦月地核、操控梦魇之境，以器官性邪物（死亡之眼/观察之眼/侦查之眼）向外扩张，最终目标是把摩泰拉也拖入黑暗。它未蜕变为邪神，但实力约在弱等神力至中等神力之间，随手一击有 10-11 环法术威力。
- **多波冲击**：死亡之眼入侵学院 → 观察之眼腐化梦魇之境半神 → 血蛇神封神 → 弦月成卵孵化 → 死兆之星本体现身（最终之战）→ 神系战争余波。每一波都伴随"反派越打越聪明"的进化（杀敌削弱反转成杀敌进化）。
- **坠落链条**：弦月生态崩溃 → 禅达大绿洲百万魔虫围困 → 虚大师以"觉者"形态发动自然之怒大灾变与死兆之星本体同归于尽 → 弦月成卵 → 反攻弦月最终之战击杀死兆之星本体。
- **主角变量**：史蒂芬以浮空城+魔像军团+龙族盟约+跨位面战略打击反攻弦月，在死兆之星重新凝聚前完成最终之战——**改写原史，把星球级浩劫收窄为一场决战**，但虚空恶魔回归的万年阴影仍在。

## 四、危机设计通则（供拆书/二创）

1. **倒计时不落地**：危机量级随卷升格，但"末日"始终悬而未坠——死兆之星从第一卷虚大师求援埋线，到第五卷才被击灭，给成长提供紧迫、不给安全坪。
2. **威胁=神性来源**：每个阶段 BOSS 都是主角下一级神性的来源（蠕虫行者→死亡之眼→血蛇神→观察之眼→死兆之星遗留），危机设计与升位严格勾连。
3. **人性化大敌**：血蛇神被自己祭司暗算、蜘蛛神后利用史蒂芬削弱对手、恶魔之王派蒙被死兆之星吓退——世界级危机带欲望与算计，而非单纯数值压顶。
4. **多波推进**：死亡之眼→观察之眼→血蛇神→弦月成卵→本体，一波方平一波又起，制造长效紧张。
