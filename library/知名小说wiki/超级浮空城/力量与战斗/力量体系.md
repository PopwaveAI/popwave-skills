# 力量体系 · 《超级浮空城》登天之路

> **一句话总纲**：这是一套**"数据面板为纲、基建碾压为翼、神性收割为终极引擎"**的炼金术士力量系统。
> 凡人期由"炼金术士等级+材料经济"定上限，登神后由神性/神格/神职三维决定扩张空间。
> 读本片请配《动力引擎.md》——这边是"体力活的规律"，那边是"为什么拼命"的答案。

## 〇、三层总结构（先看全貌）

**凡人职业轨 →（神性吸收衔接）→ 半神轨 →（封神仪式衔接）→ 真神神格轨 →（时空枢纽衔接）→ 守护者轨**

- 上层由下层承载：凡人可吸神性，但**没有神格神职就存不住神力**——"吸收了力量 ≠ 拥有承载它的容器"。这是本赛道最大的升级天花板设计，也是主角终局拒绝封神的根本原因。
- 三层切换有三个质变点：**本职5级（凡人内小质变）→ 25级高阶传奇（凡人→超凡大质变）→ 封神（超凡→神明大质变）**。
- 本书主角史蒂芬·周的完整登天轨迹（卷名即勋章）：**5级炼金术师 → 9级 → 16级 → 19级 → 22级 → 25级高阶传奇 → 26级 → 30级星界法师 → 时空枢纽第九位守护者 → 神性媲美强大神力神灵**。

> 证据行：起点5级炼金术师（巅峰45级）🔒 ch026｜终点约26级高阶传奇炼金术师、施法等级30=星界法师级别战斗力🔒 ch015｜神性值媲美强大神力神灵🔒 ch032

### 工作/经验（本书第一燃料）

- **力量来源是工作**🔒：挖矿、撸树、制作、研究→升级→激活能力。炼金术士的升级不是打怪，是"干活+烧材料"。
- 升级需要稀有材料：10级需1吨黄金激活能力🔒、秘银（10磅=1吨黄金）🔒、神之手需127道炼金刻痕+金刚石/秘银/奥法之尘/星界之沙🔒。
- **"力量第一本金"的底层逻辑是"谁的材料多、谁的地图大，谁拿得多"**——与《动力引擎》泵一咬合。

### 辐射污染（力量的反向账单）

- 辐射污染指数：40%影响身体/60%损害/80%红色警戒/90%威胁生命🔒；指数10%时法力降至上限90%、易血脉反噬🔒。
- 主角全程与辐射对抗：2.5%→4.1%→6.3%→7.5%→清零（贝蒂自然净化）🔒。

### 神性/神格/神职三载体（登神终极引擎）

- **神性**＝本源/半能量体，主免疫致命背刺与减伤；可击杀抽取、赐予选民。
- **神力**＝可直接消费的能量储备；**神格**＝力量上限之钥，后天凝成最难。
- 神性值体系：蠕虫行者神性值约7点🔒、一次神性抽取上限1点🔒、神孽抽取约20次🔒；神性值→神术（英雄宴）→神力护盾（至少12环以上法术才能打破）→封神资格（微弱神力10点/弱等神力30点）🔒。

## 七、这套书力量体系的写法规律（创作价值）

1. **机制可解释的越级**：每一境晋升都有可计算数值门槛（材料/神性/能量化），每一次"爆种"都能用面板核算，爽点可验证、不悬浮。
2. **数值与叙事咬合**：击杀结算（神性/血肉精华/灵魂晶石/装备）直接并入剧情，面板结算点=剧情推进点。
3. **三泵驱动**：炼金升级泵（个人力量）+浮空城基建泵（文明扩张）+神性收割泵（越神级成长）三台泵并行，个人线/基建线/神战线三线咬合。
4. **基建碾压**：魔像军团100:1战损、超远程位面战略打击、浮空城折越——本书战斗的独特解法是"用工程学碾压敌人"。
5. **CR即世界刻度**：刻度表既是压力源也是成长进程，成长全程可视。
