# 各卷切片 · 《超维度玩家》（诸生浮屠）

> **切片方法论**：九字段每卷可写范围提前切好——plot 做卷纲只取本卷切片内设定，禁跨卷取用。**卷末设定边界＝防透支机制**（止于什么、不开什么，不能抢的后续收益留给后面的卷；越界即透支爽点节奏）。

- **势力范围**：不列颠/罗马/撒克逊/朱特/法兰/匈人/阿瓦隆/英灵殿/北欧诸神。
- **危机范围**：阿提拉"上帝之鞭"压境、历史自愈、戴兜帽者审判、蛮族与罗马历史规律反噬。
- **敌人生态切片**：蛮族溃兵/朱特战士/海怪巨蛇/怪物之母/女妖/英灵/阿提拉匈人军。
- **矛盾轴切片**：凡人帝国生存 → 神话力量夺权 → 历史规律 vs 戴兜帽者审判。
- **卷末设定边界**：止于"统一不列颠→平推欧洲→万王之王"，帝国法理成型，未进入机械神国/高魔位面。
- **卷间债务**：历史自愈、戴兜帽者审判、誓约胜利之剑、血之杯、冰龙奥古斯都、神化能力未完全展开。

## 全书大图景：从英伦到深渊的一条主线

> **一个穿越者，从"历史长河的旁观者"变成"改写神话、信仰、战争、秩序的人"。**

邓肯的金手指不是单纯游戏界面，而是"维度空间"：他能看见历史长河、世界规律、人类命运，并不断把自身力量嵌入历史节点。卷一，他以个人武力与神化能力不列颠立国、制霸欧洲、御龙登天；卷二，他以机械神国与旧神体系正面交锋、绝地天通、神格11战神兵主；卷三，他以仙道、神道、天庭秩序重塑人间、五国统一、斩玉皇建天庭；卷四，他以法兰西大革命切入英灵、圣杯、提亚马特与跨位面锚定、人性复苏；卷五，则以深渊费伦一路杀穿诸神旧秩序，从教派权柄到弑神弑主，最终一证永证、高维观察者收束全书。

这条主线不是单一升级，而是"世界控制权"一节节扩张：

- 卷一控制历史与帝国法理（英伦神话）；
- 卷二控制旧神、新神、机械神国（机械神国）；
- 卷三控制仙道、神道、天庭秩序（仙侠神道）；
- 卷四控制英灵、空间道标、人性复苏（法兰西/英灵/高魔位面）；
- 卷五控制诸神旧秩序、死亡概念、创世权（深渊费伦）。

**核心爽点公式**：邓肯不只是变强，而是把"不可控的历史/神道/高魔位面"纳入"上帝视角游戏界面"，再从"玩家"升格为"重写规则的人"。

- 卷一：历史自愈 vs 戴兜帽者审判
- 卷二：旧神体系 vs 机械神国
- 卷三：凡间秩序 → 神道秩序 → 天庭秩序
- 卷四：法兰西因果 → 英灵异常 → 人性复苏 → 跨位面锚定
- 卷五：凡人 vs 诸神旧秩序 → 弑神夺权 → 一证永证 → 高维观察者

全书主线不是"从一个地图跑到另一个地图"，而是"从凡人帝国，到机械神国，到仙侠天庭，到英灵高魔位面，再到深渊"——每一步都在扩大邓肯对世界规则的解释权，直到最后他亲手把规则换掉。
