# 势力深度卡（神系与各方势力棋盘）

## 黑色君王教会（邓肯秩序派）

| 字段 | 内容 |
|:--|:--|
| 核心神祇 | 邓肯（黑色君王/万物终焉之主） |
| 盟友 | 莎尔、大极乐之母、劳薇塔、赛雅茉芙、洛山达/光辉之主 |
| 组织 | 黑暗圣堂、杀戮天使、黎明之刃战团、基层低阶牧师体系 |
| 与主角关系 | 邓肯自建秩序体系 |
| 在书作用 | 把"凡人受困"转化为实际信仰与社会保障 |

- **核心神祇**：邓肯，黑色君王，后成为万物终焉之主。
- **盟友**：莎尔（第二邪神/阴影魔网）、大极乐之母（欢愉教派象征）、劳薇塔（折磨女神/属神）、赛雅茉芙（贵族女神/属神）、洛山达→光辉之主。
- **组织**：黑暗圣堂、杀戮天使、黎明之刃战团、基层低阶牧师体系。
- **与主角关系**：黑色君王教会是邓肯秩序派核心组织，承担信仰、军队、医疗、教育、临终皈依与再生术。
- **在书作用**：把"凡人受困"转化为实际信仰，是邓肯从弑神者转为秩序缔造者的组织基础。[ch130-132]

## 塞尔帝国 / 后期人类帝国

| 字段 | 内容 |
|:--|:--|
| 核心统治者 | 邓肯秩序体系下的皇帝/人类帝国 |
| 盟友 | 邓肯、亚桑四世、卡莱德、莎尔、渥金、密斯特拉 |
| 组织 | 帝国体制、紫龙骑士、以太掘进机、铁甲战舰、浮空飞艇 |
| 与主角关系 | 邓肯后期秩序扩张与帝国改革的核心落地 |
| 在书作用 | 将神战成果转化为人类社会生产力 |

- **核心统治者**：塞尔帝国在V5后段发展为人类帝国，邓肯体系深度介入。
- **盟友**：邓肯、亚桑四世、卡莱德、莎尔、渥金、密斯特拉。
- **组织**：帝国体制、紫龙骑士、以太掘进机、铁甲战舰、浮空飞艇。
- **与主角关系**：塞尔帝国是邓肯收复失地战争、工业改革与人类大远征的核心落地场。
- **在书作用**：谷地历1374年，一个行省钢铁产出超越西方诸国总和；谷地历1378年，人类打通元素位面通道，生活成本降低接近一半。[ch132]
