# 敌人深度卡（反派五级梯度 = 神格/规则阶梯）

> 敌人梯度与邓肯的权柄扩张对应：早期个体强敌→帝国与旧秩序→神系旧神→深渊巨头→风暴之主/一证永证。

## 跨卷大反派

### 塔洛斯·风暴之主（终局大敌之一 / 风暴概念执掌者）

| 字段 | 内容 |
|:--|:--|
| 身份/阵营 | 风暴之主 / 狂怒神系核心 |
| 威胁 | 首展野魔法（狂乱魔法、毁灭魔法概念），以天灾威吓。 |
| 被灭方式 | 邓肯将风暴之主拖入燃素海，捏爆微型太阳引发湮灭奇点，击杀塔洛斯。 |

- **身份/阵营**：风暴之主，狂怒神系核心，V5后期最大外部压力之一。
- **威胁**：谷地历1376年，风暴之主教会与邓肯教会及风暴海冲突，塔洛斯首展野魔法，包括狂乱魔法、毁灭魔法概念。[ch132]
- **被灭**：谷地历1384年风暴海湾决战，邓肯以超凡神力"改变空间"将风暴之主拖入国度天宇之外燃素海，以真实造物术捏爆微型太阳引发物质湮灭黑洞"湮灭奇点"，击杀塔洛斯。[ch135]

### 希瑞克·暗日（死亡神系主神 / 一证永证前压轴）

| 字段 | 内容 |
|:--|:--|
| 身份/阵营 | 暗日 / 死亡神系 |
| 威胁 | 无信者领域压迫，死亡神系旧神权代表。 |
| 被灭方式 | 邓肯以无信者领域制造三十秒反神灵力场，在凡物状态下以锻钢长剑一剑穿心。 |

- **身份/阵营**：暗日，死亡神系主神之一，代表旧死亡秩序。本质是"侥幸获得神灵位格的小丑"，靠神格神职碾压一切，一旦被剥夺神格"连个蜥蜴人都打不过"。[ch129]
- **威胁**：艾欧强行审判希瑞克，死亡神职落入克蓝沃手中，邓肯意识到神上神能随意改神谱。[卷5主线]
- **被灭**：邓肯撕裂焦炎地狱，撕裂神国砸脸希瑞克，以无信者领域制造三十秒反神灵力场，在凡物状态下以锻钢长剑一剑刺穿胸膛，暗日希瑞克陨落，众魂之列诞生。[ch129]
