# 盟友深度卡（情感核心 · 教派中坚 · 神系中坚）

## 卡莱德·黑刃（核心下属 / 堕落者救赎）

| 字段 | 内容 |
|:--|:--|
| 定位 | 邓肯麾下凡人将领 / 堕落黑暗卫士转圣光归来 |
| 阵营 | 守序善良，邓肯秩序派 |
| 攀登方式类型 | 没资源型→战场与信仰重塑 |
| 等级坐标 | 堕落黑暗卫士→圣光归来的凡人统帅 |

- **身份与功能**：卡莱德是邓肯在深渊费伦篇后期的核心将领之一，代表凡人阵营在神战中的归来与重立。
- **关键事件**：在V5后段从堕落黑暗卫士走向圣光归来，并率部参与收复失地战争，从提凡顿、奥克大沙漠反攻兽人，夺回耐瑟帝国旧地。[ch130]
- **成长**：从被旧秩序与信仰侵蚀者，转为人类收复失地战争的统帅。
- **终局**：泰瑟亚玛之战中，6万人类精锐击杀兽人之神格乌什眷者"碎颅者-乌鲁什"，屠10万兽人，打通大陆中部到西部通道。[ch130]

## 莎尔（邓肯副手 / 第二邪神）

| 字段 | 内容 |
|:--|:--|
| 定位 | 黑色君王教会核心成员 / 影子与纷争信仰操盘者 |
| 阵营 | 守序邪恶 / 阴影魔网信仰核心 |
| 攀登方式类型 | 有资源型→信仰经营 |
| 等级坐标 | 黑暗系信徒→仅次于黑色君王的第二邪神 |

- **身份与功能**：莎尔是邓肯秩序体系中的暗线执行者，负责阴影、纷争与信仰扩张。
- **关键事件**：谷地历1376年，莎尔消化"纷争"领域，成为仅次于黑色君王的强大邪神，阴影魔网兴起。[ch132]
- **成长**：从邓肯计划中的暗线力量，成长为可与主神秩序并行的强大邪神。
- **终局**：莎尔教会借死亡三神旧信徒与阴影魔网扩张，成为邓肯神系中仅次于主神的第二极。[ch130-132]

## 渥金（财富女神 / 被营救者）

| 字段 | 内容 |
|:--|:--|
| 定位 | 财富女神 / 邓肯进入无底深渊的核心目标 |
| 阵营 | 财富/金钱体系 |
| 攀登方式类型 | 有资源型 |
| 等级坐标 | 财富女神 |

- **身份与功能**：渥金是V5早期邓肯进入无底深渊的直接动机。邓肯在财富神殿当众宣布渥金被困无底深渊，但不知具体位置。[ch033]
- **关键事件**：邓肯进入深渊后，营救财富女神成为主线；救出渥金后，获得财富、贸易、金钱相关权限。[卷5主线]
- **成长**：从失踪与被困状态，转为邓肯体系中的关键神祇。
- **终局**：渥金倾向晋升强大神力，在秩序双极体系中承担财富/贸易权柄。[ch132]

## 黎儿拉（欢乐女神 / 自主神格）

| 字段 | 内容 |
|:--|:--|
| 定位 | 欢乐女神 / 邓肯早期神系盟友 |
| 阵营 | 欢愉/欢乐体系 |
| 攀登方式类型 | 有资源型 |
| 等级坐标 | 欢乐女神→获得自主 |

- **身份与功能**：黎儿拉是邓肯从欢愉教派走向无底深渊的重要转折点。V5 B1中，她正式授予邓肯神选身份，命其组队探查无底深渊，寻找/营救渥金。[ch032]
- **关键事件**：欢乐女神神恩降临，使邓肯力量进入新阶段；最终授予神选身份，使邓肯正式进入深渊任务线。[ch007, ch032]
- **成长**：从赐福者与神选发布者，到邓肯秩序扩张中的盟友。
- **终局**：黎儿拉脱离爱情女神属神身份，获得自主，成为独立神祇。[ch137]

|:--|:--|

- **身份与功能**：赛雅茉芙代表王权、正统与贵族法则，在V5后期被邓肯纳入秩序双极体系。

- **成长**：从王权贵族侧的神祇，转为邓肯秩序体系中的正式属神。
- **终局**：确立为邓肯两位正式属神之一，承担贵族/正统/王权法则。[ch133]
