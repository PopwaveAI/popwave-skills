# 赛道特色 · 命名规则

## 一、主角跨卷称号链（"名号随力量升高"）

邓肯的名号随每卷力量爬升而级联上涨，**形成一条"凡人→半神→神上神"的称号链**，这是全书命名最核心的规律：

| 卷 | 力量位格 | 称号 |
|:--|:--|:--|
| 卷一 | 万王之王/不朽英灵 | 欧洲之父、奥古斯都、凯撒、万王之王 |
| 卷二 | 机械战神/兵主/神格11 | 机械战神、兵主 |
| 卷三 | 天帝/万灵信仰 | 天帝、玉皇道君（天庭）、兵主战神相 |
| 卷四 | 裁定者/英灵召唤 | 裁定者、时空锚定者 |
| 卷五前段 | 半神/神选 | 双花红棍、首席神眷者、首席打手 |
| 卷五终局 | 神上神/万物终焉 | 黑色君王、万物终焉之主、高维观察者 |

> 规律：称号永远比当前力量"高半级"作钩子，比实际权力"低半级"留余量——读者信"他还配得上更好"。

## 二、星宿主等级体系（英伦篇·单位星级）

- 格式规律：`{星级数} + {等级色}`，如 二星银灰、三星银灰、三星、六星金色。
- 颜色语义：银头=精英/准、金字=高位/传说、灰=隐藏波动（阿瓦隆仙女三星银灰、戴兜帽者三星）。
- 卷五延续为 `挑战等级N`（血焰暴君挑战等级23🔒）+ 星级（六星金色），颜色分级保留。

## 三、神职与神名命名

| 规律 | 例子 |
|:--|:--|
| `神职词 + 之神` | 财富女神、爱情女神、欢乐女神、幸运女神、时代女神 |
| `属性词/权柄 + 之主` | 万物终焉之主、风暴之主、暗日 |
| 称号级联 | 渥金·财富女神→邓肯"黑色君王"→终局"万物终焉之主" |
| 双名称并列 | 四色龙后·提亚马特、白金龙神·巴哈姆特 |

## 四、外号/绰号体系（口语层命名）

- 功能：把术语转成读者能记住的"人设标签"，如"双花红棍""首席打手""法爷？法孙！"。
- 规律：常以**反差/打脸**构成——明明是神，却用市井外号；让读者在"我很强"与"我很接地气"之间反复爽。

## 五、装备/圣物命名

- 格式：`材质/来源 + 功能词`，如 圣金誓约、黄金之手、永金池圣水、幸运金币、神圣复仇者、圣印之枪、龙枪。
- 特征：一律带"圣/金/誓约/神"等权威词，强化"规则级宝具"质感；标注属性数值（+5力量、挑战23）让爽点可量化。

## 六、位面/地名命名

- 格式：`属性位面` 或 `功能地域`，如 明水之域、无底深渊、极乐境、淫欲位面、精神位面、灵魂层面、晶壁系。
- 卷五地名带"星坠河水系"延续性（星坠、贝斯提亚姆、风暴山脉），强化地理真实感。

> 复用要点：**名号要跟力量走，星级要有色、外号要打脸、装备要圣金、位面要属性化**。
