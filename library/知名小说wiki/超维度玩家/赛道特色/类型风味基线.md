# 赛道特色 · 类型风味基线

> **赛道定位**：`超维/诸天万界流` 基底 × `游戏化系统流` 皮相 × `弑神夺权流` 内核。一句话卖点——"从一个世界横行到另一个世界，把旧神统统踩在脚下，最后自己成为规则的守望者"。

## 一、风味骨架（五要素）

| 要素 | 本书给法 | 跨书复刻要点 |
|:--|:--|:--|
| 世界观尺度 | 五卷五个异构世界，逐卷扩大控制权 | 让"世界"随主角前进而更宏大，而非困在一张地图 |
| 主角驱动力 | 从"活着/变强"升到"夺规则权柄" | 目标要能一路升级：饿→强→权→圣→守望 |
| 敌对结构 | 敌人生态逐卷换血，终局打"规则本身" | 每卷换一片敌人体系，终点不是最强的神而是规则 |
| 爽感来源 | 信息差+数值碾压+弑神夺权+打脸 | 面板可量化 + 敌人下跪 + 权柄咬合 |
| 叙事动力 | 一条越卷越高的压力山脊 | 危机永远比主角高半级，突破靠吞掉更强对手 |

## 二、爽点配方（跨书可抄）

1. **面板槽**：生命=普通人2倍🔒、体力=12次全力砍杀🔒——把弱都写成可计算的数字，读者秒懂强度。
2. **信息差碾压**：上帝视角/维度空间让主角总比敌人多一层情报。
3. **弑神夺权**：吃神性→凝神职/领域→改写规则，每吞一神=吞一套信仰链。
4. **打脸节奏**：外号反差（"法爷？法孙！"）+"被轻视→反杀→身份跃迁"循环。
5. **名场面集中**：屠龙（踩龙角/劈颅/弹射起身）、神国对质、审判城归来——每卷留1-2个可传播的高光幕。

## 三、情感配方

- **清醒克制的人设**：主角对盟友"会帮你但不会一直陪你"，不滥情、不出戏。
- **强者不装**：主角不主动炫耀，靠行为结果打脸（爽点是"他赢了"而非"他说自己强"）。
- **压力源矩阵**：旧政权+神系规则+信仰经济+时间线多维夹击，让胜利来之不易。

## 四、写作纪律（红线）

1. **名号跟力量走**：称号永远比当前力量高半级，比实权低半级。
2. **对手要配得上**：反派也是规则化身，败亡对应"吞掉一整套规则"而非单纯物理击杀。
3. **不写空喊**：爽点要有行为证据（屠龙=动作分解，夺权=权柄咬合），不用"他很强"贴标签。
4. **类型混搭要自洽**：诸天+系统+弑神三类元素要在一个"世界控制权"主线内咬合，不散装。
