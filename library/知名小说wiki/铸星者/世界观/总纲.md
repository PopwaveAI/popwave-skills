# 世界观总纲 · 《铸星者》

> **一句话总纲**：主角萧伯纳生在一个「DND 数值化」的剑与魔法世界中，以「神性+神格+神职+传说度」为唯一登神路径、以「德鲁伊→牧树人→牧星者」为职业主线，从世界之脊醒转的伪神一步步把荒野道途推向「星空亦是自然」的广义自然神学；而悬在整个蛮荒天宇头上的，是远古夺心魔文明穿越时间终结降下的「终焉时刻」与一颗名为泰拉希尔的腐化怪物星球。

## 一、世界总架构（位面链双层搭台）

世界按「主物质位面 + 垂直位面链 + 星界/远方」搭建：

- **主舞台·主物质位面（蛮荒天宇）**：人类、精灵、矮人、龙族、卓尔等诸种族的家园，萧伯纳的黄金椰枣、震旦王朝、龙之国、世界之冠等凡间势力与信仰角力之地。
- **垂直位面链**：主物质位面 → 阴影位面（黑暗山脉等半物质投影层）→ 灵界/幽魂界（灵魂能量层）→ 冥界（死亡与摆渡）→ 下层位面（暗渊/无底深渊/巴托地狱/寒冰地狱）。另有精魂界与梦境国度等依托自然与精神法则的层面。
- **上层与精魂位面**：万兽园（自然精魂大本营·荒野诸神神国）、世外桃源（东方精魂系·远东精魅安息国度）、极乐境（上层位面·欢愉女士）。朝阳神国半位面构成神灵居所与的高阶生态（V7_B3/V8_B2）。
- **星界·跨晶壁远方**：星界之海漂浮神国/陨落古神尸体/半位面；更远处是静谧太空（苏恩夺心魔故巢）、癫喧太空、以及克苏鲁式「遥远国度」——「终焉时刻」的本源所在（V9_B1/V9_B2）。
- **枢纽节点**：外域与印记城一带的喧嚣间隙/烟尘位面/无极尖峰/瘟疫城，无数传送门交汇处，主角曾经游历（V7_B3）；以及黎明神战高等精灵遗留的唯一太空要塞「月之门」（V9_B2）。

## 二、时代与大事线（时间引擎）

全书时间轴由「终焉时刻 + 登神之路」双线驱动，历史序绳如下：

- **黎明神战**：荒神阵营（魔教总坛·恐龙之父-乌塔欧叛军）与寰宇巨蛇对撞，寰宇巨蛇击败荒神却因面相过多而撕裂自身（V3_B6/V7_B4/V1_B2）。失落七神/暗夜巨蛇/上古邪物/噬魂者等禁忌之名由此降临。
- **远古夺心魔帝国**：曾横跨星界、以类人宿体孵化繁衍，精灵王庭一度沦陷；主脑帝国的遗毒绵延至今（V1_B1/V1_B2）。
- **耐瑟时代**：大奥术师研究神格、触碰亚空间禁忌造物，留下魔能遗产与天灾终焉末日底色（V1_B1）。
- **第三纪元·巨龙王庭**：龙族黄金文明，最终因通缩经济倒台；《龙裔法典》与龙脉仪式为其遗产（V6_B1/V6_B2）。
- **第四纪元·精灵王庭**：世界树·尤克希尔与树冠精灵时代的末法之殇；海上失落群岛因大陆撕裂沉落（V6_B2/V7_B4）。
- **震旦西征与白玉京「南天门」计划**：东方王朝极限换家撞星门，泛精魂神系几乎全灭、上古邪物冲入蛮荒天宇，随后神龙帝国/黑暗时代直至当代复兴（V6_B2）。
- **诸神黄昏预言**：星界商人携「萨贡恩预言石板」归，揭示远古夺心魔帝国穿越时间终结未来降临（V9_B1）。
- **终焉时刻（本书最终引擎）**：远古夺心魔的黑暗主脑驾千万鹦鹉螺巨舰降临，萧伯纳以梦境之心、原始魔网与诸神盟军力挽，并在番外走向「漫游者」神上神道途——蛮荒天宇随后拉开星空/高魔时代（V9_B2）。

## 三、世界设计原则

1. **DND 数值化世界观**——角色面板、神格具现化、挑战等级、领域、专长、法术环数穿凿整个世界运行逻辑，系统提示音即是叙事的一部分。
2. **登神硬规则**——神性+神格+神职+传说度+祈祷言的不可绕过成神门槛；半神=神格0+永生不朽三要素（V2_B1/V7_B4）。
3. **德鲁伊道途主线**——草创「德鲁伊→牧树人→牧星者」职业柱，最终以「星空亦是自然》的广义自然定义权重构神学，压制造神、走自然道统（V9_B1/V9_B2）。
4. **信仰-神力闭环**——信仰供神力、神力反哺赐术，神职是循环关键；传说度（声望）是封神前置门槛（V2_B1/V5_B1/V9_B1）。
5. **位面横竖琴**——主物质-阴影-灵界-冥界-下层-星界的垂直纵深支撑冒险穿越；阴影/灵魂/梦境/精魂多线跨位面战役制造持续战场。
6. **终焉时刻为时间引擎**——「悬在头上的刀随主角昇位升格」，从一城邪教案走向位面大战与跨晶壁远征。
7. **信仰诸神 vs 无信/泛意识神系**——东方图腾崇拜、万灵信仰以泛意识精魂对抗诸神体系，构成神学立场的纵深冲突（V3_B1/V4_B1）。
8. **文明扩张作为道途落点**——黄金椰枣生态城邦（异族混居/废奴/粮革/工业萌芽）到震旦丝绸之路、龙之国、星空/高魔时代，萧伯纳的秩序观贯穿始终（V6_B2/V9_B1）。
