# 动力引擎 · 为什么人人都往神位上爬，他却要走到神上面

> **一句话总纲**：逼着这个世界一路往上爬的，是一套"**异怪时代将临＋神权压迫＋文明将被抹平**"的多重重力场；而萧伯纳的破解之道不是比别人爬得更狠，而是——**他把"什么是神"的定义权握进手里**：登神不只是力量，是他全程一直在经营的"话语/秩序"。
> 配《力量与战斗/力量体系》看：那边定义了力量怎么长、序列与挑战等级；这边回答"凭什么爬、代价多少、为什么神性底下总有一把'人性''异怪'的刀悬着"。

---

## 一、世界总驱动力：登神不解决真正的问题

- **表层重力：力量即生存**。伪神重生即死过一次的他清楚，凡人在异怪、伪神、独神暴政面前就是口粮——"变强"是他回到世界的第一动机（卷1 ch1 弃荒野定牧星者）。
- **深层重力：异怪时代将临**。远古夺心魔舰队（卷7-9）与苏恩（卷9）数十年内将降临，诸神黄昏已是预言——**"守护文明"必须由能改写法则的人来做**（卷9 ch7,22-27）。
- **反手镰刀：神性腐化人性**。卷8 萧伯纳半神后遭植物法则侵蚀人性、靠萨丽·月桂锚定；登神本身不是免费续命，是另一场对"他还是不是人"的审计。
- **萧伯纳的解法：把"定义权"当最高生产力**。星空亦是自然、牧星者高于神明、人可以走人人如龙——他一路赢战，最后赢的是"定义"。

## 二、运转机制：序列、神性、定义权三台泵

### 泵一 · 序列泵（德鲁伊→牧星者的肉身机）
- **规则**：弃荒野之道、自定"牧星者"，走 德鲁伊→牧树人→牧星者 的原创序列进阶；靠猎杀仪式、祭献、神性提取往上爬。
- **代价**：肉身上限（序列曲线/体质硬上限）、血肉与法则摩擦、"点化/祭献"会烧等级与灵魂材料（卷3 点化黄金椰枣掉两级半）。
- **书证**：卷1 牧树人厂商；卷2 猎杀领域+高阶德鲁伊；卷3 挑战20；卷7-9 牧星者/半神/神上神。

### 泵二 · 神性泵（猎神/登神的燃料机）
- **规则**：杀神性生物→抽神性/神职→填自身或拆给盟友；弑伪神（卷6 西蒙·达尔贡/鬣狗之神）是最猛的单次燃料。
- **代价**：神性无容器存不住、神职有责任、神国强权冲突不休、"拒绝神位"是他反复踩下的刹车（卷6 击碎黑暗圣杯）。
- **书证**：卷3 精魂召唤（血爪）；卷6 神性一分为五；卷7 荒野精魂接管死亡权柄；卷9 吞苏恩领域。

### 泵三 · 定义权泵（其他神都不会的登神机）
- **规则**：不靠封神仪式，靠**让亿人认同你的定义**——"星空也是自然""人性本善""牧星者高于神明"被世界整体接受时，主角自动登顶。
- **代价**：要经营文明（扫盲/商路/工业/学校）、要说服万神殿、要扛"过度神化＋小心别人用同一招反制"。
- **书证**：卷9 万神殿人性本善废奴、自然之心神国、神上神成即"漫游者归位"——抽。

## 三、众生攀登分层（谁在爬、爬到哪、掉在哪）

| 层级 | 身份 | 驱动 | 代价/终点 |
|:--|:--|:--|:--|
| 凡人/平民 | 牧民/难民/小人物 | 活着、一顿饱饭 | 经验指数增长→旧猎场收益衰减 |
| 职业者 | 沙蜥/螳螂/德鲁伊学徒 | 序列进阶、立誓立功 | 职业/领域/晋升门槛 |
| 高端职业者 | 高阶德鲁伊/准传奇 | 一城一方倚仗 | 传奇天命/序列自定义门槛 |
| 天命传奇 | 大德鲁伊/武僧宗师 | 弑神话事权、建立势力 | 传奇仪式＋血脉/领域纯化 |
| 半神 | 有神性、神职未落地 | 万神殿无座、神国经营 | 神性无容器、神位挤压 |
| 伪神 | 凝神职未登真神 | 诸神重点打击对象 | 封神前夜最危险（西蒙/鬣狗之神） |
| 真神 | 微弱→弱等→中等神力 | 神国与万神殿博弈 | 信仰/神职依赖、王座吞并 |
| 神上神 | 定义权之巅（萧伯纳） | 守护文明 | 人性侵蚀、太强即成靶 |
| 漫游者 | 萧伯纳终局席位 | 扛着文明走星空 | 留白：续作地平线 |

> 萧伯纳的攀登轨迹（卷名即勋章）：**荒野之主→神眷者→（神孽之战）→（登神预备）→（黑港看封神）→（龙之国弑神）→（上古邪物·死亡权柄）→登神铸星→星空德鲁伊→神上神/漫游者**。读者透过他看完整条"凡→神→主→漫游"的天梯，爽感来自"我又走了一格、而头顶那把刀还在"。

## 四、代价结构：爬得越快，账单越厚

1. **肉身与法则摩擦** → 序列曲线硬上限、祭献烧等级（卷3 点化掉两级半）。
2. **越强越怕／越强越孤独** → 越接近神位越是诸神靶子，也越疏离"人"的锚点（卷8-9 萨丽·月桂锚定人性）。
3. **容器与责任双重枷锁** → 神性无容器存不住、神职有责任、神国信仰耗神力。
4. **多线经营的时间账** → 领地＋教会＋暗渊＋泰拉希尔＋星界多线并行，神格增长与人性侵蚀双线赛跑。
5. **"拒绝神位"的最贵刹车** → 他反复拒神/砸神职，把"成为神"从欲望拧成选择，成本是必须等到"定义权"成型才肯登顶。

## 五、引擎与全书的咬合（为什么这套动力不因登顶失效）

- **后端重力场**：苏恩/远古夺心魔入侵（卷9 决战+远期地平线）让"守护文明"成为登神之后仍然存在的任务，主角登顶不是终点而是更大战场的哨位。
- **爽点放大原理**：序列进阶（数值在涨）＋神性猎神（身份在跳）＋文明经营（有人在拥戴）＋异怪将临（世界在被抹平）＋人性侵蚀（他会不会变怪物）——五根油门叠加成立。
- **创作取用**：若要复刻，核心是**先立一台"异怪时代将临"的倒计时＋神权压迫，再立"序列—神性—定义权"三台泵，让主角的终局不是"杀死所有神"而是"重新定义神"**——动力一脚油，读者自然会跟着主角往上冲。
