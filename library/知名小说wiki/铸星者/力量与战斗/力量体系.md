# 力量体系 · 《铸星者》从德鲁伊到铸星者

> **一句话总纲**：这是一套**"神格具现化系统 + 类DND数值面板"双驱动的德鲁伊道途登神体系**。
> 凡人期以"职业等级×法术环位×变身形态"成长，登神后以"神性值/神格值/神职领域"三维经济扩张。
> 主角萧伯纳的终极身份标签即书名——**铸星者**：以最高自然解释权重铸星球、重塑魔网的最后真神。
> 读本片请配《战斗系统》与《金手指》——这边是"力量长什么样"，那边是"怎么打"和"凭什么是他"。

## 〇、三层总结构（先看全貌）

**凡人职业轨（德鲁伊→牧树人→牧星者）→（半神晋升仪式衔接）→ 半神轨（自然半神·不朽者）→（登神/铸星衔接）→ 真神神格轨 → 神上神**

- 上层由下层承载：凡人攒职业等级与法术位，登神后以神性值存神力、以神格值封免疫、以神职领域定权柄——"没有神格就存不住神力、封不住免疫"。
- 三层切换的质变点：**本职5级（凡人内小质变）→ 传奇进阶（凡人→超凡大质变）→ 半神晋升（ch82，超凡→不朽大质变）→ 登神/铸星（ch71-72，神明级）→ 神上神（终卷晋升中）**。
- 主角萧伯纳完整登神轨迹（按批号卷位）：5级德鲁伊 → 牧树人 → 牧星者 → 自然半神·不朽者 → 弱等神性 → 中等神性（登神/铸星者）→ 强大神性（挑战72+）/ 神上神晋升中（漫游者道途）。

## 一、第一层 · 世界源力量（属性/法术环位/神性三载体）

### 属性体系
- **六维**：力量/敏捷/体质/智力/感知/魅力。凡人基准 **10**。萧伯纳主感知（德鲁伊施法主属性），ch1=20(+4)，终局感知50🔒。
- **属性成长**：装备加持（感知另+6~8）、职业进阶、变身形态临时替换、神性/神格增益（微弱神性全属性+1、中等神性全属性+3）。
- **超凡/神性阈值**：力量跨60为神龙形态（力突破67超绝大多数主物质位面生物；主物质位面上限约60🔒）。

### 魔法环位体系（Caster Level 法术分档）
- 常规法术 **0-9环**（传统DND高环区）。
- **传奇法术区**：10-11环（时间复制术＝唯一瞬发传奇法）；12环（永恒炽阳·仅神龙梦境之心可引爆/群体德鲁伊启蒙术）；13环（海啸术·神迹升阶）；14环（冰河世纪·灭世）；15环（最高环位·时空法则·「大自然的报复」永恒神迹）。
- **法术环位随等级解锁**：职业等级40封顶15环🔒；登神前 13环封顶🔒。
- **施法体系下限**：凡人均可修行，原始魔网（终极终卷）把施法门槛由"智力16"降到"连接魔网即可"——底层施法普及的历史转折。

### 神性/神格/神职/领域四载体（登神终极引擎）
- **神性值**＝半神力能量存量，主降神属性减免、可击杀抽取、可吞噬（斩苏恩吞神性夺领域）。分级刻度：微弱神性（约10-15值）→弱等神性（30值上下）→中等神性（突破100值）→强大神性（神格值693，终卷）🔒。V7_B2：微/弱神神性10-15/30、依卓斯本源=弱等神力30点+🔒。
- **神格值**＝力量上限之钥与神格免疫来源（免疫即死/麻痹/睡眠/魅惑/变形/毒/疾病等，随神格等级依次开）；神格值上限受神性值制约；神格等级1约半径1公里感知、神格等级20为"盖亚意识"级🔒。
- **神职**＝权柄方向（产神力、养信徒、凝神格）。萧伯纳终卷执掌：**自然/植物/动物/死亡/猎杀/机运/传送门/诡术/灵能/血肉/疯狂** 等神职。
- **领域**＝能力兼职槽（可叠加，未全掌握标x/y）。已访问领域：**植物/猎杀/荒野精魂(荒野)/自然/死亡/生命/风/传送门/机运/保护/庇护/旅行/森林/创造/气候** 等。

### 变身形态线（德鲁伊核心战斗资源）
萧伯纳的变身是可进化的核心战力，按档位递进：
- 野兽形态：月影巨狼、巨龟、巨狮兽准传奇、霸王龙、树化三角龙守卫（野兽部属）。
- 神龙变化：**古红龙**（力42-44·龙威/龙息洗地/浴血喷吐，阶位随等级逼近上古红龙）→ **精魂龙·古苍龙**（力40+）→ **太古苍龙**（挑战31、力超60）→ **时光龙形态**（挑战60+、力量突破67·时间停止9环/操纵时间/时间奔流借未来6秒，先仅梦境之心可用，后全面掌握）。
- 精魂/幽冥形态：月影巨狼幽冥形态、精魂形态（镇魂/魂遁）、杀戮者（炼狱模板·力+8体+6敏+6·失施法）、圣者化身（荒野精魂神选·挑战30+·神力值300）。

## 七、这套书力量体系的写法规律（创作价值）

1. **机制可解释的越级**：每一境晋升都有可计算数值门槛（职业等级/挑战等级/神性值/神格值），每次爆种都能用面板核算。职业等级40后"每级=一类神力等级、每4级+1超凡神力专长"把神级成长也数值化。
2. **数值与叙事咬合**：击杀结算（装备/神性/领域/神职）直接并入剧情，面板结算点=剧情推进点；魔网、重铸星球等宇宙级操作也以环位/法术升阶核算。
3. **变身/领域/神职三线并行**：变身形态管战斗吃饭、领域管能力叠、神职管权柄经营——路径分化空间大。
4. **"力量为谁而用、代价是什么"**：斩苏恩吞神性夺领域却承受精神污染；灭世重铸星球耗星球生态——每次登神都标注情感与代价账本。
5. **CR即世界刻度**：敌人梯度与主角成长全程可视，挫败也量化（铁群岛沦陷、海军溃败），爽点与代价都有据可依。
