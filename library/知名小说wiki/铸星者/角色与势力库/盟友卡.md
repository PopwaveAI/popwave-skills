# 盟友深度卡（情感核心 + 神系中坚）

> 《铸星者》以萧伯纳建黄金椰枣→安息之国→自然神系为主线，盟友分「情感核心层」与「神系/神眷中坚层」双轨。

## 莎塔菈（女主/正宫 → 魔法之神道途）

| 字段 | 内容 |
|:--|:--|
| 定位 | 女主/正宫；前段富婆式慷慨的精灵宫廷法师→后段掌管帝国施法体系的魔法之神道途追随者 |
| 阵营 | 正派（精实多谋、交易感强） |
| 攀登方式类型 | 有资源型（精灵宫廷出身+传奇法师传承） |
| 等级坐标 | 传奇法师→职业24皇家大法师/窃法者🔒V6_B4 ch85 →（萧伯纳钦点）推举其登【魔法之神】神职 |

- **身份**：精灵裔大法师、窃法者、持有祖父遗物星辰卫士魔能装甲+母亲遗物秘银魔像（挑战22）🔒V6_B4 ch86。
- **成长弧**：从"宁可交易也不白给"的富婆，到长大并肩部队长，靠星辰卫士/湮灭球/时空长河预知能力屡建奇功；终卷被萧伯纳托付并扫平道路登魔法之神（V9_B1 ch7）。
- **关键战例**：弑伪神西蒙-达尔贡时以「时间复制术」（10环传奇·唯一瞬发传奇法🔒）+湮灭法球双杀圣者化身（V6_B4 ch98-99）；终焉之战干掉黑暗主脑一份。
- **情感线**：慢炖式正宫——萧伯纳握其手、多次"我会站在你这边"，精神契合伴侣终抱（V6_B4 ch100/V9_B1 ch7/V9_B2 ch38,48）。
- **叙事功能**：帝国所有"科技/魔法/计算"侧的唯一大脑；她把萧伯纳抽象而宏大的"自然道统"换算成可执行的城中事务所。

## 艾妮塞（东方舞姬·堕落/救赎双相·黑港暗势力线锚）

| 字段 | 内容 |
|:--|:--|
| 定位 | 前期黄金椰枣商业总管，中期因贪婪坠入暗渊魅魔化身，后期承东方舞姬遗产的救赎型盟友 |
| 阵营 | 中立→堕落→克制救赎 |
| 攀登方式类型 | 没资源型→亵渎恩赐（灵魂契约）→自体救赎 |
| 等级坐标 | 高手+东方舞姬（流沙之刃）→获得高阶魅魔形态（亵渎恩赐）🔒V3_B2 |

- **身份**：黑鸦镇富商，东方舞姬，商队头领，流沙之刃一族。
- **成长弧**：情报交易起家，因贪婪深入蛛影溪谷被卓尔伏击，向钢铁修女求亵渎恩赐获魅魔形态（每次使用肉/魂向魅魔蜕变，代价沉重）🔒V3_B2 ch130-131；黑港时期被希尔芙剥咒镇压恶魔印记，后期在暗渊/东方舞姬线寻求救赎与把控（V5_B1 ch3）。
- **情感线**：萧伯纳对其从信任到怜悯到"为她的灵魂留一条回头路"，终卷因其半神艾妮塞而留有救赎余地（V9_B2 ch38）。
- **叙事功能**：商业/贸易/商路线的负责人；暗渊-东方舞姬线的变数喉舌。

## 萨丽-月桂（均衡教派·自然平衡·黄金椰枣第二战力）

| 字段 | 内容 |
|:--|:--|
| 定位 | 均衡教派领袖、高阶德鲁伊；萧伯纳最核心的自然神迹执行者 |
| 阵营 | 正派（重自然平衡道统） |
| 攀登方式类型 | 有资源型（平衡道统+传奇天命） |
| 等级坐标 | 天命传奇大德鲁伊·挑战🔒24（均衡领袖）→黄金椰枣第二人 |

- **身份/能力**：天命之证「自然均衡」（将其与目标属性拉平+共享免疫🔒V6_B4 ch83）；取传古武器「森林长者」第一形态（传奇奇物🔒V7_B3 ch55）；主持萧伯纳多次自然晋升仪式。
- **情感线**：萧伯纳把传古武器刻意让给她、庇护其主持晋仪式——是"自然道统"与"理性底线"并重的灰色判官。
- **叙事功能**：自然平衡争论、德鲁伊教团的内部路线之争，都以她为首的均衡教派为出口；也是萧伯纳人性/神性锚点中最清晰的那根。

## 黄金椰枣（古树卫士·自然之灵·"种树点化神木"的答案）

| 字段 | 内容 |
|:--|:--|
| 定位 | 萧伯纳亲手净化+点化的传奇古树卫士，东方神木的最初闺蜜 |
| 阵营 | 正派（森林精魂） |
| 攀登方式类型 | 有资源型（被高等启蒙术点化） |

- **身份**：黄金椰枣圣居净化后，萧伯纳以高等启蒙术点化苏醒的第一株"同伴"，爱播种、爱生育、性孤独悲伤又天真。
- **成长弧**：一路从麾下无名之木长成支撑黄金椰枣/东方神木神迹的巨构，承「自然之灵+图腾之灵」双传奇专长🔒V3_B1 ch82。
- **叙事功能**："种树点化神木"母题的具体化；也是萧伯纳"万物有灵、皆可成道"价值观的招牌。

- **叙事功能**：萧伯纳"闯造性定义自然""文明启蒙"思想的神国落到实处的载体；也是贯穿全书的亲情化生命物（"嘤嘤婴语孩子气"）。

- **身份/成长**：从精魂狂热/精魂召唤（血爪）到烛阴选举/荒野神选（圣者形态），再到升星空、成盖亚意识——是与萧伯纳"双生双栖"的最长盟友（V3_B1/V7_B1/V9_B1）。

## 神系/神眷中坚盟友

### 李察德大师/禅达苦行者（东方守护·印玺交棒）
- **身份**：禅达·蔚蓝印记守护者、传奇武僧苦行者（职业40🔒？V7_B4只提…见V3_B1李察德≈40级）、贫穷誓约；多次现身救场与考察，最终把「神龙印玺」交付萧伯纳接任东方守护者（V8_B2 ch44）。
- **终卷**：以人类信念入魂，斩黑暗主脑；走「觉者·攀云僧」道途（V9_B2 ch50）。
- **叙事功能**：东方守护/神孽监管的道统长者——他塑成了「牧星者」晋升与「东方守护者」使命的合法渠道。

### 克里恩·杜（救赎者的回归）
- 禅达流放者→东方游侠兼苦行者立绿洲誓约→黄金椰枣救赎者天命传奇（V6_B4 ch104）；萧伯纳对旧兄弟的信任重拾与赎罪成全线。

### 高加索之狼（荒野之主·瘟疫行者的登神）
- 从霜巨人心脏交易（V1_B1 ch21）一路长大，晋「荒野之主」天命传奇（野性之力力敏体+8🔒V6_B3 ch78）、终局登【瘟疫行者·微弱神力】🔒V9_B2 ch34——萧伯纳麾下第一个真正"因哈随而凡人化凡"的登神者。

### 珍爱弟兄·苏纳斯-迅影（大德鲁伊五巨头·趋向）
- 迷失的旧德鲁伊，归来成德鲁伊五巨头之一；终卷成为野兽系真神🔒V9_B2。

### 嗜法者·阿莱葛莉（异种蓝龙·巨龙领地代理人）
- 跳反归顺敲打调教后接管巨龙领地/蓝龙龙脉军团，成为萧伯纳在东方的战略代理人（V6_B3 ch75,80-81）。

### 妙月-龙影殿下（震旦长公主·精魂龙）
- 授龙珠助借神龙变化如精魂龙·苍龙形态，镇杀神孽驰援，背后又有巍京龙庭联姻谋算（V7_B1/V7_B3 ch78-80）——东方龙脉线的重要盟友与潜在联姻对象。

> **盟友设计通则**：每个盟友都在护萧伯纳的自然道统/神职兑现（莎塔菈=神职兑现的计算侧、萨丽=道统执行、神木/荒野精魂=自然观归化、月神=庇护伞），从"养一棵树"到"养一整个自然神系"，情感线与登神主线双螺旋并进。
