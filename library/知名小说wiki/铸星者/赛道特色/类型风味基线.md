# 类型风味基线 · 《铸星者》

> 一句话世界观：**DND向多位面西幻·德鲁伊种田经营+封神登神+文明守护+外星终焉征战的复合风味**——《深渊主宰》诸神宇宙的"另一条命"上的重生物：陶土与神面上的尘世牧者萧伯纳弃"荒野之道"改立"牧星者"宏愿，从黄金椰枣一城粒沙开始种田经营、登神铸星，在远古夺心魔帝国/苏恩与黑色君王终焉战争的倒计时里，以"自然定义权"守护整片晶壁系文明，最终踏向"漫游者"神上神道途。

## 三大风味引擎（本书独有，同赛道基准力）

1. **种田经营即时反馈**——面板数值化+领地建设双轨兑现：黄金椰枣从腐化沙渊→神圣之地（ch3-81）、千湖沙漠一夜间升至（ch7-2）、金刚木+1军备批量成型、移民文明启蒙、66古树人群体启蒙（ch6-10）；每个基建节点=当刻的成长回报，把"经营"做成可感爽点而非背景板。
2. **自然定义权金手指**——"祂说是那就是了，最终解释权"（ch9-1）：拓荒自然道途（星空亦是自然）、重定义【自然】/【死亡】法则、把异变体/污化元素"定义为自然造物"，荒神/精魂神借泛精魂神系破信仰封锁；金手指=对世界规则的"定义权"，越到后期解释力越强。
3. **登神·神性经济+文明守护史诗**——神职/神格/神力三维独立经济+晶壁系存亡压力：从5级德鲁伊一路登神（微弱→弱等→中等→强大→伟大神性·神上神），同时被迫经营财政、外交、军备去对抗夺心魔帝国/苏恩/黑色君王终焉；把"个人登神"升格为"守护整片晶壁系文明"的史诗责任感。

> 衍生引擎：**多条进化伪躯/化身分工**——化身继承本体六成专长（V8_B1），本体经营×化身百战把爽点密度结构性翻倍；**东方泛精魂神系缝合**——酆都鬼门/奈河/烛阴/英魂军/人人如龙与西式DND无缝共存，构成同赛道最稀缺的"汉风西DND"标志。

## 类型门禁（防漂移自检清单）

- [ ] 数值是否量化且有🔒坐标，禁"很强/很厉害"悬空表述（职业等级/挑战等级/属性必须锚章节）
- [ ] 升级是否「可解释的越级」（用职业等级/神格值核算，不悬浮）
- [ ] 神名是否走神职尊号式（月之女士/受难之神，禁"X神X帝"中式直叫）
- [ ] 东部地名/神职是否用"西方DND语法"呈现（专名+通名/神职+位格），禁中式修仙黑话直接空降
- [ ] 种田经营是否有"面板可感的基建节点"反馈，而非只摆设定
- [ ] 登神是否与"文明守护"压力绑定，而非单纯个人开挂吊打
- [ ] 叙事是否含终焉倒计时/远古夺心魔帝国悬顶（燃素海/苏恩/黑色君王）
