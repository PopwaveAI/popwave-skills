# CP模板·人物与关系组装卡索引

> 定位：网文 CP 写作素材库——写人物张力、CP 关系推进、可套用素材清单、背景势力搭建时对号取用。
> 范式（v1，2026-08-27）：整体对齐 `../写作技法库/元素卡库/` 的「组装卡」标准——节拍序列为主体（每拍 = 拍义 + 填法标准），做法要点、线效果分栏；已去博主口播成分，纯技法文档。
> 素材性质：本库为全网写法素材整理，多来源，**非单书拆书、不设单书溯源**——所有内容可套用、可直接换壳进正文。

|---|---|---|---|

**全库硬规则**（任何主题不可缺）：
1. **可套用不溯源**：全网素材整理，内容要具体到能直接换壳，不伪造单书出处
2. **素材进戏**：素材/底色本身不是剧情，必须配人物目标与代价才有戏
3. **去口播**：全库零博主成分、零营销腔、零 HTML 视觉稿，纯技法文档

## 统一卡结构（v1 格式）

```
卡N【名】
适用（一句话：什么情境什么任务）
节拍序列/素材清单/搭建节拍（N拍，主体）：
  N. 拍名 — 拍义：填法标准（写什么才合格）
写法要点（一句品味约束）
线效果（一线一行）
素材性质（一行交代来源性质）
```

**用法三步**：选卡（按情境表对号入座）→ 落拍（主体是必答题，顺序可微调不可缺）→ 按拍义填料（现编，套自己的角色与语境）。

## 族间协同

1. **人设扬长族喂关系推进族**：先立住两张有张力的脸，再用推进族的阶梯趁势升温——脸谱提供张力来源，阶梯提供落点。
2. **素材清单族是通用料池**：40 梗/7 CP/8 前世今生这类清单可被任一族直接换壳取用，投一场目标与代价即进戏。
3. **架构搭建族是舞台底盘**：世家门阀/仙侠宗门为冲突提供"谁有资格、谁能改规则、谁担后果"的平台，供人设与关系书写站队线。
