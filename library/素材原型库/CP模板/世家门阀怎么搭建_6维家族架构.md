# 世家门阀怎么搭建·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写古言/家族文时搭一个"像门阀的家族"——给想把家世写成"宅子很大、族谱很长、权力只剩老祖宗一句话"的一屋子亲戚。取向：搭建框架型，先验维再填再验活。

## 用法（三步）
1. **选卡**：按搭建阶段/维度对号入座，六维各配一张卡，一格不许删
2. **落拍**：每个搭建维是必答题，逐一填充到能叫出姓名
3. **验活**：搭完必须用一场稀缺资源分配/危机事件（家主倒下）跑通全架构，检验"主角不在场它还会自己运转"

## 选卡情境表

**世家门阀底线**（3条硬规则，任何卡不可缺）：
1. 六维彼此兑换也彼此牵制——血缘给名分、官位给通道、财产付成本、婚盟扩网络、教育生产下一代、危机检验前五项有没有说谎
2. 每维必落到一个能叫出姓名的具体人物/机构/动作（不画几十个空名）
3. 故意留一处裂缝给主线（嫡脉有名无实/军功旁支进不了祠堂/女儿能管账却不能上族谱），人物一伸手，六张网同时收紧

## 卡1【血缘承继卡】
**适用**：立家族"谁算自家人、谁坐主位"——继承正名的地基，各房承不承认比宅子大小更关键。
**搭建节拍**（6拍）：
1. **划血缘边界** — 列清宗主/房头/嫡支/旁支/姻亲/门生，谁姓沈却已出继、谁能进祠堂议事（写进谱牒旧例，不模糊）
2. **分继承权** — 每支对主位的继承次序：嫡长孙离印最近，不等于拿得稳（名分不等于坐稳）
3. **分议事权** — 谁能参与议族：问谁、听谁、谁的一句话作数（议事名单即权力表）
4. **分资源份额** — 每支的田/钱/学堂配额：二房掌族学、三房管田庄、远支在边军领兵（一支一职）
5. **定担责义务** — 每支替家族担什么责：一指事、一支掌兵、一支交账（有权必有责）
6. **主位检验** — 继承人要接住各房愿不愿意承认的名分，不是接一处宅子（一接名分，各房反应落定）
**写法要点**：血缘边界要具体到人（谁出继/谁能进祠堂），不写"一大家子"。
**线效果**：权力线↑（主位之争）｜派系线（各房站位）
**素材性质**：势力设定框架，可按世界观换具体称谓（世家/门阀/宗族）。

## 卡2【官位权力卡】
**适用**：铺"人分到哪里"——把官位当护城河也是裂缝，别让全族挤在同一个衙门。
**搭建节拍**（5拍）：
1. **分派位子** — 把人分中枢/地方/军府/财赋/监察/清议六个口（一支一地，不叠加）
2. **架补位** — 一处被削/被调走，别处能接上：家族有换手腾挪的能力（留活口）
3. **埋猜疑** — 分权必带内部猜疑：中枢怕军功支系坐大、军中嫌主家只会写奏章（猜疑=派系燃料）
4. **算护族成本** — 官位越高，公开保护家族的代价越高：护了谁、明面上不能护谁（成本入账）
5. **标裂缝口** — 权力落点里点一处软肋：哪支手上有兵却进不了祠堂（这条专接主线）
**写法要点**：官位既是护城河也是裂缝，分位必带一句互相不信任。
**线效果**：权力线↑（补位与猜疑）｜派系线（支系对峙）｜主线伏笔（裂缝口）
**素材性质**：官场势力框架，可按朝代换官名/治所。

## 卡3【财产供养卡】
**适用**：铺"钱从哪里来、流向哪"——田庄商路是入口，钱要养回官位与声望，且有人管账。
**搭建节拍**（5拍）：
1. **列财源** — 田庄/商路/借贷/学田四处进项（一处一个具体名目）
2. **定流向** — 钱往哪去：养士/嫁妆/赈济/诉讼/情报/子弟教育（每笔定一个去向，不空"富可敌国"）
3. **设兑换** — 花钱换什么：养士换声望、赈济换清名、教育换下一代（钱与官位声望互兑）
4. **安管账人** — 谁掌账、谁审核、谁动得了族产（管账者=隐形权力者）
5. **标断链后果** — 钱一断会发生什么：婚约松/门生走/清名变笑话（断链=冲突入口）
**写法要点**：只写"富可敌国"没人管账，家族会显得很薄；钱流向必须串回官位与声望。
**线效果**：权力线（管账权）｜主线伏笔（断链后果）
**素材性质**：经济供养框架，可换产业名目。

## 卡4【婚盟外戚卡】
**适用**：铺"婚姻交换了什么"——一桩婚事至少换三样（通道/担保/风险），并给女性实权动作。
**搭建节拍**（5拍）：
1. **给通道** — 婚姻打开的路：借谁入局、谁能进哪处朝堂（通路具体到门）
2. **给担保** — 谁替谁站队：联姻即联合，站谁的一摊（担保=立场绑定）
3. **留风险** — 哪条承诺会在下次政变里反噬：共同担保的条款、收不住的手（风险=下次冲突）
4. **指账外线** — 不只洞房，婚书含钱/军/政条文：谁签字、条款内容（把婚姻写成会咬人的合同）
5. **授动作权** — 女性角色可传信/持产/举荐/翻约，给能改变局面的动作（权力不只在男身）
**写法要点**：给双方各一项想得到的东西，再各给一项最怕被对方握住的风险。
**线效果**：派系线（婚盟绑定）｜主线伏笔（反噬条款）｜女性线（实权动作）
**素材性质**：联姻利益链框架，可换朝代联姻对象。

## 卡5【教育声望卡】
**适用**：续"下一代怎么长"——家学不是全家背书，要筛选出能办事的人，且声望不压一个天才。
**搭建节拍**（6拍）：
1. **列筛法** — 藏书/老师/清谈/考试/军学/品评六种筛选方式（各定一种用途）
2. **分人才型** — 需要文名/实务/军功/社交多类人才，不只要好看的（门面+干事各有人）
3. **设实务考** — 子弟过关考题：能作文章 ≠ 会看庄账/叫得出各房主事名（考实事防花瓶）
4. **摊声望** — 声望不能压在一个天才身上，多家撑起门面（分摊防断档）
5. **定排位** — 考出来的子弟排到什么位子：谁去科举、谁入实务、谁掌差遣（筛选接官位卡）
6. **埋考卷伏笔** — 考册/庄账这类"纸上证据"留作验活时的翻案工具（接危机卡证据）
**写法要点**：门阀培养漂亮门面，也必须培养能办事的人；实务考是最好的筛子。
**线效果**：权力线（子弟排位）｜主线伏笔（考卷/庄账证据）
**素材性质**：教育筛选框架，可换科举/军学/品评具体制度。

## 卡6【危机验活卡】
**适用**：验活+制造矛盾——家主一倒，六维同时表态，全架构在这一场跑通；也把线收束或引爆。
**搭建节拍**（7拍）：
1. **起危机** — 引爆点：家主病倒/嫡脉绝嗣/朝局清洗/边军倒戈（一场逼全族表态）
2. **逼六维表态** — 血缘给名分、官位给通道、财产付成本、婚盟扩网络、教育出替手、危机验前五项有没有说谎（六张网同时收紧）
3. **看伸手指** — 谁会先伸手：嫡长孙取印、掌田契的三房不肯交账、定亲的梁家追问边粮（每个伸手者=一条线）
4. **留真规则** — 谁临时掌印、谁动族产、谁见皇帝、谁被牺牲止损——答案比家训更说明运作（写运作不写口号）
5. **设翻案工具** — 主角用已有证据破局：封账房/请房头族谱前验印/把联姻"共保边粮"条款摆上桌（调用财产/婚盟/考卷卡成果）
6. **问担责问题** — 一句兑到底："谁接家主之位谁签边粮军令，三个月粮不到他先入狱"（把争名分换成争担责）
7. **定主事者** — 选出肯在军令上落印、肯承担失败的人，不是最受宠或血缘最近者（收束+立新权力格局）
**写法要点**：夺的不是印，问的是"谁签军令谁担后果"——把争权戏替换成担责戏。
**线效果**：权力线收/重组｜派系线定盘｜主线引爆（裂缝兑现）
**素材性质**：危机实测框架，可换朝代职官/供需（粮/兵/女眷）。

## 族级硬规则（3条）

1. **六维同收紧**：一次危机让血缘/官位/财产/婚盟/教育/危机同时表态，六张网互兑互牵；写单维不写咬合=没搭起来
2. **具体物下脚**：每维必落到一个能叫出名的具体人物/机构/契约/账册笔账，不画几十个空名字
3. **留缝+用缝**：故意留一处裂缝（女儿不能上族谱/旁支进不了祠堂），人物一伸手六网收紧、剧情就动——裂缝是主线的入口，不是漏洞
