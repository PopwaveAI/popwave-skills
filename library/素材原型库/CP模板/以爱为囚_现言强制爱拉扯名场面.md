# 以爱为囚（现言强制爱拉扯名场面）·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写强取豪夺/强制爱关系的可套用名场面——从"女主被截停"到"男主交还选择权"的拉扯推进，适合强制爱文写僵在"男主一路发疯、女主一路受苦、场面很重关系却不走"。取向：可套用、可直接换壳进正文（换职业与筹码）。

## 用法（三步）
1. **选卡**：按下方情境表对号入座；名场面可从后往前反推（先定女主能做什么）
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准填入你自己的角色与语境

## 选卡情境表
| 情境 | 选卡 |
|---|---|
| 女主被截停/当众护短 | 卡1【变局反制卡】 |
| 被迫同居/同居变相处 | 卡2【反向合作卡】 |
| 冲突失控/关系要转折 | 卡3【主动停手卡】 |
| 想收服/给女主自由与尊严 | 卡4【兑现交还卡】 |

**强制爱底线**（3条硬规则，任何卡不可缺）：
1. **女主的拒绝必须改变真实局面**（改变成本），不能只负责刺激男主
2. **男主的越界必有具体代价**，不靠"太爱了"免责；停手由男主主动完成，修复先停止伤害
3. **女主保有事业、盟友、证据与离开后的生活**——终局交还选择权，自由先兑现，爱情以后谈

## 卡1【变局反制卡】
**适用**：女主被截停/当众护短——她暂时走不了，但让每次越界都更贵，并拒绝交出自我的归属。
**节拍序列**（5拍）：
1. **优势铺陈** — 先让男主展示真实资源优势：门是他关的、人是他带的、监控归他管（危险感要看得见）
2. **旧牌兑现** — 给女主角一张前文埋过、当场可兑现的牌：录音/见证人/董事会时间点/她能公开的证据（牌不必大，必须当场有效）
3. **拒绝改本** — 女主的拒绝改变局面成本：不必立刻赢，但让对方每次越界都更贵（若拒绝后什么都没变，就只剩单向受苦）
4. **收助不认属** — 收下帮助，不收下"我的人"：把外套叠好放回他手里、逐条公开证据、坚持"我有名字"（她可收救场，不收归属）
5. **换位定格** — 关系位置改变：称呼/规则/距离发生变化（他第一次在众人面前改口叫她的全名）
**写法要点**：强制爱真正好写的地方藏在不对称里——他能困住她的人，困不住她的判断；她暂时赢不了，却能让他的每次越界都更贵。
**线效果**：张力线↑（女主反制改变布局）｜关系线（称呼/规则换位）｜伏笔（牌需前文埋设）
**素材性质**：拉扯类素材，可用"优势—反制—换位"三件套型方法

## 卡2【反向合作卡】
**适用**：被迫同居/同居变相处——把"被迫同居"改写成一场期限明确的合作，看似低头实则反向利用。
**节拍序列**（5拍）：
1. **主动敲门** — 女主主动把被动局面改成有期限的合作：深夜拖箱敲门"我住七天"（这不是认输，是借势）
2. **先出条件** — 女主先提出条件：不进卧室/不碰手机/到期无条件放人，并留下书面记录与知情人（把权利落成凭证）
3. **借势查因** — 她借他的保护/监控/安保查真正的敌人，不归顺（反向利用，目标独立）
4. **距离交易** — 他得到她在身边的距离，却拿不到随意越界的许可：双方都拿到一点，也都觉得远远不够
5. **定格合作** — 用一句"现在，我们只是合作"把关系位置写死（不同意，不越界，各取所需）
**写法要点**：这个桥段好用在双方都得到一点又都不够——被迫同居不再是方便撒糖，而成了一场有期限、有证人、有目的的合作。
**线效果**：关系线（从属→对等合作）｜伏笔（她借来的保护=查真凶的暗线）
**素材性质**：反转类素材，可用"合作式同居"型设定

## 卡3【主动停手卡】
**适用**：冲突失控、关系要转折——整段强制爱最重要的一拍：停手。
**节拍序列**（6拍）：
1. **危险边缘** — 把镜头落在具体动作：挡门的脚/扣腕的手/逼近的距离（危险要看得见，不靠氛围渲染）
2. **不安抚** — 女主不安抚创伤，也不拿亲密交换安全，只说一句止步点（"你再往前一分，我们之间就只剩害怕"）
3. **停手主动** — 停手必须由男主主动完成：脚移开/力松掉/钥匙放回桌面（禁电话、助理或意外打断来救命）
4. **真离开** — 让她真的走：停手不能立刻换来原谅，她不回来（拒绝的第一次生效才是转折）
5. **修复对应** — 修复必须对应伤害：监控害人→撤权限/交日志/接受审查；事业被干预→归还机会与决定权（付出控制感/利益/名誉，不是几场自我感动）
6. **不邀功** — 男主的代价不是证明自己难受（跪/喝酒/发疯），而是证明他改了行为（她未必回，愿意坐下听完也算）
**写法要点**：停手比强吻重要——先让他的手真的松开、脚真的移开、她真的离开；修复的第一步是停止继续伤害，不是把自己淋病给她看。
**线效果**：关系线→（互信重建起步）｜张力线↓（压迫退场）｜承诺线（停止伤害）
**素材性质**：转折类素材，可用"危险边缘—停手—对应修复"模型

## 卡4【兑现交还卡】
**适用**：想收服/给女主自由与尊严——用把柄换自由，并把选择权真正交还，爱情以后谈。
**节拍序列**（7拍）：
1. **备好底牌** — 信任测试不赌命：提前安排证人/备份/无辜者保护再交筹码（她交的是筹码，不是安全）
2. **交出筹码** — 女主交出一个关键筹码（把柄/原件），逼男主在无外部威胁时暴露价值观：继续控制，或兑现她的自由
3. **选择兑现** — 男主兑现承诺：还文件/按开门锁/说一个"走"字（自由先兑现，爱情以后再谈）
4. **不留恋** — 她拿回东西不拥抱不回头；他提醒"备份别放同一个地方"（这是他第一次帮她准备离开自己）
5. **物件交还** — 把选择权落到物件与程序：护照/工作室钥匙/签好的解约书/撤销指令（交还敢要可触可见）
6. **他先离开** — 男主先离开，让女主独立决定：她回来/暂不回来/只接受合作都成立（自由先兑现，他不再跟）
7. **邀请非命令** — 赴约是邀请不是命令：只留一张展览邀请函"周五七点，你可以来，但别迟到"（他能接受她不选自己，她的选择才有分量）
**写法要点**：最后一场不再比谁更狠，而是看他能不能承受她不选自己——他明明还有能力替她决定，却放弃使用。
**线效果**：关系线→（从压迫长成选择）｜自由线兑现｜承诺线收（赴约是邀请）
**素材性质**：抉择类素材，可用"筹码兑现+交还选择权"模型

## 族级硬规则（3条）
1. **圈女主的动词**：若只剩哭/躲/求/被带走，给她补一个能改变成本的动作——拒绝必须制造真实后果
2. **圈男主的代价**：若只有买醉/砸钱/失眠，给他补一次停止、归还或公开承担——越界要有价码
3. **尊重不越界**：名场面后检查权限/称呼/距离/规则是否变化；女主保有事业、盟友、证据与离开后的生活，停手先停止伤害再谈亲密
