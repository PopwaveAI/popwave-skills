# 先婚后爱怎么写·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写"协议结婚→日久生情"式CP——从立约到重新谈约推进感情线的选卡与落步，适合先婚后爱文案卡在"婚后只剩同居吃醋、协议再也不影响剧情"。取向：可套用、可直接换壳进正文。

## 用法（三步）
1. **选卡**：按下方情境表对号入座；这是一条线性推进链，可一张接一张用满八步
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准填入你自己的角色与语境

## 选卡情境表
| 情境 | 选卡 |
|---|---|
| 两人刚坐定/婚后戏还没开 | 卡1【立约卡】 |
| 婚后第一波升温/想推进感情 | 卡2【合作破例卡】 |
| 矛盾爆发/人心偏移 | 卡3【冲突站队卡】 |
| 感情到位/要收关系线 | 卡4【重谈约卡】 |

**先婚后爱底线**（3条硬规则，任何卡不可缺）：
1. **婚约四栏必具体**（各有所求/禁止事项/公开义务/退出条件）——删掉"夫妻"身份剧情还能照样发生，这份婚约大概率只是同居许可证
2. **破例必有选择空间+现实成本**——禁发烧/醉酒/意外拥抱充数（第二天醒来一切归零）
3. **保护、牺牲、秘密保持双向**——终局必须保留拒绝权、事业目标与退出权

## 卡1【立约卡】
**适用**：协议刚签/婚后初期——先让两个人坐定，把这场婚姻谈成一笔双方都需要、也付得起代价的交易。
**节拍序列**（5拍）：
1. **各自所求** — 双方都离不开婚约的现实目标：她要保住母亲留下的工作室，他要已婚身份拿到家族项目的表决资格（目标要具体到"非结不可"）
2. **禁止事项** — 各自绝不准备交出去的东西：她怕再被家人替自己做主，他怕私人选择拖累整个团队（禁区要踩得进剧情）
3. **公开义务** — 对外必须完成的任务：每月共同出席一次家宴、重要场合统一口径（义务是"合作"的落点）
4. **退出条件** — 何时/如何结束：项目交割后离婚（截止日期要写具体，结尾要划掉它）
5. **边界履约** — 开局让双方准确履约：分房/按时出席/对外配合，回家后互不打扰；礼貌比互怼好用，因为每一次额外关心都会变显眼（列三条边界，给每条配一个未来必然触发它的事件）
**写法要点**：婚约越具体，后面的破例才越让人心动——四栏表会替后文制造选择（他该不该在全家前替她挡撤职？她要不要接受保护、会不会失去最看重的决定权）。
**线效果**：关系线（从合同起步）｜伏笔（每条禁区都是未来冲突的引线）
**素材性质**：立约类素材，可用"婚约四栏表"型方法

## 卡2【合作破例卡】
**适用**：婚后第一波升温——先看见能力，再允许好感发生。
**节拍序列**（6拍）：
1. **共同任务** — 任务要同时影响两个人的目标：家族宴会临时加投资答辩，她熟数据他懂表决，少一个人都过不了关（公式：同一结果+不同职责）
2. **必交权限** — 任务里有一次必须交给对方的权限：他把问题交还给负责人/在某一步让渡主导（合作时的信任起点）
3. **能力看见** — 心动点落在"这个人值得信任"：他公开场合不抢她的话，她明知能借婚姻走捷径仍把每笔账算清（能力/原则/选择比外貌特写撑长线）
4. **第一次破例** — 破例要小却有选择空间：协议外他本可离开，却留下来核一份有问题的授权书；没代签没命令，只把风险和证据摆上桌（分量来自"他本可不做"）
5. **递进秘密** — 第二次交出更难收回的：秘密必须改变下一步行动——她告诉他缺母亲留的原始账册，他承认拿不到资格团队会被撤（否则只是人物小传里的苦情资料）
6. **递进刻度** — 按轻重逐级递进：时间最轻→信息更深→利益更重→退路最难收回
**写法要点**：反例——每次危机都由男主解决、女主唯一作用是让他发现自己会心疼，双方谁也不能突然降智。
**线效果**：关系线↑（信任破例）｜伏笔（秘密=未来冲突引信）
**素材性质**：升温类素材，可用"合作—破例"递进型方法

## 卡3【冲突站队卡】
**适用**：感情已有底子但外力冲突——让利益真正相撞，再写站队。
**节拍序列**（5拍）：
1. **目标对撞** — 冲突来自双方目标：她查到泄密线索指向他家必须冻结合作，他若公开证据会失资格还连累无辜团队（争的是调查权/证据公开范围/谁承担后果，不是"为什么不相信我"）
2. **各自不能让** — 各有一件绝不能放弃的事：她不能为爱情放弃调查，他不能用丈夫身份接管工作室
3. **第三种方案** — 谈一次不会立刻消失的冲突：共同委托独立审计、各自交出一部分证据、接受结果可能先伤到自己的代价；解决后留下一**条新规则**（公式：目标相反+损失同等重要+解决后留新规则）
4. **挡权不替决** — 站队先交还选择权：他拒接笔，把文件推到她面前"负责人坐在这里，你问她"（不喊"我的人谁也不能动"，那仍是替她做决定）
5. **代价站队** — 偏爱分量来自成本：他公开承担拒签后果（失表决/失支持）；她也主动递解约书让他止损——双方都能离开仍愿找第三条路，关系才平等
**写法要点**：反例——误会只需一句话说清却靠不接电话拖十章；保护用"挡权+还选择权"而不是查手机/替辞职/切断社交。
**线效果**：关系线（站队落账）｜误会线禁用（冲突必须来自双方目标）｜伏笔（新规则）
**素材性质**：冲突类素材，可用"目标对撞—第三方方案"型方法

## 卡4【重谈约卡】
**适用**：关系到位、表白/收线前——用一场家宴写完"动作—代价—改约"。
**节拍序列**（4拍）：
1. **动作** — 他拒代签把文件交还，她拿出数据亲自说明撤换会造成的损失（两人都不借身份压人）
2. **代价** — 他失去家族表决支持，她必须接受独立审计；散席后她主动递解约书让他止损
3. **改约** — 她交出原始账册、他交出会失资格的内部邮件；六个月后重新坐回协议桌：保留财产独立/事业自决/离开权，只划掉结束日期
4. **关系新位** — 关系位置变更落账：各取所需→共享风险；替对方做主→共同做决定（告白可以很短，前面每一次有代价的选择才是正文）
**写法要点**：每一次压力到来，检查他们是否做出与开篇不同的选择；一场戏结束问三问——谁做了合同外的选择？他付了什么代价？结束后两人的权限/秘密/退路变了吗？
**线效果**：关系线收（重谈约）｜承诺线兑现
**素材性质**：收线类素材，可用"动作—代价—改约"三段式方法

## 族级硬规则（3条）
1. **四栏表是情感推进的引擎**：删掉"夫妻"身份剧情还能照样发生=同居许可证，一条栏都不能省
2. **升级只许走"有代价的选择"**：禁发烧/醉酒/意外拥抱充数，关系必须因选择而非意外前进
3. **双向与终局**：保护、牺牲、秘密必须双向；收尾保留拒绝权、事业目标与退出权，偏爱要落在有成本的选择里
