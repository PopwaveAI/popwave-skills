# 冷心人沦陷名场面（枯木逢春救赎梗）·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写冷心人/救赎线——从戒备松动到把春天写进余生的权限递进推进，适合冷心人感情线卡在"前一章谁都别靠近、下一章抱着人喊此生唯一"的跳变。取向：可套用、可直接换壳进正文（换旧伤/代价/多出的权限）。

## 用法（三步）
1. **选卡**：按下方情境表对号入座；这是一条权限递进链，按阶段一张张推进
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准填入你自己的角色与语境

## 选卡情境表
| 情境 | 选卡 |
|---|---|
| 沦陷初期/先写例外 | 卡1【松动例外卡】 |
| 护短送暖/求交互→求助 | 卡2【护短求助卡】 |
| 救赎单向/给予者太累 | 卡3【反向接住卡】 |
| 高潮喜欢/要收服 | 卡4【选择余生卡】 |

**冷心人沦陷底线**（3条硬规则，任何卡不可缺）：
1. **"冷"有具体来处，前段先写例外别写爱**：沦陷靠一点点交权限（伤口/真名/后背/求助权），不靠一场舍命相救跳变
2. **救赎必须双向**：救赎者有目标/边界/疲惫，冷心人也要回应对方，不能只负责被照顾
3. **偏爱必加代价、甜落长期选择**：每次靠近比上一次多交一项权限，高潮后生活习惯/未来计划真的改变

## 卡1【松动例外卡】
**适用**：沦陷初期/先写例外——冷心人最先交出的往往只是一点点权限，别急着写心动。
**节拍序列**（4拍）：
1. **善意先到** — 善意者见伤不进屋、不追问旧案，只留下必需品：药和绷带放门外/窗前的灯亮着（退开三步，给安全距离）
2. **允许例外** — 他第一次允许一件平时绝不允许的事：用她留下的药/绕道从她窗下经过/不立刻结清人情（善意者给的是选择，不是施恩）
3. **物件回转** — 例外被无声回应：空药瓶洗净放回门口/那盏灯熄了他站雨里等到天亮/银钱只收走一枚说余下等他愿意开口再还（回应落在物件上，不落话语）
4. **台词护线** — 台词仍守旧防线："明天还放这里。你不必见我""我只是确认你没出事""这笔账，先欠着"（话越疏离，做越越界）
**写法要点**：前段别写爱，先写例外——一个把善意当价码的人不会因一次拥抱忽然学会信任，最先交出的只是一点点权限。
**线效果**：关系线（允许被靠近）｜伏笔（每项例外都可续上一档）
**素材性质**：松动类素材，可用"善意—允许—物件回转"三拍型方法

## 卡2【护短求助卡】
**适用**：关系推进/护短送暖 + 要写冷心人真正的裂口——护短快过理智，承认自己也需求人。
**节拍序列**（5拍）：
1. **身体先动** — 嘴上仍冷，身体已先站过去：她跌下城墙他离得最远却第一个掠过去接住/当场把她的名字写在自己旁边/进山前拆掉所有会惊到她的铜铃
2. **细节记住** — 他连自己生辰都懒得记，却记得她怕什么（她幼时曾被铃声困在祭阵，他只听过一次）：偏心藏在只有他能给的关心里
3. **狼狈呼名** — 旧伤发作照例锁门硬撑，快散前不摸刀，扣住传讯符第一次完整叫出她的名字"来一下。只要你"（求助是冷心人真正的裂口）
4. **交后背** — 把唯一退路图/关键物件交给她，自己转身迎敌，这回没回头确认："你定路线，我跟"（过去连同行都留三分戒心）
5. **承认不会** — 沉默很久后没说"随便"、也没替两个人做决定，承认自己不会并开口求教："我不会过安稳日子。你能不能教我？"（交出的不只是秘密，还有处置自己的权利）
**写法要点**："来一下。只要你"比"我爱你"更适合冷心人——他把求助看成软弱、依赖看成把柄，此刻却愿意在最狼狈时让她看见。
**线效果**：关系线↑（护短泄底）｜信任线（交出后背/求助权）｜等待线（此刻她可走可不来）
**素材性质**：裂口类素材，可用"护短—呼名—交后背"型方法

## 卡3【反向接住卡】
**适用**：救赎单向/给予者太累——让救赎线平衡：给予者也终于可以累，他也学会接住她。
**节拍序列**（4拍）：
1. **读懂伪装** — 她总说自己没事、替所有人圆场，只有他看穿：把她从宴席带走/拆开她攥到发白的手指（"不想笑就别笑。我在这里，不用圆场"）
2. **替她守门** — 她病倒仍惦记外面的伤员，他坐门口挡住所有来求她的人，连最急的公文也自己处理："今天谁都不能拿你的命讲大义"
3. **允许后悔** — 她为救他放弃晋升、嘴上说不后悔，他却替她留好复职材料，把选择重新放回她手里："爱我不用拿前程作证"
4. **权利互还** — 她曾给过他拒绝的权利，他现在把同样的权利还给她：两个人都能脆弱，也都能接住对方（救赎有了这一笔才真正双向）
**写法要点**：救赎线走到这里，给予者终于可以累——冷心人也要回应对方，不能只被照顾。
**线效果**：关系线（双向救赎）｜等待线（选择权归还）｜平静线（同频的支撑）
**素材性质**：平衡类素材，可用"看穿—守门—还选择"型方法

## 卡4【选择余生卡】
**适用**：高潮喜欢/要收服——偏爱加上代价，甜落在长期选择里。
**节拍序列**（5拍）：
1. **偏爱加代价** — 高潮给偏爱加代价：只要签字指认她就能洗清旧案，他却把契约撕成两半，且不替她撒谎："该认的罪我认。没做过的事，也别往她身上放"（没有拿原则换爱情，只是拒绝踩着她回到岸上）
2. **站到人群** — 从从不参加庆功宴到第一次走到她身侧：她被迫接受联姻，他当众递出共同任务书"她的去处由她自己选。我只来给她多一个选项"（保护不替选，多给选项）
3. **不再拿命还债** — 敌阵需一人献祭，过去他会毫不犹豫留下，这回他把阵图摊开要求所有人一起改阵："我答应过她活着回去。诸位，换个解法"（愿意在清白/名声与她的命运之间重新选择）
4. **小余生落点** — "逢春"别只落大婚和拥吻，写一点很小的余生：独居杯悄悄换成一对"左边那只你的，别拿错"/每张路线图旁多一行归期、变故会主动报平安（变化藏在生活习惯里）
5. **允许伤口在** — 噩梦仍会回来、他仍会在深夜惊醒：她不急着抱，他缓过呼吸后自己伸手握住她"再坐一会儿。等我睡着"（伤口没凭空消失，变化在开始报平安/给屋里留位置/相信明天有人等）
**写法要点**：终点看的是他的长期选择而非高光告白——为了救她，他连自己的品行、归期和生活方式都一起改了。
**线效果**：关系线收（选择+余生落账）｜承诺线兑现｜平淡线（甜在长期选择）
**素材性质**：收服类素材，可用"偏爱加价—站队—小余生"三段式方法

## 族级硬规则（3条）
1. **权限递进，一步一交**：可替换权限＝伤口/真名/住处/后背/求助权/公开立场/归期/共同未来；每次靠近比上一次多交一项，换皮时一起换掉旧伤、代价与多出的权限
2. **救赎必双向**：救赎者有目标、边界与疲惫；冷心人也接得住对方——两个人都能脆弱，也都能接住对方
3. **偏爱必加代价 + 甜落长期选择**：高潮后检查生活习惯/未来计划是否真的改变（杯子/归期/报平安），不然沦陷只是嘴上说说；让他先交出一厘米，那一厘米写稳了后面的沦陷才站得住
