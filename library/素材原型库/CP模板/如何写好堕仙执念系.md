# 如何写好堕仙执念系·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写"为爱成魔"型仙侠CP，把堕仙写成清醒选择的因果斜坡，给写仙侠/重生/修真长线文的人。取向：可套用、可直接换壳进正文（聚魂→找回失忆爱人、生死簿→被篡改医疗记录）。

## 用法（三步）
1. **选卡**：按下方情境表对号入座；同一CP可连续用多张卡推进
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准填入你自己的角色与语境

## 选卡情境表
| 情境 | 选卡 |
|---|---|
| 先立堕仙底盘——昔日仙格×唯一执念、先见他神性 | 卡1【昔日仙格×唯一例外】 |
| 挖执念深层——把"爱"拆成愿望/恐惧/私心三层 | 卡2【三层执念】 |
| 写堕落下坡路——四次越界台阶，步步铺退路 | 卡3【四次越界】 |
| 写执念动作与失控名场面——做到不可挽回再开口 | 卡4【执念动作·名场面】 |

**堕仙执念底线**（3条硬规则，任何卡不可缺）：
1. 神性先行——先让读者见过他没堕落的样子（曾为众生克己），那次徇私才像裂缝而非换皮疯批
2. 越界台阶化——每次给他退路、他能停却舍不得停，堕落是一连串清醒选择不是无差别发疯
3. 偏执必改关系状态——一次越界至少留一个可见后果（她更怕他/开始防他/夺回选择权），爱不能免罪，狠话不能替代人物变化

## 卡1【昔日仙格×唯一例外】
**适用**：动笔前立堕仙底盘——先立旧秩序，再给他唯一例外，堕才有来处。
**节拍序列**（6拍）：
1. **昔日仙格** — 写他曾真心守过什么：大旱散灵引雨/雪夜护受伤鸟/宁损修为不拿凡人填阵——守戒有动作证明，自律才可信
2. **唯一例外** — 给不可替代的来处：一个人/一段旧约/一座已亡的城/一句没能兑现的承诺——例外越具体，越界理由越成立（可能是她替他挡过一场因果，或万人拜神时只问他冷不冷）
3. **设定公式** — 昔日仙格×唯一执念×越界选择×持续反噬——先写他曾守住什么，再写这次为何偏偏守不住
4. **机制轨** — 守戒→徇私→反噬：先立旧秩序，再画他的堕落路线
5. **追读钩子** — 定追读问题：他会为执念走到哪一步？她会不会接受这种"被救"？——钩子挂在"下一步越界"上
6. **翻车边界** — 若他登场就无差别发疯，读者只见危险不见"堕"在哪——必须先给下坡路

**写法要点**：堕仙不是变坏，是选择不断越界。先立旧秩序（因果不可逆/私情不凌驾苍生）并让他用行动守过，读者才会为他第一次徇私痛；他守戒非因冷漠，是太清楚力量失控的代价。
**线效果**：人物线（神性立住）｜主线（下坡路起步）
**素材性质**：设定底盘类素材，可用"昔日仙格×唯一例外"双元公式。

## 卡2【三层执念】
**适用**：挖执念深层——把"爱得太深"拆成愿望、恐惧、私心三层，越往里越不能只剩爱。
**节拍序列**（5拍）：
1. **表层愿望** — 把"我要她回来"立刻变成任务：聚魂/改命/偷生死簿/截天劫/养承魂身——目标能推动行动，执念才拽得动剧情
2. **深层恐惧** — 他怕的不是死，是再次承认自己无能为力：既怕当年没救下她的自责重演，也怕她醒来后不再需要自己——"保护"慢慢长成囚笼
3. **隐藏私心** — 她必须仍是旧日的她：转世者有新名字新爱恨新选择，他执意抹去，想复活的其实不是她、是自己不肯结束的过去
4. **三层分工** — 表层制造任务、深层解释失控、私心让关系产生反弹——不能只是同一句爱的扩写
5. **验收场景** — 让三层见证据：她亲手改旧习惯/烧前世遗物/直说"我不是你等的那个人"，他如何回应就是私心有没有被揭开的证据

**写法要点**：她一旦拒绝被还原成旧人，他的"救"就第一次遭遇真正审判。关系变化要写出来：她从"被拯救者"变成"审判这场拯救的人"，他第一次发现复活一个人不等于有权替她决定余生。
**线效果**：关系线（被救→审判）｜私心线（占有显形）
**素材性质**：执念结构类素材，可用"表层愿望×深层恐惧×隐藏私心"三层公式。

## 卡3【四次越界】
**适用**：写堕落下坡路——用四次选择或台阶，每次都有退路、能停却越停越舍不得。
**节拍序列**（6拍）：
1. **一次留残魂** — 他骗自己只为替她收尸——代价很轻，只违一条不得扰亡魂的戒律；越界从这里开始
2. **二次借命灯** — 借无辜者命灯养魂，仍给自己留借口"只借十日事后会偿"——被借走的人开始忘记亲人
3. **三次改命数** — 她本可平安长大，他却毁掉婚约/师门/名字，只为逼她回自己身边——剥夺她的现在
4. **四次挡天劫** — 拿苍生替她挡天劫，走到这里终于不再辩解："天若不肯还她，他便让三界一起欠这条命"——越界到顶
5. **升级指标** — 堕落升级看三件事：伤及的人更远、借口更短、回头路更少——每阶对号自检
6. **神性反差** — 恶里留旧习惯：屠尽追兵却避开她怕的血、锁她入殿仍夜夜替她点凡间旧灯——矛盾比纯狠更扎心

**写法要点**：别开场就满级权谋/屠杀。每次都给他退路，他每次都能停、却一次比一次更舍不得停；越界越深，越界面对的是自己一手造成的捷径。神性没凭空消失，只是被他亲手浓缩成一个例外。
**线效果**：堕落线（四级下坡）｜反差线（恶里留善）
**素材性质**：堕落递进类素材，可用"留魂→借命→改命→挡劫"四阶公式。

## 卡4【执念动作·名场面】
**适用**：写执念如何进入他的身体/法术/习惯，以及失控名场面——先做不可挽回的动作，再让他开口。
**节拍序列**（7拍）：
1. **执念进身体** — 挑三四反复出现：记住无人会记的小事/把天地异象当她的病历/重复失败过的救法（同一座阵摆三百年）
2. **抹她命运** — 替她抹掉不喜欢的命运：未婚夫/师门/朋友一一离开，她以为是天意其实是他——占有最狠的形态
3. **收集遗物** — 收集她每一世的遗物：凡人的木簪/旧鞋/药方与仙器并排供在无人能进的殿中
4. **失控叫旧称** — 众人面前唤她今生姓名，只有神识崩裂时唤那声三百年前的小字——私心在失控处漏底
5. **名场面先选择** — 先做不可挽回的动作再开口：替她接下不属于她的天雷（把仙骨炼成替劫符）/藏魂殿现九十九世/她亲手划掉自己名字他捏碎仙印
6. **关系状态校验** — 一次越界至少留一个可见后果：她更怕他/开始防他/夺回选择权/或逼他承认自己所谓的保护已经伤人
7. **三问自查** — 写前自问：这一场是谁做了选择？谁承担损失？谁因此改变下一步行动？答不出来，就先别加更狠的台词

**写法要点**：别总靠掐脖子证明偏执。执念越具体、角色嘴上的否认越有用；名场面先写选择——角色一旦做出会改命的动作，情绪自然追上。终局校验：结局不是"他够惨了吗"，而是伤害有没有被看见、责任有没有被承担、她是否仍握着拒绝的权利。
**线效果**：执念线（进身体）｜关系线（状态必变）｜反噬线（代价追债）
**素材性质**：执念动作库类素材，可用"记忆/异象/旧物/旧称"四种执念具象+名场面先择结构。

## 族级硬规则（3条）
1. **神性先行，偏好危险**：先写他守住众生，读者见过他的自律，第一次徇私才会像裂缝；登场就疯=读者只见危险不见"堕"
2. **越界台阶+持续反噬**：四次选择给退路、能停却舍不得停；仙骨裂/功德散/故人惧的代价逐页追债，不能只在结尾补一场雷劫
3. **偏执必改关系状态**：爱不能免罪——他是该占有、放手还是偿还，终局要落一个明确回答；她可以仍爱他也可以拒绝原谅，男主受苦不能自动兑换她的同意
