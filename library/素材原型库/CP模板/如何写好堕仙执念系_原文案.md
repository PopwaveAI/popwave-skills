# 堕仙最痛的一步，不是失去仙骨

诛仙台落雷那一夜，所有人都以为他是被天道逼成魔的。

只有他自己知道，最后一道天雷落下以前，山门还为他留着。他只要松开怀里那个女子，回头走三步，仍是受万人敬仰的仙君。

可他没有回头。

写堕仙执念系，最关键的不是让角色穿黑衣、长魔纹，也不是让他说几句“我愿为你屠尽三界”。真正的堕落必须是一连串清醒的选择：他知道规矩为什么存在，知道越界会伤到谁，仍一次次把例外留给同一个人。

所以，写他的堕落之前，要先让读者见过他的神性。

他曾经在大旱之年散尽灵力引雨，曾经为了不惊扰一只受伤的鸟，在雪里站了整夜。他守戒并非因为冷漠，而是太清楚力量失控会带来什么。这样的人后来第一次徇私，才会真正刺痛。

第一次越界应该很小。也许他只是隐去她身上的一缕妖气，让搜山的弟子从门外经过。他告诉自己，她还没有害人，救她不算违背戒律。

第二次，他开始改动证据。她被指认为灭村凶手，他明明察觉口供有缺口，却先替她毁掉了最不利的一页卷宗。理由依旧正当：他只是想多争取三天，等真正的凶手现身。

第三次，代价必须落到无辜者身上。为了救她，他挪用了镇守山河的法器，结果封印松动，妖潮入城。那一刻，他不能再说自己只是在救一个清白的人。他已经让众生替自己的执念付账。

第四次，要给他最后的退路。掌门把剑放在他面前，说只要亲手封住她的灵脉，过往仍可赦免。他看见身后死去的人，也看见她眼里的拒绝。然后他折断了剑。

到这里，堕仙才真正成立。天罚只是结果，选择才是下坡路。

他的执念也不能只有“爱”。外层是救她，中层是害怕再次失去，最深处往往藏着一句他不肯承认的话：只要她还需要我，我就仍是那个正确的人。于是，救赎会慢慢变成占有。他封住她的记忆，替她决定去处，甚至把所有危险都变成她无法离开自己的理由。

这也是为什么女方不能只负责被救。她要看见他的代价，并对这种代价作出判断。她可以心疼他，却不能因为心疼就接受被囚禁；她可以爱他，却仍要问一句：“你救的是我，还是那个不能失败的自己？”

名场面最好让动作先发生。比如，他为护她劈开镇妖塔，却在塔门倒下后发现，被压住的不是仇敌，而是曾经最信任他的弟子。别急着让他说狠话。让他先伸手，想扶起对方，又在听见她咳嗽时转身。这个转身，比一百句为爱成魔都更狠。

终局也不一定非要让他死。真正完整的结局，是让他再做一次选择：继续用天下证明自己的爱，还是停下来承认，爱一个人并不等于拥有替她决定一切的权力。

诛仙台的雷停以后，她也许没有跟他走。她把断剑放回他手中，说：“仙骨碎了还能重修，选择错了，只能一件一件还。”

堕仙最痛的一步，从来不是跌下神坛。是他终于看清，那个把自己推向深渊的人，一直都是他自己。
