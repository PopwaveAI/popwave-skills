# 如何写好禅意和尚x妖艳妖妃·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写"戒律×欲望×权谋×双向救赎"型禁忌CP，给写古言宫斗/佛门与权贵CP的人。取向：可套用、可直接换壳进正文（袈裟红裙→任何身份对立CP）。

## 用法（三步）
1. **选卡**：按下方情境表对号入座；同一CP可连续用多张卡推进
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准填入你自己的角色与语境

## 选卡情境表
| 情境 | 选卡 |
|---|---|
| 立底盘——他要守什么、她要抢什么、共谋什么 | 卡1【双人真源】 |
| 写张力递进——四次靠近、步步改写边界 | 卡2【四次靠近】 |
| 把"欲"写进细节——视线/触碰/称呼三锚点 | 卡3【欲望落细节】 |
| 写她主动 + 破戒名场面——公开付出代价的那刻 | 卡4【她主动·破戒名场面】 |

**禅意和尚×妖艳妖妃底线**（3条硬规则，任何卡不可缺）：
1. 反差别停在衣着表情——给两人各自目标、手段与不会为恋爱让掉的东西（他有愿要守、她有局要破），禁忌感不在"能不能爱"、在"爱了之后谁来承担后果"
2. 张力要一寸寸长——靠近按"判断→权限→身体→公开"逐级改写边界，别一见面就失态；每次破例必有价（名声/戒籍/权位/证人或一城安危）
3. 双向救赎——她保持拒绝/离开/判断的能力，他动心仍把选择权还给她；两人都改变、都为旧选择付账，不能写成"他渡化她"或"她勾引他"

## 卡1【双人真源】
**适用**：动笔前立两人底盘——确认他要守的愿、她要抢的局，和他们非合作不可的事。
**节拍序列**（6拍）：
1. **他的愿** — 他要守的不是清白，是愿：护寺中流民/止住兵祸/查清皇室借佛敛权——戒连着责任才有重量，不是抽象戒律
2. **她的局** — 她要抢的不是宠爱，是生路：扳倒外戚/保住族人/夺回被皇帝拿走的姓名——美貌是盔甲也是武器，能记住朝臣酒量、宫人亲眷、皇帝翻脸前的小动作
3. **共同底子** — 两人都被误读：他被人供上神坛、她被人钉在祸水柱上——第一次同频来自"我知道你不只是传闻"
4. **共同任务** — 一桩不干净同盟：他有密道与民心、她有宫门与证据——救人要合作，合作就要互相交出软肋，谁也绕不开谁
5. **有价破例** — 每次靠近都要有可见代价：名声/戒籍/权位/证人或一座城的安危——破例之后关系不能原地归零
6. **关系公式** — 慈悲戒心×求生欲望×政局共谋×有价破例——一句话记住：禁忌感不在"不能爱"，在"爱了之后谁来承担后果"

**写法要点**：她为什么艳、为什么狠——不能只因为美，而是深宫活了十年知道温顺换不来怜悯，把美貌当刀、把轻佻当让敌人低估的诱饵；他守的不是抽象戒律，是原型（少年见过战乱）里"欲望一旦被奉为正义，最先受苦的永远是无辜者"的判断。
**线效果**：人设线（有愿有局）｜主线（共谋软肋互换）
**素材性质**：禁忌CP底盘类素材，可用"守愿×抢生路×共谋×有价破例"四元公式。

## 卡2【四次靠近】
**适用**：写张力递进——四次靠近、四次改写边界，例外先发生在判断/权限/选择上。
**节拍序列**（6拍）：
1. **试心·改判断** — 她故意靠近，他只问她手腕疼不疼——先看见镯下勒痕，不接挑逗先见伤；她第一次发现美色不必表演到底
2. **共谋·改权限** — 他把寺中暗门交给她，她借暗门送走宫女，他因此被同门怀疑——信任从一句判断变成可追责的权限
3. **失衡·改身体** — 她替他饮下皇帝赐的酒，他扶她回廊、手始终隔着一层袈裟——越克制越显得那一步碰不得
4. **破戒·公开** — 他当众认下藏匿妖妃的罪——失去清名不是爱情奖章；他要先救人、止乱，再决定自己配不配穿这身僧衣
5. **升级指标** — 四级升级看三件事：距离更近、代价更重、下一次再也装不回陌生人
6. **动心仍还权** — 他的克制是真正的克制：每次破例经过判断、也愿意承担名声与身份代价，且他把选择权还给她

**写法要点**：别一见面就让他失态。例外先发生在判断（他先看伤不挑逗）、权限（交出暗门）、选择（公开认罪）上，最后一层才到身体；台词越硬、身体越放软，克制才不油腻。
**线效果**：张力线↑（每级一改写）｜代价线（破例显形）
**素材性质**：张力递进类素材，可用"判断→权限→身体→公开"四级边界公式。

## 卡3【欲望落细节】
**适用**：把"欲"写进细节——视线/触碰/称呼三个锚点反复用，越具体越克制。
**节拍序列**（6拍）：
1. **视线** — 他从不盯着她的唇，却记得她每次说谎前会抿一下——换三种唇脂他不评价，她唇角破一道口子他诵经错了一字
2. **触碰** — 每次触碰都有正当理由：把脉/挡箭/渡河/换药——碰完便收手
3. **称呼** — 身份决定距离：娘娘/施主/真名/你——公开时叫娘娘、独处守施主，直到她要赴死、他第一次喊出她被夺走的本名
4. **克制证据** — 想碰而不碰、想问却先忍住、想留下却把路让开——克制不是木头
5. **停顿半息** — 他碰完便收手，她这一次却没有顺势逗他——停顿半息，比多写十句呼吸灼热更有分量
6. **每收手亮差点做** — 每一次收手，都要让读者看见他"差点做了什么"——欲望经历不计较

**写法要点**：欲望越具体，角色嘴上的否认越有用。语气对照——假禁欲是"嘴上念经、见她就失控"（戒律只延迟亲密，无信念无代价）；真克制是"他动心，仍能把选择权还给她"（每次破例经判断并付代价）。
**线效果**：情欲线（克制外溢）｜细节呼应（称呼显形）
**素材性质**：欲望细节类素材，可用"视线×触碰×称呼"三锚点公式。

## 卡4【她主动·破戒名场面】
**适用**：写她的主动选择，以及破戒名场面——公开付出代价的那刻，先让动作发生、再让情绪追上。
**节拍序列**（7拍）：
1. **停止试探** — 发现他真会为她受罚后，她不再拿身体逼答复，改用证据和条件谈同盟——主动把关系升格
2. **保留拒绝权** — 他愿带她出宫，她却先留下救被牵连的宫人——爱不是更换一个新的庇护者
3. **替欲望命名** — "我想要你"与"我要你救我"分开说——两种需要可同时存在，但不能混成一笔债
4. **为他守边界** — 他动摇时，她把佛珠放回他掌心："想清楚再来。别拿后悔偿我。"——她也在护他清醒
5. **自己的终局** — 无论他还俗/留寺/战死，她都要完成揭案/安置旧部/拿回姓名这条人物线——她的完整不依附他
6. **破戒先动作** — 名场面先让动作发生再开口：雨夜她把佛珠绕上他的腕、佛前验伤他撕半幅袈裟、宫门口他当众喊出她的真名——一次公开站队往往比吻更重
7. **双向照见** — 他学会承认私心，她学会不拿伤人护身——两个人都改变、都为旧选择付账，不是单向渡化

**写法要点**：别把妖妃写成等他渡的祸水。双向救赎不是一个人拯救另一个，是两个人都阻止对方以爱为名走向自毁；她爱得热烈仍保留离开能力，她可以拒绝被藏进寺里、可以在他独自担责时拆穿他的安排。
**线效果**：关系线（双向对等）｜公开站队（名场面）
**素材性质**：双向救赎+破戒名场面类素材，可用"她主动五步×破戒先动作"型公式。

## 族级硬规则（3条）
1. **有价反禁忌**：每次破例要付出可见代价，禁忌感来自"爱了之后谁来承担后果"而非单纯"不能爱"
2. **边界逐级改写**：靠近按判断→权限→身体→公开四阶升，别一见面失态；克制靠"每收手亮出差点做什么"落具体
3. **双向不对等不成立**：她有拒绝离开的能力、他有把选择权还她的自觉，两人都为旧选择付账——否则必写俗成渡化或勾引
