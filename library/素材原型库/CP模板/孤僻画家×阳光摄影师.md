# 孤僻画家×阳光摄影师·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写"害怕被看见×坚持温柔观看"型治愈系CP，给写现言/文艺向"小太阳与阴郁男主"的人。取向：可套用、可直接换壳进正文（职业/创伤/场景可换）。

## 用法（三步）
1. **选卡**：按下方情境表对号入座；同一CP可连续用多张卡推进
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准填入你自己的角色与语境

## 选卡情境表
| 情境 | 选卡 |
|---|---|
| 先立两人底盘——双方都不是"温差贴纸" | 卡1【双人底盘】 |
| 把心动拆成视线动作——取景/避让/许可/回望 | 卡2【视线动作】 |
| 写感情递进——从不入镜到主动站进她的光 | 卡3【四阶递进】 |
| 写一场雨夜名场面——用"未按下的快门"收束 | 卡4【雨夜名场面】 |

**孤僻画家×阳光摄影师底线**（3条硬规则，任何卡不可缺）：
1. 双向——她的阳光要照见他的边界，他的沉默要变成真实行动；不是小太阳强行改造阴郁男主，两边都是人
2. 边界动作链必出现——看见边界→停下→等许可→把选择权交回去；删掉"孤僻/阳光/治愈"仍能从许可、作品、误解和选择里认出他们
3. 越近越付代价——创作伦理/公众目光/私人边界一起进场，HE也要留痕：爱不替职业伦理、创伤与道歉一键结账

## 卡1【双人底盘】
**适用**：动笔前立两人底盘——性格反差只管第一眼，真正相爱的是观看世界的方式。
**节拍序列**（6拍）：
1. **他为何孤僻** — 不是"天生厌世"，而是曾被评价/窥探/消费，因此把画室变成边界——他怕的不是人，是失去解释自己的权利
2. **她为何阳光** — 不是永远快乐，而是习惯主动找光、走近陌生人；镜头背后也藏"只有记录才不会失去"的焦虑，收起相机会有几秒不知把笑放哪
3. **共同内核** — 两人都在凝视：他把感受变成画、她把瞬间变成照片——区别是他向内挖、她向外追，方法相反、心里的焦虑却互相听见
4. **核心冲突** — 她想拍真实、他拒绝被取景；他想画她无人看见的一面，她却害怕镜头外的沉默
5. **各有自保** — 她是"记录才不会失去"的焦虑、他是"守画室才保有解释权"的边界——两个自保方式相反
6. **CP公式** — 边界感×好奇心+相似的创作执念+相反的自保方式

**写法要点**：别让他们停在"一个冷一个甜"的贴纸。她的好不来自永远快乐（害怕失去才不停拍），他的孤僻也不只是讨厌人（曾被人拿未完成作品换名声，可怕的是失去解释权）。共同点在创作里，一个向内、一个向外。
**线效果**：人设线（双人完整）｜冲突基因（看与避）
**素材性质**：治愈CP底盘类素材，可用"都是凝视者×自保方式相反"型公式。

## 卡2【视线动作】
**适用**：把抽象心动拆成具体视线动作——取景、避让、许可、回望，别写"她治愈了他"。
**节拍序列**（7拍）：
1. **远景镜避** — 她拍整条旧巷、唯独绕开他窗前那一格；他后来却把那块空白画进画里——小心思落进作品
2. **近景互记** — 他不看人、却记得她换镜头时会咬住镜头盖；她话很多、却从不问那幅被白布遮住的画——都记着对方、都没越界
3. **许可** — 第一次拍他，不是偷拍背影，而是把相机递过去："你决定留哪一张。"——把选择权给他
4. **回望他见** — 她习惯追着所有人的笑，只有他看见她收起相机后脸上那几秒无人负责的空——他看穿她的疲惫
5. **动作链** — 看见边界→停下→等许可→把选择权交回去——四步是靠近的准绳
6. **未按下的快门** — 雨后她举起相机对准亮灯窗，见他后退半步，缓慢放下——没有发生什么，但对一个长期防备凝视的人，这个停下来的动作比追上去解释更有分量
7. **长句示范** — "她看见了他的边界，也把选择权留给他"——用"停下"代替"解释"写心动

**写法要点**：程式中让作品先替两个人说话——她给的是外面的世界（同一时刻的光），他回的是自己眼中的世界（无署名小稿），合作越顺，藏起来的东西越容易露。动作链的核心是双向：她尊重他的拒绝，他也不能永远躲在拒绝里享受她的照顾。
**线效果**：动心线（未按的快门上膛）｜作品线（互赠暗语）
**素材性质**：视线互动类素材，可用"取景→避让→许可→回望"四步链公式。

## 卡3【四阶递进】
**适用**：写感情递进——从不入镜到主动站进她的光，每阶改变一次"谁在看/谁允许/谁先暴露"。
**节拍序列**（6拍）：
1. **Level1 误入** — 她为拍老建筑撞进他的取景范围；他冷脸遮画，她立即删掉误拍——留下边界感
2. **Level2 交换** — 她给他同一处景物的照片，他回赠一张没有署名的小稿——作品先替本人建立通道
3. **Level3 共创** — 她负责寻找将消失的街景，他负责补画照片之外的记忆——合作越顺、私生活越难躲（她发现他画里常有一块空白、像给某个不愿被说的名字留位置）
4. **Level4 越界** — 她作品遇争议时藏起笑，他第一次主动入镜替她作证；他旧作被旧事攻击时，她选择放下相机陪他沉默——轮到双方为对方越个人边界
5. **暴露度标尺** — 每阶都改变一次"谁在看、谁允许、谁先暴露"——用这三问自校是否真推进
6. **双向暴露** — 他主动站进光、她承认自己收起相机后并非永远明亮——爱把两人都带出旧的自保方式

**写法要点**：小太阳不是话疗（闯画室扯白布逼聚会=没有边界没代价），孤僻也不是持续甩脸（嘴硬毒舌伤人后突然心动=强行改造）。双人都要用选择推进关系而非靠标签自动相爱。
**线效果**：感情线↑（每阶改一次谁看谁）｜作品线（共创）
**素材性质**：感情递进类素材，可用"误入→交换→共创→越界"四阶公式。

## 卡4【雨夜名场面】
**适用**：写顶点名场面——街巷摄影展被指"消费他人"，他赶到闭馆后的展厅，9拍收束一段双向尊重的关系。
**节拍序列**（9拍）：
1. **空场** — 她独自拆展，把获奖照片翻向墙面（画面朝下）——先立她的选择
2. **到场** — 他淋雨赶来，却站在玻璃门外不敲——保持边界地出现
3. **误判** — 她笑说没关系，他看出她在咬镜头盖——他识破她的强撑
4. **冲突** — 他要撤下争议作品，她质问他凭什么替她决定——价值观碰撞
5. **刺痛** — 他说："因为我知道被人观看是什么感觉。"——他用自己的伤理解她
6. **反转** — 她拿出已签好的撤展书：争议照片昨晚就删了——她早就主动守了边界
7. **暴露** — 她真正难过的是无人相信她会主动守住边界，而非失去机会
8. **回应** — 他把从不外借的肖像画挂上，主动站进灯下、允许她写下两人的故事——把选择权交过来作答
9. **余波** — 她没拍这一刻，只把伞往他那边偏了偏——用行动而非快门回应

**写法要点**：钩子=表面争的是一张照片，底下争的是"你是否相信我有能力作出正确选择"。她删掉那张能一夜成名的照片没有犹豫，说明创作伦理与信任高于机会；他挂画回应，是"把选择权还给她"而非替她追机会。越温柔越无解，边界感本身就是这场戏的张力。
**线效果**：感情线（双向尊重收束）｜主线（创作伦理+信任立住）
**素材性质**：名场面模板类素材，可用"拆展→到场→冲突→双向让渡"型公式。

## 族级硬规则（3条）
1. **双向不成救赎**：她尊重他的拒绝，他也不能永远躲在拒绝里享受照顾；治愈不是谁拯救谁，是两边都拿回了被认真观看的权利
2. **边界动作链必出现**：看见边界→停下→等许可→交选择权——删掉"治愈"仍能从许可、作品、误解、选择里认出这组CP才成立（可用白布、垂下的镜头、没有追问、主动入镜四象验证）
3. **越近越付代价**：隐私/职业/表达/误解/控制/失去换着进场；HE也留痕——爱不替创作伦理、创伤与道歉一键结账
