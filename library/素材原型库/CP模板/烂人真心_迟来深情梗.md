# 烂人真心_迟来深情梗·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写"追妻火葬场/烂人觉醒真心"感情线，给写BE/开放式结局、要读者不原谅男主的人。取向：可套用、可直接换壳进正文（职业/伤害点/代价可换）。

## 用法（三步）
1. **选卡**：按下方情境表对号入座；同一CP可连续用多张卡推进
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准填入你自己的角色与语境

## 选卡情境表
| 情境 | 选卡 |
|---|---|
| 写他"烂"的地方——把伤害写实、不靠误导 | 卡1【把伤害写实】 |
| 真心觉醒后——先收走他依赖的特权 | 卡2【收走特权】 |
| 写修复——对准原伤口、付不可撤回代价 | 卡3【修复对伤口】 |
| 定结局——HE/BE都不动摇人物底线 | 卡4【终局权在受伤方】 |

**烂人真心底线**（3条硬规则，任何卡不可缺）：
1. 伤害是反复做出的选择，不是单一误会——他一次次把利益/体面/控制欲放在她前面，每次都有理由
2. 道歉要准确说出做错了什么，修复对准原伤口而非只会淋雨下跪；付出不可撤回的代价并持续改变
3. 复合权留给被伤害的一方——他真心（甚至真爱真改）≠她必须回头；她保留拒绝、离开和不原谅的权利

## 卡1【把伤害写实】
**适用**：写他糟糕的部分——把"烂"落到具体选择，让读者信他真心晚、旧账不能自动清零。
**节拍序列**（6拍）：
1. **越界具象** — 不写抽象"受伤"，写具体越界：替她决定工作/当众指认/把她排在所有人后面——填空：＿
2. **理由取暖** — 每次伤害给他一个体面理由：觉得判断更好/家族名声更重要/工作离不开而她一向懂事——理由让伤害像选择而非意外
3. **节点落定** — 缺席/伤害落到一个无法重来的节点：独自签字的手术夜/颁奖礼后台/渡口登基前——一次性扎深
4. **替身卑劣** — 若用"她像故人"开局，别用"后来是真的"覆盖最初利用——首因卑劣必须被正视
5. **名场面·烧婚书** — 他拿洗冤卷宗赶来低声想娶，她当着面烧掉婚书只留证据："谢你还我父兄清白。至于我，不在你的赏赐里。"——他办成她要的事，也看清她不需要他了
6. **迟来真相** — 他站台空了、船离岸了，才承认自己一路都在催她等——把"迟来"写成选择累积的后果

**写法要点**：痛苦只能证明他现在难受，不能证明旧伤已修好。淋雨失眠喝酒跪门画面好看，但说不清做错了什么，就只是向她讨一张心软通行证。"迟来"的重量在：他直到站台空了才承认自己一路催她等。
**线效果**：虐线（旧伤扎实）｜主线（烂人劣根立证）
**素材性质**：伤害设定类素材，可用"反复越界×理由取暖×节点扎深"型公式。

## 卡2【收走特权】
**适用**：真心觉醒后——别急着复合，先把他最习惯依赖的特权一处一处收走，让真心不立刻换到她的认真。
**节拍序列**（5拍）：
1. **不再被打动** — 他的偏爱不再能换她心软：发一条消息只换公事回复——从态度上先冷处理
2. **特权没收** — 他习惯依赖的照顾逐一收回：不再解释/不再等他态度/不再因他的好留下
3. **能力翻身** — 她长出独立：自己签合同、自己去复查、自己决定去哪；离开后她终于有了自己的名字（编剧/摄影师卖房远行）
4. **认真不对认真** — 他第一次认真，不该立刻换来她的认真——两头的节奏不能对等
5. **最刺一刀** — 最刺的不是恨，是她早已学会不再把他的态度当成生活的天气——彻底脱敏

**写法要点**：真心觉醒后先收特权的逻辑=从他以前一条消息她解释、如今只剩公事，从前她因他态度留下、如今自己拿主意。「最刺的一刀恰恰是她学会不把他的态度当天气」——她不是不爱，是已不需要他的爱作生存依据。
**线效果**：虐线（脱敏）｜成长线（她独立）
**素材性质**：关系切断类素材，可用"特权收回×独立翻身×脱敏一刀"型公式。

## 卡3【修复对伤口】
**适用**：写修复——补偿要能改善她的处境，却买不回她；对准原伤口而非只淋雨下跪。
**节拍序列**（6拍）：
1. **对准原位** — 伤害发生在哪里，修复就回到哪里：公开羞辱过就在人前还清白/拿走过署名就归还署名和收益
2. **撤销控制** — 用权力控制的就撤掉控制、接受她拒绝合作——不靠道歉，靠行为撤回
3. **不可撤回代价** — 付出不可撤回的代价并持续改变：交出官印/承担同罪追责/补齐分成——不能夜里跪一跪过关
4. **补偿不抵人** — 补偿能改善处境、买不回她：她接回证据/欠款/道歉，不等于接过他——修复不是感动交换
5. **相似选择重现** — 给他一次同样情境再选：当年为名声把她推到众人面前，如今真相曝光仍能把责任推给下属——这一次他当众承认伪证摘官帽
6. **改说"还我"** — 她在宫门外看完不扶他："今日这句话，是还我的，不是换我的。"——力气落在"换"字：改变没有奖品，她可以看见也可以不回来

**写法要点**：让他的补偿能改善她的处境、却买不回她——她可以收证据/收欠款/收道歉，这些本来就是他欠的；收下不等于收下他。一场戏改法：写清他曾在哪个节点选择伤害她，再让他回到相同节点做一次没有回报的新选择。
**线效果**：赎罪线（持续改变）｜主线（旧账对清）
**素材性质**：修复动作类素材，可用"对准原伤口×付不可撤回代价×相似选择重现"型公式。

## 卡4【终局权在受伤方】
**适用**：定结局——无论HE还是BE，都不动摇"他真心≠她必须回头"这条底线。
**节拍序列**（6拍）：
1. **改好不打扰** — 最高级的迟来是不再索取结果：他删掉煽情致谢、只承认旧伤害并补齐分成——"这次不是为了让你回来"
2. **替身付清** — 开局的利用要清偿：他付清费用、不再要求她替他的真心作证——她拆戒改胸针返还账单："你后来爱上的或许是我。可最先被你骗来的，也是我"
3. **清晰拒绝** — 她保留拒绝/离开/不原谅权：把应急联系人改回自己"我最怕的时候已经学会不找你了"；递回终止合作书"我原谅你，但我不回来"
4. **HE守底线** — 想写HE别让她被惨状打动：给足够长空白期，让他在无人注视时仍坚持改变、她有自己的事业关系判断；重逢她选的是现在的他，不是替读者验收赎罪
5. **BE不贬真心** — 想写BE也不用把真心写假：他可以真爱真改仍永远失去——真心负责刺痛，后果负责守住人物尊严，两件事不冲突
6. **五查自检** — 检查表五关：伤害是误会还是选择？道歉是否错得准？修复是否对准原伤口？是否付不可撤回代价并持续改变？对方是否保留拒绝/离开/不原谅权？

**写法要点**：HE与BE共用一条准则——他真心不等于她必须回头；迟来的深情有分量，靠的是认错、后果和持续改变，复不复合把选择留给被伤害的人。别让一场痛哭替他洗白。
**线效果**：结局线（HE/BE两轨都可）｜主线（底线守权）
**素材性质**：终局设计类素材，可用"真心+后果+持续改变"三件套公式。

## 族级硬规则（3条）
1. **"烂"要具体、要反复**：伤害=一次次可选却选错的节点，每步有理由——读者才信他不是一时糊涂
2. **修复大于忏悔**：对准原伤口、付不可撤回代价、在相似情境重选一次——哭着淋雨不算
3. **结局权在受伤方**：删掉万能痛哭，写清他何处选择伤害她、何处做无回报的新选择；她回不回头，最后再决定
