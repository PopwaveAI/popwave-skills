# 疯批帝王×清醒废后·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写"强者疯批×清醒无解"型高张力BE CP，给写古言/仙侠/豪门废后梗的人。取向：可套用、可直接换壳进正文（皇权冷宫→仙门废道侣/豪门清醒前妻）。

## 用法（三步）
1. **选卡**：按下方情境表对号入座；同一CP可连续用多张卡推进
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准填入你自己的角色与语境

**疯帝×废后底线**（3条硬规则，任何卡不可缺）：
1. 权力与心位必须倒置——他明强（主宰她身份生死）、她明弱，却要"能决定她住哪、却命令不了她重新爱上"，错位是张力来源
2. 双人都清醒——他疯只在失度处（朝堂极度理智、只对她偏执），她的冷是"看过后的退出"，不是懦弱受虐
3. 禁三条红线：禁女主二次沦陷、禁男主全员疯批、禁强行圆满和解——爱恨一旦重新对等，CP独有的错位就没了

## 卡1【五重对冲盘】
**适用**：动笔前立底盘——用身位与心位永远相反制造"他困住人、留不住心"的倒置感。
**节拍序列**（6拍）：
1. **身位悬差** — 写外在权力悬殊：他主宰生死，她被废去尊荣——先压下"能决定她去留"的力道
2. **心位倒置** — 反手写他管不了她：他能定她死活，却拿她的心意毫无办法——她反而主宰他的情绪
3. **状态对翻** — 他高居九重却内心荒芜；她跌到尘埃反而通透安稳——高处寂寞対低处安稳
4. **姿态错位** — 他对天下强硬、只对她失度；她对旁人温淡、只对他寸步不让——两份反常互为镜像
5. **宿命落点** — 他拥有世间一切、唯独得不到她的真心；她失去世间所有、唯独守住本心
6. **一句话判词** — 收一句定调："最高的权势，困不住最淡的人心"——全文判词锚点

**写法要点**：这对CP不能只靠"他疯她惨"；真正好看的是身位与心位永远相反。落宿命那句要能拆成标题/封面/结局判词反复回响。
**线效果**：主线（倒置张力立起）｜情感线（无解前提）
**素材性质**：关系倒置型设定素材，可用"外在强弱悬殊×内在主导倒置"型公式。

## 卡2【双人底盘】
**适用**：深写两人内在——帝王的疯批要失度不失智，废后的清醒要冷而不失骨。
**节拍序列**（7拍）：
1. **帝王·外** — 冷血、善制衡、杀伐果断——朝堂上必须理智得可怕，心理独白证明他从来不失算（他知道谁能用谁该杀、一纸诏书牵动多少兵）
2. **帝王·内** — 只对她偏执、惶恐、反复破例——一边伤害一边补偿，明知强求仍不肯放手
3. **失度证据** — 点出他为她破的唯一原则：权衡完利弊却在落笔前停一夜/下令封门又亲自问缺不缺炭——少一个都是按头
4. **废后·外** — 褪去凤袍不争宠不结党不诉苦——看似无所作为，其实主动退出他的棋局
5. **废后·内** — 不是不爱，是爱过痛过看透后彻底脱敏——身被宫墙困住、心已自由
6. **清醒证据** — 写她拒绝继续参加以爱为筹码的棋局：照旧吃饭看书养花、不打听前朝、不接受补偿买她回心
7. **称呼锚点** — 从前她叫"夫君"、废后后只剩"陛下"两字——称呼差是关系温度计，回不来即无解

**写法要点**：他"只对她失度"、她"身困而心不困"——少一个都写俗。疯批不是无脑发疯，废后不是软弱受虐，双人都清醒悲剧才成立。
**线效果**：情感线（旧称谓vs新称谓）｜主线（两人判断权位移）
**素材性质**：双人设定类素材，可用"皇上·外冷内偏执 / 废后·外礼内抽离"双层型公式。

## 卡3【四阶拉扯】
**适用**：写感情线递进——帝王尊严一层层落、废后的心一层层静，错位随阶梯加深。
**节拍序列**（6拍）：
1. **冷淡制衡** — 他人前冷漠、暗中偏袒；她以平常心接住他的阴晴不定——他暗流汹涌，她死水无澜
2. **偏执试探** — 他禁足、推拉、言语伤人后再补偿；她不接招、不解释，步步退出情爱棋局
3. **疯魔卑微** — 他放权、低头、许她凤位荣宠；她仍不贪温柔、也不拿他的悔恨疗伤
4. **宿命无解** — 他守她一生却得不到真心；她守住本心却终身走不出宫墙
5. **度差记账** — 他的尊严一层层落下去、她的心一层层静下来——两条线反向记账
6. **补偿掉价** — 他想补偿、错位越明显：送炭火药材旧书→翻案→还凤印，每一份都买不回当年那个等他回头的人

**写法要点**：不要开场就跪地求爱。四阶从"冷淡制衡"爬到"宿命无解"，每一层先让他付出更多代价再让她更静；补偿跟着掉价是这组CP独有的推理线。
**线效果**：情感线（递进无解）｜虐线（补偿掉价）
**素材性质**：递进冲突类素材，可用"他的主张层层降+她的心层层静"对轨型公式。

## 卡4【9拍名场面】
**适用**：写顶点场景——深夜冷宫，他带着凤印来求她重回中宫，9拍走完一场清醒拒绝。
**节拍序列**（9拍）：
1. **强者入场** — 宫门尽开，帝王带凤印与仪仗而来——先压他最强的姿态
2. **弱者反常** — 她不跪不喜，只合上读到一半的书——反常即不接招的开始
3. **先给诱饵** — 他许凤位、权势、替她洗净旧罪——把能给的都摆出来
4. **她不接招** — 她问："陛下想换回哪一年的我？"——问句顶回他，暗示还不了昔日承诺
5. **帝王失态** — 他捏紧凤印，第一次承认自己错了——全场唯一失态者是他
6. **旧伤见光** — 她说当年等过、后来便不等了——揭出他欠她最久的那段
7. **放下尊严** — 他低声求她，哪怕只装作从前——把最后的体面交出
8. **温柔拒绝** — 她替她扶正衣襟："不必了，陛下。"——最温柔的拒绝最无解（无赌气无等待追）
9. **余波落刀** — 凤印留下，人却再也没回到他身边——判词收束

**写法要点**：这场戏的张力=他拿出全天下都想要的东西，她只用一句"不必"证明他的最高权力已对她失效。越温柔越无解——不带恨、不赌气，她是真的不再需要了。
**线效果**：情感线（顶点拒绝）｜主线（权力失效+无解BE）
**素材性质**：名场面模板类素材，可用"强者送礼×弱者不接×尊严落地"型公式。

## 族级硬规则（3条）
1. **倒置优先，反差服务倒置**：权力/身位落差不只是站桩，要落到"他命令不了她重新爱自己"这种具体选择上，错位才有戏
2. **双清醒是命门**：他疯在失度处（极理智+唯她破例），她冷在退出处（不争不诉苦不等于接受）；一方沦为普通疯批/受虐都会塌
3. **无解来自"还不了"**：等名分/荣宠/公道都能还，却还不了当年那个等他回头的人；用镜头锚点（金殿vs冷宫、宫灯燃尽、凤印留人走）把判词砸进画面
