# 落难公主复仇系·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写"破碎强者×清醒复仇"型女主复仇线，给写古言权谋/宗门遗孤/豪门弃女复仇的人。取向：可套用、可直接换壳进正文（王朝→宗门遗孤/末世基地继承人）。

## 用法（三步）
1. **选卡**：按下方情境表对号入座；同一CP可连续用多张卡推进
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准填入你自己的角色与语境

**落难公主底线**（3条硬规则，任何卡不可缺）：
1. 先让读者见过她从前的荣光——旧日教养让今天泥泞有落差，也是她仍有分寸的来处
2. 复仇是取舍不是发疯——每一步要有信息差/筹码/后果，删掉"她很聪明她要复仇"仍能看懂她计划
3. 狠绝有界——对仇人精准清算、对无辜绝不牵连，靠守底线与仇人区分开（她变狠没变脏）

## 卡1【五重对冲盘】
**适用**：动笔前立女主底盘——确认她从哪摔、凭什么清醒、狠劲的边界在哪。
**节拍序列**（6拍）：
1. **昔日荣光** — 写她拥有过什么：宫宴礼序/边关舆图/粮道军心——必要时漏点教养（端酒腕骨稳、听到旧名停半拍）让泥泞有落差
2. **今朝泥泞** — 身份、亲人、故国尽失，必须活在卑劣人情里——先压"最低点"
3. **清醒隐忍** — 不靠侥幸不沉溺悲痛——低头是为了看清谁的鞋上沾着血，把羞辱换成信息
4. **狠绝有界** — 对仇人精准清算、绝不牵连无辜——她变狠没有变脏，这条边界让复仇变难也让她区别于仇人
5. **宿命缺口** — 第五层是宿命：她能夺回山河却夺不回旧日——"得胜无归"最疼
6. **一句话判词** — 定调："她学会了把人心放上秤，却始终不肯把无辜者算进代价里"

**写法要点**：破碎感来自落差（荣光vs泥泞）、强者感来自选择（清醒+有界）——两样要同时存在，才不是"换装黑化"。昔日荣光不是贴一层高贵，它解释她今天为何仍有分寸。
**线效果**：主线（复仇地基）｜人物线（风骨立住）
**素材性质**：破碎强者设定素材，可用"荣光×泥泞×清醒×有界"四元公式。

## 卡2【取舍技】
**适用**：写手段——她怎么收集筹码、借力、取证、设局，把复仇写成精准取舍而非发疯。
**节拍序列**（7拍）：
1. **藏锋潜身** — 用卑微身份藏住锋芒：罪臣之女/添酒丫头——身份越矮越安全
2. **假消息之钓** — 放半真半假的消息引两名仇敌互相猜疑——借力而非硬拼
3. **采样记忆** — 把环境变筹码：记三拨守卫脚步/换岗时辰/管家腰间铜钥/每个人的欲望弱点
4. **取要证少杀** — 只拿能撬动整条利益链的一页账——杀人解恨低效，拿证据才撬得动
5. **杀与留之择** — 一具尸体只能解恨，一张活人的嘴能撬开关上的宫门——留着比杀了有用
6. **作局剪羽翼** — 不再只求自保：主动设局让仇人失去羽翼/名声/退路，账页送进御史台
7. **每一笔记账** — 每次翻盘给她开一张账单：身体/身份/信任/底线/归处/关系换着付——爽点不轻

**写法要点**：读者要看的是她"舍掉什么、又坚持不舍什么"。判断标准——删掉"她很聪明、她要复仇"，仍能从信息差、筹码和取舍里看懂计划，复仇才可信。
**线效果**：主线（复仇推进）｜代价线（每次翻盘付一账）
**素材性质**：权谋手段类素材，可用"筹码收集×借力×取证×设局"型公式。

## 卡3【四阶成长】
**适用**：写复仇成长线——从活下来递进到得胜无归，每升一级失去一点原本的自己。
**节拍序列**（6拍）：
1. **蛰伏** — 先活下来：藏身份、忍小辱、记人情，把地形与规矩变成未来筹码
2. **博弈** — 开始借力：放半真消息引两方互疑，自己只拿走关键证据
3. **清算** — 主动设局剪仇人羽翼，让仇人失去羽翼名为与退路——仍不伤无辜
4. **归位** — 夺回权柄，也承认故国无法复原——胜利不是回到从前，而是带伤继续掌舵
5. **账单续计** — 每升一级付一账：身体不可逆伤/抹去姓名被当叛徒/利用真心者欠情债/爱她的人与她走上不同岸
6. **胜而无归** — 故宫可重开、旧人不归：曾梳头的宫女/教执笔的太傅/雪夜背她回宫的兄长都不会从"殿下"里走回来

**写法要点**：别开场就满级权谋。每升一级都要让她失去一点原本的自己——只写爽点会轻，复仇越向前、代价越要碰到她珍惜的东西。胜利越完整，那个空缺越清楚。
**线效果**：成长线（四级递进）｜代价线（得胜无归）
**素材性质**：成长递进类素材，可用"蛰伏→博弈→清算→归位"四阶公式。

## 卡4【上元宴9拍】
**适用**：写顶点复仇戏——她以罪臣遗孤身份赴仇人的上元宴，用一场低头换回多条信息，9拍走完。
**节拍序列**（9拍）：
1. **入局** — 她穿旧衣入宴，任众人拿亡国旧事取乐——先示弱
2. **刺痛** — 故宫旧曲响起，她认出母后曾改过的尾音——半拍尾巴是身份撕口，情绪只刺一下
3. **藏锋** — 她失手打翻酒盏，顺势跪下、像真的慌乱——把失态演成示弱
4. **取信** — 主动献上半条假消息/认错，用示弱换被害者位置——把低头换成筹码
5. **误判** — 仇人认定她怕死、无能，准她进入内院——放下风险
6. **取证** — 从镜中/银壶映照看清书案暗格，不立刻动手——先记位
7. **折返** — 先救被牵连的宫女，放弃最安全的撤退时机——守底线用一次"意外"
8. **落子** — 账页送出，同时引两名仇敌互相指认——一箭双雕
9. **余波** — 满城灯火，她独自把那支旧曲听完——胜利已寄好

**写法要点**：钩子=她看似一路被羞辱，其实每次低头都换回一条信息；唯一计划外的动作，是仍救了无辜的人。这场戏的力气落在那"折返"上——守底线反而找到旧曲乐师这条新路。
**线效果**：主线（复仇兑现）｜人物线（风骨在取舍中显形）
**素材性质**：名场面模板类素材，可用"低头×换信息×折返守底线"型公式。

## 族级硬规则（3条）
1. **先荣光后泥泞**：要读者信她复仇有分寸，先让她真拥有过体面；落差让今天的卑微与狠都有来处
2. **取舍胜于发疯**：删掉"她很惨/她很狠"仍能从选择、筹码、底线和代价里看懂她——复仇才不倚发礼包
3. **得胜无归是余韵**：不给复仇开免费完美结局，用"故宫可重开旧人不归"收束，胜利越完整空缺越疼
