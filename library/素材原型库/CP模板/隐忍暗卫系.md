# 隐忍暗卫系·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写"身份枷锁×禁忌心动×克制美学"型暗卫CP，给写古言仙侠权谋里的隐忍暗卫人设。取向：可套用、可直接换壳进正文。

## 用法（三步）
1. **选卡**：按下方情境表对号入座；同一CP可连续用多张卡推进
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准填入你自己的角色与语境

## 选卡情境表
| 情境 | 选卡 |
|---|---|
| 写暗卫人设底盘——四道枷锁先锁死他 | 卡1【四道枷锁】 |
| 写克制细节——别写"他很隐忍"，写停收藏退四个动作锚点 | 卡2【四动作锚点】 |
| 写感情递进——从尽职写到越界，四级台阶步步踩实 | 卡3【四级越界】 |
| 写一场押他的名场面，按9拍骨架填 | 卡4【9拍名场面】 |

**隐忍暗卫底线**（3条硬规则，任何卡不可缺）：
1. 强能力×低身份×禁忌心动×行为偏爱=有疼才能读；删掉"他爱她"这句话，读者还能从站位、取舍和后果里看出来——爱不用作者说
2. 每次偏爱都要开一张账单——身体/身份/信任/名声/自由/关系换着付代价，甜结局也不能让代价自动清零
3. 克制不写抽象情绪——用"停、收、藏、退"写动作，每次少做半步比反复写眸色一暗更有用

## 卡1【四道枷锁】
**适用**：动笔前扣住暗卫人设底盘——强能力配不自由，张力才有地方放。
**节拍序列**（5拍）：
1. **能力自由** — 刀快、判断准、能在混战里掌控生死——他有改变局面的能力，不是工具人
2. **身份不自由** — 命令高于意愿，站位永远落后半步——他没有选择关系的资格；奴籍/死契/门规/旧恩，至少一条写清楚能执行
3. **情感不自由** — 心动会被解释成逾矩，偏爱只能伪装成尽职——越爱越要像无情，情动必须藏
4. **姓名不自由** — 功劳归于主人，过错落在自己；活成一串代号，死后未必留名——活成一个不占空间的位置
5. **一句定调** — 收锚："他能在三十步外取人性命，却不敢在她回头时，多看一眼"——把能力与枷锁撞出反差

**写法要点**：强，不会自动变成张力。能做什么与不敢做什么同时出现，人物才会疼。奴籍死契门规要具体，不能只是作者说"他不敢爱"，要让规矩能执行。
**线效果**：人设线（四道枷锁锁死）｜张力线（能力×禁忌）
**素材性质**：设定底盘类素材，可用"能做什么+不能做什么"双轨公式。

## 卡2【四动作锚点】
**适用**：把"隐忍"落到身体动作——用停收藏退四个锚点让克制具体可感。
**节拍序列**（4拍）：
1. **远景（停）** — 众人因她退开，他却在她身后停住；不是贴身，永远隔着一臂——第一步停到位
2. **近景（收）** — 先替她试毒、清路、封窗，再把染血的手藏进袖中——做完立刻收，不邀功
3. **特写（藏）** — 伤口绷开时，指节只紧了一瞬；回话仍稳，刀鞘也没有碰响——疼到极致也藏住动静
4. **反差（退）** — 对敌一刀封喉，对她一句责问只回"属下领罚"——面对她永远退一步
5. **自检口诀** — 判断标准：停（位置停）→收（做完收）→藏（疼藏）→退（面对退），四个动作写克制——不用写"眸色一暗"

**写法要点**：写克制常用四个动作：停、收、藏、退。每次少做半步，比反复写"他很隐忍""眸色一暗"更有用。血滴在她看不见的地方，疼在她接不到的位置。
**线效果**：细节线（克制落地）｜情感线（偏爱藏在动作里）
**素材性质**：动作细节类素材，可用"远景停→近景收→特写藏→反差退"四锚点公式。长句套：廊下风急，他先一步按住被吹起的帘角，等她安稳跨过门槛，才把肩上那支折断的箭往里推了半寸，免得血滴在她看得见的地方。

## 卡3【四级越界】
**适用**：写感情递进——从守规矩写到越界，越界别太早，步步递进才值钱。
**节拍序列**（6拍）：
1. **Level1 尽职** — 按命令保护，动作精准，不多问一句；温柔全藏在顺手做完的小事里——只在本职里藏偏
2. **Level2 自困** — 开始回避目光、减少近身，却在危险来时比任何人都快——身体先于规矩动
3. **Level3 偏私** — 表面照章办事，暗中改掉一处名单、放走一个证人、替她藏下一项罪证——已经开始徇私
4. **Level4 越界** — 第一次拒绝她的命令：不是为了占有，是为了不让她去死——关系从主从变成对抗；这一步才越界
5. **暗记代价** — 每次越界开一张账单：身体/身份/信任/名声/自由/关系，每偏爱一次就记代价
6. **自检一句** — 他对她的偏爱：他违令调走两名同僚先把她送出火场再回去补缺口，事后不辩，因为供出调令来源会牵连她——删掉"他爱她"仍可读出来

**写法要点**：越界别来得太早——先让他守得住，后面那半步才值钱。递进看三件事：级别越高，伤及无辜越远、回头路越少、代价越重。
**线效果**：感情递进（守→困→偏→越）｜代价线（每次偏爱一张账单）
**素材性质**：感情递进类素材，可用"尽职→自困→偏私→越界"四级公式。

## 卡4【9拍名场面】
**适用**：写顶点名场面——她被指通敌，他奉命亲自押她入狱，按9拍走完一场暗卫克制戏。
**节拍序列**（9拍）：
1. **公令** — 众目睽睽之下，主人命他拿人——先给公开命令压场
2. **私情** — 他知道证据有假，也知道她怕黑——他心里先有私事，但不能说
3. **守规** — 照样上锁、押送，不替她求情——明面上按规矩来
4. **微偏** — 锁链扣松一格，火把留在牢门外——规矩之下留一丝余地，只有两人能感觉到
5. **误解** — 她问："连你也不信我？"——她开口点破关系错位
6. **失语** — 他不能说查案已惊动真正内鬼，说了会打草惊蛇——秘密咽回去
7. **暗行** — 夜里离城取证，伤重仍赶在天亮前回来——私下替她翻案
8. **代价** — 证据送到，他因擅离职守被废去职位——明账要付代价
9. **余波** — 她获释时，他已不再有资格站回她身后——代价最后收一刀

**写法要点**：这场戏真正的钩子——表面上他最冷，实际每个冷动作里都藏着一处保护；等读者回看，才发现他早把退路铺完了。克制的张力=明面上做一件事、暗地里做另一件保护，代价自己付。
**线效果**：名场面（克制极致）｜虐线（代价收束）
**素材性质**：名场面模板类素材，可用"明规→暗护→代价"结构公式。

## 族级硬规则（3条）
1. **行为证据是命门**：删掉"他爱她"这句话，读者还能不能从站位、取舍和后果里看出来——这是判断隐忍写成功的唯一标准
2. **偏爱必付代价**：每次偏爱开一张账单，身体/身份/信任/名声/自由/关系换着付；甜结局也不能让代价自动清零，只能说两个人一起承担代价
3. **克制写动作不写情绪**：停收藏退四个动作锚点，每次少做半步——"他能在三十步外取人性命，不敢在她回头多看一眼"，把反差说完就够
