# 隐晦吃醋怎么写·CP组装卡（v1）

> 素材性质：本卡为全网CP写法素材整理，多来源，非单书拆书，不设单书溯源。
> 版本：v1 · 定位：写暧昧期/感情线醋意——用动作逻辑把占有欲写出来，不做直白的冷脸/攥拳/质问，适合角色吃醋却不能说破、想让读者从一只越过桌面的手看见偏心。取向：可套用、可直接换壳进正文。

## 用法（三步）
1. **选卡**：按下方情境表对号入座；动作逻辑是一条递进链，可三卡连用完成一场完整吃醋戏
2. **落拍**：节拍是必答题——逐拍落位，顺序可微调，节拍不可缺
3. **按拍义填料**：每拍自带「写什么才合格」的标准，照标准填入你自己的角色与语境

## 选卡情境表
| 情境 | 选卡 |
|---|---|
| 第三人靠近/产生威胁 | 卡1【替代介入卡】 |
| 克制到了临界/想露馅 | 卡2【露馅找补卡】 |
| 醋意要落成关系变化 | 卡3【关系落地卡】 |

**隐晦吃醋底线**（3条硬规则，任何卡不可缺）：
1. **吃醋必须前后差**：平时不问今天偏问、平时礼貌今天话短、平时坐远今天挪近半寸——越界的那件小事才显偏心
2. **动作只属于这个角色**（换个人不成立）+ **嘴硬必配后果**（语言后退、行动靠近）
3. **写的是在意失守，不是控制有理**：越界有分寸，另一人保留拒绝与追问的权利

## 卡1【替代介入卡】
**适用**：第三人靠近/产生威胁——用"处理第三个人的东西"代替"处理感情"，完成吃醋的越界动作。
**节拍序列**（5拍）：
1. **钉边界** — 先把角色平时不管什么写清楚（基线）：不问行踪/不评朋友/坐得远/不替人做决定（这是后文越界的对照）
2. **第三人靠近** — 一个真正的威胁出现在现场：递酒/送簪子/约展/派起的任务（必须造成位置变化，不只是背景板）
3. **替代性介入** — 不处理感情，只处理"第三个人"带来的东西：挡下酒杯/改掉约定的展期/接回派走的任务（不下手于对方其人，下手于其物其约）
4. **嘴硬配后果** — 语言后退的同时行动靠近：嘴上说"随你"，手上却把共享文档截止时间改到周六上午，或散场时先拿走她的外套（语言在后退，行动在靠近）
5. **只用他会做的** — 动作要只属于这个角色：抢酒/改计划/接任务都源自他原本的性子，换个人不成立（读者从这只越过桌面的手看见偏心）
**写法要点**：醋意藏在一件不该由他做、他却抢着做了的小事里——他处理的是"第三个人"，却始终不处理感情，不问"你喜欢他吗"。
**线效果**：关系线↑（读者先见偏心）｜张力双曲线（靠近冲动↑ vs 身份顾虑↑）
**素材性质**：介入类素材，可用"边界—第三物—替代动作"型方法

## 卡2【露馅找补卡】
**适用**：克制到临界、想让醋意短暂失守——用称呼/动作漏出一个破绽，再找一个补。
**节拍序列**（5拍）：
1. **张力交汇** — 在靠近冲动与身份顾虑两线交叉处，安排一句嘴硬+一个越界动作（两条线同时拉满才最酸）
2. **称呼失控** — 平时叫全名的人物，在对方替她擦了酒渍/靠得太近时，忽然叫出小名：小名暴露亲密资格（失控不必吵架）
3. **失控要短** — 叫完自己先静一瞬，不挑明、不追问（那一瞬越短越值钱）
4. **事后找补** — 立刻恢复原语气"车到了"，或把那杯酒喝完装作什么都没发生：越想抹平，读者越知道那一瞬是真的
5. **越界分寸** — 只露一点"想要资格"的心思，不控制、不羞辱第三者、不擅自替对方取消约会（醋是失守，不是控制）
**写法要点**：最抓人的不是发火，是他多管的那一件事——全名到小名的变化，暴露的不是告白而是占有欲先于理智替她做了次选择。
**线效果**：关系线（亲密诉求泄露）｜伏笔（称呼变化=事后可被察觉的凭证）
**素材性质**：失守类素材，可用"临界—称呼失控—找补"模型

## 卡3【关系落地卡】
**适用**：醋意要落成关系变化——让对方察觉并反向试探，让关系第一次被两人共同看见。
**节拍序列**（4拍）：
1. **让她察觉** — 她捕捉到那瞬异常：那只手/那句改口/改掉的截止时间（她在场，心里有数）
2. **反向试探** — 她故意问一句戳破："你不是说随我？""那你改什么截止时间？"（试探要轻、要带笑）
3. **嘴硬松口** — 他仍嘴硬但有松口：拉开车门"是随你"，停一下补一句"怕你周一后悔"（承认一点，立场后退一步）
4. **共同看见** — 关系第一次被两人同时知道：他没告白，她也知道他已经知道——下一次靠近不可能再装成偶然（吃醋的任务完成了，不留原地当糖点）
**写法要点**：跨题材可换道具——古言替她换一支更衬衣裳的簪子、仙侠把送聘灵兽拦在山门外、职场把派给新同事的出差任务接回手里；身份/道具/代价都能换，动作的逻辑别丢：看见威胁→装作无关→多管一件事→短暂露馅→事后找补。
**线效果**：关系线↑（没告白却再也装不回偶然）｜误会线禁用（吃醋不是误会，是共同的懂）
**素材性质**：落地类素材，可用"察觉—试探—共见"三拍型方法

## 族级硬规则（3条）
1. **删掉"他有些吃醋"**：醋意靠越界动作成立，不靠形容词——换个性别/身份动作就不成立的，不算吃醋
2. **动作必须只属于这个角色 + 嘴硬必配后果**：平时不管的今天多管了，嘴上后退手上却往前伸一寸
3. **越界有分寸**：不贬低第三者、不限社交、不擅自取消约会；最好看的醋不是"你只能属于我"，是他明明没资格仍忍不住泄露一点想要资格的心思
