**全库通用基线**（沿用 `library/readme.md`，以下兜底约束本库适用）：
1. 单件≤15KB，超限拆分；frontmatter 带 read_policy（机器优先）
2. 无源不入库：每件知识能回答"凭什么这么写"
3. 采样留痕：带"书名+章节范围+件数+缺口"
4. 命名唯一、主题化；禁止 `_原文案`/`_HTML源码` 双文件冗余
5. 禁止百科式散文：agent 优先，分类维度=知识离写作的距离
