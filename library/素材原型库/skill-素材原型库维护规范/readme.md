# skill-素材原型库维护规范 · 内容目录

> 定位：`素材原型库/` 库的**建卡与维护规范唯一真源**（强门禁 SKILL v1.0.0）——三个子库各产什么卡、卡片什么规格、按什么 SOP 产出、按什么门禁入库。本目录为 skill 载体，SKILL.md 即规范正文。

## 内容清单

- `SKILL.md` —— 强门禁正文：三子库×卡形态 + 统一卡结构（用法三步）+ 四步 SOP + 六条红线 + 层级入口（新 agent 上手路径）+ 全文件速查表。
- `references/` —— 素材进戏与换壳验收（质量控制的支点方法论）。
- `templates/` —— 三张卡模板（人设原型卡 / CP组装卡 / 金手指配方卡），复制填充即产出。

## 相关约束要点

1. **强门禁定位**：建卡/改卡/建子库必读 SKILL.md；违反红线（不读就建 / 伪造单书出处 / 素材不进戏 / 去口播 / 模板不收敛 / 子库不注册）= 不合格不入库。
2. **本库立身之本**：可套用不溯源 + 素材进戏（配人物目标与代价）+ 换壳验收（套进它没提过的世界观仍成立）。区别于赛道包/IP百科的源书锚点，本库靠"可换壳"兜底。
