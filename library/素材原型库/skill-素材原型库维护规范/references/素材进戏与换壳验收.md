# 素材进戏与换壳验收（方法论）

> 本文件回答一个核心问题：素材原型库的卡，怎么从"一堆可套用的料"变成"真正能出戏的写作武器"。这是全库质量控制的支点——素材本身不是剧情，质量差在一念之间。

---

## 一、素材进戏（铁律）

**素材/底色/设定本身不是剧情**。人设卡里的"冷态度×软动作"、CP卡里的"错位拉扯"、金手指卡里的"面板+限制"，都只是底盘。要出戏，必须补上两样东西，缺一即废卡：

1. **人物目标**——这拍落到谁想得到什么（要权/要人/要活着/要复仇），目标不清，动作无从发生。
2. **代价 / 成本**——拿到想要的东西要付什么（尊严/性命/关系/自由），没有代价，冲突立不起来。

**判定问句**：把卡里某拍抽出来问"这段戏在争什么？谁在付代价？"。答不上 = 这拍是空转，重写。

**落地手法**（进戏三连）：
- **给目标一个"不够"的起点**：先让角色处在"够不着"的位置，才有争夺的空间。
- **给代价一个"真的会失去"的落点**：代价要能具体到"失去的东西价值肉眼可见"，不是"他很痛苦"。
- **给选择一个"不选也错"的两难**：好卡里的高潮都是一道没有正解的题，读者替角色紧张。

## 二、换壳验收（入库门禁的最后一关）

素材原型库的承诺是"可套用、可换壳"。一张卡如果不能套进它没提过的世界观还成立，就是自说自话的半成品。

**换壳测试**（step4 验收必做）：
1. 把卡整体套进一个**它没提过的世界观/赛道**（CP卡：古言→仙侠→豪门；金手指卡：仙侠→末世→星际；人设卡：现代→古言→科幻）。
2. 逐拍检查——概念层是否还成立（缺南方系世界观都能）？套完后能否自然长出属于新壳的具体细节？
3. **结论**：能成立 = 卡是"机制/结构可移植"的合格品；变味 = 卡里混入太多原壳的具体装饰，剥掉装饰、保留机制后重写。

**换壳示例**（示范"机制可移植"）：
- CP卡《疯批帝王×清醒废后》机制="权力倒置 + 双清醒"，换壳到仙侠 = 行事？仙盟掌门×被逐的清醒道侣，同样的倒置与清醒。
- 《以爱为囚》机制="强制爱 + 反制 + 主动停手"，换壳到现代 = 商业联姻×清醒前妻，同样成立。
- 金手指"面板流"机制="数据面板 + 上限 + 对价"，换壳到末世 = 遇险面板驱动身强体，换到星际 = 舱内战斗数据投射。

## 三、去口播与"不缴出成品句"

素材库不是搬运博主文案，产出型 `CP模板/00-索引.md` 三类硬规则：**可套用不溯源 / 素材进戏 / 去口播**。具体到卡片：

- **零博主口播腔**：删"家人们/我跟你讲/必看/狠狠拿捏"，转成中性技法描述。
- **零营销词/感叹号连用**：卡是工具，不喊口号。
- **零 HTML 视觉稿 / 双文件冗余**：只要纯技法 `.md`，不要渲染稿、不要 `_原文案` 双份。
- **不缴出成品句**：卡给出"拍义 + 填法标准"（怎么去写才合格），不替作者写死成句；例：拍义"称呼差是关系温度计，回不来即无解"，而非把"陛下"二字写成定稿台词。

> 一句话收束：卡给机制、给标准、给换壳示范，不给结论句、不给营销腔、不给一次性壳。这样它才能被任意 agent 和任意作者反复取用。
