# 每日网文简报 · 索引

> 定位：像 AI 界新闻日报一样的自动化简报——榜单变化、平台公告、爆款动态、行业新闻，每日一份供 agent 选题参考与老板晨读。

## 组织方式

- 文件命名：`YYYYMMDD-网文简报.md`
- 每份五段：
  1. **今日榜单**（起点/番茄/晋江三榜头部变动，新晋 vs 常驻）
  2. **平台动态**（签约政策/分成调整/新功能）
  3. **爆款观察**（新书起飞案例：题材+书名+数据+一句话归因）
  4. **行业事件**（影视化/监管/融资/舆情）
  5. **今日一签**（一条对写作有直接用处的信号，如"某赛道密度过高"）
- 采源标准：榜单实时数据+平台公告原文+正规媒体报道，传闻标注「未证实」

## 自动化路径

- 阶段1（现在）：手动/半自动，跑调研 agent 采集当日五段
- 阶段2：TRAE 定时任务（Schedule cron）每日早间自动跑采集+落盘
- 数据源优先级：平台官方页 > 权威媒体 > 行业自媒体
