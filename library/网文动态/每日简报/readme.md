# 每日简报 · 内容目录

> 定位：每日一份的网文圈自动化简报（榜单/平台/爆款/行业/今日一签），供 agent 选题参考与老板晨读。采源：榜单实时数据+平台公告原文+正规媒体报道，传闻标「未证实」。
> 深入规范见 `00-索引.md`（本目录唯一规范源），入库约束唯一来自上级库 `网文动态/readme.md`，本文件不重复铺开。

## 入口

`00-索引.md`（组织方式 + 自动化路径）

## 相关约束要点

1. 文件命名 `YYYYMMDD-网文简报.md`；每份五段式（今日榜单/平台动态/爆款观察/行业事件/今日一签）。
2. 所有条目带来源；数据源优先级：平台官方页 > 权威媒体 > 行业自媒体。
