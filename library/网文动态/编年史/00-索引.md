# 网文编年史 · 索引

> 定位：中国网络文学大事记——平台兴衰、爆款诞生、监管节点、商业模式演变。供 agent 写作时定位"当下坐标"，供选题判断"什么梗已过气/正在起势"。

## 组织方式

- 按年代分卷：`1998-2003 蛮荒期.md` / `2004-2010 门户期.md` / `2011-2016 移动期.md` / `2017-2021 免费期.md` / `2022- 分流期.md`
- 每条事件：年份 | 事件 | 类别（平台/爆款/监管/模式/技术） | 影响一句话 | 来源
- 采源标准：新闻报道/平台官方公告/权威媒体专访，无源不入
- 爆款事件须记：书名+作者+平台+成绩（订阅/影视化/出圈标志）
