## 赛道文件夹标准结构

> ⚠️ 现行正式结构以**西幻dnd**为标杆（用 `skill-赛道包维护规范` 倒推对齐），取代本页旧的「8标准子目录」草态。

每个赛道统一标准子文件夹 + 门面，**建包/维护前必读 `skill-赛道包维护规范/`**（含完整目录树、每文档规格、产出矩阵 step、入库检查门禁）：

```
西幻dnd/  （标杆，结构请对齐它）
├── readme.md / changelog.md       ← 门面 + 迭代日志

├── 立项/01-立项PRD.md            ← 六要素方向句
├── 赛道特色/                      ← 内容风味层：类型风味基线 / 名词表 / 命名规则
├── 文风DNA/                       ← 笔触形态层：00-库索引与消费协议 + 三层组件池
├── 力量与战斗/                    ← 机制层：力量体系 / 战斗系统 / 金手指 [+战斗表现/=笔触层]

├── 角色库/                        ← 角色配置规格 + 标杆卡/
└── 剧情库/                        ← 索引 + 动力引擎 + 三池储备卡（早期/中期/后期）
```

新包按上建；旧包逐步对齐。已归档的源书拆解素材卡可直接供通用元素卡库组装参考；空子文件夹待同赛道新书立项后逐步填充。**多 agent 协作：新增/维护任何包，先读 `skill-赛道包维护规范/SKILL.md`，规范即可执行，不依赖历史对话。**

→ 详见 [采样范围验证-前段vs中段.md](采样范围验证-前段vs中段.md)
