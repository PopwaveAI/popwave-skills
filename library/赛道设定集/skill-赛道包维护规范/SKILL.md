# 赛道包维护规范 skill

> **定位**：本 skill 是 `library/赛道设定集/` 的**建包与维护规范唯一真源**。任何人/任意 agent 要在这个库里加一个赛道包、改一个既有包、补一份文档，都先读本 skill，照规格产出、照门禁入库——不再依赖"上一个对话的记忆"。
> **基准样本**：西幻dnd（最完善包）。本 skill 的所有规格都是从它倒推出的可复用标准，详见 `references/西幻dnd-结构标杆.md`。
> **现有支持资产**（在 `赛道设定集/` 根下，配合本 skill 使用）：
> - `全量赛道分类表.md` —— 赛道=题材×玩法×情绪价值，判定"这是不是一个该单独立包的细分赛道"
> - `单赛道极致深度采样方案.md` —— 采到"西幻dnd级深度"的 5-Phase 方法论（多书×全阶段）
> - `细分建包与深度补优执行方案.md` —— 就地改名/迁移/占位包的执行细则

---

## 一、资料包是什么（做什么）

`赛道设定集/{赛道名}/` 下每个文件夹 = 一个**「赛道标杆包」**：某条「题材×玩法×情绪价值」赛道的完整 DNA，供 test-* 系列 skill（write/plot/review 等）消费。

**包=greed 自描述知识单元**：内含多份子文档，文档按「消费者 × 加载时机」分层，各自带 frontmatter 声明消费方。包消费时按需选读，不整包硬灌。

**抄什么**：结构 / 节奏数值 / 颗粒密度 / 公式触发。**不抄什么**：专有名、具体事件、人物（一律100%原创或并入储备库供组装）。

## 二、包标准结构（对齐西幻dnd）

```
{赛道}/
├── readme.md              ← 包门面：包介绍（广告化）+ 文件目录（全展开）+ 消费方式 + 资产缺口
├── changelog.md           ← 迭代日志：版本号+每次改了什么+为什么（多人维护的唯一事实链）
├── 使用手册.md             ← 强制标准唯一来源：N套参数表 + 包结构映射 + 消费映射表（test-skill读取路径）+ 达标线
├── 立项/
│   └── 01-立项PRD.md      ← 六要素方向句（赛道基线版，【】槽位由新书创意X填充）
├── 赛道特色/              ← 内容风味层（写什么词）：类型风味基线 / 名词表 / 命名规则
├── 文风DNA/               ← 笔触形态层（怎么写）：00-库索引与消费协议 + 三层组件池（通用基底/场景卡分档/卷级演变）；共享组件库，按需采用
├── 力量与战斗/            ← 表层规则层：力量体系 / 战斗系统 / 金手指 [+ 战斗表现/ =笔触层，逻辑归属文风DNA库·场景卡分档]
├── 世界观/               ← 5件赛道百科：总纲 / 地理版图 / 文明与社会 / 规则总账 / 危机与敌人
├── 角色库/               ← 角色配置规格.md + 标杆卡/（主角/盟友/敌人/配角/势力/总表 + 源书角色深度标尺）
├── 剧情库/               ← 索引.md + 动力引擎.md + 各卷切片.md + 早期/中期/后期三池储备卡（幕级）
└── 源书拆解/             ← 采源真实性证据仓库（§六）：源书txt + 分档拆解件 + 收敛检测；元素卡/ 可选
```

> ⚠️ 这是**现行正式结构**，取代 `赛道设定集/readme.md` 里旧的「8标准子目录」草态（元素卡/原文注入包等）。其中 `源书拆解/` 保留但**身份升级**（v2.0.0）：从旧草态的普通素材目录，升级为采源真实性证据仓库（§六门禁的落地位置）。新包按本结构建，旧包按此对齐。

## 三、五层 DNA（资料包的内容分层）

> 包的内容 = 5 层 DNA + 1 笔触层，分别对应 samples/机制/内容/风味/素材。新增包时逐层产出。

| 层 | 落点（目录/文件） | 对应 skill 消费 |
|:--|:--|:--|
| **结构层** | `使用手册.md` 的 N 张参数表（卷幕骨架/节奏/颗粒度/爽点配比/角色配置） | seed / plot / write / review |
| **机制层** | `力量与战斗/`（力量体系/战斗系统/金手指）+ `剧情库/动力引擎.md` | world / character |
| **内容层** | `世界观/`5件 + `角色库/` + `剧情库/`三池 | world / plot / write |
| **风味层** | `赛道特色/`（类型风味基线/名词表/命名规则） | world/character/plot/write 取词与门禁 |
| **笔触层** | `文风DNA/`（怎么写，三层组件池） | write / plot / review |
| **素材层** | 源书拆解 / 原文注入包 / 元素卡（指向 `写作素材和技巧/` 通用卡库） | 组装参考 + **采源真实性证据仓库** |

**"做到极致"判定**（对标西幻dnd 完整度）：6 层全齐 + 每层有≥3本书交叉验证 + 块类型收敛（不再现新块）+ **采源真实性门禁全过（§六）**。判定细则见 `单赛道极致深度采样方案.md` 与 `references/采源真实性门禁.md`。

## 四、SOP 纲要（怎么产出/怎么维护）

> 详细步骤见 `steps/`。这里是执行地图：

| 步骤 | 文件 | 场景 | 核心动作 |
|:--|:--|:--|:--|
| **1 立包/立项** | `steps/step1-立包.md` | 新增一个赛道包 | 判定细分（查分类表）→ 选书（标杆1+腰部2+变体1，**源书txt齐备门禁**）→ 建标准目录 |

| **3 入库检查** | `steps/step3-入库检查.md` | 包完成后验收 | 对齐西幻dnd目录100% + frontmatter齐全 + ≤15KB + 采源真实性清单 + 索引三处同步 |
| **4 维护/扩展** | `steps/step4-维护扩展.md` | 既有包补件/大改 | 新增文档走入库检查；大改 = 新版本号 + changelog 记录 |

## 五、红线（违反 = 不合格 = 不入库）

1. **目录对齐红线**：新包目录必须 100% 对齐西幻dnd 正式结构（§二），不得自造目录名或回退到旧8目录草态。违反=不合格。
2. **单件 ≤15000字符 红线**（2026-08-22 定字符口径）：任何单件揭示超 15000 **字符**必须拆件（中文 UTF-8 每 3 字节才 1 字符，字节口径虚高约3倍，作废不用；agent 加载量与字符/token 相关）。违反=不合格（防 agent 加载过载）。
3. **去专名红线**：包内只抄机制/结构/参数，**禁照搬源书专有名、具体事件、人物原名**（标杆卡具名角色禁进新书正文）。违反=不合格。
4. **三处索引同步红线**：建包/改名/大改必须同步 ① `赛道设定集/readme.md` 赛道目录 ② `全量赛道分类表.md` 状态 ③ 各包内 readme/changelog/使用手册 自指路径。三处缺一=不合格。
5. **采源真实性红线（v2.0.0）**：`source_book` 禁匿名——必须具体书名+作者；关键参数/机制须能追溯 `源书拆解/` 的章节锚点（chXX），量化值标 🔒，推导项显式标注；无源书 txt 的包禁标「✅完整包」。违反=不合格（详见 §六 + `references/采源真实性门禁.md`）。

## 六、采源真实性门禁（v2.0.0 新增）

> **核心原则**：「选本赛道最好的小说 → 从实际拆书提炼经验知识」是赛道包**唯一合法内容来源**。凭记忆/泛知识/别的赛道套用 = 乱编 = 不入库。完整标准见 `references/采源真实性门禁.md`（对标 decon 侧 skill 的防乱编五道闸门）。

**五道闸门**（违者判不合格）：

1. **源书必下载**：`源书拆解/` 必须有所选源书 txt（全本或已申明取样范围）；无源书产出=乱编。
2. **锚点前置**：关键参数/机制必经 `源书拆解/` 对应章节采样后才写结论。
3. **逐条 chXX 证据**：正文关键结论带 `(chXXX)` 章节号；量化数值标 🔒。
4. **原文未展开标注**：源书没写清、靠合理延伸的，显式标「原文未展开/推导」。
5. **自检+删编造**：入库检查（step3）含采源清单；无锚点结论不得入库。

**溯源字段**（每件 track-package 文档 frontmatter 必带）：`source_book`（具体书名+作者，**禁匿名**）+ `source_range`（取样章节范围）+ `derive_policy`（纯拆书提取 / 拆书+合理推导 / 全推导待补）；参数表/机制表下加「采源说明」块接线到 `源书拆解/` 具体文件。

> **去专名 ≠ 源书匿名**：去专名去的是正文层的专有名/事件/人物（红线3不变）；源书身份（书名/作者/章节锚点）必须实名可溯。旧版「全包源书匿名化」决策就此作废。

**降级规则**：无法追溯源书的包不得标「✅完整包」，只能标「推导待补」或「占位待采源」，补齐后再升。
