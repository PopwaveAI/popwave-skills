# skill-赛道包维护规范 · 内容目录

> 定位：`赛道设定集/` 库的**建包与维护规范唯一真源**（强门禁 SKILL v2.1.0）——一个赛道包该有哪些文档、各文档什么规格、按什么 SOP 产出、按什么门禁入库。本目录为 skill 载体，SKILL.md 即规范正文。

## 内容清单

- `SKILL.md` —— 强门禁正文：五层 DNA + 标准目录结构 + 五条红线 + 采源真实性门禁（五道闸门）+ 采样量两级制 + SOP 纲要。
- `references/` —— 结构标杆、门禁细则等支撑资产。
- `steps/` —— step1 立包 / step2 产出矩阵 / step3 入库检查 / step4 维护扩展。

## 相关约束要点

1. 强门禁定位：建包/改包必读 SKILL.md；违反红线（目录对不齐 / 单件超限 / 去专名 / 三处索引不同步 / 采源真实性）= 不合格不入库。
2. 采源真实性为本库立身之本：每包 `源书拆解/` 必备源书txt，`source_book` 禁匿名，正文结论带 chXX 章节锚点；无源书 txt 只可标「推导待补/占位」。
