## 二、每文档规格要点

| 件 | frontmatter 要点 | 关键内容规范 |
|:--|:--|:--|
| readme | doc_type: readme, layer: track-package | 包介绍广告化、目录全展开、消费方式、资产缺口 |
| changelog | doc_type: changelog, version | 版本号+每次改什么+为什么 |
| 使用手册 | doc_type: 使用手册, layer: track-package, consumers: seed~review, read_policy: full-required | 5表每个参数「赛道基线值+仿写规则」；包结构树；消费映射表（test-*读取路径）；达标线；职业路线图 |
| 立项PRD | doc_type: 立项PRD | 六要素方向句，【】槽位由X填充 |
| 类型风味基线/名词表/命名规则 | track-package | 类型声明+风味锚+门禁 / 十二类风味词库 / 命名规则 |
| 文风DNA库门面 | doc_type: 文风DNA库门面 | 三层结构+存量映射+三段式+write消费协议+门禁 |
| 力量体系/战斗系统/金手指 | track-package | 阶位表/战斗规则/金手指模板+三约束 |
| 战斗表现各件 | category: 战斗写法, part, load_when, source_book | 四段模板「〇阶位定位/一战前/二战中/三战后」；≤15KB；每件自包含编号 |
| 世界观5件 | track-package | 每个维度给到数字实证颗粒度 |
| 角色配置规格+标杆卡 | track-package | 槽位制结构层+双源选样实证+具名禁入正文红线 |
| 剧情库三池 | category: 剧情储备 | 弧总卡+幕件（幕级）；status: 幕纲级·生态解耦/源书转写/参数级 |

## 三、frontmatter 模板（track-package 件）

```yaml
---
doc_type: {readme / 使用手册 / 战斗表现 / …}
layer: track-package
category: {赛道风味 / 战斗写法 / 剧情储备 / …}
part: {可选，件在包内的定位}
producer: {产出方，如 write-skill dndlike 迁移 / 赛道蒸馏}
source_book: {可选，源书名}
consumers:
  - {配套 test/主 skill 名}
read_policy: {full-required / full-if-targeted / …}
load_when: {可选，加载时机}
version: {x.y.z}
last_updated: {YYYY-MM-DD}
description: {一句话说明+本件在管线里的作用}
---
```

## 四、通用规格红线（全件统一）

1. **单件 ≤15000字符**（2026-08-22 定字符口径：中文UTF-8每3字节1字符，字节口径虚高约3倍作废；防 agent 加载过载，超限拆件）
2. **frontmatter 双 schema 合规**：标准七字段（doc_type/layer/consumers/read_policy/version/last_updated/description）或剧情储备卡专属 card_id schema（card_id/源类型/arc_type/status…）任一即可
3. **去专名移植**：抄机制不抄事件；标杆卡具名角色禁进新书正文
4. **储备库组装**：世界观/势力/角色/剧情均按可错配储备库维护，落地按创意X组装
