# references · 采源真实性门禁（防乱编）

> **定位**：本文件是 `skill-赛道包维护规范` 的**内容真实性门禁唯一标准**。回答一个核心问题——
> **「这个赛道包里的参数/机制/世界观/角色配置，究竟是从哪本书、哪几章、怎么拆出来的？能不能查到原文？」**
> **蓝本**：对标 decon 侧 skill（`pop-decon` / `pop-decon-dimension`）的**防乱编五道闸门**，移植为赛道包建包标准。
> **原则**：**「选本赛道最好的小说 → 从实际拆书提炼经验知识」是赛道包的唯一合法内容来源。「凭记忆/泛知识/别的赛道套过来」= 乱编 = 不合格。**

---

## 一、为什么必须有这道门禁（现状诊断）

`skill-赛道包维护规范` v1.0.0 管了结构/规格/去专名/索引同步，**唯独不管内容源头**，导致三类乱编漏洞：

| 漏洞 | 表现 | 危害 |
|:--|:--|:--|
| **源书匿名** | `source_book: 赛道标杆源书（匿名）` | 匿名=无法验证=可凭空 |
| **参数无锚点** | "爽点0.93/章"无源书章节出处 | 数值不可回溯，失信 |
| **正文不接线** | 包内拆了`源书拆解/`，但使用手册/世界观正文不引用 | 拆是拆、写是写，两层脱节 |

> 判断标准一句话：**一个文档能不能从它的字段+正文，一路追到 `源书拆解/` 里的具体 txt、具体章节？** 追不到=不合格。

---

## 二、五道闸门（对标 decon，移植为赛道包标准）

| 闸门 | decon 原版 | 赛道包版要求 —— 违者判定 |
|:--|:--|:--|
| **1 源书必下载** | 无源文件不得开工 | `源书拆解/` 必须有所选源书 txt（全本或已申明取样范围）；无源书就产出=乱编 |
| **2 锚点前置** | Grep 命中≥20章才精读 | 关键参数/机制必经 `源书拆解/` 对应章节采样；纯推导项必须显式标「推导」 |
| **3 逐条 chXX 证据** | 每条设定带(chXXX) | 每文档正文关键结论带 `(chXXX)`；量化数值标 🔒 |
| **4 「原文未展开」** | 原文没有的标「原文未展开」 | 源书没写清、靠合理延伸的，标「原文未展开 / 推导」 |
| **5 自检+删编造** | 无证据条目删除 | 入库检查清单含「采源真实性」，无锚点结论不得入库 |

## 三、每个赛道包文档必须带的溯源字段（frontmatter + 正文）

### 3.1 frontmatter 必带字段（track-package 件）

```yaml
---
source_book: 《遮天》辰东（具体书名，禁匿名）
source_range: 三档采样（开局ch001-005 / 推进ch200-204 / 高潮ch1700-1704）
source_anchors: references 于 `源书拆解/遮天-*.md`（交叉引用）
derive_policy: 纯拆书提取 / 拆书+合理推导 / 全推导待补
---
```

> ⛔ **匿名源书禁用**：`source_book: 赛道标杆源书（匿名）` 一律判不合格，须填具体书名。无法追溯到源书的包不得标「完整包」，只能标「占位待采源」。

### 3.2 正文关键区加「采源说明」块

每个「参数表 / 机制表 / 世界观设定表」下方（或 frontmatter 上方），加一行：

```markdown
> **采源说明**：本表数值/机制采自《{书名}》(chXXX-chYYY) 拆解，详见 `源书拆解/{文件名}.md`；未在源书出现的为「推导」项，需跨书验证。
```

### 3.3 量化数值标 🔒（对标 decon）

- 凡是**源书原文明确出现的数值**（爽点0.93/章、凡人9阶、跨一境3-5倍、灵气潮汐周期等）→ 标 🔒，表示"原文实证，可溯源"。
- 凡**源书未展开、靠合理推断**的 → 不标🔒，且带「推导」二字。
- **同一文档内🔒数占比低**（<30%）→ 提示该文档推导过多，需回源书补采或降级为「推导待补」状态。

## 四、每类文档的溯源接线（与 `源书拆解/` 的交叉引用）

| 文档 | 须接线的源书拆解 | 溯源方式 |
|:--|:--|:--|
| `使用手册.md` 参数表 | 节奏/颗粒度参数 → 对应档拆解统计块 | 每个参数值标注采自哪档哪块 |
| `力量与战斗/力量体系.md` | 等级/境界/进阶 → 源书境界体系 | 每档位带(chXXX)首个出现章 |
| `世界观/`5件 | 地理/势力/规则 → 对应世界观块 | 每实体带首次出场章 |
| `角色库/标杆卡/` | 角色 → 源书角色卡 | 具名角色标注源书章号 |
| `剧情库/`三池 | 幕 → 源书剧情块 | 每幕标注改编自哪段 |
| `赛道特色/命名规则.md` | 命名 → 源书命名实例 | 规则附源书实例章号 |

> 一句话：**背包内的 `源书拆解/` 是「证据仓库」，包内所有结论都要能「起诉到」它。**

## 五、采源真实性自检清单（入库前必过）

- [ ] `源书拆解/` 有源书 txt（≥1本，标清取样范围）
- [ ] 每文档 frontmatter `source_book` 具体书名 + `derive_policy` 已填（无「匿名」）
- [ ] 参数表/机制表带 `(chXXX)` 锚点，量化值标 🔒
- [ ] 源书未展开项标「原文未展开 / 推导」
- [ ] 🔒 占比 ≥30%（不足则补采或降级推导状态）
- [ ] 包状态标注诚实：真·完整包 vs 推导待补 vs 占位待采源

> 任一未过 → 不得标「✅完整包」，须降级为「推导待补」或「占位待采源」，补齐后再升。
