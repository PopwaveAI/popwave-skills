# Step 1：立包 / 立项

> 场景：新增一个「赛道设定集」资料包。前置：本 skill 全文已读，已确认这是该立包的赛道。

---

## 1.1 判定细分：这是不是要单独立包的赛道？

> 一处发现：不是所有书都要独立建包，按「题材×玩法」颗粒度对齐西幻dnd。

- 读 `全量赛道分类表.md`：查该赛道（题材×玩法×情绪价值）是否已存在、是否已细分、是否与现有包重叠。
- **该立包**：细分颗粒度与西幻dnd 同级（如 西幻×DND面板流、灵异×恐怖经营流）且尚不存在 → 立。
- **不该立**：题材级粗包已存在、新书属其子玩法之一 → 就地并入或在既有包下占位，勿重复建包。

## 1.2 命名

- 格式：`{题材}×{玩法}`，写成 `{题材}{玩法}` 单文件夹名（已有先例：`西幻dnd`、`灵异恐怖经营`、`都市修仙`、`仙侠争霸`）。
- 命名对齐分类表与根 readme 的赛道目录列。

## 1.3 选书（横向样本，对应采样方案维度1）

| 书位 | 数量 | 选择标准 | 作用 |
|:--|:--|:--|:--|
| 标杆书（现象级） | 1本 | 该赛道最成功/最典型 | 主样本，DNA主源 |
| 腰部书（成熟） | 2本 | 稳定盈利的腰部 | 交叉验证，收敛检测 |
| 变体书（差异化） | 1本 | 同题材不同玩法的边缘 | 边界检测，防过拟合 |

> 同赛道×不同成功层级×不同作者风格，避免全选同一作者。

### 采样量两级制（v2.1.0）

| 档位 | 书量 | 章数 | 拆解件 | 达标效力 |
|:--|:--|:--|:--|:--|
| **硬底线** | 标杆书 ≥1本（全本txt或申明取样范围） | 15章（开局/推进/高潮 三档×5章） | 三档块线拆解3份 + 收敛检测1份（单书三档收敛即可） | 允许标 ✅完整包 |
| **目标线** | 书位矩阵4本（标杆1+腰部2+变体1） | 每本15章，共45-60章 | 全书位三档拆解 + 跨书收敛（≥3本交叉验证） | 允许标「极致采样」 |

- 硬底线不过 → 包状态只能标「推导待补/占位待采源」（step3 判定）
- 硬底线过、目标线未达 → 仍是 ✅完整包，但禁标「极致采样」；缺口在 readme 留痕块注明

> ⛔ **采源门禁（v2.0.0 红线5）**：标杆书 txt 必须齐备（全本或已申明取样范围）才能进入 Step 2 产出；txt 未到位 → 只能建「占位待采源」骨架（readme 标注资产缺口），**禁止凭记忆先写内容**。下载走 `tool-download-webnovel` skill。判定标准一句话：**没有 txt 就没有拆书，没有拆书就没有赛道包**。

### 采样留痕（v2.1.0，硬底线组成部分）

采样完成（或阶段完成）后，必须在包 `readme.md` 填「采样留痕」块——**采了哪些书、各采多少章、产出哪些件、缺口是什么，一览可审计**。无留痕 = 采样不可审计，step3 按「留痕缺失」判不合格。模板：

```markdown
## 采样留痕

| 源书 | 书位 | 采样章节 | 拆解件 |
|:--|:--|:--|:--|
| 《{书名}》{作者} | 标杆书 | 开局 ch001-005 / 推进 ch{XXX} / 高潮 ch{XXX}（{N}章） | 三档块线拆解3份 + 收敛检测1份 |

**产出统计**：{N}块{N}线
**两级制判定**：硬底线 ✅过｜目标线 ⬜未达（{缺口}）
**缺口**：{待补书目/章数/件数}
```

## 1.4 建标准目录

照 SKILL.md §二 的正式结构建目录（含全部子文件夹）。经验证对齐西幻dnd：

```
{赛道}/  readme.md changelog.md 使用手册.md  立项/  赛道特色/  文风DNA/  力量与战斗/  世界观/  角色库/  剧情库/  源书拆解/
```

- 目标路径 `library/赛道设定集/{赛道名}/`
- `源书拆解/` 建包即建：放入源书 txt + 后续分档拆解件（采源真实性证据仓库，见 SKILL.md §六）
- 自检：`LS` 目标目录确认所有子目录存在。

## 1.5 输出

`{赛道}/readme.md`（包门面：包介绍 + 文件目录 + 资产缺口 + **采样留痕块**）占位可建；其余文档进入 Step 2 产出。
