# Step 2：产出矩阵（填各层文档）

> 场景：目录建好，逐层产出。原则：按「消费者 × 加载时机」分层，每份文档带 frontmatter，单件 ≤15KB。

---

## 2.1 产出顺序（建议）

先立「骨」（结构/机制），再填「肉」（内容/风味/笔触），后补「素材」。对应五层 DNA：

1. 结构层 → `使用手册.md`（N 张参数表 + 消费映射 + 达标线）——**全包强制标准的唯一真源，先定它**
2. 机制层 → `力量与战斗/`（力量体系/战斗系统/金手指）+ `剧情库/动力引擎.md`
3. 内容层 → `世界观/`5件 + `角色库/` + `剧情库/`三池储备卡
4. 风味层 → `赛道特色/`（类型风味基线/名词表/命名规则）
5. 笔触层 → `文风DNA/`（三段式组件池，见 `文风DNA槽位协议`）
6. 素材层 → 源书拆解 / 原文注入包 / 元素卡（跨赛道通用卡在 `写作素材和技巧/`）

> ⛔ **采源顺序（v2.0.0）**：素材层不是"最后补"，而是**先于结论**——每层写参数/机制前，先在 `源书拆解/` 对应档位采样取证（走 decon 侧拆书 skill 或直接精读分档章节），结论逐条带 `(chXXX)`。拆解件先落盘，结论后落笔。

## 2.2 每份文档的硬规格（对齐西幻dnd 倒推）

| 项 | 规格 |
|:--|:--|
| frontmatter | `doc_type` / `layer` / `category` / `consumers` / `read_policy` / `version` / `last_updated` / `description` 必备（track-package 件另需 `producer` / `source_book` / `load_when` / `part`）。模板见 `references/西幻dnd-结构标杆.md` |
| **溯源字段（v2.0.0 必带）** | `source_book`（**具体书名+作者，禁匿名**）+ `source_range`（取样章节范围）+ `derive_policy`（纯拆书提取 / 拆书+合理推导 / 全推导待补）。细则见 `references/采源真实性门禁.md` |
| **采源说明块（v2.0.0）** | 每张参数表/机制表/世界观设定表下加一行：`> 采源说明：本表数值/机制采自《{书名}》(chXXX-chYYY)，详见 源书拆解/{文件}.md；未在源书出现的为「推导」项` |
| **锚点与🔒（v2.0.0）** | 正文关键结论带 `(chXXX)`；源书原文实证的量化数值标 🔒；推导项不标🔒并显式标注。同文档 🔒 占比 <30% → 降级「推导待补」 |
| 单件体积 | **≤15000字符**（字符口径：中文UTF-8每3字节1字符，字节口径作废；超了拆件，防 agent 加载过载） |
| consumer 声明 | 每个文件开头/ frontmatter 标清谁消费、何时加载（如 `read_policy: full-required` / `load_when`） |
| 段落颗粒 | 数字实证 > 形容词；有因果、能看见、给参照物梯子 |
| 参数表 | 每条带「赛道基线值 + 仿写规则」，明确抄结构不抄事件 |
| 储备库 | 世界观/势力/角色/剧情均做成**可错配的独立储备库**（供组装，不作预设绑定） |

## 2.3 文风DNA 层的当前标准

- 见 `文风DNA槽位协议`（shared）+ 各赛道 `文风DNA/00-库索引与消费协议.md`。
- 三层结构：通用笔触基底 / 场景卡分档 / 卷级演变；三段式（操作特征+完整段落+反面教材）唯一格式；write 消费走 5章滑窗去重。

## 2.4 去专名（贯穿全程）

- 所有机制件 = **去专名移植**（抄机制不抄事件）；标杆卡 = **双源选样实证**（抄深度不抄人物）。
- 具名标杆角色可入库作「深度标尺」，但禁照搬进新书正文。
- ⚠️ **去专名 ≠ 源书匿名（v2.0.0 澄清）**：去的是正文层专有名/事件/人物；`source_book` 书名/作者/章节锚点照实实名（红线3+红线5并行不悖）。旧版「全包源书匿名化」作废。
