# 仙侠争霸赛道包

## 包介绍

**九棺聚，大道开——古史解谜流仙侠的爽感密码，全部拆成了能直接抄的参数。**

写这条赛道最容易死在三个地方：爽点排不密、境界没分量、古史大谜底撑不起全书。这个包把答案全部数值化——

- **参数5表**：爽点0.93/章、章末钩子率100%、卷末三件套，每条都是强制红线
- **战斗写法分件**：动作拆到招式级、境界外显【】数据流，通用层+等级段战斗模式三段位+叠加层5件，战斗章照着写就有打击感
- **世界观5件赛道百科**：泛仙侠总纲入口+地理/文明/规则/危机四篇，地理版图从凡尘祖星到星空古路到禁区终域，每个维度都给到数字实证颗粒度
- **角色库双件**：28人配置规格+实证级标杆卡+势力储备库，深度标尺直接量
- **剧情库三池23卡全幕级**：早期/中期/后期——总卡+幕件分件体系，「古史解谜·九棺归位」动力引擎+十卷切片，白描+逐章锚点卡，改改就能当幕纲用
