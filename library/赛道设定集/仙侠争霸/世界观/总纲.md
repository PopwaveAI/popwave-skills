# 世界观总纲 · 东方仙侠玄幻（赛道百科入口）

> **定位**：本赛道=古史解谜×证道登仙的东方仙侠玄幻。世界观底座是**泛仙侠宇宙观**——凡尘与修仙界并存、天地灵脉、证道果位与古史遗物这一整套共享概念（遮天/完美世界/凡人流等泛仙侠生态作品共用同一底座），赛道标杆源书是这套底座在网文赛道的最佳实证转写。本件是百科入口：先读此件建立全景，再按需下钻《地理版图》《文明与社会》《规则总账》《危机与敌人》。
> **消费方式**：world展开11文件时的顶层输入；plot的时代背景板；write的世界质感基线。**抄机制、抄结构、抄颗粒度，不抄专有名**；名词层以《赛道特色/名词表.md》为唯一真源。

## 一 · 宇宙结构（层域金字塔）

> 空间类型=**叠层天地**（多层世界纵向叠加，非星球）：凡尘祖星为基，一层层向上叠加修仙界与古史遗地，越上层天地元气越浓郁、越接近大道，最大者为修仙界首域。

| 层位 | 内容 | 叙事功能 |
|:--|:--|:--|
| 外裹·无尽星海 | 近乎无穷的星海包裹一切大域；无灵气，须靠星空古路/传送阵承载；可见古棺残片/太古神魔尸体/废星遗落，别称「放逐星域」 | 跨域旅行通道+古史遗产垃圾场（卷二起解锁） |
| 上层·仙界仙域 | 星海往上=仙界/仙域位面，元气浓郁，天仙与大能执掌大道 | 证道终极舞台（卷六–十） |
| 四面·四极秘域 | 东蓬莱/西昆仑/南火洲/北玄丘四极秘域，元气暴烈、排斥外界进出 | 保守孤立古仙遗族，星路强化后被卷入 |
| 核心·三层纸 | 首域（修仙界最大一域，含中域/东荒/南岭/北原/西漠五大域）+凡尘祖星（凡人世界，元气稀薄，灵脉隐伏）+幽冥（灵魂能量层，直连阴司轮回台） | 主舞台+凡人原点+死亡线通道 |
| 下层·幽冥阴间 | 阴司黄泉/九幽地层（鬼魅/魂灵），轮回台运转 | 中盘大场面舞台；古棺猎场 |
| 附·洞天福地 | 靠天地灵脉一点一点「凝聚」成形，证道大能亦难凭空开辟 | 圣地秘境/主角道场的成长容器 |

- **跨域三方式**（由易到难）：神魂出窍（鬼修/大能常用，出窍失力不致死本体）→ 秘境小世界穿越（连接首域与凡尘/幽冥，域界系证道进阶条件）→ 星空古路/跨域传送（大能级能力）。
- **泛仙侠生态对应**：即泛仙侠宇宙的赛道化转写——星辰大海、洞天福地与幽冥轮回皆同源底座；新书自建专名，概念层可直接复用。

## 二 · 果位与道统（证道之路的运行底座）

> 本赛道世界观的特殊性：**道统即政权**——顶层是掌握大道果位的证道者与诸道统圣地，而非世俗王朝，凡界王朝只是中层（势力分层见《角色库/标杆卡/势力卡.md》）。

| 机制 | 内容 | 叙事功能 |
|:--|:--|:--|
| **果位五档** | 凡境<入仙<地仙<天仙<超脱（主宰级）；档间约3–5倍战力跳、跨二境以上碾压 | 力量天花板刻度尺；越境虐杀的压迫感来源 |
| **证道三载体** | 境界<道基<道果（容量排序）；只有凝成道果才算出道正果；引气成功但无道基道果=道基不稳/走火隐患 | 容器源头双限（原则4）：想证道必须先立道基与道果 |
| **因果循环** | 行善积德/悟道/结缘 → 添道行 → 道果成长 → 更多机缘；业力太重 → 堕境/遭天谴 | 「登仙后从苦修转经营道统」的叙事转型引擎 |
| **灵魂流转** | 幽冥先收走灵魂，再决归于轮回转世、封入古棺或入仙域；觉醒者之魂是古史重要遗产，仙逝时大能亲自接引 | 死亡线（卷九–十）的规则地基 |
| **道果五阶** | 凡胎（基石）→入仙（宗门战主力）→地仙（核心，近乎不朽）→天仙→证道者（握大道果） | 生前道行决定死后道境——道统承诺是稳定器 |
| **道统传承** | 各道统以传功碑/护法阵复刻道法，「道统广大方成体系」 | 圣地传承是社会稳定器，亦是势力博弈活水 |

| 道统 | 构成 | 功能位 |
|:--|:--|:--|
| 正道圣地 | 首域诸圣地共治；顶尖圣地可开山封授 | 秩序顶端，终局洗牌对象 |
| 仙域道统 | 上古天仙后裔/仙域古族 | 证道终极，主角登顶对象 |
| 古史遗族 | 荒古世系（先天道体后裔）+太古神魔遗蜕 | 信仰来源+堕落线 |
| 魔道古教 | 幕后魔主（天魔虚影）/魔道大能/九幽鬼帝 | 九棺棋局布设者（终极幕后） |
| 四极古仙 | 蓬莱/昆仑/南火洲/北玄丘遗仙（皆地仙以上） | 保守孤立的世界背景板 |
| 新道统 | 主角自建道统（证道后开山立派） | 主角的终点形态 |

## 三 · 时代引擎 · 古史解谜（九棺归位）

> **古史解谜·九棺归位=本赛道的时代引擎**（泛仙侠「九龙拉棺一类神话器物」的赛道化扩写）：上古神祇降世诰祭，以五色祭坛连通诸天、铸**九座青铜巨棺**散落诸天各域——集齐九棺、解开其上**青铜刻图**的古史真相者，可证无上大道、超脱古今；棺中既藏仙缘、亦藏灾劫。九棺散落与古史谜底在某一纪元集中引爆、改写力量格局。

- **集棺竞赛窗口**：凡人或修士可凭悟道、因果、集棺夺运——「属于集棺证道者的时代。」每次「集棺→解谜→晋道果」=一卷高潮的标准公式（原则1）。
- **因果棋局**：预见大劫的古仙留遗蜕/子嗣散落诸天、令其相互了结因果、集全者合道复活——幕后大反派的标准布局。
- **原生威胁涌入**：黑暗动乱爆发、先天道体沉沦、古史真相揭示改写力量格局；九幽阴魅随古棺出世降临，诸域灵脉颠倒。
- **落幕形态**：九棺归位→古史真相揭晓→凡人重归凡尘、纪元更替收束全书——主角证道超脱、携道统升入仙域。
- **备选引擎「黑暗动乱」**：大事件供给猎物的备选轮（大事件清单见《危机与敌人.md》）。

## 四 · 历史时间线（纪元五段式）

| 纪元 | 关键事件 | 意义 |
|:--|:--|:--|
| 远古纪元 | **上古诰祭·神魔时代**：上苍神祇以五色祭坛连通诸天、铸九座青铜巨棺散落诸天；**先天道体出世**（荒古圣体级）、天书古字初现，太古神魔开天辟地 | 九棺谜底伏笔+古史遗地层世界观纵深 |
| 远古→中古 | 先天道体沉沦、太古神魔天命终结同期；诸圣地争雄、魔道古教崛起 | 「神魔+古仙」降格为「诸道统均势」，埋结构性失衡 |
| 中古 | **黑暗纪元**：古史真相磨灭、古棺横空再现、五色祭坛残迹封隐 | 遗殇与猎场预演 |
| **主线纪元** | **九棺之谜开启**：主角自凡尘祖星经星空古路入首域（祖星大案波及东荒三十七城/五大圣地/上百世家——开篇大案波及面颗粒度标尺） | 时代引擎点火=卷一开卷 |
| 主线中盘 | 首次集棺（卷三）→主角证道立派（卷四）→首域道统洗牌（卷五） | 古史持续解谜+道统加速洗牌 |
| 主线终局 | 黑暗动乱（卷九）→九棺归位·古史真相揭晓→纪元更替，主角携道统升仙域 | 时代收束+跨书彩蛋（道果种子入星河） |

## 五 · 世界设计原则（5条 · 赛道强制标准）

> 全包各表「回溯原则」列均指此5条——世界层的总开关，world展开各维度时逐条回溯。

| # | 原则 | 一句话 | 世界含义 |
|:--|:--|:--|:--|
| 1 | **大事件供给猎物** | 古史大事件=猎物清单 | 周期性喂大糖的引擎：每破一谜/集一棺=一卷高潮 |
| 2 | **地图分卷解锁** | 地图随境界开放 | 力量等级决定能去哪；每卷开新图=开新规则层 |
| 3 | **境界数值量化一切** | 变强必须看得见 | 读者与主角共享同一张境界地图；压迫感与爽感双轨 |
| 4 | **古史双限** | 古史是容器，道果是源头 | 防数值无限膨胀，强制「苦修→经营道统」转型 |
| 5 | **传说度=叙事合法性货币** | 世界认可你才能证道 | 「低调发育」vs「高调扬名」做成可计算取舍 |

**原则×十卷校验法**：plot产卷纲后逐卷自检「每卷每原则至少一格」。抽查锚点——卷一（首触古史遗物/凡尘祖星/首境界量化落地/「道基不稳」实装/传说度10 vs 200+差距）→卷四（证道道果落地/星空古路线启动/证道面板/容器源头齐备/传说度达标时点）→卷十（登大能·仙域+古史遗地/终局结算面板/超脱门槛留白/传说度450升仙扬名）。
