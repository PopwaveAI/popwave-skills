# 规则总账 · 东方仙侠玄幻（赛道百科·规则篇）

> 赛道级参考答案——机制与结构源自赛道标杆源书全书拆解，专有名已槽位化、章锚点已剥离。新书 world 展开对应维度时**抄机制、抄结构、抄颗粒度，不抄事件与专有名**；名词层以《赛道特色/名词表.md》为唯一真源。
> 七类规则是各维度公共输入的规则总账，每条回溯五设计原则（定义见《总纲.md》第五节）：**原则1** 大事件供给猎物 · **原则2** 地图分卷解锁 · **原则3** 境界数值量化 · **原则4** 古史双限 · **原则5** 传说度合法性（藏与显）。
> **空间类型判定**：**叠层天地**（多层世界平行叠加+纵向分层，首域修仙界最大层）——先按叠层天地处理，再定各层规则；宇宙结构全景见《总纲.md》第一节，本件只收规则细则。

## 一 · 规则总账表（七类规则）

| 规则类型 | 规则内容 | 回溯原则 |
|:--|:--|:--|
| **位面物理** | 层域世界物理：世界是多层天地纵向叠置（非星球），凡尘祖星为基一层层向上；"三层纸"模型：首域修仙界+半物质秘境小世界+幽冥灵魂层为核心，全部包裹在无穷无尽星海里；幽冥几乎无血肉生命，多为魂灵，直连阴司轮回；物质世界的"物理定律"由上古神魔遗产部分打破（浮空城/先天道体沉沦死地/灵脉逆转） | 原则2/3 |
| **位面物理** | **星空古路机制**：星海无灵气，须靠灵舟/星空古路承载；进入星路的修士自动掌握【道法瞬发】（合道境以下全瞬发，传奇道法半时间）；接近星矿源质可令传奇道法瞬发；星海有【源质/星矿】与尽头边界【晶壁】；星空古路=连接绝大部分大域的旅行通道与"垃圾场"（古棺残片/废弃洞天/神秘遗落/幽闭仙域），别称【放逐星域】；阶层越深对手越强（境界随星路深度上升），凡人难入星路，合道境以上方可跨域常态行走 | 原则2 |
| **位面物理** | **秘境小世界（半物质位面）**：连接首域与凡尘/幽冥，灰蒙仙雾基调，投影复制首域古老建筑，有古棺幻影/扭曲魂灵/尸魅；主角在极怒/爆发状态下可短暂进入秘境小世界；跨域传送【秘境】是秘境系证道进阶条件之一 | 原则2 |
| **位面物理** | **神魂出窍**是最简单的跨域方式（鬼修/大能常用），出窍失力不致死本体；洞天福地靠天地灵脉+混沌元气一点一点"凝聚"成形，即便证道大能也无法凭空开辟 | 原则2 |
| **超凡法则** | 力量=肉身+真元+灵根+功法+神通的物化战力，一切可数值化（体魄/六识/灵根/境界/道基/道果/因果）；功法分三系：炼气聚元（正道，操控最好，补刀/控制型）、引灵入体（妖修，来自灵气灵脉）、天赋异术（修士/妖灵，最具不可控性，早期有能量暴走期）；道法以"重/层"计量（1–9重，终局强者颗粒度标尺：法术免疫1–6重、道法瞬发1–8重）；施法代价：道法印刻可省功法书但需付出杀戮经验/灵根损耗 | 原则3 |
| **超凡法则** | 证道规则：道果=道性血脉，灵识能量化，免疫致命攻击（无致命伤/无心可活/免疫背刺，重击部位伤害更高）；微弱证道全属性+1、弱等+2；大能化身形态获【超凡入圣】（免疫+1以下法宝）+【道法免疫1–3重】；终局道果免疫：属性伤害/夺舍/业火、极阳、纯阴、即死、心魔、切削、灵损、心神影响、麻痹、毒、混毒、震慑、变形、封印、流放 | 原则4 |
| **战斗规则** | **境界等级（道行级）**衡量敌人强度与组队难度：约需5个同境界修士组队才有约一半胜算；合道≈大能与道身级别 | 原则3 |
| **战斗规则** | 伤害判定以**气象式/弹窗式呈现**（「道法瞬发/渡劫历雷」）；道身级免疫致命攻击（免疫背刺），但重击部位伤害更高；仙魔战中散修/入仙/地仙/天仙一旦战死即**真正陨落** | 原则3/4 |
| **攀登规则** | 本职境界**5重=一阶→二阶分水岭**；境界阶位1–9阶；升级经验指数增长（顶级境界需千万级杀戮经验/道行点） | 原则3 |
| **攀登规则** | **证道三件套**：境界<道基<道果（容量排序）；只有凝成道果才算正道正果；引气成功但无道基道果则道基不稳 | 原则4 |
| **攀登规则** | 正常证道标准需**传说度最少200点**；传说度取决于众生敬仰/传播范围而非敌人强度——隐秘杀强者只得微量，扬名之战得高额 | 原则5 |
| **攀登规则** | 道果储存道行有极限（微弱道果约200点）；果位五档：凡境<入仙<地仙<天仙<超脱（主宰级），档间约3–5倍战力跳、跨二境碾压 | 原则4 |
| **攀登规则** | **灵根开通仪式**每次进阶限一次，需1000灵石级花费+法术辨识+悟道；进入合道后那次仪式获【大道身】（近战硬撼古兽的资格） | 原则3 |
| **危机规则** | **黑暗动乱（时代引擎）**：先天道体沉沦、古棺横空/五色祭坛重启，诸域灵脉颠倒、怒火滔天；诸域平衡打破→魔道古教/幽冥阴间与首域连接强化 | 原则1 |
| **危机规则** | **道统责任**：拥有道果即背负相应道统责任，不尽责可能陨落；放弃道果归隐只有强大古仙能做到；弟子数不足→道统式微 | 原则4 |
| **危机规则** | 黑暗动乱终局→灵脉归位、首域恢复→凡界辨明排斥、证道者被排斥出凡界；洞天十不存三、诸道统衰微、需数十年恢复弟子 | 原则1 |
| **原生威胁规则** | 魔道古教/九幽阴魅随灵脉颠倒大量降临为祸；四极秘域排斥外界进出；尸祸（生死道果失衡触发）；上古古器（星界古神尸/仙魔战争遗产）随地图解锁投放 | 原则1/2 |
| **原生威胁规则** | **仙魔大战**：正道妙手vs魔道古教的永恒战争，永不停歇的前线绞肉机——中盘大场面与道位晋升的天然舞台 | 原则1/2 |
| **博弈规则** | **散修是仙道重点打击目标**；若所悟道果与他道冲突会遭不死不休攻击 | 原则1/4 |
| **博弈规则** | **因果棋盘机制**：预见大劫的古仙留遗蜕/子嗣分散因果、令其相互了结、集全者合道复活——幕后大反派的标准棋局 | 原则1 |
| **博弈规则** | 出窍只降一点力量，但出窍上注入的道性/道基不可返还——可被【杀戮】道性者吸收 | 原则4 |
| **博弈规则** | **信仰经济**：首域凡界是一切的根基——主角道场的信仰绝大部分来自凡界；灵魂流转：幽冥先收走灵魂，再决归于轮回转世还是封入古棺/入仙域；觉醒者之魂是古史重要财富，仙逝时大能亲自接引 | 原则4/5 |
| **博弈规则** | **血祭证道风险**：血祭可快速增力但造成瓶颈（正道集棺念力证道上限远高于邪道血祭）；灵修证道易被信仰绑架、魂灵扭曲 | 原则4/5 |
