# 建势幕2示范 · 追随者成形·班底聚拢（ch11-25）

> CN-001 幕件之一（弧概览/六幕功能位序列/量级升级节奏/使用红线见《星空古路建势弧总卡.md》）。

## 套路决策
- **演绎框架**：单主线（死单立信）+班底聚拢线并织；变体=「用一单活命换回一队人」
- **内容引擎**：主 三段护航死单+一次星陷突围；辅 班底各自身世与信任磨合
- **高潮**：位置幕中后段（ch20-22型）｜类型 星陷困局·生死并肩｜蓄力 两段护航摩擦1-2章｜余波 班底聚拢成形
- **幕末钩子**：一批「无处安身的人」跟了他→指向幕3据点建设

## 幕定位
- **本幕作用**：把「一个人能办事」升级为「有一队人肯跟你闯」——班底是建势力的第一块地基。
- **核心体验**：死单立信的快意×第一批人把命交到你手里的重。
- **情感弧线**：初搭边角的人 → 摩擦磨合 → 生死并肩 → 从搭伙到追随。
- **幕末质变**：独狼→带班底的头；「有人肯为你去死」从概念变成现实。

## 剧情白描（示范叙事）
名号立住后，黑命护航的死单找上门：三批船串联互为保险，敢接这活的人，等于把命押在航线上。主角接下一批「无援死航线」的护航单——航线一段是陨铁残域，凶兽与星坠都收过路费。散修、落魄飞船夫、被排挤的边境术士顺着名号聚到赤沙屿——不是来干活的，是来找活路。他先立规矩：不碰害人的活、账算清楚、一个不落。第一段护航有惊；第二段护航撞上星坠带，他把危机一个人扛了大半、又分给各人最擅长的位置——散修的风水堪舆、落魄飞夫的星图手感、边境术士的阵甲——各凭所长的协同救下一整批船。第三段，星陷困局：航线被多重夹击至死路，本可独自弃船脱身的主角，选择留下来把船队带出去——他赌的是「这批人能别主动跑」。困局里，有人替他挡下第一记、有人为他拆阵、有人冒伤背他——生日夜那晚他第一次觉得，「黑心星港收买的人心，买不到今晚这种」——一顿酒、几句掏心窝的话，这些人从「搭伙」变成「追随」。幕末：他带着这第一批班底回赤沙屿记账，落脚的地方太小、住不下这么多人——一个「有自己的家」的念头在班底里不约而同地冒出来，指向幕3据点建设。

## prose-render交接
- **文风注意**：法外星海的粗粝×班底掏心窝的暖——两条舆情线反差。
- **不可改动骨架**：①接死单立信 ②班底聚拢+各身世 ③三重协同救船 ④星陷困局/不弃船突围=信任爆点 ⑤追随者成形+落脚念头埋钩。
- **可自由发挥**：护航细节、星坠带机关、班底各自背景。
- **爽点外显**：酬金数字外显；信任以「他肯为你留下/挡刀」外显。
- **角色行为锚点**：主角-立规矩在先、账算清；班底-各有短板但各擅长、舍命认死理。
