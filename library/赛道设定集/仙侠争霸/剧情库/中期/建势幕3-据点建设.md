# 建势幕3示范 · 据点建设·经营线开（ch26-45）

> CN-001 幕件之一（弧概览/六幕功能位序列/量级升级节奏/使用红线见《星空古路建势弧总卡.md》）。

## 套路决策
- **演绎框架**：经营幕（据点经济链开启）+危机穿插并织；变体=「把落脚点变成摇钱筐」
- **内容引擎**：主 据点基建/过路费/护航/星器换购的经营链；辅 地头蛇眼红与一次袭击危机
- **高潮**：位置幕末（ch42-45型）｜类型 据点守御战·逆境反杀｜蓄力 眼红摩擦2-3章｜余波 经济链成型+威名再升
- **幕末钩子**：据点成了肥肉被更大的星墟势力记上→指向幕4势力扩张

## 幕定位
- **本幕作用**：把「落脚点」升级为「会自己下蛋的据点」——经营线必须在扩张期开启（中盘双线引擎的地基）。
- **核心体验**：看着一个坑越建越实的数值快感×经营家的脑力转。
- **情感弧线**：搬进据点的归属感 → 基建与摩擦的拉扯 → 守住自己地盘的硬气。
- **幕末质变**：落脚点→会经营的据点（经济链成型）；主角从「强者」多一重「经营者」身份。

## 剧情白描（示范叙事）
班底在陨铁残域圈下一处废弃锚台，改成「陨铁烽堡」——这里在航道要冲上，往来的船都想有个能护、能修、能换购歇脚的地方。经营线照他读过的商路规则开起来：过路费（往来的靠泊）配护航费（落单船买保）配星器换购（零散材料换维修与克星）——账归一位账面算得清的术士管，安全则归堪舆与阵甲手轮流巡。头一个月账起来得慢，但每一笔都扎实：烽堡从「有人住」变成「有进账」、从「有编号」变成「有口碑」——往来船夫开始说「过了陨铁烽堡这趟才叫走完一半」。经营幕不是太平账：成本被一次次不显眼的地方挑高（材料价/人工/护航损手），地头蛇眼红着来收「孝敬」不成，转头在星磁残域设伏扣了一船货，把烽堡往「缴税」的绝路上逼——他被惹到头，领烽堡一队人反打回去端了地头蛇一掌毒窝（据点守御战），把扣货夺回、把价码立住。幕末：经济链在两次袭击与一次守御战里彻底成型（过路+护航+换购+威慑四头进账），烽堡成了星港间喊得响的名字——也正因如此，被更大的星墟势力正式记进了账本里。

## prose-render交接
- **文风注意**：据点经营的数值质感×守御战的硬；别写成纯数据流，穿插人情往来。
- **不可改动骨架**：①经营线此时必须开（过路/护航/换购）②成本被暗处抬的隐性压力 ③地头蛇设伏扣货的危机穿插 ④守御战反打立价 ⑤大势力觊觎埋钩。
- **可自由发挥**：据点基建细节、各人分工、守御战具体打法。
- **爽点外显**：账面数值外显；经营活动以「过路船的感谢/地上的口风」外显。
- **角色行为锚点**：主角-把经营当另一场战斗来读；账面术士-算得死但护自己人。
