# 禁区风暴线（OS-003）

> 骨架源自泛仙侠生态通用「禁区异变/古史真相现场」意象（解耦借鉴）。禁区/古史异变/站队/古民残魂为泛仙侠生态通用概念，可直接使用；具体剧情分支禁止照搬。
> **消费方式**：plot 产幕白描时以本卡为底稿——改专名、换事件分支、对接本书X张力即成幕纲；示范专名（桑原/圜光禁区/御守世系/圜光长老柳旌/九渊剑主厉舟/域前残民/牧野等按赛道规则登记示例库。

## 弧定位
- **本弧作用**：中盘「换引擎」前奏——一场禁区古史异变把主角从「打手」架上「站队者」，逼他交出立场。
- **核心体验**：大场面的壮阔×「你在哪一边」的逼问——古史真相与选择同时砸下来。
- **情感弧线**：旁观禁区异变 → 被卷入站队 → 看清两边的真假 → 给出自己的立场。
- **弧末质变**：旁观者→站队者；世界观从「个体争胜」转向「秩序/站队的棋局」。

## 剧情白描（示范叙事）
禁区圜光深处突发一场古史异变——本该封存的古域残民残魂被某种力量唤醒、潮水般涌出禁区边缘，困住了一批误入其中的宗门小队，异变现场牵动整片域界格局。赶来的不止主角桑原：御守世系的圜光长老柳旌带着「清理残民、守护禁区」的令牌；九渊剑主厉舟则要的是禁区深处那段古史真相与器物——两拨人身后，还各站着圣地一系的既得利益与魔道古教一系暗桩。这是一场无人能置身事外的站队：看疗效，柳旌师出有名却把人当耗材；看本心，厉舟为古史真相而来却手段愈狠。异变现场里，桑原救出被困小队、也救下几个残民——站队的压力把他逼到「不选也选」的墙角。他读了两边的底：柳旌的令牌能借来御守之力守域，却对残民赶尽杀绝；厉舟的剑能开禁区之道，却也要把残民拦腰一并吞噬。卷尾事故烟多发，桑原做的不是投靠任一边，而是「直面异变、守下能守的人」——他借两边之势、又破两边之弊，亲手把残民护出一条生路，把那段古史真相撬出一角留在自己手里。幕末：域界记下「圜光一役」，也把「桑原站的那一队」写进各势力的账本——他从「打手」正式走上「操盘/站队者」的位置，世界规则的重量这他第一次切身扛起。

## 压力机制/站队博弈（本卡核心资产）
- **双选无解**：柳旌师出有名却把人当耗材、厉舟为真相对却把人当拦腰——「都要救」本身就得站出第三条路；
- **多方互相钳制**：御守系/九渊系/圣地一系/魔道一系四方各有进退，主角可借势但每借一步都要还人情；
- **大场面压制**：古史异变的体量不是斩首能解的——破局靠「读局+守人」而非硬碾，这是换引擎前的「格局课」。

## prose-render交接
- **文风注意**：禁区的苍茫×异变的壮阔；两边都站得住的「对错编织」用留白与各执一词。
- **不可改动骨架**：①禁区异变爆发大场面 ②两派并立各带令牌/剑 ③不站即自站（无解）④借两派之势破两派之弊 ⑤守人+真相一角 ⑥换引擎前奏埋钩。
- **可自由发挥**：异变地形、残民群像、两派具体诉求、破局的打法。
- **爽点外显**：大场面以「域界震动」级侧写外显；立场以「各方账本记名」外显。
- **角色行为锚点**：主角-本能先守人、读局再出手；柳旌/厉舟-各执一偏的有力反派，不脸谱。
