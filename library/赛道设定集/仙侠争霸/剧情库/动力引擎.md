# 动力引擎 · 仙侠古史流基线

> 引擎默认推荐：**「古史解谜·九棺归位」**——上古九座青铜巨棺散落诸天，聚齐者可得证无上大道的资格，同时=引爆黑暗动乱的引信；上古纪元被一场「断史」抹去，当世修仙者不识古史全貌——「古史真相分层供给猎物」，修士第一次有资格循九棺叩问大道、重写秩序。
> **引擎是世界级的**：所有修士、宗门、圣地、古族都在同一场寻棺争道里攀爬，主角的金手指只是让他看得更远、解得更快——这是古史流与普通升级流的本质区别。
> 备选引擎（同类互换，机制同构）：①黑暗动乱（古史真相揭示改写力量格局，猎物=被封印的禁区圣者/古帝王道）②圣体沉沦（体质之谜反噬血脉，猎物=体质源流与古圣遗血）。选型规则：引擎必须做到「力量天花板松动+赛道大事件点火」两件事，否则改。

## 组成1 驱动逻辑

- **世界级驱动力：寻棺总因果**（L5级全书钩，开篇10章内点火）。源头建议设为「断史之外的古史残响」（被抹除的上古纪元的执念/一枚最后的古棺信使/诸天对湮灭真相的回声，任选其一），使九座青铜巨棺封存的上古大道显世。
- 寻棺打破当世修行秩序→**大道通道重开**：上古仙人以棺为凭坐化封存道果，九棺齐集=证无上道果的唯一入口；每座古棺出世=一处灵脉/秘境/禁区异变，异位面古凶兽与古帝残魂大量显世为祸——低阶猎物与危机的无限供给源。
- **为什么所有人都在争**：九棺=大道天花板松动。谁先开棺炼化，其承载道果立即空出成为新阶跳板；圣地要守己系道统，古族要迎回血脉古祖，禁区圣者要借棺续命，散修野心家要循棺搏一个登仙契机——一场诸天同时进行的寻棺竞逐。
- **个体层驱动（主角侧）**：初始唯一执念（护某人/活下去）→责任与格局层层放大为「护一城→护一域→定秩序」，终点落在两个字（守护/超脱/大道，X注入）。

## 组成2 运转机制

> 通用攀登闭环（输入→转化→输出→反馈），全量化驱动（境界/真元/道行/灵根/法宝/功德皆可量化）：

1. **输入**：击杀妖兽/异兽获精血魂力（=铜镜映出的真灵，强敌给高额）；宗门任务/历练获宗门贡献与功德（闭关/布阵/临敌本职行为）；事迹传播获**名声/仙名**（由观众与传播范围决定，非敌人强度）；经营获信徒/护山者（开宗立派可得【运朝/香火】类权柄）。
2. **转化**：真元→金丹元婴→化神；道行→合道→证道果位；名声+道果→开宗立教/成道入册；香火信仰→神通权柄（微末神祇法力上限约数人之力一档）。
3. **输出**：境界大爆→身份/能力跃迁→新地图/新秘境（爽点核心公式：每次跃迁必须境界数值外显）。
4. **反馈**：突破资源指数增长（顶级境界需海量天材地宝/悟道机缘）→旧猎场收益衰减→**强制开拓新秘境/新星路/新禁区**（位面分卷解锁的物质基础，不许靠「作者忘了」绕过）。

## 组成3 众生攀登分层（四类群体）

| 群体 | 攀登方式 |
|:--|:--|
| **有资源者（圣地/古族/宗派）** | 灵脉灵地+资源培养弟子→凝聚道统→立教成道；强大教统有资格开辟新秘境/剥离道统封师弟；圣地经营山门与榜书经济 |
| **没资源者（散修/凡人）** | 炼气筑基+宗门任务认证；趁古棺出世浑水摸鱼猎古帝残魂夺道果（主角路线之一）；野蛮路线：血炼魂晶借宝续命（快但有瓶颈） |
| **爬到顶者（大能/古圣人）** | 保证道统不至于分崩否则果位动摇；履行道义责任否则业力反噬/道基受损；预见陨落的提前布局（留子嗣传承道统、借道果分身复活）；禁地圣人守成一系（古帝→战将→护道者→香火神→万民） |
| **掉下来者（陨落/被夺舍）** | 修士彼此吞噬真灵、集全者夺舍复活；化身/夺舍死亡只降一档境界但注入的真灵/道性不可返还——可被【噬灵】类神通吸收；卷末降级实证位：主角遭【噬灵·噬魂】类攻击永久降境、真元封印 |

> **非主角变强路径≥5条（供势力/角色库消费）**：①宗门灵脉资源线 ②夺舍/借舍线 ③血炼/魂晶线 ④妖兽/凶兽晋级线 ⑤上古遗脉/传承线 ⑥香火封神线（血祭供奉邪神，风险=灵魂扭曲被信仰绑架）。

## 组成4 代价结构（含代价转嫁层）

- **通用代价**：突破资源指数增长；金手指跳过时间的代价=用精血魂力弥补原住民苦修数十年获得的功法感悟/境界底蕴。
- **群体差异代价**：血炼续命有瓶颈（正道悟道封限远高于邪道血炼）；开棺反噬与名声成反比；伪道统是诸圣地重点打击目标，道统冲突=不死不休。
- **代价累积效应**：【噬灵】类永久性损耗（降境+真元封印+灵根受损）；古棺莲子/护道者一旦战死即**真正陨灭**（不可复活）；黑暗动乱后洞天福地十不存三、诸圣地道基可能跌落、需数百年恢复香火。
- **代价转嫁层（关键设计）**：①圣地把争道竞争转嫁给弟子（令其寻棺夺道果相残，集全者可觉醒血脉——主角至亲亦可是一枚棋子）；②强圣地把经营成本转嫁给附庸宗门（剥离道统封师弟）；③宗派把开战成本转嫁给香客/弟子；④禁区把古兽潮消耗转嫁给凡尘（古棺出世后凶兽降临为祸）。

## 组成5 范式归类

- **主范式：飞轮型**（加速vs减速的矛盾基调）——境界即时正反馈机制（每场质变都给出可量化境界数据，读者「看得见的变强」）+ 周期性开棺喂大糖（每次「开棺→炼化道果→证道果位」即一卷高潮）。
- **副范式：探索型混合**——秘境/星路分卷解锁（凡尘故土→跨星路→秘境洞天→禁区→终域），「已知vs未知」驱动新地图开拓；叠加「压迫型」段落（卷一压抑期、中盘蓄力段、黑乱期）形成节奏谷。
- **节奏基调**：四段式大结构——崛起期（压抑→灵根觉醒→扬眉吐气）→扩张期（爽点烈度逐级抬升，一步入仙为第一情绪峰值）→双线期（本体修途×分身古路爽点密度翻倍，中段一次蓄力）→登顶期（弑圣连发冲大道，终局执掌终域+集体超脱=最高峰与情感闭环）。
