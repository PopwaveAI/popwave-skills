# 终局幕3示范 · 古史决战·抄底接管（ch845-895·51章）

> CN-002 幕件之一（弧概览/五幕功能位序列/弑圣大戏分配/使用红线见《证道终局弧总卡.md》）。

## 套路决策
- **演绎框架**：抄底接管幕（把浩劫/残局换算成资源）+终极幕后对决；变体=「你在风暴眼里抢果子」
- **内容引擎**：主 古史决战/抄底接管（残魂/古史/道果/猎物）+魔主玄冥对决；辅 棋局真相收线（主角身世/金手指因果）
- **高潮**：位置幕末（ch888-895型）｜类型 位面战·魔主对决（终局幕后）｜蓄力 抄底与接管交错2-3章｜余波 魔主陨/棋局收口
- **幕末钩子**：赢下此役、终域大道果位成为唯一猎物→指向幕4证道摊牌

## 幕定位
- **本幕作用**：把上一幕扛住的灾劫与黑暗动乱变成主角的猎场——抄底接管的冷峻豪迈+幕后棋局一次性收线。
- **核心体验**：别人在劫里逃生，他在劫里捡钱（爽感反转）；再与数卷布局的终极幕后面对面。
- **情感弧线**：抄底的冷峻 → 对决魔主的背水 → 棋局真相揭晓/身世因果的释然。
- **幕末质变**：操盘者→终域果位唯一争夺者；棋局真相揭开大半。

## 剧情白描（示范叙事）
黑暗动乱与莫渊留下的残局，对大多数势力是浩劫，对池晏是猎场：他一手抄底——把灾劫里失威/崩溃的道统遗业、被唤醒的残魂、古史异变现场的断史遗物、因大道洗牌空出的道果与猎物逐一换算收编，「别人逃难他纳粮」；另一手则接管——在乱局里重建首域秩序，把自己的道统踏成安稳基石。正是抄底让他看清：莫渊、乃至整个黑暗动乱，都只是魔主玄冥（终极幕后）的一步棋——玄冥布局数卷，为的是借九棺/断史之力打开终域大道，而池晏手里的底牌（古符/身世/执念的因果）正是这盘棋局的钥匙（棋局真相收线：原来他之所以被选中，与他自始至终的求道因果相连）。古史决战：战场在大道洗牌现场/玄冥根本地撕开，池晏以抄底收到的一整套资源（残魂护法、古史遗物、道果储备）应对玄冥的每一招反制，最终以把数卷因果拧成一点、借浩劫残势一击——魔主陨灭、数卷棋局一次性收口（位面战·终局幕后）。幕末：浩劫收束、首域渐稳，可大道洗牌真正剥到最后一层——终域的那枚证道果位，成了整场比赛唯一剩下的猎物，也成了「谁执掌新秩序」的入场券（指向幕4）。
