# 秘境夺宝线（OS-002）

> 骨架源自泛仙侠生态通用「组队探秘夺宝+中途背叛」意象（解耦借鉴）。古墓秘境/灵脉洞天/坊市/寻龙探宝为泛仙侠生态通用概念，可直接使用；具体剧情分支禁止照搬。
> **消费方式**：plot 产幕白描时以本卡为底稿——改专名、换事件分支、对接本书X张力即成幕纲；示范专名（楚横/江氏道统后裔沈灵焕/采药女医沐芝/老相师司观/@坊市云集坊/古墓秘境「九幽墓」/灵脉洞天）按赛道规则登记示例库。

## 弧定位
- **本弧作用**：一场「允许失败」的中盘夺宝——把团队冒险的结构、信任的建立与破灭、终局三抢一次给足。
- **核心体验**：宝藏之喜(前) → 信任崩塌之痛(中) → 反转翻盘的机锋(后)。
- **情感弧线**：临时搭伙 → 患难相扶的信任 → 「小我」暴露的反转 → 承认/清算的收束。
- **弧末质变**：「搭伙寻宝的散修」→「看破人心、收下分寸」；地图从坊市推向一方秘境。

## 剧情白描（示范叙事）
一处筑基-金丹可探的古墓秘境「九幽墓」在坊市风传数日后被确认为真——入口只在月望夜开一线。散修们都知道这里头有东西，却没人敢只身下：墓里机关、守墓古修遗护、还有一层灵脉洞天等着人开门。想组队的人各怀心思。楚横是个有寻龙术的散修，凭一手配准入口的本事被拉进一支临时搭伙：江家道统遗后沈灵焕（想取古史遗卷）、采药女修沐芝（要墓中一味续命药）、老相师司观（自称只求观摩阵清）——临行前笔记里他多留了一手：司观的身世，坊市里没人能查全。下墓三重：第一重机关暗算，靠楚横的寻龙术排路；第二重守墓古修遗护现身，四人合作以沐芝的牵制+沈灵焕的剑抗住；第三重进入灵脉洞天，众人在快意中取到各自所求的初件，师徒情/道侣味在这段温暖里被写得很满——就在这时，沈灵焕从暗处反水：他把「古史遗卷」与洞天钥匙一并扣下，机关落闸要将其余三人封死在墓心，原来他接的是「独吞」的活。背叛的痛与墓中的死路同时逼到眼前：楚横利用之前留的那手牌——司观身世里有线，倒过来看透了沈灵焕背后金主的布置：这不是沈灵焕的独吞，是坊市里另一家排在队伍后头想捡漏的黑手在作局。真相翻转，墓中困局以司观的一句阵要破开、楚横的寻龙术反制落闸，三人在洞天身份反转——从被活埋的人，翻成「守住墓心、看清作局者」的人。弧末：各人分了墓中份例、定了各自去向；楚横没追杀沈灵焕——他留了半步，让那条金主的线继续淌出来，作为下一次交锋的引子。

## prose-render交接
- **文风注意**：坊市的市侩与墓中的幽深反差；合战写的团队配合，反转写的「人心冷刺」。
- **不可改动骨架**：①寻线组队（各怀所求）②下墓三重+合守遗护 ③洞天快意后反转（叛变）④反转再破（识破作局者）⑤收束（份例/去向/留尾线）。
- **可自由发挥**：三重机关、守墓遗护、洞天机关、各人背景。
- **爽点外显**：寻龙术以「排路的准确」外显；信任以「他肯为此暂缓私心」外显。
- **角色行为锚点**：主角-把队友身世当信息读、先保人身再谈宝；司观-藏一手的稳重老练。
