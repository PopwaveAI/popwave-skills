# 战斗系统 · 仙侠赛道基线

> 定位：战斗=境界差×资源代价×当前局面的综合结果。本赛道战斗基底是「肉身×真元×神通×法宝」的叠乘，越境界战是「可算的逆转」而非「无脑碾压」。

## 一、胜利判定（战力量化）

| 判定要素 | 说明 | 越级战参考 |
|:--|:--|:--|
| 境界差 | 一境一峰，跨一境3-5倍战力差 | 跨一境可战需「神通/法宝/炼体」补足缺口 |
| 肉身×真元 | 炼体打底+真元续航 = 综合战力 | 炼体修士十可战高半境 |
| 神通 | 御剑/法象/一气化三清（需真元灌注） | 多神通可抗同级群攻；但神通续力有限 |
| 法宝 | 可越阶，但认主/渊源/耗神代价 | 宝强则人弱转强，代价是「宝反噬/被抢」 |
| 场地/机关/人脉 | 阵法/陷阱/援军 | 借势可量变转质变 |

## 二、资源代价（战斗非免费）

- **真元/灵力**：战斗消耗真元，真元耗尽即战力衰减（需吐纳/丹药补充）；
- **肉身损耗**：炼体者战斗消耗肉身，久战有内伤/力竭；
- **法宝损耗**：法宝有耐久/反噬，强宝用之有耗神、伤己风险；
- **时间/空间**：困局/围攻/带人质/守护目标=时间与机动代价；
- **因果/业缘**：涉因果之战代价隐现（结仇/负伤/背负业力）。

## 三、分阶形态

| 阶段 | 形态 | 战斗样式 |
|:--|:--|:--|
| 凡人境 | 拳脚/兵刃/吐纳强化 | 近战缠斗、棍棒兵刃、闪转借势，多为市井冲突/武者对抗 |
| 入仙境 | 真元+御物+初步神通 | 御剑/符箓/法阵/仙光轰身，战局可算（谁真元厚/神通练得圆满者胜） |
| 证道者境 | 道行/法则/因果经营 | 法象天地/跨界压制/业缘结算，打的是「道」与「局」而非拳脚 |

> 凡人境按17大道/格拦下细节：走地道近战，禁凡人动不动御剑千里（味大漂移）。

## 四、战斗写法4拍（write/plot必守）

1. **试探**：互探底细（境界/法宝/援军），一交手先抓旁观优势；
2. **对抗**：你来我往交换，战力量化可见（真元消耗、法宝宕机、神通冷却）；
3. **转折**：一方翻盘（埋伏/法则/因果破局），是「可算的逆转」不是「突然爆种」；
4. **收尾**：结算战果（战利/负伤/因果赔账）+战末余波（威名/余党/后续钩子）。

## 五、碾压型力量红线

- 碾压型（请神/绝杀/巨宝爆发/灵脉灌注）必须配风险窗口/时限/副作用；
- 禁止出手即结束；碾压前必有铺垫、碾压后有代价（反噬/透支/暴露/引强敌）；
- 一场「直接碾压」的戏可作开篇立威，但全书碾压频次必须低（禁每章扫人）。

## 六、场景化速查（faithful可累进）

- **单挑**：两境差+切入试探→对抗→转折→收尾；
- **群战/混战**：多线视角、混战区我用神通行区分；
- **守护战**：贴身护目标，时间/机动代价高，能守不能退；
- **越境战**：补短板、借法宝，赢在「可算的算计」而非数值碾压。
