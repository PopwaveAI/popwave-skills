## 文件定位

本文件覆盖入仙期（金丹/元婴）全部战斗模式、量感格式、句式节奏与使用规范。入仙期与凡人期的核心差异：**战局从近身短打升格为神通/法宝/法阵的多层对阵，真元赤字上场（谁先耗空谁败），境界差距更硬（跨一境3-5倍战力差），叙事视角从全主角扩展到多POV**。

write层写入仙期战斗章，按本文件7种模式选取对应模式渲染；量感与境界外显按「境界外显叙事.md」取的数值锚与本文件量感格式调度；敌情探知走「数据化分析.md」完整式。

## 二、战斗模式详解

### 模式1：御剑＋神通混战

**适用场景**：主角常规战斗，入仙期最常见的战斗。

**核心结构**：御剑贴身 → 神通压敌 → 法宝补刀，三段式推进。技能名用破折号引出形成快节拍。

**原文锚点**：

> “——赤霞掩日印！”
> “——御剑诀〈百丈化一〉！”
> “——一气化三清！”

**连招写法**（御剑→神通→位移→御剑→终结）：

> “——御剑三连（劈/撩/挑）！”
> “——金光咒印*3！”
> “——剑遁瞬移！”
> “——御剑诀〈纵切〉！”
> “——青木玄雷剑定斩！”

**机制说明要点**：
- 神通层次与境界挂钩：圆满神通同阶难破，未圆满神通易被高境压制
- 真元消耗具象化：以“××丈真元”计，谁先耗空谁败（赤字数赤字叙事）
- 瞬发小术（金光咒/剑气）穿插在御剑间隙，形成“砍一剑→放一术→砍一剑”的连招节奏

**渲染要点**：
1. 每个技能名独立成行或紧跟破折号引出，形成视觉节拍
2. 御剑与神通交替，不得连续3次同一类型攻击
3. 连招中间可插位移（剑遁/横移）制造空间转换
4. 法宝作为收尾或转折，区别于常规神通（不消耗本体真元，但认主有门槛）

**节奏模板**：
```
[神通A] → [剑势B] → [位移C] → [剑气D] → [法宝定斩E]
```
每个节点可插1-2句旁白（对方反应/环境变化/主角判断），但不得打断破折号节拍流。

### 模式2：法相/领域碰撞

**适用场景**：金丹中期+，遭遇拥有法域/领域的强敌。

**核心结构**：展开法域 → 视觉化气场 → 领域内一切被改变 → 对付领域最好的办法是展开自己的法域碰撞扭曲。

**原文锚点**：

> 金丹法域一展，方圆千丈的天光尽数压下来，气温骤降，草木瞬时凝霜。
>
> 对付法域最好的办法，就是自己也展开法域，让两座气场碰撞、扭曲。

**法域效果呈现三维度**：
1. **天光维度**：压天光/敛光/改色——金域泛金光，火域染赤
2. **温度维度**：寒域骤冷凝霜，火域灼热
3. **空间维度**：法域内敌我相对位置错乱，剑遁距离受限

**境界压制直接改规则**：
- 一方法域更圆满，可压过对方法域内的道韵
- 法域碰撞交界处产生气爆/裂缝/规则扭曲的视觉化描写

**渲染要点**：
1. 法域展开必须有明确触发动作（掐诀/合手/神通释放）
2. 法域效果用物理感受呈现，读者要“觉得”天光和温度变了
3. 法域碰撞是高潮点，至少3句写交界的异象
4. 法域内战斗节奏变慢（气场压制），与法域外快节奏形成对比

### 模式3：多阶段大战

**适用场景**：强敌/宗门长老战，入仙期核心爽点。

**核心结构**：阶段1试探交锋→阶段2境界/神通免疫链→阶段3破防→阶段4环境崩塌+斩首。**每阶段必须有明确攻防转换标志。**

**阶段详解**：

#### 阶段1：试探交锋
- 藏锋示弱作战术开篇（主角隐藏实数神通/真元）
- 常规御剑/剑气试探，观察对方神通路数
- 攻防转换标志：对方亮出真实境界/第一层底牌，主角判断“常规手段无效”

#### 阶段2：境界/神通免疫链
- 主角连续放神通，对方逐一化解
- 用递进式排比呈现：

> “压不住。”
> “压不住。”
> “压不住。”

- 化解用量感呈现：

> “这一剑的金行剑气被他元婴圆满的护体真元一浸，便化去七成。”

- 攻防转换标志：主角意识到需要破防手段，切换战术

#### 阶段3：破防
- 用特殊手段突破（剑意对撞/属性碾压/法则借势/法宝破护）
- 量感分路结算弹出，精确到肉身/真元/神通/法宝：

> “赤霞印镇下，肉身伤三百丈、真元伤一百八十丈！……剑诀余锋却被金刚身吞了三尺”

- 含减免信息：

> 他外修魔体五百载，肉身可免七成真元之伤！……我这一剑穿透护体三寸，却被他金刚身硬扛下来，只溅两分血。

- 攻防转换标志：对方受伤后的狂怒态/第二形态开启

#### 阶段4：环境崩塌+斩首
- 环境成转折点：山峰龟裂→灵石崩塌→灵脉不稳
- 突袭打断他神通（利用环境碎片/御剑贴身压他手印）
- 法宝封锁逃跑路线
- 斩首终结，境界清算数值外显

**渲染要点**：
1. 每阶段转换必须有明确标志事件（不能模糊过渡）
2. 免疫链用短句排比，每句独立成行，制造“绝望递进”
3. 环境破坏用拟声词独立成段：

> 轰隆隆！

4. 伤害分路必须分离（肉身X+真元Y），体现入仙期精确度
5. 斩首后必弹境界清算数值外显

### 模式4：傀儡/灵兽武

**适用场景**：御傀/御兽系战斗。

**核心结构**：召唤过程视觉化→召唤物未出场先制造环境效果→召唤物数量与境界挂钩→宏观叙事。

**原文锚点**：

> 出窍一挥，阵纹在地面蔓延，灵潮骤涌，草木疯长。紧接着，一尊土灵傀儡自地下的灵脉中冲起——

**召唤过程视觉化三步**：
1. 灵光（灵气汇聚）
2. 阵纹（几何纹路蔓延）
3. 傀儡/灵兽冲出（体型/气势描写）

**环境前置效果**：
- 召唤物未出场，先改环境：土系→草木疯长/地动；火系→温度骤升；水系→潮涌
- 越强的召唤物，环境效果越剧烈——这是境界的间接暗示

**成长机制**：
- 召唤物随主人境界提升而增强（体型/能力/数量同步成长）
- 可写当前召唤物境界（衬敌情探知格式精简版）

**宏观叙事**：
- 以方阵/群压形式呈现，不同个体视角
- 宏观笔触：傀儡成阵/兽潮碾压/傀儡海淹没
- 召唤物数量与主人境界挂钩的机制说明

**渲染要点**：
1. 召唤过程不得跳步——灵光→阵纹→冲出，三步缺一不可
2. 环境效果必须在召唤物出场前出现（悬念+暗示）
3. 群战用宏观笔触，单个召唤物仅在关键击杀时给特写
4. 召唤物境界可简写（比敌情探知少字段），但必须有境界/体型/核心能力

### 模式5：宗门/团战

**适用场景**：大规模战役，多势力交战。

**核心结构**：多修系交战→每种修系战术特点→主角以补刀/指挥身份参与→宏观推进笔触。

**原文锚点**：

> 御剑的急着突进，阵修在后面铺阵，丹修的护体掩盖了灵气波动——这就是绞杀场，双方在半山腰反复拉锯，每一寸坡地都被灵火与剑气犁过三遍。

**多修系战术分析**：
- 剑修：突进/斩首
- 阵修：铺阵/困敌/领域
- 符修：远程/范围
- 丹修：回气/腐毒/护体
- 御兽：炮灰/骚扰
- 每系给1-2句战术特点

**主角定位**：
- 补刀者：不参与正面消耗，专收割残血/斩对方主阵者
- 指挥者：通过号令/印诀调度多系配合
- 两种身份可切换，但同役换身份需触发事件

**绞杀场比喻**：
- 用于消耗战的残酷
- 配合量感结算（但团战简化，侧重总量/趋势不个体）

**宏观推进笔触**：
- 不聚焦个体，写战线推移/阵型变化/士气/灵潮波动
- 用地图视角俯瞰战场全貌
- 多势力参战，每方给一句定位

**渲染要点**：
1. 团战不得用1v1细腻笔触写——必须宏观、趋势性
2. 多势力参战，每方至少一句定位
3. 主角视角切入时从宏观拉近到微观（特写击杀），再拉回宏观
4. “绞杀场”类比喻每役最多1次

### 模式6：法阵/禁制战

**适用场景**：阵法/禁制类事件、困阵/护山阵/聚灵阵攻防。

**核心结构**：灵气灌注→阵基运转→掉境/破阵风险→大阵威压→环境崩坏→阵眼修复。

**原文锚点**：

> 山石崩裂，护山阵灵光在威压下急剧闪烁，阵基有数处龟裂。地脉灵潮疯狂涌动，补着破碎的阵纹。

**法阵战核心要素**：
1. **灵气灌注**：施术者意识/真元汇入阵纹网络，感知范围扩大
2. **真元消耗**：真元值下降，量感呈现消耗量
3. **掉境风险**：阵破/中断可能导致境界跌落（入仙期独有风险）
4. **大阵威压**：高阶存在降临/被召唤时的威压直压环境
5. **环境崩坏链**：山石崩→阵灵光闪→阵基龟裂
6. **阵眼修复**：地脉灵潮自我修复，提供拉锯感

**法阵大小与召唤物/威压挂钩**：
- 阵直径/面积与所镇之物正相关
- 大型法阵需多修协同维持阵基

**渲染要点**：
1. 灵气灌注用第一人称内视（感知扩展/真元涌入）
2. 真元消耗必须有量感数值（消耗前→消耗后）
3. 掉境风险作悬念铺垫，不必每次都真掉
4. 大阵威压破坏按递进：山石→阵灵光→阵基
5. 阵眼修复提供“破坏-修复”拉锯节奏

### 模式7：五行相克战

**适用场景**：五行生物交战，多系混合。

**核心结构**：极短对仗句式呈现五行冲突→灵潮剧烈波动→主角利用异象混战侧面肢解。

**原文锚点**：

> 金行的锋芒弥漫。
> 火行的灼焰肆虐。

**句式特征**：
- 极短对仗句式，每句独立成行
- 结构：[五行]＋“的”＋[力/气]＋[动]
- 对仗工整，字数接近，呈视觉对称

**灵潮波动描写**：
- 空气中灵气剧烈波动（不稳定的能量场）
- 五行交界处产生湮灭/爆裂/相生相克链
- 用环境变化侧面呈强度（金石融/空气结冰/草木焦）

**侧面肢解战术**：
- 主角不正面参战，利用巨兽/异象混战的混乱
- 在对方互相攻伐时，趁机收割受伤目标
- 体现入仙期战术思维——不硬拼，借力打力

**渲染要点**：
1. 对仗句式仅在五行交锋高潮使用，整段使用节奏单调
2. 侧面肢解先铺垫混战场景（至少2-3句）
3. 每次出手后写量感，但可简化（侧重克制关系）
4. 克制加成/减免用量感数值体现（如“金行剑气对木行成两倍伤”）

## 三、量感与境界外显结算（入仙期）

> **红线**：入仙期量感比凡人期更细——从“一掌/一剑”升级为“真元××丈＋分路结算＋克制比”。不能凡人期量感写入仙期，反之亦然。

### 3.1 真元资源条（谁先耗空谁败）

```
真元：１３２０／３２００丈。
剑意：五成——纵切剩余可１次。
神通：一气化三清（分神二，耗真元××丈/息）。
```

### 3.2 境界突破量感（金丹一转/九转、元婴）

```
“金丹转成。金光冲霄十丈，丹香盈亩。”
“真元暴涨十倍（三百丈→三千二百丈），可窥元婴之门。”
```

### 3.3 神通压制量感

```
“神通圆满与未圆满之判：他九转剑意圆满，我七转便被压住三成锋芒。”
```

### 3.4 五行克制量感

```
“金行剑气对木行×２倍伤！……我本命神火却被这水行真元化去六成。”
```

### 3.5 敌情探知（入仙期完整式）

```
根基：金丹九转。
真元：３２００／３２００丈。
道行：悟道·金行，法则亲合金系。
神通：一气化三清（分神二）、天眼通（观百里）、御剑诀〈百丈化一〉。
法宝：赤霞掩日印（灵宝）。
肉身：金刚不坏身（小成）。
标记：身负古史一角，因果线牵暗潮。
```

### 3.6 境界清算（多阶段大战斩首后）

```
“击杀→抽魂炼气→真元＋××丈→掌握神通〈××〉→境界稳固（金丹九转不开退境）”
```

## 四、句式节奏特征

### 4.1 技能名破折号引出（快节拍）

> “——御剑诀〈纵切〉！”
> “——金光咒印！”

**规则**：技能名前加破折号，后加感叹号，独立成行或跟句末。用于连招快节拍。

### 4.2 压制免疫链（递进排比）

> “压不住。”
> “压不住。”
> “压不住。”

**规则**：每次独立成行，句号收束（非感叹号），制造冷静递进的无奈感。至少3次构成“链”。

### 4.3 五行相克（极短对仗）

> 金行的锋芒弥漫。
> 火行的灼焰肆虐。

**规则**：两句对仗，字数接近，结构一致。仅五行交锋高潮用。

### 4.4 环境破坏（拟声词独立成段）

> 轰隆隆！

**规则**：拟声词独立成段，用于山崩/灵脉断裂/巨物坠落的听觉冲击。每场最多2次。

### 4.5 多POV切换

**规则**：入仙期必须有多POV切换，至少每3章切1次非主角视角。

可用视角：敌方宗门弟子视角（呈恐惧/误判/被碾）、友方长老/同门视角（侧面评主角）、旁观者视角（呈战局影响）。

**切换技巧**：
- 段落间隙用场景转换标志引导
- 非主角视角更主观、情绪化，与主角冷静量感对比
- 每次持续1-3段，不宜过长

## 六、使用指引

### 6.1 加载条件

- 施工卡标注“主角今入仙期（金丹/元婴）”时加载本文件
- 施工卡战斗类型对应本文件7模式之一时，查模式详解渲染

### 6.2 模式选择逻辑

```
施工卡战斗类型 → 模式映射：
  御剑+神通混战      → 模式1
  法相/领域对抗      → 模式2
  强敌大战          → 模式3
  傀儡/灵兽        → 模式4
  宗门/大规模战役    → 模式5
  法阵/禁制        → 模式6
  五行生物         → 模式7
```

一场战斗可混多种模式（如强敌战中场召傀儡=模式3+模式4），但主模式不得连续3章重复。

### 6.3 决策树（可算的战局）

```
开局：探敌（完整式探知）→ 双方境界/真元/神通层次对比
  ├─ 同级或略低 → 正面对战（模式1/3）
  │    转折看“谁先耗尽真元/神通是否圆满破防”
  ├─ 高半境 → 借势/借阵/引敌入局（模式6+战术心账）
  └─ 高一境以上（碾压）→ 禁正面接招，寻风险窗口/借古阵/请法宝爆发
无敌中的变数：失控/时限/误伤/反噬——碾压局同样走4拍，禁“一招定胜负”
```

### 6.4 多POV切换检查

每3章检查1次：是否有至少1段非主角视角？

- 有 → 合格
- 无 → 下一章必须插入非主角视角段落

### 6.5 红线自查清单

- [ ] 量感格式匹配当前境界（真元××丈+分路，非凡人期一掌一剑）
- [ ] 连续3章未用同一种战斗模式
- [ ] 多阶段大战每阶段有明确攻防转换标志
- [ ] 至少每3章1次非主角视角切换
- [ ] 伤害分路（肉身+真元+神通+法宝），非单一
- [ ] 掉境风险时常铺设悬念
- [ ] 突破量感格式匹配境界段（丹香/紫气/星象）
- [ ] 首遇新敌弹完整式敌情探知
- [ ] 战斗以“谁先耗空真元/谁神通圆”为胜负判据，可算不玄
- [ ] 碾压型突破/爆发带风险窗口/反噬（禁只写强不写代价）
- [ ] 量感以叙述嵌入，非弹窗/光屏
