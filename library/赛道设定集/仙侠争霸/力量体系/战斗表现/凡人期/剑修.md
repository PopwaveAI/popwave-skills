# 战斗表现 · 凡人期-剑修（执行配方卡 v1.0.0）

> **这是操作手册，不是理念文档。** 面向 write 层（多为轻量模型）。你只要照着下面【第0步→第7步】的顺序填空，就能产出合格战斗章。看懂理念不如照做流程。
> **开工前必读（按顺序）**：①先读这个文件 → ②再用 Read 读合格模板《夜袭营地》式战斗章 + 对一下本赛道凡人期战斗的节奏（见 `战斗模式-凡人期.md`）→ ③动笔。模板就是“合格长什么样”的唯一基准，照着它写，别自己发挥。
> **一句话底线**：凡人期剑修走**地道近战**——御剑贴身搏杀、剑气纵横不过数尺，禁凡人动不动“剑光千里、千里取人头”。这是本赛道红线。

## 第0步：填四问（3分钟，不填不写正文）

动手写正文前，先在草稿写下这四句——正文里不出现，只用于约束你自己。

| 问 | 你要填空 |
|:--|:--|
| 战斗功能 | 打完后____变了（成长/夺物/暴露/信息/危机/关系，选1个写进结尾钩子） |
| 双方目标 | 主角要____，敌方要____（两边目标要不一样，禁止都是“杀光对方”） |
| 胜负条件 | ____发生=主角赢；____发生=主角输（拖太久被围/真元耗尽/大部队赶到，三选一） |
| 信息差 | 读者知道____但____不知道，在第____拍揭示（制造紧绷/爽感/意外） |

## 第1步：战前铺垫（写开篇100-200字）

**必做其一**（二选一，都能用）：
- 偷袭战→写**敌方视角短铺垫**：敌方对话（收了钱退无可回/落单历练）→环境转场→落单。主角出场前不露面、剑不出鞘。
- 遭遇战→主角**胜算内心算账**：看清敌人数量/装备/所处境界，判断“能打还是该撤”，用引号写判断（例：`“对面是成了气候的魔修，别硬接，绕他刀长项。”`）。

**禁止**：战中才想起来算账；主角一上来就“怒啸一声拔剑冲天”。

## 第2步：出手（1-2拍，打核心敌人）

- **出手前必有拟声或动作先兆**（剑出鞘的“铿锵”/脚下点地的“哒”/御剑就位的“嗡”），再写致命一击。致命一击必须写**落点**（打哪），而且要讲得通：打“护体甲的接缝”“咽喉下颔”“肩井后那处背身空当”，别只写“他挺剑刺出”。
- 御剑贴身三选二：①**贴身搏杀**（剑随人走，三尺内换剑势）②**剑气横掠**（借剑气压迫，实则刺向要害）③**环境借势**（借地形/借灵植/借阵法边缘）。
- **打斗时长为短**：正面交锋压缩在几十秒内（例“短短几十息”）。剑修走快剑，绝不打持久战——一察觉拖久了，立刻安排转折结尾。

## 第3步：量感结算（格式硬约束，照抄不要改）

第一杀用量感结算。**格式唯一，无第二写法**：
- 每行 = **一句 + 一个确证**（境界/数值/落点）。禁止用【】包裹（【】只给法宝/招式名用）。
- 标准顺序（5行，照抄顺序）：
  ```
  第一剑破护体真元三寸，剑尖刺入咽喉。
  对手为筑基三层魔修，比主角高一层。
  主角凭“剑气凝一线”以快破力，一击中的。
  敌境虽高我半头，御剑贴身反而压住他长刀。
  生死分晓——出鞘一剑，落点两寸，取了性命。
  ```
- **拟声在前，结算在后**（先“锵”出剑/“嗤”入肉，再写量感）。禁止结算先于声音。

**结算后必须紧跟一段“为什么能赢”的解释**（秒杀不是运气，是算计）：
> 例（照这结构写）：“他刀厚是真厚，可长刀的破绽在刀门——我一剑贴身，压着他刀门短打，他三尺多的刀根本转不开。筑基三层又如何，急不得我快剑半步。”——写清“快剑贴身压长兵＋境界虽低但近身便是主角主场”这层算账。

## 第4步：续战（1-2拍，第二位敌人/转折）

- **同类连杀只结算一次**：第二个敌人非死不可也用叙述带过（“顺势一剑补了”），不再写第二段量感结算。
- **每占便宜必挨一下**：主角得手后，必须挨一次还击（被刮到/剑气反震/被迫弃一手剑势），写一处小伤。
- 可在一章内破境（只用一次，做转折，并外显一丝气机变化）。

## 第5步：转折与收尾（决定“会不会死、怎么脱身”）

- 设置**倒计时或增援**制造压力（敌方增援脚步声/毒效将尽/真元不济），逼主角**速战速决或撤退**。
- 主角要显**判断力**：识破陷阱/判断“这剑刺不透他金刚身，只能切那处旧伤”级取舍/选定逃跑路径。禁止无脑莽。
- 撤退用“借地形/借烟气/一剑剑气逼退再走”，撤退后**听身后声渐远**再停下。

## 第6步：战后结算（收获与损失两栏必须同时写）

**收获至少写3样**：经验/修为精进（数值要自洽：杂兵三五日修养、筑基敌则是一次大萃取）＋钱/物（翻尸清单，写具体物名）＋剩一样（剑术成长/声望称号/情报/新线索，选1）。

**损失至少写3样**，且每一种都要“有代价地写”：
- **伤**：写明部位+程度＋处理动作（“撕裂后衣裹住剑伤，乘夜得重新换药”），伤要带到章末甚至下章。
- **耗材**：剑气真元耗了一半/灵剑缨断了一根/符一枚烧了/缠剑的布条扯裂（写具体数量）。
- **暴露/隐患**：目击者/验尸发现剑口/诨名开始被传/树了未知之敌（这条就是要埋进结尾钩子）。

## 第7步：收束三段 + 结尾钩子（写最后100-150字）

1. **收剑仪式**：一个动作＋一句气（例：`锵。回剑入鞘，长吐一口浊气，就着残阳缠起剑伤。`）
2. **生活流切换**：从血战切到烟火气（残破客栈/吃面/店家笑骂/晨雾），形成反差。
3. **结尾钩子**：收口在“下一步/隐患/未解之谜”，必须让读者想知道下章（例：那人临终塞进他袖里的一枚玉牌，上头烙着一支眉眼——"原来是他"）。**禁止平淡收尾**。

## 量感格式速查（照抄改数字即可）

| 场景 | 行数 | 末行写法 |
|:--|:--|:--|
| 秒杀（贴身一剑） | 5 | “生死分晓——出鞘一剑，落点两寸，取了性命。” |
| 未秒杀 | 4 | “敌重创遁走，剑气染血。” |
| 战中破境 | 3-4 | 带成长数值，如“真元从两百丈涨至三百丈，剑气凝一线。” |
| 战后总结 | 3 | “御剑三尺+1、剑气横掠+1……” |
| 首遇鉴敌 | 6 | “切入难度：乙－。”（动手前亮） |
| 招式/法宝 | 描述式 | 用【】，如“【赤霞掩日印】护身借日晖，克阴邪” |

## 红线（写完逐条自查，全过才交付）

1. **地道近战三件套齐**：御剑贴身＋剑气只用近身/数尺＋战术心账（算境位差分）。纯“千里飞剑”=废。
2. **御剑不越段**：凡人期剑不离身，换剑势在数尺内；御剑飞行/飞剑千里=本赛道红线，禁。
3. **不算账不动手**：出手前内心有一句境位/打法判断。禁“怒啸冲天”。
4. **量感在前面板逻辑在后**：拟声在前，结算在后，量感结算后紧跟解释段。
5. **同类连杀一次结算**；破境一章一次。
6. **收获必有损失**：两栏各≥3项，收支同落账，禁止只记收获。
7. 视觉/词汇按上面表，**禁止“御剑千里/身法/真气”等神词玄词**。
8. **结尾必须有钩子**：收在未知数上，禁止“一切都好”白开水收尾。
9. **碾压必带代价**：破境/剑气爆发后必须写代价（真元耗竭/剑伤/反震），禁只写强不写代价。
