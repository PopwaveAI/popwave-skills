# 战斗表现 · 战斗模式-凡人期（仙侠赛道）

> 定位：凡人期（炼气/炼体/筑基前）的战斗=近战缠斗、兵刃拳脚、武者对抗、借势。此段是「主角从凡到仙」的第一层，战斗写「肉身/兵刃/市井/借势」，禁凡人动不动御剑千里。

## 一、5模式15子型

| 模式 | 子型 | 说明 |
|:--|:--|:--|
| 近战缠斗 | 拳脚/兵刃/棍棒 | 贴身短打，写「力/速/闪」 |
| 武者对抗 | 切磋/生死斗/江湖仇杀 | 有来有回，境界差可算 |
| 借势 | 地形/人质/机关/援军 | 借势可量变转质变 |
| 群战 | 被围/突围/斩首 | 多线视角 |
| 首弑借调 | 第一次杀人/第一次越境 | 心理戏+后遗症（见下） |

## 二、7面板（凡人期可用的「量感」工具）

| 面板 | 说明 |
|:--|:--|
| 体力/耐力 | 久战力竭，需喘息 |
| 真元/内息 | 吐纳补充，耗尽即衰 |
| 伤势 | 内伤/外伤，影响战力 |
| 兵刃耐久 | 断刀/卷刃 |
| 地形 | 借势/受限 |
| 援军/人质 | 守护/牵制 |
| 时间 | 追逃/围城/守护 |

## 三、首弑借调（第一次杀人）

- **写法**：第一次杀人后写大段心理活动（震惊/愧疚/麻木），后续逐步习惯；
- **后遗症**：杀人有因果/业缘/梦魇，作为后续钩子；
- **禁**：第一次杀人轻描淡写（味漂移）。

## 四、句式节奏

- 短句快节奏，动作直给（「一拳砸出」「侧身闪过」）；
- 拟声词适度（「砰」「嗤」「哐当」）；
- 禁长句铺陈战斗（战斗要快、要爽）。

## 五、红线

- 禁凡人期御剑/飞遁/千里取人头（味漂移）；
- 禁「主角一招秒全网」——凡人期碾压也需铺垫+代价；
- 战斗必带「一个因果/一个取舍」，禁纯动作堆砌。
