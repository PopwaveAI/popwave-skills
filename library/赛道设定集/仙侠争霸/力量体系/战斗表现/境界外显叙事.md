# 境界外显叙事（仙侠赛道）

> 战斗表现叠加层按需加载文件 | write 层按需加载
> 适用境界：全境界通用（凡人期至证道者期）
> 依赖文件：`凡人期/战斗模式-凡人期.md`、`入仙期/战斗模式-入仙期.md`、`证道者期/战斗模式-证道者期.md`（各境界段异象格式来源）、`数据化分析.md`（境界数值锚定）

## 一、境界外显的本质

境界外显不是「弹窗提示」，是本赛道特有的纪律：**读者看得见的变强**。主角的每一次大境界突破、每一次战力质变，都必须以「天地异象＋气机外放」的形式写出来——异象就是境界的数值刻度，读者凭异象规模就能读出主角强了多少。

核心原则：
- 突破不是主角心中暗喜“我又强了”，是**天象/灵光/雷劫/气机**在众目睽睽之下显形
- 异象是数值外显——异象规模（冲霄多高/丹香盈亩/波及几里）就是境界数值的具象
- 境界数值（层/转）必须与异象规模锚定，读者能“看见”倍数
- 威压外放同样是数据——压了多少里、压弯了几株灵木、逼退了几层修士

异象的本质是「主角的战力状态被世界感知」。当主角突破，通天的灵光、奔驰的紫气、落下的雷劫，不是装饰，是读者读出的成长刻度。

## 二、异象弹出时机表

| 场景 | 外显什么 | 频率 | 规模锚 |
|------|--------|------|---------|
| 引气入门 | 灵气入体，灵窍生光 | 全书1次 | 周身数尺灵光 |
| 小境界突破 | 气机外放／金光微亮 | 每破一次小境弹 | 观者能觉气息一变 |
| 大境界突破 | 天地异象显形（丹香/金光/紫气） | 每次大境突破必显 | 详见第四节规模梯 |
| 渡劫／证道 | 雷劫／天哭／金莲涌地 | 每渡一劫必显 | 详见第四节 |
| 战力质变（无境界跃迁的质变） | 灵光冲霄／神威外放 | 质变冲突节点显 | 同境界大爆锚 |
| confrontation压力章 | 威压想压／气机对比 | 可显 | 二号主角对阵强敌前 |
| 幕末/卷末盘点 | 完整境界状态 | 可显 | 一览式境界总账 |

**频率说明**：
- 必显＝无条件写异象外放，漏写即不合格
- 首显＝全书仅首次突破时详写，后续同类小突破可简化
- 可显＝根据章意图决定，显与不显都合格
- 大境界突破必显是硬的，禁「境界提升」四个字带过

## 三、突破异象意识流写法

### 3.1 基本格式

突破段落以「内视＋外放」双线嵌入叙述：先写体内道基变化（内视），再写天地异象外显（外放）。异象用引号/白描嵌入，配合气机波动的节奏。

**示例**：

> 丹田深处，那枚金丹忽地一颤，万缕金光从窍穴里外溢——周身的灵气在这一瞬被抽空半丈方圆。
>
> “金丹九转成。金光冲霄三丈，灵雀绕飞，百丈内兽鸟蛰伏。”
>
> “真元暴涨，渡劫之基自足，可窥元婴之门。”
>
> 山门外打坐的弟子们齐齐抬头，望见那道金光刺破晨雾，压得一旁筑基长老失手捏碎了茶盏。

### 3.2 内视与外放双线

- 内视写“道基怎么变”：金丹转、元婴凝、道行合——境界数值的来源
- 外放写“天地怎么应”：灵光/雷/霞/紫气/兽惊——境界的规模刻度
- 内视与外放成对推进，先内视（根因）后外放（果证）

### 3.3 异象不是弹窗

| 错误写法 | 正确写法 |
|---------|---------|
| “眼前弹出一个境界提示：金丹圆满。” | 突破以“丹田金丹一转”内视＋“金光冲霄”外放嵌入叙述 |
| “系统提示：境界提升。” | “金丹九转成——真元暴涨”以境界数值＋倍数显现 |
| “半透明的境界面板在视野展开……” | 异象是天地感知，不需UI式展开 |

### 3.4 突破段落在章节中的插入位置

| 插入时机 | 说明 |
|---------|------|
| 破境瞬间 | 金丹凝成／元婴破体的刹那，外放异象 |
| 修士闭关出关 | 出关时以威压/灵光外显，不必写漫长修炼 |
| 战斗中被逼破境 | 边战边破，异象因战斗放大（破境既保障也风险） |
| 渡劫节点 | 雷劫降下的全程，配合天劫节奏 |
| 剧情节点 | 非突破章节在战力展示处可外显气机 |

## 四、各境界段异象规模递进

异象随境界递进，规模逐级抬升。当前境界段的异象格式从对应等级段文件加载。

| 境界段 | 异象风格 | 核心特征 | 规模参考 |
|--------|---------|---------|---------|
| 炼气初～圆满 | 微光 | 灵窍生光、气息外放，境界相反 | 外放数尺～寻丈 |
| 筑基/培元 | 金光 | 金光护体，御剑之基显，可开宗门基层 | 金光半矮～盈盈尺许屋 |
| 金丹 | 丹香+冲霄 | 金丹成→丹香盈亩、灵光冲霄，雀绕鹤舞 | 冲霄三丈～十丈，香飘一亩 |
| 元婴 | 紫气+灵婴 | 元婴破体·紫气东来，一域皆见 | 紫气弥山旷野，百里可见 |
| 化神 | 星象+玄门 | 神识入微·玄门大开，天光垂落 | 星光垂落，一界感应 |
| 合道 | 天地同感 | 与大道相合，山川河岳齐鸣 | 异象动摇天地一隅 |
| 渡劫 | 九重雷劫 | 每劫一异象，雷光/心魔/业火坠落 | 雷云罩百里 |
| 大罗/混元 | 天哭+金莲 | 法则显化·金莲涌地/天哭陨光 | 波及大洲/界域 |
| 超脱 | 秩序书写 | 大道自叙，古史回响 | 波及整个宇宙秩序 |

**递进逻辑**：
- 低境界异象是“个人/小范围”——灵光几尺，几个门人看见
- 中境界异象扩到“一域”——百里可见的紫气，一域修士动
- 高境界异象扩到“一界/一洲”——天哭金莲，跨界生感
- 顶级境界异象是“秩序级”——天地因主角证道而改写

**境界/异象规模映射表（数值锚）**：

| 境界 | 层/转 | 异象规模（对标西幻dnd升延时） | 战力倍数（对凡） |
|:--|:--|:--|:--|
| 炼气初 | 一层 | 灵窍微光盈尺 | ≈1 |
| 炼气圆满 | 九层 | 金光冲霄寻丈 | ≈3-5 |
| 筑基 | 一层→九层 | 金光盈屋→护体成阵 | ≈10 |
| 金丹 | 一转→九转 | 丹香半亩→冲霄十丈 | ≈30 |
| 元婴 | 一婴→数婴 | 紫气弥野→百里皆见 | ≈100 |
| 化神/合道 | 玄门→合道 | 星光垂落→天地同感 | ≈数百 |
| 大罗/混元 | — | 天哭/金莲→波及大洲 | 千倍以上 |

## 五、境界大爆数值外显（全段盘点必显）

每个大境界突破、战力质变时，异象之外必须带一层「数值外显」——用可比的数字把这次变强钉进读者脑子里。对标使用手册「境界大爆每卷≥3次数值外显」。

**格式**：
```
境界：〔旧〕→〔新〕。
修为：真元〔数值〕，跨〔境〕。
异象：〔外放描述，规模数字〕。
与下境差距：〔战力倍数/成形距离〕。
```

**示例**：

> 境界：筑基九层→金丹初成。
> 修为：真元从三百丈暴涨至三千二百丈，跨过凡人境天堑，正式踏入修行界上层。
> 异象：金光冲霄十丈，丹香盈亩，整座山门残枝被灵光熏得更绿三分。
> 与下境差距：距元婴，尚隔一境三倍鸿沟，须再磨神通之圆。

**写法要点**：
- 数值外显里“旧境→新境”“真元暴涨数值”“异象规模”三栏必须齐
- 倍数要能以参照物读出来（“从三百丈到三千二百丈”＝读者立刻算得十倍）
- 异象规模用具体数字（十丈/一亩/百里），不用“漫天霞光”这类纯形容
- 境界大爆是真数值，与力量体系/力量体系.md的跨境3-5倍锚一致

## 六、威压领域与倒影（confrontation_pressure特有）

这是主角“在算”的威压对比可视化，不是系统界面。用于对强敌/不知深浅的高人时，展示主角的境界判断与忌惮。

**格式**：
```
对方境界评估：〔境位转/层〕。
威压对比：对方〔压实力度〕，我方〔承压反应〕。
正面接招把握：〔成数〕。
应对方案：〔引/避/借阵/合击〕。
```

**示例**：

> 沈尘的目光落在那人身上，神识与对方气机一触即离。
>
> 对方境界评估：元婴六转。
> 威压对比：对方气机如山，我方金光被压得贴着体表。
> 正面接招把握：四成。
> 应对方案：引他入山门古阵，借合道守势接抵，再以剑诀耗其元婴真元。

**写法要点**：
- 这是主角的「内心算账」，不必弹出异象或面板——不实写外放，写评估
- “成数”是主角主观估算，可有误差
- “应对方案”必须与后续剧情一致——说了怎么打就怎么打
- 仅confrontation章用此格式，其他章不用

## 七、世界级异象（reveal_hook特有，首次幕末）

用于世界级大事件/古史显形时。展示天象级异变对世界的影响，与角色个人异象区分。

**格式**：
```
【天地异象】××
波及：××（地域/界域）
影响：××（修行界/凡间各层反应）
```

**示例**：

> 那天，天穹一隅忽然裂开一道缝，紫芒倾泻，山河齐鸣。凡间惊呼是天光，修士们却认得——是黑暗动乱未散的残兆。
>
> 【天地异象】古史一角显形
> 波及：整个东域，波及千里灵脉
> 影响：各宗门连夜查古史，凡间以“仙人降世”讹传。

**写法要点**：
- 世界级异象用【】包裹异象名，与角色个人突破异象区分
- “波及”“影响”各1行，信息精炼
- 世界级异象弹出后，该事件必须在后续5章内对主角产生直接影响
- 幕末首次弹世界级异象时，标志剧情从“个人成长”向“世界级冲突”升级

## 八、完整境界状态（幕末/卷末特有）

用于幕末或卷末，完整盘点主角当前境界。相当于“存档点”，让读者在幕/卷结束时看清成长进度。

**格式**：
```
姓名：××。体质／灵根：××。
境界：〔主养成境界层/转〕＋〔子养成线〕。
修为：真元××丈。肉身：××。
神通：××（层）、××（层）。
法宝：××、××、××。
因果/道行：××。
```

**示例**：

> 第一幕·终。
>
> 姓名：沈尘。灵根：先天木灵根。
> 境界：金丹九转＋御剑诀大圆满。
> 修为：真元三千二百丈。肉身：金刚不坏身（小成）。
> 神通：御剑诀〈百丈化一〉、天眼通（观百里）、一气化三清（分神二）。
> 法宝：赤霞掩日印（灵宝）、青木玄雷剑（灵宝）、敛息玉。
> 因果/道行：悟道·金行成，身负古史一角，因果线已牵。

**写法要点**：
- 完整境界盘点独占段落，前后用空行与叙事隔离
- 境界行含“主养成境界＋子养成线”双轨
- 神通/法宝列举3-6项，含层次
- “因果/道行”是本赛道特色字段——记录主角背负的古史线索/道果进程，体现信息积累
- 仅在幕末/卷末使用，章节内不用

## 十、红线

1. **突破必显异象红线**：大境界突破必写天地异象外放（灵光/丹香/紫气/雷劫/天哭）。“境界提升”四个字带过＝不合格。
2. **数值外显红线**：境界大爆必有数值外显（旧境→新境＋真元暴涨＋异象规模），三者齐备。缺任一＝不合格。
3. **异象意识流红线**：异象以「内视＋外放」嵌入叙述，禁弹窗/光屏/UI式展开。
4. **异象规模匹配红线**：异象规模必须匹配当前境界段（炼气几尺光、元婴百里紫气……）。规模错位＝不合格。
5. **威压评估使用红线**：威压对比评估仅在confrontation章使用，其他章不用。
6. **世界级异象回收红线**：世界级异象弹出后，该事件必须在后续5章内对主角产生直接影响。
7. **完整盘点一致性红线**：完整境界状态仅在幕末/卷末使用。数据必须与当前叙事中已弹出的一致，不得前后矛盾。
8. **异象与战力绑定红线**：碾压型突破（请神/绝杀/巨宝）必须配风险窗口/时限/反噬——异象越大，代价越要明写（雷劫/业火/道基受损），禁只写强不写代价。
