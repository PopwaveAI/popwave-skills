# 战斗表现 · 多线叙事（仙侠赛道）

> 定位：一场大战/一件世界级大事件，往往需要多线镜头推进。本件给「POV切换技法+必切场景+大事件叙事法」。

## 一、POV切换六类技法

| 技法 | 说明 | 适用 |
|:--|:--|:--|
| 主位跳切 | 主角视角为主线，跳切对手/旁观者 | 大战、试探 |
| 敌位切入 | 短暂切到对手，让读者知其计划（制造紧张） | 埋伏/计谋 |
| 群像远景 | 一瞬拉大，写天地/战场全貌 | 世界级事件/跨界 |
| 旁观回放 | 事后再补，写余威/传播 | 打完回城见闻 |
| 内部独白 | 主角心理小段（不打断主台） | 转折/决断 |
| 体制对冲 | 两个阵营视角并置（截取因果） | 因果战/业缘战 |

## 二、必切场景（哪些场景值得切POV）

- 主角在布局、而读者需要看到另一头在酝酿时（切对手/切师父）；
- 主角救人/守塔，切被救者/战场众生相（情感落点）；
- 世界级敌人登场，切「高塔/王朝/仙域」的反应（政局反应写威名）；
- 我方被围/被算计，切「暗处射箭之手」给紧张感。

## 三、世界级大事件叙事法（跨界/大战/古史显形）

1. **前置征兆**——先给大事件一个「起风前」的镜头（山雨欲来/灵潮异动）；
2. **多方视角入场**——大帝、宗门、凡尘三个层面各有镜头（政局/修行界/市井）；
3. **主战场旁观者镜头**——天地异象+底层修士仰望，把「此战的分量」钉死；
4. **余波收尾**——威名/格局/因果在一段时间后予以结算（禁战斗结束即散）。

## 四、红线

- POV切换要有意义（推进情报/制造紧张/落情感），禁为切而切；
- 世界级大事件禁「主角独角戏」，须有天下反应；
- 切POV时用短自然段锁住节奏，别在切换中掉进「上帝俯瞰长篇说明」。
