> 战斗表现叠加层按需加载文件 | write 层按需加载
> 适用境界：全境界通用（凡人期至证道者期）
> 依赖文件：`境界外显叙事.md`（境界与异象意识流写法）、`凡人期/战斗模式-凡人期.md`（简式敌情格式来源）、`入仙期/战斗模式-入仙期.md`（完整式敌情格式来源）

## 一、敌情探知面板

首遇新敌类型时探知。以神识灵魄之探、天眼通视、气息辨阶的方式嵌入叙述，不以弹窗/光屏形式弹出。同类敌人后续不再重复探（异种/精英/头目视为新类型）。

### 1.1 简式（凡人期）

适用凡人期（1-4境：炼气初境～筑基/培元，金丹前），探知内容简略，5栏以内。

**格式**：
```
“〔名称〕【〔种族/命格〕】（〔境位〕）。”
“修为〔境位〕X层，〔练法类别〕。”
“肉身〔体魄〕，真元〔厚薄〕，最高者〔肉身或真元〕。”
“罕见手段：〔神通/法宝/毒/异术〕……”
“切入难度：〔甲/乙/丙/丁〕±”
```

**示例**：

> 神识一探，那人身上的炁便尽数落入眼底。
>
> “〔黑煞刀客〕【魔修·练气】（筑基初境）。”
> “修为筑基一层，刀氏魔刀路数。”
> “肉身精壮，真元中平，最高者为刀意（可越半境）。”
> “罕见手段：淬毒暗刃、魔元断魂。”
> “切入难度：乙＋。”

### 1.2 完整式（入仙期＋）

适用入仙期及更高（5-9境：金丹/元婴 → 化神/合道 → 渡劫/大罗/混元），探知含专属资源、道行、神通、法宝、法则印记等完整信息。

**格式**：
```
根基：〔金丹/元婴〕X转。
真元：XXX/XXX。
道行：〔悟道层次〕，法则亲合〔属性〕。
神通：〔神通1〕（〔效果/次数〕）、〔神通2〕……
法宝：〔法宝名〕（〔阶级：凡器/灵宝/神器〕，〔特性〕）。
肉身：〔体魄层次，金刚/法身〕
秘术/印记：〔古史根脚/因果印记/劫祸真相〕
```

**示例**：

> 灵魄探入，那人周身道韵便如灯火般亮起。
>
> 根基：金丹九转。
> 真元：三千二百丈／三千二百丈。
> 道行：悟道·金行，法则亲合金系。
> 神通：一气化三清（分神二，各具七成战力）、天眼通（观百里）、御剑诀〈百丈化一〉。
> 法宝：赤霞掩日印（灵宝，护身借日晖，克阴邪）。
> 肉身：金刚不坏身（小成）。
> 秘术/印记：身负古史一角，因果线牵「黑暗动乱」旧账。

### 1.3 简式与完整式对比

| 维度 | 简式（凡人期） | 完整式（入仙期＋） |
|------|--------------|-----------------|
| 栏数 | 5栏 | 8-10栏 |
| 基根/真元 | 无（用道行类别代替） | 有（×××/×××格式） |
| 专属资源 | 无 | 有（真元/道行/法则印记等） |
| 神通 | 无 | 有（含效果/次数） |
| 法宝 | 用「罕见手段」概括 | 逐项列举（含阶级/特性） |
| 秘术/印记 | 无 | 有（含古史根脚/因果） |
| 适用境界 | 1-4境 | 5-9境 |

### 1.4 敌情探知写法要点

- 命格/种族用方括号【】：【人修】【魔修】【妖修】【鬼修】【尸修】【异族】【神裔】
- 境位用圆括号（）：（炼气初境）（筑基境）（金丹境）（元婴境）……凡人期敌人通常为炼气/筑基/培元
- 战士境界用「境位＋层数」双锚：筑基三层 / 金丹五转，境界必须落到具体层/转
- 切入点难度用甲乙丙丁＋±：丁− < 丁 < 丁＋ < 丙− < 丙 < 丙＋ < 乙− < 乙 < 乙＋ < 甲− < 甲 < 甲＋
- 完整式的专属资源随敌类变化：魔修用「魔元」、鬼修用「阴煞」、妖修用「妖丹/妖气」等
- 探知面板弹出后，同类敌人后续不再重复探（异种/精英/头目除外）

## 二、体感反推（气血/神识/威压三路）

不直接探知敌人时，通过交手的身体感受反推敌人境界。这是凡人期最常用的「境界感知」写法——主角通过战斗中的体感，将身躯反应转化为修为判断。

### 2.1 气血反推（肉身力量）

| 体感描写 | 反推境界 | 说明 |
|---------|---------|------|
| “手臂发麻” | 炼气中层以上 | 硬碰硬后手臂酸麻，对方气血明显壮于常人 |
| “胸口一闷” | 炼气圆满 | 正面受一拳冲击，气血入心 |
| “差点脱刀” | 筑基境 | 格挡后兵器险些易手，对方已是修行者 |
| “被震退丈外” | 高境碾压 | 硬接一击被迫后退丈许，气血完全不是一个层级 |

**示例**：

> 铛。
>
> 铁剑重重砍在黑刀上，那人的刀口一沉，虎口一股巨力顺着刀柄撞进臂骨——仅仅是一下狠碰，他的手臂就开始发麻。
>
> 气血炼气圆满，他强过我半层。硬碰无胜算，得借他刀路大开时的空档寻隙而入。

### 2.2 神识反推（静止/神速/剑遁）

| 体感描写 | 反推境界 | 说明 |
|---------|---------|------|
| “跟不上他的身形” | 速度落差过大 | 对方身法远超神识捕捉 |
| “只辨一道残影” | 金丹遁速 | 神识锁定不住对方移动轨迹 |
| “动作快得不像常人” | 培元·锻体者 | 明显高于武人范畴，但勉强能追 |
| “气息一敛如死物” | 化神神识 | 气息完全收敛，若非照面根本察之不着 |

### 2.3 威压判定（境界压制）

威压是境界差距的直接外显——用到「威压判定」时，通常已跨一大境界（3-5倍战力以上）。

| 体感描写 | 反推境界 | 说明 |
|---------|---------|------|
| “肩头有千钧压” | 跨一中境 | 对方境界高于自身，孟浪出手会招大祸 |
| “双腿如灌铅” | 跨一大境 | 仅余威势便压人喘不过气，战力差在3-5倍之上 |
| “神魂被钉死般战栗” | 高境威压/道果显形 | 神念被压，连逃的余地都被封死 |

### 2.4 体感反推写法要点

- 反推后必须紧跟战策（专破刀长/绕后/劝退），禁只判不动
- 反推是主角的「战斗直觉」，不必弹出探知面板——是经验判断，允许有误
- 体感反推用于「来不及探知面板」的场景（遭遇战中来不及细探）
- 同一场战斗，体感反推最多用2次（气血/神识/威压各算1次），第3次起应正式探知或用旁白带过

## 三、境界伤害分路（入仙期＋）

入仙期（5-9境）开始，伤害不再是单一总数，而是分路结算。肉身/真元/神通/法宝各成一类，对应不同承伤方式与减伤规则。

### 3.1 基本格式

伤害分路弹出，各路单独结算：

**示例**：

> “赤霞掩日印镇下，肉身伤三百丈、真元伤一百八十丈！……剑诀余锋却只透进两尺就碎——此人金刚不坏身太厚。”

### 3.2 含防/免信息

敌人对某路有减免时，探知/结算必须反映：

**示例**：

> “魔修炼体五百载，肉身可免七成真元之伤！……我这一剑穿透护体真元三寸，却被他金刚身硬扛下来，只溅了两分血。”

**写法要点**：
- 减免信息用感叹号＋省略号引出，带惊讶语气（“却只溅了两分血”）
- 减免比例用“七成/九成以上”等模糊表述，不用精确到小数
- 减免后的实际伤害必须低于理论值，差额即减免效果
- 境界伤害分路是入仙期核心结算特征，凡人期不用（凡人期伤害是单一总数）

### 3.3 常见伤害路类

| 伤害大类 | 具体路类 | 典型减免者 |
|------------|---------|-----------|
| 肉身伤 | 兵刃劈砍、拳脚所骨、暗器 | 金刚不坏身（免七成+）、炼体雄者（减伤） |
| 真元伤 | 剑诀真元、掌力吐息、本命神火 | 魔修真元（互引相克）、护体重甲（化元） |
| 神通伤 | 天眼束光、一气化三清、法象显化 | 道行高者（神通复合被破）、法则亲合者（免对应属性） |
| 法宝伤 | 灵宝镇杀、神器之威、法阵辗压 | 同阶法宝护体（对耗）、古史遗物（记根脚） |

### 3.4 分路结算写法要点

- 肉身伤细分为劈砍/刺扎/钝击，与兵刃类对应；真元伤与功法属性对应
- 神通伤与悟道层次对应（道行越深，神通越难抵御）
- 每次结算分路不超过3类（肉身＋路加护＋特殊效果）
- 减免/抑制信息只在首次对该敌人该路伤害时探知，后续同类用旁白带过

## 四、境界标尺锚定

探知/弹境界数值时，必须在同章内用参照物锚定。

### 4.1 锚定规则

- 境界数值弹出后，同章内必须出现至少1个参照物锚定
- 参照物可以是：凡人/武人水平、具体宗门弟子、已知角色、体感描述
- 同一参照物跨章间隔 ≥ 3章（避免反复用同一锚点）

### 4.2 锚定方式

| 锚定方式 | 示例 |
|---------|------|
| 直接锚定 | “金丹一转——这意味着同等阶唯有亲自出手方能破我剑阵。” |
| 比较锚定 | “元婴境，已是能开宗设坛的一方强者，压我一整个大境界。” |
| 体感锚定 | “仅余威我便胸口发闷，境界至少高我一境。” |
| 参照物锚定 | “化神境——境界金字塔上，一域能出几位化神？此人已是一界顶尖。” |

### 4.3 境界参照梯子（战力倍数锚）

| 境位 | 定性 | 战力倍数（对凡）/参照 | 跨级对主角局面 |
|--------|------|---------|------------|
| 炼气初境 | 凡人锻体 | ≈1倍，寻常武人 | 可与之一换一 |
| 炼气圆满 | 武人之上 | ≈3-5倍凡人 | 需借力/切兵器方胜 |
| 筑基境 | 修行者门内 | ≈10倍 | 正面难，得靠法宝/暗算 |
| 金丹境 | 一域强者 | ≈30倍（跨一境3-5倍梯度） | 碾压，须借阵/借势/损耗 |
| 元婴境 | 可开宗设坛 | ≈100倍 | 需引敌入局，硬碰九死一生 |
| 化神/合道 | 一界顶尖 | ≈数百倍 | 靠道行/法则周旋，禁正面接招 |
| 大罗/混元 | “不朽”起点 | 千倍以上 | 打的是道，拼的是局，非力可及 |

## 五、战境评估（境界差视角的“需要怎么打”）

用“己方阵容 vs 对手”的视角反推敌我实力。战境评估不是单纯数值对比，而是「需要什么配置/什么打法才打得赢」的实战判断。

### 5.1 评估格式

**示例**：

> 若按修行界的老话，我如今的金丹境，对上这尊化神，便是一境三倍有余的鸿沟。
>
> 换作旁人早该逃——除非我引他入身后的古阵，借道行合道守三，才有一两成翻盘的余地。

### 5.2 评估写法要点

- 战境评估用“修行界的老话/老人家常言”作信息来源——主角借修行界经验推断世界表面的实力秩序
- 评估结果用「配置＋该成把握」格式：“跨一境三倍鸿沟”＋“只一两成翻盘余地”
- 战境评估用于关键节点：主角实力质变时、遭遇超规格强敌时、幕末/卷末实力盘点
- 可评自身（“我如今金丹境”）也可评敌人（“这尊化神”）

### 5.3 战境评估与切入难度的区别

| 维度 | 战力倍数评估 | 切入难度 |
|------|---------|---------|
| 表述方式 | 战力倍数（×3倍/×30倍）+境界层数 | 甲乙丙丁+± |
| 出现位置 | 敌情探知第2栏 + 独立评估段 | 敌情探知末栏 |
| 含义 | 敌我实力量化为倍数 | 对主角个体的打法难度评档 |
| 使用频率 | 凡人期内探知 + 入仙期独立评估段 | 仅凡人期探知内 |

| 技法 | 适用境界 | 触发条件 | 核心功能 |

## 七、红线

1. **敌情探知红线**：首遇新敌类型必探知。同类后续不重复（异种/精英/头目除外）。漏探＝不合格。
2. **境界锚定红线**：探知弹境界数值时，同章内必须用参照物锚定。同一参照物跨章间隔 ≥ 3章。纯数字无锚定＝不合格。
3. **伤害分路红线**：境界伤害分路只在入仙期＋使用。凡人期伤害为单一总数，不分路；入仙期＋不分路＝不合格。
4. **体感反推红线**：体感反推后必须紧跟战策，禁只判不动。同一场战斗体感反推最多2次。
5. **探知格式匹配红线**：简式仅用于凡人期，完整式用于入仙期＋。格式错位＝不合格。
6. **战境评估红线**：只在关键节点使用（质变/遭超规格强敌/幕末卷末盘点），不滥用。
7. **境界标注红线**：敌人必须标明境界（境位＋层/转），禁模糊“很强/恐怖如斯”。不标境界＝不合格。
