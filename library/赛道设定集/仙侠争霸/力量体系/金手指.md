# 金手指 · 仙侠赛道模板

> 定位：金手指=主角越阶的「根源」。本赛道金手指普遍带古史重宝/传承/洞天/灵脉形态，价值随境界而觉醒（越后期越利害），是三约束的铁约束执行点。

## 一、金手指三约束（强制，任何形态必须满足）

1. **key非生成器**——金手指只「记账/点化/借力」，不凭空产出资源；越后期越重「借力」「显形」，但**绝不无条件白给**（例如古灯只照亮、不点石成金）；
2. **赋能不越级**——只能在当前境界内变强；想跨大境界必须同时满足境界/悟道/资源多项前置，禁「宝物一拿秒天秒地」；
3. **限制显性**——代价/时限/反噬必写进设定（押寿/雷劫/走火风险/因果债）。限制越显性，追读越稳。

## 二、金手指模板（选型骨架）

| 组件 | 说明 | 选择项 |
|:--|:--|:--|
| 形式 | 金手指的外壳 | 古史重宝（古灯/棺/玉）/传承功法/洞天福地/灵根变异/天书经文 |
| 能力 | 它能做什么 | 现识他物/借古力/修炼加速/识破谎言/御物破禁/因果视 |
| 限制 | 有什么代价 | 押寿命/雷劫/反噬/因果债/有主人渊源才肯帮 |
| 成长 | 越后期越强 | 觉醒层次越多/传承越深/县点暴击越高 |

| 遮天·五色祭坛 | 跨界门户 | 接引/传送+反应的故事机 | 五色祭坛专名 | 跨星域流 |

## 四、三约束落地自查

- [ ] 金手指从不「免费吐币」，所有增强都有来源/代价；
- [ ] 主角想越阶必先通关前置硬条件（境界/悟道/资源），不是宝物一拿即巅峰；
- [ ] 代价、时限、反噬清晰写进《power 设置》，跨书不漏。
