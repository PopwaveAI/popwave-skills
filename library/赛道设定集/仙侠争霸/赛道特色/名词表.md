# 仙侠赛道 · 十二类风味词库

> 取词原则：形/色/意偏东方古韵，禁现代都市词、禁日式直译腔、禁西幻词。每个格子给常用落点，落地时按创意X微调；直用赛标杆书专名的须撞名自检。

## 一、命名体系（人名/地名/宗门）

| 类别 | 常用落点 |
|:--|:--|
| 人名 | 三字姓+名（叶凡/庞博/林佳式）、名+道号（陈北玄式）、名+仙名（夜孪真仙式） |
| 地名 | 二/三字+通名（泰山/昆仑/燕归湖/摩云顶/星空古路式）、方位+意象（东海/南疆/雾隐/离火） |
| 宗门 | 圣地/仙宗/古刹/门派字号（青天宗/苦海寺式）、+「岭/山/宫/府/观」 |
| 洞天福地 | 天宫/禁地/墟界/龙脉/神域（此处多可形成体系：三十六洞天七十二福地式） |
