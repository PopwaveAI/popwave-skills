# 仙侠赛道 · 命名规则

> 目的：起名要有东方古意、可读、不撞车、可记忆。所有新项目人名/地名/宗门/境界/法宝/古史名词生成后，必须过下方撞名自检。

## 一、人名生成规则

| 规则 | 说明 | 示例 |
|:--|:--|:--|
| 三字姓+名 | 主称谓（姓+单双字），朴实耐读、含一两个意象字 | 叶凡/庞博/林佳（风/云/山/水/木/华等意象字） |
| 道号/仙号 | 高人/大能/主角到高阶加号，取「名质概括或意象勾联」，常带「君/子/真人/仙尊/天尊」后缀 | 北玄仙尊/苍青真人/夜孪仙 |
| 女性名 | 弱柳扶风/花玉意象字，少用生僻 | 紫玉/嫣然/若兰/清影 |
| 反派名 | 阴寒/枭雄质感字 | 夜枭/寒渊/血煞/嫉天子 |

## 二、地名生成规则

| 规则 | 说明 | 示例 |
|:--|:--|:--|
| 二/三字+通名 | 意象字+地貌通名（山/峰/湖/关/域/墟/界/谷/洞/天/宫） | 摩云顶/燕归湖/离火谷/苦海 |
| 方位前置 | 东南西北+名（地域大方位好记） | 东荒/南疆/北海/西岭 |
| 洞天福地 | 意象+福地/洞天/秘境/禁地 | 玄天福地/万剑洞天 |
| 星路跨界 | 星/墟/域后缀作跨星域名 | 荧惑星/星路/冥墟 |

## 三、宗门名规则

| 规则 | 说明 | 示例 |
|:--|:--|:--|
| 特征+宗门通名 | 取一意象词+宗/门/教/寺/宫/阁/院 | 青天宗/苦海寺/万剑阁 |
| 地名+传承 | 大派常带地名或福地 | 蜀山/昆仑派 |
| 圣地级别 | 不带「宗门」仍成体系才显气派 | 天庭/灵山/紫霄宫 |
| 邪宗意象 | 阴/血/冥/煞字 | 血煞教/冥狱宗 |

## 四、境界名规则

| 规则 | 说明 | 示例 |
|:--|:--|:--|
| 二字/四字道义 | 组合体悟/登仙意象，成体系递增 | 炼气→先天→金丹→元婴→化神→返虚→合道→渡劫 |
| 质变点命名 | 大境界拐点给独立名（承载「换引擎」功能） | 一步入仙/雷劫/极致蜕变 |
| 巅峰命名 | 顶点名要有收束感 | 混元/大道境/道主 |

## 五、法宝/功法名规则

| 规则 | 说明 | 示例 |
|:--|:--|:--|
| 意象+器型 | 一字意象 + 剑/印/钟/灯/珠/杵/镜/图 | 青铜古灯/翻天印/量天尺 |
| 古史重器 | 前缀带「太古/荒古/天书/古」抬价值 | 太古青铜棺/天书古字 |
| 功法前缀 | 前缀带修途意象 | 九转炼体诀/虚空炼体诀/大衍天术 |
| 禁雷同 | 同书内法宝名忌「一剑一灯一转」机械堆 | 用「材质+名」拉开层级 |

## 六、古史/仪式/名词术语规则

| 规则 | 说明 | 示例 |
|:--|:--|:--|
| 古史段落 | 用纪年/叠词/排比营造久远感 | 「生而去、枯骨归、裹尸还」 |
| 仪式设施 | 名词+坛/祭/殿/洞 | 五色祭坛/封禅大典/古庙 |
| 时空通道 | 古星/古路/门户/通道 | 星空古路/荧惑 |

## 七、撞名自检协议（落地必过）

1. 新起的每个专名，先在**同赛道标杆书**（仙侠=遮天等）里检索，出现同字愈多越危险，重名必改；
2. 跨书同名、同频名暂时可接受（仙侠大词「云/天/山」本身高频），但两个核心人物/宗门/境界不可与既定标杆同名同类；
3. 专名在全书出现频率≥10次的（主角/女主/核心宗门/主境界），必须能一眼分出、二眼记住，禁拗口生僻字滥用；
4. 名字要能「一读出声」——避免三字以上连续仄声或连续平声的生涩组合；
5. 创建后回填到《名词表.md》相应类（补充合法落点），保持赛道词库自生长。

## 八、示例库（合法落点，供新项目直接采用/微调）

- 人名：叶尘/沈瑶/楚行舟/孟晚晴/陆九渊/苏浅眠
- 地名：观澜城/碧落天/暮云顶/万象墟/幽冥域
- 宗门：玄清宗/太虚剑门/百花故里/镇魔寺/焚天阁
- 境界：炼体→筑基→金丹→元婴→化神→合道→超脱境
- 法宝：青冥剑/镇狱印/南明离火/菩提古灯/九鳞钟
