# 单赛道极致深度采样方案

> 老板指示：需要系统、全面、深入的采样方案，把某个赛道的深度做到极致。
> 目标：产出一个「西幻dnd级」的赛道完整DNA包（5张参数表+机制层+内容层+风味层+素材层）。
> 现状反思：此前采样只拆各书前5章（开局期），已证实中段会出现新块类型（深渊中段新增4族）——本方案修正为「多书×全阶段」双维采样。

---

## 一、赛道极致 = 完整DNA包（对标西幻dnd）

```
赛道DNA包（西幻dnd级完整度）
├── 结构层    5张参数表（卷幕骨架/节奏/颗粒度/爽点配比/角色配置）
├── 机制层    力量体系/战斗系统/金手指/动力引擎
├── 内容层    世界观5件/角色库/剧情库（三池储备卡）
├── 风味层    类型风味基线/名词表/命名规则
└── 素材层    元素卡（块类型）/源书拆解/原文注入包
```

**"做到极致"的判定**：上述5层全齐 + 每层有≥3本书交叉验证 + 块类型收敛（不再出现新块）。

---

## 二、采样双维模型

### 维度1：横向（多本书）
| 书位 | 数量 | 选择标准 | 作用 |
|---|---|---|---|
| 标杆书（现象级） | 1本 | 该赛道最成功/最典型 | 主样本，DNA主源 |
| 腰部书（成熟） | 2本 | 该赛道稳定盈利的腰部 | 交叉验证，收敛检测 |
| 变体书（差异化） | 1本 | 同题材不同玩法的边缘 | 边界检测，防过拟合 |

**选书原则**：同赛道（题材×玩法）× 不同成功层级 × 不同作者风格。避免全选同一作者。

### 维度2：纵向（全叙事阶段）
| 阶段 | 章节位置 | 采样量 | 主导块类型（预期） |
|---|---|---|---|
| 开局期 | ch001-005 | 5章/本 | 金手指落地/立威/世界观/施压 |
| 推进期 | 中段（ch100±） | 5章/本 | 势力/升级/多线/旅途风土 |
| 高潮期 | 后期（ch200±） | 5章/本 | 大场面/多方博弈/决战/收束 |

**每本书采样15章（3阶段×5章），3-4本书共45-60章。**

---

## 三、采样管线（5 Phase）

### Phase 0：赛道定义与选书
1. 确定赛道（题材×玩法，如「灵异恐怖经营」）
2. 定义赛道边界：什么算（恐怖+经营+任务系统）/什么不算（纯恐怖无经营=灵异民俗怪谈）
3. 选书：标杆1+腰部2+变体1（按上表）
4. 产出：赛道定义卡（边界+选书清单+理由）

### Phase 1：全阶段拆解（纵向）
每本书按「块线拆解」范式拆3个阶段：
1. 开局期（ch001-005）→ 块+线
2. 推进期（中段5章）→ 块+线
3. 高潮期（后期5章）→ 块+线
产出：每本书3份拆解文件（或1份含3阶段）

### Phase 2：多书对比（横向）
1. **同阶段对比**：3本书的开局期块类型并排，找共性/差异
2. **跨阶段对比**：同本书开局vs推进vs高潮，找阶段差异
3. **收敛检测**：累计块类型是否收敛（新增块数趋近0=覆盖完整）
4. **结构指纹识别**：该赛道独有、其他赛道没有的块类型（如灵异的「恐怖事件五段式」）
产出：块类型收敛曲线 + 赛道结构指纹清单

### Phase 3：归族抽象
1. 全部块归族（跨书≥3实例→抽象卡，遵循「单实例不抽象」红线）
2. 赛道特有块→新族（如恐怖事件族）
3. 线类型归纳（该赛道的典型线：经营线/任务线/恐怖事件线…）
4. 更新通用元素卡库（新增卡/族）+ 赛道元素卡（赛道特有）
产出：通用卡库更新 + 赛道元素卡

### Phase 4：DNA提取（对标西幻dnd）
按西幻dnd使用手册的5张参数表格式，从拆解+原文提取：
| 表 | 内容 | 提取来源 |
|---|---|---|
| 表1 卷幕骨架 | 全书规模/四段式/质变点位/卷末收益 | 标杆书全本结构 |
| 表2 节奏参数 | 爽点密度/钩子率/章型枚举/战斗密度 | 全阶段拆解统计 |
| 表3 颗粒度 | 主养成线/升级代价/敌分级/数值锚 | 力量体系+面板 |
| 表4 爽点配比 | 各爽感公式占比 | 全阶段块统计 |
| 表5 角色配置 | 角色规模/反派梯度/金手指三约束 | 角色库+标杆卡 |

同时提取：力量体系/战斗系统/金手指/动力引擎 + 世界观5件 + 角色库（配置规格+标杆卡）+ 剧情库（动力引擎+各卷切片+三池储备卡）+ 赛道特色（风味基线/名词表/命名规则）
产出：赛道DNA包全部文件

### Phase 5：入库
1. 建赛道文件夹（对齐西幻dnd标准结构：readme/使用手册/立项/赛道特色/力量与战斗/世界观/角色库/剧情库/源书拆解/元素卡/原文注入包）
2. 归档：源书拆解（全阶段）/原文注入包/元素卡/参数表
3. 更新全量赛道分类表（该赛道状态→✅完整包）
4. 更新通用元素卡库索引（新族/新卡登记）
产出：西幻dnd级完整赛道包

## 四、深度指标（极致判定）

| 指标 | 标准 | 达标信号 |
|---|---|---|
| 块类型覆盖度 | ≥90%该赛道块类型已识别 | 收敛检测：新增块趋近0 |
| 跨书验证 | ≥3本书样本 | 块类型跨书收敛，无单书独有块 |
| 结构指纹 | 赛道独有结构已抽象成卡 | 恐怖事件五段式→恐怖事件族 |
| 味道基准 | 原文注入包≥5000字 | 覆盖3阶段代表性段落 |
| 参数表 | 5张全齐 | 表1-5对标西幻dnd格式 |
| 包完整度 | 对齐西幻dnd目录100% | 11个子目录全有内容 |

## 六、采样工作量估算

| 环节 | 工作量 | 说明 |
|---|---|---|
| 选书+赛道定义 | 0.5轮 | 1次确认 |
| 全阶段拆解（3-4本×3阶段×5章） | 9-12次子agent拆解 | 每本3次，可并行 |
| 多书对比+收敛检测 | 1-2轮 | 主agent汇总 |
| 归族抽象 | 1-2轮 | 主agent+确认 |
| DNA提取（5表+机制+内容+风味） | 3-4轮 | 对标西幻dnd |
| 入库+更新索引 | 1轮 | 收尾 |

**总计约6-8轮对话**可产出一个西幻dnd级完整赛道包。
