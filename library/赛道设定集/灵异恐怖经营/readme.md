**惊声一响，惊吓到账——灵异恐怖经营流的爽感密码，全部拆成了能直接抄的参数。**

写这条赛道最容易死在三个地方：恐怖只有"吓"没有经营闭环、恐怖事件爽点前置、恐惧没有数值化升级。这个包把答案全部数值化——

- **角色库双件**：26人配置规格+实证级标杆卡+势力储备库
- **剧情库三池**：早期/中期/后期全幕级——恐怖事件族+营销引爆族，白描+逐幕锚点卡，改改就能当幕纲用
