# 规则总账 · 泛灵异赛道（赛道百科·规则篇）

> 赛道级参考答案——机制与结构源自赛道标杆源书全书拆解，专有名已槽位化、章锚点已剥离。新书 world 展开对应维度时**抄机制、抄结构、抄颗粒度，不抄事件与专有名**；名词层以《赛道特色/名词表.md》为唯一真源。
> 七类规则是各维度公共输入的规则总账，每条回溯五设计原则（定义见《总纲.md》第五节）：**原则1** 大事件供给猎物 · **原则2** 地图随经营等级解锁 · **原则3** 惊吓值/等级量化 · **原则4** 任务奖励与收鬼双限 · **原则5** 名声=流量合法性。
> **空间类型判定**：**双轨空间**（现实都市与异度/灵界叠加）——先按现实侧处理经营日常，再定灵异侧各层规则；双轨全景见《总纲.md》第一节，本件只收规则细则。

## 一 · 规则总账表（七类规则）

| 规则类型 | 规则内容 | 回溯原则 |
|:--|:--|:--|
| **现实经营** | 恐怖屋=现实盈利单元：门票几十元一张、按日计游客；星级由「游客人数×好评率」评级（2星解锁游客100人/好评率60%起）；扩建费逐星翻倍（满星十万元级）；场景尖叫指数（0.5星-5星）是卖点也是评级参考；每月乐园评级/收租审查 | 原则3/5 |
| **现实经营** | 恐怖消费本质：一次性消费为主（流动新游客），长期口碑靠「大有名气」的固定恐怖屋；「故事-场景-情绪」三要素（没故事的鬼屋无灵魂）；重温失效（同样的场景看过就不吓人）→强制不断翻新/新增场景 | 原则2 |
| **超凡法则** | 灵异侧量化：尖叫指数/恐怖星级衡量灵体强度与恐怖程度（怨灵~厉鬼0.5-2星、红衣鬼4星、鬼王5星）；「恐怖」本身可被计量（游客惊吓值、灵体怨力） | 原则3 |
| **超凡法则** | 灵体特性：怨灵困于怨念、厉鬼主动作恶、红衣鬼有领地与法则、鬼王经营领地；灵体可由任务器引导进入异度/灵界空间；越级擅闯异度空间有灵异反噬（未达星级强行深入会受伤） | 原则4 |
| **收鬼规则** | 收服/封印鬼怪为员工的前提=**解除怨念**（否则失控反噬）；获取方式是做任务、解谜、兑现（恐怖事件五段式中的「兑现」）；鬼怪员工供恐怖屋当「演员」/帮手，提升惊吓值与战力 | 原则4 |
| **任务规则** | 任务器每日重启任务抽屉：每日任务（简单/一般/噩梦三难度，午夜刷新，每日领1个）+周常/主线；任务难度越高奖励越高、风险越大（【警告！个别任务极度危险，请慎重选择！】）；等级制动=恐怖屋星级限制可接任务上限（越级有反噬）；任务完成→奖励（强化道具/惊吓值/解锁场景） | 原则2/3/4 |
| **升级规则** | 主养成=恐怖屋星级1-13星+鬼怪使役席（1-12席）；星级靠游客/好评/扩建跃迁，升级仪式=每月评级+挂牌；任务奖励是容器（等级制动限流速），收鬼是生产力（最多12席）——双限防无限膨胀 | 原则3/4 |
| **升级规则** | 惊吓值：游客产生的惊吓能量=恐怖大转盘筹码（抽寿命灵果/厉鬼/道具）——抽到厉鬼要当场收服，是「变强看运气+潜能」机制 | 原则3 |
| **危机规则** | **经营扩张×灵异入侵（时代引擎）**：恐怖屋越扩张、灵潮越上涨、灵异事件越浮出——升级与灾祸同源；备选引擎「灵潮上涨」（灵异事件随地图揭开逐渐加剧） | 原则1 |
| **危机规则** | **灵异反噬**：星级/任务等级不够越级擅闯高阶异度=被鬼反噬（受伤/游客出事/员工契约崩溃）；高阶鬼怪收服不当会失控反噬团队 | 原则4 |
| **原生威胁规则** | 异度空间（废弃医院/古宅/灵车/镜屋）随地图解锁投放，内藏怨灵/厉鬼/红衣鬼/鬼王；灵潮上涨期异度扩张、都市暗角怨灵活跃 | 原则1/2 |
| **原生威胁规则** | 灵界（灵体大本营）：鬼王格局、灵潮源头——卷5起开放，灵界主宰是幕后大反派 | 原则1 |
| **博弈规则** | **灵异不可任人收**：不是所有鬼都可当员工；只有「可收服型」（怨念可解）鬼怪能入队，「诅咒型」鬼怪收服有代价/反噬 | 原则4 |
| **博弈规则** | **营销双平台**：论坛完整版（理性讨论引流长尾）+短视频高能版（情绪引爆促短时转化）；评论区骂声=流量（「一点都不恐怖的恐怖屋」反讽+威胁感争议=二次热度） | 原则5 |
| **博弈规则** | **名声=流量合法性**：藏（低调防调查/防对手/防灵异注意） vs 显（营销变形/客流/名声）做成可计算取舍；名声越大越招灵异注意（也越容易触发主线/被幕后盯上） | 原则5 |
| **博弈规则** | **父母遗物币**：父母失踪留下的布偶/任务器等遗物既开线又藏真相（父母之谜本身即主线/大反派棋局） | 原则1 |
