# 灵异恐怖经营·任务型子配方卡（我的诡异人生）

> **定位**：同一赛道「物屋经营」主骨之外的**任务型子配方**。物屋型爽点=游客/营销变现闭环；任务型爽点=**死亡结算+情报迭代+元玉/天赋养成**。本书中后期漂移至玄学权谋/仙道证道，采样价值主要在开局「任务型」内核与漂移轨迹。
> **用法**：组装任务型章纲时，以本卡选择块；与物屋型主骨衔接处按下表「换轨点」处理，**不可两种引擎同章混用**。
> **跨书验证**：死亡轮回结算/怪物规则推演为任务型独有，冒险屋（物屋型）无，故本卡不抽象入通用卡库，保留赛道独有。

## 一、换轨点速查（任务型 vs 物屋型）

| 维度 | 物屋经营型（冒险屋） | 任务型（我的诡异人生） |
|---|---|---|
| 经营载体 | 游客/金钱/营销变现 | 元玉经济+天赋养成（数值线） |
| 爽点引擎 | 恐怖兑现→营收增长→扩张 | 死换情报→备战→元玉/天赋成长 |
| 开局核心块 | 营销引爆块 | 死亡轮回结算块 |
| 推进核心块 | 鬼团收编/商业博弈 | 组织调度/誓约执法/玄学政治 |
| 高潮核心块 | 战役动员/决战揭示 | 宇宙证道/诸我归一/返凡 |
| 恐怖兑现形态 | 完整五段式（游客视角） | 影中瞬杀单点高密（主角亲历） |

## 二、任务型独有指纹块

### 卡T1 死亡轮回结算块【死-分-析】
- 适用：任何一次模拟死亡后，把「死亡损失」转译为「可量化收益」的结算块。
- 节拍序列：
  1. 判定 — 死因复盘（评分/失败原因归档）
  2. 结算 — 元玉/经验带出（数值弹幕，死亡≠纯损失）
  3. 推演 — 下次备战锚点（明确改什么）
  4. 触发 — 新轮回载入预告（钩子）
- 写法要点：死亡必须「赔一赚情报」，不能让读者觉得白死；结算数值要具体。
- 线效果：成长线+元玉数值线双重前进；悬念线-轮回链加深。
- 源书：我的诡异人生 ch002 首死结算块/ch005 丙上结算块。

### 卡T2 怪物规则推演块【析-推-备】
- 适用：靠跨轮回情报差，debug 一个怪物的行为规则。
- 节拍序列：
  1. 采集 — 本轮气味/痕迹/弱点观测
  2. 对比 — 跨轮回前后差异（如气味强弱变化）
  3. 推演 — 反推怪物规则（探知其规律）
  4. 应对 — 针对性备战装备/策略
- 写法要点：推演用「线索链」而非作者旁白，读者跟得上；规则要能复用打脸/规避。
- 线效果：探索线+情报积累；怪物线-弱点揭示。
- 源书：我的诡异人生 ch003 破影调研/ ch005 变数撞杀。

### 卡T3 誓约咒术执法块【诵-咒-震】
- 适用：主角凭权柄/誓言，隔空处决不听话的驭诡者（强权工具）。
- 节拍序列：
  1. 立誓 — 对手掌供起誓（契约建立）
  2. 违誓 — 某方背约（触发条件显形）
  3. 应誓 — 咒术发动隔空爆亡（权柄兑现）
  4. 威慑 — 旁观者震怖（威名/惧名世界侧写）
- 写法要点：誓言要「有代价的严肃」而非随意；应誓瞬间要爽点爆发，给旁观者反应。
- 线效果：势力线-权威确立；对方集团线-人心离散。
- 源书：我的诡异人生 ch752-754 誓约显威/应誓爆发/远程诛杀。

### 卡T4 玄学政治·组织调度块【析-断-调】
- 适用：主角以掌舵人/调查局身份，调度多股势力（警务/驭诡者/法寺）多边博弈。
- 节拍序列：
  1. 汇总 — 多方势力情报汇聚
  2. 决策 — 权衡处置方向
  3. 调配 — 分流任务/许以利益
  4. 折服 — 反水者被诚服/震慑
- 写法要点：调度要显「操盘手」掌控感而非跑腿；多边博弈要出现一个「意外变量」破局。
- 线效果：势力线-高位强化；阴谋线-浮出。
- 源书：我的诡异人生 ch750 决策调度/折服。

### 卡T5 宇宙证道终局块【踏-燃-揭】
- 适用：全书末期孤身证道，收束伏笔的道德升华终局（漂移向）。
- 节拍序列：
  1. 逼至源 — 终极对手/真相汇聚
  2. 舍饵 — 弃「本我」守「人道」（理念抉择）
  3. 揭开 — 道基/真相彻底公开
  4. 返凡 — 跌回现代日常，轮回式收束（首尾呼应）
- 写法要点：「真仙=饵」式理念反转要前置伏笔；结尾返凡一根线勾回开头画面。
- 线效果：全部主线闭环；主题线-理念裁定。
- 源书：我的诡异人生 ch1540-1544。

## 三、与物屋型主骨的拼接协议

1. **开局选型**：任务型开局第一块必为「死亡轮回结算」而非「营销引爆」——两者互斥，不可都做。
2. **推进期升级**：物屋走「鬼团收编+商业博弈」，任务型走「组织调度+誓约执法」——代换经营载体为元玉经济后，结构骨架可复用。
3. **高潮漂移警示**：任务型极易漂向玄学权谋/证道主线（本书已验证），若按「灵异恐怖经营」写，需在推进期把「恐怖兑现」锚住，避免丢了经营魂。
4. **恐怖兑现降级**：任务型恐怖兑现是「影中瞬杀」单点高密，非完整五段式——如需五段式节奏，从物屋主骨取恐怖事件五段式卡注入。
