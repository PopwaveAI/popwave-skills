# 灵异恐怖经营·民俗物屋子配方卡（开局打造恐怖屋）

> **定位**：物屋经营主骨的**民俗市井向变体**。无系统任务核心，靠「创业者亲测鬼屋 + 相继撞真鬼」双轨推进，走「经营危机+真实灵异 + 市井喜剧」。本书是「恐怖屋经营+民俗鬼怪+市井喜剧」路数，民间怪谈（黄大仙/奈何桥）比重高。
> **用法**：写「民间撞鬼+经营」向章纲时用本卡；怪物不是系统任务刷的，而是**请来了真鬼**，恐怖兑现靠「亲历」，不是「游客视角直播」。

---

## 一、与主骨物屋型（冒险屋）的差异

| 维度 | 系统任务物屋（冒险屋） | 民俗物屋（开局打造恐怖屋） |
|---|---|---|
| 恐来源 | 系统任务刷级 | 请神召鬼/老庙真邪 |
| 主角身份 | 任务执行者（陈歌） | 创业者亲测（张本千/三叔） |
| 恐怖兑现 | 完整五段式（游客直播） | 亲验撞鬼/民俗致幻（亲历） |
| 支线驱动 | 金手指系统 | 市井关系+民间怪谈求签 |
| 喜感 | 弱 | 强（市井喜剧+丑角配角） |
| 结构指纹 | 任务闭环+营销引爆 | 创业立项+民俗避险+谈判供奉 |

## 二、民俗物屋独有指纹块

### 卡F1 创业签地块【议-签-立】
- 适用：开局把「买块地开鬼屋」做成兴奋的创业立项（用荒庙/废地做恐怖生意）。
- 节拍序列：
  1. 看场 — 主角带眼线目击荒废古庙（杂草半人高/菩萨断臂/白蚁蛀梁）
  2. 压价 — 与场地持有者（村长/地主）议价签约（现金/按手印）
  3. 唱反调 — 对方或同伴说「这庙闹鬼/出事概不负责」晦气话
  4. 立誓 — 主角宣称「必须闹鬼，鬼越多越好」反话立创业志向
  5. 落成 — 改建落成+公司成立（合伙人入股）
- 写法要点：「晦气必须是卖点」的反差要一步点破；签约的现金数量要具体（市井实感）；合伙人要有丑角味。
- 线效果：经营线-创业落地；撞鬼悬念线-「出事概不负责」预埋。
- 源书：开局打造恐怖屋 ch001 签地块/落成块。

### 卡F2 民俗避险块【避-查-现】
- 适用：主角撞上民间怪谈（黄大仙/奈何桥/打赌迷晕），需避险保命。
- 节拍序列：
  1. 现异 — 民间灾祸征兆显形（土地震裂/那人迷晕/失眉）
  2. 询俗 — 长者/知情者解说民俗典故（黄大仙传说/奈何桥）【科普灌注拍】
  3. 避险 — 按民俗规矩/活人手段回避
  4. 存疑 — 留一个「到底信不信」的成长钩子
- 写法要点：民俗说法要「像真的民间八卦」而非设定书；避险手段要有市井操作性（靠活人办法不是靠金手指）。
- 线效果：灵异线-民俗纵深；主角画像线-半信半疑的凡人心态。
- 源书：开局打造恐怖屋 ch51 黄大仙传说/ ch53 莫名奈何桥/ ch50 打赌迷晕。

### 卡F3 谈判供奉块【议-诚-待】
- 适用：与请来的真鬼/邪物**谈条件、上贡和解**（关系缓和而非硬收编）。
- 节拍序列：
  1. 对峙 — 鬼物显形/发作
  2. 递话 — 主角与对方谈条件（见招拆招）
  3. 上贡 — 准备贡品/物（供奉仪式）
  4. 和解 — 达成默契，暂安（留后续牵绊）
- 写法要点：谈判要「鬼也讲理」的怪诞喜感；贡品要是市井随手物（香烛/糕点）接地气；和解留尾巴——别真清净。
- 线效果：鬼物线-从敌到半友；经营线-鬼屋员工雏形（民俗向先供奉后收编）。
- 源书：开局打造恐怖屋 ch52 谈判块/贡品块。

## 三、与主骨拼接协议

1. **开局**：走「创业签地→造屋→宣传试业」升格（10块/4线），**不用**系统任务开局——恐怖兑现从试业撞真鬼开始，非任务刷级。
2. **民俗替代五段式**：恐怖兑现走「民俗避险」而非「恐怖事件五段式」——主骨的五段式卡可从物屋主骨卡取来，在民俗组块时替换恐怖来源为「请神召鬼」。
3. **喜感注入**：本变体需市井喜剧+丑角配角（睡神小胖型），这是与物屋主骨最大气质差，不可省。
4. **尾部筹备**：中后期筹备重开张（改名/子布局），复用物屋主骨的经营日常块，但恐怖核仍是民俗怪谈。
