# 幕3示范 · 据点建设（卷三-卷四 ch0201-0300）

> RHL-002 幕件之一（弧概览/六幕功能位序列/密度基准/使用红线见《建势弧总卡.md》）。

## 套路决策
- **演绎框架**：主线（颤栗迷宫改造+藏灵司承）= 经营史诗；据点守御任务支线并织
- **内容引擎**：主 恐怖屋扩建为颤栗迷宫（三次扩建质变A）；辅 据点守御（鬼队）+灵潮小潮盯防
- **高潮**：位置幕内+尾段｜类型 颤栗迷宫改造落成+首场据点守御（战群来犯异象）｜蓄力 改造/破财/人力2-3章｜余波 据点化身「灵异侧前线驻地」
- **幕末钩子**：颤栗迷宫+5星初现，鬼王格局边缘的脚步声由远及近 → 指向幕4

## 幕定位
- **本幕作用**：把「收养厉鬼经营」的成果固化成「建据点」——恐怖屋从门面升级为灵异侧前线驻地，肝书店。

## 核心体验
- 从「一间恐怖屋」到「一座颤栗迷宫」的建造爽——扩建数值逐格点亮。
- **情感弧线**：破财的肉疼 → 落成的成就感 → 守御的默契。
- **幕末质变**：「一间恐怖屋」→「颤栗迷宫·灵异侧前线驻地」。

## 剧情白描（示范叙事）
江渡攒够了扩建条件，把恐怖屋逐步改造成「颤栗迷宫」——三次扩建（游客过百+好评率+扩建资金）逐格完成，互锁的通道、会"活"的布景、镇在墙里的镇压符阵，2星变5星。扩建高峰他倾尽所积、差点崩盘（破财三连），徐婉和鬼队替他顶了一段。改造落成当夜，有一批异象（游荡红衣/零散厉鬼）循着迷宫「高吓人」的声誉聚来，想趁夜闯境——江渡指挥鬼队守御，颤栗迷宫初显「前线驻地」模样，惊险守住（首场据点守御）。落成后面板大爆： 颤栗迷宫 落成 星级5 编制水涨。他站在迷宫入口，望着逐渐热闹起来——也可说是「危险起来」的城区，隐约听见更深处传来一声不属于人的低语。江渡握紧黑手机："这块地，怕是要当战场用了。"
