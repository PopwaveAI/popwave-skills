# 幕3示范 · 任务首爆（ch0031-0055）

> RHL-001 幕件之一（弧概览/五幕功能位序列/密度基准/使用红线见《卷一五幕总卡.md》）。

## 套路决策
- **演绎框架**：主线（星级首次任务链）+营销引爆支线并织；恐怖事件五段式全段亮相
- **内容引擎**：主 恐怖事件（规则倾倒+异象+高潮+兑现+复盘）+绝命灵车开局；辅 论坛/短视频营销首爆
- **高潮**：位置幕内中段+尾段｜类型 第一次星级任务惊险通关（恐怖五段式全爆）+第一次营销引流量｜蓄力 任务难度/营销酝酿若干章｜余波 游客排起队、面板大爆
- **幕末钩子**：月评级倒计时+扩建条件（游客过百/好评率过六成）逼近 → 指向幕4

## 幕定位
- **本幕作用**：让「恐怖事件五段式」完整亮相一次、营销引爆滚起来——经营和恐怖双向破圈的第一高峰。
- **核心体验**：恐怖爆点+流量兑现的双重爽——从「能接单」到「有人冲看」。
- **情感弧线**：任务疲惫 → 通关后怕而释然 → 流量带来的虚惊与踏实。
- **幕末质变**：「识破者」→「恐怖事件全段通关者+有流量的经营者」。

## 剧情白描（示范叙事）
江渡硬着头皮开了绝命灵车（两星，一小时内离不开灵车被永远扣留）。这一场他把恐怖事件五段式用了个透：先撞进灵车的「规则倾倒」——车上有阴冷的气味、异度空间里的乘客不知死活；异象随之而来，冷雾在车舱里盘旋、座下把手逐渐结霜；高潮是倒计时与车身外的拍打，他把有限的符水/镇定符拼着用；兑现——镜裂般的一瞬，他识破这是被循环困住的「旧把戏」叠加真灵异，反手撬开一个「规则漏洞」通关；复盘——回看录像才看清灵车上那些「乘客」的倒影不对劲。这一战他靠任务器奖励+识破智斗险胜，收获骨牌恶力的惊吓值+一只「车票」（异度空间的钥匙）。他把整个通关过程（隐去真名）剪成短视频挂到论坛，标题反讽：「一点都不恐怖的恐怖屋·绝命灵车」。评论区先是理性分析，接着被路人「吓尿破骂」——骂声也是流量，吧友把「西郊恐怖屋」地址顶上了首页。几日里游客从两位数涨到三四十，甚至有人专程赶来被吓。江渡偷偷勾了当月游客/好评率——离「游客过百+好评六成」的扩建线越来越近，可浓月的黑手机又刷新出一条主线任务的苗头：和某座「有人目击哭泣新娘」的现场有关。他捏着车票想："这扩建，怕是等不及了。"
