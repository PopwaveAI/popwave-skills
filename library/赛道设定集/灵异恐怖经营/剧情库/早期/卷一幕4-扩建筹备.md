# 幕4示范 · 扩建筹备（ch0056-0080）

> RHL-001 幕件之一（弧概览/五幕功能位序列/密度基准/使用红线见《卷一五幕总卡.md》）。

## 套路决策
- **演绎框架**：主线（扩建冲线+后台经营）+月评级动员支线并织；解谜搜证（深）首次作为主战场
- **内容引擎**：主 扩建筹备+星级任务链（解谜搜证）；辅 员工扩编/财力周转
- **高潮**：位置幕内尾段｜类型 一次「解谜搜证（深）」任务惊险收束（逼月评级大考的势头）｜蓄力 筹备/缩减若干章｜余波 扩建线临门一脚
- **幕末钩子**：首个「游客过百+好评六成」距线还差最后一点 + 月评级大考前夜 → 指向幕5

## 幕定位
- **本幕作用**：把扩建条件（游客/好评/三次扩建）的第一次临门一脚下注——把读者拖进「就快成了」的心弦。
- **核心体验**：事倍功半的筹备+「解谜搜证」的烧脑——暧昧的蓄力感。
- **情感弧线**：冲线的兴奋 → 筹备耗财耗力的疲 → 离大门一步的急切。
- **幕末质变**：「有流量的经营者」→「离扩建线一步，心弦已吊」。

## 剧情白描（示范叙事）
江渡盘算扩建：当月游客刚过九十，好评率约五成，差一口气。可钱和人手都不够——乐园租金还在压着，徐婉劝他先稳一场高星怪。他接了新一批解谜搜证（深）任务：三四处「怪事点」要查因，地点从旧楼到夜市，线索靠他「懂行」的眼睛扒（留痕/谈吐/被吓者的口供拼图）。有一处「夜市收摊后的哭声」最深，他蹲了三夜，终于锁定是某户夜市摊主因家变装的「活鬼」——人祸而非灵异（识破圈套高级版）。他人傻钱不够，只能精打细算拆旧布景扩建两处，把「颤栗迷宫」的雏形拼出半边。月底任务器刷新，主线把「哭泣新娘」的线索续了一条——对着月色，黑手机幽幽提示：「想不想知道他们最后去了哪座医院？」江渡盯着那句血字，一阵发毛——这口吻，太像他老爹了。
