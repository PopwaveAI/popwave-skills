# 剧情库 · 索引（检索协议）

> **定位**：通用包不含任何单书剧情（主线/卷纲/章白描由新书 plot 在项目空间产出）。剧情层参考走本库：plot Step1 产卷纲时、Step2 产幕白描时，按幕功能位+叙事阶段取卡作**幕白描底稿**。
> **判定口诀**：卡片给「槽位化的参考答案」——白描+锚点卡的结构与节奏可直接继承，专名与事件血肉必须替换重推。
> **库结构**：`早期/中期/后期/` 三池（按**主角叙事阶段**放置，无并列目录——卷一结构基准RHL-001已入早期池）。池内两级卡片体系：**总卡**（弧概览+幕功能位序列+量级跳档+使用红线，产卷纲读）+**幕件**（幕级全套字段：套路决策/幕定位/剧情白描/六要素/敌人-成长耦合/POV规划/逐区间锚点卡/prose-render交接，产幕白描按幕选读）——**全库卡片粒度统一为幕级**。卡是素材库不是排期表——不按先后顺序，同池内可任取重组；泛灵异恐怖生态作品（规则怪谈/恐怖经营/诡秘流等）剧情解耦后按阶段入库维护。
> **源锚**：本赛道剧情库以《我有一座冒险屋》（经营期产出）为源书样本锚，中后期为机制层自造示范（对齐「恐怖事件五段式/任务系统驱动经营/营销引爆」赛道指纹）。世界观锚走《世界观/总纲.md》，力量/战斗锚走《力量体系/》。

## 卡片元数据schema

每张卡头部必带：

```
card_id: 弧级三位编号（幕件=弧级编号-M{n}） | 阶段: 早期/中期/后期 | 源类型: 国内源书/灵异生态/节奏基准+示范
arc_type: 开局弧/建势力弧/换引擎弧/终局弧/支线弧/一幕完整剧情（幕件=弧类型·幕n功能位）
level_range: 适配经营等级区间（对齐力量体系位阶）
map: 适配地图类型（现实都市/异度空间/灵界/恐怖屋）
tension: 核心张力类型
status: 幕纲级（储备卡：白描+锚点卡可改造为幕纲；OS=灵异生态解耦/CN=源书深度匿名化转写/RHL=示范级接口）
```

**阶段划分标准**（按主角叙事位置，不按卷号）：早期=凡人经营轨（濒临倒闭→站稳脚跟，经营等级N1-N2）｜中期=降灵战术轨（收服厉鬼→红衣鬼→鬼王，N5-N7）｜后期=灵界掌控轨（灵潮爆发→秩序重铸，N8-N10）。

## 检索协议

1. **产卷纲**（plot Step1）：按卷功能位（开局/建势/蓄力/爆发…）→ 定位三池某一条弧 → 读该弧**总卡**（功能位序列+量级跳档），套进卷框架。
2. **产幕白描**（plot Step2）：按当前幕功能位 → 读对应**幕件**（全字段），改造三步落笔。
3. **改造三步**（强制）：①改专名（主角/恐怖屋名/鬼怪名/城市）→②换分支（同一幕功能位删原事件，换各X张力重推）→③遮卡测试：遮住示范白描，你的幕白描必须能从X+新世界+新角色推出——原样能推=抄的，回炉。

## 使用红线

1. **取结构弃血肉**：幕功能位序列/章配比/敌人-成长耦合/POV规划法/节奏参数照搬；示范专名与全部事件细节必须替换；
2. **遮卡测试**（改造三步第③）：每张卡落笔前必过——遮住示范白描，你的白描要能自分推出（织于X张力+灵异源世界）；原样能推=抄的；
3. **阶段对齐**：早期卡不得混用降灵/灵界机制（经营等级N1-N4禁高星收服）；后期卡不返经营日结模式（节奏已由灵潮/灵界主导）；
4. **越卷防透支**：任何卡所用面板/星级/地图功能位止于本卷区间，plot 越界即透支全书爽点——具体见《各卷切片.md》卷末边界。
5. 引用留痕：`RHL-001·借鉴维度=功能位+节奏参数+耦合结构`。
