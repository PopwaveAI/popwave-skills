## 一、鬼怪鉴定面板

首次遭遇新鬼怪类型时弹出。面板以意识流数据流嵌入叙述。同类鬼怪后续不再重复弹（变种/红衣/精英/觉醒视为新类型）。

### 1.1 简版（经营期）

适用于N1–N4（经营期），面板简洁，5行以内。

**格式**：
```
"[名称]【[类别]】（[恐怖星级]）。"
"怨气评级X，威胁[个人/事件]星级X，[灵体类型]。"
"最高能力X点，最低能力X点，怨气范围X－X。"
"特殊能力：[能力1]、[能力2]……"
"威胁判断：[字母]+/-。"
```

**示例**：

> "路灯残念【游魂】（一星）。"
> "怨气评级2，个人星级1，执念灵体。"
> "最高能力感知2点，最低能力灵力0点，怨气1－3。"
> "特殊能力：示警、飘动。"
> "威胁判断：D-。"

### 1.2 完整版（降灵期+）

适用于N5以上（降灵期+），面板含怨气/灵力专属资源、能力、弱点、收服倾向等完整信息。

**格式**：
```
怨气：XXX/XXX。
灵力：0/XXX。（或专属资源条）
能力：示警、飘动、低语……
弱点：怕火烛、怕诵经、怕契约。
情绪/性格：[性格描述一句话]
收服倾向：可谈/可渡/需以战收服。
```

**示例**：

> "红衣·长街新娘【红衣厉鬼】（五星）。"
> 怨气：150/150。
> 灵力：80/80。
> 能力：红衣夺目、长街巡游、执手索命……
> 弱点：怕晨光、怕旧宅封印、克守约定。
> 情绪/性格：偏执、记仇、但守诺。
> 收服倾向：需以战收服后谈契约。

### 1.3 简版与完整版对比

| 维度 | 简版（经营期） | 完整版（降灵期+） |
|:--|:--|:--|
| 行数 | 5行 | 7-10行 |
| 怨气值 | 无（用星级代替） | 有（XXX/XXX格式） |
| 专属资源条 | 无 | 有（怨气/灵力等） |
| 能力 | 无 | 有（含数值） |
| 弱点/性格 | 用"特殊能力"概括 | 逐项列举（含性格/收服倾向） |
| 适用经营段 | N1-4 | N5+ |

### 1.4 鬼怪鉴定写法要点

- 类别用方括号【】：【游魂】【怨灵】【厉鬼】【凶魂】【红衣】【鬼王】【灵潮】
- 星级用圆括号（）：（一星）……（五星）……经营期敌人通常为一至三星
- 怨气评级为阿拉伯数字，威胁判断为字母+/-：D- < D < D+ < C- < C < C+ < B- < B < B+ < A- < A < A+
- 怨气范围格式"X－X"表示最低到最高能力
- 完整版专属资源条随鬼怪变化：红衣用"灵力"、鬼王用"统辖怨气"等
- 鬼怪鉴定面板弹出后，后续同类鬼怪不再重复弹（红衣/变种/精英除外）

## 二、灵体感知反推

不直接看鬼怪面板时，通过主角对怨气/阴气的身体感受反推鬼怪星级与威胁。这是经营期最常用的"灵体感知"写法——主角（顺感/灵异体质）通过战斗中的感知，将身体反应转化为数值判断。

### 2.1 心血来潮/阴气反推

| 体感描写 | 反推星级 | 说明 |
|:---------|:---------|:------|
| "后背一阵发凉" | 一星 | 轻微阴气，残念级 |
| "寒毛炸起/房间骤冷" | 二星 | 怨灵级阴气明显 |
| "冷汗直冒/心跳骤停半拍" | 三星 | 厉鬼级，压迫感鲜明 |
| "一股窒息感/视线发白" | 四星 | 凶魂级，接触即危险 |
| "皮肤刺疼/呼吸凝固" | 五星以上 | 红衣/鬼王级，不可正面硬抗 |

**示例**：

> 推开旧宅大门的一瞬，主角的后背毫无征兆地炸起一层鸡皮疙瘩。房间里的空气骤然阴冷下来，像是一头巨物正从门缝后窥着他。

> 至少四星。主角在心中迅速判断。凶魂级，不可正面硬抗，得先撤出去做功课。

### 2.2 界线/环境反推

| 体感描写 | 反推星级 | 说明 |
|:---------|:---------|:------|
| "门关不上/烛火乱跳" | 一两星 | 低星灵体扰动物理的征兆 |
| "卫生间再次潮湿/镜面泛雾" | 三星 | 厉鬼级开始改环境 |
| "所有门窗同时咬死/空气凝固" | 四星+ | 凶魂/鬼王封锁空间 |

### 2.3 灵体感知反推写法要点

- 反推后必须紧跟战术决策（撤退布置/搜证引灵/撑秒），不能只判断不行动
- 反推是主角的"顺感/专业直觉"，不需要面板弹出——是主角的经验判断，可以有误差
- 灵体感知反推用于"来不及弹鬼怪鉴定面板"的遭遇场景
- 同一场恐怖事件中，灵体感知反推最多使用2次，第3次起应弹正式面板或用旁白概括

## 三、恐怖星级×怨气分离

降灵期（N5+）开始，鬼怪不再是一个总数，而是分维度结算。星级（恐怖/威胁层）与怨气（战力层）是两个不同维度。

### 3.1 基本格式

星级与怨气分开弹出，各自体现威胁与战力。

**示例**：

> "红衣·长街新娘——星级5／怨气150。"
> "星级判断的是威胁与收服难度，怨气判断的是作战强度。"

### 3.2 含抗性/免疫信息

当鬼怪对某种反制有免疫或减免时，面板必须反映：

**示例**：

> "物理符箓对这个怨气极高的厉鬼几乎是无效的！……只有懂它的执念，才能谈渡化。"

**写法要点**：
- 抗性/免疫信息用感叹号+省略号引出，语气带惊讶感
- 减免表述用"几乎无效""勉强"等模糊表述，不用精确到小数
- 减免后的实际效果必须低于理论值，差额即抗性
- 星级×怨气分离是降灵期核心面板特征，经营期不用（经营期是一个总数）

## 四、星级标尺锚定

面板弹出星级数值时，必须在同章内用参照物锚定。

### 4.1 锚定规则

- 星级数值弹出后，同章内必须出现至少1个参照物锚定
- 参照物可以是：普通游客承受力、恐怖屋现有场景星级、普通经营者的能力、体感描述
- 同一参照物跨章间隔 ≥ 3章（避免重复使用同一锚点）

### 4.2 锚定方式

| 锚定方式 | 示例 |
|:---------|:------|
| 直接锚定 | "五星——这意味着现有的道具和团队撑不住，必须先撤。" |
| 比较锚定 | "四星凶魂，已经比恐怖屋最高星场景·第三病栋还高一级。" |
| 体感锚定 | "皮肤刚刺疼一下就知道，这鬼至少四星。" |
| 参照物锚定 | "这是一星场景·午夜逃杀都挡不住的凶魂，得用红衣来克。" |

### 4.3 参照物梯子（完整版）

| 星级 | 定性 | 恐怖参照 | 战力参照 | 收服参照 |
|:--|:--|:--|:--|:--|
| 1 | 残念 | 普通游客轻微不适 | 戏耍级，可符纸镇 | 可谈可渡 |
| 2 | 怨灵 | 游客发冷汗 | 纠缠级，需道具 | 可渡可谈 |
| 3 | 厉鬼 | 游客吓哭/逃离 | 撑秒能破 | 需以战收服 |
| 4 | 凶魂 | 游客心理阴影 | 团队+道具才可敌 | 难，多需围 |
| 5 | 红衣/鬼将 | 职业经营者也犯怵 | 需红衣同级/灵界手段 | 需以战收服+契约 |
| 6-7 | 鬼王 | 都市传说级恐慌 | 需鬼王级/灵潮压制 | 需灵界力量 |
| 8 | 鬼皇 | 区域灵潮级 | 需灵域级 | 灵界掌控后 |
| 9-10 | 灵界主宰 | 全域灵异灾变 | 灵潮+整个灵域 | 纵贯掌控 |

## 五、遭遇评估（挑战评估）

用"要什么样的恐怖屋/队伍才能扛住"的视角反推事件或自身实力。星级不是单纯数值对比，而是"需要什么体量才能应对"的实战评估。

### 5.1 评估格式

**示例**：

> 如果按旧城灵异产业的老话讲，这道门里的东西，恐怖星级该有五级往上。
> 换句话说，得是能镇住红衣的灵异老铺，还得搭上一整个肯卖命的班子，才有一半的可能活着出来。

### 5.2 评估写法要点

- 遭遇评估用"灵异产业老话/老手评估"作为信息来源——主角（懂行）的视角，用产业经验评估恐怖事件
- 评估结果用"体量配置+胜率"的格式表述："能镇红衣的灵异老铺+肯卖命的班子"+"一半的可能"
- 遭遇评估用于关键节点：恐怖屋实力质变时、遭遇超规格鬼王时、幕末/卷末实力盘点时
- 评估可以用于自身（"我这恐怖屋现在能扛几星"）也可以用于敌人（"这个厉鬼几星"）

## 七、红线

1. **鬼怪鉴定红线**：首次遭遇新鬼怪类型必弹鬼怪鉴定面板。同类鬼怪后续不重复弹（红衣/变种/精英除外）。漏弹=不合格。
2. **星级锚定红线**：面板弹出星级数值时，必须在同章内用参照物锚定。同一参照物跨章间隔 ≥ 3章。纯数字无锚定=不合格。
3. **星级×怨气分离红线**：星级与怨气分离只在降灵期+使用。经营期为一个总数，不分维度。降灵期+不分维度=不合格。
4. **灵体感知反推红线**：灵体感知反推后必须紧跟战术决策，不能只判断不行动。同一场恐怖事件中灵体感知反推最多2次。
5. **面板格式匹配红线**：简版鬼怪鉴定面板仅用于经营期，完整版用于降灵期+。格式错位=不合格。
6. **遭遇评估红线**：遭遇评估仅在关键节点使用（实力质变/遭遇超规格鬼王/幕末卷末盘点），不滥用。
