> 战斗表现按需加载文件 | 恐怖经营·任务器面板流 | write层按需加载

## 文件定位

本文件覆盖恐怖经营流中所有特殊条件战斗技法。特殊条件战**不替代常规恐怖模式**，而是在常规模式上叠加环境/条件约束——当恐怖事件发生在黑暗中、镜中、废弃建筑中、追逐中、需要频繁切换反制道具或涉及困局时，常规节奏、描写侧重和面板格式都需要相应调整。

write层加载本文件后，根据施工卡标注的特殊条件类型从下方6种类型中选取对应技法渲染，叠加到当前经营段的常规模式之上。

**核心原则**：特殊条件必须影响恐怖节奏和描写方式，不能只是换个背景板。

## 一、特殊条件恐怖战斗类型总览

| 编号 | 类型名 | 核心约束 | 描写侧重变化 |
|:--|:--|:--|:--|
| 1 | 熄灯黑暗战 | 视觉信息剥夺 | 听觉/触觉替代视觉，拟声词密度增加，恐怖极致 |
| 2 | 镜中世界战 | 颠倒/扭曲现实空间 | 镜像描写，恶劣幻觉，空间错位 |
| 3 | 废弃建筑战 | 结构化探索+翻新恐怖 | 环境腐败递进，走廊楼栋层次，机关/困局 |
| 4 | 走廊追逐战 | 移动中遭遇，空间收窄 | 快慢交替节奏，死角压迫 |
| 5 | 多反制道具切换 | 道具频繁切换应对鬼怪类型 | 每种道具不同拟声/效果，切换触发 |
| 6 | 困局/陷阱战 | 环境作为恐怖核心要素 | 拆/触发/利用困局的恐怖反馈 |

## 二、特殊条件恐怖战斗类型详解

### 类型1：熄灯黑暗战

**适用场景**：失去照明的黑暗恐怖——熄灯的恐怖屋、被断电的废弃楼、浓雾遮蔽视线、灵异空间黑暗吞光。

**核心约束**：视觉信息完全或部分剥夺，主角必须依赖其他感官与专业预判。

**感官替代体系**：

| 被剥夺的视觉信息 | 替代感官 | 判断方式 |
|:--|:--|:--|
| 鬼怪位置 | 听觉 | 脚步声/低语/刮擦声方位 |
| 鬼怪距离 | 听觉 | 声音大小/回声延迟 |
| 鬼怪强弱 | 触觉+顺感 | 阴气波动/发麻/心悸 |
| 威胁方向 | 触觉+听觉 | 气流变化/风声方位 |
| 恐怖环境 | 触觉 | 墙皮/地板/锁/湿冷程度 |

**描写节奏变化**：
- **拟声词密度增加**：因视觉缺失，听觉成为主要感知渠道，拟声词（嘎吱/低语/抓挠/沙沙）出现频率比常规高50%以上
- **黑暗中只剩呼吸声与环境异响**——用听觉构建恐怖全貌
- 星级/阴气判断从灵体感知反推：通过阴气波动判断强弱，通过低语方位判断位置

**原作锚点**：

> 熄灯下的镜前游戏——环境异响都用听觉、触觉呈现，人物靠呼吸声与倒数撑秒，恐怖全由感官与心理压力顶起。

**渲染要点**：
1. 拟声词独立成段或紧跟动作，密度高于常规
2. 星级/阴气判断用灵体感知反推句式："胸腔里那点阴气猛地一跳——这鬼至少三颗星。"
3. 黑暗中的恐惧感通过呼吸声、心跳声等生理声音呈现
4. 面板仍正常弹出（面板是意识流，不依赖视觉），但可补充感官判断："通过阴气波动判断——目标不下三颗星。"
5. 如主角有顺感/灵异体质，面板需呈现该能力激活："顺感激活。感知范围：整层楼。"

**节奏模板**：
```
[拟声词] → [触觉/听觉判断] → [面板补充确认] → [行动决策/撑秒] → [拟声词] → ……
```

### 类型2：镜中世界战

**适用场景**：镜子作为灵界入口的恐怖——镜前游戏、镜中倒影异变、被拖入镜面世界。

**核心约束**：主角面对的是一个"颠倒/扭曲现实"的空间，镜像成为恐怖主体，世界观可被改写。

**镜像恐怖体系**：

| 镜像现象 | 恐怖表现 | 写法侧重 |
|:--|:--|:--|
| 镜像迟缓 | 镜中人动作慢半拍/先动 | 制造"另有其人"的诡异 |
| 镜像异变 | 镜中倒影不同（表情/动作/数量） | 展现世界线分歧 |
| 镜裂门开 | 镜面裂痕→另一侧空间 | 进入异度的入口 |
| 镜中撞镜 | 镜中人向镜面冲撞 | 兑现段的恐怖峰值 |

**讲讲节奏模板**：
```
[照镜入局] → [镜中异象：迟缓/异变] → [识破"镜中坑"·专业判断] → [高潮：镜中撞镜/撑秒] → [兑现：镜裂+异度空间揭示] → [复盘：回看录像推真相]
```

**渲染要点**：
1. 镜内外的描写必须区分（"镜中的自己更灵动"）——制造"另一个意识"的惊悚
2. 镜面视角是"单向门"——能看不能触，直至兑现段打破
3. 面板在兑现段弹出（镜裂+奖励/异度揭示），复盘段给线索推断
4. 镜中世界可承载"世界的另一面"世界观钩子（镜中是灵界的入口之一）

### 类型3：废弃建筑战

**适用场景**：废弃医院/旧宅/矿洞等结构化探索恐怖——本赛道的"翻新地图加层"传统。

**核心约束**：结构化空间（房间/走廊/楼层/地下）+环境腐败递进，恐怖一层层揭开。

**腐朽递进链**：

```
走进大门（霉味/灰尘） → 一层走廊（抓痕/积水/滴答） → 楼梯转角（温度骤降/阴气） → 深处房间（异象/低语） → 最深处（鬼怪兑现）
```

- 环境腐败是递进的，不是一次性铺满
- 每层配对应恐怖感：霉味→抓痕→温度骤降→异象→鬼怪
- 腐朽递进度反映恐怖不断逼近

**结构化探索**：
- 废弃建筑自带"房间/楼层/深度"结构，恐怖按结构逐步揭开
- 每进一个空间，恐怖上一个台阶；深处是兑现/复盘位
- 死布言论：搜证（取证）穿插在整个探索中，既是恐怖推进也是线索埋设

**渲染要点**：
1. 环境描写用五感（嗅觉/触觉尤其强）——霉味、湿冷、皮屑感
2. 每个房间/转角是一个恐怖台阶，不得跳步（不能从大门直达最深处）
3. 鬼怪通常在"最深处"与主角兑现，是恐怖高峰
4. 探索中穿插取证/复盘，把恐怖推进与线索积攒焊在一起

---

### 类型4：走廊追逐战

**适用场景**：在恐怖屋/废弃建筑中被追或追逐——关节追逐、席卷压迫。

**核心约束**：双方在狭窄移动中，空间收窄压迫，恐怖由"被逼近"驱动。

**追逐节奏：快慢交替**

追逐节奏不是匀速的，而是快慢交替——潜伏时慢（听声辨位），被逼近时快，折返死角时慢。

**被追方视角四阶段**：

| 阶段 | 节奏 | 描写侧重 |
|:--|:--|:--|
| 察觉 | 快 | 察觉追来者的脚步/低语，启动逃离 |
| 逃窜 | 快 | 穿过走廊/钻过门洞，利用地形 |
| 死路 | 慢 | 死胡同/门锁死/退无可退 |
| 反转/被吞 | 极快 | 硬碰/识破圈套逃脱 |

**追来者的逼近恐怖**：
- 脚步由远及近、低语越来越大声——用声音推进恐惧
- 每拐一个弯，脚步声与恐惧同步逼近
- 环境影响：走廊尽头一扇锁死的门=最绝望的恐怖瞬间

**渲染要点**：
1. 追逐节奏必须快慢交替，不得从头到尾同一节奏
2. 追逐空间的收窄必须具体（走廊/门/窗/死角），不用模糊描写
3. 恐怖由"被逼近"驱动——脚步声/低语由远及近是核心
4. 面板在反转/兑现段弹出（识破圈套逃脱/奖励结算）

### 类型5：多反制道具切换

**适用场景**：应对不同牌面鬼怪/鬼能力，战斗中频繁切换反制道具（灵符/盐/火烛/诵经/契约/封印）。

**核心约束**：每种道具针对不同鬼怪类型，切换道具即切换应对节奏。

**道具切换矩阵**：

| 道具 | 适用场景 | 拟声词/效果 | 写法侧重 | 切换原因 |
|:--|:--|:--|:--|:--|
| 灵符 | 驱散残念/封阵 | 呼/嗤 | 镇压、速封 | 残念/怨灵靠近 |
| 盐/火烛 | 阻隔阴气/照明破黑 | 簌/滋 | 划界、燃亮 | 黑暗笼罩/阴气逼近 |
| 诵经/圣水名 | 渡化/拖延 | 嗡/静 | 安宁、对峙 | 需谈判/拖延时间 |
| 契约/封印 | 收服/镇压高星 | 嗡/哐 | 契约、封印 | 以战收服/困鬼王 |

**切换原因触发**：
- **鬼怪类型变化**：残念→厉鬼，需从灵符切诵经
- **各自消耗**：灵符贴完/火烛燃尽，需切换
- **战术需要**：需要拖延时切诵经，需要镇压时切封印

**切换的节奏作用**：
- 每次切换道具，应对节奏明显变化
- 灵符的速封 → 火烛的缓慢怖局 → 诵经的.Suspenie对峙 → 契约的收服爆发

**渲染要点**：
1. 每种道具的拟声/恐惧感必须区分
2. 写法侧重随道具切换变化——灵符写速，火烛写怖局，诵经写对峙，契约写收服
3. 道具切换必须有明确触发原因（鬼怪类型/消耗/战术），不得无理由切
4. 面板在道具生效/收服时弹出（镇魂成功/契约达成）

### 类型6：困局/陷阱战

**适用场景**：灵异制造的环境困局/陷阱——被锁死的房间、欺骗性的回廊、循环的走廊、扣下的机关。

**核心约束**：环境是恐怖的执行者，主角拆解/触发/利用困局。

**困局交互三模式**：

#### 模式A：识破困局
- 面板弹出物种反馈："识破困局！灵感+X。"
- 拆解过程用专业判断描写："重复的回廊——这是鬼在造循环，不是真有这么多房间。"

#### 模式B：触发困局
- 恐怖反馈+负面状态同时弹出："陷阱触发：回廊循环。……状态异常：迷失，持续X段，探知失效。"

#### 模式C：利用困局
- 将鬼怪引入困局（把鬼骗进封印阵/让它踩中机关的布置）
- 利用困局需要铺垫：主角知道困局机制→制造引诱路径→鬼中招

**困局类型与面板对应**：

| 困局类型 | 触发方式 | 恐怖效果 | 附加效果 |
|:--|:--|:--|:--|
| 循环回廊 | 走错路 | 迷失 | 探知失效 |
| 锁死门窗 | 触发落差 | 困死 | 出口封锁 |
| 欺骗性回声 | 环境 | 误判 | 位置判断错乱 |
| 封印阵 | 布置 | 镇压/收服 | 高星鬼可困 |

**渲染要点**：
1. 识破困局必须有专业判断过程（观察→推理→识破），不能直接"破了"
2. 触发困局的恐怖反馈必须附带负面状态
3. 利用困局需要提前铺垫困局存在（主角发现/布置的段落），不能突然冒出
4. 困局面板格式与常规区分——困局带"困局触发："前缀

## 三、特殊条件叠加规则

特殊条件可以叠加——一场恐怖事件可能同时满足多个特殊条件。

**常见叠加组合**：

| 叠加组合 | 场景示例 | 叠加效果 |
|:---------|:---------|:---------|
| 熄灯黑暗+走廊追逐 | 断电的废弃医院走廊 | 视觉+听觉双重剥夺压力，触觉为唯一可靠感官 |
| 镜中世界+困局 | 镜内循环回廊 | 颠倒+迷失叠加，恐怖最大化 |
| 废弃建筑+多道具 | 逐层探索频繁换反制 | 每层换道具应对不同鬼怪 |
| 黑暗+困局 | 熄灯后被锁死 | 困死+迷失双重绝境 |

**叠加渲染要点**：
1. 叠加时以主要特殊条件为主框架，次要作为修饰叠加
2. 不得两个特殊条件互相矛盾各写一半——必须确定主次
3. 叠加组合在施工卡中需明确标注主次关系

## 四、与常规战斗模式的关系

特殊条件战**不替代**常规恐怖模式，而是在常规模式上叠加环境/条件约束。

```
常规战斗模式（经营段文件） + 特殊条件约束（本文件） = 特殊条件恐怖战斗
```

**叠加方式**：
1. 先确定当前经营段的常规恐怖模式（经营期/降灵期/灵界期）
2. 再叠加施工卡标注的特殊条件类型
3. 常规恐怖模式提供恐怖结构（五段式）和面板格式
4. 特殊条件类型提供环境约束和恐怖描写调整

**示例**：
- 降灵期收服战（常规） + 熄灯黑暗（特殊条件） = 黑暗中收服厉鬼，拟声词密度增加，星级判断从灵体感知反推
- 经营期撑秒任务（常规） + 镜中世界（特殊条件） = 镜前游戏，镜像异象+识破+兑现的完整链条

## 五、红线

1. **不替代红线**：特殊条件战不替代常规恐怖模式，是在常规模式上叠加环境/条件约束。施工卡未标注特殊条件时不加载本文件。
2. **影响节奏红线**：特殊条件必须影响恐怖节奏和描写方式——不能只是换个背景板。如果特殊条件对恐怖描写没有任何影响，则不该标注为特殊条件战。
3. **感官替代红线**：熄灯黑暗战中不得出现视觉描写（"他看到……"），必须用听觉/触觉替代。例外：主角拥有顺感/灵异体质时，面板需呈现激活后方可使用灵体感知描写。
4. **追逐节奏红线**：走廊追逐必须快慢交替，不得从头到尾同一节奏。追与被追的语感必须有区分。
5. **熄灯渲染红线**：熄灯黑暗战必须呈现黑暗剥夺（异常断电/被吞光），不得忽略光源问题。
6. **道具切换理由红线**：多反制道具切换必须有明确触发原因，不得无理由切换。每种道具的拟声/效果必须区分。
7. **困局铺垫红线**：利用困局必须提前铺垫困局存在，不能突然冒出。识破困局必须有专业判断过程。
