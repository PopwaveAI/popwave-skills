# 战斗表现 · 通用层

> 赛道级参考答案——机制与结构源自赛道标杆源书全书拆解，专有名已槽位化、章锚点已剥离。新书 write 渲染战斗章时**抄机制、抄结构、抄颗粒度，不抄事件与专有名**；名词层以《赛道特色/名词表.md》为唯一真源。

> **消费顺序**：本文件（每战必读——定经营段+三段流+五段式+笔法+红线）→ 按经营段加载《{经营段}/战斗模式-{经营段}》（模式/面板/数值锚全集）→ 经营期主角另加读《经营期/任务执行配方卡》（照单施工版）→ 按需叠加：《特殊条件战》（镜中/废弃医院/走廊追逐/黑暗/多道具反制）、《恐怖事件五段式》（五段式意识流与特殊事件写法全集）、《灵体探知数据》（鬼怪鉴定面板/体感反推/星级评估）、《多线叙事》（POV切换/世界级灵潮事件）、《场景卡》（场景公式速查）。世界级规则读 `../战斗系统.md`；阶位定义读 `../力量体系.md`。
> **经营系边界（消费前必读）**：战斗模式件从标杆书主角（**恐怖屋经营者→降灵师→灵界行者**）蒸馏——覆盖恐怖屋任务执行、鬼怪使役、灵界掌控本体线。跨经营复用=本文件全部+各模式件的面板格式框架/句式节奏/拟声词/数值规模。**驱流派/僵尸流/纯猎杀流主角：当前无专属配方卡（扩展位）**——禁止经营系模式换皮套用（收服鬼怪/经营变现对纯猎杀主角不成立），须按本文件三段流骨架另行推导。
> **三段流总纲**：一场恐怖事件/战斗的写法=**战前（填图纸）→战中（用笔法）→战后（收结算）**。通用层给跨经营段三段流；经营段模式件给对应段的专属模式/面板/句式/数值。

## 〇 经营等级定位（先定段，再动笔）

经营段不按经营等级数字划分，按**力量体系三质变点**锚定（扩建为颤栗迷宫=凡人→降灵，探入灵界=降灵→灵界掌控）。写战斗章第一步：对照下表锁定所在段。

| 经营段 | 阶位锚（对齐力量体系·经营等级参考） | 战斗规模 | 面板复杂度 | 画风一句话 | 与下一段分界线 |
|:--|:--|:--|:--|:--|:--|
| **经营期** | N1–N4，**扩建迷宫前** | 恐怖屋日常任务/低星鬼怪遭遇；镜中游戏/闹鬼小区 | 5–8字段，纯数值结算 | 冷硬写实的恐怖经营流——数值小、任务器直给、识破圈套定生死 | 未扩建为迷宫：无迷宫级体量，无收服高星鬼怪能力 |
| **降灵期** | N5–N7，**迷宫→收服鬼王** | 收服鬼怪团队/使役对凶魂；逐屋解谜 | 10+字段：天赋技能+鬼怪星级【】+收服数据链 | 收服与使役的诡谲感——星级分离，多POV | 未收服高星鬼王：无鬼王战力使用资格，无灵界门票 |
| **灵界期** | N8–N10，**探入灵界核心后** | 灵域vs灵域/灵潮级战争 | 三资源条（灵力/惊吓值/鬼怪编制）+叙事化描述 | 灵域尺度的灵潮对撞史诗——不写搏斗写灵潮崩坏 | —（灵界主宰=顶点） |

**三阶差异速记**（防串段，其余维度差异按落点查）：恐怖描写经营段模糊单一→降灵段星级分离+收服数据链→灵界段灵力结算+灵潮变化｜事件收获经营段仅经验/道具→降灵段+灵力/鬼怪/契约→灵界段灵域四连暴涨｜叙事视角经营段全主角→降灵段每3章≥1次非主角POV→灵界段必须有非主角POV｜环境互动经营段室内局部→降灵段区域破坏→灵界段地图级｜风险机制经营段反噬致命→降灵段+收服反噬→灵界段灵潮/鬼王格局（3.2节）。

## 一 战前（动笔前：填图纸，不填不动笔）

> 六要素是笔法，规划是图纸。没有图纸的笔法=写得好看的空壳——读者看战斗看的是"谁在算计谁、谁先撑不住、什么时候识破、打完得到了什么"。

### 1.1 战前五问

| # | 问 | 填法 |
|:--|:--|:--|
| 1 | 恐怖事件功能 | 一句话——"这场灵异事件后，____变了"（经营扩张/任务奖励/暴露身份/关系改变/信息揭示/制造危机/灵界推进） |
| 2 | 双方目标 | 主角想____（不只破案：取证/收服/拖延/保护/逼问/逃跑），灵异在想____（不只杀人：索命/附身/困局/吞噬/核算）——目标错位=张力来源 |
| 3 | 胜负条件 | ____发生=主角赢，____发生=主角输（倒计时归零/反制失败/被诅咒缠上/对方脱身）。禁"谁强谁赢" |
| 4 | 信息差布局 | 读者知道____但____不知道，第____拍揭示，制造____效果（揪心/爽感/意外/恐惧） |
| 5 | 恐怖后置 | 哪里才是爽点？——恐怖本身不负责爽，**兑现/复盘段**才是爽点所在（识破反杀/线索落地/奖励兑现），必须预先设计 |

### 1.2 战中五编排（动笔前一并填好，战中照图施工）

| # | 编排 | 填法 |
|:--|:--|:--|
| 6 | 氛围→异象推进 | 第1拍环境如何过招（温度/声音/景物异变），第2拍主角专业性如何插笔（识破圈套），高潮第4拍倒计时 |
| 7 | 恐怖递进 | 第1拍松散→第2拍阴森→高潮压迫→兑现崩塌（环境→听觉→触觉→幻觉→失控，选3–5级） |
| 8 | 转折点 | 第____拍，____触发（识破圈套/反制/收服/敌方失误/倒计时到达），局势从____变为____ |
| 9 | 读者情绪曲线 | 第1拍无语→第2拍紧绷→第3拍毛骨悚然→兑现释然/爽→复盘悬疑（全程一个情绪=疲劳或无聊） |
| 10 | 后置爽点设计 | 兑现段给什么（识破反杀/奖励落袋）、复盘段给什么（线索/悬念加深/世界观揭示） |

### 1.3 恐怖事件类型速查

| 类型 | 核心维度 | 规划要点 |
|:--|:--|:--|
| 倒计时撑秒 | 高潮拍 | 谁先到点；转折=倒计时结束/识破"圈套" |
| 越级反噬局 | 胜负条件 | 越级擅闯的变数（不可知变量/诅咒缠上）；反噬在后置拍结算 |
| 收服局 | 兑现拍 | 核心是谈判/渡化/以战收服的三段式；兑现=契约达成 |
| 解谜局 | 复盘拍 | 核心是搜证推理——复盘=线索落地+悬念加深 |
| 智斗局 | 信息差 | 专业识破圈套；转折=关键信息揭示、攻守转换 |
| 生存/守御 | 胜负条件 | 核心是撑住而非赢；转折=救援到达/限期结束/灵潮退潮 |

**5拍节奏全程通用**（具体化见恐怖事件五段式与分阶战斗形态表）：氛围→异象→高潮→兑现→复盘。**真实恐怖必须走完整5拍**，爽点后置——禁"开场即识破即结束"（恐怖是过程不是背景）。

### 1.4 标杆局拆解示例（开场镜中游戏·倒计时撑秒局范本）

- **五问填法**：功能=任务奖励兑现+经营转机；双方目标=主角撑过倒计时收奖励 vs 镜中之物想"拖主角进来"；胜负=倒计时归零且不睁眼主角赢，被拖入镜中/睁眼主角输；信息差=读者知"门外之物是圈套"为主角的专业判断；恐怖后置=恐怖在撑秒，爽在兑现（镜裂+布偶+奖励）+复盘（录像推真相）
- **5拍**：氛围（半夜个体卫生间+专业分析镜中游戏原理+录像留言）→异象（温度降低+门外呼唤+识破圈套）→高潮（门板抓挠啃咬+半小时倒计时撑秒）→兑现（镜裂+父母布偶回归+任务奖励落袋）→复盘（回看录像：身体前倾+镜中撞镜+玩偶救主推断）
- **要点**：恐怖"后置"——爽点不在撑秒本身，在兑现与复盘；主角时时用"开鬼屋的懂行"视角识破手段最低级的"圈套"，恐怖+智斗双引擎并跑。

## 二 战中（落笔时：笔法底线）

### 2.1 战斗六要素（每场恐怖事件到底线）

| 要素 | 差 | 好 | 本赛道（恐怖经营流）适配 |
|:--|:--|:--|:--|
| **动作** | 事件级——一个词概括（"扑来""关上"） | 姿态级——拆到"手怎么动/门怎么被挠"（撑秒拆到呼吸/门板/烛火） | 先动作（门板被指甲抓出一道深痕）→再事件（——门板在挠！）→后效果（倒计时还剩十秒） |
| **恐怖命名** | 报幕式——鬼名是主体，动作被省略 | 嵌入式——异象是主体，恐怖是标签 | 恐怖用破折号："——门外有人在唤我的名字！"；鬼怪/技能用【】内联任务器数据流 |
| **画面表达** | 色彩标签——只有"阴森"没有轨迹动态 | 画面精确——色彩+形状+轨迹+动态≥2个维度 | 感官带类型质感：温度（骤降/发凉）、听觉（嘎吱/抓挠/低语）、触觉（湿冷/发麻/汗） |
| **内心波动** | 标签式——"心头一凛" | 专业判断式——具体分析/推理/识破 | 本赛道招牌：**识破圈套三连**——"这声音从门外来，游戏规则是别睁眼。哪个真鬼会蠢到叫门？又是吓人的旧把戏。" |
| **路人/旁白捧场** | 无人理会，只有主角与鬼 | 旁白/论坛/游客反应放大恐怖或爽感 | 每场≥1次：游客后怕/论坛评论区"吓尿了"/员工竖拇指；恐怖+营销双变现 |
| **环境把握** | 打完环境完好 | 破坏匹配星级，形变有具体形状 | 按段匹配（见〇节环境互动行）：经营期室内局部→降灵期区域破坏→灵界期地图级 |

### 2.2 任务器面板总则（跨经营段跨等级）

1. **意识流内联**：面板以意识流数据流嵌入叙述，任务器界面以【】内联；禁弹窗/光屏/全息投影，禁markdown代码块。
2. **弹出时机**：任务奖励结算/收服成功/升级/首遇鉴定/惊吓值入账五类节点弹，纯恐怖推进不弹（详情见3.1）；每次任务奖励必弹。
3. **复杂度对段**：经营期5–8字段直给；降灵期10+字段+鬼怪星级【三星】式量化；灵界期三资源条同屏+叙事性描述。
4. **数值对段**：数值规模匹配段（区间锚见各模式件）——经营期惊吓收益≤200、任务奖励单一。
5. **参照物锚定**：星级/惊吓值数值弹出必须同章内锚定（直接/比较/体感三式），同一参照物跨章间隔≥3章。

### 2.3 拟声词基础表（跨经营段通用）

| 拟声词 | 用途 | 独占行 |
|:--|:--|:--|
| 嘎吱 | 门扉/门轴/楼梯晃动（吊诡前兆） | 否 |
| 抓挠/吭嚓 | 门板被指甲抓挠/啃咬（高潮撑秒） | 是 |
| 沙沙 | 下水道/墙角/耳侧低响 | 否 |
| 滴答 | 漏水/钟摆/血滴（节拍感） | 否 |
| 呜咽/低语 | 门外/镜中传来的人声 | 是 |
| 轰隆 | 墙壁/灵潮/大门被撞 | 否 |
| 哔/叮 | 任务器面板提示音（奖励/解锁） | 否 |

规则：独占行不加标点；同一段恐怖事件同一拟声词≤2次，第3次起用恐怖描写替代。各经营段专属拟声词见对应模式件。

### 2.4 句式节奏型（5种公式，跨经营段框架）

| 节奏型 | 公式 | 节奏感 |
|:--|:--|:--|
| 撑秒型 | 极短句（3–5字）×2–3 → 倒计时 → 拟声词独占行 → 解释性推理×1–2 | 快-停-快 |
| 识破圈套型 | 拟声词独占行 → 动作句（15–25字）→ 专业判断/推理旁白×1–2 → 反击短句 | 稳-稳-快 |
| 收服爆发型 | 压力铺垫（中长句×2–4）→"——契约！！"极短句 → 魂体内部（中句×1–2）→ 动作链（短句×3–4）→ 恐怖凝聚 → 任务器面板 | 慢-爆-快-收 |
| 复盘推断型 | 拟声词 → 极简概括1句 → 星级/线索判断1句 → 一笔带过结果1句 | 快-快-止 |
| 协作型（鬼怪使役） | 主角指挥1句 → 鬼怪行动2句 → 循环（以鬼怪星级称区分）；+旁观游客反应1句 | 交替-交替 |

## 三 战后（收尾时：结算+余波）

### 3.1 任务器面板类型速查（何时弹什么）

| 场景 | 面板类型 | 弹出规则 |
|:--|:--|:--|
| 任务完成 | 任务奖励面板（奖励+惊吓值+解锁） | 必弹；格式见对应经营段模式件 |
| 反制失败 | 失败面板（debuff："破局失败！目标进入诅咒状态"） | 失败是张力来源，不要每发必中 |
| 经营/天赋升级 | 升级面板（星级公式+新场景+新天赋） | 升级当场弹 |
| 首遇新鬼怪 | 鬼怪鉴定（【类别】+（星级）+怨气/能力/弱点） | 首遇必弹；同类不重复，红衣/变种/精英除外 |
| 收服/高强度战后 | 战后总结面板（鬼怪团队变化明细） | 收服/大战后弹，杂兵遭遇不弹 |

### 3.2 伤势/反噬处理规则（按段分级）

- **经营期**：越级反噬或受创=即致隐患——具体后果必写（被困/诅咒/睡眠透支/道具损毁），禁中途自愈；医疗资源稀缺，战后写消耗；撑秒消耗战主角带1处可见损耗到战斗结束。
- **降灵期**：可用灵力/道具/鬼怪团队恢复，但必须消耗对应资源——恢复=资源换血，禁无代价愈合；收服反噬是本段独有悬念。
- **灵界期**：灵力/鬼怪编制即血条——战后结算灵力余量+惊吓值产出恢复；灵潮中鬼怪编制战损（残念/怨灵/厉鬼/凶魂/红衣/鬼王）——越级碾压的代价在收尾拍结算。

### 3.3 战后余波三件套（打完≠结束）

1. **善后动作**：取证复盘一笔带过（解谜流）/奖励兑现清点（任务流）/传闻与游客口碑扩散（经营流）。
2. **代价清偿**：反噬延续到下一章、惊吓值/道具缺口记录、暴露的连锁反应（游客怀疑/灵界势力盯上/评级波动）。
3. **钩子埋设**：奖励中的异常项（"奖励里的灵物有未知气息"式悬念）、新线索、下一场事件的引信——收尾拍同时是下一拍的开场。

**写后自检**：动作姿态级？恐怖名嵌入动作链？感官≥2维度？内心是专业判断？旁白/游客≥1次反应？环境破坏对段？任务奖励弹面板？反噬没中途自愈？余波三件套齐？

## 四 红线

1. **经营段红线**：三段战斗模式与面板格式不得混用——经营期禁多段收服面板/灵域面板；灵界期必含灵潮级对抗（只写对轰不写灵潮规则=不合格）。
2. **模式去重红线**：连续3章禁用同一种战斗模式（含子类型），第4章必须切换。
3. **任务奖励面板红线**：每次任务完成必弹奖励面板。例外：协作伏击、纯旁观取证。
4. **面板意识流红线**：意识流内联【】，禁弹窗/光屏/全息投影，禁markdown代码块。
5. **数值规模红线**：数值匹配经营段——经营期惊吓收益≤200；灵界期三资源条同屏。
6. **参照物锚定红线**：星级/数值弹出同章内锚定；同一参照物跨章间隔≥3章。
7. **反噬持续性红线**：越级反噬/受创持续到战后，禁中途自愈。
8. **POV红线**：降灵期每3章≥1次非主角视角；灵界期全程只有主角POV=不合格。
9. **拟声词红线**：独占行不加标点；抓挠（门板）/低语（门外）不可混用；同段同词≤2次。
10. **特殊条件红线**：特殊条件必须影响节奏和描写方式；镜中禁视觉描写（改触觉/听觉）；利用道具必须提前铺垫。
11. **经营系红线**：经营系模式件只适用于恐怖屋经营者/降灵师/灵界行者主角；驱流派/僵尸流/纯猎杀流禁换皮套用，按通用层三段流骨架另行推导。
