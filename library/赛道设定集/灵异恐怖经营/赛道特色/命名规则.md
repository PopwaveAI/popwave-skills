# 命名规则 · 灵异赛道

> 用法：所有专有名（人名/鬼名/场景名/恐怖屋名）按本规则生成；示例库可直接取用。

## 1 总原则

1. **现代生活感**：人名/地名/场景名是现实都市可遇到的名字（读起来像当下中国人名/城市/店面），无武侠古风、无日式直译；
2. **禁武侠古风**：无「X子慕/令狐X/掌门/少侠」式；
3. **禁日式怪谈直译**：无「X之仪式/X宅级咒/彼岸谷」式堆砌；
4. **撞名检查**：新名诞生必过检查表（见§7）。

## 2 音节构件表（构词原料）

| 类别 | 常用构件 |
|:--|:--|
| 男名首音/字 | 小- (小陈/小郭) / 阿- (阿宇) / 张/李/王/陈/周（常用姓） |
| 男名尾字 | -宇/-航/-杰/-磊/-峰/-斌/-军 |
| 女名首音/字 | 小- (小婉/小晴) / 阿- / 徐/林/苏/李/赵（常用姓） |
| 女名尾字 | -婉/-晴/-娜/-玲/-雪/-月 |
| 恐怖屋名词缀 | 惊魂/鬼屋/惊悚/灵堂/墓园/迷宫 + 一夜/欢/屋/历险 |

## 3 人名三层

- **主角/员工**：姓+名（如：X晨 / X婉式——现代普通中国人名，槽位化，禁写具体人）；
- **昵称**：小X / 老X（家人/同事/吧友间称呼）；
- **代号/外号**：认不出真名时用「形态+特征」（如：红衣·无名氏 / 无脸人 / 惹眼的外号「鬼屋老板」）。

## 4 鬼名（代号式）

- 主格式：**形态/特征+称呼**——无脸人 / 哭泣新娘 / 白衣女 / 镜子里的女人；
- 星级正名：怨灵 / 厉鬼 / 红衣鬼 / 鬼王（按恐怖星级）；
- 禁止：起与知名恐怖IP鬼怪同名或近音（贞子/裂口女/伽椰子等官方名号）。

## 5 场景命名法（设施/任务命名）

- **主格式：场景+危险行为/悬念**——午夜逃杀 / 第三病栋 / 绝命灵车 / 镜中有你 / 连环失踪案；
- 恐怖屋场景=「恐怖场景名+尖叫指数」捆绑标定；
- 任务=「悬念+线索」式（噩梦任务/镜中有你/连环失踪案）。

## 6 恐怖屋与机构命名

- 恐怖屋：恐怖屋/鬼屋/惊悚屋 + 关键词（西郊/惊魂/惊魂一夜——「位置/氛围+品类」）；
- 论坛板块名：怪谈求助区 / 实拍分享区 / 鬼屋探店区（现代平台板块式）；
- 机构：评级机构 / 民间灵异调查会 / 乐园管理方（现代机构通名）。

## 7 撞名检查表（新名必过）

1. 念三遍，有没有武侠古风/日式怪谈直译腔？
2. 是否与《地狱公寓》《盗墓笔记》《午夜凶铃》《请在护栏缝隙翻阅》等知名恐怖IP角色/地点撞名或近音？
3. 是否与本赛道知识库内其他书的人物名重复（防串味）？
4. 鬼名是否带代号式？场景名是否带悬念？恐怖屋名是否带品类？（三挂齐=格式合格）
