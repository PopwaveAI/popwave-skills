# 类型风味基线 · 灵异恐怖经营活动

> 一句话世界观：**现代都市×异度空间双轨的灵异恐怖世界**——城市里经营着一座吓人不吓人的恐怖屋，白天卖门票、夜里接灵异任务；现实侧（社区/论坛/短视频/商战/游客）与灵异侧（怨灵/厉鬼/红衣鬼/鬼王/异度空间）双轨并行，时代引擎是「经营扩张×灵异入侵」。

## 类型声明

```
【类型声明】当前作品类型：灵异×恐怖屋经营×任务系统（任务流恐怖经营）。
写作全程保持灵异味：恐怖要「后置」（爽点在恐怖事件后的兑现/复盘，不在恐怖本身），
主角用专业视角（开鬼屋的懂恐怖设计）制造「懂行感」，识破圈套即智斗爽点。
现代侧：都市社区/论坛/短视频/民宿商战/游客吐槽/物价游客量（人民币/门票价/扩建费）。
灵异侧：怨灵/厉鬼/红衣鬼/鬼王/异度空间/古宅/废弃医院/尖叫指数（恐怖星级）。
设定名词以【方括号】标注（【惊吓值】【尖叫指数】【噩梦级任务】【恐怖大转盘】）。
禁止漂移到中式修仙（境界/灵气/金丹/宗门）或纯现实都市（无灵异）或日式怪谈直译腔。
```

## 类型门禁

> 写「恐怖兑现」用【尖叫指数+一星成就达成】——不是「阴风阵阵/灵气四溢」；写「收鬼」用【收服厉鬼为员工，解除其怨念】——不是「祭炼/炼化/夺舍」；写钱用【门票钱/扩建费人民币】——不是「灵石/银两」。
> 任何维度产出「境界突破/法宝祭炼/灵气运转/金丹元婴/皇宫朝堂/镖局武林」=类型味漂移，打回。

## 附加风味锚（灵异类特有）

1. **恐怖后置是本类核心叙事装置**（爽点在恐怖事件之后的兑现/复盘，不在事件本身）；
2. **懂行智斗**（主角专业视角识破圈套——「恐怖设计原理」「尖叫机制」「心理弱点」），自问自析式内心戏；
3. **设定名词用【方括号】标注专有名词**（【惊吓值】【噩梦级任务】【尖叫指数】式），界面信息量大但交互片段化（屏幕一亮/神经一绷涌现）；
4. **恐怖双平台转发**（论坛完整版理性讨论 + 短视频高能版情绪引爆，评论区骂声=免费流量）；
5. **冷幽默保温**（白天老板逗趣、游客吐槽、员工斗嘴）——恐怖章前后必须用现代日常对冲，防止全篇压抑劝退。
