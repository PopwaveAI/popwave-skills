# 西幻DND赛道包

## 包介绍

**面板一开，经验到账——DND流西幻的爽感密码，全部拆成了能直接抄的参数。**

写这条赛道最容易死在三个地方：爽点排不密、战斗没打击感、世界观搭不起来。这个包把答案全部数值化——

- **参数5表**：爽点0.93/章、章末钩子率100%、卷末三件套，每条都是强制红线
- **战斗写法分件**：动作拆到关节级、面板【】内联流，通用层+等级段战斗模式三段位+叠加层5件，战斗章照着写就有打击感
- **文风DNA笔触库**：共享笔触组件库按需采用——通用笔触基底首件（深渊主宰三段式）+场景卡分档（25场景公式）+ 卷级演变 + 5章滑窗去重，防长更重复；与赛道特色分层，只学笔触不学内容
- **世界观5件赛道百科**：泛DND总纲入口+地理/文明/规则/危机四篇，每个维度都给到数字实证颗粒度
- **角色库双件**：28人配置规格+实证级标杆卡+势力储备库，深度标尺直接量
- **剧情库三池23卡全幕级**：早期/中期/后期——总卡+幕件分件体系，白描+逐章锚点卡，改改就能当幕纲用

新书走 **DND规则×游戏面板流**？整包消费，全管线照标准执行。
