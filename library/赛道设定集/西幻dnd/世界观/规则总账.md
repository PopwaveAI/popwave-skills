# 规则总账 · 泛DND赛道（赛道百科·规则篇）

> 赛道级参考答案——机制与结构源自赛道标杆源书全书拆解，专有名已槽位化、章锚点已剥离。新书 world 展开对应维度时**抄机制、抄结构、抄颗粒度，不抄事件与专有名**；名词层以《赛道特色/名词表.md》为唯一真源。
> 七类规则是各维度公共输入的规则总账，每条回溯五设计原则（定义见《总纲.md》第五节）：**原则1** 大事件供给猎物 · **原则2** 位面分卷解锁 · **原则3** 数值面板量化 · **原则4** 容器源头双限 · **原则5** 传说度合法性（藏与显）。
> **空间类型判定**：**叠加空间**（多位面平行叠加+纵向分层，物质位面为最大层）——先按叠加空间处理，再定各层规则；宇宙结构全景见《总纲.md》第一节，本件只收规则细则。

## 一 · 规则总账表（七类规则）

| 规则类型 | 规则内容 | 回溯原则 |
|:--|:--|:--|
| **位面物理** | 平面世界物理：世界是平面大陆架（非星球），大陆架有起伏；上下层位面如金字塔底对底，最大者为物质位面；"三层纸"模型：物质位面+半物质位面（阴影）+灵魂能量位面（灵界）为核心，全部包裹在近乎无穷无尽的星界海洋里；灵界几乎无血肉生命，多为灵体存在，直接连接死神国度；物质世界的"物理定律"由奥术帝国遗产部分打破（浮空堡垒/中子星魔像/元素泯灭） | 原则2/3 |
| **位面物理** | **星界机制**：星界无空气，须靠半位面承载；进入星界的施法者自动掌握【法术瞬发】（6环以下全瞬发，传奇法术半时间）；接近源质海洋可令传奇法术瞬发；星界有【源质/暗能量】与尽头边界【晶壁】；星界=连接绝大部分位面的旅行通道与"垃圾场"（古神尸体/隐蔽半位面/陨落神国/残破浮空堡垒/星界战舰），别称【放逐之地】；阶层越深对手越强（CR随位面深度上升），凡人难入星界，传奇以上方可跨位面常态行走 | 原则2 |
| **位面物理** | **阴影位面（半物质位面）**：连接物质位面与大部分位面，灰蒙蒙基调，投影复制物质位面古老建筑，有影龙/扭曲阴影/亡灵；主角在杀戮/爆发状态下可短暂进入阴影位面；跨位面传送【阴影】是阴影系登神的进阶条件之一 | 原则2 |
| **位面物理** | **灵魂投影**是最简单的跨位面方式（恶魔/魔鬼常用），死亡只降低部分实力不致死本体；半位面靠星界+以太能量一点一点"长大"，即便传奇施法者也无法供给开辟能量 | 原则2 |
| **超凡法则** | 力量=六大属性+职业等级+专长的物化战力，一切可数值化（属性/职业/神性/神格/神力/领域/杀戮经验）；法术分三系：奥术（巫师，操控最好，补刀/控制型）、神术（牧师/德鲁伊，来自神灵与信仰）、类法术天赋（术士/神子，最具不可控性，早期有能量暴走期）；法术以"环"计量（1–9环，终局强者颗粒度标尺：法术免疫1-6环、法术瞬发1-8环）；施法代价：法术记忆印刻可省法术书但需付出杀戮经验 | 原则3 |
| **超凡法则** | 神性规则：神性=神性血脉，躯体能量化，免疫致命攻击（无致命伤/无心可活/免疫背刺，重击部位伤害更高）；微弱神性全属性+1、弱等+2；诸神化身形态获【超凡入圣】（免疫+1以下武器）+【法术免疫1-3环】；终局神格免疫：属性伤害/吸取、火、酸、冷、即死、疾病、瓦解、电、能量吸取、心智影响、麻痹、毒、睡眠、震慑、变形、监禁、放逐 | 原则4 |
| **战斗规则** | **挑战等级（CR）**衡量敌人强度与组队难度：约需5个同等级职业者组队才有约一半胜算；CR25≈半神和神性生物级别 | 原则3 |
| **战斗规则** | 伤害判定以**弹窗式呈现**（「条件反射通过/豁免失败」）；神性生物免疫致命攻击（免疫背刺），但重击部位伤害更高；神战中祈并者/英灵/圣灵/异界神侍一旦战死即**真正陨落** | 原则3/4 |
| **攀登规则** | 本职职业**5级=一阶→二阶分水岭**；职业阶位1–9阶；升级经验指数增长（顶级职业需千万级杀戮经验） | 原则3 |
| **攀登规则** | **封神三件套**：神性<神格<神职（容量排序）；只有拥有神职才能算是真神；抽取神性成功但无神格神职则神力储存失败 | 原则4 |
| **攀登规则** | 正常封神标准需**传说度最少200点**；传说度取决于观众/传播范围而非敌人强度——隐秘杀强者只得微量，扬名之战得高额 | 原则5 |
| **攀登规则** | 神格储存神力有极限（微弱神格约200点）；神力五档：微弱<弱等<中等<强大<伟大（主宰级），档间呈三倍金字塔跳、战力差≥6倍 | 原则4 |
| **攀登规则** | **血脉纯化仪式**每次进阶限一次，需1000金币级花费+法术辨识+学识；进入传奇后那次仪式获【传奇生命】（近战肉搏巨龙的资格） | 原则3 |
| **危机规则** | **大动荡（时代引擎）**：诸神全部失去神格力量，以化身形态行走凡间（化身属性普遍超凡、强者翻倍）；位面平衡打破→深渊/地狱/元素位面与物质位面连接强化 | 原则1 |
| **危机规则** | **神职承载责任**：拥有神职即背负相应责任，不尽责可能陨落；放弃神职归隐只有强大古神能做到；信徒数目不足→神格降级 | 原则4 |
| **危机规则** | 大动荡结束→诸神力量回归→物质位面产生强排斥力，诸神被排斥出物质位面；神殿十不存三、诸神神格可能降级、需数十年恢复信徒 | 原则1 |
| **原生威胁规则** | 深渊恶魔/九层地狱魔鬼随位面连接强化大量降临为祸；元素位面排斥外界进出；亡灵天灾（死亡神职失衡触发）；上古魔物（星界古神尸/位面战争遗产）随地图解锁投放 | 原则1/2 |
| **原生威胁规则** | **深渊血战**：恶魔vs魔鬼的永恒战争，永不停歇的前线绞肉机——中盘大场面与位面晋升的天然舞台 | 原则1/2 |
| **博弈规则** | **伪神是诸神重点打击目标**；若目标神职与他神冲突会遭不死不休攻击 | 原则1/4 |
| **博弈规则** | **神子机制**：预见陨落之神留子嗣分散神力、令其相互杀戮掠夺、集全者融合复活——幕后大反派的标准棋局 | 原则1 |
| **博弈规则** | 化身死亡只降一点力量，但化身上注入的神性/神格不可返还——可被【杀戮】神性者吸收 | 原则4 |
| **博弈规则** | **信仰经济**：物质位面是一切的根基——诸神国度的祈并者绝大部分来自物质位面；灵魂流转：死神先收走灵魂，再决定归于神国还是进入冥河轮回；狂信徒灵魂是神灵重要财富，死亡时神灵亲自接引 | 原则4/5 |
| **博弈规则** | **血祭封神风险**：血祭可快速增力但造成瓶颈（正道信仰封神上限远高于邪道血祭）；灵体封神易被信仰绑架、灵魂扭曲 | 原则4/5 |
