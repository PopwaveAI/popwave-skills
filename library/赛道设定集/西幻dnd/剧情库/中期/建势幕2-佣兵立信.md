# 建势幕2示范 · 佣兵立信·班底成形（ch11-25）

> CN-001 幕件之一（弧概览/六幕功能位序列/量级升级节奏/使用红线见《海外建势弧总卡.md》）。

## 套路决策
- **演绎框架**：单主线（死单翻盘）+班底聚拢线并织；变体=「反用内鬼」的伏击反伏击
- **内容引擎**：主 护航战与反伏击；辅 三骨干来投群像+情感线开启
- **高潮**：幕中段预设水道伏击反伏击｜类型 智斗翻盘+以弱胜强｜蓄力 排查内鬼与做饵局｜余波 商会背书、班底招牌
- **幕末钩子**：加码合同的条款缝里读出商会棋局——要的是航线控制权 → 指向幕4

## 幕定位
- **本幕作用**：把「一个人的名号」变成「一支队伍的招牌」——班底成形+雇主背书双落地。
- **核心体验**：死单翻盘的智斗爽×「有人愿意跟他走」的人心爽。
- **情感弧线**：孤身接单的算计 → 团队首战的托付 → 班底各带旧账来投的羁绊。
- **幕末质变**：挂牌佣兵→三线队长；「外来者的队伍」成为黑锚港招牌；商会棋局暗流挂上。

## 剧情白描（示范叙事）
名号换来第一张像样的单子：护送「必被劫」的黑金航线——船东们心知肚明这条线养着内鬼，三次护航三次被劫，悬赏一次比一次高。主角接单即立规矩：全队听他调度，报酬后结。他以排查内鬼开局——装货记录对不上账期，信息差一眼见底——却不动声色反用内鬼做饵：假情报引真劫匪入预设水道，一场伏击反伏击，劫船队全灭。这一战打得黑锚港侧目，也打来第一批追随者：女游侠诺拉主动入伙管斥候线——她看中的不是赏金，是「这人打仗先想队友退路」；被商行坑破产的老船长带着最后一条船投奔，管船务；半兽人铁匠因工坊被领主强占来投，管工坊。雇主（殖民商会大班）背书跟进：违约金条款、独家护航约、佣兵行会信用评级上调——「外来者的队伍」成了黑锚港的招牌。情感线开启：诺拉的嘴硬心软、老船长的酒与往事、铁匠沉默的报恩，班底从雇员变成「跟他走的人」。幕末，大班递来一份加码合同，主角却在条款缝里读出不对——雇主背后的商会，在下一盘更大的棋：他们要的从来不是护航，是这条航线的控制权。

## prose-render交接
- **文风注意**：团队战写调度感（分工/手语/预案）；班底来投各一场戏，来路写足；合同段写「读条款如读刀」。
- **不可改动骨架**（事件可换、功能位不可动）：①死单立规矩 ②反用内鬼伏击反伏击 ③诺拉/老船长/铁匠三骨干来投 ④商会背书+信用上调 ⑤合同疑点埋棋局。
- **可自由发挥**：内鬼身份、伏击战打法、班底旧账细节。
- **爽点外显**：信用评级上调面板式外显；全灭战以劫匪头目视角错愕侧写。
- **角色行为锚点**：主角-先想队友退路；诺拉-嘴硬心软；老船长-酒后吐往事；铁匠-沉默报恩。
