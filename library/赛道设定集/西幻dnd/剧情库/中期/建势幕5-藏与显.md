# 建势幕5示范 · 威名远扬·藏与显（ch76-90）【机制实装+人设高光幕】

> CN-001 幕件之一（弧概览/六幕功能位序列/量级升级节奏/使用红线见《海外建势弧总卡.md》）。

## 套路决策
- **演绎框架**：单主线（藏与显的取舍）+班底路线之争线并织；变体=「机制实装章」+「计算过的扬名战」
- **内容引擎**：主 传说度机制与扬名战三连；辅 班底价值观碰撞
- **高潮**：幕中后段摘死悬赏加冕｜类型 摘冠爽+名号峰值｜蓄力 藏显实验与双轨制定型｜余波 巨龙公敌锁定
- **幕末钩子**：青年巨龙「灰雾」全线公敌，面板「传说度预估+15」，圈进猎杀名单 → 指向幕6

## 幕定位
- **本幕作用**：传说度机制实装——封神线点火；「藏与显」抉择成为主角价值观外显的舞台。
- **核心体验**：规则揭示的智力快感×「每场扬名战都是算过的」的操盘感。
- **情感弧线**：机制亮栏的好奇 → 班底争吵的碰撞 → 扬名连打的痛快 → 圈定巨龙的冷静。
- **幕末质变**：势力之主→扬名者（「外来者神话」加冕）；双轨制（对内藏对外显）定型；封神构想确立。

## 剧情白描（示范叙事）
势力坐大后，面板上那个一直灰着的栏位亮了——【传说度】：名号传播的广度与烈度，可兑换为神格资格的入场券。规则同时给出两副算盘：藏，隐秘行事，收益打折但安全；显，扬名而战，收益翻倍但树大招风。主角第一次直面这套算术：他让斥候网做过一次实验——同一场猎杀，匿名完成，传说度+0.3；打出旗号完成，传说度+2.1，代价是三股旧势力的敌意警告。班底为此吵了一架：老船长要稳（「命都没了要门票干嘛」），诺拉要显（「咱们的人死一个，名号就得响十倍才值」），铁匠不说话，把二代军械又擦了一遍。主角的选择成为本弧的人设高光：对内藏——据点虚实、军械产能、航线底牌全部转入暗线管理；对外显——专挑「民心所向」的靶子扬名：剿灭贩奴船队、击退劫掠渔村的狂信徒、把黑锚港悬赏墙上挂了十年的死悬赏摘下来兑现。每一场扬名战都经过计算：风险、收益、传说度入账、凶名回传故土的时效。中盘，作乱航路的青年巨龙「灰雾」成为全线公敌——各方悬赏皆折戟，商会舰队折了三条船。主角盯着面板上那行「巨龙：传说度预估+15」的提示，把「灰雾」两个字圈进了猎杀名单：这不再是生意，是封神路上的第一块路标。
