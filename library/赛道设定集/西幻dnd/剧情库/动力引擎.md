# 动力引擎 · 西幻DND诸神流基线

> 引擎默认推荐：**「诸神失格·大动荡」**——诸神全部失去神格力量，被迫以化身形态行走凡间；位面平衡被打破、位面连接强化，神职空悬——「大事件供给猎物」，凡人第一次有资格弑神夺职登神。
> **引擎是世界级的**：所有凡人、教会、神子、半神都在同一场大动荡里攀爬，主角的金手指只是让他爬得快、看得远——这是诸神流与普通升级流的本质区别。
> 备选引擎（同类互换，机制同构）：①亡灵天灾（死亡神职失衡→亡灵潮席卷，猎物=死亡系神职）②魔网崩解（施法体系洗牌，猎物=法则类神职）③位面大融合（位面壁障碎裂，猎物=位面门户与古神遗产）。选型规则：引擎必须做到「神职空悬/权力真空+位面连接强化」两件事，否则改。

## 组成1 驱动逻辑

- **世界级驱动力：大动荡总因果**（L5级全书钩，开篇10章内点火）。源头建议设为「位面之外的扰动源」（不可名状/旧神残响/多元宇宙排异，任选其一），使诸神全部失去神格力量。
- 大动荡打破位面平衡→**位面连接强化**：深渊/九层地狱/元素位面与物质位面连接变紧密，异位面生物大量降临为祸——低阶猎物与危机的无限供给源。
- **为什么所有人都在爬**：神职悬空=权力真空。谁先陨落，其神职领域立即悬空成为新神跳板。诸神要夺回/守住神职，神子要集碎片复活夺舍，凡人野心家（伪神/登神者）要趁乱封神——一场全位面同时进行的登神竞赛。
- **个体层驱动（主角侧）**：初始唯一执念（护某人/活下去）→责任与格局层层放大为「庇护一城→庇护一域→重建秩序」，终点落在两个字（秩序/守护/自由，X注入）。

## 组成2 运转机制

> 通用攀登闭环（输入→转化→输出→反馈），全数值化面板驱动（属性/职业/神性/神格/神力/领域/经验均可量化）：

1. **输入**：击杀生物获杀戮经验（=灵魂能量，强敌给高额）；职业行为获职业经验（撬锁/解陷阱/潜行等本职行为）；事迹传播获**传说度**（由观众与传播范围决定，非敌人强度）；经营获信徒/领域（建城经营可得【统治】等领域）。
2. **转化**：经验→属性点+职业等级；神性→半神变身；传说度+神职→封神仪式；信徒信仰→神力（微弱神格储神力上限约200点）。
3. **输出**：面板大爆→身份/能力跃迁→新地图/新目标（爽点核心公式：每次跃迁必须数值外显）。
4. **反馈**：升级经验指数增长（顶级职业经验需求达千万级）→旧猎场收益衰减→**强制开拓新位面/新猎物**（位面分卷解锁的物质基础，不许靠「作者忘了」绕过）。

## 组成3 众生攀登分层（四类群体）

| 群体 | 攀登方式 |
|:--|:--|
| **有资源者（教会/神系）** | 发展信徒→凝聚神职→提神格；强大神力有资格开辟自己的神系、剥离神职制造属神；教会经营货币与神殿经济 |
| **没资源者（凡人/散人）** | 职业等级+冒险者工会任务认证；趁大动荡浑水摸鱼猎神子夺神性（主角路线之一）；野蛮路线：血祭供奉孕育邪神（快但有瓶颈） |
| **爬到顶者（诸神/主宰）** | 保证信徒数目否则神格降级；履行神职责任否则陨落；预见陨落的提前布局（留子嗣分散神力、借神子复活）；神国五阶守成体系（从神→神侍→圣灵→英灵→祈并者） |
| **掉下来者（陨落/被猎杀）** | 神子相互杀戮掠夺、集全者融合复活；化身死亡只降一点力量但注入的神性/神格不可返还——可被【杀戮】神性者吸收；卷末降级实证位：主角遭【能量吸取】类攻击永久降级、经验封印 |

> **非主角变强路径≥5条（供势力/角色库消费）**：①教会信仰经营线 ②神子夺舍线 ③登神者血祭线 ④深渊恶魔晋级线（低阶魔→高等魔领主）⑤女巫/术士传承线 ⑥灵体封神线（血祭邪神，风险=灵魂扭曲被信仰绑架）。

## 组成4 代价结构（含代价转嫁层）

- **通用代价**：升级经验指数增长；金手指跳过时间的代价=用杀戮经验弥补原住民年复一年训练获得的专长/技能。
- **群体差异代价**：血祭封神有瓶颈（正道信仰封神上限远高于邪道血祭）；封神反噬与传说度成反比；伪神是诸神重点打击目标，神职冲突=不死不休。
- **代价累积效应**：【能量吸取】类永久性损耗（降级+经验封印+属性削减）；神战中祈并者/英灵/圣灵一旦战死即**真正陨落**（不可复活）；大动荡后物质位面神殿十不存三、诸神神格可能降级、需数十年恢复信徒。
- **代价转嫁层（关键设计）**：①诸神把神位竞争转嫁给子嗣（令其相互杀戮掠夺，集全者融合复活——主角至亲亦可是一枚棋子）；②强大神力把经营成本转嫁给属神（剥离神职造属神）；③教会把神战成本转嫁给信徒；④下层位面把血战消耗转嫁给物质位面（位面连接强化后恶魔降临为祸）。

## 组成5 范式归类

- **主范式：飞轮型**（加速vs减速的矛盾基调）——数值即时正反馈机制（每场质变都给出可量化数据面板，读者「看得见的变强」）+ 周期性弑神喂大糖（每次「弑神→夺神职→晋神格」即一卷高潮）。
- **副范式：探索型混合**——位面分卷解锁（物质位面→海外/边疆→星界→深渊→冥界），「已知vs未知」驱动新地图开拓；叠加「压迫型」段落（卷一压抑期、中盘蓄力段、天灾期）形成节奏谷。
- **节奏基调**：四段式大结构——崛起期（压抑→突破→扬眉吐气）→扩张期（爽点烈度逐级抬升，封神为第一情绪峰值）→双线期（本体×化身爽点密度翻倍，中段一次蓄力）→登顶期（弑神连发冲伟大，终局执掌终域+集体升天=最高峰与情感闭环）。
