# 终局幕3 · 亡灵天灾（卷九·对应原书 ch845-895·51章）

> CN-002 幕件之一（弧概览/五幕功能位序列/使用红线见《诸神黄昏终局弧总卡.md》）。
> **本卡写法**：白描=源书卷九（ch845-895）真实剧情的槽位化转写，逐章核对自拆书白描卡；专名槽位化（主角/双子/野心死神/现任死神/谋杀之神/红龙女王/猫之少女皆尊号，新书替换）；数值锚点保真。

## 套路决策
- **演绎框架**：天灾为幕布、多线抄底为内容——亡灵之灾是凡人的浩劫、主角的机遇期
- **内容引擎**：主 趁乱发育（夺宝/收人/截资源）；辅 死亡秩序崩灭与接管（旧王衰落、新王布局）
- **高潮**：幕内三次中大爆——截断冥河（神迹级工程）、夺角之冠升【死亡】神职、碾杀夺舍女神封猫之少女｜蓄力 加冕/收红龙/钻石行星
- **幕末钩子**：神格251距300强大神格还差49，再杀一个强大目标即可跻身强大神力；死亡神系角逐开启 → 指向幕4

## 幕定位
- **本幕作用**：还前八卷死亡线的总账。旧死亡秩序（现任死神的长眠领域）在天灾中崩灭，主角以死亡神系继承者身份一步步接管：改神使接引灵魂、夺【死亡】神职、截流冥河、蓄养刷怪池。同时把天灾变成发育窗口，攒够冲击强大神力的最后一批筹码。
- **核心体验**：别人救灾他抄底——浩劫每深一层，主角的盘子就大一圈。
- **情感弧线**：晋级的笃定 → 浩劫下的冷峻 → 收服敌人的快意 → 截断冥河的豪迈 → 碾杀夺舍者的狠辣。
- **幕末质变**：神性350→368、神格240→251（距强大神格300还差49）；【死亡】领域升格为死亡神职，再获【诡术】领域；冥河支流两条+神国刷怪池成型；金刚石魔像一万五千尊产能落地；明确锁定下一个猎杀目标。

## 剧情白描（槽位化转写）

**第一段·晋级与天灾开幕（ch845-851）。** 融合恐惧魔神力量的红利到账：神性累计350点跃升强大神性，面板全面更新（神格240【中等神格·300升强大】、神力1513/4800），神格免疫开启。主角清醒地算了笔账：再击杀一个强大目标，即可跻身强大神力。同一时刻，第四波亡灵之灾开始酝酿：泥潭镇坟场死者复生，查明是蓄谋已久的人为袭击；各地热疫、鼠疫、亡灵瘟疫全面爆发，亚马逊死亡上万，风暴之主直接毁灭感染城镇。审判处揪出混进城的红袍巫师会死灵系巫师，供出幕后是奈瑟时代的古老半神巫妖"不死者"；无底深渊里，不死之王回归，亡灵军团在白骨殿堂集结——多元宇宙的诸神与魔鬼都听见了动静。三位不死君王先后现身，沙漠中的野心死神与老巫妖密谋：围杀现任死神。

**第二段·加冕与收服（ch852-866）。** 浩劫之下，爱情女神携欢乐、猫与舞蹈女神上门求庇护，主角接纳五万信徒——看中的正是他们有钱。长公主封神（神职冰雪/寒冷/冬季），女巫领袖备下价值超五百万金德勒的聘礼，自甘退让成全；女王加冕大典上，主角暗中连除五波破坏者，与长公主化身并肩屹立云端，亲手为她戴上金冠。谋杀之神破开时空封印降临，却被圣者浩劫压制成圣者形态，靠杀巫妖夺灵魂之火恢复半神。被魔鬼抛弃的红龙女王走投无路投上门来：主角带她看水泥大道、水晶路灯、四十万人口的城市，再逐一戳破她与欲魔女王的契约、以邪恶魔祭抽取同族血脉的隐秘，断了她所有退路，开价"神国圣灵之位"，收下她的单膝跪地——以及事后的暗中监视。

**第三段·长眠崩灭（ch858-860）。** 现任死神追击巫妖之神，落进野心死神设下的陷阱：不死者、老巫妖、不死之王率上百巫妖与亡灵君主围攻。长眠领域消散——物质位面的死者从此无需任何法术便可自行转生为亡灵，南海岸战场尸骸遍野站起。主角颁下神谕：死神侍从已无力接引，改由己方异界神使亲自接引信徒灵魂，绝不让魔鬼恶魔偷走一个。旧秩序的账，新秩序开始接手。

**第四段·抄底发育（ch867-887）。** 主线之外，主角把天灾过成了丰收季。颁布【对抗亡灵同盟契约】，调五万海盗战士支援前线——心里定的却是让其中两万人战死，清洗军队、补充神国英灵，一言定生死。探明星界一颗直径约一公里的钻石小行星：五十倍重力、每秒十点辐射，内部全是成型金刚石与秘银精金；长公主出材料、女巫领袖布下三十六座浮空环，硬把它拖进阴影位面，收益主角独占六成，金刚石魔像产能一万五千尊落地，核心三千吨黑色晶体单独封进半位面，改造成五倍重力修炼场。化身攻下骸骨之界，收割约五万灵魂晶石；又潜入龙巫教营地，从前任死者之王遗留的高等神器【角之冠】里抽干神性：神性+10、神格+5，【死亡】领域正式升格为死亡神职，残器重铸成七枚死亡魔戒。期间顺手掌握神格能力【天神下凡】（免疫一至八环法术），借圣灵牧师之力击碎野心死神的临时化身，判定双方实力三七开；异界神以现任死神踪迹为饵求合作，主角拒绝——无法信任一个目标疑似某位强大神力的外人。

**第五段·冥河改道与猫之少女（ch888-895）。** 天灾最深处：北风之城等相继被攻破，遇难者灵魂神秘失踪；野心死神占领冥海，现任死神彻底失去冥界。主角决定把王国与神国切开——扶持红发女海盗在南海岸建国，自己摘出俗世因果；然后干了票大的：真身降临无底深渊，多重神格力量齐开，硬生生劈出一条三千米河道，把第七条冥河支流截进自家神国，截留的灵魂经转生池刷成阴影生命，占地五十平方公里的"刷怪池"成型，英灵定期收割。卷末，有人以神性给家养小奶猫种下夺舍诅咒——查明是近乎陨落的猫与舞蹈女神想借体重生。她现身求饶，愿以冥河誓约臣服，主角断然拒绝，直接碾杀：经验+150万、神性+8、神格+6，【诡术】领域入账；逸散的神职与力量尽数注入小奶猫，一只拥有【猫】神职的半神"猫之少女"就此诞生，交给双子调教。

## 设计提炼（本幕的写作指导）

1. **天灾的三层推进**：疫病（凡人层，村镇死者复生）→君主现身（神话层，三位不死君王亮底牌）→长眠领域崩灭（规则层，死者自动转生）。浩劫感不靠形容词堆，靠灾难一层一层升级，每一层都比上一层大一个量级。
2. **危机即机遇的抄底结构**：本幕主角的每笔大收益都长在天灾的伤口上——瘟疫想起堕落女巫的瘟疫神力、亡灵大军变成英灵来源、衰弱女神变成猎物、冥界失控变成截流窗口。写天灾期主角的正确姿势：不是扛灾，是把灾难换算成资源。
3. **目标清单明文化**：晋级后立刻算账——神格240缺60，主角逐一分析候选猎物（谋杀之神/重伤的现任死神/巫妖之神），锁定优先级。终局升级不靠偶遇，靠菜单；读者看着清单，就等着看他先吃哪一道。
4. **神明冷酷面与人性面并存**：一言定两万海盗生死（换血弃子）、夺神器时无视濒死银龙——神性面的"视凡人如棋"；同一幕里护奶猫、调教双子、给忠仆封神使——人性面的温度。两面都写，主角才是神而不是爽文机器。
5. **收服敌人的完整流程**：戳破隐秘（契约/魔祭血脉）→断退路（魔鬼已弃、公国必亡）→开价（神国圣灵之位）→受降→事后继续监视。降服不是一笑泯恩仇，是把刀柄永远攥在手里。
6. **捡尸的艺术**：天灾期猎杀优先挑落单衰弱的——近乎陨落的女神送上门（还是她自己先动的手），碾杀后神职喂给自己人。大爆不一定打大怪，落魄的神也是神。
7. **神迹级工程的写法**：截断冥河不写"他挥挥手就成了"——真身降临、多重神格力量齐开、劈山三千米、改道工程才完成一半。奇观要写出工程量，豪迈感来自具体的数字。
