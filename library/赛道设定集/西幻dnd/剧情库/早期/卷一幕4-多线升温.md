# 幕4示范 · 多线升温·双子觉醒（ch0139-0182）

> RHY-001 幕件之一（弧概览/五幕功能位序列/密度基准/使用红线见《卷一五幕总卡.md》）。

## 套路决策
- **演绎框架**：双线并行+汇合（北地融神性修炼线×公主护送线），汇合后转双子觉醒线
- **内容引擎**：主 意志磨砺+融神性；辅 双情感线（公主表白/伴生人格觉醒）
- **高潮**：ch0160-0161型｜类型 危机反转+萌反差（8岁秒杀传奇）｜蓄力 融神性与刺客逼近｜余波 变异悬念+人格之争
- **幕末钩子**：危机预告（大都会恶魔降临）→指向幕5

## 幕定位
- **本幕作用**：主角融合神性完成「意志强者」蜕变；伴生人格独立登场；公主线定型为「守护承诺」。
- **核心体验**：三重爽——融神性的苦修回报、公主表白的情绪爆点、8岁萝莉秒杀传奇的反差碾压。
- **情感弧线**：雪地力竭的孤立无援 → 公主线与双子之秘交替升温 → 恶魔降临的阴云。
- **幕末质变**：主角获恐惧系天赋（不可逆战力跃升）；双子人格公开化；主角背上「变异」之谜。

## 剧情白描（示范叙事）
北地雪原，凯登以雪地行走磨砺意志，融合恐惧神性：获【恐惧目光】【恐惧术】【吸血鬼之触】，属性提升，得弱等寒冷抗性与「苦行者」背景专长——代价是力竭倒毙雪中，被路过的「贵族小姐」所救：她支付住宿伙食、请牧师治疗，想带这个冒险者同行被嬷嬷劝阻。她就是霜环城王国的小公主卡珊。她的姐姐以冰雪化身冻杀蒙面人救妹、以寒冰堡垒封禁古兽，对凯登保持戒备。护送路上，凯登背卡珊翻越冰封山路，她为他守夜、学照料；二人分别得「幸运/厄运」双子赐福，命运被暗中拴线——厄运女神牧师「敲诈」凯登却赐下【厄运赐福】：免疫厄运+敌人厄运减值，表面敲诈实为机缘。临别，卡珊光脚策马追出皇宫，站上城墙当众大喊：「凯登！我喜欢你！你敢不敢娶我！我明年就十六岁了！」凯登因「为妹妹必走魔神道路」，以守护骑士礼回应、拒绝成婚、转身离去。感情的余温未散，杀机已至：传奇刺客将薇欧拉逼至绝境，瞳孔充血、恶魔之翼张开——「我不是薇欧拉，我是魔女-□□」——【恐惧神域】+【时间静止】，一剑分尸传奇刺客；随后留信：「告诉哥哥我杀光那些杂碎就回来，还给他准备一份大礼。」凯登的面板闪过「未知变异」的猎杀者模板；双子人格之争浮出水面，魔神意志在背后窥视。堕落女巫与米瑞安母女理念决裂。凯登招募叛逃的新生吸血鬼合作，她临终以「救赎」自问，凯登应「愿你获得救赎」，她含笑死去，凯登为其立墓刻「身在黑暗，心向光明」。幕末，大都会恶魔降临，一尊「魔鬼」走进火海——大风暴的前夜。
