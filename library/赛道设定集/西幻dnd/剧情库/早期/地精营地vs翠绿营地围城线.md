# 地精营地vs翠绿营地围城线（OS-004）

> 骨架源自博德之门3第一幕「地精大军vs翠绿营地」战争线（解耦借鉴）。地精/提夫林/德鲁伊为DND开放种族概念，可直接使用；BG3具体角色与剧情分支禁止照搬。本卡是「解耦入库」旗舰示范：一幕完整剧情，拆出即用。
> **消费方式**：plot 产幕白描时直接以本卡为底稿——改专名、换事件分支、对接本书X张力；示范专名（塞文/贝拉翠/格雷姆/莉安德拉/翠绿营/蚀日教团）已登记命名规则示例库。

## 弧定位
- **本弧作用**：一幕喂出「声望+班底+第一桶金+跨卷暗线」四件套——低阶主角的战争红利收割机。
- **核心体验**：三方夹缝里的破局智斗——弱者靠裂缝搅动大局。
- **情感弧线**：过客心态 → 两头受信的骑墙 → 摊牌站队 → 战后担责。
- **弧末质变**：「外来佣兵」→「声望者+班底之主」；教团背后的「神」转入跨卷暗线。

## 剧情白描（示范叙事）
界河对岸的战火把流民全赶向同一条活路——翠绿营，德鲁伊守护的自然庇护所，古树结界是方圆百里唯一的挡箭牌。佣兵塞文护着一小队提夫林难民赶到时，正撞上营内的争吵现场：大德鲁伊格雷姆外出未归、生死不明，代理首领「棘语者」贝拉翠执意启动封林仪式——结界闭合之日，就是营外数千难民的死期；提夫林首领莉安德拉领着难民据守营门，寸步不让。塞文以佣兵身份两头接活：替贝拉翠调查营内连环异变（物资失窃/孩童失踪/仪式材料被动过），替莉安德拉清剿路上的地精猎杀队——每一步都在为「谁信得过我」加权。调查线揪出真相：营内潜伏着蚀日教团的内应，异变全是围城军的攻心布置，而封林仪式本身就是教团借贝拉翠之手设的死局。塞文带小队潜入地精营地，摸回两件致命情报：围城兵力是预估的三倍；三头目各怀心思——军阀「碎颅者」只信拳头，女祭司「黑瞳」只信主子，投机者「三指」只信活命。双倒计时并轨：封林仪式七日后启动，围城军十日后总攻。摊牌夜：内应发难、贝拉翠政变失败被软禁，塞文当众揭露仪式死局，并救回被地精掳走的大德鲁伊格雷姆——封林术反转用途，结界变瓮：放地精先锋入瓮、闭合、聚歼。总攻日三段式打完：营门战（难民武装据守）+瓮中聚歼+斩首战（塞文猎杀三头目），地精先锋覆灭。战后分账：翠绿营开门放行、难民立誓相随成为塞文第一批班底、缴获军械是第一桶金；而格雷姆只留下一句话——「蚀日教团的背后，站着神。」

## prose-render交接
- **文风注意**：难民群的写实质感×结界神术的奇幻奇观；低阶战斗写「脏、快、狠」，不写史诗腔。
- **不可改动骨架**：①入营即撞派系之争 ②双倒计时并轨 ③内应线+仪式死局揭露 ④敌营三头目分化 ⑤封林术反转为瓮 ⑥总攻三段式+战后分账。
- **可自由发挥**：异变案细节/荒野遭遇/地精营地生态/守城手段。
- **爽点外显**：声望以他人反应侧写；缴获军械开清单；班底投效给名场面。
- **角色行为锚点**：主角-骑墙但守底线，先算三方出价再算良心；贝拉翠-恐惧驱动的强硬，不是反派。

## 阵营抉择树（一幕三走法）
- **守序/善良线**：揭露内鬼+政变失败+守城胜利——收获：庇护所声望+难民班底+德鲁伊传承；代价：地精残部记仇（下幕钩子）；
- **黑暗线**：勾结围城军开门屠营——收获：邪教阵营信用+战争横财；代价：全镇通缉+班底离心（黑化流开局专用）；
- **中立渔利线**：两头收钱，战前套走双方关键资源远走高飞——收获：第一桶金；代价：声望归零，后续以假名行走（适合独行流）。

## 结构性经验
1. **双倒计时锁节奏**：内部「关门仪式」与外部「围城日程」并轨——无论主角选哪边，时间都在流逝，幕中段永远不塌；
2. **三方都有裂缝**：每一方都不是铁板（内鬼/三头目/派系斗争）——低等级主角的破局点全在裂缝里，这是「弱者搅动大局」的合法引擎；
3. **难民=免费班底池**：战后流民天然成为主角第一批追随者/情报网/商队护卫——一幕战争喂出扩张期班底；
4. **政变=副本化内部BOSS**：庇护所内部政变是不用打硬仗的「智斗BOSS」，调剂围城战前的节奏；
5. **战后分账=声望变现窗口**：胜利后的分账大会是低阶主角获得第一份「超规格待遇」的标准场景。

## 可移植变体
庇护所可换成：边境要塞/商队驿站/矿区小镇/修道院/学院城；地精大军可换成：兽人战帮/亡灵潮/邪教军团/佣兵讨伐队——保留「庇护所+难民+内鬼+围城军+双倒计时+三方裂缝」结构即可。
