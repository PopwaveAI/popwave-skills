# 盗贼团夺宝线（OS-002）

> 骨架源自知名奇幻冒险电影叙事型（解耦借鉴）。适合做扩张期前的「组队弧」或单元剧支线。
> **消费方式**：plot 产幕白描时直接以本卡为底稿——改专名、换事件分支、对接本书X张力；示范专名（「银指」科尔/安妮娅/瓦里克/桑德维尔/金穗镇）已登记命名规则示例库。

## 弧定位
- **本弧作用**：低成本喂出一支「有旧账的班底」——组队、磨合、背叛、重聚一轮全走完。
- **核心体验**：计划完美推进→当众崩盘→藏在计划里的计划翻盘。
- **情感弧线**：互相利用 → 并肩磨合 → 背叛谷底 → 复生重聚。
- **弧末质变**：「独行惯犯」→「有队伍的人」；队伍去留抉择直接对接扩张期班底。

## 剧情白描（示范叙事）
「银指」科尔要赎回被地下钱庄抵押的妹妹安妮娅，价钱是买下整座钱庄——而全城只有一件东西值这个价：金穗镇夺宝大赛的头奖，传说级圣物「复生圣杯」。他从城邦监狱越狱，不靠蛮力，靠一把偷来的钥匙和一场恰到好处的火灾。按职业互补拉队伍：收钱办事的蛮勇前排巴尔特、被学院除名的落魄法师芙兰卡、话痨神棍牧师莫恩、只为分红入伙的机动位赛琳，以及「太了解他」的老搭档瓦里克——当年科尔的旧队因为他而散，瓦里克是唯一没死、也没原谅他的人。分成条款当场谈崩又谈成：三七开，三成抵旧账。

大赛第一轮·遗迹竞速：十二支队伍同入坍塌的神庙地宫，只有前三名晋级。种子队「掘金者」买通守卫堵死主墓道，逼所有人挤进塌方频发的侧廊；科尔的队走芙兰卡用学院旧识认出的排水暗渠——代价是她被守陵的旧同学当场认出，讥讽她「落魄到和贼一起偷坟」。遭遇战在墓室深处爆发：守墓构装体苏醒，巴尔特顶盾、莫恩喊破神术弱点、赛琳飞身拔走符文核心——第一场仗打完，六个散人第一次像一支队伍。摩擦也在这里：分赃时瓦里克坚持先扣「旧队抚恤金」，与赛琳的「先按合同来」当场翻脸；科尔各打五十大板，把抚恤金折成分成比例写进补充条款——第一次露出队长的成色。

第二轮·攻防易位：上轮前三轮流守擂，其余队伍抽签攻擂，夺旗即换位。科尔抽到攻「掘金者」——正面强攻是死路，他使盘外招：赛前让莫恩以「为亡者安魂」的名义登台勘察，把守方布防摸了个底朝天。攻擂战里巴尔特佯攻正门，芙兰卡与赛琳走祭坛暗道直取旗杆，瓦里克殿后反杀追兵——连携成型。真正的买卖在场外：圣杯要在金库与赛台之间转运两次，科尔扮作清点杂役混进转运队，第二次转运时用三天前做好的赝品换下真杯——没人发现，因为全城都在看擂台。这一轮的内讧也最凶：瓦里克撞见科尔深夜独行，质问他「又想在谁背后下刀」，科尔只答「习惯就好」——猜疑的种子在连胜里发芽。

第三轮·决赛夺杯：决斗场中央的锁链阵，两支决赛队隔阵争杯，先捧杯者胜。科尔的队以连携碾压夺冠，赝品圣杯当众捧起——满场欢呼里，只有瓦里克读懂了科尔眼里的冷。当夜庆功，瓦里克没回营地：他把布防图与离场路线卖给了大赛背后的黑金主人奥古斯特·桑德维尔——他确信科尔要独吞圣杯，与其被再卖一次，不如先出手。桑德维尔的人连夜收网：「圣杯」被夺、队伍当场散伙；而科尔在最不可能的地方见到了死者——桑德维尔最锋利的爪牙，正是他以为早已病死的安妮娅。她被「复活」过，代价是记忆被篡改：妹妹看哥哥的眼神，像看一件抵押物。

谷底反弹藏在职业本能里——科尔从不在一张牌上押全部：被夺走的本就是赝品，真杯早在第二轮转运时已换藏。他用真杯复生旧队长亨里克（当年替他挡刀而死），召回瓦里克（一句「下次三七归我」抵掉所有抱歉），团队重聚掀翻桑德维尔的黑金王国——账本、金库、上游买家名单一锅端，救回被「复活」扭曲了的安妮娅。终局分账：妹妹自由、旧债勾销、去留自选——留下的是班底，离开的是自由身。

## prose-render交接
- **文风注意**：盗贼的「手艺感」写细节（开锁/调包/易容），队伍群像靠斗嘴日常喂活。
- **不可改动骨架**：①越狱=巧胜非力敌 ②五人互补组队+分成谈判（背叛种子）③三轮赛事=遭遇×内讧交替 ④决赛夜双重背叛（队友+至亲）⑤调包计翻盘+复生召回 ⑥分账收束。
- **可自由发挥**：监狱机关/赛事规则细节/各队友背景/黑金王国生态。
- **爽点外显**：连携战给「配合成功」的即时反馈；复生与重聚用情感爆点写。
- **角色行为锚点**：主角-计划里永远藏计划；瓦里克-失望者的叛变，重聚时不说抱歉说「下次三七归我」。
