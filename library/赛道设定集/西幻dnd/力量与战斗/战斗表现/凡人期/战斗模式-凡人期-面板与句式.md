## 一、面板格式汇总

### 1.1 暗杀击杀面板（5行标准）
```
"阴影躲藏成功！"
"背刺发动！"
"成功发动背刺*2，对目标造成X点伤害！"
"目标死亡！"
"抽取目标灵魂能量，获得杀戮经验X点。"
```
适用：伏击秒杀型、信息逼供型补刀、游击消耗战补刀（背刺补刀时）

### 1.2 暗杀未秒杀面板（4行）
```
"阴影躲藏成功！"
"背刺发动！"
"成功发动背刺*2，对目标造成X（+X）点伤害！"
"目标严重受伤！"
```
适用：未秒杀转型

### 1.3 技能击杀面板（跨阶击杀，5-6行）
```
"跳斩成功命中！……"
"额外附加X（XX－10）点力量伤害加成！……对目标造成X点穿刺伤害！……"
"目标死亡。"
"成功击杀XX！……抽取目标灵魂能量！……"
"获得X点杀戮经验。"
```
适用：终结技爆发（剑势【重劈】成功、剑势【斩首】成功）

### 1.4 道具击杀面板（3行）
```
"圣水命中幽灵，造成60点伤害。"
"目标死亡！"
"抽取目标灵魂能量，获得经验值120点。"
```
适用：使用道具（圣水/炸弹/毒药）完成击杀

### 1.5 职业升级面板
```
"盗贼职业提升到X级。"
"获得X（敏捷值X+（智力X－10）*0.5）点技能点，生命值提高X点（职业生命X点+（体质X－10）*0.5）。"
"获得1点自由属性。"
```
特定等级追加：
```
"领悟职业技能【XX】。"
"获得一个专长点。"
```
适用：战斗后升级、训练后升级

### 1.6 技能失败面板
```
"发动剑势【斩首】！……"
"斩首失败！……你对目标造成重击效果！……目标受到X点的劈斩伤害！……目标进入流血状态！……"
```
适用：终结技爆发（剑势【斩首】失败）

### 1.7 战后总结面板
```
"战斗结束。"
"经过一场艰难的战斗，你的技艺获得提升！……你成功对XX发动嘲讽！……你成功对XX发动威吓！……"
"威吓+10，嘲讽+5，闪避（翻滚）+2，闪避（腾挪）+1，招架+1，野外生存+2。"
"你掌握了战斗技能——剑势【重劈】。"
```
适用：训练对战、高强度战斗后的技能成长总结

## 二、怪物鉴定面板格式

首次遭遇新怪物类型时必弹。面板以意识流数据流形式嵌入叙述。

```
"[名称]【[种族类型]】（[阶位]）。"
"挑战等级X，[个人/生物]等级X，[生命类型]。"
"最高属性X点，最低属性X点，总属性值X－X点。"
"特殊专长：[专长1]、[专长2]……"
"挑战难度：[字母]+/-。"
```

**示例**：

> "半兽人战士【人型生物】（一阶）。"
> "挑战等级2，生物等级3，人型生命。"
> "最高属性力量17点，最低属性魅力6点，总属性值12－17点。"
> "特殊专长：狂暴、野蛮打击。"
> "挑战难度：D+。"

**写法要点**：
- 种族类型用方括号【】：【人型生物】【亡灵】【野兽】【异怪】
- 阶位用圆括号（）：（一阶）（二阶）（三阶）……凡人期敌人通常为一至三阶
- 挑战等级为阿拉伯数字，挑战难度为字母+/-：D- < D < D+ < C- < C < C+ < B- < B < B+ < A- < A < A+
- 总属性值格式"X－X"表示最低属性到最高属性的范围
- 特殊专长列举2-4个，用顿号分隔
- 怪物鉴定面板弹出后，后续同类怪物不再重复弹（除非出现变种/精英/首领）

## 三、拟声词体系

| 拟声词 | 用途 | 出现位置 | 独占行 |
|--------|------|---------|--------|
| 噗通 | 尸体倒地（暗杀） | 暗杀击杀面板后 | 是 |
| 扑通 | 尸体倒地（非暗杀） | 正面战/游击战击杀后 | 是 |
| 铛铛铛 | 连续格挡（三连） | 正面战格挡起头 | 是 |
| 铛 | 单次格挡 | 正面战单次格挡/弯刀格挡 | 是 |
| 铿锵 | 金属碰撞/武器出鞘 | 战斗准备/武器交锋 | 否 |
| 嗦 | 箭矢飞行 | 协作伏击远程攻击 | 是 |
| 噗嗤 | 利器刺入肉体 | 背刺/匕首刺入 | 否 |
| 砰 / 砰砰砰 | 撞击声（围攻） | 多敌人围攻/重武器砸地 | 否 |

**使用规则**：
- 拟声词独占行时，后面不加标点（"噗通"而非"噗通。"）
- 同一段战斗中，同一种拟声词最多出现2次，第3次起用动作描写替代
- "噗通"专用于暗杀后的尸体倒地，"扑通"用于非暗杀的尸体倒地，不可混用
- "铛铛铛"为三连格挡专用，单次格挡用"铛"，不可用"铛铛"（双连无此用法）

## 四、句式节奏特征

### 4.1 暗杀型节奏
```
极短句（3-5字）×2-3 → 面板（5行）→ 拟声词独占行 → 解释性长句（1-2句）
```
> 示例：气息收敛。匕首翻转。→ 面板 → 噗通 → 尸体倒在地上，索伦迅速上前翻找。

### 4.2 正面交锋型节奏
```
拟声词独占行 → 动作句（中长，15-25字）→ 属性判断/战术旁白（1-2句）→ 反击动作（短句）
```
> 示例：铛铛铛！→ 长剑连续劈下，索伦用匕首硬生生接了三击。→ 力量不算太强，长剑的优势在于攻击距离。→ 侧身一步，匕首沿剑身滑下。

### 4.3 技能爆发型节奏
```
压力铺垫（中长句×2-4）→ 破折号引出技能名（极短句）→ 身体内部描写（中句×1-2）→ 连续动作链（短句×3-4）→ 视觉冲击结果（中句×1-2）→ 面板
```
> 示例：体力见底，退无可退。→ ——剑势【重劈】！→ 肌肉绷紧，力量凝聚到极限。→ 跃起，高举，劈下，斜斩，横斩。→ 头颅飞起，鲜血喷涌。→ 面板

### 4.4 游斗型节奏
```
拟声词 → 极简概括（1句）→ 属性差距说明（1句）→ 一笔带过结果（1句）
```
> 示例：铛铛铛——长剑连续挥出，每一剑都切中要害。→ 敏捷差距不可弥补。→ 三息之后，战斗结束。

### 4.5 协作型节奏
```
A行动（2句）→ B行动（2句）→ A行动（2句）→ ……循环
```
> 示例：箭矢破空——嗦！→ 命中后背，对方身形一顿。→ 索伦暴起，匕首划出弧线——背刺！→ 匕首没入腰侧，对方闷哼。→ 索伦后撤，另一支箭矢紧随其后。

**五种节奏型对比表**：

| 节奏型 | 句长 | 面板位置 | 拟声词 | 核心节奏感 |
|--------|------|---------|--------|-----------|
| 暗杀型 | 极短→长 | 中间 | 噗通（面板后） | 快-停-快 |
| 正面交锋型 | 中长→短 | 可选 | 铛铛铛（起头） | 稳-稳-快 |
| 技能爆发型 | 长→极短→短→长 | 末尾 | 破折号引出 | 慢-爆-快-收 |
| 游斗型 | 中→短 | 可选 | 铛铛铛（起头） | 快-快-止 |
| 协作型 | 中→中→中 | 无 | 嗦（区分角色） | 交替-交替-交替 |

## 五、武器差异写法

| 武器 | 战斗侧重 | 标志拟声词 | 标志动作 | 适用模式 |
|------|---------|-----------|---------|---------|
| 匕首 | 刺入+格挡崩裂 | 噗通/铛铛铛 | 背刺/侧步刺 | 暗杀/正面格挡/游击 |
| 弯刀 | 穿透+斩落 | 嗦/铛 | 能量穿透/连续斩 | 正面交锋/终结技 |
| 长剑 | 游斗+架住 | 铛铛铛 | 架住/绕杀/一笔带过 | 游斗/正面格挡/终结技 |
| 弓弩 | 远程穿透 | 嗦 | 破空/命中 | 协作伏击/游击消耗 |

**武器切换写法**：
- 同一场战斗中主角可切换武器，切换时用1句过渡："索伦收起匕首，拔出了长剑。铿锵。"
- 武器切换标志着战斗模式切换（如暗杀→正面战 = 匕首→长剑）
- 武器出鞘声"铿锵"仅用于切换时，不用于战斗开始时的初始武器

## 六、使用指引

### 6.1 战斗模式选择决策树

```
施工卡标注战斗类型？
├─ 暗杀/偷袭 → 查是否秒杀
│   ├─ 秒杀 → 伏击秒杀型（1.1）
│   ├─ 未秒杀 → 未秒杀转型（1.2）
│   ├─ 有队友 → 协作伏击型（1.3）
│   └─ 需逼供 → 信息逼供型（1.4）
├─ 正面遭遇 → 查武器组合
│   ├─ 匕首vs长剑 → 匕首格挡长剑（2.1）
│   ├─ 匕首vs铁剑(力量碾压) → 匕首架住铁剑（2.2）
│   ├─ 长剑vs弱敌 → 长剑游斗（2.3）
│   ├─ 弯刀vs重武器 → 弯刀对重武器（2.4）
│   └─ 潜行vs潜行 → 潜行vs潜行（2.5）
├─ 属性/体型远超主角 → 游击消耗战（3）
├─ 高潮章/压力临界 → 终结技爆发（4）
└─ 非生死战斗 → 训练对战（5）
```

（各模式详解见《战斗模式-凡人期-模式库.md》第三章）

### 6.3 参照物锚定规则

属性数值弹出时，必须在同章内用参照物锚定：

| 属性值 | 参照物锚点示例 |
|--------|--------------|
| 力量8-10 | 普通成年人类水平 |
| 力量12-14 | 超过大多数人类，接近战士入门 |
| 力量16-17 | 精锐战士级别，手臂发麻级别 |
| 力量18+ | 怪物级力量，正面不可对抗 |
| 敏捷14-16 | 超越绝大多数人类 |
| 敏捷18-20 | 盗贼顶尖水平，肉眼难追踪 |
| 体质12-14 | 比普通人耐打，但不抗重击 |
| 体质16+ | 半兽人级别，难以击杀 |

**锚定方式**：
- 直接锚定："力量16点以上——这意味着正面对抗毫无胜算。"
- 比较锚定："敏捷18点，已经超越了绝大多数人类能达到的极限。"
- 体感锚定："仅仅是这一击，手臂就开始发麻。力量至少16点。"
- 同一参照物跨章间隔 ≥ 3章

| 章节类型 | 推荐战斗模式 | 面板密度 |
|---------|-------------|---------|

### 6.6 特殊借调：首弑神性（卷末大事件）

凡人期主角击杀神性生物（如神子）时，**临时借调超凡期的弑神数据链面板模板**（`../超凡期/战斗模式-超凡期.md`）——数值规格按超凡期锚，制造"凡人杀神性物"的跨段冲击；但战斗过程仍全程按凡人期写法（底牌尽出+神器/外部介入翻盘，禁突然出现超凡期战斗能力）。借调只在卷末大事件用一次，滥用=等级段红线违规。

## 七、面板/句式级红线

1. **击杀面板红线**：每次击杀必弹面板。无面板击杀=不合格。例外：协作伏击型（1.3）和潜行vs潜行（2.5）无面板。
2. **参照物锚定红线**：属性数值必须有参照物锚定（同章内）。同一参照物跨章间隔 ≥ 3章。
3. **面板意识流红线**：面板以意识流数据流形式嵌入叙述，不以弹窗/光屏/全息投影形式出现。
4. **数值规模红线**：凡人期伤害值控制在个位至两位数（最大不超过99）。杀戮经验不超过200。不得出现三位数以上的伤害值。
5. **拟声词独占行红线**：噗通/扑通/铛铛铛/铛/嗦独占行时不加标点。不可混用噗通（暗杀）与扑通（非暗杀）。
6. **怪物鉴定红线**：首次遭遇新怪物类型必弹怪物鉴定面板。同类怪物后续不重复弹（变种/精英/首领除外）。
7. **技能命名红线**：凡人期终结技命名格式为"剑势【XX】"，用破折号引出。不得使用超凡期的"奥义""领域""神技"等命名。
