# 战斗表现 · 凡人期-敏捷系（执行配方卡 v4.2.0）

> **这是操作手册，不是理念文档。** 面向 write 层（多为轻量模型）。你只要照着下面【第0步→第7步】的顺序填空，就能产出合格战斗章。看懂理念不如照做流程。
> **开工前必读（按顺序）**：①先读这个文件 → ②再用 Read 读合格样板《夜袭营地》→ ③动笔。样板就是"合格长什么样"的唯一基准，对照它写，别自己发挥。

## 第0步：填四问（3分钟，不填不写正文）

动手写正文前，先在草稿写下这四句——正文里不出现，只用于约束你自己。

| 问 | 你要填空 |
|:--|:--|
| 战斗功能 | 打完后____变了（成长/夺物/暴露/信息/危机/关系，选1个写进结尾钩子） |
| 双方目标 | 主角要____，敌方要____（两边目标要不一样，禁止都是"杀光对方"） |
| 胜负条件 | ____发生=主角赢；____发生=主角输（拖太久被围/资源耗尽/大部队赶到，三选一） |
| 信息差 | 读者知道____但____不知道，在第____拍揭示（制造紧绷/爽感/意外） |

## 第1步：战前铺垫（写开篇100-200字）

**必做其一**（二选一，都能用）：
- 暗杀战→写**敌方视角短铺垫**：敌方对话（收了钱退无可回）→环境转场→落单。主角出场前不露面。
- 遭遇战→主角**胜算内心算账**：看清敌人数量/装备/职业，判断"能打还是该撤"，用引号写判断（例：`"要速战，先断那两个弩手的指头。"`）。

**禁止**：战中才想起来算账；主角一上来就"怒吼一声冲上去"。

## 第2步：出手（1-2拍，打核心敌人）

- **出手前必有拟声或动作先兆**，再写致命一击。致命一击必须写**落点**（打哪），而且要讲得通：打"护甲盖不住的缝""骨缝""咽喉下颔缝""颈侧动脉"，别只写"他刺出一刀"。
- 敏捷系三选二：①**无限制**（现场抓道具：勾砖砸手/踢凳/拿尸体挡箭）②**毒**（淬毒武器/弩可，中毒者要有反应）③**环境**（借地形/阴影/借力）。
- **打斗时长为短**：正面交锋压缩在几十秒内（例"短短三十秒"）。盗贼绝不打持久战——一察觉拖久了，立刻安排转折结尾。

## 第3步：弹面板（格式硬约束，照抄不要改）

第一杀用面板结算。**格式唯一，无第二写法**：
- 每行 = **引号 + 一句 + 感叹号**。禁止用【】包裹（【】只给物品/专长描述用）。
- 标准顺序（5行，照抄顺序）：
  ```
  "技能名成功！"
  "背刺发动！"
  "成功发动背刺*2，对目标造成XX点伤害！"
  "目标死亡！"
  "抽取目标灵魂能量，获得杀戮经验XX点。"
  ```
- **拟声在前，面板在后**（先"噗通"倒地，再出面板）。禁止面板先于声音。

**面板后必须紧跟一段"为什么能赢"的解释**（秒杀不是运气，是算术）：
> 例（照这结构写）："一个普通的打手，生命也就五六点。背刺翻倍的十四点伤害，奔着咽喉去，本就是一击了账。"——写清"伤害值 > 敌方生命值"这层算账。

## 第4步：续战（1-2拍，第二位敌人/转折）

- **同类连杀只弹一次面板**：第二个敌人非挂不可就用**叙述带过**（"顺势一刀补了"），不再弹第二块面板。
- **每占便宜必挨一下**：主角得手后，必须挨一次还击（被刮到/被扑/被迫脱手一件），写一处小伤。
- 可在一章内升级（只用一次，做转折）。

## 第5步：转折与收尾（决定"会不会死、怎么脱身"）

- 设置**倒计时或增援**制造压力（敌方增援脚步声/逐迫近/毒效将尽），逼主角**速战速决或撤退**。
- 主角要显**判断力**：识破陷阱/判断"这斧子太重拿不动"级取舍/选定逃跑路径。禁止无脑莽。
- 撤退用"借阴影/攀墙/滚落"，撤退后**听身后声渐远**再停下。

## 第6步：战后结算（收获与损失两栏必须同时写）

**收获至少写3样**：杀戮经验（数值要自洽：打手30/骷髅45/战士270/强敌数百）＋钱/物（翻尸清单，写具体物名）＋剩一样（技能成长/声望称号/情报/新线索，选1）。

**损失至少写3样**，且每一种都要"有代价地写"：
- **伤**：写明部位+程度+处理动作（"勒紧止血，天亮前得重新包"），伤要带到章末甚至下章。
- **耗材**：毒少了一份/弩失了一支/匕首丢了/皮甲划了两道（写具体数量）。
- **暴露/隐患**：目击者/验尸发现刀切口/诨名开始被传/树了未知的敌（这条就是要埋进结尾钩子）。

## 第7步：收束三段 + 结尾钩子（写最后100-150字）

1. **收刀仪式**：一个动作+一句气（例：`铿锵。收刀入鞘，长吐一口浊气，开始缠伤口。`）
2. **生活流切换**：从血战切到烟火气（澡堂/吃面/店家笑骂/晨光），形成反差。
3. **结尾钩子**：收口在"下一步/隐患/未解之谜"，必须让读者想知道下章（例：掌心里那枚铜牌烙着花押——"原来是他"）。**禁止平淡收尾**。

## 词汇对照表（防越线，逐词对照，不用算比例）

| 你写的词 | 判定 | 换成 |
|:--|:--|:--|
| 打/刺入咽喉/划开颈侧 | ✅西幻可用 | —— |
| 弩矢/皮甲/弯刀/匕首/军用刀路/职业者/淬毒 | ✅西幻可用 | —— |
| 背刺/面板/生命值/杀戮经验/挑战等级/经验 | ✅游戏化可用 | —— |
| **欺身/贴身/虚晃一引/借力卸力/侧步** | ⚠️高危 | 改为"逼近/错开/擦过/侧移/借地形" |
| **掌心一翻/剑走偏锋/凌空/残影/罡气** | ❌武侠词，禁止 | 删掉，改用"侧身避过""刀锋擦过" |
| **闪转腾挪/身法/真气/内劲** | ❌武侠词，禁止 | 删掉，用"脚步一错""侧滑半步" |

> 一句话规则：**只写"手怎么动、刀往哪、打哪个缝"，不写"气势/内劲/身法"这些玄词。** 宁可平实，不可武学。

## 面板格式速查（复制改数值即可）

| 场景 | 行数 | 末行写法 |
|:--|:--|:--|
| 秒杀（暗杀） | 5 | "抽取目标灵魂能量，获得杀戮经验XX点。" |
| 未秒杀 | 4 | "目标严重受伤！" |
| 战中升级 | 3-4 | 带成长公式，如"敏捷值20+（智力18-10）\*0.5" |
| 战后总结 | 3 | "呆板（腾挪）+1，规避（翻滚）+2……" |
| 怪物首遇鉴定 | 6 | "挑战难度：C+。"（动手前弹） |
| 物品/专长 | 描述式 | 用【】，如"【命中+3、伤害+3、攻击速度+1】" |

## 红线（写完逐条自查，全过才交付）

1. **本质三件套齐**：技艺（落点/侧移/借地形）＋无限制（道具/毒/环境）＋战术心账（算能不能打）。纯对砍=废。
2. **盗贼不打持久战**：正面交锋几十秒内；拖久立刻设转折。
3. **不算账不动手**：出手前内心有一句判断。禁"怒吼冲上去"。
4. **禁光污染**：视觉只允许 寒光/血/阴影/营火，禁可怖能量颜色。
5. **环境破坏只局部**：凹坑/血渗地/碎骨可以，禁拆楼拆街。
6. **拟声在前面板在后**，面板后紧跟解释段。
7. **同类连杀一次面板**；升级一章一次。
8. **收获必有损失**：两栏各≥3项，收支同落账，禁止只记收获。
9. 视觉/词汇按上面对照表，**禁止"身法/真气"等玄词**。
10. **结尾必须有钩子**：收在未知数上，禁止"一切都好"白开水收尾。
