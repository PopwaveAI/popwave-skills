# 战斗表现 · 通用层

> 赛道级参考答案——机制与结构源自赛道标杆源书全书拆解，专有名已槽位化、章锚点已剥离。新书 write 渲染战斗章时**抄机制、抄结构、抄颗粒度，不抄事件与专有名**；名词层以《赛道特色/名词表.md》为唯一真源。

> **消费顺序**：本文件（每战必读——定等级段+三段流+笔法+红线）→ 按等级段加载《{等级段}/战斗模式-{等级段}》（模式/面板/数值锚全集）→ 敏捷系主角凡人期加读《凡人期/敏捷系》执行配方卡（照单施工版）→ 按需叠加：《特殊条件战》（盲战/追逃/围城/水下/多武器/陷阱）、《面板叙事》（面板意识流与特殊面板全集）、《数据化分析》（怪物鉴定/体感反推/伤害类型）、《多线叙事》（POV切换/世界级事件）、《场景卡》（25种场景公式速查）。世界级规则读 `../战斗系统.md`；阶位定义读 `../力量体系.md`。
> **职业系边界（消费前必读）**：战斗模式件从标杆书主角（**敏捷型盗贼/刺客**）蒸馏——覆盖敏捷性战士/盗贼/刺客（超凡期起含法术混合，仍以敏捷系为骨架）。跨职业复用=本文件全部+各模式件的面板格式框架/句式节奏/拟声词/数值规模。**武僧（拳法/气）、法师（施法系）、灵能/心灵系：当前无专属配方卡（扩展位）**——禁止敏捷系模式换皮套用（背刺/潜行游击对拳法家与心灵术士不成立），须按本文件三段流骨架另行推导，路径见使用手册「战斗表现职业路线图」。
> **三段流总纲**：一场战斗的写法=**战前（填图纸）→战中（用笔法）→战后（收结算）**。通用层给跨职业三段流；等级段模式件给对应段的专属模式/面板/句式/数值。

## 〇 阶位定位（先定段，再动笔）

等级段不按本职等级数字划分，按**力量体系三质变点**锚定（传奇进阶=凡人→超凡，封神=超凡→神明）。写战斗章第一步：对照下表锁定所在段。

| 等级段 | 阶位锚（对齐力量体系·本职等级参考） | 战斗规模 | 面板复杂度 | 画风一句话 | 与下一段分界线 |
|:--|:--|:--|:--|:--|:--|
| **凡人期** | 一阶→高阶职业者（1–6阶，1–14级），**传奇进阶前** | 1v1/小队（≤5人）；街头/地窖/荒野 | 5–8字段，纯数值结算 | 冷硬写实的街头盗贼流——数值小、面板直给、一击定生死 | 未完成传奇进阶：无【传奇生命】，无传奇专长，无跨位面能力 |
| **超凡期** | 传奇职业者→半神→伪神（7–9阶+神性累积，15–25级），**封神前** | 军团/弑神/跨位面 | 10+字段：超魔代价+技能参数【】+弑神数据链 | 免疫链与规则对抗的碾压美学——伤害类型分离，多POV | 未完成封神仪式：无完整神职，神力循环未成 |
| **神明级** | 真神（神力五档：微弱→弱等→中等→强大→伟大，25级+），**封神后** | 神系vs神系/位面级战争 | 三资源条（神性/神格/神力）+叙事化描述 | 位面尺度的法则对撞史诗——不写搏斗写结构崩坏 | —（伟大神力=顶点） |

**三阶差异速记**（防串段，其余维度差异按落点查）：伤害描写凡人模糊单一→超凡类型分离+免疫百分比→神明神力结算+法则变化｜击杀收益凡人仅经验→超凡+神性/神格/专长（弑神数据链）→神明神职四连暴涨｜叙事视角凡人全主角→超凡每3章≥1次非主角POV→神明必须有非主角POV｜环境互动凡人局部形变→超凡区域破坏→神明地图级｜风险机制凡人负伤即致命→超凡+掉级风险→神明神职责任/属下真陨落（3.2节）。

## 一 战前（动笔前：填图纸，不填不动笔）

> 六要素是笔法，规划是图纸。没有图纸的笔法=写得好看的空壳——读者看战斗看的是"谁在算计谁、谁先撑不住、什么时候翻盘、打完得到了什么"。

### 1.1 战前四问

| # | 问 | 填法 |
|:--|:--|:--|
| 1 | 战斗功能 | 一句话——"打完后，____变了"（成长突破/获取资源/暴露身份/关系改变/信息揭示/制造危机/余波消化） |
| 2 | 双方目标 | 主角想____（不只赢：拖延/夺物/保护/逼供/逃跑），敌方想____（不只杀：吞噬/封印/试探/驱赶）——目标错位=张力来源 |
| 3 | 胜负条件 | ____发生=主角赢，____发生=主角输（资源先耗尽/核心被破坏/时限到达/对方撤退）。禁"谁强谁赢" |
| 4 | 信息差布局 | 读者知道____但____不知道，第____拍揭示，制造____效果（揪心/爽感/意外/恐惧） |

### 1.2 战中四编排（动笔前一并填好，战中照图施工）

| # | 编排 | 填法 |
|:--|:--|:--|
| 5 | 攻防节奏 | ____先手，____轮交锋，第____拍高潮。先手可以是"等待"——蓄力本身是第一拍 |
| 6 | 代价递进 | 第1轮____→第2轮____→转折____（资源消耗→装备损伤→身体伤害→认知污染→失控反噬，选3–5级） |
| 7 | 转折点 | 第____拍，____触发（找到弱点/突破极限/敌方失误/外部介入/金手指激活），局势从____变为____ |
| 8 | 读者情绪曲线 | 第1拍____→第2拍____→第3拍____→收尾____（全程一个情绪=疲劳或无聊） |

### 1.3 战斗类型速查

| 类型 | 核心维度 | 规划要点 |
|:--|:--|:--|
| 消耗战 | 代价递进 | 谁先撑不住；转折=资源耗尽或找到弱点 |
| 碾压局 | 转折点 | 碾压中的变数（失控/时限/误伤/反噬）；碾压在转折拍不在第一拍 |
| 暗杀/偷袭 | 攻防节奏 | 核心是时机——准备→等待→一击；2–3拍 |
| 遭遇战 | 双方目标 | 核心是适应——互相试探找弱点或暴露弱点 |
| 智斗/博弈 | 信息差布局 | 信息就是武器；转折=关键信息揭示、攻守转换 |
| 防守/生存 | 胜负条件 | 核心是撑住而非赢；转折=救援到达/时限结束/敌方撤退 |

**4拍节奏全程通用**（具体化见战斗系统·分阶战斗形态表）：试探（摸底/信息差预判）→对抗（攻防交换/底牌轮替）→转折（变数出现）→收尾（收割+结算+代价清偿）。**碾压局同样走完整4拍，禁"一招定胜负"**。

### 1.4 标杆局拆解示例（卷一末伪神围剿局·碾压局范本）

- **四问填法**：功能=暴露底牌厚度+收尾拍揭示神力储存规则；双方目标=主角杀神子夺神性 vs 神子完成封神活祭（仪式=天然时限装置）；胜负=仪式完成主角输，中断+击杀主角赢
- **4拍**：试探（伪装祭司混入）→对抗（底牌轮替尽出）→转折（专长厚度+神器翻盘）→收尾（吸收神力储存失败——碾压的代价在收尾拍结算规则）
- **要点**：微弱神力的神子也让主角"底牌尽出才能取胜"——碾压局同样走完整过程，标杆书全程无"一招定胜负"

## 二 战中（落笔时：笔法底线）

### 2.1 战斗六要素（每场战斗的笔法底线）

| 要素 | 差 | 好 | 本赛道（DND面板流）适配 |
|:--|:--|:--|:--|
| **动作** | 事件级——一个词概括整个动作（"放出""拍散"） | 姿态级——拆到"手怎么动"（格挡到关节级/施法到动作级） | 技能名不得替代动作：先动作（侧身一步，匕首沿着长剑的剑身滑下，直刺手腕）→再技能名（——背刺！）→后效果（匕首没入腰侧） |
| **招式命名** | 报幕式——招式名是主体，动作被省略 | 嵌入式——动作是主体，招式名是标签 | 技能用破折号引出："——剑势【重劈】！"；面板用【】内联意识流数据流 |
| **画面表达** | 色彩标签——只有颜色没有形状/轨迹/动态 | 画面精确——色彩+形状+轨迹+动态≥2个维度 | 伤害带类型质感：劈斩（断面/骨头碎裂）、暗影（沿武器渗透侵蚀）、火焰（灼烧/汽化） |
| **内心波动** | 标签式——"心头一凛""瞳孔一缩" | 判断式——具体判断/推理/计算 | 本赛道招牌：**体感反推属性**三连——"仅仅是这一击，他的手臂就开始发麻。力量16点以上。正面对抗毫无胜算，他必须闪避。" |
| **路人捧场** | 无旁观者，只有两人对打 | 旁观者生理反应放大战斗分量 | 每场≥1次：按住武器/手抖/倒吸凉气/后退；面板流加分位——旁观者看不到面板，用"他居然……"式震惊侧写数值差 |
| **环境影响** | 打完环境完好无损 | 破坏匹配战斗等级，形变有具体形状 | 按段匹配（见〇节环境互动行）：凡人期局部形变→超凡期区域破坏→神明级地图级 |

### 2.2 面板总则（跨职业跨等级）

1. **意识流内联**：面板以意识流数据流嵌入叙述，【】内联格式；禁弹窗/光屏/全息投影，禁markdown代码块。
2. **弹出时机**：技能结算/击杀/升级/首遇鉴定四类节点弹，纯动作交换不弹（类型明细见3.1）；每次击杀必弹（例外：协作伏击、潜行vs潜行）。
3. **复杂度对段**：凡人期5–8字段直给；超凡期10+字段+技能参数【200米】式量化；神明级三资源条同屏+叙事性描述。
4. **数值对段**：数值规模匹配等级段（区间锚见各模式件）——凡人期伤害≤99、杀戮经验≤200。
5. **参照物锚定**：属性数值弹出必须同章内锚定（直接/比较/体感三式），同一参照物跨章间隔≥3章。

### 2.3 拟声词基础表（跨职业通用）

| 拟声词 | 用途 | 独占行 |
|:--|:--|:--|
| 噗通 | 尸体倒地（**专用于暗杀**） | 是 |
| 扑通 | 尸体倒地（非暗杀，与噗通不可混用） | 是 |
| 铛铛铛 | 三连格挡（无"铛铛"双连用法） | 是 |
| 铛 | 单次格挡 | 是 |
| 铿锵 | 武器出鞘/切换 | 否 |
| 嗦 | 箭矢破空（远程） | 是 |
| 噗嗤 | 利器刺入肉体 | 否 |
| 砰/砰砰砰 | 撞击（围攻/重武器砸地） | 否 |

规则：独占行不加标点；同一段战斗同一拟声词≤2次，第3次起用动作描写替代。各等级段专属拟声词见对应模式件。

### 2.4 句式节奏型（5种公式，跨职业框架）

| 节奏型 | 公式 | 节奏感 |
|:--|:--|:--|
| 暗杀型 | 极短句（3–5字）×2–3 → 面板 → 拟声词独占行 → 解释性长句×1–2 | 快-停-快 |
| 正面交锋型 | 拟声词独占行 → 动作句（15–25字）→ 属性判断/战术旁白×1–2 → 反击短句 | 稳-稳-快 |
| 技能爆发型 | 压力铺垫（中长句×2–4）→"——技能名！"极短句 → 身体内部（中句×1–2）→ 动作链（短句×3–4）→ 视觉冲击 → 面板 | 慢-爆-快-收 |
| 游斗型 | 拟声词 → 极简概括1句 → 属性差距1句 → 一笔带过结果1句 | 快-快-止 |
| 协作型 | A行动2句 → B行动2句 → 循环（"嗦"区分远程角色） | 交替-交替 |

## 三 战后（收尾时：结算+余波）

### 3.1 面板类型速查（何时弹什么）

| 场景 | 面板类型 | 弹出规则 |
|:--|:--|:--|
| 击杀成功 | 击杀面板（伤害结算+杀戮经验） | 必弹；格式见对应等级段模式件 |
| 技能失败 | 失败面板（debuff："斩首失败！目标进入流血状态"） | 失败是张力来源，不要每发必中 |
| 职业/技能升级 | 升级面板（属性公式+自由点+新专长） | 升级当场弹 |
| 首遇新敌 | 怪物鉴定（种族【】/阶位（）/CR/专长/难度字母） | 首遇必弹；同类不重复，变种/精英除外 |
| 训练/高强度战后 | 战后总结面板（技能成长明细） | 训练战/大战后弹，杂兵战不弹 |

### 3.2 伤势处理规则（按段分级）

- **凡人期**：负伤即致命——具体伤口（位置+长度/深度）必写，禁中途自愈；治疗资源稀缺，战后写伤势处理；游击消耗战主角带1处可见伤到战斗结束。
- **超凡期**：可用法术/神性恢复，但必须消耗对应资源（法术位/神力值）——恢复=资源换血，禁无代价愈合；掉级风险是本段独有悬念。
- **神明级**：神力值即血条——战后结算神力余量+信仰产出恢复速度；属下（祈并者/英灵/圣灵/神侍）战死=真陨落——碾压的代价在收尾拍结算。

### 3.3 战后余波三件套（打完≠结束）

1. **善后动作**：翻尸搜刮一笔带过（暗杀流）/战利品清点（高阶战）/声望与传闻扩散。
2. **代价清偿**：伤势延续到下一章、资源缺口记录、暴露身份的连锁反应（帮派报复/成为诸神公敌/神职责任）。
3. **钩子埋设**：击杀收益中的异常项（"部分被未知目标抽取"式悬念）、新线索、下一场战斗的引信——收尾拍同时是下一拍的开场。

**写后自检**：动作姿态级？招式名嵌入动作链？感官≥2维度？内心是判断？旁观者≥1次生理反应？环境破坏对段？击杀弹面板？伤势没中途自愈？余波三件套齐？

## 四 红线

1. **等级段红线**：三段战斗模式与面板格式不得混用——凡人期禁多段连击面板/领域面板；神明级必含概念级对抗（只写神力对轰不写法则干涉=不合格）。
2. **模式去重红线**：连续3章禁用同一种战斗模式（含子类型），第4章必须切换。
3. **击杀面板红线**：每次击杀必弹面板。例外：协作伏击、潜行vs潜行。
4. **面板意识流红线**：意识流内联【】，禁弹窗/光屏/全息投影，禁markdown代码块。
5. **数值规模红线**：数值匹配等级段——凡人期伤害≤99、杀戮经验≤200；神明级三资源条同屏。
6. **参照物锚定红线**：属性弹出同章内锚定；同一参照物跨章间隔≥3章。
7. **受伤持续性红线**：游击消耗战伤势持续到战后，禁中途自愈。
8. **POV红线**：超凡期每3章≥1次非主角视角；神明级全程只有主角POV=不合格。
9. **拟声词红线**：独占行不加标点；噗通（暗杀）/扑通（非暗杀）不可混用；同段同词≤2次。
10. **特殊条件红线**：特殊条件必须影响节奏和描写方式；盲战禁视觉描写；利用陷阱必须提前铺垫。
11. **职业系红线**：敏捷系模式件只适用于敏捷性战士/盗贼/刺客主角；武僧/法师/灵能系禁换皮套用，按通用层三段流骨架另行推导。
