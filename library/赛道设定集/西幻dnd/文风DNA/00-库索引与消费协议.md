# 文风DNA库 · 西幻dnd

> **定位**：本库 = 赛道的「**笔触形态层**」（怎么写），与 `赛道特色/`（内容风味层：写什么词）**并列**，各司其职。
> **形态**：一个**共享笔触组件库，跨赛道/跨书按需采用**——不复制整份DNA进每书，而是三层组件按章取材。本书/本品由 write 取本库组件即时渲染。
> **铁律**：只学笔触不学内容——本库不承载名词表/类型门禁（那些在 `赛道特色/`）；否则 write 学句式会被内容带偏。

---

## 一、三层结构（库即组件池，按需采用）

| 层 | 内容 | 货源 | 本节落地状态 |
|:--|:--|:--|:--|
| **1·通用笔触基底** | 跨书复用的句式/感官/叙事距离/段落呼吸/对话方式（三段式维度） | 从赛道标杆源书每段蒸馏；可向上提升为跨赛道通用件 | ✅ 首件已产：`通用笔触基底/深渊主宰-通用笔触基底.md`（10操作特征+完整段落+5反面教材，源出DNA-AB测试胜出版）；后续按书扩充 |
| **2·场景卡分档** | 战斗/对话/描写/叙述四类场景公式，按**事件分量分档**（交锋/大战/决死三层密度） | 现有 `战斗表现/场景卡.md`（25种公式）+ 叠加层 | ✅ 存量挂接（见下节） |
| **3·卷级演变曲线** | 卷内笔触强度爬坡脚本（遭遇战碎段快杀→决死战长句铺陈） | 每卷开始时由 plot/本项目卷纲标定 | ⏳ 按卷现订 |

> 加载顺序按层：**1笔触基底 → 2场景卡分档 → 3卷级演变**，最后过 5章滑窗去重（见第四节）。
> 落地优先级（老板定令）：**防线1（卷级演变）+ 防线3（5章滑窗）先上、成本低、对长更防重复最直接**；防线2（场景卡分档细化）待战斗集多后再补。

## 三、组件格式（三段式，每个笔触维度/场景卡唯一格式）

| 要素 | 作用 | 形式 |
|:--|:--|:--|
| **操作特征** | 条件式指令（何时启用→写什么→写多长→边界） | 可执行动词，禁"营造/巧妙/让读者"评价词 |
| **完整段落** | 段落内技法组合示范（不切碎） | 1-3段真实原文 blockquote |
| **反面教材** | AI味护栏（功能级禁则+病句族+原书替代） | 禁点破后文/数据文学化包裹/情绪直述/能力科普 |

> AB测试实证：碎片化垫底，完整段落+反面教材凭1/7输入超越原文直灌。凡缺任一要素=组件无效。协议全文明细见 `library/写作素材和技巧/文风DNA槽位协议.md`。

## 四、write 消费协议（按需采用 + 防长更重复）

write 渲染一章时，按序：

1. **笔触基底**：取本章命中场景卡的三段式笔触（操作特征+完整段落+反面教材）。首件：`通用笔触基底/深渊主宰-通用笔触基底.md`。
2. **场景卡分档**：按本章事件分量（交锋/大战/决死）选对应档密度；主骨架场景公式每章1种。
3. **卷级演变**：读本卷演变曲线，定本章笔触强度档（卷首低烈度→卷末决死高潮爬坡）。
4. **5章滑窗去重**：回看最近5章已启用的笔触特征（相类喻体/独句段重击/数据句式/场景公式），高频者本章自动规避，强制换气。

**加载优先级**：笔触基底=第一优先级（10万字裁剪不裁）。

## 五、门禁

| 检查项 | 标准 | 不合格处理 |
|:--|:--|:--|
| 并列归属 | 文风DNA/ 与 赛道特色/ 平级，不互相吞并 | 调整位置 |
| 只学笔触不学内容 | 无名词表/类型门禁混入本库 | 移出到赛道特色 |
| 三段式完整 | 每新增维度/场景卡含操作特征+完整段落+反面教材 | 补全缺失段 |
| 存量挂接 | 战斗表现/ 在索引映射中登记归属 | 补登记 |
