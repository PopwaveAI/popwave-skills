# 命名规则 · 西幻DND赛道

> 用法：所有专有名（人名/地名/神名/组织名）按本规则生成；示例库可直接取用。

## 1 总原则

1. **音译感**：念起来像从某种西方语言音译过来的（拼写可回推英文感）；
2. **禁中式**：无姓氏宗族感、无「XX子/老X/阿X」式；
3. **禁日式直译**：无「XX酱/XX君/五十铃式音节堆砌」；
4. **撞名检查**：新名诞生必过检查表（见§7）。

## 2 音节构件表（构词原料）

| 类别 | 常用构件 |
|:--|:--|
| 男名首音 | 艾-/阿-/巴-/德-/格-/凯-/莱-/罗-/莫-/瑞-/塞-/瓦- |
| 男名尾音 | -德/-恩/-兰/-里克/-特/-斯/-顿/-文/-德鲁/-斯坦 |

| 专名构件 | 灰/风/铁/白/金/暗/银 + 鸥/鸦/狼/鹿/棘/灯/哨 |

## 3 人名三层

- **平民**：单名（如：科尔/哈罗德/薇拉）；
- **有身份者**：名+姓（如：塞德里克·凡恩海姆）；
- **强者/神眷者**：名+尊号（如：「白鸦」赛琳 / 断刃者·凯登）——外号走「标志物/事迹+者」结构。

## 4 神名（神职尊号式）

- 主格式：**职能+头衔**——死亡之主 / 月冕女士 / 星辉夫人 / 潮汐之母 / 破晓之刃；
- 真名讳称：可给古神起单名讳（如：欧格 / 姆恩式短音节），但日常称呼一律用尊号；
- 禁止：起与知名神话/游戏神明同名或近音的名（如奥丁/宙斯/巴哈姆特等官方名号）。

## 5 地名构词法

- **主格式：专名+通名**——灰鸥港 / 风哨堡 / 落雨城 / 毒棘沼 / 白鹿城 / 铁砧镇；
- 通名从《名词表.md》§9取；专名优先「颜色/物候/物象+生物/器物」组合；
- 位面名固定用通用译名（星界/深渊/九层地狱等），不自造位面名。

## 6 组织命名

- **机构后缀制**：贸易商会 / 佣兵公会 / 女巫议会 / 银誓骑士团 / 暗火教团 / 巫师联盟；
- 前缀走「颜色/金属/天象/品德」词（银誓/暗火/灰鹰/晨曦/暴风）。

## 7 撞名检查表（新名必过）

1. 念三遍，有没有中式语感/日式直译腔？
2. 是否与《指环王》《冰与火之歌》《DND官方角色》《哈利波特》等知名IP角色/地名撞名或近音？
3. 是否与本赛道知识库内其他书的人物名重复（防串味）？
4. 神名是否带尊号？地名是否带通名？组织是否带机构后缀？（三带齐=格式合格）
