# 规则总账 · 泛都市修仙赛道（赛道百科·规则篇）

> 赛道级参考答案——机制与结构源自赛道标杆源书全书拆解，专有名已槽位化、章锚点已剥离。新书 world 展开对应维度时**抄机制、抄结构、抄颗粒度，不抄事件与专有名**；名词层以《赛道特色/名词表.md》为唯一真源。
> 七类规则是各维度公共输入的规则总账，每条回溯五设计原则（定义见《总纲.md》第五节）：**原则1** 大事件供给猎物 · **原则2** 地图随境界解锁 · **原则3** 境界数值量化 · **原则4** 重生与仙力双限 · **原则5** 名利=围猎引子。
> **空间类型判定**：**叠加双轨**（凡俗烟火轨+隐世修仙轨纵向叠加、共享同一片山河）——先按双轨处理，再定各轨规则；空间结构全景见《总纲.md》第一节，本件只收规则细则。

## 一 · 规则总账表（六类规则）

| 规则类型 | 规则内容 | 回溯原则 |
|:--|:--|:--|
| **双轨物理** | 凡俗轨=现代华国物理（热兵器/资本/权力）；隐世轨=灵气（近枯竭）+宗门/洞天；交界=武林武者（数值爬坡到仙人门槛）。凡俗只见凡俗，修士洞天藏于市井（隐匿术法/洞天结界） | 原则2/3 |
| **双轨物理** | **灵气规则**：灵气近枯竭的末法——灵气像水哪里低流到哪里，低洼灵气汇聚=洞天福地灵地；单日可抽灵气有上限；灵气强度决定能修多深；天材地宝/药材/灵石可补足；煞气阴气等宇宙能量要专门法门提取 | 原则2/4 |
| **超凡法则** | 修仙=境界（炼气筑基…大乘）+真元+法术神通法器；武者=内劲（明劲暗劲化劲）+罡气（先天武者/抱丹宗师）。倒挂看得见：灵根/境界/战力（战机）倍数；力量=战力的物化，可数值化（灵气强度/境界差/肉身之力·千斤→一蹦几米高→一拳穿钢板） | 原则3 |
| **超凡法则** | **凡人→修士**：未得灵气法门者只是凡人（枪械能杀炼气/先天）；得机缘/师承/灵脉/丹药才入修士界；末法时代修士稀少（地球唯一修仙者级的稀缺） | 原则4 |
| **战斗规则** | **境界差碾压**：跨一境3-5倍战力差，跨两境以上碾压实锤；炼气初=武者明劲/暗劲高手，炼气圆满=化劲/先天武者大宗师，筑基=凌驾抱丹宗师之上（一域霸主），金丹=武道神话/隐世长老 | 原则3 |
| **战斗规则** | 战斗落点在装逼打脸：对手叫嚣→蓄压→一记碾压→围观者倒吸凉气（观众反应即爽感）；拳印留在柳树/打穿钢板/飞出数米白练=异象钩子 | 原则3/4 |
| **攀登规则** | **双轨攀登**：修仙境炼气（筑基/通玄/神海）→先天→金丹→元婴→化神→虚神→渡劫→大乘；武者境明劲→暗劲→化劲→先天武者→抱丹宗师。每阶修到圆满=同阶无敌（无上道基），是主角「一步一个脚印」的独有优势 | 原则3/4 |
| **攀登规则** | **重生双限**：①前世记忆有盲区（当前境界记忆不全/当世情报错漏）②仙力有上限与代价（末法不可无限抽灵气/冲境耗耗药材灵石重资/过度显露被火并——枪械能杀凡修） | 原则4 |
| **攀登规则** | 冲境仪式：大境界需天材地宝+夺灵阵+心魔/雷劫淬形；灵气枯竭的痛点在「境界越高越难&越贵」 | 原则3 |
| **攀登规则** | **标准天花板**：末法上限颇低——地球这环境正常修士最多修到先天；主角凭「无上道基+前世记忆」可三年内突破先天计划、向更高境界冲击 | 原则4/5 |
| **危机规则** | **仙凡相撞（时代引擎）**：重生者归来+隐世与都市势力在烟火中交织；动静渐大的武道大会/宗门大比/隐世浮现改写格局 | 原则1 |
| **危机规则** | **身份暴露风险**：越展露越被火并/被豪门争抢/被宗门招揽（够大者视为「可利用战力」）——藏锋低调是最优策略，但很大爽点也由暴露而来 | 原则5 |
| **原生威胁规则** | 同城武者/世家/商界对手（都市层）；隐世宗门/魔修（隐世层）；海外凶险秘境（终局）——按地图卷位解锁投放 | 原则1/2 |
| **博弈规则** | 世家豪门供奉修士=凡俗资本换修士武力/丹药/护身；武道大会/宗门大比=公开角力场（名利即围猎引子）；魔修血祭/夺舍=反派路径 | 原则1/5 |
| **博弈规则** | **热兵器制衡**：枪械可杀炼气/先天层凡修；导弹高端为设定上限兜底；高境界修士弹指碎星为终极对照——早期主角对热兵器/权力需恪守敬畏（防无脑碾压） | 原则4 |
| **博弈规则** | **道基规则**：主角前世因「修行太快根基不稳+道心心魔」陨落——今生重修以「一步一个脚印、把每个境界修到最圆满」为最硬因果锚（也是情感因果/爽点基石） | 原则1/4 |
