# 都市修仙赛道元素卡（重生之都市修仙 三档）

> 定位：都市修仙（重生归来×装逼打脸×都市烟火日常×位阶差碾压）赛道。本卡 v0.2.0 在 v0.1.0 基础上整合**开局/推进/高潮三档共70块**采样，为赛道特有素材卡。**打脸族、都市日常族已在通用元素卡库（10族54卡）**抽象，本卡记录「装逼打脸流」完整触发链、「修仙×都市双轨」位阶反差写法，以及推进/高潮档新增的「商业战/势力合谋/位阶差碾压仙域战」特有块。
> 关键结构变化：**都市烟火日常族在推进/开局活跃、高潮档退场**，舞台后期整体迁入仙域天荒界——建包/写后期时不得滥用都市日常块。

## 二、赛道特有块（打脸族/都市日常族触发链 + 推进/高潮独有块）

> 本节统一放都市修仙赛道的**赛道特有块**，按 v3 卡结构（适用/节拍序列[拍名-拍义-填法标准]/写法要点/线效果/源书）给出。打脸族、都市日常族已在通用卡库抽象（此处为赛道编排走法）；商业战/势力合谋、位阶差碾压仙域战、渡劫升维为推进/高潮档新增独有块。

### 2.1 装逼打脸三连发（打脸族赛道触发链）

**适用**：前中期（开局最浓，中段演化为"威名震慑/势利臣服"反向打脸）。

> 都市修仙最核心的结构指纹：一场打脸被拆成「轻视蓄压→挑衅蓄压→打脸反转」三段式逐级加压，爽点在反转兑现。ch002-004姜家轻视三连发完整示范。
> ⚠️ 本块为「打脸族」的赛道完整触发链版本（通用卡库打脸族3卡：轻视蓄压/挑衅蓄压/打脸反转），此处展示其在本赛道的编排走法，非新块。

**节拍序列**（三段，拉满全卷）：
1. **轻视蓄压** — 白富美/长辈「看不上」判定：初见外貌家境学历评断+「配不上」「普通朋友」诛心语（姜初然评「最多清秀，全身不过一千」）
2. **挑衅蓄压** — 主动挑衅/试探：长辈审视「学历敲门砖」+同龄人参照系（李易晨对比）+「你配不上我女儿」
3. **打脸反转** — 关键兑现：主角以真实身份/实力/预知掀桌（修炼兑现/身份暴露/商战翻盘），围观从轻视到哗然

**写法要点**：轻视必须「双源布局」（家人+外人、主角知读者知）；蓄压期主角「淡然无感」制造反差（「他眼中无足轻重」）；打脸靠「位阶差碾压」兑现（修仙者vs凡人），围观表情蒙太奇；每段都有「诛心语」供反转时回收打脸。
**线效果**：打脸蓄压线（轻视→挑衅→反转）｜重生复仇线（仇敌名单慢烧）｜档案线（楚州生态）
**源书**：都市修仙ch002初见+ch003拜访/ch004打发（轻视三连发）+ch005冲突（演技挑衅）

### 2.2 都市烟火日常（重生落地感）

**适用**：**前中期**。⚠️ **高潮档（ch1000-1004）零块出现，舞台迁入仙域天荒界——不得在后期滥用此块**（本赛道最重要阶段边界）。

> 都市修仙区别于其他修仙赛道的质感骨架：把死板置换成生活的「重生落地」——看房/家宴/采购/城市生态四类，承担"读者相信主角真的重生了"功能。
> ⚠️ 通用卡库「都市日常族」（4卡：看房/城市生态/家庭饭局/日常采购）即由本赛道提炼；此处记录其赛道编排走法。

**节拍序列**（4拍，穿插入主线）：
1. **重生落地** — 初见现代生活物件/城市的质感重构（大巴/手机/房价/早餐摊），「他五百年来第一次」视角
2. **恩人暖源** — 都市中唯一暖源照拂落地（租房/家宴/药房），立主角报答承诺
3. **烟火对照** — 市井物价/房价/人情世故与前世记忆对照（曹州房价7000/龙景花园几千万），慢节奏质感
4. **日常植入修炼** — 修炼与城市经济碰撞（用药材太贵、夺灵阵提速、被钱难到），都市修仙独有幽默

**写法要点**：都市物件必须具体（奥迪A6六七十万/湖畔小区三室一厅/宜兴紫砂壶）；「前世今生对照」制造信息差（主角知道房价要涨）；恩人线是打脸流唯一情感锚（唐姨vs姜家冷脸对比）；都市日常块常作为蓄压期「透气口」穿插。
**线效果**：家族亲情线（恩人暖源）｜档案线（楚州生态）｜修炼成长线（经济碰撞）
**源书**：都市修仙ch002看房+ch004饭桌+ch005采购（开局）；ch204幻术块/巧遇块（推进）

### 2.3 商业战 / 势力合谋（施压族赛道特有·推进档新增）

**适用**：**中段（推进档）骨架**——主角武力已登顶后，「威名引发的势力博弈」取代「个人修行」成为主冲突源。

> ⚠️ 通用卡库施压族为新卡候选（势力合谋/反扑布谋）；本轮三档采样确认其为推进/高潮档收敛块。示例=洪门反扑全链（ch202-203）。

**节拍序列**（5拍，反派视角跨章推进）：
1. **势力会议倾倒** — 反派组织总部场景+巨头/负责人矩阵倾倒（洪门总部岛→七巨头会议，地下基地/兵力/财力底蕴）
2. **拍板悬赏/布谋** — 反派核心定调反扑方案（大龙头拍板十亿悬赏、"引出华夏布杀局"）
3. **隐藏情报/误判伏笔** — 卧底/内鬼隐瞒主角真实实力，诱反派战略误判（罗蒙藏"肉身破音障"消息）
4. **地下悬赏引爆** — 赏金引爆国际/界域地下世界，杀手组织/雇佣兵群像倾倒（十亿美元、计各大杀手组织接单）
5. **终局合谋博弈** — 高潮档升级为联盟围堵/天宝围困（天君联盟贪秘法，见 2.4），反派规模随主角武力逐档膨胀

**写法要点**：反派群像必须「一人一格」（毁灭力/癖好/地域），站股东大会式对话倾倒人设；布谋要有「双盲信息差」（主角知/反派不知→读者知/反角不知）制造观众优越感；赏金数值要顶格夸张（十亿美金）以"钱铸杀局"立势。
**线效果**：势力博弈线（施压）｜反派线（阵营立起）｜都市场景线（双幕对切副轨）
**源书**：都市修仙ch202机场/密室/运筹 + ch203秘书/悬赏/猎手（洪门十亿悬赏全链）

### 2.4 位阶差碾压仙域战（战斗族赛道特有·高潮档新增）

**适用**：**后期（高潮档）**——舞台迁仙域天荒界，主角以纯肉身/跨阶战力碾压修仙阶强者，暴力奇观峰点。

> ⚠️ 通用卡库战斗族为新卡候选（位阶差碾压兑现卡）；本轮三档确认三档收敛，但**碾压实底**集中在高潮档。都市修仙由都市入仙域后，"仙凡位阶差碾压"内核不变、碾压对象从凡人升为元婴天君。

**节拍序列**（N拍连，一场围剿战逐级加压）：
1. **压境威势倾倒** — 开场倾倒敌方阵容威势（十五元婴/法则之力扭曲空间），立后期战力天花板
2. **出山引爆** — 主角一人面对群敌出场，引爆全场/围观押注（气概定性）
3. **审敌嘲压** — 敌方神念扫描判定主角"蝼蚁"（区区金丹初期），恩威并施欲收编/缴秘法
4. **立威碾压** — 主角以跨阶实力给其一击/连击（打爆半张脸/一拳杀宗师/纯肉身碾压元婴），围观轰然
5. **群战穿插升级** — 越杀越强（吞婴练功修为暴涨写进战斗缝），一击/一拳九杀制造震撼
6. **余波震怖+收束** — 敌人陨落震怖（10万年未有）+主角斩草除根/史官封卷

**写法要点**：碾压必须「跨阶」（肉身破音障vs武道宗师、纯肉身vs元婴），并全量化位阶差（汽油vs航空燃油/伪元婴vs真元婴）；围观群像（各宗哭嚎/天骄心死/史官定调）承担震撼与情感温度；**升级写进战斗缝**（吞婴/吞噬修为实时反馈）是后期"越杀越强"的爽感引擎。
**线效果**：战斗线（碾压全程）｜世界观线（后期升维体系随战斗逐层揭）｜修炼线（吞婴练功狂飙）｜配角线·见证群像（外部震撼）
**源书**：都市修仙ch1000压境/出山/挑衅 + ch1001疾打/觉醒 + ch1002群战/升级 + ch1003追杀/吞婴/横扫 + ch1004除根/封卷

### 2.5 渡劫升维 · 由都市入仙域（世界观科普族赛道特有·高潮档新增）

**适用**：**后期（高潮档）结构转折**——舞台整体迁入仙域/异界，修炼体系升维，都市烟火日常族退场。

> ⚠️ 都市修仙后期最重要的结构指纹：开局给都市烟火建立代入感→中段都市/势力间摇摆→后期彻底放飞仙域暴力奇观。地球→天荒界迁移，体系自"武者/宗师/神境"切换为"炼气→金丹→元婴(天君)→化神(神君)"正规修仙阶。建议保留赛道特有层，跨书验证后再议抽象。

**节拍序列**（并非单块，而是后期多块的**结构总纲候选**）：
1. **世界迁移** — 舞台迁入仙域/异界（古魔渊/仙土/帝神山），建立新场景生态
2. **体系升维倾倒** — 后期力量体系随战斗逐层揭（元婴/天君/神品金丹/神君化神/帝神体/天宝神宝）
3. **主线钩子转场** — 以新大陆/异族军事线引路（华族被押北荒天牢→寻北荒天牢续集引线）
4. **史官封卷** — 以事件纪年式定调收束（"天荒历十二万九千五百六十五年，天荒将再崛起一位新霸主"）

**写法要点**：升维必须是"内核对齐再生皮"——都市修仙本质不是"都市场景"而是"位阶差碾压爽感"，仙域战换皮不换骨，才能让老读者不流失；都市烟火前期建立的温度靠"亲友/旧识"线延续（救林舞华三女圆环收束）。
**线效果**：世界观线（体系升维）｜悬念线（主线钩子转场）｜收线族（封卷/续集引线）
**源书**：都市修仙ch1000-1004（古魔渊围剿→华族/帝神山主线→天荒新霸主封卷）
