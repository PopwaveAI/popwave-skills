# 建势幕3示范 · 据点建设·经营线（ch27-46）

> CN-001 幕件之一（弧概览/六幕功能位序列/密度基准/使用红线见《CN-001-建势力弧总卡.md》）。

## 套路决策
- **演绎框架**：单主线（据点落成+经营立业）+暗手支线；把"队伍"落成"一处能运转的基业"
- **内容引擎**：主 批地建据/经营线开（商号+武馆）；辅 暗手觊觎智斗
- **高潮**：位置幕内前中段（ch31-34型）｜类型 批地被卡/资源被夺的破局战｜蓄力 4-5章｜余波 据点落成+第一桶经营收益
- **幕末钩子**：据点渐旺引来旁门眼红/扩张苗头→指向幕4势力扩张

## 幕定位
- **本幕作用**：把建势力的"硬件"落成——据点选址、批地经营、资源运转、第一桶经营收益；同时破解觊觎据点的暗手。
- **核心体验**：从"有队伍"到"有基业"的实业家掌控感——经营线与宗门线拧合。
- **情感弧线**：批地处处碰壁 → 破局拿地 → 经营渐旺、班底各安其位。
- **幕末质变**：「有班底的门主」→「有一处能运转的据点+第一桶经营收益根基的门主」。

## 剧情白描（示范叙事）
邵青玄着手落实据点——选址、批地、建设、挂牌号（商号+武馆双身落地）。批地处处被卡：暗中觊觎的手（地方商会/雷家旁门）拿"资质/批文/地契"拿捏要挟，主角以双轨之力（资本砸通+武道压底）连破几道卡子，把批地/经营证照拿下（经营线开）。据点落成后，经营渐旺：商会合作、武馆收徒、资源流转，班底各安其位、上下同心。暗手不甘，两次派"查账/闹事"试探，主角以制度+人情双管化解，顺藤摸瓜揪出背后指使（暗手半揭）。幕末，据点渐旺、第一桶经营收益入账，却也引眼红——旁门/世家中转的扩张苗头开始逼近，指向幕4势力扩张。

## prose-render交接
- **文风注意**：经营的烟火/实业感×主角双轨调度的从容；证照/收益数字直给，经营写"账目流转"。
- **不可改动骨架**：①批地被卡（双轨破局）②挂牌落成经营线开③暗手查账闹事两试皆破+顺藤摸瓜④据点渐旺+第一桶收益⑤旁门眼红扩张苗头。
- **可自由发挥**：批文具体卡点/经营项目/闹事细节/班底分工管理。
- **爽点外显**：收益以账目数字直给；破局以证照/地盘落地；根据地以"挂牌名号"具象。
- **角色行为锚点**：主角-双轨调度收放自如；班底-分工守位、上下同心；暗手-不择手段的利欲。
