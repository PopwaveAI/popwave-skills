# 隐世宗门/禁区风暴线（OS-003）

> 骨架源自都市/修仙双轨源书通用的「隐世秘境-宗门-禁区」生态原型（解耦借鉴）。秘境开启/规则夺宝/隐世宗门站队/雷暴禁区为赛道通用语汇，可直接利用其"场合规则"；具名宗门与具体秘境规则禁止照搬。本卡=中盘"都市→隐世换引擎"的枢纽示范。
> **消费方式**：plot 产幕白描时以本卡为底稿——改专名、换事件分支、对接本书X张力；示范名（秘境「沉墟」/大宗玄冥宗/隐世同盟/雷暴禁区）已登记命名规则示例库。

## 弧定位
- **本弧作用**：把主线引擎从"都市双规"切换到"隐世主线"——一幕喂出「秘境夺宝第一桶+隐世画风切换+势力站队选边+禁区风暴大场面」四件套；是换引擎的枢纽。
- **核心体验**：一脚踩进隐世的明规则暗秩序——秘境里讲规则、站错队就是死。
- **情感弧线**：初入隐世的新奇与陌生 → 秘境夺宝的险中取食 → 被迫站队的抉择 → 禁区风暴里的死里逃生+格局看清。
- **弧末质变**：「都市双轨强者」→「在隐世棋盘上有自己一子的一方」；从都市主角转正式隐世玩家。

## 剧情白描（示范叙事）
一处隐世秘境（示范名「沉墟」）即将开启——规定出关、规则夺宝、多方入场（隐世大宗玄冥宗、散修世家、魔修旁门）。主角为求境界资源/呼应灵脉线索率队入秘境：先摸清秘境规则（探规则→抢宝→多方火并→黄雀在后），在秘境夺宝里以"规则利用+信息差"先后得手三件关键资财，也结下隐形仇怨（胜者有仇）。秘境收尾牵出更大棋盘：一场大比/争端逼主角在隐世大宗、散修同盟、魔修之间站队——主角以双轨之力+秘境战绩在隐世同盟里拿到一席资格（站队博弈：选边、代价、收益权衡）。随后禁区（雷暴禁区）风暴线触发——一场禁区天灾/守护之变的大场面接踵而至，主角临危不乱、以命换局保住同盟一方，既看清隐世生态的残酷、也把玄冥宗/魔修的暗手暴露一角。弧末，主角以隐世同盟一席+禁区死局的格局，正式踏入更深的隐世主线（换引擎完成的钩子）。

- **可自由发挥**：秘境具体规则/夺宝细节/站位相互算计/禁区天灾具体表现。
- **爽点外显**：秘境夺宝以在场机/资财清单直给；禁区以天灾排面+主角抉择侧写；换引擎以"画风切换"的观感点出。
- **角色行为锚点**：主角-规则意识强、临危不乱、换引擎主动；玄冥宗-霸金刚慢逐利；魔修旁门-不择手段。

## 阵营抉择树（一幕三走法）
- **光明立同盟**：以战绩+规矩拿一席资格光明站边——收获：同盟资格+声望；代价：玄冥宗/魔修结怨（下幕钩子）；
- **隐忍渔利**：不公开站队、借秘境漏窗渔利再悄然结盟——收获：少露锋芒；代价：同盟资格滞后（喜幕后可走）；
- **铁腕抢顶**：直接以战力压服秘境诸方强硬顶位——收获：盟主权柄；代价：同盟离心、树敌更众（霸王流）。

## 结构性经验
1. **换引擎=规则切换枢纽**：秘境开启是把都市双轨切到隐世主线的"规则重设"信号——主角靠规则意识在新世界立足；
2. **规则夺宝=智斗舞台**：秘境讲"规则利用+信息差"，不是纯战力对撞——主角的破局点全在读懂规则的先机里；
3. **站队=换引擎抉择点**：被逼在势力间选边，是检验主角格局与取舍的箱庭——代价透明才显抉择成长；
4. **禁区大场面=格局放大器**：一场天灾死局让主角既看清敌方暗手、又立住同盟情分——大场面要服务叙事而非炫技；
5. **留一名敌手**：秘境夺宝胜者有仇——胜者的隐怨是后续隐世线的燃料。

## 可移植变体
秘境可换成：洞天/道场/遗迹/灵脉眼；禁区可换成：雷暴山/玄冰谷/绝地/上古战场——保留"秘境规则+站队博弈+禁区大场面+换引擎"结构即可。
