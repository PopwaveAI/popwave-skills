# 家族饭局打脸线（OS-001）

> 骨架源自国内都市源书通用的「家庭老宅寿宴/家族聚会羞辱-反转」生态原型（解耦借鉴）。家族饭局/寿宴席位/攀比羞辱/辈分规矩为赛道通用语汇，可直接利用其"场合规则"；具名角色与具体剧情分支禁止照搬。本卡=中早期主角"以家族局立威起步"的解耦旗舰示范。
> **消费方式**：plot 产幕白描时以本卡为底稿——改专名、换事件分支、对接本书X张力；示范专名（邵家/主角邵青玄/堂族霍家霍定权/主母名节）已登记命名规则示例库。

## 弧定位
- **本弧作用**：一幕喂出「母亲名节得正+家族话语权+当面打脸仇家+露一笔锋芒」四件套——中早期主角的立威第一步。
- **核心体验**：在一屋子的攀比与施舍眼神里，用一出证据+气势把席位反坐。
- **情感弧线**：被羞被压的憋屈 → 隐忍观局 → 当众反转 → 全场风向立转。
- **弧末质变**：「被视作落魄穷亲戚的少年」→「让家族上下重新打量的一方人物」。

## 剧情白描（示范叙事）
老宅寿宴前夕，母亲名下家业旁支的堂族霍家办寿，主角随母赴宴——明为祝寿、实遭攀比羞辱。席间辈分/住房/学历/产业轮番被踩，霍定权当众拿"落魄主母名节/主角前途"做文章、暗讽主角母子高攀门第。主角不急着发难，先以重生记忆+探察把霍家同伙手里那些见不得光的账目/股权/舞弊实证摸清（借"规矩"二字立起自己出手的名正言顺）。寿宴当口三连反转：先是霍家子弟炫富踩到位，主角三言两语点破其浮财来路不正（信息差回敬）；再当众抖出霍家吞母产业的具体证据（数字账目一次抛清）；最后以轻量炼气威压镇住全场、逼霍定权当场进退两难、不得不当众赔不是。全场从踩转拜：辈分最高的长辈起身打圆场、风向立转，母亲名节得正。主角不恋战，举杯一句"今天是寿宴，点到为止"，携母离席——落了个"不卑不亢、惹不起"的名声，也把霍家推上后续复仇线。

## prose-render交接
- **文风注意**：家族饭局的体面暗涌×证据反转的干脆×威压的压抑感；动作/眼神直给，多写"说话声渐小/落针可闻"。
- **不可改动骨架**：①赴宴受辱（名节被踩）②探察证据借规矩备牌③三连反转（信息差回敬→证据→威压）④全场风向立转+名节得正⑤不恋战离席落威名+仇家落线。
- **可自由发挥**：寿宴细节/证据具体账目/长辈端水的场面话。
- **爽点外显**：威压以全场寂静侧写；证据以具体数字账目直给；风向转向以群像心理+外人评价呈现。
- **角色行为锚点**：主角-压而不恋战、点到为止；母亲-隐忍但信儿；霍定权-色厉内荏老谋深算。

## 阵营抉择树（一幕三走法）
- **磊落反转**：证据+威压光明正大打脸——收获：名节+名望+长辈认同；代价：霍家记仇（下幕钩子）；
- **黑手离间**：借他人之手挑拨霍家内斗再从中取利——收获：少露锋芒；代价：长辈戒心（渗线流专用）；
- **顺势归隐**：当众退嫁不再争名，蓄力待反——收获：母亲安宁；代价：锋芒埋得更深（偏好藏锋可走）。

## 结构性经验
1. **借"规矩"正名**：先让对手输在"名不正言不顺"上，主角出手名正言顺——打脸要有合法性底盘；
2. **证据>武力**：家族局里冷数据比气势更有杀伤力——证据反转是打脸王炸；
3. **不恋战=更大反噬**：点到为止+当众给台阶，名望与刺杀平衡，后续仇家落地更有张力；
4. **长辈=风向裁判**：放一个中立长辈当风向转向的见证/正名者，打脸收割更可信；
5. **寿宴=席位落差放大器**：老宅寿宴的辈分/席位天然放大"踩→拜"的反差，是都市立威的黄金场景。

## 可移植变体
寿宴可换成：家族年会/升学谢师宴/婚礼敬酒/宗祠祭祖/家谱续修；攀比维度可换成：学历/婚配/产业/赡养——保留"席位羞辱+证据反转+风向转向"结构即可。
