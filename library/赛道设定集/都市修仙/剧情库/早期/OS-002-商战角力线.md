# 商战角力线（OS-002）

> 骨架源自都市/修仙源书通用的「中海商战」生态原型（解耦借鉴）。股权收购/拍卖会/证券会会场/写字楼博弈/资本胜负手为赛道通用语汇，可直接利用其"场合规则"；具名公司与具体并购剧情禁止照搬。本卡=中早期主角"以商战回本立身"的解耦示范。
> **消费方式**：plot 产幕白描时以本卡为底稿——改专名、换事件分支、对接本书X张力；示范公司名（云锦集团/霍氏控股/顾家资本）已登记命名规则示例库。

## 弧定位
- **本弧作用**：一幕喂出「资本回本+复仇筹码+商业话语权+背后靠山揭露」四件套——把复仇线与资本线拧合。
- **核心体验**：别人在明牌谈生意、你用重生记忆看穿牌桌底——香车资本与运筹帷幄。
- **情感弧线**：被侵占的愤懑 → 静观运筹（把筹码摸清）→ 胜负手反转 → 落定而有余威。
- **弧末质变**：「被资本挤到角落的旧主」→「让中海商界忌惮的执棋者」；商战仇家落定+背后靠山揭开一角。

## 剧情白描（示范叙事）
主角察觉到中海那头自己前世家业（示范名云锦集团）被侵占的股权线浮出水面——仇家体系（示范顾家资本/霍氏控股）正暗中把当年吞下的产业洗白变现。主角不急着正面对撼商会，而是以重生记忆+中海证分处人脉，把人家的持股结构、快进快出的杠杆缝隙、乃至合作方背地里的软肋一张张摸清（信息差套利）。商战角力分三段：第一段，试探。敌手在证券会/拍卖场扬言再蚕食一块产业，主角按兵不动、只以旁观者姿态出价压一压（把对方资金链逼紧）。第二段，胜负手。趁对方杠杆紧绷、被拍卖会/结算节奏钳住之时，主角出其不意接盘关键股权/截击现金流，当众给出"你们当初怎么吞、今天怎么吐"的账目清单（资本反转+名正言顺的复仇回本）。第三段，立威。商界风向转向，霍家/顾家护其靠山恐其翻、主角顺势立起中海商界话语权一角，并被背后更深的靠山（隐世等）注意。弧末钩子：这场角力赢了回本，却被更深一层的势力记上名——复仇线向更上层攀爬。

## prose-render交接
- **文风注意**：证券会/拍卖场的资本质感×主角运筹帷幄的从容；数字/账目直给，用"数字>形容词"呈现资本量级。
- **不可改动骨架**：①前世业仇浮现（回本动机）②摸牌信息差（杠杆/软肋）③胜负手截击+账目清单④话语权立起⑤背后靠山注意（跨卷钩）。
- **可自由发挥**：具体并购标的/拍卖场细节/中间人人情/商界群像话说。
- **爽点外显**：回本以股权/数字清单直给；反转以对手指挥落空的现场侧写；靠山关注以"多了一双眼睛"玄笔呈现。
- **角色行为锚点**：主角-静观运筹、一击致命、不恋战；顾家掌舵-傲慢自负、遇险色厉；中间人-两头留余地的精明。

## 阵营抉择树（一幕三走法）
- **光明回本**：当众账目+合法接盘正名回本——收获：话语权+复仇；代价：彻底登上敌手黑名单（下层反扑）；
- **暗线控盘**：不出面、借中间人/盟友代持悄然回收——收获：藏锋芒；代价：话语权滞后、受信局复杂（喜欢幕后可走）；
- **趁虚渔利**：趁敌手周转不灵低价抄底再高价倒手——收获：资本横财；代价：商界口碑两面、靠山戒心（投机流）。

## 结构性经验
1. **信息差是商战的矛**：重生记忆/人脉/暗账是主角唯一不怕体量悬殊的武器——商战必写"看穿底牌"；
2. **名正言顺才爽**：回本要有账目与合法性底盘，才不是"抢"，是"讨回"——爽感来自名正言顺；
3. **胜负手要快**：反转1-2章解决，不拖泥带水——商战写"一击致命"比"拉锯"更爽；
4. **靠山埋线**：商场之上永远有更高一层的注视——每场商战留一双眼睛（跨卷L4）；
5. **资本棋盘=活棋**：每个合作方都有裂缝可撬——主角的破局点全在裂缝与杠杆缝隙里。

## 可移植变体
资本场可换成：股权收购/拍卖会/竞标/对赌协议/连锁扩张/金融杠杆/地产回本——保留"前世业仇+信息差+胜负手+话语权+靠山"结构即可。

## 使用红线
- 幕纲级借鉴：结构/反转节奏/信息差套利/账目正名可直接继承；具体公司与并购标的禁止照搬，资本场合规则为赛道通用语汇可直接利用；
