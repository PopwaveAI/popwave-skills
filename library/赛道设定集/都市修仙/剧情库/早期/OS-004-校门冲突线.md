# 校门冲突线（OS-004）

> 骨架源自都市校园题材通用的「校门冲突-反派穿帮-谈心立人」生态原型（解耦借鉴）。校门围堵/风云人物下绊/起哄打脸为校园生态通用语汇，可直接利用其"场合规则"；具名角色与具体剧情分支禁止照搬。本卡=炼气前主角"以校园小舞台立人拆局"的解耦示范。
> **消费方式**：plot 产幕白描时以本卡为底稿——改专名、换事件分支、对接本书X张力；示范专名（主角邵青玄/女主沈清瑶/学生会风云人物顾砚舟）已登记命名规则示例库。

## 弧定位
- **本弧作用**：一幕喂出「被欺→反击+拆局长线反派+女主好感值+从容立人」四件套——校园层的小试牛刀。
- **核心体验**：反派自以为把我当背景板，我三言两语把他的台拆了——从容的降维。
- **情感弧线**：被围被压的憋屈 → 蓄压拆局 → 湖边谈心（与女主的信任兑换）。
- **弧末质变**：「被视作好欺负的新人」→「让校门上下忌惮又服气的从容者」；长线反派立起。

## 剧情白描（示范叙事）
常青藤中学，校门风云人物顾砚舟（或同类压人者）盯上主角邵青玄——或因其与沈清瑶走得近、或因新来的不善茬，起手在校门口让人"围"主角：呼朋引伴起哄、当众造谣主角高攀/出身，摆出一副"给我跪着走"的架势。主角不逃也不莽，先以观察看穿对方的盘（谁领的头/谁站得远在看戏/女主的反应），再把对方诬名里的漏洞当场拆给你看——一条条点破造谣的时间线/证伪点，令其当众下不来台（拆台穿帮，不靠动手）。接着，反派不服气再上一手（放学湖边又堵一次/威逼女主/拿出小男生那套面子），主角以一句轻描淡写的拿捏+轻量威压让他和同伙灰溜溜散场——校门一役，旁观者侧写定级："那小子真不简单，几句话就把顾砚舟整趴了。"事后湖边，沈清瑶因被牵入这场冲突来"质问/道谢"，主角顺势坦诚一点底色、又把她的心防拆下一层，二人信任与好感值明显上升（立人心灵线）。弧末钩子：顾砚舟主体虽被拆台，但其背后的更高层/年级资源浮出水面，作为长线反派悬在主角头上。

## prose-render交接
- **文风注意**：校园青春感×主角从容的降维；动作/眼神直给，拆台以对话逻辑取胜，不靠怒吼。
- **不可改动骨架**：①校门被压②拆台穿帮（证伪点）③再堵+轻量威压④名望侧写（旁观者）⑤湖边交心（信任兑换）⑥长线反派立起。
- **可自由发挥**：具体诬名内容/拆台台词/湖边日常/同伙墙头草表现。
- **爽点外显**：拆台以其逻辑碾压+围观者反应侧写；威压以周围人安静/退步侧写；交心以女主眼神/语气变化直给。
- **角色行为锚点**：主角-从容克制、不爆粗不恋战、对女主坦诚；沈清瑶-清冷心防、被拆后松动；顾砚舟-跋扈好面、屡败不甘。

## 阵营抉择树（一幕三走法）
- **从容拆台**：逻辑+轻量威压光明正大翻案——收获：名望+女主信任；代价：反派结仇（下幕钩子）；
- **借力打脸**：借旁观者/老师之口当众证伪，主角只顺水推舟——收获：少露锋芒更从容；代价：声音更小（大隐游可走）；
- **冷眼待变**：全程不出头、等反派自身穿帮垮台——收获：零结怨零锋芒；代价：女主信任差值（极偏幕后慎用）。

## 结构性经验
1. **拆台靠逻辑不靠拳头**：校园层打脸用"证伪之于造谣"，主角赢在脑与克制上，才显从容；
2. **旁观者=名望载体**：围观看客的一句"那小子不简单"是立人的最优外显，胜过主角自夸；
3. **女主嵌入冲突**：让清瑶被牵入，冲突才升级为"护人也立人"的双赢，感情线自然推进；
4. **长线反派不打死**：反派主体拆台即可、保留背后资源作后续张力——矛盾不断裂；
5. **湖边=拆心防**：文戏落在湖边谈心，把"打脸戏"缓冲成"感情戏"，节奏张弛有度。
