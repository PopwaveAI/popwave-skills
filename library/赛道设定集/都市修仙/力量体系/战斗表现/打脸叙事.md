## 一、打脸的本质

打脸不是"装完逼再打人一顿"。**打脸 = 用"先轻视、再反转"制造情绪落差**——读者跟着围观者一起从头到尾经历"轻视→紧张→惊艳/哗然→爽"的心路，反抗被打的是"看走眼的人"，不是"物理上的敌人"。装逼打脸三连是一切名场面的情绪骨架：

1. **轻视（起压）**：对手/观众/长辈明确看轻主角，让读者产生"你们等着"的不平感；
2. **蓄压（发酵）**：主角不急着亮底，轻视在台词、围观、场合中发酵到临界点，读者期待的反弹阈值越拉越高；
3. **打脸反转（爆破）**：一击反转——主角用身份/手腕/信息差/实力反手一击，围观表情集体从轻视到哗然/前倨后恭。

**一个名场面=一次完整三连**。只给反转不给蓄压="无效打脸"，只给轻视不给反转="憋屈烂尾"。

## 二、轻视蓄压类型词库（第1-2连：起压+发酵）

### 2.1 轻视来源类型

| 轻视来源 | 常用原型 | 轻视话术示例 | 蓄压侧写 |
|:--|:--|:--|:--|
| **长辈/长辈辈分** | 家族长辈、宗主、武道前辈 | "一个连课都上不起的穷学生，也配坐这里？" | 长辈摇头、递话给旁人错开 |
| **白富美/同辈** | 豪门千金、世家子弟、师兄 | "家世和能力都差点，只能做个普通朋友。" | 暗叹、扭头、拿手机打发时间 |
| **业界/商界** | 商会主事、对手总裁 | "毛都没长齐就想拿下三千万的单？" | 全场低笑、账房把合同往边上推 |
| **隐世同辈** | 宗门弟子、散修世家 | "一个没门没派的散修，也来秘境夺宝？" | 抱臂冷笑、护身真元外放示威 |
| **围观大众** | 服务生、食客、同学、看客 | "看这身打扮，穷酸得紧。" | 窃窃私语、投来同情的目光 |

### 2.2 主角"不急着亮底"的蓄压写法

| 蓄压方式 | 写法要点 | 禁 |
|:--|:--|:--|
| **陪笑不反驳** | 微笑着点头应下所有轻视，句句温和但句句不留把柄 | 一被呛就跳起来回怼（破坏蓄压） |
| **岔开重点** | 把话题拐到利益/正事上，"张总、合同的事，我们回头细聊。" | 顺着对方轻视角搭台阶（把压蓄没了） |
| **以退为进** | 主动让步让轻视再发酵一档，"好，那我先不争这个。" | 真的一走了之（丢了反转现场） |
| **细节埋牌** | 不动声色埋一件能反杀的细节（手机里的合同/口袋里的古玉/对谈里的破绽） | 露牌即败（蓄压被戳穿） |

> **蓄压核心**：让轻视在"观众面前"发酵，因为反转的爆破力=观众错愕的程度。为什么要这个穷学生的反击？因为他刚刚被所有人踩下去。

## 三、反转手段库（第3连：打脸反转）

> 反转不是"变强"，而是"用当下能拿到的东西把轻视者的判断推翻"。轻重分档，够用就好——**别场场都要核弹级反转**，会爽感通胀。

| 手段档 | 典型 | 反转点写作示例 |
|:--|:--|:--|
| **身份反转** | 隐藏身份/幕后主事人曝光 | 一位中途赶到的商会实际主事人进来先向主角俯身行礼——"慕先生。" |
| **手腕反转** | 数据/合同/证据反杀 | "——张总，贵司那批货里掺了十二吨次品，对账单我一周前就拿到了。" |
| **信息差反转** | 用对方不知道的情报压制 | "王家的地，底下是条灵脉——你想瞒到什么时候？" |
| **实力反转** | 探境后反杀/一击破防 | "--筑基四层的护体真元，我一指按下即碎。" |
| **借势反转** | 借法律/摄像头/当众的规则反制 | "你这台车的行车记录仪还开着，我们要不要看一遍？" |
| **人脉反转** | 某个大人物是他的故交/下属 | 那名不可一世的地头蛇见了主角身后人，腿一软跪了下去 |

## 四、打脸名场面公式大全

> 每场名场面选1个公式作主骨架，按序组织。连续3章不得复用同一公式。

| 名场面 | 公式 | 适用阶位段 |
|:--|:--|:--|
| **1. 宴会/包间打脸** | 入席（被车/台阶/座位位置看轻）→长辈与同辈轮流呛声→蓄压发酵（服务生倒酒都轻微的迟疑）→反转（主事人行礼/合同递上）→全场哗然+逐家投靠 | 全阶位段 |
| **2. 酒楼/食肆打脸** | 进店被撵/好位置被占→店内外围观→主角不动声色点菜/出招镇场→反转（锅碗一瞬齐平/一席话让掌柜服软） | 都市期 |
| **3. 校门/校园冲突** | 门口被拦（没名牌/被学生会挑衅）→围观停步→蓄压（主角不动手）→反转（校长/某大人物"慕同学"点名接走）→围观懊悔 | 都市期 |
| **4. 商战谈判打脸** | 会议室压价/外行看轻→账房/数据对峙→蓄压（合同拖着不签）→反转（财务造假被点破/对家崩盘）→签约或撤资 | 都市期-筑基期 |
| **5. 拍卖会打脸** | 举牌被压（穷酸看客被踩价）→蓄压下不报价→反转（牌价一次拉满/鉴宝一语点破真伪）→主持人改口/众人倒吸 | 都市期-筑基期 |
| **6. 斗法/比武打脸** | 宣战被看轻（后辈/散修）→斗法起手受压制→蓄压（护体真元/底牌）→反转（揭穿对方伪术/一击破防）→宗门/同辈哗然 | 筑基期-证道期 |
| **7. 宗门大比打脸** | 上位者名单无名人/首轮被嘲→逐轮蓄压（每轮险胜留手）→反转（直取最强者/提前亮道果）→冠名/收拥趸 | 证道期 |
| **8. 隐世对上位者打脸** | 老牌仙尊看轻新入局→法则文斗蓄力→反转（道果/神通总爆发）→一宗俯首 | 证道期 |

## 五、围观反应与名望外显（打脸的正确落点）

打脸反转的"爽"落在围观者的反应上——这就是装逼打脸流特有的"赚快感"方式。

**围观反应梯度（从轻视到哗然）**：

| 阶段 | 围观者反应 | 写法 |
|:--|:--|:--|
| 轻视 | 窃窃私语/投来同情的目光/低笑 | 一句台词一件小动作 |
| 反转瞬间 | 倒吸凉气/手抖/酒杯悬停 | 速度放慢，特写1-2个关键表情 |
| 哗然 | 全场寂然后爆议论/前倨后恭/递名片 | 蒙太奇式切3-5张脸 |
| 投靠 | 逐家递上合同/俯身行礼/请托 | 列名单式一笔带过（金额数字外显） |

**名望外显面板（对标世界事件/传说度）**——打脸名场面后视场合弹：

```
名望变化：楚州商圈无→楚州商圈"慕先生"。
知晓范围：湖畔小区→常青藤中学名流圈→楚州商会。
可信度：3成传言、4成猜测、3成事实。
```

## 六、反转信息差面板（打脸翻转的可视化）

主角"在算"的内心账（对标内心属性评估面板），仅用于打脸名场面里主角翻盘前的那一拍。

```
目标评估：张总（商会主事）。级别：楚州商会三把手。
他的死穴：名下公司偷税/那批货掺假/背后靠山换人。
反转点：把"他以为我不知道的事"翻上台面。
出手时点：全场都在看我的那一眼。
```

## 七、红线

1. **三连完整红线**：每场名场面必须轻视→蓄压→打脸反转三连完整；缺任何一连=无效打脸。
2. **蓄压不破红线**：蓄压期主角不亮底、不露牌；露牌=蓄压失效。
3. **不靠自称红线**：反转靠身份/手腕/信息差/实力，不靠"本座乃……"自称+秒杀（"老……自称就能秒"=废）。
4. **档位匹配红线**：低频名场面（±每卷1-2台）用核弹级反转；日常喂糖用中小档反转，别场场核弹（爽感通胀）。
5. **名望一致性红线**：名望只能递增不倒退；名号必须与后文他人称呼一致。
6. **金额与数据实数红线**：打脸收益（合同额/拍卖价/弟子数/灭宗等级）必须数字具体，禁"堪称恐怖如斯"。用 面板叙事 的"世界事件"时也仅在关键章。

---

> 装逼打脸是全阶位段的引擎，不是都市期专利；只是都市期载体是酒楼/宴/商战（话语压场），越到后期载体越转向斗法/宗门（法则压场）。核心永远是三连+围观反应。
