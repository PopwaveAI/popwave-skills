## 二、特殊条件战斗类型详解

### 类型1：酒楼/食肆对峙

**核心约束**：公众场合，有服务员/食客围观；有市井规矩（别砸店、别惊客人）。

**压制与借势**：
- **压场胜过动手**：宁可"一只酒杯稳稳落在对方跟前""一桌碗筷齐平"镇场，也不掀桌惊扰大势（掀桌=低档反派行为）；
- **借围观造势**：食客/服务生是观众，反转靠他们先惊再服；
- **市井攻防**：点菜/座位/好位置被抢作战场失势的隐喻。

**节奏模板**：
```
[进店/抢座(轻视)] → [点菜/出招(蓄压)] → [反转(碗筷齐平/一席话让掌柜服软)] → [食客哗然+投靠]
```

### 类型2：宴会/包间压席

**核心约束**：席面规矩（主位/敬酒/长辈为先）+长辈权威在场。

- 反转优先走"长者俯身行礼"式身份反转，双号手留下"主位/敬酒"线；
- 席间服务生/邻座的迟疑与哗然是被打脸的佐证；
- 包间四面有实时的被围观——房间门开合/望风是重要信号。

（详细三连与公式见《打脸叙事》名场面1宴会/包间打脸。）

### 类型3：商战谈判

**核心约束**：商业规则（合同/账本/法律/摄像头），武力武力悬置——赢在"利益与法理"。

- 用的是文件、对账单、财务造假证据、银行流水——"——张总，那批货里的次品，对账单我早就拿到了"；
- 反转落在签约/撤资/崩盘，体现"金钱与名望坍落"；
- 摄像头不等于"师父在上"——现实中打斗会被摄像头记录，反而成了反制的材料（借势反转，见《打脸叙事》手段库）。

**量感面板（商战）**：

```
——财务造假。
对账单：去年4月、9月两笔，各掺12吨次品。
影响：张总名下公司停牌、合同解约，楚州商会重排座次。
```

### 类型4：追逃战

（结构沿用通用；都市地形化——巷/楼/地铁/车/商场）**快慢交替**：跟踪（慢）→锁定（慢→快）→逼近（快）→出手（极快）；环境要具体（翻墙/钻巷/下地铁/跳窗），都市地形是双方战术资源。

### 类型5：围堵/巷战

**多视角切换**（守/攻/平民至少3视角）；主角常执行斩首/突围而非硬抗（利用都市建筑/人群制造混乱脱身）；拟声词系扩展含敲门砸门（砰砰砰）/警笛/金属碰撞。

### 类型6：秘境夺宝

**核心约束**：规则不明（古阵/机关/异域法则）+多方竞争（宗门/散修/魔修/势力）。

- 先探规则（古阵走势/机关规律/异域法则）→再抢宝；
- 法宝/神通对撞，护身真元/结界作防御，以"谁先摸到核心"分段博弈；
- 重生信息差在此变现最大（知道秘境的钥匙/机关死穴/藏宝位）；
- 多方借力打力（引宗门与魔修互斗，主角黄雀在后）。

### 类型7：盲战/黑暗战斗

（结构沿用通用）听觉/触觉替代视觉；拟声词密度增50%+；通过呼吸/脚步/武器破风声判断位置与境界（体感反推）。重生者凭前世记忆可"听声辨派系"。

### 类型8：陷阱/伏击

（结构沿用通用）拆（探机关→除→成功/失败面板）/触发（伤害+负面状态）/利用（提前铺垫→引敌人入局）。都市秘境/地库/废弃大楼均为常见场景。

## 三、特殊条件叠加规则

特殊条件可以叠加——一场"秘境夺宝"可能是"盲战+陷阱"；"追逃"可能是"巷战+镜头死角"。

| 叠加组合 | 场景示例 | 叠加效果 |
|:--|:--|:--|
| 酒楼对峙+盲战（关窗） | 包间拉帘后谈崩 | 围观骤减、压场转动手，动作由缓转快 |
| 商战+陷阱 | 合同里埋条款 | 账外汇合的"条款陷阱"，反转更狠 |
| 秘境夺宝+盲战 | 黑暗洞窟夺宝 | 听觉探秘，法宝对撞 |
| 追逃+围堵 | 都市追车被包抄 | 地形交错，突围 |

**叠加渲染要点**：以主要特殊条件为主框架，次要作修饰；不得互相矛盾各写一半；施工卡中标注主次。

## 五、红线

1. **不替代红线**：特殊条件战叠加在常规模式之上，施工卡未标注特殊条件时不加载。
2. **影响节奏红线**：特殊条件必须影响战斗节奏和描写方式——不能只是换个背景板。
3. **市井红线**：都市公众场合禁无脑掀桌/乱甩神通（有市井规矩+摄像头），优先压场/借势。
4. **盲战视觉红线**：盲战中不得出现视觉描写，必须用听觉/触觉替代（豁免：有神识/天眼等能力时面板呈现激活后方可用视觉）。
5. **追逃节奏红线**：追逃必须快慢交替，不得同一节奏。
6. **围堵多视角红线**：围堵/巷战必须有至少3个视角切换。
7. **陷阱铺垫红线**：利用陷阱杀敌必须提前铺垫，不能突然冒出。
8. **秘境规则红线**：秘境必须先探规则再抢宝，禁止"主角瞬到直接拿走核心"。
