# 战斗表现 · 战斗模式-筑基期（都市修仙赛道）

> 定位：筑基期（筑基→元婴，金丹后一步入道）的战斗=隐世仙缘战斗（宗门斗法/秘境夺宝/魔修对抗）+开宗建派前哨+对抗世家。此段「仙法×都市双轨」成型——护身真元与商战文件在同一叙事里穿行，明面商战、暗中斗法。

## 一、5模式15子型

| 模式 | 子型 | 说明 |
|:--|:--|:--|
| 隐世斗法 | 宗门斗法/秘境夺宝/魔修搏杀 | 神通护体起手，探境破防，护宗护体拉锯 |
| 双轨战旗 | 白天商战/夜里斗法 | 同一筹码两条轨兑现，因果连因果 |
| 开宗/世家战 | 开宗建派/对抗世家/宗门内斗 | 一宗之力级，阵法/长老团成建制 |
| 群战 | 多方火并/退围剿/斩首 | 多线视角（秘境夺宝多方） |
| 越境借调 | 越级战/仙力解封/一步入道 | 信息差+仙力代价（见下） |

## 二、8量感面板（筑基期）

| 面板 | 说明 |
|:--|:--|
| 境界/真元 | 探境+真元量（约几丈/方圆） |
| 护体真元 | 初成/成，破裂要写硬伤 |
| 灵石/丹材 | 恢复资源，消耗即资源换血 |
| 法宝/古董 | 夺宝/拍卖，认主渊源 |
| 秘境地/机关 | 规则不明，先探再抢 |
| 名望/势力 | 隐世+都市双轨名望 |
| 援军/宗门 | 长老/弟子/世家调令 |
| 仙力余量 | 重生者专属（解封节奏） |

## 三、隐世斗法借调（本段主战场写法）

- **打法**：探境面板（隐世完整版）→护体真元拉锯→神通过招→反转（揭穿伪术/一击破防）→夺势/夺宝（详见《打脸叙事》名场面6-8）；
- **多资源记账**：斗法消耗真元+灵石+法宝耐久三线，战后做一记结；禁无代价愈合；
- **秘境规则先行**：先探古阵/机关/异域法则再抢宝，禁"瞬到直接拿走核心"；
- **可跑**：护体破/真元见底→借地形/阵眼脱身，先保命再复盘。

**量感示例（斗法破防）**：

```
——筑基四层护体真元，我一指按下即碎。
对方踉跄后退半步，护体震荡如涟漪，裂纹顺着衣摆爬上来。
旁观的宗门弟子倒吸一口凉气——他刚刚还嘲我是散修。
```

## 四、越境借调（本段独有悬念）

- **可算逆转**：重生信息差──知道对方功法死穴/旧患/背景，越境五五开；
- **仙力解封中段**：一步入道时先用一节旧余量，之后一段时间不可再用（走火/暴露风险）；
- **禁白嫖越级**：越级战必有仙力代价/暴露代价。

## 五、句式节奏

- 斗法用「慢-爆-快-收」（试探→神通前兆（嗡）→破防判定→敌方失势）；
- 双轨并叙用「白天X线/夜里Y线」的错位标记；
- 都市+隐世并行的经费数要两边都给（合同额+夺宝法宝等级）。

## 六、红线

- 禁筑基期覆手灭宗门/断山河（超段，化神+才可）；
- 禁「一招秒全网」——护体真元拉锯要写够，反转靠信息差/破伪术；
- 斗法消耗必须结算（真元/灵石/法宝），禁无代价打赢；
- 双轨并叙必须明示因果，禁各写各的。
