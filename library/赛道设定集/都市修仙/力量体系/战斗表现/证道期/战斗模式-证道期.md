# 战斗表现 · 战斗模式-证道期（都市修仙赛道）

> 定位：证道期（化神+：虚神/合道/渡劫/大乘）的战斗=隐世决战/灭宗门/仙尊斗法/仙凡大撞。此段「仙尊棋局」成型——覆手灭宗门、弹指断山河，战斗单位是宗门与秘境，个体是执棋的意志；都市早攻略成底色，双轨棋盘已尽收尾。

## 一、5模式15子型

| 模式 | 子型 | 说明 |
|:--|:--|:--|
| 仙尊斗法 | 法则文斗/道果对撞/秩序改写 | 少写搏斗，多写法则与秩序 |
| 灭宗战 | 宗门阵法/一宗之力对撞/覆手灭宗 | 地图级破坏，道果总爆发 |
| 隐世大决战 | 宗门大比/魔修覆没/仙凡大撞 | 卷级高潮，多方站队 |
| 仙凡双轨清算 | 都市-隐世秩序重写/复仇总清算 | 两轨收官并轨 |
| 终局清算借调 | 渡劫/证道/超脱对位 | 与前世尊号对位（见下） |

## 二、9量感面板（证道期）

| 面板 | 说明 |
|:--|:--|
| 仙力上限/余量 | 重生者专属（解封旧余量，用一次少一节） |
| 道行/境界 | 化神→虚神→合道→渡劫→大乘 |
| 一宗之力/宗门 | 灭宗等级数据链（护宗弟子数/阵法层数） |

| 超脱/留白 | 大乘顶点、跨书彩蛋 |

## 三、仙尊斗法借调（本段主写法）

- **打法**：法则文斗（谈规则/论道果）→神通道果对撞→秩序改写→敌方能力失效/俯首——写"法则与秩序"而非"对轰"；
- **毁灭叙事**：覆手灭宗门用一宗之力数据链结算（护宗阵几层、长老几位、弟子几万），禁"恐怖如斯"空泛；
- **双轨收官**：证道期都市早已攻略，笔墨转隐世棋盘与复仇总清算；
- **天象代价**：动用仙力引雷云/灵光，暴露身份引来隐世注意/仇人到场——碾压的代价在收尾拍结算。

**量感示例（覆手断山河）**：

```
——覆手。那座占了一方山头的宗门，连护宗阵带长老弟子，尽数化为齑粉。
方圆百里地脉一滞，天际聚起一层雷云——仙力动的代价，天象在替他报信。
```

## 四、终局清算借调（本段独有悬念）

- **渡劫历雷**：一劫一生死，硬冲/风险即道心试炼——渡劫是最强的高潮装置；
- **证道对位**：大乘证道=与前世尊号对位（主角重生复仇的终点闭环）；
- **超脱留白**：大乘顶点/超脱差一点，留续作与跨书彩蛋。

## 五、句式节奏

- 法则文斗用「慢-慢-爆」（规则文斗铺垫→道果对撞→秩序改写）——比前段更缓更深；
- 中期少 POV，终局多 POV 并切（宗门/世家/仇人各方清算反应）；
- 环境破坏地图级（断山河/覆宗门），非局部。

## 六、红线

- 禁证道期只写"仙力对轰不写法则/秩序"（必含法则级对抗）；
- 禁「一招秒全网」——覆手断山河也须写宗门数据链+天象/因果代价；
- 仙力动用必须结算（天象暴露/走火/余量），禁白嫖碾压；
- 终局必须有非主角POV（罪名/仇人/宗门各方清算反应）。
