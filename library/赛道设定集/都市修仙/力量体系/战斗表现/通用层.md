# 战斗表现 · 通用层

> 赛道级参考答案——机制与结构源自赛道标杆源书全书拆解，专有名已槽位化、章锚点已剥离。新书 write 渲染战斗章时**抄机制、抄结构、抄颗粒度，不抄事件与专有名**；名词层以《赛道特色/名词表.md》为唯一真源。

> **消费顺序**：本文件（每战必读——定阶位段+装逼打脸三连+三段流+笔法+红线）→ 按阶位段加载《{阶位段}/战斗模式-{阶位段}》（模式/量感/数值锚全集）→ 都市期主角加读《都市期/打脸执行配方卡》（照单施工版）→ 按需叠加：《特殊条件战》（酒楼对峙/宴会/商战/秘境/追逃/陷阱）、《打脸叙事》（打脸三连意识流与反转全集）、《境界探知》（探敌人境界/体感反推/战力标尺）、《多线叙事》（POV切换/双轨/世界级事件）、《场景卡》（25种场景公式速查）。世界级规则读 `../战斗系统.md`；阶位定义读 `../力量体系.md`。
> **主角系边界（消费前必读）**：战斗模式件从标杆书主角（**重生仙尊·兼修真武与都市武者**）蒸馏——覆盖武法双修/御剑贴身/借势装逼打脸流。若新书主角改走其他系（纯体修/纯符修/纯商战流），套路与量感骨架可继承，但须替换对应武器/神通/打脸载体。
> **三步流总纲**：一场战斗/一次打脸的写法=**战前（填图纸）→战中（用笔法）→战后（收结算）**。通用层给跨阶位三步流；阶位段模式件给对应段的专属模式/量感/句式/数值锚。

## 〇 阶位定位（先定段，再动笔）

阶位段不按境界数字划分，按**力量体系三质变点**锚定（炼气圆满+筑基=都市→隐世，化神之上=仙尊）。写战斗章第一步：对照下表锁定所在段。

| 阶位段 | 境界锚（对齐力量体系） | 战斗规模 | 量感复杂度 | 画风一句话 | 与下一段分界线 |
|:--|:--|:--|:--|:--|:--|
| **都市期** | 武者/外家→炼气（**炼气圆满前**） | 1v1/小规模；酒楼/夜巷/校园/商战/武馆 | 量感直给，数值小，打脸是话语主载 | 都市烟火里的武者气——酒楼谢幕/夜巷截杀/宴会压席，赢法是信息差+借势+打脸 | 未跨入筑基：无护体真元，扛不住枪械/团围 |
| **筑基期** | 修士（筑基→元婴，**一步入道@金丹后**） | 宗门斗法/秘境夺宝/对抗世家 | 量感+境界探知；多资源条（真元/灵石/法宝） | 隐世仙法×都市商战的错位美学——斗法仙气叠商战烟火 | 未到化神：无仙尊威能，覆不了宗门 |
| **证道期** | 化神+（虚神/合道/渡劫/大乘，**化神之上**） | 隐世决战/灭宗门/仙尊斗法 | 法则叙事化；一宗之力级数据链 | 仙尊棋局的法则对撞史诗——覆手灭宗门/弹指断山河 | —（大乘=顶点，超脱留白） |

**三阶差异速记**（防串段）：打脸载体都市期靠话语+气场压场→筑基期靠斗法+底牌→证道期靠法则文斗+道果总爆发｜量感都市期数量小直给→筑基期境界探知+多资源条→证道期法则叙事化｜视角都市期全主角→筑基期每3章≥1次非主角POV→证道期必须有非主角POV｜环境互动都市期局部形变→筑基期区域破坏→证道期地图级（断山河/覆宗门）。

## 一 战前（动笔前：填图纸，不填不动笔）

> 六要素是笔法，规划是图纸。装逼打脸的图纸**比别人的多一根轴**：别人只回答"怎么打赢"，你还必须回答"这场打脸的三连怎么走、观众怎么看、反转在哪拍炸"。

### 1.1 战前四问（通用）

| # | 问 | 填法 |
|:--|:--|:--|
| 1 | 战斗功能 | 一句话——"打完后，____变了"（成长突破/获取资源/暴露身份/关系改变/信息揭示/制造危机/装逼打脸立威/余波消化） |
| 2 | 双方目标 | 主角想____（不只赢：拖延/夺物/保护/逼供/逃跑/压场立威），敌方想____（不只杀：试探/驱赶/看轻/羞辱/吞并）——目标错位=张力来源 |
| 3 | 胜负条件 | ____发生=主角赢，____发生=主角输（护身真元耗尽/被围/时限到达/对方求援）。禁"谁强谁赢" |
| 4 | 信息差布局 | 读者知道____但____不知道，第____拍揭示，制造____效果（揪心/爽感/意外/恐惧） |

### 1.2 装逼打脸三连预填（都市栖主，每场必填）

| # | 三连 | 填法 |
|:--|:--|:--|
| 5 | **轻视** | 谁轻视主角？（对手/观众/长辈），轻视为啥不慌（穷学生/外乡人/后辈/散修），用____一句话/一个眼神立起轻视 |
| 6 | **蓄压** | 主角____不急着亮底，让轻视在台词/围观/观众反应里发酵到____（临界点），读者期待的反弹阈值 |
| 7 | **打脸反转** | 在哪一拍反转？（一击压场/一席话反杀/揭穿底牌/翻出身份），反转造成的____（观众惊愕/对手崩溃/资源投靠），反转后主角取走____（威望/资源/势） |

### 1.3 战斗类型速查

| 类型 | 核心维度 | 规划要点 |
|:--|:--|:--|
| 消耗战 | 代价递进 | 谁先撑不住；转折=真元耗尽或找到弱点 |
| 碾压局 | 打脸反转 | 碾压中的反转（惊到观众的笑点）；三连完整，禁第一拍就秒 |
| 宴会/商战打脸 | 装逼三连 | 依"宴席/会议/拍卖"的场合规则立轻视→围观发酵→文件/手腕反杀 |
| 酒楼对峙 | 攻防节奏 | 核心是场合控制（压场）；2-3拍内收 |
| 遭遇战/斗法 | 双方目标 | 核心是适应——探境+找弱点或暴露弱点 |
| 智斗/博弈 | 信息差布局 | 信息就是武器；转折=关键信息揭示、攻守转换 |
| 防守/护人 | 胜负条件 | 核心是撑住而非赢；转折=救援到达/时限结束/敌方撤退 |

**打脸三连全程通用**（叠加在4拍之上）：轻视→蓄压→打脸反转。**底层的搏斗仍走4拍**（试探→对抗→转折→收尾）。碾压局同样走完整三连+4拍，禁"一招定胜负"、禁"老……自称就能秒"。

### 1.4 标杆局拆解示例（宴会打脸局·碾压范本）

- **四问填法**：功能=立威+资源吞并（商战打脸）；双方目标=主角镇场拿合同/信誉 vs 三位长辈否定其"穷学生"资格；胜负=主角拿不出王牌输/亮出王牌一反全场赢
- **打脸三连**：轻视（三位长辈看轻外乡穷学生，当众呛声）→蓄压（主角陪笑不反驳，让轻视在宴席发酵，观众/服务生/邻座都等着看笑话）→打脸反转（一名中途赶到的商会实际主事人进来先向他俯身行礼——"慕先生"；全场哗然，前倨后恭，合同/投靠蜂拥，最呛声那位递上赔礼）
- **要点**：碾压局同样走完整三连+4拍——靠"身份/手腕反杀"胜过"硬打"，标杆书全身无一招定胜负

## 二 战中（落笔时：笔法底线）

### 2.1 战斗六要素（每场战斗的笔法底线）

| 要素 | 差 | 好 | 本赛道（都市装逼流）适配 |
|:--|:--|:--|:--|
| **动作** | 事件级——一个词概括整个动作（"放出""拍散"） | 姿态级——拆到"手怎么动"（格挡到关节级/施法到动作级） | 先动作（他侧身半步，手腕一抖，一只酒杯稳稳落在对方跟前）→再判定（——护体真元？）→后效果（对方隔空被压得后仰） |
| **招式命名** | 报幕式——招式名是主体，动作被省略 | 嵌入式——动作是主体，招式名是标签 | 招用破折号引出："——御剑贴身！"；法宝/功法名用【】内联 |
| **画面表达** | 色彩标签——只有颜色没有形状/轨迹/动态 | 画面精确——色彩+形状+轨迹+动态≥2个维度 | 真元带质感：护体真元（涟漪/碎裂）、仙力解封（雷云/灵光/天象）、内劲（寸劲/震退） |
| **内心波动** | 标签式——"心头一凛""瞳孔一缩" | 判断式——具体判断/推理/计算 | 本赛道招牌：**探境反推**三连——"这一掌下来，他臂上青筋一爆。筑基四层以上。正面硬接不明智，先让他三分。" |
| **路人捧场** | 无旁观者，只有两人对打 | 旁观者生理反应放大战斗分量 | 每场≥1次：按住酒杯/手抖/倒吸凉气/后退；**装逼打脸加分位**——围观者的表情由"轻视"到"哗然"的转变是被打脸的直接证据 |
| **环境影响** | 打完环境完好无损 | 破坏匹配战斗等级，形变有具体形状 | 按段匹配：都市期局部（酒杯裂/桌沿崩）→筑基期区域（墙塌/地板裂）→证道期地图级（断山河/覆宗门） |

### 2.2 量感总则（跨阶位跨模式，本赛道"看得见的强"）

1. **意识流内联**：本赛道以"量感叙述+血液冷数据"嵌入，不用弹窗/光屏；关键判定（破防/反制/击杀）用"——XX！"破折号引出。
2. **弹出时机**：探境/破境/击杀/身份反转/资源外显五类节点弹；纯动作交换不弹；每次击杀必给量感（例外：协作/幕后）。
3. **复杂度对段**：都市期量感短平直给；筑基期+境界探知+多资源条；证道期法则叙事化+一宗之力级数据链。
4. **数值对段**：数值规模匹配阶位段（区间锚见各模式件）——都市期单次伤害/金额≤几十级；证道期一宗之力级。
5. **都市金额外显**：装逼打脸常以金额/合同额/名望外显（例：一单合同三千万、地下拍卖会一件法器标价两亿），金额必须数字具体。

### 2.3 拟声词基础表（跨阶位通用）

| 拟声词 | 用途 | 独占行 |
|:--|:--|:--|
| 嗤 | 真元破空/劲风（隔空出劲） | 否 |
| 嗡 | 御剑就位/护体真元震颤 | 否 |
| 铛 | 兵刃格挡/兵器落地 | 否 |
| 砰 | 撞击/一桌掀翻/酒杯碎裂 | 否 |
| 咔嚓 | 骨骼错位/杯盘崩裂（打脸名场面常配） | 否 |
| 噗 | 内劲透体的闷响 | 否 |
| 咚/咚 | 隔空点穴/叩桌震场 | 否 |

规则：独占行不加标点；同一段战斗同一拟声词≤2次，第3次起用动作描写替代。各阶位段专属拟声词见对应模式件。

### 2.4 句式节奏型（5种公式，跨阶位框架）

| 节奏型 | 公式 | 节奏感 |
|:--|:--|:--|
| 秒压型 | 极短句（3-5字）×2-3 → 破折号判定 → 拟声词独占行 → 围观反应1-2句 | 快-停-快 |
| 打脸转弯型 | 轻视铺垫（中长句×2-4）→"——XX！"极短句 → 围观从轻视到哗然（短句×3-4）→ 反杀后的冷评1句 | 慢-爆-转-爽 |
| 斗法型 | 压力铺垫（中长句×2-4）→ 法宝/神通前兆（嗡）→ 破防判定 → 敌方失势1句 | 慢-爆-快-收 |
| 借势型 | 控场1句 → 借法律/观众/摄像头1句 → 反手一击1句 | 快-快-止 |
| 商战型 | A方压价2句 → B方亮牌2句 → 文件/数据反杀（"——财务造假。"）→ 签约/撤资1句 | 交替-交替 |

## 三 战后（收尾时：结算+余波）

### 3.1 量感类型速查（何时给什么）

| 场景 | 量感类型 | 弹出规则 |
|:--|:--|:--|
| 击杀/重创 | 量感结算（破防+境界+落点） | 必给；格式见对应阶位段模式件 |
| 越境/破境 | 破境结算（境界→新能力→加点方向） | 破境当场给 |
| 探敌 | 境界探知（见《境界探知》） | 首遇必探；同类不重复，变种/精英除外 |
| 打脸反转 | 反转外显（围观反应+名望/资源投靠+金额） | 打脸名场面必外显 |
| 战利品/宝物 | 宝物名+属性+来历 | 夺宝/拍卖时给 |
| 战后总结 | 修行成长/势力变化 | 大战后给 |

### 3.2 伤势处理规则（按段分级）

- **都市期**：负伤即致命偏多——具体伤口（位置+程度）必写，禁中途自愈；低阶无治疗资源，战后写伤势处理；肉身是唯一底牌，禁无代价硬扛枪械。
- **筑基期**：可真元/丹药恢复，但必须消耗对应资源（真元/灵石）——恢复=资源换血，禁无代价愈合；护体真元破裂的硬伤要写。
- **证道期**：道心+仙力即门户——战后写仙力余量/走火反噬/一宗之力损耗；因果债清偿（报一次仇担一次业）。

### 3.3 战后余波三件套（打完≠结束）

1. **善后动作**：收割资源一笔带过/宝物清点（高阶战）/名望与传闻扩散（谁镇得下资源流向谁）。
2. **代价清偿**：伤势延续/仙力缺口记录/暴露身份的连锁反应（隐世注意/仇人搜捕/树敌）。
3. **钩子埋设**：反转收益中的异常项（"那人交换名片后眼神一暗"式悬念）、新线索、下一场打脸/大战的引信——收尾拍同时是下一拍的开场。

**写后自检**：动作姿态级？招名嵌入动作链？感官≥2维度？内心是判断？旁观者≥1次生理反应？环境破坏对段？打脸三连完整（轻视→蓄压→反转）？击杀给量感？伤势没中途自愈？余波三件套齐？

## 四 红线

1. **阶位段红线**：三段战斗模式与量感格式不得混用——都市期禁多资源条/法则面板；证道期必含法则级对抗（只写仙力对轰不写秩序=不合格）。
2. **模式去重红线**：连续3章禁用同一种战斗模式（含子类型），第4章必须切换。
3. **打脸三连红线**：每一场装逼打脸名场面必须三连完整（轻视→蓄压→打脸反转）；禁只写反转不蓄压（不打脸三连的"打脸"=无效打脸）；三连反转靠身份/手腕/信息差，不靠"自称+秒杀"。
4. **重修圆满红线**：主角禁跳境硬冲，越级战必须有信息差+仙力代价支撑的"可算逆转"。
5. **数值外显红线**：金额/境界/战力换算必须数字具体（都市金额、弟子数、灭宗等级），禁"堪称恐怖如斯"式空泛。
6. **拟声词红线**：独占行不加标点；同段同词≤2次。
7. **受伤持续性红线**：游击消耗战伤势持续到战后，禁中途自愈。
8. **POV红线**：筑基期每3章≥1次非主角视角；证道期全程只有主角POV=不合格。
9. **特殊条件红线**：特殊条件必须影响节奏和描写方式；利用摄像头/法律必须提前铺垫。
