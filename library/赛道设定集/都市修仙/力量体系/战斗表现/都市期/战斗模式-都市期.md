# 战斗表现 · 战斗模式-都市期（都市修仙赛道）

> 定位：都市期（武者/外家→炼气，炼气圆满前）的战斗=市井武者对决、酒楼对峙、宴会压席、商战握手、夜巷截杀。这是「主角从凡到修行者」的第一层，战斗写「肉搏/兵刃/市井/借势/打脸」，禁主角动不动"一剑光寒十四州"。

## 一、5模式15子型

| 模式 | 子型 | 说明 |
|:--|:--|:--|
| 武者近战 | 拳脚/兵刃/内劲 | 贴身短打，写「力/速/闪」，一撩一放倒 |
| 市井对峙 | 酒楼/宴会/街头 | 压场+借势+打脸，动手让位于手腕 |
| 商战 | 谈判/竞标/拍卖 | 文件/合同/摄像头为武器，借势 |
| 群战 | 被围/突围/斩首 | 多线视角（巷战/围堵） |
| 首弑借调 | 第一次杀人/第一次越境/第一次打脸 | 心理戏+后遗症（见下） |

## 二、7量感面板（都市期可用的「看得见的强」）

| 面板 | 说明 |
|:--|:--|
| 内劲/真元量 | 一层一层外显；炼气前是内力，炼气后是真元 |
| 体力/伤势 | 肉身是唯一底牌，伤要写部位+程度 |
| 金钱/资源 | 商战筹码/合同额/拍卖价（数字外显） |
| 名望/威名 | 装逼打脸的核心反馈（谁镇下资源流向谁） |
| 借势环境 | 围观/摄像头/法律/世家内斗 |
| 援军/人质 | 守护/牵制 |
| 时间 | 追逃/围堵/限度 |

## 三、装逼打脸借调（本段主引擎）

- **打法**：轻视→蓄压→打脸反转，三连完整（详见《打脸叙事》）；载体是话语+气场+身份，动手只在不惊大势/无人目击时；
- **后遗症**：打脸名场面树敌/名望递增引来更大挑战——当成下一段钩子；
- **禁**：主角一味"忍让欺负"不给反转（憋屈烂尾）或"一被呛就秒杀打脸"（无蓄压无效打脸）。

## 四、句式节奏

- 短句快节奏，动作直给（「一拳砸出」「侧身闪过」「一撩放倒」）；
- 拟声词适度（「砰」「铛」「嗤」）+都市物件的拟声（「咔嚓」杯盘崩裂）；
- 禁长句铺陈战斗（战斗要快、要爽）；
- 打脸名场面用「围观表情由轻视到哗然」的蒙太奇节奏。

## 五、红线

- 禁都市期御剑千里/飞遁/覆手灭城（味漂移）；
- 禁「主角一招秒全网」——都市期碾压也需铺垫+代价；
- 战斗必带「一个因果/一个取舍」，禁纯动作堆砌；
- 市井公众场合禁无脑掀桌/乱甩神通（有摄像头+市井规矩），优先压场/借势。
