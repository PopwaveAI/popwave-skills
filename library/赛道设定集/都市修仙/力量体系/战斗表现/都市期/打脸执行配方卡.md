# 战斗表现 · 都市期-装逼打脸（执行配方卡 v1.0.0）

> **这是操作手册，不是理念文档。** 面向 write 层（多为轻量模型）。你只要照着下面【第0步→第7步】的顺序填空，就能产出合格打脸名场面。看懂理念不如照做流程。
> **开工前必读（按顺序）**：①先读这个文件 → ②再用 Read 读合格模板 + 对一下本赛道都市期打脸的节奏（见 `战斗模式-都市期.md` 与 `打脸叙事.md`）→ ③动笔。模板就是"合格长什么样"的唯一基准，照着它写，别自己发挥。
> **一句话底线**：都市期装逼打脸走**话语+气场+身份反杀**——酒楼谢幕、宴会压席、商战核存。禁主角一被呛就"自称仙尊秒杀全场"，那是无蓄压的无效打脸。

## 第0步：填三连预填（3分钟，不填不写正文）

动手写正文前，先在草稿写下这三句——正文里不出现，只用于约束你自己。

| 连 | 你要填空 |
|:--|:--|
| 轻视 | 谁轻视主角？用____一句话/一个眼神立起轻视。 |
| 蓄压 | 主角用____（陪笑/岔开/以退为进）不急着亮底，让轻视在____（观众/食客/会议室）发酵到临界。 |
| 打脸反转 | 第____拍用____（身份/手腕/信息差/人脉/实力）反杀，制造____（哗然/前倨后恭/资源投靠）。 |

## 第1步：立轻视（写开篇100-200字）

**必做其一**（任选）：
- **长辈/同辈呛声**：显赫长辈/白富美/业界主事先看轻——"一个连课都上不起的穷学生，也配坐这？"→旁边人跟着低笑/递话错开。
- **场合看轻**：进门被撵/好座位被占/举牌被压价——用动作+一句台词立起"这个人没分量"。

**禁止**：主角一上来就"我乃……仙尊，你们也配？"——轻视角没立起来就直接反转=无效打脸。轻视角必须让读者产生"你们等着"的不平感。

## 第2步：蓄压（1-2拍，不看反怼）

- 主角**陪笑/岔开/以退为进**，句句温和但句句不落把柄——"张总，合同的事我们回头细聊。"；
- 让轻视在**旁观者**里发酵（食客窃语/服务生倒酒迟疑/邻座投来同情目光）——蓄压的核心是读者期待的反弹阈值越拉越高；
- **埋一件能反杀的细节**：手机里的合同/口袋里的古玉/对谈里对方一句破绽——露牌即败。

**禁止**：蓄压期被呛就跳起来回怼；或顺着轻视角搭台阶把压蓄没了。

## 第3步：反转引爆（1-2拍，核心高光）

**反转手段三选一（或连用）**，写一个"迎面而来的转折"：
- **身份反转**：一个大人物中途到场，先向主角俯身行礼——"慕先生。"（全场哗然点）；
- **手腕/信息差反转**："——张总，那批货里的次品，对账单我一周前就拿到了。"（数据反杀）；
- **实力反转**（若前面已铺垫逆行）：探境后一指破防/一撩放倒，"——筑基四层护体真元，我按得下就碎。"

**围观反应（必写）**：反转瞬间全场从"轻视"到"哗然"——倒吸凉气/手抖/酒杯悬停特写，蒙太奇式切3-5张脸；最呛声那位前倨后恭递上赔礼。

## 第4步：反杀后的冷评（1-2拍，收角色）

写一句主角的"冷评/转身"定性——不罗嗦，留白收束：
> 例："慕先生没接那张名片，只把桌上的合同收进大衣，起身，留下一句——'楚州这块蛋糕，我吃不下，但也轮不到你来切。'"

## 第5步：余波外显（收获与损失两栏必须同时写）

**收获至少写3样**：名望/威名递增（谁镇下资源流向谁，用名望面板）＋金钱/资源/合同（数字外显：三千万合同/一件法宝/宗门投靠）＋剩一样（情报/人脉/新线索/仇敌档案补全，选1）。

**损失/代价至少写3样**，每一种都"有代价地写"：
- **树敌**：刚被打脸的世家/商会咽不下这口气，背影里多了双盯梢的眼睛（埋进章末钩子）；
- **暴露**：名望传到该传的人耳朵里——隐世注意/仇人搜捕（重生记忆里的旧敌开始定位到他）；
- **隐忧**：这次反转用掉的信息差/人情（下次要用得更省）、借的势要还。

## 第6步：收束三段 + 结尾钩子（写最后100-150字）

1. **抽身仪式**：一个动作＋一句气（例：`他扣上车门，把合同往副驾一放，总算能回湖畔小区吃口热饭了。`）
2. **生活流切换**：从打脸场切到烟火气（热饭/家人来电/邻家普通高中生身份的重新落地），形成反差——**越是装逼打脸高手，越要写"他其实回到普通生活"**。
3. **结尾钩子**：收在"下一步/隐患/未解之谜"（例：合上手机，短信显示——唐姨约他明天来家里吃饭，说"有位故人要见见你"，而那个故人，前世跟他有笔没算清的账）。**禁止平淡收尾**。

## 红线（写完逐条自查，全过才交付）

1. **三连完整**：轻视→蓄压→打脸反转三连完整；缺任一=无效打脸。
2. **蓄压不破**：蓄压期不亮底不露牌；露牌=蓄压失效。
3. **不靠自称**：反转靠身份/手腕/信息差/实力，禁"自称+秒杀"。
4. **围观佐证**：反转必须有围观者深浅反应（表情/动作/前倨后恭），只写主角赢了不写围观=打脸没落点。
5. **档位匹配**：低频名场面用核弹级反转；日常喂糖用中小档反转，别场场核弹（爽感通胀）。
6. **收获必有损失**：两栏各≥3项，收支同落账，禁止只记收获。
7. **金额数字外显**：合同额/拍卖价/名望数字具体，禁"天上很多钱"式空泛。
8. **结尾必须有钩子**：收在未知数上，禁"一切都好"白开水收尾。

## 合格模板（写前必读）

合格模板读本赛道《打脸叙事.md》的名场面公式（宴会/酒楼/商战）＋《通用层.md》的标杆局拆解示例（宴会打脸局）。读它们拿"打脸名场面长什么样"的度量衡（三连节奏/围观反应/收支落账/收束钩子）。**写之前先读一遍，写的时候"像它们一样"，别追求和它们不同。**
