# 命名规则 · 都市修仙赛道

> 用法：所有专有名（人名/地名/宗派名/组织名）按本规则生成；示例库可直接取用。

## 1 总原则

1. **中式现代感**：念起来像现实都市里会出现的名字（普通而可信，不中二浮夸）；
2. **禁西幻直译**：无「XX·XX」外国式复姓拼写、无西式音译（艾德温/凯登/罗德里克式）；
3. **禁日式异世界**：无「XX酱/XX君/勇者/入队」直译腔；
4. **撞名检查**：新名诞生必过检查表（见§7）。

## 2 音节构件表（构词原料）

| 类别 | 常用构件 |
|:--|:--|
| 男名首字 | 陈/林/苏/江/沈/李/顾/陆/韩/秦/云/萧 |
| 女名首字 | 姜/苏/林/顾/安/秦/云/白/沈/许/柳/苏 |
| 泛用单名 | 凡/晨/然/君/凝/曦/风/痕/月/雪/涛/茂 |
| 姓（可组合） | 陈/姜/沈/李/顾/陆/苏/林/顾/韩/秦/云/萧/安 |

## 3 人名三层

- **底层**：单姓单名/双名（如：沈君文/姜初然式「正常现代名」——但本包禁照搬源书专名，见红线）；
- **中层**：单姓双名，带长幼（如：陈凡/安雅式—禁照搬；改原创如「顾晨」「林澈」）；
- **高层/修士**：道号/尊号（如：「受真人所赐道号」/「北玄仙尊」式——本包禁照搬「北玄仙尊/陈北玄」，改原创如「青冥真人/寻真道君」），外号走「绰号体」（藏九露一，如「那位爷/少年宗师/杀神」）。

## 4 宗派/修士名（尊号式）

- 主格式：**道号/姓氏+尊称**——仙尊/真人/老祖/道君/长老/掌门/魔尊；
- 别称：以地名/器物藏锋（「云雾山那位」「把过问老宅的那位高人」）；
- 禁止：起与知名修真IP（《凡人修仙传·韩立》《遮天·叶黑》《赘婿》《永夜君王》等）同名或近音。

## 5 地名构词法

- **主格式：专名+通名**——燕归湖 / 云雾山 / 龙景花园 / 湖畔小区 / 龙景山半山豪宅 / 常青藤中学（改原创如「云岚中学」）/ 火车站别墅区；
- 专名优先「景物/次序/颜色」（湖畔/云雾/紫金/云岚/盛和）；通名从《名词表.md》§9取（市/县/区/湖/山/小区/中学/港）。

## 6 组织命名

- **凡俗·机构后缀制**：XX集团 / XX地产 / XX会所 / XX武馆 / XX世家庄园 / XX慈善基金会（前缀走 姓氏/地名/云气象词，云岚/盛和/金鼎/四季）；
- **隐世·宗派后缀制**：XX宗 / XX派 / XX阁 / XX谷 / XX洞天（前缀走 天/地/玄/云/剑/丹/阵/武，如 青冥宗/万剑派/丹心阁）。

## 7 撞名检查表（新名必过）

1. 念三遍，有没有西幻直译感/日式异世界/中二浮夸？
2. 是否与《凡人修仙传》《遮天》《斗破苍穹》《赘婿》等知名IP角色/宗门撞名或近音？
3. 是否与本赛道知识库内其他书的人物名重复（防串味）？
4. 地名是否带通名？宗派是否带后缀？人物是否带辈分/绰号？（三带齐=格式合格）
