# 类型风味基线 · 都市修仙（重生归来·装逼打脸）

> 一句话世界观：**现代都市×修仙双轨**——中国式城市的烟火气（学区房/家宴/酒楼/会所/商厦）里藏着几乎枯竭的灵气与隐世宗门；修士藏于市中（在上学、在卖茶、在守一座老宅），主角以重生者之姿藏锋低调、只在该显时陡然展露，围观者的震惊即爽感。

## 类型声明

```
【类型声明】当前作品类型：都市×修仙×重生归来×装逼打脸。
写作全程保持都市修仙味：人名/地名为中式现代名（命名规则见同包《命名规则.md》），
货币/器物/社会符号为都市烟火风（人民币/房价/学区房/市值/药店/会所/酒楼/私立高中/政务大楼/校门/摊位）。
社会符号含修仙境界（炼气筑基金丹元婴化神虚神渡劫大乘）、都市武者（明劲暗劲化劲先天武者抱丹宗师）、
热兵器/权力资本制衡、世家豪门、隐世的宗门洞天秘境。
禁止漂移到纯西幻仙侠（无城市烟火/无现代都市符号）或纯都市异能（无境界体系/无法术神通）
或日式异世界直译腔（异度/召唤/勇者/入队）。
```

## 类型门禁

> 写「打脸」用【围观众人倒吸凉气/那句「磕头」/身份陡然亮出】——不是「仙威如狱」；写「修炼」用【炼气入筑基/真元渡周天/灵气入体】——不是「获得3点神性」；写钱用【三千万一栋/市值百亿】——不是「金克朗/灵石银两」。
> 任何维度产出「屠龙/法师塔/金克朗/银先令/冒险者工会/魔像/星界/神职神格」=类型味漂移到西幻，打回；产出「只有异能力没有境界/没有灵气/纯都市异能」=境界味漂移，打回。

## 附加风味锚（都市修仙类特有）

1. **装逼打脸三连是本类核心叙事装置**（轻视→蓄压→打脸反转，每章一个完整闭环）；
2. **境界自报可当剧情道具**（「炼气期修士」/「金丹老祖」当围观者听懂时=压轴爆点）；
3. **观众反应是爽感放大器**——打脸瞬间围观众人倒吸凉气/交头接耳/由鄙转惊的微表情镜头必给；
4. **都市烟火感**（看房/家宴/采购/早饭摊）是舞台质感，重生的「落地感」靠它；
5. 境界数值直给、一次性倾倒（灵气强度/战力倍数），不停节奏（防数值科普过载）。
