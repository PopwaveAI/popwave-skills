# 西幻诸神流剧情模式

> 在通用剧情模式基础上叠加，西幻·DND 诸神流赛道专属。
> 基于标杆书《深渊主宰》（诸生浮屠，全书980章）拆解提炼，源头见拆书库/西幻·DND/深渊主宰.md。

---

## 赛道特征

| 维度 | 说明 |
|------|------|
| 世界观 | DND 龙与地下城规则：六维属性 + 职业等级 + 法术环位 + 阵营 + 多元宇宙位面 |
| 主角身份 | 重生者/穿越者 + 游戏职业者（盗贼/巫师/术士等）+ 神职攀升 |
| 核心爽点 | 数值成长标尺跳档 / 弑神夺职 / 信息差预知 / 双身份双线并发 |
| 节奏偏好 | 事件密度高，数值面板即时反馈，每卷一台弑神大戏 |
| 冲突来源 | 神权洗牌大事件 / 阵营对抗 / 数值竞赛 / 信息差博弈 |

## 爽点结构（6 模式）

| 模式 | 爽感公式 | 功能 |
|------|---------|------|
| 数值成长 | 压力→突破 | 日常底盘，标尺跳档即 L4-L5 高潮 |
| 弑神夺职 | 弱→强（凡→神→伟大） | 大事件驱动的周期性峰值 |
| 信息差/预知 | 未知→揭示 | "藏九露一"布局型爽点底层外挂 |
| 打脸/反差 | 被欺→反击 | 单场面爆发剂 |
| 双线齐发 | 双轨叠加 | 结构创新，密度乘数 |
| 情绪调剂 | 张弛缓冲 | 防爽感通胀 |

## 事件分量标准

- 改变命运：觉醒职业 / 越级反杀 / 弑神 / 夺得神职 / 建立神国
- 打开可能：解锁新职业进阶 / 新法术环位 / 新位面 / 新神职领域
- 制造追读：圣者浩劫下一波冲击波 / 信仰链争夺 / 圣血子猎杀线 / 双线汇合点

## 三重引擎（故事机制骨架）

> 核心：**游戏数据流 × 圣者浩劫大事件 × 双身份双线并行**。数值成长负责日常喂糖，大事件负责周期高潮，双线把爽点密度翻倍。

| 引擎 | 机制 | 应用要点 |
|------|------|---------|
| 1. 游戏数据流 | 面板/等级/经验/专长/神性神格神力全部数据化 | 力量成长可视化 + 数值标尺跳档制造稳定爽点 |
| 2. 大事件供给猎物 | 「圣者浩劫」冲击波一波接一波，每波供给可猎杀的神灵/神子 | 周期大事件既是末日压力，也是主角猎杀收益来源 |
| 3. 双身份双线 | 本体神性经营 + 化身深渊武力，关键节点汇合 | 两线同卷各爆一次，密度成倍叠加 |

## 低压区设计

- 被当凡人/新手轻视（低等级/落魄身份/扮猪吃虎）
- 被数值碾压（高等级强者/挑战等级悬殊到绝望）
- 被神职/权柄压制（神战波及、神国壁垒）
- 被大势力/教会针对（圣血子猎杀、教团追杀）

## 冲突来源

| 冲突类型 | 主角欲望 | 敌方欲望 | 不可调和原因 |
|---------|---------|---------|-------------|
| 神权洗牌 | 想登神/夺神职 | 旧神想维持神位 | 神位有限/信仰唯一 |
| 阵营对抗 | 想自由布局 | 教会/神系想控制 | 权力 vs 自由 |
| 数值竞赛 | 想变强登神 | 竞争者也想登神 | 神格/神力稀缺 |
| 信息差 | 想保持预知优势 | 他人想揭开主角底牌 | 信息 = 力量 |

## 特有节奏要求

- 每卷至少 1 台「希腊式弑神大戏」作为体积型高潮
- 数值面板/升级即时反馈循环不可断（行动→数值/神性/神格回报）
- 大事件（圣者浩劫类）既是压力源也是收益来源，一波接一波
- 双线并行时关键节点必须汇合，作记忆锚点防割裂
- 后期防神职/神格数值通胀，用主题收束（如"秩序"）而非继续堆数值

## 深渊主宰拆解补充

### 力量体系三层范式

| 层 | 内容 | 爽点来源 |
|----|------|---------|
| 凡人层 | DND 职业 + 等级 + 属性 + 专长 + 技能 | 前世记忆 + 面板的降维打击 |
| 超凡层 | 职业进阶 + 传奇境界 + 法术环位（0-9环） | 专长/进阶的质变 |
| 神灵层 | 神性/神格/神力 + 神职 + 领域 + 神国 | 每跨一个神力等级都是属性质变 |

**迁移要点**：力量体系必须分层（至少三层），每层有独立的"跳档标尺"，让升级的质变点可数、可视。

### 人物结构骨架（双线人物）

- 双身份双线人物结构：本体（神性经营/秩序理想）+ 化身（扩张武力/执行），互为表里，最终融合收束。
- 核心配套弧线「从依赖到独立」：妹妹/伴侣/盟友/化身都从"被庇护"走向"独立成势"，最终回归主角体系，形成闭环。
- 主角弧线核心动词「吃与建」：先"吃"（猎神子、弑神、夺神职），后"建"（建城、建神国、建神系、重建秩序）。

### 情感线设计原则（男性向成长文）

- 情感 = 动机引擎：亲情/伴侣线驱动主线动机（护妹求生、为伴侣救神）。
- 情感 = 力量绑定放大器：每个情感转折同时是神性/神格/位面扩张节点。
- 轻量化：异性线点到为止，情感服务剧情与爽感，非独立卖点。
- 结构形态：「一强二弱一特殊」——一条主线情感带满全书，异性线克制，特殊羁绊做变化。

### 世界宪法（十条运转规律 · 骨架）

神力=意志力 / 杀怪得魂力是底层规则 / 位面互有通道 / 施法依赖法网或神灵 / 神祇可陨落可借圣血子复活 / 超凡20是分水岭传奇25是天花板 / 阵营由行为决定 / 施法者是噩梦（法爷至上）/ 等级≠战力 / 封神需声威+神职+信徒+神格四要素。

**迁移要点**：西幻诸神流必须有"世界宪法"——用几条硬规则把世界运转、力量来源、神战逻辑焊死，机制自洽才能支撑长篇。

### 风险预警

- 后期神职/神格数值通胀 → 用"秩序/主题"收束
- 经营蓄力卷过缓 → 用明确目标钩子垫落差
- 硬核 DND 设定劝退新读者 → 机制夹叙夹议控密度
- 双线切换割裂 → 关键节点双线汇合作记忆锚点
