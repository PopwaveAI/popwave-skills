## 〇、总览：本书力量的本质

《深渊主宰》的力量体系是 **「DND（龙与地下城）规则 + 游戏数据化面板 + 神性/神格/神力三位一体 + 前世传奇记忆」** 的复合体系。

- **世界载体**：主角索伦重生苏醒于一个名为《诸神之战》的虚拟游戏世界，世界已 "接近真实"。他融合了游戏数据流，可看到属性面板、经验、技能点、专长点、生命值等（ch0002）。
- **核心力量来源分三层**：
  1. **凡人层**——职业（平民/盗贼/巫师/影武者/奥术师等）+ 等级 + 属性 + 专长 + 技能（DND 式）；
  2. **超凡层**——职业进阶（二阶→七阶）、传奇境界、法术环位（0–9 环）、传奇专长；
  3. **神灵层**——神性值、神格值、神力值、神职、领域、神国、弱小/微弱/弱等/中等/强大/伟大神力（完全按 DND 神格等级命名）。
- **力量扩展主线**：凡人职业 → 兼职巫师 → 传奇 → 半神 → 真神（微弱神力）→ 弱等神力 → 中等神力 → 强大神力。全书 980 章贯穿这条 "从盗贼到真神" 的攀升线。

## 一、力量定义——力量来源与本质

### 1.1 力量来源

| 来源 | 说明 | 章节证据 |
|:-----|:-----|:---------|
| 前世记忆 | 索伦前世为传奇盗贼，记忆游戏机制与战斗经验，是最大信息差与成长加速度 | ch0002、ch0004、ch0022 |
| 游戏数据流 | 世界如游戏，有属性面板、经验值、杀戮经验、技能点、专长点、生命值 | ch0002、ch0017 |
| 职业修炼/升级 | 通过杀戮获得经验、消耗经验升级进阶 | ch0017、ch0031、ch0065 |
| 神性/神格/神力 | 击杀神性生物、吸收神格碎片、发展信徒累积神力，是神灵层核心 | ch0206、ch0456、ch0528 |
| 信仰网络 | 真神通过信徒祈祷获得信仰之力；封神需神职、信徒、传说度 | ch0478、ch0528、ch0880 |
| 传说度 | 主角的声望值，≥100 点是封神分水岭，取决于观众与传播广度 | ch0434、ch0514 |

### 1.2 力量呈现方式（三套面板并存）

1. **凡人属性面板**：六大属性（力量/敏捷/体质/智力/感知/魅力）+ 职业等级 + 生命值 + 技能点 + 潜行/陷阱等技能数值。例：ch0002 初始「力量12/敏捷19/体质15/智力18/感知15/魅力16，5级平民·1级盗贼，生命12」。
2. **神灵面板**：神性值 + 神格值 + 神力值 + 神职 + 领域 + 圣者形态属性。例：ch0939「神性值715/神格值350」。
3. **境界/阶位**：职业按阶位划分（三阶、四阶、五阶传奇、六阶、七阶），同时配合挑战等级（Challenge Rating）。

### 1.3 力量获取方式

- **凡人层**：杀戮获得"杀戮经验"→ 升级 → 分配属性点/技能点/专长点；学习/抄录法术；进阶职业（兼职/进阶）。
- **神灵层**：击杀神性生物抽神性；融合神格碎片；吸收神职/领域；发展信徒积累信仰与神力；祭献/猎杀。

## 三、战斗体系

### 3.1 战斗规则核心

1. **属性/等级压制**：高阶对低阶往往碾压（如传奇野蛮人【传奇狂暴】+10力/+10体，免疫心智类法术/迷宫术/禁锢术，ch0037）。
2. **专长系统**：凡人战斗依赖专长（如【双武器战斗】【直觉闪避】【反射闪避】【阴影穿梭】【阴影袭杀】【阴影掌控】），专长可进阶为传奇版本（ch0320 弯刀【传奇】）。
3. **法术系统**：按环位（0–9 环）划分；施法需法术位/法术书；奥术师可借里魔网自动回忆已用法术（ch0495）；高阶法术如九环【流星爆】需施法等级20、八环【拟像术】近乎失传（ch036、ch0715）。禁魔领域可限制三环以下法术（ch0846）。
4. **职业特色**：盗贼/游荡者走阴影、潜行、背刺路线；影武者走阴影穿梭；巫师/奥术师走法术；战士/剑圣/蛮人走物理碾压。

### 3.2 神灵层战斗规则

- **神性/神格/神力三维属性**决定神灵强度；神性值决定"神性等级"（微弱神性→弱等神性→中等神性→强大神性），神格值/神力值决定神力等级。
- 神格能力需消耗杀戮经验或神力值掌握（ch0487）；真神可【改变形态】（ch0532 百余神力）。
- 部分神灵能力免疫机制：半神免疫【时间停止】（ch0456）；弱等神力获法术免疫1-4环（ch0678）；中等神力1-3环瞬发（ch0751）。
- 神格容纳上限：神力值超神格容纳上限会失控（长公主 ch0719）。

### 3.3 战力衡量数值体系

- **挑战等级（CR）**：三阶掘地虫挑战8/生物10（ch031）、传奇恐怖骑士挑战16/生物24（ch036）、上古红龙挑战25/生物34（ch044）。
- **杀戮经验**：击杀高阶生物获海量经验（16.5万、81.9万、125万、758万等）。
- **传说度**：与敌人强度无关，取决于观众与传播广度（ch0434）。

### 3.5 战斗写法规律

- **数值爽点前置**：白描卡常以属性面板/经验/神性神格数值作为"爽点"，先展示数值跃升再落实战斗。
- **信息差/机制破局**：主角常以"看破机制"取胜（如识破禁魔领域、弱点洞察、识破魔法女神魔网），战斗服务叙事而非纯战力。
- **防止战力碾压跳过战斗**：主角常因"无神格无法储存神性""神力值为0""奥术师/巫师兼容失败"等限制不能无限碾压，制造张弛。

## 五、拆解理解（力量体系的叙事逻辑）

本书的力量体系是典型的 **"数值升级爽文 + 神灵血统扩张"** 双轮驱动：

1. **凡人层的爽点**来自"前世传奇记忆 + 数据面板"的降维打击——主角用前世机制认知来"看破"战斗与升级捷径（兼职、进阶、专长选择），让数值成长既有道理又有爽感。
2. **神灵层的爽点**来自"从盗贼到真神"的等级跃迁——神性/神格/神力三值不断累积，每跨一个神力等级（微弱→弱等→中等→强大）都是一次属性与能力质变，配合"猎杀神子/恶魔/从神"的屠神叙事，制造持续的高规格冲突。
3. **成长节奏**呈"凡人快（ch17、ch44、ch69）+ 神灵慢（ch456、ch530、ch678、ch751、ch939）"的阶梯状，且每次质变都伴随明确门槛（经验达标、传说度100、神性10、神力300、神格300等），保证升级不因数值无限膨胀而失控。
4. **力量体系的"能力限制"**（无神格无法存神性、神力不足无法掌握神格能力、奥术师/巫师兼容失败）是全书制造张力、防止主角无限碾压的关键机制，也是后续"圣者浩劫""诸神博弈"主线的底层逻辑。
