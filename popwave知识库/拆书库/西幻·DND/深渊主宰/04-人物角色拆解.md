## 〇、全书人物格局速览

本书是「**双身份双线并行**」的人物结构：

- **本体线·索伦**：物质位面经营的凡人盗贼 → 真神 → 伟大神性「死者之王」，走神性神格攀升、弑神夺职、建立神国一路。
- **化身线·索隆**：无底深渊武力扩张的恶魔化身，走竞技场 → 炎魔 → 巴洛炎魔 → 恶魔领主 →「恶魔王子」一路，为神国提供兵源/资源/位面据点。
- 两条线在关键节点汇合（ch0610 本体斩杀恶魔领主助化身立足、ch0976 本体与化身神力融合），实现「神性经营」与「深渊武力」互为表里的终极闭环。

**核心人物关系网**：索伦（兄长/主神）— 薇薇安（同母异父妹妹/恐惧神子/双子神座之一）— 莉莉安（与薇薇安同体的恐惧魔女人格/双子神座之二）— 歌莉娅（北地女巫后裔/预言法师半神/此生伴侣）— 安娜（阿伦戴尔公主→女王/世俗王权线）— 阿拉丁（半身人美食家游荡者/早期旅伴）— 索隆（恶魔化身/武力扩张执行者）。

### 1.2 动机

- **底层动机（第一卷）**：乱世求生，护住幼妹薇薇安，摆脱贫民区饥寒与帮派/人贩威胁。ch0001–ch0004。

### 1.4 核心能力

- **凡人层**：盗贼/游荡者阴影系（潜行、背刺、阴影缠绕、阴影穿梭、阴影袭杀）+ 巫师/奥术师法术（奥术飞弹、蛮力术、阴影黑触手、九环流星爆等）+ 传奇专长（剑术大师、阴影主宰、完美双武器战斗、传奇闪避）。
- **神灵层**：神性/神格/神力三值体系；神职含半精灵、游荡者、阴影、盗窃、追踪、死亡、死者、谋杀等；领域含统治、秩序、毁灭、诡术等；圣者形态随意改变形态。
- **战斗风格**：以「信息差看破机制 + 数值碾压」为核心，兵器为双弯刀（斩首者/斩魂者等神器），配合阴影穿梭与神性瞬发天赋。
- **位面手段**：摩多城改造成浮空城/浮空岛（ch0802 海啸救城、ch0897 密瑟能核、ch0968 摩多城升空），实现脱离物质位面的位面级统治。

### 2.3 莉莉安（与薇薇安同体的恐惧魔女 / 双子神座之二）

**角色定位**：与薇薇安同体的恐惧魔女人格/身份，肩负「恐惧神子」的毁灭面；书末与薇薇安同封神为双子神座。

**动机**：作为恐惧神子现世，宣称要杀光其他恐惧神子（ch0160）；主导夺回恐惧神系的力量，最终得【纷争】神职登神。

**弧线**：ch0024 预言「第一位神之子【恐惧魔女】莉莉安将现世」→ ch0160 生死之际现身（张恶魔之翼、斥责本体无用、宣布杀光其他恐惧神子）→ ch0176 以人类定身术制住阿拉丁并诱其去寻吸血鬼神子（卖萌装可怜、暗藏算计）→ ch0844 与薇薇安同封神，得【纷争】神职 → ch0980 一同升天重返神国。

**与主角/薇薇安关系演变**：与薇薇安为同一身体的两种存在（本体/人格之争），觉醒时嘲弄本体无用；后期与薇薇安形成「恐惧双子」合力，最终双双登神、回归索伦神系。

- **终点（ch0980）**：伟大神性死者之王，携家人挚友升天重返神国，播撒无意志神性种子（潜能最低中等神力）。

### 4.4 弧线底层逻辑

- **主角弧线的核心动词是「吃与建」**：先「吃」——猎神子、弑神、夺神职，把恐惧/阴影/死亡/谋杀等神职逐一纳入囊中；后「建」——建摩多城、建神国、建神系、重建冥界秩序，最终从「猎神者」蜕变为「一系之主」。
- **配套设施弧线是「从依赖到独立」**：薇薇安、歌莉娅、安娜、索隆都从「被索伦庇护/安排」走向「独立成势」，最终以各自方式（登神/封王/融合）回归索伦体系，形成「主神 + 属神 + 世俗王权 + 深渊武力」的完整闭环。
