# 封面图模式

> 封面不是插画，是**视觉钩子**。唯一目标是让目标读者在 0.3 秒内识别赛道、感知独特性、产生点击欲望。

## 核心原则

- 封面是**营销工具**，书名是主角之一
- 画面服务于"让读者停下来"，不是"展示角色长什么样"
- 书名必须大、必须可读、必须有赛道辨识度

## 设计要素

| 要素 | 要求 | 权重 |
|:-----|:-----|:-----|
| 书名 | 必须可读，有材质质感 | 两成 |
| 画面主视觉 | 视觉钩子主体+场景 | 七成 |
| 文化元素 | 定场诗/印章（可选） | 半成 |
| 留白/暗部 | 承载文字叠加 | 半成 |

## 四层信息架构

```
标题区（上1/4）→ 主视觉（中1/2）→ 赛道符号 → 作者区（下1/4）
```

## 提示词结构

```
整体氛围框架 + 画面内容（远→近）+ 书名文字（融入画面）+ 风格
```

- 书名用双引号包裹，有材质质感
- 文字融入画面层次（被前景遮挡/与雾气融合），不形成独立"文字区"
