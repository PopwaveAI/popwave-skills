# 人设构建方法论

## 核心公式

**一个有记忆点的人物 = 欲望（Want）× 软肋（Need）× 执念（Wound）× 反差（Contrast）**

这四个维度缺一不可。少了一个，人物就会扁平。

---

## 维度一：欲望（Want）

### 什么是欲望
外在的、人物自己认为他想要的。驱动故事的外部引擎。

### 检验标准
- 足够具体吗？（不是"想过好日子"，是"想在这个月底前凑够我妈的手术费"）
- 有时限吗？（有紧迫感的欲望更能推动情节）
- 失败有代价吗？（如果得不到，后果必须是真的可怕的）

### 短篇特别注意
欲望不能太宏大——短篇没有空间去写"拯救世界"或"成为最强"。
短篇的欲望应该是：一个具体的、有期限的、失败代价立即可见的目标。

### 各题材的欲望范例
- 悬疑："找到杀死妹妹的真凶，在警察结案之前"
- 言情："让那个毁了我前半生的人跪下道歉"
- 规则怪谈："活过今晚，找到这栋楼的第13条规则"
- 年代："在春节前凑够3800块钱盘下那个店面"

---

## 维度二：软肋（Need）

### 什么是软肋
内在的、人物真正需要但自己可能没意识到的。
这是人物弧光的来源——从"想要A"到"意识到真正需要的是B"。

### 欲望 vs 软肋的经典冲突
- "想复仇"（欲望） vs "需要放下"（软肋）
- "想证明自己"（欲望） vs "需要被爱"（软肋）
- "想控制一切"（欲望） vs "需要学会信任"（软肋）
- "想逃离过去"（欲望） vs "需要与过去和解"（软肋）

### 短篇中的软肋
短篇空间有限，人物的"意识到软肋"的过程需要更简洁：
- 不是在长线发展中慢慢领悟，而是在一次关键事件中"顿悟"
- 软肋和欲望的冲突是一个瞬间的选择，而不是漫长的内心斗争

---

## 维度三：执念 / 创伤（Wound）

### 什么是执念/创伤
人物过去的某个具体事件，形成了TA现在的性格和行为模式。
这是人物所有"不合理行为"的合理解释。

### 好的执念特征
- 不是泛泛的"原生家庭不好"，而是"七岁那年，我眼睁睁看着妈妈把最后一口粥倒在我碗里，说自己不饿。后来我才知道那天她已经两天没吃东西了。"
- 具体到能被拍成一个简短的闪回片段
- 和主线的欲望/软肋形成因果链条

### 执念生成器
问这三个问题来找到人物的执念：
1. 在TA的人生中，最让TA后悔的一个瞬间是什么？
2. 这个事件让TA从此相信了一个什么"谎言"？（例："我不配被爱""只有足够强才不会被抛弃""相信别人就会受伤"）
3. 这个"谎言"在故事中如何被证明是错的？

---

## 维度四：反差（Contrast）

### 什么是反差
人物身上看似矛盾的特质。反差是"记忆点"的来源。

### 反差类型
- **身份反差**：身世显赫但市井气质 / 看似普通但隐藏身份
- **外表 vs 内在反差**：冷漠脸但热心肠 / 甜美外表但腹黑
- **能力反差**：战力爆表但社恐 / 智商巅峰但生活白痴
- **价值观反差**：杀手但不杀孩子 / 骗子但从不说假话

### 好的反差标准
- 不为了反差而反差——反差必须和人物的执念/软肋有关联
- 反差在情节中要被"用到"：故事的某个关键节点，反差制造了关键事件
- 短篇中一个人物一般只有1个核心反差，多了会让人物模糊

## 配角设计原则

### 短篇铁律：一个角色一个功能
短篇没有空间"养"配角。每个配角必须：
- 有一个明确的叙事功能（推动情节 / 揭示主角 / 制造冲突 / 提供信息）
- 有至少一个鲜明标签（不是外貌标签，是性格/行为标签）
- 功能重复的配角必须合并

### 配角功能表
| 功能 | 例子 | 注意事项 |
|------|------|----------|
| 对手/反派 | 制造核心冲突 | 不能是纯粹的脸谱化坏人，需要有可理解的动机 |
| 镜像/对照 | 和主角处境相似但选择不同 | 用来凸显主角的选择和成长 |
| 信息源 | 提供关键线索或背景 | 不能只出场一次给完信息就消失 |
| 情感锚 | 代表主角的"正常世界"或"情感归属" | 往往是驱动主角行动的情感动力 |
| 催化剂 | 推动主角做出关键决定 | 其行为直接导致主角的转折 |

## 人设检查清单

在开始写作前，逐项检查：
- [ ] 欲望是具体的、有期限的、失败代价可见的吗？
- [ ] 软肋和欲望有真实的冲突吗？
- [ ] 执念是具体的、能被一句话描述的"闪回片段"吗？
- [ ] 执念→行为模式→欲望→软肋之间有因果链条吗？
- [ ] 反差是"一个"明确的矛盾点，而不是一堆小特征吗？
- [ ] 配角各自有明确叙事功能，且无重复吗？
- [ ] 主角和对手有真正的价值观/利益的冲突（不只是"他是坏人"）吗？
- [ ] 在故事结局，人物的软肋得到了回应吗？（不管是和解、放弃还是转变）
