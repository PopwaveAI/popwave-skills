# 结构模板大全

## 模板一：知乎反转体

### 适用场景
- 平台：知乎盐言故事（最佳）、每天读点故事（适用）
- 流派：悬疑反转、社会派、情绪流
- 字数：1-3 万字

### 结构框架
```
【开场】第一人称，直接扔出反常事实或悬念（300字内）
  例："我当了十年刑警，见过的死人比活人多。但第一次让我想辞职的，是那个自称'已经死了一个月'的报案人。"

【布局】通过"现在的叙事"与"过去的闪回"交替，逐步释放信息
  每个章节如同一片拼图，读者跟着叙事者一起拼
  关键：信息释放的节奏——不能太快（失去悬念），也不能太慢（失去耐心）

【误导】在第2-3个章节设置"看似合理的解释"
  让读者以为自己猜到了真相
  这个"假真相"必须看起来合理，但经不起细节推敲

【逆转】在第4-5章揭示真正的真相
  真相比假真相更惊人，但所有线索早已埋好
  逆转后回头看，读者会发现"原来那些细节是这个意思"

【收束】结尾回到叙事者身上
  不只是事件的收束，更是叙事者的情感收束
  知乎体经典结尾："后来我……但直到现在，我仍然会在____的时候想起____。"
```

### 字数分配参考（总 15000 字）
| 段落 | 字数 | 占比 | 说明 |
|------|------|------|------|
| 开场+布局 | 4500字 | 30% | 免费部分，建立悬念和叙事者形象 |
| **付费钩子** | — | — | 断在"假真相刚刚被推翻、真线索刚刚露出"的瞬间 |
| 误导+逆转前半 | 4500字 | 30% | 付费第一段：假真相→线索→动摇 |
| 逆转高潮+收束 | 6000字 | 40% | 付费第二段：真真相→情感释放→收束 |

## 模板二：番茄单元剧体

### 适用场景
- 平台：番茄短故事（最佳）
- 流派：脑洞向、系统、规则怪谈、爽文
- 字数：6000-15000 字

### 结构框架
```
【开局（免费）】前三句立住：绝境/金手指/冲突 三选一至少亮两个（300-500字）
  例："我觉醒了'反向许愿'系统——许什么，老天就偏不给什么。'
  然后直接进入第一个冲突场景。

【单元1（免费）】第一次使用金手指/破解第一个规则（1500-2000字）
  展示金手指的运作方式
  制造第一个爽点：用金手指解决问题/打脸
  → 末尾埋一个新疑问/新危机

  **付费钩子** 断在新危机/新规则被发现但还没被破解的瞬间

【单元2（付费）】第二个挑战（2000-2500字）
  规则升级/挑战变大
  引入新人物或新信息
  第二次爽点释放

【单元3（付费）】高潮/最大挑战（2000-3000字）
  金手指的极限使用/规则的终极破解
  最大爽点释放

【收束（付费）】结局+情感落点（500-1000字）
  快速收束，不拖沓
  番茄读者不喜欢"后日谈"
```

### 字数分配参考（总 10000 字）
| 段落 | 字数 | 占比 |
|------|------|------|
| 开局+单元1（免费） | 2500-3000字 | 25-30% |
| 单元2（付费） | 2000-2500字 | 20-25% |
| 单元3（付费） | 2500-3000字 | 25-30% |
| 收束（付费） | 800-1000字 | 8-10% |

## 模板三：经典三幕式

### 适用场景
- 平台：全平台通用
- 流派：言情、现实情感、年代、都市
- 字数：5000-30000 字（灵活适配）

### 结构框架
```
【第一幕：开局】（约 25%）
  建立主角的"日常世界"
  引出欲望（Want）和核心困境
  激励事件（Inciting Incident）：打破日常，推动故事
  第一幕结束于：主角决定/被迫采取行动

【第二幕：冲突升级】（约 50%）
  一连串的阻碍、危机、反转
  每个障碍都比前一个更大
  中点转折：局势发生不可逆的变化
  "最黑暗的时刻"：主角看似走投无路
  第二幕结束于：主角获得关键领悟/资源/盟友

【第三幕：收束】（约 25%）
  最终对决/最终选择
  矛盾解决（达成/放弃/转换目标）
  人物完成蜕变（或不完成——有时"没变"也是一种收束）
  结尾：情感落点+主题升华
```

### 三幕式 + 付费钩子适配（以 12000 字为例）
| 段落 | 字数 | 说明 |
|------|------|------|
| 第一幕前半（免费） | 1500字 | 建立日常+引出困境 |
| 第一幕后半 + 激励事件（免费） | 1500字 | 激励事件发生 |
| **付费钩子** | — | 断在"激励事件发生后的第一个抉择时刻" |
| 第二幕上半（付费） | 3000字 | 冲突推进 |
| 第二幕下半 + 中点转折（付费） | 3000字 | 局势变化+最黑暗时刻 |
| 第三幕（付费） | 3000字 | 收束+结局 |

## 模板四：情绪爆发体

### 适用场景
- 平台：每天读点故事（最佳）、知乎盐言（适用）
- 流派：甜宠、虐恋、追妻火葬场、暖甜治愈
- 字数：5000-8000 字

### 结构框架
```
不同于"事件驱动"的结构，情绪爆发体是"情绪驱动"的。

【情绪引子（免费）】一个情绪饱满的场景片段（500-800字）
  不需要交代背景，直接用情感场景切入
  让读者"一秒共情"
  例：一个雨夜的车站、一张被撕碎的照片、一条未发出的消息

【回忆/展开（免费）】解释情绪引子的来源（1500-2000字）
  从情绪引子回溯，交代背景
  但持续保持情绪温度

  **付费钩子** 断在情绪最高点——通常是一段关系的关键时刻
  or 一个真相即将揭晓的情感爆发前

【情绪攀升（付费）】情感的深度展开（1500-2000字）
  不是"发生了更多事"，而是"情感更深了"
  读者对人物的共情持续加深

【情绪释放（付费）】高潮情感场景（1500-2000字）
  全篇的情绪最高点
  可能是和解、告别、表白、释怀……

【余韵（付费）】一个安静的落点（500-800字）
  不像三幕式那样"收束"，而是一个"情感余韵"
  让读者合上后还在回味
```

### 字数分配参考（总 6000 字）
| 段落 | 字数 | 占比 |
|------|------|------|
| 情绪引子+展开（免费） | 2000-2500字 | 35-40% |
| 情绪攀升（付费） | 1500-1800字 | 25-30% |
| 情绪释放（付费） | 1200-1500字 | 20-25% |
| 余韵（付费） | 400-600字 | 7-10% |

## 结构选择指南

| 如果你的故事是…… | 推荐模板 |
|-------------------|---------|
| 悬疑/反转为主，第一人称叙事 | 知乎反转体 |
| 脑洞/系统/金手指，爽为主 | 番茄单元剧体 |
| 言情/现实/年代，人物成长为主线 | 经典三幕式 |
| 情感驱动，共鸣＞情节 | 情绪爆发体 |
| 混合型（如：规则怪谈+言情） | 优先选主导元素对应的模板，混合次要模板的节奏 |
