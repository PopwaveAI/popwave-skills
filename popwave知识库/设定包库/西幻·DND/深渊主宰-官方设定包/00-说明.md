# 西幻·DND 官方设定包 · 深渊主宰参考原型

> 依据：标杆书《深渊主宰》深度拆解产出（设定 L1 / 剧情卷纲 / 文风 DNA）
> 改造原则：**借机制 · 换皮肉 · 剔证据**。本包是"官方预制、用户开盒即食"的模版设定包原型。

## 本包是什么

一份**可直接开写**的 DND 风西幻世界设定包。用户立项时一次下载整套，无需再逆向拆书，拿到即可开写。分成三个子包：

| 子包 | 内容 | 对应原书物料 |
|:--|:--|:--|
| `世界篇.md` | 世界构造 / 地理地图 / 力量体系 / 种族 / 神灵 / 历史 / 势力 / 经济资源 / 世界宪法 / 金手指 | 设定库 L1-01~06 + 世界宪法 |
| `驱动篇.md` | 开局配置 / 驱动引擎 / 卷1幕序列 / 高潮点 / 长线债务 | 剧情库卷纲 |
| `笔法篇.md` | 文风场景卡（去原文，只留技法规则） | 文风 DNA v4 |

## 改造声明（重要）

本包是**原创皮肉 + 借鉴机制**：

- **机制可放心复用**：六维属性、职业进阶、20 超凡/25 传奇门槛、兼职经验惩罚、位面通道、神子复活、阵营行为决定论、法爷至上、Boss 战必濒死铁律等——均为结构性规则，不构成侵权。
- **皮肉已全部换新**：所有专有名词（人名/地名/神名/货币/组织/金手指）均已原创化，不撞原书。
- **原文证据全部剔除**：不含任何原书原文摘录，不含具体情节细节。

## 对本包的使用方式

1. **直接开写**：按 `世界篇` 的世界观 + `驱动篇` 的开局与矛盾 + `笔法篇` 的笔触，直接立项开写。
2. **换皮再开写**：把命名（人名/地名/神名/货币）再换一套，即得到差异化新设定，避免同世界观撞车。
3. **机制取用**：只想用某块机制（如 Boss 战濒死铁律、数据内嵌笔法），单独取用对应章节。
