# 笔法篇 · 文风场景卡（技法规则）

> 提炼自标杆书文风 DNA，**只保留可复用的笔触技法规则，剔除全部原文摘录**。附 `scene` 字段，供渲染时按场景精配。

---

## 全书稳定特征（两大铁律）

1. **角色思考 = 三步**：`信息 → 评估 → 决定`。不写内心独白长段，用"观察到→推断出→决定做"推进。
2. **数字绑定角色感知**：面板、装备、等级、威胁值跟随角色当下的感知出现，不脱离角色视角甩数据。

## 场景卡清单

### scene: combat_early_skirmish（遭遇战）

- 动作链精确：每个动作单独拆解，有明确命中部位。
- 击杀反馈紧跟回报（经验/掉落），不延迟。
- 招式名用"术语包装"（如"背刺""冲锋"），制造技能感。
- **时间演变**：开篇极简（潜行→背刺→秒杀）；中期动作链密度最高；后期升格为军团级/神性能力。

### scene: combat_mid_boss（Boss 战）—— 必濒死铁律

- **模板**：危机爆发 → 濒死逃亡 → 绝境反击 → 进阶击杀 → 成长巩固。
- **打 Boss 必须濒死**，非碾压流。先显示"数据不可力敌"，再靠陷阱/战术/意志翻盘。
- Boss 战难度要"看得见"：先展示对方碾压级数据，再让主角用智慧而非蛮力取胜。
- **时间演变**：开篇是原型（单人硬扛）；中后期升格为军团级配合。

### scene: combat_stealth（暗杀/偷袭）

- 流程：潜行判定 → 观察 → 接近 → 背刺 → 反馈 → 搜刮撤离。不到五秒，干净利落。
- 不写"他感到紧张"，写身体动作（"一根一根握紧手指"）。氛围靠动作营造。
- **时间演变**：开篇是生存技能；中期正面+偷袭混合；后期"优先击杀高价值目标"的战术选择。

### scene: dialogue_daily（日常对话）

- 台词极简（配角的日常对话 ≤5 字常见）。
- **零引导词**：对话前必有动作铺垫，台词从动作背景自然产生。连续对话第一句标说话人后省略。
- 情绪通过动作让读者感受，不直述。

### scene: dialogue_emotional（情感高潮）

- 身体/表情描写多于引导词本身。
- 情感直述坦诚不留白（告白、决裂等关键节点）。
- 仅出现在关键情感锚点，不滥用。

### scene: description_environment（环境引入）

- **新场景首出场必从感官启动**：听觉 → 嗅觉 → 视觉递进，不扔全景说明书。
- 空间认知从最近身边物件向外推，不飞俯视图。
- 新场景用"地名。"独句起势，再自然带出背景信息。

### scene: narration_suspense（紧张叙述）

- 流程：听动静 → 评估威胁 → 计算资源 → 制定计划。
- 不写"他感到紧张"，写具体身体反应。
- 用短促独句制造压迫感，不拖长段。

## 通用笔法（跨场景）

### 独句段节奏

独句成段是最显眼的节奏手法，三类功能：
- **情绪收束**："恐惧。"（动作积累后单列收束）
- **时间跳跃**："后来。""那时候。"
- **重击信息**："这是一个罪恶的世界！"

开篇最密集（开篇 3000 字可约 28 处），中期战斗场景微收束，后期频率下降。不连续的短句制造"呼吸感"，让读者在密集描写后有停顿。

### 情绪·身体动作为主

全书约 96% 情绪通过身体动作/生理反应传递。直述情绪仅作波峰收束器——3-5 段动作积累后，单列一个独词段收束。

### 数据嵌入·从不弹出

面板/升级/装备/反馈全部用自然段落呈现——冒号、逗号连接，是叙述流的一部分，不是弹出式窗口。格式全程稳定。

### 外貌·绑在动作中

外貌不独立描写。手茧、背青、眼红——每处身体痕迹都绑着叙事信息（"被熏得黑漆的脸"=做饭状态，"青紫的背"=被打的痕迹）。

### 物品·数据与视觉并置

物品描述固定格式：**视觉特征 + 系统数据 + 叙事信息**。前半句画面感，后半句游戏属性。高阶物品优先呈现数据面。装备不是装饰，是叙事驱动力的量化载体。

### 叙事者距离

叙事者紧贴角色视线，不跳入内心。角色思维通过"观察到→推断出→决定做"三步。偶有极短因果解释，一两句内收住。**开篇**零距离、背景解释最短；**中期**加入评价性描述；**末期**视角升格为宏观全知。
