# 剧情库 · 分卷剧情

> template_id: `plot.volume` ｜ template_version: `1.0.0`
> 目标文件：`剧情库/{卷N}-{卷名}.md`（每卷一份；卷号、卷名与章范围以源包 `manifest.json` / `合并章节索引.json` 的卷边界为准）
> 定位：剧情库核心成品，回答「这一卷讲了一个什么故事」。立意是当百科读，不是证据平铺。
> 契约级别：`剧情库/` 目录名、`{卷N}-{卷名}.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 这一卷讲了一个什么故事 | 开场句（谁·什么处境·做了什么）；时间线四段（起点 / 推进 / 高潮 / 结尾）；关键事件要点 5–8 条（事件 + 为主角做了什么 + 冲突或转折 + 结果） | 每条要点尾部 `（chXXX）`；数值型设定紧随 🔒；本节末尾一行 `> 证据：…` |
| 二 | 主线推进 | 5–8 个链条节点：阶段名 + 卷内推进了什么 + ch 范围 | ch 落位在表格 `ch` 列，不写进句子 |
| 三 | 支线串联 | 支线名、本卷进展、去向（未展开 / 下卷深化 / 本卷收束） | ch 落位在表格 `ch` 列 |
| 四 | 伏笔埋设与回收 | 本书级伏笔表（伏笔 / 埋设 / 回收 / 状态）；本卷内短伏笔（埋设 → 回收） | 埋设与回收两列都必须是 ch 或 `待扩展`；表格后附一行 `> 证据：…` |
| 五 | 卷末钩子与追读点 | 钩子一句话、强度 L1–L5 | ch 落位在表格 `ch` 列 |
| 六 | 创作价值 | 创作机理名、为什么成立、可如何复刻 | 机理名后可选挂 `（chX-Y）` 作为取证锚 |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 证据 | 每条结论可回溯到该卷批次档案；ch 只出现在表格 `ch` 列或段尾 `> 证据：` 行，**正文不内联 chXX** |
| 🔒 | 等级、位阶、章数、势力数等原文给出的数值，标在数值紧后（如 `12🔒`）；原文没给就写「原文未展开」，不省略、不发明 |
| 部分范围 | 本卷只覆盖部分章时，文档头写 `篇幅状态：部分范围（覆盖 chXXX–YYY）`；第五节改列「本范围内断点（chXXX 止）」；第六节写 `待扩展：全卷创作价值待覆盖整卷后补` |
| 待扩展 | 字段存在但本范围取不到证据，写 `待扩展：{字段}（原因：本范围未覆盖 / 原文未展开）`；禁止留空、禁止编造 |
| 卷名一致 | H1 卷名与 `剧情库/索引.md`、`剧情库/各卷切片.md`、`manifest.json` 卷边界三方对齐 |
| 标题洁净 | H1 只留 `{卷N} · {卷名}`，不挂书名前缀与格式后缀；ch 范围写在文档头，不进 H1 |
