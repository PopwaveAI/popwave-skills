# 剧情库 · 各卷切片

> template_id: `plot.slices` ｜ template_version: `1.0.0`
> 目标文件：`剧情库/各卷切片.md`（全书一份）
> 定位：把每一卷切成同一套九字段，供横向比对与立项（L2/L3）直接取用。它是「一卷一行」的横向台账，不重复分卷文档的叙事流。
> 契约级别：`剧情库/` 目录名、`各卷切片.md` 文件名、下列一级小节骨架 = **稳定契约**；九字段的列名与列序 = **可变细节**（但九字段本身不得增删）。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 切片总表 | 每卷一行的九字段：力量范围 / 动力引擎 / 战斗系统 / 地理 / 势力 / 危机 / 敌人生态 / 矛盾轴 / 卷末边界 | 表格末尾 `ch` 列给出该卷范围；字段内含数值时紧随 🔒 |
| 二 | 逐卷要点 | 每卷 3–5 行叙事式补充，说明该卷九字段各自的「本卷增量」 | 每行尾 `（chXXX）` |
| 三 | 卷间衔接 | 上一卷「卷末边界」→ 下一卷「起点承接」，逐卷成对，卷间必须连续、无断点 | 每对尾 `（chXXX → chXXX）` |
| 四 | 覆盖范围声明 | 本次覆盖到第几卷、哪些卷为部分范围、哪些卷未覆盖 | 未覆盖卷写 `待扩展：卷N（原因：本范围未覆盖）` |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 九字段不缺 | 每卷九字段齐全，缺项写 `待扩展：{字段}`，不得留空单元格 |
| 证据 | 总表末尾统一给 `ch` 列；详细增量在第二节给 `（chXXX）`；不内联进句子 |
| 🔒 | 力量区间、数值上限、势力数量标 🔒；原文未给出写「原文未展开」 |
| 部分范围 | 末节必须给覆盖范围声明；部分范围卷在总表内用 `（至 chXXX）` 标注 |
| 与分卷对齐 | 卷名、ch 范围与 `剧情库/索引.md`、各分卷文档三方一致 |
