# 文风DNA · 通用笔触基底

> template_id: `style.base` ｜ template_version: `1.0.0`
> 目标文件：`文风DNA/通用笔触基底.md`（本书一份；若后续要跨书共享，另存到写作技法库并按宿主约定命名，本模块内只留本文件）
> 定位：把这本书的笔触沉淀成可复刻的模板——句式、叙事距离、对白、感官、节奏。写手照它写，能写出「像这本书」的文。
> 契约级别：`文风DNA/` 目录名、`通用笔触基底.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 句式偏好 | 句长分布、常用句式、段落长度习惯、破折/短句的使用场合 | 每条给采样章 ch |
| 二 | 叙事距离 | 贴脸 / 中距 / 远观的切换规则；什么时候切、切了给什么效果 | 每条给采样章 ch |
| 三 | 对白风格 | 对白占比、人物语体区分、提示语（说话人标签）用法 | 每条给采样章 ch；占比可标 🔒 |
| 四 | 感官描写 | 偏好哪几感、意象库、比喻密度与取喻来源 | 每条给采样章 ch |
| 五 | 情绪节奏 | 单章情绪曲线、高潮段落的处理、留白与收束方式 | 每条给采样章 ch |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 采样不受范围限制 | 文风维度不走检索；即使本次范围是部分章，也要在范围内凑齐六类场景各 ≥2 章；凑不齐时写 `待扩展：{场景}采样（原因：本范围不足 2 章）` |
| 不复制原文 | 结论用本书自己的话概括，可引用极短片段（不超过一句）作为例证；不得大段摘抄 |
| 证据 | 每条结论给采样章号；正文不内联 chXX（采样章写在括号或表格列里） |
| 🔒 | 对白占比、句长统计等量化标 🔒 |
| 与战斗系统对齐 | 战斗场景的叙述特征与 `力量与战斗/战斗系统.md` 第四节「写法特征」一致 |
| 标题洁净 | H1 为 `通用笔触基底 · {书名}`（模块内文件）；跨书共享副本按宿主约定命名，不加格式后缀 |
