# 爽点

> template_id: `payoff` ｜ template_version: `1.0.0`
> 目标文件：`爽点.md`（版本目录根，全书一份）
> 定位：消费六模块综合而来的爽点总账——名场面（叙事式）、爽感公式、压力机制、分布密度。它是「这本书为什么好读」的证据库，也是立项与复刻的输入。
> 契约级别：文件名与下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 名场面（叙事式） | 每个名场面一段叙事式描述（谁·什么处境·做了什么·读者爽在哪）+ 类型 + 强度 | 每条尾 `（chXXX）`；量化（越级数、人数）紧随 🔒 |
| 二 | 爽感公式 | 3–6 条高频公式：公式名 / 触发条件 / 兑现方式 / 复用场合 | 每条给代表 ch |
| 三 | 压力机制 | 压力源清单：类型 / 施加者 / 计时或衰减规则 / 解除条件 | 时间与数值紧随 🔒；表格 `ch` 列 |
| 四 | 爽点分布密度 | 按卷统计：卷 / 爽点总数 / 名场面数 / 密度（每 X 章 ≥ 1 个） | 数值紧随 🔒；表格 `ch` 列 |
| 五 | 覆盖范围与待扩展 | 已覆盖卷与章、未覆盖部分、无法归类的爽点 | 未覆盖写 `待扩展：…（原因：本范围未覆盖）` |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 只综合不新造 | 每条可回溯到六模块成品与批次档案，不新增原文里没有的名场面 |
| 叙事式 | 第一节必须是能读的故事段，不是条目列表；条目式写法判不通过 |
| 证据 | 名场面、公式、压力源都挂 ch；正文不内联 chXX |
| 🔒 | 越级数、人数、时间、密度一律紧随 🔒；原文未给出写「原文未展开」 |
| 部分范围 | 只覆盖部分章时，第四节只统计覆盖卷；末节声明覆盖止点，不得把未读部分算进密度 |
| 跨模块一致 | 压力机制与 `剧情库/动力引擎.md` 的代价结构、`立项/04-逆向破解.md` 的爽点引擎一致 |
| 标题洁净 | H1 为 `爽点` |
