## 填写纪律

| 项 | 写法 |
|:--|:--|
| 只综合不新造 | 每卷走向可回溯到 `剧情库` 分卷与切片，不虚列 |
| 三件齐全 | 每卷「质变 / 强敌 / 新困境」缺一不可；缺项回 `剧情库` 补读，仍缺则标 `待扩展` 并写明原因 |
| 只到概括层 | 不写具体战斗与对话，那是 `剧情库` 的活；本文件只到脉络 |
| 🔒 | 质变的档位跨度、势力规模标 🔒 |
| 部分范围 | 只覆盖部分章时，仅写覆盖到的卷；卷末走向不得据推测延伸 |
| 标题洁净 | H1 为 `L2 命运图plus` |
