# 根索引

> template_id: `root.index` ｜ template_version: `1.0.0`
> 目标文件：`{版本目录}/索引.md`（根级索引，全书一份）
> 定位：整套拆解产物的入口——覆盖范围声明、六模块导航、卷导航、检索协议、降级与待扩展清单。所有对外交付物都要在这里能被找到。
> 契约级别：文件名 `索引.md` 与下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 覆盖范围声明 | 范围类型（全书 / 卷 / 章）/ 资产与章区间 / 篇幅状态（完整 / 部分范围）/ 未覆盖部分 | 不涉证据行；数值紧随 🔒 |
| 二 | 六模块导航 | 模块名 / 目录 / 文件清单 / 一句话用途 / 指向模块索引 | 只写真实存在的文件；未产出标 `未产出` |
| 三 | 卷与分卷导航 | 卷号 / 卷名 / ch 范围 / 分卷文件 / 对应批次档案 | 表格 `ch` 列 |
| 四 | 主线 / 支线 / 伏笔检索协议 | 三条检索路径各自的第一步去哪：先查哪个索引、再落到哪个文件 | 每条给检索顺序与目标文件 |
| 五 | 降级与待扩展清单 | 未产出 / 降级 / 待扩展的文件与小节，逐条给原因，与 `_meta/templates.json` 的 `gaps` 一致 | 每条尾注明 `kind`（degraded / pending）与原因 |
| 六 | 变更记录指针 | 指向 `CHANGELOG.md`，并说明本次与父版本的关系（若有） | 只写指针，不重复变更内容 |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 只写真实路径 | 导航里的文件必须实际存在；未产出写 `未产出`，禁止指向幽灵路径 |
| 收尾顺序 | 本文件在六模块、`爽点.md`、`立项/` 落盘之后产出，确保导航与实际产物一致 |
| 与留痕一致 | 第五节必须与 `_meta/templates.json` 的 `gaps` 逐条对齐，不得一处声明降级、另一处不认 |
| 部分范围 | 必须显式声明覆盖范围与未覆盖部分；未覆盖不得写成全书结论 |
| 🔒 | 章数、字数、资产数标 🔒 |
| 标题洁净 | H1 为 `索引` |
