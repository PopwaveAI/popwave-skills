> 目标文件：`角色与势力库/主角卡.md`（全书一份，一位主角）

> 契约级别：`角色与势力库/` 目录名、`主角卡.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| 二 | 性格（挂行为证据） | 3–6 条性格点，每条 = 行为证据 + 出处（先写做了什么，再归结性格，禁止只下形容词） | 每条尾 `（chXXX）` |

| 五 | 口头禅 | 2–5 句原话（不转述），标注首次出现与重复场景 | 每句尾 `（chXXX）` |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 证据 | 性格点必须先给行为证据再下结论；ch 只出现在表格 `ch` 列或条目尾部，正文不内联 chXX |
| 🔒 | 面板、位阶、数值、代价比率紧随 🔒；原文未给出写「原文未展开」，不发明面板 |
| 部分范围 | 只覆盖部分章时，文档头写 `覆盖范围：chXXX–YYY`；第七、八节只到覆盖范围末，之后写 `待扩展：后续阶段（原因：本范围未覆盖）` |
| 待扩展 | 字段存在但本范围取不到证据，写 `待扩展：{字段}（原因：本范围未覆盖 / 原文未展开）` |
| 跨模块一致 | 金手指与 `力量与战斗/金手指.md`、成长档位与 `力量与战斗/力量体系.md` 主养成线对齐，不自行推翻 |
| 标题洁净 | H1 为 `主角卡 · {主角名}`，不挂书名前缀与格式后缀 |
