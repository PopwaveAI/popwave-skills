# 角色与势力库 · 盟友卡

> template_id: `cast.ally` ｜ template_version: `1.0.0`
> 目标文件：`角色与势力库/盟友卡.md`（全书一份，按人分节）
> 定位：把与主角同阵线的角色逐个写清「他是谁、跟主角什么关系、在哪件事上站到一起、怎么退场」。人物多了先给总表再做卡。
> 契约级别：`角色与势力库/` 目录名、`盟友卡.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 盟友总表 | 姓名 / 身份 / 与主角关系 / 初登场 ch / 退场或现状 ch | 表格 `ch` 列；姓名与 `总表与版图.md` 一致 |
| 二 | 逐人卡 | 每位一个三级标题，六个必填字段：基本信息 / 性格 / 与主角关系 / 关键事件 / 成长 / 退场 | 字段内 ch 落在条目尾或表格列；数值紧随 🔒 |
| 三 | 覆盖范围声明 | 已写卡人数、未写卡名单（只在总表出现）、部分范围说明 | 未写卡的人写 `待扩展：{人名}（原因：本范围未覆盖）` |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 六字段不缺 | 每位盟友六字段齐全；确实无内容时写 `待扩展：{字段}`，不得整段省略 |
| 证据 | 关系结论必须挂具体事件与 ch；正文不内联 chXX |
| 🔒 | 等级、能力数值、势力规模标 🔒；原文未给出写「原文未展开」 |
| 部分范围 | 只覆盖部分章时，未进入覆盖范围的盟友只进总表，并在第三节标 `待扩展` |
| 对账 | 写完回查 `各卷出场角色对账表.md`，本卷出现的盟友必须有卡或明确标 `待扩展` |
| 标题洁净 | H1 为 `盟友卡`；逐人卡用三级标题带姓名，不加格式后缀 |
