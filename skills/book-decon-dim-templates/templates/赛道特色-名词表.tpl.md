# 赛道特色 · 名词表

> template_id: `track.glossary` ｜ template_version: `1.0.0`
> 目标文件：`赛道特色/名词表.md`（全书一份）
> 定位：把本书自己造的词收成一张表，并给出「本书说法 ↔ 赛道通行说法」的对照。写手用它保证用词统一，跨书复刻时用它判断哪些词可移植。
> 契约级别：`赛道特色/` 目录名、`名词表.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 名词总表 | 名词 / 类别（人名 / 地名 / 势力 / 力量 / 物品 / 组织 / 事件）/ 释义 / 首次出现 / 是否本书独有 | 表格 `ch` 列；「是否本书独有」只允许 是 / 否 |
| 二 | 术语对照 | 本书说法 / 赛道通行说法 / 差异点 / 依据 ch | 表格 `ch` 列 |
| 三 | 命名溯源 | 本书自造词的构词思路（音译、拼合、典故等），支撑 `命名规则.md` | 每条尾 `（chXXX）` |
| 四 | 覆盖范围声明 | 词条数、已覆盖章区间、未覆盖部分 | 未覆盖写 `待扩展：{类别}词条（原因：本范围未覆盖）` |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 释义有据 | 释义必须来自原文语境，不按同类作品常识解释；正文不内联 chXX |
| 🔒 | 词条数、含数值的名词（如年限、档位）标 🔒 |
| 与其它模块分工 | 力量类名词的机制解释放 `力量与战斗/力量体系.md`，本表只给一句话释义与首次出现 |
| 部分范围 | 只覆盖部分章时，词条数写实际数并标覆盖止点；不得把未读部分的名词凭猜测补入 |
| 标题洁净 | H1 为 `名词表` |
