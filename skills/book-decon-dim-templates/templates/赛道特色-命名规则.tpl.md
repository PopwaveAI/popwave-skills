> template_id: `track.naming` ｜ template_version: `1.0.0`
> 目标文件：`赛道特色/命名规则.md`（全书一份）
> 定位：从本书已有名词反推出**命名机制与格式规律**（人名、地名、势力名、招式名、物品名各一套），供跨书复刻与后续写作统一。
> 契约级别：`赛道特色/` 目录名、`命名规则.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|

| 二 | 格式规律（分类目） | 五个类目各一张小表：人名 / 地名 / 势力名 / 招式名 / 物品名；每类给格式模板与实例 | 实例后挂 `（chXXX）` |

| 四 | 可复用清单 | 可直接移植到新书的命名模板与需替换的词根表 | 每条给来源 ch；推断项标 `待扩展` |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 从实例反推 | 每条格式模板必须至少有一个书中实例支撑；推不出规律时写 `待扩展：{类目}格式规律（原因：样本不足）` |
| 类目为空 | 该类目在本书**天然不存在实例**时（如本书极少给招式命名），实例列写 `本范围无此类实例`，格式模板列写清「本作如何替代命名」（如「以动作／效果直述」）。**不得为凑格式填一个本书没写过的词** |
| 不造实例 | 只有原文出现过的串才能进实例列；类型文学通用词（如「结界」「禁咒」这类同赛道常见词）在本书没出现过就一律不许用 |
| 实例挂哪一章 | 挂的 ch 必须真能找到这个串——写完回该章核对一次，找不到就换章或改标 `本范围无此类实例` |
| 样本计数 | 类目样本数可标 🔒（如「人名实例 20 个🔒」），便于判断规律可靠度 |
| 证据 | 模板与实例都挂 ch；正文不内联 chXX |
| 部分范围 | 只覆盖部分章时，样本数写实际数；不得用未读部分的命名推断规律 |
| 跨模块一致 | 招式名规律与 `力量与战斗/战斗系统.md` 第四节「招式命名」对齐 |
| 标题洁净 | H1 为 `命名规则` |
