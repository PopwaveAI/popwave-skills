# 赛道特色 · 类型风味基线

> template_id: `track.flavor` ｜ template_version: `1.0.0`
> 目标文件：`赛道特色/类型风味基线.md`（全书一份）
> 定位：把这本书所属赛道的**风味基线**抽出来（题材要素、情绪基调、读者预期），再标出本书对基线的偏离与增益。目的是跨书复刻：新书要复刻的是风味，不是专名。
> 契约级别：`赛道特色/` 目录名、`类型风味基线.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 去专名 | 第四节只写可移植的风味与结构，不写本书专名、不复述剧情 |
| 证据 | 基线与偏离都要挂在书中的表现上；不得只凭赛道常识写基线而不给本书实例 |
| 🔒 | 赛道容量、比例等量化推断标 🔒，并注明为推断值 |
| 部分范围 | 只覆盖部分章时，「读者预期」「赛道容量」这类需全书判断的行标 `待扩展：需覆盖全书后补` |
| 标题洁净 | H1 为 `类型风味基线` |
