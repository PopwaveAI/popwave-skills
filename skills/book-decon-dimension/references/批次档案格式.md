# 批次档案格式 · batch-archive-format

> 定位：L1 事实层批次档案（版本目录 `_temp/batches/` 下）的**结构规范**，规定一份批次档案必须有哪些章节、每节必填什么、格式如何，供 L2 六模块回溯取证。
>
> 本文件是**格式规范**，与同目录 `批次完成标志.md`（收敛契约/字段规范）分工不同：本文件管"档案长什么样"，标志文件管"这批能不能放行"。判读口径以 `批次完成标志.md` 为准，本文件不重复其字段定义。
>
> 档案按**交付物分两种**：**L1 批次档案**（完整交付 `standard` / `deep`，见第 1–2 节）与**骨架档案**（骨架交付 `outline`，见第 3 节）。两者并列但不同物，必备节与门禁均不同，**不得混用**。

---

## 1. 命名与批头

**文件名**：`V{卷序}_B{批序}_ch{起3位}-{止3位}.md`，例 `V1_B1_ch001-030.md`。批次范围以源包根 `批次计划.json` 的生效档位为准，不另行切批。若宿主另行指定文件名，档案内的 `batch` 字段仍按上式取值，并在本批 `warnings` 中留痕。

**批头（frontmatter，必填 5 项）**：

| 字段 | 必填 | 说明 |
|:--|:--:|:--|
| `batch` | 是 | 批次标识，取值同上式，须与本批标志文件的 `batchId` 一致 |
| `volume` | 是 | 所属卷号（源包按单卷切分时填 1） |
| `chapter_range` | 是 | 全书序号闭区间，如 `ch001-030` |
| `卷名` | 是 | 本卷名（源包未给卷名时如实标注，不自拟） |
| `主角状态快照` | 是 | 本批**终点**的主角状态一句话：等级/身份/金手指阶段/位置 |

主角状态快照是批次之间的连续性锚：上一批终点等于下一批起点，缺失会导致 L2 卷主线断裂。

## 2. 正文必备章节（缺一不可）

批次档案正文按固定顺序含以下章节；除「人物关系变化」为条件节外，其余均为**必备节**。

| 序 | 章节 | 必备 | 内容要求 |
|:-:|:--|:--:|:--|
| 一 | 预扫描术语表与锚点池 | 是 | 5 张术语表（人名/地名/等级名/势力名/物品名）逐条列出并标条数；锚点池写明命中章数、三段（开头/中段/结尾）覆盖、各模块命中章数、文风采样章 |
| 二 | 分场事件链表 | 是 | 表格，一事件一行，列固定为：`# / 事件 / 转折类型 / 类型 / ch / 参与角色 / 原文定位` |
| 三 | 八维提取子节 | 是 | 剧情、人物、力量、世界观、爽点、情感、文风、功能位 **八节齐全**；每节条目逐条写 |
| 四 | 关键数据 🔒 块 | 是 | 一行式摘要 + 原文定位指针，禁止全文引用 |
| 五 | 爽点与钩子 | 是 | 爽点一栏 + 钩子一栏（每条带强度 L1–L5） |
| 六 | 人物关系变化 | 条件 | **仅本批确实发生时写**；无则省略整节，不写"无" |
| 七 | 证据自计 | 是 | 事件链条目数 + 八维条目数 + 合计，用于对照证据密度门禁 |
| 八 | 本批自检 | 是 | 7 项门禁逐项结论与依据摘要，须与标志文件 `checks` 一致 |

### 2.1 事件链表口径

- **转折类型**取值：开局立威 / 身份跃迁 / 金手指升级 / 危机引入 / 关系变化 / 伏笔埋设 / 章末钩子。
- **类型**取值（7 型）：日常 / 成长 / 披露 / 转折 / 社交 / 探索 / 交锋。
- 每条事件用一句话说清"谁做了什么、冲突或转折是什么、结果如何"。
- `ch` 精确到章；`原文定位` 落到**段**，便于 L2 回溯。

### 2.2 八维条目纪律

- 每条必须带 `(chXXX)` 锚点；显式列出的章节锚点以半角括号紧贴条目末尾。
- 原文出现的量化数值必须摘录并标 `🔒`；无量化则不加。
- 原文未展开的设定标「原文未展开」；本批某维度确无内容标「本批无XX」——两种情况均为**合法标注**，不视为缺项。
- **禁止**凭记忆、书评或常识补充原文没有的内容。

### 2.3 功能位（第 8 维）

功能义名不超过 6 字，**不得出现人名地名**；每条写清"干什么活 + 服务哪个爽点"，只做事件级候选标注，不判断、不抽骨架、不定族。

### 2.4 关键数据块

格式为 `🔒 摘要 | 原文定位`，一条一行；只写摘要与定位指针，**禁止整段引用正文**。

### 2.5 钩子强度

`L1 日常 / L2 轻微 / L3 中等 / L4 强 / L5 致命`。

## 3. 骨架档案（`processingProfile = outline`）的必填节

骨架档案是**卷级骨架交付**的档案，与第 2 节的 L1 批次档案**并列，但不是同一种物**：它不是八维事实层，而是**按卷抽样**的卷级骨架，供快速判卷与范围决策，产物**未取证**。归档单位是**卷**，文件名 `V{卷序}_SK_ch{起3位}-{止3位}.md`（例 `V1_SK_ch001-048.md`），落在版本目录 `_temp/batches/`；单卷超过 40 章上限时按 `批次计划.json` 拆成多份同卷档案。骨架档案**不写八维提取子节、不写分场事件链表、不设证据密度**。

**批头（frontmatter，必填 7 项）**：

| 字段 | 必填 | 说明 |
|:--|:--:|:--|
| `batch` | 是 | 骨架档案标识，须与本卷标志 `batchId` 一致（`V{卷序}_SK_ch{起3位}-{止3位}`） |
| `volume` | 是 | 卷号 |
| `chapter_range` | 是 | 该卷全书序号闭区间，如 `ch001-048` |
| `卷名` | 是 | 本卷名（源包未给卷名时如实标注，不自拟） |
| `samplingRatio` | 是 | 本卷抽样比例（30%–40%） |
| `sampledChapters` | 是 | 本卷抽样章清单（全书序号），**须含卷首 / 卷末 / 卷末钩子章** |
| `skippedRanges` | 是 | 本卷被跳过章节区间（全书序号闭区间列表） |

**正文必备节（缺一不可）**：

| 序 | 章节 | 必备 | 内容要求 |
|:-:|:--|:--:|:--|
| 一 | 抽样声明 | 是 | 抽样比例、抽样章清单、被跳过区间；逐项标注必含章（卷首 / 卷末 / 卷末钩子章）是否命中 |
| 二 | 卷级九字段骨架 | 是 | 力量范围、动力引擎、战斗系统、地理、势力、危机、敌人生态、矛盾轴、卷末边界 **九字段齐全**，每字段条目带 `(chXXX)` |
| 三 | 主线链 | 是 | 卷内主线链条目 + 卷间衔接（与上一卷卷末边界、下一卷起点对齐，卷间连续） |
| 四 | 主要角色 | 是 | 本卷主要登场角色及其功能，带 `(chXXX)` |
| 五 | 力量体系要点 | 是 | 本卷力量体系增量要点，带 `(chXXX)` |
| 六 | 世界观要点 | 是 | 本卷世界观增量要点，带 `(chXXX)` |
| 七 | 未取证声明 | 是 | 逐项列出「抽样未取证」条目与被跳过章节区间，须与 `骨架/_未取证声明.md` 一致 |
| 八 | 本卷自检 | 是 | 6 项骨架门禁逐项结论与依据摘要，须与标志文件 `checks` 一致 |

### 3.1 骨架条目纪律

- 每条必须带 `(chXXX)` 锚点（可多章并列）；量化数值**不再强制 🔒**（骨架不设量化门禁）。
- 抽样**未覆盖**章节的推断必须显式标「**抽样未取证**」；**不得**凭记忆、书评或后文补全；未被抽样的内容不得写成确定结论。
- 必含章（卷首 / 卷末 / 卷末钩子章）未命中即不得判 `samplingDeclared` 通过。

### 3.2 与完整交付档案的区别（不得混用）

| 维度 | L1 批次档案（`standard` / `deep`） | 骨架档案（`outline`） |
|:--|:--|:--|
| 归档单位 | 批次（约 30 / ≤20 章） | 卷（≤40 章） |
| 取证方式 | 逐章精读，八维全提 | 按卷抽样 30%–40% |
| 必备节 | 八维提取、分场事件链表、🔒 块、（条件）人物关系变化 | 九字段骨架、主线链、主要角色、力量体系要点、世界观要点、未取证声明 |
| 门禁 | 7 项（见 `批次完成标志.md` 第 3.1 节） | 6 项（见 `批次完成标志.md` 第 3.2 节） |
| 免责标注 | 「原文未展开」 | 「抽样未取证」 |

## 4. 与其余契约的关系

| 契约 | 关系 |
|:--|:--|
| `批次计划.json` | 决定 `batch` 的卷序/批序/章范围，本档案不自行切批 |
| `批次完成标志.md` | 管放行判定；本档案的「证据自计」「本批自检」须与其 `evidenceCount`、`checks` 对齐 |
| 源包 `chapters/` | 唯一正文来源，只读；本档案不得引用 `_temp/chapters/` 这类不存在的路径 |
| `骨架/` 三份产物 | 骨架档案是其来源；骨架**未取证**，**不得作为 L2 证据来源** |
| 精拆版本（`standard` / `deep`） | 以骨架版本为父版本时，须在档案中标明「输入为未取证骨架」，骨架条目只作线索 |
| L2 六模块成品 | 本档案是 L2 的**唯一事实地基**，L2 证据须回溯到本档案，不自行推翻 |

## 5. 常见格式错误

| 错误 | 后果 |
|:--|:--|
| 缺八维中任意一节 | `schema` 门禁不过 |
| 条目无 `(chXXX)` 且未标「原文未展开」 | `noFabrication` 门禁不过，属编造 |
| 量化数值未标 🔒 | `quantified` 门禁不过 |
| 关键数据块整段引用正文 | 违反本规范，需改为一行式摘要 |
| 无关系变化却写"无" | 违反条件节约定，应省略整节 |
| 缺「主角状态快照」 | 批次连续性断裂，L2 卷主线无法衔接 |
| 骨架档案缺九字段中任意字段 | `skeletonFields` 门禁不过 |
| 骨架档案未声明抽样比例或被跳过区间 | `samplingDeclared` 门禁不过 |
| 骨架条目无 `(chXXX)` 且未标「抽样未取证」 | `noFabrication` 门禁不过，属编造 |
| 骨架档案误写「原文未展开」 | 免责标注用错（骨架应为「抽样未取证」），回溯口径混乱 |
| 骨架档案混入八维提取子节 / 分场事件链表 | 与交付物错配，应按本规范第 3 节重写 |
