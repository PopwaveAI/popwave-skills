# 变更记录

> template_id: `root.changelog` ｜ template_version: `1.0.0`
> 目标文件：`{版本目录}/CHANGELOG.md`（全书一份）
> 定位：本次拆解版本的改动台账——产出了什么、与父版本有何修正或冲突、哪些件降级或待扩展。续拆时先读它。
> 契约级别：文件名 `CHANGELOG.md` 与下列一级小节骨架 = **稳定契约**；措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 本次拆解概览 | 任务 ID / 范围 / 档位（`standard` / `deep`）/ 父版本 / 使用的 skill 与模板版本 | 数值紧随 🔒；模板版本见 `_meta/templates.json` |
| 二 | 产出清单 | 目录 / 文件 / 状态（新增 / 续写 / 未产出）逐条列出 | 只列真实产物；未产出标 `未产出` |
| 三 | 修正与冲突留痕 | 修正（父版本结论被推翻：写修正点与依据章）/ 冲突（两份都有证据：两份并存并标来源） | 每条尾给 `（chXXX）` |
| 四 | 降级与待扩展 | 与 `_meta/templates.json` 的 `gaps` 一致：`kind`（degraded / pending）/ 原因 / 影响 | 每条注明 kind 与原因 |
| 五 | 版本历史 | 本版本号与日期 + 一条要点；历史版本追加在下方，不覆盖 | 日期与版本号 |

## 模板正文

```markdown
# CHANGELOG

## {版本号}｜{YYYY-MM-DD}

**本次拆解概览**

| 项 | 内容 |
|:--|:--|
| 任务 ID | {taskId} |
| 范围 | {全书 / 卷 / chXXX–YYY}🔒 |
| 档位 | standard / deep |
| 父版本 | {目录或「无」} |
| skill 版本 | {版本号} |
| 模板版本 | 见 `_meta/templates.json` |

**产出清单**

| 目录 | 文件 | 状态 |
|:--|:--|:--|
| `剧情库/` | `卷1-{卷名}.md` | 新增 |
| `立项/` | `03-L3全书大纲.md` | 未产出（degraded） |

**修正与冲突留痕**

- 修正：{修正点}（依据 chXXX）
- 冲突：{两份结论}并存，来源分别为 {父版本 / 本次}（chXXX）

**降级与待扩展**

| 文件 / 小节 | kind | 原因 | 影响 |
|:--|:--|:--|:--|
| {文件} | degraded / pending | {原因} | {影响} |

**版本历史**

- {版本号}｜{YYYY-MM-DD}：{一条要点}
```

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 不覆盖历史 | 新版本追加在上方，历史条目保留，不重写、不删除 |
| 与留痕一致 | 第四节与 `_meta/templates.json` 的 `gaps`、根 `索引.md` 的降级清单三处一致 |
| 修正与冲突不静默 | 与父版本结论不一致时，必须二选一登记：修正（更新成品并写明依据）或冲突（并存并标来源），禁止静默覆盖 |
| 证据 | 修正与冲突条目必须挂 ch；正文不内联 chXX |
| 标题洁净 | H1 为 `CHANGELOG`；版本条目用二级标题带版本号与日期 |
