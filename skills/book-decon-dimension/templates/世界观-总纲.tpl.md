> 契约级别：`世界观/` 目录名、`总纲.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 世界总架构 | 一句话世界形态 / 分层（上界下界、内外域等）/ 支撑它运转的底层设定 2–4 条 | 每条尾 `（chXXX）`；层数与规模紧随 🔒 |
| 二 | 时代大事线 | 时间线表：时期 / 事件 / 影响 / ch（远史 → 近史 → 开书时点） | 表格 `ch` 列；年代、纪元名紧随 🔒 |
| 三 | 设计原则（八条） | 八条立世界观的取法（如「规则先行，不为爽让路」），每条给判据与一个书中实例 | 每条实例尾 `（chXXX）`；不足八条时标 `待扩展：第 N 条（原因：本范围未覆盖）` |
| 四 | 与其它模块的接口 | 本文件向下引出哪些文件、各覆盖什么 | 引用真实文件路径；不写不存在文件 |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 八条原则 | 第三节能给满八条就给满；不足时逐条标 `待扩展`，不得为凑数编原则 |
| 证据 | 总架构与大事线每条挂 ch；正文不内联 chXX |
| 🔒 | 纪元、年代、层数、规模标 🔒；原文未给出写「原文未展开」 |
| 部分范围 | 只覆盖部分章时，第二节大事线只写到覆盖范围能证实的时点，之后标 `待扩展`，不得据简介补远史 |
| 与动力引擎一致 | 世界形态命名与 `剧情库/动力引擎.md` 的世界总驱动不冲突 |
| 标题洁净 | H1 为 `世界观`，不挂书名前缀与格式后缀 |
