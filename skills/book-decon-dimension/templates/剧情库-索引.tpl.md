# 剧情库 · 索引

> template_id: `plot.index` ｜ template_version: `1.0.0`
> 目标文件：`剧情库/索引.md`（模块级索引，全书一份）
> 定位：剧情库内部的导航与检索协议——从「卷 / 主线链 / 支线 / 伏笔」四条路都能找到具体文件与位置。它是模块级索引，全书总导航在根 `索引.md`。
> 契约级别：`剧情库/` 目录名、`索引.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 分卷导航 | 卷号 / 卷名 / ch 范围 / 本卷功能位 / 文件名 | 表格 `ch` 列；卷名与各分卷 H1、`各卷切片.md` 三方一致 |
| 二 | 主线检索 | 主线链条目 → 所属卷文件（阶段名 / 卷 / 文件锚点） | 表格 `ch` 列 |
| 三 | 支线检索 | 支线名 → 埋设卷 / 深化卷 / 收束卷 | 每个去向带 ch 或 `待扩展` |
| 四 | 伏笔检索 | 伏笔名 → 埋设卷（ch）/ 回收卷（ch）/ 状态 | 两个 ch 列；未回收写 `待扩展` |
| 五 | 覆盖范围声明 | 已覆盖卷与章、部分范围卷、未覆盖卷 | 部分范围必须显式声明，不得默认全书 |

|:--|:--|:--|:--|

## 四、伏笔检索

| 伏笔 | 埋设 | 回收 | 状态 |
|:--|:--|:--|:--|

## 五、覆盖范围声明

- 已覆盖：{卷与章区间}
- 部分范围：{卷与章区间}

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 文件名一致 | 「文件」列给出的是真实文件相对路径；不得写未产出的文件（部分范围未产出卷文件时，该行标 `未产出`） |
| 证据 | 索引只做导航，不承载结论；每条指向的 ch 必须与分卷文档一致 |
| 收尾顺序 | 本文件在各分卷与 `各卷切片.md` 落盘之后产出，确保导航与实际产物对齐 |
| 部分范围 | 第三节、第四节允许出现 `待扩展`（未覆盖到回收点），但必须与第五节声明一致 |
| 卷名一致 | 卷名一律取源包 `manifest.json`，不自造别名 |
