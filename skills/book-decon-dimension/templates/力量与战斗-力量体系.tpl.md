## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 刻度可查 | 位阶表必须写成可查的刻度（门槛 + 刻度），禁止「逐步变强」这类含糊表述 |
| 交叉规则下限 | 第四节不得少于 5 条；不足 5 条说明 L1 该维度证据不足，回退补拆而不是删条 |
| 证据 | 每条规则给依据 ch；正文不内联 chXX |
| 🔒 | 门槛、刻度、加成、数量一律紧随 🔒；原文未给出的数值写「原文未展开」 |
| 部分范围 | 只覆盖部分章时，位阶表只列已出现的档位并在末行写 `待扩展：更高位阶（原因：本范围未覆盖）`；挑战刻度只到覆盖范围止点 |
| 与金手指对齐 | 金手指带来的越级能力必须在第四节交叉规则里有对应条目，与 `金手指.md` 一致 |
| 标题洁净 | H1 为 `力量体系` |
