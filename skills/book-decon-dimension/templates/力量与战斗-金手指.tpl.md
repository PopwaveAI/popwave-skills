> template_id: `power.cheat` ｜ template_version: `1.0.0`
> 目标文件：`力量与战斗/金手指.md`（全书一份）
> 定位：回答「主角凭什么比别人快」——双核机制、信息差从哪来、升级路径怎么排、限制与代价卡在哪。没有代价的金手指是失败设计，本文件必须把代价写实。
> 契约级别：`力量与战斗/` 目录名、`金手指.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 金手指总览（双核） | 两个核各一句话、双核怎么配合、能否单独运作 | 每条尾 `（chXXX）` |
| 二 | 双核机制 | 每个核一个三级标题：触发条件 / 作用范围 / 输出 / 冷却或容量 | 数值紧随 🔒 |
| 三 | 信息差机制 | 主角比别人多知道什么、差从哪来、怎么兑现成优势、什么时候会失效 | 每条尾 `（chXXX）` |
| 四 | 升级路径 | 逐阶段：阶段名 / 解锁什么 / 升级条件 / 对应力量档位 / 触发卷 | 数值紧随 🔒；表格 `ch` 列 |
| 五 | 限制与代价 | 限制清单（不能做什么）+ 代价清单（用了要付什么），逐条给后果与依据 ch | 每条尾 `（chXXX）`；代价量紧随 🔒 |
| 六 | 与力量体系的咬合 | 金手指如何抬升位阶速度、如何与子养成线配合、越级边界在哪 | 每条尾 `（chXXX）`；引用 `力量体系.md` 位阶名 |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 代价必写实 | 第五节不得为空或只写「有代价」；无据可依时写 `待扩展：代价结构（原因：本范围未覆盖）` 并回退补拆 |
| 双核不糊 | 两个核必须能分别说清触发与输出，禁止把双核写成一句话凑数 |
| 证据 | 每条机制、限制、代价挂 ch；正文不内联 chXX |
| 🔒 | 冷却、容量、倍数、代价量一律紧随 🔒；原文未给出写「原文未展开」 |
| 部分范围 | 只覆盖部分章时，第四节只到覆盖范围末并标 `待扩展：后续阶段`；不得预告未读卷的解锁 |
| 跨模块一致 | 与 `主角卡.md` 第四节双核金手指、`力量体系.md` 交叉规则三方一致；冲突时以本文件为准并回改两处 |
| 标题洁净 | H1 为 `金手指`；双核用三级标题带机制名 |
