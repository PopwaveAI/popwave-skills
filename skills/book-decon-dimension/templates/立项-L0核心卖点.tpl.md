## 填写纪律

| 项 | 写法 |
|:--|:--|
| 只综合不新造 | 卖点、母题、钩子、判据都要能指回成品文件；禁止虚列条目 |
| 落在全书级母题 | 卖点必须能归到五类母题之一；禁止「引擎 × 职业」浅命名冒充 L0 |
| 不写公共库 | 本阶段**不写入**卖点方向库 / 剧情周期表，只产候选与待处理状态（与 SKILL.md 跨库口径一致） |
| 判据不留空 | 四条判据必须逐条给「过 / 不过」与回答；证据不足时写 `待扩展：{判据}（原因：本范围未覆盖）` 并如实判「不过」 |
| 部分范围 | 只覆盖部分章时，第一节与第二节标注推断性质，第四节「可撑全书」不得轻判为「过」 |
| 标题洁净 | H1 为 `L0 核心卖点` |
