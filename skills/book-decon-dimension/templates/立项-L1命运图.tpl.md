# 立项 · L1 命运图

> template_id: `proposal.l1` ｜ template_version: `1.0.0`
> 目标文件：`立项/01-L1命运图.md`
> 定位：反推的一句话命运图——世界舞台与四颗钉子，回答「这本书讲了个什么命」。**只综合已有成品，不产生新数据**（消费 `剧情库`、`角色与势力库`）。
> 契约级别：`立项/` 目录名、`01-L1命运图.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 一句话命运图 | 一句话说清：主角是谁、背着什么秘密与金手指、在什么世界、从什么处境起步、走到什么终点 | 末尾 `> 依据：` 行指向成品文件与 ch |
| 二 | 世界舞台 | 世界 / 时代背景 / 当下变局 三项 | 每项尾给依据 ch |
| 三 | 四颗钉子 | 起点 / 终点 / 最大反转 / 最大落差（各给「内容 + 干什么」） | 每颗钉尾 `（chXXX）`；落差量级紧随 🔒 |
| 四 | 覆盖范围声明 | 覆盖到第几卷、终点与反转是否已确证 | 未确证写 `待扩展：{钉子}（原因：本范围未覆盖）` |

## 模板正文

```markdown
# L1 命运图

> 覆盖范围：chXXX–YYY ｜ 篇幅状态：完整 / 部分范围

## 一、一句话命运图

{一句话。读完要有「我要看他怎么从那里走到那里」的欲望。}

> 依据：`剧情库/各卷切片.md`、`角色与势力库/主角卡.md`（chXXX）

## 二、世界舞台

| 项 | 内容 |
|:--|:--|
| 世界 | {故事发生在哪个世界} |
| 时代背景 | {和平 / 乱世 / 末世 / 变革期} |
| 当下变局 | {开幕时正在发生的那场大事或窗口期} |

## 三、四颗钉子

| 钉子 | 内容 | 干什么 |
|:--|:--|:--|
| 起点 | {主角开局的处境} | 读者代入的入口 |
| 终点 | {主角最后成了什么} | 全书的引力方向 |
| 最大反转 | {全书最深的钩子或真相} | 藏在开头、贯穿全书的悬念 |
| 最大落差 | {起点到终点的距离}🔒 | 全书养成总账 |

## 四、覆盖范围声明

- 已确证：{钉子清单}
- 未确证：{钉子}（`待扩展`）
```

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 只综合不新造 | 四颗钉子必须能指回 `剧情库` / `主角卡` 的具体条目，不虚列 |
| 与六模块一致 | 起点、终点、反转、落差与 `剧情库` 主线、`主角卡.md` 成长数据一致，不自行推翻 |
| 部分范围硬约束 | 只覆盖部分章时，**终点与最大反转一律标 `待扩展` 并如实说明未确证**，不得据同类作品补结局 |
| 🔒 | 落差量级（如位阶跨度、势力规模）标 🔒；推断值必须注明为推断 |
| 标题洁净 | H1 为 `L1 命运图` |
