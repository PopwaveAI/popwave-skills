# 角色与势力库 · 势力卡

> template_id: `cast.faction` ｜ template_version: `1.0.0`
> 目标文件：`角色与势力库/势力卡.md`（全书一份）
> 定位：把每个势力当成一个「有立场、有组织、有脾气的行动主体」写清——它对主角是敌是友、在书里干什么活。势力与人的映射在 `总表与版图.md` 收口。
> 契约级别：`角色与势力库/` 目录名、`势力卡.md` 文件名、下列一级小节骨架 = **稳定契约**；表格列名、措辞、顺序、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 势力总表 | 势力名 / 立场（敌对 / 中立 / 同盟 / 摇摆）/ 出场卷 / 与主角关系 / 在书作用 | 表格 `ch` 列 |
| 二 | 逐势力卡 | 每个势力一个三级标题，五个必填字段：势力名（别称）/ 立场 / 组织（层级、头目、编制、规模）/ 与主角关系（演变）/ 在书作用 | 每字段尾 `（chXXX）`；规模数值紧随 🔒 |
| 三 | 势力关系图（文字版） | 敌对 / 同盟 / 从属 / 交易四类关系清单，逐条给依据 ch | 每条尾 `（chXXX）` |
| 四 | 覆盖范围声明 | 已写卡数、只在总表的势力、部分范围说明 | 未写卡写 `待扩展：{势力名}（原因：本范围未覆盖）` |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 五字段不缺 | 每个势力五字段齐全；「在书作用」必须写叙事功能，不写「很重要的组织」这类空话 |
| 证据 | 立场演变与关系必须有事件依据；正文不内联 chXX |
| 🔒 | 编制、人数、层级数、控制范围标 🔒；原文未给出写「原文未展开」 |
| 部分范围 | 只覆盖部分章时，势力关系图只画覆盖范围内的关系，未覆盖关系标 `待扩展` |
| 与人对齐 | 势力名、头目与 `总表与版图.md`、盟友 / 敌人 / 配角卡一致 |
| 标题洁净 | H1 为 `势力卡`；逐势力卡三级标题带势力名 |
