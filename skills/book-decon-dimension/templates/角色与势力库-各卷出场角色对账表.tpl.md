## 填写纪律

| 项 | 写法 |
|:--|:--|
| 权威源不可替换 | 逐卷名单只能从 L1 批次档案聚合，禁止拿别的角色卡反推名单（否则漏人查不出来） |
| 逐卷不漏 | 覆盖范围内每一卷都要有一节；部分范围时末节声明覆盖止点 |
| 结论可核 | 「卡内是否有条目」必须实查对应卡文件后填写，不得凭印象 |
| 缺卡处置 | 查出缺卡时，先在第四节登记，再回补对应卡；本表不代替卡 |
| 🔒 | 本文件一般不承载量化；若引用数值（如某角色本卷等级）则紧随 🔒 |
| 标题洁净 | H1 为 `各卷出场角色对账表`；逐卷三级标题带卷号卷名与章范围 |
