## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 单一来源 | 本表是角色与势力的**汇总视图**，逐人细节在各自的卡里；本表不重复写性格与事件 |
| 卡位固定 | 卡位只允许「主角 / 盟友 / 敌人 / 配角」四值；不确定时归配角并标 `待扩展：卡位待定` |
| 卡文件真实 | 「卡文件」列必须是真实存在的文件路径；未写卡的人写 `待扩展：{人名}（原因：未写卡）`，不指向不存在的文件 |
| 证据 | 首次出场必须是可回溯的 ch；正文不内联 chXX |
| 部分范围 | 第四节必须显式声明；未覆盖卷的人可以进总表，但必须标出覆盖止点 |
| 标题洁净 | H1 为 `总表与版图` |
