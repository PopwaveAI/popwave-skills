# 角色与势力库 · 敌人卡

> template_id: `cast.enemy` ｜ template_version: `1.0.0`
> 目标文件：`角色与势力库/敌人卡.md`（全书一份）
> 定位：敌人不按出场顺序堆，按**威胁梯度**分层写——读者与写手都要能一眼看出「这一档敌人压了主角多久、靠什么压、怎么被处理掉」。
> 契约级别：`角色与势力库/` 目录名、`敌人卡.md` 文件名、下列一级小节骨架 = **稳定契约**；梯度名、表格列名、措辞、示例 = **可变细节**。

## 一级小节骨架

| # | 一级小节 | 必填字段 | 证据行 / 🔒 落位 |
|:-:|:--|:--|:--|
| 一 | 威胁梯度分层总表 | 梯度层级（从低到高，如 街头 → 野外 → 邪教 → 领地 → 超凡；梯度名可按本书改写，层数按本书实际）/ 该层敌人名单 / 出场卷 / 威胁量级 | 表格 `ch` 列；威胁量级数值紧随 🔒 |
| 二 | 逐敌卡 | 每位一个三级标题，三个必填字段：登场（身份、场合 ch）/ 威胁（压了主角什么、压了多久）/ 结局（被灭、收编、未解，附 ch） | 每个字段尾挂 `（chXXX）` |
| 三 | 梯度口径 | 分层依据、层与层之间的跃迁条件、与力量体系位阶的对应关系 | 引用 `力量与战斗/力量体系.md` 位阶名 + ch |
| 四 | 覆盖范围声明 | 已写卡数、只在总表的敌人、部分范围说明 | 未写卡写 `待扩展：{敌人名}（原因：本范围未覆盖）` |

## 模板正文

```markdown
# 敌人卡

> 覆盖范围：chXXX–YYY ｜ 篇幅状态：完整 / 部分范围

## 一、威胁梯度分层总表

| 梯度 | 层名 | 敌人名单 | 出场卷 | 威胁量级 | ch |
|:-:|:--|:--|:--|:--|:--|
| 1 | {最底层，如街头} | {名字} | 卷1 | {量级，如单人恶棍}🔒 | chXXX |
| 2 | {…} | {名字} | 卷1–2 | {量级}🔒 | chXXX |

## 二、逐敌卡

### {敌人名}（梯度 {N}｜{层名}）

- 登场：{身份、所在势力、首次冲突场合}（chXXX）
- 威胁：{他拿什么压主角、压了主角多久、主角为什么一时解决不了}（chXXX）
- 结局：{被灭 / 收编 / 转为盟友 / 未解}（chXXX）；未写结局写「未解（至 chXXX）」

### {下一个敌人名}

- {同上三字段}

## 三、梯度口径

- 分层依据：{按力量档、按势力规模、按压迫范围}
- 跃迁条件：{主角到哪一档才打得动下一层}
- 与位阶对应：{梯度 ↔ `力量体系.md` 位阶名}（chXXX）

## 四、覆盖范围声明

- 已写卡：{敌人清单}
- 仅在总表：{敌人清单}（`待扩展`）
```

## 填写纪律

| 项 | 写法 |
|:--|:--|
| 三字段不缺 | 每位敌人三字段齐全；威胁必须写「压了多久」，不能只写「很危险」 |
| 证据 | 登场、威胁、结局三处都要挂 ch；正文不内联 chXX |
| 🔒 | 威胁量级、位阶、数量标 🔒；原文未给出写「原文未展开」 |
| 部分范围 | 只覆盖部分章时，第三节口径照写，第二节只写覆盖范围内的敌人并标明覆盖止点 |
| 梯度命名 | 默认沿用「街头 / 野外 / 邪教 / 领地 / 超凡」五层；本书实际层数不同时按实际改，层数与层名属可变细节 |
| 标题洁净 | H1 为 `敌人卡`；逐敌卡三级标题带姓名与梯度，不加格式后缀 |
