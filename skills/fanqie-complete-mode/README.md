# fanqie-complete-mode

番茄完本模式专用 overlay，叠加在 `pop-snow-*` 结构骨架上。

## 文件

- `SKILL.md`：模式契约、必读路由、硬约束。
- `references/genre-fit.md`：赛道诊断与 30 万字可行性。
- `references/golden-three.md`：黄金三章、前 300 字爆点、前 1/3 爽点。
- `references/hook-and-reversal.md`：章末钩子五型、翻转公式。
- `references/emotion-and-payoff.md`：三章一循环、爽点五形态、30 万字节奏。
- `references/quality-gate.md`：批末四块报告、质量清单、完本包。
- `references/pipeline.md`：阶段路由、两条 goal、状态字段、goal.create 边界。

## 校验

```bash
npm run skills:validate
```
