# 黄金三章与开篇

番茄读者划走一本书只要几秒。前三章决定他留不留，前 300 字决定他点不点下一章。

## 黄金三章

| 章 | 任务 | 判据 |
| --- | --- | --- |
| 第 1 章 | 抛出核心冲突 | 主角当场遇到一件不可逆的事，状态变了 |
| 第 2 章 | 亮核心设定／金手指／替代驱动 | 读者看懂这本书“凭什么不一样” |
| 第 3 章 | 第一次小爽点 ＋ 短期目标 | 读者拿到一次兑付，知道接下来要看什么 |

没有金手指的题材，第 2 章写“替代驱动”：靠什么让读者追下去。不能两样都没有。

## 前 300 字：一个爆点

爆点＝当场就懂、但当场解释不了的事实。读者反应是“啊？”，不是“哦”。

四型任选：

| 型 | 是什么 | 例 |
| --- | --- | --- |
| 矛盾同框 | 两个各自成立、放一起冲突的事实 | 表是温的，可她说她爸上个月就走了 |
| 能力现形 | 主角的独特之处当场露一次头，不解释 | 他手一碰表，手一抖，把表推了回去 |
| 代价前置 | 先把已经付出、收不回的代价摆出来 | 他右手食指侧面那层薄茧 |
| 倒计时 | 一个已启动、有期限、此刻在场的威胁 | 量铺子的卷尺搭在柜台上，三天后动工 |

注意：需要后文背景才能理解的“异常”是伏笔，不是爆点。

## 前 1/3：一个爽点

爽点＝读者想要的事发生了。五选一为主：

| 形态 | 首章兑现判据 |
| --- | --- |
| 碾压 | 主角当众用一次别人没有的手段，旁人反应可见 |
| 信息兑付 | 主角看穿了，并且当场说出口 |
| 认可 | 有人因为主角做的事，改变了对他的对待 |
| 关系兑付 | CP 当场做出一个可指认的动作：来了、喊了名字、留下东西、没走 |
| 整活兑付 | 主角做出一个离谱但成立的做法，至少一个人当场被整到 |

信息兑付类只看穿不说＝零爽点。

## 主角主动行动

全章至少 1 次“别人没要求、主角自己决定要做”的行动。全章被别人推着走，读者会觉得什么都没发生。

## 开篇六雷

| 雷 | 为什么 |
| --- | --- |
| 天气开场 | 没有事件，只有氛围 |
| 睡醒开场 | 网文十大毒点之首 |
| 照镜子写外貌 | 自恋式描写 |
| 简历式介绍 | 没有张力 |
| 世界观说明 | 信息倾倒 |
| 日常流水账 | 没有冲突 |

天气可以作氛围，但不能当首句；首句要是一个动作或一个具体物件。

## 开篇 50 字三版

给三个版本，供作者选型：

| 版本 | 写法 |
| --- | --- |
| 强冲突 | 这本书里最早发生的那件“不对劲的事”，从它开始写 |
| 强反差 | 把主角“有什么”和“要什么”之间最刺眼的矛盾压进一句 |
| 强情绪 | 先给主角已经付出、收不回的代价 |

50 字版是选型稿，不是正文首段。正文首段必须“做出来”，不能把能力声明、规则说明直接搬进去。

## 第 1 章检查

- 前 300 字有 1 个爆点。
- 前 1/3 有 1 个爽点。
- 主角主动行动 ≥1 次。
- 没有开篇六雷。
- 章末有钩子，且钩子强度不低于下一章。
