# 批末质检与完本包

## 批次报告四块

1. **本批写了什么**：章节范围、核心事件、兑付物。
2. **主线推进到哪**：主角目标、对手、伏笔、关系变化。
3. **发现的问题**：重复桥段、逻辑断裂、人物不一致、节奏塌陷、AI 味。
4. **下一批计划**：章节范围、要兑现的爽点、要埋/收的伏笔、风险。

## 质量清单

正向五条：

- 题材切入、开篇事件或人物设定有创新性，能快速激发好奇。
- 三观正向、立意深刻，自然融入故事，不大段说教。
- 文笔清晰流畅。
- 结构完整、主线清晰、节奏稳定，有延展潜力。
- 每章有钩子，钩子类型轮换。

反向五条：

- 粗制滥造。
- 逻辑混乱。
- 结构失常。
- 内容空洞。
- 刻意灌水。

## 单章检查

| 项 | 判据 |
| --- | --- |
| 字数 | 2000-2500 字；按题材档位 |
| 章末钩子 | 五型之一，且与上一章不同型 |
| 主动行动 | 主角至少 1 次主动行动 |
| 兑付物 | 本章读者拿到了什么，推翻了哪个旧理解 |
| 承接 | 逐句问：有信息吗、接得上吗、指得清吗、对得上吗 |
| 重复 | 相邻章不得出现同一桥段、同一钩子型、整段复述 |
| AI 味 | 不用“此外/然而/值得注意的是”等 AI 高频词；长短句交错 |

## 去 AI 味

- 词表与改法见 `fanqie-write/references/ai-flavor.md`。
- 需要工具时用 `pop-ai-reduce-lite`，只在批末或用户点名时跑。
- 不承诺通过朱雀等检测。

## 完本包

```text
正文/            全部章节
章纲/            全部章纲
剧情日志/        每章日志 + 全书日志
立项/            立项卡、黄金开篇、人物、世界观
目标/spec.md     规格书
验收/verify.mjs  冻结脚本
质量报告.md      批次汇总、问题清单、完本结论
书名封面清单.md  非默认书名、封面、简介、标签检查项
```

完本包不承诺签约、流量、稿费；只保证按验收脚本写完、写全。
