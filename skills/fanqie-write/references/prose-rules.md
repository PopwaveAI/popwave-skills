# 番茄正文规则

## 字数与分段

- 单章 2000-2500 个汉字。少于 1800 或高于 2800 视为不合格。
- 叙事段 40-120 字；对话段可短。不得整章都是 10 字以内的碎句；也不得连续三段超过 200 字。
- 一段只讲一件事。场景切换另起一段。

## 开头

前 120 字至少出现一项：主角的欲求、反常事件、压力、反馈、主动动作。

禁止：天气开场、睡醒开场、照镜子写外貌、简历式介绍、世界观说明、日常流水账。

## 场景

- 每章 3-6 场。每场写清：谁想要什么、谁挡着、发生了什么、局面变了什么。
- 每场至少一个具体动作或物件，不写纯氛围。
- 场景之间要有过渡：姿态、空间、取物、时间跳转，不能跳。

## 人物

- 每个出场人物有“本章在场理由”；没有理由的不进画面。
- 对白遮住名字也能分辨谁在说话：称呼、句长、语气、禁忌不同。
- 行为由欲望、恐惧、利益、压力推出；不能只靠“剧情需要”。

## 爽点

- 碾压：当众、有人看见、对手反应具体。
- 信息兑付：主角看穿了，并且说出口。
- 认可：具体得失，例如第一笔钱、有人点名、日子量得出的变化。
- 关系兑付：一个可指认的动作，例如来了、喊了名字、留下东西、没走。
- 整活兑付：一个离谱但成立的做法，至少一个人当场被整到，局面更乱。

## 章末

- 钩子五型：A 信息差、B 危机逼近、C 关系转折、D 规则异常、E 认知颠覆。
- 相邻章不同型；强度不低于上一章。
- 写到八成留一成，不要一章把问题全部解决。

## 禁止

- 大纲腔：不把章纲里的“功能位”“兑付物”“情绪坐标”写进正文。
- 分析腔：“核心动机”“信息边界”“利益最大化”不进正文。
- 替读者下结论：不写“他明白了”“她意识到”，用动作让读者自己明白。
- 金句、元叙事、编剧脚注。
- 同一细节重复描写；同一事实前后矛盾。
- 半角引号、破折号滥用、连续均匀长句。

## 写后自检

1. 这一章有几件事？少于 2 件，回章纲补事件。
2. 每场冲突是什么？写不出，删场或重排。
3. 主角主动做了什么？没有，补一个主动动作。
4. 章末钩子是哪一型？和上一章同型，换。
5. 读者拿到什么？说不出来，回章纲补兑付物。
