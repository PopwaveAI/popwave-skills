# fanqie-writer v1.29.45（番茄小说写作技能）

为「番茄小说」平台写长篇连载的创作技能。

## 能做什么

- **两种进入方式**：① **从零立项**——选题 → 大纲 → 人物 → 情绪曲线 → 黄金开篇 → 章节细纲 → 正文；② **接续已有项目**——项目里已有大纲／细纲／人设，甚至正文已经写了若干章，说一句「续写第 X 章」就接着往下写，**不重新立项、不重做已交付件**。
- **四批交付闸门**：`00-大纲`＋`01-人物档案`＋`02-情绪曲线`＋`03-黄金开篇` → `04-章节细纲` → 第 1 章正文 → 第 2 章起连续写。**分批交付、不跳批**。
- **交付物 7 件**：每件的读者都是「人」，配套「交付前自查词表」硬门禁——技能路径、工序话术、内部编号、占位残留一律不得出现在交付文件里。
- **平台向写法**：情绪标签驱动、黄金开篇三版锻造、爆点与爽点分布、章末悬念钩子、评论区诱导、质量评分。
- **本地门禁脚本**：字数区间与逐场配额、格式归一、确定性错误机检、钩子轮换校验、触发面校验（详见 `scripts/`）。

> **包内信息**：会随包发出的文件（`README.md`／`SKILL.md`／`skill.json` ＋ `references/`／`templates/`／`scripts/`／`assets/`）里，不含开发期内测样本的书名、角色名与私有项目名。打包脚本每次都会自动扫描，**不通过则包生不出来**。

## 目录结构

```
fanqie-writer/
├── SKILL.md          # 主流程：已知边界 / 接续模式 / 四批交付闸门 / 写前必读 / 交付前自检
├── README.md         # 本文件
├── skill.json        # 入库清单（版本 = 1.29.45，稳定号段）
├── references/       # 参考文件（题材包 / 套路库 / 情绪模板 / 文笔规则 / 平台硬信息等）
├── templates/        # 模板（大纲 / 细纲 / 人物 / 情绪 / 章节 / 写作规则 / 记忆 / 拆书）
├── scripts/          # 脚本（字数真源与解析 / 字数校验 / 配额 / 格式归一 / 门禁与风格画像 / 触发面校验等）
└── assets/           # 卷级规划模板
```

## 上传到仓库

1. 解压本 zip，得到 `fanqie-writer/` 目录。
2. 把整个 `fanqie-writer/` 目录（含子目录）上传到仓库约定位置，**覆盖旧版**。
3. 不要只上传 SKILL.md —— references / templates / scripts 是运行必需依赖。

## 安装使用

把 `fanqie-writer/` 整个目录放到 `~/.workbuddy/skills/` 下，新开对话用 `/fanqie-writer` 调用。
**已有半本书时**：说「续写第 X 章」并给出项目路径（技能找不到会主动问）。
**给一份粗大纲时**：说「这是我大概的大纲，按番茄平台写成书」。
