# 番茄题材包（genre-packs）

> 定位：能力 3「题材研究」的落点资产。回答"这个题材的读者点进来想看什么、什么必须出现、爽点该在第几章给、什么一写就掉量"。
> 用法：1.1 六问定下题材后**必读对应小节**，再进 1.2 提示词补全；写作过程中每开新卷/新单元回看一次。
> 数据基准：番茄平台读者结构——男女约 50:50，**45 岁以上用户占 45.7%**（约 1.21 亿），免费阅读 + 广告分成模式。这两条决定所有题材的写法偏向：**表达直白、情绪优先、不依赖圈层梗、不做文艺留白**。

## 使用规则

1. **1 主题材包 + ≤2 副题材包**（2026-09-21 修正——原为"主题材包 + 副题材包"两包，三包并至时无规则可依）：
   - **主包**（唯一）：决定「必备元素」与「爽点节奏」——这是本书的骨架；
   - **第一副包**：取「开篇雷区」+ 该包对人情／关系的处理方式；
   - **第二副包**（仅在确有第三类题材时）：**只取"与本作正面冲突的项"**——例如穿越包的「信息差优势」对日常生活流是雷区，须明确禁用；
   - **三包冲突时以主包为准**，并在 `00-大纲.md` 与 1.3.5 自检第 6 条写明"用了哪几包、各取什么"；
   - 主副判定：按**读者进分类页时第一眼归到哪一类**定主包（如"穿越 + 种田 + 古代人情"，读者先看到"种田"→ 主包＝种田/日常流）。
2. **番茄是题材驱动平台**：读者在分类页按题材找书，题材选错比书写差更致命。1.1 六问的题材项若与市场风向明显背离，按 `market-trends.md` 提示风险，但不替用户改。**六问第 2 问的选项已与本文件的 10 包同坐标**（2026-09-21 对齐），选完直接对照同名包。
3. **"必备元素"缺一即失格**：这类元素是读者进入该题材的最低预期，缺了会被直接划走，且评论区会点出来。**但"缺"的前提是它对本作适用**——第 4 包已拆为两型（见下），换场型穿越不适用"改命型"的必备元素，不得据此误判失格。
4. **与情绪标签的映射（2026-09-21 新增）**：本文件 10 包与 1.1 第 1 问的情绪标签不是一一对应，常用映射如下——第 5 包（年代文）、第 10 包（种田/日常）→ **现实奋斗·生活流**（爽点形态＝认可类）；第 9 包（系统流）、第 10 包的空间/养娃变体 → 脑洞大开；第 4 包 4-B 换场型 → 治愈甜宠 或 现实奋斗·生活流；第 1 包（都市现实）→ 打脸爽文（若走生活向则归现实奋斗）；**第 2 包（现代言情）、第 3 包（古代言情）→ 关系兑付类**（2026-09-22 女频验证新增的第四类爽点形态，判据＝读者想要的那句关系确认落在一个**可指认的动作**上。**言情不要挂"认可类"或"信息兑付类"**——认可类的判据是"手艺被认可／日子可测量地变好"、信息兑付类的是"主角当场说出改变他人判断的话"，两者在言情里**逐项对不上**，2026-09-22 实测）。**选定后两处必须自洽**：`00-大纲.md` 第 1 节的「情绪标签 + 爽点形态」须能推出本包给的「爽点节奏」。

## 1. 都市现实（战神 / 赘婿 / 医武 / 神豪）

| 栏 | 内容 |
|----|------|
| **读者期待** | 被轻视的底层身份 + 藏着的实力，在众人面前一次翻盘。要的是"当众"与"身份反差" |
| **必备元素** | ① 前 3 章内一个**当众羞辱场景** ② 主角的"隐藏身份或隐藏能力"（读者知道、场上人不知道） ③ 一个明确的敌对家族/公司/集团 |
| **爽点节奏** | 第 2 章兑现**第一个小打脸**；第 5-8 章第一次身份揭露；此后每 15-20 章把对手量级抬一档（小混混 → 公司 → 家族 → 集团 → 隐世势力） |
| **开篇雷区** | 用"十年前……"回忆开篇；让主角先受 3 章以上憋屈再反击（免费阅读读者没有耐心额度）；打脸对象是无名路人（没人在乎） |
| **反套路要点** | 把"隐藏身份"从外挂改成**负担**——一曝光反而害了想护的人。身份从爽点变痛点，长线张力自己就出来了 |

## 2. 现代言情（甜宠 / 虐恋 / 追妻火葬场 / 萌宝）

| 栏 | 内容 |
|----|------|
| **读者期待** | **情绪浓度**。要么甜到齁，要么虐到哭。中间态（不甜不虐的文艺恋爱）在番茄最危险 |
| **必备元素** | ① CP 对象前 3 章内出场 ② 一个**可归因的障碍**（阶级/家庭/职业冲突，不能靠误会） ③ 女主有独立动机，不是纯等待 |
| **爽点节奏** | 每 3 章一个情绪高峰；虐恋流的"觉醒/离开"必须在中点前完成（约全书 30% 处）；追妻流的"悔"要用**行动**兑现，不是道歉台词 |
| **开篇雷区** | 女主的全部价值由男主定义；冲突全靠"误会 + 不解释"；男主的渣没有可理解的动机（读者会骂掉追读） |
| **"合理沉默"与"误会梗"的分界（2026-09-22 女频验证补）** | 言情最核心的张力常是"两人都不说"，与上一条雷区**外观相同**。**三条判据全过才算好戏，缺一即雷**：① **动机**：沉默方有一个具体的、与他处境相称的理由（不是"懒得解释"）；② **代价**：沉默让他自己也在失去某样东西（只有对方难受＝虐读者，不是拉扯）；③ **期限**：**中点（约全书 30% 处）之前必须给读者一个可理解的原因**——可以让**另一方**不知道，但**不能让读者**不知道，否则读者把它读成"作者在拖"。 |
| **反套路要点** | 让男主的后悔发生在**女主已经不需要他之后**——追妻火葬场的爽点不在复合，在他追不上 |

## 3. 古代言情（宫斗 / 宅斗 / 替嫁 / 侯门）

| 栏 | 内容 |
|----|------|
| **读者期待** | 规矩之下的暗斗 + 身份逆转 + 女子的处境感。**器物与规矩细节是这类型的长板**，也是它比现代言情更耐读的原因 |
| **必备元素** | ① 一套清晰的等级秩序（谁管谁、什么错会死） ② 一个"上面的人"作为靠山或威胁 ③ 具体到吃食/衣料/称谓/请安的物质细节 |
| **爽点节奏** | 每 3-5 章一次"**规矩之内**的反击"（不越规矩的赢比硬闯更爽）；晋位/掌权每 20-30 章一阶 |
| **开篇雷区** | 娘家的委屈铺垫超过 3 章；大段介绍家族关系表（读者记不住）；用现代思维直接碾压对手（显得无脑且破坏质感） |
| **反套路要点** | 让正妻/嫡母/婆母**有自己的困局**——对手也是同类，她们也在被规矩困住。这一条做过（见《南味入京》索绰罗氏线），效果比工具人反派好得多 |

## 4. 穿越重生（历史架空 / 权谋）

> **本包分两型，先判型再用**（2026-09-21 未覆盖路径验证补入）。原包只覆盖「改命型」，而"穿到某个地方过日子、不改命不复仇"的**换场型**照原包对照会**误判失格**（原包必备元素③「前世导致失败的错判」对换场型本来就不适用）。
> **判型问法**：主角有没有前世、有没有要报的仇、有没有要改的命？（有 → 4-A；只是换了个世界生活 → 4-B）

### 4-A · 改命型（重生复仇 / 权谋反杀 / 扭转前世败局）

| 栏 | 内容 |
|----|------|
| **读者期待** | 信息差优势 + 改命。核心快感是"我知道将来会发生什么" |
| **必备元素** | ① 明确的重生锚点（回到哪一刻） ② "能改 / 不能改"的规则 ③ **前世导致失败的错判**（这是故事的心脏，没有它重生就只是作弊器） |
| **爽点节奏** | 第 1-3 章立刻用信息差解决一个前世踩过的坑；每 10-15 章用一次前世记忆预警；每 30-40 章一次"命运明显改道" |
| **开篇雷区** | 记忆变成万能外挂（没代价＝没悬念）；前世交代超过 500 字；重生后的处境与前世的连接交代不清（读者不知道他为什么这么恨某个人） |
| **反套路要点** | 让信息差**逐渐失效**——改变了未来，记忆就不准了。这是这类型天然的长线张力，比"记得更多"高级 |

### 4-B · 换场型（穿到某处过日子 / 换环境重新开始）

> 常见组合：「穿越 + 种田日常」「穿越 + 古代人情」「穿越 + 治愈」——这三类**爽点形态通常是认可类**。
> **⚠️ 但形态不由本包钉死（v1.29.2 校准）**：4-B 只规定"换场、靠站住"这件事，**它不决定爽点形态**。形态一律由 `SKILL.md` 1.1 的判定表按**第 1 问情绪标签 ＋ 第 4 问反差点**定。
> **反例（2026-09-24 实测）**：`穿越重生 4-B × 爆笑反套路` 样本《BGM 一响，全江湖都得跟着晃》——落点同样是"换场 + 被按在最低位次"，但形态是**整活兑付类**。原包"爽点形态＝认可类"的死写法会让执行者照着认可类取库，**取错库**；且与 1.1 判定表（标签＝爆笑反套路 → 整活兑付类）**构成两份真源打架**。

| 栏 | 内容 |
|----|------|
| **读者期待** | **落差与适应**——带着另一套常识的人落在完全陌生的规矩里，靠"过日子"一点点站住。快感不是碾压别人，是**看着她把陌生的地方过成自己的地方** |
| **必备元素** | ① **换场的落点与落差**（穿到谁身上、那个身份有多低、她与原世界差多远） ② **她与原世界的关系如何处理**（回不去 / 不想回 / 留一条断线——这是长线情绪的来源） ③ **一个"必须靠自己站住"的处境**（无可依靠，只能拿会的那点东西换位置） |
| **爽点节奏** | **形态为认可类时**（本包最常见，也是本栏原文默认的情形）：不套"信息差预警"，改为**每 5-10 章一次"她做的东西被人认下来"**；每 25-30 章一次生活层级跃升（帮工→主事、借住→有自己的门面）。**⚠️ 形态为其余四类时本栏不适用**——节奏按该形态对应的模板走（v1.29.2） |
| **开篇雷区** | ① **把"穿越"本身当卖点写**（穿越不是卖点，落差才是） ② 用现代知识碾压同代人（既掉质感，又毁掉"适应"这个看点） ③ 原世界的回忆插叙超过 300 字（读者不关心她原来的世界，只关心她现在的落脚点） |
| **反套路要点** | 让"回不去的原世界"成为**她主动放弃**的选项，而不是一辈子的遗憾——她最后把陌生地方过成家，比"如果还能回去"有力得多 |

## 5. 年代文（六七十年代 / 八九十年代）

| 栏 | 内容 |
|----|------|
| **读者期待** | 匮乏年代的生活质感 + 邻里人情 + 一点点攒起来的家底。番茄 45 岁以上读者对本类型有真实生活记忆 |
| **必备元素** | ① **年代物质细节**（票据/粮食/工厂/下乡/工分）——这是可信度命门 ② 明确的"家底起点"（多穷、缺什么） ③ 家族内部的对立关系（偏心/重男轻女/过继/后娘） |
| **爽点节奏** | 靠"过日子"攒出**可见**的成绩（第一笔钱 / 第一间房 / 孩子上学 / 被邻里认可）；每 20-30 章生活水平上一个台阶 |
| **开篇雷区** | 年代细节造假（这批读者极度在意，写错一件就掉信任）；用现代观念直接批判那个年代（评论必吵，风险高）；金手指过强（超自然能力会毁掉生活质感） |
| **反套路要点** | 金手指限死在**生活知识**（吃食做法 / 账目 / 人情世故 / 器物审美），不给预知、不给异能——这正是《南味入京》的设定逻辑 |

## 6. 玄幻修真

| 栏 | 内容 |
|----|------|
| **读者期待** | 升级体系 + 变强快感 + 境界碾压。**体系本身是卖点**，读者会研究它 |
| **必备元素** | ① 清晰的境界阶梯，**前 10 章内亮出** ② 明确的资源获取路径（丹药/秘境/传承/买卖） ③ 一个当下打不过但必须打的对手 |
| **爽点节奏** | 第 3 章内第一次越级打脸；每 10-20 章突破一个境界；每卷末一次"当众证明自己" |
| **开篇雷区** | 开局堆设定（一次罗列 20 个境界名）；天赋废柴却获传承而不解释（读者会问"凭什么是你"）；宗门/家族说明单次超 200 字 |
| **反套路要点** | 让"变强"有代价（寿命 / 情感 / 记忆 / 人性），升级不只是加数字。体系有了成本，才有张力 |

## 7. 武侠仙侠

| 栏 | 内容 |
|----|------|
| **读者期待** | 江湖道义 + 门派恩怨 + 一人一剑的爽感。侠气比战力更重要 |
| **必备元素** | ① 一个明确的身份污点或师门恩怨 ② 一套有**限制**的武学逻辑（内力有限、招式有破） ③ 一个"该不该管"的选择（这是侠与强的分界） |
| **爽点节奏** | 前 3 章一场**以弱胜强**的打斗；每 15-20 章一次门派级冲突；每卷末一次道义上的抉择 |
| **开篇雷区** | 打斗没有空间感（读者不知道谁站在哪、相距多远）；招式名堆砌而无实质动作；侠客满口现代网络语（破气质） |
| **反套路要点** | 让主角的"义"带来**实际损失**——好人不必每次都有回报，这才是江湖。次次善有善报等于没江湖 |

## 8. 悬疑推理 / 惊悚

| 栏 | 内容 |
|----|------|
| **读者期待** | 细思极恐 + 解谜快感 + 反转。番茄爆款案例《十日终焉》即是此型（首句即钩子） |
| **必备元素** | ① 第一章一个**无法解释**的事件 ② 一条可追踪的线索（读者能跟着猜） ③ 一个"读者比主角多知道一点"的信息差 |
| **爽点节奏** | 每 3-5 章给一个小答案（但引出更大问题）；每卷一次大反转；**答案必须在前文埋过线**，没埋就是作弊，评论区会扒 |
| **开篇雷区** | 用超自然力量兜底解释（读者会有被骗感）；线索只藏在作者心里不写出来；惊悚靠血腥场面堆（平台审核也压这类） |
| **反套路要点** | 让"真相揭示之后主角怎么选"比真相本身更重要——悬念解决，人性问题才刚开始 |

## 9. 系统流 / 无限流

| 栏 | 内容 |
|----|------|
| **读者期待** | 规则感 + 用规则玩出花 + 层层升级的任务。读者爱研究规则漏洞 |
| **必备元素** | ① 前 3 章明确系统规则（能做什么 / 不能做什么 / 代价是什么） ② 一个失败惩罚 ③ 一处"规则漏洞被主角发现"的瞬间 |
| **爽点节奏** | 每个任务单元 5-10 章，单元内必含一次"利用规则反转"；每 30 章系统升级或换地图 |
| **开篇雷区** | 系统无限给奖励无代价；规则前后矛盾（读者会记账并指出）；系统人格过于话痨（抢戏且拉低节奏） |
| **反套路要点** | 系统本身是敌人或骗局——规则的最终解释权归谁，是这类型最好用的长线悬念 |

## 10. 种田 / 日常流（含美食 / 空间 / 养娃）

| 栏 | 内容 |
|----|------|
| **读者期待** | 慢下来的生活质感 + 一点点变好的踏实感。要的是"日子在往上走" |
| **必备元素** | ① 可衡量的起点（多穷 / 多难 / 缺什么） ② 一套**具体的营生**（做什么、卖给谁、赚多少） ③ 一个需要被护住的人 |
| **爽点节奏** | **认可类爽点**（不是打脸）：手艺被认可、日子可测量地变好。每 5-10 章"做出点东西"；每 25-30 章一次生活层级的跃升 |
| **开篇雷区** | **本类型在番茄最容易死**——番茄读者要强钩子，纯日常定调开篇会被划走。前 3 章必须给一个明确危机（被赶出家门 / 欠债 / 失亲 / 断粮），把"慢"放在危机之后 |
| **反套路要点** | 让过好日子的阻力来自**亲近的人**（婆家、娘家、邻里），不是外部恶人——生活流的痛点本就在人情里 |

## 跨题材通用硬约束（所有题材都成立）

| 项 | 约束 | 依据 |
