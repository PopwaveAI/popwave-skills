# 创意生成与雷同自检（idea-dedup）

> 定位：能力 2「创意思维 / 避免雷同」的落点资产。这是本技能此前**完全空白**的一块，也是"产出像骨架"的根源——技能原只有"把内容填进格子"的机制，没有"生成格子里该有什么"的机制。
> 用法：三处必用——① 阶段一选定方向后、写入 00-大纲 之前 ② 每次开新卷/新单元前 ③ 写作中发现自己"顺手在写一个熟悉的桥段"时。
> 硬规则：**本文件产出的是候选，不是结论。** 生成后必须过第四节的雷同自检，未过检的点子不得进入大纲。

## 一、五种点子生成法（可执行，非方法论空谈）

每种给"操作步骤 + 番茄语境实例"。**一次至少跑两种，产出的候选互相不重合才算有效**。

### 法一 · 换维度法（最稳，番茄最常用）
**操作**：拿一个成熟配方，只替换其中一维，其余保持——读者要熟悉感，新鲜感来自那一个变量。
**实例**：配方「战神归来 + 被岳家羞辱 + 当众翻盘」。换一维：
- 换成身份 → 回归的不是战神，是**当年被顶替了学籍的人**
- 换成羞辱场 → 不是岳家家宴，是**母校的校友会**
- 换成翻盘方式 → 不靠武力，靠**他这些年攒下的一份名单**
> 老瓶装新酒最稳，指的就是这个：**一维新、其余旧**。

### 法二 · 极端变量法
**操作**：取日常中一个可变量，推到极端，问"如果它到了极限会怎样"。
**实例**：
- 「一个人记得所有事」→ 极端 → **他记不住任何新事，只有前世记得的事清清楚楚**（重生 + 失忆双设，张力自生）
- 「小饭馆生意差」→ 极端 → **全城只有他家还开火，因为别人都跑了**

### 法三 · 跨界嫁接
**操作**：把 A 领域的机制装进 B 领域的壳。番茄读者的新鲜感大多来自这种错位。
**实例**：
- 把**宫斗的位分逻辑**装进**职场**（KPI 就是位分，汇报就是请安）
- 把**刑侦的取证逻辑**装进**宅斗**（查谁动过账簿 = 查凶案现场）
- 把**外卖平台的派单算法**装进**修真**（秘境入口按接单率分配）

### 法四 · 规则反转
**操作**：把读者对这类桥段的默认预期写下来，然后反转它。
**实例**：
- 默认：重生就要改命复仇 → 反转：**主角不想改，只想把前世没说完的一句话说完**
- 默认：隐藏身份被揭穿 = 爽点 → 反转：**身份一揭穿，他护的人立刻有危险**（见 `genre-packs.md` 都市现实的反套路要点）
- 默认：系统给奖励 → 反转：**系统记得每一次他没用奖励救人的时候**

### 法五 · 代价加压
**操作**：给已有的爽点加一个成本，成本本身就成了新的故事线。
**实例**：
- 「手艺好能赚钱」→ 加代价 → **他的手艺是跟一个不希望他做这行的人学的**
- 「能治百病」→ 加代价 → **每治一人，他忘掉对方的一件事**

## 二、候选生成：交叉矩阵与六维改造

### 2.1 交叉矩阵（B 路 / 无原文立项用）

立项需要候选时，把六问的答案填进矩阵，**每个交叉格强制产 3 条候选，再筛**。禁止只产 1 条就定案——第一条通常是脑子里最熟的那个（＝最容易撞车的那个）。

```
题材（genre-packs 的 10 个）
  × 反差点（表面摆烂实际卷王 / 社恐被迫打脸 / 被虐后觉醒反杀 / 老实人黑化 / 隐藏大佬装萌新 / 看似废柴实天赋异禀）
  × 核心冲突（生死存亡 / 查明真相 / 爱情阻碍 / 复仇雪恨 / 权力争夺 / 成长突破 / 守护保护）
  × 一个"六问外补充设定"（穿越 / 重生 / 系统 / 满级号…）
```

**筛候选的三条标准**（按顺序过）：
1. **能不能用一句话说出它跟别人的不同**——说不出来就是没差异，淘汰。
2. **这个差异能不能撑 50 章以上**——只能撑 5 章的是桥段，不是设定，降级为单元剧情用。
3. **它会不会让主角的处境变难**——只会变简单的设定＝送分外挂，没有长线张力。

### 2.2 参照重构的六维改造表（A 路拆书后专用｜remake-workflow 步骤 4）

> A 路（有参考原文）拆解完成后，按此表**逐维生成改造候选**。
> **六维必须全部有候选**——某维确实不改时，写明"此维保持，理由是 __"，不得留空。
> 每个候选必须附：**一句话差异说明 + 对全书的影响 + 代价**。禁止只列维度名不产方案（那是让用户做选择题，不是给候选）。

| # | 维度 | 改造什么 | 候选方向池 |
|---|------|---------|-----------|
| 1 | **故事类型** | 换赛道 | 悬疑 / 恐怖 / 言情 / 复仇 / 都市 / 情感 / 玄幻 / 奇幻 / 重生 / 穿越 / 科幻 |
| 2 | **时代背景** | 换时空 | 古代 / 架空 / 民国 / 现代 / 未来 / **平行时空** |
| 3 | **人物关系** | 换关系结构（**差异产出最高的一维**） | 主角与对手**身份对调** / 亲属关系改写 / 权力位次置换 / 增加或抽掉一个中间人 |
| 4 | **人物设定** | 换人物本身 | 性别 / 职业 / 来历 / 性格底色 / 缺陷 |
| 5 | **情节走向** | 换事件链 | 关键事件替换 / 结果反转 / 动机对调 |
| 6 | **情节设定** | 换机制与节点 | 金手指形式 / 核心规则 / 关键道具 / 两难点位置 |

**用法**：先在**维度 3（人物关系）**上试——**把主角与对手的位置对调**，往往一个动作就能让整本书脱开原作的影子，且不必改任何结构。一维不够用时再叠加维度 2（时代背景）或 1（故事类型）。

**与 SKILL.md 1.0 A③ 的关系**：A③ 的"人物 / 事件 / 名词 / 设定"四维＝本表 4/5/6 维再加一个名词层面。**本表补足了它缺的三维**（故事类型 / 时代背景 / 人物关系）与"候选必须带影响与代价"的要求——这三维是差异产出最高的部分。

**生成后立即过第四节三道雷同自检关**，未过不得进大纲。

## 三、生成结果的三种去向

| 结果 | 处理 |
|------|------|
| 能撑全书 | 升级为**核心设定**，写进 00-大纲「作品基因」并加规则与限制 |
| 只能撑一段 | 降级为**单元剧情**，放进节奏蓝图的某个情绪单元 |
| 与已有设定冲突 | 记录到 `00-大纲.md`「作者决策」区，说明取舍理由（不要默默丢弃，后续可能回用） |

## 四、雷同自检（三道关，未过不得进大纲）

### 关一 · 与热门书撞车检测
逐项对照，**三项以上相同即需改造**：

| 对照项 | 说明 |
|--------|------|
| 开篇场景 | 主角第一次出场在做什么（被赶出家门 / 婚礼被拦 / 车祸醒来…） |
| 第一个冲突类型 | 谁在什么时候因为什么羞辱/威胁主角 |
| 金手指形式 | 系统 / 传承 / 记忆 / 异能 / 无金手指 |
| 主角身份反差的揭开时机 | 第几章、什么场合 |
| 书名与简介的承诺句式 | 是否与在榜书的句式高度相似 |

改造手段优先用**法一换维度法**（只换一维，保持可读性）。

### 关二 · 与自己的书撞车（本技能独有，防止越写越像自己）
开新单元前，检索 `.learnings/PLOT_POINTS.md`：
- 本次要用的**冲突类型**过去出现过几次？（第 3 次以上，读者会开始预判）
- 本次要用的**解决方式**是不是又靠同一个金手指？（连续 3 次同解＝套路疲劳）
- 本次的**对手类型**是否与前一个单元同构（都是仗势欺人的长辈 / 都是误会型障碍）？
命中任一项 → 回到第二节矩阵重新生成，或按第五节表的反转方向改造。

### 关三 · 桥段新鲜度评分（交付前自查，每项 0-2 分）

| 项 | 0 分 | 1 分 | 2 分 |
|----|------|------|------|
| 开篇场景 | 与在榜书同场景 | 同类型不同场景 | 想不出谁写过 |
| 主角的解法 | 靠金手指硬解 | 靠信息差 | 靠只有他会的东西 |
| 冲突的起因 | 路人挑事 | 利益冲突 | 双方都认为自己是对的 |
| 反转位置 | 章末例行反转 | 意料之中的反转 | 读者会往回翻前文找线索的反转 |

**≥6 分可进大纲；4-5 分需改造一处；≤3 分重做。**

### 关四 · 生态位查重（2026-09-21 新增——前三关查不出来的一类撞车）

> **为什么前三关不够**：关一查热门书撞车、关二查单元内的桥段复用、关三查开篇与解法的写法——**三关都是"桥段级"的**。
> 而最常发生的自我撞车是**生态位重叠**：桥段完全不同，可读者一看就会说"这不就是那本吗"。
> 2026-09-21 实测：一本"古代 + 过日子 + 生活知识型金手指 + 在灶台边讨生活的外来者"的新立项，与库内已有的《南味入京》**四元组三项相同**，
> 而前三关**全部放行**（书名不同、桥段不同、新鲜度 8/8）。这正是关四要拦的类型。

**查法**：把**本项目库里已有的作品**与本次立项，各写成一个**四元组**，逐项比对：

| 元 | 问法 | 例 |
|---|------|-----|
| 题材 | 读者进分类页会归到哪一类？ | 古代言情 / 种田日常 / 年代文 |
| 情绪标签 + 爽点形态 | 靠什么爽？ | 治愈甜宠 · 认可类 |
| 金手指类型 | 主角凭什么？ | 生活知识型（无预知、无异能） |
| 主角身份起点 | 他从哪开始？ | 在最普通的灶台边讨生活的外来者 |

**判定**：四元组 **≥3 项相同 → 生态位重叠**，必须至少换一项（优先换「**主角身份起点**」或「**金手指类型**」——这两项最能拉开读者观感）。**≥3 项相同仍要照写，须在此写明理由**，并接受"两本书互为竞品"。

## 六、番茄特有风险：结构性雷同

平台官方把「结构失常」列为四类低质违规之一，专查**模板化拼接、句式重复堆砌**。这不只是"桥段别抄别人"的问题，还包括**你自己的章节之间不能长得一样**：

- 连续章节的段落骨架重复 <30%（`scripts/chapter_stats.py` 有量化项）
- 章末钩子类型必须轮换，不得连续同型（见 `hook-techniques.md` 轮换规则）
- 每章开头不得都用同一句式起手（如"XX 睁开眼"连续出现三次即触发判定）

**这条是技能层面的自检，写后处理阶段必跑，与"点子新不新"同等重要。**
