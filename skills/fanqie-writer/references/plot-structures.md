# 爽文情节结构参考

经典的爽文情节套路和节奏设计参考。

> **适用范围（2026-09-21 补，2026-09-22 升级为四库，2026-09-23 扩为五库）**：本文件现含**五套剧情配方库**，按爽点形态取用——
>
> | 爽点形态 | 用哪一节 | 节奏参照 |
> |---------|---------|---------|
> | **碾压类**（打脸爽文 / 都市逆袭 / 玄幻 / 马甲） | §十大经典爽文套路 | 本文件三级节奏 |
> | **信息兑付类**（悬疑推理 / 惊悚 / 重生预知 / 信息差向） | §信息兑付类套路库 | 本文件三级节奏 |
> | **认可类**（种田 / 日常 / 年代 / 治愈 / 现实奋斗） | §认可类套路库 | `emotion-curve.md` 第 7 套（双层周期） |
> | **关系兑付类**（言情 / 治愈甜宠 / 双向奔赴） | §关系兑付类套路库 | `emotion-curve.md` 第 5 套（治愈甜宠三章循环） |
> | **整活兑付类**（爆笑反套路 / 沙雕 / 神转折 / 精神病主角 / 现代梗穿越） | §整活兑付类套路库 | `emotion-curve.md` 第 3 套（整活三章循环） |
>
> **为什么信息兑付类要单列一库（2026-09-22 实测）**：曾按"碾压类 / 信息兑付类共用十大套路"写，拿悬疑样本《停摆》
> 实际选配方时发现——**十条套路里只有「绝境突破」「逆转局势」勉强沾边，且都不是"查明真相"的核心配方**；
> 十条的爽感全部建立在"**压过 / 震住别人**"上（扮猪吃虎、拍卖会装逼、越级挑战、身份揭秘……），
> 而信息兑付类的爽感是"**读者比场上人早一步明白**"，两者不是一回事。**三库表看起来齐整，其中一个库是空的**——
> 这是本轮动态验证抓出的缺陷（静态检查看不出）。
>
> **形态无关的部分**（三级节奏的"单章 / 卷级 / 全书"框架、伏笔设计规范、章节衔接技巧）**四类通用**。
> **红线**：认可类与关系兑付类**严禁套用对抗套路**（扮猪吃虎 / 打脸 / 碾压 / 揭身份）——一出现"当众打脸"，这两类读者会直接判定"书跑偏了"。
> **本文件是主线工序，不是参考资料**：立项 1.3 从本文件选出本书的**套路配方**写入 `00-大纲.md` 第 3.1 节，章纲逐章标注用哪条，3.2 写前分析再核一次。取用与频率的登记方式见 `UPSTREAM-INHERITANCE.md` 第二节。

## 经典爽文结构公式

### 单章节奏（微观）

```
铺垫（前20%）→ 冲突升级（中间50%）→ 爆发/反转（后20%）→ 钩子（最后10%）
```

### 卷级节奏（中观）

```
第1章：困境建立 + 获得机缘
第2-3章：小试牛刀 + 第一次打脸
第4-5章：实力提升 + 引来更强对手
第6-8章：连番挑战 + 主角成长
第9-10章：卷级 BOSS 战 + 大高潮
第11章：新篇开启 / 更高层次世界
```

### 全书节奏（宏观）

```
开篇卷（1-10章）：废柴逆袭，从底层崛起
发展卷（11-30章）：扬名立万，碾压同辈
转折卷（31-50章）：遭遇挫折，绝地反击
高潮卷（51-70章）：巅峰对决，真相揭示
终章卷（71-80章）：终极一战，功成名就
```

## 十大经典爽文套路

### 1. 扮猪吃虎

```
伪装弱者 → 被人看不起 → 关键时刻展示实力 → 众人震惊
```

**适用频率**：每 3-5 章一次
**变体**：装穷、装傻、隐藏修为、故意示弱

### 2. 退婚打脸

```
被退婚/被抛弃 → 发奋图强/获得机缘 → 实力飞涨 → 前任/对方后悔莫及
```

**适用频率**：通常作为开篇引擎
**变体**：被逐出家族、被开除宗门、被解除婚约

### 3. 拍卖会装逼

```
进入拍卖场 → 竞价被人嘲笑没钱 → 一掷千金碾压 → 众人震惊身份
```

**适用频率**：每 10-15 章一次
**变体**：赌石、炼丹大会、比武招亲

### 4. 越级挑战

```
面对高等级对手 → 众人认为必败 → 出人意料获胜 → 声名大噪
```

**适用频率**：每 5-8 章一次
**变体**：以一敌多、以低境界胜高境界、不用全力就获胜

### 5. 身份揭秘

```
以普通身份行事 → 遭遇困难/被刁难 → 真实身份曝光 → 所有人跪了
```

**适用频率**：每 15-20 章一次（不宜太频繁）
**变体**：师承揭秘、血脉觉醒、势力背景曝光

### 6. 绝境突破

```
陷入绝境 → 生死之间感悟 → 突破境界 → 反杀
```

**适用频率**：每 8-12 章一次
**变体**：战斗中突破、服用丹药突破、机缘巧合

### 7. 打脸势利眼

```
势利眼狗眼看人低 → 主角展示实力/身份/财力 → 势利眼跪舔 → 主角冷漠离去
```

**适用频率**：每 3-5 章穿插
**变体**：药店、武器店、宗门入门

### 8. 故人重逢

```
早期看不起主角的人 → 多年后再次相遇 → 发现主角已飞黄腾达 → 后悔/震惊/跪
```

**适用频率**：每 20-30 章一次
**变体**：同学聚会、回乡、宗门大会

### 9. 逆转局势

```
局势一边倒（不利于主角方）→ 主角出场/使出底牌 → 一己之力扭转 → 全场欢呼
```

**适用频率**：卷终高潮必用
**变体**：战场逆转、谈判逆转、比赛逆转

### 10. 连环打脸

```
打脸 A → A 叫来更强的 B → 打脸 B → B 叫来更强的 C → 打脸 C → 最后大 BOSS 出面 → 终极碾压
```

**适用频率**：大高潮章节
**变体**：层层递进式、一气呵成式

## 信息兑付类套路库（2026-09-22 新增，本技能叠加）

> **本技能叠加，非上游原文**。上游的十大套路全部建立在"**压过 / 震住别人**"上，
> 而信息兑付类（悬疑推理 / 惊悚 / 重生预知 / 信息差向）的爽感是"**读者比场上人早一步明白**"，
> 两者不是一回事。拿悬疑样本《停摆》按十大套路选配方时，十条里只有两条勉强沾边（见开头适用范围表下的实测记录）。
> **本类的"爽"只有一种形态**：**一个信息在读者眼前合上了**（拼上、对上、应验、看穿）。

| # | 套路 | 形态 | 适用频率 | 变体 |
|---|------|------|---------|------|
| 1 | **读者先知道** | 主角的发现**先给读者看**，他还没说出口（读者握着他没用的优势） | 每 3-5 章 | 读者看见他拆开了表，场上人还在问"看出什么了" |
| 2 | **反常的一处** | 一个**不该出现、或该出现却没出现**的东西（时间 / 数量 / 位置 / 气味） | 每 3-5 章 | 表壳是温的 / 油多了一滴 / 该来的帖子没来 |
| 3 | **两件事对上** | 两处不相干的线索**在读者眼前拼上**（主角未必当场说破） | 每 5-8 章 | 两个时间对上 / 同一种手法 / 同一句话出现在两处 |
| 4 | **随口一句应验** | 前文一句不以为意的台词，此刻**以另一种含义回来** | 每 8-12 章 | 父亲那句"别修它" / 邻居说"交上就踏实" |
| 5 | **他不是他自称的人** | 身份错认：自称的身份与实际不符，或读者以为的那个其实是另一个 | 每 10-15 章 | 老师傅不肯说姓名 / 有人在巷口两次不进门 |
| 6 | **同一刻再来一次** | 同一时刻或同一动作**第二次出现**，含义完全变了 | 每 10-15 章 | 又一个停在同一分钟的表 / 第二次敲墙 |
| 7 | **只解了外层** | 以为解开了，发现只是一层（真相分层）；卷终一次叠两层 | 每 10-15 章 | 以为查出是谁修的，发现是替谁收的 |
| 8 | **为知道付代价** | 每得到一点真相，**当场付一次看得见的代价** | 每 5-8 章 | 忘掉父亲一件事 / 得罪一个必须用的人 / 铺子少一桩生意 |

**本类的"压"怎么写**（对应上游"被虐后觉醒"的位置）：不是被打压，是**知道了却不能说 / 说了没人信 / 真相本身伤人**。

**本类的"扬"怎么写**（对应上游"逆转局势"的位置）：不是翻盘，是**拼上了一块 / 有人信了他 / 他确认自己没记错**。

> **红线（本类独有）**：**严禁用"读者也不知道"来拖**。本类的爽感来自"**读者比场上人早一步**"，
> 不是"**作者比读者晚一步揭晓**"。把悬念做成"作者藏着不说"，读者只会觉得被骗
> （对应 `hook-techniques.md` 的信息差钩子，两处口径须一致）。

## 认可类套路库（2026-09-22 新增，本技能叠加）

> **本技能叠加，非上游原文**。上游的十大套路全部是对抗向（每一条的"爽"都靠"有人被压过"），
> 认可类（种田 / 日常 / 年代 / 治愈 / 现实奋斗）照它取用会写不出东西。本节补齐。
> **本类的"爽"只有一种形态**：**可见的具体得失**（数字、物件、别人说出的一句话）。
> **严禁**：把任何一条写成"对手被羞辱"；**不写**"她的日子渐渐好起来了"这种抽象概括。

| # | 套路 | 形态 | 适用频率 | 变体 |
|---|------|------|---------|------|
| 1 | **第一笔钱** | 她的手艺/东西第一次换成钱，且有人**愿意为它付** | 开篇引擎，之后每 10-15 章量级升级一次 | 头一笔工钱 / 第一次有人上门买 / 第一次收定金 |
| 2 | **有人记住我** | 她做过的一件小事，被**别人记住**并在人前说出来 | 每 5-8 章穿插 | 记得她熬的那碗粥 / 记得她哪天替过班 / 记得她说过的话 |
| 3 | **懂行的认了** | 一个**懂这一行的人**认出她的东西好（不是夸她人好） | 每 8-12 章一次 | 老师傅点头 / 行家出手加价 / 外人看不出、内行一眼看出 |
| 4 | **差一点然后够了** | 眼看够不着（差七十文 / 差一个人情 / 差一天），**有人悄悄补上** | 每 5-8 章穿插 | 门口放着的钱 / 账上多出的一笔 / 有人提前替她想到了 |
| 5 | **替她说话** | 她被挑剔/为难时，**有人先一步替她出声** | 每 5-8 章穿插 | 掌柜开口 / 邻里作证 / 平时最不亲近的人先说了一句 |
| 6 | **旧物回头** | 她以为没人要的东西（或人），**被人回头来找** | 每 15-20 章一次 | 退回来的货又上门 / 三年前的主顾回来了 / 被丢下的手艺有人认 |
| 7 | **一次被选择** | 在几个人里，对方**选了她**（当众或私下） | 每 10-15 章一次 | 挑了她做主事 / 点名要她做 / 把事交到她手上 |
| 8 | **日子量得出变化** | 生活层级跃升，**当众发生**且改变她在此处的位置 | **卷终**（每 25-30 章） | 帮工→主事 / 借住→有自己的地方 / 没人认→被邻里当个人物 |

**本类的"压"怎么写**（对应上游"打脸势利眼"的位置）：不是被打压，是**白干 / 不被认 / 差一点**。
力气花出去没结果、做对了没人看见、眼看够得着又滑掉。

**本类的"扬"怎么写**（对应上游"逆转局势"的位置）：不是翻盘，是**被接住**。
有人替她说话、有人记得她做过什么、有人先一步替她想到了。

## 关系兑付类套路库（2026-09-22 新增，本技能叠加）

> **本技能叠加，非上游原文**。言情 / 治愈甜宠 / 双向奔赴的"爽"落在**两人之间**，
> 上游十大套路全是"主角对世界"（压过对手、揭自己身份的底），取不到。
> **本类的"爽"只有一种判据**：读者想要的那句关系确认，**落在一个可指认的动作上**（情绪或氛围不算）。
> 配套节奏见 `emotion-curve.md` 第 5 套（三章一循环 + "甜"的四动作 + 递进一档自查）。

| # | 套路 | 形态（可指认的动作） | 适用频率 | 变体 |
|---|------|-------------------|---------|------|
| 1 | **他来了** | 不是偶遇，是**为见她而到**（时间/路线/理由能看出来） | 每 3-5 章一次 | 绕路 / 提前到 / 编了个不成立的理由 |
| 2 | **他不走** | 拒绝、尴尬、雨、麻烦出现了，他**仍在原地** | 每 3 章至少一次 | 被拒了还站着 / 等她关门才走 / 第二天照来 |
| 3 | **他记得** | 说出或做出一个**只有留心才知道**的信息 | 每 5-8 章一次 | 她的口味 / 旧物 / 习惯 / 她说过一次的话 |
| 4 | **他把话说出口** | 一句能改变她判断的话，且**当场说**（不是事后回想） | 每 8-12 章一次 | 我认得你 / 那年我去过 / 我不是送人 |
| 5 | **同一件事两种说法** | 两人对同一件事的记忆有出入，其中一个版本**更深情** | 每 8-12 章一次 | 她记得他迟到，他记得那天下了雨 / 一方记得的细节多得多 |
| 6 | **他先低头** | 争执后**他先做了那个动作**（把东西留下 / 回来敲门 / 追出去） | 卷终或关系转折点 | 把伞留下 / 第二天带着东西来 / 当众承认 |

**本类的"压"怎么写**：不是靠"两人都不说"（那是开篇雷区"误会 + 不解释"，判据见 `genre-packs.md` 第 2 包），
而是**由她的旧伤或外力造成**（她先退：躲、关门、说"我没事"）。

**递进要求（唯一的防水平判据）**：相邻两次兑付必须**比上一次更近一档**
（从"留东西"到"说出口"到"不走"）。**原地重复＝没推进**："他还是来买花"重复三次就是水章。

## 整活兑付类套路库（2026-09-23 新增，本技能叠加）

> **本技能叠加，非上游原文**。上游十大套路与前三库的爽感全部建立在"**压过 / 别人认了我 / 两人之间**"上，
> 而整活兑付类（爆笑反套路 / 沙雕 / 神转折 / 精神病主角 / 现代梗穿越）的爽感是"**一个做法离谱但居然成立**"——
> 读者要的不是"他赢了"，是"**这也行？**"。拿沙雕样本按十大套路取配方时，十条里**一条都不命中**：
> 十条的"爽"全在"结果上赢了"，本类的"爽"在"**过程不按规矩来**"。
> **本类的"爽"只有一种形态**：**一个当场做出的做法**（动作，不是吐槽；离谱，但在本书规则内说得通）。
>
> **与碾压类的分界线（最容易混，必须写死）**：主角**靠"更强"**解决问题＝碾压类；主角**靠"另做一件事"**解决问题＝整活兑付类。
> 一旦整活样本里出现"亮出更强实力把人镇住"，本类型就塌回打脸爽文，读者会掉头。

| # | 套路 | 形态（可指认的做法） | 适用频率 | 变体 |
|---|------|-------------------|---------|------|
| 1 | **规则照字面执行** | 对手／系统定了条规矩，主角**一字不差地照做**，结果规矩自己崩了 | 每 3-5 章 | 让你跪你就跪到底 / 让你道歉就写三千字 / 抽奖必中一等就全抽一等 |
| 2 | **拿现代法子办古代事** | 用**读者熟、场上人不懂**的一套办法解决古局（做法要具体到能画出来） | 每 3-5 章 | 送外卖式跑腿 / 直播式叫卖 / 垃圾分类式分赃 / BGM 一放全场跟走 |
| 3 | **反向薅系统／规则** | 系统给的能力是"给人下套"或"必须付费"，主角**把规则当成资源用** | 每 5-8 章 | 吸收负面情绪变修为 / 别人修炼我涨 / 差评越多我越强 |
| 4 | **专业不对口** | 用**本行的专业做法**硬闯异界难题（精神科、厨子、会计、修车工） | 每 5-8 章 | 拿诊断书怼鬼 / 拿记账法破案 / 拿颠勺法炼器 |
| 5 | **整活给别人看** | 主角的做法**当场不够赢**，但它是**设计给特定人看的**（做局／下套／引蛇） | 每 8-12 章 | 故意当众认怂 / 把假货做得像真的 / 演一场给对头看 |
| 6 | **正经人被迫跟着整** | 一个**守规矩的人**被主角拖进整活，**他的反应比主角更好笑** | 每 5-8 章穿插 | 长老被迫念口号 / 反派学着抄作业 / 执法者当场改规则 |
| 7 | **规格外的用法** | 把**已有道具／能力**用在完全不同的场景（不是新造能力） | 每 8-12 章 | 储物戒指当垃圾桶 / 护身符当门铃 / 剑意用来削苹果 |
| 8 | **一个梗贯穿一卷** | 一个"没人想过的点"（穿越自带 BGM、龙王开演唱会）**反复回来**，每次升级一档 | 卷级主线，每 3 章碰一次 | 每次出现规模更大 / 牵进更多人 / 变成规矩 |
| **9** | **连锁失控**（2026-09-24 新增，**本类主引擎**） | 主角做出一个做法，**别人各自按自己的私心反应**（反应各不相同），反应又牵出别的事，局面滚成他管不了的样子 | 每 3 章（**本类必备**） | 一院子人跟着晃且一路漏话 / 一首歌让嫡母发现父亲的小秘密 / 一句口误让两个门派当场翻脸 |

**本类的"压"怎么写**（对应上游"打脸势利眼"的位置）：不是被打压，是**被按回套路里**——
所有人都认定你该按老规矩来（系统催你走剧情、长辈逼你守旧例、对手等你按剧本出招），**你一按套路走就输**。

**本类的"扬"怎么写**（对应上游"逆转局势"的位置）：不是翻盘，是**做出那个做法**——
动手、掏东西、改流程、把规则反过来用；**关键是当场看得见，且当场有人说"这不合理"**。

**本类的红线（独有）**：
1. **严禁用吐槽代替整活**——一句内心 OS 或嘴炮不算兑付，必须有一个**做出来的动作**。
2. **严禁整活"不成立"**——离谱可以，但要能**用本书规则补出逻辑链**；补不出＝胡闹，读者不笑。判据见 `emotion-curve.md` 第 3 套"笑"的动作清单第 2 条。
3. **严禁无本万利**——每次整活**当场付一点小代价**（被记恨／被围观／被罚／被盯上），否则读者觉得"作者在编"。
4. **严禁塌回碾压**——不得用"亮出更强实力"收场（见上方分界线）。

**⚠️ 第 9 条是本类的「引擎」，不是可选项（2026-09-24 补）**：前 8 条解决"**他怎么做**"，第 9 条解决"**做完之后会发生什么**"。**只做前 8 条、不接第 9 条，写出来是"聪明的主角"，不是"爆笑反套路"**——2026-09-24 沙雕样本第一版就栽在这里（自检全绿、形态被用户当场否掉）。判据句：**这一章结束时比开头更乱，还是更整齐？** 更整齐＝写成了智斗。

**规格外的坏例子（本轮实测需回跑验证）**：整活三章内若**每次做法都不同、且各自成立**，属正常；
若**同一个做法换三种说法重复**（"他又整了一次，大家又笑了"），属水章——判据同 `emotion-curve.md` 第 3 套"规模递进"。

## 伏笔设计规范

### 伏笔类型

| 类型 | 埋设 | 回收间隔 | 示例 |
|------|------|---------|------|
| 短期伏笔 | 本章暗示 | 1-3 章后回收 | 神秘人的身份 |

### 伏笔检查

每 5 章检查一次 `PLOT_POINTS.md`，确保：
- 状态为"伏笔待回收"的条目不超过 5 个
- 没有超过 30 章仍未回收的伏笔
- 已回收的伏笔标记为"已完结"

## 章节衔接技巧

### 好的衔接

- 承接上章钩子，但不完全重复
- 视角切换（从主角切到对手的反应）
- 时间跳跃（"三天后..."）+ 简述间隔期变化

### 差的衔接（避免）

- 完全重复上章最后一段
- 毫无关联地切换场景
- 大段回忆/解释打断节奏
