# 与 pop 管线打通（可选模式）

> 定位：桥接文档。用户已装 pop 系列 44 技能（snow/灯塔/涌现三条完整网文管线）。当用户说「用 pop 管线写番茄书」「用章纲写」「接着 pop 项目续写」时，按本文档路由；纯番茄项目（本技能独立立项）不需要读。
> 原则：pop 管线管"生产"，本技能管"番茄合规与平台节奏"；冲突时番茄规则优先。

## 路径与输入映射

| pop 产物 | 本技能消费点 |
|----------|--------------|
| pop-outline 四块章纲（章节背景/舞台背景/剧情场景/补充信息） | 替代 3.2 写前分析的场景规划输入；动作细节/心理/台词仍按本技能现编 |
| pop-write 去AI味产出（sepia 结构层+字词层） | 作为 3.3 撰写的文本基础；**仍须跑 3.4 过审自检**——pop 去AI味不覆盖番茄审核特征（四类低质违规） |
| pop-review 章日志 | 事件层记忆进 `.learnings/`（PLOT_POINTS/CHARACTERS）；番茄数据层（钩子类型/情绪标注）进 02-情绪曲线 |
| pop-snow-pipeline 的 状态.md | 作为项目唯一状态总账保留；本技能的项目文件（00-大纲等）与其并存，路径不重复建 |
| pop-review 判定标准八条 | 与本技能质量审查并行，两套都过才算定稿 |

## 冲突裁决（番茄优先，逐条可判）

1. **字数**：番茄 2200-2800 字/章 > pop-write 默认 2000-2500。按 2200-2800 出稿，跑本技能字数脚本校验。
2. **钩子**：章末钩子用本技能钩子库（10 种+轮换规则），pop-review 钩子承接检查照常执行。
3. **更新节奏**：按 `fanqie-platform-facts.md` 全勤口径（日更 4000-6000 字）倒排生产计划，而不是 pop 卷纲的节奏。
4. **开篇**：pop 立项稿的三章节奏若与本技能"黄金三章闭环"冲突，以黄金三章闭环为准，回改章纲。

## 启用判据

- 项目由 pop 管线初始化（存在 状态.md 或 pop 目录结构）→ 自动进入桥接模式。
- 用户明确说"用章纲写/用 pop 管线" → 进入桥接模式。
- 其余情况（本技能六问立项的纯番茄项目）→ 不读本文档，走默认流程。
