# 文笔规则（番茄长篇通用）

写正文前读「摘要」。交付前按「死线清单」逐条自查。标「死线」的不通过就重写相关段落，不做局部遮掩。

## 摘要（写正文时随任务包传入）

- 视角统一：一章只跟一个视角人物，只写他看得见、听得见、想得到的事；无提示不换视角。
- 开头进入变化：前三句给新冲突、新信息或新异常。禁写天气、起床、照镜子、闹钟与上回回顾。
- 章末留前进力：抛未解问题、升级冲突、改变关系或给出新目标，四选一以上；不停在事情讲完、情绪散完。
- 台词有功能：每句重要台词推动情节、揭示人物或埋伏笔；删寒暄、重复表态与借人物之口总结。
- 信息分批：单章只讲清与当前冲突直接相关的信息，背景拆进动作、对话与后果，禁连续多段纯说明。
- 行动有因果：重要行动前写清性格、欲望、恐惧或利益上的理由；重大决定加「触发信息 → 权衡 → 情绪或动作落点」。
- 知识边界：角色只知道亲历、听说、推测或调查得到的事；禁未卜先知。
- 发现与反转有前文线索：每次认知变化都要有新证据，不靠巧合解决关键冲突。
- 连续性四项：人数（谁在场、谁离场）、物品（在哪、谁持有）、时间（与上章间隔与顺序）、人物状态（伤势、情绪、知识）。
- 句子闭合：代词有先行词，动作有发出者与对象，半截话能判断是省略还是被打断；缺主谓宾的句子重写。
- 细节有功能：外貌、天气、家具、路人至少服务人物、氛围、伏笔、冲突或动作之一；装饰性凑字删除。
- 语言去模板：长短句交错，删机械连接词、空泛评价、四字堆砌与同质比喻；一段只讲一件事。
- 情绪外化：少写「他很愤怒／害怕／震惊」，改写动作、生理反应、视线落点与说话长短。
- 场景有缓冲：连续高压、连续打斗、连续甜会失去弹性；每章用日常、幽默或安静段落做主情绪对照。
- 伏笔有账：重要伏笔记埋设章、计划回收位置与状态；不埋没有回收计划的伏笔。
- 道具链完整：关键道具写清来历 → 当前位置 → 知情者或持有者；角色只能用当前场景可触及的物品。
- 格式统一：中文全角标点与中文弯引号，全书一致。
- 字数服务结构：默认 2000-2500 字（用户约束优先）；不足时扩有效场景、动作与对话层次，超标时删重复说明与无功能细节。

## 一、叙述与结构（死线）

1. **视角统一**：开书定人称与视角范围；同一章无提示不换视角。多视角必须用章节、分节或明确锚点切换。
2. **时态与文体统一**：正文保持同一时态体系。信件、规则、档案、系统提示、梦境可用相异时态，但要用排版或引号让读者识别。
3. **开头进入变化**：第一章与每一章都尽早给新信息、新冲突、新人物或新异常。禁止天气、起床、照镜子、空泛风景、「上回说到」充当前几段。
4. **章末留下前进力**：结尾至少完成一项：抛出未解问题、升级冲突、改变人物关系、兑现情绪、给出新目标。不能停在事情讲完、情绪散完。
5. **转场有锚点**：时间、地点或视角变化时，写清何时、何地、谁在经历什么。禁止「镜头一转」「与此同时」「另一边」这类无信息过渡。

## 二、描写与信息

6. **环境描写有功能**：每处环境至少完成一项：推进动作、制造氛围、外化情绪、埋伏笔、交代世界规则。零功能风景删除。
7. **心理优先外化**：少直接解释情绪，多用动作、生理反应、习惯物、说话方式和选择表现。内心独白只在人物无法通过行动表达时用。
8. **台词推动文本（死线）**：每句重要台词至少完成一项：推动情节、制造冲突、揭示人物、传达必要信息、埋伏笔、制造悬念。人物说话方式要可区分。
9. **情感有对照**：连续高压、连续甜、连续打斗都会失去弹性。每章用日常、幽默、安静或温情给主情绪做缓冲。
10. **信息分批（死线）**：背景、设定、身世、谜底不一次讲完。单章只讲清与当前冲突直接相关的信息，其余延后、拆散或藏进动作与对话。
11. **背景落进场景**：解释世界观与过去事件时，优先通过行动、争执、道具、误会产生后果呈现。禁止连续多段纯说明。
12. **特殊文本有最小逻辑（死线）**：规则、遗言、信件、系统提示、合同至少具备「适用对象、触发条件、后果或代价」中的两项。故意不完整时，要让角色意识到缺失并因此行动。

## 三、人物与动机

13. **行动有因果（死线）**：角色做事不是「剧情需要」，而是性格、欲望、恐惧、利益、关系与当下信息共同作用。重要行动前读者能看见理由。
14. **重大决定有决策链（死线）**：离开、涉险、撒谎、背叛、告白、战斗、放弃，要写出「触发信息 → 权衡 → 情绪或动作锚点 → 决定」。情绪性决定也要有落点。
15. **知识边界（死线）**：角色只能知道自己经历、听说、推测或调查得到的信息。禁止未卜先知。
16. **关系变化有铺垫**：信任、爱慕、仇恨、误解、和解通过事件逐步变化。突转必须给此前可见的裂缝。
17. **新人物有功能**：首次出场至少完成一项：推动剧情、制造冲突、提供帮助、揭示处境、建立关系、埋下伏笔。没有后续功能的人物删除。

## 四、情节与逻辑

18. **时间轴清楚（死线）**：按时间自然推进。闪回整块进入、内部顺叙、明确返回。章内时间状语咬合，年龄、年数、日期、季节经过核对。
19. **发现与反转有依据（死线）**：角色发现真相、读者遭遇反转前，前文必须给过可见线索。每次认知变化都要有新证据。
20. **冲突升级或转化**：每章让目标遇到阻力、代价、误解、失败或新选择。每次推进改变局面，不重复同一情绪。
21. **巧合不替代因果**：巧合作开局麻烦可以，关键解决不能靠巧合。救场人物与突发消息要在后文承担代价。
22. **伏笔登记并回收**：重要伏笔记埋设位置、计划回收位置与状态。不埋没有回收计划的伏笔，不临时回收前文没有依据的伏笔。

## 五、连贯与语言（死线）

23. **连续性四项**：交付前核对人数（谁在场、谁离场）、物品（在哪、谁持有）、时间（与上章间隔、天色、顺序）、人物状态（伤势、情绪、知识与能力变化）。
24. **世界质感一致**：时代、科技、制度、经济、地域、职业与口吻处在同一世界层。现代词不误入古代日常，旧俗词不污染现代生活。
25. **道具链完整**：关键道具写清来历 → 当前位置 → 知情者或持有者。角色只能使用当前场景可触及的物品。
26. **句子关系闭合**：代词有先行词，动作有发出者与对象，半截话能判断是省略还是被打断。主客倒置、悬垂句、无落点省略句重写。
27. **句子完整**：不出现缺主语、缺谓语、缺宾语、搭配不当、半句未收尾。对话可短，但要有明确说话人或叙事功能。
28. **行文顺畅**：按时间、因果与动作推进，不写成设定摘记或大纲扩写。每段只讲一件事，读者不回读也能理清顺序。
29. **细节有功能**：外貌、动作、服饰、天气、家具、路人至少服务人物、氛围、伏笔、冲突或动作推进之一。装饰性凑字删除。
30. **语言去模板化**：长短句交错，删机械连接词、空泛评价、过度修饰、四字堆砌与同质化比喻。对话接近真实人声，叙述贴人物经验。
31. **标点格式统一**：中文正文用全角中文标点和中文弯引号，不中英混用。章节标题、分段、对话格式全书一致。
32. **字数服务结构**：不足时扩有效场景、动作层次、对话层次与必要反应；超标时删重复说明与无功能细节。不为凑字数加风景、回忆和重复心理。

## 六、修正执行

33. **先删无功能元素**：列出首次出场的人物、物件、细节；不推进动作、关系、氛围或已登记伏笔的直接删。
34. **关键物件链闭合**：发现、传递、藏匿、开启、转交、遗失的道具，按「在哪 → 谁拿到 → 如何开启 → 结果」重排，名称、状态、位置不中途变化。
35. **信息交接有最后动机**：把危险任务、秘密、证据、遗物交给另一人时，写清为什么现在只能交给他、为什么本人不能继续、为什么对方会接手。
36. **关键台词完整呈现**：影响人设、动机、关系或主题的回答、告白、拒绝、承诺、遗言，不能概括成「她说了一个理由」，要写出完整对话、动作与反应。
37. **跨场景只用随身信息**：角色换场景后，只能检查随身或当前可见的东西；留在家、办公室、他人手上的物品只能回忆或转述。
38. **修文优先合并碎句**：背景、关系与设定优先由动作、道具、对话、信件带出。删只重复结论的短段，保留改变人物判断的信息。
39. **类型卖点承担功能**：悬疑的异常、言情的拉扯、玄幻的术法、科幻的设定，要同时服务人物、氛围、伏笔或下一步动作。做不到就删或改到能推动剧情。

## 最小交付口诀

视角不飘，时间不乱；动机可见，信息分批；道具有链，人物有界；发现有据，伏笔有账；句子闭合，细节有用；语言自然，格式统一。
