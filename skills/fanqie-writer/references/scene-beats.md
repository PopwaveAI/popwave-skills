# 章内回合与冲突升级（scene-beats）

> **定位**：解决"一章只有一个场景/一件事，硬撑成一章"的缺陷（2026-09-22 第 1 章实测暴露）。
> **归属**：**大纲层**资产——回合数在**章纲**阶段就要数清，不是写完正文再补。写作期只做兑现。
> **触发时机**：① 1.3.5 章节细纲生成时（每章必须填回合表）② 3.2 写前分析第 3 步"场景规划" ③ 用户反馈"节奏慢/不知道在写什么/看不下去"时先查回合数。
> **与 `chapter-guide.md` 的关系**：chapter-guide 的"信息密度"讲**怎么排**，本文件讲**够不够**。字数、场景数达标 ≠ 回合数达标。

---

## 一、核心命题：容量有两级——事件单元 → 回合（v1.14.0 两级定型）

原体系（v1.13.2 及以前）写的是「2200-2500 字 = 1 个主要事件 + 1 个次要事件 + 2-3 个场景」。

**这条是错的**——它把"1 个事件"当成一章的容量。照它执行，正好得到：

> 一个场景（她递表）→ 一句话对话 → 一个动作转折（他拒绝）→ 收尾。
> 2500 字里，**故事前进了 0 步**。读者读完不知道"接下来要等什么"，只会觉得"就这？"

**正确单位有两级**（2026-09-22 二次实测修正）：

- **第一级 · 事件单元（event unit，2-4 个/章）**：一个独立的「**谁想要什么 → 结果如何**」闭环。**这是读者感知到的"事"。**
- **第二级 · 回合（beat，每单元 1-3 个）**：单元内部的攻防来回。**这是读者感知到的"拉扯"。**

**事件是名词，回合是动词——读者追的是动词，但一章不能让所有动词都指向同一个名词。**

> **本文件 v1.13.3 只补了"回合"一级，实测仍被判"还是一整章节就在讲一件事"**——
> 因为第 1 章那 6 个回合**全部落在"她送表 / 他拒收"同一个单元内**：回合数从 1-2 涨到 6，
> 事件数始终是 **1**。**回合数达标 ≠ 事件数达标。** 补齐方法见 §七。

## 二、回合的判定：三问

任取一段，问这三句：

| # | 问 | 答不上来的意思 |
|---|----|--------------|
| 1 | **谁在向谁施压？** | 没有主动方 → 这段是场景描写，不是回合 |
| 2 | **被压的一方做了什么？** | 只是"没答""沉默" → 没有回应，局面不动 |
| 3 | **这一下之后，局面和刚才哪里不同？** | 答不出差异 → **这不是新回合，是上一回合的重复** |

**三问全过 = 1 个回合。** 第 3 问答不出 = 同层重复，**不计入回合数**。

### 实测反例（第 1 章原稿）

原稿女人的四轮追问：① 修不修 ② 为什么 ③ 别人怎么修 ④ 是你的规矩还是手艺。

用第 3 问检验：

| 追问 | 优势方变了吗 | 新信息 | 代价变了吗 |
|------|------------|--------|-----------|
| ① → ② | 没变（他一直在拒） | 无 | 无 |
| ② → ③ | 没变 | 无 | 无 |
| ③ → ④ | 没变 | 她知道了他的规矩 | 无 |

→ **四轮追问 = 1 个回合**，不是 4 个。加上开头递表和结尾她走，全章**只有 1-2 个回合**，却写了 2500 字。这就是"节奏密度低"的准确算法。

## 三、升级：相邻回合之间必须变一项

"冲突必须不断升级"是清单（`prose-rules.md` 第 21 条），本文件给**可判定定义**——相邻两个回合之间，至少一项变量必须改变：

| 变量 | 变的样子 |
|------|---------|
| **① 筹码升级** | 拒绝/失败的代价变大（"不接这活" → "铺子保不住" → "父亲的秘密要被人翻出来"） |
| **② 信息升级** | 有一方拿到新信息，且**因此改变了做法**（她掏出一张照片；他确认这表是父亲的手法） |
| **③ 关系升级** | 两人的相对位置变了（陌生人 → 试探到底线 → 摊牌 / 结盟 / 翻脸） |
| **④ 物理升级** | 场面本身变了（有人闯进来 / 东西掉出来 / 东西被带走 / 时间到了） |

**四项都不变 = 没有升级**，写多少字都是原地踏步。

> **最容易自欺的一处**：把"追问得更狠"当成升级。**问得更凶不是升级，局面变了才是。** 自检时必须写出"这一回合结束时，局面和上一回合结束时差在哪"——写不出就是没升级。

## 四、冲突三要素（缺一即不成立）

写冲突时逐项填，缺项就补，补不上说明这个"冲突"是假的：

| 要素 | 问 | 第 1 章原稿的实际状态 |
|------|----|--------------------|
| **诉求** | 双方各自要什么？**且不可兼容** | 她要修表 ✅ / 他要"不碰父亲那条线" ✅ → 诉求成立 |
| **筹码** | 双方能让对方付什么代价？ | ❌ **她没有筹码**（只是请求），**他也没有代价**（不修就完事） |
| **代价** | 拒绝 / 失败**在本章内**显形了吗？ | ❌ 完全没有——他拒绝得很轻松，拒绝之后铺子照开 |

→ 诉求有了，**筹码和代价是空的**。所以读者"看不到冲突和矛盾"——因为确实没有，只有一次客气的一问一答。

**补法**（本书实例，可作范式）：把代价从"背景"提到"台面"——
- 她不该是"请求"，该是**手上有一张让他无法拒绝的牌**（表本身的来历 / 他父亲的名字 / 一张只有他认得的东西）；
- 同时**让外部压力在章内落到他身上**（催租的人当众上门、有人当面量他的铺子），而不是只存在于电话和隔墙对话里。

> **注意**：本书是无对抗诉求的生活流，**不靠打脸制造冲突**。生活流的冲突＝**生计压力 + 守住某样东西的代价**，不是羞辱对手。

## 五、素材量 vs 容量：写完章纲先数"单元"，再数"回合"

**每写完一章章纲，按这个顺序数两遍：**

**第一遍 · 数事件单元**（2-4 个，方法见 §七）：

| 单元数 | 判定 | 处理 |
|--------|------|------|
| **1** | **本章素材撑不起一章**（最典型：一件"日常业务"——来个人、说件事、主角拒绝） | 二选一：**① 与相邻章合并**；**② 引进新单元**（加人物 / 加压力 / 加反转 / 把后文的某个事件提前） |
| 2-4 | 合格 | 继续，并检查章末单元是不是**本章最大的那一个**；且至少有 1 个单元由主角主动发起 |
| > 4 | 过载 | 拆章，或把其中 1-2 个移到相邻章 |

**第二遍 · 数回合**（4-6 个，方法见 §二、§三）：

| 回合数 | 判定 | 处理 |
|--------|------|------|
| < 4 | 交锋不够 | 回单元层看是不是单元太少（1 个单元必然排不出 4 个真回合） |
| ≥ 4 但都同层 | 等价于 1 个回合 | 按 < 4 处理 |
| 4-6 | 合格 | 并检查章末回合是不是**本章最大的那一个** |
| > 6 | 过载 | 拆章，或把其中 1-2 个移到相邻章 |

**章末回合必须最大**——读者读完要知道"下一回合怎么打"。章末那个回合如果不比前面任何一次强，钩子就立不住。

> **顺序不能反**：先数单元再数回合。**反过来先数回合，会得到"6 个回合 = 达标"的错觉**——
> 第 1 章 v1.13.3 稿正是这么过的（回合 6 ✅、单元 1 ❌），用户读作"一整章就讲一件事"。

### 与既有指标的分工

| 指标 | 管什么 | 达标不等于 |
|------|--------|-----------|
| 字数 2200-2800 | 体量 | 单元/回合数够 |
| 场景数 3-5 | 空间调度 | 单元/回合数够 |
| **事件单元数 2-4** | **一章有几件事** | —— |
| **回合数 4-6** | **每件事交锋几次** | 单元数够 |
| 情绪变化 ≥3 次 | 读者体感 | 单元/回合数够 |

**五个指标必须同时过。** 第 1 章 v1.13.3 稿：字数 ✅、场景数 ✅（4 处空间切换）、情绪变化 ✅（自评 6 次）、回合数 ✅（6 个）、**事件单元数 ❌（1 个）**——前四项达标把最后一项盖住了，这是同一类缺陷**连续两轮通过自检**的原因。

## 六、开篇 300 字三问（章首专用）

`golden-opening.md` 要求"前 50 字出现反差点或冲突"。第 1 章原稿**达标**（第 2 句就给出"停在二十一点四十七分，跟他抽屉里那块一样"），读者却仍觉得前 300 字可弃——说明**反差 ≠ 局面变化**。

前 300 字逐问答：

1. **状态变了吗？** 300 字内有没有发生一件**让状态不可逆改变**的事？（"发现了什么"不算，要"发生了什么"）
2. **有人要东西吗？** 有没有一个具体的人，在此时此刻想要一件具体的东西？
3. **阻力兑现在此刻吗？** 挡住他的，是**此刻就在场**的人或事，还是"背景里有个麻烦"？

**三问缺一 → 读者在书架页划走。** 原稿：① 没有（表送来不改变任何状态）② 有（她要修表）③ 没有（他拒绝得太容易，阻力不痛）→ 缺两项。

## 七、章事件单元：一章要有 2-4 件"事"，不是一件事的 4 个回合

> **来源**：2026-09-22 第 1 章二次实测。上一版（6 个回合）仍被判「**还是一整章节就在讲一件事**」「很平凡的一件事而已」。
> 诊断：**回合数≠事件数**。6 个回合全部是"她递表→他拒收"的攻防分段，全章**只有 1 个事件单元**。

### 单元 vs 回合：先把两级的边界划清

| | 事件单元（event unit） | 回合（beat） |
|---|---|---|
| 是什么 | 一件**独立的事**：谁想要什么 → 结果如何 | 一件事**内部的攻防来回** |
| 读者感知 | "**又发生了一件事**" | "**他被逼了一步**" |
| 数量 | 2-4 个 / 章 | 每单元 1-3 个 / 全章 4-6 个 |
| 判据 | 删掉它，后文的**走向**会变 | 删掉它，只是这次攻防短了一点 |

### 单元判定四问（全过才算 1 个单元）

| # | 问 | 答不上来的意思 |
|---|----|--------------|
| 1 | **谁想要什么**（一个具体的人 + 一件具体的东西/结果） | 没有诉求主体 → 这是描写，不是单元 |
| 2 | **结果是什么**（得到 / 没得到 / 变得更糟，三选一，必须明确） | 结果是"气氛变了""他懂了" → 没有结果，不算单元 |
| 3 | **删掉它，后文会缺什么** | 答不出 → 它不是单元，是场景装饰 |
| 4 | **结束状态与开始状态，哪一项变了**（地位 / 信息 / 关系 / 物理 / 资源） | 四项都没变 → 这是上一单元的延长，不是新单元 |

### 单元的三种形态（排布用）

| 形态 | 是什么 | 谁推动 | 典型 |
|------|--------|--------|------|
| **推力单元** | 外部给主角一个麻烦 | 别人 | 她送表、房东催租、有人来要东西｜**言情向：他来了、有人提起旧事、外力逼近（工期／房租／调令）** |
| **探察单元**（**言情向读作"主动试探"**） | 主角**主动**去查 / 去看 / 去做 / **去问** | **主角自己** | 他拆表、翻登记本、上门找人对质｜**言情向：她主动问一句、主动送一次、主动跟出去、主动站在门口等他走过去** |
| **代价单元** | 主角为前面的选择付账 | 后果 | 东西被拿走、人被牵连、规矩破了一次｜**言情向：她的规矩破了一次、安全区被占了一格、她开始等／开始算他什么时候来** |

**一章的两种排布范式**：

```
A：推力 → 探察 → 代价              （3 单元，最稳，适合首章）
B：推力 → 探察＋反转 → 代价＋钩子    （3 单元 + 章末加码，适合高潮章）
```

### 三条硬约束

1. **一章 2-4 个单元**。原因：一个完整的「问题→拉扯→结果」闭环在 2200-2800 字里最舒服的篇幅是 700-1200 字，所以 2-4 个；1 个单元必然注水（本样本原稿：1 个单元撑 2219 字），5 个以上必然赶。
2. **全章至少 1 个单元由主角主动发起**（探察单元）。**全章都由别人推动＝主角在首章没有存在感**——这比"没冲突"更致命，读者不会跟着一个只会被动回应的人走一百章。
3. **章末那个单元必须是本章最大的一次变化**，且它同时承担钩子。

### 实测对照（《停摆》第 1 章）

| 版本 | 事件单元数 | 单元内容 | 判定 |
|------|-----------|---------|------|
| v1.13.2 原稿 | **1** | 她送表 → 她四轮追问 → 他拒收 | ❌ 1 个单元撑 2219 字 |
| v1.13.3 改稿 | **1** | 同一件"送表 / 拒收"，拆成 6 个回合 | ❌ **回合数涨了，事件数没变** |
| 合格线 | **3** | ① 推力：她送表（表是温的｜他接手那一下出了状况）② 探察：**他主动拆表**，查出三处不该有的东西 ③ 代价：他没能把这块表推出去，且为它付出第一笔账 | ✅ |

> **注意第三栏**：合格线的三个单元与"1 个单元拆 6 回合"的差别不在字数分配，而在**每一件都是不同的事**——
> 送表是"别人给他的"，拆表是"他自己去做的"，代价是"他做的这件事反过来咬他"。
> **这三件在读者脑子里是三个记忆点，才叫"一章有事发生"。**

## 八、自检动作（写进章纲与章自检）

**章纲阶段（`templates/outline-template.md` 第 4 节）——两张表都要填，先填单元表**：

```
① 事件单元表（2-4 个）：
| # | 形态（推力/探察/代价） | 谁想要什么 | 结果 | 结束状态变了哪一项 |
|---|---------------------|-----------|------|-----------------|
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |

  自检：单元数 2-4 ✅／至少 1 个是主角主动发起 ✅／章末单元是本章最大变化 ✅

② 回合表（每个单元内部 1-3 个，全章 4-6 个）：
| # | 属于第几单元 | 施压方 → 被压方 | 这一下做了什么 | 结束时的局面变化（筹码/信息/关系/物理） |
|---|------------|----------------|--------------|-----------------------------------|
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |
| 4 |  |  |  |  |
```

**成稿阶段**：把两张表与实际正文对照——**正文里没有兑现的单元/回合，要么补写，要么从表里删掉**（表里写了没写进正文 = 假规划）；正文里有但表里没有的，回填。

> **填不出 2 个以上单元的章，说明这一章的素材本身不够一章**——此时不要靠描写稀释、不要靠把动作拆碎充数，
> 走 §五 的两条路：**与相邻章合并**，或**引进新单元**（加人物 / 加压力 / 加反转 / 把后文的某个事件提前）。

**判定口诀**：

> 事件是名词，回合是动词；
> **一章至少两件事，全章别指一个名词；**
> 三问过不了，不算一个回合；
> 四问过不了，不算一个单元；
> 相邻不变项，就是原地踏步；
> 筹码代价空，冲突就是假的；
> **主角不主动，读者不跟你走；**
> 章末那一合，必须最狠。
