# T1 卖点卡 与 T2 立项卡

## T1 卖点卡

卖点卡是这本书「读者为什么点进来、为什么追下去」的一页纸，不是故事简介，也不是大纲。T1 只交 `立项/00-卖点卡.md`，不写正文、不写章纲。

### 必填字段

1. **一句话卖点**：≤30 字，写清「谁 + 在什么处境 + 靠什么翻盘」。要能被读者复述，不写抽象主题（如「人性的挣扎」）。
2. **三个爽点承诺**：每条 ≤20 字，按出现顺序写「第 1 章 / 第 10 章 / 第 30 章 兑现什么」。承诺必须能在正文里被看见，不写「越来越强」这类不可验收的话。
3. **目标读者**：年龄段、阅读场景、同类书阅读经验。写「看过 3 本以上年代文、对 80 年代有记忆的 30-45 岁男性」这类可判断的描述。
4. **同类差异**：列 2-3 本同类书的常见开局，写清本书哪一处不同。差异必须是剧情动作，不是文风。
5. **卖点兑现表**：爽点承诺 → 计划兑现章 → 兑现方式。后续 T4 直接从这张表取本章兑现点。

### 判断锚点

- 一句话卖点读完，听的人能说出「主角要干什么」→ 合格；只能说出「讲了一个故事」→ 重写。
- 三个爽点承诺里有一个落在前 3 章 → 合格；全部落在 30 章后 → 重写，前置一个。
- 同类差异写不出具体动作 → 说明卖点还没想清，回用户确认，不硬编。

### 平台体量参考

- 新人先走完本签约，目标 ≥15 万字、约 60 章起；单章 2000-2500 字。
- 以上是排量参考，签约门槛以番茄后台当期页面为准；不把平台数字写进正文或卖点卡。
- 卷规划按 5 章一小爽、20-30 章一卷倒推，不做百章空规划。

## T2 立项卡

立项卡是写作者自己的施工图，不是给读者看的内容。T2 只交 `立项/01-立项卡.md`，不重复卖点卡，不写正文。

### 必填字段

1. **题材与时代**：题材、年代、地域、主角年龄与身份。男频年代/都市/重生必须写清「重生回到哪一年、原世界知道什么、不知道什么」。
2. **主角**：姓名、出身、当前处境、缺什么、怕什么、最想得到什么。写具体的人，不写「坚韧不拔的少年」这类标签。
3. **金手指与代价**：能力是什么、怎么触发、每次使用的代价、不能被用来做什么。金手指不是主角特性；主角特性不配代价，压迫感由世界给。
4. **世界规则**：3-6 条会影响吃饭、工作、交易、出行的规则，每条写代价。不写数值表和百科。
5. **主线目标**：主角在全书要完成的一件事，以及 3 个阶段性目标（对应卷）。
6. **卷规划**：卷号、卷目标、卷级敌人、卷末变化，每卷 20-30 章。
7. **人物卡**：出场人物的姓名、身份、与主角关系、目标、说话方式、当前状态。只写本卷会出场的人，不建空档案。

### 判断锚点

- 金手指每次使用都有可见代价 → 合格；只有好处 → 补代价。
- 世界规则能解释「主角为什么不能直接暴力解决」→ 合格；规则只是名词 → 重写。
- 卷规划每卷都有「卷末变化」→ 合格；只有「继续变强」→ 重写。

## 写作要求

- 直接用条目写，不写前言、不写「本文将……」。
- 每个字段写可执行内容，不写形容词堆叠。
- 用户已给的设定优先，缺的字段标「待确认」，不自行补成事实。
- T1/T2 调 `popwave-write-idea` 时，`task` 分别传 `T1`、`T2`，context 按 SKILL.md 配方组装。
