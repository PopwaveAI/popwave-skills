# 《参照文提炼卡》模板

> 用途：A 路（用户提供参考原文）的产出物。提炼**可复用配方**，不复述剧情、不复制原文句子。
> 交付方式：**由 AI 填好并定案**（六问答案、每维改造首选、红灯改造方案**全部自己定**）→ 第五节适配体检 → 汇总改造纲领 → 反推六问答案 → **整套交用户过目，用户改哪项改哪项**（2026-09-23 改：原为"填好后交用户确认 → 有红灯项就逐项弹选项让用户定方向"）。
> **两条红线**：① 版权——提炼配方 ≠ 搬运内容，情节骨架/人物关系/设定名词必须差异化改造（番茄 2026 年 7 月单月下架侵权网文 5829 篇、封禁账号 91 个）；② 平台适配——参照文写得好 ≠ 能上番茄，**拆完不裁决等于把死配方交给用户**（见第五节）。

## 基本信息

| 项 | 内容 |
|----|------|
| 参照作品 | （书名/作者，用户提供的原文或链接） |
| 原文体量 | （字数/章节数，用于判断是否全量拆或抽样拆） |
| 用户想搬什么 | （用户原话，逐条记录） |

## 一、可搬配方（拆出来的、能复用的写法规律）

| 维度 | 提炼结果 | 证据（原文第 N 章/哪一段） |
|------|----------|----------------------------|
| 情绪标签归属 | 六类中归哪类（打脸爽文/极致虐恋/爆笑反套路/悬疑惊悚/治愈甜宠/脑洞大开），或复合 | |
| 开篇结构 | 前 3 章各做了什么（第1章钩子/第2章兑现/第3章升级），前 50 字用的是什么句式 | |
| 节奏配比 | 每几章一个情绪单元、爽点间隔、单章场景数、章末钩子类型分布 | |
| 冲突结构 | 核心冲突类型 + 冲突升级阶梯（对手怎么逐级变强） | |
| 立意落点 | 深层立意是什么，落在哪些具体剧情/选择上（**不从原文抄句子，要复述其机制**） | |
| 人物关系 | 主角-对手-盟友的张力结构（身份/欲望/反差点三要素） | |
| 文风特征 | 句长分布、叙述/对话比、口头禅与用词习惯（判断是否可迁移） | |
| 评论区机制 | 争议点/两难设计在哪、读者会吵什么 | |

## 四、差异化改造清单（必填，防侵权）

## 五、番茄适配裁决（必填，防白拆）

对照 `references/adaptation-decision.md` 逐项打灯。**只要有 1 个红灯，就必须给出 AI 的改造方案（首选 ＋ 备选 ＋ 代价）并写进《改造纲领》**（方案素材见该文件第三节）。**用户不改即采用**（2026-09-23 改：原为"逐项弹改造选项请用户拍板，用户没拍板不进 `00-大纲.md`"）。

| 检查项 | 原文表现 | 灯（绿/黄/红） | 番茄及格线 | 改造方案（红灯时 AI 出首选 ＋ 理由） | 备选与代价 |
|--------|----------|----------------|------------|----------------------------|----------|
| 开篇钩子 | | | 前 50 字内出现反常/危机 | | |
| 类型归属 | | | 番茄六大情绪标签池内 | | |
| 情绪密度 | | | 每章 ≥1 情绪爆点 | | |
| 单章字数 | | | 2200-2800 | | |
| 视角结构 | | | 主角视角 ≥70% | | |
| 结局形态 | | | 明确胜负/HE | | |
| 卖点性质 | | | 情绪爽感 | | |
| 章末钩子 | | | 每章有钩且类型轮换 | | |

**体检结论**（三选一）：

- ☐ 全绿 → 可直接搬配方，无需改造
- ☐ 有黄灯无红灯 → 按提示改造，记入纲领
- ☐ **有红灯 → AI 已出改造方案（首选＋备选＋代价）并写入《改造纲领》，用户可改**
- ☐ 用户选择保留原调性（走出口）→ 已如实告知数据预期，决定记入 `00-大纲.md`「作者决策」区
