# 去AI味改写

> 对中文正文跑一次标点与字形规范化，并按五条原则自检。创作管线里唯一的改写执行方，**执行者是脚本，不是模型**。

## 做什么

跑一次脚本，把正文的标点与字形规范化，并给主角与重要角色加引号；写回并留档；按五条原则自检一遍；回报一行。

**不做**：不做强度分级、不做前后对照、不做整章模型改写、不动用词与句式、不承诺任何降幅。

**为什么执行者是脚本**：实测降分红利全部来自标点与字形，字词层实测无效；整章模型改写不但没有分数贡献，实测还会把红利吃掉（同一章：只跑脚本 0.6405，脚本加改写 0.7671），且一次要十分钟。所以改写那一层不恢复。

## 五原则（判定与自检口径）

这五条是本 skill 的判定口径，逐条来自本包 CHANGELOG 里已经记过的规则，不是新拟的。前三条由脚本报数，后两条交付前自己过一遍。

| # | 原则 | 出处 | 怎么查 |
| :-- | :-- | :-- | :-- |
| 1 | 长句不串动作 | 脚本 CHECKS 第 1 项 | `--json` 里 long_action 的命中数 |
| 2 | 同义短语不重复 | 脚本 CHECKS 第 2 项 | `--json` 里 repeat_phrase 的命中数 |
| 3 | 情绪不直说 | 脚本 CHECKS 第 3 项 | `--json` 里 emotion_direct 的命中数 |
| 4 | 内容守恒 | CHANGELOG v6.2.0 质量校验第 2 道 | 人名、地名、道具名、数字一个不丢；字数波动 ±10% 以内 |
| 5 | 不承诺降幅 | CHANGELOG v6.0.0 定位 | 回执与对作者的说明里不出现任何降幅数字 |

第 1 到 3 条是报数项，脚本不做改写，命中数不下降不阻断交付；第 4、5 条是硬条，不过就重跑。

## 走法

1. 定位正文文件。
2. 复制一份改前稿留底。
3. 取名单：从章纲或角色卡读出本章的**主角与重要角色**姓名，只取姓名，不读正文、不改正文。
4. 跑脚本：`python "<包根>\scripts\deai_gate.py" <文件> --fix --names "主角、重要角色"`。脚本原地改写。
5. 写回与留档（仅管线内）：新正文写回原文件，旧正文留一份历史档。
6. 回报：回执一行，附本次修复条目。

**除了第 3 步取名单，这一步不经过模型**：名字由 agent 从章纲或角色卡读出后作为参数传入。不许手工替改标点，不许顺带动字词。用词、句式、语感一律不动。

## 脚本位置与参数

**脚本位置**：`scripts/deai_gate.py`，路径相对**本包根目录**展开。本包根目录 = 本 skill 的 SKILL.md 所在目录，即你读取本 SKILL.md 时那个绝对路径的父目录（系统提示 `<available_skills>` 里该 skill 的 `<location>` 也是它），命令行等价于 `--skill` 的取值，逐台机器不同。不要写死绝对路径，不要用 `<pop-ai-reduce-lite 包根>/...` 这类写法，也不要到磁盘上搜脚本。

**参数表**，以 `python <包根>\scripts\deai_gate.py --help` 为准：

| 参数 | 作用 |
| :-- | :-- |
| `<文件>` | 位置参数，必填。本脚本只处理单个正文文件 |
| `--fix` | 原地机械修复，标点与字形归位，改后文本写回原文件 |
| `--names` | 主角与重要角色名单，顿号或逗号分隔。给了才做「加引号」这一项，不给则跳过 |
| `--name-marks` | 每个人名最多标几处，默认 4 |
| `--name-max` | 全文最多标几处，默认 12 |
| `--json` | 输出 JSON，供 agent 消费 |
| `-h` / `--help` | 打印用法 |

脚本只有以上参数。**不存在 `--profile`、`--prof`、`-r`**，这三项已于 2026-09-20 移除，不要试。报「找不到文件」时，脚本会打印它实际找的完整绝对路径与用法，照那条路径改一次即可，不要搜索磁盘。

## 标点与字形

动哪些项由脚本定，本文件不逐条列，也不在别处解释。这一轮的口径不写进回执，也不讲给作者听——作者要的是改后的正文。

一处要说清：**对话引号保持原样，不再全量转成直角引号**；直角引号只加在 `--names` 给出的名字上。名字落在对话引号内部时会读成「……「某某」……」，这是这套写法的已知观感代价，先接受。

## 回执

```
去AI味:正文|PASS
```

## 红线

1. 只跑脚本，不改字词、句式、语感。
2. 旧正文必须留档，不许直接覆盖丢了。
3. 只交改后的正文，不讲这一轮改了什么、按什么标准改的。
4. 不承诺任何降幅数字，不说「能改到什么程度」。
5. 只查不改的场景下，一个字都不许改。
6. 工程标签不动（锚点、刻度、单元边界这类精确技术名不属于叙事主体）。
7. 取名单只取姓名，不把正文读进上下文，不改正文。
8. 五原则的第 4、5 条不过就重跑，不许把没验过的稿子交出去。
