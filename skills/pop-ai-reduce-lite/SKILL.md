# 去AI味

> 一条动作：agent 读完正文，给主角与重要角色的名字加中文引号，每一处都加。没有脚本，没有检查项。

## 做什么

agent 读正文，在主角与重要角色的名字上加直角引号「」；写回并留档；回报一行。

## 加引号的做法

**名单。** 从章纲或角色卡取本章的主角与重要角色，不凭记忆。名单只装主角与重要角色，不装只在某一句里露面的龙套。

**全量。** **名单里的名字每出现一次就加一次「」**，不留没加的。两条理由：一是实测全量降幅最大，20 章真实正文命中 19/20、平均降 0.25，比「只加几处」的配方高近一倍；二是章内一致，读者不会看到同一个名字一处加了、另一处没加。

**只加不改。** 插「」两个字符，不改字、不删字、不调语序。名字已经落在直角引号里的不再重复加。

**已知代价。** 两条，先接受：一是密度高，全量约每万字 82 处，是真人网文里拿「」标人名最激进那一部（每万字 2.6 处）的约 32 倍；二是名字落在对话引号内部时会读成「……「某某」……」。

## 不做

不改标点、不改字形、不改字词、不改句式、不做语感改写、不跑任何脚本、不做前后对照、不承诺任何降幅数字。

## 走法

1. 定位正文文件。
2. 复制一份改前稿留底。
3. 从章纲或角色卡取出本章的主角与重要角色名单。
4. 读正文，按上一节给名单里的名字加直角引号。
5. 写回：新正文写回原文件，旧正文留一份历史档。
6. 回报：回执一行，附本次加了几处。

## 回执

```
去AI味:正文|PASS
```

## 红线

1. 只许插「」两个字符，不许改任何已有的字。
2. 名单从章纲或角色卡取，不凭记忆。
3. 旧正文必须留档，不许直接覆盖丢了。
4. 只交改后的正文，不讲这一轮改了什么、按什么标准改的。
5. 不承诺任何降幅数字，不说「能改到什么程度」。
6. 只查不改的场景下，一个字都不许改。
