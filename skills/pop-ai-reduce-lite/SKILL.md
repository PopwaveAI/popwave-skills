# 去AI味改写

> 对中文正文跑一次标点与字形规范化。创作管线里唯一的改写执行方，**执行者是脚本，不是模型**。

## 做什么

跑一次脚本，把正文的标点与字形规范化；写回并留档；回报一行。

**不做**：不做强度分级、不做前后对照、不做语感改写、不动用词与句式、不承诺任何降幅。

**为什么只剩脚本**：实测降分红利全部来自标点与字形，字词层实测无效；语感改写不但没有分数贡献，实测还会把红利吃掉（同一章：只跑脚本 0.6405，脚本加语感改写 0.7671）。所以语感那一层整体撤掉。

## 走法

1. 定位正文文件。
2. 复制一份改前稿留底。
3. 跑脚本：`python "<包根>\scripts\deai_gate.py" <文件> --fix`。脚本原地改写。
4. 写回与留档（仅管线内）：新正文写回原文件，旧正文留一份历史档。
5. 回报：回执一行，附本次修复条目。

**这一步不经过模型**：不许手工替改标点，不许顺带动字词。用词、句式、语感一律不动。

## 脚本位置与参数

**脚本位置**：`scripts/deai_gate.py`，路径相对**本包根目录**展开。本包根目录 = 本 skill 的 SKILL.md 所在目录，即你读取本 SKILL.md 时那个绝对路径的父目录（系统提示 `<available_skills>` 里该 skill 的 `<location>` 也是它），命令行等价于 `--skill` 的取值，逐台机器不同。不要写死绝对路径，不要用 `<pop-ai-reduce-lite 包根>/...` 这类写法，也不要到磁盘上搜脚本。

**参数表**，以 `python <包根>\scripts\deai_gate.py --help` 为准：

| 参数 | 作用 |
| :-- | :-- |
| `<文件>` | 位置参数，必填。本脚本只处理单个正文文件 |
| `--fix` | 原地机械修复，标点与字形归位，改后文本写回原文件 |
| `--json` | 输出 JSON，供 agent 消费 |
| `-h` / `--help` | 打印用法 |

脚本只有以上参数。**不存在 `--profile`、`--prof`、`-r`**，这三项已于 2026-09-20 移除，不要试。报「找不到文件」时，脚本会打印它实际找的完整路径与用法，照那条路径改一次即可，不要搜索磁盘。

## 标点与字形

动哪些项由脚本定，本文件不逐条列，也不在别处解释。这一轮的口径不写进回执，也不讲给作者听——作者要的是改后的正文。

## 回执

```
去AI味:正文|PASS
```

## 红线

1. 只跑脚本，不改字词、句式、语感。
2. 旧正文必须留档，不许直接覆盖丢了。
3. 只交改后的正文，不讲这一轮改了什么、按什么标准改的。
4. 不承诺任何降幅数字，不说「能改到什么程度」。
5. 只查不改的场景下，一个字都不许改。
6. 工程标签不动（锚点、刻度、单元边界这类精确技术名不属于叙事主体）。
