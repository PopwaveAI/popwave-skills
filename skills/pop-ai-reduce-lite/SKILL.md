# pop-ai-reduce-lite · 快速去AI味

> v2.0.0 | 单轮4步管线 · 纯减法 · 零迭代 · 不改内容 · 表面降噪

## 管线顺序

```
Step 1: 结构骨架破坏   —— 砍模板头尾 + 打散三段式
Step 2: 句长随机化      —— 插极短句打破15-25字均匀区 [不拆叙述连续性]
Step 3: 破折号+英文引号+对仗 —— 兜底清理表层字符
Step 4: 过渡词替换      —— 词表替换为口语连接词
```

> 定位：**表层降噪器，不是润色器。** 不改角色感受、情节推进、场景描写。深层AI味（情感扁平、Telling）走 V4。

## ❌ 质量红线

| # | 红线 |
|:-:|:-----|
| ❌1 | **读取文件用 Get-Content -Encoding UTF8 -Raw** — Read 工具会截断 |
| ❌2 | **一轮完成禁止迭代** — 4步执行完即交付，不回改不微调 |
| ❌3 | **不修改内容** — 只做表层替换和删除，不删不改情节、感受、描写 |
| ❌4 | **一次任务仅一章** — 严禁单次任务改写多章 |

## 强弱加载保障

- **强保障**：本 SKILL.md 红线每次 run 强制注入，100% 到达 agent 上下文
- **弱保障**：`steps/pipeline-execute.md`、`templates/rewrite-output.md` 需 agent 主动读取
