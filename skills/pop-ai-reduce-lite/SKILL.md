# 去AI味

> 一条动作：agent 读完正文，给重要人名加中文引号。没有脚本，没有检查项。

## 做什么

agent 读正文，在重要人名上加直角引号「」；写回并留档；回报一行。

## 加引号的做法

**名单。** 从章纲或角色卡取本章的主角与重要角色，不凭记忆。名单只装主角与重要角色，不装只在某一句里露面的龙套。

**篇数。** 一章加 2 处完全无效，加 8 处起效。**一个人名最多 4 处，全章最多 12 处**，在全文里均匀铺开，不管送检方怎么切块，每块都能落到几处，不要都挤在同一段。出现次数最多的那个人名优先。

**位置。** 加在人物被当作话题、称谓、对象的位置，不是每个主语都加。照《十日终焉》的做法。

**只加不改。** 插「」两个字符，不改字、不删字、不调语序。名字已经落在直角引号里的不再重复加。

**已知代价。** 名字落在对话引号内部会读成「……「某某」……」。这是这套写法的观感代价，先接受。

## 不做

不改标点、不改字形、不改字词、不改句式、不做语感改写、不跑任何脚本、不做前后对照、不承诺任何降幅数字。

## 走法

1. 定位正文文件。
2. 复制一份改前稿留底。
3. 从章纲或角色卡取出本章的主角与重要角色名单。
4. 读正文，按上一节给重要人名加直角引号。
5. 写回：新正文写回原文件，旧正文留一份历史档。
6. 回报：回执一行，附本次加了几处。

## 回执

```
去AI味:正文|PASS
```

## 红线

1. 只许插「」两个字符，不许改任何已有的字。
2. 名单从章纲或角色卡取，不凭记忆。
3. 旧正文必须留档，不许直接覆盖丢了。
4. 只交改后的正文，不讲这一轮改了什么、按什么标准改的。
5. 不承诺任何降幅数字，不说「能改到什么程度」。
6. 只查不改的场景下，一个字都不许改。
