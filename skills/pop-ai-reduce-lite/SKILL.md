# pop-ai-reduce-lite · 快速去AI味

> v2.1.0 | 单轮4步管线 · 能改不删 · 零迭代 · 不改内容 · 表面降噪
>
> ⚠️ **路由规则**：仅当用户明确说"快速降AI味"/"快速去AI味"或使用 /pop-ai-reduce-lite 命令时启用。用户只说"降AI/去AI味/润色"→ 那是 `pop-ai-reduce` 的职责，不要抢。

## 管线顺序

```
Step 1: 结构骨架改写   —— 模板头尾改成场景化表达 + 打散三段式
Step 2: 句长随机化      —— 插极短句打破15-25字均匀区 [不拆叙述连续性]
Step 3: 破折号+英文引号+对仗 —— 兜底清理表层字符
Step 4: 过渡词改写      —— 词表改写为口语连接词
```

> 定位：**表层降噪器，不是润色器。** 不改角色感受、情节推进、场景描写。能改不删——保留信息，换掉套话外壳。深层AI味（情感扁平、Telling）走 `pop-ai-reduce`。

## ❌ 质量红线

| # | 红线 |
|:-:|:-----|
| ❌1 | **读取文件用 Get-Content -Encoding UTF8 -Raw** — Read 工具会截断 |
| ❌2 | **一轮完成禁止迭代** — 4步执行完即交付，不回改不微调 |
| ❌3 | **不修改内容** — 只做表层改写和替换，不改情节、感受、描写 |
| ❌4 | **一次任务仅一章** — 严禁单次任务改写多章 |
| ❌5 | **字数保留率 ≥ 85%** — 改后字数不得低于原文85%，否则回查过度删除 |

- **弱保障**：`steps/pipeline-execute.md`、`templates/rewrite-output.md` 需 agent 主动读取
