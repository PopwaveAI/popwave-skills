# 输出模板

## 输出规则

改写完成后生成 **两个独立文件**。

---

## 输出位置与覆盖保护

1. 输出目录：`d:\Popwave项目\降AI版本\`
2. 文件命名：`{章节名}_纯文.txt` 和 `{章节名}_报告.txt`
3. **覆盖保护**：写入前检查文件是否已存在——
   - 不存在 → 直接创建
   - 已存在 → 自动追加版本后缀 `_v2`、`_v3`……直到不冲突
4. 原文文件不动，只产出改写版本

---

### 文件 1：纯正文（`{章节名}_纯文.txt`）

完整可读的小说正文。无任何技法标注、无分析标记。

```
[标题/章节名]

[段落1正文]

[段落2正文]

...
```

---

### 文件 2：简要报告（`{章节名}_报告.txt`）

```
============================================================
改写报告（pop-ai-reduce-lite v2.0.0）
============================================================

一、基础数据
原文字数：XXXX
改后字数：XXXX

二、各步执行概要
Step 1 结构破坏：砍头X句 / 砍尾X句 / 三段式打散：是/否
Step 2 句长随机化：均匀区X处 → 插入极短句X处 / 无均匀区，跳过
Step 3 破折号清理：原文X个 → 保留X个（密度：X个/500字）
   英文引号清理：X处 → 已全部替换为中文引号
   对仗清理：命中X处 → 已拆散
Step 4 过渡词替换：命中X处 → 已替换/删除

三、红线自检
[ ] 内容未被修改（情节、感受、描写完整保留）
[ ] 破折号 ≤ 1个/500字
[ ] 英文引号已全部清除
```
