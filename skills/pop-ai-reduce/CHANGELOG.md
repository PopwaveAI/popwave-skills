## v4.2.2 (2026-08-13)

措辞修正：多技法协同为主轴，走神降为约束。

### 修改

- **`SKILL.md`**：标题从"18技法+比例框架+深度区集中走神"改为"18技法按段落功能协同（走神仅限深度区≤5%）"；红线 #2/#3 从"全文均匀走神=新规律 / B3只在深度区"改为"按段落功能匹配技法，单一技法重复=新规律 / 技法按段落功能协同（动作B5/内心A6/情绪A7+B6/对话C4C5，走神B3仅限深度区）"
- **`skill.json`**：description 从"18技法+比例框架+节奏规划+深度区集中走神"改为"18技法按段落功能协同+节奏规划，走神仅限深度区"

### 背景

v4.1.0 已引入 18 技法协同（地基A1/D1/A2 60-70% + 质感B5/A6/A7+B6 20-25% + 深度B3/B2 10-15%），但 SKILL.md 强保障层的标题和红线反复强调"走神"，使 agent 注意力错误集中在 B3 上。本次修正措辞，让"多技法协同"成为主轴，走神（B3）仅作为深度层的一个占比约束。

## v4.2.1 (2026-08-13)

修复：子Agent 不写文件，返回结果给主Agent 落盘。

### 修复

- **`subagent-execution.md`**：子Agent 职责从"输出双文件"改为"返回正文+分析报告数据"；主Agent 工作从"展示路径"改为"收到结果→写入双文件→展示"

- **恢复 v3.3.0 的「输出位置（强约束）」**：`templates/rewrite-output.md` 补回"产出写入「正文-降AI味版本」文件夹、不覆盖原文"段；`SKILL.md` 新增红线 #7"禁止覆盖原文"。此约束在 v4.x 重构时曾丢失

## v4.2.0 (2026-08-12)

合并执行步骤：6步→4步（-33% 模型轮次）。

### 背景

基于 Run 637b36fc / dbbae295 的实际数据：每次 run 消耗 6 轮模型往返，其中 Step 1 朱雀预估 + Step 2a 节奏规划 是同一"扫描判断"思维链，Step 4 句长检查 + Step 5 双文件输出 是同一"检查+输出"链。分开执行增加 2 轮冗余往返。

### 修改

- **`steps/pipeline-execute.md`**：Step 1+2a 合并（朱雀预估+节奏规划）、Step 4+5 合并（句长检查+双文件输出）、Step 2 段落分层独立保留（依赖深度区选定结果，保持质量）、Step 3 叠层改写独立保留（核心创作，全注意力）。快速模式同步压缩为 3 步。
- **`SKILL.md`**：版本 4.1.1→4.2.0、速查表更新步骤描述
- **`references/subagent-execution.md`**：执行指令更新为 4 步流程

### 预期效果

- 每 run 模型轮次：6 → 4（-33%）
- 工具调用：~8 → ~6
- Step 2 和 Step 3 保持独立，分层质量和改写质量不回退

## v4.1.0 (2026-08-12)

18技法 + 比例框架 + 节奏规划 + 深度区集中走神。

### 背景

v4.0.0 实测发现：B3 联想发散（走神）全文均匀散落 → 叙事节奏混乱（"每段都在走神"）。真正的人味应该是"不同质感的人味"，而非"同一种走神反复使用"。

### 新增

- **6 种新技法**：A6 不确定表达、A7 自纠、B5 身体知觉、B6 微动作链、C4 社交误读、C5 回忆比对
- **`references/techniques.md` 新增「技法比例约束」段**：三层框架（地基60-70%/质感20-25%/深度10-15%）+ 段落级组合约束
- **`steps/pipeline-execute.md` 新增 Step 2a「节奏比例规划」**：
  - 标注可深度处理候选区
  - 按章节字数选定 1-2 个深度区（B3 走神集中投放）
  - 段落功能标签分配（动作→B5 / 内心→A6 / 情绪→A7+B6 / 对话→C4+C5）
  - 技法比例预算核查
- **`references/subagent-execution.md`**：技法预注入升级为"按段落功能匹配的比例框架"
- **Step 3 新增段落级组合约束**：单段 ≤3 种技法、相邻两段不重复、B3 只在深度区

### 修改

- **SKILL.md**：版本 4.0.0→4.1.0、红线新增#3(必做Step 2a)/#4(B3只在深度区)、速查表更新
- **`steps/pipeline-execute.md`**：Step 2 改为"基于 Step 2a 规划结果"、Step 3 L2 示例改用 B5 身体知觉替代 B3 走神、L1 示例标注干净叙述、Step 3 新增段落级约束
- **`references/fallback-strategy.md`**：快速模式 Step 2' 新增"只选 1 个深度区"
- **红线顺序重排**：原#4(禁重试)→#6、原#5(禁微调)→#7
