# pop-ai-reduce · 网文降 AI 检测率

> 分层叠层改写引擎。12 轮朱雀实测验证——单技法无效，多技法叠层才有效。

## ❌ 质量红线

| # | 红线 |
|:-:|:-----|
| ❌1 | **读 reference 文件用 Get-Content -Encoding UTF8 -Raw** — Read 工具会截断 |
| ❌2 | **每处操作必须叠至少 2 层技法** — 单技法操作朱雀无视 |
| ❌3 | **必须执行段落分层（L3/L2/L1/L0）** — 全文统一处理 = 无效 |
| ❌4 | **膨胀比 ≤ 1.5** — 超过后朱雀和读者都感知异常 |
| ❌5 | **改写后必须做句长检查** — 连续3句15-25字区间 = 朱雀秒抓 |
| ❌6 | **禁止词汇替换** — 改"仿佛"为"好像" = 朱雀反升 |
