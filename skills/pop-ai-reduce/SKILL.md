# pop-ai-reduce · 网文降 AI 检测率

> 分层叠层改写引擎。12 轮朱雀实测验证——单技法无效，多技法叠层才有效。

## 任务前置（强约束）

**每次任务仅处理一章正文。** 拆章原则：

| 规则 | 说明 |
|:---|:-----|
| 一次任务 = 一章 | 无论用户给多少章，单次任务只改写一章，写完交付后再接下一章 |
| 超量必拆 | 用户给多章时，主Agent 先按章拆分，逐章发起独立子Agent任务，禁止一章塞多章 |
| 单章边界 | 单章内可含多个段落区间（L3/L2/L1/L0），但文本范围不得跨章 |
| 章节识别 | 以"第X章""第X节"或章节标题为边界，无明确边界时以用户划分的原文块为一章 |

> 为什么：降AI改写是深度逐句改写，上下文越长子Agent注意力越稀释、膨胀比越难控，单章是已验证的稳定处理单元。

## 执行模式

**改写工作必须由子Agent执行，主Agent只负责确认任务和组装上下文。**

| 角色 | 职责 |
|:---|:-----|
| **主Agent** | ①确认原文 + 角色认知体系 ②按 `references/subagent-execution.md` 组装干净上下文 ③启动子Agent ④展示结果 |
| **子Agent** | 读所有skill文件 → 执行5步流水线 → 输出双文件 → 返回摘要 |

> 为什么：主Agent上下文被历史对话污染，注意力稀释导致效果下降。子Agent拿到干净上下文，全注意力专注改写。详见 `references/subagent-execution.md`。

## 质量红线

| # | 红线 |
|:-:|:-----|
| 1 | **一次任务仅一章** — 严禁单次任务改写多章，超量先拆章，逐章发起独立任务 |
| 2 | **读 reference 文件用 Get-Content -Encoding UTF8 -Raw** — Read 工具会截断 |
| 3 | **每处操作必须叠至少 2 层技法** — 单技法操作朱雀无视 |
| 4 | **必须执行段落分层（L3/L2/L1/L0）** — 全文统一处理 = 无效 |
| 5 | **膨胀比 ≤ 1.5** — 超过后朱雀和读者都感知异常 |
| 6 | **改写后必须做句长检查** — 连续3句15-25字区间 = 朱雀秒抓 |
| 7 | **禁止词汇替换** — 改"仿佛"为"好像" = 朱雀反升 |
| 8 | **固定双文件输出到「正文-降AI味版本」文件夹** — 输出①纯正文 + ②分析报告，禁止合并输出或技法标注混入正文，禁止覆盖原文 |

## 输出格式（必读）

改写完成后必须生成 **两个独立文件**：

| 文件 | 内容 | 要求 |
|:---|:-----|:-----|
| **纯正文** | 完整可读的改写后小说，无任何技法标注、分层标记 | 可直接贴朱雀检测 |
| **分析报告** | 分层明细表 + 朱雀预估 + 句长检查 + 膨胀比 + 破折号密度 + 技法统计 | 不混入正文 |

> 禁止输出类似"区间A: L3, A1+A2+B1+B3"分散在各处的碎片化结果。两个文件各自完整、独立。

### 输出位置（强约束）

**产出文档绝不覆盖原文，必须写入新建的「正文-降AI味版本」文件夹。**

| 规则 | 说明 |
|:---|:-----|
| 创建文件夹 | 在原文所在目录下新建 `正文-降AI味版本/`，若已存在则复用不重建 |
| 双文件入夹 | 两个输出文件（纯正文 + 分析报告）都存进该文件夹 |
| 原文不动 | 原文文件保持原样，禁止在原文件上覆盖/改写 |
| 命名规范 | 文件名保留章节辨识度，如 `第X章_降AI味_纯文.txt`、`第X章_降AI味_报告.txt`；多章任务按章命名隔离 |
| 路径告知 | 主Agent 在子Agent 上下文中明确给出输出文件夹路径，子Agent 写入后返回完整路径 |

> 为什么：原文是唯一真源，覆盖即丢失。独立文件夹隔离降AI版本，方便对比、回溯与多章分批处理。

## 破折号与"不是…而是…"使用限制

| 约束 | 说明 |
|:---|:-----|
| 破折号密度 ≤ 1个/100字 | 改写后统计全文破折号总数，除以字数 ≤ 0.01。超标则替换为逗号/句号/冒号分流 |
| 禁止连续两句使用破折号 | 同一自然段内，破折号之间至少间隔 1 句无破折号句 |
| "不是…而是…"每500字 ≤ 1次 | AI高频句式，过量触发朱雀。可用"没…就…""不像…倒像…""说不上…反正…"等变体替代 |

> 破折号和"不是…而是…"不是不能用——是在正确的叙述视角下用（角色即时反应/认知过程），禁止作为叙述模板反复使用。

## 朱雀基准：Agent自判

**不获取原始朱雀值。** Agent 基于原文文本特征自行预估：

| 特征 | AI高风险信号 |
|:---|:-----|
| 概括式内心活动 | "他脑子里飞速运转""职业病犯了"等陈述式心理 |
| 外貌描写式人物出场 | "五十来岁的老头，满脸褶子，胡子拉碴" |
| 环境描写为纯客观陈述 | "正墙上挂着…""堂下摆着…"无感官过滤 |
| 句长集中在15-25字 | 连续多句落在此区间 |
| "不是…而是…"高频 | 每千字超过2次 |

预估原则：以上特征每命中1项 +0.10-0.15。原文毫无AI味的网文约0.30-0.50，标准AI生成文约0.90-0.99。
