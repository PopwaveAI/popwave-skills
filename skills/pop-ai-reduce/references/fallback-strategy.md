# 超时降级策略：回收 → 快速模式

> 子Agent 超时不等于任务失败。先回收结果，回收失败再进快速模式。

## 为什么需要降级梯子

基于 2026-08-11 实际 run 数据（Run 22c12ae8）：

| 实测数据 | 数值 |
|:---|:---|
| 子Agent 完成 4500 字章节改写 | 8-11 分钟 |
| 宿主超时阈值 | 5 分钟 |
| 子Agent #1 结果到达时间 | 超时信号后 4 分钟 |
| 子Agent #2 结果到达时间 | 超时信号后 9 分钟 |
| 主Agent 亲自执行（4轮迭代） | 6 分钟 + 30+ 工具调用 |

**核心洞察：子Agent 实际能完成任务，结果在超时后延迟到达。一旦主Agent 接手，质量下降导致迭代螺旋。**

## L2：回收超时结果

子Agent 返回 `subagent_timeout` 后，主Agent **不立即进入快速模式**，先执行回收检查：

1. **等待 30 秒**：给宿主子Agent 通道缓冲时间
2. **检查结果文件**：查找子Agent 对应 `result.json` 是否已落盘
   - 路径模式：`{project}/.paopao/projects/{projectId}/runs/{runId}/subagents/{subagentId}/result.json`
3. **结果判定**：
   - 结果已到达且 `status=ok` → 直接使用子Agent 产出，展示给用户
   - 结果未到达 → 进入 L3 快速模式

> 如果宿主环境无法直接访问子Agent 结果文件，跳过回收检查，直接进快速模式。

## L3：主Agent 快速模式

当回收失败、主Agent 必须亲自执行时，走简化流程：

### 快速模式 vs 标准模式

| 维度 | 标准模式（子Agent） | 快速模式（主Agent） |
|:---|:---|:---|
| 段落分层 | 4 级（L3/L2/L1/L0）+ 区间约束 | 全文统一 L2 层 |
| 技法叠层 | 四层叠（A1+A2+B1+B3） | 三层叠（A1+B1+B3） |
| 句长检查 | 禁连击>3 + 必须有极短/超长句 | 只禁连击>5 |
| 迭代 | 允许 1 轮微调 | **禁止微调** |
| 质量目标 | 朱雀 ≤ 0.50 | 降幅 ≥ 20% 或 连击 ≤ 3 |

### 快速模式 5 步（简化版）

**Step 1'：朱雀预估** — 同标准 Step 1，基于原文文本特征自判。

**Step 2'：全文 L2 层** — 不做段落区间划分，全文统一 L2 半滤（每 2-3 句叠 1-2 层技法）。对话段原样保留。

**Step 3'：三层叠改写** — A1 感官过滤 + B1 内心独白 + B3 联想发散。不强制 A2 判断插入和四层叠，降低单句复杂度。

改前加载技法速查表（嵌入主Agent 上下文，不额外读文件）：

```
A1 感官过滤：不描述客观事实，描述角色接收信息的过程
B1 内心独白：把人物当下的混乱想法写出来
B3 联想发散：从当前事物联想到完全无关的事物
D1 句长极端：混合极短句(≤5字)和超长逗号句(≥50字)
```

**Step 4'：句长粗检 + 表层收尾** — 只检查 15-25 字最长连击是否 > 5。> 5 则原地打断（拆句或加极短句），只改 1 处。不要求"每段必须含极短+超长句"。**表层收尾必做（简化版）**：英文引号/标点全改归零 + 对话开头破折号删净。表意破折号限频、不是而是限频为可选（快速模式止损优先）。

**Step 5'：双文件输出** — 同标准 Step 5。注意输出位置约束（`正文-降AI味版本/`）。

### 快速模式止损规则补充

快速模式自检增加一条：**英文引号归零 + 对话开头破折号清零，否则标注风险**（不回头改）。

### 快速模式禁令

| 禁止 | 原因 |
|:---|:-----|
| ❌ 写完后逐句微调高频词 | 引发迭代螺旋（本次 run：4轮） |
| ❌ 写完后逐段打断句长连击 | 同上 |
| ❌ 重跑验证后回头再改 | 一次 write 即终版 |
| ❌ 启动第二次子Agent | 浪费算力（本次 run：2次子Agent产出被丢弃） |

### 快速模式质量自检

写完后按以下规则判定，不达标在报告中标注即可，**不回头改**：

```
IF 朱雀预估降幅 ≥ 20% AND 连击 ≤ 3:
  → ✅ 直接交付
ELIF 降幅 < 20% OR 连击 > 5:
  → ⚠️ 报告中标注风险（如"日常内心段降幅仅7%，建议人工补刀"），仍交付
ALWAYS:
  → 高频词各降 ≥ 50% 即达标，不要求清零
  → 膨胀比 ≤ 1.5 即合规
```

## 上下文组装（快速模式用）

主Agent 快速模式时，在开始改写前先读取 `references/techniques.md`（使用宿主提供的文件读取工具），然后直接按快速模式 5 步执行。不需要组装子Agent 上下文。
