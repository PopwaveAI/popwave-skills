# 子Agent执行模式：上下文组装规范

## 为什么用子Agent

主Agent 执行降AI改写的效果通常不如子Agent，原因：

| 问题 | 主Agent | 子Agent |
|:---|:---|:---|
| 上下文污染 | 历史对话、其他项目文件引用混杂 | 干净上下文，只有任务相关文件 |
| 注意力稀释 | 前N轮对话的细节争夺注意力 | 全注意力聚焦当前文本 |
| 文件加载意愿 | 倾向于略读或不读 reference | 独立任务，会系统读完所有文件 |
| 质量检查深度 | 容易跳过 Step 2a/4 | 完整执行流水线 |

## 超时策略

**子Agent 只调 1 次，超时不重试。**

子Agent 返回 `subagent_timeout` 后，主Agent 按三级降级梯子处理：
1. **L2 回收**：检查子Agent 结果是否已到达 → 已到则直接用
2. **L3 快速模式**：回收失败则主Agent 亲自执行简化流水线

详见 `references/fallback-strategy.md`。

## 主Agent职责（确认 + 组装）

### 1. 确认任务参数

快速向用户确认：
- **拆章**：一次任务仅一章，用户给多章先按章拆分
- 角色的认知体系是什么——如果用户没给，主动问

### 2. 组装子Agent上下文（含技法比例速查）

```
【原文】
{粘贴当前章节完整文本（仅一章）}

【角色认知体系】
{主Agent确认或从原文提取的角色类比系统}

【技法比例速查（v4.1.0 预注入，按段落功能匹配）】
地基技法（全场景可用）：
  A1 感官过滤(≤30%)：描述角色接收信息的过程，非客观事实
  D1 句长极端(≤20%)：极短句(≤5字)+超长句(≥50字)混合
  A2 判断插入(≤10%)：极短个人判断（说实话/八成）
段落功能匹配（不同功能用不同技法，避免全文单一质感）：
  动作推进 → B5 身体知觉(≤8%)："松开的时候腮帮子酸了"
  内心独白 → A6 不确定表达(≤5%)："说不上来...也许是..."
  情绪反应 → A7 自纠+B6 微动作链(≤7%)：说错再改、小动作
  对话段   → C4 社交误读/C5 回忆比对（轻触）
深度技法（只在选定的1-2个深度区集中投放）：
  B3 联想发散(≤5%)：全文只在深度区走神，其余段落绝对不用
  B2 记忆提取(≤5%)：全文1-2次
核心原则：走神是甜品不是主食。全文用同一种人味=朱雀识别为新规律。

仍建议读取 references/techniques.md 获取完整18种技法定义和比例约束细则。

【输出位置】
{原文目录下「正文-降AI味版本」文件夹完整路径}
双文件入夹，原文不动。

【输出位置】
{原文目录下新建的「正文-降AI味版本」文件夹完整路径}
产出双文件（纯正文 + 分析报告）都写入此文件夹，绝不覆盖原文。

【执行指令】
1. 用 Get-Content -Encoding UTF8 -Raw 读取 steps/pipeline-execute.md 和 templates/rewrite-output.md
2. 按 pipeline-execute.md 执行：Step 1（朱雀预估）→ Step 2a（节奏比例规划）→ Step 2（段落分层）→ Step 3（叠层改写）→ Step 4（句长检查）→ Step 5（双文件输出）
3. 输出双文件到【输出位置】
4. 返回摘要：输出文件路径、朱雀预估对比、深度区位置、技法比例核查、膨胀比
```

> v4.1.0 变更：技法预注入从"6种速查"升级为"按段落功能匹配的比例框架"，新增 B5/A6/A7/B6/C4/C5 六种技法，明确 B3 走神仅在深度区使用。

## 子Agent职责（执行 + 输出）

1. 按 pipeline-execute.md 的 Step 1-5 完整执行（含 Step 2a 节奏规划）
2. 输出两个文件并返回执行摘要

## 上下文隔离规则

| 传入子Agent | 不传入子Agent |
|:---|:---|
| 用户原文全文（单章） | 历史对话记录 |
| 角色认知体系说明 | 其他项目的文件 |
| 技法比例框架速查 | 之前的改写版本 |
| 输出文件夹路径 | 降朱雀的讨论过程 |

## 主Agent确认清单

- [ ] 单次任务 = 单章（已拆分）
- [ ] 原文完整（未截断）
- [ ] 角色认知体系已标注
- [ ] 技法比例速查已嵌入上下文
- [ ] 输出文件夹路径已指定
- [ ] 已告知子Agent"读 pipeline-execute.md + rewrite-output.md 后执行，必须做 Step 2a"

## 返回后主Agent工作

子Agent 返回执行摘要后：
1. 展示两个文件的路径给用户
2. 简述核心数据（朱雀预估降幅、深度区位置、技法比例核查）
3. 提醒用户实测验证

**如果子Agent 超时**：进入回收→快速模式流程，**不重试子Agent**。
