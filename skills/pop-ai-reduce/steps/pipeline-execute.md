# 执行层：分层叠层改写

## Step 1+2a：朱雀预估 + 节奏比例规划

**不获取原始朱雀值。** Agent 基于原文文本特征自行预估基准值：

| 特征 | AI高风险信号 | 命中加分 |
|:---|:---|:---|
| 概括式内心活动 | "他脑子里飞速运转""职业病犯了"等陈述式心理 | +0.15 |
| 外貌描写式人物出场 | "五十来岁的老头，满脸褶子，胡子拉碴" | +0.10 |
| 环境描写为纯客观陈述 | "正墙上挂着...""堂下摆着..."无感官过滤 | +0.10 |
| 句长集中在15-25字 | 连续多句落在此区间 | +0.10 |
| "不是...而是..."高频 | 每千字 >2次 | +0.10 |
| 破折号高频 | 每百字 >1个 | +0.05 |

基准锚点：毫无AI味的网文约 0.30-0.50。标准AI生成文约 0.90-0.99。预估 = 锚点 + 命中加分。

### 节奏比例规划

> 全文均匀走神 = 新规律。集中火力在深度区，其余段落保持叙事干净。

### 1. 标注"可深度处理候选区"

扫描全文，找出以下类型的段落作为候选：
- 内心独白段（角色在思考/回忆/犹豫）
- 感官观察段（角色在感知环境，动作暂停）
- 情绪反应段（事件后的余波、情感消化）

### 2. 选定深度区（B3 联想发散的投放位置）

| 章节字数 | 深度区数量 | L3 总占比目标 |
|---|---|---|
| <2000 字 | 1 个 | 15-25% |
| 2000-4000 字 | 1-2 个 | 15-25% |
| >4000 字 | 2 个 | 20-30% |

深度区之间必须 ≥ 3 段叙事推进段做间隔。

### 3. 分配段落功能标签

对每个段落区标注功能，按功能匹配技法：

| 段落功能 | 分配技法组合 | 人味来源 |
|---|---|---|
| 动作推进 | B5 身体知觉 + A1 感官过滤 + D1 | 身体比脑子先反应 |
| 内心独白 | A6 不确定表达 + B1 + D1 | 人想问题不是线性的 |
| 情绪反应 | A7 自纠 + B6 微动作链 + A1 | 说错再改、小动作链 |
| 对话段 | C4 社交误读/C5 回忆比对（轻触，不叠） | 人聊天时会误读/对比 |
| 描写/观察 | A1 感官过滤 + A2 判断插入 + D1 | 注意力偏移、主观滤镜 |
| **深度区（L3）** | A1+A2+B1+B3 四层叠（全文仅此走神） | 集中爆发，不分散 |

### 4. 技法比例预算核查

改前按以下上限核查全文规划（详见 `references/techniques.md` 技法比例约束）：

| 层级 | 技法 | 占比上限 |
|---|---|---|
| 地基 | A1 感官过滤 | ≤ 30% |
| 地基 | D1 句长极端 | ≤ 20% |
| 地基 | A2 判断插入 | ≤ 10% |
| 质感 | B5 身体知觉（动作段） | ≤ 8% |
| 质感 | A6 不确定表达（内心段） | ≤ 5% |
| 质感 | A7 自纠 + B6（情绪段） | ≤ 7% |
| 深度 | B3 联想发散 | ≤ 5%（只在深度区） |
| 深度 | B2 记忆提取 | ≤ 5%（全文 1-2 次） |

## Step 2：段落分层

基于 Step 2a 规划结果，标注每个区间层级：

| 层级 | 操作密度 | 适用场景 |
|:---|:---|:---|
| **L3 全滤** | 每句叠 2-3 层技法 | **只有深度区**（内心独白+情绪余波），四层叠 |
| **L2 半滤** | 每 2-3 句叠 1-2 层 | 动作推进段、过渡段（B5+D1，不走神） |
| **L1 轻触** | 仅首尾句 | 纯描写段、对话前铺垫、叙事推进段（A1+A2+D1） |
| **L0 不动** | 不改 | 对话核心段、已有强人味的段落 |

**约束**：相邻区间层级差 ≤1。L0 ≤ 30%（对话占比 > 50% 时放宽至 ≤ 70%）。

## Step 3：叠层改写

**每处操作必须叠至少 2 层技法。** 深度区（L3）：A1+A2+B1+B3 四层叠。其他层按 Step 2a 分配的技法组合执行。

在改写前，先读取 `references/techniques.md` 获取完整技法定义（使用宿主提供的文件读取工具）。

### 段落级组合约束

- 单段技法种类 ≤ 3 种（**L3 深度区豁免**，四层叠 A1+A2+B1+B3 为框架明确要求）
- 相邻两段技法组合不重复
- B3 只出现在深度区，非深度区绝对不用

### L3 全滤示例（深度区专用）

原文："周围安静得过分。没有虫鸣，没有狗叫。"

改写："安静得让耳膜不舒服——不是在安静，是在压你。（A1+A2）你知道那种感觉吧？（A3）虫不叫了，狗不吭声了，大货车也没了。他想起上次民主生活会也是这么安静，十八个人，自由发言环节，一根针落地能听见。（B3+B2）"

### L2 半滤示例（动作推进，不用走神）

原文："然后他看见了。路边那棵老槐树的阴影里，蹲着个东西。"

改写："他看见了。老槐树底下蹲着个东西。不大，半米来高。说实话，第一反应不是害怕——是腮帮子先紧了，手在口袋里攥了个拳。（A1+B5）"

### L1 轻触示例（叙事推进，干净叙述）

原文："两条后腿直立，身披黄褐色的皮毛，一条蓬松的大尾巴垂在身后。"

改写：开头"两条后腿直立，皮毛是黄不拉几带点褐的颜色。（A1+A2）" 中间不动，尾句"那眼神吧，有点过于认真了。（A2+B4）"

### A5 出场改写

如果区间包含人物介绍：删掉所有外貌+气质+周围反应。让人物做一个只有他会做的行为。"门开的时候我正在倒茶。不是开门的声音让我抬头——是壶嘴的水柱忽然抖了一下。"

### 破折号与句式约束（改写字幕内）

- 破折号密度 ≤ 1个/100字
- 禁止连续两句使用破折号
- "不是...而是..." ≤ 1次/500字（含"不是X——是Y"变体）

## Step 3.5：表层收尾（必做，v4.3.0）

> **定位**：深度改写完成后必做的表面清理。只动标点/引号/句式，不叠技法、不改内容、不增字数。**不因深度通道豁免。**

### 第一类：明确错误（全改，零保留）

| 项 | 规则 | 示例 |
|---|---|---|
| 英文双引号 | `"` `"` → `""` | `"你好"` → `"你好"` |
| 英文单引号 | `'` `'` → `''` | `'他说'` → `'他说'` |
| 英文逗号 | `,` → `，` | `他说,对` → `他说，对` |
| 英文句号 | `.` → `。` | `走了.` → `走了。` |
| 英文感叹号 | `!` → `！` | `对!` → `对！` |
| 英文问号 | `?` → `？` | `是吗?` → `是吗？` |
| 英文冒号/分号 | `:` `;` → `：` `；` | `他说:好` → `他说：好` |

### 第二类：机械破折号（删，无表意）

| 项 | 规则 | 示例 |
|---|---|---|
| 对话开头破折号 | 删，保留原话 | `"——卧——"` → `"卧"` |
| 话尾悬空破折号 | 删或改省略号 | `"我在想——"` → `"我在想……"` |

### 第三类：连接破折号（改标点）

| 项 | 规则 | 示例 |
|---|---|---|
| 连续动作 | `动作A——动作B` → 逗号或句号 | `钥匙——转了半圈——门开了` → `钥匙转了半圈，门开了` |

### 第四类：表意破折号（保留 + 限频）

| 项 | 白名单 | 阈值 |
|---|---|---|
| 转折 | `不是A——是B` | 全文 ≤1/100 字 |
| 插入语 | `他——那个迟到的人——到了` | 全文 ≤1/100 字 |

### 降密执行顺序

1. 先删第二类（机械破折号）——通常占多数
2. 再改第三类（连接破折号）→ 逗号/句号
3. 最后统计第四类（表意破折号），若仍 >1/100 字，按表意必要性排序，保留最关键的，其余删/改

### "不是...而是..."（含变体）

| 项 | 规则 | 阈值 |
|---|---|---|
| 完整句式 | `不是A，而是B` | ≤1/500 字 |
| 破折号变体 | `不是A——是B` | 计入破折号限频，同时计入"不是而是"限频 |

超出阈值改法：`不是A——是B` → `不是A，是B`（去破折号，去"而"）。

### 边界与自检

| 边界 | 处理 |
|---|---|
| 破折号是角色口头禅/风格设计 | 白名单豁免：作者显式声明才保留 |
| 对话里表意省略号 `……` | 不在此规则范围，保留 |
| 英文引号出现在英文品牌名/代码 | 豁免（如 `"iPhone"` 保留） |

**自检清单**（Step 3.5 完成后）：
- [ ] 英文引号/标点已归零（豁免项除外）
- [ ] 对话开头破折号已清零
- [ ] 破折号密度 ≤1/100 字
- [ ] "不是...而是..." ≤1/500 字（含变体）

**单遍处理即停（防循环）**：Step 3.5 按四类规则**处理一遍即止**。自检清单核对后，未达标项**不回头再清**——在报告中标注未达标项，直接进入 Step 4+5。禁止"检查→清理→再检查"循环。

## Step 4+5：句长检查 + 双文件输出

### 句长检查

- 禁止连续 3 句落在 15-25 字区间
- L3/L2 段包含至少 1 句极短句（≤5字）和 1 句超长逗号句（≥50字）
- 分段：日常 3-6 句，紧张 1-2 句，禁止连续 5 个单句段
- **微调上限（防循环）**：如发现问题，**最多微调 1 轮**。1 轮后仍未达标 → 报告中标注"句长检查未完全达标（已微调1轮）"，直接进入双文件输出，禁止第 2 轮微调

### 双文件输出

改写完成后必须生成两个独立文件。**子Agent 模式下**：子Agent 直接写入双文件，返回元数据（路径+字节数+首末片段）给主Agent 轻量校验，不回传全文。

**文件 1：纯正文** — 完整可读的改写后小说，无任何标注，可直接贴朱雀检测。

**文件 2：分析报告** — 包含：朱雀预估对比、段落分层明细表（含功能标签）、技法比例核查、句长检查结果、膨胀比、表层收尾结果（英文引号/破折号/不是而是）。

# 快速模式（主Agent降级执行）

> 仅当子Agent 超时且回收失败时使用。详见 `references/fallback-strategy.md`。

## 快速模式 vs 标准模式

| 维度 | 标准模式（子Agent） | 快速模式（主Agent） |
|:---|:---|:---|
| 节奏规划 | 完整 Step 2a 规划 | 简化：只选 1 个深度区 |
| 段落分层 | 4级（L3/L2/L1/L0）+ 区间约束 | 全文统一 L2 层 |
| 技法叠层 | 按功能分配（B5/A6/A7/B6/B3） | 三层叠（A1+B1+B3），不用新技法 |
| 句长检查 | 禁连击>3 + 必有极短/超长句 | 只禁连击>5 |
| 迭代 | 允许 1 轮微调 | **禁止微调** |

## Step 1'：朱雀预估 + 深度区

同标准 Step 1+2a。简化：只选 1 个深度区。

## Step 2'：全文 L2 层 + 改写

不做段落区间划分，全文统一 L2 半滤。对话段原样保留。只选 1 个深度区投放 B3 走神。

## Step 3'：三层叠改写

A1 感官过滤 + B1 内心独白 + B3 联想发散（仅深度区）。不强求新技法（B5/A6/A7/B6）。

## Step 3'：句长粗检 + 双文件输出

只查 15-25 字连击是否 > 5。> 5 则原地打断 1 处即停。写完后按止损规则自检，不回头改：
- 降幅 ≥ 20% 且 连击 ≤ 3 → ✅ 交付
- 否则 → ⚠️ 报告中标注，仍交付，**不回头改**
