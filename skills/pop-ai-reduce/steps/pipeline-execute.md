# 执行层：分层叠层改写

## Step 1：朱雀预估（Agent自判）

**不获取原始朱雀值。** Agent 基于原文文本特征自行预估基准值：

| 特征 | AI高风险信号 | 命中加分 |
|:---|:-----|:---|
| 概括式内心活动 | "他脑子里飞速运转""职业病犯了"等陈述式心理 | +0.15 |
| 外貌描写式人物出场 | "五十来岁的老头，满脸褶子，胡子拉碴" | +0.10 |
| 环境描写为纯客观陈述 | "正墙上挂着...""堂下摆着..."无感官过滤 | +0.10 |
| 句长集中在15-25字 | 连续多句落在此区间 | +0.10 |
| "不是...而是..."高频 | 每千字 >2次 | +0.10 |
| 破折号高频 | 每百字 >1个 | +0.05 |

**基准锚点**：毫无AI味的网文约 0.30-0.50。标准AI生成文约 0.90-0.99。预估 = 锚点 + 命中加分。

## Step 2：段落分层

将原文划分为段落区间，每个区间标注：

| 层级 | 操作密度 | 适用场景 |
|--|--|--|
| **L3 全滤** | 每句叠 2-3 层技法 | 日常过渡段、内心独白段（朱雀高风险 + 低动作密度） |
| **L2 半滤** | 每 2-3 句叠 1-2 层 | 动作推进段（朱雀高风险 + 高动作密度） |
| **L1 轻触** | 仅首尾句 | 纯描写段、对话前铺垫 |
| **L0 不动** | 不改 | 对话核心段、已有强人味的段落 |

**约束**：相邻区间层级差 ≤1。L0 ≤ 30%。

## Step 3：叠层改写

**每处操作必须叠至少 2 层技法。** 最优组合：A1感官过滤 + A2判断插入 + B1内心独白 + B3联想发散（四层叠）。

在改写前，使用 `Get-Content -Encoding UTF8 -Raw references/techniques.md` 加载完整技法定义。

### L3 全滤示例

原文："周围安静得过分。没有虫鸣，没有狗叫。"

改写："安静得让耳膜不舒服——不是在安静，是在压你。（A1+A2）你知道那种感觉吧？（A3）虫不叫了，狗不吭声了，大货车也没了。他想起上次民主生活会也是这么安静，十八个人，自由发言环节，一根针落地能听见。（B3+B2）"

### L2 半滤示例

原文："然后他看见了。路边那棵老槐树的阴影里，蹲着个东西。"

改写："他看见了。老槐树底下蹲着个东西。不大，半米来高，说实话，第一反应不是害怕——是觉得这玩意儿站着的姿势有点滑稽。（A1+A2）"

### L1 轻触示例

原文："两条后腿直立，身披黄褐色的皮毛，一条蓬松的大尾巴垂在身后。"

改写：开头"两条后腿直立，皮毛是黄不拉几带点褐的颜色。（A1+A2）" 中间保持不动，尾句"那眼神吧，有点过于认真了。（A2+B4）"

### A5 出场改写

如果区间包含人物介绍：删掉所有外貌+气质+周围反应。让人物做一个只有他会做的行为。"门开的时候我正在倒茶。不是开门的声音让我抬头——是壶嘴的水柱忽然抖了一下。"

### 破折号与句式约束

改写过程中注意：
- 破折号密度 ≤ 1个/100字（统计全文后检查）
- 禁止连续两句使用破折号
- "不是...而是..." ≤ 1次/500字，用变体分流："没...，就...""不像...，倒像...""说不上...，反正..."

## Step 4：句长节奏检查

- 禁止连续 3 句落在 15-25 字区间
- L3/L2 段包含至少 1 句极短句（≤5字）和 1 句超长逗号句（≥50字）
- 分段：日常 3-6 句，紧张 1-2 句，禁止连续 5 个单句段

## Step 5：生成双文件输出

**改写完成后必须生成两个独立文件：**

### 文件 1：纯正文

- 完整可读的改写后小说
- 无任何技法标注、分层标记、方括号注释
- 无分析表格、统计数字
- 可直接复制粘贴到朱雀检测

### 文件 2：分析报告

包含以下内容：

1. **朱雀预估对比**：原文预估值 → 改写后预估值
2. **段落分层明细表**：每个区间的层级、字数变化、技法组合
3. **句长检查结果**：各层级抽样统计
4. **膨胀比**：总体 + 分层
5. **破折号密度检查**：全文破折号数 / 总字数
6. **技法使用统计**：每种技法使用次数和主要应用区间
