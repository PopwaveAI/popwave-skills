# 改写输出模板

## 输入格式

用户提供需要降AI的网文段落。可以是整章、片段或多段混排。

## 输出格式

按五步流程处理，输出的改写文本结构如下：

```
[标题/章节名]

[段落1 · L3/L2/L1层 · 技法组合标注]

改写后的段落正文。保留原剧情桥段不变，在语义层面注入角色意识活动。

[段落2 · L3/L2/L1层 · 技法组合标注]

改写后的段落正文。

...
```

## 输出质量检查

- [ ] 膨胀比 ≤ 1.5
- [ ] 每处操作叠 ≥ 2 层技法
- [ ] 无连续 3 句落在 15-25 字区间
- [ ] 原文核心桥段零丢失
- [ ] 无词汇替换痕迹（"仿佛"未改"好像"）
- [ ] 贴朱雀实测，AIGC ≤ 0.50 或较原文显著下降
