# 改写输出模板

## 输出位置（强约束）

**产出文档绝不覆盖原文，必须写入原文所在目录下新建的「正文-降AI味版本」文件夹。**

- 原文目录下新建 `正文-降AI味版本/`，已存在则复用
- 两个输出文件都存进该文件夹，原文文件保持原样、禁止覆盖
- 多章任务按章命名隔离（如 `第X章_降AI味_纯文.txt`）
- 写入后返回完整文件夹路径给主Agent

## 输出规则

改写完成后必须生成 **两个独立文件**，禁止合并输出或把技法标注混入正文。

### 文件 1：纯正文（`改写_*_纯文.txt`）

完整可读的小说正文，可以直接贴朱雀检测。

**格式要求：**
- 无任何技法标注（A1/A2/B1 等）
- 无任何分层标记（L3/L2 等）
- 无任何方括号注释
- 无分析表格、统计数字
- 就是一篇干净的小说正文

```
[标题/章节名]

[段落1正文]

[段落2正文]

...

——第X章完——
```

### 文件 2：分析报告（`改写_*_报告.txt`）

包含全部分析数据，不混入正文。

**必须包含：**

```
============================================================
改写分析报告
============================================================

一、朱雀预估
原文预估：X.XX
改写后预估：X.XX
预估降幅：-XX%

二、段落分层明细
区间 | 原文范围 | 层级 | 技法组合 | 原文字数 | 改后字数
A    | xxx      | L3   | A1+A2+B1+B3 | xx | xx
B    | xxx      | L2   | A5+A1     | xx | xx
...

三、句长节奏检查
区间A (L3): 极短句X处 ✓ / 超长句X处 ✓ / 3连15-25字: 无 ✓
...

四、膨胀比
总体：1.XX
分层：L3=X.X, L2=X.X, L1=X.X, L0=1.0

五、表层收尾检查（Step 3.5）
英文引号：X 个 → 0 ✓
英文标点：X 处 → 0 ✓
破折号：X 个 → Y 个（密度 X→Y 个/100字）
  机械删除：A 个 / 连接改写：B 个 / 表意保留：C 个
"不是...而是..."：X 次 → Y 次（含变体）

六、技法使用统计
技法 | 次数 | 主要区间
A1   | X    | A/B/D/...
...```

## 输出质量检查

- [ ] 纯正文无任何标注标记
- [ ] 膨胀比 ≤ 1.5
- [ ] 破折号密度 ≤ 1个/100字
- [ ] "不是...而是..." ≤ 1次/500字
- [ ] 每处操作叠 ≥ 2 层技法
- [ ] 无连续 3 句落在 15-25 字区间
- [ ] 原文核心桥段零丢失
- [ ] 无词汇替换痕迹（"仿佛"未改"好像"）
