## v0.11.0 | 2026-08-09

终稿出片定版：《苟在诸天从黑暗佛门开始》第1章五处问题一次修齐，vocabulary 与情绪表达升级。

### 背景
老板实测 v0.10 后反馈五处：① 切页面卡点对不上；② 字幕重叠；③ 声音太快；④ 配音很平；⑤ 缺章节信息页。并拍板「不烧字幕」。v0.11 以交付终稿标准重做。

### 修复
- **切页点严格对齐口播段边界**：`build_comic_video.py` 每页口播窗口 = 该页首句 start → 末句 end，xfade 过渡中心 = 上一页末句 end（即下一页口播开始），消除"切页与配音错位"。
- **不烧字幕**（老板拍板）：成品图已内嵌旁白/对白文字，烧口播字幕必然重叠，改为不烧。
- **语速 +8 → +5**：+8 仍偏快且抹平情绪，+5 更从容，让情绪指令有发挥空间。
- **配音加情绪指令**：seed-audio-1.0 是自然语言驱动音频大模型，在每段前用全角括号 `（低沉，恐惧地）` `（松了口气，温暖）` `（神秘，压低）` 等引导语气，**指令不会被念出**（ASR 验证过）。封面钩子句配 `（低沉，神秘地）`。
- **补章节封面/信息页**：从 `分享/长图-极乐.png` 顶部标题区裁出竖版封面（书名+章节号+钩子文案），作为视频开头信息页。

### 修改
- `scripts/build_comic_video.py`：整页顺序播放 + 封面信息页 + 切页点对齐口播段 + 不烧字幕（v0.10 已具备，v0.11 定版）。
- `steps/step4-render.md`：语速 +8→+5，补情绪指令说明（指令不进语音、对齐用纯文本）。
- `steps/step3-tts.md`：逐句拼接改整段合成（+5 + 情绪指令），产出改 `full_voice.mp3` + `对齐.json`。
- `SKILL.md`：版本升至 v0.11.0，Step 3/Step 4/速查表同步。

### 实测验证
- 第1章 v0.11：语速 +5 + 情绪指令整段合成配音（60.66s），ASR 对齐 8 段（封面+正文），整页顺序播放 + 封面信息页 + xfade 淡入淡出，不烧字幕。
- 抽帧校验封面/各切页点/各页中段全部正常：封面标题完整、切页点前后已切到对应页、画面无黑边、无字幕重叠。

## v0.6.0 | 2026-08-07

出片从「逐帧截图拼 MP4」升级为「浏览器自播 + 录屏」，性能提升一个数量级。

### 背景
原方案 `render_frames.py` 逐帧调用 `render(t)` 截图 PNG 再合成，本质等于"把 PPT 每一帧固化成图片"，吃性能。实测绯红第一章（57s@30fps）光渲染 1710 帧就要 7-10 分钟以上。

### 新增
- **`scripts/record_video.py`（方案 B 主路径）**：给已有 `render(t)` 的 HTML 注入自播时钟（`requestAnimationFrame` 按真实时间驱动），Playwright `record_video` 边播边录成 WebM，再转 MP4。**不落千张 PNG**，录屏时长 ≈ 动画时长。
- `--preset` 参数（veryfast/fast/medium）控制转码速度与质量，`--crf 18` 保画质。

### 修改
- `steps/step4-render.md`：出片主路径改为 `record_video.py` 录屏；`render_frames.py` 降级为**预览校验构图**用途（抓关键帧）。
- `references/comic-render-guide.md`：渲染命令改为录屏主路径 + 逐帧预览，写入实测数据。
- `SKILL.md` / `skill.json`：版本升至 v0.6.0，模型说明、Step 4、速查表同步。

### 实测验证（绯红第一章 57s 竖版）
- 方案 B 录屏 + 转码全程 ~86s 出片（录屏 60.5s + 转码 25.4s）。
- 产物 probe 校验：1080×1920 竖版、30fps、H.264、57.87s。
- 抽帧核查封面/分镜/字幕渲染正常，与逐帧方案画面一致。
- 对比：原逐帧方案光渲染 300 帧就 ~2 分钟（约 0.4s/帧），全量 1710 帧需 7-10 分钟以上。

## v0.3.0 | 2026-08-07

用《诡秘之主》第 1 章「绯红」实操验证整条出片链路，沉淀三个关键坑为文档铁律。

### 修复与沉淀
- **竖版渲染必须显式传 `--w 1080 --h 1920`**：`render_frames.py` 默认横版 1920×1080，漏传会把竖版 HTML 裁成横版（画面被砍、字幕错位）。实操曾产出错误横版视频，已把该约束写进 `step4-render.md` 与 `comic-render-guide.md`。
- **字幕必须带出场淡出防重叠**：字幕只写进场 `app()` 会导致同页两条字幕叠加重叠。改为 `app(进场)*out(出场)`，第二条进场前先淡出第一条。生命周期公式沉淀进 `comic-render-guide.md`。
- **混音改为按时间轴 adelay 定位**：新增 `scripts/mix_audio.py`（本轮实测），用 ffmpeg `adelay` 把每段配音定位到对应字幕时间点 + `amix` 混合，替代原 concat 拼接方案。`step5-mix.md` 重写。
- 配音时长驱动时间轴：每页时长 = 该页口播总时长 + 0.5s 余量，配音起始时间即该段字幕进场时间。

### 新增
- `scripts/mix_audio.py`：按 `--offsets "seg01.mp3=3.0,..."` 时间轴定位混入配音，可选 BGM（0.15）。

### 实操验证
- 用火山灿灿按口播脚本生成 10 段配音（seg01~seg10），重排竖版时间轴 57s，修复字幕重叠后合成 56.5s 竖版配音视频（1080×1920 30fps）。
