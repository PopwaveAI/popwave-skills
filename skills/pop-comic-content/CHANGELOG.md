## v0.11.0 | 2026-08-09

终稿出片定版：《苟在诸天从黑暗佛门开始》第1章五处问题一次修齐，vocabulary 与情绪表达升级。

### 背景
老板实测 v0.10 后反馈五处：① 切页面卡点对不上；② 字幕重叠；③ 声音太快；④ 配音很平；⑤ 缺章节信息页。并拍板「不烧字幕」。v0.11 以交付终稿标准重做。

### 修复
- **切页点严格对齐口播段边界**：`build_comic_video.py` 每页口播窗口 = 该页首句 start → 末句 end，xfade 过渡中心 = 上一页末句 end（即下一页口播开始），消除"切页与配音错位"。
- **不烧字幕**（老板拍板）：成品图已内嵌旁白/对白文字，烧口播字幕必然重叠，改为不烧。
- **语速 +8 → +5**：+8 仍偏快且抹平情绪，+5 更从容，让情绪指令有发挥空间。
- **配音加情绪指令**：seed-audio-1.0 是自然语言驱动音频大模型，在每段前用全角括号 `（低沉，恐惧地）` `（松了口气，温暖）` `（神秘，压低）` 等引导语气，**指令不会被念出**（ASR 验证过）。封面钩子句配 `（低沉，神秘地）`。
- **补章节封面/信息页**：从 `分享/长图-极乐.png` 顶部标题区裁出竖版封面（书名+章节号+钩子文案），作为视频开头信息页。

### 修改
- `scripts/build_comic_video.py`：整页顺序播放 + 封面信息页 + 切页点对齐口播段 + 不烧字幕（v0.10 已具备，v0.11 定版）。
- `steps/step4-render.md`：语速 +8→+5，补情绪指令说明（指令不进语音、对齐用纯文本）。
- `steps/step3-tts.md`：逐句拼接改整段合成（+5 + 情绪指令），产出改 `full_voice.mp3` + `对齐.json`。
- `SKILL.md`：版本升至 v0.11.0，Step 3/Step 4/速查表同步。

### 实测验证
- 第1章 v0.11：语速 +5 + 情绪指令整段合成配音（60.66s），ASR 对齐 8 段（封面+正文），整页顺序播放 + 封面信息页 + xfade 淡入淡出，不烧字幕。
- 抽帧校验封面/各切页点/各页中段全部正常：封面标题完整、切页点前后已切到对应页、画面无黑边、无字幕重叠。

## v0.8.0 | 2026-08-09

出片从「v0.7 缩放模板」重构为「逐格阅读相机系统」，并落地语速统一提速。

### 背景
老板实测 v0.7 缩放模板后否掉：漫画是分格叙事，Ken Burns 放大/缩小破坏格子与阅读节奏，且格/页硬切造成"剪映拼图"式生硬 gap。重构为逐格阅读——按分镜裁剪格子，相机在格间纯平移滚动，一格一格"读"过去。

### 新增
- **`references/scene-template.md` 重写为「逐格阅读相机系统」**：废弃 T1~T5 缩放模板，改为分镜标注（`分镜标注.json`，bbox 底部 ≤0.88 避水印）+ 格子裁剪（cover 填满无黑边）+ 横向胶片 strip + `translateX` 格间平移过渡（ease 0.45s）+ 字幕按时间窗显示。锁死 render 写法。
- **语速统一提速**：TTS 配音统一 `--speech-rate +20` 重合成，去除语速不均/偏慢（第1章实测总时长从 ~76s 压到 ~53s）。

### 修改
- `steps/step4-render.md`：重写为逐格阅读流程（标注分镜框 → 裁剪格子 → 排 HTML → 预览校验 → 录屏出片）。
- `references/comic-render-guide.md`：画面主体/动效改为逐格阅读，字幕改为按时间窗显示。
- `SKILL.md` / `skill.json`：版本升至 v0.8.0，描述/模型说明/Step 3/Step 4/速查表同步。
- `references/bgm-guide.md`：新增「火山引擎曲库能力 + 本地 BGM 兜底骨架」说明（智能创作云正版曲库 / 豆包音乐模型；本 skill 仍可不配乐，预留 `assets/bgm/` 兜底）。

### 修复
- **字幕永不显示 bug**：原 render 用格子 id（`P1-1`）匹配字幕 id（`seq1`），两者本就不同导致所有字幕 opacity 恒 0。改为按字幕 `start/end` 时间窗显示。

### 实测验证
- 《苟在诸天从黑暗佛门开始》第1章 v0.8：6 页 21 格逐格阅读，57.77s 竖版（1080×1920），统一提速配音混入，probe 校验 H.264+AAC 正常。
