# pop-comic-content

> 漫画 → 内容物料 skill。**模型读图自理解**漫画页（图片为主，`页面配置.json` 文字兜底）→ 一键产出三件套：**口播脚本**（视频配音用）+ **种草/安利笔记**（小红书/公众号）+ **短视频推广文案**（标题/封面/话题/简介话术）。**（可选）出片**：把确认后的口播脚本 + 漫画页图组装成竖版短视频（**整页顺序播放 + 章节封面信息页 + xfade 淡入淡出**，配整段火山灿灿配音，**不烧字幕**——成品图已内嵌文字，**切页点严格对齐口播段边界**）。**图片优先用 `分享/` 成品图**（有字/水印），无则回退 `output/` 生图。**先读图后产出**，产出一套后停下来等老板确认。v0.11.0

**核心定位**：把已成稿的漫画页（page1~N.png + 页面配置.json + OC/封面）转化为**可投放市场的内容物料**，服务"让更多人看到这部漫画"的推广目标。文本三件套是主产出；出片为可选项（复用 pop-video-brand 的确定性渲染引擎，画面适配漫画竖版）。

**读图为主、配置兜底（铁律）**：所有内容产出的依据是模型**读图**得到的剧情理解，`页面配置.json`/`导演卡.md` 的文字只做锚点与保真兜底。禁止不读图凭记忆编造漫画内容。

## 做什么

输入：漫画页图片（page1~N.png）+ `页面配置.json`（文字锚点）+ 可选 `导演卡.md`（剧情因果链）+ OC/封面图。
输出：一套内容物料（三份可投放文本）+ 可选一支竖版短视频。

| 产出 | 文件名 | 用途 | 主投平台 |
|:--|:--|:--|:--|
| 口播脚本 | `口播脚本.md` | 视频配音/解说稿 | 抖音/视频号/B站 |
| 种草笔记 | `种草安利笔记.md` | 图文安利笔记 | 小红书/公众号 |
| 推广文案 | `短视频推广文案.md` | 标题+封面+话题+简介话术 | 抖音/视频号 |
| 出片视频（可选） | `成品-配音.mp4` | 图片+字幕+配音 | 抖音/视频号 |

核心管线：**Step 0 收集 → Step 1 读图理解 → Step 2 内容创作【确认闸门】→ Step 3 配音（可选）→ Step 4 出片（可选）→ Step 5 混音（可选）→ Step 6 导出归档**。

## 模型说明

| 工序 | 工具/方式 | 说明 |
|:-----|:---------|:-----|
| 读图理解（画面+剧情） | 模型多模态读图 | 主 agent 直接 Read 漫画页，产出逐页画面白描 + 剧情因果锚点 |
| 内容创作 | DeepSeek/主 agent | 复用漫画剧情与卖点，按平台语法产出口碑内容 |
| TTS 配音（可选） | 火山灿灿 2.0（`scripts/tts_generate.py`） | key 固化在 `scripts/.env`（`VOLC_ARK_API_KEY`），自动读取 |
| 出片渲染（可选） | 浏览器自播+录屏（`scripts/record_video.py`） | HTML 编排稿自播，Playwright 录成 WebM 转 MP4，不落千张 PNG；画面走**逐格阅读相机**（分镜剪裁+平移） |
| 导出归档 | 主 agent 写文件 | 三件套+视频写入 `{项目}/内容/` 与 `{项目}/视频/` |

> 出片是**确定性渲染**（HTML+Playwright+ffmpeg），不走 AI 视频（Seedance/GenerateVideo）。若老板只要文本三件套，Step 3/4/5 可跳过。

## 怎么运作

### Step 0: 收集素材 → `steps/step0-collect.md`

- 扫描漫画章目录：**优先 `分享/page01~N.png` 成品图（有字/水印），无则回退 `output/page1~N.png` 生图** + `页面配置.json` + 可选 `导演卡.md`
- 定位 OC/封面图（种草笔记与推广文案的视觉素材）
- 产出 `素材清单.md`（含每页图片来源标注：分享/output）

### Step 1: 读图理解 → `steps/step1-understand.md`

- 逐页 Read 漫画图，产出每页【画面白描 + 氛围标签 + 剧情因果锚点 + 镜头感】
- **审查兜底**：图片被安全拦截时用 `页面配置.json` 对应文字补全，禁止中断
- 识别全章**剧情主线 + 高光/名场面 + 观众爽点/悬念**（口碑内容的核心卖点来源）
- 产出 `画面理解.md`

### Step 2: 内容创作 → `steps/step2-content.md` 【🚪 老板确认闸门】

基于画面理解 + 文字锚点，用**素材驱动 6 步创作法**（先想清楚再写，借 brand 骨架）一键产出三件套：

- `口播脚本.md`：钩子开头 + 每页 1-2 句口播 + 情绪线 + 章末钩子（供视频配音）
- `种草安利笔记.md`：小红书式图文笔记（吸睛标题 + 剧情亮点 + 视觉卖点 + 安利理由 + 话题标签）
- `短视频推广文案.md`：短视频标题 ×3 + 封面文案 + 热门话题标签 + 视频简介话术 + 评论区引导

产出三件套后**停下来等老板确认**，确认后才进入配音/出片/归档。

### Step 3: TTS 配音（可选）→ `steps/step3-tts.md`

- 火山灿灿 2.0 **整段合成**口播（复用 brand `scripts/tts_generate.py`），避免逐句拼接割裂
- **统一 `--speech-rate +5`**（比 +8 更从容，让情绪有发挥空间）
- **文案嵌入情绪指令**：每段前用全角括号 `（低沉，恐惧地）` 等引导语气（seed-audio-1.0 自然语言驱动，指令不会被念出）
- 输出 `audio/v{版本}/full_voice.mp3` + ASR 词级对齐 `对齐.json`（8 段：封面句 + 正文各段）

### Step 4: 出片渲染（可选）→ `steps/step4-render.md`

- **整页顺序播放**（漫画是分格叙事，禁止 Ken Burns 缩放）+ 开头**章节封面/信息页**（长图顶部标题区）+ **xfade 淡入淡出**
- **切页点严格对齐口播段边界**（每页末句 end，过渡中心 = 切页点）→ `scripts/build_comic_video.py`
- **不烧字幕**（成品图已内嵌文字，避免与画面文字重复/重叠）
- 竖版 1080×1920；**预览校验**：抽封面/各切页点/各页中段帧逐张审查（铁律）

### Step 5: 混音（可选）→ `steps/step5-mix.md`

- **BGM 选曲植入**（`references/bgm-guide.md`，按赛道×情绪选曲，如悬疑配青衣/fever pitch）
- 配音轨按**时间轴定位**混入视频（`scripts/mix_audio.py`，adelay+amix），配音对齐对应字幕时间点
- 可选 BGM（0.15 不压人声），产出 `成品-配音.mp4`

### Step 6: 导出归档 → `steps/step6-export.md`

- 三件套写入 `{项目}/内容/`，视频写入 `{项目}/视频/`
- 产出 `内容索引.md` 汇总

## 产出文件结构

> 落盘遵循 `pop-visual-pipeline/references/落盘规范.md` §3.1b §五 §六：文本三件套确认后在 `内容/`（内容成品），视频成品版本化+`-final`。

```
{漫画项目}/内容/
├── 素材清单.md           # Step 0 产出
├── 画面理解.md           # Step 1 产出（画面+剧情+卖点）
├── 口播脚本.md           # Step 2 产出①（视频配音）
├── 种草安利笔记.md        # Step 2 产出②（小红书/公众号）
├── 短视频推广文案.md      # Step 2 产出③（标题/封面/话题/简介）
└── 内容索引.md           # Step 6 产出

{漫画项目}/视频/         （若出片）
├── index.html + assets/  # Step 4 HTML 动效
├── preview/ + frames/    # Step 4 校验帧 + 全量帧（过程）
├── audio/seg{N}.mp3      # Step 3 配音（过程）
├── 第{N}章-v{版本}.mp4   # Step 4 无音轨（中间候选）
└── 第{N}章-配音-v{版本}-final.mp4  # Step 5 最终视频
```

## ❌ 铁律

| # | 铁律 | 违反后果 |
|:-:|:-----|:---------|
| ❌1 | **先读图后产出** — Step 1 必须先 Read 漫画页完成画面理解，禁止跳过读图直接凭项目记忆编造内容 | 内容与画面脱节，卖点虚构，口碑失真 |
| ❌2 | **读图为主、配置文字兜底** — 剧情理解以模型读图为主，`页面配置.json`/`导演卡.md` 文字做锚点；图片被安全审查拦截时用配置文字补全，禁止因读图失败中断 | 审查拦截页导致管线断裂，产出残缺 |
| ❌3 | **内容必须绑定真实剧情** — 种草/推广文案的卖点、亮点、悬念必须来自实际读图到的剧情，禁止虚构书中不存在的剧情或卖点 | 安利内容与漫画不符，读者落差，口碑反噬 |
| ❌4 | **产出三件套后停下等确认** — Step 2 产出完成必须停下来等老板确认，确认后才进配音/出片/归档；禁止一次性直接跑完全流程 | 方向跑偏，三件套白做，返工三份 |
| ❌5 | **出片走确定性渲染，不走 AI 视频** — 用 HTML+Playwright+ffmpeg 合成，禁止 Seedance/GenerateVideo 按秒生成的 AI 视频 | 成本失控、画面不可控、与漫画版式相悖 |
| ❌6 | **产出落盘版本化+final** — 文本三件套确认后在 `内容/`（内容成品）；出片视频命名 `第{N}章-配音-v{版本}-final.mp4`，禁止裸名 `成品.mp4`/`成品-配音.mp4`；`preview/frames/audio/` 是过程（见落盘规范 §3.1b §六） | 多版本无法区分、过程误当成品、与视觉管线脱节 |

## 前置条件

1. 漫画项目已存在（`output/page1~N.png` + `页面配置.json`，可选 `导演卡.md`）
2. OC/封面图尽量提供（种草/推广的视觉卖点）
3. 出片需：Python 3.8+ + Pillow + numpy + Playwright + Chromium + `imageio-ffmpeg`（完整版 ffmpeg）
4. 配音需：火山语音「豆包语音合成大模型」+ key 固化在 `scripts/.env`（`VOLC_ARK_API_KEY`，复制 `scripts/.env.example` 填入真实 key；不出片/不配音可跳过）
5. 输出目录可写
