# pop-comic-content

> 漫画 → 内容物料 skill。**模型读图自理解**漫画页（图片为主，`页面配置.json` 文字兜底）→ 一键产出三件套：**口播脚本**（视频配音用）+ **种草/安利笔记**（小红书/公众号）+ **短视频推广文案**（标题/封面/话题/简介话术）。**（可选）出片**：把确认后的口播脚本 + 漫画页图组装成竖版短视频（**整页顺序播放 + 章节封面信息页 + xfade 淡入淡出**，配整段火山灿灿配音，**不烧字幕**——成品图已内嵌文字，**切页点严格对齐口播段边界**）。**图片优先用 `分享/` 成品图**（有字/水印），无则回退 `output/` 生图。**先读图后产出**，产出一套后停下来等老板确认。v1.1.0

**核心定位**：把已成稿的漫画页（page1~N.png + 页面配置.json + OC/封面）转化为**可投放市场的内容物料**，服务"让更多人看到这部漫画"的推广目标。文本三件套是主产出；出片为可选项（确定性渲染：FFmpeg 整页拼接，TTS/混音脚本与 pop-video-brand 同源）。

**读图为主、配置兜底（铁律）**：所有内容产出的依据是模型**读图**得到的剧情理解，`页面配置.json`/`导演卡.md` 的文字只做锚点与保真兜底。禁止不读图凭记忆编造漫画内容。

**执行模式**：Step 0/1（素材收集 + 读图理解）是只读扫描/读图分析，可派子agent执行并回报（素材清单/逐页白描表/卖点识别），主agent落盘；Step 2 起进入老板确认闸门（需多轮交互确认），Step 2-6（创作/配音/出片/混音/归档）主agent直执。

## 做什么

输入：漫画页图片（page1~N.png）+ `页面配置.json`（文字锚点）+ 可选 `导演卡.md`（剧情因果链）+ OC/封面图。
输出：一套内容物料（三份可投放文本）+ 可选一支竖版短视频。

| 产出 | 文件名 | 用途 | 主投平台 |
|:--|:--|:--|:--|
| 口播脚本 | `口播脚本.md` | 视频配音/解说稿 | 抖音/视频号/B站 |
| 种草笔记 | `种草安利笔记.md` | 图文安利笔记 | 小红书/公众号 |
| 推广文案 | `短视频推广文案.md` | 标题+封面+话题+简介话术 | 抖音/视频号 |
| 出片视频（可选） | `第{N}章-配音-v{版本}-final.mp4` | 图片+配音 | 抖音/视频号 |

核心管线：**Step 0 收集 → Step 1 读图理解 → Step 2 内容创作【确认闸门】→ Step 3 配音（可选）→ Step 4 出片（可选）→ Step 5 混音（可选）→ Step 6 导出归档**。

## 模型说明

| 工序 | 工具/方式 | 说明 |
|:-----|:---------|:-----|
| 读图理解（画面+剧情） | 模型多模态读图 | 主 agent（或子agent）逐页 Read 漫画页，产出逐页画面白描 + 剧情因果锚点 |
| 内容创作 | DeepSeek/主 agent | 复用漫画剧情与卖点，按平台语法产出口碑内容 |
| TTS 配音（可选） | 火山灿灿 2.0（`scripts/tts_generate.py`） | key 固化在 `scripts/.env`（`VOLC_ARK_API_KEY`），自动读取 |
| 出片渲染（可选） | FFmpeg 图片序列+xfade（`scripts/build_comic_video.py`） | 整页顺序播放+封面信息页+切页点对齐口播段+不烧字幕，确定性渲染不落千张 PNG |
| 混音（可选） | `scripts/mix_audio.py` | ffmpeg adelay+amix 按时间轴定位混入，BGM 0.15 不压人声 |
| 导出归档 | 主 agent 写文件 | 三件套+视频写入 `{项目}/内容/` 与 `{项目}/视频/` |

> 出片是**确定性渲染**（脚本+FFmpeg），不走 AI 视频（Seedance/GenerateVideo）。若老板只要文本三件套，Step 3/4/5 可跳过。

## 怎么操作（SOP 全内联）

### Step 0: 收集素材

1. **扫描章目录**，确认素材源：
   - **图片两套来源（重点）**：`分享/page01~N.png` 成品图（含对白/旁白/水印，**优先**——投放市场的真实样子，读图与出片首选）；`output/page1~N.png` 生图（无字/无水印，**回退替补**——分享缺页时用对应页补齐，标注「成品图缺失，用生图回退」）
   - `页面配置.json`（每页文字锚点）
   - `导演卡.md`（可选：剧情因果链/高光名场面/旁白文案，卖点识别的保真锚点）
   - OC/封面图（可选，种草/推广的视觉素材，通常在 `成品/` 或 `漫画/assets/characters/`）
2. 读 `页面配置.json`，提取每页文字锚点清单（page / 文字锚点 / 类型 os|dialogue|narration）。
3. 读 `导演卡.md`（若存在），提取因果链摘要。
4. 用 PIL 记录每页图片数量与尺寸（供视觉描述/画布规划），**记录每页来源（分享/output）**。
5. 产出 `素材清单.md`：每页图片路径 + 来源 + 尺寸 + 文字锚点 + 导演卡摘要 + OC/封面路径。

**缺件兜底**：缺 `页面配置.json` → 跳过文字锚点纯读图（仍可走，锚点会弱）；缺 `导演卡.md` → 卖点识别只靠读图+页面配置；`分享/` 与 `output/` 都缺页 → 如实报告缺图，不编造。

**完成判定**：成品图优先已检查｜缺页回退已标注｜文字锚点已提取｜素材清单已写入（含来源标注）。

### Step 1: 读图理解

1. **逐页 Read 漫画图**（一次一页），每页产出五要素：

| page | 画面白描 | 氛围标签 | 剧情因果锚点 | 镜头感 | 展示模板 |
|:--|:--|:--|:--|:--|:--|
| page1 | 非对称三格，痛苦主体+青蓝裂纹 | 身体恐怖/心理惊悚 | 周明瑞头痛惊醒，穿越前奏 | 特写压迫 | T1@面部 |

   **展示模板**列：按画面特征映射 `T1`推近（特写）/`T2`拉远（全景）/`T3`横移（长横格）/`T4`纵移（竖分格）/`T5`驻留（情绪落幅）+ 聚焦点，供 Step 2 口播脚本引用，参数见 `references/scene-template.md`。

2. **审查兜底（铁律❌2）**：单页被安全审查拦截 → 用该页 `页面配置.json` 文字锚点 + `导演卡.md` 因果链补全画面理解，标注 `[读图被拦截，配置文字兜底]`；**禁止因读图失败中断管线**，继续处理下一页。
3. **氛围标签统一词汇表**：恐怖系（身体恐怖/心理惊悚/哥特恐怖/密恐/压迫）｜情绪系（脆弱/崩解/窒息/悬置/绝望）｜奇观系（史诗/壮观/神秘/崇高）。
4. **全章卖点识别**（口碑内容唯一素材源，铁律❌3 的保真基础）：剧情主线（一句话）｜高光/名场面（哪几页最抓眼球：视觉奇观/情绪爆发/剧情转折）｜观众爽点/悬念（为什么想看下去）｜可安利卖点（人设/画风/世界观/剧情冲突）。
5. 产出 `画面理解.md`（逐页五要素表 + 全章卖点识别）。

**完成判定**：所有页已处理（含拦截页兜底）｜每页五要素齐全｜卖点识别完成｜已落盘。

### Step 2: 内容创作【🚪 老板确认闸门】

**素材驱动 6 步创作法**（先想清楚再写，借 brand 骨架，"价值点"换成漫画"剧情卖点"）：

1. **提炼剧情真相**：这部漫画/这一章最打动人的是什么（从画面理解的卖点识别提炼）
2. **立定立意**：这套内容想让观众带走的一句话（北极星）
3. **选择角度**：从剧情卖点选切入（强钩子/悬念/情感/视觉奇观）
4. **铺设结构**：三件套功能位——口播=推进+情绪线；种草=感受+安利；推广=钩子+互动
5. **逐镜写作**：三件套逐条写，卖点全部来自画面理解
6. **闸门自检**：删掉画面描述只看文字，验证能讲清/有钩子/无虚构/像真人说话

**① 口播脚本.md**（视频配音用，直接进 Step 3/4）：

```
[钩子 0-5s]   开场 1-2 句抓注意力（设问/悬念/反差）
[展开 5-50s]  按页推进，每页 1-2 句口播，情绪线递进
[收尾 50-60s] 钩子留白/悬念，引导追读
```

每句口播字段（绑定 page，保证画面与口播同步）：`seq / page / text / emotion / est_sec / template / focus`

- **template**：该页展示模板（`T1`推近/`T2`拉远/`T3`横移/`T4`纵移/`T5`驻留），按情绪线选，参数见 `references/scene-template.md`
- **focus**（仅 T1/T3/T4 需要）：聚焦点或扫过方向（如 `T1@镜中白狗`、`T3@左→右`）；T2/T5 填 `—`

**② 种草安利笔记.md**（小红书/公众号）：

```
标题（吸睛，含情绪或悬念，≤20字）
正文（3-5 段）：开场钩子（"这部漫画第一页就让我头皮发麻..."）→ 剧情亮点（全章主线+高光名场面）
  → 视觉卖点（画风/人设/OC/封面）→ 安利理由（人设/世界观/悬念/爽点）→ 结尾钩子（埋追读悬念）
话题标签：#漫画推荐 #悬疑漫画 ...（5-8 个）
```

**③ 短视频推广文案.md**（抖音/视频号）：

```
标题 ×3（不同角度，各 ≤25 字，含钩子/反差/悬念）
封面文案（大字，≤8 字，一眼抓人）
热门话题标签（5-8 个，贴合平台热门池）
视频简介话术（完整简介：钩子+内容预告+引导关注）
评论区引导（3-5 条预埋互动话术，引导讨论）
```

**写作总原则**：①卖点全部来自画面理解（铁律❌3，禁虚构）②平台语法差异化（口播口语化叙述/种草感性安利/推广短平快钩子，三件套角度互补不重复同一句话）③钩子优先，开头不平铺直叙④情绪线贯穿（如"痛醒→陌生→穿越→恐惧→惊悚"递进）⑤每页至少 1 句且绑定 `page{N}`，总时长 ~60s（约 240-300 字），**每句必须指定 template**（镜头感标注，出片不自由发挥动效）⑥平台写法细节参照 `references/content-method.md`。

**🚪 确认闸门**：产出三件套后**停下来等老板确认**（铁律❌4）。确认后才进 Step 3/4/5（若要视频）+ Step 6 归档；只要文本不出片则跳过 Step 3/4/5 直接归档。

**完成判定**：口播有钩子+每页≥1句绑 page+情绪线递进+~60s+每句有 template/focus｜种草五要素齐｜推广五要素齐｜三件套卖点无虚构｜**已等老板确认**（未确认禁止进入出片/归档）。

### Step 3: TTS 配音（可选，火山灿灿）

**前置**：口播脚本已确认；火山控制台已开通「豆包语音合成大模型」；X-Api-Key 固化在 `scripts/.env`（`VOLC_ARK_API_KEY=<X-Api-Key>`，脚本自动读取；无 .env 则复制 `scripts/.env.example` 填入。key 获取：`https://console.volcengine.com/voice` → 开通豆包语音合成大模型 → API Key 管理复制 X-Api-Key）。

**操作**：

1. **文案嵌入情绪指令**：每段前用全角括号 `（低沉，恐惧地）` `（松了口气，温暖）` `（神秘，压低）` 等引导语气，封面钩子句配 `（低沉，神秘地）`。seed-audio-1.0 是自然语言驱动的音频大模型，括号指令调节念法且**不会被念出**（ASR 验证过）。
2. **整段一次合成**（含封面钩子句 + 正文全部，避免逐句拼接割裂/语速不均）：
   ```bash
   python scripts/tts_generate.py \
     --text "$(cat 口播全文含情绪指令.txt)" \
     --out "{项目}/视频/audio/v{版本}/full_voice.mp3" \
     --speech-rate 5
   ```
   - key 读取优先级：`--api-key` > 环境变量 `VOLC_ARK_API_KEY` > `scripts/.env`，三者皆缺脚本报错并提示配置
   - 默认音色灿灿；`--speaker` 可换其他音色（如 `zh_female_zhixingnv_uranus_bigtts` 知性女声）
   - **统一 `--speech-rate +5`**（v0.11 终稿：+8 偏快且抹平情绪，+5 从容让情绪指令有发挥空间）；必要时 `--loudness-rate/--pitch-rate` 微调
3. **ASR 对齐**：用 faster-whisper（small, word_timestamps）对整段音频做词级时间戳，按**纯文本（去掉情绪指令）**的汉字序列映射到每句，产出 `audio/v{版本}/对齐.json`（seq / start / end / duration / text；封面句为 seq0，正文各段依次）。对齐必须用纯文本——情绪指令不进语音、不占时长。

**失败处理**：整段合成失败重试整段；反复失败换 `--speaker` 备用音色，或对情绪指令做口语化微调。

**完成判定**：整段一次合成无割裂｜对齐.json 含全部句（封面 seq0+正文）的 seq/start/end/duration｜语速 +5 情绪指令生效（有起伏、无指令被念出）｜总时长与画面偏差可接受。

### Step 4: 出片渲染（可选）

**核心决策（v0.10 起定稿）**：

| 决策 | 定稿方案 |
|:--|:--|
| 页面形态 | **整页顺序播放**（漫画是分格叙事，禁止 Ken Burns 缩放） |
| 封面信息页 | **开头加章节封面/信息页**（长图顶部标题区，含书名+章节号） |
| 字幕 | **不烧字幕**（成品图已内嵌文字，避免重复/重叠） |
| 切页点 | **对齐口播段边界**（每页末句 end，xfade 过渡中心=切页点） |
| 配音 | **整段 TTS**（一次合成，语速统一无割裂） |

**输入**：老板确认的口播脚本｜漫画页（按素材清单来源记录取图，优先分享成品图）｜封面/信息页（`分享/长图-*.png` 顶部标题区 或 `成品/封面/*-final.jpg`，无则跳过封面）｜`对齐.json`（每句 start/end）｜`分镜标注.json`（可选，整页方案下主要用于页→seq 映射）。

**操作**：

1. **准备封面信息页**：优先 `分享/长图-*.png` 顶部标题区——按竖版宽高比裁顶部 `h = w/0.5625`，LANCZOS 缩放到 1080×1920 存 `cover.png`；无长图用 `成品/封面/*-final.jpg`（已竖版，直接缩放）。封面配口播首句（书名钩子，如"苟在诸天，从黑暗佛门开始。"）。
2. **切页点计算**（脚本内已实现）：每页口播窗口 = 该页首句 start → 末句 end；平滑处理消除句间 gap/重叠（`start = max(start, 前句end)`）保证切页点连续。
3. **FFmpeg 整页拼接**（`scripts/build_comic_video.py`）：
   ```bash
   python scripts/build_comic_video.py \
     --base <项目根目录> --share <分享成品图目录> \
     --align <对齐.json> --voice <整段配音.mp3> \
     --outdir {项目}/视频 --chapter N --v v{版本} \
     [--cover <封面.png> --cover-seq 0] \
     [--page-seq '{"cover":[0],"page01.png":[1,2],"page02.png":[3]}'] \
     [--trans 0.4] [--fg-h 1515]
   ```
   - `--page-seq`：页文件名→口播段 seq 列表（0-based）；缺省一页一段
   - 每输入 `-loop 1 -t dur -i img`；每输入 filter：背景 scale 1080:1920 + 模糊 + 压暗，前景等比缩放居中 overlay（分享页 820×1150 → 宽 1080 高 `FG_H=1515` 垂直居中）
   - 串联 `xfade`：`transition=fade duration=TRANS`，`offset = 上一页末句end - TRANS/2`；`TRANS=0.4`（比 0.5 利落）
   - 产出 `第{N}章-v{版本}.mp4`（无音轨中间候选）+ 自动混入整段配音 → `第{N}章-配音-v{版本}-final.mp4`（命名遵循落盘规范 §3.1b）
4. **逐帧校验（铁律）**：
   ```bash
   ffmpeg -ss <切页点> -i 第{N}章-配音-v{版本}-final.mp4 -frames:v 1 -q:v 2 check.png
   ```
   抽封面/各切页点/各页中段帧**逐张 Read 审查**：封面标题完整｜无黑边变形｜每页取景完整｜切页点前后已切到对应页｜无水印残留侵占｜无字幕与画面文字重叠。发现问题回改再出，直到通过。

**完成判定**：开头封面信息页（书名/章节号清晰无黑边）｜整页顺序播放无 Ken Burns｜切页点对齐口播段边界｜无字幕与画面文字重叠｜1080×1920 / 30fps / 时长与配音一致（probe 校验）。

> 出片是确定性渲染（FFmpeg 图片序列+xfade），不走 AI 视频。若老板只要文本三件套，本步可跳过。

### Step 5: 混音（可选）

1. **BGM 选曲**：按漫画**赛道 × 主要情绪段**从 `references/bgm-guide.md` 的「赛道 × 情绪 → 参考曲目」表选定（示例：悬疑赛道钩子段配 `青衣` 国风戏腔悬疑感；紧张/高潮段配 `fever pitch` 电子狂热感），BGM 放 `{项目}/视频/bgm/bgm-*.mp3`。老板已指定 BGM 则直接用，不重新选。
2. **配音/BGM 混入**（`scripts/mix_audio.py`，本质 ffmpeg adelay+amix+volume）：
   ```bash
   python scripts/mix_audio.py \
     --video 第{N}章-v1.mp4 \
     --audio-dir audio \
     --offsets "seg01.mp3=3.0,seg02.mp3=8.9,seg03.mp3=16.2,..." \
     --out 第{N}章-配音-v1-final.mp4 \
     [--bgm {项目}/视频/bgm/bgm-悬疑-青衣.mp3 --bgm-vol 0.15 --voice-vol 1.1]
   ```
   - `--offsets` 每项 `文件名=起始秒`，逗号分隔，与配音段一一对应；每段 `adelay` 延迟到对应时间点，`amix` 混合，`volume` 控制响度
   - 有 BGM 传 `--bgm`（音量 0.15 循环铺满全程、不盖人声）；无 BGM 省略，脚本自动只混配音
   - 注：整段配音流程（v0.11 起）的 final 已由 Step 4 的 `build_comic_video.py` 直接混入，本步主要用于 BGM 植入与逐段时间轴定位重混
3. **probe 校验**：分辨率 1080×1920｜时长正确｜含 AAC 音轨。

**完成判定**：BGM（若有）匹配赛道×情绪且 0.15 不压人声｜口播清晰、落在对应画面时间点｜probe 三项通过｜最终视频已交付。只要文本三件套本步可跳过。

### Step 6: 导出归档

1. **确认产出完整**：三件套 + 素材清单 + 画面理解均已存在且内容完整。
2. **写入目标目录**：文本三件套 → `{项目}/内容/`（确认后即内容成品）；视频（若出片）→ `{项目}/视频/`（`第{N}章-配音-v{版本}-final.mp4`）。命名遵循落盘规范 §3.1b。
3. **产出 `内容索引.md`** 汇总：
   ```markdown
   # 内容索引 · {章节名}

   章节：{章节名} | 产出日期：{date}
   来源：{漫画项目路径}

   ## 内容清单
   | 文件 | 用途 | 主投平台 |
   |:--|:--|:--|
   | 口播脚本.md | 视频配音/解说稿 | 抖音/视频号/B站 |
   | 种草安利笔记.md | 图文安利笔记 | 小红书/公众号 |
   | 短视频推广文案.md | 标题+封面+话题+简介 | 抖音/视频号 |
   | 第{N}章-配音-v{版本}-final.mp4 | 出片视频（若出片） | 抖音/视频号 |

   ## 核心卖点速览
   （一行列出本套内容的主打卖点，供后续投放时快速回顾）
   ```
4. 向老板汇报产出位置与内容索引。

**完成判定**：三件套+素材清单+画面理解全部在目标目录｜（若出片）final 视频已归档｜内容索引.md 已写入｜已向老板汇报。

## ❌ 铁律

| # | 铁律 | 违反后果 |
|:-:|:-----|:---------|
| ❌1 | **先读图后产出** — Step 1 必须先 Read 漫画页完成画面理解，禁止跳过读图直接凭项目记忆编造内容 | 内容与画面脱节，卖点虚构，口碑失真 |
| ❌2 | **读图为主、配置文字兜底** — 剧情理解以模型读图为主，`页面配置.json`/`导演卡.md` 文字做锚点；图片被安全审查拦截时用配置文字补全，禁止因读图失败中断 | 审查拦截页导致管线断裂，产出残缺 |
| ❌3 | **内容必须绑定真实剧情** — 种草/推广文案的卖点、亮点、悬念必须来自实际读图到的剧情，禁止虚构书中不存在的剧情或卖点 | 安利内容与漫画不符，读者落差，口碑反噬 |
| ❌4 | **产出三件套后停下等确认** — Step 2 产出完成必须停下来等老板确认，确认后才进配音/出片/归档；禁止一次性直接跑完全流程 | 方向跑偏，三件套白做，返工三份 |
| ❌5 | **出片走确定性渲染，不走 AI 视频** — 用脚本+FFmpeg 合成（整页顺序播放），禁止 Seedance/GenerateVideo 按秒生成的 AI 视频 | 成本失控、画面不可控、与漫画版式相悖 |
| ❌6 | **产出落盘版本化+final** — 文本三件套确认后在 `内容/`（内容成品）；出片视频命名 `第{N}章-配音-v{版本}-final.mp4`，禁止裸名 `成品.mp4`/`成品-配音.mp4`；`preview/frames/audio/` 是过程（见落盘规范 §3.1b §六） | 多版本无法区分、过程误当成品、与视觉管线脱节 |
