# 小说漫剧 BGM 选曲指南

> 为漫画漫剧视频挑选合适的背景音乐并植入。**先按赛道定曲风，再按情绪段挑曲目**，最后用 `mix_audio.py --bgm` 植入。BGM 服务于剧情氛围，不盖人声（音量 0.15）。

## 一、选曲原则

1. **赛道决定曲风底色**：先判断漫画所属赛道（悬疑/国风/都市/玄幻/甜宠…），选对曲风大类，再谈具体曲目。
2. **情绪段决定曲目**：同一支视频按场景情绪分段（钩子/紧张/悬念/高潮/收尾），每段可配同一曲或不同段切换。
3. **BGM 反向服务于字幕与配音**：BGM 的强弱起伏应贴合剧情节奏，不喧宾夺主——音量恒定 0.15，禁止盖过口播。
4. **曲目可替换**：下述为参考曲目与风格底色，实际以当前平台（抖音/视频号）热门曲库可用版本为准，找到同曲风替代即可。

## 三、植入方法

1. **选曲**：按漫画赛道 + 主要情绪段，从上方表选定 1 支 BGM（或按段分段选 2~3 支）。
2. **准备素材**：把 BGM 文件（mp3/wav）放到 `{项目}/视频/bgm/`，命名如 `bgm-悬疑-青衣.mp3`。
3. **混音植入**（Step 5 用 `mix_audio.py`）：
   ```bash
   python scripts/mix_audio.py \
     --video 成品.mp4 --audio-dir audio \
     --offsets "seg01.mp3=3.0,seg02.mp3=8.9,..." \
     --out 成品-配音.mp4 \
     --bgm {项目}/视频/bgm/bgm-.mp3 --bgm-vol 0.15 --voice-vol 1.1
   ```
   - 口播 1.1、BGM 0.15，混音时 BGM 自动循环铺满全程、不压人声。
4. **校验**：听一遍确认 BGM 不盖人声、强弱贴合情绪段；不合则换曲或调 `--bgm-vol`。

## 四、常见坑

- **BGM 盖过口播**：音量务必 ≤0.15，人声 1.0-1.1。BGM 是氛围底层，不是主声。
- **曲风与赛道错位**：悬疑赛道配甜宠钢琴、国风赛道配电子舞曲 → 出戏。先定曲风再选曲。
- **节奏与画面脱节**：高潮段配慢抒情曲、钩子段配重鼓 → 情绪塌。BGM 强弱要贴合时间轴情绪。
- **只当背景不选曲**：漫剧 BGM 是叙事的一部分，选曲要匹配剧情情绪，不能随便填一支。
