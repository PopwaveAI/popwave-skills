# 口碑内容方法论

> pop-comic-content Step 2 内容创作的参考方法。三件套（口播脚本 / 种草安利笔记 / 短视频推广文案）的平台语法与写法要点。

## 一、通用原则

1. **卖点来自真实剧情**：所有亮点的源头是 Step 1 读图得到的剧情理解，禁止虚构。可安利卖点五类：人设、画风、世界观、剧情冲突、悬念钩子。
2. **钩子优先**：所有内容第一句必须抓人，禁止平铺直叙"这是本漫画"。
3. **情绪线驱动**：从漫画的递进情绪（痛→陌生→恐惧→惊悚）提炼天然张力，作为内容骨架。
4. **平台语法差异化**：同一部漫画，三种内容要不同角度切入，避免复读同一句话。

## 二、口播脚本（视频配音）

- **口吻**：讲给朋友听，口语化，非书面朗读。
- **节奏**：钩子（0-5s）→ 展开（按页推进，每页 1-2 句）→ 收尾钩子（章末悬念）。
- **绑定**：每句标注 `page{N}`，保证画面与口播同步。
- **时长**：~60s，约 240-300 字，按 4-5 字/秒估算。
- **情绪标签**：紧张/惊悚/悬疑/崩溃/钩子，标注在每句。

## 三、种草安利笔记（小红书/公众号）

- **标题**：≤20 字，含情绪或悬念（"这部漫画第一页就让我头皮发麻"）。
- **正文结构**（3-5 段）：
  1. 开场钩子：第一句抓人，用具体画面/感受切入
  2. 剧情亮点：主线 + 高光名场面（视觉奇观/情绪爆发/转折）
  3. 视觉卖点：画风/人设/OC/封面的吸引力
  4. 安利理由：为什么值得看（悬念/爽点/世界观）
  5. 结尾钩子：埋追读悬念，引导关注
- **话题标签**：5-8 个，含大类（#漫画推荐）+ 垂类（#悬疑漫画 #暗黑系）+ 热点池。
- **语气**：感性安利，有个人感受，不冷冰冰介绍。

## 四、短视频推广文案（抖音/视频号）

- **标题**：3 条不同角度，各 ≤25 字。角度可拆：悬念式 / 反差式 / 情感式。
- **封面文案**：≤8 字大字，一眼抓人（如"开局就死了？"）。
- **话题标签**：5-8 个，贴合平台热门池 + 垂类标签。
- **简介话术**：完整简介 = 钩子 + 内容预告 + 引导关注（关注理由）。
- **评论区引导**：3-5 条预埋互动话术，引导讨论（设问/抛争议/求推荐）。

## 五、三件套角度互补模板

| 内容 | 切入角度 | 目的 |
|:--|:--|:--|
| 口播脚本 | 剧情推进 + 情绪线 | 让人看完视频 |
| 种草笔记 | 感受 + 亮点安利 | 让人想去看 |
| 推广文案 | 钩子 + 悬念 + 互动 | 让人点进来 |

> 无论哪种内容，核心红线：**卖点必须来自真实读图**，这是口碑内容可信度（不反噬）的根基。
