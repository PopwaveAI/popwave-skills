# Step 0: 收集素材

> pop-comic-content 入口。扫描漫画章目录，收集图片 + 文字锚点 + 视觉素材，产出素材清单。**图片优先用 `分享/` 成品图（有字/水印），无则回退 `output/` 生图（无字/无水印）**。

## 输入

- 漫画项目路径（如 `{项目}/漫画/第1章/`）
- 目标：找出读图理解所需的全部素材源

## 图片素材来源（重点：优先成品图）

章目录下通常有两套图：

| 目录 | 内容 | 用途 |
|:--|:--|:--|
| **`分享/`** | **成品图**（含对白/旁白/水印，`page01~N.png`） | **优先使用**：出片/种草/推广的正式素材，读图理解也优先看成品 |
| **`output/`** | **生图**（无字/无水印，`page1~N.png`） | **回退替补**：分享缺页或素材不够时用生图 |

> ⚠️ **优先从 `分享/` 找成品图**：成品图含对白、旁白、水印，是真正投放市场的样子，读图理解和出片都应优先用它。`output/` 生图是半成品，仅当分享缺失时才作为回退。若分享目录不全（如某页缺），可用 output 对应页补齐，但要标注「成品图缺失，用生图回退」。

## 操作

1. **扫描章目录**，确认以下文件存在：
   - **`分享/page01~N.png`（成品图，优先）**；若 `分享/` 不存在或缺页，则用 `output/page1~N.png`（生图回退）
   - `页面配置.json`（每页文字锚点，脚本骨架）
   - `导演卡.md`（可选，剧情因果链，保真兜底）
   - OC/封面图（可选，种草/推广的视觉素材，通常在 `成品/` 或 `漫画/assets/characters/`）

2. **读取 `页面配置.json`**，提取每页文字锚点到一个清单：

   | page | 文字锚点（台词/旁白/OS） | 类型 |
   |:--|:--|:--|
   | page1 | ... | os/dialogue/narration |
   | page2 | ... | ... |

3. **读取 `导演卡.md`**（若存在）：提取剧情因果链、高光/名场面、旁白文案，作为 Step 1 卖点识别的保真锚点。

4. **记录图片数量与尺寸**（用 PIL 读尺寸，确认比例，供种草/推广的视觉描述参考）。同时**记录每页用的是分享成品图还是 output 生图**。

5. **产出 `素材清单.md`** 到 `{项目}/内容/`，包含：每页图片路径 + 来源（分享/output）+ 尺寸 + 文字锚点 + 导演卡摘要 + OC/封面路径。

## 产出

- `{项目}/内容/素材清单.md`

## 完成判定

- [ ] 已检查 `分享/` 成品图是否存在，优先用成品图
- [ ] 分享缺页时用 output 生图回退，并在清单标注「生图回退」
- [ ] `页面配置.json` 已读取，每页文字锚点已提取
- [ ] `导演卡.md` 已读取（若存在），因果链摘要已收录
- [ ] 素材清单.md 已写入，含每页图片来源标注

> 若缺少 `页面配置.json`：跳过文字锚点，Step 1 完全依赖读图理解（仍可走，但剧情锚点会弱）。若缺少 `导演卡.md`：卖点识别只依赖读图 + 页面配置。若 `分享/` 与 `output/` 都缺页：如实报告缺图，不编造。
