# Step 0: 收集素材

> pop-comic-content 入口。扫描漫画章目录，收集图片 + 文字锚点 + 视觉素材，产出素材清单。

## 输入

- 漫画项目路径（如 `{项目}/漫画/第1章/`）
- 目标：找出读图理解所需的全部素材源

## 操作

1. **扫描章目录**，确认以下文件存在：
   - `output/page1~N.png`（漫画页，读图理解主力）
   - `页面配置.json`（每页文字锚点，脚本骨架）
   - `导演卡.md`（可选，剧情因果链，保真兜底）
   - OC/封面图（可选，种草/推广的视觉素材，通常在 `素材/视觉/` 或 `漫画/assets/characters/`）

2. **读取 `页面配置.json`**，提取每页文字锚点到一个清单：

   | page | 文字锚点（台词/旁白/OS） | 类型 |
   |:--|:--|:--|
   | page1 | ... | os/dialogue/narration |
   | page2 | ... | ... |

3. **读取 `导演卡.md`**（若存在）：提取剧情因果链、高光/名场面、旁白文案，作为 Step 1 卖点识别的保真锚点。

4. **记录图片数量与尺寸**（用 PIL 读尺寸，确认比例，供种草/推广的视觉描述参考）。

5. **产出 `素材清单.md`** 到 `{项目}/内容/`，包含：每页图片路径 + 尺寸 + 文字锚点 + 导演卡摘要 + OC/封面路径。

## 产出

- `{项目}/内容/素材清单.md`

## 完成判定

- [ ] `output/page1~N.png` 全部找到
- [ ] `页面配置.json` 已读取，每页文字锚点已提取
- [ ] `导演卡.md` 已读取（若存在），因果链摘要已收录
- [ ] 素材清单.md 已写入

> 若缺少 `页面配置.json`：跳过文字锚点，Step 1 完全依赖读图理解（仍可走，但剧情锚点会弱）。若缺少 `导演卡.md`：卖点识别只依赖读图 + 页面配置。
