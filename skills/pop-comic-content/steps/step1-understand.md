# Step 1: 读图理解

> pop-comic-content 核心差异化步骤：模型**读图自理解**漫画页，产出逐页画面白描 + 剧情因果锚点 + 全章卖点识别。图片为主，`页面配置.json`/`导演卡.md` 文字兜底。

## 输入

- `素材清单.md`（Step 0 产出）
- 漫画页图片 `output/page1~N.png`
- 可选 `导演卡.md`（剧情因果链，保真兜底）

## 操作

1. **逐页 Read 漫画图**（主 agent 直接 Read，一次一页），对每页产出四要素：

   | page | 画面白描 | 氛围标签 | 剧情因果锚点 | 镜头感 |
   |:--|:--|:--|:--|:--|
   | page1 | 非对称三格，痛苦主体+青蓝裂纹 | 身体恐怖/心理惊悚 | 周明瑞头痛惊醒，穿越前奏 | 特写压迫 |
   | ... | ... | ... | ... | ... |

2. **审查兜底（铁律❌2）**：单页被安全审查拦截时——
   - 用 `页面配置.json` 该页文字锚点 + `导演卡.md` 因果链补全画面理解
   - 标注该页 `[读图被拦截，配置文字兜底]`
   - **禁止因读图失败中断管线**，继续处理下一页

3. **氛围标签**用统一词汇表，便于内容创作阶段调用：
   - 恐怖系：身体恐怖 / 心理惊悚 / 哥特恐怖 / 密恐 / 压迫
   - 情绪系：脆弱 / 崩解 / 窒息 / 悬置 / 绝望
   - 奇观系：史诗 / 壮观 / 神秘 / 崇高

4. **全章卖点识别**（口碑内容的核心素材源，铁律❌3 的保真基础）：
   - **剧情主线**：一句话概括全章讲了什么
   - **高光/名场面**：哪几页最抓眼球（视觉奇观/情绪爆发/剧情转折）
   - **观众爽点/悬念**：读者为什么想看下去（悬念/爽点/钩子）
   - **可安利卖点**：能拿来做推广的亮点（人设/画风/世界观/剧情冲突）

5. 产出 `画面理解.md`。

## 产出

- `{项目}/内容/画面理解.md`（逐页四要素表 + 全章卖点识别）

## 完成判定

- [ ] 所有页已处理（含被拦截页的兜底补全）
- [ ] 每页有画面白描 + 氛围标签 + 剧情因果锚点 + 镜头感
- [ ] 全章卖点识别完成（主线/名场面/爽点悬念/可安利卖点）
- [ ] 画面理解.md 已写入

> 读图是主源，配置文字是兜底，两者在内容创作阶段交叉使用。卖点识别是 Step 2 口碑内容的唯一素材来源。
