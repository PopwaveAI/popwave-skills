# Step 4: 漫画页出片（整页顺序播放 + 封面信息页）

> 把老板确认的口播脚本 + 漫画页图片组装成竖版短视频。**v0.10 起走「整页顺序播放 + 封面信息页」确定性渲染**：开头放章节封面/信息页（`分享/长图` 或 `成品/封面` 顶部标题区），随后整页顺序展示分享成品图，页与页之间 **xfade 淡入淡出**，切页点严格对齐口播段边界。**不烧录口播字幕**（分享成品图已内嵌旁白/对话框文字，画面自带文本信息，配音承载听感，二者不重复）。出片用 FFmpeg 图片序列 + xfade 拼接（`build_v10.py` 思路），不走 AI 视频，不落千张 PNG。

## 输入

- 老板确认的 `口播脚本.md`（Step 2 产出）
- **漫画页图片（优先 `分享/` 成品图，无则回退 `output/` 生图）**——按 Step 0 素材清单的来源记录取图
- **封面/信息页**：`分享/长图-*.png`（章节长图）顶部标题区，或 `成品/封面/*-final.jpg`；无则跳过封面
- `对齐.json`（包含整段配音每句 start/end，Step 3 用 ASR 对齐产出）——**切页点 = 每页末句 end**
- `分镜标注.json`（可选，用于确认每页归属口播段；整页方案下主要用于页→seq 映射）

## 关键决策（v0.10 铁律）

| 决策 | v0.9 之前 | v0.10 |
|:--|:--|:--|
| 页面形态 | 逐格阅读 / 整页缩放 | **整页顺序播放**（漫画是分格叙事，禁止 Ken Burns 缩放） |
| 封面信息页 | 无 | **开头加章节封面/信息页**（长图顶部标题区，含书名+章节号） |
| 字幕 | 底部烧录口播字幕 | **不烧字幕**（成品图已内嵌文字，避免与画面文字重复/重叠） |
| 切页点 | 累计时长推算 | **对齐口播段边界**（每页末句 end，xfade 过渡中心=切页点） |
| 配音 | 逐句拼接 | **整段 TTS**（一次合成，语速统一，无割裂） |

## 操作

### 1. 准备封面信息页（可选但有则用）

- 优先用 `分享/长图-*.png` 顶部标题区：读取长图尺寸，按竖版 1080×1920 宽高比裁顶部 `h = w/0.5625`，`LANCZOS` 缩放到 1080×1920，存为 `cover.png`。
- 无长图则用 `成品/封面/*-final.jpg`（已是竖版，直接缩放）。
- 封面配口播首句（如书名钩子"苟在诸天，从黑暗佛门开始。"），作为整段文案开头。

### 2. 整段合成配音 + ASR 对齐（Step 3）

- **整段文案一次合成**（含封面钩子句 + 正文全部），`--speech-rate +5`（v0.11：+8 仍偏快且情绪空间不足，+5 更从容自然）。
- **文案嵌入情绪指令**：每段前用全角括号 `（低沉，恐惧地）` `（松了口气，温暖）` `（神秘，压低）` 等引导语气——seed-audio-1.0 是自然语言驱动的音频大模型，括号指令用于调节念法且**不会被念出来**（ASR 验证过）。封面钩子句配 `（低沉，神秘地）`。
- 用 faster-whisper（small, word_timestamps）对整段音频做 ASR，词级时间戳按汉字序列对齐到每句，产出 `audio/v{N}/对齐.json`（每句 start/end）。**对齐用纯文本（去掉情绪指令）**，因为指令不进语音。
- 平滑处理：消除句间 gap/重叠（`start = max(start, 前句end)`），保证切页点连续。

### 3. FFmpeg 整页拼接（核心）

参考工作区 `build_v11.py`（或 skill 内 `scripts/build_comic_video.py`）：
- 封面信息页 + 整页顺序播放 + xfade 淡入淡出，切页点严格对齐口播段边界

```python
# 每页 -> 口播段 seq 映射（0-based）
page_seq = {"cover": [0], "page01.png": [1,2], "page02.png": [3], ...}
# 每页口播窗口 = 该页首句 start -> 末句 end
page_bounds[p] = (min(smooth[s][0] for s in seqs), max(smooth[s][1] for s in seqs))
# 每页输入时长 = 口播时长 + TRANS
page_in_dur[p] = (page_bounds[p][1]-page_bounds[p][0]) + TRANS
# 每个输入: -loop 1 -t dur -i img
# 每输入 filter: 背景scale1080:1920+blur+压暗, 前景等比缩放居中 overlay
# 串联 xfade: transition=fade duration=TRANS, offset = 上一页末句end - TRANS/2
```

- 分享页 820×1150 → 前景等比缩放到宽 1080，高 `FG_H=1515`，垂直居中；背景模糊压暗填充 1080×1920。
- `TRANS=0.4`（淡入淡出 0.4s，比 0.5 更利落）。
- 输出 `第{N}章-v{版本}.mp4`（无音轨），再混入整段配音 → `第{N}章-配音-v{版本}-final.mp4`（命名遵循落盘规范 §3.1b）。

### 4. 逐帧校验（铁律）

```bash
ffmpeg -ss <切页点> -i 第{N}章-配音-v{版本}-final.mp4 -frames:v 1 -q:v 2 check.png
```

逐张 Read 审查：封面标题完整、无黑边变形、每页取景完整、切页点前后已切到对应页面、无水印残留侵占、无字幕与画面文字重叠。发现问题回改再出，直到通过。

## 产出

- `{项目}/视频/cover.png`（封面信息页，过程）
- `{项目}/视频/第{N}章-v{版本}.mp4`（无音轨中间候选）
- `{项目}/视频/第{N}章-配音-v{版本}-final.mp4`（最终视频，含整段口播，无额外字幕）

## 完成判定

- [ ] 开头有封面信息页（书名/章节号清晰，无黑边）
- [ ] 整页顺序播放，无 Ken Burns 缩放
- [ ] 切页点对齐口播段边界（校验帧在切页点前后已切到对应页）
- [ ] 无字幕与画面内嵌文字重叠/重复
- [ ] 1080×1920 / 30fps / 时长与配音一致（probe 校验）

> 出片是确定性渲染（FFmpeg 图片序列 + xfade），不走 AI 视频。若老板只要文本三件套，本步可跳过。
