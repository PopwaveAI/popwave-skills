# Step 6: 导出归档

> 老板确认产出后，将文本三件套（+ 可选视频）归档到项目目录，并产出内容索引汇总。

## 输入

- Step 0/1/2 全部产出（素材清单 / 画面理解 / 三件套）
- 可选 Step 3/4/5 产出（配音 / `第{N}章-v{版本}.mp4` / `第{N}章-配音-v{版本}-final.mp4`）

## 操作

1. **确认产出完整**：三件套 + 素材清单 + 画面理解 均已存在且内容完整。

2. **写入目标目录**：确认落到 `{项目}/内容/`（文本三件套，确认后即内容成品）+ `{项目}/视频/`（若出片，`第{N}章-配音-v{版本}-final.mp4`）。命名遵循落盘规范 §3.1b。

3. **产出 `内容索引.md`** 汇总：

```markdown
# 内容索引 · {章节名}

章节：{章节名} | 产出日期：{date}
来源：{漫画项目路径}

## 内容清单
| 文件 | 用途 | 主投平台 |
|:--|:--|:--|
| 口播脚本.md | 视频配音/解说稿 | 抖音/视频号/B站 |
| 种草安利笔记.md | 图文安利笔记 | 小红书/公众号 |
| 短视频推广文案.md | 标题+封面+话题+简介 | 抖音/视频号 |
| 第{N}章-配音-v{版本}-final.mp4 | 出片视频（若出片） | 抖音/视频号 |
```

## 核心卖点速览
（一行列出本套内容的主打卖点，供后续投放时快速回顾）

## 产出

- `{项目}/内容/内容索引.md`

## 完成判定

- [ ] 三件套 + 素材清单 + 画面理解 全部在目标目录
- [ ] （若出片）成品-配音.mp4 已归档
- [ ] 内容索引.md 已写入
- [ ] 向老板汇报产出位置与内容索引
