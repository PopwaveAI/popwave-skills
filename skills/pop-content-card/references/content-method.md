# 素材生产方法论

> 本文件是整条管线的**质量源头**。定义素材卡的"三可"价值（可截图×可套用×可回看），所有下游层（信息架构、视觉模板）的好坏标准都从三可推导。本文回答三个问题：定位（素材卡对读者有什么用）、什么是好的（三可标准）、如何写出好的（生产公式+自检门禁）。

---

## 一、第一性原理：读者为什么要收藏这张卡

网文作者刷到素材卡的行为链：

```
看到封面 → 0.5秒判断值不值得点 → 点进来扫一眼 → 发现能直接抄的东西 → 截图/收藏 → 日后回看套用
```

所以"好"的标准是：

1. **封面**：0.5秒知道讲什么桥段，钩子句让人想点
2. **公式**：拆解清晰，能套用到自己的故事
3. **素材句**：截图就能用，不依赖上下文
4. **正误对照**：看完就学会一个技法
5. **收束**：有长期参考价值，收藏后回看仍然有用

**一句话**：好的素材卡 = 可截图 × 可套用 × 可回看。

## 二、素材类型与差异化结构

不同类型的素材，信息架构不同。5页是上限，宁可少而精。

### 类型判定

| 类型 | 判断依据 | 典型主题 |
|:--|:--|:--|
| **桥段** | 可改写的情节套路，有起承转合 | 破镜重圆、恨海情天、强制爱 |
| **字句** | 可存用的短句/台词，单条独立 | 虐心短句、氛围感细节、100个古言动作 |
| **人设** | 角色设计模板，有内在矛盾 | 病美人、疯批帝王、失忆千金 |
| **写法** | 写作技法拆解，教人怎么写 | 克制拉扯、余情泄密、战斗场面 |

### 桥段型 — 5页结构

桥段有完整的叙事弧线，需要公式+素材+场景+对照+收束。

| 页 | 功能 | 产出什么 |
|:--|:--|:--|
| 1 | **封面** | 桥段名 + 钩子句 + 核心标签 |
| 2 | **公式+素材句** | 核心公式拆解 + 4条可改写素材句 |
| 3 | **正误对照** | 2组坏例vs好例 + 点睛总结 |
| 4 | **名场面** | 1个完整场景 + 选择/代价/情绪拆解 |
| 5 | **收束地图** | 结局分支 + 素材索引 + 收藏引导 |

### 字句型 — 5页结构

字句型核心是"量大、条短、可扫读"。

| 页 | 功能 | 产出什么 |
|:--|:--|:--|
| 1 | **封面** | 主题 + 数量 + 使用场景 |
| 2 | **分类清单A** | 15-20条短句（编号+内容） |
| 3 | **分类清单B** | 15-20条短句 |
| 4 | **分类清单C** | 15-20条短句 |
| 5 | **使用指南** | 改写示范 + 组合用法 + 收藏引导 |

### 人设型 — 5页结构

人设型核心是"矛盾拆解"。

| 页 | 功能 | 产出什么 |
|:--|:--|:--|
| 1 | **封面** | 人设名 + 核心矛盾一句话 |
| 2 | **人设公式** | 表面 vs 底层 + 形成原因 |
| 3 | **素材句** | 4条体现人设矛盾的具体场景句 |
| 4 | **正误对照** | 坏例（标签化）vs 好例（立体化） |
| 5 | **弧光+收束** | 成长曲线 + 高光场景 + 收藏引导 |

### 写法型 — 5页结构

写法型核心是"教会一个技法"。

| 页 | 功能 | 产出什么 |
|:--|:--|:--|
| 1 | **封面** | 技法名 + "看完就会"承诺 |
| 2 | **原理拆解** | 技法公式 + 为什么有效 |
| 3 | **正误对照** | 2-3组坏例vs好例 |
| 4 | **实战示范** | 完整片段 + 逐句拆解 |
| 5 | **检查清单** | 自检表 + 常见错误 + 收藏引导 |

## 三、什么是好的素材句

这是整个skill最核心的部分。素材句的好坏直接决定卡片价值。

### 好素材句的结构

每条好的素材句都包含三层：

```
物件/动作（具象载体）+ 感官细节（让读者"看到"）+ 情绪暗示（不直说但读者"感觉到"）
```

**好例**：
> 她习惯性地把咖啡杯放在他右手能够到的位置，放下后才想起他们已经分手两年——那个空荡荡的杯沿，比任何道歉都让人心慌。

拆解：
- 物件/动作：把咖啡杯放在他右手能够到的位置
- 感官细节：空荡荡的杯沿
- 情绪暗示：比任何道歉都让人心慌（不写"她很伤心"，写杯沿的心慌）

**坏例**：
> 她还是很爱他，分手两年了都忘不掉。

拆解：没有物件、没有感官、情绪直说。不可改写、不可截图。

### 好素材句的判断标准

| 维度 | ✅ 好 | ❌ 坏 |
|:--|:--|:--|
| **具象度** | 有具体物件/动作/场景 | 只有形容词（"很虐""很美"） |
| **可改写性** | 换掉身份/场景/代价就能复用 | 绑定特定角色名/特定剧情 |
| **感官层** | 视觉/触觉/嗅觉/听觉至少命中1个 | 纯心理描写无感官 |
| **情绪层** | 情绪通过物件传达（含蓄） | 情绪直接说出（直白） |
| **信息密度** | 一句话里有2-3层信息 | 一句话只有1层信息 |

### 好素材句的生产公式

针对桥段型，4条素材句应覆盖不同的感官通道和情绪阶段：

```
句1 — 触觉/视觉层（身体记忆类）：旧习惯暴露未断的情感
句2 — 物件层（证物类）：旧物成为情感的锚点
句3 — 动作层（下意识类）：身体比理智先反应
句4 — 信息层（隐秘类）：删除/隐藏的东西反而证明在意
```

### 正误对照的好/坏标准

**坏例**的特征：停在概念，没有细节。
**好例**的特征：比坏例多一层"具体到物件/动作"的细节。

对照一：
- 坏例：她看到他，心跳好快，手都在发抖。（停在"心跳"概念）
- 好例：她低头看自己颤抖的指尖——指甲陷入掌心，疼意让她回过神来。她没有抬头，只是用余光确认他手上还戴着那枚素戒，磨痕比两年前更深了。（多了一层：指甲陷入掌心的痛感 + 素戒磨痕的细节）

对照二：
- 坏例：他开口说：我想你。她哭了。（直白）
- 好例：他顿了顿，说："你头发剪短了。"语气平淡得像在说天气，但下一秒他抬手想碰又收回，指尖停在半空中。（多了一层：用"头发剪短了"替代"我想你" + 抬手又收回的动作）

### 名场面的好坏标准

**好的名场面必须包含**：
1. **选择** — 角色清醒地做出伤害自己最想保护的东西的决定
2. **代价** — 选择带来明确的失去
3. **情绪层** — 表面行为与内心感受的反差

**坏的名场面**：只有动作流，没有选择和代价。读者看完不知道"这个场景在讲什么"。

## 四、封面设计标准

封面是读者0.5秒判断的入口。

### 封面必须包含

1. **桥段名/主题词**（最大字号，读者第一眼看到）
2. **钩子句**（一句话点明这个桥段的核心张力）
3. **核心标签**（2-3个关键词，便于搜索识别）

### 好的钩子句标准

钩子句不是副标题，是让读者想点进来的"诱饵"。

| ✅ 好钩子 | ❌ 坏钩子 |
|:--|:--|
| 分手后重逢的每一步，都是旧账本上的标记 | 破镜重圆的写法拆解 |
| 她删了他所有联系方式，却记得他生日的天气预报 | 关于破镜重圆的素材集合 |
| 他签下收购她父亲公司的协议，血滴在文件上 | 破镜重圆名场面赏析 |

好钩子的公式：**具体物件/动作 + 情绪张力**。

---

## 五、收束页设计标准

收束页是读者收藏后回看的入口。

### 收束页必须包含

1. **结局分支**（HE/BE/OE/转折，各有代价）
2. **素材索引**（本卡所有素材类型的速查表）
3. **收藏引导**（一句话告诉读者"收藏此案，下次直接套用"）

### 好的结局分支标准

每个结局不是"标签"，是"可套用的收束方案"：

| ✅ 好结局 | ❌ 坏结局 |
|:--|:--|:--|
| HE：他放弃了公司，用那份签了字的协议点燃了壁炉。她看着他眼里的火光，知道他们终于可以重新开始——但烧掉的不仅是纸，还有彼此的骄傲。 | HE：他们和好了，幸福地生活在一起。 |
| BE：她带着恨意远走他乡，他独自坐在会议室里，看血渍干涸在文件上。后来他听说她在异国结婚，那个人闻起来没有雪松味。 | BE：他们再也没有见面。 |

好结局的公式：**具体物件/动作 + 代价 + 一个让人记住的细节**。

## 六、数量与密度的关系

核心原则：**宁可少而精，不要多而泛**。

- 桥段型：5页，4条素材句，2组对照，1个名场面，4个结局分支。总量刚好够读者收藏后回看。
- 字句型：5页，45-60条短句（每页15条左右）。量大但每条必须独立可读。
- 人设型/写法型：5页，内容按结构组织，不追求条数。

**禁止**：为了凑满5页而注水。如果5页讲不清楚，说明素材拆解还不够深，不是页数不够。

## 七、产出格式与字段清单

内容产出必须以JSON格式输出，字段名与HTML母版占位符**一一对应**。以下是桥段型的完整字段清单（其他类型见后）。

### 桥段型字段清单（60个内容字段）

| 页 | 字段 | 质量要求 |
|:--|:--|:--|
| **全局** | `{{TITLE}}` `{{TOOLBAR_TITLE}}` `{{ACCOUNT_NAME}}` `{{ACCOUNT_INITIAL}}` `{{FOOTER_SIGN}}` `{{FOOTER_TAG}}` `{{CLOSING_LINE}}` `{{SIGNOFF_TEXT}}` | 账号配置类，无质量要求 |
| **P1 封面** | `{{KICKER}}` `{{TITLE_MAIN}}` `{{COVER_SUB}}` `{{COVER_HOOK}}` `{{COVER_DECO_TEXT}}` | 钩子句必须：具体物件/动作 + 情绪张力 |
| **P2 公式+素材句** | `{{TOPIC_LABEL_2}}` `{{TOPIC_TITLE_2}}` `{{TOPIC_DESC_2}}` `{{FORMULA_MAIN}}` `{{FORMULA_KEY_1~4}}` `{{FORMULA_VAL_1~4}}` `{{QUOTE_1~4}}` | 每条素材句必须含三层：物件/动作 + 感官细节 + 情绪暗示 |
| **P3 正误对照** | `{{TOPIC_LABEL_3}}` `{{TOPIC_TITLE_3}}` `{{TOPIC_DESC_3}}` `{{CONTRAST_BAD_TITLE_1~2}}` `{{CONTRAST_BAD_1~2}}` `{{CONTRAST_GOOD_TITLE_1~2}}` `{{CONTRAST_GOOD_1~2}}` `{{SUMMARY_TITLE_3}}` `{{SUMMARY_COPY_3}}` | 好例必须比坏例多一层具体到物件/动作的细节 |
| **P4 名场面** | `{{TOPIC_LABEL_4}}` `{{TOPIC_TITLE_4}}` `{{TOPIC_DESC_4}}` `{{SCENE_TITLE_4}}` `{{SCENE_EXAMPLE_4}}` `{{BREAKDOWN_1A~3B}}` `{{ROUTE_TITLE_A~B}}` `{{ROUTE_COPY_A~B}}` | 名场面必须含：选择 + 代价 + 情绪反差 |
| **P5 收束地图** | `{{TOPIC_LABEL_5}}` `{{TOPIC_TITLE_5}}` `{{TOPIC_DESC_5}}` `{{ENDING_KEY_1~4}}` `{{ENDING_VAL_1~4}}` | 每个结局：具体物件/动作 + 代价 + 记忆点 |

### 字句型字段清单

P2-P4替换为清单网格字段：每页15-20条 `{{ITEM_1}}` ~ `{{ITEM_20}}`，P5改为使用指南。详见 step1-content.md。

### 铁律

- **所有字段必须产出**，禁止漏字段。漏一个 = 模板渲染出现 `{{...}}` 残留 = 废品。
- 字段值不得为空字符串。如果某字段暂时没内容，说明素材拆解不够深，回去补内容。
- `{{QUOTE_1~4}}` 四条素材句必须覆盖不同感官通道（触觉/物件/动作/信息），禁止四条都是同一个角度。

## 八、产出后自检门禁

内容产出后、进入Step 2之前，必须通过以下自检。**任一项不通过 = 回去补内容，禁止带着缺陷进入模板渲染**。

### 自检清单

| # | 检查项 | 对应三可 | 通过标准 | 不通过怎么办 |
|:-:|:--|:--|:--|:--|
| 1 | **字段完整性** | 可截图 | 60个内容字段全部产出，无遗漏（缺字段=渲染残留=不可截图） | 找到遗漏字段，补写 |
| 2 | **字段非空** | 可截图 | 每个字段值 ≥ 5字，无空字符串 | 补写空字段内容 |
| 3 | **素材句三层** | 可截图+可套用 | 每条QUOTE含物件/动作 + 感官 + 情绪暗示 | 重写不达标的句子 |
| 4 | **正误对照差异** | 可套用 | 每组好例比坏例多一层具体细节 | 补充好例的细节层 |
| 5 | **名场面三要素** | 可回看 | 场景含选择 + 代价 + 情绪反差 | 重写名场面 |
| 6 | **封面钩子句** | 可截图 | 具体物件/动作 + 情绪张力 | 重写钩子句 |
| 7 | **结局可套用** | 可套用+可回看 | 每个结局含具体物件/动作 + 代价 + 记忆点 | 重写结局 |
| 8 | **感官覆盖** | 可截图 | 4条素材句覆盖 ≥3种感官通道 | 调整素材句角度 |

### 自检方式

```
对产出的JSON逐字段检查：
1. 统计字段数 = 60（桥段型内容字段）
2. 逐字段检查非空
3. 逐条QUOTE检查三层结构
4. 逐组对照检查差异层
5. 检查SCENE_EXAMPLE_4含"选择"和"代价"
6. 检查COVER_HOOK含具体物件/动作
7. 逐个ENDING检查"代价"和"记忆点"
8. 检查4条QUOTE的感官通道覆盖
```

**通过全部8项 → 进入 Step 2。否则 → 回到内容生产补内容。**
