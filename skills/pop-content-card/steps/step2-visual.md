# Step 2 · HTML视觉化

> 本步骤把JSON数据传导为读者0.5秒可感知的视觉呈现。模板每个模块都服务一个"可"——好模板不是装饰多，是让三可被读者一眼看到。复制母版改槽位，不从空白写。

---

## 输入

1. Step 1 产出的 `{主题}-content.json`（已通过8项校验的完整JSON）
2. 母版文件 `templates/html/master-template.html`

---

## 执行流程

### 1. 读取密度规范

```
Get-Content -Encoding UTF8 -Raw references/visual-density.md
```

### 2. 复制母版

```
Copy-Item templates/html/master-template.html {输出目录}/{主题}-素材图文卡-v1.html
```

### 3. 选风格（切 body class）

母版内置6套锁死色板，通过 `<body>` 的 class 切换：

| 风格 | body class | 气质 | 适配题材 |
|:-----|:-----------|:-----|:---------|
| 暖纸调（默认） | `theme-warm` | 温暖手作 | 情感/古言/治愈 |
| 墨韵调 | `theme-ink` | 冷静克制 | 现代/悬疑/都市 |
| 青碧调 | `theme-jade` | 清新自然 | 种田/治愈/日常 |
| 赤金调 | `theme-gold` | 华贵厚重 | 权谋/大女主/宫斗 |
| 暮紫调 | `theme-dusk` | 神秘梦幻 | 奇幻/修仙/幻想 |
| 极夜调 | `theme-night` | 深邃暗黑 | 暗黑/无限流/恐怖 |

操作：把 `<body class="theme-warm">` 改为用户选定的风格 class。

**禁止手改 `:root` 变量或内联写死颜色。** 只能切 body class。

### 4. 填账号占位符

全局替换母版中的 `{{...}}` 占位符：

| 占位符 | 说明 | 示例 |
|:--|:--|:--|
| `{{ACCOUNT_NAME}}` | 账号名 | 猫的咪 / 写作素材铺 |
| `{{ACCOUNT_INITIAL}}` | 头像首字母 | 猫 / 写 |
| `{{FOOTER_SIGN}}` | 页脚左侧署名 | 猫的咪｜网文素材积累 |
| `{{FOOTER_TAG}}` | 页脚右侧标签 | 脑洞与质感并存 |
| `{{CLOSING_LINE}}` | 末页收尾语 | 关注XX，继续攒网文素材。 |
| `{{TOOLBAR_TITLE}}` | 工具栏标题 | XX图文预览 |

无头像时：用 `.brand-avatar` 纯色圆替代（母版已有代码）。
无贴纸时：用 `.signoff-visual` 纯色块替代（母版已有代码）。

### 5. 检查JSON字段完整性

填充前先检查JSON字段与母版占位符的匹配：

- 统计母版中 `{{...}}` 占位符数量
- 统计JSON中key数量
- 两者必须一致。JSON缺字段 = 回Step 1补内容，禁止带着缺失字段填充模板

### 6. 按JSON填充母版

从JSON中逐个取key-value，替换母版中对应的 `{{...}}` 占位符。

母版默认桥段型5页结构：
- **P1 封面**：kicker + h1 + cover-sub + cover-hook
- **P2 公式+素材句**：formula-card + quote-stack(4条)
- **P3 正误对照**：contrast(2组坏vs好) + 总结panel
- **P4 名场面**：scene-paper + scene-breakdown
- **P5 收束地图**：ending-grid(4个结局) + signoff-card

字句型调整：P2-P4替换为 trope-grid（每页15-20条），P5改为使用指南。

### 7. 填充后检查

填充完成后检查：
- 母版中无 `{{...}}` 占位符残留（用正则 `\{\{[A-Z_]+\}\}` 检查）
- 如有残留 = JSON缺字段，回Step 1补

### 8. 密度检查

逐页检查内容占比：

- 目标：75%-85%。
- 低于70%：加厚卡片、补素材槽、增加 quote 条数。
- 超过90%：压缩模块间距、内边距、行高（只压问题页，加单页 class）。

### 9. 页脚安全区检查

逐页检查页脚：

- 主内容不得碰到账号名和页码。
- 素材句页容易贴底：quote 控制在4条左右。

### 10. 落盘

落盘到项目目录：`{主题}-素材图文卡-v1.html`

---

## 完成检查

- [ ] 页面数和页码一致（5页）〔可截图〕
- [ ] 每页主内容占比约 75%-85%〔三可基础〕
- [ ] 手机缩略图能读出标题和主要素材词〔可截图〕
- [ ] 顶部/页脚账号名一致〔可回看〕
- [ ] 末页有收尾视觉（纯色块或贴纸）〔可回看〕
- [ ] 无 `{{...}}` 占位符残留〔可截图〕
- [ ] 无页脚被遮挡〔可截图〕
- [ ] body class 与用户选定风格一致〔三可基础〕

`{主题}-素材图文卡-v1.html` — 自包含文件，双击浏览器直接打开，可打印导出 PDF。
