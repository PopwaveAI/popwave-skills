# CHANGELOG

## v1.0.0 | 2026-09-08

### 初始版：多子 agent 盲评挑刺团

> 背景：老板提出"群聊式多 agent"想法——多个 agent 各带不同视野和初始提示词，对小说设定/剧情挑刺。明确约束：**子 agent 之间不能互相看到（防立场趋同），只做一轮各自解读，主 agent 回收结论**。据此定型为"单轮盲评"而非"互辩群聊"。

- **核心机制**：主 agent 组团 → 并行派 N 个隔离子 agent（各自独立上下文）→ 单轮盲评 → 主 agent 四分裁决（采纳/误报/冲突/存疑）→ 盲评报告落盘 `审查/盲评-{靶子名}-{YYYYMMDD}.md`。
- **内置四视角团**：读者代表（只读靶子·12岁滑动读者模型）/ 逻辑审查（靶子+全书日志）/ 赛道编辑（靶子+大纲卷向）/ 设定考据（靶子+设定库）。视野边界是刻意信息不对称，prompt 内写明防子 agent 越界补读。
- **子 agent 提示词骨架模板全内联**（身份/视野边界/评审尺/纪律/回传格式），主 agent 复制填充即可组团；支持用户自定义视角入团。
- **输出规范**：每条刺必带定位＋类型＋三档严重度（🔴致命/🟡警告/🔵建议）＋问题＋建议，上限 10 条；回传 ≤8KB 量级。
- **回收规范**：多视野同点命中合并加权；冲突原样保留留用户拍板（主 agent 不代裁）；误报给理由；存疑列缺料清单。
- 落盘后半步=消毒（deai_gate doc 报告闸，回执一行），与 snow 六 skill v1.5.1+ 的消毒 SOP 同步。
