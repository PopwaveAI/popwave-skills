# Step 1：名场面深度拆解

> **方向**：从章节白描识别名场面并做叙事式拆解。
> **级别覆盖**：前N章 / 全书

## 定位

名场面是爽点体验的集大成者。识别"哪个场景最让读者记住/最爽/最具转折意义"，并拆解它为什么成立。

## 数据来源

- 章节白描 — 爽感数据
- 剧情线（可选）— 场景在弧线中的位置
- 原文（`_temp/chapters/chXXX.txt`）— 原文锚点

## 产出

| 文件 | 内容 |
|:-----|:-----|
| `设计/名场面库.md` | 名场面清单 + 每个场景的叙事式拆解 + 场景节奏分析 |

## 拆解流程

### 1. 从白描标记高潮点和转折点

扫描白描，标记：
- 每幕的高潮点（剧情梗概中最激烈的场景）
- 跨幕的转折点（改变故事方向的关键场景）

### 2. 从白描提取爽感数据

扫描爽点强烈的章节：情绪弧线高潮、爽点机制明确、章末钩子强的章节。

### 3. 交叉筛选，确定名场面清单

**收录标准**（满足任意2条即可）：
- 让读者印象深刻的"名场面"
- 对剧情有重大转折意义
- 展现角色核心特质
- 爽感爆发强烈

### 4. 对每个名场面写叙事式拆解

**核心原则：像给朋友讲"这个场景为什么牛逼"，不是填表。**

每个场景300-500字自然叙事分析，一口气写完。分析时自然融入思考维度（融入叙事，不拆表）：

| 思考维度 | 分析时想什么 |
|:---------|:------------|
| 位置 | 在故事弧线的哪个位置，承担什么功能 |
| 压力 | 读者为什么紧张？压力源是什么 |
| 行动 | 主角具体做了什么？行为序列 |
| 爽感 | 读者为什么满足？爽感公式（弱→强/被欺→反击/未知→揭示/压力→突破） |
| 铺垫 | 靠前面哪些章的铺垫才有效？标注chXX |
| 技法 | 作者用了什么叙事手法（POV切换/信息差/预期违背） |

### 5. 分析全书场景节奏

- 每个章节区间的名场面数量和平均间隔
- 节奏规律总结（一句话）
