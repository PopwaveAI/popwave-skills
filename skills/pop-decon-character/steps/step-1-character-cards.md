# Step 1：角色人物卡

> **方向**：从章节白描提取主要角色的人物卡（含敌人卡）。
> **级别覆盖**：前N章 / 全书

## 定位

人物卡是角色拆解的骨架。先看清"每个角色是谁、立场是什么、核心特质是什么"，才能拆弧线和动机。

## 数据来源

- 章节白描 — 主要数据源
- 原文（`_temp/chapters/chXXX.txt`）— 证据验证

## 产出

| 文件 | 内容 |
|:-----|:-----|
| `设计/角色/主要角色人物卡.md` | 主要角色人物卡清单（含敌人卡） |

## 拆解流程

### 1. 锁定主要角色

从白描识别主要角色：主角 + 重要配角 + 关键敌人。数据极少的角色标注「数据极少」。

### 2. 建立人物卡

为每个角色建立人物卡：

| 字段 | 内容 |
|:-----|:-----|
| 姓名/身份 | 角色名 + 身份定位 |
| 立场 | 主角阵营/中立/敌对 |
| 核心特质 | 性格关键点（1-3条） |
| 目标/动机 | 他在追求什么（chXX证据） |
| 能力/地位 | 力量层级/社会地位 |
| 关键事件 | 出场章 + 质变章 |
| 原文证据 | {原文一句话} + chXX |

### 3. 标注数据置信度

数据充足的标注「证据充分」，数据少的标注「数据极少」，不得编造。
