# pop-decon-dimension · 维度拆解（方案B · 共享锚点池）

> 方案B 维度拆解 skill。7 个维度联合检索、共享精读：所有选中维度的检索词合并为一次 Grep，命中章去重形成联合锚点池，每章只读一次同时提取所有维度设定，最后分维度各自产出。v2.0.0：steps 两件全合入单文件精炼。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 做什么

| 输入 | 来源 | 输出 | 下游 |
|:-----|:-----|:-----|:-----|
| 原文 `_temp/chapters/` + `dims=[维度列表]` + `scope=[章节范围]` | 原文（必）+ pop-decon 征询 | `设计/{维度}拆解-{范围}.md` × N | pop-decon-prd、创作参考 |

**执行模式**：只读拆解分析类工作可派子 agent——锚点池 >8 章时分批委派子 agent 精读+多维提取并回报提取笔记，主 agent 汇总合并+分维度产出落盘（子 agent 不产出文档）；锚点池 ≤8 章主 agent 直接精读。维度与范围由 pop-decon 征询后传入。

## 怎么操作（SOP全内联）

> execution.mode: 按维度参数驱动（dims + scope 由 pop-decon 传入）

### Step 1：预扫描 + 联合 Grep → 联合锚点池

**1a 预扫描（提取本书专属术语表，只做一次，所有维度共享）**：读 scope 范围内前 3-5 章原文，提取 5 张术语表记为临时笔记（通用词命中率有限，需本书专属术语作补充检索词）：

| 术语表 | 提取内容 | 示例 |
|:------|:--------|:-----|
| 人名表 | 出场角色姓名/绰号/称号 | 萧炎\|药老\|萧薰儿 |
| 地名表 | 所有出现的地名 | 乌坦城\|迦南学院\|黑角域 |
| 等级名表 | 力量体系具体阶位名 | 斗者\|斗师\|大斗师\|斗灵 |
| 势力名表 | 宗门/组织/势力名称 | 云岚宗\|纳兰家\|魂殿 |
| 物品名表 | 宝物/武器/丹药名称 | 异火\|骨灵冷火\|紫云翼 |

**1b 联合 Grep 全书检索**：读 `references/维度路由清单.md` 获取每个选中维度的通用检索词 + 从 1a 术语表匹配该维度的补充词 → **所有维度的检索词合并为一个 Grep pattern（用 `|` 连接）** → 对 scope 范围内章节执行 Grep（`output_mode: files_with_matches`）→ 记录命中章列表。各维度检索策略：

| 维度 | 检索策略 |
|:-----|:---------|
| plot | 预扫描人名逐个检索 → 追踪人物出场轨迹 |
| romance | 关系词 + 预扫描人名两两组合（CP 同章出现） |
| character | 预扫描人名逐个检索 + 称号词 + 描写词 |
| power | 力量词 + 战斗词 + 预扫描等级名 |
| world | 地理词 + 势力词 + 物品词 + 预扫描地名/势力名 |
| beat | 反转词 + 情绪词 + 冲突词 |

**1c style 维度场景定向采样（如选中）**：不走 Grep，按场景类型采样后并入联合锚点池——必采：日常对话/战斗场景/情感爆发/环境描写/严肃悲伤/高潮名场面；选采：幽默吐槽/转场时间跳跃/升级突破。每种场景类型采样 2-3 章，总计 18-27 章。

**1d 合并去重 → 联合锚点池**：合并 1b 命中章 + 1c 采样章 → 按章节序号去重排序，形成一份去重后的章节号列表。收敛规则（池过大时）：≤40 章全部保留｜41-60 章按命中密度排序保留高密度章｜61+ 章按命中密度+均匀性筛选保留 40-50 章。均匀性保证：开头（scope 前 10%）至少 2 章、中段至少 50%、结尾（scope 后 10%）至少 2 章。多维度覆盖验证：某维度在池中命中章 < 该维度锚点章下限的 60% → 补充该维度专属 Grep 检索。

**Step 1 门禁**：术语表已提取（人名/地名/等级名至少3项）｜所有选中维度检索词已合并为一次 Grep｜锚点池无重复章节｜命中章数 ≥20（不足则扩大检索词或补充均匀采样）｜覆盖开头/中段/结尾｜每个维度在池中命中章 ≥该维度下限的 60%｜style（如选中）采样 ≥18 章已并入锚点池。

### Step 2：分批精读联合锚点池 + 多维提取

**2a 分批策略（硬限制：每批≤8章，超限强制拆批）**：

| 联合锚点池大小 | 分批数 | 每批 | 执行方式 |
|:-------------|:------:|:----:|:---------|
| ≤8 章 | 1 | 全量 | 主 agent 直接精读 |
| 9-16 章 | 2 | ~5-8 | 主 agent 分批 或 委派 2 个子 agent |
| 17-32 章 | 3-4 | ~6-8 | 委派子 agent（参考 `pop-decon/references/delegation-orchestration.md`） |
| 33+ 章 | 5-7 | ~6-8 | 委派子 agent，上限 7 批 |

**2b 精读 + 多维提取清单**（每章只读一次，选中哪些维度就提取哪些，未选跳过）：

| 维度 | 提取什么 | 无相关内容时 |
|:-----|:---------|:-----------|
| plot | 事件推进/转折点/伏笔/时间跳跃/主线进展 | 标注「本章无剧情线相关内容」 |
| romance | CP 互动/情感变化/信任/背叛/关系进展 | 标注「本章无情感线相关内容」 |
| character | 人物出场/性格表现/能力展示/关系建立/成长变化 | 标注「本章无人物相关内容」 |
| power | 等级变化/新能力/战斗过程/修炼突破/力量规则 | 标注「本章无力量相关内容」 |
| world | 地理信息/势力信息/物品信息/历史背景/社会规则 | 标注「本章无世界观相关内容」 |
| beat | 名场面/爽点触发/情绪高潮/反转/打脸/追读钩子 | 标注「本章无爽点相关内容」 |
| style | 笔触特征/句式/对白风格/叙事距离/感官描写方式 | 标注「本章无文风相关内容」 |

提取笔记格式（每条必须带 `(chXXX)` 章节号；量化数值原文有的必须摘录并标 🔒；原文未展开的设定标注「原文未展开」；禁止凭记忆/书评补充原文没有的内容；「本章无XX相关内容」是合法标注，不强制每章每维度都有内容）：

```
[ch003]
- plot: 萧炎测试斗气结果为斗之气三段，被族人嘲笑 (ch003)
- power: 斗之气三段 🔒，处于最低等级 (ch003)
- world: 乌坦城，萧家宅院 (ch003)
- romance: 本章无情感线相关内容
- style: 第三人称限知视角，短句为主，对话简洁有力 (ch003)
```

**2c 分维度笔记汇总**：收集所有批次笔记 → 按维度拆分归入 → 维度内按章节序号排序 → 设定演变保留时间线（`ch003: 前期状态 → ch045: 中期变化 → ch120: 后期定型`）。委派模式下：子 agent 只返回多维提取笔记（含所有选中维度），主 agent 按维度拆分合并 + 检查批次间设定冲突（同一设定不同章节的演变保留时间线）+ 主 agent 负责产出文档（子 agent 不产出）。

**2d 按维度分别产出**：每个选中维度读 `templates/{维度}.tpl.md` → 将 2c 中该维度汇总笔记按模板结构填充 → 每条设定标注 chXX 证据、量化数值标 🔒 → 落盘 `项目本地/设计/{维度}拆解-{范围}.md`。

文件命名：全书拆解 `{维度}拆解-ch001-ch{末章}.md`｜前N章 `{维度}拆解-ch001-ch{N}.md`｜指定卷 `{维度}拆解-卷N.md`（⛔ 文件名不得含"全书"，必须有 scope 声明）。SCOPE 声明模板：

```markdown
> 维度：{维度}（方案B · 共享锚点池）| 范围：ch001-ch{N}（共{N}章）| 依据：原文 `_temp/chapters/`
> 方法：联合 Grep 共享锚点池，单次精读多维提取
```

**2e 自检（每个维度独立执行，标准详见 `references/output-quality-standards.md`）**：

| 检查项 | 标准 |
|:------|:-----|
| 锚点章覆盖 | 该维度在联合锚点池中的命中章数≥该维度下限 |
| 证据条目数 | 每条设定带 chXX 证据，证据条目数≥锚点章数×2 |
| 量化数值 | 关键数值标 🔒，不省略 |
| 可回溯性 | 所有结论可回到原文对应章节 |
| 不编造 | 原文未明确处标注「原文未展开」 |
| scope 声明 | 文件名不含"全书"，有范围声明 |

不通过处理：某维度锚点不足 → 补充该维度专属 Grep 检索追加精读｜证据条目不足 → 补充精读遗漏章节｜编造内容 → 删除无 chXX 证据的条目。

**Step 2 门禁**：每批≤8章｜联合锚点池所有章节已精读｜每章按清单提取了所有选中维度｜各维度笔记已独立汇总｜每个选中维度各自按模板产出且路径正确｜每个维度自检通过。

> 所有维度产出完成 → 路由到 pop-decon-prd（如用户选了立项设计）。

## 红线

1. **读取协议**：读取 skill 文件用 `Get-Content -Encoding UTF8 -Raw`，禁用 Read 工具
2. **凭空发明内容** — 无 chXX 证据且未标注「原文未展开」的设定=编造（禁止凭记忆/书评补充）
3. **前N章产出全书级文件** — 文件名不得含"全书"，必须有 scope 声明
4. **正文内联 chXX** — 正文中不得出现内联章节号，证据归表格列或段落末尾证据行
5. **量化数值丢失** — 关键数值必须用 🔒 标出，不得省略
6. **未确认维度就全跑** — 必须先由 pop-decon 征询确认维度，只跑被选中的（未选维度不提取）
7. **单批精读超8章** — 精读锚点章时每批≤8章，超限强制拆批，避免子 agent 超时
