# L1 批次档案格式规范 · batch-format

> 定位：L1 事实层的内部依托（`_temp/batches/`），**不是对外交付物**。它是 L2 六模块成品的唯一事实地基，质量硬门禁在此定义。
> 模式：默认 ~30章/批（质量优先 ≤20章/批，全书骨架 ≤40章/批）。每批 1 个子 agent 读该批连续章节 → 回报提取笔记 → 主 agent 汇总落盘。

---

## 1. 文件命名与批头

```
V{n}_B{m}_chXXX-YYY.md
```

批头（frontmatter + 摘要）：

```markdown
---
batch: V1_B1_ch001-030
volume: 1
chapter_range: ch001-030
卷名: {本卷名}
主角状态快照: {本批终点的主角状态一句话，含等级/身份/金手指阶段}
---
```

主角状态快照是**批次间连续性锚**（上一批终点=下一批起点），缺失会导致 L2 卷主线断裂。

---

## 2. 分场事件链表（本批骨架）

每批一个事件表，一个事件节点一行：

| # | 事件 | 转折类型 | 类型 | ch | 参与角色 | 原文定位 |
|:--|:--|:--|:--|:--|:--|:--|
| 1 | 索伦夜袭小巷背刺恶棍巴拉斯 | 开局立威 | 交锋 | ch003 | 索伦/巴拉斯 | ch003-巷战段 |

- **转折类型**：开局立威/身份跃迁/金手指升级/危机引入/关系变化/伏笔埋设/章末钩子
- **类型**：日常/成长/披露/转折/社交/探索/交锋（7型）
- 每个事件一句话说清"主角做了什么+冲突/转折+结果"
- ch 锚点必须精确到章，原文定位到"段"便 L2 回溯

---

## 3. 七维提取子节（每批必全，缺标注）

逐维度列出本批内的设定与演变，每条带 `(chXXX)`，量化 🔒，未展开标「原文未展开」：

```markdown
## 剧情
- 主线推进：… (chXXX)
- 支线铺线：… (chXXX)｜「未展开」
- 伏笔埋设：… (chXXX)

## 人物
- 主角可挂行为证据的性格点：… (chXXX)
- 新出场角色：… (chXXX)

## 力量
- 力量变化/新能力：… 🔒 (chXXX)

## 世界观
- 地理/势力/物品/历史增量：… (chXXX)

## 爽点
- 名场面/打脸/反转：… (chXXX)

## 情感
- 关系演变：… (chXXX)

## 文风
- 笔触特征/句式/叙事距离：… (chXXX)
```

**纪律**：
- 每条必须带章号；量化数值原文有则摘录并 🔒
- 原文未展开的设定标「原文未展开」；无内容维度标「本章无XX」是合法标注
- **禁止凭记忆/书评补充原文没有的内容**

---

## 4. 关键数据🔒块（本批硬数据）

一行式摘要 + 原文定位指针，**禁止全文引用**：

```
🔒 主角面板：力量12/敏捷19(+1)/体质15/智力18/感知15/魅力16 | 平民5级/盗贼1级 | ch002-面板段
🔒 "燃烧之手！"——暗红狗头人术士释放 | ch050-战斗高潮段
```

---

## 5. 爽点·钩子（批内名场面 + 悬念链）

```markdown
## 爽点
- {类型: 信息差/数值/打脸/情绪} 名场面一句话 (chXXX)

## 钩子
- {悬念内容} → 预期回收 chXXX（强度 L1-L5）
```

钩子强度：L1日常 / L2轻微 / L3中等 / L4强 / L5致命

---

## 6. 人物关系变化（仅本批确实发生时填）

```
索伦→薇薇安: 信任深化（护妹→并肩）
索伦→歌莉娅: 结盟（全名互许）
```

无则省略整节，不写"无"。

---

## 7. L1 硬门禁（不过关退回补拆）

| # | 检查项 | 标准 |
|:-:|:--|:--|
| 1 | 术语表完整 | 人名/地名/等级/势力/物品 5 表均提取 |
| 2 | 锚点池覆盖 | 命中章≥20；覆盖开头/中段/结尾；每模块命中≥下限60% |
| 3 | schema完整 | 每批含七维子节；每事件带 ch 锚点 |
| 4 | 证据密度 | 每批证据条目 ≥ 章数×2 |
| 5 | 量化无丢失 | 关键数值 🔒 必标 |
| 6 | 不编造 | 无证据且未标「原文未展开」= 编造 |
| 7 | 章节号可回溯 | 所有结论可回到原文对应章 |

> **根因记忆**：本规范吸收旧 pop-decon-design-pack 白描卡方法论（事件白描/🔒数据/爽点钩子/关系变化），颗粒度从单章升级为 30章/批，避免逐章人工料冗余，同时保证 L2 有足够证据依托。
