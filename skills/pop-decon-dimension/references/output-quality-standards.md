# 产出质量门禁（方案B · 共享锚点池）

> pop-decon-dimension 各维度完成后自检标准。Step 4 读取。
> v3.0.0：锚点章改为联合锚点池共享模式，各维度证据条数独立计算。

## 通用门禁

### 1. 联合锚点池覆盖

> ⚠️ 共享锚点池模式下，所有选中维度共享同一批精读章。但每个维度的证据条数独立计算。
> - **联合锚点池大小**：所有维度 Grep 命中去重后的总章数（每章只读一次）
> - **各维度证据条数**：产出文档中该维度带 chXX 证据的设定条目数（1 章可贡献多个维度的多条证据）

| 维度 | 联合池中该维度命中章数下限 | 该维度证据条数下限 | 说明 |
|:--|:--:|:--:|:--|
| plot 剧情线 | ≥35 | ≥70 | 每章平均贡献 2 条事件证据 |
| romance 情感线 | ≥20 | ≥40 | 每章平均贡献 2 条情感证据 |
| character 人物 | ≥30 | ≥60 | 每章平均贡献 2 条人物证据 |
| power 力量 | ≥25 | ≥50 | 每章平均贡献 2 条力量证据 |
| world 世界观 | ≥30 | ≥60 | 每章平均贡献 2 条世界观证据 |
| beat 爽点 | ≥20 | ≥40 | 每章平均贡献 2 条爽点证据 |
| style 文风 | ≥18 | ≥18 | 场景定向采样，每场景 1 条笔触特征 |

> 联合锚点池总大小 = 所有维度命中章去重后的章数（通常 40-60 章，远小于各维度独立精读的总和）。
> 小书（<100章）或指定范围（<100章）的锚点章数下限可降低至标准的 60%。
> 如某维度在联合池中命中章不足下限，需补充该维度的专属 Grep 追加精读。

### 2. 量化数值保留
关键数值用 🔒 标出，不省略

### 3. 可回溯性
所有结论可回到原文对应章节

### 4. 不编造
原文未明确处标注「原文未展开」

### 5. scope 声明
文件名不含"全书"，有范围声明

## 维度特有门禁

| 维度 | 特有门禁 |
|:--|:--|
| plot | 故事DNA每条有原文证据；卷纲从剧情逆向归纳 |
| romance | 情感节点有触发事件chXX，不编造角色内心 |
| character | 角色卡有chXX证据；弧线覆盖起点→终点；对白逐字摘录 |
| power | 境界链有出处；战斗按五轴标注 |
| world | 地理/势力有chXX证据；骨架优先血肉并行 |
| beat | 名场面叙事式不拆表；爽感点出公式 |
| style | 采样覆盖≥8种场景类型；只摘笔触层 |
