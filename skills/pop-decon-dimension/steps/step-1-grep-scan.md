# Step 1：联合 Grep 检索——形成共享锚点池

> pop-decon-dimension 执行流程的 Step 1。所有选中维度的检索词合并为一次 Grep，命中章去重形成联合锚点池。
> 前置：SKILL.md 已加载、dims + scope 参数已由 pop-decon 传入。

---

## 1a：预扫描——提取书本专属术语表

> 目的：Grep 通用词命中率有限，需要从原文前几章提取本书专属术语作为补充检索词。
> 预扫描只在本次拆书执行一次，所有维度共享。

### 操作

1. 读取 scope 范围内的前 3-5 章原文
2. 提取以下术语表：

| 术语表 | 提取内容 | 示例 |
|:------|:--------|:-----|
| 人名表 | 所有出场角色的姓名、绰号、称号 | "萧炎\|药老\|萧薰儿" |
| 地名表 | 所有出现的地名 | "乌坦城\|迦南学院\|黑角域" |
| 等级名表 | 力量体系的具体阶位名 | "斗者\|斗师\|大斗师\|斗灵" |
| 势力名表 | 宗门/组织/势力名称 | "云岚宗\|纳兰家\|魂殿" |
| 物品名表 | 宝物/武器/丹药名称 | "异火\|骨灵冷火\|紫云翼" |

3. 术语表记录为临时笔记（供 1b 使用）

---

## 1b：联合 Grep 全书检索

> 目的：将所有选中维度的检索词合并，执行一次 Grep 全书扫描。

### 检索词组装

1. 读取 `references/维度路由清单.md`，获取每个选中维度的：
   - **通用检索词**（原文中高频出现的词）
   - **预扫描补充词**（从 1a 提取的术语表中匹配该维度的术语）
2. 将所有维度的检索词合并为一个 Grep pattern（用 `|` 连接）

### 示例

用户选了 plot + character + power 三个维度，合并后的 Grep pattern：

```
# plot 通用词 + 预扫描人名
年后|月后|日后|转眼|不知过了|萧炎|药老|萧薰儿
# character 通用词 + 预扫描人名
少爷|公主|大人|师姐|师兄|师父|殿下|长老|穿着|眼神|萧炎|药老
# power 通用词 + 预扫描等级名
突破|升级|境界|阶|级|层|段|品|战斗|攻击|防御|技能|斗者|斗师|大斗师
# 合并去重后
年后|月后|日后|转眼|不知过了|萧炎|药老|萧薰儿|少爷|公主|大人|师姐|师兄|师父|殿下|长老|穿着|眼神|突破|升级|境界|阶|级|层|段|品|战斗|攻击|防御|技能|斗者|斗师|大斗师
```

3. 对 scope 范围内的章节执行 Grep（`output_mode: files_with_matches`）
4. 记录命中的章节列表

### 检索策略

| 维度 | 检索策略 |
|:-----|:---------|
| plot | 预扫描人名逐个检索 → 追踪人物出场轨迹 |
| romance | 关系词 + 预扫描人名两两组合（CP 同章出现） |
| character | 预扫描人名逐个检索 + 称号词 + 描写词 |
| power | 力量词 + 战斗词 + 预扫描等级名 |
| world | 地理词 + 势力词 + 物品词 + 预扫描地名/势力名 |
| beat | 反转词 + 情绪词 + 冲突词 |

> style 维度不参与联合 Grep，走场景定向采样（见 1c）。

## 1c：style 维度的场景定向采样（如选中）

> 文风维度不走 Grep，而是按场景类型定向采样。但采样结果合并进联合锚点池，与其他维度共享精读。

### 场景类型采样

| 场景类型 | 采样优先级 |
|:---------|:----------|
| 日常对话 | 必采 |
| 战斗场景 | 必采 |
| 情感爆发 | 必采 |
| 环境描写 | 必采 |
| 幽默/吐槽 | 选采 |
| 严肃/悲伤 | 必采 |
| 转场/时间跳跃 | 选采 |
| 升级/突破 | 选采 |
| 高潮/名场面 | 必采 |

- 每种场景类型采样 2-3 章
- 总计 18-27 章
- 将采样章节并入联合锚点池

---

## 1d：合并去重 → 联合锚点池

### 操作

1. 合并 1b 的 Grep 命中章 + 1c 的 style 采样章
2. 按章节序号去重
3. 按章节序号排序
4. 形成联合锚点池（一份去重后的章节号列表）

### 收敛规则（如锚点池过大）

| 命中量 | 处理 |
|:------:|:-----|
| ≤40 章 | 全部保留，不收敛 |
| 41-60 章 | 按命中密度排序，保留高密度章 |
| 61+ 章 | 按命中密度+均匀性筛选，保留 40-50 章 |

### 均匀性保证

确保锚点池覆盖 scope 全时间线：
- 开头（scope 前 10%）至少 2 章
- 中段至少 50%
- 结尾（scope 后 10%）至少 2 章

### 多维度覆盖验证

检查联合锚点池是否每个维度都有足够命中：
- 如果某维度在池中命中章 < 该维度锚点章下限的 60%，补充该维度的专属 Grep 检索

---

## 门禁

| 检查项 | 标准 |
|:------|:-----|
| 预扫描完成 | 术语表已提取（人名/地名/等级名至少3项） |
| 联合 Grep 执行 | 所有选中维度的检索词已合并为一次 Grep |
| 去重完成 | 联合锚点池无重复章节 |
| 命中章数 | ≥20 章（不足则扩大检索词或补充均匀采样） |
| 均匀性 | 锚点池覆盖开头/中段/结尾 |
| 多维度覆盖 | 每个维度在池中命中章 ≥该维度下限的 60% |
| style（如选中） | 场景定向采样完成（≥18章），已并入锚点池 |
