# Step 2：主线/支线/暗线拆解

> **方向**：从故事机制DNA梳理主线、支线、暗线三条剧情线，标注每条线的生命周期。
> **级别覆盖**：前N章 / 全书

## 定位

主线/支线/暗线是剧情线的骨架。分清"哪条线承载核心矛盾、哪条是陪衬、哪条是埋得深的暗线"，才能理解作者如何组织多线叙事。

## 数据来源

- 故事机制DNA（Step 1 产出）— 主要数据源
- 章节白描 — 证据验证

## 产出

| 文件 | 内容 |
|:-----|:-----|
| `设计/剧情线-主线支线暗线.md` | 三条线各自的生命周期 + 交织关系 |

## 拆解流程

### 1. 识别剧情线

从故事机制DNA的按幕拆解中，识别所有贯穿的剧情线。区分：

| 线类型 | 特征 |
|:-----|:-----|
| 主线 | 承载全卷核心矛盾，贯穿始终，决定结局 |
| 支线 | 阶段性目标/支线任务，有始有终 |
| 暗线 | 埋得深，前期只露线索，后期引爆 |

### 2. 为每条线标注生命周期

| 字段 | 内容 |
|:-----|:-----|
| 线名 | 一句话描述 |
| 类型 | 主线/支线/暗线 |
| 起始章 | 首次出现chXX |
| 激化章 | 关键冲突点chXX |
| 收束/引爆章 | 结局或引爆点chXX |
| 承载矛盾 | 这条线解决/推动什么矛盾 |
| 原文证据 | {原文一句话} + chXX |

### 3. 分析多线交织关系

- 主线与支线/暗线如何交织
- 支线是否服务于主线（陪衬/铺垫/补充世界观）
- 暗线如何铺垫并在后期反哺

### 4. 写多线结构叙事

用叙事总结多线怎么组织，像给朋友讲"作者是怎么用三条线把故事串起来的"，300-500字。
