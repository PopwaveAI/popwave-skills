# Step 1：收集全管线产出 → `_temp/prd-collected-data.md`

**目标**：扫描全管线产出，统计关键数据，为 Step 2 综合提供数据基础。

## 收集清单

### 1. 设计包统计（Phase 1）
- 读取 `设计包v4/` 或 `白描卡/` 目录
- 统计：章节数 / 总字数 / 模式（precision/fast）
- 记录：拆解窗口（前N章 / 全书M章 / 百分比）

### 2. 故事机制DNA统计（Phase 2）
- 读取 `设计/故事机制DNA-卷N.md`
- 统计：卷数 / 每卷幕数 / 总幕数
- 提取：全卷故事梗概 + 主角成长曲线 + 核心矛盾链

### 3. 名场面库统计（Phase 2）
- 读取 `设计/名场面库.md`
- 统计：名场面总数 / 场景节奏分析
- 提取：可复刻/变奏方向清单 + 跨界融合方向

### 4. 读者体验曲线统计（Phase 2）
- 读取 `设计/读者体验曲线-卷N.md`
- 统计：爽点总数 / 爽点密度规律 / 悬念链数
- 提取：压力机制清单 + 追读驱动力分析

### 5. 卷纲统计（Phase 2）
- 读取 `设计/卷纲/` 目录
- 统计：卷数 / 每卷幕数 / 篇幅预算
- 提取：跨卷方向清单

### 6. 设定统计（Phase 3）
- 读取骨架层：`力量体系.md`
- 读取血肉层：地理/历史/势力/资源/物种/金手指/弹性边界
- 读取角色层：人物卡 + 对白风格库 + 角色弧线
- 读取叙事资产层：伏笔与悬念追踪
- 统计：设定文件数 / 关键设定要素

### 7. 文风DNA
- 读取 `素材/文风锚定.md`（由dna-style独立产出）
- 提取：核心文风特征 / 笔触层维度

## 产出

`_temp/prd-collected-data.md` — 结构化数据摘要，包含以上 7 项统计结果。

> **注意**：本步骤只收集不分析。所有数据原样记录，分析判断留给 Step 2。
