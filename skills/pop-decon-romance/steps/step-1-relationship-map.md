# Step 1：情感关系网拆解

> **方向**：从章节白描梳理全书情感关系网，定位所有涉及情感连接的配对/群体。
> **级别覆盖**：前N章 / 全书

## 定位

情感关系网是情感线的骨架。先看清"谁和谁有情感连接、连接是什么类型"，才能拆 CP 线和羁绊演变。

## 数据来源

- 章节白描（`写作资产/白描卡/chXXX.md` 或 `设计包v4/chXXX.md`）— 主要数据源
- 原文（`_temp/chapters/chXXX.txt`）— 证据验证用

## 产出

| 文件 | 内容 |
|:-----|:-----|
| `设计/情感关系网.md` | 情感关系网清单（角色×角色×关系类型×强度×关键节点） |

## 拆解流程

### 1. 扫描白描，识别情感连接

扫描所有章节白描，识别角色间的情感连接。识别信号：

| 关系类型 | 信号 |
|:-----|:-----|
| 恋爱/CP | 暧昧互动、心动、告白、吃醋 |
| 亲情 | 血缘、养育、守护、牺牲 |
| 友情/羁绊 | 并肩作战、信任托付、生死相托 |
| 敌对/背叛 | 由信任转背叛、怨恨、反目 |
| 师徒/上下级 | 提携、传承、依赖 |

### 2. 建立关系网清单

为每对关系建立条目：

| 字段 | 内容 |
|:-----|:-----|
| 关系对 | A × B |
| 关系类型 | 恋爱/亲情/友情/敌对/师徒 |
| 初始强度 | 强/中/弱/无 |
| 关键节点 | 首次建立 + 质变点（chXX） |
| 演变方向 | 升温/降温/破裂/复合 |
| 原文证据 | {原文一句话} + chXX |

### 3. 标注关系驱动主角的比例

标注哪些关系对主角成长/行动有驱动作用（是情感动力的一部分），哪些只是背景点缀。
