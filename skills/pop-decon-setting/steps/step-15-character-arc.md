# Step 15：角色弧线提取 → 角色弧线.md

**数据来源**：故事机制DNA（Phase 2 Step 1产出）的有效事件清单 + 附录主角成长曲线

**归纳逻辑**：
1. 从故事机制DNA的"主角做了什么"列提取主角的行为轨迹
2. 从"主角level"列提取主角的能力/等级变化
3. 从附录"主角成长曲线"提取心态变化
4. 对每个主要角色（不只主角）提取弧线：
   - 起点→转折→终点的状态变化
   - 心态变化（什么触发了变化）
   - 弧线功能（在故事中承担什么角色功能）
5. **禁止行为**：故事DNA中没有的角色弧线 = 不准编造。必须基于有效事件清单的实际数据

**与Step 11人物卡的区别**：人物卡记录角色的静态设定（身份/能力/关系），角色弧线记录角色的动态变化（从什么状态到什么状态，什么驱动了变化）。

**续写/同人价值**：续写时延续角色弧线方向，同人写作时参考弧线节奏设计角色发展。

**产出**：

```markdown
## 角色弧线 — {角色名}

| 节点 | 章节 | 状态变化 | 心态变化 | 触发事件 | 弧线功能 |
|:-----|:------|:---------|:---------|:---------|:---------|
| 起点 | ch1 | {初始状态} | {初始心态} | {触发事件} | 建立基线 |
| 转折1 | chXX | {状态变化} | {心态变化} | {触发事件} | 推动变化 |
| 转折2 | chXX | {状态变化} | {心态变化} | {触发事件} | 深化/反转 |
| ... | | | | | |
| 终点 | chXX | {最终状态} | {最终心态} | {触发事件} | 弧线收束 |

**弧线特征**：{一句话概括这个角色的弧线——如"从求生本能到主动布局的觉醒弧线"}
```

覆盖范围：主角 + 主要配角 + 主要反派（每个角色一个弧线表）
