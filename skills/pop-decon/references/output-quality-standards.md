## 二、各产出物详细标准

### 2.1 Phase 1 — 设计包

**当前已知缺陷（深渊主宰评估，2026-06-15）**：
- 事件粒度：前4包良好(5-9事件/章)，第5包起退化(格式丢失+事件类型分类缺失)
- 动作序列：有但缺节奏感和肢体感受
- **对话：严重不足** — 仅摘1-2句引文，无完整对话序列，无语气/语调标注
- **感官锚点：致命缺口** — 无系统化视觉/听觉/嗅觉/触觉记录
- POV/文风指引：无叙事视角/内心独白密度标注

**最低标准**(L1)：
- 每章≥3个原子事件
- 每个事件有类型分类（交锋/社交/探索/成长/披露/转折/日常）
- 情绪节拍分段完整（起点→推进→高潮→终点或等价的子段）
- 智慧实体状态轨迹每5章聚合一次

**良好标准**(L2，在L1基础上追加)：
- 每个事件的"证据"字段指向具体原文行或段落
- 关键数据锚点（属性面板、技能数值、装备属性）完整保留
- 每章有章末钩子类型标注（悬念/信息/情绪）

**优秀标准**(L3，在L2基础上追加)：
- 每事件含 ≥3个感官细节（场景看/听/嗅/触至少2种维度）
- 关键对话场景保留 ≥3句连续对话，标注说话人语气
- 每章有叙事视角标注（POV角色 + 内心独白密度）
- 战斗章节有节奏标记（快写段落 / 慢写段落 / 中速对话段）

### 2.2 Phase 2 — 故事机制DNA(故事机制DNA-卷N.md)

**最低标准**(L1)：
- 两层结构完整：全卷故事梗概（含高潮和结局） + 按幕拆解（含有效事件清单）
- 有效事件清单每条标注 chXX 原文来源

**良好标准**(L2，在L1基础上追加)：
- 附录完整：主角成长曲线 + 核心矛盾链
- 幕间因果关系清晰

**优秀标准**(L3，在L2基础上追加)：
- 跨卷方向有因果逻辑链
- 有效事件清单三维度（主角level / 主角做了什么 / 读者知道了什么）均有原文证据

### 2.3 Phase 2 — 卷纲(卷N-卷纲.md)

**当前已知缺陷（深渊主宰评估）**：
- 三大剧情线仅罗列等级变动阶段，缺人格成长轨迹
- 分支线完全未统计（一卷有7条活跃副线）
- 无剧情密度/节奏分析
- 无卷末未解之谜提示

**最低标准**(L1)：
- 3条主线各≥5个阶段，每阶段≥2行描述
- 每个阶段标注起止章号
- 本卷总字数/总章数统计

**良好标准**(L2，在L1基础上追加)：
- **分支线跟踪表**：每条副线记录 起止章/活跃状态/活跃章数/所属幕
- 主角阵营漂移轨迹（关键选择→阵营变化）
- 情感节奏表：每幕的情感基调

**优秀标准**(L3，在L2基础上追加)：
- 伏笔-回收对照表：本卷埋了多少根线，收了多少根，留了多少根
- 未解之谜清单：卷末遗留悬念（至少明确列出）
- 角色出场密度统计：主要角色在各幕的出场权重

### 2.4 Phase 2 — 名场面库(名场面库.md)

**最低标准**(L1)：
- 每个名场面的叙事式拆解有原文锚点
- 300-500字自然叙事

**良好标准**(L2，在L1基础上追加)：
- 6个思考维度（位置/压力/行动/爽感/铺垫/技法）自然融入叙事

**优秀标准**(L3，在L2基础上追加)：
- 含跨界融合方向 + 场景节奏分析

### 2.5 Phase 2 — 读者体验曲线(读者体验曲线-卷N.md)

**最低标准**(L1)：
- 爽点分布覆盖全部章节
- 每个爽点标注 chXX + 爽感公式

**良好标准**(L2，在L1基础上追加)：
- 含情绪曲线 + 信息释放节奏

**优秀标准**(L3，在L2基础上追加)：
- 含压力机制分析 + 追读驱动力分析

### 2.6 Phase 3 — L1世界观六件套

**当前状态（深渊主宰评估）**：✅ 优秀级别，覆盖率、准确性、跨文档一致性均表现良好。

**门禁检查点**：
| 检查项 | 说明 |
|:-------|:------|
| ✅ 全部条目有chXX证据出处 | 必须执行 |
| ✅ 无编造内容 | 跨文档一致性抽查≥3项 |
| 🔴 无ch05X类占位符 | 零容忍——发现即退回 |
| 🔴 无问号存疑名未处理 | 命运女神? 类必须修复或标注脚注 |
| ⚠️ prose-render可消费性 | 建议增加世界观总纲作为入口文档 |

## 三、跨产出物一致性校验

不同Phase的产出物之间数据可能冲突，必须在全部产出后做至少3项交叉校验：

| 校验 | 源1 | 源2 | 失败后果 |
|:-----|:----|:----|:---------|
| 主角起始属性 | L1-02力量体系 | 起点终点快照 | prose-render用错数据 |
| 等级体系 | L1-02力量体系 | combat_capability | 战斗数值不一致 |
| 重要物品归属 | L1-06资源与物品 | design-pack事件链 | 物品-角色归属错误 |
| 核心角色名称 | 所有产出 | 所有产出 | 名称不一致→穿帮 |
| 卷-幕-章关系 | 故事机制DNA | 故事机制DNA/卷纲 | 章节归属错位 |
