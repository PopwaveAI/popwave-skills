# 拆书路由清单（单书深度wiki拆解）

> pop-decon 征询范围后的路由依据。拆书统一路由到 pop-decon-dimension（单书深度wiki拆解），直读原文反向抽取。**家从 4 精简为 2，已无 prd / design-pack 独立 skill**——立项/批次拆解方法论均内吸进主拆解成品层。

## L1 提取维度（批次档案七维 + 检索词）

| 维度 | 检索策略 | 拆什么 |
|:--|:--|:--|
| plot 剧情 | 预扫描人名逐个检索→追踪出场轨迹 | 主线/支线/暗线/卷纲/转折/伏笔 |
| romance 情感 | 关系词+人名两两组合（CP同章） | 关系演变/信任/背叛/情感节点 |
| character 人物 | 人名逐个检索+称号词+描写词 | 角色卡/弧线/动机/成长 |
| power 力量 | 力量词+战斗词+等级名 | 力量/升级/战斗/境界 |
| world 世界观 | 地理词+势力词+物品词+地名/势力名 | 地理/历史/物种/势力/物品 |
| beat 爽点 | 反转词+情绪词+冲突词 | 名场面/爽点/钩子/追读 |
| style 文风 | 场景定向采样（非Grep） | 笔触/句式/叙事距离/语气 |

> 所有维度检索词合并为**一次 Grep（`|` 连接）**，命中章去重成联合锚点池，每章只读一次多维提取→落盘批次档案。

## 铁律

- **先征询范围**（全书/卷/N章），只拆所选范围，禁止默认全量跑
- **L1 批次硬门禁不过关不进 L2**（空中楼阁禁令）
- **成品叙事流具名讲透**，禁止证据清单平铺
- **提醒少测**：拆书启动/完成时提醒"建议先用一卷/前N章少量测试再拓展全书"
