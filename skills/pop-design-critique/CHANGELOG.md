# CHANGELOG

## v1.0.0 | 2026-11-03

### 初始版：页面设计评审

> 背景：公众号「数字边界」解读的 `design-critique` 补上了我们最薄的一环——评审。现有工具链里 `frontend-design`、`solo-design` 都是生成类技能，AI 产出界面「精致但通用」，缺一个逐条挑刺的环节。据此新建本 skill，吸收其「位置-问题-影响」三段式与分阶段评审，并补上它对本项目不适用的部分（交互验收、一致性真源）。

- **四维评审**：可用性／视觉层次／一致性／可读性，另加本项目「每个元素是否服务明确用户目的」一条。
- **两档阶段范围**：早期只审结构，交付页才审对齐、间距、文案与状态，避免早期被像素级问题带偏。
- **三段式条目**：每条必须带位置、问题、影响，缺一段不算条目；给不出位置的直接丢弃。
- **三级定级**：🔴阻断／🟡干扰／🔵打磨，上限 10 条，同因多处合并。
- **明确不越界**：交互、滚动、响应式、键盘可达、加载态写进「未验证」，截图评审不算验收通过。
- **一致性需真源**：未提供 token 或同类页面基准时只报存疑，不凭感觉断言。
- **不做多 agent**：评审看同一批截图，多 agent 不增信息；多视野挑刺仍走 `pop-critic-panel`。
