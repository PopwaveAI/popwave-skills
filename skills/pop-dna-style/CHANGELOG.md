# CHANGELOG

## v1.5.0 (2026-08-11)

### 产出格式升级为「操作特征+精选原文」精简版

**根因**：文风库39个DNA已全部重构为「操作特征+精选原文」精简版（3-5K字），但pop-dna-style产出的文风锚定.md仍沿用旧的三层全量结构（原文≥500字堆叠），与write消费协议脱节。需统一产出格式，让write全量加载无压力。

**改动**：
- 产出格式统一切换为「操作特征+精选原文」精简版，与文风库精简版、write消费协议同构
- Step 2（提取）：v4模板从「观察+原文≥500字+时间演变」改为「操作特征(1段可执行)+精选原文(1-3句金句)」，时间演变并入操作特征
- Step 4（部署）：文件头标注精简版格式，消费协议明确「操作特征=可执行约束，精选原文=句式示范」
- Step 5（Stage 2综合重构）：终版笔触层改为操作特征+精选原文结构，新增3条质量门（格式/可执行性/金句化）
- 移除「原文≥500字堆叠」硬性要求，改为「精选原文金句化」
- SKILL.md红线2、SOP、速查表同步更新；skill.json版本号1.4.0→1.5.0

## v1.4.0 (2026-07-28)

### 新增Stage 2综合重构模式

**根因**：文风DNA从参考书纯提取存在局限性——参考书的笔触可能和本书世界画风矛盾（如深渊主宰的弹窗式面板在生存记录感的世界里不自然），且用户需求（面板偏好/主角姿态/节奏偏好）无法在纯提取阶段注入。需要在世界圣经产出后，用世界画风+用户需求对笔触层进行校验重构。

**改动**：
- 新增Stage 2：Phase 3完成后由pipeline调度，用世界画风+用户需求重构Stage 1笔触层
- 新增step5-synthesize.md：世界画风提取→笔触层校验重构（三问每个维度）→三层综合产出
- Stage 2对Stage 1笔触层拥有写权限（可修改/删除/保留），不是只读追加
- 每个修改/删除需世界画风的因果依据（源力量+物理规则+战斗方式矛盾才能改/删）
- 文风锚定.md从单层（笔触层）升级为三层（笔触层+世界画风层+用户需求层）
- 新增无参考书模式：用户Phase 0跳过拆书时，Stage 2从零构建（仅世界画风层+用户需求层）
- 新增红线❌6（Stage 2重构权限）和红线❌7（单一文件）
- SKILL.md重构为双阶段结构：Stage 1（Step 1-4）+ Stage 2（Step 5）
- skill.json版本号1.3.0→1.4.0

## v1.1.0 (2026-07-20)

### step1新增类型权重采样

**根因**：项目c测试发现诡舍DNA（恐怖悬疑）均匀采样导致恐怖氛围丢失——恐怖小说的核心笔触集中在揭秘/暗杀/情感高潮3类场景，但均匀采样只各采2-3章，核心笔触样本权重被日常对话/过渡缓冲等边缘场景稀释。

**改动**：
- step1.md新增1.0节：识别参考书类型→确定采样偏重
- 类型→采样偏重表：恐怖悬疑（重采揭秘/暗杀/情感高潮）、战斗爽文（重采boss战/群战）、都市异能（重采日常对话/揭秘/暗杀）、仙侠养成（重采环境引入/过渡缓冲/揭秘）
- 核心场景采3-4章，边缘场景采1-2章，总采样量保持25-30章不变
- 采样清单追加偏重说明
- skill.json：v1.1.0

## v1.0.0 (2026-07-20)

### 新建skill：文风DNA提取

填补write skill笔触DNA标准插槽的供给方空白。基于R42测试验证（玄鉴仙族+夜无疆+深渊主宰交叉测试）确认DNA可插拔方案可行。

**新增：**
- 双档位设计：
  - A·笔触DNA（必做）：句式/感官/叙事距离/对话/情绪外化/段落呼吸/系统面板格式 → `涌现/文风锚定.md`，write消费
  - B·剧情DNA brief（可选）：爽点节奏/Boss梯度/主角成长曲线3维度brief → `涌现/剧情DNA-brief.md`，seed/plot消费
- 场景定向采样策略：9种场景类型×2-3章=25-30章，替代旧的"前10+中5+后5"固定时间分段
- v4模板强制：每个维度/场景卡 = 观察(1-2句) + 原文(≥500字) + 时间演变(1-2句)
- 部署到项目本地`涌现/`，不进library库（library库已优化掉）
- 4条红线：v4模板完整性/场景覆盖≥8/只学笔触不学内容/部署到项目本地

**和decon的边界：**
- decon = 重拆（8维度全拆+Beat Sheet+全书剧情白描），用于精拆一本书做立项圣经
- pop-dna-style = 轻采（笔触DNA必做+剧情brief可选），用于拿参考书当灵感源
- 两者读同一本书但粒度不同，不冲突

**设计依据：**
- R42原版"仅DNA"高分是假象（DNA含原文+同章剧情梗概双重叠），R42f公平测试（ch50/ch075排除采样范围）验证DNA可插拔真实有效
- write v8.0.0做减法移除内置风格倾向后，笔触层全靠DNA供给，pop-dna-style填补这个供给方
