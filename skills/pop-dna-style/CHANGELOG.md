# CHANGELOG

## v1.6.0 (2026-08-13)

- skill.json 的 description 改为面向用户介绍、tags 改为可调用专家标签、版本号同步至 v1.6.0。

## v1.5.0 (2026-08-11)

### 产出格式升级为「操作特征+精选原文」精简版

**根因**：文风库39个DNA已全部重构为「操作特征+精选原文」精简版（3-5K字），但pop-dna-style产出的文风锚定.md仍沿用旧的三层全量结构（原文≥500字堆叠），与write消费协议脱节。需统一产出格式，让write全量加载无压力。

**改动**：
- 产出格式统一切换为「操作特征+精选原文」精简版，与文风库精简版、write消费协议同构
- Step 2（提取）：v4模板从「观察+原文≥500字+时间演变」改为「操作特征(1段可执行)+精选原文(1-3句金句)」，时间演变并入操作特征
- Step 4（部署）：文件头标注精简版格式，消费协议明确「操作特征=可执行约束，精选原文=句式示范」
- Step 5（Stage 2综合重构）：终版笔触层改为操作特征+精选原文结构，新增3条质量门（格式/可执行性/金句化）
- 移除「原文≥500字堆叠」硬性要求，改为「精选原文金句化」
- SKILL.md红线2、SOP、速查表同步更新；skill.json版本号1.4.0→1.5.0

## v1.4.0 (2026-07-28)

### 新增Stage 2综合重构模式

**根因**：文风DNA从参考书纯提取存在局限性——参考书的笔触可能和本书世界画风矛盾（如深渊主宰的弹窗式面板在生存记录感的世界里不自然），且用户需求（面板偏好/主角姿态/节奏偏好）无法在纯提取阶段注入。需要在世界圣经产出后，用世界画风+用户需求对笔触层进行校验重构。

**改动**：
- 新增Stage 2：Phase 3完成后由pipeline调度，用世界画风+用户需求重构Stage 1笔触层
- 新增step5-synthesize.md：世界画风提取→笔触层校验重构（三问每个维度）→三层综合产出
- Stage 2对Stage 1笔触层拥有写权限（可修改/删除/保留），不是只读追加
- 每个修改/删除需世界画风的因果依据（源力量+物理规则+战斗方式矛盾才能改/删）
- 文风锚定.md从单层（笔触层）升级为三层（笔触层+世界画风层+用户需求层）
- 新增无参考书模式：用户Phase 0跳过拆书时，Stage 2从零构建（仅世界画风层+用户需求层）
- 新增红线❌6（Stage 2重构权限）和红线❌7（单一文件）
- SKILL.md重构为双阶段结构：Stage 1（Step 1-4）+ Stage 2（Step 5）
- skill.json版本号1.3.0→1.4.0
