# 文风DNA档案 · 三段式模板

> **三段式（v1.7.0）**：本模板与文风库、write 消费协议同构，产出「操作特征+完整段落+反面教材」。完整段落让模型学到段落内技法组合，反面教材压住默认AI写作先验。AB测试实证：碎片化垫底（输入量大且学不到技法组合），本三段式凭1/7输入超越原文直灌。

---

## 格式规则

- **平铺**，无章节编号。每个维度/场景卡一节 H2 标题。
- **每个项目 = 操作特征(条件式) + 完整段落(不切碎) + 反面教材(AI味清单) 三段，缺一不可**。时间演变并入操作特征。
- **操作特征（条件式指令）**：【何时启用】→【写什么】→【写多长】→【边界】。用可执行动词。禁"营造/巧妙/让读者"评价词。不得写成"内容改写指令"（A改成B）——让子agent直接读DNA感受笔触。
- **完整段落**：1-3段该维度最典型原文，blockquote 引用，**整段保留不切碎**。父agent不得将其切成语义碎片。宁精勿滥（<3段），1段亦可。
- **反面教材（AI味清单）**：功能级禁则+病句族+「原书怎么替」反例替代。是功能性护栏，非关键词黑名单。
- **来源标注用斜体**：`> _——CH{N}，一句话说明_` 跟在完整段块后。
- **场景卡头标注 scene 字段**：`scene: combat_early_skirmish` 紧随 H2 标题。
- **不写绝对化结论** — 有全书搜索数字的标注数字，没有的标注"采样范围内"。
- **⚠️ 消费警告：'操作特征'描述的是作者的笔触特征（句式节奏/叙事距离/感官顺序/对话方式），不是'内容改写指令'；'反面教材'禁的是功能行为（点破后文/能力科普/情绪直述），不是单个词。**

## 一、场景卡矩阵（scene 字段取值协议）

> **消费协议**：设计包的 `scene` 字段必须与场景卡名称严格对齐。
> 例：设计包写 `combat_mid_boss` → write 匹配到此卡的原文 + 操作特征。

| 场景卡 | 对应 scene 字段值 | 选择标准 |
|:------|:----------------|:--------|
| 战斗·早期遭遇战 | `combat_early_skirmish` | 主角 ≤ 二阶，对手同级或杂兵，规模 ≤ 1 房间 |
| 战斗·中坚 boss 战 | `combat_mid_boss` | 主角 2-4 阶，单挑 boss，有招式名对抗，规模 = 建筑级 |
| 战斗·后期大规模 | `combat_late_war` | 主角 ≥ 4 阶，势力/军团级对抗，有神性能力展示 |
| 战斗·暗杀/偷袭 | `combat_stealth` | 背刺系统、潜行判定，暗杀公式 |
| 对话·日常 | `dialogue_daily` | 短对话，≤2 人 |
| 对话·情感高潮 | `dialogue_emotional` | 眼泪/告白/告别/久别重逢 |
| 对话·信息交换 | `dialogue_intel` | 打听/交锋，功能性 |
| 描写·环境引入 | `description_environment` | 新场景首次出场，从感官进入 |
| 描写·角色外貌 | `description_character` | 首次出场/换装/受伤后 |
| 叙述·孤独紧张 | `narration_suspense` | 独处/听动静/计算——信息→评估→决定 |
| 叙述·过渡/缓冲 | `narration_transition` | 战后收尾/清晨/赶路，节奏放缓 |
| 叙述·揭秘/心理戏 | `narration_reveal` | 揭开真相/内心挣扎，信息释放 |

> **不硬套不存在的卡。** 此书没有暗杀系统 → 不写 combat_stealth。

## 二、通用维度（≥4个必选）

每个维度格式：

```
## {维度名}

**操作特征**：（条件式指令：【何时启用】→【写什么】→【写多长】→【边界】）

**完整段落**：（1-3段最典型原文，blockquote整段保留不切碎）

**反面教材**：（AI味禁则+病句族+原书替代）
```

### 通用维度池

| 维度 | 要回答的问题 |
|:-----|:------------|
| **叙事者距离** | 叙事者离角色多近？进入内心还是只跟视线？是否偷看配角度？ |
| **情绪传递** | 情绪通过动作/对话/直述中的哪一种？ |
| **对话·引导词** | 引导词密度？零引导词/动作前置/完整引导的比例变化。 |
| **外貌描写** | 通过身体状态还是形容词直述？ |
| **数据嵌入** | 面板/装备/升级怎么呈现？内联【】还是独立段？ |
| **环境展开** | 每章从什么感官启动？空间认知从哪向外推？ |
| **段落呼吸** | 独句段的使用频率和功能？开篇/中期/末期的差异。 |
| **物品/装备描写** | 物品如何呈现——视觉在前还是数据在前？ |

## 五、禁止事项

- ❌ 不统计词频/句长/修辞密度
- ❌ 不写单个关键词禁令（反面教材只做功能级禁则）
- ❌ 不把单章偶然细节当全书规律
- ❌ 操作特征写成"内容改写指令"（A改成B）→ 退回
- ❌ 操作特征用"营造/巧妙/让读者"评价词 → 改写为条件式
- ❌ 任何维度/场景卡缺"完整段落"或"反面教材" → 退回
- ❌ 完整段落被切碎成语义碎片 → 恢复整段
- ❌ 反面教材写成关键词黑名单（只禁词不禁功能）→ 重写为功能级
- ❌ 完整段落/反面教材杜撰、与采样章不符 → 回采样章核对
