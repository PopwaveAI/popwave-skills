# Step 2: 笔触DNA提取（档位A·必做）

> 对采样清单的25-30章，按精简模板（`references/文风DNA-profile.md`）提取笔触DNA。这是必做档位，产出 write skill 的笔触层供给。

---

## 提取目标

- **通用维度**：≥4个（从8个必选维度中选）
- **场景卡矩阵**：≥8个（覆盖采样清单的主要场景类型）
- **全书稳定特征**：2条
- **每个维度/场景卡格式**：操作特征(1段可执行) + 精选原文(1-3句金句) + 时间演变(并入操作特征)，三者不可缺一
- **产出格式**：「操作特征+精选原文」精简版，与文风库精简版、Stage 2终版同构

---

## 精简模板格式（操作特征+精选原文）

### 通用维度卡格式

```markdown
### 维度：{维度名}

**操作特征**：（1段可执行的笔触约束，如"多用短句，平均每段2-3行，对话段独立成段；前期短句密集，后期逐渐出现长段叙事"——把观察和时间演变化为可执行指令）

**精选原文**：（1-3句最典型原文金句，体现该维度特征，blockquote引用）
```

### 场景卡格式

```markdown
### 场景卡：{场景类型}

**操作特征**：（1段该场景类型的可执行笔触，含时间演变要点）

**精选原文**：（1-3句最典型原文金句，blockquote引用）
```

---

## 提取流程

### 2.1 通用维度提取（≥4个必选）

从8个必选维度中选≥4个（优先选该参考书最有特色的）：

| 维度 | 观察什么 |
|:--|:--|
| 叙事者距离 | 近距跟随主角/中距旁观/全知视角？视角切换频率？ |
| 情绪传递 | 直述情绪/动作外化/物象外化/环境烘托？ |
| 对话引导词 | "道"/"说"/省略引导词/动作带出？ |
| 外貌描写 | 什么时候写外貌？写多少？静态铺陈还是动态带出？ |
| 数据嵌入 | 系统面板/数值/属性怎么呈现？内联【】还是独立段？ |
| 环境展开 | 环境描写长度？感官覆盖？功能化还是氛围化？ |
| 段落呼吸 | 段落长度分布？长短交替规律？节奏感？ |
| 物品描写 | 物品命名风格？描写详略？是否功能化？ |

> 每个维度读3-5个采样章，归纳特征。

### 2.2 场景卡矩阵提取（≥8个必选）

按采样清单的场景类型，每种类型做1张场景卡：

**候选场景卡**（按采样覆盖选）：
- 战斗·早期遭遇战
- 战斗·中坚boss战
- 战斗·群战/军队战
- 战斗·暗杀/背刺
- 对话·日常
- 对话·情感高潮
- 对话·信息交换
- 描写·环境引入
- 描写·角色外貌
- 叙述·孤独紧张
- 叙述·过渡缓冲
- 叙述·揭秘/心理戏

> 每张场景卡读该类型的2-3个采样章，归纳该场景的笔触特征。

### 2.3 全书稳定特征（2条必选）

归纳全书贯穿始终的稳定笔触特征，不随场景变化：

例如：
- "全书对话段独立成段，不与动作段混合"
- "全书无内心独白大段，情绪用动作或物象外化"

## 笔触DNA红线自检

提取完成后，逐条自检：

| 自检项 | 标准 | 不合格处理 |
|:--|:--|:--|
| v4模板完整性 | 每个维度/场景卡都有 操作特征+精选原文 两部分 | 补全缺失段 |
| 操作特征可执行 | 操作特征是直接可执行的笔触约束（句式/感官/叙事距离），非剧情描述 | 改写为可执行语气 |
| 精选原文金句化 | 每维精选1-3句最典型原文，非整段堆砌 | 精简为金句 |
| 场景覆盖 | 场景卡矩阵 ≥8 个 | 补充采样和场景卡 |
| 只学笔触不学内容 | 操作特征只描述写作风格，不描述剧情/战斗/角色思维 | 重写操作特征 |
| 原文真实性 | 精选原文必须来自采样章真实原文，不杜撰 | 回采样章核对 |

> 红线3（只学笔触不学内容）特别重要：观察字段禁止出现"主角用XX技能打败敌人"这类剧情描述，只描述"短句密集+动作动词连续+无心理描写"这类笔触特征。
