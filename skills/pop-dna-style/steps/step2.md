# Step 2: 笔触DNA提取（档位A·必做）

> 对采样清单的25-30章，按三段式模板（`references/style-dna-profile.md`）提取笔触DNA。这是必做档位，产出 write skill 的笔触层供给。
> ⚠️ v1.7.0 起产出为「**操作特征+完整段落+反面教材**」三段式——完整段落（不切碎）让模型学到段落内技法组合，反面教材（AI味护栏）压住默认AI写作先验。碎片化已被AB测试证明垫底，禁止回退。

---

## 提取目标

- **通用维度**：≥4个（从8个必选维度中选）
- **场景卡矩阵**：≥8个（覆盖采样清单的主要场景类型）
- **全书稳定特征**：2条
- **每个维度/场景卡格式**：操作特征(条件式指令) + 完整段落(整段不切碎) + 反面教材(AI味清单+功能诊断)，三者缺一不可；时间演变并入操作特征
- **产出格式**：「操作特征+完整段落+反面教材」三段式，与文风库、Stage 2终版、write消费协议同构

---

## 三段式模板格式

### 通用维度卡格式

```markdown
### 维度：{维度名}

**操作特征**：（条件式指令——【何时启用】→【写什么】→【写多长】→【边界】。用可执行动词，禁"营造/巧妙/让读者"等评价词）

**完整段落**：（1段该维度最典型原文，blockquote引用，整段保留不切碎——让模型学段落内技法组合。1-3段，最多3段，宁精勿滥）

**反面教材**：（AI味禁则清单——功能级禁则+病句族+「原书会怎么写」的反例替代）
```

### 场景卡格式

```markdown
### 场景卡：{场景类型}

**操作特征**：（条件式指令，含该场景类型的时间演变要点）

**完整段落**：（1段该场景类型最典型原文，blockquote引用，整段保留不切碎）

**反面教材**：（该场景类型的AI味清单——对话/动作/氛围各一条最易翻车的病句族）
```

## 提取流程

### 2.1 通用维度提取（≥4个必选）

从8个必选维度中选≥4个（优先选该参考书最有特色的）：

| 维度 | 观察什么 |
|:--|:--|
| 叙事者距离 | 近距跟随主角/中距旁观/全知视角？视角切换频率？是否偷看配角度 |
| 情绪传递 | 直述情绪/动作外化/物象外化/环境烘托？ |
| 对话引导词 | "道"/"说"/省略引导词/动作带出？ |
| 外貌描写 | 什么时候写外貌？写多少？静态铺陈还是动态带出？ |
| 数据嵌入 | 系统面板/数值/属性怎么呈现？内联【】还是独立段？ |
| 环境展开 | 环境描写长度？感官覆盖？功能化还是氛围化？ |
| 段落呼吸 | 段落长度分布？长短交替规律？节奏感？独句段功能？ |
| 物品描写 | 物品命名风格？描写详略？是否功能化？ |

> 每个维度读3-5个采样章，归纳特征。

### 2.2 场景卡矩阵提取（≥8个必选）

按采样清单的场景类型，每种类型做1张场景卡：

**候选场景卡**（按采样覆盖选）：
- 战斗·早期遭遇战
- 战斗·中坚boss战
- 战斗·群战/军队战
- 战斗·暗杀/背刺
- 对话·日常
- 对话·情感高潮
- 对话·信息交换
- 描写·环境引入
- 描写·角色外貌
- 叙述·孤独紧张
- 叙述·过渡缓冲
- 叙述·揭秘/心理戏

> 每张场景卡读该类型的2-3个采样章，归纳该场景的笔触特征。

### 2.3 反面教材提取（每维度/场景卡必选）

对每个维度/场景卡，从采样章反推该特征最易翻成AI味的写法：

| 反面教材要素 | 定义 | 示例 |
|:--|:--|:--|
| **病句族** | 该维度下模型最容易默认产出的AI病句形态 | 情绪直述病（"他的眼睛里闪过一丝复杂"）/定格病（"时间仿佛凝固了"） |
| **功能级禁则** | 该维度下必须禁止的功能行为 | 禁"点破后文"（"这是他此生最后一个安全时刻"）/禁"能力科普旁白" |
| **原书替代** | 原书是「怎么避开上面病句」的——给一句原书处理示范 | 原书用"动作外化"替代"情绪直述" |

> **反面教材是功能性护栏，不是关键词黑名单**：禁的是"这个维度里模型最易翻车的功能行为"，不是某个词。原书替代说明"该禁的东西，原书作者用了什么更高明的写法顶上"。

### 2.4 全书稳定特征（2条必选）

归纳全书贯穿始终的稳定笔触特征，不随场景变化：

例如：
- "全书对话段独立成段，不与动作段混合"
- "全书无内心独白大段，情绪用动作或物象外化"

## 笔触DNA红线自检

提取完成后，逐条自检：

| 自检项 | 标准 | 不合格处理 |
|:--|:--|:--|
| 三段式完整性 | 每个维度/场景卡都有 操作特征+完整段落+反面教材 三部分 | 补全缺失段 |
| 操作特征条件式 | 操作特征=何时启用→写什么→写多长→边界，可执行；禁"营造/巧妙/让读者"评价词 | 改写为条件式指令 |
| 完整段落不切碎 | 整段保留原文，不切成语义碎片块；blockquote引用 | 恢复整段 |
| 反面教材功能性 | 反面教材=功能级禁则+病句族+原书替代，非关键词黑名单 | 重写为功能级 |
| 场景覆盖 | 场景卡矩阵 ≥8 个 | 补充采样和场景卡 |
| 只学笔触不学内容 | 操作特征只描述写作风格，不描述剧情/战斗/角色思维 | 重写操作特征 |
| 原文真实性 | 完整段落必须来自采样章真实原文，不杜撰 | 回采样章核对 |

> 红线3（只学笔触不学内容）特别重要：观察字段禁止出现"主角用XX技能打败敌人"这类剧情描述，只描述"短句密集+动作动词连续+无心理描写"这类笔触特征。
