# Step 5: 文风DNA综合重构（Stage 2）

> **本步骤定位**：当世界设定产出后，拿世界画风当镜子照一遍Stage 1的笔触层——问"这个笔触维度放到本书世界里还成立吗？"成立就保留，不成立就修改，矛盾就删除。然后追加世界画风层和用户需求层，产出终版文风锚定.md。
> **触发时机**：pipeline Phase 3（world）完成后，由pipeline主agent调度执行。
> **核心权限**：对Stage 1产出的笔触层拥有写权限——可修改/删除/保留任何维度，不是只读追加。

## 重构流程

### 5.1 世界画风提取

> 从全书设定文件中提取本书世界的综合画风。画风是源力量+物理规则+战斗方式的综合气质，不是参数清单。

从全书设定文件中提取以下维度：

| 画风维度 | 来源文件 | 提取方法 | 产出 |
|:--|:--|:--|:--|
| **战斗画风** | `战斗系统.md`产出E（战斗画风表） | 直接消费——每个阶位段的画风描述 | 战斗场景的整体气质 |
| **环境画风** | `物理规则.md` + 力量体系.md源力量 | 问"这个世界的物理环境什么气质？"（如阴冷压抑/飘逸华丽/硬朗写实/荒诞诡谲） | 环境描写的整体调性 |
| **日常画风** | `民风民俗.md` + `政治经济.md` | 问"这个世界的人日常生活什么调性？"（如苦涩沉重/轻松市井/森严等级） | 日常场景的整体氛围 |
| **源力量画风** | `物理规则.md`力量法则 + 力量体系.md源力量 | 问"这个世界的超凡力量什么视觉气质？"（如金色神圣/暗红血腥/幽蓝神秘/灰色朴素） | 超凡力量表现的视觉基调 |

> **画风提取硬约束**：画风从世界因果链涌现（源力量→物理规则→战斗方式→画风），不是凭空设计。每个画风描述必须回溯到全书设定文件的具体设定。

### 5.2 笔触层校验重构

> **核心环节**：拿5.1提取的世界画风，逐维度校验Stage 1的笔触层。每个维度问三个问题。

对文风锚定.md v1中的**每个通用维度**和**每张场景卡**，执行以下校验：

#### 校验三问

| # | 问题 | 判断标准 | 处理方式 |
|:--|:--|:--|:--|
| 1 | **这个笔触维度放到本书世界里成立吗？** | 笔触描述的写作手法在世界画风的气质下是否自然 | 成立→保留（标记✅） |
| 2 | **如果不成立，是部分不成立还是完全不成立？** | 部分不成立=核心手法对但某些细节和世界矛盾；完全不成立=整个手法和世界气质冲突 | 部分不成立→修改（标记🔧）<br>完全不成立→删除（标记❌） |
| 3 | **如果修改，改成什么？** | 用世界画风作为校准基准，把矛盾的部分替换成本书世界的等效手法 | 写明修改前后对比 |

#### 校验维度清单

对以下维度逐个执行校验三问：

**通用维度**：
| 维度 | 校验重点（举例） |
|:--|:--|
| 叙事者距离 | 参考书的叙事距离放到本书世界是否自然？如参考书贴身跟随但本书世界是宏大史诗感→可能需要拉远 |
| 情绪传递 | 参考书的情绪传递方式放到本书世界是否自然？如参考书用身体反应传情但本书世界是高魔华丽→可能需要加入灵能/法术层面的情绪表达 |
| 对话引导词 | 参考书的引导词风格放到本书世界是否自然？如参考书朴素直接但本书世界是贵族政治→可能需要加入身份感引导词 |
| 数据嵌入 | **关键校验项**——参考书的面板嵌入方式放到本书世界是否自然？如参考书弹窗式但本书世界是写实生存感→改为编织式或混合式 |
| 环境展开 | 参考书的感官顺序放到本书世界是否自然？如参考书嗅觉先行但本书世界是冰雪纯净→可能改为触觉先行 |
| 段落呼吸 | 参考书的段落节奏放到本书世界是否自然？如参考书短句密集但本书世界是史诗感→可能需要加入长段叙事 |
| 外貌描写 | 参考书的外貌描写方式放到本书世界是否自然？ |
| 物品描写 | 参考书的物品描写方式放到本书世界是否自然？ |

**场景卡**：
| 场景卡 | 校验重点（举例） |
|:--|:--|
| 战斗·早期遭遇战 | 参考书的低阶战斗笔触放到本书世界的低武期画风下是否自然？ |
| 战斗·中坚boss战 | 参考书的boss战笔触放到本书世界的中武期画风下是否自然？ |
| 对话·日常 | 参考书的日常对话笔触放到本书世界的日常画风下是否自然？ |
| 描写·环境引入 | 参考书的环境引入笔触放到本书世界的环境画风下是否自然？ |
| 叙述·孤独紧张 | 参考书的紧张段笔触放到本书世界的战斗画风下是否自然？ |
| ... | 对每张存在的场景卡都执行校验 |

#### 重构决策表

将校验结果汇总为重构决策表：

| 维度/场景卡 | 校验结果 | 处理方式 | 修改说明（如修改/删除） |
|:--|:--|:--|:--|
| 叙事者距离 | 成立 | ✅保留 | — |
| 数据嵌入 | 部分不成立 | 🔧修改 | 弹窗式→混合式（战斗中编织+战后结算弹窗），因本书世界是生存记录感，弹窗打断叙事流 |
| 战斗·早期遭遇战 | 部分不成立 | 🔧修改 | 动作链精确拆解→动作+感官反馈交织，因本书世界画风是阴冷压抑而非游戏化 |
| 外貌描写 | 完全不成立 | ❌删除 | 参考书的动态外貌描写和本书世界的非人视角冲突，删除此维度 |
| ... | | | |

> **重构硬约束**：修改和删除必须有世界画风的因果依据。不能"我觉得这个不好"就删——必须是"这个笔触维度和本书世界的画风（源力量+物理规则+战斗方式）矛盾"才能修改/删除。

### 5.3 用户需求层提取

> 从用户意图和世界决策表中提取用户对文风的显性偏好。这些偏好优先级最高——即使参考书笔触层和世界画风层都不矛盾，用户需求也可以覆盖。

| 需求维度 | 来源 | 提取方法 | 产出 |
|:--|:--|:--|:--|
| **面板嵌入方式** | 用户意图 + 世界决策表 | 用户是否明确要求保留/删除面板？如保留，偏好弹窗式/编织式/混合式？ | 面板嵌入方式声明 |
| **主角姿态偏好** | 用户意图 + 世界决策表 | 用户偏好猎手式（掌控全局）/幸存者式（挣扎求生）/混合式？ | 主角姿态声明 |
| **节奏偏好** | 用户意图 | 用户偏好快节奏游戏化/慢节奏生存感/混合节奏？ | 节奏偏好声明 |
| **特殊文风要求** | 用户意图 | 用户是否有明确的文风要求（如"像XX书的笔触""要有古风感"）？ | 特殊要求声明 |

> **用户需求优先级**：用户需求层 > 世界画风层 > 笔触层。三者冲突时，用户需求覆盖世界画风，世界画风覆盖笔触层。

### 5.4 三层综合产出

> 将校验后的笔触层 + 世界画风层 + 用户需求层综合为终版文风锚定.md。

#### 产出硬约束

1. **单一文件**——终版文风锚定.md是唯一文件，不拆分。三层在同一个文件中用H2分隔
2. **Stage 1内容不删除**——即使某维度被标记❌删除，也保留原文+标注删除原因（write可据此理解参考书原貌）

## 无参考书模式

> 如果用户在Phase 0选择跳过拆书（无参考书），文风锚定.md v1不存在。Stage 2此时从零构建。

### 流程调整

1. **跳过5.2**（笔触层校验重构）——没有Stage 1笔触层可校验
2. **5.1世界画风提取**照常执行——从全书设定文件提取画风
3. **5.3用户需求层提取**照常执行——从用户意图提取偏好
4. **5.4三层综合产出**调整为二层产出——只有世界画风层+用户需求层，无笔触层
5. **文件头标注**"无参考书模式"——`Stage 1: 跳过（用户选择无参考书）`

> **无参考书模式的write消费**：write skill拿到无笔触层的文风锚定.md时，从世界画风层+用户需求层推导笔触——画风决定"战斗什么气质"，用户需求决定"面板怎么嵌"，write结合战斗六要素自行落地。质量会降级（没有参考书的具体笔触锚定），但不会无法工作。

## Stage 2质量门

| 检查项 | 标准 | 不合格处理 |
|:--|:--|:--|
| 世界画风提取完整 | 4个画风维度（战斗/环境/日常/源力量）全部提取 | 补充缺失维度 |
| 笔触层校验完整 | 每个通用维度+每张场景卡都有校验结果 | 补充校验 |
| 重构决策表完整 | 每个修改/删除都有世界画风的因果依据 | 补充依据 |
| 用户需求层完整 | 4个需求维度全部提取（无则标注"用户未指定"） | 标注缺失 |
| 三层综合文件结构正确 | H2分隔三层 + 重构决策表在末尾 | 调整结构 |
| 画风回溯链完整 | 每个画风描述回溯到全书设定文件设定 | 补充回溯 |
| 单一文件 | 素材/文风锚定.md是唯一产出文件，不拆分 | 合并 |
| **「操作特征+精选原文」格式** | 每个维度/场景卡 = 操作特征（1段）+ 精选原文（1-3句blockquote），与文风库精简版同构 | 重写为精简版格式 |
| **操作特征可执行** | 操作特征是直接可执行的笔触约束，非观察描述 | 改写为可执行语气 |
| **精选原文金句化** | 每维精选1-3句最典型原文，非整段堆砌 | 精简为金句 |
