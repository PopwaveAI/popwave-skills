# pop-drama-review

> 短剧剧本线审核环节。当前版本 v1.0.0（2026-10-19：首版）。
> 本环节只判剧本能不能交，不改写。改写回 script。

---

## 本环节负责什么

| 任务 | 触发 | 输入 | 产出 |
|:--|:--|:--|:--|
| 单集审核 | 每集或每组剧本写完 | `剧本/EP{NNN}.md`、分集大纲本集行、人物小传、上集剧本 | `审核/EP{NNN}-审核.md` |
| 整剧审核 | 全剧写完或阶段验收 | 全部剧本、分集大纲、钩子台账 | `审核/全剧审核报告.md` |

**边界**：审核只出结论与改法，不替 script 重写整集。发现方向性错误，报 plot 或 seed。

**执行方式**：主 agent 直接执行。审核必须逐集读原文，不能只看自检表。

---

## 审核顺序（不可跳步）

```
格式 → 卡点 → 开头 → 转折 → 台词 → 可拍性 → 连续性 → 合规
```

先看格式，格式乱后面的判断都不可靠；最后看合规，避免前面白改。

---

## 一、格式检查

| 项 | 判据 | 不合格处理 |
|:--|:--|:--|
| 文件名 | `EP{NNN}.md` | 改名 |
| 场次头 | `集号-场号 地点 时间 内/外` | 补全 |
| 人物行 | 本场相关人物，不用"众人" | 补全 |
| 动作行 | 全部以 △ 开头 | 改格式 |
| 台词 | `角色（状态）：台词` | 改格式 |
| 首次出场 | 有字幕介绍 | 补字幕 |
| 卡点 | 有 `【卡点】` 标记 | 补标记 |
| 字数 | 在目标区间 ±20% | 增删 |

格式不合格超过 3 处，直接 REJECT，不再往下审。

---

## 二、卡点检查（最重）

逐集看最后 5 秒：

| 项 | 判据 |
|:--|:--|
| 是一个问题 | 观众无法从本集内容回答 |
| 类型明确 | 能归入揭露/反转/倒计时/闯入之一 |
| 不与上集同型 | 对照钩子台账 |
| 与下集开头成对 | 下集开头接的是反应，不是换场景 |
| 不是情绪收尾 | 最后一句不是"她哭了""他笑了" |
| 不是结论 | 最后一句不是"她终于安全了" |

**红线**：连续两集同型，或本集没有卡点，直接 REJECT。

---

## 三、开头检查

| 项 | 判据 |
|:--|:--|
| 前 3 秒 | 有画面钩子，不靠台词开场 |
| 前 15 秒 | 讲清谁、要什么、谁挡着 |
| 无前情提要 | 不靠字幕或旁白补上一集 |
| 第 1 集 | 是反常开局，不是日常起床 |

---

## 四、转折检查

| 项 | 判据 |
|:--|:--|
| 有转折 | 本集局势发生一次变化 |
| 主角主动 | 转折由主角的选择造成 |
| 位置 | 在 55%-80% 区间，不拖到最后 |
| 有代价 | 转折让主角付出代价，不是白赚 |

**红线**：主角全程被动，或转折由配角替主角完成，REJECT。

---

## 五、台词检查

| 项 | 判据 |
|:--|:--|
| 单句长度 | ≤30 字；超过 3 句需要拆 |
| 口语 | 念一遍顺口，无书面腔 |
| 无解释 | 不出现"其实我是因为……"式说明 |
| 有辨识度 | 遮住名字能认出说话人 |
| 无废话 | 每句至少承担推进/暴露/反击/定调之一 |
| 无 AI 腔 | 不出现"值得注意的是/总之/由此可见"等 |

---

## 六、可拍性检查

| 项 | 判据 |
|:--|:--|
| 场景数 | 每集 ≤3 |
| 人物数 | 有台词人物 ≤5 |
| 场景可用 | 场次头的地点能在场景库找到 |
| 动作可拍 | 无心理、无抽象判断、无"众人震惊" |
| 构图 | 不同时并排站 3 人以上 |
| 特效 | 本集特效在预算内，未超总集数 20% |
| 道具 | 关键道具在本集前后一致 |

**红线**：出现心理描写、抽象判断、无法拍摄的概述，REJECT。

---

## 七、连续性检查

| 项 | 判据 |
|:--|:--|
| 人物称呼 | 与人物小传一致，无改名 |
| 性格 | 行为与人物卡一致，无突然转变 |
| 语言 | 与本集之前一致，无口吻漂移 |
| 时间线 | 与上集接得上，无跳日无重复 |
| 伤势/道具 | 与上集结尾一致（伤口、衣服、信物） |
| 信息边界 | 人物只知道他该知道的事 |
| 钩子 | 钩子台账已更新，无超期未表态 |

**红线**：人物知道了他不该知道的信息，或关键道具凭空出现，REJECT。

---

## 八、合规检查

| 项 | 判据 |
|:--|:--|
| 暴力 | 不展示过度血腥细节；用反应与声音替代 |
| 性暗示 | 不写露骨内容；亲密戏点到为止 |
| 未成年人 | 不涉及性化、虐待细节 |
| 敏感身份 | 不歧视地域、职业、疾病、族群 |
| 真实人物 | 不影射可识别的真实个人 |
| 平台规则 | 与目标平台公开规则不冲突 |

合规问题不评分，命中即改。

---

## 评分与结论

满分 100：

| 维度 | 分值 |
|:--|--:|
| 卡点 | 25 |
| 开头 | 15 |
| 转折 | 15 |
| 台词 | 15 |
| 可拍性 | 15 |
| 连续性 | 10 |
| 格式 | 5 |

**结论规则**：

- 80 分以上且无红线：PASS。
- 60-79 分：CONDITIONAL，列必改项，改完复审。
- 60 分以下或命中任一红线：REJECT，回 script 重写。

**红线四条**：

1. 没有卡点，或连续两集同型。
2. 出现小说式心理描写或无法拍摄的概述。
3. 人物知道了他不该知道的信息，或关键道具凭空出现。
4. 场景 >3 或有台词人物 >5。

## 报告写法

每集一份 `审核/EP{NNN}-审核.md`，用 `templates/审核报告.tpl.md`。问题逐条写四样：

- 位置：第几场、哪一句。
- 问题：原文摘录。
- 判据：违反哪条。
- 改法：具体怎么改，给一句示例。

不只写"节奏不好""台词生硬"这类判断。

---

## 整剧审核

全剧写完后做一次，额外检查：

- [ ] 每 3 集一个完整弧线，弧末有翻面。
- [ ] 付费墙集是全剧前段最强揭露。
- [ ] 中点有一次权力或关系翻面。
- [ ] 85% 处有最低点。
- [ ] 卡点四型都有出现，无连续同型。
- [ ] 钩子台账无超期未回收。
- [ ] 人物弧光从起点走到终点。
- [ ] 主场景未超出场景库。
- [ ] 结局回答了核心信息差。
- [ ] 全剧没有重复的冲突解法。
