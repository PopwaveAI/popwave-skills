# pop-drama-script

> 短剧剧本写作模块。当前版本 v3.0.0（2026-10-19：整体重构——按 AI 可生成约束写剧本，增加全剧合订本与镜头交接）。
> 本模块把分集卡点表的一行，写成一集可拍、可拆成 12-13 镜的剧本。

---

## 本模块负责什么

**输入**：

- `04-分集卡点表.md` 的本集一行（含镜头预算、台词预算、风险）。
- `03-人物关系与人物卡.md`：语言指纹、视觉锚点、信息边界。
- `03-场景与视觉.md`：场景 ID、空景锚点、道具、光线与声音。
- `03-故事核.md`：信息差与揭示节点。

**输出**：

- `05-剧本/EP{NNN}.md`：单集剧本。
- `05-剧本/全剧剧本.md`：全剧合订本（全部集写完后）。

**边界**：不改分集卡点的方向；不写首帧 prompt；不做镜头意图表（归 shotintent）。

**执行方式**：主 agent 直接执行。一次写 3 集为一组，写完即交 review。用户点名单集时只写单集。

---

## 写前五问

动笔前回答，答不出不写：

1. **本集冲突是什么？** 一句话，只有一个。
2. **主角本集主动做了什么？** 一个选择，不是被动挨打。
3. **最后 5 秒留下什么问题？** 一个问题，不是一个结论。
4. **本集能不能拆成 12-13 镜？** 不能，回 beats 重排。
5. **本集是否只有 1 个主场景、3 个主要角色、台词 70-80 字？** 不是，回 beats 重排。

五问写进剧本头部，写完回查是否兑现。

## AI 可生成约束

| 项 | 标准 |
|:--|:--|
| 本集主场景 | 1 个（最多 2 个） |
| 本集主要角色 | 3 个（最多 4 个） |
| 本集镜头 | 12-13 镜（10-14 可接受） |
| 单镜动作 | 1 个 |
| 单句台词 | ≤12 字 |
| 本集台词总量 | 70-80 字 |
| 禁止 | 奔跑、打斗、快速转身、多人互动、crowd、儿童正脸、动物特写、大范围水/火/烟 |

**写剧本时就要按镜头想**：一场戏里如果一次写了三个动作，shotintent 拆不出 12-13 镜，说明剧本阶段就超了。

详见 `<pop-drama-workbench 包根>/references/AI短剧生产约束.md`。

## 单集写作流程

### Step 1 拆场

按分集卡点表的场景列，把本集拆成 1-2 场（最多 2 场）。每场只干一件事。

**场次头格式**：

```
7-1 海底封印处 夜 外
人物：佩特拉、罗德里克、王子
```

- 场号：`集号-场号`。
- 地点、时间（日/夜/黄昏/清晨）、内/外。
- 人物行列出本场有台词或关键动作的人，最多 3 个主要角色。

**拆场判据**：一场里出现两个地点、两个时间，或两件互不相关的事，拆。

### Step 2 排四拍

90 秒标准：

| 时间 | 拍 | 写什么 |
|:--|:--|:--|
| 0-15 秒 | 钩子 | 一个画面或一句冲突台词，直接开始 |
| 15-60 秒 | 升级 | 2-3 次交锋，每次抬高代价 |
| 60-80 秒 | 转折 | 主角做出改变局势的选择 |
| 80-90 秒 | 卡点 | 最后 5 秒留下问题 |

60 秒集：0-10 / 10-40 / 40-53 / 53-60。
120 秒集：0-15 / 15-75 / 75-108 / 108-120。

**顺序纪律**：先写卡点，再写钩子，最后填中间。两头定了，中间才知道往哪推。

### Step 3 写动作行

动作行以 `△` 开头，只写镜头能拍到的：

- 谁做了什么动作。
- 什么道具出现了。
- 环境发生了什么变化。
- 人物表情或身体状态（外部可见）。

**合格**：

```
△ 她把手机摔在桌上，屏幕裂了一道纹。
△ 罗德里克拔剑，横在佩特拉身前。
△ 门缝下渗进来的水，漫过她的鞋尖。
```

**不合格**：

```
△ 她心里一阵刺痛。（拍不到）
△ 他意识到自己被骗了。（拍不到）
△ 气氛变得尴尬。（拍不到）
```

**动作三条**：

1. 一个动作行只写一个动作，最多两个短句。
2. 关键情绪用道具承担：捏碎杯子、撕照片、把戒指放回桌上。
3. 每 3-5 秒要有一个画面变化，不写超过 3 行的静态描述。

**镜头意识**：每 3-5 行动作/台词，应该能切成一个镜头。写的时候心里数：这一集够不够 12-13 个可切的点。

### Step 4 写台词

**格式**：

```
角色（状态）：台词
角色（OS）：内心独白
角色（电话）：电话里的声音
```

**台词五条**：

1. 一句只干一件事：推进、暴露、反击。
2. 单句 ≤12 字；冲突句更短。
3. 用口语，不用书面语；念一遍，拗口就改。
4. 不用台词解释观众已经看到的画面。
5. 能用一个动作替代的，不写台词。

**四种有力写法**：

| 写法 | 例 |
|:--|:--|
| 反问 | "你确定？" |
| 打断 | "闭嘴。听。" |
| 重复 | "你再说一遍。" |
| 沉默 | 她看着他，不说话，把戒指放在桌上。 |

**禁止**：

- 解释性台词："其实我是因为小时候……"
- 总结性台词："看来这一切都是他设计的。"
- 书面腔："我对此感到十分失望。"
- 一句话塞两个信息点。

### Step 5 写字幕与标记

- **人物首次出场**：`字幕：【身份 姓名】`，省掉自我介绍。
- **时间地点跳转**：`字幕：【三天后·北境】`。
- **画外音**：`角色（OS）：…`，一集不超过 3 次。
- **闪回**：`【闪回】` 标注进入与退出。
- **空镜**：`△【空镜】…`，只拍环境，用于过渡。
- **卡点**：`△【卡点】…`，本集最后一个画面。

### Step 6 收尾检查

写完后逐项过 `templates/剧本自检表.tpl.md`，不过项就改。至少检查：

- [ ] 第一行是否有画面或冲突，不是背景介绍。
- [ ] 15 秒内是否讲清谁、要什么、谁挡着。
- [ ] 是否有主角主动做出的转折。
- [ ] 最后 5 秒是否是一个问题。
- [ ] 是否出现心理描写词（心想、感到、意识到、回忆起）。
- [ ] 场景是否 ≤2，主要角色是否 ≤3。
- [ ] 台词是否 70-80 字，单句是否 ≤12 字。
- [ ] 是否能切成 12-13 镜，且每镜一个动作。
- [ ] 卡点类型是否与上一集不同。
- [ ] 本集是否推进了钩子台账至少一条线。

## 批量写法（3 集一组）

1. 读本组 3 集的分集卡点表行与前 10 集节拍（若在前 10 集）。
2. 一次写完 3 集，写的时候保持三集卡点类型不同。
3. 三集写完，统一做一次台词朗读检查与镜头切点检查。
4. 交 review，按意见改。
5. PASS 后更新 `00-创作总表.md`，写下一组。

**禁止**：一次生成 10 集以上不审。

---

## 全剧合订本

全部集 PASS 后，写 `05-剧本/全剧剧本.md`：

- 封面：剧名、集数、时长、版本。
- 故事梗概（300 字以内）。
- 人物表（ID、姓名、身份、一句话）。
- 分集目录。
- 全剧剧本正文（按集顺序合并）。
- 附：每集台词字数统计。

合订本只做阅读与审批，不作为镜头意图来源。

---

## 交镜头意图

剧本 PASS 后，交 `pop-drama-shotintent`：

- 每集剧本。
- 本集分集卡点行（镜头预算、台词预算、风险）。
- 人物卡（角色 ID、视觉锚点）。
- 场景与视觉（场景 ID、空景锚点）。

**不要**在剧本里写首帧 prompt 或运动指令。

## 常见问题与改法

| 问题 | 表现 | 改法 |
|:--|:--|:--|
| 开头像小说 | 第一场在交代背景 | 把本集最激烈的冲突提到第一场 |
| 中段塌 | 15-60 秒只有对话，没有新信息 | 每 15 秒加一次代价抬升或新事实 |
| 转折太晚 | 60-80 秒才开始动 | 把转折提到 55-60 秒，卡点留最后 10 秒 |
| 卡点弱 | 最后是情绪或结论 | 改成四型中的一种，留下具体问题 |
| 台词太长 | 一句超过 12 字 | 拆成两句，或删掉解释部分 |
| 人物声音一样 | 遮住名字认不出 | 按语言指纹重写 |
| 场景太贵 | 一集 3 场、外景加群演 | 合并同地点，群演改成一两个具体的人 |
| 信息靠说 | 角色互相解释设定 | 改成道具、字幕或一个动作 |
| 镜头切不开 | 一集只有 6-8 个动作点 | 加交锋、加反应、加道具特写 |
| 镜头太多 | 一集 18 个动作点 | 砍线、合并动作、拆集 |
