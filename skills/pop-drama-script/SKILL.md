# pop-drama-script

> 短剧剧本模块。当前版本 v4.0.0（2026-10-19：剧本成为最终创作对象，分镜收为剧本子页）。
> 本模块把分集卡点表的一行，写成一集可拍、可拆成 12-13 镜的剧本。

---

## 本模块负责什么

**输入**：

- `05-分集/分集卡点表.md` 的本集一行（含镜头预算、台词预算、风险）。
- `05-分集/预算表.md` 本集预算。
- `04-人物/主要人物.md` 与 `04-人物/选角与视觉锚点.md`：语言指纹、视觉锚点、信息边界。
- `03-设定/场景库.md`：场景 ID、空景锚点、道具、光线与声音。
- `03-设定/视觉风格.md`、`03-设定/语言风格.md`、`03-设定/合规红线.md`。
- `03-设定/故事核.md`：信息差与揭示节点。

**输出**：

- `06-剧本/EP{NNN}.md`：单集剧本。
- `06-剧本/全剧剧本.md`：全剧合订本。
- `06-剧本/台词统计.md`：每集台词字数与语音秒数。
- `06-剧本/分镜/EP{NNN}.md`：分镜子页，由 `pop-drama-shotintent` 生成。
- `06-剧本/审稿/EP{NNN}-审稿.md`：审稿记录，由 `pop-drama-review` 生成。

**边界**：

- 不改分集卡点的方向。
- 不写分镜 12 字段（归 shotintent）。
- 不写首帧 prompt、不做抽卡、不做剪辑。

**执行方式**：主 agent 直接执行。一次写 3 集为一组，写完即交 review。用户点名单集时只写单集。

## 写前五问

1. **本集冲突是什么？** 一句话，只有一个。
2. **主角本集主动做了什么？** 一个选择，不是被动挨打。
3. **最后 5 秒留下什么问题？** 一个问题，不是一个结论。
4. **本集能不能拆成 12-13 镜？** 不能，回 beats 重排。
5. **本集是否只有 1 个主场景、3 个主要角色、台词 70-80 字？** 不是，回 beats 重排。

五问写进剧本头部，写完回查是否兑现。

## AI 可生成约束

| 项 | 标准 |
|:--|:--|
| 本集主场景 | 1 个（最多 2 个） |
| 本集主要角色 | 3 个（最多 4 个） |
| 本集镜头 | 12-13 镜（10-14 可接受） |
| 单镜动作 | 1 个 |
| 单句台词 | ≤12 字 |
| 本集台词总量 | 70-80 字 |
| 禁止 | 奔跑、打斗、快速转身、多人互动、crowd、儿童正脸、动物特写、大范围水/火/烟 |

**写剧本时就要按镜头想**：一场戏里如果一次写了三个动作，shotintent 拆不出 12-13 镜，说明剧本阶段就超了。

详见 `<pop-drama-workbench 包根>/references/AI短剧生产约束.md`。

## 单集写作流程

### Step 1 拆场

按分集卡点表的场景列，把本集拆成 1-2 场（最多 2 场）。每场只干一件事。

**场次头格式**：

```
7-1 海底封印处 夜 外
人物：佩特拉、罗德里克、王子
```

- 场号：`集号-场号`。
- 地点、时间（日/夜/黄昏/清晨）、内/外。
- 人物行列出本场有台词或关键动作的人，最多 3 个主要角色。

### Step 2 排四拍

90 秒标准：

| 时间 | 拍 | 写什么 |
|:--|:--|:--|
| 0-15 秒 | 钩子 | 一个画面或一句冲突台词，直接开始 |
| 15-60 秒 | 升级 | 2-3 次交锋，每次抬高代价 |
| 60-80 秒 | 转折 | 主角做出改变局势的选择 |
| 80-90 秒 | 卡点 | 最后 5 秒留下问题 |

60 秒集：0-10 / 10-40 / 40-53 / 53-60。
120 秒集：0-15 / 15-75 / 75-108 / 108-120。

**顺序纪律**：先写卡点，再写钩子，最后填中间。

### Step 3 写动作行

动作行以 `△` 开头，只写镜头能拍到的：

- 谁做了什么动作。
- 什么道具出现了。
- 环境发生了什么变化。
- 人物表情或身体状态（外部可见）。

**合格**：

```
△ 她把手机摔在桌上，屏幕裂了一道纹。
△ 罗德里克拔剑，横在佩特拉身前。
△ 门缝下渗进来的水，漫过她的鞋尖。
```

**不合格**：

```
△ 她心里一阵刺痛。（拍不到）
△ 他意识到自己被骗了。（拍不到）
△ 气氛变得尴尬。（拍不到）
```

**动作三条**：

1. 一个动作行只写一个动作，最多两个短句。
2. 关键情绪用道具承担。
3. 每 3-5 秒要有一个画面变化。

**镜头意识**：每 3-5 行动作/台词，应该能切成一个镜头。写的时候心里数：这一集够不够 12-13 个可切点。

### Step 4 写台词

**格式**：

```
角色（状态）：台词
角色（OS）：内心独白
角色（电话）：电话里的声音
```

**台词五条**：

1. 一句只干一件事：推进、暴露、反击。
2. 单句 ≤12 字；冲突句更短。
3. 用口语，不用书面语。
4. 不用台词解释观众已经看到的画面。
5. 能用一个动作替代的，不写台词。

**禁止**：

- 解释性台词：“其实我是因为小时候……”
- 总结性台词：“看来这一切都是他设计的。”
- 书面腔：“我对此感到十分失望。”
- 一句话塞两个信息点。

### Step 5 写字幕与标记

- 人物首次出场：`字幕：【身份 姓名】`。
- 时间地点跳转：`字幕：【三天后·北境】`。
- 画外音：`角色（OS）：…`，一集不超过 3 次。
- 闪回：`【闪回】` 标注进入与退出。
- 空镜：`△【空镜】…`。
- 卡点：`△【卡点】…`。

### Step 6 收尾检查

写完后逐项过 `templates/剧本自检表.tpl.md`，不过项就改。至少检查：

- [ ] 第一行是否有画面或冲突。
- [ ] 15 秒内是否讲清谁、要什么、谁挡着。
- [ ] 是否有主角主动做出的转折。
- [ ] 最后 5 秒是否是一个问题。
- [ ] 是否出现心理描写词（心想、感到、意识到、回忆起）。
- [ ] 场景是否 ≤2，主要角色是否 ≤3。
- [ ] 台词是否 70-80 字，单句是否 ≤12 字。
- [ ] 是否能切成 12-13 镜，且每镜一个动作。
- [ ] 卡点类型是否与上一集不同。
- [ ] 本集是否推进了钩子台账至少一条线。

## 批量写法（3 集一组）

1. 读本组 3 集的分集卡点表行、预算表与前 10 集节拍。
2. 一次写完 3 集，保持三集卡点类型不同。
3. 三集写完，统一做台词朗读检查与镜头切点检查。
4. 交 review，按意见改。
5. PASS 后更新 `00-创作总表.md`，写下一组。

**禁止**：一次生成 10 集以上不审。

---

## 全剧合订本与台词统计

全部集 PASS 后：

1. 写 `06-剧本/全剧剧本.md`：封面、故事梗概、人物表、分集目录、全剧正文、每集台词字数。
2. 写 `06-剧本/台词统计.md`：每集字数、预估语音秒数、最长单句、总量、超时风险、配音角色表。

合订本只做阅读与审批；分镜以 `06-剧本/分镜/` 为准。

---

## 分镜与审稿

- 分镜：剧本 PASS 后，交 `pop-drama-shotintent`，输出 `06-剧本/分镜/EP{NNN}.md`。工作台上它是剧本的子页，不是一级阶段。
- 审稿：交 `pop-drama-review`，输出 `06-剧本/审稿/EP{NNN}-审稿.md`。

**不要**在剧本里写首帧 prompt 或运动指令。

## 常见问题与改法

| 问题 | 表现 | 改法 |
|:--|:--|:--|
| 开头像小说 | 第一场在交代背景 | 把本集最激烈的冲突提到第一场 |
| 中段塌 | 15-60 秒只有对话 | 每 15 秒加一次代价抬升或新事实 |
| 转折太晚 | 60-80 秒才开始动 | 把转折提到 55-60 秒 |
| 卡点弱 | 最后是情绪或结论 | 改成四型中的一种 |
| 台词太长 | 一句超过 12 字 | 拆成两句，或删解释 |
| 人物声音一样 | 遮住名字认不出 | 按语言指纹重写 |
| 场景太贵 | 一集 3 场、外景加群演 | 合并同地点 |
| 信息靠说 | 角色互相解释设定 | 改成道具、字幕或动作 |
| 镜头切不开 | 一集只有 6-8 个动作点 | 加交锋、加反应、加道具特写 |
| 镜头太多 | 一集 18 个动作点 | 砍线、合并动作、拆集 |
