# 剧本格式规范

> 全剧统一格式。格式不统一，剧组要重新排版，review 也无法逐项检查。

---

## 一、文件结构

一集一个文件，`剧本/EP001.md`。文件从上到下固定六块：

```
# EP001

## 本集信息
冲突：
转折：
卡点：
场景数：
人物数：

## 场次
1-1 地点 时间 内/外
人物：A、B、C
△ …
A（状态）：…
△【卡点】…

## 本集检查
- [ ] …
```

- `本集信息` 是给 review 与自己回查用的，不进成片。
- `场次` 是正文，交剧组。
- `本集检查` 勾完即删或保留均可，项目内统一。

---

## 二、场次头

格式：

```
{集号}-{场号} {地点} {时间} {内/外}
```

| 字段 | 取值 | 例 |
|:--|:--|:--|
| 集号 | 三位数 | 007 |
| 场号 | 从 1 起 | 7-1 |
| 地点 | 剧中叫法，与场景库一致 | 海底封印处 |
| 时间 | 日 / 夜 / 黄昏 / 清晨 / 深夜 | 夜 |
| 内外 | 内 / 外 / 内/外 | 外 |

**写法要求**：

- 地点名必须能在 `舞台库/场景库.md` 找到；现编地点要回填场景库。
- 同集场号连续，不跳号。
- 一个场次头只对应一个地点、一个时间。

---

## 三、人物行

```
人物：佩特拉、罗德里克、王子
```

- 只列本场有台词或关键动作的人。
- 群众用 `群演` 或具体身份（`守卫甲`、`侍女`），不写"众人"。
- 首次出场的人物，在第一次说话前加字幕：

```
字幕：【学生会会长 佩特拉】
```

---

## 四、动作行

以 `△` 开头。一个动作行只写一个可拍的动作或画面。

```
△ 罗德里克翻身而起，从白骨堆里拔出一柄重剑。
△ 剑身覆满暗红血锈。
△ 触手砸下，石柱碎成骨粉。
```

**允许写**：

- 动作、走位、表情、身体状态。
- 道具、服装、环境。
- 声音、光线、天气。
- 镜头能拍到的细节（手抖、指节发白、鞋尖浸水）。

**禁止写**：

- 心理活动：心想、感到、意识到、回忆起、内心翻江倒海。
- 无法拍的判断：气氛尴尬、关系微妙、大家都震惊了。
- 导演级指令：用 35mm 镜头、推轨、升格。需要时另写镜头提示，不混在动作行。

---

## 五、台词

格式：

```
角色（状态）：台词
```

| 状态写法 | 用途 | 例 |
|:--|:--|:--|
| （冷笑） | 表情或语气 | 佩特拉（冷笑）：海底垃圾分类都拒收你。 |
| （压低声音） | 音量 | 罗德里克（压低声音）：外面有人。 |
| （OS） | 内心独白 | 海伦娜（OS）：这里的规则只有一条。 |
| （电话） | 电话或广播 | 律师（电话）：遗嘱现在宣读。 |
| （画外） | 人不在画面内 | 母亲（画外）：别回来。 |

**台词规则**：

- 一句话一个功能。
- 单句 ≤12 字为佳，最长不超过 15 字（AI 生成模式）。
- 不用括号写心理，只写能演出来的状态。
- 同一角色连续台词超过 3 句，中间加动作行或对方反应。

---

## 六、特殊标记

| 标记 | 写法 | 用途 |
|:--|:--|:--|
| 卡点 | `△【卡点】…` | 本集最后一个画面或问题 |
| 闪回 | `【闪回】` / `【闪回结束】` | 进入与退出过去时空 |
| 空镜 | `△【空镜】…` | 只拍环境，用于过渡 |
| 字幕 | `字幕：【内容】` | 人物身份、时间、地点 |
| 匹配剪辑 | `【匹配剪辑】` | 两个画面形状相接 |
| 转场 | `【切】` / `【淡出】` | 明确需要时写，默认硬切不写 |

**标记纪律**：

- 一个标记只表达一件事。
- 标记用中文全角括号，与正文区分。
- 项目内标记体系统一，不混用英文 `CUT TO`、`FADE IN`。

---

## 七、一集的标准长度

| 成片时长 | 剧本字数 | 场数（AI 模式） | 主要角色 |
|:--|--:|--:|--:|
| 60 秒 | 600-800 | 1-2 | 2-3 |
| 75-80 秒 | 800-1200 | 1-2 | 3 |
| 90 秒 | 800-1200 | 1-2 | 3 |
| 120 秒 | 1200-1900 | 1-2 | 3-4 |

> 真人拍摄可放宽到 3 场；AI 生成模式按 1 主场景、最多 2 场执行。

字数含动作行、台词、标记，不含本集信息与检查表。

**超出怎么办**：

- 超过上限 20%：先删解释性台词，再合并同地点场次。
- 不足下限：检查是否漏了转折或升级拍，不要靠加废话补。

## 八、完整示例

```
# EP007

## 本集信息
冲突：佩特拉必须在救罗德里克和保住解药之间选一个。
转折：她故意被触手刺穿，借痛觉共享把罗德里克唤醒。
卡点：王子捏碎水晶瓶，毒雾吞没整个海沟。
场景数：2
人物数：3

## 场次

7-1 海底封印处 夜 外
人物：佩特拉、罗德里克、王子

△ 封印石柱炸裂，黑水从裂缝里喷出来。
△ 罗德里克被气浪掀翻，重剑脱手，落在三米外。
王子（狞笑）：十年了，你们是第一批走到这里的猎物。
佩特拉（盯着他胸口的水晶瓶）：你的力量在那瓶子里。
王子（脸色一变）：你怎么知道？
佩特拉（冷笑）：因为你一直在用左手护着它。

△ 王子挥出触手，缠住罗德里克的脚踝，把他拖向裂缝。
罗德里克（嘶吼）：别管我！拿解药走！
△ 佩特拉看向三米外的剑，又看向罗德里克。
△ 她扔掉手里的解药瓶，瓶子滚进裂缝。
王子（愣住）：你疯了？
佩特拉（拔出短刃）：我跟他绑着同一条命。

△ 触手刺穿她的左肩，血喷在罗德里克脸上。
罗德里克（猛然睁眼）：佩特拉！
佩特拉（咬牙）：现在，砍它胸口。

△ 罗德里克扑向重剑。
△【卡点】王子捏碎胸口的水晶瓶，黑雾从瓶口喷出，瞬间吞没整个海沟。

## 本集检查
- [x] 第一行有画面
- [x] 15 秒内讲清冲突
- [x] 主角主动做出转折
- [x] 最后 5 秒是问题
- [x] 无心理描写
- [x] 场景 ≤2（AI 模式），主要角色 ≤3
- [x] 卡点类型与上集不同
```
