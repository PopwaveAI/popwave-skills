# 台词与动作写法

> 短剧剧本只有两种材料：镜头能拍到的动作，和演员能说出口的台词。除此之外都不写。

---

## 一、台词的四个功能

每句台词至少承担一个：

1. **推进**：让事情往前走（下命令、做决定、提条件）。
2. **暴露**：露出人物的欲望、秘密、立场。
3. **反击**：回应上一句，改变力量关系。
4. **定调**：用一句话让观众知道这场戏是什么性质。

一个功能都不承担的台词，删。

---

## 二、台词长度与节奏

| 项 | 标准 |
|:--|:--|
| 单句 | ≤12 字为佳，最长 15 字（AI 生成模式） |
| 一次发言 | ≤3 句，超过加动作或对方反应 |
| 交锋回合 | 每 15 秒至少 2 个回合 |
| 解释性台词 | 一集不超过 2 处，每处不超过 2 句 |

**念一遍测试**：大声念，卡气、拗口、像文章，就改。

---

## 三、六种有力台词

### 1. 反问

不直接回答，把压力推回去。

> "你确定要我把话说明白？"

### 2. 打断

用短句切断对方，制造压迫。

> "闭嘴。听。"

### 3. 重复

重复对方的话，逼他面对。

> "你说你爱我。你再说一遍。"

### 4. 条件

把关系变成交易，暴露利益。

> "我可以救他。你拿什么换？"

### 5. 具体数字

数字比形容词有力。

> "三千八百五十四美元。威胁另收费。"

### 6. 沉默 + 动作

不说话，用动作回答。

> △ 她看着他，把戒指放在桌上，转身走了。

---

## 四、潜台词

人物不说自己真正想的，观众从动作和上下文补出来。

**直白写法**：

> 女：我很伤心，你背叛了我。

**潜台词写法**：

> 女：这杯咖啡，你以前不加糖。
> 男：人都会变。
> △ 她把糖罐推到他面前，盖子没开。

**判据**：台词如果已经把情绪说尽，动作就多余；台词留白，动作才有事干。

---

## 五、信息交付

设定、身份、前史，优先用这四种方式，不靠角色互相解释：

| 方式 | 写法 | 例 |
|:--|:--|:--|
| 字幕 | `字幕：【身份 姓名】` | 首次出场交代身份 |
| 道具 | 一份文件、一张照片、一枚徽章 | 遗嘱上写着名字 |
| 动作 | 一个只有内行才懂的动作 | 他进门先看三个出口 |
| 一句行话 | 行业词，不解释 | "按老规矩，三七分。" |

**最差的方式**：两个角色站在那儿互相讲设定。

## 六、动作行写法

### 公式

> 人物 + 可拍动作 + 具体对象

**合格**：

```
△ 她把手机摔在桌上。
△ 屏幕裂了一道纹。
△ 他拔剑，横在她身前。
△ 门缝下的水漫过她的鞋尖。
```

**不合格**：

```
△ 她感到一阵愤怒。（心理）
△ 气氛凝固了。（不可拍）
△ 他决定不再忍了。（决定不可拍，要写他做了什么）
```

### 用道具承担情绪

| 情绪 | 可拍动作 |
|:--|:--|
| 愤怒 | 捏碎杯子、掀桌、把钥匙砸在对方脸上 |
| 恐惧 | 手抖、后退半步、抓住门框 |
| 隐忍 | 指节发白、把话咽回去、慢慢放下杯子 |
| 决绝 | 摘下戒指、剪断头发、把门反锁 |
| 心虚 | 避开眼神、把手机翻面、清了清嗓子 |

### 环境承担信息

- 水渍、灰尘、空椅子、没关的灯，都能说明"这里发生过什么"。
- 一场戏开头先给一个环境细节，比旁白有效。

## 七、竖屏构图约束

- 画面 9:16，宽度有限，两个人并排站会挤。
- 双人对话用近景、过肩、前后站位，不用并排。
- 关键道具给特写，放在画面中部安全区。
- 一场戏里人物不超过 3 个同时入画，多了观众看不清脸。

**写法**：

```
△ 佩特拉站在前，罗德里克在她身后半步，剑尖越过她肩膀。
```

不写：

```
△ 两人并肩站在海边。
```

---

## 八、节奏控制

- 每 3-5 秒一次画面变化：切、推、拉、换景、人物进出。
- 每 15 秒至少一次信息增量或力量变化。
- 一集至少一次"停顿"：全场安静一拍，让观众反应。
- 高潮前先压：把台词变短，把动作放慢，再爆。

---

## 九、小说句改剧本句

| 小说原文 | 剧本写法 |
|:--|:--|
| 她心里翻江倒海，却强装镇定。 | △ 她把手伸进包里，握住那瓶喷雾，指节发白。 |
| 他意识到自己被最信任的人骗了。 | △ 他低头看那份文件，签名是他自己的。 |
| 气氛一时有些尴尬。 | △ 两个人都不说话。服务员过来问要不要加水。 |
| 她回忆起三年前的那个雨夜。 | 【闪回】△ 雨夜。她站在同一扇门前，手里攥着同一把钥匙。【闪回结束】 |
| 他终于下定决心。 | △ 他把辞职信放在桌上，转身就走。 |
| 她美丽得让人窒息。 | △ 她推门进来。全场安静。一个杯子从桌上滑落。 |

## 十、禁写清单

| 禁写 | 原因 | 改成 |
|:--|:--|:--|
| 心想、感到、意识到、回忆起 | 拍不到 | 动作、道具、OS |
| 气氛、关系、气场等抽象判断 | 拍不到 | 具体动作或环境 |
| "与此同时"、"转眼间"、"不知不觉" | 叙述腔 | 字幕或直接切场 |
| "她知道，从这一刻起……" | 小说旁白 | 删，或改成一句台词 |
| "所有人震惊了" | 群体反应不可拍 | 给一个具体人的具体反应 |
| "经过一番激烈的战斗" | 概述 | 写三个具体动作 |
| "他冷笑一声，说道" | 文白夹杂 | `他（冷笑）：…` |
| 一句台词两个信息点 | 信息过载 | 拆成两句 |

---

## 十一、写完后的三遍检查

1. **遮名字读台词**：能否认出谁在说。认不出，按语言指纹重写。
2. **遮台词读动作**：只看 △ 行，能否看懂发生了什么。看不懂，动作没写清。
3. **静音看画面**：把台词全删，只看动作与道具，冲突是否仍然成立。不成立，说明戏全靠嘴说。
