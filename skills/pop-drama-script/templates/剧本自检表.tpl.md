# 剧本自检表

> 每集写完逐项过。任何一项"否"，先改再交 review。

---

## 一、开头

| 检查项 | 判据 | 是/否 |
|:--|:--|:--|
| 第一行是画面或冲突 | 不是背景、天气、旁白 |  |
| 前 3 秒有视觉钩子 | 一张脸、一个动作、一件道具 |  |
| 15 秒内讲清谁、要什么、谁挡着 | 遮住后面内容也能懂 |  |
| 没有前情提要 | 不靠字幕或旁白补前集 |  |

## 二、中段

| 检查项 | 判据 | 是/否 |
|:--|:--|:--|
| 每 15 秒有新信息或代价抬升 | 找不到连续 15 秒只聊天 |  |
| 交锋至少 2 个回合 | 有来有回，不是单方面输出 |  |
| 主角不是全程被动 | 至少主动做一次选择 |  |
| 场景 ≤3 | 数场次头 |  |
| 有台词人物 ≤5 | 数人物行 |  |

## 三、转折与卡点

| 检查项 | 判据 | 是/否 |
|:--|:--|:--|
| 转折在 55-80 秒区间 | 不是最后一秒才动 |  |
| 转折是主角做的 | 不是别人替她做 |  |
| 最后 5 秒是一个问题 | 不能已经回答完 |  |
| 卡点类型与上集不同 | 对照钩子台账 |  |
| 本集卡点与下集开头成对 | 反应留给下集 |  |

## 四、台词

| 检查项 | 判据 | 是/否 |
|:--|:--|:--|
| 单句 ≤30 字 | 逐句数 |  |
| 没有解释性长台词 | 一集不超过 2 处 |  |
| 遮住名字能认出人物 | 按语言指纹核对 |  |
| 念一遍不拗口 | 大声读 |  |
| 没有"心想/感到/意识到" | 搜索关键词 |  |

## 五、动作与画面

| 检查项 | 判据 | 是/否 |
|:--|:--|:--|
| 动作行全部以 △ 开头 | 逐行看 |  |

| 每 3-5 秒有画面变化 | 无超过 3 行的静态描述 |  |
| 竖屏构图可拍 | 不同时并排站 3 人 |  |

## 六、连续性与台账

| 推进了钩子台账至少一条线 | 台账已更新 |  |
