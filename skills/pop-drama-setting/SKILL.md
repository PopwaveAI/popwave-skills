# pop-drama-setting

> 短剧设定库模块。当前版本 v1.0.0（2026-10-19：从 story 拆出，设定独立成库）。
> 产出：设定库八份。本模块建的是可被分集、人物、剧本、分镜反复引用的设定库，不是一份设定文档。

---

## 本模块负责什么

| 产出 | 内容 |
|:--|:--|
| `03-设定/故事核.md` | 一句话、梗概、主题、情感契约、核心信息差、结局、20 个冲突源 |
| `03-设定/世界与规则.md` | 时代、地域、社会结构、题材机制、权力规则、禁忌、时间线 |
| `03-设定/视觉风格.md` | 色彩脚本、光线、镜头语言、构图、参考 moodboard、重复符号 |
| `03-设定/场景库.md` | 场景 ID、空间结构、光线、空景锚点、复用规则 |
| `03-设定/道具与服装.md` | 关键道具、服装变化、造型、连续性 |
| `03-设定/声音基调.md` | 配乐风格、音效基调、静默使用、主题旋律 |
| `03-设定/合规红线.md` | 平台禁忌、暴力/血腥/性暗示/未成年人/敏感身份边界 |
| `03-设定/语言风格.md` | 台词规则、旁白规则、禁用词、语言指纹总则 |

**边界**：

- 人物卡归 `pop-drama-character`。
- 分集归 `pop-drama-beats`。
- 剧本归 `pop-drama-script`。
- 本模块不写人物小传、不排分集、不写台词。

**它可以单独调用**：用户只想补世界规则、只想做场景库、只想定视觉风格，都可以只做其中一份。

## AI 可生成性约束（先读）

| 项 | 标准 |
|:--|:--|
| 单集主场景 | 1 个；全剧主场景 ≤8 |
| 单集主要角色 | 3 个（人物库负责） |
| 单集镜头 | 12-13 镜 |
| 单镜动作 | 1 个 |
| 禁止 | 奔跑、打斗、快速转身、多人互动、大 crowd、儿童正脸、动物特写、大范围水/火/烟 |

设定阶段就要为可生成性负责：世界规则不要依赖大场面，视觉风格不要依赖复杂特效，场景库要能复用。

详见 `<pop-drama-workbench 包根>/references/AI短剧生产约束.md`。

## 操作步骤

### Step 0 读输入

- `01-市场定位.md`：平台、受众、题材、生产模式、集数、时长、卖点。
- `02-对标拆解.md`（若有）：可复用招式与避坑。
- `00-创作总表.md`：已确认的关键决定。

缺市场定位时，先问三项：平台与受众、集数与时长、生产模式。不硬写。

### Step 1 故事核

写六样：

1. **一句话故事**：谁，因为什么，要什么，谁挡着，代价是什么。≤60 字。
2. **故事梗概**：300 字以内，按"开局—升级—崩塌—收束"四段写。
3. **主题与母题**：一句话主题；3-5 个重复意象。
4. **情感契约**："一个______的人，能不能______一个______的人？"
5. **核心信息差**：类型、观众知道什么、剧中人不知道什么、三次揭示节点。
6. **结局画面**：谁站在哪里、谁对谁做了什么、最后一个镜头看到什么。

再列 **20 个冲突源**：每条写谁和谁、触发条件、可变成第几集。至少 12 条能在 1 场景 3 角色内完成。

**判据**：一句话能 15 秒讲清；结局能回扣第 1 集；冲突源能撑满总集数。

### Step 2 世界与规则

写七样：

1. **时代与地域**：什么年代、什么地方、什么季节。
2. **社会结构**：阶层、权力、家族、组织。
3. **题材机制**：本题材的核心规则（狼群等级、契约婚姻条款、继承试炼规则、复仇链条等）。
4. **规则边界**：什么能做、什么不能做、违反的代价。
5. **禁忌**：人物不能碰的东西，碰了会触发什么。
6. **时间线**：开局前发生了什么、剧中时间跨度。
7. **可生成性**：哪些规则需要大场面，哪些可以用对话/道具/局部替代。

**判据**：规则能直接制造冲突；不依赖旁白解释；不出现"设定很宏大但拍不出来"。

### Step 3 视觉风格

写六样：

1. **色彩脚本**：开局、转折、结局三个阶段的主色与情绪。
2. **光线**：主光方向、色温、明暗对比、夜景/日景比例。
3. **镜头语言**：常用景别、运镜、构图；竖屏 9:16 的安全区。
4. **参考 moodboard**：3-5 个参考方向，只写"参考什么"，不抄具体作品。
5. **重复符号**：3-5 个（镜子、钥匙、红色、雨），各对应一个主题。
6. **特效边界**：需要什么特效、出现在哪几集、复杂度、预算。

**判据**：两个场景/两种光线能区分阶段；特效不超过预算；关键信息在竖屏中部安全区。

### Step 4 场景库

全剧主场景 ≤8；单集 1 个主场景（最多 2 个）；核心复用 3-4 个。

每个场景十项：

| 项 | 内容 |
|:--|:--|
| 场景 ID | S1 / S2… |
| 场景名 | 剧中叫法 + 拍摄类型 |
| 空间结构 | 面积、门窗、家具、地面材质 |
| 谁的地盘 | 归属哪个势力/人物 |
| 谁能进 | 进入条件 |
| 主用途 | 谈条件/撕破脸/藏秘密/权力展示 |
| 光线 | 光源位置、方向、色温 |
| 视觉符号 | 一眼能认出的东西 |
| 空景锚点 | 空间、结构、光线、色温、材质、关键道具 |
| 可复用道具 | 至少一件 |

**空景锚点例**：

> 约 30 平米中式老宅堂屋，正中长条木桌，两支红烛在桌中偏左，两侧木格窗，后方低门框木门，青砖地面有灰，唯一光源是红烛 1900K 暖光，门缝渗入 7000K 冷光。

**判据**：两个场景能否互相替代；能替代的合并；单集需要 3 个以上场景的，回故事核改写法。

### Step 5 道具与服装

**关键道具**：每个主要人物至少一件固定道具；每个道具写首次出现、作用、连续性。

**服装**：每个主要人物三套（日常/正式/关键场次）；写颜色、材质、变化节点；与视觉锚点一致。

**判据**：道具能承担情绪或信息；服装变化能标记人物阶段；B 组能据此锁资产。

### Step 6 声音基调

写四样：

1. **配乐风格**：题材、节奏、情绪曲线。
2. **音效基调**：环境音、动作音、惊吓音的使用规则。
3. **静默使用**：什么时候刻意无声。
4. **主题旋律**：是否有固定动机，出现在哪些节点。

**判据**：声音能补画面不能说的信息；不靠音乐硬煽。

### Step 7 合规红线

逐项写边界与处理：

| 项 | 边界 | 处理 |
|:--|:--|:--|
| 暴力 |  |  |
| 血腥 |  |  |
| 性暗示 |  |  |
| 未成年人 |  |  |
| 敏感身份 |  |  |
| 真实人物 |  |  |
| 迷信导向 |  |  |
| 平台规则 |  |  |

**判据**：命中任一项，先改设定，不留到剧本阶段。

### Step 8 语言风格

写五样：

1. **台词总则**：单句 ≤12 字、口语、一句一件事。
2. **旁白规则**：什么时候用、每集上限、由谁说。
3. **语言指纹总则**：短刀型/绕弯型/书面型/沉默型四类，人物具体分配归 character。
4. **禁用词**：AI 腔、书面腔、解释性台词。
5. **字幕规则**：人物首次出场、时间地点跳转、闪回标记。

**判据**：遮住名字能认出说话人；念一遍不拗口；没有解释性长台词。

### Step 9 交付检查

- [ ] 八份文件齐全。
- [ ] 一句话 ≤60 字，含主角、目标、阻碍、赌注。
- [ ] 20 个冲突源，≥12 条能在 1 场景 3 角色内完成。
- [ ] 世界规则能直接制造冲突，不依赖大场面。
- [ ] 视觉风格有色彩脚本、光线、镜头语言、重复符号。
- [ ] 场景 ≤8，单集 1 主场景，每个场景有空景锚点。
- [ ] 关键道具与服装三套齐全。
- [ ] 声音基调四样齐全。
- [ ] 合规八项有边界与处理。
- [ ] 语言风格五样齐全。
- [ ] B 组能据此锁场景、道具、视觉风格。

通过后写八份文件，更新 `00-创作总表.md` 的模块就绪。
