## 二、题材专项

### 民俗 / 悬疑

- [ ] 灵异感最终落到"人在装神弄鬼"或现实解释。
- [ ] 不出现封建迷信操作教程。
- [ ] 不出现恐怖化妆、鬼脸、jump scare。
- [ ] 负面锁排除 gore / blood / horror makeup。

### 末世 / 灾变

- [ ] 不出现怪物正脸、僵尸、啃食。
- [ ] 不出现武器特写与血腥。
- [ ] 末日感靠环境、光线、声音，不靠尸体。

### 甜宠 / 萌宝

- [ ] 儿童不露正脸或只给局部。
- [ ] 亲密戏不越界。
- [ ] 不出现成人向暗示。

### 复仇 / 逆袭

- [ ] 暴力复仇不展示细节。
- [ ] 不美化违法手段。
- [ ] 结局有代价或边界。
