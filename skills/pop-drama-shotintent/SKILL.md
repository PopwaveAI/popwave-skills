# pop-drama-shotintent

> 短剧分镜子页。当前版本 v2.0.0（2026-10-19：收为剧本子页，不再是独立一级）。
> 本模块把审稿通过的剧本，拆成 12-13 镜、一镜一动作、可交给 AI 制作组的分镜表。

---

## 本模块负责什么

| 项 | 内容 |
|:--|:--|
| 层级 | 剧本子页，不是一级阶段 |
| 输入 | `06-剧本/EP{NNN}.md`、`05-分集/分集卡点表.md` 本集行、`04-人物/`、`03-设定/场景库.md` |
| 输出 | `06-剧本/分镜/EP{NNN}.md`、`06-剧本/分镜/全剧分镜表.md` |
| 下游 | B 组据此写首帧 prompt、运动指令、参考图与模型参数 |

**边界**：

- 不写首帧 prompt、不写英文提示词、不写运动指令、不写模型参数。那些归 B 组。
- 不写故事、不改台词、不改分集卡点。发现故事问题，回 setting 或 beats。
- 只写“观众看到什么、听到什么、这一镜是什么情绪、有什么生成风险”。

**执行方式**：主 agent 直接执行。一次拆一集；全剧拆完后合并成总表。

---

## 硬约束

| 项 | 标准 |
|:--|:--|
| 单集镜头数 | 12-13 镜；10-14 可接受；少于 10 或多于 15 退回 |
| 单镜时长 | 3-8 秒；4-5 秒最稳 |
| 单集总时长 | 75-80 秒 |
| 主场景 | 1 个 |
| 主要角色 | 3 个 |
| 单镜动作 | 1 个 |
| 单句台词 | ≤12 字 |
| 单集台词总量 | 70-80 字 |
| 心理活动 | 转旁白/字幕，不进画面 |

**不允许写进画面的动作**：奔跑、打斗、快速转身、多人互动、大范围移动、crowd、动物、儿童、水/火/烟（除非在风险列显式标注并给替代方案）。

## 操作步骤

### Step 0 前置检查

- 本集剧本是否已通过审稿？没有，先走 `pop-drama-review`。
- 本集是否只有 1 个主场景、3 个主要角色？不是，回 setting 或 beats。
- 本集分集卡点是否明确？没有，回 beats。

### Step 1 拆镜

按剧本的场次与动作，把一集拆成 12-13 镜。

**拆镜五条**：

1. **一镜一动作**：一个镜头只写一件事。要三件事，拆三镜。
2. **每镜必须有变化**：新信息、权力变化、情绪转折、威胁出现，至少占一个。只是“走过来”的镜头，删。
3. **首镜给钩子**：0-4 秒，一个画面或一句旁白，直接抛冲突。
4. **末镜给卡点**：5-8 秒，留下一个观众答不出的问题。
5. **时长先定**：先给每镜 3-8 秒，合计 75-80 秒；超了就砍镜或压时长，不靠加快动作。

**拆镜判据**：把每镜写成“谁 + 做了什么 + 结果”一句话。写不出，拆错或该删。

### Step 2 填 12 字段

| 字段 | 写法 | 例 |
|:--|:--|:--|
| 镜号 | 集号-镜号 | 03-01 |
| 时长 | 秒 | 4s |
| 景别 | 大特写/特写/近景/中景/全景/远景 | 大特写 |
| 运镜 | 固定/推/拉/摇/移/跟/手持 | 固定 |
| 画面 | 中文，只写一个动作，看得见 | 一双红色绣花鞋停在门槛外 |
| 台词/旁白 | ≤12 字，或写“无” | 旁白：进村先记三条规矩 |
| 情绪 | 一个词 | 悬 |
| 出场角色 | 角色 ID + 名字 | A3 新娘 |
| 场景 | 场景 ID | S1 堂屋 |
| 关键道具 | 本镜必须出现的道具 | 绣花鞋 |
| 生成风险 | 本镜最容易崩的点 | 鞋面细节糊、裙摆穿模 |
| 备注 | 给 B 组的表演/构图提示 | 越静止越毛，不要加风 |

**画面写法**：

- 写“瞬间”，不写“过程”。
- 写“看得见的东西”：动作、道具、光线、表情、身体状态。
- 不写心理：`她心里一沉`，改成 `她手指收紧，纸被捏皱`。

### Step 3 AI 可生成性检查

逐镜检查：

- [ ] 这一镜只有一个动作。
- [ ] 没有奔跑、打斗、快速转身、多人互动。
- [ ] 没有大范围移动或复杂运镜。
- [ ] 没有 crowd、动物、儿童、水/火/烟（或已标风险并给替代方案）。
- [ ] 台词 ≤12 字。
- [ ] 画面不需要模型“理解关系”，只需要生成一个瞬间。
- [ ] 角色/场景都有 ID，B 组能挂参考图。

不合格的镜，先改画面；改不了，标风险并给 fallback。

### Step 4 标风险

风险分五级：

| 级别 | 含义 | 处理 |
|:--|:--|:--|
| A | 必崩，换方案 | 改画面或删镜 |
| B | 高风险，需多抽 | 标抽卡次数与备选方案 |
| C | 中风险，注意即可 | 写备注 |
| D | 低风险 | 不标 |

**高风险清单**：

| 风险 | 典型镜头 | Fallback |
|:--|:--|:--|
| 正脸揭示 | 揭盖头、摘面具、转身正脸 | 只给眼睛/嘴/侧脸；或用影子、背影 |
| 手部互动 | 递东西、抓住手腕、按手机 | 只拍手部特写，不拍两个人同时入画 |
| 两人近距离 | 拥抱、扑倒、耳语 | 拆成两个单人镜，用反应镜头接 |
| 服装/盖头/长发 | 古装、婚纱、长发飘动 | 减少飘动，改成静止或微动 |
| 儿童/动物 | 抱婴儿、狗、猫 | 只给轮廓、局部或声音 |
| 水/火/烟 | 雨、烛火、烟雾 | 用光影和声音暗示，不拍大范围流体 |
| 人群 | 宴会、街头、战场 | 用两三个具体的人代替 crowd |
| 镜面/反射 | 镜子、手机屏幕、水面 | 不给镜中内容，只给光或模糊轮廓 |
| 文字/屏幕 | 手机消息、文件、字幕 | 后期加字，画面不生成文字 |

### Step 5 写交接摘要

每集末尾写五句，给 B 组：

- 本集镜头数、总时长。
- 角色 ID 与场景 ID 清单。
- 高风险镜列表（A/B 级）。
- 本集最稳的三镜。
- 本集必须保留的一个画面（删了故事就断）。

### Step 6 自检

- [ ] 12-13 镜（10-14 可接受）。
- [ ] 总时长 75-80 秒。
- [ ] 每镜一个动作。
- [ ] 每镜有变化。
- [ ] 首镜是钩子，末镜是卡点。
- [ ] 台词 ≤12 字，总量 70-80 字。
- [ ] 1 个主场景、3 个主要角色。
- [ ] 每个高风险镜都有 fallback。
- [ ] B 组拿到表，不需要再问“这一镜到底要什么”。

---

## 输出格式

每集一份 `06-剧本/分镜/EP{NNN}.md`，用 `templates/镜头意图表.tpl.md`。

全剧拆完后合并为 `06-剧本/分镜/全剧分镜表.md`，头部写全剧统计：

- 总集数、总镜头数、总时长。
- 每集镜头数分布。
- A/B 级风险镜总数与集数分布。
- 角色/场景复用统计。
