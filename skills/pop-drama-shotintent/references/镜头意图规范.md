# 镜头意图规范

> 本文件回答三件事：怎么把剧本拆成 12-13 镜、怎么判断一镜能不能生成、崩了怎么换。

---

## 一、拆镜的基本单位

**一镜 = 一个动作 + 一个变化。**

动作是"画面里发生了什么"，变化是"观众知道了什么、关系变了什么、危险近了什么"。

合格：

- 她把手机摔在桌上，屏幕裂了。（动作：摔；变化：关系破裂）
- 三爷的手从侧面按下手机。（动作：按；变化：规矩出现）
- 新娘的头极慢转向他。（动作：转头；变化：她不是死的）

不合格：

- 她走进房间，坐下，倒水，看手机。（四个动作，拆四镜）
- 两个人在房间里聊天。（没有具体动作）
- 她想起三年前。（拍不到，改旁白或闪回画面）

## 二、12-13 镜怎么分配

| 段落 | 镜数 | 任务 |
|:--|--:|:--|
| 钩子 | 1-2 镜 | 0-10 秒，抛出冲突或异常 |
| 升级 | 4-5 镜 | 每次交锋抬高代价 |
| 转折 | 2-3 镜 | 主角做出改变局势的选择 |
| 卡点 | 1-2 镜 | 最后 5-8 秒，留下问题 |

**时长分配**：

- 钩子镜 3-5 秒。
- 升级镜 4-6 秒。
- 转折镜 6-8 秒。
- 卡点镜 5-8 秒。
- 总时长 75-80 秒。

**如果只有 10 镜**：说明冲突不够，回 beats 加一次交锋。
**如果超过 15 镜**：说明一场戏塞了两件事，回 script 拆集或砍线。

## 三、画面写法

### 写瞬间，不写过程

| 不写 | 写 |
|:--|:--|
| 她走向门口 | 她站在门口，手放在门把上 |
| 他打了她一巴掌 | 她的脸偏向一侧，嘴角有血 |
| 两个人争吵 | 他把杯子砸在桌上，她后退半步 |
| 她回忆起过去 | 【闪回】雨夜，同一扇门，同一把钥匙 |

### 写看得见的东西

- 动作：手、脚、眼神、呼吸、转身、停住。
- 道具：手机、钥匙、红烛、白米、铜钱。
- 环境：门缝的光、灰尘、水渍、影子。
- 身体状态：指节发白、手抖、汗、眼泪、伤口。

### 不写

- 心理：心想、感到、意识到、回忆起。
- 抽象：气氛尴尬、关系微妙、 everybody shocked。
- 过程：奔跑、打斗、快速转身、多人互动。
- 模型无法理解的关系：她是他前世的妻子。

## 四、台词规则

- 单句 ≤12 字。
- 一镜一句，最多两句。
- 台词不追求口型同步，后期配音。
- 心理活动转旁白或字幕，不进画面。
- 一集台词总量 70-80 字，按每秒 4-5 字估算。

**例**：

- 旁白：进这个村，先记三条规矩。（13 字，偏长，可改"进村，先记三条规矩"）
- 三爷：别拿镜头照她。（7 字）
- 陈默：她被绑着。（5 字）
- 新娘：救我……（3 字）

## 五、风险判断

### A 级：必崩，换方案

| 镜头 | 为什么崩 | 换成 |
|:--|:--|:--|
| 正脸大特写 + 复杂表情 | 脸崩、表情不自然 | 只给眼睛/嘴/侧脸，或背影 |
| 两个人拥抱/扑倒 | 手臂穿模、身体融合 | 拆成两个单人反应镜 |
| 快速打斗 | 动作糊、肢体变形 | 只拍起手/落点/反应 |
| 大 crowd | 人脸重复、背景糊 | 用两三个具体的人 |
| 儿童正脸 | 脸崩、比例不对 | 只给手、背影、襁褓轮廓 |
| 动物特写 | 变形、多腿 | 只给影子、声音、局部 |

### B 级：高风险，多抽

| 镜头 | 风险 | 处理 |
|:--|:--|:--|
| 揭盖头/摘面具 | 脸和布料穿模 | 抽 8-12 版；只给局部 |
| 递东西/抓手 | 手指粘连 | 只拍手部特写，不拍两个人 |
| 古装转头 | 头饰/头发穿模 | 转头幅度小，抽 8 版 |
| 镜面/手机屏幕 | 反射内容乱 | 只给光，不给内容 |
| 烛火/雨/烟 | 流体不稳 | 小范围，靠光影 |
| 车辆/武器 | 结构变形 | 只给局部或声音 |

### C 级：注意即可

- 单人近景、固定机位、简单道具。
- 正常走路、坐下、开门。
- 静态场景的空镜。

---

## 六、Fallback 写法

每个 A/B 级风险镜，必须写一句"崩了怎么办"。

格式：

> 风险：揭盖头时脸和红布穿模。Fallback：只拍盖头落地 + 眼睛特写，不给完整正脸。

> 风险：两人近距离抓扯，手臂融合。Fallback：拆成"她伸手"和"他被推后退"两个单人镜。

> 风险：手机屏幕内容乱。Fallback：屏幕只给白光，内容后期贴。

---

## 七、单集交接摘要

每集末尾必须写：

| 项 | 内容 |
|:--|:--|
| 镜头数 | 12 |
| 总时长 | 76 秒 |
| 角色 ID | A1 陈默、A2 三爷、A3 新娘 |
| 场景 ID | S1 堂屋 |
| A 级风险 | 03-09 正脸揭示 |
| B 级风险 | 03-06 转头、03-08 两人抓扯 |
| 最稳三镜 | 03-01 绣花鞋、03-05 米粒、03-07 手腕 |
| 删了会断的一镜 | 03-09 揭盖头 |
