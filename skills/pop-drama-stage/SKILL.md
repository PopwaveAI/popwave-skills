# pop-drama-stage

> 短剧剧本线人物与舞台环节。当前版本 v1.0.0（2026-10-19：首版）。
> 本环节把立项稿里的功能位做成可选角、可拍摄、可写台词的人物与场景。

---

## 本环节负责什么

| 产出 | 内容 | 下游 |
|:--|:--|:--|
| `人物库/人物小传.md` | 每个主要人物的标签、欲望、阻碍、关系、弧光、语言指纹 | plot 排冲突、script 写台词 |
| `人物库/选角卡.md` | 年龄、外形、配色、服装、参考形象、道具 | 选角、美术、AI 出图 |
| `舞台库/场景库.md` | 主场景清单、每个场景的戏剧用途与视觉符号 | plot 排场次、script 写场次头 |
| `舞台库/视觉规则.md` | 色彩、构图、镜头、特效、重复符号 | 全剧统一视觉 |

**边界**：本环节不排剧情、不写台词、不写场次。人物只做到"能被人一眼认出、能被演员演出来"，不写完整前史。

**执行方式**：主 agent 直接执行。关键选择给选项，用户不在场时自定并标注。

## 操作步骤

### Step 0 读立项稿

读取 `立项/00-立项稿.md`，重点取六项：

- 市场与语言（决定人名、地名、阶层符号）
- 题材与主标签（决定人物原型）
- 人物功能位（主角、对手、见证者、引爆者）
- 预算等级（决定主场景数量）
- 核心信息差（决定谁知道什么）
- 结局画面（决定人物终点）

立项稿缺项时，先回 seed 补，不在本环节猜。

### Step 1 命名

**人名规则**：

- 海外剧用目标市场常见名，同一家族同姓；名字一眼能读对，不用生僻拼写。
- 国内剧用现代中文名，避免同音混淆；主要人物姓氏不同，方便观众区分。
- 每个名字写中英两版，英文名不是拼音直译时，标注重音。

**地名与机构名**：

- 只起剧中会反复出现的：主场景、公司/学校/家族、关键机构。
- 名字带功能：一听知道是医院、律所、庄园、警局，不造生词。

**判据**：把 6 个主要人物的名字念给没看过的人听，能不能一次记住并区分。记不住，改名。

### Step 2 人物小传

**人物数量上限**：

- 主要人物 5-8 个（含主角与对手）。
- 有台词配角不超过 5 个。
- 功能重复的合并：两个智囊不如一个智囊加一个执行者。

**每张卡必填十项**：

| 项 | 写法 | 判据 |
|:--|:--|:--|
| 功能位 | 推动者/阻挡者/见证者/引爆者 | 四选一，不混用 |
| 身份 | 职业、阶层、与主角的关系 | 一句话说清 |
| 核心标签 | ≤2 个 | 观众 3 秒能记住 |
| 欲望 | 本剧里具体要什么 | 能用动作演出来 |
| 阻碍 | 谁或什么不让他得到 | 与主角目标正面相撞 |
| 秘密 | 他知道什么、瞒着什么 | 与核心信息差挂钩 |
| 关系张力 | 与主角既合作又对抗的点 | 不能只是"好人/坏人" |
| 弧光 | 第 1 集是什么样，最后一集是什么样 | 两端各一个具体画面 |
| 语言指纹 | 句长、用词、口头禅、禁用词 | 去掉名字能认出是谁 |
| 行为习惯 | 一个反复出现的小动作或道具 | 可拍、可复用 |

**语言指纹四型**（每人选一主型）：

| 型 | 特征 | 例 |
|:--|:--|:--|
| 短刀型 | 句子短，常打断，少解释 | "说完了？滚。" |
| 绕弯型 | 爱反问、爱比喻、不直说 | "你确定要我把话说明白？" |
| 书面型 | 用词正式，爱讲条件 | "按协议，你没有资格。" |
| 沉默型 | 话少，用动作回应 | 不说话，把杯子推过去 |

**关系设计**：

- 主角与对手必须是一对镜像：同一欲望的不同解法，或同一伤口的不同反应。
- 每对重要关系写一句"既需要又对抗"的理由。写不出，关系是平的。
- 禁止用"天生坏"当对手动机；对手的行为要能从他的利益推出来。

### Step 3 选角卡

每个主要人物一张，六项：

| 项 | 内容 |
|:--|:--|
| 年龄感 | 实际年龄与视觉年龄分开写 |
| 外形 | 身高体态、发型、面部特征、一个记忆点 |
| 色彩 | 主色、辅色、禁用色；色彩随剧情怎么变 |
| 服装 | 日常、正式、关键场次三套；服装承担什么叙事功能 |
| 参考形象 | 2-3 个公开人物或剧照方向，只取气质，不抄经历 |
| 固定道具 | 一件反复出现的物件，承担身份或情感功能 |

**判据**：只看剪影和配色，能不能区分两个角色。不能，调整外形或主色。

### Step 4 场景库

**数量上限**：主场景 ≤8 个，其中反复使用的核心场景 3-4 个。

每个场景填七项：

| 项 | 内容 |
|:--|:--|
| 场景名 | 剧中叫法 + 拍摄类型（实景/棚拍/外景） |
| 谁的地盘 | 归属哪个势力或人物，决定谁能进出 |
| 戏剧用途 | 谈条件、撕破脸、藏秘密、权力展示，四选一主用途 |
| 视觉符号 | 一件一眼能认出的东西（吊灯、铁门、鱼缸、监控屏） |
| 进入门槛 | 谁能进、需要什么理由、被撞见会怎样 |
| 可复用道具 | 至少一件能在多集反复用的道具 |
| 出现集数 | 预估出现在哪些集，避免建了不用 |

**判据**：两个场景能不能互相替代。能替代的合并，不建重复场景。

**预算对齐**：

- 低预算：≤5 个主场景，其中 2 个可反复用；避免大规模外景与人群。
- 中预算：6-8 个主场景，可有 1 个奇观场景。
- 高预算：8 个以上，可有大场面与特效，但每集仍控制在 3 场内。

### Step 5 视觉规则

写五条，全剧统一：

1. **画幅与构图**：9:16 竖屏；关键信息放画面中部安全区；双人对话用近景与过肩，不并排站。
2. **色彩脚本**：按阶段变三次色（开局、转折、结局），每个阶段主色一个。
3. **镜头习惯**：每集至少一次特写道具或手部；每 3-5 秒一次画面变化（切、推、拉、换景）。
4. **特效边界**：只写预算能做的；大特效提前标集数，不能每集都有。
5. **重复符号**：3-5 个反复出现的视觉符号（镜子、钥匙、红色、雨），各自对应一个主题。

**判据**：把视觉规则交给摄影和美术，他们能不能直接排机位、定色。不能，写具体。

### Step 6 交付检查

逐项过：

- 主要人物是否都能用一句话说清"他是谁、要什么、挡谁的路"？
- 去掉名字，台词能否认出是谁？
- 对手的行为能否从他的利益推出来？
- 主场景是否 ≤8 个，且每个都有不可替代的用途？
- 色彩与重复符号是否服务剧情，而不是装饰？
- 预算等级与场景、特效是否对得上？

不过项，回对应步骤重做。通过后更新 `状态.md`，交 plot。
