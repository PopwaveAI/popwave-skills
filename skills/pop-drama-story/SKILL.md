# pop-drama-story

> 短剧故事核与人物模块。当前版本 v3.0.0（2026-10-19：整体重构——加入 AI 可生成性约束、人物视觉锚点、场景空景锚点）。
> 本模块把市场卖点做成能撑几十集、且 B 组能直接生成的故事、人物与场景。

---

## 本模块负责什么

| 产出 | 内容 |
|:--|:--|
| `03-故事核.md` | 一句话故事、情感契约、核心信息差与揭示节奏、结局画面、20 个冲突源 |
| `03-人物关系与人物卡.md` | 5-8 个主要人物、关系图、功能位、语言指纹、视觉锚点、禁用项 |
| `03-场景与视觉.md` | 主场景 ≤8、单集 1 主场景、空景锚点、视觉规则、色彩脚本、预算 |

**边界**：

- 不排每集写什么（归 beats）。
- 不写台词、不写场次（归 script）。
- 不写首帧 prompt（归 B 组）。

**它可以单独调用**：用户已有故事核，只想补人物；或只想定场景，都可以只做对应文件。

---

## AI 可生成性约束（先读）

本模块的所有产出都要服从 `pop-drama-workbench` 的生产约束：

| 项 | 标准 |
|:--|:--|
| 单集主场景 | 1 个；全剧主场景 ≤8 |
| 单集主要角色 | 3 个；全剧主要人物 5-8 个 |
| 单集镜头 | 12-13 镜 |
| 单镜动作 | 1 个 |
| 单句台词 | ≤12 字 |
| 禁止 | 奔跑、打斗、快速转身、多人互动、大 crowd、儿童正脸、动物特写、大范围水/火/烟 |

故事阶段就要按这个约束写。写到一半发现必须拍打斗或 crowd，回故事核换写法，不要留给 B 组硬扛。

详见 `<pop-drama-workbench 包根>/references/AI短剧生产约束.md`。

## 操作步骤

### Step 0 读输入

- `01-市场定位.md`：商业承诺、核心信息差、题材、集数、时长、预算、语言、生产模式。
- `02-对标拆解.md`（若有）：可复用招式与避坑。
- `00-创作总表.md`：已确认的关键决定。

缺市场定位时，先问三项：平台与受众、集数与时长、生产模式。不硬写。

### Step 1 写一句话故事

句式：

> 谁，因为什么，要什么，谁挡着，代价是什么。

三条要求：

1. ≤60 字。
2. 必须出现主角、目标、阻碍、赌注。
3. 不写设定名词堆砌，不写"在某个大陆上"。

**15 秒口述版**：说给没听过的人，三句话以内讲完。讲不清，重写。

**判据**：听的人能复述"谁、要什么、谁挡着、输了会怎样"。

### Step 2 写情感契约

一句话，写清观众为什么要看这两个人（或这场复仇）：

> "一个______的人，能不能______一个______的人？"

或：

> "看一个______的人，怎么______。"

判据：读出来有张力；换成任何两个路人也成立，就是没写具体。

### Step 3 定核心信息差与揭示节奏

| 项 | 内容 |
|:--|:--|
| 类型 | 身份型 / 局型 / 秘密型 / 未来型 |
| 观众知道什么 |  |
| 剧中人不知道什么 |  |
| 第一次险些揭穿 | 第__集 |
| 正面威胁（付费墙） | 第__集 |
| 真揭穿 | 第__集 |

**四条规则**：

1. 信息差要能用一句话说清。
2. 前 3 集至少给一次"险些被揭穿"。
3. 付费墙是第一次正面威胁，不是提前揭底。
4. 真揭穿放在中后段，揭完必须还有后果可写。

### Step 4 定结局画面

写成一个具体画面，不写"幸福生活"：

- 谁站在哪里。
- 谁对谁做了什么。
- 最后一个镜头看到什么。

**判据**：这个画面能回扣第 1 集的某个画面或道具；同时它必须是一个"单镜能拍"的画面。

### Step 5 列 20 个冲突源

按题材机制列，至少 20 条，每条一句话：

| # | 冲突源 | 谁和谁 | 触发条件 | 可变成第几集 |
|--:|:--|:--|:--|:--|
| 1 |  |  |  |  |
| … |  |  |  |  |

**题材机制参考**：

- 契约婚姻：每条条款是一次倒计时，每个见证人是一次闯入。
- 复仇：每揭开一层仇人，是一次揭露。
- 隐藏身份：每次险些被认出，是一次反转。
- 狼群权力：每次族群挑战，是一次权力翻面。
- 继承试炼：每条规则是一次选择，每次淘汰是一次揭露。

**判据**：20 条里至少有 12 条能直接变成某集的核心冲突，且每条都能在 1 个场景、3 个角色内完成。

### Step 6 建人物系统

**数量**：全剧主要人物 5-8 个；单集主要角色 3 个；有台词配角 ≤5 个；功能重复的合并。

**每个主要人物十二项**：

| 项 | 写法 |
|:--|:--|
| 角色 ID | A1 / A2 / A3…，全剧固定 |
| 功能位 | 推动者/阻挡者/见证者/引爆者 |
| 身份 | 职业、阶层、与主角关系，一句话 |
| 核心标签 | ≤2 个，观众 3 秒能记住 |
| 欲望 | 本剧里具体要什么，能用动作演 |
| 阻碍 | 谁或什么不让他得到 |
| 秘密 | 他知道什么、瞒着什么，与信息差挂钩 |
| 关系张力 | 与主角既合作又对抗的点 |
| 弧光 | 第 1 集与最后一集各一个具体画面 |
| 语言指纹 | 短刀型/绕弯型/书面型/沉默型，加口头禅与禁用词 |
| 行为习惯 | 一个反复出现的小动作或固定道具 |
| 视觉锚点 | 年龄、性别、脸型、发型发色、服装、标志特征、气质，七项写死 |

**视觉锚点写法**：

- 中文写，给 B 组翻译成英文 prompt。
- 七项齐全：年龄 / 性别 / 脸型 / 发型发色 / 服装（颜色材质）/ 标志特征（疤、痣、饰品）/ 气质。
- 写"稳定可见"的特征，不写"倾国倾城"这类无法生成的形容。
- 每个角色另写「禁用项」：不要胡须、不要眼镜、不要浓妆、不要换发型等。

**例**：

> A1 陈默：28 岁男性，瘦长脸，短黑发，黑色连帽户外夹克内搭灰 T 恤，单肩黑背包，目光平稳。禁用项：不要胡须、不要眼镜、不要登山杖。

**关系设计**：

- 主角与对手是镜像：同一欲望的不同解法，或同一伤口的不同反应。
- 每对重要关系写一句"既需要又对抗"的理由。
- 对手的行为必须能从他的利益推出来，不能靠"天生坏"。

**两个测试**：

1. 遮住名字读三句台词，能否认出是谁。
2. 只看视觉锚点，B 组能否生成同一个人的两张图。

### Step 7 定场景与视觉

**数量**：全剧主场景 ≤8；单集 1 个主场景（最多 2 个）；核心复用 3-4 个。

每个场景九项：

| 项 | 内容 |
|:--|:--|
| 场景 ID | S1 / S2 / S3…，全剧固定 |
| 场景名 | 剧中叫法 + 拍摄类型（实景/棚拍/外景） |
| 空间结构 | 面积、门窗位置、家具摆位、地面材质 |
| 谁的地盘 | 归属哪个势力或人物 |
| 戏剧用途 | 谈条件/撕破脸/藏秘密/权力展示，四选一主用途 |
| 光线 | 光源位置、方向、强弱、色温 |
| 视觉符号 | 一眼能认出的东西 |
| 空景锚点 | B 组生成空景图所需的稳定描述：空间、结构、光线、色温、材质、关键道具 |
| 可复用道具 | 至少一件 |
| 出现阶段 | 开局/中段/结局 |

**空景锚点写法**：

> 约 30 平米中式老宅堂屋，正中长条木桌，两支红烛在桌中偏左，两侧木格窗，后方低门框木门，青砖地面有灰，唯一光源是红烛 1900K 暖光，门缝渗入 7000K 冷光。

**视觉规则五条**：

1. 画幅 9:16；关键信息放画面中部安全区；双人对话用近景与过肩，不并排站。
2. 色彩脚本按阶段变三次（开局、转折、结局），每阶段一个主色。
3. 每集至少一次特写道具或手部；每 3-5 秒一次画面变化。
4. 特效只写预算能做的，提前标集数，不每集都有。
5. 重复符号 3-5 个（镜子、钥匙、红色、雨），各对应一个主题。

**判据**：两个场景能否互相替代。能替代的合并；单集需要 3 个以上场景的，回故事核改写法。

### Step 8 交付检查

- [ ] 一句话 ≤60 字，含主角、目标、阻碍、赌注。
- [ ] 15 秒口述版讲得清。
- [ ] 情感契约一句，有具体张力。
- [ ] 信息差四型可归类，三个揭示节点有集数。
- [ ] 结局是一个画面，能回扣第 1 集。
- [ ] 冲突源 ≥20 条，其中 ≥12 条能在 1 场景 3 角色内完成。
- [ ] 主要人物 5-8 个，每人十二项齐全。
- [ ] 每个主要人物有视觉锚点与禁用项。
- [ ] 遮名字能认出说话人。
- [ ] 主场景 ≤8，单集 1 个主场景。
- [ ] 每个场景有空景锚点。
- [ ] 视觉规则五条与预算对得上。

通过后写三份文件，更新 `00-创作总表.md` 的关键决定与文件索引。
