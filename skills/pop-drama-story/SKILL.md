# pop-drama-story

> 短剧故事核与人物模块。当前版本 v2.0.0（2026-10-19：合并原"立项"与"人物舞台"，按短剧实际做法重写）。
> 本模块把市场卖点做成能撑几十集的故事核、人物关系与可拍场景，不排分集、不写台词。

---

## 本模块负责什么

| 产出 | 内容 |
|:--|:--|
| `03-故事核.md` | 一句话故事、情感契约、核心信息差与揭示节奏、结局画面、20 个冲突源 |
| `03-人物关系与人物卡.md` | 5-8 个主要人物、关系图、功能位、语言指纹、选角信息 |
| `03-场景与视觉.md` | 主场景 ≤8、视觉规则、色彩脚本、重复符号、预算约束 |

**边界**：

- 不排每集写什么（归 beats）。
- 不写台词、不写场次（归 script）。
- 人物只写到"能演、能认、能推剧情"，不写完整前史。

**它可以单独调用**：用户已有故事核，只想补人物；或只想定场景，都可以只做对应文件。

## 操作步骤

### Step 0 读输入

- `01-市场定位.md`：商业承诺、核心信息差、题材、集数、时长、预算、语言。
- `02-对标拆解.md`（若有）：可复用招式与避坑。
- `00-创作总表.md`：已确认的关键决定。

缺市场定位时，先问三项：平台与受众、集数与时长、卖点一句话。不硬写。

### Step 1 写一句话故事

句式：

> 谁，因为什么，要什么，谁挡着，代价是什么。

三条要求：

1. ≤60 字。
2. 必须出现主角、目标、阻碍、赌注。
3. 不写设定名词堆砌，不写"在某个大陆上"。

**15 秒口述版**：说给没听过的人，三句话以内讲完。讲不清，回 Step 1 重写。

**判据**：听的人能复述"谁、要什么、谁挡着、输了会怎样"。

### Step 2 写情感契约

一句话，写清观众为什么要看这两个人（或这场复仇）：

> "一个______的人，能不能______一个______的人？"

或：

> "看一个______的人，怎么______。"

判据：读出来有张力；换成任何两个路人也成立，就是没写具体。

### Step 3 定核心信息差与揭示节奏

| 项 | 内容 |
|:--|:--|
| 类型 | 身份型 / 局型 / 秘密型 / 未来型 |
| 观众知道什么 |  |
| 剧中人不知道什么 |  |
| 第一次险些揭穿 | 第__集 |
| 正面威胁（付费墙） | 第__集 |
| 真揭穿 | 第__集 |

**四条规则**：

1. 信息差要能用一句话说清。
2. 前 3 集至少给一次"险些被揭穿"。
3. 付费墙是第一次正面威胁，不是提前揭底。
4. 真揭穿放在中后段，揭完必须还有后果可写。

### Step 4 定结局画面

写成一个具体画面，不写"幸福生活"：

- 谁站在哪里。
- 谁对谁做了什么。
- 最后一个镜头看到什么。

**判据**：这个画面能回扣第 1 集的某个画面或道具。

### Step 5 列 20 个冲突源

按题材机制列，至少 20 条，每条一句话：

| # | 冲突源 | 谁和谁 | 触发条件 |
|--:|:--|:--|:--|
| 1 |  |  |  |
| … |  |  |  |

**题材机制参考**：

- 契约婚姻：每条条款是一次倒计时，每个见证人是一次闯入。
- 复仇：每揭开一层仇人，是一次揭露。
- 隐藏身份：每次险些被认出，是一次反转。
- 狼群权力：每次族群挑战，是一次权力翻面。
- 继承试炼：每条规则是一次选择，每次淘汰是一次揭露。

**判据**：20 条里至少有 12 条能直接变成某集的核心冲突。少于 12 条，换机制或加一条关系线。

### Step 6 建人物系统

**数量上限**：主要人物 5-8 个；有台词配角 ≤5 个；功能重复的合并。

**每个主要人物十项**：

| 项 | 写法 |
|:--|:--|
| 功能位 | 推动者/阻挡者/见证者/引爆者，四选一 |
| 身份 | 职业、阶层、与主角关系，一句话 |
| 核心标签 | ≤2 个，观众 3 秒能记住 |
| 欲望 | 本剧里具体要什么，能用动作演 |
| 阻碍 | 谁或什么不让他得到 |
| 秘密 | 他知道什么、瞒着什么，与信息差挂钩 |
| 关系张力 | 与主角既合作又对抗的点 |
| 弧光 | 第 1 集与最后一集各一个具体画面 |
| 语言指纹 | 短刀型/绕弯型/书面型/沉默型，加口头禅与禁用词 |
| 行为习惯 | 一个反复出现的小动作或固定道具 |

**选角四项**（同卡填写）：年龄感、外形记忆点、主色与禁用色、服装三套（日常/正式/关键场次）。

**关系设计**：

- 主角与对手是镜像：同一欲望的不同解法，或同一伤口的不同反应。
- 每对重要关系写一句"既需要又对抗"的理由。
- 对手的行为必须能从他的利益推出来，不能靠"天生坏"。

**语言指纹四型**：

| 型 | 特征 | 例 |
|:--|:--|:--|
| 短刀型 | 句子短，常打断，少解释 | "说完了？滚。" |
| 绕弯型 | 爱反问、爱比喻、不直说 | "你确定要我把话说明白？" |
| 书面型 | 用词正式，爱讲条件 | "按协议，你没有资格。" |
| 沉默型 | 话少，用动作回应 | 不说话，把杯子推过去。 |

**两个测试**：

1. 遮住名字读三句台词，能否认出是谁。
2. 遮住人物卡，只看行为，能否推出他的欲望。

### Step 7 定场景与视觉

**主场景 ≤8 个**，核心复用 3-4 个。每个场景七项：

| 项 | 内容 |
|:--|:--|
| 场景名 | 剧中叫法 + 拍摄类型（实景/棚拍/外景） |
| 谁的地盘 | 归属哪个势力或人物 |
| 戏剧用途 | 谈条件/撕破脸/藏秘密/权力展示，四选一主用途 |
| 视觉符号 | 一眼能认出的东西 |
| 进入门槛 | 谁能进、被撞见会怎样 |
| 可复用道具 | 至少一件 |
| 出现阶段 | 开局/中段/结局，避免建了不用 |

**视觉规则五条**：

1. 画幅 9:16；关键信息放画面中部安全区；双人对话用近景与过肩，不并排站。
2. 色彩脚本按阶段变三次（开局、转折、结局），每阶段一个主色。
3. 每集至少一次特写道具或手部；每 3-5 秒一次画面变化。
4. 特效只写预算能做的，提前标集数，不每集都有。
5. 重复符号 3-5 个（镜子、钥匙、红色、雨），各对应一个主题。

**判据**：两个场景能否互相替代。能替代的合并。

### Step 8 交付检查

- [ ] 一句话 ≤60 字，含主角、目标、阻碍、赌注。
- [ ] 15 秒口述版讲得清。
- [ ] 情感契约一句，有具体张力。
- [ ] 信息差四型可归类，三个揭示节点有集数。
- [ ] 结局是一个画面，能回扣第 1 集。
- [ ] 冲突源 ≥20 条，其中 ≥12 条可变成单集冲突。
- [ ] 主要人物 5-8 个，每人十项齐全。
- [ ] 遮名字能认出说话人。
- [ ] 主场景 ≤8，每个有不可替代用途。
- [ ] 视觉规则五条与预算对得上。

通过后写三份文件，更新 `00-创作总表.md` 的关键决定与文件索引。
