# CHANGELOG

## 4.0.0 - 2026-10-19

按“创作对象”重排信息架构，修正上一版把生产工序当创作对象的问题。

- 一级导航改为：概览 / 设定 / 人物 / 分集 / 剧本 / 交付。
- 市场定位与对标拆解降为项目背景，不占一级。
- 审稿降为动作，记录在 `06-剧本/审稿/`。
- 分镜降为剧本子页，放在 `06-剧本/分镜/`。
- 新增 `03-设定/` 八份、`04-人物/` 五份、`05-分集/` 四份。
- 旧 `pop-drama-story` 拆为 `pop-drama-setting` 与 `pop-drama-character`。
- 总表改为模块就绪 + 当前焦点 + 风险，不再按阶段。

## 3.0.0 - 2026-10-19

整体重构为剧本包生产线，不做最小补丁。

- A 组交付物从"剧本"升级为"剧本包"：00-08 共十类文件。
- 新增 `06-镜头意图表/`、`07-审稿/`、`08-交付/` 三层；旧 `06-审稿/` 改为 `07-审稿/`。
- 模块清单扩为 10 个：新增 `pop-drama-shotintent`、`pop-drama-delivery`。
- 工作台新增交付标准、五条红线、A→B 交接契约、降级记录。
- 总表新增生产模式、单集结构、单集镜头数、交付对象。
- 导入规则同步支持镜头意图与交付包，旧项目自动把 06-审稿 归到 07-审稿。

## 2.0.1 - 2026-10-19

- 补充市场卡面 summary 与精选元数据。

## v2.0.0 | 2026-10-19

按短剧工作流重排，去掉小说管线的阶段状态机。

- `pop-drama-pipeline` 更名 `pop-drama-workbench`。
- 不再用 phase 1-5，不再强制"立项→舞台→剧情→剧本"。
- 改为模块化路由：market / decon / story / beats / script / review / research 可单独调用。
- 状态文件改为 `00-创作总表.md`，只记项目信息、关键决定、文件索引与进度。
- 新增"导入已有项目"的归位规则与"只提示相关缺口"的原则。

## v1.0.0 | 2026-10-19

首版。短剧剧本线总控，范围到剧本交付与审核。
