# AI 短剧生产约束

> 本文件是 A 组所有模块的共同硬约束。故事、分集、剧本、镜头意图都要按它写。
> 目标：A 组交出的剧本包，B 组能直接生成，不需要回头改故事。

---

## 一、单集标准

| 项 | 标准 | 允许范围 |
|:--|:--|:--|
| 单集时长 | 75-80 秒 | 60-90 秒 |
| 镜头数 | 12-13 镜 | 10-14 镜 |
| 单镜时长 | 4-5 秒 | 3-8 秒 |
| 主场景 | 1 个 | 最多 2 个 |
| 主要角色 | 3 个 | 最多 4 个 |
| 有台词人物 | 3 个 | 最多 5 个 |
| 单镜动作 | 1 个 | 不允许第二个 |
| 单句台词 | ≤12 字 | 最长 15 字 |
| 单集台词总量 | 70-80 字 | 60-100 字 |
| 画幅 | 9:16 | 固定 |
| 分辨率 | 1080×1920 | 固定 |
| 帧率 | 24fps | 固定 |

超出范围的，先砍故事或拆集，不靠生成硬扛。

---

## 二、一集怎么分配

| 段落 | 镜数 | 时长 | 任务 |
|:--|--:|--:|:--|
| 钩子 | 1-2 | 0-10 秒 | 抛冲突或异常 |
| 升级 | 4-5 | 10-50 秒 | 每次交锋抬高代价 |
| 转折 | 2-3 | 50-70 秒 | 主角做出改变局势的选择 |
| 卡点 | 1-2 | 70-80 秒 | 留下一个问题 |

---

## 三、不能写进画面的动作

| 禁止 | 原因 | 替代 |
|:--|:--|:--|
| 奔跑 | 动作糊、背景漂移 | 站着喘气、脚停住 |
| 打斗 | 肢体变形、穿模 | 起手、落点、反应 |
| 快速转身 | 脸和身体崩 | 缓慢转头、局部特写 |
| 多人互动 | 手臂融合、多余人 | 两三个具体的人、单人反应 |
| 大范围移动 | 场景漂移 | 固定机位、换镜 |
| 人群 | 人脸重复 | 用声音、影子、两三人代替 |
| 儿童正脸 | 脸崩、比例不对 | 手、背影、襁褓 |
| 动物特写 | 多腿、变形 | 影子、声音、局部 |
| 水/火/烟大范围 | 流体不稳 | 小范围光影、声音 |
| 镜面内容 | 反射乱 | 只给光、模糊轮廓 |
| 屏幕文字 | 文字乱码 | 后期贴字 |

---

## 四、A 组各模块要守的线

| 模块 | 必须守 |
|:--|:--|
| market | 生产模式、单集结构、集数、时长 |
| decon | 对标剧的场景数、角色数、镜头数、复杂动作 |
| story | 人物 ≤3 主角色、场景 ≤2、视觉锚点 |
| beats | 每集 12-13 镜、1 主场景、3 角色、台词预算 |
| script | 场次 ≤2、人物 ≤3、台词 ≤12 字、一镜一动作 |
| shotintent | 12-13 镜、一镜一动作、风险与 fallback |
| review | 以上全部检查 |

---

## 五、B 组负责的部分

A 组不写：

- 首帧 prompt
- 运动指令
- 参考图
- 模型参数
- 抽卡次数
- 剪辑转场

A 组只写：这一镜观众看到什么、听到什么、什么情绪、有什么风险。

---

## 六、超限处理

| 情况 | 处理 |
|:--|:--|
| 故事需要 20 镜 | 拆成两集，或砍掉一条线 |
| 一集需要 4 个主场景 | 合并场景，或改成分集 |
| 一集需要 5 个主要角色 | 合并功能重复角色 |
| 一镜需要两个动作 | 拆成两镜 |
| 一句台词 20 字 | 砍字或拆句 |
| 必须拍 crowd/打斗 | 改拍反应、局部、声音；或换故事写法 |
