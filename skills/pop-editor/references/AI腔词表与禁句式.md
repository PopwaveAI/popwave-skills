# AI 腔词表与禁句式

> **本文件是词表的唯一出处。** 其他文件（SKILL.md、三张打分表、写作红线通用层）一律引用本文件，不复制词表，避免两套标准打架。
> 判据统一用一句话：**把这个词删掉，句子的意思有没有变化。没有变化，说明它没有承担信息功能，就是腔调词。**

## 一、词表（按去留强度分三级）

### 一级 · 红线词（任何正文里默认不用）

赋能、闭环、抓手、底座、全链路、打通、拉齐、飞轮、矩阵、沉淀、破局、突围、重构、重塑、范式革命、王炸、封神、天花板、张力、楔子、稳了、一文讲透。

**判据**：把左边这些词删掉，句子意思没有明显变化，说明它们原本就没有承担信息功能。
来源：连享会公开整理（AI 烂词清单）。

### 二级 · 一级高频词（出现即可疑，一段里出现三个以上即判超标）

深耕、聚焦、助力、打造、引领、全方位、多维度、高质量、沉浸式、一站式、底层逻辑、顶层设计、降本增效、提质增效、数智化。
替换示例：底层逻辑 → 根本原因；认知升级 → 学到了新东西；第一性原理 → 从头想；范式转移 → 大变化；颗粒度 → 细节程度。
来源：cn-humanizer 开源中文 AI 词表。

### 三级 · 过渡与拔高词（叙述层删掉，对话内可改口语）

- **过渡连接词**：此外、另外、值得注意的是、值得一提的是、毫无疑问、不言而喻、众所周知、不可否认、与此同时、事实上、总的来说、综上所述、不难发现、由此可见、因此、所以、于是、这意味着、也就是说。
  改法：此外 → 直接说下一句；与此同时 → 同时或不加连接词；值得注意的是 → 删掉。
- **意义拔高短语**：具有里程碑式的意义、标志着新篇章、开创了先河、谱写了新华章、注入了新的活力、提供了有力支撑、树立了新标杆。
- **万能开头**：随着某某的不断发展、在当今某某的时代、在某某的背景下。
- **万能收尾**：让我们拭目以待、未来可期、前景广阔、大有可为、我们有理由相信。
来源：cn-humanizer 开源词表。

## 二、中文网文向补充词（来自阅文与番茄的公开写作帖）

**删词清单**（原帖直接给出的执行动作）：删掉然而、此外、仿佛、似乎；把书面化表达换成口语化。
**去 AI 规则**：抛弃首先、其次、总之，用隐性连接；避免 AI 习语（值得注意的是、不难发现）；用具体、形象、有温度的替换中性生硬的词。
`来源：阅文起点创作学堂社区帖；网文写作社区整理帖。`

## 三、禁句式

| 句式 | 处置 |
|:--|:--|
| 不是……而是…… | 每章每项不超过一次 |
| 虽然……但是…… | 同上 |
| 不仅……而且…… | 同上 |
| 第一……第二……第三 | 同上 |

来源：cn-humanizer 与新写作方法论公开帖。

## 四、模糊断言（比词表更隐蔽的一类）

判据：只在宣称"这事很难""很重要"，不给具体事物。
高频样本：原因是结构性的、影响是深远的、这是最根本的问题、赌注很高、后果是真实的。
改法三问：有模糊断言吗（写出具体影响）？用了 every／always／never 这类极端词吗（换数字或案例）？只在宣称这事很难很重要吗（删掉或给证据）？
来源：stop-slop 规则四的公开整理。
