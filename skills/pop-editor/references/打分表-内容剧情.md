# 打分表 · 内容剧情

> 这一维只问一件事：**本章该写的东西有没有写到，写出来没有。**
> 这一维要看"本章该写什么"，所以必须在盲读之后做（先盲读评文笔与情绪，再看输入评这一维）。
> 案例栏待填。

## 一、什么是好

1. **该写的都写到了**，且每一条都是被写出来的，不是被提一句的。判定：把这一条相关段落删掉，情节会不会断。会断就是写到了，不会断就只是提了一嘴。
2. **落点命中**：结尾停在要求的那一处处境上。换了收尾方式要能说清是不是失守。
3. **读得出一处明确变化**：信息、关系、物理、权力四类至少一类变了。
4. **章末有钩子，且与上一章不同类**（六类：悬念、威胁、情绪、信息、反转、选择）。
5. **前后不打架**：时间、地点、人物状态、道具、信息边界，与前文对得上。

## 二、什么是坏

| 病例 | 判定 |
|:--|:--|
| 事实都在，但都只提一句 | 关键场景被压成提要，读者被"告知"了一切，没有一处被放进去 |
| 漏事实 | 该写的没写，情节断了 |
| 落点失守 | 结尾跑到别的地方去了，或把该留的悬念说破了 |
| 说了答案 | 输入里已经给了答案，正文只剩"演" |
| 无变化 | 读完说不出"什么变了" |
| 两条互不相干的支线 | 一章一条主线的原则被破坏 |
| 钩子同类 | 上一章与这一章的钩子属同一类，读者会腻 |
| 前后矛盾 | 与前文冲突的设定、时间或状态 |

## 三、四级标准

| 级 | 标准 |
|:--|:--|
| **一级 · 好** | 该写的全写到且写出来；落点命中；有明确变化；章末钩子与上一章不同类；无矛盾 |
| **二级 · 可改** | 漏一条非关键事实，或落点略偏；骨架完整，改得动 |
| **三级 · 差** | 漏两条以上，或关键场景被写成提要，或落点失守 |
| **四级 · 垃圾** | 情节读不出；或与输入要求基本不相关；或前后矛盾成片 |

## 五、三档各自的样子（判档先看这一节）

> 口径：档位由平台成绩切（见 `成绩台账.md`）。样本出处见 `对照表-起点.md` 与 `对照表-番茄.md`。

| 档 | 剧情这一维长什么样 | 依据样本 |
|:--|:--|:--|
| **80** | 交代一次给足世界规则与任务；交代旁边有具体的物与动作；事件成立且有变化 | 对照表-番茄 80-01（凡骨 行1）、80-02（凡骨 行23） |
| **60** | 交代**一次一件事**，其余留给后文；系统音／公告体开场在本赛道合法 | 对照表-起点 60-04（黜龙 行5）；对照表-番茄 60-01（全民大航海 行1） |
| **40** | 交代**连着讲完三件事**；有戏的事被压成一句短语；关键场景被压成提要 | 对照表-起点 40-01（明末 行19） |

**三条可判的判据（行为指令）**：
1. 数本章交代了几件事。**一段里超过一件 → 这一维最多 60。**
2. 找出本章最该展开的一处（有冲突、有转折、有代价），看它是否被写成实景。**被压成一句 → 落 40。**
3. 把相关段落删掉，情节会不会断。**不会断 ＝ 只是"提到了"，不算写出来。**
