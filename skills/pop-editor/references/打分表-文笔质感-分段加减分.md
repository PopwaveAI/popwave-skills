# 打分表 · 文笔质感（分段加减分制）

> 作者 2026-09-13 改定第二版口径：**打分单位从"一句"改成"一段"**，理由是「一句单拆打分不太适合，因为要看上下文」。
> 第一版（逐句）的判定被作者否掉：**我标的 +1／+2 全部作废，作者判那六句是 0 与扣分**。见第三节。
> 执行细则：一段一个分（+2／+1／0／−1／−2），段内毛病按最重的一处定，不做句子算术和。

## 一、打分单位

**一个「阅读段」**——由切段规则从正文重建出来的段，不是源文 txt 的行。

**为什么需要重建**：源文 txt 的空行只出现在**章与章之间**，章内一律"一句一行"（一整章 = 一个 40 至 130 行的连续块）。照行切出来的"段"每段只有一句，读不出上下文，没法打分。作者 2026-09-13 指出：「得按段来 不能一句一句，如果一段只有一句 就得把临界几段合一起」。

**切段规则（四条，实现见 `新流程探索/网文编辑/打分器/build.py`）**
1. **收段**（从左到右累加时判断，满足任一即收）：已 ≥2 句且 ≥40 汉字、且下一段的类型（对白／叙述）与当前段不同；或 已 ≥4 句且 ≥120 汉字；或 已达上限 8 句／260 汉字。
2. **必断**：纯符号分隔行（`***`、`......`）与章标题行 → 丢弃并在该处断段。
3. **转场行起新段**：≤10 汉字、以「。」结尾、不含引号的行（如「半月后。」）。
4. **收尾不足**（句数 <2 或 汉字 <40）的段 → 并入上一段。单行超 150 汉字的（历史文的灌水长句）在句末标点处拆开。

**实测效果**：13 章从 986 段降到 **260 段**，每段 40 至 242 汉字、平均约 110 字。连续对白不再被切断（凡骨开篇三句「瑶池诏令…」、全民大航海开篇八句系统音各成一段），对白与叙述的交界处断开（天渊开篇「我给你两个选择」＋后四句叙述成一段，「我选择二」起新段）。

**素材文件本身不动**：`素材/*.md` 是"一句一行"的原始格式，`对照表`／`打分表` 里的行号都对着它；阅读段在打分器构建时现场生成。改素材会打乱全部行号，不允许。

**判的时候必须连上下文读**：一段的力度靠它前一段铺了什么，拆成句就看不见。作者给的第一条 0 分锚「顾烬睁开眼，先把压在身上的半截木梁推开」单看是干净句，放在开篇那一段里看才知道它立没立住。

## 二、五级（门槛按作者判定修正）

| 分 | 判据 |
|:--|:--|
| **+2** | 这一段是"全章最好的东西"，读到会停下、会想回头看一遍。**极稀有，一章 0 至 1 段** |
| **+1** | 这一段里有读者会记住的东西（一个动作、一个物象、一句台词），且**不是靠干净取分** |
| **0** | 干净、通顺、有物象、有动作——**但读完不会停**。功能段都落这里 |
| **−1** | 段内有 1 至 2 处可指认的毛病（套语、情绪直述、重复、该留白的说破、破折号） |
| **−2** | 段内毛病成片（≥3 处），或含一级红线（G18／G16／G17／G22） |

**门槛的修正（这是本轮最要紧的一处）**：
**"有物象、有动作、句子干净"是 0，不是 +1。** 第一版我把 +1 定义成"有增量"，于是 116 句里标出 42 句加分。作者一句话否掉：「我看下来 是没有加分的 你都标了加分」。
**加分句"稀有"这件事本身就是判据**：如果一篇稿里到处是加分，那一定是尺子坏了。

**归属说明（诚实标注）**：六条批注的锚点位置有两处重叠（第 4、5 条落在相邻两行），上表的对应是我按批注锚点推定；若作者认为某一行对错了，只改标注不影响规则。

**这批锚点带出的三条硬结论**

1. **「干净」不是加分。** 我以为本章文笔最高的四处（冷烫对照、锁与手心、黑贴水、锈退露新铁）全被判扣分。**加分门槛比"写得好"高得多。**
2. **一章里"零加分"是常态，不是异常。** 灰烬之主 ch001 全章 48 段，作者的判定是**没有任何加分**（原话：「我看下来 是没有加分的」）。
3. 因此**「把扣分修成 0」＝ 40 分档；要到 60 分档，需要真的出现加分段**。这条与上一轮从「0 分项」推出来的结论一致，现在被六句判定坐实了。

## 四、从分段分到全章定级

数三个量：段数 `N`、加分段 `A`（+1 与 +2）、扣分段 `D`（−1 与 −2）。

- **加分率 ＝ A / N**（这是区分 40 与 60 的那把尺）
- **扣分率 ＝ D / N**（这是区分 20 至 30 与 40 的那把尺）

**定级线（待校准，五个阈值仍是估的，不许当结论用）**

| 条件 | 落档 |
|:--|:--|
| 出现 −2 成片（同一场景内 ≥3 段），或 扣分率 > 50% | 20 至 30 |
| 扣分率 30% 至 50% | 40 |
| 扣分率 15% 至 30% | 60 |
| 扣分率 <15% 且 加分段 ≥1 | 80 |
| **加分段 ＝ 0** | **封顶 40**（不管扣分多干净） |

**加最后一条的理由**：本轮实测两篇都在 40 分档或以下，灰烬之主加分段 0、克苏鲁航海有加分段——若不加"零加分封顶 40"，一篇全干净但无加分段的稿会靠低扣分率混进 60。
