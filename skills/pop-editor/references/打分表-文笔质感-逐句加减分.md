# 打分表 · 文笔质感（逐句加减分制）

> 作者 2026-09-13 定的新口径：**文笔质感以「完整的一句话」为单位打分，不用四级标签。**
> 理由（作者原话意）：这样全篇看下来，找问题与全章定级都容易。
> 本文只讲怎么打分与怎么计数。三档的"样子"仍看 `对照表-起点.md`／`对照表-番茄.md`。

## 一、打分单位

**一个"完整的一句话"**，以句号、问号、叹号、省略号结句为一个单位。引号内的对白各算一句。

- 逗号、分号连起来的一整句算 **1 句**，不管中间有几个分句。
- 引号内的对白各自独立计句。
- 不按段落计分，不按字计分。

## 二、五级

| 分 | 名字 | 判据（可判） |
|:--|:--|:--|
| **+2** | 非常非常好 | 给出新信息或新画面，且**读者自己得出结论、作者没说破**；或一句把前文串起来（回收）。读到会停一下 |
| **+1** | 好 | 有增量：动词带身体感、物象具体、比喻方向对且有新意。读一遍就懂，不用回读 |
| **0** | 中性 | 不出彩但不错。功能句（交代、过渡、对白推进）干净，无毛病 |
| **−1** | 不好 | 一眼看得过去的毛病：套语、情绪直述、抽象抒情、同一信息说两遍、句略长 |
| **−2** | 非常非常不好 | 硬伤或把效果说破：成分缺／生造词／比喻方向错／替读者下结论／该留白的说破／因果跳／主语跳／长句粘连 |

**0 分项不是坏句。** 作者给的定义：0 分项是"至少不是扣分项"。**把扣分项修成 0 分项，是及格线的活；要往上走，必须有 +1 与 +2 的句子。**

## 四、第一处校准：两版开篇对照

同一段内容（醒来到看清街在烧），两版逐句打分。

**修句版**

| 句 | 分 |
|:--|:--|
| 顾烬睁开眼，先把压在身上的半截木梁推开。 | 0 |
| 木头早烧成了灰，一推就塌下一片，扑了他满脸。 | +1 |
| 他撑着地坐起来，喉咙里全是烟。 | 0 |
| 天是红的，红得发暗，整条街都在烧，火苗顺着屋檐往上蹿。 | 0 |
| **小计** | **+1，扣分 0 句** |

**大重构版**

| 句 | 分 |
|:--|:--|
| 顾烬睁开眼，先动的是他的手。 | −1 |
| 不是他去推，是那只手自己去推的。 | −1 |
| 按在压着胸口的那截木梁上，肩膀跟着一沉，木头就塌了。 | +1 |
| 木头早烧成了灰，一推就塌下一片，扑了他满脸。 | +1 |
| 他撑着地坐起来，喉咙里全是烟。 | 0 |
| 天是红的，红得发暗，整条街都在烧，火苗顺着屋檐往上蹿。 | 0 |
| 这不是他的手。 | −2 |
| 他试着张开五指，五根指头张得很顺，像是用过很多年。 | −1 |
| 他不记得自己练过什么。 | 0 |
| **小计** | **−3，扣分 5 句** |

**同样一段内容：修句版 +1，大重构版 −3。** 方法与作者的判定同向，且把"还不如之前的"这句话落成了可数的数：**我为了做出"身体不听话"的钩子，多写了五句，其中四句是扣分项。**

## 五、怎么从逐句分到全章定级

**不做简单求和**（长章吃亏）。先数三个量：

- `N` ＝ 全章句数
- `A` ＝ 加分句数（+1 与 +2 合计）
- `D` ＝ 扣分句数（−1 与 −2 合计）

再算两个率：**加分率 ＝ A / N**，**扣分率 ＝ D / N**。

**定级线（初版，待校准，不许当结论用）**

| 条件 | 落档 |
|:--|:--|
| 出现 −2 成片（同一场景内 ≥3 处），或 扣分率 > 15% | 40 档及以下 |
| 扣分率 ≤ 15%，且 加分率 < 5% | **40 档**（句子干净但不出彩） |
| 加分率 5% 至 10% | 60 档 |
| 加分率 > 10% 且无扣分项 | 80 档 |
| **开篇前 3 句里出现 −1 及以下** | 全章降一档 |

**为什么留一条"开篇降档"**：作者这次挑的就是开篇第一句。开篇第一句坏，后面全打折。

**定级线怎么定准（下一步要做的）**：拿三档锚点各 3 章逐句打完，看 加分率 与 扣分率 的真实分布，用分布定线。**现在是初版，五个数字都是估的，必须用实测数据替换。**

## 六、与旧四级标准的关系

`打分表-文笔质感.md` 里的四级标准（一级好／二级可改／三级差／四级垃圾）与本节并存，用途不同：

- **四级标准**判"这稿能不能用"，粗，一屏看完。
- **逐句加减分**判"具体哪一句值多少"，细，用来找问题与算全章的分率。

两者冲突时**以逐句加减分为准**，因为它是可数的、可复核的。
