## 一、什么是好

四条都可指认，不含形容词结论：

1. **画面由细节承担，不由形容词承担。** 写"墙皮一块块往下掉，窗框发黑，桌角缺了口"，不写"屋子很破旧"。
2. **动词驱动。** 段落以动词为核心，形容词少而准。让人看见发生了什么，而不是被告知是什么样。
3. **长短句错落，单句有上限。** 一句长叙事配两句短动作；单句尽量不超过三十字，超过五十字读者要回读。
4. **比喻方向一致。** 喻体与本体在语境里对得上，不用同质比喻（以气比气味），不用方向反了的比喻（把自身的一部分写成外来之物）。

**两条进阶判据**（判"笔力"用，不常出现）：寥寥几笔立起人物或画面；前文铺得很轻，某处一句把前面串起来。

## 二、什么是坏

| 病例 | 长什么样 | 坏在哪 |
|:--|:--|:--|
| 长句塞满信息 | 一句里连续装了动作、场景、情绪好几层 | 读者抓不到重点，要回读 |
| 情绪直述 | 写"他非常生气，因为他觉得被羞辱了" | 替读者下结论，人物变空 |
| 抽象空泛 | 写"屋子很破旧，条件很差" | 读者看不见，只是一个判断 |
| 冗余绕句 | 写"她在听完这句话之后，内心当中立刻就产生了一种非常明显的慌乱情绪" | 用词重复，力量被稀释 |
| 神态词全篇复用 | 所有人遇到事都是"眉头一皱" | 描写库贫乏，人物分不开 |
| 助词滥用 | 一句里连用几个"的" | 读起来幼稚冗余 |
| 搭配不准 | 形容味道用"重"（"重"只配臭辣这类刺激味） | 搭配错了，读者会绊一下 |
| 比喻不搭语境 | 在水深火热处写"像清幽山谷中的一记钟声" | 喻体与上下文的语境冲突 |
| 指代与逻辑断裂 | 前后句读起来像两件事，第三句才明白 | 语言出了问题，信息没交代清 |
| AI 腔 | 出现"值得注意的是""与此同时""赋能""闭环"这类词 | 没有承担信息功能，删掉意思不变 |
| 生造词与文言残句 | 「贪弱地」「此为上限否」 | 词典里没有，或不像人话 |
| **前提与结果不同质** | 「木头烧透了，一推就散」 | 烧透＝成炭，炭是一整块，不会散；能一推就散的是灰。A 与 B 不是同一种物态／性质，因果就不成立 |
| **动作与结果的主语不一致** | 「她拽他，拽不动，就哭」 | 前一句主语是她，中一句的实际主语是他，末一句主语又是她。主语跳两次，读起来像半截话 |

## 三、四级标准

| 级 | 标准（可判） |
|:--|:--|
| **一级 · 好** | 四条"什么是好"里至少中三条；无句法层硬伤；无 AI 腔词超限；读一遍不出戏 |
| **二级 · 可改** | 有 1 至 2 处毛病，但都不在句法层；骨架是活的，删改那几处即可用 |
| **三级 · 差** | 出现句法层硬伤（搭配矛盾、成分缺、生造词），或形容词堆砌与情绪直述成片 |
| **四级 · 垃圾** | 语病成片；或一页里多处指代与逻辑断裂；或读两段就想停 |

**句法层硬伤清单**（命中即落三级及以下）：生造词、话没说完、搭配矛盾、比喻方向错、用符号代替句子成分。

### 一级 · 好（引样文库，不复制原文）

### 二级 · 可改

| 案例 | 位置 | 为什么在这一级 | 升档条件 |
|:--|:--|:--|:--|
| 末句替读者下结论 | `素材/合格边缘/J-稳定S01.md` 行 5：「这喷嚏倒是把院里的寂静震碎了些，他觉得舒坦了点。」 | 毛病只在末句（替读者说感受），前半句"寂静震碎"是活的 | 删掉"他觉得舒坦了点"，改用动作带出 |
| 比喻成立但平 | `素材/合格边缘/J-稳定S04.md` 行 37：「窗台上落着一只死去的飞蛾，翅膀上的粉沾在玻璃上，像一小片灰。」 | 比喻不算错，喻体也对得上，只是没有增量（灰本来就灰） | 换一个能带上情绪的喻体，或删掉比喻只留物象 |

### 三级 · 差（句法层硬伤）

| 案例 | 位置 | 硬伤 |
|:--|:--|:--|
| 喻体自相矛盾 | `素材/合格边缘/J-稳定S01.md` 行 7：「像走在某种老骨头的脊梁上」 | 脊梁本就是骨，喻体在本体里面 |
| 同质比喻 | `素材/合格边缘/J-稳定S03.md` 行 13：「气味涌过来，像是一口气」 | 以气比气味，等于没说 |
| 动作矛盾 | `素材/合格边缘/J-稳定S01.md` 行 47：「纸是被裁开的……像是情急之下撕的」 | 裁是刀切、撕是手撕，同一句里两个动作互斥 |
| 假反转 | `素材/合格边缘/J-稳定S02.md` 行 11 至 13：「字迹是他的。不，字迹是师父的。」 | 制造一个读者没有的误认，再把标点当反转 |

### 四级 · 垃圾（带作者判定）

| 案例 | 位置 | 作者判定 |
|:--|:--|:--|
| 结果硬接 | `素材/不合格/X-灰烬之主ch001.md` 行 3：「木头烧透了，一推就散，灰扑了他满脸。」 | 作者圈为"不舒服" |
| 动作与结果不接 | 同行 行 9：「她拽他，拽不动，就哭，眼泪在灰脸上冲出两道白印。」 | 作者圈为"不舒服" |
| 少动词 | 同行 行 11：「这些话一句都出不来」 | 作者指出应为"一句都说不出来"，**少了动词"说"** |
| 该紧张写成一片 | 同行 行 23 起（追逐段，从"顾烬一把捞起她"到"灰扑了满巷"） | 作者判定"写的也一塌糊涂，基本上全篇都不行" |

**这一级的特殊之处**：四级案例全部带作者逐行判定，这是最强证据。判四级时先找有没有这类硬伤成片。

案例填报格式：逐字原文 + 位置（章号／行号）+ 为什么在这一级 + 升档条件。
