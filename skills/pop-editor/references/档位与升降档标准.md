# 档位定义与升降档标准

> 用途：判定一稿"落在哪一档"时对照本文件定档，再对照两张对照表里的真实样本。
> **口径变更（2026-09-13）**：档位从"由产源决定"的四档（满分／降级能用／不合格／垃圾）改为**由平台成绩决定的三档（80／60／40）**。
> 定档依据一律以 `成绩台账.md` 为准；档位的**样子**看 `对照表-起点.md` 与 `对照表-番茄.md`。
> 旧四档只保留作历史记录，不再作为判定口径。
> 何时更新：档样改动、模型换版本、判据改动，三件事任一发生都要重跑校准。

## 一、三档定义

判定看的是**落在哪一档**，不是给一个分。每档都有可判的界线。

| 档 | 一句话 | 判据（满足其一即为该档） |
|:--|:--|:--|
| **80** | 学习样板：可以发布，一个字不改 | 无一级红线命中；有可指认的好句；场景成立；读一遍不出戏 |
| **60** | 及格线样板：能发布，但有一处明显不到位，改得动 | 无一级红线；有 1 至 3 处描写层或节奏层的毛病（句句告知感受、作文式概述、主语重复、套语成片）；删改那几处即可用 |
| **40** | 反面样板：能读但不出彩，或有一处明确不到位 | 命中任意一条一级红线（见下）；或通篇把该展开的场景压成概述；或情绪全靠旁白命名；或读两遍才明白哪句接哪句 |

**一级红线清单（命中即落 40 档及以下）**：G18 正文带工作标记、G16 生造词与文言残句、G17 成分缺（动词被省掉）、G22 假反转。破折号（G45）不计入红线，只作档内减分项。

**档不是分**。80／60／40 是三个标签，同档内不分高下；说"改到 60"＝改到 60 档水平，不是凑一个数值。

## 二、升降档标准

对照表不能只是几个孤立例子，必须写清"差什么才升一档"。

| 从 | 到 | 需要补什么 |
|:--|:--|:--|
| 40 | 60 | 清掉一级红线；把该展开的场景从概述写成实景（谁、在哪、看见什么、做了什么动作） |
| 60 | 80 | 让环境与旁白**作用在人身上**，而不是摆在那里给人看；把"告知感受"换成"可见的动作" |

**两条跨档差（可指认，来自两张对照表）**：
1. **80 与 60 的分界**是"交代旁边有没有具体的物与动作"。80 的交代紧跟着一个动作（灵镜弈棋、啪嗒一声）；60 的交代就是交代（八句系统音、春雷细雨与主角无关）。
2. **60 与 40 的分界**是"场景是被写出来的还是被说出来的"。60 的场景被写出来（灰尘呛咳、干枯骸骨）；40 的场景被说出来（"显得悲凉""六十年一句压完"）。

## 三、场景类型（判样本与判稿子都要先分场景）

同一个档里，战斗段的好与日常段的好不是一回事。评样本与评稿子都要标注场景，不许跨场景比。

| 场景 | 判什么 |
|:--|:--|
| 环境引入 | 是否用感官交代空间，有没有功能（不只是布景） |
| 人物出场 | 外貌与身份是否由动作带出，不是静态铺陈 |
| 对话 | 是否有潜台词与回避，各人说话是否可辨 |
| 战斗 | 动作链是否完整、有无段落呼吸、暴露程度是否与全篇一致 |
| 情感 | 是否外化，有没有替读者下结论 |
| 过渡 | 是否用行动衔接，有没有时间标记 |
| 日常 | 是否在为后文服务，有无空转 |

## 四、判定纪律

1. **不许跨赛道比**。付费站（起点）与免费站（番茄／七猫）两套线各自切档，不做"起点 80 ＞ 番茄 80"这类比较。判一两稿要先说它是哪个赛道的。
2. **免费站的不扣分项不许当缺陷扣**。系统音、面板直列、公告体、口语词、套语，在免费站 60 与 80 两档里都出现，**不作为降档理由**；降档只看一级红线、该写的有没有被写出来。
3. **每条判定必须挂样本**。说"这稿在 40 档"，必须指出它最接近哪张对照表里的哪一条，并写出差在哪。
4. **不许用形容词下判**。不写"文笔流畅""感染力强"，只写可指认的事实（哪个词、哪个搭配、哪一句的比喻方向）。
