# 检查模式 · 文风质感

> 本文件是 `pop编辑` 默认模式的完整走法。判据正本在 `毛病清单-AI写作共性.md`（**14 条速查表已内联在下文第二步**），切段 6 条原则内联在 `SKILL.md`「模式一 · 第一步」，报告样式在 `汇总报告模板.md`。

## 一、这个模式问什么

**句子本身站不站得住。** 不问剧情好不好、不问情绪够不够——那两件是另外两个模式的事。混着问会把一篇剧情好文笔好的稿判歪。

## 二、三步走

### 第一步：拆段

按 `SKILL.md`「模式一 · 第一步」的 **6 条断段原则**切（正本原在 `拆段口径.md`，2026-09-13 起内联在 SKILL.md）。切完先报两个数：**原始段数 → 切后段数、段均汉字数**。段均落在 30 至 50 为正常，超出要说明原因。

### 第二步：逐段打分

一段一个分。打之前先给这一段填一份「毛病清单」。

| 顺序 | 做什么 |

| 1 | 读这一段的**上一段**——本轮力度靠它铺了什么 |
| 2 | 拿 `毛病清单-AI写作共性.md` 的 14 条逐条对，记下命中了哪几条、原文哪一句 |
| 3 | 问一句「这一段本该交付什么」。若发现写的东西与该交付的不是一回事，回去补记命中条目 |

**落点分层**：6（句式残）与 9（收卷说明）是"**坏件**"——不是文笔问题而是错误，可硬拦；1（动作流水）与 8（旧稿回收）是**独有高频病**，最该优先治；4（比喻空转）与 11（先讲后做）**有合法例外**，判据必须带边界条款，否则误杀。

**附（工序层，不在 1-14 内）**：**改写空转**——改写版大面积搬原稿，扣分段也没真改（段32 保留 100%）。判据：扣分段保留率必须 <30%。

| 分 | 判什么 | 门槛 |
|:--:|:--|:--|
| **+2** | 整段独立构成一个读者会转述的片段 | 极稀有，一章 0 至 1 段 |
| **+1** | 段内有明确记忆点（物象／对白／数字） | 且**不是靠干净取分** |
| **0** | 干净、通顺、有物象、有动作，但读完不会停 | 功能段都落这里 |
| **−1** | 命中清单任一条目，且是该段的主要特征 | 轻度命中（清单里标了「轻度」的）不算主要特征，仍给 0 并在原因栏记一笔 |
| **−2** | 一段命中两条以上，或含坏件级缺陷 | 坏件＝句式残、收卷说明 |

**一段内同时有 +1 材料与 −1 材料 → 报 0，原因栏两样都写。** 实例：「遛弯的大爷凑过来…她问大爷："您外甥知道您拿他当断桥特产往外送吗？"」——「断桥特产」是 +1 材料，段中插入「这一年混熟了／上个月介绍外甥」是话题漂移 −1 材料，报 0。

### 第三步：出汇总报告

按 `汇总报告模板.md` 出。四块必须齐：两率表、逐段打分表、命中最多的条目、要作者拍的问题。

## 三、三条尺度纪律

1. **「干净」不是加分。** 有物象、有动作、句子通顺，是 0。加分门槛是「读到会停下」。
2. **一章里「零加分」是常态。** 若一份稿到处是加分，先怀疑尺子坏了。实测：第一版把 116 句标出 42 句加分，被作者一句话否掉。
3. **判据必须带语境。** 纯字面匹配只能抓句式残、收卷说明、模板骨架这类字面级缺陷；过度解释说明、话题漂移、动作代情绪三条必须先定「这一段该交付什么」，再看写法对不对。

## 四、两率怎么算

| 率 | 算式 | 量什么 |
|:--|:--|:--|
| **加分率** | （+2 段数 ＋ +1 段数）÷ 总段数 | 文笔轴的高度 |
| **扣分率** | （−1 段数 ＋ −2 段数）÷ 总段数 | 这份稿能不能用 |

**两率必须同批同形态才可比。** 一段长句多的稿与一段对白多的稿，段数结构不同，两率不能直接比。

**已知参照（同口径实测）**：

| 样本 | 加分率 | 扣分率 |
|:--|:--:|:--:|
| 夜无疆 第1章（人书） | 31.9% | 0% |
| 凡骨 第1章（人书） | 1.8% | 0% |
| 灰烬之主 ch001 原稿（自家） | 8.3% | 47.2% |
| 奔现 ch001（自家） | 11.5% | 19.5% |

**读法**：扣分率是最该盯的数——人书是 0%，自家稿只要不是 0 就说明有活没干。加分率给出的是高度，拿人书的天花板（夜无疆 31.9%）当参照线。

## 五、四种常见误判（实测踩过）

| 误判 | 长什么样 | 怎么防 |
|:--|:--|:--|
| **判过头** | 把一个未校准的读数当结论，还在它上面继续推理 | 报数时标明是段级打分、不是定档；结论只出「哪段值多少」 |
| **按句判** | 标出一堆加分句，作者看了说没有 | 打分单位是段，读上一段再判 |
| **拿干净当加分** | 通顺的过渡段标 +1 | 门槛是「读到会停下」 |
| **只报坏的，不报好的** | 报告只有扣分 | 加分项必须列出来，它是改稿时的保留清单 |

## 六、我出结论的样板

**逐段全覆盖，不跳段；原因栏只写命中哪一条与机制；末段给两率与要作者拍的问题。** 骨架与四块硬要求见 `汇总报告模板.md`。

## 七、这一模式的边界

- **不做跨稿排序。** 排序会让不同形态的稿互相比，详见 `检查模式-剧情内容.md` 末尾的形态说明。
- **不判档、不报总分。** 20／40／60 已作废，理由见 SKILL.md 第八节。
- **不改稿。** 作者说改才进 SKILL.md 第四节的三级改写。
