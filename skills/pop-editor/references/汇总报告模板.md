# 汇总报告模板

> 文风质感模式的产出格式。四块必须齐，少一块算没交。
> 报告不报总分、不报档、不排序。

## 报告骨架

```
# {书名} {章号} 毛病清单走查

> 被查文件：{路径}（{原始段数} 个原始段 → {切后段数} 段，{汉字数} 汉字，均 {段均} 字）
> 切段口径：references/拆段口径.md
> 判据来源：references/毛病清单-AI写作共性.md（14 条 ＋ 改写工序缺陷）
> 日期：{yyyy-mm-dd}

## 一、一句结论

{这一章的毛病集中在哪一层，一句话。附两率与同口径参照的对比。}

## 二、逐条命中

{按毛病清单编号排。每条给：命中几处、最重的一处带段号与原文、老板／作者改法（若有示范版可对照）}

## 三、逐段打分表

| # | 原文 | 打分 | 原因 |
|:--:|:--|:--:|:--|
| 1 | {照抄段原文} | 0 | {一句，写命中哪条／为什么 0} |
| … | | | |

## 四、汇总

{两率表 ＋ 加分项清单 ＋ 扣分段清单 ＋ 命中最多的条目 ＋ 零命中的条目}

## 五、要作者拍的

{每条最多三条。必须是可以二选一或多选一的判断题，不是「请指示」。}
```

## 四块硬要求

| 块 | 缺什么算没交 |
|:--|:--|
| **两率表** | 必须给加分率与扣分率，且附同口径参照（夜无疆／凡骨／灰烬之主之类） |
| **逐段打分表** | 必须**逐段全覆盖**，不许只列有问题的段，也不许跳段 |
| **命中最多的条目** | 必须给条数分布（哪条命中几处），并点出**零命中的条目**——零命中本身就是结论 |
| **要作者拍的** | 最多三条，每条是判断题 |

## 原因栏怎么写

**只写两样：命中哪一条、机制是什么。** 不许写形容词结论。

| 差 | 好 |
|:--|:--|
| 这段读着有点平 | #1 动作流水：站→买→吃→站，用动作填满时间跨度，零交付 |
| 文笔还可以 | 0——干净通顺，无记忆点，未命中清单 |
| 情绪不到位 | #3 旁白格言：叙述者替读者定性「每一句都像在给她打预防针」 |
| 这里有点乱 | #5 话题漂移：从"她选烟萝"漂到苏瑶的门派／ID／技术／榜单，一段塞四项属性 |

**两样都有的段**在原因栏写「两样都有：+1 材料是……；−1 材料是……」，让作者看得见我是怎么折的。

## 加分项与扣分项怎么列

- **加分项**要给段号 ＋ 那句记忆点原文。它是改稿时的**保留清单**——改写不许把这些改掉。
- **扣分段**要给段号 ＋ 命中条目号，方便改写时逐段对账。
- **改写后的验收直接查这两张表**：扣分段必须消除，加分率不许掉。

## 一页结论怎么写（作者只看这一页时）

一页里放：一句结论、两率、命中最多的三条、要作者拍的三条。其余内容折在后面的表里。

**不许写「总体不错」「有待提升」这类句子。** 一页结论里每个句子都要带段号或数字。
