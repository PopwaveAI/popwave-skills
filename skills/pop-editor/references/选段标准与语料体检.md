# 玄幻赛道 · 满分档选段标准与语料体检

> 满分档来源：《夜无疆》（辰东）。《遮天》列为参考，不作样本来源（原因见下）。
> 本文件先记语料体检，再定选段标准，最后是避开清单。

## 一、语料体检（2026-09-13，各取前 3MB 约 89 万汉字）

| 项 | 夜无疆 | 遮天 |
|:--|--:|--:|

| 乱码串（形如「一一一」） | 0 | **64 处** |

| 行内 3 个以上连续空格 | 345 处 | 0 |
| 残缺串（形如 `..`、`r一`） | 106 处 | 156 处 |

**结论（含一次更正）**
1. **夜无疆可以用**，错字密度极低，但**不能整本直接抽段**，必须逐段校验。
2. **更正此前判断**：先前只看半角冒号与引号两项，说"遮天更干净"，那是错的。**遮天错字与乱码都更多**（神休 13、今生物 11、`一一一` 64 处），只能当交叉参考，不能当选段来源。
3. 两书都有空格与残缺串噪声，选段前先归一化空白，再逐段核。

## 二、选段标准（每段必须六条全中）

1. **逐字原文**，不改写、不摘句拼接、不用省略号截断
2. **长度 110 至 240 汉字**，一段一个完整意思
3. **零错字、零半角冒号、引号统一、无乱码串**（选中后逐条核）
4. **标注场景类型**（环境风物／人物出场／对话／战斗动作／情感外化／日常过渡），样本与稿子都按场景比
5. **标注位置**（章号、章标题、行号）
6. **写清为什么在这一档**，指到具体特征，并写出一条升档条件

## 三、选段与校验流程

1. 抽候选段（按场景关键词初筛）
2. **逐段通读校验**（我既是读者也是校验人）
3. 通过的进档样库，不通过的登记进避开清单
4. 每个场景类型留两段，共 12 段
5. 选完用遮天做一次交叉比对，确认两书的满分标准不冲突
