# 判据摘要（注入评委 prompt 用）

> 每轮开跑前由 `run_judge.py` 读入并拼进 prompt。改本文件等于改判据，**改完必须重校**。

## 一、三档标尺（判档位用）

> **档位由平台成绩切，不由读感切。** 定档依据见 `../references/成绩台账.md`；档位的**样子**见 `../references/对照表-起点.md` 与 `对照表-番茄.md`。
> 及格线＝**60 档**。自家产出（popagent 走 skill 链路）一律按 20 至 30 处理，**不判档、只改写**。

| 档 | 线怎么切 | 一句话识别特征 | 逐字样本（照这样认） |
|:--|:--|:--|:--|
| **80** | 起点：首订 ≥5 万或均订 ≥5 万或月票榜长期前 10；免费站：在读 ≥50 万 | 靠物象与动作落地，交代旁边总有具体的物与动作 | 夜无疆第1章 行5「永夜，天地漆黑，似不可测的深渊要吞噬一切。」 |
| **60** | 起点：首订 1000 至 5 万或均订 3000 至 5 万；免费站：在读 5 万至 50 万 | 能发布，但有一处明显不到位；场景**被写出来**，隔一段出现一句"告知感受" | 全民大航海时代第1章 行21「杨逸苏醒过来，发现自己正躺在一张老旧的床上。他试着起身，却被带起的灰尘呛得咳嗽起来。」 |
| **40** | 起点：首订 <1000 或均订 <3000；免费站：在读 <5 万 | 能读但不出彩；场景**被说出来**，或一级红线命中 | 明末第1章 行29「……徐晨成为了高家寨四里八乡有名的大夫靠着村民的米面，鸡蛋，老母鸡……」（长句粘连，缺断句） |

**两条跨档差（判档先比这两条）**：
1. **80 与 60**：交代旁边有没有具体的物与动作。80 的交代紧跟一个动作（灵镜弈棋、啪嗒一声）；60 的交代就是交代（八句系统音、春雷细雨与主角无关）。
2. **60 与 40**：场景是被写出来的还是被说出来的。60 被写出来（灰尘呛咳、干枯骸骨）；40 被说出来（"显得悲凉""六十年一句压完"）。

**四条纪律**：①档位由平台成绩切，不由印象决定。②判档先逐句举证，再说落在哪一档。③**不许跨赛道比**：付费站（起点）与免费站（番茄／七猫）两套线各自切档。④**免费站的不扣分项不许当缺陷扣**：系统音、面板、公告体、口语词、套语，在免费站 60 与 80 两档里都出现，不作降档理由。

**判 60 与 40 只认一条主判据（第 7、8 轮实测后改定）**：**该展开的场景是被写出来的，还是被说出来的。**
- **被写出来** → 60。有地点、有动作、有感官。例：灰尘呛咳、干枯骸骨握燧发枪、陶碗掼地床板散架、牛粪血腥与粪叉爆头。
- **被说出来** → 40。用旁白把经过压成一句，或把有戏的事压成短语。例：「六十年，足以让一个意气风发的青年，变成一个行将就木的老人」（莫欺老年穷）；「差点被黑吃黑了」（明末）。
- **不要拿"直接命名情绪的词数"当判据。** 第 8 轮实测被证伪：60 档的《超维度玩家》与 40 档的《莫欺老年穷》，直述词都超过三处，这个数分不开两档——第 8 轮据此把 60 档误降到 40。直述只作参考项：**同一段内连续两处以上**再扣，散在全章各处的记下来但不据此判档。

## 二、一级红线（文笔质感排序的硬门槛）

**命中任一条即进"红线组"，红线组一律排在非红线组之下。** 这一条是硬约束：不许因为"某一笔画面写得好"把命中者提上来。

| 编号 | 判据 |
|:--|:--|
| G18 | 正文夹带工作标记（章节编号、项目名、状态、markdown 残留） |
| G16 | 生造词与文言残句（「贪弱地」「此为上限否」） |
| G17 | 成分缺：动词被省掉（「这些话一句都出不来」） |
| G22 | 假反转：制造读者没有的误认，再拿标点当反转 |

**破折号（G45）不计入红线组**，只在所属组内作为减分项——它常出现在合格边缘档，不足以单独判档。

## 三、编辑用红线编号（可判的十六条，命中就写编号）

| 编号 | 判据 |
|:--|:--|
| G13 | 叙述惯性词（好像、顿了顿、嘴角、说不清、微微、轻轻、忽然、深吸一口气）每章每词不超过两次 |
| G14 | 水文：删掉大半后信息与情绪都不损失，那删掉的就是多余的 |
| G15 | 比喻方向：喻体与本体必须不同质、不互斥（"以气比气味""脊梁本是骨"都算错） |
| G16 | 生造词与文言残句（「贪弱地」「此为上限否」） |
| G17 | 话要说完：成分不缺、动词不省（「这些话一句都出不来」应为"说不出来"） |
| G18 | 正文禁工作标记（章节编号、作者术语、markdown 残留） |
| G19 | 情绪不外化就不写，禁止直述（"他非常生气"） |
| G20 | 暴露程度全篇一致（同一类伤害不许一处写"后背一片暗色"、另一处写"肠子流了一地"） |
| G21 | 禁自问自答 |
| G22 | 禁假反转（制造读者没有的误认，再拿标点当反转） |
| G23 | 视角守界，不许写 POV 角色感知不到的信息 |
| G5 | 同场景、同记忆、同开头不许写两遍 |
| G6 | 相邻章结尾禁止同句收尾 |
| G9 | 伏笔三环：异常事实＋当事人当场察觉＋悬置，缺中间环就成漏洞 |
| G27 | 时代语域一致（旧时语境不得出现塑料、蜂窝煤、菜市场、手机） |
| G45 | 正文不用破折号 |

## 四、排序官的四步纪律

1. **先标场景**：给每稿标出主要场景类型（环境／人物／对话／战斗／情感／过渡／日常）。
2. **文笔质感走硬门槛**：先扫一级红线分组，红线组沉底；组内再按"句子有没有增量"互排。
3. **先举证再排序**：每个维度先写 2 至 3 条带位置的证据，再给序。
4. **三个维度各自独立排序**：不做加权求和；两维相反的稿要单独列出并保留，不许抹平。
