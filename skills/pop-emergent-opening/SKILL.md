# pop-emergent-opening

> 涌现流黄金三章试味：**不排章纲、从立项卡直接写三章正文**（2000-2500字/章），再用黄金三章方法论尺做**试味评估**——味道对进滚动写章循环，味道不对调向/重写。产出 `正文/ch001-003.txt`＋`开篇/试味评估.md`。**涌现流位置：Phase 2——立项（seed）后直接写，先于任何规划；评估通过后进写章循环（3a/3b/3c）**。当前版本 v1.1.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

## 这个 Skill 做什么

**职责：把立项卡变成能端给读者的前三章正文，并用黄金三章尺判定"这味道立不立得住"。** 涌现流没有章纲、没有设定、没有账本——写前三章唯一可依据的是立项卡（主角立身一句话＋文风承诺＋模糊灯塔），所有世界观、金手指形态、配角都在这三章里临场长出来。

| 段 | 对谁 | 干什么 | 产出 |
| :-- | :-- | :-- | :-- |
| 试味准备（Step 0） | 对文档 | 消费立项卡，抽写作包（开场画面/文风/灯塔方向） | 每章一句话定位 |
| 直接写（Step 1-3） | 对文档 | 从主角立身画面直接下笔，三章连写，临场造设定 | `正文/ch001-003.txt` |
| 试味评估（Step 4） | 对双方 | 黄金三章尺判定（情绪曲线/五条红线/文风遵守） | `开篇/试味评估.md` |
| 调向决策（Step 5） | 对双方 | 味道对→进写章循环；不对→调向/重写 | 状态.md phase 更新 |

三条根原则：

1. **先写后补，设定临场造**：不排章纲、不先写设定——世界观、金手指、配角在这三章里边写边长。写出的新事实当场记入试味评估的"新长出来的设定"区，供后续 review 回填涌现账本。
2. **文风承诺是唯一稳定锚**：没有章纲兜底，三章的稳定全靠文风承诺——语感跑偏=试味失败，不进入写章循环。
3. **试味是决策不是流程**：三章写完必须给出明确判定（过/调向/重写），"味道不对还继续写"是涌现流最贵的浪费。

**边界**：本 skill 只写前三章＋试味评估；不写章纲（归 outline）、不写后续章节（归 write）、不审中后段。写前三章时不读账本（还没有）、不读任何规划（没有规划）。

**产出**：`正文/ch001.txt`＋`ch002.txt`＋`ch003.txt`（2000-2500字/章，文风承诺渲染）＋`开篇/试味评估.md`（情绪曲线判定＋五条红线＋自检清单＋新长出设定登记＋调向决策）。

**称谓约定（不混叫）**：「试味」=写三章＋评估的整段；「试味评估」=评估文档（判定味道立不立得住）；「调向」=小改（改主角立身/文风承诺后重写三章），不是推翻立项。

## 执行模式

**主 agent 直执写作与评估。** 黄金三章是味道总检验，写与评都由主 agent 亲自做，不派子 agent 代写正文。唯一例外：`pop-snow-research` **主动补采**（跨系列只读调用，不写其文件）——**不设"考据不足才派"门槛**：开篇涉及现实职业/行业/历史场景、前三章场景质感缺真实料、或用户点名要参考某原作细节时，**主动派 research 补采**再下笔；查不到的写"没查到"，不凭空编造。

**共创三态**：

1. **共创态**（默认）：写前可快速确认开场画面（一问，不问也按主角立身画面直接写）；试味评估后把判定端给用户拍板。
2. **代理自定态**（无真人／自动化环境）：agent 直写直评，调向决策标注 `[](agent自定·{原因})`。
3. **降级态**：共创中用户离开——已确认的保持，未确认的降为 agent 自定，降级时刻写进试味评估。

## 怎么操作（SOP 全内联）

### Step 0 消费立项卡（抽写作包）

读 `立项/涌现立项卡.md`，抽出三样：

| 抽什么 | 怎么用 |
| :-- | :-- |
| 主角立身一句话 | 第一章第一幕的画面来源——从这句话直接开场 |
| 文风承诺 | 全三章的渲染腔调＋防漂移禁区，句句对照 |
| 模糊灯塔 | 方向感（从X翻成Y）——不写进前三章正文，只决定"往哪个方向埋第一颗种子" |

开场画面快速确认（可选，一问）：从主角立身画面直接开场 vs 先给环境再带出主角——用户没想法就用前者，不拖延。

**写作包自检**：主角立身能当第一章画面？文风承诺在手上（缺失禁止下笔）？→ 三样齐了才开写。

### Step 1 第一章：从立身画面直接下笔

**只依据**：主角立身一句话。**不依据**：任何设定/金手指预想（没有就临场造）。

- 前 200 字主角出现并做第一个可见行动；前 300 字给出反常/落差/危险/利益/误会中至少一种钩子；800 字内触发核心冲突。
- 场景 ≤ 2 个，互动人物 ≤ 3 个；开头段落写具体事：谁在场、正在发生什么、主角被迫面对什么。
- **第一章任务：让落差被看见**（主角曾经站在哪、现在跌到哪）——落差越大，情绪越重。落差三要素：锚点（坠落前最高光）、现状（坠落后最低谷）、对比触发器（同场景正面碰撞）。
- 世界设定只露"现在这场面需要的那一点"，多一点都不写。
- 章末钩子：最后一句话制造"想知道后来怎么了"。

### Step 2 第二章：让读者捏住一张牌

- **任务：给特权信息**——读者知道但剧中人不知道的信息（身份/未来/能力/视角，择一），在一个具体事件里展示，不靠旁白。
- 金手指（如果这章长出来了）：通过行动效果展现，不是属性面板。
- 特权信息最好与第一章落差直接关联。
- 章末钩子：让读者焦虑"接下来会怎样"。

### Step 3 第三章：还小账，立新标

- **任务：让前两章攒的情绪释放一次**——力量验证/预判兑现/选择宣示，择一还一笔小账。
- 然后立新标：时间标/距离标/状态标，3-10 章内可达成的具体目标。
- 禁止开新地图、铺世界观、拉势力网——前两章的账没还完不聊世界。
- 章末钩子：制造新期待（非重复旧情绪）。

**三章连写纪律**：写完一章不回头改（试味阶段允许粗糙，评估统一算账）；新长出来的设定随手记进"本稿新长出设定"草稿区（ch001-003 写完后并入试味评估）。

### Step 4 试味评估（黄金三章尺）

逐章对照检查，全部落进 `开篇/试味评估.md`（模板 `templates/试味评估.tpl.md`）：

**情绪曲线判定**：

```
第1章 ──→ 第2章 ──→ 第3章
同情    焦虑    满足+期待
落差被看见  特权被握紧  小账被收回
                 新目标被放下
```

- 第一章结束：读者同情主角，想看他翻身
- 第二章结束：读者焦虑，迫切想知道下一步
- 第三章结束：读者满足（小账还了）＋期待（新目标立下）

**五条红线（任一违反=直接判定失败）**：

1. 300 字内无主角
2. 第一章场景 > 2 个
3. 金手指靠旁白介绍（没通过行动展现）
4. 第三章开新地图推世界观
5. 章末无钩子

**文风遵守抽检**：每章抽 2-3 段对照文风承诺——腔调对得上？进没进防漂移禁区？出现"大纲腔"（抽象名词/标签句/压缩句式）=语感跑偏，记档。

**新长出设定登记**：这三章临场长出了哪些世界设定/金手指形态/配角？逐条登记（这是涌现账本的第一批种子，Step 5 交接给 review 回填）。

### Step 5 调向决策

把试味评估端给用户，给明确判定：

| 判定 | 条件 | 动作 |
| :-- | :-- | :-- |
| **过（进写章循环）** | 情绪曲线三拍齐＋五条红线全过＋文风抽检通过 | 状态.md：phase=3a、current_chapter=ch004；新长出设定交 review 回填涌现账本 |
| **调向（小改重写）** | 曲线太平/某章红线差一点/文风轻微漂移 | 按反模式诊断定位问题，调主角立身画面或文风承诺（回 seed 微调或本 skill 内重定），重写受影响章节 |
| **重写（回立项）** | 三章全不对味/文风承诺守不住/主角立身立不住 | 回 pop-emergent-seed 重新对齐主角立身/文风承诺，重走 Phase 2 |

**反模式诊断速查**：

| 症状 | 诊断 | 方案 |
|------|------|------|
| 看了三章不知道主角什么样 | 第一章没有锚点 | 第一章前500字加"主角曾经高光"的具体场景 |
| 金手指出现太突兀 | 第二章没有事件铺垫 | 金手指通过具体事件展现，不是系统弹出 |
| 看了三章不知道要干嘛 | 第三章没有钉目标 | 加可量化的短期承诺（时间/距离/状态） |
| 三章情绪曲线太平 | 落差幅度/特权信息/小账回收不到位 | 回查三要素，重写对应章节 |
| 语感不像文风承诺 | 正文跑偏 | 拿文风承诺拉回，重写跑偏段落 |

**Step 5 质量门**：ch001-003 落盘｜试味评估落盘（情绪曲线/五条红线/文风抽检/新设定登记齐全）｜判定明确且用户拍板｜判定为过时状态.md 已更新。

## 红线

1. **不排章纲直接写**：前三章没有章纲，从立项卡直接下笔；写完才评，边写边评=写不动。
2. **文风承诺是唯一稳定锚**：缺失禁止下笔；语感跑偏=试味失败。
3. **设定临场造、当场登记**：不回头补设定；新长出设定必须进试味评估，交 review 回填账本。
4. **五条红线不可破**：300字内无主角/第一章场景>2/金手指靠旁白/第三章开新世界/章末无钩子。
5. **试味必须给明确判定**：过/调向/重写三选一，禁止"还行，继续写"。
6. **research 主动触发**：开篇涉现实考据（现实职业/行业/历史场景）或场景质感缺真实料即主动派 pop-snow-research（跨系列只读调用，不写其文件），不设"考据不足才派"门槛；查不到写"没查到"，不凭空编造。
