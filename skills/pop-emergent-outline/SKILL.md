# pop-emergent-outline

> 涌现流轻量章纲：**只定接下来 1-3 章**（每章 3-5 个事件节点），从**涌现账本＋模糊灯塔**临场生成——不拆卷、不排全书、不翻前期规划（没有前期规划）。产出 `章纲/ch{NNN}-章纲.md`。**涌现流位置：Phase 3a——滚动写章循环第一步；章纲是 write 的起跳板不是锁链，write 临场写偏由 review 记账本、账本再回喂本环节**。当前版本 v1.1.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

## 这个 Skill 做什么

**职责：从已发生的事实（涌现账本）推演"接下来该发生什么"，给 write 一个轻量起跳板。** 灯塔流的章纲从卷纲拆、管"这章在幕/卷里承担什么"；涌现流没有卷纲，章纲只回答三个问题：主角现在在哪、什么线悬着、接下来 1-3 章往哪冒。

| 段 | 对谁 | 干什么 | 产出 |
| :-- | :-- | :-- | :-- |
| 消费账本（Step 0） | 对文档 | 读涌现账本当前态＋上一章章日志＋模糊灯塔＋用户意图 | 推演输入（悬着的线/主角处境） |
| 临场生成（Step 1） | 对文档 | 从悬线＋处境＋灯塔方向推 1-3 章事件 | 事件草案 |
| 写章纲（Step 2） | 对文档 | 按轻量模板落盘（每章功能位/舞台/事件节点/章末钩） | `章纲/ch{NNN}-章纲.md` |
| 自检存档（Step 3） | 对双方 | 描述约束铁律＋容量红线（≤3章）自检 | 存档＋交付 write |

三条根原则：

1. **只排 1-3 章**：涌现流没有远排——章纲是"最近几步怎么走"，不是"全书怎么走"。排多了=偷偷回灯塔流。
2. **事实只从账本取**：悬着的线、人物状态、已长出的设定全在涌现账本；章纲不新造与账本冲突的事实，新造的设定写中长（write 现场长）。
3. **章纲是起跳板不是锁链**：事件节点定"往哪冒"，write 有权临场改向（人物自己长/情节自己冒）；写偏了 review 记账本，账本回喂本环节——章纲错了改章纲，不是改账本。

**边界**：只产轻量章纲；不排伏笔台账（悬线明细在账本）、不写白描、不预写台词；超出 3 章的排期禁止；卷纲/方向总表归转灯塔流后由 pop-lantern-plot 产。

**产出**：`章纲/ch{NNN}-章纲.md`（一次可含接下来 1-3 章，每章一节）。

**称谓约定（不混叫）**：「轻量章纲」=本环节产出（1-3章、3-5事件节点/章）；「涌现账本」=已发生事实唯一承载（章节日志/涌现账本.md）；「悬着的线」=账本里记的未收线（对应灯塔流的伏笔，涌现流不另建台账）。

## 执行模式

**主 agent 直执章纲。** 推演事件是创作，不派子 agent。唯一例外：`pop-snow-research` **主动补采**（跨系列只读调用，不写其文件）——**不设"考据不足才派"门槛**：排章纲遇专业场景/新地域/新行业、事件需要真实冲突原型或行业运作流程、或用户点名要考据某设定时，**主动派 research 补采**再落章纲；查不到的写"没查到"，不凭空编造。

**共创三态**：

1. **共创态**（默认）：章纲产出后把 1-3 章事件草案端给用户瞄一眼（不问也行，用户没想法就直接排）；大方向争议（要不要收某条线）用户拍板。
2. **代理自定态**（无真人／自动化环境）：agent 自推自排，标注 `[](agent自定·{原因})`。
3. **降级态**：共创中用户离开——保持已确认，未确认降为 agent 自定。

## 怎么操作（SOP 全内联）

### Step 0 消费账本（推演输入）

读四样：

| 读什么 | 取什么 |
| :-- | :-- |
| `章节日志/涌现账本.md` | 当前态：主角现在在哪/什么线悬着/已长出的设定/人物状态 |
| 上一章 `章节日志/ch{NNN-1}.md` | 上一章停在哪/章末钩是什么（新章纲的钩不得重复它） |
| `立项/涌现立项卡.md` | 模糊灯塔（方向感）＋文风承诺（情绪基调参照） |
| 用户本轮意图 | 覆盖默认（"写推进""收那条线""写日常"） |

**推演三问**（对账本问）：

1. 现在哪条悬着的线最该动？（账本"悬着的线"里最长没动的那条优先）
2. 主角当前处境推着他必须面对什么？（从账本人物状态推，不是从设定推）
3. 往哪个方向冒，最接近模糊灯塔？（灯塔只给方向感，不给路线）

答不上第 1 问=账本没有悬线，说明上一章收干净了——从主角当前处境自己造一条线（涌现流允许新线自己冒）。

### Step 1 临场生成 1-3 章事件

按推演三问的答案，生成接下来 1-3 章的事件草案：

- **每章 3-5 个事件节点**，按推进顺序：{发生什么}→{转折}→{落点}。
- 章与章之间留连续性：第 N 章章末钩 = 第 N+1 章的起手（或显式换线）。
- 新设定在这步不造：事件需要新东西（金手指新用法/新人物）就标"写中临场长"，不提前定形。
- 1-3 章的量怎么定：情绪弧（小高潮 2-3 章一个）收在哪章，就排到哪章；一般 3 章一坨，用户只让写 1 章就排 1 章。

### Step 2 写轻量章纲

按模板落 `章纲/ch{NNN}-章纲.md`（模板 `templates/轻量章纲.tpl.md`），每章一节：

| 块 | 填什么 | 判据 |
| :-- | :-- | :-- |
| 功能位 | 推进主线/蓄力/爆发/过渡/揭示 | 一句话，定位这章干嘛 |
| 情绪基调 | 爽/揪心/意外/紧绷/甜 | 参照文风承诺的赛道味 |
| 舞台 | 时间×地点×在场人物（每人一句） | 从账本取，不新造 |
| 事件节点 | 3-5 个：{事件}→{转折}→{落点} | 只定事，不定动作细节/台词/心理 |
| 当前任务 | 主角本章一个具体可执行动作（一句） | 强化"每章 ≥1 决策+1 行动" |
| 章末钩 | 类型（悬念/危机/反转/期待/情感/信息）＋一句 | 与上一章不重复 |

### Step 3 自检＋存档

1. **描述约束铁律**：章纲里出现任何"像正文句子"的表述（动作细节/心理陈述/对白台词/文学落点）=越界，删——write 的活 outline 不代劳，只圈事件和落点。
2. **容量红线**：排期 ≤3 章；单章事件节点 3-5 个，超了拆下一章。
3. **账本一致**：舞台/人物/悬线全部能在账本找到出处，找不到=新造，改从账本取或标"写中长"。
4. **存档**：`章纲/ch{NNN}-章纲.md`（可一文件含多章）；头部「共创状态」按三态标注。

**Step 3 质量门**：1-3 章已排｜描述约束过（无正文句）｜账本一致｜章末钩与上章不重复｜存档落盘。

## 红线

1. **只排 1-3 章**：排多了=回灯塔流；章纲里出现"全书/卷级"排期=违规。
2. **事实只从账本取**：不翻前期规划（没有）、不新造与账本冲突的设定；新设定标"写中长"。
3. **描述约束不可破**：章纲只圈事件和落点，动作细节/心理/对白/意象归 write。
4. **章纲可偏离**：write 临场改向不算事故，review 记账本后账本回喂本环节；禁止为了"章纲正确"压死写章。
5. **research 主动触发**：排章纲遇专业场景/新地域/新行业、或事件缺真实冲突原型/行业运作流程时，主动派 pop-snow-research 补采（跨系列只读调用，不写其文件）再落章纲；不设"考据不足才派"门槛；查不到写"没查到"，不凭空编造。
