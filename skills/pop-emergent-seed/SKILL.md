# pop-emergent-seed

> 涌现流轻量立项：**在 snow seed 基础上做减法**——不产 14 维融合立项稿，只锁三样：主角立身一句话＋文风承诺＋模糊灯塔。故事方向由用户拍板，细节不提前设计，交给写章循环从账本里长出来。当前版本 v1.0.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

## 这个 Skill 做什么

**职责：把用户的模糊想法＋参考，收成一张轻量立项卡。** 顺序不可倒：先问需求，再查底子，后锁三样。产出 `立项/涌现立项卡.md`。

| 段 | 对谁 | 干什么 | 产出 |
| :-- | :-- | :-- | :-- |
| 立项引导（Step 0-2） | 对人 | 收命题问需求，按需求查底子，拍板锁三样 | 需求清单＋底子卡组＋涌现立项卡 |

涌现三样（只锁这三样，其他全放开）：

1. **主角立身一句话**：主角是谁＋要什么＋谁挡着——一句话能说清，写章循环里主角的所有行动都从这句话来。
2. **文风承诺**：腔调一句话＋防漂移禁区——唯一稳定锚。渲染参照固定 `pop-emergent-write/references/文风兜底/辰东.md`（西幻·玄幻史诗纯样文），seed 只定承诺，不选档。
3. **模糊灯塔**：方向感一句话＋3-10 章内可达的第一个标——给写章循环一个方向，不锁细节，不锁卷级剧情。

**不做**：不排卷、不锁根决策（欲望线/压力源/世界结局/最终敌人/伏笔线都不锁）、不产 14 维转录、不设计世界观/力量体系/角色卡——这些全交给写章循环临场长。

**边界**：只锁故事的功能方向，不实名（人物用「主角/反派/配角」占位，命名和细节临场长）、不拆卷不排章（没有卷）。

## 执行模式

**主 agent 直执，禁用子 agent 代跑共创。** 立项是交互最密集的环节——出草案、听意见、改稿必须主 agent 亲自做。唯一例外：纯只读的调研支撑（扫榜、查底子）可派子 agent 回报原始材料，主 agent 消费。

**共创三态**：

1. **共创态**（默认）：用户在场，每步端候选给用户圈定，拍板定稿。
2. **代理自定态**（无真人／自动化环境）：agent 逐层自出草案、自审自拍，串行推进。拍板栏显式标注 `[](agent自定·{原因})`，禁止伪造"用户说过"。
3. **降级态**：共创中用户离开——已拍层保持用户意见，未拍层降为 agent 自定，降级时刻写进共创记录。

所有产出物头部「共创状态」按三态如实标注。

## 怎么操作（SOP 全内联）

### Step 0 收命题、问需求

**产品形态先说清**：家里产品直接进 AI 对话，没有前置表单——用户开口那句话就是全部输入。所以立项第一步是问，不是读字段。

先收再问：

1. **收命题**：用户进对话说的话逐字收下，拆出元素清单。
2. **盘已有**：项目内资产（调研采风、拆书报告、旧大纲、`pop-emergent-write/references/文风兜底/辰东.md` 固定文风档）、用户历次裁决记录。已确认的不重问，已有的不重查。
3. **问缺口**：命题说不清的，分轮问，一轮两三问，每问给 2-4 个选项、至少一个标推荐：

   - 想写什么流／什么题材（命题只给模糊方向时，凭常识给流派候选让用户挑；这一步只定方向，不做深度调研）
   - 给谁看（男频／女频，主分类方向）
   - 读者点开这本书图什么（方向级一句即可，不必精确）
   - 篇幅量级（目标章数，几卷量级即可——涌现不排卷，只用来估节奏）

产出**需求清单**：什么流、给谁看、图什么、多长。**需求清单没经用户确认，不开查底子**——调研方向由需求定。

**文风味主档在此收**：涌现流的渲染参照固定写死 `辰东.md`（西幻·玄幻史诗纯样文），不按赛道另选。但文风承诺（腔调一句话）要按本书题材和用户口味定——问用户想要什么腔调（热血/压抑/诙谐/冷峻…），给出候选句。

### Step 1 查底子

按需求清单逐个元素出一张底子卡（模板 `templates/底子卡.tpl.md`）。七栏：

| 栏 | 内容 | 例（神豪流） |
| :----- | :---------------- | :------------------- |
| 定义与定位 | 这个流派是什么，用番茄标签库定流派 | 系统发钱、狂拽平推 |
| 开山与代表作 | 三到五本 | 《重生之神级败家子》… |
| 读者图什么 | 爽点清单，逐项可执行 | 压抑后打脸／扮猪吃虎／消费奇观／平推碾压 |
| 标配零件 | 这个流的世界配置 | 花钱系统、返利公式、打脸递进 |
| 王道走法 | 主流验证过的主线 | 触发→执行→到账，高频短循环 |
| 写烂清单 | 被用滥的点 | 纯炫耀无代价 |
| 组合先例 | 元素组合有没有人写过 | 灵气复苏×财富＝《全球高武》 |

规则：

- **调研清单先经用户确认增删再执行**——调研不是可选项，查什么由用户拍板。
- 检索顺序：wiki 站 `https://wiki.popwave.cn`（卖点方向库、`写作灵感/{赛道}/{书名}/seed-*` 卡）→ web。wiki 命中与 web 新查分区标注。
- 信息源优先级：自有 wiki → 官方资料 → 权威百科 → 垂直百科 → 社区讨论（降权，标"非官方"）。
- 取材预算：单环节 ≤1 轮 / ≤5 query / 回传 ≤30KB，超限截断留结论区。
- 流派定位用 `references/番茄标签库.md` 按需查，不向用户穷举整表。
- 查不到的元素如实说"没查到"，不用脑补顶替。**底子卡没齐，不进 Step 2。**
- 批量查底子走 `pop-snow-research`（跨系列只读调用，不写其文件）。

### Step 2 锁涌现三样（分轮拍板）

分轮与用户确认，一轮一两问，每问给 2-4 个选项、至少一个标推荐。**三样之外一概不锁**——用户想多定细节时，提醒"涌现流不提前锁，细节写的时候长"，除非用户坚持。

- **轮一·主角立身一句话**：主角是谁＋要什么＋谁挡着。基于 Step 0 的方向和底子卡的"读者图什么"组装，端 2-3 个候选句给用户选。判定：一句话能说清；听的人能说出"这是本XX流的书"。三毒点必验（定金手指倾向时）：任意改根规则型金手指（一出手就是终局）、神转世/天选当理由（机械降神）、丢记忆/丢人性/反噬伤己式副作用（代价由外部世界承担）。
- **轮二·文风承诺**：腔调一句话＋防漂移禁区。腔调按本书题材与用户口味定（固定渲染参照辰东.md，此处只定承诺不选档）；防漂移禁区=明确"禁止漂移到哪"（如"禁止飘成轻快沙雕腔""禁止用现代网络梗"）。
- **轮三·模糊灯塔**：方向感一句话＋3-10 章内可达的第一个标。方向感=这本书往哪走（一句话，如"从弃儿一步步揭开身世，卷进王都的旧案"）；第一个标=3-10 章内可达成的小目标（如"第一次力量觉醒""在城里立住脚"）。**不锁具体情节、不排卷**。

**冲突让用户选（不静默覆盖）**：新需求、新查证或用户新说法，与**已确认的三样／底子卡／历次裁决**冲突时——不断言、不平均处理、不直接覆盖。摆出冲突双方与各自后果，让用户选保留哪条；确认前不写入。（源：Mirror 01 立项沟通纪律）

**只沉淀已确认、留白不阻塞**：用户只答一部分时，只沉淀已确认的，剩余缺口继续保留、登记待补强，不拿"你没答的"当"你默认同意"。留白不阻塞立项完成。

### Step 3 定稿交接

**一道门**：

- **一句话测试**：合上材料，只凭脑子把这本书讲给没读过任何材料的朋友听（100 字左右）——他能复述"主角是谁、要什么、谁挡着、往哪走"才算过。卡壳、只有设定没有事件＝没成型，回 Step 2 重拍。

存档流程：用户逐项确认→拍板→存档 `立项/涌现立项卡.md`（模板见 `templates/涌现立项卡.tpl.md`）→**去AI味后半步**：`python skills/pop-emergent-pipeline/scripts/deai_gate.py 立项/涌现立项卡.md --profile doc --json`（WARN 定位自查，机械项 `--fix`），回复报一行 `去AI味:涌现立项卡|PASS` 或 `WARN×N`。

**载体分流标签**（存档时每项标注，杜绝载体错位，源：Mirror 01 三载体分流）：

- 作品元数据（书名/分类/标签/简介）→ 头部独立块。**分类、标签是元数据，不是写作规则**——不得写进约束块。
- 写作行为约束（POV/每章字数/禁忌/节奏）→ 约束块。**一条管一个维度、可执行、不含空话**。
- 故事事实（主角立身/文风承诺/模糊灯塔）→ 对应块。**不进写作规则、不当长期约束注入**。
- 流程（skill/工作流）不存故事事实——本稿只归档决定，不把任何可执行流程当小说资料写入。

向用户报告交接："涌现立项卡已定，接下来进写章循环：outline 排前 3 章章纲（含开篇三要素＋爽点标注）→ write 写正文 → review 审查回填账本。"加载 pop-emergent-outline 接力。
