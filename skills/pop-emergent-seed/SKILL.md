# pop-emergent-seed

> 涌现流立项。v1.1.0：只锁两样——**主角立身一句话＋文风承诺**，外加**模糊灯塔**（结局方向一句话）；产出 `立项/涌现立项卡.md`，**不产设定、不排卷、不写大纲**。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 这个 Skill 做什么

**职责：把用户的模糊想法问成"可以直接下笔"的最小包——主角立身一句话＋文风承诺＋模糊灯塔一句话。** 顺序：先收命题问需求、再定文风、后立灯塔——不润色用户原话，不提前铺设定。

| 段 | 对谁 | 干什么 | 产出 |
| :-- | :-- | :-- | :-- |
| 立项引导（Step 0-1） | 对人 | 收命题问需求，对齐文风承诺 | 涌现立项卡·主角立身一句话＋文风承诺 |
| 灯塔定调（Step 2） | 对双方 | 立模糊灯塔（结局方向一句话）＋不设清单 | 涌现立项卡·模糊灯塔 |
| 定稿交接（Step 3） | 对双方 | 三问自检、一句话讲述测试 | `立项/涌现立项卡.md` |

三条根原则：

1. **只锁两样＋模糊灯塔**：主角立身一句话（什么人＋处境＋凭什么读者要看他）＋文风承诺（这本书的叙事腔调）——没有这两样没法下笔；模糊灯塔只到"结局方向一句话"，不设路线、不排卷。
2. **主角立身一句话是下笔的起手**：它是黄金三章第一幕的画面来源，不甩给任何后面的环节（涌现流没有后面的设定环节）。
3. **其余全留白**：设定、卷、章、金手指形态——全不在此定，让它们从写作里长出来。

**边界**：主角立身=一句话（身份＋处境＋凭什么读者要看他），不写小传；金手指不定形态；不拆卷、不排章；世界设定不写——这些全是涌现产物。

**产出**：`立项/涌现立项卡.md`：①主角立身一句话 ②文风承诺（叙事腔调＋禁止漂移到哪）③模糊灯塔（结局方向一句话）④不设清单（显式列出本次没锁的：设定/卷纲/金手指形态——防止后面偷偷补）。

**称谓约定（不混叫）**：「涌现立项卡」=立项唯一产出（替代灯塔流的需求卡+故事脉络+篇幅量级三件）；「模糊灯塔」=结局方向一句话（不是方向总表，没有每卷行）。

## 执行模式

**主 agent 直执，禁用子 agent 代跑共创。** 立项是整条流程交互最密集的环节——出草案、听意见、改稿必须主 agent 亲自做。唯一例外：纯只读的调研支撑（扫榜、拆书包检索、参考材料消化）可派子 agent 回报原始材料，主 agent 消费；`pop-snow-research` 主动补采（跨系列只读调用，不写其文件）。

**共创三态**：

1. **共创态**（默认）：用户在场，每步端候选给用户圈定，拍板定稿。
2. **代理自定态**（无真人／自动化环境）：agent 逐层自出草案、自审自拍，串行推进。拍板栏显式标注 `[](agent自定·{原因})`，禁止伪造"用户说过"。
3. **降级态**：共创中用户离开——已拍层保持用户意见，未拍层降为 agent 自定，降级时刻写进共创记录。

所有产出物头部「共创状态」按三态如实标注。

## 怎么操作（SOP 全内联）

### Step 0 收命题、问需求

先收再问：

1. **收命题**：用户进对话说的话逐字收下，拆出元素清单。
2. **盘已有**：项目内资产（`pop-snow-write/references/文风兜底/` 的现成文风档、`素材/文风锚定.md`、旧案底）、用户历次裁决记录（同类问题他怎么判过）。已确认的不重问，已有的不重查。
3. **问缺口**：命题说不清的，分轮问，一轮一两问，每问给 2-4 个选项、至少一个标推荐：
   - 主角是谁、读者第一眼看到什么（一句话画面；问不出就按命题里的元素给 2-3 个候选画面让用户挑）
   - 这本书的味道/文风照谁（点名书/作者/口味 → 查文风兜底库命中；没想法按题材赛道默认推荐）

产出 **涌现立项卡·主角立身一句话**（全用户语言，不掺行话）：

| 字段 | 填什么 | 判据 |
| --- | --- | --- |
| 主角立身 | 一句话：什么人＋处境＋凭什么读者要看他 | 能当第一章第一幕的画面；换成路人故事立刻不成立=立住 |
| 文风承诺 | 一句话叙事腔调＋禁止漂移到哪 | 能防漂移；正文跑偏时能拿它拉回 |

**主角立身一句话（核心，下笔起手）**：

- **是A**：立项级决策——"什么人＋处境＋凭什么读者要看他"，能直接变成第一章画面的一句话。
- **不是B**：金手指形态（档位表/能力细节/奇遇）、小传、成长史——全是涌现产物，写中长出来。
- **判据**：把主角换成书里任何一个路人，故事立刻不成立 = 立住；换成谁都行 = 没立住，回问。
- **提问句式（大白话）**："这个主角第一眼是谁、在什么处境里？读者凭什么想看他继续？"（问题就这一个，问透它）

**文风承诺（必锁，涌现流唯一稳定锚）**：

- 涌现流没有章纲/设定兜底正文稳定，**文风承诺是正文唯一稳定锚**——缺失禁止下笔。
- 来源优先级：①用户点名书/作者/口味 → `pop-snow-write/references/文风兜底/` 命中档（跨系列只读调用，不写其文件）②用户给文风锚定素材 → 校验后作承诺 ③默认按题材赛道选档。
- **文风参照主动搜**：用户点名书/作者/口味但文风兜底库没命中档时，**主动派 `pop-snow-research` 搜样文/文风参照**（同赛道名作开篇、作者文风评析）回填承诺——不只在考据不足时才派（research 是三方共用基建，涌现任何环节可主动触发）。
- 承诺写法：{腔调一句话}＋{禁止漂移到哪}（如"冷硬克制的第三人称，禁止甜宠腔""热血流打脸向，禁止文艺腔"）。

### Step 1 查底子＋赛道校准（主动搜·按需）

涌现流不铺设定，但**赛道底子**仍要查（回答"这套路读者图什么、什么写烂了"）——按用户给的方向出底子卡，来源：番茄标签库（`pop-snow-seed/references/番茄标签库.md` 跨系列只读）、拆书报告、扫描榜单；**库内不够或要实时行情时主动派 `pop-snow-research` 补**（赛道盘子/竞品/读者口味，数据纪律：标平台/榜型/日期/样本数）。

**research 主动触发点**：①查底子库内不够（赛道定义/代表作/读者图什么/写烂的点）②用户点名参考书/IP 要消化五件套（终点形态/核心危机/敌人谱系/主角特殊性/结构节奏）③文风参照没命中档。触发即派（跨系列只读调用，不写其文件）；查不到的写"没查到"，不凭空编造。

> 底子卡只作背景理解，不进立项卡——立项卡只锁两样＋模糊灯塔。

### Step 2 立模糊灯塔＋不设清单

- **模糊灯塔**：结局方向一句话（从 X 翻成 Y，不锁路线）。问法："这本书最后大概翻到哪？"用户说不出就用主角立身反推（脱颖而出 → 终极兑现）。判据：只有一句话、能说清"从哪翻到哪"；没有每卷行、没有路线。
- **不设清单**：显式列——不锁：设定（从账本长）、卷纲（不排）、金手指形态（写中长）、配角/反派（写中长）。写进立项卡，防后续环节偷偷补（涌现流最怕"写两章后又回去铺设定"）。

### Step 3 自检＋落盘

1. **三问自检**：主角立身一句话能当第一章画面吗？文风承诺能防漂移吗？模糊灯塔只有一句话吗（没偷排路线）？
2. **一句话讲述测试**："这本书讲了个XX的故事，主角是XX"——讲不清=没立住，回填。
3. **存档**：`立项/涌现立项卡.md`（模板 `templates/涌现立项卡.tpl.md`），头部「共创状态」按三态标注。

**Step 3 质量门**：立项卡落盘｜三问全过｜一句话讲述用户认可｜未越界（设定/卷纲/金手指未提前定）｜research 触发点已答（查不到的写"没查到"）。

## 红线

1. **只锁两样＋模糊灯塔**：设定/卷/章/金手指形态一律不锁，锁了=回退成灯塔流。
2. **主角立身一句话是下笔起手**：能当第一章画面，不能当小传；凭什么读者要看他必须问透。
3. **文风承诺必锁**：涌现流没有章纲/设定兜底时，文风承诺是正文唯一稳定锚，缺失禁止下笔。
4. **不润色**：立项卡全用户语言；拍板栏按共创三态如实标注，禁止伪造"用户说过"。
5. **research 主动触发**：查底子/文风参照/现实考据都可主动派 pop-snow-research（跨系列只读调用，不写其文件）；查不到写"没查到"，不凭空编造。
