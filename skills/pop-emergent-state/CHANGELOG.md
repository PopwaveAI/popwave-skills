## v1.0.0 | 2026-09-11

### 涌现流重建·设定装配台首版

新增 state 环节（老板拍板流程重构：seed 甲方文档 → state 设定装配 → outline 情绪章纲 → write 正文 → review 章日志+账本）：

- **设定不创造只装配**：读 seed 甲方文档（题材/读者/卖点/主角立身一句话），从内容模板库选配世界底子——力量体系/世界观结构/金手指/身份结构，每条模板标代表作出处（从真正小说抽离），不让 agent 凭空发明。
- **产出《世界装配单.md》**（立项/）：选了哪些模板＋改了哪些参数，世界底子的唯一来源；写章中长出的新设定继续从内容模板库选并记入涌现账本。
- **配套**：`references/内容模板库.md`（五块模板：力量体系/世界观/金手指/身份/剧情事件套路库，标代表作）、`templates/装配单.tpl.md`。
- **不做**：不写长线剧情（plot 砍了）、不排卷、不锁伏笔线、不做角色卡。
