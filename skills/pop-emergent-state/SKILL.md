# pop-emergent-state

> 本技能只规定流程、文件契约与检查项，不规定题材、结构、风格或审美偏好。
> 本技能是涌现流的世界底子登记台：读取 seed 甲方文档与项目已有资料，逐项生成候选交用户拍板，产出《世界装配单.md》。设定只记录用户确认与资料支撑的内容，不由本环节发明故事方向。当前版本 v2.0.1（2026-10-23：瘦身为流程层，模板库降为可选参考）。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

---

### 候选交付纪律（贯穿本技能）

- **先列缺口。** 写清本次要定哪几件（力量体系、世界观结构、金手指、身份结构，可按用户要求增减），再列已有资料覆盖了哪些。二者之差即缺口。
- **缺口才取材。** 缺口内先查项目资料（`调研采风/`、`原始资料/`、用户口述、wiki），不足时再补检索。检索项自拟；来源优先内部 wiki 站 `https://wiki.popwave.cn`，不足时再查网络。单个环节最多取材一轮，一轮最多五个检索项，回传不超过 30KB，超出即截断只留结论。
- **候选附依据。** 每个候选写明依据（用户原话、资料路径、作品先例）；无依据的候选标「临场拟」。最终选定由用户拍板。
- **不做打分排名。** 只并列候选与依据，不替用户评优劣。
- **交付后复检一次。** 自查是否漏项、依据是否可回源；用户拍板即定稿。

取材内容仅进入上下文，仅当用户采纳后方可写入产出。

## 职责范围

| 项 | 内容 |
| :- | :-------------------------------------- |
| 定位 | 世界底子登记台：把立项卡、用户素材与资料收成装配单 |
| 输入 | seed 甲方文档（`立项/涌现立项卡.md`：题材、读者、卖点、主角立身一句话）、项目资料（`调研采风/`、`原始资料/`、用户口述）、可选参考 `references/内容模板库.md` |
| 输出 | `立项/世界装配单.md`（记录定了哪些件、依据是什么、哪些还没定，是世界底子的唯一来源） |
| 下游 | outline（排章纲时引用装配单）、write（写正文时遵守装配单）、review（写章中长出的新设定记入账本） |

**本环节存在的理由**：涌现流做减法，但世界底子不能在每次写章时临场乱造。装配只在开书时执行一次；写章中长出的新设定继续登记。

**装配纪律**：

1. **有据可循。** 每个件先查已有资料与用户素材；查不到时按当前任务生成候选，在装配单中标注「临场拟」。
2. **标出处。** 每条装配注明依据：用户口述、资料路径或作品先例。
3. **不做的事项。** 不写长线剧情、不排卷、不锁伏笔线、不做角色卡、不产出复杂设定文档。

**执行方式**：由主 agent 直接执行。读取立项卡与项目资料，给出候选交用户圈定，用户拍板后产出装配单。

## 操作步骤（规程全内联）

### Step 0：读取 seed 甲方文档（需求源头）

读取 `立项/涌现立项卡.md`，抽取以下依据：
- 题材与方向
- 卖点（读者图什么）
- 主角立身一句话（主角是谁、要什么、谁挡着；装配出的世界须能装下这句话）
- 用户本轮要求（存在特殊约束时，以用户要求为准）

**立项卡缺失时**：先退回 seed 补充；用户坚持直接装配时，按用户口述生成候选，装配单对应项标「待回填立项卡」。

### Step 1：按装配件列缺口与候选

逐件对照已有资料，列出缺口，再按缺口生成候选，每件给 2-3 个交用户择取：

| 装配件 | 候选来源 | 依据 |
|:--|:--|:--|
| 力量体系 | 立项卡、用户素材、调研采风、原始资料、可选参考索引 | 用户原话 / 资料路径 / 作品先例 |
| 世界观结构 | 同上 | 同上 |
| 金手指 | 同上 | 同上 |
| 身份结构 | 同上 | 同上 |

- 用户要求增减装配件时，按用户要求执行。
- 用户仅答部分时，只记已确认的部分，其余标「待定」，不阻塞（留白即该件不开，写章时再定）。

### Step 2：逐件确认并记录

按用户圈定的结果逐件写入，每件照以下格式：

```markdown
### 力量体系
- 选定内容：{名称与要点}
- 依据：{用户口述 / 资料路径 / 作品先例}
- 参数与约束：{改了什么，全文统一用什么}
- 待定：{未定部分}
```

**自洽检查。** 改动名称、层级或结构后，全文须统一使用新名；装配单是唯一基准，write 不得另行发明一套。

### Step 3：产出装配单并存档

将装配单写入 `立项/世界装配单.md`（格式见下）。

向用户报告交接：装配完成。接下来由 outline 排章纲，write 写正文，review 审查并回填账本。加载 pop-outline 接力。
