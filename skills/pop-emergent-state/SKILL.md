# pop-emergent-state

> 涌现流设定装配台：**设定不创造、只装配**——读 seed 甲方文档，从内容模板库里选模板（力量体系/世界观结构/金手指/身份结构），配出《世界装配单.md》。模板是内容层的成熟套路（从真正小说里抽离），不让 agent 凭空发明。当前版本 v1.0.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。
- **Pack**：缺口足够才取材，query 自生成；来源 **wiki 站 https://wiki.popwave.cn** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query / 回传 ≤30KB，超限截断仅留结论区。
- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版，不越权定终局。
- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

## 做什么

| 项 | 内容 |
| :- | :-------------------------------------- |
| 定位 | 设定装配台——从内容模板库**选配**世界底子，不是创造设定 |
| 输入 | seed 甲方文档（`立项/涌现立项卡.md`：题材/读者/卖点/主角立身一句话）＋内容模板库（`references/内容模板库.md`） |
| 输出 | `立项/世界装配单.md`（选了哪些模板＋改了哪些参数——世界底子的唯一来源） |
| 下游 | outline（情绪标准→排事件时引用装配单）、write（写正文时遵守装配单）、review（长出的新设定继续从库选并记账本） |

**为什么有这一环**：涌现流做减法，但"世界长什么样"不能每次写章临场乱长——力量体系/世界观这类**结构件**从经市场验证的模板里选配，读者秒懂、爽感天然成立。装配只做一次（开书时），写章中长出的新设定继续从库选。

**装配纪律**：
1. **选配不发明**：每个需要装配的件，先在内容模板库里找模板；库里没有才临场造，且装配单里显式标"无模板，临场造"。
2. **标出处留痕迹**：每条装配注明"选了哪个模板（代表作）+改了哪些参数"——防止把网文惯例说成首创。
3. **不做**：不写长线剧情（plot 砍了）、不排卷、不锁伏笔线、不做角色卡、不产复杂设定文档。

**执行模式**：主 agent 直执。读 seed 甲方文档＋内容模板库，出候选给用户圈定（共创态），拍板后出装配单。

## 怎么操作（SOP 全内联）

### Step 0：读 seed 甲方文档（需求源头）

读 `立项/涌现立项卡.md`，抽取装配依据：
- 题材/赛道（决定选哪类力量体系模板）
- 读者图什么（卖点：爽点来源，决定金手指/身份结构方向）
- 主角立身一句话（主角是谁＋要什么＋谁挡着——装配的世界要能装下这句话）
- 用户本轮要求（有特殊约束以用户要求为准）

**seed 缺失【禁止】装配**：先回 seed 补甲方文档，不许自己猜题材。

### Step 1：读内容模板库，按题材选候选

读 `references/内容模板库.md`，按 seed 的题材/卖点圈候选（每类圈 2-3 个端给用户选）：

| 装配件 | 对应模板块 | 选配依据 |
|:--|:--|:--|
| 力量体系 | 一、力量体系模板（修仙/斗气/武道/异能/血脉） | 题材决定；卖点决定细度 |
| 世界观结构 | 二、世界观结构模板（三界/宗门/势力盘/地图推进） | 长线需求决定；不锁长线剧情 |
| 金手指 | 三、金手指模板（系统/穿越/老爷爷/面板/吞噬） | 卖点+主角立身决定 |
| 身份结构 | 四、身份结构模板（废柴逆袭/身世之谜/扮猪吃虎） | 主角立身一句话决定 |

**共创态**：每类端候选+推荐给用户圈定；用户只答部分时只沉淀已确认，剩余留白不阻塞（留白=该件不装配，写章时从库现选）。

### Step 2：装配（逐件定，标模板+参数改动）

按用户圈定，逐件装配，每件格式：

```markdown
### 力量体系
- 选用模板：1.1 修仙境界体系（练气→筑基→金丹→元婴→化神）——《凡人修仙传》为代表作
- 参数改动：境界名沿用；每境小阶改"九层"→"三层"；破境方式=天劫
- 未覆盖处：合体期后设定临场从库续选
```

**参数改动自洽铁律**：改境界名/地图名/套路结构后，全文统一用新名；装配单是唯一基准，write 不得另发明一套。

### Step 3：出装配单＋存档

存档 `立项/世界装配单.md`（格式见下）。**存档后半步=去AI味**：`python skills/pop-emergent-pipeline/scripts/deai_gate.py 立项/世界装配单.md --profile doc --json`——WARN 定位自查、机械项 `--fix`，结果一行 `去AI味:世界装配单|PASS` 或 `WARN×N`。

向用户报告交接：装配完成，接下来 outline 按情绪标准排章纲（查心跳库定本章情绪点→反向设计剧情）→ write 写正文 → review 审查回填账本。加载 pop-emergent-outline 接力。

## 世界装配单格式

```markdown
# 世界装配单

> producer: pop-emergent-state ｜消费：outline/write/review ｜装配日期：{日期}
> 规则：装配单=世界底子的唯一来源；写章中长出的新设定继续从内容模板库选，选了什么记入涌现账本"已长出设定"。

## 甲方文档摘要（摘自涌现立项卡）
- 题材：{仙侠/玄幻/都市…}
- 读者图什么：{卖点一句}
- 主角立身一句话：{原文}

## 一、力量体系
- 选用模板：{模板名+代表作}
- 参数改动：{逐条}
- 无模板临场造：{若有}

## 二、世界观结构
- 选用模板：{模板名+代表作}
- 参数改动：{逐条}

## 三、金手指
- 选用模板：{模板名+代表作}
- 参数改动：{逐条}

## 四、身份结构
- 选用模板：{模板名+代表作}
- 参数改动：{逐条}

## 未装配项（留白）
- {哪些件没装配，写章时从库现选}
```
