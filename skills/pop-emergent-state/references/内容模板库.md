# 内容模板库（题材层成熟套路·从真正小说抽离）

> 用途：涌现流 state 装配台的选配库——写书需要的世界观/力量体系等**从库里选模板装配，不让 agent 凭空创造**。也是 outline 反向设计剧情时的套路库。内容模板＝题材素材套路（写什么），不是流程结构（怎么组织）。每条标代表作/通用出处，不许凭空造。
> 消费方式：state 按题材挑模板→装配单；outline 按情绪点挑事件套路→章纲。模板只是候选，装配单/章纲里注明"选了哪个模板、改了哪些参数"。

## 一、力量体系模板（境界阶梯）

### 1.1 修仙境界体系（练气→化神）
- **阶梯**：练气 → 筑基 → 金丹 → 元婴 → 化神 →（渡劫 → 大乘 → 真仙）
- **特征**：每境有小阶（如练气一层~九层）；破境有大坎（结丹/元婴天劫）；寿元随境界涨
- **代表作**：《凡人修仙传》（忘语）为发扬者；源自道教修炼术语（炼精化气、炼气化神）
- **适用**：仙侠 / 修真 / 古典玄幻
- **参数可改**：境界名、每境小阶数、破境方式（天劫/心魔/丹药）

### 1.2 斗气体系（斗者→斗帝）
- **阶梯**：斗者 → 斗师 → 大斗师 → 斗灵 → 斗王 → 斗皇 → 斗宗 → 斗尊 → 斗圣 → 斗帝
- **特征**：每阶有明确战力量化（斗者一掌碎石、斗王能飞）；高阶靠机缘/传承突破
- **代表作**：《斗破苍穹》（天蚕土豆）
- **适用**：东方玄幻
- **参数可改**：阶名、每阶细分（九星）、能量名（斗气/元气/灵力）

### 1.3 武道境界体系（淬体→大宗师）
- **阶梯**：淬体 → 通脉 → 聚气 → 先天 → 宗师 → 大宗师 →（武圣）
- **特征**：前期打熬肉身，中期内力外放，后期以武入道；重招式与心法
- **代表作**：武侠/国术通用（《龙蛇演义》国术境界、《武动乾坤》武学体系）
- **适用**：武侠 / 武道 / 国术 / 都市武者
- **参数可改**：境界名、是否分品（一品武者~九品）

### 1.4 异能分级体系（F→SSS）
- **阶梯**：F → E → D → C → B → A → S → SS → SSS
- **特征**：按觉醒能力强度分级；能力类型多样（元素/念力/强化）；S 级是分水岭
- **代表作**：日漫/都市异能通用（《一拳超人》英雄协会 S/A/B/C 级）
- **适用**：都市异能 / 末世 / 超能力
- **参数可改**：级名、S 级以上是否设传说级

### 1.5 血脉/觉醒体系（凡血→神血）
- **阶梯**：凡血 → 灵血 → 王血 → 圣血 → 神血（或武魂/神格觉醒）
- **特征**：血脉决定上限与天赋；觉醒仪式定终身；高阶血脉可碾压低阶
- **代表作**：《斗罗大陆》武魂觉醒（唐家三少）、《完美世界》凶兽血脉
- **适用**：玄幻 / 斗气类 / 学院流
- **参数可改**：血脉名、觉醒方式（仪式/机缘/吞服）

## 二、世界观结构模板（地图/组织）

### 2.1 三界/飞升结构
- **结构**：人间界 → 灵界/仙界 → 神界；境界到了飞升换图
- **特征**：下界争的东西上界不值钱；飞升=换地图+旧恩怨难追
- **代表作**：《凡人修仙传》（人界→灵界→仙界）、《遮天》（红尘仙）
- **适用**：修仙 / 玄幻长线
- **参数可改**：界数、飞升条件、界间通道

### 2.2 宗门结构
- **结构**：外门 → 内门 → 真传/亲传 → 长老 → 宗主；资源按层分配
- **特征**：入门有考核；外门靠任务换资源；真传有靠山
- **代表作**：《凡人修仙传》黄枫谷/落云宗、《斗破苍穹》迦南学院
- **适用**：仙侠 / 学院流 / 宗门流
- **参数可改**：层级名、入门门槛、资源分配方式

### 2.3 势力盘结构（五方制衡）
- **结构**：宗门 / 王朝 / 世家 / 散修 / 魔道（或黑道）五方并立，互相制衡
- **特征**：主角起于底层（散修/小世家），一路卷进各方博弈
- **代表作**：《斗破苍穹》加玛帝国（宗门+皇室+世家+散修+魔道）、《雪中悍刀行》庙堂+江湖
- **适用**：玄幻 / 仙侠 / 武侠
- **参数可改**：势力方数、主角出身方

### 2.4 地图推进结构（新手村→上界）
- **结构**：新手村/小城 → 主城/帝国 → 大陆 → 上界；每换一图升一档对手
- **特征**：前期小冲突、后期大格局；旧地图的人追不上新地图
- **代表作**：《斗破苍穹》（乌坦城→加玛帝国→中州→大千世界）、《遮天》（地球→北斗→星空）
- **适用**：升级流 / 玄幻长线
- **参数可改**：地图层数、换图节奏

## 三、金手指模板

### 3.1 系统流
- **形态**：绑定系统，任务+奖励+商城/抽奖；宿主执行任务得积分换能力
- **代表作**：《超神机械师》（系统+面板）、《我修的可能是假仙》（系统修仙）
- **参数可改**：系统类型（任务/加点/抽奖/商城）、惩罚机制

### 3.2 穿越/重生
- **形态**：现代人魂穿/带记忆重生；信息差+前世知识=先手
- **代表作**：《斗破苍穹》（萧炎穿越）、《庆余年》（范闲带现代知识）、《重生之贼行天下》
- **参数可改**：穿越方式、保留多少记忆、是否带现代物品

### 3.3 随身老爷爷/空间
- **形态**：戒指/玉佩里住着高人（导师），或随身空间（可进人/种田/藏物）
- **代表作**：《斗破苍穹》药老（戒指老爷爷）、随身空间流
- **参数可改**：导师形态（灵魂/器灵/系统音）、空间功能（种田/修炼/藏宝）

### 3.4 面板/加点流
- **形态**：数据面板+属性点，杀怪/修炼得点，自己分配
- **代表作**：《全球高武》（面板+属性）、《惊悚乐园》类无限流面板
- **参数可改**：面板项目（力量/敏捷/精神）、点数来源

### 3.5 吞噬/复制流
- **形态**：吞噬他人血脉/能力/修为为己用；或复制接触过的能力
- **代表作**：《吞噬星空》（吞噬流）、《无限恐怖》复制强化
- **参数可改**：吞噬限制（同阶才能吞/有反噬）、复制条件

## 四、身份结构模板

### 4.1 废柴逆袭
- **结构**：天才陨落/天赋被废 → 受尽羞辱 → 奇遇翻身 → 崛起 → 打脸旧敌
- **代表作**：《斗破苍穹》萧炎（三年之约）
- **配套**：多配打脸流套路，退婚/逐出族谱当触发点

### 4.2 身世之谜
- **结构**：孤儿/小人物 → 身世线索断续浮现 → 揭示大势力遗孤/神界后人 → 身份公开震动
- **代表作**：玄幻通用（《遮天》叶凡身份、《雪中悍刀行》徐凤年身世）
- **配套**：身份公开=9-10 级心跳事件，留给大高潮

### 4.3 扮猪吃虎
- **结构**：隐藏实力 → 被轻视/嘲讽 → 关键时刻碾压 → 围观者震惊
- **代表作**：网文通用（退婚流、装逼流底层结构）
- **配套**：配打脸流；碾压前必须有"参照物"垫高（先写敌人多强）

## 五、剧情事件套路库（outline 反向设计用）

> 用法：outline 定好本章情绪坐标（查剧情-情绪打分表）后，按情绪线挑套路倒推事件；套路只是骨架，具体化由 outline 排事件、write 写正文。

| 套路 | 结构 | 对应情绪线 | 代表作 |
|:--|:--|:--|:--|
| 退婚流 | 被退婚/被逐 → 立誓 → 崛起 → 打脸当初之人 | 爽（打脸） | 《斗破苍穹》 |
| 夺宝流 | 秘境/拍卖会 → 夺宝 → 追杀/争夺 → 到手或失利 | 紧张+爽 | 修仙通用（《凡人修仙传》夺宝） |
| 打脸流 | 被轻视 → 展示实力 → 围观震惊 → 地位变化 | 爽（打脸） | 网文通用 |
| 救人结缘 | 路见不平 → 出手 → 被救方回报/结缘 | 爽+甜 | 通用 |
| 拜师入宗 | 资质被认出 → 入门/拜师 → 资源倾斜 → 地位跃升 | 爽（成长） | 《凡人修仙传》入门 |
| 身份公开 | 秘密被揭开 → 全场立场翻转 → 世界级震荡 | 震惊（9-10 级） | 玄幻通用 |
| 绝境反杀 | 濒死/被围 → 底牌/突破 → 反杀 → 余波（敌人势力反应） | 恐惧→爽 | 通用 |
| 大考/比试 | 登场 → 被轻视 → 轮番碾压 → 名次/威名 | 爽（装逼） | 学院流通用 |

## 使用规则

1. **选配不发明**：state/outline/write 需要设定或事件套路时，先查本库选模板，注明"选了 X 模板+改了 Y 参数"；库里没有才临场造，且临场造的要记"新增事实待 review"。
2. **模板只是骨架**：境界名/地图名/套路结构可改参数，但改完要自洽（改力量体系名=全文统一用新名）。
3. **出处标注**：每条模板标代表作/通用出处，防止把"网文惯例"说成"某书首创"；拿不准标"网文通用"。
4. **与涌现流减法不冲突**：模板是"长设定时的候选来源"，不是"开书前必须填的设定"——seed 只锁三样，state 装配一次，写章中长出的新设定继续从本库选。
