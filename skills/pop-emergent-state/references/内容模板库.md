> 用途：本文件是参考资料，不是必选项，也不是创作要求。state 收世界底子、outline 排章纲时可以查阅，是否取用由当前任务与用户确认决定。

## 一、力量体系结构参考（境界阶梯）

### 1.1 修仙境界体系（练气→化神）
- **阶梯**：练气 → 筑基 → 金丹 → 元婴 → 化神 →（渡劫 → 大乘 → 真仙）
- **特征**：每境有小阶（如练气一层~九层）；破境有大坎（结丹/元婴天劫）；寿元随境界涨
- **代表作**：《凡人修仙传》（忘语）为发扬者；源自道教修炼术语（炼精化气、炼气化神）
- **常见题材**：仙侠 / 修真 / 古典玄幻
- **可改项**：境界名、每境小阶数、破境方式（天劫/心魔/丹药）

### 1.2 斗气体系（斗者→斗帝）
- **阶梯**：斗者 → 斗师 → 大斗师 → 斗灵 → 斗王 → 斗皇 → 斗宗 → 斗尊 → 斗圣 → 斗帝
- **特征**：每阶有明确战力量化（斗者一掌碎石、斗王能飞）；高阶靠机缘/传承突破
- **代表作**：《斗破苍穹》（天蚕土豆）
- **常见题材**：东方玄幻
- **可改项**：阶名、每阶细分（九星）、能量名（斗气/元气/灵力）

### 1.3 武道境界体系（淬体→大宗师）
- **阶梯**：淬体 → 通脉 → 聚气 → 先天 → 宗师 → 大宗师 →（武圣）
- **特征**：前期打熬肉身，中期内力外放，后期以武入道；重招式与心法
- **代表作**：武侠/国术通用（《龙蛇演义》国术境界、《武动乾坤》武学体系）
- **常见题材**：武侠 / 武道 / 国术 / 都市武者
- **可改项**：境界名、是否分品（一品武者~九品）

### 1.4 异能分级体系（F→SSS）
- **阶梯**：F → E → D → C → B → A → S → SS → SSS
- **特征**：按觉醒能力强度分级；能力类型多样（元素/念力/强化）；S 级是分水岭
- **代表作**：日漫/都市异能通用（《一拳超人》英雄协会 S/A/B/C 级）
- **常见题材**：都市异能 / 末世 / 超能力
- **可改项**：级名、S 级以上是否设传说级

### 1.5 血脉/觉醒体系（凡血→神血）
- **阶梯**：凡血 → 灵血 → 王血 → 圣血 → 神血（或武魂/神格觉醒）
- **特征**：血脉决定上限与天赋；觉醒仪式定终身；高阶血脉可碾压低阶
- **代表作**：《斗罗大陆》武魂觉醒（唐家三少）、《完美世界》凶兽血脉
- **常见题材**：玄幻 / 斗气类 / 学院流
- **可改项**：血脉名、觉醒方式（仪式/机缘/吞服）

## 二、世界观结构参考（地图/组织）

### 2.1 三界/飞升结构
- **结构**：人间界 → 灵界/仙界 → 神界；境界到了飞升换图
- **特征**：下界争的东西上界不值钱；飞升=换地图+旧恩怨难追
- **代表作**：《凡人修仙传》（人界→灵界→仙界）、《遮天》（红尘仙）
- **常见题材**：修仙 / 玄幻长线
- **可改项**：界数、飞升条件、界间通道

### 2.2 宗门结构
- **结构**：外门 → 内门 → 真传/亲传 → 长老 → 宗主；资源按层分配
- **特征**：入门有考核；外门靠任务换资源；真传有靠山
- **代表作**：《凡人修仙传》黄枫谷/落云宗、《斗破苍穹》迦南学院
- **常见题材**：仙侠 / 学院流 / 宗门流
- **可改项**：层级名、入门门槛、资源分配方式

### 2.3 势力盘结构（五方制衡）
- **结构**：宗门 / 王朝 / 世家 / 散修 / 魔道（或黑道）五方并立，互相制衡
- **特征**：主角起于底层（散修/小世家），一路卷进各方博弈
- **代表作**：《斗破苍穹》加玛帝国（宗门+皇室+世家+散修+魔道）、《雪中悍刀行》庙堂+江湖
- **常见题材**：玄幻 / 仙侠 / 武侠
- **可改项**：势力方数、主角出身方

### 2.4 地图推进结构（新手村→上界）
- **结构**：新手村/小城 → 主城/帝国 → 大陆 → 上界；每换一图升一档对手
- **特征**：前期小冲突、后期大格局；旧地图的人追不上新地图
- **代表作**：《斗破苍穹》（乌坦城→加玛帝国→中州→大千世界）、《遮天》（地球→北斗→星空）
- **常见题材**：升级流 / 玄幻长线
- **可改项**：地图层数、换图节奏

## 三、金手指结构参考

### 3.1 系统流
- **形态**：绑定系统，任务+奖励+商城/抽奖；宿主执行任务得积分换能力
- **代表作**：《超神机械师》（系统+面板）、《我修的可能是假仙》（系统修仙）
- **可改项**：系统类型（任务/加点/抽奖/商城）、惩罚机制

### 3.2 穿越/重生
- **形态**：现代人魂穿/带记忆重生；信息差+前世知识=先手
- **代表作**：《斗破苍穹》（萧炎穿越）、《庆余年》（范闲带现代知识）、《重生之贼行天下》
- **可改项**：穿越方式、保留多少记忆、是否带现代物品

### 3.3 随身老爷爷/空间
- **形态**：戒指/玉佩里住着高人（导师），或随身空间（可进人/种田/藏物）
- **代表作**：《斗破苍穹》药老（戒指老爷爷）、随身空间流
- **可改项**：导师形态（灵魂/器灵/系统音）、空间功能（种田/修炼/藏宝）

### 3.4 面板/加点流
- **形态**：数据面板+属性点，杀怪/修炼得点，自己分配
- **代表作**：《全球高武》（面板+属性）、《惊悚乐园》类无限流面板
- **可改项**：面板项目（力量/敏捷/精神）、点数来源

### 3.5 吞噬/复制流
- **形态**：吞噬他人血脉/能力/修为为己用；或复制接触过的能力
- **代表作**：《吞噬星空》（吞噬流）、《无限恐怖》复制强化
- **可改项**：吞噬限制（同阶才能吞/有反噬）、复制条件

## 四、身份结构参考

### 4.1 废柴逆袭
- **结构**：天才陨落/天赋被废 → 受尽羞辱 → 奇遇翻身 → 崛起 → 打脸旧敌
- **代表作**：《斗破苍穹》萧炎（三年之约）
- **常见搭配**：退婚/逐出族谱一类触发点

### 4.2 身世之谜
- **结构**：孤儿/小人物 → 身世线索断续浮现 → 揭示大势力遗孤/神界后人 → 身份公开震动
- **代表作**：玄幻通用（《遮天》叶凡身份、《雪中悍刀行》徐凤年身世）
- **常见搭配**：身份公开通常放在长线节点

### 4.3 扮猪吃虎
- **结构**：隐藏实力 → 被轻视/嘲讽 → 关键时刻出手 → 围观者反应
- **代表作**：网文通用（退婚流、装逼流底层结构）
- **常见搭配**：出手前先写对手的强度作为参照
