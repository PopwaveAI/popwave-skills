# pop-emergent-write

> 涌现流正文写作：**直接写正文（2000-2500字/章），世界底子照装配单、新设定从内容模板库选、情节自己冒、人物自己长**——轻量章纲是起跳板不是锁链，写偏了由 review 记账本回喂。write 只干三件事：**①读章纲读日志 → ②注入文风DNA → ③去AI味**（文档篇幅大部分留给去AI味：sepia 结构层 + 字词层唤起）。产出 `正文/ch{NNN}.txt`，不产任何账本/记录文件。当前版本 v1.3.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

---

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。
- **Pack**：缺口足够才取材，query 自生成；取材走 **`pop-snow-research`**（三方共用基建·跨系列只读调用，不写其文件），来源 **wiki 站 https://wiki.popwave.cn** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query（超限截断仅留结论区）。
- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版，不越权定终局。
- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

## 做什么

**输入（只吃六样核心，其余按需）**：轻量章纲（含情绪坐标，起跳板，可偏离）＋ 涌现账本（当前态）＋ 世界装配单（世界底子）＋ 前一章正文（衔接基准）＋ 文风承诺（唯一稳定锚）＋ 固定文风辰东.md（腔调渲染参照）。

**输出**：`正文/ch{NNN}.txt`（2000-2500字/章）。不产任何账本/记录文件——write 只在对话回复给一句摘要＋章末钩子＋新增事实待 review 清单。字数检查与去AI味检查由 write 存档后自跑脚本收束。

**硬约束链**：涌现账本🔒（当前态：主角现在在哪/此刻悬着的线/已长出设定——不得与已发生事实冲突）→ 世界装配单🔒（力量体系/世界观/金手指/身份——世界底子唯一来源，不得另发明一套）→ 文风承诺🔒（叙事腔调＋防漂移禁区）→ 轻量章纲◐（事件节点按序兑现＋情绪坐标兑现，**但可临场偏离**——偏离不是事故，进新增事实清单）→ 类型声明（防风味漂移，从立项卡赛道味取）。

**与 snow write 的本质区别（涌现纪律）**：
1. **设定从库选、不凭空造**：需要新设定（金手指新用法/新人物/新地点）→ 先从**内容模板库**（`skills/pop-emergent-state/references/内容模板库.md`）选模板装配，库里没有才当场造；当场造/库选都记"新增事实待 review"——不查设计库（没有）、不等 outline 补（大纲不产设定）。
2. **章纲可偏离**：写的时候情绪来了、人物自己走了——跟着走，偏离的后果由 review 记账本、账本回喂 outline 修正；禁止为了"章纲正确"压死写章。**情绪坐标（峰值）不可偏离**——峰值事件必须兑现，兑现方式可偏离。
3. **文风承诺是唯一稳定锚**：没有文风DNA库兜底正文稳定，腔调只对文风承诺＋固定文风辰东负责。

**执行模式**：主 agent 直执写作＋存档。输入缺口审计/章纲事实 vs 账本冲突比对可派子 agent（verification）只读审计回报。**写前/写中卡真实料（场景质感/专业细节/行业运作/历史器物）即主动点单 `pop-snow-research` 聚焦搜索**（跨系列只读调用，不写其文件）——**不设"考据不足才派"门槛**，回报结论区即可；查不到的写"没查到"，不凭空编造。

## Step 1：读输入（三件事的第一件——把料吃进来）

> 🔒 **语感隔离阀（先读这道总开关）**：章纲/账本的措辞是**剧情结构语言**，不是**正文语感**——它们天然带压缩性 AI 腔（"过量收敛""打脸""爆点"这类标签句），只用来描述"这章发生什么、读起来该怎样"。write 只从它们取**意**（事件顺序+落点功能+情绪坐标+钩子），用文风承诺的语言**重铸**成正文。**禁止照抄章纲/账本的抽象名、标签句、句式进正文**；情绪坐标只作强度提示，不成句搬。若正文出现与文风承诺语感不符的"大纲腔"，视为语感污染，review 打回。

按"必读核心 vs 按需点读"分层消费，不把档案全搬进上下文。缺必读核心项记入缺口。

**①用户本轮要求（最优先）**：覆盖默认取值。用户要求与账本冲突时以用户要求为准。

**②必读·涌现账本（当前态·跨章连续参照）**：`剧情日志/涌现账本.md`。抽取：现在在哪 / 主角此刻 / 此刻悬着的线（含不可提前吞并的钩子）/ 已长出的设定（世界碎片/金手指形态/配角——不得与其冲突）/ 不许碰（文风承诺防漂移禁区＋用户禁令）。章纲事实与账本冲突时**以账本为准**＋对话回复给 review"冲突标注"。

**③必读·世界装配单（世界底子·不得跳出）**：`立项/世界装配单.md`。抽取：力量体系（境界阶梯/能量名——正文用装配单的体系，不得另发明）/ 世界观结构（地图/势力/宗门）/ 金手指（形态与规则）/ 身份结构（主角身份走向）。**需要装配单没有的新设定→从内容模板库选模板装配，选了什么进"新增事实待 review"清单。**

**④必读·轻量章纲（起跳板）**：`章纲/ch{NNN}-章纲.md`。取：功能位 / 情绪坐标（章首/峰值/章末＋峰值事件）/ 舞台（时间×地点×在场人物）/ 事件节点（事件→转折→落点）/ 当前任务 / 章末钩。**章纲事件按序兑现为主，偏离为临场选择**——偏离时本章照写，偏离内容进"新增事实待 review"清单；**情绪坐标（峰值）是硬约束，峰值事件必须兑现。**

**⑤必读·前一章正文（叙事流+文气基准）**：`正文/ch{NNN-1}.txt`。把它作为本章的**衔接基准**带进：上一章结尾停在哪（余味/钩子落点）、人物蹦到哪、叙事口吻/语感到哪。保证本章从上一章文气上无缝接续。

**⑥注入文风DNA（第二步的核心）**：
- **文风承诺（唯一稳定锚）**：`立项/涌现立项卡.md` 的文风承诺字段（腔调一句话＋防漂移禁区）。文风承诺缺失【禁止】直接写作，先回 seed 补。
- **固定文风（腔调参照·写死）**：`references/文风兜底/辰东.md`——西幻·玄幻史诗纯样文，源书《夜无疆》辰东逐字原文，**只此一份不换不选**，取它的**笔触/句式/段落呼吸/叙事距离**等解剖维度作语感主师。**只作腔调参照，不取代文风承诺的锚位。**

## Step 2：渲染正文（按章纲写，可临场偏离）

按轻量章纲事件节点渲染 2000-2500 字，一个节点一个节点兑现。正文写入 `正文/ch{NNN}.txt`。

**正文规则（质量护栏，write 照做不越界）**：

- 开场 120 字内出现目标、异常、压力、反馈或主动动作之一
- **章纲必兑现（除非临场偏离）**：事件节点按序推进一个不丢；每节点「事件/转折/落点功能」落到正文；落点功能必须兑现。不能只铺氛围
- **情绪坐标必兑现（不可偏离）**：章纲标注的 8 分峰值事件必须外显——峰值事件与情绪级强度不匹配=章纲标注没兑现，review 打回（判据以打分表为准）
- **世界底子照装配单**：力量体系/世界观/金手指按装配单写，不得另发明一套；装配单没有的新设定→从内容模板库选，选了什么进"新增事实待 review"清单
- **事实冲突以账本为准**（见 Step 1②）；账本没有的新事实=临场长，进新增事实清单
- 关键爽点必须**外显**（旁人反应/资源变化/局势翻转/敌人误判），不能只由作者总结"他赢了"
- 不提前吞并账本"此刻悬着的线"里未到期的钩子
- 结尾必须留下主动钩子或威胁逼近，不用自然停顿收尾
- 判定链/系统数值一律自然段内联呈现（【】格式），禁弹窗式/代码块

**对白**：每个有台词的角色从账本/上一章正文取语言指纹（句式偏好/用词偏好/对话标志）；新角色现场定语言指纹，进"新增事实待 review"清单。write 负责"对话内容对+角色语言指纹对"，review 负责"对话质量好不好看"。

**存档**：正文写入 `正文/ch{NNN}.txt`，文件名固定。对话只回交接信息（摘要/钩子/字数/新增事实待核/冲突），不把正文全文放进对话，不存档创作记录文件。

## Step 3：去AI味（第三步的核心·write 把多数功夫花在这）

> 顺序：先在写时规避表层 AI 味（生成即达标），写完过【结构层复查】→【字词层语义复审】→【脚本兜底】三道。结构层优先于字词层——结构有问题时改词句是治标。

### 3.0 写时规避（生成即达标，非事后降噪）

写作时主动规避表层 AI 味信号，正文天然去魅，禁止写完再整章跑"降AI味"重写流程：

| 信号 | 写时规避 |
| :-- | :-- |
| 模板化开头 | 不写"随着…/在当今社会/近年来/众所周知"，直接场景起句（"天擦黑…"） |
| 展望套话收尾 | 不写"综上所述/让我们拭目以待/相信在不久的将来"，点到即收束 |
| 三段式/对仗排比 | 不排"首先→其次→最后""不仅…而且""既…又""一方面…另一方面" |
| 过渡连接词 | 换口语：值得注意的是→说白了；由此可见→看得出来；与此同时→同一时间 |
| 破折号 | ≤1个/500字，只留列举式/必要转折 |
| 半角引号 | 一律中文全角引号，禁止半角 `"` `'` |
| 句长均匀 | 避免连续3句都是15-25字，穿插≤5字短句控节奏 |
| 概括式内心 | 少写"他忽然觉得/她突然明白"，落到具体动作/细节外显 |

### 3.1 结构层复查（sepia 核心·先过这层，5 项全过落地）

机器抓表面模式、字词层抓句子语义；**结构层问题（上下逻辑/氛围兑现/重复/矛盾/造作句）在话语与语用层**，两句单看都对、连起来就不对，只有通读全章才现形。终稿通读一遍，5 项全过才算落盘（源：用户点评+sepia 结构去AI味）：

| # | 把关项 | 反例（AI常见病） | 合格判据 |
|:--|:--|:--|:--|
| 1 | 上下逻辑接得住 | "桅是旧伤，断口在里头，昨天就裂了。他说完，闭了嘴。"——前因不接后果 | 每处事件/对白的**前因→后果**两条都能对上；读者不用回读找逻辑。查法：把每个"于是他/所以/从此"往回问一句"凭什么是这后果" |
| 2 | 氛围铺垫有兑现 | 写了凉意和祷词断裂，后面直接跳去"他站住了，对面船有记号"，凉意没接任何后续 | 每个显眼的氛围描写（发凉/静默/异响/异象）后**必须兑现**——要么引出下一个事件，要么被后文解释/反讽；写氛围不兑现=空转，删或补承接 |
| 3 | 细节不重复描 | 刚写过"刻得很深，像是拿刀凿出来的"后文又说一遍刻痕深 | 同一细节（深度/新旧/颜色/声音）**只描述一次**，后文需要时用"它""那处"指代或换事件视角，不换词重描 |
| 4 | 细节不自相矛盾 | "声音不大，甲板上每个人都听见了"——声音不大+众人全听见互斥 | 同一逻辑事实不互相打架（音量/数量/距离/时间/空间）。查法：夸张修辞（"每个人都/全都/一动不动"）与精确限定（"声音不大/只有…/险些"）不同框出现 |
| 5 | 无造作句法 | "一眼——他把一次辩解"——破折号硬塞解释句，语义勉强 | 每句都用正常中文语序能通读；破折号不给硬补解释；不靠顿号/破折号/分行强行制造"文学感" |

> **结构层优先于词句层（sepia 核心）**：先过结构层（主题别讲白、因果别收太工整、氛围因与魂都在、情绪用动作不靠身体空转），再过字词层——结构有问题时改词句是治标。任一项不过=回该节点按冲突/落点功能重写该段，不靠降AI味词句打补丁。

### 3.2 语义复审清单（字词层·只查机器抓不出的语义味）

机器脚本抓表面模式（标点/套话/句式/句长），判不了语义味。终稿人工过一遍，7 项全过（源：Mirror 08 去AI味专家叙事恶习）：

| # | 把关项 | 合格判据 |
|:--|:--|:--|
| 1 | 无分析腔入正文 | 「核心动机/信息边界/信息落差/利益最大化」等分析术语禁止进句子；推导链、信息差设计只在脑中跑 |
| 2 | 不替读者下结论 | 读者能从行为推断的意图，叙述者不说破（"他明白她是生气了"✗，让行为外显✓） |
| 3 | 情感不后置解释 | 情绪动作后不紧跟"他感到/他忽然觉得"（"他攥紧拳头走开"✓，尾追"他感到委屈"✗） |
| 4 | 无金句体质 | 听起来像名人名言的句子重写为场景白话 |
| 5 | 无元叙事旁白 | "到这里算是钉死了"这类编剧脚注不进正文 |
| 6 | 同体感不连续渲染 | 同一意象域（如火在体内流动）连续渲染≤两轮 |
| 7 | 惊讶标记词≤1/3000字 | 「仿佛/忽然/竟/竟然/猛地/猛然/不禁/宛如」终稿数一遍，超了删到只剩最有力一处 |

### 3.3 脚本兜底（两项，写完必跑）

**① 字数检查（先跑——字数收束会增删文本，AI味检测须在终稿上跑）**：

```
powershell -File skills/pop-emergent-write/scripts/word-count.ps1 -Path 正文/ch{NNN}.txt
```

- 纯汉字 2000-2500 合格。不足→回章纲既有节点内扩写（补场景细节/对话往来/动作链，不灌水不复读）；超限→删最弱场景；改完复跑至 PASS
- **字数不足不外交**：review 不补救字数，write 自己收束达标后才交 review
- stdout 原文进对话回复交接信息，review 直接消费（review 不跑脚本）
- **段落节奏扫描（同脚本·自动化）**：**60% 以上叙事段<40字 = `判定:FAIL(段落过碎)`，阻断交稿**，write 调段（并短句、扩长句）复跑至 PASS；连续 3 短段处数、短段总数输出给 agent 人工判断是否留（允许场景：开场前300字反转金句/章末钩子最后一句/单章≤3个爆点短段，三个场景合计一章最多5个短段，超即"堆砌电报体"）。叙事段 40-120 字，对话段天然短不计入叙事段。

**② 去AI味检查（终稿上跑）**：

```
python skills/pop-emergent-pipeline/scripts/deai_gate.py 正文/ch{NNN}.txt --fix --json
```

- **零风险项脚本原地自动修**（标点全角化/引号配对/省略号归一/零宽字符/HTML与markdown残留/emoji/思考残留行/tab/行首标点归位等），无需人工
- **WARN/FAIL 项=自查自修清单**：按报告 hits 行号定位，只局部改写命中处（禁止全文重写），修后复跑至 FAIL 清零；WARN 酌情。注意"中文间空格""引号未配对""括号注释"三项有合法豁免，确认合法可放行

## 存档后检查 + 收束

三道（字数→去AI味→人工复审）都在 write 存档后自跑，不达标自己收束后才交 review。语义复审与结构层复审需人工通读，不放脚本。**验收检查**：正文存在 ✓｜字数 PASS 且段落节奏 PASS ✓｜去AI味 FAIL 清零 ✓｜结构层 5 项全过 ✓｜语义 7 项全过 ✓。

**新增事实处理**：write 不维护任何库文件。**临场长出的设定/新角色/偏离章纲的内容/从内容模板库选的新设定，只在对话回复里列"新增事实待 review"清单，由 review 落库。** write 只声明不落库。

**下一步（硬后继）**：正文存档后必须执行 pop-emergent-review。review 是 write 的硬后继，未执行 review 不得写下一章。

## 红线

1. **文风承诺缺失禁写**：涌现流没有文风DNA库兜底，文风承诺是唯一稳定锚＋固定文风辰东.md 作腔调参照；腔调进防漂移禁区=本章不合格。
2. **账本事实不可违**：已发生事实（时间线/人物状态/悬着的线）不得改写；新事实=临场长，进"新增事实待 review"清单。
3. **世界底子照装配单**：力量体系/世界观/金手指按装配单写，不另发明；需要新设定→从内容模板库选，选了什么声明交 review 落账本。
4. **情绪坐标不可偏离**：章纲峰值事件必须外显兑现（判据以打分表为准）；兑现方式可临场偏离，标准不可降。
5. **章纲可偏离、不可全丢**：偏离是临场选择（跟着人物/情绪走），不是随手乱写；核心落点功能仍要兑现。
6. **硬后继**：正文存档后必须执行 pop-emergent-review，未 review 不得写下一章。
7. **research 主动触发**：写前/写中卡真实料即主动点单 pop-snow-research 聚焦搜索回报结论区（跨系列只读调用，不写其文件），不设"考据不足才派"门槛；查不到写"没查到"，不凭空编造。
8. **固定文风写死**：渲染参照只认 `references/文风兜底/辰东.md`（西幻·玄幻史诗·《夜无疆》辰东纯样文），不按赛道另选、不临时换档；正文腔调偏离辰东样文的强特征视为风味漂移，review 打回。
