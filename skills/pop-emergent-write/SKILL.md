# pop-emergent-write

> 涌现流正文写作：**直接写正文（2000-2500字/章），世界底子照装配单、新设定从内容模板库选、情节自己冒、人物自己长**——轻量章纲是起跳板不是锁链，写偏了由 review 记账本回喂。消费**轻量章纲（含情绪坐标）＋涌现账本（当前态）＋世界装配单＋前一章正文＋文风承诺＋固定文风（辰东.md）**六样核心，其余按需点读。产出 `正文/ch{NNN}.txt`，不产任何账本/记录文件。当前版本 v1.1.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。
- **Pack**：缺口足够才取材，query 自生成；取材走 **`pop-snow-research`**（三方共用基建·跨系列只读调用，不写其文件），来源 **wiki 站 https://wiki.popwave.cn** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query / 回传 ≤30KB，超限截断仅留结论区。
- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版，不越权定终局。
- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

## 做什么

输入（有轻量章纲前提下，**只吃六样核心，其余按需**）：轻量章纲（含情绪坐标，起跳板，可偏离）＋ 涌现账本（当前态）＋ 世界装配单（世界底子）＋ 前一章正文（衔接基准）＋ 文风承诺（唯一稳定锚）＋ 固定文风辰东.md（腔调渲染参照）

输出：`正文/ch{NNN}.txt`（2000-2500字/章）。**不产任何账本/记录文件**——write 只在对话回复给一句摘要＋章末钩子＋新增事实待 review 清单。字数检查与去AI味检查由 write 存档后自跑脚本收束。

**硬约束链**：涌现账本🔒（当前态：主角现在在哪/此刻悬着的线/已长出设定——不得与已发生事实冲突）→ 世界装配单🔒（力量体系/世界观/金手指/身份——世界底子唯一来源，不得另发明一套）→ 文风承诺🔒（叙事腔调＋防漂移禁区）→ 轻量章纲◐（事件节点按序兑现＋情绪坐标兑现，**但可临场偏离**——偏离不是事故，进新增事实清单）→ 类型声明（防风味漂移，从立项卡赛道味取）

**与 snow write 的本质区别（涌现纪律）**：

1. **设定从库选、不凭空造**：需要新设定（金手指新用法/新人物/新地点）→ 先从**内容模板库**（`skills/pop-emergent-state/references/内容模板库.md`）选模板装配，库里没有才当场造；当场造/库选都记"新增事实待 review"——不查设计库（没有）、不等 outline 补（大纲不产设定）。
2. **章纲可偏离**：写的时候情绪来了、人物自己走了——跟着走，偏离的后果由 review 记账本、账本回喂 outline 修正；禁止为了"章纲正确"压死写章。**情绪坐标（双8峰值）不可偏离**——峰值事件必须兑现，兑现方式可偏离。
3. **文风承诺是唯一稳定锚**：没有文风DNA库兜底正文稳定，腔调只对文风承诺＋固定文风辰东负责。

**执行模式**：主 agent 直执写作＋存档。输入完备性缺口审查/章纲事实 vs 账本冲突比对可派子 agent（verification）只读审计回报，主 agent 据此判 execution.mode 并渲染存档。**写前/写中卡真实料（场景质感/专业细节/行业运作/历史器物）即主动点单 `pop-snow-research` 聚焦搜索**（三方共用基建·跨系列只读调用，不写其文件）——**不设"考据不足才派"门槛**，回报结论区即可（聚焦回报不强制落采风文件）；查不到的写"没查到"，不凭空编造。

## 怎么操作（SOP 全内联）

### Step 1：消费输入（抽取本章写作包）

> 🔒 **语感隔离阀（先读这道总开关，再消费任何章纲/账本）**：章纲/账本的措辞是**剧情结构语言**，不是**正文语感**——它们天然带压缩性 AI 腔（"过量收敛""打脸""爆点"这类标签句），只用来描述"这章发生什么、读起来该怎样"。write 只从它们取**意**（事件顺序+落点功能+情绪坐标+钩子），用文风承诺的语言**重铸**成正文。**禁止照抄章纲/账本的抽象名、标签句、句式进正文**；情绪坐标只作强度提示，不成句搬。若正文出现与文风承诺语感不符的"大纲腔"，视为语感污染，review 打回。

有轻量章纲前提下，按"必读核心 vs 按需点读"分层消费，不把档案全搬进上下文。缺必读核心项记入缺口。

**①用户本轮要求（最优先）**：覆盖默认取值。明确：把X写成Y/当前章位/续写或重写/特殊约束。用户要求与账本冲突时以用户要求为准。

**②必读·涌现账本（当前态·跨章连续参照）**：`剧情日志/涌现账本.md`。抽取：现在在哪（时间线/地点/故事到哪）/主角此刻（当刻在场·正交互的人）/此刻悬着的线（未收的线·含不可提前吞并的钩子）/已长出的设定（世界碎片/金手指形态/配角——不得与其冲突）/不许碰（文风承诺防漂移禁区＋用户禁令）。

**③必读·世界装配单（世界底子·不得跳出）**：`立项/世界装配单.md`。抽取：力量体系（境界阶梯/能量名——正文用装配单的体系，不得另发明）/世界观结构（地图/势力/宗门）/金手指（形态与规则）/身份结构（主角身份走向）。**需要装配单没有的新设定→从内容模板库选模板装配，选了什么进"新增事实待 review"清单。**

**④必读·轻量章纲（起跳板）**：`章纲/ch{NNN}-章纲.md`。取：功能位/情绪坐标（章首/峰值/章末＋峰值事件）/舞台（时间×地点×在场人物）/事件节点（事件→转折→落点）/当前任务/章末钩。**章纲事件按序兑现为主，偏离为临场选择**——偏离时本章照写，偏离内容进"新增事实待 review"清单；**情绪坐标（双8峰值）是硬约束，峰值事件必须外显兑现。**

**⑤必读·前一章正文（叙事流+文气基准）**：`正文/ch{NNN-1}.txt`。**必须带进本章写作包**——不只是"读过"，而是作为本章的**衔接基准**：上一章结尾停在哪（余味/钩子落点）、人物蹦到哪、叙事口吻/语感到哪。保证本章从上一章文气上无缝接续。与上一章章日志互补：章日志管"事件讲了啥"，前一章正文管"怎么讲的、停在哪、那股气"。

**⑥必读·文风承诺（唯一稳定锚）**：`立项/涌现立项卡.md` 的文风承诺字段（腔调一句话＋防漂移禁区）。渲染参照：**`references/文风兜底/辰东.md`（固定文风·写死）**——西幻·玄幻史诗纯样文，源书《夜无疆》辰东逐字原文，只此一份不换不选——**只作腔调参照，不取代文风承诺的锚位**；文风承诺缺失【禁止】直接写作，先回 seed 补。

**⑦按需·上一章章日志（衔接摘要）**：`剧情日志/ch{NNN-1}.md`。要上一章"事件摘要式"回顾（讲了哪些事/定了什么）才读；更细的历史回溯对应账本按需点读，**不默认逐章全读**。

**抽取本章写作包**：

```markdown
## 本章写作包
execution.mode:
- 把 X 写成 Y：
- 当前章位：
- 上一章结尾状态：（上一章停在哪/余味/人物当前处境——衔接基准）
- 此刻悬着的线：（账本里未收的线·本章不可提前吞并）
- 已长出设定：（账本里已有——本章不得冲突）
- 世界装配单：（力量体系/世界观/金手指/身份——本章不得跳出）
- 本章轻量章纲：（功能位/情绪坐标/舞台/事件节点/当前任务/章末钩要点）
- 情绪坐标兑现：（峰值事件怎么外显——双8是硬约束，假致命不算）
- 临场偏离声明：（写前预判可能的偏离；写后记录实际偏离）
- 用户本轮新增要求：
- 文风承诺：（腔调一句话＋防漂移禁区）
- 固定文风辰东：（腔调参照——大场面压画面/反应躯体外化/情绪藏进物象/短句独立成段）
- 对话要点：（本章有对话角色的语言指纹——从账本/上一章正文取，新角色现场定）
```

**execution.mode 判定**：formal=账本+装配单+轻量章纲+前一章正文（必读带进）+文风承诺+固定文风辰东齐全；draft=必读核心有缺口但用户要求继续；trial=快速试做不存档。**缺账本/装配单/前一章正文/文风承诺不得标 formal。**

**检查（进入 Step 2 前）**：写作包完整｜execution.mode 已判定｜账本当前态已锁定｜装配单在手（世界底子不得跳出）｜章纲事件节点已取｜情绪坐标已取（双8峰值待兑现）｜前一章正文已带进（衔接基准）｜文风承诺在手（缺失禁写）｜固定文风辰东在手（腔调参照）｜缺口已记录｜写前卡真实料已主动点单 research（若有）。

### Step 2：渲染正文＋存档

按轻量章纲的事件节点推进渲染 2000-2500 字：节点逐个兑现（事件+转折+落点功能）＋情绪坐标兑现（峰值事件按心跳库 8 分标准外显）＋章末钩子分级落章。正文写入 `正文/ch{NNN}.txt`。两道检查脚本（字数 word-count.ps1 + 去AI味 deai_gate.py）均归 write 存档后自跑（见下方「存档后检查」），不达标自己收束。

**正文规则**：

- 开场 120 字内出现目标、异常、压力、反馈或主动动作之一
- 主角至少完成一次动作收束：压力/诱因→判断→主动动作→阻碍升级→可见反馈→收益/损失→新压力
- **轻量章纲必兑现（除非临场偏离）**：事件节点按序推进，一个不丢；每节点「事件/转折/落点功能」落到正文；落点功能必须兑现。不能只铺氛围
- **情绪坐标必兑现（不可偏离）**：章纲标注的 8 分峰值事件必须外显——**8 分=见血/见死/见不可逆或同级正向震撼（旁人反应/局势翻转/全场哗然），假致命（危险发生了但没留不可逆后果）不算兑现**；峰值事件与情绪级强度不匹配=章纲标注没兑现，review 打回
- **物理缝合**：章纲只锁"事件/转折/落点功能"，不锁具体时序与动作细节时，write 负责补齐物理链（谁的手/什么时机/物件从哪来），补的拍服从章纲功能与前后因果
- **世界底子照装配单**：力量体系/世界观/金手指按装配单写，不得另发明一套；装配单没有的新设定→从内容模板库选，选了什么进"新增事实待 review"清单
- **事实冲突以账本为准**：章纲事实与账本冲突时以账本为准＋对话回复给 review"冲突标注"；账本没有的新事实=临场长，进新增事实清单
- 关键爽点必须外显（旁人反应、资源变化、局势翻转、敌人误判），不能只由作者总结"他赢了"
- 不提前吞并账本"此刻悬着的线"里未到期的钩子
- 结尾必须留下主动钩子或威胁逼近，不用自然停顿收尾
- 判定链/系统数值一律自然段内联呈现（【】格式），禁弹窗式/代码块

**创作技法（渲染前先把这几把尺过了，禁入正文的分析句不写进去）**：

- **关键场景行为推导 6 步（禁入正文）**：本章高潮/转折场景动笔前，对主角与关键角色各跑一遍推导链——当前处境 → 核心动机（最想要/最怕）→ 信息边界（知道/不知道/误判）→ 性格过滤（冲动/谨慎/果断…）→ 行为选择 → 情绪外化（身体语言/表情/语气）。推导卡壳（找不到合理行为）=前置铺垫不足——**涌现流：往前翻账本找这根线，没有就当场补一个动机（人物自己长），不硬写**；推导只用于自洽，**不得以"他意识到/他内心权衡"类分析句进入正文**。
- **读者视角设计（信息差管理）**：动笔前定本章「读者-角色信息差」——读者比角色多知道一点=紧张，少知道一点=好奇；至少制造一层"读者知情、角色不知情"。**锚定效应**：想突出主角表现，先在场景里放一个"参照"（敌人强度/困难上限/旁人水平）再让主角出手。
- **场景纪律**：①**新场景前 100 字让读者知道谁在场、在哪儿、正发生什么**（三要素）；②**每场景锁定 1 个核心情感基调**（对峙/温柔/压抑/热血），全部描写围绕它；③**行动桥接**：段落过渡用行动衔接（"门在他身后咔嗒锁上"✓），禁"与此同时/过了一会儿"（✗）。
- **字级节奏密度**：每 300 字 ≥1 爽点/看点、每 500 字 ≥1 钩子、每 1000-1500 字 ≥1 完整悬念、叙事段 40-120 字（手机屏 3-5 行）、长句给环境/心理短句给动作/冲突、避免连续 3 个短段(<40字)并列——前四项为**软性自查尺**；**段落碎裂是硬门禁**：60% 以上叙事段<40字=段落过碎返工，由 word-count.ps1 段落节奏扫描自动打回（机器可判），不等 review 人工。对话段天然短，不计入叙事段。

**去AI味写字节（生成即达标，非事后降噪）**：写作时主动规避表层AI味信号，正文天然去魅，禁止写完再跑"降AI味"重写流程：

| 信号 | 写时规避 |
| :-- | :-- |
| 模板化开头 | 不写"随着…/在当今社会/近年来/众所周知"，直接场景起句（"天擦黑…"） |
| 展望套话收尾 | 不写"综上所述/让我们拭目以待/相信在不久的将来"，点到即收束 |
| 三段式/对仗排比 | 不排"首先→其次→最后""不仅…而且""既…又""一方面…另一方面" |
| 过渡连接词 | 换口语：值得注意的是→说白了；由此可见→看得出来；与此同时→同一时间 |
| 破折号 | ≤1个/500字，只留列举式/必要转折 |
| 半角引号 | 一律中文全角引号，禁止半角 `"` `'` |
| 句长均匀 | 避免连续3句都是15-25字，穿插≤5字短句控节奏 |
| 概括式内心 | 少写"他忽然觉得/她突然明白"，落到具体动作/细节外显 |

**文风承诺落地**（不是事后润色，而是参与本章生成）：

| 项 | 在正文中的体现 |
| :-- | :-- |
| 腔调 | 叙事距离、句式、段落呼吸、感官顺序、对话引导方式全按承诺走；**固定文风辰东作腔调参照**：大场面（血月/神桩/龙虎相）几笔压成画面＋凡人/敌众反应用躯体外化（毛骨悚然、寒毛倒竖）＋情绪藏进物象与身体事件不喊不叫＋短句独立成段、每屏有推进 |
| 防漂移禁区 | 承诺"禁止漂移到哪"即硬清单，正文进禁区=本章不合格 |
| 主角主动方式 | 主角必须做出选择或动作 |
| 爽点外显方式 | 旁人反应、资源变化、局势翻转、敌人误判 |
| 信息释放 | 先给结果还是先给过程，哪些暂不解释；**遭遇式揭露优先，禁集中科普**；新层级设定（新势力/新规则/新地图）按节奏引，不每章堆 |

**对话落地**：每个有台词的角色从账本/上一章正文取语言指纹（句式偏好/用词偏好/对话标志）；新角色现场定语言指纹，进"新增事实待 review"清单。write 负责"对话内容对+角色语言指纹对"，review 负责"对话质量好不好看"。

**存档**：正文写入 `正文/ch{NNN}.txt`。文件名固定，对话只回交接信息（摘要/钩子/字数/新增事实待核/冲突），不把正文全文放进对话，也不存档创作记录文件。两道检查（字数+去AI味）都是 write 自己的存档后步骤，必跑、不达标自己收束后才交 review。

**存档后检查（写完必跑，两道：先字数→后去AI味）**：

**① 字数检查（先跑——字数收束会增删文本，AI味检测须在终稿上跑）**：

```
powershell -File skills/pop-emergent-write/scripts/word-count.ps1 -Path 正文/ch{NNN}.txt
```

- 纯汉字 2000-2500 合格。不足→回章纲既有节点内扩写（补场景细节/对话往来/动作链，不灌水不复读）；超限→删最弱场景；改完复跑至 PASS
- **字数不足不外交**：review 不补救字数，write 自己收束达标后才交 review
- stdout 原文进对话回复交接信息，review 直接消费进本章日志"字数"栏（review 不跑脚本）
- **段落节奏扫描（含在同脚本·自动化）**：`word-count.ps1` 同时输出段落分布——**60% 以上叙事段<40字 = `判定:FAIL(段落过碎)`，阻断交稿**，write 调段（并短句、扩长句）复跑至 PASS；连续 3 短段处数、短段总数、对话短段数输出给 agent 人工判断是否留（允许场景：开场前300字反转金句/章末钩子最后一句/单章≤3个爆点短段，三个场景合计一章最多5个短段，超即"堆砌电报体"）。叙事段 40-120 字，对话段天然短不计入叙事段。

**② 去AI味检查（终稿上跑）**：

```
python skills/pop-emergent-pipeline/scripts/deai_gate.py 正文/ch{NNN}.txt --fix --json
```

- **零风险项脚本已原地自动修**（标点全角化/引号配对/省略号归一/零宽字符/HTML与markdown残留/emoji/思考残留行/tab/行首标点归位等），无需人工，不进 LLM
- **WARN/FAIL 项=自查自修清单**：按报告 hits 行号定位，只局部改写命中处（禁止全文重写），修后复跑至 FAIL 清零；WARN 酌情。注意"中文间空格""引号未配对""括号注释"三项有合法豁免，确认合法可放行；[报告]标识项只看数不判级，异常高时人工判断

**③ 语义复审清单（人工点检·只查机器抓不出的语义味）**：

| # | 把关项 | 合格判据 |
|:--|:--|:--|
| 1 | 无分析腔入正文 | 「核心动机/信息边界/信息落差/利益最大化」等分析术语禁止进句子；推导链、信息差设计只在脑中跑 |
| 2 | 不替读者下结论 | 读者能从行为推断的意图，叙述者不说破（"他明白她是生气了"✗，让行为外显✓） |
| 3 | 情感不后置解释 | 情绪动作后不紧跟"他感到/他忽然觉得"（"他攥紧拳头走开"✓，尾追"他感到委屈"✗） |
| 4 | 无金句体质 | 听起来像名人名言的句子重写为场景白话 |
| 5 | 无元叙事旁白 | "到这里算是钉死了"这类编剧脚注不进正文 |
| 6 | 同体感不连续渲染 | 同一意象域（如火在体内流动）连续渲染≤两轮 |
| 7 | 惊讶标记词≤1/3000字 | 「仿佛/忽然/竟/竟然/猛地/猛然/不禁/宛如」终稿数一遍，超了删到只剩最有力一处 |

**验收检查**（存档后必跑）：

| 项 | 验收方式 |
| :-- | :-- |
| 正文存在 | `正文/ch{NNN}.txt` 存在 |
| 字数检查通过 | `word-count.ps1` 已跑：纯汉字 2000-2500 PASS 且段落节奏 PASS；不足/超限/段落碎裂已在 write 内收束 |
| 去AI味检查通过 | `deai_gate.py --fix` 已跑：零风险项已自动修，FAIL 清零（WARN/合法豁免项在对话回复注明） |
| 语义复审通过 | ③清单过一遍：分析腔0/替读者下结论0/情感后置解释0/金句0/元叙事0/同体感连续渲染≤2轮/惊讶标记词≤1每3000字 |

**新增事实处理**：write 不维护任何库文件。**临场长出的设定/新角色/偏离章纲的内容/从内容模板库选的新设定，只在对话回复里列"新增事实待 review"清单，由 review 落库。** write 只声明不落库。

**下一步（硬后继）**：正文存档后必须执行 pop-emergent-review。review 是 write 的硬后继，未执行 review 不得写下一章。

## 红线

1. **文风承诺缺失禁写**：涌现流没有文风DNA库兜底，文风承诺是唯一稳定锚＋固定文风辰东.md 作腔调参照；腔调进防漂移禁区=本章不合格。
2. **账本事实不可违**：已发生事实（时间线/人物状态/悬着的线）不得改写；新事实=临场长，进"新增事实待 review"清单。
3. **世界底子照装配单**：力量体系/世界观/金手指按装配单写，不另发明；需要新设定→从内容模板库选，选了什么声明交 review 落账本。
4. **情绪坐标不可偏离**：章纲双8峰值事件必须外显兑现（8分=见血/见死/见不可逆或同级正向震撼，假致命不算）；兑现方式可临场偏离，标准不可降。
5. **章纲可偏离、不可全丢**：偏离是临场选择（跟着人物/情绪走），不是随手乱写；核心落点功能仍要兑现。
6. **硬后继**：正文存档后必须执行 pop-emergent-review，未 review 不得写下一章。
7. **research 主动触发**：写前/写中卡真实料（场景质感/专业细节/行业运作/历史器物）即主动点单 pop-snow-research 聚焦搜索回报结论区（跨系列只读调用，不写其文件），不设"考据不足才派"门槛；查不到写"没查到"，不凭空编造。
8. **固定文风写死**：渲染参照只认 `references/文风兜底/辰东.md`（西幻·玄幻史诗·《夜无疆》辰东纯样文），不按赛道另选、不临时换档；正文腔调偏离辰东样文的强特征（大场面压画面/反应躯体外化/情绪藏物象）视为风味漂移，review 打回。
