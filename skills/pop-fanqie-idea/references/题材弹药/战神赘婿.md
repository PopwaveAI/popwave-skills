# 题材弹药卡 · 战神赘婿

> 定位：访谈弹药库，不是写作配方。只收结构、套路与事实；身份与商业细节标来源，查不到标「待核」。

## 一、定义与定位

- 平台标签：战神赘婿 + 赘婿 / 隐藏身份 / 打脸 / 护妻 / 豪门。
- 一句话：主角表面是被人看不起的赘婿/普通人，实际是战神、财阀、神医或大佬；被羞辱到极点后亮身份，护妻打脸，往上收拢势力。
- 常见篇幅：30-80 万字为主；80-150 万字要加商战/武道/家族线。
- 近邻与区别：与「都市高武」的区别是核心爽点在身份反差，不在升级；与「豪门总裁」的区别是男频视角与打脸节奏。

## 三、读者期待（5-8 条）

1. **身份反差**：最被看不起的人，实际最强。
2. **护妻/护家人**：谁动我的人，我就动谁。
3. **当场打脸**：羞辱→亮身份→对方跪，节奏要快。
4. **多层身份**：战神/财阀/神医/家主，一层层揭开。
5. **家族/商战**：不只是打架，还有股权、合同、豪门斗争。
6. **兄弟/旧部**：主角有班底，不是孤家寡人。
7. **底线**：不滥杀、不欺负普通人，护短但有原则。

## 四、常见套路（8-12 条）

- **开局**：入赘受辱、妻子被欺、家族逼离婚、被赶出家门。
- **破局**：亮一层身份；一个电话叫来旧部；出手治病/打架；签下大单。
- **升级**：赘婿→家族供奉→商会会长→战区统帅→隐世家主。
- **打脸/反转**：岳父岳母跪；情敌/富二代被打脸；家族背后还有更大势力。
- **换图**：家庭 → 家族 → 城市 → 省城/京城 → 国际。

## 五、反套路清单（5-8 条）

1. **同类都忍辱负重 → 本书开局就离婚/分家**：不憋屈，直接断关系再打脸。风险：少了「隐忍反转」，要用利益线补。
2. **同类都亮身份碾压 → 本书先搞事业**：用公司/医术/武道合法上位。风险：爽点慢，要设计「合法打脸」。
3. **同类都战神无敌 → 本书有约束**：身份不能随便用，用了有政治/家族代价。风险：主角不能太爽，要给资源补偿。
4. **同类都护妻无脑 → 本书护短有原则**：护自己人，但不纵容。风险：读者可能嫌不够爽，要用对手更恶补。
5. **同类都反派降智 → 本书反派有背景**：对手有家族/资本/官方靠山。风险：主角赢得慢，要写智力博弈。
6. **同类都多马甲乱飞 → 本书马甲有限**：每层身份有明确代价与暴露风险。风险：揭秘太快会掉爽感，要控制节奏。
7. **同类都物化女性 → 本书女主有事业线**：不是奖品，是合伙人。风险：男频读者可能嫌感情线多，要控制比例。

## 六、金手指 / 替代驱动（5-8 种）

| 类型 | 能做什么 | 限制/代价 | 适合的主线动作 |
|:--|:--|:--|:--|
| 战神身份 | 调旧部、武力威慑 | 身份敏感；不能公开；有政敌 | 护人、商战、收势力 |
| 财阀/家族 | 资金、人脉、渠道 | 家族内斗；资金有监管 | 商战、收购、布局 |
| 神医/医术 | 治病、救人、收人情 | 缺药/风险；不能包治 | 救人、打脸、结盟 |
| 系统/任务 | 给技能、给奖励 | 任务失败惩罚；奖励有限 | 升级、打脸 |
| 信息差 | 知道对手底牌/政策 | 信息会过期；传错反噬 | 商战、站队 |
| 无金手指 + 班底 | 靠旧部/兄弟/专业 | 班底有限；要养 | 组织、商战 |

## 七、雷点 / 毒点（5-8 条）

1. 反派降智，为了被打脸而送。
2. 重复打脸：同一套羞辱→亮身份循环。
3. 身份解释不通：这么强为什么之前受辱。
4. 现代秩序降智：随便调兵/杀人没人管。
5. 女性工具化：女主只负责被救/被宠。
6. 三观问题：滥杀、仗势欺人、双重标准。
7. 后期悬浮：从赘婿直接成世界霸主，没有阶梯。
8. 马甲太多，作者自己收不回来。

## 九、事件种子与分卷阶梯

**事件种子（10-15 条）**

1. 婚礼当天，主角被岳父当众羞辱。
2. 妻子被富二代骚扰，主角出手。
3. 家族逼离婚，主角签下「净身出户」后反手收购。
4. 主角一个电话叫来旧部，家族傻眼。
5. 岳母重病，主角用医术救人，身份露一角。
6. 情敌设局，主角用合同反杀。
7. 家族内斗，主角站队赢家。
8. 旧部被陷害，主角回战区/公司救人。
9. 主角的马甲被媒体盯上，必须处理。
10. 终敌不是富二代，而是掌握资本/规则的人。
11. 女主自己创业，主角从「护」变成「合作」。
12. 主角放弃一层身份，换更大的局。
