# 导入模式·标准内容结构对照表

> 弱加载：仅 pop-fanqie-pipeline step0-import（导入/续写模式）的 0b-2 环节读取。
> 用途：将用户自由格式文件转换为管线标准结构。结构正源在各子 skill 的 step 产出规范；本表是导入转换视角的汇总（含转换方式），两者冲突时以子 skill step 为准并反馈修订本表。

## 转换规则

保留用户原始内容，用标准结构重新组织（加标准标题/分节），不删除用户已有信息。缺失分节标注"⏳待补"，不编造。非md文件（.docx/.txt/.json）先读取内容再按标准格式写入.md。
