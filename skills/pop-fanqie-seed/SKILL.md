# pop-fanqie-seed · 番茄创意引擎

> 自由出创意，结构做打磨。从无到有把创意打磨成可试读的开篇。v14.0.0：step1/step2/step3 三件全合入 SKILL.md 单文件精炼（SOP全内联），steps 目录删除。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 做什么

| 输入 | 输出 | 下游 |
|:-----|:-----|:-----|
| 用户一句话方向/偏好/参考书意图 | `设计/创意.md` + `正文/ch001.md` | pop-fanqie-world, pop-fanqie-plot |

**定位**：seed负责创意到首章。世界构筑移交plot，seed不碰。用户提到参考书时，seed 1a 路由到前置供给（tool-download-webnovel+pop-dna-style/pop-decon），完成后回 1b。

**执行模式**：Phase 1 摸底问答/策略选择/10选1、Phase 2 打磨确认、Phase 3 试读确认均需用户多轮交互——主agent直执；1b-2 闸门放行后的四路并发（笔触DNA提取/力量体系拆书/市场调研/扫榜）为只读调研类工作——派子agent执行回报结果，主agent落盘消费。

### Phase 1 · 摸底+调研+双轨发散

**1a 七维底牌摸底**：pipeline调起（`素材/用户意图.md`已存在）→跳过摸底直接进1b闸门；seed独立启动→完整执行。方向摸底路由：用户直接给创意/画面/一句话→跳过Phase 1发散直接进Phase 2打磨；给方向/偏好→1b闸门→1c→1d；完全开放→1c（含扫榜定方向）→1d。

- 摸底表模板见 `templates/Phase1-模板.md`·七维底牌摸底表——照表向用户**一次性**问7类底牌（笔触参考书/力量体系参考书/赛道经典/现有设定/情绪基调/全书最大卖点/需要推荐）。
- **红约束**：必须等用户回答完七维摸底表才能进1b闸门；用户说"全跳过"可直接放行。

派发原则：告诉子agent扮演哪个skill哪个档位→让它自己读SKILL.md→给具体参数（书名/路径/赛道）不给SOP；①②④互不依赖同时启动，③也同时启动；缺失跳过；四路全部返回后进1d双轨发散。

**1c 市场调研**（产出是"借鉴点+避雷点清单"，不是搜索数据本身；搜索数据消化完后**不进入发散prompt**。如1b-2中③已启动→等返回后消费落盘文件，直接确认1c-4落盘）：

- 1c-1 WebSearch三轮：①`"番茄小说/起点中文网" + "{赛道} + 热门/排行榜/2026"`找榜单热门 ②`"B站/抖音/知乎" + "{赛道} + 小说推荐/出圈" + "2026"`找出圈概念 ③`"网文" + "{赛道} + 新题材/新趋势/审美疲劳" + "2026"`找新方向+疲劳模式
- 1c-2 市场分析：对每部热门作品分两层标注（借鉴：可借鉴的机制/爽感/节奏；避雷：必须避开的已有设定/金手指/开局），产出校准清单
- 1c-3 落盘：格式见 `templates/Phase1-模板.md`·市场校准清单，落盘到 `素材/市场校准.md`
- **红线**：市场调研产出必须落盘为文件，供plot加载——plot是新agent没有seed的上下文，不能只停留在对话里

**1c-5 题材深度调研**（条件触发）：触发条件=1a底牌"全书最大卖点"选了"处置驱动型/设定驱动型"且赛道涉及需专业素材的题材（诡异/修仙/末世/系统等）；不触发=卖点选"故事驱动型"或都市言情/职场等不需专业素材的题材。执行1轮WebSearch做题材级素材库建设：诡异/灵异→处置方式素材库（民俗驱鬼/佛教超度/道教镇煞/克苏鲁封印/现代收容）；修仙→修炼体系素材库（丹道/符箓/阵法/雷劫/心魔）；末世→生存体系素材库（变异/进化/资源/避难所）。产出格式见 `templates/Phase1-模板.md`·题材深度调研，落盘到 `素材/题材深度调研.md`。
**消费规则**：1d-0策略组装时从素材库选处置方式；1d发散时必须从素材库选处置方式，不能选最偷懒的"吞噬变强"；故事纲领力量体系层必须消费素材库。

**1d-0 改编策略分析**：核心=在5+5发散前，用参考书DNA+赛道调研+用户元素+情绪+爽点类型组装3-5个"改编策略"，用户选1-2个后，1d双轨发散在策略框架下产出10个创意。**策略是生成器，创意是产物。**

- 1d-0-A 素材盘点：赛道借鉴点+避雷点（1c，用于策略的爽点类型选择）/参考书力量体系DNA（decon-lite表1，借什么力量体系）/势力格局DNA（表6，借什么势力结构）/金手指DNA（表7，借什么金手指机制）/世界危机DNA（表8，借什么危机引擎）/用户元素（七维底牌+用户意图，融入什么元素）。缺失项检查：情绪基调、全书最大卖点（1a已收集，未收集则追问）、爽点类型清单（从1c借鉴点提炼，未提炼则提取）。
- 1d-0-B 策略组装卡（3-5个）：结构见 `templates/Phase1-模板.md`·策略组装卡。组装原则：3-5个策略的改编维度必须差异化；策略是"生成器"不是"成品"；必须和参考书DNA结合；无参考书时从赛道调研提炼切入策略。
- 1d-0-C 用户选策略：选1-2个，可混搭（策略A的改编维度+策略B的爽点类型）。无用户交互时默认选第1个。
- 1d-0-D 策略→发散传递，选定策略后注入发散prompt：
  - **A轨（王道）**：`system: 你是一个网文创意编辑。 user: 赛道：{方向}。改编策略：{改编维度+借什么+改什么}。已验证卖点：{卖点列表}。避雷点：{避雷点}。爽点偏好：{策略选定爽点}。情绪基调：{策略选定情绪}。用融合策略产出5个王道方向开书创意。`
  - **B轨（猎奇）**：`system: 你是一个网文创意编辑。 user: 我想写{方向}，改编策略：{改编维度+借什么+改什么}。爽点偏好：{策略选定爽点}。情绪基调：{策略选定情绪}。生成5个完全不同方向的开书创意种子，形式自由。`
  - 关键约束：策略定方向不定形式；B轨在策略框架内仍自由发散；不破坏红线2（纯自由发散）——B轨system只有一句话。

**1d 双轨发散：王道×猎奇**（在1d-0策略框架下，A轨5个+B轨5个=共10个）：

- **1d-A 王道赛道**：①扫榜（如1b-2中④已启动→直接消费返回结果；否则2轮搜索：`"番茄小说"+"{赛道}"+"排行榜/热销/2026"`→top5，`"{赛道}"+"起点"+"精品/万订/2026"`→补top3）②提取核心卖点（每本top书1句"可迁移的核心卖点"——理解读者为什么买单，只提取卖点机制不提取具体设定）③融合发散（5种融合策略：卖点平移/卖点叠加/反向操作/设定替换/情绪基调换挡，基于5-8个卖点产出5个方向）④质量门禁（每个王道方向必须有卖点基底+有差异化+不踩避雷点+有画面，不过→重新发散）。
- **1d-B 猎奇赛道**——发散指令：`system: 你是一个网文创意编辑。 user: 我想写{用户方向}，请帮我生成5个完全不同方向的开书创意种子。` 关键约束（agent自检，不给API）：5个方向差异最大化（不同切入点/主角类型/情绪基调/创意类型）；创意类型强制多样化（10个创意必须覆盖≥3种创意类型：反转型/阶级攀爬型/生存竞技型/重建型/身份揭秘型，禁止全偏一种）；情绪基调强制多样化（10个必须覆盖≥5种：热血逆袭/暗黑复仇/悬疑烧脑/都市恐怖/情感治愈/荒诞轻喜剧/末世求生/权谋博弈）；画面优先（每句话读完脑子里立刻浮现场景）。
  - **好创意六标准**（全过才放行）：读者三标准=有画面+有张力（反差/攀爬压力/生存压力/揭秘悬念任一）+有意思；作者三标准=有世界（力量体系+隐藏规则）+有舞台（世界危机驱动100章）+有主角（特殊性含金手指+力量路径在世界力量体系内）。
  - **反面教材**：纯事件无特殊性（穿越→系统→升级）/纯机制无舞台/纯势力操盘无金手指。
- **1d-C 双轨市场校准**：用1c校准清单统合校验——踩避雷点=淘汰；用到借鉴点=加分。王道额外校验卖点基底+差异化（最多淘汰2个）；猎奇额外校验画面+张力+有意思（重新发散补足5个）。最终呈现10个。

**1e 用户选择**（10选1，双轨展示）：展示格式见 `templates/Phase1-模板.md`·创意展示格式，分王道🔷/猎奇🔶两条赛道展示，用户选1个。无用户交互时默认从王道选1个（验证过的卖点+差异化达标）。

### Phase 2 · 结构化打磨

> 用户选定方向后进入。这一阶段不改创意，而是**给选定的创意装上引擎、验证质量、写成简介**。

**2a 行为引擎检查**：检查选定创意是否已有行为引擎——主角每章在做一件具体的事（谈判/把脉/写手册）还是在操作一个系统（抽卡/升级/兑换）。已有→跳过碰撞直接进2b；没有→用行为框架碰撞补上。行为框架来源=与赛道无关的日常领域，自带流程、甲乙方关系、可博弈规则：

| 素材池 | 示例行为 |
|-------|---------|
| 职场行为 | 签合同/写手册/定KPI/走流程 |
| 社会服务 | 接投诉/送快递/做客服 |
| 法律框架 | 维权/执法/合规审查 |
| 民间习俗 | 讨封问话/红白事流程 |
| 日常生活 | 做饭/装修/带娃/相亲 |

碰撞方法：把行为框架的流程步骤逐条映射到创意场景，每条映射=一个章节。例："殡葬直播间"碰撞"客服"框架：接单→亡魂提需求→走流程完成→满意度评分→获得功德值。

**2b 合成金手指**：

```
金手指 = 创意（提供形式——怎么表现）
       × 机制（提供动力——为什么有效果）
       × 限制（提供张力——为什么不能随便用）
```

合成示例库见 `references/showcase.md`「三要素合成示例」（弱加载，仅本环节读取）。合成要求：创意提供表现形态；机制提供有效性来源；**限制至少3条**——单条限制不够支撑100章张力，world需多条限制推导不同维度的压力源/倒计时；**禁止只加限制不加代价**——限制必须让主角做选择，不能是单纯削弱。

**2c 四眼法验证**（对合成后的金手指逐眼验证）：

| 眼 | 检查什么 | 通过标准 |
|----|---------|---------|
| 画面眼 | 闭上眼能不能看到主角用金手指的具体画面？ | 能说出1个具体场景 |
| 限制眼 | 限制能不能制造选择压力？ | 主角用金手指时要权衡，不能无脑用 |
| 场景眼 | 这个金手指能跑10个不同的场景吗？ | 能列出10个章节场景 |
| 引擎眼 | 主角每章在做什么具体行为？ | 能说出行为引擎，不是纯升级 |

四项全过→放行进2e；任何一项不过→打回，换机制或调整限制重新合成。

**2e 故事纲领（三核心+营销层·≤1000字）**

> **触发锚定**：结构化打磨（2b/2c/2e）前**必须加载** `references/design-guide.md`（🔴写崩级）——金手指进化/主角反推/世界观骨架/长线线索的具体设计方法是产出质量的真源，禁止凭本节要点硬凑。
> 故事纲领是 world 的核心输入：世界→力量体系/地图/势力，舞台→敌人梯度/压力源/倒计时，主角→成长路径/幕序列。金手指不再是独立维度——融入"主角"核心。**纲领不是创意摘要，是 world 的设定蓝图，每项必须给足结构元素。走形式=废纲领。**
> 三核心正反例对照见 `references/showcase.md`「故事纲领三核心质量对照示例」（弱加载，写各核心前对照校准）。

**核心一：什么样的世界（3-4句）**——写法：第一句给世界质感，**第二句明确力量体系**，后续句给world推导方向。质量标准=**规则差异四层**（缺项=走形式=重写）：

- ✓ **力量体系层**（world推导力量层级的**唯一基底**，world不再自己发明力量体系）：必须给足3项信息——①力量体系类型（修仙境界/系统规则/规则怪谈/异能等级/职业树/…）②阶位名称（≥3级，每级有名字且要有文化渊源——不是"觉醒者/承载者"通用词，是"咒印修行者/系缚修行者/佛子"这种有渊源的词）③核心成长机制（靠什么变强？吞噬/系缚/修炼？不能只给"位阶1-7"不解释怎么升。**处置驱动型卖点必须给处置方式**——封印/谈判/利用/转化/共生/驱使，不能逃避到"吞噬变强"）
- ✓ **差异层**：1条核心差异——具体的运转法则（"疾病是活的，有意识，会谈判"），不是"有魔法"泛标签
- ✓ **日常层**：差异如何影响普通人日常（"生病了不能只吃药，得找人跟病灵谈判"）——world从中推导地图/经济/社会结构
- ✓ **主角层**：差异如何影响主角生存（"主角是少数能跟病灵谈判的人"）——world从中推导主角特殊性来源

任何小说的世界本质都是"规则差异"——力量体系是骨架，差异→影响日常→影响主角，四层在任何类型都成立。

**世界类型+风味基调**（world执行命名/器物/社会符号的唯一基线）：必须明确声明——世界类型（西幻/东方玄幻/现代都市/末世/系统流/规则怪谈/…）+风味基调（该类型的命名/器物/社会符号基本盘参考系：西幻=西式命名+银币/酒馆/石堡/短剑+职业/神祇/魔法/教会；东方玄幻=中式命名+灵石/洞府/飞剑/宗门+境界/门派/功法；现代都市=现代命名+人民币/公寓/地铁/手机+公司/学校/都市规则；末世=废土命名+罐头/营地/枪械+幸存者/军阀/变异体）。**硬约束**：声明西幻却用"铜板/米斗/驿站/柴刀/江湖/门派"=类型味漂移，world打回西幻化。

**核心二：什么样的舞台·世界危机（3-4句）**——舞台=世界危机，危机驱动剧情持续运转100章。写法：第一句给读者压迫感（全书危机本质），后续句给world推导方向（危机源头→敌人梯度→压力源矩阵）。质量标准（缺项=走形式=重写）：

- ✓ 1个全书危机源头（具体的、有来源的威胁——"零号病灵百年前被镇压在医院地下，封印随城镇化磨蚀"，不是"有人要毁灭世界"）
- ✓ ≥3层敌人梯度（从底层到顶层每层有具体对象——"寄生级病灵（感冒级别）→共生级（糖尿病/高血压）→领地级（癌症/渐冻症）→灾祸级（瘟疫）→零号"，不是"底层恶鬼/中层律师所/顶层委员会"标签）
- ✓ ≥1个压力源/倒计时（驱动主角不能停——"每谈判一次泄漏气息加速封印松动"/"信誉度归零除名"）

**核心三：什么样的主角（4-5句）**——主角特殊性=金手指+成长路径。**硬约束：主角的力量路径必须在核心一力量体系层内**——金手指可以是加速器/特殊视角/漏洞利用，但不能是另一个维度的东西（修仙世界主角力量路径是修仙境界，不能是"管理权限层级"；系统流主角力量路径是系统等级，不能是"现实中的人际关系层级"）。写法：起点（初始状态/困境+初始能力）、拐点（什么事件迫使改变+特殊性觉醒）、终点（最终变成什么+特殊性成熟）、力量路径（从什么能力→到什么能力，每级有具体场景；金手指的机制和限制在这里交代）。质量标准（缺项=走形式=重写）：

- ✓ 起点+拐点+终点三段完整（具体的状态转变——"从被生活压垮的急诊大夫→活体封印"，不是"他会变强"）
- ✓ ≥3级力量路径（每级有具体能力描述+对应场景——"单病灵谈判（求小病灵离开→获权柄碎片）→多病灵协同（用权柄碎片诊断→介入领地级谈判）→灾祸级谈判（谈一支病灵军团→参与零号封印）"，不是"看合同→改合同→写合同"标签）
- ✓ 力量路径直接映射幕序列（每级力量路径=一幕，world拿到后知道每幕主角在干什么）
- ✓ 力量路径对齐世界力量体系（每级=核心一力量体系中的一个层级或跨层级；不对齐=废纲领）
- ✓ 前期成长路线（第一卷3-4个成长阶段，每阶段有主角的处境+目标+对手——如"街头期（求生/小赌徒/地痞）→起家期（立足/小赌场主/灰蛇）→扩张期（扩张/公会博弈/制度权力）→立足期（稳固/直面世界危机/幕后层）"；world需要它定第一卷章节预算和敌人梯度）

**营销层**（读者消费，非world输入）：

- **最大钩子（≤20字）**：纯读者视角——路人翻三页被什么概念暴力抓住。类型示例：概念反转"穿越成一面镜子——不能说话、不能动、不能被人发现你是活的"／装疯反杀"被关进精神病院的天才棋手，不是受害者而是猎手"／内鬼视角"10人密室1个说谎者——主角就是那个必须骗过所有人的人"／体制复仇"被自己效忠的国家枪决的英雄之子，重生回到一切开始前"。
- **即时兑现感（2-3句）**：前5章如何让读者感受到"已经在路上了"。节奏模式示例：剥洋葱式（第1章赌场翻盘→第2章被堵门反杀→第3章公会接单→第4章下水道发现尸体→第5章第一次和制度权力博弈）／两线交织（现实线和梦境线交替推进，每章两个世界的拼图各多一块）／技能树开枝（每章激活金手指的一个新功能，同时引入一个新对手）。

**故事纲领自检清单**（落盘前逐项检查，缺项=重写；标准详见上文各核心质量标准）：世界有力量体系层｜世界有世界类型+风味基调｜世界有差异层｜世界有日常层｜世界有主角层｜舞台有危机源头｜舞台有敌人梯度｜舞台有压力源/倒计时｜主角有三段弧线｜主角有力量路径｜力量路径映射幕序列｜力量路径对齐世界力量体系｜主角有前期成长路线。

**硬约束**：三核心+营销层加起来≤1000字（信息密度极高的"浓缩液"）｜三核心每项必须通过自检清单（world拿到后能直接推导设定）｜金手指融入"主角"核心不独立成维度｜每项必须给出具体答案（"他从独狼变成必须保护公会的人"，不是"主角会成长"废话）｜最大钩子必须能以≤20字一句话讲清（讲不清=还没想明白）｜走形式=废纲领（只写标签不写具体对象/场景的必须重写）。

### Phase 3 · 黄金首章

> 定位：黄金首章是**试读章**——验证"这个创意能不能抓住读者"。不是精雕细琢的正式版（正式版由write按plot剧情白描产出），但必须是能让读者想看第二章的开篇。**首章不好看=创意死刑**。R37/R38实测退化根因：纯事件展示（穿越→被抢劫→找大D）或纯战斗展示（苏醒→杀怪→杀怪），没有"生活化场景×金手指"的反差画面。

**3a 加载创意.md**：全文加载Phase 2落盘的 `设计/创意.md`，提取关键要素——创意（首章必须展现）/金手指（首章必须激活）/行为引擎（首章主角在做这个行为）/轻量主角轮廓（首章建立主角形象）/番茄简介（首章基调参考）。**笔触DNA检测**：`素材/文风锚定.md` 存在→启用态，按需加载DNA（通用维度全读+首章场景卡"对话·日常""描写·环境引入""叙述·揭秘心理戏"最多3张），**首章从第1句开始用DNA笔触写，禁止先写后改**；不存在→提示用户部署DNA，用户拒绝则进trial模式（不内置默认风格，用户须显式声明基础风格倾向，如"简洁短句+无面板+动作驱动"；不声明则接受API自由发挥的质量波动）。启用态下DNA无系统面板格式设定时，首章不得擅自加面板。（笔触三态协议同步write v8.0.0减法版——write v7.2.0的动作链/多感官/感官优先级表/【】面板/碎片化思考等已移除，不作为首章硬约束。）

**3b 黄金开篇法则**（6条全守）：

1. **前3句扔炸弹**——第一句话就制造冲突/悬念/反差，禁止铺垫环境/背景/天气
2. **300字内完成4件事**——冲突爆发+主角出场+金手指激活+章末钩子
3. **第一章必须激活金手指**——不能等到第二章
4. **第一章必须有1个爽感触发**——压力突破/弱→强/未知揭示/被欺→反击
5. **章末必须有钩子**——让读者想看第二章的悬念/威胁/转折
6. **必须有1个"生活化场景×金手指"的反差画面**（R13/R14核心特质，纯战斗展示/纯穿越事件不算合格首章）

法则6详解——**反差画面=生活化场景×金手指**，金手指触发在一个日常可感的场景里制造荒谬反差：

| 样本 | 生活化场景 | 金手指 | 反差画面 |
|------|----------|--------|---------|
| R14《诡编》 | 推开凶宅大门 | 篡改诡异属性面板 | 女鬼扑来，我把她"暴躁"改成"正在织毛衣"，她真的开始织毛衣 |
| R13张平凡 | 加班骑车回家 | 公文语成真 | 黄鼠狼拦路讨封，用红头文件格式回答，它必须照办 |
| 反面R37 | 跳恒河穿越（非日常） | 系统看忠诚度 | 无生活化场景，无反差 |
| 反面R38 | 沙滩苏醒杀怪（非日常） | 基因种子烧蝌蚪 | 无生活化场景，无反差 |

设计方法：找主角金手指能触发的**日常可感场景**（上班/回家/买菜/相亲/加班/收快递）→让金手指在这个场景里**以最荒谬的方式触发**→画面要有**具体动作+具体台词+具体物象**（毛线球/红头文件/属性面板）。禁止的开篇类型：纯战斗展示（苏醒→杀怪→杀怪）/纯穿越事件（跳河→机场→被抢）/纯设定铺陈（介绍世界观→介绍金手指→介绍主角）。

**3c 首章结构（7节拍）**：

| 节拍 | 内容 | 字数参考 |
|------|------|---------|
| 1. 开场炸弹 | 第一句话制造冲突/悬念/反差 | 50字 |
| 2. 冲突爆发 | 主角面对的具体威胁/困境 | 300字 |

| 5. 爽感爆发 | 金手指带来的反转/突破 | 400字 |
| 6. 危机暗示 | 暗示更大的威胁/主角危机 | 300字 |

总字数2000-2500字，**不准超过2500字**。

**3e 爽感闭环（必须）**：首章必须有1个爽感触发，且必须是**触发→爆发→后果**三段式——触发（主角面对压力/被欺/未知/弱者处境）→爆发（金手指激活，反转/突破/揭示/反击）→后果（爆发后的可见变化：诡异被改写/敌人失态/主角获得反馈）。三段缺一=废章。
