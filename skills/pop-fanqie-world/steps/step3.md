# Step 3: 全书设定（3-8卷200万字级）

> **v1.7.0 质量升级**：从起点汲取5项经验——①战斗可写性约束（4拍节奏+画风）②维度好坏标准表 ③分段落盘+段间检查点 ④势力攀登方式标注 ⑤轻量原则推导。分3段落盘，每段好坏标准自检通过才进入下段。

## 前置：轻量原则推导（Step 2a 内化产出校验）

> 从创意.md核心条款推导3-5条世界设计原则。原则是"创意主线在世界层面的投影"，确保后续地图/势力/危机不跑偏。**不做IP验证，不做全书贯穿校验**（番茄保持轻快）。

| # | 设计原则 | 创意依据 | 世界含义 | 回溯产出维度 |
|:--|:--|:--|:--|:--|
| 1 | （原则陈述，如"安全区在收缩"） | 创意.md哪条核心条款推出 | 这条原则下世界长什么样 | 力量体系/地图/势力/危机 至少1个 |
| 2 | | | | |
| ... | | | | |

**硬约束**：
- 3-5条原则，每条必须回溯创意.md具体条款（不是凭空编）
- 地图/势力/危机每个维度的关键设定，后续必须回溯至少1条原则
- 原则是"创意主线的投影"，不是"好坏标准清单"

## Part 1 · 骨架层：力量体系 + 地图

| 力量阶位 | 名称 | 这个世界长什么样 | 主角面对什么 | 升级触发条件 | 社会地位参照 | 源力量转化 | **战斗可写性·4拍节奏** | **战斗画风** | **预计展开卷** |
|:--|:--|:--|:--|:--|:--|:--|:--|:--|:--|
| 阶位1 | （从Step 2b取） | | | | | | 试探/对抗/转折/收尾各写什么 | （1句话气质描述） | 第一卷 |
| 阶位2 | | | | | | | | | 第一卷 |
| 阶位3 | | | | | | | | | 第二卷 |

| 阶位7 | | | | | | | | | 终卷 |

**要求**：5-7层完整展开，每层标注预计在哪卷展开。第一卷通常覆盖前2-3层，后续卷逐层展开。

**战斗可写性硬约束（P0）**：
- 每阶必须标注4拍节奏（试探→对抗→转折→收尾），每拍写什么内容（不是四个词）
- 碾压型力量（金手指爆发/高阶技能等）必须配限制：①启动前风险窗口 ②启动后时限 ③启动中副作用——至少1类
- 质变点前后战斗形态有本质变化（战斗方式改变），不是数值变大
- **只有规则没有可写性=废设定，write写不出好看战斗**

**战斗画风硬约束**：
- 每阶1句话描述整体气质（如阴冷压抑/飘逸华丽/硬朗写实），从源力量+物理规则+战斗方式涌现
- 画风是给write的气质指引，不是参数清单（参数由write的战斗六要素处理）

**要求**：全书所有区域列出，每个标注哪卷进入。第一卷通常在前2-3个区域，后续卷逐卷扩展。

### ✅ Part 1 检查点 · 骨架层自检

落盘前逐项对照好坏标准表，全部"好"列达成才通过：

**力量体系好坏标准**

| 维度 | 好 | 坏 | 自检 |
|:--|:--|:--|:--|
| 四层完整 | 世界源力量+主养成线(含社会地位+战斗可写性+画风)+子养成线(含阶位+挂钩)+交叉规则 | 缺任何一层 | ☐ |
| 三源合流 | 创意种子+参考书DNA+市场校准各有痕迹 | 只有一个来源 | ☐ |
| 战斗可写性 | 每阶有4拍节奏+画风+碾压型有约束 | 只有阶位名没有怎么打 | ☐ |
| 质变点 | 质变点前后战斗方式本质变化 | 只是数值变大 | ☐ |
| 社会地位参照 | 每阶有多少人/什么社会角色 | 只有阶位名没有社会含义 | ☐ |
| 原则回溯 | 关键设定回溯世界设计原则 | 凭空设计 | ☐ |

**地图好坏标准**

| 维度 | 好 | 坏 | 自检 |
|:--|:--|:--|:--|
| 力量映射 | 区域分布映射阶位梯度 | 地名列表和力量体系脱节 | ☐ |
| 空间叙事 | 每个区域有戏剧潜力（能撑什么戏） | 只有地名没有叙事价值 | ☐ |
| 信息差 | 每个区域有信息差来源 | 全知视角没有探索感 | ☐ |
| 原则回溯 | 关键区域设定回溯世界设计原则 | 凭空编地名 | ☐ |

**通过** → 落盘 `step3-part1-骨架层.md` → 进入Part 2

## Part 2 · 实体层：势力 + 危机 + 配角

### 2a. 势力全书展开表（含攀登方式标注）

| 势力层 | 势力名 | 控制什么资源 | 弱点/裂缝 | 和上层关系 | **攀登方式/生存逻辑** | **对赌角色** | **回溯原则** | **预计碰撞卷** |
|:--|:--|:--|:--|:--|:--|:--|:--|:--|
| 第1层·街头层 | | | | | （这个势力的人怎么爬/怎么活） | 提供资源/信息/障碍/对手 | 原则N | 第一卷 |
| 第2层·地方势力层 | | | | | | | | 第一卷（碰撞）/第二卷（深入） |
| 第3层·执法系统层 | | | | | | | | 第二卷/第三卷 |
| 第4层·幕后金主层 | | | | | | | | 终卷 |

**要求**：
- 4层势力全部具名设计（不是只做第一卷的前2层）。每层标注哪卷碰撞。
- 每层至少1个具名反派。
- **攀登方式/生存逻辑**（P1新增）：每个势力标注"这个势力的人靠什么活/怎么往上爬"，从力量体系+引擎行为推导，不凭空设计
- **对赌角色**（P1新增）：这个势力在主角的对赌行为中扮演什么角色（提供资源/提供信息/设置障碍/作为对手）

### 2b. 危机全书展开表

| 危机类型 | 危机描述 | 触发条件 | 来源层面 | **回溯原则** | **预计爆发卷** | 后果 |
|:--|:--|:--|:--|:--|:--|:--|
| **终极危机** | （全书终卷爆发的世界级威胁） | | 世界固有/力量内压/金手指反噬/赛道惯例 | 原则N | 终卷 | |
| **阶段性危机1** | （第一卷爆发的危机） | | | | 第一卷 | |
| **阶段性危机2** | （第二卷爆发的危机） | | | | 第二卷 | |
| **阶段性危机3** | （第三卷爆发的危机） | | | | 第三卷 | |

**要求**：1条终极危机（全书终卷爆发）+ 2-3条阶段性危机（分卷爆发）。每条标注来源层面+回溯原则。

### 2c. 全书配角设计（补充seed未覆盖的配角）

创意.md已给主角+羁绊角色。world补充全书的功能性配角——只设计角色设定，不设计剧情角色。

**全书视角**：列出全书3-8卷的主要配角（不是只第一卷的），每个标注预计在哪卷出场。

每个配角必须回答：**"这个角色在主角的对赌行为中扮演什么设定角色？"**（提供资源/提供信息/设置障碍/作为对手）

```markdown
### 配角1：[名字]
- **核心欲望**：（一句话）
- **设定角色**：提供资源（给主角关键情报，换取主角帮他解决X）
- **势力归属**：属于第N层势力
- **攀登方式代表**：（这个角色代表哪类生存/攀登逻辑）
- **关系张力**：（和主角的利益冲突点在哪）
- **预计出场卷**：第X卷

### 配角2：[名字]
...
```

### ✅ Part 2 检查点 · 实体层自检

**势力好坏标准**

| 维度 | 好 | 坏 | 自检 |
|:--|:--|:--|:--|
| 4层全具名 | 4层势力全部有名字+代表人物 | 只做前2层 | ☐ |
| 攀登标注 | 每个势力有攀登方式/生存逻辑 | 势力是孤岛，不知道靠什么活 | ☐ |
| 对赌角色 | 每个势力标注在主角对赌中的角色 | 势力和主角主线无关 | ☐ |
| 弱点结构性 | 弱点是攀登方式导致的必然弱点 | 弱点是随机编的 | ☐ |
| 地图附着 | 势力地盘扎根在地图区域上 | 势力和地图脱节 | ☐ |
| 原则回溯 | 关键势力设定回溯世界设计原则 | 凭空设计 | ☐ |

**危机好坏标准**

| 维度 | 好 | 坏 | 自检 |
|:--|:--|:--|:--|
| 四源覆盖 | 世界固有/力量内压/金手指反噬/赛道惯例 至少覆盖2-3类 | 只有一种危机来源 | ☐ |
| 因果涌现 | 危机从力量体系+势力+地图推导 | 随机外部威胁 | ☐ |
| 倒计时感 | 每条危机有触发条件+恶化路径 | 危机只有描述没有时间压力 | ☐ |
| 原则回溯 | 关键危机回溯世界设计原则 | 凭空编灾难 | ☐ |

**通过** → 落盘 `step3-part2-实体层.md` → 进入Part 3

## Part 3 · 导航层：各卷设定切片

给plot提供"各卷该取哪些设定"的导航。不是详细剧情——是设定切片的索引。

```markdown
### 第一卷设定切片
- **力量范围**：阶位1-阶位2
- **地理范围**：区域A+区域B
- **势力范围**：第1层（碰撞）+第2层（初接触/暗示）
- **危机范围**：阶段性危机1爆发，终极危机暗示
- **核心配角**：（本卷出场哪些配角）
- **卷末设定边界**：主角触及但未进入区域C/阶位3
- **回溯原则**：（本卷主要体现哪几条设计原则）

### 第二卷设定切片
- **力量范围**：阶位2-阶位3
- **地理范围**：区域B+区域C
- **势力范围**：第2层（深入）+第3层（碰撞）
- **危机范围**：阶段性危机2爆发
- **核心配角**：...
- **卷末设定边界**：...
- **回溯原则**：...

### 第三卷及后续同上格式
```

### ✅ Part 3 检查点 · 导航层自检

| 检查项 | 通过标准 | 自检 |
|:--|:--|:--|
| 卷数完整 | 3-8卷切片全部列出 | ☐ |
| 边界清晰 | 每卷有卷末设定边界（下一卷钩子） | ☐ |
| 原则回溯 | 每卷标注主要体现的设计原则（≥1条） | ☐ |
| 梯度合理 | 力量/地图/势力/危机逐卷梯度展开，不跳级 | ☐ |
| 配角分配 | 每卷有对应核心配角标注 | ☐ |

**通过** → 落盘 `step3-part3-导航层.md` → Step 3完成 → 进入Step 4
