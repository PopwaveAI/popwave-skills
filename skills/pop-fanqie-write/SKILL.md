# pop-fanqie-write

> 番茄正文渲染。从ch002开始，章型骨架驱动结构，笔触DNA驱动笔触。v8.6.0：新增剧情白描流水账长线锚（每章白描append-only，回溯全书历史）。

## 做什么

输入：项目上下文（设计/第一卷剧情/剧情白描.md+审核/剧情白描流水账.md+设计/全书设定/+current-state.md+前章正文+设定库精选）+本章锚点+笔触DNA（三态协议）
输出：2000-2500字章节正文（不准超过2500字），附交付面板

write从ch002开始（ch001由seed产出）。消费plot产出的剧情白描.md——**剧情白描=向前锚（定位本章场景表），剧情白描流水账=长线锚（全书历史，review按章追加），current-state=向后锚（上一章白描）**，逐章渲染。续写项目必须先由plot补建剧情白描.md再写，禁止用章锚点表替代。

## 怎么操作（SOP骨架）

> execution.mode: 串联式 | 强保障：本SKILL.md由host层强制注入 | 弱保障：steps/references/scripts需agent主动读取，设计时假设可能没读到

- **Step 1** 加载燃料（内化）→ 1a全文加载(**剧情白描.md=向前锚·定位本章场景表** > **剧情白描流水账.md=长线锚·全书历史** > **current-state.md=向后锚·上一章白描** > 全书设定 > 创意 > 前章)→1b设定库精选注入(≤3维度≤1500字,角色库必选)→1c笔触DNA三态协议(启用态/禁用态/trial态,战斗升级场景必须面板格式)→1d回收前章钩子
- **Step 2** 选章型+章意图思考 → `steps/step2.md`（6种章型选1）
- **Step 3** 写正文（内化·三层指导）→ 结构层(6种章型7节拍骨架,字数分配)→节奏层(事件间隔≤20行,密度8-12个/章,微钩子每3-5行)→爽感层(主推爽感必触发,爆发后三段式:爆发≤3行→反馈≤2段→余韵≥1段)→技法层(从微观技法索引选2-3类落地)
- **Step 4** 篇幅硬限制检查+落盘 → `steps/step4.md`
- **Step 5** 交付面板+人机共创 → `steps/step5.md`

### 6种章型

| 章型 | 使用条件 | 读者期待 |
|:--|:--|:--|
| opening_shift | 第一章/规则松动/金手指激活 | 先信现实→被打开更大世界 |
| exploration_gain | 进入新地点/发现资源/秘境探索 | 跟着主角挖宝 |
| confrontation_pressure | 对峙/打脸/信息差博弈 | 看打脸反转 |
| combat_reversal | 战斗/绝境翻盘/首杀 | 看绝境翻盘 |
| high_tier_display | 高位者出场/格局展示 | 看碾压+立志 |
| reveal_hook | 揭秘/新敌人/升级/章末钩子 | 看真相炸裂 |

## 红线

1. **读取协议**——读取skill文件用`Get-Content -Encoding UTF8 -Raw`，Read工具有行数限制会截断丢内容
2. **每章必须全文加载剧情白描+剧情白描流水账+current-state+全书设定+角色库**——禁止用current-state替代立项包，设定库禁止全文注入（≤3维度≤1500字，角色库维度必选）
3. **篇幅硬限制2000-2500字不准超过2500字**——超2500字=废章必须裁剪，章型必选（6种选1按7节拍骨架），爽感≥1/章
4. **ch001由seed产出write从ch002开始**——ch002必须回收ch001章末钩子，每章必须以主动钩子或威胁逼近收尾
5. **笔触DNA标准插槽三态协议**——启用态从DNA取/禁用态无DNA/trial态用户声明，战斗/升级场景必须使用DNA面板格式（即时反馈面板/成长反馈面板），禁止战斗/升级场景无面板
6. **不写思考过程/检查表**——直接写正文，每章正文开头必须有正常章节名
7. **Step文件链式加载**——Step1+3内化→step2.md→step4.md→step5.md，禁止跳过
8. **微观技法每章选2-3类**——从微观技法索引按章型推荐组合选，不超过3类/章，禁止堆砌技法（技法是调料不是主菜）

## 🗺️ 知识地图（reference 读取索引）

> **每次 run 先扫本表**——它告诉你"有哪些参考书、什么时候必须读"。写崩级（缺了就写废正文）标注🔴，触发时才读；提品级标注🟡，卡壳时选读。**看就记住，别读全文**。

| 参考 | 级别 | 什么时候必须读（触发条件） |
|:--|:--|:--|
| `references/章型定义.md` | 🔴写崩级 | **Step2 选章型时必读**——6种章型7节拍骨架+密度约束，缺它7节拍结构会写散 |
| `references/爽点引擎.md` | 🔴写崩级 | **Step3 设计爽感爆发段前必读**——5种爽感引擎+爆发后三段式，缺它爽感会写成平铺 |
| `references/微观技法索引.md` | 🟡提品级 | 技法选择时读——3类16种技法索引+按章型推荐，选2-3类后加载对应技法文件 |
| `references/通用技法/*.md` | 🟡提品级 | 选定了具体技法后读——5个通用技法详细文件（人设微操/信息差博弈/后果链设计/节奏微操/预期违背） |
| `references/technique.md` | 🟡提品级 | 卡壳时快速翻——代入感/流水账/去油旧版参考卡 |

**判定规则**：🔴写崩级=不读则正文成色崩坏，属条件必读，Step内已绑定触发；🟡提品级=不读只是少个技巧，靠卡壳时自查。**agent 若发现正文字数/结构/爽感不达标，先回查知识地图找对应参考，再动手改。**
