# 章型定义

> **v8.5.0升级：4章型→6章型**，从起点write章型体系迁移exploration_gain和high_tier_display两种。每种7节拍骨架。plot选章型时锁定密度约束，write按7节拍骨架渲染。
> 为什么加2种：番茄白描中有大量"探索新地点/发现资源"和"高位者出场展示格局"的场景，以前硬塞进confrontation_pressure或reveal_hook里，节拍不对位导致爽感错位。给这两类场景独立章型，让骨架和读者期待对齐。

---

## 6种章型速查

| 章型 | 使用条件 | 读者期待 | 主动行为类型 |
|:----|:--------|:--------|:------------|
| opening_shift | 第一章/世界规则松动/金手指激活 | 先信现实→被打开更大世界 | 收获/质变级反馈 |
| exploration_gain | 进入新地点/发现资源线索/秘境探索 | 跟着主角探索未知 | 主动出击/收获 |
| confrontation_pressure | 对峙/打脸/信息差博弈/势力试探 | 看打脸反转 | 宏观层面解决问题 |
| combat_reversal | 战斗/绝境翻盘/首杀/暗杀 | 看绝境翻盘 | 战斗 |
| high_tier_display | 远超主角层级的战斗/人物出场/格局展示 | 看格局碾压+立志 | 获得反馈/树立目标 |
| reveal_hook | 揭秘/新敌人/升级/章末钩子 | 看真相炸裂 | 获得反馈/质变级反馈 |

---

## 密度约束

每种章型自带密度约束。plot选类型时自动锁定，write必须遵守。

| 章型 | 战斗密度 | 系统交互密度 | 冲突密度 |
|:----|:--------|:--------|:--------|
| opening_shift | 无要求 | ≥1次（金手指激活） | ≥1次外部压力 |
| exploration_gain | 无要求（可有探索型危险） | ≥1次检定/扫描 | ≥1次信息差展示 |
| confrontation_pressure | 无要求 | ≥1次（主角用系统分析） | ≥1次信息差博弈 |
| combat_reversal | 必须有战斗（占比≥30%） | 战斗后必须弹系统反馈 | ≥1次正面交锋 |
| high_tier_display | 可有可无（高位展示型） | 可弹格局面板/怪物鉴定 | ≥1次位阶展示 |
| reveal_hook | 无要求 | 可弹升级/伏笔/异常面板 | ≥1次信息揭露一半 |

**密度分配原则**：前5章不允许连续2章无战斗类章型。前5章至少1章是combat_reversal。

## 7节拍骨架

每种章型7个节拍。节拍功能定义是通用的，笔触绑定在笔触DNA模板中。

### opening_shift（开篇/世界松动章）

| 节拍 | 功能 |
|:----|:----|
| 1 起笔 | 现实常识/日常/机构秩序 |
| 2 第一信息变化 | 不合常理的数据/痕迹/目击 |
| 3 压力/诱因 | 权威或群体无法解释 |
| 4 主角动作或判断 | 接近异常 |
| 5 阻碍升级 | 异常是更大物象的一角（爽感爆发点） |
| 6 可见反馈 | 群体失语/机构失效/常识崩裂 |
| 7 章末钩子 | 异常继续逼近或呼叫下一层真相 |

### exploration_gain（探索/资源露头章）

> **新增v8.5.0**：专门处理"进入新区域/发现资源/秘境探索"类场景。核心读者期待是"跟着主角挖宝"，爽感来自未知→收获的闭环。

| 节拍 | 功能 |
|:----|:----|
| 1 起笔 | 环境反常或生物异常（新区域的第一印象） |
| 2 资源/线索露头 | 发现目标物象（宝物/线索/特殊资源的痕迹） |
| 3 危险阻挡 | 或别人不敢拿/有守卫/有禁制 |
| 4 判断收益，冒险 | 主角选择深入/尝试获取（展示主角的判断力和胆量） |
| 5 危险扩大或深处异动 | 爽感爆发点（获取过程中的惊险一刻） |
| 6 资源到手/能力变化 | 获得回报（可见的战利品/新信息/能力变化） |
| 7 更深处还有更大变化 | 章末钩子（暗示区域深处还有更大的东西） |

### confrontation_pressure（对峙/压力章）

| 节拍 | 功能 |
|:----|:----|
| 1 敌方/高位者给压力 | 出场即轻视 |
| 2 对方暴露目的/误判 | 筹码出现 |
| 3 语言羞辱/身份压制 | 被欺蓄力 |
| 4 沉默/反问/亮筹码 | 暗蓄 |
| 5 对方加码/旁人围观 | 爽感爆发点（被欺→反击） |
| 6 对方失态/局势微反转 | 打脸反馈 |
| 7 矛盾升级到下一场行动 | 章末钩子 |

### combat_reversal（战斗/反击章）

| 节拍 | 功能 |
|:----|:----|
| 1 明确对方优势/主角劣势 | 出场即轻视 |
| 2 主角发现缝隙/变量 | 物象出现 |
| 3 对方攻击/羞辱/封路 | 压制蓄力 |
| 4 不解释，直接执行 | 暗蓄 |
| 5 对方后手/位阶压制超预期 | 爽感爆发点（压力→突破）。内部=压制段≤3段+爆发段≤3行 |
| 6 身体损伤/法器破碎/敌人失态 | 代价必须可见且不可逆 |
| 7 反击引来更高后果 | 章末钩子 |

### high_tier_display（高位展示/格局章）

> **新增v8.5.0**：专门处理"高位存在出场/远超主角层级的战斗展示"类场景。核心读者期待是"看格局碾压+主角立志"，爽感来自未知→揭示（世界原来这么大）+ 压力→动力（主角要爬到那个高度）。

| 节拍 | 功能 |
|:----|:----|
| 1 高位存在出场/气息压场 | 威压即事件（一个动作/一句话全场变色） |
| 2 普通判断失效 | 独句段（主角/读者的认知被打碎） |
| 3 旁观者/环境承受不住 | 侧面定级（用环境破坏/旁观者反应反衬强度） |
| 4 观察/避让/借势/立志 | 主角动作（主角的反应——震撼/羡慕/立下目标） |
| 5 高位行为造成大范围后果 | 爽感爆发点（未知→揭示——世界的层级比想象中高得多） |
| 6 天地/组织/群众影响变化 | 反馈（这场展示对世界/势力的影响） |
| 7 主角未来必须抵达此层级 | 章末钩子（主角的新目标/新的成长动力） |

### reveal_hook（揭秘/章末钩子章）

| 节拍 | 功能 |
|:----|:----|
| 1 上一场结果/异常余波 | 余波开场 |
| 2 新解释出现 | 信息句清楚 |
| 3 解释带来更大危险 | 短句施压 |
| 4 选择追查/隐瞒/反击 | 主角动作 |
| 5 新信息牵出更高层 | 爽感爆发点（未知→揭示） |
| 6 关系/组织判断改变 | 反馈 |
| 7 下一章必须进入新场面 | 章末钩子 |

## 技法推荐组合

每种章型推荐的微观技法组合（可调整，但不超过3类）：

| 章型 | 推荐组合 |
|------|---------|
| opening_shift | 信息差博弈 + 感官锚点 + 预期违背 |
| exploration_gain | 世界观渐进揭示 + 感官锚点 + 后果链设计 |
| confrontation_pressure | 信息差博弈 + 人设微操 + 节奏微操 |
| combat_reversal | 节奏微操 + 感官锚点 + 后果链设计 |
| high_tier_display | 高位视角插入 + 恐怖奇观美学化 + 感官锚点 |
| reveal_hook | 预期违背 + 后果链设计 + 信息差博弈 |

## 关于升级和情感

升级面板和情感锤击不单独成章型：
- **升级面板**：嵌在combat_reversal的节拍6（代价/反馈）或reveal_hook的节拍6（关系/判断改变）中。如果某章的核心事件是升级，用reveal_hook章型，在事件方向中写明升级内容。
- **情感锤击**：嵌在任何章型的节拍中（如opening_shift的节拍1用配角视角建立情感锚点）。不单独成章，但在章意图中标注本章有情感锤击内容。

## 章型选择原则

1. **第一章必选opening_shift**——黄金开篇
2. **探索/新地点/资源发现选exploration_gain**——跟着主角挖宝
3. **对峙/谈判/打脸选confrontation_pressure**——信息差博弈
4. **战斗场景选combat_reversal**——绝境翻盘
5. **高位者出场/格局展示选high_tier_display**——看碾压+立志
6. **揭秘/升级/新敌人选reveal_hook**——真相炸裂
7. **不要硬塞**——场景核心事件是什么就选什么章型，探索就是探索，展示就是展示，别塞进对峙或揭秘里
