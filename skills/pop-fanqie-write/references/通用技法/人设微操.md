# 人设微操

> 通过小动作、小习惯、小矛盾让角色立体，不靠外貌描述和旁白定义，靠行为让读者自己感受人设。
> 适用章型：confrontation_pressure / opening_shift / exploration_gain

---

## 子技法清单

| 子技法 | 一句话说明 | 用在哪 |
|:--|:--|:--|
| 标志性小动作 | 一个专属动作反复出现，建立识别度 | 角色出场/思考/紧张时的习惯动作 |
| 口癖/语言指纹 | 说话有独特用词或句式，一听就知道是谁 | 对话场景，不用标"XX说"也能分辨 |
| 反向小习惯 | 人设和小动作反差，增加层次 | 冷酷大佬喜欢喂猫/暴躁老哥会做针线活 |
| 行为一致性 | 角色做选择时符合人设，不崩 | 关键决策点，用行为证明人设不是说说 |
| 人设小矛盾 | 角色身上有两个看似冲突的特质 | 贪财但讲义气/胆小但底线硬 |
| 环境映射 | 角色的住处/随身物品反映性格 | 第一次进角色房间/翻角色口袋 |
| 他人视角反衬 | 通过别人的评价/反应侧面立人设 | 路人议论/对手评价，比主角自夸有效 |

---

## 怎么用

### 使用步骤
1. 确定本章要强化的人设标签（比如"冷静"、"贪财"）
2. 选2-3个子技法，设计对应的行为细节
3. 把细节揉进剧情里，不要单独拎出来写
4. 同一个人设标签用不同子技法反复强化，形成记忆点

### 注意事项
- 每章人设微操不超过3处，多了喧宾夺主
- 人设是"做"出来的，不是"说"出来的——别让旁白告诉你他很冷静
- 小动作要和当前场景相关，不能为了加细节而硬加

### 反例（别这么写）
- 开篇就写"他是一个冷酷无情但内心温柔的男人"——直接定义，没味道
- 每个角色都有"嘴角勾起一抹弧度"，没有辨识度
- 人设和行为打架：上章说他冷静，这章遇事就暴走
