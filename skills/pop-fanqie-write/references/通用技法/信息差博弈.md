# 信息差博弈

> 围绕"谁知道什么"设计三方信息不对等，读者知道的比角色多/少，产生上帝视角快感或解谜快感。
> 适用章型：opening_shift / confrontation_pressure / reveal_hook

---

## 子技法清单

| 子技法 | 一句话说明 | 用在哪 |
|:--|:--|:--|
| 上帝视角差 | 读者知道反派阴谋，主角不知道，替主角着急 | 对峙章开头，先切反派视角露底 |
| 主角藏底牌 | 主角有后手，反派/读者都不知道，最后亮出 | 对战/谈判后半段反转用 |
| 反派误判 | 反派以为掌握了主角信息，其实是错的 | 打脸章前半段铺垫反派自信 |
| 观众信息差 | 围观群众不知道真相，只有读者+主角知道 | 装逼打脸场景，群众反应制造爽感 |
| 信息延迟揭露 | 一件事分几次揭示，每次揭一层 | 悬念章末钩子，只露冰山一角 |
| 假信息误导 | 角色故意散布假消息，引对方入套 | 智斗/布局类章节 |
| 信息交易 | 角色用信息作为筹码交换利益 | 谈判/合作场景 |
| 失忆/遗忘差 | 主角忘了某件事，读者记得，产生焦虑 | 重生/穿越流，主角遗漏关键信息 |

---

## 怎么用

### 使用步骤
1. 先确定本章三方（主角/对手/读者）各自的已知信息边界
2. 选1-2个信息差子技法，明确"谁比谁多知道什么"
3. 在章中前段铺设信息差（让读者感知到不对等）
4. 章末或下一章利用信息差产生反转/爽感

### 注意事项
- 每章最多2个信息差，太多读者记不住
- 读者知道的信息必须通过画面展示，不能旁白硬塞
- 信息差必须在2-3章内兑现，不能埋太久

### 反例（别这么写）
- 开篇用大段旁白说"主角不知道的是，一场阴谋正在酝酿"——太直白，没画面
- 一章塞5个反转，每个反转都是新信息，读者脑壳疼
- 信息差埋了十章才揭晓，读者早忘了
