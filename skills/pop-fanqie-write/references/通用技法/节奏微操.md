# 节奏微操

> 一章内快慢交替、张弛有度，通过段落长度、场景切换、信息密度控制读者的阅读呼吸感。
> 适用章型：combat_reversal / confrontation_pressure / high_tier_display

---

## 子技法清单

| 子技法 | 一句话说明 | 用在哪 |
|:--|:--|:--|
| 短句爆破 | 连续短句子、短段落，制造紧迫感 | 战斗高潮/追逐戏/关键反转 |
| 长句铺陈 | 长句+多细节描写，放慢节奏，蓄力 | 战前压抑/环境渲染/情绪铺垫 |
| 信息密度变速 | 一段塞很多信息，下一段几乎没信息 | 揭秘段后接一段放空，给读者消化 |
| 场景快切 | 多个短场景快速切换，制造双线并行感 | 同时发生的两件事，交替出现 |
| 停顿留白 | 关键时刻插一句环境描写/内心活动 | 大招前的屏息/重磅消息后的反应 |
| 倒计时压迫 | 给事件加时间限制，越接近越紧张 | 限时任务/爆炸倒计时/日出前必须完成 |
| 重复句式 | 相同结构句子连续出现，强化节奏感 | 排比式攻击/层层递进的揭示 |
| 视角跳跃 | 在不同角色视角间快速切换 | 群像戏/多方混战，每个人看到的都不同 |
| 慢动作分解 | 一个瞬间拆成好几步写，拉长时间 | 致命一击/关键决定，放大瞬间 |
| 加速跳过 | 用一句话跳过一段过程，直接到结果 | 赶路/训练/准备工作，不重要就快进 |
| 插叙缓冲 | 紧张段落中插一段回忆/日常，松一下 | 大战前插一段和亲人的回忆，增加情感重量 |

---

## 怎么用

### 使用步骤
1. 把本章切成3-4段节奏块（起-承-转-合）
2. 给每块定节奏：快/中/慢，形成快慢交替
3. 高潮块用短句爆破+慢动作分解，蓄力块用长句铺陈+停顿留白
4. 整章读下来像过山车：有爬坡有俯冲有失重

### 注意事项
- 一章至少有一次节奏变化，不能全程快或全程慢
- 番茄读者耐心有限：慢的部分别超过半章，快的部分别短到看不清
- 节奏是为情绪服务的，不是为炫技——该快的时候快，该慢的时候慢

### 反例（别这么写）
- 全程都是长段落大段描写，读者翻两页就划走
- 全程都是短句子对话，像看剧本，没有代入感
- 每段都在反转，每句都在爆炸，读者疲劳到麻木
