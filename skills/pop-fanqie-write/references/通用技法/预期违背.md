# 预期违背

> 先通过铺垫让读者建立"事情应该会这样发展"的预期，然后在关键节点打破它，产生错愕和惊喜。
> 适用章型：reveal_hook / opening_shift / combat_reversal

---

## 子技法清单

| 子技法 | 一句话说明 | 用在哪 |
|:--|:--|:--|
| 身份反转 | 读者以为是路人甲，结果是大佬/仇人/亲人 | 人物出场的后半段，揭开真实身份 |
| 结果反转 | 以为赢了其实输了/以为输了其实赢了 | 战斗/赌约/谈判的最后一秒 |
| 动机反转 | 以为对方是来害你的，其实是来帮你的 | 对峙中段，解释对方真实目的 |
| 道具反转 | 以为没用的东西是关键/以为厉害的是废物 | 寻宝/鉴宝/战斗中道具的真实作用 |
| 场景反转 | 以为在A地，其实在B地/以为是现实是幻境 | 悬疑/惊悚类，环境认知被推翻 |
| 关系反转 | 以为是敌人其实是盟友/以为是朋友其实是内鬼 | 阵营类章节，信任崩塌或化敌为友 |

---

## 怎么用

### 使用步骤
1. 确定要违背什么预期（身份/结果/动机/道具/场景/关系）
2. 在前半章用2-3个细节"加固"读者的错误预期（让他深信不疑）
3. 反转点放在章中后段或章末，一击到位
4. 反转后立刻给1-2个"回头看合理"的细节，让读者觉得不是硬转

### 注意事项
- 反转必须有伏笔支撑，不能空降——读者回头看要觉得"原来早有暗示"
- 一章一个大反转就够了，小反转可以搭配1-2个
- 反转后要立刻有新问题/新钩子，不能反转完就结束了
- 预期铺垫要自然，不能为了反转故意把读者当傻子

### 反例（别这么写）
- 前面完全没铺垫，突然说"其实他是你失散多年的亲爹"——硬转，读者骂街
- 每章都反转，反转到读者已经麻木了，反正什么都是假的
- 反转后没有后续，只是为了爽一下，没有推动剧情
