## 2a. 选章型

> **触发锚定**：选章型前**必须加载** `references/章型定义.md`（🔴写崩级）——6种章型7节拍骨架+密度约束是正文结构的真源，禁止凭记忆从下表硬套。下表是速查摘要，完整骨架以参考为准。

从6种章型中选1个（详见 `references/章型定义.md`）：

| 章型 | 使用条件 |
|:----|:--------|
| opening_shift | 第一章/世界规则松动/金手指激活 |
| exploration_gain | 进入新地点/发现资源线索/秘境探索 |
| confrontation_pressure | 对峙/打脸/信息差博弈/势力试探 |
| combat_reversal | 战斗/绝境翻盘/首杀/暗杀 |
| high_tier_display | 远超主角层级的战斗/人物出场/格局展示 |
| reveal_hook | 揭秘/新敌人/升级/章末钩子 |

**选择依据**：白描中本章的核心事件类型+本章章意图。

**锁定密度约束**：选定章型后，自动锁定该章型的战斗密度/系统交互密度/冲突密度。

**选择原则**：场景核心事件是什么就选什么章型，不要硬塞。探索就是探索，展示就是展示。

## 2b. 章意图思考

回答3个问题（想清楚再写，不写在正文里）：

1. **本章核心事件是什么**？（1句话）
2. **本章爽感爆发点在哪**？（对应章型7节拍的哪个节拍）
3. **本章章末钩子是什么**？（主动钩子或威胁逼近）

## 2c. 爽感引擎选择

> **触发锚定**：设计爽感爆发前**必须加载** `references/爽点引擎.md`（🔴写崩级）——爆发后三段式（触发→爆发→后果）是爽感闭环的真源，禁止凭下表大意写平淡爆发。

从5种爽感引擎中选1-2个（详见 `references/爽点引擎.md`）：

| 章型 | 主推爽感 | 次推爽感 |
|------|---------|---------|
| opening_shift | 压力突破 | 未知揭示 |
| exploration_gain | 即时奖励 | 未知揭示 |
| confrontation_pressure | 打脸循环 | 即时奖励 |
| combat_reversal | 压力突破 | 小爽沿途 |
| high_tier_display | 未知揭示 | 压力突破（转化为动力） |
| reveal_hook | 未知揭示 | 小爽沿途 |

**主推必触发**，次推可选。

**爽感必须闭环**：触发→爆发→后果，缺一不可。

## 2d. 微观技法选择

从 `references/微观技法索引.md` 中选2-3类（不超过3类/章）。优先选章型推荐组合里的：

| 章型 | 推荐组合 |
|------|---------|
| opening_shift | 信息差博弈 + 感官锚点 + 预期违背 |
| exploration_gain | 世界观渐进揭示 + 感官锚点 + 后果链设计 |
| confrontation_pressure | 信息差博弈 + 人设微操 + 节奏微操 |
| combat_reversal | 节奏微操 + 感官锚点 + 后果链设计 |
| high_tier_display | 高位视角插入 + 恐怖奇观美学化 + 感官锚点 |
| reveal_hook | 预期违背 + 后果链设计 + 信息差博弈 |

**使用方式**：
1. 从推荐组合中确认2-3类
2. **加载对应技法文件**（不是索引文件）——先读 `references/微观技法索引.md` 定位到具体技法，再读 `references/通用技法/{技法名}.md` 拿详细指导
3. 挑1-2个子技法落地到本章具体场景
4. 在交付面板"微观技法"字段填写选了哪几类+落地位置

**硬约束**：
- 每章≤3类技法，禁止堆砌（技法是调料不是主菜）
- 每类技法只选1-2个子技法落地，不要全铺
- 技法必须服务于爽感爆发或角色塑造，不为炫技而用
