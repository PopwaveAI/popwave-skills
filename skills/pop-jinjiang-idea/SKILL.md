# pop-jinjiang-idea

> 创意环节（晋江）：访谈收敛、定位候选、故事核心。只做决策级，不写设定、人物卡、卷纲或正文。
> 当前版本 2.0.0。

## 负责什么

输入：用户一句话、一个角色、一个场面、一段设定、一份外部大纲，或什么都没有。

输出：

- `立项/brief候选.md`：2–3 个定位候选全文，每个 ≤300 字。
- `立项/故事.md` 的「故事核心」段：一句话梗概、一段话梗概、主线设计、支线设计、剧情循环。
- 交接：已锁定项、待定项、用户原话、下一步。

不负责：世界观、金手指落地、人物卡、卷纲、章纲、正文；这些交给 `pop-jinjiang-setting` / `pop-jinjiang-character` / `pop-jinjiang-plot` / `pop-jinjiang-write`。

## 流程

### Step 0 接住已有的

1. 逐字收下用户本轮原话，不摘要。
2. 拆出已有元素：赛道、标签、主角、场面、终点、感觉、对标书、外部大纲。
3. 读项目已有资产：旧立项稿、旧大纲、拆书成果、文风档、历史正文、`.popwave/metrics/recap.json`。已确认的不重问。

### Step 1 需求访谈（最多 3 轮）

读 `references/访谈问题库.md`：

- 轮一·定位：平台与篇幅、主分类与标签、对标与「读者图什么」。
- 轮二·偏好：爽点类型、雷点/禁区、主角底线与感情线。
- 轮三·方向：差异化方向、终点期待、金手指偏好。

每题 2–4 个候选 + 「其他」；用户已回答的不重问；跳过的标「待定」，不阻塞。访谈结束把决策写进故事.md 头部的「用户偏好卡」。

### Step 2 读题材弹药

1. 读 `references/题材弹药/00-索引.md`，按主分类找对应文件；读 `references/晋江标签库.md` 校准标签。
2. 有文件时挑 5–8 条可打的弹药摆给用户：开局 2–3、破局 2–3、循环 2、金手指/替代驱动 2。
3. 没文件时先查站内 knowledge / 公开资料，最多 5 个检索项，补一份最小弹药卡；其余标「待补」。
4. 用户选 3–5 条后，原样写进偏好卡「选定弹药」。

### Step 3 定位候选

调 `popwave-write-idea`，协议 v2：

- `protocolVersion`：2；`brief`：一句"出定位候选"。
- `context` 按段标题装：必填 `【用户原话】【已确认决策】【平台与分类】`；可选 `【总控头卡】`（用 `popwave_project_site_read` 读 `/profile`）、`【题材弹药参考】【对标开局】【已有角色锚点】`。
- 只装用户选过或本轮要用的弹药；不要把整份弹药卡塞进去。
- 候选之间必须换世界、换主角位置或换终点；只换措辞不算；不写第一章细节。

候选全文先写入 `立项/brief候选.md`，一个候选一节。用 Ask 让用户选或合成；选项正文只写一句核心，`reference.path` 指到文档里的候选小节。用户不选就停，不自动选推荐。

### Step 4 故事核心

用户选定后，把候选全文（≤300 字）并入 `【已确认决策】`，再调 `popwave-write-idea`：

- `context` 必填 `【用户原话】【已确认决策】【平台与分类】`；可选 `【总控头卡】【题材弹药参考】【对标开局】`。
- 产出：一句话 ≤60 字；一段话 300–500 字、六要素齐全；主线四阶冲突；支线 2–4 条、每条四栏；循环 4–6 拍。
- 不写正文句、不写对白、不写设定机制。

工具产出原样填进 `立项/故事.md` 的「故事核心」段，主 agent 只做格式与配额检查，不重写故事。

### Step 5 门禁

1. 偏好卡每一项写明落在哪一节，或写「未满足·原因」。
2. 合上材料，150 字能讲清「谁、要什么、谁挡着、怎么推进、结局往哪去」。
3. 故事核心四小节齐全，配额达标，未确认项标「待定」。

不过就回对应步骤补，不进入下一环节。

### Step 6 交接

在故事.md 末尾写：已锁定项、待定项、用户原话、下一步（默认 `pop-jinjiang-setting`）。

用 `popwave_project_site_update` 同步总控头卡：`profile` 写 name／oneLine／genre／storyLine／styleDna／tags（读不出就不写），`rules` 写本书规则；没变化不调用。

## 红线

1. 不替用户拍板；用户不选，推荐不算数。
2. 不把「待定」写成定论。
3. 不发明用户没选的弹药。
4. 不写设定、人物卡、卷纲、正文。
