# 题材弹药卡 · 古风世情

> 定位：访谈弹药库，不是写作配方。只收结构、套路与事实；礼制、称谓、经济细节标来源，查不到标「待核」。

## 一、定义与定位

- 平台标签：古风世情 + 宅斗 / 宫斗 / 权谋 / 婚恋 / 嫡庶 / 家族。
- 一句话：古代家宅或宫廷里，女主在礼教与家族规则内争位置、争婚事、争活路，靠脑子与人心往上走。
- 常见篇幅：80-150 万字为主；30 万字写一段宅斗/婚事；200 万+ 要换图到宫廷/天下。
- 近邻与区别：与「宫斗宅斗」的区别是世情更重生活与家族；与「古言脑洞」的区别是不靠穿越系统，重规则内博弈。

## 三、读者期待（5-8 条）

1. **宅斗/宫斗**：姐妹、继母、妾室、婆家，明枪暗箭。
2. **规则内博弈**：不能随便杀人，要靠礼法、人情、证据。
3. **婚恋**：先婚后爱、双向试探、克制情感。
4. **女主成长**：从被动到掌家、掌权。
5. **家族/宫廷结构**：嫡庶、品级、诰命、月例，写得可信。
6. **反转**：以为的好人另有目的，以为的敌人有苦衷。
7. **不憋屈**：女主可以忍一时，但要有反击。

## 四、常见套路（8-12 条）

- **开局**：穿越/重生嫡女庶女；继母陷害；被退婚；家宅争产；入宫/入府。
- **破局**：管家查账；借力打力；站队；婚事谈判；医术/绣艺/厨艺立身。
- **升级**：庶女→嫡妻→掌家→诰命→宫妃/太后。
- **打脸/反转**：继母/姐妹自食其果；婆家/宫里靠山倒台。
- **换图**：家宅 → 侯府/王府 → 宫廷 → 天下。

## 五、反套路清单（5-8 条）

1. **同类都困在宅斗 → 本书直接分家/和离**：不陪烂人玩，拿钱走人。风险：古代女性独立难，要写清制度卡点。
2. **同类都嫁高门 → 本书搞事业/低嫁**：开铺子、做绣坊、当女先生。风险：古代女性经商受限，要挂靠家族/夫家。
3. **同类都靠男主救 → 本书女主自己破局**：用证据、账本、人心。风险：男主魅力下降，要写「并肩」。
4. **同类都当圣母 → 本书有底线地反击**：不害无辜，但不原谅。风险：女主不能太狠，要留人情。
5. **同类都宅斗重复 → 本书换规则**：从家宅到商战/宫廷/地方治理。风险：换图要合理，不能突兀。
6. **同类都反派降智 → 本书反派有立场**：继母/姐妹也有生存逻辑。风险：女主赢得慢，要设计智力爽点。
7. **同类都现代词汇 → 本书用古代称谓/礼制**：称呼、请安、月例、诰命要准。风险：考据成本高。

## 七、雷点 / 毒点（5-8 条）

1. 现代词汇/观念乱入，古代人秒懂平等自由。
2. 嫡庶、品级、称谓、月例写错。
3. 女主降智，靠男主/男配救场。
4. 宅斗重复，同一招用十次。
5. 反派无脑恶，没有立场与弱点。
6. 女主圣母，被陷害还原谅。
7. 宫廷/家族权力儿戏，随便杀人没人管。
8. 感情线工业糖精，先婚后爱没有博弈。

## 九、事件种子与分卷阶梯

**事件种子（10-15 条）**

1. 及笄礼上，继母送错衣裳，女主当众难堪。
2. 婚事被换，女主被许给「病秧子」。
3. 管家账本对不上，女主查出亏空。
4. 姐妹栽赃，女主用证据反杀。
5. 婆家刁难，女主立规矩。
6. 宫里选秀/赐婚，女主被迫入局。
7. 家族站队，女主押中赢家。
8. 女主开铺子/绣坊，被同行封杀。
9. 男主身份揭晓，婚事重谈。
10. 继母/姐妹背后靠山倒台。
11. 灾年/战乱，女主用存粮/医术救人。
12. 女主和离/分家，自立门户。
13. 终敌不是宅里人，而是规则/皇权。
