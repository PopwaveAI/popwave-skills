## 一、故事核心（800-1200 字）

### 1. 一句话梗概（≤60 字）

{必须含：反差点 + 金手指 + 目标 + 时代。例：顶级私厨重生 1973，靠百味情绪面板走合规特供路线，从大队伙夫做到餐饮教父。}

### 2. 一段话梗概（300-500 字）

{六要素齐全：谁 / 什么处境 / 要什么 / 谁挡着 / 付出什么 / 最后成了什么。读给没看过的人听，对方能复述。}

### 3. 主线设计

- **核心爽点**（3 条）：{每条一句，写清读者拿到什么快感}
- **终极目标**（1 句）：{主角最后要拿到什么，落到具体地位/资源/关系}
- **核心冲突演变**（4 阶）：{生存资源 → 话语权 → 编制/指标/特供权 → 行业标准/资本；可按题材同构替换}
- **终局预期**（1 段）：{主角站在哪、世界变成什么样、曾经轻视他的人落到哪}

### 4. 支线设计（2-4 条）

每条四栏：

- **支线名**：{如：极品家庭的悔恨线}
- **起点**：{开局欠了什么/结了什么仇}
- **升级**：{每隔几卷怎么加码，谁被卷进来}
- **收束**：{怎么收，收在主角哪个阶段}
- **与主线接口**：{这条线为主线提供什么资源/敌人/情绪}
- **服务爽点**：{对应「核心爽点」哪一条}

### 5. 剧情循环（4-6 拍）

每拍 1-2 句，按顺序：

1. **困境与轻视**：{新环境/新地图；谁给主角下马威；缺什么资源}
2. **反套路破局**：{主角不硬刚，换哪条路；用了金手指哪条机制}
3. **征服与反转**：{谁的态度 180 度反转；读者爽在哪}
4. **利益收割与跃迁**：{拿到什么合规资源/编制/地盘；开下一张地图}
5. **（可选）代价与反扑**：{谁不服，下一卷的敌人从哪来}
6. **（可选）换图信号**：{时代节点/政策/新舞台}
