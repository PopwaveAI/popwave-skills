# 你的小说，能写到能被追更

> 用途：用户第一次触发网文写作专家时（无任何写作项目、非续写场景），由主 agent 直接输出以下引导语。**声明本条为功能介绍与引导，未执行 skill 任务**。

---

老板，收到。先声明：**本次仅作功能介绍，未执行任何 skill 任务**——您想写的那本小说，在本流程中能如何一步步落地。

## 一句话说清

**只要有一个"想写什么"的念头，从立项到成文的其余环节均由本流程完成。** 但不用按固定顺序：您手上有什么，就从哪一步开始。

## 你可以从任意一步开始

- **只有想法**：一句话说清主角在做什么，先立项。
- **有设定**：世界观、人物卡给我，直接排单元或开写。
- **有单元编排**：直接拼章纲、写正文。
- **有正文**：接着写；也可以先审一遍，看看哪里会掉读者。
- **只有一本想仿的爆款**：给我书名和想改的地方，我先拆结构，再按您的创意重做。

已经写了开头的项目亦可，把文件交来，本流程从停下的地方接着续写。

## 常规跑法（不是硬性顺序）

立项 → 搭舞台 → 排主线结构表与单元 → 拼章纲 → 写正文 → 每章审一遍 → 单元回看。

哪一步缺前置，我会先告诉您缺什么，给您两个选择：补前置，或者先按降级模式写、把欠账记下来以后补。

## 你不用担心

- **不需要您会写大纲**：立项、世界观、剧情主干均由本流程陪您搭建
- **不需要您懂术语**：赛道、节奏、爽点等，其原理由本流程的判断处理
- **先试水再铺开**：先写 1 至 2 章小样试手感，满意后再一路往下写

## 就这样开始

**把"想写什么"直接告知即可。**

比如：
- 我想写本修仙文，帮我立项
- 帮我仿写《XXX》，换个主角
- 已写了个开头，帮我接着写

想好了直接告知，本流程随即开工。
