# 剧情-情绪打分表

> **灯塔流审美固定位**：情绪刻度的唯一权威参照。全管线"情绪坐标"标注（plot 单元剧编排四拍/章序列、outline 章纲、review 情绪达标检查）一律以本表为准，禁止另立刻度。
> **同源声明**：本表与 `pop-emergent-outline/references/剧情-情绪打分表.md` 同源（结构/示例/规则一致），**改动必须两边同步**。
> **用途**：给章纲"情绪坐标"（章首/峰值/章末）**打分**（1-10）——先定这章要调动的**情绪**，再查本表定分值、倒推可兑现的事件。核心原则：**分数=读者实际能收到的情绪强度，不是事件理论上多震撼**；**6 分以上必须铺垫引爆，无铺垫打不到 6 分**。来源见文末。

## 一、打分三原则

1. **分数=读者收到的情绪强度，不是事件理论值**——写不好=0 分。"历经轮回终重逢，一眼万年"写砸了，对读者情绪调度就是 0 分。标分先问：按现在的铺垫和写法，读者真能收到这个强度吗？
2. **按情绪分维度，不按剧情线分**——先定这章要调动的情绪（愤怒/害怕/喜悦/搞笑…），再倒推什么事件能兑现它。说不出"要调动什么情绪"=没有心跳点，回 outline 重排。
3. **6 分以上必须铺垫引爆**——单章无铺垫打不到 6 分；8 分必须跨章铺垫（或开篇在单章内完成铺垫+引爆的极限操作）。标 6 分以上，先写得出来"铺垫在哪"。

## 二、两个情绪档：基础四情 vs 高阶三情

| 档 | 情绪 | 定位 |
|:--|:--|:--|
| **基础四情**（强烈·相对简单·主推） | 愤怒 / 害怕 / 喜悦 / 搞笑 | 章纲情绪峰值**优先押这四类**，兑现把握大，读者共情门槛低 |
| **高阶三情**（非常难写·没把握别赌） | 感动 / 甜蜜（嗑CP）/ 悲伤 | 需要长铺垫+文笔功力，写崩概率高。**没把握不要把章纲情绪点赌在上面**：标分一律保守（无长铺垫标 ≤5），或换成基础情绪替代兑现（如"甜蜜"降为"喜悦"、"悲伤"转为"愤怒"） |

## 三、分数档位（每情绪通用，铺垫成本是硬约束，十档逐档）

| 分 | 铺垫成本 | 读者状态 |
|:--|:--|:--|
| 1 | 无铺垫（信息级） | 只接收信息，微动，记住这事 |
| 2 | 无铺垫 | 轻微不快/微喜，皱眉或浅笑，开始在意 |
| 3 | 单场内小铺垫 | 被勾到，想知道接下来 |
| 4 | 单场内小铺垫+小引爆 | 被带入，情绪开始起来 |
| 5 | 本章内铺垫+小引爆 | 明显紧张/明显期待 |
| 6 | 本章内铺垫+引爆 | 情绪明显升起（6 分以上必须铺垫引爆） |
| 7 | 1-2 章铺垫 | 情绪被顶起，高潮前 |
| **8** | **跨章铺垫**（开篇＝单章内完成铺垫+引爆的极限） | **大峰值：心提到嗓子眼** |
| 9 | 长铺垫+关键单元 | 破防，读者失语 |
| 10 | 全书级铺垫，顶点留给最终局 | 世界级震荡，久久回不过神 |

**标分自检两步闸（每个峰值必过，过不了回 outline 重排）**：
① **对档核分**：按本表铺垫成本核——无跨章铺垫标 8=虚标；无本章铺垫标 6=虚标。8 分事件须能说出铺垫在哪（哪几章/哪个事件）。
② **兑现测试**：把情绪效果换成"读者真的收到"——按现有铺垫写得出来吗？写不出=回 outline 改事件或降分。负面 8 分还须过"已发生测试"：后果换成"已经发生了"故事还立得住吗？立不住=假致命。

## 四、七情打分细则（每情：定义 + 十档锚定剧情"铺垫→引爆"）

> **十档逐档纪律**：每档必须实打实列锚定剧情，不许省 1/2、不许把 3 和 4 合并成"3~4"。锚定剧情=具体到"谁、在哪、发生什么、读者收到什么"的场景，照写即兑现。

### 愤怒（基础·主推）

是什么：对不公/羞辱/威胁的怒火，读者最易共情的情绪。调动它=给读者一个"可恨对象+在乎之人/主角吃亏"。

| 分 | 锚定剧情（铺垫→引爆） |
|:--|:--|
| 1 | 信息级记账：主角听到旁人说一句不公闲话（"他一个废物也配"），瞥一眼记下，没发作。读者：心里一动，知道账记下了 |
| 2 | 小亏暂忍：主角办成的事被一句带过，功劳落到旁人头上，主角没争，只抿了下唇。读者：皱眉，替主角不快 |
| 3 | 当众被贬一句：酒席上被人阴阳"你这种人也配来"，主角端杯笑了笑，没接话（单场小铺垫）。读者：被勾到，想看怎么还 |
| 4 | 当众羞辱+吃小亏：主角护着的东西被当众夺走一件，还被奚落"穷酸"，拳头捏紧又放开（单场小铺垫+小引爆）。读者：被带入，替主角憋 |
| 5 | 本章铺垫：读者刚认识并喜欢上的配角→引爆：该配角当众被羞辱（被泼茶/被骂"贱种"），主角在场却暂不能出手（本章内铺垫+引爆）。读者：跟着上火 |
| 6 | 本章铺垫：读者在乎的配角被构陷→引爆：当众受罚（被指作弊/被罚跪），主角想拦被按下（本章内铺垫+引爆，憋屈+愤怒双叠）。读者：明显愤怒，期待爆发 |
| 7 | 1-2 章铺垫仇人的恶（明写恶行：欺压弱小/草菅人命）→引爆：仇人当众折辱主角在乎之人（扇脸/踩手/当众羞辱），主角被迫看着，目眦欲裂。读者：情绪被顶起，高潮前 |
| 8 | 跨章铺垫（读者在乎之人+仇人恶行都已建立）→引爆：在乎之人被掳、衣领撕开、烙铁贴脸，不可逆伤害**即将**发生，主角被按在地上（**临界不越界**：只到"即将"，绝不能真发生=重大毒点）。读者：心提到嗓子眼 |
| 9 | 长铺垫：不公积累到极点（十几章恶账）→引爆：当众清算，旧账一并了结，仇人跪地求饶，全场哗然（复仇单元高潮）。读者：破防，怒极而畅 |
| 10 | 全书级铺垫：毕生不公的源头/最在乎之人的深仇（全书一直在攒）→引爆：最终局当众昭雪/手刃，全书伏笔一并收束，世界级震荡。读者：久久回不过神 |

### 害怕（基础·主推）

是什么：对未知威胁/失去/死亡的恐惧。调动它=威胁必须真实可信（读者相信会发生），结果必须可逆（不能真发生）。

| 分 | 锚定剧情（铺垫→引爆） |
|:--|:--|
| 1 | 信息级不安：主角听到一个没头没尾的坏消息（"城外的雾又近了"），心头一紧，没深究。读者：微动，记住这事 |
| 2 | 轻微忌惮：主角路上遇到一个明显惹不起的存在（强者掠过/凶物路过），屏息避让，对方没理他。读者：替主角捏汗 |
| 3 | 单场小恐惧：深夜独行，身后脚步声跟了一路，回头没人（单场小铺垫）。读者：被勾到，发毛 |
| 4 | 威胁逼近：追兵/凶物一寸寸靠近藏身处，主角屏住呼吸，能听见自己的心跳（单场小铺垫+小引爆）。读者：被带入，紧张 |
| 5 | 本章铺垫：追兵逼近→引爆：藏身处被一寸寸搜到，最后一层遮挡前停住（本章内铺垫+引爆）。读者：明显紧张 |
| 6 | 本章铺垫：威胁临到读者在乎之人头上→引爆：在乎之人被逼到绝境边缘，主角差一步赶到（本章内铺垫+引爆）。读者：手心出汗 |
| 7 | 1-2 章铺垫威胁的不可对抗（层级立住）→引爆：威胁降临到主角在乎之人头上，救援**即将**来不及。读者：情绪被顶起 |
| 8 | 跨章铺垫（威胁层级已立）→引爆：在乎之人落入威胁之手，救援**即将**来不及（**临界不越界**：结果可逆，绝不能真发生）。读者：心提到嗓子眼 |
| 9 | 长铺垫：全书级威胁降临，至亲在眼前消失（结果可逆，为后续救回/复仇蓄力）。读者：破防 |
| 10 | 全书级铺垫：终局级威胁压顶，主角赌上一切去面对，读者屏息到底（结果可逆但代价未知）。读者：失语 |

### 喜悦（基础·主推）

是什么：收获/胜利/成长/团聚的满足。调动它=先让读者"想要"，再给"得到"。

| 分 | 锚定剧情（铺垫→引爆） |
|:--|:--|
| 1 | 信息级小确幸：主角发现一件小事顺了（借到想看的书/捡到一枚铜板）。读者：微微一笑 |
| 2 | 小收获：学会一招/得一个小物件/被敬重的人夸一句。读者：舒服，想继续看 |
| 3 | 小翻盘：被人小看后在一件小事上翻回来（识破对方心思/赢下一局小棋）（单场小铺垫）。读者：被勾到，爽一下 |
| 4 | 小赢：当众赢下一场小比试/抢回被夺走的东西（单场小铺垫+小引爆）。读者：小爽，期待更大的 |
| 5 | 本章铺垫：憋屈一整章（被压/被疑/被踩）→引爆：反杀/打脸成功（本章内铺垫+引爆）。读者：明显爽快 |
| 6 | 本章铺垫：大目标临门一脚→引爆：拿下（晋级/夺宝/破局），全场刮目相看（本章内铺垫+引爆）。读者：明显畅快 |
| 7 | 1-2 章铺垫→引爆：拿下大目标/重要关系破冰（获得认可/心上人回眸）。读者：情绪被顶起 |
| 8 | 跨章铺垫（长线目标）→引爆：斩强敌/得传承/身份公开，全场哗然。读者：大峰值，爽到颤 |
| 9 | 长铺垫：大仇得报/大愿得偿（全书主线里程碑兑现）。读者：破防，哭着笑 |
| 10 | 全书级铺垫：最终目标达成/全世界级事件（登顶/昭雪/大团圆），全书伏笔收束。读者：失语，久久回不过神 |

### 搞笑（基础·主推·最吃节奏）

是什么：反差/误会/吐槽引发的笑。四情里最吃节奏，8 分以上难度高，不轻易标。

| 分 | 锚定剧情（铺垫→引爆） |
|:--|:--|
| 1 | 一句话梗：主角一句淡淡的吐槽（回应一个离谱要求，"行，您说了算"）。读者：嘴角一弯 |
| 2 | 小误会：主角被误认成另一个人/被误会一个动作，几秒后澄清（无后果）。读者：轻笑 |
| 3 | 单场小喜剧：主角一本正经做蠢事（拿错东西/走错门），旁人无语看他（单场小铺垫）。读者：被勾到，笑出声 |
| 4 | 单场反差引爆：高冷人设突然崩一下（怕猫/被小孩拿捏）（单场小铺垫+小引爆）。读者：小爆笑 |
| 5 | 本章铺垫：人设反差铺垫一整章→引爆：当众出糗/误会连环（本章内铺垫+引爆）。读者：笑出声，明显愉悦 |
| 6 | 本章铺垫：误会越滚越大→引爆：全场社死现场/双线误会同时引爆（本章内铺垫+引爆）。读者：大笑 |
| 7 | 1-2 章铺垫（人设/关系铺足）→引爆：名场面级桥段（经典误会+完美时机）。读者：爆笑，情绪顶起 |
| 8 | 跨章铺垫+桥段设计（人设、关系、时机都对）→引爆：爆笑名场面（全书级笑点）。读者：笑到捶桌。**少数天赋局**，没把握标 5-6 更稳 |
| 9 | 长铺垫：角色弧光里的终极反差→引爆：全书级社死/反差名场面（关键时刻人设崩成喜剧）。读者：破防笑 |
| 10 | 全书级铺垫：最终局全场性喜剧高潮（庆典/比武/婚礼上的大乱斗），笑声收束全书。读者：笑着哭 |

### 感动（高阶·没把握别赌）

是什么：牺牲/成全/默默付出被看见。依赖长铺垫和笔力，写崩概率高。

| 分 | 锚定剧情（铺垫→引爆） |
|:--|:--|
| 1 | 信息级暖意：配角一句不经意的体贴话（"天凉了，把袄穿上"）。读者：心里暖一下 |
| 2 | 小付出被看见：配角为主角默默做的一件小事被发现（留的饭/补的衣）。读者：心软 |
| 3 | 单场小感动：配角为成全主角让出一件小事（让机会/挡一下小麻烦）（单场小铺垫）。读者：被勾到，动容 |
| 4 | 单场感动引爆：误会解除，发现对方一直在默默付出（单场铺垫+引爆）。读者：鼻子一酸 |
| 5 | 本章铺垫：配角付出铺垫一整章→引爆：真相揭晓，默默付出被看见（本章内铺垫+引爆）。读者：动容，明显受触动 |
| 6 | 本章铺垫：牺牲抉择→引爆：配角在关键处让出自己那份（本章内铺垫+引爆）。读者：眼眶湿 |
| 7 | 1-2 章铺垫（关系建立）→引爆：牺牲成全/默默守护被看见。读者：破防 |
| 8 | 全书级感情积累→引爆：至亲牺牲/大义成全（关系铺垫够长才敢标）。读者：失语。**没把握别赌**——宁可换成"害怕+喜悦"组合（先怕失去，再失而复得） |
| 9 | 长铺垫：全书最重要的人做出全书级牺牲→引爆：真相/动机揭晓。读者：大哭 |
| 10 | 全书级铺垫：最终局的成全/牺牲，全书感情线收束。读者：哭到失声，久久回不过神 |

### 甜蜜/嗑CP（高阶·没把握别赌）

是什么：双箭头/拉扯/定情的甜。依赖感情线积累，单章硬造=工业糖精。

| 分 | 锚定剧情（铺垫→引爆） |
|:--|:--|
| 1 | 一个对视：两人目光对上又移开，谁都没先开口。读者：姨母笑 |
| 2 | 一句双关：一方的话被另一方听出弦外之音，没点破。读者：嗑到了 |
| 3 | 单场小互动：递水/挡风/让座这类自然的体贴（单场小铺垫）。读者：被勾到，期待 |
| 4 | 单场拉扯：一方口是心非（说不理却跟着走）（单场小铺垫+小引爆）。读者：小激动 |
| 5 | 本章铺垫：关系升温铺垫一整章→引爆：一个越过界限的瞬间（牵手/护在身后）（本章内铺垫+引爆）。读者：甜到笑 |
| 6 | 本章铺垫：暧昧推到顶点→引爆：表白/定情（本章内铺垫+引爆，感情线已铺足）。读者：甜到跺脚 |
| 7 | 1-2 章铺垫（误会/阻碍）→引爆：破冰/宣示（当众护短/承认关系）。读者：情绪顶起 |
| 8 | 跨章感情线铺垫（几十章积累）→引爆：生死关头告白/重逢定情。读者：大峰值。**没把握别赌**——"历经轮回终重逢，一眼万年"写不好对读者就是 0 分，用"喜悦"替代（重逢的喜悦照常兑现，不赌甜蜜本身） |
| 9 | 长铺垫：全书级定情/名场面婚礼（全书感情线积蓄）。读者：哭着笑。没把握别赌，宁可用"喜悦"替代 |
| 10 | 全书级铺垫：最终局大团圆（全书感情线收束）。读者：失语，久久回不过神。顶点留给最终局，轻易别标 |

### 悲伤（高阶·没把握别赌）

是什么：失去/永别/遗憾。全书级永别轻易别标，写崩=读者弃书。

| 分 | 锚定剧情（铺垫→引爆） |
|:--|:--|
| 1 | 信息级怅然：听到一个旧人的消息（故人已远/旧地已改）。读者：微微一叹 |
| 2 | 小失去：丢了一件有纪念意义的小物/宠物走丢。读者：有点难过 |
| 3 | 单场小离别：与短暂相处的人告别（驿站分别/目送远行）（单场小铺垫）。读者：被勾到，惆怅 |
| 4 | 单场失去：珍视的小物被毁/旧地重游物是人非（单场铺垫+引爆）。读者：鼻子酸 |
| 5 | 本章铺垫：回忆铺垫一整章→引爆：旧物/旧人带来的怅然爆发（本章内铺垫+引爆）。读者：明显难过 |
| 6 | 本章铺垫：离别→引爆：至亲/挚友踏上不归路（本章内铺垫+引爆，关系已建立）。读者：眼眶湿 |
| 7 | 1-2 章铺垫（关系铺足）→引爆：牺牲/永别（结果可逆或有转机）。读者：破防 |
| 8 | 全书级永别（真正失去），轻易别标。**没把握别赌**——宁可用"愤怒"替代（哀而怒，化悲痛为复仇）。锚定：至亲在眼前逝去（全书级关系铺垫） |
| 9 | 长铺垫：全书最重要的人永别→引爆：遗言/遗物揭晓动机。读者：大哭。没把握别赌，宁可用"愤怒"替代 |
| 10 | 全书级铺垫：最终局的永别/成全，全书收束。读者：哭到失语。顶点留给最终局，轻易别标 |

## 五、峰值标定规则（章纲/章序列用）

1. **每章 ≥2 个峰值点**（可一正一负），分值按铺垫可达性定——普通章峰值 5-6 为主，别硬标 8。
2. **8 分是稀缺资源**：须有铺垫支撑（跨章铺垫，或开篇单章内完成铺垫+引爆），标 8 分必过两步自检。
3. **开篇前 3 章**：无既有铺垫，8 分只能靠"单章内完成铺垫+引爆"——一章内先立起在乎之人（让读者喜欢上她）→ 再让她陷入临界威胁。这是开篇最难的写法，做不到就标 6-7，不硬凑 8。
4. **峰值优先押基础四情**（愤怒/害怕/喜悦/搞笑）；高阶三情（感动/甜蜜/悲伤）没把握不赌。
5. **10 级顶点（失语）留给关键单元**；峰值有起伏，十章里八章 10 分=读者麻木。
6. 与上一章不连续同刻。

## 六、反例区（不算情绪点，别拿来标分）

- 表演小动作：抬眼镜、抿唇、握拳、挑眉、瞳孔一缩、心里咯噔一下、嘴角上扬——这些是**情绪的表现**，不是**情绪的触发**。
- 形容词情绪：紧张、愤怒、悲伤、害怕——情绪名词，没有事件，读者无法共情。
- 伪钩子："他忽然想起一件事，但想不起来"——钩子必须给读者足够信息让他能"猜"。
- 空反转：没有铺垫突然反转（读者反应是"啊？"不是"卧槽"）。
- 假致命：爪子擦过脸颊、险象环生、差一点就死——危险发生了但没留下不可逆后果，读者不揪心。
- 主角光环假威胁：主角本人掉海/被刀架脖子/重伤濒死——读者默认主角不死，调动不了情绪，不算 8 分负面事件；要命悬一线，得让**读者在乎的人**去悬。
- 配角死亡充数：让一个无关轻重的配角死掉换"见血"——读者对配角无感，心跳不起来。
- 理论值标分：拿"历经轮回终重逢"这类没铺垫的极端事件标 8-10——写不好=0 分，标分只认可兑现强度。
- 合并档偷懒：把 1-2 省掉、把 3 和 4 合并成"3~4"——十档逐档是硬纪律，每档必须能说出锚定剧情；说不出的档，说明这档情绪设计缺失，回 outline 补。

## 七、使用规则（灯塔流全管线）

1. **plot 单元剧编排**：四拍（起承转合）每拍标情绪峰值目标（对照本表，格式 `{情绪}·{分值}`，如"转拍=愤怒·8分"）；章序列每章白描卡标**情绪目标（情绪+分值）**——6 分以上须能说出铺垫在哪。供 outline 直接消费。
2. **outline 章纲**：先定本章要调动的情绪，再查本表定本章情绪坐标（章首/峰值/章末 1-10）——**峰值 ≥5 且每章 ≥2 个**，8 分须有铺垫支撑并过两步自检——再反向设计剧情事件。峰值优先基础四情，高阶三情没把握不赌。
3. **review 核验**：先反核章纲标注（8 分事件是否匹配本表情绪定义+铺垫成本，虚标直接打回 outline），再核正文兑现（标注的情绪/分值正文没兑现=情绪未达标，差 2 级以上打回）。
4. **铺垫成本记账**：标 6 分以上的情绪点，章纲"峰值事件"里必须写清铺垫在哪（哪几章/哪个事件）；写不出的降分。
5. **十档逐档取用**：查表定分值必须落到具体档（1/2/3…10），不许写"3~4"这种区间——锚定剧情就是铺垫+引爆的设计依据，区间=没想清楚。
