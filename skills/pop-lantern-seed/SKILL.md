# pop-lantern-seed

> 灯塔流立项。v1.0.0：只锁灯塔四样——主角立身三件/世界内核双层失衡/结局方向/篇幅量级；产出需求卡+故事脉络+篇幅量级，**不产全书卷纲、不锁死卷数**；全书卷方向（方向总表）不在立项产，开篇定调后由 pop-lantern-plot 首轮产。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

## 这个 Skill 做什么

**职责：把用户的模糊想法＋参考＋调研，先问成需求卡，再查底子，最后用五元素公式推故事脉络，锁下灯塔四样。** 顺序不可倒：先问需求、再查底子、后构造——不润色用户原话，不提前定金手指形态。

| 段 | 对谁 | 干什么 | 产出 |
| :-- | :-- | :-- | :-- |
| 立项引导（Step 0-1） | 对人 | 收命题问需求（需求卡五字段），按方向查底子出卡，分轮拍板 | 需求卡＋底子卡组 |
| 故事构造（Step 2-3） | 对文档 | 照五元素公式推故事脉络（主角立身三件+双层失衡+欲望串+谁挡着+结局），定量级 | 故事脉络＋篇幅量级 |
| 定稿交接（Step 4） | 对双方 | 六问自检、脱稿讲述测试 | `立项/需求卡.md`＋`立项/故事脉络.md`＋`立项/篇幅量级.md` |

三条根原则：

1. **先问需求，再查底子，后构造**。用户开口那句话就是全部输入。先把方向问清（什么流、给谁看、图什么、多长），再按方向查底子（是什么流、读者图什么、标配是什么、什么写烂了）。方向没定就查，查回来一堆用户不要的；没查底子就构造，产出结构再对也会跑题。
2. **灯塔四样锁根，其余留白**：立项只锁——①主角立身三件（什么人＋凭什么脱颖而出＋读者记住什么）②世界内核（双层失衡：旧失衡被压＋新失衡撕破）③结局方向（从 X 翻成 Y 的质变，不锁路线）④篇幅量级（总字数量级＋卷数量级，不锁死切法）。金手指形态（档位表/能力细节/奇遇）归 character；卷级排期（方向总表/单元表）归 plot，立项不排。
3. **主角立身三件是立项的灵魂**：凭什么脱颖而出（换路人故事立刻不成立）在立项必须问透——它是读者追这本书的第一理由，不甩给后面的角色设计。

**边界**：故事脉络=种子＋脱颖而出的理由＋读者第一印象，不写小传；金手指只定"独一份"性质，形态留 character；不拆卷、不排章，归 plot。

**产出**：`立项/需求卡.md`（全用户语言五字段）＋`立项/故事脉络.md`（五元素表格＋主角立身三件）＋`立项/篇幅量级.md`（量级方向＋下游约束）。下游：world 消费世界内核与篇幅量级；character 消费主角立身种子补金手指形态；opening 从灯塔四样直接搭前三章；plot 消费结局方向产方向总表。

**称谓约定（不混叫）**：「底子卡」=查底子的输入料卡（一源一卡）；「需求卡」=用户原话五字段整理（不润色）；「故事脉络」=五元素公式推出来的叙事弧种子；「灯塔四样」=立项锁的四样根。

## 执行模式

**主 agent 直执，禁用子 agent 代跑共创。** 立项是整条流程交互最密集的环节——出草案、听意见、改稿必须主 agent 亲自做。唯一例外：纯只读的调研支撑（扫榜、拆书包检索、参考材料消化）可派子 agent 回报原始材料，主 agent 消费。

**共创三态**：

1. **共创态**（默认）：用户在场，每步端候选给用户圈定，拍板定稿。
2. **代理自定态**（无真人／自动化环境）：agent 逐层自出草案、自审自拍，串行推进。拍板栏显式标注 `[](agent自定·{原因})`，禁止伪造"用户说过"。
3. **降级态**：共创中用户离开——已拍层保持用户意见，未拍层降为 agent 自定，降级时刻写进共创记录。

所有产出物头部「共创状态」按三态如实标注。

## 怎么操作（SOP 全内联）

### 第一段·立项引导（对人：分轮确认，没拍板不往下走）

#### Step 0 收命题、问需求

**产品形态先说清**：家里产品直接进 AI 对话，没有前置表单——用户不先填书名、分类、标签，开口那句话就是全部输入。所以立项第一步是问，不是读字段。

先收再问：

1. **收命题**：用户进对话说的话逐字收下，拆出元素清单。
2. **盘已有**：项目内资产（赛道包、拆书报告、旧大纲、`pop-snow-write/references/文风兜底/` 的现成文风档）、用户历次裁决记录（同类问题他怎么判过）。已确认的不重问，已有的不重查。
3. **问缺口**：命题说不清的，分轮问，一轮两三问，每问给 2-4 个选项、至少一个标推荐：

   - 想写什么流／什么题材（命题只给模糊方向时，凭常识给流派候选让用户挑；这一步只定方向，不做深度调研）
   - 给谁看（男频／女频，主分类方向）
   - 读者点开这本书图什么（方向级一句即可，不必精确）
   - 篇幅量级（总字数量级＋大概几卷，方向级即可，不锁死卷数）

产出**需求卡五字段**（全用户语言，不掺行话）：

| 字段 | 填什么 | 判据 |
| --- | --- | --- |
| 基调 | "这是本XX流的书，向读者承诺A/B/C" | 三项承诺说得全，流派就立住了 |
| 主角欲望线 | 谁＋要什么＋凭什么 | "凭什么"填金手指雏形，占位符，不定形 |
| 世界线 | 过去出过什么事＋现在正走向什么结局 | 写事件，不写机构地图 |
| 篇幅 | 量级、分几卷 | 量级方向用户定，不锁死切法 |
| X 元素清单 | 用户喜欢的元素逐条登记 | 只登记，不筛选 |

三条细则：

- 世界线写事件不写机构：朝廷、宗门、地图是舞台设定的事，卷纲期再做。
- 世界线分厚薄：谜底流一段话起步；言情文一行也够。用户的谜底直觉哪怕半句也记入。
- 金手指是占位符：定形在 character 补全——谜底定了，金手指从谜底里派生。
- **世界线先预判量级（防写小）**：按篇幅记一句"这书大概多大世界"（单城/星球/多元），写进世界线。**200 万字以上的，这里就标"至少星球/多元"，别等画像阶段才纠正。**

**需求卡没经用户确认，不开查底子**——调研方向由需求定，方向没定就查，查回来一堆用户不要的。

#### Step 1 查底子

按需求清单逐个元素出一张底子卡（模板 `templates/底子卡.tpl.md`）。七栏：

| 栏 | 内容 | 例（神豪流） |
| :-- | :-- | :-- |
| 定义与定位 | 这个流派是什么，用番茄标签库定流派 | 系统发钱、狂拽平推 |
| 开山与代表作 | 三到五本 | 《重生之神级败家子》… |
| 读者图什么 | 爽点清单，逐项可执行 | 压抑后打脸／扮猪吃虎／消费奇观／平推碾压 |
| 标配零件 | 这个流的世界配置 | 花钱系统、返利公式、打脸递进 |
| 王道主线 | 主角成长线的标准走法 | 开局受辱→返利暴富→打脸循环→豪强→产业帝国 |
| 写烂的点 | 同质化死法 | 无限返利无代价／从头到尾只有打脸 |
| 差异化机会 | 本书能插进去的新东西 | 融合职场/空间裂缝… |

查底子来源：番茄标签库（`pop-snow-seed/references/番茄标签库.md` 跨系列只读）、拆书报告、扫描榜单。**涉及现实考据/专业设定时**：落盘前先答"资料够不够"，不够必派 `pop-snow-research` 补采（跨系列只读调用，不写其文件）；查不到的写"没查到"，不凭空编造。

底子卡给用户看过，确认"这套路立得住、差异点在点子上"后，进故事构造。

### 第二段·故事构造（对文档：照五元素公式推）

#### Step 2 五元素公式推故事脉络

有了需求卡和底子卡，推演这本书的故事脉络。唯一可靠尺子跨书通用，不分赛道、不分类型：

```
主角立身 → 世界哪里失衡 → 欲望串（串行/并行） → 谁挡着 → 最后落什么结局
```

五元素定义（模板 `templates/故事脉络.tpl.md`）：

| 元素 | 填什么 | 判据 |
| --- | --- | --- |
| 主角立身 | 三件：**什么人**（身份＋特质＋处境）＋**凭什么脱颖而出**（独一份的不可替代性）＋**读者记住什么**（第一印象） | 什么人＝现状可感知；脱颖而出＝换成路人故事立刻不成立；第一印象＝一句话能被复述 |
| 世界哪里失衡 | 世界/环境哪里不对劲，逼着主角动 | 是失衡，不是背景板；具体到可感知；**分双层（旧失衡被压＋新失衡撕破）** |
| 欲望串 | 贯穿全书的心理动机，可串行可并行 | 主线最多一两条；**末尾要同时挂钩解决新旧双失衡** |
| 谁挡着 | 明面阻力＋暗面阻挡 | 分两层：明面是谁、暗面后面还有谁 |
| 最后落什么结局 | 主角最终翻到哪一步 | 有收束，不悬空 |

**主角立身三件（核心补充，立项必须问透）**：

- **脱颖而出（核心）**：是主角身上"独一份、换别人这本书就不成立"的特质，是读者追这本书的第一理由。是A：立项级决策——这个主角的核心辨识度；不是B：金手指形态（档位表/成长量/能力细节，归 character）。
- **判据**：把主角换成书里任何一个路人，故事立刻不成立 = 脱颖而出立住了；换成谁都行 = 没立住，回问。
- **提问句式（大白话）**：
  - "这个主角一开始是什么人？读者第一眼看到他，记住的是什么？"
  - "这本书 XX 万字，凭什么写这个人？换成这个世界里任何一个路人，故事还成立吗？——他身上有什么是独一份的？"（核心问题，必须问）
  - "他能出头，靠的是只有他能用的东西，还是别人也能有？"（区分"独一份"与"可复制"）
- **模板句式**："他是唯一/第一个/天生/被迫……能……的人"。例："唯一能识破混沌腐化的穿越者""负债的底层耗材，某天发现自己那页早该撕掉的命有问题"。
- **脱颖而出可以来自哪（五类来源，避免只盯金手指）**：①身份（唯一/被选中的身份）②认知（穿越者认知差/重生先知）③命格/体质（天生与众不同）④处境（被逼到只有他能动的墙角）⑤金手指雏形（系统/职业/传承的"独一份"性质，占位，不定形态）。
- **反例（可复制特质不算脱颖而出）**："他很努力""他有贵人相助""他运气好"——换成别人也成立，立不住，回问。

**越界边界**：故事脉络的主角 = 种子＋脱颖而出的理由，不是小传。**"凭什么"拆两层**：脱颖而出的理由（为什么是他：唯一/第一个/天生/被迫能X）——故事脉络定；能力/金手指形态（档位表、成长量、能力怎么用、奇遇细节）——留给 `主要角色设计·主角力量资格/金手指` 那份锁根。越界判据：写完"主角立身"，若读者已经知道"他具体的能力有几档、怎么用、那场奇遇怎么发生"= 越界（形态定早了）；若读者知道"他是唯一能X的人、他有别人没有的东西"= 正确（脱颖理由，立项该定）。

#### Step 3 定量级（只锁方向）

**篇幅量级两样**（模板 `templates/篇幅量级.tpl.md`，或并入故事脉络）：

- **总字数量级**：如"200-300 万字量级""百万字内"——作为所有锁根设定的总参数来源。
- **卷数量级**：如"8-12 卷的方向"，不锁死卷数 N、不锁每卷切法。

**量级怎么定**：按赛道默认规模（男频长线 200-300 万字、一卷 25-40 万字常见量级）粗估区间；200 万字以上的，世界观先标"至少星球/多元"（防写小）。

**判据**：立项能说出"这本书 XX 字量级、大概 8-12 卷方向"；**不能**说出"全书 10 卷，卷1 70 章，卷2 85 章"这种锁死切法——卷级排期归 plot 滚动。

### 第三段·定稿交接

#### Step 4 自检＋落盘

1. **六问自检**：主角立身三件齐了吗？脱颖而出换路人成立吗？失衡是双层（旧被压＋新撕破）吗？欲望串挂钩解决双失衡吗？结局有收束吗？篇幅是量级方向吗（没锁死卷数）？
2. **脱稿讲述测试**：不看文档，把"这本书讲了个XX的故事"讲给用户听——讲不清 = 故事脉络没立住，回填。
3. **存档**：`立项/需求卡.md`＋`立项/故事脉络.md`＋`立项/篇幅量级.md`，头部「共创状态」按三态标注。

**Step 4 质量门**：三份文档落盘｜六问全过｜脱稿讲述用户认可｜未越界（金手指形态/卷级排期未提前定死）。

## 红线

1. **先问需求再查底子后构造**，顺序不可倒。
2. **只锁灯塔四样**：主角立身三件/世界内核双层失衡/结局方向/篇幅量级；不产方向总表、不锁卷数、不排单元表。
3. **主角立身三件在立项完成**：脱颖而出（换路人故事不成立）必须问透，不甩给 character；金手指形态留 character。
4. **不润色**：需求卡全用户语言；拍板栏按共创三态如实标注，禁止伪造"用户说过"。
5. **资料门**：现实考据/专业设定不够必派 pop-snow-research 补采再落盘；查不到写"没查到"。
