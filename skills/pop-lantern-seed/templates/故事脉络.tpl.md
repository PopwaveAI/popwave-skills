# 故事脉络

> 只锁灯塔四样：主角立身三件 / 世界内核双层失衡 / 结局方向 / 篇幅量级。金手指形态归 character，卷级排期归 plot，本档不提前定死。

## 一句话落点

> "这本书讲了个XX的故事"——能讲给朋友听，且五元素填全。

## 五元素

### 1. 主角立身（三件一起定）

| 件 | 填什么 | 判据 |
| --- | --- | --- |
| 什么人 | 身份＋特质＋处境 | 现状可感知 |
| 凭什么脱颖而出 | 独一份的不可替代性（唯一/第一个/天生/被迫能X） | 换成路人故事立刻不成立 |
| 读者记住什么 | 第一印象（一句话可复述） | 一句话能被复述 |

脱颖而出来源（五类）：身份/认知/命格体质/处境/金手指雏形（占位，不定形态）。

### 2. 世界哪里失衡（双层）

| 层 | 填什么 |
| --- | --- |
| 旧失衡被压 | （过去出过什么事，被什么压住） |
| 新失衡撕破 | （现在什么不对劲，逼着主角动） |

### 3. 欲望串（链条不是清单）

- 主线（最多一两条）：（谁＋要什么＋凭什么——凭什么填金手指雏形占位符）
- 次要目标：（串行接力/并行组合）
- 末尾挂钩：解决新旧双失衡

### 4. 谁挡着（分两层）

| 层 | 填什么 |
| --- | --- |
| 明面 | （明面是谁） |
| 暗面 | （暗面后面还有谁） |

### 5. 最后落什么结局

- 结局方向：（从 X 翻成 Y 的质变，不锁路线）

## 篇幅量级（只锁方向）

| 项 | 值 |
| --- | --- |
| 总字数量级 | （如 200-300 万字量级） |
| 卷数量级 | （如 8-12 卷方向，不锁死切法） |
| 世界规模预判 | （单城/星球/多元；200万+ 至少星球/多元） |

> 判据：主角立身三件齐、脱颖而出换路人不成立、失衡双层、欲望串挂钩解决双失衡、结局有收束、篇幅是量级方向。
