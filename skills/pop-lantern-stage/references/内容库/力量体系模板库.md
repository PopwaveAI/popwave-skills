# 力量体系模板库

> **定位**：stage 建力量体系的唯一配方源。agent 不现场创造力量体系——先查库选配方，换皮适配；库没有才现场提取并回填（见"回填纪律"）。
> **库规（每条配方六字段）**：名称／内核／来源／验证状态／适配规则／不可动硬核。
> **消费顺序**：先查库→选配方→换皮适配→回填验证状态。
> **待完善**：本库为占位+示范，条目持续回填（长期完善；建库来源=拆书/头部作品抽离，见 pop-snow-research）。

## 条目格式（新增条目照此写）

```
- 名称：{配方名}
- 内核：{可复用的核心结构/机制，3-5句}
- 来源：{哪本书/哪类作品抽离}
- 验证状态：{头部作品/普通验证/待验证}
- 适配规则：{什么题材能用/怎么换皮}
- 不可动硬核：{哪些部分禁止改}
```

## 示范条目（第一批）

- 名称：修仙线性升级（练气→筑基→金丹→元婴→化神）
- 内核：线性升级＋每阶质变（新能力/新寿元/新境界）＋境界差绝对压制＋名称自带修仙韵味＋大众认知度极高（读者零学习成本）
- 来源：修仙网文通用（凡人修仙传/遮天系路线）
- 验证状态：头部作品
- 适配规则：仙侠/玄幻/东方奇幻题材可直接套；换皮=换升级资源（灵气→魔能/星力）与名称语素（练气→锻体）；每阶质变的内容按题材重写
- 不可动硬核：境界差必须绝对压制（低阶打不过高阶是铁律）；升级必须质变（纯数值增长不算升级）；境界名称要有"体系韵味"不跨味

- 内核：分层清晰＋每层能力方向差异大＋觉醒即身份跃迁＋底层翻身爽感强

## 回填纪律（消费后）

- 现场提取的新配方：提取后 48 小时内回填本库，六字段齐全，标"待验证"。
- 已用配方的验证状态：review 记录"哪套配方生效了/效果如何"，本库同步更新验证状态（普通验证→头部作品级需过拆书确认）。
- 本库是跨项目资产：任何灯塔流项目都可消费；回填时注明提取自哪个项目（书名/项目名）。
