# pop-mirror-character

> Mirror 人设专家：让角色既有人能记住的标签、也有能解释行为的内核——角色总账与顺序纪律（主角设计在画像/法则/格局之后，金手指三件套显式声明）+ 主角标签/类型/命名/内核、配角功能位、反派模板、关系范式、对话区分度、群像收缩。覆盖区以 [小说设定-SOP] 为权威，镜界 `05-人设设计` 精华降为执行层工具。当前版本 v2.0.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 这个 skill 做什么

**定位**：角色设计方法论——顺序纪律决定"什么时候造谁"，标签负责第一印象，内核负责长期可信；并控制群像不失控。

**触发时机**：建立主角/配角/反派时；连环角色流量需收缩时；卷纲里需要给配角定性时。

**前置输入**：故事脉络（主角是谁的种子：身份/特质/处境）+ 世界观（画像/法则/格局已定）+ 篇幅推导（卷数 N）。

**产出**：主角设计（本命/核心身份＋力量资格/金手指）、主要反派、核心配角、角色关系网、群像名单（含活跃人数与退场计划）。

**交接给**：pop-mirror-plot（角色在场理由、卷纲一句话定性）、pop-mirror-write（行为推导）、pop-mirror-review（角色一致性）。

> 纯方法论，不依赖镜界运行时能力，可直接落地。

## 怎么操作（SOP 全内联）

**角色设计 = 先按顺序纪律定"谁在哪个阶段造"，再用执行层工具把每个角色设计到"标签记住人、内核解释行为"。** 顺序是先总账后动手：不在一上来就雕主角小传。

### A. 角色总账与顺序纪律（SOP 权威）

**主角设计顺序纪律（硬约束）**：**本命/核心身份＋力量资格/金手指，在画像/法则/格局之后**——主角脚下的局先摆好，才造主角这个人。不要因为"主角最重要"就先造他。

| 角色文档 | 回答 | 产出时机 | 详细要求 |
| --- | --- | --- | --- |
| 主角设计（本命/核心身份＋力量资格/金手指） | 主角本质上是谁、凭什么入局超速 | 锁根 | 从故事脉络"主角是谁"的种子出发；种子只含身份/特质/处境，凭什么/能力/奇遇在此补全 |
| 主要反派 | 挡在欲望串终点的那个人 | 骨架 | 对应故事脉络"谁挡着"的暗面结构 |
| 核心配角 | 陪主角走、既给助力也给阻力的人 | 展开 | 排卷排到那一卷才展开 |
| 角色关系网 | 谁爱谁、谁欠谁、谁恨谁 | 展开 | 排卷排到那一卷才展开 |

**金手指三件套（显式声明）**：主角独有的例外刻度，作为一条特殊养成系，必须显式声明三件套，**不写进世界法则**：

1. **独立档位表**：金手指自己有几档，每档什么形态。
2. **每档成长量**：每档带来多少成长，能量化。
3. **与主养成线对表**：金手指档位与主养成线等级怎么对齐、怎么互推。

**展开层纪律**：卷纲里配角**一句话定性（名字+身份+立场），不写小传**；需要小传时才展开。配角离开主角后也要有自己的利益和去向。

### B. 执行层工具（保留，与 SOP 不冲突）

#### 核心目标

角色必须既有读者能记住的标签，也有能解释行为的内核。标签负责第一印象，内核负责长期可信。

设计角色时，先回答四个问题：

1. 他想要什么？
2. 他害怕什么？
3. 他用什么方式解决问题？
4. 他在关系里通常占什么位置？

#### 主角标签

主角标签用于稳定读者预期，但不能替代动机。

- 力量型：杀伐果断、霸道强势、热血冲动、越战越勇。
- 智慧型：谨慎稳健、腹黑深沉、步步留后手、靠信息差取胜。
- 个性型：嘴硬、逗趣、高冷、傲娇、疯批、洒脱。
- 情感型：偏执、温柔、护短、缺爱、强归属需求。
- 信念型：理想主义、现实主义、反英雄、有底线的灰色人物。

一个角色最多抓 2-3 个核心标签。标签越多，越容易写散。

#### 主角类型

网文主角有明确的类型范式，类型决定了读者的核心期待。

- 逆袭型：从低谷起步，靠金手指或努力翻盘。核心情绪：憋屈 → 翻身。
- 重生型：带着前世记忆回到过去，知道未来走向。核心情绪：遗憾 → 弥补 → 改命。
- 穿越型：从现代进入异世界，认知差制造笑点和优势。核心情绪：陌生 → 掌控 → 超越。
- 系统型：获得面板化的能力系统，任务驱动成长。核心情绪：迷茫 → 解锁 → 升级。
- 无限型：被迫在副本世界中生存，规则学习和团队博弈。核心情绪：恐惧 → 适应 → 掌控。
- 日常型：无大冲突，靠生活细节和人情味留人。核心情绪：温暖 → 共鸣 → 放松。

类型可以混合，但核心情绪只能有一个主轴。混合过多会让读者预期混乱。

#### 角色命名

名字是角色的第一张脸，读者通过名字建立第一印象。

- 主角名：好记、好念、有辨识度。两字名最稳，三字名次之，避免生僻字。
- 反派名：可以比主角更华丽或更阴沉，但不能比主角更像主角。
- 配角名：功能性角色名字要轻，重要配角名字要有记忆点。
- 避免撞名：同场景出现的角色首字不能重复，姓氏不能集中在同一个声母。
- 时代感：古风用文雅字，都市用普通字，科幻可以用编号或代号。

名字泄露的信息越少越好。读者认人靠行为和关系，不靠名字。

#### 主角内核

每个关键选择都要能从以下维度推出：

- 经历：过去发生了什么，让他形成这种反应？
- 利益：他此刻得到什么，失去什么？
- 恐惧：他最怕哪件事重演？
- 渴望：他真正想证明、拥有或守住什么？
- 误判：他知道什么，不知道什么，错判了什么？

如果行为只能用"剧情需要"解释，就是 OOC。

#### 配角功能位

配角不只是陪衬，必须在结构中承担明确功能。

- 引路人：带主角进入新规则、新地图、新行业。
- 智囊：补足主角信息、推理、谋略或专业短板。
- 执行者：承担战斗、跑腿、技术、后勤等行动功能。
- 情绪镜子：让主角的恐惧、软肋、骄傲或变化被看见。
- 对手：逼主角成长，不一定是反派。
- 垫脚石：用于短期打脸和实力参照，不能长期占用篇幅。
- 传声筒：替读者提问或反应，但不能只会惊叹。

配角离开主角后也要有自己的利益和去向。

#### 反派模板

反派要有压迫感，也要有行动逻辑。

- 纯恶型：目标简单，压迫直接，适合短期爽点。
- 灰色型：理由可理解，手段不可接受。
- 魅力型：目标宏大，手段高明，有追随者和信念。
- 悲剧型：被环境或旧伤推到对立面。
- 伪善型：表面正义，暗中攫取利益。
- 执念型：为单一目标越走越窄。
- 成长型：随主角一起升级，长期维持压力。
- 幕后型：操控链条长，适合卷末揭露。

反派不能靠降智送爽。读者要爽，是因为主角赢得有代价、有方法、有反应。

#### 关系范式

关系变化必须由事件触发，并产生后效。

- 师徒：传承、控制、反抗、超越。
- 兄弟/搭档：互补、并肩、利益分歧、信任考验。
- 情侣：吸引、误解、选择、付出、边界。
- 宿敌：对立、认可、互相成就。
- 上下级：忠诚、压迫、背叛、提拔。
- 亲缘：期待、亏欠、保护、叛逆。

关系升温、背叛、和解都要回答：触发事件是什么？双方付出了什么？别人怎么看？下一章会变成什么新状态？

#### 人物弧光

- 正面弧光：缺陷 -> 挑战 -> 代价 -> 改变。
- 负面弧光：优点 -> 诱惑 -> 越界 -> 堕落。
- 平坦弧光：信念 -> 考验 -> 坚守 -> 改变他人。

弧光不是人物突然"想通了"，而是他做出以前不会做的选择，并承担后果。

#### 对话区分度

关掉角色名字，读者还能认出谁在说话吗？如果不能，对话需要区分。

- 句长：急性子用短句，慢性子用长句，学者爱用从句。
- 词汇：角色有自己的口头禅、禁用词和知识背景。
- 语气：同一句话，恭敬地说、讽刺地说、冷淡地说，传递完全不同的信息。
- 信息量：有人说话只说一半，有人把心里话全倒出来。
- 禁忌：角色不会说的话比会说的话更重要。禁忌暴露底线和教养。

好的对话不是两个人在交换信息，而是两个人在博弈。

#### 群像管理

角色数量失控是网文最常见的病。管理群像的核心是控制同时活跃人数。

- 同时活跃角色不超过 5-7 个。超出读者记不住。
- 功能重叠的角色必须合并或淘汰。两个智囊不如一个智囊加一个执行者。
- 角色退场要有交代：死亡、离开、转为背景板。不能人间蒸发。
- 每个活跃角色都要有当前章节的"在场理由"。没有理由的角色不要写。
- 每 20 章清理一次角色表：谁还在发挥作用？谁可以退场？

读者记住的是关系，不是名单。

## 红线

1. **顺序纪律硬约束**：主角设计（本命/核心身份＋力量资格/金手指）在画像/法则/格局之后——主角脚下的局先摆好，才造主角这个人。
2. **金手指三件套**：独立档位表/每档成长量/与主养成线对表，显式声明；作为主角独有例外刻度，不写进世界法则。
3. **展开层纪律**：卷纲里配角一句话定性（名字+身份+立场），不写小传；需要小传时才展开。
4. **标签≤2-3 个**：主角核心标签过多即散；类型可混合但核心情绪只能一个主轴。
5. **行为可推出**：每个关键选择能从经历/利益/恐惧/渴望/误判推出；只能"剧情需要"解释=OOC。
6. **受体不降智**：反派必须要有行动逻辑，不靠降智送爽；读者爽是因为主角赢得有代价有方法有反应。
7. **关系事件驱动**：关系升温/背叛/和解必须有触发事件+后效，不能一夜之间。
8. **群像可控**：同时活跃 ≤5-7 人，功能重叠合并，退场有交代，每 20 章清理一次。
