# 故事脉络（五元素公式）

> 唯一尺子：**主角立身 → 世界哪里失衡 → 欲望串 → 谁挡着 → 最后落什么结局**。
> 填法：每个小格写完整句（是什么＋为什么可感知/可记忆），不写单个名词或短语。
> 主角立身三件必填全；"凭什么脱颖而出"是核心，判据=换成路人故事立刻不成立。
> 只写"什么人＋脱颖理由 / 哪里失衡 / 欲望 / 谁挡 / 什么结局"，**不写金手指形态**（档位表、能力细节、奇遇留给角色设计）。

## 1 · 主角立身（三件）

**什么人**：一句话立人：身份＋特质＋处境，现状可感知。
*例：一个被除名的顶级义体佣兵，落到底层靠接脏活为生。*

**凭什么脱颖而出（核心，必答）**：他身上"独一份、换别人这本书就不成立"的特质，读者追这本书的第一理由。
*例：唯一能识破混沌腐化的穿越者。／ 负债的底层耗材，某天发现自己那页早该撕掉的命有问题。*
*模板句式："他是唯一/第一个/天生/被迫……能……的人"。*
*来源五类：身份（唯一/被选中）／认知（穿越认知差/重生先知）／命格体质（天生与众不同）／处境（被逼到只有他能动）／金手指雏形（系统/职业/传承的"独一份"性质，占位不定形态）。*
*反例（可复制特质不算）：他很努力／他有贵人相助／他运气好——换成别人也成立，立不住。*

**读者记住什么**：第一印象，一句话能被复述；与结局"翻成Y"首尾呼应。
*例：一个装成神明的凡人。／ 一个被全世界针对的凡人。*

## 2 · 世界哪里失衡（双层）

* **旧失衡（被压着）**：这个世界本就不对劲、被压到习惯的那一面。
* **新失衡（被撕破）**：什么事件/东西凿开了裂缝，逼着主角动。
* 写法对照：写"这个本就被资本压榨到习惯的世界，被诡异复苏凿开了裂缝"，不写"这是一个充满怪物的世界"。

## 3 · 欲望串（串行接力 / 并行组合）

**主串**：贯穿全书的心理动机链（串行=接力律，一段比前一段大一号；并行=组合律，主打一两条）。
*例：活下去 → 想回家 → 目睹巨大威胁 → 清算天灾。*

* 判据：串得再长，全书主线最多一两条，其余是次要目标。
* 末尾挂钩双失衡：欲望串到终点时，要同时挂钩解决"旧失衡"与"新失衡"两条。

## 4 · 谁挡着（明面＋暗面）

* **明面阻力**：眼前直接对上的势力/个人。
* **暗面阻挡**：明面背后还有谁——结构性钩子所在地，越查越大。

## 5 · 最后落什么结局

**从 X 翻成 Y**：主角最终翻到哪一步，写质变，不悬空。
*例：从一个只想活命的穿越者，翻成斩断虫潮、定世界生死的人。*

## 越界检查（落盘前自查）

- [ ] 主角立身三件填全（什么人/脱颖而出/第一印象），脱颖理由是"换路人就不成立"的独特性
- [ ] 只写"脱颖而出的理由"，未写金手指形态（几档/怎么用/奇遇细节）——形态留角色设计
- [ ] 失衡是驱动、分双层，不是背景板
- [ ] 欲望串末尾挂钩双失衡
- [ ] 结局写"从 X 翻成 Y"的质变
