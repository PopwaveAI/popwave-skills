# pop-mirror-pipeline

> 将镜界（Mirroric 小说创作应用）系列 AgentSkill 的提示词精华，改造成一个可直接跑通全创作流程的专家 skill 系列。本 skill 是系列**总控**——维护专家清单+源映射+创作链路，按链路路由到七个写作子专家。当前版本 v1.1.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

## 这个 skill 做什么

**定位**：Mirror 创作专家系列总控，负责编排与路由，**不产具体创作产出**。七个写作子专家各司其职，配合本总控构成完整专家系列。

**触发时机**：新书想用 Mirror 专家体系走完整创作流程时；或进入某创作环节想确认该调哪个专家时。

**前置输入**：用户当前创作意图（立项/世界观/人设/开篇/规划/写作/去AI味/审查）+ 已有项目资料（若存在）。

**产出**：路由指示（该调哪个子专家 + 优先喂什么）；不产出正文/大纲等创作物。

**交接给**：按链路路由到七个子专家之一；子专家产物回流本总控继续下一环。

**子专家清单（id → 镜界源 → 链路作用）**：

| # | skill id | 对应镜界源文件 | 链路作用 |
|:-:|:--|:--|:--|
| 01 | pop-mirror-onboard | 11-创作向导 | 新书 Onboarding：根决策/元数据/规则沉淀 |
| 02 | pop-mirror-world | 10-世界观设定 | 力量体系自洽/地图/势力/资源设计 |
| 03 | pop-mirror-character | 05-人设设计 | 主角标签/类型/配角功能位/反派模板/群像 |
| 04 | pop-mirror-opening | 06-黄金三章 | 开篇 300 字/落差/特权信息/还账立标 |
| 05 | pop-mirror-plot | 02-章节规划 | 每章四段大纲/伏笔操作台账 |
| 06 | pop-mirror-write | 03-章节写作（+**01-章节节奏**，已并入） | 正文渲染 + 节奏硬尺（字数/密度/断章/钩子） |
| 07 | pop-mirror-deai | 07-去AI味 | 正文 AI 痕迹去除 |
| 08 | pop-mirror-review | 04-角色一致性 / 09-设定一致性 / 08-长篇连续性 | 一致性/设定/长篇连续性审查闭环 |

> 源文件「16-番茄榜单」是市场数据工具，非写作流程，不转本系列 skill。
> **合并说明**：原 `pop-mirror-rhythm`（06-章节节奏）为单章硬尺，与 write 同为单章级任务且有重复维护，v1.1.0 已并入 pop-mirror-write 成「节奏硬尺」节，不再单设专家。链路中的节奏约束统一由 06 write 承担。

**通用约定**：

- **一次一专家**：同一时刻只有一个执行者，避免方法论混用。
- **保真红线**：各子 skill 的「怎么操作·精华」节 = 镜界对应源文件原文逐字直贴，未增删改写；凡新增编排内容只出现在专属「做什么/红线/速查表」节，与精华分隔。若编排节与精华冲突，以精华（原文）为准。
- **运行时落地**：镜界原文含 `Run {command:...}` / `AgentSkill` / 工作区资源（`/novel`、`/relations` 等）等镜界运行时能力；纯本地/其他项目落地时视为需轻量化的人为输入，不改变方法精化。

## 怎么操作（编排 SOP 全内联）

### Step 1：判断当前创作环节

先问用户此刻要做什么，映射到七个子专家之一：

```
立项(01) ──► 世界观(02)·人设(03) ──► 开篇(04黄金三章)
                                      │
                        ┌──── 每章循环（05规划 先行）─────┐
                        ▼                                 │
                  06 写作专家（渲染正文 + 节奏硬尺）         │
                        │                                 │
                  07 去AI味专家（清洗）                   │
                        │                                 │
                  08 审查专家（一致性/设定/连续性） ── 打回/通过 ──┤
                        └────────────────────────────► 下一章
```

- **一次一专家**：同一时刻只路由一个子专家，避免方法论混用。
- **开篇专家(04)** 只在前三章启用；**审查专家(08)** 是创作后的质量闸，不做创作入口。
- **写法合一**：单章节奏硬尺（字数±10%、密度、断章、钩子轮换）已并入 **06 write**，规划(05)只需交给 write 大纲与伏笔台账，不再另调节奏专家。

### Step 2：按环节通向对应子专家

| 用户想要 | 路由到 | 优先喂给它的输入 |
|:--|:--|:--|
| 新书引导/定方向 | pop-mirror-onboard | 书名/简介/分类/题材（若有） |
| 建世界观/力量体系 | pop-mirror-world | 根决策 + 已有设定摘要 |
| 建人设 | pop-mirror-character | 世界观 + 主角类型/故事承诺 |
| 设计开篇/黄金三章 | pop-mirror-opening | 根决策 + 世界观 + 主角人设 |
| 定本章大纲 | pop-mirror-plot | 上章钩子 + 主线 + 伏笔台账 |
| 写正文（含节奏） | pop-mirror-write | 本章规划大纲 + 人设/设定（节奏硬尺内嵌） |
| 去AI味清洗 | pop-mirror-deai | 待清洗正文 |
| 审查一致性 | pop-mirror-review | 正文 + 既有事实（角色卡/世界书/伏笔） |

### Step 3：收尾衔接

- 每个子专家产出后，若创作未完成，路由到其「交接给」所指的下一专家，形成闭环。
- 审查未通过 → 打回写写作专家重写；通过 → 进入下一章/下一环。
- 不跨专家预判内容：trigger 具体写作、审查等任务时不擅自越权由本总控直接执行对应专家的工作。

***

## 红线

1. **总控不越权**：本 skill 只路由编排，不替代任何子专家执行具体创作/审查；落到具体环节时必须加载对应子 skill。
2. **保真不可破**：各子专家「怎么操作·精华」是权威内容源；路由与编排不得改写精华，不得用"升华/改写/去AI味"加工原文。
3. **一次一专家**：同一时刻一个执行者，禁止在同一产出内混用多个专家方法论。

## 执行模式

主 agent 直执路由：判断环节 → 路由子专家 → 接子专家产物继续编排。不派子 agent 执行创作。
