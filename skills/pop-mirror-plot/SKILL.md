# pop-mirror-plot

> Mirror 规划专家：把一章压缩成「章节连续性 + 当前任务 + 节拍序列 + 伏笔操作」四段式大纲——小周期推进/伏笔不空转/角色有根/聚焦单线/高潮管理。镜界 `02-章节规划` 精华逐字直贴。当前版本 v1.1.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

## 这个 skill 做什么

**定位**：章节大纲规划——保证主线不停、伏笔不空转、角色有根、聚焦单线。大纲只写"做什么"，不写"怎么描写"。

**触发时机**：每章动笔前产出本章大纲；长线伏笔台账需要统一核对时。

**前置输入**：上章钩子与既有事实（连续性）、全书/卷大纲主线、伏笔台账（已开启/推进/回收/搁置）。字数断章等节奏约束由 pop-mirror-write 内嵌节奏硬尺承担，本 skill 不另定。

**产出**：一份可直接供 pop-mirror-write 渲染的章节大纲（四段式）。

**交接给**：pop-mirror-write（按本章大纲渲染正文）、pop-mirror-review（大纲后一致性检验基准）、pop-mirror-opening（前三章规划回溯对照黄金三章情绪曲线）。

> ⚠️ 原文含"按 AgentSkills 匹配正文写作/长篇连续性技能"的运行时动作，本系列由 pop-mirror-write（正文写作+节奏硬尺）/ pop-mirror-review（长篇连续性审查）顶替，方法精化不变。事实冲突裁决顺序（已发布正文→最新事实→角色卡→世界书→伏笔记录→大纲）为方法核心，逐字保留。

## 怎么操作（SOP 全内联）

> **精华保真声明**：本节为镜界 `02-章节规划` 原文件正文逐字直贴，未增删改写。

## 核心原则

1. **小周期推进**：每 3-5 章完成一个小目标或悬念升级，主线不能停
2. **伏笔不空转**：过渡段落的每一笔都在为后文服务。每章处理旧钩子的同时埋下新钩子，开启数量 ≥ 回收数量，新钩子上限 2 个且最好与刚回收的有因果关联
3. **角色有根**：角色的每个选择来自"过往经历 + 当下利益 + 性格底色"。反派不能降智，主角不能突变成圣人
4. **聚焦**：一章推进一条主线，支线最多一条且必须服务主线
5. **高潮管理**：大高潮前 3-5 章铺线索，爆发后 1-2 章写改变（主线推进、角色成长、关系变化）

正文写作原则：按 **AgentSkills** 匹配正文写作类技能并 AgentSkill 加载后参照。
长篇或多卷规划时，先按 **AgentSkills** 匹配长篇连续性类技能并 AgentSkill 加载，整理本章状态包。事实冲突时按以下顺序裁决：已发布正文 → 最新事实提取 → 角色卡 → 世界书 → 伏笔记录 → 大纲。

## 章节大纲结构

一份完整的章节大纲包含以下 4 个部分：

### 1. 章节连续性

写明本章和前后的衔接关系：

- 上章钩子怎么接
- 本章起止的时间、地点
- 角色硬状态（位置、伤势、能力、持有物、已知信息）
- 章末必须落地的改变（信息 / 关系 / 物理 / 权力，至少 1 条）
- 上下文冲突时以哪条既有事实为准

### 2. 当前任务

一句话说明主角本章要完成的具体动作，必须是可执行的行动。

可附带一句话说明读者此刻在期待什么、本章怎么处理这份期待。

### 3. 节拍序列

按顺序列出本章的事件或场景，每个节拍标注其功能（推进主线 / 深化关系 / 揭示设定 / 埋设伏笔 / 营造氛围）。

不含正文和对话。

### 4. 伏笔操作

- **开启**：新钩子（≤ 2 个）。注明目标揭示章节和埋设方式（对话暗示 / 环境细节 / 角色行为）
- **推进**：已有伏笔的推进。注明 ID、状态变化、本章释放的新线索
- **回收**：已有伏笔的回收。注明 ID、回收方式、对剧情的影响
- **搁置**：暂不处理的伏笔。注明理由和下次规划窗口
- **健康度**：伏笔健康度快照（可选，每 5 章评估一次）。记录未揭示伏笔总数与平均悬置章数、超期伏笔、沉睡 10 章以上的伏笔

## 输出格式

直接输出完整的章节大纲，用 Markdown 标题层级组织。按上面 1-4 的顺序依次输出。

- 每个部分写实，不空泛
- 恪守世界观和已有设定

## 红线
- 不要在大纲里用方法论术语：用这本书的人物、地点、事件说话
- 不要提前写出正文或对话：大纲只写"做什么"，不写"怎么描写"
- 不要编造不存在的伏笔 ID 或事实：每个 推进/回收 的钩子必须真实存在于已有记录中

***

## 红线（编排层强化，叠加于精华「红线」之上）

1. **四段完整**：连续性/当前任务/节拍序列/伏笔操作四部分缺一不可，按 1-4 顺序输出。
2. **伏笔闭合**：开启数量 ≥ 回收数量、新钩子 ≤2 且与刚回收有因果关联；不编造不存在的伏笔 ID。
3. **大纲不越权写正文**：大纲只写"做什么"，不得提前写正文/对话，不用方法论术语。
4. **事实冲突以既有正文为准**：裁决顺序="已发布正文→最新事实→角色卡→世界书→伏笔记录→大纲"，不得静默覆盖旧事实。

## 速查表

| 环节 | 校验点 |
|:--|:--|
| 章节连续性 | 上章钩子怎么接/时空/硬状态/章末必落地改变 |
| 当前任务 | 一句可执行动作 + 读者期待处理 |
| 节拍序列 | 事件序列+每拍功能标注 |
| 伏笔操作 | 开启/推进/回收/搁置/健康度五栏 |
| 裁决顺序 | 正文>最新事实>角色卡>世界书>伏笔>大纲 |
