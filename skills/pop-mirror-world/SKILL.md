# pop-mirror-world

> Mirror 世界观专家：把世界设计成"制造冲突、选择、代价的规则系统"，而非百科条目——设定总账与链路（锁根/骨架/展开/写章四层 tag，画像→法则→格局→主角）+ 力量体系自洽/地图挂钩剧情/势力利益系统/资源循环/设定节奏/设定钩子。**操作编排：先问参考、四轮分步确认（画像→法则→格局→主角），落一份确认一份；资料门不够必派 pop-snow-research 补采。** 覆盖区以 [小说设定-SOP] 为权威，镜界 `10-世界观设定` 精华降为执行层工具。当前版本 v2.1.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 这个 skill 做什么

**定位**：世界观设计方法论——设定总账告诉你"这本书要建哪些设定文档、每份何时产（tag）、链路顺序是什么"；执行层工具告诉你"每一条设定怎么设计到能制造冲突"。**和用户的分工：设定决策由用户拍板，world 给结构、给选项、给推荐，落一份确认一份。**

**触发时机**：立项后建立力量体系/地图/势力/资源时；后续新增设定需自洽检查时；需要核对某份设定该在哪一步产出时。

**前置输入**：故事脉络（需求卡 + 五元素）+ 篇幅推导（总字数/卷数 N）+ 已有设定摘要。

**产出**：设定总账与链路（四层 tag 落地）、力量体系刻度、地图分层、势力格局、资源经济、设定节奏与设定钩子清单——**分四轮产出，每轮用户确认后落盘**。

**交接给**：pop-mirror-character（角色被世界规则约束）、pop-mirror-plot（卷级剧情从设定棋盘取势）、pop-mirror-write（世界观信息释放进正文节奏）、pop-mirror-review（设定一致性审查基准）。

> 纯方法论，不依赖镜界运行时能力，可直接落地。

## 怎么操作（SOP 全内联）

**世界设定 = 先定总账（哪些设定、何时产、什么顺序），再逐份产出（用执行层工具设计到能制造冲突）。** 顺序是先总账后动手：不在一上来就雕某一处设定。

### 第 0 节 · 操作编排：先聊参考，分步确认，落一份确认一份

world 不是一口气干完的：链路四步（画像→法则→格局→主角）每一步都是一次近乎不可逆的锁根决策，**必须落一份、确认一份，再进下一步**。禁止一次把四份全写完再问"过不过"——那等于让用户当返工纠错员。

**第 0 问 · 先问参考**：动手前先问一句"有没有想照的结构/参考作品"（用户常对某套成熟结构有强偏好，比如照某本书的养成线、位面分层）。用户指定了参考，就照参考结构搭，再在关键分叉处给选项；没指定再给推荐结构。

**分步确认**（每一轮 1-2 个大白话问题 + 2-4 个选项 + 一个推荐项）：

| 轮次 | 确认什么 | 落盘 |
|:--|:--|:--|
| 第 1 轮 | 世界画像：时代/内核/独特点/代价/危机/隐喻 ＋ 三层地图怎么分 | 世界画像部分 |
| 第 2 轮 | 世界法则：基石 ＋ 养成线结构（主/准主/从，量化等级节点） | 世界法则部分 |
| 第 3 轮 | 世界格局：棋盘势力 ＋ 矛盾线 | 世界格局部分 |
| 第 4 轮 | 主角硬约束：金手指三件套 ＋ 防无敌 | 主角硬约束部分 |

- 一轮只确认一件事，顺着上一轮的回答定制下一轮；不一次抛整张清单。
- 全用户语言，不掺行话：不说"基石/养成线/锁根"这类术语，要说"这本书的'强'靠什么撑""主角升级走哪条线"。
- 用户说「你来定」：给默认建议汇总，请求确认后再落盘；未确认不写入。
- 用户改主意：以新为准，回写对应文档，不推诿。

**资料门（每轮落盘前）**：先答"资料够不够"——涉及**现实 IP（战锤40k/DND/漫威等）、参考作品细节、历史/现实行业/专业设定**的考据，或用户指定参考作品的结构细节时，资料不够**必派 `pop-snow-research` 补采**（wiki 站检索，跨系列只读调用，不写其文件）再落盘；查不到的写"没查到"，不凭空编造。

**完成回报**：四轮都确认落盘后，简短回报画像/法则/格局/主角各定了什么 + 资料门是否触发过，然后交接 pop-mirror-character。

### A. 设定总账与链路（SOP 权威）

设定不是一次性浇完的整体，是一份**分步交付**的东西：它被剧情一步步召唤。每份设定标好产出时机（tag），不靠临场推。

**四层 tag**：

| tag | 含义 |
| --- | --- |
| 锁根 | 核心设定设计阶段定，主路径必踩、近乎不可逆 |
| 骨架 | 主线剧情设计阶段定到骨架级，决定全书形状但不需马上全展开 |
| 展开 | 排卷排到那一卷才展开 |
| 写章 | 写到那一章才造的细节，临场造即可 |

**链路顺序（硬约束）**：**世界画像 → 世界法则 → 世界格局 → 主角设计。** 画像先定"这世界长什么样、最被抢什么"（内核），法则再从中点出**基石**定"强怎么构成"；先画像后法则，基石才不会凭空造（赛博朋克先定"钱>一切"→ 基石=钱）。不要因为"世界法则看起来更重要"就先造它。这条顺序在所有相关设定里都要保持。

**世界画像（锁根，链路第一步）**：世界本体长什么样 + 最被抢的内核 + 三层地图。

- 先定调：时代/内核/独特点/代价/危机/隐喻六件事。
- 再画地图，标出"这世界最被抢的东西"（内核）——它正是《世界法则》要点名成基石的那个。
- 产出时机在链路第一个：法则的基石从它点出。

**世界法则（锁根，基石从画像内核点名）**：世界的"强"怎么构成。

- **核心结构：两侧对开（武力侧 + 非武力侧，各有基石，武力侧可多基石）→ 子解决方式（战斗/社会对抗）→ 各配养成线。**

```
        武力侧（通常主打）                非武力侧（通常次之）
基石      钱(赛博)/序列(诡秘)/灵气        社会地位/资产量级
子方式    战斗/法术/忍术/忍具            商战/权谋/规则/谈判
养成线    序列升级/境界/血继限界          升职/社交/签单（能量化等级）
```

- **养成线硬规则**：主1条＋准主1条（两侧对开都重要时强制升格，每卷必升档、质变与主线错开）＋从≥3条，各不同维度且不重叠；必须量化为等级节点（序列1-9、境界、资产量级），否则爽感和排卷无处兑现。
- **主角独有的例外刻度（金手指）作为一条特殊养成系**，在《主角设计》显式声明三件套（独立档位表/每档成长量/与主养成线对表），**不写进世界法则**。
- 关键约束：基石从画像内核点名；爽文无真代价。

**世界格局（锁根，画像/法则之后）**：把画像的地图 + 法则的力量摆上棋盘——谁占哪格、哪两格对冲、主角从哪格往哪打。势力=棋子、矛盾=冲突线。

**骨架级（主线剧情设计阶段定）**：

- 宏观地理格局：东西大陆/上中下界级别，一张能排戏的棋盘。
- 世界历史/时代背景：与结局相关的那一段历史（危机因果链）。
- 顶层势力/敌我顶端：谁决定结局，谁站主角这边。

**展开级（排卷排到那一卷才展开）**：职业/流派/方向、中层势力/分支/下属、势力关系网/阵营、核心配角、角色关系网。

**写章级（写到那一章才造）**：力量外物（魔法/异能/道具/装备）、路人/龙套组织。

**篇幅为总参数来源**：世界法则的养成线档数、世界画像的层/域数、世界格局的矛盾数，都由篇幅推导链给出——主养成线质变点数≈N+1、地图升级次数≈N、世界矛盾解锁层数≈N（N=卷数，见 pop-mirror-onboard 篇幅推导）。装不下就缩小范围或切割分层；装不满就并卷或加戏。

> 判断一份设定何时产，只问一个问题：它是主路径必踩、牵一发动全身（锁根/骨架），还是用到才够（展开/写章）？

### B. 执行层工具（保留，与 SOP 不冲突）

#### 核心目标

世界观不是百科条目，而是制造冲突、选择和代价的规则系统。每条设定都要能回答：它会让角色获得什么、失去什么、误判什么、争夺什么。

#### 力量体系

设计力量体系时，优先定义边界，再定义名字。

- 等级：有哪些阶段？阶段之间差距多大？
- 突破：靠积累、悟性、资源、战斗、仪式还是代价？
- 上限：当前卷允许出现的最高能力是什么？
- 消耗：每次使用要消耗什么？体力、灵力、寿命、金钱、权限、关系还是秘密？
- 克制：谁能反制它？什么环境会让它失效？
- 后效：能力使用后会留下什么痕迹、伤害或债务？

新增能力不能只在本章生效。它的限制、代价和滥用风险必须同步出现。

#### 体系自洽

力量体系最怕"写到后面打自己脸"。每次新增设定前做自洽检查。

- 向下兼容：新能力是否让旧能力变得无用？如果旧体系被架空，说明新能力越界了。
- 向上封顶：当前阶段的上限是否留够了下一阶段的升级空间？突破不能一步到位。
- 横向克制：有没有一种能力是无敌的？如果有，必须给它一个明确的弱点或代价。
- 环境约束：这个能力在不同场景下是否表现一致？水中、空中、禁魔区是否都有效？
- 时间成本：修炼、恢复、准备需要多长时间？如果随时可用，紧张感就没了。

写完力量体系后，用一句话测试：主角能不能用这个能力解决所有问题？如果能，体系有问题。

#### 地图扩展

地图扩展要有过渡，不能从村口一步跳到宇宙中心。

- 初期：小范围，建立日常规则和主角缺口。
- 中期：中范围，暴露势力结构和资源争夺。
- 后期：大范围，揭示世界本质和历史真相。
- 每次扩展都要有门槛：路程、权限、代价、引路人、情报或资格。

移动、传讯、调兵、运输都受距离、时间、资源和制度约束。地图升级次数由篇幅推导链给定（≈N），每卷扩一次舞台，可合并。

#### 地图与剧情绑定

每个地点必须服务于剧情，不能只因为"世界观里有这个地方"就写。

- 地点 = 利益：这个地方控制什么资源或信息？谁想要它？
- 地点 = 冲突：不同势力对这个地方的态度是否不同？
- 地点 = 门槛：进入这个地点需要付出什么代价？
- 地点 = 记忆：主角在这个地点经历了什么？重访时读者会想起什么？

如果一个地点可以被另一个地点完全替代，它就不该存在。

#### 势力格局

势力不是名字列表，而是利益系统。

每个主要势力至少定义：

- 目标：它想得到什么，害怕失去什么？
- 资源：它控制什么稀缺物？
- 规则：它如何奖惩成员？
- 弱点：它的制度漏洞或内部矛盾是什么？
- 关系：和主角、反派、其他势力是联盟、敌对、中立还是暗斗？

势力不能完全均势，也不能一家独大到剧情无解。强势力必须有成本，弱势力必须有生存理由。矛盾解锁层数由篇幅推导链给定（≈N），每卷解一层。

#### 资源与经济

资源循环让世界可信。

- 货币：普通货币、特殊货币、资源等价物如何兑换？
- 获取：任务、交易、探索、生产、掠夺、分配。
- 消耗：修炼、装备、情报、治疗、突破、维持组织。
- 稀缺：为什么不能无限获取？谁在控制供给？
- 黑市：正式制度之外，谁能绕开规则，代价是什么？

资源设定要进入剧情：交易失败、药材短缺、装备损坏、情报买错，比旁白解释更有效。

#### 设定节奏

世界观不能一次性倒给读者，也不能永远藏着不说。节奏是关键。

- 第1-3章：只给主角能直接接触的规则。不要出现主角当前碰不到的势力或体系。
- 每 10-15 章：引入一个新层级的设定（新势力、新规则、新地图）。
- 每卷结束：揭示一个底层真相或推翻一个读者以为正确的认知。
- 设定密度上限：单章新设定不超过 2 个。超过读者记不住。

节奏测试：读完一章后，读者能说出"这章告诉了我什么新东西"吗？如果不能，信息太少；如果说了三样以上，信息太多。

#### 设定钩子（供 SOP 卷级剧情设计消费）

世界观本身可以成为钩子：让读者因为好奇规则而追读。

- 悬念式：这个能力为什么有副作用？这个世界为什么是圆的？
- 冲突式：两条规则互相矛盾时，哪个优先？
- 反转式：读者以为是A规则，后来发现是B规则。
- 拼图式：每揭示一块设定，都让已有的设定产生新含义。

最好的设定钩子是：读者知道了一条规则，然后立刻看到有人违反了它，代价是什么？

#### 信息释放（供 SOP 卷级剧情设计消费）

设定按读者承受量逐层释放。

- 表层规则：主角和读者刚进入世界时必须知道的日常规则。
- 隐藏历史：跨章或跨卷揭露的旧灾难、失落文明、隐秘组织。
- 世界本质：支撑终局的底层真相。
- 例外规则：打破常规前必须先让常规稳定存在。

信息释放以遭遇式揭露为主：让角色在行动中撞上规则。集中科普只在进入新领域、学习新体系或规则改变时使用。

## 红线

1. **链路顺序硬约束**：世界画像 → 世界法则 → 世界格局 → 主角设计；画像先标内核，法则从内核点基石，基石不凭空造。
2. **设定即冲突系统**：每一条设定都必须落在"获得/失去/误判/争夺"四问上，禁止百科式罗列。
3. **养成线硬规则**：主1条＋准主1条＋从≥3条，各不同维度且不重叠，量化等级节点；金手指作为主角特殊养成系在主角设计显式声明，不写进世界法则。
4. **体系自洽测试**：新增设定前做向下兼容/向上封顶/横向克制/环境约束/时间成本五查；"主角能解决所有问题"=体系有问题。
5. **密度与节奏**：单章新设定 ≤2 个；第1-3章只给主角能接触的规则；例外规则前常规须先稳定。
6. **地图/势力/资源皆有钩子**：地点必须服务剧情，势力必须可替代性失去生存理由，资源必须有稀缺与代价。
7. **分步确认**：画像→法则→格局→主角四轮，落一份确认一份；禁止一次写完四份再问"过不过"。
8. **资料门**：涉及现实 IP/参考作品/专业考据时，落盘前必答"资料够不够"，不够必派 pop-snow-research 补采；查不到写"没查到"，不凭空编造。

## 执行模式

主 agent 直执（分轮聊天式 + 写盘）：链路四步落一份确认一份；资料门触发时派 pop-snow-research（跨系列只读）补采；后续设定一致性核验可交 pop-mirror-review。
