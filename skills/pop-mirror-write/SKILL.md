# pop-mirror-write

> Mirror 正文写作专家：消费**本章章纲＋全书日志（当前态）＋前一章正文＋文风DNA**四样核心输入，其余按需点读，渲染2000-2500字/章。并入 pop-mirror-deai 精华（07-去AI味深化清洗规则，生成即达标）。当前版本 v1.1.0（自 pop-snow-write v1.12.0 复制迁移，补产出三检查与 mirror 输入适配，v1.1.0 并入 deai 精华），完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。

- **Pack**：缺口足够才取材，query 自生成；来源 **wiki 站** **<https://wiki.popwave.cn>** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query / 回传 ≤30KB，超限截断仅留结论区。

- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版，不越权定终局。

- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

## 做什么

输入（有章纲前提下，**只吃四样核心，其余按需**）：本章章纲 + 全书日志（当前态）+ 前一章正文 + 文风DNA

输出：`正文/ch{NNN}.txt`（2000-2500字/章）。**不产任何账本/记录文件**——write 只在对话回复给一句摘要+章末钩子。字数检查与去AI味检查均由 write 存档后自跑脚本收束。

**硬约束链**：本章章纲🔒（时空与主体/事件节点/交接信息三块）→ 全书日志🔒（当前态：现在在哪/此刻悬着的线/禁止漂移）→ DNA约束（3-5条笔触）→ 类型声明（防风味漂移）

**执行模式**：主agent直执写作+存档。输入完备性缺口审查/章纲事实vs全书日志冲突比对可派子agent（verification）只读审计回报，主agent据此判execution.mode并渲染存档。

### 第 0 节 · 产出三检查（正文怎么聊）

**事前沟通**：动笔前先对齐 2 件事（1-2 问，每个给 2-3 个大白话选项 + 推荐项）：①本章节奏基调（蓄力/爆发/过渡/揭示，从章纲情绪基调与 mirror-plot 卷纲爽点标签取默认）；②文风延续（按前文已定风格走，还是这章要调）。第一章动笔前对齐一次文风基准，之后默认延续，只在章节有特殊要求（大高潮/大转场）时再问。用户没想法就用章纲与前文默认，不拖延。

**事后确认**：每章正文产出后，回查自检清单（字数检查 PASS/去AI味 FAIL 清零/断章钩子/章纲事件节点全兑现/上章钩子承接），把待确认点报给用户（字数/断章位置/钩子类型/新增事实待核），用户确认后才落盘；打回则按意见改，改完再确认一次。连续多章可一次报多章确认点。

**research 评估**：正文涉及**现实细节/专业名词/历史器物**（武器型号、药品剂量、法律条文、时代器物等）时，落盘前先答"资料够不够"——不够**必派 `pop-snow-research` 补采**（跨系列只读调用，不写其文件，落 `素材/采风/`）再落盘；查不到的写"没查到"，不凭空编造。

## 怎么操作（SOP全内联）

### Step 1：消费输入（抽取本章写作包）

> 🔒 **语感隔离阀（先读这道总开关，再消费任何 # 章纲/幕白描 # ）**：章纲/幕白描/全书日志的措辞是**剧情结构语言**，不是**正文语感**——它们天然带压缩性 AI 腔（"过量收敛""打脸""爆点"这类标签句），只用来描述"这章发生什么、读起来该怎样"。write 只从它们取**意**（事件顺序+落点功能+情绪基调+钩子），用文风DNA（Step ⑤⑥）的语言**重铸**成正文。**禁止照抄章纲/幕白描的抽象名、标签句、句式进正文**；情绪基调只作气氛提示，不成句搬。若正文出现与文风DNA语感不符的"大纲腔"，视为语感污染，review 打回。

有章纲前提下，**按"必读核心 vs 按需点读"分层消费**，不把档案全搬进上下文。缺必读核心项记入缺口。

**①用户本轮要求（最优先）**：覆盖默认取值。明确：把X写成Y/当前章位/续写或重写/特殊约束。用户要求与全书日志冲突时以用户要求为准。

**②必读·本章章纲（向前依据）**：`卷纲/章纲/ch{NNN}-章纲.md`（pop-mirror-outline产出，描述约束版 v5.1，每章一文件）。向左用上一章章日志衔接（不必读前1章章纲）。章纲三块各司其职，按下述消费：

- **时空与主体**=场景与登场：时间×地点×在场人物各一句今天干嘛 → 本章画面基准，直接定场景/人物状态起点

- **事件节点**=推进主干：每节点「事件/转折/落点功能」按顺序兑现，一个不丢；落点功能（"这节结尾要读者感受到什么/为后文铺什么"）是本节目标，write 负责把它落到正文

- **交接信息**=写前约定：对白意图→write 现编台词；世界观功能→write 现编意象；角色语感→按清单查对应角色卡

- **write发挥**=留白区：动作细节/心理/对白台词/结尾意象全部在这现编，但不得与章纲事件及全书日志事实矛盾

**事实冲突处理**：章纲事实性字段（年龄/等级术语/人名）与全书日志冲突时，全书日志为准，写作包"冲突标注"记录。本章章纲缺失（outline 未产出到本章）=缺口，**走缺口处理（回 outline 补章纲），不自行补剧情、不降级硬写**。

**③必读·全书日志（当前态·跨章连续参照）**：`全书日志.md`（当前态·只记活跃·全量读）。抽取：现在在哪（时间线/地点/故事到哪/下一步）/人物此刻（当刻在场·正交互的人）/此刻悬着的线（未解·还在进的线，含不可提前吞并的钩子）/还没揭的悬念（别过早掀）/不许碰（禁止漂移硬清单）。**取代原"状态快照＋近5白描卡全量"**——连续锚已聚合在这里，不再逐章全读白描卡。

**④按需·上一章章日志（衔接摘要）**：`章节日志/ch{NNN-1}.md`。要上一章"事件摘要式"回顾（讲了哪些事/定了什么）才读；更细的历史回溯对应白描卡按需点读，**不默认逐章全读**。

**⑤必读·前一章正文（叙事流+文气基准）**：`正文/ch{NNN-1}.txt`（full-if-targeted）。**必须带进本章写作包**——不只是"读过"，而是把它作为本章的**衔接基准**：上一章结尾停在哪（余味/钩子落点）、人物蹦到哪、叙事口吻/语感到哪。保证本章从上一章文气上无缝接续，不产生文字断裂或人物状态跳变。它与④章日志互补：章日志管"事件讲了啥"，前一章正文管"怎么讲的、停在哪、那股气"。

**⑥文风DNA输入（存在时必读，缺失时必须兜底）**：

| 优先级 | DNA源                    | 触发条件                                        |
| :-- | :---------------------- | :------------------------------------------ |
| P0  | `references/文风兜底/`按赛道选一 | **首选·纯样文原文**（frontmatter标注源书与txt路径，可回源逐字核查） |
| P1  | `素材/文风锚定.md`            | 存在即用，但只能作为"同赛道reference的辅助转写"，不得取代P0原文      |
| P2  | 上一章白描卡`## 本章DNA执行包`     | review产出，有则优先加载章内套路                         |

**文风来源权重（硬规则）**：`references/文风兜底/`里 frontmatter 标注了源书+txt路径的**纯样文原文**是唯一权威文风源，权重 **最高**。本地 `素材/文风锚定*.md` 只是"辅助参考"，**禁止以其为正文主师**，禁止用本地自造锚定替代 P0、禁止跳到项目外搜索/蒸馏现造新锚定。

**P0 命中即锁定**：若`references/文风兜底/`里某档 frontmatter 的源书与本次文风目标（用户点名书名/作者/口味）命中，必须直接用该档纯样文原文，禁止绕过它去搜索或自造。执行报告标注"文风源：{文件名}（源书：{源书}）"。

兜底规则：P0 全库无匹配时，从`references/文风兜底/`选一个——**找不到合适赛道档时，默认拿`西幻·玄幻史诗.md`（源书：参考小说txt/起点/玄幻仙侠/夜无疆-辰东.txt，纯样文原文）兜底**，而非跳过或外搜。执行报告标注"兜底文风：{文件名}（源书：{源书}）"。

**DNA必带进（硬约束）**：无论走 P0 命中 / P1 本地辅助 / P2 执行包 / 兜底，本章**必须带进至少一份文风DNA**（纯样文解剖维度或对其的转写均可，但必须真实存在、可回源），缺失态【禁止】跳过DNA直接写作。

读取规则：优先按 P0 纯样文原文加载其`## 笔触``## 句式``## 段落呼吸`等解剖维度；有执行包时叠加按执行包加载章内套路；无执行包时按本章章型加载对应场景卡+通用维度；DNA源过大时只读源文件目录/源书开头+对应章型解剖/角色口癖隔离（须标注所读范围）。

**禁止行为清单**：①禁止以本地自造锚定为主师，reference原文只当"辅助对照"；②禁止"reference里其实有匹配档却说没有"而外搜蒸馏；③禁止读本地锚定后不读/不再查 P0 reference。违者=文风源断言不实，review 打回。

**设定带进（每章≤3维度≤1500字，按章型按需）**：按章型从 mirror 前段（pop-mirror-world/character）产出文件按需读取，禁止全文带进。每维度≤500字。

必选（每章）：

| 文件路径                | 提取内容                    |
| :------------------ | :---------------------- |
| `设计/角色库/角色库.md`     | 本章有对话角色的语言指纹+行为模式+关系张力  |
| `设计/全书设定/类型风味基线.md` | 类型声明+风味基线表——类型味方向参照，杜绝漂移 |

按章型再选≤1个：

| 章型  | 文件路径                                  | 提取内容                |
| :-- | :------------------------------------ | :------------------ |
| 战斗章 | `设计/力量体系.md` + `设计/全书设定/战斗系统.md`      | 力量边界+分阶战斗形态+战斗底层规则  |
| 日常章 | `设计/卷舞台/卷N-舞台.md`                     | 本卷舞台的势力格局+地图区域+矛盾核心 |
| 探索章 | `设计/全书设定/物理规则.md` + `设计/全书设定/地理建筑.md` | 力量法则+空间法则+区域信息      |
| 危机章 | `设计/全书设定/危机敌人矛盾.md`                   | 危机体系+敌人体系+矛盾轴       |
| 社交章 | `设计/全书设定/政治经济.md` + `设计/全书设定/民风民俗.md` | 权力结构+文化质感           |
| 成长章 | `设计/金手指.md` + `设计/力量体系.md`            | 金手指限制+阶位突破规则        |

> 落盘说明：mirror 前段（pop-mirror-world/character）产出的设定文档按 `设计/` 布局落盘（角色库/全书设定/卷舞台等），`设计/力量体系.md`/`设计/金手指.md` 等由 world 按章型对应产出；尚未落盘的维度按需先路由对应前段 skill 补齐，write 不自行补设定。

带进规则：角色库+类型风味基线必选，再按章型选≤1个；每文件只提取本章相关段落（≤500字）不全文带进；提取内容写入写作包"设定状态"字段。

**X体验层带进（可选，改编项目）**：项目存在`素材/改编计划.md`时按章型带进X类互动（战斗/日常/剧情），每章至少1处参与动作/对话/决策。不存在时跳过，不自行编造。

**缺口处理**：全书日志/本章章纲明显缺关键事实时，停止并要求先执行pop-mirror-review产出。用户要求继续则execution.mode降为draft或trial。

**抽取本章写作包**：

```markdown
## 本章写作包
execution.mode:
- 把 X 写成 Y：
- 当前章位：
- 上一章结尾状态：（上一章停在哪/余味/人物当前处境——衔接基准）
- 上一章白描：（叙事流回溯参照）
- 钩子台账：（本章可回收/不可提前吞并）
- 角色当前状态：（主角/配角当前立场）
- 读者已知信息池：（信息差类型，写信息不穿帮）
- 关键数据🔒：（写错=bug）
- 本章章纲：（时空与主体/事件节点/交接信息三块要点）
- 后1章悬念：（全书日志"此刻悬着的线/还没揭的悬念"里本章不可提前吞并列一行——钩子指向校验）
- 可用燃料：
- 用户本轮新增要求：
- 类型声明：（当前作品类型+保持什么味+禁止漂移到哪）
- DNA约束：（3-5条本章实际执行的笔触约束）
- 文风DNA执行：（DNA源/模式/章型/笔触目标/章内套路/可见反馈/禁止误用；兜底标注"兜底文风：{文件名}"）
- 对话要点：（本章有对话角色的语言指纹——句式偏好/用词偏好/对话标志2个）
```

**execution.mode判定**：formal=上一章章日志（按需）+全书日志+本章章纲（读取完成）+**前一章正文（必读带进）**+用户要求齐全且达标（DNA源齐全或已兜底）；draft=必读核心有缺口但用户要求继续；trial=快速试做不存档。**缺本章章纲/全书日志/前一章正文不得标formal。**

**检查（进入Step 2前）**：写作包完整｜execution.mode已判定｜章纲读取完成、时空与主体/事件节点/交接信息三块已锁定｜**前一章正文已带进（衔接基准）**｜章纲事实冲突已比对全书日志｜类型声明已带进｜DNA约束3-5条已选定｜对话锚点已提取或确认"本章无对话"｜缺口已记录。

### Step 2：渲染正文+存档

按本章章纲的事件节点推进渲染2000-2500字：节点逐个兑现（事件+转折+落点功能）+章末钩子分级落章。正文写入`正文/ch{NNN}.txt`。两道检查脚本（字数 word-count.ps1 + 去AI味 deai\_gate.py）均归 write 存档后自跑（见下方「存档后检查」），不达标自己收束。

**正文规则**：

- 开场120字内出现目标、异常、压力、反馈或主动动作之一

- 主角至少完成一次动作收束：压力/诱因→判断→主动动作→阻碍升级→可见反馈→收益/损失→新压力

- **本章章纲必兑现**：事件节点按序推进，一个不丢；每节点「事件/转折/落点功能」落到正文；落点功能（本节结尾读者感受到什么/为后文铺什么）必须兑现；交接信息（对白意图/世界观功能/角色语感）按写前约定走。不能只铺氛围

- **物理缝合**：章纲只锁"事件/转折/落点功能"，不锁具体时序与动作细节时，write 负责补齐物理链（谁的手/什么时机/物件从哪来），补的拍服从章纲功能与前后因果。章纲功能空=补缝合并标注

- **事实冲突以全书日志为准**：章纲事实与全书日志冲突时以全书日志为准+对话回复给 review"冲突标注"

- 关键爽点必须外显（旁人反应、资源变化、局势翻转、敌人误判），不能只由作者总结"他赢了"

- 不提前吞并全书日志"此刻悬着的线"里未到期的钩子

- 结尾必须留下主动钩子或威胁逼近，不用自然停顿收尾

- 判定链/系统数值一律自然段内联呈现（【】格式），禁弹窗式/代码块

**创作技法（渲染前先把这几把尺过了，禁入正文的分析句不写进去）**：

- **关键场景行为推导 6 步（禁入正文）**：本章高潮/转折场景动笔前，对主角与关键角色各跑一遍推导链——当前处境 → 核心动机（最想要/最怕）→ 信息边界（知道/不知道/误判）→ 性格过滤（冲动/谨慎/果断…）→ 行为选择 → 情绪外化（身体语言/表情/语气）。推导卡壳（找不到合理行为）=前置铺垫不足，**回 outline 补衔接，不硬写**；推导只用于自洽，**不得以"他意识到/他内心权衡"类分析句进入正文**。

- **读者视角设计（信息差管理）**：动笔前定本章「读者-角色信息差」——读者比角色多知道一点=紧张，少知道一点=好奇；至少制造一层"读者知情、角色不知情"。**锚定效应**：想突出主角表现，先在场景里放一个"参照"（敌人强度/困难上限/旁人水平）再让主角出手——先给参照再展示主角，比空喊"他很强"有效。

- **场景纪律**：①**新场景前 100 字让读者知道谁在场、在哪儿、正发生什么**（三要素）；②**每场景锁定 1 个核心情感基调**（对峙/温柔/压抑/热血），全部描写围绕它，不五彩斑斓乱cue情绪；③**行动桥接**：段落过渡用行动衔接（"门在他身后咔嗒锁上"✓），禁"与此同时/过了一会儿"（✗）。

- **字级节奏密度（软性自查尺，与事件密度并存，非硬检查）**：每 300 字 ≥1 爽点/看点、每 500 字 ≥1 钩子、每 1000-1500 字 ≥1 完整悬念；叙事段保持 40-120 字（手机屏 3-5 行），长句给环境/心理、短句给动作/冲突，避免连续 3 个短段(<40字)并列。

**去AI味写字节（生成即达标，非事后降噪）**：写作时主动规避表层AI味信号，正文天然去魅，禁止写完再跑"降AI味"重写流程：

| 信号       | 写时规避                                  |
| :------- | :------------------------------------ |
| 模板化开头    | 不写"随着…/在当今社会/近年来/众所周知"，直接场景起句（"天擦黑…"） |
| 展望套话收尾   | 不写"综上所述/让我们拭目以待/相信在不久的将来"，点到即收束       |
| 三段式/对仗排比 | 不排"首先→其次→最后""不仅…而且""既…又""一方面…另一方面"    |
| 过渡连接词    | 换口语：值得注意的是→说白了；由此可见→看得出来；与此同时→同一时间    |
| 破折号      | ≤1个/500字，只留列举式/必要转折                   |
| 半角引号     | 一律中文全角引号，禁止半角 `"` `'`                 |
| 句长均匀     | 避免连续3句都是15-25字，穿插≤5字短句控节奏             |
| 概括式内心    | 少写"他忽然觉得/她突然明白"，落到具体动作/细节外显           |

**深化清洗规则（pop-mirror-deai 精华并入，07-去AI味）**：上表是浓缩信号，本节是完整规则——写作时按此规避，正文若已带 AI 痕迹按此改写：

**核心规则**：

1. **删废话** — 去除开场白、强调性拐杖词、过渡填充
2. **破模板** — 打散三段式列举、二元对比、排比结构
3. **变节奏** — 混合句子长度和开头方式，变换段落结尾
4. **信任读者** — 直接陈述，跳过过度解释和手把手引导
5. **去金句** — 如果某句话听起来像名人名言，重写它

**废话黑名单**（正文中禁止出现以下词汇和短语）：

"值得注意的是""总的来说""与此同时""不可否认""毫无疑问""显而易见""众所周知""由此可见""值得一提的是""综上所述""换言之""从某种意义上说""需要指出的是""不言而喻""毋庸置疑"

**禁止句式**：

- **"不是……而是……"** — 改用直述句
- **破折号"——"** — 用逗号或句号断句
- **"虽然……但是……"** — 用角色内心吐槽替代转折词
- **"不仅……而且……"** — 打散为两句
- **"第一……第二……第三"** — 改为散句叙述
- **连续"了"字** — 保留一个有力的："他走了过去，拿了杯子" → "他走过去，端起杯子"

**叙事恶习**：

- **不替读者下结论** — 读者能从行为推断的意图，叙述者不得直接说出
- **不写分析报告** — 正文中禁止出现"核心动机""信息边界""信息落差""利益最大化"等分析术语
- **不堆叠从句** — 一句话中避免三个以上从句堆叠，拆分为短句
- **不重复开头** — 变化"他/她"开头，用动作或场景描写前置
- **不过度解释** — 情感时刻后不要紧跟"他感到……"，让行动和对话说话
- **控制惊讶标记词** — "仿佛""忽然""竟""竟然""猛地""猛然""不禁""宛如"每 3000 字不超过 1 次
- **同一体感不连续渲染** — 同一意象域（如火在体内流动）禁止连续渲染超过两轮
- **禁止元叙事** — 不写"到这里算是钉死了"这类编剧旁白
- **空洞强调词** — "非常""极其""十分"能用精确描述词代替时不用

**被动 → 主动**：

- ✗ "杯子被他捏碎了" → ✓ "他捏碎了杯子"
- ✗ "消息被传到了城里" → ✓ "消息传到了城里"

**副词删除**：

- ✗ "他冷冷地说" → ✓ 用对话本身传达冷淡
- ✗ "她悄悄地走" → ✓ "她踮着脚尖，地板在脚下发出轻微的吱呀声"

**反例 → 正例速查**：

| 反例 | 正例 |
|---|---|
| 虽然他很强，但是他还是输了 | 他确实强，可对面那个老东西更脏 |
| 然而事情并没有那么简单 | 哪有那么便宜的事 |
| 这一刻他终于明白了什么是力量 | 删掉，让读者自己感受 |
| 他走了过去，拿了杯子，喝了一口水 | 他走过去，端起杯子，灌了一口 |
| 那双眼睛充满了智慧和深邃 | 那双眼睛像饿狼见了肉 |
| 全场为之震惊 | 老陈的烟掉在了裤子上，烫得他跳起来 |
| 他不禁感叹道 | 直接写感叹内容，删掉"不禁感叹" |
| 他的内心充满了矛盾和挣扎 | 他攥着拳头站了半天，最后骂了句脏话，转身走了 |
| 值得注意的是，这座城市的夜晚格外美丽 | 城市的夜景铺开在眼前 |
| 他感到一种前所未有的恐惧 | 他的后背紧贴在墙上，冷汗浸透了衬衫 |
| 综上所述，这次行动失败了 | 行动失败了。就这么简单。 |

**其他 AI 模式**：

- **系动词回避**：不要用复杂结构替代简单的"是"。"这座城市被誉为东方明珠" → "这座城市是东方明珠"
- **三段式法则**：不要强行将想法分成三组。两项或一项更自然
- **刻意换词**：不要为避免重复而使用生僻同义词。宁可重复也不要别扭
- **虚假范围**：避免"从 X 到 Y"的结构，除非 X 和 Y 确实在有意义的尺度上
- **过度限定**：避免"可能大概也许某种程度上"的堆叠
- **被动句式回避**：检查全文，发现"被"字句尽量改为主动

**快速检查清单**：

- ✓ 连续三个句子长度相同？打断其中一个
- ✓ 段落以简洁的单行结尾？变换结尾方式
- ✓ 使用了"此外""然而"等连接词？考虑删除
- ✓ 三段式列举？改为两项或四项
- ✓ 有金句体质的句子？重写

**DNA落地**（不是事后润色，而是参与本章生成）：

| DNA项   | 在正文中的体现                            |
| :----- | :--------------------------------- |
| 笔触目标   | 叙事距离、句式、段落呼吸、感官顺序、对话引导方式           |
| 主角主动方式 | 主角必须做出选择或动作                        |
| 爽点外显方式 | 旁人反应、资源变化、局势翻转、敌人误判                |
| 叙事人格   | 旁白站位和判断顺序                          |
| 句子气口   | 长短句、独句段、信息先后                       |
| 信息释放   | 先给结果还是先给过程，哪些暂不解释                  |
| 章内套路   | 起笔、第一信息变化、压力/诱因、主角动作、阻碍升级、可见反馈、章末钩 |
| 可见反馈   | 敌人失态、旁观者改判、资源/信息变化、威胁逼近            |

**对话落地**：每个有台词的角色必须从对话锚点取语言参数（句式偏好/用词偏好/对话标志），不凭记忆写对话。对话锚点缺失时从`设计/角色库/角色库.md`按需读取语言指纹。write负责"对话内容对+角色语言指纹对"，review负责"对话质量好不好看"。

**存档**：正文写入`正文/ch{NNN}.txt`。文件名固定，对话只回交接信息（摘要/钩子/字数/新增事实待核/冲突），不把正文全文放进对话，也不存档创作记录文件。两道检查（字数+去AI味）都是 write 自己的存档后步骤，必跑、不达标自己收束后才交 review。

**存档后检查（写完必跑，两道：先字数→后去AI味）**：

**① 字数检查（先跑——字数收束会增删文本，AI味检测须在终稿上跑）**：

```
powershell -File skills/pop-mirror-write/scripts/word-count.ps1 -Path 正文/ch{NNN}.txt
```

- 纯汉字 2000-2500 合格。不足→回章纲既有节点内扩写（补场景细节/对话往来/动作链，不灌水不复读）；超限→删最弱场景；改完复跑至 PASS

- **字数不足不外交**：review 不补救字数，write 自己收束达标后才交 review

- stdout 原文进对话回复交接信息，review 直接消费进本章日志"字数"栏（review 不跑脚本）

**② 去AI味检查（终稿上跑）**：

```
python skills/pop-snow-pipeline/scripts/deai_gate.py 正文/ch{NNN}.txt --fix --json
```

- **零风险项脚本已原地自动修**36类（标点全角化/引号配对/省略号归一/零宽字符/HTML与markdown残留/emoji/思考残留行/tab/行首标点归位/独立单引号转双引号等），无需人工，不进 LLM

- **WARN/FAIL 项=自查自修清单**：76项检测（套话硬模板/软密度组/结构统计/工具痕迹四层），按报告 hits 行号定位，只局部改写命中处（禁止全文重写），修后复跑至 FAIL 清零；WARN 酌情。注意"中文间空格""引号未配对""括号注释"三项有合法豁免（收件人排版/多段对话约定/游戏面板文），确认合法可放行；\[报告]标识项只看数不判级（人书作者风格方差大，如单引号内心独白/四字格连排），异常高时人工判断

- 阈值经人书基线校准（参考小说txt八本同口径抽样实测，人书全过、AI稿多挂）：破折号人书为0/500字，AI稿超1.0即警；句号密度人书21-38/千字，超45即警；的着了气口人书38-79.5/千字，低于36即警（AI缺气口）

**验收检查**（存档后必跑）：

| 项        | 验收方式                                                          |
| :------- | :------------------------------------------------------------ |
| 正文存在     | `正文/ch{NNN}.txt` 存在                                           |
| 字数检查通过   | `word-count.ps1` 已跑：纯汉字 2000-2500 PASS；不足/超限已在 write 内扩写/删减收束 |
| 去AI味检查通过 | `deai_gate.py --fix` 已跑：零风险项已自动修，FAIL 清零（WARN/合法豁免项在对话回复注明）   |

**新增事实处理**：write不维护任何库文件。新增事实只在对话回复里列"新增事实待review"清单，由 review 落库。write只声明不落库。

**下一步（硬后继）**：正文存档后必须执行pop-mirror-review。review是write的硬后继，未执行review不得写下一章。

## 红线

1. **四样核心必读**：本章章纲/全书日志/前一章正文/文风DNA 缺一不得标 formal；缺章纲走缺口处理回 outline 补，不自行补剧情。
2. **语感隔离**：禁止照抄章纲/全书日志的标签句/大纲腔进正文；情绪基调只作气氛提示不成句搬。
3. **章纲必兑现**：事件节点按序一个不丢；落点功能/交接信息必须落到正文；物理缝合补的拍服从章纲功能与因果。
4. **DNA必带进**：P0 纯样文原文为唯一权威文风源；禁止本地锚定作主师、禁止跳过 P0 外搜。
5. **爽点外显**：关键爽点必须旁人反应/资源变化/局势翻转/敌人误判外显，不得由作者总结。
6. **脚本双检**：字数 word-count.ps1 纯汉字 2000-2500 PASS + 去AI味 deai_gate.py FAIL 清零，write 自收束不外交。
7. **深化清洗**：正文按深化清洗规则（废话黑名单/禁止句式/叙事恶习）规避，黑名单命中必改；违者 review 打回。
8. **交接纪律**：正文纯文本无 Markdown；write 只声明新增事实不落库，由 review 落库。
9. **硬后继**：正文存档后必须执行 pop-mirror-review，未执行不得写下一章。
10. **三检查纪律**：动笔前对齐节奏/文风；正文经用户确认才落盘；现实细节/专业名词资料不够必派 pop-snow-research 补采再落盘，查不到的写"没查到"。
