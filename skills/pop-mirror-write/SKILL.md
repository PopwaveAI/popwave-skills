# pop-mirror-write

> Mirror 写作专家：拿到 pop-mirror-plot 的章节大纲 → 内嵌**节奏硬尺**（原 pop-mirror-rhythm，已并入本 skill）渲染可直接交付的正文。14 条创作原则、创作技法（场景/视角/节奏/人物行为推导/读者心理学）、AI 禁词、自检清单与输出要求，并含节奏硬尺——字数额度±10%、爽点/钩子/悬念密度、叙事段 40-120 字、80/20 断章、钩子六类轮换、高潮前铺线后效。镜界 `03-章节写作` + `01-章节节奏` 精华逐字直贴。当前版本 v1.1.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 这个 skill 做什么

**定位**：正文写作专家——将 05 规划的章节大纲渲染为可直接交付的正文，并在写作全程套用**节奏硬尺**（量化阈值随文执行）。**本 skill 就是"写正文"的那一下**：主会话逐章调用，落盘后交 08 去AI味、09 审查。

**触发时机**：拿到 pop-mirror-plot 的章节大纲之后；正文需要承接上一章钩子与角色状态时。节奏硬尺内嵌本 skill，写作时随文参校，无需另调专家。

**前置输入**：本章大纲（节拍序列 + 当前任务）+ 上一章正文/钩子 + 人设卡（行为推导依据）+ 世界观设定（用到时按需）+ 文风参照（可选）。

**产出**：直接可交付的正文，纯文本、无 Markdown、无创作说明；字数落在目标区间±10%；密度达标（每300字爽点/500字钩子/1000-1500字悬念）；章末断在 action-climax（80/20）并留轮换钩子。

**交接给**：pop-mirror-deai（AI 痕迹清洗）、pop-mirror-review（一致性/设定/连续性验收，**以本 skill 的节奏硬尺作为段落/断章验收阈值**，打回则回到本 skill 重写）。

> ⚠️ 原文中"按 AgentSkills 匹配节奏密度断章/长篇连续性/去AI味技能"的运行时动作：节奏硬尺已并入本 skill（见精华·B），长篇连续性/去AI味由 pop-mirror-review（09）/ pop-mirror-deai（08）顶替，方法精化不变。为保正文反 AI 味，本 skill 自带下文「AI 禁词」硬黑名单；深度去味由 pop-mirror-deai 承接。

## 创作原则

内化以下写作原则。

1. **展示而非告知** — 情绪通过行动外化，不贴标签
2. **价值观融进行为** — 角色的信念靠他在关键时刻做什么来证明，不喊口号
3. **人设三问** — 每个行动同时立在三条腿上：经历、利益、性格底色
4. **配角有自己的算盘** — 每个配角在遇到主角之前就存在，离开主角后继续过日子
5. **节奏有呼吸感** — 紧张和舒缓交替，日常段落为后文服务
6. **章尾必有拉力** — 钩子或情绪缺口，把读者钉在下一章
7. **全员智商在线** — 不降智、不圣母、不做无铺垫的妥协
8. **关系变化需事件触发** — 不是一夜之间称兄道弟或莫名深情
9. **欲望驱动** — 制造缺口 → 释放时超过读者预期
10. **五感具体化** — 每场景 1-2 种感官细节，不要只有视觉
11. **信息分层植入** — 基础信息通过行动带出，关键设定结合剧情节点揭示
12. **拒绝空转** — 每行字要么推剧情，要么塑人物
13. **高潮后有后效** — 爆发后 1-2 章必须写出改变
14. **每段有增量** — 至少带来新信息、态度变化或利益变化

## 创作技法

### 场景、视角与节奏
- **场景驱动**：新场景前 100 字让读者知道谁在场、在哪儿、发生什么
- **场景分层**：每个场景按序展开：感官设定（人/地/事）→ 角色行动 → 对话 → 内心反应 → 过渡到下一节拍
- **情感单一**：每个场景只有一个核心情感基调（对峙/温柔/压抑/热血），所有描写围绕它展开
- **行动桥接**：段落过渡用行动衔接，不用时间标记。"门在他身后咔嗒锁上" ✓　"与此同时" / "过了一会儿" ✗
- **对白功能化**：每段对白推进情节或揭示角色。不同角色说话方式有辨识度：用词习惯、句子长短、口头禅、方言痕迹
- **节奏控制**：长短句交替，紧张场景短句加速，抒情段落长句延展。避免连续以"他/她"开头
- **视角一致**：POV 角色只能知道其感知范围内的信息
- **禁止上帝视角**：不要直接写非 POV 角色的真实想法、隐藏动机、远处同步事件、未来结果或世界真相。需要让读者知道的信息，必须通过 POV 角色能接触到的动作、对白、表情、环境痕迹、传闻、文件、回忆或合理推断呈现。
- **默认受限视角**：用户未明确允许全知叙事时，默认按第三人称受限视角写；切换 POV 前必须有清晰场景边界，不在同一段落内跳头。

### 人物行为推导
每个关键角色在关键场景中的行为，必须经过以下推导：

1. **当前处境**：角色此刻面临什么局面？
2. **核心动机**：角色最想要什么？最害怕什么？
3. **信息边界**：角色知道什么？不知道什么？有什么误判？
4. **性格过滤**：同样的局面，这个性格会怎么反应？（冲动/谨慎/阴险/果断）
5. **行为选择**：基于以上四点，角色会做出什么选择？
6. **情绪外化**：用什么身体语言、表情、语气表达？

推导不出合理行为时，说明前置铺垫不足。以上六步仅用于创作推导，绝不可出现在正文叙事中。

### 读者心理学

- **期待管理**：读者期待释放时适当延迟以增强快感；即将失去耐心时立即给反馈
- **信息落差**：让读者比角色多知道一点（紧张），或比角色少知道一点（好奇）
- **锚定效应**：先给参照（对手多强/困难多大），再展示主角表现
- **代入感维护**：主角的困境必须有普遍性（被欺压、不公待遇、被低估）
- **欲望钩子**：每章至少让读者产生一个"接下来会怎样"的好奇心

### 字数与密度
章节密度和断章规则：全套硬尺见下文「精华·B｜源文件 01-章节节奏（节奏硬尺）」——每 300 字至少 1 个看点，每 500 字至少 1 个钩子，叙事段 40-120 字，禁止连续 3 个短段并排，章末 80/20 断章。

### 长篇连续性
超长篇正文生成前，核对上章钩子、时间线、空间线、角色状态、关系状态、道具资源、信息边界和活跃伏笔。资料冲突时，以已发布正文和最新事实提取为准，不静默覆盖旧事实。（对应审查由 pop-mirror-review 承接）

### 去AI味
输出前按 pop-mirror-deai 的完整规则执行清洗。

## AI 禁词

正文中禁止出现以下词汇和句式：

**废话黑名单**："值得注意的是""总的来说""与此同时""不可否认""毫无疑问""显而易见""众所周知""由此可见""值得一提的是""综上所述""换言之""从某种意义上说""需要指出的是""不言而喻""毋庸置疑"

**禁止句式**："不是……而是……""虽然……但是……""不仅……而且……""第一……第二……第三"；禁止使用破折号"——"，用逗号或句号断句

**因果连词**："因此""所以""于是""这意味着""也就是说"— 用行动直接推进，不解释因果关系

**情感标签**："他感到""他觉得""他不禁""他忍不住""他忽然意识到"— 用行动和对话外化情绪

**分析术语**："核心动机""本质上是""从根本上说""标志着""预示着"— 不写分析报告

**惊讶标记词**："仿佛""忽然""竟""竟然""猛地""猛然""不禁""宛如"— 每 3000 字不超过 1 次

**空洞强调词**："非常""极其""十分""无比""格外"— 能用精确描述代替时不用

## 自检清单

输出前确认：
- [ ] 无 AI 废话黑名单中的过渡词
- [ ] 句子长度和开头方式有变化
- [ ] 每段落有明确目的（情节/角色/氛围）
- [ ] 情绪通过行动呈现，而非贴标签
- [ ] 段落长度符合手机阅读规范（无连续短段）
- [ ] 章末有明确的钩子或情绪缺口
- [ ] 如有大纲，字数在大纲目标区间内（±10%）
- [ ] 上一章钩子已承接，角色位置/伤势/道具/信息边界没有断裂
- [ ] 没有上帝视角泄露：未写出 POV 角色无法感知、回忆、听闻或合理推断的信息
- [ ] 本章至少推进一个旧伏笔，新伏笔不超过 2 个

## 输出要求
- 如有大纲，严格依照其节拍顺序，不遗漏关键事件
- 保持与前文的人物状态、道具、时间线一致
- 保持既定叙事视角；没有明确视角规则时，默认第三人称受限视角
- 所有正文使用纯文本，禁用 Markdown 或任何格式标记
- 直接输出正文，不附创作说明、前言或元评论

### 精华·B｜源文件 01-章节节奏（节奏硬尺）

网文章节的字数、密度、段落和断章规则。

## 字数与爽点密度

- 每300字至少1个爽点/看点
- 每500字至少1个钩子
- 每1000-1500字至少1个完整悬念
- 目标字数允许区间为目标的±10%

## 叙事段长度

- 叙事段40-120字（3-5行手机屏）
- 对话段落天然短，不需并段
- 连续3个及以上短段（<40字）并列连排属于违规
- 短段仅在以下场景允许：(1)开场前300字反转金句 (2)章末钩子最后一句 (3)单章≤3个爆点短段
- 三个场景合计一章最多5个短段，超过即"堆砌电报体"
- 审核硬阈值：60%以上叙事段<40字 → 段落过碎，触发返工

## 80/20 断章硬尺

永远不要在一章里把本章故事讲完：写到80%，剩下20%留给下一章。

章末必须断在 action-climax 的那一刻：主角刚放大招尚未见效 / 刚拔刀尚未落下。

## 断章钩子轮换

每章结尾至少留下一个缺口。钩子必须轮换，不能每章都靠同一种悬念。

- 悬念类：关键信息即将揭露、秘密即将暴露、真相刚露一角。
- 危机类：强敌降临、陷阱触发、计划失败、背叛发生。
- 反转类：身份即将揭露、敌友转换、局势逆转、意外变故。
- 期待类：即将突破、宝物将到手、比赛结果、考核成绩。
- 情感类：误会将解、重逢/离别、告白回应、关系破裂。
- 信息类：重大消息、阴谋揭露、世界观重大信息、系统提示。

钩子必须在下一章前 1/3 处给反馈。可以不完全回收，但要让读者感觉上一章的问题被正面处理了。

## 节奏变化

```
紧张 → 缓解 → 新紧张 → 更紧张
```

- 紧张场景用短句加速（连续短句排比）
- 抒情或思考段落适当放慢（长句+感官细节）
- 避免单调的句子开头：不要连续以"他/她"开头
- 句式长短错落：长句用于环境/心理，短句用于动作/冲突

## 场景规范

- 新场景前100字让读者知道谁在场、在哪儿、发生什么
- 场景转换必须有过渡，禁止前一刻在A地、下一刻毫无过渡出现在B地
- 场景切换需通过感官细节建立新空间感

## 高潮前后规则

- **高潮前**：大高潮前3-5章必须有线索埋设
- **高潮后**：爆发后1-2章必须写出改变（主线推进、人设成长、关系变化），不能直接跳到下一个蓄压

***

## 红线

1. **展示而非告知**：情绪通过行动外化；禁止贴标签/喊口号/上帝视角/大段解释代替行动。
2. **受限视角默认**：未明确全知时按第三人称受限视角，POV 不越界、切换有场景边界。
3. **AI 禁词清零**：废话黑名单/禁止句式/因果连词/情感标签/分析术语/惊讶标记词密度/空洞强调词，按上文硬黑名单执行。
4. **节奏硬尺随文执行**：字数目标±10%；每300字≥1爽点/500字≥1钩子/1000-1500字≥1悬念；叙事段40-120字，>60%叙事段<40字返工，一章短段≤5个。
5. **章末拉力**：必留钩子或情绪缺口，断在 action-climax（80/20），钩子六类轮换且下一章前1/3给反馈。
6. **场景/高潮纪律**：场景切换有过渡靠感官建空间；高潮前3-5章铺线、爆发后1-2章写后效。
7. **每章推进一个旧伏笔**，新伏笔 ≤2 个；上一章钩子必须承接，状态不断裂。
8. **交接纪律**：正文纯文本无 Markdown、不附创作说明；新增事实只声明交 pop-mirror-review 落库，write 不自行落库。
