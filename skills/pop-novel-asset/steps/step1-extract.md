# Step 1: 资产提取

> 按 Step 0 规划执行提取 → 🚪 门禁：资产确认 → 落盘 → 消费路由

## 1. 角色档案提取

读取 `references/asset-extract-guide.md` §一 获取详细方法论。

### 1.1 关键词搜索（5轮）

对每个目标角色执行5轮搜索：

| 轮次 | 关键词类型 | 示例（李周巍） | 目的 |
|:-----|:---------|:-------------|:-----|
| 第1轮 | 角色名 | `李周巍` | 定位所有出场段落 |
| 第2轮 | 外貌词 | `李周巍.*(眸\|眼\|甲\|氅\|袍\|发)` | 采集外貌描写 |
| 第3轮 | 性格词 | `李周巍.*(霸道\|虎豹\|冷\|笑\|怒)` | 采集性格特征 |
| 第4轮 | 评价词 | `白麟\|魏王\|李氏天骄` | 采集他人评价 |
| 第5轮 | 关系词 | `李周巍.*(父亲\|母亲\|叔公\|部下)` | 采集人际关系 |

> 使用 Grep 工具搜索原文，output_mode=content, -n=true, 记录命中行号。
> 写作专家项目：搜索 `正文/` 目录下所有 ch*.txt 文件。
> 独立项目：搜索单个 txt 文件。

### 1.2 上下文采样

每个关键词命中后，用 Read 工具读取前后20-50行上下文。重点关注：外貌描写、对话、动作、他人评价、心理活动。每个维度至少3-5条原文佐证。

### 1.3 10维度档案整理

将采样结果整理为10维度档案：

| 维度 | 内容 |
|:-----|:-----|
| 一、角色概览 | 姓名/道号/称号/兵器/功法/命格/核心气质 |
| 二、外貌演变 | 按年龄阶段记录外貌变化（含行号） |
| 三、性格特征 | 5-7个性格侧面+原文佐证 |
| 四、人际关系 | 与3-5个关键人物的互动模式 |
| 五、成长弧线 | 6-8个成长阶段（事件+变化） |
| 六、金句语录 | 5-10句标志性台词（按主题分类） |
| 七、他人评价 | 旁人/长辈/敌人/龙属的评价（分类） |
| 八、矛盾与暗面 | 角色的复杂性、阴暗面、非人感 |
| 九、视觉设计参考 | 3-8个最适合做OC的关键场景与形象 |
| 十、核心意象与符号 | 贯穿全文的视觉符号（3-7个） |

### 1.4 写作专家项目辅助

如果已有 `设计/角色库/角色库.md`：
- 读取已有角色设定，作为维度一（概览）和维度三（性格）的辅助参考
- 已有设定提供概览，但仍需从正文采样原文佐证
- 在档案中标注："已有设定参考"部分，与"原文采样"部分区分

### 1.5 增量更新

如果是增量更新模式：
- 只搜索增量章节范围（如 ch016-ch020）
- 新发现的外貌描写 → 追加到维度二（外貌演变）
- 新的成长事件 → 追加到维度五（成长弧线）
- 新的评价/金句 → 追加到维度六/七
- 更新文件头部的"采样范围"标记

## 2. 场景资产表提取

读取 `references/asset-extract-guide.md` §二 获取详细方法论。

### 2.1 场景扫描

对指定章节范围（或全文）执行场景扫描：

1. 用 Grep 搜索场景转换标志词：`到了|进入|来到|站在|眼前|远处|天空|大地`
2. 用 Grep 搜索视觉密集段落：颜色词+器物词+动作词的共现段落
3. 对每个命中段落，用 Read 读取上下文确认是否为关键场景

### 2.2 场景拆解

每个关键场景拆解为"可定格帧"：

| 帧编号 | 章节位置 | 场景名 | 参与角色 | 视觉元素清单 | 氛围基调 | 叙事含义 | 行号 |
|:-------|:---------|:-------|:---------|:-------------|:---------|:---------|:-----|
| F001 | ch005 | 封王大典 | 李周巍、宋帝 | 金光礼舆、仙旨、黑金华服 | 庄严、神圣 | 角色身份质变 | 193219-193269 |
| F002 | ch012 | 全甲战斗 | 李周巍 | 黑金甲衣、王氅、长戟、曦炁之火 | 狂暴、压迫 | 武力巅峰 | 194849-194863 |

### 2.3 帧评估与筛选

对每个帧评估：
- **视觉张力**（1-5）：画面构图潜力
- **叙事含量**（1-5）：承载的故事信息量
- **情感共鸣**（1-5）：读者想"看到"的程度

> 优先保留视觉张力≥3 且 叙事含量≥3 的帧。消费方可按需选取。

## 3. 视觉符号库提取

读取 `references/asset-extract-guide.md` §三 获取详细方法论。

### 3.1 意象扫描

从全文中提取贯穿反复出现的视觉意象：

| 搜索维度 | Grep 关键词模板 | 提取内容 |
|:---------|:---------------|:---------|
| 核心意象 | `[角色名].*(眸\|眼\|甲\|袍\|戟\|钺)` | 角色标志性视觉特征 |
| 标志色 | `(金色\|暗金\|黑金\|白金\|浅紫\|朱砂)` | 反复出现的色彩 |
| 标志器物 | `(长戟\|王钺\|法器\|灵器)` | 标志性道具 |
| 阵营符号 | `(旗帜\|纹章\|族徽\|标记)` | 势力视觉标识 |

### 3.2 符号整理

| 意象 | 含义 | 首次出现 | 出现频率 | 视觉描述 |
|:-----|:-----|:---------|:---------|:---------|
| 暗金色眸子 | 白麟命格外显 | ch001 | 贯穿全文 | 金色圈环相扣，情绪波动时变亮 |
| 长戟（大昇） | 武力与征伐 | ch002 | 从小到大 | 深金色长戟，古筑基法器 |
| 王钺 | 明阳权柄 | ch010 | 封王后 | 棕黄蕴银光，麟兽之纹 |

### 3.3 写作专家项目辅助

如果已有 `设计/力量体系.md`：
- 读取力量体系中的视觉外显描述（如"明阳之道→金色光芒"）
- 辅助推导力量体系的视觉特征

## 4. IP视觉DNA提取（同人时）

读取 `references/asset-extract-guide.md` §四 获取详细方法论。

### 4.1 源IP识别

从书名、角色名、世界观术语中识别源IP。

### 4.2 视觉DNA提取

WebSearch 搜索源IP视觉资料，提取4维度：

| 维度 | 提取内容 | 搜索关键词 |
|:-----|:---------|:---------|
| 源IP画风 | 笔触/比例/色彩倾向 | `[源IP] official art style` |
| 角色经典形象 | 原著角色标志性外观 | `[源IP] character design` |
| 世界观视觉符号 | 原作反复出现的视觉元素 | `[源IP] visual symbols` |
| 标志色 | 原作主色调 | `[源IP] color palette` |

## 5. 🚪 门禁：资产确认

**这是强制暂停点。禁止跳过。**

### 5.1 呈现资产摘要

```
## 视觉资产提取完成

### 角色档案
#### [角色名]
- 核心气质：[1-2句话]
- 外貌关键特征：[3个特征+行号]
- 最适合做OC的场景：[3个+行号]
- 核心意象：[3-5个]
- 核心金句：[1句+行号]

### 场景资产表
- 共提取 [N] 个可定格帧
- 高视觉张力帧（≥4）：[M] 个
- 覆盖章节范围：ch001-ch020

### 视觉符号库
- 核心意象：[N] 个
- 标志色：[N] 个
- 标志器物：[N] 个

### IP视觉DNA（如有）
- 源IP：[名称]
- 画风特征：[一句话]
- 标志色：[列表]

---
请确认提取结果是否准确，或告诉我遗漏了什么。
确认后资产将落盘到 素材/视觉资产/。
```

### 5.2 等待用户确认

用户可能的回复：
- "确认，落盘" → 执行落盘
- "[角色]的评价不对，应该是..." → 修正后重新呈现
- "漏了一个场景：[描述]" → 补充提取
- "再提取一个角色：[角色名]" → 返回 §1 执行新角色提取

## 6. 落盘

### 6.1 创建目录

确保 `素材/视觉资产/` 目录存在。

### 6.2 写入资产文件

每个产出写入独立文件：

- `素材/视觉资产/[角色名]角色档案.md`
- `素材/视觉资产/场景资产表.md`
- `素材/视觉资产/视觉符号库.md`
- `素材/视觉资产/IP视觉DNA.md`（同人时）

### 6.3 文件头部标记

每个资产文件头部必须包含：

```markdown
> 采样范围：ch001-ch020（共20章）
> 提取日期：2026-07-30
> 项目类型：[类型]
> 源文件：[原文路径]
```

### 6.4 更新资产索引

更新 `素材/视觉资产/资产索引.md` 中的资产清单和状态。

## 7. 消费路由

资产落盘后，根据用户意图路由：

| 用户意图 | 路由指令 |
|:---------|:---------|
| "做OC/立绘" | 告知用户："角色档案已就绪，可调用 pop-novel-oc 生成OC立绘" |
| "做漫画" | 告知用户："角色档案+场景资产表已就绪，可调用 pop-novel-comic 生成漫画" |
| "做封面/场景图" | 告知用户："场景资产表+视觉符号库已就绪，可调用 pop-novel-cover 生成封面" |
| "只提取" | 告知用户："视觉资产已落盘到 素材/视觉资产/，后续可随时使用" |

> asset skill 本身不调用消费 skill，只告知用户资产已就绪。由用户或主 agent 触发消费 skill。
