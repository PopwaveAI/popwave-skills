# Step 0: 项目初始化

> 读取小说项目设定 → 提取角色视觉规格 → 生成定妆图 → 冻结提示词 → 创建记忆文件

## 设计哲学

Phase 0 是漫画连载的**一次性地基**。所有跨章一致性的根基在这里奠定：角色长什么样（定妆图）、怎么描述（冻结提示词）、全系列什么风格（风格锚定串）。

冻结提示词是核心——角色定妆图生成后，发给 API 的原始提示词立即冻结到角色库。后续所有章节直接引用这个冻结版，不再重新组装。这样 DeepSeek 即使没有视觉能力，也能通过"引用同一份文本指令"保证角色一致。

## 1. 读取小说项目设定

从小说项目读取以下文件（按优先级）：

| 文件 | 路径 | 用途 |
|:-----|:-----|:-----|
| 角色库.md | `设计/角色库.md` 或 `角色库.md` | 提取角色清单和视觉特征 |
| 主角设计.md | `设计/主角设计.md` | 主角详细设定 |
| 力量体系.md | `设计/力量体系.md` | 世界观风格参考 |
| 卷纲.md | `设计/第一卷剧情/卷纲.md` | 了解故事走向，预判角色变化 |

> 如果项目无上述文件，从正文 `ch001.txt` 中提取角色信息。

## 2. 提取角色视觉规格表

为每个重要角色建立视觉规格表。**必读 `references/char-consistency-guide.md`** 了解角色一致性管理方法论。

### 角色筛选标准

- 主角：必出定妆图
- 出场≥2章的配角：强制出定妆图
- 只出场1章的配角：不需要，在分镜提示词中描述即可

### 规格表格式

| 字段 | 说明 | 示例 |
|:-----|:-----|:-----|
| 角色名 | 原文中的称呼 | 索伦 |
| 年龄/性别 | 推断 | 18岁男性 |
| 体型 | 瘦弱/健壮/高大/矮小 | 瘦削，病后初愈 |
| 发色/发型 | 原文描述或推断 | 亚麻色短发，微乱 |
| 瞳色 | 原文描述或推断 | 黑色 |
| 服装 | 原文描述或推断 | 破旧亚麻衬衫，赤脚 |
| 标志性特征 | 疤痕/异色瞳/特殊道具 | 苍白面色，锁骨突出 |

## 3. 确定风格锚定串

从小说赛道和情绪基调推导全系列统一的视觉风格。风格锚定串**冻结到漫画快照.md**，全系列所有章节共用。

| 赛道 | 推荐风格锚定串 |
|:-----|:-------------|
| 暗黑奇幻 | `暗黑奇幻半写实日式漫画风格，水彩质感笔触，灰暗色调，暖色火光点缀，情绪氛围浓郁` |
| 都市异能 | `都市暗黑漫画风格，写实笔触，霓虹色调，高对比度光影，电影感构图` |
| 言情甜宠 | `清新水彩少女漫画风格，柔和色调，暖光氛围，细腻笔触` |
| 修仙玄幻 | `国风水墨漫画风格，写意笔触，青绿山水色调，留白意境` |
| 悬疑诡异 | `暗黑写实漫画风格，冷灰色调，强烈明暗对比，压抑氛围` |

## 4. 生成角色定妆图

为每个角色生成定妆图（纯文生图）。

### 定妆图提示词写法

```
一个[年龄]的[体型特征]角色，[发色/发型]，[瞳色]，穿[服装描述]，[标志性特征]。[表情]。[风格锚定串]，全身立绘，纯色背景。
```

### 调用方式

```powershell
$env:ARK_API_KEY="{API_KEY}"
python "{pop-novel-visual路径}/scripts/generate.py" image `
  --prompt '{定妆提示词}' `
  --model doubao-seedream-5-0-lite-260128 `
  --size 1728x2304 `
  --output "{漫画项目}/assets/characters/char-{角色名}-v1.png"
```

### 生成后立即冻结提示词

**这是最关键的一步。** 定妆图生成后，将发给 API 的完整提示词原文冻结到角色库。格式见 `templates/漫画角色库.md.tpl`。

> 冻结提示词 = 曾经发给 API 的原始文本。后续章节引用此文本，不重新组装。

## 5. 创建记忆文件

使用模板创建三个记忆文件：

| 文件 | 模板 | 说明 |
|:-----|:-----|:-----|
| 漫画角色库.md | `templates/漫画角色库.md.tpl` | 填入所有角色的四层结构（规格表+冻结提示词+资产+日志） |
| 漫画快照.md | `templates/漫画快照.md.tpl` | 填入风格锚定串+角色清单+空章节清单 |
| 漫画状态.md | `templates/漫画状态.md.tpl` | 初始状态：当前章=第1章，无历史问题 |

同时创建：
- `assets/characters/` 目录（定妆图已在此步骤生成）
- `视觉沉淀.md`（空文件，等待 Phase 2 append）

## 6. 🚪 门禁0：角色定妆确认

向用户呈现：

1. **角色视觉规格表**（全部角色的规格表）
2. **定妆图**（生成的所有角色定妆图）
3. **冻结提示词**（每个角色的冻结版提示词）
4. **风格锚定串**

用户确认后 Phase 0 完成。用户可调整：改角色外观、换风格、增删角色。

> Phase 0 完成后，进入 Phase 1（读取 `steps/step1-chapter.md`）。
