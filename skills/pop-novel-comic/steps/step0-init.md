# Step 0: 项目初始化

> 读取设定 → 推导画风 → 生成定妆图 → 门禁0(角色+画风双确认) → 冻结 → 创建记忆文件

## 设计哲学

Phase 0 是漫画连载的**一次性地基**。所有跨章一致性的根基在这里奠定：角色长什么样（定妆图）、怎么描述（冻结提示词）、全系列什么风格（风格锚定串）。

冻结提示词是核心——角色定妆图生成后，发给 API 的原始提示词立即冻结到角色库。后续所有章节直接引用这个冻结版，不再重新组装。这样 DeepSeek 即使没有视觉能力，也能通过"引用同一份文本指令"保证角色一致。

**画风不是从表里选一行字符串就定的**——风格锚定串必须通过定妆图的视觉效果验证后才能冻结。门禁0同时确认角色外观和画风，不通过则调整后重新生成。

## 1. 读取小说项目设定

从小说项目读取以下文件（按优先级）：

| 文件 | 路径 | 用途 |
|:-----|:-----|:-----|
| 角色库.md | `设计/角色库.md` 或 `角色库.md` | 提取角色清单和视觉特征 |
| 主角设计.md | `设计/主角设计.md` | 主角详细设定 |
| 力量体系.md | `设计/力量体系.md` | 世界观风格参考 |
| 卷纲.md | `设计/第一卷剧情/卷纲.md` | 了解故事走向，预判角色变化 |
| ch001.txt | `正文/ch001.txt` | 无设定文件时，从正文提取 |

### 1.1 IP 背景检查（画风推导前必执行）

**在推导画风之前，必须先判断小说是否基于已有 IP。** 同人/改编小说的画风推导需要参考源 IP 的视觉 DNA。

| IP 类型 | 识别信号 | 处理方式 |
|:---------|:---------|:---------|
| **同人** | 出现原著角色名、世界观术语、能力体系 | WebSearch 搜索源 IP 官方画风 → 提取视觉 DNA → 决定锚定或偏离 |
| **改编** | 书名或设定与已知 IP 高度重合 | 同上 |
| **原创** | 无原著角色名、无已知世界观 | 跳过，正常推导画风 |

> 详见 `../pop-novel-visual/references/novel-visual-design.md` §IP 背景理解。漏判 IP 背景会导致画风方向完全跑偏。

## 2. 提取角色视觉规格表

为每个重要角色建立视觉规格表。**必读 `references/char-consistency-guide.md`** 了解角色一致性管理方法论。

### 角色筛选标准

- 主角：必出定妆图
- 出场≥2章的配角：强制出定妆图
- 只出场1章的配角：不需要，在分镜提示词中描述即可

### 规格表格式

| 字段 | 说明 | 示例 |
|:-----|:-----|:-----|
| 角色名 | 原文中的称呼 | 索伦 |
| 年龄/性别 | 推断 | 18岁男性 |
| 体型 | 瘦弱/健壮/高大/矮小 | 瘦削，病后初愈 |
| 发色/发型 | 原文描述或推断 | 亚麻色短发，微乱 |
| 瞳色 | 原文描述或推断 | 黑色 |
| 服装 | 原文描述或推断 | 破旧亚麻衬衫，赤脚 |
| 标志性特征 | 疤痕/异色瞳/特殊道具 | 苍白面色，锁骨突出 |

## 3. 推导画风主基调

画风不是从表里选一行就完事——要结合小说的**赛道 + 情绪基调 + 世界观特征**三维度推导。

### 推导公式

```
风格锚定串 = [画种风格] + [笔触质感] + [色调倾向] + [光影特征] + [氛围修饰]
```

### 赛道基准表（起点，非终点）

| 赛道 | 基准风格串 | 在此基础上叠加 |
|:-----|:---------|:-------------|
| 暗黑奇幻 | 暗黑奇幻半写实日式漫画风格 | + 具体色调（灰暗/冷蓝/暖火光） |
| 都市异能 | 都市暗黑漫画风格 | + 城市特征（霓虹/雨天/高楼阴影） |
| 言情甜宠 | 清新水彩少女漫画风格 | + 暖光特征（午后阳光/樱花/暖黄） |
| 修仙玄幻 | 国风水墨漫画风格 | + 山水特征（青绿/云雾/留白） |
| 悬疑诡异 | 暗黑写实漫画风格 | + 压抑特征（高对比/冷灰/雾气） |

### 情绪基调修正

读取小说第1章和卷纲，判断全书情绪基调，对基准风格串做修正：

| 情绪基调 | 修正方向 | 示例 |
|:---------|:---------|:-----|
| 绝望生存 | 加重灰暗、压抑、粗糙质感 | 贫民窟破败感，泥土和锈迹 |
| 热血逆袭 | 提亮对比、加动态感、锐利线条 | 烈火和金属光泽 |
| 诡秘悬疑 | 加雾气、模糊边界、不对称构图 | 维多利亚煤气灯，阴影浓重 |
| 温馨治愈 | 柔化笔触、加暖光、圆润线条 | 水彩晕染，午后阳光 |

### 推导示例

《深渊主宰》——暗黑奇幻赛道 + 绝望生存基调 + 贫民窟世界观：

```
基准: 暗黑奇幻半写实日式漫画风格
修正: + 水彩质感笔触（手绘感，非数码光滑）
     + 灰暗色调为主，暖色火光点缀（灶火/油灯）
     + 破败泥泞质感（发霉墙壁/湿柴/泥水）
     + 情绪氛围浓郁
最终: 暗黑奇幻半写实日式漫画风格，水彩质感笔触，灰暗色调，暖色火光点缀，破败泥泞质感，情绪氛围浓郁
```

> 此时的风格锚定串是**待验证版**，尚未冻结。

## 4. 生成角色定妆图（兼画风验证）

定妆图同时承载两个验证目标：**角色外观对不对** + **画风效果好不好**。

### 定妆图提示词写法

定妆图是跨章一致性的基准，建议使用高精度模板（见 `../pop-novel-visual/references/seedream-prompt-guide.md` §1.10）。

**基础写法**（简单角色/速度优先）：
```
一个[年龄]的[体型特征]角色，[发色/发型]，[瞳色]，穿[服装描述]，[标志性特征]。[表情]。[待验证风格锚定串]，全身立绘，纯色背景。
```

**高精度写法**（主角定妆图/商业级质量）：
```
LOCKED COMPOSITION:
[镜头规格]：35mm镜头，平视，角色居中占画面75%
[角色外观]：年龄+种族+发型发色+眼瞳色+面部特征+皮肤质感+表情+服装逐层（外套→衬衫→腰带→裤子→靴子）+配饰
[角色动作]：每只手的具体动作 + 身体姿态
[背景]：纯色或简约背景

ENVIRONMENT AND LIGHTING:
[光源]：正面柔光为主 + 轮廓光
[渲染]：photorealistic materials, detailed fabric texture, individual hair strands, skin pores, [风格锚定串]

HARD CONSTRAINTS:
Exactly one character. No duplicated limbs. Exactly five fingers per hand. No chibi proportions. No flat cel-shaded anime.
```

> **定妆图是全系列基准，值得用高精度模板。** 主角定妆图强烈建议使用高精度写法，配角可用基础写法加速。

### 调用方式

```powershell
$env:ARK_API_KEY="{API_KEY}"
python "{pop-novel-visual路径}/scripts/generate.py" image `
  --prompt '{定妆提示词}' `
  --model doubao-seedream-5-0-lite-260128 `
  --size 1728x2304 `
  --output "{漫画项目}/assets/characters/char-{角色名}-v1.png"
```

### 生成顺序

1. 先生成**主角**定妆图（1张）——用最关键的角色验证画风
2. 看效果，如果画风明显不对 → 回 §3 调整风格串 → 重新生成
3. 画风OK → 继续生成其他角色定妆图

## 5. 🚪 门禁0：角色 + 画风双确认

向用户呈现：

1. **风格锚定串**（待验证版）+ 推导理由（赛道+基调+世界观）
2. **角色定妆图**（全部已生成的角色）
3. **角色视觉规格表**（全部角色的规格表）

### 用户决策分支

| 反馈 | 处理 |
|:-----|:-----|
| 角色OK，画风OK | → 进入 §6 冻结 |
| 画风不对 | → 回 §3 调整风格串 → 重新生成全部定妆图 → 再次门禁0 |
| 某个角色不对 | → 调整该角色的规格表/提示词 → 重新生成该角色定妆图 → 再次门禁0 |
| 增删角色 | → 补生成新角色定妆图 / 删除不需要的 → 再次门禁0 |

> **画风调整时必须重新生成全部已出的定妆图**——因为风格串变了，旧定妆图的画风就不统一了。

## 6. 冻结（门禁0通过后执行）

门禁0通过后，**一次性冻结所有基线资产**：

### 6.1 冻结风格锚定串

将门禁0确认的风格锚定串写入 `漫画快照.md`。此后全系列冻结，不每章重推导。

### 6.2 冻结角色提示词

将每个角色定妆图的完整提示词原文冻结到 `漫画角色库.md`。

> 冻结提示词 = 曾经发给 API 的原始文本。后续章节引用此文本，不重新组装。

### 6.3 创建记忆文件

使用模板创建四个记忆文件：

| 文件 | 模板 | 说明 |
|:-----|:-----|:-----|
| 漫画角色库.md | `templates/漫画角色库.md.tpl` | 填入所有角色的四层结构（规格表+冻结提示词+资产+日志） |
| 漫画快照.md | `templates/漫画快照.md.tpl` | 填入已冻结的风格锚定串+角色清单+空章节清单 |
| 漫画状态.md | `templates/漫画状态.md.tpl` | 初始状态：当前章=第1章，无历史问题 |
| 视觉沉淀.md | 无模板（空文件） | 等待 Phase 2 append |

同时确认：
- `assets/characters/` 目录已有全部定妆图
- `视觉沉淀.md` 已创建（空文件）

> Phase 0 完成后，进入 Phase 1（读取 `steps/step1-chapter.md`）。
