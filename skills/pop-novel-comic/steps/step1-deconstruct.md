# Step 1: 章节解构 → 分镜脚本

> 读取章节原文 → 提取角色 → 拆 6-8 个关键帧 → 确定风格锚定串 → 门禁A（分镜确认）

## 设计哲学

Step 1 的核心是**像漫画编剧一样思考**。Agent 读一章网文，不是翻译文字为画面，而是理解故事的情绪弧，从中选出最该画的 6-8 个瞬间。

Seedream 不理解故事，它只会画单张图。分镜脚本的质量决定了漫画的叙事质量——选错了帧，画得再好也讲不清故事。

## 1. 读取章节原文

读取用户指定的章节文件（.txt / .md）。

如果用户未指定文件，从项目文件中寻找可用的正文文件：
- `正文/ch{NNN}.txt` 或 `正文/ch{NNN}.md`
- 优先选第 1 章（开头场景最适合做漫画）

## 2. 提取角色清单

从原文中识别出场角色，为每个角色提取视觉特征：

| 项目 | 内容 |
|:-----|:-----|
| 角色名 | 原文中的称呼 |
| 年龄/性别 | 推断 |
| 体型特征 | 瘦弱/健壮/高大/矮小 |
| 发色/发型 | 原文描述或推断 |
| 服装 | 原文描述或推断 |
| 标志性特征 | 疤痕/异色瞳/特殊道具等 |

> 只提取有视觉特征信息的角色。背景路人不列入。

## 3. 拆关键帧

从章节中拆出 6-8 个关键帧。选帧原则：

### 选帧标准

1. **情绪转折点优先**：每次情绪变化都值得一个分镜
2. **动作高潮优先**：打斗、追逐、冲突的瞬间
3. **信息揭示优先**：新角色登场、关键道具出现、真相揭露
4. **避免纯对话帧**：两个人站着说话是最差的漫画画面
5. **机位变化**：全景→中景→近景→特写交替，避免连续相同机位

### 分镜脚本表格式

每帧确定以下要素：

| 字段 | 说明 | 示例 |
|:-----|:-----|:-----|
| 帧号 | 1~8 | 3 |
| 场景 | 地点+时间+环境 | 破屋门口，雨夜 |
| 角色动作 | 谁在做什么 | 薇薇安抱住老狗希斯的脖子 |
| 机位 | 全景/中景/近景/特写 | 中近景 |
| 情绪 | 这一帧的情感基调 | 温暖安慰 |
| 对白/文字 | 气泡/旁白/拟声词 | 薇薇安："你会保护我的，对不对？" |
| 画面提示词 | ≤300字，给 Seedream 的画面描述 | 参考图中的人物形象。瘦弱女孩蹲在... |

### 提示词写法

每格提示词结构：
```
[参考图指令（如有角色）] + [角色动作描述] + [场景环境描述] + [风格锚定串]
```

- 第 1 句写 `参考图中的人物形象`（告诉模型要从参考图提取角色特征）
- 第 2-3 句写角色在做什么、场景什么样
- 末尾追加风格锚定串

## 4. 确定风格锚定串

从章节的赛道和情绪基调推导统一的视觉风格：

| 赛道 | 推荐风格锚定串 |
|:-----|:-------------|
| 暗黑奇幻 | `暗黑奇幻半写实日式漫画风格，水彩质感笔触，灰暗色调，暖色火光点缀，情绪氛围浓郁` |
| 都市异能 | `都市暗黑漫画风格，写实笔触，霓虹色调，高对比度光影，电影感构图` |
| 言情甜宠 | `清新水彩少女漫画风格，柔和色调，暖光氛围，细腻笔触` |
| 修仙玄幻 | `国风水墨漫画风格，写意笔触，青绿山水色调，留白意境` |
| 悬疑诡异 | `暗黑写实漫画风格，冷灰色调，强烈明暗对比，压抑氛围` |

> 风格锚定串全章共用，追加在每格提示词末尾。

## 5. 🚪 门禁A：分镜确认

向用户呈现：

1. **角色视觉规格表**（角色名 + 视觉特征）
2. **分镜脚本表**（6-8 帧的完整信息）
3. **风格锚定串**

用户确认后进入 Step 2。用户可调整：增删帧、改机位、改对白、换风格。

## 6. 输出文件

将分镜脚本写入 `{输出目录}/storyboard.md`，包含：
- 风格锚定串
- 角色视觉规格表
- 分镜脚本表（含每帧的提示词）

> Step 1 完成后，自行进入 Step 2（读取 `steps/step2-generate.md`）。
