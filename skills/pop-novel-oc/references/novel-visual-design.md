# 网文视觉设计方法论

> 本文件提供从小说卖点到视觉设计方案的翻译方法论，作为 Step 1 设计环节的参考依据。

## 一、核心原则

**小说封面不是插画，是视觉钩子。** 封面的唯一目标是让目标读者在 0.3 秒内识别赛道、感知独特性、产生点击欲望。

**设计推理三步法**：
1. **读懂小说** → 提取小说 DNA（IP背景 + USP + 电影海报时刻 + 读者承诺）
2. **设计钩子** → 选择视觉钩子类型，设计独有画面
3. **构建构图** → 用空间关系讲 0.3 秒的故事

### IP 背景理解（读懂小说的第一步）

**小说不是凭空诞生的——它可能基于已有 IP，已有 IP 的视觉 DNA 是设计的重要参考。**

在提取 USP 之前，必须先判断小说的 IP 背景：

| IP 类型 | 识别信号 | 处理方式 |
|:---------|:---------|:---------|
| **同人**（基于动漫/小说/游戏） | 出现原著角色名、世界观术语、能力体系 | 必须提取源 IP 的视觉 DNA：原作画风、角色经典形象、标志色、世界观视觉符号 |
| **改编**（基于影视/动漫 IP） | 书名或设定与已知 IP 高度重合 | 同上 |
| **原创**（无 IP 背景） | 无原著角色名、无已知世界观 | 跳过此步，正常提取 USP |

**同人小说的视觉 DNA 提取清单**：

| 维度 | 提取内容 | 示例（海贼王同人） |
|:-----|:---------|:------------------|
| 源 IP 画风 | 原作的笔触风格、色彩倾向、人物比例特征 | 尾田荣一郎风格：男性角色棱角分明、夸张体态、热带海域高饱和色彩 |
| 角色经典形象 | 原著角色的标志性外观特征 | 索隆的绿发三刀流、路飞的草帽、女帝的高傲表情 |
| 世界观视觉符号 | 原作中反复出现的视觉元素 | 海贼旗骷髅、恶魔果实纹路、伟大航路岛屿特征 |
| 标志色 | 原作的主色调 | 海蓝+金黄+草帽麦色 |

> **同人 ≠ 照搬原作画风**。提取源 IP 视觉 DNA 是为了在设计中**有意识地锚定或偏离**——比如"海贼王同人但走暗黑写实路线"比"海贼王同人但画风不明"有明确的设计方向。在 Pinterest 搜索时，IP 维度搜索应包含源 IP 的官方美术作为参考。

> **门禁**：如果无法判断是否为同人，必须问用户"这本小说是否基于某个已有 IP（动漫/小说/游戏）"。漏判 IP 背景会导致设计方向完全跑偏——比如把海贼王同人画成维京海盗风格。

**封面视觉权重分配**（v1.5.1 实测验证）：

| 层 | 内容 | 视觉权重 | 说明 |
|:---|:-----|:---------|:-----|
| 画面主视觉 | 视觉钩子主体+场景 | 七成左右 | 绝对主体，画面才是封面的"主角" |
| 书名文字 | 书名 | 两成左右 | 画面"注释"，融入画面而非独占空间 |
| 文化元素 | 定场诗+印章等 | 半成左右 | 点缀提逼格，不抢焦点 |
| 留白/暗部 | 呼吸空间 | 半成左右 | 暗部区域承载文字叠加 |

> **核心原则**：画面是绝对主体，文字是画面的"注释"不是"主角"。文字融入画面层次（被前景遮挡/与雾气融合），不形成独立"文字区"。

## 二、视觉钩子设计库

视觉钩子是封面的核心——那个让读者 0.3 秒停下拇指的东西。一张封面只有 1 个钩子。

| 钩子类型 | 适用场景 | 视觉特征 | 构图骨架 | 示例 |
|:---------|:---------|:---------|:---------|:-----|
| 标志道具 | 小说有独特核心道具 | 道具居中/放大，散发能量，人物为辅 | 中心放射 | 玄鉴仙族→破碎古镜 |
| 角色统治力 | 主角人设是最大卖点 | 角色占据画面主体，俯视/压迫姿态 | L型构图 | 深渊主宰→主角居高临下 |
| 反差瞬间 | 扮猪吃虎/身份反转 | 前景朴素 vs 后景恐怖力量暗示 | 框中框 | 质子逆袭→囚徒 vs 王座 |
| 群像史诗 | 家族/势力群像 | 多人物分层站位，有等级关系 | 分层群像 | 玄鉴仙族→族长+族人 |
| 世界奇观 | 世界观是最大卖点 | 场景占画面主体，人物渺小 | 分层群像 | 仙穹→浮空仙殿群 |
| 对峙张力 | 核心冲突是双雄对决 | 双方分列画面两侧，中间能量碰撞 | 对角线对峙 | 宿敌→正邪对峙 |

### 钩子设计原则

1. **唯一性**：这个钩子换一本书就不适用。如果"主角站在山顶修炼"适用于任何修仙文，那就不是钩子
2. **故事性**：读者看一眼能脑补出剧情。"破碎古镜倒映敌人功法"比"一面古镜"有故事感
3. **承诺感**：钩子承诺了读者将获得的体验。破碎古镜承诺"以敌为师的智斗爽感"
4. **差异化**：和同赛道 50 张封面放一起，这个钩子能让读者多看一眼

### 赛道 → 视觉风格 + 差异化机会

| 赛道 | 常见风格 | 常见色调 | 视觉符号 | 差异化机会 |
|:-----|:---------|:---------|:---------|:-----------|
| 修仙/玄幻 | 国风/暗黑国风 | 深蓝墨黑+流光 | 法宝、云海、神殿 | 暗红铜锈/水墨留白/道具特写 |
| 都市异能 | 写实/赛博朋克 | 冷灰霓虹+暖光 | 高楼、夜景、能量 | 日间逆光/暖色主导 |
| 末世生存 | 废土写实 | 黄灰废土+绿光 | 废墟、变异、装备 | 科技蓝/夜间极光 |
| 悬疑诡异 | 暗黑写实/油画 | 冷暗色+局部高光 | 阴影、符号、雾气 | 暖黄老照片/高饱和局部 |
| 游戏入侵 | 赛博/游戏UI | 蓝紫科技+数据流 | 面板、代码、装备 | 红色警告/复古像素 |
| 言情甜宠 | 日系水彩/清新 | 粉白暖色+柔光 | 互动、花瓣、光晕 | 暗黑反差/冷色调言情 |

| 无限流 | 电影质感/暗黑 | 冷暗色+局部光 | 关卡入口、倒计时 | 暖色安全区对比冷色危险 |
| 科幻星际 | 硬科幻/赛博 | 深空蓝紫+金属光 | 星舰、星云、机甲 | 生物质感/废土复古 |

### 爽点 → 视觉焦点 → 钩子类型

| 爽点类型 | 视觉焦点 | 钩子类型 | 构图建议 | 示例 |
|:---------|:---------|:---------|:---------|:-----|
| 逆天改命 | 突破/觉醒瞬间 | 角色统治力 | 低角度仰拍，人物居中 | 角色周身能量爆发，俯视众生 |
| 扮猪吃虎 | 反差对比 | 反差瞬间 | 分层构图，前景弱后景强 | 朴素外表 vs 恐怖力量暗示 |
| 降维打击 | 俯视/碾压感 | 角色统治力 | 高角度俯拍，对手渺小 | 角色居高临下，对手如蝼蚁 |
| 热血战斗 | 对峙/碰撞 | 对峙张力 | 对角线构图，张力拉满 | 两方力量碰撞，能量交错 |
| 甜宠互动 | 双人近距离 | 角色统治力 | 中心对称，温馨光效 | 两人对视，柔和暖光 |
| 悬疑解谜 | 信息碎片 | 标志道具 | 不对称构图，留白悬念 | 局部特写，暗角处理 |
| 权谋布局 | 棋局/俯瞰 | 群像史诗 | 俯拍全局，人物为棋子 | 角色执棋，天下为局 |
| 探索未知 | 前路/门 | 世界奇观 | 纵深构图，引导线向前 | 角色背对镜头，面向未知 |

## 四、构图骨架库

构图骨架是画面的空间结构——元素怎么排列才能在 0.3 秒内传递钩子。

| 构图骨架 | 特征 | 适合钩子 | 视觉效果 | 空间层次 |
|:---------|:-----|:---------|:---------|:---------|
| L型构图 | 文字竖排一侧+主体另一侧 | 标志道具/角色统治力 | 稳定、商业感强 | 左文右图/左图右文 |
| 中心放射 | 核心道具居中，光芒向外辐射 | 标志道具/世界奇观 | 视觉冲击力最强 | 中心爆点→四周衰减 |
| 分层群像 | 多层景深，人物按层级分布 | 群像史诗 | 史诗感、信息量大 | 远景→中景→主体→前景 |
| 对角线对峙 | 双方分列对角，中间碰撞 | 对峙张力 | 动态张力 | 左下vs右上/左上vs右下 |
| 框中框 | 用道具/建筑形成画中画 | 反差瞬间/悬疑 | 窥视感、悬念 | 外框→内框→焦点 |

### 空间层次设计模板

每个构图骨架需要 3-5 层空间层次，每层回答三个问题：放什么？占多大面积？什么光照？

```
远景层：[世界观环境] — 占X成 — 暗处理/雾气虚化
中景层：[叙事元素/次要人物] — 占X成 — 半剪影/背光
主体层：[视觉钩子主体] — 占X成 — 最高细节密度/主光源照射
前景层：[压边元素/道具特写] — 占X成 — 纯剪影/虚化
```

**群像处理技巧**：多人物时用"阵型+光照统一"避免个体崩坏
- 倒三角站位 + 背光剪影 → 统一处理，不画脸
- 菱形分布 + 半身露出 → 只画上半身，避免手脚崩坏
- 层级分布 + 前大后小 → 主次分明，近实远虚

### 字体控制公式

```
[书名] + [字体类型] + [材质/质感] + [色彩层次]
```

- ❌ "行草书法体，深靛蓝色"（太素）
- ✅ "鎏金毛笔书法体，笔画飞白明显，墨色浓淡变化，带金石碑刻龟裂质感"（有材质有层次）

- 材质词：鎏金、银白、朱砂、墨色
- 质感词：飞白、龟裂、碑刻、浓淡变化、金石质感

## 六、配色与光影

### 3 色原则 + 成数描述

- **主色调**（七成左右）：决定整体气质，画面绝对主体
- **辅助色**（两成左右）：丰富层次、承载能量/光效
- **强调色**（半成左右）：制造视觉焦点、文字/纹饰
- **点缀色**（半成左右）：印章朱砂红等文化元素

> **用"成数"不用百分比**：模型理解"玄黑七成"但无法计算"70%"。

色彩情绪速查：
- 深蓝/墨黑 → 神秘、压迫、深沉
- 暖橙/金黄 → 热血、希望、温暖
- 冷灰/苍白 → 荒凉、冷漠、末世
- 赤红/暗红 → 危险、权力、激烈
- 粉白/淡紫 → 温柔、梦幻、少女
- 翠绿/土黄 → 生机、自然、质朴

### 光源设计

**单一主光源原则**：画面只有 1 个主光源，所有光照逻辑由此推导。

| 光源类型 | 适合氛围 | 效果 |
|:---------|:---------|:-----|
| 道具自发光 | 道具钩子 | 道具成为视觉焦点，人物受光 |
| 逆光/轮廓光 | 角色统治力 | 人物轮廓发光，面部可剪影化 |
| 顶光 | 神圣/压迫 | 仪式感、权威感 |
| 环境散射光 | 温馨/日常 | 柔和均匀 |
| 底光 | 诡异/恐怖 | 反自然、不安感 |

## 七、人设图设计原则

### 7.1 角色辨识度三要素

每个角色需要 3 个让读者一眼认出的视觉特征：
1. **轮廓特征**：体型/发型/标志性服饰轮廓
2. **色彩特征**：代表色/配色组合
3. **细节特征**：疤痕/纹身/配饰/标志性物品

示例：
- 深渊主宰主角 → 黑色长袍 + 幽蓝剑光 + 左眼封印纹
- 末世主角 → 军绿色夹克 + 改装弩 + 左臂机械义肢

### 7.2 体态语言

角色姿态传达性格：
- 双手抱胸 → 自信/傲慢
- 手握武器向前 → 战斗意志
- 侧身回眸 → 神秘/从容
- 低头沉思 → 智谋/深沉
- 仰头望远 → 雄心/志向

### 7.3 服饰叙事

服装细节传达世界观信息：
- 材质：丝绸（富贵）/粗布（贫寒）/皮质（战斗）/金属（铠甲）
- 纹样：宗门标识/家族纹章/魔法符文/科技线路
- 破损：战斗痕迹/磨损程度/修补方式
- 配色：身份等级/阵营归属/个性表达

## 八、文化元素设计库

> 文化元素是封面的"逼格放大器"——将网文封面从商品图升级为有文化底蕴的视觉作品。不是所有封面都加，只在该加的时候加，服务于小说气质。

### 8.1 文化元素速查表

| 元素 | 视觉形态 | 适合赛道 | 逼格效果 | 使用位置 |
|:-----|:---------|:---------|:---------|:---------|
| 定场诗 | 竖排古体诗，2-4句，小篆/隶书/行草 | 修仙/玄幻/古言/权谋 | ★★★★★ | 书名旁/画面留白区/边栏 |
| 小篆题字 | 古文字竖排，线条匀称圆润 | 修仙/玄幻/历史/悬疑 | ★★★★☆ | 副标题/装饰文字/镜面铭文 |
| 朱砂印章 | 方形/圆形红印，阴文或阳文 | 全赛道通用 | ★★★★☆ | 书名下方/画面边角/落款处 |
| 古籍版式线 | 鱼尾/版框线/界栏线 | 修仙/古言/历史 | ★★★☆☆ | 画面边框/文字区装饰 |
| 题跋落款 | 小字行书，作者名+创作感言 | 修仙/玄幻/文艺向 | ★★★☆☆ | 画面底部/边角 |
| 阴阳八卦符 | 太极/八卦/河图洛书纹样 | 修仙/玄幻/风水悬疑 | ★★★★☆ | 背景纹理/道具纹饰/边框 |
| 古地图残片 | 泛黄地图碎片，墨线标注 | 历史/探险/权谋 | ★★★☆☆ | 背景层/前景压边 |
| 竹简/帛书 | 竖排文字载体，编绳穿连 | 修仙/历史/玄幻 | ★★★★☆ | 背景纹理/画面边框 |

### 8.2 定场诗设计

**核心原则**：定场诗是封面的"文学签名"，用 2-4 句古体诗浓缩小说核心意境。

**创作公式**：
```
[核心意象A] + [核心意象B] + [因果/转折] + [情感升华]
```

**创作要求**：
1. 2-4 句，每句 5-7 字（五言/七言），总计不超过 28 字
2. 必须包含小说的核心意象（道具/场景/情感），不能是通用诗句
3. 押韵但不强求平仄，重意境不重格律
4. 读者扫一眼能感受到"这本书有文化底子"

**各赛道定场诗示例**：

| 赛道 | 定场诗 | 意象来源 |
|:-----|:-------|:---------|
| 家族修仙（玄鉴仙族） | "鉴中千秋血，镜外万骨枯。六代薪传火，一鉴照仙途。" | 古镜+家族传承+血与仙途 |
| 诡异悬疑（我的诡异人生） | "表盘藏生死，裂痕窥幽冥。死亡非终局，时针转乾坤。" | 手表+死亡循环+模拟器 |
| 暗黑修仙（深渊主宰） | "深渊无底处，诸神亦为尘。一人执剑起，万界颤乾坤。" | 深渊+诸神+主角逆袭 |
| 古言权谋 | "朱墙掩枯骨，金殿藏孤魂。棋落天下动，一笑定乾坤。" | 宫殿+权谋+棋局 |

### 8.3 小篆应用

**核心原则**：小篆用于"需要古老感但不影响可读性"的场景。读者不需要读懂小篆内容，只需要感受到"这字很古"。

**使用场景**：
1. **副标题/装饰文字**：定场诗用小篆书写，增加古韵
2. **道具铭文**：古镜/法宝/玉简上的刻字用小篆，增强道具真实感
3. **边框纹饰**：画面边框用小篆字符作为装饰带
4. **印章文字**：朱砂印章中的文字用小篆（篆刻传统）

**提示词写法**：
- "小篆字体竖排" — 明确字体类型
- "线条匀称圆润，笔画粗细一致" — 小篆的视觉特征
- "古铜色/鎏金/朱砂红" — 配合材质色
- 不需要模型真的写出正确的小篆，只需要"看起来像小篆"的视觉效果

**字体层级搭配**：
| 层级 | 字体 | 用途 | 尺寸 |
|:-----|:-----|:-----|:-----|
| 主标题 | 毛笔书法体（行草/飞白） | 书名 | 最大 |
| 定场诗 | 小篆/隶书 | 诗句 | 中等 |
| 副标题 | 楷体/宋体 | 副标题/作者名 | 小 |
| 印章 | 篆刻体（阴文/阳文） | 印章内容 | 小但醒目（红色） |

### 8.4 印章设计

**核心原则**：印章是封面的"文化落款"，用朱砂红色形成视觉锚点。

| 印章类型 | 形态 | 内容 | 位置 |
|:---------|:-----|:-----|:-----|
| 作者印 | 方形，2-3cm | 作者笔名/字号 | 书名下方左侧 |
| 闲章 | 圆形/椭圆形 | 定场诗中关键词/成语 | 画面留白处 |
| 骑缝印 | 长方形 | 书名缩写 | 画面边缘 |
| 引首章 | 长方形 | 开卷/鉴赏类词 | 定场诗开头处 |

**提示词写法**：
- "朱砂红印章，阴文篆刻" 或 "朱砂红印章，阳文篆刻"
- 给位置锚点："书名下方左侧" / "画面右下角"
- 尺寸控制："约占画面2%面积"

### 8.5 古籍版式元素

**核心原则**：用古籍印刷的版式元素做边框/装饰，增加"典籍感"。

| 元素 | 形态 | 用途 |
|:-----|:-----|:-----|
| 鱼尾 | ♣形装饰符号 | 版框中线两端 |
| 版框线 | 双线/单线矩形框 | 包围文字区 |
| 界栏线 | 竖向分隔线 | 分隔竖排文字列 |
| 书耳 | 版框外侧小框 | 标注卷名/页码 |

**提示词写法**：
- "古籍版式风格边框，双线版框，鱼尾装饰" — 一句话编码多个元素
- 配合小篆定场诗使用效果最佳

### 8.6 文化元素使用原则

1. **不贪多**：一张封面最多用 2-3 种文化元素，过多会杂乱
2. **服务气质**：文化元素必须服务于小说 DNA，不能为了"有文化"而硬加
3. **赛道适配**：修仙/玄幻/古言天然适合，都市/科幻/末世需谨慎（可做变体）
4. **可读性优先**：定场诗不需要读者逐字读懂，但整体视觉感受要"有底蕴"
5. **红点锚定**：印章的朱砂红是画面中重要的红色锚点，配合配色方案统一考虑
6. **融入而非堆叠（关键！）**：文化元素不能独占空间形成"文字区"，必须融入画面层次——定场诗叠在留白处、印章压在画面边角、版式线做边缘装饰不封闭、小篆刻在道具表面

### 8.7 赛道适配建议

| 赛道 | 推荐元素组合 | 不推荐 |
|:-----|:-------------|:-------|
| 修仙/玄幻 | 定场诗(小篆) + 印章 + 古籍版式线 | 竹简（除非有具体设定） |
| 古言权谋 | 定场诗(隶书) + 印章 + 八卦符 | 小篆（太古远，用隶书更合适） |
| 悬疑诡异 | 定场诗(行草) + 印章 + 古地图残片 | 古籍版式线（太正式） |
| 都市异能 | 印章(变体) + 题跋落款 | 定场诗/小篆（违和） |
| 末世生存 | 题跋落款(手写体) | 定场诗/小篆/印章（违和） |
| 言情甜宠 | 印章(小清新变体) + 题跋落款 | 定场诗/小篆（太严肃） |

## 九、设计方案自检清单

**设计推理自检**：
- [ ] 小说 DNA 提取了独特卖点（USP），不是泛泛的"主角很强"
- [ ] 视觉钩子是这本小说独有的，换一本书就不适用
- [ ] 能回答"同赛道 50 张封面里，读者为什么点这张"
- [ ] 构图骨架服务于视觉钩子，不是为了好看而堆砌元素

**技术规范自检**：
- [ ] 主视觉传达了 1 个核心钩子
- [ ] 色彩方案有 3 个层次（主/辅/强调），用"成数"描述
- [ ] 光源设计指定了"唯一主光源"
- [ ] 风格词具体可执行（非"好看的画风"）
- [ ] 封面预留了文字位
- [ ] 字体有材质质感描述
- [ ] 文化元素服务于小说 DNA（非为了有文化而硬加）
- [ ] 文化元素不超过 3 种（不贪多）
- [ ] 定场诗包含小说核心意象（非通用诗句）
- [ ] 人设图有 3 个辨识度特征
- [ ] 设计方案人能看懂（非技术人员也能理解画面会长什么样）
