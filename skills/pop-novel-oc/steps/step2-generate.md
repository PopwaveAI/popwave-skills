# Step 2: 生成资产

> 读取确认方案 → 高精度提示词（4块结构）→ 执行 API → 保存产出 → 系列化循环（如需）

## 设计哲学

Step 2 的核心是**高精度提示词工程**——用4块结构（LOCKED COMPOSITION→ENVIRONMENT AND LIGHTING→EXACT TYPOGRAPHY→HARD CONSTRAINTS）确保角色视觉的一致性和文字渲染的准确性。

对于系列化产出，通过冻结核心特征+变化变量特征，确保同一角色在不同图中保持一致。

## 1. 读取确认方案

读取 `素材/视觉设计方案.md` 中的记录，提取：
- 角色档案路径
- 选定的形态/场景
- 六层信息架构内容
- 布局模板
- 冻结特征列表
- 系列化规划（如需）
- 参考图路径（如有）

## 2. 高精度提示词（4块结构）

读取 `references/seedream-prompt-guide.md` §1.10 获取高精度模板详细说明。

### 2.1 四块结构

```
[LOCKED COMPOSITION]
锁定构图：角色站位、姿态、视角、画面分割比例。这一块定义画面的骨架，后续块不得矛盾。

[ENVIRONMENT AND LIGHTING]
环境与光影：背景场景、光源方向、色温、明暗分配、氛围粒子。

[EXACT TYPOGRAPHY]
精确文字：每一层文字的精确内容、字体类型、字号比例、位置、材质质感。文字用双引号包裹。

[HARD CONSTRAINTS]
硬约束：负面约束（禁止多指、残肢、文字乱码、面部扭曲等）+ 一致性约束（冻结特征清单）。
```

### 2.2 冻结特征嵌入

在 HARD CONSTRAINTS 块中嵌入冻结特征清单：
```
Character consistency locks:
- Eye color: [冻结的眼瞳色]
- Facial structure: [冻结的面部轮廓]
- Core temperament: [冻结的核心气质表达]
以上特征在系列图中必须保持一致。
```

### 2.3 文字层翻译

将六层信息架构翻译为 EXACT TYPOGRAPHY 块：
- 每层文字用双引号包裹
- 明确字体类型（书法体/宋体/篆刻体）
- 明确字号比例（相对画面高度）
- 明确位置（底部面板/右侧竖排/四角分布）
- 明确材质质感（鎏金/银白/朱砂/墨色）

### 2.4 参考图处理（如有）

如果用户提供了参考图或在 Step 1 搜到了 Pinterest 参考图：
- 参考图作为 `image` 参数传入（data URI 格式）
- 在提示词中明确参考范围（画风/色系/构图）
- 冻结特征不受参考图影响

## 3. 确定参数

| 参数 | 默认值 | 说明 |
|:-----|:-------|:-----|
| model | `doubao-seedream-5-0-pro-260628` | Seedream 5.0 Pro |
| size | 按画幅决定（立绘常用1125x1500或1440x2560） | 3:4或9:16 |
| watermark | `false` | 不需要水印 |
| response_format | `b64_json` | 直接返回base64，避免URL下载问题 |
| image | 无 | 参考图 data URI（有参考图时传入） |

## 4. 执行 API 脚本

### 4.1 检查环境

API Key 已内置在 `scripts/generate.py` 中。如需覆盖，可设置 `ARK_API_KEY` 环境变量。

### 4.2 执行生成

```powershell
python scripts/generate.py image --prompt "[高精度提示词]" --model doubao-seedream-5-0-pro-260628 --size 1125x1500 --output "素材/[角色名]OC-v1.png"
```

有参考图时：
```powershell
python scripts/generate.py image --prompt "[高精度提示词]" --model doubao-seedream-5-0-pro-260628 --size 1125x1500 --image "data:image/png;base64,<base64数据>" --output "素材/[角色名]OC-v1.png"
```

### 4.3 输出目录

确保输出目录存在，如不存在则创建。

## 5. 系列化循环

如果 Step 1 规划了系列图，在第一张生成完成后进入循环：

### 5.1 循环流程

对系列规划表中的每一张图：
1. **复制冻结特征**：从上一版提示词的 HARD CONSTRAINTS 块中复制冻结特征
2. **更新变量特征**：按系列规划表更新服饰、场景、姿态、文字层
3. **重新组装提示词**：LOCKED COMPOSITION（新姿态）+ ENVIRONMENT（新场景）+ EXACT TYPOGRAPHY（新文字层）+ HARD CONSTRAINTS（冻结特征不变）
4. **执行生成**：文件名递增（v2, v3...）
5. **一致性检查**：对比上一张图，确认冻结特征一致

### 5.2 一致性检查

每张系列图生成后检查：
- [ ] 眼瞳色一致
- [ ] 面部轮廓一致
- [ ] 核心气质一致
- [ ] 文字渲染正确（无乱码）
- [ ] 角色可辨识（同一人）

> 如果一致性不达标，在提示词的 HARD CONSTRAINTS 块中强化冻结特征描述，重新生成。

## 6. 降级机制

| 问题 | 降级策略 |
|:-----|:---------|
| 文字乱码 | 精简文字内容，每层≤15字；或减少文字层数 |
| 角色不一致 | 强化 HARD CONSTRAINTS 中的冻结特征描述 |
| 面部扭曲 | 添加"五官清晰、面部对称、人体结构正常"约束 |
| 参考图影响过强 | 强化"以下画面内容由描述决定"声明 |
| 整体翻车 | 降级为标准提示词结构，放弃4块高精度模板 |

## 9. 迭代

如果用户对生成结果不满意：

1. 诊断问题维度——是文字渲染问题、角色一致性问题、还是画面整体问题
2. 调整对应提示词块
3. 重新生成（文件名递增 v2, v3...）
4. 更新提示词记录

常见调整方向：

| 用户反馈 | 诊断 | 调整方向 |
|:---------|:-----|:---------|
| 文字乱码 | 文字层过多或过长 | 精简文字，每层≤15字 |
| 角色不像 | 冻结特征描述不够 | 强化 HARD CONSTRAINTS |
| 气质不对 | LOCKED COMPOSITION 姿态描述不准 | 调整姿态和视角描述 |
| 背景太抢 | ENVIRONMENT 块过重 | 简化背景，增加角色占比 |
| 整体偏暗 | 光影描述不够 | 调整 ENVIRONMENT AND LIGHTING 块 |
