# pop-novel-visual

> 网文视觉资产生成器。小说卖点 → 视觉设计方案 → Seedream/Seedance 提示词 → API 生成。v1.5.1

## 这个 Skill 做什么

输入：小说项目文件（世界圣经、角色库、卷纲等）+ 视觉需求（封面/人设图）+ 可选参考图。
输出：生成图片或视频 + 设计方案文档（人可读）+ 提示词记录。

核心价值：将小说的文学卖点翻译为视觉语言，再翻译为模型能理解的提示词，确保生成结果精准传达小说气质。支持参考图生图，可精确控制画风与构图的吸收范围。

**两段翻译**：小说卖点 →（视觉设计翻译）→ 设计方案 →（提示词翻译）→ 模型提示词。设计方案是中间层，人能看懂、能修改；提示词是执行层，模型能理解、能生成。

**参考图生图**：当有参考图时，用"精确分离公式"控制画风与构图的吸收范围——只吸收画风不影响构图，或构图互换。实测验证画风吸收率可达 85%+，构图独立度可达 100%。

## 模型说明

| 模型 | 版本 | 用途 | API 端点 | 默认 |
|:-----|:-----|:-----|:---------|:----:|
| Seedream | 5.0 Pro | 静态图片（封面、人设图） | `POST /api/v3/images/generations` | ✅ |
| Seedream | 5.0 lite | 静态图片（速度优先，可选） | `POST /api/v3/images/generations` | ❌ |
| Seedance | 1.0 Pro | 动态视频封面（可选） | `POST /api/v3/contents/generations/tasks` | ❌ |

默认使用 Seedream 5.0 Pro（`doubao-seedream-5-0-pro-260628`）生成静态图片。A/B 实测 5.0 Pro 在色彩层次、文字渲染、视觉焦点管理上显著优于 5.0 lite 和 4.5，纯文生图质量达到商业优秀级。核心跃升：学会"何时展示何时隐藏"，面部的剪影处理、远景虚化、文字突出体现专业级视觉焦点管理。5.0 lite 速度更快，可用于快速草稿验证。用户明确要求"动态封面/视频封面"时切换 Seedance。

> **关键特性**：Seedream 5.0 Pro/5.0 lite **画面不再泛白**，简洁精确的提示优于堆砌华丽词汇。支持文生图、图生图（增删替换改）、参考图生图、多图输入、组图生成。**支持文字渲染**：将要生成的文字内容用双引号包裹。

## 怎么运作

- **Step 1** 设计方案 → `steps/step1-design.md`
  - **读懂小说** → 提取小说 DNA（USP + 电影海报时刻 + 读者承诺）
  - **设计视觉钩子** → 选择钩子类型（标志道具/角色统治力/反差瞬间/群像史诗/世界奇观/对峙张力），设计独有画面
  - **设计构图叙事** → 选择构图骨架（L型/中心放射/分层群像/对角线对峙/框中框），填充空间层次
  - **设计文化元素** → 选择 2-3 种文化元素（定场诗/小篆/印章/古籍版式等），创作定场诗
  - **全局视觉统筹** → 视觉权重分配（画面六成/书名两成/文化元素一成/留白一成），检查单一焦点、无硬切割、融入式文化元素
  - **竞争差异化检查** → 同赛道对比 + 0.3 秒识别度测试
  - 落盘 `素材/视觉设计方案.md`

- **Step 2** 生成资产 → `steps/step2-generate.md`
  - 读取设计方案 → 用结构化提示词公式翻译为 Seedream 提示词 → 确定参数 → 执行 `scripts/generate.py` → 保存图片到 `素材/视觉/` → 回写提示词记录
  - 有参考图时：用精确分离公式控制画风/构图吸收范围（只吸收画风 / 构图互换）

## 实测验证的控制公式

| 公式 | 用途 | 写法 |
|:-----|:-----|:-----|
| **结构化提示词** | 纯文生图达到商业级质量 | `构图骨架（类型+空间关系）+ 配色比例（色名+成数）+ 光源设计（单一主光源）+ 画面内容（按空间层次）+ 文化元素（定场诗+小篆+印章）+ 风格` |
| 风格控制 | 精确指定画风 | `[风格名称] + [技法描述] + [质感描述] + [参考标杆]` |
| 字体控制 | 精确指定书名质感 | `[书名] + [字体类型] + [材质/质感] + [色彩层次]` |
| 定场诗创作 | 浓缩小说意境为古体诗 | `[核心意象A] + [核心意象B] + [因果/转折] + [情感升华]` |
| 参考图精确分离 | 控制画风/构图吸收 | `仅参考此图的[具体要素]，不参考[具体要素]。以下画面内容由描述决定` |

> **结构化提示词核心发现**（5.0 Pro A/B 实测）：纯文生图质量瓶颈在于缺少"结构信息"。参考图生图效果好是因为参考图提供了构图骨架+配色比例+字体版式。纯文生图用结构化提示词显式编码这三层结构后，可达 A 级商业封面（4.2/5），接近参考图生图质量（4.5/5）。关键：配色用"成数"不用百分比，指定单一主光源，群像用阵型+光照统一处理。

## ❌ 铁律

| # | 铁律 | 违反后果 |
|:-:|:-----|:---------|
| ❌1 | **先理解再生成** — 必须先读取小说项目文件（至少世界圣经 + 角色库），禁止凭空想象画面 | 画面与小说气质脱节 |
| ❌2 | **提示词不超限** — Seedream 中文 ≤300 字，Seedance 中文 ≤500 字 | 生成结果缺失元素 |
| ❌3 | **设计方案必须落盘** — 设计方案和提示词记录写入 `素材/视觉设计方案.md`，便于追溯和迭代 | 无法迭代优化 |
| ❌4 | **API Key 从环境变量读取** — 脚本从 `ARK_API_KEY` 环境变量读取，禁止硬编码 | 安全风险 |

## 前置条件

1. 环境变量 `ARK_API_KEY` 已设置（火山引擎方舟 API Key）
2. 小说项目文件存在（至少 `设定库/世界圣经.md` 和 `设定库/角色库.md`）
3. Python 3.8+ 环境（脚本仅使用标准库，无需额外安装）

## 强弱加载保障

- **强保障**：本 SKILL.md 由 host 层每次 run 强制注入，100% 到达 agent 上下文
- **弱保障**：`steps/` `references/` `templates/` `scripts/` 需 agent 按 SKILL.md 指引主动 readFile
- **设计原则**：核心 SOP 骨架和铁律在 SKILL.md 自包含，step/reference 文件提供详细指导
