# 封面图模式

> 封面不是插画，是**视觉钩子**。唯一目标是让目标读者在 0.3 秒内识别赛道、感知独特性、产生点击欲望。

## 核心原则

- 封面是**营销工具**，书名是主角之一
- 画面服务于"让读者停下来"，不是"展示角色长什么样"
- 书名必须大、必须可读、必须有赛道辨识度

## 设计要素

| 要素 | 要求 | 权重 |
|:-----|:-----|:-----|
| 书名 | 必须可读，有材质质感 | 两成 |
| 画面主视觉 | 视觉钩子主体+场景 | 七成 |
| 文化元素 | 定场诗/印章（可选） | 半成 |
| 留白/暗部 | 承载文字叠加 | 半成 |

## 四层信息架构

```
标题区（上1/4）→ 主视觉（中1/2）→ 赛道符号 → 作者区（下1/4）
```

## 与人物立绘的关键区别

| 区别点 | 封面图 | 人物立绘 |
|:-------|:-------|:---------|
| 目的 | 让读者点进书 | 让读者记住这个角色 |
| 主体 | 画面/钩子 | 角色本人 |
| 文字内容 | 书名+作者+标语 | 角色名+定场诗/人设简介 |
| 文字大小 | 书名最大（标题级） | 角色名中等，定场诗小字 |
| 文字位置 | 标题区独占空间 | 底部面板/侧边条/叠加层（不遮角色） |
| 画幅 | 3:4 | 3:4（半身）或 9:16（全身） |
| 设计驱动 | 视觉钩子（营销优先） | 角色身份（辨识度优先） |

## 提示词结构

```
整体氛围框架 + 画面内容（远→近）+ 书名文字（融入画面）+ 风格
```

- 书名用双引号包裹，有材质质感
- 文字融入画面层次（被前景遮挡/与雾气融合），不形成独立"文字区"
