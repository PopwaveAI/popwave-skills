# 视觉模式区分指南

> 本文件定义三种视觉产出模式的设计逻辑差异。Step 0 提取视觉意图时必须判定模式，Step 1 设计方案时按模式选择不同的设计方法论。

## 三种模式对照表

| 维度 | 封面图 | 人物立绘 | 普通素材 |
|:-----|:-------|:---------|:---------|
| **目的** | 书架展示，0.3秒识别赛道 | 角色展示，让读者记住这个人 | 场景/氛围/参考图 |
| **设计驱动** | 视觉钩子（营销优先） | 角色身份（辨识度优先） | 纯视觉美学 |
| **文字** | 书名+作者+标语（**必须**） | 角色名+定场诗/人设简介（**必须**） | 无要求 |
| **文字角色** | 书名是主角之一（占20%视觉权重） | 文字是角色的"注释"（占15%视觉权重） | 无 |
| **画幅** | 3:4（1125x1500） | 3:4或9:16（1125x1500或844x1500） | 任意 |
| **主体** | 画面/钩子为主体，文字为辅 | 角色为主体（80%+），文字为辅 | 纯视觉 |
| **参考文档** | `novel-visual-design.md` 全文 | 本文件 §二 + `novel-visual-design.md` §七 | 无特殊要求 |

## 一、封面图模式

### 核心原则

封面不是插画，是**视觉钩子**。唯一目标是让目标读者在 0.3 秒内识别赛道、感知独特性、产生点击欲望。

### 设计要素

| 要素 | 要求 | 权重 |
|:-----|:-----|:-----|
| 书名 | 必须可读，有材质质感 | 两成 |
| 画面主视觉 | 视觉钩子主体+场景 | 七成 |
| 文化元素 | 定场诗/印章（可选） | 半成 |
| 留白/暗部 | 承载文字叠加 | 半成 |

### 关键区别

- 书名是**营销工具**，必须大、必须可读、必须有赛道辨识度
- 画面服务于"让读者停下来"，不是"展示角色长什么样"
- 四层信息架构：标题区（上1/4）→ 主视觉（中1/2）→ 赛道符号 → 作者区（下1/4）

### 详细方法论

→ 参见 `novel-visual-design.md` 全文

## 二、人物立绘模式

### 核心原则

人物立绘是**角色名片**，不是封面。角色是绝对主体，文字是角色的"注释"——告诉读者这个人是谁、有什么故事。**纯图不算立绘，纯图只是素材。**

### 与封面的关键区别

| 区别点 | 封面 | 人物立绘 |
|:-------|:-----|:---------|
| 主体 | 画面/钩子 | 角色本人 |
| 文字内容 | 书名+作者+标语 | 角色名+定场诗/人设简介 |
| 文字大小 | 书名最大（标题级） | 角色名中等，定场诗小字 |
| 文字位置 | 标题区独占空间 | 底部面板/侧边条/叠加层（不遮角色） |
| 营销目的 | 让读者点进书 | 让读者记住这个角色 |
| 画幅倾向 | 3:4 | 3:4（半身）或 9:16（全身） |

### 设计要素

| 要素 | 要求 | 权重 |
|:-----|:-----|:-----|
| 角色主视觉 | 角色全身或半身，辨识度三要素齐全 | 八成 |
| 角色名 | 中等大小，有材质质感，不抢角色 | 一成 |
| 定场诗/人设简介 | 小字，2-4句，浓缩角色核心意象 | 半成 |
| 装饰元素 | 印章/纹饰/边框（可选） | 半成 |

### 文字设计

#### 角色名

- **位置**：底部面板中央 / 侧边竖排 / 画面留白处
- **字体**：与角色气质匹配（修仙=书法体，都市=现代体，诡异=残破体）
- **大小**：中等，不超过画面10%面积
- **质感**：有材质描述（鎏金/银白/朱砂等）

#### 定场诗/人设简介

两种形式，按角色气质选择：

**形式A：定场诗（古风/修仙/玄幻/权谋赛道）**

创作公式：`[角色核心意象A] + [角色核心意象B] + [命运转折] + [角色宿命]`

要求：
1. 2-4句，每句5-7字，总计不超过28字
2. 必须包含角色的核心意象（能力/身世/命运），不能通用
3. 与封面定场诗的区别：封面诗讲"书"，立绘诗讲"人"

示例（苏午·我的诡异人生）：
> 表盘藏生死，鬼手探幽冥。
> 凡躯承诡道，一念定乾坤。

**形式B：人设简介（都市/科幻/末世/悬疑赛道）**

格式：`[角色名] · [核心身份] — [一句话人设]`

示例：
> 苏午 · 诡异模拟器持有者 — 以凡人之躯驾驭死亡循环，每一次死亡都是下一次蜕变的起点。

### 布局模板

#### 模板1：底部面板型（推荐）

```
┌─────────────────────┐
│                     │
│                     │
│      角色主视觉      │  ← 80% 面积
│                     │
│                     │
├─────────────────────┤
│  角色名 · 定场诗     │  ← 20% 面积，半透明底色面板
└─────────────────────┘
```

#### 模板2：侧边条型

```
┌──────────┬──────────┐
│          │ 角色名   │
│          │ ─────── │
│  角色主视觉 │ 定场诗   │  ← 文字竖排，占15%宽度
│          │ 印章     │
│          │          │
└──────────┴──────────┘
```

#### 模板3：叠加层型（沉浸式）

```
┌─────────────────────┐
│                     │
│                     │
│      角色主视觉      │  ← 90% 面积
│                     │
│        角色名        │  ← 叠加在角色下方留白处
│      定场诗小字      │  ← 极小，融入暗部
└─────────────────────┘
```

### 角色辨识度三要素（沿用）

每个角色需要 3 个让读者一眼认出的视觉特征：
1. **轮廓特征**：体型/发型/标志性服饰轮廓
2. **色彩特征**：代表色/配色组合
3. **细节特征**：疤痕/纹身/配饰/异变部位

> 详细参考 `novel-visual-design.md` §七

## 三、普通素材模式

### 核心原则

纯视觉，无文字要求。用于场景概念图、氛围图、参考图等。

### 设计要素

| 要素 | 要求 |
|:-----|:-----|
| 画面 | 纯视觉，服务于场景/氛围 |
| 文字 | 无要求 |
| 画幅 | 任意，按用途决定 |

### 典型用途

- 场景概念图：城市/战场/秘境
- 氛围图：情绪/季节/光影参考
- 道具特写：法宝/武器/信物
- 参考图：画风/构图/配色锚定

## 四、模式判定流程

Step 0 提取视觉意图时，按以下流程判定模式：

```
用户需求
  ├─ 提到"封面/上架/书架" → 封面图模式
  ├─ 提到"人设/立绘/角色图/角色卡" → 人物立绘模式
  ├─ 提到"场景/氛围/概念图/参考图" → 普通素材模式
  └─ 未明确 → 询问用户
```

判定后，在门禁A呈现时**明确标注视觉模式**，让用户确认。

## 五、提示词差异

不同模式的提示词结构有差异：

### 封面图提示词结构

```
整体氛围框架 + 画面内容（远景→前景） + 书名文字（融入画面） + 风格
```

### 人物立绘提示词结构

```
角色描述（外貌+服饰+特征+姿态+表情） + 背景氛围 + 角色名（中等大小，指定位置） + 定场诗/简介（小字，指定位置） + 风格
```

### 普通素材提示词结构

```
整体氛围框架 + 画面内容 + 风格
```
