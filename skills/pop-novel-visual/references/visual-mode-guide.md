# 视觉模式区分指南

> 本文件定义三种视觉产出模式的设计逻辑差异。Step 0 提取视觉意图时必须判定模式，Step 1 设计方案时按模式选择不同的设计方法论。

## 三种模式对照表

| 维度 | 封面图 | 人物立绘 | 普通素材 |
|:-----|:-------|:---------|:---------|
| **目的** | 书架展示，0.3秒识别赛道 | 角色展示，让读者记住这个人 | 场景/氛围/参考图 |
| **设计驱动** | 视觉钩子（营销优先） | 角色身份（辨识度优先） | 纯视觉美学 |
| **文字** | 书名+作者+标语（**必须**） | 角色名+定场诗/人设简介（**必须**） | 无要求 |
| **文字角色** | 书名是主角之一（占20%视觉权重） | 文字是角色的"注释"（占15%视觉权重） | 无 |
| **画幅** | 3:4（1125x1500） | 3:4或9:16（1125x1500或844x1500） | 任意 |
| **主体** | 画面/钩子为主体，文字为辅 | 角色为主体（80%+），文字为辅 | 纯视觉 |
| **参考文档** | `novel-visual-design.md` 全文 | 本文件 §二 + `novel-visual-design.md` §七 | 无特殊要求 |

## 一、封面图模式

### 核心原则

封面不是插画，是**视觉钩子**。唯一目标是让目标读者在 0.3 秒内识别赛道、感知独特性、产生点击欲望。

### 设计要素

| 要素 | 要求 | 权重 |
|:-----|:-----|:-----|
| 书名 | 必须可读，有材质质感 | 两成 |
| 画面主视觉 | 视觉钩子主体+场景 | 七成 |
| 文化元素 | 定场诗/印章（可选） | 半成 |
| 留白/暗部 | 承载文字叠加 | 半成 |

### 关键区别

- 书名是**营销工具**，必须大、必须可读、必须有赛道辨识度
- 画面服务于"让读者停下来"，不是"展示角色长什么样"
- 四层信息架构：标题区（上1/4）→ 主视觉（中1/2）→ 赛道符号 → 作者区（下1/4）

### 详细方法论

→ 参见 `novel-visual-design.md` 全文

## 二、人物立绘模式

### 核心原则

人物立绘是**角色名片**，不是封面。角色是绝对主体，文字是角色的"注释"——告诉读者这个人是谁、有什么故事。**纯图不算立绘，纯图只是素材。**

### 基础版与加强版（OC）

人物立绘支持两档文字密度，按需求选择：

| 档位 | 文字内容 | 适用场景 |
|:-----|:---------|:---------|
| **基础版** | 角色名 + 定场诗/人设简介 | 角色展示、人物库配图 |
| **加强版（OC）** | 角色名 + 称号 + 背景故事（2-3句）+ 诗句/判词 + 系列名 + 印章 | 角色设定卡、系列角色展示、世界观名片 |

> 加强版就是原"OC图"——本质是立绘的文字增强版，不是独立模式。文字内容agent可自动生成（角色背景从项目文件提取，定场诗/判词按公式创作），不需要用户手写。Seedream 5.0 Pro可处理4-6个短文本区块，每个≤15字时渲染稳定；背景故事超30字时建议精简为2-3个短句。

#### 加强版布局参考

加强版文字区块多，推荐"四角分布"布局：

```
┌─────────────────────┐
│ 系列名    角色名·称号  │  ← 上方两角
│                     │
│      角色主视觉       │  ← 70% 面积
│                     │
│ 诗句/判词  背景简介   │  ← 下方两角小字
│     印章             │
└─────────────────────┘
```

### 与封面的关键区别

| 区别点 | 封面 | 人物立绘 |
|:-------|:-----|:---------|
| 主体 | 画面/钩子 | 角色本人 |
| 文字内容 | 书名+作者+标语 | 角色名+定场诗/人设简介 |
| 文字大小 | 书名最大（标题级） | 角色名中等，定场诗小字 |
| 文字位置 | 标题区独占空间 | 底部面板/侧边条/叠加层（不遮角色） |
| 营销目的 | 让读者点进书 | 让读者记住这个角色 |
| 画幅倾向 | 3:4 | 3:4（半身）或 9:16（全身） |

### 设计要素

| 要素 | 要求 | 权重 |
|:-----|:-----|:-----|
| 角色主视觉 | 角色全身或半身，辨识度三要素齐全 | 八成 |
| 角色名 | 中等大小，有材质质感，不抢角色 | 一成 |
| 定场诗/人设简介 | 小字，2-4句，浓缩角色核心意象 | 半成 |
| 装饰元素 | 印章/纹饰/边框（可选） | 半成 |

### 文字设计

#### 角色名

- **位置**：底部面板中央 / 侧边竖排 / 画面留白处
- **字体**：与角色气质匹配（修仙=书法体，都市=现代体，诡异=残破体）
- **大小**：中等，不超过画面10%面积
- **质感**：有材质描述（鎏金/银白/朱砂等）

#### 定场诗/人设简介

两种形式，按角色气质选择：

**形式A：定场诗（古风/修仙/玄幻/权谋赛道）**

创作公式：`[角色核心意象A] + [角色核心意象B] + [命运转折] + [角色宿命]`

要求：
1. 2-4句，每句5-7字，总计不超过28字
2. 必须包含角色的核心意象（能力/身世/命运），不能通用
3. 与封面定场诗的区别：封面诗讲"书"，立绘诗讲"人"

示例（苏午·我的诡异人生）：
> 表盘藏生死，鬼手探幽冥。
> 凡躯承诡道，一念定乾坤。

**形式B：人设简介（都市/科幻/末世/悬疑赛道）**

格式：`[角色名] · [核心身份] — [一句话人设]`

示例：
> 苏午 · 诡异模拟器持有者 — 以凡人之躯驾驭死亡循环，每一次死亡都是下一次蜕变的起点。

### 布局模板

#### 模板1：底部面板型（推荐）

```
┌─────────────────────┐
│                     │
│                     │
│      角色主视觉      │  ← 80% 面积
│                     │
│                     │
├─────────────────────┤
│  角色名 · 定场诗     │  ← 20% 面积，半透明底色面板
└─────────────────────┘
```

#### 模板2：侧边条型

```
┌──────────┬──────────┐
│          │ 角色名   │
│          │ ─────── │
│  角色主视觉 │ 定场诗   │  ← 文字竖排，占15%宽度
│          │ 印章     │
│          │          │
└──────────┴──────────┘
```

#### 模板3：叠加层型（沉浸式）

```
┌─────────────────────┐
│                     │
│                     │
│      角色主视觉      │  ← 90% 面积
│                     │
│        角色名        │  ← 叠加在角色下方留白处
│      定场诗小字      │  ← 极小，融入暗部
└─────────────────────┘
```

### 角色辨识度三要素（沿用）

每个角色需要 3 个让读者一眼认出的视觉特征：
1. **轮廓特征**：体型/发型/标志性服饰轮廓
2. **色彩特征**：代表色/配色组合
3. **细节特征**：疤痕/纹身/配饰/异变部位

> 详细参考 `novel-visual-design.md` §七

## 三、普通素材模式

### 核心原则

纯视觉，无文字要求。用于场景概念图、氛围图、参考图等。

### 设计要素

| 要素 | 要求 |
|:-----|:-----|
| 画面 | 纯视觉，服务于场景/氛围 |
| 文字 | 无要求 |
| 画幅 | 任意，按用途决定 |

### 典型用途

- 场景概念图：城市/战场/秘境
- 氛围图：情绪/季节/光影参考
- 道具特写：法宝/武器/信物
- 参考图：画风/构图/配色锚定

## 四、场景图模式

### 核心原则

场景图从**小说原文**出发，不是从"用户想要什么感觉"出发。核心是**理解**——把文学叙事翻译成视觉叙事，再生成画面。

与封面/立绘/素材的根本区别：**起点不同**。

| 模式 | 起点 | 核心能力 |
|:-----|:-----|:---------|
| 封面图 | 用户意图（书名+赛道+感觉） | 视觉钩子设计 |
| 人物立绘 | 用户意图（角色+气质） | 角色名片设计 |
| 普通素材 | 用户意图（场景描述） | 纯视觉生成 |
| **场景图** | **小说原文** | **原文理解→视觉转化** |

场景图必须走独立的理解管线（`steps/step0-scene-understand.md`），不能直接把原文丢进提示词。

### 理解管线五层

1. **原文解构**：拆动作序列→角色规格→环境元素→材质细节→安全转换
2. **上下文补全**：角色身份/前因后果/读者印象/文字体验/小说基调（分级策略：热门IP自动搜索→冷门IP搜索+用户补充→原创小说从项目文件读取）
3. **叙事瞬间选取**：从连续动作中选最该画的那一帧（情感峰值+叙事关键+读者共鸣+视觉张力）
4. **🚪门禁A**：理解确认（不是选图，是确认理解正确）
5. **[可选]风格参考搜索**：Pinterest搜画风参考（画面内容由理解层决定，不由参考图决定）

### 设计要素

| 要素 | 要求 |
|:-----|:-----|
| 画面 | 基于理解层产出（选定瞬间+视觉元素+情感基调） |
| 文字 | 无强制要求（场景图通常无文字，除非用户要求加标题） |
| 画幅 | 按场景决定，常用3:4或16:9 |
| 理解层 | **必须经过五层理解管线才能进入设计** |

### 与其他模式的关键区别

| 区别点 | 封面/立绘/素材 | 场景图 |
|:-------|:-------------|:-------|
| 输入 | 用户意图描述 | 小说原文 |
| Step 0 | Pinterest搜图+选图+对齐参考点 | 原文解构+上下文补全+瞬间选取 |
| 门禁A | 选图+对齐参考点 | 理解确认 |
| 设计驱动 | 参考图+参考点 | 理解层产出 |
| 画面内容来源 | 参考图+提示词 | 理解层转化 |

## 五、模式判定流程

Step 0 提取视觉意图时，按以下流程判定模式：

```
用户需求
  ├─ 提到"封面/上架/书架" → 封面图模式
  ├─ 提到"人设/立绘/角色图/角色卡" → 人物立绘模式
  ├─ 提到"场景/氛围/概念图/参考图" → 普通素材模式
  ├─ 提供小说原文 / 说"场景图/场景画面/原文场景" → 场景图模式（走 step0-scene-understand.md）
  └─ 未明确 → 询问用户
```

> **场景图模式判定关键**：用户直接贴了一段小说原文，或者说"把这段文字画出来"、"这段场景生成图"——这就是场景图模式。场景图走独立的理解管线，不走Pinterest搜图流程。

判定后，在门禁A呈现时**明确标注视觉模式**，让用户确认。

## 六、提示词差异

不同模式的提示词结构有差异：

### 封面图提示词结构

```
整体氛围框架 + 画面内容（远景→前景） + 书名文字（融入画面） + 风格
```

### 人物立绘提示词结构

```
角色描述（外貌+服饰+特征+姿态+表情） + 背景氛围 + 角色名（中等大小，指定位置） + 定场诗/简介（小字，指定位置） + 风格
```

### 普通素材提示词结构

```
整体氛围框架 + 画面内容 + 风格
```

### 场景图提示词结构

```
整体氛围框架（基于情感基调）+ 画面内容（选定瞬间的角色+环境+材质，按空间层次）+ 风格
```

> 场景图提示词的**画面内容来源不是用户描述**，是理解层产出（选定瞬间+视觉元素清单+安全转换后的描述）。提示词必须忠实于理解层，不能自行添加理解层没有的元素。
