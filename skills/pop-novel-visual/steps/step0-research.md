# Step 0: 读懂小说 + 关键词理解 + 联网找参考

> 读取小说项目 → 提取小说DNA → **关键词理解** → 联网搜索参考（分路径）→ 理解用户参考图（如有）→ 🚪门禁A：方向对齐

## 设计哲学

封面设计最大的浪费不是生成次数，而是**方向跑偏后一路狂奔**。方向跑偏的根因往往不是搜索不够，而是**对用户意图的理解偏差**——用户说"邪典"，agent 理解成"肉体恐怖"，用户心里想的是"帅的邪典"。

Step 0 的职责：在动手设计前，先用"关键词理解确认"消除意图偏差，再和用户对齐"这本书的封面/人设图应该往什么方向走"。

## 0. 判断视觉类型

从用户需求中判断视觉类型，决定后续搜索路径：

| 用户表达 | 视觉类型 | 搜索路径 |
|:---------|:---------|:---------|
| "封面""书封""封面图" | 封面 | 封面路径（§3.1） |
| "人设图""角色图""立绘""人物设计" | 人设图 | 人设图路径（§3.2） |
| 未明确 | 默认封面，门禁A确认 | 封面路径 |

## 1. 读取小说项目文件

按优先级读取以下文件（存在则读，不存在则跳过并记录）：

| 优先级 | 文件路径 | 用途 |
|:------:|:---------|:-----|
| P0 | `设计/全书设定/（10个文件）` | 世界观、力量体系、物理规则、势力格局 |
| P0 | `设定库/角色库.md` | 主角及核心角色外貌、性格、服饰 |
| P1 | `设定库/卷纲.md` | 当前卷的剧情走向、核心冲突 |
| P1 | `current-state.md` | 项目当前状态、最新章节信息 |
| P2 | `素材/文风锚定.md` | 文风 DNA（影响视觉气质） |

**门禁**：P0 文件至少存在 1 个，否则报错中止：「未找到小说项目文件，请确认当前目录为小说项目根目录」。

## 2. 提取小说 DNA

不是提取元数据，是**找到这本小说的 DNA**——它和同赛道其他书的区别是什么。

### 2.1 基础信息提取

从项目文件中提取（从文件内容中找答案，不凭空想象）：

1. **赛道** — 修仙/都市/末世/悬疑/游戏入侵/种田/言情…
2. **核心爽点** — 逆天改命/扮猪吃虎/降维打击/甜宠/权谋…
3. **主角关键特征** — 外貌、气质、标志性服饰/武器/能力
4. **世界视觉关键词** — 废土/仙山/都市夜景/地下城/星际…
5. **情绪基调** — 热血/黑暗/温馨/悬疑/史诗…

### 2.2 小说 DNA 提取（差异化分析）

回答以下问题，找到**这本小说和同赛道其他书的区别**：

1. **独特卖点（USP）**：同赛道有 1000 本书，读者为什么选这本？
   - ❌ "主角很强"（同赛道都说自己主角强）
   - ✅ "主角能通过古镜看到他人修仙记忆，以敌为师"（具体、独特、可视觉化）

2. **电影海报时刻**：如果这本小说拍电影，海报上是哪个画面？
   - ❌ "主角站在山顶修炼"（所有修仙文都有）
   - ✅ "主角手握破碎古镜，镜中倒映出敌人的功法秘籍"（独特、有故事感）

3. **读者承诺**：封面要对读者承诺什么体验？
   - 逆天改命型 → 承诺"你会看到弱者逆袭的爽感"
   - 家族群像型 → 承诺"你会看到一个家族的兴衰史诗"

### 2.3 气质定调

将基础信息 + DNA 提取综合为 3-5 个视觉关键词，作为设计方向的气质锚点。

示例：
- 玄鉴仙族 → 「家族宿命、镜照因果、暗黑史诗、血与铜锈」
- 深渊主宰 → 「暗黑、仪式感、阶级压迫、神明俯视」

## 3. 关键词理解（意图对齐核心环节）

> **这是 v2.1.0 新增的核心环节。** 用户的描述中常含抽象词（邪典/暗黑/帅气/恐怖/诡异/治愈/热血），这些词在不同人脑中映射的视觉特征差异极大。必须先翻译为具体视觉特征并让用户确认，才能防止意图偏差。
>
> **v2.1.1 增强**：关键词理解现在同时使用 **WebSearch（文字定义）+ Pinterest（视觉示例）**。Pinterest 是视觉搜索引擎，搜"邪典美学"返回的是真实图片而非文字描述——让用户指着图说"就是这个方向"，比任何文字翻译都精准。

### 3.1 提取抽象关键词

从用户的需求描述中，提取所有**需要翻译的抽象词**：

| 抽象词类型 | 示例 | 为什么需要翻译 |
|:-----------|:-----|:-------------|
| 氛围词 | 邪典、暗黑、恐怖、诡异、治愈、热血 | "邪典"可以是优雅堕落也可以是肉体恐怖 |
| 风格词 | 日系、国风、赛博朋克、二次元 | "国风"可以是水墨写意也可以是工笔重彩 |
| 气质词 | 帅气、威严、可爱、冷酷、妖异 | "帅气"的邪典和"帅气"的修仙完全不同 |
| IP指向词 | 黑神话风格、宫崎骏风格、新海诚风格 | 需要搜索该IP的美术特征 |

### 3.2 双轨搜索：文字定义 + 视觉示例

对每个抽象词执行**双轨搜索**——WebSearch 搜文字定义，Pinterest 搜视觉示例。

#### 轨道一：WebSearch（文字定义）

| 搜索目的 | 关键词模板 | 示例 |
|:---------|:---------|:-----|
| 抽象词的视觉化定义 | `[抽象词] 视觉设计 特征` | `邪典美学 视觉设计 特征` |
| 抽象词的子类型 | `[抽象词] 风格 类型 分类` | `暗黑风格 类型 分类` |
| IP指向词的美术特征 | `[IP名] 美术风格 设计特征` | `黑神话悟空 美术风格 角色设计` |

#### 轨道二：Pinterest 视觉搜索（核心环节）

> **v2.1.2 策略升级**：从"单关键词搜5张"改为"3维度×多表达并行搜6张"。旧方案把一个抽象词翻成一个英文表达直接搜5张——如果翻译偏了，5张全废。新方案从3个维度同时搜，每个维度用2-3个英文表达各搜2张，覆盖面和命中率显著提升，总额度不变。

##### 第一步：拆分搜索维度

从用户描述中拆出 2-3 个搜索维度，每个维度代表一个视觉方向：

| 维度 | 来源 | 适用场景 | 示例（"黑神话金蝉子邪典"） |
|:-----|:-----|:---------|:------------------------|
| **IP维度** | 用户提到的IP名 | 有IP指向时必搜 | `black myth wukong character art` |
| **角色维度** | 角色身份/职业/特征 | 人设图必搜；封面有角色时搜 | `dark monk character design` |
| **风格维度** | 抽象氛围词 | 必搜（核心维度） | `elegant dark fantasy art` |

> 无IP指向时，用"角色维度+风格维度"两维；有IP指向时三维全开。总量控制在6张以内。

##### 第二步：同一维度的多表达并行

每个维度内，把一个中文概念翻译为 **2-3 个不同的英文表达**，每种表达搜 1-2 张。不同表达在 Pinterest 上返回不同子方向：

**风格维度多表达示例**（"邪典" → 3种英文表达）：

| 中文意图 | 英文表达 | Pinterest 返回的子方向 |
|:---------|:---------|:---------------------|
| 帅的邪典 | `elegant dark fantasy art` | 精致暗黑、优雅堕落 |
| 帅的邪典 | `dark elegance character art` | 威严暗黑、华丽危险 |
| 恐怖向邪典 | `dark cult aesthetic art` | 肉体恐怖、仪式诡异 |

> **为什么要多表达**：Pinterest 是视觉搜索引擎，同一个中文概念在不同英文表达下返回的图片差异极大。一轮搜3个表达，等于一次覆盖了概念的多个子方向，用户直接从结果里选最接近的——不用等agent"翻译"对不对。

**角色维度多表达示例**（"金蝉子" → 2种英文表达）：

| 英文表达 | 覆盖方向 |
|:---------|:---------|
| `dark monk character design` | 暗黑僧人角色设计 |
| `golden cicada mythical character` | 神话生物/妖异角色 |

##### 第三步：执行搜索

每个英文表达搜 1-2 张，总量控制在 6 张以内：

```powershell
# 维度1：风格维度（3个表达各搜2张）
python "scripts/pinterest_search.py" "elegant dark fantasy art" --max-results 2 --download --limit 2
python "scripts/pinterest_search.py" "dark elegance character art" --max-results 2 --download --limit 2
python "scripts/pinterest_search.py" "dark cult aesthetic art" --max-results 2 --download --limit 2

# 维度2：IP维度（1个表达搜2张）
python "scripts/pinterest_search.py" "black myth wukong character art" --max-results 2 --download --limit 2

# 维度3：角色维度（1个表达搜2张）
python "scripts/pinterest_search.py" "dark monk character design" --max-results 2 --download --limit 2
```

> **额度控制**：每个表达 `--max-results 2`，总量 = 维度数 × 2 ≈ 6张。与旧方案5张持平，但覆盖面从1个方向扩展到3个方向。

> **为什么用英文搜**：Pinterest 用户群以英文为主，英文搜索结果更丰富、质量更高。

##### 第四步：图片分析

对下载的每张 Pinterest 图用 Read 工具查看，提取画风/构图/配色特征，并标注**所属维度和子方向**。这些图片将在门禁A中直接展示给用户。

### 3.3 翻译为具体视觉特征

将双轨搜索结果综合，把每个抽象词翻译为 2-4 个**具体视觉特征** + Pinterest 视觉示例（按维度分组）：

```
关键词理解报告：

"邪典" →
  WebSearch 文字定义：
  搜索发现邪典有多个子方向：
  - 优雅堕落型：神圣符号的腐败化、华贵与阴暗并存、威严感不减
  - 肉体恐怖型：皮肤异变、器官外露、生物畸形
  - 仪式诡异型：诡异仪式感、非自然光影、心理不安

  Pinterest 视觉示例（按维度分组）：
  【风格维度】
  - pin_001.jpg（elegant dark fantasy art）：暗黑奇幻半身肖像，精致暗金色纹路，优雅堕落型
  - pin_002.jpg（dark elegance character art）：威严角色立绘，华丽暗色铠甲，华丽危险型
  - pin_003.jpg（dark cult aesthetic art）：仪式场景，非自然光影，仪式诡异型
  【IP维度】
  - pin_004.jpg（black myth wukong character art）：黑神话风格角色，写实暗黑国风
  【角色维度】
  - pin_005.jpg（dark monk character design）：暗黑僧人角色，破损法衣+锡杖
  - pin_006.jpg（golden cicada mythical character）：蝉翼生物，妖异金色

  → 我倾向于：[选择一个方向，说明理由]

"暗黑" →
  → 我理解为：[具体描述]
```

### 3.4 关键词理解结果用途

这份理解报告用于：
1. **门禁A呈现**：在建议方向之前，先呈现关键词理解（文字定义+Pinterest视觉示例）让用户确认
2. **设计方案指导**：确认后的关键词理解作为 Step 1 设计推理的输入
3. **提示词翻译**：确认后的视觉特征直接写入提示词
4. **参考图候选**：用户确认方向的 Pinterest 图可直接作为 Seedream 图生图的参考图

## 4. 联网搜索参考（按视觉类型分路径）

### 4.1 封面路径

搜索三个维度，每个维度 1-2 组搜索：

| 搜索维度 | 关键词模板 | 示例 | 价值 |
|:---------|:---------|:-----|:-----|
| **同赛道封面** | `[赛道] 小说封面 设计` | `修仙小说封面设计` | 锚定赛道视觉惯例 |
| **IP美术风格**（如有IP指向） | `[IP名] 美术风格 设计` | `黑神话悟空 美术风格` | 防止IP特征跑偏 |
| **抽象关键词视觉化** | `[抽象词] 封面设计 视觉` | `邪典 封面设计 视觉` | 发现关键词的多种视觉方向 |

### 4.2 人设图路径

搜索三个维度，每个维度 1-2 组搜索：

| 搜索维度 | 关键词模板 | 示例 | 价值 |
|:---------|:---------|:-----|:-----|
| **角色现有形象** | `[角色名] 形象 设定 外观` | `金蝉子 形象 设定 外观` | 锚定角色辨识度 |
| **IP美术风格**（如有IP指向） | `[IP名] 角色设计 美术` | `黑神话 角色设计 美术` | 锚定IP美术特征 |
| **抽象关键词视觉化** | `[抽象词] 角色设计 立绘` | `邪典 角色设计 立绘` | 发现关键词的多种视觉方向 |

### 4.3 搜索结果整理

从搜索结果中筛选 3-5 张有代表性的参考图，为每张标注：

```
参考图1：[来源/名称]
  - 风格：[厚涂/工笔/水墨/电影概念/暗黑写实]
  - 构图：[L型/中心放射/分层群像/对角线/框中框]
  - 配色：[主色调]+[辅助色]+[强调色]
  - 视觉焦点：[人物/道具/场景]
  - 特点：[一句话评价]
```

### 4.4 搜索结果分析总结

回答以下问题，形成视觉认知：

1. **搜索结果中有什么共同特征？**（色调/构图/风格/视觉焦点）
2. **搜索结果中有什么差异？**（不同子方向、不同处理手法）
3. **本书/本角色可以在哪些维度差异化？**（反色调？独特道具？构图差异？）

> 查 `references/novel-visual-design.md` §三「赛道视觉速查」获取赛道常见风格和差异化机会。

## 5. 理解用户参考图（如有）

如果用户提供了参考图（在任何阶段提供都处理），执行参考图理解。

### 5.1 参考图类型判断

判断用户提供的参考图属于哪种类型：

| 参考图类型 | 特征 | 用户意图 |
|:---|:---|:---|
| 风格参考 | 用户说"喜欢这个画风""这种质感" | 想要接近这个画风 |
| 构图参考 | 用户说"这个布局好""这种排版" | 想要类似构图 |
| 综合参考 | 用户说"整体感觉像这样" | 风格+构图都要接近 |
| 角色参考 | 用户说"人物画这样" | 角色精度参考 |

### 5.2 参考图特征提取

用 Read 工具查看参考图，提取以下特征形成文字描述：

```
参考图理解报告：
  - 画风：[笔触技法、色彩系统、明暗方式]
    示例："泼墨晕染与块面塑造结合，灰白与墨黑低饱和度单色调，金色作为唯一暖色点缀"
  - 构图：[人物数量、位置关系、空间层次]
    示例："单人居中构图，人物占画面主体，上方留白"
  - 配色：[主色调]+[辅助色]+[强调色]+[比例]
    示例："墨黑七成为底，灰白两成，金色半成点缀"
  - 可吸收要素：[具体列出]
  - 不吸收要素：[具体列出]
  - 生成路线建议：[图生图/文生图] + [理由]
```

### 5.3 参考图理解结果用途

这份理解报告用于两个目的：
1. **门禁A对齐**：用人话告诉用户"我从这张图里提取了什么，打算怎么用"
2. **降级fallback**：如果后续图生图翻车，这份文字描述直接作为文生图提示词基础

### 6.2 等待用户确认

**禁止自主进入 Step 1。** 必须等用户明确回复后才能继续。

用户可能的回复类型：

| 用户回复 | 处理方式 |
|:---------|:---------|
| "可以/没问题/继续" | 关键词理解+方向均确认，进入 Step 1 |
| "邪典不是这个意思，是XXX" | **修正关键词理解**，重新搜索视觉化表现，更新呈现后重新等待确认 |
| "第二张图就是这个感觉" | **以用户选中的 Pinterest 图为锚点**，将该图的画风/构图特征提取为关键词理解的最终确认方向，可直接作为 Step 2 图生图参考图 |
| "改成X方向" | 根据用户反馈调整方向，重新呈现 |
| "这是我的参考图[图]" | 执行 §5 参考图理解，更新呈现后重新等待确认 |
| "搜索一下X风格的" | 补充搜索，更新呈现后重新等待确认 |
| "同赛道的不对，我的书是X赛道" | 修正赛道，重新搜索+呈现 |

> **关键**：如果用户纠正了关键词理解，必须重新搜索该关键词的视觉化表现（WebSearch + Pinterest），更新理解报告后再呈现。不能只改文字不重新搜索——用户的纠正可能指向一个完全不同的视觉方向。
>
> **Pinterest 图的后续利用**：用户确认方向的 Pinterest 图，在 Step 2 生成时可直接作为 Seedream 图生图的参考图（图生图路线），实现"用户选的图→生成参考"的闭环。
