# Step 0: 读懂小说 + 联网找参考

> 读取小说项目 → 提取小说DNA → 联网搜索同赛道封面 → 理解用户参考图（如有）→ 🚪门禁A：方向对齐

## 设计哲学

封面设计最大的浪费不是生成次数，而是**方向跑偏后一路狂奔**。Step 0 的职责：在动手设计前，先和用户对齐"这本书的封面应该往什么方向走"。用同赛道封面参照物 + 小说DNA摘要，让用户在30秒内确认方向。

## 1. 读取小说项目文件

按优先级读取以下文件（存在则读，不存在则跳过并记录）：

| 优先级 | 文件路径 | 用途 |
|:------:|:---------|:-----|
| P0 | `设定库/世界圣经.md` | 世界观、力量体系、物理规则、势力格局 |
| P0 | `设定库/角色库.md` | 主角及核心角色外貌、性格、服饰 |
| P1 | `设定库/卷纲.md` | 当前卷的剧情走向、核心冲突 |
| P1 | `current-state.md` | 项目当前状态、最新章节信息 |
| P2 | `素材/文风锚定.md` | 文风 DNA（影响视觉气质） |

**门禁**：P0 文件至少存在 1 个，否则报错中止：「未找到小说项目文件，请确认当前目录为小说项目根目录」。

## 2. 提取小说 DNA

不是提取元数据，是**找到这本小说的 DNA**——它和同赛道其他书的区别是什么。

### 2.1 基础信息提取

从项目文件中提取（从文件内容中找答案，不凭空想象）：

1. **赛道** — 修仙/都市/末世/悬疑/游戏入侵/种田/言情…
2. **核心爽点** — 逆天改命/扮猪吃虎/降维打击/甜宠/权谋…
3. **主角关键特征** — 外貌、气质、标志性服饰/武器/能力
4. **世界视觉关键词** — 废土/仙山/都市夜景/地下城/星际…
5. **情绪基调** — 热血/黑暗/温馨/悬疑/史诗…

### 2.2 小说 DNA 提取（差异化分析）

回答以下问题，找到**这本小说和同赛道其他书的区别**：

1. **独特卖点（USP）**：同赛道有 1000 本书，读者为什么选这本？
   - ❌ "主角很强"（同赛道都说自己主角强）
   - ✅ "主角能通过古镜看到他人修仙记忆，以敌为师"（具体、独特、可视觉化）

2. **电影海报时刻**：如果这本小说拍电影，海报上是哪个画面？
   - ❌ "主角站在山顶修炼"（所有修仙文都有）
   - ✅ "主角手握破碎古镜，镜中倒映出敌人的功法秘籍"（独特、有故事感）

3. **读者承诺**：封面要对读者承诺什么体验？
   - 逆天改命型 → 承诺"你会看到弱者逆袭的爽感"
   - 家族群像型 → 承诺"你会看到一个家族的兴衰史诗"

### 2.3 气质定调

将基础信息 + DNA 提取综合为 3-5 个视觉关键词，作为设计方向的气质锚点。

示例：
- 玄鉴仙族 → 「家族宿命、镜照因果、暗黑史诗、血与铜锈」
- 深渊主宰 → 「暗黑、仪式感、阶级压迫、神明俯视」

## 3. 联网搜索同赛道封面

用 WebSearch 搜索同赛道优质封面图，给用户锚定"这个赛道封面通常长什么样"。

### 3.1 搜索策略

**搜索关键词组合**（按优先级执行 2-3 组搜索）：

| 搜索目的 | 关键词模板 | 示例 |
|:---------|:---------|:-----|
| 同赛道封面整体风格 | `[赛道] 小说封面 设计` | `修仙小说封面设计` |
| 同赛道高人气封面 | `[赛道] 小说 封面 欣赏` | `玄幻小说封面欣赏` |
| 特定平台封面风格 | `[赛道] 封面 起点/番茄` | `修仙封面起点` |
| 设计风格参考 | `[赛道] 封面 插画风格` | `暗黑修仙封面插画风格` |

### 3.2 搜索结果整理

从搜索结果中筛选 3-5 张有代表性的封面图，为每张标注：

```
封面1：[来源/书名]
  - 风格：[厚涂/工笔/水墨/电影概念/暗黑写实]
  - 构图：[L型/中心放射/分层群像/对角线/框中框]
  - 配色：[主色调]+[辅助色]+[强调色]
  - 视觉焦点：[人物/道具/场景]
  - 特点：[一句话评价这张封面为什么有效/无效]
```

### 3.3 同赛道封面分析总结

回答以下问题，形成赛道视觉认知：

1. **同赛道封面的共同特征是什么？**（色调/构图/风格/视觉焦点）
2. **同赛道封面的常见问题是什么？**（同质化/气质偏差/视觉混乱）
3. **本书可以在哪些维度差异化？**（反色调？独特道具？构图差异？）

> 查 `references/novel-visual-design.md` §三「赛道视觉速查」获取赛道常见风格和差异化机会。

## 4. 理解用户参考图（如有）

如果用户提供了参考图（在任何阶段提供都处理），执行参考图理解。

### 4.1 参考图类型判断

判断用户提供的参考图属于哪种类型：

| 参考图类型 | 特征 | 用户意图 |
|:---|:---|:---|
| 风格参考 | 用户说"喜欢这个画风""这种质感" | 想要接近这个画风 |
| 构图参考 | 用户说"这个布局好""这种排版" | 想要类似构图 |
| 综合参考 | 用户说"整体感觉像这样" | 风格+构图都要接近 |
| 角色参考 | 用户说"人物画这样" | 角色精度参考 |

### 4.2 参考图特征提取

用 Read 工具查看参考图，提取以下特征形成文字描述：

```
参考图理解报告：
  - 画风：[笔触技法、色彩系统、明暗方式]
    示例："泼墨晕染与块面塑造结合，灰白与墨黑低饱和度单色调，金色作为唯一暖色点缀"
  - 构图：[人物数量、位置关系、空间层次]
    示例："单人居中构图，人物占画面主体，上方留白"
  - 配色：[主色调]+[辅助色]+[强调色]+[比例]
    示例："墨黑七成为底，灰白两成，金色半成点缀"
  - 可吸收要素：[具体列出]
  - 不吸收要素：[具体列出]
  - 生成路线建议：[图生图/文生图] + [理由]
```

### 4.3 参考图理解结果用途

这份理解报告用于两个目的：
1. **门禁A对齐**：用人话告诉用户"我从这张图里提取了什么，打算怎么用"
2. **降级fallback**：如果后续图生图翻车，这份文字描述直接作为文生图提示词基础

## 5. 🚪 门禁A：方向对齐

**这是强制暂停点。禁止跳过。**

向用户呈现以下内容（全部用用户能看懂的自然语言，非技术术语）：

### 5.1 呈现内容

```
## 封面方向对齐

### 你的小说核心
- 赛道：[赛道]
- 核心卖点：[一句话USP]
- 读者承诺：[一句话读者承诺]
- 气质关键词：[3-5个视觉关键词]

### 同赛道封面长什么样
[展示3-5张搜索到的同赛道封面图，或描述其风格特征]
- 同赛道共同特征：[总结]
- 常见问题：[总结]
- 差异化机会：[总结]

### 我建议的方向
- 视觉钩子：[一句话描述画面核心，如"破碎古镜居中发光，镜中倒映敌人功法"]
- 构图方向：[一句话，如"中心放射构图，古镜为绝对焦点"]
- 配色方向：[一句话，如"玄黑七成+青绿两成+鎏金半成，暗黑修仙差异化"]
- 风格方向：[一句话，如"暗黑厚涂，类似暗黑魂系列质感"]

### 参考图理解（如有）
- 你提供的参考图，我提取了：[画风/构图/配色特征]
- 我打算吸收：[具体要素]
- 我打算不吸收：[具体要素]
- 生成路线：[图生图/文生图]

---
请确认方向是否正确，或告诉我需要调整的地方。
你也可以现在提供参考图，我会分析后纳入设计。
```

### 5.2 等待用户确认

**禁止自主进入 Step 1。** 必须等用户明确回复后才能继续。

用户可能的回复类型：

| 用户回复 | 处理方式 |
|:---------|:---------|
| "可以/没问题/继续" | 方向确认，进入 Step 1 |
| "改成X方向" | 根据用户反馈调整方向，重新呈现（或直接进入Step 1带调整） |
| "这是我的参考图[图]" | 执行 §4 参考图理解，更新呈现后重新等待确认 |
| "搜索一下X风格的" | 补充搜索，更新呈现后重新等待确认 |
| "同赛道的不对，我的书是X赛道" | 修正赛道，重新搜索+呈现 |

### 5.3 落盘

将方向对齐结果追加到 `素材/视觉设计方案.md`：

```markdown
## 方向对齐记录

### 小说DNA
- USP：[独特卖点]
- 电影海报时刻：[画面描述]
- 读者承诺：[承诺内容]
- 气质关键词：[3-5个]

### 同赛道封面参照
[搜索结果摘要]

### 确认方向
- 视觉钩子：[确认的钩子方向]
- 构图方向：[确认的构图方向]
- 配色方向：[确认的配色方向]
- 风格方向：[确认的风格方向]

### 参考图（如有）
- 参考图理解：[理解报告]
- 生成路线：[图生图/文生图]

### 用户反馈
[用户确认/调整记录]
```

## 6. 进入 Step 1

方向确认后，读取 `steps/step1-design.md`，基于确认方向设计具体方案。
