# Step 1: 设计方案（基于参考图+参考点）

> 读取选图记录+参考点 → 基于参考图设计画面差异 → 形成人可读方案 → 🚪门禁B：方案对齐

## 设计哲学

设计方案不是"从零设计一个画面"，是**基于参考图+参考点，设计需要改动/差异化的部分**。

用户选了参考图并明确了参考点——这已经决定了设计的基调。Step 1 的职责是：把"参考图保留什么 + 自己改什么"翻译成一个用户能看懂的方案。

## 1. 读取选图记录

读取 `素材/视觉设计方案.md` 中的「选图与参考点记录」，提取：
- 选中的参考图
- 参考点（全面参考/色系/构图/画风/光影/字体/组合）
- 提示词策略
- 用户意图（赛道、目标读者、核心卖点）

## 2. 设计画面差异

### 2.0 视觉模式决定设计方法论

**必读 `references/visual-mode-guide.md`**，根据 Step 0 判定的视觉模式选择设计方法论：

| 视觉模式 | 设计方法论 | 参考文档 |
|:---------|:---------|:---------|
| 封面图 | 视觉钩子设计（6种钩子类型+构图骨架库） | `references/novel-visual-design.md` 全文 |
| 人物立绘 | 角色名片设计（角色为主体80%+，文字为注释15%） | `references/visual-mode-guide.md` §二 + `references/novel-visual-design.md` §七 |
| 普通素材 | 纯视觉设计，无文字约束 | 无特殊参考 |

> **人物立绘设计要点**：
> - 角色主视觉占八成，辨识度三要素齐全（轮廓+色彩+细节）
> - 角色名中等大小（不超过画面10%），有材质质感
> - 定场诗/人设简介为小字，2-4句，浓缩角色核心意象
> - 三种布局模板可选：底部面板型/侧边条型/叠加层型
> - **与封面的关键区别**：封面是视觉钩子（让读者点进书），立绘是角色名片（让读者记住这个人）

### 2.1 参考点决定设计范围

根据参考点确定设计方案需要描述的维度：

| 参考点 | 设计方案需要描述的 | 设计方案不需要描述的（交给参考图） |
|:-------|:-----------------|:-------------------------------|
| 全面参考 | 仅描述需要改的部分（书名+必要内容差异） | 画面、色系、构图、画风、光影、字体 |
| 色系 | 画面内容+构图+画风+光影+字体 | 配色 |
| 构图 | 画面内容+配色+画风+光影+字体 | 构图布局 |
| 画风 | 画面内容+配色+构图+光影+字体 | 笔触技法、渲染方式 |
| 光影氛围 | 画面内容+配色+构图+画风+字体 | 光源设计 |
| 字体风格 | 画面内容+配色+构图+画风+光影 | 字体类型、排版风格 |
| 色系+构图 | 画面内容+画风+光影+字体 | 配色+构图 |

### 2.2 设计画面内容差异

基于小说 DNA 和参考图，设计**参考图中没有但封面需要的元素**：

1. **书名文字**：书名内容、分行方式、大致位置（字体风格交给参考图或用户指定）
2. **内容差异**：如果参考图是海滩漫步，但小说是都市客厅——设计场景替换。如果参考图已经贴合小说场景——可能只需换书名
3. **视觉钩子**：从小说 DNA 推导的独特卖点，如何融入或替换参考图画面

> **门禁**：如果参考点=全面参考，设计方案应尽量少改动参考图画面。最多改书名+少量内容差异。不是"基于参考图重新设计一个不同画面"。

### 2.3 目标读者画像校验

设计方案的画风描述必须与 Step 0 确定的目标读者画像一致：

| 读者画像 | 画风校验点 |
|:---------|:---------|
| 18-35岁女性 | 精致成熟，韩剧海报质感，**非卡通非Q版** |
| 12-18岁少女 | 可爱明亮，日系动漫风格 |
| 男性读者 | 视觉冲击力，概念艺术质感 |

> **门禁**：如果设计方案中出现了与目标读者画像矛盾的画风词（如给18-35岁女性读者写了"Q版""卡通"），必须修正。

## 3. 形成设计方案文档

将设计结果整合为设计方案，读取 `templates/design-plan.tpl.md` 模板，追加到 `素材/视觉设计方案.md`。

设计方案必须包含：
1. **参考图与参考点**（选中的图+参考点）
2. **画面差异描述**（相对参考图改了什么、保留了什么）
3. **目标读者画像**（年龄层+审美偏好）
4. **书名排版**（内容+分行+大致位置）
5. **提示词策略预览**（告诉用户生成时怎么处理参考图）

## 4. 🚪 门禁B：方案对齐

**这是强制暂停点。禁止跳过。**

向用户呈现完整设计方案（全部用人话，非技术prompt）：

```
## 封面设计方案

### 参考图与参考点
- 参考图：[pin_xxx]
- 参考点：[全面参考/色系/构图/...]
- 保留：[参考图中保留的元素]
- 改动：[参考图中改动的元素]

### 画面描述（用人话说画面长什么样）
[2-3句话描述画面，重点说"和参考图有什么不同"]

### 目标读者
- 年龄层：[年龄]
- 审美偏好：[韩剧唯美/精致写实/...]
- 画风校验：[与读者画像一致]

### 书名排版
- 内容：[书名]
- 分行：[分行方式]
- 位置：[大致位置]

### 生成策略
- 参考图用法：[保留画面主体/只吸收色系/只吸收构图/...]
- 提示词不控制：[交给参考图的维度]

---
请确认设计方案是否正确，或告诉我需要调整的地方。
确认后我将生成封面。
```

### 4.1 等待用户确认

**禁止自主进入 Step 2。** 必须等用户明确回复后才能继续。

### 4.2 落盘

将方案对齐结果追加到 `素材/视觉设计方案.md`：

```markdown
## 方案对齐记录

### 设计方案
[完整设计方案]

### 用户反馈
[用户确认/调整记录]
```

## 5. 进入 Step 2

方案确认后，读取 `steps/step2-generate.md`，根据参考点对应的提示词策略翻译为提示词并生成。
