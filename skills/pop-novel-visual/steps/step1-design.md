# Step 1: 设计方案（对齐版）

> 基于门禁A确认的方向 → 设计视觉钩子 → 设计构图叙事 → 全局视觉统筹 → 形成人可读设计方案 → 🚪门禁B：方案对齐

## 设计哲学

封面不是插画，是**视觉钩子**。读者在平台网格里 0.3 秒扫过 50 张封面，只点那张**承诺了最想要体验**的。设计方案的职责：找到这本小说的"视觉钩子"，用一个构图把它变成 0.3 秒能读懂的 promise。

设计方案不是"填表选元素"，而是**设计推理**：从门禁A确认的方向出发，推导出唯一最优的视觉表达。

## 1. 读取确认方向

读取 `素材/视觉设计方案.md` 中的「方向对齐记录」，提取门禁A确认的：
- 视觉钩子方向
- 构图方向
- 配色方向
- 风格方向
- 参考图理解结果（如有）

## 2. 设计视觉钩子

**核心原则：一张封面只传达 1 个视觉钩子。不贪多。**

### 2.1 选择钩子类型

读取 `references/novel-visual-design.md` §二「视觉钩子设计库」，根据确认方向选择钩子类型：

| 钩子类型 | 适用场景 | 视觉特征 | 示例 |
|:---------|:---------|:---------|:-----|
| 标志道具 | 小说有独特核心道具 | 道具居中/放大，散发能量，人物为辅 | 玄鉴仙族→破碎古镜 |
| 角色统治力 | 主角人设是最大卖点 | 角色占据画面主体，俯视/压迫姿态 | 深渊主宰→主角居高临下 |
| 反差瞬间 | 扮猪吃虎/身份反转 | 前景朴素 vs 后景恐怖力量暗示 | 质子逆袭→囚徒 vs 王座 |
| 群像史诗 | 家族/势力群像 | 多人物分层站位，有等级关系 | 玄鉴仙族→族长+族人 |
| 世界奇观 | 世界观是最大卖点 | 场景占画面主体，人物渺小 | 仙穹→浮空仙殿群 |
| 对峙张力 | 核心冲突是双雄对决 | 双方分列画面两侧，中间能量碰撞 | 宿敌→正邪对峙 |

### 2.2 设计钩子画面

选定钩子类型后，回答以下问题设计具体画面：

1. **画面主体是谁/什么？**（人物/道具/场景）
2. **主体在做什么/呈现什么状态？**（标志性动作/姿态/能量状态）
3. **画面暗示了什么故事？**（读者看一眼能脑补出什么剧情？）
4. **这个画面和同赛道其他封面的区别是什么？**

> **门禁**：如果第 4 题答不出区别，回到 Step 0 重新对齐方向。

### 2.3 竞争差异化检查

想象目标平台的推荐页网格——读者的拇指在滑动，同赛道有 50 张封面竞争。回答：

1. **同赛道封面通常长什么样？**（门禁A已搜索，回顾搜索结果）
2. **本封面如何从网格中跳出来？**（反色调？独特道具？构图差异？）
3. **0.3 秒识别度测试**：读者扫一眼能判断赛道吗？能感知到独特性吗？

## 3. 设计构图叙事

构图不是"元素摆放"，是**用空间关系讲 0.3 秒的故事**。

### 3.1 构图骨架选择

根据钩子类型选择构图骨架（读取 `references/novel-visual-design.md` §四「构图骨架库」）：

| 构图骨架 | 特征 | 适合钩子 | 视觉效果 |
|:---------|:-----|:---------|:---------|
| L型构图 | 文字竖排一侧+主体另一侧 | 标志道具/角色统治力 | 稳定、商业感强 |
| 中心放射 | 核心道具居中，光芒/能量向外辐射 | 标志道具/世界奇观 | 视觉冲击力最强 |
| 分层群像 | 多层景深，人物按层级分布 | 群像史诗 | 史诗感、信息量大 |
| 对角线对峙 | 双方分列对角，中间碰撞 | 对峙张力 | 动态张力 |
| 框中框 | 用道具/建筑形成画中画 | 反差瞬间/悬疑 | 窥视感、悬念 |

### 3.2 空间层次设计

为构图骨架填充空间层次（每层回答：放什么？占多大面积？什么光照？）：

```
远景层：[世界观环境] — 占X成 — 暗处理/雾气虚化
中景层：[叙事元素/次要人物] — 占X成 — 半剪影/背光
主体层：[视觉钩子主体] — 占X成 — 最高细节密度/主光源照射
前景层：[压边元素/道具特写] — 占X成 — 纯剪影/虚化
```

### 3.3 配色方案

**3 色原则 + 成数描述**（适配 Step 2 结构化提示词）：

- **主色调**（七成左右）：决定整体气质，画面绝对主体
- **辅助色**（两成左右）：丰富层次、承载能量/光效
- **强调色**（半成左右）：制造视觉焦点、文字/纹饰
- **点缀色**（半成左右）：印章朱砂红等文化元素

配色必须回答：**这个配色和同赛道其他封面有什么区别？**

### 3.4 光源设计

**单一主光源原则**：画面只有 1 个主光源，所有光照逻辑由此推导。

| 光源类型 | 适合氛围 | 效果 |
|:---------|:---------|:-----|
| 道具自发光 | 道具钩子 | 道具成为视觉焦点，人物受光 |
| 逆光/轮廓光 | 角色统治力 | 人物轮廓发光，面部可剪影化 |
| 顶光 | 神圣/压迫 | 仪式感、权威感 |
| 环境散射光 | 温馨/日常 | 柔和均匀 |
| 底光 | 诡异/恐怖 | 反自然、不安感 |

### 3.5 字体版式

用字体控制公式：`[书名] + [字体类型] + [材质/质感] + [色彩层次]`

- 书名用双引号包裹
- 给尺寸锚点："占画面高度X成"（**不超过三成**，画面才是绝对主体）
- 材质要有物理质感：鎏金/金石碑刻/飞白枯笔/银白冷光
- 位置与构图骨架配合：L型构图文字在侧面，中心放射构图文字在上方留白
- **文字是画面的"注释"不是"主角"**——画面钩子才是主角，文字融入画面而非独占空间
- **文字融入策略**：描述文字与画面元素的物理交互——"底部笔画被前景碎石遮挡""部分笔画被飘散粒子和雾气融合"，避免文字"浮于画面之上"的贴图感

### 3.6 文化元素设计

读取 `references/novel-visual-design.md` §八「文化元素设计库」，根据小说 DNA 和赛道选择文化元素。

**选择流程**：

1. **判断是否适合加文化元素**：修仙/玄幻/古言/悬疑 → 适合；都市/末世/言情 → 谨慎或跳过
2. **选择 2-3 种文化元素**（不贪多）：
   - 定场诗：用创作公式 `[核心意象A] + [核心意象B] + [因果/转折] + [情感升华]` 写 2-4 句古体诗
   - 小篆：定场诗用小篆书写，或道具铭文用小篆
   - 印章：朱砂红印章做落款，位置在书名下方或画面边角
   - 古籍版式线/八卦符/竹简等：按需选择
3. **设计字体层级**：主标题（书法体）> 定场诗（小篆/隶书）> 副标题（楷体）> 印章（篆刻体）
4. **确认朱砂红锚点**：印章的朱砂红纳入配色方案的强调色体系

> **门禁**：文化元素必须服务于小说 DNA。如果加了文化元素后封面气质和小说 DNA 矛盾，不加比加好。

**文化元素融入原则（关键！）**：

文化元素不能独立占空间、不能形成"文字区"，必须**融入画面层次**：

| 元素 | ❌ 堆叠式（割裂画面） | ✅ 融入式（统一画面） |
|:-----|:---------------------|:---------------------|
| 定场诗 | 竖排独占一列，形成"文字墙" | 叠在画面留白处/背景虚化区，半透明或小字融入 |
| 印章 | 放在独立文字区底部 | 压在画面边角，像盖章在画上 |
| 古籍版式线 | 双线框包围整个文字区 | 仅做画面边缘装饰线，不形成封闭框 |
| 小篆 | 作为独立副标题竖排 | 刻在道具表面/融入背景纹理 |

### 3.7 风格方向

用风格控制公式：`[风格名称] + [技法描述] + [质感描述] + [参考标杆]`

已验证风格池（5 种）见 `references/novel-visual-design.md` §五。

如果有参考图：结合门禁A的参考图理解结果，明确哪些画风要素从参考图吸收，哪些由风格方向决定。

### 3.8 全局视觉统筹（关键步骤！）

> **退后一步看整体**。前面每一步都在做"加法"——选钩子、填层次、加文化元素。这一步做"减法"和"调平衡"：确保所有元素加在一起是一张**统一的画面**，不是"文字区+画面区"的拼贴。
>
> **设计思维反转**：不是"先局部后统筹"，而是"**先整体后局部**"。在设计第一步就锁定全局视觉框架（画面占多少、文字占多少、留白多少），然后往框架里填内容。文字是最后填入的"注释"，不是先占空间的"主角"。

**视觉权重分配**：

```
画面主视觉（钩子主体+场景）  — 七成左右（绝对主体）
书名文字                     — 两成左右（辨识但不抢戏）
文化元素（定场诗+印章等）     — 半成左右（点缀提逼格）
留白/暗部                    — 半成左右（呼吸空间）
```

**检查项**：

1. **单一焦点原则**：画面只有 1 个视觉焦点。书名+文化元素+画面不能形成"多焦点竞争"。如果书名和文化元素的视觉权重加起来超过两成半，缩减文字尺寸
2. **无硬切割**：文字区和画面区之间不能有硬边界（版式线/颜色突变）。文字应叠加在画面上，而非占据独立空间
3. **视线流畅**：读者视线应 0.3 秒直达视觉钩子，而非被文字拦截。书名是"第二眼"信息，定场诗是"第三眼"信息
4. **文字尺寸上限**：书名高度不超过画面三成；定场诗字号不超过书名的五分之一；印章面积不超过画面百分之一
5. **元素层次融入**：文化元素必须叠加在画面的某个层次上（前景压边/背景虚化区/道具表面），不能独占空间
6. **文字物理交互**：文字不能"浮于画面之上"。书名部分笔画被前景元素遮挡/与雾气粒子融合，形成"文字长在画面里"的效果

## 4. 形成设计方案文档

将以上设计推理结果整合为设计方案，读取 `templates/design-plan.tpl.md` 模板，追加到 `素材/视觉设计方案.md`。

设计方案必须包含：
1. **小说 DNA**（USP + 电影海报时刻 + 读者承诺）
2. **视觉钩子**（类型 + 画面描述 + 差异化点）
3. **构图叙事**（骨架 + 空间层次 + 配色 + 光源 + 字体 + 风格）
4. **文化元素**（定场诗原文 + 字体选择 + 印章设计 + 融入方式）
5. **视觉权重分配**（画面/书名/文化元素/留白各占几成）
6. **竞争差异化**（同赛道对比 + 本封面如何跳出）
7. **参考图用法**（如有：吸收什么/不吸收什么/生成路线）

## 5. 🚪 门禁B：方案对齐

**这是强制暂停点。禁止跳过。**

向用户呈现完整设计方案（全部用用户能看懂的自然语言，非技术prompt）：

### 5.1 呈现内容

```
## 封面设计方案

### 画面描述（用人话说画面长什么样）
[2-3句话描述画面，像给朋友讲故事一样]
示例："画面中央是一面破碎的青灰古镜，镜面散发幽冷月白光芒，裂纹中渗出青绿能量。右侧族长侧脸半身像，面容冷峻。下方三名族人背光剪影，执剑施法。"

### 视觉钩子
- 类型：[标志道具/角色统治力/反差瞬间/群像史诗/世界奇观/对峙张力]
- 画面：[一句话]
- 差异化：[一句话，和同赛道什么不同]

### 构图
- 骨架：[L型/中心放射/分层群像/对角线对峙/框中框]
- 空间层次：[远景→中景→主体→前景，每层一句话]

### 配色
- 主色调：[色名] [X成] — [气质]
- 辅助色：[色名] [X成] — [用途]
- 强调色：[色名] [X成] — [用途]
- 点缀色：[色名] [X成] — [用途]

### 光源
[一句话，如"古镜自发光为唯一主光源，人物受光轮廓分明"]

### 文字
- 书名：[书名] [字体类型] [材质] [尺寸]
- 定场诗：[诗句原文] [字体] [尺寸]
- 印章：[位置] [颜色] [尺寸]

### 风格
[一句话，如"暗黑厚涂数字油画，笔触粗犷厚重，类似暗黑魂系列"]

### 参考图用法（如有）
- 吸收：[具体要素]
- 不吸收：[具体要素]
- 生成路线：[图生图/文生图]

### 视觉权重
画面七成 / 书名两成 / 文化元素半成 / 留白半成

---
请确认设计方案是否正确，或告诉我需要调整的地方。
确认后我将生成封面。
```

### 5.2 等待用户确认

**禁止自主进入 Step 2。** 必须等用户明确回复后才能继续。

用户可能的回复类型：

| 用户回复 | 处理方式 |
|:---------|:---------|
| "可以/没问题/继续" | 方案确认，进入 Step 2 |
| "改成X" | 根据用户反馈调整方案，重新呈现 |
| "文字再小一点" | 调整文字尺寸，重新呈现 |
| "配色改成X" | 调整配色，重新呈现 |
| "换个构图" | 调整构图骨架，重新呈现 |
| "加个X元素" | 增加元素，重新呈现 |

### 5.3 落盘

将方案对齐结果追加到 `素材/视觉设计方案.md`：

```markdown
## 方案对齐记录

### 设计方案
[完整设计方案]

### 用户反馈
[用户确认/调整记录]
```

## 6. 自检

设计方案落盘前检查：

**设计推理自检**：
- [ ] 视觉钩子是这本小说独有的，换一本书就不适用
- [ ] 能回答"同赛道 50 张封面里，读者为什么点这张"
- [ ] 构图骨架服务于视觉钩子，不是为了好看而堆砌元素

**技术规范自检**：
- [ ] 配色用"成数"描述（玄黑七成），不用百分比
- [ ] 光源设计指定了"唯一主光源"
- [ ] 风格词具体可执行（非"好看的画风"）
- [ ] 字体有材质质感描述
- [ ] 文化元素服务于小说 DNA（非为了有文化而硬加）
- [ ] 文化元素不超过 3 种（不贪多）
- [ ] 定场诗包含小说核心意象（非通用诗句）

**全局视觉统筹自检**：
- [ ] 画面主视觉占七成左右（绝对主体）
- [ ] 书名文字不超过画面高度三成
- [ ] 文化元素融入画面层次（非独占空间形成"文字区"）
- [ ] 文字区与画面区无硬切割（文字叠加在画面上）
- [ ] 文字有物理交互描述（被前景遮挡/与雾气融合，非浮于画面之上）
- [ ] 画面只有 1 个视觉焦点（无多焦点竞争）
- [ ] 定场诗字号不超过书名的五分之一
- [ ] 读者视线 0.3 秒直达视觉钩子（书名是第二眼信息）

**门禁B呈现自检**：
- [ ] 画面描述用人话，非技术prompt（"画面中央是一面破碎古镜" 而非 "中心放射构图+道具自发光"）
- [ ] 所有设计决策都有用户能理解的理由
- [ ] 参考图用法已明确（如有参考图）

## 7. 进入 Step 2

方案确认后，读取 `steps/step2-generate.md`，将确认方案翻译为提示词并生成。
