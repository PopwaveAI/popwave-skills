# Step 2: 生成资产

> 读取确认方案 → 生成路线决策 → 翻译为提示词 → 执行 API 脚本 → 保存产出 → 降级处理（如需）

## 1. 读取确认方案

读取 `素材/视觉设计方案.md` 中的「方案对齐记录」，提取门禁B确认的：
- 视觉类型（封面/人设图）
- 画幅与尺寸
- 主视觉描述
- 氛围场景
- 色彩方案
- 光影方向
- 风格方向
- 参考图用法（如有：吸收什么/不吸收什么/生成路线）

## 2. 生成路线决策

根据门禁A/B中确认的参考图情况，决定生成路线：

### 2.1 路线决策树

```
有参考图？
├─ 是 → 参考图类型？
│   ├─ 风格参考 → 路线A：图生图（只吸收画风）
│   ├─ 构图参考（简单） → 路线A：图生图（吸收构图+画风由prompt控制）
│   ├─ 构图参考（复杂） → 路线B：文生图（用Step 0理解阶段的文字描述）
│   ├─ 综合参考 → 路线A：图生图+反向强化
│   └─ 联网搜的同赛道封面 → 路线B：文生图（方向锚定，不复刻）
└─ 否 → 路线B：文生图（V3结构化提示词）
```

### 2.2 路线A：图生图（参考图+精确分离公式）

默认路线。参考图作为 `image` 参数传入，配合精确分离公式控制吸收范围。

**优势**：质感无损传递（笔触/光感比文字描述准确十倍）
**风险**：强特征泄漏（参考图的颜色/人物/构图可能"泄漏"到生成结果）
**对策**：精确分离公式 + 反向强化技巧

### 2.3 路线B：纯文生图（V3结构化提示词）

无参考图，或参考图类型不适合图生图时使用。

**优势**：构图完全自由，无"太像"风险
**基础**：Step 0 参考图理解阶段的文字描述作为提示词基础（如有参考图但走文生图路线）

### 2.4 降级机制

图生图生成后，检查结果：
- **太像参考图**（强特征泄漏）→ 降级为文生图，用理解阶段文字描述
- **构图不满意**（参考图构图约束过强）→ 降级为文生图
- **画风吸收不足**（不像参考图）→ 强化精确分离公式的"仅参考"要素描述

降级时无需再次通过门禁，直接用 Step 0 理解阶段的文字描述 + V3结构化提示词重新生成。

## 3. 翻译为模型提示词

读取 `references/seedream-prompt-guide.md` 获取提示词写法，然后执行翻译。

> **核心原则**：Seedream 5.0 Pro/5.0 lite **画面不再泛白**，简洁精确的提示优于堆砌华丽词汇。用自然语言连贯描述，不堆叠关键词。

### 2.1 Seedream 提示词翻译（默认）

> **核心发现**（5.0 Pro A/B 实测）：纯文生图质量瓶颈在于提示词缺少"结构信息"。参考图生图效果好，是因为参考图提供了构图骨架+配色比例+字体版式。纯文生图要达到同等质量，必须在提示词中**显式编码这三层结构**。

#### 结构化提示词公式（实测验证，5.0 Pro 纯文生图达 A 级商业封面）

```
整体氛围框架（画面是绝对主体）+ 画面内容（远景→前景按层次）+ 文字（最后描述，融入画面）+ 风格
```

> **关键原则（v1.5.1 实测修正）**：prompt 结构必须**先整体后局部**——先锁定整体氛围和视觉权重，再描述画面内容，文字放在最后。文字不是先占空间的"主角"，而是最后填入画面的"注释"。文字必须描述与画面元素的物理交互（被遮挡/被融合），避免"浮于画面之上"的贴图感。

**翻译规则**：
1. **先整体氛围**：一句话定调画面主体性和整体色彩权重（"画面是绝对主体""X色占七成为底"）
2. **画面内容按空间层次**：从远到近逐层描述，每层内容+光照
3. **文字最后描述**：书名放在画面内容之后，明确"叠于画面[位置]"而非"独占空间"
4. **文字融入策略**：描述文字与画面的物理交互——"底部笔画被前景碎石遮挡""部分笔画被飘散粒子和雾气融合"
5. **配色用"成数"不用百分比**：模型理解"玄黑七成"但无法计算"70%"
6. **指定单一主光源**：写"为画面唯一主光源"，避免多光源混乱
7. **字体要写材质**：书名用双引号包裹 + 字体类型 + 材质质感（鎏金/金石碑刻/飞白枯笔）
8. **文字尺寸不超过三成**：写"占画面高度两成"而非"四成"或"七成"
9. **风格词放末尾**：用"X风格"句式收尾
10. **文化元素极简**：定场诗字号不超过书名的五分之一，印章不超过画面百分之一
11. 中文提示词 ≤400 字

**实测对比**（同一画面内容，三种写法）：

| 写法 | 评分 | 问题 |
|:-----|:-----|:-----|
| 旧法：自然语言叙述画面内容 | 3.0/5 | 无结构信息，配色漂移，构图随机 |
| V1：分层描述+百分比 | 3.8/5 | 百分比模型理解不了，紫色侵入 |
| V2：构图优先+成数比例 | 4.2/5 | 文字过大，文字区与画面区割裂 |
| **V3：全局优先+文字融入** | **4.5/5 (A级)** | **最佳，文字融入画面，无割裂** |

**翻译示例（V3 全局优先写法）**：

设计方案：
> 书名：玄鉴仙族 | 赛道：暗黑修仙 | 主视觉：族长侧脸+破碎古镜 | 配色：玄黑/青绿/鎏金 | 风格：暗黑国风厚涂

翻译为提示词：
> 暗黑奇幻国风小说封面，竖版构图，画面是绝对主体。整体氛围：幽暗深邃的仙山废墟之夜，玄墨黑为底色占七成，青绿幽光和鎏金铜锈点缀。画面中央偏上是一面破碎的青灰古镜，镜面散发幽冷月白光芒为唯一主光源，裂纹中渗出青绿能量呈放射状扩散。镜中隐约可见修士身影和仙山废墟倒影。右侧族长侧脸半身像，玄色暗金纹路长袍，面容冷峻，受镜光照射轮廓分明。下方三名族人倒三角站位，背光剪影，执剑施法。远景崩塌仙山废墟与暗紫雷云，前景废墟碎石从画面左侧延伸至中央。书名"玄鉴仙族"四字竖排，叠于画面左侧，鎏金毛笔书法体，占画面高度两成，飞白枯笔，金石碑刻龟裂质感，底部笔画被前景碎石微微遮挡，融入画面而非独占空间。定场诗"鉴中千秋血镜外万骨枯"极小篆字竖排，叠于书名右侧背景暗部，古铜色半透明，字号为书名的五分之一，若隐若现。画面右下角压一枚朱砂红方形印章，约占画面百分之一。厚涂数字油画风格，笔触粗犷厚重可见，类似暗黑魂系列美术质感。

**关键技巧**：
- "画面是绝对主体" — 开篇定调，避免文字喧宾夺主
- "占画面高度两成" — 文字尺寸锚点，不超过三成
- "叠于画面左侧" — 文字叠加在画面上，而非独占空间
- "底部笔画被前景碎石微微遮挡" — 文字与画面的物理交互，消除贴图感
- "倒三角站位，背光剪影" — 群像用阵型+光照统一处理，避免个体崩坏
- "为画面唯一主光源" — 锁定光源，避免多光源混乱
- "玄黑七成…青绿两成半…鎏金一成" — 用成数控制配色比例，不用百分比
- "前景废墟碎石从画面左侧延伸至中央" — 前景元素延伸到文字区，消除硬切割

### 2.2 Seedance 提示词翻译（可选，用户要求视频封面时）

**公式**：`主体 + 动作（慢、连贯） + 场景 + 光影 + 镜头语言 + 风格 + 画质 + 稳定性约束`

**翻译规则**：
1. 动作写慢、写碎：用"缓慢""轻柔""连贯"等词
2. 镜头语言明确：推/拉/摇/移/环绕/跟随 + 景别
3. 必加稳定性约束：五官清晰、面部稳定、不扭曲、人体结构正常
4. 必加画质词：4K、超高清、无闪烁
5. 中文提示词 ≤500 字

**翻译示例**：
> 一个身穿黑色长袍的青年站在悬崖边缘，缓慢转身面向镜头，手持漆黑长剑，剑身散发幽蓝色微光。悬崖下方云海翻涌，远处神殿轮廓若隐若现。镜头从背影缓慢推近至近景，逆光，云海反射微光。深蓝与墨黑色调，电影质感，4K超高清，面部清晰不变形，人体结构正常，画面流畅稳定，无闪烁。

### 2.3 参考图生图提示词翻译（有参考图时）

当用户提供参考图时，用**精确分离公式**控制画风与构图的吸收范围。

> **何时使用参考图**：5.0 Pro + 结构化提示词的纯文生图已可达 A 级商业封面质量。参考图生图在以下场景仍有优势：①需要精确复刻特定画风笔触 ②需要吸收特定构图骨架 ③用户提供了高质量风格参考。有参考图时，参考图 + 结构化提示词 = 最优生成策略。

#### 精确分离公式

```
仅参考此图的[具体画风/构图要素列表]，不参考[具体排除要素列表]。
以下画面内容完全由本段描述决定：[详细画面描述]
```

**关键原则**：
1. 画风要素拆解到**笔触技法、色彩系统、明暗方式**层面（不写"参考风格"这种模糊词）
2. 构图要素拆解到**人物数量、位置关系、空间布局**层面（不写"参考构图"这种模糊词）
3. 明确声明"以下画面内容由描述决定，与参考图无关"

#### 两种使用模式

**模式一：只吸收画风（高度可靠）**

吸收参考图的画风特征，构图完全由提示词控制。实测画风吸收率 75-90%，构图独立度 100%。

```
仅参考此图的[笔触技法A、笔触技法B]和色彩系统（[主色调描述]、[点缀色描述]），
不参考图中的人物形象、姿态动作、服饰道具、场景环境、构图布局。
以下画面内容完全由本段描述决定：[目标画面详细描述]
```

实测示例（白麟参考图 → 铜镜单道具构图）：
> 仅参考此图的笔触技法（泼墨晕染与块面塑造结合、飞白枯笔效果）和色彩系统（灰白与墨黑低饱和度单色调、金色作为唯一暖色点缀），不参考图中的人物形象、姿态动作、面部表情、服饰道具、场景环境、构图布局。以下画面内容完全由本段描述决定：设计一张修仙小说封面。画面左侧竖排书名 "玄鉴仙族" 四字，采用鎏金毛笔书法体……铜镜居中偏上，下方留白。

**模式二：构图互换（需强化控制）**

保留参考图的构图骨架，画风由提示词控制。实测不对称：从构图简单的参考图吸收构图较容易，从构图复杂的参考图吸收构图较难。

```
仅参考此图的构图布局：[人物数量+位置关系+空间层次的具体描述]，
不参考图中的人物服饰、色彩配色、场景环境、笔触风格。
以下画面的画风和色彩完全由本段描述决定：[目标画风+色彩详细描述]
```

实测示例（状元游街构图 → 水墨画风）：
> 仅参考此图的构图布局：一个中心人物被四个次要人物对称环绕的"1中心+4围绕"结构，中心人物占据画面中轴线核心位置且体量最大，四人分列四角呈半包围态势。不参考图中的人物服饰、色彩配色、场景环境、笔触风格。以下画面的画风和色彩完全由本段描述决定：……灰白与墨黑低饱和度主色调，金色点缀。泼墨晕染笔触，飞白枯笔效果。

#### 反向强化技巧（当参考图影响过强时）

参考图的强特征（如白麟的白色长发、状元游街的红黑配色）会"泄漏"到生成结果。当提示词中的目标画风被参考图画风覆盖时：

1. **将目标画风描述提到提示词最前面**（增加权重）
2. **用量化词**："占比不低于40%""大面积"
3. **用禁止词**："完全不使用[参考图的色彩]""禁止[参考图的技法]"
4. **用具体色名替代笼统描述**："朱砂红"而非"红色"

强化示例（白麟构图 → 红黑画风，D1失败后D2改进）：
> 画面以大面积朱砂红与墨黑为绝对主色调，红色占比不低于百分之四十。完全不使用灰白墨黑单色调，禁止水墨晕染效果。仅参考此图的构图布局：……

#### 参考图技术注意事项

- `image` 参数必须使用 **data URI 格式**：`data:image/png;base64,<base64数据>`，不能传裸 base64（会报 invalid url 错误）
- 本地图片转换：`base64.b64encode(open(path,'rb').read()).decode()`，再拼上 `data:image/{mime};base64,` 前缀
- 参考图类型选择：风格参考提升字体和色彩质感，构图参考提升分层结构，角色参考提升单体精度

## 3. 确定参数

### 3.1 Seedream 参数

| 参数 | 默认值 | 说明 |
|:-----|:-------|:-----|
| model | `doubao-seedream-5-0-pro-260628` | Seedream 5.0 Pro（默认，质量最优）。5.0 lite（`doubao-seedream-5-0-lite-260128`）速度更快，用于草稿验证 |
| size | 按画幅查 SKILL.md 速查表 | 如 1728x2304 |
| watermark | `false` | 网文封面通常不需要水印 |
| response_format | `url` | 返回 URL，脚本自动下载 |
| image | 无 | 参考图 data URI（图生图场景，详见 §2.3） |

> **模型选择建议**：封面/人设图默认用 5.0 Pro（质量优先，色彩层次和文字渲染显著优于其他版本）；快速草稿验证可用 5.0 lite。

### 3.2 Seedance 参数

| 参数 | 默认值 | 说明 |
|:-----|:-------|:-----|
| model | `doubao-seedance-1-0-pro-250428` | Seedance 1.0 Pro |
| ratio | 按画幅映射 | 3:4 / 16:9 / 9:16 等 |
| duration | `5` | 5 秒（可选 4-10） |
| resolution | `1080p` | 1080p |
| camera_fixed | `false` | 允许运镜 |

## 4. 执行 API 脚本

### 4.1 检查环境变量

确认 `ARK_API_KEY` 环境变量已设置。未设置则报错：
```
错误：未设置 ARK_API_KEY 环境变量
设置方法：set ARK_API_KEY=your_api_key
```

### 4.2 执行生成

**图片生成（Seedream）**：
```powershell
python scripts/generate.py image --prompt "提示词内容" --model doubao-seedream-5-0-pro-260628 --size 1125x1500 --output "素材/视觉/封面-v1.png"
```

**参考图生图（Seedream + 参考图）**：
```powershell
python scripts/generate.py image --prompt "提示词内容" --model doubao-seedream-5-0-pro-260628 --size 1125x1500 --image "data:image/png;base64,<base64数据>" --output "素材/视觉/封面-v1.png"
```

**视频生成（Seedance）**：
```powershell
python scripts/generate.py video --prompt "提示词内容" --model doubao-seedance-1-0-pro-250428 --ratio 3:4 --duration 5 --output "素材/视觉/封面-v1.mp4"
```

脚本路径说明：`scripts/generate.py` 指向 skill 目录下的脚本。执行时使用完整路径。

### 4.3 输出目录

确保输出目录存在：
```
素材/视觉/
```

如不存在则创建。

## 7. 迭代

如果用户对生成结果不满意：
1. 修改设计方案中的对应要素
2. 重新翻译提示词
3. 调用脚本重新生成（输出文件名递增 v2, v3...）
4. 更新提示词记录

常见调整方向：
- 画面元素缺失 → 提示词中该元素描述不够具体，增加细节
- 气质偏差 → 风格词不准确，更换风格描述（用风格控制公式）
- 构图问题 → 增加构图指引词（如"竖版构图""视觉重心在画面下方"）
- 人物变形 → 添加"五官清晰、人体结构正常"约束
- 字体太素 → 用字体控制公式：`[书名] + [字体类型] + [材质/质感] + [色彩层次]`
- 参考图太像（吸收过度） → 用精确分离公式，明确列出"不参考"的要素
- 参考图太不像（吸收不足） → 检查"仅参考"的要素是否具体到技法层面
- 参考图强特征泄漏 → 用反向强化技巧（量化词+禁止词+具体色名）
