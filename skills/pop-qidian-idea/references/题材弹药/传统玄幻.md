# 题材弹药卡 · 传统玄幻

> 定位：访谈弹药库，不是写作配方。只收结构、套路与事实；力量体系架空，但必须自洽。

## 一、定义与定位

- 平台标签：传统玄幻 + 东方玄幻 / 升级流 / 宗门 / 位面 / 争霸。
- 一句话：主角从底层或废柴起步，靠功法、机缘与战斗一路升级，从家族/宗门打到大陆/位面。
- 常见篇幅：200 万字以上为主；80-150 万字要压缩地图；30 万字只写一段。
- 近邻与区别：与「东方仙侠」的区别是仙侠重意境/长生，玄幻重升级/争霸；与「都市高武」的区别是舞台架空。

## 三、读者期待（5-8 条）

1. **升级**：每一阶有明确战力、资源、地位变化。
2. **打脸**：退婚/被欺/被看不起，后面当场翻盘。
3. **机缘**：秘境、传承、丹药、异火，读者期待「捡漏」。
4. **宗门/家族**：有归属、有内斗、有师兄弟。
5. **战斗**：招式、底牌、越级挑战，打得清楚。
6. **地图**：从小镇到大陆到星空，换图有新鲜感。
7. **红颜/兄弟**：感情线与兄弟情，但不喧宾夺主。

## 四、常见套路（8-12 条）

- **开局**：废柴/退婚/家族被欺；得戒指老爷爷/神秘功法；觉醒特殊体质；被宗门拒收。
- **破局**：闭关升级；下秘境；炼丹/炼器；参加宗门大比；抱大腿。
- **升级**：斗者→斗师→大斗师…（同构阶位）；家族→宗门→帝国→位面。
- **打脸/反转**：退婚对象回头；看不起主角的长老被打脸；反派背后有更大势力。
- **换图**：小镇 → 宗门 → 帝国 → 大陆 → 星空/位面。

## 五、反套路清单（5-8 条）

1. **同类都废柴开局 → 本书开局有真本事**：主角不是废物，只是被压制。风险：少了「逆袭反差」，要用身份/资源补。
2. **同类都靠老爷爷 → 本书靠经营/组织**：建商会、宗门、学院。风险：升级爽感慢，要用战斗补。
3. **同类都加入宗门 → 本书自建势力**：从家族/小队起步。风险：建设线长，要控制篇幅。
4. **同类都打打杀杀 → 本书做生意/搞资源**：垄断丹药、灵矿、运输。风险：读者要战斗，不能全商战。
5. **同类都后宫 → 本书单女主/无CP**：把篇幅给对手与地图。风险：感情读者流失，要在人设补。
6. **同类都无代价升级 → 本书给代价**：功法有缺陷、资源有主、越级有反噬。风险：爽感被抵，要给突破补偿。
7. **同类都反派降智 → 本书反派有脑子**：对手会设局、会逃、会联合。风险：主角赢得慢，要设计智力爽点。
8. **同类都换地图重复 → 本书换规则**：每张地图换资源/势力/战斗方式，不只换名字。风险：设定成本高。

## 六、金手指 / 替代驱动（5-8 种）

| 类型 | 能做什么 | 限制/代价 | 适合的主线动作 |
|:--|:--|:--|:--|
| 戒指老爷爷/残魂 | 指导功法、炼丹、战斗 | 能量有限；会沉睡；有旧仇 | 升级、炼丹、解谜 |
| 系统/面板 | 显示进度、发布任务 | 任务失败惩罚；奖励不等于战力 | 升级、资源、势力 |
| 特殊体质/血脉 | 修炼快、抗性强 | 会被觊觎；有失控风险 | 战斗、秘境 |
| 重生/推演 | 知道未来机缘 | 未来会偏移；只知道大势 | 布局、避坑、抢机缘 |
| 空间/灵田 | 种药、囤资源 | 不能暴露；初期小 | 种田、炼丹、经商 |
| 无金手指 + 功法/组织 | 靠苦修与人脉 | 慢；上限受天赋限制 | 宗门、家族、争霸 |

## 七、雷点 / 毒点（5-8 条）

1. 战力崩：阶位只是名字，没有破坏力尺度。
2. 反派降智，为了被打脸而送。
3. 地图重复：换大陆只是换名字，冲突同构。
4. 升级注水：闭关一章升三阶，没有代价。
5. 后宫工具化：女性角色只负责爱主角。
6. 机缘白给：秘境像自家后花园。
7. 后期战力膨胀，世界装不下。
8. 结局仓促：大敌突然被秒，线没收。

## 九、事件种子与分卷阶梯

**事件种子（10-15 条）**

1. 退婚现场，主角被当众羞辱，觉醒血脉。
2. 家族大比，主角被分到最差的分组。
3. 秘境开启，主角捡到别人不要的「废丹」。
4. 宗门收徒，主角被长老拒收。
5. 炼丹大会，主角用偏方赢正统。
6. 灵矿争夺，主角联合小势力对抗大宗门。
7. 帝国招安，主角拒绝当狗。
8. 位面裂缝，异族入侵。
9. 老爷爷身份揭晓，带来旧仇。
10. 主角自建宗门/商会，被旧势力围剿。
11. 红颜/兄弟为救主角牺牲。
12. 终敌不是最强，而是掌握规则/资源的人。
13. 主角打破位面规则，付出代价。

**分卷阶梯样例（10 卷）**
