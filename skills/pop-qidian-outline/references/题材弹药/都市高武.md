# 题材弹药卡 · 都市高武

> 定位：访谈弹药库，不是写作配方。只收结构、套路与事实；战力与机构细节标来源，查不到标「待核」。

## 一、定义与定位

- 平台标签：都市高武 + 都市异能 / 灵气复苏 / 高武世界 / 隐藏身份。
- 一句话：现代都市表面正常，底下有武者/异能者/秘境；主角从普通人或底层武者起步，靠升级与组织博弈往上走。
- 常见篇幅：80-150 万字为主；30 万字单城；200 万+ 要换图到全国/异界。
- 近邻与区别：与「都市修真」的区别是力量来源（武道/异能 vs 修真）；与「玄幻」的区别是现代都市代入与现代机构。

## 三、读者期待（5-8 条）

1. **现代代入**：手机、外卖、房贷、公司/学校，怪事发生在身边。
2. **隐藏世界**：普通人不知道的武者/异能者社会，有准入规则。
3. **升级可见**：等级、战力、资源、地位，每卷有明确台阶。
4. **打脸**：被看不起的底层/隐藏身份，当场翻盘。
5. **组织博弈**：武馆、学院、协会、国家部门、财团，各有利益。
6. **异能规则**：能力有边界、有代价，不是许愿。
7. **国家/城市尺度**：个人武力不能随便碾压现代秩序，要有约束。

## 四、常见套路（8-12 条）

- **开局**：灵气复苏/秘境开启；主角觉醒异能/得到功法；武馆招生；被霸凌后反杀；隐藏身份回归。
- **破局**：考武馆/学院；加入协会/部门；打比赛；下秘境；抱大腿；经营武馆/公司。
- **升级**：武者段位→异能评级→城市/省级→国家级→异界。
- **打脸/反转**：看不起主角的富二代/师兄被反杀；隐藏大佬现身；反派背后有组织。
- **换图**：单城 → 省/全国 → 秘境/异界 → 人族战场。

## 五、反套路清单（5-8 条）

1. **同类都隐藏身份装逼 → 本书直接考编/登记**：在现代秩序里合法使用异能。风险：爽点变慢，要用任务/比赛补。
2. **同类都靠武力碾压 → 本书靠规则/组织**：用协会规则、合同、舆论限制对手。风险：战斗爽感弱，要设计「合法打脸」。
3. **同类都独狼 → 本书建组织/公司**：武馆、安保公司、异能事务所。风险：经营线会分散，要有明确收益。
4. **同类都拯救世界 → 本书先赚钱/护家人**：大危机是背景，主角先解决自己的问题。风险：格局小，要用暗线补。
5. **同类都无代价异能 → 本书给硬限制**：用一次少一次/需要资源/会暴露。风险：爽感被抵，要给成长补偿。
6. **同类都现代军队降智 → 本书国家力量在线**：个人武力受约束，主角要学会合作。风险：主角不能太无敌，要写博弈。
7. **同类都后宫 → 本书单女主/无CP**：把篇幅给事业与对手。风险：感情线读者流失，要在人设补魅力。

## 六、金手指 / 替代驱动（5-8 种）

| 类型 | 能做什么 | 限制/代价 | 适合的主线动作 |
|:--|:--|:--|:--|
| 武道面板 | 显示功法进度、弱点 | 只显示已知信息；不能直接加战力 | 训练、比赛、战斗 |
| 异能觉醒 | 一种可成长的能力 | 有冷却/消耗/暴露风险 | 战斗、任务、隐藏 |
| 系统/任务 | 发布任务、给奖励 | 任务失败有惩罚；奖励不等于战力 | 升级、经营、组织 |
| 秘境/资源点 | 提供药材/矿石/功法 | 有主；进入有门槛 | 下副本、争夺、交易 |
| 信息差 | 知道谁要什么、哪里有机缘 | 信息会过期；传错会死 | 交易、站队、布局 |
| 无金手指 + 训练/组织 | 靠苦练与人脉 | 慢；上限受天赋限制 | 武馆、学院、军队 |

## 七、雷点 / 毒点（5-8 条）

1. 战力崩：前一卷打不过，后一卷秒杀，没有解释。
2. 现代军队/警察降智，主角随便碾压秩序。
3. 隐藏世界不合理：全世界都知道，只有普通人不知道。
4. 主角莽，明知打不过还送。
5. 异能万能，没有代价与边界。
6. 女性角色工具化，只负责被救/被爱。
7. 地图重复：换城市只是换名字，冲突同构。
8. 后期战力膨胀，现代背景装不下。

## 九、事件种子与分卷阶梯

**事件种子（10-15 条）**

1. 主角在送外卖时觉醒异能，第一单就遇到异能者。
2. 武馆招生，主角被分到最差的班。
3. 城市地下擂台，赢一场能拿资源。
4. 协会登记异能者，主角被迫选边。
5. 富二代用异能欺负人，主角用规则反杀。
6. 秘境开启，主角拿到别人不要的「废资源」。
7. 公司/武馆被砸，主角发现对手有官方背景。
8. 主角的异能会暴露，必须决定是否登记。
9. 全国比赛，主角代表小城市出战。
10. 异界/人族战场开启，现代秩序被打破。
11. 主角的家人被绑架，对手要他的异能。
12. 组织内鬼出卖主角，主角反设局。
13. 终敌不是武力最强，而是掌握规则的人。

**分卷阶梯样例（8 卷）**
