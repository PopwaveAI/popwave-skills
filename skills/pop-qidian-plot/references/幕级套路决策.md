# 幕级套路决策层

> 从《深渊主宰》《诡秘之主》《道诡异仙》三本成品书实证提炼的幕级剧情设计方法论。
> **用途**：plot Step 2 分幕设计时，每幕在"起承转合四段式"之前先走一遍套路决策五步，让每幕自带密度与结构，避免单靠卷纲推演导致剧情平淡。
> **本位**：本文件是 `幕纲-模板.md` 的方法论前置，不替代模板落盘结构。
> **核心纠正**：幕型 = 演绎框架（主线形态），只有 2 种主力；驱动机制不是幕型，是内容引擎。幕里装什么内容由剧情演绎决定，模板不管。

---

## 〇、总览：一幕怎么设计

```
第一步 选演绎框架       ← 2种主力：单主线+支线并织 / 双主线并行+汇合
第二步 选内容引擎       ← 从7种引擎选1主+0-2辅（驱动剧情，不决定框架）
第三步 定卷内递进范式   ← 从3种范式选（线性递增/堆松爆/累积爆）+ 强度档 L1-L5
第四步 定幕内章配比     ← 主线≥45% / 支线15-25% / 过渡10-20% / 信息5-20%
第五步 设计高潮与幕末/卷末钩子 ← 高潮压幕末 + 收益+预告双钩
```

**核心心法**：一幕 = 一个主要事件的主体闭环（起点→手段3-5步→终点），允许留伏笔；每个主要事件解决 = 一次大高潮；一幕可塞支线/过渡/信息章；强力幕可双线主体事件；一卷 = 多个主要事件按强度递进构成。

---

## 第一步 · 选演绎框架（幕型）

**目的**：先定这一幕的**主线排布骨架**，再填充内容。框架决定"怎么排布"，内容由剧情演绎时自然分配，模板不管。

| 框架 | 定义 | 适用 |
|:--|:--|:--|
| **A 单主线 + 支线并织** | 一条主线贯穿，支线插花点缀/埋伏笔/铺人物 | **绝大多数幕**（占比65-80%），主线以战斗/冲突为主体 |
| **B 双主线并行 + 汇合** | 两条主体事件并头推进，各自高潮后汇合放大 | 全书/卷强度顶点幕，双线密度翻倍 |

**选择规则**：
- 默认选框架A。除非本幕是"全书/卷最强爽点引爆点"且剧情天然有两条可并行的主体线，才选框架B。
- 框架A变体：群像增强版（支线接近主线）／蓄力版（支线为主垫落差）／卷末版（主线收束=大高潮）。
- 框架B变体：双身份版／双世界交替版／多线网版。

**决策输出**：写清 `框架{ A/B } + 变体`，这一步决定后续节奏模板。

---

## 第二步 · 选内容引擎（驱动力）

**目的**：明确这一幕剧情靠什么推动。引擎决定"怎么驱动"，不决定框架。

从 7 种内容引擎选，**1 主 + 0-2 辅叠加**：

| 引擎 | 作用 | 典型场景 |
|:--|:--|:--|
| **压力递进** | 连环危机一节扣一节 | 大事件、卷末引爆 |
| **解密/推理** | 信息逐步揭示驱动 | 真相、组织隐秘、伏笔回收 |
| **博弈/智斗** | 多方算计、信息差 | 权谋、布局留筹 |
| **倒计时** | 时间/仪式/检定窗口压迫 | 晋升、限时任务 |
| **收集/成长** | 资源/能力累积 | 升级流底盘 |
| **生存/逃亡** | 威胁追击驱动 | 开局、换地图重置 |
| **认知颠覆** | 真相推翻世界模型 | 反转高潮 |

**注意**：战斗不是独立引擎，是主线主体的默认大头。信息/经营/成长以"穿插"方式融入主线，不单独成幕。**例外**：蓄力幕/开局幕（L1-L2）主线主体可让位给压力/解密引擎，战斗比重降低——首幕藏锋类设计无正面战斗仍成立。

**决策输出**：写清 `主引擎 + 辅引擎`。

---

## 第三步 · 定卷内递进范式

**目的**：明确本幕在卷强度曲线中的位置，避免每幕都一个强度、或全程绷紧。

| 范式 | 结构 | 适用场景 | 注意 |
|:--|:--|:--|:--|
| **线性递增** | 每幕强度+1 → 卷末爆 | 首卷／新地图卷 | 每幕比前一幕强一点，卷末最高 |
| **堆松爆** | 堆强度→松缓冲→卷末爆 | 多线并行卷 | 中段用"松"缓冲，避免全程绷紧 |
| **累积爆** | 信息累积→认知颠覆→终局爆 | 高位逼近卷 | 靠信息差累积，不靠武力强度 |

**卷级铁律**：
- 一卷 4-5 幕（起点头式），一幕 8-12 章 → 一卷 40-60 章（起点主流黄金容量）。
- 蓄力卷与爆发卷交替，**不可连续两卷蓄力**（蓄力卷 0.78-0.88，爆发卷 0.98-0.99）。
- 每卷一个核心功能位，所有幕服务于该功能位。

**决策输出**：写清本幕强度档（L1-L5）+ 本卷采用的递进范式。

---

## 第四步 · 定幕内章配比

**目的**：用配比约束，防止"主线摊薄"或"信息灌水"。

三书收敛的**健康区间**（红线）：

| 章型 | 健康区间 | 红线 |
|:--|:--|:--|
| **主线推进章** | 45-60% | **≥45%，低于则水** |
| **支线章** | 15-25% | ≤25% |
| **过渡章** | 10-20% | ≤20% |
| **信息（设定/世界观）章** | 5-20% | 认知/解密题材可到20%，升级流降到5-8% |

调整规则：
- 蓄力卷 → 支线占比调高（20-25%），主线压到最低。
- 认知颠覆幕 → 信息章提到 20%（设定重构需要）。
- 卷末大高潮幕 → 主线提到 60%+，其余压缩。

**决策输出**：写清本幕各章型章数 + 占比，作为分章的硬约束。

## 第五步 · 设计高潮与幕末/卷末钩子

**目的**：高潮是幕的灵魂，必须主动设计；幕末须指向前方制造追读拉力。

### 5a · 设计高潮

1. **高潮压幕末**（铁律）：给读者"看完这章再睡"的追读理由。几乎不在幕中段爆。
2. **蓄力要足**：全卷/全幕铺垫比幕内铺垫效果好 N 倍。卷末大高潮用全卷蓄力垫落差。
3. **高潮类型**：按赛道选——升级流用"实力跃升+身份反转"；悬疑/认知流用"认知颠覆"；双线流用"双线会合"。
4. **余波立刻开新钩**：高潮后不能停。升级流立刻转新目标（避免爽感通胀）；认知流立刻给"代价/两难"。
5. **多高潮必须错峰**：同一幕多个高潮要不同时间点/不同维度爆，互相绑定会稀释。

### 5b · 设计幕末/卷末钩子

卷末钩子 7 种手法（三书实证），按需选：

| 手法 | 作用 | 代表案例 |
|:--|:--|:--|
| **底盘爆破** | 炸掉安稳，逼主角必须行动 | 身份暴露/组织网爆 |
| **不完全收束** | 留旧悬念给后续，开新地图承诺 | 贝城线留悬念→卷4归来 |
| **收益兑现+新目标预告** | 双钩最稳，既给爽点又开口 | 弑神后+下一波冲击波预告 |
| **锚定下卷主题** | 刚性承诺，明确读者期待 | 卷末直接报下卷名 |
| **预告切换** | 预告新舞台/新地图 | 成神后转恶魔线 |
| **伏笔后置大悬念** | 首卷埋→终局收，全书骨架 | 阿蒙/末日/圣者浩劫 |
| **由外向内递进** | 后期拉力来自内部宿命 | 悬念→设定→人物→命运→环形回扣 |

**铁律**：**幕末/卷末钩子必须指向前方，不能封闭**。最好的钩子是"收益兑现 + 新目标预告"双钩，既是旧闭环又是新开口。

**决策输出**：写清高潮点（章节位置）+ 类型 + 蓄力手段 + 余波处理 + 幕末钩子手法 + 指向的下一幕/下一卷目标 + 跨卷伏笔（早埋哪个、何时收）。

## 坑位清单（拆书发现的常见失败模式）

| 坑 | 表现 | 对策 |
|:--|:--|:--|
| **对手不在场** | 主角单向推进，无多回合对抗，剧情容量不足 | 每个幕设计对手"持续在场"，至少3个对抗单元 |
| **全章同强度** | 全程绷紧或全程松散，读者疲劳或无感 | 用"堆松爆"范式，中段松缓冲 |
| **高潮不到位** | 高潮放幕中或余波冗长 | 高潮压幕末，余波立刻开新钩 |
| **卷末封闭** | 卷末不开口，读者无追读动力 | 卷末必开"收益+预告"双钩 |
| **信息灌水** | 信息章超20%，读者流失 | 信息章压到20%内，装进动作/对话 |
| **伏笔不回收** | 埋了线后面忘了收 | 伏笔台账（剧情累计卡），每个必须回收 |
