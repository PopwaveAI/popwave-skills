## 一、把种子打磨成六要素故事

> 基于 Step 2 选中的种子（用户最满意那条），把六要素从"骨架"打磨成"能讲清楚的故事"。这不是扩写设定，而是**让每个要素都能讲成人话、让读者共鸣**。

### 六要素打磨要点

| 要素 | 打磨要求 |
|:--|:--|
| **世界** | 一句话时代+地点+类型+**尺度**，2-3 句样貌，增量钩子（3 个元素+主钩子）。读者能被吸进去。**尺度（A单世界/B多元位面/C多元宇宙）必须明确——它决定篇幅与力量上限** |
| **力量体系** | 力量源+干预方式+成长阶梯方向+代价。让读者能想象"主角怎么变强" |
| **人物** | 主角三定位（身份/欲望/行动）+金手指方向+关键人物。主角有代入感与弧光 |
| **起因** | 核心矛盾一句话+主角为何开始。有真实动机，读者信服 |
| **经过** | 主线走向+成长路径。有递进阶梯（看得见变强/变懂） |
| **结果** | 主角命运终点+爽点落点。有明确落点，读者有期待 |

### 打磨硬约束

1. **能讲成故事**：每要素一句话让外行听懂，整体能 30 秒讲成一个故事。
2. **有爽感**：起点网文必须是"爽"的——递进阶梯+爽点落点缺一不可。
3. **有画面**：想想这个故事的封面/开篇场景，能不能浮现。
4. **有追读**：读者为什么想看下一章——起因矛盾+结果期待要立住。
