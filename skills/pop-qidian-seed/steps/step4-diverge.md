# Phase 1 · 两轮发散（1g）

> 本文件是 seed v10.0.0 的创意发散步骤——在骨架框架内，**先王道立项，后新奇钩子订枝叶**。
> **骨架先行红线**：1g 必须在 1f 骨架自洽检查通过后执行。先创意后骨架=废流程。
> **v10.0.0 核心重构**：废弃 v8.0.0 的"王道轨5+猎奇轨5并列"双轨结构。根因——并列发散产出的是"10 个新奇身份开头钩子"，区分维度是"身份能力多新奇"=变向猎奇，丢了起点王道爽文的根本（主角主动/升级争霸/爽点/追读）。重构为**两轮**：第一轮产出一批**王道立项**（决定全书根本，不走猎奇），用户选中后第二轮再加**新奇钩子**（只做枝叶，可挂可切）。
> **主剧情路线 = 双递进**（v10.0.0 定义）：①**位置递进**——主角在力量体系坐标系的位置 + 在社会体系的位置，双坐标同步爬升；②**阶段递进**——走向结局的阶段推进（升级/争霸/身份跃迁主轴）。王道立项的分子是"一次跃迁/势力跃升"，不是"能力多怪"。

## 两轮结构总览

```
第一轮：王道立项发散（决定全书根本）
  产出一批王道立项候选卡（起点/终局/主剧情路线+核心矛盾+敌人阶梯）
  → 用户从中选中 1 个（王道尺子 PK）
第二轮：新奇钩子订枝叶（用户选中后）
  围绕选中的王道主干，发散新奇钩子做差异化外壳（身份/金手指/行当/开局势能）
  → 落地校验（忠实主剧情路线+不改主干）→ 金手指公式 → 定稿
```

**核心原则**：
- **王道为骨，猎奇为味**——第一轮只走王道，猎奇不可决定全书剧情内核；猎奇元素最多作为第二轮主干上的一朵花，不是主干本身。
- **第一轮定"这本书的争霸主干和 250 章怎么走"，第二轮定"主角靠什么新奇身份落地这个主干"**。
- 第一轮区分单位是**主剧情路线+争霸形态**，不是身份能力强弱新奇。

## 第一轮：王道立项发散（产出 6-8 个）

> **目标**：产出一批"全书立项级"王道候选——每个先填全三要素 + 两个支撑维度，让用户能在"全书剧情"里挑，而不是在"开头钩子"里挑。

### 王道立项候选卡（三要素 + 两支撑）

每个王道候选是一张卡，结构固定：

```
## 王道候选 N：{主干名}
- 起点：{主角开局身份（最普适模板）+ 初始处境}
- 终局：
  · 最终威胁：{全书最大威胁，一句话，结局导向}
  · 结局状态：{终点位置}
- 主剧情路线：{起点→终局的 3-5 段阶段递进，每段标注双递进}
  · 位置递进：{本段在力量体系坐标系 + 社会体系的位置变化}
  · 阶段递进：{本段走向结局的推进（升级/争霸/身份跃迁）}
- 全书核心矛盾：{一句话，能撑 250 章}
- 敌人阶梯：{≥3 级递进，对应主剧情路线各阶段}
```

**模板示范（深渊主宰式）**：
```
- 起点：前世游戏高手穿越，底层散人开局
- 终局：
  · 最终威胁：圣者浩劫 + 妹妹身上恐惧魔神复苏
  · 结局状态：登临死亡之主
- 主剧情路线：盗贼独行 → 南海海贼王 → 登神 → 神国+地底深渊双身份发育 → 死亡之主
  · 位置递进：凡人小偷 → 海贼王（势力顶端）→ 半神 → 双神格寄主 → 死亡之主（概念顶端）
  · 阶段递进：独行求生 → 争霸一方 → 越神 → 双身份制衡 → 终局
- 全书核心矛盾：凡人如何在诸神陨落的浩劫中，靠独行与双身份发育登临神位
- 敌人阶梯：底层佣兵/盗贼势力 → 各国海权势力 → 诸神势力 → 圣者浩劫/恐惧魔神
```

### 王道立项发散方法

- **从主剧情路线发散**：先想"这本书的争霸/升级主干怎么走"，再倒推起点终局。参考用户意图的最大卖点 + 市场校准的借鉴点/避雷点，在骨架坐标系内学主流结构、换血肉。
- **差异化要求（第一轮硬约束）**：候选之间必须在**主剧情路线 + 争霸形态**上实质不同（凡人升级逆袭 / 无根争霸逐鹿 / 扮猪吃虎碾压 / 种田经营滚雪球 / 宗门修仙攀爬…）。不是靠身份能力强弱新奇区分。
- **禁用新奇身份/行当/金手指当卖点（第一轮硬约束）**：主角身份只填最普适模板（底层散人/小人物/凡人胚子），新奇身份（读心者/券商/审计师）一律不出现——留给第二轮。谁把"身份多新奇"当候选卖点=不合格，回炉重发。

### 王道立项判定（第一轮质量门禁）

对每个候选执行 **王道续航判定**（5 项全过才进 PK）：

| 项 | 问题 | 通过标准 |
|:--|:--|:--|
| ① 主干可撑 | 核心矛盾能撑 250 章吗？ | 一句矛盾能自然展开成多条可升级冲突链（不是一口气写完的悬念） |
| ② 主角主动 | 主角靠主动行为驱动，不靠世界压迫？ | 主剧情路线每段都有主角的决策/行动/争霸，不是被动挨打 |
| ③ 双递进清晰 | 主剧情路线有位置递进+阶段递进吗？ | 每段能说清力量/社会位置变化 + 走向结局的推进 |
| ④ 敌人可递进 | 敌人阶梯能逐级升级吗？ | ≥3 级，每级有具体对象，量级递进脉络清晰 |
| ⑤ 终局王道式 | 结局是"争霸/登顶/跃迁"式可达目标？ | 终局是王道式终点（非"概念惊艳但不知后续写什么"） |

任一不通过：回炉重发该候选。

### 王道候选 PK + 推荐

对全过的候选逐项 PK（**王道尺子**，禁以新奇度加分）：

| 维度 | 候选 A | 候选 B | ... |
|:--|:--|:--|:--|
| 主干爽感结构（升级/争霸/逆袭/经营） | | | |
| 主角主动性 | | | |
| 双递进清晰度（位置+阶段） | | | |
| 长线续航（250 章+，核心矛盾+敌人阶梯判定） | | | |
| 骨架对齐度（坐标系+引擎） | | | |
| 王道差异化（同赛道 100 本中的争霸形态区分度） | | | |
| 执行难度 | | | |

推荐 1 个 + 理由 + 吸收败者强点 + 淘汰项。**推荐方案必须满足**：主剧情路线一句话说清且主角主动明确；终局是王道式可达目标；不把"世界压迫"当主角驱动；在力量体系.md+动力引擎.md框架内。

**用户确认 1 个后方可进第二轮。**

## 第二轮：新奇钩子订枝叶（用户选中后）

> **目标**：围绕选中的王道主干，发散新奇钩子做差异化外壳——让这本书"抓眼"但不改"骨头"。

### 新奇钩子发散维度

围绕选中的王道候选卡，发散并填写：

| 维度 | 内容 | 说明 |
|:--|:--|:--|
| 主角身份 | 新奇身份/行当（读心者/篡忆师/券商/骗子教父…） | 让主角"落地"第一轮的主剧情路线 |
| 金手指形态 | 梗×机制×限制 | 金手指=主角的专属加速器 |
| 行当错位 | 身份与环境的错位搭配 | 开局势能/反差感 |
| 开局势能 | 开局身份落地的具体场景 | 第一印象钩子 |

**落地校验（第二轮硬约束）**：
- 每个新奇钩子必须能**忠实落地选中的主剧情路线**——身份/金手指/行当不能改变三要素主干（起点/终局/主剧情路线）。
- 钩子只在主干上开花，可挂可切；若某钩子推导出的故事会偏离选中主干，淘汰该钩子。

### 金手指设计公式（保留 v7.0.0，落位第二轮）

```
金手指 = 梗 × 机制 × 限制
```

| 要素 | 作用 | 来源 |
|:--|:--|:--|
| 梗 | 提供形式——金手指"长什么样" | 燃料 B（跨赛道机制）或用户输入 |
| 机制 | 提供动力——金手指"怎么运转" | 碰撞结果中的核心爽感机制 |
| 限制 | 提供张力——金手指"为什么不能随便用" | 燃料 C（现实矛盾）或碰撞中的决策困境 |

**骨架框架约束**：金手指是助力，不能取消坐标系本身的意义；金手指是引擎加速器，不是引擎本身。

**反模式检查**（4 种必须避免）：纯翻译器 / 纯正向循环 / 无使用场景限制 / 成长速度过慢。

### 新奇钩子的质量门禁（三眼法，保留 v7.0.0）

| 眼 | 问题 | 通过标准 |
|:--|:--|:--|
| 第一眼：画面 | 读完概念，脑子里是否立刻浮现一个具体场景？ | 能描述出 1 个具体画面（谁在哪做什么，有冲突） |
| 第二眼：限制 | 主角/金手指是否有有意义的约束？ | 有明确的代价/限制/博弈条件 |
| 第三眼：落地 | 这个钩子能忠实落地第一轮的主剧情路线吗？ | 不改变起点/终局/主剧情路线，且能推导出逐段剧情 |

任何一眼不通过：淘汰该钩子，回炉补一个。
