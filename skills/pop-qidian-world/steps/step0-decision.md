# Step 0 - 交互式世界决策+IP调研门禁

> **本步骤定位**：world的设计大脑。在世界设定生成前，先验证IP调研充分性（条件加载），再通过2轮交互采集用户对世界结构和危机体系的偏好，产出`世界决策表.md`作为Step 1-3的硬输入。
> **核心原则**：给选项不给空白——每轮提供2-3个结构化选项+1个自定义入口。选项必须标注好坏标准，让用户知道每个选择的质量后果。

## 前置条件

- Phase 2 seed完成
- 立项/01-立项PRD.md 齐全（seed六要素立项，含「世界+力量体系」方向句）
- 设计/力量体系.md + 动力引擎.md（Step 0.5已展开，Step 0进行时如未展开则先展开）
- IP调研-{IP名}.md（条件加载，用户声明IP时必须存在）

## 产出

`设计/世界决策表.md`——后续世界设定生成的硬输入

## 0a · IP调研充分性验证门禁（条件加载）

> **触发条件**：用户意图.md七维底牌①声明了IP方向（如"DND+战锤40K"），或立项/01-立项PRD.md世界方向句增量钩子包含IP元素时触发。无IP声明时跳过此步。
> **门禁原理**：world的7维度推演需要消费IP设定（IP物理法则/IP战斗系统/IP政治经济/IP民俗/IP地理/IP势力/IP危机）。agent如果不懂IP本体，推导出来的就是"AI幻觉版IP"而非真实IP。IP调研门禁和decon-lite原文存在性门禁同理——禁止基于记忆编造。

### 验证3维度

| 维度 | 判断标准 | 不通过= |
|:--|:--|:--|
| **覆盖度** | IP调研是否覆盖world需要的7维度（物理规则/战斗系统/政治经济/民俗/地理/势力/危机） | 报错回Phase 0补调研 |
| **深度** | 是否到可消费级别（"费伦是城邦联盟制，深水城由面具贵族议会统治"可消费；"DND有费伦"不可消费） | 报错回Phase 0补调研 |
| **准确性** | 是否基于真实IP资料（Wiki/设定集/原文），不是agent记忆重构 | 报错回Phase 0用WebSearch补真实资料 |

### 验证流程

1. 检查用户意图.md七维底牌①是否声明IP方向
2. 如声明IP→检查`素材/IP调研-{IP名}.md`是否存在
3. 如存在→验证7维度覆盖+可消费深度+基于真实资料
4. 如不存在或不充分→报错回Phase 0补调研，**不在world层自行编造IP设定**

> **红线**：world禁止基于agent记忆编造IP设定。IP元素必须从IP调研-{IP名}.md消费。这条红线和decon-lite原文存在性门禁同理——"基于记忆重构而非原文执行"这个坑踩过，IP调研同理。

## W1 世界结构偏好（核心轮·必答）

**两层结构**：W1先定全书世界格局（W1a·宪法级·广度），再切首卷开局舞台（W1b·施工级·深度）。**广度先行圈定，深度后置深化**——边境公国只是全书世界的一格，不是全书世界的边界。把握不好"边境公国只是起点、不是整个世界"，就是本次要修的核心坑。

**底牌消费**：设计/力量体系.md（坐标系阶位顶点=扩张阶梯顶点）+ 立项/01-立项PRD.md（世界+力量体系方向句）+ IP调研（条件加载，IP地理/势力）

**Agent动作**：
0. **读世界尺度**：从 立项/01-立项PRD.md 读 seed 定的世界尺度（A单世界/B多元位面/C多元宇宙）——它决定扩张阶梯顶点。若 PRD 未定尺度，回 seed 补，禁止自己猜
1. **W1a 全书世界格局**：读力量体系.md坐标系（阶位顶点）→ 定全书版图（边境公国在世界哪一角）+ 势力格局（世界级势力谁在争）+ 扩张阶梯（据点到顶点，顶点=世界尺度决定，对齐阶位）。这是宪法级——定了全书有效
2. **W1b 首卷开局舞台**：从全书格局切出第一卷地图（核心舞台+外围区域）。这是施工级——只服务于第一卷
3. 生成3个世界结构方案（见下），每个方案都标注全书版图+扩张阶梯+首卷舞台

### 好坏标准

| 层级 | 维度 | 好世界结构 | 坏世界结构 |
|:--|:--|:--|:--|
| W1a 全书 | 全书版图 | 边境公国（起点）在世界版图中有明确位置，世界级势力/终点存在 | 只有首卷舞台，没有全书版图（起点=整个世界） |
| W1a 全书 | 扩张阶梯 | 据点→区域→王国→大陆→顶点（顶点=seed世界尺度决定：A单世界=世界顶点/B多元位面=位面顶点/C多元宇宙=诸天顶点），对齐力量体系阶位，世界尺度匹配力量尺度 | 世界太小，力量到顶了世界还是个小公国（尺度崩坏） |
| W1a 全书 | 势力格局 | 世界级势力有谁在争、谁能到阶梯顶点 | 只有首卷能碰到的势力 |
| W1b 首卷 | 空间叙事 | 首卷舞台每个区域有戏剧潜力（资源争夺/势力交叉/信息差/危险梯度） | 地名列表（只有名字没有叙事价值） |
| W1b 首卷 | 坐标系映射 | 首卷舞台空间分布映射首卷阶位区间（高阶位区=危险区/核心区） | 空间和力量体系脱节 |
| 两层级 | 主角适配 | 地图结构匹配主角移动模式 | 地图和主角行为模式矛盾 |
| 两层级 | 区域差异 | 区域间有明确差异（资源/法则/势力/氛围全不同） | 所有区域长得一样 |

### 选项生成规则

**方案A：据点型**（从据点向外扩张，起点=首卷舞台）
→ 适合：主角欲望是"扎根/经营/保护"，坐标系是层级嵌套型
→ **全书版图（W1a）**：边境公国所在板块→周边王国→大陆→顶点（顶点=seed世界尺度决定），据点逐级扩张
→ **扩张阶梯（W1a）**：据点→区域板块→王国→大陆→顶点（顶点=seed世界尺度决定，对齐阶位）
→ **首卷舞台（W1b）**：1核心城+3-5外围区域，阶层从内到外递减
→ 势力：层数4层（城内3层+外围1层）
→ 危机：扩张型（向外探索=接触更高阶位）
→ 空间叙事：从小处着眼逐渐展开世界

**方案B：游击型**（多城+道路，起点=移动叙事）
→ 适合：主角欲望是"逃离/追查/流浪"，坐标系是线性推进型
→ **全书版图（W1a）**：主角沿路线逐级深入世界，终点=世界核心/终极真相所在
→ **扩张阶梯（W1a）**：起点区域→沿途节点→世界腹地→顶点（顶点=seed世界尺度决定，对齐阶位）
→ **首卷舞台（W1b）**：3-5城+连接道路，每城对应不同阶位区间
→ 势力：层数3-4层（每城1-2层势力）
→ 危机：追猎型（移动中不断遭遇不同层面危机）
→ 空间叙事：公路片式，每城一个完整弧线

**方案C：争霸型**（棋盘式多势力，起点=首卷棋盘一角）
→ 适合：主角欲望是"征服/改变/掌权"，坐标系是平行竞争型
→ **全书版图（W1a）**：多势力棋盘从首卷区域延展到全书大陆级/世界级，逐级扩盘
→ **扩张阶梯（W1a）**：区域棋盘→王国棋盘→大陆棋盘→顶点棋盘（顶点=seed世界尺度决定，对齐阶位）
→ **首卷舞台（W1b）**：1大区域+5-8子区域，多势力棋盘交叉
→ 势力：层数4层（每子区域1-2层，跨区域势力联盟）
→ 危机：博弈型（多势力制衡+坐标系天花板压迫）
→ 空间叙事：棋盘博弈，势力交叉产生冲突

**输出格式**：
```
## W1 世界结构偏好

基于{坐标系类型}+{主角移动模式}，提供3个世界结构方案：

A) {方案A名}
   → 全书版图：{W1a·边境公国在世界哪一角+世界级势力/终点}
   → 扩张阶梯：{W1a·据点到顶点的升级路径（顶点=seed世界尺度决定），对齐阶位}
   → 首卷舞台：{W1b·第一卷地图布局}
   → 势力：{层数+数量}
   → 危机：{类型}
   → 空间叙事：{策略}
   → 好坏标准对照：{该方案在好坏标准维度的表现}

B) {方案B名}
   → ...

C) {方案C名}
   → ...

请选择，或描述你想要的世界结构。
```

**影响标注**：W1a全书格局定下后，Step 1的地图空间化（维度5·3层地图）和势力具名化（维度6·3层势力）都基于此；各卷切片.md按"每卷扩张到阶梯哪一格"导航。W1b首卷舞台只约束第一卷。plot的分幕走向和write的空间尺度也基于此。

## W2 危机体系偏好（可选轮·可跳过）

**底牌消费**：W1选择 + 动力引擎.md引擎演化节点 + 立项/01-立项PRD.md人物方向句（金手指限制，由character展开）

**Agent动作**：
1. 基于选定的世界结构，从动力引擎.md引擎三层面推导危机体系方案
2. 每个方案标注：终极危机/阶段性危机/危机驱动机制

### 好坏标准

| 维度 | 好危机体系 | 坏危机体系 |
|:--|:--|---|
| 引擎对齐 | 危机是引擎运转的必然阻力（坐标系内压/引擎代价/金手指限制三层面） | 随机外部威胁（和引擎无关） |
| 全书覆盖 | 1条终极+2-3条阶段性，分卷爆发形成危机链 | 只有第一卷的危机 |
| 升级路径 | 危机会恶化（不解决越来越糟），有明确升级节点 | 一次性事件，解决就没了 |
| 层面归属 | 每条危机标注属于哪个层面 | 不知道是坐标系问题还是引擎代价 |

### 选项生成规则

**方案A：引擎代价主导型**
→ 终极危机：引擎闭环断裂（代价清算）
→ 阶段性危机：每卷爆发一种引擎代价（通用代价→群体差异→代价突变）
→ 驱动机制：主角越爬越高，代价越大

**方案B：坐标系内压主导型**
→ 终极危机：坐标系顶层对决（强者碾压）
→ 阶段性危机：每卷突破一层阶位壁垒
→ 驱动机制：上面有人压制，不爬就被踩

**方案C：金手指限制主导型**
→ 终极危机：金手指终局抉择（代价转嫁到极致）
→ 阶段性危机：金手指限制逐卷暴露
→ 驱动机制：金手指是双刃剑，越用越危险

**跳过规则**：用户说"跳过"或"默认"→ agent按动力引擎.md的引擎节点+三层面自动分配

## 红线

1. **每轮必须给选项**——必须给2-3个结构化选项，不能开放式提问
2. **每轮必须有自定义入口**——选项末尾必须有"或描述你想要的XXX"
3. **W1必须广度先行**——先定W1a全书世界格局（版图+扩张阶梯对齐阶位），再切W1b首卷舞台。禁止只给首卷舞台当全书世界（起点=整个世界=尺度崩坏坑）
4. **选项必须在骨架约束内**——世界结构必须匹配力量体系的空间需求
5. **选项必须标注好坏标准**——让用户知道每个选择的质量后果
6. **核心轮不可跳过**——W1必答，W2可跳过
7. **决策表是世界设定生成的硬输入**——Step 1-3消费决策表展开，不另起炉灶
