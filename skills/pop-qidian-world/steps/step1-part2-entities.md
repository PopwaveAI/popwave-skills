## 维度5 · 地理建筑（人活在哪里）

> **定位**：因果链第五环。从维度1物理规则+维度2战斗系统+维度3政治经济+维度4民俗涌现地理建筑。地图是势力的底座——维度6势力扎根在维度5地图上。
> **3层纵深**：世界地图（整体轮廓）→ 区域地图（内部展开）→ 核心舞台（第一卷详细）。300万字小说需要3层地图，不是1张扁平区域表。
> **消费源**：维度1物理规则 + 维度2战斗系统 + 维度3政治经济 + 维度4民俗 + 1a+世界设计原则 + 力量体系.md主养成线阶位 + 世界决策表W1（地图布局）+ IP调研（条件加载）

| IP准确 | IP地理从IP调研消费 | agent凭记忆编造IP地名 |

### 达成方法

从物理规则推导空间格局→从战斗系统推导军事/防御格局→从政治经济推导人口/城市分布→从民俗推导建筑风格→3层展开：世界地图轮廓→区域地图展开→第一卷核心舞台详细设计。

#### 5a · 世界地图轮廓（整体长什么样）

> 整个世界的大地图。不是6个地名——是一个大陆/世界的地理全貌。这张地图决定后续所有区域的坐标关系和空间格局。

| 要素 | 内容 | 回溯原则 | 因果来源 |
|:--|:--|:--|:--|
| **地理分区** | 大陆分几个大区域/州/国？每区特征？ | 原则N | 物理规则→地形分区 |
| **主要地形** | 山脉/河流/平原/荒漠/海洋的分布 | 原则N | 物理规则→地形 |
| **气候带** | 不同区域的气候特征 | 原则N | 物理规则→气候 |
| **人口/修士分布** | 哪里密集/稀少？安全区vs危险区？ | 原则N | 政治经济→人口分布 |
| **交通干线** | 主要道路/航线/传送阵/商路 | 原则N | 政治经济→贸易路线 |
| **空间格局** | 安全区/危险区/禁区的整体分布 | 原则N | 物理规则→空间壁垒 |

#### 5b · 区域地图展开（每区域里面有什么）

> 每个区域内部展开。一个区域不是一行表格——里面有子区域、城市据点、地标、危险区。每个区域要能撑起20-40万字叙事。

| 区域 | 子区域 | 城市据点 | 关键地标 | 危险区 | 资源产地 | 区域间通道 | 回溯原则 |
|:--|:--|:--|:--|:--|:--|:--|:--|
| 区域A | 子区域1/2 | 城市1/2 | 秘境/古战场/灵脉 | 妖兽领地/禁区 | 矿脉/药园 | 通往区域B | 原则N |

#### 5c · 第一卷核心舞台（40万字在哪里写）

> 第一卷主角活动区域的详细地图。城区怎么分？势力地盘在哪？地标建筑在哪？地下世界长什么样？这张地图要足够详细，让plot skill能直接在地图上排布剧情。

| 要素 | 内容 | 回溯原则 | 叙事功能 |
|:--|:--|:--|:--|
| **城区分布** | 城分几个区？（散修区/商业区/势力区/禁区） | 原则N | 不同区=不同冲突场 |
| **势力地盘** | 各势力控制哪些街区？ | 原则N | 势力地盘=冲突边界 |
| **地标建筑** | 擂台/黑市/任务板/城主府/情报站 位置 | 原则N | 地标=剧情节点 |
| **地下世界** | 地下水道/暗市/隐藏通道/废弃矿道 | 原则N | 秘密行动空间 |
| **周边地形** | 城墙外/山脉外围/据点/哨站 | 原则N | 外出冒险舞台 |
| **空间叙事价值** | 主角能干什么（日常/冲突/秘密/逃亡路线） | 原则N | plot直接消费 |

## 维度6 · 势力·人物·关系（谁在活怎么争）

> **定位**：因果链第六环。从维度3政治经济+维度5地理涌现势力人物——政治经济决定了权力格局，地理决定了势力分布，两者交叉产生势力。势力=同一种攀登方式的群体+政治经济实体。问"政治经济+地理下，谁在活？他们怎么争？"
> **3层纵深**：世界势力格局（整体骨架）→ 各层势力展开（每层具名+代表人物）→ 第一卷核心势力+关系网络（详细）。300万字小说需要3层势力，不是1张扁平4层表。
> **边界**：world只做势力组织+代表人物（一句话锚定：谁当家/谁代表），不设计完整角色卡——全部"人"的深度塑造归 character（角色库+全书角色版图消费本维度代表人物填人）。
> **附着关系**：势力扎根在维度5地图上——6a格局对应5a世界地图，6b展开对应5b区域地图，6c核心对应5c核心舞台。产出顺序：地图→势力→代表人物→关系，后者依附前者。地图是底座，势力扎根地图，代表人物让势力不抽象，关系连接势力。
> **消费源**：维度3政治经济（权力结构+社会分层）+ 维度5地理（5a世界地图+5b区域地图+5c核心舞台）+ 1a+世界设计原则（对抗相关原则）+ 动力引擎.md引擎组成3（四类攀登群体）+ 世界决策表W1（势力层数）+ IP调研（条件加载，IP势力）

### 好坏标准

| 维度 | 好 | 坏 |
|:--|:--|:--|
| 因果涌现 | 势力从政治经济+地理因果推导 | 凭空设计势力 |
| 3层纵深 | 世界格局→各层展开→核心+人物+关系，每层独立产出 | 只有1层扁平4层表 |
| 地图附着 | 势力地盘扎根在维度5地图上（6a↔5a/6b↔5b/6c↔5c） | 势力和地图脱节 |
| 引擎溯源 | 每个势力标注攀登方式来源（回溯引擎组成3） | 脱离引擎凭空设计 |
| 全层覆盖 | 4层全具名（底层/中层/高层/顶层+散人） | 只做前2层 |
| 人物具象 | 每层势力有代表人物（名字+欲望+设定角色） | 只有势力名没有人物 |
| 关系网络 | 纵向（跨层）+横向（同层）关系都设计 | 只有纵向无横向 |
| 弱点可利用 | 弱点是结构性的（攀登方式导致的必然弱点） | 弱点是随机编的 |
| 碰撞设计 | 每层标注碰撞卷 | 势力平行存在不交叉 |

### 达成方法

从引擎组成3四类群体→每类1层势力→从维度3政治经济推导势力权力定位→从维度5地理推导势力分布（地盘扎根地图）→3层展开：世界势力格局（骨架）→各层势力展开（具名+代表人物）→第一卷核心势力+人物+关系网络（详细）。

#### 6a · 世界势力格局（整体权力骨架）

> 整个世界的势力层级分布。势力扎根在5a世界地图上——哪个大区域是哪个层级势力的地盘。这一层定的是"世界的权力骨架"，不具名具体势力，定的是层的格局。
> **产出顺序**：先有5a地图→6a在地图上划分势力层的地盘。

| 势力层 | 攀登方式来源 | 总体特征 | 地盘分布（对应5a地理分区） | 跨层关系（纵向） | 层内关系（横向） | 碰撞卷 |
|:--|:--|:--|:--|:--|:--|:--|
| 第1层·底层 | 没资源的人怎么爬 | （这一层势力总体长什么样） | （占5a哪些区域） | 被中层剥削 | 同层互争残杀 | 第一卷 |
| 第2层·中层 | 有资源的人怎么爬 | | | 受高层压制 | 同层竞争资源 | 第一卷/第二卷 |
| 第3层·高层 | 有资源的人怎么爬（进阶） | | | 受顶层制约 | 同层结盟/博弈 | 第二卷/第三卷 |
| 第4层·顶层 | 爬到顶的人怎么维持 | | | 规则制定者 | 同层零和博弈 | 终卷 |
| 散人/变节者 | 掉下来的人怎么办 | | | 各卷穿插 | 无固定阵营 | 各卷 |

#### 6b · 各层势力展开（每层具名+代表人物）

> 每层势力内部展开。一层势力不是一行——里面有多个具名势力、内部派系、代表人物。扎根在5b区域地图上——每个势力的地盘精确到子区域/城市。
> **产出顺序**：先有5b区域地图→6b在区域里放置具名势力+代表人物。

| 势力层 | 具名势力 | 内部派系/结构 | 代表人物 | 控制资源 | 地盘（对应5b子区域/城市） | 弱点/裂缝（结构性） | 回溯原则 |
|:--|:--|:--|:--|:--|:--|:--|:--|
| 第1层·底层 | （势力名） | （派系/组织结构） | （人物名+一句话定位） | | （5b哪个子区域） | （攀登方式的必然弱点） | 原则N |
| 第2层·中层 | | | | | | | |
| 第3层·高层 | | | | | | | |
| 第4层·顶层 | | | | | | | |
| 散人/变节者 | | | | | | | |

> **要求**：每层至少1-2个具名势力，每个势力至少1个代表人物。弱点必须是攀登方式的结构性弱点（资源型→资源依赖/垄断型→僵化/野路子→资源匮乏）。

#### 6c · 第一卷核心势力+人物+关系网络（详细）

> 第一卷出场势力的详细设计。扎根在5c核心舞台上——势力地盘精确到城区/地标。这一层要足够详细，让plot skill能直接在势力关系网上排布冲突。
> **产出顺序**：先有5c核心舞台→6c在舞台上放置核心势力+人物+关系网络。

**核心势力详细表**

| 具名势力 | 势力层 | 地盘（对应5c城区/地标） | 代表人物 | 核心成员 | 控制资源 | 弱点 | 碰撞卷 |
|:--|:--|:--|:--|:--|:--|:--|:--|
| （势力名） | 第N层 | （5c哪个城区） | （人物名） | （核心成员） | | | 第一卷 |

**核心人物表**

> 人物是势力的具象化代表。每个人物标注所属势力+攀登方式代表+设定角色（提供资源/提供信息/设置障碍/作为对手）。

| 人物 | 所属势力 | 势力层 | 攀登方式代表 | 核心欲望 | 设定角色 | 量级（阶位） | 预计出场卷 |
|:--|:--|:--|:--|:--|:--|:--|:--|
| （人物名） | （势力名） | 第N层 | （引擎组成3） | （一句话） | 提供资源/信息/障碍/对手 | 阶位N | 第一卷 |

**关系网络（横向+纵向）**

> 关系是最后的产出——依附于势力（纵向）和人物（横向）。纵向=跨层势力的权力关系，横向=同层势力/人物的博弈关系。

| 关系类型 | 主体A | 主体B | 关系性质 | 张力来源 | 叙事功能 |
|:--|:--|:--|:--|:--|:--|
| **纵向**（跨层） | （上层势力/人物） | （下层势力/人物） | 剥削/依附/压制/反叛/庇护 | （权力不对等产生什么冲突） | （给主角什么可利用的裂缝） |
| **横向**（同层） | （同层势力/人物A） | （同层势力/人物B） | 竞争/联盟/贸易/敌对/暗合作 | （资源争夺/利益交叉产生什么冲突） | （给主角什么可介入的空隙） |

> **关键**：关系网络是plot消费的核心——纵向关系提供"以下犯上"的攀爬通道，横向关系提供"渔翁得利"的博弈空间。没有关系网络的势力是孤岛，plot无法排布冲突。
