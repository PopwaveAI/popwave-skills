# pop-snow-opening

> 开篇把关＝卷1 前3章的结构与情绪设计闸。当前版本 v1.0.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。
> 源：本 skill 从 Mirror 创作专家 04-开篇专家（镜界 06-黄金三章）方法论提炼，落进 snow 卷循环作"卷1 开篇闸口"，非原文直贴。

***

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。
- **Pack**：缺口足够才取材，query 自生成；来源 **wiki 站 https://wiki.popwave.cn** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query / 回传 ≤30KB，超限截断仅留结论区。
- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版,不越权定终局。
- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

## 做什么

**开篇不是"把前3章讲清楚"，是"前3章让读者对主角产生牵挂"。** 堆情绪，不堆冲突。核心是三件事建成不可放下的阅读欲：**落差被看见 → 特权被握紧 → 小账被还掉、新标被立下**。

本 skill 管"卷1 前3章的结构与情绪曲线设计＋开篇把关"，是**卷1 专用的开篇闸口**，在 stage 卷一舞台就绪后、前3章章纲(2d)之前跑一次。产出开篇设计档＋把**开篇承诺基线**写入全书日志，供 outline/write/plot 引用与校验。

| 项  | 内容 |
| :- | :--- |
| 输入 | 融合立项稿(seed产物：爽点兑现表/敌人阶梯/主角标签与内核)＋文风DNA锚定＋卷一舞台(`设计/卷舞台/卷N-舞台.md`或舞台起步)＋卷进度表(卷1向) |
| 输出 | `卷纲/开篇设计.md`（前3章情绪曲线＋每章落差/特权/小账与新标＋300字开篇＋自检12项＋红线扫描）＋ 开篇承诺基线写入 `全书日志.md` |
| 下游 | pop-snow-outline（ch001-ch003 章纲依托开篇设计）→ pop-snow-write（按情绪曲线渲染）→ pop-snow-plot（卷进度表"距终点贡献"回头校验开篇立的标是否兑现） |
| 重跑 | 仅卷1 前3章未写时设计；若前3章已写，只做**开篇复盘诊断**（反模式扫描＋承诺基线补记） |

**执行模式**：主agent直执。开篇设计是创作判断，不经子agent。

## 怎么操作（SOP全内联）

### Step 0：接收自检

判断本趟是"设计"还是"复盘"：

- **设计态**：`正文/` 无 ch001（卷1 前3章未写）→ 做前3章开篇设计。
- **复盘态**：ch001 已写 → 停止新设计，只做**开篇诊断**：对已写前3章跑自检12项＋反模式诊断表，给出打回/保留结论与补改点，并补记开篇承诺基线入全书日志。

### Step 1：输入加载（只看这几样，零分叉）

- **立项**：`立项/00-融合立项稿14维.md` — 重点取 **爽点兑现表**（读者图什么/前三卷必须排上的爽点）＋ **敌人阶梯**（首个对手是谁、在哪爆）＋ 主角标签/内核。
- **文风**：文风DNA锚定（有则带，无则不卡）。
- **舞台**：`设计/卷舞台/卷N-舞台.md`（或舞台起步）— 开局的地点/势力/当前局势。
- **走向**：卷进度表（卷1 向主角要推到哪，开篇不能与卷轴矛盾）。

设定/人物卡/元素卡库＝字典，只在"落差锚点选谁、特权信息挂谁"时按需点开，不整体搬进上下文。

### Step 2：前3章结构与情绪曲线

**三章递进情绪**（本 skill 的骨架）：
```
第1章   第2章   第3章
同情    焦虑    满足+期待
落差被看见 特权被握紧  小账被收回+新标被立下
```

**第1章 · 展现落差**（让读者同情主角，想看他翻身）：
- **落差三要素**必齐：
  1. **锚点**＝主角坠落前最高光时刻（一个具体画面，地位需"合法"：天赋/家世/努力构成的合法性）
  2. **现状**＝坠落后的最低谷（一个具体画面，且"不该如此"：不是主角活该）
  3. **对比触发器**＝锚点与现状在**同一场景正面碰撞**
- 落差公式：同情 ∝ f(过去的地位 − 现在的处境, 地位的合法性)。
- 三种落差模式选一：天赋坠落（玄幻仙侠）/ 身份颠覆（都市历史）/ 认知反转（悬疑系统流）。

**第2章 · 给特权信息**（让读者焦虑，迫想知道下一步；不是把主角写越惨）：
- 四种特权信息四选一：**身份特权**（读者知道真身份剧中人不知）/ **未来特权**（读者或主角知即将发生）/ **能力特权**（读者见主角得金手指剧中人以为废物）/ **视角特权**（读者见反派密谋主角不知）。
- **必须在一个具体事件中展示**，不是旁白介绍；金手指必须以**行动效果**展现，不靠属性面板。
- 特权信息最好与第1章落差直接关联。
- 制造最少一层"观众知情、角色不知情"的结构。

**第3章 · 还小账，立新标**（让读者满足＋期待；不贪心铺世界观）：
- **还小账**三选一：力量验证（用金手指完成一件小事）/ 预判兑现（前面铺垫的冲突第一次回应）/ 选择宣示（主角主动做了个决定）。
- **立新标**三选一：时间标（如"三年之约"）/ 距离标（如"先找到下一味药材"）/ 状态标（如"三个月内恢复三段斗之力"）。**新目标必须 3-10 章内可达成。**
- 第3章禁开新地图/新势力/新世界观线，先把前两章的账还了。

### Step 3：开篇 300 字

- 前200字主角出现并做第一个可见行动。
- 前300字给反常/落差/危险/利益/误会**至少一种钩子**；最后一句话是戏剧性反转。
- 800字内触发核心冲突；**不先铺世界观、履历、体系名词**。
- 第1章场景 ≤2 个，互动人物 ≤3 个。

### Step 4：红线扫描（任一命中＝打回）

1. **300字内无主角**（第1章前200字主角未出现/未行动）
2. **第1章超2个场景**或互动人物超3个
3. **金手指靠旁白介绍**（"他有XX系统"而非"在XX场景无意用出XX能力"）
4. **第3章开新地图/推世界观**（前两章账没还就铺世界）
5. **章末无钩子**（每章最后一句没制造"想知道后来"的冲动）

### Step 5：开篇承诺基线（1+1>2 的关键）

设计定案后，把**可被后续追溯的承诺**写入 `全书日志.md`（替换式更新"当前态·只记活跃"区）：

- **第3章立下的新标**（时间/距离/状态）——后续卷 outline 引用、plot 卷进度表在预期章节校验兑现。
- **已给的特权信息类型**——备忘它在第几章被摆上台面、何时该揭开/兑现。
- **第1章落差的对比触发器画面**——后续"打脸/翻身"高潮的回放锚点。

**这条路让开篇从"只把关一次"变成"全书承诺基线"**：不只检查前3章合格，还给整本书留下可追踪的期待线，后文每章 outline 都能引用它。

### Step 6：存档

**存档前先过资料门**：开篇若进入全新场景/地域且 `素材/采风/` 没对应考据/质感料→先派 research 采一点（落 `素材/采风/`）再存档；熟悉场景不查。→ 写 `卷纲/开篇设计.md`（模板 `templates/开篇设计.tpl.md`）。**存档后半步=去AI味**：`python skills/pop-snow-pipeline/scripts/deai_gate.py 卷纲/开篇设计.md --profile doc --json`——WARN 定位自查、机械项 `--fix`，结果一行 `去AI味:开篇设计|PASS` 或 `WARN×N`。同时按 Step 5 更新 `全书日志.md`。

**Step 质量门**：三章情绪曲线已成｜落差三要素/特权四选一/小账三选一+新标三选一已定｜300字开篇已含主角+钩子+反转｜自检12项逐条核｜红线5项无命中｜承诺基线已入全书日志。

```
开篇设计《{书名}》卷1 前3章

情绪曲线：第1章 同情(落差被看见) → 第2章 焦虑(特权被握紧) → 第3章 满足+期待(小账收回+新标立下)

第1章 落差
  落差模式：{天赋坠落/身份颠覆/认知反转}
  锚点：{最高光具体画面·合法性}
  现状：{最低谷具体画面·不该如此}
  对比触发器：{锚点与现状同场碰撞的场景}

第2章 特权信息
  类型：{身份/未来/能力/视角·四选一}
  具体事件：{在一个事件中展示，非旁白}
  与第1章关联：{是否承接落差}
  观众知情/角色不知情：{谁知谁不知}

第3章 还小账+立新标
  还小账：{力量验证/预判兑现/选择宣示}
  立新标：{时间标/距离标/状态标}＋{具体目标，3-10章内可达}

开篇300字：{前200字主角+首行动}／{前300字钩子}／{结尾反转}

红线扫描：{5项逐一 ✅/❌，任一❌=打回}
自检12项：{第1章6/第2章5/第3章5 → 见 SKILL.md，逐条 ✅/❌}
反模式诊断：{无/命中：症状→诊断→方案}

承诺基线（写入全书日志）：
  新标：{时间/距离/状态标·目标}
  特权信息备忘：{已给哪种·何时揭开}
  对比触发器画面：{回放锚点}
```

## 自检清单（第1章6 / 第2章5 / 第3章5 → 共16核）

**第1章**：前200字主角出现｜前300字末句戏剧性反转｜800字内触发核心冲突｜场景≤2/人物≤3｜落差三要素齐全｜章末有钩子。

**第2章**：有一项明确特权信息交给读者｜在具体事件中展示非旁白｜金手指已通过行动效果展现｜与第1章落差有关联｜章末让读者焦虑"接下来会怎样"。

**第3章**：前两章情绪得到一次释放｜通过具体事件验证主角进步｜钉下3-10章内可达短期目标｜没开多余新线/新势力/新世界观｜章末制造新期待（非重复旧情绪）。

## 反模式诊断

| 症状 | 诊断 | 方案 |
|:--|:--|:--|
| "看了三章不知道主角什么样" | 第1章无锚点 | 第1章前500字加一个"主角曾经高光"的具体场景 |
| "金手指出现太突兀" | 第2章无事件铺垫 | 金手指必须经一次具体事件展现，非系统弹出 |
| "看了三章不知道要干嘛" | 第3章没钉目标 | 加可量化短期承诺（时间/距离/状态） |
| 追读率低但收藏还行 | 三章情绪曲线太平 | 检查落差幅度/特权类型/小账回收力度 |
| 跳订率高 | 第3章开了不该开的新线 | 把第3章新信息推迟到第4章 |
