# CHANGE

## v1.4.1 | 2026-09-03

### 章纲三块 → 四块：增"章节背景"前置定位

老板复核发现 v5 直接进时空/场，write 缺"这章在整个故事里占什么位置"的定位语句。由 v5（戏带事件·三块）演进为 v5.1（四块）：

**格式 v5 → v5.1**：
- 前置新增 **块①章节背景**：功能位（推进主线/蓄力/爆发/过渡/揭示）＋情绪基调（爽/揪心/意外/紧绷/甜）＋主线开关（主线推进/搁置/收线；支线收不收）。定位一句话，不含事件/钩/线明细。
- 原"时空与主体" → **块②舞台背景**，并增"当前局势"（开场舞台环境/局面，不含本章事件）。
- **块③剧情场景**＝原戏剧节拍（场·带事件，单章 4~6 场），不变。
- **块④补充信息**＝原补充信息（对白/世界观/角色语感/本章推的线），不变。

"本章定位（性质）"与"本章推的线（对账）"边界：前者说这章什么性质/什么味，后者说动了哪条线从哪推到哪，不重复。

同步四件套：SKILL.md / skill.json（1.4.1）/ templates/章纲.tpl.md（v5.1 四块版）/ CHANGELOG。

## v1.4.0 | 2026-09-03

### 章纲粒度定稿：事件节点 → 戏剧节拍（戏带事件）v5

多轮子 agent 无原文实测（虚拟书《时间重置者》，同一章节位对比带/不带事件版）后，老板拍板"带事件更好"：章纲锁到"场"太稀，write 拿到手找不着北；锁到"事件"才给足脚手架。定稿为"戏带事件"：

**格式 v4 → v5**：
- 块②由"事件节点(N≤3行)"改为"戏剧节拍（场·带事件明细）"：一场一组，单章 **4~6 场**（容量红线：≤6 场，超量拆下一章；<4 场说明戏没撑满）。
- 每场含：**事件**（该场关键事件 2-4 个逐条列，只定事不定动作细节）＋**转折**＋**落点功能**。
- 事件细化的最小步归 write；场是 outline 锁定的最后粒度（write 前最后一环 = 一场戏，不是事件）。
- 块③ "交接信息" → **"补充信息"**（去技术腔），新增 **"本章推的线"**（主线/支线：从哪推到哪，收还是悬；轻量声明，明细在全书日志）。

**红线不变**（描述约束/自举回流/事实校验链/零必读分叉/不代 plot 职责）。

同步四件套：SKILL.md / skill.json（1.4.0）/ templates/章纲.tpl.md（v5 戏带事件版）/ CHANGELOG。

## v1.3.0 | 2026-09-03

### 章纲重构：拼装式 v3.1 → 描述约束版 v4（去 AI 味 + 容错自举）

多轮产出端实验验证（深渊主宰第二章 x 文风DNA / x 遮天文风）：章纲若写成"完成态成品句/预写台词/文学落点"，write 只能转述→ AI 味从天而降救不回。根因在章纲带的描述性水分，不在文风。

**章纲格式 v3.1 → v4**：
- 删：叙事原子序列/内部事件串/出线口/线账本/plot锚点区直拷/选卡记录/逐锚核对表/出口门禁（料≥40/量化1/3等 write 产出校验尺压给 outline 的项）。
- 新增：**描述约束铁律**——章纲只定【事件/转折/落点功能】三块；动作细节/心理/对白台词/结尾意象全部划给 write 现编（—write发挥：…你现编—占位）；出现"像正文句子"的表述＝越界，删。
- 章型降为可选批注（方向引导，不再按章型拼积木）。

**容错自举（Step 0 A/B 双路径）**：
- A路【消费】：上游健全→排张力；
- B路【自举】：上游缺失/被改烂/设定冲突风险高→outline 读全书日志当前态自推本章事件，**新事件/新钩子回流登记全书日志**再写章纲。定位=上游好当导演、上游烂自己当编剧+导演，永远踩最新全书日志重建。

**输入收敛（零必读分叉）**：设定/人物卡/元素卡库/剧情周期表全部移出必读，降为"卡壳才翻的字典"，消掉"要不要读"的掂量税。

红线重写 5 条：描述约束 / 自举回流 / 事实校验链 / 零必读分叉 / 不代 plot 职责。

同步三件套：SKILL.md / skill.json（1.3.0）/ templates/章纲.tpl.md / CHANGELOG。
