# pop-snow-outline

> 章纲＝事前预演的写前清单（描述约束版·四块）。当前版本 v1.8.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。

- **Pack**：缺口足够才取材，query 自生成；来源 **wiki 站** **<https://wiki.popwave.cn>** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query / 回传 ≤30KB，超限截断仅留结论区。

- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版，不越权定终局。

- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

***

## 做什么

章纲＝「没文风渲染的正文」该有的剧情含金量，但**只定事件/转折/落点功能，把动作细节、心理、对白台词、结尾意象全部划给 write 现场创作**。write 的唯一向前依据＝章纲，读 3 章渲染正文。

白描卡管"这章发生哪些事件＋落点"，outline 管"这些事件排成什么推进/张力曲线＋把 write 动笔前要定的东西提前答掉"。

| 项  | 内容                                                                                                     |
| :- | :----------------------------------------------------------------------------------------------------- |
| 输入 | **态**＝`全书日志.md`（当前态·只记活跃）｜**向**＝本幕`卷N-幕M-白描.md`（钦定事件）＋大纲卷向（本卷到哪）＋上一章`章节日志/ch{NNN-1}.md`（衔接） |
| 输出 | `卷纲/章纲/ch{NNN}-章纲.md`（每章一文件）                                                                           |
| 下游 | pop-snow-write（读章纲3章渲染正文）                                                                              |

**执行模式**：章纲求"事前预演+自举"是创作，主agent直执。若缺上游/被改烂，outline 自举推演并将新事件**回流登记全书日志**（B路，见 Step 0）。

***

## 怎么操作（SOP全内联）

### Step 0：接收自检·A/B双路径

判断本章剧情料是否够推到、能否构成一个让 write 直接起稿的章纲：

- **A路【消费】**：上游健全（白描有钦定事件+落点，全书日志当前态可用）→ 直接把钦定事件排成节点序列。
- **B路【自举】**：上游缺失/被改烂（用户自带、白描单薄、承接线断裂），或"极可能跟真实后续冲突"的设定风险 → outline **自己推演本章事件**：读全书日志当前态＋悬着的线＋用户最新意图＋大纲卷向，自主定出本章该发生什么＋张力节奏；自举定下的**新事件/新钩子必须回流登记回全书日志**，再据此写章纲。

一句话：**上游好的当导演排张力，上游烂的自己当编剧+导演，且永远踩在最新全书日志上重建。**

### Step 1：输入加载（只看三样，按需零分叉）

- **态**：`全书日志.md`（当前态·只记活跃——现在在哪/人物此刻/此刻悬着的线/没揭悬念/不许碰）
- **向**：本幕`卷N-幕M-白描.md`（本章事件+落点，白描卡管"写什么"）＋ 大纲卷向（本卷到哪，方向参照）＋ 上一章`章节日志/ch{NNN-1}.md`（衔接"上一章停在哪"）
- **事实抽查（承接8项状态包核对）**：起章纲前把承接状态核一遍（全书日志已聚合多数，重点核对剧情层会漏的两项）——时间线（上章结束/本章开始）/空间线（从哪来/如何到/往哪去）/角色状态（位置/伤势/能力/持有物）/关系状态（称呼/信任/敌意有无变化事件支撑）/道具状态（谁持有/是否损坏）/信息边界（角色知道什么）/伏笔状态（悬着的线哪条到期）/世界规则（能力科技地理是否允许本章事件）。**缺道具/关系两个易漏项任一未核＝回读补充再落章纲**。

**设定、人物卡、元素卡库、剧情周期表＝一律不进必读。** 它们只是字典，只在"某个节点你实在想不出怎么排张力"时按需点开查一眼；任何"要不要读"的掂量都会分叉注意力，章纲默认零分叉。

### Step 2：写章纲（描述约束版四块）

**块①章节背景**：功能位（这章在幕/卷里承担什么：推进主线/蓄力/爆发/过渡/揭示）＋情绪基调（这章整体让读者感受的味）＋主线开关（主线推进/搁置/收线，支线收不收）。定位一句话，不含事件、钩、线明细。

**块②舞台背景**：时间×地点×当前局势（开场舞台环境/局面，不含本章事件）×在场人物（每人一句今天要干嘛）。把该用的角色画进画面，write 不必为"要不要查人物卡"纠结。

**块③剧情场景**（按推进顺序，单章 4~6 场，容量红线）：
- **场**＝一场戏一组（write 能一口气演完的最小可独立单元）
- 每场含：
  - **事件**＝这一场要发生的关键事件，2-4 个逐条列（只定事，不定动作细节）
  - **转折**＝本场关键变化
  - **落点功能**＝"本场结尾读者该感到什么/为后文铺什么"，一个动作/一句话写清
- 事件细化的最小步归 write；场是 outline 锁定的最后粒度。少于 4 场说明戏没撑满，多于 6 场超量→拆下一章（容量红线）

**块④补充信息**：
- **对白**＝只写"要达成什么"（哪几处、谁对谁、功能），**不预写一句台词**
- **世界观**＝只写"要铺什么功能"（铺哪几处、服务什么），不代劳意象
- **角色语感**＝哪个角色要语气（查那张卡）、哪个免查
- **当前任务**＝主角本章要完成的**一个具体可执行动作**（一句话），强化"主角每章 ≥1 决策+1 行动"的硬要求
- **读者期待处理**＝读者此刻在期待什么 ＋ 本章怎么回应这份期待（不回应＝下章再回应，但必须写明"留着等什么时候"）
- **伏笔处理（本章）**＝处理哪条线、**四选一操作**（回应/推进/误导/压住但给理由）；新钩子 ≤2 且**优先从刚回收的旧钩子长出来**（链式推进非并列堆线）；全书日志有"沉睡10章预警"项时，本章是否接手
- **章末钩**＝钩子类型从 6 类选 1（悬念/危机/反转/期待/情感/信息），**与上一章不重复**；断章位置提示 write：**写到 8 成留 1 成，禁一章写满收束**（80/20 action-climax 断章）
- **本章推的线**＝主线/支线：这章从哪推到哪，收还是悬（轻量声明，明细在全书日志）

### Step 3：描述约束自检（任一越界＝删）

章纲里出现以下任何一项＝"成品句/越界"，必删：

- **动作细节**（"她把干饼掰一半塞给它"→ 只写"她分饼"）
- **心理陈述**（"她心里升起凉意"→ 不写，不代劳）
- **对白台词**（预写具体话 → 只写意图）
- **结尾意象/文学落点**（"天际露出一线血色""决定比夜还硬"→ 只写功能）。

**铁律判据**：章纲里出现任何"像正文句子"的表述＝越界。write 的活（动作/心理/对白/意象）outline 不得代劳，只能圈功能区——用"—write发挥：…你现编—"占位划界。

### Step 4：存档

**存档前先过资料门**：本章进入新场景/新职业/新地域/新材料（前文没写过）且 `素材/采风/` 没对应考据/质感料→**先派 research 采一点（落 `素材/采风/`、够本章质感即止）再存档**；熟悉旧场景不查。→ 每章一文件 `卷纲/章纲/ch{NNN}-章纲.md`（模板 `templates/章纲.tpl.md`）。**存档后半步=去AI味**：`python skills/pop-snow-pipeline/scripts/deai_gate.py 卷纲/章纲/ch{NNN}-章纲.md --profile doc --json`——WARN 定位自查（装腔换大白话，行话放行；工程标签如章型枚举/落点功能不查）、机械项 `--fix`，结果一行 `去AI味:ch{NNN}-章纲|PASS` 或 `WARN×N`（review 存档时会核验此结果）。write 读章纲 3 章渲染正文。write/review 反馈章纲质量问题时回本步重写该章，禁止 write 层私自补剧情——事件落点的修改权在 plot 层，outline 自举的演化登记在全书日志。

## 章纲格式 v5.1（描述约束版·四块）

```
ch{NNN}《{章名}》

一、章节背景
功能位：{推进主线/蓄力/爆发/过渡/揭示}
情绪基调：{爽/揪心/意外/紧绷/甜}
主线开关：{主线推进/搁置/收线；支线收不收}

二、舞台背景
时间：{何时} ｜地点：{何处}
当前局势：{开场舞台环境/局面，不含本章事件}
在场人物：{每人一句今天要干嘛}

三、剧情场景（共{N}场，一场戏一组）
场1 {场名}
  事件：
    1. {这一场发生的关键事件，2-4个逐条列}
    2. {事件}
  转折：{本场关键变化}
  落点功能：{本场结尾读者该感到什么/为后文铺什么}
场2 …
场{N} …

四、补充信息
对白：{哪几处、谁对谁、达成什么——不预写台词}
世界观要铺：{铺哪几处、服务什么——不代劳意象}
角色语感：{哪个角色要语气（查那张卡）｜哪个免查}
当前任务：{主角本章要完成的一个具体可执行动作，一句话}
读者期待处理：{读者此刻期待什么 + 本章怎么回应}
伏笔处理：{处理哪条线·回应/推进/误导/压住；新钩子≤2且从刚回收的长出来；沉睡预警项是否接手}
章末钩：{6类选1；与上章不重复；断章位置提示80/20}
本章推的线：{主线/支线：从哪推到哪，收还是悬}
```

**描述约束判据**：章纲里出现任何"像正文句子"的表述（动作细节/心理陈述/对白台词/文学落点）＝越界，删。write 的活不得代劳，只能圈功能区。**容量红线**：单章≤6 场，超量拆下一章。

## 章型表（可选批注，非强制工艺）

章型起"方向引导"作用，列在章头作注释，不强制全章按序列组装（章纲 v5.1 不按章型拼积木，章型只为 write 提示本章基调）。

| 英文枚举          | 中文别名  | 提示基调            |
| :------------ | :---- | :-------------- |
| opening_shift | 开局转折章 | 世界/身份剧变开局       |
| confrontation_pressure | 蓄压章 | 压力累积，冲突升级未爆 |
| combat_reversal | 战斗反转章 | 战斗清算/绝地反转 |
| reveal_hook   | 信息揭示章 | 情报/身世/规则揭示+钩子  |
| exploration_gain | 探索收获章 | 空间探索+收益进账 |
| high_tier_display | 高位展示章 | 位阶碾压/威名扩散/世界侧写 |
