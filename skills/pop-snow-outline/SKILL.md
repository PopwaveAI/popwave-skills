# pop-snow-outline

> 章纲拼接——白描卡×剧情周期表→章纲。当前版本 v1.1.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。
- **Pack**：缺口足够才取材，query 自生成；来源 **wiki 站 https://wiki.popwave.cn** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query / 回传 ≤30KB，超限截断仅留结论区。
- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版，不越权定终局。
- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

## 做什么

白描卡管"写什么"（plot产的事件锚），outline管"怎么拼"——把每章白描卡组装成章纲。write的向前锚=章纲，读3章渲染正文。

| 项 | 内容 |
|:--|:--|
| 输入 | `卷纲/卷N-幕M-白描.md`（逐章白描卡+锚点段）+ `产出/状态快照.md`（线入章状态）+ 元素卡库/剧情周期表（选卡） |
| 输出 | `卷纲/章纲/ch{NNN}-章纲.md`（每章一文件） |
| 下游 | pop-snow-write（读章纲3章渲染正文） |

**执行模式**：拼装是创作且跨章状态强耦合，主agent直执。出口门禁逐章核对是纯只读，可派子agent（verification）回报，主agent裁决落盘。

## 怎么操作（SOP全内联）

### Step 1：输入加载

- 本幕白描文件就绪（plot任务C产出，已过幕内自检）
- `产出/状态快照.md`（本幕首章的线入章状态源）
- 元素卡库索引 `https://wiki.popwave.cn/写作技法库\元素卡库\00-索引.md`（= wiki.popwave.cn，本地镜像）——按本幕章型清单预判需开的族文件（如战斗章开战斗族/收线族/施压族）
- 剧情周期表 `https://wiki.popwave.cn/写作技法库\剧情周期表\00-周期表索引.md`——按功能族/赛道/爽点三入口反查（当前仅少量原子卡，元素卡库54卡为主力选卡源，并轨迁移中）

**线入章状态源**：本幕首章=幕头+状态快照；其余章=前一章章纲线账本的章末状态。

**事实抽查**：白描卡锚点中的年龄/等级术语/人名已对照状态快照（plot已做，此处抽查）。

### Step 2：拼装五步（逐章执行）

**步1 读下发**：读本章白描卡+前1章白描卡（衔接）+后1章白描卡（钩子指向）。提取章型/事件锚/锚点段/线动作目标/出章面板。

**步2 选卡**：按章型从卡库选4-6张卡。参照元素卡库索引「章内族配方」：纯战斗章=战斗×3+收线；混装章按白描卡事件分布取族。开对应族文件读卡的先后手序列——先后手是必答题，顺序可微调不可缺。选卡记录进章纲尾部（族名+卡名）。

**步3 填槽**：白描卡事件锚入位（每个锚落到具体叙事原子的内部事件串）。锚点段直拷附章纲尾部——章纲=白描卡超集的保证，write只读章纲即得全部plot锁定信息。线入章状态从Step 1来源抄录作线账本起点。

**步4 现编**：锚外全部自由编（人物龙套名/数字/生态/对白），过三道关：
- **一致**：不与白描卡事实/前情/设定冲突；情报断言带获取渠道——主角怎么知道的
- **审美**：数字>形容词、有因果、能看见、档案配落差、留钩
- **密度**：每原子≥15条料，全章≥40条，量化料≥1/3

**步5 记账+门禁**：线账本逐线达成白描卡「本章线动作」目标。章尾原子必产生线翻转（章末钩=线状态翻转）。过出口门禁。

### Step 3：出口门禁（逐章，任一不达标=回炉重组装）

- 叙事原子4-6个（超6=渲染会被料拽跑）
- 全章料≥40条、量化料≥1/3
- 白描卡锚100%落位（章纲尾部附逐锚核对表：锚→所在原子）
- 线账本达成「本章线动作」每线目标
- 事件串物理闭合：因果链每步物理可执行（谁的手/什么时机/物件从哪来）
- 出章面板：硬锚直拷+可编区间标注，不与后文升级节点撞车
- 章型用英文枚举ID（见下表），禁自造词汇

### Step 4：落盘

每章一文件 `卷纲/章纲/ch{NNN}-章纲.md`（模板 `templates/章纲.tpl.md`）。全幕组装完→交付write（write读章纲3章渲染）。write/review反馈章纲质量问题（锚漏/线断/物理洞）时，回本步重组装该章，禁止write层私自补锚——锚的修改权在plot层。

## 章纲格式 v3.1

```
ch{NNN}《{章名}》

章型：{英文枚举ID}·{中文别名}（POV）
剧情梗概：1-2句
章节目的：形象/压力/伏笔三件套

【叙事原子序列】（经，4-6个，按顺序渲染）
叙事原子{N} {名}【{内部微观弧：如 缺-挤-忍}】
  使命：这个原子为什么存在（一句话）
  内部事件串：事件→事件→事件（因果锁死，含要落料）
  出线口：叙事原子结束时各线的状态变化

【线账本】（纬，独立记账）
{线名}（{线型}）：原子1启 → 原子2{状态} → … → 本章末{悬/收}

【plot锚点区】（从白描卡锚点段直拷）
- 爽点：{公式类型+落点}
- 章末钩子：{内容}（L{1-5}）
- POV：{主视角；切换注明对象+目的}
- 关键数据：{面板数值/登场退场/不可逆事实}
- 出场人物：{本章全部出场角色，按白描卡}
- 本章线动作：{每线本章 转/收/悬 目标}
- 出章面板：{硬锚=白描卡锁定值；可编区间=组装层可自填范围}
```

## 章型统一表

全链统一用英文枚举ID，中文别名仅作注释。禁自造词汇。

| 英文枚举 | 中文别名 | 说明 |
|:--|:--|:--|
| opening_shift | 开局转折章 | 世界/身份剧变开局 |
| confrontation_pressure | 蓄压章 | 压力累积，冲突升级未爆 |
| combat_reversal | 战斗反转章 | 战斗清算/绝地反转 |
| reveal_hook | 信息揭示章 | 情报/身世/规则揭示+钩子 |
| exploration_gain | 探索收获章 | 空间探索+收益进账 |
| high_tier_display | 高位展示章 | 位阶碾压/威名扩散/世界侧写 |

## 红线

1. **事件串物理闭合**：因果链每一步物理可执行（谁的手、什么时机、物件从哪来）。"只锁结果不锁时序"=回炉。
2. **判定链自然段内联**：系统数值/判定一律自然段呈现（【】内联格式），禁弹窗式/代码块。plot/write同一口径。
3. **出章面板必锁**：经验/数值增量必须在「出章面板」标硬锚或可编区间。无锁定值=章内可能升级撞车后文。
4. **事实校验链**：白描卡事实性字段产卡前必读状态快照。章纲→正文中事实冲突时以状态快照/前文为准。
