# pop-snow-outline

> 卷纲 + 章纲（可选）。章纲不是必填，首三章建议写，之后可直接写正文。
> 当前版本 v8.0.1。

## 何时用

开新卷、排卷纲、排下一章章纲。只写大纲，不写设定、不写正文。

## 流程

### Step 1 卷纲 `[工具:outline]` → `剧情/卷N-卷纲.md`

一行一句，写四块：

1. **卷目标**：这一卷主角要拿到什么，一句话。
2. **卷级敌人**：这一卷谁在挡他，一个具体的人或组织。
3. **卷末变化**：卷末他失去什么、得到什么，一句话。
4. **分章推进**：八到十五章，每章一句「这章发生了什么」。

### Step 2 章纲（可选）`[工具:outline]` → `章纲/ch{NNN}.md`

只写五栏，每栏一两句：

```
本章目标：{主角这章要完成的一个动作}
冲突：{谁跟谁争什么，谁挡着谁}
事件：{三到五条，按顺序，只写发生了什么}
转折：{这章的关键变化}
章末钩子：{读者想翻下一章的那一点}
```

首三章必写；之后用户说「直接写」就跳过，并在章日志记「无章纲」。章纲里不写对白、不写心理、不写结尾意象——那些归正文。

### Step 3 自检 `[主]`

- 每章至少一件事发生，没有「过渡到过渡」。
- 卷末对得上卷目标；对不上就改卷纲，不改人物铁律。
- 章纲与人物卡不冲突（谁会做什么、不会做什么）。

## 注入清单（缺一不调）

- `outline`：
  - `brief`：这次排卷纲／排第 N 章。
  - `context`：`立项/故事.md`、`人物/人物卡.md`、`设定/世界观.md`、`设定/力量与社会体系.md`、`设定/战斗冲突表现.md`、前情摘要（≤500 字）、已有章纲索引。
  - `constraints`：章数、每章字数、必须发生／必须避免、禁区。

## 红线

1. 不写正文句、不写对白与心理。
2. 不排幕，不做多卷总纲，除非用户要。
3. 不发明主线之外的事件。
4. 章纲缺了不影响写正文，别为了补章纲卡住用户。
