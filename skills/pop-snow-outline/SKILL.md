# pop-snow-outline

> **章纲＝事前预演的写前清单（描述约束版·四块·情绪坐标）**：只定事件/转折/落点功能，把动作细节、心理、对白台词、章末钩全部划给 write 现场创作。write 的唯一向前依据＝章纲，读 3 章渲染正文。当前版本 v2.1.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

---

## §1 定位 · 章纲是什么

章纲＝「没文风渲染的正文」该有的**剧情含金量**。产出 `卷纲/章纲/ch{NNN}-章纲.md`（每章一文件），下游 pop-write 读它渲染正文。

白描卡管"这章发生哪些事件＋落点"，outline 管"这些事件排成什么推进/张力曲线＋定本章情绪坐标＋把 write 动笔前要定的东西提前答掉"。

**核心边界**：outline 只圈/定事件、转折、落点功能；**动作细节、心理、对白台词、结尾意象全部划给 write**。章纲里出现任何"像正文句子"的表述＝越界（详见 §4 Step 3）。

**执行模式**：章纲求"事前预演+自举"是创作，主 agent 直执。若缺上游/被改烂，outline 自举推演并将新事件**回流登记全书日志**（见 §2 B路）。

## §2 心法 · 上游当导演，上游烂自己当编剧＋导演

### 一句话心法

**上游好的当导演排张力，上游烂的自己当编剧＋导演，且永远踩在最新全书日志上重建。**

### A/B 双路径（Step 0）

判断本章剧情料是否够推到、能否构成一个让 write 直接起稿的章纲：

- **A路【消费】**：上游健全（白描有钦定事件+落点，全书日志当前态可用）→ 直接把钦定事件排成节点序列。
- **B路【自举】**：上游缺失/被改烂（用户自带、白描单薄、承接线断裂），或"极可能跟真实后续冲突"的设定风险 → outline **自己推演本章事件**：读全书日志当前态＋悬着的线＋用户最新意图＋大纲卷向，**先用剧情-情绪打分表定本章情绪坐标，再选套路**，自主定出本章该发生什么＋张力节奏；自举定下的**新事件/新钩子必须回流登记回全书日志**，再据此写章纲。

### 每章都有权大改（不锁死上游白描卡）

> **（老板拍板 2026-09-11：不是只有黄金第一章能大改，是每一章都有权大改。）**

**铁律**：outline **不锁死**白描卡。只要本章白描卡温吞（慢热铺垫/纯信息钩/无倒计时威胁/冲突缺席只算信息流），outline **有权重排本章事件**成大戏章（强指令倒计时＋关键底牌第一发就开大＋章末大反转，参考 sepia 结构去AI味：**主题别讲白、这一章就要让读者放不下**）。**判据**：本章能否头 120 字内给读者一个放不下的压力/反常/反转，做不到＝白描钦定太温吞，outline 重构并登记全书日志。

**重构的两条实战铁律（ch001-黄金重构版 2026-09-11 复盘沉淀，全章通用）**：
① **关键底牌必须触及现实层，别只当"识别器/感知工具"**——第一发就要改现实（预言/改写/落下不可逆后果），不能只是"读得懂/认得出/看得见"这类感知增强，否则立不起"这东西要命"的分量。
② **本章情绪坐标宁实勿虚，别为爽感虚标双8**——重构后情绪坐标按打分表铺垫成本现实给级（同名体验可 章首3/峰值4×2/章末5，不硬凑 8），全程对照打分表标分自检过闸降档落级，**读者收到的比纸面 8 分实在**。

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。
- **Pack**：缺口足够才取材，query 自生成；来源 **wiki 站** **<https://wiki.popwave.cn>** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query（超限截断仅留结论区）。
- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版，不越权定终局。
- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

## §3 思考顺序 · 先标准后解法，采风先行

**v2 章纲思考顺序**：起章纲前先核采风库（`素材/采风/`，新场景/职业/地域/材料缺料必派 research 补采）→ 再定"本章要达到什么情绪坐标"（剧情-情绪打分表查级定标，细则以打分表为准，本文件不另立判据）→ 再按白描钦定事件＋情绪目标排张力曲线——**采风料是底座，情绪标准是需求，白描事件是解法落地**。

| 项  | 内容 |
| :- | :------------------------------------------------------------------------------------------------------------------------------------- |
| 输入 | **态**＝`全书日志.md`（当前态·只记活跃）｜**向**＝本幕`卷N-幕M-白描.md`（钦定事件）＋大纲卷向（本卷到哪）＋上一章`章节日志/ch{NNN-1}.md`（衔接） |
| 库  | **剧情-情绪打分表**＝本章情绪坐标刻度（`references/剧情-情绪打分表.md`，本包副本·查级用）｜**采风库**＝场景/职业/地域/材料考据质感料（`素材/采风/`，research 产出·硬性核对源） |
| 输出 | `卷纲/章纲/ch{NNN}-章纲.md`（每章一文件） |
| 下游 | pop-write（读章纲 3 章渲染正文） |

## §4 怎么操作 · SOP（全内联）

### Step 1：输入加载（只看四样，按需零分叉）

- **态**：`全书日志.md`（当前态·只记活跃——现在在哪/人物此刻/此刻悬着的线/没揭悬念/不许碰）
- **向**：本幕`卷N-幕M-白描.md`（本章事件+落点，白描卡管"写什么"）＋ 大纲卷向（本卷到哪，方向参照）＋ 上一章`章节日志/ch{NNN-1}.md`（衔接"上一章停在哪"）
- **采**：`素材/采风/`（research 定向采风产出·**硬性核对源**）——起章纲前必核：本章要进入的**新场景/新职业/新地域/新材料**（前文没写过的），对应考据/质感料在不在：在→读种子直接用；不在→**必派 pop-snow-research 定向补采**（落 `素材/采风/`、够本章质感即止）**再落章纲**，禁止凭印象硬造细节。
- **事实抽查（承接8项状态包核对）**：起章纲前把承接状态核一遍（全书日志已聚合多数，重点核对剧情层会漏的两项）——时间线（上章结束/本章开始）/空间线（从哪来/如何到/往哪去）/角色状态（位置/伤势/能力/持有物）/关系状态（称呼/信任/敌意有无变化事件支撑）/道具状态（谁持有/是否损坏）/信息边界（角色知道什么）/伏笔状态（悬着的线哪条到期）/世界规则（能力科技地理是否允许本章事件）。**缺道具/关系两个易漏项任一未核＝回读补充再落章纲**。

**设定、人物卡、元素卡库、剧情周期表＝一律不进必读。** 它们只是字典，只在"某个节点你实在想不出怎么排张力"时按需点开查一眼；章纲默认零分叉。

### Step 1.5：情绪标准先行（先定情绪点，再排张力曲线）

**情绪标准在前，事件编排在后。** 白描管"发生哪些事件"，outline 管"这些事件排成什么情绪曲线"。

1. **查打分表**：打开本包 `references/剧情-情绪打分表.md`——选情绪→核铺垫成本→查锚定剧情→峰值规则→反例对照，**内容一律以打分表为准，本文件不另立判据**。agent 不感受情绪，只对照查级。
2. **定本章情绪坐标**（三个值，查表定级，标注格式 `{情绪}·{分值}`）：
   - **章首值**：承接上章钩子的读者情绪起点
   - **峰值**：本章最高情绪点——查打分表定峰值点数与分值；**8 分是稀缺资源，须铺垫支撑（跨章铺垫，或开篇单章内完成铺垫+引爆）**
   - **章末值**：章末钩子处的情绪落点（断章位）
   - **判据以打分表为准**：8 分定义/临界规则/假致命/主角光环假威胁一律对照打分表核，不另立判据
3. **8 分落级自检（每个 8 分级峰值必过，过不了回本步重排）**：按打分表「标分自检」过闸（对档核分=按铺垫成本核、兑现测试=读者真收到），判据一律以打分表为准，本文件不另立；负面 8 分还须过打分表反例区"已发生测试"。
   → 两闸都过，块①"峰值事件"标注 `[自检通过]`。
4. **排张力曲线**：把白描钦定事件按情绪坐标排进场序——每个峰值点对应到具体事件（情绪点与事件必须**强度匹配**：定了负8 就排见血/见死/见不可逆的事件，不许用"擦过脸颊"糊 8 分）；**6 分以上必须铺垫引爆**：标 6 分以上先写得出来"铺垫在哪"（哪几章/哪个事件），写不出的降分。
5. **情绪坐标写进章纲**：随章纲存入 `卷纲/章纲/ch{NNN}-章纲.md` 头部（feed review 情绪达标核验）。

**为什么倒着来**：先想事件再标情绪，agent 会把所有章都标成"爽"——情绪没有鉴别力。先定情绪标准，再排事件，章纲才带情绪起伏。

### Step 2：写章纲（描述约束版四块）

**块①章节背景**：功能位（这章在幕/卷里承担什么：推进主线/蓄力/爆发/过渡/揭示）＋**情绪坐标（章首/峰值/章末，查打分表定级，格式 `{情绪}·{分值}`＋峰值事件简述＋8 分事件带 `[自检通过]`）**＋主线开关（主线推进/搁置/收线，支线收不收）。定位一句话，不含事件、钩、线明细。

**块②舞台背景**：时间×地点×当前局势（开场舞台环境/局面，不含本章事件）×在场人物（每人一句今天要干嘛）。把该用的角色画进画面，write 不必为"要不要查人物卡"纠结。

**块③剧情场景**（按推进顺序，单章 4~6 场，容量红线）：
- **场**＝一场戏一组（write 能一口气演完的最小可独立单元）
- 每场含：
  - **冲突**＝本场矛盾，放**事件之前**先定（先写这场谁跟谁在争、靠什么驱动，再让事件去兑现它）：`源自谁×对谁＋双方要什么、谁挡着谁＋靠什么驱动（显性对抗/信息差/选择）＋读者情绪参照打分表定 {情绪}·{分值}`。**冲突缺席=本场只算信息流不算戏**，回排
  - **事件**＝这一场要发生的关键事件，2-4 个逐条列（只定事，不定动作细节），每条兑现/加深上面冲突
  - **转折**＝本场关键变化
  - **落点功能**＝"本场结尾读者该感到什么/为后文铺什么"，一个动作/一句话写清
- 事件细化的最小步归 write；场是 outline 锁定的最后粒度。少于 4 场说明戏没撑满，多于 6 场超量→拆下一章（容量红线）

**块④补充信息**：
- **对白**＝只写"要达成什么"（哪几处、谁对谁、功能），**不预写一句台词**
- **世界观**＝只写"要铺什么功能"（铺哪几处、服务什么），不代劳意象
- **角色语感**＝哪个角色要语气（查那张卡）、哪个免查
- **当前任务**＝主角本章要完成的**一个具体可执行动作**（一句话），强化"主角每章 ≥1 决策+1 行动"的硬要求
- **读者期待处理**＝读者此刻在期待什么 ＋ 本章怎么回应这份期待（不回应＝下章再回应，但必须写明"留着等什么时候"）
- **调研支撑**＝本章进入的**新场景/新职业/新地域/新材料**引用了 `素材/采风/` 哪份料（文件名）；无则写"—"；缺料必先补采（Step 1「采」）再落章纲，不留硬写项
- **伏笔处理（本章）**＝处理哪条线、**四选一操作**（回应/推进/误导/压住但给理由）；新钩子 ≤2 且**优先从刚回收的旧钩子长出来**（链式推进非并列堆线）；**读 卷brief 健康度快照＋全书日志"沉睡10章预警"**——已到期/超期线本章**必须表态**（回收或压住给理由）、沉睡≥10章线提示接手或显式搁置，**不得静默跳过**
- **章末钩**＝钩子类型从 6 类选 1（悬念/危机/反转/期待/情感/信息），**与上一章不重复**；**对照打分表好奇模块定档**（格式 `好奇·X档`，能查出该档才标，伪钩子回排）；断章位置提示 write：**写到 8 成留 1 成，禁一章写满收束**（80/20 action-climax 断章）
- **开篇三要素（仅前3章）**＝落差三要素（锚点=坠落前最高光／现状=坠落后最低谷／对比触发器=同场景正面碰撞）＋特权信息（读者知道但剧中人不知道：身份/未来/能力/视角，择一）＋还小账立新标（力量验证/预判兑现/选择宣示；时间标/距离标/状态标，3-10章内可达成）——前3章必填，立开篇承诺基线（随章纲写入全书日志）
- **爽点标注（每章）**＝重大爽点类型（9类选1-2：战斗胜利/夺宝获资/成长升级/打脸装逼/剧情推进/关系推进/身份跃迁/危机拯救/震撼场面）＋密度目标 ≥2；爽点需含发生（事件本身）＋反应（读者情绪落点，对照打分表情绪名）＋影响（对状态/剧情的实际改变）——喂 review 爽点密度+情绪达标检查
- **本章推的线**＝主线/支线：这章从哪推到哪，收还是悬（轻量声明，明细在全书日志）

### Step 3：描述约束自检（任一越界＝删）

章纲里出现以下任何一项＝"成品句/越界"，必删：

- **动作细节**（"她把干饼掰一半塞给它"→ 只写"她分饼"）
- **心理陈述**（"她心里升起凉意"→ 不写，不代劳）
- **对白台词**（预写具体话 → 只写意图）
- **结尾意象/文学落点**（网文章末钩不靠文学意象收尾——钩子是让人发狂的悬念/冲突，如"主角转身一瞥/管家竟一把扯下女主的衬衫/你找死？！"→ 只写钩子功能，不写成品句）。

**铁律判据**：章纲里出现任何"像正文句子"的表述＝越界。write 的活（动作/心理/对白/意象）outline 不得代劳，只能圈功能区——用"—write发挥：…你现编—"占位划界。

### Step 4：存档

**存档前先过资料门（硬性，每章必核）**：本章进入新场景/新职业/新地域/新材料（前文没写过）且 `素材/采风/` 没对应考据/质感料→**先派 pop-snow-research 采一点（落 `素材/采风/`、够本章质感即止）再存档**；熟悉旧场景不查、不噪音。→ 每章一文件 `卷纲/章纲/ch{NNN}-章纲.md`（模板 `templates/章纲.tpl.md`）。**存档后半步=去AI味**：`python skills/pop-snow-pipeline/scripts/deai_gate.py 卷纲/章纲/ch{NNN}-章纲.md --profile doc --json`——WARN 定位自查（装腔换大白话，行话放行）、机械项 `--fix`，结果一行 `去AI味:ch{NNN}-章纲|PASS` 或 `WARN×N`（review 存档时会核验此结果）。write 读章纲 3 章渲染正文。write/review 反馈章纲质量问题时回本步重写该章，**禁止 write 层私自补剧情**——事件落点的修改权在 plot 层，outline 自举的演化登记在全书日志。

## §5 参考样例 · 章纲格式 v6（描述约束·四块·情绪坐标·调研支撑·爽点标注）

```
ch{NNN}《{章名}》

一、章节背景
功能位：{推进主线/蓄力/爆发/过渡/揭示}
情绪坐标：章首{·}｜峰值{·}×{N}｜章末{·}（格式：`{情绪}·{分值}`，峰值点数与分值查打分表定标）

二、舞台背景
时间：{何时} ｜地点：{何处}
当前局势：{开场舞台环境/局面，不含本章事件}
```
