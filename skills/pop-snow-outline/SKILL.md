# pop-snow-outline

> 卷纲先写清这一卷发生了什么，再落章。章纲可选，首三章建议写，之后可直接进入正文。
> 当前版本 v8.1.2。

## 何时使用

开新卷、编制卷纲、编写下一章章纲。只写大纲，不写设定与正文。

## 流程

### 第 1 步 卷纲 `[工具:outline]` → `剧情/卷N-卷纲.md`

先写清剧情，再写结构项。五项按顺序：

1. **卷剧情**（400-800 字）：连续叙事，讲清这一卷谁要什么、谁挡着、中间如何转折、卷末停在哪里。判据是合上材料能复述这一卷发生了什么；每段有前因后果；不是世界观介绍，不是事件清单。
2. **卷目标**：一句话，这一卷主角要拿到什么。
3. **卷级敌人**：一个具体的人或组织，写明凭仗与弱点。
4. **卷末变化**：失去什么、得到什么、下一卷的钩子。
5. **分章推进**：八到十五章，每章一句「这章发生了什么」。每章必须对得上卷剧情中的某一段，不得另起一条线。

**判据**：分章推进是卷剧情的展开，不是另一套剧情。卷剧情写不出来，不得继续写分章推进。

### 第 2 步 章纲（可选）`[工具:outline]` → `章纲/ch{NNN}.md`

只写五栏，每栏一两句：

```
本章目标：{主角这章要完成的一个动作}
冲突：{谁跟谁争什么，谁挡着谁}
事件：{三到五条，按顺序，只写发生了什么}
转折：{这章的关键变化}
章末钩子：{读者想翻下一章的那一点}
```

首三章必写；之后用户说「直接写」即可跳过，并在章日志记「无章纲」。章纲不写对白、心理与结尾意象，这些归正文。

章纲服务于卷剧情：本章目标必须对得上卷剧情中的一段推进，不得临时增加卷外主线。

### 第 3 步 自检 `[主]`

- 卷剧情能复述，四问答得出：谁要什么、谁挡着、怎么转、停在哪。
- 分章推进与卷剧情一一对应，没有凭空多出的章。
- 每章至少发生一件事，没有「过渡到过渡」。
- 卷末变化对得上卷目标；对不上就修改卷纲，不修改人物设定。
- 章纲与人物卡不冲突（谁会做什么、不会做什么）。

## 注入清单（缺一不调）

**context 传正文，不传文件名**：每次调用前，先用 Read 把下列文档整份读入，原文放进 `context`。不得只写文件路径，不得把设定压成要点。`context` 上限约 13 万字节，超出时按优先级取舍：立项故事核 ＞ 人物卡 ＞ 本卷相关的设定 ＞ 前情摘要。

- `outline`：
  - `brief`：本次编制第 N 卷卷纲／编写第 N 章章纲。编制卷纲时，先要卷剧情，再要分章推进。
  - `context`：`立项/故事.md` 全文；`人物/人物卡.md` 全文；`设定/世界观.md`、`设定/力量与社会体系.md`、`设定/战斗冲突表现.md` 全文（至少含规则底座、阶位表、按卷敌人表三节）；前情摘要（≤500 字，此项可摘要）；已有章纲索引。
  - `constraints`：卷剧情字数（400-800）、章数、每章字数、必须发生／必须避免、禁区。

## 红线

1. 不写正文句、对白与心理。
2. 卷纲必须先有卷剧情，再写分章推进；不许只列目标、敌人与章句。
3. 不写幕纲，不做多卷总纲，除非用户要求。
4. 不发明主线之外的事件。
5. 章纲缺失不影响写正文，不要为了补章纲卡住用户。
