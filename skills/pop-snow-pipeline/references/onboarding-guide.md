# 你的小说，能写到能被追更

> 用途：用户第一次触发网文写作专家（无任何写作项目、非续写场景）时，由主 agent 直接输出以下引导语。**声明本条为功能介绍 + 引导，未执行 skill 任务**，以「网文作者」视角快速建立「我能怎么开始写一本小说」的认知，再引导开展第一步。

---

老板，收到。先声明：**这次没动用什么干活，只是带你看看**——你想写的那本小说，在我手上能怎么一步步落地。

## 一句话说清

**你只要有个"想写什么"的念头，剩下的从立项到成文我陪你走完。** 定方向、搭设定、排剧情、一章章写正文、写完自查，一整套都给你安排好。你负责出想法，我负责把想法变成能发出去的文字。

## 三种开始方式

- **有明确创意**：一句话说清主角在做什么，直接立项。
- **只有方向**：想写修仙/都市/灵异但没具体想法，我陪你摸底调研，发散十个方向你挑一个。
- **想仿写某本爆款**：给我书名和你的改动想法，我先拆书再按你的创意改编，换演员、换世界观还是全换由你定。

已经写了开头的也行，把文件给我，我从你停下的地方接着跑。

## 后面会发生什么

立项定六要素 → 搭世界和角色 → 一卷一卷排剧情 → 拼章纲 → 写正文 → 每章审一遍。每章写完我照着"读者会不会跳章、爽不爽、有没有坑"自查，问题当场改，不把毛病带到完结。

## 你不用担心

- **不用你会写大纲**：立项、世界观、剧情骨架我都陪你搭
- **不用你懂术语**：赛道、节奏、爽点，原理交给我的判断
- **先试水再铺开**：先写 1-2 章小样看手感，满意再一路往下写

## 就这样开始

**直接把「你想写什么」丢给我就行。**

比如：
- 我想写本修仙文，帮我立项
- 帮我仿写《XXX》，换个主角
- 已写了个开头，帮我接着写

想好了就直接说，我这就开工。
