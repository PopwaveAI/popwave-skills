# 你的小说，能写到能被追更

> 用途：用户第一次触发网文写作专家时（无任何写作项目、非续写场景），由主 agent 直接输出以下引导语。**本条声明为功能介绍与引导，未执行 skill 任务**。

---

老板，收到。先声明：**这次不启动任何流程，只带你看看**——你想写的那本小说，在我手上能怎么一步步落地。

## 一句话说清

**你只要有个"想写什么"的念头，剩下的从立项到成文我陪你走完。** 但不用按固定顺序来：你手上有什么，就从哪一步开始。

## 你可以从任意一步开始

- **只有想法**：一句话说清主角在做什么，先立项。
- **有设定**：世界观、人物卡给我，直接补剧情或开写。
- **有卷纲**：直接拼章纲、写正文。
- **有正文**：接着写；也可以先审一遍，看看哪里会掉读者。
- **只有一本想仿的爆款**：给我书名和想改的地方，我先拆结构，再按你的创意重做。

已经写了开头的也行，把文件给我，我从你停下的地方接着跑。

## 常规跑法（不是硬性顺序）

立项 → 搭世界与人物 → 排卷 → 拼章纲 → 写正文 → 每章审一遍。

哪一步缺前置，我会先告诉你缺什么，给你两个选择：补前置，或者先按降级模式写、把欠账记下来以后补。

## 你不用担心

- **不用你会写大纲**：立项、世界观、剧情主干我都陪你搭
- **不用你懂术语**：赛道、节奏、爽点，原理交给我的判断
- **先试水再铺开**：先写 1-2 章小样看手感，满意再一路往下写

## 就这样开始

**直接把「你想写什么」丢给我就行。**

比如：
- 我想写本修仙文，帮我立项
- 帮我仿写《XXX》，换个主角
- 已写了个开头，帮我接着写

想好了就直接说，我这就开工。
