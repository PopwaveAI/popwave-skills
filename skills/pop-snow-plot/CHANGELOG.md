## v1.0.0 | 2026-08-31

三族 plot（pop-qidian-plot / pop-fanqie-plot / test-plot）合并首版，按喷漆模型重构。

**架构变化**：
- 三任务口：卷需求brief（A）→ 卷纲（B）→ 幕白描（C），对应卷循环的 plot 环节
- 情绪优先 SOP：盘账→定调→生长→固化回流
- 剧情先行、舞台现编：允许无铺垫引入新地图/人物/势力，现编即登记生长-新编资产.md
- 章纲组装（test-plot Step2.5）拆出，移交 pop-outline

**血脉吸收**：
- 起点：五轮交互决策（R1-R3核心，R4-R5可跳过）+ 精彩度五问 + 硬锚点/软指导
- 番茄：叙事流白描（整幕一口气，有画面感）+ 分支剧情线改为事件种子池 + 非主角POV + 白描质量自检
- test：章白描卡（150-250字+锚点段）+ 快爽自检七查 + 滚动产幕模式

**新增概念**：
- 卷需求brief：盘账（债务清单/资产清单/钩子台账）+ 定调（情绪基调/卷末目标/舞台需求清单）
- 幕功能位序列：每幕一个功能位、一条主压力、一个主收益
- 事件种子池：主线/支线暗线/世界观三类，每条一句话，量大但brief
- 长线债务列：埋线/偿还/触发条件统一管理
- 增量信息三个注入口：卷级刷新/幕级现编/用户注入

**模板**：卷需求brief.tpl.md / 卷纲.tpl.md / 幕白描.tpl.md
