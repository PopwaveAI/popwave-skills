# pop-snow-plot

> 剧情编排——卷需求brief/卷纲/幕白描三任务口。当前版本 v2.0.2，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

**与全书大纲的关系**：`立项/03-全书大纲.md` 是全书宪法，已定每卷的"卷命运+养成刻度批额+核心危机+卷末边界"。本 skill 不另起全书炉灶——只在大纲分配给本卷的那一片里展开：任务A提取本卷切片为订货单，任务B在本卷批额内排幕，任务C按幕产白描。**本卷主养成线推进不得超大纲批的刻度**（大纲批"卷三到超凡初阶"，卷纲就不得写到中阶）；要突破须回 seed 显式修订大纲，不许静默超纲。

---

## 做什么

plot 管"这台戏唱什么"。stage 搭好台子，plot 往上排戏。

**三个任务口**：

| 任务 | 触发 | 消费 | 产出 | 下游 |
|:--|:--|:--|:--|:--|
| A 卷需求brief | 卷循环起点（新书卷一/上卷写完） | `立项/03-全书大纲.md`本卷切片+`产出/状态快照.md`+`设计/主线.md`+上卷舞台档 | `卷纲/卷N-需求brief.md` | stage 卷级刷新 |
| B 卷纲 | stage 刷新完（卷N-舞台.md就绪） | 卷需求brief+`03-全书大纲.md`本卷切片+卷N-舞台.md+主线+角色库 | `卷纲/卷N-卷纲.md` | 本skill任务C |
| C 幕白描 | 卷纲就绪，按幕推进 | 卷纲+卷舞台+角色库+状态快照 | `卷纲/卷N-幕M-白描.md` | pop-snow-outline |

**执行模式**：主agent直执。交互轮（任务B）用户在场走选项，不在场agent自定并标注。任务C的快爽自检是纯只读核对，可派子agent（verification）回报，主agent裁决落盘。

**增量信息三个注入口**：卷级刷新（任务A用户注入新想法）/ 幕级现编（任务C写白描时自然长出新设定，登记到生长-新编资产.md）/ 用户随时注入（任何阶段用户插话，plot吸收后继续）。

## 怎么操作（SOP全内联）

### 任务A：卷需求brief（每卷一次）

给 stage 的订货单 + 给自己的方向盘。brief 不定细节，只框范围。

**A1 盘账**：

读完再动笔，缺哪个补哪个。

- `立项/03-全书大纲.md`：**本卷切片**——本卷的卷命运一句话、养成刻度批额、核心危机、卷末边界。卷一从这里定方向；卷二起它是本卷展开的上限，大纲里没有的不能凭空拔高
- `产出/状态快照.md`：上卷写到哪、主角阶位/面板/关系现状、未兑现的钩子（卷二起）
- `设计/主线.md`：本卷在全书卷目录中的那行（卷名/舞台方向/主压力/主收益/不抢的后续收益）
- 上卷舞台档 `设计/卷舞台/卷{N-1}-舞台.md`：哪些设定还能用，哪些该淘汰了
- `设计/全书设定/生长-新编资产.md`：上卷现编了什么东西，要不要转正

盘账产出三张清单：

1. **债务清单**：上卷埋的线，哪些本卷该还、哪些继续欠着（标偿还条件和预计卷）
2. **资产清单**：上卷现编的设定/角色/地点，本卷继续用还是封存
3. **钩子台账**：章级钩子哪些已兑现、哪些悬着

**A2 定调**：

回答四个问题，每个一两句话：

1. 本卷什么感觉？（压抑蓄力/扩张爽感/谷底反弹/暗流涌动……一句话情绪基调）
2. 主角卷末站在哪？（阶位/身份/地图/关系，坐标系至少一项跃迁）
3. 读者卷末记住什么？（最重的一击，卷末大爽点）
4. 本卷新增什么舞台？（新地图/新势力/新角色需求，喂给stage）

**A3 落盘** `卷纲/卷N-需求brief.md`（模板 `templates/卷需求brief.tpl.md`）。

### 任务B：卷纲（每卷一次）

卷纲定战略不定战术。幕怎么打交给任务C，卷纲只管"打几仗、每仗为什么打、打完得到什么"。

**B1 输入加载**：

- `卷纲/卷N-需求brief.md`（任务A产出）
- `立项/03-全书大纲.md`（本卷切片：卷命运+养成刻度批额+卷末边界——R1 终点区间和本卷阶位以此为准，不得超批额）
- `设计/卷舞台/卷N-舞台.md`（stage卷级刷新产出：本卷地图/势力/新角色锚/主矛盾/力量范围）
- `设计/主线.md`（全书卷目录+敌人阶梯+因果链）
- `设计/角色库/角色库.md`（登场/退场/弧线转折点）

**B2 交互轮（核心三轮，可选两轮）**：

用户在场走选项（给选项不给空白，每轮2-3方案+自定义入口）；不在场agent自定，标注"agent自定"。

| 轮 | 必答？ | 干什么 | 选项规则 |
|:--|:--|:--|:--|
| R1 卷终点定位 | 必答 | 从主线本卷行+力量范围提取可行终点区间，生成3方案 | A标准路线（跨度适中）/B保守路线/C激进路线，每个标注：阶位/卷末大事件/坐标系跃迁/风险 |
| R2 关底对手 | 必答 | 从角色库反派卡+卷舞台筛选等级匹配的对手 | A标准对手/B组合对手（联手或前后脚）/C意外对手（中立方/盟友反转），每个标注：强度/冲突点/击败方式 |
| R3 核心爽感 | 必答 | 从金手指+卷舞台矛盾提取爽感可用组合 | 面板爆发/信息差碾压/越级击杀/打脸反击——用户排优先级选2-3个 |
| R4 剧情节奏 | 可跳过 | 参考赛道主流节奏，定幕密度和章数 | 用户说"跳过/默认"→按赛道主流自动选 |
| R5 角色登场 | 可跳过 | 从角色库和卷舞台新角色锚定登场顺序 | 用户说"跳过"→按原定引入章生成 |

决策结果记入卷纲「决策记录」节。后续步骤必须遵守，调整需重走对应轮。

**B3 幕功能位序列+事件种子池**：

**幕功能位序列**（5幕为基线，可按节奏调整4-6幕）：每幕一行——幕号/功能位（一个）/主压力（一条）/主收益（一个）/幕末质变/幕末钩子。功能位从组合库选：压抑蓄力/首杀立威/远行扩张/信任结盟/谷底反弹/身份跃迁/暗线揭示/决战收束……每幕只挑一个，不贪多。

**事件种子池**（替代旧"分支剧情线"）：三类种子，每条一句话，量大但brief，让幕白描自由发挥选取：

- 主线种子（3-5条）：推动主要矛盾的事件方向
- 支线暗线种子（4-6条）：角色关系/情感/隐藏线索，每条标"预计揭示卷"
- 世界观种子（2-3条）：设定展示/生态描写/规则揭示

种子不设起止状态，不写关系字段。幕白描决定哪条种子在哪幕发芽。

**B4 长线债务+收益管控**：

- **长线债务列**：全书级的埋线和偿还计划。每行：线名/埋设卷/预计偿还卷/触发条件。本卷新增的线登记进来，本卷偿还的线划掉
- **不能抢的后续收益**：从主线本卷行直拷，加上本卷新识别的（后续卷的重头收益，本卷禁止提前兑现）
- **卷末三件套**：面板大爆+新地图解锁+下卷钩子，结构固定，内容原创

**B5 落盘+六问自检**：

落盘 `卷纲/卷N-卷纲.md`（模板 `templates/卷纲.tpl.md`）。落盘前过六问，每问给出具体证据（不是"我觉得"，是"第X幕的XXX就是这个理由"）。六问全过才落盘，任一不过=回对应节重做：

| # | 问题 | 通过标准 | 不过回哪 |
|:--|:--|:--|:--|
| 1 | 追读理由 | ≥2个具体的"读者为什么想继续看"（"那个秘密到底是什么"级钩子，不是"好看"空话） | 幕功能位+种子池 |
| 2 | 意外性 | ≥2个"没想到"的转折（队友是卧底级反转，不是主角升级这种预期内的事） | 种子池暗线+幕功能位转折段 |
| 3 | 情感投入 | ≥1个情感锚点角色（读者会在意这个人的命运） | 种子池支线 |
| 4 | 爽感密度 | ≥60%的幕有爽点，且幕幕升级不是平的 | 幕功能位主收益列 |
| 5 | 卷末高潮 | 终幕是全卷最强爽点+卷末钩子有明确下卷期待 | 幕功能位终幕行 |
| 6 | 大纲批额对齐 | 本卷终点阶位/养成推进，未超 `03-全书大纲.md` 给本卷批的刻度（对照大纲本卷切片，超了即违规） | R1 卷终点+幕功能位主收益 |

### 任务C：幕白描（每幕一次）

plot 层最重要的产出，投入50%注意力。不是提纲，是给朋友讲故事——读完之后 outline 应该能感受到"这一段的温度是什么"。

**C1 输入加载**：

- `卷纲/卷N-卷纲.md`（幕功能位序列+种子池+债务列）
- `设计/卷舞台/卷N-舞台.md`（本幕场景地标/势力矛盾/新角色锚）
- `设计/角色库/角色库.md`（登场角色语言指纹/欲望/关系）
- `产出/状态快照.md`（重产幕时必读，吸收正文偏差：新增钩子/数值/关系变化）

**C2 叙事流生长**（整幕一口气，不拆章不贴标签）：

从卷纲种子池里挑本幕要发芽的种子，从卷舞台里挑本幕要用的场景和势力，从角色库里挑本幕登场的人。然后讲故事——800-2000字，有画面有温度有转折。

必须包含：

- **起承转合完整弧线**：不是四个标签，是故事自然走完一个圆
- **2-4条故事线交织**：情感+成长+战斗，一条线撑不起一幕。每条线有独立核心事件+独立爽点
- **主角主动驱动**：主角在做决策和行动，不是被世界推着走
- **危机循环完整**：危机→手段→变强→解决→新危机，手段与上一幕不同
- **至少1个非主角视角段落**：切到敌人/旁观者的眼睛，看到什么/不知道什么。制造信息差，不是主角猜
- **成长分散在多个活动**：不一次连升3级
- **1-2次挫折且每次推动转向**：挫折不是凑数，是让故事拐个弯
- **前1/3有爆发爽点**：首杀/面板激活/越级击杀，别憋着

叙事流中现编的新设定（地名/人物/组织/规则），随手登记到 `设计/全书设定/生长-新编资产.md`。现编是权利不是罪，登记是义务。

**C3 逐章白描卡沉淀**：

叙事流写完，往回拆——从故事里沉淀每章的施工锚。每章一卡，禁止跳章禁止区间合并。

每卡两段：

- **白描段（150-250字，硬性）**：场景画面（在哪+什么氛围）+事件推进（发生什么）+至少1个对话锚或动作锚（关键台词一句/决定性动作一个，直接可落）+情绪转折（本章内弧光位移）+章末钩子落点
- **锚点段**：爽点（公式类型+落点，每章≥1）/章末钩子（L1-5）/POV（含切换+目的）/关键数据（面板数值/登场退场/不可逆事实）/出场人物（全部角色）/本章线动作（每条种子线"线名：入→出"目标）/出章面板（硬锚+可编区间，防章内升级撞车）

**事实校验**：关键数据和出场人物中的年龄、等级术语、人名，产卡前对照状态快照的禁止漂移清单。白描卡写错会经章纲原样传染正文。

**C4 自检+落盘**：

落盘 `卷纲/卷N-幕M-白描.md`（模板 `templates/幕白描.tpl.md`）。

**幕内自检**（写完一幕数一遍，超差当场改）：

- 每卡白描段≥150字且含对话锚或动作锚
- 章型无连续2章同种、战斗模式无连续3章同种
- 爽感公式分布无单一类型>50%
- 大爽点前有2-3章压力铺垫
- 角色登场/退场章对齐角色库
- 幕末质变对齐卷纲幕功能位行
- 「不能抢的后续收益」未提前兑现

**快爽自检**（每幕强制门禁，七查全绿才交付outline）：

战斗按「场次」计：一场=独立对手+独立目的+独立空间。一章含3段小遭遇=3场；同一战役同一目的同一战场=1场。高烈度智斗算冲突不算战斗场次。

| 查 | 检查项与阈值 |
|:--|:--|
| 查1 战斗密度 | 场次密度硬底线≥1场/5章（阻断）、目标线≥1场/3章；无战间隔≤5章；首杀≤ch0004（卷一红线）；每场在白描卡内有≥1句「怎么赢」打法锚 |
| 查2 冲突覆盖 | 冲突=战斗/智斗/压力对抗/情感对抗任一；零冲突章≤幕章数10%；连续2章零冲突=阻断 |
| 查3 成长收获 | 每章爽点锚≥1；任意3章滑动窗口≥1次成长事件（面板/技能/装备/情报/人脉/威名）；成长不抢后续收益 |
| 查4 钩子 | 钩子率100%且每卡带L级标注；每幕≥2个L4+；幕末钩=卷纲幕功能位行；大爽点章的后1章须有承接 |
| 查5 节奏红线 | 铺垫≤3章必爆；禁连续2章同章型；蓄力≤2段/章 |
| 查6 对齐 | 幕头=卷纲幕功能位对应行；本幕章数=卷纲预算；角色登场/退场对齐角色库（±1章容忍） |
| 查7 事实一致 | 白描卡年龄/等级术语/人名与状态快照禁止漂移清单零冲突 |

自检表追加到幕白描文件尾部。

**滚动产幕**：推荐"产幕N→outline拼章纲→write写正文→产幕N+1"滚动，让后续幕吸收正文沉淀。

## 红线

1. **盘账先行**：不动账不动笔。任务A前必须读完状态快照+主线+上卷舞台档，缺哪个回哪个上游补。任务C重产幕前必须读状态快照吸收正文偏差。
2. **剧情先行、舞台现编**：允许无铺垫引入新地图/人物/势力，现编即登记到生长-新编资产.md。stage卷级刷新时回编。但PRD/卷需求brief定的方向不发明、不矛盾，方向不足回上游。
3. **白描卡信息量下限**：每卡≥150字+≥1对话锚或动作锚+每章爽点≥1。一句话梗概=回炉。禁止跳章/区间合并。
4. **快爽自检绿灯才交付**：每幕白描必须过七查，未过=回炉，禁止带病交付outline。
