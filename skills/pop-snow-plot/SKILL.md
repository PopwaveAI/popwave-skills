# pop-snow-plot

> 剧情编排——把融合立项稿剧情组长成剧情长档（全书卷进度表＋卷纲＋幕白描）。当前版本 v3.0.3，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。
- **Pack**：缺口足够才取材，query 自生成；来源 **wiki 站 https://wiki.popwave.cn** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query / 回传 ≤30KB，超限截断仅留结论区。
- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版，不越权定终局。
- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

---

**与融合立项稿的关系**：`立项/00-融合立项稿14维.md` 是全书宪法骨架层，剧情组（8 故事大概／9 剧情线／10 成长曲线／11 前中后期）＋敌人阶梯（7）是 plot 的主消费源。plot 只在骨架内长成剧情长档，不发明骨架没有的方向；骨架模糊或要突破批额 → 回 seed 显式修订，不许静默超纲。

---

## 做什么

plot 管"这台戏唱什么"。stage 搭好台子，plot 往上排戏。

**四个任务口**：

| 任务 | 触发 | 消费 | 产出 | 下游 |
|:--|:--|:--|:--|:--|
| **P 全书卷进度表** | 首卷卷纲前（一次）；敌梯/骨架修订后重出 | 融合稿剧情组＋敌人阶梯＋stage 力量体系＋位阶-社会坐标谱 | `卷纲/00-全书卷进度表.md` | 任务A/B 逐卷对照；outline/write 量级感知 |
| **A 卷需求brief** | 每卷循环起点 | 融合稿剧情组＋进度表本卷行＋全书日志＋上卷卷纲 | `卷纲/卷N-需求brief.md`（含舞台点播清单） | stage 卷级点播 |
| **B 卷纲** | brief＋stage 长档就绪 | brief＋融合稿剧情组＋stage 长档（力量体系/位阶谱/角色库/势力格局/世界全书） | `卷纲/卷N-卷纲.md` | pop-snow-outline（从卷叙事切章纲） |
| **C 幕白描** | 按需（用户点名/幕粒度信息不足） | 卷纲＋stage 长档＋全书日志 | `卷纲/卷N-幕M-白描.md` | pop-snow-outline |

**执行模式**：主agent直执。用户在场走选项（给选项不给空白，每轮2-3方案＋自定义入口）；不在场 agent 自定并标注。卷纲头部记共创状态与拍板记录。

**任务C 默认态**：卷纲第一屏卷叙事已承担叙事闸、outline 章纲已是叙事形态——幕白描**默认不逐幕必跑**，用户点名或某幕章数大、线密、需预埋细锚时启用。（独立"卷叙事脚本"环节去留待老板拍板，当前默认由卷纲第一屏承担。）

**增量信息三个注入口**：卷需求brief（用户注入新想法）／幕白描现编（登记回填 stage 长档）／用户随时插话（plot 吸收后继续）。

## 怎么操作（SOP全内联）

### 任务P：全书卷进度表（卷前必出，一次）

像拉数值养成线一样排全书：

- **结构**：纵轴卷1~终卷，横轴四维——**力量位阶／社会地位／本卷卷敌／距终点贡献**，逐卷一格。
- **四维联动**：每卷四维都要动；**不许原地踏步、不许往回缩、不许跳段**——神力台阶从微弱→弱等→中等→强大→伟大的**每一格都要走**，不许临近结尾直接跳到伟大收场。
- **位阶对齐** stage `位阶-社会坐标谱`：每一格"多高"读者可感知（爬到第几阶=能带队守防线/一城之将/世人张口就念的神名）。
- **成长斜率自定义**：主养成线不线性——按篇幅和爽点密度逐卷定斜率；前期陡（快节奏抢留存）、中段换节奏、后期重质量。
- **卷敌够格**：每卷卷敌是将级怪级（有名有姓、战力在线、声势压人），不是文官/管事。

落盘 `卷纲/00-全书卷进度表.md`（模板 `templates/全书卷进度表.tpl.md`）。**落盘后半步=消毒**：`python skills/pop-snow-pipeline/scripts/deai_gate.py 卷纲/00-全书卷进度表.md --profile doc --json`——WARN 定位自查、机械项 `--fix`，回执一行 `消毒:全书卷进度表|PASS` 或 `WARN×N`。用户逐卷审拍板。

### 任务A：卷需求brief（每卷一次）

给 stage 的点播单＋给自己的方向盘。brief 不定细节，只框范围。

**A1 盘账**（读完再动笔，缺哪个补哪个）：

- 融合稿剧情组：本卷段位置＋该推进的剧情线
- 进度表本卷行：位阶／地位／卷敌／贡献——本卷量级锚
- `全书日志.md`：上卷写到哪、主角阶位/面板/关系现状、悬着的钩子
- 上卷卷纲：长线债务／不能抢的后续收益

盘账产出三张清单：**债务清单**（哪些本卷该还，标偿还条件）/ **资产清单**（上卷现编的设定/角色，继续用还是封存）/ **钩子台账**（哪些已兑现、哪些悬着）。

**A2 定调五问**（顺序不可倒，第一问先答）：

1. 本卷给终局供什么？（具体化成人/物/情报/格局——这卷让离结局更近哪一步）
2. 本卷什么感觉？（压抑蓄力/扩张爽感/谷底反弹……一句话情绪基调）
3. 主角卷末站在哪？（位阶对齐进度表本卷行，坐标系至少一项跃迁）
4. 读者卷末记住什么？（最重的一击）
5. 本卷新增什么舞台？（→舞台点播清单，喂 stage）

**A3 落盘** `卷纲/卷N-需求brief.md`（模板 `templates/卷需求brief.tpl.md`）→ **落盘后半步=消毒**：`python skills/pop-snow-pipeline/scripts/deai_gate.py 卷纲/卷N-需求brief.md --profile doc --json`——WARN 定位自查、机械项 `--fix`，回执一行 `消毒:卷N-brief|PASS` 或 `WARN×N`。

### 任务B：卷纲（每卷一次，plot 的核心产出）

**思考顺序即纪律（先公转后自转）**：先问终局（这卷给结局供什么）→ 再定冲突（敌人挡在交付路上，冲突被解决的方式=交付完成的方式）→ 后排剧情（幕/爽感/种子围绕"解决冲突=完成交付"展开）。

**B1 先钉两件事（卷纲强制首两节，没钉死不推幕）**：

- **卷一级敌人**：本卷最大阻碍——具体到人名/表面身份（在主角头顶哪一层）/里子勾当（利益从哪来）/为什么挡主角（有接触点，不是随机碰上）/尺度（卷内可清算，为后续卷留口）。**够格**：战力在线、声势压人的将级怪——不是文官/管事。
- **本卷对终点的贡献**：终点={终卷·终点位阶}。本卷贡献几笔，每笔说清（根/底色/入场/人/物/情报/格局——"这卷让离结局更近哪一步"）。

**B2 卷叙事（第一屏·给朋友讲这卷）**：

一段话（300-600字）从起点讲到卷末停点——带起承转合、情绪起落、卷末钩子。**叙事在前、结构在后**：先讲故事，幕波浪/敌人/贡献只作后附解剖图。卷纲天然让人忘叙事，必须用"先讲故事"破。

**B3 幕序列（解剖图）**：

- 每幕=**单元剧完整闭环**：自成"危机→手段→变强→解决→新危机"，同时坐一个波浪位、推**卷敌线**与**终点贡献线**两条线。
- 四幕为保底（=四次波浪：谷底微起→明显抬升→最深的谷→全卷最高），可按节奏 4-6 幕；**终幕最重**。
- 每幕一行：单元剧闭环（这幕自己的起承转合）/波浪位/功能位/卷敌线推进/终点贡献线推进/幕末代价→钩子。

**B4 事件种子池**：主线种子（3-5条）/支线暗线种子（4-6条，标预计揭示卷）/世界观种子（2-3条）——每条一句话，量大但 brief，章纲自由选取。

**B5 长线债务＋不能抢的后续收益**：债务台账（线名/埋设卷/预计偿还卷/触发条件）；不能抢清单（后续卷的重头收益本卷禁提前兑现——如二阶质变/旧日级敌人/登神相关）。

**B6 卷末三件套**：面板/势位（对齐进度表本卷行）＋新局解锁＋下卷钩子（"下一阶的坎已在眼前"的栓）。

**B7 人话复审（落盘闸，替代旧七问）**：落盘前通读一遍，用故事本身验收：

- 卷敌人从头到尾压场、卷内可清算？
- 对终点贡献笔笔有着落？
- 幕幕成环、波浪起伏、终幕最高？
- **量级闸五件**：正式进阶/职＋有名有姓名声＋干掉卷敌＋被主流接纳拔擢＋下一阶的栓——齐吗？（缺任一=回 B1 重钉）
- 读一遍想不想追？

**落盘前先过资料门**：本卷要排的冲突、剧情线、单元剧闭环需要真实事件结构，但 `素材/采风/剧情-*` 没对应种子→**先派 research 剧情定向补采（冲突升级/转折/解开模型，落 `素材/采风/剧情-{主题}.md`、来源可回源）再落盘**。资料门过 → **落盘** `卷纲/卷N-卷纲.md`（模板 `templates/卷纲.tpl.md`）→ **落盘后半步=消毒**：`python skills/pop-snow-pipeline/scripts/deai_gate.py 卷纲/卷N-卷纲.md --profile doc --json`——WARN 定位自查、机械项 `--fix`，回执一行 `消毒:卷N-卷纲|PASS` 或 `WARN×N` → 交接 outline（从卷叙事切章纲）。

### 任务C：幕白描（按需）

启用时投入全量注意力——不是提纲，是给朋友讲故事：

**C1 输入**：卷纲（幕序列＋种子池）＋stage 长档（场景/势力/角色）＋全书日志（重产幕必读，吸收正文偏差）。

**C2 叙事流**：整幕一口气 800-2000 字——起承转合完整弧线/2-4条故事线交织/主角主动驱动/危机循环完整（手段与上一幕不同）/≥1个非主角视角（切敌人或旁观者的眼睛，制造信息差）/成长分散在多个活动/1-2次挫折且推动转向/前1/3有爆发爽点。现编设定随手登记回填 stage 长档。

**C3 逐章白描卡**：从叙事流往回拆，每章一卡（禁止跳章/区间合并）——白描段 150-250 字（场景画面＋事件推进＋≥1对话锚或动作锚＋情绪转折＋章末钩子落点）＋锚点段（爽点公式+落点/章末钩子/POV/关键数据/出场人物/本章线动作/出章面板）。

**C4 事实校验＋落盘**：年龄/等级术语/人名对照全书日志禁止漂移清单；**落盘前资料门**：某幕要排的冲突/事件模型 `素材/采风/` 没有支撑→先派 research 剧情定向补采一点再落盘；落盘 `卷纲/卷N-幕M-白描.md`（模板 `templates/幕白描.tpl.md`）→ **落盘后半步=消毒**：`python skills/pop-snow-pipeline/scripts/deai_gate.py 卷纲/卷N-幕M-白描.md --profile doc --json`——WARN 定位自查、机械项 `--fix`，回执一行 `消毒:卷N-幕M-白描|PASS` 或 `WARN×N`。读一遍自检：每卡可落笔、事实零漂移、未抢后续收益、幕末质变对齐卷纲幕序列行。

## 红线

1. **量级闸（卷纲强制）**：卷终主角必须到"当众亮得出成绩"的爽点级终点——正式进阶/职＋有名有姓的名声＋干掉本卷大敌＋被主流接纳拔擢，并给下一卷铺"下一阶的坎已在眼前"的栓。**严禁缩成"刚起步/摸到门/待考察"安全垫——那等于给读者喂屎。**
2. **成绩的斤两看对手**：够格的大战绩=当着公开大场面斩落一个有名有姓、战力在线、声势压人的冲突目标（将级怪，不是文官/管事）；手段＋临门突破＋代价撑起"可就"的密度。
3. **卷一级敌人＋对终点贡献=卷纲强制首两节**：没钉死不推幕。
4. **进度表四维联动**：逐卷一格、不许原地踏步/往回缩/跳段；位阶对齐 `位阶-社会坐标谱`；超批额回 seed 显式修订，不许静默超纲。
5. **叙事在前结构在后**：卷纲第一屏是给朋友讲的故事，不是表格；四幕波浪/敌人/贡献只作后附解剖图。
6. **幕=单元剧完整闭环**：每幕自成危机循环＋坐波浪位＋推两条线（卷敌线/终点贡献线），不是孤立"功能位"。
7. **快节奏基准**：前3章立人（穿越＋烂壳＋死局同章砸出、第3章靠前世脑子破局活着回来被看见）、前10章闭环、之后每两三章一个单元剧闭环（压力→破局→即时回报→立刻新压力）、不空铺世界观。
8. **盘账先行**：任务A前必须读完全书日志＋进度表＋上卷卷纲；任务C重产幕前必读全书日志吸收正文偏差。
