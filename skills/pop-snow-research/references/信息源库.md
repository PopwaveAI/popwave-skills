## 快速起手式（每场景 1 个 query 就能起步）

> 实跑经验：不必一次全站逛，每个场景给 1 个默认 query 起步，命中了再深挖。

* **世界观**：`{赛道} + 世界观/设定 + 素材/考据` → 命中 B站/百科/写作素材帖后深挖。

* **剧情**：`{赛道} + 小说百科 或 {题材} + 真实{行业}危机/事件` → 命中小说百科结构帖或新闻站。

* **人物·势力**：`{赛道} + 职业/组织/原型 或 {职业} + 语言/阶层` → 命中中世纪职业/组织运作考据。

* **力量·养成**：`{赛道} + 境界/职业/法术/数值 体系` → 西幻直奔 DND SRD；仙侠直奔修真境界词条；都市直奔神豪财富参数。

> **西幻实跑经验（2026-09-08 三份采风落盘验证）**：搜"中世纪+制度/行会/城堡/信仰"能稳定命中 阅文历史在线阅读、OUR RHINE、学科网课件、社科院/人大期刊 等高回源度站；搜"DND+职业/法术"命中 D\&D Beyond 官方职业卡。中世纪社会制度/地理信仰力量/人物职业原型三份采风均出自真实可回源站点（标注于每份元数据与速查）。
>
> 每个站首次用先 `WebFetch` 通不通、看内容颗粒度，再决定落盘哪些条目；标注多为 `🔶` 的站首次用时转 ✅ 并回写本库。
