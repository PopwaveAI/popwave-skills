# pop-snow-review

> 章节验收 + 归档。就三件事：确认本章正文满意（定稿）→ 生成本章日志 → 更新全书日志。当前版本 v1.5.1，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

<br />

## 这是什么

review 是"写完这一章、准备写下一章"之间那道归档闸门。它**不审质量**——质量是 write 的事；它只负责把"这一章发生了啥"记下来、把"整个世界现在该是啥样"更新到最新，让下一章开写之前有可依据的准。

**正文没让用户满意前，不进账本**（还在改的，别记）。

## 三件事

| # | 活 | 产出 |
|:--|:--|:--|
| 1 | 确认本章正文满意 | 满意=定稿（不满意→打回，不入库） |
| 2 | 按定稿正文，生成本章日志 | `章节日志/ch{NNN}.md`（本章档案，只增不改） |
| 3 | 按本章日志，更新全书日志 | `全书日志.md`（当前态，replace 只记活跃）＋回收项入 `退出档案.md` |

## 两个产物 + 一个仓库

- **本章日志**（=单章日志/卡片）：每章一张，只增不改，存"这一章怎么了"（事件源，历史）。
- **全书日志**（=状态快照）：单份 replace，只记"当下仍活跃的"（现在在哪／人物此刻／此刻悬着的线／还没揭的悬念／不许碰）——当前态投影。
- **退出档案**：从全书日志移除的（已回收钩子／已退场角色／已完结线）落这里，留痕防失联。

> 三条心法：
> 1. 全书日志**只记活跃**——人物退场/钩子已回收/线已完结，就从全书日志挪进退出档案，别再留在当前态；这样它"进得来出得去"，100 章也不臃肿。
> 2. **世界规则/静态设定不进全书日志**——力量体系/货币/地理这些在大纲·设定库·卷纲里已有，再记就是重复、就是双源打架。
> 3. 全书文档**不拆分**——当前态就是全书日志这一份，靠"只记活跃"压体积，不搞一堆文件。

## 步骤

**第 1 步 确认满意＋消毒核验**
读本章正文。判断：用户/完成度上，这章算定稿了吗？
- 满意 → 定稿，进第 2 步。
- 不满意 / 还要改 → 打回 write（或告诉用户），**不入库**，结束。

**消毒核验（闭环闸）**：查上游消毒回执——①write 交接的正文消毒结果（body 闸 FAIL 清零）；②outline 章纲的 `消毒:ch{NNN}-章纲|PASS` / `WARN×N` 回执。章纲缺回执 → review 补跑 `python skills/pop-snow-pipeline/scripts/deai_gate.py 卷纲/章纲/ch{NNN}-章纲.md --profile doc --json` 一次（doc 报告闸：WARN 定位自查、机械项 `--fix`），并在对话注明补消毒；正文消毒回执缺失 → 在本章日志备注"上游消毒回执缺失"，提示 write 下章前补跑。报告闸只报不打回，核验不阻塞归档，但必留痕。

**满意判别标准（第 1 步"确认满意"时逐条核，供"定稿/打回"判据，不审文风只审一致性/连续性/设定三把尺）**：

| # | 判别维度 | 判定 |
|:--|:--|:--|
| 1 | **硬状态承接** | 位置/伤势/能力/持有物/信息边界与上章结尾、全书日志无错位；"突然想到/突然做到"糊过去=不一致 |
| 2 | **行为可信（动机6问）** | 异常行为能由 经历→利益→恐惧→渴望→压力→误判 推出；**只能用"剧情需要"解释=OOC**；**信息越界（角色知道他不该知道的）最严重，优先于性格偏差** |
| 3 | **对白遮名辨人** | 关掉角色名仍能分辨谁在说话（称呼/句长/语气/禁忌）——抽 1-2 段验 |
| 4 | **钩子承接** | 上一章钩子在本章有反馈（回应/推进/误导/压住），章末留新缺口，未提前吞并未到期钩子 |
| 5 | **章末落地改变** | 信息/关系/物理/权力 至少一类落地；**四类皆无=空转章** |
| 6 | **高潮后效** | 本章处大高潮后 1-2 章时，是否写出改变（主线推进/人设成长/关系变化），不能直接跳下一个蓄压 |
| 7 | **设定矛盾抽查** | 能力使用无越界（等级/消耗/上限/克制/后效）；单章新设定≤2；无解释的瞬移/传讯默认判风险 |

**打回意见（四要素格式）**：位置（章节/段落/句子）→ 问题（违反哪条既有事实/信息边界）→ 严重性（严重/警告/提示）→ 改法（不改变核心剧情的最小修复）。按此给 write，**不替 write 写文、只给方向和最小修法**——通过才入库，最多 2 轮。

**第 2 步 生成本章日志**
按定稿正文写 `章节日志/ch{NNN}.md`（模板：`templates/chapter-card.tpl.md`）：
1. 时间 · 地点 · 人物
2. 本章剧情（顺一遍，回看用）
3. 这一章定了哪些事（改了后文对不上的重事实）
4. 这一章动了哪些线（`线｜这章干了啥｜线现在走到哪`）

> **write 交接并入**：write 对话回复给【冲突标注/新增事实待核】——review 核验有效性后并入"这一章定了哪些事"，write 只声明不落库，落库以 review 为准。

> **字数=消费 write 交接数据**：字数门禁已在 write 内闭环（word-count.ps1 由 write 落盘后自跑，不足自扩写，不交 review 补救）。review 不跑字数脚本，直接把 write 交接的 stdout 原文（`chNNN.txt|汉字N|判定:PASS`）填进本章日志"字数"栏；交接缺失时追问 write，不自己补跑。

> **落盘后半步=消毒**：章日志落盘后自跑 `python skills/pop-snow-pipeline/scripts/deai_gate.py 章节日志/ch{NNN}.md --profile doc --json`——WARN 定位自查（档案措辞贴事实，装腔换大白话）、机械项 `--fix`，回执一行 `消毒:ch{NNN}-章日志|PASS` 或 `WARN×N`。

**第 3 步 更新全书日志**
打开 `全书日志.md`，按本章日志 replace：
- 新人物 / 新线 / 新悬念 → 进"活跃"；
- 已解 / 已弃 / 退场 / 已揭 → 移出"活跃"，落 `退出档案.md`
  -（模板：`templates/state-snapshot.tpl.md`、`templates/exit-archive.tpl.md`）；
- 更新"现在在哪"，给出下一章开写前的准。
- 这章若有意改翻了某条旧现状 → 当场在全书日志标"改了哪条、为什么"，留痕。
- **落盘后半步=消毒**：全书日志 replace 后同第 2 步步法自跑（`退出档案.md` 本轮有追加也一并跑），回执一行 `消毒:全书日志|PASS` 或 `WARN×N`。
- 结束。

## 红线

1. **正文没定稿，不入库**：还在改的别记。
2. **全书日志只记活跃**：回收即移出并入退出档案，不残留。
3. **世界规则/静态设定不重复进全书日志**。
4. **本章日志只增不改**（历史）；**全书日志单份 replace，不拆分**。

## 速查

| 模板 | 用在哪 | 说明 |
|:--|:--|:--|
| `templates/chapter-card.tpl.md` | 第 2 步 | 本章日志模板 |
| `templates/state-snapshot.tpl.md` | 第 3 步 | 全书日志·只记活跃（replace） |
| `templates/exit-archive.tpl.md` | 第 3 步 | 退出档案·归档（追加） |

## 批量回溯（可选）

对已有正文批量重建时，用同一个流程逐章跑：每章做第 1 步（存量正文视为已定稿）→ 第 2 步建本章日志 → 第 3 步合进全书日志。批量不宜一次硬吞，按采样/分批逐章推进。
