# pop-snow-seed

> 统一管线立项——按「终点优先」模板共创全书大纲：**L0 参考消化（输入约束）→ 定终点 → 反推世界舞台 → 定主角团 → 定起点 → 排敌人阶梯 → 输出 L0-L3 大纲（输出约束）**。每步用户逐层拍板、串行定稿（无真人时走 agent 自定态），定稿即全书宪法。当前版本 v4.0.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。

- **Pack**：缺口足够才取材，query 自生成；来源 **wiki 站** **<https://wiki.popwave.cn>** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query / 回传 ≤30KB，超限截断仅留结论区。

- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版，不越权定终局。

- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

## 做什么

**seed 的核心职责 = 按「终点优先」模板，共创一套全书大纲。** 核心思想：**先设想终点（终点给读者什么补偿、主角图什么），终点把故事锁一大半；其余全部为终点服务。** 1\~6 步思考走完，大纲直接成型——不是"逐层创造"，是"一次想透、分层落盘"：

| 步骤                  | 干什么                                                                      | 对应产物                        |
| :------------------ | :----------------------------------------------------------------------- | :-------------------------- |
| **0·L0 参考消化**（输入约束） | 消化用户给的参考（博德3/DND/克苏鲁/战锤40K等）+卖点方向库+拆书包，拆出"终点形态/危机/敌人谱系/主角特殊性/结构节奏"五类可用骨架 | 参考消化结论（进上下文）                |
| **1·定终点**           | 锁最终敌人（具体可恨对象）+ 终点状态（终点给读者什么补偿）+ 主角图什么                                    | `立项/00-L0核心卖点.md`（终点卡+卖点包装） |
| **2·反推世界舞台**        | 终点需要的容器：位面/力量体系/格局/时代变局                                                  | `立项/01-命运图.md`（世界舞台段）       |
| **3·定主角团**          | 主角（最大份额）+核心同伴（情感锚点/战力/主线绳）+次要主角（各带成长线不脱主线）                               | `立项/01-命运图.md`（主角团段）        |
| **4·定起点**（处境）       | 起点=读者为什么代入；可替换式设计（凡人底层/富商之子/邪教人质…）                                       | `立项/01-命运图.md`（四钉·起点钉）      |
| **5·排敌人阶梯**         | 起点→终点，由弱到强每级=可打对手+真实利益反扑；波浪式上升的骨架                                        | `立项/02-命运图plus.md`（分卷走向）    |
| **6·输出大纲**（输出约束）    | 1\~5 走完直接落 L0-L3 四产物，格式须被 stage/plot/outline/write 有效消化                  | `00/01/02/03-*.md` 四产物      |

**共创原则（立身之本）**：每一步都是"agent 出草案 → 用户拍板 → 改 → 再拍"的来回拉锯。**用户拍板是每步的唯一关卡**，不是 agent 自检。审美判断（动不动人/好不好看/逻辑密不密）全部发生在用户与 agent 面对面共创的这几步，在源头被人的判断接住，不在下游被规则拦截。

**下游对接**：L3 全书大纲=全书宪法。pop-snow-stage 消费大纲补世界血肉（力量体系数值化/势力/地理/角色库）；pop-snow-plot 在大纲的一卷切片内展开卷纲→幕白描，不许突破大纲刻度；pop-snow-outline/write 接力正文。

## 执行模式

**主 agent 直执，禁用子agent代跑共创。** seed 是全链路交互最密集的环节——每步都要和用户对话、拍板、修改，这些共创对话必须由主 agent 亲自进行，不得派发给子agent。

**唯一例外**：纯只读的调研支撑（扫榜/拆书包内容检索/参考材料消化）可派子agent回报原始材料，主agent消费。但凡涉及"出草案给用户看、听用户意见、改稿"的环节，一律主agent。

**共创三态（决定每步走哪套拍板）**：

1. **共创态**（默认）：用户在场，每步端候选给用户圈定 → 拍板定稿。这是 skill 的主设计。
2. **代理自定态**（无真人/自动化/评估环境）：用户不在场或明确"你全权定"。agent 以 `agent 自定` 模式逐层自拍板：每层自出最优草案、自审自拍，全程串行推进。拍板结果在「用户拍板」栏显式标注 `[](agent自定·{原因})`，共创记录用户意见栏同样标注，禁止伪造"用户说过"。
3. **共创→自定降级**：共创进行中用户中途离开——已拍层保持用户意见，未拍层降为 agent 自定继续，降级时刻写进共创记录。
   所有产出物头部「共创状态」按三态如实标注：已定稿（用户拍板于·共创态）/ 已定稿（agent 自定·{原因}）。

execution.mode：formal（落盘定稿）/ draft（共创中，未拍板）。

## 怎么操作（SOP全内联）

### 输入约束：L0 参考消化（定终点的唯一前置，先做这一步再谈终点）

> **核心思想（老板定调）**：L0 的参考能给到**多么细、多么全**，决定后面大纲的成色。**定终点前必须先消化参考**——终点本身就把故事锁了一大半，不看参考就定终点=闭眼开车。L0 卖点不是最后一道皮，是定终点前的第一道门。

**干什么**：把用户给的参考（如博德之门3/DND/克苏鲁神话/战锤40K）+ 卖点方向库 + 拆书包，消化成五类可用骨架，作为定终点的材料。**参考不是"看过"，是"拆出能用的骨架"。**

**消化五件套（每个参考都拆出这五样）**：

| #  | 拆什么       | 问什么                             | 例子（博德3）                                                         |
| :- | :-------- | :------------------------------ | :-------------------------------------------------------------- |
| 1  | **终点形态**  | 这个参考的"终点/高潮形态"是什么样？危机是怎么收场的？    | 至上真神：第一卷不是正式解决，而是借主角团之手脱离死亡三神控制、遁入下层位面"鱼游入海"，叠加圣者危机，逐渐成长为最终boss |
| 2  | **危机**    | 读者不喜欢的现象/危机是什么？具体到可恨对象          | 至上真神/夺心魔危机：夺舍、改造、大灭绝级威胁                                         |
| 3  | **敌人谱系**  | 由弱到强的敌人怎么排？每级是谁                 | 第一章区域boss→整个费伦世界级危机，敌人与主角同步成长                                   |
| 4  | **主角特殊性** | 主角凭什么能走到终点？落在哪一档（偷步/加速成长/抗性/覆盖） | 起源角色各带身世与成长线，意志/血脉/神性等可解释来源                                     |
| 5  | **结构节奏**  | 单元是什么？主线怎么回收？几章一个闭环             | 起源角色个人任务+主线并行，每个角色一段成长弧                                         |

**来源与顺序**：

1. 用户给的参考**最先消化**（用户点名=优先级最高，如博德3/DND/克苏鲁/战锤40K）；
2. 卖点方向库 `https://wiki.popwave.cn/卖点方向库`（目录级自找，母题卡=五类谱系+融合方式+判据）——补母题类型与已验证套路；
3. 拆书包匹配（找最近标杆）：扫描 wiki 写作灵感区 `https://wiki.popwave.cn/写作灵感/{赛道}`，找赛道/机制最接近的拆书包，读它的 `写作灵感/{赛道}/{书名}/seed-*` 卡（seed-L0卖点卡/seed-L1命运图/seed-L2分卷走向/seed-L3全书大纲），拿骨架对标。无接近的拆书包→声明裸原创，从方向库做实。

**输出**：消化结论（每参考的五件套拆解），进上下文供 Step 1 定终点使用。**消化不到位（参考看过说不出骨架）禁止进 Step 1。**

> **⚠️ 踩坑两条（批次2 实测补录）**：
>
> 1. **wiki 赛道目录名大小写折叠**：wiki 侧赛道目录是**全小写无分隔符折叠**（实测为 `写作灵感/西幻dnd/…`，非 `写作灵感/西幻DND/`）。照任务里的习惯大写直接 404。拿不准时先试小写，或直接访问「卖点方向库」页脚链到的示例路径确认实际写法。
> 2. **裸目录不可枚举书目**：`写作灵感/{赛道}/`（不带书名）返回 nginx 页、无目录列表，**别依赖目录列表去发现有哪些书**。发现参考书的可靠入口 = 「卖点方向库」页脚链接 / 已知识名书种子卡直连 `写作灵感/{赛道}/{书名}/seed-L0卖点卡`。若某赛道在 `写作灵感/` 下无 seed-\* 卡（该赛道拆书数据未迁移），即走"无接近拆书包→裸原创+方向库做实"路径，并在共创记录里注明"该赛道 seed-\* 卡缺失，裸原创"。

### Step 1：定终点（全书宪法第一钉，终点锁死故事一大半）

**干什么**：锁三件事——**① 最终敌人是谁（具体可恨的对象，能列出一排爪牙）② 终点状态（主角最终把世界变成什么样，终点给读者什么补偿）③ 主角图什么（驱动欲望）**。这一步是整个模板的心脏，**后面所有步骤全为它服务**。

**驱动套别（先锁主角图什么，再谈别的）**：

| 套别       | 主角的驱动欲望         | 终点补偿                  | 代表作                                  |
| :------- | :-------------- | :-------------------- | :----------------------------------- |
| 套1·改变型   | 读者不喜欢的世界危机，改变命运 | 变强+整顿世界；或"逃出/暂时缓和"留续集 | 深渊主宰（登神改变命运）、诡秘（缓和外神入侵）、无限恐怖（逃出主神空间） |
| 套2·经营扩张型 | 把我的一亩三分地立成王     | 地盘/势力/王朝              | 领主文、种田基建                             |
| 套3·情感执念型 | 守着某个人/弥补遗憾/讨一口气 | 守住那人那口气               | 重生文、复仇文                              |

> 套1 内部：终点两种——推到顶点彻底改（登神/砸了主神空间/弄清真相并解决）= 定稿结局；只到"逃出/暂时缓和" = 结尾留续集。套2/套3 可叠进套1（解决危机过程中普遍带经营/情感推进）。

**终点三判据（锁"终点定多高"可操作的尺）**——终点高度不由感觉定，由三把尺共同锁：

1. **与母题/赛道的匹配烈度**：终点是母题内在逻辑的自然终点（登神文→神位；克苏鲁→看清深渊并被吞没/超脱；猎杀者→猎得最大目标），不是随手安"世界最强"。问：这个终点是不是这个卖点撑得起的最合理顶点？
2. **落差可兑现（波浪式上升）**：起点到终点的距离，必须能排出一条**由弱到强的敌人阶梯**一格一格爬完，全程敌人梯度接得住，不会"卷一就打最终BOSS"。问：从起点到终点这条路，梯子够不够长、够不够陡但爬得动？**一根急转弯（半卷就打到最后）→ 判死，回炉。**
3. **终点形态头尾呼应**：终点的"身份/位置"要能回扣起点和最大反转。问：终点是不是让主角"最初的处境/隐藏的真相"有了最大兑现？

**三毒点排除（定终点时就要验）**：

- ✗ **禁"任意改根规则/随心所欲"型金手指**：一出手就是终局，没得爬坡（哥布林"找规则漏洞"=死刑判据）。特殊性必须落在**系统内偷步/加速成长/抗性/覆盖**这一档（对标：不交税魂力自留→加速成长；覆盖灵魂烙印→引发神战）。

- ✗ **禁"神转世/天选"当理由**：用"审判者转世/天选之人"解释主角为什么特殊=双倍机械降神（仙侠《赦罪》=死刑判据）。特殊性来源必须**可解释、符合世界内在逻辑**（血脉/体质/知识/经历/选择）。

- ✗ **禁"丢记忆/丢人性/反噬伤己"式主角副作用**：给主角设计任何副作用、让主角产生负面效应的都是重大毒点（《律》剪记忆填世界=死刑判据）。代价应由外部世界承担（被追杀/利益反扑），不是从主角身上割。

**共创流程**：agent 基于参考消化，出 1-3 个终点候选（各带最终敌人+终点状态+主角图什么+三判据判定+三毒点排除）→ 用户选/改/拍板 → 定稿。**终点没拍板，不进 Step 2。**

**输出**：终点卡（进 `00-L0核心卖点.md` 的"终点卡"节），一句话锁死：这本书讲"主角从{处境}走到{终点状态}，改变了{危机/敌人}"。

### Step 2：反推世界舞台（终点需要的容器）

**干什么**：终点定了，反推"什么样的世界才装得下这个终点"——位面格局/力量体系/时代变局/势力分布。**不是随便设个背景，是终点倒逼出来的容器。**

**四问（每问都回扣终点）**：

| 问    | 干什么                 | 例子（西幻DND·死亡之主终点）                                 |
| :--- | :------------------ | :----------------------------------------------- |
| 世界形态 | 什么世界/位面结构？          | 多元宇宙：上层位面/下层位面/主物质（费伦），有神系无神上神IO，三巨头格局（光辉/死亡/地狱） |
| 时代变局 | 什么大事件/窗口期驱动全书？      | 圣者浩劫/万法重叠类变局，规则松动、旧秩序洗牌                          |
| 力量体系 | 什么力量层级能承载从起点到终点的落差？ | DND 职业/等级/神性阶梯，凡人数级→半神→真神→伟大神力                   |
| 势力格局 | 谁掌权/谁在暗流/主角站在哪？     | 神系/教团/位面势力，主角从最底层位面站位起步                          |

**共创流程**：agent 出舞台草案（四问各答）→ 用户拍板 → 并入 `01-命运图.md` 的世界舞台段。**舞台不定，不进 Step 3。**

***

### Step 3：定主角团（主角+核心同伴+次要主角）

**干什么**：定主角团——**主角占最大份额**，核心同伴是"情感锚点+重要战力+最主要剧情线"（深渊主宰的妹妹：既是情感锚点，又是恐惧神子战力，又是去无底深渊推翻恐惧魔神的主线绳），次要主角各带成长线但不偏离大主线（像博德3起源角色：每个角色都有个人成长任务，但都不偏离"主角成为死亡之主"这条主线）。

**主角团三件**：

| 件    | 要求                                                                               |
| :--- | :------------------------------------------------------------------------------- |
| 主角   | 读者能代入的"处境里不甘的人"；特殊性可解释、落在偷步/加速/抗性/覆盖档（见 Step 1 三毒点）；金手指=叙事装置（成长机制+结构骨架+主线伏笔三重功能） |
| 核心同伴 | 情感锚点+战力+主线绳三合一；与主角有具体关系（兄妹/搭档/死敌转同路），情感线贯穿全书                                     |
| 次要主角 | 各带个人成长线/任务线（博德3式起源角色），**所有支线不偏离"主角走到终点"这条大主线**                                   |

**金手指三要素**：创意{形式}×机制{动力}×限制{≥3条且每条制造选择压力}——限制制造压力（被追杀/利益反扑/选择两难），**不是从主角身上割副作用**。

**共创流程**：agent 出主角团草案（主角三定位+核心同伴+次要主角表）→ 用户拍板 → 并入 `01-命运图.md` 的主角团段。**主角团不定，不进 Step 4。**

***

### Step 4：定起点（处境，读者为什么代入）

**干什么**：定起点=定处境——读者代入主角后**为什么咬牙切齿/心有不甘**。起点是"第一个敌人的替身"（第一个处境=第一个要解决的对手），**可替换式设计**：今天什么火了/什么处境最能拉代入，替换第一个处境即可，只要强度和敌人格局合理。

**起点的性质**：

- 起点通常=凡人底层（贫民窟孤儿/被轻视的杂役/被当经验刷的野怪/邪教人质/修道院僧侣觉醒），也可传奇开局（无敌流例外）——**不写死，由终点落差倒推**。

- 起点决定故事形态：凡人起点=从底层一路往上爬；传奇起点=另一种形态。

- 起点定完，才能划分中间有多少个阶梯、设置具体路径。

**共创流程**：agent 出起点候选（1-3 个可替换起点，各带"读者代入后的不甘感"说明）→ 用户拍板 → 并回 `01-命运图.md` 四钉·起点钉。**起点不定，不进 Step 5。**

***

### Step 5：排敌人阶梯（波浪式上升的骨架，全书最长气的来源）

**干什么**：从起点到终点排一条**由弱到强、每一级=一个可打的对手/可解决的一层**的具体阶梯（小怪→中怪→大怪→小boss→中boss→大boss）。**这是网文"波浪式上升、起承转合"的骨架——能不能写长全看这条梯子。**

**三律**：

1. **每级=一个具体可恨的对手**（不是抽象制度）：小怪=第一个处境里的敌人，中怪=挡在路上的利益集团，大boss=终点那个最终敌人；每一级都具体到"谁、什么势力、什么利益"。
2. **每级必须招致真实利益反扑**：主角动谁的蛋糕，谁就派人来打他——危机链由此而生，波浪由此而起。**没有反扑=世界是死的脚本，主角是机械降神。**
3. **每级强度/格局递进**：与终点落差匹配，不"卷一就打最终BOSS"，也不"结尾突然蹦出个没铺垫的大反派"。

**分卷走向（承接阶梯）**：把敌人阶梯摊到每卷——每卷一段走向（120-200字，纯单元剧卷≤120字），内容="本卷交付物+进场敌人/冲突+主角状态迁移+卷末困境"，用事实句写"发生了什么/成了什么"，**不写打法、不改对话、不铺具体场景特写**（那是 plot 的活）。判据一句话：这一段单独拿出来，outline 应该能看出"这卷完成了什么、卡在哪个困境上、下卷往哪走"，但看不出任何"某个具体战斗怎么打的"。

**每卷必立张力结构**：质变（实力/势力不可逆跃迁）+ 里程碑强敌（解决压了一段对手）+ 新困境/新敌（旧敌解决立刻引来更大麻烦）——三段合起来：主角每卷都在"爬一级台阶—踩碎一个拦路的—发现头顶还有更大的"。**任何一卷没有新困境，故事就在这里断了气。**

**共创流程**：agent 出敌人阶梯+分卷走向草案 → 用户逐卷审、提意见 → 拍板 → 落盘 `02-命运图plus.md`。**阶梯不定，不进 Step 6。**

***

### Step 6：输出大纲（L0-L3 四产物落盘，输出约束）

**干什么**：1\~5 步思考走完，**大纲就已经出来了**——不是"逐层创造"，是"想透了分层落盘"。输出约束：**格式合不合理、后面的文档能不能有效消化**，全在这一步检验。

**四产物（格式必须可被下游消化）**：

| 产物              | 内容                                                                 | 下游消化                                        |
| :-------------- | :----------------------------------------------------------------- | :------------------------------------------ |
| `00-L0核心卖点.md`  | 参考消化结论 + 终点卡（最终敌人/终点状态/主角图什么/三判据/三毒点排除）+ 一句话卖点包装                   | stage 知道"这书核心是什么"                           |
| `01-命运图.md`     | 世界舞台 + 主角团 + 四钉（起点/终点/最大反转/最大落差）                                   | stage 补世界血肉/角色库；plot 知道舞台与人物                |
| `02-命运图plus.md` | 敌人阶梯 + 分卷走向（每卷120-200字+张力结构）                                       | plot 逐卷展开卷纲；outline 看"这卷干了啥"                |
| `03-全书大纲.md`    | 结构化全书大纲：分卷剧情表（对终点的意义/卷命运/养成刻度/里程碑强敌/卷末新困境/卷末边界）+世界观/人物/养成节点+最大反转落卷 | **全书宪法**：stage/plot/outline/write 全部在它约束下做功 |

**L3 五提炼物（必须齐）**：分卷剧情安排（先"对终点的意义"再"卷命运"，列序即思考序）/ 世界观 / 人物（含主角团与债期收线）/ 养成系节点（主养成线全书刻度显式+副养成线卷间分配）/ 逻辑缜密自检（卷间因果链咬合、数值刻度不崩、伏笔债线有收、最大反转落卷前伏笔已铺、敌人梯度连贯、每卷张力承接 L2、意义列与 L2 第一句对应、与 L1 一致）。

**输出自检（格式闸门）**：四产物单独拿出来，下游 agent（stage/plot/outline/write）能不能**只看这个文件就知道下一步干什么、不能干什么**？看不懂/信息不够→回改。

**共创流程**：agent 把 1\~5 步已拍板的结论填进四产物落盘 → 用户逐卷审 → 拍板 → 全书宪法生效。

***

### 定稿后：交接下游

L3 全书大纲用户拍板定稿后，seed 职责完成。向用户报告："全书大纲已定，接下来交 world 完善设定（力量体系数值化/势力/地理/角色），再由 plot 逐卷展开卷纲。"加载 pop-snow-stage 接力。

> **seed 止于全书大纲**：力量体系数值化/角色库/分卷卷纲等工程级展开由 pop-snow-stage/pop-snow-plot 接力，不回 seed。

## 红线

1. **终点优先，先定终点再谈一切**：必须先消化 L0 参考 → 定终点 → 才允许反推世界/主角/起点/阶梯。禁止"先想冲突/卖点再回头贴终点"（=两张皮）。定终点时 L0 卖点参考必须在场——**L0 卖点是定终点前的第一道门，不是最后一道皮**。
2. **每步串行，用户拍板**：0\~5 步不定稿不进下一步，Step 6 四产物逐卷审。用户拍板是每步唯一关卡，agent 自检不能替代用户确认。禁止一口气全出完丢给用户。
3. **共创对话主 agent 直执**：出草案/听意见/改稿一律主agent，禁派子agent代跑与用户的共创对话；仅纯只读调研支撑（参考消化/拆书包检索）可派子agent。
4. **三毒点红线（定终点/主角时必验）**：✗ 禁任意改根规则型金手指（一出手=终局）✗ 禁神转世/天选当特殊性理由（双倍机械降神）✗ 禁丢记忆/丢人性/反噬伤己式主角副作用（代价由外部世界承担，不从主角身上割）。
5. **波浪式上升红线**：起点→终点必须能排出一条由弱到强的敌人阶梯，每级招致真实利益反扑；一根急转弯/半卷打最终BOSS/结尾空降大反派=判死回炉。
6. **L3 数值刻度必须显式**：养成线每卷到哪一档、天花板何时碰，必须写成可查的刻度，禁止"逐步变强"这类含糊表述。这是防 28 章半神类崩坏的唯一闸门。
7. **参考不抄内容**：参考只取结构/节奏/刻度/终点形态骨架，专有名/具体事件/人物 100% 原创，禁止换名复用。
8. **seed 止于全书大纲**：禁产 `设计/` 力量体系数值化/角色库/卷纲等工程级文档——那是 stage/plot 的职责。
9. **金手指必须是叙事装置**：金手指要承担成长机制+结构骨架+主线伏笔三重功能，禁止只当一次性能力设定。
10. **L0-L3 落盘后消毒（doc 报告闸）**：四产物（00-L0/01/02/03）落盘后自跑 `python skills/pop-snow-pipeline/scripts/deai_gate.py <文件> --profile doc --json`——只报不打回：黑话/套路句式/空腔段按 WARN 定位自查（装腔换大白话，行话正常用可放行）；工程标签（刻度/锚点/卷末边界等精确技术名）不在消毒范围。零风险机械项可加 `--fix` 原地修。
