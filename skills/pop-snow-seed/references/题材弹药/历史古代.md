# 题材弹药卡 · 历史古代

> 定位：访谈弹药库，不是写作配方。只收结构、套路与事实；制度、官职、物价、军事必须考据，查不到标「待核」。

## 一、定义与定位

- 平台标签：历史古代 + 科举 / 争霸 / 种田 / 改革 / 历史脑洞。
- 一句话：主角穿越/重生到古代，用现代知识或历史先见，在真实或架空的王朝里科举、做官、种田、打仗、改革。
- 常见篇幅：150-200 万字为主；30 万字写一段；80-150 万字写一朝/一地。
- 近邻与区别：与「古风世情」的区别是男性向/家国线；与「历史脑洞」的区别是更重真实制度与推演。

## 三、读者期待（5-8 条）

1. **历史还原**：制度、官职、物价、服饰、军事，写得像。
2. **科举/做官**：寒门起步，考试、升迁、站队。
3. **种田/建设**：修水利、炼钢、制盐、经商，改变一地。
4. **战争/争霸**：练兵、后勤、谋略，不是儿戏。
5. **改革**：用现代知识推动局部变革，但不一步登天。
6. **权谋**：朝堂博弈、派系、君臣。
7. **改变历史**：在关键节点做不同选择。

## 四、常见套路（8-12 条）

- **开局**：穿越成寒门/小吏/纨绔/皇帝；灾年/战乱/科举。
- **破局**：抄诗/发明/经商/种田；拜师；科举；投军；站队。
- **升级**：秀才→举人→进士→县令→知府→朝堂。
- **打脸/反转**：世家/贪官/敌军被打脸；皇帝态度反转。
- **换图**：乡村 → 县城 → 州府 → 京城 → 天下。

## 五、反套路清单（5-8 条）

1. **同类都抄诗装逼 → 本书搞实业/技术**：炼钢、制盐、修水利、改良农具。风险：技术推演要可信。
2. **同类都当皇帝 → 本书当技术官/改革者**：在体制内做事，不推翻规则。风险：爽点慢，要用政绩补。
3. **同类都一步登天 → 本书尊重制度**：升迁有年限、有考核、有派系。风险：节奏慢，要设计阶段目标。
4. **同类都现代民主 → 本书写时代局限**：不能用现代观念硬套。风险：读者嫌保守，要用利益线补。
5. **同类都战争儿戏 → 本书写后勤/训练**：粮草、兵器、士气、情报。风险：战斗爽感弱，要用谋略补。
6. **同类都反派降智 → 本书反派有立场**：世家/权臣/敌国都有自己的利益。风险：主角赢得慢，要写智力博弈。
7. **同类都改变大势 → 本书改局部**：一个县/一个行业，不硬改王朝。风险：格局小，要用暗线补。

## 六、金手指 / 替代驱动（5-8 种）

| 类型 | 能做什么 | 限制/代价 | 适合的主线动作 |
|:--|:--|:--|:--|
| 历史知识 | 知道大势、人物、技术 | 只知道大势；细节会偏移 | 站队、避坑、改革 |
| 现代技术 | 炼钢、制盐、农具、医疗 | 缺材料/工匠；会被当异类 | 种田、建设、军工 |
| 系统/空间 | 给图纸/物资 | 不能暴露；有时代上限 | 建设、囤货、经商 |
| 科举/记忆 | 考试、公文 | 需要学习；字迹/格式会露 | 做官、升迁 |
| 医术 | 救人、收人情 | 缺药；有风险 | 救人、结盟、军医 |
| 无金手指 + 现代管理 | 制度、成本、组织 | 不能超出时代认知 | 改革、建军、经商 |

## 七、雷点 / 毒点（5-8 条）

1. 历史错误：官职、制度、物价、地理、服饰。
2. 现代词汇/观念乱入。
3. 主角万能：会炼钢、会医术、会打仗、会治国。
4. 战争儿戏：几万人说打就打，没有后勤。
5. 改革太容易：一道命令就改变王朝。
6. 反派降智：世家/权臣无脑送。
7. 后宫工具化：女性只负责爱主角。
8. 结局仓促：大势突然逆转。

## 九、事件种子与分卷阶梯

**事件种子（10-15 条）**

1. 穿越成灾年寒门，第一件事是找吃的。
2. 科举考场，主角用现代逻辑破题。
3. 县衙当小吏，查出粮仓亏空。
4. 修水利/炼钢/制盐，被地方豪强阻挠。
5. 边关战事，主角管后勤。
6. 朝堂站队，主角押中/押错。
7. 灾民/流寇，主角练兵/赈灾。
8. 世家联姻/打压，主角反制。
9. 皇帝召见，主角献策。
10. 改革触动利益集团，被弹劾。
11. 敌国入侵，主角守城。
12. 终敌不是敌国，而是制度/利益集团。
13. 改变局部历史，付出代价。
