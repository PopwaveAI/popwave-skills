# 题材弹药卡 · 年代

> gold sample：以用户提供的外部年代文立项大纲为结构参考，补足事实与反套路。**这是参考答案，不是完美答案**；已知失真单列在文末，不得带进其他题材或正文。
> 适用：女频年代 / 男频年代 / 年代种田 / 年代美食 / 四合院生活流 / 知青返城。

## 一、定义与定位

- 平台标签：年代 + 种田 / 美食 / 发家致富 / 四合院 / 知青 / 军嫂 / 创业。
- 一句话：物资匮乏的年代里，主角靠手艺、信息差或时代红利，把日子越过越好，顺带打脸极品、结交人脉。
- 常见篇幅：80-150 万字为主；30 万字走单地图（生产队/县城）；200 万+ 必须换图到省城/京城/海外。
- 近邻与区别：与「都市种田」的区别是时代约束（票证、工分、政策）；与「古言宅斗」的区别是权力来自编制/资源，不是宅斗位份。

## 三、读者期待（5-8 条）

1. **时代还原**：票证、工分、物价、称呼、住房、集体生活，读者要能「闻到他家灶台的味」。
2. **物资匮乏的代入**：缺油少盐、粗粮细作、边角料变美味，越缺越馋。
3. **打脸极品**：偏心父母、绿茶继兄、村霸、老知青，开局就要解气，不能长期憋屈。
4. **发家致富的可见阶梯**：工分→编制→国营厂→个体户→下海，每一步有具体收益。
5. **美食/手艺的感官爽**：做法、火候、香气、吃相，读者要咽口水。
6. **政策红利的智商优越**：主角比旁人早半步看到政策，但不违法。
7. **人情社会的博弈**：不是打打杀杀，是票证、指标、名额、人情债。
8. **年代婚恋的克制感**：感情慢热、互相成就，不写现代狗血。

## 四、常见套路（8-12 条）

- **开局**
  1. 重生/穿越到下乡前夜，面对抢工作、逼下乡。
  2. 睁眼在生产队，原主留下烂摊子（欠工分/得罪村霸）。
  3. 知青点报到，被分最苦的活。
  4. 四合院分房/分家，极品亲戚上门。
- **破局**
  5. 半夜黑市倒卖（高风险、憋屈）。
  6. 随身空间囤物资/种田。
  7. 系统商城兑换物资。
  8. 靠一手厨艺拿下大队食堂/公社小灶。
  9. 靠考试/技术/医术拿到编制或返城名额。
  10. 参军/随军/进国营厂，换地图。
- **升级**
  11. 工分→副业队→社办企业→县食品厂→省城→京城。
  12. 从「被同情」到「被领导递烟」。
- **打脸/反转**
  13. 极品家人悔恨、继兄破产、村霸变狗腿。
  14. 同行封杀→主角用产品/手艺反杀。
- **换图**
  15. 恢复高考、返城潮、广交会、改革开放、下海经商。

## 五、反套路清单（5-8 条）

1. **同类都走黑市倒爷 → 本书走合规特供**：挂靠大队副业组/公社试点/县办集体企业，让领导成为利益共同体。风险：需要写清政策边界，不能写成「随便搞」。
2. **同类都撕逼分家 → 本书直接卖名额/断后路**：不吵不闹，把工作名额高价卖给继兄的死对头，拿钱下乡。风险：名额转让不合法，必须写成「走后门+领导默许」，并埋风险。
3. **同类都靠空间/系统 → 本书靠手艺+信息差**：金手指只给洞察/配方，不给实物，逼主角种田、搞人脉。风险：前期爽感慢，要用美食/打脸补。
4. **同类都当圣母 → 本书利益捆绑**：帮人先算账，救急不救穷，敌人变盟友靠利益不靠感动。风险：主角不能写成冷血，底线要清楚。
5. **同类都囤货居奇 → 本书做增量**：改良种子、菌菇、饲料、酱菜厂，把蛋糕做大，不抢存量。风险：需要真实农业/食品知识。
6. **同类都嫁军官/靠男人 → 本书靠编制/技术岗**：女主自己考学/进厂/做账，感情是并肩不是依附。风险：年代女性上升通道窄，要写清卡点。
7. **同类都苦大仇深 → 本书阳光发财**：不写长时间受虐，开局就反手，爽点前置。风险：反派太弱会降智，要给对手真凭仗。
8. **同类都个人英雄 → 本书绑集体所有制**：所有产业挂集体名义，主角做「致富带头人」，不碰时代红线。风险：主角收益要绕一道，不能写成私有老板。

## 六、金手指 / 替代驱动（5-8 种）

| 类型 | 能做什么 | 限制/代价 | 适合的主线动作 |
|:--|:--|:--|:--|
| 美食/情绪面板 | 扫描食材最佳做法、食客身体与心理渴求；情绪转积分 | 不提供实物；同一道菜对同一人边际递减 | 食堂救场、药膳、私房菜 |
| 随身空间 | 囤物资、种菜、保鲜 | 空间不能暴露；初期容量小；不能凭空变出时代没有的工业品 | 种田、囤货、救急 |
| 系统商城 | 兑换物资/技术 | 需要积分/任务；兑换有时代上限；不能直接换钱 | 副业、加工、技术升级 |
| 重生记忆 | 知道政策节点、物价走势、谁将平反 | 记忆会因主角行动偏移；只知道大势，不知道细节 | 提前布局、抱大腿、避坑 |
| 医术/药膳 | 治病、调理、收买人心 | 缺药材；不能包治百病；有风险 | 牛棚救人、领导保健、女主调理 |
| 信息差 | 知道谁要什么、什么将紧缺 | 信息有时效；传错会反噬 | 倒腾指标、公关、投资 |
| 手艺（厨艺/木工/ repair） | 把边角料做成精品 | 需要食材/工具；产能有限 | 食堂、作坊、私房菜 |
| 无金手指 + 时代经验 | 靠现代管理/卫生/成本意识 | 不能超出时代认知；会被当异类 | 作坊管理、食品厂、连锁 |

## 七、雷点 / 毒点（5-8 条）

1. **数值失真**：工分、工资、物价、票价与年代不符，读者一眼出戏。
2. **政策时间线错**：外汇券、个体户、私房菜馆、雇工、自由市场提前出现。
3. **主角长期憋屈**：被极品反复欺负却不反击，爽点迟迟不来。
4. **极品循环**：同一家人反复作妖，没有升级，读者疲劳。
5. **金手指万能**：空间/系统直接变出一切，主线种田/人脉失去意义。
6. **后期悬浮**：从生产队直接跳到京城首富，缺少中间阶梯。
7. **女性工具化**：女主只负责被救、被宠、被吃醋，没有自己的事业线。
8. **称呼/方言/单位错**：公社、大队、革委会、供销社、粮站等建制写错。

## 参考稿已知问题（不得带进其他题材或正文）

1. **工分值 1.5 元/分**：1973 年绝大多数生产队达不到；日 10 分=15 元、月 450 元，超过当时高层工资。改为「一个工分几毛、富队几毛到五毛」。
2. **1978 年用外汇券买四合院**：外汇券 1980 年 4 月才发行。改为「侨汇券/外汇/人民币+批文」，或把时间推到 1980 年后。
3. **1978 年开私房菜馆**：个体餐饮合法化在 1980 年前后；1978 年只能挂靠集体/国营。改为「街道集体食堂/招待所承包」，或把时间推到 1980 年后。
4. **肉联厂学徒工名额公开卖 500 元**：名额不能合法转让，只能「走后门+领导默许」，且风险极高。写法要补「不能公开、要担责、后续被举报」的风险，不能写成合法资产。
5. **1975 年县级食品厂签百万美元出口单**：量级需要核；可改为「省级外贸公司代理、分批订单、几十万美元」，或把舞台抬到省城。
6. **「工分值突破一块五引发轰动」**：可作为爽点，但要先解释「副业+加工业+特供渠道」如何让全队分值翻几倍，不能只靠种粮。
