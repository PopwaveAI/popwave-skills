# 题材弹药卡 · 青春甜宠

> 定位：访谈弹药库，不是写作配方。只收结构、套路与事实；校园/城市细节标来源，查不到标「待核」。

## 一、定义与定位

- 平台标签：青春甜宠 + 校园 / 都市甜宠 / 暗恋 / 双洁 / 1v1 / HE。
- 一句话：两个人在校园或都市里从相遇、暗恋、误会到确定关系，主打通甜、轻喜剧与成长。
- 常见篇幅：30 万字上下为主；80 万字要加事业/群像/婚后。
- 近邻与区别：与「现言脑洞」的区别是不靠马甲/系统，重日常；与「豪门总裁」的区别是轻甜，不是强权。

> 只借结构，不借专名、桥段与台词。

## 三、读者期待（5-8 条）

1. **甜**：高频糖点，互动有来有回。
2. **双洁/1v1**：感情线干净，不搞暧昧拉扯。
3. **暗恋/双向**：一个人先动心，另一个人早就在等。
4. **校园/都市质感**：校服、考试、社团、通勤、租房，真实可代入。
5. **轻喜剧**：误会小、笑点多，不虐。
6. **成长**：两个人互相成就，不是恋爱脑。
7. **HE**：确定关系、公开、未来，给读者交代。

## 四、常见套路（8-12 条）

- **开局**：同桌/邻居/青梅竹马；转学生；网游/社团相遇；合租/同事。
- **破局**：补课/比赛/活动拉近距离；误会→解释；情敌出现→双向奔赴。
- **升级**：暧昧→告白→恋爱→公开→同居/结婚。
- **打脸/反转**：看不起主角的人被实力/关系打脸；情敌退场。
- **换图**：校园→大学→职场→婚姻。

## 五、反套路清单（5-8 条）

1. **同类都误会拖十章 → 本书直接说开**：有嘴就沟通，糖点靠互动不靠误会。风险：冲突少，要用外部事件补。
2. **同类都学霸救学渣 → 本书双强/各自成长**：谁也不依附谁。风险：少了「救赎感」，要用互补补。
3. **同类都恋爱脑 → 本书事业线并行**：喜欢归喜欢，考试/工作不能丢。风险：甜度下降，要加日常糖。
4. **同类都男配工具 → 本书配角有自己线**：朋友、家人、对手都有动机。风险：篇幅分散，要控制。
5. **同类都工业糖精 → 本书用细节糖**：小动作、习惯、默契，不硬塞台词。风险：写不好会淡，要设计记忆点。
6. **同类都虐恋反转 → 本书轻甜到底**：不写背叛/绝症/失忆。风险：读者嫌平，要用成长/事业冲突补。
7. **同类都校园失真 → 本书写真实校园**：考试压力、家庭、升学，不只有恋爱。风险：甜度被稀释，要平衡。

| 空间/物资 | 辅助生活 | 不能暴露；与甜宠无关时慎用 | 日常、创业 |

## 七、雷点 / 毒点（5-8 条）

1. 工业糖精：硬塞台词、强行撒糖。
2. 误会太多：一句话能解决，拖十章。
3. 女主降智：为了恋爱放弃底线/事业。
4. 男配/女配工具化，只负责捣乱。
5. 校园失真：没有考试/家庭/升学压力。
6. 三观问题：跟踪、控制、霸凌被美化。
7. 虐点乱入：甜宠文突然绝症/背叛。
8. 结局仓促：确定关系就完，没有未来交代。

## 九、事件种子与分卷阶梯

**事件种子（10-15 条）**

1. 开学分同桌，主角和「高冷学霸」坐一起。
2. 雨天共伞，两个人第一次靠近。
3. 运动会/文艺汇演，主角被推上台。
4. 补课/小组作业，发现对方另一面。
5. 情敌出现，主角第一次吃醋。
6. 误会→当面说开，关系升温。
7. 考试失利/家庭变故，两个人互相支撑。
8. 告白被拒/延迟，进入暧昧期。
9. 毕业/异地，现实压力出现。
10. 职场重逢，身份变化。
11. 公开关系，面对家人/朋友。
12. 一起完成一个目标（比赛/创业/升学）。
13. 见家长/同居/结婚，收束。
