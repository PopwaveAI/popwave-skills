## 二、分卷剧情安排（核心表）

### 语感隔离声明（write 消费本文档必须先读）

> ⚠️ **本文档所有措辞是"剧情结构语言"，不是"正文语感"。** write 从本大纲只取**意**（剧情事件+情绪基调+钩子），用文风DNA语言**重铸**；禁止照抄本大纲的任何标签句/抽象名/句式进正文（如"过量收敛""舆情逆转""收割机器"这类词只作剧情指代，不作正文用语）。情绪基调只作气氛提示，不成句照搬。若 write 发现正文被他用词/语感，视为语感污染，review 打回。

> **分卷剧情怎么写（每卷一块，不是一行短句）**：每卷给四件事——**① 本卷开端局面**（从上一卷末尾卡在哪个困境开）**② 主角的处境与行动**（这卷主角是谁、图什么、主动做什么）**③ 冲突与转折**（和谁冲突、谁出招、主角怎么接、最大转折是什么）**④ 卷末落点+钩子**（这卷让主角变成什么样、卡在哪个更麻烦的坑里，逼读者翻下一卷）。**写成能讲清楚"怎么演"的白描，不是标签堆砌。** 每卷另给"对终点的意义/养成刻度/卷末边界"三行结构信息（承接 L2）。

## 六、逻辑缜密自检

> 定稿前逐条核：

- [ ] 卷间因果链咬合：每卷的果是下一卷的因，无断裂
- [ ] 养成刻度无崩坏：每卷刻度不超第二节分配，无"卷一半神"式透支
- [ ] 伏笔债线有收：每个人物、关键物件、关键情报的伏笔线都有明确的埋设卷位和收线卷位
- [ ] 最大反转落卷前，它需要读者见过的伏笔（人/物/真相线索）都已铺到
- [ ] 敌人梯度连贯：从底层到顶层的力量跨度合理，主角打谁都不突兀
- [ ] 每卷张力承接 L2：每卷都有里程碑强敌+卷末新困境（终卷闭环除外），无断气卷
- [ ] 每卷"对终点的意义"列与 L2 每卷第一句一一对应，无沉默跑题卷
- [ ] 与 L1 命运图一致：终点/反转/落差在大纲中全部兑现，无偏离
