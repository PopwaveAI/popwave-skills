# pop-snow-stage

> 设定只补「这一卷要用的」，不建百科。
> 当前版本 v8.0.0。

## 何时用

立项已定，要写世界与人物；或写到某一卷发现设定不够。

## 流程

### Step 1 读立项，列缺口 `[主]`

读 `立项/故事.md`，列出本轮要补的条目，最多五条。只补会影响接下来三章的那几条，其余留到用到时再补。

### Step 2 世界 `[工具:setting]` → `设定/世界.md`

只写四块，每块三句以内：

1. **规则**：能做什么、不能做什么、代价是什么。三条封顶。
2. **势力**：谁在挡谁，各自要什么。两三个，不铺全图。
3. **地理**：只写影响剧情的地点，一个地点一句。
4. **质感**：三个日常细节（吃什么、怎么称呼、怕什么）。

### Step 3 人物 `[工具:setting]` → `人物/人物卡.md`

每人六项，一段话写完：

```
{姓名}
要什么：{具体目标}
怕什么：{具体失去}
绝不做什么：{一条铁律，全书不许破}
说话方式：{短句/绕弯/爱用比喻，给一个口头禅}
和主角的关系：{现在是什么，张力在哪}
什么时候出场：{第几章/什么场合}
```

主角与主要反派必写；其余按出场需要补。

### Step 4 一致性检查 `[主]`

- 每条规则有代价，没有「万能」。
- 人物没有「什么都会」，铁律能约束情节。
- 与 `立项/故事.md` 不冲突；冲突时改设定，不改故事核。
- 查不到的写「待定」，不编。

## 给 setting 的注入清单（缺一不调）

- `brief`：这次补哪一块（世界规则／势力／地理／某个角色）。
- `context`：`立项/故事.md` 全文；已有 `设定/世界.md` 与 `人物/人物卡.md`；用户对设定的原话。
- `constraints`：条目数上限、每条字数、必须避免的设定（禁区）。

## 红线

1. 不写十四维长档，不做数值表、位阶表、势力全图。
2. 不编用户没确认的专名。
3. 不在本环节排剧情、不写正文。
4. 一次只补缺口，不顺手重建整个世界观。
