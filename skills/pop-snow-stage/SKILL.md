# pop-snow-stage

> 舞台设定——世界与角色的唯一产出方（长档方）。当前版本 v2.3.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

---

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。
- **Pack**：缺口足够才取材，query 自生成；来源 **wiki 站 https://wiki.popwave.cn** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query / 回传 ≤30KB，超限截断仅留结论区。
- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版，不越权定终局。
- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

## 做什么

stage 把 seed 融合立项稿的**世界观组（1-4）＋人物组（5-7）**长成可落笔的**长档**。**长=扩展补充丰富，不是换张表格抄骨架**——每层只做"上一层没做、但下一层真需要的增量"。剧情归 plot、表达归 write。

**14维 → 长档地图**：

| seed 维 | 长档（落盘 `设计/`） |
|:--|:--|
| 1 世界形态 | `世界全书.md` |
| 2 力量体系 | `力量体系.md` ＋ 配套档 `位阶-社会坐标谱.md` |
| 3 势力格局 | `势力格局.md` |
| 4 基调/母题 | `基调母题.md` |
| 5 主角（含金手指） | `主角.md` |
| 6 主角团/配角 | `角色库.md`（主角团） |
| 7 反派/敌人 | `角色库.md`（反派敌梯） |
| —（write 方向锚） | `类型风味基线.md`（命名参考系＋复用名词库） |

**两种模式**：

| 模式 | 触发 | 干什么 |
|:--|:--|:--|
| 首喷 | 无 `设计/力量体系.md` | 新书一次：消费 `立项/00-融合立项稿14维.md`，只长**当前要开写那批**（默认世界观＋人物全套或用户点名），不追文件全家桶 |
| 卷级点播 | plot 卷需求brief 舞台点播清单 | 每卷一次：brief 点哪块长哪块（新地图/新势力/新角色锚/贯穿层演化），回填对应长档 |

**长档四原则（长档尺，逐档过）**：

1. **参考源真落地（否决条款）**：任一关键复用点未吃透/未查实（没走聚焦调研、没法回源），该档不达交付标准。禁止"为凑满而挂复用源"——没吃透就张冠李戴标"复用自X"，是本轮最重的教训。
2. **一档只服务 seed 特指骨架**：长的是 seed 点名的那根骨架；不发明 seed 没定的故事方向，方向不足或矛盾→报错回上游（seed/plot），不在 stage 层自己补。
3. **有温度画面**：关键条目带"正文长什么样"的可落笔描述（战斗气质/一句画面）。只有规则没有画面，write 不知道怎么落笔。
4. **待补强项补掉**：seed 待补强清单点名的问题必须消化；消化不掉的显式登记回待补强清单，不许装看不见。

**复用域纪律（力量体系尤其如此）**：

- 能复用就复用，不原创：有参考→消化其**分级方式**；没参考→主动搜相似赛道最有名那套复用（派 research 聚焦调研查实）。
- 自定义的是**成长斜率**（多少内容爬多少阶、前期陡中段换节奏后期重质量），不是阶位本身。
- 数值刻度从参考来：钉"板式＋跨度"，具体数值留给正文按板式现算（防拍脑袋返工）。

**位阶-社会坐标谱（力量体系配套档）**：纵轴=全书完整位阶，每档横摆战力表现/社会地位/大众感知三坐标——让"主角爬到第几阶=多高"可感知；同时钉死世界金字塔约束（满街不见高阶）。plot 排卷进度表、write 写量级都拿它当参照系。

**执行模式**：主agent直执。用户在场时关键决策走交互轮（给选项不给空白，每轮2-3方案+自定义入口）；不在场 agent 自定并在档头标注"agent 自定"。

## 怎么操作（SOP全内联）

### 模式A：首喷（新书一次）

```
Step 0  输入加载：立项/00-融合立项稿14维.md 全文（世界观1-4＋人物5-7＋机制溯源附录＋待补强清单）
Step 1  盘复用源：机制溯源每个复用点过聚焦调研查实
Step 2  力量体系长档＋位阶-社会坐标谱配套档
Step 3  世界全书／势力格局／基调母题
Step 4  主角档（含金手指）→ 角色库（主角团＋反派敌梯）
Step 5  类型风味基线（命名参考系＋复用名词库）
Step 6  逐档过长档尺 → 消毒 → 交接 plot
```

**Step 0 输入加载**：读融合稿全文，重点取世界观组、人物组、附录A机制溯源、附录B待补强清单。输入路径判定：改编=另读拆书成果当质量锚（有则必用，不抄事件不抄人名）；半成书=另读已有正文反推既有设定。

**Step 1 盘复用源（防挂名）**：附录A列出的每个复用点，逐一确认"吃透没"。吃透标准：能说出它在原体系里怎么运转、本作怎么披皮。没吃透→派 research 聚焦调研（六纪律）查实再长；查不到→换源或降级为"自创待标"，绝不硬挂。

**Step 2 力量体系长档**（质量锚：`references/长档样例-力量体系.md`）：

- **先边界后名字＋设计四问（镜界10-A1/A2 吸收）**：每个关键能力/阶位落表前，先钉"边界"（上限/消耗/克制/后效/环境约束/时间成本）再命名；并回答四问"它让主角**获得**什么/**失去**什么/**误判**什么/**争夺**什么"——答不出=纯摆设定，回炉。**新增能力必须同步带出限制、代价与滥用风险，不能只本章生效**；过**自洽6查**：向下兼容（新能力不废旧能力）／向上封顶（当前上限留够下一阶段升级空间，突破不一步到位）／横向克制（无无敌，若有必给弱点代价）／环境约束（不同场景表现一致）／时间成本（修炼恢复耗时，随手可用则无紧张感）／**一句话测试**（"主角能用这能力解决所有问题吗？"能=体系有问题）。与 step6/outline 的"能力使用无越界"审查形成"**建（stage）→查（review）**"闭合。
- **两股源**：主角走的那股＋敌人走的对位邪路（从融合稿第2维长）
- **主角职业线表**：阶位/文化渊源/社会地位/升级触发/预计卷/**正文长什么样**（每阶一段可落笔画面——腐化之寒漫上来时脑子嗡嗡、手抖，但刀先挥出去了）
- **数值板式**：复用参考板式（如整数大数字面板），钉板式＋跨度；具体数值正文现算，不凭空写死
- **技能/被动命名**：词干复用＋语义微调（原词照用或按本书皮微调），不发明全新体系
- **神力刻度**（如登神线）：复用真实分级（如 DND 神力6档），每一格都列全——微弱→弱等→中等→强大→伟大，中间不许吞格
- **交叉规则/代价/掉落**：协同（几线齐可跨几档越级）/制约/等价交换/掉落恢复代价＋非主角变强路径≥5（金手指只让主角爬得快）
- **位阶-社会坐标谱**（质量锚：`references/长档样例-位阶社会坐标谱.md`）：全书位阶×三坐标表＋金字塔约束

**Step 3 世界全书／势力格局／基调母题**：

- **世界全书**：从第1维长——地理格局/时代质感/运作逻辑；每区域带够撑卷级篇幅的钩子；本卷要开写的区域细到 plot 能直接排戏。**每个地点过"地图剧情绑定4问"（镜界10-A3 吸收）**：①地点=利益（控制什么资源/信息，谁想要）②冲突（不同势力态度是否不同）③门槛（进入付什么代价）④记忆（主角在此经历过什么，重访读者想起什么）——**被另一地点完全可替代→不单独入档或标记精简**，不堆"只当背景板"的地理。
- **势力格局**：从第3维长——多方棋局（抵抗/入侵/摇摆）、友军互隙、每势力带结构性弱点；含"众生攀登分层"（有资源/没资源/爬到顶/掉下来的各是谁——势力与角色的来源）
- **基调母题**：从第4维长——底色（暗到哪）＋减压阀（暖在哪）＋一句话母题

**Step 4 主角档＋角色库**：

- **角色原型联动（写前必刮 wiki，人物复用域）**：建每个角色（主角/主角团/反派）前，先查 wiki 取原型——**`素材原型库/人设原型/`**（「少年天子型/退婚流女主型/高冷师兄型」这类现成人物底色）按定位作**搭骨架选型**；再翻**`赛道设定集/{本书赛道}/角色库`**取该赛道已验证角色做**同级参考**（反派按8型/主角按攀登方式对谱）。**人物是复用域，同力量体系纪律：有原型→消化其人格内核换壳填本书，不硬原创**（呼应"所有主要角色要有原型"）；原型本身不是剧情，取来后必须配"目标＋代价"才入卡。复用域名：`wiki/素材原型库/人设原型`、`wiki/赛道设定集/{赛道}/角色库`。没刮过就建卡=人物复用域失责，review 可打回。
- **主角档**：攀登方式/起点阶位/性格（写行为倾向——"嘴硬心软，总在暗地里帮忙"，不写"善良勇敢"）/小传≥200字/成长线/语言指纹；**标签上限（镜界05-A2 吸收）**：核心标签 ≤2-3 个（力量/智慧/个性/情感/信念 5 型里选），再定 **1 个核心情绪主轴**（逆袭/重生/穿越/系统/无限/日常，可混合但情绪单主轴）作一致性基准——**越多越写散**；金手指三约束（是钥匙不是资源机器/强化不越级/限制写明白）
- **角色库**：主角团＋反派敌梯逐卡——等级坐标对齐力量体系（禁悬空数值）/独立欲望（不是工具人）/超预期细节/小传＋语言指纹（去掉名字也能认出谁在说话）；反派另加冲突必然性（欲望对立，不是碰巧挡路）＋层级标注。**每个主要配角标一个"功能位"（镜界05-A3 吸收）**：引路人／智囊／执行者／情绪镜子／对手／垫脚石／传声筒——**功能重叠的角色合并淘汰**（两个智囊不如智囊+执行者），垫脚石类不长期占篇幅；**反派按 8 型模板对号**（纯恶/灰色/魅力/悲剧/伪善/执念/成长/幕后），明写行动逻辑与压迫感来源（目标/手段/代价），**禁靠降智送爽**——主角爽在赢得有代价有方法有反应
- **三问逐卡过**：有独立欲望吗/行为能从欲望推出来吗/和主角的冲突有必然性吗——任一不过重做该卡

**Step 5 类型风味基线**（质量锚：`references/长档样例-类型风味基线.md`）：

- **类型声明**（write 每章注入）：`【类型声明】当前作品类型：{类型}。保持{类型}味：{命名风格}/{器物风格}/{社会符号}。禁止漂移到{其他类型}。`
- **命名/器物/社会符号参考系**（本书自建）
- **复用名词库**：参考体系直接植入（职业链/被动/战技/器物/刻度词），write 取词处——库里有直接用，库外按参考系造词并回填登记

**Step 6 交付闸（先过资料门）**：交档前自问"这几个长档，复用域有没有找到可复用源、要新设的现实骨架（真实组织运作/职业黑话/地貌气候/行业规则）查实没、角色原型落位没？"——有缺口→**先派 research 定向补采（落 `素材/采风/`、来源可回源）再来长**。资料门过了才逐档过长档尺四原则（尤其①复用源真落地）→ **落盘后半步=消毒**：本次产出的档逐份 `python skills/pop-snow-pipeline/scripts/deai_gate.py <文件> --profile doc --json`（doc 报告闸：WARN 定位自查——装腔换大白话、行话放行，机械项 `--fix`；多档可目录递归 `-r` 聚合），回执一行 `消毒:设计长档|PASS` 或 `WARN×N` → 向用户报告 → 交接 plot（排卷进度表与卷纲）。

### 模式B：卷级点播（每卷一次）

```
Step R0  输入加载：卷需求brief 舞台点播清单＋全书日志＋上卷卷纲
Step R1  按单生长：新地图/新势力/新角色锚长进对应长档（或本卷专档）；新复用点过聚焦调研查实
Step R2  贯穿层 append：新阶位/新势力进总纲、演化记录——只追加不重写，写错走纠错注记
Step R3  交接 plot
```

**现编回填**：write/plot 现编的设定（地名/组织/规则）回填对应长档；取词优先查类型风味基线复用名词库，库外按命名参考系造词并回填登记。现编是权利，登记是义务。

**R2 落盘后半步=消毒**：本卷动过的档（长档增量/卷专档）逐份 `python skills/pop-snow-pipeline/scripts/deai_gate.py <文件> --profile doc --json`（doc 报告闸：WARN 定位自查、机械项 `--fix`），回执一行 `消毒:设计长档|PASS` 或 `WARN×N`。

## 红线

1. **读文件用宿主原生读取工具**。
2. **长档尺①否决条款**：任一关键复用点未吃透/未查实，该档不达交付标准；为凑满而挂复用源=打回重做。
3. **从上游方向展开，不发明故事方向**：融合稿/卷需求brief 为准；方向不足或矛盾→报错回上游（seed/plot），不在 stage 层自己补。
4. **力量体系是复用域**：不自创阶位体系（有参考消化其分级方式/没参考搜最有名那套复用）；自定义的只有成长斜率；数值钉板式＋跨度，不凭空写死。
5. **人物也是复用域**：建角色前必刮 wiki（人设原型＋赛道角色库），有原型消化换壳、不硬原创；原型须配"目标＋代价"才入卡；原型本身不是剧情。
6. **有温度画面**：关键条目可落笔（每阶"正文长什么样"），纯干表格=回炉。
7. **贯穿层只演化不重写**；卷级点播一卷一版；禁止回头改旧档，写错走纠错注记不抹原文。
8. **群像收缩（镜界05-A1/A5 吸收）**：同时活跃角色 ≤5-7；功能重叠必合并淘汰；退场有交代（死亡/离开/转背景板，禁人间蒸发）；每个活跃角色在当前卷有"在场理由"，没理由不写。本长档只建不删，**收缩动作由 review 每 N 章清角色表时执行**（哪张卡撤活跃进退出档案），stage 保证每个入档角色可回答"他凭什么在场"。
