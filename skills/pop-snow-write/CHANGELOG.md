## v1.8.0 | 2026-09-05

### 字数门禁从 review 拿回：write 落盘后自跑自闭环（两道门禁顺序固化）

老板拍板："字数不足不能在 review 里补救，还得 write 自己闭环"。v1.5.1 起字数脚本归 review 的设计缺陷：字数不足的补写只能发生在 write（有章纲上下文、有文风DNA），review 发现不合格只能打回，多一轮空转。本轮闭环归位：

- **脚本迁回**：`scripts/word-count.ps1` 从 review 迁回本 skill（脚本头部注释同步"write 落盘后自跑，不足/超限自己闭环，不交 review 补救"）。
- **落盘后门禁重构为两道，顺序固化——先字数后去AI味**：字数闭环会增删文本，AI味检测必须在终稿上跑。① word-count.ps1（纯汉字2000-2500，不足→章纲既有节点内扩写补场景细节/对话往来/动作链，超限→删最弱场景，复跑至 PASS）；② deai_gate.py --fix（在字数 PASS 后的终稿上跑）。
- **字数不足不外交**：write 自己闭环达标后才交 review；stdout 原文进对话交接信息，review 直接消费进章日志"字数"栏（review 不跑脚本）。
