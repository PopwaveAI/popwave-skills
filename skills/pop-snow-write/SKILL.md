# pop-snow-write

> 正文写作：消费**本章章纲＋全书日志（当前态）＋文风DNA**三样核心输入，其余按需点读，渲染2000-2500字/章。当前版本 v1.5.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

***

### 心智前置·意识层（贯穿本 skill 与全流程）

动笔/定稿前自问：本产出要更好，还需要看过哪些候选？当前信息够不够？有更优选项没探索？

- **Know-Gap**：先显式列出"要更好需见过哪些候选面"，再列已覆盖，缺口=差值；缺口≥1 个未覆盖维度才触发取材，缺了取、别硬写。

- **Pack**：缺口足够才取材，query 自生成；来源 **wiki 站** **<https://wiki.popwave.cn>** 居先、网络补齐；单环节 ≤1 轮 / ≤5 query / 回传 ≤30KB，超限截断仅留结论区。

- **Worth**：拿本 skill 决策尺对"现有 vs 候选"必给打分表，禁止一句"更优"带过；只端候选/升级版，不越权定终局。

- **Deepen**：产出/候选后自问"这是天花板吗？有更优候选吗？"显著更优才升级再问，上限 2 轮。

取材仅进上下文，升级被采纳才落产出。

***

## 做什么

输入（有章纲前提下，**只吃三样核心，其余按需**）：本章章纲 + 全书日志（当前态）+ 文风DNA

输出：`正文/ch{NNN}.txt`（2000-2500字/章）。**不产创作记录文件**——write只在对话回复里给"摘要/钩子/新增事实待核/冲突/字数"，由 review 吸收进章节日志。

**硬约束链**：本章章纲🔒（时空与主体/事件节点/交接信息三块）→ 全书日志🔒（当前态：现在在哪/此刻悬着的线/禁止漂移）→ DNA约束（3-5条笔触）→ 类型声明（防风味漂移）

**执行模式**：主agent直执写作+落盘。输入完备性缺口审查/章纲事实vs全书日志冲突比对可派子agent（verification）只读审计回报，主agent据此判execution.mode并渲染落盘。

***

## 怎么操作（SOP全内联）

### Step 1：消费输入（抽取本章写作包）

有章纲前提下，**按"必读核心 vs 按需点读"分层消费**，不把档案全搬进上下文。缺必读核心项记入缺口。

**①用户本轮要求（最优先）**：覆盖默认取值。明确：把X写成Y/当前章位/续写或重写/特殊约束。用户要求与全书日志冲突时以用户要求为准，但必须在对话回复里给 review 标注冲突。

**②必读·本章章纲（向前锚）**：`卷纲/章纲/ch{NNN}-章纲.md`（pop-snow-outline产出，描述约束版 v4，每章一文件）。向左用上一章章日志衔接（不必读前1章章纲）。章纲三块各司其职，按下述消费：

- **时空与主体**=场景与登场：时间×地点×在场人物各一句今天干嘛 → 本章画面基准，直接定场景/人物状态起点
- **事件节点**=推进骨架：每节点「事件/转折/落点功能」按顺序兑现，一个不丢；落点功能（"这节结尾要读者感受到什么/为后文铺什么"）是本节目标，write 负责把它落到正文
- **交接信息**=写前约定：对白意图→write 现编台词；世界观功能→write 现编意象；角色语感→按清单查对应角色卡
- **write发挥**=留白区：动作细节/心理/对白台词/结尾意象全部在这现编，但不得与章纲事件及全书日志事实矛盾

**事实冲突处理**：章纲事实性字段（年龄/等级术语/人名）与全书日志冲突时，全书日志为准，写作包"冲突标注"记录。本章章纲缺失（outline 未产出到本章）=缺口，**走缺口处理（回 outline 补章纲），不自行补剧情、不降级硬写**。

**③必读·全书日志（当前态·跨章连续锚）**：`全书日志.md`（当前态·只记活跃·全量读）。抽取：现在在哪（时间线/地点/故事到哪/下一步）/人物此刻（当刻在场·正交互的人）/此刻悬着的线（未解·还在进的线，含不可提前吞并的钩子）/还没揭的悬念（别过早掀）/不许碰（禁止漂移硬清单）。**取代原"状态快照＋近5白描卡全量"**——连续锚已聚合在这里，不再逐章全读白描卡。

**④按需·上一章章日志（衔接细节）**：`章节日志/ch{NNN-1}.md`。要上一章结尾级细节（最后场景/余味/上一章停在哪）才读；更细的历史回溯对应白描卡/正文按需点读，**不默认逐章全读**。

**⑤按需·最近正文**：`正文/ch{NNN-1}.txt`（full-if-targeted）。需更细原文细节时读目标文件。

**⑥文风DNA输入（存在时必读，缺失时必须兜底）**：

| 优先级 | DNA源                    | 触发条件               |
| :-- | :---------------------- | :----------------- |
| P0  | `references/文风兜底/`按赛道选一 | **首选·纯样文原文**（frontmatter标注源书与txt路径，可回源逐字核查） |
| P1  | `素材/文风锚定.md`            | 存在即用，但只能作为"同赛道reference的辅助转写"，不得取代P0原文 |
| P2  | 上一章白描卡`## 本章DNA执行包`     | review产出，有则优先加载章内套路 |

**文风来源权重（硬规则）**：`references/文风兜底/`里 frontmatter 标注了源书+txt路径的**纯样文原文**是唯一权威文风源，权重 **最高**。本地 `素材/文风锚定*.md` 只是"辅助参考"，**禁止以其为正文主师**，禁止用本地自造锚定替代 P0、禁止跳到项目外搜索/蒸馏现造新锚定。

**P0 命中即锁定**：若`references/文风兜底/`里某档 frontmatter 的源书与本次文风目标（用户点名书名/作者/口味）命中，必须直接用该档纯样文原文，禁止绕过它去搜索或自造。执行报告标注"文风源：{文件名}（源书：{源书}）"。

兜底规则：P0 全库无匹配时，从`references/文风兜底/`选一个——**找不到合适赛道档时，默认拿`西幻·玄幻史诗.md`（源书：参考小说txt/起点/玄幻仙侠/夜无疆-辰东.txt，纯样文原文）兜底**，而非跳过或外搜。执行报告标注"兜底文风：{文件名}（源书：{源书}）"。

**DNA必注入（硬约束）**：无论走 P0 命中 / P1 本地辅助 / P2 执行包 / 兜底，本章**必须注入至少一份文风DNA**（纯样文解剖维度或对其的转写均可，但必须真实存在、可回源），缺失态【禁止】跳过DNA直接写作。

读取规则：优先按 P0 纯样文原文加载其`## 笔触``## 句式``## 段落呼吸`等解剖维度；有执行包时叠加按执行包加载章内套路；无执行包时按本章章型加载对应场景卡+通用维度；DNA源过大时只读源文件目录/源书开头+对应章型解剖/角色口癖隔离（须标注所读范围）。

**禁止行为清单**：①禁止以本地自造锚定为主师，reference原文只当"辅助对照"；②禁止"reference里其实有匹配档却说没有"而外搜蒸馏；③禁止读本地锚定后不读/不再查 P0 reference。违者=文风源断言不实，review 打回。

**设定注入（每章≤3维度≤1500字，按章型按需）**：按章型从 pop-snow-stage 产出文件按需读取，禁止全文注入。每维度≤500字。

必选（每章）：

| 文件路径                | 提取内容                    |
| :------------------ | :---------------------- |
| `设计/角色库/角色库.md`     | 本章有对话角色的语言指纹+行为模式+关系张力  |
| `设计/全书设定/类型风味基线.md` | 类型声明+风味基线表——类型味方向锚，杜绝漂移 |

按章型再选≤1个：

| 章型  | 文件路径                                  | 提取内容                |
| :-- | :------------------------------------ | :------------------ |
| 战斗章 | `设计/力量体系.md` + `设计/全书设定/战斗系统.md`      | 力量边界+分阶战斗形态+战斗底层规则  |
| 日常章 | `设计/卷舞台/卷N-舞台.md`                     | 本卷舞台的势力格局+地图区域+矛盾核心 |
| 探索章 | `设计/全书设定/物理规则.md` + `设计/全书设定/地理建筑.md` | 力量法则+空间法则+区域信息      |
| 危机章 | `设计/全书设定/危机敌人矛盾.md`                   | 危机体系+敌人生态+矛盾轴       |
| 社交章 | `设计/全书设定/政治经济.md` + `设计/全书设定/民风民俗.md` | 权力结构+文化质感           |
| 成长章 | `设计/金手指.md` + `设计/力量体系.md`            | 金手指限制+阶位突破规则        |

注入规则：角色库+类型风味基线必选，再按章型选≤1个；每文件只提取本章相关段落（≤500字）不全文注入；提取内容写入写作包"设定状态"字段。

**X体验层注入（可选，改编项目）**：项目存在`素材/改编计划.md`时按章型注入X耦合（战斗/日常/剧情），每章至少1处参与动作/对话/决策。不存在时跳过，不自行编造。

**缺口处理**：全书日志/本章章纲明显缺关键事实时，停止并要求先执行pop-snow-review产出。用户要求继续则execution.mode降为draft或trial。

**抽取本章写作包**：

```markdown
## 本章写作包
execution.mode:
- 把 X 写成 Y：
- 当前章位：
- 上一章白描：（叙事流回溯锚）
- 钩子台账：（本章可回收/不可提前吞并）
- 角色当前状态：（主角/配角当前立场）
- 读者已知信息池：（信息差类型，写信息不穿帮）
- 关键数据🔒：（写错=bug）
- 本章章纲：（时空与主体/事件节点/交接信息三块要点）
- 后1章悬念：（全书日志"此刻悬着的线/还没揭的悬念"里本章不可提前吞并列一行——钩子指向校验）
- 可用燃料：
- 用户本轮新增要求：
- 类型声明：（当前作品类型+保持什么味+禁止漂移到哪）
- DNA约束：（3-5条本章实际执行的笔触约束）
- 文风DNA执行：（DNA源/模式/章型/笔触目标/章内套路/可见反馈/禁止误用；兜底标注"兜底文风：{文件名}"）
- 对话锚点：（本章有对话角色的语言指纹——句式偏好/用词偏好/对话标志2个）
```

**execution.mode判定**：formal=上一章章日志（按需）+全书日志+本章章纲（读取完成）+最近正文（按需）+用户要求齐全且达标（DNA源齐全或已兜底）；draft=必读核心有缺口但用户要求继续；trial=快速试做不落盘。**缺本章章纲/全书日志不得标formal。**

**门禁（进入Step 2前）**：写作包完整｜execution.mode已判定｜章纲读取完成、时空与主体/事件节点/交接信息三块已锁定｜章纲事实冲突已比对全书日志｜类型声明已注入｜DNA约束3-5条已选定｜对话锚点已提取或确认"本章无对话"｜缺口已记录。

### Step 2：渲染正文+落盘+对话回复

按本章章纲的事件节点推进渲染2000-2500字：节点逐个兑现（事件+转折+落点功能）+章末钩子分级落章。正文写入`正文/ch{NNN}.txt`后，在对话回复里给 review 交接信息（不落盘文件）。

**正文规则**：

- 开场120字内出现目标、异常、压力、反馈或主动动作之一

- 主角至少完成一次动作闭环：压力/诱因→判断→主动动作→阻碍升级→可见反馈→收益/损失→新压力

- **本章章纲必兑现**：事件节点按序推进，一个不丢；每节点「事件/转折/落点功能」落到正文；落点功能（本节结尾读者感受到什么/为后文铺什么）必须兑现；交接信息（对白意图/世界观功能/角色语感）按写前约定走。不能只铺氛围

- **物理缝合**：章纲只锁"事件/转折/落点功能"，不锁具体时序与动作细节时，write 负责补齐物理链（谁的手/什么时机/物件从哪来），补的拍服从章纲功能与前后因果。章纲功能空=补缝合并标注

- **事实冲突以全书日志为准**：章纲事实与全书日志冲突时以全书日志为准+对话回复给 review"冲突标注"

- 关键爽点必须外显（旁人反应、资源变化、局势翻转、敌人误判），不能只由作者总结"他赢了"

- 不提前吞并全书日志"此刻悬着的线"里未到期的钩子

- 结尾必须留下主动钩子或威胁逼近，不用自然停顿收尾

- 判定链/系统数值一律自然段内联呈现（【】格式），禁弹窗式/代码块

**去AI味写字节（生成即达标，非事后降噪）**：写作时主动规避表层AI味信号，正文天然去魅，禁止写完再跑"降AI味"重写流程：

| 信号       | 写时规避                                  |
| :------- | :------------------------------------ |
| 模板化开头    | 不写"随着…/在当今社会/近年来/众所周知"，直接场景起句（"天擦黑…"） |
| 展望套话收尾   | 不写"综上所述/让我们拭目以待/相信在不久的将来"，点到即收束       |
| 三段式/对仗排比 | 不排"首先→其次→最后""不仅…而且""既…又""一方面…另一方面"    |
| 过渡连接词    | 换口语：值得注意的是→说白了；由此可见→看得出来；与此同时→同一时间    |
| 破折号      | ≤1个/500字，只留列举式/必要转折                   |
| 半角引号     | 一律中文全角引号，禁止半角 `"` `'`                 |
| 句长均匀     | 避免连续3句都是15-25字，穿插≤5字短句控节奏             |
| 概括式内心    | 少写"他忽然觉得/她突然明白"，落到具体动作/细节外显           |

**DNA落地**（不是事后润色，而是参与本章生成）：

| DNA项   | 在正文中的体现                            |
| :----- | :--------------------------------- |
| 笔触目标   | 叙事距离、句式、段落呼吸、感官顺序、对话引导方式           |
| 主角主动方式 | 主角必须做出选择或动作                        |
| 爽点外显方式 | 旁人反应、资源变化、局势翻转、敌人误判                |
| 叙事人格   | 旁白站位和判断顺序                          |
| 句子气口   | 长短句、独句段、信息先后                       |
| 信息释放   | 先给结果还是先给过程，哪些暂不解释                  |
| 章内套路   | 起笔、第一信息变化、压力/诱因、主角动作、阻碍升级、可见反馈、章末钩 |
| 可见反馈   | 敌人失态、旁观者改判、资源/信息变化、威胁逼近            |

**对话落地**：每个有台词的角色必须从对话锚点取语言参数（句式偏好/用词偏好/对话标志），不凭记忆写对话。对话锚点缺失时从`设计/角色库/角色库.md`按需读取语言指纹。write负责"对话内容对+角色语言指纹对"，review负责"对话质量好不好看"。

**落盘**：正文写入`正文/ch{NNN}.txt`。文件名固定，对话只回交接信息（摘要/钩子/新增事实待核/冲突/字数），不把正文全文放进对话，也不落盘创作记录文件。

**验收门禁**（落盘后必跑）：

| 项      | 验收方式                                                                               |
| :----- | :--------------------------------------------------------------------------------- |
| 正文存在   | `正文/ch{NNN}.txt` 存在                                                                |
| 汉字字数达标 | exec 跑 `scripts/word-count.ps1 -Path 正文/ch{NNN}.txt`；纯汉字2000-2500；脚本stdout原文放进对话回复交 review |

**新增事实处理**：write不维护任何库文件。新增事实只在对话回复里列"新增事实待review"清单，由 review 落库。write只声明不落库。

**下一步（硬后继）**：正文落盘后必须执行pop-snow-review。review是write的硬后继，未执行review不得写下一章。

## 红线

1. **章纲必兑现**：事件节点按序推进一个不丢；每节点「事件/转折/落点功能」落到正文、落点功能兑现；交接信息/角色语感按写前约定走。任一节点缺失或落点功能未兑现=不合格，review打回。
2. **事实冲突以全书日志为准**：章纲事实性字段与全书日志冲突时，以全书日志为准。章纲事实错误不经write放大传染。
3. **状态连续性**：全书日志"不许碰/此刻悬着的线"的禁止漂移硬清单写错=bug；未到期钩子不得提前吞并。
4. **每章爽点≥1**：爽感公式必须落地且有爆发感；连续2章无爽点=不合格。
5. **DNA必注入**：本章必须注入至少一份真实可回源的文风DNA；缺失时默认拿`西幻·玄幻史诗.md`（源书《夜无疆-辰东》纯样文原文）兜底，禁止裸写。
6. **文风源权重**：`references/文风兜底/`纯样文原文为唯一权威文风源；禁止以本地自造锚定为主师、禁止"reference有匹配档却说没有"而外搜蒸馏、禁止读本地锚定后不查P0。违者=文风源断言不实，review打回。
7. **字数门禁**：落盘后必跑word-count.ps1，纯汉字2000-2500为合格；脚本stdout放进对话回复交 review，禁用模型自报字数。
8. **去AI味写字节**：正文按「去AI味写字节」表在生成时即规避表层AI味（模板头尾/对仗排比/过渡词/破折号≤1每500字/半角引号/句长均匀/概括式内心），**生成即达标**；禁止"写完再单独降AI味"的重写流程。
