# 类型风味基线

> world 维度0产出（跨维度横切基线——seed 声明的世界类型+风味基调展开为命名/器物/社会符号参考系）。**write 每章注入此基线作为类型味方向锚，杜绝"声明西幻却写出中式味"。**所有后续维度（民俗/地理/势力/人物）的命名与器物必须符合此基线。

## 类型声明

一句话锁死当前类型+保持什么味+禁止漂移到哪——write 每章注入此声明。

```
【类型声明】当前作品类型：{seed 声明的类型}。
写作全程保持{类型}味：{命名}为{命名风格}，货币/器物/食物/建筑为{器物风格}，
社会符号含{社会符号}。
禁止漂移到{其他类型}（{该类型典型命名/器物}）或{其他类型}。
```

## 风味基线表

| 类别 | 参考系（该类型基本盘） | 落地维度 |
|:--|:--|:--|
| **命名体系** | 人名/地名/势力名风格（西式/中式/现代） | 维度4民俗/维度5地理/维度6势力·人物 |
| **器物清单** | 货币/食物/建筑/工具（西幻=银币黑面包石堡短剑；东方武侠=银两客栈刀剑镖局；现代都市=人民币公寓地铁手机） | 维度4民俗/维度5地理 |
| **社会符号** | 职业/神祇/魔法/教会 或 江湖/门派/内力/武功 或 公司/学校/都市规则 | 维度3政经/维度4民俗/维度6势力 |

> **类型门禁**：各维度产出命名/器物/社会符号前对照此基线检查——声明西幻却产出"铜板/米斗/驿站/柴刀/江湖/门派"=类型味漂移，打回。此门禁贯穿Pare 1/2/3检查点。
