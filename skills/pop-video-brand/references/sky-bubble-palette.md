# Sky Bubble 品牌色板与文案口径速查

> 品宣视频必须严格使用本页色板与文案口径，禁止自创配色或夸大文案。

## 色板（CSS 变量）
```css
:root{
  --pb-blue:#2F64FF;   /* 主蓝：核心强调、按钮、重点词 */
  --pb-cyan:#26D7E8;   /* 泡泡青：渐变、高光、信息点 */
  --pb-purple:#7B59FF; /* 波浪紫：Agent 与品牌渐变 */
  --pb-ink:#141824;    /* 主墨色：大标题 */
  --pb-text:#343B4D;   /* 正文色：正文与说明 */
  --pb-canvas:#FBFDFF; /* 画布白：主背景 */
  --pb-line:#DCE8F2;   /* 线框色：轻边框和结构线 */
}
```
- 整体：高明度白底 + 天空蓝到泡泡青柔和光晕 + 少量紫色过渡。
- 避免：厚重拟物、灰边、廉价高光。

## 品牌定位一句话
Popwave 是一站式 AI 网文写作 Agent，从开书、拆书、设定、正文、去 AI 味、资料下载到推书营销素材，都在同一项目中持续完成。核心卖点"一书到底"：从开坑到完本，再到出圈，由一个 Agent 持续工作。

## 主标题 / 核心条
- 主标题：`一个 Agent，陪你写完一整本书`
- 核心条：`一书到底｜从开坑到完本，再到出圈`
- 证明标签：`Agent 对话与创作`、`文件全在本地`、`作品资料持续沉淀`
- 功能链：`开书`、`拆书`、`设定`、`正文`、`去 AI 味`、`资料下载`、`推书营销素材`
- CTA：`关注 @Popwave泡泡写作，申领百万字创作福利`

## 章节引擎口径
- 主标题：`不用再对着空白页｜这一章，先想清楚再写`
- 机制：`章前设计 → 写正文 → 章后自检`；结果：`把每章变成完整循环`
- 痛点标签：`不卡文`、`接得上`、`不注水`、`留钩子`、`有自检`

## 文风 DNA 口径
- 主标题：`别让 AI，把所有故事写成同一个模样`
- 副标题：`锁定行文风格，写出赛道专属文笔质感`

## 推书营销口径
- 差异化能力：`推书营销素材 · 独家能力`
- 一句话：`一句话，AI 帮你做推书海报`
- 请求示例：`「我想推广这本书，请帮我做一张海报」`
