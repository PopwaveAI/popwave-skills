# Step 0 · 盘素材（Inventory）

> 目的：摸清素材包里有什么、品牌口径是什么、能讲几个价值点，为 Step 1 定脚本提供输入。
> 做完本步，产出 `素材清单.md`，然后进入 Step 1。

## 0.1 扫描素材包目录
- 用 LS 递归列出素材包全部文件，识别四类资产：
  - 品牌规范（视觉规范 / 文案口径 / 版式参考结论）
  - 品牌资产（logo / wordmark / 吉祥物）
  - 产品截图（每张截图代表一个功能价值点）
  - 版式参考（16:9 母版 / 3:2 可延展构图 / 超宽工作流）

## 0.2 读品牌规范（必读，铁律）
- 读视觉规范：提取品牌定位、色板（主色/辅助/文字/背景/线框）、吉祥物边界、产品截图使用规则。
- 读文案口径：提取一句话人设、首选叙事结构、常用表达原则、频道差异、禁用对照。
- 读版式筛选结论：确认默认母版、推荐保留的构图、不建议的做法。

## 0.3 读关键素材 + 量尺寸
- 用 Read 工具读 1-2 张核心截图（母版 + 主价值截图），理解界面视觉与可放大局部。
- 用 Python/PIL 批量量出所有候选图片的尺寸与格式（PNG/RGBA 等），供 Step 2 排版定位用。
- 确认哪些截图能支撑你要讲的价值点，哪些文字密度过高不适合放大。

## 0.4 圈定价值点与镜头组
- 按"每支视频只讲一个价值点、最多 3-4 张界面图"的铁律，圈定：
  - 主价值点（一句话）
  - 采用的截图清单（3-4 张，含主证据镜头、闭环镜头、扩展能力镜头）
  - 是否使用团队故事图（仅当视频讲"我们是谁"）

## 产出
`素材清单.md`：素材包结构、品牌要点摘要、价值点、截图清单、图片尺寸表。

## 传导
- 拿着 `素材清单.md` 进入 **Step 1 定脚本**，把价值点展开成逐镜头叙事。
