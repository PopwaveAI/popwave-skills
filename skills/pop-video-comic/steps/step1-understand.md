# Step 1: 读图理解

> pop-video-comic 核心差异化步骤：模型**读图自理解**漫画页，产出每页画面白描 + 氛围标签 + 镜头感。图片为主，`页面配置.json` 文字兜底。

## 输入

- `素材清单.md`（Step 0 产出）
- 漫画页图片 `output/page1~N.png`

## 操作

1. **逐页 Read 漫画图**（主 agent 直接 Read，一次一页），对每页产出三要素：

   | page | 画面白描 | 氛围标签 | 镜头感 |
   |:--|:--|:--|:--|
   | page1 | 非对称三格，痛苦主体+青蓝裂纹 | 身体恐怖/心理惊悚 | 特写压迫/IMAX 沉浸 |
   | ... | ... | ... | ... |

2. **审查兜底（铁律❌2）**：单页被安全审查拦截时——
   - 用 `页面配置.json` 该页文字锚点补全画面理解
   - 标注该页 `[读图被拦截，配置文字兜底]`
   - **禁止因读图失败中断管线**，继续处理下一页

3. **氛围标签**用统一词汇表，便于脚本阶段调用：
   - 恐怖系：身体恐怖 / 心理惊悚 / 哥特恐怖 / 密恐 / 压迫
   - 情绪系：脆弱 / 崩解 / 窒息 / 悬置 / 绝望
   - 奇观系：史诗 / 壮观 / 神秘 / 崇高

4. 产出 `画面理解.md`。

## 产出

- `{项目}/视频/画面理解.md`（逐页三要素表）

## 完成判定

- [ ] 所有页已处理（含被拦截页的兜底补全）
- [ ] 每页有画面白描 + 氛围标签 + 镜头感
- [ ] 画面理解.md 已写入

> 读图是主源，配置文字是兜底，两者在脚本阶段交叉使用。
