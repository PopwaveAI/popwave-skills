# Step 2: 脚本创作 【🚪 老板确认闸门】

> 基于画面理解 + 文字锚点，写口播脚本。**产出脚本后必须停下来等老板确认**（铁律❌1）。

## 输入

- `画面理解.md`（Step 1 产出）
- `素材清单.md`（Step 0，文字锚点）

## 脚本结构（1 分钟短视频）

```
[钩子 0-5s]   开场 1-2 句，抓注意力（设问/悬念/反差）
[展开 5-50s]  按页推进，每页对应 1-2 句口播，情绪线递进
[收尾 50-60s] 钩子留白/悬念，引导追读
```

### 每句口播的字段（铁律❌3）

| 字段 | 说明 |
|:--|:--|
| `seq` | 句序 |
| `page` | 绑定到哪页（如 page1）——**必填** |
| `text` | 口播文案（中文，一句话） |
| `emotion` | 情绪标签（紧张/惊悚/悬疑/崩溃/钩子） |
| `est_sec` | 估算时长（按字数估，约 4-5 字/秒） |

## 写作原则

1. **钩子优先**：开头 2 句必须有悬念或反差，不能平铺直叙"这是一个..."
2. **每页至少 1 句**，绑定 `page{N}`，保证画面与口播同步
3. **情绪线递进**：从"痛醒"→"陌生房间"→"穿越惊惧"→"笔记恐惧"→"伤口惊悚"，层层升温
4. **口播是"讲给朋友听"的口吻**，自然口语化，不是书面朗读
5. **总时长目标 ~60 秒**，字数约 240-300 字

## 产出口播脚本.md

```markdown
# 口播脚本 · {章节名}

视频时长目标：~60s | 总字数：~{N}字
图片：page1~page{N} + 封面/OC

## 开场（钩子）
1. [page-封面] (钩子) 深夜，一个男人从剧痛中惊醒，却发现……  
2. [page1] (紧张) 他睁不开眼，身体像被钉在床上。

## 展开
3. [page2] (悬疑) 等他终于睁开眼，看到的却不是自己的房间……
...

## 收尾（钩子留白）
N. [page5] (惊悚钩子) 镜子里，他太阳穴的伤口……还在蠕动。
```

## 🚪 确认闸门

产出 `口播脚本.md` 后，**停下来等老板确认**。仅当老板确认脚本后，才进入 Step 3 配音 + Step 4 合成。若老板要求修改，迭代脚本后再确认。
