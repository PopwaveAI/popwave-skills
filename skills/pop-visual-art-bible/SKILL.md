# pop-visual-art-bible

> Art Bible · 美术设定集。L1 基建层「产出美术设定集」，全 IP 宇宙视觉唯一真源。当前版本 v3.1.0，完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 做什么

输入：`pop-visual-asset`（查原文：角色档案/场景资产表/视觉符号库/IP视觉DNA/势力档案/地理档案/规则档案）+ `pop-visual-style`（定画风：画风DNA/画风决策/定标图）。
输出：**美术设定集** `素材/美术设定集.md`（八篇合一）——全 IP 宇宙视觉的唯一真源，**文+图**。

**核心价值**：把原 `character` skill 从"只设计人物身份"升级为"产出整部美术设定集"。原体系画风归 style、人物归 character、场景符号散在 asset，没有统一 owner 裁决"这个 IP 宇宙整体长什么样"，各画各的必然漂移。本 skill 就是那个权威 owner：消费 L1 基建产出 → 翻译成统一美术设定集 → 跨实体一致性仲裁 → 冻结为派生层唯一消费的真源。

**一句话定位**：`asset` 负责"**原文里有什么**"（查），`style` 负责"**用什么画**"（画风），`art-bible` 负责"**这个宇宙看起来怎样**"（设定集，唯一真源）。

> **世界观推广素材同样归此**：势力卡/地理卡/规则卡等推广素材的视觉真源，由势力篇/地理篇/规则篇统一裁定，oc 只消费不再重建。

## 与 L1 基建的关系

| L1 基建 | 提供什么 | 本 skill 消费方式 |
|:-----|:--------|:-------|
| `pop-visual-asset` | 角色档案（10维度）、场景资产表、视觉符号库、IP视觉DNA、势力档案（8维度）、地理档案（7维度）、规则档案（6维度） | 各篇的**原文证据来源**，翻译成画面 |

> **铁律**：美术设定集是派生层唯一消费的视觉真源。下游渲染**只改渲染格式，不改视觉事实**（人物/场景/符号/画风）；任何视觉事实改动必须回本 skill 升级设定集版本。设定集经认可后冻结为基线资产（标 `✅ 已认可`），下游只消费冻结版。

## 怎么运作（SOP全内联）

### Step 0: 读输入 + 档位规划

**前提校验**：asset 资产缺失 → 提示先跑 `pop-visual-asset`，或本 skill 内部执行 5 轮原文关键词搜索+上下文采样补齐；画风未定 → 从 `pop-visual-style` 画风DNA库按赛道选基准，或先跑 style 定标。

**读 asset 原文资产**（`素材/视觉资产/`）：

| 文件 | 服务篇章 | 重点读 |
|:--|:--|:--|
| `[角色名]角色档案.md`（10维度） | 人物篇 | 一概览/二外貌演变/五成长弧线/八矛盾暗面/十核心意象与符号 |
| `场景资产表.md` | 场景篇 | 可定格帧清单 |
| `视觉符号库.md` | 符号篇 | 核心意象/标志色/器物/阵营符号 |
| `IP视觉DNA.md`（同人时） | 各篇 | IP 视觉事实证据 |
| `[势力名]势力档案.md`（8维度） | 势力篇 | 二人群画像/三美学基调/四象征体系 |
| `[地名]地理档案.md`（7维度） | 地理篇 | 二空间质感/三氛围基调/四标志性地标 |
| `[规则名]规则档案.md`（6维度） | 规则篇 | 二视觉外显/三层级可视化/四器物载体 |

**读 style 画风**：`素材/风格/画风决策.md` + `skills/pop-visual-style/references/文风DNA-library.json`，取 `dna`/`constraint`/`recommended_lighting`/`recommended_composition` 四字段。画风决定**美术语言**（厚涂/赛璐璐/暗黑高对比），不决定**视觉事实用色**（色彩基调仲裁是本 skill 的活）。画风已冻结（`✅ 已认可`）时直接引用冻结版+定标图+seed。

**读已有美术设定集**：存在 → 升级模式（增量：新增角色/换装/受伤/觉醒/新场景/新符号/改画风；**反类型化和撕裂感一旦建立就保持**）；不存在 → 新建模式走 Step 1 完整设计。

**档位规划**（按 intent 决定点亮哪几篇、复现多深，**不默认全量**）：

| intent | 点亮篇章 | 复现深度 |
|:--|:--|:--|
| `cover` | 画风 + 场景（局部）+ 封面相关人物 | 单张参考图（可选） |
| `oc` | 画风 + 人物 | 单张定妆图（可选） |
| `comic` | 画风 + 人物 + 场景 + 符号 | 完整复现（人物双角度+场景定妆） |
| `world` | 画风 + 势力 + 地理 + 规则 | 势力/地理/规则示例图（可选） |
| `full` | 全部八篇 | 完整复现 |
| `asset-only` | 不进入本 skill | — |

> 独立模式（不在 pipeline 语境）按用户当次意图判定，规则一致。

### Step 1: 设计美术设定集

> **设计顺序铁律：先"全局上锁"（画风基调→人物差异化→场景/符号），再"单实体填料"。** 设计第一个实体前必须先想它在全书视觉里的差异化位置，否则就是"属性堆砌"、跨形态漂移。
> **必读**：`references/advanced-character-design.md`（人物篇方法论）+ `references/bible-arbitration-guide.md`（一致性仲裁）。

**① 画风篇**：引用冻结画风四字段 + 画风决策 + 定标图 + seed + 参考图路径；从画风DNA推导**全宇宙色彩基调**（≤3主色+辅助色），作为场景/人物/符号的用色上限与**仲裁准绳**——签名色/场景主色/符号色不得超基调，撞色即废。

**② 人物篇**（原 character 全套方法论，必读 advanced-character-design.md）：

- **🚪 实体覆盖门禁**：人物篇设计范围 = asset 角色档案清单范围；只为清单内角色设计，清单外角色不进人物篇也不进互查表。剧情重要但无档案的角色（如金翅鸟煞/配角）：cover/oc 档在主角"符号/撕裂感"里锚定不单独立角色；comic/full 档**先回 asset 补档案**再设计，禁止跳过档案直接画。每角色标注视觉事实来源（档案维度/行号）备 ❌1 反查。
- **三把锁差异化纪律**（全局先行，先于单角色设计）：

| 锁 | 约束 | 判据 |
|:--|:-----|:-----|
| ① 剪影签名 | 一人一个可辨认轮廓签名，全局唯一 | 十米外只看剪影能喊出名字；同书互比不撞 |
| ② 签名色 | 一人一个全局唯一主色，不超色彩基调 | 同屏两角色不撞色；撞色即废 |
| ③ 记忆锚点 | 主角可多锚点组合，配角只给1个 | 主角/重要角色 2-3 个锚点组合（统一指向同一核心人设）；配角/路人 1 个（宁缺毋滥）。**锚点数 = 角色重要度** |

  **置换测试**：把角色A的剪影/签名色/锚点换成角色B，画面还成立吗？成立=未差异化，回炉。

- **五问提取法**（原著不是描述"长什么样"，而是描述"过什么日子"；每问从角色档案/原文找证据，不靠外貌形容词）：

| 问 | 提取什么 | 落到视觉 |
|:---|:---------|:---------|
| 1. 他靠什么活？ | 职业/经济 | 服装、姿态、物件 |
| 2. 他失去了什么？ | 创伤/缺憾 | 面部瑕疵、表情残留 |
| 3. 他每天做什么动作？ | 习惯性行为 | 姿态锚点 |
| 4. 他此刻最缺什么？ | 欲望/困境 | 表情谱系 |
| 5. 他身上的"符号"是什么？ | 命运隐喻 | 道具/印记 |

- **角色设计金字塔**（三层递进）：剪影层（最远，0.3秒认出"是谁"）/色彩层（中景，区分阵营暗示命运）/细节层（特写，信息密度埋彩蛋）。**AI 落地**：提示词显式三层各写一段，每层只给"一个主视觉+至多一个辅助"。
- **反类型化 + 撕裂感**：反类型化=表情/职业/完美/信息密度四维反"网感脸"，打破 AI 平均值；撕裂感=符号（潜力隐喻）与行为（日常）冲突，在命运节点被撕开。
- **每角色产出**：三把锁 + 七维度规格表 + 三级金字塔 + 记忆锚点 + 反类型化 + 撕裂感 + **视觉锚点串（英文）+ 冻结提示词（英文）**。可拆用 `templates/visual-identity-card.tpl.md` 结构，内容必须并入设定集人物篇。

**③ 场景篇**：读场景资产表取可定格帧清单；只做**关键场景**（承载剧情升降/名场面，不穷举），每场景翻译成画面五字段：**场景意象**（什么感觉1句话）/ **氛围基调**（光影色彩情绪，符合色彩基调）/ **构图骨架**（主视觉焦点+层次，符合画风构图模板）/ **可定格帧**（引原文行号）/ **冻结提示词**（英文，供下游复用）。

**④ 符号篇**：读视觉符号库；每符号整理成：符号含义（叙事功能）+ 视觉形态（配合画风）+ 使用场景 + 冻结提示词。符号色符合色彩基调，作为人物/场景的"彩蛋层"复用。

**🚪 三篇实体覆盖门禁（势力/地理/规则，与人物篇同源）**：三篇设计范围 = asset 对应档案清单范围，只为清单内实体设计；无档案实体先回 asset 补档案再设计，禁止跳过档案直接画；每实体标注视觉事实来源（档案维度/行号）。

**⑤ 势力篇**：读势力档案取阵营美学/象征体系/人群画像/等级秩序；只做**主线/关键势力**（承载阵营冲突，不穷举），每势力翻译"阵营视觉身份"六字段：**势力定位**（是什么1句话）/ **核心气质**（如肃杀铁律/超然出尘）/ **阵营美学**（标志色/纹饰/建筑/器物，符合基调）/ **象征体系**（旗帜纹章族徽图腾，关联符号篇）/ **等级秩序**（阶层视觉外显：服饰差异/地位标识）/ **冻结提示词**（英文，供下游势力卡）。势力美学必须**与人物签名色互查**：同阵营人物用色归拢势力基调下，跨势力不撞。

**⑥ 地理篇**：读地理档案取空间质感/氛围基调/标志性地标/生灵种族；只做**关键小世界/城市/秘境**（有独特空间质感，不穷举），每地理翻译"空间视觉设计"六字段：**地理意象**（什么感觉1句话）/ **空间质感**（材质地形建筑植被气候）/ **氛围基调**（光线色彩温度声音情绪，符合基调）/ **构图骨架**（主视觉焦点+层次）/ **标志性地标**（3-5个可定格节点，关联场景篇）/ **冻结提示词**（英文，供下游地理卡）。地理氛围必须**与场景篇互查**：同一地理内关键场景氛围归拢一致。

**⑦ 规则篇**：抽象规则最难画，**必须从原文已有的视觉外显提取具象载体，禁止凭空发明符号**。读规则档案取视觉外显/层级可视化/器物载体；只做**主线体系/核心规则**（决定全书力量观/世界观，不穷举），每规则设计"可视化策略"六字段：**规则内涵**（是什么1句话）/ **可视化策略**（符号/光影/器物/天象载体）/ **视觉外显**（光效纹路天象异象，引原文行号）/ **层级可视化**（各境界突破的不同视觉奇观）/ **器物载体**（关联符号篇）/ **冻结提示词**（英文，供下游规则卡）。

**⑧ 一致性仲裁**（必做，见 `references/bible-arbitration-guide.md`）：

- **三把锁全局互查**：全角色剪影/签名色/记忆锚点互比确保无撞。互查对象 = 人物篇实际产出角色；**角色数 <2 时只放单行+标注"待 asset 补配角档案后互查"，禁止虚构配角填表**；覆盖校验：互查表角色数 = 人物篇角色数，出现伪角色即虚构，回炉。
- **跨实体冲突裁决**：人物签名色 vs 场景主色 vs 符号色 vs 势力阵营色 → 撞色即回炉，**以色彩基调为准绳**；势力阵营色归拢麾下人物用色、地理氛围归拢场内场景调性、规则外显色复用符号层。
- **画风一致**：各篇冻结提示词基于同一画风，不停发明新画风。
- 输出三把锁全局差异化表 + 仲裁记录。

**⑨ 产出**：用 `templates/art-bible.tpl.md` 填充八篇合一——一 画风篇（DNA+决策+定标图+seed+色彩基调）/ 二 人物篇（每角色：三把锁+七维度+三级金字塔+锚点+反类型化+撕裂感+冻结提示词+定妆图路径）/ 三 场景篇（意象/氛围/构图/可定格帧+冻结提示词+场景图路径）/ 四 符号篇（含义/形态/使用场景+冻结提示词）/ 五 势力篇（定位/气质/阵营美学/象征体系+冻结提示词+示例图路径）/ 六 地理篇（意象/空间质感/氛围/构图+冻结提示词+示例图路径）/ 七 规则篇（内涵/可视化策略/视觉外显+冻结提示词+示例图路径）/ 八 一致性复现（三把锁全局差异化表+仲裁记录+复现资产索引[seed/参考图/冻结提示词/定妆图路径]+版本）。

**设计自检**：画风引用冻结无发明｜用色不超基调｜三把锁全局唯一过置换测试｜人物篇角色数 = asset 档案清单数（无虚构配角；<2 时互查表仅单行+待补）｜锚点按重要度分级且每个有"为什么"｜显式写"偏科"｜场景/符号/势力/地理/规则均来自 asset 档案无虚构实体｜势力色归拢人物/地理归拢场景/规则色复用符号层｜规则可视化有原文行号依据｜有撕裂感｜仲裁无撞色撞剪影。

### Step 2: 确认 + 落盘 + 冻结

**🚪 门禁：美术设定集确认**——向用户呈现摘要逐项确认：画风引用 style 冻结（无发明）｜人物有辨识度（0.3秒认出）+忠于原著处境+有锚点/撕裂感/反类型化｜场景/符号/势力/地理/规则形象均来自 asset 对应档案（非凭空捏造）｜规则可视化有原文视觉外显依据｜仲裁已做（无撞色/撞剪影，势力色归拢人物、地理氛围归拢场景）｜色彩基调统一。**未确认不落盘冻结**；用户提修改 → 回 Step 1 调整对应篇章。

**落盘**：`素材/美术设定集.md`——首次新建；已有 → 升级版本（版本号递增，变更记录保留到"八、一致性复现·版本"）。

**冻结为基线资产**：用户认可后标注 `签核状态: ✅ 已认可`（全 IP 宇宙视觉准绳），记录复现资产生成状态（未生成则提示进入 Step 3），通知下游可消费（见「与下游的关系」表）。

### Step 3: 复现资产生成（按 intent 档位分支）

> 复现图是设定集的**可视化验证**，不是出新视觉事实——验证"这个宇宙长什么样"的设计在大图上是否成立。**不达标 → 回设定集升级版本（改视觉事实），禁止在渲染层硬凑**；未认可不冻结、不放行下游。

**档位分支**：只做设定集不渲染 → **跳过本步**（Step 0→1→2 即完成）；`comic`/`full` → **完整复现（必做）**：人物**正/侧双角度**定妆图 + 关键场景定妆图，走完整验收门禁，进入下游前先复现；`cover`/`oc` → **轻量复现（可选）**：基建到 Step 2 即可派生，**不强制双角度**，如需参考图渲染单张，agent 自查达标标 `✅ 已认可`；`world` → **世界观复现（可选）**：基建到 Step 2 即可派生，如需势力/地理/规则示例图渲染单张。独立模式（无 状态.md）按用户当次意图判定：漫画/连载→完整档，封面/OC→轻量档，世界观推广素材→世界观档。

**复现图 = 纯生产参考图**（给下游做图生图 `ref_image` 的纯净素材，非展示作品；与 `pop-visual-oc` 立绘OC——带文字+文化元素的展示作品——严格区分）：**禁止**任何文字（角色名/称号/题诗/书法大字/钤印）、装饰元素（边框/印章/纹样/排版线）、文化元素（背景文字/铭文/道具特殊文字）；只要纯净视觉本体——居中，标准姿态/视角，干净背景，聚焦"长什么样"。

**组装复现提示词**（读 `../pop-visual-shared/references/seedream-prompt-guide.md` 6段式，画风DNA放第2段）：

```
[质量触发词] + Art style: [dna] [constraint] + [构图策略] + [光影叙事] + [设定集冻结提示词] + [标准视角/姿态]
```

- 各篇用对应**冻结提示词**：人物段（含三层+反类型化+撕裂感）/场景段（意象/氛围/构图骨架）/势力段（阵营美学/象征体系）/地理段（空间质感/氛围基调）/规则段（可视化策略/视觉外显）
- 构图/光照：画风基线的 `recommended_composition` + `recommended_lighting`
- **硬约束**：追加 `no text, no letters, no characters, no watermark, no decorative elements, no border, no seal`

**生成复现图**（统一走 `image_generate` 工具，不直连 API；传画风定标图作 ref_image 图生图保证画风一致）：

```text
人物定妆：image_generate(prompt='人物冻结提示词', size='1125x1500', ref_image='画风定标图', output='测试/复现/复现-{角色名}-v1.png')
场景/势力/地理/规则：image_generate(prompt='对应冻结提示词', size='1500x1125', ref_image='画风定标图', output='测试/复现/复现-{名称}-v1.png')
```

**📁 落盘三态**（见 `../pop-visual-pipeline/references/落盘规范.md`）：候选图统一输出 `测试/复现/`（确保目录存在）；**门禁认可后**复制到 `成品/复现/`（加 `-final`），成品路径记入美术设定集复现资产索引——下游 oc/comic/cover 做 `ref_image` 一律读成品路径，禁止引用 `测试/` 候选。**⚠️ 复现图禁止加品牌水印**：加了 `popwave.cn` 会被 Seedream 当画面内容带进下游正式成品，水印层层污染；水印只在对外展示产出（OC立绘/封面/漫画页）落地后叠加。

**🚪 门禁：复现验收**——向用户呈现复现图逐项验收：

| 维度 | 验收判据 |
|:-----|:---------|
| 人物剪影层 | 0.3 秒能否凭轮廓认出"是他" |
| 色彩签名 | 主色块能否区分阵营/暗示命运，不超色彩基调 |
| 记忆锚点 | "0.3 秒认出"的锚点是否真的被画出来 |
| 反类型化/撕裂感 | 是否打破网感脸，有"状态感"而非"摆拍感" |
| 场景意象 | 是否传达出"这个场景是什么感觉" |
| 势力阵营美学 | 是否传达出"这个阵营是什么气质"（标志色/象征可辨识） |
| 地理空间氛围 | 是否传达出"这个地方是什么感觉"（空间质感/氛围基调） |
| 规则可视化 | 抽象规则是否被具象化（有原文视觉外显载体，非凭空符号） |
| 画风一致 | 与画风定标图是否同款画风（无漂移） |

**未达标不冻结**——回设定集升级版本，重渲 v2、v3... 直到达标。**认可 → 冻结基线资产**：`素材/美术设定集.md` 标 `签核状态: ✅ 已认可`，复现图成品路径记入"一致性复现·复现资产索引"，作为下游参考图（图生图 image 参数传第一张）。

**下一步**：完成。Pipeline 语境进入派生层（Phase 3-6）按 intent 路由（`cover`→Phase3/5、`oc`→Phase4、`comic`→Phase6、`full`→loop）。

## ❌ 铁律

| # | 铁律 | 违反后果 |
|:-:|:-----|:---------|
| ❌1 | **视觉事实必须来自 asset 原文提取（五问提取法）** — 形象必须能从角色档案/场景资产表/视觉符号库或原文找到证据，禁止凭记忆/想象虚构 | 视觉事实扁平化，偏离原著，下游全部跑偏 |
| ❌2 | **每个视觉元素必须有"为什么"** — 写不出"为什么必须是这个样子"的元素删掉 | 落入平均值陷阱，视觉平庸不出彩 |
| ❌3 | **必须显式写"偏科"** — 禁止默认"黑发+白T+标准网感脸/标准场景"；要写 `lean build`、`tired bloodshot eyes`、`muted gray palette` 这类偏离均值的词 | 视觉无辨识度，0.3秒认不出 |
| ❌4 | **美术设定集是唯一真源，下游不重建** — 落盘后 oc/cover/comic/comic-content 只消费它，禁止各自重新设计人物/场景/符号/画风 | 各处各画各的，视觉漂移 |
| ❌5 | **视觉事实改动必须升级版本** — 人物/场景/符号/画风变化必须回本 skill 升级设定集版本，禁止下游擅自改 | 设定集与渲染脱节，跨形态不一致 |
| ❌6 | **复现图不达标回设定集，不硬凑渲染** — 不达标时回设定集升级版本（改视觉事实），禁止在渲染层硬凑 | 视觉漂移，下游全跑偏 |
| ❌7 | **三把锁差异化先行** — 设计人物前先定全局唯一位置（剪影签名/签名色/记忆锚点），同书互比不撞；锚点按重要度分级（主角2-3个组合/配角1个），过不了置换测试即回炉 | 角色"属性堆砌"，同书角色撞脸 |
| ❌8 | **定妆照是纯生产材料** — 定妆图必须纯净（无文字/无装饰/无文化元素），只做全下游生产参考，禁止混合展示功能 | 定妆图混杂展示元素，下游无法直接复用 |
| ❌9 | **画风必须引用 style 冻结** — 画风篇只引用冻结画风（DNA+决策+seed+定标图），禁止发明新画风 | 画风漂移，脱离已认可的定标 |
| ❌10 | **势力/地理/规则篇范围与来源 = asset 对应档案** — 只为档案清单内实体设计（无档案先回 asset 补，禁止跳过档案直接画），形象来自对应档案，规则可视化从原文视觉外显提取具象载体，禁止凭空虚构势力/地理/规则或发明规则符号 | 势力/地理/规则脱离原著，设定集失真 |
| ❌11 | **人物篇范围 = asset 档案范围，禁止虚构配角** — 人物篇与互查表只覆盖 asset 角色档案清单内角色；无档案角色不进人物篇，cover/oc 档在主角符号里锚定，comic/full 档先回 asset 补档案；角色数 <2 时互查表仅单行+标注待补 | 为填互查表虚构配角视觉，违反 ❌1 且设定集失真 |
| ❌12 | **规则可视化必须有原文视觉外显依据** — 可视化载体（光效/纹路/器物/天象）必须来自 asset 规则档案的原文行号，禁止凭空发明规则符号 | 规则可视化架空原著，下游规则卡失真 |
