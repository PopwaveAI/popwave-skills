# 高级角色设计方法论：从"平铺直叙"到"有故事的脸"

> v7.4.0 新增。解决"AI 角色立绘千篇一律、廉价感"的根因。**本文件是 `oc-design-guide.md` 的"高级设计层"增量**——在七维度规格表 + 高精度4块模板之上，注入"叙事性角色设计"。
>
> **核心命题**：AI 立绘平庸的根因不是"AI 画得差"，而是**提示词没给 AI 一个"偏科"的理由**。AI 默认输出训练数据里的"完美平均值"（黑发+白T+卫衣+牛仔裤+标准网感脸+标准站姿）。要打破它，必须显式告诉 AI"这个角色该偏离均值多少、往哪个方向偏"。
>
> **一句话解药**：把"帅"换成"有故事"，把"平均值"换成"能被 0.3 秒指认的偏科"。

---

## 0. 为什么"美型"救不了平庸

现有 `oc-design-guide.md` 的底层逻辑是"美型"（韩漫美型公式：骨相清晰、五官有戏、服装有设计感）。但**美型只解决"画得好看"，不解决"画得独特"**。苏午立绘的教训：按美型公式画出了一个"精致无瑕的二次元美男"，反而跟原著"穷困憔悴打工人"的设定 180° 背离。

**美型 ≠ 高级。** 高级角色（电锯人电次、咒术回战五条悟、灌篮高手樱木）的共性不是更美，而是**每个维度都带着"信息裁量"**——每个元素都在回答同一个问题："这个元素为什么必须是这个样子的？" 写不出原因的元素，删掉。

## 0.5 三把锁差异化纪律（全局先行，先于单角色设计）

> **v1.2.0 新增，老板定调。** 网文角色辨识度低、跨小说也低，根因不是"人文/精神层不够"，而是**设计层本身就没建立差异化**——网文角色是"属性堆砌"（一堆类型标签：黑金甲+金瞳+长发+俊美），而日漫（海贼王/火影）靠"一人一个互相冲突的剪影签名"分人。
>
> **核心命题**：差异化不是"加更多细节"，是**在全局层面让每个角色占一个"唯一"的视觉位置**。设计单个角色前，必须先想它在全书里的差异化位置。

### 三把锁（全局唯一约束）

| 锁 | 约束 | 判据 |
|:--|:-----|:-----|
| **① 剪影签名** | 一人一个**可辨认的轮廓签名**，全局唯一 | 十米外只看剪影能喊出名字；同书角色互比剪影不撞 |
| **② 签名色** | 一人一个**全局唯一主色** | 同屏两角色不撞色；撞色即废 |
| **③ 记忆锚点** | 主角可多锚点组合，配角**只给1个** | 见下"记忆锚点分级" |

**关键：三把锁是"全局唯一、互相冲突"的，不是"更多细节"的堆砌。** 不会有两个角色共享同一个剪影/签名色/锚点。

### 记忆锚点分级（主角 vs 配角）

> **老板细化**：记忆标识点不是"每人一个"这么简单，要按角色重要度分级——**主角可能不止一个点，配角可能就一个点。**

| 角色角色 | 锚点数量 | 原则 |
|:---------|:--------|:-----|
| **主角 / 重要角色** | **2-3 个锚点组合** | 多个锚点必须**统一指向同一个核心人设**，不互相抢戏。例：李周巍 = 白麟角（剪影）+ 白金签名色（色彩）+ 碑形大氅（轮廓）——三者合成一个"白麟碑"签名 |
| **配角 / 路人** | **1 个锚点** | 只给一个"0.3秒认出"的锚点，宁缺毋滥。给多了和主角抢辨识度 |

**原则**：主角用"锚点组合"建立厚重签名，配角用"单锚点"保持克制。**记忆锚点数量 = 角色重要度**，不是每个角色都堆满。

### 置换测试（差异化收口）

把角色A的剪影/签名色/记忆锚点换成角色B，画面还成立吗？

- **成立** = 没有差异化，两个角色共用一套签名，回炉
- **不成立** = 差异化成立，锚点长在"这个人"身上

李周巍案例：旧版"黑金甲+金瞳+长发"换任何人差异<30%（置换成立=没差异化）；新版"白麟角+白金+碑形"换人就散架（置换不成立=差异化成立）。

### 三把锁与现有方法的衔接

- **锁①剪影签名** → 用 §2 剪影辨识度（图形感/线的语言/姿态目的）做出"唯一轮廓"
- **锁②签名色** → 用 §3 色彩签名（主≤3辅≤2 + 唯一高饱和色）做出"全局唯一主色"
- **锁③记忆锚点** → 用 §4 记忆锚点 + §6 撕裂感，按主角/配角分级定数量

> 一句话：**三把锁是"全局差异化纪律"，§1-§8 是"单角色设计工具箱"。先上锁（定全局唯一位置），再填料（用工具箱做细节）。**

## 1. 角色设计金字塔（三层，逐层递进）

对应"第一眼→第二眼→第三眼"的观看节奏。**低层错了，高层永无翻盘。**

| 层级 | 观看距离 | 承担任务 | 判断标准 |
|:-----|:---------|:---------|:---------|
| **① 剪影层** | 最远（缩略图/远景/背光） | 0.3秒认出"是谁" | 闭眼能不能凭轮廓认出角色 |
| **② 色彩层** | 中景 | 区分对手/阵营、暗示情绪与命运 | 同屏两人能否靠主色块区分 |
| **③ 细节层** | 特写 | 提供信息密度、埋彩蛋 | 凑近看有没有"值得发现"的细节 |

**AI 落地**：提示词必须**显式地把三层各写一段**，每层只给"一个主视觉 + 至多一个辅助"。AI 不会自动分层，你不写，它就铺平。

## 2. 剪影辨识度设计（金字塔底）

### 2.1 图形感——剪影的"表情"
三种基础图形直接决定性格，整体观感取决于占视觉比重最大的图形：

| 图形 | 性格暗示 | 适合 |
|:-----|:---------|:-----|
| 三角形 | 尖锐、速度、攻击性、危险 | 反派/危险角色 |
| 圆形 | 圆润、亲和、友善、安全 | 好人/温和角色 |
| 方形 | 稳定、忠诚、老实、可靠 | 力量型角色 |

> 同一角色多为多图形组合，比重小的图形负责"拨回"。如"圆润主体 + 尖锐头饰/利刃" = 有战斗意志但亲和的好人。

### 2.2 线的语言（内在构成骨架）
- 放射线 → 向外扩张的强悍；水平线 → 开阔宁静；垂直线 → 庄严挺拔；曲线 → 自由灵活；斜线 → 动力与速度

### 2.3 张力与姿态目的——为什么站姿会廉价
- **张力十之八九在剪影阶段就已定死**。标准站姿 = 无张力的"中宫站姿"，等于剪影什么都没说。
- **AI 落地（关键）**：姿态段禁止裸写 `standing`。要写 **"有目的的站姿"**：`slight forward lean, weight on one leg, one hand in pocket, shoulders subtly hunched`（重心偏移、单腿承重、手插兜、微驼背）。**站姿是剪影的一部分，不是空白填充。**

## 3. 色彩签名与叙事（金字塔中）

### 3.1 色彩签名
- 主色 ≤3 + 辅助色 ≤2（与「娓造设计原则」一致）。作用：同屏可区分。
- 色彩签名的核心是**"唯一性"**：全角色唯一的那个高饱和色，才是记忆锚点。

### 3.2 色彩叙事标记
色彩不只是装饰，是**叙事变量**：
- 红色 = 危险/欲望/愤怒；金色 = 神性/上位；黑色/灰 = 压抑/底层/沉默；冷色 vs 暖色 = 阵营/情绪对立。

**关键原则**：色彩的"语义"必须与角色命运绑定，且要**克制**。一个红色元素反复出现 = 记忆锚点；全身上下都是红 = 廉价。

### 3.3 色彩留白（信息克扣的色彩面）
高级角色**敢少用色**。留出"哑区"（低信息、低饱和的大块面），让唯一的高饱和色成为"被迫注意"的焦点。**越克制越高级。**

## 4. 记忆锚点类型（可操作清单）

每个角色至少 1 个"读者 0.3 秒认出"的锚点。锚点不止脸部特征，是多维度任选其一：

| 锚点类型 | 定义 | 例子 |
|:---------|:-----|:-----|
| 面部锚点 | 疤痕/胎记/异色瞳/特殊眼型 | 五条悟六眼、宿傩纹面 |
| 发型锚点 | 反常规轮廓/发色 | 电次电锯头、发梢变色 |
| 道具锚点 | 随身符号物 | 电锯拉索、咒具 |
| 剪影锚点 | 比例/轮廓异常 | 高挑+长披风、矮壮+大肩 |
| 色彩签名锚点 | 全角色唯一的色 | 五条悟白+银发 |
| 姿态锚点 | 习惯性体态 | 苏午驼背+手插兜+疲惫 |
| 表情谱系锚点 | 反常规默认表情 | 见第五节 |

**铁律：宁可锚点夸张到"过"，不可平庸到"无"。** 一个能指认的锚点，胜过十个精致的平均值。

## 5. 反类型化技巧（打破"网感脸"）

反类型化 = 在"符合期待"与"违背期待"之间制造张力，让角色"不是那个你以为的谁"。

### 5.1 表情反类型化
- **默认表情 ≠ 类型化表情**。不要一上来就"微笑/面无表情/邪魅"。让表情带着职业与处境的矛盾。
- 例：疲惫打工人脸上带着"不驯的警惕"（苏午：冷漠/警惕/疲惫/穷困——四个谱系都是"有故事"，而非"帅"）。

### 5.2 反职业/反身份
- 反"标签化"：强迫症医生穿白大褂普通，**强迫症杀手穿白衬衫做事一丝不苟**才是记忆点。
- 反"强者即威严"：能力最强的人日常最松弛（五条悟、电次）。

### 5.3 反完美（直接杀掉"AI 平均值脸"）
- 给"完美"的脸加"瑕疵"：红血丝（疲惫）、细微疤痕、雀斑、肤色不均、不对称眉。
- 提示词句：`slightly asymmetrical features, subtle facial flaws, tired bloodshot eyes`。

### 5.4 反"信息密度"直觉
- 不是越复杂越高级，而是**越克制越高级**。平庸的脸把所有信息一口气给满；高级的脸"只给线索，不给答案"。

## 6. 符号与行为的撕裂感（最有记忆张力的设计）

**这是高质量日漫标杆图的核心，也是"高级"的终极来源。**

**定义**：角色身上有一个承载其命运的视觉符号，但这个符号与角色的日常行为是**冲突的、撕裂的**——于是这个符号在关键页被"引爆"时，才有震撼力。

**机制**：
1. 符号是"潜力"的隐喻，不是"现状"的复读。
2. 符号平时被"藏"，行为上是个普通人/反典型。
3. 符号在命运节点被"撕开"，与日常行为形成炸裂对比。

**经典案例**：
- **电锯人·电次**：日常是贫穷卑微的底层少年，符号是"电锯"——直到濒死时拉下引擎，电锯从头和双臂撕裂而出。符号（暴力）与行为主体（底层小人物）的冲突，才是记忆点来源。
- **咒术回战·五条悟**：符号是"六眼+无下限"，行为却是"轻浮玩世不恭"。最强力量与最松弛态度的撕裂，让他"神性"与"人性"并存。
- **灌篮高手·樱木**：符号是"红发+天才宣言"，行为却是"门外汉、笨拙、犯规王"。

**AI 落地**：把"符号"写进提示词**标志性特征**段，把"行为"写进**姿态/表情**段，让两者在提示词里就构成矛盾。例如苏午：符号 = 腕上祖传的泛黄沉表（表针停2:15），行为 = 疲惫警惕的驼背打工人。AI 生成的不是"一个帅人"，而是"一个戴着命运符号却不肯认命的人"。

## 7. 从原著提取视觉锚点（小说文字 → 视觉符号）

**核心方法：原著不是描述"长什么样"，而是描述"过什么日子"。** 提取锚点要靠"处境/状态/习惯"，而非"外貌形容词"。

### 7.1 五问提取法（每问都从原文找证据）
1. **他靠什么活？**（职业/经济）→ 服装、姿态、物件
2. **他失去了什么？**（创伤/缺憾）→ 面部瑕疵、表情残留
3. **他每天做什么动作？**（习惯性行为）→ 姿态锚点
4. **他此刻最缺什么？**（欲望/困境）→ 表情谱系
5. **他身上的"符号"是什么？**（命运隐喻）→ 道具/印记

### 7.2 二创共识提取
- 对知名角色，先搜"小说名+角色名+漫画/插画/二创"，提取多来源一致的视觉特征 = 读者共同记忆。与原文冲突时以原文为准，标注差异。

### 7.3 苏午案例（反面教训 → 正面示范）
- **错**：把苏午塑造成"国产乙游男主"（帅、精致、无缺憾）——浪费了原文"父母双亡、独居、打零工、疲惫警惕"的处境。
- **对**：把"帅"换成"有故事"——注入 6 个忠于原著的锚点：面部（红血丝/疲惫）、主视觉符号（破旧外套/旧工牌/泛黄沉表）、剪影（偏瘦/驼背）、色彩签名（低饱和灰+暗）、表情谱系（冷漠/警惕/疲惫/穷困）、姿态习惯（手插兜/重心偏）。

## 8. 如何写成高质量 AI 生图提示词

> 对齐 `oc-design-guide.md` 高精度模板（4块结构）+ 七维度规格表 + 冻结提示词机制。本方法论在现有模板里**新增"三层 + 反类型化 + 撕裂感"三个字段**，让立绘从"正确"升级为"有记忆"。

### 8.1 提示词组装公式（在现有高精度模板基础上增强）

```
[所选基准定妆照画风串 + 题材配色]

CHARACTER DESIGN SHEET, FRONT VIEW, HIGH-PRECISION:
A {年龄} {性别} with {体型}. {发型发色}, {瞳色眼型}, {脸型} face with {面部特征(含瑕疵/红血丝)}.
Wearing {服装分层描述}. {标志性特征/命运符号}. {反类型化表情谱系}.

SILHOUETTE: {剪影层——体型张力+姿态目的，如"lean build, slight forward hunch, weight on one leg, one hand in pocket"}
COLOR SIGNATURE: {色彩层——主色≤3+辅助≤2+唯一高饱和色，如"muted gray palette, single faded red band as the only accent"}
DETAIL: {细节层——信息克扣，只给1-2个彩蛋，如"worn frayed collar, old worker badge"}

COMPOSITION / LIGHTING / TEXTURE / 硬约束: [沿用现有4块高精度模板]
Exactly one character. No duplicated limbs. No chibi. No text. No cheap plastic skin. No generic anime face. No perfect symmetry.
```

### 8.2 反廉价感负面约束（新增，针对"网感脸+平均值"）
```
No generic anime face. No perfect model face. No plastic skin. No symmetrical idealized features.
No flat idle standing pose. No cheap default streetwear (unless that's the deliberate anchor).
```

### 8.3 三条落地铁律
1. **每个锚点都要有"为什么"**：提示词里每个视觉元素，都要能回答"这个元素为什么必须是这个样子的"。写不出原因的元素，删掉。
2. **必须显式写"偏科"**：AI 默认给你平均值，你要写 `lean build`、`subtle asymmetry`、`tired bloodshot eyes` 这类"偏离均值"的词。
3. **冻结 + 版本化**：定妆图生成后提示词原文冻结到美术设定集，后续章节直接引用冻结版，杜绝漂移。
