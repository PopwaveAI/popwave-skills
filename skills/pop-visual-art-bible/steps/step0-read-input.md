# Step 0: 读输入 + 档位规划

> 产出美术设定集前，先吃透两个引擎的输入：asset 原文资产（这个世界有什么）+ style 画风（用什么画）。**缺一不可。** 再按 intent 定档位，决定设定集点亮哪几篇。

## 0. 前提校验

| 检查项 | 缺失处理 |
|:-------|:---------|
| asset 原文资产存在 | 缺失 → 提示用户先跑 `pop-visual-asset` 提取（角色档案/场景资产表/视觉符号库），或告知本 skill 内部可做 5 轮原文采样（见 §1） |
| 画风已定 | 缺失 → 从 `pop-visual-style` 画风DNA库按赛道选基准，或先跑 `pop-visual-style` 定标 |

## 1. 读 asset 原文资产（这个世界有什么）

- 路径：`素材/视觉资产/`（`pop-visual-asset` 产出）
  - `[角色名]角色档案.md`（10维度）——人物篇证据
  - `场景资产表.md`（可定格帧清单）——场景篇证据
  - `视觉符号库.md`（核心意象/标志色/器物/阵营符号）——符号篇证据
  - `IP视觉DNA.md`（同人时）——IP 视觉事实证据
  - `[势力名]势力档案.md`（8维度）——势力篇证据
  - `[地名]地理档案.md`（7维度）——地理篇证据
  - `[规则名]规则档案.md`（6维度）——规则篇证据
- 角色档案重点读：维度一 角色概览、维度二 外貌演变、维度五 成长弧线、维度八 矛盾暗面、维度十 核心意象与符号
- 势力档案重点读：二 人群画像、三 美学基调、四 象征体系
- 地理档案重点读：二 空间质感、三 氛围基调、四 标志性地标
- 规则档案重点读：二 视觉外显、三 层级可视化、四 器物载体
- 资产缺失时，本 skill 内部执行原文采样（5 轮关键词搜索 + 上下文采样），补齐后继续

## 2. 读 style 画风（用什么画）

- 路径：`素材/风格/画风决策.md`（定标后可读）+ `skills/pop-visual-style/references/文风DNA-library.json`
- 取 `dna` + `constraint` + `recommended_lighting` + `recommended_composition` 四字段
- 画风决定**美术语言**（厚涂/赛璐璐/暗黑高对比），但不决定**视觉事实用色**（色彩基调的仲裁是本 skill 的活）
- 画风已冻结（`✅ 已认可`）时，直接引用冻结版画风 + 定标图 + seed

## 3. 读已有美术设定集（升级模式）

- 路径：`素材/美术设定集.md`
- 存在 → 升级模式：在原有设定集上做增量（新增角色/换装/受伤/觉醒/新场景/新符号/改画风），**反类型化和撕裂感一旦建立就保持**
- 不存在 → 新建模式：走 Step 1 完整设计

## 4. 档位规划（按 intent）

> 决定"点亮哪几篇、复现多深"。**不默认全量。**

| intent | 点亮篇章 | 复现深度 |
|:-------|:---------|:---------|
| `cover` | 画风篇 + 场景篇（局部）+ 封面相关人物篇 | 单张场景/人物参考图（可选） |
| `oc` | 画风篇 + 人物篇 | 单张人物定妆图（可选） |
| `comic` | 画风篇 + 人物篇 + 场景篇 + 符号篇 | 完整复现（人物双角度+场景定妆） |
| `world` | 画风篇 + 势力篇 + 地理篇 + 规则篇（世界观推广素材） | 势力/地理/规则示例图（可选） |
| `full` | 全部八篇 | 完整复现 |
| `asset-only` | 不进入本 skill | — |

> 独立模式（不在 pipeline 语境）时，按用户当次意图判定，规则一致。

## 5. 产出

- 确认输入就绪，进入 Step 1 设计美术设定集
