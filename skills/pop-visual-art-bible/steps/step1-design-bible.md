# Step 1: 设计美术设定集

> 核心步骤。产出 `素材/美术设定集.md`（画风/人物/场景/视觉符号/势力/地理/规则/一致性复现八篇合一，文+图）。
>
> **设计顺序铁律：先"全局上锁"（画风基调→人物差异化→场景/符号），再"单实体填料"（用工具箱做细节）。** 设计第一个实体前，必须先想它在全书视觉里的差异化位置，否则视觉就是"属性堆砌"，跨形态漂移。
>
> **必读**：`references/advanced-character-design.md`（人物篇方法论）+ `references/bible-arbitration-guide.md`（一致性仲裁）。

## 1. 画风篇（引用 style，定全宇宙色彩基调）

- 引用 `pop-visual-style` 的冻结画风：`dna` + `constraint` + `recommended_lighting` + `recommended_composition`
- 引用画风决策 + 定标图 + seed + 参考图路径
- 定**全宇宙色彩基调**：从画风DNA推导主色板（≤3主色 + 辅助色），作为场景/人物/符号的用色上限
- 色彩基调是**仲裁准绳**：后续人物签名色/场景主色/符号色都不得超出基调，撞色即废

## 2. 人物篇（保留原 character 全套方法论）

> **必读 `references/advanced-character-design.md`**（三把锁差异化纪律/角色设计金字塔/反类型化/撕裂感/五问提取法）。

### 2.0 🚪 实体覆盖门禁（先确定"有哪些角色可设计"，再动笔）

> 人物篇的**设计范围 = asset 角色档案覆盖范围**。没有档案的角色，禁止本 skill 自行虚构视觉事实。

- **列出 asset 提供的角色档案清单**：读 `素材/视觉资产/`，列出所有 `[角色名]角色档案.md`（或 `[角色名]视觉身份卡.md`）。
- 人物篇**只为清单内的角色**设计视觉身份；清单外角色不出现在人物篇，也不出现在一致性互查表。
- 若某角色是剧情重要实体但 asset 无档案（如金翅鸟煞/配角）：
  - cover/oc 档 → 在主角的"符号/撕裂感"里锚定即可，不单独立角色；
  - comic/full 档 → **先回 `pop-visual-asset` 补该角色档案**，再进本步设计，禁止跳过档案直接画。
- **记录依据**：每个角色设计完后，在人物篇标注其视觉事实来源（角色档案维度/行号），确保铁律 ❌1 可反查。

### 2.1 三把锁差异化纪律（全局先行，先于单角色设计）

| 锁 | 约束 | 判据 |
|:--|:-----|:-----|
| **① 剪影签名** | 一人一个**可辨认的轮廓签名**，全局唯一 | 十米外只看剪影能喊出名字；同书角色互比剪影不撞 |
| **② 签名色** | 一人一个**全局唯一主色**，不超色彩基调 | 同屏两角色不撞色；撞色即废 |
| **③ 记忆锚点** | 主角可多锚点组合，配角**只给1个** | 见下"记忆锚点分级" |

**记忆锚点分级**：主角/重要角色 2-3 个锚点组合（统一指向同一核心人设）；配角/路人 1 个锚点（宁缺毋滥）。**记忆锚点数量 = 角色重要度。**

**置换测试**：把角色A的剪影/签名色/锚点换成角色B，画面还成立吗？成立=未差异化，回炉。

### 2.2 五问提取法（从原著处境提取视觉锚点）

**核心：原著不是描述"长什么样"，而是描述"过什么日子"。** 每问都从角色档案/原文找证据，不靠外貌形容词。

| 问 | 提取什么 | 落到视觉 |
|:---|:---------|:---------|
| 1. 他靠什么活？ | 职业/经济 | 服装、姿态、物件 |
| 2. 他失去了什么？ | 创伤/缺憾 | 面部瑕疵、表情残留 |
| 3. 他每天做什么动作？ | 习惯性行为 | 姿态锚点 |
| 4. 他此刻最缺什么？ | 欲望/困境 | 表情谱系 |
| 5. 他身上的"符号"是什么？ | 命运隐喻 | 道具/印记 |

### 2.3 角色设计金字塔（三层逐层递进）

| 层 | 观看距离 | 承担任务 |
|:---|:---------|:---------|
| ① 剪影层 | 最远 | 0.3秒认出"是谁" |
| ② 色彩层 | 中景 | 区分对手/阵营、暗示命运 |
| ③ 细节层 | 特写 | 信息密度、埋彩蛋 |

**AI 落地**：提示词必须显式把三层各写一段，每层只给"一个主视觉 + 至多一个辅助"。

### 2.4 反类型化 + 撕裂感

- **反类型化**：表情/职业/完美/信息密度四维反"网感脸"，打破 AI 平均值
- **撕裂感**：符号（潜力隐喻）与行为（日常）冲突，在命运节点被撕开
- 每角色产出：三把锁 + 七维度规格表 + 三级金字塔 + 记忆锚点 + 反类型化 + 撕裂感 + **视觉锚点串（英文）+ 冻结提示词（英文）**

> 人物篇可拆用 `templates/visual-identity-card.tpl.md` 结构，但内容必须并入美术设定集人物篇。

## 3. 场景篇（从 asset 场景资产表翻译成画面）

- 读 `素材/视觉资产/场景资产表.md`，取可定格帧清单
- **每关键场景翻译成画面**（场景形象）：
  | 字段 | 内容 |
  |:-----|:-----|
  | 场景意象 | 这个场景"是什么感觉"（1句话） |
  | 氛围基调 | 光/影/色彩/情绪（符合色彩基调） |
  | 构图骨架 | 主视觉焦点 + 层次（符合画风构图模板） |
  | 可定格帧 | 原著可定格瞬间（引原文行号） |
  | 冻结提示词 | 英文，供下游复用 |
- 场景只做"关键场景"（能承载剧情升降/名场面的），不穷举

## 4. 符号篇（从 asset 视觉符号库整理）

- 读 `素材/视觉资产/视觉符号库.md`，取核心意象/标志色/器物/阵营符号
- **每符号整理成**：符号含义（叙事功能）+ 视觉形态（配合画风）+ 使用场景 + 冻结提示词
- 符号色必须符合色彩基调，作为人物/场景的"彩蛋层"复用

## 4.5 三篇实体覆盖门禁（势力/地理/规则，先确定"有哪些可设计"再动笔）

> 与人物篇 §2.0 同源铁律：**势力/地理/规则篇的设计范围 = asset 对应档案覆盖范围**。没有档案的势力/地理/规则，禁止本 skill 自行虚构视觉事实。

- **列出 asset 提供的档案清单**：读 `素材/视觉资产/`，列出所有 `[势力]势力档案.md` / `[地名]地理档案.md` / `[规则]规则档案.md`。
- 势力/地理/规则篇**只为清单内的实体**设计视觉；清单外实体不出现。
- **记录依据**：每个实体设计完后，标注其视觉事实来源（档案维度/行号），确保铁律 ❌1 可反查。
- 若某势力/地理/规则是剧情重要实体但 asset 无档案 → **先回 `pop-visual-asset` 补档案**，再进本步设计，禁止跳过档案直接画。

## 5. 势力篇（从 asset 势力档案翻译成"阵营视觉"）

- 读 `素材/视觉资产/[势力]势力档案.md`，取阵营美学/象征体系/人群画像/等级秩序
- **每势力翻译成"阵营视觉身份"**：
  | 字段 | 内容 |
  |:-----|:-----|
  | 势力定位 | 这个势力"是什么"（1句话） |
  | 核心气质 | 这个势力给人的感觉（如肃杀铁律/超然出尘） |
  | 阵营美学 | 标志色/纹饰/建筑/器物风格（符合色彩基调） |
  | 象征体系 | 旗帜/纹章/族徽/图腾（关联符号篇） |
  | 等级秩序 | 阶层划分的视觉外显（服饰差异/地位标识） |
  | 冻结提示词 | 英文，供下游势力卡渲染 |
- 势力美学必须**与人物签名色互查**：同阵营人物用色归拢到势力基调下，跨势力不撞
- 势力只做"主线势力/关键势力"（能承载阵营冲突的），不穷举

## 6. 地理篇（从 asset 地理档案翻译成"空间视觉"）

- 读 `素材/视觉资产/[地名]地理档案.md`，取空间质感/氛围基调/标志性地标/生灵种族
- **每地理/小世界翻译成"空间视觉设计"**：
  | 字段 | 内容 |
  |:-----|:-----|
  | 地理意象 | 这个地方"是什么感觉"（1句话） |
  | 空间质感 | 材质/地形/建筑/植被/气候 |
  | 氛围基调 | 光线/色彩/温度/声音/情绪（符合色彩基调） |
  | 构图骨架 | 主视觉焦点 + 层次（符合画风构图模板） |
  | 标志性地标 | 3-5个可定格节点（关联场景篇） |
  | 冻结提示词 | 英文，供下游地理卡渲染 |
- 地理氛围必须**与场景篇互查**：同一地理内的关键场景，氛围基调要归拢一致
- 地理只做"关键小世界/城市/秘境"（有独特空间质感的），不穷举

## 7. 规则篇（从 asset 规则档案设计"抽象规则可视化"）

> 抽象规则最难画，**必须从原文已有的视觉外显提取具象载体**，禁止凭空发明符号。

- 读 `素材/视觉资产/[规则]规则档案.md`，取视觉外显/层级可视化/器物载体
- **每规则/体系设计"可视化策略"**：
  | 字段 | 内容 |
  |:-----|:-----|
  | 规则内涵 | 这个抽象规则"是什么"（1句话） |
  | 可视化策略 | 如何把抽象变成画面（符号/光影/器物/天象载体） |
  | 视觉外显 | 规则表现时的光效/纹路/天象/异象（引原文行号） |
  | 层级可视化 | 各境界/层级突破时的不同视觉奇观 |
  | 器物载体 | 承载规则的具象器物/符号（关联符号篇） |
  | 冻结提示词 | 英文，供下游规则卡渲染 |
- 规则可视化必须**有原文依据**：视觉外显来自档案行号，禁止凭空发明规则符号
- 规则只做"主线体系/核心规则"（决定全书力量观/世界观的），不穷举

## 8. 一致性仲裁（必做，见 `references/bible-arbitration-guide.md`）

> **互查对象 = 人物篇实际产出的角色**（即 asset 档案覆盖的角色）。**角色数 < 2 时，只放单行 + 标注"待 asset 补配角档案后互查"，禁止虚构配角填充互查表。**

- **三把锁全局互查**：全角色剪影/签名色/记忆锚点互比，确保无撞
- **跨实体冲突裁决**：人物签名色 vs 场景主色 vs 符号色 vs 势力阵营色 → 撞色即回炉，以色彩基调为准绳
  - 势力阵营色归拢麾下人物用色；地理氛围归拢场内场景调性；规则外显色复用符号层
- **画风一致**：人物/场景/势力/地理/规则的冻结提示词都基于同一画风，不停发明新画风
- 输出三把锁全局差异化表 + 仲裁记录
- **覆盖校验**：互查表角色数 = 人物篇角色数；若表内出现人物篇之外的伪角色，即虚构，回炉

## 9. 产出美术设定集

用 `templates/art-bible.tpl.md` 模板，填充八篇合一：

| 篇 | 内容 |
|:--|:--|
| 一 画风篇 | 画风DNA + 画风决策 + 定标图 + seed + 色彩基调 |
| 二 人物篇 | 每角色：三把锁 + 七维度 + 三级金字塔 + 锚点 + 反类型化 + 撕裂感 + 冻结提示词 + 定妆图路径 |
| 三 场景篇 | 每关键场景：意象/氛围/构图/可定格帧 + 冻结提示词 + 场景图路径 |
| 四 符号篇 | 每符号：含义/形态/使用场景 + 冻结提示词 |
| 五 势力篇 | 每势力：定位/气质/阵营美学/象征体系 + 冻结提示词 + 示例图路径 |
| 六 地理篇 | 每地理：意象/空间质感/氛围/构图 + 冻结提示词 + 示例图路径 |
| 七 规则篇 | 每规则：内涵/可视化策略/视觉外显 + 冻结提示词 + 示例图路径 |
| 八 一致性复现 | 三把锁全局差异化表 + 仲裁记录 + 复现资产索引（seed/参考图/冻结提示词/定妆图路径）+ 版本 |

## 10. 设计自检

- [ ] 画风是引用 style 冻结，未发明新画风
- [ ] 色彩基调已定，人物/场景/符号用色不超基调
- [ ] 人物三把锁全局唯一，同书不撞，通过置换测试
- [ ] **人物篇角色数 = asset 档案清单角色数；无档案角色未进入人物篇/互查表（无虚构配角）**
- [ ] **角色数 <2 时一致性互查表仅单行 + 标注待补，未虚构填充**
- [ ] 记忆锚点按重要度分级（主角2-3个组合/配角1个）
- [ ] 每个锚点都有"为什么"（写不出原因的元素删掉）
- [ ] 显式写了"偏科"（偏离均值，非平均值脸/标准场景）
- [ ] 场景/符号形象来自 asset 原文提取，非凭空捏造
- [ ] **势力/地理/规则篇范围 = asset 对应档案清单范围；无档案实体未进入对应篇（无虚构势力/地理/规则）**
- [ ] **势力阵营色归拢麾下人物，地理氛围归拢场内场景，规则外显色复用符号层，均不超色彩基调**
- [ ] **规则可视化有原文视觉外显依据（引档案行号），未凭空发明规则符号**
- [ ] 有撕裂感（符号 vs 行为冲突）
- [ ] 一致性仲裁已做，无撞色/撞剪影
