# Step 2: 确认 + 落盘 + 冻结

> 美术设定集是基建真源，落盘前必须确认，落盘冻结后下游才能消费。

## 1. 🚪 门禁：美术设定集确认

向用户呈现美术设定集摘要，确认：

- [ ] 画风是引用 style 冻结（无发明）
- [ ] 人物有辨识度（0.3秒能认出）+ 忠于原著处境 + 有锚点/撕裂感/反类型化
- [ ] 场景/符号形象来自 asset 原文（非凭空捏造）
- [ ] 一致性仲裁已做（无撞色/撞剪影）
- [ ] 色彩基调统一

**未确认不落盘冻结。** 用户提出修改 → 回到 Step 1 调整对应篇章。

## 2. 落盘

- 路径：`素材/美术设定集.md`
- 首次 → 新建文件
- 已有 → 升级版本（版本号递增，保留变更记录到"五、一致性复现·版本"）

## 3. 冻结为基线资产

用户认可后，把美术设定集**冻结为基线资产**，这是全 IP 宇宙视觉准绳：

- `素材/美术设定集.md` 标注 `签核状态: ✅ 已认可`
- 记录复现资产生成状态（未生成则提示进入 Step 3）

## 4. 通知下游

落盘冻结后，告知用户美术设定集已就绪，可被以下消费：

| 消费方 | 触发方式 | 消费什么 |
|:-------|:---------|:---------|
| `pop-visual-oc` | "做 OC/立绘" | 人物篇 + 定妆图 |
| `pop-visual-comic` | "做漫画/定妆照" | 全篇（画风/人物/场景/符号） |
| `pop-visual-cover` | "做封面/场景图" | 画风篇 + 场景篇 + 人物篇 |
| `pop-comic-content` | "出漫剧/放映/物料" | 全篇 |

> **铁律**：下游只改渲染格式，不改视觉事实（人物/场景/符号/画风）。任何视觉事实改动必须回到本 skill 升级美术设定集版本。
