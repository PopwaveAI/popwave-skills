# Step 3: 复现资产生成（按 intent 档位分支）

> 美术设定集是"看得见的文字"，但视觉到底成立不成立，只有渲染成图才能验证。本步用**冻结画风 + 设定集冻结提示词**渲染复现资产（人物定妆图/场景定妆图/符号示例图），让设定集第一次被眼睛看到。用户认可后**冻结美术设定集为基线资产**。未认可不冻结、不放行下游。

## 何时用（按 intent 档位分支）

- 本 skill 只做设定集（不渲染）：**跳过本步**（Step 0→1→2 出美术设定集即完成）。
- **Pipeline 语境下（Phase 2 产出美术设定集）**，按 `视觉项目总控.html` 的 `intent` 档位分支：
  - `comic`/`full` → **完整复现（必做）**：人物**正/侧双角度**定妆图 + 关键场景定妆图，走完整门禁，进入下游前先复现。
  - `cover`/`oc` → **轻量复现（可选）**：基建到美术设定集（Step 0→1→2）即可派生，**不强制双角度**；如需封面/OC 参考图渲染单张，agent 自查达标标 `✅ 已认可`。
- > Pipeline 未建总控（独立模式）时，按用户当次意图判定：明确做漫画/连载 → 完整档；做封面/OC → 轻量档。

## 核心原则：视觉事实不变，只验证渲染

复现图是**美术设定集的可视化验证**，不是出新视觉事实。它验证的是"这个宇宙到底长什么样"的设计在大图上是否成立。

**复现图不达标 → 回设定集升级版本（改视觉事实），禁止在渲染层硬凑。**

## 复现图 = 纯生产参考图（非展示作品）

复现图是**给下游做图生图参考的纯净素材**，不是给读者看的展示图。因此：

- **禁止**出现任何文字（角色名/称号/题诗/书法大字/钤印）
- **禁止**叠加任何装饰元素（边框/印章/纹样/排版线）
- **禁止**叠加任何文化元素（背景文字/铭文/道具特殊文字）
- 只需纯净视觉本体：角色/场景/符号居中，标准姿态/视角，干净背景，聚焦"长什么样"

> 与 `pop-visual-oc` 的**立绘OC**严格区分：立绘OC是带文字+文化元素的展示作品，复现图是纯净生产参考。

## 1. 读输入

- 读美术设定集 `素材/美术设定集.md`，取各篇**冻结提示词**（英文，API 读）
- 读画风基线 `素材/风格/画风决策.md`，取画风三字段 + 定标图 + seed（同款画风渲染，保证画风一致）

## 2. 组装复现提示词

读取 `../pop-visual-shared/references/seedream-prompt-guide.md` 的 6 段式结构，画风 DNA 放第 2 段：

```
[质量触发词] + Art style: [dna] [constraint] + [构图策略] + [光影叙事] + [设定集冻结提示词] + [标准视角/姿态]
```

- 人物段：用美术设定集人物篇**冻结提示词**（含三层 + 反类型化 + 撕裂感）
- 场景段：用场景篇冻结提示词（意象/氛围/构图骨架）
- 构图/光照：用画风基线的 `recommended_composition` + `recommended_lighting`
- **硬约束**：追加 `no text, no letters, no characters, no watermark, no decorative elements, no border, no seal`，确保产出纯净复现图

## 3. 生成复现图

> 生图统一走 `image_generate` 工具，不直连 API（无内置 API Key）。

```text
人物定妆：image_generate(prompt='人物冻结提示词', size='1125x1500', ref_image='画风定标图', output='素材/视觉/角色定妆-{角色名}-v1.png')
场景定妆：image_generate(prompt='场景冻结提示词', size='1500x1125', ref_image='画风定标图', output='素材/视觉/场景定妆-{场景名}-v1.png')
```

> 可传画风定标图作参考（图生图），保证画风与定标一致。

## 4. 🚪 门禁：复现验收

向用户呈现复现图，逐项验收：

| 维度 | 验收判据 |
|:-----|:---------|
| 人物剪影层 | 0.3 秒能否凭轮廓认出"是他" |
| 色彩签名 | 主色块能否区分阵营/暗示命运，不超色彩基调 |
| 记忆锚点 | 那个"0.3 秒认出"的锚点是否真的被画出来了 |
| 反类型化/撕裂感 | 是否打破网感脸，是否有"状态感"而非"摆拍感" |
| 场景意象 | 场景是否传达出"这个场景是什么感觉" |
| 画风一致 | 与画风定标图是否同款画风（无漂移） |

**未达标不冻结。** 回设定集升级版本（改视觉事实），重新渲染 v2、v3... 直到达标。

## 5. 认可 → 冻结美术设定集基线资产

用户认可后，把美术设定集**冻结为基线资产**，这是全 IP 宇宙视觉准绳：

- `素材/美术设定集.md` 标注 `签核状态: ✅ 已认可`
- 记录复现图路径到设定集"五、一致性复现·复现资产索引"，作为下游 oc/comic/cover 的**参考图**（图生图 image 参数传第一张）

## 6. 通知下游

告知用户美术设定集 + 复现图已就绪，可被以下消费：

| 消费方 | 用途 |
|:-------|:-----|
| `pop-visual-oc` | 取人物篇 + 定妆图作为立绘角色本体参考 |
| `pop-visual-comic` | 取全篇 + 定妆图（`ref_images` 传第一张） |
| `pop-visual-cover` | 取画风/场景/人物作为封面钩子视觉依据 |

> **铁律**：美术设定集基线一旦冻结，下游只消费它，只改渲染格式、不改视觉事实。任何视觉事实改动必须回到本 skill 升级设定集版本。
