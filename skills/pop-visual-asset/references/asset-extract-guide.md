# 资产提取方法论

> 本文件定义四种资产产出的提取方法论。asset skill 执行提取时必读。

---

## §一 角色档案（10维度）

> **方法论唯一权威源**：`../pop-visual-shared/references/character-research-guide.md`（与 pop-visual-oc 共用，禁止本地重建副本）。
> 本文件 §一 仅保留 asset 特有的提取要点，10维度模板与五轮搜索沿用共享权威源。

### 核心理念

**角色调研不是"找外貌描写"，是"理解一个人"。**

角色立体化的三个层次：

| 层次 | 采集内容 | 比喻 | 没有的后果 |
|:-----|:---------|:-----|:---------|
| 表层 | 外貌描写（发色/眼瞳/服饰/体型） | 画皮 | 没有视觉特征 |
| 中层 | 性格特征+行为模式+说话方式 | 画骨 | 有特征但没性格 |
| 深层 | 他人评价+矛盾暗面+成长弧线 | 画魂 | 有性格但没灵魂 |

### asset 特有提取要点

- **五轮搜索 + 10维度模板 + 采样质量自检**：见共享权威源 `../pop-visual-shared/references/character-research-guide.md`
- **原文行号索引**：每条提取信息必须标注原文行号（asset 铁律 ❌2）
- **写作专家项目辅助**：已有 `设计/角色库/角色库.md` 时读取作为维度一/三辅助参考，但仍需从正文采样原文佐证
- **增量更新**：只追加新章节发现的外貌/成长/评价/金句，不覆盖已有内容，更新文件头部"采样范围"标记

### 10维度一览（结构对齐共享权威源）

| 维度 | 内容 |
|:-----|:-----|
| 一、角色概览 | 姓名/道号/称号/兵器/功法/命格/核心气质 |
| 二、外貌演变 | 按年龄阶段记录外貌变化（含行号） |
| 三、性格特征 | 5-7个性格侧面+原文佐证 |
| 四、人际关系 | 与3-5个关键人物的互动模式 |
| 五、成长弧线 | 6-8个成长阶段（事件+变化） |
| 六、金句语录 | 5-10句标志性台词（按主题分类） |
| 七、他人评价 | 旁人/长辈/敌人/龙属的评价（分类） |
| 八、矛盾与暗面 | 角色的复杂性、阴暗面、非人感 |
| 九、视觉设计参考 | 3-8个最适合做OC的关键场景与形象 |
| 十、核心意象与符号 | 贯穿全文的视觉符号（3-7个） |

> 每维度的详细模板与示例见共享权威源。

## §二 场景资产表

### 核心理念

场景资产表是"可定格帧清单"——把小说中的连续叙事拆解成一个个可绘制的画面瞬间。

### 提取流程

#### 1. 场景定位

用 Grep 搜索场景转换标志词：

| 搜索目的 | 关键词模板 |
|:---------|:---------|
| 场景转换 | `到了\|进入\|来到\|站在\|眼前\|远处` |
| 视觉密集段落 | 颜色词+器物词+动作词共现 |
| 情感峰值 | `怒\|笑\|哭\|吼\|颤\|惊` |
| 战斗场景 | `刺\|劈\|斩\|挡\|闪\|攻` |

#### 2. 帧拆解

每个关键场景拆解为帧：

| 字段 | 内容 |
|:-----|:-----|
| 帧编号 | F001, F002, ... |
| 章节位置 | ch005, ch012, ... |
| 场景名 | 一句话概括 |
| 参与角色 | 出场角色列表 |
| 视觉元素清单 | 环境/器物/光影/特效 |
| 氛围基调 | 情绪/色调/空气感 |
| 叙事含义 | 这帧在讲什么 |
| 行号范围 | 原文行号 |

#### 3. 帧评估

| 评估维度 | 评分 | 说明 |
|:---------|:-----|:-----|
| 视觉张力 | 1-5 | 画面构图潜力 |
| 叙事含量 | 1-5 | 承载的故事信息量 |
| 情感共鸣 | 1-5 | 读者想"看到"的程度 |

> 优先保留视觉张力≥3 且 叙事含量≥3 的帧。

### 帧选取原则

选帧不是选"最好看的画面"，是选**最能传达这段文字核心体验的瞬间**：

| 选取依据 | 说明 |
|:---------|:-----|
| 动作交接点 | 前一动作刚完成、后一动作将开始，视觉张力最强 |
| 情感峰值 | 这段文字的情感最高点 |
| 叙事关键 | 承载最核心叙事信息的帧 |
| 读者共鸣 | 读者读到这里最想"看到"的画面 |

## §三 视觉符号库

### 核心理念

视觉符号库是"这本书的视觉DNA"——贯穿全文、反复出现的视觉元素。

### 提取维度

#### 1. 核心意象

角色或世界观中反复出现的标志性视觉元素：

| 搜索方式 | Grep 关键词 | 提取内容 |
|:---------|:---------|:---------|
| 角色标志 | `[角色名].*(眸\|眼\|甲\|袍\|发\|兵器)` | 角色标志性外观 |
| 世界观标志 | `(灵气\|法力\|神通\|阵法)` | 力量体系视觉外显 |

#### 2. 标志色

全文反复出现的色彩：

| 色彩 | 出现频率 | 关联对象 | 视觉含义 |
|:-----|:---------|:---------|:---------|
| 暗金色 | 贯穿全文 | 眸子/甲衣/权柄 | 白麟命格/帝王之权 |
| 浅紫色 | 封王后 | 王氅羽色末端 | 权位象征 |

#### 3. 标志器物

反复出现的关键道具：

| 器物 | 首次出现 | 视觉描述 | 叙事功能 |
|:-----|:---------|:---------|:---------|
| 大昇长戟 | 幼年选兵器 | 深金色古筑基法器 | 武力象征 |
| 王钺 | 封王后 | 棕黄蕴银光，麟兽纹 | 明阳权柄 |

#### 4. 阵营符号

势力/组织的视觉标识：

| 阵营 | 标识 | 视觉描述 |
|:-----|:-----|:---------|
| 李家 | 旗帜/纹章 | [从原文提取] |
| 宋帝 | 帝袍/空袍胄甲 | [从原文提取] |

### 写作专家项目辅助

如有 `设计/力量体系.md`，读取力量体系中的视觉外显描述：
- 力量体系 → 视觉外显（如"明阳之道→金色光芒"）
- 阶层体系 → 视觉差异（如"筑基期vs紫府期的视觉差异"）
- 功法体系 → 视觉效果（如不同功法的不同光影表现）

## §四 IP视觉DNA（同人/改编时）

### 核心理念

同人小说的视觉设计必须锚定或有意偏离源IP的视觉DNA。asset skill 在同人判定后提取源IP视觉特征，供消费 skill 参考。

### 提取流程

#### 1. 源IP识别

从以下信号识别源IP：
- 书名包含已知IP名（如"海贼法典"→海贼王）
- 角色名来自已知IP（如"摩根·威廉"→One Piece OC）
- 世界观术语来自已知IP（如"恶魔果实""霸气"→海贼王）

#### 2. WebSearch 搜索

| 搜索目标 | 关键词模板 |
|:---------|:---------|
| 源IP画风 | `[源IP名] official art style character design` |
| 角色经典形象 | `[源IP名] character official art` |
| 世界观视觉符号 | `[源IP名] visual symbols world building` |
| 标志色 | `[源IP名] color palette art direction` |

#### 3. 4维度DNA整理

| 维度 | 提取内容 | 示例（海贼王） |
|:-----|:---------|:-------------|
| 源IP画风 | 笔触/比例/色彩倾向 | 尾田画风：男性棱角分明、夸张体态、热带高饱和 |
| 角色经典形象 | 原著角色标志性外观 | 路飞：草帽+红背心+疤痕+橡胶体 |
| 世界观视觉符号 | 原作反复出现的视觉元素 | 海贼旗、恶魔果实纹路、伟大航路 |
| 标志色 | 原作主色调 | 蓝色（大海）、红色（草帽团）、金色（财宝） |

#### 4. 设计方向建议

在IP视觉DNA文件末尾，给出设计方向建议：

```
## 设计方向建议

- 锚定元素：[哪些源IP视觉元素应该保留]
  - 理由：[为什么这些元素对同人读者很重要]

- 偏离元素：[哪些源IP视觉元素可以有意偏离]
  - 理由：[为什么偏离能产生差异化]

- 融合建议：[如何将源IP视觉DNA与本作独特风格融合]
```

> 这只是建议，最终设计决策由消费 skill 和用户在门禁环节确定。

## §五 势力档案

> 网文势力/阵营/宗门/家族/王朝等多是可视化推广素材（势力卡）的视觉真源。本类档案从原文提取"一个势力看起来是什么样"，供 art-bible 势力篇翻译成画面。

### 核心理念

势力视觉不是"画一个标志"，是提取**这个势力占哪种视觉生态位**——它的人群、规矩、审美、象征，共同构成可辨识的阵营美学。

### 提取流程

#### 1. 势力定位搜索

| 搜索维度 | Grep 关键词模板 | 提取内容 |
|:---------|:---------------|:---------|
| 势力名 | `[势力名]` | 所有出场段落 |
| 归属 | `[势力名].*(宗门\|家族\|王朝\|教派\|阵营)` | 势力性质 |
| 人群 | `[势力名].*(弟子\|族人\|信众\|军士\|百姓)` | 势力人群构成 |
| 地标 | `[势力名].*(峰\|城\|宫\|殿\|谷\|坛)` | 势力主场地理 |

#### 2. 势力档案整理

| 维度 | 内容 |
|:-----|:-----|
| 一、势力概览 | 名称/性质/规模/历史沿革/核心气质 |
| 二、人群画像 | 服饰/面貌/气质/普遍行为（含行号） |
| 三、美学基调 | 标志色/纹饰/建筑风格/器物风格（含行号） |
| 四、象征体系 | 旗帜/纹章/族徽/图腾/口号（含行号） |
| 五、等级秩序 | 阶层划分/服饰差异/地位外显（含行号） |
| 六、主导者 | 领袖/代表人物的视觉特征（关联角色档案） |
| 七、视觉设计参考 | 3-5个最适合做势力卡的场景与形象 |
| 八、与主角关系 | 敌/友/中立/被征服，影响势力卡情感基调 |

> 势力档案只在原文有明确描述时提取，禁止凭刻板印象虚构势力美学。

## §六 地理档案

> 网文地理/城市/小世界/位面/秘境常是推广素材（世界观地理卡）的视觉真源。本类档案从原文提取"一个地方看起来是什么样"，供 art-bible 地理篇翻译成画面。

### 核心理念

地理视觉不是"画一张地图"，是提取**这个地方的空间质感与氛围**——它是什么材质、什么温度、什么光线、什么情绪，让人一眼记住这个"小世界"。

### 提取流程

#### 1. 地理定位搜索

| 搜索维度 | Grep 关键词模板 | 提取内容 |
|:---------|:---------------|:---------|
| 地名 | `[地名]` | 所有出场段落 |
| 空间特征 | `[地名].*(城\|山\|海\|渊\|宫\|界\|域\|境)` | 空间类型 |
| 氛围 | `[地名].*(雾\|光\|暗\|冷\|热\|静\|嚣)` | 环境氛围 |
| 建筑 | `[地名].*(楼\|殿\|塔\|墙\|桥\|街\|府)` | 建筑风貌 |

#### 2. 地理档案整理

| 维度 | 内容 |
|:-----|:-----|
| 一、地理概览 | 名称/类型/所属世界/核心气质 |
| 二、空间质感 | 材质/地形/建筑/植被/气候（含行号） |
| 三、氛围基调 | 光线/色彩/温度/声音/情绪（含行号） |
| 四、标志性地标 | 3-5个可定格的地标节点（含行号） |
| 五、生灵种族 | 当地居民/生物/文明形态 |
| 六、象征隐喻 | 这个地理对故事的意义/情绪符号 |
| 七、视觉设计参考 | 3-5个最适合做地理卡的场景与形象 |

> 地理档案只在原文有明确描述时提取，禁止拼凑"仙侠标配"的通用场景。

## §七 规则档案

> 网文抽象规则/力量体系/修炼境界/功法/法则/天道/禁忌,是推广素材（规则卡/体系卡）的视觉真源。这类内容最难画，本类档案提取"抽象规则的视觉外显"，供 art-bible 规则篇设计可视化策略。

### 核心理念

抽象规则没有天然形象，必须从原文已有的**视觉外显**（光效/纹路/器物/天象/境界异象）提取具象载体，再设计可视化。禁止凭空捏造一个与原文无关的符号。

### 提取流程

#### 1. 规则定位搜索

| 搜索维度 | Grep 关键词模板 | 提取内容 |
|:---------|:---------------|:---------|
| 规则名 | `[规则名\|境界名\|功法名]` | 所有出场段落 |
| 视觉外显 | `[规则名].*(光\|纹\|阵\|雷\|焰\|雾\|虚影\|印记)` | 规则的视觉表现 |
| 境界异象 | `[境界名].*(突破\|天象\|雷劫\|金光\|黑雾)` | 突破时的视觉奇观 |
| 器物载体 | `[功法规格].*(印\|镜\|书\|卷\|符\|剑)` | 规则具象化器物 |

#### 2. 规则档案整理

| 维度 | 内容 |
|:-----|:-----|
| 一、规则概览 | 名称/类型/层级结构/核心气质 |
| 二、视觉外显 | 规则表现时的光效/纹路/天象/异象（含行号） |
| 三、境界/层级可视化 | 各层级突破时的不同视觉奇观（含行号） |
| 四、器物载体 | 承载规则的具象器物/符号（含行号） |
| 五、象征隐喻 | 规则对故事的意义/情绪符号 |
| 六、视觉设计参考 | 3-5个最适合做规则卡/体系卡的场景与形象 |

> 规则档案必须在原文有视觉外显描述时提取，禁止凭空发明规则符号。
