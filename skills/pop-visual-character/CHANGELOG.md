# CHANGELOG — pop-visual-character

## v1.2.0 | 2026-08-04

### 新增：三把锁差异化纪律（角色差异化核心方法）

老板定调：网文角色辨识度低、跨书也低，根因是设计层没建立差异化——网文角色是"属性堆砌"，而日漫靠"一人一个互相冲突的剪影签名"分人。差异化不是"加更多细节"，是**在全局让每个角色占一个"唯一"的视觉位置**。

- 新增 `references/advanced-character-design.md` §0.5 三把锁差异化纪律（全局先行，先于单角色设计）
- **三把锁**：① 剪影签名（一人一个可辨认轮廓，同书不撞）② 签名色（一人一个全局唯一主色）③ 记忆锚点（见分级）
- **记忆锚点分级（老板细化）**：主角/重要角色 2-3 个锚点组合（统一指向同一核心人设），配角/路人 1 个锚点（宁缺毋滥）。记忆锚点数量 = 角色重要度
- **置换测试**：把角色A的剪影/签名色/锚点换成角色B，画面仍成立=未差异化，回炉
- `steps/step1-design-identity.md`：三把锁设为设计主流程第一步（全局先行），记忆锚点改分级，更新自检
- `templates/visual-identity-card.tpl.md`：新增"三把锁差异化位置"区块 + 记忆锚点分级
- SKILL.md：Step 1 更新、新增铁律 ❌7、速查表更新

## v1.0.0 | 2026-08-03

**新建 skill：人物形象设计（营销专家基建层）**

填补营销专家管线"人物形象设计"空白。定位：把"这个角色长什么样"这个身份设计一次性做对，产出「角色视觉身份卡」，作为 oc/cover/comic 全下游共用的视觉真源。

### 核心内容
- **身份设计方法论**：从 `pop-visual-comic` 提升 `advanced-character-design.md`（角色设计金字塔/反类型化/撕裂感/五问提取法）为核心方法论
- **角色视觉身份卡**：整本书角色视觉的唯一真源，产出 `素材/视觉资产/[角色名]视觉身份卡.md`
- **三步流程**：Step 0 读输入（档案+画风）→ Step 1 身份设计（五问+金字塔+锚点+反类型化+撕裂感）→ Step 2 确认+落盘
- **5 条铁律**：忠于原著、锚点有"为什么"、显式"偏科"、身份卡唯一真源、身份改动升级版本

### 与营销专家 skill 群的关系
- `pop-visual-asset`：提供角色档案（人是谁）
- `pop-visual-style`：提供画风（世界怎么画）
- `pop-visual-oc` / `pop-visual-comic` / `pop-visual-cover`：消费角色视觉身份卡

### 背景
老板反馈"角色形象不出彩、千篇一律"。根因是每个 skill 各自"美型渲染"，没先做"角色身份设计"。本 skill 把身份设计抽出来作为基建，全下游消费同一身份。
