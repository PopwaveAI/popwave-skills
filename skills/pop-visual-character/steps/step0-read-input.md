# Step 0: 读输入

> 人物形象设计前，先吃透两个输入：角色档案（人是谁）+ 画风（世界怎么画）。**缺一不可。**

## 0. 前提校验

| 检查项 | 缺失处理 |
|:-------|:---------|
| 角色档案存在 | 缺失 → 提示用户先跑 `pop-visual-asset` 提取角色档案，或告知用户本 skill 内部可做 5 轮原文采样（见 §2） |
| 画风已定 | 缺失 → 从 `pop-visual-style` 画风DNA库按赛道选基准 |

## 1. 读角色档案（人是谁）

- 路径：`素材/视觉资产/[角色名]角色档案.md`（`pop-visual-asset` 产出，10维度）
- 重点读：**维度一 角色概览**（命格/气质/道具）、**维度二 外貌演变**、**维度五 成长弧线**、**维度八 矛盾暗面**、**维度十 核心意象与符号**
- 角色档案缺失时，本 skill 内部执行原文采样（5 轮关键词搜索 + 上下文采样），输出角色档案后继续

## 2. 读画风（世界怎么画）

- 从 `skills/pop-visual-style/references/style-dna-library.json` 按赛道选画风基准
- 取 `dna` + `constraint` + `recommended_lighting` + `recommended_composition` 四字段
- 画风决定**美术语言**（厚涂/赛璐璐/暗黑高对比），但不决定**角色身份**（身份是本 skill 的活）

## 3. 读已有身份卡（升级模式）

- 路径：`素材/视觉资产/[角色名]视觉身份卡.md`
- 存在 → 升级模式：在原有身份上做增量（换装/受伤/觉醒/年龄），**反类型化和撕裂感一旦建立就保持**
- 不存在 → 新建模式：走 Step 1 完整身份设计

## 4. 产出

- 确认输入就绪，进入 Step 1 身份设计
