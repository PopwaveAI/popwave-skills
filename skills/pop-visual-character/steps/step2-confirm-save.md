# Step 2: 确认 + 落盘

> 身份卡是基建真源，落盘前必须确认，落盘后下游才能消费。

## 1. 🚪 门禁：身份卡确认

向用户呈现角色视觉身份卡摘要，确认：

- [ ] 角色身份设计有辨识度（0.3秒能认出）
- [ ] 忠于原著处境（非凭空捏造）
- [ ] 有记忆锚点 + 撕裂感（非平庸平均值）
- [ ] 反类型化到位（非网感脸）

**未确认不落盘。** 用户提出修改 → 回到 Step 1 调整对应维度。

## 2. 落盘

- 路径：`素材/视觉资产/[角色名]视觉身份卡.md`
- 首次 → 新建文件
- 已有 → 升级版本（版本号递增，保留变更记录）

## 3. 通知下游

落盘后，告知用户身份卡已就绪，可被以下消费：

| 消费方 | 触发方式 | 产出 |
|:-------|:---------|:-----|
| `pop-visual-oc` | "做 OC/胶志版立绘" | 杂志版立绘（角色本体+六层排版） |
| `pop-visual-comic` | "做漫画/定妆照" | 正/侧双角度定妆图（角色本体+高精度4块） |
| `pop-visual-cover` | "做封面/场景图" | 封面/场景中的角色（角色本体+构图） |

> **铁律**：下游只改渲染格式，不改角色身份。身份改动必须回到本 skill 升级身份卡。
