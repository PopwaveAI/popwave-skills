# Step 3: 角色定妆（Pipeline 语境下必做）

> 身份卡是"看得见的文字"，但角色到底成立不成立，只有渲染成图才能验证。本步用**选定画风 + 身份卡冻结提示词**渲染 1 张角色定妆图，用户认可后**冻结身份卡为全书基线资产**。未认可不冻结、不放行下游。

## 何时用

- 本 skill 只做身份设计（不渲染图）：**跳过本步**（Step 0→1→2 出身份卡即完成）。
- **Pipeline 语境下（Phase 2 设计人物）**：**必做**。身份卡确认落盘后、进入下游（cover/oc/comic）前，先定妆验证。

## 核心原则：身份不变，只验证渲染

定妆图是**身份卡的可视化验证**，不是出新身份。它验证的是"这个角色到底是谁"的设计在大图上是否成立。

**定妆图不达标 → 回身份卡升级版本（改身份），禁止在渲染层硬凑。**

## 定妆照 = 纯生产参考图（非展示作品）

定妆照是**给下游做图生图参考的纯净素材**，不是给读者看的展示图。因此：

- **禁止**在定妆图中出现任何文字（角色名/称号/小传/题诗/书法大字/钤印）
- **禁止**叠加任何装饰元素（边框/印章/纹样/排版线）
- **禁止**叠加任何文化元素（背景文字/铭文/道具上的特殊文字）
- 只需纯净的角色本体：角色居中，标准姿态，干净背景，聚焦"角色长什么样"

> 与 `pop-visual-oc` 的**立绘OC**严格区分：立绘OC是带文字+文化元素的展示作品（角色名片），定妆照是纯净生产参考。二者职责不同，**定妆照不承担展示功能**。

## 1. 读输入

- 读身份卡 `素材/视觉资产/[角色名]视觉身份卡.md`，取**冻结提示词**（英文，API 读）
- 读画风基线 `素材/风格/画风决策.md`，取画风三字段 + 定标图（同款画风渲染，保证画风一致）

## 2. 组装定妆提示词

读取 `steps/step2-prompt-build.md` 的 6 段式结构，画风 DNA 放第 2 段（铁律❌2）：

```
[质量触发词] + Art style: [dna] [constraint] + [构图策略] + [光影叙事] + [身份卡冻结提示词] + [标准姿态]
```

- 人物段：用**身份卡冻结提示词**（含三层 + 反类型化 + 撕裂感）
- 姿态段：标准正面半身或立姿，中性（不抢身份）
- 构图/光照：用画风基线的 `recommended_composition` + `recommended_lighting`
- **硬约束**：追加 `no text, no letters, no characters, no watermark, no decorative elements, no border, no seal`，确保产出纯净定妆照

## 3. 生成定妆图

```powershell
python ../pop-visual-shared/scripts/generate.py image --prompt "定妆提示词" --model doubao-seedream-5-0-pro-260628 --size 1125x1500 --image "画风定标图" --output "素材/视觉/角色定妆-{角色名}-v1.png"
```

> 定妆图可传画风定标图作参考（图生图），保证画风与定标一致。

## 4. 🚪 门禁：角色定妆验收

向用户呈现定妆图，逐项验收：

| 维度 | 验收判据 |
|:-----|:---------|
| 剪影层 | 0.3 秒能否凭轮廓认出"是他" |
| 色彩签名 | 主色块能否区分阵营/暗示命运 |
| 记忆锚点 | 那个"0.3 秒认出"的锚点是否真的被画出来了 |
| 反类型化/撕裂感 | 是否打破网感脸，是否有"状态感"而非"摆拍感" |
| 画风一致 | 与画风定标图是否同款画风（无漂移） |

**未达标不冻结。** 回身份卡升级版本（改身份），重新渲染 v2、v3... 直到达标。

## 5. 认可 → 冻结身份卡基线资产

用户认可后，把身份卡**冻结为基线资产**，这是全书角色视觉准绳：

- 身份卡 `素材/视觉资产/[角色名]视觉身份卡.md` 标注 `签核状态: ✅ 已认可`
- 记录定妆图路径到身份卡，作为下游 oc/comic 的**角色参考图**（图生图 image 参数传第一张）

## 6. 通知下游

告知用户定妆图已就绪，可被以下消费：

| 消费方 | 用途 |
|:-------|:-----|
| `pop-visual-oc` | 作为杂志版立绘的"角色本体"参考 |
| `pop-visual-comic` | 作为定妆照参考（`ref_images` 传第一张） |
| `pop-visual-cover` | 作为封面角色钩子的视觉依据 |

> **铁律**：身份卡基线一旦冻结，下游只消费它，只改渲染格式、不改角色身份。身份改动必须回到本 skill 升级身份卡版本。
