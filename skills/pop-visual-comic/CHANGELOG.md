## v7.23.0 | 2026-08-10

### 导演卡前移「剧情白描」硬性前置 + 信息页 YZ-INFO 模板

**背景**：老板校准（8-10）——漫画"画得漂亮但没讲清剧情"的病根是**信息被压缩成点状概述**。导演卡"剧情概述"列是概述式（每页2-3句），不是白描式，因果/动机/转折在"讲清"层面断裂。老板定调：①放宽页数预算（宁多勿少，少页=压旁白=丢因果）；②先做剧情白描+分镜头处理，再产出导演指令卡；③模板库补信息页模板；④回炉敲定后出对比版本，已有章节不回炉。

**改动**：

- `steps/step1-director-card.md`：**阶段重构为 5 阶段**——①剧情白描（v7.23.0 起硬性前置，§1）→②分镜头处理（§2）→③改编分析（§3）→④页面设计（§4）→⑤提示词产出（§5）。**新增 §1 剧情白描**：把整章翻译成 800-2000 字"白描式完整故事弧线"（谁/做了什么/为什么/导致什么/转折点/章末悬念，像给朋友讲故事，0基础读者能复述），分镜/改编/页面一切从白描派生；§2 分镜以白描为唯一输入源拆页，不再直接从原文拆；§2.1 页数规划改为"先算 N_cause 因果承载量再定页数，禁止先定页数再压文字"，页数宁多勿少；采摘表新增「白描因果链」列 + 页面设计表和 10 项核查表章节号全部对齐新 5 阶段
- `references/guides/director-card-template.md`：顶部新增「剧情白描」段（800-2000字完整弧线）；原文采摘表新增「白描因果链」列；页数决策加"宁多勿少"；引用同步到新章节号
- `references/layout-baseline.md`：**新增 YZ-INFO 信息页模板**——上漫画 50%（Seedream 单格大图）+ 下文字 50%（HTML 文字块），锁定上半 Seedream 分格指令；速查表/速查新增条目
- **信息页实现锁定（老板拍板）**：上半 = Seedream 单格大图（画风统一/漫画沉浸），下半 = HTML 文字块（文字层物理上只能由 HTML 承载，Seedream 不画可读文字）。混合 = 每页仅 1 次生成，成本极低且保画风统一。**禁止纯 HTML 搭整页**——那会像网页插进漫画滚动流
- `skill.json`：版本至 v7.23.0，description 补剧情白描改造说明
