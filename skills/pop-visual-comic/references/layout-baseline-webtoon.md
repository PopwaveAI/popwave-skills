# 条漫排版基准库（Layout Baseline · Webtoon）

> Step 2 **条漫模式**分格设计的唯一来源。工程化复现铁律：**条漫不是页漫的窄版，是"大单格+纵向摇镜"的竖屏叙事。**

> 页漫排版基准见 `layout-baseline.md`（元尊 YZ-1~8 分页）。本文件管"条漫怎么切格"——**一格 = 一屏 = 一个叙事节拍**，靠纵向滚动（摇镜）推进叙事。

## 一、条漫 vs 页漫：核心 gap（先读这个）

| 维度 | 页漫（翻页漫画） | 条漫（webtoon 竖屏滚动） |
|:-----|:----------------|:----------------------|
| 阅读载体 | 印刷/横屏翻页 | 手机竖屏滚动 |
| 阅读动作 | 翻页（每次一页） | 下滑（每次一屏） |
| 基本单元 | **一页**（含多格） | **一屏 ≈ 一格**（一屏一镜） |
| 单格尺寸 | 小、信息密度高、多格密集 | **大、信息密度低、单格完整** |
| 画幅 | 固定比例（如 3:4） | **宽度固定、高度随叙事节拍变** |
| 节奏来源 | 翻页分隔 + 格内布置 | **滚动本身就是节奏**（摇镜） |
| 构图导向 | 网格化分格（横向阅读） | **纵向延展**（垂直引导视线） |
| 人物构图 | 常截半身/局部 | **全身构图是常态** |
| **文字载体** | 气泡/旁白框叠在格内 | **格间留白区写文字**（内戏/旁白占据独立留白条，不叠画面）+ 格内画面对白 |

**一句话本质（老板校准）**：条漫 = 照顾手机用户的竖屏叙事。**每一格 = 手机一屏刚好读完的一格**（单格高度 ≈ 屏幕高度，短、快、一屏一镜）。读者滑一下 = 读一格 = 一个叙事节拍，大量快速切换营造"滑手机"的沉浸流。**单格必须够大够完整**，一格做超小 = 把条漫切回页漫思维，违背竖屏叙事逻辑。

> 反例：把页漫一页里的 3-4 个小格硬拆成 3-4 张竖图，那不是条漫，是"页漫切条"。条漫的单格天生就大、就完整、就一屏一镜。

## 二、一屏一镜原则（铁律）

1. **基准单格 ≈ 一屏高度**（手机屏）。读者滑一下 = 读一格 = 一个叙事节拍。
2. **单格高度 = 叙事节拍决定**，不是固定值。普通节拍一格一屏；高潮节拍可跨屏（长切）；快节奏可半屏（短切）。
3. **一格承载一个完整信息**（一个动作/一个反应/一个揭示），不塞多个并列事件。
4. **信息密度低**：单格内要素少而精，留白给滚动节奏，让读者读得舒服、滑得顺。
5. **一屏一镜是阅读单元**，不是"一格一屏高度"的机械套用——跨屏长格用于高潮视觉冲击，是例外不是常态。
6. **格间留白是叙事的一部分**：切格之间留出纯色留白条带（黑底/白底），旁白、内心戏、时间停顿、情绪沉淀都写在留白区里——**文字不叠画面，占据独立留白**（老板校准：真实条漫用格间留白写内戏/旁白）。
7. **大切格内可有内嵌分镜**：一个切格的画面内可上下排列 2-3 个连贯镜头单元（景别递进/动作分解），不是"任何切格都只能是一个完整画面"——**格内分镜是条漫的常态细节**，与格间留白互补（详见下文 §2.8）。

### 2.7 格间留白区（Gap Zone）—— 文字的家

> 条漫区别于页漫的关键之一：**文字不在画面上，而在格与格之间的留白区**。这是老板校准的核心设计规范。

**定义**：相邻两个切格之间的一段纯色留白条带（常见黑底，也可白底），不承载画面，专门写旁白/内心戏/时间提示。

| 项 | 规范 |
|:---|:-----|
| 载体 | **HTML 层实现**（切格图片之间插入留白 div），禁止 AI 直出文字（沿铁律6：乱字不可修复） |
| 底色 | 黑底（默认，暗黑题材）/ 白底（清新题材）——与切格画面形成"剧场式"明暗呼吸 |
| 文字类型 | 旁白（讲因果）、内心戏 OS（给动机）、时间/地点提示、情绪停顿、"……"沉默 |
| 高度 | 随文字量定：单句旁白 ≈ 1-2 行高度；情绪停顿/沉默张力可拉大（参考图 15%-25% 屏高） |
| 位置 | 插在需要停顿/交代的切格之间，不是每个切格后都有——**留白是节奏工具，克制使用** |

**留白区 = 情绪放大镜**：留白占比与情绪强度正相关。电话挂断后的沉默、告别前的停顿、揭示前的悬念——加大留白区高度，让读者在滑动中"被迫等待"，制造张力。

**镜表标注**：条漫镜表新增"留白区"列，标注每个切格**之后**是否插留白区 + 文字内容。无留白的切格间标 `-`。

### 2.8 格内内嵌分镜（Internal Panels）—— 一屏之内的镜头切分

> 老板校准：条漫大切格内部可以有**适当的切格分镜**——一屏画面内上下排列多个连贯镜头，不是每个切格都只能画一个完整画面。

**定义**：一个切格（WT 类型）内部，画面可上下补充分为 2-3 个镜头单元，实现"一屏读完多个镜头"的节奏。

| 项 | 规范 |
|:---|:-----|
| 内嵌形式 | 上下纵向排列的连贯镜头（景别递进/动作分解/反应连拍），**无分格线、full bleed 出血**，靠画面内容自然分割 |
| 出现位置 | 通常用于**对话**（你-我-反应）、**动作连拍**（起-中-落）、**情绪递进**（忍-怒-爆发） |
| 数量 | 一个切格内 2-3 个内嵌镜头，**不刻意细分**（过多 = 退化成页漫网格） |
| 与留白区关系 | 内嵌分镜管"格内节奏"，格间留白管"格间停顿"，两者互补不冲突 |
| 提示词 | Layout 段写"纵向多镜头切分"描述（见 §四 分镜切指令），画面自动上下分割，禁分格线 |

**一句话**：条漫 = 格间留白（写文字）+ 格内分镜（镜头细分）双轨并行。**格间留白让读者停下来读文字，格内分镜让读者一屏看够镜头变化。**

> 反例：把格间留白区去掉、把所有文字重新叠回画面上、把每个切格都砍成单一完整画面——那就丢失了条漫的"留白叙事"灵魂，退化成"大图+字幕"的幻灯片。

## 三、画布规格 + 像素上限约束（硬约束）

| 项 | 规格 | 说明 |
|:-----|:-----|:-----|
| 宽度 | **1125px 固定** | 全系列切格统一宽度，HTML 纵向拼接顺畅 |
| 高度 | **随切格类型变** | 见 §四 切格类型库 |
| 上限 | **总像素 ≤ 2,360,000** | Seedream 计费临界，超 2.36M 单价翻倍（MaxPixels 硬校验） |
| 分辨率 | 拟 300dpi 输出 | 生图按尺寸出即可 |

> **跨屏长切的高度上限**：1125 宽度下，`2,360,000 ÷ 1125 ≈ 2097px`。故**跨屏长切最高 1125x2000**（≈1.3 屏）。若确需更长（1.5-2 屏），降宽到 900（`900x2500 = 2.25M`，≈1.67 屏）或接受高计费档。**默认用 1125x2000，不降宽**（保持拼接宽度一致）。

## 四、切格类型库（WT-1 ~ WT-5）

> Step 2 条漫镜表里，每格从本库选一个切格类型。**选切格 = 从本库选一个已验证结构，换题材填内容。**

| 码 | 切格类型 | 尺寸 | 像素 | 叙事用途 | 构图倾向 |
|:---|:---------|:-----|:-----|:---------|:---------|
| WT-1 | **标准切** | 1125x1500 | 1.69M | 基准一屏，一个完整叙事节拍（动作/反应/对话） | 全身或中景，纵向完整 |
| WT-2 | **节奏切** | 1125x900 | 1.01M | 半屏快节奏，短情绪点/对话切换/连环动作 | 局部特写或紧凑全身 |
| WT-3 | **跨屏长切** | 1125x2000 | 2.25M | 高潮大场面/摇镜拉开/纵深穿越（1.3 屏） | 纵向三段式（上引→中体→下收） |
| WT-4 | **全景切** | 1125x1500 | 1.69M | 横向大场景建立（摇镜起点），交代环境关系 | 横构图大场面，人物渺小 |
| WT-5 | **特写切** | 1125x1500 | 1.69M | 情绪钉（摇镜终点），单点聚焦 | 大特写，留白少 |

**分格指令（锁定，进提示词 Layout 段）**：

- WT-1 标准切：`A single tall webtoon cut, fixed width, full screen height, one complete scene, no internal panels, no gutters, no borders, full bleed.`
- WT-2 节奏切：`A single short webtoon cut, fixed width, half screen height, one quick beat, no internal panels, no gutters, no borders, full bleed.`
- WT-3 跨屏长切：`A single extra-tall webtoon cut, fixed width, taller than one screen, one sweeping dramatic scene, vertical composition, no internal panels, no gutters, no borders, full bleed.`
- WT-4 全景切：`A single tall webtoon cut, fixed width, full screen height, one wide establishing shot, horizontal composition, no internal panels, no gutters, full bleed.`
- WT-5 特写切：`A single tall webtoon cut, fixed width, full screen height, one extreme close-up, no internal panels, no gutters, full bleed.`

> **切格高度配比建议**：一章内 WT-1 基准占多数（50-60%），WT-2 节奏切 20-30%，WT-3 跨屏长切 1-2 处（仅高潮/名场面），WT-4/WT-5 用于摇镜起止。**跨屏长切是稀缺资源，一章最多 2 处，否则滚动手感被拖垮。**

**内嵌分镜指令（格内细分镜，§2.8）**：当某切格画面内要纵向排 2-3 个连贯镜头时，在上述 WT 指令基础上追加分镜描述（**禁分格线，full bleed 出血**）：

- **动作连拍**（起-中-落）：`A single tall webtoon cut, fixed width, one seamless vertical sequence of the same action in phases (start - middle - landing), no internal panel borders, no gutters, full bleed, the shots flow together naturally.`
- **对话对切**（你-我-反应）：`A single tall webtoon cut, fixed width, one seamless vertical sequence alternating between two speakers' faces and a reaction shot, no internal panel borders, no gutters, full bleed, the shots flow together naturally.`
- **情绪递进**（忍-怒-爆发）：`A single tall webtoon cut, fixed width, one seamless vertical sequence of escalating emotion on one face (restrained - rising - erupting), no internal panel borders, no gutters, full bleed, the shots flow together naturally.`

> 内嵌分镜与普通 WT 切格共用同一画布尺寸（WT-1 用 1125x1500 等），只是画面内做多次纵向镜头切分。**文字仍走格间留白区或 HTML 气泡，画面内不出现文字。**

## 五、纵向摇镜节奏（条漫的灵魂）

> 条漫的"镜头语言"不在格内，而在**格与格的纵向衔接**——读者下拉屏幕 = 摄像机纵移。四种摇镜模式：

| 摇镜模式 | 切格序列（纵向） | 效果 | 适用 |
|:---------|:---------------|:-----|:-----|
| **推近**（push in） | WT-4 全景切 → WT-1 标准切 → WT-5 特写切 | 景别递减，镜头推近人物，情绪逼近 | 揭示/逼近/觉醒 |
| **拉远**（pull back） | WT-5 特写切 → WT-1 标准切 → WT-4/WT-3 | 景别递增，镜头拉远，主观抽离 | 释然/大局/宿命 |
| **快切**（pan） | 连续 2-4 个 WT-2 节奏切 | 半屏快切，节奏爆点，滑手机爽感 | 追逃/打斗/连环反应 |
| **纵贯**（depth） | 1 个 WT-3 跨屏长切 | 单格内自上而下纵深穿越 | 大场面/名场面 |

**摇镜节奏铁律**：
1. **推近/拉远是景别递进**，最少 3 个切格完成一次完整摇镜，禁止"全景切直接跳大特写"的突兀跳切。
2. **快切连续 ≤4 个 WT-2**，超过必须插一个标准切或换摇镜模式，否则读者被"滑爆"。
3. **跨屏长切前后必须接标准切**，不能接另一个长切（两个长切连排 = 手势疲劳）。
4. **每章至少 1 次完整摇镜**（推近或拉远），让读者感受到"滚动即镜头"的条漫专属体验。

## 六、条漫构图规则（纵向导向）

> 页漫构图管"单格方框内"，条漫构图管"纵向画布内"。同一套 L/C 码可用，但**构图权重往纵向倾斜**。

| 规则 | 说明 |
|:-----|:-----|
| **垂直引导视线** | 主要动线自上而下，配角/道具/影子放在中下部承接视线 |
| **全身构图是常态** | 人物全身/大半身是条漫默认，不主动截半身（页漫习惯要改） |
| **垂直象征轴线** | 权威/天象在上，受难/地面在下（沿用 content-layer §2.2 维度3） |
| **跨屏长切三段式** | 顶部引入（环境/人物入画）→ 中部主体（核心动作/情绪）→ 底部收尾（后果/影子/下一钩子） |
| **留白给滚动呼吸** | 每 3-4 个切格至少 1 个有上部/下部留白，避免连续满格压迫 |
| **景别过度** | 相邻切格景别必须变化（全→中→近→特），连续 2 切同景别 = 单调（沿用 content-layer §3.1 景别递进） |

> 镜语 L/C/F 三码沿用 `content-layer.md` §三（L1-L12 / C1-C10 / F1-F9），**条漫模式把"相邻格"换成"相邻切格"**，S 级切格禁 C1 三分法，特效每切 ≤2 种。

## 七、切格设计规则（红线）

| # | 红线 | 违反后果 |
|:-:|:-----|:---------|
| 1 | **一格一屏一信息，禁止一格塞多事件**（允许格内 2-3 个连贯分镜展现同一事件，禁止塞多个独立并列事件） | 信息过载，读者滑一下读不完，节奏崩溃 |
| 2 | **跨屏长切一章 ≤2 处，仅高潮/名场面用** | 长切滥用，滚动手感拖垮，读者疲劳 |
| 3 | **文字控制在 HTML 层（格间留白区 + 画面气泡），切格只画画面** | 对话气泡/拟声字乱字，不可修复（沿用 content-layer §六） |
| 4 | **每切格必带镜语 L/C 码，S 级切格禁 C1** | 画面平庸、张力弱 |
| 5 | **切格高度由叙事节拍定，禁止统一高度切割** | 一刀切 = 失去摇镜节奏，退化成"页漫竖排" |
| 6 | **旁白/内心戏写进切格间留白区，禁止叠在画面上** | 文字挡画面、丢"留白叙事"灵魂，退化成"大图+字幕"幻灯片（老板校准） |
| 7 | **留白区是节奏工具，克制使用，禁止每格间都插留白** | 留白泛滥拖垮滚动，读者烦躁 |
