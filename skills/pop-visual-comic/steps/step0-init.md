# Step 0: 项目初始化

> 读取设定 → 定画风 → 定OC → 生成双角度定妆图 → 门禁0 → 冻结 → 创建记忆文件

## 设计哲学

Phase 0 只做两件事：**定画风、定OC**。这两件事是全系列一致性的根基——模式固定页漫（一页多格，YZ-1~8 分页），画风错了全书白画，OC 错了角色永远对不上。

冻结提示词是核心——定妆图生成后，提示词原文立即冻结到角色库。后续所有章节直接引用冻结版，不再重新组装。DeepSeek 无视觉能力，但"引用同一份文本指令"就能保证角色一致。

## 1. 读取项目设定

从小说项目读取角色清单和基础设定：

| 优先路径 | 读取内容 |
|:---------|:---------|
| `素材/视觉资产/` | pop-visual-asset 产出的角色档案（含10维度+视觉设计参考），优先读取 |
| `设计/角色库.md` | 角色清单和视觉特征（无资产时回退） |
| `设计/主角设计.md` | 主角详细设定 |
| `正文/ch001.txt` | 无设定文件时从正文提取 |

> 资产缺失时回退到角色库.md+正文提取，不影响核心流程。

## 1.6 🚪 基建签核检测（pipeline 已跑基建时跳过门禁0）

> **目的**：comic 单独跑时走完整"定画风+定OC+门禁0"（§2-§4）。但当 visual-pipeline 基建层（Phase1 定画风/Phase2 定人物）已签核完成时，画风与角色身份**已被老板认可过一次**，本步不再重复确认，直接消费基建冻结资产，避免同一套"选画风+验角色"让老板确认两轮。

**检测**：读取以下文件，检查签核状态是否均为 `✅ 已认可`：

| 文件 | 签核标记来源 |
|:-----|:-----------|
| `素材/风格/画风决策.md` | `签核状态: ✅ 已认可`（pop-visual-style step4 落盘） |
| `素材/美术设定集.md` | `签核状态: ✅ 已认可`（pop-visual-art-bible step2 落盘） |

| 检测结果 | 流向 |
|:---------|:-----|
| **基建全部已签核** | 走 **快速路径**（消费基建，跳过 §2 定画风/§3 定OC/§4 门禁0，直接 §5 冻结） |
| 基建缺失或未签核 | 走完整路径（§2 定画风 → §3 定OC → §4 门禁0 → §5 冻结） |

### 快速路径（§A）：基建已签核时的消费流程

> 角色身份已在美术设定集人物篇冻结，本步只做"渲染格式转换"（comic 需要双角度定妆图），**不改角色身份**。铁律：下游只改渲染格式，不改身份。

1. **画风**：从 `素材/风格/画风决策.md` 提取画风三字段（锚定串/执行串/风格保真约束）到 `漫画快照.md` + `漫画角色库.md` 顶部。**不做门禁0的画风确认**（画风已签核）。
2. **角色双角度立绘**：从美术设定集人物篇取角色本体描述（三层+反类型化+撕裂感），按 `oc-design-guide.md` §高精度立绘升级（4块结构）组装 comic 双角度立绘提示词 → 生成 front+side 定妆图到 `assets/characters/`。**这是技术动作，不设确认闸口**（身份已认可；若生成偏离美术设定集人物篇描述，回美术设定集升级版本，不在此处重新确认）。
3. 直接进入 §5 冻结（跳过 §4 门禁0）。

## 2. 定画风

> **必读 `references/art-style-baseline.md`** — 画风基准库（多画风基准池，按小说赛道选基准，换题材只换配色，不换画风底盘）

### 2.1 选基准（按赛道选，不锁单一基准）

> **画风跟小说类型走。** 查 `art-style-baseline.md` §一 赛道→画风映射表，按小说赛道选基准。**表内是"待入库"的赛道 = 先走 §三 入库流程实测通过再回填，禁止硬套。**

| 小说赛道 | 画风基准 | 画风底盘特征 |
|:---------|:---------|:-------------|
| **仙侠/玄幻/史诗** | **厚涂玄幻史诗**（§二-B） | 无线稿厚涂+冷暖大对撞+体积光/粒子/发光 |
| **国漫玄幻/古风** | **元尊V1**（§二） | 书法墨线赛璐璐+高饱和+对角分区 |
| **赛博朋克/都市异能** | 韩漫暗黑厚涂（待入库） | 厚涂冷色+电影感+无线稿 |
| **都市/悬疑/诡异** | 韩漫暗黑厚涂（待入库） | 同赛博行 |
| **热血/战斗** | 日系热血/韩漫厚涂（待入库） | 需实测 |
| **言情/甜宠/古言** | 少女水彩/日系赛璐璐（待入库） | 需实测 |

选好后向用户呈现：

```
基于小说赛道【{赛道名}】，推荐画风基准：{基准名}（{画风底盘特征一句话}）
画风底盘：{五维特征，已锁定，不换}
```

### 2.2 换题材配色（非仙侠/玄幻默认配色时）

从小说世界观提取 3-4 组对角色彩（冷/暖/线索色），替换画风串的 `[题材配色]` 占位。**只换配色，画风底盘不动。** 示例见 art-style-baseline.md §2.4（元尊V1）+ §2B.4（厚涂玄幻）题材适配表。

### 2.3 组装三字段

按 art-style-baseline.md 所选基准的锁定画风串（§2.2 或 §2B.2）产出：
- **锚定串**（人读）
- **Seedream 执行串**（API读，提示词开头，`[题材配色]` 已替换为本章配色）
- **风格保真约束**（API读，提示词末尾）

> 此时的三字段是**待验证版**，定妆图验证通过后才冻结。

## 3. 定OC

> **必读 `references/oc-design-guide.md`** — 双角度定妆图设计指南+妩造方法论

### 3.1 角色筛选

- 主角：必出双角度定妆图
- 出场≥2章配角：强制出定妆图
- 只出场1章配角：不需要，分镜提示词中描述

### 3.2 建立七维度规格表

为每个需定妆图的角色填写七维度规格表（详见 oc-design-guide.md §七维度规格表）：年龄/性别/体型 → 发型/发色 → 瞳色/眼型 → 面部特征 → 服装 → 标志性特征 → 视觉锚点串。

### 3.3 知名角色二创搜索（知名IP时）

对知名网文角色搜索二创参考，提取视觉共识特征回填规格表（详见 oc-design-guide.md §知名角色二创融合）。冷门/原创跳过。

### 3.4 生成双角度定妆图

**先生成主角正面立绘验证画风**——画风不对就回§2调整，不对就继续。

按 oc-design-guide.md §高精度立绘升级（4块结构：锁构图+锁光源+锁材质+锁硬约束）生成：
1. **正面立绘**：`char-{角色名}-v1-front.png` — 验证画风+面部+服装
2. **侧面立绘**：`char-{角色名}-v1-side.png`（传正面立绘作参考）— 锁定轮廓+发型

> **主角/重要配角/需跨章复用角色 = 必用高精度模板**（立绘是参考真相源，精度=全书质量上限）。一次性配角可用基础模板。

主角验证通过后，继续生成其他角色的双角度定妆图。

## 4. 🚪 门禁0：画风 + OC 双确认

向用户呈现：

1. **画风选择**：维度组合 + 预设名 + 代表作 + 三字段
2. **角色定妆图**：全部角色的正面+侧面立绘
3. **角色规格表**：七维度规格表（含二创验证标注）

### 用户决策

| 反馈 | 处理 |
|:-----|:-----|
| 画风OK，角色OK | → 进入§5冻结 |
| 画风不对 | → 回§2调整维度 → **重新生成全部定妆图** → 再次门禁0 |
| 某角色不对 | → 调整该角色规格表/提示词 → 重新生成该角色 → 再次门禁0 |
| 增删角色 | → 补生成/删除 → 再次门禁0 |

> **画风调整必须重新生成全部已出定妆图**——风格串变了，旧定妆图画风不统一。

## 5. 冻结（门禁0通过后执行）

### 5.1 冻结画风三字段

将三字段写入 `漫画快照.md` 和 `漫画角色库.md` 顶部。此后全系列冻结。

### 5.2 冻结角色提示词

将每个角色正面+侧面的完整提示词原文冻结到 `漫画角色库.md`。后续章节直接引用，不重新组装。

### 5.3 创建记忆文件

| 文件 | 模板 | 内容 |
|:-----|:-----|:-----|
| 漫画角色库.md | `templates/漫画角色库.md.tpl` | 全角色四层结构（规格表+冻结提示词+双角度资产+决策日志） |
| 漫画快照.md | `templates/漫画快照.md.tpl` | 冻结风格锚定串+角色清单+空章节清单 |
| 漫画状态.md | `templates/漫画状态.md.tpl` | 初始状态：当前章=第1章 |
| 视觉沉淀.md | 无模板（空文件） | 等待 Step 2 append |

确认 `assets/characters/` 目录已有全部角色的双角度定妆图。

> Phase 0 完成后，进入 Step 1（读取 `steps/step1-director-card.md`）执行导演卡创作。
