# Step 0: 项目初始化

> 读取美术设定集 → 消费画风/角色 → 双角度渲染定妆 → 冻结 → 创建记忆文件

## 设计哲学

comic 是 L2 派生层，**只消费 `pop-visual-art-bible` 产出的美术设定集，不重建画风、不重建角色身份**。画风与角色身份已在基建层（asset→style→art-bible）被老板认可过一次，本步只做两件事：**把美术设定集冻结资产转成 comic 需要的渲染格式（双角度定妆图）**、**冻结到记忆文件**。不做门禁0的画风/OC重确认。

> **铁律（art-bible ❌4）**：美术设定集是唯一视觉真源，comic 只改渲染格式、不改视觉事实。任何视觉事实改动必须回到 `pop-visual-art-bible` 升级设定集版本，不在 comic 侧改。

## 1. 🚪 美术设定集唯一入口门禁

> comic 初始化**必须以美术设定集为唯一入口**。基建缺失时禁止自建画风/OC，先引导跑基建。

**检测**：读取 `素材/美术设定集.md`，检查是否存在且签核状态为 `✅ 已认可`：

| 检测结果 | 处理 |
|:---------|:-----|
| 美术设定集存在且 `✅ 已认可` | 进入 §2 消费美术设定集 |
| 美术设定集存在但 `待认可` | 中止，提示先跑 `pop-visual-art-bible` Step 2 确认冻结 |
| 美术设定集缺失 | 中止，提示先跑 `pop-visual-pipeline` 基建（asset→style→art-bible）产出美术设定集 |

> **禁止**在本步自建画风基准（`art-style-baseline.md`）、自建OC规格表、自建门禁0的画风/OC确认。这些是基建层职责。

## 2. 消费美术设定集（画风 + 角色）

读取 `素材/美术设定集.md`，提取：

### 2.1 画风（画风篇 → 漫画快照）

| 美术设定集画风篇字段 | 用途 |
|:-----------|:-----|
| 画风DNA | 作为 Seedream 执行串（画风串开头） |
| 画风约束 | 作为风格保真约束（提示词末尾） |
| 定标图 | 作为双角度定妆图的参考图（图生图 image 参数） |
| 复现 seed | 沿用，保证画风一致 |
| **色彩基调** | 全漫画用色上限（主色≤3+辅助≤2），撞色即废 |

- 从美术设定集画风篇提取以上字段，写入 `漫画快照.md` + `漫画角色库.md` 顶部。
- **不做门禁0的画风确认**（画风已在基建层签核）。

### 2.2 角色（人物篇 → 双角度定妆图）

> 角色本体身份以美术设定集人物篇为唯一真源。本步只做"渲染格式转换"——comic 需要双角度定妆图，从人物篇取角色本体描述组装 comic 双角度立绘提示词。

1. **角色筛选**：从美术设定集·人物篇取全部角色（≈ asset 档案覆盖范围）。主角/出场≥2章配角必出双角度定妆图；只出场1章配角不需要，分镜提示词中描述。
2. **取角色本体**：从人物篇每角色小节取本体描述（三层：剪影/色彩/细节 + 反类型化 + 撕裂感 + 冻结提示词）。
3. **双角度渲染**：按 `references/oc-design-guide.md` §高精度立绘（4块结构：锁构图+锁光源+锁材质+锁硬约束）组装 comic 双角度立绘提示词：
   - 正面立绘：`char-{角色名}-v1-front.png`（定面部+服装）
   - 侧面立绘：`char-{角色名}-v1-side.png`（传正面作参考，锁轮廓+发型）
   - 存到 `assets/characters/`，版本递增
4. **这是技术动作，不设确认闸口**（身份已认可；若生成偏离美术设定集人物篇描述，回 `pop-visual-art-bible` 升级设定集版本，不在此处重新确认）。

## 3. 冻结

### 3.1 冻结画风三字段

将 §2.1 提取的画风字段（DNA/约束/seed/定标图/色彩基调）写入 `漫画快照.md` 和 `漫画角色库.md` 顶部。此后全系列冻结。

### 3.2 冻结角色提示词

将每个角色正面+侧面的完整提示词原文冻结到 `漫画角色库.md`。后续章节直接引用，不重新组装。

### 3.3 创建记忆文件

| 文件 | 模板 | 内容 |
|:-----|:-----|:-----|
| 漫画角色库.md | `templates/漫画角色库.md.tpl` | 全角色四层结构（规格表+冻结提示词+双角度资产+决策日志） |
| 漫画快照.md | `templates/漫画快照.md.tpl` | 冻结风格锚定串+角色清单+空章节清单 |
| 漫画状态.md | `templates/漫画状态.md.tpl` | 初始状态：当前章=第1章 |
| 视觉沉淀.md | 无模板（空文件） | 等待 Step 2 append |

确认 `assets/characters/` 目录已有全部角色的双角度定妆图。

> Phase 0 完成后，进入 Step 1（读取 `steps/step1-director-card.md`）执行导演卡创作。

## 红线

- **美术设定集是唯一入口**：缺失/未签核 → 中止引导跑基建，禁止自建画风/OC
- **只改渲染格式，不改视觉事实**：双角度定妆图必须基于美术设定集人物篇冻结提示词，禁止重建角色身份
- 画风字段必须来自美术设定集画风篇（消费 style 冻结画风），禁止从 art-style-baseline 自选基准
- 双角度定妆图必须持久化在 `assets/characters/` 且版本递增（铁律 ❌4）
