# 封面图模式

> 封面是**视觉钩子**，封面是**营销工具**。唯一目标：让目标读者在 0.3 秒内识别赛道、感知独特性、产生点击欲望。

## 三条底线

1. **构图必须有骨架**：镜头焦段、主体占比、前中后景虚实，缺一不可。
2. **书名必须可读**：字号够大、字形准确、有材质层次；字丑等于封面废。
3. **画面必须干净**：单一主光源、三色成数、明确明暗对比；泛白、发灰、五颜六色都不合格。

## 设计要素与权重

| 要素 | 要求 | 权重 |
|:-----|:-----|:-----|
| 书名 | 占画面高度 15%-25%，字形准确，有材质 | 两成 |
| 画面主视觉 | 视觉钩子主体 + 环境，最高细节密度 | 七成 |
| 文化元素 | 定场诗 / 印章（可选，宁缺勿滥） | 半成 |
| 留白 / 暗部 | 承载文字叠加，约两成 | 半成 |

## 四层信息架构

```
标题区（上1/4）→ 主视觉（中1/2）→ 赛道符号 → 作者区（下1/4）
```

竖排方案：文字区放一侧（左文右图 / 左图右文），主体让出两成宽度。

## 提示词结构

纯文生图走主文件里的「封面 4 块结构」：锁定构图 → 环境与光影 → 精确文字排版 → 硬约束。
有参考图走「参考点策略」，把参考图已覆盖的维度放权。

## 视觉钩子 → 构图骨架

| 钩子类型 | 推荐骨架 | 空间层次 |
|:---------|:---------|:---------|
| 角色统治力 | L 型（竖排文字 + 半身主体） | 主体六成、背景两成、前景剪影一成 |
| 标志道具 | 中心放射 | 道具居中三成，光效向外衰减，环境压暗 |
| 世界奇观 | 分层群像 / 大远景 | 远景五成、中景两成、主体一成、前景压边 |
| 对峙张力 | 对角线 | 双主体分列对角，中间留冲突带 |
| 反差 / 悬疑 | 框中框 | 外框两成、内框三成、焦点居中 |

## 字体规范（书名）

- **字形类别只选一种**：毛笔书法（仙侠/玄幻）、宋体衬线（古言/悬疑）、黑体无衬线（都市/科幻）。
- **字号**：书名占画面高度 15%-25%；作者名约为书名 1/4；定场诗 ≤ 书名 1/5。
- **分行**：按语义断成 2-3 行，主标题字重最重，禁止一行塞满。
- **材质**：鎏金、朱砂、墨色、碑刻龟裂；必要时加 1-2px 描边或外发光脱离背景。
- **硬要求**：字形准确可读，禁止错字、乱码、自造字、整段英文。

## 配色与光影

- 主色约七成、辅色两成、强调色半成、点缀色半成；用"成数"不用百分比。
- 画面只有 1 个主光源，写清方向与色温；道具自发光时，道具即焦点。

## 生成前自检

| 项 | 不合格表现 | 修法 |
|:---|:-----------|:-----|
| 构图 | 主体站桩、无前后景 | 补焦段、主体占比、层次虚实 |
| 光影 | 多光源、脸上双影 | 写"唯一主光源 + 方向 + 色温" |
| 配色 | 发灰、发土、五颜六色 | 回到三色成数 |
| 文字 | 字小、字糊、乱码 | 调字号占高、字形、描边 |
| 质感 | 塑料感、纯色块 | 补材质清单（织纹、划痕、粒子） |
| 缺陷 | 多指、多手、泛白 | 补硬约束负面清单 |
