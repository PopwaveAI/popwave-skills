# 普通素材模式

> 纯视觉，无文字要求。用于场景概念图、氛围图、参考图等。

## 核心原则

- 纯视觉生成，服务于场景/氛围/参考用途
- 无文字约束，画面是唯一主体
- 画幅按用途灵活决定

## 设计要素

| 要素 | 要求 |
|:-----|:-----|
| 画面 | 纯视觉，服务于场景/氛围 |
| 文字 | 无要求 |
| 画幅 | 任意，按用途决定 |

## 典型用途

- **场景概念图**：城市/战场/秘境
- **氛围图**：情绪/季节/光影参考
- **道具特写**：法宝/武器/信物
- **参考图**：画风/构图/配色锚定

## 提示词结构

```
整体氛围框架 + 画面内容 + 风格
```

无文字处理，全部篇幅用于画面描述。

## 与其他模式的关键区别

| 区别点 | 普通素材 | 封面图 | 场景图 |
|:-------|:---------|:-------|:-------|
| 文字 | 无 | 书名（必须） | 无强制要求 |
| 目的 | 纯视觉参考 | 营销钩子 | 原文还原 |
| 主体 | 场景/氛围/道具 | 视觉钩子 | 叙事瞬间 |
| 起点 | 用户意图 | 用户意图 | 小说原文 |
