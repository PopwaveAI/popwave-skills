# Step 2: 生成资产

> 读取确认方案 → 参考点→提示词策略 → 翻译为提示词 → 执行 API 脚本 → 保存产出 → 降级处理（如需）

## 设计哲学

Step 2 的核心不是"写提示词"，是**根据用户在门禁A选的参考点，决定提示词在哪些维度放手、哪些维度控制**。

用户选了"色系"参考点，提示词就不写配色——交给参考图。用户选了"全面参考"，提示词就只写差异——保留参考图画面主体。不写死路线，由参考点灵活组合。

**核心铁律**：用户选了什么参考点，提示词就在那个维度**放弃控制权**，交给参考图。不能既说"参考色系"又写"暖粉七成"——自相矛盾时模型听提示词不听参考图。

## 1. 读取确认方案

读取 `素材/视觉设计方案.md` 中的记录，提取：

- 视觉类型（封面/场景图/素材）
- 画幅与尺寸
- 参考图路径（如有）
- **用户选定的参考点**（全面参考/色系/构图/画风/光影/字体/组合）
- 设计方案中的画面描述（仅描述差异部分）
- 目标读者画像（校验画风方向）

## 2. 参考点→提示词策略

### 2.0 视觉模式决定提示词结构

**按视觉模式读取对应文件**（`references/mode-cover.md` / `references/mode-scene-art.md` / `references/mode-scene.md`），根据视觉模式选择不同的提示词结构：

| 视觉模式 | 提示词结构 | 文字处理 |
|:---------|:---------|:---------|
| 封面图 | 整体氛围框架 + 画面内容（远→近）+ 书名文字（融入画面）+ 风格 | 书名用双引号包裹，有材质质感 |
| 普通素材 | 整体氛围框架 + 画面内容 + 风格 | 无文字要求 |
| 场景图 | 整体氛围框架（基于情感基调）+ 画面内容（选定瞬间的角色+环境+材质，按空间层次）+ 风格 | 无文字要求（除非用户要求加标题） |

### 2.1 策略决策核心

根据用户在门禁A选定的参考点，确定提示词的**控制维度**和**放权维度**：

| 用户参考点 | 提示词控制的维度 | 提示词放权的维度（交给参考图） | 生成方式 |
|:---------|:---------------|:---------------------------|:---------|
| 全面参考 | 仅差异部分（书名+必要内容差异） | 画面、色系、构图、画风、光影、字体 | 图生图，最小改动 |
| 色系 | 画面内容+构图+画风+光影+字体 | 配色 | 图生图，不写配色 |
| 构图 | 画面内容+配色+画风+光影+字体 | 构图布局 | 图生图，不写构图 |
| 画风 | 画面内容+构图+字体 | 画风质感（笔触技法+色彩系统+光影氛围+人物精致度） | 放开吸收，只排除具体场景内容+人物长相 |
| 光影氛围 | 画面内容+配色+构图+画风+字体 | 光源设计 | 图生图，不写光源 |
| 字体风格 | 画面内容+配色+构图+画风+光影 | 字体类型、排版风格 | 图生图，不写字体 |
| 色系+构图 | 画面内容+画风+光影+字体 | 配色+构图 | 图生图，不写配色+构图 |
| 无参考图 | 全部维度 | 无 | 纯文生图（V3结构化提示词） |

### 2.2 提示词写法（按参考点分策略）

#### 策略一：全面参考

参考图作为 `image` 参数传入，提示词**只描述需要改的部分**。

**核心原则**：不抢画面控制权。参考图已经是一张完整图，提示词的任务是"微调"而非"重画"。

```
在参考图基础上仅做以下调整：
1. 书名改为"[书名]"，用[字体类型]，[材质质感]，[位置]
2. [其他必要差异，如人物肤色/服饰细节/场景元素]
保持参考图的整体画面、色调、构图、画风不变。
```

**实测注意**：全面参考容易导致"太像原图"（洗稿感）。如果用户反馈太像，转向更细粒度的参考点组合（如只参考色系+构图）。

#### 策略二：单一维度参考（色系/构图/画风/光影/字体）

参考图作为 `image` 参数传入，提示词**在放权维度不写，在控制维度详写**。

**色系参考**（不写配色）：
```
[画面内容详细描述] + [构图描述] + [光影描述] + [画风描述] + [字体描述]
（不写任何颜色/色调词——配色完全交给参考图）
```

**构图参考**（不写构图）：
```
[画面内容详细描述] + [配色描述（成数）] + [光影描述] + [画风描述] + [字体描述]
（不写人物位置/空间布局/层次安排——构图完全交给参考图）
```

**画风参考**（放开吸收公式）：
```
参考这张图的画风质感、色彩系统和光影氛围：柔和数字插画笔触，painterly soft-focus质感，人物精致细腻的画风，[色彩倾向描述]，[光影氛围描述]。
仅排除图中具体场景内容和人物长相——场景里的物品、环境元素、人物五官长相不参考。
以下画面内容完全由本段描述决定：[目标画面详细描述]
```

> **重要**：不要在提示词里堆"不参考"清单（人物/姿态/服饰/场景/构图/配色全排除=等于没参考，实测画风吸收被抑制）。只保留两条最小排除——**具体场景内容**和**人物长相**。其余（姿态、服饰、构图、色彩）都允许参考图自然传导，才能真正吸收画风。吸收要素要落到具体词（笔触技法/色彩倾向/光影语言/人物精致度），不写"参考风格"这种模糊词。

**光影参考**（不写光源）：
```
[画面内容详细描述] + [配色描述] + [构图描述] + [画风描述] + [字体描述]
（不写光源类型/方向/强度——光影完全交给参考图）
```

**字体参考**（不写字体）：
```
[画面内容详细描述] + [配色描述] + [构图描述] + [光影描述] + [画风描述]
（不写字体类型/材质/排版——字体风格完全交给参考图，仅用双引号包裹书名内容）
```

#### 策略三：组合维度参考

多维度组合时，提示词在**所有选定的放权维度**都不写，在**剩余控制维度**详写。

**色系+构图**（不写配色+不写构图）：
```
[画面内容详细描述] + [光影描述] + [画风描述] + [字体描述]
（配色和构图完全交给参考图）
```

**色系+构图+画风**（不写配色+构图+画风）：
```
[画面内容详细描述] + [光影描述] + [字体描述]
（配色、构图、画风完全交给参考图）
```

#### 策略四：纯文生图（无参考图）

无参考图时，使用 V3 结构化提示词，控制全部维度：

```
整体氛围框架（画面是绝对主体）+ 画面内容（远景→前景按层次）+ 文字（最后描述，融入画面）+ 风格
```

### 2.3 多图参考处理

用户可指定多张参考图各取不同参考点（如"pin_003的色系+pin_005的构图"）：

- 每张参考图作为 `image` 参数传入（Seedream 支持多图输入）
- 提示词明确标注每张图的参考范围
- 交叉维度（如色系来自图A、构图来自图B）时，提示词在两个维度都放权

```
参考图A：仅参考其[色系特征描述]
参考图B：仅参考其[构图特征描述]
以下画面内容由本段描述决定：[画面内容+画风+光影+字体]
```

## 3. 翻译为模型提示词

读取 `../pop-visual-shared/references/seedream-prompt-guide.md` 获取提示词写法，然后根据 §2 确定的策略执行翻译。

> **画风DNA来源**：从 `skills/pop-visual-style/references/style-dna-library.json` 取画风的 `dna` + `constraint` 字段。按赛道用 `suggested_genres` 筛选，取 `recommended_lighting` 检查光照兼容性（柔美风格禁用LT1减法照明）。详见 `skills/pop-visual-style/references/lighting-composition-templates.md`。

> **核心原则**：Seedream 5.0 Pro/5.0 lite **画面不再泛白**，简洁精确的提示优于堆砌华丽词汇。用自然语言连贯描述，不堆叠关键词。

### 3.1 V3 结构化提示词公式（纯文生图 / 控制维度全写时）

> **核心发现**（5.0 Pro A/B 实测）：纯文生图质量瓶颈在于提示词缺少"结构信息"。参考图生图效果好，是因为参考图提供了构图骨架+配色比例+字体版式。纯文生图要达到同等质量，必须在提示词中**显式编码这三层结构**。

```
整体氛围框架（画面是绝对主体）+ 画面内容（远景→前景按层次）+ 文字（最后描述，融入画面）+ 风格
```

**翻译规则**：
1. **先整体氛围**：一句话定调画面主体性和整体色彩权重（"画面是绝对主体""X色占七成为底"）
2. **画面内容按空间层次**：从远到近逐层描述，每层内容+光照
3. **文字最后描述**：书名放在画面内容之后，明确"叠于画面[位置]"而非"独占空间"
4. **文字融入策略**：描述文字与画面的物理交互——"底部笔画被前景碎石遮挡""部分笔画被飘散粒子和雾气融合"
5. **配色用"成数"不用百分比**：模型理解"玄黑七成"但无法计算"70%"
6. **指定单一主光源**：写"为画面唯一主光源"，避免多光源混乱
7. **字体要写材质**：书名用双引号包裹 + 字体类型 + 材质质感（鎏金/金石碑刻/飞白枯笔）
8. **文字尺寸不超过三成**：写"占画面高度两成"而非"四成"或"七成"
9. **风格词放末尾**：用"X风格"句式收尾
10. **文化元素极简**：定场诗字号不超过书名的五分之一，印章不超过画面百分之一
11. 中文提示词 ≤400 字

> **放权维度的翻译规则**：当某个维度交给参考图时，**该维度不写任何描述词**。例如用户选了"色系"参考点，提示词中不出现任何颜色/色调词——"暖粉""暖黄""暖色调"全部删除，只描述画面内容、构图、画风。

**翻译示例（V3 全局优先写法）**：

设计方案：
> 书名：玄鉴仙族 | 赛道：暗黑修仙 | 主视觉：族长侧脸+破碎古镜 | 配色：玄黑/青绿/鎏金 | 风格：暗黑国风厚涂

翻译为提示词：
> 暗黑奇幻国风小说封面，竖版构图，画面是绝对主体。整体氛围：幽暗深邃的仙山废墟之夜，玄墨黑为底色占七成，青绿幽光和鎏金铜锈点缀。画面中央偏上是一面破碎的青灰古镜，镜面散发幽冷月白光芒为唯一主光源，裂纹中渗出青绿能量呈放射状扩散。镜中隐约可见修士身影和仙山废墟倒影。右侧族长侧脸半身像，玄色暗金纹路长袍，面容冷峻，受镜光照射轮廓分明。下方三名族人倒三角站位，背光剪影，执剑施法。远景崩塌仙山废墟与暗紫雷云，前景废墟碎石从画面左侧延伸至中央。书名"玄鉴仙族"四字竖排，叠于画面左侧，鎏金毛笔书法体，占画面高度两成，飞白枯笔，金石碑刻龟裂质感，底部笔画被前景碎石微微遮挡，融入画面而非独占空间。厚涂数字油画风格，笔触粗犷厚重可见，类似暗黑魂系列美术质感。

### 3.2 Seedance 提示词翻译（可选，用户要求视频封面时）

**公式**：`主体 + 动作（慢、连贯） + 场景 + 光影 + 镜头语言 + 风格 + 画质 + 稳定性约束`

**翻译规则**：
1. 动作写慢、写碎：用"缓慢""轻柔""连贯"等词
2. 镜头语言明确：推/拉/摇/移/环绕/跟随 + 景别
3. 必加稳定性约束：五官清晰、面部稳定、不扭曲、人体结构正常
4. 必加画质词：4K、超高清、无闪烁
5. 中文提示词 ≤500 字

### 3.3 画风参考的放开吸收公式

当用户参考点为"画风"时，使用放开吸收公式控制吸收范围：

```
参考这张图的画风质感、色彩系统和光影氛围：柔和数字插画笔触，painterly soft-focus质感，人物精致细腻的画风，[色彩倾向描述]，[光影氛围描述]。
仅排除图中具体场景内容和人物长相——场景里的物品、环境元素、人物五官长相不参考。
以下画面内容完全由本段描述决定：[目标画面详细描述]
```

**关键原则**：
1. **正向吸收**：明确列出要吸收的要素——画风质感（笔触技法/渲染方式）+ 色彩系统（色调倾向/饱和度/明暗）+ 光影氛围（光源/氛围/空气感）+ 人物精致度（人物渲染的画风品位）
2. **最小排除**：只排除两样——**具体场景内容**（场景物品/环境元素）和**人物长相**（五官/脸型）。姿态、服饰、构图、色彩都允许参考图自然传导
3. 吸收要素落到具体词（笔触技法/色彩倾向/光影语言/人物精致度），不写"参考风格"这种模糊词
4. 明确声明"以下画面内容由描述决定"，保证主体内容（书名/人物/构图）由提示词控制

**实测示例**（R14 双参考图言情封面，放开吸收）：
> 参考这两张图的画风质感、色彩系统和光影氛围：柔和数字插画笔触，painterly soft-focus质感，人物精致细腻的画风，温暖治愈的色调过渡，通透的日光光效和空气感，明亮甜美的整体氛围。仅排除图中具体场景内容和人物长相。以下画面内容完全由本段描述决定：都市甜宠小说封面……三人三角站位，女主牵萌宝做"嘘"手势，霸总深蓝西装错愕……

**实测结论**：放开吸收后画风传递显著增强（柔和 painterly 笔触、通透光效、暖色调过渡、光斑粒子效果均明显从参考图传导），同时三人三角站位和人物动作仍由提示词精确控制。对比早期"精确分离公式"（排除人物/姿态/服饰/场景/构图/配色）画风吸收被抑制，用户反馈"等于没参考"。

### 3.4 反向强化技巧（当参考图影响过强时）

参考图的强特征会"泄漏"到生成结果。当提示词中的目标方向被参考图覆盖时：

1. **将目标描述提到提示词最前面**（增加权重）
2. **用量化词**："占比不低于40%""大面积"
3. **用禁止词**："完全不使用[参考图的色彩]""禁止[参考图的技法]"
4. **用具体色名替代笼统描述**："朱砂红"而非"红色"

### 3.5 参考图技术注意事项

- `image` 参数必须使用 **data URI 格式**：`data:image/png;base64,<base64数据>`，不能传裸 base64
- 本地图片转换：`base64.b64encode(open(path,'rb').read()).decode()`，再拼上 `data:image/{mime};base64,` 前缀
- 多图输入：Seedream 支持多张参考图，每张图分别标注参考范围

## 5. 执行生图（image_generate 工具）

> 生图不再调用 `generate.py` 直连 API（已移除内置 API Key），统一改用 `image_generate` 工具。图生图时传参考图路径，保证参考点策略生效。

### 5.1 文生图（无参考图）

```text
image_generate(prompt='提示词内容', size='1125x1500', output='素材/视觉/封面-v1.png')
```

### 5.2 图生图（有参考图，按参考点策略）

```text
image_generate(prompt='提示词内容', size='1125x1500', ref_image='素材/视觉/参考图.png', output='素材/视觉/封面-v1.png')
```

### 5.3 多图参考（多张参考图各取不同参考点）

按工具能力传入多张参考图路径，提示词中说明各图参考点，输出到 `素材/视觉/封面-v1.png`。

### 5.4 视频生成（Seedance）

视频生成不在 `image_generate` 工具范围。如需封面动态化，见 `generate.py video` 子命令（需显式设置 `ARK_API_KEY` 环境变量，本脚本不内置 key）。

### 5.5 输出目录

确保输出目录存在：`素材/视觉/`，如不存在则创建。

## 6. 降级机制

生成后检查结果，根据用户反馈降级：

| 问题 | 降级策略 |
|:-----|:---------|
| **太像参考图**（全面参考时洗稿感） | 收窄参考点：从"全面参考"降为"色系+构图"，提示词补回画风+内容描述 |
| **放权维度失控**（如色系参考但颜色偏了） | 该维度从放权降级为控制：提示词补回配色描述，参考图只保留其他维度 |
| **画风吸收不足**（不像参考图） | 放开吸收范围：删掉"仅排除"限制，允许更自由传导；或切换为全面参考 |
| **构图不满意**（参考图构图约束过强） | 构图维度从放权降级为控制：提示词补回构图描述 |
| **全面翻车** | 降级为纯文生图（V3结构化提示词），放弃参考图 |

> 降级时无需再次通过门禁。根据用户反馈调整参考点组合，直接重新生成。输出文件名递增 v2, v3...

## 9. 迭代

如果用户对生成结果不满意：

1. 诊断问题维度——是放权维度偏了，还是控制维度描述不够
2. 调整参考点组合——收窄或放宽参考范围
3. 重新翻译提示词——根据新策略调整放权/控制维度
4. 调用脚本重新生成（输出文件名递增 v2, v3...）
5. 更新提示词记录

常见调整方向：

| 用户反馈 | 诊断 | 调整方向 |
|:---------|:-----|:---------|
| 太像原图（洗稿感） | 全面参考太保守 | 收窄为具体维度参考，提示词补回更多控制 |
| 颜色不对 | 色系放权但参考图色系不适合 | 色系从放权降级为控制，或换参考图 |
| 构图不好 | 构图放权但参考图构图不适合 | 构图从放权降级为控制 |
| 画风不像参考图 | 画风吸收不足 | 放开吸收范围，删掉"仅排除"限制；或检查吸收要素是否落到具体词 |
| 整体气质偏 | 风格词不准确 | 更换风格描述（用风格控制公式） |
| 人物变形 | 无约束 | 添加"五官清晰、人体结构正常"约束 |
| 字体太素 | 字体描述不够 | 用字体控制公式：`[书名] + [字体类型] + [材质/质感] + [色彩层次]` |
