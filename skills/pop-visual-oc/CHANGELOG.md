## v6.0.0 | 2026-08-12

### 简化重构：立绘优先 · 顶部聚字（废弃字槽混合式）

老板定调："走简化方案吧，整个 OC 都重构下，不走复杂 HTML 方案了。但是简单版我要求质量、构图、画风，以及对原文的理解和二创（二创很重要，好看是第一生产力，小说原文描述不一定好看）。" 诊断根因——字槽混合式(v5)要求 AI 直出"短书法字+预留字槽"，实测 **AI 写字不可控**（广蝉"蝉"字压肩颈、正文贴衣袍），多次重试仍不稳定。本版把 skill 收敛为**唯一大范式：立绘优先·顶部聚字**——AI 底图只出纯立绘零文字，HTML 只在顶部纯背景留白区叠少量核心文字，底部一个印章，整图截图即成品。**质量重心从"文字排版"转向"立绘本身"**：构图、画风、原文理解、二创注入。

- **`references/layout.md`（重写）**：由"字槽混合式"改为**立绘优先·顶部聚字**——四律 G1（AI 零文字）/G2（文字顶部聚）/G3（字不压人物）/G4（字少而精）；立绘构图段（直接拼进生图 prompt：主体占60-65%、人物居中下部、顶部≥40%纯净留白、显式声明无第二分身）；文字分工（全部文字 HTML 顶部聚字，不再让 AI 直出任何字）；文字字色（从顶部留白取色）；画风联动（画风库条目DNA 回填 + 画风定字色）
- **`references/content.md`（更新）**：五类信息架构精简为顶部聚字少量文字（立绘/类型标签/名字/称号/金句/印章，总模块≤5）；文案公式精简为称号+金句两个钩子字段 + **稳定性门禁三问**；新增 **二创方法论引导**（指向 `二创-method.md`）
- **`references/二创-method.md`（新建）**：原文理解→好看注入方法论——**二创五问**（魂/符号/姿态/光/记忆点）定立绘 + **好看注入六式**（姿态立魂/光塑情绪/动张显力/物托记忆/藏九露一/反差点睛）+ 二创边界（魂和符号从原文锚定，构图姿态光影由设计者注入）
- **`templates/ocr-1flow.tpl.html`（重写）**：顶部聚字唯一模板——AI 底图铺满画布 + 顶部聚字区（kicker/h1/rule/sub/creed）+ 底部印章（CSS 变量 `--pad-top/--ink/--em/--gold/--seal-*` 取色定位）；五类一张模板
- **`templates/design-plan-oc.tpl.md`（重写）**：新增**二创设计区**（五问 + 立绘构图段）+ 顶部聚字文案表（文字分工=全部 HTML）+ 成图效果预估
- **step0 扩展**：新增二创专用采样（气质锚点/视觉母题/他人评价，供 Step 1 二创注入）
- **step1 重写**：新增**二创设计立绘**（核心，必读 `二创-method.md`，答五问+选招式+写立绘构图段）+ 顶部聚字文案 + 选画风回填DNA
- **step2 重写**：生成纯立绘零文字底图（prompt 明确顶部留白 + 负面清单含 `No text overlay...`）→ HTML 顶部聚字 → 整图截图；自检新增 AI零文字/顶部聚字/字不压人物/字少而精 项
- **SKILL.md 重构**：唯一大范式立绘优先·顶部聚字；铁律收敛为 G1-G5 + ❌1-❌9（新增 G5 二创不可跳过）；速查表新增 `二创-method.md`
- **`_archived/`（归档）**：v5.x 字槽混合式旧文件（README-归档说明.md + layout-字槽混合式-v5.md + ocr-1flow-字槽混合式-v5.tpl.html）归档，不再被引用

## v5.0.0 | 2026-08-10

### 唯一大范式：字槽混合式（废弃旧 HTML 拼接路径）

老板定调："旧路径我建议先干掉，那个有点像网页设计，但我们用户目前用不上，就用这版本新的。" 诊断根因——旧的一图流（mask 融入画布）与画册页/3A（长滚动 HTML 装裱）本质是"网页设计"思维，图与 HTML 拼接生硬割裂（V3 验证暴露：边缘不融合、不像同一张图）。本版把 skill 收敛为**唯一大范式：字槽混合式**——AI 底图直出完整构图（画面主体 + 短书法题字 + 印章 + 预留字槽留白块），HTML 只在预留字槽补长效文字，整图截图即成品。图与字在设计阶段协同规划（先定字槽，再按字槽出图，再在字槽补字）。

- **`references/layout.md`（重写）**：由"两种版面形态"改为**唯一大范式**——字槽混合式 A1-A4 四铁律（A1 图是主角 / A2 字槽规划先行 / A3 信息区不压图 / A4 文字分工守则）；文字分工表（短书法字 AI 直出 vs 长效文字 HTML 补）；字槽规划维度（Step 1 必答）；**跨赛道赛道 token 包**（古风/赛博朋克/都市现代/科幻/暗黑）+ **画风库联动映射**（`文风DNA-library.json` category → 模板 data-track）；画幅与截图；字槽规划要点（Step 2 落进提示词）；技术脚本
- **`references/content.md`（更新）**：顶部范式说明改为字槽混合式；新增**字体系统**（本机已确认中文字体 + font-family 回退写法 + 字体选择规则，铁律❌7）
- **`templates/ocr-1flow.tpl.html`（新建，替代 album-1flow + album-deep 两套旧模板）**：字槽混合式唯一模板——AI 底图铺满画布 + 字槽 overlay（CSS 变量 `--slot-x/-y/-w` 定位对齐底图留白块）+ 本机书法字体补长效文字；**`body[data-track="..."]` 内置 5 套赛道 token 包**（古风/赛博朋克/都市现代/科幻/暗黑，字体/配色/装饰随赛道切换）；五类内容一张模板
- **`templates/album-1flow.tpl.html` / `album-deep.tpl.html`（删除）**：废弃旧 HTML 拼接路径（网页设计思维，图与 HTML 割裂）
- **step0 新增需求确认**：生成前先问内容类型/用途传播场景/画风偏好/是否参考图/画幅比例，避免返工
- **step1 重写**：新增字槽规划（核心，出图前必答）+ **选赛道 + 画风库联动**（按画风库 category 映射模板 data-track 赛道 token）+ 成图效果预估（组装前用 HTML 骨架占位预估最终成品）+ 文字分工标注
- **step2 重写**：生成含字槽底图（提示词明确预留字槽空白块 + 画风库 DNA 回填 + AI 直出短书法字）→ HTML 在字槽补长效文字（赛道 token 应用）→ 整图截图；自检新增字槽干净/字槽对齐/短书法字 AI 直出项
- **`templates/design-plan-oc.tpl.md`（重写）**：新增字槽规划表 + 文字分工列 + 成图效果预估 + 赛道 token/画风库字段
- **SKILL.md 重构**：唯一大范式 + **跨赛道说明**；铁律收敛为 4A + ❌1-❌9（新增 ❌9 跨赛道必选赛道 token）；速查表模板入口改 `ocr-1flow.tpl.html`
- **版本同步**：SKILL.md / skill.json 至 v5.0.0；skill.json 移除"画册页/3A设定集/一图流"旧触发词
