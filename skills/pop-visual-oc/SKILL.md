# pop-visual-oc

> 网文视觉推广素材生成器。OC = 原创设定（Original Creation），不止人物。v7.0.0：steps 三件全合入单文件精炼；执行模式见「怎么运作」。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 做什么

**OC = 原创设定**——不止人物，涵盖一切可视觉化设定实体；从原文系统采样，立体化理解后设计视觉展示。

**输入**：小说项目文件 + 目标实体 + 可选参考图。**输出**：设定档案 + 视觉卡（纯立绘零文字底图 + HTML 顶部聚字 + 整图截图）。

**五类内容类型**（信息架构见 `references/content.md`）：

| 类型 | 视觉主体 | 一句话定位 |
|:-----|:---------|:-----------|
| **人物卡** | 角色本人 | 让读者记住这个人 |
| **势力卡** | 阵营/宗门/家族/王朝 | 让读者记住这群人什么气质 |
| **地理卡** | 城市/秘境/位面 | 让读者记住这个地方什么感觉 |
| **规则卡** | 力量体系/境界/功法 | 让抽象规则被"看到" |
| **场景卡** | 关键场景/名场面 | 让读者记住这个高光时刻 |

**唯一大范式：立绘优先 · 顶部聚字（V6，全 OC 质量基准）**

> **AI 底图只出纯立绘零文字**（主体占画面≥60%，居中下部，顶部留≥40%纯净背景）→ **HTML 只在顶部纯背景区叠少量核心文字**（类型/名字/称号/一句金句）+ **底部一个印章** → 整图截图即成品。**质量重心从"文字排版"转向"立绘本身"**。

**范式依据（2026-08 老板定稿）**：字槽混合式（v5）实测 **AI 写字不可控** → **不让 AI 承担任何"落实文字"的活**；质量聚焦构图/画风/原文理解/二创注入（好看是第一生产力，原文描述不一定好看），放弃复杂 HTML 排版。

**核心原则**：四律 G1-G4 + 二创 G5（完整约束见铁律表）。

**二创是 OC 的灵魂**：原文理解→好看注入见 `references/二创-method.md`（Step 1 必读）——从原文提取气质锚点/核心意象，构图/姿态/光影/动作张力/记忆点由设计者注入，不被原文朴素描述捆住。

**视觉真源**：视觉本体来自 `pop-visual-art-bible` 美术设定集对应篇（唯一真源，用最新版防跨版本 gap），OC 只负责"怎么画好看 + 顶部叠少量文字"，**禁止重建设定身份**；构图/姿态/光影由二创注入。

## 怎么运作（SOP全内联）

**执行模式**：门禁A（档案确认）/门禁B（方案对齐）需用户交互确认，设计/生图/组装/截图**主agent直执**；Step 0 原文采样调研（Grep+Read 只读工作）可派子agent执行并回报采样结果，主agent整理落盘。

### Step 0: 需求确认 + 设定调研

**需求确认**（生成前必问，一次性问清）：内容类型（五类卡哪类，不明确按实体推荐）｜用途/传播场景（社交单图/封面/设定集，影响画幅与信息密度）｜画风偏好（可参考图标定）｜是否参考生图（全面/画风/纯文生图）｜画幅（2:3 竖版默认/4:3/16:9）。结果记入 `_过程/提示词记录.md`；无明确偏好用默认值直接进调研，不为低影响偏好反复打扰。

**资产检查（优先路径）**：LS 扫描 `素材/视觉资产/` 找对应档案——人物=`[角色名]角色档案.md`（10维度）/势力=`[势力名]势力档案.md`（8）/地理=`[地名]地理档案.md`（7）/规则=`[规则名]规则档案.md`（6）/场景=`场景资产表.md`（帧）。存在→校验维度完整→直接门禁A；不存在→提示可先跑 `pop-visual-asset`，或走原文采样（**找不到原文文件必须问用户，禁止凭记忆设计**）。

**原文采样（回退路径）**：Grep 按类型轮次搜索（关键词模板，示例实体名）：

| 类型 | 轮次 | 关键词模板 |
|:--|:--|:--|
| 人物 | 5轮 | 角色名 / `名.*(眸\|眼\|甲\|氅\|袍\|发)` / `名.*(霸道\|冷\|笑\|怒)` / 他人评价 / `名.*(父亲\|部下)` |
| 势力 | 4轮 | 势力名 / `名.*(宗门\|家族\|王朝\|教派)` / `名.*(弟子\|族人\|信众)` / `名.*(峰\|城\|宫\|殿\|谷)` |
| 地理 | 4轮 | 地名 / `名.*(山\|海\|渊\|宫\|界\|域)` / `名.*(雾\|光\|暗\|冷\|热)` / `名.*(楼\|殿\|塔\|桥\|街)` |
| 规则 | 4轮 | 规则名 / `名.*(光\|纹\|阵\|雷\|焰\|雾\|印记)` / `名.*(突破\|天象\|雷劫\|金光)` / `名.*(印\|镜\|书\|卷\|符\|剑)` |
| 场景 | 帧定位 | `到了\|进入\|来到\|眼前` / 颜色+器物+动作共现 / `怒\|笑\|吼\|惊` |

每个命中 Read 前后 20-50 行，采样**三层**：表层（外貌/美学/空间描述，画皮）/中层（气质/秩序/氛围，画骨）/深层（评价/隐喻/意象，画魂），每维度≥3-5条佐证记录行号。**二创专用采样**：另记气质锚点（性格/身份/处境最核心一点）、核心意象/视觉母题（贯穿符号如蝉/碑/麒麟）、他人评价/标志台词（可提炼金句）——Step 1 二创注入的原料，**魂和符号必须从原文锚定**。

**设定档案**：整理为 `素材/[类型][实体名]档案.md`；方法论：人物=character-research-guide，势力/地理/规则=asset-extract-guide §五/§六/§七（完整路径见速查表·调研方法论）。

**🚪 门禁A：设定档案确认**（强制暂停，禁止跳过）——向用户呈现：核心气质｜关键视觉特征（带原文佐证）｜最适合做卡的内容｜核心意象（3-5符号）｜代表词口号。**等用户确认后才进 Step 1**；档案存 `素材/`，确认结果追记 `_过程/提示词记录.md`。

### Step 1: 设计（二创设计 + 顶部聚字 + 成图预估）

> 内容见 `references/content.md`（五类信息架构+文案公式+字体系统）；排版见 `references/layout.md`；二创见 `references/二创-method.md`（**设计立绘前必读**）。

**读取输入**：Step 0 需求 + 设定档案（气质/视觉/意象/金句）+ 美术设定集对应篇（`素材/美术设定集.md`，用最新版）。画幅 2:3 竖版默认，可改 4:3/16:9。

**二创设计立绘（核心·质量第一来源）**：好看是第一生产力，立绘是绝对主角。先答**二创五问**，再按**好看注入六式**选招式：

| 五问 | 答案（写入方案） |
|:--|:--|
| ① 他的魂是什么？ | 性格/身份/处境最核心的一点（原文锚定） |
| ② 他的符号是什么？ | 贯穿的视觉母题/意象（原文锚定，如蝉/碑/麒麟） |
| ③ 他该是什么姿态？ | 用姿态外显①——骄傲就昂首，阴冷就垂眸，癫狂就咧嘴 |
| ④ 他该是什么光？ | 用光影营造②的情绪——神性就金光，压抑就暗部，凄美就冷月 |
| ⑤ 让他多难忘？ | 一个记忆点动作/特效/氛围物，让读者 0.3 秒记住 |

再写**立绘构图段**（Step 2 直接拼进生图 prompt）：主体（全身/半身+姿态+视角，占画面约60-65%）｜位置（居画面中下部，脚部约10%，头顶垂直约55%）｜顶部留白（顶部40%纯净背景，**显式声明"无任何元素、无第二分身、无杂物"**防 AI 画气流/分身/光效污染文字安全区；人物本体禁止侵入）｜记忆点（二创注入）。

**顶部聚字文案**（钩子优先，按 content.md §文案公式填，**禁止介绍句**；五字段对应 `ocr-1flow.tpl.html` 占位符）：

| 字段（占位符） | 公式 | 约束 |
|:--|:--|:--|
| 类型标签（`{{kicker}}`） | 系列名+类型（如"玄鉴仙族·人物卡"） | ≤10字 |
| 名字/标题（`{{name}}`） | 实体名（鎏金大字） | 第一权重，楷体 |
| 称号/定位（`{{subtitle}}`） | 最有记忆点的反差/强力特征 | ≤8字，仿宋/隶书 |
| 金句/箴言（`{{creed}}`，可选） | 「[动作/交易]，换/成/得[结果]」，有代价/反转 | ≤16字，钩子，仿宋 |
| 印章（`{{seal}}`/`{{seal_cap}}`） | 专属印章（人名朱文/族徽/地标/规则符印/场景图腾） | 印文≤4字，底部，避开人物下摆 |

**文案稳定性门禁**（组装前必过）：① 有钩子吗？② 圈外人3秒懂吗？③ 字少吗（总模块≤5）？任一不通过回写修正。**文字分工（v6）**：全部文字由 HTML 顶部聚字，AI 底图零文字（G1），印章由 HTML 底部叠（G2）。

**成图效果预估（组装前必填）**：生图前用 HTML 骨架占位（`ocr-1flow.tpl.html`）预估加字后的成品——文字大小/间距/是否在留白区内/与头顶≥7%间距/颜色是否融入底图。门禁B 呈现的是"成图预期"而非文字描述。

**系列化规划（如需）**：一份档案驱动 N 张图，填 `templates/design-plan-oc.tpl.md` 系列表；冻结特征见铁律 ❌3，变量=服饰/场景/姿态/文字层。

**选画风 + 回填生图 DNA**：从 `skills/pop-visual-style/references/文风DNA-library.json` 按赛道+气质选最匹配条目（玄幻→国漫玄幻厚涂、暗黑→暗黑奇幻油画）→ 回填 `dna`/`constraint`/`recommended_lighting` 供生图 → **据画风定字色**（浅留白深字/深留白浅字）；产出记入方案（画风条目/DNA来源/底色倾向）。**画风不匹配再好的构图也白搭**（质量第二来源）。

**可选 Pinterest 参考**：气质参考图（档案够用即跳过）；画风参考用放开吸收公式（只排除场景+长相）。

**🚪 门禁B：方案对齐**（强制暂停，禁止跳过）——向用户呈现：类型+画幅｜设定理解（核心气质+冻结特征）｜**二创设计方案**（五问+构图段）｜**聚字文案**（过稳定性门禁）｜**画风条目+字色**｜**成图效果预估**（HTML 骨架预览）。**等用户确认后才进 Step 2**；方案追记 `_过程/提示词记录.md`，填 `design-plan-oc.tpl.md`。

### Step 2: 生成纯立绘零文字底图 + 顶部聚字 + 截图

**读输入**：`_过程/提示词记录.md` 上一版确认方案（二创设计/聚字文案/画风DNA/冻结特征/参考图/画幅）。

**生成纯立绘零文字底图**（🔴 主视觉 pop 直出 `image_generate`，无该工具暂停等待——❌5）。提示词按 layout.md §立绘构图组装，画风用 Step 1 条目 DNA 回填：

```
[画风 DNA（Step 1 条目回填，无匹配时按赛道写质感）]
[主体：<实体>全身/半身立绘，姿态<N>，视角<正面/侧身/仰角>，占画面约60-65%]
[位置：人物居画面中下部，脚部在画面底部约10%，头顶在画面垂直约55%]
[顶部留白：画面顶部40%为纯净背景色，无任何元素、无第二分身、无杂物，用于后续叠加标题]
[记忆点：二创注入的动作张力/特效/氛围物]
[环境/光源/氛围]
[硬约束：负面清单（含 No text overlay, no text, no letters, no watermark, no seal）+ 冻结特征清单]
```

有参考图按意图选模式（详见 prompt-guide §三）：模式A 全面参考（提示词≤200字只改差异）/模式B 画风参考（放开吸收只排除场景+长相）/模式C 纯文生图。

```
image_generate(prompt='[提示词]', size='1125x1500', ref_image='[参考图，如有]', output='测试/{类型}/{类型}-{实体名}-v1.png')
```

出图后**检查顶部留白纯净**：被气流/分身/光效污染或出现文字/水印 → 回写重出（v2, v3...），顶部不净直接打回。

**HTML 顶部聚字**：复制底图到 `测试/{类型}/`，用 `templates/ocr-1flow.tpl.html` 组装（唯一模板，CSS 变量驱动五类+画风；占位符见 Step 1 文案表，底图填 `{{visual_path}}`；字色 `--ink/--em/--gold` 从顶部留白取色；画幅 `--cv-w/--cv-h` 与底图一致，改横版同步改截图 width）。组装约束：文字只落顶部纯背景（G2）与人物头顶≥7%间距（G3），不够则调小字号/上移**禁止压人物**；印章避开人物下摆必要时并入顶部；同一张卡最多2种字体。

**截整图**（2:3 竖版默认）：

```
SCREENSHOT_WIDTH=1125 SCREENSHOT_SCALE=2 python scripts/screenshot_album.py '<html>' '<out.png>'
```

**失败中断**：文字溢出顶部留白/文字压到人物/顶部留白不净/底图出现文字，任一即截图失败，修正后重截，**禁止带残缺交付**。

**落盘三态**：候选 `测试/{类型}/`，用户确认后复制到 `成品/{类型}/`（加 `-final`）；HTML+成品图 `成品/{类型}/{类型}-{实体名}-{形态}.html` + `-成品.png`；设计记录追加 `_过程/提示词记录.md`（模型/类型/实体/形态/参考模式/提示词/二创设计/冻结特征/输出/状态）。

**系列化循环（如需）**：对系列表每张图复制冻结特征（HARD CONSTRAINTS 块）→ 更新变量 → 重组提示词 → 生成（v2, v3...）→ 一致性检查（冻结特征不变+顶部留白仍纯净）。

**自检**：G1-G4 全过｜冻结特征嵌 HARD CONSTRAINTS｜文案过稳定性门禁｜字体≤2种｜截图无溢出｜落盘三态+记录回写。

**迭代快速路径**：改已生成图跳过 Step 0/1，直接读 `_过程/提示词记录.md` 上一版方案改对应维度重生成（v2, v3...）；仅"重新设计/换方向"回完整流程。

## ❌ 铁律

| # | 铁律 | 违反后果 |
|:-:|:-----|:--------|
| **G1** | **AI 底图零文字** — 提示词负面清单必须含 no text 类硬约束（见 Step 2 prompt 结构），禁止让 AI 直出任何字 | 字乱码/压人物，卡毁掉 |
| **G2** | **文字顶部聚** — 全部文字收敛到顶部纯背景区（顶部 ≥40% 纯净留白），底部只留一个印章 | 字没地方放，压人物 |
| **G3** | **字不压人物** — 文字只落纯背景，与人物头顶保持 ≥7% 画布间距 | 主体被遮挡，失去焦点 |
| **G4** | **字少而精** — 总文字模块 ≤5，称号≤8字、金句≤16字，不做大段正文 | 信息过载，立绘沦为背景 |
| **G5** | **二创不可跳过** — 设计立绘前必读 `references/二创-method.md`，答二创五问 + 选好看注入招式；魂和符号从原文锚定，构图姿态光影由设计者注入 | 立绘平庸，好看第一位落空 |
| ❌1 | **角色调研不可跳过** — 必须从原文系统性采样设定，形成档案（含气质锚点/视觉母题），禁止凭记忆/想象设计 | 形象扁平，偏离原著 |
| ❌2 | **两个门禁不可跳过** — 门禁A（档案确认）和门禁B（方案对齐，含二创设计+成图预估）必须等用户确认 | 理解偏差，浪费生成次数 |
| ❌3 | **系列一致性** — 系列图冻结核心特征（人物=眼瞳/轮廓/气质；势力=阵营美学；地理=空间氛围；规则=视觉外显；场景=场景基调），只变服饰/场景/姿态 | 同一设定不同图认不出来 |
| ❌4 | **落盘三态** — 档案进 `素材/视觉资产/`；方案+提示词进 `_过程/提示词记录.md`；候选 `测试/`→确认后 `成品/` | 无法迭代和系列扩展 |
| ❌5 | **主视觉必须 pop 直出** — 用 `image_generate` 工具，不用本地/替代生图工具；无 `image_generate` 时暂停等待 | 画面质量远不及 pop 直出 |
| ❌6 | **文案按公式填** — 文案按 `references/content.md` 公式填写，组装前必过稳定性门禁（有钩子/圈外人3秒懂/字少），禁止介绍句无钩子文案 | 文案时好时坏，卡退化成说明书 |
| ❌7 | **字体用本机书法系统** — HTML 补字用本机已装书法字体（楷体/仿宋/隶书/宋体），同一张卡最多 2 种字体；字体系统见 `references/content.md` §字体系统 | 字体不可控或乱码 |
| ❌8 | **AI 画风做减法** — 写意留白 > 满铺细节，克制精致、真实质感，禁止"过度精致"（毛发过度渲染/算法对称脸/塑料质感） | 失去差异化辨识度，被竞品淹没 |
| ❌9 | **画风决定一切** — 必须从 `文风DNA-library.json` 选画风条目并回填 DNA，画风定立绘质感与顶部留白字色；无匹配时按赛道写质感 | 画风漂移，再好的构图也白搭 |
