# pop-visual-oc

> 网文视觉推广素材生成器。OC = 原创设定（Original Creation），不止人物。v5.0.0

## 做什么

**OC = 原创设定**，天然涵盖一切可视觉化的设定实体——人物只是其中一类。从小说原文系统采样设定，立体化理解后设计视觉展示。

**输入**：小说项目文件 + 目标实体 + 可选参考图。**输出**：设定档案 + 视觉卡（AI 底图 + HTML 字槽补字 + 整图截图）。

**五类内容类型**（信息架构见 `references/content.md`）：

| 类型 | 视觉主体 | 一句话定位 |
|:-----|:---------|:-----------|
| **人物卡** | 角色本人 | 让读者记住这个人 |
| **势力卡** | 阵营/宗门/家族/王朝 | 让读者记住这群人什么气质 |
| **地理卡** | 城市/秘境/位面 | 让读者记住这个地方什么感觉 |
| **规则卡** | 力量体系/境界/功法 | 让抽象规则被"看到" |
| **场景卡** | 关键场景/名场面 | 让读者记住这个高光时刻 |

**唯一大范式：字槽混合式 · 载体范式（V4，全 OC 质量基准）**

> AI 底图直出**设定载体页面**：**载体材质（卷轴/羊皮纸等无具象元素的信息面，不是具体场景）→ 画面内容错落拼贴（主角多视图/局部特写/武器特效）→ 留白区（载体上无元素处）**。HTML 只在留白区补长效文字，整图截图即成品。**图与字在设计阶段协同规划**——先定载体与留白区，再按载体出图，再在留白区补字。

**留白定义（V4 定稿）**：留白 ≠ 空白/纯色，留白 = 载体上没有"重要信息元素"的区域。具象内容（场景建筑/街巷/窗户/道具/人物）都是重要信息元素，不能当背景盖字；画面应是"设定载体/图鉴页"——纸底无具象元素、重要信息错落拼贴、无元素处才是字槽。详见 `references/layout.md` §什么是"留白"。

**文字分工（两种，各司其职）**：

| 文字类型 | 由谁承载 | 约束 |
|:---------|:---------|:-----|
| **短书法字**（标题/副题/印章/器物标签） | AI 直出，融入画面 | 每处≤4字，用书法体，天生不会乱码 |
| **长效文字**（金句/小传/词条说明/落款） | HTML 在预留字槽补 | 放 AI 预留的干净留白块，用本机书法字体 |

> 为什么这样分工：短书法字 AI 直出效果好且融入画面（已验证 V3 底图自带"李周巍/明煌"等字完美）；长文字若 AI 直出必乱码，交给 HTML 在预留字槽补，既可控又绝不乱码。

**跨赛道**：字槽混合式这条**载体机制赛道无关**，跨赛道只换**文字风格层**——模板 `body[data-track="..."]` 内置 5 套赛道 token（古风/赛博朋克/都市现代/科幻/暗黑），按画风库 `category` 映射。详见 `references/layout.md` §跨赛道。

## 怎么运作（SOP）

1. **Step 0 需求确认 + 设定调研** → `steps/step0-setting-research.md`：确认用途/传播场景/画风偏好/是否参考图 → 优先读 `素材/视觉资产/` 已有档案，无则原文采样（Grep 关键词→上下文采样→按类型维度整理档案）→ **🚪门禁A：档案确认**
2. **Step 1 设计（含成图预估）** → `steps/step1-design.md`：选类型 → 按 `references/content.md` 填文案 SOP → **字槽规划**（图哪些区域留白、要哪些元素、是否参考生图）→ **选赛道 + 画风库联动**（按画风库 `category` 映射模板 `data-track` 赛道 token）→ **成图效果预估**（HTML 骨架占位，预估最终效果）→ **🚪门禁B：方案对齐**
3. **Step 2 生成 + 补字** → `steps/step2-generate.md`：`image_generate` 直出含字槽底图（prompt 明确预留字槽空白块）→ HTML 在字槽补长效文字（本机书法字体）→ `screenshot_album.py` 整图截图 → 落盘三态 → 系列化循环

**视觉真源**：所有类型视觉本体来自 `pop-visual-art-bible` 美术设定集对应篇（唯一真源），OC 只负责构图+文字叠加，**禁止重建设定身份**。用最新版（防跨版本 gap）。

**迭代快速路径**：用户要求改已生成图时跳过 Step 0/1，直接读 `_过程/提示词记录.md` 上一版方案改对应维度重生成（v2, v3...）。

## ❌ 铁律

| # | 铁律 | 违反后果 |
|:-:|:-----|:--------|
| **A1** | **图是主角** — AI 底图是画面唯一主体，构图饱满、边界完整；HTML 只是字槽补字层，不抢画面 | 图沦为背景，失去传播力 |
| **A2** | **字槽规划先行** — 生成前必须先定"图哪些区域留白给文字/要哪些元素"，提示词明确预留字槽空白块；未规划就出图 → 文字没地方放 | 文字硬压画面，割裂 |
| **A3** | **信息区不压图** — 长效文字只放 AI 预留字槽/留白块，不遮挡图主体；短书法字由 AI 融入画面 | 主体被遮挡，失去焦点 |
| **A4** | **文字分工守则** — 短书法字（标题/印章/器物标签）AI 直出融入画面；长效文字（金句/小传/词条/落款）必须 HTML 在字槽补，禁止让 AI 直出长文字 | 长文字 AI 必乱码，卡毁掉 |
| ❌1 | **角色调研不可跳过** — 必须从原文系统性采样设定，形成档案，禁止凭记忆/想象设计 | 形象扁平，偏离原著 |
| ❌2 | **两个门禁不可跳过** — 门禁A（档案确认）和门禁B（方案对齐，含成图预估）必须等用户确认 | 理解偏差，浪费生成次数 |
| ❌3 | **系列一致性** — 系列图冻结核心特征（人物=眼瞳/轮廓/气质；势力=阵营美学；地理=空间氛围；规则=视觉外显；场景=场景基调），只变服饰/场景/姿态 | 同一设定不同图认不出来 |
| ❌4 | **落盘三态** — 档案进 `素材/视觉资产/`；方案+提示词进 `_过程/提示词记录.md`；候选 `测试/{类型}/`，确认后 `成品/{类型}/` | 无法迭代和系列扩展 |
| ❌5 | **主视觉必须 pop 直出** — 用 `image_generate` 工具，不用本地/替代生图工具；无 `image_generate` 时暂停等待 | 画面质量远不及 pop 直出 |
| ❌6 | **文案按公式填** — 文案 SOP 四模块（定位线/箴言/机制/体系）必须按 `references/content.md` 公式填写，组装前必过稳定性四问，禁止介绍句无钩子文案 | 文案时好时坏，卡退化成说明书 |
| ❌7 | **字体用本机书法系统** — HTML 补字用本机已装书法字体（楷体/仿宋/隶书/宋体），不使用 Trae 独有或 ds 直出（不存在）；字体系统见 `references/content.md` §字体系统 | 字体不可控或乱码 |
| ❌8 | **AI 画风做减法** — 写意留白 > 满铺细节，克制精致、真实质感，禁止"过度精致"（毛发过度渲染/算法对称脸/塑料质感） | 失去差异化辨识度，被竞品淹没 |
| ❌9 | **跨赛道必须选赛道 token** — 模板 `body[data-track]` 按画风库 `category` 映射赛道（古风/赛博朋克/都市现代/科幻/暗黑），禁止古风模板套一切 | 赛博/都市/科幻赛道违和，卡毁掉 |
