# _archived 归档说明

> 本目录归档 pop-visual-oc **v5.x 字槽混合式**旧版范式文件，仅作历史参考，**不再被 SKILL.md/SOP 引用**。

## 归档原因（2026-08 老板定稿）

字槽混合式要求 AI 底图直出"短书法字 + 预留字槽"，HTML 在字槽补长效文字（金句/小传/词条/落款）。实测证明 **AI 写字不可控**——字形/位置/是否压人物全由模型决定，多次重试仍不稳定（广蝉"蝉"字压肩颈、正文贴衣袍）。判定该方案不可靠，降级为「立绘 + 顶部聚字」简化路线。
