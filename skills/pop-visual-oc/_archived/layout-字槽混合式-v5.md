# 版面范式总纲（字槽混合式 · v5 归档）

> **2026-08 老板定稿：本范式废弃。** 字槽混合式要求 AI 底图直出"短书法字 + 预留字槽"，HTML 在字槽补长效文字。实测 AI 写字不可控（字形/位置/压人物全由模型决定），判定不可靠，降级为「立绘 + 顶部聚字」简化路线。本文件仅作历史参考，不再被 SOP 引用。新范式见重写后的 `references/layout.md`。

## 旧范式陈述（历史记录）

> OC 的**唯一大范式**（V4）：AI 底图直出**设定载体页面**（载体材质 + 错落拼贴的画面内容 + 预留留白区），HTML 只在**留白区**补长效文字，整图截图即成品。

### 什么是"留白"（旧 V4 定稿）

> 留白 ≠ 空白/纯色。留白 = 载体上没有"重要信息元素"的区域。画面本身是一张"设定载体/图鉴页"，纸底用无具象信息元素的材质（卷轴/羊皮纸等），"重要信息元素"错落拼贴在纸底上，纸底没被内容占用的区域才是字槽。

### 旧文字分工

| 文字类型 | 由谁承载 | 约束 |
|:---------|:---------|:-----|
| 短书法字（标题/副题/印章/器物标签） | AI 直出 | 每处≤4字 |
| 长效文字（金句/小传/词条说明/落款） | HTML 在预留字槽补 | 放 AI 预留的字槽 |

### 旧载体范式三要素

| 要素 | 说明 |
|:-----|:-----|
| 载体材质 | 卷轴/羊皮纸等无具象内容的信息面 |
| 画面内容 | 主角多视图/局部特写/武器特效错落拼贴 |
| 留白区 | 载体上没被内容占用的干净区域 |

### 旧字槽混合式铁律（A1-A4）

- A1 图是主角 / A2 字槽规划先行 / A3 信息区不压图 / A4 文字分工守则

### 旧跨赛道 token 包

5 套赛道（古风/赛博朋克/都市现代/科幻/暗黑），`body[data-track]` 切换字体与配色。
