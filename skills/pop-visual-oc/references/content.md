# 内容方法论（五类信息架构 · 文案 SOP · 视觉系统 · 字体系统）

> 配合 `layout.md`（怎么排版）使用。本文件定义**放什么内容**：五类实体各自的信息架构、文案写法公式、印章/题诗/花语等视觉系统素材，以及 HTML 补字的字体系统。所有内容统一按 `layout.md` 字槽混合式大范式承载（短书法字 AI 直出，长效文字 HTML 在预留字槽补）。

## 五类内容类型（OC 的完整边界）

| 类型 | 视觉主体 | 一句话定位 | 消费的美术设定集篇 |
|:-----|:---------|:-----------|:------------------|
| **人物卡** | 角色本人 | 让读者记住这个人 | 人物篇 |
| **势力卡** | 阵营/宗门/家族/王朝 | 让读者记住这群人是什么气质 | 势力篇 |
| **地理卡** | 城市/小世界/秘境/位面 | 让读者记住这个地方什么感觉 | 地理篇 |
| **规则卡** | 力量体系/境界/功法/禁忌 | 让抽象规则被"看到" | 规则篇 |
| **场景卡** | 关键场景/名场面瞬间 | 让读者记住这个高光时刻 | 场景篇（+符号篇） |

> **视觉真源**：所有类型的视觉本体一律来自 `pop-visual-art-bible` 美术设定集对应篇（唯一真源）。OC 只负责"怎么摆进版式、叠加什么文字文化元素"，**禁止重建视觉事实**。

## 一、人物卡

> 人物是信息量最大的类型。角色是绝对主体，文字是"注释"不是主角。**做正式推广一律走 HTML 大范式**（字/色板/tag 全由 HTML 承载，主视觉只画角色本人）。

### 人物卡 HTML 信息架构（字/色板/tag 全 HTML 承载）

| 模块 | 内容 | 说明 |
|:-----|:-----|:-----|
| **主视觉（无文字）** | 角色立绘（复用美术设定集人物篇本体） | 角色占画面主体≥60%，四周留呼吸空间 |
| **顶部标题区** | 系列名 / 类型标签 / 角色名（鎏金大字）/ 身份定位 | 角色名信息第一权重 |
| **称号** | 四字格称号（方框衬底） | 一句话点出角色厉害在哪 |
| **属性栏** | 境界/阵营/煞兽/秘法/命格（≤4字/项，5-6项） | 硬核设定，可收藏 |
| **配色板** | 角色代表色 seratch（无字仅色块） | 视觉记忆点，可二创取色 |
| **花语象征** | 代表花 + 花语短句（≤8字） | 文化隐喻 |
| **台词** | 角色代表性台词（≤15字） | 情感共鸣，可截图传播 |
| **题诗** | 七言对仗（意象驱动法） | 升华角色意境 |
| **小传** | 60-100字微型人物志 | 核心信息层，HTML 精确排版 |
| **表情差分** | 2-4 个表情/状态小图（可选） | 角色鲜活度 |

**人物卡三铁律（P1-P3）**：
- **P1** 主视觉零文字零标签零色板 — 角色名/称号/属性/色板/tag/台词一律 HTML 承载，禁止 AI 渲染在人物图上
- **P2** 信息区全部在图框之外，不压角色主体
- **P3** 角色是绝对主角（占画面≥60%）

### 人物卡多表达图格（默认启用）

主视觉之外挂 2-5 个表达图格，打破单图单调，对标参考表"主视觉+多图格"结构。图格之间用**同一张脸**（眼瞳/轮廓/气质/关键配饰）锁定一致性，是同一角色的不同切面，不是两个角色。

| 图格类型 | 展示什么 | 图格比例 | 视觉张力 |
|:---------|:---------|:---------|:---------|
| **多状态 state** | 慈悲态/煞化态/战斗态/觉醒态 | 3:4 竖图 | 反差、蜕变、隐藏实力 |
| **多视角 view** | 正面/背面/侧脸/特写 | 1:1 方图 | 完整性、专业参考感 |
| **日常向 daily** | 佛前缝衣/市井采买/月下小酌 | 4:3 横图 | 亲近、可代入、生活切片 |

> 至少挂 1 类（2 格以上），最多 2 类 5 格。图格零文字，标注全由 HTML 承载。

## 二、势力卡 / 三、地理卡 / 四、规则卡 / 五、场景卡

> 设定实体卡是**推广物料/世界观名片**，不是说明书。目标是让读者 3 秒记住"这个势力/地方/规则/场景是什么感觉"。

### 势力卡

| 模块 | 内容 | 设计目标 |
|:-----|:-----|:---------|
| **主视觉** | 势力代表形象（建筑群/战旗阵列/标志地貌/代表角色） | 一眼识别阵营气质 |
| **势力名+定位** | 势力名 + 一句话定位（≤8字） | 3秒知道这是谁 |
| **阵营美学** | 标志色块 + 纹饰风格（从美术设定集势力篇取） | 视觉记忆点 |
| **象征体系** | 旗帜/纹章/族徽图腾 | 可二次创作的符号 |
| **宣言/口号** | 一句代表宣言（≤15字） | 情感共鸣 |
| **等级/结构** | 阶层划分的视觉外显（可选） | 世界观体系感 |

### 地理卡

| 模块 | 内容 | 设计目标 |
|:-----|:-----|:---------|
| **主视觉** | 地理地标/空间氛围全景 | 一眼记住这个地方 |
| **地名+定位** | 地名 + 一句话定位（≤8字） | 3秒知道这是哪 |
| **氛围基调** | 代表色块 + 光线情绪（从美术设定集地理篇取） | 空间记忆点 |
| **标志性地标** | 2-4个可定格节点名 | 可探索的代入感 |
| **当地生灵** | 居民/生物/文明形态（可选） | 世界观活性 |
| **象征隐喻** | 一句情绪/隐喻短句（≤15字） | 情感共鸣 |

### 规则卡

> 规则卡最难画——抽象规则没有天然形象。**必须从美术设定集规则篇的原文视觉外显（光效/纹路/器物/天象）提取具象载体**，禁止凭空发明与原文无关的符号。

**可视化策略（三选一，从规则篇取）**：器物载体（印/镜/书/卷/符/剑）/ 天象异象（突破/雷劫/金光）/ 符号纹路（符纹法阵）/ 组合。

| 模块 | 内容 | 设计目标 |
|:-----|:-----|:---------|
| **主视觉** | 规则载体（器物/天象/纹路） | 让抽象规则被"看到" |
| **规则名+定位** | 规则名 + 一句话定位（≤8字） | 3秒知道这是什么 |
| **层级可视化** | 境界/层级 + 各自视觉奇观（可选示意） | 力量体系感 |
| **外显色板** | 规则表现的代表色块 | 力量色彩记忆点 |
| **器物/符号** | 承载规则的具体器物/符号 | 可二次创作 |
| **规则一句话** | 规则 DNA 的一句话（≤15字） | 提炼记忆点 |

### 场景卡

| 模块 | 内容 | 设计目标 |
|:-----|:-----|:---------|
| **主视觉** | 场景高光瞬间（从美术设定集场景篇取可定格帧） | 一眼进入那个时刻 |
| **场景名+定位** | 场景名 + 一句话定位（≤8字） | 3秒知道这是什么时刻 |
| **氛围基调** | 代表色块 + 光影情绪 | 现场感 |
| **关键元素** | 参与角色/器物/符号（可选） | 剧情代入 |
| **情境一句话** | 一句高光台词/情境（≤15字） | 情感共鸣 |

### 文字密度铁律（所有设定实体卡通用）

总模块≤7，属性/标签每项≤4字、实体名+定位≤8字、口号/隐喻/台词≤15字。信息量过大宁可减少模块数，禁止塞满导致信息过载。

## 文案设计规范（文案 SOP，全 OC 稳定性基准）

> 不稳定根因是没按公式写。**组装 HTML 前四个文案模块必须按公式填写**，禁止自由发挥平铺直叙的介绍句。

**核心架构：钩子架构三明治**——从圈外人视角，卡片阅读动线是"先被钩住 → 再懂机制 → 最后消化体系"，四个模块各司其职：

```
定位线 positioning  ← 一句话点出"这设定最反直觉/最核心的悖论"
箴言   creed        ← 钩子：一句有代价/反转的台词，0.3秒抓眼球
机制   core         ← 人话：一段讲清"它是什么 + 为什么厉害"，读完能复述
体系   ranks/symbols ← 结构化：层级递进 + 象征键值对，能"认物"
```

### 文案字段写法公式（对标「借香他化」成功成品）

| 字段 | 公式 | 圈外人可读判据 |
|:-----|:-----|:-------------|
| **定位线 positioning** | `[核心元素]即[本质] · [命运/结果]` 或 `[反差A]·[反差B]` | 一句话点出核心悖论，≤14字 |
| **箴言 creed（钩子）** | `「[一个具体动作/交易]，换/成/得 [一个结果]」`——必须有交易感、代价或反转 | 是台词/宣言，**不是介绍句**，≤16字 |
| **机制 core** | `[它在哪个体系]：谁做了什么→换来什么→代价/反转` | 圈外人读完能用自己的话复述；句式"设定名词+冒号+白话解释" |
| **体系 ranks（层级）** | name=层级名（≤5字），desc=该层一句话（≤8字），从低到高递进 | 构成一条能看懂的"成长/递进"链 |
| **体系 symbols（象征）** | 键=能"看/摸/认"的实物，值=它在世界观里意味着什么（≤12字） | 键是具象物，值是"它对这个设定意味着什么" |

**成功标杆（「借香他化」规则卡）**：
- 定位线：`香火即欲念 · 念头为王`
- 箴言：`「一炷香，换你一段人生。」`
- 机制：`《香取经》核心秘法，琉璃寺统治术的根基：香客祈愿化作一缕香火，僧人借香火反刍享受他人人生——香客失忆，僧人称王；无强大我执者，寿元尽耗。`
- 体系 ranks：`观虚无→观香→借香反刍→他化入身→念头为王`
- 体系 symbols：`一炷香=欲念载体·媒介 / 香取经=他化之源·奇书 / 开光符=功德假象 / 铁莲花=他化刑具`

### 文案稳定性门禁（组装前必过）

```
① 有钩子吗？      箴言是否具体、有代价/反转，且不是平铺直叙的介绍句
② 讲清机制了吗？  核心气质读完，圈外人能否用自己的话复述这个设定
③ 有黑话吗？      专有名词是否紧跟冒号用白话解释；无解释的黑话即打回
④ 圈外人3秒懂吗？ 定位线+箴言+核心气质任一模块，读完能否说清"这设定是关于什么的"
```

> 任一问不通过即文案不合格，回写修正后再组装 HTML。**禁止带"介绍句风格的无钩子文案"进组装**。

## 视觉系统

### 印章形制（每实体专属，按类型选）

| 类型 | 印章形制 | 示例 |
|:-----|:---------|:-----|
| 人物 | 人名朱文印（红字） | 「慈安」方印 |
| 势力 | 族徽/寺号印 | 「琉璃寺」方印 |
| 地理 | 地标徽记印 | 「菩提城」方印 |
| 规则 | 规则符印（圆印） | 「香火入念」圆印 |
| 场景 | 场景图腾（可双印对照） | 「金翅」朱文 + 「破界」白文 |

印文≤4字，能一眼认出"这是谁的设定"。`.seal.plain` 为白文（字空底朱）。

### 题诗创作（意象驱动法）

1. 提炼核心的 1 个画面瞬间
2. 用对仗句式呈现这个画面（不急于交代全部设定）
3. 植入 1 个情感锚点词（泪/寒/孤/别/梦）
4. 留白——读者能感受到意境但不完全看懂

2 句对仗，每句 7 字最佳（七言），总计 14 字。**好诗检验**：把诗中的设定名替换成另一个设定名，如果诗仍然成立 = 太通用，必须重写。

**好诗 vs 坏诗**：
- 坏（填空公式）：`表盘藏生死，鬼手探幽冥`——每句都在"说设定"，无画面感
- 好（意象驱动）：`长桥一盏别离泪，乡堂二歌舞腰轻`——有画面、有对仗、有情感锚点、有留白

### 小传创作（人物卡）

公式：`[性格特质一句话] + [居所/活动场景] + [职业行为/日常] + [一个矛盾或伏笔]`，总字数 60-100 字。
- 细节优于概括：写"嗜甜食"不写"可爱"，写"六角歌台"不写"神殿"
- 矛盾是灵魂：没有矛盾的小传只是设定卡，有矛盾才有记忆点
- 文学性重于准确性：允许模糊和留白，不是 wiki 词条

### 花语象征库（赛道对照）

| 角色气质 | 代表花 | 花语 |
|:---------|:-------|:-----|
| 孤高冷漠 | 白梅 | 高洁、傲雪凌霜 |
| 杀伐果断 | 曼珠沙华 | 死亡之美、决绝 |
| 温柔悲悯 | 白莲 | 出淤泥不染、慈悲 |
| 癫狂妖异 | 彼岸花 | 幽冥、往生 |
| 隐忍负重 | 雪莲 | 冰清、坚韧 |
| 帝王霸业 | 金莲/牡丹 | 尊贵、权倾 |
| 凄美宿命 | 彼岸花/昙花 | 一瞬灿烂、宿命 |
| 清冷出尘 | 空谷幽兰 | 淡泊、孤高 |

> 花语不强行套用，优先从角色核心意象提炼"最像的那一朵"。花语短句≤8字。

### AI 画风做减法（差异化护城河）

主流 AI 画风普遍"过度精致"（毛发过度渲染/算法对称脸/塑料质感），读者已审美疲劳。**建立辨识度的机会是画风做减法**——写意留白 > 满铺细节，克制精致、真实质感（纸感/水墨/布纹），避免"网红脸/算法对称脸"。这是全 OC 的差异化护城河，不是加分项。

## 字体系统（HTML 补字用，铁律❌7）

> **技术事实**：HTML 里的中文字由**浏览器加载本机系统字体**渲染，Playwright(Chromium) 截图落地。**不是 Trae 独有工具，也不是 ds 直出**——是系统字体 + CSS 排版，可完全控制、绝不乱码。局限：只能用本机已装字体，无真书法笔触（除非补装书法 ttf）。

**本机已确认可用的中文字体**（Windows）及其用途：

| 字体 | 字形 | 用途 |
|:-----|:-----|:-----|
| 楷体 `simkai.ttf` / `STKAITI.TTF` | 楷书 | 金句/标题/印章（默认主字体） |
| 仿宋 `simfang.ttf` / `STFANGSO.TTF` | 仿宋 | 正文小字/小传/词条说明 |
| 隶书 `STLITI.TTF` | 隶书 | 词条名/魏碑感/器物标签 |
| 宋体 `simsun.ttc` / `STSONG.TTF` | 宋体 | 正文备选 |
| 手写 `BRUSHSCI.TTF` | 手写体 | 书法笔触备选 |

**Font-family 写法（按优先级回退）**：

```css
/* 金句/标题（楷体） */
font-family:"Kaiti SC","STKaiti","KaiTi","Noto Serif CJK SC",serif;
/* 正文小字（仿宋） */
font-family:"FangSong","STFangsong","仿宋",serif;
/* 词条/器物标签（隶书） */
font-family:"Kaiti SC","LiSu","STLiti",serif;
/* 宋体备选 */
font-family:"SimSun","STSong","宋体",serif;
```

**字体选择规则**：金句/标题用楷体（厚重有力）；正文/小传用仿宋（清晰透气）；词条/器物标签用隶书（古雅）；落款/署名用楷体或手写。**同一张卡最多 2 种字体**，形成粗细/书体对比但不过度混杂。
