# 版面范式总纲（字槽混合式）

> OC 的**唯一大范式**（全 OC 质量基准）：AI 底图直出**设定载体页面**（载体材质 + 错落拼贴的画面内容 + 预留留白区），HTML 只在**留白区**补长效文字，整图截图即成品。**图与字在设计阶段协同规划**——先定载体与留白区，再出图，再在留白区补字。

## 什么是"留白"（老板 V4 定稿）

> **留白 ≠ 空白/纯色。留白 = 载体上没有"重要信息元素"的区域。** 画面上的任何具象内容（场景建筑、街巷、窗户、道具、人物本体）都是"重要信息元素"，把它们当背景再盖字，视觉元素就会打架、乱。正确做法：**画面本身是一张"设定载体/图鉴页"，纸底用无具象信息元素的材质（卷轴/羊皮纸等），"重要信息元素"（主角多视图/局部特写/武器特效）错落拼贴在纸底上**，纸底没被内容占用的区域才是留给 HTML 打字的字槽。

**底图范式（三要素，缺一不可）**：

| 要素 | 是什么 | 作用 |
|:-----|:-----|:-----|
| **载体材质** | 卷轴/羊皮纸/画布等无具象内容的信息面（**禁止用具体场景**：房子/街道/窗户/天空） | 作为"纸底"，是干净的信息承载面，天然能盖字不打架 |
| **画面内容** | 主角多视图 / 局部特写 / 武器特效，**错落有致**拼贴（不能只有一个孤零零的主角占满画面） | 承载"重要信息元素"，制造信息层级与视觉节奏 |
| **留白区** | 载体上没被内容占用的干净区域 | 只留给 HTML 补长效文字，不承载任何画面元素 |

## 文字分工（两种，各司其职）

| 文字类型 | 由谁承载 | 约束 | 为什么 |
|:---------|:---------|:-----|:-------|
| **短书法字**（标题/副题/印章/器物标签） | AI 直出，融入画面 | 每处≤4字，书法体，一般不乱码 | 短字 AI 直出效果好且天生融入画面（V3 底图自带"李周巍/明煌/白麟擎苍·金瞳照夜"完美） |
| **长效文字**（金句/小传/词条说明/落款） | HTML 在预留字槽补 | 放 AI 预留的干净留白块，用本机书法字体 | 长文字 AI 直出必乱码，HTML 补既可控又绝不乱码 |

> **判断标准**：4字以内短书法字 → AI 直出；超出 4 字的正文级文字 → 必须规划字槽，由 HTML 补。

## 字槽混合式铁律（违反即打回）

| # | 铁律 | 违反后果 |
|:-:|:-----|:--------|
| **A1** | **图是主角** — AI 底图是画面唯一主体，构图饱满、边界完整；HTML 只是字槽补字层，不抢画面 | 图沦为背景，失去传播力 |
| **A2** | **字槽规划先行** — 生成前必须先定"图哪些区域留白给文字/要哪些元素"，提示词明确预留字槽空白块；未规划就出图 → 文字没地方放 | 文字硬压画面，割裂 |
| **A3** | **信息区不压图** — 长效文字只放 AI 预留字槽/留白块，不遮挡图主体 | 主体被遮挡，失去焦点 |
| **A4** | **文字分工守则** — 短书法字 AI 直出；长效文字必须 HTML 在字槽补，禁止让 AI 直出长文字 | 长文字 AI 必乱码，卡毁掉 |

## 字槽规划维度（Step 1 设计阶段必答）

出图前，Step 1 必须明确以下问题，成果写入 `design-plan-oc.tpl.md`：

| 维度 | 问题 | 产出 |
|:-----|:-----|:-----|
| **留白预留** | 图哪些区域要专门留白给长效文字？预留多大？ | 字槽清单：位置/尺寸/用途 |
| **画面元素** | 图要哪些元素？主体什么姿态/场景？短书法字放哪几处？ | 画面元素清单 |
| **是否参考生图** | 有参考图吗？参考点（全面/画风/纯文生图）？ | 参考模式 |
| **画幅比例** | 用哪种画幅（见下）？ | 比例 + 尺寸 |

## 画幅与截图

| 画幅 | 像素 | 用途 | 截图命令 |
|:-----|:-----|:-----|:---------|
| **2:3 竖版**（默认） | 1125×1500 | 社交单图传播标准 | `SCREENSHOT_WIDTH=1125 SCREENSHOT_SCALE=2 python scripts/screenshot_album.py <html> <out.png>` |
| **4:3 横版** | 1500×1125 | 卷轴/横构图 | 同上，改 width |
| **16:9 横幅** | 1500×844 | 横幅 | 同上 |

> 底图由 `image_generate` 直出对应比例；HTML 画布固定同尺寸，`overflow:hidden` 禁止滚动，整屏截图即成品。

## 字槽规划要点（Step 2 生成时落进提示词）

> 生成底图的提示词走**载体范式三要素**（V4 定稿）：**载体材质 + 画面内容拼贴 + 留白区**。禁止用具体场景当背景盖字。

```
[载体材质：卷轴/羊皮纸/画布等无具象元素的信息面，整体主色调X，纹理干净，边缘做旧/卷边（禁止画房子/街道/窗户/天空等具体场景作为背景）]
[画面内容：主角多视图错落拼贴——主视图（半身/全身）+ 局部特写（面部/武器/配饰）+ 武器特效（能量/符文/粒子），各视图大小不一、错落有致分布在载体上]
[短书法字：标题/印章/器物标签，每处≤4字，书法体，融入画面内容]
[留白区：载体上被内容拼贴包围的空余区域，保持干净无元素、无纹理干扰，用于后续叠加文字]
[环境/光源/氛围：载体纸面光影]
[硬约束：负面清单 + 冻结特征]
```

> ⚠️ **载体范式铁律**（V4）：图里的"重要信息元素"（主角/武器/特写）必须**错落拼贴**，不能孤零零一个主角占满画面；纸底必须无具象场景；留白区不得承载任何画面元素。

## 跨赛道：赛道 token 包（模板 `body[data-track="..."]` 切换）

> schema：字槽混合式这条**载体机制是赛道无关的**（AI 底图直出 + 预留字槽 + HTML 补字），跨赛道只需换**文字风格层**。模板内置 5 套赛道 token 包，改 `body[data-track="{{track}}"]` 的 `{{track}}` 值即整套切换（古风是 default，其他覆盖变量）。

| 赛道 | `{{track}}` 值 | 画风库 category | 字体 | 主强调 | 次强调 | 装饰语言 |
|:-----|:-----|:-----|:-----|:-----|:-----|:-----|
| **古风**（default） | `guofeng` | 国漫/国画 | 楷体/仿宋/隶书 | 朱砂红 `#8a1f1f` | 鎏金 `#7a5a3a` | 印章/竖排/墨晕 |
| **赛博朋克** | `cyberpunk` | 二次元·赛博 | 黑体/等宽 | 霓虹粉 `#ff2d95` | 电蓝 `#00e5ff` | 故障字/机械角标 |
| **都市现代** | `urban` | 韩漫·现代 | 黑体 | 雾蓝 `#4a7ba6` | 冷灰 `#8a97a5` | 粗体胶囊/极简线 |
| **科幻** | `scifi` | 插画·科幻 | 细黑/等宽 | 电蓝 `#2f7bff` | 紫 `#9b5cff` | 几何光效/科技纹 |
| **暗黑** | `dark` | 哥特/暗黑奇幻 | 衬线/黑体 | 暗红 `#b3222a` | 暗金 `#c9a05a` | 哥特纹/暗金 |

**token 变量**（模板 `:root` / 各 `body[data-track]` 块定义）：

| 变量 | 作用 |
|:-----|:-----|
| `--track-title-font` | 金句/标题字体（楷体→Impact→雅黑→等宽→衬线） |
| `--track-body-font` | 正文字体 |
| `--track-label-font` | 词条名字体 |
| `--ink` / `--muted` | 主/次级文字 |
| `--em` | 强调/印章色 |
| `--gold` | 次强调 |
| `--seal-bg` / `--seal-fg` | 印章底/字 |
| `--divider` | 分隔线色 |

### 画风库联动（Step 1 选赛道必读）

> `pop-visual-style/references/style-dna-library.json` 是**生图 DNA 库**（每画风含 `category`/`keywords`/`dna`/`constraint`/`recommended_lighting`）。OC 组装时**必须联动**：按画风库条目回填生图 DNA（现有机制），同时按 `category` 映射到模板赛道 token（新增）。

**映射规则**：画风库 `category` → 模板 `data-track` 赛道：

| 画风库 category | 模板赛道 |
|:-----|:-----|
| 国漫 / 国画（玄幻厚涂/武侠/新国潮/暗黑悬疑） | `guofeng`（古风） |
| 二次元·赛博（赛博边缘行者等） | `cyberpunk` |
| 韩漫·现代（Webtoon现代风等） | `urban` |
| 插画·科幻 / 蒸汽朋克铜 | `scifi` |
| 哥特 / 暗黑奇幻 / 废土 | `dark` |

> 若画风库无匹配条目，按实体所在小说赛道人话判断；选赛道后按上表 token 包填模板 `{{track}}`。**赛道决定字体与配色，但短书法字（≤4字）仍由 AI 直出、颜色由底图决定**——HTML 补字的 `--ink/--em/--gold` 必须以底图实际拿色为准微调，保证融入不割裂。
