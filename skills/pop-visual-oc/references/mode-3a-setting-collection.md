# 3A 设定集方法论（HTML 组装档位 · 终极形态）

> OC 的第五档位，也是**对标 3A 游戏美术设定集（Art Setting Collection）的终极形态**。核心范式一句话：
>
> **「设定集页面」——把一张 OC 卡从"单张海报"升级为"信息丰富的设定集页面"：多视图网格 + PIL 细节特写 + 01-07 编号模块 + 专属印章 + 文化沉浸 + 角落篆刻水印。**
>
> 适用于**五类内容（人物/势力/地理/规则/场景）全部类型**，且**画风可多元适配**（通过 CSS 变量切换整套配色）。

## 与画册页档位的关系

3A 设定集并非独立逻辑，而是**画册页档位（HTML 组装版）的升级增强**。它继承画册页的全部铁律（A1 图是主角 / A2 主视觉零文字 / A3 信息区在图外），在此基础上新增 6 个 3A 结构。

| 维度 | 画册页（v3.6.0） | 3A 设定集（v3.7.0） |
|:-----|:----------------|:-------------------|
| 样式 | 单主视觉 + 底部无编号 info 块 | 多视图网格 + 细节特写引线 + 01-07 编号模块 |
| 视觉系统 | 颜色/等级 swatch | + 每实体专属印章 + 篆刻签名 |
| 文化沉浸 | 题诗/色板 | + 几何纹饰 + 竖排题诗 + 中英双语标签 |
| 水印 | footer 横条 `popwave.cn 让创意一键落地` | **角落篆刻签名章**（替代横条，不破坏画面） |

## 三条继承铁律（画册页 DNA，必须保持）

| # | 铁律 | 违反后果 |
|:-:|:-----|:---------|
| **A1** | **图是主角，HTML 是装裱** — 主视觉作为独立 `<figure>` 图框放在中央，有完整边界；HTML 是更大的装裱层。禁止图铺满当 background | 退化成"网页海报" |
| **A2** | **主视觉零文字** — AI 生成的主视觉必须无文字（提示词保留 `no text`），所有文案由 HTML 承载 | 图上乱字不可用 |
| **A3** | **信息区在图外** — 标题区/信息区/多视图/细节/印章全部在图框之外，不压图主体 | 主视觉被遮挡失去传播力 |

## 六个 3A 结构（核心 DNA）

### 结构1：多视图网格（Multi-View Grid）

主视觉之外的**多视图/多状态/多角度图格**，打破"单图"单调，对标设定集"多角度展示设定"的惯例。

| 类型 | 多视图内容 | 列数 |
|:-----|:----------|:----|
| 人物 | 情绪/状态/视角/日常多格（慈悲观/四分之三侧/侧脸…） | 3 列 |
| 势力 | 阵营阵列/代表场景/成员多格 | 3 列 |
| 地理 | 地标多格/昼夜四季/空间层次 | 3 列 |
| 规则 | 载体多格（介质/观想/代价）/器物多角度 | 3 列 |
| 场景 | 高光多帧/关键元素多格 | 3 列 |

- **素材来源**：优先复用存量视觉（`成品/画册页/` 已有主视觉 + 不同版本 OC 图）；缺素材时用 `crop_details.py` 从主视觉裁出不同局部当"伪多视图"过渡。
- **零文字**：图格与主视觉一样是纯图，状态名/视角名由 `.stat`/`.lbl` HTML 承载。
- **一致性锚点**：所有图格是**同一个设定**的不同切面，不是两个设定（人物=同一张脸，势力=同一阵营美学…）。

### 结构2：细节特写 + 引线标注（Detail Close-up + Leader Line）

对照 3A 设定集"局部放大 + 引线指向 + 末端标签"的信息组织方式。

**方法（铁律❌16：复用存量视觉，禁止为特写另起 AI 生图）**：
1. 用 `scripts/crop_details.py` 从主视觉按**相对坐标**裁出细节局部图（`--config <json>` 定义裁剪框 + 标签 + 放大倍率）。
2. 引线不在 PIL 画（定位不准），由 HTML 在细节区叠加 SVG `<line>` + 末端标签（更可控）。
3. 每个细节 cell 下挂 `.dline` 指示线 + `.detail-tag` 标签。

```
python skills/pop-visual-oc/scripts/crop_details.py \
  '<主视觉图>' '<输出目录>' --config crop_xxx.json [--sheet]
```

**config 示例**（相对坐标 0-1，从左上角）：
```json
{
  "details": [
    {"x": 0.62, "y": 0.10, "w": 0.34, "h": 0.26, "out": "detail-face", "label": "眉眼藏锋", "scale": 1.0},
    {"x": 0.10, "y": 0.55, "w": 0.30, "h": 0.30, "out": "detail-bird", "label": "白鸟栖肩", "scale": 1.0}
  ]
}
```

| 类型 | 细节特写内容 |
|:-----|:-----------|
| 人物 | 五官/配饰/神采/法器（眉眼、白鸟、红袍、念珠） |
| 势力 | 旗帜/纹章/建筑细部/僧阶 |
| 地理 | 建筑/地标/生灵/纹理 |
| 规则 | 器物/纹路/光效/祭品 |
| 场景 | 主体局部/关键元素/冲突落点 |

### 结构3：01-07 编号模块（Modular Numbered Info）

全卡信息模块统一带**编号徽标**（`.mod-idx`），对标设定集"分章节编号"的信息组织。

| 类型 | 01 | 02 | 03 | 04 | 05 | 06 | 07 |
|:-----|:---|:---|:---|:---|:---|:---|:---|
| 人物 | 称号 | 细节特写 | 属性 | 配色 | 花语 | 台词 | 小传 |
| 势力 | 定位 | 细节特写 | 势力气质 | 等级秩序 | 象征体系 | 色板 | 宣言 |
| 地理 | 定位 | 细节特写 | 氛围基调 | 标志性地标 | 当地生灵 | 色板 | 象征隐喻 |
| 规则 | 定位 | 细节特写 | 机制 | 层级 | 外显色板 | 器物载体 | 代价/象征 |
| 场景 | 高光时刻 | 细节特写 | 画面构成 | 色板 | 关键词条 | 情境 | 定场诗 |

> **01-07 可缺省到 5 字段，不硬凑 7**（遵循 ❌8 宁减模块精神）。编号必须连续，缺省时跳过该编号即可。

### 结构4：每实体专属印章（Entity Seal）

对标 3A 设定集"每角色/阵营有专属纹章/符印"的视觉系统。每张卡一个专属印章，作为**实体的视觉签名**。

**四种印章形制**（按类型选）：

| 类型 | 印章形制 | 示例 |
|:-----|:---------|:-----|
| 人物 | 人名朱文印（红字） | 「慈安」方印 |
| 势力 | 族徽/寺号印 | 「琉璃寺」方印 |
| 地理 | 地标徽记印 | 「菩提城」方印 |
| 规则 | 规则符印（圆印） | 「香火入念」圆印 |
| 场景 | 场景图腾（可双印对照） | 「金翅」朱文 + 「破界」白文 |

- **CSS 实现**：`.seal` 方框 + 选字 + 朱砂红描边；`.seal.plain` 为白文（字空底朱）。
- **印章内容**：实体名缩写/核心意象词（≤4字），能一眼认出"这是谁的设定"。

### 结构5：文化沉浸区（Cultural Immersion）

对标设定集"文化元素密度"带来的沉浸感。三件套：
1. **竖排题诗**（`.poem-col`，vertical-rl）：对仗句/定场诗，升华意境。
2. **几何纹饰**（`.meander` 云纹/回纹 SVG）：背景装饰，增强东方美学。
3. **中英双语标签**（`.sub-eng` 顶部 + 模块 `.mod-sub` 英文）：兼顾国际化与设定集质感。

### 结构6：角落篆刻签名章（Colophon Seal）

**替代画册页的底部横条水印（解决差距6：水印破坏沉浸）**。右下角低调的篆刻小章 `popwave` + 一句话，不破坏画面。

**铁律 ❌15（水印沉浸化）**：3A 设定集档位的品牌水印**必须用角落篆刻签名章**，禁止用底部横条/像素水印。既保留溯源，又不破坏画面沉浸。

## 画风多元适配（通用性/稳定性/多元适配）

3A 设定集通过 **CSS 变量驱动画风/配色**，一套模板适配不同赛道画风：

| 变量 | 作用 | 默认（黑暗佛门·朱砂金） |
|:-----|:-----|:----------------------|
| `--gold` / `--accent` | 主强调色 | `#DFB16A` 金 |
| `--gold2` / `--accent2` | 次级强调色 | `#C8654F` 朱砂 |
| `--accent3` | 渐变深端 | `#8A5A3B` |
| `--line` / `--line-soft` | 强调描边 | `rgba(223,177,106,.55/.22)` |
| `--seal-ink` | 印章朱砂红 | `#8E2F2A` |
| `--glow` | 光晕 | `rgba(223,177,106,.30)` |

> 换赛道时只需替换 `:root` 变量整套（如仙侠→青碧/黛青，都市→雾蓝/冷灰，科幻→电蓝/紫），模板结构不变。**这是"多元适配"的机制保证。**

## 工作流（3A 设定集档位）

```
Step 1 设计（选档位=3A设定集）
  ├─ 从档案+美术设定集对应篇选主视觉形态（无文字）
  ├─ 设计 3A 信息架构（多视图清单 + 细节裁图规划 + 印章设计 + 01-07 模块）
  ├─ 门禁B：方案对齐（含 3A 专项区块）
  └─ 落盘到 design-plan-oc.tpl.md

Step 2 生成（三步）
  ├─ ① AI 生成无文字主视觉（image_generate，保留 no text）
  ├─ ② crop_details.py 从存量主视觉裁细节特写
  ├─ ③ 用 album-3a-*.tpl.html 组装（多视图 + 细节/引线 + 01-07 + 印章 + 文化 + 角落篆刻水印）
  ├─ 本地预览 → ④ screenshot_album.py 截长图
  └─ 落地：复制到 成品/画册页/，角落篆刻水印已内嵌
```
