# 人物卡多表达图格方法论

> **老板定调（v3.5.0）**：人物 OC 不能再是"单张主视觉 + 文字堆叠"的单调产出。对标你收集的 OC 参考图（`005.jpg` 多视角 / `010.png` 多状态 / `022.jpg` 日常向 / `017.png` 多表达）——**一套角色 = 1 张主视觉 + N 个表达图格**，图格之间有状态/视角/场景的对比张力。本方法论把角色表达从"一张图"扩为"一张主视觉 + 一组表达图格"的参考表结构。

## 为什么单调——根因

对照对标素材，问题不在画工，而在**结构**：旧产出把人物卡做成了「单张主视觉 + 文字堆叠」，而对标参考表是「**主视觉 + 多图格**」的参考表结构。你收集的素材全是这个规律——一套角色卡用多个图格展示角色的不同切面，图格之间有对比张力，弥补单张图的信息扁平。

## 三类表达图格

人物卡主视觉之下，可挂载**三类表达图格**，每类聚焦一个表达维度：

| 图格类型 | 展示什么 | 视觉张力 | 图格数量 | 图格比例 | 对标素材 |
|:---------|:---------|:---------|:---------|:---------|:---------|
| **多状态 state** | 慈悲态/煞化态/战斗态/受伤态/觉醒态 | 反差、蜕变、隐藏实力 | 2-4 格 | 3:4 竖图 | 010.png / 017.png |
| **多视角 view** | 正面/背面/侧脸/特写/3/4 侧 | 完整性、专业感、建模参考感 | 2-4 格 | 1:1 或 3:4 | 005.jpg |
| **日常向 daily** | 佛前缝衣/市井采买/月下小酌/读书饮茶 | 亲近、可代入、生活切片 | 2-3 格 | 4:3 横图 | 022.jpg |

> 三类图格**可自由组合**：一张人物卡可用「多状态 + 日常向」双类，或「多状态」单类，按角色信息量弹性选择。至少挂 1 类（2 格以上），最多 2 类 5 格。

## 三种版式模板（对应三类图格）

`templates/album-character.tpl.html` 一个模板文件，通过 `{{variant_type}}` 变量切换三种版式：

| 版式 | 变量 | 图格排布 | 图格标注 | 视觉重心 |
|:-----|:-----|:---------|:---------|:---------|
| **状态卡** | `variant_type=state` | 主视觉下 2 列网格（3:4 竖图） | 「状态名」（慈悲态/煞化态）+ 状态类型徽标 | 反差张力，卖点引爆 |
| **视角卡** | `variant_type=view` | 主视觉下 3-4 列网格（1:1 方图） | 「视角名」（正面/背面/特写） | 完整性、专业参考感 |
| **日常卡** | `variant_type=daily` | 主视觉下 2-3 列网格（4:3 横图） | 「场景名」（佛前缝衣/月下小酌） | 亲近感、生活切片 |

### 图格标注规范

每个图格带三类元信息，HTML 承载（图格本身零文字，铁律 P1 延伸）：

| 元素 | 内容 | 说明 |
|:-----|:-----|:-----|
| **序号 idx** | `1/2/3/4` 圆形徽标 | 图格顺序 |
| **状态类型 stat** | 右上角徽标，如「煞化·显形」「日常·佛前」 | 图格所属类别/细分 |
| **标签 lbl** | 图格底部渐变条，如「金翅鸟·煞化法相」 | 一句话点出该图格表达什么 |

## 图格的角色一致性锚点

多图格最容易翻车的是"同一角色认不出"。图格间必须锁定**角色一致性锚点**（冻结特征，铁律 ❌3）：

| 锚点 | 说明 |
|:-----|:-----|
| **眼瞳色 + 面部轮廓** | 所有图格必须同一张脸，色瞳一致 |
| **核心气质** | 慈悲态/煞化态是同一人的两极，不是两个人 |
| **关键配饰** | 白鸟/佛珠/红袍等标志性元素跨图格延续 |

> 图格可以是**同一角色的不同时间切片**（慈悲态→煞化态），也可以是**同一身份的多个视角**（正面/背面），但绝不能变成"两个角色"。

## 文案 SOP 在人物卡多表达的延伸

人物卡信息区（小传/题诗/台词/配色板）仍按 `mode-album-html.md` §文案设计规范的**钩子架构三明治**填写，多表达图格**不占用文案 SOP 的四个字段**——图格承担"视觉对比"职能，文字区承担"叙事深化"职能，二者分工。

- **箴言**可用角色的**双相呼应**做钩子（如「白鸟温顺，金鸟噬人。」）——一句话点破"看到的慈悲只是假面"
- **小传**可补一句"多状态"说明，点出图格间的剧情关系（如"日间白鸟温顺如雀，绝境时金翅裂天"）

## 工作流（人物卡多表达）

```
Step 1 设计（选档位=HTML组装版·人物卡）
  ├─ 选主视觉形态（慈悲态，无文字，零标签零色板）
  ├─ 选图格类型（多状态/多视角/日常向，可组合）
  ├─ 规划图格内容（每格是什么状态/视角/场景 + 标注）
  ├─ 门禁B：方案对齐（主视觉 + 图格清单 + 文案 SOP）
  └─ 落盘到 design-plan-oc.tpl.md

Step 2 生成（两步）
  ├─ ① AI 生成主视觉 + N 张图格（image_generate，全部无文字）
  ├─ ② 用 album-character.tpl.html（variant_type=state/view/daily）
  │     组装多表达人物卡（主视觉 + 图格区 + 信息区）
  ├─ 本地预览 → 用户确认
  ├─ ③ 截成长图（screenshot_album.py）→ 交付可传播长图
  └─ 落地：复制到 `素材/`，品牌水印已内嵌 HTML footer
```

> **图格零文字铁律**：图格与主视觉一样必须是**无文字纯图**（提示词保留 `no text, no letters`），所有状态名/视角名/场景标注由 HTML 承载。图格不单独叠加水印，整体卡 footer 水印即可。

## 与旧版的关系

| 形态 | 旧版（单调） | v3.5.0（多表达） |
|:-----|:------------|:----------------|
| 产出结构 | 单张主视觉 + 文字 | 主视觉 + 表达图格 + 文字 |
| 角色切面 | 单一姿态 | 多状态/多视角/日常向 |
| 信息承载 | 文字堆叠 | 图格对比 + 文字深化 |
| 传播力 | 单张美图 | 可收藏的角色全谱 |

> 旧版单图形态仍保留（基础版/加强版/设定卡传播版），多表达图格是 **HTML组装版·人物卡**的增强能力——人物卡做正式推广时默认启用多表达，不再出单图。
