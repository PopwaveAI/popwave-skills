# 人物立绘模式

> 人物立绘是**角色名片**，不是封面。角色是绝对主体，文字是角色的"注释"——告诉读者这个人是谁、有什么故事。**纯图不算立绘，纯图只是素材。**

## 核心原则

- 角色是绝对主体（80%+ 画面面积），文字是注释不是主角
- 立绘的文字不是为了"好看"，是为了**让读者3秒记住这个人是谁、有什么故事**
- 与封面的核心区别：封面是视觉钩子（让读者点进书），立绘是角色名片（让读者记住这个人）

## 基础版 / 加强版（OC）/ 设定卡传播版

人物立绘支持三档文字密度，按需求选择：

| 档位 | 信息层数 | 文字内容 | 适用场景 |
|:-----|:---------|:---------|:---------|
| **基础版** | 3层 | 角色名+身份 → 定场诗/人设简介 → 钤印 | 角色展示、人物库配图 |
| **加强版（OC）** | 6层 | 角色名+身份 → 称号 → 角色小传 → 题诗 → 书法大字 → 钤印 | 角色设定卡、系列角色展示、世界观名片 |
| **设定卡传播版** | 模块化 | 立绘 + 属性栏 + 配色板 + 表情差分 + 花语象征 + 境界徽章 + 语录 | 粉丝传播、同人二创、收藏型物料、IP角色墙 |

> 加强版就是原"OC图"——本质是立绘的文字增强版，不是独立模式。文字内容 agent 可自动生成（角色背景从项目文件提取，小传/题诗按公式创作），不需要用户手写。Seedream 5.0 Pro 可处理 4-6 个短文本区块，每个 ≤15 字时渲染稳定；角色小传超 30 字时建议精简为 2-3 个短句。
>
> **设定卡传播版**是竞品普筛出的最佳内容形态（非纯剧情分格页），把角色做成**可识别、可传播、可二创、可收藏**的独立物料。它复用美术设定集人物篇的角色本体，在其上叠加模块化信息架构——不是"生产参考"，是"粉丝收藏品"。

## 人物卡 HTML 组装版·画册页（推荐推广形态，v3.3.0 铁律升级）

> **老板定调（v3.3.0）**：人物 OC 的推广形态必须与规则卡「画册页范式」统一——**图是主角，字/色板/tag 全部由 HTML 承载，主视觉零文字**。前三个档位把角色名/称号/小传/属性栏/色板/标签/台词/表情差分全塞进 AI 渲染的画面，结果**字多、色杂、tag 密**（参考 `OC-李玄-慈安-v1`、`OC-玄心-v1` 的 7 层文字+8 色+7 tag 包围式信息），既增乱码风险又稀释角色主体。

**人物卡推广形态的答案**：与 `mode-album-html.md` 画册页范式同构——
1. **① 无文字主视觉**：AI 只画一张**纯净人物主视觉**（保留 `no text, no letters`），角色是绝对主角
2. **② HTML 画册页**：角色名/称号/小传/题诗/属性栏/色板 swatch/花语/台词/表情差分，**全部由 HTML 承载放在图框之外**
3. **③ 截成长图**：组装后 `screenshot_album.py` 截成高清长图交付

> **为什么必须这样**：AI 渲染 4-6 个短文本区块是极限，人物卡需要承载的信息量（角色名+称号+小传+题诗+属性+色板+台词+表情差分）远超此限。强行塞进画面=乱码+构图平庸+角色被文字稀释。HTML 精确排版，图不被文字污染，字不被 AI 限制。

### 人物卡 HTML 组装版信息架构（HTML 承载全部字/色板/tag）

| 模块 | 内容 | 位置 | 说明 |
|:-----|:-----|:-----|:-----|
| **主视觉（无文字）** | 角色立绘（复用美术设定集人物篇本体，剥离 no text） | 中央独立 `<figure>` 图框 | A1 图是主角，A2 零文字 |
| **顶部标题区** | 系列名 / 类型标签「人物设定卡」/ 角色名（鎏金篆/书法体）/ 身份定位 | 图框上方 | 角色名是绝对信息第一权重 |
| **称号** | 四字格称号（方框衬底） | 标题区下 | 一句话点出角色厉害在哪 |
| **属性栏** | 境界/阵营/煞兽/秘法/命格 等（≤4字/项，5-6项） | 图框外 | 硬核设定，可收藏 |
| **配色板** | 角色代表色系 swatch（无字，仅色块） | 图框外 | 视觉记忆点，可二创取色 |
| **花语象征** | 代表花 + 花语短句（≤8字） | 图框外 | 文化隐喻 |
| **台词** | 角色代表性台词（≤15字） | 图框外 | 情感共鸣，可截图传播 |
| **题诗** | 七言对仗（意象驱动法产出） | 图框外 | 升华角色意境 |
| **小传** | 60-100字微型人物志（可长，HTML 不限） | 图框外 | 核心信息层，HTML 精确排版 |
| **表情差分** | 2-4 个表情/状态小图（可选，复用主视觉旁） | 图框外 | 角色鲜活度 |
| **品牌水印** | `popwave.cn 让创意一键落地` | footer | 内嵌 HTML，不走 watermark.py |

> **与前三档位的关系**：前三档位（基础版/加强版/设定卡传播版）是**快速出单图**形态，信息量受限；**HTML 组装版是人物卡的推广终极形态**——信息量放开、图最干净、排版最专业。人物卡做正式推广物料时**默认走 HTML 组装版**，不做 AI 渲染文字的前三档位。

> **多表达图格（v3.5.0 增强）**：人物卡 HTML 组装版不再出"单张主视觉+文字"的单调产出，默认启用**多表达图格**——主视觉之下挂载 2-5 个表达图格（多状态/多视角/日常向），对标参考表的"主视觉+多图格"结构。详见 `mode-character-multi.md` 方法论 + `templates/album-character.tpl.html` 三版式模板。

| # | 铁律 | 违反后果 |
|:-:|:-----|:---------|

## 加强版六层信息架构

加强版立绘的信息呈现遵循**漏斗式阅读动线**——从快速识别到深度沉浸，每一层递进吸引读者多看一眼：

| 层级 | 内容 | 视觉权重 | 阅读时间 | 设计目标 |
|:-----|:-----|:---------|:---------|:---------|
| **第1层** | 角色名+身份 | ★★★★☆ | 3秒 | 一眼知道"这是谁" |
| **第2层** | 称号 | ★★★☆☆ | 5秒 | 一句话概括"这个人厉害在哪" |
| **第3层** | 角色小传 | ★★★☆☆ | 15秒 | 60-100字微型人物志，有故事有矛盾 |
| **第4层** | 题诗 | ★★☆☆☆ | 10秒 | 画面感+对仗+情感留白，升华角色意境 |
| **第5层** | 书法大字 | ★★☆☆☆ | 视觉扫描 | 1-2字狂草装饰，纯视觉不传递信息 |
| **第6层** | 钤印 | ★☆☆☆☆ | 视觉扫描 | 朱砂红印点缀，文化落款 |

```
【阅读动线设计】
3秒：看清角色姿态 + 角色名+身份     ← 第1层
 ↓
5秒：读称号，知道角色厉害在哪        ← 第2层
 ↓
15秒：读角色小传，进入角色的世界      ← 第3层（核心信息层）
 ↓
10秒：品味题诗，感受角色意境         ← 第4层
 ↓
视觉扫描：书法大字+钤印提升文化质感   ← 第5-6层
```

## 各层创作指南

### 第1层：角色名+身份

- **内容**：角色全名 + 身份标签（如"萍琪派·神婆""苏午·诡异模拟器持有者"）
- **位置**：右侧竖排（古籍版式）或底部面板中央
- **字体**：与角色气质匹配（修仙=书法体，都市=现代体，诡异=残破体）
- **大小**：中等，不超过画面10%面积
- **质感**：有材质描述（鎏金/银白/朱砂等）
- **身份标签**：从项目角色库提取核心身份，浓缩为2-4字标签

### 第2层：称号

- **内容**：四字格最佳（如"百味别饮""万鬼之主""深渊执剑"），概括角色的核心能力或特质
- **创作公式**：`[核心能力/特质的意象] + [行为/状态动词]`，凝练为四字
- **视觉**：方框衬底或朱丝栏强调，字号介于角色名和小传之间
- **来源**：从角色设定中提炼最具辨识度的能力标签

### 第3层：角色小传（核心信息层）

角色小传是一段**有文学性的微型人物志**，不是设定说明文。让读者15秒内进入角色的世界。

**创作公式**：

```
[性格特质一句话] + [居所/活动场景] + [职业行为/日常] + [一个矛盾或伏笔]
```

**各部分要求**：

| 部分 | 要求 | 字数 | 示例（参考图） |
|:-----|:-----|:-----|:--------------|
| 性格特质 | 用具体细节而非抽象形容词，"嗜甜食擅乐舞"优于"活泼可爱" | 10-15字 | "嗜甜食，擅乐舞的活泼小神婆" |
| 居所/场景 | 一个有画面感的具体地点，暗示世界观 | 10-15字 | "固居于幽銮的六角歌台顶端" |
| 职业行为 | 角色做什么、怎么做，体现职业特性 | 15-25字 | "似能助人忘却生前红尘。钟情于为每一位过路鬼魂备饮一杯" |
| 矛盾/伏笔 | 一个反转、隐患或悬念，制造记忆点 | 15-25字 | "些许茶水应是让歇脚的解了渴，不过长此以往，怨成苦者反众多" |

**总字数**：60-100字，竖排正文，行距宽松，字距紧凑

**创作要点**：
1. **细节优于概括**：写"嗜甜食"不写"可爱"，写"六角歌台"不写"神殿"
2. **矛盾是灵魂**：没有矛盾的小传只是设定卡，有矛盾才有记忆点（"解了渴"vs"怨成苦者"）
3. **文学性重于准确性**：这是视觉作品的文字层，不是wiki词条，允许模糊和留白
4. **素材来源**：从项目角色库（人物库/设定文件）提取，agent 负责文学化重写

### 第4层：题诗

#### 意象驱动法（v2.5.0 升级）

旧公式 `[核心意象A] + [核心意象B] + [命运转折] + [角色宿命]` 产出像填空题——每句都在"说设定"而非"造意境"。

**新方法论：意象驱动法**

```
Step 1: 提炼角色最核心的1个画面瞬间（如神婆的"为鬼魂备饮"）
Step 2: 用对仗句式呈现这个画面（不急于交代全部设定）
Step 3: 植入1个情感锚点词（如"别离泪""舞腰轻""孤灯寒"）
Step 4: 留白——读者能感受到意境但不完全看懂，比说透更好
```

#### 好诗 vs 坏诗对照库

**坏诗（填空公式产出）**：
> 表盘藏生死，鬼手探幽冥。
> 凡躯承诡道，一念定乾坤。

问题：每句都是设定陈述（"藏生死""探幽冥""承诡道""定乾坤"），无画面感，无情感留白，读起来像人物卡说明书。

**好诗（意象驱动法产出）**：
> 长桥一盏别离泪，乡堂二歌舞腰轻。

优点：有画面（长桥、乡堂）、有对仗（一盏/二歌）、有情感锚点（别离泪、舞腰轻）、留白不说透。

**好诗核心特征**：

| 特征 | 说明 | 检验方法 |
|:-----|:-----|:---------|
| 画面感 | 能脑补出一个具体场景 | 闭上眼能否"看到"画面？ |
| 对仗 | 句式对称，节奏感 | 上下句字数相同，结构对称 |
| 留白 | 不交代全部设定，留想象空间 | 删掉这句后角色设定是否少了关键信息？如果不少=留白到位 |
| 情感锚点 | 有一个情绪词触动读者 | 诗中是否有1个"软"词（泪/寒/孤/别/梦）？ |

#### 创作要求

1. 2句对仗，每句7字最佳（七言），总计14字
2. 必须包含角色的核心画面瞬间，不能通用
3. 与封面定场诗的区别：封面诗讲"书"（全书意境），立绘诗讲"人"（角色瞬间）
4. 押韵但不强求平仄，重意境不重格律
5. **好诗检验**：把诗中的角色名替换成另一个角色名，如果诗仍然成立=太通用，必须重写

#### 各赛道题诗示例

| 赛道 | 题诗 | 画面瞬间 | 情感锚点 |
|:-----|:-----|:---------|:---------|
| 民俗志怪（神婆） | 长桥一盏别离泪，乡堂二歌舞腰轻 | 为鬼魂备饮 | 别离泪 |
| 诡异悬疑（苏午） | 十二时辰死生转，一面残钟叩幽冥 | 死亡循环中看表盘 | 幽冥 |
| 暗黑修仙（深渊） | 万丈深渊无底处，独执残灯照归途 | 深渊中独行 | 归途 |
| 古言权谋 | 朱墙一局天下棋，深殿独坐落子迟 | 深宫弈棋落子 | 落子迟 |

### 第5层：书法大字（装饰层）

- **内容**：从角色名/称号/核心意象中提取1-2个字（如"流炉""深渊""棋"）
- **字体**：狂草或行草，纵势构图，笔画飞动
- **功能**：纯视觉装饰，不传递信息，提升画面文化质感和层次感
- **位置**：与角色主视觉形成对角线呼应（如角色在右，书法在左下）
- **大小**：中等偏大，但笔画疏朗不抢角色焦点
- **质感**：墨色浓淡变化，飞白枯笔效果

> 书法大字是"画中画"——它不是文字信息层，是视觉装饰层。读者不需要读懂它写了什么，只需要感受到"这张图有文化底蕴"。

### 第6层：钤印

- **内容**：角色名缩写/称号关键词/闲章（成语或意象词）
- **形态**：方形/圆形朱砂红印，阴文或阳文篆刻
- **数量**：2-4处，分布于画面四角平衡构图
- **大小**：约占画面1-2%面积，小但醒目（红色锚点）
- **功能**：文化落款 + 画面平衡

## 设定卡传播版（模块化信息卡）

> 竞品破译结论：**角色设定卡（Character Sheet）是社交媒体漫改赛道的主流形态**，而非纯剧情分格页。竞品把"角色立绘 + 属性栏 + 配色板 + 表情差分 + 花语象征 + 境界徽章"做成可识别、可传播、可二创、可收藏的独立物料。我方此前只做了"生产参考（定妆图）"和"角色名片（立绘OC）"两层，这是同一份资产缺的第三层——**传播物料**。

### 与立绘OC的本质区别

| 维度 | 立绘OC（加强版） | 设定卡传播版 |
|:-----|:----------------|:-------------|
| 本质 | 角色名片（让读者记住这个人） | 角色说明书（让粉丝收藏、二创、转发） |
| 信息密度 | 6层文字 | 模块化信息（属性+配色+表情+花语+境界） |
| 叙事 | 聚焦一个画面瞬间 | 系统化呈现角色多维度信息 |
| 传播力 | 中（单张美图） | 高（信息密度大，可收藏可二创） |
| 服务对象 | 读者 | 粉丝/同人圈 |
| 产出目的 | 展示角色气质 | 建立角色IP资产、制造传播素材 |

### 模块化信息架构（7大模块）

设定卡传播版是**模块的组合**，不是固定版式。按角色信息量弹性组合：

| 模块 | 内容 | 视觉权重 | 设计目标 |
|:-----|:-----|:---------|:---------|
| **立绘主视觉** | 角色立绘（复用最新定妆本体） | ★★★★★ | 画面主体，一眼识别角色 |
| **属性栏** | 境界/阵营/武器/天赋/命格等数值 | ★★★★☆ | 硬核设定党最爱，可收藏 |
| **配色板** | 角色代表色系 swatch 色块 | ★★★☆☆ | 视觉记忆点，可二创取色 |
| **表情差分** | 2-4个表情/状态小图 | ★★★☆☆ | 角色鲜活度，可当表情包 |
| **花语象征** | 代表花 + 花语短句 | ★★★☆☆ | 文化隐喻，增添意境 |
| **境界徽章** | 修炼等级/身份徽章 | ★★☆☆☆ | 世界观体系可视化 |
| **语录** | 角色代表性台词一句 | ★★★☆☆ | 情感共鸣，可截图传播 |

### 花语象征库（赛道对照）

角色代表花语是文化隐喻的核心，从角色意象/性格/命运提炼：

| 角色气质 | 代表花 | 花语 |
|:---------|:-------|:-----|
| 孤高冷漠 | 白梅 | 高洁、傲雪凌霜 |
| 杀伐果断 | 曼珠沙华 | 死亡之美、决绝 |
| 温柔悲悯 | 白莲 | 出淤泥不染、慈悲 |
| 癫狂妖异 | 彼岸花 | 幽冥、往生 |
| 隐忍负重 | 雪莲 | 冰清、坚韧 |
| 帝王霸业 | 金莲/牡丹 | 尊贵、权倾 |
| 凄美宿命 | 彼岸花/昙花 | 一瞬灿烂、宿命 |
| 清冷出尘 | 空谷幽兰 | 淡泊、孤高 |

> 花语不强行套用，优先从角色核心意象提炼出"最像的那一朵"。花语短句≤8字。

### 境界徽章

从角色修炼体系/势力阵营提炼等级徽章（如"筑基/金丹/元婴"或"一品/二品"），用篆刻/灵纹式徽章呈现，增强世界观体系感。

### 文字密度控制（关键）

Seedream 5.0 Pro 可稳定处理 4-6 个短文本区块，每个 ≤15 字。设定卡传播版模块多，**文字必须精简**：

- 属性栏：每项 ≤4 字（如"境界·金丹"），最多 5-6 项
- 花语：≤8 字
- 语录：1 句 ≤15 字
- 模块总数 ≤7，必要时合并（配色板无字、境界徽章仅徽章名）

> ⚠️ 若某角色信息量过大，**宁可减少模块数**保文字清晰，也不要塞满导致乱码。文字乱码会直接毁掉传播卡的收藏价值。

### AI画风做减法（差异化机会）

竞品破译发现：主流 AI 画风普遍"过度精致"（毛发过度渲染/面部算法对称/塑料质感），读者已审美疲劳。**我方建立辨识度的机会是画风做减法**——更写意、更克制：

- **笔触**：写意留白 > 满铺细节，边缘保留笔触感而非无瑕渲染
- **面部**：克制精致度，避免"网红脸/算法对称脸"
- **材质**：避免塑料光泽，用纸感/水墨/布纹等真实质感
- **构图**：留白优先，不堆满元素

> 这条是差异化护城河，不是加分项。竞品已经集体掉进"过度精致"陷阱，谁先做减法谁先建立辨识度。

## 角色辨识度三要素

每个角色需要 3 个让读者一眼认出的视觉特征：

1. **轮廓特征**：体型/发型/标志性服饰轮廓
2. **色彩特征**：代表色/配色组合
3. **细节特征**：疤痕/纹身/配饰/异变部位

示例：
- 深渊主宰主角 → 黑色长袍 + 幽蓝剑光 + 左眼封印纹
- 末世主角 → 军绿色夹克 + 改装弩 + 左臂机械义肢

### 体态语言

角色姿态传达性格：
- 双手抱胸 → 自信/傲慢
- 手握武器向前 → 战斗意志
- 侧身回眸 → 神秘/从容
- 低头沉思 → 智谋/深沉
- 仰头望远 → 雄心/志向

### 服饰叙事

服装细节传达世界观信息：
- 材质：丝绸（富贵）/粗布（贫寒）/皮质（战斗）/金属（铠甲）
- 纹样：宗门标识/家族纹章/魔法符文/科技线路
- 破损：战斗痕迹/磨损程度/修补方式
- 配色：身份等级/阵营归属/个性表达

> 辨识度三要素/体态语言/服饰叙事已内嵌于本节（见上）。完整方法论见 `pop-visual-cover/references/novel-visual-design.md`

## 提示词结构

```
角色描述（外貌+服饰+特征+姿态+表情） + 背景氛围 + 文字层（角色名→称号→小传→题诗→书法大字，按布局指定位置） + 风格
```

### 文字处理要点

- 角色名用双引号包裹（如 `"苏午"`），指定位置和字体类型
- 称号用双引号包裹（如 `"百味别饮"`），指定方框衬底
- 角色小传用双引号包裹（如 `"嗜甜食，擅乐舞的活泼小神婆……"`），指定竖排小字
- 题诗用双引号包裹（如 `"长桥一盏别离泪"`），指定小字位置
- 书法大字用双引号包裹（如 `"流炉"`），指定狂草字体
- 文字位置不遮角色：底部面板/侧边条/叠加层/四角分布

### 与封面提示词的核心差异

| 差异点 | 封面提示词 | 立绘提示词 |
|:-------|:---------|:---------|
| 文字主体 | 书名（营销级大小） | 角色名+小传+题诗（注释级大小） |
| 文字层级 | 书名+作者+标语 | 6层信息架构（加强版） |
| 画面主体 | 视觉钩子+场景 | 角色本人 |
| 配色驱动 | 赛道符号色 | 角色代表色 |
