# 设定实体卡模式（势力/地理/规则/场景）

> OC 不止人物。势力/地理/规则/场景等**世界观设定实体**同样是可视觉化的推广素材——像游戏美术设定集一样，表达方式应该非常丰富。本文件定义四类设定实体卡的视觉方法论。
>
> **核心原则**：设定实体卡是**推广物料/世界观名片**，不是说明书。目标是让读者 3 秒记住"这个势力/地方/规则/场景是什么感觉"，而不是罗列设定条目。

## 五类内容类型总览（OC 的完整边界）

| 类型 | 视觉主体 | 一句话定位 | 消费的美术设定集篇 |
|:-----|:---------|:-----------|:------------------|
| **人物卡** | 角色本人 | 让读者记住这个人 | 人物篇 |
| **势力卡** | 阵营/宗门/家族/王朝 | 让读者记住这群人是什么气质 | 势力篇 |
| **地理卡** | 城市/小世界/秘境/位面 | 让读者记住这个地方什么感觉 | 地理篇 |
| **规则卡** | 力量体系/境界/功法/禁忌 | 让抽象规则被"看到" | 规则篇 |
| **场景卡** | 关键场景/名场面瞬间 | 让读者记住这个高光时刻 | 场景篇（+符号篇） |

> **视觉真源**：所有类型的视觉本体一律来自 `pop-visual-art-bible` 美术设定集对应篇（唯一真源）。OC 只负责"怎么摆进版式、叠加什么文字文化元素"，**禁止重建视觉事实**。

---

## 势力卡

> 势力卡的视觉主体是"这个阵营占哪种视觉生态位"——它的人群、审美、象征共同构成可辨识的阵营美学。

### 信息架构（模块化）

| 模块 | 内容 | 设计目标 |
|:-----|:-----|:---------|
| **主视觉** | 势力代表形象（建筑群/战旗阵列/标志地貌/代表角色） | 一眼识别阵营气质 |
| **势力名+定位** | 势力名 + 一句话定位（如"镇北王府·铁血长城"） | 3秒知道这是谁 |
| **阵营美学** | 标志色块 + 纹饰风格（从美术设定集势力篇取） | 视觉记忆点 |
| **象征体系** | 旗帜/纹章/族徽图腾 | 可二次创作的符号 |
| **宣言/口号** | 一句代表性宣言（≤15字） | 情感共鸣 |
| **等级/结构** | 阶层划分的视觉外显（可选） | 世界观体系感 |

### 文字密度

- 势力名+定位：≤8字
- 宣言/口号：1句 ≤15字
- 属性标签：每项 ≤4字，最多 5-6 项
- 模块总数 ≤7，宁减模块保清晰

---

## 地理卡

> 地理卡的视觉主体是"这个地方的空间质感与氛围"——材质、温度、光线、情绪，让人一眼记住这个"小世界"。

### 信息架构（模块化）

| 模块 | 内容 | 设计目标 |
|:-----|:-----|:---------|
| **主视觉** | 地理地标/空间氛围全景 | 一眼记住这个地方 |
| **地名+定位** | 地名 + 一句话定位（如"幽冥界·亡者归处"） | 3秒知道这是哪 |
| **氛围基调** | 代表色块 + 光线情绪（从美术设定集地理篇取） | 空间记忆点 |
| **标志性地标** | 2-4个可定格节点名 | 可探索的代入感 |
| **当地生灵** | 居民/生物/文明形态（可选） | 世界观活性 |
| **象征隐喻** | 一句情绪/隐喻短句（≤15字） | 情感共鸣 |

### 文字密度

- 地名+定位：≤8字
- 象征隐喻：1句 ≤15字
- 地标名：每项 ≤4字
- 模块总数 ≤7

---

## 规则卡

> 规则卡最难画——抽象规则没有天然形象。**必须从美术设定集规则篇的原文视觉外显（光效/纹路/器物/天象）提取具象载体**，再设计可视化。禁止凭空发明一个与原文无关的符号。

### 可视化策略（三选一，从规则篇取）

| 策略 | 适用 | 做法 |
|:-----|:-----|:-----|
| **器物载体** | 规则有具象器物（印/镜/书/卷/符/剑） | 以器物为主视觉，器物即规则 |
| **天象异象** | 规则有突破/天象奇观 | 以境界异象为主视觉，光效/雷劫/金光 |
| **符号纹路** | 规则表现有纹路/法阵 | 以符纹法阵为主视觉，规则即纹路 |
| **组合** | 规则多维度 | 主器物 + 背景天象/纹路叠加 |

### 信息架构（模块化）

| 模块 | 内容 | 设计目标 |
|:-----|:-----|:---------|
| **主视觉** | 规则载体（器物/天象/纹路） | 让抽象规则被"看到" |
| **规则名+定位** | 规则名 + 一句话定位（如"明阳之道·皇道法则"） | 3秒知道这是什么 |
| **层级可视化** | 境界/层级 + 各自视觉奇观（可选示意） | 力量体系感 |
| **外显色板** | 规则表现的代表色块 | 力量色彩记忆点 |
| **器物/符号** | 承载规则的具体器物/符号 | 可二次创作 |
| **规则一句话** | 规则heare/DNA 的一句话（≤15字） | 提炼记忆点 |

### 文字密度

- 规则名+定位：≤8字
- 规则一句话：1句 ≤15字
- 层级名：每项 ≤4字
- 模块总数 ≤7

---

## 场景卡

> 场景卡的视觉主体是"一个关键场景/名场面瞬间"——它承载剧情升降，是读者最想"看到"的时刻。

### 信息架构（模块化）

| 模块 | 内容 | 设计目标 |
|:-----|:-----|:---------|
| **主视觉** | 场景高光瞬间（从美术设定集场景篇取可定格帧） | 一眼进入那个时刻 |
| **场景名+定位** | 场景名 + 一句话定位（如"封王大典·君临天下"） | 3秒知道这是什么时刻 |
| **氛围基调** | 代表色块 + 光影情绪 | 现场感 |
| **关键元素** | 参与角色/器物/符号（可选） | 剧情代入 |
| **情境一句话** | 一句高光台词/情境（≤15字） | 情感共鸣 |

### 文字密度

- 场景名+定位：≤8字
- 情境一句话：1句 ≤15字
- 模块总数 ≤7

## 通用布局（设定实体卡共享）

四类设定实体卡共用一套模块化布局，与人物设定卡传播版同构：

```
┌─────────────────────────────┐
│ 系列名    实体名·定位        │ ← 顶部标题区
├─────────────────────────────┤
│ ┌───────────┬─────────────┐ │
│ │           │  阵营美学/   │ │
│ │  主视觉   │  氛围基调/   │ │ ← 右侧:色板+象征/地标/层级/关键元素
│ │  (55%面积)│  外显色板    │ │
│ │           │  象征:____  │ │
│ └─────┬─────┴──────┬──────┘ │
│       │ 宣言/隐喻/台词 (≤15字)│  ← 底部:情感点
│       └────────────┘        │
└─────────────────────────────┘
```

> 布局细节与文字编码规则与人物设定卡传播版一致（见 `mode-character.md`「设定卡传播版」章节的布局与文字密度）。四类实体卡是同一套"模块化信息架构"在不同实体上的应用。

## AI画风做减法（差异化垄断，与人物卡一致）

同人物设定卡传播版：写意留白、克制精致、真实质感，避免竞品"过度精致/塑料质感"审美疲劳陷阱。这是全 OC 内容类型的差异化护城河。
