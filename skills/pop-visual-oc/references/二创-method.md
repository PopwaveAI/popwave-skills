# 二创方法论（原文理解 → 好看注入）

> **二创是 OC 的灵魂。** 原则：**好看是第一生产力，小说原文描述不一定好看**。本文件定义"忠实于原著"与"好看优先"如何平衡——从原文提取气质锚点，但构图/姿态/光影/动作张力/记忆点由设计者注入，让角色"看起来够帅/够美/够有记忆点"。

## 一、为什么必须二创（不照抄原文）

原文是**文字采样**，不是**视觉方案**。原文往往只给"他穿褐色长衣、面容清俊"这类朴素信息，直接照画会得到一张平庸的图。**读者 0.3 秒扫过，脸不记得、气质不记得、就划走了**。二创的任务是：把原文的"气质"翻译成"视觉冲击力"。

**原文 vs 二创的分工**：

| 层面 | 谁定 | 说明 |
|:-----|:-----|:-----|
| **气质锚点**（性格/身份/处境） | 原文 | 忠实——这是角色的"魂"，不能改 |
| **核心意象**（蝉/碑/麒麟等视觉母题） | 原文 | 忠实——这是角色的"符号"，不能丢 |
| **视觉母题**（贯穿性符号） | 原文 | 忠实——这是角色的"记忆点" |
| **构图**（站位/视角/画面布局） | **二创** | 决定第一眼冲击力 |
| **姿态/动作** | **二创** | 决定气质外显（骄傲/阴冷/慈悲/癫狂） |
| **光影/色调** | **二创** | 决定情绪氛围 |
| **动作张力**（特效/动势/氛围物） | **二创** | 决定"够不够帅" |

> 一句话：**原文管"他是谁"，二创管"他看起来多难忘"。** 前者忠实，后者自由发挥，两者不冲突。

## 二、二创五问（设计立绘前必答）

动手设计前，先回答 5 个问题，答案写入设计方案：

```
① 他的魂是什么？     性格/身份/处境里最核心的一点（原文锚定）
② 他的符号是什么？   贯穿的视觉母题/意象（原文锚定，如蝉/碑/麒麟）
③ 他该是什么姿态？   用姿态外显①——骄傲就昂首，阴冷就垂眸，癫狂就咧嘴
④ 他该是什么光？     用光影营造②的情绪——神性就金光，压抑就暗部，凄美就冷月
⑤ 让他多难忘？       一个记忆点动作/特效/氛围物，让读者 0.3 秒记住
```

## 三、好看注入六式（二创工具箱）

| 招式 | 做什么 | 例子 |
|:-----|:------|:-----|
| **1 姿态立魂** | 用肢体语言外显气质，不靠脸 | 骄傲→昂首睥睨；阴冷→垂眸斜睨；慈悲→低眉合十；癫狂→咧嘴/歪头 |
| **2 光塑情绪** | 用光影定调氛围 | 神性→背后金光/光环；压抑→暗部包边；凄美→冷月侧光；邪性→红光/逆光 |
| **3 动张显力** | 加动态张力（衣摆飘动/发丝飞扬/特效/氛围物） | 衣袍被风掀起、能量粒子环绕、武器锋芒外放 |
| **4 物托记忆** | 用道具/意象强化记忆点 | 蝉停肩头、碑影垂落、麒麟虚影盘踞 |
| **5 藏九露一** | 信息不摊平，留悬念 | 只露一个关键特征，其余留白，让读者想探索 |
| **6 反差点睛** | 一个打破预期的细节 | 凶煞角色却别一支素花；慈悲角色却满身血 |

## 四、二创铁律（不越过红线）

| # | 铁律 | 违反后果 |
|:-:|:-----|:--------|
| **C1** | **气质锚点不改** — 性格/身份/处境的最核心点必须来自原文，禁止为好看歪曲角色本质 | 角色失真，读者认不出"这是谁" |
| **C2** | **核心意象不丢** — 贯穿性视觉母题（蝉/碑/麒麟等）必须保留，禁止丢掉换别的 | 记忆点消失，角色失去辨识度 |
| **C3** | **好看不得压过识别** — 二创注入的姿态/光影/特效不得让角色本体变得难认 | 过度堆特效，角色淹没在画面里 |
| **C4** | **二创服务于推广** — 注入的一切要有"让读者记住"的功能，非为炫技而炫技 | 无意义华丽，读者记不住任何点 |

## 五、二创示例（广蝉验证）

- **原文**：和尚，皮相颇佳，金纹袈裟，棕色长衣，前后两张脸，白蝉栖于口中。
- **魂**：高傲自负、睥睨众生、临死解脱（原文锚定）
- **符号**：白蝉（本命根基）、前后双脸、金纹袈裟（原文锚定）
- **二创注入**：
  - 姿态 → 睥睨侧身，头微扬，下巴微抬（外显高傲）
  - 光影 → 背后金色释光 + 金沙粒子（神性/佛门氛围）
  - 动张 → 袈裟被风掀起、衣摆飘动（动态张力）
  - 物托 → 白蝉栖于肩/口，复眼泛红（记忆点）
  - 反差 → 睥睨神情却唇边有金色血迹（呼应"蝉脱壳"解脱结局）
- **结果**：读者 0.3 秒记住"一个高傲的、口含白蝉的、带着神性金光的和尚"。

## 六、与 Step 1 的衔接

Step 1 设计立绘时：**先读本文件** → 按"二创五问"填答案 → 把"姿态/光影/动张/记忆点"写进生图提示词 → 立绘质量达标后再叠顶部聚字。**立绘是主角，文字是注解，二创让立绘成为主角。**
