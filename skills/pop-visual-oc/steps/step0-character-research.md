# Step 0: 角色调研管线

> 关键词搜索 → 上下文采样 → 角色档案 → 🚪门禁A：角色档案确认

## 设计哲学

OC不是直接搜图画图，是先从原文中系统性地采样角色信息，形成立体化的角色档案。

**角色立体化的核心**：不只采"长什么样"，更要采"别人怎么看他"、"他怎么说话"、"他的矛盾在哪"。一个角色的视觉设计，如果不建立在对角色立体理解的基础上，画出来的只是一个好看的壳——没有灵魂。

## 0. 资产文件检查（优先路径）

> 如果 `pop-visual-asset` 已提取过角色档案，直接读取，跳过原文采样。

### 0.1 检查资产文件

用 LS 扫描 `素材/视觉资产/` 目录，查找 `[角色名]角色档案.md`：

| 情况 | 处理 |
|:-----|:-----|
| 资产文件存在 | 读取档案 → 跳到 §4 门禁A（跳过 §1~§3 原文采样） |
| 资产文件不存在 | 提示用户："建议先运行 pop-visual-asset 提取角色档案，可直接执行 `提取角色档案`。也可直接在 OC 内完成调研。" → 走 §1 原文采样流程 |

### 0.2 资产文件校验

读取 `素材/视觉资产/[角色名]角色档案.md` 后：
- 确认10维度完整性（特别是维度二外貌演变、维度九视觉设计参考）
- 确认采样范围是否覆盖所需章节（检查文件头部"采样范围"标记）
- 如档案不完整或采样范围过旧 → 建议用户先运行 pop-visual-asset 增量更新

> **关键**：资产文件是 pop-visual-asset 的产出，格式和10维度与 OC 内部调研完全一致。读取后直接进入门禁A确认，不重复采样。

## 1. 关键词搜索策略（无资产文件时）

> ⚠️ 本节是资产文件不存在时的回退路径。如果 `素材/视觉资产/[角色名]角色档案.md` 已存在，跳过本节。

### 1.1 定位小说原文

首先确认小说原文文件路径。常见位置：
- `原料/小说原文/[书名].txt`
- `workspace/拆书项目/[书名]/` 下的文件
- 用户直接提供的文件路径

> 如果找不到原文文件，必须向用户询问，禁止凭记忆设计角色。

### 1.2 多轮搜索

从角色名出发，逐步扩展搜索关键词：

| 轮次 | 关键词类型 | 示例（李周巍） | 目的 |
|:-----|:---------|:-------------|:-----|
| 第1轮 | 角色名 | `李周巍` | 定位所有出场段落 |
| 第2轮 | 外貌词 | `李周巍.*(眸\|眼\|甲\|氅\|袍\|发)` | 采集外貌描写 |
| 第3轮 | 性格词 | `李周巍.*(霸道\|虎豹\|冷\|笑\|怒)` | 采集性格特征 |
| 第4轮 | 评价词 | `白麟\|魏王\|李氏天骄` | 采集他人评价 |
| 第5轮 | 关系词 | `李周巍.*(父亲\|母亲\|叔公\|部下)` | 采集人际关系 |

> 使用 Grep 工具搜索小说原文，output_mode=content, -n=true, 记录命中行号。

### 1.3 采样原则

- 每个关键词命中后，用 Read 工具读取该行前后20-50行上下文
- 重点关注：**外貌描写**、**对话**、**动作**、**他人评价**、**心理活动**
- 记录行号，便于后续引用和用户查验
- 采样量：每个维度至少3-5条原文佐证

### 1.4 采样深度

| 层次 | 采集内容 | 价值 | 采样难度 |
|:-----|:---------|:-----|:---------|
| 表层 | 外貌描写（发色/眼瞳/服饰/体型） | 画皮 | 低（直接搜索） |
| 中层 | 性格特征+行为模式+说话方式 | 画骨 | 中（需上下文理解） |
| 深层 | 他人评价+矛盾暗面+成长弧线 | 画魂 | 高（需多轮交叉） |

> **关键**：只采表层=画了个好看的壳。必须采到中层和深层，角色才有灵魂。

## 2. 角色档案（10维度）

将采样结果整理为 `素材/[角色名]角色档案.md`，按10维度组织：

| 维度 | 内容 | 采样来源 |
|:-----|:-----|:---------|
| 一、角色概览 | 姓名/道号/称号/兵器/功法/命格/核心气质 | 多轮综合 |
| 二、外貌演变 | 按年龄阶段记录外貌变化 | 第2轮 |
| 三、性格特征 | 5-7个性格侧面+原文佐证 | 第3轮 |
| 四、人际关系 | 与3-5个关键人物的互动模式 | 第5轮 |
| 五、成长弧线 | 6-8个成长阶段（事件+变化） | 全轮综合 |
| 六、金句语录 | 5-10句标志性台词（按主题分类） | 第1轮对话 |
| 七、他人评价 | 旁人/长辈/敌人/龙属的评价（分类） | 第4轮 |
| 八、矛盾与暗面 | 角色的复杂性、阴暗面、非人感 | 全轮综合 |
| 九、视觉设计参考 | 3-8个最适合做OC的关键场景与形象 | 第2轮+视觉筛选 |
| 十、核心意象与符号 | 贯穿全文的视觉符号（3-7个） | 全轮综合 |

> 详细维度说明和范例见 `../pop-visual-shared/references/character-research-guide.md`（角色调研方法论唯一权威源）

## 3. 可选：Pinterest 参考图搜索

角色档案完成后，如果需要视觉风格参考，执行 Pinterest 搜索。

> **非必须**：角色档案已提供足够信息时跳过。用户提供参考图时直接使用。

## 4. 🚪 门禁A：角色档案确认

**这是强制暂停点。禁止跳过。**

向用户呈现角色档案的核心摘要：

```
## 角色档案确认

### 核心气质
[1-2句话概括角色最核心的气质]

### 外貌关键特征
- [特征1]：[原文佐证]
- [特征2]：[原文佐证]
- [特征3]：[原文佐证]

### 最适合做OC的场景
1. [场景名]：[一句话描述]（第XXXXXX行）
2. [场景名]：[一句话描述]（第XXXXXX行）
3. [场景名]：[一句话描述]（第XXXXXX行）

### 核心意象
[列出3-5个视觉符号]

### 核心金句
> "[最 defining 的台词]"（第XXXXXX行）

---
请确认角色理解是否准确，或告诉我遗漏了什么。
确认后我将进入设计阶段。
```

### 4.1 等待用户确认

**禁止自主进入 Step 1。** 必须等用户明确回复后才能继续。

### 4.2 落盘

- 角色档案保存为 `素材/[角色名]角色档案.md`
- 门禁A确认结果追加到 `素材/视觉设计方案.md`

## 5. 进入 Step 1

用户确认角色档案后，读取 `steps/step1-design.md`，基于角色档案选取形态并设计方案。
