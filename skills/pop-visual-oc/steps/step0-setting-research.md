# Step 0: 需求确认 + 设定调研管线

> 先确认需求，再调研设定本体，再谈设计。**OC 不是从零画设定，是从原文系统性采样"这个设定是什么样"，形成立体档案**。五类内容（人物/势力/地理/规则/场景）逻辑一致。

## 0. 需求确认（新增 · 第一步，生成前必问）

动手调研前，先向用户确认以下需求（人话，一次性问清，避免返工）：

| 维度 | 问题 |
|:-----|:-----|
| **内容类型** | 做人物卡/势力卡/地理卡/规则卡/场景卡哪一类？（若不明确，按目标实体推荐） |
| **用途/传播场景** | 用于社交单图传播？封面？设定集？影响画幅与信息密度 |
| **画风偏好** | 国风/暗黑/赛博/水墨等倾向？（可用参考图标定） |
| **是否参考生图** | 有参考图吗？参考点（全面/画风/纯文生图）？ |
| **画幅比例** | 2:3 竖版（默认）/4:3 横版/16:9 横幅？ |

> 需求确认结果记入 `_过程/提示词记录.md`。若用户无明确偏好，用默认值（类型=按实体、画幅=2:3 竖版、国风或按参考图）直接进入调研，不必为低影响偏好反复打扰。

## 1. 资产文件检查（优先路径）

用 LS 扫描 `素材/视觉资产/`，按类型找对应档案：

| 类型 | 档案文件 | 维度 |
|:-----|:---------|:-----|
| 人物 | `[角色名]角色档案.md` | 10 |
| 势力 | `[势力名]势力档案.md` | 8 |
| 地理 | `[地名]地理档案.md` | 7 |
| 规则 | `[规则名]规则档案.md` | 6 |
| 场景 | `场景资产表.md` | 帧 |

档案存在 → 校验维度完整 → 跳到 §4 门禁A。不存在 → 提示可先跑 `pop-visual-asset` 提取，或走 §2 原文采样。

## 2. 关键词搜索 + 上下文采样（回退路径）

用 Grep 搜索原文（找不到原文文件必须问用户，禁止凭记忆设计）。按类型轮次搜索：

| 类型 | 轮次 | 关键词模板（示例实体名） |
|:-----|:-----|:------------------------|
| 人物 | 5轮 | 角色名 / `名.*(眸\|眼\|甲\|氅\|袍\|发)` / `名.*(霸道\|冷\|笑\|怒)` / 他人评价 / `名.*(父亲\|部下)` |
| 势力 | 4轮 | 势力名 / `名.*(宗门\|家族\|王朝\|教派)` / `名.*(弟子\|族人\|信众)` / `名.*(峰\|城\|宫\|殿\|谷)` |
| 地理 | 4轮 | 地名 / `名.*(山\|海\|渊\|宫\|界\|域)` / `名.*(雾\|光\|暗\|冷\|热)` / `名.*(楼\|殿\|塔\|桥\|街)` |
| 规则 | 4轮 | 规则名 / `名.*(光\|纹\|阵\|雷\|焰\|雾\|印记)` / `名.*(突破\|天象\|雷劫\|金光)` / `名.*(印\|镜\|书\|卷\|符\|剑)` |
| 场景 | 帧定位 | `到了\|进入\|来到\|眼前` / 颜色+器物+动作共现 / `怒\|笑\|吼\|惊` |

每个命中用 Read 读前后 20-50 行，采样**三层**：表层（外貌/美学/空间直接描述，画皮）、中层（气质/秩序/氛围，画骨）、深层（评价/隐喻/意象，画魂）。每维度≥3-5 条佐证，记录行号。

## 3. 设定档案（按类型维度）

把采样整理为 `素材/[类型][实体名]档案.md`（维度见 §1 表）。权威方法论：人物=`../pop-visual-shared/references/character-research-guide.md`；势力/地理/规则=`../pop-visual-asset/references/asset-extract-guide.md` §五/§六/§七。

## 4. 🚪 门禁A：设定档案确认（强制暂停，禁止跳过）

向用户呈现：核心气质 / 关键视觉特征（带原文佐证）/ 最适合做卡的内容 / 核心意象（3-5符号）/ 代表词口号。**等用户确认后才能进 Step 1**。档案存 `素材/`，确认结果追记 `_过程/提示词记录.md`。

## 5. 进入 Step 1

用户确认后，读 `steps/step1-design.md` 选类型+版面形态并设计方案。
