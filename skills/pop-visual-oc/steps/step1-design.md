# Step 1: 设计方案（二创设计 + 顶部聚字 + 成图预估）

> 读档案 → 选类型 → **二创五问 + 好看注入六式定立绘** → 顶部聚字文案 → 成图效果预估 → 系列化 → 🚪门禁B：方案对齐。
> **放什么内容**见 `references/content.md`（五类信息架构+文案公式+视觉系统+字体系统）；**怎么排版**见 `references/layout.md`（立绘优先·顶部聚字大范式）；**原文理解→好看注入**见 `references/二创-method.md`（**设计立绘前必读**）。

## 1. 读取输入

1. **需求确认**：Step 0 产出的需求（类型/画幅/画风/参考图偏好）。
2. **设定档案**：读 Step 0 产出的 `素材/[类型][实体名]档案.md`，聚焦气质/视觉/意象/金句。
3. **美术设定集对应篇**（唯一真源）：`素材/美术设定集.md` → 人物篇/势力篇/地理篇/规则篇/场景篇。**版本校验**：用最新版，禁止旧版（防跨版本 gap）。

## 2. 选类型 + 画幅

**类型**：人物卡/势力卡/地理卡/规则卡/场景卡（五类定义见 `references/content.md` §五类）。

**画幅**：2:3 竖版（默认）→ 按需求/参考图可改 4:3 横版 / 16:9 横幅。

## 3. 二创设计立绘（核心 · 质量第一来源）

> **好看是第一生产力，小说原文描述不一定好看。** 立绘是绝对主角，构图/画风/姿态/光影/记忆点是全场第一优先级。动手前**必读 `references/二创-method.md`**，先答**二创五问**，再按**好看注入六式**选招式。**魂和符号从原文锚定，构图姿态光影由设计者注入。**

| 五问 | 答案（写入方案） |
|:-----|:----------------|
| ① 他的魂是什么？ | 性格/身份/处境最核心的一点（原文锚定） |
| ② 他的符号是什么？ | 贯穿的视觉母题/意象（原文锚定，如蝉/碑/麒麟） |
| ③ 他该是什么姿态？ | 用姿态外显①——骄傲就昂首，阴冷就垂眸，癫狂就咧嘴 |
| ④ 他该是什么光？ | 用光影营造②的情绪——神性就金光，压抑就暗部，凄美就冷月 |
| ⑤ 让他多难忘？ | 一个记忆点动作/特效/氛围物，让读者 0.3 秒记住 |

选好招式后，写**立绘构图段**（Step 2 直接拼进生图 prompt，见 `references/layout.md` §立绘构图）：

| 维度 | 产出 |
|:-----|:-----|
| **主体** | 全身/半身？姿态？视角（正面/侧身/仰角）？占画面约 60-65% |
| **位置** | 人物居画面中下部，脚部在画面底部约 10%，头顶在垂直约 55% |
| **顶部留白** | 顶部 40% 纯净背景，显式声明"无任何元素、无第二分身、无杂物" |
| **记忆点** | 二创注入的动作张力/特效/氛围物（好看注入六式） |

> ⚠️ **构图铁律**（`layout.md`）：顶部留白区必须显式声明"无任何元素、无第二分身、无重叠"，否则 AI 常把气流/分身/光效画进顶部，污染文字安全区。人物本体禁止侵入顶部留白区。

## 4. 顶部聚字文案（少量，钩子优先）

按 `references/content.md` §文案公式 填（**组装前必按公式，禁止介绍句**）：

| 字段 | 公式 | 字数 |
|:-----|:-----|:-----|
| 类型标签 | 系列名 + 类型（如"玄鉴仙族·人物卡"） | ≤10字 |
| 名字/标题 | 实体名（鎏金大字） | 第一权重 |
| 称号/定位 | `[最有记忆点的反差/强力特征]` | ≤8字 |
| 金句/箴言（可选） | `「[动作/交易]，换/成/得[结果]」`，有代价/反转 | ≤16字 |
| 印章 | 专属印章（人名朱文/族徽/地标/规则符印/场景图腾） | 印文≤4字 |

**过文案稳定性门禁**（`content.md` §文案公式）：① 有钩子吗？② 圈外人3秒懂吗？③ 字少吗（总模块≤5）？任一不通过回写修正。

> **文字分工标注**（v6 简化）：**全部文字由 HTML 顶部聚字**，AI 底图零文字（G1）。印章由 HTML 底部叠（G2）。不再让 AI 直出任何字。

## 5. 成图效果预估（组装前必填）

**在真正生图前，先用 HTML 骨架占位（`ocr-1flow.tpl.html`），预估加了字之后的最终成品效果**——这是与旧路径最大区别：方案阶段就要"看到"打完字的完整画面，而不是生成后才调整。预估：文字大小/间距/是否在顶部留白区内/与人物头顶是否保持 ≥7% 间距/颜色是否融入底图。让门禁B 时老板看到的是"成图预期"而非"图+文字的文字描述"。

## 6. 系列化规划（如需）

一份档案驱动 N 张图。填 `templates/design-plan-oc.tpl.md` 系列表。**冻结特征**（不变）：人物=眼瞳/轮廓/气质；势力=阵营美学；地理=空间氛围；规则=视觉外显；场景=场景基调。**变量**：服饰/场景/姿态/文字层。

## 7. 选画风 + 回填生图 DNA（核心新增）

`pop-visual-style/references/文风DNA-library.json` 是**生图 DNA 库**（`references/layout.md` §画风联动）：

1. **选画风库条目**：按实体所在小说赛道 + 气质选最匹配的画风条目（如是玄幻→「国漫玄幻厚涂」、暗黑→「暗黑奇幻油画」）。
2. **回填生图 DNA**：把该条目的 `dna`/`constraint`/`recommended_lighting` 供 Step 2 生图用。
3. **据画风定字色**：浅色系留白用深字，深色系留白用浅字（`layout.md` §文字字色）。

| 产出 | 值 |
|:-----|:---|
| 画风库条目 | {{style_entry}} |
| 生图 DNA 来源 | {{dna_source}} |
| 顶部留白底色倾向 | {{bg_tone}}（浅/深 → 定字色） |

> 画风决定立绘质感，也决定顶部留白底色与字色。**画风不匹配再好的构图也白搭**——这是质量第二来源。

## 8. 可选：Pinterest 参考

设定气质参考图（非必须，档案够用即跳过）。画风参考默认用放开吸收公式（只排除场景内容+实体长相）。

## 9. 🚪 门禁B：方案对齐（强制暂停，禁止跳过）

向用户呈现（人话）：类型+画幅 / 设定理解（核心气质+冻结特征）/ **二创设计方案**（五问答案 + 姿态/光影/记忆点 + 立绘构图段）/ **顶部聚字文案**（类型/名字/称号/金句/印章，过稳定性门禁）/ **画风条目 + 字色** / **成图效果预估**（HTML 骨架预览，打完字的样子）。**等用户确认后才能进 Step 2**。方案追记 `_过程/提示词记录.md`，填 `design-plan-oc.tpl.md`。

## 10. 进入 Step 2

方案确认后，读 `steps/step2-generate.md` 生成纯立绘零文字底图并在顶部聚字。
