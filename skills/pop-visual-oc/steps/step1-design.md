# Step 1: 设计方案（基于设定档案）

> 读取设定档案 → 选类型 → 选档位 → 设计信息架构 → 系列化规划 → 🚪门禁B：方案对齐

## 设计哲学

OC 设计方案不是"从零画一个设定"，是**基于设定档案的立体理解，选取最能代表设定的形态/场景，设计文字层信息架构**。

设定档案已经提供了立体信息——Step 1 的职责是：从档案中选取最适合做视觉卡的形态，设计信息架构，并规划系列化产出。

## 1. 读取输入

### 1.1 读取设定档案

读取目标实体对应的档案文件（Step 0 产出或 asset 产出），重点关注：
- **人物**：维度二·外貌演变 / 维度九·视觉设计参考 / 维度十·核心意象 / 维度六·金句 / 维度七·他人评价
- **势力**：人群画像 / 美学基调 / 象征体系 / 等级秩序 / 视觉设计参考
- **地理**：空间质感 / 氛围基调 / 标志性地标 / 生灵种族 / 视觉设计参考
- **规则**：视觉外显 / 层级可视化 / 器物载体 / 视觉设计参考
- **场景**：可定格帧清单（帧编号/氛围基调/叙事含义）

### 1.2 读取美术设定集对应篇（唯一真源）

读取 `素材/美术设定集.md` 对应篇，作为设定本体（冻结提示词/阵营美学/空间氛围/视觉外显/可定格帧）：

| 内容类型 | 读取的美术设定集篇 |
|:---------|:-----------------|
| 人物 | 二 人物篇 |
| 势力 | 五 势力篇 |

> **铁律❌6 版本校验**：读取美术设定集对应篇的**最新版本**，禁止使用旧版。若设定集已升级，用最新版重新生成。

## 2. 类型选择 + 档位选择

### 2.1 类型选择

从五类内容类型中确认要产出哪类卡（用户已指定则直接确认）：

| 类型 | 视觉主体 | 一句话定位 |
|:-----|:---------|:-----------|
| 人物卡 | 角色本人 | 让读者记住这个人 |
| 势力卡 | 阵营/宗门/家族/王朝 | 让读者记住这群人是什么气质 |
| 地理卡 | 城市/小世界/秘境/位面 | 让读者记住这个地方什么感觉 |
| 规则卡 | 力量体系/境界/功法/禁忌 | 让抽象规则被"看到" |
| 场景卡 | 关键场景/名场面瞬间 | 让读者记住这个高光时刻 |

### 2.2 档位选择

确认当前档位：**基础版 / 加强版（OC）/ 设定卡传播版 / HTML组装版 / 3A设定集**。

- 基础版/加强版 → 人物走六层信息架构；设定实体系简单信息卡
- **设定卡传播版** → 模块化信息架构（所有类型通用，见 §3.3）
- **HTML组装版** → AI 出无文字主视觉 + HTML 画册页排版（见 §3.4），**适用于文案多/正式推广物料**
- **3A设定集** → HTML组装版的终极形态，对标 3A 美术设定集信息丰富度（见 §3.5），**适用于对标设定集/信息量大/正式推广**

## 3. 设计信息架构

### 3.0 人物卡：六层信息架构（基础版/加强版）

读取 `references/mode-character.md` 获取六层信息架构详细指南：

| 层级 | 内容 | 来源 |
|:-----|:-----|:-----|
| 第1层 | 角色名+身份 | 角色档案维度一 |
| 第2层 | 称号（四字格） | 从维度三性格+维度七评价提炼 |
| 第3层 | 角色小传（60-100字） | 从维度三+五+八综合创作 |
| 第4层 | 题诗（七言对仗） | 从维度六金句+维度十意象创作 |
| 第5层 | 书法大字（1-2字） | 从维度十核心意象提取 |
| 第6层 | 钤印 | 角色名缩写/称号关键词 |

### 3.1 人物小传创作

按 `references/mode-character.md` 第3层创作公式：
`[性格特质一句话] + [居所/活动场景] + [职业行为/日常] + [一个矛盾或伏笔]`

总字数60-100字，竖排正文。

### 3.2 人物题诗创作

按 `references/mode-character.md` 第4层意象驱动法：
1. 提炼角色最核心的1个画面瞬间
2. 用对仗句式呈现这个画面
3. 植入1个情感锚点词
4. 留白——读者能感受到意境但不完全看懂

2句对仗，每句7字最佳，总计14字。

### 3.3 设定卡传播版：模块化信息架构（所有类型通用）

**人物**走 `references/mode-character.md`「设定卡传播版」章节的 7 大模块（属性/配色/表情/花语/徽章/语录）。

**势力/地理/规则/场景**走 `references/mode-setting-cards.md` 对应类型的模块化信息架构：

| 类型 | 核心模块 | 方法论 |
|:-----|:---------|:-------|
| 势力卡 | 主视觉+势力名定位+阵营美学+象征体系+宣言口号+等级结构 | mode-setting-cards.md §势力卡 |
| 地理卡 | 主视觉+地名定位+氛围基调+标志性地标+当地生灵+象征隐喻 | mode-setting-cards.md §地理卡 |
| 规则卡 | 主视觉载体+规则名定位+层级可视化+外显色板+器物符号+规则一句话 | mode-setting-cards.md §规则卡 |
| 场景卡 | 主视觉高光+场景名定位+氛围基调+关键元素+情境一句话 | mode-setting-cards.md §场景卡 |

> **文字密度铁律（❌8）**：传播版模块化信息总模块≤7，属性/标签每项≤4字、势力名+定位≤8字、口号/隐喻/台词≤15字。信息量过大时**宁可减少模块数**保文字清晰，禁止塞满导致乱码。同时应用"AI画风做减法"差异化原则（❌9）。

> **规则卡可视化策略（从规则篇取）**：器物载体 / 天象异象 / 符号纹路 / 组合，三选一作为主视觉——禁止凭空发明一个与原文无关的符号。

### 3.4 HTML 组装版：画册页信息架构（所有类型通用）

> **必读 `references/mode-album-html.md`**（画册页范式 + 三条铁律 + 排版语言）。

**核心范式**：一张图放在页面中央，四周 HTML 排版。图是主角，HTML 是装裱和排版。

**组装三要素**：
1. **主视觉图**：AI 生成**无文字**高完成度主视觉（从美术设定集对应篇冻结提示词剥离 no text），是独立画框主体
2. **顶部标题区**：系列名 + 类型标签 + 实体名（鎏金渐变大字）+ 定位
3. **信息区**（图框之外）：箴言/口号 + 分割线 + 核心气质 + 等级/色板阵列 + 象征词条

**五类信息架构**（HTML 版文字量放开，可承载完整介绍）：

| 类型 | 顶部标题区 | 图（主视觉） | 信息区推荐模块 |
|:-----|:---------|:-----------|:-------------|
| 人物卡 | 角色名 + 身份定位 | 纯净人物主视觉（零文字零标签零色板） | 称号 · 属性栏 · 配色板 · 花语 · 台词 · 题诗 · 小传 · 表情差分（全由 HTML 承载） |
| 势力卡 | 势力名 + 阵营定位 | 势力代表场景/阵列 | 核心气质 · 等级秩序 · 象征体系 · 宣言 |
| 地理卡 | 地名 + 地理定位 | 地标/空间全景 | 氛围基调 · 标志性地标 · 当地生灵 · 隐喻 |
| 规则卡 | 规则名 + 体系定位 | 规则载体（器物/天象/纹路） | 规则内涵 · 层级 · 外显色板 · 器物符号 |
| 场景卡 | 场景名 + 高光定位 | 场景高光瞬间 | 氛围基调 · 关键元素 · 情境一句话 |

> **人物卡专项（v3.3.0 铁律升级）**：人物卡是信息量最大的类型，**禁止 AI 渲染角色名/称号/属性/色板/tag/台词**——AI 渲染 4-6 个短文本区块是极限，超限必乱码且稀释角色主体。人物卡 HTML 组装版信息架构见 `references/mode-character.md` §人物卡 HTML 组装版（称号/属性栏/配色板/花语/台词/题诗/小传/表情差分全由 HTML 承载），三铁律 P1（主视觉零文字零标签零色板）/P2（信息区在图框外）/P3（角色占画面≥60%）。

> **人物卡多表达图格（v3.5.0 增强）**：人物卡 HTML 组装版默认启用**多表达图格**——主视觉之下挂载 2-5 个表达图格，打破"单张主视觉+文字"的单调。**必读 `references/mode-character-multi.md`**（三类图格：多状态/多视角/日常向 + 三种版式模板 + 图格标注规范 + 角色一致性锚点）。设计时选主视觉形态 + 选图格类型（可组合）+ 规划每格内容（状态/视角/场景 + 标注）+ 确认图格比例（state=3:4竖图 2列 / view=1:1方图 4列 / daily=4:3横图 3列）。

> **画册页三条铁律（mode-album-html.md）**：①图是主角，HTML 是装裱（禁止图铺满当 background）；②主视觉零文字（AI 不画字，文案全由 HTML 承载）；③信息区在图框之外，不压图主体。

### 3.4.1 文案设计规范（v3.4.0 稳定性升级，HTML 组装版必读）

> **必读 `references/mode-album-html.md` §文案设计规范**。文案是 HTML 组装版的核心价值，**不稳定根因是没按公式写**。本 step 门禁B 呈现前，HTML 组装版的定位线/箴言/机制/体系四个文案字段必须**按 SOP 公式填写**，禁止自由发挥。

**四个文案模块的公式速查**（对标「借香他化」成功成品）：

| 字段 | 公式 | 判据 |
|:-----|:-----|:-----|
| **定位线 positioning** | `[核心元素]即[本质] · [命运/结果]` | 一句话点出核心悖论，≤14字 |
| **箴言 creed（钩子）** | `「[具体动作/交易]，换/成/得 [结果]」`——有代价/反转 | 是台词不是介绍句，≤16字 |
| **机制 core** | `[体系]：谁做什么→换来什么→代价/反转` | 圈外人读完能复述 |
| **体系 ranks/symbols** | 层级递进链 + 象征键值对（值=它在世界观里意味着什么） | 键是具象物 |

> **文案稳定性门禁（四问）**：①有钩子吗？②讲清机制了吗？③有黑话吗（专有名词紧跟冒号白话解释）？④圈外人3秒懂吗？**任一不通过即回写修正，禁止带介绍句风格的无钩子文案进入门禁B。**

### 3.5 3A 设定集：信息架构 + 门禁B 专项（v3.7.0）

> **必读 `references/mode-3a-setting-collection.md`**（3A 设定集方法论：六个 3A 结构 + 多类型模块映射 + 画风多元适配 + 六项验收）。

当档位为 **3A 设定集**时，在 §3.4 画册页信息架构基础上，新增 3A 信息架构设计：

**1. 多视图网格**：主视觉之外设计 3-6 个多状态/多视角/多角度图格（按类型选：人物=情绪/视角/日常；势力=阵营阵列/代表场景；地理=地标/昼夜；规则=载体多格；场景=高光多帧）。素材优先复用存量视觉，缺则用 `crop_details.py` 裁图过渡。

**2. 细节裁图规划**：设计 2-4 处细节特写（人物=五官/配饰/法器；势力=旗帜/纹章；地理=地标/生灵；规则=器物/纹路；场景=主体局部/冲突落点）。用 `crop_details.py` 从存量主视觉裁。

**3. 专属印章设计**：每实体一个印章（人物=人名朱文印/势力=族徽印/地理=地标徽记印/规则=符印圆印/场景=场景图腾可双印对照），印文≤4字。

**4. 01-07 编号模块**：信息区全部带编号徽标。模块映射见 `mode-3a-setting-collection.md` §结构3 表格（人物=称号/细节/属性/配色/花语/台词/小传；势力=定位/细节/气质/等级/象征/色板/宣言；…）。**可缺省到 5 字段，编号连续跳过即可。**

**5. 文化沉浸 + 角落篆刻水印**：竖排题诗 + 几何纹饰 + 中英双语标签；水印用右下角 `popwave` 篆刻签名章（铁律❌15，替代横条）。

## 4. 系列化规划

读取 `templates/design-plan-oc.tpl.md` 模板，填写系列化规划表。

一份设定档案可驱动 N 张系列图：

| 类型 | 系列方向 |
|:-----|:---------|
| 人物 | 形态演变系列 / 核心场景系列 / 群像关系系列 |
| 势力 | 阵营美学沿革 / 代表场景 / 势力群像 |
| 地理 | 地标节点系列 / 四季昼夜 / 小世界全景 |
| 规则 | 层级可视化系列 / 突破异象系列 |
| 场景 | 同一场景多帧 / 递进叙事 |

### 4.1 冻结核心特征（系列一致性）

从设定档案+美术设定集对应篇提取系列图中不变的视觉锚点：

| 类型 | 冻结特征 |
|:-----|:---------|
| 人物 | 眼瞳色 / 面部轮廓 / 核心气质 |
| 势力 | 阵营美学（标志色+纹饰） |
| 地理 | 空间质感 / 氛围基调 |
| 规则 | 视觉外显（光效/纹路/器物） |
| 场景 | 场景基调 / 关键元素 |

### 4.2 变量特征（系列差异化）

系列图中变化的元素：服饰/场景背景/姿态动作/层级/细节，文字层可随场景变化。

## 5. 可选：Pinterest 参考图搜索

如果需要视觉风格参考，执行 Pinterest 搜索（设定气质参考图）。

> **非必须**：设定档案已提供足够信息时跳过。用户提供参考图时直接使用。

搜索维度：实体气质关键词 + 赛道风格 + IP视觉DNA（同人时）。画风参考默认用放开吸收公式（只排除场景内容+实体长相，实体长相排除正好保护实体一致性）。

## 6. 选择布局模板

根据信息层级选择布局模板：

- **人物卡**：底部面板型 / 侧边条型 / 叠加层型 / 四角分布型 / 右侧古籍版式型（详见 `mode-character.md`）
- **设定实体卡（势力/地理/规则/场景传播版）**：设定卡模块化版式（详见 `mode-setting-cards.md` §通用布局——顶部标题区+主视觉+右侧色板/象征块+底部情感点）
- **HTML组装版**：**画册页版式**（一张图居中 + 四周 HTML 装裱排版，详见 `mode-album-html.md` §核心范式 + `templates/album-card.tpl.html`）
- **3A设定集**：**3A设定集版式**（多视图网格 + 细节特写引线 + 01-07编号 + 专属印章 + 文化沉浸 + 角落篆刻水印，详见 `mode-3a-setting-collection.md` + `templates/album-3a-*.tpl.html`）
