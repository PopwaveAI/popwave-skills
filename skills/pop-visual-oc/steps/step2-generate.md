# Step 2: 生成含字槽底图 + 字槽补字 + 截图

> 读确认方案 → **生成含预留字槽的底图**（AI 直出完整构图：画面主体 + 短书法题字 + 印章 + 预留字槽留白块）→ **HTML 在字槽补长效文字** → 整图截图 → 落盘三态 → 系列化循环。
> **大范式铁律（layout.md）**：A1 图是主角 / A2 字槽规划先行 / A3 信息区不压图 / A4 文字分工守则（短书法字 AI 直出，长效文字 HTML 补）。

## 1. 读输入

读 `_过程/提示词记录.md` + `design-plan-oc.tpl.md` 方案：档案路径 / 字槽规划（哪些区域留白给长效文字）/ 画面元素 / 短书法字放哪几处 / 冻结特征 / 参考图 / 画幅比例。

## 2. 生成含字槽底图（AI 直出完整构图）

**🔴 主视觉必须由 pop 直出（`image_generate` 工具）**——本地直出画面质量远不及 pop 直出 Seedream。无 `image_generate` 时暂停等待，禁止擅自用本地工具出图。

提示词按 `references/layout.md` §字槽规划要点 4 块结构拼（`../pop-visual-shared/references/seedream-prompt-guide.md` §三），**画风用 Step 1 选的画风库条目 DNA**（`style-dna-library.json` 的 `dna`/`constraint`/`recommended_lighting` 回填），**关键差异**：画面主体之外，**必须用自然语言明确预留字槽空白块**（铁律 A2），并让 AI 直出短书法字（题字/印章，每处≤4字，铁律 A4）：

```
[画风 DNA（Step 1 画风库条目回填，或画风库无匹配时按赛道写好写意/霓虹/极简/暗黑质感）]
[画面主体 + 站位/层次/视角]
[四周/指定区域预留干净留白块——无图案、无纹理干扰、纯背景色，用于叠加文字]
[短书法字：标题/印章/器物标签，每处≤4字，书法体（如 [画面右上写书法字"XXX"]）]
[环境/光源/氛围]
[硬约束：负面清单 + 冻结特征清单（§5 系列一致性）]
```

**有参考图时**按意图选模式（详见 prompt-guide §三）：模式A 全面参考（提示词≤200字只改差异）/ 模式B 画风参考（放开吸收只排除场景+长相）/ 模式C 纯文生图。

```
image_generate(prompt='[提示词]', size='1125x1500', ref_image='[参考图，如有]', output='测试/{类型}/{类型}-{实体名}-v1.png')
```

> 出图后**检查预留字槽是否干净**：若留白块被图案/纹理污染，或短书法字乱码，回写出图（v2, v3...）。字槽不干净 → 文字没地方放，直接打回。

## 3. HTML 在字槽补长效文字（`ocr-1flow.tpl.html`）

复制底图到 `测试/{类型}/`，用 `templates/ocr-1flow.tpl.html` 组装（**唯一模板**，CSS 变量驱动五类+画风）：

| 填什么 | 占位符 | 约束 |
|:-------|:-------|:-----|
| 底图路径 | `{{visual_path}}` | AI 直出完整构图 |
| 赛道 token | `data-track="{{track}}"` | 按 `references/layout.md` §跨赛道映射（古风/赛博朋克/都市现代/科幻/暗黑） |
| 引首章 | `{{lead_seal}}` | ≤4字，AI 直出或 HTML 补 |
| 题头 | `{{kicker}}` | 系列名 + 篇目 |
| 金句 | `{{creed_q}}` / `{{creed_src}}` | 无标点直书，大字行楷 |
| 小传/词条本文 | `{{core_body}}` | 仿宋，无现代引号 |
| 属性/象征词条 | `{{sym_rows}}` | 错落排布，非对齐表格 |
| 落款 | `{{foot_name}}` / `{{foot_zhu}}` / `{{foot_seal}}` | 款识 |

**组装时**：
- **字槽位置必须与底图预留留白块对齐**——改 `:root` 的 `--slot-x / --slot-y / --slot-w` 变量，让 overlay 精确落在底图留白区（铁律 A3）
- 文字色从底图纸面取（`--ink / --red / --gold`），保证融入不割裂
- 文案按 `references/content.md` 公式填（组装前必过稳定性四问）；同一张卡最多 2 种字体
- **短书法字（≤4字）若已在底图 AI 直出，则 HTML 不再重复叠加**（铁律 A4）

**截整图**（2:3 竖版默认）：
```
SCREENSHOT_WIDTH=1125 SCREENSHOT_SCALE=2 python scripts/screenshot_album.py '<html>' '<out.png>'
```
画幅改横版/横幅时，同步改 `:root` 的 `--cv-w / --cv-h` 与截图 width。

**失败中断**：字槽文字溢出留白块 / 文字压到图主体 / 底图缺预留留白 / 短书法字乱码，任一即截图失败，修正后重截，禁止带残缺交付。

## 4. 落盘三态

- 候选：`测试/{类型}/`；用户确认后复制到 `成品/{类型}/`（加 `-final`）
- HTML+成品图：`成品/{类型}/{类型}-{实体名}-{形态}.html` + `-成品.png`
- 设计记录：`_过程/提示词记录.md`（追加生成记录：模型/类型/实体/形态/参考模式/提示词/字槽规划/冻结特征/输出/状态）

## 5. 系列化循环（如需）

对系列表每张图：复制冻结特征（HARD CONSTRAINTS 块）→ 更新变量特征（服饰/场景/姿态/文字层）→ 重新组装提示词 → 生成（文件名 v2, v3...）→ 一致性检查（冻结特征不变 + 字槽位置不变）。

## 6. 自检

- [ ] 底图为 pop 直出（image_generate），非本地工具
- [ ] 画风用 Step 1 画风库条目 DNA 回填（无匹配时按赛道写好写意/霓虹/极简/暗黑）
- [ ] 底图构图饱满，边界完整，图是主角（A1）
- [ ] **字槽规划已落实**：提示词明确预留字槽空白块，出图后留白块干净（A2）
- [ ] 短书法字 AI 直出（题字/印章≤4字），未乱码（A4）
- [ ] 长效文字全部 HTML 在字槽补，字槽位置与底图留白对齐，不压图主体（A3）
- [ ] 冻结特征已嵌入 HARD CONSTRAINTS
- [ ] 文案按公式填写，稳定性四问通过（❌6）
- [ ] 字体用本机书法系统（❌7），同一张卡≤2种字体
- [ ] 整图已截图，字槽文字无溢出，四段不缺
- [ ] 落盘三态完成，提示词记录已回写（❌4）

## 7. 迭代（快速路径）

用户要求修改已生成图时，跳过 Step 0/1，直接读 `_过程/提示词记录.md` 上一版方案，改对应维度重新生成（v2, v3...）。仅当要求"重新设计/换方向"时回到完整流程。
