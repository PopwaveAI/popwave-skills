# Step 2: 生成纯立绘零文字底图 + 顶部聚字 + 截图

> 读确认方案 → **生成纯立绘零文字底图**（AI 只出人物/视觉主体，占画面≥60%，顶部留≥40%净空）→ **HTML 顶部聚字**（类型/名字/称号/金句/印章）→ 整图截图 → 落盘三态 → 系列化循环。
> **大范式铁律（layout.md）**：G1 AI 零文字 / G2 文字顶部聚 / G3 字不压人物 / G4 字少而精。

## 1. 读输入

读 `_过程/提示词记录.md` + `design-plan-oc.tpl.md` 方案：档案路径 / **二创设计方案（五问答案 + 立绘构图段）** / 顶部聚字文案 / 画风条目 DNA / 冻结特征 / 参考图 / 画幅比例。

## 2. 生成纯立绘零文字底图

**🔴 主视觉必须由 pop 直出（`image_generate` 工具）**——本地直出画面质量远不及 pop 直出 Seedream。无 `image_generate` 时暂停等待，禁止擅自用本地工具出图。

提示词按 `references/layout.md` §立绘构图 组装，**画风用 Step 1 选的画风库条目 DNA**（`文风DNA-library.json` 的 `dna`/`constraint`/`recommended_lighting` 回填），**关键差异（v6）**：AI 底图**零文字**（G1），构图保证**顶部留白**（G2）：

```
[画风 DNA（Step 1 画风库条目回填，或画风库无匹配时按赛道写质感）]
[主体：<实体>全身/半身立绘，姿态<N>，视角<正面/侧身/仰角>，占画面约60-65%]
[位置：人物居画面中下部，脚部在画面底部约10%，头顶在画面垂直约55%]
[顶部留白：画面顶部40%为纯净背景色，无任何元素、无第二分身、无杂物，用于后续叠加标题]
[记忆点：二创注入的动作张力/特效/氛围物]
[环境/光源/氛围]
[硬约束：负面清单（含 No text overlay, no text, no letters, no watermark, no seal）+ 冻结特征清单（§5 系列一致性）]
```

> ⚠️ **构图铁律**：顶部留白区必须显式声明"无任何元素、无第二分身、无重叠"（详见 `layout.md` §立绘构图）。**AI 底图零文字**——提示词负面清单必须含 `No text overlay, no text, no letters, no watermark, no seal`，禁止让 AI 直出任何字（G1）。

**有参考图时**按意图选模式（详见 prompt-guide §三）：模式A 全面参考（提示词≤200字只改差异）/ 模式B 画风参考（放开吸收只排除场景+长相）/ 模式C 纯文生图。

```
image_generate(prompt='[提示词]', size='1125x1500', ref_image='[参考图，如有]', output='测试/{类型}/{类型}-{实体名}-v1.png')
```

> 出图后**检查顶部留白是否纯净**：若顶部被气流/分身/光效污染，或出现任何文字/水印，回写出图（v2, v3...）。顶部不净 → 文字没地方放，直接打回。

## 3. HTML 顶部聚字（`ocr-1flow.tpl.html`）

复制底图到 `测试/{类型}/`，用 `templates/ocr-1flow.tpl.html` 组装（**唯一模板**，CSS 变量驱动五类+画风）：

| 填什么 | 占位符/CSS变量 | 约束 |
|:-------|:-------------|:-----|
| 底图路径 | `{{visual_path}}` | AI 直出纯立绘零文字 |
| 类型标签 | `{{kicker}}` | 系列名 + 类型，≤10字 |
| 名字/标题 | `{{name}}` | 第一权重，楷体 |
| 称号/定位 | `{{subtitle}}` | ≤8字，仿宋/隶书 |
| 金句（可选） | `{{creed}}` | ≤16字，钩子，仿宋 |
| 印章 | `{{seal}}` / `{{seal_cap}}` | 印文≤4字，底部，避开人物下摆 |
| 字色 | `--ink / --em / --gold / --muted` | 从底图顶部留白实际取色（浅底深字/深底浅字） |
| 画幅 | `--cv-w / --cv-h` | 与底图比例一致 |

**组装时**：
- **文字只落顶部纯背景区**（G2），与人物头顶保持 ≥7% 画布间距（G3）——不够则调小字号/上移，**禁止压人物**
- 文字色从底图顶部留白取（`--ink/--em/--gold`），保证融入不割裂
- 文案按 `references/content.md` 公式填（组装前必过稳定性门禁）；同一张卡最多 2 种字体
- 底部印章避开人物下摆（G2），必要时并入顶部

**截整图**（2:3 竖版默认）：
```
SCREENSHOT_WIDTH=1125 SCREENSHOT_SCALE=2 python scripts/screenshot_album.py '<html>' '<out.png>'
```
画幅改横版/横幅时，同步改 `:root` 的 `--cv-w / --cv-h` 与截图 width。

**失败中断**：文字溢出顶部留白 / 文字压到人物 / 顶部留白不净 / 底图出现文字，任一即截图失败，修正后重截，禁止带残缺交付。

## 4. 落盘三态

- 候选：`测试/{类型}/`；用户确认后复制到 `成品/{类型}/`（加 `-final`）
- HTML+成品图：`成品/{类型}/{类型}-{实体名}-{形态}.html` + `-成品.png`
- 设计记录：`_过程/提示词记录.md`（追加生成记录：模型/类型/实体/形态/参考模式/提示词/二创设计/冻结特征/输出/状态）

## 5. 系列化循环（如需）

对系列表每张图：复制冻结特征（HARD CONSTRAINTS 块）→ 更新变量特征（服饰/场景/姿态/文字层）→ 重新组装提示词 → 生成（文件名 v2, v3...）→ 一致性检查（冻结特征不变 + 顶部留白仍纯净）。

## 6. 自检

- [ ] 底图为 pop 直出（image_generate），非本地工具
- [ ] 画风用 Step 1 画风库条目 DNA 回填（无匹配时按赛道写质感）
- [ ] 底图构图饱满，边界完整，人物居画面中下部，顶部留白纯净（G1/G2）
- [ ] **AI 底图零文字**：无任何字/字母/数字/水印/印章（G1）
- [ ] 顶部聚字：文字只落顶部纯背景，与人物头顶 ≥7% 间距，不压人物（G2/G3）
- [ ] 字少而精：总模块≤5（类型/名字/称号/金句/印章）（G4）
- [ ] 冻结特征已嵌入 HARD CONSTRAINTS
- [ ] 文案按公式填写，稳定性门禁通过（❌6）
- [ ] 字体用本机书法系统（❌7），同一张卡≤2种字体
- [ ] 整图已截图，顶部文字无溢出，四段不缺
- [ ] 落盘三态完成，提示词记录已回写（❌4）

## 7. 迭代（快速路径）

用户要求修改已生成图时，跳过 Step 0/1，直接读 `_过程/提示词记录.md` 上一版方案，改对应维度重新生成（v2, v3...）。仅当要求"重新设计/换方向"时回到完整流程。
