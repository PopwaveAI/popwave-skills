# pop-visual-pipeline

> 小说视觉化总控管线。Phase 0→6路由调度。把 7 个 visual 子 skill 串成一条工程流：**基建层（读小说→定画风→设计人物）是必做地基，派生层（封面/OC/场景/漫画）按需产出**。v1.1.0

---

## 做什么

pipeline 只做路由不干活——读视觉项目总控.html判断 phase→路由到对应子 skill→完成后更新 html。不提取资产、不选画风、不设计人物、不画图、不生成漫画。

输入：项目名或当前项目目录（mode=fresh/import/resume）
输出：标准化目录结构 + `视觉项目总控.html`（唯一状态文件）

**核心价值**：visual 群原本是散点——7 个 skill 各自独立，没有顺序约束，导致"没定画风就先画封面""没设计人物身份就先出漫画"的乱序。本 pipeline 把"**定画风 + 人物形象设计 = 基建**"这条老板定调的铁律固化成工程流，所有派生产出（封面/OC/场景/漫画）都必须先消费基建。

---

## 怎么操作（SOP骨架）

1. **Step 0**（初始化）→ `steps/step0-init.md`：创建标准目录 + 生成视觉项目总控.html + 自检
2. **Step 1**（导入/续写）→ `steps/step1-import.md`：已有项目扫描→资产归位→调度子skill reconstruct补跑→落地Phase决策
3. **Step 2**（路由循环）→ `steps/step2-route.md`：读html→按Phase路由表调度子skill→SearchReplace更新html

### Phase 路由表

> **两段式架构**：Phase 0-2 是**基建层**（必做，顺序不可跳），Phase 3-6 是**派生层**（按需，在基建就绪后任意触发）。

| Phase | 调用Skill | 定位 | 前置检查 | 产出 |
|:--|:--|:--|:--|:--|
| **0** | `pop-visual-asset` | 读小说理解 | state=init/import+正文文件就绪 | `素材/视觉资产/`（角色档案+场景资产表+视觉符号库+IP视觉DNA） |
| **1** | `pop-visual-style` | 定画风 | 资产就绪 | `素材/风格/画风决策.md`（选定基准+配色+风格串）+ **画风定标图**（签核✅） |
| **2** | `pop-visual-character` | 设计人物形象 | 资产+画风就绪 | `素材/视觉资产/[角色名]视觉身份卡.md`（全下游唯一真源）+ **角色定妆图**（签核✅） |
| **3** | `pop-visual-cover` | 封面图 | 基建就绪（身份卡可读） | `素材/视觉/封面-{书}-v1.png` |
| **4** | `pop-visual-oc` | 人物OC | 基建就绪（身份卡可读） | `素材/视觉/OC-{角色}-v1.png` |
| **5** | `pop-visual-cover`(场景) | 场景图 | 基建就绪（身份卡可读） | `素材/视觉/场景-{名}-v1.png` |
| **6** | `pop-visual-comic` | 漫画 | 基建就绪（身份卡可读） | `漫画/`（定妆图+分镜+漫画页+HTML） |

> **基建就绪门禁**：进入 Phase 3-6 前必须验证 `素材/视觉资产/[角色名]视觉身份卡.md` 存在且**签核状态为 ✅ 已认可**（含角色定妆图），同时 `素材/风格/画风决策.md` 签核状态为 ✅ 已认可（含画风定标图）。基建产出未签核 = 地基未完成 = 禁止派生产出。老板定调：**定画风 + 人物形象设计是整个项目的基建**，派生层必须消费它。本文档经签核冻结的图 + 文字定义即为全书基线资产，供派生层复用。

> **派生层触发规则**：Phase 3-6 之间**不是线性顺序**，是**按需路由**。用户说"出封面"→Phase 3；"出OC"→Phase 4；"出场景图"→Phase 5；"出漫画"→Phase 6。无论哪个，都先检查基建就绪门禁。

## 红线

1. **读取协议**：每次对话第一件事读视觉项目总控.html获取当前phase→按路由表调度。禁止跳过读html直接干活。
2. **pipeline只做路由不干活**——所有产出由下游skill生成。pipeline不直接提取资产/选画风/设计人物/画图/生成漫画。
3. **基建层依赖链不可跳过**——资产没就绪不进定画风，画风没就绪不进人物设计，基建没就绪不进任何派生产出。
4. **基建就绪门禁强制**——进入派生层（Phase 3-6）前必须验证角色视觉身份卡存在且签核为 ✅ 已认可，画风决策签核为 ✅ 已认可。未签核=报错中止，提示先跑基建并完成定标/定妆。
5. **身份卡是唯一真源**——派生层（cover/oc/comic）只消费身份卡，禁止各自重建角色身份。身份改动必须回 character 升级身份卡版本。
