# 你的小说，能变成什么样？

> 用途：用户第一次触发视觉专家（无任何视觉项目、非续写场景）时，由主 agent 直接输出以下引导语。**声明本条为功能介绍 + 引导，未执行 skill 任务**，以「作者 / 漫画人 / 同人爱好者」的视角快速建立「我能把小说变成什么」的场景认知，再引导开展第一步。

---

老板，收到。先声明：**这次没动用什么干活，只是带你看看**——你这本小说，在我手上能"长"成什么样。

## 一句话说清

**你写的是文字，我把它变成看得见的作品。** 不用你懂任何技术，你只要告诉我书名和想要什么，剩下的我全包。

## 你有这些玩法

### 🎨 封面 —— 让小说在书架上被一眼看到
写完了 / 正在写的小说，想要一张能发出去、能一眼抓住人的封面。读者扫过书架，0.3 秒决定要不要点开——我给你的，就是这"第一眼"的杀伤力。

### 🧑 人物立绘 / OC —— 让角色"活"在你眼前
你脑子里那个角色，把他画出来。一张能收藏、能当壁纸、能发社交平台的立绘，附上人物设定小卡。原创角色、同人 OC 都可以。

### 📖 漫画 —— 把情节画成一章章能追更的连载
想把关键情节、甚至整本书，画成能一页页往下翻的漫画。分镜、台词、情绪、氛围都替你排好，**没看过你原著的读者也能看懂**。发出去就是连载，追更感拉满。

只做一样可以，全都要也行——封面、立绘、漫画一起上，一套画风从头到尾不串味。

## 你不用担心

- **人物画风一致**：同一个角色，封面、立绘、漫画用的是同一张脸、同一套风格，不会出现"换个画面就换张脸"的尴尬
- **不用你懂技术**：你只管给书名 + 想法，流程我全包
- **先小样、再开整**：先出 1-2 张样张给你看画风手感，你满意了我们再铺开做整本 / 整章，不让你白等

## 就这样开始

**直接把「书名 + 你想做什么」丢给我就行。**

比如：
- 《诡秘之主》，做封面
- 我这本书，画主角的立绘
- 这部写一半了，把前几章做成漫画

想好了就直接说，我这就开工。
