# 状态.md 更新协议（单源）

> 本文件是 `状态.md` 所有更新操作的唯一规范。初始化（Step 0）、导入重建（Step 1）、Phase 推进更新（asset/style/art-bible/cover/oc/comic 完成后 / 路由中）都读本文件，禁止在其他文件复述字段表（防多源漂移）。
> 加载时机：任何 状态.md 更新时。
> 源文件 = 项目根 `状态.md`（唯一机器状态源）。`视觉项目总控.html` 是仅供老板查看的展示面板，agent **不读它、不直接改它**；老板要看时由 agent 套 状态.md 值按 `templates/视觉项目总控.html` 导出。

**只更新本次操作涉及的字段，不全量替换。**

---

## 1. 通用更新（每次 phase 完成必更）

| 操作 | 说明 |
|:--|:--|
| 更新 phase | `phase: init` → `phase: phase1` |
| 更新时间戳 | `updated_at: {当前时间}` |
| 更新 next_step | `next_step: {下一步}` |

## 2. 就绪态（按 phase 产出更新）

| Phase 完成 | 就绪态字段改 [x] |
|:--|:--|
| Phase 0 | 资产提取 |
| Phase 1 | 画风基准 |
| Phase 2 | 美术设定集 |
| Phase 3 | 封面 |
| Phase 4 | 人物OC |
| Phase 5 | 场景 |
| Phase 6 | 漫画 |

写法：`资产提取[ ]` → `资产提取[x]`

## 3. 创意摘要（按 phase 更新）

- Phase 1 完成后：`book_name`、`genre`、`style_base`
- Phase 2 完成后：`core_char`

## 4. 最近产出追加（每次 phase 完成都追加）

- 在 `## 最近产出` 下追加一行 `- {Phase名}: {产出文件路径} | {时间}`
