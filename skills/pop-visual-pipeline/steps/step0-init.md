# step0 · 初始化视觉项目

> 本文件是 pop-visual-pipeline 第一步执行指令。state=init 且无已有文件时执行。

## 目标

创建标准目录 + 生成 `视觉项目总控.html` + 自检。只做地基，不干活。

## 执行

### 1. 项目空间探测

| 探测信号 | 项目类型 | 原文路径 | 处理 |
|:---------|:---------|:---------|:-----|
| `项目总控.html` | 写作专家·起点 | `正文/ch*.txt` | import 模式，走 step1 |
| `project-state.md` | 写作专家·番茄 | `正文/ch*.txt` | import 模式，走 step1 |
| `原料/小说原文/` | 独立小说项目 | 单个完整 txt | init 模式 |
| 用户指定路径 | 临时模式 | 指定文件 | init 模式 |

- 若检测到已有项目文件 → 转入 `steps/step1-import.md`
- 若是全新项目 → 继续本 step

### 1.5 🚪 意图闸口（前置，决定基建档位）

> **目的**：先问用户这次要做什么，由意图决定基建深度，杜绝"默认奔漫画"。用户可能只做封面/OC/场景，不需要完整漫画基建（双角度定妆/深度角色档案）。

**询问**：用 `AskUserQuestion` 或书面提问，让用户明确本次目标：

| 目标 | intent 值 | 基建档位 | 说明 |
|:-----|:---------|:---------|:-----|
| 做封面 / 场景图 | `cover` | 轻量 | 只需场景资产表+视觉符号+画风，刊物角色可跳过双角度定妆 |
| 做人物 OC / 立绘 | `oc` | 轻量~中 | 需角色档案+身份卡+画风，可跳过 comic 双角度定妆 |
| 做漫画 / 连载 | `comic` | 完整 | 需完整基建（深度角色档案+画风定标+身份卡+双角度定妆） |
| 全套视觉工程 | `full` | 完整 | 封面+OC+漫画都要，走完整基建 |
| 只提取资产 | `asset-only` | 最轻 | 只跑 asset，不进派生层 |

**未明确时**：不默认漫画，回问用户。只有当用户明确说"做漫画/连载"才走 `comic` 完整档。

> **记录**：intent 值写入总控 `<!--STATE:intent -->`，全链路按档位路由。

### 2. 创建标准目录

在项目根目录创建以下目录（用 LS 确认，不存在则创建）。**落盘三态（成品/测试/_过程）与基建真源（素材/）是视觉管线唯一权威分区，见 `references/落盘规范.md`**：

```
{项目}/正文/
{项目}/素材/视觉资产/      # 基建真源：设定档案（asset 产出）
{项目}/素材/风格/           # 基建真源：画风决策 + 冻结定标图
{项目}/素材/ref-cache/      # 基建真源：Pinterest 参考图
{项目}/漫画/assets/characters/   # 漫画工程：定妆生产参考
{项目}/成品/                # 三态-成品：用户确认的对外发布图
{项目}/测试/                # 三态-测试：未确认候选/变体/定标/定妆初稿
{项目}/_过程/               # 三态-过程：原始图/脚本/任务清单/提示词记录
```

> **禁止** 再建 `素材/视觉/` 扁平目录；封面/OC/画册页/定标/复现一律按三态落盘（候选→`测试/`，确认→`成品/`）。

### 3. 生成视觉项目总控.html

读取 `templates/视觉项目总控.html` 全文，复制到项目根目录 `视觉项目总控.html`。

用 SearchReplace 填充以下 STATE 字段（用 `<!--STATE:xxx -->` 标记）：

| 字段 | 初始值 |
|:-----|:-------|
| `mode` | `fresh` |
| `phase` | `init` |
| `intent` | 意图闸口确认值（cover/oc/comic/full/asset-only） |
| `project_name` | 项目名（用户输入或目录名） |
| `book_name` | 待指定 |
| `genre` | 待指定 |
| `created_at` | 当前时间 |
| `updated_at` | 当前时间 |
| `next_step` | `Phase 0: 按意图档位读小说提取视觉资产` |

### 4. 自检

- [ ] 9 个标准目录存在（正文/ 素材/视觉资产/ 素材/风格/ 素材/ref-cache/ 漫画/assets/characters/ 成品/ 测试/ _过程/）
- [ ] 视觉项目总控.html 生成且 STATE 字段正确
- [ ] phase=init，next_step=Phase 0

### 5. 路由到 Phase 0

自检通过后，调度 `pop-visual-asset` 执行 Phase 0（读小说提取视觉资产），进入 `steps/step2-route.md` 的路由循环。

## 红线

- 只创建地基，不提取资产/不选画风/不设计人物（这些是 Phase 0/1/2 的事）
- 视觉项目总控.html 是唯一状态文件，禁止另建 project-state.md
