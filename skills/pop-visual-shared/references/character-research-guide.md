# 角色档案·角色调研方法论

> 从小说原文中系统性地采样角色信息，形成立体化的角色档案。基于《玄鉴仙族》李周巍案例验证。
> 本文件是角色档案方法的**唯一权威在源**，由 `pop-visual-asset`（提取）与 `pop-visual-oc`（调研）共用。任何 skill 禁止本地重建副本。

## 核心理念

**角色调研不是"找外貌描写"，是"理解一个人"。**

一个角色的视觉设计，如果不建立在对角色立体理解的基础上，画出来的只是一个好看的壳。读者看了不会记住这个人——因为图里没有灵魂。

角色立体化的三个层次：

| 层次 | 采集内容 | 比喻 | 没有的后果 |
|:-----|:---------|:-----|:---------|
| 表层 | 外貌描写（发色/眼瞳/服饰/体型） | 画皮 | 没有视觉特征 |
| 中层 | 性格特征+行为模式+说话方式 | 画骨 | 有特征但没性格 |
| 深层 | 他人评价+矛盾暗面+成长弧线 | 画魂 | 有性格但没灵魂 |

> **李周巍案例**：暗金眸子是表层，虎豹般的野性是中层，"为我而死，岂不应当"的帝王冷酷是深层。三层都有，角色才立体。

## 关键词搜索策略

### 搜索工具

使用 Grep 工具搜索小说原文文件：
- pattern: 关键词（支持正则，用 `|` 分隔多个词）
- output_mode: content
- -n: true（显示行号）
- path: 小说原文文件路径

### 五轮搜索法

| 轮次 | 关键词类型 | Grep pattern 示例 | 目的 |
|:-----|:---------|:-----------------|:-----|
| 第1轮 | 角色名 | `李周巍` | 定位所有出场段落 |
| 第2轮 | 外貌词 | `李周巍.*(眸|眼|甲|氅|袍|发|面|皮肤)` | 采集外貌描写 |
| 第3轮 | 性格词 | `李周巍.*(霸道|虎豹|冷|笑|怒|狡|威)` | 采集性格特征 |
| 第4轮 | 评价词 | `白麟|魏王|李氏天骄|白麟转世` | 采集他人评价 |
| 第5轮 | 关系词 | `李周巍.*(父亲|母亲|叔公|部下|儿子)` | 采集人际关系 |

> 第2-5轮的 pattern 可根据第1轮的结果调整。如果角色有多个称呼（如李周巍=魏王=白麟=明煌），需要在每轮搜索中都包含。

### 上下文扩展

Grep 命中后，用 Read 工具读取命中行前后20-50行：

```
Read(file_path="小说原文.txt", offset=命中行号-20, limit=50)
```

> 原文中的角色描写往往是分散的——一句话外貌、一句话动作、一句话评价，散布在不同章节。采样时要像拼图一样，一块块拼出完整的角色形象。

## 10维度档案模板

### 维度一：角色概览

| 项目 | 内容 | 采样来源 |
|------|------|:-------|
| 姓名 | [角色全名] | 第1轮 |
| 道号/字号 | [如有] | 第1轮 |
| 称号 | [所有称号/外号] | 第1轮+第4轮 |
| 兵器 | [所有兵器名称+描述] | 第2轮 |
| 功法 | [修炼功法名称] | 第2轮 |
| 神通 | [所有神通/能力] | 第2轮 |
| 命格 | [命格/体质/天赋] | 第4轮 |
| 核心气质 | [3-5个关键词] | 全轮综合 |

### 维度二：外貌演变

**按年龄阶段分段记录**，每个阶段提取关键视觉特征：

```
### 1. 婴幼期
> [原文引用]（第XXXXX行）
**要点**：[提炼视觉特征]

### 2. 幼儿期（约X岁）
> [原文引用]（第XXXXX行）
**要点**：[提炼视觉特征]

### 3. 少年期（约X-X岁）
> [原文引用]（第XXXXX行）
**要点**：[提炼视觉特征]

### 4. 青年期（约X岁至筑基）
> [原文引用]（第XXXXX行）
**要点**：[提炼视觉特征]

### 5. 封王期/成熟期
> [原文引用]（第XXXXX行）
**要点**：[提炼视觉特征]

### 6. 全甲战斗形态（最核心视觉形象）
> [原文引用]（第XXXXX行）
**要点**：[提炼视觉特征]
```

> **外貌演变为系列化提供基础**——每个年龄阶段都可以生成一张系列图。必须记录行号，每阶段至少1条原文佐证。

### 维度三：性格特征

5-7个性格侧面，每个附原文佐证：

```
### 1. [性格特征1]
> [原文引用]（第XXXXX行）

### 2. [性格特征2]
> [原文引用]（第XXXXX行）
```

### 维度四：人际关系

3-5个关键关系，每个记录互动模式：

```
### 1. 与[人物A]
[关系描述]
> [原文引用]（第XXXXX行）
**要点**：[互动模式总结]
```

### 维度五：成长弧线

6-8个成长阶段：

```
### 第一阶段：[阶段名]（[时间段]）
- [关键事件1]
- [关键事件2]
- [定性评价]
```

### 维度六：金句语录

按主题分类的标志性台词：

```
### 核心金句
> **"[最 defining 的台词]"**
> ——[角色名]（第XXXXX行，[场景简述]）

### [主题1]类
> "[台词]" ——[场景简述]（第XXXXX行）

### [主题2]类
> "[台词]" ——[场景简述]（第XXXXX行）
```

> **金句是角色的灵魂**——它定义了角色说话的方式和思考的深度。

### 维度七：他人评价

分类记录旁人评价：

```
### 长辈评价
> "[评价]" ——[评价者]（第XXXXX行）

### 下属/旁人评价
> "[评价]" ——[评价者]（第XXXXX行）

### 敌人/旁观者评价
> "[评价]" ——[评价者]（第XXXXX行）
```

> **他人评价是角色立体化的关键**——角色自己怎么看不重要，别人怎么看他才定义了他在世界中的位置。

### 维度八：矛盾与暗面

角色的复杂性、阴暗面、非人感：

```
### 1. [矛盾点1]
[描述+原文佐证]

### 2. [矛盾点2]
[描述+原文佐证]
```

> **矛盾是灵魂**。没有矛盾的角色是纸片人。李周巍的矛盾在于：白麟的霸道 vs 红蝉的心计，帝王冷酷 vs 仁义之师，天生神圣 vs 天生妖邪。

### 维度九：视觉设计参考

3-8个最适合做OC的关键场景与形象：

```
#### 场景一：[场景名]（第XXXXX行）
> [原文引用]
**视觉要点**：[提炼视觉元素]

#### 场景二：[场景名]（第XXXXX行）
> [原文引用]
**视觉要点**：[提炼视觉元素]

#### 场景N：全甲战斗形态（第XXXXX行）——最核心视觉形象
> [原文引用]
**视觉要点**：
- [视觉元素1]
- [视觉元素2]
- ...
```

> **此维度直接服务于 Step 1 设计**——选取哪个场景做OC，取决于这里整理的场景列表。

|------|------|----------|

## 采样质量自检

| 检查项 | 标准 | 不达标怎么办 |
|:-------|:-----|:------------|
| 外貌描写覆盖 | 至少3个年龄阶段有外貌描写 | 扩大搜索关键词 |
| 性格侧面数量 | 至少5个不同侧面 | 增加性格词搜索轮次 |
| 他人评价数量 | 至少3个不同视角的评价 | 扩大评价词搜索 |
| 金句数量 | 至少5句标志性台词 | 搜索对话场景 |
| 矛盾点数量 | 至少2个核心矛盾 | 交叉分析性格+评价 |
| 视觉场景数量 | 至少3个可做OC的场景 | 筛选外貌描写密集段落 |
| 原文佐证 | 每个关键特征都有行号 | 补充采样 |
