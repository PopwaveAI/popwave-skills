## v1.10.0 — 2026-08-09

### 画风×内容解耦（治本，防画风污染实际内容）

老板实测发现「十日终焉-2」最新 run 里画风污染实际内容——国漫玄幻厚涂的 `修仙流` 题材锚词把现代密封都市场景拉回古代仙侠。定位根因：**画风DNA里技法层（怎么画）与内容层（画什么）耦合**。改造为通用两段式解耦结构：

- `文风DNA-library.json` 升级 v5.3：37种画风全部拆解耦——`dna` 统一为**中性技法层**（线稿/上色/光影/比例/特征，可跨题材复用），新增 `content_theme` 承载**可交换题材层**（画什么），`constraint` 剔净题材性限制，全部标 `decoupled: true`
- 逐条审计（**不同画风耦合方式各异，不一律只揪 修仙流**）：黑执事耦合维多利亚哥特、赛博边缘行者耦合高科技城市、蒸汽朋克黄铜耦合齿轮机械、穆夏新艺术耦合花卉装饰……逐个识别并剥离；v5.3 补充净化新国潮/硬朗武侠/日系热血战斗残留的题材词（传统纹样/荒漠场景/招数斗气）
- 深耦合画风（蒸汽朋克/玄幻/超现实/新艺术）技法本质与题材强绑定，`content_theme` 保留原生题材锚点，跨题材时由用户场景覆盖决定
- `SKILL.md`：新增「画风×内容解耦铁律」说明 + 铁律 ❌10（DNA 必须是纯技法层）+ Step 2 内容层接入规则 + 跨skill引用协议第1/4条
- `steps/step1-style-select.md`：加载 `content_theme` 作为原生题材默认内容层
- `steps/step2-prompt-build.md`：新增「内容层接入规则」——场景段用户描述优先、`content_theme` 兜底；画风段只取 `dna`+`constraint` 纯技法；自检新增 ❌10 检查项
- 版本同步：SKILL.md / skill.json 至 v1.10.0
