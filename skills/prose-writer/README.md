# prose-writer v2.5.2（正文写手）

**只做一件事：把一章正文写出来。** 通用正文写作技能——不绑定任何平台、任何题材、任何形态。

## 它能写什么

| 维度 | 覆盖 |
|---|---|
| **题材** | 不限（悬疑／年代／都市／奇幻／日常／科幻……由材料与设定带出来） |
| **形态** | 长篇连载／文学向连载／单本长篇／系列单元剧／文学短篇／微型小说／散文书信体／儿童文学——**形态决定参数**（每章多少字、每章几件事） |
| **材料** | 给细纲能写、只给设定能写、**只给前文能接着写**、只给一句方向也能写 |

## 两个特色能力

**① 接续（含半截稿）**：手上只有前文——半句、半段、半章、写到第 N 章，都能接。

开写前先做三件事：**前文体检**（扫前文自带的毛病，如破折号、反应套话，交付时一并清掉）＋
**取四样接续锚**（语气／视角／未完成项／**事实**）＋ **接缝七问**（续文与前半段是否同一个人写的、
事实对得上吗、靠"演"还是靠"讲"）。工具：`scripts/check_seam.py`。

**② 反应拍写法**：写「震惊／心慌／愣住」这类情绪反应时，**不用生理套话**（"心脏漏跳半拍"
"呼吸凝滞了"），改用四个公式——愣住只占一拍／行为延迟／欲望延迟／物件锚定。判据与真人样本
摘句见 `references/reaction-beats.md`（**样本库没覆盖的品类，先联网取样 2-3 篇高口碑作品再动笔**）。

## 本版重点（v2.5.2）

**架构独立**：本技能与同类的立项类技能（如番茄平台的 `fanqie-writer`）**各自一套文件、
各自维护、各自上架，改动互不影响**。本版把"上架"这件事也还给本技能自己：

- **自有的打包器** `prd/make_package.py`——读自己的版本号、跑自己的门禁、产自己的包；
  **只清自己的旧包**，不会动别的技能在同一个输出目录里的产物。
- **自有的私有信息门禁** `prd/check_private_terms.py`——扫描"会随包发出的文件"里
  有无开发期的内测样本名／角色名／私有项目名（硬词命中即 FAIL，同形软词只报数留人判断）；
  并含**扫描面覆盖自检**与**锚点断言**（`SKILL.md` 必须在扫描面里——否则是"空扫"，而空扫会假 PASS）。
- **自有的自检** `prd/self_check.py`——引用完整性／frontmatter 合法性／通用性／词表真源，四项。

## 目录结构

```
prose-writer/
├── SKILL.md          # 主流程：材料适配四级 / 写七步 / 门禁 / 收尾自检
├── README.md         # 本文件
├── skill.json        # 入库清单（版本 = 2.5.2）
├── references/       # 文笔规则真源 / 形态参数 / 接续指南 / 反应拍 / 对话 / 场景 / 连续性
├── templates/        # 章节模板（含交付前自检清单）/ 记忆模板
├── scripts/          # 门禁与工具：指标与画像 / 字数校验 / 配额 / 格式归一 / 接缝检查 / 词表
└── prd/              # 【不随包】开发侧：自检、私有词扫描、打包脚本与 README 模板
```

## 安装使用

把 `prose-writer/` 整个目录放到 `~/.workbuddy/skills/` 下，新开对话即可用。

- **写新章**：说「写第 X 章」并给出细纲或设定路径
- **接着写**：说「接着写／续写／继续更」并给出已有正文
- **检查一章**：说「这章正文帮我检查一遍」

## 与其他技能的关系

**互相独立、可选配合。** 本技能不依赖任何其他技能——手上的材料是别的技能做的、或自己手写的，
都能用。若你同时装了立项类技能（选题 → 大纲 → 细纲），走完立项后把项目路径交给本技能接手即可。
**两个技能的文件各自一套，改动互不影响。**
