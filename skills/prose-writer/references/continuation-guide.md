# 接续模式（**用户说"接着写／续写／继续"时走这条**）

> **为什么单独一节**：写一整章和**接一段已经开了头的文字**，是两种活。前者从零搭结构；后者**先要读懂别人（或自己）已经写下的东西**，然后**从断点处无声地接上去**。
> 接续最常见的失败不是"写得差"，是**"接得不像同一个人写的"**——语气变了、称呼变了、把前文刚讲过的事又讲一遍。
> 本节的目标：**让续文和前文连起来读，看不出缝。**

---

## 一、先确认走哪条路

| 输入 | 走哪条 |
|---|---|
| 只有大纲／设定，没有正文 | **写章模式**（第四节），不是接续 |
| **有正文**（完整章节，或半截稿），要往下写 | ✅ **接续模式**（本节） |
| 有正文，但用户要**改**它（"重写一下"） | **改稿模式**（第五节），不是接续 |

> **注意**：本模式对输入的宽容度是**最高**的——**"写了一半"就是合格的输入**。半句、半段、半章、写到第 N 章，都能接。

---

## 二、开写前先做两件事：**前文体检**（0 步）＋ **定位断点**（第 1 步）

### 第 0 步 · 前文体检（**前文不是干净的，别默认它合规**）

> **为什么有这一步**（2026-10-09 实测）：基准样本（短章文艺向）**自带 3 处破折号 ＋ 17 处 `「」` 包人名**。
> 我把它当成「**这本书的排版特征**」照抄进续文，交付的整章里人名被 `「」` 包住出现 15 次、破折号 2 处，
> 用户当场质疑「为什么会出现这个符号」。**前文带什么，续文就会跟着带什么。**

**动笔前，先对前文跑一次门禁，把违规逐条记下来**：

```bash
python scripts/chapter_stats.py 前文.md
```

| 前文里查到什么 | 怎么处置 |
|---|---|
| **破折号**（S1 死线） | **记下来**；续文自己不许写；交付**整章**时**一并清掉**（含前文那几处），并在交付说明里写明「顺手清了前文 N 处」 |
| **`「」` 包人名／对白**（S6.4③） | **这是来源排版格式，不是这份稿子的特征** → **一律换成 `“”`**；包人名则**直接去掉括号** |
| **AI 高频词／AI 句式模板**（如「显然」「不禁」「顿时」） | 跑 `python scripts/chapter_stats.py --lexicon` 看清单。**这是 FAIL 项** → 交付整章时一并改掉 |
| **生理反应套话**（漏跳／呼吸凝滞类） | **前文也可能自带**——2026-10-09 红框实录：被框的三句全在前文（基准样本原文）。交付整章时按 `reaction-beats.md` 四式改写，写明改了几处 |
| **ASCII 直引号／拉丁字母／半角数字** | 同上：记下来，交付整章时一并清 |
| 前文**本身**的标点错配／引号不配对 | 记下来（可能是前文作者的疏漏），**不擅自大改**，交付时如实报 |

> **三条纪律**
> ① **不许把前文的问题当成「这本书的风格」去模仿**——这是接续最隐蔽的坑：**「贴前文」和「抄前文的问题」只差一线**。
> ② **动不动前文，看交付形态**：只交「续写片段」→ 不动前文，但**在说明里报出来**；交「整章」→ **整章一起清**。
> ③ **动了前文必须讲明白**——用户要知道你改了他原文哪几处。

---

先看前文**停在哪**，三类处理方式不同：

| 断点类型 | 怎么认 | 你要做的 | 本次目标字数 |
|---|---|---|---|
| **① 章间断点** | 前文是**完整的一章**（有头有尾），要写下一章 | 等于写新一章：走写章模式七步，**但首段必须接住前章末尾的前进力** | 按形态取一整章的区间 |
| **② 章内·段间断点** | 同一章写到一半，停在**一个完整段落**结束处 | 接着往下，**把这一章写完** | 整章区间 **− 已写字数** |
| **③ 章内·句中断点** | 停在**半句话**上（行尾无句号／逗号悬着） | **先补完那句话**（延续它的主语与语气），再接段落 | 同上 |

> **⚠️ 别重打前文。** 续文**只包含你新写的那部分**。交付时如果前文和后文要合在一起，说明清楚从哪一行开始是你写的。**用户要的是"接下来的内容"，不是"前文＋后文"。**

**如果用户指定了篇幅**（"再写 500 字""接完这一段就行"）→ **按用户的**，不用补满整章。

## 三、第二步 · 读前文，取四样「接续锚」

**这四样是接续的命门，取不到就别动笔。** 取法：读**前文的最后 1-2 段** ＋ 快速扫一遍全章／前 1-2 章。

### 锚 1 · 语气锚（**怎么写**）

- **风格档**：前文属 A 叙述驱动／B 心理流／C 短句碎切／D 对白驱动／E 对话长句（判据 `benchmark-writing.md` 第三节）。
- **句段节奏**：跑一次画像 —— `python scripts/chapter_stats.py 前文.md`，记下**均段长／均句长／短句率／对白占比**四项。
- **落地**：**续文这四项，与前三项对照，不得差一倍以上**（差一倍＝跳档，读者会觉得"换人写了"）。**这是可量化的**，别凭感觉。

### 锚 2 · 视角锚（**谁在看**）

逐项确认，**续文一律照前文**：

| 项 | 例 |
|---|---|
| 人称 | 第一人称？第三人称限定？ |
| 视角人物 | 贴着谁写？本章内有没有换过？ |
| 时态 | 过去时（"他走进门"）？现在时（"他走进门"）——**中文不显，但看有没有"了／着"的习惯** |
| **称呼习惯** | 前文管这个人叫**"爸"**还是**"父亲"**？叫**"老陈"**还是**"陈师傅"**？——**这一项最容易穿，也最容易查**（搜前文里那个人名前后 2 字） |
| 叙述距离 | 贴近人物内心（自由间接）？还是镜头式远观？ |

### 锚 3 · 未完成项（**往哪走**）

前文抛出去、**还没有接住**的东西，列出来——**续文必须至少接住其中一项**，否则就是"接了个寂寞"：

| 类型 | 例 |
|---|---|
| 未答的问题 | "那人是谁？"——前文问了，没答 |
| 未完成的动作 | 门刚被推开，没写推门的人 |
| 已做出、代价未付的决定 | 他决定说实话，但还没说出口 |
| 已经变化、后果未到的状态 | 关系断了，但还没人尝到后果 |
| 前文的"前进力"指向 | 前章末明示"接下来要面对什么" |

### 锚 4 · 事实锚（**别写穿帮** · v2.2.0 新增）

**前三个锚管「怎么写」，这一锚管「写的对不对」。** 前文交代过的事，是一条**不能违反的线**。

从**前文**抄出这张小表，写完**逐条核**：

| 项 | 从前文取什么 | 本轮踩过的坑（实录） |
|---|---|---|
| **时间线** | 现在**几点／什么季节／距某事多久**；「一年前」「三天后」往前推**落点是哪天** | 前文写「**晚冬**的寒气」＋「整整一年／第 365 张」，我却在续文写「从**盛夏**排到深秋，从深秋排到今天」——**把一年前算成了盛夏，与 365 天直接冲突** |
| **道具状态** | 关键道具**此刻在谁手里、什么状态**（已打开／还封着／放在哪） | — |
| **空间位置** | 人**站在哪**、朝向哪、门开没开、灯亮没亮 | 前文「抱进屋内、顺手反锁」，续文不能还写「站在门外」 |
| **已发生的事实** | 前文**已经确认**的事实（谁走了、东西丢没丢、谁说过什么） | 我写「底座上**什么都没有**」，紧接着又写「有人**刻了字**」——**同一处自相矛盾** |
| **称呼与称谓** | 谁管谁叫什么（并入锚 2） | — |

> **判据**：续文里**每一个带时间／地点／数量／状态的句子**，都能在前文找到依据，或明确是**新发生**的。
> **⚠️ 最容易穿的是「数量与时长」**——凡续文要复述数字（365 天／一年／三年前），**回前文抄，不要凭印象写**。

> **⚠️ 这四样取完，走写章模式的第 2 步（写前分析八项）——但第 2 项"本章在全书里的位置"、第 3 项"事件单元"要按下面的口径改**：
> - **章间断点**：按整章口径（形态决定装几件事）
> - **章内接续**：**这一章的事件单元是前文已定的** —— 你是在**写完它**，不是在**新起一章**。别再塞新的事件单元，**除非前文明显只开了一个头**。

## 四、第三步 · 接续三不（**三条禁令，犯一条就是接坏了**）

| 禁令 | 什么算犯 | 为什么 |
|---|---|---|
| **① 不复述** | 续文里把前文已经讲过的事再讲一遍（哪怕换个说法） | 读者刚看过，会觉得"卡带了" |
| **② 不重演** | 把断点前的场景重写一遍再往下 | 同上；**唯一例外是①②③三条断点里的"补完半句话"** |
| **③ 不抢用** | 把后面才该出现的材料提前用了（还没埋的伏笔当场揭底、新角色提前登场、反转提前翻） | 打乱后面的节奏；如果前文有伏笔台账，**查台账确认哪些还没到期** |

> **判断有没有犯①②**：**删减测试**——把续文**首段**试着删掉，看读者会不会掉信息。**不掉＝首段是复述，删。**
> **判断有没有犯③**：**对台账**——前文登记的"未回收伏笔"里，哪些是**本章不该动的**？

## 五、第四步 · 写

走**通用文笔规则**（`prose-rules.md` 全文 ＋ 本地条款），同写章模式第 4 步。三处与"写新章"不同：

1. **开头不适用"起手式清单"**——续文的首段**不是章节开头**，它的任务不是"进入变化"，是**接上前文**。前文的势头已经起来了，你**顺着推**就行。
2. **字数按"剩余量"取**（整章区间 − 已写），不按整章区间。
3. **风格档不重选**——**沿用前文的档**（锚 1 已取）。

4. **呈现方式：能演就别讲**（2026-10-09 用户的批评）——

   | 别写 | 改成 |
   |---|---|
   | **心理直述**：「她心里想，补偿要走流程，要有单据……」 | **动作**：她翻过箱子找单据、拆开夹层、把纸板捏出响声 |
   | **心理解说**：「她渐渐明白了这意味着什么」 | **反应**：她的手停在半空，没有收回来 |
   | **情绪形容词**：「她非常震惊」 | **生理／动作**：她后退半步，后腰撞上桌角 |
   | **反应套话**：「心脏漏跳了半拍」「呼吸凝滞了」 | **行为延迟**：「她在门口站了几秒，才走过去」——四式与真人摘句见 `reaction-beats.md` |

   **判据（可数，别凭感觉）**：续文里**连续 2 段以上**都由**认知动词**开头、而**没有一个物理动作** → **不合格，回改**。
   **认知动词自查表**：她想着／她觉得／她明白／她意识到／她记得／她以为／在她心里／心底／她试着……

   > **⚠️ 与风格档的关系**：B 档（心理流）**允许**心理描写多，但那也要求**心理被人物此刻的具体处境托着**，
   > 不是作者的解说。**判据仍是删减测试**：删掉这句心理，读者只少了「解释」、没少「事实」＝删。

5. **描写的功能测试**（同一条批评的另一半）——

   **每一处景物／氛围／环境描写，都要能回答「它让读者多知道了什么」。答不出＝渲染，删。**

   | 判 | 例 |
   |---|---|
   | ✅ 留 | 「窗外的湖还亮着一排灯」——若前文用「湖」锚定她仍在西湖边、没离开 |
   | ❌ 删 | 「光从窗帘的缝里漏进来，落在伞面上，弯成一道很细的弧」——纯装饰，删掉读者不掉任何东西 |
   | ⚠️ 看全局 | 「挂钟的秒针一格一格往前走」——若全书有「时间停滞」意象系统，它是在**工作**；否则是渲染 |

   **判据只有一条**：**删减测试**——删掉它，读者少了什么？**没少＝删。**

## 六、第五步 · 接缝测试（**「续得好」的判据，七问逐条过**）

**做法**：把**前文最后 1-2 段** 与 **续文最前 1-2 段** **连起来读一遍**（中间不要有断）。然后逐条给依据，**不许打勾**：

| # | 问 | 判据 | 不过怎么办 |
|---|---|---|---|
| **缝1** | **语气跳不跳？** | 续文与**前文全文**的画像对照：均段长／均句长／短句率／对白占比**任一差 > 1 倍**＝跳档 | 改续文的句段节奏去贴前文（**不是改前文**） |
| **缝2** | **视角人称时态一致吗？** | 人称／视角人物／时态／叙述距离，与前文对不对得上 | 改成前文的口径 |
| **缝3** | **称呼用语一致吗？** | 搜前文里那个人名**前后 2 字**，看前文怎么叫，续文用不用同一套 | 统一成前文的叫法 |
| **缝4** | **前文抛出的东西接住了吗？** | 锚 3 列出的"未完成项"，**续文至少接住一项**，且接得自然 | 回第三步重看未完成项 |
| **缝5** | **连读有没有"重来一遍"感？** | 做删减测试：删掉续文首段，读者会不会掉信息。**不掉＝首段在复述** | 删首段或改写首段 |
| **缝6** | **事实与前文对得上吗？**（v2.2.0 新增） | 锚 4 那张表逐条核：**时间线／道具状态／空间位置／已发生的事实／数字与时长**。凡续文复述的既有信息，**回前文抄，不凭印象** | 回锚 4，逐条改 |
| **缝7** | **这半章是靠「演」还是靠「讲」？**（v2.2.0 新增） | 有没有**连续 2 段以上**由认知动词开头而**无物理动作**？每处景物／氛围描写**删掉它读者少不少东西**？ | 心理改动作、渲染删掉 |

**七问全过 ＝ 接缝合格。**（缝 1–5 管「接得像不像」，缝 6–7 管「接得对不对／写得好不好」） 缝1 与缝5 **可以脚本辅助**：
```bash
python scripts/chapter_stats.py 前文.md     # 前文画像
python scripts/chapter_stats.py 续文.md     # 续文画像 → 对比四项，看差多少
python scripts/check_seam.py 前文.md 续文.md   # 自动比对画像 + 查首段复述（若有此脚本）
```

## 七、交付形态

| 场景 | 交付什么 |
|---|---|
| 章间断点（写下一章） | 正常的 `第XX章.md`（纯正文），首段接住前章 |
| 章内接续（同一章半截） | **只交你新写的那一段**（纯正文），并说明**从哪一行开始接**；若用户要完整章，再给出"前文＋续文"的合并版 |
| 用户只要一小段 | 交那一小段，**不补满整章** |

**收尾照跑**：格式化 → 字数校验 → 客观指标 → **接缝测试七问** → 记录更新。

> **⚠️ 字数校验必须按「剩余量」传参**：`python scripts/check_chapter_wordcount.py 续写片段.txt 300 500`（区间 ＝ 整章目标 − 已写，±20%）。
> **不传参会踩坑**：默认区间是 2200-2800（平台向连载的整章档），片段必然被判 `[X] 字数不足`。**那个 X 说的不是"续文不好"，是"你没告诉它这次是片段"。**（2026-10-09 实测记录）

## 八、续写常见失败模式（**对着这张表改**）

| 失败 | 症状 | 根因 | 修法 |
|---|---|---|---|
| 语气断裂 | 读起来像换了一个作者 | 锚 1 没取，凭自己习惯写 | 回锚 1，按画像贴 |
| 复述感 | "他想起刚才……"把前文重讲一遍 | 犯了禁令① | 删首段／删复述句（删减测试判） |
| 称呼改变 | 前文"爸"，续文"父亲" | 锚 2 没查 | 搜前文统一 |
| 进度错位 | 前文还在铺垫，续文突然高潮 | 没看前文的"未完成项"，当成新章写 | 回锚 3，顺着前文的势头走 |
| 抢用伏笔 | 提前抖了后面才该抖的包袱 | 犯了禁令③ | 对前文伏笔台账，退回 |
| 半句话没接完 | 断点在半句，续文另起一句 | 断点类型判错（③当成①） | 补完那半句 |
| 断章感 | 续文像"另开一段"而不是"接着上句" | 首段没接前文的动作或话题 | 首段从**前文最后那个动作／那句话**续起 |
| **时间线穿帮**（v2.2.0） | 前文「晚冬／整整一年」，续文说「从盛夏开始」 | **没取锚 4**，凭印象复述数字与时长 | 回前文抄时间线，逐条核数字 |
| **同一处自相矛盾**（v2.2.0） | 「底座上什么都没有」＋「有人刻了字」 | 两句各自的时点没对齐，压成了一句 | 一句说清「本该有 A，实际是 B」 |
