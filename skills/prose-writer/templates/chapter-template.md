## 写前准备（⚠️ 不进交付的 `第XX章.md` → 写进 `.learnings/`）

> **三件缺一不许动笔。** 做法与判据见 `references/prose-rules-supplement.md` **S7.1** 与 `SKILL.md` 第四章第 3 步。

### 一、动作链（治「跳」）

逐场戏列**关键动作的物理顺序**；相邻两步之间**显式标注四类过渡**（姿态变更／空间位移／取物／时间跳转）。**标不出过渡的地方＝「跳」**，当场补步骤。

| 场 | 起点状态 | 动作序列（标注过渡） | 终点状态 |
|---|---------|-------------------|---------|
| 1 | | 动作 →【姿态／位移／取物／时间】→ 动作 → … | |

### 二、信息增量表（治「碎」）

逐场戏列**每一轮**（一次对白来回／一个叙述回合）改变了什么。**写不出增量的那一轮＝「碎」**，删掉或换内容。

| 场 | 轮次 | 这一轮改变了什么（新事实／立场变化／关系推进／物理变化） |
|---|---|---|
| 1 | 1 | |

### 三、字数配额表（治「写不到」）

> **写前把总字数分摊到每一场，写后只做验收**——**字数不是一个可写的单位，段数才是**（`字数 = 段数 × 均段字数`；叙述驱动 26.8 字/段、对白驱动 20.5 字/段）。
> **直接跑脚本，把输出整表贴到下面**：
> ```
> python scripts/plan_word_quota.py --total 2250 --scenes 6 --avg-para 20.5 \
>        --weights 1,1.2,1.3,1,1,0.8        # 重头场多给、过渡场少给
> ```
> （`--scenes` ＝本章场戏数，从上面「一、动作链」的场序号数出来；`--avg-para` 叙述驱动取 26-27、对白驱动取 20-21；总字数按项目要求改 `--total`。**三条硬规则与差额处理见 `SKILL.md` 第四章第 3 步**。）

| 场 | 目标字 | 目标段数 | 建议拍数 | 写完实际字 | 差额 |
|---|---|---|---|---|---|
| 1 | | | | | |
| **合计** | | | | | |

### 四、接续锚（**仅路径 B · 续写时填**；写新章跳过本节）

> "写了一半也能接"靠的就是这三样。**取不到别动笔。**

| 锚 | 取什么 | 记下来 |
|---|---|---|
| **语气锚** | 风格档 ＋ 跑 `scripts/chapter_stats.py 前文` 取**均段长／均句长／短句率／对白占比** | |
| **视角锚** | 人称 ／ 视角人物 ／ 时态 ／ **称呼习惯**（搜那个人名前后 2 字，看前文怎么叫） | |
| **未完成项** | 前文抛出去**还没接**的东西（未答的问题／未完成的动作／代价未付的决定）——**续文至少接住一项** | |

**断点类型**（决定目标字数）：章间（写一整章）／ 章内·段间（写完这章，目标＝区间−已写）／ 章内·句中（**先补完那句话**）

**接续三不**：① 不复述 ② 不重演（唯一例外：补完半句）③ 不抢用（不提前抖后文的伏笔）

## 正文

（⚠️ 下面括号里是「**长篇连载·平台向**」口径。**文学向连载／单本长篇／单元剧／文学短篇的容量不同**——形态判定见 `references/form-guide.md`）
（全章 2-4 个事件单元：每单元＝一件独立的事【谁想要什么 → 结果】；**至少 1 个单元由主角主动发起**；单元之间必须换"事"，不是把同一件事拆碎——见 `references/scene-beats.md` §七）
（全章回合：每个回合＝谁向谁施压 → 被压方回应 → 局面变化；相邻回合必须变一项【筹码/信息/关系/物理】，**章末那个单元最狠**）
（开头：**必须已经进入变化**——从一件已经发生／正在发生的事切入；起手式任选，见 `SKILL.md` 4.2）
（发展 50-60%：回合递进、信息分批揭示、代价逐步显形）
（高潮后 15-20%：本章最大的那个单元爆发／反转发生）
（收束 5-10%：**留下前进力**——读者合上这一章，知道"接下来要面对什么"；**不要求写成悬念句**）

（正文长度按项目要求；默认 2200-2800 字。**动笔前通读 `references/prose-rules.md` 并按其执行——死线级硬约束**；展示而非讲述；去除 AI 味；对话有角色个性；句长按所选风格档走，**不设长短门槛**）
