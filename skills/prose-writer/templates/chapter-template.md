### 三、字数配额表（治「写不到」）

> **为什么要有这一件**：字数要求一直写在**写完之后**。**实测第一稿稳定差 18%-35%**——同一测试样本三次重写的第一稿分别是 **1486 / 1822 / 1475 字**（目标 2200），每次都要 3-5 轮扩写才达标。
> **根因不是"描写不够"，是"拍数不够"**：字数不是一个可写的单位，**段数才是**。
>
> **两把尺（都有实测凭据）**：
> - `字数 = 段数 × 均段字数`，而均段字数由风格档决定——叙述驱动（A/B）实测 **26.8 字/段**；对白驱动（D）实测 **20.5 字/段**。
> - 由此，**2200 字需要 82-107 段**；**一拍**（谁向谁施压 → 回应 → 局面变化）约 **65 字 ≈ 3 段**。
> - 实测反证：把历史第一稿的体积还原出来（**1488 字 / 63 段**），按此表算 **缺 19 段 ≈ 6 拍**——**与当时的实况完全一致**。
>
> **直接跑脚本，把输出整表贴到下面**：
> ```
> python scripts/plan_word_quota.py --total 2250 --scenes 6 --avg-para 20.5 \
>        --weights 1,1.2,1.3,1,1,0.8        # 重头场多给、过渡场少给
> ```
> （`--scenes` ＝本章**场戏数**，从上面「一、动作链」的场序号数出来；`--avg-para` 叙述驱动取 26-27、对白驱动取 20-21；**总字数按项目要求改 `--total`**）

| 场 | 目标字 | 目标段数 | 建议拍数 | 写完实测字 | 差额 |
|---|---|---|---|---|---|
| 1 | | | | | |
| **合计** | | | | | |

**硬规则（三条）**：
1. **写前把总字数分摊到每一场**（重头场 ×1.2-1.3、过渡场 ×0.8），**写后只做验收**——与"位置是排出来的"同一条纪律，只是这次排的是字数。

3. 全章写完跑 `--check 第XX章.md` 对账，把实测值回填本表。

| **S6.1 风格档已声明＋档内一致**——本章属 A–E 哪档？与上一章是否跳档超一倍且无场景边界？（跳档＝「跳」） | |

> **非死线条目（2/5/6/7/9/11/16/17/20/21/22/23/30/31/33/34）也要过**，但可在上方各步的"问题类型"里带过；其中 **21（冲突升级或转化）属甲层结构判定**，**30（细节功能）由第一步删减测试覆盖**。
> 标"死线"各项**任一不过，直接重写相关段落，不做局部遮掩**（口诀：视角不飘，时间不乱；动机可见，信息分批；道具有链，人物有界；发现有据，伏笔有账；句子闭合，细节有用；语言自然，格式统一）。
>
> **风格与硬伤的分界（用户拍板）**：用户交付 7 本异风格长篇并指正「**不同的方式都可以有的，但病句、碎句、跳、上下句描述错误这种问题是通用不能有的**」。据此——
> **风格类（对白占比／均段长／均句长／短句率／碎句链／短对白链）全部撤销阈值，只做画像**（8 本正例区间：对白占比 0–94%／均段长 12–149／短句率 0–45%／碎句链 0–15），**写前先选风格档 A–E**；**唯一通用底线＝承接测试四问**。
> **⚠️「短」的算法**：「短」本身不是错。**错的是"短到读不出东西"**（半截句／行尾无终止标点／接不上的碎片）。**判据是承接测试四问，不是句长阈值**；**禁止以"句子太短／段太短／对白太多"为由改文**。
>
> **机器化程度**：**"确定性错误"由 `scripts/chapter_stats.py` 直接检出**（S1 破折号／ASCII 直引号／标点错配／标点连用／引号不配对／相邻行重复／叠字／半截句／行尾无终止标点／跨章对白复现），改到脚本 PASS 为止；**其余的核（S3.2 遮蔽测试、S3.4 文书、S4.1–4.3 场景具现、S5.3 承接测试四问）由执行本技能的模型跑**——脚本把"该看的位置"摆出来，**模型逐段判定并输出举证表**。**两类都不靠打勾，也不需要用户逐句指。**
