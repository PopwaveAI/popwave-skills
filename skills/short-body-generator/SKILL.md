# short-body-generator
> 短篇正文生成器。执行流程为选定文风、确定生成模式、逐段生成、去除 AI 痕迹。v2.2.0：原 steps 四项全部合入单一文件并精炼，清理了两条失效链接引用；执行模式明确为由主 agent 直接执行。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 做什么
输入：骨架卡片，由 plot-structurer 的流转上下文传入。
输出：完成的草稿，以及传向 reviewer 的流转上下文（正文全文与全部前置卡片）。

**执行模式**：由主 agent 直接执行。本技能是连续创作流程，逐段生成、逐段经用户确认，并全程以文风为基准，每一段都依赖用户的实时反馈，没有适合派子 agent 的环节。

## 怎么操作（规程全部直接写在本文件内）

### 5A 文风选择
1. **提取前置输入**：从 plot-structurer 的流转上下文中提取【选定平台】【文章性质】【脑洞一句话】【导语】【黄金三句】。
2. **加载文风库**：读取 `references/writing-styles.md`，展开五种文风的完整特征：知性沉稳、网感快节奏、情感细腻、文学质感、极速钩子。
3. **平台对应的默认推荐**：

| 平台 | 默认推荐 |
|:---|:---|
| 知乎盐言 | 知性沉稳 |
| 番茄短故事 | 网感快节奏 |
| 每天读点故事 | 情感细腻 |
| 豆瓣阅读 | 文学质感 |
| 小程序/信息流 | 极速钩子 |

   展示推荐的文风、三至四条核心特征与该风格的开头范例（引自 writing-styles.md），请用户确认或调整，用户也可上传喜欢的文字作参考。
4. **用户参考文本的优先级最高**：提取其语言特征（句长、对话比例、描写密度、特有词汇），标注其与默认推荐的差异点，再以参考文本的特征覆盖默认推荐，生成时向参考文本靠拢。
5. 文风确认后进入 5B。

### 5B 确定生成模式
问用户："一段一段确认，还是先出全文？默认逐段确认。"

| 模式 | 流程 | 用户可操作 |
|:---|:---|:---|
| 逐段确认（默认） | 每段执行一次生成、一次自检、一次用户确认 | "继续"、"这段重写"、"调整某处" |
| 一键全文 | 先生成全文，再快速逐段自检，最后一次性展示 | "第三段重写""收束太弱""付费钩子不够狠" |

### 5C 收集用户额外补充
问："开始前有没有想特别加入的内容？（某段多写什么/某角色多出现一次/某段调整情绪基调）"随后将补充内容记录下来，并嵌入对应段落的蓝图。

### 5D 逐段生成
- **生成前**：从弧线表读取本段蓝图，取得核心事件、信息释放策略、情绪走向与密度目标。
- **生成时**：开头标注「第X段/共Y段｜目标X字」；持续引用前序设定（主角五维、配角标签、导语、黄金三句）以避免跑偏；到付费钩子断点处暂停，并标注「←付费钩子」。
- **生成后自检**：

| 检查项 | 标准 |
|:---|:---|
| 推进了情节或深化了人物？ | 删除该段后不影响理解，即须重写 |
| 情绪密度达标？ | 对照弧线表的密度标注判定；不达标的，在情绪下坡处插入一个动作、一段对话或一次信息释放 |
| 偏离脑洞？ | 对照脑洞一句话与导语判定 |
| AI 痕迹？ | 对照 writing-styles.md 的去 AI 味清单：总结句、模板句式、过度过渡、抽象描写、AI 式对话 |
| 角色一致？ | 主角行为符合底线；配角语言风格符合标签 |

- **等待确认**：每段生成后暂停，用户可选择继续、重写该段、调整某处或回改上一段。
- **一键全文的差异**：先生成全文，再快速逐段自检，最后一次性展示；用户可指定任意一段（"第三段重写""收束太弱""付费钩子不够狠"），由本技能翻回该段重写，其余段落保持不变。

### 5E 付费钩子段断点控制
1. **识别**：从弧线表提取所有标注"付费钩子"的段落，对照 opening-designer 的付费钩子策略逐项确认：断点位置（占全文百分比）、断点类型（信息缺口、情绪最高点、决策时刻、反转预告）与驱动力方向。
2. **开篇策略一致性验证（必须执行，用以防止正文阶段与开篇设计脱节，避免到评审阶段才发现问题）**：

| 验证项 | 方法 | 不一致时 |
|:---|:---|:---|
| 断点类型与策略一致？ | 将策略类型标注与当前段断点类型比对 | 若属设计漂移，须判断是更新策略（由开篇设计器重新确认）还是调整当前段断点方向 |
| 位置偏差在允许范围？ | 将策略位置与实际位置比对，偏差不得超过全文的 ±3% | 超出范围的，调整段落边界或更新策略 |
| 信息缺口与设计一致？ | 核对策略标注的"读者不知道的X个问题"是否在实际断点处同时被激活 | 遗漏任何一个，即补一句暗示以激活该缺口 |

3. **断点检查**：

| 检查项 | 标准 | 不通过时 |
|:---|:---|:---|
| 断点位置与策略一致 | 对照策略的位置标注判定 | 调整段落边界 |
| "必须知道后续"的驱动力足够 | 信息缺口足够大、情绪高点被掐断、角色处于两难 | 补强悬念，增加一句反转或暗示 |
| 断点前后衔接自然 | 不将断点落在对话、动作或描写的中间，而落在"该说但没说"处 | 调整断点句 |

4. **生成要求**：到断点处暂停并标注「←付费钩子」；向用户展示断点处最后两句的驱动力强度以供确认，分强（必须知道后续）、中（想知道但不急）、弱（可读可不读）三档。
5. **驱动力补强**：驱动力为中或弱时，向用户提问："这个断点的驱动力是【中/弱】，建议断点前加一句：[补强建议]。要加吗？还是直接用现在的版本？"

### 5F 清除 AI 痕迹
全文完成后，先逐段扫描，再全文扫描。

**七类 AI 痕迹的识别与修改方向**：

| 类型 | 症状/识别模式 | 修改方向 |
|:---|:---|:---|
| 总结感 | 段末或章末以总结句式替读者解读情绪（终于、从此、这一夜、或许、也许） | 删除总结句，用动作或场景收尾 |
| 模板句式 | 高频且跨作品通用的描写模板（模板化比喻与情绪标配动作的组合） | 换成角色独有的反应方式（基于人设） |
| 过度过渡 | 以显式连接词衔接事件，而非依靠事件本身的节奏（与此同时、紧接着、话音刚落、然而） | 直接并列或省略过渡词 |
| 抽象描写 | 用概括词替代可验证的感官信息（无可验证细节的情绪概括句） | 改用可验证的具体细节（看到、听到、做了什么） |
| AI式对话 | 对话完整无歧义、信息全部交代、人物说话方式雷同 | 删掉一半台词以留出潜台词；两人的说话方式须有区别 |
| 百科口吻 | 叙事中途切换为解释、定义或说明模式（"X是一种Y物质""根据N学原理"等定义句式，把读者当作被科普的对象） | 不删信息，把定义句式改成角色认知句式，让信息从角色的眼睛或记忆里出来 |
| 全文总结句 | "她终于明白""他感到""他意识到"等内心独白标签 | 改成与"明白"无关、但暗示了"明白"的具体动作 |

**逐段扫描**：按正文顺序标注可疑位置（段号与句子），加以分类，再给出修改方向（给方向，不作具体改写），最后由用户确认"这个改吗？"

**全文扫描阈值**：

| 检查项 | 方法 | 阈值 |
|:---|:---|:---|
| 内心独白标签密度 | 检索"终于、感到、意识到、明白、觉得、好像懂了"等认知动词与心理陈述的组合 | 每五千字不超过一次；超出的，标记段号并列出全部出现位置 |
| 百科解释密度 | 检索"是一种、指的是、根据、原理、专业术语"等定义句式 | 全文不超过两处；超出的，标记段号并替换为角色视角的认知（"她记得带教老师说过——"比"根据医学原理"自然） |
| 段落对称性 | 连续三段以上字数高度一致（±20字） | 超过连续三段的，标记后由人工打破其中一段的段落长度 |

**完成确认**："AI 痕迹扫描完成。共发现 X 处可疑痕迹，已处理 X 处。正文草稿已就绪，进入评审器。"

**流转至 short-reviewer**：【流转上下文】包含正文草稿（完整全文）、【选定平台】【文章性质】【核心约束】【脑洞一句话】【导语】【黄金三句】【付费钩子策略】【剧情弧线】（完整表格）、【主角五维】与【角色清单】。

## 红线
| # | 红线 | 违反后果 |
|:-:|:-----|:---------|
| 1 | 生成前必须确认文风，不得跳过文风选择直接生成；用户参考文本的文风优先级最高，覆盖平台默认推荐 | 文风与平台不匹配，或用户风格诉求被忽略 |
| 2 | 付费钩子段必须特殊标记，并在断点处暂停，不得混入普通段 | 钩子位置模糊，付费策略失效 |
| 3 | 每段生成后必须通过自检再交给用户；清除 AI 痕迹为必走流程，不得跳过 | 低质量草稿流入下游，或成品 AI 感重 |
| 4 | 用户在任何后续步骤（评审后、自行重读后）要求改某段正文时，只重写该段，其余段落保持不变；单段重写仍须走完整自检（推进情节、密度达标、不偏离脑洞、AI 痕迹、角色一致） | 整篇重写导致逐段确认白费，或重写段与其余段落质量不一致 |
| 5 | 微调响应格式：本轮只修改已有段落且不超过五句话时，响应仅输出改动段与一句说明，不输出钩子分析、创作记录与自检清单 | 响应膨胀，浪费算力 |

## 响应分级

| 用户指令类型 | 响应格式 |
|:---|:---|
| 明确确认（"继续""可以""ok""没问题"） | 只输出下一段正文。不附带创作记录、钩子分析、自检清单 |
| 微调请求（"改一下XX""这里不对"） | 只输出改动段落，并附一句话说明改了什么 |
| 新方向、新段落或首次生成 | 输出正文、关键钩子与创作记录要点（五条以内） |
