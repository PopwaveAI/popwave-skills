# short-body-generator
> 短篇正文生成器。选文风→定模式→逐段生成→去AI味儿。v2.0.0：steps 四件全合入单文件精炼（清理2条死链引用）；执行模式明确为主agent直执。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 做什么
输入：骨架卡片（自 plot-structurer 流转上下文）
输出：完成草稿 + 流向 reviewer 的流转上下文（正文全文+全部前置卡片）

**执行模式**：主agent直执。连续创作链——逐段生成+逐段用户确认+文风全程锚定，每段依赖用户实时反馈，无自然子agent适配点。

## 怎么操作（SOP全内联）

### 5A 文风选择
1. **提取前置输入**：从 plot-structurer 流转上下文提取【选定平台】【文章性质】【脑洞一句话】【导语】【黄金三句】。
2. **加载文风库**：读 `references/writing-styles.md`，展开5种文风完整特征：知性沉稳/网感快节奏/情感细腻/文学质感/极速钩子。
3. **平台→默认推荐**：

| 平台 | 默认推荐 |
|:---|:---|
| 知乎盐言 | 知性沉稳 |
| 番茄短故事 | 网感快节奏 |
| 每天读点故事 | 情感细腻 |
| 豆瓣阅读 | 文学质感 |
| 小程序/信息流 | 极速钩子 |

   展示推荐文风+核心特征3-4条+该风格开头范例（引自 writing-styles.md），请用户确认或调整，也可上传喜欢的文字作参考。
4. **用户参考文本=文风最高优先**：提取语言特征（句长/对话比例/描写密度/特有词汇）→标注与默认推荐的差异点→以参考文本特征覆盖默认推荐，生成时向其靠拢。
5. 文风确认后进 5B。

### 5B 确定生成模式
问用户："一段一段确认，还是先出全文？默认逐段确认。"

| 模式 | 流程 | 用户可操作 |
|:---|:---|:---|
| 逐段确认（默认） | 每段一次生成→一次自检→一次用户确认 | "继续"/"这段重写"/"调整某处" |
| 一键全文 | 先生成全文→快速逐段自检→一次性展示 | "第三段重写""收束太弱""付费钩子不够狠" |

### 5C 收集用户额外补充
问："开始前有没有想特别加入的内容？（某段多写什么/某角色多出现一次/某段调整情绪基调）"补充记录并嵌入对应段落的蓝图。

### 5D 逐段生成
- **生成前**：从弧线表读取本段蓝图——核心事件/信息释放策略/情绪走向/密度目标。
- **生成时**：开头标注「第X段/共Y段｜目标X字」；持续引用前序设定（主角五维/配角标签/导语/黄金三句）防跑偏；到付费钩子断点暂停并标注「←付费钩子」。
- **生成后自检**：

| 检查项 | 标准 |
|:---|:---|
| 推进了情节或深化了人物？ | 删掉不影响理解→重写 |
| 情绪密度达标？ | 对照弧线表密度标注；不达标→情绪下坡处插入一个动作/对话/信息释放 |
| 偏离脑洞？ | 对照脑洞一句话+导语 |
| AI味儿？ | 对照 writing-styles.md 去味儿清单：总结句/模板句式/过度过渡/抽象描写/AI式对话 |
| 角色一致？ | 主角行为符底线；配角语言风格符标签 |

- **等待确认**：每段生成后停止，用户可选继续/这段重写/调整某处/回头改上一段。
- **一键全文差异**：生成全文→快速逐段自检→一次性展示；用户可指任何段（"第三段重写""收束太弱""付费钩子不够狠"），翻回该段重写，其余段保持不变。

### 5E 付费钩子段断点控制
1. **识别**：从弧线表提取所有标注"付费钩子"的段落，对照 opening-designer 付费钩子策略确认：断点位置（占全文百分比）/断点类型（信息缺口/情绪最高点/决策时刻/反转预告）/驱动力方向。
2. **开篇策略一致性验证（必须——防止正文阶段与开篇设计脱节，到评审才发现就晚了）**：

| 验证项 | 方法 | 不一致时 |
|:---|:---|:---|
| 断点类型与策略一致？ | 策略类型标注 vs 当前段断点类型 | 设计漂移→判断是更新策略（开篇设计器重新确认）还是调整当前段断点方向 |
| 位置偏差在允许范围？ | 策略位置 vs 实际位置 ≤ 全文±3% | 超出→调整段落边界或更新策略 |
| 信息缺口与设计一致？ | 策略标注的"读者不知道的X个问题"是否在实际断点处同时激活 | 遗漏任何一个→补一句暗示激活该缺口 |

3. **断点检查**：

| 检查项 | 标准 | 不通过时 |
|:---|:---|:---|
| 断点位置与策略一致 | 对照策略位置标注 | 调整段落边界 |
| "必须知道后续"驱动力够 | 信息缺口够大/情绪高点被掐断/角色处于两难 | 补强悬念，增加一句反转/暗示 |
| 断点前后衔接自然 | 不断在对话/动作/描写中间，断在"该说但没说"处 | 调整断点句 |

4. **生成要求**：到断点暂停标注「←付费钩子」；展示断点处最后两句的驱动力强度给用户确认——强（必须知道后续）/中（想知道但不急）/弱（可读可不读）。
5. **驱动力补强**：为中或弱时问用户："这个断点的驱动力是【中/弱】，建议断点前加一句：[补强建议]。要加吗？还是直接用现在的版本？"

### 5F 去AI味儿
全文完成后先逐段扫描、再全文扫描。

**7类AI痕迹识别+修改方向**：

| 类型 | 症状/识别模式 | 修改方向 |
|:---|:---|:---|
| 总结感 | 段/章末总结句式替读者解读情绪（终于/从此/这一夜/或许/也许——） | 删总结句，用动作或场景收尾 |
| 模板句式 | 高频跨作品通用描写模板（模板化比喻+情绪标配动作组合） | 换成角色独有的反应方式（基于人设） |
| 过度过渡 | 显式连接词衔接事件而非事件本身节奏（与此同时/紧接着/话音刚落/然而） | 直接并列或省略过渡词 |
| 抽象描写 | 概括词替代可验证的感官信息（无可验证细节的情绪概括句） | 用可验证的具体细节替代（看到/听到/做了什么） |
| AI式对话 | 对话完整无歧义、信息全交代、人物说话方式雷同 | 删掉一半台词留潜台词；两人说话方式要不同 |
| 百科口吻 | 叙事中途切换为解释/定义/说明模式（"X是一种Y物质""根据N学原理"等定义句式，把读者当被科普对象） | 不删信息，把定义句式改成角色认知句式——信息从角色的眼睛/记忆里出来 |
| 全文总结句 | "她终于明白/他感到/他意识到"等内心独白标签 | 改成与"明白"无关但暗示了"明白"的具体动作 |

**逐段扫描**：按正文顺序标注可疑位置（段号+句子）→分类→给修改方向（非具体改写，是方向）→用户确认"这个改吗？"

**全文扫描阈值**：

| 检查项 | 方法 | 阈值 |
|:---|:---|:---|
| 内心独白标签密度 | 搜"终于/感到/意识到/明白/觉得/好像懂了"等认知动词+心理陈述组合 | 每5000字≤1次；超→标记段号+列全部出现位置 |
| 百科解释密度 | 搜"是一种/指的是/根据/原理/专业术语"定义句式 | 全文≤2处；超→标记段号，替换为角色视角认知（"她记得带教老师说过——"比"根据医学原理"自然） |
| 段落对称性 | 连续3段以上字数高度一致（±20字） | 超连续3段→标记，人工打破一段的段落长度 |

**完成确认**："去AI味儿扫描完成。共发现X处可疑痕迹，已处理X处。正文草稿已就绪，进入评审器。"

**流转至 short-reviewer**：【流转上下文】= 正文草稿（完整全文）+【选定平台】【文章性质】【核心约束】【脑洞一句话】【导语】【黄金三句】【付费钩子策略】【剧情弧线】（完整表格）【主角五维】【角色清单】。

## 红线
| # | 红线 | 违反后果 |
|:-:|:-----|:---------|
| 1 | 生成前必须确认文风，禁止跳过文风选择直接生成；用户参考文本是文风最高优先，覆盖平台默认推荐 | 文风与平台不匹配/用户风格诉求被忽略 |
| 2 | 付费钩子段必须特殊标记+断点暂停，不能混入普通段 | 钩子位置模糊，付费策略失效 |
| 3 | 每段生成后必须通过自检再交给用户；去AI味儿是必走流程，不可跳过 | 低质量草稿流入下游/成品AI感重 |
| 4 | 用户在任何后续步骤（评审后/自己重读后）要求改某段正文，只重写该段其余段落保持不变；单段重写仍走完整自检（推进情节/密度达标/不偏离脑洞/AI味儿/角色一致） | 整篇重写导致逐段确认白费/重写段与其余段落质量不一致 |
| 5 | 微调响应格式——本轮只修改已有段落≤5句话时，响应仅输出改动段+一句说明，不输出钩子分析、创作记录、自检清单 | 响应膨胀，浪费算力 |

## 响应分级

| 用户指令类型 | 响应格式 |
|:---|:---|
| 明确确认（"继续""可以""ok""没问题"） | 只输出下一段正文。不附带创作记录、钩子分析、自检清单 |
| 微调请求（"改一下XX""这里不对"） | 只输出改动段落 + 一句话说明改了什么 |
| 新方向/新段落/首次生成 | 输出正文 + 关键钩子 + 创作记录要点（≤5条） |
