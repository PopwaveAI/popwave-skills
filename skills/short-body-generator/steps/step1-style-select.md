# Step 5A: 文风选择
> 从流转上下文提取平台信息，自动匹配推荐文风。加载 writing-styles.md 展示特征和范例。如用户上传参考文本，以参考文本为最高优先。

## 1. 提取前置输入
从 plot-structurer 的流转上下文中提取：
- 【选定平台】
- 【文章性质】
- 【脑洞一句话】
- 【导语】
- 【黄金三句】

## 2. 加载文风库
读取 `references/writing-styles.md`，展开5种文风的完整特征描述：
- 知性沉稳
- 网感快节奏
- 情感细腻
- 文学质感
- 极速钩子

## 3. 平台→文风推荐
| 平台 | 默认推荐 |
|:---|:---|
| 知乎盐言 | 知性沉稳 |
| 番茄短故事 | 网感快节奏 |
| 每天读点故事 | 情感细腻 |
| 豆瓣阅读 | 文学质感 |
| 小程序/信息流 | 极速钩子 |

## 4. 展示给用户
> "根据你选的【平台】，我推荐「{文风名称}」文风。
> 特征：{从 writing-styles.md 提取的核心特征，3-4条}
> 这里是一段该风格的开头范例：[引用 writing-styles.md 的范例]。
> 用这个风格可以吗？还是想调？你也可以上传一段你喜欢的文字让我参考。"

## 5. 用户上传参考文本
如用户上传参考文本，执行文风学习：
1. 提取语言特征：句长、对话比例、描写密度、特有词汇
2. 标注与平台默认推荐的差异点
3. 以参考文本特征覆盖默认推荐

> "我提取了你这段参考文本的特征：[特征摘要]。生成时会朝这个方向靠。确认开始？"

## 6. 确认
文风确认后进入 Step 5B。
