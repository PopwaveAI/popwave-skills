# Step 5B-5D: 确定模式 + 逐段生成
> Step 5B 确认生成模式（逐段/一键全文），Step 5C 收集用户额外补充，Step 5D 按蓝图逐段生成正文。

## 5B. 确认生成模式
> "你想一段一段确认，还是我先出全文给你看？默认为逐段确认。"

| 模式 | 流程 | 用户可操作 |
|:---|:---|:---|
| 逐段确认 | 每段一次生成→一次自检→一次用户确认 | "继续"/"这段重写"/"调整某处" |
| 一键全文 | 先生成全文→快速逐段自检→一次性展示 | "第三段重写""收束太弱""付费钩子不够狠" |

## 5C. 用户额外补充
> "开始前，有没有想在正文里特别加入的内容？比如某段多写什么、某个角色想多出现一次、某段想调整情绪基调？"

将该补充记录并嵌入对应段落的蓝图。

## 5D. 逐段生成

### 生成前
从弧线表中读取本段蓝图：
- 核心事件
- 信息释放策略
- 情绪走向
- 密度目标

### 生成时
- 开头标注：「第 X 段 / 共 Y 段 | 目标 X 字」
- 持续引用前序设定（主角五维、配角标签、导语、黄金三句），确保不跑偏
- 付费钩子段特殊处理：生成到断点后暂停，标注「← 付费钩子」

### 生成后自检

| 检查项 | 标准 |
|:---|:---|
| 这段推进了情节或深化了人物吗？ | 如果这段可以删掉而不影响理解 → 重写 |
| 情绪密度达标了吗？ | 对照弧线表的密度标注。不达标 → 在情绪下坡处插入一个动作/对话/信息释放 |
| 有没有偏离脑洞？ | 对照脑洞一句话 + 导语 |
| AI 味儿检查 | 对照 writing-styles.md 的去味儿清单：有没有总结句？模板句式？过度过渡？抽象描写？AI 式对话？ |
| 角色一致性 | 主角行为符合底线吗？配角的语言风格符合标签吗？ |

### 等待用户确认
每段生成后停止，让用户选择：继续 / 这段重写 / 调整某处 / 回头改上一段。

## 一键全文模式差异处理
- 先生成全文 → 快速逐段自检 → 一次性展示
- 展示完后用户可以在任何段说："第三段重写""收束太弱""付费钩子不够狠"
- Skill 翻回对应段重写，保持其他段不变
