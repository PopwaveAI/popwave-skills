# Step 5E: 付费钩子段断点控制
> 在弧线表中标注的付费钩子位置，做特殊断点处理和驱动力检查。确保断点位置、类型、驱动力与 opening-designer 的付费钩子策略对齐。

## 1. 识别付费钩子段
从剧情弧线表中提取所有标注为"付费钩子"的段落。对照 opening-designer 的付费钩子策略确认：
- 断点位置（占全文百分比）
- 断点类型（信息缺口 / 情绪最高点 / 决策时刻 / 反转预告）
- 驱动力方向

## 2. 和开篇策略的一致性验证（必须）
在断点检查前，先做一次"策略对齐确认"：

| 验证项 | 方法 | 不一致时 |
|:---|:---|:---|
| 断点类型是否和 opening-designer 的设计一致？ | 提取付费钩子策略中的类型标注，和当前段的断点类型对比 | 不一致→这是一个设计漂移。需要判断：是策略需要更新（开口篇设计器重新确认），还是当前段需要调整断点方向 |
| 断点位置偏差是否在允许范围内？ | 策略位置和实际位置差 ≤ 全文的 ±3% | 超出范围→调整段落边界或更新策略 |
| 断点处的信息缺口是否和设计一致？ | 策略中标注的"读者不知道的 X 个问题"是否在实际断点处同时被激活 | 遗漏任何一个→补一句暗示，激活该缺口 |

**目的：防止正文生成过程中付费钩子设计和开篇设计脱节——两个 Skill 分属不同阶段，如果不对齐，到了评审阶段才发现"钩子类型不对"已经晚了。**

## 3. 断点检查

| 检查项 | 标准 | 不通过时 |
|:---|:---|:---|
| 断点位置是否与策略一致？ | 对照付费钩子策略中的位置标注 | 调整段落边界 |
| 断点处读者"必须知道后续"的驱动力够不够？ | 信息缺口够大 / 情绪在高点被掐断 / 角色处于两难 | 补强悬念，增加一句反转/暗示 |
| 断点前后衔接是否自然？ | 不断在对话/动作/描写的中间，断在"该说但没说"的位置 | 调整断点句 |

## 4. 生成要求
- 生成到断点后暂停，标注「← 付费钩子」
- 展示断点处最后两句的"驱动力强度"给用户确认
- 驱动力强度分三级：强（必须知道后续）/ 中（想知道但不急）/ 弱（可读可不读）

## 4. 驱动力补强
如果驱动力为中或弱：
> "这个断点的驱动力是【中/弱】。建议在断点前加一句：[补强建议]。你要加吗？还是直接用现在的版本？"
