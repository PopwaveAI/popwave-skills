# Step 5F: 去AI味儿流程
> 全文生成完成后，用去AI味儿自检清单逐段扫描。识别7类AI痕迹，给出修改方向，用户逐段确认。

## 1. 7类AI痕迹识别

| 类型 | 症状 | 识别关键词/模式 |
|:---|:---|:---|
| 总结感 | 段落/章节末尾出现总结句式，替读者解读情绪 | 终于、从此、这一夜、或许、也许—— |
| 模板句式 | 高频率、跨作品通用的描写模板 | 模板化比喻+情绪标配动作组合 |
| 过度过渡 | 用显式连接词衔接事件，而非用事件本身节奏 | 与此同时、紧接着、话音刚落、然而 |
| 抽象描写 | 用概括词替代可验证的感官信息 | 没有可验证细节的情绪概括句 |
| AI式对话 | 对话完整无歧义、信息全部交代、人物说话方式雷同 | 对话信息密度过高、多人物语言风格无差别 |
| **百科口吻** | **叙事中途突然切换为解释/定义/说明模式** | **"X是一种Y物质""Z是W领域的专业术语""根据N学原理"等定义句式；把读者当成需要被科普的对象** |
| **全文总结句** | **全文范围内出现"她终于明白/他感到/他意识到/她明白了"等内心独白标签** | **每5000字扫描，累计超过1次则触发警告** |

## 2. 逐段扫描（段级别）
按正文顺序逐段执行：

1. 标注可疑位置（段号+句子）
2. 分类（上述前5类）
3. 给出修改方向（非具体改写，是方向）
4. 用户确认（"这个改吗？"）

## 3. 全文扫描（全文级别）
生成完成后做跨段落扫描：

| 检查项 | 方法 | 阈值 |
|:---|:---|:---|
| **内心独白标签密度** | 搜索"终于/感到/意识到/明白/觉得/好像懂了"等认知动词+心理陈述的组合 | 每5000字≤1次；超过→标记段号+列出所有出现位置 |
| **百科解释密度** | 搜索"是一种/指的是/根据/原理/专业术语"等定义句式 | 全文≤2处；超过→标记段号，建议替换为角色视角的认知（"她记得带教老师说过——"比"根据医学原理"更自然） |
| **段落对称性** | 检查连续3段以上字数高度一致（±20字） | 超过连续3段→标记，人工打破一段的段落长度 |

## 4. 修改方向示例

| 类型 | 修改方向 |
|:---|:---|
| 总结感 | 删掉总结句，用动作或场景收尾 |
| 模板句式 | 换成角色独有的反应方式（基于人设） |
| 过度过渡 | 直接并列或省略过渡词 |
| 抽象描写 | 用可验证的具体细节替代（看到什么/听到什么/做了什么） |
| AI式对话 | 删掉一半台词，给潜台词留空间；两人说话方式要不同 |
| 百科口吻 | 不删信息，但把"定义句式"改成"角色认知句式"——让信息从角色的眼睛/记忆里出来，不从旁白里出来 |
| 全文总结句 | 把"她终于明白了"改成角色做了一件和"明白"无关但暗示了"明白"的具体动作 |
