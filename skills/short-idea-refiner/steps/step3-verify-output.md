# Step 3: 脑洞检验 + 输出卡片
> 对选定方向逐条检验3项标准→未全通过则给出补强建议→输出脑洞卡片+流转上下文。模板参照 `templates/idea-card.tpl.md`。

## 3a. 脑洞检验（必须逐条给出判定）
| 检验项 | 判断 |
|:---|:---|
| 让人想听下去吗？ | ✅/❌ |
| 有反常识/反预期的元素吗？ | ✅/❌ |
| 能在 3 分钟内讲清吗？ | ✅/❌ |

**至少2项通过才进入下一步。** 如未全通过，给出 2-3 个补强建议，让用户选择改进方向。

## 3b. 输出脑洞卡片
```
【脑洞卡片】
  【脑洞一句话】
  【题材】
  【流派标签】
  【目标平台】
  【适配性质】
  【核心冲突】
  【预期反转/爽点】
  【检验结果】（✅/❌ 逐项）
  【热点参考】（本次参考的品类趋势摘要）
```

## 3c. 生成流转上下文
```
【流转上下文】
  【选定平台】
  【文章性质】
  【核心约束】
  【选定脑洞方向】
  【脑洞一句话】
  【题材】
  【流派标签】
  【检验结果】
  【热点参考】（本次参考的品类趋势摘要）
```

## 3d. 落盘
保存为 `step2-脑洞提炼.md`。
