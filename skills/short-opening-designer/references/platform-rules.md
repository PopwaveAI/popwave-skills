# 平台规则参考手册

## 知乎盐言故事（原盐选）

### 基础参数
- **字数要求**：1万字以上完本可投稿，优质作品通常 1-3 万字
- **付费模式**：50%分成，千字单价 30-100 元（由有效完读量决定）
- **免费阅读比例**：约 30%-40%，之后进入付费

### 目标读者
- 一二线城市 25-40 岁高知女性为主
- 追求"有智商的爽"：故事要有反转、有深度、有社会洞察
- 喜欢第一人称叙事带来的沉浸感和代入感

### 调性要求
- **知性成熟**：不能低幼，不能纯爽文无脑
- **现实共鸣**：最好有社会议题的暗线（性别、阶层、职场、家庭等）
- **情绪价值**：读完要让读者"想到点什么"
- **"知乎体"特征**：常以提问式或悬念式开头、第一人称、叙事者往往带有一定反思距离

### 热门品类
- 悬疑反转（第一梯队）：社会派悬疑、职场悬疑、家庭悬疑
- 现实情感（第一梯队）：婚姻、亲子、女性成长
- 规则怪谈（快速上升）：中式恐怖 + 民俗 + 自洽规则
- 职场/行业故事：医生、律师、警察、殡葬等特殊职业视角

### 开篇铁律
- 第一人称
- 前 300 字必须建立紧张感或抛出核心悬念
- 开篇常见模式："我从未想过……""直到那天，我发现了……""所有人都以为……但真相是……"

### 付费钩子特征
- 停在"真相即将揭晓但还没揭晓"的瞬间
- 停在主角做出关键选择的前一刻
- 停在某个角色的身份/秘密被揭示的边缘
- 断点要有"不得不付费"的紧迫感

### 格式注意
- 分段标题可用可不用，但用了可以增加阅读节奏感
- 段落不宜过长，手机屏阅读体验优先
- 结尾要有"收束感"——伏笔必须回收

## 番茄短故事

### 基础参数
- **字数要求**：6000 字以上完本可签约，主流作品 6000-2 万字
- **付费模式**：作者拿 100% 收益，平台不抽成
- **审核速度**：最快 1 小时出结果
- **过签率**：纯新人分成签约过签率 60%-70%

### 目标读者
- 下沉市场为主，年龄性别跨度大
- 追求"爽"和"快"：读着不累，节奏快，爽点密集
- 对文笔要求不高，但对"开篇能不能抓住我"要求极高

### 调性要求
- **网感强**：接地气的语言，不能文艺腔
- **爽点密**：每 300-500 字就要有一个小爽点或小反转
- **开篇即高潮**：前 300 字必须抛出核心冲突和金手指
- **"番茄味儿"**：鲜活、诙谐、不做作，即使是虐文也要有"人间烟火气"

### 热门品类
- 重生/穿越（永恒热门）：重生搞钱、重生复仇、重生追妻
- 甜宠/萌宝：轻松愉悦向，女主强/男主宠
- 规则怪谈 + 民俗悬疑（快速上升）：凶宅试睡员、古籍修复师、殡仪馆整容师等"自带规则"的职业
- 系统/脑洞：反套路系统、毒舌系统、奇葩金手指
- 年代文（需新角度）：纯年代退潮，但"年代+重生+搞钱"仍可跑

### 开篇铁律
- **前 3 句（不是 300 字，是 3 句）**内必须立住绝境或亮出金手指
- 第一段就要让读者知道"这篇爽在哪"
- 常用模式："我重生了/我穿成了X/我觉醒了一个逆天系统/我一觉醒来发现所有人都……"

### 付费钩子特征
- 和知乎不同，番茄的付费钩子更偏向"爽点预告"
- 断在主角即将打脸/翻身/揭露真相的前一刻
- 断在系统升级/新能力解锁的前一刻
- 断在反派即将被制裁的预告

### 格式注意
- 段落短，200-400 字一段，手机屏阅读友好
- 段落间建议空行
- 对话占比可以高，网文读者喜欢"能脑补画面"的对话
- 不用过于讲究文学性分段标题

## 每天读点故事

### 基础参数
- **字数要求**：建议 5000-8000 字
- **付费模式**：VIP 级别保底 1000 元/篇，稿费直接发放
- **特色**：专注中短篇，强短剧改编通道，多部改编播放量破亿

### 目标读者
- 全年龄段，女性为主
- 追求"情感共鸣"：被感动、被温暖、被治愈
- 喜欢适合"碎片化阅读"的短篇精品

### 调性要求
- **原生 + 奇崛 + 动人**：平台官方的核心内容主张
- **情感细腻**：人物心理刻画要有层次
- **冲突鲜明**：情感冲突是核心驱动力
- 不能纯爽文，要有情感深度

### 热门品类
- 暖甜/甜宠：轻松治愈向
- 都市情感：现代人的情感困惑与成长
- 悬疑（轻悬疑）：有悬念但不恐怖
- 青春/校园：青春回忆与成长
- 奇幻爱情：轻奇幻设定包装的情感故事

### 开篇铁律
- 前 200 字必须有"情感温度"
- 开篇常见模式：一个具体的生活场景/情感片段切入
- 不要求"炸裂开头"，但要求"让人想看下去的开头"

### 付费钩子特征
- 偏"情感断点"：停在情感升温最高处
- 停在关系转折的边缘
- 停在一个重要决定的前一刻

### 格式注意
- 适合音频改编的语感，语言要有"可朗读性"
- 段落适中，不需要像番茄那么短
- 环境描写和心理描写比番茄更被接受

## 豆瓣阅读

### 基础参数
- **字数要求**：2 万字以上可申请签约
- **付费模式**：70% 分成
- **风格**：注重文学性和深度

### 目标读者
- 偏成熟文艺的读者群体
- 追求"文学质感"
- 对叙事手法和语言风格有要求

### 调性要求
- **文学性**：语言要有质感，不能纯网文化
- **深度**：不满足于表面情节，追求人物和主题的深度
- **审美**：对美感有要求（语言美感、结构美感）

### 热门品类
- 都市/现实：当代城市生活
- 青春/成长：个人成长叙事
- 悬疑（文学悬疑）：偏氛围和心理的悬疑
- 女性叙事：女性视角的深度故事

### 开篇铁律
- 不要求炸裂，但要求"有质感"
- 可以慢热，但语言要抓人
- 不适用番茄式/知乎式的开篇公式

### 付费钩子特征
- 相对淡，不强调强断点
- 更多依靠整体阅读体验驱动付费

### 格式注意
- 正常段落长度即可
- 不排斥文学性描写
- 结尾要有"余韵"
