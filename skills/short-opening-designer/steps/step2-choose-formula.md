# Step 2: 选择导语公式
> 根据平台 × 卖点主轴，自动推荐最适配的公式，并向用户说明选择理由。

## 2a. 6种导语公式速查
### 公式1：悬念前置
结构：惊人结果 + "但事情没这么简单" + 更大的疑问
适配：知乎 ⭐⭐⭐⭐⭐ / 番茄 ⭐⭐⭐

### 公式2：情绪爆发
结构：强烈情绪词 + 一个具体事件 + "那一刻我明白了……"
适配：每天读点故事 ⭐⭐⭐⭐⭐ / 知乎 ⭐⭐⭐⭐

### 公式3：对话开头
结构：一句带引号的话 + 谁说的+场景 + 这句话引发的后果
适配：知乎 ⭐⭐⭐⭐ / 每天读点故事 ⭐⭐⭐⭐

### 公式4：身份共鸣
结构：精准身份标签 + 扎心困境 + "你是不是也……"
适配：番茄 ⭐⭐⭐⭐⭐ / 每天读点故事 ⭐⭐⭐⭐

### 公式5：反转
结构：常规认知 + "但我发现……" + 完全相反的真相
适配：知乎 ⭐⭐⭐⭐⭐ / 番茄 ⭐⭐⭐⭐

### 公式6：画面切入
结构：具体画面/动作 + 时间地点 + 画面的"不对劲"之处
适配：每天读点故事 ⭐⭐⭐⭐⭐ / 豆瓣 ⭐⭐⭐⭐⭐

## 2b. 平台 × 公式自动匹配表
| 平台 | 优先推荐公式（按顺序） |
|:---|:---|
| 知乎盐言 | 悬念前置、反转、对话开头 |
| 番茄短故事 | 身份共鸣、反转、悬念前置 |
| 每天读点故事 | 情绪爆发、画面切入、对话开头 |
| 豆瓣阅读 | 画面切入、情绪爆发、对话开头 |
| 小程序生态 | 身份共鸣、反转、悬念前置 |

## 2c. 输出推荐
```
【推荐公式】
  首选：公式N（理由：……）
  备选：公式M（理由：……）
```

标注公式与卖点主轴的契合度。如用户有异议，可换备选公式。
