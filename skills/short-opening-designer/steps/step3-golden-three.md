# Step 3: 生成黄金三句
> 用三要素法生成2-3组黄金三句。每组标注公式、读者心理、平台适配度。等用户选定+精修。

## 3a. 三要素法
| 句 | 功能 | 方法 |
|:---|:---|:---|
| 句1 | **甩冲突** | 反常事件 / 绝境宣示 / 强烈情绪 / 身份反差 / 直接亮结果 |
| 句2 | **拉近距/抛悬念** | 具体感官细节（动作/触感/声音/气味）**或** 引出"但事情没这么简单"的信号 |
| 句3 | **留钩子/定调性** | 暗示走向（爽？虐？悬？暖？）+ 最强烈的一个未解谜题 |

## 3b. 生成2-3组
每组标注：
- 所用公式名称
- 适配的读者心理（如"悬念导向型读者会立刻点进来"）
- 平台对该公式的适配度

```
【黄金三句 · 组#N】（公式：XXX）
  句1: ……
  句2: ……
  句3: ……
  【适配】平台XXX对该公式适配度：⭐⭐⭐⭐⭐
  【读者心理】……
```

## 3c. 用户选定 + 精修
等用户选择一组后，允许：
- 合并两组的写法
- 调整某个句子的语气
- 缩短某句话

迭代精修直到用户确认。**黄金三句确认前不进入 Step 4。**
