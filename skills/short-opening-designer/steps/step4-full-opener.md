# Step 4: 补完整导语
> 黄金三句确定后，根据需要补充1-2句。目标：让读者对"看完全篇能获得什么"有预期。

## 4a. 补句规则
| 平台 | 是否需要补句 | 补充方向 |
|:---|:---|:---|
| 知乎 / 番茄 | 可选（三句话常已足够） | 如补，补一句叙事视角/风格定调 |
| 每天读点故事 / 豆瓣 | 建议加一句 | 情感落点，让读者有情绪预期 |

## 4b. 导语字数约束
| 参数 | 值 |
|:---|:---|
| 最小 | 100字 |
| 最大 | 200字 |
| 黄金三句占比 | 60-80% |

## 4c. 补句禁忌
以下三类内容绝对不出现在导语中：
1. 交代背景（"故事发生在……"）
2. 抒情议论（"爱情是这世上最……"）
3. 解释说明（"之所以会这样，是因为……"）

## 4d. 输出完整导语
```
【完整导语】
  （黄金三句 + 补句，100-200字）
  
  【导语最后一句话是否为最强悬念/钩子？】✅/❌
```

导语确定前不进入 Step 5。
