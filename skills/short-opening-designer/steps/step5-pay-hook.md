# Step 5: 设计付费钩子 + 输出开篇卡片
> 设计付费断点策略→输出开篇卡片→生成流转上下文。模板参照 `templates/opening-card.tpl.md`。

## 5a. 确定钩子位置
| 平台 | 免费比例 | 钩子位置 |
|:---|:---|:---|
| 知乎盐言 | 30-40% | 全篇约 35% 字数处 |
| 番茄短故事 | 前 25-30% | 全篇约 30% 字数处 |
| 每天读点故事 | 35-40% | 全篇约 35-40% 字数处 |
| 豆瓣阅读 | 不强制 | 如需设置，约 40% 处 |

## 5b. 选择钩子类型
| 类型 | 触发机制 | 适用卖点 |
|:---|:---|:---|
| **信息缺口** | 刚抛出重大悬念时，不让读者知道答案 | 悬疑、猎奇 |
| **情绪最高点** | 读者对人物情感投入达最高时戛然而止 | 情感、虐 |
| **决策时刻** | 主角面临重大选择时，停在选择前 | 反转、身份共鸣 |
| **反转预告** | 暗示即将发生反转，不透露内容 | 反转、悬疑 |

## 5c. 输出钩子策略
```
【付费钩子策略】
  【位置】全篇约 X% 字数处（约 X 字）
  【类型】XXX
  【断点设计】具体描述断点内容
  【设计逻辑】为什么这个地方能让读者不得不付费？
```

## 5d. 输出开篇卡片
```
【开篇卡片】
  【卖点主轴】
  【导语公式】
  【黄金三句】
    句1:
    句2:
    句3:
  【完整导语】（含补充句）
  【付费钩子】
    位置:
    类型:
    断点设计:
```

## 5e. 生成流转上下文
```
【流转上下文】
  【选定平台】
  【文章性质】
  【核心约束】
  【脑洞一句话】
  【导语】（完整版）
  【黄金三句】
  【付费钩子策略】（位置+类型+断点设计）
```

## 5f. 落盘
保存为 `step3-开篇设计.md`。
