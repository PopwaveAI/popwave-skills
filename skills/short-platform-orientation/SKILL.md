# short-platform-orientation
> 短篇平台定位器。摸底3问→平台深度匹配→定位卡片。v2.1.0：steps 三件全合入单文件精炼；执行模式=主agent直执。

## 做什么
输入：作者意向（题材倾向/核心目标/现有想法，可能全空）
输出：平台定位卡片 + 传递 idea-refiner 的流转上下文 + **项目总览.md 完整内容（由主agent创建文件）**

**执行模式**：主agent直执。全程与作者问答交互（摸底→匹配→定位确认），无自然子agent适配点。

## 怎么操作（SOP全内联）

### Step 1 快速摸底（3问）
明确意向则跳过摸底：说了平台+题材→确认后展开该平台该题材；只说了题材→做该题材跨平台对比；什么都没说→摸底3问：①题材倾向——悬疑/言情/重生穿越/规则怪谈/年代/现实情感/脑洞/还没想好？②核心目标——快速签约拿稿费/打磨品质冲击改编/兼顾/练手？③现有素材——有没有成型想法，还是从零开始？
产出：题材方向+目标意图（签约/品质/兼顾）+现有想法（有/无及内容）。

### Step 2 平台深度匹配
基于题材+意图深度展开**1-2个最适合的平台**（数据以 references/platform-rules.md + genre-guide.md 为准），其余平台一句话简述（"XX平台对YY题材不友好，因为……"）。
每个展开平台8维度：签约门槛与速度·目标读者画像·该题材平台表现（头部还是边缘）·子方向推荐（最值得做的细分方向）·开篇铁律（前多少字/句达成什么效果）·付费钩子模式（有无/断在哪/怎么断）·改编潜力（短剧/漫剧）·风险注意。两个候选平台按8维度出对比表，展示优劣让作者选。

### Step 3 输出定位卡片+流转上下文
1. **定位卡片**（格式参照 `templates/platform-card.tpl.md`）：【平台】（对比表提炼）+【文章性质】（平台自动推导，见下表）+【签约门槛】【核心读者】【开篇铁律】【付费钩子模式】【改编方向】【风险提示】。作者方向与平台性质明显冲突→卡片标注风险警告，不强制阻止。
2. **流转上下文**：【选定平台】【文章性质】【核心约束】（平台铁律+开篇要求+付费模式）【用户意向】（题材×目标×改编诉求）【原始想法】（模糊想法，可能为空）。
3. **落盘** `step1-平台定位.md`，流转到 `short-idea-refiner`。

## 项目总览.md 模板

首次执行 Step 3 时必须**返回以下格式的 `项目总览.md` 完整内容给主agent**，后续所有 Step 按此格式返回更新：

```markdown
# 项目总览

> 更新日期：YYYY-MM-DD ｜ 当前阶段：Step N 名称

## 流程进度

<!-- STAGE_TABLE_START -->
| ID | Step | 状态 | 摘要 |
|:--|:--|:--|:--|
| S1 | 平台定位 | 🟡 | — |
| S2 | 脑洞提炼 | ⬜ | — |
| S3 | 开篇设计 | ⬜ | — |
| S4 | 剧情结构 | ⬜ | — |
| S5 | 正文生成 | ⬜ | — |
| S6 | 评审 | ⬜ | — |
<!-- STAGE_TABLE_END -->
```

**状态约束：**
- 仅三种：`⬜` 未开始 / `🟡` 进行中 / `✅` 完成
- **有且仅有 1 个 Step 为 🟡**
- `STAGE_TABLE_START` 和 `STAGE_TABLE_END` 标记不可删除
- ID（S1-S6）不可改动
- 如用户跳过某 Step，标记为 `✅ 已跳过`，不可留 `⬜`

## 平台 × 性质推导
| 平台 | 自动性质 |
|:---|:---|
| 番茄短故事 | 快节奏爽文 / 网感强 / 下沉市场 |
| 知乎盐言故事 | 知性深度 / 社会洞察 / 反转导向 |
| 每天读点故事 | 情感治愈 / 暖甜 / 短剧感 |
| 豆瓣阅读 | 文学质感 / 慢热 / 长尾品质 |
| 小程序生态 | 信息流钩子 / 极致快节奏 |
| 七猫 | 精品网文 / 保底导向 |

## 红线
| # | 红线 | 违反后果 |
|:-:|:-----|:---------|
| 1 | 不做跨平台通稿——只深度展开1-2个最适合的平台 | 信息稀释，作者无法决策 |
| 2 | 不替作者做最终决定——展示优劣，让作者选 | 作者投错平台归咎skill |
| 3 | 平台数据以 `references/platform-rules.md` 为准，不发明规则 | 误导作者 |
| 4 | 遇到实时性政策问题如实告知作者去后台确认 | 过时信息导致签约失败 |
