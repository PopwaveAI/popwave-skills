# Step 3: 输出定位卡片 + 流转上下文
> 定位卡片格式参照 `templates/platform-card.tpl.md`。文章性质由平台自动推导。

## 3a. 输出定位卡片
```
【平台定位卡片】
  【平台】从对比表格中提炼
  【文章性质】由平台自动推导（见SKILL.md平台×性质推导表）
  【签约门槛】
  【核心读者】
  【开篇铁律】
  【付费钩子模式】
  【改编方向】
  【风险提示】
```

如果作者方向与平台性质明显冲突（"想在番茄写文学性强的"），在卡片中标注风险警告，但不强制阻止。

## 3b. 生成流转上下文
```
【流转上下文】
  【选定平台】
  【文章性质】
  【核心约束】（来自平台铁律+开篇要求+付费模式）
  【用户意向】题材 × 目标 × 改编诉求
  【原始想法】（用户手头的模糊想法，可能为空）
```

## 3c. 落盘
保存为 `step1-平台定位.md`。

## 下一步
流转到 `short-idea-refiner`。
