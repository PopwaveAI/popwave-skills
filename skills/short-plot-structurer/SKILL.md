# short-plot-structurer
> 本技能为短篇剧情结构器，流程依次为：选模板、画弧线、配角色、输出骨架卡片。v2.2.0 将四个步骤全部合入单文件并精炼；执行模式为由主 agent 直接执行。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 职责范围
输入：导语、黄金三句与付费钩子策略，均来自 opening-designer 的流转上下文，含选定平台、文章性质、脑洞一句话、导语、黄金三句、付费钩子策略六项。
输出：骨架卡片（含结构模板、剧情弧线、角色清单）与流向 body-generator 的流转上下文。

## 核心原则
短篇的核心是**情节节奏与情绪释放**，不是人物深度。须先定剧情，再根据剧情需要设计角色。
> 判断依据："这个反转需要什么样的人设来撑？谁来承受这个情绪爆发效果最有力？" 角色是剧情的函数，人设由剧情反推得出。

**执行模式**：由主 agent 直接执行。连续创作链（脑洞、导语、结构）的交互确认环节，即模板选定、弧线确认、角色清单三项须与用户逐关确认，不存在适合派发子 agent 的环节。

## 怎么操作（规程全内联）

### Step 1 推荐结构模板
按平台、题材、卖点主轴自动推荐结构模板，展示结构框架，待用户确认后进入下一步：

| 平台×题材 | 推荐模板 | 原因 |
|:--|:--|:--|
| 知乎+悬疑/反转 | 知乎反转体 | 采用第一人称，层层剥洋葱，结尾大反转 |
| 知乎+社会派/现实 | 知乎反转体或经典三幕式 | 视主卖点是反转还是人物成长而定 |
| 番茄+脑洞/系统/爽文 | 番茄单元剧体 | 每段设一个爽点或一次解谜，节奏极快 |
| 番茄+重生/言情 | 番茄单元剧体或经典三幕式 | 视主线为"单元爽点"还是"人物弧线"而定 |
| 每天读点故事+情感/甜宠 | 情绪爆发体 | 以情绪线为主线，事件为副线 |
| 每天读点故事+轻悬疑 | 经典三幕式 | 事件线与情感线双线并行 |
| 豆瓣+全品类 | 经典三幕式 | 最通用，为文学质感留出空间 |

四种模板的结构框架如下：
- **知乎反转体**（1-3万字）：依次为开场、布局、误导、逆转、收束；信息释放通过"现在叙事"与"过去闪回"交替完成。
- **番茄单元剧体**（6000-15000字）：依次为开局、单元1（免费，埋新危机）、单元2（付费）、单元3（付费高潮）、收束。
- **经典三幕式**（全平台）：第一幕建立日常并设置激励事件（25%），第二幕冲突升级、中点转折、最黑暗时刻（50%），第三幕最终对决并收束（25%）。
- **情绪爆发体**（5000-8000字）：依次为情绪引子、回忆或展开、情绪攀升、情绪释放、余韵。

输出【推荐模板】及理由，并输出【备选模板】及理由。

### Step 2 剧情弧线设计
基于选定模板按免费段与付费段分段设计。每段包含五项：**本段功能**（建立悬念、推进冲突、制造误导或情绪释放）、**核心事件**（段内最重要的一件事）、**信息释放**（读者知道什么、还不知道什么）、**情绪走向**（从什么变成什么）、**付费钩子嵌入**（标注 opening-designer 确定的钩子位置）。

表格列依次为：段落、字数、免费付费、核心事件、信息释放、情绪走向、钩子；付费钩子单独列一行（信息释放栏写"断在XXX"，钩子栏标"←"）。

设计约束：总字数须匹配选定模板的字数范围；**付费钩子位置必须与 opening-designer 的钩子策略对齐**；每段功能不得重复，信息释放须递进；情绪走向须有起伏，不得单调。

**剧情动作差异化自检**（弧线设计完成后逐段核对以下三条规则）：
1. **相邻段落核心事件类型不得重复。** 任意两段核心事件属同一类别（如都是"当众揭开真相"或都是"意外发现线索"），即使内容不同也视为重复。连续两段同类时，须合并较短一段，或改为不同类型的事件（如"发现线索"改为"线索被主动送到主角面前"）。本条适用于全篇所有相邻段落对。
2. **收束段跨度控制。** 从全篇最高情绪点（通常为逆转段或高潮段）到收束段结尾，中间最多隔一个段落。隔两段及以上即为收束"拖沓"，须合并中间段落，或将高峰后移。收束段自身字数不得超过逆转段的 90%。
3. **反转或高潮工具类型多样性。** 同一"推进方式"全篇使用超过两次（如"当众曝光"超过两次），第三次必须更换不同机制。推进方式分为当众对质、私下摊牌、物证发现、第三方意外介入、角色自身认知变化、时间压力六类。本条适用于第 1 段到收束段。

### Step 3 角色设计（服务于剧情）
剧情弧线确认后开始。短篇铁律：**有名有姓的角色不超过五个，每个角色承担一个功能**。先用表格列出角色清单，列为角色、叙事功能、在哪个剧情节点发挥作用三项。

**主角四维**（每维度只写一句话，不得在人设上铺开）：
- **欲望（Want）**：外在目标。须具体、有期限、失败代价可见，并对应剧情中的具体事件。
- **软肋（Need）**：内在需求，与欲望相冲突，如"想要复仇"与"需要放下"。
- **执念/创伤（Wound）**：指一个具体的过往事件，它形成现在的行为模式，并在故事结局得到回应。
- **反差（Contrast）**：一个明确的矛盾特质，用于让读者记住主角。

**配角功能**（引用 references/character-card.md 的方法论）：

| 功能 | 说明 |
|:--|:--|
| 对手/反派 | 制造核心冲突，必须有可理解的动机，不得是纯粹的恶 |
| 镜像/对照 | 与主角处境相似但选择不同，用于凸显主角的成长 |
| 信息源 | 提供关键线索或背景，不得只出场一次 |
| 情感锚 | 代表主角的"正常世界"或情感归属 |
| 催化剂 | 推动主角做出关键决定 |

**功能重复的配角必须合并。**

输出角色清单：主角列出外在标签、内在反差、渴望、软肋、底线、小缺点；配角每人列出叙事功能、出场节点、活人标签；配角最多四个。

**角色密度合并检查**（角色清单完成后）：统计弧线表每段"首次出场"的角色数。某段引入两个及以上新角色时，检查能否将其提前到前一段出场，或将其中至少一个角色的功能合并给已有角色。全篇有名有姓且有台词的角色超过上限时，按以下优先级合并：①优先合并功能重叠的配角；②优先合并只出场一次的角色；③优先合并无独立台词的角色。合并后须验证：每个角色至少碰撞主角的一个维度（渴望、软肋、底线、内在反差），不得只是简单"删掉一个人的台词给另一个人"。合并导致一个角色承担三个及以上不同功能时，须保留拆分（功能数超过两个的角色可作例外）。

### Step 4 输出骨架卡片与流转上下文
**骨架卡片**：含结构模板、总字数、剧情弧线（Step 2 的完整表格）、主角四维（外在标签、内在反差、渴望、软肋、执念创伤、小缺点）、角色清单（每人含角色、叙事功能、出场节点、活人标签）、付费钩子嵌入位置（弧线第 X 段、第 X 字）。

**流转上下文**（流向 short-body-generator）：含选定平台、文章性质、核心约束、脑洞一句话、导语、黄金三句、付费钩子策略、剧情弧线（完整表格）、主角四维、角色清单。

**完整性自检**（有未通过项时，须返回相应步骤修正后再写入）：

| 检查项 | 判定 |
|:--|:--|
| 角色总数≤5 | ✅/❌ |
| 付费钩子与剧情弧线对齐 | ✅/❌ |
| 总字数在模板范围内 | ✅/❌ |
| 每段情绪走向有起伏 | ✅/❌ |

**写入**：保存为 `step4-剧情结构.md`。

## 红线
| # | 红线 | 违反后果 |
|:-:|:-----|:---------|
| 1 | 有名有姓的角色不超过五个（短篇铁律） | 角色过多，读者记不住 |
| 2 | 不在人设上铺陈过多，每维度只写一句话 | 正文空间被挤占 |
| 3 | 功能重复的配角必须合并 | 浪费有限篇幅 |
| 4 | 剧情弧线钩子位置必须与付费钩子策略对齐 | 钩子错位，付费策略失效 |
| 5 | 骨架确定前不得进入 body-generator | 正文生成失去结构约束 |
