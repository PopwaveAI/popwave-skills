# short-plot-structurer
> 短篇剧情结构器。选模板→画弧线→配角色→输出骨架卡片。v2.0.0：steps 四件全合入单文件精炼；执行模式=主agent直执。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 做什么
输入：导语+黄金三句+付费钩子策略（来自 opening-designer 流转上下文：选定平台/文章性质/脑洞一句话/导语/黄金三句/付费钩子策略）
输出：骨架卡片（结构模板+剧情弧线+角色清单）+ 流向 body-generator 的流转上下文

## 核心原则
短篇的核心是**情节节奏和情绪释放**，不是人物深度。先定剧情、再根据剧情需要设计角色。
> 逻辑链："这个反转需要什么样的人设来撑？谁来承受这个情绪爆发效果最有力？" ——角色是剧情的函数。

**执行模式**：主agent直执。连续创作链（脑洞→导语→结构）的交互确认环节——模板选定/弧线确认/角色清单与用户逐关确认，无自然子agent适配点。

## 怎么操作（SOP全内联）

### Step 1 推荐结构模板
按平台×题材×卖点主轴自动推荐，展示结构框架，等用户确认后进入下一步：

| 平台×题材 | 推荐模板 | 原因 |
|:--|:--|:--|
| 知乎+悬疑/反转 | 知乎反转体 | 第一人称+层层剥洋葱+结尾大反转 |
| 知乎+社会派/现实 | 知乎反转体或经典三幕式 | 看主卖点是反转还是人物成长 |
| 番茄+脑洞/系统/爽文 | 番茄单元剧体 | 每段一个爽点/解谜，节奏极快 |
| 番茄+重生/言情 | 番茄单元剧体或经典三幕式 | 看是"单元爽点"还是"人物弧线" |
| 每天读点故事+情感/甜宠 | 情绪爆发体 | 情绪线为主线，事件为副线 |
| 每天读点故事+轻悬疑 | 经典三幕式 | 事件+情感双线并行 |
| 豆瓣+全品类 | 经典三幕式 | 最通用，给文学质感留空间 |

4种模板结构框架：
- **知乎反转体**（1-3万字）：开场→布局→误导→逆转→收束；信息释放通过"现在叙事"和"过去闪回"交替
- **番茄单元剧体**（6000-15000字）：开局→单元1（免费+埋新危机）→单元2（付费）→单元3（付费高潮）→收束
- **经典三幕式**（全平台）：第一幕建立日常+激励事件（25%）→第二幕冲突升级+中点转折+最黑暗时刻（50%）→第三幕最终对决+收束（25%）
- **情绪爆发体**（5000-8000字）：情绪引子→回忆/展开→情绪攀升→情绪释放→余韵

输出【推荐模板】+理由+【备选模板】+理由。

### Step 2 剧情弧线设计
基于选定模板按免费/付费分段设计。每段包含：**本段功能**（建立悬念/推进冲突/制造误导/情绪释放）+**核心事件**（段内最重要的1件事）+**信息释放**（读者知道什么/还不知道什么）+**情绪走向**（从什么变成什么）+**付费钩子嵌入**（标注 opening-designer 确定的钩子位置）。

表格列：段落/字数/免费付费/核心事件/信息释放/情绪走向/钩子；付费钩子单列一行（信息释放=断在XXX，钩子列标←）。

设计约束：总字数匹配选定模板字数范围；**付费钩子位置必须与 opening-designer 的钩子策略对齐**；每段功能不重复、信息释放递进；情绪走向有起伏不单调。

**剧情动作差异化自检**（弧线设计完成后逐段过三条规则）：
1. **相邻段落核心事件类型不得重复**——任意两段核心事件属同一类别（如都是"当众揭开真相"/都是"意外发现线索"），即使内容不同也视为重复；连续两段同类→合并较短一段，或改为不同类型事件（如"发现线索"改为"线索被主动送到主角面前"）。适用全篇所有相邻段落对。
2. **收束段跨度控制**——从全篇最高情绪点（通常为逆转段/高潮段）到收束段结尾，中间最多隔1个段落；隔2段及以上=收束在"拖"，合并中间段落或把高峰后移；收束段自身字数不超过逆转段的90%。
3. **反转/高潮工具类型多样性**——同一"推进方式"全篇使用超过2次（如"当众曝光">2次），第3次必须换不同机制。推进方式分类：当众对质/私下摊牌/物证发现/第三方意外介入/角色自身认知变化/时间压力。适用第1段到收束段。

### Step 3 角色设计（服务于剧情）
剧情弧线确认后进行。短篇铁律：**≤5个有名有姓的角色，每个角色一个功能**。先用表格列角色清单（角色/叙事功能/在哪个剧情节点发挥作用）。

**主角四维**（每维度一句话，不在人设上铺开）：
- **欲望（Want）**：外在目标。具体、有期限、失败代价可见，对应剧情中的具体事件
- **软肋（Need）**：内在需求，和欲望有冲突——"想要复仇" vs "需要放下"
- **执念/创伤（Wound）**：具体的一个过往事件，形成现在的行为模式，在故事结局得到回应
- **反差（Contrast）**：一个明确的矛盾特质，让读者记住主角

**配角功能**（引用 references/character-card.md 方法论）：

| 功能 | 说明 |
|:--|:--|
| 对手/反派 | 制造核心冲突，必须有可理解的动机（不是纯恶） |
| 镜像/对照 | 和主角处境相似但选择不同，凸显主角的成长 |
| 信息源 | 提供关键线索或背景，不能只出场一次 |
| 情感锚 | 代表主角的"正常世界"或情感归属 |
| 催化剂 | 推动主角做出关键决定 |

**功能重复的配角必须合并。**

输出角色清单：主角（外在标签/内在反差/渴望/软肋/底线/小缺点）+配角每人（叙事功能/出场节点/活人标签），最多4个配角。

**角色密度合并检查**（角色清单完成后）：统计弧线表每段"首次出场"角色数；某段引入≥2个新角色→检查能否在前一段提前出场，或将其中≥1个的功能合并给已有角色。全篇有名有姓+有台词角色超上限→按优先级合并：①功能重叠配角优先②只出场1次的角色优先③无独立台词的角色优先。合并后验证：每个角色至少碰撞主角的一个维度（渴望/软肋/底线/内在反差），不是简单"删掉一个人的台词给另一个人"；合并导致一个角色承担≥3个不同功能→保留拆分（功能数>2的角色可例外）。

### Step 4 输出骨架卡片 + 流转上下文
**骨架卡片**：结构模板/总字数/剧情弧线（Step 2完整表格）/主角四维（外在标签/内在反差/渴望/软肋/执念创伤/小缺点）/角色清单（每人：角色/叙事功能/出场节点/活人标签）/付费钩子嵌入位置（弧线第X段/第X字）。

**流转上下文**（流向 short-body-generator）：选定平台/文章性质/核心约束/脑洞一句话/导语/黄金三句/付费钩子策略/剧情弧线（完整表格）/主角四维/角色清单。

**完整性自检**（有未通过项→返回相应步骤修正后再落盘）：

| 检查项 | 判定 |
|:--|:--|
| 角色总数≤5 | ✅/❌ |
| 付费钩子与剧情弧线对齐 | ✅/❌ |
| 总字数在模板范围内 | ✅/❌ |
| 每段情绪走向有起伏 | ✅/❌ |

**落盘**：保存为 `step4-剧情结构.md`。

## 红线
| # | 红线 | 违反后果 |
|:-:|:-----|:---------|
| 1 | 角色不超过5个有名有姓的（短篇铁律） | 角色过多、读者记不住 |
| 2 | 不在人设上铺陈过多——每维度一句话 | 正文空间被挤占 |
| 3 | 功能重复的配角必须合并 | 浪费有限篇幅 |
| 4 | 剧情弧线钩子位置必须与付费钩子策略对齐 | 钩子错位，付费策略失效 |
| 5 | 骨架确定前不进入 body-generator | 正文生成失去结构约束 |
