# Step 1: 推荐结构模板
> 根据平台 × 题材 × 卖点主轴，自动推荐最适配的结构模板。展示结构框架，确认后进入下一步。

## 1a. 提取前置输入
从 opening-designer 的流转上下文中提取：
- 【选定平台】
- 【文章性质】
- 【脑洞一句话】
- 【导语】
- 【黄金三句】
- 【付费钩子策略】

## 1b. 平台 × 题材匹配表
| 平台 × 题材 | 推荐模板 | 原因 |
|:---|:---|:---|
| 知乎 + 悬疑/反转 | **知乎反转体** | 第一人称+层层剥洋葱+结尾大反转 |
| 知乎 + 社会派/现实 | **知乎反转体** 或 **经典三幕式** | 看主卖点是反转还是人物成长 |
| 番茄 + 脑洞/系统/爽文 | **番茄单元剧体** | 每段一个爽点/解谜，节奏极快 |
| 番茄 + 重生/言情 | **番茄单元剧体** 或 **经典三幕式** | 看是"单元爽点"还是"人物弧线" |
| 每天读点故事 + 情感/甜宠 | **情绪爆发体** | 情绪线为主线，事件为副线 |
| 每天读点故事 + 轻悬疑 | **经典三幕式** | 事件+情感双线并行 |
| 豆瓣 + 全品类 | **经典三幕式** | 最通用，给文学质感留空间 |

## 1c. 4种模板结构框架
### 知乎反转体（1-3万字）
开场→布局→误导→逆转→收束。信息释放通过"现在叙事"和"过去闪回"交替。

### 番茄单元剧体（6000-15000字）
开局→单元1（免费+埋新危机）→单元2（付费）→单元3（付费高潮）→收束。

### 经典三幕式（全平台）
第一幕：建立日常+激励事件（25%）→第二幕：冲突升级+中点转折+最黑暗时刻（50%）→第三幕：最终对决+收束（25%）。

### 情绪爆发体（5000-8000字）
情绪引子→回忆/展开→情绪攀升→情绪释放→余韵。

## 1d. 输出推荐+确认
```
【推荐模板】XXX（理由）
【备选模板】XXX（理由）
```

展示选定模板的结构框架，等用户确认后进入下一步。
