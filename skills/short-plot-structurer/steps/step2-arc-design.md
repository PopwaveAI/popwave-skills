# Step 2: 剧情弧线设计
> 基于选定模板，设计全篇剧情弧线。按免费/付费分段，每段标注功能/事件/信息释放/情绪走向/钩子。

## 2a. 弧线段落字段
每段包含：
- **本段功能**：建立悬念？推进冲突？制造误导？情绪释放？
- **核心事件**：一段内发生的最重要的 1 件事
- **信息释放**：读者在这一段知道了什么、还不知道什么
- **情绪走向**：读者的情绪状态从什么变成什么
- **付费钩子嵌入**：标注 opening-designer 确定的付费钩子位置

## 2b. 弧线表格格式
```
【剧情弧线】

| 段落 | 字数 | 免费/付费 | 核心事件 | 信息释放 | 情绪走向 | 钩子 |
|:---|:---|:---|:---|:---|:---|:---|
| 第一段 | X字 | 免费 | XXX | 知道XXX / 不知道XXX | 好奇→投入 | |
| 第二段 | X字 | 免费 | XXX | … | 投入→紧张 | |
| … | … | … | … | … | … | |
| 付费钩子 | — | — | — | 断在XXX | — | ← |
| … | … | … | … | … | … | |
```

## 2c. 设计约束
- 总字数需匹配选定模板的字数范围
- 付费钩子位置必须与 opening-designer 的钩子策略对齐
- 每段功能不重复，信息释放递进
- 情绪走向有起伏，不单调

## 2d. 剧情动作差异化规则（通用）
设计完成的弧线需逐段自检以下三项：

**规则 1：相邻段落核心事件类型不得重复。**
- 任意两段如果核心事件属于同一类别（如都是"当众揭开真相" / 都是"角色拒绝某人" / 都是"意外发现线索"），即使内容不同也视为重复
- 连续两段出现同类事件 → 合并其中较短的一段，或将其中一段改为不同类型的事件（如"发现线索"改为"线索被主动送到主角面前"）
- 适用范围：全篇所有相邻段落对

**规则 2：收束段从最后情绪高峰到结尾的跨度控制。**
- 从全篇最高情绪点（通常为逆转段/高潮段）到收束段结尾，中间最多只能隔 1 个段落
- 如果中间隔了 2 段及以上 → 说明收束在"拖"。合并中间段落或把高峰后移
- 收束段自身字数不超过逆转段的 90%

**规则 3：反转/高潮工具的类型多样性。**
- 如果全篇使用了同一种"推进方式"超过 2 次（如"会议/公开场合当众曝光"出现了 >2 次），在第 3 次时必须换成不同机制
- 推进方式分类：当众对质 / 私下摊牌 / 物证发现 / 第三方意外介入 / 角色自身认知变化 / 时间压力
- 适用范围：全篇，从第 1 段到收束段
