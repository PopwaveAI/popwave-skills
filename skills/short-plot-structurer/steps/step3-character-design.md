# Step 3: 角色设计（服务于剧情）
> 剧情弧线确认后，根据剧情需要设计角色。短篇铁律：≤5个有名有姓的角色，每个角色一个功能。

## 3a. 确定角色清单
用表格列出每个角色：

| 角色 | 叙事功能 | 在哪个剧情节点发挥作用 |
|:---|:---|:---|
| 主角 | 推动全篇 | 全程 |
| 配角 A | （对手/镜像/信息源/情感锚/催化剂） | 第X段出场 / 制造关键冲突 |
| … | … | … |

## 3b. 主角四维深度构建
引用 `references/character-card.md` 的四维法。短篇每维度一句话：

- **欲望（Want）**：外在目标。具体、有期限、失败代价可见。对应剧情中的具体事件。
- **软肋（Need）**：内在需求。和欲望有冲突——"想要复仇" vs "需要放下"。
- **执念/创伤（Wound）**：具体的一个过往事件，形成现在的行为模式。在故事结局得到回应。
- **反差（Contrast）**：一个明确的矛盾特质，让读者记住主角。

> 不要在主角人设上铺得太开——短篇空间有限。

## 3c. 配角功能表
引用 `references/character-card.md` 的配角功能分类：

| 功能 | 说明 |
|:---|:---|
| 对手/反派 | 制造核心冲突，必须有可理解的动机（不是纯恶） |
| 镜像/对照 | 和主角处境相似但选择不同，凸显主角的成长 |
| 信息源 | 提供关键线索或背景，不能只出场一次 |
| 情感锚 | 代表主角的"正常世界"或情感归属 |
| 催化剂 | 推动主角做出关键决定 |

> 短篇铁律：功能重复的配角必须合并。

## 3d. 输出角色清单
```
【角色清单】
  【主角】
    外在标签:
    内在反差:
    渴望:
    软肋:
    底线:
    小缺点:
  【配角A】
    角色: 叙事功能 / 出场节点 / 活人标签
  【配角B】
    ……
  （最多4个配角）
```

## 3e. 角色密度合并检查（通用规则）

弧线表确认后、角色设计完成后，逐段做以下检查：

**规则：每段弧线引入的新角色数量与全篇角色总数的比率控制。**
- 统计弧线表中每段"首次出场"的角色数
- 如果某段弧线引入 ≥2 个新角色 → 检查这些角色是否可以在前一段提前出场，或将其中 ≥1 个的功能合并给已有角色
- 全篇有名有姓+有台词的角色总数超过设计上限 → 按以下优先级合并：
  1. 功能重叠的配角优先合并（如两个都是"信息源"的配角）
  2. 只出场 1 次的角色优先合并（让已有角色承担其功能）
  3. 无独立台词的角色优先合并
- 适用范围：从第 1 段到收束段

**合并后验证：**
- 合并后每个角色至少碰撞主角的一个维度（渴望/软肋/底线/内在反差），确保合并不是简单"删掉一个人的台词给另一个人"
- 如果合并导致一个角色同时承担 ≥3 个不同功能 → 保留拆分，功能数 >2 的角色可以例外
