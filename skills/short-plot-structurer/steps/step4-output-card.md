# Step 4: 输出骨架卡片 + 流转上下文
> 汇总前3步产出→填写骨架卡片→生成流转上下文→落盘。模板参照 `templates/skeleton-card.tpl.md`。

## 4a. 输出骨架卡片
```
【骨架卡片】
  【结构模板】
  【总字数】
  【剧情弧线】（Step 2 的完整表格）
  【主角四维】
    外在标签:
    内在反差:
    渴望:
    软肋:
    执念/创伤:
    小缺点:
  【角色清单】（每人：角色/叙事功能/出场节点/活人标签）
  【付费钩子嵌入位置】在弧线的第X段 / 第X字
```

## 4b. 生成流转上下文
```
【流转上下文】
  【选定平台】
  【文章性质】
  【核心约束】
  【脑洞一句话】
  【导语】
  【黄金三句】
  【付费钩子策略】
  【剧情弧线】（完整表格）
  【主角四维】
  【角色清单】
```

## 4c. 完整性自检
| 检查项 | 判定 |
|:--|:--|
| 角色总数 ≤ 5 | ✅/❌ |
| 付费钩子与剧情弧线对齐 | ✅/❌ |
| 总字数在模板范围内 | ✅/❌ |
| 每段情绪走向有起伏 | ✅/❌ |

如有未通过项，返回相应步骤修正后再落盘。

## 4d. 落盘
保存为 `step4-剧情结构.md`。
