# Step 1: 加载草稿 + 确认评审范围
> 从流转上下文加载正文草稿和全部前置卡片，确认评审范围（全篇/指定段/指定维度）。全部前置输入就绪后才进入诊断。

## 1. 提取前置输入
从 body-generator 的流转上下文中提取：
- 正文草稿（完整全文）
- 【选定平台】
- 【文章性质】
- 【核心约束】
- 【脑洞一句话】
- 【导语】
- 【黄金三句】
- 【付费钩子策略】
- 【剧情弧线】（完整表格）
- 【主角五维】
- 【角色清单】

## 2. 加载参考文件
根据上下文加载必要的 references：
- `references/platform-rules.md` — 平台格式要求
- `references/structure-guide.md` — 结构模板对照
- `references/character-card.md` — 人设检查清单
- `references/writing-styles.md` — 文风特征+去AI味儿指南

## 3. 确认评审范围
默认全篇9维诊断。用户可指定：
- 只评审某几个维度（如"只看钩子和节奏"）
- 只看某一段（如"只看付费钩子断点那段"）
- 只看AI味儿

> "默认全篇9维诊断。要限制范围吗？还是直接开始？"
