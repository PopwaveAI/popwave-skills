# Step 4: 文风画像
> 抽取例文的量化文风特征。输出格式贴合 writing-styles.md 中的风格描述格式。正文生成器可直接将此画像作为自定义文风选项。

## 特征抽取维度

| 特征 | 抽取方法 |
|:---|:---|
| 平均句长 | 统计全文字数/句数 |
| 段落长度 | 统计全文字数/段数 |
| 对话占比 | 对话字数/总字数 |
| 描写密度 | 描写段落字数/总字数。高=描写占主导/中=描写与叙事均衡/低=叙事为主 |
| 独有词汇/句式 | 例文中高频出现的特有词汇、句式模式、标点习惯 |
| 情绪表达方式 | 直接陈述 vs 动作替代 vs 对话承载 |

## 输出格式
贴合 `references/writing-styles.md` 中的风格描述格式。标注该文风与5种标准文风的异同点。

> "这篇例文的文风可以概括为：{总结描述}。
> 最接近【{标准文风名称}】，差异主要在{差异点}。
> 正文生成时可以选择'用这篇的文风'作为自定义选项。"
