# short-zhihu-write

> 知乎盐言短篇正文：选文风 → 逐段写 → 九维自检 → 去 AI 味扫描 → 落盘。
> 只读 `short-zhihu-outline` 给的 `短篇/大纲.md`；不改平台、脑洞、导语与付费钩子位置。
> 当前版本 v1.0.0。

## 何时用

用户说「按这个结构写正文」「写正文」「继续写」「审一下」「看看哪里不行」时用它。

不用于：从零定平台、定脑洞、定导语、搭结构；这些回 `short-zhihu-outline`。

## 输入与输出

输入：`短篇/大纲.md`（必需）；用户当次补充（可选）；用户参考文本（可选）。

输出：

- `短篇/正文.md`：完成的短篇正文。
- `短篇/审稿.md`（可选）：用户要审稿时写九维诊断报告。

## 流程

### Step 0 读大纲与确认范围

1. 读 `短篇/大纲.md` 全文，提取平台、篇幅、脑洞一句话、导语、黄金三句、付费钩子策略、剧情弧线、主角四维、角色清单。
2. 没有 `短篇/大纲.md` 时，不硬写：回 `short-zhihu-outline` 补大纲。
3. 读用户当次补充：某段多写什么、某角色多出现一次、某段调整情绪基调；写进本段蓝图。
4. 确认写作范围：默认全篇；用户可指定先写某几段或先出开篇。

### Step 1 选文风

读 `references/writing-styles.md`，展开五种文风：知性沉稳、网感快节奏、情感细腻、文学质感、极速钩子。

- 知乎盐言默认「知性沉稳」。
- 展示推荐文风、三到四条核心特征与一个开头范例，让用户确认或调整。
- 用户上传参考文本时，参考文本优先级最高：提取句长、对话比例、描写密度、特有词汇，以参考文本覆盖默认。

### Step 2 选生成模式

问用户：一段一段确认，还是先出全文？默认逐段确认。

| 模式 | 流程 | 用户可操作 |
|:--|:--|:--|
| 逐段确认（默认） | 每段生成、自检、确认 | 继续 / 这段重写 / 调整某处 |
| 一键全文 | 先生成全文，再逐段自检，最后一次性展示 | 第三段重写 / 收束太弱 / 付费钩子不够狠 |

### Step 3 逐段写正文

按结构卡的弧线表逐段写；每段生成前读本段蓝图。

- 开头标注「第 X 段 / 共 Y 段｜目标 X 字」。
- 持续引用主角四维、配角标签、脑洞一句话、导语、黄金三句，避免跑偏。
- 到付费钩子断点处暂停，标注「←付费钩子」。
- 每段写完自检：
  - 删掉这段是否影响理解？影响即重写。
  - 情绪密度是否达到弧线标注？不达标就在情绪下坡处补一个动作、对话或信息释放。
  - 是否偏离脑洞与导语？
  - 角色行为是否符合底线与标签？
- 逐段模式下等用户确认再写下一段；一键全文模式先生成全文，再按用户点名的段落重写。

### Step 4 付费钩子断点检查

从弧线表提取所有付费钩子段，对照策略检查：

| 检查项 | 标准 | 不通过时 |
|:--|:--|:--|
| 断点位置 | 与策略位置一致，偏差不超过全文 ±3% | 调整段落边界 |
| 断点类型 | 信息缺口 / 情绪最高点 / 决策时刻 / 反转预告，与策略一致 | 调整断点方向或回大纲改策略 |
| 驱动力 | 读者「必须知道后续」 | 补一句反转或暗示，补强悬念 |

断点不落在对话、动作或描写的中间，落在「该说但没说」处。驱动力弱时给用户补强建议，让用户选。

### Step 5 九维自检

用户要审稿，或正文完成后自检时，按九维只诊断、不改稿：

| 维度 | 检查点 |
|:--|:--|
| 钩子密度 | 每段开篇有必须读下去的元素；段尾留悬念、问题或未闭合情绪 |
| 节奏控制 | 信息释放顺序制造悬念；相邻段核心事件不重复 |
| 付费钩子 | 位置、类型、驱动力与策略一致 |
| 角色塑造 | 主角行为符合四维；配角完成叙事功能且有辨识度 |
| 结局收束 | 伏笔回收、情感闭合、字数在平台范围；高峰后不拖沓 |
| 文风适配 | 句长、对话比例、描写密度符合选定文风 |
| 情绪张力 | 情绪密度达到弧线标注；转折有铺垫 |
| 商业驱动 | 能吸引付费；与知乎盐言付费模式适配 |
| AI 味儿 | 单独标注，不纳入评分 |

每维给 X.X/10；低于 7.0 的写具体问题与建议方向。输出格式用 `templates/审稿报告.tpl.md`；用户只要审稿时写 `短篇/审稿.md`。

### Step 6 去 AI 味扫描

读 `references/writing-styles.md` 的去 AI 味清单，逐段扫描七类痕迹：

- 总结感：段末总结句式替读者解读情绪。
- 模板句式：跨作品通用的描写模板。
- 过度过渡：显式连接词替代事件节奏。
- 抽象描写：概括词替代可验证的感官信息。
- AI 式对话：对话完整无歧义、人物说话方式雷同。
- 百科口吻：叙事中途切解释、定义、说明模式。
- 全文总结句：「她终于明白」「他感到」等内心独白标签。

只标注位置、类型与修改方向，不擅自大改；用户确认后再改。全文扫描阈值：

- 内心独白标签每五千字不超过一次。
- 百科解释全文不超过两处。
- 连续三段字数高度一致（±20 字）时，标出并建议打破其中一段。

### Step 7 落盘

- 正文写入 `短篇/正文.md`。
- 审稿报告写入 `短篇/审稿.md`（可选）。
- 交付回复写清文件路径、字数、自检结论与下一步；不复述全文。

## 红线

1. 不改 `短篇/大纲.md` 的平台、脑洞、导语与付费钩子位置；要改回大纲技能。
2. 不跳段、不合并多段；一段写完再写下一段。
3. 付费钩子断点必须与大纲策略对齐，偏差超过 ±3% 要调整。
4. 九维自检只诊断不改稿；用户确认后再改。
5. AI 味儿只作参考，不纳入评分。
6. 不写盗版、洗稿、代写；参考素材只用用户提供或合法来源。
7. 不承诺签约、流量、稿费；只保证按大纲写完、写全。
