# Step 1 · 确认X与改编强度

> 唯一前置步。一次完成：读用户意图 → 确认X → 呈现A/B/C强度 → 冲突拍板。

## 1. 前置门禁（30秒）

1. 确认设定包路径：优先项目 `素材/参考答案-{书名}/`，全局回退 `D:\popwave-skills\knowledge-base\设定包\{书名}\`
2. Read 包 `包配方.md`——**表1·卷幕骨架表**必须存在，缺失=报错中止并提示用 test-research 建包
3. Read 项目 `素材/用户意图.md`——确认X与包路径是否已记录

## 2. 创意X确认

- 用户已给X → 直接用，记录进用户意图
- 未给 → 问用户一句话脑洞（想要的世界/金手指/主角方向，任一维度都行）；用户仍无头绪 → 从包配方表1反推3个候选X（换题材皮换机制，结构不动）列给用户选

## 3. 改编强度选择（必问，禁止默认）

向用户呈现三档并让其选择，附清晰说明：

| 强度 | 改什么 | 保留什么 | 适合场景 |
|:--|:--|:--|:--|
| **A 改演员** | 主角/敌人/盟友/剧情事件/开篇场景 | 世界/地理/势力/力量体系/金手指 | X与包同世界观，只换人换事 |
| **B 改世界观** | A全部 + 地理/势力/世界观/时代引擎 | 力量体系/金手指 | X换了大背景，但力量底层可复用 |
| **C 全改** | B全部 + 力量体系/金手指 | 仅商业架构 | X彻底换机制（如盗贼→心灵系） |

- 用户选A/B/C → 记录进用户意图
- 用户不确定 → 给出推荐：**X与包力量体系机制差异大（如盗贼→心灵异能）时推荐C；只换人物不换世界时推荐A**
- 强度记录格式：`改编强度：{A/B/C}`

## 4. X与包冲突适配（只在有冲突时）

X与包结构参数冲突项（如X要慢热 vs 包蓄力≤2段）逐项列出 → 用户逐项拍板：
- **覆盖包**（用户坚持X）→ 记入偏离声明，下游该参数以X为准
- **改X**（接受包参数）→ 不记偏离

冲突项≤3个直接列清单问一次，不要反复打断。

## 5. 落盘

更新 `素材/用户意图.md`：X原文 + 包路径（含包配方5表确认状态）+ **改编强度** + 覆盖意向。

- [ ] 包配方表1存在（或已提示建包）
- [ ] X已确认（用户给或已选候选）
- [ ] **改编强度A/B/C已由用户选择并记录**
