# Step 2 · 改编计划 + 新立项PRD直写

> 核心执行步。一次完成：读包 → 生成改编计划（DNA替换矩阵+剧情类比切换策略）→ 直写新立项PRD → 验收。

## 1. 前置门禁（30秒）

1. Read 包 `包配方.md` **表1全文**——质量锚参数（四段式/质变点位/卷末三件套/首三章功能位）
2. Read 包 `立项/01-立项PRD.md` **全文**（禁limit截断）——六要素的格式与深度标杆
3. Read `素材/用户意图.md`——X原文 + 改编强度A/B/C + 偏离决策

## 2. 生成改编计划（`素材/改编计划.md`）

按 `templates/素材/改编计划.tpl.md` 落盘，核心是**X DNA替换矩阵**。逐维度对照包PRD，按强度决定改多少：

| 维度 | A（改演员） | B（改世界观） | C（全改） |
|:--|:--|:--|:--|
| 主角 | ✅重写 | ✅重写 | ✅重写 |
| 敌人/盟友 | ✅类比切换 | ✅类比切换 | ✅类比切换 |
| 剧情事件 | ✅类比切换 | ✅类比切换 | ✅类比切换 |
| 开篇场景 | ✅类比切换 | ✅类比切换 | ✅类比切换 |
| 地理/势力/世界观 | ❌保留 | ✅重写 | ✅重写 |
| 力量体系/金手指 | ❌保留 | ❌保留 | ✅重写 |

**DNA替换三问**（每维度必答）：
1. **原包DNA是什么**——包PRD该维度的核心设定（不是名字，是机制/张力/功能）
2. **新DNA是什么**——X替换后的核心设定
3. **怎么换**——保留（原样）/类比切换（同功能位换事件DNA）/重写（从X重新推导）

**剧情类比切换策略**（本步最重，plot据此执行）：
1. **提取原包核心张力**：每卷/幕的冲突模式（如卷一=「小人物在乱世靠信息差求生+初触超凡」），不是具体事件
2. **推导新X核心张力**：X的冲突模式（如心灵窃取=「偷 vs 被偷」——窃取他人心智，却恐惧被夺舍/被看穿）
3. **开篇场景切换**：原开篇 → 新开篇（如「贫民窟崛起」→「夺心魔入侵大事件」，博德之门3式）
4. **每卷功能位 → 新事件DNA**：功能位保留（质变点位/收益管控），事件从新X核心张力+新世界+新角色重推——**禁止把包的事件换名复用**

**X体验层**（防X浮于表面，write/plot据此耦合）：
- **战斗耦合**：X在战斗中的独特表现（如心灵窃取=偷敌人招式/植入假记忆）
- **日常耦合**：X在日常中的表现与代价（如读心带来的社交困境/窃忆的道德代价）
- **剧情耦合**：X与主线的耦合点（如身份危机/被夺舍恐惧）

## 3. 直写新立项PRD（`立项/01-立项PRD.md`）

对照包PRD的六要素结构逐要素填X的内容，深度对齐包PRD（包PRD每要素写到什么颗粒度，本书就写到什么颗粒度）。**强度-aware**：
- 保留维度（A的势力/地理等）→ 从包PRD继承，只做风味微调
- 重写维度 → 从X全新推导，禁止换名复用

**红线自查**：六要素能讲成一个故事（有递进阶梯/爽点落点/追读欲），讲不成=重写经过要素。

## 4. 改编继承表（PRD末尾必附）

```markdown
## 改编继承表（质量锚声明）
> 源：`{包名}`包配方 表1。抄商业架构，不抄皮/机制/人/事件。改编强度：{A/B/C}
| 质量锚参数 | 本书取值 | 状态 |
|:--|:--|:--|
| 四段式大结构（崛起/扩张/双线/登顶） | {本书实际分段} | ✅继承 |
| 质变点位（~10%/40%/70%/100%处） | {本书实际点位} | ✅继承 |
| 卷末收益三件套（面板爆+新地图+下卷钩） | 照搬 | ✅继承 |
| 首三章功能位（金手指→首杀→大时代） | 照搬 | ✅继承 |
| {用户拍板的偏离项} | {X取值} | ⚠️偏离声明：{原因+影响} |
```

## 5. 落盘+验收

1. 按模板落盘 `素材/改编计划.md` + `立项/01-立项PRD.md`
2. 向用户汇报：改编强度 + X DNA替换矩阵速览 + 剧情类比切换策略 + 一句话故事 → 用户确认通过即完成；不满意→只改对应维度，不推翻全盘
