# 《{项目名}》 · 立项 PRD

> 一句话故事：{30-60字讲清主角是谁+靠什么+从哪到哪+终局是什么。外行能听懂，读者能被勾住。}

## 一、世界（含时间·地点·世界类型·世界尺度·风味基调）

- **时间**：{故事发生的时代节点+时代引擎是什么（一场大变局/一次灾变/一个窗口期），它决定全书卷数跨度}
- **地点**：{起点地点→中段扩展方向→终局舞台，用箭头串联，对应卷级地理递进}
- **世界类型**：{世界基本盘类型（西幻/都市/末世/修仙/悬疑等）+核心规则一句话}
- **世界尺度**：{A单世界/B多元位面/C多元宇宙——必须明确，决定篇幅与力量上限}
- **风味基调**：{类型参考系声明：命名风格+器物清单+社会符号。world 据此执行，杜绝类型味漂移}
- **赛道标签**：{从创意X+包立项PRD提炼（如：西幻DND规则·诸神流·重生·智斗经营），供下游识别风味参考系}
- **世界样貌**：{2-3句大时代样貌——谁在掌权、暗流是什么、主角站在哪个位置}
- **增量钩子（3 元素 + 主钩子）**：
  1. **{长线钩子1}**——{埋设方式→兑现节奏→供给多少卷增量}
  2. **{长线钩子2}**——{同上}
  3. **{长线钩子3}**——{同上}
  - **主钩子**：{全书最大悬念/终极方向，书名指向什么}

> 改编标注：本维度改编方式={保留/重写}（来自改编计划）。保留=继承包PRD只做风味微调；重写=从X全新推导。

## 二、力量体系

- **力量源**：{力量从哪来（几层结构）+成神/登顶的燃料是什么}
- **干预方式**：{力量怎么作用于世界（技能/法术/科技/权谋）；主角独有的干预方式是什么}
- **成长阶梯（境界落点 + 节奏方向）**：{大层划分+每层境界序列+全书节奏分配（前期扎实/中期跃迁/后期收束）}
- **代价 / 限制**：{升级/进阶的代价≥3条——没有代价的力量体系撑不起张力}

> 改编标注：本维度改编方式={保留/重写}。A/B强度=保留包力量体系（只换命名风味）；C=从X重写机制。

## 三、人物

- **主角（三定位：身份 / 欲望 / 行动）**：
  - 身份：{开局身份+隐藏身份/金手指来源}
  - 欲望：{初始执念（具体到人/事）→ 欲望半径如何层层放大 → 终点落在哪两个字}
  - 行动：{行为模式标签（谋定而动/杀伐果断/苟住发育等），读者能用一个词记住他}
- **金手指方向（能力类别 + 限制原则 + 代价方向）**：{金手指是什么+不做什么（非生成器原则）+越用越少的红利或越滚越大的风险}
- **关键人物（对手 / 伙伴 / 羁绊）**：
  - 对手：{卷级对手阶梯，至少点出3层递进的敌人}
  - 伙伴：{核心伙伴3-5人，各一句话功能}
  - 羁绊：{情感锚点人物——主角狠辣决策的正当性来源}

> 改编标注：人物全员=重写（所有强度）。敌人/盟友按改编计划「类比切换」——同功能位换事件DNA。

## 四、起因

- **核心矛盾**：{一句话时代矛盾+主角卷入的方式（被动还是主动）}
- **主角为何开始**：{开篇事件给出"不得不动"的理由——生存/守护/复仇，动机必须具体可信}

## 五、经过

- **主线走向（{N}卷）**：卷一 {卷名+一句话功能}（ch跨度）→ 卷二 {…} → … → 卷终 {…}

> 改编标注：剧情=类比切换（所有强度）。功能位/质变点位保留，事件从新X核心张力重推（详见改编计划第三节）。
