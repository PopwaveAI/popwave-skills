# Step 1 · 读改编计划+包直写角色库+金手指

## 1. 前置门禁

1. Read `素材/改编计划.md`——确定**主角/敌人/盟友维度的改编方式**（类比切换）与X DNA替换方向
2. Read `立项/01-立项PRD.md` 人物要素 + 改编继承表偏离项
3. Read 本书 `设计/力量体系.md`（档位表）+ `设计/动力引擎.md`（攀登四群体+非主角路径≥5条）
4. Read 包 `包配方.md` **表5** + 包 `角色库/角色库.md` **全文** + 包 `力量与战斗/金手指.md` **全文**（均禁limit截断；结构变异包路径见包配方「包结构与 test-skill 消费映射」节）

## 2. 改编方式判定（来自改编计划）

| 维度 | 改编方式 | 执行 |
|:--|:--|:--|
| 主角 | 重写 | 从X全新推导（身份/欲望/行动），三定位结构照搬 |
| 敌人/盟友 | 类比切换 | 同功能位换事件DNA——包敌人的功能位（如"卷末BOSS"）保留，人物从X全新推导，禁止换名复用 |
| 配置规格 | 保留 | 规模/梯度/三约束/攀登标注/欲望半径照搬包表5 |

## 3. 先写金手指（主角核心）

按包金手指章节结构直写本书金手指，三约束逐项落实：

| 节 | 照搬包 | 本书原创 |
|:--|:--|:--|
| 一句话定义 | 定义句式（形态+两样核心收益） | 形态完全自创（PRD人物方向句） |
| 机制展开 | 获取方式/运作方式/信息差运作的小节结构 | 具体机制 |
| 赋能范围 | 「当前阶位内变强/更快/更准，不越级」边界 | 具体赋能 |
| 限制与代价 | 4条限制（时效/key非生成器/规则不豁免/密度控制） | 具体限制 |
| 成长路线 | 按力量体系三大层对齐的解锁路线 | 具体路线 |
| 商业逻辑 | 三引擎结构（喂糖×智斗×大事件） | 本书落点 |

> 金手指改编方式：A/B=保留包金手指机制（只换风味）；C=从X重写形态（三约束照搬）。

## 4. 再写角色库（模板：`templates/角色库/角色库.tpl.md`）

按包角色库的分区结构直写，顺序：角色总表 → 全书角色版图 → 主角深度卡 → 分层配角卡。

### 4.1 角色总表（~28人，±20%）

表格列照包：角色名/定位/阵营/攀登方式类型/等级坐标/引入章/最后出场章。
- 攀登方式标4类之一：有资源/没资源/爬到顶/掉下来（从动力引擎四群体映射）
- 等级坐标两端写清（起点档→终点档），对到本书力量体系档位表
- 反派标退场章+退场方式

### 4.2 全书角色版图

- 主角弧线终点：起点阶位→终点阶位+终卷形态+全书级转折点10-12条（带预计卷）
- 核心配角6配置位（照搬配置卡规格）：情感主锚1/女主1/政治联姻线1/盟友暧昧线1/温情符号1/战友牺牲位1——人全换
- 跨卷反派3-5个：全书常驻，各带与主角的冲突轴（按改编计划类比切换）
- 欲望半径：主角执念四段放大（护一人→护一城→护一域→定秩序），每段预计卷

### 4.3 主角深度卡

三定位展开：身份（底层+金手指载体）/欲望（执念起点→终点两字收束）/行动模式（谋定而动·藏九露一或X指定）。金手指与力量体系三大层的解锁路线对齐。

### 4.4 分层配角卡

- 卷一登场配角：每人完整卡（外貌/性格/动机/与主角关系/登场卷/退场章）
- 街头层反派（前10章）→城市层（卷一）→卷末BOSS→跨卷大反派：四层梯度逐层配人（按改编计划类比切换）
- 非主角变强路径≥5条分配给配角/反派（从动力引擎直接取）

### 4.5 情感线节奏（照搬结构）

每条主情感线：信任建立→生死相托→告白/转折→终局团圆，跨卷慢炖；每线1次「代价外显」（具体代价自创）。

## 5. 落盘+一次性自检

1. 落盘 `设计/角色库/角色库.md` + `设计/金手指.md`
2. 对照§3/§4要点打钩一遍：三约束✓/规模✓/四层梯度✓/攀登标注✓/等级坐标挂档位✓/无包人名✓/改编计划类比切换✓。缺项当场补写。
3. 汇报pipeline完成，进入plot。
