# pipeline

> 设定包改编管线总控。v6.2.0：Phase 4/5路由对齐章纲组装层（plot v8.2四步产出章纲，write v7读3章章纲）。pipeline只做路由不干活。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

---

## 做什么

输入：设定包（`KB/设定包/{书名}/`或项目`素材/参考答案-{书名}/`，含包配方5表）+ 用户创意X + **改编强度A/B/C** + 项目名（mode=fresh/import/resume）

输出：标准化目录结构 + `项目总控.html`（唯一状态文件）

**管线一句话**：包配方（商业架构质量锚）× 创意X（DNA替换）× 改编强度A/B/C（改多少）→ 改编计划 → 世界 → 角色 → 剧情 → 正文 → 审核。

---

## 怎么操作（SOP骨架）

1. **Step 0**（导入/续写）→ `steps/step0-import.md`：资产清点→文件归位→调度review重建→落地Phase。用户说"导入/续写"或目录已有文件时触发
2. **Step 1**（初始化）→ `steps/step1.md`：创建目录+生成项目总控.html+包校验+X采集+**改编强度A/B/C选择**
3. **Step 2**（路由循环·每次对话）→ **直接执行本文件下方「路由循环」节**

### 路由循环（每次对话开始时）

1. 第一件事读项目根 `项目总控.html`：mode（fresh/import/resume）+ phase + 各就绪态
2. 对照「Phase路由表」路由到对应Phase执行
3. Phase完成后更新html（phase、updated_at、对应就绪态STATE标记、产出表），向用户一句话汇报（本Phase产出+下一步），用户无异议继续下一Phase

### 主agent执行协议（所有Phase通用）

1. Read 对应skill的 `SKILL.md` + 本Phase涉及的 `steps/*.md` **全文**
2. 提炼红线+操作要点，按skill的SOP执行（消费项目输入文件→生成→落盘）
3. **产出真实性检查**（Phase推进门禁，防空转）：
   - Phase 1→3：改编计划含X DNA替换矩阵+剧情类比切换策略；PRD含六要素+改编继承表（质量锚声明）
   - Phase 3→3.5：力量体系晋阶表有档位+全书设定11文件非空
   - Phase 4→5：卷纲含幕框架5行+核心张力映射表5行；首幕章白描每卡≥150字含对话锚/动作锚+锚点9行；首幕章纲每章叙事原子4-6个+plot锚点区齐全（Step3七查绿灯）
   - 检查不通过=停留当前Phase，向用户报告缺口
4. 更新 项目总控.html，衔接下一Phase

> 禁止派发子agent执行技能生成任务；主agent直接执行全部step。

### Phase 5/6 写审循环

- 每次写1章（write）→ 审1章（review）。review打回→write按打回清单修改→重审
- write向前锚=本章章纲（读3章）；review沉淀白描卡+状态快照后，write续写下一章（消费近5张白描卡+快照+章纲）
- 用户说"继续写/下一步"=推进下一章循环；批量请求>8章拆批
- 本幕章白描写完 → 提示用户：plot按幕产下一幕章白描→Step2.5组装章纲（产前读状态快照吸收正文偏差）再继续写；卷一5幕全完 → plot产卷二卷纲+幕1章白描+章纲（复用同skill流程换卷）

### 异常处理

- **包缺失/配方缺表**：任何Phase发现 → 中断，提示建包或换包（step1 §3）
- **正文已有但无白描卡**（import残留）：调度 test-review step2-reconstruct 重建
- **设计文档缺失**（import残留）：对照Phase就绪检查，缺哪个补跑哪个skill

## 红线

1. **读取协议**：每次对话第一件事读项目总控.html获取当前phase→按路由表调度。禁止跳过读html直接干活。
2. **pipeline只做路由不干活**——所有产出由下游skill生成，不直接写正文/创意/审核。
3. **包准入门禁**：Phase 0必须验证包配方5表齐全，缺表=拒绝启动并提示建包。包缺失/不合格不得凭记忆或通用知识顶替。
4. **改编强度必问**：Phase 0用户输入X后必须呈现A/B/C三档让其选择（A=改演员/B=改世界观/C=全改），禁止默认。强度未定=不进入Phase 1。
5. **主agent直接执行所有step**——执行前Read对应skill的SKILL.md+step文件，禁止派发子agent执行技能生成任务。
