# step1 · 初始化+包校验+X采集

> test-pipeline 初始化执行指令：目录→总控→包校验→创意X采集，一次完成。

## ⚠️ 前置检测：是否走导入/续写模式

执行任何创建前先LS扫描项目目录：
1. `正文/` 有章节文件或 `设计/` 有 .md 文件 → 跳转 `steps/step0-import.md`
2. 目录为空或仅有 `项目总控.html` → 继续本步

## 1. 创建目录结构（一次性）

```powershell
$dirs = @(
  "素材", "素材/downloads", "素材/知识沉淀",
  "设计", "设计/全书设定", "设计/角色库",
  "卷纲",
  "立项",
  "产出", "产出/白描卡",
  "正文", "审核"
)
foreach ($d in $dirs) { New-Item -ItemType Directory -Force -Path $d | Out-Null }
```

创建后LS自检全部存在（缺一=初始化失败补创后才继续）。

## 2. 创建项目总控.html

读 `templates/项目总控.html` 写入项目根，SearchReplace更新：project_name/created_at/updated_at/genre（未指定保留"待指定"）。再简建README.md。

## 3. 包校验（Phase 0门禁，缺表=拒绝启动）

1. **定位包**：用户指定书名 → 先查项目 `素材/参考答案-{书名}/`，无则查全局 `D:\popwave-skills\knowledge-base\设定包\{书名}\`
2. **校验包配方**：Read `{包路径}/包配方.md`，逐项确认5表齐全（卷幕骨架/节奏参数/颗粒度/爽点配方/角色配置）
3. **不合格处理**：缺表/无包 → 提示用户二选一：①用 test-research 建包（需要源书txt）②换一个已建好的包。**禁止凭记忆/通用知识顶替包**
4. **包定位到项目**：全局包 → 提示可复制进项目（或记录全局路径直接消费）；包内有文风锚定类文件则一并登记

## 4. 创意X采集（轻交互，一次问完）

向用户要三样（已给则跳过）：
1. **创意X**：一句话脑洞即可（想要的世界/金手指/主角方向，任一维度都行）
2. **赛道方向**（可省，默认从X推断）
3. **对包参数的覆盖意向**（可省，默认全继承）

## 5. 改编强度选择（必问，禁止默认）

用户输入X后，必须呈现三档让其选择（附清晰说明）：

| 强度 | 改什么 | 保留什么 |
|:--|:--|:--|
| **A 改演员** | 主角/敌人/盟友/剧情事件/开篇场景 | 世界/地理/势力/力量体系/金手指 |
| **B 改世界观** | A全部 + 地理/势力/世界观/时代引擎 | 力量体系/金手指 |
| **C 全改** | B全部 + 力量体系/金手指 | 仅商业架构 |

- 用户不确定 → 推荐：**X与包力量体系机制差异大（如盗贼→心灵异能）时推荐C；只换人物不换世界时推荐A**
- 强度未选 = 不进入Phase 1，先问清楚再推进

落盘 `素材/用户意图.md`：X原文+包路径（含包配方5表确认状态）+**改编强度A/B/C**+覆盖意向。更新总控html：phase=1、genre、素材就绪态、改编强度。
