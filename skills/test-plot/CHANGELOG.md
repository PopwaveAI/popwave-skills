## v8.1.0 | 2026-08-18

### 新增Step3快爽自检门禁（番茄起点同标）

- **根因**：幕白描缺量化出口检查——战斗密度曾按"含战章"粗计（2场/29章），一章多场战斗被漏计导致gap被低估；冲突/成长/钩子无逐幕核查，慢热问题到write/review才暴露
- **六查**：①战斗密度（**按场次计**：独立对手+目的+空间，一章可多场；硬底线1场/5章❌阻断+目标线1场/3章🟡黄灯写显式理由；对照包幕锚×0.8）②冲突覆盖（零冲突章≤10%，禁连续2章）③成长收获（每章爽点锚≥1+3章滑窗≥1成长）④钩子（100%+L级+每幕≥2个L4+）⑤节奏红线（首杀≤ch4/铺垫≤3章爆/禁连续2章同章型）⑥对齐（幕头=卷纲行+角色±1章漂移记录）
- 自检表（场次清单+六查表+判定汇总）追加幕白描尾部；**🟢绿灯才可交付write，❌=修复重跑**
- 战斗字数占比复核（战斗章≥30%/单场≥300字）移交review——plot无字数可查，只保结构密度
- skill.json version 8.0.0→8.1.0

## v8.0.0 | 2026-08-16

### 废除章锚点表，剧情层双层重构

- **根因**：章锚点表（~50字表格行/章）信息量撑不起单章写作，write只能现场编；`read_policy: full-required`全卷耦合浪费上下文；与卷纲是两份独立文档，对应关系靠人肉对齐无结构保证（boss实证：8-15-dnd小说项目）
- **新双层结构**：`卷纲/卷一-卷纲.md`（战略层：卷定位+幕框架5幕+核心张力映射表+分支线+卷末三件套+不能抢的后续收益）+ `卷纲/卷一-幕N-章白描.md`×5（章粒度：幕头决策+逐章白描卡）
- **章白描卡规格**：每章150-250字叙事白描（画面+事件+≥1对话锚/动作锚+情绪转折+钩子落点）+锚点6行（爽点/钩子/POV/X耦合/关键数据）。信息量=旧表格行5-10倍
- **write消费解耦**：read_policy改为3-segments（前1+本章+后1章白描段），不再读全卷
- **step2改为按幕推进**：一次产一幕，推荐"产幕N→write写幕N→产幕N+1"滚动；重产幕前必须Read状态快照吸收正文偏差
- **核心张力映射表**：step1新增——每幕原包张力（提炼成冲突模式一句话）→本书X张力，是step2逐章事件唯一推导源；映射表内禁止出现原包具体事件/台词/道具/人名
- **包章锚点表角色回归**：仅作节奏参数源（章型分布/爆点间隔/区间宽窄）被plot读取，禁止取事件内容；不再是项目侧产出模板
- **新增红线**：白描卡信息量下限（≥150字+对话锚+爽点≥1+X耦合参与动作）／禁止跳章与区间合并
- **删除**：`templates/第一卷剧情/章锚点表.tpl.md`、`steps/step2-anchors.md`；新增 `templates/第一卷剧情/幕N-章白描.tpl.md`、`steps/step2-chapters.md`
- skill.json version 7.0.0→8.0.0
