# plot

输入：

输出：

| 产出文件 | 继承包（商业架构） | 原创层（X替换） |
|:--|:--|:--|
| `设计/主线.md` | 四段式/质变点位/换引擎/三件套 | 每卷具体剧情（X张力重推） |

## 怎么操作（SOP全内联）

### Step 1：主线+卷纲战略层（直写）

产出全书卷级目录+第一卷战略层；章粒度内容全部留给Step 2，本步不写幕内事件。

**前置门禁（4项Read）**：①`素材/改编计划.md`（剧情类比切换策略：原包核心张力→新X核心张力、开篇场景切换、X体验层战斗/日常/剧情耦合）②`立项/01-立项PRD.md`（起因/经过/结果+改编继承表偏离项）③本书`设计/全书设定/危机敌人矛盾.md`（危机链波次）+`各卷切片.md`+`设计/角色库/角色库.md`（跨卷反派+主角弧线转折点）④包`包配方.md`表1+包`剧情库/主线.md`**全文**+包`剧情库/卷纲/卷一-卷纲.md`**全文**（禁limit截断——用于提取幕功能位/质变点/张力，不是抄事件）。

**核心张力替换（本步灵魂）**：对包卷一的每一幕提取**原包核心张力**（冲突模式一句话，非事件），映射**本书X核心张力**，填进卷纲「核心张力映射表」——此表是Step 2逐章白描的唯一事件推导源。示例：原包幕1张力（提炼）"重生者靠信息差在底层求生，面板是外挂也是催命符"→X映射"窃取他人心智获得力量，每偷一分就向'被夺舍'靠近一分——偷 vs 被偷"。**映射表只允许出现冲突模式，不允许出现原包具体事件/台词/道具/人名——出现即污染下游。**

**直写主线**（模板`templates/主线.tpl.md`）：按包主线结构直写全书卷级目录，逐卷一行——卷序+卷名（卷数与四段式归属崛起/扩张/双线/登顶照搬包，卷名原创）/舞台（每卷1新地图解锁节奏照搬，具体地图从新世界推导）/主压力（每卷1主BOSS+主矛盾结构照搬，具体敌人与矛盾从X核心张力重推）/主收益（卷末三件套=面板大爆+新地图+下卷钩结构照搬，具体收益内容原创）/质变点（3-4个落在~10%/40%/70%/100%卷位，具体质变内容从X剧情耦合落地）。主线末尾必带：**中盘换引擎节点**（~60%处世界级事件）+**敌人阶梯总表**（街头层→城市层→卷级BOSS→跨卷大反派3-5个，对齐角色库退场章）+**终局闭环**（最高峰+初心不改收束）。

**直写卷纲·战略层**（模板`templates/第一卷剧情/卷纲.tpl.md`）七板块：卷定位→幕框架（5幕总表：功能位🔒/强度档/幕末质变🔒/幕末钩子）→**核心张力映射表**→分支剧情线（≥6条）→卷末三件套→不能抢的后续收益。幕框架功能位序列继承包商业架构：①压抑蓄力（底层困境+金手指落地+首执念）②首杀立威（首次主动出手+威名/能力外显）③远行/扩张（离开起点+核心配角入场+情感线开启）④信任结盟（队伍成型+中段BOSS+世界观规则揭示）⑤谷底反弹+身份跃迁（永久性重创→新形态觉醒→反杀+三件套）。章号区间本书自定（按事件密度），不逐章复刻包章号。

**落盘+衔接**：`设计/主线.md`+`卷纲/卷一-卷纲.md`，对照表1清单打钩（四段式/质变点位/三件套/换引擎/闭环/张力映射表5行齐）→进入Step 2。

### Step 2：章白描直写（按幕推进）

本步是plot层最重要环节，投入50%注意力——逐章白描=Step2.5章纲组装的施工图，每章一卡150-250字+锚点9行，锚的how层粒度（具体打法/台词/落点）决定章纲方向上限。

**前置门禁**：①`素材/改编计划.md`（X体验层，每章白描的X耦合据此落地）②本书`卷纲/卷一-卷纲.md`（幕框架+核心张力映射表）+`设计/角色库/角色库.md`（登场/退场章+语言指纹）③包`剧情库/卷纲/卷一-幕N-章白描.md`（**本幕对应文件**）——幕头节奏参数=节奏参数源（章配比/高潮位置/密度统计行），逐区间锚点卡=质量锚（感受该幕章粒度的冲突质感与节拍）；一律禁止抄事件④重产幕（非首产）时Read `产出/状态快照.md`——吸收已写正文产生的偏差（新增钩子/数值/关系变化），白描必须与其对齐。

**一次产一幕**，落盘`卷纲/卷一-幕N-章白描.md`，按幕顺序推进；推荐"产幕N→组装幕N→write写幕N→产幕N+1"滚动，让后续幕吸收正文沉淀。

**幕头（决策+定位）**：从卷纲幕框架+包对应幕的节拍参数填：演绎框架/内容引擎/递进范式/章配比/高潮位置/幕定位/敌人耦合/**X张力轴**。

**逐章白描卡**（模板`templates/第一卷剧情/幕N-章白描.tpl.md`，每章一卡，禁止跳章/禁止"ch0003-0005"区间合并），每卡两段：

- **白描段（150-250字，硬性）**——Step2.5组装的全部剧情信息：场景画面（在哪+什么氛围）+事件推进（发生什么）+**至少1个对话锚或动作锚**（关键台词一句/决定性动作一个，how层粒度——具体打法/台词/落点直接可落）+情绪转折（本章内主角/关键角色的弧光位移）+章末钩子落点（最后一句落在哪）。
- **锚点段（9行）**——爽点🔒（公式类型+落点，每章≥1）/章末钩子🔒（L1-5）/POV（含切换+目的）/X耦合（1处，参与动作/对话/决策）/关键数据🔒（面板数值/登场退场/不可逆事实）/出场人物（全部角色，组装人物清单源）/本章线动作（每线"线名：入→出"目标契约）/出章面板（🔒硬锚+可编区间，防章内升级撞车）。

**事件推导源（唯一）**：每章事件从「**幕X张力轴×本章前情×角色库人物动机**」现推。检查法：遮住本书白描，问"这个事件能从X张力+新世界+新角色推出来吗"——推不出=抄的，回炉。禁止原包事件换名复用；原包台词/道具/名场面/外号出现即红线。

**事实性字段校验**：关键数据/出场人物中的年龄、等级术语、人名，产卡前对照`产出/状态快照.md`禁止漂移清单——白描卡写错会经章纲原样传染正文。

**幕内自检（写完一幕数一遍，超差当场改卡，不通过pipeline打回）**：每卡白描段≥150字且含对话锚/动作锚｜章型无连续2章同种、战斗模式无连续3章同种｜每3章至少1个combat_reversal或高强度对抗；前3章完成觉醒+首杀（首幕内）｜爽感公式分布无单一>50%；情感爆点2-3个/卷｜大爽点前有2-3章压力铺垫（谷底反弹标配）｜X耦合按章型全覆盖（本幕战斗章全用X战斗耦合/日常章有X日常耦合/剧情章有X剧情耦合；X只当背景提及=回炉）｜章末钩子分级：每20章L1≥4个｜角色登场/退场章对齐角色库；幕末质变对齐卷纲幕框架｜「不能抢的后续收益」未提前兑现。

**落盘+衔接**：汇报pipeline本幕章白描就绪（章节范围+卡数）→进入Step 2.5组装；组装过密度门禁后交付write；写完本幕正文后回来产下一幕。

### Step 2.5：章纲组装（按幕产出，白描卡×元素卡库→章纲）

白描卡管"写什么"（事件锚），本步管"怎么拼"——把每章白描卡组装成章纲（叙事原子4-6+线账本+plot锚点区）。write的向前锚从本章起=章纲。格式与规则唯一真源：`library/写作素材和技巧/章纲组装协议.md`（必读）。

**前置门禁**：①Read`library/写作素材和技巧/章纲组装协议.md`（章纲格式v3.1+章型统一表+四红线）②Read`library/写作素材和技巧/元素卡库/00-索引.md`（十族54卡选卡入口），按本幕章型清单预判需开的族文件（如战斗章开战斗族/收线族/施压族）③本幕章白描就绪（已过Step2自检）④**线入章状态源**：本幕首章=幕头+`产出/状态快照.md`；其余章=前一章章纲线账本的章末状态⑤事实校验：白描卡锚点中的年龄/等级术语/人名已对照状态快照（Step2已做，此处抽查）。

**拼装五步（逐章执行）**：

1. **读下发**：读本章白描卡+前1章白描卡（衔接）+后1章白描卡（钩子指向）；提取章型/事件锚/锚点9行/线动作目标/出章面板。
2. **选族**：按章型从元素卡库选4-6张卡（参照索引「章内族配方」：纯战斗章=战斗×3+收线；混装章按白描卡事件分布取族）。**开对应族文件读卡的节拍序列**——节拍是必答题。选卡记录进章纲尾部（族名+卡名）。
3. **填槽**：白描卡事件锚入位（每个🔒锚落到具体叙事原子的内部事件串）；plot锚点区=锚点9行**直拷**附章纲尾部（章纲=白描卡超集的保证）；线入章状态从门禁④来源抄录作线账本起点。
4. **现编细节**：锚外全部自由编（人物龙套名/数字/生态/对白），过三道关——**一致**（不与白描卡事实/前情/设定冲突；情报断言带获取渠道——主角怎么知道的）/**审美**（数字>形容词、有因果、能看见、档案配落差、留钩）/**密度**（每原子≥15条料，全章≥40条，量化料≥1/3）。
5. **记账+门禁**：线账本逐线达成白描卡「本章线动作」目标；章尾原子必产生线翻转（章末钩=线状态翻转）；过出口门禁。

**章纲出口门禁（逐章，任一不达标=回炉重组装）**：叙事原子4-6个（超6=渲染会被料拽跑）｜全章料≥40条、量化料≥1/3｜白描卡🔒锚100%落位（章纲尾部附逐锚核对表：锚→所在原子）｜线账本达成「本章线动作」每线目标｜事件串物理闭合：因果链每步物理可执行（谁的手/什么时机/物件从哪来）｜出章面板：🔒硬锚直拷+可编区间标注，不得与后文升级节点撞车｜章型用英文枚举ID（协议§2统一表），禁自造词汇。

**落盘+回炉规则**：每章一文件`卷纲/章纲/ch{NNN}-章纲.md`。全幕组装完→进Step3七查→绿灯交付write（write读章纲3章渲染）。write/review反馈章纲质量问题（锚漏/线断/物理洞）时，回本步重组装该章，禁止write层私自补锚——**锚的修改权在plot层**。

### Step 3：快爽自检（每幕产完强制门禁，七查全绿才交付write）

幕白描+章纲组装完≠能交付write；任何❌=修复后重跑该查，禁止带病进write。适用标准：番茄与起点同标——快爽是通用底线，不因平台放松。

**统计口径（先定口径再计数，防自欺）**——战斗按「场次」计，不按章计：

- 一场=独立对手+独立目的+独立空间。一章含3段小遭遇=3场；一个战役夜多点击杀但同一目的同一战场=1场。
- 「战斗」定义：主角（或其棋盘上的代理人，如借刀/代战）与敌方的对抗性冲突。高烈度智斗（嫁祸/将计就计/反设局）**算冲突不算战斗场次**；旁观无关打斗（主角不在场不参与决策）不计。
- **对照组**：读包对应幕`剧情库/卷纲/卷一-幕N-章白描.md`幕头「密度统计行」（场次/含战章/密度已按场次口径预数，**禁止自数**）。包幕2-4类中后段稀疏幕是时代特征（包自注"新书应压缩+加密"），不作达标线只作参考；达标线一律用下表阈值。

**七查**：

| 查 | 检查项与阈值 |
|:--|:--|
| 查1 战斗密度（场次口径） | 场次密度（场次÷章数）硬底线≥1场/5章（❌阻断）、目标线≥1场/3章（未达记🟡黄灯+显式理由，不阻断）；本书场次≥包幕场次×0.8，低于必须写显式理由；无战间隔≤5章、幕内前10章≤3章；首杀≤ch0004（开局红线）；前10章场次≥2场；每场在白描卡内有≥1句「怎么赢」打法锚——打法必须X化/智斗化，数值对砍=回炉 |
| 查2 冲突覆盖 | 冲突=战斗/智斗/压力对抗/情感对抗任一；零冲突章≤幕章数10%；**连续2章零冲突=❌** |
| 查3 成长收获 | 每章爽点锚≥1（锚点行有公式类型+落点）；任意3章滑动窗口≥1次成长事件（面板/技能/装备/情报/人脉/威名）；成长不得抢卷纲「不能抢的后续收益」 |
| 查4 钩子 | 钩子率100%且每卡带L级标注；每幕≥2个L4+；幕末钩=卷纲幕框架行；大爽点章的后1章须有承接（余波/兑现） |
| 查5 节奏红线 | 铺垫≤3章必爆（查首个爆点位置）；禁连续2章同章型、成对战斗章须注明模式差异（如棋盘旁观vs白刃）；蓄力≤2段/章（查白描卡） |
| 查6 对齐 | 幕头六项=卷纲幕框架对应行；本幕章数=卷纲预算；角色登场/退场对齐角色库（±1章容忍，漂移逐条记录） |
| 查7 章纲密度与事实（Step2.5产出逐章查） | 叙事原子4-6个/章（超6=❌）；全章料≥40条、量化料≥1/3；🔒锚100%入事件串（核对表齐全）；线账本逐线达成+章尾原子有线翻转；事件串物理闭合（抽2原子复演：谁的手/什么时机/物件从哪来）；出章面板🔒硬锚+可编区间齐全、不与后文升级撞车；章纲年龄/等级术语/人名vs状态快照禁止漂移清单零冲突；章型ID英文枚举统一表口径，禁自造词汇 |

**输出格式（追加到幕白描文件尾部，替换旧"自检记录"节）**：

## 红线

1. **改编计划是剧情改编指令源**：动笔前必须Read `素材/改编计划.md`（原包张力→X张力、X体验层）。缺=禁止动笔。
2. **事件零照搬（张力替换）**：每章事件从「幕X张力轴×前情×角色动机」现推——包名场面/台词/道具/外号出现即换皮书，回炉。遮住本书白描问"能从X+新世界+新角色推出来吗"，推不出=抄的。
3. **白描卡信息量下限**：每卡≥150字+≥1对话锚/动作锚+每章爽点≥1+X耦合1处参与动作/对话/决策。写梗概一句话=回炉。
4. **禁止跳章/区间合并**：每章一卡。"ch0003-0005"式合并段=回炉。
5. **产出门禁**：卷纲标「不能抢的后续收益」；每幕白描必须过Step3快爽自检（战斗场次密度+冲突+成长+钩子量化绿灯），未过=回炉禁止交付write；重产幕白描前必须读状态快照吸收正文偏差。
6. **章纲密度与事实门禁（Step2.5）**：全章料≥40条/量化≥1/3/白描卡🔒锚100%落位/事件串物理闭合/出章面板锁定——任一不达标=回炉重组装，禁止带病交付write；章纲事实性字段（年龄/等级术语/人名）与状态快照冲突时以状态快照为准。
