# Step 1 · 主线+卷纲（战略层）直写

> 产出全书卷级目录+第一卷战略层。章粒度内容全部留给Step 2（章白描），本步不写幕内事件。

## 1. 前置门禁

1. Read `素材/改编计划.md`——**剧情类比切换策略**（原包核心张力→新X核心张力、开篇场景切换、X体验层战斗/日常/剧情耦合）
2. Read `立项/01-立项PRD.md`（起因/经过/结果+改编继承表偏离项）
3. Read 本书 `设计/全书设定/危机敌人矛盾.md`（危机链波次）+ `各卷切片.md` + `设计/角色库/角色库.md`（跨卷反派+主角弧线转折点）
4. Read 包 `包配方.md` 表1 + 包 `剧情库/主线.md` **全文** + 包 `剧情库/卷纲/卷一-卷纲.md` **全文**（禁limit截断——用于提取幕功能位/质变点/张力，不是抄事件。旧`卷一-幕纲.md`已废弃，禁止读取）

## 2. 核心张力替换（本步灵魂）

对包卷一的每一幕，提取**原包核心张力**（冲突模式一句话，非事件），映射**本书X核心张力**，填进卷纲「核心张力映射表」。此表是Step 2逐章白描的唯一事件推导源：

- 原包幕1张力示例（提炼）："重生者靠信息差在底层求生，面板是外挂也是催命符"
- X映射示例："窃取他人心智获得力量，每偷一分就向'被夺舍'靠近一分——偷 vs 被偷"

**红线**：映射表只允许出现冲突模式，不允许出现原包具体事件/台词/道具/人名——出现即污染下游。

## 3. 直写主线（模板：`templates/主线.tpl.md`）

按包主线结构直写全书卷级目录，逐卷一行：

| 列 | 照搬包 | 本书原创（X替换） |
|:--|:--|:--|
| 卷序+卷名 | 卷数与四段式归属（崛起/扩张/双线/登顶） | 卷名 |
| 舞台 | 每卷1新地图/猎场解锁节奏 | 具体地图（从新世界推导） |
| 主压力 | 每卷1主猎物（BOSS）+主矛盾 | 具体敌人与矛盾（从X核心张力重推） |
| 主收益 | 卷末三件套（面板大爆+新地图+下卷钩） | 具体收益内容 |
| 质变点 | 3-4个质变点落在~10%/40%/70%/100%卷位 | 具体质变内容（从X剧情耦合落地） |

主线末尾必带：**中盘换引擎节点**（~60%处世界级事件）+ **敌人阶梯总表**（街头层→城市层→卷级BOSS→跨卷大反派3-5个，对齐角色库退场章）+ **终局闭环**（最高峰+初心不改收束）。

## 4. 直写卷纲·战略层（模板：`templates/第一卷剧情/卷纲.tpl.md`）

七个板块：卷定位→幕框架（5幕总表：功能位🔒/强度档/幕末质变🔒/幕末钩子）→**核心张力映射表**→分支剧情线（≥6条）→卷末三件套→不能抢的后续收益。

幕框架功能位序列继承包商业架构：
1. **压抑蓄力**（底层困境+金手指落地+首执念）
2. **首杀立威**（首次主动出手+威名/能力外显）
3. **远行/扩张**（离开起点+核心配角入场+情感线开启）
4. **信任结盟**（队伍成型+中段BOSS+世界观规则揭示）
5. **谷底反弹+身份跃迁**（永久性重创→新形态觉醒→反杀+三件套）

章号区间本书自定（按事件密度），不逐章复刻包章号。

## 5. 落盘+衔接

落盘 `设计/主线.md` + `卷纲/卷一-卷纲.md`，对照表1清单打钩（四段式/质变点位/三件套/换引擎/闭环/张力映射表5行齐）。完成进入 Step 2（逐章白描）。
