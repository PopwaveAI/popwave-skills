# Step 2 · 章白描直写（按幕推进）

> 本步是plot层最重要环节，投入50%注意力。逐章白描=Step2.5章纲组装的施工图，每章一卡150-250字+锚点9行，锚的how层粒度（具体打法/台词/落点）决定章纲方向上限。

## 1. 前置门禁

1. Read `素材/改编计划.md`——X体验层（战斗/日常/剧情耦合），每章白描的X耦合据此落地
2. Read 本书 `卷纲/卷一-卷纲.md`（刚写好的战略层：幕框架+核心张力映射表）+ `设计/角色库/角色库.md`（登场/退场章+语言指纹）
3. Read 包 `剧情库/卷纲/卷一-幕N-章白描.md`（**本幕对应文件**）——幕头节奏参数=节奏参数源（章配比/高潮位置/密度统计行），逐区间锚点卡=质量锚（感受该幕章粒度的冲突质感与节拍）；一律禁止抄事件
4. 重产幕（非首产）时：Read `产出/状态快照.md`——吸收已写正文产生的偏差（新增钩子/数值/关系变化），白描必须与其对齐

## 2. 逐章白描（模板：`templates/第一卷剧情/幕N-章白描.tpl.md`）

**一次产一幕**，落盘 `卷纲/卷一-幕N-章白描.md`。按幕顺序推进；推荐"产幕N→Step2.5组装幕N→write写幕N→产幕N+1"滚动，让后续幕吸收正文沉淀。

### 2a. 幕头（决策+定位）

从卷纲幕框架+包对应幕的节拍参数填：演绎框架/内容引擎/递进范式/章配比/高潮位置/幕定位/敌人耦合/**X张力轴**。

### 2b. 逐章白描卡（每章一卡，禁止跳章/禁止"ch0003-0005"区间合并）

每卡两段：

**白描段（150-250字，硬性）**——Step2.5组装的全部剧情信息：
- 场景画面（在哪+什么氛围）+事件推进（发生什么）
- **至少1个对话锚或动作锚**（关键台词一句/决定性动作一个，how层粒度——具体打法/台词/落点直接可落）
- 情绪转折（本章内主角/关键角色的弧光位移）
- 章末钩子落点（最后一句落在哪)

**锚点段（9行）**——爽点🔒（公式类型+落点，每章≥1）/章末钩子🔒（L1-5）/POV（含切换+目的）/X耦合（1处，参与动作/对话/决策）/关键数据🔒（面板数值/登场退场/不可逆事实）/出场人物（全部角色，组装人物清单源）/本章线动作（每线"线名：入→出"目标契约）/出章面板（🔒硬锚+可编区间，防章内升级撞车）

**事实性字段校验**：关键数据/出场人物中的年龄、等级术语、人名，产卡前对照 `产出/状态快照.md` 禁止漂移清单——白描卡写错会经章纲原样传染正文。

### 2c. 事件推导源（唯一）

每章事件从「**幕X张力轴 × 本章前情 × 角色库人物动机**」现推。检查法：遮住本书白描，问"这个事件能从X张力+新世界+新角色推出来吗"——推不出=抄的，回炉。

**禁止**：原包事件换名复用；原包台词/道具/名场面/外号出现即红线。

## 3. 自检（一次性，不循环）

写完一幕数一遍：
- [ ] 每卡白描段≥150字且含对话锚/动作锚
- [ ] 章型无连续2章同种；战斗模式无连续3章同种
- [ ] 每3章至少1个combat_reversal或高强度对抗；前3章完成觉醒+首杀（首幕内）
- [ ] 爽感公式分布无单一>50%；情感爆点2-3个/卷
- [ ] 大爽点前有2-3章压力铺垫（谷底反弹标配）
- [ ] X耦合：本幕战斗章全用X战斗耦合、日常章有X日常耦合、剧情章有X剧情耦合；X只当背景提及=回炉
- [ ] 章末钩子分级：每20章L1≥4个
- [ ] 角色登场/退场章对齐角色库；幕末质变对齐卷纲幕框架
- [ ] 「不能抢的后续收益」未提前兑现

超差当场改卡，不通过pipeline打回。

## 4. 落盘+衔接

落盘 `卷纲/卷一-幕N-章白描.md`。汇报pipeline：本幕章白描就绪（章节范围+卡数），进入**Step2.5章纲组装**（`steps/step2_5-assemble.md`）。组装过密度门禁后交付write；写完本幕正文后回来产下一幕。
