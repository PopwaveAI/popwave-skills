# Step 2.5 · 章纲组装（按幕产出，白描卡×元素卡库→章纲）

> 白描卡管"写什么"（事件锚），本步管"怎么拼"——把每章白描卡组装成章纲（叙事原子4-6+线账本+plot锚点区）。write的向前锚从本章起=章纲。
> 格式与规则唯一真源：`library/写作素材和技巧/章纲组装协议.md`（Step2.5必读）。

## 1. 前置门禁

1. Read `library/写作素材和技巧/章纲组装协议.md`——章纲格式v3.1+章型统一表+四红线
2. Read `library/写作素材和技巧/元素卡库/00-索引.md`——十族54卡选卡入口；按本幕章型清单预判需开的族文件（如战斗章开战斗族/收线族/施压族）
3. 本幕章白描就绪（`卷纲/卷一-幕N-章白描.md` 已过Step2自检）
4. **线入章状态源**：本幕首章=幕头+`产出/状态快照.md`；其余章=前一章章纲线账本的章末状态
5. 事实校验：白描卡锚点中的年龄/等级术语/人名已对照状态快照（Step2已做，此处抽查）

## 2. 拼装五步（逐章执行，协议§3展开）

### 步1 读下发
读本章白描卡+前1章白描卡（衔接）+后1章白描卡（钩子指向）；提取：章型/事件锚/锚点9行/线动作目标/出章面板。

### 步2 选族
按章型从元素卡库选4-6张卡（参照索引「章内族配方」：纯战斗章=战斗×3+收线；混装章按白描卡事件分布取族）。**开对应族文件读卡的节拍序列**——节拍是必答题。选卡记录进章纲尾部（族名+卡名）。

### 步3 填槽
- 白描卡事件锚入位：每个🔒锚落到具体叙事原子的内部事件串
- plot锚点区：锚点9行**直拷**附章纲尾部（章纲=白描卡超集的保证）
- 线入章状态：从步1门禁4的来源抄录，作线账本起点

### 步4 现编细节
锚外全部自由编（人物龙套名/数字/生态/对白），过三道关（协议§4）：
- 一致：不与白描卡事实/前情/设定冲突；**情报断言带获取渠道**（主角怎么知道的）
- 审美：数字>形容词、有因果、能看见、档案配落差、留钩
- 密度：每原子≥15条料，全章≥40条，量化料≥1/3

### 步5 记账+门禁
线账本逐线达成白描卡「本章线动作」目标；章尾原子必产生线翻转（章末钩=线状态翻转）；过§3门禁。

## 3. 章纲出口门禁（逐章，任一不达标=回炉重组装）

- [ ] 叙事原子4-6个（超6=渲染会被料拽跑）
- [ ] 全章料≥40条，量化料≥1/3
- [ ] 白描卡🔒锚100%落位（章纲尾部附逐锚核对表：锚→所在原子）
- [ ] 线账本达成「本章线动作」每线目标
- [ ] 事件串物理闭合：因果链每步物理可执行（谁的手/什么时机/物件从哪来）
- [ ] 出章面板：🔒硬锚直拷+可编区间标注；不得与后文升级节点撞车
- [ ] 章型用英文枚举ID（协议§2统一表），禁自造词汇

## 4. 落盘+衔接

每章一文件：`卷纲/章纲/ch{NNN}-章纲.md`。全幕组装完→进Step3快爽自检（七查）→绿灯交付write（write读章纲3章渲染）。

**回炉规则**：write/review反馈章纲质量问题时（锚漏/线断/物理洞），回本步重组装该章，禁止write层私自补锚——锚的修改权在plot层。
