## 全书卷级目录
> 广度先行·圈定每卷目的地。每卷只给战略（一句话定位+主压力+主收益+卷末爽点+不抢后续收益），不写幕/章细节。

| 卷 | 卷定位（一句话） | 主压力 | 主收益 | 卷末爽点 | 不抢的后续收益 |
|----|----------------|--------|--------|---------|--------------|
| 卷1 | {阶段X·主角到这格} | {本卷核心压力} | {能力/资源/关系/地位} | {卷末爆发感} | {忍住不兑现的后续爽点} |
| 卷2 | ... | | | | |

> - **卷定位**：本卷主角到了扩张阶梯哪一格、解决了什么（映射阶段推进链）
> - **主压力**：本卷主角面对的核心压力（对应本卷爆发的阶段性危机）
> - **主收益**：本卷主角获得什么（能力/资源/关系/地位）
> - **卷末爽点**：本卷收尾的爆发感（读者期待兑现）
> - **不抢的后续收益**：本卷必须忍住不兑现的后续高潮爽点（防前置卷透支）——只标不展开，后卷兑现
