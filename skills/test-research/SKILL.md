# research

> 设定包构建器。v6.0.0：steps 两件全合入单文件精炼（DL0-DL5拆解转写流程+五表蒸馏流程内联）。一本已验证成功书 → 设定包全套文件 + 包配方（硬对齐层唯一真源）。建一次，全管线消费。完整版本历史见 [CHANGELOG.md](CHANGELOG.md)。

---

## 做什么

输入：成功书书名（起点月票榜/番茄完结爆款级）+ 原文txt（`素材/downloads/{书名}.txt`，无则先用 tool-download-webnovel 下载）

输出：

| 产出 | 路径 | consumer |
|:--|:--|:--|
| 拆解底稿（9表） | `素材/decon-lite-{书名}.md` | 建包中间产物 |
| 设定包全套（28文件） | `KB/设定包/{书名}/`（立项1+赛道特色1+力量与战斗8[3+战斗表现5]+世界观8+角色库1+剧情库9[主线/动力引擎/各卷切片+卷纲6]，按需复制进项目`素材/参考答案-{书名}/`） | adapt/world/character/plot/write |
| 包配方（5张参数表） | `KB/设定包/{书名}/包配方.md` | 全管线硬对齐层 |

**执行模式**：拆书分析（DL0验证+DL2九表拆解）可派子agent执行并回报结果（只读原文采样+分析）；DL5转写、Step 2蒸馏、落盘归主agent；采样范围确认等轻交互主agent直执。

---

## 怎么操作（SOP全内联）

### Step 1：拆解+转写

**DL0 原文存在性验证（前置门禁）**：检查`素材/downloads/{书名}.txt`存在（或用户指定路径），读取前100行确认是实际正文非错误页面；都不存在=**报错中止**："参考书txt未找到，无法执行decon-lite拆书。请先通过tool-download-webnovel下载，或手动提供txt文件路径。"验证通过后在产出元数据记录：采样源文件路径+文件大小+验证时间。**禁止基于记忆/书评/评论/公开数据重构内容，禁止跳过DL0直接进DL1。**

**DL1 接收需求**：必读输入=书名+本地txt路径+采样范围（默认前300章，用户可指定）+本项目赛道方向（`素材/用户意图.md`，判断可迁移方向）。采样策略：开篇前10章（服务表5）+中段间隔章（服务表2/3）+关键高潮点（从目录章节标题判断）；用户给了范围按用户指定；采样声明必须落到产出元数据。

**DL2 九表拆解**（9张表必须全拆，表1/表9是硬约束）：

| 表 | 执行要点 |
|:--|:--|
| 表1 力量体系结构（**规则级深度**） | 先识别类型（等级制/修炼境/规则系/百分比/职业树…）→主养成线≥4阶（每阶标注章节范围+质变标志）→先识别子养成线**数量**再逐条拆规则（数量不固定勿预设"4条"；每条规则字段由其性质决定拆什么）→每条标注原文chXX出处→交叉规则（兼职惩罚/制约/增益）→升级触发/强度膨胀/破局手段演变/设计亮点。陷阱：只列阶位骨架=描述级不合格 |
| 表2 剧情节奏 | 爽点间隔必须有具体章数（不是"快/慢"） |
| 表3 情绪弧线 | 每10章标注情绪高点位置 |
| 表4 人称与视角 | 视角策略+切换规律 |
| 表5 开篇解剖 | 第1章第1句必须有**原句摘录**（不仅分析） |
| 表6 势力格局 | 先识别分层结构（层数由书决定）→每层具名势力+主角关系 |
| 表7 金手指深度 | 机制/限制/代价/成长路径四项齐全+与主养成线耦合（金手指加速哪条线） |
| 表8 世界危机引擎 | 分层结构（层数由书决定）+终极危机1-2句概括+驱动机制 |
| 表9 动力引擎提取（**三组成齐全**） | 驱动逻辑（世界级驱动力非个人动机，标注覆盖范围+chXX）/运转机制（输入→转化→输出→反馈闭环+加速器+减速器+自洽性）/代价结构（代价清单+主要代价，是否真实可感）+范式归类+引擎与力量体系关系（骨架本身/外挂/平行）+三组成合一性+辨识度评估 |

范式判据（24本男频验证）：飞轮型=正反馈闭环+外部输入维持（29.2%）｜探索型=靠发现新区域/新规则驱动（29.2%）｜混合型=两种以上范式叠加（25%）｜压迫型=外部压力+倒计时驱动（12.5%）｜对抗型=靠与同位竞争者博弈驱动（4.2%）。

**DL3 质量门禁**（落盘前逐项检查，不合格补拆后才能进DL4）：

| 检查项 | 合格标准 |
|:--|:--|
| 9张表全部完整 | 每张表字段齐全不缺项 |
| 表1规则级深度 | 主养成线≥4阶+子养成线≥2条（每条有规则+chXX出处）+交叉规则有 |
| 表6势力格局 | ≥2层具名势力+层间矛盾有 |
| 表7金手指深度 | 四项齐全+与主养成线耦合关系明确 |
| 表8世界危机引擎 | ≥2层危机+终极危机明确+驱动机制有 |
| 表9动力引擎 | 三组成齐全+范式归类有+合一性评估有 |
| 爽点间隔有章数 | 不是"快/慢" |
| 开篇第1句有原文摘录 | 有原句非仅分析 |
| 采样范围已声明 | "基于前N章采样" |

**DL4 存盘+返回**：底稿落盘`素材/decon-lite-{书名}.md`（元数据块：采样源文件+文件大小+验证时间+采样范围+本项目赛道；9表各一节）。返回：skill名+书名+采样范围+落盘路径（底稿+包目录）+9表完整性摘要（表1主养成线X阶+子养成线Y条/表6层数/表9范式归类+三组成齐全）+下一步（Step 2蒸馏包配方）。

**DL5 转写设定包**（9表全拆且DL3绿灯后执行）：把拆解底稿按消费端格式转写为包文件，全部落`KB/设定包/{书名}/`七文件夹（转写时可按需复制各skill的templates作格式锚）：

| 包文件 | 转写源 | 要点 |
|:--|:--|:--|
| `立项/01-立项PRD.md` | 表5/7/8/9 | 六要素+赛道标签+增量钩子，一句话故事开头 |
| `赛道特色/类型风味基线.md` | 采样 | 命名/器物/社会符号三参考系（按源书实际符号全量提炼，下游只学格式不学词） |
| `力量与战斗/力量体系.md` | 表1 | 四层结构：源力量/主养成线晋阶表/子养成线/交叉规则 |
| `力量与战斗/战斗系统.md` | 表1+采样 | 4拍节奏+碾压限制约束+分阶战斗形态+资源代价体系（世界级规则） |
| `力量与战斗/金手指.md` | 表7 | 机制/赋能/限制/成长路线/商业逻辑 |
| `力量与战斗/战斗表现/`5件 | 表1/2+采样 | 通用层（六要素+战前规划卡+红线，跨职业）+凡人期/超凡期/神明级（按主角等级段，模式层）+特殊条件战（盲战/追击/围攻等叠加件）；每件头部极简+互指消费顺序 |
| `世界观/`8文件 | 表1/6/8+采样 | 物理规则/政治经济/民风民俗/地理建筑/势力人物/危机敌人矛盾/世界规则表/世界设计原则 |
| `角色库/角色库.md` | 表6+采样 | 角色总表（含退场章）/全书版图/主角弧线/配角卡 |
| `剧情库/主线.md` | 表1/6+采样 | 阶段推进链+敌人阶梯+因果链+跨卷伏笔+卷级目录 |
| `剧情库/动力引擎.md` | 表9 | 六组成：驱动/运转/攀登分层/代价/范式/演化节点 |
| `剧情库/各卷切片.md` | 表1/2+采样 | 每卷一段：舞台/主压力/主收益/新解锁 |
| `剧情库/卷纲/卷一-卷纲.md` | 表2/3+采样 | **战略层**：卷定位+幕框架5幕（功能位/主压力/主收益/不能抢的后续收益/张力/敌人耦合/章配比）+章节流指针指向幕白描。格式锚：test-plot `templates/第一卷剧情/卷纲.tpl.md` |
| `剧情库/卷纲/卷一-幕N-章白描.md`×5 | 表2/3+采样 | **章粒度**：幕头节奏参数+快爽密度统计行（战斗场次/含战章/密度；场次口径=独立对手+目的+空间，一章多场分别计；中后段稀疏幕加注时代特征警示）+逐区间锚点卡（章型/事件锚带chXX/爽感节点/章末钩子/主角变化）。格式锚：test-plot `templates/第一卷剧情/幕N-章白描.tpl.md` |
| `补充参考/`（按需） | — | 附加参考件（文风锚定/名词表等），默认不产出 |

> ⚠️ 废弃项：旧`设计/`三层结构与旧`卷纲/卷一-幕纲.md`/`章锚点表-卷一.md`格式不再产出（新标准=七文件夹+卷纲战略层+幕N-章白描）。

**转写铁律**：①全部实证带源章号（chXXX），推断处标「依据拆解推断」、源未覆盖处标「源未覆盖」 ②采样只覆盖前300章时，后半书内容标「基于目录/拆解推断」——配方蒸馏时此类参数降权 ③类型风味基线按源书实际命名/器物/社会符号全量提炼（下游只学格式不学词） ④**单文件≤15KB**：超限按「消费者×加载时机」拆分（战斗表现40KB单件拆5件即范例）——包=skill原则，防agent单次加载过载。

### Step 2：蒸馏包配方（5张参数表）

输入=Step 1产出的`KB/设定包/{书名}/`全套包文件（不回原文）；输出=`KB/设定包/{书名}/包配方.md`——全管线硬对齐层唯一真源；金标准=`templates/金标准-包配方.md`（=深渊主宰包配方本地副本，5表结构照抄，参数换源书）。

| 表 | 数据源 | 提炼要点 |
|:--|:--|:--|
| 表1 卷幕骨架 | 剧情库/主线+剧情库/卷纲/卷一-卷纲（战略层） | 全书规模（卷×章）/四段式大结构分段/卷一幕功能位序列/质变点位分布（卷位百分比）/卷末收益标配/每卷主猎物排期/中盘换引擎节点/终局闭环。每参数一行：取值+仿写规则 |
| 表2 节奏参数 | 剧情库/卷纲/幕白描（幕头节奏参数+密度统计行+区间卡粒度）+剧情库/动力引擎 | 全部数值化：爽点密度（爽点/章）/章末钩子率+L1-L5分级体系/区间锚点粒度规律（爆点细/过渡宽）/6章型枚举/蓄力段上限/大爽点前置压力章数/卷内情感峰值数/首三章功能位/每幕战斗场次密度（场次口径） |
| 表3 颗粒度参数 | 力量与战斗/力量体系+剧情库/动力引擎 | 主养成线三层结构（阶数+档数+质变点数）/升级代价曲线（指数比+顶级数值锚）/敌分级量化体系/数值锚密度（经济锚N/卷+面板爆N/卷）/子养成线条数+涌现机制/交叉规则条数+四关系/进阶仪式+花费/双线机制 |
| 表4 爽点配方 | 剧情库/卷纲/幕白描爽感公式节+剧情库/动力引擎范式 | 9类爽感公式+全书配比百分比+三引擎结构（喂糖×智斗×大事件）+谷底反弹标配模式 |
| 表5 角色配置 | 角色库/角色库+力量与战斗/金手指 | 总表规模/核心配角配置位清单/反派梯度层数+各层退场节奏/主角三定位/金手指三约束/欲望半径段数/攀登方式标注体系/非主角变强路径条数/情感线节奏结构 |

末尾两节：**硬对齐达标线**（adapt/world/character/plot/write/review各消费哪几张表+达标判定，照金标准格式）+**包准入标准**（来源书级别要求+5表齐全判定）。

**Step 2质量门禁**（落盘前一次过）：5表齐全（缺任一表=包不合格，禁止落盘）｜参数数值化（节奏/颗粒度表全部带数字，禁"快/慢/多"模糊词）｜推断降权（源于「依据拆解推断/源未覆盖」的参数表内标⚠️）｜仿写规则列（每行都有"抄什么/换什么"，可直接被下游消费）｜金标准结构（与深渊主宰包配方同构，表名/列名一致）。

落盘后返回：包配方路径+5表参数速览，建包完成。

## 红线

1. **原文存在性门禁**：采样前必须验证txt存在且非空，不存在=报错中止，禁止凭记忆/书评重构。
2. **9表全拆**：表1力量体系必须规则级深度（主养成线≥4阶+子养成线≥2条+chXX出处），表9三组成齐全。
3. **转写带源章号**：包文件全部实证标chXXX，推断处标「依据拆解推断」，禁止无据断言。
4. **5表齐全才准入**：包配方缺任一表=包不合格，管线拒绝启动。
