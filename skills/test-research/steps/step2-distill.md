# Step 2 · 蒸馏包配方（5张参数表）

> 输入：step1-decon 产出的 `KB/设定包/{书名}/` 全套包文件。不需要回原文。
> 输出：`KB/设定包/{书名}/包配方.md`——全管线硬对齐层唯一真源。
> 金标准：`KB/设定包/深渊主宰/包配方.md`（5表结构照抄，参数换源书）。

## 蒸馏流程（一次过）

### 1. 表1 · 卷幕骨架表 ← 剧情库/主线.md + 剧情库/卷纲/卷一-卷纲.md（战略层）

提炼：全书规模（卷×章）/四段式大结构分段/卷一幕功能位序列/质变点位分布（卷位百分比）/卷末收益标配/每卷主猎物排期/中盘换引擎节点/终局闭环。每参数一行：取值+仿写规则。

### 2. 表2 · 节奏参数表 ← 剧情库/卷纲/卷一-幕N-章白描.md（幕头节奏参数+密度统计行+区间卡粒度）+ 剧情库/动力引擎

提炼（全部数值化）：爽点密度（爽点/章）/章末钩子率+L1-L5分级体系/区间锚点粒度规律（爆点细/过渡宽）/6章型枚举/蓄力段上限/大爽点前置压力章数/卷内情感峰值数/首三章功能位/每幕战斗场次密度（场次口径）。

### 3. 表3 · 颗粒度参数表 ← 力量与战斗/力量体系 + 剧情库/动力引擎

提炼：主养成线三层结构（阶数+档数+质变点数）/升级代价曲线（指数比+顶级数值锚）/敌分级量化体系/数值锚密度（经济锚N/卷+面板爆N/卷）/子养成线条数+涌现机制/交叉规则条数+四关系/进阶仪式+花费/双线机制。

### 4. 表4 · 爽点配方表 ← 剧情库/卷纲/幕白描爽感公式节 + 剧情库/动力引擎范式

提炼：9类爽感公式+全书配比百分比+三引擎结构（喂糖×智斗×大事件）+谷底反弹标配模式。

### 5. 表5 · 角色配置表 ← 角色库/角色库 + 力量与战斗/金手指

提炼：总表规模/核心配角配置位清单/反派梯度层数+各层退场节奏/主角三定位/金手指三约束/欲望半径段数/攀登方式标注体系/非主角变强路径条数/情感线节奏结构。

### 6. 末尾两节

- **硬对齐达标线**：seed/world/character/plot/write/review 各消费哪几张表+达标判定（照金标准格式）
- **包准入标准**：来源书级别要求+5表齐全判定

## 质量门禁（落盘前一次过）

| 检查 | 合格标准 |
|:--|:--|
| 5表齐全 | 缺任一表=包不合格，禁止落盘 |
| 参数数值化 | 节奏/颗粒度表全部带数字，禁止"快/慢/多"模糊词 |
| 推断降权 | 源于「依据拆解推断/源未覆盖」的参数在表内标注⚠️ |
| 仿写规则列 | 每行都有"仿写规则"列（抄什么/换什么），可直接被下游消费 |
| 金标准结构 | 与深渊主宰包配方同构（表名/列名一致） |

落盘后返回：`KB/设定包/{书名}/包配方.md` 路径+5表参数速览。建包完成。
