# Step 1 · 一次过三审

> 输入：`正文/ch{NNN}.txt`、`卷纲/卷一-幕N-章白描.md` 本章白描卡、`产出/状态快照.md`、包`包配方.md`（硬对齐达标线节+表2/表4）、`素材/改编计划.md`（X体验层）。

## 第0审 · 配方符合性（不达标直接打回，后续审不做）

对照本章白描卡+包配方逐项打钩：

| 检查项 | 达标线 |
|:--|:--|
| 白描卡兑现 | 白描段（场景/事件/对话锚/动作锚/情绪转折/钩子落点）+锚点（爽点/POV/X耦合/关键数据🔒）全兑现，缺任一=打回 |
| 爽点密度 | ≥0.9/章（本章锚点标注的爽感公式必须落地且有爆发感） |
| 章末钩子 | 100%有钩+分级标注正确（L1-L5） |
| 节奏物理量 | 蓄力≤2段、大爽点前有压力铺垫、事件密度达标 |
| 偏离项 | PRD配方继承表标⚠️的参数按X取值放行，其余按包 |

达标率<90% → 打回清单（缺什么+怎么改）交write，流程结束。

## 第0.5审 · X 符合性（改编引擎专属，不达标打回）

对照 `素材/改编计划.md` X体验层逐项检查本章 X 是否深耦合：

| 检查项 | 达标线 |
|:--|:--|
| X战斗耦合（战斗章） | 本章战斗是否用X独特方式（如心灵窃取=偷招式/植入假记忆/读心预判），禁止写成包式打斗 |
| X日常耦合（日常/过渡章） | X在日常的表现与代价（如读心社交困境/窃忆道德代价/灵能侵蚀）是否落地 |
| X剧情耦合（剧情推进章） | X与主线耦合点（如身份危机/被夺舍恐惧/记忆真伪）是否推进 |
| X参与度 | X必须参与动作/对话/决策，不能只是背景设定提及 |
| 事件原创性 | 本章核心事件是否从X核心张力重推，禁止复用包事件（换名复用=打回） |

X 浮于表面或复用包事件 → 打回清单交write，流程结束。

## 第1审 · 质量与充足性（合并快审）

1. **状态连续性**：关键数据🔒/禁止漂移清单逐条比对（人名/数值/已死角色/已废设定）——写错=bug打回
2. **钩子台账**：未到期钩子是否被提前吞并
3. **正文质量**：代入感（活人感/熟悉感）/画面感/对白指纹/类型味（对照类型风味基线）/微观技法落地
4. **充足性**：设定引用是否够（该用的设定没用=单薄）/情感线是否欠账
5. **字数**：2000-2500字区间

## 第2审 · 沉淀双文件（通过后必落盘）

### 白描卡 `产出/白描卡/ch{NNN}.md`（模板：`templates/ch{NNN}.tpl.md`）

```markdown
## 事件白描（叙事流，300-500字）
## 关键数据🔒（人名/数值/不可改事实）
## 爽点·钩子（已兑现爽点公式+新埋钩子+分级）
## 人物关系变化
## 本章DNA执行包（章型卡/笔触目标/章内套路——write下一章消费）
```

### 状态快照 `产出/状态快照.md`（模板：`templates/产出/状态快照.tpl.md`，增量更新）

- 未回收钩子台账：+本章新钩-已回收钩，标预期回收章
- 角色当前状态表：立场/位置/关系增量
- 禁止漂移：新死亡角色/新废设定/新硬事实追加

## 产出

对话内输出：三审结论（配方达标率/质量评级/通过或打回清单）+ 双文件路径。打回时只列清单不重写。批量审核>8章拆批执行。
