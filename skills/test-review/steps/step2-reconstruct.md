# Step Reconstruct：批量回溯审核

> 触发：pipeline 导入模式 0f 调度，或用户说"回溯审核""批量审稿"。
> 目标：对已有正文逐章回溯审核，生成逐章白描卡 + 状态快照，为续写提供状态基础。

## 与正常review的区别

| 维度 | 正常review（单章） | reconstruct review（批量回溯） |
|:--|:--|:--|
| 触发 | write写完一章后 | 导入模式/续写模式，已有未审核正文 |
| 输入 | 单章正文 + 白描卡 + 状态快照 + 施工卡 | 多章正文（采样）+ 已有设定文件 |
| 审核 | 四步完整审核 | 简化版（跳过"要求用户修改"，只做信息提取+沉淀） |
| 产出 | 白描卡 + 状态快照更新 | 逐章白描卡 + 状态快照生成（审核结论对话内输出） |
| 落盘 | formal/draft | formal（必须落盘，为续写提供基础） |

---

## 采样策略

根据已有正文章数选择审核范围：

| 章数 | 采样策略 | 说明 |
|:--|:--|:--|
| ≤10章 | 全部逐章审核 | 章数少，全审保证质量 |
| 11-30章 | 最近5章全审 + 其余每5章取1章采样 | 兼顾效率与覆盖 |
| >30章 | 最近5章全审 + 第一章 + 每10章取1章采样 | 大量章节采样审核 |

> 采样章节做完整审核（信息提取+正向符合性简化+正文质量简化）并为每章建白描卡；非采样章节只快速提取关键信息（角色状态/设定/伏笔/章末钩子）汇聚进状态快照。

---

## 执行步骤

### 1. 读取已有正文

用LS扫描 `正文/` 目录，获取所有章节文件列表，确定最大章节号。

按采样策略确定审核范围：
- 全审章节：完整审核
- 采样章节：完整审核
- 非采样章节：快速提取（角色出场/设定揭示/伏笔埋设/章末钩子）

### 2. 读取已有设定文件（按需）

- `设计/力量体系.md`（如存在）：审核力量体系一致性
- `设计/金手指.md`（如存在）：审核主角行为与金手指限制一致性
- `设计/角色库/角色库.md`（如存在）：审核角色一致性
- `设计/全书设定/（10个最小闭环文件）`（如存在）：审核世界观一致性
- `素材/文风锚定.md`（如存在）：审核笔触DNA一致性
- `卷纲/卷一-幕N-章白描.md`（如存在）：审核剧情符合性

> 设定文件不存在时跳过对应检查，不阻塞流程。

### 3. 逐章审核（采样章节）

对每个采样章节执行简化版四步审核：

#### 3a. 信息提取（每章必做）

从正文中提取：
- 核心事件（2-3句概括）
- 角色状态变化（位置/能力/资产/心态/关系）
- 新揭示的设定/规则
- 新登场角色（如有）
- 章末钩子
- 伏笔埋设/回收

#### 3b. 正向符合性（简化版）

仅检查：
- 主角是否有动作闭环（压力→判断→动作→反馈）
- 是否有越级不付代价
- 是否有金手指规则违反

> 不检查与施工卡的对照（导入模式可能无施工卡）。

#### 3c. 正文质量（简化版）

仅检查：
- AI味检测（15项patterns+高疲劳词3级+结构性4项，每项检出给具体位置）
- 字数检查

> 不做好看度4问（回溯审核不要求主观评价，只提取信息）。

#### 3d. 产出白描卡（审核结论对话内输出）

每章一张 `产出/白描卡/ch{NNN}.md`（参照 `templates/ch{NNN}.tpl.md`，~300-500字）。审核结论在对话内输出，不落盘：

```markdown
# 审核-chNNN（reconstruct）

## 一、信息提取
- 核心事件：（2-3句）
- 角色状态变化：（位置/能力/资产/心态/关系）
- 新揭示设定：（如有）
- 新登场角色：（如有）
- 章末钩子：
- 伏笔：埋设/回收

## 二、正向符合性（简化）
- 主角动作闭环：✓/✗
- 越级不付代价：✓/✗
- 金手指规则：✓/✗

## 三、正文质量（简化）
- AI味：标注问题项+位置
- 字数：XXXX字

## 四、来源标记
- 审核模式：reconstruct
- 采样类型：全审/采样/快速提取
```

白描卡写入 `产出/白描卡/ch{NNN}.md`：事件白描（3-5句）+ 关键数据 + 爽点·钩子（含信息差类型）+ 人物关系变化（可选）。

### 4. 汇总生成状态快照

参照 `templates/产出/状态快照.tpl.md` 生成 `产出/状态快照.md`（replace 模式，覆盖旧版）。reconstruct 生成的状态快照需在开头标注"本快照由批量回溯审核生成，采样章节已完整审核，非采样章节仅提取关键信息"。

> 续写锚点：write 读 近5张白描卡（场景连续性）+ 状态快照（钩子/角色/禁止漂移）即可续写，无需 current-state。

### 5. 落盘后检查

- [ ] 所有采样章节的白描卡已落盘（`产出/白描卡/ch{NNN}.md`）
- [ ] `产出/状态快照.md` 已生成（含钩子台账/角色状态/禁止漂移）
- [ ] 未产出任何旧文档（审核报告/剧情累计卡/current-state/小说快照/review-沉淀/压缩归档）
