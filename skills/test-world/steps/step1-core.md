# Step 1 · 核心设计改编（力量体系+动力引擎）

## 1. 前置门禁

1. Read `素材/改编计划.md`——确定**力量体系/动力引擎维度的改编方式**（保留 or 重写）与X DNA替换方向
2. Read `立项/01-立项PRD.md`——提取「世界+力量体系」方向句、风味基调声明、改编继承表偏离项
3. Read 包 `力量与战斗/力量体系.md` **全文** + 包 `剧情库/动力引擎.md` **全文**（禁limit截断；结构变异包路径见包配方「包结构与 test-skill 消费映射」节）
4. Read 包 `包配方.md` 表3（颗粒度参数）——质量锚清单如下

## 2. 改编方式判定（来自改编计划）

| 强度 | 改编方式 | 执行 |
|:--|:--|:--|
| A/B | **保留** | 照包力量体系结构直写，只换命名/风味/文化渊源，机制与数值锚照搬 |
| C | **重写** | 从X全新推导机制（力量源/干预方式/成长阶梯/代价），但表3颗粒度参数照搬 |

## 3. 质量锚清单（表3，逐项打钩）

| 参数 | 质量锚要求 |
|:--|:--|
| 主养成线 | 「凡人N阶+超凡M档+3大质变点」三层结构；晋阶表逐档：名称/地位/升级触发/预计卷 |
| 升级代价 | 经验指数增长（给出顶级数值锚，如20级=千万级）+旧猎场衰减机制 |
| 敌分级 | 敌人全数值化分级体系（类CR），给出≥8档示例+组队胜算换算 |
| 数值锚密度 | 经济锚≥1/卷（货币+物价）、面板大爆≥3/卷、超凡层金字塔数值化（档位间倍率） |
| 子养成线 | 3-5条，各自身阶位+与主线挂钩方式；每大境界突破涌现1条新线 |
| 交叉规则 | ≥5条，每条标四关系：协同/制约（或等价交换）/涌现 |
| 进阶仪式 | 每次进阶=仪式+花费+代价 |
| 双线机制 | 中盘起双线（形态可换），资源输送比例量化 |

## 4. 改编本书文件

### 4.1 力量体系（模板：`templates/力量体系.tpl.md`）

按包力量体系的四层结构写：源力量（含转化链+敌分级标准）→ 主养成线（晋阶表逐档）→ 子养成线（3-5条表）→ 交叉规则（四关系表）。末尾给终局面板结算锚（全书数值天花板）。

- **保留模式**（A/B）：抄包力量体系全部机制与数值锚，只换力量源命名/风味/文化渊源
- **重写模式**（C）：从X推导新机制（力量源/干预方式/成长阶梯/代价），但档位数量、表格列结构、数值锚密度、质变点分布照搬包
- 换：力量源、机制内容、专有名、文化渊源——全部来自PRD方向句+X

### 4.2 动力引擎（模板：`templates/动力引擎.tpl.md`）

按包动力引擎六组成写：驱动逻辑（世界级引擎+个体执念）→ 运转机制（输入→转化→输出→反馈闭环）→ 众生攀登四群体表 → 代价结构（含代价转嫁层）→ 范式归类（主范式+副范式+四段式节奏基调）→ 演化节点表（远古→前传→主线起点→中盘→终局→跨书伏笔）。

- 非主角变强路径≥5条（写进攀登分节，供character复用）
- 演化节点表至少6行，每行标触发事件/引擎变化/预计卷
- **保留模式**：引擎结构照搬，引擎内容换X风味；**重写模式**：从X推导引擎，结构照搬

## 5. 落盘+快速自检

两文件落盘 `设计/力量体系.md`、`设计/动力引擎.md` 后，对照§3清单逐项打钩一遍（一次性，不循环）。缺项→当场补写，不进入Step 2。
