# write

> 设定包改编·正文写作引擎。v6.0.0：消费协议改为**章白描卡读3段**——向前锚从章锚点表（50字表格行）升级为plot章白描卡（150-250字叙事白描+锚点6行），只读前1+本章+后1三张卡，不读全卷。白描段的对话锚/动作锚直接落笔，write不再现场编剧情。

---

## 做什么

输入：本章白描卡（3段）+ 近5张白描卡 + 状态快照 + 文风DNA + 设定库精选注入（每章≤3维度≤1500字）+ X体验层

输出：`正文/ch{NNN}.txt`（2000-2500字/章）+ 创作记录

**硬约束链**：本章白描卡🔒（白描段+锚点）→ 白描卡/状态快照🔒（过去事实+禁止漂移）→ DNA约束（3-5条笔触）→ 类型声明（防风味漂移）

---

## 怎么操作（SOP骨架）

### Step 1：消费输入 → `steps/step1-consume.md`

抽取本章写作包：用户要求→近5白描卡→状态快照→**章白描卡3段**（前1衔接校验+本章向前锚+后1钩子指向校验）→DNA（缺失态从KB兜底，禁止跳过）→设定精选注入→execution.mode判定。

### Step 2：渲染正文 → `steps/step2-write.md`

按章型骨架渲染2000-2500字：兑现白描段的场景/事件/对话锚/动作锚/情绪转折/钩子落点+17微观技法+爽感公式落地+章末钩子分级落章+创作记录落盘。

---

## 红线

1. **白描卡必兑现**：白描段的事件/对话锚/动作锚/情绪转折/钩子落点+锚点段爽点/POV/X耦合/关键数据🔒，任一缺失=不符合plot设计，review打回。
2. **状态连续性**：关键数据🔒/禁止漂移清单写错=bug；未到期钩子不得提前吞并。
3. **每章爽点≥1**：爽感公式必须落地且有爆发感；连续2章无爽点=不合格。
4. **DNA不跳过**：文风DNA缺失时必须选KB兜底，禁止裸写。
