# write

> 设定包改编·正文写作引擎。v7.0.0：消费协议升级为**章纲读3章**——向前锚从plot白描卡升级为plot v8.2章纲（叙事原子4-6+线账本+plot锚点区，章纲=白描卡超集）。叙事原子序列按序渲染，事件串逐条落地，write不再现场编结构。

---

## 做什么

输入：本章章纲（3章）+ 近5张白描卡 + 状态快照 + 文风DNA + 设定库精选注入（每章≤3维度≤1500字）+ X体验层

输出：`正文/ch{NNN}.txt`（2000-2500字/章）+ 创作记录

**硬约束链**：本章章纲🔒（叙事原子序列+事件串+出线口+plot锚点区）→ 白描卡/状态快照🔒（过去事实+禁止漂移）→ DNA约束（3-5条笔触）→ 类型声明（防风味漂移）

---

## 怎么操作（SOP骨架）

### Step 1：消费输入 → `steps/step1-consume.md`

抽取本章写作包：用户要求→近5白描卡→状态快照→**章纲读3章**（前1衔接校验+本章向前锚+后1钩子指向校验）→DNA（缺失态从KB兜底，禁止跳过）→设定精选注入→execution.mode判定。

### Step 2：渲染正文 → `steps/step2-write.md`

按叙事原子序列渲染2000-2500字：逐原子兑现内部事件串（料全落）+出线口达成+plot锚点区🔒兑现+17微观技法+章末钩子分级落章+创作记录落盘。

---

## 红线

1. **章纲必兑现**：叙事原子序列按序渲染（4-6原子一个不丢）；每原子内部事件串逐条落地、出线口达成；plot锚点区爽点/POV/X耦合/关键数据🔒/出章面板任一缺失=不符合plot设计，review打回。
2. **事实冲突以状态快照为准**：章纲事实性字段（年龄/等级术语/人名）与状态快照/近5章正文冲突时，以状态快照为准，创作记录"冲突标注"里记冲突——章纲事实错误不经write放大传染。
3. **状态连续性**：关键数据🔒/禁止漂移清单写错=bug；未到期钩子不得提前吞并。
4. **每章爽点≥1**：爽感公式必须落地且有爆发感；连续2章无爽点=不合格。
5. **DNA不跳过**：文风DNA缺失时必须选KB兜底，禁止裸写。
