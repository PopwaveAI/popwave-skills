# 拆书源文本预处理 · 契约说明

三份契约，全部走文件，消息通道只传状态与指针。前两份由宿主/预处理产出，第三份由拆解层产出。

## 一、合并章节索引.json

`split` 子命令产出，或桌面端 `bookImportService` 产出。这是拆解层与 UI 唯一认的章清单。

| 字段 | 类型 | 含义 |
|:--|:--|:--|
| `schemaVersion` | int | 固定 1 |
| `book` | object | 书名、作者、来源、总字数、指纹、分章方式 |
| `assets` | array | 有序资产列表，每个资产即一卷（多 TXT 场景一资产一卷） |
| `assets[].id` | string | 资产 ID |
| `assets[].fingerprint` | string | `sha256:...`，同名不同文件用指纹后 8 位区分 |
| `assets[].volumeNo` | int | 卷号 |
| `assets[].chapterIndexFile` | string | 单卷章节索引文件路径 |
| `totalChapters` | int | 全书总章数 |
| `volumes` | array | 卷列表，`no`/`name`/`from`/`to`（全书序号） |
| `chapters` | array | 章列表 |
| `chapters[].globalNo` | int | 全书序号（分章后连续编号） |
| `chapters[].volumeNo` | int | 所属卷号 |
| `chapters[].volumeLocalNo` | int | 卷内序号（每卷从 1 起） |
| `chapters[].file` | string | 章节文件 `ch0001.txt` |
| `chapters[].chars` | int | 去防盗标记后的正文字数 |
| `chapters[].flags` | array | 异常标记：`antileech`（防盗）等 |
| `quality` | object | `missing`（缺失序号）、`duplicated`（重复）、`contamination`（污染章号） |
| `splitMethod` | string | `title-regex`（标题正则）或 `crawl-order`（爬取目录）或 `toc`（目录） |

**章号纪律**：`globalNo` 以分章后的序号为准，不用标题内嵌数字（站点普遍缺号重号）。所有下游引用章节一律用 `globalNo`。

## 二、拆解配置.json

宿主（或 `pop-decon` 入口）冻结后传给 run，启动即不可变。模板见 `pop-decon/templates/拆解配置.tpl.json`。

| 字段 | 类型 | 含义 |
|:--|:--|:--|
| `schemaVersion` | int | 固定 1 |
| `taskId` | string | 任务 ID |
| `referenceBookId` | string | 参考书 ID |
| `scope` | object | 拆解范围 |
| `scope.type` | string | `full` 全书 / `volume` 单卷 / `chapters` 章范围 |
| `scope.volumeNo` | int | type=volume 时的卷号 |
| `scope.from` / `scope.to` | int | type=chapters 时的起止全书序号 |
| `focusDimensions` | array | 拆书重点，只许填七个产品标签：剧情结构、人设&关系、力量体系、世界观、爽点&钩子、赛道特色、文本DNA |
| `processingProfile` | string | `standard` / `deep` / `skeleton`，对应切批档位 |
| `skillVersions` | object | 各 skill 版本快照 |
| `outputRoot` | string | 产物根目录 |

**focusDimensions 只影响 L2 结果呈现与组织**，不改变 L1 八维提取或 L2 六模块交付。

## 三、批次完成标志

`pop-decon-dimension` 每批结束时产出，宿主据此判断能否进下一批或进 L2。模板见 `pop-decon-dimension/templates/批次完成标志.tpl.json`。

| 字段 | 类型 | 含义 |
|:--|:--|:--|
| `batchId` | string | `V{n}_B{m}_chXXX-YYY` |
| `status` | string | `passed` 通过 / `failed` 失败 / `partial` 部分 |
| `chaptersCovered` | array | `[from, to]` 全书序号 |
| `evidenceCount` | int | 证据条目数 |
| `checks` | object | 七项门禁逐项布尔 |
| `checks.glossary` | bool | 术语表完整 |
| `checks.anchorPool` | bool | 锚点池覆盖 |
| `checks.schema` | bool | 八维子节完整 |
| `checks.evidenceDensity` | bool | 证据密度 |
| `checks.quantified` | bool | 量化无丢失 |
| `checks.noFabrication` | bool | 不编造 |
| `checks.traceable` | bool | 章节可回溯 |
| `artifacts` | array | 本批产物文件路径 |
| `warnings` | array | 警告信息 |

**可靠性纪律**：宿主判断批次状态读这个文件，不解析 run 事件文本。事件是运行级的，靠解析文本判断批次状态不可靠。
