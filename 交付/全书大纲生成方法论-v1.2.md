# 全书大纲生成方法论 v1.2

> 用途：把一句模糊想法，变成一份"讲得清剧情本身"的全书大纲
> 依据：三次实测（DND混合赛道 / 无限流 / 守序邪恶家族修仙）
> 本版改动：①全书大线补上"世界结局"这条腿；②全文换掉工程黑话，只用网文行话和日常中文。v1.1 废止。

***

## 0. 先立一条用词规矩（本文件自己先守）

这份文件以后会被写作 agent 当范文读：文件里用什么词，大纲里就会冒出什么词，还会顺着漏进正文。上一版里的"引擎、库存、流水线、耦合、register"，人看不懂，agent 学去还会写出"契约、回执、资产负债表"这种串味的东西。

**规矩：本文件只许用两类词——网文行话（主线、明线暗线、伏笔、换地图、金手指、单元剧、马甲流、撞梗、烂尾……）和日常中文。不造工程词，不写英文。**

## 1. 底层认识（四条）

### 1.1 故事结构分三层，别混

| 层     | 管什么         | 例子              | 用在哪 |
| ----- | ----------- | --------------- | --- |
| 一卷的形状 | 一卷里故事怎么走    | 英雄之旅十二段、三幕、起承转合 | 每一卷 |
| 全书的骨架 | 几十个小故事从哪不断来 | 下面 1.2 的"两条腿"   | 整本书 |
| 种子    | 这台机器最初的样子   | 主角要什么＋世界怎么了     | 立项  |

英雄之旅那类套路写的是"一个故事"的形状，它默认故事有结尾。长篇连载要把一个大故事拆成几十个各自完整、各自好看的小故事——所以它当不了全书骨架，只能管一卷。雪花法管"怎么把一卷展开成章节"，也不管种子。

### 1.2 长篇靠两条腿走路：日常线和伏笔线

| <br /> | 日常线（管饭）              | 伏笔线（管高潮）               |
| ------ | -------------------- | ---------------------- |
| 内容     | 现写现卖：新地图、新案子、新生意、新对手 | 提前埋好、到时候引爆：信息差、身世、世界真相 |
| 特点     | 源源不断，但写多重复           | 弹药有限，但一响就是大高潮          |
| 只有它会怎样 | 三卷之后读者腻              | 中途弹尽粮绝，日常稀汤寡水          |

成熟流派就是这两条腿的各种装法：

- 日常腿：升级换图流、单元副本流（无限流/破案流）、经营种田流

- 伏笔腿：马甲流（读者知道、书里人不知道，揭穿即高潮）、解谜流（世界真相一层层揭开，诡秘那样）

两条腿能装在不同大小的东西上：主角个人、家族、宗门、国家都行——家族修仙文就是把整套东西装在家族身上。

两条腿的四种接法：

- **接力**：前期一条、中期换另一条（前期升级打怪立威，后期转解谜收网）

- **一明一暗**：明线日常跑节奏，暗线伏笔攒大高潮，全程并行

- **挂钩**：伏笔的进度挂进日常——每破一个案子，马甲暴露的风险就多一分；案子结了，伏笔也攒满了

- **喂料**：每揭开一层真相，顺手解锁一块新地图。世界的秘密越大，能换的地图越大——这是长篇越写越大的原理

### 1.3 世界之谜怎么跟主线配合

主线 ＝ 真相怎么分层（结构）＋ 哪一卷揭开哪一层（时间表）。

世界之谜默认**沉在暗线**：平时不打扰明线，每卷末露一次脸，把这一卷的意义翻个面——读者以为的"胜利"原来是别的东西。它不在明线上"解决问题"，明线让给主角想要的东西。

反面教训：三次实测都把世界之谜放上了明线，于是每揭一层就得平掉一层危机，全书被拉成"危机一环扣一环"——这是英雄之旅在全书层面的还魂，是病。

### 1.4 全书大线＝主角要什么＋世界落个什么结局

只定"主角想要什么"不够，还得定"世界最后落个什么结局"——没有终点线，收尾卷就没有重量。两条线的关系有四种，选哪种是大事：

| 关系    | 样子                       | 效果                    |
| ----- | ------------------------ | --------------------- |
| 同路    | 主角得偿所愿＝世界得救              | 顺，但轻；常规爽文             |
| 相撞    | 主角想要的和世界需要的结局不能兼得        | 悲剧势能；终局没有干净选项         |
| 变了样   | 主角一路要A，最后发现A其实是B，以B的形态拿到 | 回甘最重；"我要错了"和"我是谁"同时揭开 |
| 主角是钥匙 | 主角欲望达成的那一下，恰好就是世界结局的开关   | 爽感强、结构紧，但最容易用滥        |

注意第四种最好用也最容易偷懒——三次实测全是它。连着用要自觉换。

## 2. 八步流程

### Step 1 听懂想法

从模糊想法里认出：赛道、元素、主角雏形、读者点开这本书图什么。不急着搭结构。
产出：一句话诉求＋元素清单。

### Step 2 定全书大线

定三样：

- 主角想要什么（起点是缺，一路去要）

- 世界落个什么结局（终点线）

- 两线关系四选一

注意：大线由日常线推着走（升级、办案、经营），不由世界之谜推。危机留给每一卷当卷内冲突。
产出：大线两句话＋关系一项。
自检（防套路）：大线要是能读成"主角应对一个不断加深的危机"，重定。

### Step 3 定谜底

- 先选谜底的类型（见 3.1 六种，优先挑这个赛道没写烂的）

- 再写谜底一句话：最里面那层真相。这句话必须同时回答"世界怎么了"和"主角是谁"——一条根

自检（防撞梗）：谜底要是能读成"有个东西在养/收割我们"，换；赛道头部作品都用过这个谜底，换。

### Step 4 铺六层真相（两行写法）

拿谜底问一句话：**"如果这是真的，世界为了正常运转，必须把它误会成什么？"** 每一层误会，就是一层。从外往里排：

**不对劲 → 里头的规矩 → 敌我关系 → 谁掌权 → 我是谁 → 世界是什么**

每层写两行：

- **结构行**：写给作者自己看的备忘，随便怎么记

- **世界行**：用赛道自己的词写的，**只有这行能进大纲**

用词三条（防串味）：

1. 先用赛道现成的词（末法、道统、祠堂、香火）
2. 不够就用赛道语素造新词（承泽、除籍、道印）
3. 禁止跨行借词（回执、信托、资产表、归档）——任何赛道都一样

判据：把大纲里所有名词拎出来逐个问"赛道头部作品里出现过吗？是赛道语素造的吗？"有一个不是就重造。
为什么：揭开真相时最重的词，是读者背了二十年的旧词（重定义"飞升""末法"），不是教读者一套新词。

### Step 5 配机器

- 伏笔腿：世界之谜（书的名分，管卷末大高潮）

- 日常腿：升级换图／单元副本／经营种田三选一（管饭，顺便推大线）

- 接法：一明一暗打底，挂钩让伏笔进度每圈可见，喂料让揭层解锁新地图

- 装在谁身上：个人／家族／宗门

自检（防断粮）：这套日常线写到四百章还有饭吗？

### Step 6 排卷

- 全书分 3-4 段（换挡点）

- 每卷＝一个完整小故事（英雄之旅在这一层合法），卷内自己有危机、有解决

- 排"哪卷揭开哪层"：层数约等于卷数一半，两次大揭间隔约三卷；场面越揭越大，事情越揭越跟主角自己有关

- 列跨卷伏笔总表：哪条线哪卷埋、哪卷收

自检（防烂尾）：最后一层揭开之后，这本书还剩什么？要么还有更深一层，要么明确收尾并留续作口子。

### Step 7 讲一遍

把整本书当故事讲给朋友听——"他本来是什么人，出了什么事，离开了家，遇上谁，干掉谁，得到什么，又遇上谁……"按排卷逐段讲，每卷一段；到揭开真相的卷，把那一层写成大转折。

要点：

- 讲的是明线（主角要东西的路），世界之谜只在卷末转折处浮出来

- 每卷要有变化：对手更大、舞台更大、代价更大——不然就是原地打转

- 讲完每段自查一遍用词（Step 4 的三条）

产出：全书白描，每卷一段，每段可直接交给卷纲。

### Step 8 五问自检

1. **防套路**：大线是"想要/建造"驱动，不是危机串？
2. **防撞梗**：谜底不是"养我们"？赛道没写烂？跟前几本没撞？
3. **防串味**：全文名词都是赛道的话？
4. **防断粮**：四百章还有饭？
5. **防烂尾**：最后一层揭完还剩什么？

外加一问：第一卷埋的三个"不对劲"（金手指的怪、主角的怪癖、第一场事件），到后边都收回来了吗？——金手指常常就是谜底露在外面的那一角（主角"听得懂怪物"其实是母语）。

## 3. 手艺模块

### 3.1 谜底的六种类型

| 类型  | 那句话问什么    | 真相的形状                      | 跟谁斗         | 代表      |
| --- | --------- | -------------------------- | ----------- | ------- |
| 被圈养 | 谁在养我们     | 有人拿我们当牲口/庄稼                | 活着的圈养者      | 天道流（写烂） |
| 遗产  | 主人去哪了     | 主人已死，世界是没人认领的家业，天道是自动执行的遗嘱 | 一份死人的合法意志   | 诡秘      |
| 铁律  | 这条规矩为什么存在 | 没有坏人，只有一条法则                | 法则本身＋利用法则的人 | 黑暗森林    |
| 残局  | 世界为什么还没完  | 终局早打完了，现在是拖着不结算            | 拒绝终局的一方     | 回环流     |
| 废墟  | 乐园怎么塌的    | 没有恶人，只有事故和被抹掉的历史           | 遗忘和谎言本身     | 进击的巨人   |
| 真假  | 我和世界哪个是梦  | 谜底关于"故事"本身                 | 叙事自己        | 缸中之脑    |

**新鲜感账**：读者觉得新的程度＝元素新×谜底新，两项能互相拆借。元素够怪（dnd＋克苏鲁），谜底用熟的也能过；元素是老赛道（纯仙侠），谜底必须自己扛。定谜底前先看看这个赛道的名作用的是哪种，别踩进挖烂的矿。

设计者三个不由自主的毛病（每次都想犯，写的时候警惕）：

1. 一想"世界归谁"就往"有东西在养我们"上跑
2. 一想"揭开要震撼"就造一套新黑话
3. 一想"主角重要"就把主角写成"系统的产物"（样本、钥匙、容器）

### 3.2 世界之谜的八条手艺标准

1. **翻面**：每揭开一层，读者要能回头重新理解之前的事。只是多知道点新东西，不算揭开
2. **换对手**：每层真相要重新划一遍敌我——谁跟谁打、为什么打
3. **一条根**：最里面那层，既答"世界怎么了"，也答"主角是谁"
4. **提前露影**：每层揭开之前，它早就以"不对劲"的样子被读者见过——能隐约猜到，但被误导猜错方向
5. **有代价**：每揭开一层，主角烧掉一样东西——盟友、身份、信念、亲人。信息到了，疼也要到
6. **不空转**：两次大揭之间，悬念要小步往前走（又多一个不对劲、半个答案），不许原地晾着
7. **省着用**：层数约等于卷数一半；场面越揭越大，事情越揭越跟主角自己有关
8. **逼选择**：最后一层揭开后，主角面对的必须是没有干净答案的选择——是重画善恶，不是放烟花

四个翻车样：

1. 黑手背后还有黑手——只加码不翻面，读者麻了
2. 把揭开当百科讲——设定倾泻
3. 只挖不填——神秘盒病
4. 读者早猜到了却不做误导——提前漏气

补两条手艺：

- **一条根的两种感情**：好主角揭开"我是谁"是惊喜；恶主角揭开"我是谁"是恐怖（原来我这个性格本身就是条款）。结构不换，换感情就行

- **恶主角的"在乎"**：靠两样——本事让人服＋只剩一个软肋。守序恶的收尾不是牺牲自己，是在规矩里赢下规矩本身

### 3.3 大线四种关系

见 1.4。补一句：四种里"变了样"回甘最重——它让"我要错了"和"我是谁"同时揭开，是诡秘结尾的技术来源。

## 4. 三次实测复盘

| 测     | 输入           | 验出什么                                          | 暴露什么                    | 买到的自检       |
| ----- | ------------ | --------------------------------------------- | ----------------------- | ----------- |
| DND混合 | dnd＋克苏鲁＋战锤入侵 | 流程跑得通；"在乎的人"和"最高潮"从结构里自己长出来，不用事后补             | ——                      | ——          |
| 无限流   | "写个无限流"      | 从零生成可行；金手指从谜底里自己长出来（听得懂怪物＝母语）                 | 谜底跟DND撞了型；现代词漏进大纲       | 防撞梗、防串味     |
| 家族修仙  | 守序邪恶＋家族修仙    | 整套东西能装在家族上；主角阵营要跟日常线配套（守序配规矩，混乱拆家）；"我是谁"的恐怖写法 | 谜底三连撞；黑话在古典赛道裸奔；大线写成危机串 | 防撞梗、防串味、防套路 |

规律：**每测暴露一个我自己都没意识到的默认习惯**（谜底总往一处想、词总往新造处跑、大线总往危机上写）。解法不是打补丁，是把每个"想当然"变成流程里明写的一步，再配一道自检。**流程的职责是把所有要做的选择摆到桌面上，自检的职责是拦住手滑。**

## 5. 已知短板（诚实清单）

1. 三测都是同一个出题人，方法可能只是适配了出题人——要换人/换 agent 盲测
2. 六种谜底只实测了"被圈养"两次、"遗产"一次；铁律/残局/废墟/真假没测
3. 大线四种关系全是理论，没实测；下一测必须强制选"同路/相撞/变了样"之一，不许再用"主角是钥匙"
4. "经营种田当全书大线"（大线由经营推着走）没实测——上测有原料但大线跑偏了
5. "在乎"目前靠"有代价＋一条根"推出来，够不够待验
6. 每卷一段怎么交接给卷纲、跨卷伏笔总表怎么对接最终面板，还没细化
7. 感情线怎么当日常腿用，没成文
