# 文风五大类型

> 借鉴自 novel-writer 的文风分类，独立重写并补充例证。
> 此文档仅在 `novel-brainstorm` 中作选项概览用。具体文风规则（句长、禁用词、段落长度等）由 `novel-style-engine` 在样本投喂后抽取。

---

## A. 动词驱动型

**核心特征**：短句、快节奏、信息密集、动作先行

**适用题材**：悬疑、权谋、生存、爽文、网文连载

**典型作品**：
- 《大奉打更人》（卖花女）
- 《诡秘之主》（爱潜水的乌贼）
- 《诡秘之主》（前期）

**写作偏好**：
- 段落长度短（每段 1-3 句）
- 心理描写用动作 / 场景表达，不用形容词直述
- 对话简短有力，留白多
- 章节钩子强，喜欢"一刀切"式收尾

**避免**：
- 形容词堆砌
- 长句从句嵌套
- 抽象心理描写

---

## B. 克制典雅型

**核心特征**：情感内敛、留白艺术、古典韵味、节制美学

**适用题材**：历史正剧、权谋、情感、传统文学风格

**典型作品**：
- 《琅琊榜》（海宴）
- 《庆余年》（猫腻）
- 《大明王朝 1566》（剧本风格）

**写作偏好**：
- 段落不刻意求短，但句式精炼
- 情绪靠典故、意象、对照来传递
- 对话注重身份感、礼仪、潜台词
- 章节收尾常用诗意 / 哲思式结尾

**避免**：
- 直白抒情
- 现代口语
- 过度心理解释

---

## C. 幽默吐槽型

**核心特征**：主角内心戏丰富、现代梗、轻松化解紧张、自我消解

**适用题材**：爽文、穿越、系统流、轻喜剧、都市奇幻

**典型作品**：
- 《我师兄实在太稳健了》（言归正传）
- 《大奉打更人》（部分段落）
- 《史上第一混乱》（张小花）

**写作偏好**：
- 内心 OS 大量出现
- 现代词汇 / 网络梗 / 段子穿插
- 段落节奏快，喜欢用反差制造笑点
- 章节钩子常用"主角倒霉但很欠"的口吻

**避免**：
- 过度煽情
- 沉重压抑氛围
- 严肃说教

---

## D. 热血燃向型

**核心特征**：金句频出、情绪高涨、对抗性强、男性向爽点

**适用题材**：玄幻、武侠、升级流、战斗番

**典型作品**：
- 《斗破苍穹》（天蚕土豆）
- 《雪中悍刀行》（烽火戏诸侯）
- 《一念永恒》（耳根）

**写作偏好**：
- 战斗 / 对抗场面详细
- 短句堆叠制造冲击力
- 金句 / 口号 / 名言频出
- 主角强势，少自省

**避免**：
- 拖沓
- 主角犹豫不决
- 过度算计 / 政治戏

---

## E. 悬疑压抑型

**核心特征**：氛围营造、信息差、层层揭秘、心理压力

**适用题材**：悬疑、惊悚、探案、克苏鲁、社会派推理

**典型作品**：
- 《诡秘之主》（爱潜水的乌贼）
- 《盗墓笔记》（南派三叔）
- 《心理罪》（雷米）

**写作偏好**：
- 环境描写多（光线、声音、温度）
- 叙述者刻意保留信息，制造信息差
- 段落节奏慢，铺垫长
- 章节钩子常用"未解之谜"式结尾

**避免**：
- 过早解密
- 平铺直叙
- 角色全知全能

---

## 混搭说明

文风可以混搭。常见组合：

- **A + C**：动词驱动 + 幽默吐槽 → 爽文常见配方（如《大奉打更人》）
- **B + E**：克制典雅 + 悬疑压抑 → 高质量历史悬疑（如《长安十二时辰》）
- **A + D**：动词驱动 + 热血燃向 → 玄幻战斗主流
- **C + E**：幽默吐槽 + 悬疑压抑 → 软克苏鲁

混搭时通常一个为主、一个为辅。在 `novel-style-engine` 抽取样本时，可以从两类样本各投喂一些，让 LLM 学到混合特征。
