# 章节写作准则

> 整合 novel-writer "八大写作原则" + inkos 的"完成度优先" 理念，独立重写。
> 用作 writer prompt 的"行为准则"段。

---

## 一、画面感优先

> "让读者**看到**，而不是**被告知**。"

**错误示例**：
> 他很紧张。

**正确示例**：
> 他的手指不自觉地敲击着桌面，额头上渗出细密的汗珠。

**应用**：
- 用动作 + 神态 + 环境替代情绪形容词
- 用五感（视/听/嗅/触/味）描写场景
- 每个情绪描述背后必须有一个具体动作

---

## 二、代入感营造

> "让读者**身临其境**。"

**应用**：
- 描写环境氛围：光线 / 温度 / 气味 / 声音
- 通过 POV 角色的感官体验传递信息，不要用上帝视角描述
- 每个场景描写开头建立"现场感"——读者要知道**在哪里、什么时候**

---

## 三、冲突张力

> "每一场景都要有冲突或悬念。"

**冲突类型**（每个场景至少有 1 个）：
- 人与人（直接对抗）
- 人与环境（资源稀缺 / 时间紧迫 / 障碍）
- 人与自己（内心矛盾）
- 信息差（读者知道角色不知道，或反之）

**反例**：纯水日常段落（吃饭 / 走路 / 闲谈），如果不承担其他功能（埋伏笔 / 推关系 / 建反差）→ 删掉或合并。

---

## 四、对话有戏

> "对话推动情节，揭示人物性格，藏潜台词。"

**错误示例**：
> "你觉得怎么样？"  
> "我觉得不太好。"  
> "为什么？"  
> "因为..."

**正确示例**：
> "你觉得怎么样？"他端起茶杯，目光却没落在对方身上。  
> 她沉默了很久。"你早就知道了。"

**应用**：
- 用动作 / 神态打断对话节奏
- 对话要有潜台词，不要把所有意思说出来
- 一段对话不要超过 4-5 个回合，再长就让事件介入打断

---

## 五、节奏控制

> "长短句交替，避免单调。"

**应用**：
- **动作场景**：短句堆叠，营造紧张
- **情感场景**：长句铺垫，营造氛围
- **过渡段落**：中等长度，匀速推进
- 段落不要过长，便于阅读（建议 ≤ 3 句话每段）

---

## 六、留白艺术

> "不要把所有东西都写出来。"

**应用**：
- 用暗示代替直说
- 让读者自己想象和推理
- 重要事件不要"事无巨细全写"——选择最有冲击力的细节展现

---

## 七、开场抓人

> "开头就要有钩子。"

**第一段必须满足之一**：
- 悬念
- 冲突
- 强烈的对话
- 鲜明的场景

**避免**：开头大段背景介绍 / 心理铺垫 / 风景描写。先勾住读者，再给信息。

---

## 八、结尾留钩

> "结尾必须为下一章留下明确的钩子。"

**钩子类型**：
- **悬念钩子**：一个未解决的问题（"门外传来脚步声，是谁？"）
- **行动钩子**：人物即将采取的行动（"他站起身，走向狱门"）
- **对话钩子**：以暗示性对话结束（"'大人，使者到了。'"）
- **消息钩子**：重要消息传来
- **场景钩子**：场景转换，暗示变化（"远处，马蹄声渐近"）

**避免**：
- ❌ "风暴要来了"（泛泛而谈）
- ❌ 总结本章主题 / 升华
- ❌ 解决所有问题（读者没动力追下一章）

**要做的**：
- ✅ 指向下一章的具体事件
- ✅ 让读者想"接下来会发生什么"

---

## 关于"去 AI 味"

> 详细禁用列表见 `novel-review/references/anti-ai-rules.md`。

最常见的 AI 痕迹（**全部禁用**）：

| 禁用 | 改用 |
|---|---|
| "不是 X 而是 Y" | 直接写动作和神态 |
| 破折号 —— | 逗号或句号 |
| "值得注意的是" / "关键在于" | 直接陈述 |
| "突然 / 忽然 / 猛然"（密度上限：1 次 / 3000 字） | 通过具体动作呈现 |
| "似乎 / 可能 / 或许"（密度上限：3 次 / 1000 字） | 确定性叙述 |
| "全场震惊" / "众人皆惊" | 写具体某个人的反应 |
| "显然 / 毋庸置疑" | 让读者自己得出结论 |
| "核心动机 / 锚定效应"（学术词）| 用具体语言 |
| "读者可能" / "接下来就是" | （元叙事，删除）|

## 章节的"骨架时间"

每章写之前先想：

1. **本章占多少字？** word-target 决定
2. **几个场景？** 一般 3-5 个
3. **每个场景占多少字？** 在章纲里写出来
4. **每个场景的核心动作是什么？** 一句话能说出来

写作时按这个骨架推进，避免某一段拖太长或太短。

---

## 给 writer prompt 的最后嘱托

写完后请自检：

- [ ] 开头 3 段有钩子
- [ ] 每 3-5 段有小高潮
- [ ] 至少 2 个明确冲突
- [ ] 对话有潜台词
- [ ] 结尾有具体钩子
- [ ] 没有禁用句式 / 禁用词
- [ ] 段落长度有变化（不是全部 3 句话）
- [ ] 五感描写至少出现 2-3 类

不通过 → 修正后再输出。
