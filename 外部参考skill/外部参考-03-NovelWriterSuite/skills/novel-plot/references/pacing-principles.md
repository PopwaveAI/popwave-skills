# 章节情节推进四大原则

> 借鉴 novel-writer，独立重写并扩展。这 4 条原则是中文网文章纲设计的硬约束。
> 在 `novel-plot` 设计卷级章节大纲、`novel-chapter` 写章纲时都要应用。
> `novel-review` 在校稿时会用这些原则检查"流水账"和"节奏单调"。

---

## 原则一：因果链原则

> **每一章的危机必须从上一章的隐患发展而来。**

### 含义

每章不是独立事件，是一根**因果之绳**上的一节。第 N 章的核心冲突，必然来自第 N-1 章主角的某个抉择 / 失误 / 隐患。

### 反例（错误）

```
第 3 章：主角在校园里被欺负
第 4 章：主角的母亲突然生病住院
第 5 章：主角的工作丢了
```

这 3 章互不相关，是"流水账"，不是因果链。

### 正例（正确）

```
第 3 章：主角被欺负后愤而辍学 ← 抉择
第 4 章：辍学导致家里经济崩溃，母亲压力过大住院 ← 因果
第 5 章：主角为母亲医药费铤而走险接了非法工作 ← 因果链延伸
```

每章是上一章的**结果**，又是下一章的**原因**。

### 格式要求

每章细纲必须明确写"**危机来源**：来自上一章的什么隐患"。

---

## 原则二：抉择 + 代价原则

> **主角每章必须做出明确抉择，每个抉择都有代价，这个代价成为下一章的危机。**

### 含义

主角不能只是**被动承受**——必须**主动选择**。每个选择都不是免费的，必然有代价。

### 反例（错误）

```
第 4 章：主角的家被烧了，无处可去，只好流落街头。
```

这一章主角是被动的（家被烧 + 流落街头），没有抉择。

### 正例（正确）

```
第 4 章：主角的家被烧了。他面临三个选项：
  A. 投靠仇人（保命但屈辱）
  B. 揭竿而起（豪气但九死一生）
  C. 隐姓埋名远走他乡（安全但放弃复仇）
  
他选择 B。这个抉择的代价：失去最后一个亲人（叔叔反对而决裂），自己也付出重伤。
这个代价 → 下一章的危机：重伤后被仇人发现踪迹。
```

### 格式要求

每章细纲必须明确写"**主角抉择 + 代价**"和"**埋下隐患**：这个抉择埋下了什么"。

---

## 原则三：升级递进原则

> **危机必须层层升级，像绷紧的绳子越绷越紧。**

### 含义

不允许同一级别的危机重复出现。如果第 3 章主角面对"可能暴露身份"，第 4 章不能仍然是"可能暴露"——必须升级为"即将暴露"或"已经暴露"。

### 升级阶梯（以"身份暴露"为例）

```
Level 1  可能被怀疑
Level 2  有人开始调查
Level 3  关键证据落到对方手里
Level 4  对方已经确认，开始布局
Level 5  对方公开点名
Level 6  对方采取行动
```

每章应该比上一章上升 1 级。**绝对不能**第 5 章回到 Level 2 然后第 7 章又上 Level 3。

### 反例（错误）

```
第 3 章：主角差点被发现（Level 1）
第 5 章：主角又差点被发现（Level 1）
第 7 章：主角又又差点被发现（Level 1）
```

这是"重复消费同一个紧张"——读者会疲劳。

### 正例（正确）

```
第 3 章：主角差点被发现（Level 1）
第 5 章：调查者锁定了主角的居住区域（Level 2）
第 7 章：调查者掌握了关键证据（Level 3）
```

### 例外：节奏波形

为了避免"全章都在升级"的疲劳，可以有"喘息章 / 后效章"。但喘息章必须承担其他功能（埋伏笔 / 推关系 / 建反差），**不能是纯水日常**。

---

## 原则四：节奏权重原则

> **用章节数量体现节奏。重要的事多用几章，过渡的事一章带过。**

### 权重标记规范

| 权重 | 含义 | 章节数建议 | 用途 |
|---|---|---|---|
| ⭐ | 过渡 | 1 章 / 一段时间 | 时间推进、日常交代 |
| ⭐⭐ | 铺垫 | 1-2 章 | 张力积累、危机初现 |
| ⭐⭐⭐ | 转折 | 2-3 章 | 重大变化、局势恶化 |
| ⭐⭐⭐⭐ | 高潮前奏 | 3-4 章 | 决战准备、正面对峙 |
| ⭐⭐⭐⭐⭐ | 大高潮 | 4-6 章 | 全卷最精彩段落，详细展开 |

### 一卷的节奏结构示例

假设一卷 25 章：

```
Ch 1-3   ⭐⭐    铺垫（建立卷一情境）
Ch 4-5   ⭐     过渡（时间推进）
Ch 6-8   ⭐⭐⭐  转折（事态恶化）
Ch 9-10  ⭐⭐   铺垫（积累压力）
Ch 11-13 ⭐⭐⭐⭐ 高潮前奏（正面对峙）
Ch 14-18 ⭐⭐⭐⭐⭐ 大高潮（5 章详细展开）
Ch 19-21 ⭐⭐⭐  转折（高潮后效）
Ch 22-25 ⭐⭐   铺垫（为下一卷做准备）
```

### 常见错误

- ❌ 全卷都是 ⭐⭐⭐⭐⭐（永远在高潮 → 没有高潮）
- ❌ 全卷都是 ⭐（一直在过渡 → 读者掉头）
- ❌ 大高潮只用 1 章（应该 4-6 章）
- ❌ 过渡用 5 章（应该 1 章）

---

## 在卷级章节大纲中应用四大原则

设计大纲时，对每一章追问 4 个问题：

1. **因果链**：这一章的危机来自上一章哪个隐患？
2. **抉择代价**：主角在本章做什么抉择？付出什么代价？这个代价是下一章的什么危机？
3. **升级递进**：这一章比上一章升级了几个 Level？
4. **节奏权重**：这一章是 ⭐ 几？跟它对应的章节数匹配吗？

如果某一章 4 个问题答不出，说明这一章**不合格**。要么调整定位，要么砍掉。

## novel-review 的对应检查（v0.2）

`check_consistency.py` 会扩展加入：
- 检查每一章的"危机来源"是否对应得上前一章的"埋下隐患"
- 检查"危机升级 Level"是否真的递增
- 检查"权重 vs 实际字数"是否匹配（⭐⭐⭐⭐⭐ 的章不应该只有 1500 字）
