# 全书结构模型

5 种常用结构。在 `plot/_index.md` frontmatter 的 `structure` 字段选一种。

---

## 1. 三幕结构（three-act）

**适用**：通用，西式叙事默认

**结构**：

| 幕 | 比例 | 关键节点 |
|---|---|---|
| Act 1（建立） | 25% | 1. 开场 / 平凡世界<br>2. 触发事件（10%）<br>3. 第一转折点（25%） |
| Act 2（对抗） | 50% | 4. 升级阻碍<br>5. 中点（50%，攻守互换）<br>6. 危机（75%）<br>7. 第二转折点（75%） |
| Act 3（解决） | 25% | 8. 高潮<br>9. 结局 |

**适合**：历史正剧、悬疑、传统文学风格

---

## 2. 英雄之旅（hero-journey）

**适用**：成长向、史诗、奇幻

**结构（12 阶段）**：

| 阶段 | 内容 |
|---|---|
| 1. 平凡世界 | 主角初始状态 |
| 2. 冒险召唤 | 触发事件 |
| 3. 拒绝召唤 | 主角抗拒 |
| 4. 遇见导师 | 获得引导 |
| 5. 跨越门槛 | 进入新世界 |
| 6. 试炼 / 盟友 / 敌人 | 学习与积累 |
| 7. 接近最深处 | 准备终极挑战 |
| 8. 苦难考验 | 面对最大恐惧 |
| 9. 奖赏 | 获得宝物 / 知识 / 力量 |
| 10. 回归之路 | 带着收获返回 |
| 11. 复活 | 最终蜕变 |
| 12. 携宝归来 | 改变世界 |

**适合**：玄幻、奇幻、修真、变身流

---

## 3. 起承转合（kishotenketsu）

**适用**：东方传统四段式，言情、生活流、文艺类

**结构**：

| 段 | 占比 | 内容 |
|---|---|---|
| 起 | 20% | 介绍人物、世界、初始状态 |
| 承 | 40% | 发展、深入、积累 |
| 转 | 20% | 重大转折，打破之前的格局 |
| 合 | 20% | 解决，回应主题 |

**特点**：不依赖外部冲突，可以是情感 / 认知的转折

**适合**：言情、文艺、成长、慢生活

---

## 4. 救猫咪 15 拍（save-the-cat）

**适用**：影视化友好，节奏感强

**15 个 beat**（按页数百分比）：

| # | Beat | 位置 |
|---|---|---|
| 1 | Opening Image | 1% |
| 2 | Theme Stated | 5% |
| 3 | Set-Up | 1-10% |
| 4 | Catalyst | 10% |
| 5 | Debate | 10-20% |
| 6 | Break Into 2 | 20% |
| 7 | B Story | 22% |
| 8 | Fun and Games | 20-50% |
| 9 | Midpoint | 50% |
| 10 | Bad Guys Close In | 50-75% |
| 11 | All Is Lost | 75% |
| 12 | Dark Night of the Soul | 75-85% |
| 13 | Break Into 3 | 85% |
| 14 | Finale | 85-99% |
| 15 | Final Image | 99% |

**适合**：剧本风格小说、想未来转影视的项目

## 5. 网文升级流（web-novel-escalation）

**适用**：中文网文（玄幻、都市、修真、系统流）

**核心理念**：连载小说不能像传统小说那样把高潮放在最后。**前期必须密集给爽点**，否则读者断更。

**结构**：

```
卷一（10-30 章）  - 完整小目标周期 1
  ├─ 1-3 章：建立主角困境 + 给第一个钩子
  ├─ 4-8 章：第一个金手指 / 转机
  ├─ 9-15 章：第一次小爽（打脸 / 升级 / 翻盘）
  └─ 16-30 章：进入下一周期前的过渡

卷二（25-50 章）  - 完整小目标周期 2（升级版）
  ├─ 跟卷一同节奏，但格局更大
  └─ 末章揭开"更大世界"
  
卷三-卷 N        - 每卷一个完整小目标周期，每卷格局上一级
  └─ 大世界 → 更大世界 → 终极世界

终章卷            - 真正的高潮，回应全书母题
```

**关键约束**：
- 每 3-5 章一个小高潮（节奏波形：蓄压 → 升级 → 爆发 → 后效）
- 每 10-15 章一个完整周期
- 不允许 5 章以上没有爆发
- 大高潮后必须有"后效章"（爆发的影响落地）

**适合**：起点 / 番茄 / 七猫 / 飞卢类网文

---

## 选型建议

| 题材 | 推荐结构 |
|---|---|
| 玄幻 / 修真 / 都市爽文 | 网文升级流 |
| 历史 / 权谋 / 悬疑 | 三幕结构 |
| 言情 / 文艺 / 治愈 | 起承转合 |
| 奇幻 / 史诗 / 成长 | 英雄之旅 |
| 想转影视的 | 救猫咪 15 拍 |

可以混搭：比如"用三幕结构组织全书，但每卷用网文升级流的节奏"。
