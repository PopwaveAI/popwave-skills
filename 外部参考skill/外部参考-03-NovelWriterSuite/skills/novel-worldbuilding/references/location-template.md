# 地点文件模板

```markdown
---
name: "{地点名}"
type: {city / fortress / wilderness / village / dungeon / virtual / other}
region: {所属区域 / 大陆 / 国家}
status: {active / ruined / hidden / unknown}
notable-characters:
  - {character-id-kebab}
  - {character-id-kebab}
linked-systems:
  - {system-id-kebab}
tags:
  - {tag-1}
  - {tag-2}
---

# {地点名}

## 物理描述与氛围

<!-- 让读者能"看见"的细节：建筑风格、地理特征、典型的视觉/声音/气味 -->
<!-- 1-3 段，不要长篇大论 -->

## 历史

<!-- 跟主线相关的历史，不需要写出整个国家的史书 -->
<!-- 重点写：这地方为什么存在 / 经历过什么大事 / 当前为什么是这个状态 -->

## 居民文化与习俗

<!-- 谁住在这里 / 他们怎么生活 / 有什么独特的礼仪或禁忌 -->

## 主角的交互方式

<!-- 主角会在这里做什么 / 这地方对主角是什么意义（家 / 战场 / 中转站 / ...）-->

## 当前状态

<!-- 故事开始时，这地方处于什么状态 / 谁掌权 / 有什么待解决的问题 -->

## 注意点

<!-- 写本地场景时要记得的特征（比如"这里晚上不能出门"或"语言不通需要翻译"） -->
```

## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | 完整地点名 |
| `type` | ✅ | 地点类型，便于按类型分组 |
| `region` | 推荐 | 所属大区域，便于 graph view 聚类 |
| `status` | ✅ | 当前状态，会影响章节中的描述 |
| `notable-characters` | 可选 | 与此地相关的重要角色 |
| `linked-systems` | 可选 | 与此地深度绑定的体系（如某教派的总坛） |
| `tags` | 可选 | 自由标签，便于检索 |

## 命名建议

- 中文小说：地点名用中文（落雁城 / 天枢宗）
- 英文小说：kebab-case
- 避免：直接用真实地名（容易侵权），如必要应加修饰（"虚构的伦敦"→"虚构-伦敦"）
