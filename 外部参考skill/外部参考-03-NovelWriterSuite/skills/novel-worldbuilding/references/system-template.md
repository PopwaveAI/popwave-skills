## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | 完整体系名 |
| `type` | ✅ | 体系类型，决定模板侧重 |
| `status` | ✅ | core = 主线必读，supplementary = 辅助，hidden = 后期才揭露 |
| `practitioners` | 可选 | 使用此体系的核心角色 |
| `linked-locations` | 可选 | 与此体系深度绑定的地点（如某教派的总坛） |

## 网文常见陷阱

1. **力量没有代价**：导致"战力膨胀"和"爽不起来"。修真小说尤其要注意——升级太快没有阵痛 = 读者审美疲劳。
2. **规则边界模糊**：导致后期出现"为了剧情需要随意突破规则"，被读者吐槽"金手指打肿了脸"。
3. **体系内部矛盾**：等级 A 比等级 B 强，但主角到了 A 后却打不过 B 阶段的某个反派 → 设定崩塌。
4. **跟世界其他要素割裂**：力量体系存在但没人用 / 没有影响政治经济 → 假世界感。

建议在 `## 规则边界` 段写得越详细越好，作为日后 `novel-review` 战力崩坏检查的依据。
