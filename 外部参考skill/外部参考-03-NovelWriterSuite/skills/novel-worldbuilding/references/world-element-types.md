# 体系类型 —— 引导问题清单

每个体系类型对应一组针对性问题。在 `novel-worldbuilding` 创建体系时，根据 `type` 字段选用对应清单。

---

## 1. 修真体系（cultivation）

**核心问题**：
1. 力量来源是什么？（天地灵气 / 自身血脉 / 外丹 / 心境）
2. 修炼方法是什么？（打坐冥想 / 服食 / 战斗 / 顿悟 / 双修）
3. 境界划分？建议不超过 9 大境，每大境内分小层
4. 突破瓶颈靠什么？（资源 / 顿悟 / 试炼 / 杀戮）
5. 修炼的副作用？（心魔 / 寿元损耗 / 与世俗脱节）
6. 飞升 / 转世 / 终极境界长什么样？
7. 修真者跟凡人的关系？（隔绝 / 守护 / 统治 / 共存）
8. 宗门 / 散修的生态？

**常见模板**：
- 三花聚顶 / 五气朝元 / 元婴 / 化神 / 渡劫
- 九大境界 + 小层（如《凡人修仙传》）
- 词牌 / 灵根 / 法宝 / 阵法 / 丹药 五大支柱

---

## 2. 魔法体系（magic）

**核心问题**：
1. 魔法来源（神授 / 元素 / 血脉 / 知识 / 契约）
2. 施法方式（吟唱 / 手势 / 符文 / 仪式 / 意念）
3. 魔力是有限资源还是可再生？
4. 学习成本（天赋 / 师承 / 时间 / 价格）
5. 法系流派（元素 / 神圣 / 死灵 / 召唤 / 时空）
6. 反魔法 / 抗性的存在？
7. 跟科技 / 宗教的关系？
8. 法师社会地位？

**常见模板**：
- 西式：元素流（火/水/土/风/光/暗）
- 东式：阴阳五行 / 道法 / 巫蛊
- 现代魔法（《哈利波特》式学院制度）
- 科学魔法（魔法可推导可量化，如《魔法禁书目录》）

---

## 3. 异能体系（superpower）

**核心问题**：
1. 觉醒方式（天生 / 实验 / 异变 / 触发）
2. 异能分类（系统化 vs 一人一种）
3. 异能等级（评级体系？S/A/B/C/D？）
4. 副作用 / 限制（体力消耗 / 后遗症 / 不能用于某些目的）
5. 异能者比例（千分之一 / 万分之一）
6. 社会对异能者的态度（恐惧 / 利用 / 隔离 / 崇拜）
7. 反异能手段？
8. 异能跟科技的关系？

**常见模板**：
- 末日 + 异能（《全球高考》《魔王奶爸》式）
- 学院 + 异能（《一人之下》《学园都市》）
- 都市异能（《赘婿》《九星霸体》）

---

## 4. 科技体系（tech）

**核心问题**：
1. 科技水平参照（前工业 / 工业 / 信息 / 后人类）
2. 关键科技节点（哪几项决定了世界的样子？）
3. 科技差距（不同势力之间）
4. 科技的副作用（环境 / 伦理 / 社会）
5. AI / 机器人 / 生物科技 / 太空科技各自的状态
6. 科技的传播 / 控制（谁掌握 / 谁被禁止）
7. 与其他体系的关系（魔法 / 修真 / 宗教）

**常见模板**：
- 赛博朋克（高科技低生活）
- 蒸汽朋克
- 太空歌剧
- 后启示录 / 末日科技
- 硬科幻（科技自洽可推导）

---

## 5. 武学体系（martial）

**核心问题**：
1. 内功 / 外功 / 心法的区分
2. 招式数量 / 复杂度（武学谱系）
3. 武林等级（一流 / 绝顶 / 宗师 / 仙人）
4. 武学传承方式（师承 / 偷学 / 秘籍）
5. 各大门派 / 流派
6. 兵器与人的关系
7. 武学与江湖政治的关系
8. 突破瓶颈（顿悟 / 奇遇 / 死战）

**常见模板**：
- 金庸式（招式 + 内功 + 心法）
- 古龙式（重意境轻招式）
- 网文式（系统化等级 + 战斗力数值）

---

## 6. 政治体系（political）

**核心问题**：
1. 政体（君主 / 共和 / 帝国 / 联邦 / 神权）
2. 权力来源（血统 / 选举 / 武力 / 神授 / 财富）
3. 阶级结构（贵族 / 平民 / 奴隶 / 公民）
4. 权力的合法性来源
5. 内部矛盾（派系 / 阶级 / 地域 / 民族）
6. 外部关系（友好 / 敌对 / 朝贡）
7. 法律体系
8. 革命 / 改朝换代的可能性

---

## 7. 宗教体系（religion）

**核心问题**：
1. 神祇（一神 / 多神 / 泛神 / 无神）
2. 神祇是真实存在还是信仰对象？
3. 教义核心（救赎 / 来世 / 因果 / 自由）
4. 教会组织（教皇 / 主教 / 神父 / 信徒）
5. 与政权的关系（政教合一 / 分离 / 对抗）
6. 异端 / 邪教
7. 神迹 / 神职人员的能力
8. 宗教仪式与日常生活的渗透

---

## 8. 经济体系（economic）

**核心问题**：
1. 流通货币（金银 / 灵石 / 元素 / 信用积分）
2. 主要产业 / 贸易品
3. 阶级流动性
4. 关键资源稀缺度（粮食 / 燃料 / 法器 / 灵草）
5. 商人地位
6. 跨区域贸易
7. 经济危机 / 通胀的可能性

---

## 9. 军事体系（military）

**核心问题**：
1. 武装类型（冷兵器 / 火器 / 法术兵团 / 异能小队）
2. 编制（军 / 师 / 旅 / 队）
3. 兵源（征兵 / 雇佣 / 世袭）
4. 跟力量体系的关系（普通士兵 vs 强者）
5. 战争形态（正面对抗 / 游击 / 攻城 / 谋略）
6. 军中等级与升迁
7. 战略与战术习惯

---

## 选型建议

- 一本书的核心体系通常 1-3 个，不要一上来全建满
- 主线体系（核心）必须详细，副线体系（辅助）可以简略
- 体系数量 ≠ 世界观深度。深度来自体系之间的**互动**和**矛盾**
