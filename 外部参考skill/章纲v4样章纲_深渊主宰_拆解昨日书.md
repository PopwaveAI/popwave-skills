# 章纲 v4 样章纲 —— 表演脚本提纲

> 章纲 = 本章表演脚本提纲。两片输入（态=全书日志 · 向=本章钦定事件）+ 三块产出（一支定位 / 一张节奏流 / 三道考题）。零"按需读库"依赖。
> 两张样张：《深渊主宰·第一章》与《拆解昨日书·第一章》，验证同一张模板能否接住西幻与都市言情。

---

## 一、模板（章纲骨架·三块）

```
ch{NNN}《{章名}》（{推动位}）

【一支定位】
- 在幕/卷里的位置：{这一章往前推进到什么位，给后面的升级/转折留的缝}
- 剧情梗概：{1-2句}
- 本章目的：{塑造谁·施加什么·埋/收什么伏笔}

【一张节奏流】（3~5 拍，张力怎么一浪一浪推）
- 拍{N}：情绪到哪 → 用什么触发 → 接下文
- …每个拍只锁"情绪+触发+接下文"，不写对白、不写数字、不写物件来源

【三道考题】
- 本章爽点：{兑现哪种爽感}×{落在哪拍}
- 章末钩：{钩什么}（L{1-5}）
- 本章线动作：{推进/收/悬，一句话}
```

> 事实与数值不在章纲里——关键帧/硬度/禁止漂移在全书日志；事件细节在白描卡。章纲只留"节奏与落点"。

## 二、样章纲 A：《深渊主宰·第一章 夜雨（上）》

> 态源：全书日志走到"琥珀城贫民区·薇薇安喂昏迷的哥哥"。向源：本书白描钦定事件（雨夜·断粮·老狗防线·索西亚威胁·帮派火并逼近）。

```
ch001《夜雨（上）》（卷·开部第1章 / 贫民区生存基座）

【一支定位】
- 位置：把主人公生存环境的第一块地基立起来——他是谁（被巫师重伤昏迷的哥哥）、守他的是谁（八岁妹妹），外面是什么（贫民区的恶）。
- 梗概：断粮孤屋，妹妹一人守着昏迷的哥哥，面对人贩与火并的双重威胁。
- 目的：立"贫民生态+主角被困昏迷"这个起点；埋"哥哥被巫师重伤"的疑；也给"贫民区随时会死人"这个底色锚上悬念。

【一张节奏流】
- 拍1：压抑→靠作法(断粮+妹妹精打细算的恐慌) → 接"她决意要守住哥哥"
- 拍2：危机探头→靠老狗希斯逼退闯门的男人 → 接"只有它能护她"
- 拍3：抉择拉紧→靠"索西亚要卖她"的潜台词+她决然愿自卖救兄 → 接"比敌人先想一步，但更绝望"
- 拍4：外部失序压境→靠帮派火并/死人锁门 → 接"这个角落谁都不来管，压到章底"
- 拍5：收口钩人→靠门栓+雨夜杀声，哥哥仍昏迷 → 章末：她以命相抵也要救他的决劲，撞上"他会不会醒"

【三道考题】
- 本章爽点：不兑现"打斗爽"，兑现"共情决然"——最弱小的(八岁女童)对最坏的环境说出"卖也是我去卖"。落在拍3。
- 章末钩：他昏迷的原因(被巫师重伤)与"她愿自卖换救"的代价悬着（L3）。
- 本章线动作：贫民生态·主线（起）；哥哥昏迷之谜·暗线（埋）。
```

> 注意：这是"节奏与落点"样张——具体对白（喂粥/喊哥哥）、数字（粮袋斤两）、物件（糙米/陶碗）都留给 write；章纲不锁。

## 三、样章纲 B：《拆解昨日书·第一章 第365天》

> 态源：全书日志走到"现世·他消失满365天·今日是断桥等待的收束日"。向源：用户正文钦定事件（手办寄到/底座刻字揭幕/断桥之约·"念念等我"）。

```
ch001《第365天》（卷一·开篇 / 等待划上句点之日）

【一支定位】
- 位置：全书开篇——把"女主等了他一整年、今天放下"这个情感起点立起来，同时让"他的债/手办/断桥约"浮出水面。
- 梗概：一年之期到，她决定今天起不再去断桥；而他的手办与底座那句、"念念等我"的最后一条，让"放下"变得没那么简单。
- 目的：立"等待/放下"的情感张力；埋"手办刻字·留的扣"；为整本"他有没有真消失"埋第一根线。

【一张节奏流】
- 拍1：日常淡开→靠她醒来，明说是最后一天去断桥 → 接"今天要跟一年做个了断"
- 拍2：物件切入→靠手办寄到，硬生生把她拉回那个"约"→ 接"举起又放不下"
- 拍3：钩线亮底→靠底座那句"对不起。请忘了我"+断桥之约回响 → 接"他明明要她忘，可全是让人记的痕迹"
- 拍4：决断与余味→靠她真的去桥边/或不去的取舍，落到"等满一年"这个命数 → 章末：留白他是否会回来，+读她的动摇

【三道考题】
- 本章爽点：不兑现物质爽，兑现"情绪反转"——说好放下、又舍不得放。落在拍4。
- 章末钩：他到底是真消失、还是有什么没交代（手办刻字/断桥约）被撂在台上（L3）。
- 本章线动作：等待/放下·主线（起）；手办刻字·暗线（埋）。
```

> 注意：这是"节奏与落点"样张——具体情绪词/原对白（"念念等我"）、数字（365天）都不进章纲，只锁"放下又被拉回"这个节奏；对白与细节由 write 现演。

## 四、两张样张都成立 → 模板通用性成立

| 维度 | 深渊主宰 | 拆解昨日书 |
|:--|:--|:--|
| 题材 | 西幻·贫民生存 | 都市言情·情感等待 |
| 态（全书日志给） | 谁在哪儿、守谁、外面多恶 | 谁、等满一年、今天收束 |
| 向（白描钦定） | 断粮/狗防/索西亚/火并 | 手办/底座刻/断桥约/念念等我 |
| 章纲产出 | 5拍节奏+共情爽+走线 | 4拍节奏+情绪反转爽+走线 |
| 章纲"不锁" | 对白/数字/物件 | 原对白/数字/细节 |

**两张都体现同一件事**：章纲只回答"这一场节奏怎么排、落点在哪、给 write 出什么题"，事件细节与精确值全部不背——恰好是你前几轮一路收敛的那个方向。
