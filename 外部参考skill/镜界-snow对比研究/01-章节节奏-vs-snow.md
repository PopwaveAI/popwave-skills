# 01-章节节奏 vs pop-snow

> 镜界「01-章节节奏」与 snow 的微观对比。snow 侧对应能力：snow 无独立"节奏"skill，章节节奏规则当前散落在 pop-snow-write（节奏物理量/爽感公式）+ 用户 profile 玩法脑（每 30 秒新内容 / 事件间隔≤20行 / 事件密度 8-12 / 爽感≥1）。

---

## 一、镜界该 skill 有哪些提示词（全拆）

镜界把"章节节奏"做成了一组**可执行的量化硬尺**，共 7 个维度：

1. **字数与爽点密度**：每 300 字 ≥1 爽点/看点；每 500 字 ≥1 钩子；每 1000-1500 字 ≥1 完整悬念；目标字数允许区间 = 目标的 ±10%。
2. **叙事段长度**：叙事段 40-120 字（3-5 行手机屏）；对话段天然短不算；**连续 ≥3 个短段(<40字)并列连排 = 违规**；短段仅允许 3 类场景（开场 300 字反转金句 / 章末钩子最后一句 / 单章 ≤3 个爆点短段）；三分场景合计一章最多 5 个短段，超过即"堆砌电报体"；**审核硬阈值：60% 以上叙事段 <40 字 → 段落过碎，触发返工**。
3. **80/20 断章硬尺**：永远不要在一章里把本章故事讲完——写到 80%，留 20% 给下一章；章末必须断在 action-climax 那一刻（主角刚放大招尚未见效 / 刚拔刀尚未落下）。
4. **断章钩子轮换**：每章结尾至少一个缺口，且必须轮换、不能每章同一种悬念。给出 6 类钩子：悬念类（关键信息即将揭露）/ 危机类（强敌降临陷阱触发）/ 反转类（身份揭露敌友转换）/ 期待类（即将突破宝物到手）/ 情感类（误会将解告白回应）/ 信息类（重大消息系统提示）。**钩子必须在下一章前 1/3 处给反馈**——可以不完全回收，但要让读者感觉上一章的问题被正面处理了。
5. **节奏变化**：`紧张 → 缓解 → 新紧张 → 更紧张`；紧张场景短句加速（连续短句排比），抒情/思考放慢（长句+感官细节）；避免连续以"他/她"开头；长句用于环境/心理，短句用于动作/冲突。
6. **场景规范**：新场景前 100 字让读者知道谁在场、在哪儿、发生什么；场景转换必须有过渡，禁止毫无过渡跳地；切换通过感官细节建立新空间感。
7. **高潮前后规则**：大高潮前 3-5 章必须有线索埋设；爆发后 1-2 章必须写出改变（主线推进/人设成长/关系变化），不能直接跳下一个蓄压。

## 二、snow 对应环节定位

- **snow 定位**：章节节奏是 pop-snow-write 的"渲染前约束"的一部分，但**没有独立成节、没有量化硬尺**。
- snow 现有的节奏资产（用户 profile 玩法脑）：
  - 节奏物理量：事件间隔 ≤20 行 / 感官 ≤3 行 / 情绪 ≤2 行 / 事件密度 8-12 个 / 爽感 ≥1。
  - 爽感公式：压力→突破 / 弱→强 / 未知→揭示 / 被欺→反击，每章触发 ≥1 且有爆发感。
  - 默认快节奏：蓄力≤2段 / 信息≤3段 / 情绪≤2段；主角每章 ≥1 决策 +1 行动。
  - 章末追读（结尾制造追读欲望）；对"小冲突→快解决→强反馈"每 3-5 章 1 个爽点。

## 三、值得深挖的学习点（snow 可吸收）

### 🟢 A 级：结构性量刑尺（snow 最缺）
| # | 镜界提示词 | 为什么值得学 | snow 现状 / 吸收方式 |
|:-:|:--|:--|:--|
| A1 | **80/20 断章硬尺**（写到 80%，断在 action-climax：刚放大招未生效/刚拔刀未落下） | snow 有"藏九露一"理念但**没有把"断在哪"具象成可执行的时刻**。action-climax 断章 = 把高潮瞬间当断点，比"保留悬念"更具体、更好让子 agent 执行 | 写进 pop-snow-write 章末钩子约束：章末应断在"动作已发出/结果未揭晓"的最焦灼一刻，禁止一章写满闭环 |
| A2 | **钩子 6 类轮换 + 下一章前 1/3 必须反馈** | snow 的"不可提前吞并"只防抢戏，**不治"每章同一种钩子"的同质病**。6 类轮换防套路化；"前 1/3 反馈"保证读者的问题被正面处理（追读的兑现承诺） | 注入 pop-snow-outline 后1章钩子：增加"钩子类型轮换"检查——连续两章不得同类型；上一章钩子须在章前 1/3 有正面反馈动作 |
| A3 | **短段硬阈值返工机制**（连续 3 短段违规；60% 叙事段 <40 字 → 返工） | 这是**可自动检测的门禁**（类似 deai_gate.py），snow 完全没有段级量化门禁。手机阅读场景下车厢"电报体"是弃读主因 | 可扩展进 deai_gate.py 或 write 排版门禁：段长统计 + 连续短段检出 + 60% 阈值返工 |
| A4 | **高潮前 3-5 章埋线 / 高潮后 1-2 章写改变** | snow 在幕纲有"不能抢后续收益"，但**没有"高潮后必须写后效"的强约束**。镜界把"爆发后要落地改变"作为节奏规则（对应 snow 的事件分量/人物弧光） | 注入 pop-snow-review：大高潮章节验收时检查"是否写出后效（主线推进/人设成长/关系变化）"，否则打回 |

### 🟡 B 级：量化锚点（snow 可对齐数值）
| # | 镜界提示词 | 学习点 | 吸收方式 |
|:-:|:--|:--|:--|
| B1 | 每 300 字 ≥1 爽点 / 500 字 ≥1 钩子 / 1000-1500 字 ≥1 完整悬念 | snow 的"事件密度 8-12/章"是"事件级"粗粒度，镜界是**"字级"细粒度**，二者互补：以字数定密度更贴合手机滑动 | 作为 write 渲染的密度自查补充尺，与 snow 事件密度并存 |
| B2 | 叙事段 40-120 字；长句用于环境/心理，短句用于动作/冲突 | snow 有"感官≤3行/情绪≤2行"但缺"叙事段标准长度"。40-120 是手机屏 3-5 行的最佳可读区间 | 可写入 write 排版默认规范（软约束，非硬门禁） |
| B3 | 目标字数 ±10% 允许区间 | snow 用章字数由 outline 定，但**缺"容差区间"**，容易在 review 卡字数 | review 字数校验改为区间判定而非近似值 |
| B4 | 紧张场景短句加速 / 抒情长句延展 / 避免连续"他/她"开头 | snow 文风 DNA 管句式但无常量化节奏。短句/长句交替实质是"句长 CV"控制 | 可纳入 deai_gate 的"句长变化度"检测（已有段长 CV，可加句长 CV） |

## 四、snow 反补镜界 / 交汇点

- 镜界的节奏是**单一章节内的节奏**；snow 的优势是**卷级节奏**（幕功能位/卷纲定战略、事件分量质变级才独立成章、每 3-5 章小爽点）。两者是"微观节奏尺 + 宏观节奏结构"的互补关系，不冲突。
- 镜界"钩子 6 类"对应 snow"张力的多向出口"；snow 的"预设性未揭悬念台账"更深（跨卷交付计划），镜界缺"钩子台账"，二者可合并：钩子类型 + 悬置时长 + 触发条件统一记账。

---

## 五、结论 / 吸收建议

snow 当前节奏靠"理念+用量"，镜界靠"量化硬尺+返工门禁"。**最值得吸收的 3 点**：
1. **80/20 action-climax 断章** → 注入 write 章末钩子约束。
2. **钩子 6 类轮换 + 前 1/3 反馈** → 注入 outline 后1章钩子 + 连续性校验。
3. **短段 60% 硬阈值返工 → deai_gate.py 新增段级门禁**（机械化可自动判，符合去AI味工具定位）。

量化密度（300/500/1000字）与叙事段 40-120 字作为 write 软性自查尺补充，不设硬门禁。
