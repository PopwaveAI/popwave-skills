# 02-章节规划 vs pop-snow-outline

> 镜界「02-章节规划」——单章大纲的四段结构 —— 与 snow 的 pop-snow-outline（章纲）微观对比。snow 侧：章纲 = **叙事形态**（一段叙事正文，画面/对线/情绪/落点 + 重要信息三栏：上章承接/本章落定/下章钩子）；伏笔台账不设独立块、统一走全书日志；不使用"拍/节奏流"黑话，用这本书的人物事件说话。

---

## 一、镜界该 skill 有哪些提示词（全拆）

### 核心原则（5 条）
1. **小周期推进**：每 3-5 章完成一个小目标或悬念升级，主线不能停。
2. **伏笔不空转**：过渡段落的每一笔都为后文服务；**每章处理旧钩子的同时埋下新钩子，开启数量 ≥ 回收数量，新钩子上限 2 个且最好与刚回收的有因果关联**。
3. **角色有根**：每个选择来自"过往经历 + 当下利益 + 性格底色"；反派不降智，主角不突变圣人。
4. **聚焦**：一章推进一条主线，支线最多一条且必须服务主线。
5. **高潮管理**：大高潮前 3-5 章铺线索，爆发后 1-2 章写改变。

（附：冲突裁决链——已发布正文 → 最新事实提取 → 角色卡 → 世界书 → 伏笔记录 → 大纲）

### 章节大纲四段结构
1. **章节连续性**：上章钩子怎么接 / 本章起止时间地点 / 角色硬状态（位置、伤势、能力、持有物、已知信息）/ **章末必须落地的改变（信息/关系/物理/权力，至少 1 条）** / 上下文冲突时以哪条既有事实为准。
2. **当前任务**：一句话说明主角本章要完成的**具体可执行动作**；可附带一句"读者此刻在期待什么、本章怎么处理这份期待"。
3. **节拍序列**：按顺序列出本章事件/场景，**每个节拍标注其功能**（推进主线/深化关系/揭示设定/埋设伏笔/营造氛围）；不含正文和对话。
4. **伏笔操作**：
   - 开启（≤2，注明目标揭示章节 + 埋设方式：对话暗示/环境细节/角色行为）
   - 推进（注明 ID、状态变化、本章释放的新线索）
   - 回收（注明 ID、回收方式、对剧情影响）
   - 搁置（注明理由 + 下次规划窗口）
   - 健康度快照（可选，每 5 章评估一次：未揭示伏笔总数与平均悬置章数、超期伏笔、**沉睡 10 章以上的伏笔**）

### 红线
- 不用方法论术语，用这本书的人物/地点/事件说话
- 不提前写出正文或对话：大纲只写"做什么"，不写"怎么描写"
- **不编造不存在的伏笔 ID 或事实：每个推进/回收的钩子必须真实存在于已有记录中**

## 二、snow 对应环节定位

pop-snow-outline（章纲）——snow 的章纲是"没文风渲染的正文"，叙事形态一段 + 重要信息三栏，依赖全书日志（当前态快照）给出"剧情线与伏笔台账 / 还没揭的悬念 / 这一卷不许碰的"。

---

## 三、值得深挖的学习点（snow 可吸收）

### 🟢 A 级
| # | 镜界提示词 | 为什么值得学 | snow 现状 / 吸收方式 |
|:-:|:--|:--|:--|
| A1 | **当前任务 = 一句话可执行动作 + 读者期待处理** | snow 章纲叙事正文强在"这段写什么/落点"，但**没有显式要求"主角本章的核心可执行动作一句话 + 读者当下在期待什么"**。加了这一栏，章纲就有了"主角主动性"的硬锚（呼应 snow 主角每章 ≥1 决策+1行动） | 在 outline 章纲"重要信息"旁新增一栏：`当前任务（一句话可执行动作）+ 读者期待处理（本章如何回应此刻的期待）`。可并入叙事正文落点句，不另设块也可 |
| A2 | **伏笔操作四态台账**（开启/推进/回收/搁置）+ **健康度快照**（每 5 章：未揭示总数/平均悬置/超期/沉睡 10 章） | snow 的伏笔隐藏于全书日志"剧情线与伏笔台账"，章纲不设独立块。镜界把伏笔做成**每章可操作、可衡量负债**的台账，尤其"沉睡 10 章预警 + 每 5 章健康度评估"是 snow 全书日志缺的**量化债务尺**——防止伏笔越埋越多无人管 | 不强建独立块（避免推翻 snow"约束由正文驱动"设计），但可在全书日志的伏笔台账加**"悬置时长/沉睡预警"**两列，由 review 在更新全书日志时顺带维护；outline 在起章纲时读取预警项决定"本章是否推进/回收某条沉睡线" |
| A3 | **开启数量 ≥ 回收数量 + 新钩子与刚回收的因果关联** | snow 有"新伏笔≤2/至少推进一个旧伏笔"，但**缺"回收-开启因果关联"**。镜界用"新钩子最好与刚回收的有因果"保证剧情是链式推进而非并列堆线 | 注入 outline：新钩子优先选"从刚回收的旧钩子长出来"的，减少并列新线的堆积 |
| A4 | **章末必须落地至少 1 条改变（信息/关系/物理/权力）** | snow 有"每章至少一个明确变化"，但镜界把变化**类型化**（信息/关系/物理/权力）更可验收 | 写入 review 验收项：本章落地的改变属于哪类；四类皆无 → 判定"空转章"打回 |

### 🟡 B 级
| # | 镜界提示词 | 学习点 | 吸收方式 |
|:-:|:--|:--|:--|
| B1 | 节拍序列每拍标注功能（推进主线/深化关系/揭示设定/埋设伏笔/营造氛围） | snow 章纲事件序列是"谁做什么、发生什么转变"，加**功能标签**后每拍可审计（是否服务主线） | outline 叙事正文可选给事件补"功能"尾注，服务"聚焦/拒绝空转" |
| B2 | 角色硬状态四件套（位置/伤势/能力/持有物）+ 冲突裁决链 | snow 靠全书日志维护状态，outline 起章时按需读。镜界的硬状态四件套可作为 outline"是否漏查状态"的提示清单 | 并入 outline 的承接读——强调"硬状态/信息边界"是本章承接的必核项 |
| B3 | 支线至多一条且必须服务主线；小周期 3-5 章一闭环 | snow 卷纲已有"主线/支线暗线/世界观三类事件种子池"，理念同构；镜界把"聚焦"落到章纲粒度 | 无需新增，snow 已覆盖 |

## 四、snow 反补镜界 / 交汇点

- **snow 更强**：章纲的**叙事形态**（一段"给朋友讲故事"的正文）比镜界的"四段结构台账"更不容易被 agent 写成冷冰冰的清单 → snow 的"叙事流先行"是镜界"节拍序列"的有力进化方向。
- 镜界更强：**伏笔健康度量化** + **当前任务/读者期待显式锚定**。

---

## 五、结论 / 吸收建议

**最值得吸收 3 点**：
1. **伏笔沉睡预警 + 每 5 章健康度** → 进全书日志伏笔台账两列，review 维护、outline 决策触发。
2. **当前任务一句话 + 读者期待处理** → 补入章纲，强化主角主动性与读者期待管理。
3. **章末落地改变四类型（信息/关系/物理/权力）** → 进 review 验收，杜绝空转章。
（开启≥回收+因果关联、节拍功能标注，作为 outline 软约束并入。）
