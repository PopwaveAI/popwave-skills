# 03-章节写作 vs pop-snow-write

> 镜界「03-章节写作」与 then snow 的 pop-snow-write 微观对比。snow 侧：正文渲染 step（消费本章章纲 + 全书日志 + 前一章正文 + 文风 DNA → 渲染正文 → 落盘 → 门禁：字数门禁 + 去AI味 deai_gate[脚本机械化]）；snow 强在"叙事流给朋友讲故事 + POV 切换 + 文风 DNA 注入"。

---

## 一、镜界该 skill 有哪些提示词（全拆）

### 创作原则（14 条）
展示而非告知 / 价值观融进行为 / 人设三问（行动立三腿：经历、利益、性格底色）/ 配角有自己的算盘（遇到主角前就存在、离开主角后继续过）/ 节奏有呼吸感 / 章尾必有拉力 / 全员智商在线 / 关系变化需事件触发 / 欲望驱动（制造缺口→释放超预期）/ 五感具体化（每场景 1-2 种感官）/ 信息分层植入（基础信息靠行动带出，关键设定结合剧情节点揭示）/ 拒绝空转（每行要么推剧情要么塑人物）/ 高潮后有后效 / 每段有增量（新信息/态度/利益变化）

### 创作技法
- **场景驱动**：新场景前 100 字让读者知道谁在场、在哪儿、发生什么
- **场景分层**：感官设定（人/地/事）→ 角色行动 → 对话 → 内心反应 → 过渡到下一节拍
- **情感单一**：每个场景只有一个核心情感基调（对峙/温柔/压抑/热血），所有描写围绕它展开
- **行动桥接**：段落过渡用行动衔接，不用时间标记。"门在他身后咔嗒锁上"✓　"与此同时/过了一会儿"✗
- **对白功能化 + 辨识度**：每段对白推进情节或揭示角色；角色说话方式有辨识度（用词习惯/句长/口头禅/方言痕迹）
- **视角纪律**：POV 只能知道感知范围内的信息；禁止上帝视角直接写非 POV 真实想法/隐藏动机/远处同步/未来结果/世界真相；默认受限视角，切换 POV 前清晰场景边界，不在同一段跳头

### 人物行为推导（6 步，仅创作用，禁入正文）
当前处境 → 核心动机（最想要/最怕）→ 信息边界（知道什么/不知道/误判）→ 性格过滤（冲动/谨慎/阴险/果断）→ 行为选择 → 情绪外化（身体语言/表情/语气）。推导不出合理行为 = 前置铺垫不足。

### 读者心理学（5 条）
期待管理（释放时适当延迟增强快感/将失去耐心时立即反馈）/ 信息落差（读者比角色多知道一点=紧张，少知道一点=好奇）/ 锚定效应（先给参照再展示主角表现）/ 代入感维护（主角困境要有普遍性：被欺压/不公/被低估）/ 欲望钩子（每章至少一个"接下来会怎样"）

### AI 禁词（7 类，极细）
1. 废话黑名单 15 词：值得注意的是/总的来说/与此同时/不可否认/毫无疑问/显而易见/众所周知/由此可见/值得一提的是/综上所述/换言之/从某种意义上说/需要指出的是/不言而喻/毋庸置疑
2. 禁用句式："不是而是""虽然但是""不仅而且""第一第二第三"；禁用破折号——
3. 因果连词：因此/所以/于是/这意味着/也就是说——用行动推进不解释因果
4. 情感标签：他感到/他觉得/他不禁/他忍不住/他忽然意识到——用行动对话外化
5. 分析术语：核心动机/本质上/从根本上说/标志着/预示着
6. 惊讶标记词：仿佛/忽然/竟/竟然/猛地/猛然/不禁/宛如——每 3000 字不超过 1 次
7. 空洞强调词：非常/极其/十分/无比/格外

### 自检清单（10 项，落盘前逐条）
无废话过渡词 / 句长开头有变化 / 每段有目的 / 情绪靠行动不加标签 / 段长合手机阅读（无连续短段）/ 章末有钩子 / 字数在大纲区间 / 上一章钩子承接+状态无断裂 / 无上帝视角泄露 / 至少推进一个旧伏笔、新伏笔≤2

## 二、snow 对应环节定位

pop-snow-write：正文 step。输入「四样」= 本章章纲 + 全书日志 + 前一章正文（文气锚）+ 文风 DNA（每章必注入 ≥1，禁裸写）。渲染后跑字数门禁 + deai_gate 去AI味门禁。

## 三、值得深挖的学习点（snow 可吸收）

### 🟢 A 级
| # | 镜界提示词 | 为什么值得学 | snow 现状 / 吸收方式 |
|:-:|:--|:--|:--|
| A1 | **人物行为推导 6 步 + 明确禁入正文** | snow 有"人设三问"，但**没有把角色行为推导做成可勾选的 6 步链**。这条链把"为什么这个角色此刻这么做"从玄学变成可执行流程，且强调"推导不出=铺垫不足"倒查案情 | 写入 pop-snow-write 渲染前一步：关键场景先跑 6 步推导；推导卡壳 → 回 outline 补衔接。`核心=主角/关键角色每场景行为要有推导依据` |
| A2 | **读者心理学 5 条（期待管理/信息落差/锚定/代入感/欲望钩子）** | snow 有"藏九露一/爽感公式"，但**没系统化"读者-角色信息差管理"**。尤其"锚定效应（先给参照再展示主角表现）"是爽感公式之外的一层铺垫机制 | 并入 write/write 前置"读者视角"段落：本章信息差策略（读者比主角多知道还是少知道）+ 锚定参照（对抗强度/困难上限） |
| A3 | **情感单一（每场景一个核心情感基调）** | 场景级"一个基调"纪律防"五彩斑斓乱cue情绪"——snow 场景规范没有这条 | write 场景规范补：每场景锁定 1 个核心情感基调，描写全围绕它 |
| A4 | **行动桥接（门咔嗒锁上 ✓ / 与此同时 ✗）** | 具体到"不用时间标记、用行动衔接"的可执行句法，防"与此同时/过了一会儿"癌。镜界的句子级技法比 snow 细 | 纳入 deai_gate 禁词库（已含"与此同时"等）+ write 段落过渡规范 |

### 🟡 B 级
| # | 镜界提示词 | 学习点 | 吸收方式 |
|:-:|:--|:--|:--|
| B1 | 情感标签禁用清单（他感到/他觉得/他忽然意识到） | snow 靠 deai_gate + 标点修复，但"情感标签"类禁词需更全 | 并入 deai_gate 废话/情感标签黑名单 |

## 四、snow 反补镜界 / 交汇点

- **snow 更强**：文风 DNA 每章强制注入（镜界无独立文风源体系）；去 AI 味被系统化为 deai_gate 脚本门禁（镜界靠提示词黑名单）；POV 切换/镜头移动是 snow 特色（镜界强调"禁跳头"，snow 主张"适当转移 POV 是优点"——方向略有张力，可取镜界的"受限视角默认" + snow 的"必要时切换"平衡）。
- 镜界更强：**人物行为推导 6 步 / 读者心理学 5 条 / 场景级情感单一** 三块可落地的执行模板。

---

## 五、结论 / 吸收建议

**最值得吸收 3 点**：
1. **人物行为推导 6 步链**（当前处境→动机→信息边界→性格过滤→行为选择→情绪外化，且禁入正文）→ 进 write 渲染前一步。
2. **读者心理学 5 条**，尤其信息落差 + 锚定效应 → 进愿 write 读者视角设计。
3. **场景级情感单一 + 前 100 字信息清单 + 行动桥接** → 进 write 场景规范；情感标签类补充进 deai_gate 黑名单。
