# 06-黄金三章 vs snow（开篇能力）

> 镜界「06-黄金三章」vs snow 开篇能力微观对比。snow 侧：**无独立"黄金三章"skill**，开篇能力散在 pop-snow-seed（融合立项稿"更卖点源"）+ 用户 profile 开篇玩法（卖点主轴→6 种导语公式→黄金三句→完整导语→付费钩子策略）+ "从炸楼级事件切入"。snow 胜在**导语/卖点/付费钩子**，镜界胜在**前三章结构与情绪曲线**——二者正好互补成完整开篇法。这是全系列**最值得独立沉淀的一档**。

***

## 一、镜界该 skill 有哪些提示词（全拆）

**总纲**：黄金三章不是"三章把事讲清楚"，是"三章内让读者对主角产生牵挂"。**堆冲突不如堆情绪**（冲突让人紧张，情绪让人放不下）。读者要在前三屏知道：主角是谁、他缺什么、为什么他不该落在这个处境、下一步有什么值得等。

### 开篇 300 字

前 200 字主角出现并做第一个可见行动 / 前 300 字给出反常/落差/危险/利益/误会中至少一种钩子 / 第一章场景 ≤2、互动人物 ≤3 / **800 字内触发核心冲突**（不先铺世界观履历体系名词）/ 开头写具体事：谁在场、正发生什么、主角被迫面对什么。

### 第一章：展现落差（核心方法论）

新手错误：主角第一章被追杀/被退婚/被扔绝境，冲突够猛读者还是划走——**读者还不认识主角**，陌生人被刀架脖子没人关心。真正有效的第一章不是让危险发生，而是**让落差被看见**。

**落差公式**：`读者对主角的同情 = f(过去的地位 − 现在的处境, 地位的合法性)`。过去的地位必须有合法性（读者认可主角配得上：天赋/家世/努力）；现在处境必须"不该如此"（不是主角活该）。
**落差三要素**：①锚点（坠落前最高光时刻，一个具体画面：万人敬仰/家族第一/天才之名）②现状（坠落后最低谷，一个具体画面）③对比触发器（让锚点和现状在同一场景正面碰撞）。
**三种落差模式**：天赋坠落（玄幻，萧炎天才变废物）/ 身份颠覆（都市，特工变上班族）/ 认知反转（悬疑，普通人发现隐藏身份）。

### 第二章：特权信息（拉焦虑）

第二章真正的任务不是拉仇恨，是给出"**读者知道但其他人不知道的信息**"，产生上帝视角快感——读者手里捏着一把枪，知道下一幕会响，但不知道何时响，等待比哭喊更焦灼。
**四种特权信息**：身份（读者知道真实身份剧中人不知）/ 未来（知道即将发生什么）/ 能力（金手指出现但剧中人以为还是废物）/ 视角（上帝叙述给了剧中人不知的背景）。
**执行要点**：特权信息必须在**一个具体事件**中展示（非旁白）/ 金手指靠**行动效果**展现而非属性面板 / 最好与第一章落差直接关联 / 制造最少一层"观众知情、角色不知情"。

### 第三章：还小账，立新标（给满足+下期待）

很多作者第三章铺世界观开主线拉势力→读者弃。因为前两章读者憋了情绪等着看主角打回去用金手指验证预判，第三章不满足反而塞信息=被骗感。
**还小账 3 种**：力量验证（金手指完成一件小事别人做不到）/ 预判兑现（前面铺垫冲突第一次回应）/ 选择宣示（主动决定展现成长态度）。
**立新标 3 种**：时间标（可预期未来时刻：三年之约）/ 距离标（近在咫尺下一级目标）/ 状态标（可量化状态变更：三月内恢复三段斗之力）。**新目标必须 3-10 章内可达成**。

### 三章递进情绪曲线

`第1章 同情(落差被看见) → 第2章 焦虑(特权被握紧) → 第3章 满足+期待(小账被收回+新目标被放下)`。

### 高潮密度

小高潮每 2-3 章 / 中高潮每 8-10 章 / 大高潮每卷一个（前 3-5 章铺线索）/ 高潮后 1-2 章写后效（主线推进/关系变化/权力格局/角色状态）。

### 类型变体（5 种）

玄幻/都市/悬疑/系统流/无限流——每种给了第一章锚点形态、金手指形态、第三章目标、核心情绪四件套。

### 五条红线（绝对禁止）

300 字内无主角 / 第一章超过 2 场景 / 金手指靠旁白介绍 / 第三章开新地图推世界观 / 章末无钩子。

### 反模式诊断表（读者反馈→定位→方案）

"看了三章不知主角什么养样"→无锚点→第一章前500字加高光场景 / "金手指突兀"→无事件铺垫→金手指经具体事件展现 / "不知要干嘛"→无目标→加可量化短期承诺 / "追读低收藏行"→情绪曲线太平→查落差幅度/特权信息/小账力度 / "跳订高"→第三章开新线→推迟到第四章。

## 二、snow 对应环节定位

- snow **开篇能力散落**：seed 融合立项稿（卖点源/读者承诺）+ 开篇玩法（导语公式/黄金三句/付费钩子）；**缺"前三章结构（落差→特权→还账立标）+情绪曲线"这一套**。

- 层次：snow 开篇 = **第一章首要导语/卖点层**；镜界 = **前三章完整结构层**。

## 四、snow 反补镜界 / 交汇点

- snow 强在**卖点/导语/付费钩子**（AM 开篇的"钩读者付费"层），镜界强在**前三章结构/情绪**（留存层）。合并即完整开篇法：卖点定方向（seed）→ 导语公式列首句（用户 profile 玩法）→ 前三章走落差→特权→还账立标（镜界）。

- snow 备注：看着 mirror/镜界的"前 200 字主角出现"与 snow"开篇直接动作/感官"同构，可互相校准。

***

## 五、结论 / 吸收建议

**这是一档 snow 能力空白的富矿。最值得动作**：

1. **建议沉淀一个独立** `黄金三章/开篇` **能力块**（或并入 seed 开篇 step，做成"落差公式 + 特权信息 4 类 + 还账立标 + 三章情绪曲线 + 反模式诊断表 + 自检清单"六件套），对接 snow 现有"卖点/导语"上游。
2. **落差公式 + 落差三要素**是全系列最缺的第一章方法论，优先固化。
3. 开篇三章 review 用**情绪曲线验收**（同情→焦虑→满足+期待）。
4. 反模式诊断表并入开篇 review，用追读/跳订信号反查病灶。
