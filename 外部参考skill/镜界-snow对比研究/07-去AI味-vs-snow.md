# 07-去AI味 vs pop-ai-reduce-lite / deai_gate

> 镜界「07-去AI味」vs snow 的去AI味能力微观对比。snow 侧：pop-ai-reduce-lite（规则检测+分层改写+质控流水线 A/B/C 三模式）+ deai_gate.py（**脚本机械化门禁**：14 类零风险自动修复 + 9 项滥用检测[句号密度/破折号密度等]，阈值按千字归一化、用 6 本人书校准过）。snow 强在**可自动执行的脚本门禁**；镜界强在**提示词黑名单 + 反例→正例对照库**。

---

## 一、镜界该 skill 有哪些提示词（全拆）

**身份**：文字编辑，专门识别去除 AI 痕迹，让文字自然有网文人味。

**核心规则 5 条**：删废话（开场白/强调拐杖/过渡填充）/ 破模板（打散三段式、二元对比、排比）/ 变节奏（混合句长和开头、变换段尾）/ 信任读者（跳过过度解释手把手引导）/ 去金句（像名人名言的句子重写）。

**废话黑名单（15 词）**：与 03 一致（值得注意的是/总的来说/与此同时/不可否认…）。

**禁用句式**：不是…而是…改直述 / 破折号改逗号句号 / 虽然…但是…用内心吐槽替代 / 不仅…而且…打散两句 / 第一…第二…第三…改散句 / **连续"了"字**（他走了过去拿了杯子→他走过去端起杯子）。

**叙事恶习 9 条**：不替读者下结论（读者能推断的意图叙述者不得直说）/ 不写分析报告（禁"核心动机/信息边界/信息落差"）/ 不堆叠从句（一句 ≤3 从句拆分）/ 不重复"他/她"开头 / 不过度解释（情感时刻后不跟"他感到"）/ **控制惊讶标记词每 3000 字 ≤1 次** / **同一体感不连续渲染超两轮**（火在体内流动勿连挂两段）/ 禁止元叙事（不写"到这里算钉死了"编剧旁白）/ 空洞强调词（非常/极其/十分）。

**被动→主动**：杯子被他捏碎 → 他捏碎杯子；消息被传进城 → 消息传进城。

**副词删除**：他冷冷地说 → 用对话本身传达冷淡；她悄悄地走 → 她踮着脚尖，地板吱呀响。

**反例→正例速查表（11 条）**：如"虽然他很强但他输了"→"他确实强，可对面那个老东西更脏"；"全场为之震惊"→"老陈的烟掉在裤子上，烫得他跳起来"；"他不知不觉道"→ 直接写感叹内容。**核心：把抽象评价替换成具体动作画面**。

**其他 AI 模式 6 条**：系动词回避（被誉为东方明珠→是东方明珠）/ 三段式法则（不强行三组，两项或一项更自然）/ 刻意换词（用生僻同义词替换重复宁可别别扭）/ 虚假范围（避免"从 X 到 Y"除非真尺度）/ 过度限定（避免"可能大概也许某种程度上"堆叠）/ 被动句式回避。

**快速检查清单**：连续三句同长？打断 / 段落简洁单行结尾？变换 / 用了"此外/然而"？删 / 三段式？改两或四 / 有金句体质句子？重写。

## 二、snow 对应环节定位

pop-ai-reduce-lite（手工/复用润色）+ deai_gate.py（自动化门禁，挂 write 渲染收尾）。deai_gate 覆盖：英文标点混入修复、句号密度、破折号密度、重复开首等 23+ 项，但**多为"密度/标点类"机械化**；镜界补的是**"句级重写类"**技巧。

## 三、值得深挖的学习点（snow 可吸收）

### 🟢 A 级
| # | 镜界提示词 | 为什么值得学 | snow 现状 / 吸收方式 |
|:-:|:--|:--|:--|
| A1 | **反例→正例对照库（11 条，抽象评价→具体动作画面）** | deai_gate 能标"这句脏"但**不教 agent 怎么改得像人话**。这张表是"抽象评价→具体动作"的可复用改写范式（全场震惊→烟烫到跳起来） | 沉淀为 deai_gate 报告附带的**"改写范例库"**，agent 收到定位后按此范式重写（配合 pop-ai-reduce-lite） |
| A2 | **副词删除（冷冷地说→用对话传达冷淡；悄悄走→踮脚尖吱呀声）** | 抽象副词→感官/动作的具体化，是去AI味的高杠杆手段，现有 deai 报告未覆盖 | 新增 deai 检测项：高发抽象副词报告（若/地结构），引导 agent 转动作/对话 |
| A3 | **同一体感不连续渲染超两轮（意象域防重复）** | "火在体内流动"这类意象连续渲染两段以上是典型 AI 味，deai 无数值维度 | 新增 deai 检测项——意象域连续性（同感官意象相邻段落重复次数） |
| A4 | **去金句 / 信任读者 / 不替读者下结论** | deai 管标点机械错，**管不了"道理说破/金句上瘾"**这一层；镜界给了判断准则（像名言的句子重写） | 进 pop-ai-reduce-lite 重写层 checklist + deai 的"金句密度"参考项 |

|:-:|:--|:--|
| B1 | 连续"了"字 / 被动→主动 / 系动词回避 / 虚假范围 / 过度限定 | 并入 pop-ai-reduce 规则集（部分已在） |

## 四、snow 反补镜界 / 交汇点

- **snow 更强**：deai_gate 的**脚本机械化 + 阈值按千字校准 + 14 类零风险修复**远胜镜界纯提示词；且 snow 有"6 本人书回归实测"校准。镜界的反例正例库可回灌给 deai 当"rewrite guidance"。
- **分工**：deai 判"哪里脏"（机械化）+ 镜界范式教"怎么改成像人话"（重写层），合成一条完整去AI味链。

---

## 五、结论 / 吸收建议

**最值得吸收 4 点**：反例→正例改写范例库（抽象评价→具体动作）、副词删除机制、同一体感不连续渲染（意象域防重复）、去金句/不替读者下结论准则。前三者可进 deai_gate 扩展（报告项+范例），第四者进 pop-ai-reduce 重写层 checklist。
