# 08-长篇连续性 vs pop-snow-review（全书日志闭环）

> 镜界「08-长篇连续性」vs snow 的长篇记忆闭环微观对比。snow 侧：pop-snow-review（章日志"定了哪些事/动了哪些线" + 全书日志"当前态快照" + 退出档案），滚动"正文驱动 replace 只留最新"；outline/write 承接读全书日志。**两者理念高度同构**——都主张"写完提取事实、正文驱动记忆、近因强远因准"，但镜界把"写前状态包/写后提取标准"做成了更显式的清单。

---

## 一、镜界该 skill 有哪些提示词（全拆）

**核心原则（目标声明）**：不是让模型一次记住全书，而是把每章写作纳入**可追踪的状态闭环**。5 条：
事实优先于灵感（已发布正文>章节摘要>角色卡>世界书>伏笔记录）/ 写前做状态核对 / **写中不静默修补**（矛盾时给可接受因果解释或标待修，不硬盖）/ 写后更新记忆（提取真实发生事实）/ **近因强，远因准**（最近 1-3 章管语气情绪动作衔接；全书摘要世界书管硬设定因果链长期目标）。

**上下文优先级（7 级）**：已发布正文明确事实 → 最新章节摘要与事实提取 → 角色卡当前状态（关系/能力/伤势/持有物）→ 世界书规则（地理势力能力上限）→ 活跃伏笔与未解冲突 → 全书/卷/章纲 → 用户本轮临时要求。用户临时要求冲突时指出冲突给改法，不静默覆盖。

**写前状态包（8 项）**：时间线（上章结束/本章开始/场景间隔）/ 空间线（从哪里来/如何到/离开去哪）/ 角色状态（位置情绪伤势能力公开身份秘密目标）/ 关系状态（称呼信任敌意利益绑定有无事件支撑）/ 道具状态（谁持有/是否损坏/是否被看见）/ 信息边界 / 伏笔状态（本章回应推进回收暂压）/ 世界规则（能力科技制度地理是否允许本章事件）。**缺失关键信息用中性承接或计划中标待补，不编造影响后续的硬事实**。

**角色防乱**：关键行为 vs 最想得到/最怕失去/是否符合经历利益性格/信息是否足够/反常是否给压力误判伪装成长事件。关系变化需事件驱动。

**伏笔长线管理**：**每章至少处理一个旧钩子（回应/推进/误导/压住但给理由，四选一）**；新伏笔 ≤2 且与本章事件有因果；伏笔记录含（埋设章节/当前状态/下一次推进窗口/预计回收范围）；**超 10 章未提及→标沉睡伏笔**；回收时写清后果（谁知道了/谁受损/关系局势如何改变）。

**长篇审查清单（6 项）**：角色未突破信息边界 / 伤势消耗距离时间未忽略 / 能力世界规则未临时加码 / 道具金钱身份证据硬状态一致 / 上章钩子承接且章末留新缺口 / 本章新增事实可被写后提取。

**写后事实提取标准（7 类）**：**只提取正文明确发生的事实，不把大纲计划当既成事实**。优先记录：角色状态变化（位置伤势能力目标情绪秘密暴露）/ 关系变化（触发事件双方态度称呼利益绑定）/ 时间地点（开始结束时间重要场景）/ 道具资源（获得失去损坏转交发现）/ 伏笔（新埋推进误导回收沉睡）/ 世界规则（新揭示规则例外限制代价）。**结论：事实提取结果服务于下一章写作，而非读后感**。

## 二、snow 对应环节定位

pop-snow-review：每章闭环后半段（确认满意→章日志→更新全书日志），+ outline/write 承接读。snow 全书日志 = 当前态快照（在哪/人物/定死设定/剧情线伏笔台账/还没揭悬念/这卷不许碰的），"约束必须由正文驱动 replace，能由 agent 写前脑补未来"。

## 三、值得深挖的学习点（snow 可吸收）

### 🟢 A 级
| # | 镜界提示词 | 为什么值得学 | snow 现状 / 吸收方式 |
|:-:|:--|:--|:--|
| A1 | **每章至少处理一个旧钩子：回应/推进/误导/压住但给理由（四选一）** | snow 只说"至少推进一个旧伏笔"，比较窄；镜界给"误导"和"压住但给理由"两个弹性出口，防钩子要么收要么烂尾，更贴合长线管理 | 进 outline 章纲承接/全书日志伏笔台账处理方式枚举：回应/推进/误导/压住 |
| A2 | **写前状态包 8 项（时间线/空间线/角色状态/关系状态/道具状态/信息边界/伏笔状态/世界规则）** | snow 承接读出依赖全书日志，但**没有"动笔前逐项核对"的显式清单**，容易漏"道具/关系"这类轻量状态 | 强化 outline/write 承接读为 8 项核对清单，尤其是道具状态、关系状态两项 snow 常漏 |
| A3 | **伏笔记录字段（埋设章节/当前状态/下一次推进窗口/预计回收范围）** | snow 伏笔台账字段未标准化，镜界的 4 字段让观摩伏笔"该不该现在动"可判断 | 标准化全书日志伏笔记录字段，加"下一次推进窗口"供 outline 决策 |
| A4 | **写中不静默修补（矛盾给因果解释或标待修，不硬盖）** | snow review 有"冲突标注 + 打回"，但**写中"不静默盖旧事实"**纪律值得写进 write 红线——防止 write 为了自洽悄悄改设定 | 进 write 红线：发现前后矛盾时正文给因果或标待修，禁止用新设定硬盖旧设定 |

### 🟡 B 级
| # | 学习点 | 吸收方式 |
|:-:|:--|:--|
| B1 | 近因强远因准（近 1-3 章管语气情绪，全书摘要管硬设定） | snow 已有此设计哲学（前一章正文作文气锚 + 全书日志硬设定），无需新增，可写进 write 读序说明 |
| B2 | 写后提取 7 类只提正文事实 | 与 snow"全书日志约束由正文驱动"完全同构；可把 7 类作为 review 章日志模板的字段清单 |
| B3 | 上下文 7 级裁决链 | 与 04/09 的 6 级链同构（少了"世界书vs角色卡"顺序微调）；统一成 snow 全局裁决序列即可 |

## 四、snow 反补镜界 / 交汇点

- **snow 更强**：「当前态快照 + replace 只留最新」比镜界的"记忆库随写增长"更省 token、更不易漂移；「退出档案回收沉睡项」具备镜界没有的**记忆衰退管理**。
- 镜界更强：**写前状态包 8 项清单** + **伏笔处理四选一** + **写中不静默修补纪律**。
- 合并方向：snow 全书日志（状态快照主干）+ 镜界写前核对清单（读写两个视角）+ 伏笔四态处理（台账操作枚举）。

---

## 五、结论 / 吸收建议

**最值得吸收 3 点**：伏笔处理四选一（回应/推进/误导/压住）、写前状态包 8 项清单（重点补道具/关系两个易漏项）、写中不静默修补纪律（进 write 红线）。伏笔记录 4 字段 + 写后提取 7 类并入 review 章日志模板。
