# 09-设定一致性 vs snow（stage 力量体系 / review 设定检查）

> 镜界「09-设定一致性」审查规则包 vs snow 的设定一致性能力微观对比。snow 侧：pop-snow-stage 建力量体系刻度表（等级/上限/份额/是否定死），pop-snow-review 在验收时留意设定矛盾，但**没有独立的设定审查规则包**（力量体系 6 查/地图距离/势力制度/资源经济/信息释放）。

---

## 一、镜界该 skill 有哪些提示词（全拆）

**定位声明**：这是给"内容核验/世界观分析/改稿任务"使用的**规则包，不是最终审查入口**，最终判定由 agent 负责（即：规则包进入判断上下文，终审权在人/主控）。

**核心目标**：世界观规则必须**稳定、可追踪、有代价**；新设定不能只服务本章，不能绕开前文难题让旧冲突显得多余。

**事实优先级（6 级）**：已发布正文 → 最新章节事实提取与摘要 → 世界书/设定圣经 → 角色卡能力身份阵营持有物 → 伏笔记录未解冲突 → 大纲本轮临时要求。突破既有规则必须给出限制、代价或可接受解释。

**力量体系（6 查）**：等级（达使用门槛了吗）/ 消耗（体力灵力寿命金钱权限媒介冷却）/ 上限（超当前卷天花板了吗）/ 克制（有反制/失败条件/环境限制吗）/ 后效（留痕/伤害/债务/暴露风险吗）/ 向下兼容（新能力让旧能力旧困境旧胜利失去意义吗）。**主角能用新能力解决所有问题=体系有问题**。

**地图与距离**：移动/传讯/调兵/运输受距离时间资源权限约束；追问：从哪来到哪花多久 / 是否跨前文交通地理门禁通讯限制 / 场景切换有无过渡 / 同地空间关系稳定 / 天气季节昼夜政局宏观连贯。**没解释的瞬移即时传讯默认判风险**。

**势力与制度**：势力是利益规则系统非名字列表；权限（有资格进入调动吗）/ 奖惩（违约有代价吗）/ 利益（为什么支持阻挠沉默）/ 内部矛盾（统一立场还是派系）/ 弱点（强势力有成本弱势力有生存理由）。**势力行为不能只为主角让路**。

**资源经济**：来源/消耗/稀缺三问（货币如何兑换/谁控制供给/为什么不能无限获取）；本章消耗是否影响后续；交易治疗装备情报有价格风险。资源突然出现免费解决用完不影响后续→削弱世界可信度。

**信息释放**：单章新设定通常 ≤2 个 / 重要规则靠遭遇行动失败代价显露 / 例外规则出现前常规必须稳定存在 / 新名词过多时优先保留影响选择冲突的。科普段允许但必须在新领域/学习新体系/规则改变节点。

**冲突判定（5 条达则至少警告）**：与正文世界书角色能力时间线冲突 / 绕开既有难题 / 无明确代价限制后续影响 / 只本章生效 / 新名词挤压章节情绪行动。**严重冲突必须要求修订；轻微冲突可补丁解释，但补丁要能写进正文或世界书**。

**输出建议**：位置 / 冲突来源（引用既有事实）/ 严重性（严重警告提示）/ 改法（最小修复）/ 世界书更新（若新设定成立：名称首次出现章节适用范围例外条件后续影响）。

## 二、snow 对应环节定位

- pop-snow-stage：力量体系刻度表（等级/上限）——**存档层**。
- pop-snow-review：章节验收时留意设定，但缺标准体检包。

## 三、值得深挖的学习点（snow 可吸收）

### 🟢 A 级
| # | 镜界提示词 | 为什么值得学 | snow 现状 / 吸收方式 |
|:-:|:--|:--|:--|
| A1 | **力量体系 6 查（等级/消耗/上限/克制/后效/向下兼容）** | snow 力量体系刻度表关注等级/上限/份额，**缺"消耗/克制/后效/向下兼容"四个审查维度**——这几个正是"能力会不会失控/开挂/打脸"的关键 | 进 stage 力量体系表每档补"消耗/克制/后效"三列；进 review 能力使用审查用 6 查勾选 |
| A2 | **向下兼容测试（新能力让旧能力旧困境失去意义=越界）+ 主角能解决所有问题=体系有问题** | snow"不能抢后续收益"管的是**剧情层**，这是**能力层**的自洽闸，两者互补 | 进 stage 力量体系设计红线：加新能力前跑向下兼容 + 万能测试 |
| A3 | **信息释放量化（单章新设定≤2 / 例外前常规先稳）** | snow 有"信息分层植入"理念但无数值；≤2 是防"信息轰炸"的可控阀 | 进 write/review：单章新设定计数检查，超 2 提示 |
| A4 | **补丁须可写进正文或世界书** | 防 review 打"轻补丁"敷衍了事——要求补丁可落到正文或档案，真正闭环 | 进 review 冲突处理：补丁解释必须能在正文或设定库落地 |

| # | 学习点 | 吸收方式 |
|:-:|:--|:--|

## 四、snow 反补镜界 / 交汇点

- snow 生存干的是**"设定怎么建"（stage 长档尺）**，镜界 09 是**"设定怎么查"（一致性规则包）**——正好是建/查闭环。配 10 世界观设定的"设计方法论"，三者合成：设计（10）→ 存档（stage）→ 审查（09/review）。

---

## 五、结论 / 吸收建议

**最值得吸收 3 点**：力量体系 6 查（补消耗/克制/后效/向下兼容四维度）、"向下兼容+万能测试"能力自洽闸、单章新设定≤2 + 补丁须可落进正文/设定库。09 本身可沉淀为 snow 的设定审查规则包（配合 10 世界观方法论 + stage 存档，形成设定三件套）。
