# 13-图像生成工具指南 vs snow（pop-visual-style / shared / asset）

> 镜界「13-图像生成工具指南」vs snow 视觉栈微观对比。snow 侧：pop-visual-style（37 种画风 DNA 库 + 3 光照模板 + **6 段式提示词结构** + Seedream API）、pop-visual-shared（共享资产：提示词指南/参考搜索）、pop-visual-asset（从原文提取角色档案/场景资产/视觉符号）。snow 视觉**系统化更强**（画风 DNA 库/定妆/资产提取），镜界这里以**命令层 + prompt 要素层**为主。

---

## 一、镜界该 skill 有哪些提示词（全拆）

**图像命令三类**：`character-avatar`（角色头像 1024×1024 方形）/ `character-photo`（角色照片 864×1536 竖版）/ `item-photo`（物品照片 864×1536）。写 prompt 前**先 Read 小说信息（题材/风格）或角色卡（外貌/标志性元素），不要用通用套路硬填**。

**角色与物品 Prompt 要素（按需组合）**：主体（谁/什么在中心）/ 构图（全身半身特写俯仰眼）/ 光线（顺逆侧黄昏夜景烛光）/ 色调（冷暖高饱和脱色对比强）/ 风格（写实水墨赛博油画漫画概念）/ 镜头（广角长焦浅景深）/ 限制（no watermark、普通图 no text）。

**角色视觉一致性**：同一角色多次出图，prompt 须保留**外貌锚点（发色、发型、服饰特征、标志性配件）**；**有角色卡必须先读取，不凭空描述外貌**。

**地图设计（先建地点树再出图，重点）**：
1. 读目标世界 + `/locations`，确认 world/现有地点/层级/描述（world ID 须从 Read 结果复制）。
2. 结合设定规划尺度/地貌/势力/水系/道路关隘，优先复用已有地点。
3. 地点树不足 → 缺信息实质改变方案时提问停止；用户"你决定"才自行 Create；否则先给方案等确认。
4. **调用 Run 前核对：prompt 中每个具名地域/城市/地标/河流/道路都已存在于地点树；地名/数量/父子关系/方位/河流流向/道路端点一致（世界名不自动代表地域数量）；地名逐字复制 Read 结果，不得让图片模型发明只存在于 prompt 中的新地名**。
5. 完整中文地图 prompt：画幅尺度/空间骨架/具名地点及相对位置/水系交通/标签层级/禁止元素；清晰中文地名，不套普通插画 no text 限制；**prompt 不写画风，画风通过 style 单独提交（Parchment/inkmap/engraving/realistic/woodcut/watercolor/atlas/custom）**。

## 二、snow 对应环节定位

pop-visual-style（文生图调度：画风 DNA 库 + 6 段式提示词结构 + 光照模板）；pop-visual-asset（视觉资产提取/字符短档）；pop-visual-oc（立绘定妆）。snow 视觉核心在"画风 DNA 与冻结提示词"，镜界核心在"命令参数 + prompt 要素 + 地图数据结构"。

## 三、值得深挖的学习点（snow 可吸收）

### 🟢 A 级
| # | 镜界提示词 | 为什么值得学 | snow 现状 / 吸收方式 |
|:-:|:--|:--|:--|
| A1 | **地图 prompt 不得发明设定库不存在的具名元素 + 地名逐字复制** | 这条把"视觉生成"和"世界设定库"硬绑定：图片模型不得发明只存在于 prompt 的新地名，地名从 Read 逐字复制。snow 出图（尤其场景图/地图）也应遵循"真源优先，不即兴发明具名地理" | 进 pop-visual-style/shared 红线：生成场景/地图图时，具名地点/势力/地标必须来自设定库，逐字复用，禁止 AI 发明不在真源里的具名元素 |
| A2 | **角色视觉一致性 = 外貌锚点（发色/发型/服饰/配件）+ 有角色卡先读不凭空描述** | snow 用"冻结提示词 + 定妆图"保证一致性，原理相同；镜界把"锚点必须显式列出 + 有卡先读"作为 prompt 前置纪律 | 可作为 pop-visual-style 的一致性检查项：出图前列锚点字段 ，确认已读角色卡 |
| A3 | **prompt 七要素 + 画风独立提交（prompt 内容与画风分离）** | snow 的 6 段式提示词结构已含此理念；镜界再次印证"画风不写进内容 prompt、单独给 style" | 无需新增（snow 已有），可作提示词指南补充清单 |

### 🟡 B 级
| # | 学习点 | 吸收方式 |
|:-:|:--|:--|
| B1 | 先 Read 小说信息/角色卡，不用通用套路硬填 | snow 已内化为"读资产再出图"，无新增 |
| B2 | 地图先建地点树、缺关键信息请示用户 | 对应 snow 视觉"参考搜索+理解确认"两步，无新增 |

## 四、snow 反补镜界 / 交汇点

- **snow 更强**：37 画风 DNA 库 + 定妆图 + 视觉资产提取 + 多 skill 共享层，整体系统化远胜镜界的"命令+要素"层。
- 镜界可补 snow 一条：**图像生成与设定库硬绑定（不发明具名元素）** + **锚点显式清单**。

---

## 五、结论 / 吸收建议

**最值得吸收 2 点**：①图像/地图 prompt 不得发明设定库不存在的具名元素（地名逐字复用真源），进 pop-visual-shared 红线；②角色视觉一致性"外貌锚点 + 先读角色卡"作为 pop-visual 出图前置检查项。
