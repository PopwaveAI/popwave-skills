# 图像生成工具指南

## 图像生成命令

通过 Run 工具生成图像：

```json
{"command":"image","subcommand":"character-avatar","options":{"character":"<id>","prompt":"<text>","image":"<path>"}}
{"command":"image","subcommand":"character-photo","options":{"character":"<id>","prompt":"<text>","image":"<path>"}}
{"command":"image","subcommand":"item-photo","options":{"item":"<id>","prompt":"<text>","image":"<path>"}}
```

- **character-avatar**：角色头像（1024×1024，1:1 正方形），需在 `options.character` 传角色 ID
- **character-photo**：角色照片/插画（864×1536，9:16 竖版），需在 `options.character` 传角色 ID
- **item-photo**：物品照片/插画（864×1536，9:16 竖版），需在 `options.item` 传物品 ID

读取上下文时先用 Read 获取小说信息（题材、风格）或角色卡（外貌、标志性元素），再动笔写 prompt，不要用通用套路硬填。

## 图像类型选择

| 需求 | 命令 |
|---|---|
| 角色肖像/头像 | `{"command":"image","subcommand":"character-avatar","options":{"character":"<id>","prompt":"..."}}` |
| 角色照片/插画 | `{"command":"image","subcommand":"character-photo","options":{"character":"<id>","prompt":"..."}}` |
| 物品照片/插画 | `{"command":"image","subcommand":"item-photo","options":{"item":"<id>","prompt":"..."}}` |
| 小说地图设计 | 按下方"地图设计"流程调用 `Run map draft` |

## 地图设计

地图设计必须先形成可维护的地点树，再提交图片草案。图片 prompt 不能替代地点数据。

严格按以下顺序执行：

1. 使用 Read 读取用户引用的世界，再读取 `/locations`，确认目标 world、现有地点、层级与描述。world ID 必须从 Read 结果复制，不得猜测。
2. 结合现有设定规划地图尺度、地貌骨架、地域与势力分布、水系、道路和关隘。优先复用已有地点。
3. 若地点树不足：
   - 缺失信息会实质改变方案时，向用户提问并停止；此时不要 Create，也不要调用 Run。
   - 用户明确表示"你决定""自行设计"等时，先简要给出方案，再按父级到子级使用 Create 建立所需地点，无需重复追问。
   - 其他情况先给出方案并等待确认，确认后再 Create。
4. 创建或修改后再次使用 Read 读取 `/locations`。调用 Run 前必须核对：
   - prompt 中每个具名地域、城市、地标、河流和道路都已存在于目标世界的地点树中；无名山脉、森林等纯视觉元素除外。
   - 地名、数量、父子关系、方位、河流流向和道路端点彼此一致。世界名称不自动代表地域数量；若方案声明了数量，必须与地点记录一致。
   - 地名逐字复制 Read 结果，不得让图片模型发明只存在于 prompt 中的新地名。
5. 核对通过后，编写完整中文图片 prompt，依次写清画幅与地图尺度、空间骨架、具名地点及相互位置、水系与交通、标签层级和禁止元素。地图需要清晰中文地名，不要套用普通插画的 `no text` 限制。prompt 中不要写画风；画风通过 `style` 单独提交，制图师会在真正生成图片时使用当前选择的风格。
6. 最后只调用一次：

```json
{"command":"map","subcommand":"draft","options":{"world":"<引用世界 ID>","prompt":"<完整中文地图内容提示词>","style":"parchment","resolution":"2k","quality":"medium","include_locations":true,"reference_current_image":false}}
```

- `style`：`parchment`、`inkmap`、`engraving`、`realistic`、`woodcut`、`watercolor`、`atlas` 或 `custom`
- 自定义画风使用 `style: "custom"`，并通过 `custom_style` 提交完整画风描述
- 地图 prompt 只描述地图内容，不重复写画风；画风通过 `style` 单独提交
- `resolution`：`1k`、`2k` 或 `4k`
- `quality`：`low`、`medium` 或 `high`
- 除 `world`、`prompt` 外均可省略；但 `style: "custom"` 时 `custom_style` 必填。不确定时使用 `Run help map`
- `map draft` 只把设计交给制图师审阅，不生成或采用图片。地图任务不要调用 `Run image`

## 角色与物品 Prompt 写法

有效的 prompt 需要以下要素（按需组合）：

- **主体**：谁/什么在画面中心（人物、建筑、场景）
- **构图**：全身 / 半身 / 特写 / 俯视 / 仰视 / 远景
- **光线**：顺光 / 逆光 / 侧光 / 黄昏 / 夜景 / 烛光
- **色调**：冷色 / 暖色 / 高饱和 / 脱色 / 对比强烈
- **风格**：写实 / 水墨 / 赛博朋克 / 油画 / 漫画 / 概念艺术
- **镜头**：广角 / 长焦 / 浅景深
- **限制**：no watermark；普通人物或物品图通常写 no text，地图按"地图设计"的标签规则处理

## 角色视觉一致性

- 同一角色多次出图时，prompt 须保留外貌锚点：发色、发型、服饰特征、标志性配件
- 有角色卡时必须先读取，不凭空描述外貌
