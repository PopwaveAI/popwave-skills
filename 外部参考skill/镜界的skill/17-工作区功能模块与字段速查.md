# 工作区功能模块与字段速查

> 本文档非小说正文，是 Mirroric 工作区可操作模块的参考速查，供作者查看 AI 在创作时读写哪些数据。

## 一、底层原理概览

工作区是一套**按类型组织的结构化知识库**，不是一堆自由 markdown 文件。

- 大部分集合（角色、伏笔、关系、章节、卷、大纲、地点等）用**带类型字段**存数据，程序靠字段语义做查询、关联、生命周期追踪。

- 只有少数**内容类字段**（世界观正文、章节正文、状态快照正文、资料正文）用 markdown 承载可读文本。

- 关系图谱是纯图结构数据（有向边），角色/伏笔等是对象数据，正文是文本数据。

## 二、路径语法

- 集合列表：`/{集合}`，可带过滤 query，如 `/chapters?chapter_num=1`、`/lore?search=关键词`

- 单例：`/novel`

- 按 ID 寻址：`/chapters/{id}`、`/characters/{id}`、`/foreshadowing/{id}`、`/locations/{id}`、`/relations/{id}`、`/volumes/{id}`

- 按标题寻址：`/skills/{标题}`、`/items/{标题}`、`/factions/{标题}`、`/creatures/{标题}`、`/lore/{标题}`、`/outlines/{标题}`、`/canvas/{名称}`；`/lore` 与 `/materials` 可多级

- 字段路径：`资源路径 + "/" + 字段名`，如 `/chapters/{id}/content`

- 子资源：`/outlines/{标题}/beats`、`/outlines/{标题}/beats/{index}`、`/canvas/{名称}/nodes`、`/canvas/{名称}/edges`

> 规则：路径中的 `{id}` 只能从工具返回结果原样复制，禁止自行生成；`{标题}`、`{名称}` 照抄 listing 原文。

| 字段                          | 说明    | 备注                                                                   |

| source\_type / target\_type | 实体类型  | character/faction/skill/item/location/chapter/foreshadowing/creature |
| source\_id / target\_id     | 实体 id | 原样复制，禁止拼                                                             |

> 关系建立后不可改写：要改就 Remove 后重新 Create。

## 四、关系图谱：合法关系类型

读法：`A --type--> B` 读作「A 是 B 的 <type>」；`[对称]` 两端可互换、只建一条；`[反读]` 类型名描述 target；`[动词]` 按字面读、source 是主语。

### character → character

| 类型               | 读作                      |
| ---------------- | ----------------------- |
| family           | A 与 B 有血缘/亲属 \[对称]      |
| sibling          | A 与 B 兄弟姐妹 \[对称]        |
| friend           | A 与 B 朋友 \[对称]          |
| enemy            | A 与 B 敌对 \[对称]          |
| lover            | A 与 B 恋人 \[对称]          |
| colleague        | A 与 B 同事/同门 \[对称]       |
| parent           | A 是 B 的父母               |
| grandparent      | A 是 B 的祖辈               |
| master\_disciple | A 是 B 的师父               |
| subordinate      | B 是 A 的下属（A 上级）\[反读]    |
| alter\_ego       | B 是 A 的化身/马甲（A 本体）\[反读] |

### character → faction

| 类型      | 读作         |
| ------- | ---------- |
| member  | A 是 B 的成员  |
| leader  | A 是 B 的首领  |
| founder | A 是 B 的创始人 |
| ally    | A 是 B 的盟友  |
| enemy   | A 是 B 的敌人  |

### character → skill / character → item

| 类型                             | 读作                  |
| ------------------------------ | ------------------- |
| learned / mastering / mastered | A 已学会/在学/精通 B \[动词] |
| creator                        | A 是 B 的创造者          |
| owner / user / former\_owner   | A 是 B 的持有者/使用者/前持有者 |

### faction → faction

| 类型          | 读作                |
| ----------- | ----------------- |
| ally        | A 与 B 结盟 \[对称]    |
| enemy       | A 与 B 敌对 \[对称]    |
| subordinate | B 是 A 的下属组织 \[反读] |

### skill → skill / item → item / creature → creature

| 类型           | 读作                |
| ------------ | ----------------- |
| prerequisite | A 是 B 的前置技能       |
| branch       | A 是 B 的分支流派       |
| evolves\_to  | A 进化为 B \[动词]     |
| part\_of     | A 是 B 的组成部分       |
| prey         | A 是 B 的猎物（B 捕食 A） |
| predator     | A 是 B 的天敌（A 捕食 B） |

> 易放反的四个：subordinate（source 是上级）、alter\_ego（source 是本体）、master\_disciple（source 是师父）、predator（source 是捕食方）。

## 五、可用命令 / 工具

| 工具                   | 用途                                                 |
| -------------------- | -------------------------------------------------- |
| Read                 | 读列表（可过滤）/ 读字段，分页读长文本                               |
| Write                | 覆盖已有资源字段（整表替换）                                     |
| Create               | 创建资源（角色/章节/卷/伏笔/大纲/关系等）                            |
| Edit                 | 替换字段中精确文本                                          |
| Replace              | 批量正则替换（改名、称谓统一）                                    |
| Remove               | 删除资源                                               |
| Glob                 | 按路径模式发现资源                                          |
| Grep                 | 在文本字段中搜索正则                                         |
| GraphSearch          | 沿关系图展开某实体的关联资源                                     |
| SpawnAgent           | 委派子代理（正文写手/编年史者/内容核验/文风润色/资料收集）                    |
| WebSearch / WebFetch | 联网搜索 / 抓取网页                                        |
| AskUser              | 向作者提问                                              |
| SuggestNextAction    | 挂下一步建议                                             |
| Run                  | 执行系统命令（agent-rules 管理规则、agent-skills 管理技能、novel 等） |
| AgentSkill           | 加载技能指令                                             |
