# 幕级套路拆解 · 项目说明

> 目标：从三本爆款成品书中，实证提炼可迁移的"幕级剧情设计套路模板"，供 `plot`（幕纲/卷纲设计）环节消费。
> 指导思想：一幕 = 一个主要事件的主体闭环（起点状态 → XXXX手段 → 终点状态的状态迁移，允许留伏笔），可塞入支线/过渡/信息章；一幕可双线主体事件；每个主要事件解决 = 一次大高潮；一卷 = 多个主要事件按强度递进构成。
