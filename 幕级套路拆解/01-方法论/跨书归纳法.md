# 跨书归纳法

> 阶段D：从三本书的同构拆解卡中，提炼可迁移的幕级剧情套路。

## 一、归一化前提

阶段B 的拆解卡全走统一 schema（`幕级拆解卡-模板.md`），三本书产出即"同构数据"，消除书名差异，才能横向比。

## 二、横向比对四步

1. **套路类型频次表**：汇总三本各类型出现次数。
   - 三本共有 → 强共性，可迁移性最高。
   - 只在一本出现 → 流派差异，单列不强行迁移。
2. **状态迁移模式比对**：抽共性骨架——"起点状态→手段→终点状态"的迁移形态（如"劣势受困→资源累积→翻盘跃升"在各类型的固定变体）。
3. **章配比区间比对**：支线/过渡/信息章占比三本各取区间，收敛出"健康幕"的配比参考带。
4. **高潮设计比对**：高潮触发器、蓄力手段、余波处理的共性手法。

## 三、分级提炼（L0/L1/L2）

| 层级 | 判定 | 去向 |
|:--:|:--|:--|
| L0 通用骨架 | 三本共有 | 直接进 plot 幕纲模板（`pop-qidian-plot/幕纲-模板.md`），最强可迁移 |
| L1 流派套路 | 两本/特定题材共有 | 进套路类型库，按题材/赛道取用 |
| L2 书专属 | 仅一本特有 | 仅作参考，不制成模板 |

## 四、产出物

- `跨书对比矩阵.md`：三本 × 维度（类型/状态迁移/配比/高潮/卷组装）对照表。
- `套路类型库.md`：每类型一条——定义/触发条件/适用场景/幕内节奏模板/推荐章配比/高潮设计/驱动机制/常见变异。
- `幕级剧情设计SOP.md`：最终可进 plot 的完整模板（由 L0 骨架 + 各类型变体拼装），输出到 `04-最终模板/`。
