# 《深渊主宰》卷组装分析

> 目的：从"一卷 = 多幕按强度递进"视角，拆解《深渊主宰》十卷如何把幕组装成卷、卷如何组装成书。
> 依据：复用拆书库《01-剧情线拆解》卷纲 + 《02-爽点拆解》卷密度 + 《10-标杆样板库》卷级结构 + 《幕盘点.md》幕序列。
> 强度口径：借鉴爽点密度（爽点/章），L1-L5 为单幕强度，卷级密度为整体口径。

---

## 〇、卷组装总览（全书骨架）

```
卷1 觉醒(0.88) → 卷2 封神(0.96) → 卷3 科技(0.90) → 卷4 深渊(0.89) → 卷5 双线(0.98)
→ 卷6 寻秘(0.88) → 卷7 蓄力(0.78) → 卷8 征战(0.98) → 卷9 亡灵(0.94) → 卷10 终局(0.99)
```

- **松紧交替骨架**：蓄力卷（卷6/卷7 低密度）与爆发卷（卷5/卷8/卷10 高密度）交替，用经营内容垫高下一个弑神大高潮的落差。
- **一卷一冲击波**：圣者浩劫冲击波（封神→元素→亡灵→血战）驱动每卷卷末弑神大高潮，卷末钩子指向下一波冲击波。
- **双线密度乘数**：卷5、卷10 以双主线并行把爽点密度翻倍（0.98/0.99），是全书爽感峰值所在。
- **卷功能位**：每卷一个功能位（觉醒/封神/科技/深渊/双线/寻秘/蓄力/征战/亡灵/终局），剧情线服务于卷功能。

## 二、卷组装手法总结

### 1. 卷末钩子手法类型清单（全书7种）

| 手法 | 代表卷 | 机制 | 强度 |
|:--|:--|:--|:--:|
| 身份翻转+降级紧迫 | 卷1 | 挡吸能术变杀戮者、降8级 | 危机型 |
| 威名升级 | 卷2 | 割喉者→斩首者 | 野心型 |
| 首次质变 | 卷3 | 首次弑神，天花板掀开 | 里程碑型 |
| 预告切换 | 卷4 | 死亡竞技场→恶魔线 | 舞台型 |
| 弑神收益+征兆前置 | 卷5 | 弑马拉+魔法女神坠落征兆 | 收获+预警型 |
| 布局预告 | 卷6 | 死亡三神合拢构想 | 蓝图型 |
| 神职转型+蓝图成型 | 卷7 | 阴影的主宰+神系蓝图 | 格局型 |
| 收益封顶+压力预热 | 卷8 | 强大神性+亡灵之灾酝酿 | 收获+预警型 |
| 悬念开启 | 卷9 | 死亡神系角逐开启 | 终极目标型 |
| 全书收束 | 卷10 | 升天重返神国 | 圆满型 |

**共性规律**：卷末钩子**必须指向前一卷的新局面、不能封闭**；且多采用"收益兑现 + 下一压力/目标预告"双钩，让收束既是旧闭环又是新开口。

### 2. 跨卷伏笔网（纵向贯穿）

- **神格标尺跳档**（贯穿全10卷）：微弱→弱等→中等→强大→伟大，每卷卷末以一次跳档收束，是全书最强的纵向价值链。
- **圣者浩劫冲击波**（贯穿全10卷）：封神→元素→亡灵→血战，一卷一冲击波，供给每卷弑神猎物。
- **双身份双线**（ch0016→0976）：本体神性经营 + 化身深渊武力，卷5/卷10两次会合，是全书结构创新线。
- **人物支线**（薇薇安/歌莉娅/安娜/索隆）：均从开局埋线、逐步成长、最终在卷10圆满回收，形成"主神+属神+王权+武力"闭环。

### 3. 强度曲线规律（卷级）

- **蓄力卷（卷6 0.88 / 卷7 0.78）**：经营/积累为主，为爆发卷垫落差，不可连续两卷。
- **爆发卷（卷5 0.98 / 卷8 0.98 / 卷10 0.99）**：弑神连发/双线齐爆，是全卷爽感峰值，必须接在蓄力卷之后。
- **节奏口诀**：数值做底盘、信息差做布局、打脸做单章爆发、弑神做大事件高潮、双线做密度乘数、情绪做缓冲垫；蓄力卷→爆发卷交替组装。
