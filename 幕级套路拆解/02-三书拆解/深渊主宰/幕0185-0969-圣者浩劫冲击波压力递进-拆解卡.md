# 幕0185-0969-圣者浩劫冲击波压力递进 拆解卡

> 阶段B产出：压力递进幕代表样本（大事件驱动）。走统一 schema。
> 对应盘点：跨卷压力递进序列（封神 ch0185 → 元素动乱 ch0801 → 亡灵之灾 ch0845 → 血战 ch0969）。
> 说明：这是《深渊主宰》作为"诸神黄昏大事件引擎"的**跨卷压力递进套路**，非单一线性幕，而是以"圣者浩劫冲击波"为母体的循环幕模型。用拆解卡schema解剖其内部骨架，供 plot 复刻"大事件压力逐级升级"。

## 一、幕边界识别

- 起始信号：**大事件冲击波宣告升级**——每波冲击波以"位面级异变 + 神职悬空 + 可猎杀目标现世"为起点（ch0185 吸血鬼神子封神、ch0801 元素动乱、ch0845 亡灵之灾、ch0969 浩劫末血战）。
- 收束信号：**冲击波被主角工具化消化**——主角借此弑神夺职、神格跃升、位面扩张，随后冲击波降温（ch0208 出海、ch0845 晋升强大神性、ch0980 浩劫落幕）。
- 是否跨卷边界：★★★★★（此套路天然跨卷，是连接各卷的纵向压力源）
- 幕前状态 → 幕后状态：**世界压力等级被动抬升（每次冲击波=一次位面级危机升级）→ 主角力量等级被冲击波倒逼抬升（弑神夺职追着危机走）**。

## 二、主体事件闭环（核心）

- **起点状态** → **XXXX手段（冲击波循环手段链）** → **终点状态**
  - 起点：圣者浩劫序幕拉开，诸神被能量风暴扫出神国、坠落凡间，神职悬空，神子现世，位面屏障不稳。
  - 手段链（冲击波循环五步）：
    1. **冲击波成形**：一个位面级大事件爆发（封神 / 元素动乱 / 亡灵之灾 / 血战）。
    2. **供给猎物**：冲击波必然制造一个可猎杀的神灵/神子/巨头（吸血鬼之神、恐惧魔神、巫妖之神、死者之王克蓝沃、深渊巨头奥喀斯）。
    3. **主角收割**：以猎杀→夺神职→神格跃升完成"借势蜕变"。
    4. **压力升级**：收割后世界压力不降反升，催生下一波更猛冲击波。
    5. **循环再启**：进入下一波冲击波，压力与主角力量同步上台阶。
  - 终点状态：浩劫落幕，冲击波耗尽，主角力量达位面顶点（伟大神性·死者之王），压力源与主角一并登顶。
- 主体事件数：**单主线+大事件驱动**（每次冲击波=一个主事件，整体构成压力递进链）
- 留伏笔清单：
  - 前一波冲击波的"神职悬空"未完全回收，为后续诸神争夺埋线（如死亡神职贯穿第九、十卷）。
  - 冲击波放出的"神子/神性"散落，部分供支线（薇薇安、莉莉安）在后续波回收。

## 三、套路类型归类

- 主类型：压力递进型
- 辅类型（亚型）：倒计时型 / 单次高潮型（每波各自一个高潮）
- 判定依据：压力源逐级升级——封神(L3)→元素动乱(L4)→亡灵之灾(L4/5)→血战(L5)，每波冲击波供给一个可猎杀猎物，构成"大事件压力递进 = 周期式弑神高潮发生器"（证据：ch0185/ch0801/ch0845/ch0969）。

## 四、幕内章配比

- 节奏结构：**冲击波爆发-应对蓄力-弑神收割-压力升级**。前段冲击波实景化（绝望感），中段主角蓄力/猎杀，末段弑神大高潮，余波引出下一波。

## 五、高潮设计

- 高潮点：每波冲击波的弑神夺职点（ch0471-72 首次弑神、ch0750 中等神力、ch0843-45 强大神性、ch0947-48 伟大神性）
- 高潮类型：**大事件解决 + 实力跃升 + 认知颠覆**（弑神夺职让力量标尺跳档）。
- 高潮前蓄力手段：**冲击波制造"凡力无解"的绝望 + 倒计时压力**（ch0801 海啸救城"凡力无解只能靠神迹"），垫高主角以一己救世的规格。
- 高潮后余波处理：**冲击波降温 + 立即预告下一波**（ch0845"亡灵之灾酝酿，再杀一强即强大神力"），把"事件解决"的松弛直接对接到下一段压力，保持张而不弛的连续压迫。

## 六、本幕在卷中的位置与功能

- 卷内第N幕 / 卷内强度位置：**跨卷主引擎**，贯穿全部十卷，每卷的卷末弑神大高潮都是其一次兑现。
- 与相邻幕的强度递进关系：冲击波强度随卷单调递增（封神→元素→亡灵→血战），主角力量标尺同步跳档（微弱→弱等→中等→强大→伟大），"压力-力量"双线同步上台阶。
- 本幕对"卷如何组装"的贡献：**纵向骨架**。它把孤立的卷拼接成整体——每卷卷末以"冲击波升级 + 弑神夺职"收束，卷间以"下一波冲击波预告"作钩子，实现"一卷一冲击波、冲击波驱动全书"的纵向组装。

## 七、可迁移要点（提炼给 plot）

- 幕级骨架可迁移点：**大事件压力递进幕 = 冲击波逐级升级 + 每波供给一个可猎杀目标 + 主角借势蜕变**。压力源与主角成长必须同频递进，否则会"爽感通胀"或"压力失控"。
- 手段链可复用范式：**冲击波形成→供给猎物→主角收割→压力升级→循环再启**；每波冲击波必须制造"凡力无解的绝望"来垫高主角救世规格。
- 章配比可参考区间：冲击波应对主线 55%-65%，支线 15%-20%，过渡 10%-15%，信息释料 8%-10%；"爆发-蓄力-收割-升级"四段节奏。
- 高潮设计可借鉴手法：**周期式弑神高潮发生器**——把"大事件"当"猎物供给源"，每次冲击波=一次稳定可预期的弑神大高潮；余波必须"降温 + 预告下一波"，保持连续压迫。
