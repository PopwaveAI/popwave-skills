# 幕0581-0659-恶魔崛起·双线并行 拆解卡

> 阶段B产出：双主线并行/会合幕代表样本。走统一 schema。
> 对应盘点：幕15「恶魔崛起·双线并行」（ch0581-0643，幕范围扩展至 ch0659 以覆盖双线各爆完整闭环）。

## 一、幕边界识别

- 起始信号：**主线切换 + 双线同时启动**——ch0581 恶魔化身索隆在古伦巴竞技场登场，本体索伦同时进入"伪装猎户布局弑神"的暗线（ch0581 双线并跑起点）。
- 收束信号：**双线各爆一次后的叙事回落**——ch0613 索隆进阶炎魔立足遗忘之地（A线落地），ch0657-0659 本体弑杀猎杀之神马拉（B线引爆），ch0659 弑神收益兑现、"命运轨迹被改变"，双线闭环完成。
- 是否跨卷边界：★★★★☆（卷五/卷六交界，第五卷 ch0581-0643、第六卷 ch0644-0706，弑马拉在 ch0657-0659 位于卷六开局，属幕内双线收束的自然越界）
- 幕前状态 → 幕后状态：**双线皆"蓄势未爆"（本体弱等神力布武、化身深渊菜鸟）→ 双线皆"兑现落地"（本体弑神夺职、化身立足深渊）**。

## 二、主体事件闭环（核心）

- **起点状态** → **双线并行手段链 + 会合点 → 终点状态**
  - 起点：本体索伦需神性/神格跃升（régime 猎杀神子转向猎杀真神）；化身索隆在无底深渊从最低贱怯魔起步，需立足。
- 手段链（双线各3步 + 1个会合）：
  1. **A线（化身索隆·深渊武力）**：ch0581 古伦巴竞技场死亡竞技连战 → ch0583-0591 连斩强敌积累威名 → **ch0610 会合点**：本体神灵亲自现身古伦巴竞技场、秒杀恶魔领主米亚米德·灾币 → ch0613 索隆裨益立足、进阶炎魔。
  2. **B线（本体索伦·猎神布局）**：ch0644前奏 伪装猎户、借刀杀人布局 → ch0650"我是索伦"震慑传奇圣武士（身份小爆）→ ch0657-0659 弑杀猎杀之神马拉、夺神职神格。
  3. **会合点章节**：ch0610（本体下场为化身铺路，双线物理/叙事上首次正面互馈）。
- 主体事件数：**双主线**
  - A线：化身索隆深渊立足（武力线）
  - B线：本体弑杀猎杀之神（猎神线）
  - 会合点：ch0610
- 留伏笔清单（本幕未闭合，供后续回收）：
  - 猎杀之神马拉虽弑，但神职归属/后续神系整合未展开（供卷七神系蓝图回收）。
  - ch0642 魔法女神坠落征兆浮现（引导卷六"逐神"支线）。
  - 化身索隆的深渊扩张仅立足，未达恶魔领主/王子（供卷八 ch0794、卷十 ch0972 回收）。

## 三、套路类型归类

- 主类型：双主线并行
- 辅类型（亚型）：双线交替爆炸型 / 博弈·智斗（B线布局弑神）/ 解密（"我是索伦"身份揭示）
- 判定依据：同一幕内 A线（深渊武力）与 B线（猎神布局）并头推进、各自独立引爆，且以 ch0610 为会合点互馈——完全符合"双主线并行需会合点"定义（证据：ch0581/ch0610/ch0650-0657）。

## 五、高潮设计

- 高潮点：ch0610（会合+秒杀恶魔领主）、ch0650-0657（本体布局弑马拉）
- 高潮类型：**实力跃升 + 身份反转 + 认知颠覆**——本体以神灵身份下场（身份揭示）、弑神夺职（实力跃升）、"我是索伦"震慑（认知转换）。
- 高潮前蓄力手段：**双线并行累积**——A线用死亡竞技连斩垫威名、B线用伪装猎户+借刀杀人垫信息差；两线各自蓄力到临界再分别引爆，形成"一个幕内两次大高潮"的密度翻倍。
- 高潮后余波处理：ch0659 弑神收益兑现（神性与神格）、"命运轨迹被改变"；随后切换至卷六"魔法女神坠落/逐神"新线，双线高密度后自然回落，避免爽感通胀。

## 六、本幕在卷中的位置与功能

- 卷内第N幕 / 卷内强度位置：第五卷核心幕 / **末段**（承接卷四恶魔线开局，推向卷六）。
- 与相邻幕的强度递进关系：较前幕（卷四 ch0541-0580 恶魔线萌芽）强度显著抬升——把"单线蓄力"升级为"双线齐爆"，密度冲到卷级 0.98（全书并列最高）。
- 本幕对"卷如何组装"的贡献：**引爆 + 换挡**。双线各爆一次，既兑现前卷埋下的双线承诺，又为卷六"东方寻秘"蓄力；是全书"双线密度乘数"手法的高光示范。

## 七、可迁移要点（提炼给 plot）

- 幕级骨架可迁移点：**双主线并行幕 = A线武力 + B线猎神/布局，两线各自独立闭环、以"会合点"互馈、双线各爆一次**。会合点不必是最终融合，可以是"本体下场为化身铺路"式的互惠。
- 手段链可复用范式：A线"竞技场死亡连战→威名→本体会合背书→立足"（养成+外援背书）；B线"伪装→借刀→震慑→收割"（信息差布局四步）。
- 章配比可参考区间：主线推进 65%-75%，支线 8%-12%，过渡 10%-15%，信息 5%-8%；双线交替推进是双主线幕的节奏底盘。
- 高潮设计可借鉴手法：**同幕双高潮 + 会合点前置 + 身份揭示**；用"双线各自蓄力到临界"替代单线单高潮，把密度翻倍但用余波卷切换防通胀。
