> 套路侧重：卷末弑神夺职大高潮 + 弑神收益集中兑现 + 亲情线（双子神座）参与高潮。

## 一、幕边界识别

- 起始信号：**大战集结**——ch0835 恐惧神国三路大军压境，从"神国征战"（剪羽剿孽/科技神国）切换到"决战恐惧魔神"。
- 收束信号：**双封神 + 强大神性落地**——ch0843-0844 双子神座（薇薇安夺【恐惧】神职、莉莉安得【纷争】神职同封神），索伦融合恐惧魔神力量、神性值350跃升强大神性。
- 是否跨卷边界：★★★★★（卷八卷末收束，钩子直指卷九亡灵之灾）
- 幕前状态 → 幕后状态：**中等神力（神系初建）→ 强大神性（一系之主，神性350）**。

## 二、主体事件闭环（核心）

- **起点状态** → **XXXX手段（3-5步手段链）** → **终点状态**
  - 起点：索伦已建神国/神系雏形（中等神力），恐惧魔神为首的大敌压境，需一战定乾坤。
  - 手段链：
    1. **大战集结**：恐惧神国三路大军压境（ch0835-0842）。
    2. **恐惧王座之战**：正面决战恐惧魔神，摧毁王座（ch0843）。
    3. **双子神座封神**：薇薇安夺【恐惧】神职、莉莉安得【纷争】神职，二人同封神（ch0843-0844）。
    4. **融合强敌**：索伦融合恐惧魔神力量，神性值350跃升强大神性（ch0845）。
    5. **收益兑现**：3200万杀戮经验 + 巨额神性神格（全书最肥弑神肉）。
  - 终点状态：强大神性 + 双子神座属神归位，神系完成一次大扩张。
- 主体事件数：单主线（但高潮由"弑神 + 双子封神"双目标叠加）
- 留伏笔清单（供后续回收）：
  - 亡灵之灾酝酿（ch0845），供卷九爆发。
  - "再击杀一个强大目标即可跻身强大神力"的缺口，供卷九/卷十逐级兑现（ch0900 巫妖之神、ch0917 奥喀斯）。
  - 双子神座（薇薇安/莉莉安）作为神系属神，后续神国征战/血战复用。

## 三、套路类型归类

- 主类型：压力递进型
- 辅类型（亚型）：单次高潮型 / 博弈·智斗（正面决战+多方博弈）
- 判定依据：卷末以"恐惧王座之战"这一大事件解决形成顶点，且弑神收益（3200万经验+强大神性）为全书之最——"大招型场面收益炸裂"（证据：ch0843-0845 名场面 L5）。

## 五、高潮设计

- 高潮点：ch0843-0845（恐惧王座之战 + 双子神座 + 强大神性）
- 高潮类型：**大事件解决 + 实力跃升 + 身份反转 + 关系圆满**（弑神夺职 + 双子封神亲情双圆满）。
- 高潮前蓄力手段：**多路大军压境制造决战规格 + 前卷全卷弑神连发的余威**（卷八 ch0776 秒杀剧毒女神、ch0801 神迹救城已铺垫"弑神连发"节奏）。
- 高潮后余波处理：ch0845 转入亡灵之灾酝酿，把"最肥弑神肉"的松弛立即对接到"下一目标"（再杀一强即强大神力），保持连发节奏。

## 六、本幕在卷中的位置与功能

- 卷内第N幕 / 卷内强度位置：第八卷第3幕 / **卷末**（第19、20幕为多峰铺垫）。
- 与相邻幕的强度递进关系：较前幕（剪羽剿孽/科技神国，多峰）强度再次抬升——从"连发小高潮"到"单一最大高潮"，密度冲至卷级 0.98。
- 本幕对"卷如何组装"的贡献：**引爆 + 换挡**。作为爆发卷（卷八）的收束大高潮，把全书弑神收益推到峰值，同时以"亡灵之灾"切换到卷九新压力线，完成"爆发卷→次卷蓄力"的交接。

## 七、可迁移要点（提炼给 plot）

- 幕级骨架可迁移点：**卷末弑神大高潮 = 多路大军铺陈 + 正面决战 + 收益炸裂兑现 + 附带角色登神**。高潮可叠加多条线（弑神 + 亲情/伴侣封神）让单一事件多目标兑现。
- 手段链可复用范式：**大战集结→王座决战→配角封神→融合强敌→收益兑现**；收益要"炸"（海量经验+神格+神职）让读者直观感受"这一仗值"。
- 章配比可参考区间：决战幕主线可高达 70%，支线 20%（情感线），过渡 10%，信息压到 0%——高烈度幕信息章趋零，节奏全押冲突。
- 高潮设计可借鉴手法：**收益集中兑现 + 双目标高潮**——一次弑神同时完成"主角跃升 + 配角封神"，让大高潮的满足感翻倍。
