# 幕001-031 穿越觉醒·值夜者入门 拆解卡

> 所属卷：卷1《小丑》·卷内第1幕 · 位置：卷首建套路段
> 深拆理由：题材承诺落地 / 建套路幕（采样策略"首卷幕×1"选点）

## 一、幕边界识别

- 起始信号：开篇"光怪陆离满是低语的梦境迅速支离破碎"，周明瑞在头痛中醒来却失去身体控制——穿越者身份与"占卜家"血脉觉醒同时引爆（ch001 绯红）。
- 收束信号：赐予"小丑"魔药、以"小丑"为题的晋升正式完成，主角由"被卷入者"转为"主动选择者"（ch031 魔药）。
- 是否跨卷边界：★（不跨卷，纯卷首起手）
- 幕前状态 → 幕后状态：现代社畜周明瑞（被动、失焦）→ 世界值夜者序列9占卜家（有职业、有身份、有目标）。

## 二、主体事件闭环（核心）

- **起点状态** → **谋定后动的入行手段链** → **终点状态**
- 手段链：
  1. 穿越觉醒：头痛+祷告+梦境，确认"他乡遇故知"的异世界身份（ch001-006）。
  2. 拜师入行：通过占卜能力被老尼尔/值夜者注意，加入值夜者小队，序列9占卜家（ch013-022）。
  3. 能力累积：灵视、占卜、仪式、封印物学习，配合"罗塞尔日记"谜团建立求知主线（ch023-031）。
  4. 第一次超凡任务初尝生死，验证"占卜不是万能的"，埋下能力边际警示（ch-X）。
- 主体事件数：单主线（"如何从穿越者活成序列者"）。
  - 若双线：无（单线贯穿）。
- 留伏笔清单（本幕未闭合的线）：
  - 罗塞尔日记与"亵渎石板"（ch059-060 引出，卷二回收）。
  - "占卜家"序列背后的古老隐秘与晋升代价（多卷累积）。
  - 值夜者/教会体系与超凡失控的底层规则。

## 三、套路类型归类

- 主类型：单主线闭环 · 收集/成长型
- 辅类型（亚型）：解密/推理型（罗塞尔之谜）+ 题材承诺（克苏鲁/维多利亚蒸汽+超凡）
- 判定依据：全幕以"能力累积+身份嵌入"驱动，无外部倒计时压力；开篇即定题材基调（一句话 + 证据章 ch001-006 穿越+ch013 入值夜者）。

## 五、高潮设计

- 高潮点：ch031 晋升"小丑"（序列8）。
- 高潮类型：实力跃升（序列质变）+ 身份确认（从"占卜家"到"小丑"）。
- 高潮前蓄力手段：能力铺陈累积 + 超凡任务试炼 + 罗塞尔之谜钩子叠加。
- 高潮后余波处理：以"新的能力"与"升职加薪"松弛，随即用塔罗会/新线索接续下一幕，避免松弛过长。

## 六、本幕在卷中的位置与功能

- 卷内第1幕 / 卷内强度位置：前段（建套路）。
- 与相邻幕的强度递进关系：为后面压力递进幕（幕3）提供"能力底盘"与"世界规则"。
- 本幕对"卷如何组装"的贡献：承上启下（开卷立题）+ 铺垫（题材承诺落地）。

## 七、可迁移要点（提炼给 plot）

- 幕级骨架可迁移点：穿越/入行类题材的"觉醒→拜师→累积→晋升"四段起手，是强承诺落地范式。
- 手段链可复用范式：身份嵌入（加组织）+ 能力累积（学技能）+ 谜团钩子（留未解信息）= 建套路三件套。
- 章配比可参考区间：主线 40-45%、支线 15-20%、过渡 20-25%、信息 15-20%。
- 高潮设计可借鉴手法：用"序列质变"作为首幕高潮，比打怪升级更能兑现题材承诺；余波用"新线索"而非"新敌人"接续。
