# 幕2-091-140 组织隐秘·心理炼金会 拆解卡

> 所属卷：卷2《无面人》·卷内第3幕 · 位置：卷中段
> 深拆理由：解密/推理型·组织隐秘幕代表（采样策略"解密推理型"选点）

## 一、幕边界识别

- 起始信号："心理炼金会"等隐秘组织线索浮出，克莱恩开始探查贝克兰德地下组织网络（ch091 心理炼金会的线索）。
- 收束信号：心理炼金会/亵渎牌等多条组织线被挖出，贝克兰德隐秘组织网成形（ch130 各自/组织蛛网成形）。
- 是否跨卷边界：★★（卷内中段，组织线多卷延续）
- 幕前状态 → 幕后状态：局外人（对贝克兰德地下组织一无所知）→ 卷入组织网络的知情者。

## 二、主体事件闭环（核心）

- **起点状态** → **顺藤摸瓜的组织探查手段链** → **卷入组织网的终点状态**
- 手段链：
  1. 线索偶遇：心理炼金会/学者/贵族等组织痕迹在日常事件中闪现（ch091-100）。
  2. 交叉追踪：借不同委托/线人/塔罗会情报，把零散组织线索串成网络（ch101-115）。
  3. 深入验证：潜入/观察/接触组织成员，确认组织目的与隐秘（ch116-125）。
  4. 卷入收束：克莱恩被确认为"知情者"，组织网成形，主角选择主动介入（ch126-140）。
- 主体事件数：主线+支线并织（心理炼金会主线 + 各方组织支线插花）。
  - 若双线：A线=心理炼金会探查，B线=亵渎牌/贵族隐秘支线；会合点=组织网成形。
- 留伏笔清单（本幕未闭合的线）：
  - 心理炼金会目的与后台（后续幕回收）。
  - 亵渎牌与塔罗牌面的对应关系。
  - 贝克兰德组织的多方角力格局。

## 三、套路类型归类

- 主类型：解密/推理型（组织隐秘逐步揭示驱动）
- 辅类型（亚型）：博弈/智斗型（多方组织角力）+ 主线+支线并织
- 判定依据：全幕以"组织隐秘的线索揭示"驱动，高潮=组织网成形（证据章 ch091 起→ch130 成形）。
