# 幕2-191-230 塔罗会多线并织 拆解卡

> 所属卷：卷2《无面人》·卷内第5幕 · 位置：卷中后段
> 深拆理由：塔罗会多线并织幕代表（采样策略"塔罗会多线并织"选点，全书差异化节奏资产）

## 一、幕边界识别

- 起始信号：塔罗会各成员（奥黛丽、佛尔思、休、埃姆林）进入各自成长线，与克莱恩主线并织（ch191 起访客/各线）。
- 收束信号：多角色线各自推进到节点，克莱恩主线穿线收拢，为卷末高压幕蓄势（ch230 一个人的表演/各线收束）。
- 是否跨卷边界：★★（卷内段落，多角色线多卷延续）
- 幕前状态 → 幕后状态：克莱恩单一视角主导 → 塔罗会多角色视角并织（世界的"群像"打开）。

## 二、主体事件闭环（核心）

- **起点状态** → **多线并织+会合的手段链** → **会合收束的终点状态**
- 手段链：
  1. 各线启动：奥黛丽贵族线、佛尔思/休佣兵线、埃姆林血族线等分别展开（ch191-200）。
  2. 塔罗会串场：灰雾塔罗会作为"会合机制"，让多角色线借委托/情报交汇（ch201-215）。
  3. 主线穿线：克莱恩作为"愚者"幕后引导，各支线对主线提供情报/资源/势能（ch216-225）。
  4. 会合收束：多条线在塔罗会/关键事件汇合，为卷末幕布下多点势能（ch226-230）。
- 主体事件数：主线+支线并织（克莱恩主线 + 多角色支线插花）。
  - 若双线：A线=克莱恩主线，B线=塔罗会多角色支线；会合点=灰雾塔罗会/关键事件。
- 留伏笔清单（本幕未闭合的线）：
  - 各角色（奥黛丽/佛尔思/休/埃姆林）命运线后续。
  - 塔罗会成员与克莱恩"愚者"身份的潜在张力。
  - 多线情报指向的卷末高压事件。

## 三、套路类型归类

- 主类型：主线+支线并织（塔罗会多线并织）
- 辅类型（亚型）：博弈/智斗型（多角色多方博弈）+ 多峰节奏
- 判定依据：全幕以"多角色视角交织+灰雾塔罗会会合"驱动，节奏为多峰（证据章 ch191-230 各线+塔罗会）。
