# 幕3-191-250 晋升"旅行家"序列4 拆解卡

## 一、幕边界识别

- 起始信号：晋升"旅行家"序列4的条件/仪式逐步明确，克莱恩进入高位晋升倒计时（ch191 起接近遗落之海/修道院）。

- 是否跨卷边界：★★★（卷末收束幕，部分钩子指向卷4）
- 幕前状态 → 幕后状态：序列5"秘偶大师"（低序列）→ 序列4"旅行家"（中序列，能力与视野质变）。

## 二、主体事件闭环（核心）

- **起点状态** → **高位晋升的序列检定手段链** → **终点状态**
- 手段链：
  1. 条件确认：借遗落之海/黑色修道院与古老隐秘，推理出序列4晋升的仪式与材料（ch194-200）。
  2. 试炼累积：在修道院/灵界/秘境中经受"序列检定"（能力、心智、意志三重考验）（ch200-220）。
  3. 材料与仪式集齐：多方资源（含塔罗会/信徒）汇聚，完成晋升前置（ch221-240）。
  4. 晋升执行：在临界点完成序列4晋升，能力质变（ch241-250）。
- 主体事件数：单主线（高位晋升）+ 附探索线（遗落之海/古老隐秘）。
  - 若双线：A线=序列检定/晋升，B线=遗落之海隐秘探索；会合点=晋升所需的知识与材料齐备。
- 留伏笔清单（本幕未闭合的线）：
  - 序列4身份与更高序列（序列3"古代学者"）的代价。
  - 遗落之海/古老隐秘指向的末日真相。
  - 高位晋升带来的"失控"与"锚"需求。

- 判定依据：全幕被"序列4晋升"这一倒计时目标牵引，晋级即高潮（证据章 ch191 起→ch250 完成）。
