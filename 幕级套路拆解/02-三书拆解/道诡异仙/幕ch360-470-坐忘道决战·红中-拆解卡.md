# 幕ch360-470-坐忘道决战·红中 拆解卡

> 阶段B产出｜本幕为"单主线大高潮（多峰→总决战）"样板，红中作为主角疯癫镜像登场。
> ⚠️ 章节范围为估算；原文引用为片段级证据。

## 一、幕边界识别

- 起始信号：与坐忘道的矛盾从"躲"转"打"，红中一系确立为阶段敌，主角由被动变主动（事件突变）。
- 收束信号：坐忘道势力被打到阶段性崩溃，红中身份/镜像指向浮出，单线大高潮收束（主体事件闭环）。
- 是否跨卷边界：★★★★☆（卷三为主，单线大高潮样板）
- 幕前状态 → 幕后状态：被迫与坐忘道周旋 → 主动讨伐并阶段性击溃坐忘道

## 二、主体事件闭环（核心）

- **起点状态** → **"讨伐坐忘道"手段链** → **终点状态**
- 手段链：
  1. 情报反制：摸清坐忘道"红中"体系与"心素"需求，转化敌情为己用；
  2. 势力杠杆：借大傩朝堂/门阀之力制衡坐忘道，多线博弈；
  3. 镜像设局：让坐忘道的"疯癫逻辑"与主角"病"形成对照，借对手的疯狂反衬自己的清醒/沉沦；
  4. 决战引爆：多峰小高潮逐级升级，最终坐忘道总决战；
  5. 收束落点：阶段性胜利，但留下"红中与你不同"的镜像暗示，指向自我认知的下一次颠覆。
- 主体事件数：单主线（讨伐坐忘道为主线，双线切换退为背景节拍）
- 留伏笔清单：
  - 红中"与主角一体两面"的镜像关系（幕9/10 收）
  - 坐忘道信仰背后与太岁/大傩的关联（幕8 收）

## 三、套路类型归类

- 主类型：单主线闭环
- 辅类型（亚型）：博弈/智斗型 × 多峰型
- 判定依据：本幕以"多方算计+信息差"的智斗为驱动，多个小高潮累积成总决战，属单主线多峰大高潮（证据：ch430-ch460 总决战）。

## 五、高潮设计

- 高潮点：ch430-ch460 坐忘道总决战
- 高潮类型：大事件解决（阶段敌清退）+ 身份/镜像指向（红中）
- 高潮前蓄力手段：多峰小高潮逐级加码、多方博弈升级、信息差（主角对红中认知的滞后）
- 高潮后余波处理：阶段性大胜后不放松，立刻用"红中与你不同"的镜像暗示把张力导向"下一个自我认知问题"，衔接更高层的终极冲突。

## 六、本幕在卷中的位置与功能

- 卷内第6幕 / 卷内强度位置：中段（卷三）
- 与相邻幕的强度递进关系：在幕5 双线会合的高点之后，收缩到"单线讨伐"的实体大高潮，是强度的一次实体峰值；为幕7（太岁之乱·压力递进）铺垫更大灾劫。
- 本幕对"卷如何组装"的贡献：**引爆**——单线大高潮证明本书不只靠双线技术，也能打正面决战；红中镜像为全书"自我认知"主题埋回扣。

## 七、可迁移要点（提炼给 plot）

- 幕级骨架可迁移点：单线大高潮幕可插在双线结构高点之后，用"实体决战"给读者一次"打得爽"的释放，避免双线全程悬着。
- 手段链可复用范式：「情报反制 → 势力杠杆 → 镜像设局 → 决战引爆 → 镜像暗示收束」。
- 章配比可参考区间：单线大高潮幕，主线推进 60%、信息章压到 10%，把篇幅让给战斗与博弈。
- 高潮设计可借鉴手法：用"对手=主角镜像"来让大决战同时承担"外部矛盾解决+内部自我提示"双重功能，一石二鸟。
