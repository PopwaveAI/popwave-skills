# 幕ch580-700-认知核爆·真相揭示 拆解卡

> 阶段B产出｜本幕为"认知颠覆型高潮幕（真相揭示）"核心样本，**全书最大认知颠覆**。
> ⚠️ 章节范围为估算；原文引用为片段级证据。

## 一、幕边界识别

- 起始信号：幕7 双重临界后，主角与读者对"哪个世界为真"的既有答案开始松动（基调转变）。
- 收束信号：**地府真相揭示**——现代病院实为地府/心素归宿，大傩世界才是"真实"，主角道路全盘反转（认知颠覆完成）。
- 是否跨卷边界：★★★★★（全书边界置信度最高，主题性终极反转）
- 幕前状态 → 幕后状态：默认"病院为假/大傩为真" → 病院(地府)为真规则须重估，主角的"病"与"归宿"被重新定义

## 二、主体事件闭环（核心）

- **起点状态** → **"真相揭示"手段链** → **终点状态**
- 手段链：
  1. 地府指向：病院里一直被忽视的"秩序/治疗"细节，累积指向"这里不是普通病院"；
  2. 白秀秀身份落地：两界同现的白秀秀给出统一解释，成为揭开地府真相的钥匙；
  3. 病院/大傩层级反转：把"病院=幻觉"的旧答案推翻，确立"病院(地府)为真、大傩为真"的双真新图景；
  4. 主角宿命预演：真相揭示同时给出"化道"的代价预告，让胜利与毁灭同构；
  5. 认知落点：主角与读者接受"真/假"的终极重估，全书主题从"哪边真"升维到"如何承担真"。
- 主体事件数：单主线（重心从双线技术转向终极解答，双线切换退为解释引擎）
- 留伏笔清单：
  - 太岁/大傩同源真相的最终层（幕9 收）
  - 李火旺"化道"宿命的具体代价（幕9 收）

## 三、套路类型归类

- 主类型：单主线闭环
- 辅类型（亚型）：解密/推理型 × 认知颠覆型高潮 × 单次高潮型
- 判定依据：本幕以信息揭示为唯一驱动，且高潮是"真/假"的世界观级反转，属认知颠覆型高潮幕（证据：ch660-ch690 地府真相揭示）。

## 五、高潮设计

- 高潮点：ch660-ch690 地府真相揭示
- 高潮类型：认知颠覆型（世界观级反转/真相揭示）
- 高潮前蓄力手段：全书级信息差（从幕1 起埋的"病院真实"伏笔）、两界层级反转的层层剥茧、多方证据互相印证
- 高潮后余波处理：揭示后立刻把"胜利"改写为"两难"（化道=代价），让读者在震撼中转入关底，不安排松弛。

## 六、本幕在卷中的位置与功能

- 卷内第8幕 / 卷内强度位置：中后段（卷四末/卷五）
- 与相邻幕的强度递进关系：由幕7 的极限存亡铺垫，把"生存危机"升维为"存在危机"（哪边真、我是谁），是全书强度曲线的顶点之一；为幕9 化道终局提供"必须牺牲"的必然性。
- 本幕对"卷如何组装"的贡献：**引爆/收束前置**——最大认知颠覆在此，之后全书进入"承担真相"的收尾段。

## 七、可迁移要点（提炼给 plot）

- 幕级骨架可迁移点：认知颠覆型高潮要靠**全书级信息差**累积（从首卷就埋），揭示时一次性炸开，且必须在炸开后立刻给出"两难"而非"胜利"，才不落俗套。
- 手段链可复用范式：「地府指向累积 → 关键角色身份落地 → 层级反转 → 宿命预演 → 认知重估」。
- 章配比可参考区间：认知颠覆幕，信息章可提到 20%，用设定章重构"真实规则"。
- 高潮设计可借鉴手法：把"真相"设计成"胜利与代价同构"——知道真相的同时知道必须牺牲，震撼与悲壮一起给。
