# 套路类型库 · 幕级演绎框架

> 从《深渊主宰》《诡秘之主》《道诡异仙》三本实证提炼。
> **v2 核心纠正**：**幕型 = 剧情演绎框架（主线形态）**，只有2种主力。驱动机制不是幕型，是幕内内容引擎。幕里装什么内容（战斗/信息/经营/成长）由剧情演绎时自然分配，模板不决定内容，只提供演绎骨架。

---

## 一、幕型（演绎框架）· 真正的模板

### 框架A · 单主线 + 支线并织（主力，绝大多数幕）

- **定义**：一条主线贯穿整个幕，支线以"插花"方式穿插。
- **为什么是主力**：一幕 8-12 章，主线承载主体事件（多为战斗/冲突驱动），支线负责换气、埋伏笔、铺人物、补信息。三书绝大多数幕走此框架（占比 65-80%）。
- **演绎节奏模板**：
  ```
  主线主干（每章推进主体事件，战斗/冲突为主体，2-3章一个推进节拍）
    ├─ 支线插花（交替穿插，铺垫人物/伏笔/世界观，不抢主线戏）
    └─ 主线收束（幕末高潮，闭环）
  ```
- **配比参考**：主线（含战斗）50-60% ／ 支线 15-25% ／ 过渡 10-15% ／ 信息 5-15%。主线必须 ≥45%。
- **变体**：
  - **群像增强版**：支线权重提升到接近主线（《诡秘》塔罗会多线并织），本质仍"主线穿线 + 多支线"。
  - **蓄力版**：主线只推进一点，支线为主，为下一幕爆发垫落差。
  - **卷末版**：主线收束=大高潮兑现（成神/晋升/弑神），高潮前全卷蓄力。

---

### 框架B · 双主线并行 + 汇合（峰值幕）

- **定义**：两条主体事件并头推进，各自产生高潮，最后汇合放大（1+1>2）。
- **为什么是峰值**：双线密度翻倍、爽感倍增，承担全书/卷最强高潮。三书都只在强度顶点使用（《深渊》卷5/卷10、《道诡异仙》双世界、《诡秘》部分高位幕）。
- **演绎节奏模板**：
  ```
  A线推进（一段）
    → B线推进（一段）
    → 交替攀升（双线各爆一次，交错）
    → 会合点（大高潮，1+1>2）
  ```
- **配比参考**：主线 60%+（A/B线各分） ／ 支线 10% ／ 过渡 10% ／ 信息 10%。
- **高潮设计**：多高潮错峰——A线爆一次、B线爆一次、会合点再爆，不同时间点避免互相稀释。
- **变体**：
  - **双身份版**：本体+化身两条线并行（《深渊》）。
  - **双世界交替版**：《道诡异仙》题材核心，双线全程骨架，交替为"窗"切换。
  - **多线网版**：单主线穿线 + 多角色线各自推进（《诡秘》塔罗会）。

---

### 候选框架C · 多线并织 / 群像网（待定）

- **定义**：无单一主线，多条角色线各自推进、定期交汇。
- **当前判断**：从三书实证看，它本质是"框架A的群像增强版"或"框架B的多线版"，**尚未形成独立于 A/B 的第三种骨架**。因此暂并入 A/B 变体，不单列。
- **开放问题**：如果你认为存在独立第三种，需要额外样本佐证后再升格。

## 二、内容引擎（不是幕型！幕内驱动力）

> 这些决定"幕里剧情靠什么推动"，**自由叠加、由剧情决定，不决定演绎框架**。一幕可以同时含解密+战斗+博弈+信息。战斗是主线主体的默认大头，不是独立内容类型。

| 引擎 | 作用 | 典型场景 |
|:--|:--|:--|
| **压力递进** | 连环危机一节扣一节 | 大事件、卷末引爆 |
| **解密/推理** | 信息逐步揭示驱动 | 真相、组织隐秘、伏笔回收 |
| **博弈/智斗** | 多方算计、信息差 | 权谋、布局留筹 |
| **倒计时** | 时间/仪式/检定窗口压迫 | 晋升、限时任务 |
| **收集/成长** | 资源/能力累积 | 升级流底盘 |
| **生存/逃亡** | 威胁追击驱动 | 开局、换地图重置 |
| **认知颠覆** | 真相推翻世界模型 | 反转高潮 |

**使用规则**：一幕选 1 个主引擎 + 0-2 个辅引擎叠加。引擎决定"怎么驱动"，框架决定"怎么排布"。

## 三、铁律（编排层，所有幕适用）

> 这些不是幕型，是任何幕都必须遵守的编排原则。

| 铁律 | 内容 |
|:--|:--|
| **高潮压幕末** | 高潮放幕末，给"看完这章再睡"的追读理由 |
| **卷末钩子必开口** | 收益兑现 + 新目标预告双钩，绝不在幕末封闭 |
| **主线占比≥45%** | 主线（含战斗）低于45% = 水 |
| **多高潮错峰** | 同幕多高潮不同时间/维度爆，避免稀释 |
| **战斗为主体** | 一幕十几章，主线推进以战斗/冲突为主体，信息/支线穿插点缀 |
