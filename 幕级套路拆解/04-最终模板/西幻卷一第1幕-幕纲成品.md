## 〇、套路决策

> 方法论：`references/幕级套路决策.md`（强加载）。五步决策在下，作为本幕全部设计依据。

- **演绎框架**：A 单主线+支线并织 + 变体「蓄力版+开局契约」（主线只推进一点，支线铺垫为主，为幕2打脸垫落差）
- **内容引擎**：主「压力递进」（祭品倒计时+藏锋双输局）+ 辅「解密/推理」（地窖吃人仪式→收割周期黑幕实锤）
- **卷内递进范式**：线性递增（首卷）| 强度档 L1 | 卷内位置 前
- **章配比**：主线 50% / 支线 20% / 过渡 20% / 信息 10%（主线≥45% 达标）
- **高潮**：位置 ch007 | 类型「认知颠覆+黑幕实锤」| 蓄力 7 章（ch001-c006 全铺垫）| 余波 ch008-010 开"入局"新钩
- **幕末钩子**：手法「收益兑现+新目标预告」| 指向幕2 藏锋爬阶 | 跨卷伏笔「祭品倒计时」早埋（立誓学屠夫刀法即埋）+「薇拉下落→教会区后门」无痕埋入

## 一、幕定位

- **本幕作用**：首幕开局契约——世界展开+主角立住+第一口爽，从"被圈养的储备粮"到"主动入局学屠夫刀法"的故事启动。
- **核心体验**：压迫（我知道自己在被吃）+ 爽感（我看穿了这个屠宰场，还记了屠夫的账）——"被圈养的祭品在记屠夫的刀法"。
- **情感弧线**：从"以为得救" → 经过"惊觉入屠宰场" → 以"主动选择留下立誓"结束。
- **幕末质变**：主角从"逃还是留"的被动 → 不可逆地变成"主动入局学刀法"的幸存者 + 剧情从"生存危机"格局变为"藏锋爬阶"格局。

## 二、剧情白描

灰潮夜，洛恩在瓦砾堆里睁眼。净化队破门时他挡在妹妹薇拉前面，锁链抽在额角，血糊了满脸——白袍队长扯着攥半块黑面包的薇拉拖进雨里，巷口那个灰袍执事朝队长点了点头。洛恩追出去，被瓦砾绊倒，濒死里意识与世界应激重连，两个灵魂在同一个身体里同时睁眼：一个是他的，一个是原主残魂——"我是洛恩，这具身体原来的主人，也是薇拉的哥哥。"

灰袍执事加文把他捡回秘社，测灵塔上，三块水晶依次暗淡，枯手导师闭着眼宣判"零天赋"，满堂哄笑。洛恩站在哄笑里没动，心里盘算的是：水晶为什么读不出双魂？他被安排进偏殿——挨着那扇永远关着的地窖门。长老伯劳当众宣布"亲自重点培养"，笑得很慈祥，像一尊神像；洛恩点头受宠若惊，当夜就去摸了地窖的门缝。

地窖里，烛火昏黄。他看见伯劳把学徒阿古的灵光一寸一寸抽进指尖——阿古昨天还分过他半块黑面包。阿古记忆里"被善人收养"的假象在他触碰的瞬间裂开，原稿激活：他看见了记忆被改写前的原始版本——"测灵读不出的异常灵魂，是吃人晋升的上等材料。"他读懂了。代价紧随其后：薇拉唱过的那首歌，歌词调子全没了，只剩"她唱过歌"这个干巴事实。烛火矮了一截，伯劳转头，目光钉向门缝。

残魂在暗里说：屠夫刀法第一步，别让屠夫知道你已经醒了。洛恩没有逃——城门有漏洞他知道，可他算过账：秘社心法是真的、庇护是真的、加文通往教会的线牵着净化队、牵着薇拉，这些线索也是真的。他在"被端上餐桌之前先学会屠夫的刀法"——留下来，从伯劳藏在藏经阁底下的那本账开始。

此后十天，他装笨。白天背心法背得磕磕绊绊，夜里双魂协作冥想——残魂教他黑街的规矩、谁家的货不能碰、哪条巷子能躲人，他教残魂怎么用现代人的眼睛看秘社：管导师叫"干尸"，管伯劳叫"屠夫"，腹诽那些"开恩传法"的漂亮话。他修得极快，快得反常——同龄学徒还在背心法第一个字，他已经能"听"到通铺里每个人的情绪噪音，像一团嗡嗡作响的活物。他开始怕自己快：快=暴露=被提前端上桌，慢=等死=被养肥了吃。他卡在藏锋双输局里走钢丝。

第七夜，他摸到藏经阁外围。巡夜执事的脚步声擦着墙根过去，他屏住呼吸，在窗台下偷听到伯劳对加文说："好料子，要慢慢养。"声音平得像在谈一栏猪。他蹲在墙根，把这句话记进账本——第一个黑幕实锤，收割周期是真的，他自己就是那个"料子"。

加文开始派杂役给他跑，克扣黑面包，嘴上却"执事大人疼你"。洛恩装得感恩戴德，心里给加文记上第二笔。他摸清了偏殿所有墙根、藏经阁的巡夜规律、地窖门禁的时辰。第十天，加文递来第一单活："有笔买卖，适合你这种不值钱的学徒。"洛恩接过那枚铜板，在手里掂了掂——他清楚这枚铜板买的是什么：一个"合理变强"的外壳，一条通往教会区、通往薇拉线索的路，也是第一次把自己卷进秘社-教会-猎杀者的供应链。

他收下铜板，走回偏殿。残魂在暗里问：值不值？他在心里记下第三笔账——被端上餐桌之前，账本越厚，他活下来的底牌越硬。他选择留下，选择入局，选择在屠宰场里，学完屠夫的刀法。

## 三点五、敌人-成长耦合

| 项 | 内容 |
|----|------|
| **本幕敌人** | 结构敌人=秘社长老伯劳（关底，本幕象征性在场：地窖仪式/ch007 偷听）；直接压迫=执事加文（杂役盘剥/递活）；羞辱源=铁头（ch006 踩人，>幕2 才正面冲突） |
| **敌人类型** | 信息型（伯劳=垄断信息/黑幕）+ 关系型（加文=亦敌亦友两头下注）+ 系统型（秘社吃人晋升体系） |
| **主角为什么打不过** | 1 阶潜识 vs 伯劳 5 阶心域+隐藏觉醒期底牌、加文 3 阶操控——硬碰必死，且露锋=被提前收割 |
| **主角如何变强** | 不用力变强，用"藏锋+信息差"变强：双魂加速冥想（实力暗涨）+ 原稿读黑幕（信息差）+ 摸清环境（偏殿墙根/巡夜规律） |
| **打完获得什么** | 不"打"伯劳/加文——获得：入局资格（脏活入口）+ 黑账第一笔（信息筹码）+ 秘社资源（心法/庇护/线索）白嫖 |
| **因果链** | 本幕攒的"黑账+脏活入口+藏锋外壳"→ 是幕2 打脸反击（铁头）和幕3 读穿加文黑账的前提；本幕"好料子慢慢养"实锤 → 确认祭品身份 → 卷末掀桌的起点 |
| **解决比例** | 部分解决（不解决敌人，只解决"主角的生存路线"——从被动逃到主动入局） |

## 八、prose-render交接

- **文风注意**：暗黑为底色（压抑氛围/代价真实/黑幕惊悚），不为氛围牺牲爽点推进；短句为主，情绪内压；屠夫/屠宰场隐喻贯穿（伯劳="屠夫"、学徒="料子"）。
- **不可改动事件**：
  1. 测灵读不出双魂=零天赋（ch001，势力体系关键）
  2. 原稿首次激活读阿古记忆→掉"薇拉的歌"（记忆只剩干巴事实，代价硬锚点）
  3. 伯劳 ch001 地窖抽阿古灵光+ch007 偷听"好料子要慢慢养"（黑幕实锤）
  4. 洛恩 ch001 立誓留下学屠夫刀法（主角主动决策锚点）
  5. ch010 接加文第一单脏活=主动入局（幕末钩子）
- **可自由发挥空间**：测灵哄笑的具体细节、冥想时的感官描写、残魂对话的措辞、装废的日常细节。
- **爽点外显要求**：ch001 认知颠覆（读不出双魂=命门）、ch007 黑幕实锤（偷听）、ch010 入局——三处爽点要给足"我看穿了"的博弈快感，不写面板，用参照物梯子（同龄学徒还在背心法，他已听清全员情绪）。
- **角色行为锚点**：洛恩=藏锋/精算/记仇（蹲下记账）；残魂=黑街谚语式断言（"别让屠夫知道你已经醒了"）；伯劳=屠宰场隐喻+从不重复第二遍；加文=两头下注话里有话。
