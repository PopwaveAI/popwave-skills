# 主线任务链方法论（两书实证）

> 从《深渊主宰》《诡秘之主》主线任务链提炼的"主线怎么定"方法论。
> 回答老板追问：主线不是一句话主题，是**一套可验证的任务链系统**。

---

## 〇、主线不是什么（纠偏）

| 错误认知 | 正确认知 |
|:--|:--|
| 主线 = 一句话主题（"主角变强反抗压迫"） | 主线 = **一串可验证的状态迁移任务** |
| 主线只有一条 | 主线 = **多条链交织的网**（4-5条） |
| 主线是抽象的 | 主线是**具体的**（每卷一个任务，有目标/前置/奖励） |
| 主线自己就成立 | 主线必须**有锚点**（进度条）让读者看得见 |

---

## 一、主线 = 多条链交织的网

两本书都验证：**主线不是一条，是 4-5 条链并织**。

| 层 | 深渊主宰 | 诡秘之主 | 职责 |
|:--|:--|:--|:--|
| **力量主链** | A 神格晋升线 | A 序列晋升线 | 主角"变强"的进度条，全书主链 |
| **世界终极线** | B 弑神复仇线 | B 真相线 + E 末日线 | 主角"为什么变强"，世界危机驱动 |
| **生存/结构线** | C 双身份线 | C 身份线 + D 塔罗会 | 主角"怎么在地图切换中活"，窗口锚 |
| **情感支脉** | D 人物情感线 | （散在各线） | 主角"为谁而战"，缓冲垫 |

> **核心**：至少要有"力量主链 + 世界终极线"两条，才能同时撑起"爽感进度"和"叙事驱动力"。只有一条=单薄。

---

## 二、主线任务链的 5 个硬要素（每个任务必填）

以《深渊》卷3末"首次弑神"为例：

| 要素 | 内容 | 为什么必须有 |
|:--|:--|:--|
| **任务名** | 首次弑神 | 记忆点，读者能记住 |
| **目标(Objective)** | 进阶半神+首杀吸血鬼之神 | 可验证，不抽象 |
| **状态迁移** | 半神门槛→首次弑神 | 主线进度=心态位移 |
| **奖励(Reward)** | 弑神夺职模式+天花板掀开 | 每卷末的"升级兑现" |
| **前置(Prereq)** | 归乡科技（卷3前段） | 任务链条逻辑 |

> **主线 = 一串这样的 quest 串起来**。写主线时，逐卷列出这 5 个要素，就是一张可执行的主线任务表。

---

## 三、锚点：让主线进度"看得见"

| 锚点类型 | 深渊 | 诡秘 | 作用 |
|:--|:--|:--|:--|
| **力量标尺** | 神格：微弱→伟大 | 序列：占卜家→愚者 | 每卷末"升级"可见 |
| **卷名锚** | 卷功能位 | 卷名=序列名 | 卷=任务，任务名=进度 |
| **结构锚** | 双线会合点 | 塔罗会每周聚会 | 多线不散 |

> **锚点必须具体、可量化、可追进**。读者靠锚点判断"主线推到哪了"——没有锚点，主线散。

---

## 四、主线怎么定（SOP 五步）

```
第一步 定全书终极目标（Endgame）      ← 两书的"点"：深渊=重返神国/建冥界，诡秘=应对末日/成神
第二步 切分力量主链（多久升一级）      ← 深渊=神格标尺10档，诡秘=序列8档，每卷一级
第三步 定世界终极线（为什么升）        ← 深渊=弑神复仇，诡秘=真相+末日
第四步 定生存/结构线（怎么活）         ← 深渊=双身份，诡秘=换马甲+塔罗会
第五步 定情感支脉（为谁战）            ← 深渊=薇薇安/歌莉娅/安娜，诡秘=灰雾成员
```

---

## 五、主线 → 主体事件 → 章节（三层挂接）

**这一步直接回答老板的原始问题**：

```
全书主线任务链（L0）
   ↓ 每卷拆一个任务
幕·主体事件（L1）  ← 必须明确推进某条主线链的任务进度
   ↓ 每幕再拆
章节（L2）
```

**判定"这一幕主体事件合不合格"**：它能回答"这件事把 A/B/C/D 哪条主线，从哪个状态推到了哪个状态"吗？答不出 = 不是主体事件，是支线/为事件而事件。

## 六、给西幻卷一的启示（对照）

| 环节 | 深渊/诡秘做法 | 西幻卷一现状 |
|:--|:--|:--|
| 全书终极目标 | 深渊=重返神国，诡秘=应对末日 | 需定（掀翻黑幕算半条） |
| 力量主链 | 神格/序列标尺，每卷一档 | 灵能阶位=现成标尺 |
| 世界终极线 | 深渊=弑神复仇，诡秘=末日 | 需定（吃人黑幕/神陨真相） |
| 生存/结构线 | 深渊=双身份，诡秘=塔罗会 | 需定 |
| 情感支脉 | 深渊=薇薇安，诡秘=灰雾 | 薇拉线=现成情感支脉 |

> **西幻卷一缺的不是第1幕设计，是"先定全书主线任务链"**。主线没定,主体事件就不知道"服务于哪条链、推进到什么状态"——这就是前几版"为事件而事件"的根因。
