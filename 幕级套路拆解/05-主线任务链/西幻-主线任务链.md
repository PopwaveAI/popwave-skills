# 西幻全书主线任务链（mmorpg任务链）

> 项目：西幻小说立项（《秘社之主》暂定）
> 视角：全书 = 多条主线任务链并行交织；每卷 = 一条链上的任务推进 + 卷末兑现一个里程碑。
> 依据：设定硬输入（创意.md 5卷框架 + 力量体系.md 10阶 + 动力引擎.md + 主角设计.md + 各卷切片.md + 危机敌人矛盾.md + 势力人物.md + 卷纲决策表.md R1-R5）
> 方法：对照《深渊主宰》《诡秘之主》主线任务链实证（05-主线任务链/），确认"主线=多条链交织、每卷一个任务、有锚点、状态迁移可验证"。

## 六、给第一幕的挂接（回答"主体事件服务什么"）

**第一幕（ch001-010）要推进的四条主线状态**：
- **主线A**：从"刚觉醒失控"→"潜识稳定"（1阶站稳，D面板首爆）
- **主线B**：从"刚被捡回"→"看清屠宰场+藏锋安置"（B1 屠宰场入门）
- **主线C**：从"灰潮夜失散"→"确认妹妹走教会线"（C1 断线索→C2 摸教会线起点）
- **主线D**：从"无知"→"察觉测灵异样"（D1 埋线）

**第一幕主体事件（挂主线B）**：**洛恩在"刚进屠宰场"的生存期里，摸清秘社结构、藏锋安置自己，并从加文的教会线第一次抓到薇拉下落的碎片——完成"屠宰场入门"这个主线B任务。**

> 判定：这一幕主体事件能明确回答"把主线B从'刚被捡回'推到'看清屠宰场+藏锋'、把主线C从'失散'推到'锁定教会线'"——是可验证的状态迁移，不是为事件而事件。
