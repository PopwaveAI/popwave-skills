# 《深渊主宰》第二章章纲（描述约束版 v6）

> producer: 主agent | 用途: 示范"outline 约束描述性密度"后章纲该长啥样
> 核心铁律：章纲只定【事件·转折·落点功能】，不给【动作细节/心理陈述/对白台词/结尾意象】——后四者全部划归 write 表演区。凡出现成品句/预写台词/文学落点=越界，必须删。

---

## 一、时空与主体

- 次日，雨停。破屋 → 贫民区早市 → 富人区街口 → 回家巷子 → 破屋。主视角薇薇安(八岁)；哥哥昏迷卧床；老狗希斯守屋。

## 二、事件节点（每个节点三行内：事件 / 转折 / 落点功能）

**N1 晨醒·清查家底**
事件：薇薇安醒，查希斯是否守了一夜；探哥哥伤势；翻粮，剩最后一餐；倒铜板数钱。
转折：发现断粮 + 哥哥发热，两个钳子同时夹紧。
落点功能：逼出"今天必须弄到钱"，把读者心悬到行动起点。
（write发挥：晨光/漏屋/伤势细节/她数钱的紧张，全部现编）

**N2 早市谋活·处处碰壁**
事件：她上街主动找活（跑腿/看摊/帮工），无人雇；唯一善意是卖菜阿婶给的半颗土豆和一句劝。
转折：一上午零收入，"穷人孩子=累赘或货"这个现实拍脸。
落点功能：压死"正常劳动力"这条路。
（write发挥：早市嘈杂/摊主打量眼神/阿婶那几句话的音，全部现编）

**N3 远望神殿·问清价码**
事件：她摸到富人区街口，蹲墙根听来"请神官多少钱、神官嫌贫民区晦气"。
转折：价码是天文数，"攒几年都不够"，正路彻底堵死。
落点功能：把"请牧师"钉上不可及的价格，断掉侥幸。
（write发挥：金顶视觉/她听价的专注/心里换算，全部现编）

**N4 归途被盯·脱身**
事件：返程巷道被人贩手下男人贴上来搭话试探；她借熟地形甩脱。
转折：白天也有人盯着她——危险从"夜里的威慑"升级成"白天的现实"。
落点功能：让读者替她捏汗 + 标记"白天也不安全"。
（write发挥：那个男人怎么开口/她怎么装镇定/脱身动作，全部现编）

**N5 回屋见脚印·希斯拦过贼**
事件：屋门有扒痕、脚多陌生大鞋印，邻居警示；推门希斯守着，屋里白天来过人被它吓退。
转折：希斯守得住屋、护不住她在外头——里外都漏风。
落点功能：把"她孤身在外"和"家已被觊觎"两个隐患并压一处。
（write发挥：脚印细节/希斯姿态/她分饼的动作，全部现编）

**N6 夜定·自握缰绳**
事件：她对着昏迷的哥哥独白（她不会让人拆了家）；她改变"被动被卖"为"主动自己去谈"，定条件；睡前抵门守夜。
转折：把"等黑手来"掰成"她自己走到对方跟前，价自己喊"。
落点功能（章末钩）：让她从"被威胁的弱者"转身成"主动入局的人"，为第三章"她去找索西亚"铺势。
（write发挥：独白的内容/她怎么下这个决心/守夜的画面/章末最后一个意象，全部现编）

## 三、交接信息（只说"要达成什么"，不说"怎么写"）

**对白**：三处——与阿婶（善良但无力雇，一两句）、与盯梢男（粘腻的试探，三两句话压住，不升级成冲突）、对哥哥独白（情感主轴，长度自己控）。**台词全部 write 现编，章纲不给一句。**

**世界观要铺的功能**：①"牧师不管贫民区死活"+价码高→堵死求医正路；②货币位阶（铜板→银币，金娜不写）；③科伦/萨维两帮仅点到；④希斯"哥拉斯猎犬野种"传说残片、服务"它为什么能扛"。**用哪些意象/怎么讲，write 定。**

**角色语感**：薇薇安要"八岁、早熟、贫寒里的硬"；盯梢男次要但对味。索西亚/牧师/帮派头目本章不出场免查。

## 改成之后，write 拿到的 vs 之前

| 维度 | 旧章纲（诱发AI味） | 新章纲（v6） |
|:--|:--|:--|
| 动作细节 | 预写"她把干饼掰一半塞给它" | 只写"她分饼"，动作 write 现编 |
| 心理陈述 | 预写"她心里首次升起凉意" | 不写，标"—write发挥—"占位 |
| 对白台词 | 预写"与其等哪天黑手捆走我……" | 只写意图"变被动为主动"，台词 write 编 |
| 结尾意象 | 预写"天际露出一线血色""决定比夜还硬" | 只写落点功能"从被威胁转身成主动入局"，意象 write 给 |
| 章纲长度 | 六节点全是成品旁白 | 每节点≤3行，含发挥占位 |

**核心判据**：章纲里出现任何"像正文句子"的表述 = 越界，删。write 的活（动作/心理/对白/意象）outline 不得代劳，只能圈功能区。
