# 设定 skill · 世界法则

设计"这个世界强怎么构成、怎么升级"，是所有设定里最该打磨的基石。武力侧与非武力侧都设计，只分侧重（非都市偏武力、都市偏非武力）。侧基石可以不止一个。

> **顺序：在世界画像之后跑。** 法则的基石不能凭空造——它从《世界画像》第2步内核"什么最被抢"点出来（钱=赛博内核、序列=诡秘内核、查克拉=火影内核）。先有画像钉内核，法则才有给基石指名的对象。

## 这份设定回答什么

世界法则管"规则"。三层向下：

```
基石（总能源：非凡特性 / 广义超凡物质 / 钱的量级）
  ├── 物资系列（基石衍生的资源物）
  └── 对抗系统（怎么赢下矛盾）× 各配养成线
```

判据：拿掉它，对抗不成立、等级不可感知、篇幅排不出来。它决定世界天花板与稀缺感。

## 通则：爽文没有真代价（钉死，别自毁）

**任何基石/养成/对抗设计的"代价"，在网文里都只能做成 氛围性 / 装扮点缀级，不许做成真正拖垮主角、让读者犯堵的东西。**

- 真代价（禁用）：不可逆堕落（越强越疯、失控）；损失核心资产补不回来；主角变强却难受。
- 允许的"假代价"：只做气氛（画风暗、越强越显诡、台词带疯狂味）、只做装扮（外在形象/称号越来越克苏鲁，本质无害）、可控小摩擦（短期吃瘪、快化的爽点）。
- 判据：**主角付这个代价时，读者是"哇更酷了"还是"唉好难受想弃了"？后者=真代价，删，改氛围/装扮级。**
- 来源：读者要变强+爽，不要真实困苦。克苏鲁这类风格在爽文里当氛围滤镜，不当真实枷锁。

## 怎么填（产出 SOP —— 含"怎么想出来"）

**动工前先按题材选轨**：强世界观走完整棋盘；弱世界观（都市/言情/纯爱）棋盘坍缩成关系版图。

1. **查赛道定流派**：先查 {赛道库-SOP.md}，封面属于哪个流派、读者默认什么骨架。这是"复用"底座，先走最省。
2. **从画像内核点名基石**：回看《世界画像》第2步内核——什么最被抢？点名成基石。基石从这来，不凭空造。（钱=赛博、序列=诡秘、查克拉=火影）
3. **拆物资系列**：基石能拆出几类可点名、不可白得的物资，分档（凡/珍/禁）给获取门槛。
4. **铺开对抗系统**：分战斗（武力侧）/社会对抗（非武力侧），逐项写本质+表现。
5. **拉养成线（用硬规则）**：主养成线1条+从线≥3条，各标维度且功能不重叠，写挂主线+对角。
6. **篇幅对账**：用"每卷升几级"反推主从各线档数是否合理。
7. **跟世界格子收束**：基石/物资/系统/养成线回头解释画像一条内核+敌人共用同一套法则。
8. **过"爽文无真代价"**：所有代价审一遍，有真拖垮主角的→降到氛围/装扮级。

**"怎么想出来"并入每步**：
- **路径一 复用（兜底先走）**：查赛道库拿读者默认骨架当基线，错一格做差异（改机制/换命名/拧来源），不推倒。
- **路径二 从内核推（最稳）**：基石=画像内核点名；档数=基石守恒+篇幅"每卷升几级"反推；物资/对抗=从"升级缺什么、谁在抢"推。
- **路径三 验收锚点反推**：把验收项反过来当生成问题（"这一档一个人能干成啥？全赛道有多少他？这层什么待遇？"）。
- **选择法**：脚手架复用，卖点处路径二/三深推；处处记着"爽文无真代价+复用骨架上拧一格"。

## 逐条要领

### 基石

基石不只"总能源"，它反向决定天花板、稀缺感和张力。每个基石答三件事：

1. 这侧的总能源是什么（查克拉 / 非凡特性 / 广义超凡物质 / 钱的量级 / 社会地位）。
2. 总量是否稀缺、守恒——决定天花板（序列越靠前越稀有；钱向豪者聚；仙路断→证道抢路）。
3. 跟画像内核一条呼应（守恒=成神需牺牲他人；钱尽头=买到禁忌催更；强即分配效率）。

### 物资系列

物资是「基石→升级」的桥：升级消耗物资，变强=获取物资。稀缺物资是剧情冲突抓手。

**获取门槛**：物资分档（凡/珍/禁），主角初期只够得着低档，高档要剧情推进、能力/地位上去才够得着。

### 对抗系统（分两侧对开）

每套系统直接列出来，写清**本质（是什么）+ 表现（有什么画面）**。

- **战斗系统（武力侧）**：逐项列，本质+表现一栏。
- **社会对抗系统（非武力侧）**：随题材走（商战/权谋/医术/谍战），用真实案子定，不写死一张表。

**通用约束**：各对抗系统养成线不同步；对抗有制约（资源逼取舍）与信息差（被摸清底牌=劣势）；**敌人跟主角用同一套世界法则**——主角越级赢，靠某项养成线超标+敌人某项有短板。

### 养成线（硬规则）

**主养成线 1 条（骨架）＋ 从线至少 3 条。** 每条从线必须：①占一个不同维度（战力/心智/环境信息/资源地位），②跟别条功能不重叠，③有独一无二的成长方式，④写清"怎么挂到主线上"+"跟别条怎么对角"。不满足就追加/重定，不许一条线撑全部。

**分级↔篇幅**：每档一个叙事节点，前期少升快升（爽），后期精升慢升（稀缺）。先问"几卷、每卷升几级"反推档数。

**用主养成线给角色定档**：每档至少配四项——分级名 / 破坏力表现 / 数量估算 / 社会地位。能直接推任何角色多强、什么身份，不必单独设计强度数值。

## 质量验收

每一项都打"是"才算过：

1. 两侧都在——武力/非武力都设计了，对抗拆战斗/社会对抗两侧。
2. **基石从内核来**——基石是否从《世界画像》内核点名（钱/序列/查克拉），不是自造缝合词。
3. 基石有张力——基石总量/稀缺/天花板能造成世界独特，力量本身在讲世界观。
4. **爽文无真代价**——所有代价都做成氛围/装扮级，不拖垮主角、不让读者犯堵。
5. 物资可点名——基石拆得出几类具体物资，不是空泛能量。
6. 物资有门槛——物资分档，主角初期够不着高档，有"够不着→拼命够"张力。
7. 对抗成体系——主打侧是成套对抗规则不是数值打人，逐项写了本质+表现。
8. 养成线硬规则——主1+从≥3，每条不同维度/不重叠/独家成长/挂主线+对角。
9. 敌方同法则——敌人也用这套法则解释强弱与越级。
10. 篇幅咬合——主从各线档数与每卷升几级对得上。
11. 收束世界——基石/物资/系统/养成线能解释一条世界机理，是能反证的活规则。

## 与相邻设定的衔接

- 世界画像（**前面**）管"画面+内核"：长啥样、什么最被抢——本份基石从它点名。
- 世界法则（本份）管"规则"：怎么玩、强是什么、基石/物资/养成/对抗。
- 世界格局（后面）管"棋盘"：把地图铺成棋盘，谁占哪、挡着谁。

> 一句话：世界画像先说"这世界长啥样、在抢什么"，世界法则再说"强怎么构成、基石是最被抢的那个"，世界格局说"摆在棋盘上谁占哪"。
