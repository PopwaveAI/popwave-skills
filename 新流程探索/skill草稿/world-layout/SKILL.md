# 设定 skill · 世界格局

把前两份算出的东西"摆上桌"：世界法则是"怎么玩"、世界画像是"长啥样"，这一份回答**怎么摆、谁在台上、为何而战**。本份把原「世界格局 / 主要势力 / 势力矛盾」三份合一，统一从"棋盘（格局）"角度写——势力是棋子、矛盾是冲突线，都挂在棋盘上，不单列成章。

## 这份设定回答什么

世界格局管"棋盘"。三样东西合并但以"格局"为主纲：

| 概念 | 定义（是A，不是B） | 在棋盘里的角色 |
| --- | --- | --- |
| 世界格局 | 地图怎么分格、哪块归谁的势力范围 | 棋盘本身（格面+归属） |
| 主要势力 | 谁在台上、占哪个格、强在哪档 | 棋子（占格的主体） |
| 主要矛盾 | 格子之间为什么对冲、挡不挡主角 | 棋局（冲突线） |

一句话落点，三句连读：**棋盘铺开 → 谁占哪 → 哪两格要撞。**

## 怎么填（产出 SOP，逐层往）

1. **铺棋盘**：继承《世界画像》三层地图，每层定"几块格 + 主角起步格 + 层底 Boss"（升层如属位格迁移型，写"升层门槛位格"）。
2. **摆势力**：每层把顶层/中层/底层势力放进格子，各定【名/占地/档位/对主角作用】。
3. **画冲突线**：每层拉出"哪两格对撞"，分宿怨/资源/危机三类，单独标"谁挡主角"。
4. **放主角**：先定升层触发主型（见下），再写主角起步格 + 升层路径 + 每卷推进点。
5. **验收一句话**：读者能不能在地图上指认"谁的地盘、主角从哪往哪打"。

**动工前先按题材选轨**（对回《世界画像》双轨）：
- **强世界观**（玄幻/仙侠/克苏鲁/赛博朋克/DND）：走棋盘主纲，三层地图全铺。
- **弱世界观**（都市/言情/纯爱）：棋盘坍缩成**关系版图**——势力降维成"家庭/职场/情敌"是谁，矛盾降维成"情感+阶层阻力"单线的对冲，不铺三层地图。

## 逐条要领

### 棋盘总览

每层地图=一张棋盘格面。能用**三行**（每层一行）讲清"棋盘空着时长啥样"。棋盘层级不必是地理，可以是"接入深度/维度层/位格域"这类非物理舞台——关键是清楚画出格子与归属。层可厚可薄，一层内可跨多卷横换，别为凑 3-2-1 硬拆。

### 逐层摆势力

按逐层棋盘写，不按势力列表。每个势力至少定四件事：**名 / 占地（哪格）/ 主养成线档位 / 对主角的作用**（挡路/助力/工具/中立）。每层三层对齐：

| 层内层级 | 角色 | 对主角的作用 |
| --- | --- | --- |
| 顶层/统治阶级 | 层底 Boss、霸主势力 | 最后一战目标、晋升入下层的门槛 |
| 中层/精英 | 各关键势力当家人、爪牙 | 沿途打脸、收编、立威 |
| 底层/背景 | 平民、市井、散户 | 衬托、供爽感 |

判据：每层势力都落进"顶层/中层/底层"某一格的档次——棋盘上没有"不知该归谁"的势力。

### 逐层写矛盾

落到棋盘上就是"哪两格对撞"，分三类（对回世界法则物资 + 世界画像危机）：

1. **格间宿怨**：两块地盘间的世仇、侵吞、吞并（占位之争）。
2. **资源争夺**：围绕稀缺物资的争抢（矿脉/魔药配方/公司份额），源头上对回世界法则物资系列。
3. **围绕危机**：围绕世界画像"危机（会炸开的开关）"的角力——谁掩盖、谁引爆、谁堵死。

关键"**谁挡主角**"：主角升层要过的那条冲突线要单独标出——往往是"某格势力压着主角起步格"，主角从被压到反压，就是这层的戏。每层至少一条能一句讲清的冲突线。

### 主角的起步格与升层路径

- **起步在哪**：往往是偏远、被压、有暗格的那格。
- **往哪打**：沿冲突线，从起步格力压同格势力→抢中层→顶到升层门槛。
- **升层触发（先定主型）**：
  - **打 Boss 型**：明显"层底 Boss"，主角力压它才进下一层（玄幻/仙侠常见）。
  - **位格晋升迁移型**：升层由"晋升位格"驱动——到某位格/序列才够得着也必然迁入更高层（神秘/体系流，如"晋升半神即换更高舞台"）。赛博的"接入深度=高度"也属此型。
  - **可混用**：局部打Boss、整体靠位格。先写明主型，别默认一定是打Boss。
- **与卷数对应**：每卷=棋盘推进一段（成长+扩格+解一层矛盾同周推进）。一层内可跨多卷。

判据：写完后能答"主角从哪格到哪格经历了几战/几次晋升、每步动了棋盘哪块"，路径才成立。

## 质量验收

1. 棋盘能指认——每层能指出"哪块格归谁、主角从哪往哪打"，不是抽象势力表。
2. 势力落格齐——每层势力都落在某格，各有【名/占地/档位/作用】。
3. 冲突线清楚——每层至少一条可一句讲清的"哪两格为何对撞"，能溯源到法则物资或画像危机。
4. 谁挡主角标出——每层"压着主角起步格"的那格单独标出，是升层剧情主线。
5. 升层路径通——起步→沿冲突线→到升层门槛→入下一层，不绕路不凭空跳层；升层触发按主型走，不硬套打Boss。
6. 层厚不硬凑——层数/分布不被 3-2-1 硬拗，层可厚可薄、内可多卷横换，拗不过真实书就以书为准。
7. 卷数对位——每卷推进点对应篇幅规划的卷定义。
8. 双轨选得对——强世界观走棋盘、都市言情走关系版图。
9. 铺垫后续——把"谁在台上、为何而战"留给主角设计，不提前造主角。

## 与相邻设定的衔接

- 世界法则（前面）管"规则"：怎么玩。
- 世界画像（前面）管"画面"：长啥样、三层地图、强者档位、危机。
- 世界格局（本份）管"棋盘"：把画面铺成棋盘，摆势力、画冲突线、放主角。
- 主角设计（后面）管"人"：真造主角这个人（本命/金手指/欲望串），本份只给他摆好脚下的局。

> 一句话：世界法则说"这世界怎么玩"，世界画像说"这世界长啥样"，世界格局说"这张牌桌上谁占了什么、主角从哪格打到顶"，主角设计说"这个人是来怎么做这件事的"。
