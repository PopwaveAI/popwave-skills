# 设定 skill · 世界画像

设计"这个世界本体长什么样 + 内核在驱动什么"，是整条世界设定链路的**第一步**。落点一句话：**读者闭上眼，能想象出主角生活的这个世界的样貌；而世界法则的基石，要从这里的内核长出来。**

> **顺序：本份在链路最前面。** 因为它产出"这世界最被抢的东西"，正好是下一份《世界法则》要点名成基石的那个。先定画像(内核)，法则才有给基石指名的对象。

## 这份设定回答什么

世界画像是画面层 + 基石产地，分层向下：

```
这是一个什么样的世界（底层画像：风貌·时代·底色 + 驱动力内核）
  → 世界法则（强怎么构成，基石从内核点出）【下一份】
  → 世界格局（怎么摆：地图·阵营·分布）【再下一份】
  → 主要势力（谁在台上）【再下一份】
  → 势力矛盾（他们为何而战）【再下一份】
```

## 动工前先选轨（最重要）

先按题材选对**轨道**，再填，别硬套：

- **强世界观**（玄幻/仙侠/克苏鲁/赛博朋克/DND）：走下面的六步定调 + 三层地图，成立度高。
- **弱世界观**（都市/言情/纯爱）：没有"世界在推人做什么"，只有"关系在推什么"。走末尾的「弱世界观变体」，别强填世界因果链。这类书没有"基石"，法则下降成"社会地位/资产"或纯关系牵引。

判断依据：这书有没有"一套推动所有人的世界规则"。有=强，只有人物关系=弱。

## 六步定调（先挖到底，别跳层）

从表面挖到"世界为什么会这样、又要崩在哪"，共六步。深挖判据：六步填完，"表面什么味、内在推人做什么、凭什么独特、活下去付什么、崩在哪、在讲现实什么"全清楚，才不是套壳。

**第1步 · 壳（表）**：时代基调 + 主要风貌 + 世界色调 + 一句关键词。作用：主角穿着、城市建筑、对话腔调全由它定调。

**第2步 · 内核（里，最重要的产出）**：找这世界最根本一条因果链"如果X，那么Y"，能推到社会/经济/文化三层。**这条"最被抢的东西"就是下一份世界法则要指名成基石的那个——到这里必须钉出来。** 合格线：给这套规则，能答出"白天/夜里城市长啥样、富人和穷人抢什么、一场战争为谁打"。例：高科技低生活、巨企统治 → "钱/资本是唯一王道"。

**第3步 · 独特点（奇）**：拿一个"所有东西都遵从"的蹊跷规则，一句话讲清世界为什么独特。

**第4步 · 代价（痛）**：强起来/活下去要付什么。挖两层——世界级代价 + 普通人怎么活（写"一个普通人的一天"，把设定埋进日常，别集中说明）。三层规则（明/潜/禁：公开秩序、不可言说阶层利益、触碰即灭红线）。**注意：这只是"世界/普通人付出什么"的氛围与日常，不是主角的真枷锁——主角的真代价规则见《世界法则》通则。**

**第5步 · 危机（破）**：哪里不对劲=故事入口。是**"会炸开的开关"，不是"坏掉的状态"**。三层反常法（物理→行为→意义）。合格线：有一条让读者"心里咯噔一下、又说不清哪不对"的危机被钉住。

**第6步 · 隐喻（厚，自选）**：把一条现实议题"变形"进世界观。对纯爽文可省略。

### 弱世界观变体（都市 / 言情 / 纯爱用）

| 强世界观步 | 弱世界观降维成 |
| --- | --- |
| 第2步 内核 | 牵引力：把主角和想要的人/生活往一起推的那股劲 |
| 第4步 代价 | 情感代价：错过、误会、家庭/阶层阻力 |
| 第5步 危机 | 关系失衡：心结、误会、身份认知错位（"这段关系哪里不对劲"） |

第1步壳、第3步独特点、第6步隐喻照常填。这类书通常不需要三层大地图——层次坍缩成一个生活圈/一座城市，或简化成 1-2 层。**弱世界观没有"基石"**：世界法则在这里退化，不硬造力量体系。

一句话：强世界观把六步当"世界推演链"，弱世界观把六步当"关系牵引链"——步数不变、内核降维。

## 世界本体结构（地图分层）

默认按《篇幅与卷规划》**3 层大地图**设计，主角逐层拔升。每层地图=主角能待一段长时间段的舞台，聚焦该层主养成线质变档位。

- **层数 = 篇幅顶层的分派**，不是随剧情临时加。默认 3 层、质变分布 3-2-1；用户声明不同篇幅/节奏才偏。
- **层可厚可薄**：3-2-1 是"每层权重递减"的无声明默认，真实书常打破它。层数或分布偏离 3-2-1 都合法，只要符合篇幅规划；一层内可跨多卷横换，别为凑 3-2-1 硬拆。

### 每层地图的内部结构（三层制）

| 层级 | 角色 | 对主角的作用 |
| --- | --- | --- |
| 顶层/统治阶级 | 这层 Boss（大土皇帝/霸主） | 最后一战的目标、该层天花板 |
| 中层/精英 | 各关键势力、掌柜、Boss 爪牙 | 沿途打脸、收编、立威的对象 |
| 底层/背景 | 平民、市井、龙套 | 衬托气氛、供爽感 |

换层触发 = 这层三层都处理完（顶层 Boss 被力压）才进下一层，不是升级就跑。

### 区分三样东西（同级换图 / 卷 Boss / 层 Boss）

| 概念 | 定义 | 数量 |
| --- | --- | --- |
| 大地图层级 | 一段稳定舞台 + 该层最高阶 Boss（层底） | = 质变关键点数（默认约3） |
| 卷 | 剧情节奏单位（约70-150章），每卷一个卷级 Boss | = 卷数，可多可少 |
| 同级/半级换图 | 层级内的横向地图切换 | 不受层数限制，可无限多 |

关键：同级横换不受层级限制（海贼岛、遮天州域、深渊各地位面）——横换≠升层。升层往往发生在该层最后一卷。

### 每层地图的基本设定（分层填三块）

只写"第X层=某某界"是空的，每层向下填三块：

1. **地理构成**：这层由哪几块大陆/州域/大区拼成（一句话格式：`若干大陆 + N个特殊地点`），层内可横换的同级/半级图。
2. **活跃强者等级分布**：固定写清三档各占主养成线哪级——主流对手档 / 上层压顶档 / **层底 Boss 档**。**标出"这档在哪档位"依赖《世界法则》补搞定级（§4.3），画像只定骨架**。
3. **特殊地点设计**：每层配 N 个秘境/禁区。它是"同一层里规则更刁、奖励更高、够得着更难"的横换图，过不过它都不升层。每个至少写**特殊在哪 / 何时够得着 / 能拿什么**。

> 一句话：每层的戏，画得清"几张图、谁在这层、哪个最险、能捞什么"，这层才立得住。

## 我的产出 SOP

1. **选轨**：先定强世界观走六步，还是弱世界观走变体；查 {赛道库-SOP.md} 确认流派。
2. **定调挖到底**：第1节六步（壳→内核→独特点→代价→危机→隐喻）。
3. **钉出基石输入**：把"最被抢的东西"钉成一句话，交给下一份《世界法则》当基石点名对象。
4. **定世界本体结构**：按篇幅规划定几层（默认3层），每层挂质变分布，填三层内部结构；再定世界观底座。
5. **逐层填基本设定**：每层写【地理构成】+【强者档位（骨架，归法则）】+【特殊地点】三块。
6. **验收一句话**：读者读完能否闭眼想象出这世界长啥样 + 知道它最抢什么。

## 质量验收

1. 题材适用对齐——强世界观走六步、弱世界观走变体，不硬套。
2. 定调深挖到底——六步挖到内核（总命题/代价/危机），不是只给表面风貌。
3. **内核钉出基石输入**——第2步内核钉出"什么最被抢"，一句话能交给世界法则当基石。
4. 有点睛设定——最奇特的根规则一句话讲得清。
5. 日常感/代价齐——写了"一个普通人的一天" + 世界强起来付什么（氛围级，不做主角真枷锁）。
6. 危机钉住——三层反常有一处"不对劲"被钉住，且是"会炸开的开关"。
7. 层数对齐篇幅——与篇幅规划对齐，默认3层分布3-2-1。
8. 每层三层齐——顶层Boss/中层精英/底层背景清楚。
9. 换层触发清楚——"层Boss被摁平"为准。
10. 层内三块齐——每层【地理构成】+【强者档位】+【特殊地点】读得出。
11. 强者档位留法则——具体挂到主养成线哪级留给《世界法则》，画像只定骨架不硬定死。
12. 特殊地点够分得清——与普通同级换图分开，写明"特殊在哪/够得着/能拿什么"。
13. 可沉浸——读完整料能想象"主角活在哪"。

## 与相邻设定的衔接

- 世界画像（本份）管"画面+内核"：长啥样、什么最被抢——是链路第一步。
- 世界法则（**下一份**）管"规则"：从画像内核点基石，再定物资/对抗/养成。
- 世界格局（再下一份）管"棋盘"：把这些地图铺成棋盘，谁占哪、挡着谁。

> 一句话：世界画像先说"这世界长啥样、在抢什么"，是世界法则说"强怎么构成、基石是最被抢的那个"，世界格局说"摆在棋盘上谁占哪"。
