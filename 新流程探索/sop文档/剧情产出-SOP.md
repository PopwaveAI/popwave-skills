# 剧情产出-SOP（主线脉络 → 卷级结构 → 卷纲 → 章纲）

> 从属：与 立项创意-SOP、小说设定-SOP、管线全貌-SOP 平级的一级 SOP。管**剧情**产出，不管设定（那是小说设定-SOP），不管正文（那是写章期）。
> 产出阶段：主线剧情设计阶段（骨架：卷级结构）＋ 逐卷展开期（展开：卷纲/章纲）。
> 上游输入：03-故事脉络（五元素：主角/失衡/欲望串/谁挡着/结局）＋ 锁根设定（画像/法则/格局/主角设计）＋ 骨架设定（宏观地理/顶层势力/世界历史/主要反派）＋ 篇幅与卷规划-SOP。
> 下游交付：卷纲（给写章期的排戏清单，每章剧情点到章纲粒度）。
> 理论出处：`新流程探索\思考沉淀\网文宏观结构-引擎理论-阶段沉淀v1.md`——流水线管日常追读、库存管高潮反转，本 SOP 把它落成可执行步骤。
> 消费对象：写作 agent。agent 没有作者的记性，每个阶段必须给验收基准，不靠临场感觉。
> 定位：实践稿，先有真实案子验证（灰烬之主 04-卷级结构 v2 首测；单元剧规则随卷1卷纲 v2 重写实测，2026-09-10 对比评估：映射改造优于临场编，弹性节奏规则已修，见 `测试文档\第2轮测试\卷1新旧对比评估.md`），改到实测过才算数。

## ① 文档定位（这份管什么）

**剧情产出 = 把故事脉络的欲望串切成卷、把每卷拆成单元循环、再把单元落到章纲。** 它回答"全书怎么排戏"，不回答"世界的规则"（那是设定），不回答"某句话怎么写"（那是写章期）。

- **角色**：管线第三、四阶段的可执行方法。故事脉络是种子，设定是棋盘，本份是排戏的总谱与逐卷谱。
- **回答的问题**：主线脉络怎么立（世界终点×主角欲望线是否绑定：同芯拧双脊柱，并行两线独立）？欲望串怎么切成卷？每卷的三同进是什么？卷内怎么循环（单元层）？每章剧情点怎么写？
- **位置**：故事脉络 → 锁根设定 → 骨架设定 → **本份（卷级结构）** → **本份（卷纲）** → 写章期。
- **一句话落点**：能一句话讲清"这本书从起点到终点分几卷、每卷翻一次什么、卷内跑几个循环、每章推进什么"。

它不是：
- 不是**设定汇总**（棋盘/敌人/地图在设定文档已定，本份只排戏）。
- 不是**正文草稿**（对话、场面、节奏密度归写章期）。
- 不是**剧情灵感池**（本份给排期与方法，灵感在写章期按章产出）。

> 判据：读完①，读者知道"这份管排戏"，不知道"怎么排"——怎么排是②。

## ② 思考逻辑（填的时候脑子怎么转）

**这条推演痕迹（agent 最该掌握）：先立主线脉络（世界终点×主角欲望线是否绑定）→ 按质变点切卷 → 每卷填三同进 → 排明暗两线 → 挂真相层 → 拆单元循环 → 写卷纲 → 落章纲。**

从理论沉淀拿来的两条硬约束（灰烬之主实测都踩过）：

1. **先立主线脉络，再拆卷。** 拆卷是排期，不是编戏。先定世界终点、主角欲望线终点，判断两者是否绑定（同芯＝拧双脊柱；并行＝两线独立排期），再按主养成线质变点切卷——每卷先标"双线交汇点"，再谈卷内内容。反着来（先想卷内爽点再拼卷）＝卷会漏、主线会散。
2. **卷内必须有单元循环。** 一卷 70 章只有一条线硬写，写到 40 章就空。一卷 = 5-7 个剧情单元，流水线管日常（追读）、库存管高潮（真相/反转），两套机制并行，卷才填得满、追得动。

双机制说明（从引擎理论落地成排戏用语）：
- **流水线机制**：可重复产出的日常内容——从单元剧剧情库取模板映射改造的自成完整故事弧的小故事（委托/案件/副本/人情戏/升级小爽点，见阶段3）。它的作用是管追读：读者每天有的看。卷内约一半篇幅靠它。
- **库存机制**：一次性引爆的高潮内容——真相揭晓/身份反转/质变验证/大场面。它的作用是管订阅与口碑。库存按层排期，一层一层揭，不能一次放完。
- 两者关系：流水线推着读者走，库存决定读者什么时候"哇"。每卷都要有流水线（日常单元）+ 库存（结算单元/真相层）。

> 判断：读的人该能模仿"定世界终点×欲望线是否绑定（立双脊柱/两线并行）→ 按质变切卷 → 填三同进 → 排明暗 → 挂真相 → 拆单元循环 → 写卷纲"这套思路，换题材照推。

## ③ 文档内容（分阶段的可执行方法）

### 阶段1 · 立主线脉络（世界终点×主角欲望线是否绑定）

**主线 = 世界终点与主角欲望线的绑定关系 ＋ 真相结构（洋葱，库存管高潮）＋ 揭示排期（结算事件表）。**

- **第一步 · 定世界终点**：本小说世界的失衡最终走向哪——世界的最终解决方向（如"重建信仰体系""封印亚空间裂隙"）。来源：故事脉络的"结局"元素 ＋ 世界画像的危机与内核。
- **第二步 · 定主角欲望线终点**：主角个人命运的最终落点（如"成为灰烬之主""找到穿越真相"）。来源：故事脉络的"欲望串"＋ 主角设计的欲望串终点。
- **第三步 · 判断绑定关系（硬约束）**：世界终点与主角欲望线是否必须绑定？
  - **同芯（绑定）**：世界终点只有主角能达成，或主角本身就是世界终点的答案/钥匙（如"主角立神位＝世界重建信仰的唯一解"）。两条脊柱拧合成一条主线。
  - **并行（不绑定）**：世界危机解除与主角个人命运独立推进（如"世界危机与主角个人复仇互不绑定"）。两条线各排各的期，只在终卷或关键卷相交。
- **脊柱1 · 世界真相线**（同芯时存在）：世界为什么失衡的答案，按洋葱从外到内分层（表层异常 → 深层机制 → 底层本体），层数 = 库存机制能引爆的次数。每层标：秘密是什么、卷位、层类型。
- **脊柱2 · 个人命运线**（同芯时存在）：主角的欲望串（串行接力，一次比一次大）＋ 主角身上的谜（为什么偏偏是他/穿越真相/身世之谜），与世界真相线形成交汇点。
- **并行时的排法**：两条线各自的推进表分开排，单独标"两线在哪卷相交"。
- **每卷标交汇点**：这卷世界线怎么拧到主角身上（一句话）。
- **结算事件表**：库存机制的引爆排期——哪卷揭哪层真相、开哪条暗线、引爆哪次质变。

> 判据：能一句话讲清"世界终点是什么、主角欲望线终点是什么、是否绑定（同芯/并行）"；同芯则能讲清"世界之谜的终点为什么是主角"；每卷有交汇点；结算事件表排到卷。

### 阶段2 · 拆卷（卷序层）

- **按质变点切卷（硬约束）**：书分 N 卷 → 主养成线排 N±2 个可感知质变点；质变卷与无质变卷交错（3-2-1 递减或按地图分层），无质变卷用"准主线/从线升档 ＋ 同级换图"填满，不硬凑层级。
- **每卷填三同进**：主养成线质变一次（或无质变则准主线/从线升档一次）＋ 地图扩展一次（沿主线推进逻辑——按势力范围/认知边界/地理层级逐卷扩展）＋ 世界矛盾解锁一层（明面撞卷敌/敌群，暗面推进一条线）。
- **排明暗两线＋大boss组**：明面 = 卷敌（每卷 1 人或 1 组，档位对齐主角养成线逐档递进；处理方式待定：敌变友／敌撤离（到下一卷成次级敌人）／敌退场（被干掉））；暗面 = 2-3 条跨卷暗线（不在一卷讲完，跨卷推进、终卷收束）；大boss = 独立一组（跨卷压阵，终卷正面结算，可跨卷刷存在感）。
- **挂真相层**：洋葱每层挂一个卷位，每卷揭一层，作认知反转的钩子。
- **卷内叙事结构**：默认四段式——卷初钩子（新威胁/新地图）→ 卷中积累（升级/收编/打脸）→ 卷末高潮（质变/大场面/收束）→ 卷尾钩子（下一层入口）。特殊卷（双线收束/权谋节奏/镜像卷）在四段式内换节奏，但要注明为什么换。

> 判据：翻开任意一卷能答"这卷升到哪档、在哪块地图、解哪层矛盾、撞哪个卷敌/敌群、揭哪层真相、卷末翻成什么"。

### 阶段3 · 卷内单元循环层（防体量对不上的关键）

- **一卷 ≈ 70 章 = 5-7 个剧情单元**，每单元 = 一段完整故事弧（触发→冲突→小胜→代价→新钩）。
- **单元节奏弹性（硬约束，2026-09-10 实测修订）**：单元不写死章数。按节奏意图分三档——快单元（3-6 章，钩子密集、快爽点）／中单元（7-11 章，过渡/多视角走访/日常完整弧）／大单元（12-18 章，大事件/多人关系/卷中转折）。排布规则：一卷 5-7 个单元，**快与大至少各一**；**同档不连续超过两个**（如"大大大"重排为"大小大"）；**结算单元豁免**（卷末高潮长度由库存引爆需要定，不受同档限制）。列单元表时每单元标节奏档位（快/中/大）。
- **三类职能（篇幅配比硬约束）**：
  - **日常/填充单元**（流水线管饭）：占卷内约 50%。内容 = 从单元剧剧情库映射改造的自成完整故事弧的小故事（委托/案件/副本/人情戏/升级小爽点/世界观质感）。管追读。
  - **推进单元**（主线推进）：占卷内约 30-40%。内容 = 暗线+1、卷敌逼近、情报升级、认知反转前奏。管主线。
  - **结算单元**（卷末高潮）：占卷内约 10-20%。内容 = 质变、卷末大场面、真相层揭晓、卷末钩子。管高潮。
- **单元剧剧情库（每卷必查，check 一次）**：日常单元的具体故事不从零编——每卷卷纲产出时先查本赛道的单元剧剧情库（[单元剧剧情库.md](单元剧剧情库.md)，模板 = 结构骨架＋适用赛道＋能服务的卷主线点），按本书世界观映射改造（化结构不搬情节，如"副本"在本书长成"净化悬赏/教堂委托"）。**check 一次 = 三查**：①本卷 5-7 个单元能否全部从库取到模板（映射不上的→增量 research 三源：游戏任务链/影视单元剧/同赛道网文→新模板回填进库）；②被用过的模板是否要升级（复用预警）；③本卷日常形态是否有库外新类型要建模板。research 成本可接受，不将就。
- **生长性硬规则**：每个单元至少兑现一项量变级收获——新角色出场立人设／某条线+1／量变级成长获取（技能/资源/信众）／卷敌势力一次试探。没有收获＝注水单元，卷纲验收时查。
- **参数递增（硬约束）**：单元之间，敌人量级/庇护范围/灵能上限（对应本书主成长量）逐圈变大；同档内是量变，卷末才质变。没有参数递增＝单元内容重复，卷中段会空。卷1 实测锚点：每单元至少一项参数递增，且列成链逐单元升档（敌档链/庇护链/信众链/信息链）。
- **明暗兑现落进单元**：明面卷敌的追捕/对抗分步落在推进单元；暗线跨卷推进的"该卷部分"落在推进单元；真相层揭晓落在结算单元。

> 判据：每卷能列出单元表（#/单元名/类型/节奏档位/章节区间/职能/参数递增/服务的卷主线点），日常单元占比≈50%；每个单元注明化用模板且至少一项量变收获；每个推进单元至少推进一条线一步。

### 阶段4 · 卷纲（单元 → 章节弧段 → 章纲）

- **卷纲 = 把单元拆到章**。每章格式：**章号 + 标题 + 核心剧情点（1-3 句）＋ 单元归属 ＋ 参数递增/钩子标注**。
- **单元拆章前先查库映射**：每个单元从单元剧剧情库取模板 → 按本书映射改造 → 敲定"完整故事弧＋服务的卷主线点＋章节数（含节奏档位）"，再拆到章。
- 每单元内部按完整故事弧排（触发→冲突→小胜→代价→新钩），章与章之间留钩子（每章末至少一个"还想看下一章"的点）。
- **卷纲兑现清单（对照阶段2-3 验收）**：三同进、明暗两线该卷部分、真相层揭晓、质变验证战（层底Boss）、卷末钩子、参数递增逐单元兑现、单元剧生长性（每单元至少一项量变收获）、节奏档位兑现（同档不连续超两个，结算豁免）。
- **展开层人物在此创建**：当卷新人物（NPC/配角/次级敌人）给一句话定性（名字+身份+立场），不写小传；重要配角留到核心配角设定展开。
- **留白**：地名细节、路人、风土人情、低层规则不写进卷纲——归写章期临场造。

> 判据：读任意一章能说出"这章在哪个单元、推进什么、爽点/钩子是什么"；每个单元能说出"化用了哪个模板、服务了哪个卷主线点、节奏档位"；对照兑现清单无缺项。

### 阶段5 · 与写章期衔接

- 卷纲只到"剧情点"粒度；对话、场面、节奏密度、具体描写归写章期临场。
- 章纲写"发生什么"，不写"怎么写"——写怎么写会拖死写章 agent。

### 自检三件（每卷结构完成后必做）

1. **第400章测试**：写到全书约 60%（约 400 章）处，流水线机制还能产吗——日常单元的活儿/委托/案件清单没耗尽（单元剧剧情库还有可映射的模板），洋葱还有没揭的层。答不上＝库存或流水线不足，回填。
2. **库存耗尽测试**：最后一层真相揭完即终局吗？有没有"最后一层揭开后没下一层"的问题（有＝终局后注水）。结尾钩子（续作接口）可开可关，不占正卷篇幅。
3. **篇幅核对**：总字数 ÷ 卷数 = 每卷字数；每卷字数 ÷ 每章字数 = 每卷章数，与单元表章节区间对得上。对不上＝单元分太多或太少，重排。

## ④ 产出SOP（怎么一步步产 + 每步验收基准）

**动工前先回读输入**：故事脉络五元素（03-故事脉络）+ 锁根设定（画像危机/三层地图、法则基石/养成线、格局起步格/卷推进表、主角设计欲望串/金手指档位表/准主线排期）+ 骨架设定（地理 14 块地、顶层势力登场卷位、历史分层真相、反派卷敌表）+ 篇幅与卷规划-SOP。

1. **（立主线脉络）**：定世界终点（故事脉络"结局"＋画像危机/内核）→ 定主角欲望线终点（主角设计欲望串）→ 判断绑定（同芯拧双脊柱：世界真相线洋葱分层＋个人命运线；并行则两线独立排期）→ 标每卷交汇点 → 排结算事件表。
   → 【验收基准】能一句话讲清"世界终点是什么、主角欲望线终点是什么、是否绑定"；同芯则能讲清"世界之谜的终点为什么是主角"；每卷有交汇点；结算事件表排到卷。
2. **（按质变切卷）**：主养成线质变点分布（N卷≈N±2 质变）＋ 无质变卷的补位（准主线/从线升档＋同级换图）。
   → 【验收基准】卷序总表列全（卷/阶位/地图/卷敌/单元循环配比/暗线推进/真相层），无质变卷不硬凑层级。
3. **（每卷填三同进）**：质变一次（或无质变则准主/从线升档一次）＋ 地图扩展一次 ＋ 世界矛盾解锁一层（明面卷敌/敌群＋暗面线步）。
   → 【验收基准】每卷能答"升到哪档/在哪块地图/解哪层矛盾"；卷敌档位对齐主角养成线（反派卷敌表直接引用）。
4. **（排明暗两线）**：明面 = 卷敌/敌群分步落推进单元；暗面 = 2-3 条跨卷暗线表（内容/推进卷位/收束卷位）；大boss组独立排（跨卷压阵位＋终卷正面结算位）。
   → 【验收基准】明暗两层都兑现；暗线不在一卷讲完；卷末钩子 = 下一层入口；大boss终卷正面结算。
5. **（挂真相层）**：洋葱每层挂卷位，与历史设定卷位对齐。
   → 【验收基准】每卷揭一层；层与层之间有认知递进（异常→机制→权力→本体）。
6. **（拆单元循环）**：查单元剧剧情库（check 一次三查）→ 全卷列单元表（5-7 单元 × 类型 × 节奏档位 × 章节区间 × 职能 × 参数递增 × 服务的卷主线点），日常:推进:结算 ≈ 50:40:10。
   → 【验收基准】单元数 5-7；每单元有明确类型/节奏档位/章节区间/职能/参数递增/服务的卷主线点；单元注明化用模板（模板名）；卷1 可拆到单元粒度示范（含章节区间与每单元关键内容），其余卷至少列单元名与区间。
7. **（写卷纲）**：逐卷展开期做——每单元先敲定"完整故事弧＋服务的卷主线点＋章节数"，再拆到章纲（每章：章号+标题+核心剧情点1-3句+单元归属+参数递增/钩子标注）；展开层人物一句话定性。
   → 【验收基准】对照兑现清单（三同进/明暗/真相层/质变验证战/卷末钩子/参数递增/单元剧生长性/节奏档位）无缺项；每章末有钩子；无"写怎么写"的描写性条目。
8. **（自检三件）**：第400章测试＋库存耗尽测试＋篇幅核对。
   → 【验收基准】三件全过；过不了的回填阶段 1/3/6，不硬写。
9. **（收尾验收一句话）**：**翻开任意一卷能说出"这卷升到哪档、在哪块地图、解哪层矛盾、撞哪个卷敌、揭哪层真相、跑哪几个剧情单元、卷末翻成什么"。** 抽查两三卷答得上＝全过。

**"怎么想出来"的三条路（并入每步，按顺序优先走第一条）：**
- **路径一 从硬约束推（默认）**：质变点切卷、三同进、单元配比、参数递增都是排期硬约束——先满足约束再想内容，内容从设定里"这卷该兑现什么"长出来，不临场编戏。
- **路径二 设定回读**：卷卡写不出来时回读设定（这卷的卷敌是谁/这卷揭哪层真相/这卷升哪档），设定已定答案，卷只是排它的位置。
- **路径三 验收基准反推**：把④验收基准反过来当生成问题（"这卷卷末翻成什么""这单元结束读者手里多了什么"）。
