# 小说设定 总SOP（总目录 / 总览）

> 用途：本文件是小说设定的**总目录**。只做总览，不写任何单份设定的详细内容。
> 总目录 = 设定总账（这本书要建哪些设定文档，每份标产出时机）＋ [管线全貌](管线全貌-SOP.md)（设定在整条管线的产出节奏，已独立成档）。
> 分工：每一份设定的**产出SOP＋质量要求＋先决条件**在 `小说设定/` 子文件夹各自的文档里，本文件只做索引。
> 定位：沉淀稿，认知可能不是最终版。先用真实案子验证，改到实测过才算数。

> **链路顺序（v2 修正）**：**世界画像 → 世界法则 → 世界格局 → 主角设计。** 画像先定"这世界长什么样、最被抢什么"（内核），法则再从中点出**基石**定"强怎么构成"；先画像后法则，基石才不会凭空造（赛博朋克先定"钱>一切"→ 基石=钱）。这份链路顺序在所有相关设定里都要保持。

***

## 1. 一句话思路

设定不是一次性浇完的整体，是一份**分步交付**的东西：它被剧情一步步召唤。所以不纠结"先设定还是先剧情"，只认一件事——**每份设定在管线的哪个位置被产出、产出到什么质量算好**。总账标好时机，管线全貌画清楚节奏（见[管线全貌-SOP](管线全貌-SOP.md)），剩下的具体产出交给子文件夹。

消费对象是写作 agent。agent 没有作者的记性，所以"每份设定的产出时机"必须直接标在总账里，不靠临场推。

> 沿革：早期用"重要性 × 不可逆 → A/B/C/D 档位"决定产出时机，已废弃（临场评分，靠感觉）。现在**产出时机直接作为 tag 标在设定总账每一份上**，产出方法与质量放子文件夹；产出节奏的总览已独立成[管线全貌-SOP.md](管线全貌-SOP.md)。

## 2. 设定总账（拆到具体设定文档，每份标产出时机）

把一整本书可能要用到的设定文档逐份列出。这是总目录——"这本书要建哪些设定文档"，不是评分表。同一本书边写边有新设定，往相应大类加，不用一版定死。

**产出时机的 tag 含义**：

| tag | 含义 |
| --- | --- |
| 锁根 | 核心设定设计阶段定，主路径必踩、近乎不可逆 |
| 骨架 | 主线剧情设计阶段定到骨架级，决定全书形状但不需马上全展开 |
| 展开 | 排卷排到那一卷才展开 |
| 写章 | 写到那一章才造的细节，临场造即可 |

> 这四档对应到[管线全貌-SOP.md](管线全貌-SOP.md)的四个阶段，tag 和阶段怎么对上，看那份文档。

### ① 世界画像——这个世界长什么、内核在驱动什么（链路第一步）

世界的"画面 + 内核"。先定调（时代/内核/独特点/代价/危机/隐喻），再画地图，**并标出"这世界最被抢的东西"（内核）**——它正是《世界法则》要点名成基石的那个。**产出的位置在链路第一个**，因为法则的基石从它点出。

| 设定文档 | 回答 | 产出时机 | 详细文档 |
| --- | --- | --- | --- |
| 世界画像 | 世界本体长什么样 + 最被抢的内核（供法则点基石）+ 三层地图 | 锁根 | [世界画像.md](小说设定/世界画像.md) |
| 宏观地理格局 | 东西大陆/上中下界级别，一张能排戏的棋盘 | 骨架 | [宏观地理格局-SOP.md](小说设定/宏观地理格局-SOP.md) |
| 世界历史/时代背景 | 与结局相关的那一段历史（危机因果链） | 骨架 | [世界历史与时代背景-SOP.md](小说设定/世界历史与时代背景-SOP.md) |

### ② 世界法则——这个世界怎么运转、人怎么上升（基石从画像内核点出）

世界的"强"怎么构成。**核心结构：两侧对开（武力侧 + 非武力侧，各有基石，武力侧可多基石）→ 子解决方式（战斗/社会对抗）→ 各配养成线。** 关键约束见文档：**基石从画像内核点名**、**爽文无真代价**、**养成线主1+准主1+从≥3+金手指特殊养成系硬规则**。

```
        武力侧（通常主打）                非武力侧（通常次之）
基石      钱(赛博)/序列(诡秘)/灵气        社会地位/资产量级
子方式    战斗/法术/忍术/忍具            商战/权谋/规则/谈判
养成线    序列升级/境界/血继限界          升职/社交/签单（能量化等级）
```

养成线是重点：**主1条+准主1条（两侧对开都重要时强制升格，每卷必升档、质变与主线错开）+从≥3条，各不同维度且不重叠**，必须量化为等级节点（序列1-9、境界、资产量级），否则爽感和排卷无处兑现。**主角独有的例外刻度（金手指）作为一条特殊养成系，在《主角设计》显式声明三件套（独立档位表/每档成长量/与主养成线对表），不写进世界法则。**

| --- | --- | --- | --- |
| 世界法则 | 从画像内核点名基石 + 两侧子方式 + 量化养成线 | 锁根 | [世界法则.md](小说设定/世界法则.md)（v7：基石从画像点、无真代价、养成硬规则） |
| 职业/流派/方向 | 主角走哪条路、能分几个方向 | 展开 | （待建） |
| 力量外物 | 魔法/异能/道具/装备，用到再建 | 写章 | （待建） |

### ③ 世界格局——把地图铺成棋盘、放主角（画像/法则之后）

把画像的地图 + 法则的力量摆上棋盘：谁占哪格、哪两格对冲、主角从哪格往哪打。势力=棋子、矛盾=冲突线。

## 3. 产出节奏看管线全貌

总账只回答"有哪些设定、每份何时产（tag）"。**"为什么是这个时机""整条管线从创意到写章长什么样"**，见独立的[管线全貌-SOP.md](管线全貌-SOP.md)。那里有完整的分阶段图和四条要点，本文件不重复。

> **链路顺序提醒（重要）**：世界法则相关设定，必须先走世界画像（内核标出"最被抢的东西"），再点名基石；不要因为"世界法则看起来更重要"就先造它。产出节奏见管线全貌。

## 4. 总账之外就一句收束

**总账告诉你"有哪些设定、每份何时产（tag），链路顺序是 画像→法则→格局→主角"，[管线全貌-SOP](管线全貌-SOP.md)告诉你"为什么是这个时机、整条线怎么走"。** 真正动手产出某一份时，去 `小说设定/` 对应的文档，按它的产出SOP产、按质量要求验收、先满足它的先决条件。总目录本身到此为止，不写任何单份的操作细节。

**剧情产出（主线脉络/卷级结构/卷纲/章纲）不是设定总账范围**，做法见[剧情产出-SOP](剧情产出-SOP.md)。
