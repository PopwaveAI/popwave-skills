# 设定文档 · 世界历史与时代背景-SOP（骨架）

> 从属：小说设定总SOP（小说设定-SOP.md）①「世界画像」后续。
> 产出阶段：**主线剧情设计阶段**（设定总账 tag=骨架），在世界画像（危机）之后。
> 地位：只写**与结局相关的那一段历史**（总账定义）——不是通史，是"为什么这个世界现在是这个失衡样"的来龙去脉。
> 依赖：建立在 世界画像（危机/内核）、世界法则（基石）之上；产出供 顶层势力（掌权成因）、主要反派（动机成因）、卷纲（每卷揭一个底层真相）使用。
> 范式：按【设定文档-统一模板-v1】四段式；吸收 pop-snow-stage「时代质感」与对比研究「每卷揭一个底层真相」设定节奏。

---

## ① 文档定位（这是份什么，静态定义）

**世界历史与时代背景 = 这个世界"为什么现在是这个样"的来龙去脉。** 回答：造成当前世界失衡的那段历史是什么？这个时代的质感是什么？

- **角色**：骨架。与结局相关的历史段落定死，其余历史留白。
- **回答**：当前危机的来龙去脉？时代的质感（政治/文化/氛围）？
- **链路位置**：① 的后续（世界画像 → 世界法则 → 世界格局 → 主角 → **世界历史**）。画像的危机是本份的终点。
- **依赖**：世界画像（危机/内核）、世界法则（基石）。产出供 顶层势力（历史遗留的格局）、主要反派（从历史长出来的动机）、卷纲（每卷揭一层真相）使用。
- **一句话落点**：能一句话讲清"这个世界为什么现在是这个样"，且历史能解释现在的每个关键现状。

它不是：
- 不是**编年史/通史**（每朝每代都写——只写与结局相关的段落）。
- 不是**设定集**（宗教/民俗/政治制度列表——那些写章期造）。
- 不是**人物传记**（历史人物归角色档）。

> 判据：写完①，读者知道"这份管时间维度、为什么这么写"，但不知道"怎么填"——怎么填是②。

## ② 思考逻辑（填的时候脑子怎么转，动态方法）

**这条推演痕迹（agent 最该掌握）：历史 = 危机的来龙去脉——从画像的"当前失衡"倒推，只写"造成这个失衡"的那几段，其余留白。时代质感 = 读者第一眼看到的世界味道。**

- **倒推，不顺着写**：从世界画像的危机（当前世界失衡成什么样）倒推：这个失衡是哪次事件造成的？那次事件之前是什么样？只写这一条因果链，其他历史不写。
- **历史服务现状**：每段历史必须能解释"现在的某个现状"——现在谁掌权（历史遗留）、现在谁恨谁（历史恩怨）、现在什么资源缺（历史消耗）。解释不了的段落，删。
- **时代质感三件套（吸收 snow-stage）**：政治格局（谁管谁）、文化氛围（读者第一眼的味道：蒸汽朋克的煤灰/仙侠的灵气/赛博的霓虹雨）、底层生活（普通人怎么过）。
- **历史是钩子库（吸收对比研究「每卷揭一个底层真相」）**：把历史拆成"分层真相"——表层认知（主角初入世界以为的）→ 深层真相（每卷揭一层，卷末反转认知）→ 底层真相（支撑终局）。每卷一个"读者以为A，揭出B"的真相，历史就是这组真相的藏身处。

> 判据：一份合格的②，读的人该能模仿"从危机倒推因果链 → 段段解释现状 → 配时代质感 → 拆成分层真相"这套思路，换题材照推。

## ③ 文档内容（写进小说 / 结构 / 表格 / 案例）

### 结构总览

| 构件 | 填什么 |
| --- | --- |
| 危机因果链 | 当前失衡 ← 关键事件 ← 之前的状态（只写这条链） |
| 现状解释 | 每段历史 → 解释现在哪个现状（掌权/恩怨/资源） |
| 时代质感 | 政治格局 / 文化氛围 / 底层生活 三件套 |
| 分层真相 | 表层认知 → 深层真相（每卷揭一层）→ 底层真相（终局） |

### 案例 ≥2 跨赛道

**案例1 · 遮天（仙侠）**
- **危机因果链**：当前=仙路断绝、众生无望证道；关键事件=上古末年仙路崩塌、大帝纷纷陨落；之前=仙路通、证道者辈出。
- **现状解释**：现在圣地世家掌权（历史：上古大教传承）；禁区至尊横压（历史：证道失败者自封禁区）；资源稀缺（历史：仙路崩消耗大量资源）。
- **时代质感**：政治=圣地世家分治北斗；文化=修士拜大帝、求长生；底层=凡人在修士庇护/剥削下求活。
- **分层真相**：表层=成帝就能长生；深层1（前几卷）=禁区至尊是失败的大帝；深层2（中卷）=仙路崩塌是人为；底层（终局）=重开仙路的钥匙在主角身上。

**案例2 · 诡秘之主（克苏鲁维多利亚）**
- **危机因果链**：当前=序列越高越疯狂、末日预言逼近；关键事件=罗塞尔大帝留下的遗产与隐秘时代的旧日复苏；之前=蒸汽时代初兴、非凡者活跃。
- **现状解释**：现在正神教会掌权（历史：对抗旧日建立秩序）；隐秘组织林立（历史：罗塞尔时代的遗留）；非凡者被追杀或拉拢（历史：官方与地下分裂）。
- **时代质感**：政治=维多利亚式帝国+教会；文化=绅士侦探、纸页泛黄的报纸；底层=工人与贫民窟、煤气灯。
- **分层真相**：表层=序列是力量阶梯；深层1=扮演法背后是牺牲与疯狂；底层（终局）=灰雾之上与旧日的真相。

**泛化验证**：同一套"危机因果链→现状解释→时代质感→分层真相"，在"仙侠（历史漫长、格局大）"和"克苏鲁（历史近、阴谋密）"两个赛道都成立——历史长度随题材定，结构不变。

### 3. 弱世界观变体（都市 / 言情 / 纯爱用）

弱世界观历史坍缩成"前情"：

| 强世界观成分 | 都市言情降维成 |
| --- | --- |
| 危机因果链 | 当前关系困局 ← 过去某件事 ← 之前的状态 |
| 现状解释 | 现在的误会 / 心结 / 恩怨，都能被前情解释 |
| 时代质感 | 年代质感（故事发生的时代氛围：校园 / 职场 / 年代文） |
| 分层真相 | 每卷揭一层"当年真相"，卷末反转认知 |

## ④ 产出SOP（怎么一步步产 + 每步验收基准）

1. **回读画像危机**：世界画像的危机（当前世界失衡成什么样）。
   → 【验收基准】危机是本份的终点，倒推起点明确。
2. **倒推因果链**：当前失衡 ← 关键事件 ← 之前状态。
   → 【验收基准】只写这条链，不写通史；链上每段都能解释一个现状。
3. **写时代质感**：政治格局 / 文化氛围 / 底层生活 三件套。
   → 【验收基准】读者第一眼能闻到这个世界的味道。
4. **拆分层真相**：表层认知 → 每卷揭一层的深层真相 → 底层真相（终局）。
   → 【验收基准】卷数与真相层数对齐（N卷≈N层）；每层是"读者以为A，揭出B"。
5. **边界检查**：检查是否把《顶层势力》（现在谁掌权）写成了势力表、把《主要反派》（从历史长出的反派）写成了人物——有→只留"成因"，归位。
   → 【验收基准】本份写"历史怎么造成现状"，不写"现状长啥样"的完整版。

## 附：与相邻设定的边界

- **世界画像（前面）**：危机/内核——本份是危机的前传。
- **宏观地理格局（兄弟档）**：空间维度——本份是时间维度。
- **顶层势力（后面）**：现在谁掌权——本份解释"掌权是怎么来的"。
- **主要反派（后面）**：反派的动机——本份解释"反派从什么历史里长出来"。

> 一句话：画像说"现在失衡成这样"，历史说"怎么失衡的、现在的人活在什么味道里"。
