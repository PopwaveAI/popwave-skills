# 设定文档 · 世界格局（锁根）

> 从属：小说设定总SOP（小说设定-SOP.md）②「世界地图」归类（锁根子集），是《世界画像》的下一份。
> 产出阶段：**世界画像之后、主角设计之前**。
> 地位：把前两份算出的东西"摆上桌"。世界法则是"怎么玩"、世界画像是"长啥样"，这一份回答**怎么摆、谁在台上、为何而战**。
> 依赖：建立在 世界法则（怎么玩）＋ 世界画像（三层地图、每层地理构成/强者档位/特殊地点）之上；产出供 主角设计 使用。
> 定位：本份为**一篇**，把原「世界格局 / 主要势力 / 势力矛盾」三份合一，统一从"格局（棋盘）"角度写。
> 范式：按【设定文档-统一模板-v1】四段式重构；内容硬规则一字未动，旧「质量要求」并入④，试填复盘归拢内容/待处理问题。

## ① 文档定位（这是份什么，静态定义）

**世界格局 = 把这世界铺成一张棋盘：哪块地图归谁、谁占哪格、格子之间为什么对冲、主角从哪格起步往哪打。**

- **角色**：锁根。世界画像之后、主角设计之前。
- **回答**：怎么摆、谁在台上、为何而战（怎么把世界当一个可走动的局面来看）。
- **链路位置**：③（世界画像 → 世界法则 → **世界格局** → 主角设计）。
- **依赖**：建立在 世界法则（怎么玩）＋ 世界画像（三层地图、每层地理构成/强者档位/特殊地点）之上；产出供 主角设计 使用。
- **一句话落点**：读者能在地图上指认："这是谁的地盘，主角在这里面要从哪打到哪"。

它不是"世界长什么样"（那是画面），也不是"强是什么"（那是法则），而是**把世界当一个可走动的局面来看**。

三样东西在这里合并成一篇，但以"格局"为主纲（势力与矛盾都是棋盘上的格子和冲突线，不单独成章）：

| 概念 | 定义（是A，不是B） | 在棋盘里的角色 |
| --- | --- | --- |
| 世界格局 | 地图怎么分格、哪块归谁的势力范围 | 棋盘本身（格面 + 归属） |
| 主要势力 | 谁在台上，占哪个格、强在哪档 | 棋子（占格的主体） |
| 主要矛盾 | 格子与格子之间为什么对冲、挡不挡主角 | 棋局（冲突线） |

一句话落点，三句连读：**棋盘铺开 → 谁占哪 → 哪两格要撞。**

## ② 思考逻辑（填的时候脑子怎么转，动态方法）

**这条推演痕迹（agent 最该掌握）：把世界铺成一张棋盘——地图分格、势力占格、格间拉冲突线、主角从起步格往升层打。**

- **立场 = 棋盘，不是势力列表**：不按"势力列表"写，按"逐层棋盘"写。每层地图 = 一张棋盘格面，格子上坐势力，格子间拉冲突线。这是本份从世界观到剧情的桥梁——读者要能在图上指着说"谁的地盘"。
- **三层对齐（继承画像三层制）**：每层的势力都能落进"顶层/中层/底层"某一格的档次——顶层是层底Boss（主角升层门槛）、中层是沿途打脸/收编对象、底层是陪衬/爽感群众。
- **矛盾 = 哪两格对撞**：不是抽象写"两大势力对立"，是落到棋盘上"这两格为什么撞"。门类：格间宿怨（占位之争）→ 资源争夺（抢稀缺物资，对接法则物资）→ 围绕危机（掩盖/引爆/堵死画像的危机）。
- **放主角 = 把棋局收敛到主角脚下**：先定升层触发主型（打Boss/位格晋升迁移），再定起步格、往哪打、每卷推进点。这一步给后面的主角设计摆好局——本份不造主角，只铺他脚下的棋盘。
- **分双轨**：强世界观走三层棋盘；弱世界观（都市/言情）棋盘坍缩成关系版图（势力降维成"家庭/职场/情敌"，矛盾降维成"情感+阶层阻力"单线对冲）。

> 判据：一份合格的②，读的人该能模仿"继承画像三层地图当棋盘 → 逐层摆势力（顶层/中层/底层）→ 逐层画冲突线（宿怨/资源/危机，单独标'谁挡主角'）→ 放主角（定升层主型+起步格+路径）→ 按题材选轨"这套思路，即使换一个完全不同题材（把遮天换到都市言情）也能照这个推法想出来。

## ③ 文档内容（写进小说 / 结构 / 表格 / 案例）

### 1. 棋盘总览（把地图变成棋盘，一图看懂）

继承《世界画像》的三层大地图，但这里不是"画面"，是**棋局**：每层地图 = 一张棋盘格面，格子上坐着势力，格子间拉出冲突线。

| 层 | 棋盘格面（继承画像2.4地理构成） | 主角起步格 | 这层的层底 Boss（天花板） |
| --- | --- | --- | --- |
| 第1层 | 主城的几块区域 / 五域 / 一国诸州 | 出生地（往往是偏远、被压的格子） | 这层霸主 |
| 第2层 | 更大的一国/一域/星空古路节点 | 升层后进的新舞台 | 中阶天花板 |
| 第3层 | 上界/终极禁区/真灵界 | 收束舞台 | 全书天花板 |

> 判定：这一节要能用**三行**（每层一行）讲清"棋盘空着时长什么样"。讲不清格子有几块、谁是地头，就回《世界画像》2.4补地理构成。

> **层可厚可薄（分布基准可偏）**：模板默认"3层=质变分布3-2-1"，那是"每层权重递减"的无声明默认。真实书常打破它——如《诡秘之主》凡世一层独背序列9→3六卷、另两层各薄，分布更像 6-2-2。**层数或分布偏离 3-2-1 都合法，只要符合篇幅与卷规划；一层内可跨多卷横向换图，别为了凑 3-2-1 硬拆。** 实测发现和真实书对不上时，以书为准。

### 2. 逐层摆势力（谁在台上、占哪格）

不按"势力列表"写，按**逐层棋盘**写——每层把"占这层的势力"摆上去。每个势力至少定四件事：**名 / 占地（哪格）/ 主养成线档位 / 对主角的作用**（挡路 / 助力 / 工具 / 中立）。

每一层都三层对齐（对回《世界画像》2.2 三层制）：

| 层内层级 | 角色 | 占哪格 | 对主角的作用 |
| --- | --- | --- | --- |
| 顶层/统治阶级 | 层底 Boss、霸主势力 | 该层最肥的一格 | 主角这层最后一战的目标、晋升入下层的门槛 |
| 中层/精英 | 各关键势力的当家人、爪牙 | 该层诸格 | 沿途打脸、收编、立威的对象 |
| 底层/背景 | 平民、市井、散户 | 零碎的小格 | 衬托、供爽感 |

> 判定：每层的势力都能落进"顶层/中层/底层"某一格的档次——**棋盘上没有"不知该归谁"的势力**，有就归到最近的一层/一格。

### 3. 逐层写矛盾（为何而战、挡不挡主角）

矛盾不抽象，落到棋盘上就是"**哪两格对撞**"。每一层画冲突线，分三类（对回《世界法则》物资 + 《世界画像》第5步危机）：

1. **格间宿怨**：两块地盘之间的世仇、侵吞、吞并（占位之争）。
2. **资源争夺**：围绕稀缺物资的争抢（灵石矿脉/魔药配方/公司份额），源头上对接《世界法则》物资系列。
3. **围绕危机**：围绕《世界画像》第5步"危机（会炸开的开关）"展开的角力——谁在掩盖、谁在引爆、谁在堵死。

关键一句**"谁挡主角"**：主角升层要过的那条冲突线要单独标出——它往往是"某格势力压着主角起步格"，主角从被压到反压，就是这一层的戏。

> 判定：每一层至少有一条能被一句讲清的冲突线（"格格与乙格因为X在撞，主角夹在中间要怎么办"）。讲不清"为谁而战"，回世界法则确认这层的稀缺物资是什么。

### 4. 主角的起步格与升层路径（把主角放上棋盘）

把棋局收敛到主角脚下：

1. **起步在哪**：主角出生/入局在哪个格（往往是偏远、被压、有暗格的那格）。
2. **往哪打**：沿着第3节画的冲突线，从起步格一步步力压同格势力 → 抢中层 → 最后顶到升层门槛。
3. **升层触发（分两类，先定这书属于哪种）**：
   - **打 Boss 型**：明显的"层底 Boss"，主角力压它才进下一层（遮天打禁区之主、斗破打迫近的强者）。常见于玄幻/仙侠。
   - **位格晋升迁移型**：升层由"晋升位格"驱动——主角到达某序列/位格，满足迁入更高层舞台的门槛（诡秘从凡世升半神秘领域靠"晋升序列4半神"迁移，不是打趴一个 Boss）。常见于神秘/体系流。
   - 两型可混用（书里往往局部打Boss、整体靠位格）。**先写明主型，别默认一定是打Boss。**
4. **与卷数对应**：每卷 = 棋盘上推进一段（对回《篇幅与卷规划》卷定义：成长 + 扩格 + 解一层矛盾同周推进）。**一层内可跨多卷**（诡秘凡世层独自撑了卷1-6）。

> 判定：写完后，能答"主角从哪格到哪格经历了几战/几次晋升、每步动了棋盘上哪块"，这条路径就成立了。

### 案例 ≥2 跨赛道

**案例1 · 遮天（强世界观·仙侠，打Boss型）** —— 完整棋盘见示例A（附）

- 第1层北斗棋盘：东荒/中州/西漠/南岭/北原五格 + 荒古禁地特殊格；顶层圣地/世家/禁区之主（占肥格挡升层），中层宗门长老/世家嫡系，底层山村野修。
- 冲突线：宿怨（圣地与世家争霸中州）+ 资源（夺灵脉/神源/帝经）+ 围绕危机（禁区至尊发动黑暗动乱）。
- 升层：打Boss型——角逐北斗之巅、摁平顶层禁区Boss，进第2层星空古路。

**案例2 · 微微一笑很倾城（弱世界观·都市言情，关系进阶型）** —— 完整棋盘见示例B（附）

- 棋盘坍缩成关系版图：校园+网游+职场三个关系格。
- 势力降维成人：女主在游戏格、男主在校园+职场格、情敌挡在关系格。
- 矛盾降维成情感线：宿怨（"被真水无香抛弃"的误会）+ 资源（网游双强竞技）+ 围绕危机（身份认知错位）。
- 升层：关系进阶迁移型——误会解开、关系格坎迈过，收束——不铺三层地图。

**案例3 · 诡秘之主（强世界观·克苏鲁，位格晋升迁移型）** —— 用真实书实测（附复盘）

- 棋盘：廷根→贝克兰德→海上→神弃之地能干净认作"同一凡世棋盘的横向换图"（验证横换≠升层）；七神教会/隐秘组织/塔罗会三极落格清楚。
- 升层：位格晋升迁移型——靠"晋升序列4半神"迁入更高层舞台，不是打趴一个Boss。
- 矛盾：末日预言把宿怨+资源+危机三类拧成一条总矛盾。

**泛化验证**：同一个结构（棋盘→摆势力→画冲突线→放主角→定升层型），在"仙侠(打Boss型)/都市言情(关系进阶型)/克苏鲁(位格迁移型)"三个赛道各长成三本书——证明骨架通用，升层双型与双轨是真实存在的分岔，不单配一个赛道。

## ④ 产出SOP（怎么一步步产 + 每步验收基准）

**动工前先按题材选轨**（对回《世界画像》双轨）：强世界观走"棋盘"主纲、三层全铺；弱世界观走"关系版图"，不铺三层地图。

1. **铺棋盘**（第1节）：继承《世界画像》三层地图，每层定"几块格 + 主角起步格 + 层底 Boss"（升层如属位格迁移型，此处写"升层门槛位格"）。
   → 【验收基准】三行能讲清"棋盘空着时长什么样"；讲不清就回画像2.4补地理；层厚不硬凑3-2-1。
2. **摆势力**（第2节）：每层把顶层/中层/底层势力放进格子，各定【名/占地/档位/对主角作用】。
   → 【验收基准】每层势力都能落进"顶层/中层/底层"某一格；棋盘上没有"不知归谁"的势力。
3. **画冲突线**（第3节）：每层拉出"哪两格对撞"，分宿怨/资源/危机三类；单独标"谁挡主角"。
   → 【验收基准】每层至少一条可一句讲清的"哪两格为何对撞"；且能溯源到法则物资或画像危机；"谁挡主角"单独标出。
4. **放主角**（第4节）：先定升层触发主型（打Boss / 位格晋升迁移），再写主角起步格 + 升层路径 + 每卷推进点。
   → 【验收基准】能答"主角从哪格到哪格经历了几战/几次晋升、每步动了棋盘哪块"；升层按主型走，不硬套打Boss。
5. **收尾验收一句话**：读者能不能在地图上指认"谁的地盘、主角从哪往哪打"。
   → 【验收基准】全过：这是一张能走的棋盘，不是抽象势力表；且把"谁在台上、为何而战"留给主角设计（本份不提前造主角）。

**怎么想出来的辅助（并入每步）**：
- 从棋盘想："这层几格？谁占肥格？哪两格要撞？主角夹在哪？"——把抽象世界观落成能指认的局面。
- 升层想双型先定："这书靠打趴一个Boss升层（遮天），还是靠晋升位格迁移（诡秘）？"——别默认一定是打Boss。
- 弱世界观想关系版图："势力降维成家庭/职场/情敌是谁？矛盾降维成情感+阶层阻力这条单线？"——不硬铺三层地图。

## 附：与相邻设定的边界

- **世界法则**（前面）：世界"如何运转、强是什么"（规则层）。
- **世界画像**（前面的前面）：世界"长啥样"（画面层），定三层地图、强者档位、危机。
- **世界格局**（本份）：把画面铺成**棋盘**——怎么摆势力、哪两格对撞、主角从哪往哪打。势力与矛盾都在棋盘内。
- **主角设计**（后面）：真去造主角这个人（本命/金手指/欲望串），本份只给他摆好脚下的局。
- 分工：法则管"规则"，画像管"画面"，格局管"摆放"，主角设计管"人"。四层各管一头，不重复。

> 一句话：世界法则说"这世界怎么玩"，世界画像说"这世界长啥样"，世界格局说"这张牌桌上谁占了什么、主角要从哪格打到顶"，主角设计说"这个人是来怎么做这件事的"。

## 待处理问题（这份眼下还没定 / 存疑 / 待实测）

- [ ] **「升层触发双型」是否覆盖所有真实书的升层路径**：目前分 打Boss型 / 位格晋升迁移型，两型可混用。但有书可能"既不打明确Boss、也不靠位格晋升"，而是靠"达成某件具体事"（如解开某个谜、集齐某物）触发升层——这类算不算需新增第三型，未核。
  → 为什么悬着：双型从遮天（打Boss）和诡秘（位格迁移）归纳，样本还是少。
  → 等谁定：更多升层路径不同的真实书实测。
- [ ] **棋盘对"顶层势力与主角敌对/助力"的预判**：本份只摆"谁占哪格 + 作用（挡路/助力/工具/中立）"，不决定主角立场+目标。这要求升主角设计之后回填；但"离开主角是否会让你铺垫的势力后续对不上"未在多案例核过。
  → 为什么悬着：棋盘是"可走的局"，真正敌对/助力主逻辑靠主角设计，二者衔接在单一案例上没跑通。
  → 等谁定：走完整链（格局→主角设计）的真实书实测。
- [ ] **弱世界观「关系版图」是否够格独立成棋盘**：仙村镇树林只给出"关系版图"的概念和样例B，判据（势力降维人/矛盾降维情感单线/升层=关系进阶）是否够用、是否和"强世界观棋盘"是同一骨架的降维，未在多案例核过。
  → 为什么悬着：样例B用《微微一笑很倾城》验证了概念，但"关系版图"的完整填法和边界（什么算关系进阶）没铺开。
  → 等谁定：更多都市言情/纯爱真实书走关系版图实测。
