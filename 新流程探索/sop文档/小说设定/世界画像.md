# 设定文档 · 世界画像（锁根）

> 从属：小说设定总SOP（小说设定-SOP.md）①「世界地图/世界历史」归类，本份是链路第一步。
> 产出阶段：**核心设定设计阶段**（设定总账 tag=锁根）。
> 地位：**世界法则之前、世界格局之前。** 回答"这是一个什么样的世界"，是一切设定的画面源头，也是世界法则「基石」的产地。
> 范式：按【设定文档-统一模板-v1】四段式重构；内容硬规则一字未动，旧「质量要求」并入④，散落技术标记归拢「待处理问题」。

---

## ① 文档定位（这是份什么，静态定义）

**世界画像 = 这个世界本体长什么样，以及它的内核在驱动哪些规则。** 它不是"力量规则"（那是世界法则，且在本份之后），而是读者一眼望过去的世界画面与底色，以及一个驱动一切的"内核"。

- **角色**：锁根。链路第一步。
- **回答**：这是一个什么样的世界？（读者闭眼能想象出主角生活的世界样貌）
- **链路位置**：①世界画像 → ②世界法则（基石从内核点出，本份产出指向它）→ ③世界格局 → ④主角设计。
- **依赖**：建立在《篇幅规划》之上（几层地图、几次质变）；**产出供 世界法则（内核→基石）、世界格局/主角设计 使用**。
- **一句话落点**：读者闭上眼，能想象出主角生活的这个世界的样貌；而世界法则的基石，要从这里的内核长出来。

分层向下（本份只到"画面 + 内核"，格局/势力/矛盾是下一份）：

```
这是一个什么样的世界（底层画像：风貌·时代·底色 + 驱动力内核）
  → 世界法则（强怎么构成，基石从内核点出）【下一份，本份产出指向它】
  → 世界格局（怎么摆：地图·阵营·分布）【再下一份】
  → 主要势力（谁在台上）【再下一份】
  → 势力矛盾（他们为何而战）【再下一份】
```

> 一句话：这决定整本世界观的底盘与气质，定下之后一切画面都从这里长出来。

## ② 思考逻辑（填的时候脑子怎么转，动态方法）

先看清结构：**定调不是"六个平级步骤"，而是"1条递进线 + 3条平行支线 + 1条升华维 + 1个前置量级"。** 有的要往深挖（递进）、有的一圈展开（平行）、有的是自选升华。照这个结构填，才不会"不知道填到多深"。

```
【前置量级】这世界有多大？（太阳系/一个星球/一座城）★先定，量级定了再生画面
  │
【递进线：往深挖，一层比一层深】
  壳（表）→ 内核（里：这世界在推人做什么）
  │
【平行支线：从内核长出来，不是比内核更深，是环着内核展开、互相校验】
  独特点（奇） ←→ 代价/各阶层日常（痛） ←→ 危机（破）
  │    都是内核的暴露面，不是递进关系
【升华维：自选，可加可不加】
  隐喻（厚）
```

**这条推演痕迹（agent 最该掌握）**：

- 深挖不是堆形容词，是**一层层往下挖**——从表面（壳）挖到"世界为什么会这样、又要崩在哪"（内核→危机）。填到"表面什么味、内在推人做什么、凭什么独特、活下去要付什么、崩在哪、在讲现实什么"全清楚，才算有底盘，不是套壳。
- **内核是总命题，且是世界法则基石的产地**：找"这世界最根本的一条因果链 如果X那么Y"，并推演到社会/经济/文化三层；"最被抢的东西"要从这里点出来（钱/序列/灵气），法则只负责给它定体系。
- **画像 = 画面的源头**：主角穿着、城市建筑、对话腔调全由壳/色调定调；各阶层日常、危机都是内核的暴露面，不是独立发明。

> 判据：①是"是什么"（定位），②是"怎么想"（上面这套推演）。读的人该能模仿"先定量级→再挖壳到内核→再环着内核展开三支线→自选升华"这套思路。

## ③ 文档内容（写进小说 / 结构 / 表格 / 案例）

### 结构总览：一张表（六步 + 量级 + 结构）

| 构件 | 填什么 | 结构角色 |
| --- | --- | --- |
| 第0步 物理范围 | 世界大到什么尺度（先定量级） | 前置量级 |
| 第1步 壳（表） | 时代基调/主要风貌/世界色调/一句话关键词 | 递进线第一层 |
| 第2步 内核（里） | 总命题"如果X那么Y"+推演到社会经济文化；**点出"什么最被抢"** | 递进线第二层 |
| 第3步 独特点（奇） | 一切东西都遵从的蹊跷规则、最记住的画面 | 平行支线① |
| 第4步 代价/各阶层日常（痛） | 世界级代价 + 各阶层"一天" | 平行支线② |
| 第5步 危机（破） | 双层失衡 + 会炸开的开关 | 平行支线③ |
| 第6步 隐喻（厚） | 影射现实哪条议题（自选） | 升华维 |

### 第0步 · 物理范围（先定量级，再画任何画面）

在动笔画风之前，先定这世界的物理范围。问法：这世界大到什么尺度？主角活动的主要舞台是多大？

**量规表（防写小，先查这张表再定）**——物理范围必须由**篇幅量级**垫底，不得低于下限：

| 篇幅量级（书长） | 世界尺度下限 | 说明 |
| --- | --- | --- |
| 短篇 / 50万以内 | 一座城 / 一小片区域 | 终点小，单城装得下 |
| 中篇 50万-200万 | **至少一个星球** | 地图得撑起几十卷的纵深 |
| 长篇 200万-500万 | **多元宇宙 / 复合世界群** | 一个星球不够，要"上界/天外/平行层" |
| 超长篇 / 500万+ | 复合世界群 + 多层位面 | 单调一层世界撑不住 |

> **判据（三条，必须全过）**：
> 1. **量级垫底**：对照量规表，这书的物理范围 ≥ 篇幅量级下限。**200万字以上，绝不允许只有一座城**——除非这书明确定位"城市史诗"且终点就在这一城（如都市、某类型）。一上来就把世界缩成单城，是直接暴露"没做增量调研、没参考世界模型"的失职。
> 2. **配得上终点**：范围上限要能装下全书终点的量级（终点推多大，物理世界就得大到多少）。
> 3. **有真实纵深**：不是"写了很大"的空壳，而是"主角活动半径有梯度"——从出生的小区域，一路能扩到更宏观的舞台。

> **常见雷区（为什么总写小）**：一说"赛博朋克"就默认单城、一说"克苏鲁"就默认一座古宅。错了——**赛博=城可扩到整颗殖民星、克苏鲁=宇宙/多文明尺度**。画像定范围前，先查 {赛道库-SOP.md} 各流派的「舞台/世界规模」一行，再查量规表垫底；两处都过不了就别写小。

### 第1步 · 壳（表）：这世界第一眼什么味

1. **时代基调**：中世纪欧洲 / 工业时代英伦 / 近未来现代 / 古代东方 / 末世 / 星际……（一句话）
2. **主要风貌**：蒸汽朋克 / 克苏鲁暗黑 / 仙气飘渺 / 废土萧瑟 / 赛博霓虹……（决定画面的风格滤镜）
3. **世界色调**：阴沉哥特 / 明亮希望 / 压抑灰 / 冷金属 / 复古暖……（情绪底色，直接影响代入感）
4. **一句话关键词**：如"黑暗茶会上的蒸汽伦敦""末世孤岛上的异能文明"。

> 作用：主角穿着、城市建筑、对话腔调全由这里定调。决定读者第一眼瞳孔里是什么。

### 第2步 · 内核（里）：这世界在推着人做什么（总命题＝世界法则基石产地）★深挖到底

不是找奇景，是找**这个世界最根本的一条因果链"如果X，那么Y"**，并且能一路推演到社会、经济、文化三层。

- 问法：这世界的人被什么驱赶着活？什么东西最被抢、最被推崇、最被恐惧？
- **这条"最被抢的东西"，就是下一步《世界法则》基石的点名对象。** 画像到这块，必须把"什么最被抢"点出来（钱/序列/灵气/查克拉），法则只负责给它定体系。
- 合格线：给这套规则，能答出"白天/夜里的城市长啥样、富人和穷人在抢什么、一场战争为谁而打"，每条答得出。
- 例：灵气只在夜里降 → 白天商路畅通、夜间修仙夜市兴 → 形成"昼商夜修"的文明；律法压制超凡 → 表面秩序之城、地下全在交易非凡；**高科技低生活、巨企统治、政府半傀儡 → 钱/资本是唯一王道，谁都为钱游走。**

> **内核要挖到能"一层层揭出心理底色"**：赛博打破壳看到的内里=极度的利己、极度的剥削、极度的现实；克苏鲁/外神归来打破壳看到的内里=极度的疯狂、极度的反秩序。**这两股"心理底色"不是并列装饰，是"旧秩序被压住、新秩序凿开它"的双层动力**（见第5步危机）。

### 第3步 · 独特点（奇）：拿一个"所有东西都遵从"的蹊跷规则（平行支线①）

给世界一张名片，一句话讲清它为什么独特。

- 问法：有没有一种规则，世上万物都绕不开？它最让人记住的一个画面是什么？
- 例：这个是"蒸汽+驱魔+贵族"的维多利亚，还是"灵气复苏+现代都市"？序列越高越听见疯狂？仙路断绝、证道抢路？
- 关系：它是内核的暴露面——内核"最被抢的是X"，独特点就是把"万物绕不开X"这个事实雕成最让人记住的一刀。

### 第4步 · 代价 / 各阶层日常（痛）：各阶层怎么活（平行支线②）

世界不会白给。**这一节不只叫"代价"——对强世界观，它两个内容：世界级代价 + 各阶层日常；对都市言情/关系书，它降维成"各阶层怎么活"，别硬套"代价"二字。**

> **命名的纠偏（老板修正）**：这里的主眼不是"谁付了什么代价"，是"**各阶层的日常**"——这个世界不同阶层的人怎么活、强起来要付什么。写"代价"容易写成抽象规则，写"各阶层日常"才落得进画面。改名后内容不变，但问法从"要付什么"换成"不同阶层的人怎么活"。

- **世界级代价**：整个世界强起来靠牺牲/消耗什么（神秘守恒、仙路断、灵气枯竭）——稀缺感与张力的来源。
- **各阶层日常（日常感）**：不写抽象的"某个人"，写**至少两三个阶层的"一天"**——顶层怎么活、中层怎么活、底层怎么活；写"一个普通人（代表某一阶层）的一天"——他第一顿饭从哪来、通勤路上遇到什么、什么事最麻烦。设定埋进日常，别集中说明。
  - 例：不是写"灵气浓度决定修为"，是分阶层写——"顶层大人物在洞天福地饮晨露，底层王大妈在夜市卖灵气豆腐，每天只能熬三锅——灵气夜里才下雨，收了就散"。

> 三层规则（明/潜/禁）：公开的秩序（明）、不可言说的阶层利益（潜）、触碰即毁灭的红线（禁）。这三层一立，普通的日常就有了暗面。

### 第5步 · 危机（破）：哪里不对劲 = 故事入口（平行支线③，本书最关键）

这个世界表面自洽，总有一**处正在崩/已经歪的危机**。它就是主角被戳中的地方、故事的入口（详细矛盾下放"世界格局/势力矛盾"）。

- **三层反常法**（由浅到深触发警觉）：物理反常（天的颜色不对）→ 行为反常（邻居凌晨三点把垃圾埋进地下）→ 意义反常（所有人对此习以为常）。
- **危机必须分"双层失衡"（v6 硬补）**：失衡不该是一个单一变量带来的，而是：
  1. **旧失衡（本来就在，被惯性压着）**：世界原有的病态——极度的剥削/阶级固化/制度崩坏的某个裂纹，一直存在但秩序还撑得住、没人烧穿它。
  2. **新失衡（新事件撕破压制）**：一次新事件（诡异复苏/外神归来/大灾变）把旧失衡的裂缝撕开，让它盖不住了、秩序走向崩溃。
  - 判断：**没有危机时，这世界本身也在病态失衡中；危机是往这病态上再压一脚、让它盖不住。** 单写"新事件来了世界乱了"是浅的，双写"旧病被新事件揭开"才立体。
- 合格线：有一条能让读者"心里咯噔一下、又说不清哪不对"的**危机**被定住，且分清新旧两层失衡各自的来源。
- 例（双层）：明明盛世却不断有灵气枯竭的村庄（旧失衡，被压着）；秩序都城却有看不见的怪物下乡——而没人提（新失衡，撕破压制）。**怪物不在已病态的旧秩序里，而是病态旧秩序才是主流，怪物是那把把它凿开的刀。**
- **危机要写成"会炸开的开关"，不是"一个坏掉的状态"**：遮天真正的危机不是静态的"大道枯竭"，而是动态的"黑暗动乱"（自斩至尊为续命破封、屠戮众生炼化星辰精气）——危机得有发动的时机和后果，才有拉扯感。

### 第6步 · 隐喻（厚，自选）：这世界在影射现实什么（升华维）

把一条现实议题"变形"进世界观，让世界有厚度、有话讲。

- 问法：读者读完能不能意识到"这不只是奇幻世界，也是我们自己"？
- 例：灵根分五品、杂根当佃户、极品根当官——映射的不是修仙等级，是出身决定论；夜之城公司飞地吃人——影射资本与阶层断层。

> 隐喻是**可选的升华维**，不参与递进也不参与平行展开。有它世界更厚，但没有也不缺骨架。先看主线，别为隐喻耽误主结构。

### 弱世界观变体（都市 / 言情 / 纯爱用）

强世界观这套管得了"有世界推演"的书。都市言情没有"世界"，只有"关系"：

| 强世界观成分 | 都市言情降维成 |
| --- | --- |
| 内核（世界因果链） | 牵引力：把主角和他想要的人/生活往一起推的那股劲（相遇、错过→追回） |
| 代价 / 各阶层日常 | 情感代价：错过、误会、家庭/阶层阻力 |
| 危机（世界观失衡） | 关系失衡：心结、误会、身份认知错位——故事入口是"这段关系哪里不对劲" |

- **弱世界观这类书没有"基石"**：世界法则的"基石从画像内核点出"在关系驱动书里退化成"牵引力"，不硬造力量体系。世界法则在弱世界观下按《世界法则》§5 的弱轨处理。
- 内核在这里退化成"牵引力"，所以**世界法则的基石在关系书里往往不给力量体系，或降成"社会地位/资产"这类非武力基石**。
- **量级仍要定**：都市言情也要先定这书的世界物理范围（一座城？一个都市圈？）——只是它往往坍缩成"关系能发生的那一小片舞台"，不铺宏大天地。

### 案例 ≥2 跨赛道

**案例1 · 遮天（强世界观·仙侠，200万+）**

- **物理范围（量规+赛道）**：书长 200万+ → 量规要求至少星球/多元。从"北斗"一域起始，一路扩到"星空古路→仙域"诸天尺度，终点量级是"击穿仙域、平定黑暗动乱"，范围装得下。不是单城，是星空仙路全域。
- **壳**：古代东方的仙侠、仙气飘渺却苍凉枯寂，色调偏冷金属与雾霭磷火；一句话="大道将灭、人人争渡的星空仙路"。
- **内核**：总命题——证道成仙是唯一正路：如果"仙路断绝、大道枯竭"，那么"人人为证道抢路、绝地求生"。可推演到：宗门为气运开战、凡人拜山求一点点灵机、一城因为一条矿脉就易主。最被抢 = 大道/气运/仙路的"门票"。
- **独特点**：规则核心——气运/大道/仙路多轨并行，证道要"抢路"，荒古圣体等体质一出即被各方盯上。
- **代价/各阶层日常**：世界级=仙路断，想成仙先让人让路（证道即抢路）；各阶层日常=顶层圣境呼风唤雨，中层修士为气运奔命，底层荒古禁地外的山村"收一株不老草要抵三年灵税"。
- **危机（双层）**：旧失衡=大道枯竭、人人争渡这种制度性的病态（被压着）；新失衡=黑暗动乱炸开旧病（动态开关，会炸）。
- **隐喻**：求仙证道映着"把资源占光才算成的内卷跃迁"，抢路映照阶层与资源的分配不均。
- **三层地图**：北斗 → 星空古路 → 仙域，三个隔开的独立大世界（换世界+跨质变才升层，不是同星球上中下三层）。

**案例2 · 诡秘之主（强世界观·克苏鲁维多利亚）**

- **物理范围**：多文明尺度的星球+叠加神秘位面（克苏鲁赛道默认"宇宙/多文明尺度"，非单城）。
- **壳**：工业时代英伦 + 蒸汽 + 哥特 + 克苏鲁暗黑。
- **内核**：序列越高越听见疯狂，超凡世界的秩序由隐秘组织和末日征兆撕裂。
- **独特点**：万物绕不开"非凡特性"，序列=身份+诅咒+理智。
- **危机（双层）**：旧失衡=隐秘组织对超凡资源的垄断；新失衡=末日征兆逼近，秩序盖不住。
- **隐喻**：扮演与愚者，影射人在巨大组织/命运下的异化与无奈。

**泛化验证**：同一个结构（量级→壳→内核→独特点→代价/日常→危机→隐喻→三层地图），在"仙侠"和"克苏鲁维多利亚"两个完全不同的赛道各长成两本书——证明这套是通用骨架，不单配一个赛道。

## ④ 产出SOP（怎么一步步产 + 每步验收基准）

> 把"填什么"和"怎么想出来"合成一份：每走一步，先问"从哪想"，再填这一格的料。

1. **动工前先按题材选轨**：强世界观（玄幻/仙侠/克苏鲁/赛博朋克/DND）走完整链表，都市/言情/纯爱走「弱世界观变体」；查 {赛道库-SOP.md} 确认流派。
   → 【验收基准】选轨正确：不强世界观硬套六步、不关系书硬填世界因果链。
2. **（先查赛道定流派 + research）**：查 {赛道库-SOP.md}，这书属哪流派、读者默认什么画风/色调/时代/地图纵深/世界规模；拿不准的 research 头部代表作补准。
   → 【验收基准】不靠记忆印象顶替，拿准读者默认骨架再写。
3. **（先定物理范围）**：查**量规表**（篇幅↔世界尺度）+ **赛道默认规模**，一句讲清，且范围上限能装下全书终点量级。这是防"世界写小"的关口，先过再往下。
   → 【验收基准】符合量规下限：200万+至少星球级；范围装得下终点。
4. **（定调挖到底）**：按结构填——**递进线（壳→内核，内核点出"什么最被抢"供法则当基石）→ 平行支线（独特点/代价与各阶层日常/危机，危机分新旧双层失衡）→ 升华维（隐喻，自选）**。这一步定死整本气质，别急着画地图。
   → 【验收基准】挖到内核（总命题），不是只给表面风貌；内核点出"什么最被抢"一句话。
5. **（定世界本体结构）**：按《篇幅与卷规划》+ 物理范围 定几层（默认3层），每层挂质变分布（3-2-1），每层填三层内部结构；再定世界观底座。**检查每层是"独立大世界"不是"同一城市上下层"（三层独立性判据）。**
   → 【验收基准】第三层是"另一个独立大世界"，不是"某一层的特殊副本"；每层有顶层Boss/中层精英/底层背景。
6. **（逐层填基本设定）**：每层写【地理构成】+【活跃强者档位（骨架，档位归法则）】+【特殊地点】三块。
   → 【验收基准】每层能读出"几张图、谁在这层、哪个最险、能捞什么"。
7. **（把"最被抢的东西"定成一句话）** 交给下一份：这是世界法则的基石输入。缺它，法则就没有着落。
   → 【验收基准】一句话讲清"这世界最稀缺最被抢的是什么"。
8. **收尾验收一句话**：读者读完，能否闭眼想象出这个世界长什么样 + 知道"这世界最抢什么" + 分清"旧失衡是什么、新失衡撕开了什么" + 物理范围过没过量规 + 第三层是"另一个世界"而非"某个副本"。
   → 【验收基准】全过：这是一份能落地的画像，不是套壳。

**"怎么想出来"的三条路（并入每步，先走省力的）：**

- **路径一 research + 复用（默认路径，先走）**：查赛道库拿读者默认画风/色调/时代/地图纵深/世界规模当基线（西幻克苏鲁复"维多利亚蒸汽+哥特+不可名状"+宇宙/多文明尺度），在默认上"错一格"做差异（换色调/换最奇规则/换时代切面），不推倒。
- **路径二 从内核推演（原创，最稳）**：内核把因果链定成"如果X那么Y"，画面的每一处都从它长出来——画风/色调=心理底色；三层地图=从内核层级往里推谁上谁下、越往后越接近真相；各阶层日常/危机=从机制倒推不同阶层被压成什么样、哪环先崩；物理范围=从"篇幅+终点"反推。
- **路径三 验收基准反推**：把④的验收基准反过来当生成问法——壳/独特点："第一眼最深的画面？有没有一样万物绕不开？"；各阶层日常："顶层/中层/底层怎么活？各写一个代表的一天？"；危机："这世界原本病哪一处？新事件怎么撕开它？谁在掩盖？"；三层独立性："第三层是独立大世界还是某层副本？"
- **选择法**：先走路径一查赛道拿画风基线 → 卖点处（最奇、危机）用路径二/三往深推 → 处处记着"在公认画风上错一格 + 规模别写小 + 三层是独立世界"。

## 附：与相邻设定的边界

- **世界画像**（本份）：世界"本体长什么样 + 内核驱动什么"（画面层 + 基石产地），是链路第一步。
- **世界法则**（下一份）：世界"强怎么构成"，基石从画像内核对核"最被抢的东西"点名。法则管"规则"。
- **世界格局/势力/矛盾**（再后面）：世界"怎么摆、谁在台上、为何而战"（局势层）。
- 分工：画像管"画面+内核+量级"，法则管"规则（从内核点基石）"，格局管"摆放"。三层各管一头，不重复。

> 一句话：世界画像决定"这世界长啥样、多大、内核在推什么"，世界法则从中定"强怎么构成、基石是最被抢的那个"，世界格局决定"这世界怎么摆"。

## 待处理问题（这份眼下还没定 / 存疑 / 待实测）

- [ ] **弱世界观只约 50% 成立**：六步是为强世界观写的，都市/言情/纯爱"关系驱动"书只有约50%成立（没有"世界在推人做什么"）。当前降维成「弱世界观变体」，但降维判据是否够用，未在多案例核过。
  → 为什么悬着：四书实测（诡秘95%/遮天90%/深渊主宰80%）都是强世界观，关系书样本少。
  → 等谁定：更多都市/言情真实书实测。
- [ ] **第0步物理范围的量规表**（篇幅↔世界尺度下限）是否过宽/过严，未用一个"城市史诗且终点就在单城"的长篇（200万+单城定位）实测过。
  → 为什么悬着：往下走案例都自动扩到星球/多元，单城长篇反例没撞上。
  → 等谁定：一个明确"城市史诗"定位的真实案子。
- [ ] **三层独立性判据（v6.1，防第三层写成副本）**是新鲜规则，只在 v2「塔基裂隙降维成副本」反例上验证过一次，多案例是否都能判准未核。
  → 为什么悬着：正面样本（遮天北斗/星空/仙域）清晰，但"边界模糊"案例（像副本又算独立层）没测。
  → 等谁定：更多带"疑似副本"的地图结构真实书实测。
- [ ] **危机"双层失衡"判据是否足够区分**（旧失衡被压 vs 新失衡撕破），未在多案例核过。
  → 为什么悬着：目前在赛博×克苏鲁一人案上成立，跨赛道压力未验。
  → 等谁定：更多赛道的"旧病+新事件撕开"案例。
- [ ] **深挖/生成方法论的路径二、三**是否"能模仿着用到任意题材"，未在更多题材上实操验证。
  → 为什么悬着：方法论推演痕迹留了，但举一反三的能力需要更多题材确认。
  → 等谁定：把同一套结构套到 DND etc. 未铺过的赛道。
