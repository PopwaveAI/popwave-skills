# 设定文档 · 主要反派-SOP（骨架）

> 从属：小说设定总SOP（小说设定-SOP.md）④「主要角色设计」。
> 产出阶段：**主线剧情设计阶段**（设定总账 tag=骨架），在 主角设计（锁根）之后——主角立住，反派才对着主角立。
> 地位：挡在欲望串终点的那个人。只立"挡路的那几个层级"（终敌/卷敌），其余敌人归展开。
> 依赖：建立在 主角设计（欲望串/主线养成线）、世界格局（冲突线）、顶层势力（反派站在哪家顶端）、世界法则（敌人也走同一套法则）之上；产出供 卷纲 使用。
> 范式：按【设定文档-统一模板-v1】四段式；吸收 pop-snow-stage「反派8型」「冲突必然性」「禁降智送爽」「敌梯分层」。

---

## ① 文档定位（这是份什么，静态定义）

**主要反派 = 挡在主角欲望串终点的那个人。** 回答：谁在终点挡着？他凭什么挡得住？他为什么非挡不可？

- **角色**：骨架。立"敌梯"（终敌+主要卷敌），每卷的次级敌人归展开。
- **回答**：挡在欲望串终点的那个人是谁、凭什么挡、为什么非挡。
- **链路位置**：④ 的后续（世界画像 → 世界法则 → 世界格局 → 主角设计 → **主要反派**）。主角立住后，反派对着主角立。
- **依赖**：主角设计（欲望串）、世界格局（冲突线）、顶层势力（反派站在哪家顶端）、世界法则（敌人也走同一套法则）。产出供 卷纲 使用。
- **一句话落点**：能一句话讲清"谁挡在终点、他凭什么挡得住、为什么非挡不可"。

它不是：
- 不是**敌人目录**（每卷打的小boss列表——卷敌归展开）。
- 不是**脸谱库**（"坏人=凶恶"——反派要能过三问）。
- 不是**主角的影子**（为了衬托主角而存在——反派有独立欲望，他不挡主角也照样干自己的事）。

> 判据：写完①，读者知道"这份管谁挡路"，但不知道"怎么填"——怎么填是②。

## ② 思考逻辑（填的时候脑子怎么转，动态方法）

**这条推演痕迹（agent 最该掌握）：反派 = 欲望对立的人——他站在欲望串终点，有独立欲望（不挡主角也会干自己的事），冲突是必然的（不是碰巧挡路）。**

- **对着主角的欲望串立**：主角的欲望串终点是什么，谁挡在那——反派就是那个"守住终点"的人。主角要什么，他恰好也想要/恰好要护着。
- **过三问（吸收 snow-stage）**：
  1. **有独立欲望吗？**（不挡主角，他自己也在追求什么）
  2. **行为能从欲望推出来吗？**（他的每个行动都有欲望做底，不是为坏而坏）
  3. **和主角的冲突有必然性吗？**（欲望对立，不是碰巧挡路/误会）
- **反派8型对号（吸收 snow-stage）**：纯恶 / 灰色 / 魅力 / 悲剧 / 伪善 / 执念 / 成长 / 幕后——先对号选型，再按型写。明写行动逻辑（目标/手段/代价）与压迫感来源（他强在哪、凭什么压住主角）。
- **禁降智送爽（吸收 snow-stage）**：主角爽在"赢得有代价、有方法、有反应"——反派不降智、不犯蠢送人头；主角赢他是因为某项养成线超标+他项有短板（世界法则通则）。
- **敌梯分层（吸收 snow-stage）**：终敌（终局对撞）+ 卷敌（每卷挡路的主要敌人）——终敌立骨架，卷敌立到"够排这一卷"即可，次级敌人归展开。
- **敌人也走同一套世界法则**：反派强=某项养成线超标+他项有短板，不是"反派不用这套"。

> 判据：一份合格的②，读的人该能模仿"对主角欲望串找终点 → 立人（独立欲望/行为可推/冲突必然三问）→ 8型选型 → 禁降智 → 分层"这套思路，换题材照推。

## ③ 文档内容（写进小说 / 结构 / 表格 / 案例）

### 结构总览

| 构件 | 填什么 |
| --- | --- |
| 终敌（1人） | 欲望串终点的守门人：三问＋8型＋行动逻辑＋压迫感来源 |
| 卷敌（每卷1人） | 每卷挡路的：立到够排这一卷 |
| 敌梯总表 | 终敌→卷敌的层级表，对齐主线养成线档位 |

### 终敌卡片格式

```
反派名：
【欲望】他想要什么？（独立欲望，不挡主角也成立）
【8型】纯恶/灰色/魅力/悲剧/伪善/执念/成长/幕后
【行动逻辑】目标 / 手段 / 代价
【压迫感】他强在哪、凭什么压住主角（对应养成线档位）
【必然冲突】为什么非挡主角不可（欲望对立点）
【降智检查】主角赢他靠什么（哪条线超标+他哪项短板）
```

### 案例 ≥2 跨赛道

**案例1 · 遮天（仙侠）**
- **终敌·禁区至尊（选型：执念+幕后）**：欲望=证道长生、护住自己的道（不挡主角也自封禁区苟活）；行动逻辑=目标：守住旧秩序／手段：镇压一切成道路／代价：每次出手耗命元；压迫感=仙台大能、一域无敌，对应养成线=境界顶端；必然冲突=主角要重开仙路，等于挖他的根；降智检查=主角赢他靠圣体觉醒+境界质变+众生助力，不是他犯蠢。
- **卷敌**：每卷一个挡路的（圣地主宰/异族天骄/古帝残念），立到"够排这一卷"。
- **敌梯**：练气→仙台逐档往上，终敌站在顶端。

**案例2 · 诡秘之主（克苏鲁维多利亚）**
- **终敌·幕后（选型：幕后+灰色）**：欲望=揭穿旧日真相/重启时代（不挡主角也策划大事件）；行动逻辑=目标：控制非凡格局／手段：借教会与隐秘组织互斗／代价：身份暴露、被多方围剿；压迫感=序列顶端、掌握大棋局；必然冲突=主角要保身边的人，他要掀桌子；降智检查=主角赢他靠序列成长+灰雾身份+多方博弈，不是他犯蠢。
- **卷敌**：每卷一个（教廷猎魔人/密修会执事/大雾霾背后的组织），立到够排这一卷。
- **敌梯**：序列低→高的逐档往上，终敌站在顶端。

**泛化验证**：同一套"对欲望串找终点→三问→8型→禁降智→敌梯分层"，在"仙侠（守旧秩序的至尊）"和"克苏鲁（幕后操盘者）"两个赛道都成立——反派形态随题材变，结构不变。

### 3. 弱世界观变体（都市 / 言情 / 纯爱用）

反派降维成"关系局里的对手"：

| 强世界观成分 | 都市言情降维成 |
| --- | --- |
| 终敌 | 错位关系里的终极障碍（旧爱 / 家族阻力 / 被误会的真相持有者） |
| 三问 | 照过：他有独立欲望（守家族/护旧爱/保秘密）；行为可推；冲突必然（和主角的欲望对立） |
| 8型 | 照用：灰色 / 悲剧 / 执念 居多 |
| 禁降智 | 照用：主角赢在关系经营的积累，不是对手突然变蠢 |

## ④ 产出SOP（怎么一步步产 + 每步验收基准）

1. **回读主角设计**：主角的欲望串终点、主线养成线。
   → 【验收基准】能说出"终点是谁挡着"；欲望串是反派位置的来源。
2. **立终敌**：对欲望串找终点守门人，过三问（独立欲望/行为可推/冲突必然）。
   → 【验收基准】三问全过；他不挡主角也在干自己的事。
3. **8型选型＋行动逻辑**：对号选型，写明目标/手段/代价与压迫感来源。
   → 【验收基准】压迫感有来源（对应养成线档位），不是喊"他很强"。
4. **排卷敌**：每卷一个挡路的，立到够排这一卷。
   → 【验收基准】卷敌的档位对齐主线养成线；次级敌人归展开，不塞进本份。
5. **降智检查**：主角赢他靠什么——哪条线超标+他哪项短板。
   → 【验收基准】赢得有代价、有方法、有反应；无降智送人头。
6. **边界检查**：检查是否把《顶层势力》（他站在哪家）写成了势力表、把《世界历史》（他的动机成因）写成了史——有→只留"人"，归位。
   → 【验收基准】本份只写"人"：势力归顶层势力、成因归历史。

## 附：与相邻设定的边界

- **主角设计（前面）**：欲望串/养成线——反派是终点的守门人。
- **顶层势力（前面）**：反派站在哪家顶端——本份只写"人"，不写"家"。
- **世界历史（前面）**：反派的动机成因——本份写"他想要什么"，不写"历史怎么来的"。
- **主要反派（本份）**：挡路的人。
- **核心配角（展开，待建）**：陪主角走的人——反派团里的次级人物归展开。

> 一句话：主角设计说"主角要什么"，主要反派说"谁守住终点不让，他凭什么守、为什么非守不可"。
