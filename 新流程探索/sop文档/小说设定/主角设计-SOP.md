# 设定文档 · 主角设计-SOP（锁根）

> 从属：小说设定总SOP（小说设定-SOP.md）④「主要角色设计」。
> 产出阶段：**核心设定设计阶段**（设定总账 tag=锁根），链路最后一环——世界画像 → 世界法则 → 世界格局 → **主角设计**。
> 地位：把前三份算好的东西收束到一个人身上。画像是"世界长啥样"、法则是"强怎么构成"、格局是"棋盘怎么摆"，这一份回答**这个人是来怎么做这件事的**。
> 合并说明：本份为合并稿，把原「主角本命/核心身份」与「主角力量资格/金手指」两份锁根合一。合并理由：二者是同一件事的两面——"世界之谜为什么落在他身上"（本命）与"他凭什么能例外地动那套系统"（金手指），拆开写会互相拉扯，合起来才是一个完整的人。
> 依赖：建立在 世界画像（危机/世界样貌）、世界法则（基石/养成线）、世界格局（起步格/升层路径）之上；上游输入=立项创意-SOP 产出的故事脉络（主角是谁的种子）。
> 范式：按【设定文档-统一模板-v1】四段式；旧「质量要求」并入④，散落技术标记归拢「待处理问题」。

## ① 文档定位（这是份什么，静态定义）

**主角设计 = 回答"这个人是来怎么做这件事的"**：主角本质上是谁（本命/核心身份），以及他凭什么能入局、凭什么超速（力量资格/金手指）。

- **角色**：锁根。核心设定设计阶段的收尾一环。
- **回答**：主角是谁？凭什么入局？
- **链路位置**：④（世界画像 → 世界法则 → 世界格局 → **主角设计**）。前三份把局铺好，本份才造人。
- **依赖**：世界画像（危机/世界样貌）、世界法则（基石/养成线/金手指边界）、世界格局（起步格/升层路径）、立项创意-SOP（故事脉络里的主角种子）。产出供 主要反派（骨架）、核心配角（展开）、卷纲 使用。
- **一句话落点**：能一句话讲清"这本书的主角是个什么人、他凭什么能翻"，且这句话接得上格局的起步格、法则的养成线。

它不是：
- 不是**人物小传**（出生年月/家庭史/技能列表——那些是写章期细节）。
- 不是**通用力量规则**（那是世界法则；金手指是主角的例外资格，不写进通用系统，v8.1 金手指边界）。
- 不是**剧情大纲**（主角会遇到什么事、怎么打怪升级——那是卷纲的事）。
- 不是**金手指的孤立外挂清单**（金手指必须是一条要显式声明的**特殊养成系**——有独立档位、有成长量、与主养成线对表，不是贴一个能力就完事；怎么声明见②和③.2）。

> 判据：写完①，读者知道"这份管什么、跟谁衔接"，但不知道"怎么填"——怎么填是②。

## ② 思考逻辑（填的时候脑子怎么转，动态方法）

**这条推演痕迹（agent 最该掌握）：主角 = 种子（故事脉络里的"主角是谁"）＋ 局（画像/法则/格局铺好的棋盘）→ 立人（本命：谜怎么落在他身上）→ 给资格（金手指：系统为什么对他开例外）→ 立金手指养成系（这条例外怎么长成一条独立的成长线）。**

- **先接种子，不重造**：立项创意-SOP 已定"主角是谁"（身份/特质/处境，只写什么人、不写凭什么）。本份承接这颗种子，把"什么人"立成"这个人"，把"凭什么"补全。种子被推翻=故事脉络白做，禁止。
- **先立人，后给资格**：先定"主角本质上是谁"，再定"凭什么入局"。顺序反了会写成"一个获得XX能力的人"，而不是"一个被谜选中的人"。金手指必须从本命长出来，不是贴上去的。
- **本命 = 底色 × 谜的落点**：本命不是户口本，是两个问题——主角骨子里的特质是什么（有来处，不是标签），以及世界之谜为什么落到主角身上（"为什么偏偏是他"）。后者是主角区别于所有配角的根本。
- **金手指 = 例外资格，不是新系统**（v8.1 金手指边界）：基石是人人都能动的通用总能源，金手指是"只有主角能例外地动那套系统"的资格。设计时先问："主角是哪套系统的例外？例外在哪一环？"——别人的序列要配方+扮演，主角能跳过哪环？别人烧钱买义体，主角能走哪条不要钱的渠道？
- **金手指 = 一条特殊养成系（本份必须显式声明）**：金手指不是"挂在主养成线上的一个成长挂点"，它本身就是**主角独有的成长维度**——费伦只有一个灰骑士，这条晋升路径只有他能走。声明三件套：
  1. **档位表**：金手指自己的成长刻度是什么（几个档位、每档叫什么、每档多出什么能力）——它跟主养成线对表但不重合；
  2. **成长量**：每档的"新到手"是什么（能力/范围/资格），不是只有名字变化；
  3. **与主养成线的关系**：挂在主线的哪一档（金手指哪档随主线哪次质变开），以及它和准主线/从线怎么分工（金手指线 = 例外侧，准主线 = 资源侧，从线 = 深化侧）。
  判据：**一份合格的主角设计，能单独抽出"金手指特殊养成系的档位表"，读者看它就知道"主角每过一个成长节点，手里多了一张什么牌"**。
- **金手指要挂得住成长线**：金手指不是一次性外挂，要挂到主养成线上（法则说过"主角越级赢，是因为某项养成线超标"，金手指就是那个"超标"的合法来源）。用完即弃的金手指撑不起几百万字——特殊养成系的档位表就是"挂得住"的落点。
- **爽文无真代价**：法则通则同样管金手指——代价只做氛围/装扮级，不许拖垮主角。

> 判据：一份合格的②，读的人该能模仿"接种子→立人（底色×谜的落点）→给资格（对哪套系统开例外、例外在哪一环）→立金手指特殊养成系（档位表/成长量/与主线对表）→过真代价"这套思路，即使换一个完全不同的题材（把克苏鲁换到都市）也能照这个推法想出来。

## ③ 文档内容（写进小说 / 结构 / 表格 / 案例）

### 结构总览：一张表

| 构件 | 填什么 | 来源 / 对接 |
| --- | --- | --- |
| 本命 · 底色 | 主角骨子里的特质（有来处）＋ 当前身份处境 | 承接故事脉络"主角是谁"的种子 |
| 本命 · 谜的落点 | 世界之谜/危机为什么落到主角身上（为什么偏偏是他） | 对接世界画像危机、世界格局棋盘 |
| 资格 · 入局 | 对世界法则哪套系统开例外？例外在哪一环（获取/使用/代价） | 对接世界法则基石（v8.1 金手指边界） |
| 资格 · 超速 | **金手指这条特殊养成系**：档位表（独立刻度）？成长量（每档新到手）？与主养成线对表？成长挂点？ | 对接世界法则养成线（主/准主/从） |

### 1. 主角本命 / 核心身份（他是谁）

两个子问题，先答哪个都行，但两个都要答：

1. **骨子里的底色**：主角是个什么人——不是职业，是特质（倔/怂/狠/贪/轴/谨慎），且特质要有来处（被什么处境磨出来的）。故事脉络只给"身份+特质+处境"的种子，这里把特质立成有来处、有代价的人。
2. **谜的落点**：世界之谜如何落到主角身上——"为什么偏偏是他"。这是主角区别于所有配角的根本，也常常是金手指的产地。

> 判据：写完后能答"主角是不是'换个人故事就不成立'"。换个人也成立=本命没立住；立住的标志是"这谜只能落在他身上"。

### 2. 主角力量资格 / 金手指（他凭什么）

世界法则 v8.1 金手指边界硬规则：**金手指是"只有主角能例外地动那套系统"的资格，不是基石本身，也不是新造一套通用系统。** 主角也是走同一套世界法则的，金手指是他那条"例外条款"。

三个子问题，全答：

1. **入局资格**：凭什么能入局——主角对世界法则里哪套系统开例外？例外在哪一环（获取环节 / 使用环节 / 代价环节）？
2. **超速路径**：凭哪条路超速——金手指挂哪条主养成线（越级靠哪条线超标）？成长挂点是什么（金手指本身会进化，还是只给初始优势）？
3. **金手指特殊养成系声明**（本条必答）：金手指这条线**独立的档位表**是什么（几个档位、每档多出什么）？它跟主养成线怎么对表（金手指哪档随主线哪次质变开）？它和准主线/从线的分工是什么（例外侧 / 资源侧 / 深化侧）？

> 判据：能一句话讲清"这套世界的规则里，主角哪里是例外"；金手指不是孤立外挂——抽出档位表，能看出它是与主养成线对表的一条完整成长线。

### 案例 ≥2 跨赛道

**案例1 · 诡秘之主（克苏鲁维多利亚，身份型金手指）**

- **本命·底色**：穿越者克莱恩·莫雷蒂，表面凡俗银行小职员，实则登上"灰雾之上"扮成神秘存在"愚者"。底色：谨慎、克制、能忍、善于扮演——被身份一层压一层的处境磨出来的。
- **本命·谜的落点**：穿越时接触灰雾与罗塞尔日记遗产，命运途径的谜落在他身上。"为什么偏偏是他"：他是被灰雾选中的观察者，唯一性的承载者。
- **资格·入局**：人人走序列（魔药+扮演+消化），主角的例外是"灰雾之上"——能召集塔罗会、跨空间交易非凡材料，绕过了常规途径的获取环节。
- **资格·超速**：扮演法+灰雾交易渠道双挂点；**金手指特殊养成系**：灰雾权限本身有独立刻度（从占卜到传送、从投影到本体强度随序列提升扩大），档位表挂在主养成线（序列 9→0）上对表但不重合——序列是通用的（敌人也走），灰雾是唯一的（只有他有）。

**案例2 · 遮天（仙侠，体质型金手指）**

- **本命·底色**：地球普通青年叶凡，被九龙拉棺送进北斗星域。底色：坚韧、狠、不信命、对朋友重义——从"最普通的凡人"被扔进"最残酷的修真形态"里磨出来的。
- **本命·谜的落点**：荒古圣体+九龙拉棺——他是被帝路选中的应劫者，仙路断绝的大局需要一个打破规则的圣体。"为什么偏偏是他"：圣体是他的命，也是他的劫。
- **资格·入局**：人人走境界（轮海→道宫→仙台），主角的例外是荒古圣体——被天地压制，却在破境时远超同阶。例外在"使用环节"（同样的境界，他战力超标）。
- **资格·超速**：体质+功法双线挂点；**金手指特殊养成系**：荒古圣体有独立档位表（圣体异象随境界每次质变觉醒一档——异象从"微弱金光"到"天地异象"逐级扩容），与境界对表但不重合——境界是通用的，圣体是唯一的。

**案例3 · 玄鉴仙族（家族修仙，共同体主角）**

- **本命·底色**：主角不是单人，是一个家族单位——李氏从黎泾村凡人家族起家，四代子弟接力撑起存续。底色：求稳、重传承、集体为先——被"走错一步满盘皆输"的处境磨出来的。
- **本命·谜的落点**：家族血脉与仙途的关联之谜落到李氏头上——为什么偏偏是这支凡族能往上爬。
- **资格·入局**：人人走仙道（宗门体系），李氏的例外是"家族为单位共担风险、共享资源"——凡人根基在宗门夹缝里求存的集体资格。
- **资格·超速**：成长挂点=每一代子弟的传承接力（立稳脚跟→谋修仙之位→扩地盘→开府立制），代际累积就是共同体的养成线；金手指特殊养成系 = 家族的"气运/根脚"刻度（每代继承、每代加厚），与境界对表但不重合。

**泛化验证**：同一个结构（底色×谜的落点 → 入局资格×超速路径×金手指特殊养成系），在"克苏鲁（身份型）/仙侠（体质型）/家族修仙（共同体型）"三个赛道各长成三本书——证明骨架通用：金手指无论长成"身份例外"还是"体质例外"还是"共同体例外"，都是"只有主角能动的例外资格"，且都以一条独立档位表的特殊养成系形态与主养成线对表。

### 3. 弱世界观变体（都市 / 言情 / 纯爱用）

弱世界观没有"基石"，世界法则走弱轨，金手指降维成"凭什么让主角赢下关系局"：

| 强世界观成分 | 都市言情降维成 |
| --- | --- |
| 本命 · 底色 | 主角的底色 + 处境（仍要立人：这个人的执念/软肋从哪来） |
| 本命 · 谜的落点 | 关系错位的谜底：为什么这段关系必须由他解开（身份认知错位/误会的心结） |
| 资格 · 入局 | 例外条件：重生记忆 / 隐藏身份 / 被误会的真相——"凭什么他能赢"的那张牌 |
| 资格 · 超速 | 关系进阶的路径：误会解开、关系格的坎迈过（对接世界格局的关系版图） |

> 弱世界观同样先立人后给资格：先写"这是个什么人、心结在哪"，再写"他手里那张例外的牌"，顺序不变。金手指特殊养成系在弱轨的形态 = "例外的牌"本身有成长（重生记忆逐卷恢复 / 隐藏身份逐层揭开），同样要显式声明档位，不能只给一张静态牌。

## ④ 产出SOP（怎么一步步产 + 每步验收基准）

1. **回读种子与局**：立项创意-SOP 的故事脉络"主角是谁"（身份/特质/处境）＋ 世界画像（危机）＋ 世界法则（基石/养成线）＋ 世界格局（起步格/升层路径）。
   → 【验收基准】能说出"故事脉络给的是什么种子"；不推翻种子。
2. **立底色**：写主角骨子里的特质（有来处、有代价）＋ 当前身份处境。
   → 【验收基准】"换个人故事不成立"——这谜只能落在他身上。
3. **定谜的落点**：世界之谜/危机如何落到主角身上，"为什么偏偏是他"。
   → 【验收基准】能一句话讲清"主角区别于所有人的那一点"。
4. **定入局资格**：对世界法则哪套系统开例外？例外在哪一环（获取/使用/代价）？
   → 【验收基准】能一句话讲清"这套世界的规则里，主角哪里是例外"；金手指不是基石本身（过 v8.1 金手指边界）。
5. **定超速路径 + 立金手指特殊养成系**：金手指挂哪条主养成线？成长挂点是什么？**金手指独立的档位表是什么（每档成长量）？与主养成线怎么对表？与准主线/从线怎么分工？**
   → 【验收基准】金手指作为一条特殊养成系显式声明：抽出档位表能看出它是独立刻度、每档有成长量、与主养成线对表不重合、不是一次性外挂。
6. **过"爽文无真代价"**：金手指与身份的代价审一遍，只做氛围/装扮级。
   → 【验收基准】无不可逆堕落、无损失核心资产、无让读者憋屈的设定。
7. **边界检查**：检查世界画像/法则/格局里，有没有把主角独有机制写进通用规则的；有→回正。同时检查本份金手指特殊养成系，有没有把"通用系统人人能走"的部分误划进金手指线。
   → 【验收基准】通用系统里零主角独有机制；金手指只在本份；金手指线只收"只有主角能走"的例外刻度，通用刻度（敌人也走的）留在世界法则。
8. **收尾验收一句话**：一句话讲清"主角是个什么人、他凭什么能翻"，且接得上格局的起步格、法则的养成线。
   → 【验收基准】全过：这是一份能落地的立人稿，不是标签堆。

**"怎么想出来"的三条路（并入每步，先走省力的）：**

- **路径一 research + 复用（默认路径）**：查赛道库，确认该赛道读者默认的主角类型与金手指形态（系统流/体质流/身份流），在默认上做一处差异（换例外环节/换成长挂点），不推倒。
- **路径二 从局里推（最稳）**：不凭空造主角——本命从"故事脉络种子 + 画像危机"推（谜为什么落他身上），资格从"法则基石 + 格局起步格"推（他脚下的棋盘哪里卡着他、系统哪里对他开例），金手指特殊养成系从"主养成线"推（哪条线是他的超标合法来源，例外怎么长成独立档位表）。
- **路径三 验收基准反推**：把④的验收基准反过来当生成问法——"换个人这故事还成立吗""主角对哪套系统开例外""例外在哪一环""金手指的档位表是什么、每档多出什么""金手指挂哪条线、怎么进化"。
- **选择法**：先走路径一拿赛道默认 → 卖点处（谜的落点、例外环节）用路径二/三往深推 → 处处记着"先立人后给资格 + 金手指是例外不是新系统 + 金手指要立成特殊养成系 + 爽文无真代价"。

## 附：与相邻设定的边界

- **立项创意-SOP（前面）**：故事脉络只给"主角是谁"的种子（什么人），不写"凭什么"；本份补全"凭什么"。
- **世界画像（前面的前面）**：世界长啥样 + 危机（谜与危机的产地）。
- **世界法则（前面）**：强怎么构成（基石/养成线）；金手指边界——主角例外资格不写进通用系统；**养成线家族（主/准主/从）只收通用刻度，金手指特殊养成系归本份**。
- **世界格局（前面）**：棋盘怎么摆（起步格/升层路径）——本份不重摆棋盘，只把主角放上去。
- **主角设计（本份）**：这个人是来怎么做这件事的（本命 + 资格 + 金手指特殊养成系）。
- **主要反派（骨架，待建）**：挡在欲望串终点的那个人——主角立住后，反派才对着主角设计。
- **核心配角（展开，待建）**：陪主角走的人——主角的底色定了，才知道配谁、对谁负责。

> 一句话：世界画像说"这世界长啥样"，世界法则说"这世界怎么玩、怎么长（通用养成线）"，世界格局说"这张牌桌上谁占了什么、主角从哪格打"，主角设计说"这个人是来怎么做这件事的、他手里那张例外的牌是什么、这条例外怎么长成一条特殊养成系"。
