# 设定文档 · 宏观地理格局-SOP（骨架）

> 从属：小说设定总SOP（小说设定-SOP.md）①「世界画像」后续。
> 产出阶段：**主线剧情设计阶段**（设定总账 tag=骨架），在世界画像（三层地图骨架）之后。
> 地位：把画像的三层地图骨架铺成**能排戏的棋盘**——不是百科式地名列表，是"每个地方都有戏可排、有利益可抢"的格局图。
> 依赖：建立在 世界画像（三层地图骨架/内核/危机）、世界法则（基石/养成线——决定哪个地方的资源被抢）、世界格局（棋盘/冲突线）之上；产出供 世界历史/顶层势力/卷纲 使用。
> 范式：按【设定文档-统一模板-v1】四段式；吸收 pop-snow-stage「地图剧情绑定4问」「地图扩展有过渡有门槛」。

---

## ① 文档定位（这是份什么，静态定义）

**宏观地理格局 = 一张能排戏的棋盘，不是百科式地图。** 回答：这本书的空间怎么分块、每块地方能排什么戏、谁在争哪块地。

- **角色**：骨架。决定全书形状，但不用一次铺满——每块地细到"能排这一卷的戏"即可，其余留展开。
- **回答**：东西大陆/上中下界级别的空间怎么分？每块地方为什么值得存在？
- **链路位置**：① 的后续（世界画像 → 世界法则 → 世界格局 → 主角设计 → **宏观地理格局**）。画像给地图骨架，这里铺成棋盘。
- **依赖**：世界画像（三层地图骨架/内核/危机）、世界法则（基石/养成线→哪个地方的资源被抢）、世界格局（冲突线）。产出供 世界历史/顶层势力/卷纲 使用。
- **一句话落点**：能一句话讲清"这本书的空间怎么分块、每块有什么可抢"，且每块地细到卷纲能直接排戏。

它不是：
- 不是**地理百科**（气候/物产/风土人情列表——那些是写章期细节）。
- 不是**地图生成器**（每块地都详细到能写游记——只细到能排戏）。
- 不是**势力表**（谁占哪块地归《顶层势力》；这里管"地本身有什么可抢"）。

> 判据：写完①，读者知道"这份管空间怎么分块、为什么这么分"，但不知道"怎么填"——怎么填是②。

## ② 思考逻辑（填的时候脑子怎么转，动态方法）

**这条推演痕迹（agent 最该掌握）：空间 = 利益版图——每个地方必须能答"控制什么资源/信息、谁想要、进来付什么代价、主角在这经历过什么"（地图剧情绑定4问）。答不出的地方，删。**

- **先有画像的骨架，再铺块**：世界画像已定三层地图骨架（主地图/中层/下层），本份把每层分块。不推翻画像的层，只往里分块。
- **每块地过「地图剧情绑定4问」（吸收 snow-stage）**：
  1. **地点=利益**：控制什么资源或信息？谁想要？
  2. **冲突**：不同势力对它的态度是否不同？（态度一样=没戏）
  3. **门槛**：进入要付什么代价？（路程/权限/资格/引路人）
  4. **记忆**：主角在此经历过什么？重访时读者想起什么？
  **被另一地点完全替代→不单独入档或标记精简**，不堆"只当背景板"的地理。
- **扩展要有过渡、有门槛（吸收 snow-stage）**：初期小范围（建日常规则和主角缺口）→ 中期中范围（暴露势力结构、资源争夺）→ 后期大范围（揭示世界本质、历史真相）。不能村口一步跳宇宙中心；每次扩展都有门槛（路程/权限/代价/情报/资格）。
- **每块地带「钩子」**：够撑卷级篇幅的剧情钩子（悬念/冲突/反转/拼图），让排卷时有戏可排。
- **有温度画面**：每块地至少一句"正文长什么样"的可落笔描述（这城闻起来是什么味、主角站在这块地是什么感受）。只有规则没有画面，write 不知道怎么落笔。

> 判据：一份合格的②，读的人该能模仿"从画像骨架分块 → 每块过4问 → 有钩子有画面 → 扩展有门槛"这套思路，换任何题材（把仙侠换成赛博）都能照这个推法想出来。

## ③ 文档内容（写进小说 / 结构 / 表格 / 案例）

### 结构总览

| 构件 | 填什么 |
| --- | --- |
| 分层分块 | 画像三层骨架 → 每层分几块地（块数够排戏即可，不贪多） |
| 每块地一卡 | 4问标签：利益/冲突/门槛/记忆 ＋ 钩子 ＋ 一句画面 |
| 扩展顺序 | 主角从哪块起步、中后期扩展到哪（有门槛的过渡链） |

### 每块地的卡片格式

```
地名：
所属层：
【利益】控制什么资源/信息？谁想要？
【冲突】不同势力态度差异？
【门槛】进入付什么代价？
【记忆】主角在此经历？重访读者想起什么？
【钩子】够撑一卷的剧情钩子
【画面】正文长什么样的一句话
```

### 案例 ≥2 跨赛道

**案例1 · 遮天（仙侠，多层世界）**
- **分层分块**：地球（起点村）→ 北斗星域（主地图：东荒/北原/西漠/南岭/中州五块）→ 星空古路（中后期大范围）。
- **每块地4问（示例·东荒）**：利益=太古生物遗存、仙料（法则基石资源）；冲突=圣地世家与散修态度不同（世家占矿、散修偷渡）；门槛=进禁区要命（妖兽/古阵）；记忆=叶凡在此被追杀、与庞博结义（重访=恩怨再起）；钩子=青帝古坟、太古生物复活；画面="东荒的夜，风里带着太古生物的腥气"。
- **扩展顺序**：地球→北斗（初期），每卷换块地（中后期），星空古路收尾——每块地都是"换地图=换资源=换冲突"的典型网文空间结构。

**案例2 · 诡秘之主（克苏鲁维多利亚，城市+多国）**
- **分层分块**：廷根市（起点小城）→ 贝克兰德（主地图大都市）→ 海外/南北大陆（后期）。
- **每块地4问（示例·贝克兰德）**：利益=非凡特性情报、教会与隐秘组织（欲望串终点）；冲突=正神教会与密修会态度对立（官方vs地下）；门槛=无非凡者背景进不去高层圈子；记忆=主角以多个身份在此周旋（重访=身份穿帮风险）；钩子=大雾霾事件、天使坠落；画面="雾都的煤气灯下，穿黑风衣的侦探们交换着纸页发黄的情报"。
- **扩展顺序**：廷根（初期小城）→ 贝克兰德（中期大城）→ 海外（后期）——小城定日常规则，大城暴露势力结构，海外揭世界本质。

**泛化验证**：同一套"分层分块→4问→钩子→扩展有门槛"，在"仙侠多层世界"（换地图=换资源）和"克苏鲁城市"（同城多身份周旋）两个结构完全不同的赛道都成立——证明骨架通用，分块粒度随题材定（玄幻按大地图分、都市按城区/圈层分）。

### 3. 弱世界观变体（都市 / 言情 / 纯爱用）

弱世界观没有"地图"只有"活动空间"，4问降维成"空间绑定"：

| 强世界观成分 | 都市言情降维成 |
| --- | --- |
| 分层分块 | 活动圈层：老家 / 职场 / 社交圈 / 秘密据点 |
| 4问 | 这个空间控制什么资源（人脉/信息/面子）？谁的态度不同？进入门槛（身份/关系）？主角在此的记忆（心结）？ |
| 扩展顺序 | 从主角日常空间 → 逐步进入对方/上位者的空间（有门槛的过渡链） |

> 原则不变：每个空间都要有戏可排、有利益可抢，纯背景板的空间不入档。

## ④ 产出SOP（怎么一步步产 + 每步验收基准）

1. **回读画像骨架与格局冲突线**：世界画像的三层地图骨架/内核/危机 ＋ 世界格局的冲突线（谁占哪格）。
   → 【验收基准】不推翻画像的层；分块与冲突线对得上。
2. **分块**：每层分几块地，块数够排戏即可。
   → 【验收基准】块数能覆盖主要剧情发生地，不贪多（每卷最多新增1-2块）。
3. **逐块过4问**：每块地填 利益/冲突/门槛/记忆 四标签。
   → 【验收基准】四问都有答；被另一地点完全替代的→删除或标精简，不堆背景板。
4. **写钩子与画面**：每块地一句钩子＋一句画面。
   → 【验收基准】钩子够撑一卷；画面能让 write 直接落笔。
5. **排扩展顺序**：主角起步块 → 中后期扩展块，标清每步门槛。
   → 【验收基准】扩展有过渡有门槛，没有"村口一步跳宇宙中心"。
6. **边界检查**：检查是否把《顶层势力》的内容（谁占哪块地、谁和谁结盟）写进来了，有→归位。
   → 【验收基准】本份只写"地"，不写"谁占"；谁占归顶层势力。

## 附：与相邻设定的边界

- **世界画像（前面）**：三层地图骨架（主地图/中层/下层）——本份往里分块。
- **世界法则（前面）**：基石/养成线——决定"哪个地方的资源被抢"。
- **世界格局（前面）**：冲突线/谁占哪格——本份的地与格局的格对得上。
- **宏观地理格局（本份）**：空间怎么分块、每块有什么可抢。
- **世界历史/时代背景（兄弟档）**：时间维度——这空间在什么时代背景下。
- **顶层势力（后面）**：谁占哪块地、谁决定结局——本份只写地，不写占的人。

> 一句话：画像说"这世界有三层"，格局说"这张棋盘谁占了什么"，宏观地理格局说"每块地本身有什么可抢、能排什么戏"。

## 待处理问题（这份眼下还没定 / 存疑 / 待实测）

- [ ] **分块粒度判据（"够排戏"）未量化**：一个题材到底该分几块才既不空又不堆，待真实案子核。
  → 为什么悬着：判据靠感觉，没有数字。
  → 等谁定：第一个真实案子按④走完，看块数与卷数比例。
- [ ] **"每卷最多新增1-2块"是拍的数**，未验证。
  → 为什么悬着：没有真实卷纲样本。
  → 等谁定：真实案子卷纲排下来再看。
