# 赛道库-SOP（流派注册表 + 复用/创新判定）

> 用途：解决"对赛道的认知太粗"——把知名流派从"大类"细到"流派"，定下每个流派的**读者默认预期（该复用）** 和 **卖点差异区（该创新）**，给"超头部复用"一个可查的底。
> 从属：设定生成方法论的一等资料。生成任何设定前，先查这张表确认"这书属哪个流派、读者默认什么、哪里能创新、世界该多大"。
> 定位：沉淀稿。种子由项目已认知流派先建，随真实案子实测 + research 刷新。

---

## 0. 为什么必须有赛道表（先定认知问题）

"都是西幻"是错的粒度。**诡秘流 vs DND 都是西幻，但读者默认完全两套：**

- **DND 读者默认**：有 1-9 阶生物（CR）、1-40 级总等级/职业等级、传奇设第5阶、神力分微弱/弱等/中等/强大/伟大——层级就是"数字 + 称号"，力量可量化。
- **诡秘流读者默认**：有序列 9→0，每个序列既是身份又是诅咒，升级靠魔药 + 扮演消化，越升越付出理智代价。

分类太粗 → 复用会复用错骨架。**赛道表 = 把每个流派的"读者默认预期"定成可查清单，复用才不会用错骨架。**

### 流派 vs 族 · 判定判据（避免重蹈"西幻"太粗）

建条目前先问一句：这个候选是**族**还是**流派**？

- **族** = 大类题材，一个族装多个读者默认完全不同的流派（西幻、都市、仙侠）。
- **流派** = 读者默认（力量骨架/升级/画风）成体系的一支，赛道表的一行就是一条流派。
- **判据**：两个候选的"读者默认"是否至少一半不同？是 → 是两个流派，各建一行（DND 跟诡秘流、凡人流跟洪荒流，各一行）；否 → 是一行里补差异，不另开行。

用这条判据再看"西幻"：DND 和诡秘流的读者默认一半以上不同，所以它们是两个流派，不是同一行。**认知错了不是改措辞，是这条判据漏用了。**

### 每条流派必带「世界规模」（防写小）

每个流派一行，除了力量骨架/升级/画风，**必须带一行「世界规模（读者默认的物理底盘）」**——读者默认这书的世界有多大。生成《世界画像》第0步物理范围时，用它 + 量规表双查，**避免一写赛博/克苏鲁就缩成单城**。

## 1. 复用 vs 创新 · 判定规则（四格 + 判定顺序）

### 判定顺序（什么时候用哪格）——默认复用，除非踩触发器

**先默认：整套默认骨架一律复用**——力量分层、升级境界、地图纵深、日常氛围、世界规模，读者天天碰的结构，别为"创新感"乱动。

**只在两处才想创新：**
- **踩「卖点触发器」**：这本需求卡/你的立意点名的招牌部位——主角的金手指、核心冲突、全书最奇一次。这里才允许动。
- **踩「空白触发器」**：赛道表里该部位"读者默认"是空的，或整行查不到这流派——这时不创新也没得复用。

**没踩触发器 → 直接复用，别再问"能不能创新"。**

### 判据一 · 是不是卖点

这部位是不是主角招牌、最想让人记住的那一档？

### 判据二 · 读者有没有默认预期

查赛道表，这部位读者"理所当然"认为该长什么样？

| 是否卖点 | 有默认预期 | 无默认预期 |
| --- | --- | --- |
| 是卖点 | **复用命名骨架 + 机制上创新**（熟人一眼认出、又觉新鲜） | **大胆创新**（这是你的空白地/名片） |
| 非卖点 | **放心复用，别折腾** | 用套路逻辑补齐即可 |

**口语化判据（更快）：**
- **读者天天用的默认骨架**（力量分层、升级、地图纵深、日常、世界规模）→ 默认预期强 → **复用公认骨架**，别为"创新感"乱动。
- **你卖的差异**（主角招牌、核心矛盾、设定最奇一点）→ 主卖点 → **创新**，且是"在复用骨架上错一格"的创新，不是从零造。

**守则（避坑）：**
1. **别创新到读者认不出**：复用是"一眼看懂"的底座，创新是"懂的人眼前一亮"的亮色；创新过头 = 出戏。
2. **创新要锚**：在复用骨架上错一格（比如把 DND 的序列换成另一套机制，但保留"力量有阶梯、可量化"这个默认）。
3. **基础设施别乱翻新**：升级、地图天天用，大的结构复用，小的区别放在细节（命名、地名、物件）。

**何时才救整本书的创新**：仅当 ① 用户明确要"创新流派"，或 ② 该部位读者根本没默认。否则创新要换回"读者一眼懂的收益"才做。

## 2. 流派注册表（种子 v1）

每个流派一行都要能答四问：**读者默认什么（→复用）？哪里是差异区（→创新）？世界多大（→防写小）？代表性书是谁（→参考来源）？**

> **骨架认知校验**：行里画的骨架你若不拿准，先 research 补准再写进世界法则——DND 这套 1-9 阶 CR / 1-40 级 / 传奇 / 神力谱系，是老板实测核实过的基准，别凭印象画。

### 奇幻·西幻族

**DND（龙与地下城 like）**
- 代表书：博德之门 / 龙枪 / 冰与火之歌（半）
- 力量骨架：生物 1-9 阶 CR + 职业等级总等级 1-40 + 传奇（第5阶）+ 神力（微弱→弱等→中等→强大→伟大）
- 升级结构：职业等级（战斗/施法）+ 经验，兼职挂多职业，5阶为凡俗之巅、之上是神域
- 舞台：王都 / 冒险地牢 / 地下城 / 位面
- **世界规模（读者默认的物理底盘）**：**多大陆/多王国 + 位面体系**（主物质位面之外有元素位面、外层位面），不是单城单王国
- 画风：中世纪魔幻 + 佣兵团冒险 + 神体系
- **读者默认（复用）**：力量可量化（等级+CR）、血统/职业有传承、神有神力谱系
- **差异区（创新）**：独有职业/法术/种族/神系；主角具体超速机制
- 参考来源：查 DND 3e/5e 的 CR、等级、神力分文件为复用基线

**诡秘流（克苏鲁 × 维多利亚）**
- 代表书：诡秘之主
- 力量骨架：序列 9→0；序列 = 身份 + 诅咒 + 理智代价
- 升级结构：喝魔药 → 扮演消化 → 适配，越升越近疯狂/失控；非凡特性守恒、聚合
- 舞台：维多利亚大都会（贝克兰德）/ 神秘组织 / 灵界
- **世界规模（读者默认的物理底盘）**：**一颗文明的星球 + 相叠加的"灵界/源质/非凡位面"**（现实星球之上叠着看不见的超凡层），不是一座大都会。丛书核心在贝克兰德一城，但上层舞台辐射到星球级组织与世界性阴谋
- 画风：蒸汽 + 哥特 + 不可名状 + 权谋 + 知识考据
- **读者默认（复用）**：有序列、升序列要付代价（理智/失控）、秘密组织对局
- **差异区（创新）**：扮演机制、序列途径命名、总危机（末日）来源、组织格局
- 参考来源：查诡秘之主的序列途径、非凡特性守恒为复用基线

### 仙侠

**凡人流（境界体系）**
- 代表书：凡人修仙传
- 力量骨架：练气→筑基→金丹→元婴→化神→合体→大乘→渡劫（境界命名）
- 升级结构：灵根资质 + 功法 + 资源（灵石/丹药）
- 舞台：低武山村 → 宗门 → 一域 → 上界
- **世界规模（读者默认的物理底盘）**：**一域起步 → 多大陆/星空 → 上界/天外**，量级一路拉开到"人界→灵界/仙域"，绝不是一座山
- 画风：修仙闲适 + 夺宝法器 + 宗门斗
- **读者默认（复用）**：有修仙境界、夺宝抢资源、宗门斗法、飞升上界
- **差异区（创新）**：金手指、独有体质/前缘/功法名
- 参考来源：查凡人修仙传的境界与资源体系

**洪荒流**
- 代表书：洪荒系列
- 力量骨架：大罗金仙 / 混元大罗 / 圣人…（圣位体系）
- 舞台：洪荒大地 / 三十三天
- **世界规模（读者默认的物理底盘）**：**整个洪荒宇宙 + 三十三天/六道轮回/混沌外域**，量级直接是"宇宙级"
- 画风：神话洪荒 + 量劫 + 圣人博弈
- **读者默认（复用）**：洪荒量劫、圣人之下皆蝼蚁、先天灵宝
- **差异区（创新）**：主角入局的成圣之路、独有因果线

### 都市

**都市异能（灵气复苏）**
- 代表书：灵气复苏类
- 力量骨架：觉醒者 F-S/1-9 阶、异能分类
- 舞台：现代都市 → 异界裂缝 → 秘境/全球战场
- **世界规模（读者默认的物理底盘）**：**地球主场起步**（单城/数城），缝开到异界后扩到"全球 + 裂缝对面";后期可到"灵气海啸全地球"
- **读者默认（复用）**：灵气复苏、觉醒者、国家管控机构、异界裂缝
- **差异区（创新）**：独有系统/金手指、异能与主角绑定方式

**都市神豪/系统都市流**
- 代表书：神豪流
- 力量骨架：资产量级 + 系统奖励（无境界，纯资源地位）
- 舞台：都市商圈 → 资本世界
- **世界规模（读者默认的物理底盘）**：**单城/数城起步，上游到全国财团**，通常不扩到世界（神豪流终点是资本帝国，不是世界）
- **读者默认（复用）**：神豪系统、撒钱、打脸、资产滚雪球
- **差异区（创新）**：金手指机制、项目方向

### 系统流 / 无限流

**系统流**
- 力量骨架：宿主 + 系统 + 属性面板 + 任务奖励/抽奖积分
- 舞台：跟随宿主位置（都市/异界/宗门）
- **世界规模（读者默认的物理底盘）**：**跟随宿主所在主世界定**（都市就都市，异界就异界），系统不扩世界、只扩宿主个人
- **读者默认（复用）**：有面板、做任务、拿奖励爆属性
- **差异区（创新）**：系统从哪来、规则是否公平、有没有代价
- 参考来源：查代表性系统文的面板与任务结构

**无限流**
- 力量骨架：主神空间 + 穿越副本 + 兑换评分
- 舞台：主神空间 + 无数副本世界
- **世界规模（读者默认的物理底盘）**：**主神空间连接无数独立副本世界**，量级天然是"多元/复合世界群"
- **读者默认（复用）**：进副本、赚积分、回主神空间兑换
- **差异区（创新）**：副本选材、惩罚规则、死亡与复活机制

> 种子先建到这。这是"先有再调"：哪些流派重要、每条骨架对不对，随真实案子实测 + research 刷新，不是一版定稿。

## 3. 这张表怎么用（三步）

1. **定类**：这书写哪流派？从大类直觉落到具体流派（不是"西幻"，是"DND like / 诡秘流 / 凡人流"，查代表书确认）。落不准先过"流派 vs 族判据"，别停在族。
2. **取复用**：从该行"读者默认（复用）"列，拿来做默认骨架——力量分层、升级、地图、日常。这是"超头部复用"的默认路径。
3. **定创新**：只对踩了卖点/空白触发器的部位，从该行"差异区（创新）"且对齐需求卡卖点，定"在复用骨架上错一格"的差异点（不是推倒重来）。
4. **取世界规模**：从该行"世界规模"列读取读者默认的物理底盘，喂给《世界画像》第0步物理范围（配合量规表，防写小）。

## 4. 这张表怎么维护

- **种子**：项目已知流派先建（上文）。
- **刷新**：新开一本，先查表；查不到再用 research 调研头部书籍补一条，或纠正旧条目（骨架拿不准就补准，DND 数值就是踩过的坑）。
- **世界规模**：每本书的物理范围从画像定，但"读者默认这流派多大"存赛道表；查不到默认规模就 research 补。
- **默认骨架与资源**：这张表只存"骨架识别"，不存具体数值/数值表（那是某本具体书的设定，写进世界法则，不写进赛道表）。

## 附：一句话收束

**赛道表管"读者默认什么、哪里能创新、世界多大"；复用是"读懂读者的默认"、创新是"在能变的地方错一格"、世界规模是"别把底盘写小"——都别超过读者认得的底线。先复用默认骨架，踩到卖点/空白触发器才动创新。**
