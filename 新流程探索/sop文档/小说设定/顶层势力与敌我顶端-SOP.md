# 设定文档 · 顶层势力与敌我顶端-SOP（骨架）

> 从属：小说设定总SOP（小说设定-SOP.md）③「世界格局」后续。
> 产出阶段：**主线剧情设计阶段**（设定总账 tag=骨架），在世界格局（棋盘/冲突线）之后。
> 地位：决定结局的那几家——谁掌权、谁想改、谁站主角这边。只写到骨架级（每势力能排终局戏的程度），中层分支归展开。
> 依赖：建立在 世界格局（棋盘/冲突线）、世界法则（基石/养成线→势力的资源底座）、世界历史（掌权是怎么来的）之上；产出供 主要反派/卷纲 使用。
> 范式：按【设定文档-统一模板-v1】四段式；吸收 pop-snow-stage「势力5维」「强势力有成本、弱势力有生存理由」「金字塔约束」「众生攀登分层」。

---

## ① 文档定位（这是份什么，静态定义）

**顶层势力与敌我顶端 = 决定结局的那几家，谁站主角这边。** 回答：谁掌权、谁想改、谁决定结局、谁会在终点与主角对撞。

- **角色**：骨架。只写能排终局戏的顶层几家，中层办事机构归展开。
- **回答**：谁决定结局？谁站主角这边？
- **链路位置**：③ 的后续（世界画像 → 世界法则 → 世界格局 → 主角设计 → **顶层势力**）。格局摆棋盘，本份把棋盘上的大棋子立起来。
- **依赖**：世界格局（冲突线/谁占哪格）、世界法则（基石/养成线）、世界历史（掌权成因）。产出供 主要反派/卷纲 使用。
- **一句话落点**：能一句话讲清"谁决定结局、谁站主角这边"，且每家势力都过得了三条结构约束。

它不是：
- 不是**组织百科**（每家的规章/成员列表——中层细节归展开）。
- 不是**阵营表**（谁和谁结盟的完整关系网——那是展开层的势力关系网）。
- 不是**反派设计**（反派里最顶尖的那位归《主要反派》；本份写"势力"，反派写"人"）。

> 判据：写完①，读者知道"这份管谁决定结局"，但不知道"怎么填"——怎么填是②。

## ② 思考逻辑（填的时候脑子怎么转，动态方法）

**这条推演痕迹（agent 最该掌握）：顶层势力 = 棋局的大棋子——每方过「势力5维」（目标/资源/规则/弱点/关系），且遵守三条结构约束：强势力必须有成本、弱势力必须有生存理由、不能均势也不能独大到无解。**

- **从格局的冲突线立势力**：世界格局已画"谁占哪格、哪两格对冲"，本份把占格的大棋子立起来——每方势力 = 冲突线的一端。
- **每方过势力5维（吸收 snow-stage）**：
  1. **目标**：想得到什么？怕失去什么？
  2. **资源**：控制什么稀缺物？（对应法则的基石/物资）
  3. **规则**：如何奖惩成员？
  4. **弱点**：制度漏洞 / 内部矛盾？
  5. **关系**：与主角/其他势力的联盟、敌对、中立、暗斗？
- **三条结构约束（吸收 snow-stage）**：
  - **强势力必须有成本**（强=付出代价，否则读者不信）；
  - **弱势力必须有生存理由**（能活到今天靠什么）；
  - **不能完全均势**（无张力），**也不能一家独大到剧情无解**（主角没戏可抢）。
- **金字塔约束（吸收 snow-stage 位阶坐标谱）**：满街不见高阶——顶层势力的人站在金字塔尖，普通读者见的都是中层办事的人；顶层出场=大事发生。这保证稀缺感和压迫感。
- **众生攀登分层（吸收 snow-stage）**：有资源 / 没资源 / 爬到顶 / 掉下来的各是谁——顶层势力的成员从哪来，底层怎么仰望、攀爬。

> 判据：一份合格的②，读的人该能模仿"从冲突线立势力 → 每方5维 → 过三条结构约束 → 金字塔约束"这套思路，换题材照推。

### 案例 ≥2 跨赛道

**案例1 · 遮天（仙侠）**
- **顶层势力**：圣地世家（掌权）、禁区至尊（隐世大敌）、散修联盟（摇摆）、人族/异族大族（格局支柱）。
- **5维示例·禁区至尊**：目标=长生/复生（怕=仙路重开失去特权）；资源=太古遗存/禁区威能；规则=至尊不问世事、禁区不容侵犯；弱点=每次出手耗命元、彼此猜忌；关系=与圣地暗斗、与主角终局对撞。
- **结构约束**：圣地强但内斗消耗（成本）；散修弱但有数量与人心（生存理由）；禁区独大但互不相容（不无解）。
- **金字塔**：北斗修士满街是练气/筑基，仙台大能一域一个——顶层出场=圣战级大事。
- **敌我顶端**：终局对撞=禁区至尊（改天换地派）；站主角这边=人族古帝残念/部分圣地。

**案例2 · 诡秘之主（克苏鲁维多利亚）**
- **顶层势力**：正神教会（掌权）、隐秘组织/密修会（挑战）、官方非凡机构（摇摆）、旧日崇拜者（隐世大敌）。
- **5维示例·正神教会**：目标=维持秩序/对抗旧日（怕=秩序崩塌）；资源=官方渠道/非凡特性储备；规则=恩威并施、异端必除；弱点=官僚僵化、内部派系；关系=与隐秘组织敌对、与主角暗斗后转合作。
- **结构约束**：教会强但僵化（成本）；隐秘组织弱但灵活隐秘（生存理由）；双方缠斗不一边倒（不无解）。
- **金字塔**：贝克兰德满街是普通人+低序列者，序列3以上是传说——教会高层出场=大事件。
- **敌我顶端**：终局对撞=旧日/幕后真凶；站主角这边=灰雾之上的神秘存在（他自己）。

**泛化验证**：同一套"从冲突线立势力→5维→结构约束→金字塔→敌我顶端"，在"仙侠（圣地世家分治）"和"克苏鲁（教会vs隐秘组织）"两个赛道都成立——势力形态随题材变，结构约束不变。

### 3. 弱世界观变体（都市 / 言情 / 纯爱用）

| 强世界观成分 | 都市言情降维成 |

## ④ 产出SOP（怎么一步步产 + 每步验收基准）

1. **回读格局冲突线与法则**：世界格局（谁占哪格、哪两格对冲）＋ 世界法则（基石/养成线）。
   → 【验收基准】每方势力都能对应到格局的一格/一条冲突线。
2. **立势力**：把冲突线两端立成顶层势力，数量控制在"够排终局戏"（3-6家）。
   → 【验收基准】数量不贪多；每家都能排一场终局级戏。
3. **逐家过5维**：目标 / 资源 / 规则 / 弱点 / 关系。
   → 【验收基准】5维都有答；弱点不能空（没有弱点的势力=读者不信）。
4. **过三条结构约束**：强势力有成本、弱势力有生存理由、不均势不独大。
   → 【验收基准】三条自查全过；出问题→调整该方（加成本/给理由/调平衡）。
5. **钉金字塔**：满街不见高阶；顶层出场=大事；顶层成员从"众生攀登分层"有来处。
   → 【验收基准】读者能感知"顶层有多稀罕"；成员有来处不是凭空。
6. **定敌我顶端**：谁决定结局、谁站主角这边、终局对撞方是谁。
   → 【验收基准】与主角设计的"欲望串终点"对得上（《主要反派》的人站在其中一家的顶端）。
7. **边界检查**：检查是否把《宏观地理格局》（地）《世界历史》（成因）《主要反派》（人）写进来了，有→归位。
   → 【验收基准】本份只写"势力的现在态"：地归格局、成因归历史、人归反派。

## 附：与相邻设定的边界

- **世界格局（前面）**：棋盘/冲突线——本份把格子立成势力。
- **世界历史（前面）**：掌权成因——本份写"现在态"。
- **顶层势力（本份）**：决定结局的几家。
- **主要反派（后面）**：挡在欲望串终点的人——站在某家顶端的"人"。
- **势力关系网（展开，待建）**：完整结盟/敌对网——本份只写"顶层间的关系"，不写全图。

> 一句话：格局说"这张棋盘谁占了什么"，顶层势力说"占格子的大棋子是谁、强在哪、怕什么、站谁那边"。
