# 立项创意 SOP v1.3

> 用途：把用户一句模糊想法，变成这本书的故事脉络。故事脉络是全书叙事弧的种子，之后才进入卷级结构设计。
> 依据：全书大纲生成方法论 v1.4 ＋ 网文宏观结构引擎理论 v1 ＋ 知名小说验证（诡秘之主、遮天、玄鉴仙族）。
> 范式：按【设定文档-统一模板-v1】四段式重构；内容硬规则一字未动，散落边界/未实测归拢「待处理问题」。本 SOP 是"立项"流程，不是纯设定文档，②思考逻辑是流程顺序、③内容是需求卡+五元素表格。

---

## ① 文档定位（这是份什么，静态定义）

**立项创意 SOP = 把用户一句模糊想法，变成这本书的故事脉络。** 故事脉络是全书叙事弧的种子，之后才进入卷级结构设计。

- **角色**：立项（创意阶段）主文档。不属于核心设定"锁根"那张，但它产出需求卡 + 故事脉络，是锁根文档（世界画像/法则/格局/主角设计）的上游输入。
- **回答**：这本书讲了个什么故事？（**主角立身（什么人＋凭什么脱颖而出）**、世界哪里失衡、欲望串、谁挡着、落什么结局）
- **链路位置**：第一步。用户想法 → 问需求 → research → **故事脉络** → 核心设定（世界画像/法则/格局/主角设计）→ 卷级。
- **依赖**：输入=用户一句想法；产出=需求卡 + 调研文档 + 故事脉络（供后续设定消费）。
- **一句话落点**：能把"这本书讲了个XX的故事"讲给朋友听，且五元素故事脉络填全。

- **完成标准**：故事脉络五元素填全，讲给朋友能说出"这本书讲了个XX的故事"。故事脉络不是剧情，不写具体情节。

- 卷级结构设计（英雄之旅、三幕式、碎片式等叙事结构）在本 SOP 之后，见文末「附：卷级结构」。

- 消费对象是写作 agent，不是人脑。圈内作者一句话主线够用，因为套路在脑子里；agent 没有那份隐性知识，每个判断都写在纸上。

---

## ② 思考逻辑（填的时候脑子怎么转，流程顺序）

**这条推演痕迹（agent 最该掌握）：立项 = 一句话想法 → 问需求（别润色）→ research（补认知）→ 五元素公式（定故事脉络）。**

- **顺序是先问、再研究、最后才构造**：不是一上来就编故事。先问清用户五样（赛道/市场/爽点/参考书/X元素）→ 把原话整理成需求卡（不润色）→ research 补赛道认知 → 再拿五元素公式推故事。
- **唯一尺子跨书通用**：五元素「主角立身 → 世界哪里失衡 → 欲望串 → 谁挡着 → 落什么结局」——这个顺序是推的骨架，不分赛道不分类型都适用。
- **主角立身三件**：什么人（身份/特质/处境）＋**凭什么脱颖而出（独一份的不可替代性）**＋读者记住什么（第一印象）。三件在故事脉络里一起定——主角设计的灵魂（为什么是他）在立项完成，不甩给后面的角色设计。
- **欲望串是链条不是清单**：主角想要的不是单目标，是一根动机链（串行接力/并行组合，或叠用）。主线最多一两条，其余是次要目标。
- **失衡是驱动不是背景板**：写"圣城地下怪物最不对劲"，不写"这是一个充满怪物的世界"；分双层——旧失衡被压＋新失衡撕破。
- **越界边界**：故事脉络的主角 = 种子＋脱颖而出的理由；金手指的形态（档位表/能力细节/奇遇），全部留给主角设计，别提前定完。

> 判据：一份合格的②，读的人该能模仿"先问需求→整理需求卡→research→五元素公式逐个填"这套流程，且明白每一步为什么（不润色=查得出用户本人；金手指占位=谜底定了再定形；脱颖而出=换路人故事就不成立）。

## ③ 文档内容（结构 / 表格 / 以便 agent 直接填）

### 第 2 步 · 需求卡五字段（全用户语言，不掺行话）

| 字段 | 填什么 | 判据 |
| --- | --- | --- |
| 基调 | "这是本XX流的书，向读者承诺A/B/C" | 三项承诺说得全，流派就立住了 |
| 主角欲望线 | 谁＋要什么＋凭什么 | "凭什么"填金手指雏形，占位符，不定形 |
| 世界线 | 过去出过什么事＋现在正走向什么结局 | 写事件，不写机构地图 |
| 篇幅 | 量级、分几卷 | 卷数用户定 |
| X 元素清单 | 用户喜欢的元素逐条登记 | 只登记，不筛选 |

三条细则：

- 世界线写事件不写机构：朝廷、宗门、地图是舞台设定的事，卷纲期再做。
- 世界线分厚薄：谜底流一段话起步；言情文一行也够。用户的谜底直觉哪怕半句也记入。
- 金手指是占位符：定形在卷级结构设计后反推——谜底定了，金手指从谜底里派生。
- **世界线先预判量级（防写小）**：按篇幅记一句"这书大概多大世界"（单城/星球/多元），写进世界线。它会在世界画像第0步被量规表 + 赛道默认规模复核。**200万字以上的，这里就标"至少星球/多元"，别等画像阶段才纠正。**

### 第 4 步 · 故事脉络五元素公式

有了需求卡和调研，推演这本书的故事脉络。唯一可靠尺子跨书通用，不分赛道、不分类型：

```
主角立身 → 世界哪里失衡 → 欲望串（串行/并行） → 谁挡着 → 最后落什么结局
```

五元素定义：

| 元素 | 填什么 | 判据 |
| --- | --- | --- |
| 主角立身 | 三件：**什么人**（身份＋特质＋处境）＋**凭什么脱颖而出**（独一份的不可替代性）＋**读者记住什么**（第一印象） | 什么人＝现状可感知；脱颖而出＝换成路人故事立刻不成立；第一印象＝一句话能被复述 |
| 世界哪里失衡 | 世界/环境哪里不对劲，逼着主角动 | 是失衡，不是背景板；具体到可感知；**分双层（旧失衡被压＋新失衡撕破）** |
| 欲望串 | 贯穿全书的心理动机，可串行可并行 | 见下方"欲望串"小节，主线最多一两条；**末尾要同时挂钩解决新旧双失衡** |
| 谁挡着 | 明面阻力＋暗面阻挡 | 分两层：明面是谁、暗面后面还有谁 |
| 最后落什么结局 | 主角最终翻到哪一步 | 有收束，不悬空 |

### 4.0 主角立身（v1.3 核心补充：主角设计在立项一起完成）

**主角立身 = 三件**：什么人（身份/特质/处境）＋凭什么脱颖而出（不可替代性）＋读者记住什么（第一印象）。三件在故事脉络里一起定——主角设计的灵魂（为什么是他）在立项完成，不甩给后面的角色设计。

**脱颖而出（核心）**：是主角身上"独一份、换别人这本书就不成立"的特质，是读者追这本书的第一理由。是A：立项级决策——这个主角的核心辨识度；不是B：金手指形态（档位表/成长量/能力细节，归角色设计）。

**判据**：把主角换成书里任何一个路人，故事立刻不成立 = 脱颖而出立住了；换成谁都行 = 没立住，回问。

**提问句式（大白话，立项必须问透）**：

- "这个主角一开始是什么人？读者第一眼看到他，记住的是什么？"
- "这本书 XX 万字，凭什么写这个人？换成这个世界里任何一个路人，故事还成立吗？——他身上有什么是独一份的？"（核心问题，必须问）
- "他能出头，靠的是只有他能用的东西，还是别人也能有？"（区分"独一份"与"可复制"）

**模板句式**："他是唯一/第一个/天生/被迫……能……的人"。例："唯一能识破混沌腐化的穿越者""负债的底层耗材，某天发现自己那页早该撕掉的命有问题"。

**脱颖而出可以来自哪（五类来源，避免只盯金手指）**：

1. 身份：唯一/被选中的身份（末代皇族、唯一幸存者）。
2. 认知：穿越者认知差、重生先知（知道别人不知道的）。
3. 命格/体质：天生与众不同（荒古圣体、特殊血脉）。
4. 处境：被逼到只有他能动的墙角（全族皆亡唯他存）。
5. 金手指雏形：系统/职业/传承的"独一份"性质（占位，不定形态）。

**反例（可复制特质不算脱颖而出）**："他很努力""他有贵人相助""他运气好"——换成别人也成立，立不住，回问。

### 4.1 「主角立身」的越界边界（v1.3 修订）

- 故事脉络的主角 = **种子＋脱颖而出的理由**，不是小传。**"凭什么"拆两层**：
  - **脱颖而出的理由**（为什么是他：唯一/第一个/天生/被迫能X）——故事脉络定。这是主角设计的灵魂，立项就要立住。
  - **能力/金手指形态**（档位表、成长量、能力怎么用、奇遇细节）——留给 `主要角色设计·主角力量资格/金手指` 那份锁根。
- **越界判据**：写完"主角立身"，若读者已经知道"他具体的能力有几档、怎么用、那场奇遇怎么发生"= 越界（形态定早了）；若读者知道"他是唯一能X的人、他有别人没有的东西"= 正确（脱颖理由，立项该定）。
- **越界清单（实际踩过）**："某夜他在杂物间镜子里看见一个影子，被它'借了命'替他活下来…账本多了一页'阴账'"——这是金手指形态（奇遇+能力细节），不是故事脉络。故事脉络该写："一个负债的底层耗材，某天发现自己那页早该撕掉的命有问题"——这句同时立住了"什么人"和"脱颖而出"（他的命有问题=独一份）。
- **两层该归谁**：`身份/特质/处境＋脱颖理由`（如"被除名的顶级义体佣兵，是唯一还保有旧代义体代码的人"）放`主角立身`；`能力形态`（如"那本不该活的命是影子借给他的，影子的账页怎么翻"）归 `主要角色设计`。谁定的身份/独特性放故事脉络，谁定的能力形态放主角设计，别混。

**欲望串**（修正自"他想要什么"）：

- 主角想要的不是单目标，是一根动机链，串行或者并行。
- 串行：一个欲望达成/幻灭后，接下一个更大的（接力律，接的比之前大一号）。例：生存→变强→守护人族→平定乱世。
- 并行：多个欲望同时挂着同时追（组合律，全书主打一两个，其余为次要目标）。例：查原身死因＋想办法回家，中途又挂上阻止末日。
- 可串行和并行叠着用：一条串行的主欲望串，中间并行走支线。
- 判据：串得再长，全书主线最多一两条（主角最想要的那一两个），其余都是次要目标。否则欲望串变成清单堆砌，读者记不住主线。
- 注意：欲望串是"贯穿全书的心理动机"（战略），不等于每卷要拿到的具体东西（战术）。卷级目标是"这一卷的达成物"，别并进欲望串里。
- **欲望串末尾挂钩双失衡（v1.2 硬规则补充）**：欲望一路串到终点时，要**同时挂钩解决"旧失衡"与"新失衡"两条**——不是只灭新危机就算完。例：不只"挡住诡异复苏"，还要"同时把虐出诡异的那套资本/制度一起掀了"。（两条失衡常是同一根源的一体两面，世界观越往真相越发现二者同源。）

两条纪律：

- **立项不写"代价"**。爽文的爽感来自"成功"，代价在打通主线时会打断爽感。悬疑/反转型书真要加，放到卷级结构里单独加，不放进全书通用公式。
- **失衡是驱动，不是背景板**：写"圣城地下怪物最不对劲"，不写"这是一个充满怪物的世界"；**分双层**，写"这个被资本压榨到习惯的世界，被诡异复苏凿开了裂缝"，不写"这个世界乱了"。**结局要"翻"**：写"杂役翻成定世界生死的人"，不写"他活下来了"。

### 4.2 展示用例：用知名小说验证公式

拿三本结构差异大的知名小说，按五元素框一遍，验证公式的通用性。这三栏写得足够丰富，作为后续 agent 写故事脉络时的示范模板——照着这个密度和写法填，不写空泛的一句带过。

**《诡秘之主》——公式套得最完整（个人命运线＋世界真相线双核心）**

| 元素 | 诡秘之主 |
| --- | --- |
| 主角立身 | 什么人：穿越者克莱恩·莫雷蒂，表面是个凡俗银行小职员。脱颖而出：他登上"灰雾之上"扮成神秘存在"愚者"——这是独一份的处境，被迫在各种非凡势力间扮演、周旋、交易，身份一层压一层，越走越深。第一印象：一个装成神明的凡人。 |
| 世界哪里失衡 | 一个被隐秘组织、失控非凡者和诡异力量撕裂的世界：序列尽头的神各有目的，末日征兆逼近，普通人活在随时被卷入超凡灾祸的阴影下。 |
| 欲望串 | 串行＋并行叠用。主串：查清原身死亡真相 → 想办法回家 → 随着卷入加深，升级为阻止末日、守护自己所在乎的一切。 |
| 谁挡着 | 明面：各路诡秘势力、不可名状的敌人、追查他的赏金和断言。暗面：序列尽头的"神"、真实造物主、隐藏的末日成因——越查越大。 |
| 落什么结局 | 从"被迫扮演的愚者"翻成"真正承担使命的愚者"：不再伪装，主动选择守护，成为真实序列尽头的执掌者，直面并回应末日与神的博弈。 |

**《遮天》——欲望串最能体现"滚动接力"**

| 元素 | 遮天 |
| --- | --- |
| 主角立身 | 什么人：地球普通青年叶凡，被九龙拉棺送进北斗星域的修真世界。脱颖而出：身负荒古圣体却遭天地压制、举世皆敌——万中无一的体质加被压到极致的处境，起点是"最普通的凡人"，被扔进最残酷的修真形态。第一印象：一个被全世界针对的凡人。 |
| 世界哪里失衡 | 仙路断绝、长生之谜横亘古今；各族争霸、禁区至尊虎视眈眈，黑暗动乱时刻可能血洗宇宙。 |
| 欲望串 | 典型串行，一路接力变大：生存 → 变强证道 → 守护人族 → 平定黑暗动乱。 |
| 谁挡着 | 明面：争霸的同代天骄、轻视他的各方势力、一路设卡的敌人。暗面：历代至尊、禁区、黑暗动乱背后的力量，以及"成仙"本身被世界判为不可能的规则。 |
| 落什么结局 | 从一介凡人翻成"叶天帝"：逆天成帝，击穿仙域通道，亲手结束黑暗动乱，最后葬下己身于石棺，踏向更上一层的世界（留续作钩子）。 |

**《玄鉴仙族》——公式的"谁"要替换成共同体**

| 元素 | 玄鉴仙族 |
| --- | --- |
| 主角立身 | 什么人：**不是单人，是一个家族单位**——李氏从黎泾村凡人家族起家。脱颖而出：四代子弟接力撑起整个家族的存续，读者情感寄托在家族这个共同体上。第一印象：一个拼全家三代才站稳脚跟的凡族。 |
| 世界哪里失衡 | 仙凡分野下的生存压迫：宗门中心主义垄断资源和话语权，家族在层层叠叠的高阶战力夹缝里求存，修士走错一步就满盘皆输，凡人的根基随时会被碾碎。 |
| 欲望串 | 串行为主，但"主角"是家族：家族的存续与兴盛。每一代往前推进一步——先立稳脚跟，再谋求修仙之位，再扩地盘、开府立制，一步步从黎泾村翻成望月仙族。 |
| 谁挡着 | 明面：宗门、高阶修士、其他家族的资源争夺与倾轧。暗面：家族内部的路线分歧、嫡庶权力结构、以及"修仙无门槛"背后的资源分配之痛。 |
| 落什么结局 | 家族从一村凡族翻成望月仙族："重家族、轻个人"的主角单位，最终靠几代人的积累在仙道格局里站稳脚跟。 |

**三本对照教给我们的通用性结论：**

1. 五元素公式能装下个人主角（诡秘、遮天），也能装下共同体主角（玄鉴——把"谁"扩成家族/宗门/商号）。
2. 欲望串串行、并行、叠加都成立，遮天是串行接力最完整的样本。
3. 世界的失衡必须具体到可感知（怪物被掏空/仙路断绝/宗门垄断），不能是空泛的"这个世界的背景"；能分新旧双层失衡更好。
4. 结局一律要"翻"：主角或共同体的位置和身份，从起点到收束发生了质变。
5. 大的世界观/真相库存（诡秘的分层真相、遮天的仙路）藏在"失衡"和"谁挡着的暗面"里，不单独占栏——立项不展开，留给卷级。
6. **脱颖而出决定主角辨识度**：诡秘的"装神明的凡人"、遮天的"被全世界针对的凡人"、玄鉴的"接力兴家的凡族"——换掉这个独特性，三本书都不成立。主角立身没立住，故事脉络就是流水账。

**写故事脉络时的示范要求（照这个密度）：**

- 每个小格填完整句，包含"是什么＋为什么可感知/可记忆"，不写单个名词或短语。
- 主角立身三件填全：什么人＋脱颖而出（独一份）＋第一印象；脱颖理由必须是"换路人就不成立"的独特性，不能是"他很努力"这类可复制特质。
- 欲望串写清形态（串行/并行）和主串，串行要能看出"下一个更大"。
- 谁挡着必分明面＋暗面两层，暗面是结构性的钩子所在地。
- 落结局要写出"从X翻成Y"的质变，不留悬空。

## ④ 产出SOP（怎么一步步产 + 每步验收基准）

1. **问需求（第1步）**：和用户沟通，问清五样（写什么赛道/目标市场/核心爽点/有无参考书/喜欢的X元素）。
   → 【验收基准】五样问全；已确认的不重问。
2. **整理需求卡（第2步）**：把原话整理成需求卡五字段，存档保存。**用户原话入卡，不润色。**
   → 【验收基准】全用户语言、不掺行话；金手指是占位符不定形；世界线写事件不写机构；200万+先标至少星球/多元。
3. **research 调研（第3步）**：启动 research skill，针对赛道和 X 元素需求做增量调研（按 v1.4 七项）。数据源顺序：已有赛道包 > wiki 站 > 联网调研；查不到的写"没查到"不凭空编造。
   → 【验收基准】调研完可为需求卡回填（用户改主意以新为准）；调研文档存档保存。
4. **推演故事脉络（第4步）**：用五元素公式「主角立身→世界哪里失衡→欲望串→谁挡着→落什么结局」逐个填。
   → 【验收基准】主角立身三件填全（什么人/脱颖而出/第一印象），脱颖理由是"换路人就不成立"的独特性（越界判据过：只写理由不写形态）；失衡分双层不是背景板；欲望串串到终点同时挂双失衡；结局写出质变。

**验收总基准**：故事脉络五元素填全，讲给朋友能说出"这本书讲了个XX的故事"；且每格按示范密度(完整句+为什么可感知)，主角立身含脱颖而出，谁挡着分明暗两层，结局写"从X翻成Y"。

## 附：卷级结构（叙事结构放这一层用）

立项只定五元素大骨架，**不动叙事结构**。经典的叙事结构（英雄之旅、三幕式、爽文节奏、双线叙事、碎片式、单元剧等）全部留到卷级/具体大纲设计时，按赛道选着用。

| 层级 | 用什么 | 内容 |
| --- | --- | --- |
| 立项 | 五元素公式 | 故事脉络种子 |
| 卷级 | 按赛道选叙事结构 | 这一卷的形状 |
| 全书 | 循环机制 | 几十卷持续产出 |

叙事结构是形状层，描述"一个故事"的形状，预设终点；网文全书是几十个完整小故事，所以立项用不了结构骨架，要到卷级阶段才用得上。
