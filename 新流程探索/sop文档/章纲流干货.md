## 章纲流是什么

"章纲流"是 AI 写小说圈（星月写作工具社区）兴起的玩法叫法，出处：B站教程《【星月写作教程】AI写小说邪修'章纲流'全部流程》。核心主张：不铺全书大纲，直接一章一章用章纲驱动写，章纲当"大纲与正文之间的桥梁"。不是传统网文圈的老流派（无"大纲流/裸写流"那种历史）。

## 一、章纲黄金公式（桐梦书涵·头条·原文已全文抓取）

标题《章纲怎么写才不卡文？3个底层公式直接套》。作者整理上百本签约作品。

**卡文根源**：章纲是"事件清单"不是"情绪地图"。大纲管"发生了什么"，章纲管"读者感受到什么"。例：大纲写"主角在第三章发现师父是幕后黑手"（事件）；章纲应写"第三章结尾，读者应该感到震惊+被背叛的愤怒+迫切想知道接下来怎么办的焦虑"（情绪）。

**黄金公式**：`章纲 = 情绪曲线(70%) + 钩子分布(20%) + 节奏节点(10%)`

**情绪曲线（给每章画心跳图）**：标三个情绪坐标 `章首情绪值 + 章中峰值 + 章末情绪值`，每个 1-10 分（1平静，10极致冲突）。案例（一章"主角第一次进秘境探险"）：

| 坐标 | 分值 | 对应写法 |
|:--|:--|:--|
| 章首 | 3分（好奇但克制） | 主角站在秘境入口，四周安静得诡异 |
| 峰值 | 8分（守护兽扑出，生死一线） | 守护兽从阴影里扑出，爪子擦过脸颊 |
| 章末 | 5分（逃脱但受伤） | 主角逃出但左臂受伤，伤口会发黑 |

新手坑：别把每章峰值都标10分，十章八章10分会麻木；有低谷才有高峰。适用：中长篇玄幻/都市/仙侠每章2000-4000字；快穿/短篇爽文慎用（可压成三段式）。

**钩子分布（三种钩子，均匀分布不堆结尾）**：
- 信息钩子：给读者新信息，但他不知道意味着什么（例：秘境里捡到刻着陌生文字的石板）
- 情绪钩子：让读者处于"未完成"情绪状态（例：伤口开始发黑，但主角不知道为什么）
- 行动钩子：主角必须立刻做决定，读者不知道他会怎么做（例：前方传来打斗声，主角决定躲还是冲）

分布公式：`章首信息钩子 + 章中情绪钩子 + 章末行动钩子 + 章末信息钩子`（每章至少2信息+1情绪+1行动）。坑：钩子不是谜语——别写"他忽然想起一件事，但想不起来"，这是作者偷懒；钩子必须给读者足够信息，让他能"猜"。

**节奏节点（一章写多长）**：字数分配跟情绪曲线走，不跟情节走。四段：

| 段 | 字数占比 | 案例（全章约2000字） |
|:--|:--|:--|
| 情绪铺垫 | 15% | 主角进秘境，环境描写（约300字） |
| 情绪上升 | 35% | 深入探索，发现痕迹（约700字） |
| 情绪峰值 | 35% | 守护兽扑出，搏斗（约700字） |
| 情绪回落+钩子 | 15% | 逃脱受伤，伤口发黑（约300字） |

坑：回落段别变"总结段"——刚被爽到让主角坐下来总结=情绪断掉；回落段应该"带着悬念往前走"。

**完整章纲示例**（都市文第四章：主角去古玩市场）：
- 情绪曲线：开头3分 → 峰值7分 → 结尾5分
- 钩子分布：章首（告示被红笔划掉）+ 章中（老板眼神）+ 章末（被跟踪）+ 章末（铜钱花纹变化）
- 节奏节点：铺垫375字 + 上升875字 + 峰值875字 + 钩子375字（全章2500字）

**三个常见错误**：①章纲写成大纲微缩版（复读机）——章纲必须写"情绪+钩子+节奏"②情绪坐标全是正数没起伏③钩子全堆章末，读者读到一半跑了。

## 二、章纲的本质（UP主"停不下来的码字酱"·原文已全文抓取）

**章纲三要素**：
1. **开头**：承接上章钩子延续读者情绪；或开篇直接切入冲突拔高气氛；或做必要设定说明/新人物介绍。
2. **高潮**：章节核心部分，集中展现冲突、悬念、矛盾或重大抉择，情绪爆发点。
3. **钩子**：结尾悬念、反转或伏笔暗示。情绪线结尾为降→用伏笔平缓过渡；为升→留悬念或反转拉高期待。

**情绪线是章纲的灵魂**：章纲旁标注情绪走向，章节内至少一次情绪上升，避免平淡解释说明（平缓）。

**案例拆解**（重生女主触底反弹、手撕族中长辈后与男主初遇；雨天意外相遇、烟花般心动）：

| 设计维度 | 选项A（常规套路） | 选项B（非套路） |
|:--|:--|:--|
| 核心情节 | 英雄救美，男主救助女主 | 女主自救，误认男主为元凶后交手 |
| 互动细节 | 男主施救后对视心动 | 女主技高一筹，误会解除后回眸道歉 |
| 关键意象 | 常规互动 | 惊鸿一瞥、出水芙蓉，男主视角反差感 |

**必要条件填充**（逻辑自洽）：女主外出理由="寻找哥哥"；意外成因="雨天路滑"+"对马车做手脚的报复"；需要铺垫后续→打斗中植入关键线索（"关键人物身影一闪而过"或"掉落作证物玉佩"）。

**结尾钩子两种设计**：
- 平缓过渡型：暗示女主其实认识男主；埋伏笔小剧透下一章讲男主过去；情绪自然回落留余韵。
- 悬念拔高型：男主自爆家门，女主发现前世无此人记录；揭示矛盾点（如丞相家突然出现的"三儿子"）；制造反转或悬念强行拉高期待。

**写作习惯三件**：晨间温故（早上写前浏览昨天内容，修正错字病句+检查剧情BUG）；按纲写作（对照章纲展开，防跑偏）；超前规划（写完当前内容后，提前设计下一章或下两章章纲，保持连贯）——**与涌现流"一次排1-3章"一致**。

**章节写五遍流程**（搜索快照原文，后续楼层 JS 加载未取到全文，④⑤遍完整内容待补）：

4-5. 未取到原文。

**事件设计模式**（该帖原文已取）：事件完整过程 = 导火索（因由）→ 将你从状态X拉进状态Y → 产生需求/欲望/目标 → 行动1反馈1、行动2反馈2…直至愿望达成 → 阶段性/最终结论（情感突破/矛盾缓和）→ 回到状态X或进入新状态Z。主视角"你"可以是主角/CP/配角，开篇最好是主角或CP。

**核心梗=读者欲望的情绪奖励**（该帖原文已取）：核心梗要自带核心矛盾，能同时拉进剧情A线和情感B线；【读者欲望】的【情绪奖励】即【核心卖点】。文名文案紧紧围绕"读者欲望/情绪奖励/核心卖点/核心梗"写，和它无关的全都不写。

**"大纲要有，细纲算了"论**（该帖原文已取）：作者自述无法一开始搞定全本书细纲——①一口气想不了那么多复杂内容，强糊质量低没意义；②后面剧情细节都想好了，在脑子里演完了，就不会再有写出来的兴趣。**这条与涌现流"不做全量预设"立论一致。**

**基础矛盾细化**（该帖评论原文已取）：矛盾必须双方面，含对同一件事的【动力】和【阻力】；主角/CP人设设【引力】与【斥力】，性格设截然相反元素碰撞出戏剧性，制造贯穿全文的信息差。

## 四、30个扎心创作难题（头条"网文历史趣谈局"·原文已全文抓取）

**新手最简骨架**：大纲只回答4问——谁（主角）、在哪（世界观）、干什么（主线任务）、怎么干（关键节点）。500字就能启动开书。大纲不是一次性写完，是边写边改。

**粗纲三板块**（每块200字）：①主角身份、世界背景，冲突如何爆发 ②主角应对危机，遇见盟友敌人，经历失败与成长 ③最终决战，冲突落幕，主角完成蜕变。

**粗纲转细纲·三明治拆解法**：一句话节点逐层扩充，50-100字一层，一个剧情点拆完300-500字细纲。

**开书3条件**：①清楚开头、关键转折、结局走向 ②完整主角成长线（开局状态-经历磨难-最终蜕变）③前10章细纲全部落地。模板：30字以内一句话概括全书 + 100字简短主线描述 + 500字列出10个核心关键场景。

**章节大纲避免流水账**：删掉大纲里所有"然后"，换成"但是/因此"——但是制造反转，因此强化因果。每一段必须绑定冲突：外部冲突/内心纠结/人物立场对立，三选一。

**大纲漏洞检查**：站在反派视角通读一遍——反派每一步行动是否符合利益？有没有更好的解决手段为什么不用？不要剧情崩了后硬补设定。

**每3000字一次意料之外**：不一定是惊天大反转——人物做出反常选择、秘密浮出水面、绝境出现第三条出路。拒绝强行误会，角色的选择必须有迫不得已的理由。

**续写备忘录**：每章写完花两分钟写续写备忘录，记录关键剧情、人物状态，续写直接翻看，避免前后矛盾。

**其他**：人设用行为准则代替形容词（"杀伐果断"→威胁自身安全绝不手软/善待恩人无辜之人）；同一情绪准备多套动作轮换（"紧张就咬唇，生气就握拳"是反例）；写到哪里设定铺到哪里（力量体系先定死，历史地图用到再补）；线索不同时铺开超过3条；打胜仗后给1-2章胜利余味再抛新危机（紧张放松交替）。

## 五、星月写作（AI写作工具·功能全解析原文已抓取）

- **大纲→细纲→章节**：三层级树状图实时拖拽，AI自动补全空白节点。
- **黄金开篇**：基于"起-承-转-合-钩子"模板生成高留存开头。
- **AI拆书**：输入书名10秒输出"三幕七节点"情节拆解+爆款公式。
- **灵感骰子**：随机组合「人物-冲突-场景-金手指」四维骰子。
- **续写补全**：支持"情绪走向"滑杆调节。
- **场景模板**：小说类有爽点节奏表、打斗分镜表、CP发糖清单。
- **长文本一致性**：记忆池+情节回溯双机制，实测50万字后角色年龄/口头禅一致性≥92%。

## 六、对涌现流轻量章纲的映射（可执行）

| 章纲流干货 | 涌现流轻量章纲改造落点 |
|:--|:--|
| 情绪曲线三坐标（首/峰/末各1-10） | 章纲模板加"情绪坐标"字段：章首值+峰值+章末值，配心跳库查级 |
| 三种钩子分布公式（2信息+1情绪+1行动，分布章首章中章末） | 章纲"章末钩"字段扩展为"钩子分布"：分章首/章中/章末标钩子类型 |
| 节奏四段字数比（15/35/35/15） | 章纲加"节奏节点"字段：四段字数分配跟情绪曲线走 |
| 回落段带悬念不总结 | review 判别加"章末是否带悬念往前走"（已有钩子承接项，可对齐） |
| 超前规划1-2章（码字酱） | 与"一次排1-3章"一致，写入模板说明 |
| 删"然后"换"但是/因此"，每段绑冲突三选一 | 章纲事件节点写作规则加"节点须含但是/因此"检查 |
| 三明治拆解法（一句话节点50-100字一层） | 章纲事件节点展开法（轻量章纲每节点事件→转折→落点可对齐） |
| 续写备忘录（每章两分钟） | 与涌现账本"当前态"职责一致，不重复建 |
| 事件设计模式（导火索→状态X→Y→行动反馈→结论→状态Z） | 与 review 章日志"定了哪些事/动了哪些线"可对齐 |
