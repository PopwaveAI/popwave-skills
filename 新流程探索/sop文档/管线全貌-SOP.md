# 管线全貌-SOP（全书的产出节奏总览）

> 用途：把整条小说生产管线从创意到写章画成一张图，说明每份产出落在哪个阶段、为什么是那个时机。
> 位置：`新流程探索/sop文档/` 一级目录，与立项创意-SOP、小说设定-SOP、剧情产出-SOP 平级。
> 消费对象：写作 agent。agent 没有作者的记性，所以必须一眼看清"我这步走到了哪、下一步该产出什么"，不能靠临场想。
> 定位：沉淀稿，先有真实案子验证，改到实测过才算数。灯塔流语义：开篇（读者验证）前移到锁根之后、卷级排期之前；卷级排期改滚动两卷，不一次排完全书。

***

## 1. 一图看懂（从创意到写章）

整条管线从一句故事脉络走到正文，一共四个阶段。每个阶段写清"产出 tag 的那几样""特征"。越往上的阶段，产出越不可逆。

```
创意（故事脉络：主角是谁→世界失衡→欲望串→谁挡着→结局 + 篇幅量级）
  │  立项只锁灯塔四样：主角立身三件 / 世界内核双层失衡 / 结局方向 / 篇幅量级
  ▼
核心设定设计阶段（写主线剧情之前）────────
  │  产出 tag=锁根 的那些：力量的根、主角力量的根、世界基调的根、主角本命
  │  特征：主路径必踩、牵一发动全身、几乎不可逆
  ▼
开篇（黄金三章，读者验证前置）─────────
  │  产出：前三章三章递进情绪曲线 + 落差/特权信息/还账立标方案 + 前300字
  │  特征：网文命根子先验证——"这本书能不能留人"，开篇定调后再排卷方向
  ▼
主线剧情设计阶段（骨架+滚动：先立主线，再排方向，滚动两卷）──
  │  产出 tag=骨架 的那些：宏观地理格局、顶层势力、世界历史段落、主要反派、主线脉络
  │  卷级结构 = 主线脉络（世界终点×主角欲望线耦合：同芯拧双脊柱／并行两线独立）＋方向总表（每卷一句话）＋滚动两卷卷纲（当前卷+下一卷）
  │  特征：决定全书形状的只有"根"与"方向总表"，卷级硬约束滚动细化时执行；先立主线脉络再排方向，排卷是滚动不是一次到底
  ▼
逐卷展开期（滚动：排当前卷→写卷纲→写章纲→写章）───
  │  产出 tag=展开 的那些：这一卷遇到的势力分支、体系方向、当卷角色
  │  卷纲 = 把当前卷单元循环落地到章节弧段与章纲（每章标题+核心剧情点+爽点标签+参数递增标注）
  │  特征：剧情走到哪卷，就产出这份设定的那一卷版；写完一卷回看账本＋方向总表，再滚下一卷
  ▼
写章期（临场）────────────────
  │  产出 tag=写章 的那些：地名细节、路人、风土人情、低层规则
  │  特征：写到那一章才需要，临场造即可
```

## 2. 四条要点

1. **越靠上越不可逆**：核心设定设计阶段定的东西，后期改动＝重写一堆；写章期造的，随时可改。

2. **每份产出只有一个合适的时机**：不该在写章期才定"成长体系"，也不该在核心设定设计阶段就造"某条街叫什么"。

3. **判断一份产出落在哪，只问一个问题**：它是主路径必踩、牵一发动全身，还是用到才够？

4. **灯塔流剧情产出的顺序是硬约束**：先立主线脉络（世界终点×主角欲望线耦合：同芯拧双脊柱，并行两线独立）→ 开篇定调后产方向总表（每卷一句话：质变点＋卷末对手＋爽点标签）→ 滚动两卷（当前卷＋下一卷）：每卷填三同进（质变/地图/矛盾）、拆单元循环（5-7 个剧情单元，日常/推进/结算三类，参数递增）、写当前卷卷纲 → 写完一卷回看账本＋方向总表再滚下一卷。反着来＝编戏代替排期，卷会漏；一次排完全书单元表＝认知最浅时做最重的决策。

**这三样是配套的：总账告诉你"有哪些设定、每份何时产（tag）"，管线图告诉你"为什么是这个时机"，[剧情产出-SOP](剧情产出-SOP.md)告诉你"主线/方向总表/滚动卷纲/章纲具体怎么产"。** 真正动手产某一份时，去对应的文档，按产出SOP产、按质量要求验收、先满足先决条件。
