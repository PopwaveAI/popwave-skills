# 全书大纲生成方法论 v1.3

> 用途：把一句模糊想法，变成一份"讲得清剧情本身"的全书大纲
> 依据：三次实测（DND混合赛道 / 无限流 / 守序邪恶家族修仙）＋欲望线调研
> 本版改动：①六层固定排法作废，改"说法清单法"；②新增三线分工（欲望线/世界线/弧光），欲望线带类型库与组合接力规律；③弧光正名为"网文默认平坦弧光"。v1.2 留档不删。

***

## 0. 用词规矩（本文件自己先守）

这份文件以后会被写作 agent 当范文读：文件里用什么词，大纲里就会冒出什么词，还会顺着漏进正文。上一版里的"引擎、库存、耦合、register"，人看不懂，agent 学去还会写出"契约、回执、资产负债表"这种串味的东西。

**规矩：本文件只许用两类词——网文行话（主线、明线暗线、伏笔、换地图、金手指、单元剧、马甲流、撞梗、烂尾……）和日常中文。不造工程词，不写英文。**

## 1. 底层认识（四条）

### 1.1 故事结构分三层，别混

| 层     | 管什么         | 例子              | 用在哪 |
| ----- | ----------- | --------------- | --- |
| 一卷的形状 | 一卷里故事怎么走    | 英雄之旅十二段、三幕、起承转合 | 每一卷 |
| 全书的骨架 | 几十个小故事从哪不断来 | 下面 1.2 的"两条腿"   | 整本书 |
| 种子    | 这台机器最初的样子   | 主角要什么＋世界怎么了     | 立项  |

英雄之旅那类套路写的是"一个故事"的形状，它默认故事有结尾。长篇连载要把一个大故事拆成几十个各自完整、各自好看的小故事——所以它当不了全书骨架，只能管一卷。雪花法管"怎么把一卷展开成章节"，也不管种子。

### 1.2 长篇靠两条腿走路：日常线和伏笔线

| <br /> | 日常线（管饭）              | 伏笔线（管高潮）                 |
| ------ | -------------------- | ------------------------ |
| 内容     | 现写现卖：新地图、新案子、新生意、新对手 | 提前埋好、到时候引爆：信息差、身世、世界真相   |
| 可再生？   | **可**（换皮无限写）         | **不可**（用一次少一次；埋多少决定书走多远） |
| 只有它会怎样 | 三卷之后读者腻              | 中途弹尽粮绝，日常稀汤寡水            |

成熟流派就是这两条腿的各种装法：

- 日常腿：升级换图流、单元副本流（无限流/破案流）、经营种田流

- 伏笔腿：马甲流（读者知道、书里人不知道，揭穿即高潮）、解谜流（世界真相一层层揭开，诡秘那样）

两条腿能装在不同大小的东西上：主角个人、家族、宗门、国家都行——家族修仙文就是把整套东西装在家族身上。

两条腿的四种接法：

- **接力**：前期一条、中期换另一条（前期升级打怪立威，后期转解谜收网）

- **一明一暗**：明线日常跑节奏，暗线伏笔攒大高潮，全程并行

- **挂钩**：伏笔的进度挂进日常——每破一个案子，马甲暴露的风险就多一分；案子结了，伏笔也攒满了

- **喂料**：每揭开一层真相，顺手解锁一块新地图。世界的秘密越大，能换的地图越大——这是长篇越写越大的原理

### 1.3 全书大线是三线分工（本版核心）

| 线                    | 形状                   | 职责                 | 铁律                                           |
| -------------------- | -------------------- | ------------------ | -------------------------------------------- |
| **欲望线**（主角要什么）       | 线性笔直；可多条、可组合、可接力     | 追读的合同，稳定兑现         | **不扭**。世界线翻面可以改变欲望的意义（他要的"家"是假的），不改变方向（他接着要） |
| **世界线**（世界怎么了→落什么结局） | 全书**唯一**承载反转/扭曲/遮盖的线 | 大反转的载体，终点线         | 反转全放这条线，不动主角的合同                              |
| **弧光**（人物内在变化）       | 跟欲望线不同层面，互不冲突        | "想要的"与"真正需要的"之间的关系 | 网文默认**平坦弧光**：主角信念不动摇，变的是世界对他的回应              |

为什么欲望线不能扭：读者点开书，就是跟主角签了约——"我要看你变强/回家/复仇"。合同要稳定兑现。中途换欲望＝撕约，读者流失。所以欲望线只许**接力**（小欲望满足接大欲望：活下去→变强→长生，凡人修仙三段链）和**组合**（复仇＋变强＋回家三件套），不许反转。

为什么反转全给世界线：大反转的爽来自"原来如此"，不来自"主角变卦"。世界线翻面时，主角接着要他想要的东西——但那东西的意义变了。这是既保合同又给反转的唯一解。

弧光为什么默认平坦：升级流主角是教科书级的平坦弧光（信念贯通，世界改变）。数据显示消极弧光签约失败率高出均值近三成——读者买的就是主角那份稳定。高级写法是**欲望对象置换**（他要的东西没变，他对它的理解变了；或者结尾处一次性的"原来我要错了"），全书至多一次，放在结尾附近。

### 1.4 大线两线的四种关系（欲望线×世界线终点）

| 关系    | 样子                     | 效果                      |
| ----- | ---------------------- | ----------------------- |
| 同路    | 主角得偿所愿＝世界得救            | 顺，但轻；常规爽文               |
| 相撞    | 主角想要的和世界需要的结局不能兼得      | 悲剧势能；终局没有干净选项           |
| 变了样   | 主角一路要A，最后发现A是B，以B的形态拿到 | 回甘最重；"我要错了"和"世界是什么"同时揭开 |
| 主角是钥匙 | 主角欲望达成的那一下，恰好就是世界结局的开关 | 爽感强、结构紧，但最容易用滥          |

四种里"变了样"回甘最重——它同时动了欲望线和世界线，是三线分工下唯一合法的"欲望线大转折"。

## 2. 八步流程

### Step 1 听懂想法

从模糊想法里认出：赛道、元素、主角雏形、读者点开这本书图什么。不急着搭结构。
产出：一句话诉求＋元素清单。

### Step 2 定欲望线

从类型库给主角挑想要的东西（可组合、可接力）：

**欲望类型库**：求生/吃饱、变强、长生、回家、复仇、复活某人、找真相、挣钱兴家、守护、身份恢复

- 组合例：回家＋复仇＋变强（穿越流三件套）；长生＋保命（寿元倒计时）

- 接力例：活下去→变强→长生（凡人修仙式三段链）

- 挑的标准：①读者一看就懂、不用解释；②能推出无限日常（变强→永远有更强的；挣钱→永远有更大的家业）；③和这本书的世界咬得住

同时定**世界的结局**（终点线）和**两线关系**（1.4 四选一）。
产出：欲望线（可多条）＋世界结局一句话＋关系一项。
自检（防套路）：大线要是能读成"主角应对一个不断加深的危机"，重定——危机是卷内的事，不是全书的事。

### Step 3 定谜底

- 先选谜底的类型（见 3.1 六种，优先挑这个赛道没写烂的）

- 再写谜底一句话：最里面那层真相。这句话最好同时回答"世界怎么了"和"主角是谁"——一条根

自检（防撞梗）：谜底要是能读成"有个东西在养/收割我们"，换；赛道头部作品都用过这个谜底，换。

### Step 4 列说法清单（六层固定排法已废弃）

**列出这本书的世界呈现给主角的所有说法**——读者和主角开头信以为真的东西：

魔物是什么、这规矩是谁定的、正邪为什么打、掌权的是谁、主角的来历、家是什么、飞升是什么……通常 4-8 条，跟这本书的世界走，不跟固定格子走。

对每条说法写两行：

- **结构行**：写给作者自己看的备忘，随便怎么记

- **世界行**：用赛道自己的词写的"表面说法"和"真相"，**只有这行能进大纲**

排揭的顺序：**先揭具体的（眼前的事），后揭根本的（"我是谁""世界是什么"压最后两卷）**——根本性真相是底牌，早揭就没牌可打。

用词三条（防串味）：

1. 先用赛道现成的词（末法、道统、祠堂、香火）
2. 不够就用赛道语素造新词（承泽、除籍、道印）
3. 禁止跨行借词（回执、信托、资产表、归档）——任何赛道都一样

判据：把大纲里所有名词拎出来逐个问"赛道头部作品里出现过吗？是赛道语素造的吗？"有一个不是就重造。
为什么：揭开真相时最重的词，是读者背了二十年的旧词（重定义"飞升""末法"），不是教读者一套新词。

### Step 5 配机器

- 伏笔腿：说法清单（书的名分，管卷末大高潮）

- 日常腿：升级换图／单元副本／经营种田三选一（管饭，顺便推欲望线）

- 接法：一明一暗打底，挂钩让伏笔进度每圈可见，喂料让揭说法解锁新地图

- 装在谁身上：个人／家族／宗门

自检（防断粮）：这套日常线写到四百章还有饭吗？

### Step 6 排卷

- 全书分 3-4 段（换挡点）

- 每卷＝一个完整小故事（英雄之旅在这一层合法），卷内自己有危机、有解决

- 排"哪卷揭哪条说法"：两次大揭间隔别超过三卷；场面越揭越大，事情越揭越跟主角自己有关。排期别总用同一个节奏（连着几本都是"卷3揭俩、卷6揭俩"就要换）

- 列跨卷伏笔总表：哪条线哪卷埋、哪卷收

自检（防烂尾）：最后一条说法揭开之后，这本书还剩什么？要么还有更深一层，要么明确收尾并留续作口子。

### Step 7 讲一遍

把整本书当故事讲给朋友听——"他本来是什么人，出了什么事，离开了家，遇上谁，干掉谁，得到什么，又遇上谁……"按排卷逐段讲，每卷一段；到揭开说法的卷，把那一条写成大转折。

要点：

- 讲的是明线（主角要东西的路），说法只在卷末转折处浮出来

- 每卷要有变化：对手更大、舞台更大、代价更大——不然就是原地打转

- 讲完每段自查一遍用词（Step 4 的三条）

产出：全书白描，每卷一段，每段可直接交给卷纲。

### Step 8 五问自检

1. **防套路**：大线是"想要/建造"驱动，不是危机串？
2. **防撞梗**：谜底不是"养我们"？赛道没写烂？跟前几本没撞？
3. **防串味**：全文名词都是赛道的话？
4. **防断粮**：四百章还有饭？
5. **防烂尾**：最后一条揭完还剩什么？

外加一问：第一卷埋的三个"不对劲"（金手指的怪、主角的怪癖、第一场事件），到后边都收回来了吗？——金手指常常就是谜底露在外面的那一角（主角"听得懂怪物"其实是母语）。

## 3. 手艺模块

### 3.1 谜底的六种类型

| 类型  | 那句话问什么    | 真相的形状                      | 跟谁斗         | 代表      |
| --- | --------- | -------------------------- | ----------- | ------- |
| 被圈养 | 谁在养我们     | 有人拿我们当牲口/庄稼                | 活着的圈养者      | 天道流（写烂） |
| 遗产  | 主人去哪了     | 主人已死，世界是没人认领的家业，天道是自动执行的遗嘱 | 一份死人的合法意志   | 诡秘      |
| 铁律  | 这条规矩为什么存在 | 没有坏人，只有一条法则                | 法则本身＋利用法则的人 | 黑暗森林    |
| 残局  | 世界为什么还没完  | 终局早打完了，现在是拖着不结算            | 拒绝终局的一方     | 回环流     |
| 废墟  | 乐园怎么塌的    | 没有恶人，只有事故和被抹掉的历史           | 遗忘和谎言本身     | 进击的巨人   |
| 真假  | 我和世界哪个是梦  | 谜底关于"故事"本身                 | 叙事自己        | 缸中之脑    |

**新鲜感账**：读者觉得新的程度＝元素新×谜底新，两项能互相拆借。元素够怪（dnd＋克苏鲁），谜底用熟的也能过；元素是老赛道（纯仙侠），谜底必须自己扛。定谜底前先看看这个赛道的名作用的是哪种，别踩进挖烂的矿。

设计者三个不由自主的毛病（每次都想犯，写的时候警惕）：

1. 一想"世界归谁"就往"有东西在养我们"上跑
2. 一想"揭开要震撼"就造一套新黑话
3. 一想"主角重要"就把主角写成"系统的产物"（样本、钥匙、容器）

### 3.2 揭说法的八条手艺标准

1. **翻面**：每揭开一条，读者要能回头重新理解之前的事。只是多知道点新东西，不算揭开
2. **换对手**：每条真相要重新划一遍敌我——谁跟谁打、为什么打
3. **一条根**：最里面那条，最好既答"世界怎么了"，也答"主角是谁"
4. **提前露影**：每条揭开之前，它早就以"不对劲"的样子被读者见过——能隐约猜到，但被误导猜错方向
5. **有代价**：每揭开一条，主角烧掉一样东西——盟友、身份、信念、亲人。信息到了，疼也要到
6. **不空转**：两次大揭之间，悬念要小步往前走（又多一个不对劲、半个答案），不许原地晾着
7. **省着用**：说法条数和排期见 Step 6；场面越揭越大，事情越揭越跟主角自己有关
8. **逼选择**：最后一条揭开后，主角面对的必须是没有干净答案的选择——是重画善恶，不是放烟花

四个翻车样：

1. 黑手背后还有黑手——只加码不翻面，读者麻了
2. 把揭开当百科讲——设定倾泻
3. 只挖不填——神秘盒病
4. 读者早猜到了却不做误导——提前漏气

补两条手艺：

- **一条根的两种感情**：好主角揭开"我是谁"是惊喜；恶主角揭开"我是谁"是恐怖（原来我这个性格本身就是条款）。结构不换，换感情就行

- **恶主角的"在乎"**：靠两样——本事让人服＋只剩一个软肋。守序恶的收尾不是牺牲自己，是在规矩里赢下规矩本身

### 3.3 欲望线手艺

类型库见 Step 2。三条规律：

- **组合律**：多欲望可并行（复仇＋变强），但全书主打一两个，其余当配菜

- **接力律**：欲望满足或幻灭后接下一个，接的要比之前的大一号；接的过程读者不该觉得主角变卦，该觉得"理当如此"

- **合同律**：欲望线一旦立约必须稳定兑现；要动它只有一次机会——"变了样"式置换，放在结尾附近，动得越晚越值钱

### 3.4 弧光手艺

- 网文默认**平坦弧光**：主角信念不动摇，变的是世界对他的回应（我不是药神式）。这不是偷懒，是跟"欲望线是合同"配套的正确选择

- 想上强度：给配角的弧光（主角不变，身边人变），比动主角安全

- 最高级：欲望对象置换（"原来我要错了"）——全书至多一次，须与世界线的最后揭示同时发生才值回票价

## 4. 三次实测复盘

| 测     | 输入           | 验出什么                                               | 暴露什么                                       | 买到的自检       |
| ----- | ------------ | -------------------------------------------------- | ------------------------------------------ | ----------- |
| DND混合 | dnd＋克苏鲁＋战锤入侵 | 流程跑得通；"在乎的人"和"最高潮"从结构里自己长出来，不用事后补                  | ——                                         | ——          |
| 无限流   | "写个无限流"      | 从零生成可行；金手指从谜底里自己长出来（听得懂怪物＝母语）；欲望线实（回家，而"家"是被扭曲的说法） | 谜底跟DND撞了型；现代词漏进大纲                          | 防撞梗、防串味     |
| 家族修仙  | 守序邪恶＋家族修仙    | 整套东西能装在家族上；主角阵营要跟日常线配套（守序配规矩，混乱拆家）；"我是谁"的恐怖写法      | 谜底三连撞；黑话在古典赛道裸奔；大线写成危机串；欲望线最弱（守序是性格不是想要什么） | 防撞梗、防串味、防套路 |

规律：**每测暴露一个我们自己都没意识到的默认习惯**（谜底总往一处想、词总往新造处跑、大线总往危机上写、两线关系总用"主角是钥匙"、揭层节奏总用同一个）。解法不是打补丁，是把每个"想当然"变成流程里明写的一步，再配一道自检。**流程的职责是把所有要做的选择摆到桌面上，自检的职责是拦住手滑。**

## 5. 已知短板（诚实清单）

1. 三测都是同一个出题人，方法可能只是适配了出题人——**待双子 agent 隔离盲测**
2. 六种谜底只实测了"被圈养"两次、"遗产"一次；铁律/残局/废墟/真假没测
3. 大线四种关系全是理论，没实测；下一测禁用"主角是钥匙"
