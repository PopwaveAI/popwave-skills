# 全书大纲生成方法论 v1.4

> 用途：把一句模糊想法，变成一份讲得清剧情本身的全书大纲。
> 依据：四次实测（DND混合、无限流、守序邪恶家族修仙、灵气复苏×神豪盲测）＋两轮联网调研（欲望类型、神豪流与灵气复苏流）＋镜界创作专家系列的引导协议与行文标准。
> 本版改动：①流程拆两段——先与人分轮确认，再照确认结果组装；②新增查底子步骤，命题元素先查清、出奇项最后加；③伏笔线改为类型菜单，世界谜底只是选项之一；④书写标准对齐 Mirror 系列。v1.3 留档不删。

***

## 0. 书写标准

本文件会被写作 agent 当范文读：文件里用什么词、什么句式、夸什么，下游的大纲和正文里就会冒出什么。历史教训在两个极端之间摇摆：工程黑话（引擎、耦合、库存、register）读者看不懂；口语比喻（管饭、撒在盘边）降格成俏皮话。两者同病：都没把事情本身说清楚。

书写标准取自 Mirror 创作专家系列（`D:\popwave-skills\Mirror创作专家\`），六条：

1. **规则写成行为指令**：写做什么、不做什么，一条一个动作。不写感受和评价。
2. **新概念出现即定义**，用"是A，不是B"排除相邻概念。例：AgentSkill 是全局可复用的工作流程，不是作品规则或故事事实。
3. **判断给锚点**：写"以什么判断"，不写"很重要"。例：完成标准以"改起来贵不贵"判断，不以"第一章用不用得上"判断。
4. **行业词直接用**：网文行话（主线、伏笔、金手指、爽点、打脸、扮猪吃虎、换地图、王道）照用；工程词（引擎、管线、范式、耦合）不用；生活比喻不当概念名。
5. **一段一义，短句为主**。
6. **不用 AI 腔**：不写"值得注意的是""总而言之"，不用空洞的强调与排比。

判据：任何一句话拿给没读过本文档的写手，他能照着执行，不需要追问什么意思。

## 1. 底层认识

### 1.1 结构分三层，各管一段

| 层            | 管什么            | 用在哪 |
| ------------ | -------------- | --- |
| 英雄之旅、三幕、起承转合 | 一卷之内故事怎么走      | 每一卷 |
| 日常线与伏笔线      | 几十个各自完整的小故事从哪来 | 全书  |
| 欲望、谜底、出奇项    | 这本书最初的样子       | 立项  |

英雄之旅描述"一个故事"的形状，默认有终点。长篇连载要把一个大故事拆成几十个各自完整的小故事，所以它当不了全书骨架，只能管一卷。

### 1.2 日常线与主剧情线

- **日常线**：产出即时的剧情单元——新地图、新案子、新生意、新对手。换皮可无限重复，负责连载的持续供给。

- **伏笔线**：产出大转折——身份揭穿、身世、世界真相。用一次少一次，必须预先埋设；埋多少决定书走多远。

- 接法四种：**接力**（前期一条、后期换一条）；**一明一暗**（并行）；**挂钩**（伏笔进度挂进日常单元，每单元推一点）；**喂料**（揭一层伏笔，解锁一块新地图）。

- 装在哪一级都行：主角个人、家族、宗门、商号。

### 1.3 三线分工

| 线   | 内容          | 规则               |
| --- | ----------- | ---------------- |
| 欲望线 | 主角要什么       | 线性推进。可组合、可接力，不反转 |
| 世界线 | 世界怎么了、落什么结局 | 全书所有反转、遮盖只放这条线   |
| 弧光  | 主角内在变化      | 与欲望线不同层，互不替代     |

- 欲望线是读者与主角的约定：点开书即立约，中途换欲望等于毁约。世界线翻面可以改变欲望的意义（他要的"家"是假的），不改变方向（他接着要）。

- 弧光：网文默认**平坦弧光**——主角信念不动摇，变的是世界对他的回应。这不是保守，是与"欲望线不反转"配套的正确选择。要写"原来我要错了"，全书至多一次，放在结尾附近，与世界线最后一层同时揭开。

### 1.4 欲望线与世界线的四种关系

| 关系    | 形态                   |
| ----- | -------------------- |
| 同路    | 主角得偿所愿＝世界得救          |
| 相撞    | 主角想要的与世界需要的不能兼得      |
| 变了样   | 一路要A，最后发现A是B，以B的形态拿到 |
| 主角是钥匙 | 主角欲望达成的那一下，就是世界结局的开关 |

四种并列，不排序、不评高下。轮换纪律：同一出题人近三个案子用过哪种，列表对照，撞了必须换。已知偏差：三次实测全部默认"主角是钥匙"，盲测A默认"变了样"——这两种都用过了，后续优先实测"同路"与"相撞"。

### 1.5 伏笔线类型菜单

伏笔线选哪种由书的流派决定，不由作者偏好决定：

| 类型     | 内容                | 常见流派        |
| ------ | ----------------- | ----------- |
| 身份差    | 读者知道、书里人不知道；揭穿即高潮 | 神豪、战神回归、马甲文 |
| 世界谜底   | 世界真相分层揭开          | 灵气复苏、玄幻、克苏鲁 |
| 系统来源   | 金手指从哪来、谁给的、要什么代价  | 一切系统文       |
| 复仇对象升级 | 仇人背后还有仇人，对手逐层抬高   | 都市、复仇文      |

只有选"世界谜底"才用说法清单法（Step 6）。谜底材料必须从赛道自有的东西里长（神豪文的钱、返利、账目），不从个人趣味库搬。

## 2. 十步流程

流程分两段。**第一段（Step 0-3）对人：分轮确认，产出故事承诺与边界。第二段（Step 4-9）对文档：照确认结果组装。第一段没走完，第二段不许开始。**

### Step 0 先读再问

提问与查证之前，先收集已有信息：

1. 命题全文，逐字。
2. 用户的历次裁决与偏好记录：同类问题他怎么判过。
3. 已有资产：赛道包、拆书报告、wiki 条目、旧大纲。

已确认的不重问，已有的不重查。产出待办清单：缺哪几张底子卡、哪些要问用户、哪些已有资产直接可用。

### Step 1 查底子

命题里每个元素出一张底子卡：

1. **定义与定位**：这个流派是什么。用番茄标签库（`D:\popwave-skills\Mirror创作专家\01-立项专家.md` 附录六）锚定它在市场分类里的位置——标签库就是市场自己的词汇，"神豪""灵气复苏"都是现成标签。
2. **开山作与代表作**：三到五本。
3. **读者图什么**：爽点清单，逐项可执行（神豪：压抑后爆发的打脸、扮猪吃虎、消费奇观、平推碾压）。
4. **标配零件**：这个流的世界配置（灵气复苏＝末法结束、觉醒者阶层、官方特殊机构、隐世势力博弈）。
5. **王道走法**：主流验证过的主线（《全球高武》财富=实力；《大王饶命》负面情绪值驱动升级）。
6. **写烂清单**：这个流被用滥的点（灵气复苏的"复苏是布局、凡人是资粮"；神豪的纯炫耀无代价）。
7. **组合先例**：元素组合有没有人写过，写成了什么。

数据源顺序：已有赛道包 > wiki 站 > 联网调研。查不出来的元素，如实告知"没查到"，不用脑补顶替。底子卡没齐，不进 Step 2。

### Step 2 根决策分轮拍板

分轮与用户确认。一轮两三个问题，每问给选项并标注推荐项；推荐只是降低回答成本，用户没选不算数，不写入。

- **轮一·什么流的书**：用底子卡给候选，确认一句话："这是本XX流的书，向读者承诺XX、XX、XX。"

- **轮二·篇幅与分卷**：量级（短篇/连载/长篇/目标章数）、分几卷、每卷大致范围。卷数由用户定，AI 只建议切法。

- **轮三·结构根**：欲望线（类型库选，可组合、可接力）＋两线关系（四选一）＋伏笔线类型（菜单选）＋谜底类型（选了世界谜底才定，六型见 3.1）。

轮换查重在轮三执行：列出同一出题人近三个案子的关系、谜底、排期节奏，撞了换。

### Step 3 锁边界

只锁全书稳定、后期改起来贵的决策，与题材无关的维度跳过：

- 世界与空间结构

- 能力/资源体系与硬上限、代价

- 势力与关系格局

- 信息边界：谁知道什么，真相如何逐步揭示

- 现实、行业、史实约束

世界细节不在此展开——那是舞台设定环节的事，立项只锁方向。完成标准以"改起来贵不贵"判断：贵的决策全部确认即算完成，章级细节留白。

### Step 4 立王道骨架

日常线直接用赛道验证过的循环（神豪＝花钱→返利→升级消费清单；灵气复苏＝觉醒→修炼→势力博弈）。产出两表：

- **爽点兑现表**：故事承诺里的每个爽点，首次兑现排在哪卷、之后什么频率（打脸每卷必有；消费奇观每两三卷一场）。

- **换图阶梯**：从赛道自有的阶梯来（老街→城→国→天下；或新手村→宗门→大陆）。

### Step 5 加出奇项

出奇项最后加，只加一个大的。两道测试：

- **去掉测试**：把出奇项拿掉，王道骨架是否仍然成立？不成立，说明它已经换了菜，打回。

- **驱动测试**：出奇项是否直接驱动王道循环（《大王饶命》的负面情绪值直接驱动升级循环）？只好看、不驱动的，砍。

### Step 6 挂伏笔线

按 Step 2 轮三定的类型挂。选了世界谜底的，列**说法清单**：世界呈现给主角的每条说法写两行——表面说法一行、真相一行——标注哪卷揭开。规则：

- 条数四到八条，跟这本书的世界走，不跟固定格子走。

- 揭的顺序从具体到根本；"我是谁""世界是什么"压最后两卷。

- 每条材料从赛道土里长。

- 用词三级：赛道现成词（末法、道统、祠堂）＞ 赛道语素造新词（承泽、除籍）＞ 禁止跨行借词（回执、信托、归档）。判据：大纲里的名词逐个问"赛道头部作品里出现过吗？是赛道语素造的吗？"有一个不是就重造。

### Step 7 排卷

- 全书分三到四段，段与段之间换挡。

- 每卷一个完整小故事，卷内自带危机与解决。

- 排揭说法的卷次：两次大揭间隔不超过三卷；场面越揭越大，事情越揭越与主角相关。

- **伏笔台账**：每条伏笔记四态——开启（埋设方式＋目标卷）、推进（新线索）、回收（回收方式与影响）、搁置（理由＋下次窗口）。健康度每卷一查：悬置超三卷的、超期的、沉睡过久的，要么推进、要么显式搁置，不许晾着。

### Step 8 讲一遍

把整本书讲给朋友听：主角本来是什么人，出了什么事，遇上谁，干了什么，得到什么。每卷一段；揭说法的卷写成大转折，不是流水账。

判据：拿掉标签，听的人能说出"这是本XX流的书"。

### Step 9 六问自检

1. **防套路**：大线是想要/建造驱动，不是危机串？
2. **防撞梗**：谜底没撞赛道写烂的点？没撞自己近三个案子（关系、谜底、排期三查）？
3. **防串味**：全文名词都是赛道的话？
4. **防断粮**：日常线到四百章还有产出？
5. **防烂尾**：最后一条说法揭开之后，这本书还剩什么？
6. **防跑题**：故事承诺里的每个爽点，前三卷排上了吗？频率对吗？

外加一问：第一卷埋的三个不对劲——金手指的怪、主角的怪癖、第一场事件——到后边都收回来了吗？金手指常常是谜底露在外面的一角。

## 3. 手艺模块

### 3.1 谜底六型（只在伏笔线选"世界谜底"时使用）

| 类型  | 问的那句话     | 真相的形状                      | 跟谁斗         | 代表      |
| --- | --------- | -------------------------- | ----------- | ------- |
| 被圈养 | 谁在养我们     | 有人拿我们当牲口或庄稼                | 活着的圈养者      | 天道流（写烂） |
| 遗产  | 主人去哪了     | 主人已死，世界是没人认领的家业，天道是自动执行的遗嘱 | 一份死人的合法意志   | 诡秘      |
| 铁律  | 这条规矩为什么存在 | 没有坏人，只有一条法则                | 法则本身＋利用法则的人 | 黑暗森林    |
| 残局  | 世界为什么还没完  | 终局早打完，现在是拖着不结算             | 拒绝终局的一方     | 回环流     |
| 废墟  | 乐园怎么塌的    | 没有恶人，只有事故和被抹掉的历史           | 遗忘和谎言本身     | 进击的巨人   |
| 真假  | 我和世界哪个是梦  | 谜底关于故事本身                   | 叙事自己        | 缸中之脑    |

新鲜感账：读者觉得新的程度＝元素新×谜底新，两项互相拆借。元素够怪（dnd＋克苏鲁），谜底用熟款能过；元素是老赛道（纯仙侠、纯都市），谜底必须自己扛。定谜底前先查赛道名作用的型，写烂的不碰。

设计者三个常犯的毛病，写的时候自查：

1. 一想"世界归谁"就往"有东西在养我们"上跑。
2. 一想"揭开要震撼"就造一套新词。
3. 一想"主角重要"就把主角写成系统的产物（样本、钥匙、容器）。

### 3.2 揭说法的八条标准

1. **翻面**：每揭开一条，读者要能回头重新理解之前的事。只是多知道一点新东西，不算揭开。
2. **换对手**：每条真相重新划一遍敌我。
3. **一条根**：最里面那条，最好既答"世界怎么了"，也答"主角是谁"。
4. **提前露影**：每条揭开之前，它早已以"不对劲"的样子被读者见过——能隐约猜到，但被误导猜错方向。
5. **有代价**：每揭开一条，主角烧掉一样东西——盟友、身份、信念、亲人。信息到了，疼也要到。
6. **不空转**：两次大揭之间，悬念小步推进（又多一个不对劲、半个答案）。
7. **省着用**：场面越揭越大，事情越揭越与主角相关；排期不与近期案子重复。
8. **逼选择**：最后一条揭开后，主角面对的必须是没有干净答案的选择。

四个翻车样：黑手背后还有黑手（只加码不翻面）；把揭开当百科讲（设定倾泻）；只挖不填（神秘盒病）；读者早猜到却不做误导（提前漏气）。

补两条：

- **一条根的两种感情**：善主角揭"我是谁"是惊喜；恶主角揭"我是谁"是恐怖（原来我这个性格本身就是条款）。结构不换，换感情。

- **恶主角的"在乎"**：靠两样——本事让人服＋只剩一个软肋。守序恶的收尾不是牺牲自己，是在规矩里赢下规矩本身。

### 3.3 欲望线三条律

类型库：求生、变强、长生、回家、复仇、复活某人、找真相、挣钱兴家、守护、身份恢复。

- **组合律**：多欲望可并行（复仇＋变强），全书主打一两个，其余当配菜。

- **接力律**：欲望满足或幻灭后接下一个，接的比之前的大一号；读者不该觉得主角变卦，该觉得理当如此。

- **守约律**：欲望线立约后稳定兑现；要动它只有一次机会——"变了样"式置换，放结尾附近，动得越晚越值钱。

### 3.4 弧光

- 网文默认**平坦弧光**：主角信念不动摇，变的是世界对他的回应。

- 想上强度：给配角的弧光（主角不变，身边人变），比动主角安全。

- 最高级：欲望对象置换（"原来我要错了"）——全书至多一次，与世界线最后揭示同时发生。

## 4. 四次实测复盘

| 测       | 输入           | 验出什么                            | 暴露什么                     | 买到的规矩               |
| ------- | ------------ | ------------------------------- | ------------------------ | ------------------- |
| DND混合   | dnd＋克苏鲁＋战锤入侵 | 流程跑得通；"在乎的人"与"最高潮"从结构里自己长出来     | ——                       | ——                  |
| 无限流     | "写个无限流"      | 从零生成可行；金手指从谜底里长出来（听得懂怪物＝母语）     | 谜底跟DND撞型；现代词漏进大纲         | 防撞梗、防串味             |
