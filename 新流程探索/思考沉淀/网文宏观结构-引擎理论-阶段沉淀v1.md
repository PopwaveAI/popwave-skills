## 一、三层坐标系：先把"结构"这个词拆开

"英雄之旅12阶段"只是结构的第一层。长篇宏观结构有三层，混淆三层是一切讨论混乱的根源：

| 层   | 回答的问题      | 代表理论                                  | 在网文里的位置  |
| --- | ---------- | ------------------------------------- | -------- |
| 形状层 | 一段弧长什么样    | 英雄之旅12阶段、三幕、起承转合、Dan Harmon故事圈、救猫咪15拍 | 一卷/一幕的轮廓 |
| 引擎层 | 弧怎么源源不断产生  | 网文特有：循环引擎理论（本文主体）                     | 全书骨架     |
| 种子层 | 引擎的初始条件是什么 | 原型情节 × 引擎 × 金手指 × 世界阶梯                | 立项那一页纸   |

关键认知：形状层框架描述"一个故事"的形状，且预设故事有终点；而长篇网文的本质问题是**把一个故事拆成几十个能独立卖钱的完整小故事**。所以网文真正的宏观套路不在形状层，在引擎层。

雪花法是形状层的展开术——它不缺，缺的是往里填什么的坐标系。

## 二、引擎理论核心：两类燃料 × N种实例

第一性原理：连载百万字，读者的消费单位是章和卷，不是本。网文宏观结构 = **一台能无限重复生产"小型英雄之旅"的机器**。

引擎只有两类（按燃料性质分）：

| <br /> | 流水线引擎            | 库存引擎            |
| ------ | ---------------- | --------------- |
| 燃料     | 现产现卖：新地图、新案件、新委托 | 预埋库存：信息差、秘密层、马甲 |
| 产能     | 无限，但重复           | 有限，但爆发          |
| 职责     | 管饭（章节级日常追读动力）    | 管高潮（卷级结构性爆点）    |
| 单独跑全书  | 三卷后审美疲劳          | 中途库存耗尽、日常没节奏    |

**铁律：流水线管饭，库存管高潮。** 任何长篇都是一套"流水线＋库存"的配置方案。四大经典引擎按此分类：

- **螺旋引擎**（流水线）：打怪→升级→换地图。地图是同心阶梯（新手村→城→宗门→国→大陆→界→宇宙），每张地图内部跑一个完整英雄之旅。变体：莲花开图（《牧神记》式网状延伸）。隐藏要求：**世界必须预先设计成阶梯**——境界表不是力量设定，是结构设定。

- **单元引擎**（流水线）：外壳流程固定，每单元换内容（案件/副本/委托）。无限流是最彻底形态（系统—副本—任务三层）。神医流、规则怪谈、灵异侦探皆是。

- **马甲引擎**（库存）：装→藏→险被揭→将揭未揭→揭→换马甲。燃料是信息差（读者全知、剧中人不知），每次揭穿＝一次结构性高潮结算。

- **洋葱引擎**（库存）：世界有一个大秘密，一层层剥。每卷揭一层同时埋更深一层。克苏鲁、《诡秘之主》式。

可继续衍生新引擎：情感线（情感债＝库存＋糖点日常＝流水线）、经营线（资产累积＝流水线）。**理论形态是"两类燃料 × N种实例"，四引擎只是最常用的四个实例。**

### 引擎接线：四种耦合方式

1. **串联（换挡）**：引擎随卷接力（前期螺旋立威→中期单元扩张→后期洋葱结算），每次换挡＝全书大换血
2. **并联（外壳/内核）**：一个跑章节节奏，一个跑全书脊柱，全程并行
3. **嵌套（引信）**：库存引擎的进度条嵌进流水线每圈（每个委托自带"暴露风险＋1"）
4. **供油（耦合）**：一个引擎的产出喂另一个（洋葱剥层揭出新地图，喂给螺旋换图）。"世界的秘密越大，能换的地图越大"——长篇越写越大的原理

## 三、全书叙事弧生成公式

**全书叙事弧 ＝ 循环语法 × 参数递增 × 结算事件表**

- **循环语法**：流水线每圈固定的事件链（触发→冲突→小胜→代价→新钩），保证"是同一个故事"

- **参数递增**：每圈什么在变大（敌人量级/舞台/代价），保证"循环但不重复"

- **结算事件表**：库存引擎何时引爆（第几卷揭马甲、第几卷剥第几层），预先排期

三样齐了，跑圈的过程翻成人话就是大纲——**不是填模板，是把机器运转翻译成剧情白描**（"A原本是什么，遭遇了什么，有一天突然什么，走出了家乡，遭遇了谁，干掉了谁，又得了什么"——这段话本身就是螺旋引擎跑一圈的白描）。

长线债务台账（埋的线＋还的线＋触发条件）是结算事件表的雏形；引擎理论补上"每条线属于哪个引擎、库存够不够跑到结尾"的对账能力。

## 四、模糊想法 → 全书叙事弧：生成管线

1. **定型**：模糊想法 → 抽原型（布克七大情节/救猫咪十型）＋定主引擎（书身份）＋副引擎1-2个（节奏和高潮来源）
2. **建库存**：库存引擎预埋什么、埋几层够撑到结尾（库存-排期对账）
3. **定循环语法**：流水线每圈的事件链
4. **排换挡表**：全书3-4个引擎阶段＋结算事件排期
5. **跑圈出弧**：按阶段跑循环，每圈翻成一段叙事白描，结算事件写成大转折段。产出即大纲，且每圈天然＝一卷骨架

自检两问：

- **第400章测试**：机器到那时还能产吗？

- **库存耗尽测试**：最后一层秘密揭开之后，还有没有下一层（或明确转入系列钩）？

种子层公式：**种子 = 原型情节 × 金手指 × 世界阶梯 × 压力源**（四元件相乘，缺一个就废：没原型→三章后没得写；没金手指→没爽点引擎；没阶梯→200万字见底；没压力源→主角躺平）。

可建"引擎×原型×金手指"乘法表，从表里有策略地抽组合（含故意错位组合测张力）作为 seed 5a 的候选生成来源。

## 六、洋葱工艺学：主线剧情怎么写好（本次新增）

### 洋葱层与主线的关系（精确版）

**主线 = 真相结构（洋葱） + 揭示排期（结算事件表）**。洋葱管"读者为什么好奇"，排期管"什么时候喂"。

- BG3至上真神事件＝洋葱本体（蝌蚪异常→神术寄生机制→教团权力网→梦访者真身→主脑本体，每幕剥1-2层且改写前义）

- 深渊主宰圣者浩劫＝排期结算事件（多条洋葱层＋人物线在预定卷汇聚引爆的世界级巨响，不是"一层"本身）

主线有两根脊柱：**世界真相线（洋葱）× 个人命运线（主角线）**。顶级作品两根同芯——世界之谜的终点站必须是"我"，这是读者"在乎"的真正来源（BG3的芯是"蝌蚪会让你成为什么"，诡秘的芯是克莱恩本人）。

### 设计法：由内向外设计，由外向内揭示

1. 先写芯：一句话终极真相，且必须是关于主角的
2. 问："如果这是真的，世界为了正常运转，必须把它误读成什么样？"——每一级误读就是一层
3. 标准六层从外到内：**异常 → 机制 → 阵营 → 权力 → 自我 → 本体**
4. 自检：任取一层，说出它改写了前面哪几层的含义

### 好洋葱八则（可执行判据）

| 律   | 判据                                        |
| --- | ----------------------------------------- |
| 改写律 | 揭开后读者必须重新理解前面发生过的事；只加信息不算剥层               |
| 换阵律 | 每层必须重定义冲突——谁跟谁打、为什么打                      |
| 同芯律 | 最内层＝世界之谜∩主角身世之谜                           |
| 投影律 | 每层揭开前必须早已以"异常"形式被读者看见；可被猜到，但被红鲱鱼引导误读      |
| 代价律 | 每层结算烧掉主角一样东西（盟友/身份/信念/家园）；信息账情感账双结        |
| 可见律 | 两次大结算之间主线不许空转：异常度+1、半揭示，小步可见              |
| 经济律 | 层数≈卷数÷2；尺度向外升级（个人→世界），利害向内升级（越来越关于我），双向加深 |
| 抉择律 | 最后一层逼出没有干净选项的抉择——道德地形重绘，不是奇观展示            |

### 四个反模式

1. **套娃黑手**：幕后黑手后面还有黑手，只加码不改写（退化洋葱）
2. **设定倾泻**：把reveal当百科词条用
3. **神秘盒病**：只埋不还（LOST病）
4. **提前漏气**：结构可猜却没养红鲱鱼保护芯
