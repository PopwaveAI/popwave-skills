# 角色原型采集交接文档（供 wiki「素材原型库/角色原型」丰富）

> **用途**：给 wiki 侧一张"怎么把互联网上现成的人物原型，按可复用的方式收进素材原型库"的可执行交接单。
> **不依赖写的书**：原型直接来自网络（文学/影视/游戏/历史/现实），不是从已写的书里逆向——这样库与任何具体项目解耦，换壳即用。
> **核心难点 = 分类与分赛道**：一股脑收进来会变成"有货找不到"。本档把「一张原型卡长什么样 + 怎么分类 + 怎么分赛道 + 采集动作」定清楚，wiki 侧照此丰富即可。

***

## 一、先定「一张原型卡」长什么样（入库最小单位）

> 只有"能换壳就能用"才算入库，光收集名字不算。每张卡必须回答下面这些。

```
人设原型卡
----------------------------------------------
名称         ：少年天子型（一句话脸谱）
一句话       ：父母双亡、幼年登基、能力撑不起权位的少年君主
赛道归属     ：历史权谋 / 古言女频 / 异世界王国流
功能位       ：主角 / 主角团·引路人 / 情感对象 …（stage 功能位复用）
典型冲突     ：想守的国被架空、想信的臣子在骗他、"做好人"和"坐稳位子"二选一
人格内核     ：渴望认同 × 被迫果断 × 自我怀疑
目标＋代价   ：目标=守住江山守住身边人；代价=孤家寡人、对谁都不能全信
语言指纹     ：自称从"朕"到私底下用"我"的松动；对亲信说人话对朝堂说场面话
成长线       ：……（原型只给方向，具体线由 stage 排）
穿戴变体     ：可换成十六岁少主/流亡王子/架空朝代幼帝（换壳）
来源         ：汉武帝早政、康熙擒鳌拜、《冰与火》乔佛里对照 等
示例成品     ：《XXXX》里 X 就是个"少年天子型"
```

**入库判据（不过则不收）**：①有一句话脸谱；②有赛道归属；③有人格内核（不是好人/坏人标签）；④有独立的"目标＋代价"；⑤可换壳（穿戴变体）。缺任一=半成品，标"待补"或先不收。

***

## 二、怎么分类（第一维度：按"人设骨架/驱动"分，跨赛道通用）

> **分类不按赛道，先按"这个角色靠什么动起来"**——同一骨架可换任何赛道外壳。维度＝骨架类型，这是主分类。

| 骨架类        | 一句话             | 典型原型                   |
| :--------- | :-------------- | :--------------------- |
| **逆袭翻身型**  | 起点低、憋着一口气往上爬    | 退婚流女主、赘婿、三十年河东的落魄少爷    |
| **执念复仇型**  | 被夺走一切，目标就是拿回来   | 灭门遗孤、堕落的守护者、被废的天才归来    |
| **伪善/双面型** | 表里不一，嘴上仁德心里算账   | 笑面虎权臣、吸血的善人、道貌岸然的掌门    |
| **冷血经营者**  | 一切是生意，目标只看投入产出  | 曹操式枭雄、沈万三式商贾、幕后操盘的执棋者  |
| **魅力腐化者**  | 靠魅力诱人堕落，自己越陷越深  | 小指头式佞臣、诱惑型的反派、终成恶龙的屠龙者 |
| **被迫承担型**  | 不想当主角，被责任/时代推着走 | 少年天子、继承烂摊子的二代、被选中的普通人  |
| **理想主义者**  | 为信念不惜代价，常撞世界铁壁  | 殉道的改革者、不撞南墙不回头的小卒      |
| **工具人觉醒**  | 从"没自我"到"我是谁"    | 兵器成人、被豢养的棋子、自我意识苏醒的杂役  |

> 采到新原型先归到这 8 类之一（或开新类并说明），卡才进得了库。

***

## 三、怎么分赛道（第二维度：一个原型能挂多个赛道标签）

> 分类定"是什么人"，赛道定"在什么世界里可用"。**一张卡可多赛道**。

**采集时打赛道标签**（复用 wiki 现有 18 赛道体系，可补新赛道）：

- 都市 / 仙侠 / 西幻 / 历史权谋 / 科幻 / 无限流 / 悬疑 / 古言女频 / 现言 / 系统流 / 神豪 / 种田基建 / 游戏竞技 / 克苏鲁 / 国风玄幻 / 末世 / 战争史诗 / 日常回 / 其他

**每个原型打 1\~3 个赛道标签 + 选主赛道**。例：「退婚流女主型」主赛道=古言女频，可挂现言/都市。

## 四、采集动作（去哪找 + 怎么抽成人格内核）

| 来源      | 找什么          | 抽法                            |
| :------ | :----------- | :---------------------------- |
| 经典文学/名著 | 小人物/枭雄的完整弧线  | 拆出人格内核＋目标代价，脱专名               |
| 经典影视/剧集 | 高国民度角色的"记忆点" | 记"观众记住他是因为什么"，那正是人脸谱          |
| 游戏/动漫   | 有辨识度的职业化身    | 抽"角色型"（沉稳队长/热血白痴/冷面智者），换世界观外壳 |
| 历史真实人物  | 有起落、有争议的强人   | 拿欲望/手段/局限来做，别照抄生平             |
| 现实职业观察  | 某种职业的典型人性    | 记这一行"什么人被逼成什么样"               |
| 已有同类角色库 | 别家的整理，补漏不照搬  | 看类别覆盖、找盲区                     |

**每次采集产出**：至少 5 张完整卡（够一次入库）或 1 类骨架的全赛道变体至少 3 张；每张走「入库判据」。

## 五、给 wiki 侧的上架建议（一份结构示意）

```
素材原型库/人设原型/
├── README.md            ← 本交接文档精简版（怎么入库）
├── 01-逆袭翻身型/
│   ├── 退婚流女主型.md
│   ├── 赘婿逆袭型.md
│   └── …
├── 02-执念复仇型/ …（每类一个文件夹）
└── _索引.md             ← 全部原型一张表：名称/一句话/主赛道/所有赛道/状态
```

- **分类：按 8 骨架分文件夹**（第二维度赛道用标签，不建赛道文件夹，避免一张卡散多处）。

- **建库节奏**：先每个骨架类放满 2\~3 张质量最高的"样卡"撑起架子，再逐类扩；空着类不放目录，避免"看着有其实没货"。

- **状态标记**：`✅完备可用 / 🕐待补目标代价 / 🔨缺赛道变体`，wiki 侧照状态补。

## 六、和 stage 的衔接（拿出去就能用）

stage 建角色时按本库取原型：

1. 按主角/主角团/反派的「功能位 + 骨架」查对应分类；
2. 取到 → 消化人格内核 → **配本书的"目标＋代价"** → 换壳入卡（复用并回填楼主卡来源）；
3. 查无 → 标"人物复用域未命中，自造待标"，可回 wiki 旁路收集此类补充。

> 本交接文档不局限当前书，是**给 wiki 人设原型库持续丰富**的可执行起点。wiki 侧照此把网上现成原型收进库，stage 侧就能可靠地"刮到、消化、换壳"，达成"主要角色都有原型"。
