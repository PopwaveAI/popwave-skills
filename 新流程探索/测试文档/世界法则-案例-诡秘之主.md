## 0. 一句话

**诡秘之主的世界"强"构成 = 武力侧（非凡力量）为主 + 非武力侧（序列地位/占卜社交）为辅，所有非凡力量共用一条守恒基石——非凡特性。**

---

## 1. 三层结构

```
                          世界法则（诡秘之主）
             ┌──────────────┴──────────────┐
         武力侧（主打）                 非武力侧（次之）
             │                              │
       基石：非凡特性                   基石：序列地位 / 神秘学话语权
   （22途径×9序列，总量守恒）         （高层序列自带社会位阶与影响力）
             │                              │
        战斗系统                      社会对抗系统
    序列能力对抗（魔药+咒术+占卜）    密教博弈/组织卧底/谈赎金/耍僵化秩序
             │                              │
        配套养成线                     配套养成线
    序列9→0，每级×破坏力×地位        晋升序列（社会地位梯度）
```

**侧重**：武力侧（非凡战斗）为主，非武力侧重在——但诡秘的基石骨子是"神秘守恒"这种跟世界观机理深深咬合的设定，这正是它被称"世界谜底流鼻祖"的原因。

---

## 2. 基石：非凡特性（总能源）

| 问什么 | 诡秘之主 |
| --- | --- |
| 总能源是什么 | 非凡特性（魔药析出/非凡者吸收，从低序列到高序列一路继承） |
| 是否稀缺/守恒 | **是，总量一定**。22途径×每条序列0-9格，一格特性只在世界上存在一份，升序列会消耗原始特性、迫使继承 |
| 呼应哪条世界机理 | **序列越靠前越稀少、越掩盖不住**——越强的人越瞒不了自己的位格，这正是"世界之谜"（非凡者的存在本身即成谜）和"成神需踏着他人"的根 |

**量级特点**：基石的守恒性极强——不是"练习变强"，是"一份特性只能被一人独有"，所以力量争夺、继承、牺牲他人是全部故事的引擎。

## 3. 对抗系统

**武力侧战斗系统（主打，四样齐全）：**

| 维度 | 诡秘战斗系统 |
| --- | --- |
| 对抗手段 | 序列能力（术法/诅咒/占卜）+ 咒术/仪式魔法/卷轴 + 契合自身途径的专长 |
| 制约 | 使用力量会**感染呓语/污染心智**、灵性被消耗、过度会失控成怪物 |
| 信息差 | 情报战极重：知道对手序列能力=能针对反制（对应秘客、占卜对抗） |
| 配套等级 | 序列等级绑定社会地位与秘境准入，高的序列者天然是权威 |

**非武力侧社会对抗系统（次之但共有）：**
- 商战/权斗/谈判（密教首领、罗塞尔日记、背经机式组织、赎金谈判、占卜摆位）。

## 4. 配套养成线：序列 9→0

### 4.1 等级三位一体（节选 4-5 级代表）

**这一条是诡秘最精彩的"等级锁"：序列不靠苦练，靠"吃魔药+消化"，所以每级自带全世界稀缺度与规则。**

| 序列 | 破坏力（读者脑补） | 社会地位 | 数量/稀缺 |
| --- | --- | --- | --- |
| 序列9 | 能压制常人、轻度咒术 | 底层非凡者的门槛 | 相对常见（苟活的风险大） |
| 序列5 | 一人可破一小队打手 | 具备一定存在感 | 中等，需消化+有配剂 |
| 序列3 | 一人破一大城/有神秘权能 | 大教会主教/镇国级的地位 | 稀少 |
| 序列0 | 近乎神明/改写一部分规则 | 成为序列顶端存在 | 一条途径至多一位 |

**关键**：诡秘的等级不只是"战力"，而是"**资源分配+心智博弈**"的等级——升序列=吞特性+消化+防被夺，天然接上「成长=争夺」的主线。完全符合"每级连带破坏力+地位+稀缺"。

### 4.2 分级 ↔ 篇幅

- 前期（序列9→6）：升级相对快、给爽感；一部大卷解决 2-3 级，铺设"吃魔药+消化"的节奏。
- 后期（序列5→0）：每序列越来越慢、越来越关键，一部卷可能只推 1 级甚至 1 级过半——因为到后期序列是稀缺身份，太快就失去"终局对决"的重。

## 5. 产出 SOP 复盘（逐层在诡秘上验证）

| SOP 步 | 诡秘如何满足 |
| --- | --- |
| 1 定母类侧重 | 武力为主、非武力辅（都设计了） |
| 2 双侧定基石 | 武力=非凡特性（守恒）；非武力=序列社会地位 |
| 3 铺开对抗系统 | 战斗系统（手段/制约/信息差/配套）四样齐全；社会对抗系统共存 |
| 4 拉量化养成线 | 序列9→0，每级配破坏力/地位/稀缺 |
| 5 篇幅对账 | 前期快升爽、后期慢升精，符合"每档叙事节点" |
| 6 收束世界机理 | 序列守恒→成神牺牲→世界之谜，一整条链咬合 |

**验证结论：框架完全装得下诡秘之主，尤其"基石守恒"这一条被火光放大了——它正好接上我们之前发现的"世界谜底=与基石守恒相绑定"。**

## 复盘总评

**诡秘之主完整地填满我们世界法则的所有格子，无一处悬空。** 尤其三点验证了框架的有效性：

1. **基石守恒**是诡秘的魂，它让"越强越稀有、越容易被盯上"成了主线引擎——这正好证实了框架里"基石有张力（基石总量/稀缺/天花板造成世界独特）"这条验收项的必要性。
2. **序列既是战力也是社会位阶**——完美解释了"等级三位一体（战力×地位×数量）"为什么必须绑定social，不是可有可无。
3. **养成线前期/后期节奏**和篇幅强关联，前期快后期慢，直接印证"分级↔篇幅"这条是硬规则不是装饰。

唯一的留白：非武力侧的"社会对抗"我用的是泛指（密教博弈/占卜社交），没有像武力侧那样逐项展开——因为它确实次要，符合框架"非武力侧重不展开到同密度，但必须存在"。这一点是否要加深，看下轮复盘时老板的判断。
