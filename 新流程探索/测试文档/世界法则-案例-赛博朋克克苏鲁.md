## 第 1 步 · 世界画像（先）：定调六步 + 钉出"最被抢＝基石输入"

### 定调六步

1. **壳**：近未来现代 + 赛博霓虹 + 冷金属/霓虹灯，色调"闪耀又冷冽"；一句话="巨企统治、人人贷身给公司的钢铁丛林之城"。
2. **内核（最重要的产出）**：如果"高科技低生活、巨企统治、政府半傀儡"，那么"**钱/资本是唯一王道**——谁都为钱游走，身体和灵魂都能被标价、被贷、被抵押"。可推演：白天城市是通勤的牛马，夜里是霓虹下的交易；穷人卖身给公司换义体，富人在飞地俯瞰；一场战争为"专利垄断、数据矿脉、公司飞地"而打。**→ 最被抢的东西钉出来 = 钱/资本量级。**
3. **独特点**：钱能买到的"境界以上"——钱够到某个阈值，能买到一点点克苏鲁的、不可名状的东西（禁忌数据、灵性义体），越贵越靠近"那个存在"。
4. **代价（氛围级，不做真枷锁）**：世界级=整个文明被资本污染、人的灵魂被标价（氛围）；普通人=打工人的一天"三份工还贷，吃廉价营养膏，靠刷数据混日"。
5. **危机**：巨企掌上有个"会炸开的开关"——某家公司在挖一条数据矿脉时，捞出了"某个东西"，正被捂在盖子里（深网封印），一旦公开=全城失灵/引动不可名状。没人敢提。
6. **隐喻**（自选）：借贷=自由被公司分期买走；底层以健康换收入，映照劳动异化。

### 钉出基石输入（交给世界法则）

> **这世界最被抢的 = 钱/资本量级。**（赛博内核直接给，不用造词）

## 第 2 步 · 世界法则（后）：基石从画像内核点出 + 双能力线 + 无真代价

### 1. 基石（从画像内核点名，不是凭空造）

- **基石是什么**：**钱/资本量级**——从画像内核"高科技低生活、钱>一切"点出。谁的钱量级越高，谁越能购买义体、数据、人脉、甚至禁忌之物。
- **守恒与稀缺**：钱守恒但不断向豪者聚（寡头垄断）→ 天花板=能用钱买到的"境界"上限，越往上越稀有（顶配义体+顶层人脉+禁区数据，就那么几个人买得起）。
- **呼应内核**：强 = 能买到多少"异体之物"；钱的尽头 = 够到克苏鲁存在的一点残响（但那只是氛围，见 1.5）。

### 1.5 双能力线 + 爽文无真代价机关

- **钱（主基石）**：实打实的力量——买义体/装备/数据/人脉/雇佣军，可量化、读者秒懂。
- **克苏鲁（氛围能力线）**：不是真代价、不是第二套硬石头，而是一层**"越往上走越显风格"的氛围滤镜**——主角钱级上了某个阈值，就陆续解锁一点"不可名状"的画风：名字带腥味、身边多一层幻影、说话带点诡调，但**对主角无实质伤害、无不可逆堕落**。它给"有钱人世界还很怪"的味道，不给主角添堵。
- **禁用**：不做"越强越疯、最终失控"（真代价，读者会弃书，删）。

### 2. 物资系列（钱买得到的分档）

| 物资 | 分档（凡/珍/禁） |
| --- | --- |
| 普通义体/武器/装备 | 凡→珍 |
| 数据（情报/专利/黑市DDOS） | 珍 |
| 灵性义体 / 深网封印数据 / 禁忌之物 | 珍→禁（够到克苏鲁氛围线，买得到但极少+需身份） |
| 人脉通行证（公司飞地/禁区入场） | 珍→禁 |

**门槛**：主角初期只买得起凡/珍档义体；禁档的"灵性义体/深网封印数据"要钱级 + 身份上去才够得着——否则开局解锁，篇幅没法排。

### 3. 对抗系统（两侧对开）

**3.1 战斗系统（武力侧）**
- **义体格斗**：本质=高强度驱动的近身/远程械斗。表现=液压臂+弹道义体连击。
- **数据奇袭**：本质=借数据流入侵环境/义体。表现=夺取机械控制、黑掉保安网。
- **雇佣火力**：本质=砸钱叫人办事。表现=雇佣兵、买通管线、用钞能力碾压。
- **灵性义体**（克苏鲁氛围线）：本质=用"一点点不可名状"增强画面感，表现=出手时幻影/低语做效果，实际威力仍靠义体硬实力。

**3.2 社会对抗系统（非武力侧）**
- **企业并购/商战**：本质=资本与控制链博弈。表现=股权争夺、供应链卡脖、垄断定价。
- **地下帮派地盘**：本质=地盘与租金网络博弈。表现=抢码头、抢黑市、收"保护费"。
- **深网黑市**：本质=数据与禁忌兑换。表现=用数据换钱、用钱换身份、捂盖深渊真相。

（都成体系、本质+表现齐全，不写死一张"都市对抗"表硬套。）

### 4. 养成线（硬规则：主 1 + 从 ≥3，各维度不重叠）

**主养成线（骨架）**：**身价/资本量级**（债奴→白领→中产→企业主→寡头）。读者按数字秒懂强弱。

**从养成线（3 条，各占一个维度，功能不重叠）**：

| 从线 | 维度 | 独一无二的成长方式 | 挂主线方式 | 与它线对角 |
| --- | --- | --- | --- | --- |
| **义体武装** | 战力 | 买义体/改装备，硬实力随钱堆 | 需身价够高才买得起高阶义体 | 义体强但钱链紧→资源被卡 |
| **数据情报** | 环境信息 | 靠破解黑市数据长，手里有情报 | 需身价买得起数据源+进黑市 | 情报多但没义体→打架吃亏 |
| **人脉/公司飞地** | 资源地位 | 靠疏通关系、挤进公司飞地长 | 高位飞地才发得出禁档物资 | 人脉足但钱链紧→订单压死 |

**关键**：三条从线互相抠——主角升身价时不断砸钱进义体/数据/人脉，钱链就是三线共同的资源瓶颈（张力+吃瘪都有来源）。**克苏鲁氛围线不再占一个硬维度**（它只是主线上的色彩，不做第4条硬养成线，避免把克苏鲁做成真资源）。

### 5. 收束世界机理 + 敌人同法则

- 基石（钱）能回头解释画像内核"钱>一切"；物资/对抗/养成线都从"钱买得到什么、谁在抢钱"里长出来——是能反证的活规则。
- 敌人也用同一套：巨企大佬赢，是靠他钱量级更高 + 主角某数据/人脉短板；不是"敌人不靠钱"。

## 复盘：顺序对了 + 无真代价到位了

- **顺序对了**：先画像钉"钱>一切"，法则的基石"钱"就是从画像内核直接点名的，不是造词。这验证了"先画像后法则"成立。
- **无真代价到位**：克苏鲁从 v1 的"越强越失控+灵子"降到 v2 的"氛围能力线+主线上色彩"，去掉不可逆堕落，只留氛围/装扮级——符合爽文本质。
- **养成线符合硬规则**：主1+从3，各占战力/信息/资源地位三维度不重叠、有独家成长方式，挂主线+对角齐全。
- **缺陷提示**：克苏鲁这条氛围线，因"无真代价"，可提供的实际爽点和差异化偏弱——实际创作时它要靠"画面、压迫感、不可名状的敌人设计"补，而非真实变强枷锁。这块留给世界观/格局去补视觉与危机。
