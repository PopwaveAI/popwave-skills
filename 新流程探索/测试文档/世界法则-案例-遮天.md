# 设定文档 · 世界法则（案例：遮天 · v4 重填）

> 产出阶段：核心设定设计阶段（tag=锁根）。
> 用途：用《遮天》按 v4 模板（基石→物资系列→对抗系统×多养成线）重填，验证新增"物资系列"与"多条并行养成线"两个结构成立。
> 生成依据：《世界法则.md》v4 + 遮天设定。

***

## 0. 一句话

**遮天的世界"强"构成 = 武力侧绝对主导，非武力侧几乎并入战力。基石是多轨广义超凡物质，向上衍生一整套物资；养成线不止境界一条，是境界为主、功法/体质/神通/法宝多线并行且都挂境界。**

***

## 1. 基石：广义超凡物质（多轨）

| 问什么      | 遮天                                                             |
| -------- | -------------------------------------------------------------- |
| 总能源是什么   | **广义超凡物质**：灵气、大道法则、仙路（成仙的根）——三者共同构成"世界凭什么有力量"                  |
| 是否稀缺/守恒  | **高度守恒**。仙路断绝、成仙无门；证道会抽走天地生机，气运此消彼长                            |
| 呼应哪条世界机理 | **"想成仙，必先有人让路"**——资源守恒+仙路断＝只能靠碾过别人、续前人的命；黑暗动乱是"强者抽一界生机续自己命"的具象 |

## 2. 物资系列：基石衍生出的资源物（v4 验证点①）

遮天的基石不是空泛"灵气"，能拆出一整批可点名的物资：

| 物资      | 作用       | 稀缺性/冲突点            |
| ------- | -------- | ------------------ |
| 灵石/灵脉   | 常规修炼、补充  | 凡常见，但极品灵脉是宗门争抢点    |
| 天材地宝/灵药 | 炼体、突破辅助  | 每境界冲刺必抢，是卷内冲突抓手    |
| 仙果（神药）  | 续命、逆天突破  | 极度稀缺，一份往往引全界争夺     |
| 大道法则残余  | 悟道、证道门槛  | 证道才行，封存在险地，是后期消化核心 |
| 雷劫（天劫）  | 渡劫成道、塑体能 | 危险，是"境界突破"的代价具象    |
| 帝兵/仙器   | 战力外挂     | 一份帝兵＝一世底蕴，传承即争抢    |

**判断：遮天的基石 → 物资拆得开、可点名、不可白得，甚至直接构成剧情冲突（夺仙果、抢帝兵）。** 这说明"物资系列"这一层在遮天上完全成立，是必要的。

## 3. 对抗系统

**武力侧战斗系统（绝对主打，四样齐全）：**

| 维度   | 遮天                          |
| ---- | --------------------------- |
| 对抗手段 | 体术+法术+法宝/战兵（最核心）；功法、体质、神通辅助 |
| 制约   | 动用大神通需寿元/道伤、耗资源；索取过度损根基、招禁忌 |
| 信息差  | 功法/体质/法宝优劣可判，知道对方底牌可破局      |
| 配套养成 | 境界绑定宗门地位、人族香火、辈分权力          |

**非武力侧（并入战力、极薄）：** 宗门族权、香火均靠战力支撑，无独立上升通道。

## 4. 养成线：境界为骨干，多线并行且挂钩（v4 验证点②）

**遮天真实的多条并行养成线，且都挂境界：**

| 养成线   | 分级                   | 与境界（主养成线）关系      |
| ----- | -------------------- | ---------------- |
| 境界（主） | 轮海→道宫→神桥/彼岸→仙台（圣/大帝） | 骨架：世界观根本级        |
| 功法    | 帝经/古经/自创 · 每部有层阶     | 达某境界才可练到深层       |
| 体质    | 荒古圣体/神体/圣体 · 先天分高低   | 破境才显露/强化         |
| 神通/秘术 | 一门一阶 · 大神通/小神通       | 需境界支撑才能施展高深神通    |
| 法宝/战兵 | 灵宝/帝兵/仙器 · 等阶森严      | 有独立等阶，但威力上限受境界约束 |

**关键确认**：这些线不是平行独立等级，是"**境界是主干，其余（功法/体质/神通/法宝）都挂境界上**"。要先够上某境界，才能往深练功法、施展高深神通、驾驭高等法宝。所以遮天世界法则里，**主养成线=境界，从线=功法/体质/神通/法宝**，都绑在境界的框架上。

**篇幅**：前期轮海→道宫快升爽感，后期神桥→仙台每境一档、慢升布局；从线跟着境界、节奏一致，不产生额外篇幅负担。

## 复盘总评

**v4 模板用遮天重填后，三项新东西全部经得起"这就是遮天真实样子"的检验：**

1. **物资系列成立且是关键**——遮天的基石（灵气/大道/仙路）不拆成物资就是空的；拆出灵石、仙果、雷劫、帝兵后，升级与争抢都有了抓手。"基石必须拆出一批可点名的物资"这条对遮天是真必要。

2. **多养成线并行**修正了 v3 的短板——遮天不是"境界一条线"，是境界+功法+体质+神通+法宝五条，各有分级。模板 v4 现在能装下这个真实复杂度。

3. **"从线挂境界"是 v4 最重要的一条**——遮天最典型的地方在于这几条不是平行独立等级，而是"境界是骨架、功法/体质等附着其上"。模板这条规则精准抓到了遮天（也适用于仙侠类）的养成结构本质。

**模板结论：v4 的"基石→物资→对抗×多养成线（挂境界）"结构，在遮天上完整成立，且正好补上了 v3 抓不到的真实复杂度。**

留白：非武力侧遮天仍是"并入战力、极薄"，未验证独立非武力通道——与之前判断一致，仍需老板确认遮天是否存在独立于战力的非武力上升通道。
