# 正文质量测试规划 v1

> 用途：把"零散试一下"改成体系化测试。目标是在 flash API 上找到一套输入范式，**控制力能加上去，质量不掉**，并据此重构涌现流写作专家。
> 日期：2026-09-12。所有结论以本规划执行后的实测为准，本文件随每轮结果更新。

## 一、已知结论（第一性原理，都有实测支撑）

这七条是本规划的骨架，后面所有旋钮都从它们推出来。

| 编号 | 结论 | 实测证据 |
|:--|:--|:--|
| P1 | **通顺是"专心写"的副产品，检查补不上。** | 直出 0 次工具调用、几乎无语病；链路 23 次调用、语病密布 |
| P2 | **约束的作用层级决定它是否降质量。** 内容层约束不降，形式层约束降 | 章纲（形式＋内容混合）掉到 40 分；老板版简介（纯内容）保持 70 分 |
| P3 | **模型判不出"怪"。** 包括判它自己写的东西 | 我把你圈的 7 句全标成绿；AI 评委把 skill 稿排在直出之前，八项维度全反 |
| P4 | **形态会传染。** 输入的文本形态会被输出复制 | 条目式章纲 → 正文每段 32 字；散文式简介 → 每段 40 到 58 字 |
| P5 | **剧透杀死悬念。** | 章纲写了反转答案 → 只能演；简介不给答案 → r01 自己设计出"灯早就灭了" |
| P6 | **独立多稿优于单稿多改。** | 3 稿 3 个独立解，选稿即可；改 3 稿留下语法断口（v3 第 141 句） |
| P7 | **模型的生成目标就是它的惩罚函数。** | 链路惩罚漏节点、字数不符、去 AI 味 FAIL，不惩罚"句子说不清"，于是模型牺牲句子 |

## 二、已有基线（前面所有测试都跟这四条比）

| 编号 | 输入 | 结果 | 文件 |
|:--|:--|:--|:--|
| B1 | 宽泛入口："没有任何前提，为我写一段{赛道}小说第一章" | 70 分 | `第二次测试/输出/deepseek-flash/` |
| B2 | 旧海图章纲原样直发（3059 字符） | **40 分** | `第二次测试/输出/章纲直出/` |
| B3 | skill agent 链路产出（挂 DNA、四样必读、全部检查） | 低于 40（语病密布） | 项目空间 `9-11-项目b/正文/` |
| B4 | 老板版散文简介（121 字） | 70 分 | `第二次测试/输出/老板版直出/` |

**B2 是"控制了但掉质量"的典型，B4 是"控制了且没掉质量"的起点。整个规划要超越的是 B4，不是 B1。**

## 三、要回答的三个问题

**Q1（核心）** 输入提示词的范式怎么设计，走 flash API，让控制力加得上、质量不掉？

**Q2** 有没有办法让模型理解人类美学？试四条路：挂通病规则、挂正样板、换身份提示词、两段式（先写再以挑剔读者身份标记）。

**Q3** 在前两个答案的基础上，怎么重构涌现流写作专家？

## 四、度量体系（这是能不能体系化的关键）

### 4.1 质量的度量

**一组测试只出一稿，老板逐个打分。** 目标不是找最优方案，是跨过可用线。

- **可用线 = 60 分。** 现有方案的普遍水平是 20 到 30 分。只要能稳定拿到 60 分，就能用很久，再迭代。
- 绝对分会飘（越打越松）。所以每轮同题要带一份参照稿：基线 B2（40 分）和 B4（70 分），打分时对着参照稿比。

| 指标 | 谁出 | 怎么算 |
|:--|:--|:--|
| Q1 文笔分 | 老板 | 0 到 100。**主指标** |
| Q2 剧情分 | 老板 | 0 到 100。**和文笔分拆开给**，两分互不折算 |
| Q3 缺陷处数 | 老板圈 | 按 `正文缺陷清单-v1.md` 圈句子，数处数 |
| Q4 机器筛命中 | 脚本 | 见 4.3 |

**为什么要拆开给分**：第一轮实测里同一稿出现"文笔 60、剧情 40"。合成一个分数会把这两种毛病（写得顺不顺、故事好不好）混成一团，看不出旋钮到底动了哪一边。

### 4.2 控制力的度量

把"控制力"从感觉变成六个数：

| 指标 | 定义 | 谁判 |
|:--|:--|:--|
| K1 硬事实兑现率 | 要求出现的事实数 ÷ 实际出现数 | 脚本查关键词，人工复核 |
| K2 落点命中 | 结尾是否停在指定处境（是／否） | 老板，二值 |
| K3 人物属性命中率 | 指定的人物特征条数 ÷ 文中体现条数 | 老板勾选 |
| K4 世界观违背数 | 与指定设定冲突的处数 | 老板勾选 |
| K5 剧情偏离档 | 0 正合／1 擦边／2 跑偏 | 老板，三档 |
| K6 篇幅达标 | 字数是否落在指定区间 | 脚本 |

### 4.3 机器筛（我出，不用老板看）

字数、段落数、平均段长、句长标准差、开头引文块有无、繁简混用、数字前后一致、破折号与引号形态、同词复读 Top10、Markdown 残留。

**这一档只筛事实，不判好坏。** 因为 P3 说得很清楚：质量判断不能交给我。

## 五、旋钮表（可独立开关的输入变量）

每一条都有理由来自第一节的七条结论。

| 编号 | 旋钮 | 档位 | 现有证据 |
|:--|:--|:--|:--|
| V0 | **命题来源** | 复用原项目章纲 ／ 从世界观＋立项＋设定自拟 | 原项目章纲那版：文笔 60、剧情 40。怀疑剧情分低是原章纲的锅，故后续一律自拟命题，**不复用原项目剧情** |
| V1 | 输入形态 | 松散叙述 ／ 一句话简介 ／ 条目清单 ／ 散文段落 | P4：条目→32 字每段；散文→40 到 58 字每段 |
| V2 | 答案剧透 | 给反转答案 ／ 不给 | P5 |
| V3 | 体裁声明 | 无 ／ 一句（"这是一本 X 小说的第一章"） | B4 有，70 分 |
| V4 | 主角设定 | 无 ／ 一句身份 ／ 人设卡 | 未测 |
| V5 | 剧情约束 | 无 ／ 一句话概要 ／ 硬事实清单 ／ 追加落点指定 | B2 过度、B4 适度 |
| V6 | 世界观约束 | 无 ／ 一句 ／ 设定条目 | 未测 |
| V7 | 文风要求 | 无 ／ 一句（如"多内心思考，吐槽，对话"） | BG3 组：吐槽 3/3 到位，对话只 1/3 |
| V8 | 通病规则 | 不挂 ／ 挂 `正文缺陷清单` | 未测，Q2 入口 |
| V9 | 正样板 | 不挂 ／ 挂 2 到 3 段人书原文 | 挂 DNA 反而差（但那是腔调样文，不是标准段落），要重测 |
| V10 | 篇幅 | 不指定 ／ 指定区间 | 未测 |
| V11 | 分场 | 不指定 ／ 指定场数 | 未测（预期降质量，形式约束） |
| V12 | 人称 | 不指定 ／ 指定第一或第三人称 | 未测。实测里模型会自己选，同一批里出现过两种 |
| V13 | **任务声明** | 无 ／ 加一句"写第一章" | 实测：只发作品简介（总结口吻）时，模型把它当既有正文，去"续一段"，还带助手话尾，只出 716 字；加一句"写第一章"后正常起笔，2889 字 |

## 六、分阶段计划

### 阶段 0 · 基线固化（先做，前提）

把 B1 到 B4 的输入文件和机器筛表归档，各出 1 稿作参照。之后每一轮都拿新结果跟 B2、B4 比。

产出：一张基线表，含输入文件路径、正文、老板打分、机器筛表。

### 阶段 1 · 旋钮单扫（核心阶段，八轮）

**每轮只动一个旋钮**，其余保持 B4 的水平。固定题用克苏鲁航海（有 B2 可比），**每轮 1 稿**。

按"可能收益 × 便宜程度"排优先级：

| 轮次 | 测什么 | 预期 |
|:--|:--|:--|
| 1-1 | V5 硬事实清单（时间、地点、人物、要发生的事、结果） | 控制力涨，质量看会不会掉 |
| 1-2 | V3 体裁声明（复现 B4 的效果） | 复现验证 |
| 1-3 | V7 文风要求（一句话） | 看能不能把"对话"这一项补上 |
| 1-4 | V4 主角设定（三档各跑） | 控制力涨多少 |
| 1-5 | V6 世界观约束 | 同上 |
| 1-6 | V2 剧透（给答案／不给） | 验证 P5 |
| 1-7 | V10 篇幅区间 | 预期降质量 |
| 1-8 | V11 指定场数 | 预期降质量 |

产出：每个旋钮一行结论——质量升／平／降，控制力涨多少，进哪个清单。

### 阶段 2 · 旋钮交叉（四轮）

只拿阶段 1 里"不降质量"的旋钮做两两组合，看控制力能不能叠加、有没有互相抵消。

重点测：V5＋V4＋V6（三件内容约束一起）／V5＋V8（硬事实加通病规则）／V4＋V7（人设加文风要求）／V5＋V2（硬事实但不给答案）。

### 阶段 3 · 美学转译专项（回答 Q2，五轮）

这一阶段单独测"让模型理解人类美学"的五条路：

| 路 | 做法 | 要看的 |
|:--|:--|:--|
| A | 挂通病规则（负向清单） | 会不会因为抢注意力反而更差（P1） |
| B | 挂正样板（2 到 3 段人书原文） | 和挂 DNA 有什么不同 |
| C | 换身份提示词（从"写作助手"改成"你是作者/编辑"） | 身份一换行为变不变 |
| D | 两段式：先写完，再切成"挑剔读者"模式只标记不修改，人按标记改 | 我被指着单句能判出，这条最有希望 |
| E | 三件套原版复测（内容模板＋情绪示例＋原文硬灌） | 第 3 件套已被否，重测确认 |

### 阶段 4 · 稳定性（三轮）

**本阶段是唯一的例外，必须多稿**，因为要测的就是方差。同一输入跑 3 稿，看分数波动多大。按你的阅读精力再定要不要加到 5 稿。

产出：每章跑几稿的建议，以及单稿风险有多大。

### 阶段 5 · 泛化验证（三轮，各 1 稿）

用三个老板不熟的赛道跑最终范式。**目的是排除"因为熟悉才判得准"。**

### 阶段 6 · 重构成果（输出）

固化成四样东西：输入范式模板、人判检查清单、机器筛脚本、skill 结构。

## 七、决策规则（提前定死，不许事后找理由）

| 分数 | 控制力 | 结论 |
|:--|:--|:--|
| ≥60 且不低于参照基线 | 涨 | 进**必带清单** |
| ≥60 且不低于参照基线 | 不涨 | 进**可选清单** |
| 低于 60 或明显低于基线 | 任意 | 进**禁用清单** |
| 低于 60 | 大涨 | 进**条件清单**（只在必须控制时用，同时记下代价） |

## 八、每轮的固定产出

1. 输入文件（原样存档，可复现）
2. 正文 1 稿（raw + thinking）
3. 机器筛表
4. 老板的打分和控制力勾选
5. 一行结论：这个旋钮，分数够不够 60、控制力涨多少、进哪个清单

**交付方式**：一次只交一稿，附轮次编号、本轮动的旋钮、正文全文。不许一次贴一堆，你的阅读精力是唯一瓶颈。

## 九、成本与节奏

flash 一稿 9 到 27 秒。一轮 1 稿约 20 秒机器时间，你读一稿加打分约 2 分钟。阶段 1 八轮约 3 分钟机器时间加你 16 分钟。**全部阶段加起来不到 1 小时机器时间、你 1 小时以内。**

## 十、风险与反制

| 风险 | 反制 |
|:--|:--|
| 你疲劳，评测量太大 | 一组只出 1 稿，一次只交一稿；机器筛我不会让你看 |
| 熟悉度偏差（克苏鲁你不熟、BG3 你熟） | 每个旋钮在最熟和最不熟的题上各跑一次 |
| 单次方差大，**每轮 1 稿测不出波动** | 中间轮次接受这个风险；只对最终胜出的范式在阶段 4 补多稿复核 |
| 分数越打越松 | 每轮同题带一份参照稿（B2 或 B4）对读 |
| 我又把"绿"标错 | 质量判断不交给我。我只出机器筛和候选，你打分 |
| 把"降 AI 特征"混进目标 | 明确排除。这一阶段只求稳定出直出水平，降特征另立专项 |

## 十一、一句话路线

**先固化基线，再一个旋钮一个旋钮地扫（每轮一稿），扫出能跨过 60 分且控制力涨的那些，两两组合测控制力能不能叠加，然后把结论固化成输入范式，最后拿不熟的赛道验一遍。**
