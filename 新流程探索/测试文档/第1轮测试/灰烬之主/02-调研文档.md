# 02-调研文档 · 灰烬之主

> 案子：立项创意 SOP 实测第一案。本文档是第 3 步存档，结论供需求卡回填与故事脉络消费。
> 调研时间：2026-09-09。数据源：联网检索（wiki 站与玩家社区为主）。查不到的写"没查到"，不编造。

## 1. 战锤40K 的灰骑士（Grey Knights）是什么

**结论先行：灰骑士是战锤40K 的一支阿斯塔特战团（编号第666战团），唯一使命是追杀并驱逐入侵帝国现实的恶魔。**

关键设定四点：

1. **恶魔猎人**：与其他战团不同，灰骑士存在的唯一目的是对抗恶魔（亚空间实体）。由人类帝皇在荷鲁斯叛乱时期亲自创立，直属审判庭的特种作战部队，全帝国最顶级装备。
2. **全员灵能者（psyker）**：灵能不是专职岗位，而是入团基线要求。别的战团只有少量智库（Librarian）是灵能者，灰骑士人人都是。
3. **基因种子直接来自帝皇本人**：灰骑士的基因种子不是来自帝皇二十个原体中的任何一个，而是直接源自帝皇的基因组，被称为"帝皇的馈赠"。
4. **秘密与孤立**：灰骑士的存在本身是帝国机密，行事隐秘，在凡人眼中近乎传说。

**硬矛盾 a 的判断依据（原体问题）：**

- 原体（Primarch）是帝皇用自身 DNA 创造的二十个基因原体，是星际战士军团的基因之父，体型与力量远超常人，被描述为"活半神"。
- **灰骑士没有自己的原体**。他们的基因之父就是帝皇本人。原作中不存在"灰骑士原体"这个位阶。
- 因此"成长为灰骑士原体"在原作里无对应物。本书必须自己定义，两条路：
  - **借用概念**：原体=力量层级命名，灰骑士原体=灰骑士体系的顶点位阶（晋升到原体级力量）。费伦没有战锤的基因体系，"原体"作为层级称号借用，不重建帝皇-原体-军团谱系。
  - **重新定义**：在书内新建"灰骑士原体"的完整概念（谁定的位阶、凭什么够格、与帝皇/灰烬之力的关系），完全自洽但脱离原作语感。
- 调研不代用户拍板，两条路都写进需求卡备选，推荐"借用概念"（读者一眼认得出，又留出新位阶的新鲜感）。

## 2. 博德之门3 / DND 5e 的费伦世界（主盘设定）

**结论先行：费伦是托瑞尔（Toril）星球上的主大陆，是多神信仰真实存在的星球，博德之门3 的至上真神线是本书主盘的前史。**

关键设定四点：

1. **地理量级**：托瑞尔是主物质位面（Prime Material Plane）的一颗星球，位于 Realmspace 晶壁系。主要大陆：费伦（东西约 3500 英里、南北约 2500 英里）、卡拉图、马兹特克、扎卡拉。费伦只是托瑞尔上的一块大陆——**主盘至少是星球级**。
2. **诸神与神力**：费伦是真·多神教世界，诸神真实存在、由信仰之力供养（信徒越多神越强），可以干预凡间、派遣化身。但大神不能随意进入主物质位面——**神无法直接下场，凡人英雄与化身是主要干预手段**。神力分档：微弱→弱等→中等→强大→伟大（"伟大神力"是谱系顶点档）。
3. **至上真神线（本书前史）**：博德之门3 主线的"至上真神（Absolute）"真身是被卡萨斯王冠（Crown of Karsus）奴役的长老主脑（Netherbrain）。三神（巴尔/米尔寇/班恩）的选民本是执棋者，实际被主脑当作棋子；主脑借夺心魔蝌蚪控制"真魂者"，邪教遍布剑湾。
4. **剑湾与冒险生态**：主线主舞台是剑湾（Sword Coast），冒险者公会、佣兵团、城邦政治是 DND 读者默认的日常画风。

**硬矛盾 b 的判断依据（混沌怎么跨体系入侵费伦）：**

- 战锤的混沌来自亚空间（Warp）——由所有生物的情感、思想、欲望投射形成的镜像维度，四大邪神（恐虐/奸奇/纳垢/色孽）是情绪能量凝聚的意志。恶魔是亚空间的具现，入侵现实靠"裂隙/灵能风暴"。
- 费伦的接口点：费伦的信仰之力与灵魂本就是"精神能量"。**跨体系入侵的可行设计：费伦浓烈的信仰/灵魂/情感洪流撕开了一道通亚空间的裂隙，混沌顺着灵魂裂缝涌入；或夺心魔的灵能网络（illithid 心灵异能）凿穿了灵界边界，意外把亚空间放进来。**
- 体系对冲点（本书的独特张力）：费伦诸神靠信仰、无法直接下场；混沌四神靠情绪、本体永驻亚空间。两套"神"都只能间接出手，凡间英雄成了唯一正面战场。这天然解释了"为什么靠一个穿越的灰骑士"。
- 调研不代用户拍板入侵机制，只确认"信仰/灵能接口"成立，机制细节留给世界法则。

## 3. 网文穿越流的读者默认预期

**结论先行：穿越流读者默认四件事——穿越者视角、本土成长、金手指绑定、认知差红利。**

读者默认（该复用的骨架）：

1. **穿越者视角**：主角是地球现代人（或读者能代入的普通人），带着现代灵魂/记忆进入异界，视角锚定在他身上。
2. **本土成长**：穿越后不是空降大佬，是从底层/孤立处境一步步往上爬，成长过程可见。
3. **金手指绑定方式**：面板/系统/认知差/传承，绑定方式千变万化，但核心是"主角有别人没有的资格或信息差"。
4. **认知差红利**：现代知识（或对游戏剧情的了解）在异界变现成情报、策略、机遇——这是穿越流最稳定的爽点来源。

差异区（可创新处，踩卖点触发器才动）：

- 金手指的具体形态与来源（本书：灰骑士身份/灰烬之力从哪来）。
- 穿越的机制与代价（本书：穿越本身是不是一个局）。
- 读者默认的是"穿越进一个已知世界"，本书叠加了"第二套体系入侵"——这是缝合的新鲜点，不破坏穿越流默认骨架。

支撑结论：本书"地球大学生穿越费伦"完全落在穿越流默认骨架上，直接复用；创新只放在"灰骑士身份来源 + 混沌入侵机制 + 灰烬之主成神路径"这三处卖点部位。

## 4. 调研结论（对需求卡与故事脉络的支撑）

1. 主盘定费伦（星球级），混沌为入侵者——**需求卡世界线"至少星球/多元"成立**。
2. "灰骑士原体"在原作不存在，本书定义为"灰骑士体系的顶点位阶"（借用概念，待用户拍板）。
3. 混沌入侵的合理接口=信仰/灵魂/灵能（费伦信仰浓烈＋夺心魔灵能网络），且与费伦"神不能直接下场"形成对冲——**这给了主角存在的结构性理由**。
4. 穿越流默认骨架直接复用，创新集中在三处卖点：金手指源头、入侵机制、成神路径。
5. 没查到、需后续补：费伦信仰力与亚空间情绪的换算规则（世界法则阶段定）；灰骑士在费伦的具体编制与传承来源（主角设计阶段定）。
