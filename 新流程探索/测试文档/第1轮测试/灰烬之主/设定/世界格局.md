## ① 文档定位

**本份是什么**：把灰烬之主这世界的三层地图铺成棋盘——哪块地图归谁、谁占哪格、格子之间为什么对冲、主角从哪格起步往哪打。它不写画面（那是画像），不写强怎么构成（那是法则），只写"怎么摆、谁在台上、为何而战"。

- **角色**：锁根。链路第三步，世界画像之后、主角设计之前。
- **回答的问题**：怎么摆、谁在台上、为何而战（把世界当一个可走动的局面来看）。
- **链路位置**：①世界画像 → ②世界法则 → ③世界格局 → ④主角设计。
- **依赖**：建立在《世界法则》（怎么玩）＋《世界画像》（三层地图、每层地理构成/强者档位/特殊地点）之上；产出供《主角设计》使用。
- **一句话落点**：读者能在地图上指认"这是谁的地盘，主角在这里面要从哪打到哪"。

三样东西合并成一篇，以格局为主纲（势力与矛盾都是棋盘上的格子和冲突线，不单独成章）：

| 概念 | 定义（是A，不是B） | 在棋盘里的角色 |
| --- | --- | --- |
| 世界格局 | 地图怎么分格、哪块归谁的势力范围 | 棋盘本身（格面 + 归属） |
| 主要势力 | 谁在台上，占哪个格、强在哪档 | 棋子（占格的主体） |
| 主要矛盾 | 格子与格子之间为什么对冲、挡不挡主角 | 棋局（冲突线） |

一句话落点，三句连读：**棋盘铺开 → 谁占哪 → 哪两格要撞。**

## ② 思考逻辑（本案的推演线）

**本案 = 强世界观（DND 费伦主盘 × 战锤 40K 灰骑士/亚空间缝合），世界在推人，走三层棋盘，不走关系版图。**

推演线（从硬约束长出来，不是堆形容词）：

1. **棋盘继承三层地图**：凡世费伦、裂隙带、亚空间，一张一层。格面按《宏观地理格局》已分好的 14 块地摆，不重画地图。
2. **棋子按内核摆**：世界最被抢的是灵魂的归宿权——凡人抢庇护、神抢信仰、混沌抢无主灵魂。棋盘上每个势力占的格，本质都是"这格装了多少灵魂归谁"。谁占格 = 谁管这格的灵魂归属。
3. **矛盾从通货长**：三方抢同一个通货（灵魂），冲突线全从"抢归属"长出来——教廷抢信众份额、混沌抢无主灵魂、王权抢庇护配给权。哪两格对撞 = 两格在抢同一批灵魂。
4. **放主角**：先定升层触发主型（本案 = 位格晋升迁移型，灰骑士阶位质变触发迁层，局部打Boss），再定起步格（博德之门下城区，穿越落地格）、往哪打（沿冲突线逐层上推）、每卷推进点（对齐 7-10 卷）。
5. **不造主角**：本份只铺他脚下的棋盘。灰烬之力（金手指）归《主角设计》，本份不写。

**概念定义（首次出现即锁边界）**：
- **混沌锚点**：沿用《宏观地理格局》定义——混沌四神在凡世的固定节点（裂隙针眼/被腐化的圣所），不是判断词。
- **信仰锚定**：沿用《世界画像》定义——灵魂挂靠某个神/组织名下这件事，是活着的防务，不是死后安慰。
- **位格晋升迁移型**：沿用格局 SOP——升层由晋升位格驱动，主角到达某位格就满足迁入更高层舞台的门槛，不是打趴一个 Boss。

> 判据：读完本份，能模仿"继承三层地图当棋盘 → 按内核摆势力（谁管这格的灵魂归属）→ 画冲突线（抢同一批灵魂的哪两格）→ 放主角（位格晋升迁移型+起步格+每卷推进）"这套思路，换一个完全不同的题材也能照推。

## ③ 文档内容

### 1. 棋盘总览（一图看懂）

三层地图 = 三张棋盘格面。每张格面上坐势力、拉冲突线。主角的升层线（灰骑士阶位质变）就是跨层线。

| 层 | 棋盘格面（继承画像地理构成＋宏观分块） | 主角起步格 | 升层门槛（位格晋升迁移型） |
| --- | --- | --- | --- |
| 第1层 · 凡世费伦 | ①博德之门 ②剑湾城邦带（深水城/无冬城） ③内陆谷地 ④绝境东域 ⑤星球其余大陆（后舞台） | 博德之门下城区（穿越落地格，地下埋着裂隙主针眼） | 灰骑士阶位第3档（圣骑士/大导师，凡俗之巅）达成 → 迁入裂隙带 |
| 第2层 · 裂隙带与神域边缘 | ⑥裂隙主针眼 ⑦诸神门槛 ⑧堕落的至高神殿 | 卷5 从凡世迁入（裂隙主针眼） | 原体阶达成（初成→巅峰）→ 迁入亚空间 |
| 第3层 · 亚空间 | ⑨恐虐血神荒原 ⑩奸奇万变迷宫 ⑪纳垢腐败花园 ⑫色孽欢愉迷宫 ⑬灰烬王座区 ⑭诸神坠落之地 | 卷7 从裂隙带迁入（四神领域外围） | 立神位（灰烬之主，伟大神力）= 全书终点 |

> 层厚说明：第一层凡世独自背灰骑士阶位前 3 档（卷1-4，3次质变）；第二层 2 次；第三层 1 次。分布 3-2-1，对齐画像质变分布，不硬凑。

**三行讲清棋盘空着时长什么样**：
- 第一层五块格：博德之门与深水城是信仰经济最密的肥格（教廷占），绝境东域是混沌锚点的偏远格（四神最早的据点），内陆谷地是凋敝的田园格（信仰经济盲区），其余大陆是后舞台。
- 第二层三块格：裂隙主针眼（全书的开关）、诸神门槛（神递力量最远处）、堕落的至高神殿（危机遗留圣所，被亚空间改造成混沌据点）。
- 第三层六块格：四神领域各占一块且互相征伐，灰烬王座区是空着的立神位处，诸神坠落之地是旧神残骸。

### 3. 逐层写矛盾（哪两格对撞）

每层画冲突线，分三类：**格间宿怨**（占位之争）/ **资源争夺**（抢稀缺物资，对接法则物资）/ **围绕危机**（掩盖/引爆/堵死画像的危机）。单独标"谁挡主角"。

#### 第1层 · 凡世费伦

1. **格间宿怨**：
   - 教廷 vs 王权（博德之门/深水城的信仰格 vs 政治格）——教会想管一切灵魂归属，王权想分庇护配给权，两格抢同一批城邦居民。
   - 混沌代理人 vs 教廷（绝境东域锚点格 vs 剑湾庇护网）——锚点在蚕食庇护网的边缘格。
2. **资源争夺**：抢信众份额（教廷/各城邦神殿/混沌黑市三方抢同一个城的灵魂归属，对接社会对抗·信众争夺与信仰经济）；抢圣物与圣水配额（法则链2物资）。
3. **围绕危机**：博德之门裂隙针眼（第一处）——教廷在掩盖（怕信徒恐慌，压着裂隙消息）、混沌代理人在引爆（扩大裂隙、腐化夺心魔网络）、主角在堵死（净化）。谁在掩盖、谁在引爆、谁在堵死，三股力全压在博德之门这格。
4. **谁挡主角**：教廷把灰骑士当异端（对接社会对抗·异端审判与改信管制）＋混沌代理人网占着博德之门地下（针眼/主脑残骸）。主角从"被追杀"到"名动费伦"，就是第一层主线。

#### 第2层 · 裂隙带

1. **格间宿怨**：诸神 vs 混沌（诸神门槛格 vs 混沌锚点网格）——隔玻璃打架，神递力量、混沌扩锚点，两格在抢裂隙带本身。
2. **资源争夺**：抢无主灵魂（混沌侧吞粮）vs 抢神力递送额度（诸神侧，能递进费伦的神术量有限）。
3. **围绕危机**：裂隙主针眼（全书的开关）——混沌在合拢锚点网络（一旦连成=从侵蚀翻成吞食、神系坠落）、诸神在堵死（又不敢真开战）、主角要封印它。
4. **谁挡主角**：恶魔领主本体守在⑥针眼与⑧堕落圣所——原体晋升的层底Boss；诸神门槛的立场未定（神位垄断，暗中阻止外来神诞生）。

#### 第3层 · 亚空间

1. **格间宿怨**：四神领域互相征伐（恐虐 vs 奸奇 vs 纳垢 vs 色孽，永恒互斗）——四格之间没有和平，只有暂时停火。
2. **资源争夺**：抢灵魂与情感的洪流（四神抢食，谁吞得多谁强）；抢费伦的归属（谁先吞下费伦的信仰真空，谁在亚空间占上风）。
3. **围绕危机**：诸神坠落（被亚空间反噬的旧神，神域沉入亚空间的残骸——旧失衡的终局画面）——费伦神系正在坠落，主角要么封死裂隙（救神系），要么自己立神位（重建信仰）。
4. **谁挡主角**：四神本体（打不死，只能封——封死裂隙就是立神位的门槛）＋诸神的神位垄断（对接社会对抗·神位博弈，暗中阻力）。

> 判定：每层至少一条能一句讲清的冲突线。第一层"教廷与混沌锚点在抢博德之门的灵魂归属，主角夹在中间从被追杀到反杀"；第二层"诸神与混沌隔玻璃抢裂隙带，主角要封印开关"；第三层"四神抢食、神系坠落，主角要封死裂隙立新神位"。全成立。

### 4. 主角的起步格与升层路径（把主角放上棋盘）

**升层触发主型先定**：**位格晋升迁移型（主），局部打Boss（辅）**。
- 主型判据：主角升层不靠"打趴一个明确Boss"，靠灰骑士阶位质变——阶位到档，自动获得迁入更高层舞台的资格（卷4末圣骑士封顶迁入裂隙带、卷7原体巅峰迁入亚空间）。与世界法则主养成线（灰骑士阶位6档）对齐。
- 辅型：每层末尾有层底Boss战（卷4恶魔领主前锋、卷6恶魔领主本体、卷9-10四神本体），但Boss战是质变达成后的验证与收束，不是升层原因。

**起步格**：博德之门下城区——穿越落地格。为什么是它：偏远（下城区鱼龙混杂，教会管不到的暗角）、被压（教廷追杀异端，他见不得光）、有暗格（脚下就是第一处裂隙主针眼=全书的开关）。主角穿越醒来在这格，第一场戏就是靠游戏剧情认知（从线D）活命、锁定针眼，首战杀恶魔。认知红利最厚处 = 起步格。

**往哪打**：沿第一层冲突线"教廷 vs 混沌锚点"走——博德之门 → 内陆谷地 → 深水城/剑湾城邦带 → 绝境东域（平锚点、升层）→ 裂隙带 → 亚空间 → 灰烬王座区立神位。换图顺序与《宏观地理格局》扩展顺序一致。

## ④ 产出SOP（本案逐条对照验收）

1. **选轨**：强世界观（DND×战锤双体系缝合，世界在推人）→ 走三层棋盘，不走关系版图。
   → 验收：过。三层全铺，未硬套弱轨。
2. **铺棋盘**（第1节）：继承画像三层地图＋宏观14块分块，每层定"几块格 + 主角起步格 + 升层门槛（位格晋升迁移型，此处写门槛位格）"。
   → 验收：过。三行讲清棋盘空着时长什么样；层厚 3-2-1 对齐画像，不硬凑。
3. **摆势力**（第2节）：每层把顶层/中层/底层势力放进格子，各定【名/占地/主养成线档位/对主角作用】。
   → 验收：过。每层势力都能落进三层制某一格；棋盘上没有"不知归谁"的势力（其余大陆归入后舞台格）。
4. **画冲突线**（第3节）：每层拉出"哪两格对撞"，分宿怨/资源/危机三类；单独标"谁挡主角"。
   → 验收：过。每层至少一条可一句讲清的冲突线；能溯源到法则物资（信众份额/圣物/无主灵魂）与画像危机（裂隙针眼/锚点网络/诸神坠落）；"谁挡主角"已单独标出。
5. **放主角**（第4节）：升层触发主型 = 位格晋升迁移型（灰骑士阶位质变触发迁层），辅以局部打Boss；写起步格＋升层路径＋每卷推进点（对齐7-10卷）。
   → 验收：过。能答"主角从博德之门格到灰烬王座区格，经历6次质变、每步动了棋盘哪块"；升层按主型走，未硬套打Boss。
6. **与法则挂上**：越级赢 = 某项养成线超标（5条越级战逐条挂从线）；社会对抗 4 套已落进冲突线（信众争夺/信仰经济 = 第1层资源线、异端审判 = 第1层谁挡主角、神位博弈 = 第3层暗面）。
   → 验收：过。无孤立设定；敌人强 = 某项线超标＋他项短板，不是"敌人不用这套"。
7. **收尾验收一句话**：读者能不能在地图上指认"谁的地盘、主角从哪往哪打"。
   → 验收：过。这是一张能走的棋盘，不是抽象势力表；"谁在台上、为何而战"已留好给主角设计（灰烬之力 = 例外资格占位，本份未越位）。

## 本次实测结论（对照《世界格局.md》待处理问题逐条）

| # | 待处理问题 | 本案结论 |
| --- | --- | --- |
| 1 | 「升层触发双型」是否覆盖所有真实书的升层路径（是否需新增第三型） | 本案给双型施了压：主角升层靠灰骑士阶位质变（位格晋升迁移型），但每层末尾有层底Boss战（卷4/卷6/卷9-10）。实测答案：双型可混用成立——主型 = 位格晋升迁移（质变触发迁层），Boss战是质变达成后的验证与收束，不是升层原因。判据可补一句"分辨句：质变先行、Boss战收束 = 位格迁移型；摁平Boss才晋级 = 打Boss型"。本案未撞上需第三型的路径（"达成某件具体事"型），欲望串里的"查混沌源头"是并行支线，不驱动迁层。 |
| 2 | 棋盘对"顶层势力与主角敌对/助力"的预判（需主角设计后回填） | 本案摆势力只标作用（挡路/工具/中立），不决定立场。实测发现衔接点：第2-3层的"诸神门槛/诸神坠落之地"标注为"中立偏工具/中立偏助力"，最终立场依赖主角设计的欲望串（重建信仰 vs 立新神位），本份预判不了。新问题：棋盘上"立场未定格"（诸神门槛、诸神坠落之地）需要一个显式回填点——建议主角设计产出后回填一格，并把"回填时机"写进格局 SOP。 |
| 3 | 弱世界观「关系版图」是否够格独立成棋盘 | 本案是强世界观（世界在推人），不产生弱轨样本。悬置状态不变，仍等都市/言情真实书。 |

**新发现的问题（本案新开）**：
- **同级文档卷位不一致**：设定目录已有《宏观地理格局》扩展顺序卷位（凡世卷1-6/裂隙带卷6-7/亚空间卷8-10）与本份按《世界法则》质变分布的卷位（凡世卷1-4/裂隙带卷5-6/亚空间卷7-10）存在 1-2 卷偏移。原因：《宏观地理格局》按"每卷新增 1-2 块地"排扩展，《世界法则》按"6次质变对 7-10 卷"排卷。建议《卷纲》步回正（以质变分布为骨架，块地排进质变区间内），并把"骨架文档间卷位冲突以质变分布为准"记入 SOP。
- **同层换图与升层的边界**：卷2 从博德之门横向换到内陆谷地（同层换图，非升层），判据 = 是否发生位格质变。本份验证格局 SOP"一层内可跨多卷横向换图"判据成立。建议 SOP 补一句"同层换图与升层的判据 = 是否发生位格质变"。
- **一格多势力的主从**：博德之门一格同时坐教廷（顶层）/王权（中层）/城邦神殿（中层）/冒险者公会（中层）。处理法：同一格内按"管灵魂归属的权重"分主从（教廷主、王权从），冲突线只画主从之间。建议 SOP 补一句"一格多势力时，按该格'最被抢的东西'的掌控权重分主从，冲突线只画主从两两之间"。
