## ① 文档定位

**本份是什么**：灰烬之主这世界"强"怎么构成。它管三件事——怎么强（基石）、怎么赢（对抗系统）、怎么长（养成线）。不写世界画面（那是画像），不写棋盘摆放（那是格局）。

- **角色**：锁根。链路第二步。
- **回答的问题**：这套世界的"强"怎么构成？力量/对抗/升级长什么样？
- **链路位置**：①世界画像 → ②世界法则（基石从画像内核点名）→ ③世界格局 → ④主角设计。
- **依赖**：建立在《世界画像》之上——画像内核（灵魂的归宿权）/危机/三层地图骨架直接供本份基石使用。
- **一句话落点**：决定这套世界"怎么强、怎么打、怎么长"——对抗是否成立、等级是否可感知、篇幅怎么排。

分层向下（本份只到"强怎么构成"，棋盘与人是下一份）：

```
这是什么样的世界（画像：画面 + 内核）
  → 强怎么构成（基石→物资→对抗→养成线）【本份】
  → 怎么摆（格局：地图·阵营·分布）【下一份】
  → 谁在台上、为何而战（势力·矛盾）【再下一份】
  → 这个人来怎么做（主角设计）【最后一环】
```

## ② 思考逻辑

**本案的推演线（从硬约束长出来，不是堆形容词）**：

本案 = 双体系缝合（DND 费伦主盘 × 战锤 40K 灰骑士/亚空间），世界在推人，走强世界观完整链。

硬约束四条（需求卡拍板 + 画像点名）：
1. 混沌以"信仰/灵魂洪流撕开亚空间裂隙"入侵，诸神不能直接下场。
2. 费伦刚熬过至上真神危机，信仰体系被蛀空。
3. 画像内核点名：最被抢 = 灵魂的归宿权（信仰锚定）——凡人抢"死后有人收"，神抢"信徒信仰"，混沌抢"无主灵魂"。
4. 篇幅 200-300 万字 / 7-10 卷；主线质变 = 灰骑士 → 原体 → 伟大神力。

从这四条推：
- **基石不必另造**：画像已点名"灵魂的归宿权"，法则只把它拆成两条链——武力侧（灵魂产能：挂靠→神术、脱挂→洪流）＋非武力侧（信仰锚定：归宿权的分配）。
- **混沌线与非混沌线共用同一个通货（灵魂）**：费伦的强 = 挂靠了多少灵魂（信仰力总量）；混沌的强 = 吞了多少无主灵魂（洪流总量）。两线互为镜像，中间是争夺归宿权的战场。
- **养成线从读者默认长**：主线复用战锤灰骑士阶位（新兵→骑士→圣骑士→大导师→原体）+ DND 数值层（等级/CR/传奇/神力谱系）定档，零自造。
- **两侧对开都重要 → 非武力侧升准主线（v8.2 拍板）**：本书武力侧打穿到裂隙带，非武力侧要撑到"立神位"结局——信仰网络线升格**准主养成线**，与主养成线并行推进、每卷必升档、质变与主线错开（主线质变卷1/3/4/6/7/10，准主线主要升档在卷2/5/8/9 等无质变卷）。
- **对抗系统从"谁在抢灵魂"长**：社会对抗写信仰/灵魂这条线（信众争夺、信仰经济、异端审判、神位博弈）；战斗侧写纲要指向《战斗系统-SOP》。
- **金手指剥离**：灰烬之力只写"例外资格"占位（他动的是信仰锚定这套系统的例外），细节留给主角设计——主角设计里它是一条**金手指特殊养成系（原体之路）**，本篇只出指针。

> 判据：读的人该能模仿"画像点名基石 → 拆两条链 → 铺对抗（每套四件事）→ 设养成线（主/准主/从，维度不重叠）→ 对齐篇幅 → 复用命名 → 剥离金手指"这套思路。

## ③ 文档内容

### 1. 基石：从画像内核点名（灵魂的归宿权，两侧对开）

**总基石 = 灵魂的归宿权（信仰锚定）**。信仰锚定是设定概念，指"灵魂挂靠某个神或组织名下"这件事。一条灵魂归谁——凡人手里是庇护（保命）、神手里是神力（立足）、混沌嘴里是食物（入侵）。谁掌握灵魂归谁，谁掌握费伦的现在与未来。这直接回看画像内核："如果灵魂失去庇护，那么一切争斗都变成抢庇护、抢灵魂"。

基石按"两侧对开"拆成两条链，每条链独立走完 基石→物资→对抗→养成线：

**链1 · 武力侧基石 = 灵魂产能（归属方向决定力量性质）**

- **总能源**：灵魂本身。灵魂挂靠给神 → 产出信仰力，是神术、圣力、神力的总能源（费伦本土武力）；灵魂脱挂 → 汇入灵魂洪流，是混沌灵能、恶魔之力、裂隙扩张的总能源（混沌武力）。双方的"打"共用同一个通货，归属方向不同，力量性质就不同。
- **稀缺守恒**：费伦灵魂总量大致守恒。挂靠给神的越多，神域负担越重（神吃信仰养神域，庇护却越来越薄）；脱挂的越多，混沌越强。此消彼长，中间是抢夺归宿权的战场——这是稀缺感与张力的来源。
- **跟画像内核一条呼应**：尽头是什么？灵魂产能够到极致 = 把整条费伦的"归谁"定死 = 立神位（灰烬之主，伟大神力），同时封死混沌的粮仓。

**链2 · 非武力侧基石 = 信仰锚定（归宿权的分配权）**

- **总能源**：归宿权的分配——谁掌握"灵魂归谁"这件事，谁掌握信众份额、圣契、受洗名额，即费伦的社会权力、财富、地位。教会是最大的庇护产业，贵族靠圣契称霸，凡人拿命换一次挂靠。
- **稀缺守恒**：庇护是配给制。受洗名额靠排队、圣水限量、信众份额靠抢——挂靠资格本身就是稀缺品。混沌侧的稀缺品是"无主灵魂"：谁能把别人的灵魂从归属里挖出来（契约/诱惑/腐化），谁就抢到粮。
- **跟画像内核一条呼应**：尽头是什么？归宿权够到极致 = 掌握整个费伦的灵魂归属 = 立神位。费伦诸神对神位的垄断，本质是对"最终归宿权"的垄断。

> 判断：基石回头看画像内核——"为什么这世界最抢的就是灵魂的归宿权"？答：信仰被蛀空，灵魂失去庇护，混沌顺着缺口进来——抢灵魂就是抢命、抢粮、抢未来。成立。

### 1.5 通则：爽文没有真代价（本案逐条过）

本案最高危的真代价区是"混沌腐化"（克苏鲁式越强越疯）。逐条审：

| 设计点 | 审法（读者感到更酷还是憋屈） | 本案处理 |
| --- | --- | --- |
| 混沌污染风险 | 越强越疯 = 憋屈，删 | 只做氛围/装扮级：主角越强越有不可名状的威仪与台词腔，画风变灰，本质无害 |
| 灵能不稳 | 短期受挫可化解 = 可控小摩擦 | 保留，限定为单场受挫、很快翻成爽点 |
| 信仰经济压榨 | 主角被异端追杀 = 剧情挫折 | 保留为"前倨后恭"的翻盘结构（卷内被追，卷末立神迹打脸），不写成真损失 |
| 抗腐化成长 | 正面成长，不是代价 | 从线C 写"意志从可侵蚀→不可腐化→反蚀"，全程是变强，不是失控 |

> 判据：本案没有不可逆堕落、没有损失核心资产、没有让读者憋屈的设定；腐化只做气氛和装扮。

### 4. 养成线：主 1 条 + 准主 1 条 + 从 3 条

硬规则：主养成线 1 条（骨架）+ 准主养成线（两侧对开都重要时非武力侧升格，v8.2）+ 从线若干（默认≥3）。每条占一个不同维度、跟别条不重叠、有独家成长方式、写清挂主线方式与对角。本案 5 条线维度：战力骨架（主）/ 资源地位（准主）/ 战力深化 / 心智 / 环境信息——五个维度全占，无重叠。

#### 4.2 准主线 · 信仰网络（资源地位，v8.2 升格）

**升格理由（老板拍板）**：本书两侧对开都重要——武力侧打穿到裂隙带（主线），非武力侧要撑到"立神位"结局（归宿权的分配权 = 费伦社会局）。信仰网络不是深化用的从线，是与主线并行的第二条骨架，升格**准主养成线**。

- 维度：资源地位（谁信他、谁供给他）。
- 成长方式：救人、立神迹、收信众、建庇护。
- 命名：复用 DND 声望/虔诚（Renown/Piety）的语言；档位：异端（无信者）→ 孤证（零星信众）→ 庇护者（一城）→ 圣者（费伦公认）→ 神选（神域承认）→ 神（立神位）。
- 挂主线：主线阶位越高，能立的庇护越强（信众才敢跟）。
- 对角：阶位高但无信众 = 孤军（无补给、无名声、被当异端）；信众多但阶位低 = 守不住（庇护薄，份额被抢）。
- **排期（v8.2 错开规则）**：每卷必升档；升档点与主线质变错开——主线质变在卷1/3/4/6/7/10，准主线主要升档落在相邻无质变卷（卷2/5/8/9 及其余卷内铺垫），不挤同一次质变点。档位与主角设计的金手指特殊养成系（灰烬锚定范围）对表：锚定范围 = 灵魂供给侧，信仰网络 = 信众侧，两者同源不同轨（见主角设计 §4）。

#### 4.2b 从线 3 条（各一维度）

**从线A · 灵能修为（战力深化）**
- 维度：战力深化（施法/灵能侧）。
- 成长方式：直面亚空间、净化混沌，灵能引导上限随主线升档而开。
- 命名：复用战锤灵能分级（低阶灵能→高阶→阿尔法→阿尔法加）。
- 挂主线：主线每升一档，可引导的灵能上限开一档（新兵只够护身，原体可撕裂裂隙）。
- 对角：阶位 = 近战骨架，灵能 = 施法爆发；灵能超标但阶位低 = 打得动恶魔、扛不住凡世军队；阶位超标但灵能低 = 抗得住砍、放不出大术。

**从线C · 意志与抗腐化（心智）**
- 维度：心智。
- 成长方式：直面混沌不被腐化、净化污染（灰骑士本职）。
- 命名：复用 DND 意志豁免 + 战锤圣焰/不可腐化；档位：可侵蚀 → 稳固 → 坚韧 → 不可腐化 → 反蚀（净化亚空间）。
- 挂主线：主线升档开抗性上限。
- 对角：阶位高但心志破 = 堕落（灰骑士堕落是最强恶魔）；意志强但阶位低 = 看穿混沌、打不过。

**从线D · 混沌知识（环境信息）**
- 维度：环境信息。
- 成长方式：穿越认知兑现（博德之门 3 剧情记忆，穿越自带、拍板保留）+ 实战调查（裂隙分布、四神锚点、神位博弈）。
- 命名：复用战锤恶魔学/亚空间学 + DND 知识检定；档位：剧情认知（地球记忆）→ 费伦实查（裂隙分布）→ 亚空间规则（四神领域）→ 神域机密（神位博弈）。
- 挂主线：越接近亚空间，知识越可用。
- 对角：知识多但战力弱 = 看穿了打不过；战力强但知识少 = 被奸奇算计。

#### 4.3 质变点对篇幅

- 主养成线可感知质变点 = 6 次（灰骑士阶内 3 次 → 原体 2 次 → 立神位 1 次），挂画像三层质变分布 3-2-1。
- 对齐卷数：7-10 卷 → N±2 区间 5-12，6 次在区间内。
- **准主线错开（v8.2）**：准主线（信仰网络）每卷必升档，质变/大升档与主线错开——主线质变卷1/3/4/6/7/10，准主线大升档放卷2/5/8/9 及相邻铺垫；一卷不同时双跳。
- 卷多时（9-10 卷）不硬凑层级：同一质变内用准主线升档/从线升档/同级换图填满。
- 卷分布参考：卷 1 新兵（醒来保命）→ 卷 2-3 骑士（守住一城）→ 卷 4 圣骑士（名动费伦）→ 卷 5-6 原体初成（裂隙带）→ 卷 7-8 原体巅峰 → 卷 9-10 灰烬之主（立神位）。

### 5. 命名规则：复用头部，不创新

- **复用（本案主基调）**：DND 阶位（1-9 阶 CR/1-40 级/传奇第 5 阶）、神力谱系（微弱→弱等→中等→强大→伟大）、职业等级、意志豁免、声望/虔诚；战锤灰骑士阶位（新兵→骑士→圣骑士→大导师→原体）、灵能分级、亚空间、混沌四神（恐虐/奸奇/纳垢/色孽）、恶魔学、圣焰。
- **借用（已拍板，不算自造）**："灰骑士原体"原作无此位阶，拍板为"灰骑士体系顶点位阶"借用概念；"灰烬之主"是用户原话。
- **缝合对表（不造词）**：灰骑士阶位 ↔ DND 数值层的对照见 §4.1 表，两套读者默认名互相对照。
- **零自造**：本案没有"读者没默认"的空白部位需要造词——两个赛道读者各有默认，拼接处用对表解决。

## ④ 产出SOP（本案逐条对照验收）

1. **查赛道定流派**：DND（费伦主盘）× 战锤 40K（灰骑士/亚空间）双体系缝合，查赛道库 DND 行（力量可量化/神力谱系）+ 调研文档补战锤灰骑士背景。
   → 验收：过。读者默认骨架拿准（DND 阶位/CR/神力谱系；战锤灰骑士阶位/灵能/混沌四神）。
2. **从画像内核点名基石**：画像点名"灵魂的归宿权（信仰锚定）"，本案两侧对开成两条链（武力侧 = 灵魂产能，非武力侧 = 信仰锚定分配权）。
   → 验收：过。基石能回头看画像内核解释"为什么最抢它"；不是自造词。
3. **拆物资**：两条链各拆凡/珍/禁三档物资，高档初期拿不到。
   → 验收：过。能列出具体物资（圣水/圣物/恶魔契约/信众份额/圣契），不是空泛能量。
4. **铺对抗（v8 硬规则）**：武力侧写纲要（4 套战斗玩法，指向《战斗系统-SOP》），非武力侧写满（4 套社会对抗，信仰/灵魂这条线），每套写满四件事、都有对应养成线。
   → 验收：过。两侧都有；无空玩法。
5. **设养成线**：主 1（灰骑士阶位）+ **准主 1（信仰网络，升格理由 = 撑到立神位结局）** + 从 3（灵能修为/意志抗腐/混沌知识），各占一个维度、不重叠、有独家成长方式、写清挂主线与对角；每条对抗都能挂到线；**金手指刻度（灰烬锚定/原体之路）不写进本篇，指针给主角设计**。
   → 验收：过。主 1+准主 1+从 3；维度无重叠；对抗全有线；本篇零金手指刻度。
6. **篇幅核对**：6 次大质变对齐 7-10 卷（N±2 = 5-12），挂 3-2-1 分布；**准主线大升档与主线质变错开（卷2/5/8/9 等）**；卷多时用准主线/从线升档、同级换图填。
   → 验收：过。主/准主质变不错开不挤；不在段落硬凑层级。
7. **命名复用**：DND/战锤读者默认名全复用，缝合处用对表，零自造；灰骑士原体 = 借用概念（已拍板），灰烬之主 = 用户原话。
   → 验收：过。命名全复用；无读者认不出的生造词。
8. **收束世界机理**：基石（灵魂归宿权）回看画像内核一条（信仰被蛀空→灵魂失庇护→混沌入侵）；敌人（混沌）与主角共用同一套法则（腐化深度 = 意志抗腐的镜像，混沌武技挂线）。
   → 验收：过。不是孤立设定；敌人强 = 某项线超标 + 他项短板，不是"敌人不用这套"。
9. **爽文无真代价**：逐条审过（§1.5），腐化只做氛围/装扮级，无不可逆堕落、无损失核心资产、无憋屈。
   → 验收：过。
10. **金手指不越位**：灰烬之力只写"例外资格"占位（对信仰锚定这套系统的例外，例外环节暂定获取环节），机制全留给《主角设计》——主角设计里它作为**金手指特殊养成系（原体之路）**显式声明。
    → 验收：过。本篇零主角独有机制。

## 本次实测结论（对照《世界法则.md》待处理问题逐条）

| # | 待处理问题 | 本案结论 |
| --- | --- | --- |
| 1 | 从线"默认≥3但以够支撑对抗为准"是否过宽/过严 | 本案 8 套对抗、5 条养成线，靠"多条对抗共挂一条线"解决（信众争夺/信仰经济/异端审判三套社会对抗共挂信仰网络线）——从线不必 = 对抗数，一条线可支撑多套同维度对抗。新问题：一条线挂太多对抗会不会过载？本案 3 套共挂一线靠"同维度不同玩法"不重叠，但阈值未量化。建议判据补一句"一条线挂多套对抗时，查这些对抗是否同维度、玩法是否重叠，重叠则拆线"。 |
| 2 | 「爽文无真代价」判据够不够机械 | 本案判据能用：混沌腐化是克苏鲁式真代价高危区，判据拦住了——抗腐化写成正面成长线，污染只做氛围/装扮级。本案给出可操作的切分：真代价 = 损失已到手资产/不可逆/让主角变弱；氛围级 = 只改观感（画风/称号/台词）不改战力。建议把这条切分写进判据。 |
| 3 | 命名"复用 vs 自造"的空白触发器判定 | 本案是缝合题材（西幻 DND × 战锤 40K），实测答案：缝合处读者默认两套都有，拼接不触发自造，用"对表"（双体系默认名互相对照）解决；"灰骑士原体"原作无此位阶，由用户拍板"借用概念"，仍不算自造。全程零自造。建议判据补一句"缝合题材拼接处默认用对表，不触发自造；两赛道读者都没默认且用户点名要新意才自造"。 |
| 4 | 战斗系统拆《战斗系统-SOP》后的衔接 | 本案按拍板不单独产战斗系统文档，武力侧在法则写纲要（4 套玩法写满四件事但简写），细节留给后续《战斗系统-SOP》。切分边界实测清楚：灵能战/神术战这类带超自然能量的玩法，判为战斗系统（人人可练：夺心魔有灵能、牧师有神术），不是金手指；金手指（灰烬之力）= 对"灵魂归属权"开例外的资格，剥离回主角设计。边界判据可用"是否人人可练"：是 = 战斗系统，只有主角能 = 金手指。建议固化这条判据。 |

**新发现的问题（本案新开）**：
- **缝合对表已落地**：画像待处理问题里的"跨体系缝合档位对表"（DND 神力谱系 × 灰骑士体系）在本案 §4.1 给出答案（新兵≈1-10 级 → 圣骑士≈传奇第 5 阶 → 原体 = 半神 → 灰烬之主 = 伟大神力）。建议《世界法则.md》把"缝合对表"补成一步（双体系读者默认名互相对照，不造词）。
- **准主养成线升格（v8.2 首测）**：本案信仰网络从"从线B"升格"准主养成线"（老板拍板：两侧对开都重要、非武力侧要撑到立神位结局）。实测判据可用：**非武力侧是否撑得起一路到结局的结局（立神位）→ 升准主线**。排期错开规则（主质变卷1/3/4/6/7/10，准主线大升档卷2/5/8/9）可执行。密度标准（准主线每卷升几档不腻）待卷级结构回填。
- **金手指特殊养成系（v8.2 首测）**：灰烬锚定/原体之路在主角设计 §4 显式声明为独立养成系（锚定范围 6 档扩容 + 与主线 6 质变对表），本篇只出指针、零越位。剥离边界（"是否人人可练"：灰骑士阶位名号版 = 只有主角能走，DND 职业等级 = 人人能走）实测清晰。
- **主线质变 6 次对上 7-10 卷的边界**：N=7 时 6 次质变偏紧（区间下限 5）、N=9-10 时偏松（区间上限 12）。本案用"从线升档/同级换图填"兜住，但"质变少卷多"的填充密度没有量化标准，留待后续案子。
- **金手指剥离的完整链跑通**：《世界法则-v5》未实测清单标的"金手指剥离后归主角设计的衔接"在本案第一次整体跑通——法则只写例外资格占位（对哪套系统例外、例外在哪一环暂定），机制与成长挂点全指向主角设计（特殊养成系声明），无越位。
