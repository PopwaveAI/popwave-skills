- **角色**：锁根。链路第一步。
- **回答的问题**：这是一个什么样的世界？（读者闭眼能想象出主角生活的世界样貌）

## ② 思考逻辑

**本案的推演线（从硬约束长出来，不是堆形容词）**：

硬约束两条（需求卡拍板）：
1. 混沌以"信仰/灵魂洪流撕开亚空间裂隙"的方式入侵，诸神不能直接下场。
2. 费伦刚熬过至上真神危机，信仰体系被蛀空。

从这两条倒推：
- 混沌的食物是灵魂与情感（亚空间本质）。
- 诸神不能下场 → 凡间唯一能挡混沌的防务 = 信仰（神透过教会递出神术与庇护）。
- 信仰被蛀空 → 灵魂失去庇护 → 混沌有粮可吃、有门可进。
- 结论：这世界最被抢的东西 = 灵魂的归宿权（信仰锚定）。三方抢同一个通货：凡人抢"死后有人收"，神抢"信徒信仰"，混沌抢"无主灵魂"。

再让画面全从内核长出来：
- 壳（画面）= 信仰经济运转的剑湾 + 裂隙爬墙的夜晚。
- 各阶层日常 = 谁掌握庇护，谁掌握命（信仰是活着的保险，不是死后的安慰）。
- 危机 = 旧失衡（信仰空壳，被和平压着）被新失衡（混沌裂隙）撕开，且两条失衡同源（灵魂这条线的一体两面）。
- 三层地图 = 从内核层级往里推：凡世（抢庇护的战场）→ 裂隙带（诸神与混沌隔着玻璃打架）→ 亚空间（真相层，灵魂的归处）。

> 判据：读者读完后，能模仿"先定量级 → 挖壳到内核 → 环着内核展开三支线 → 三层从内核往里推"这套思路。

## ③ 文档内容

### 第0步 · 物理范围（先定量级，再画任何画面）

**一句话**：主盘是整颗托瑞尔星球（费伦大陆 + 周边大陆），叠加位面体系（外层位面诸神国度 + 亚空间裂隙网络）——星球级起步，复合世界群上限。

**双查（量规表 + 赛道库）**：
- 量规表：篇幅 200-300 万字 → 下限"至少星球/多元"。本案 = 星球（托瑞尔）+ 位面体系（裂隙/亚空间/外层位面）= 复合世界群，过下限。
- 赛道库 DND 行：读者默认世界规模 = "多大陆/多王国 + 位面体系（主物质位面之外有元素位面、外层位面）"。本案主盘费伦 = 多大陆/多王国，外层位面与亚空间 = 位面体系，默认规模过。

**配得上终点**：全书终点是伟大神力「灰烬之主」把混沌钉死在费伦之外——终点是"封死亚空间裂隙、在神系里立起新神位"，范围上限（亚空间/神域）装得下。

**有真实纵深**：主角活动半径有梯度——剑湾一城起步 → 费伦大陆 → 位面裂隙带 → 亚空间。

### 第1步 · 壳（表）

- **时代基调**：中世纪魔幻（DND 费伦的剑与魔法）+ 战后凋敝（至上真神危机刚过，胜利的余烬还没凉）。
- **主要风貌**：剑湾城邦冒险 + 信仰哥特（神殿、圣像、钟声）+ 亚空间侵蚀的暗黑底色（裂隙处一切开始"不对"：影子变形、水尝起来有铁锈味、梦开始串门）。
- **世界色调**：沉金灰——白昼的剑湾是暖金色冒险调，黄昏起蒙一层灰（信仰空壳的压抑）；夜晚裂隙处是腐烂的紫黑。
- **一句话关键词**："信仰蛀空、裂隙爬满星空的剑与魔法费伦"。

> 定调作用：主角的灰骑士铠甲（不属于这个世界的冷金属）在沉金灰的画面上自带反差——凡间的暖金不认识它，裂隙的紫黑认得它。

### 第2步 · 内核（里）★深挖到底

**总命题（如果X那么Y）**：如果灵魂失去庇护（信仰锚定断了），那么一切争斗都变成抢庇护、抢灵魂——凡人抢"死后有人收"，神抢"信徒信仰"，混沌抢"无主灵魂"。

**推演到三层**：
- 社会层：教会是最大的庇护产业。神术、圣水、临终祈祷全是商品；信徒 = 有主的灵魂，异端/无信者 = 无主可夺的灵魂。一个人的社会身份 = 他死后归谁（墓碑上刻神名，跟刻家族名一样重要）。
- 经济层：信仰经济（什一税、赎罪券、圣物交易、净化裂隙的悬赏）vs 混沌黑市（灵魂契约、恶魔担保、污染神术的走私）。两边抢同一个货：灵魂。
- 文化层：多神信仰退化成"信什么都行，只要有东西肯收我的灵魂"。墓地与葬礼成为奢侈品（没人庇佑的尸体，葬了也会被挖出来——混沌要的是灵魂，尸体只是包装）。

**合格线三问（每条答得出）**：
- 白天/夜里的城市：白天神殿钟声、裂隙净化队出城、商队在城门口排队领庇佑印记（灵魂税）；夜里家家门窗紧闭、祈祷声此起彼伏（不是虔诚，是保险）、城墙上火把通明（变异生物和"影子不对"的人）。
- 富人和穷人在抢什么：富人抢"庇护份额"（更多信众、更强的神殿契约、确定死后归宿）；穷人抢"一次锚定"（今天的神术庇佑印记、孩子的受洗名额——名额靠排队，不靠买）。
- 一场战争为谁而打：表面是王国/教派冲突，底下是抢"信众份额"——打下对方的城 = 对方的信徒改信 = 灵魂改归本方神系；混沌混在战争里吃情绪（战争喂养恐虐）。

**最被抢的东西（点名，交付给世界法则当基石）**：

> **最被抢 = 灵魂的归宿权（信仰锚定）。** 一条灵魂归属谁，决定了它是庇护（凡人手里的）、神力（神手里的）还是食物（混沌嘴里的）。谁掌握灵魂的归宿，谁就掌握费伦的现在与未来。

### 第3步 · 独特点（奇）

**万物绕不开的蹊跷规则**：信仰锚定（设定概念，指"灵魂挂靠某个神/组织名下"这件事，不是判断词）在这个世界是活着的必需品——不是死后安慰，是活着的防务。没有锚定的灵魂 = 混沌的活靶子。

**最记住的一个画面**：一个人跪在神殿里反复祈祷，神术毫无回应；他的影子在烛光下慢慢变形——祈祷失灵的那一刹那，混沌先啃的不是身体，是影子（灵魂的投影）。

**名片一句话**：这是"剑与魔法 × 信仰体系蛀空 × 亚空间侵蚀"的费伦——一套"没有信仰锚定，灵魂就会被吃"的规则。

### 第4步 · 代价 / 各阶层日常（痛）

**世界级代价**：凡人的强（神术、神力、庇护）靠烧信仰维持，而信仰总量在被蛀空——神吃信仰养神域，庇护却越来越薄；混沌吃灵魂涨裂隙。整颗星球的"强"是负资产：你越依赖神，神的负担越重；你不依赖神，你裸奔给混沌。

**各阶层日常（写"一天"，不写抽象规则）**：
- 顶层（大祭司、家族贵族）：把庇护当特供。家族世代持有"守护神契约"，一个城市的信众份额归哪个神殿，决定神术赐予额度。贵族的一天：早上确认家族圣契完好（圣契裂 = 家族败），中午和教廷谈"把东城区的人心划过来"，晚上审一个"死后想换神"的叛徒——叛徒是重罪，因为灵魂改挂 = 家族资产流失。
- 中层（冒险者、商人、小神殿牧师）：冒险者被教会雇佣净化裂隙，拿命换圣水配额（圣水限量，队伍里谁分得多谁说了算）；商人在信仰经济里两头倒——一边卖圣物，一边走私"来路不明的灵魂契约"（买家是怕死的富户，卖家是混沌黑市）。
- 底层（农民、城市贫民）：信仰是奢侈品。穷人的孩子排不到受洗名额 = 灵魂没上锚 = 活着的靶子；"一日祈祷三次"是保险不是虔诚。渔夫的一天：天不亮去神殿门口排队领庇佑印记（圣水沾额，临时锚定），打鱼回来发现隔壁铺子老板昨晚死了、尸体没人敢埋（没有牧师肯做葬礼，怕脏了神殿），夜里全城戒严——城墙上又爬满变异海鸥。

**三层规则（明/潜/禁）**：
- 明（公开秩序）：诸神庇佑世人，教会代行神意，信仰是美德。
- 潜（不可言说的阶层利益）：庇护是配给制——信众份额、受洗名额、圣水配额全是特权，教会靠稀缺赚钱，贵族靠份额称霸。
- 禁（触碰即毁灭的红线）：改信（灵魂改挂别的神）是重罪；碰混沌的东西（哪怕为防身碰一点污染神术）是死罪——但黑市一直在卖。

### 第5步 · 危机（破）★本书最关键

**旧失衡（被压着的那层，本来就在）**：信仰体系空壳化。至上真神危机以惨胜收场：信徒凋零、神殿冷清、祈祷越来越没回应。表面和平，可感知的是——灵魂失去庇护，凡人不再指望神。这是制度性的病态，一直被"胜利的余烬"压着，没人烧穿它。

**新失衡（撕破的那层，新事件）**：亚空间裂隙在费伦撕开。混沌以信仰/灵魂洪流渗透——小镇一夜之间全员疯癫、剑湾城头爬满非费伦形态的怪物、夺心魔的灵能网络失灵并被腐化。诸神不能下场，神术被混沌污染，凡间没有一支力量能正面挡恶魔。旧秩序不是被强攻击垮的，是被"侵蚀"瓦解的——祈祷失灵比刀剑更快摧毁防线。

**双失衡同源（故事脉络伏笔，画像确认）**：亚空间的食物正是灵魂与情感。信仰崩塌让灵魂失去庇护，混沌才吞得下——两条失衡是同一根源（灵魂这条线）的一体两面。旧失衡蛀空了粮仓，新失衡的野兽顺着粮仓的门进来。

**会炸开的开关（动态，不是坏掉的状态）**：裂隙从"渗透"进入"合拢"——四神在费伦的锚点一旦连成网络，就从"侵蚀"翻成"吞食"：诸神的神域被亚空间反噬（神也会死），凡间彻底失去庇护。开关的发动时机 = 锚点网络连成；后果 = 混沌降临、神系坠落。全书倒计时挂在这上面。

### 第6步 · 隐喻（厚，自选）

**这世界在影射现实什么**：信仰锚定 → 现代人的意义感与归属感。旧信仰（传统价值、共同体）崩塌后，失去意义锚点的人，被极端化情感（愤怒/欲望/虚无/狂热——混沌四神）捕获。诸神不能下场 = 旧秩序无法直接干预个体生活，只能透过中介（教会/机构）递出力量，而中介会腐化。费伦人拼命"抓住一个神名" = 现代人拼命"找一个东西信"，不然就被巨大的虚无吞掉。

### 三层地图（世界本体结构）

**总规则**：三层不是同一颗星球的上下层，是三个独立大世界。判据：每层有自己的物理法则或地理隔离、自己的居民、自己能捞的资源；层与层之间靠"质变"通行——主角在凡世升到凡俗之巅，才进得了裂隙带；在原体阶站稳，才进得了亚空间。质变分布 3-2-1（第一层3次、第二层2次、第三层1次，挂在灰骑士→原体→神力的养成线上）。

#### 第一层 · 主地图＝凡世费伦（主物质位面）

- **地图身份**：主地图。托瑞尔星球上的费伦大陆。
- **地理构成**：剑湾城邦带（博德之门、深水城、无冬城——冒险主舞台、信仰经济中心）；内陆谷地（精灵与半身人聚落，田园但凋敝）；绝境东域（沙漠蛮荒，裂隙的偏远针眼）；星球其余大陆（卡拉图等，为后舞台，卷级外扩用）。
- **活跃强者档位（骨架，数值归世界法则）**：凡俗士兵 → 传奇（第5阶，凡人之巅）；地表顶端是 9 阶生物（上古龙、远古恶魔）。混沌代理人：腐化信徒、夺心魔余孽、恶魔领主前锋。主角在此层处于灰骑士阶（层内顶端战力）。
- **特殊地点**：博德之门（信仰经济最密，第一处裂隙针眼所在地）；深水城（神殿最集中，庇护最贵）；绝境东域的沙漠神殿（混沌四神最早的锚点）；至上真神危机留下的主脑残骸（夺心魔余孽巢穴）。
- **质变分布**：3次（灰骑士阶内三段：醒来保命 → 守住一城 → 名动费伦）。

#### 第二层 · 中层＝裂隙带与神域边缘（位面交接带）

- **地图身份**：中层。它不是完整世界，是位面之间的交接带（实测判据：中层允许是交接带，判定落在"是否有独立可捞的东西"，不落在"是否是完整世界"——见本次实测结论第3条）。
- **地理构成**：至上真神危机留下的位面裂隙网络（星界半位面、破碎灵界通道）；外层位面诸神国度的门槛（诸神不能下场，但透过裂隙递出力量）；亚空间裂隙的活体延伸（混沌在费伦的锚点网）。
- **活跃强者档位（骨架）**：凡俗传奇巅峰 → 半神/原体阶。恶魔领主（中阶）、被污染的神使。主角在此层处于灰骑士原体阶。
- **特殊地点**：裂隙主针眼（剑湾地下的第一条裂隙，全书的开关所在）；诸神门槛（神力递得最近的位置——诸神和混沌代理人隔着玻璃打架）；堕落的至高神殿（至上真神危机遗留圣所，被亚空间改造成混沌据点）。
- **质变分布**：2次（晋升原体的两步：原体初成 → 原体巅峰）。

#### 第三层 · 下层＝亚空间（混沌四神领域）

- **地图身份**：下层。不是地理意义上的地底，是因果意义上的底层——现实是表层，亚空间是现实的底层，灵魂与情感的归处。
- **独立大世界判据**：亚空间没有方向、没有昼夜、没有常理，居民是恶魔（不吃不喝不繁衍，只存在），生态是灵魂与情感——它不可能是费伦的副本。
- **地理构成**：四大领域各占一块——恐虐的血神荒原、奸奇的万变迷宫、纳垢的腐败花园、色孽的欢愉迷宫；领域之间互相征伐。裂隙越多，亚空间与现实越贴合。
- **活跃强者档位（骨架）**：原体巅峰 → 强大/伟大神力（混沌四神本体、费伦诸神本尊、灰烬之主立神位处）。主角在此层从原体巅峰登临伟大神力「灰烬之主」。
- **特殊地点**：四神领域（四块独立，互相征伐）；灰烬王座区（主角最终立神位处——把混沌钉死在费伦之外）；诸神坠落之地（被亚空间反噬的旧神，神域沉入亚空间的残骸——旧失衡的终局画面）。
- **质变分布**：1次（立神位/伟大神力，全书终点）。

### "最被抢的东西"（一句话，交付给世界法则）

> **灵魂的归宿权（信仰锚定）。** 一条灵魂归属谁——凡人、神、混沌三方抢的是同一个通货；混沌靠它入侵（无主灵魂是入口与粮食），诸神靠它立足（信仰是神力来源）却不能下场（主物质位面的规则锁死神体）。世界法则的基石从这个名字里长出来。

## ④ 产出SOP（本案逐条对照验收）

1. **选轨**：强世界观（DND×战锤双体系缝合，世界在推人）→ 走完整链表，不走弱轨。
   → 验收：过。六步全填，未硬套弱轨。
2. **查赛道**：查赛道库 DND 行——读者默认力量可量化（等级+CR）、有神力谱系、世界规模=多大陆+位面；缝合的战锤灰骑士体系查 40K 灰骑士背景（灰骑士=全员灵能的恶魔猎人，原体=基因原体顶点，混沌=亚空间四神）。
   → 验收：过。复用 DND 的"力量可量化+神力谱系"骨架，灰骑士体系作为主盘之上的缝合层。
3. **定物理范围**：双查量规表（200-300万字 → 至少星球/多元）与赛道默认规模（多大陆+位面体系）。本案=星球+位面=复合世界群，上限装得下终点（封死裂隙、立神位）。
   → 验收：过。过量规下限，范围配得上终点。
4. **定调挖到底**：从硬约束（混沌靠信仰/灵魂入侵、诸神不能下场）倒推内核=灵魂归宿权；画面（壳）、三支线（独特点/各阶层日常/危机）、隐喻全从内核长出来；危机分新旧双层且双失衡同源。
   → 验收：过。内核挖到因果链，不是表面风貌；"最被抢"一句话已点名。
5. **定世界本体结构**：三层=凡世费伦/裂隙带/亚空间，质变分布 3-2-1。第三层亚空间是独立大世界（不同物理法则/居民/生态）。
   → 验收：过。第三层不是副本；每层有顶端强者/中层精英/底层背景。
6. **逐层填基本设定**：每层写地理构成+活跃强者档位（骨架）+特殊地点。
   → 验收：过。每层能读出"几张图、谁在这层、哪个最险、能捞什么"。
7. **"最被抢的东西"一句话**：灵魂的归宿权（信仰锚定），与信仰/灵魂线呼应。
   → 验收：过。已点名，作为世界法则基石输入。
8. **收尾验收**：读者能闭眼想象费伦画面 ✓；知道最抢什么（灵魂归宿权）✓；分清旧失衡（信仰空壳）与新失衡（混沌裂隙）✓；物理范围过量规 ✓；第三层是独立世界 ✓。
   → 验收：全过。可落地，不是套壳。

**新发现的问题（本案新开）**：
- **跨体系缝合的档位对表**：DND 神力谱系（微弱→伟大）× 战锤灰骑士体系（灰骑士→原体→神）如何互相对标，是画像与法则之间的新接口。画像只给骨架（档位归法则），SOP 里没有专门一步处理"双体系缝合"的对表。建议《世界法则》立项时补。
