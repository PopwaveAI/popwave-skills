## ① 文档定位（谁挡在终点）

**本份是什么**：灰烬之主这书"挡在欲望串终点的人"——只立挡路的层级（终敌 1 人＋卷敌每卷 1 人），其余敌人归展开。它不写势力（那是顶层势力），不写动机成因（那是世界历史），只写"谁守着终点不让、他凭什么守、为什么非守不可"。

- **角色**：骨架。主角立住后，反派对着主角立。
- **回答的问题**：谁挡在终点？他凭什么挡得住？为什么非挡不可？
- **链路位置**：④ 的最后一环（世界画像 → 世界法则 → 世界格局 → 主角设计 → **主要反派**）。
- **依赖**：主角设计（欲望串/阶位线）、顶层势力（反派站在哪家顶端）、世界法则（敌人也走同一套法则）、世界格局（卷推进表）。产出供 卷纲 使用。
- **一句话落点**：能一句话讲清"谁挡在终点、他凭什么挡得住、为什么非挡不可"。

它不是：
- 不是**敌人目录**（每卷的小怪列表——次级敌人归展开）。
- 不是**脸谱库**（"坏人=凶恶"——每个卷敌都过三问）。
- 不是**主角的影子**（反派有独立欲望——不挡主角他也干自己的事；卷7堕落残影是刻意镜像，属8型"悲剧"的极端样本，见实测结论）。

> 判据：读完①，读者知道"这份管谁挡路"，不知道"怎么填"——怎么填是②。

## ② 思考逻辑（本案的推演线）

**这条推演线（agent 最该掌握）：反派 = 欲望对立的人——对着主角的欲望串找终点，立"守住终点的那个人"，过三问，8型对号，禁降智，敌梯分层。**

本案推演线（从硬约束长出来）：

1. **回读主角欲望串**：活下去 → 守住费伦 → 查混沌源头 → 晋升原体 → 立成灰烬之主（收全费伦灵魂归宿权、重建信仰、封死裂隙）。终点 = 立神位。
2. **对终点找守门人**：谁守在终点？《顶层势力》已定终局对撞 = 四神本体（正面）＋神位垄断（制度面）。正面 = 混沌四神中盯上主角的那位（奸奇）；制度面 = 诸神中敌视外来神的那位（莎尔）。穿越布局是钩子，不是对撞方；奸奇是候补之一（不定死，卷级揭开）。
3. **过三问（每个卷敌都过，不只终敌）**：有独立欲望吗 → 有（教宗守配给制、审判长烧异端、血颅要血——不挡主角他们也照干）。行为能从欲望推出来吗 → 能（每个行动都有欲望做底）。冲突有必然性吗 → 有（主角立神位 = 搬空四神粮仓＋破神位垄断，欲望直接对立）。
4. **8型对号**：终敌奸奇 = 幕后（存在型反派的"人形化"处理，见实测结论）；卷敌逐一对号（伪善/魅力/纯恶/执念/悲剧/幕后轮换）。
5. **禁降智**：主角赢卷敌 = 某项养成线超标＋敌人项短板（世界法则通则），每卷写出具体挂点；敌人不犯蠢（卷7残影无独立意志 = 豁免样本，不是降智）。
6. **敌梯分层**：终敌立骨架，卷敌立到"够排这一卷"（卷敌卡5件套各一行，不写小传）；次级敌人归展开。

> 判据：读的人能模仿"对欲望串找终点 → 过三问 → 8型对号 → 禁降智 → 敌梯分层"这套思路，换题材照推。

## ③ 文档内容

### 1. 终敌卡片（1人）

**反派名：奸奇（万变之主，混沌四神之谋划）——四神中盯上主角的那位**

- **【欲望】** 吞下费伦的信仰真空——谁先吞下费伦，谁在亚空间四神互斗中占上风。独立欲望成立：不挡主角，他也布万局、换棋子、在四神互斗里算计另三神；费伦只是他桌上的棋盘之一。
- **【8型】** 幕后（兼存在型变体：四神本体是情感洪流的人格化，不是"人"——用"幕后"对号立住谋划者人格，存在性写进压迫感与终局）。
- **【行动逻辑】** 目标：连成锚点网络（侵蚀→吞食的开关）、抢在另三神前吞下费伦、把"灰烬之主"立神位拖死在神位博弈里。手段：借代理人网（腐化信徒/夺心魔余孽/恶魔军团）执行凡世渗透；借教廷掩盖裂隙消息拖延恐慌；借诸神不敢下场与神位垄断挡主角；布穿越局（主角为什么穿越、裂隙坐标谁刻的——钩子，候补之一，卷级揭开）。代价：亲自下场 = 神力分流进主物质位面 = 给另三神可乘之机（四神互斗，谁先下场谁被咬）；锚点被净化一段 = 粮仓断一口；信仰真空被主角填回 = 费伦这盘棋永远吃不到。
- **【压迫感】** 强大神力级（神力谱系顶点档），亚空间四域之一的主人。不是喊"他很强"，是对位：主角原体巅峰才"可战"四神大魔，本体 = 打不死只能封；他隔着亚空间看得见费伦每一步（万变），主角救的每一批灵魂都在跟他抢粮，主角打的每个代理人都只是他的弃子——压迫感来自"永远慢他半拍的棋局"与"打赢了也只是封"。对应养成线档位：主线灰骑士阶位第6档（灰烬之主）才能终结他；从线D（亚空间规则知识）＋从线C（不可腐化）是近身他的门票（对齐格局越级赢挂点卷8-9）。
- **【必然冲突】** 主角欲望串终点 = 立神位收全费伦灵魂归宿权、封死裂隙把混沌钉在费伦之外。奸奇要 = 吞费伦信仰真空、连成锚点网络。主角立神位 = 把费伦灵魂收归自己名下 = 搬空奸奇的粮仓；封死裂隙 = 奸奇永远吃不到费伦。对立点：他吞、主角守；他靠灵魂无主，主角靠灵魂有主。主角"查混沌源头"查到四神 = 查到他头上——冲突双向成立，不是碰巧挡路。
- **【降智检查】** 主角赢他（卷8-10）靠：从线D超标（亚空间规则知识：知道四神领域规则、知道封裂隙的方法——认知红利兑现）＋从线C（不可腐化 = 封裂隙的资格）＋从线B（神选级庇护网络供能）＋从线A（阿尔法级灵能）。奸奇短板：不能下场（只能透过锚点/代理人伸手）、被另三神牵制（互斗消耗）、粮仓被搬空 = 力量源头被掐。他不是犯蠢，是结构性短板被主角抓住：主角每收一批灵魂，他弱一分。赢得有代价：卷8-9硬闯四神领域、卷10立神位前夜的神位博弈、封裂隙时直面亚空间意志反噬（氛围级）——代价是过程，不是损失。

### 2. 卷敌（每卷 1 人，10 卷版）

卷敌 = 该卷挡路的主要敌人，立到"够排这一卷"（卡5件套各一行，不写小传）。档位对齐灰骑士阶位线逐档递进。7 卷版合并见 §3 表后说明。

**卷1 · 异端审判长·格雷戈里（教廷·执行层顶端）**

- 【欲望】守住灵魂归属的分配权——"灰骑士"这个不受神管束的异端多活一天，配给制就漏一天。不挡主角他也天天烧异端（这是他的职业）。
- 【8型】伪善（嘴上"为费伦烧死异端"，实际为配给制守住权柄）。
- 【行动逻辑】目标：把灰骑士定罪烧死。手段：追捕令、异端指控、雇冒险者公会猎杀、掩盖裂隙消息（怕恐慌）。代价：神术通道在漏，他越用力越漏。
- 【必然冲突】主角要活＋灰骑士本职（净化混沌）＝教廷认定的异端。他追、主角躲，职业对立。
- 【降智检查】主角靠从线D（知道教廷程序漏洞、知道针眼在教区地下——教廷越掩盖越被动）＋从线C（不被腐化）。格雷戈里短板：教廷改革派掣肘＋神术通道被污染（他用的力量在烂，不是他算错）。

**卷2 · 腐化传道者·洛蕾娜（混沌代理人网·色孽系）**

- 【欲望】把无主灵魂从信仰蛀空处挖走——传"救赎"话术让活人自愿改挂（灵魂脱挂＝混沌的粮）。不挡主角她也照常经营"灵魂生意"。
- 【8型】魅力（以"救赎者"面目出现：漂亮、温柔、话术成套）。
- 【行动逻辑】目标：内陆谷地这一片的灵魂份额。手段：教义话术、伪造圣契、把改信者喂给裂隙。代价：色孽契约反噬（她自己也悬在契约上）。
- 【必然冲突】主角把灵魂收留挂到自己名下＝直接抢她的粮；主角认得出她的仪式（从线D）。
- 【降智检查】主角靠从线D（认出混沌仪式、识破话术）＋从线B（救下的孤儿与底层成为第一批信众，庇护直接给、不经过她）。洛蕾娜短板：依赖信仰蛀空（粮是"借"来的，主角一立庇护她就断供）。

**卷3 · 恶魔军团前锋统领·卡拉克·血颅（混沌代理人·恐虐系军事执行面）**

- 【欲望】血——用费伦的血喂恐虐，把博德之门打成恐虐的军功。不挡主角他也照常屠城。
- 【8型】纯恶（战争本身，无多余动机）。
- 【行动逻辑】目标：攻下博德之门。手段：恶魔军团正面强攻、血祭破城防。代价：恐虐恩赐是双刃（越杀越强也越疯）。
- 【必然冲突】主角要守住博德之门（保住信仰经济中心＝保住自己翻身的根基）。
- 【降智检查】主角靠从线B（第一批信众供庇护补给）＋从线A（灵能爆发清场）。血颅短板：恐虐系只信正面强攻、不会变招，主角用庇护网＋灵能绕开他的强项。

**卷4 · 教宗·赫尔曼（教廷顶端）＋层底Boss·恶魔领主前锋·莫拉格·燃狱**

- 【欲望】保住配给制（权柄与收入的来源）——主角名动费伦＝信仰经济从教廷漏走。不挡主角他也守他的配给制。
- 【8型】伪善（公审定罪说"为费伦"，实际为配给制守门）。
- 【行动逻辑】目标：公审把灰骑士定罪、杀一儆百。手段：异端审判公审、三大神殿共治背书、神迹展示压场。代价：公审失败＝教廷名誉崩（他赌信仰空壳还能撑）。
- 【必然冲突】主角立神迹（庇护一城）＝活神殿绕过教廷＝配给制守门人地位被戳穿。
- 【降智检查】主角靠从线D（识破教廷伪证、神术在漏的真相）＋从线C反蚀（净化锚点当众立神迹）。赫尔曼短板：信仰空壳——配给制靠稀缺撑着、底子被蛀空，一戳就破。他输在制度本身在烂，不是个人犯蠢。
- 【层底Boss·莫拉格·燃狱】（卷4质变验证战，战斗细节归卷纲/战斗系统）：绝境东域锚点战，9阶生物（层内战力顶点）。主角靠从线D（知道锚点网络结构，提前切断）＋从线C反蚀（净化锚点）。燃狱短板：依赖锚点网络，网络被切断＝断供。

**卷5 · 瘟疫领主·格罗图斯（纳垢系·裂隙带中阶）**

- 【欲望】把裂隙带烂成纳垢的花园——无主灵魂在腐朽里慢慢烂进纳垢的领域。不挡主角他也照常腐化裂隙带。
- 【8型】纯恶（腐败本身）。
- 【行动逻辑】目标：把裂隙主针眼周边腐化成疫区、阻断净化队。手段：瘟疫、腐化孢子、把迷失灵魂沤成纳垢粮。代价：纳垢系慢性——腐化要时间，被净化就打回原形。
- 【必然冲突】主角要净裂隙带（卷5-6质变4：锚定裂隙带——混沌的粮变成他的粮）。
- 【降智检查】主角靠从线A（灵能净化）＋从线C（不可腐化）。格罗图斯短板：慢性腐蚀怕快净化——主角净化速度快于腐化速度，他耗不起。

**卷6 · 恶魔领主本体·奈克罗·噬魂（混沌执行面顶端）**

- 【欲望】守住裂隙主针眼与堕落至高神殿——四神共推的执行者，吞食开关的看门人。不挡主角他也守关。
- 【8型】纯恶（守关的吞食机器，无个人恨意）。
- 【行动逻辑】目标：挡住任何净化裂隙主针眼的力量。手段：亲自坐镇堕落圣所、吞灵魂补强、调四神各派恶魔。代价：在凡世是"客场"，离开亚空间补给线越打越弱。
- 【必然冲突】主角卷6升原体（质变4达成）＝要封印裂隙主针眼＝直接夺他的关。
- 【降智检查】主角靠从线B（神选级庇护网络供能）＋从线A（阿尔法级灵能）。奈克罗短板：客场作战（凡世锚点网格被主角逐步收拢，补给线在断）＋四神互斗（他调不齐四神的兵）。

**卷7 · 堕落英雄残影·加雷斯（亚空间外围·镜像型）**

- 【欲望】无独立欲望——只有生前执念的重复（生前：追猎恶魔、净化混沌；死后：腐化的猎人残影继续"追猎"，把活人拖进混沌）。他是8型"悲剧"的极端：不是想挡主角，是已经不能"想"了。
- 【8型】悲剧（费伦末代恶魔猎手堕落成残影——主角若不抗腐化就会变成的样子）。
- 【行动逻辑】目标：无（重复残影执念）。手段：无（本能猎杀）。代价：无（他早已付过——这就是悲剧）。
- 【必然冲突】主角迁入亚空间，撞上的第一道门就是自己的镜像：他认出加雷斯曾是猎手（呼应卷2内陆谷地的传承线索与从线C抗腐化）。
- 【降智检查】主角靠从线C（不可腐化——这正是他没变成加雷斯的原因）＋从线A。加雷斯短板：没有独立意志，只会重复生前执念，可预判、可绕过——这是"反派犯蠢"判据的豁免样本：他不是降智，是已经没有人格。

**卷8 · 奸奇大魔·泽维尔·千变（混沌四神·奸奇系，四神本体接触的前哨）**

- 【欲望】替奸奇把主角引进万变迷宫——主角是奸奇棋盘上最碍事的棋子，大魔负责收割这颗棋子。不挡主角他也照常经营万变迷宫。
- 【8型】幕后（万变魔君：以"计划中的计划"示人，每一步都像陷阱套陷阱）。
- 【行动逻辑】目标：在万变迷宫里困死主角（四神本体接触的试探）。手段：迷宫规则、幻象、时间错位、借另三神领域夹击。代价：奸奇系内耗——大魔之间也互相拆台。

## ④ 产出SOP（本案逐条对照验收）

1. **回读主角设计**：欲望串终点、主线养成线。
   → 【验收基准】能说出"终点是谁挡着"。过：终点 = 立神位收全费伦灵魂归宿权；守门人 = 奸奇（正面，四神顶端）＋莎尔（制度面，神位垄断执行者）。
2. **立终敌**：对欲望串找终点守门人，过三问（独立欲望/行为可推/冲突必然）。
   → 【验收基准】三问全过；他不挡主角也在干自己的事。过：奸奇独立欲望 = 吞费伦信仰真空（不挡主角也布万局）；行为可推（借代理人/教廷/神位垄断）；冲突必然（他吞主角守、他靠无主主角靠有主）。
3. **8型选型＋行动逻辑**：目标/手段/代价与压迫感来源。
   → 【验收基准】压迫感有来源（对应养成线档位），不是喊"他很强"。过：奸奇压迫感 = 强大神力级＋对位阶位第6档＋棋局压迫；目标/手段/代价写全。
4. **排卷敌**：每卷一个挡路的，立到够排这一卷。
   → 【验收基准】卷敌档位对齐主线养成线；次级敌人归展开。过：卷1-10档位逐档递进（职业中段→强大神力）；卡5件套各一行；层底Boss在敌梯表给一行，细节归卷纲；卷4一卷双线收束立2人（已注明）。
5. **降智检查**：主角赢他靠什么——哪条线超标＋他哪项短板。
   → 【验收基准】赢得有代价、有方法、有反应；无降智送人头。过：每卷有具体挂点与短板来源（§4总表）；加雷斯无独立意志 = 豁免样本。
6. **边界检查**：是否把《顶层势力》写成势力表、把《世界历史》写成史。
   → 【验收基准】本份只写"人"。过：势力归顶层、成因归历史、钩子归主角设计、次级人物归展开。

## 本次实测结论（对照《主要反派-SOP》待处理问题逐条）

| # | 待处理问题 | 本案结论 |
| --- | --- | --- |
| 1 | **反派8型是否有漏型**（覆盖不了的类型待核） | **有漏型，本案一次撞上两类**。①**存在型/天灾型**（混沌四神本体）：四神不是"人"，是灵魂与情感洪流的人格化。8型假设"反派是人有独立欲望"这条成立（四神有吞噬本能），但8型默认"反派可以被击败/杀死"的终局不成立——四神打不死，只能封＋断粮。本案处理：终敌选四神中"最像人"的奸奇，用"幕后"型对号立住谋划者人格，存在性写进压迫感与终局（打不死只能封）。**建议补型"存在/天灾"**：欲望 = 吞噬/生存本能、无个人恨意、终局 = 封印/断粮/改道，不是杀死。②**制度型**（神位垄断）：根本不是"人"，8型对不上。本案处理：把制度**具身成"执行者的人"**（莎尔 = 神位垄断的执行者），制度写进她的行动逻辑。**建议 SOP 补一句**："制度型阻力（垄断/戒律/霸权）不占8型，具身成执行者的人再对号；若制度本身就是终点守门人（如本案神位垄断），终敌立人，制度写进该人的行动逻辑。" |
| 2 | **"卷敌立到够排这一卷"的粒度未量化** | 本案给量法："够排这一卷" = 卷敌卡5件套（欲望/8型/行动逻辑/必然冲突/降智检查）各一行，不写小传、不写势力背景；档位 = 该卷主角阶位线的对撞档；层底Boss（质变验证战）在敌梯表给一行，战斗细节归卷纲/战斗系统。另实测撞上**"一卷双线收束"**（卷4 = 公审社会线＋锚点战力线），卷敌可立2人，判定 = 该卷有两个独立挡路高潮。此量法待卷纲实测复核。 |

**新发现的问题（本案新开）**：

- **四神出场排布**：奸奇作终敌，四神各系按"前期轮换出场、奸奇后置加重"排（卷2色孽／卷3恐虐／卷5纳垢／卷6执行面／卷8奸奇大魔／卷10奸奇本体）——终敌势力不过早透支，卷级推进有新鲜感。
- **"反派犯蠢"判据的豁免样本**：卷7堕落残影（无独立意志的傀儡/残影）可预判可绕过，不是降智。建议 SOP 在"禁降智"补一句"无独立意志的傀儡/残影可预判可绕过，属豁免，不算降智"。
- **制度型反派与"只写人"边界的落地**：本份边界检查（只写人）遇上制度型阻力时，处理法 = 制度本身不占位（归顶层势力/世界法则），只立执行者的人（莎尔）。判据可复用："终点守门人是制度 → 立执行者的人；终点守门人本来就是人 → 直接立人"。
