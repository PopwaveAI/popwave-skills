## ① 文档定位

**本份是什么**：灰烬之主这书的主角立人稿——主角本质上是谁（本命），以及他凭什么能入局、凭什么超速（力量资格/金手指＝金手指特殊养成系）。它不写世界画面（那是画像）、不写强怎么构成（那是法则）、不写棋盘（那是格局），只写"这个人是来怎么做这件事的"。

- **角色**：锁根。核心设定设计阶段的收尾一环。
- **回答的问题**：主角是谁？凭什么入局？
- **链路位置**：④（世界画像 → 世界法则 → 世界格局 → **主角设计**）。前三份把局铺好，本份才造人。
- **依赖**：世界画像（危机/三层地图）、世界法则（基石/养成线/金手指边界/准主线）、世界格局（起步格/升层路径）、立项创意-SOP（故事脉络里的主角种子）。产出供 主要反派（骨架）、核心配角（展开）、卷纲 使用。
- **一句话落点**：能一句话讲清"这本书的主角是个什么人、他凭什么能翻"，且接得上格局的起步格、法则的养成线。

它不是：
- 不是**人物小传**（出生年月/技能列表——那些是写章期细节）。
- 不是**通用力量规则**（那是世界法则；灰烬之力是主角的例外资格，不写进通用系统，v8.1 金手指边界）。
- 不是**剧情大纲**（主角会遇到什么事——那是卷纲的事）。
- 不是**金手指的孤立外挂清单**（灰烬锚定必须作为一条**特殊养成系**显式声明——独立档位表、成长量、与主养成线对表，见 §4）。

> 判据：写完①，读者知道"这份管什么、跟谁衔接"，但不知道"怎么填"——怎么填是②。

## ② 思考逻辑（本案的推演线）

**这条推演痕迹（agent 最该掌握）：主角 = 种子（故事脉络里的"主角是谁"）＋ 局（画像/法则/格局铺好的棋盘）→ 立人（本命：谜怎么落在他身上）→ 给资格（金手指：系统为什么对他开例外）→ 立金手指养成系（这条例外怎么长成一条独立的成长线）。**

本案推演线（从硬约束长出来，不是堆形容词）：

1. **先接种子，不重造**：故事脉络已定主角 = 穿越成费伦最后一名灰骑士的地球大学生，特质 = 谨慎、认死理、孤军也敢上，处境 = 孤军、异端、没人信。本份把"什么人"立成"这个人"，把"凭什么"补全。种子被推翻 = 故事脉络白做，禁止。
2. **先立人，后给资格**：先定"陆烬本质上是谁"，再定"凭什么入局"。灰烬之力必须从本命长出来，不是贴上去的。
3. **本命 = 底色 × 谜的落点**：底色有来处（他骨子里的行为倾向被什么处境磨出来的）；谜的落点答"为什么偏偏是他"——他是费伦唯一"既没被任何神系标记、又认得这场入侵"的灵魂。
4. **金手指 = 例外资格，不是新系统**（v8.1 金手指边界）：先问"主角是哪套系统的例外？例外在哪一环？"本案答案：对**信仰锚定系统**开例外，例外在**获取环节**（全世界的力量先挂靠神，他自我锚定直接自持）。
5. **金手指 = 一条特殊养成系（本份显式声明）**：金手指不是"挂在主养成线上的一个静态挂点"，它本身就是主角独有的成长维度——费伦只有一个灰骑士，**灰骑士阶位（名号版）× 灰烬锚定 = 原体之路**，这条晋升路径只有他能走。它有独立档位表（锚定范围 6 档扩容）、每档的成长量（新到手什么）、与主养成线（DND 数值层）对表但不重合。世界通用刻度（职业等级）留在世界法则，本份只声明主角独有的例外刻度。
6. **金手指挂得住成长线**：灰烬之力挂主养成线（灰骑士阶位），成长挂点 = 锚定范围随 6 次质变逐级扩容（自持 → 收留 → 庇一城 → 净裂隙 → 锚亚空间边缘 → 收全费伦）。不是一次性外挂。
7. **爽文无真代价**：灰烬之力的代价只做氛围/装扮级（开局活靶子的窒息感、画风变灰的威仪、被异端追杀的剧情挫折），无不可逆堕落、无损失核心资产、无憋屈。

> 判据：读的人能模仿"接种子 → 立人（底色×谜的落点）→ 给资格（对哪套系统开例外、例外在哪一环）→ 立金手指特殊养成系（档位表/成长量/与主线对表）→ 过真代价"这套思路，换一个完全不同的题材也能照推。

### 1. 本命 · 底色（承接故事脉络的种子）

**身份**：地球某普通二本大二学生 **陆烬**，游戏玩家（博德之门3 通关过），无神论者，家里开小饭馆。穿越成费伦最后一名灰骑士——醒来时没有同袍、没有组织、没有前辈，只有一套不属于这个世界的冷金属铠甲、一份没人信过的使命（追杀恶魔），以及费伦人听都没听过的名号。凡间把他当异类，教会把他当异端，诸神的目光不落在他身上。

**底色三件套（故事脉络给的种子：谨慎、认死理、孤军也敢上），立成有来处、有代价的行为倾向**：

1. **先看后动（谨慎）**：行为 = 动手前先观察、先摸底、先确认退路，从不赌没把握的局。来处 = 单亲家庭，母亲开小饭馆，他从小帮账、看人脸色、防赖账的客人——"先查证再相信"是看店磨出来的肌肉记忆。代价 = 初期对费伦所有善意都先怀疑三秒，差点误伤第一个真想收留他的老铁匠；该冒险的局他因犹豫慢半拍。
2. **认死理（轴）**：行为 = 认定"灵魂不该被吃"这条底线后，追杀、招揽、利诱都不改口；教廷给台阶（跪拜某神即赦免）他不下，宁可背着异端骂名走到底。来处 = 复读一年才考上大学，认准的事九头牛拉不回；玩游戏一个 Boss 卡一周也要自己打过去，不查攻略（他其实查过博德之门3 的攻略，但骨子里"自己的判断优先"）。代价 = 明明可以低头换活路，他偏要正面撞；这条路让他从卷1被追到卷4。
3. **孤军也敢上**：行为 = 没人信他，他一个人也敢顶上去；组队比单干更让他别扭。来处 = 常年独来独往，不是社恐，是嫌麻烦——自己解决最快。代价 = 穿越初期拒绝组队，把本该成为第一批队友的人推开，之后花卷2一整卷补这段信任。

**处境**：费伦的恶魔猎手已经绝迹，他是唯一还能认出混沌的人。全世界都在抢"灵魂归谁"，他一个都不靠——这正是后文例外资格的种子，此刻只表现为"孤身、无锚、人人喊打"。

> 判据检查："换个人故事不成立"——换成一个费伦本地人穿越者，没有现代认知，第一夜就死在裂隙针眼；换成无神论但不认死理的人，早跪了神求活路，灰烬之力落不到他头上。这个底色立得住。

### 2. 本命 · 谜的落点（为什么偏偏是他）

**世界之谜（承接画像/法则）**：最被抢的是灵魂的归宿权（信仰锚定）——灵魂挂靠神 = 庇护/神力，灵魂脱挂 = 混沌的粮。费伦的灵魂几乎全有主（挂靠神系，这是活着的防务）；无主灵魂 = 混沌的活靶子。诸神不能下场，凡间没有能挡混沌的力量。

**谜落到他身上的机制（三层）**：

1. **第一层 · 无锚灵魂 = 自我锚定的资格**。地球人的灵魂不在费伦神系里，没被任何神标记过——他是真正的"无主灵魂"。费伦本地人要先"解挂"（背叛神系）才能摆脱神属，成本高、有神系反噬；他天生是白纸。而灰骑士传承（不属于任何神系的净化力量）的核心资格，恰恰要求"灵魂没被别的锚占过"。全世界只有他这个异界灵魂天然满足。
2. **第二层 · 认知 = 护身符**。光无主不够——混沌吞的无主灵魂成千上万，全死了。他是唯一"认得这场入侵"的无主灵魂：博德之门3 的游戏认知让他第一夜就认出裂隙针眼、认出混沌形态、避开死局，在混沌把他当粮之前先完成传承绑定。其他无主灵魂（若曾有穿越者）没有认知，第一夜就没了。
3. **第三层 · 钩子（卷级揭开，本份不定死）**：铠甲和传承在裂隙撕开的坐标上"等着"他，像专门为他留的。候补谜底三选一，留卷级：①初代灰骑士的最后意志在亚空间边缘守着最后一套传承，等一个"既无锚又认得混沌"的灵魂；②裂隙自身的平衡机制——混沌入侵越猛，净化权柄越要显形，他是被"挑"出来的载体；③神系之外的某个古老存在布的局。谁把坐标刻进他的穿越，是欲望串并行支线（查明自己为什么穿越）的终点。

**一句话谜底**：他是整颗星球上唯一一个"既没被任何神系标记、又认得混沌"的灵魂——**无锚是他的资格，认知是他的护身符，两个条件缺一不可，所以偏偏是他**。

> 判据检查：这谜只能落在他身上——费伦本地人解不了无锚这道题，其他穿越者活不过第一夜。谜的落点同时是例外资格的生产地（无锚 = 灰烬锚定的资格），本命与资格同源，只解释一次。

### 3. 资格 · 入局（对哪套系统开例外）

**确认法则的暂定，并补齐细节**：世界法则暂定"灰烬之力 = 对信仰锚定系统开例外的资格，例外环节暂定获取环节"。本案确认获取环节，并补一条连带说明（使用环节是获取例外的自然延伸，不单列新例外）。

**对哪套系统开例外**：信仰锚定系统（灵魂归宿权的分配系统，法则链2）。这套系统的通用获取路径 = 灵魂挂靠某个神/组织 → 神透过挂靠递出庇护/神术/神力（**交灵魂换力量**）。获取环节的硬门槛 = "有主"——没有挂靠的灵魂拿不到任何力量，只会被混沌当粮。

**例外在哪一环**：

- **获取环节（主例外）**：别人的力量从"挂靠神"来，灰烬之力从"灵魂不挂靠任何神、自我锚定"来。陆烬跳过"挂靠"这一步——他把自己变成"主"。别人要向神交灵魂换庇护，他不用交，灵魂只归自己管。
- **使用环节（连带，不单列）**：神术要借神的权柄（神审批、神点头），灰烬之力自己就是权柄（自己审批自己），不经神递送。这是"获取时无主"的自然延伸，不是第二个例外。
- **代价环节（无例外，反而是福利）**：爽文无真代价（见§5）。灵魂只归自己 = 死后不被神系收编、也不喂混沌，归宿自己说了算。

**为什么这不算新系统（v8.1 边界检查）**：灰烬之力不新增任何力量规则。力量规则还是灵魂产能那套（挂靠 = 有主 = 产能；脱挂 = 洪流 = 混沌的粮）——他只是把自己的灵魂从"无主待食"变成"自我持有"，把"无锚 = 活靶子"这条通用劣势翻成"无锚 = 自持资格"这条专属优势。例外是挖了通用系统的获取环节，不是另造一套力量。

> 判据检查：能一句话讲清"这套世界的规则里，主角哪里是例外"——全世界获取力量要先挂靠神，他自我锚定直接自持；灰烬之力不是基石本身，不是新造系统，过 v8.1 边界。

### 4. 资格 · 超速（金手指特殊养成系 = 原体之路）

#### 4.0 金手指特殊养成系声明（老板拍板：金手指就是一条特殊养成系，本案 = 原体之路）

**金手指不是外挂，是一条主角独有的成长维度**。费伦只有一个灰骑士——**灰骑士阶位（名号版）× 灰烬锚定 = 原体之路**，这条晋升路径（新兵 → 骑士 → 圣骑士/大导师 → 原体·初成 → 原体·巅峰 → 灰烬之主）全世界只有他能走。它是一条与主养成线对表、但不重合的**独立养成系**：

- **世界通用刻度（人人能走，敌人也走）** = DND 职业等级（1-40 级/CR/神力谱系）——留在世界法则，是本份对表的参照物。
- **主角独有刻度（只有他能走）** = 灰骑士阶位名号版 × 灰烬锚定——本份声明。同一档位上，他的战力走 DND 数值层，他的例外走灰烬锚定（跳过挂靠、自我锚定、锚定范围逐级扩容）。
- **为什么它是一条养成系而不是一个挂点**：它有独立档位表（锚定范围 6 档）、每档有成长量（每档新到手什么）、有成长挂点（随主线 6 次质变逐级开档）、有排期（档位落卷位）——读者看档位表就知道"主角每过一个成长节点，手里多了一张什么牌"。

**三件套声明**：

1. **档位表**：锚定范围 6 档扩容（自持 → 收留 → 庇一城 → 净裂隙 → 锚亚空间边缘 → 收全费伦灵魂归宿权），挂主线 6 质变对表（见 §4.1 联动表）。
2. **成长量**：每档新到手 = 保命（锚定自己）→ 收编（锚定身边人）→ 庇城（锚定一城）→ 净裂隙（锚定裂隙带）→ 锚亚空间（锚定亚空间边缘）→ 立神位（锚定全费伦）。范围从 1 人到全费伦，撑得起 200-300 万字。
3. **与主/准主/从线的分工**：主养成线（DND 数值层）管"他多能打"（通用侧）；准主线（信仰网络）管"谁信他"（资源侧）；**金手指特殊养成系（原体之路）管"他凭什么例外"（例外侧）**——三者对表不重合：同一档位，数值层决定战力上限，锚定范围决定例外半径，信仰网络决定信众供给。

#### 4.1 挂哪条线（对表）＋ 灰烬锚定的定义

**挂哪条线**：主养成线 = 灰骑士阶位（6 质变：新兵 → 骑士 → 圣骑士/大导师 → 原体·初成 → 原体·巅峰 → 灰烬之主·伟大神力）。金手指特殊养成系的档位挂在这条线的 6 次质变上开档（对表不重合）。

**灰烬锚定的成长挂点（设定概念，第一次出现即定义）**：灰烬锚定 = 主角灵魂"自我持有"的资格与技术的合称，是"灵魂只归自己管"的第三条路，不是新造力量系统，不是挂靠神的变体。**锚定范围 = 他能给多少灵魂提供庇护的半径**，随阶位质变逐级扩容。锚定 = 提供灵魂归属秩序（灵魂挂他名下 = 受他庇护），不是吸收/吞噬灵魂（那是混沌的吃法）。收留的灵魂越多他越强（爽文逻辑），不是越烧越弱。

**6 次质变的联动表（每阶质变都开新档，不是开局给满）**：

| 质变 | 卷位 | 锚定范围开档 | 与例外资格联动（这阶新到手什么） | 联动准主线/从线 |
| --- | --- | --- | --- | --- |
| 1 新兵 → 骑士 | 卷1 | 锚定自己 | 灵魂不外泄，混沌啃不动（保命）；穿越第一夜从活靶子翻成"啃不动的硬骨头" | 从线C 意志抗腐化开档（可侵蚀 → 稳固）；从线A 灵能低阶档 |
| 2 骑士 → 圣骑士 | 卷2-3 | 锚定身边人 | 能收留无主灵魂——第一批信众（救下的码头孤儿/地下层居民）挂靠他名下，庇护直接给、不经过神殿，**准主线B 信仰网络起步** | 准主线B（孤证 → 庇护者） |
| 3 圣骑士 → 大导师 | 卷4 | 锚定一城 | 博德之门保卫战全城临时挂靠他名下——他是活神殿，神术级庇护绕过教廷直接给全城；越级赢（骑士打恶魔军团前锋）靠这条 | 准主线B（庇护者 → 圣者）；从线A 灵能爆发 |
| 4 大导师 → 原体·初成 | 卷5-6 | 锚定裂隙带 | 能净化/收编裂隙里的无主灵魂洪流——**混沌的粮变成他的粮**，粮仓开始反超混沌 | 从线A（阿尔法级灵能）；准主线B（圣者 → 神选） |
| 5 原体·初成 → 原体·巅峰 | 卷7-8 | 锚定亚空间边缘 | 在四神领域外围立"活庇护所"，救出的迷失灵魂全部挂靠他；封裂隙的资格 = 意志不可腐化 | 从线C（不可腐化）；从线D（亚空间规则知识） |
| 6 原体·巅峰 → 灰烬之主 | 卷9-10 | 锚定全费伦 | 立神位 = 把整条费伦的灵魂归宿权收归自己名下 = 搬空混沌的粮仓（混沌无粮可吃 = 被钉死在费伦之外） | 准主线B（神）；从线A 上限全开 |

**三线同步开档（成长挂点不是单点）**：每次质变，锚定范围 + 灵能上限（从线A）+ 抗腐化档（从线C）三线联动开档。锚定范围是主成长量（从 1 人到全费伦，撑得起 200-300 万字），灵能与意志是随行的深化量。

**与准主线/从线的分工（不越位）**：准主线B（信仰网络）= 锚定范围的资源侧表现（别人建网络靠神迹 + 教会体系从下往上攒，他靠收留无主灵魂自上而下给——他不跟教廷抢神殿，他就是活神殿）；从线D（混沌知识/游戏认知）= 穿越自带，是"导航"不是力量，不属于金手指（法则已定）。金手指特殊养成系只收"只有他能走的例外刻度"，通用刻度（职业等级/信仰网络人人能走的部分）留在法则。

> 判据检查：金手指作为特殊养成系显式声明（档位表 = 锚定范围 6 档扩容、成长量 = 每档新到手、与主养成线 6 质变对表不重合）；能挂到主养成线上（灰骑士阶位）、有成长挂点、不是一次性外挂。越级赢挂点（格局§4 的 5 条越级战）全部能溯源到本表——卷1 靠认知 + 锚定自己，卷3 靠锚定一城，卷4 靠反蚀，卷6 靠神选级庇护网 + 阿尔法灵能，卷8-9 靠不可腐化。

### 5. 爽文无真代价（灰烬之力的代价审一遍）

按法则 §1.5 的切分（真代价 = 损失已到手资产/不可逆/让主角变弱；氛围级 = 只改观感不改战力）逐类审：

| 潜在真代价点 | 审法（读者感到更酷还是憋屈） | 本案处理 |
| --- | --- | --- |
| 无锚灵魂 = 混沌活靶子 | 开局被吃 = 憋屈，永久活靶子 = 憋屈 | 只做开局氛围（穿越第一夜的窒息感、被混沌盯上的压迫），锚定自己后翻成"啃不动的硬骨头"（质变1）——劣势翻优势，不是长期负债 |
| 混沌腐化（越强越疯） | 越强越疯 = 憋屈，删 | 只做氛围/装扮级：主角越强越有不可名状的威仪与台词腔，画风变灰，本质无害（法则 §1.5 已审，本案沿用） |
| 锚定他人消耗灵魂 | 收信众 = 烧自己 = 憋屈 + 变弱，禁 | 设计为增益：锚定 = 提供秩序（灵魂挂他名下受庇护），不是输送/燃烧自己的灵魂；收留越多越强 |
| 异端被追杀 | 一直被追 = 憋屈 | 保留为"前倨后恭"的翻盘结构（卷内被追，卷末立神迹打脸），剧情挫折，不算真损失 |
| 灵魂归宿"只归自己" | 福利 | 死后不被神系收编、不被混沌吃，归属自己说了算——只赚不亏 |

> 判据：无不可逆堕落、无损失核心资产、无让读者憋屈的设定；灰烬之力的"代价"全部只改观感不改战力。过。

### 6. 边界检查与命名（过 v8.1 + 用词规范）

- **通用系统里零主角独有机制**：复核世界画像/法则/格局——法则 §4.1 灰骑士阶位 = 主角名号版本，但力量档位走 DND 通用职业等级（1-40 级/CR/神力谱系），敌人与主角共用同一套法则；灰烬锚定机制只写在本份；从线D 认知 = 穿越自带非金手指。**金手指特殊养成系只收例外刻度**：同一档位，DND 数值层（通用）留法则，锚定范围（例外）在本份，两边对表不重合。通过。
- **命名检查**：灰烬锚定 = 设定概念，首次出现已定义（§4）；原体之路 = 老板对金手指养成系的命名（灰骑士阶位名号版 × 灰烬锚定的合称），首次出现已定义（§4.0）；无自造黑话（对照用词规范：无"引擎/闭环/落盘/沉淀/耦合/注入"）；无装饰性比喻链。
- **棋盘立场回填（格局遗留项）**：诸神门槛（诸神本尊）立场 = 中立偏工具，随主角真开始立神位而分裂——恐惧（自我锚定成神动摇了"神位靠信徒挂靠"的根基）与期待（他能净化混沌、救神系于坠落）并存；诸神坠落之地（旧神残念）= 分裂——恨混沌的旧神助力封裂隙、守神位的旧神敌视外来神。此预判供主要反派/核心配角展开使用。

## ④ 产出SOP（本案逐条对照验收）

1. **回读种子与局**：故事脉络种子（穿越大学生 + 最后灰骑士，谨慎/认死理/孤军）+ 画像（危机/三层）+ 法则（基石/养成线/金手指边界/准主线）+ 格局（起步格/升层路径）。
   → 【验收基准】不推翻种子。过：种子三特质全部立成有来处有代价的行为倾向，身份处境原样承接。
2. **立底色**：骨子里的特质（有来处、有代价）＋ 当前身份处境。
   → 【验收基准】"换个人故事不成立"。过：费伦本地人解不了无锚题，其他穿越者活不过第一夜，谜只能落在他身上。
3. **定谜的落点**：世界之谜如何落到主角身上。
   → 【验收基准】能一句话讲清"主角区别于所有人的那一点"。过：他是费伦唯一"没被任何神系标记、又认得混沌"的灵魂；无锚 = 资格，认知 = 护身符，两者缺一不可。
4. **定入局资格**：对哪套系统开例外？例外在哪一环？
   → 【验收基准】能一句话讲清"这套世界的规则里，主角哪里是例外"；过 v8.1。过：对信仰锚定系统开例外，例外在获取环节（别人交灵魂换神庇护，他自我锚定直接自持）；不新增力量规则，不是新系统。
5. **定超速路径 + 立金手指特殊养成系**：金手指挂哪条主养成线？成长挂点？**独立档位表？每档成长量？与主线对表？与准主线/从线分工？**
   → 【验收基准】金手指作为一条特殊养成系显式声明。过：原体之路（灰骑士阶位名号版 × 灰烬锚定）有独立档位表（锚定范围 6 档扩容）、每档成长量（§4.1 联动表）、与主养成线 6 质变对表不重合（§4.0 分工）；不是一次性外挂。
6. **过"爽文无真代价"**：代价审一遍，只做氛围/装扮级。
   → 【验收基准】无不可逆堕落、无损失核心资产、无憋屈。过：四类潜在真代价全部按氛围/装扮级处理（§5 表）。
7. **边界检查**：画像/法则/格局里有没有把主角独有机制写进通用规则的；本份金手指特殊养成系有没有把通用刻度误划进金手指线。
   → 【验收基准】通用系统里零主角独有机制；金手指只在本份；金手指线只收例外刻度。过：灰骑士阶位力量档位走 DND 通用等级；灰烬锚定只在本份；职业等级/信仰网络通用侧留在法则。
8. **收尾验收一句话**：**一个"先看后动、认死理、习惯一个人扛"的地球大学生陆烬，穿越成费伦最后一名灰骑士——因为他是费伦唯一既没被神系标记、又认得混沌的灵魂，灰烬之力（灵魂自我锚定，对信仰锚定系统开获取环节的例外）只能落在他身上；他从博德之门下城区起步，靠金手指特殊养成系（原体之路：锚定范围随灰骑士阶位 6 次质变逐级扩容，自持 → 收留 → 庇一城 → 净裂隙 → 锚亚空间边缘 → 收全费伦灵魂），一路打到立成灰烬之主——把混沌的粮仓整个搬空。**
   → 【验收基准】全过。这是一份能落地的立人稿，不是标签堆；接得上格局的起步格（博德之门下城区）、法则的养成线（灰骑士阶位 6 质变 + 准主线信仰网络 + 从线 C/D）。

## 本次实测结论（对照《主角设计-SOP》待处理问题逐条）

| # | 待处理问题 | 本案结论 |
| --- | --- | --- |
| 1 | **合并后结构对"系统流/面板流"是否够用**（本案灰烬之力接近"身份型例外"） | **判据够用。** 本案是身份型例外（类《诡秘之主》灰雾，非面板/系统流），v8.1 判据（金手指 = "只有主角能动的例外资格，不是新系统"）直接可用。实测给出身份型例外的典型结构：**例外在获取环节、使用环节连带**——本案 = 对"信仰锚定系统"在获取环节开例外（跳过挂靠获取），使用环节连带（权柄自持不经神递送），代价环节无例外反而是福利。对系统流/面板流的适用性补强：面板若包含"主角独有且通用系统里没有的新规则"（刷新任务/存档读档），要检查这些新规则是否等于在通用系统外另造一套——是则回正为"对 XX 系统开例外的操作界面"的表述。建议 SOP 补一句"身份型例外也要显式写清对哪套系统开例外、在哪一环，避免写成'主角自带一套力量'"。 |
| 2 | 金手指"必须有成长挂点"是否过严（开局即满型是否成立） | 本案是长线书（200-300 万字），挂点充足（锚定范围 6 档扩容 + 三线同步开档），不产生"开局即满"样本。悬置状态不变，仍等短线爽文真实书。 |
| 3 | 弱世界观变体只在概念层 | 本案是强世界观（世界在推人），不产生弱轨样本。悬置状态不变，仍等都市/言情真实书。 |
| 4 | **"金手指 = 特殊养成系"的档位表粒度（v2 新增）** | **判据够用。** 本案给出档位表样本 = §4.1 联动表（锚定范围 6 档扩容，每档 = 范围 + 新到手 + 联动准主/从线 + 卷位），粒度定标为"每档范围/资格变化 + 新到手能力 + 卷位"，不用细到招式。**关键实测结论：金手指养成系与主养成线对表不重合，靠"通用刻度留法则、例外刻度留主角设计"切分**（本案：DND 数值层 = 通用，锚定范围 = 例外）。建议 SOP 第7步"边界检查"补"金手指线只收例外刻度"（已补 v2）。 |

**上游遗留项的复验与回填**：

- **（世界法则遗留）金手指剥离的完整链复验**：通过。法则只写例外资格占位（对哪套系统例外、例外环节暂定获取环节），机制与成长挂点全部落回本份；本份复核后确认法则零主角独有机制，剥离干净。**v8.2 后复验升级**：法则新增准主线（信仰网络）后，本份 §4 对表关系同步更新——锚定范围（灵魂供给侧）↔ 信仰网络（信众侧），同源不同轨。
- **（世界格局遗留）立场未定格回填**：诸神门槛 = 中立偏工具，后随神位博弈分裂；诸神坠落之地 = 分裂（恨混沌者助力、守神位者敌视）。已回填 §6，供主要反派/核心配角展开。

**新发现的问题（本案新开）**：

- **"谜的落点"与"例外资格"同源可省一次解释**：本案谜底（无锚灵魂）同时是例外资格的生产地（自我锚定的资格），两个构件共用同一个事实，只解释一次。建议 SOP 补一句"设计时优先让谜的落点与例外来源同源，可省一次解释、结构更紧"。
- **"通用劣势翻成专属优势"是例外的新形态**：本案的例外不是"给主角更多"，是"把主角被压制的那条路翻成立正的路"——全世界无锚 = 混沌活靶子，唯独他无锚 = 自我锚定资格。这是"例外在获取环节"的一种变体，可作 SOP 案例补强（区别于诡秘的"多一条渠道"型）。
- **金手指 = 特殊养成系（v2 首测，老板拍板）**：本案显式声明"原体之路"（灰骑士阶位名号版 × 灰烬锚定）为金手指特殊养成系——独立档位表（锚定范围 6 档扩容）、每档成长量、与主养成线 6 质变对表不重合、与准主线/从线分工（例外侧/资源侧/深化侧）。**实测判据**："是否人人能走"切分金手指线与通用线（灰骑士阶位名号版 = 只有主角能走 → 金手指线；DND 职业等级 = 人人能走 → 通用线）。档位表粒度定标为"范围/资格变化 + 新到手 + 卷位"，够卷级结构直接引用。
- **锚定范围的档位需要与准主线B档位对表**：锚定范围（自持 → 收留 → 庇一城 → 净裂隙 → 锚亚空间边缘 → 收全费伦）与准主线信仰网络（异端 → 孤证 → 庇护者 → 圣者 → 神选 → 神）天然对齐，本案已对表（§4.1 联动表）。建议 SOP 补一句"金手指特殊养成系档位与主/准主线档位对表写清，避免挂点悬空"。
