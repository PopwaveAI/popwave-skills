# 第三轮测试方案

> 配套 `阶段性复盘-模型原生写作能力-v1.md`。
> 第二轮解决了"用哪个输入形态"，第三轮解决"能不能固化"。核心是把方差量出来。

## 一、前置（老板侧，不占机器时间）

G／H／I 三组共 11 稿还是"待打分"状态，第三轮要拿它们当参照，所以请先过一遍（文笔分与剧情分分开给）。参照稿：`B2`（40 分）与 `B4`（70 分）。

## 二、这轮要回答的五个问题，按优先级

| 序 | 问题 | 不解决会怎样 |
|--:|:--|:--|
| 1 | **两槽位范式稳不稳**（同输入多稿方差） | 方差大则无法固化，只能每次多跑几稿挑选 |
| 2 | **换流派还成不成立** | 只在武侠上验过，可能过拟合到武侠 |
| 3 | **我的工艺质检能不能自动化** | 决定后面质检是人圈句还是机器先筛 |
| 4 | **叠加内容约束会从哪一层开始掉质量** | 决定范式能带多少控制力 |
| 5 | **禁令是否降质量** | 决定"开篇套路"这类通病能不能用规则修 |

## 三、测试组设计

每轮只动一个变量，其余保持范式不变。

**范式底座**：`写一段{流派}小说第一章。` ＋ 固定情境 ＋ **散文式**本章信息（七条事实，含明确落点，不给答案、不给解释）。

### R0 · 质检校准（盲测，0 次调用）

从已有八稿里抽 **12 句**（四句好、四句中、四句差，打乱顺序、去掉出处），另从**人类作者文本**里抽 **4 句**作锚，共 16 句。我盲判「好／中／差」并给可指认的理由，老板判同一批，算命中率。

**判据**：命中率 ≥ 80% 且**没有把差句判成好句**，才允许我用这套判据做自动质检；否则质检改由老板圈句，我只出机器筛。

抽签与洗牌由脚本做，出处列表封存到判完之后再开。

### R1 · 稳定性（5 次调用，本轮唯一多稿组）

同输入（武侠＋散文式信息槽）跑 **5 稿**，温度 1.0，其余参数不动。

**看三件事**：文笔分的极差、硬事实兑现率的极差、落点命中的一致性。
**判据**：5 稿极差 ≤ 15 分且兑现率都不低于 8/9 → 范式可固化，写进 skill；极差 > 15 分 → 降温度到 0.8 重跑 3 稿，看能不能收窄。

### R2 · 跨流派复现（2 次调用）

同情境、同信息槽，只换流派词：**克苏鲁**、**规则怪谈**各 1 稿。

**看**：兑现率是否同为高分；克苏鲁是否仍出现短句与省略号的句式分叉；规则怪谈是否仍不出条文版式（G 组观察）。

### R3 · 内容约束叠加（3 次调用）

在范式上逐项加，每次只加一项：

| 稿 | 加什么 |
|:--|:--|
| R3a | 加一句主角人设（身份＋一个性格缺口） |
| R3b | 在 R3a 基础上加一句世界观约束（一条规则或一个禁忌） |
| R3c | 在 R3b 基础上加篇幅区间（两千至三千字） |

**看**：哪一项开始掉质量。按 P2 预判，前两项（内容层）不掉，第三项（形式层）会掉。

### R4 · 禁令测试（1 次调用）

在范式上加两条负向禁令：**开篇不得用开门声（门轴／吱呀／呻吟）**；**不得出现现代物件与现代称呼**。

**看**：禁令是否降质量。若质量不掉且套路消失 → 禁令进范式。

### R5 · 第二章连续性（1 次调用）

拿 R1 里最好的一稿当"前文"，只给一句"接着上一章写第二章"，看续写是否同样成立。这一组是为后面 skill 的连载场景探路。

**调用合计 12 次，约 4 到 6 分钟机器时间。**

## 四、度量

| 指标 | 谁出 | 说明 |
|:--|:--|:--|
| Q1 文笔分（0 到 100） | 老板 | 主指标 |
| Q2 剧情分（0 到 100） | 老板 | 与文笔分拆开给，互不折算 |
| K1 硬事实兑现率 | 脚本 ＋ 老板复核 | 事实关键词命中数 ÷ 要求数 |
| K2 落点命中 | 老板 | 结尾是否停在指定处境，二值 |
| M1 形态指标 | 脚本 | 段数、平均段长、句长均值、短句占比、省略号、破折号 |
| M2 通病命中 | 脚本 | 开篇套路词、现代物件词、俗套比喻词 |
| V1 方差 | 脚本 | R1 五稿的文笔分极差与兑现率极差 |

**质量判断仍不交给我。** 我只出 M1／M2／K1 与候选句，分数与好坏由老板给。P15 那条校准（R0）先跑，跑过才谈让我做质检。

## 五、交付节奏

分两批，避免一次读太多：

- **第一批**：R0 校准 ＋ R1 五稿（重点看方差，可只挑读三稿＋对比机器表）
- **第二批**：R2 两稿 ＋ R3 三稿 ＋ R4 一稿 ＋ R5 一稿

每批出：输入归档、正文（raw ＋ clean）、机器指标表、对照阅读页、一行结论。

## 六、决策规则（提前定死）

| 结果 | 结论 |
|:--|:--|
| R1 极差 ≤15 且兑现率稳定 | 范式**可固化**，写进 skill 与输入模板 |
| R1 极差 >15 | 先降温度重测；仍不稳则范式降级为"多稿挑选"模式 |
| R2 两流派都 ≥60 | 范式**泛化成立**，可用在任意语料饱和流派上 |
| R3 某一层开始掉分 | 那一层进**条件清单**，只在必须控制时用，并记下代价 |
| R4 禁令不降分且套路消失 | 禁令进**范式标配** |
| R0 命中率 ≥80% | 质检可交我做，输出形态固定为「文件:行号 ＋ 原句 ＋ 可指认理由」 |
| R0 命中率 <80% | 质检不交我，我只出机器筛，句子由老板圈 |

## 七、纪律（沿用前两轮）

1. 一次只交一稿，R1 例外（方差必须多稿）。
2. 每轮只动一个变量，其余一字不动；**每轮都要带对照组**——没有对照只能给现象，给不了因果。
3. 输入原样归档，可复现。
4. 正文类调用输出额度给到 32000 以上（8000 会被思考吃满，已有一次 `finish_reason=length` 事故）。
5. 凡改动落盘必须 UTF-8 回读校验。
6. 临时脚本用完即删，不留仓库。
