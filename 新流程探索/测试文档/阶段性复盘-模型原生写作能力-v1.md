# 阶段性复盘：模型原生写作能力的探索（截至 2026-09-12）

> 配套 `正文质量测试规划-v1.md`（规划）、`正文质量测试记录.md`（逐轮数据）。
> 这一阶段的目标从"复制直出质量"进到"找到输入范式"。本文件只写已经实测过的结论，未测的不写。

## 一、这一阶段到底在解决什么

起点是一个反常：**不给任何上下文直出，文笔好；挂满 skill 与设定去写，反而不如直出。** 顺着这个反常往下挖，问题被拆成了三层：

1. **质感的来源**：直出凭什么好？
2. **控制力的代价**：为什么一加控制就掉质量？
3. **两者能不能同时要**：输入范式该怎么设计？

第一层与第二层已经有答案，第三层拿到了一个能用的候选范式，正在验稳定性。

## 二、已确证的结论

### 写作机制层（第一性原理，全部有实测支撑）

| 编号 | 结论 | 证据 |
|:--|:--|:--|
| P1 | 通顺是"专心写"的副产品，检查补不上 | 直出 0 次工具调用、几乎无语病；链路 23 次调用、语病密布 |
| P2 | 约束的**作用层级**决定它是否降质量：内容层约束不降，形式层约束降 | 章纲（形式＋内容混合）掉到 40 分；老板版简介（纯内容）保持 70 分 |
| P3 | 模型判不出"怪"，包括判它自己写的东西 | 我把老板圈的 7 句全标成绿；AI 评委把 skill 稿排在直出之前，八项维度全反 |
| P4 | **形态会传染**，句子层也传 | 条目式输入 → 每段 32 字；长段输入 → 39.5 字；本轮第三次复现（H3 条目 → 短句占比 41.7%） |
| P5 | 剧透杀死悬念 | 章纲写了反转答案 → 只能演；简介不给答案 → 模型自己设计出"灯早就灭了" |
| P6 | 独立多稿优于单稿多改 | 3 稿 3 个独立解，选稿即可；改 3 稿留下语法断口 |
| P7 | 模型的生成目标就是它的惩罚函数 | 链路惩罚漏节点、字数不符，不惩罚"句子说不清"，于是模型牺牲句子 |

### 输入范式层（本轮新增）

| 编号 | 结论 | 证据 |
|:--|:--|:--|
| P8 | **流派词是质感的开关，而且是真的"激活"，不是听话编造** | G 组交叉矩阵呈完美对角：武侠词表只在武侠稿命中（35.3／万字），克苏鲁只在克苏鲁稿（12.5），规则怪谈只在规则怪谈稿（12.7）；无线索词稿三表全零。克苏鲁稿还另有句式分叉（短句占比 54.3%，其余 21% 到 29%；省略号 42 个，其余 0 到 4） |
| P9 | **生造流派词激不出体系** | 「琉璃道」稿三张词表全零，且比喻词最多（17 次）、段最长（53.8 字）——是普通文笔，没长出自己的语汇与体式。这条把"听指令即兴编造"这个替代解释排除了 |
| P10 | **信息槽与流派词是分工加挤占** | 同一信息槽，有流派词的稿 9/9 兑现，去掉流派词只有 7/9（漏「有人敲门」这个关键事件）；但反过来，加了信息槽后流派词的自发语汇被压低（不加信息槽有 5 个武侠词，加了信息槽的字段式稿为 0，散文式稿只剩 2） |
| P11 | **信息槽不能写成"整句条目"，要写成"字段＋短语"的文档** | 两轮对照：七个整句条目 → 句子被切碎（短句占比 41.7%）、还漏事实；字段式设计文档 → 控制力 9/9 且短句占比 23.1%（四稿最低），只是段落变密 |
| P12 | **信息槽写散文也能拿满控制力，且读感更好** | 散文式 9/9 兑现、落点精准、段长 54.2 字自然；字段式同为 9/9，但读出两处硬伤、段落过密 |
| P13 | **加"这是文档不是正文，不要模仿格式"这类声明有害** | 带声明的两稿正文明显缩水（998／1089 字，无声明 1925 字），且更易漏事实。声明没隔离形态，反而把模型带进简写 |

### 模型能力边界层

| 编号 | 结论 | 证据 |
|:--|:--|:--|
| P14 | **语料库里没有具体作品，能力是分布级的** | 探针问《深渊主宰》作者与第一章：思考 1299 tokens、试错十四个作者名，回答"不记得"并自陈是推测。S2 那章 65 分是原创 |
| P15 | **它能做工艺质检，不能做品味评审** | 2026-09-12 校准：八稿里挑三句最美、三句最差，理由逐条被老板认可（正向：信息量翻倍、喻体对得上、以细节写衰亡；负向：时代错乱、位置矛盾、意象方向错）。但"哪篇更好看"的排序不可信（P3） |
| P16 | **输出的自相矛盾它自己抓不到** | I2 稿里人物已上楼敲门，下一句脚步声又回到院门外；机器指标查不出，模型自查也过。这类要靠人圈或单点复测 |

### 通病层（新发现）

| 项 | 现象 | 证据 |
|:--|:--|:--|
| 开篇套路 | **八稿里七稿用同一种手法开门**：门轴／木轴 ＋ 吱呀／呻吟 | `D1:5`、`D2:7`、`D3:5`、`D4:3`、`I2:9`、`I3:3`；唯一没用的是 `C1`（它写锁簧"咔嗒"） |
| 时代错乱 | 武侠语境里混入现代物件与称呼 | `D1:21`「塑料珠子」「同学」、`D1:57`「出租屋」「冷馒头」 |
| 俗套比喻 | 熟语当结尾 | `C1:53`「斩不断这方寸之地的一缕情丝」、`C1:27`「像一根刺……一鲜血淋漓」 |

## 三、当前最佳输入范式（候选，待稳定性验证）

两槽位：

**槽一 · 流派词**：一句「写一段{流派}小说第一章」。它决定文体、语汇与句式节奏。流派词要选**真实存在且语料饱和**的（武侠、克苏鲁、规则怪谈都验过有效）；生造流派词无效。

**槽二 · 本章要写什么信息**：写成一到两段**连贯散文**，内容是**事实层**（谁、在哪、发生什么、停在什么处境），不给答案、不解释反转、不写形式要求（不指定场数、不指定字数、不指定人称）。结尾处给一个明确落点。

**必须带的**：一句任务声明（"写一章"）。缺了它模型会当成既有正文去续写（S1 只出 716 字还带助手话尾）。

**别带的**：条目式清单、形式参数、反转答案、"这不是正文"之类声明。

## 五、还没解决的

1. **稳定性**：本阶段绝大多数轮次只跑 1 稿，方差未知。要固化范式必须先量方差。
2. **文笔分与剧情分的正式打分**：G／H／I 三组都是"待打分"，需要老板过一遍。
3. **跨流派复现**：两槽位结论目前主要在武侠上验过；克苏鲁与规则怪谈只验了流派词这一层。
4. **控制力的上限**：人物设定、世界观约束、篇幅区间这几个旋钮还没进过两槽位范式。
5. **工艺质检能不能自动化**：P15 那条"能判手法、不能判品味"，还没有被独立盲测校准过。
6. **第二章连续性**：所有测试都是第一章。续写是否同样成立，未测。

## 六、方法论上的两个收获

**一是探针设计法。** 每轮只动一个槽位，其余一字不动；并且**一定要带对照组**——G 组的生造流派词、H 组的去流派词、I 组的删声明，都是靠对照才把因果切开的。没有对照组的那几轮（T／S 组）只能给现象，给不了因果。

**二是单句话校准法。** 整篇通读的判断不可用（P3），但**指着单句给判据**时判断可用（P15）。所以质检的输出形态应是"文件:行号 ＋ 原句 ＋ 可指认的理由"，不是"这篇 70 分"。这条决定了后面机器筛与人判的分工。
