# 参数冻结 · 跑批前必读

> 每批开跑前先比对本文件与 `第三次测试/.env`，不一致即停，不许带着漂移的参数跑。
> 本文件在 2026-09-12 开工前冻结。

## 冻结值

| 项 | 冻结值 | 为什么是这个值 |
|:--|:--|:--|
| 模型 | `deepseek-flash` | 仓库规则：API 任务默认 flash，无特别说明不换 |
| temperature | 1.0 | 与第二轮探针一致，保住可比性 |
| top_p | 1.0 | 同上 |
| system message | **不发** | 真零上下文；本测试全部走 user 单条 prompt |
| max_tokens | **32000** | 8000 会被思考吃满，第二轮已有一次 `finish_reason=length`、正文只 315 字的实测事故 |
| 每条件稿数 | 1 稿 | 稳定性组（06）例外，跑 5 稿 |
| 输出额度检查 | 每稿必记 `finish_reason` 与 `usage.reasoning_tokens` | 判断有没有被思考挤占正文 |

## 固定输入（跨组复用，一字不改）

固定情境（①②④⑤⑦ 共用，与第二轮逐字一致）：

> 一个人回到十年前的旧居。房子早已空了，房东换过三任。他在二楼朝北的屋子里找到一只铁盒，里面是当年没寄出的信。当晚他决定住下，把信一封封重读。

固定风格底座（④⑤）：`武侠`。

固定信息槽形态：**散文式**。全轮不用条目式、不用元声明（第二轮已证：条目式碎句、元声明让正文缩水）。
