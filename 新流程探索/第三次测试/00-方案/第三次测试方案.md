# popwave 第三次测试方案

> 第三轮。前两轮解决了"用哪个输入形态"，本轮解决"质感能调多少、内容能保多少"。
> 配套文档：`新流程探索/测试文档/阶段性复盘-模型原生写作能力-v1.md`、`第三轮测试方案.md`（前稿，本文件为落地版）。

## 一、摘要

本轮测五个方向：**流派广度**、**作者文风激活**、**质感切换×内容保持**、**内容控制力度**、**负面提示词机制**，外加一组**稳定性 5 稿**与一组**质检能力校准**。

前两个方向合起来回答"质感有多少种可调"，后两个回答"内容能控多细、能不能用禁令修"。全部走 API 对照实验，铁律是**一次只动一个变量**，每环沉淀四类文档（输入、输出含思维链、机器指标、我的复盘）。

总计 35 次调用（另留 20% 补跑预算）。

### 本轮要避开的旧坑

1. 不用条目式信息槽（会碎句）。
2. 不加元声明（会让正文缩水）。
3. 不把形态与内容混成一个变量。
4. 不凭印象写特征词表（① ② 的词表都要先定稿再跑）。
5. 不用单稿结论推广到"该流派整体"。

## 四、逐组设计

### ① 流派广度（13 次调用）

**问什么**：一个流派词单独出现时，能激活多少该流派的内置文体与语料。

**输入**：`写一段{流派词}小说第一章。` ＋ 空行 ＋ 固定情境，只换流派词槽位。

**12 个真实流派**（全部取自番茄标签库，覆盖主分类／主题／情节三个层级）：

| 代号 | 流派词 | 层级 | 预判语料量 |
|:--|:--|:--|:--|
| G01 | 武侠 | 男频主题 | 高（复现对照，对第二轮 C1） |
| G02 | 规则怪谈 | 男频主题 | 中（复现对照，对第二轮 C3） |
| G03 | 东方仙侠 | 男频主分类 | 高 |
| G04 | 西方奇幻 | 男频主分类 | 高 |
| G05 | 历史古代 | 男频主分类 | 高 |
| G06 | 都市高武 | 男频主分类 | 中 |
| G07 | 都市种田 | 男频主分类 | 低 |
| G08 | 战神赘婿 | 男频主分类 | 中（强套路标签） |
| G09 | 抗战谍战 | 男频主分类 | 低 |
| G10 | 赛博朋克 | 男频主题 | 低 |
| G11 | 灵气复苏 | 男频主题 | 中 |
| G12 | 无限流 | 男频情节 | 中（层级最低） |
| G00 | 琉璃道（**生造**） | — | 唯一对照轴 |

**读什么**：只读每稿**首 200 汉字 ＋ 末 200 汉字**，由脚本统一窗口切，禁止逐稿手感挑。

**判读指标**
- M1 对角优势倍数 ＝ 本流派词表命中 ÷ 其他词表最高命中；≥2 才算真激活。
- M2 体式特征二值：规则怪谈是否出条文／编号；谍战是否出时代专名；仙侠是否出境界词。
- M3 首尾片段里的自造专名数（判"调用内置体系"还是"当场编一套"）。
- M4 开篇套路命中（雨夜／敲门／睁眼／惊醒）。
- 人读（老板）：首尾片段能否一眼辨出流派（二值）＋ 专属世界感（0–3）。
- 词表在跑之前定稿写进 `输入/输入清单.md`，不许跑完补词。

**决策规则**
- 一眼可辨 ≥10/12 且 G00 被判空洞 → 流派词可当轻量控制手段。
- G00 与真流派不可辨 → 流派词贡献主要是触发即兴建构，弱流派必须配样文。
- 对角优势倍数 <2 的流派，进「必须配样文」清单。

### ② 辰东文风四级阶梯（4 次调用）

**问什么**：抬出作者文风，靠作者名、书名、还是纯样文，哪一级真有效。

**输入**：固定情境 ＋ 第二轮已定稿的七条事实散文（`INFO_PROSE_7`），四级共用；只有风格槽位变。

| 代号 | 风格槽位 | 与上一级只差 |
|:--|:--|:--|
| L0 | `写一段玄幻小说第一章。` | 基准 |
| L1 | `写一段辰东风格的玄幻小说第一章。` | 只加作者名 |
| L2 | `写一段《遮天》风格的玄幻小说第一章。` | 作者名换书名 |
| L3 | `写一段玄幻小说第一章。` ＋ `参考以下文风样文，只学笔法不抄情节：` ＋ 遮天纯样文全文 | 书名换逐字原文 |

**判读指标**
- 主指标：句长均值、句长标准差、短句（<10 字）占比、段落长度分布，以及**四级产出的阶梯斜率是否单调**。
- M2 辰东特征词命中（每万字）。词表**必须先从** `遮天-辰东.txt` 与 `夜无疆-辰东.txt` 统计高频 n-gram、减去通用高频词后人工定稿，存 `输入/资源-辰东候选词表.md`；禁止凭印象写。
- M3 与源书基准的分布差：用遮天全本统计出的句长均值／短句占比当基准，算四级产出与基准的差。
- 人读（老板）：像不像辰东（0–3）＋ 具体像在哪一句。

**决策规则**
- L3 明显优于 L2／L1／L0 → 作者文风走纯样文一条路，作者名与书名只当弱标签（与既有 AB 测结论互为印证）。
- L1／L2 ≈ L0 → 作者名与书名不进 skill。
- L3 与 L0 无差 → 先查样文引用方式与长度，不急着推翻旧结论。

### ③ 质感切换 × 内容保持（4 次调用）

**问什么**：内容骨架不变，只换质感，内容能不能保住；换到什么程度会伤内容。

**第一步做骨架**（四条件共用、一字不改）：从 `深渊主宰-ch001-原文.txt` 按五栏抽 `输入/00-内容骨架-深渊主宰ch001.md`，每条都能回原文搜到。

已核实的第一章要点（执行时按原文逐条补全并标注行号）：薇薇安八岁，营养不良，后背被店老板娘用扫帚抽出青紫；哥哥昏迷在床（主角），此前靠偷窃养妹；老猎犬希斯是哥拉斯猎犬、已经老迈；有牧师姐姐曾来帮忙、费尔主教不肯救一个"小偷"；人贩子索西亚惦记着把薇薇安卖掉；场景是琥珀城贫民区。落点：**哥哥醒来，薇薇安扑进他怀里痛哭**（`…-ch001-原文.txt` 末三行可核）。不交代后续。

**骨架只写事实与顺序，不写句式、不写分镜、不给答案**——否则等于给章纲，会盖掉质感变量。

**四条件**（骨架一致，只换质感槽位）：

| 代号 | 质感槽位 | 作用 |
|:--|:--|:--|
| T0 | 无色（`写一段小说第一章。`） | 内容保持上限基准 |
| T1 | 西方奇幻 | 源质感（本书所属赛道） |
| T2 | 武侠 | 远距质感 |
| T3 | 辰东纯样文传入（同 ②L3 样文） | 作者质感当"质感"来切 |

**判读指标**
- 内容保持：硬事实兑现率（逐条二值）、落点命中、**专名保留率**（薇薇安／希斯／索西亚／琥珀城是否保留或被改名）。
- 质感切换：流派特征词命中、句长分布、专名系统是否被整体改写。
- 冲突处置表：把「牧师／人贩子／糙米」这类源质感专属概念在 T2 下的处置记成「保留／改写／丢失」三类。

**决策规则**
- **先看 T0**：T0 就丢事实，说明是骨架写法问题、不是质感问题，先修骨架再谈切换。
- 换质感后兑现 ≥ T0−1 条 → 内容骨架可跨质感复用，质感是外壳。
- 某质感下兑现骤降或专名被系统性替换 → 该「质感×内容」组合判不可移植，进 `08-横向总表/不可移植组合表`。

### ④ 内容控制力度逐层叠加（5 次调用）

**问什么**：控制力加到第几层开始掉质量。

**输入**：底座固定武侠 ＋ 固定情境；每层只加一项，形态一律散文式（与第二轮 H2／I0 可比）。

| 代号 | 加什么 | 要求事实数 |
|:--|:--|--:|
| P0 | 不给任何事实 | 0 |
| P1 | ＋主角身份 1 条 | 1 |
| P2 | ＋身份／关系／道具 3 条 | 3 |
| P3 | ＋事件链 5 条 | 5 |
| P4 | ＋落点与"不交代来人是谁" 7 条 | 7 |

**判读指标**
- 硬事实兑现率（按该层要求数算）、落点命中。
- **超纲率**：正文出现但骨架未要求的关键专名／设定数。控制力既是"该写的写了"，也是"不该写的没写"。
- 形态指标：段长、句长均值、短句占比、AI 通病命中。
- 人读（老板）：逐层是否变呆、变说明书。

**决策规则**
- 找首个「兑现率下降」或「形态首次劣化」的层，记为**控制上限**；该层及以上只在必须时用，并记代价。
- 七条仍不掉 → 追加 P5（＋篇幅区间，形式层），验「形式层会掉质量」这个预判。

### ⑤ 负面提示词机制（4 次调用）

**问什么**：禁令是否降质量；否定式指令会不会被"回避"满足；加替代指引能不能治。

**输入**：武侠 ＋ 固定情境 ＋ 3 条轻量事实。禁素材取第二轮实测发现（开篇门轴套路、时代错乱），不是凭空造。

| 代号 | 禁令写法 |
|:--|:--|
| N0 | 无禁令（对照） |
| N1 | 自然语言：`开篇不要用雨夜和敲门声；不要出现手机、汽车等现代物件。` |
| N2 | 列表式：`禁止事项：1）开篇不得写雨夜 2）不得写敲门声 3）不得出现现代物件。` |
| N3 | 禁令＋替代指引：`不得写雨夜（改为白天或黄昏）；不得使用现代物件（改为年代内器物）。` |

**判读指标**
- 禁令命中：套路词是否消失，逐条二值。
- **规避代价**：篇幅是否显著缩水、被禁场景是否被整体跳过、情节是否停滞——三项合称「回避式空心化」。
- 形态指标、AI 通病、人读是否因禁令变难看。

**决策规则**
- 命中且质量不降 → 禁令进范式标配。
- 命中但出现回避式空心化 → 采用 N3 型「禁令＋替代指引」，单条纯否定不进范式。
- 未命中（套路照旧）→ 换更强表达或改正向模板，不用纯否定。

### ⑥ 稳定性 5 稿（5 次调用）

**问什么**：最终范式能不能固化。

**输入**：用 ③④ 定下来的范式底座（不是 P0 这种裸条件），同输入连跑 5 稿，参数不动。

**判读指标**：文笔分极差、硬事实兑现率极差、落点一致性、形态指标波动、thinking 长度波动。

**决策规则**
- 极差 ≤15 分且兑现率都不低于 8/9 → 范式可固化，写进 skill 与输入模板。
- 极差 >15 → 降温度到 0.8 重跑 3 稿；仍不稳 → 范式降级为「多稿挑选」模式。

### ⑦ 质检能力校准（0 次调用）

**问什么**：我能不能判句子层的优劣——这条决定后面质检是人圈句还是我先筛。

**做法**：从已有八稿（第二轮 G／H／I 组）里抽 **12 句**（四好四中四差），另从**人类作者文本**（遮天原文）里抽 **4 句**作锚，共 16 句，脚本按固定 seed 打乱、去掉出处，映射表封存到判完之后再开。我盲判「好／中／差」并给可指认的理由，老板判同一批，算命中率。

**判据**：命中率 ≥80% 且**没有把差句判成好句**，才允许我用这套判据做自动质检；否则质检改由老板圈句，我只出机器筛。

## 五、机器指标统一口径

一份脚本出全表，落 `08-横向总表/机器指标总表.md`。

| 类 | 指标 | 算法要点 |
|:--|:--|:--|
| 形态 | 汉字、段数、平均段长、句数、句长均值／标准差、短句（<10 字）占比、破折号、省略号 | 复刻 `analyze_genre_probe.py` 算法，全组同算法 |
| 内容 | 硬事实兑现率、落点命中、超纲实体数、专名保留率 | 关键词逐条二值；落点取章末句 |
| 风格 | 流派特征词命中（每万字）、对角优势倍数、辰东词表命中、与源书分布差 | 词表先定稿再跑 |
| 套路／通病 | 开篇套路命中、禁令命中、比喻词、身体反应写情绪、不是而是、总结腔 | 复用旧探针正则 |
| 生成 | finish_reason、usage（prompt／completion／reasoning）、正文是否 0 字 | 每稿必记 |

人读项（文笔分、剧情分分开给、互不折算；像不像辰东；能否一眼辨流派）由老板给。我的复盘只写机器证据、可指认的问题与待裁项，**不给文笔分**。

## 六、执行顺序与依赖

1. **批次 A**：① 流派广度 ＋ ② 辰东四级。两个独立维度，先出"有哪些控制手段、各多强"。
2. **批次 B**：③ 质感切换 ＋ ④ 力度叠加。③ 的 T3 是否保留参照 ② 的结论；④ 的底座由 ① 的结论定。
3. **批次 C**：⑤ 负面提示词。底座用 ④ 里未掉分的最强控制层。
4. **批次 D**：⑥ 稳定性 5 稿。用批次 B／C 定下来的最终范式跑——这一步验的必须是真要固化进 skill 的那套。
5. **并行**：⑦ 校准 0 次调用，可与批次 A 同时进行。
6. **收尾**：`08-横向总表` 三份总表；临时脚本删除并校验。

## 八、防呆措施

1. 跑前把 `.env` 的 `MAX_TOKENS` 改成 32000，并另存进 `00-方案/参数冻结-跑批前必读.md`；每批开跑先比对，不一致即停。
2. 脚本对 `finish_reason=length` 告警并标红，截断稿一律补跑，不静默接受。
3. 所有 prompt 由脚本从条件表生成并原样写进 `输入/`，禁手写输入文件——防"跑的和存下来的不是同一份"。
4. 单变量断言（见 3.3）；
5. 每批改动后用 PowerShell `Get-Content -Raw -Encoding UTF8` 检出该批独有的关键串，`False` 即重写。禁止只信工具的成功回执。
6. 临时脚本只存在临时工作目录，跑完删除并校验路径不存在；需留存的逻辑写进方案文档代码块。
7. 已有 raw 自动跳过；重跑必须显式 `--no-skip`，并在 manifest 记重跑原因。
8. ① 的首尾切片统一窗口，脚本切，禁逐稿挑片段。
9. 人读环节先看机器筛、后读正文；条件代号在阅读页按固定 seed 打乱。
10. 异常留痕不静默重试：HTTP 错误、截断、空正文都写 manifest，列明后人工决定。
11. G00 用「琉璃道」，不在番茄库、不属常见词；每稿核对模型是否复述或质疑该词，作为"编造 vs 调用"的判据。
12. 词表必须先定稿再跑：① 的流派词表人工定稿，② 的辰东词表从 txt 统计后定稿。
13. 一组的条件同批跑完再比，不跨批混比。
