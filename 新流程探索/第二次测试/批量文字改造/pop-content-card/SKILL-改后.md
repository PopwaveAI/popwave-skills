# pop-content-card

> 网文素材图文卡生产工具。输入素材主题，输出 5 页手机可读的 HTML 长图。v4.0.1

## 这个 Skill 做什么

输入：素材主题（如"恨海情天""100个古言氛围细节"）、可选账号配置（账号名、署名、收尾语、配色偏好）、可选风格。
输出：一张 1080×1920 竖版 5 页 HTML 长图，手机可读，可导出 PDF。

素材类型：桥段、字句、人设、写法拆解。生产流程自包含，不依赖外部内容 skill。

## 三层与三个维度的对齐

三层各自回答三个问题，且"好"的标准从上游传导到下游，不衰减：

| 层 | 定位（解决什么） | 什么是好的 | 如何写出好的 |
|:--|:--|:--|:--|
| **内容方法论** | 定义内容价值，即素材卡对读者有什么用 | 三可：可截图、可套用、可回看 | 素材句三层结构、生产公式、自检门禁 |
| **信息架构** | 把内容价值传导为可渲染数据 | 68字段全齐、8项校验（每项对应"三可"中的一项） | JSON输出、字段映射、校验门禁 |
| **视觉模板** | 把数据传导为读者0.5秒可感知的视觉 | 占比≥75%、无残留、三可可视化 | 母版填充、body class切换、密度检查 |

**质量传导链**：三可先传导为68字段与8项校验，再落到版式呈现。每层的"好"都从三可推导。脱离三可的工程检查（如"字段数对"但不"可截图"），即为不通过。

**执行模式**：由主agent直接执行。素材内容生产与模板填充是一条连续的创作链（Step 1产出的68字段JSON直接交给Step 2填充，中间隔着8项校验门禁），没有可交给子agent的环节。

## 怎么操作（流程全内联）

### Step 1 · 素材生产

**1. 读方法论**：`references/content-method.md`（生产前必读，含4类型生产原则、字段清单、自检门禁全表）。

**2. 主题分析**：判断素材类型（桥段、字句、人设、写法），提炼核心卖点（读者第一眼想搜索或想收藏的词），再对照「素材类型与5页结构」表选定结构。

**3. 内容生产**（核心质量标准，详见 content-method.md 第三节）：
- 每条素材句必须包含三层：物件或动作、感官细节、情绪暗示
- 素材句要具备"可改写性"：换掉身份、场景或代价后仍可复用
- 正误对照的"好"例子必须比"坏"例子多一层具体细节
- 名场面必须包含"选择"和"代价"
- 封面钩子句必须包含：具体物件或动作，以及情绪张力

**4. 按JSON格式组织产出**：产出格式为JSON（不是Markdown），字段名与HTML母版占位符一一对应。桥段型共68字段（60个内容字段加8个账号字段）：

| 区块 | 占位符字段 |
|:--|:--|
| 全局8字段 | TITLE, TOOLBAR_TITLE, ACCOUNT_NAME, ACCOUNT_INITIAL, FOOTER_SIGN, FOOTER_TAG, CLOSING_LINE, SIGNOFF_TEXT |
| P1 封面 | KICKER, TITLE_MAIN, COVER_SUB, COVER_HOOK（钩子句）, COVER_DECO_TEXT |
| P2 公式+素材句 | TOPIC_LABEL_2 / TITLE_2 / DESC_2, FORMULA_MAIN, FORMULA_KEY_1~4 + FORMULA_VAL_1~4, QUOTE_1~4（触觉/物件/动作/信息层） |
| P3 正误对照 | TOPIC_LABEL_3 / TITLE_3 / DESC_3, CONTRAST_BAD_TITLE_1~2 + CONTRAST_BAD_1~2, CONTRAST_GOOD_TITLE_1~2 + CONTRAST_GOOD_1~2, SUMMARY_TITLE_3 + SUMMARY_COPY_3 |
| P4 名场面 | TOPIC_LABEL_4 / TITLE_4 / DESC_4, SCENE_TITLE_4, SCENE_EXAMPLE_4, BREAKDOWN_1A~3B（3组标题+内容）, ROUTE_TITLE_A / COPY_A + ROUTE_TITLE_B / COPY_B（动作设计+情绪设计） |
| P5 收束地图 | TOPIC_LABEL_5 / TITLE_5 / DESC_5, ENDING_KEY_1~4 + ENDING_VAL_1~4（HE/BE/OE/转折） |

字句型：P2-P4替换为 `{{ITEM_1}}`~`{{ITEM_20}}`（每页15-20条），P5改为使用指南字段。人设型与写法型：参考 content-method.md 第二节的对应结构，调整字段。

**5. 字段校验门禁**（JSON产出后必须逐项校验，任一项不通过即回到第3步补内容，不得进入Step 2）：

1. **字段完整性**〔可截图〕：桥段型68字段（60个内容字段加8个账号字段），一个都不能缺
2. **字段非空**〔可截图〕：每个value不少于5字，不得出现空字符串
3. **素材句三层**〔可截图+可套用〕：每条 QUOTE_1~4 含物件或动作、感官、情绪暗示
4. **正误对照差异**〔可套用〕：每组好例（CONTRAST_GOOD）比坏例（CONTRAST_BAD）多一层具体细节
5. **名场面三要素**〔可回看〕：SCENE_EXAMPLE_4 须包含"选择""代价""情绪反差"三项
6. **封面钩子句**〔可截图〕：COVER_HOOK 须包含具体物件或动作与情绪张力
7. **结局可套用**〔可套用+可回看〕：每个 ENDING_VAL 须包含具体物件或动作、代价、记忆点
8. **感官覆盖**〔可截图〕：QUOTE_1~4 覆盖≥3种感官通道

校验通过后写入 `{主题}-content.json`，作为 Step 2 的直接输入。

### Step 2 · HTML视觉化

**1. 读密度规范**：`references/visual-density.md`（渲染前必读）。

**2. 复制母版**：把 `templates/html/master-template.html` 复制为 `{输出目录}/{主题}-素材图文卡-v1.html`。

**3. 选择风格**：把 `<body class="theme-warm">` 改为用户选定的风格class（见下「风格池」表）。

**4. 填账号占位符**（全局替换）：

| 占位符 | 说明 | 示例 |
|:--|:--|:--|
| ACCOUNT_NAME | 账号名 | 猫的咪 / 写作素材铺 |
| ACCOUNT_INITIAL | 头像首字母 | 猫 / 写 |
| FOOTER_SIGN | 页脚左侧署名 | 猫的咪｜网文素材积累 |
| FOOTER_TAG | 页脚右侧标签 | 脑洞与质感并存 |
| CLOSING_LINE | 末页收尾语 | 关注XX，继续攒网文素材。 |
| TOOLBAR_TITLE | 工具栏标题 | XX图文预览 |

无头像时用 `.brand-avatar` 纯色圆替代；无贴纸时用 `.signoff-visual` 纯色块替代（母版中均已有对应代码）。

**5. 字段匹配检查**：统计母版中 `{{...}}` 占位符的数量与JSON key的数量，两者必须一致。JSON缺字段即回到Step 1补内容，不得带着缺失字段填充模板。

**6. 按JSON填充母版**：逐个替换key与value对应的占位符。母版默认采用桥段型5页结构：P1封面（kicker、h1、cover-sub、cover-hook）；P2公式与素材句（formula-card、quote-stack 4条）；P3正误对照（contrast 2组坏例与好例、总结panel）；P4名场面（scene-paper、scene-breakdown）；P5收束地图（ending-grid 4个结局、signoff-card）。字句型调整：P2-P4替换为trope-grid（每页15-20条），P5改为使用指南。

**7. 填充后检查**：用正则 `\{\{[A-Z_]+\}\}` 检查母版有无占位符残留；有残留即JSON缺字段，回到Step 1补齐。

**8. 密度检查**：逐页检查内容占比，目标为75%至85%。低于70%时，加厚卡片、补素材槽、增加quote条数；超过90%时，压缩模块间距、内边距与行高（只压问题页，为其加单页class）。

**9. 页脚安全区检查**：主内容不得碰到账号名和页码；素材句页容易贴底，quote控制在4条左右。

**10. 写入文件**：`{主题}-素材图文卡-v1.html`。该文件自包含，用浏览器直接打开，可打印导出PDF。

**完成检查**：页面数和页码一致（5页）〔可截图〕｜每页主内容占比约75%-85%〔三可基础〕｜手机缩略图能读出标题和主要素材词〔可截图〕｜顶部与页脚账号名一致〔可回看〕｜末页有收尾视觉（纯色块或贴纸）〔可回看〕｜无`{{...}}`占位符残留〔可截图〕｜无页脚被遮挡〔可截图〕｜body class与用户选定风格一致〔三可基础〕。

## 素材类型与5页结构

| 类型 | P1 | P2 | P3 | P4 | P5 |
|:--|:--|:--|:--|:--|:--|
| **桥段** | 封面 | 公式+素材句 | 正误对照 | 名场面 | 收束地图 |
| **字句** | 封面 | 分类清单A | 分类清单B | 分类清单C | 使用指南 |
| **人设** | 封面 | 人设公式 | 素材句 | 正误对照 | 弧光+收束 |
| **写法** | 封面 | 原理拆解 | 正误对照 | 实战示范 | 检查清单 |

## 风格池（6套固定色板）

| 风格 | body class | 气质 | 适配题材 |
|:-----|:-----------|:-----|:---------|
| 暖纸调（默认） | `theme-warm` | 温暖手作 | 情感/古言/治愈 |
| 墨韵调 | `theme-ink` | 冷静克制 | 现代/悬疑/都市 |
| 青碧调 | `theme-jade` | 清新自然 | 种田/治愈/日常 |
| 赤金调 | `theme-gold` | 华贵厚重 | 权谋/大女主/宫斗 |
| 暮紫调 | `theme-dusk` | 神秘梦幻 | 奇幻/修仙/幻想 |
| 极夜调 | `theme-night` | 深邃暗黑 | 暗黑/无限流/恐怖 |

用户未指定时使用 `theme-warm`。切换方式是改 `<body>` 的 class，不得手改 CSS 变量。

## ❌ 铁律

| # | 铁律 | 违反后果 |
|:-:|:-----|:---------|
| ❌1 | **不得从空白写HTML** — 必须复制 `templates/html/master-template.html` 母版并改槽位 | 版式崩坏 |
| ❌2 | **不得改5页结构和模块类型** — 只填 `{{...}}` 占位符，不得增删页面、不得改CSS、不得加新模块 | 设计失控 |
| ❌3 | **只使用风格池配色** — 切换 body class 选择风格，不得手改 `:root` 变量或内联固定颜色 | 色彩混乱 |
| ❌4 | **单页占比 ≥75%，并守住页脚安全区** — 满页不等于贴底，主内容不得碰到页脚 | 手机不可读 |
