# 底层认识与手艺

> 立项的结构方法论全文。SKILL.md 只留菜单简表与判据，完整版放于本文件：Step 2 轮三拍板前读"谜底六型、四种关系、欲望线三律"，Step 6 挂伏笔线前读"揭说法八条"。
> 依据为《全书大纲生成方法论 v1.4》与四次实测（DND混合、无限流、守序邪恶家族修仙、灵气复苏与神豪盲测）。

## 一、结构三层分工

| 层            | 管什么            | 用在哪 |
| :----------- | :------------- | :-- |
| 英雄之旅、三幕、起承转合 | 一卷之内故事如何走      | 每一卷 |
| 日常线与伏笔线      | 几十个各自完整的小故事从哪里来 | 全书  |
| 欲望、谜底、出奇项    | 这本书最初的样子       | 立项  |

英雄之旅描述"一个故事"的形状，默认有终点。长篇连载要把一个大故事拆成几十个各自完整的小故事，所以它无法充当全书主干，只能管一卷。

## 二、日常线与伏笔线

| | 日常线 | 伏笔线 |
|:--|:--|:--|
| 产出 | 即时剧情单元：新地图、新案子、新生意、新对手 | 大转折：身份揭穿、身世、世界真相 |
| 素材的性质 | 现挖现用，换皮可无限重复 | 预埋，用一次少一次 |
| 管什么 | 章节级追读 | 卷级高潮 |
| 单独支撑全书的失败方式 | 三卷后审美疲劳 | 高潮之间没有正文填充，中途牌尽 |

- 铁律：**日常线管章节级追读，伏笔线管卷级高潮**。任何长篇都是这两条线的搭配方案，只配一条必然失败。
- 衍生线同理：情感线（情感债是预埋的牌，日常糖点是每轮的料）、经营线（资产逐轮累积）。理论形态是"两条线 × N 种走法"，下表四种仅为最常用的搭配。
- 接法四种：**接力**（前期一条、后期换一条）；**一明一暗**（并行）；**挂钩**（伏笔进度挂进日常单元，每单元推一点）；**喂料**（揭一层伏笔，解锁一块新地图）。
- 可安装在任意一级：主角个人、家族、宗门、商号。

**四种经典搭配**（Step 4 定线的候选库）：

| 搭配 | 循环内容 | 隐藏要求 |
|:--|:--|:--|
| 打怪升级换地图 | 地图是同心阶梯（新手村→城→宗门→国→大陆），每张地图内跑一轮完整小旅程 | 世界预先设计成阶梯——境界表是结构设定，不是力量设定 |
| 单元剧 | 外壳流程固定，每单元换内容（案件、副本、委托）；无限流是最彻底形态 | 外壳流程必须能无限复用不重样 |
| 马甲流 | 装→藏→险被揭→将揭未揭→揭→换马甲 | 每次揭穿＝一次卷级高潮结算，揭穿排期先定 |
| 层层揭开的世界谜底 | 每卷揭一层，同时埋更深一层 | 层的排布与设计法见第六节 |

前两条是日常线经典，后两条是伏笔线经典；一条日常线配一条伏笔线是最小可跑配置。

## 三、三线分工

| 线   | 内容          | 规则               |
| :-- | :---------- | :--------------- |
| 欲望线 | 主角要什么       | 线性推进。可组合、可接力，不反转 |
| 世界线 | 世界怎么了、落什么结局 | 全书所有反转、遮盖只放这条线   |
| 弧光  | 主角内在变化      | 与欲望线不同层，互不替代     |

- 欲望线是读者与主角的约定：点开书即立约，中途换欲望等于毁约。世界线翻面可以改变欲望的意义（他要的"家"是假的），不改变方向（他接着要）。

- 弧光：网文默认**平坦弧光**——主角信念不动摇，变的是世界对他的回应。要写"原来我要错了"，全书至多一次，放在结尾附近，与世界线最后一层同时揭开。

## 四、欲望线与世界线的四种关系

| 关系    | 形态                   |
| :---- | :------------------- |
| 同路    | 主角得偿所愿＝世界得救          |
| 相撞    | 主角想要的与世界需要的不能兼得      |
| 变了样   | 一路要A，最后发现A是B，以B的形态拿到 |
| 主角是钥匙 | 主角欲望达成的那一下，就是世界结局的开关 |

四种并列，不排序、不评高下。轮换纪律：同一出题人近三个案子用过哪种，撞了必须换。已知偏差：早期实测全部默认"主角是钥匙"，其后默认"变了样"——轮三拍板时先查这一项。

## 五、伏笔线类型菜单

| 类型     | 内容                | 常见流派        |
| :----- | :---------------- | :---------- |
| 身份差    | 读者知道、书里人不知道；揭穿即高潮 | 神豪、战神回归、马甲文 |
| 世界谜底   | 世界真相分层揭开          | 灵气复苏、玄幻、克苏鲁 |
| 系统来源   | 金手指从哪来、谁给的、要什么代价  | 一切系统文       |
| 复仇对象升级 | 仇人背后还有仇人，对手逐层抬高   | 都市、复仇文      |

只有选"世界谜底"才用说法清单法。谜底材料须从赛道自有的东西中生长（神豪文的钱、返利、账目），不得从个人趣味库搬用。

## 六、谜底六型（选世界谜底时用）

| 类型  | 问的那句话     | 真相的形状                      | 跟谁斗         | 代表      |
| :-- | :-------- | :------------------------- | :---------- | :------ |
| 被圈养 | 谁在养我们     | 有人拿我们当牲口或庄稼                | 活着的圈养者      | 天道流（写烂） |
| 遗产  | 主人去哪了     | 主人已死，世界是没人认领的家业，天道是自动执行的遗嘱 | 一份死人的合法意志   | 诡秘      |
| 铁律  | 这条规矩为什么存在 | 没有坏人，只有一条法则                | 法则本身＋利用法则的人 | 黑暗森林    |
| 残局  | 世界为什么还没完  | 终局早打完，现在是拖着不结算             | 拒绝终局的一方     | 回环流     |
| 废墟  | 乐园怎么塌的    | 没有恶人，只有事故和被抹掉的历史           | 遗忘和谎言本身     | 进击的巨人   |
| 真假  | 我和世界哪个是梦  | 谜底关于故事本身                   | 叙事自己        | 缸中之脑    |

**新鲜感权衡**：读者认为新的程度，等于元素的新意乘以谜底的新意，两项互相拆借。元素够怪（dnd＋克苏鲁），谜底用熟款能过；元素是老赛道（纯仙侠、纯都市），谜底必须自己扛。定谜底前先查赛道名作用的型，写烂清单里的不碰。

**层的排布与设计法**（选世界谜底时用）：

- 标准六层由外到内依次为：**异常、机制、阵营、权力、自我、本体**。最里层同时回答"世界怎么了"和"主角是谁"（一条根）。
- **由内向外设计，由外向内揭示**：先写最里层——一句话终极真相，必须是关于主角的；再问"如果这是真的，世界为了正常运转，必须把它误读成什么样"——每一级误读即为一层；成稿后从最外层揭起。
- 自检基准：任取一层，说出它改写了前面哪几层的含义。答不出，即这层只加信息，不是揭层。
- **用牌检查**：大约两卷揭一层大说法；埋的层数对照总卷数，缺额补埋或末卷转系列钩。

**设计者三个常犯的毛病**，写作时自查：

1. 一想"世界归谁"就往"有东西在养我们"上跑。
2. 一想"揭开要震撼"就造一套新词。
3. 一想"主角重要"就把主角写成系统的产物（样本、钥匙、容器）。

## 七、揭说法的八条标准

1. **翻面**：每揭开一条，读者要能回头重新理解之前的事。只是多知道一点新东西，不算揭开。
2. **换对手**：每条真相重新划一遍敌我。
3. **一条根**：最里面那条，最好既答"世界怎么了"，也答"主角是谁"。
4. **提前露影**：每条揭开之前，它早已以"不对劲"的样子被读者见过——能隐约猜到，但被误导猜错方向。
5. **有代价**：每揭开一条，主角烧掉一样东西——盟友、身份、信念、亲人。信息到了，疼也要到。
6. **不空转**：两次大揭之间，悬念小步推进（又多一个不对劲、半个答案）。
7. **省着用**：场面越揭越大，事情越揭越与主角相关；排期不与近期案子重复。
8. **逼选择**：最后一条揭开后，主角面对的必须是没有干净答案的选择。

四种失败形态：黑手背后还有黑手（只加码不翻面）；把揭开当百科讲（设定倾泻）；只挖不填（神秘盒病）；读者早猜到却不做误导（提前漏气）。

补两条：

- **一条根的两种感情**：善主角揭"我是谁"是惊喜；恶主角揭"我是谁"是恐怖（原来我这个性格本身就是条款）。结构不换，换感情。

- **恶主角的"在乎"**：靠两样——本事让人服，加上只剩下一个软肋。守序恶的收尾不是牺牲自己，是在规矩里赢下规矩本身。

## 八、欲望线三律

类型库：求生、变强、长生、回家、复仇、复活某人、找真相、挣钱兴家、守护、身份恢复。

- **组合律**：多欲望可并行（复仇＋变强），全书主打一两个，其余当配菜。

- **接力律**：欲望满足或幻灭后接下一个，接的比之前的大一号；读者不该觉得主角变卦，该觉得理当如此。

- **守约律**：欲望线立约后稳定兑现；要动它只有一次机会——"变了样"式置换，放结尾附近，动得越晚越值钱。

## 九、弧光

- 网文默认**平坦弧光**：主角信念不动摇，变的是世界对他的回应。

- 想上强度：给配角的弧光（主角不变，身边人变），比动主角安全。

- 最高级：欲望对象置换（"原来我要错了"）——全书至多一次，与世界线最后揭示同时发生。

| 测      | 输入           | 验出什么                        | 暴露什么                                             |
| :----- | :----------- | :-------------------------- | :----------------------------------------------- |
| DND混合  | dnd＋克苏鲁＋战锤入侵 | 流程跑得通；"在乎的人"与"最高潮"从结构里自己长出来 | ——                                               |

| 家族修仙   | 守序邪恶＋家族修仙    | 整套可装在家族上；主角阵营要跟日常线配套        | 谜底三连撞；黑话裸奔；大线写成危机串                               |
| 盲测（反面） | 灵气复苏×都市神豪    | 隔离上下文也能产出结构完整的大纲            | 没查底子就组装：神豪四爽点一个没排进前三卷，写成经营文；流程没锁"什么流的书"；文档带着作者品味 |

规律：**每测暴露一个没人自觉的默认习惯**（谜底总往一处想、词总往新造跑、大线总往危机写、关系总用同一格、品味总跟着文档走）。解法不是打补丁，是把每个想当然变成流程里明写的一步，再配一道自检。
