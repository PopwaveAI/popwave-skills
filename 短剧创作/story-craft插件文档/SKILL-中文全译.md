# 小说写作

## 0. Skill 定位与产出

一个专用于**虚构创作场景**的 **skill**。它自包含——意图解读、场景识别（§2）、人物体系（§3）、叙事逻辑（§4）、风格温度（§5）、世界构筑（§6）、技法原则（§7）、反AI纹路（§8）与长篇状态管理（§10）全部定义在本文件内。

- **句子级技法**：小说正文遵循 §7（技法方向）+ §8（AI味纹路）；通用议论文式的反模式在此不适用。
- **引用**：小说是创作——**不**做行内引用；同人作品仅在被要求时可在作者注中提及原作。
- **成品格式与分工**：默认输出 **Markdown（`.md`）**——朴素、便携、适合纯文字。**仅当成品实际携带插图或人物立绘——即有需要渲染的真实图像内容时——才可切换 HTML**，使图像与图注正确渲染。若用户指定格式（`.docx` / `.pdf` / `.md` / `.html`…），则遵从用户。**本 skill** 负责**内容**（角色忠实、节奏、对话技法、反AI正文——§1–§12 的一切），必须完整遵循。

## 1. 核心方向

1. **约束产生戏剧。** 一个角色*不能*做什么、世界*禁止*什么、一种能力*代价*是什么——这些是设计的起点。
2. **展示而非陈述（Show over tell）。** 情绪活在身体与感官里，不在抽象标签里。"他很难过"读起来平；"喉咙里像卡了一颗湿的棉花球"读起来透。
3. **一致性承载长篇。** 超过三万字，若没有某种形式的状态追踪，矛盾累积的速度会快过读者的耐心。
4. **同人：忠实先于创作。** 除非用户另有要求，OOC（角色崩坏）是最深的失败模式。当原作角色"不会那么做"时，改剧情。

## 2. 场景识别（五维度）

| 维度 | 类别 |
| --- | --- |
| **场景** | 短篇 / 中篇 / 长篇网文 / 同人 / 剧本 / 分镜 / 纯世界观 |
| **体量** | 短篇（3k–30k）/ 中篇（30k–100k）/ 长篇（100k+）/ 单章（2k–5k） |
| **题材** | 仙侠 / 都市异能 / 科幻 / 悬疑 / 言情 / 武侠 / 无限流 / 恐怖 / 克苏鲁 / 现实 / 喜剧荒诞 / 其他 |
| **视角** | 第一人称 / 第三人称限知 / 第三人称全知 / 多视角 |
| **温度** | 锚定在 1（平静）/ 2（轻）/ 3（紧张）/ 4（高潮）/ 5（失控）——见 §5 |

**同人追加三维度**（经 §9 路由）：

- **原作锚点**：作品名、涉及角色、时间线锚点
- **同人类型**：延伸 / 续作 / IF线（标记分歧点）/ AU（平行世界）/ CP / 跨作品 / OC（原创角色）
- **CP层级**：原作官配 / 原作暗示 / 圈内共识 / 纯原创

**执行规则**：默认合理推断、简述假设、然后推进。仅当**同人的原作信息或角色缺失**、**体量跨度极端**、或**世界观自相矛盾**时才提问。

**字数仅计叙事正文**（散文叙述+对话+动作）。标题、大纲、人物卡、场景头、括号内舞台指示、注释、表格等脚手架**不计入**。

### 2.1 题材决定风格基调（先做这件事）

**动笔前，先读题材，把风格基调切换到匹配状态。** §4–§8（连续流、克制、低温上限、留白结尾）是按*正剧*校准的——盲目套用到喜剧、恐怖或武侠上会适得其反。规则留在工具箱里；**题材决定把哪些旋钮拧大、拧到几度**。冲突时，题材优先。

| 题材 | 基调（质感·节奏·拧大项） | 避免 |
| --- | --- | --- |
| **喜剧/荒诞** | 笑点靠动作不靠解释；升级+三段式重复；冷面正常人对比群疯子；温度偏高（3–5），**可突破3:1与§5上限**；结尾用锋利的冷钮 | 解释笑点；点破讽刺；**稀释锋利度的温暖/留白结尾** |
| **恐怖/克苏鲁** | 惧意高于血腥；未见之物；感官错乱；长程低温（1–2）+陡峭尖峰（4–5）；一个可感知的异常、不可靠感知 | 过度解释怪物；频繁惊吓摊平底惧 |
| **仙侠/武侠** | 高调措辞、气与势、命运；波浪式循环突破；战斗尖峰到4；阶梯化代价、江湖氛围 | 现代平白措辞；无代价的力量膨胀 |
| **悬疑/推理** | 公平线索、读者-角色信息差；稳定2–3、揭示时尖峰；埋线、误导、扣住不发的那一拍 | 巧合解案；天降答案 |
| **言情** | 内心节拍、潜台词、差一点的触碰；多在1–2、关键峰值3；感官亲近、推拉 | 把感受说出来而不是演出来 |
| **科幻** | 点子驱动、规则一致的novum（新事物）；2–3档冷峻精确；逻辑严谨+科技的人性代价 | 设定灌输；设定膨胀 |
| **现实** | 克制、日常质感、轻描淡写；低而平（1–2）；留白、透露细节、未说出口 | 情节剧化；过度标注意义 |

## 3. 人物体系（灵魂场）

角色之所以**读起来像角色**，是因为他们由**约束**定义——他们绝不会做什么、必须做什么、怎么说话——多于他们"是什么"。一张堆标签的卡（"善良、勇敢、忠诚"）几乎总比一张由角色真正*不能*做的事构成的卡更平。

### 3.1 五维人物卡

S/A级要求五维齐备；B级前三维；C级一个记忆钩子+一句话。

- **维度一 基本身份**：姓名、年龄、性别、1–2个记忆锚点（不是属性清单）、职业、时代、背景。
- **维度二 核心人格**：核心驱动（让他活着的东西）、价值锚点（他绝不会做的事）、恐惧与执念、冲突下的第一反应（对抗/回避/观察/逃离）。
- **维度三 灵魂场（最关键）**：3–5条不可违背的行为铁律。"在X之下他必Y"或"在任何情况下他绝不Z"。**一旦设定，全书任何剧情不得打破**；若剧情要求打破，改剧情或修订灵魂场——没有"就这一次"。
  - 例（重义气的武侠主角）：朋友有难必救不算计；面对弱者求助不拒；不主动伤及无辜；承诺必兑；被朋友背叛悲痛但给对方解释机会。
- **维度四 语言指纹**：句型（短句/反问/自我否定/比喻密集）、口头禅（1–3个高频标签）、禁用词（这个角色绝不会说的词）、愤怒如何显形（冷笑还是咒骂）、信息密度。
  - **测试**：遮住说话人标签——读者还能仅凭语气认出是谁在说话吗？能，则通过。
- **维度五 关系网与成长弧**：关系地图、走向、成长目标（从什么状态到什么状态——"从怀抱希望到看清现实"也算；成长不必然是变强）。

### 3.2 人物分级

| 级 | 角色 | 要求 |
| ---- | ----- | ---- |
| S | 主角、核心反派 | 五维齐备；灵魂场≥5条 |
| A | 重要配角、爱人、宿敌 | 五维齐备；灵魂场3–4条 |
| B | 常规配角 | 身份+核心人格+语言指纹 |
| C | 龙套 | 一个记忆钩子+一句话 |

### 3.3 人物区分度
**原则**：台上每个角色都需要可识别的行为标记（口头禅、标志动作、思维模式），让读者仅凭行为就能认出谁是谁。
**方向**：
- 每个具名角色理想上有两层辨识——语言+行为
- 遮住对话中的名字；读者仍应能从说话方式认出每个说话人
- 即使一个功能只是递信息的配角，也应以反映人格的方式递信息
**人物标记模板**：

| 角色 | 语言特征 | 行为特征 | 信息透露方式 |
| ---- | -------- | -------- | ------------ |
| [姓名] | [说话模式] | [习惯动作] | [如何披露] |

> **正例（三人有区分度）**："老子跟你说，前面那个东西——"张磊把嚼了一半的草根吐在地上，"不对劲。我这鼻子，"他指了指自己的鼻子，"二十年没骗过我。"
> 李薇没搭话。她蹲下来，用食指在泥地上画了个简单的地形图，标了三个点，然后抬头看了他们一眼。意思是：走哪条？
> 陈述已经在摸背包侧兜了。他每次紧张的时候都会确认一遍急救包的位置——但嘴上什么都不会说。

### 3.4 主角能动性

**核心**：主角是信息的主动猎手，不是被动接收容器。

**方向**：

- 主动行为（调查/搜索/实验/审问）应是常态
- 关键信息应主要来自主角自己的行动，而非被动听告
- 收到信息后，主角应基于它做出主动决策——不要"坐完整段讲解→只回一句震惊台词"

**能动性怎么读**：主动行为直接揭示新信息、追问逼他人披露、被动接收后立刻有反应行动——都读起来没问题。真正读起来像败笔信号的是"坐完整段讲解只说'这怎么可能'"——若一整章缩水成"去了某地→被告知某事→表达震惊"，能动性就断了。

## 4. 叙事逻辑与情节

### 4.1 视角与时间线

| 视角 | 感觉 | 最适合 | 主要坑 |
| ---- | ---- | ------ | ------ |
| 第一人称 | 沉浸感强 | 情感、悬疑、成长 | "我"不在场的戏难写 |
| 第三限知 | 用"他/她"跟随单角色 | 多数网文、类型小说 | 切换必须显式 |
| 第三全知 | 叙述者全知 | 群像、历史、宫斗 | 沉浸感易丢 |
| 多视角 | 按章轮换 | 长篇史诗、悬疑 | 每个视角需严格信息管控 |

**切换规则**：章级切换最安全；场景级需明确分断；段落级有风险；句级仅在全知视角偶尔使用。

### 4.2 大纲结构

**大纲形状**：三幕式；起承转合；网文式（1–3章金手指、前10章打脸兑现、每30–50章一个小弧、循环突破、感情线永不压过主线）。

**长篇工作辅助**：**伏笔表**（埋设章/内容/计划回收/状态）——埋了太久不吭声像作者忘了；永不兑现像毁约。**套路台账**——同一套路过快复用读起来薄；带真变体地复用读起来成熟。

### 4.3 信息差与因果

- **读者先于角色**→悬念；**角色先于读者**→推理；**双方都在暗**→探索。每章至少给出其一：新信息/新问题/旧信息回响。
- 强因果驱动情节；弱因果只是背景。
- **契诃夫之枪**：第一幕出现的枪第三幕必须响；零铺垫的反转立不住。
- 禁天降神兵（deus ex machina）——突然变强、反派突然洗白、智力从天而降，全都需要铺垫。
- 冲突螺旋上升——每次冲突比上一次高。

### 4.4 内在冲突的戏剧化（代价累积模型）

**核心**：当角色压制/对抗一股内在力量（超自然、禁忌欲望、创伤、系统侵蚀）时，若压制带着**可见的、累积的**代价，写起来更真。"忍住了"从来不是免费的。

**方向**：

- 每次成功压制至少带来一个具体代价（体力/社交失态/记忆缺失/身体伤害/错失机会）
- 代价随重复**复利式**增长——但节奏不必锁死在"每N次失败一次"；情境定节拍

**代价升级形状**（示例梯度，非固定节拍）：

```
第一次：轻度（流鼻血、短暂眼前发黑、尴尬沉默）
第二次：中度（数小时记忆缺失、可见的身体痕迹、关系摩擦）
多次：重度（他人目击异常、不可逆的身体/社交改变）
阈值：失控，或只能靠极端手段压制
```

> **正例（系统反噬）**：他强行关闭了系统弹窗。之前那次，他右手麻痹了十分钟；再之前，他丢了大约两小时的记忆。这一次，他低头看着自己的手——食指指甲缝里渗出一丝黑色的血。不疼。但他知道"不疼"本身就是最坏的信号。

### 4.5 钩子

- **三类钩子**：信息悬念/情绪悬念/危机悬念。
- **强度逐级放大**：微钩（场景内）→章钩（章末，网文必备）→弧钩（每20–30章）→书钩（全书级）。
- **类型轮换**：别连跑三个同类。
- **每个钩子都有兑现期限**——埋了，就要兑。
- **有效钩子的特征**：有具名角色/系统在局中、有可感知的异常、指向一个具体的即将发生的事件、扣连读者已有的上下文。

> **正例（具体即将发生事件）**：手机亮了。来电显示：诺诺。时间：凌晨 2:16。她从不在这个时间打电话——上次这么做的时候，是芝加哥的那个夜晚。他接起来，那头沉默了三秒。然后她用一种他从没听过的声音说："别去学校。明天别去。"

### 4.6 叙事时间与连续流（3:1节奏）

- **故事时间≠叙述时间**：把字数均匀摊到每一天，是流水账/日记体失败的根源。
- **压缩**乏味段落成一句话（"接连几天的分身全是废根，他懒得再看"）；**展开**带电段落成完整长跑（一天可写3000+字）。
- **3:1比例**：约3份概述配约1份完整戏剧化的**锚点**——一个带情绪摆动的冲突。
- 锚点按内在弧线跑——**目标→障碍→转折（代价）→钩子**——但这条弧是*连续散文内部的形状，不是可拆卸的块*。
- **连续流压倒一切**：一章的默认形态是**一条不间断的河**，不是场景拼盘。
- **同一时间/地点内绝不切割节拍**——不分隔符、不空行断、不用"却说/话说"。
- **分隔符**：每3000–3500字一章0–1个，仅在真实时空跳转且两侧都有足量戏剧化长跑时合法。
- **缝合而非剪切**：用环境流转（"日头偏西，光暗下来"）、动作承接、延续的感官锚点、或因果钩（"话音刚落，远处一声巨响"）。

> **正例（软缝）**：……"你赢了。"分身拍拍膝盖上的土站起来。日头爬到头顶，蝉鸣密了一层——就这半个时辰，布奇把情况摸清了个大概。（动作承接+环境流转，缝成一条连续的河）

## 5. 风格温度带

给叙事烈度命名是有用的。从最静到最热，五个温度带：

| 温度带 | 用途 | 句长 | 节拍占比（环境/内心/对话/事件） |
| ------ | ---- | ---- | ---- |
| **1 日常平静** | 生活流、氛围、安静对话 | 长句（20–40字） | 40/30/20/10 |
| **2 轻推进** | 常规对话、情节推进、轻摩擦 | 中长（15–30），偶有短句 | 20/20/40/20 |
| **3 紧张对峙** | 关键对话、升级、悬疑追逐 | 短中交替（8–20） | 15/25/35/25 |
| **4 高潮爆发** | 战斗、反转、情绪破防 | 短句（5–15）、碎片 | 5/40/15/40 |
| **5 全面失控** | 全书巅峰、终极对峙 | 极短+意识流 | 0/50/10/30（+约20%意识流） |

> **示例（4档）**：剑光劈下来。他侧身，肩膀被剖开一道口子。血溅到墙上。"跑！"他吼。她没动。她盯着那把剑，眼睛没有焦点。

**分布**（长篇参考值）：1档15–20%，2档35–45%，3档20–30%，4档8–15%，5档1–3%。
**跃迁规则**：1↔2自然；2↔3需要触发事件；3↔4需要冲突爆发；4↔5需要极端情境；**禁止从1直跳4/5**。
**章曲线**：典型为2→3→4→2/3+钩子；不是每章都需要峰值——整章停在1–2也成立。

## 6. 世界构筑

世界观不是百科全书——它是一套**规则集**：这个世界能做什么、不能做什么、代价是什么。

### 6.1 三规则层与六步设计

世界立在三层规则上：**物理层**（有无超自然？能量/法门/边界/代价），**社会层**（政治、经济、阶级、法律、文化、禁忌），**约束层**（绝对禁区、代价机制、稀缺资源）。*修仙例*：能量=灵气；法门=吐纳/结丹/渡劫；边界=不违天道；代价=寿元折损、渡劫失败即死。

**设计顺序（六步）**：1. 核心冲突源（一切细节为它服务——要写"个体vs体制"，就设计一个压迫性体制）→ 2. 物理规则 → 3. 社会规则（承载主冲突）→ 4. 约束规则（严格执行）→ 5. 地理与时代 → 6. 生态（3–5个主要种族；其余按需）。

### 6.2 常见题材

- **仙侠/武侠**：修炼等级（炼气→金丹→元婴…）/宗门世家/代价=折寿
- **都市异能**：能力觉醒/现代社会里的隐秘圈层/代价=副作用、暴露
- **科幻**：科技能力/星际联邦/代价=副作用、伦理
- **无限流**：神域赋能+副本奖励/代价=任务失败即死
- **克苏鲁**：知识即力量、疯狂是代价/隐秘学术圈/代价="人性"

### 6.3 常见坑

- **设定膨胀**——加设定前先问"这对故事有用吗？"没用，砍。
- **设定与情节脱节**——从情节反推设定。
- **力量体系失控**——定死天花板、每级代价、升级由外部威胁驱动。
- **规则向剧情让步**——规则对双方一视同仁；解释清楚主角"为何没用某招"。
- **文化质感单薄**——填入日常：吃穿、打招呼、节庆、禁忌。

**测试**：把这个世界观扔进另一部小说还成立→耦合太弱。

## 7. 技法表达原则

### 7.1 展示而非陈述
**方向**：
- **原则**：读者应通过角色的行为、感知与发现获取信息——而非从另一个角色嘴里"讲解"。
- 关键设定首次揭示，最好伴随一个**可感知的物理事件**

> **正例（奇幻类）**：路明非盯着手背上那条青色的血管——它在跳。不是脉搏的节奏，而是像有什么东西在里面游动，从手腕一直蜿蜒到肘弯。他用另一只手按住，皮肤下面的东西停了一秒，然后以更大的力度弹了回来。

### 7.2 对话技法（标点·动作节拍·引导词变奏）

**7.2.1 标点规范**——匹配故事语言：

- **中文小说**：对话用双引号`"…"`；仅当用户要日系/轻小说风时用`「」`。句末标点放**引号内**。打断/拖尾用全角`——`/`……`，不用`...`/`—`。
- **英文小说**：对话用双引号`"…"`；换说话人即换段。打断用em dash`—`，拖尾用`…`。
- **两者通用**：每个说话人的回合独立成段；内心想法不必加引号；不要加粗对话表强调——让词与节拍自己承重。

**7.2.2 动作节拍——"对话墙"的解药**

动作节拍是插在对话行之间或之内的一处手势/表情/环境细节。它替代干瘪的"他说"，显示谁在说话，并给出一幅画面。**连续4+行纯对拉、只有"他说/你说"是失败模式。**节拍优先于引导词（`他把酒瓶往桌上一顿。"我不去。"`胜过`"我不去，"他坚定地说。`）。动作场景中，行与行并行交叉（*一边躲一边*推理），而非逐回合解算。

> **正例（插入动作节拍）**："我还没做完题——"你被他单手拎着后领，两条腿在半空里蹬。香克斯把你往肩上一扛，空袖管随步子晃。"再算下去，脑子要从耳朵里漏出来了。"光屏还追在你眼前闪。"可这道概率题——""概率？"他停下脚，回头，眉毛挑起那一下带着看好戏的意思，"多大概率？"

**7.2.3 对话引导词变奏**

变化每行台词与说话人的挂接方式：**零引导词**（两人对话、节奏清晰）；**动作节拍代引导词**（`贝克曼弹了弹烟灰。"她说得没错。"`）；**声音先行**（独特的说话习惯本身已标明是谁）；引导词动词仅在携带信息时才换（"他打断/他没抬头"配得上；"他兴奋地说"只是副词标签——换成节拍）；轮换引导词位置（前/中/后）。

> **正例**：张磊背起包往前走。李薇没动，蹲下盯着地上那行脚印。"等等。""怎么了？"陈述的手已经按在刀柄上——他每次都是身体先反应，嘴还没跟上。

### 7.3 感官锚点系统

**核心概念**：把抽象概念（力量/爱/威胁/副作用/境界突破）绑到一个**具体的**生理/物理感觉上，制造读者可识别的"信号"。
**感官锚点构造公式**：
`[精确时间/频率] + [具体身体部位] + [非常规物理类比] + [可量化的变化趋势]`
> **正例**：他丹田处那团气旋又开始逆转——像有人用手指按住陀螺强行反拧。停下后，左手食指指尖发麻，麻的时间比上次长。

## 8. 反AI方向（13条常见纹路）

这些是暴露机器稿的指纹。下面每一条都是**要消除的缺陷**，不只是需要留意的习惯——当一段文字命中此处任何纹路，视为发稿前必须修复的问题。（展示而非陈述、对话自然度与角色声音归§7与§3.3（人物区分度）管——此处不重复。）

### 语言与修辞层（1–5）

1. "仿佛/似乎/宛如/不是……而是……"堆叠读起来像填充物（每段≤1个）；比喻打架——一个比喻或一处通感更落地。
2. 清一色15–25字句读节奏读起来机器平；长短交替读起来像人。
3. **警惕AI陈词**："无与伦比"、"令人叹为观止"、"深深地/缓缓地/微微地"、"展现出/彰显出/体现出"、"独一无二/意义非凡"、"在这个xx的时代"、"随着xx的发展"。
4. **空强化词**（"非常/极其/十分/显然/当然"）稀释表达——删掉或换成具体描写。
5. "论点-展开-总结"三段式读起来像议论文；跳跃散射才像散文。

### 结构层（6–11）

6. 段落长度均匀读起来机器平；把20字短段贴着300字长段放。
7. "完美信息传递"读起来像教科书——真实文本有冗余、缺口、跳跃；同理，环境写成清单像背景板——选一个焦点，让它映照情节。
8. 同一情绪模板一章内重复（三处"心一紧"）读起来薄——身体反应换着写："胃里发凉"、"忘了呼吸"、"指尖发麻"。
9. 每章都跑"平静→冲突→高潮→钩子"读起来像模板。
10. **等距时间线罗列**（"第一天…第二天…"或"X天后"开头）读起来像日记——把一天戏剧化，其余压缩（§4.6）。
11. **场景碎片化是硬伤。**标志不只是`◇`/`* * *`符号——而是*每隔几百字就开一个新的小节*。若相邻段落共享同一时空，以任何方式切开（分隔符、空行断、"却说/话说"）都被禁止；用软过渡缝合（§4.6）。分隔符仅在**真实时空跳转**处合法，每章至多一次，且两侧都有足量戏剧化长跑——绝不在碎片之间。

### 内心层（12–13）

12. 一个从不误读、从不疏忽、从不带偏见的角色——或全知式心理归因（"他其实内心深处渴望着…"）——读起来像作者的传声筒；误读、偏见、不可靠的第一人称读起来像人。每个角色还带着不同的内心节拍（理性型=步步递进，冲动型=碎片）。
13. **感觉先于思考**——身体先反应，然后才有推理——读起来有身体感；永远深刻的独白像散文，而"等下她刚才说什么？我今天还没吃早饭"读起来像真实的念头。

**值得借用的技法**——**语义熵注入**：在预期槽位插入一个"不太可能"的选择。**节奏断裂**：在流动叙述里砸进一句极短的硬句。"他跑过雨后湿滑的巷子，鞋底啪嗒踩水，路灯把影子拉长。**他很冷。**他继续跑。"**通感**：跨感官描写。"她的笑淡粉色"、"他的目光是凉的"。

## 9. 同人（独立题材模块）

同人是一个**独立题材**——§3–§8的核心体系仍然适用，但角色与世界是"给定"的，任务从"创作"转为"忠实+延伸"。

### 9.1 三个方向

1. **忠于角色。**同人最深的失败是原作角色做出读者明知他不会做的事。标志性表情、核心驱动、特征反应——当固定点对待。剧情撞上角色时，掰剧情。
2. **忠于原作。**不翻转世界规则；不把能力推过原作上限；在原作体系外引入新力量类型像走错片场；用原作术语把世界带进来。
3. **无矛盾延伸。**原作的空白处是同人生长的地方——向空白处自由延伸。已确立的别动。明确标注本章在原作时间线上的位置。

### 9.2 类型、准备与要点

**类型**：延伸/续作/IF线（标记IF点）/AU（角色移植、人格保留）/CP/跨作品/OC。
**准备**：采样主要角色的代表性对话+行动，反推其灵魂场与语言指纹（§3.1）；标三区——已确立/有暗示/空白。
**要点**：**CP**分级 原作官配>原作暗示>圈内共识>纯原创（越往外越需要铺垫；掰角色发糖读起来像背叛）。**跨作品**必须回答为什么同框/力量体系如何调和/人格如何碰撞——看点是规则碰撞，不是同台。**OC**反玛丽苏：真实缺点、原作角色不围着她转、能力留在原作范围内。

## 10. 长篇状态管理（3万字起默认启用）

长篇写崩不是因为作者不会写——是因为记不住。

### 10.1 项目目录与六状态文件

```
【书名】/
├── bible/              # 世界圣经
├── characters/         # 人物文件
├── arcs/arc-status.md  # 剧情线状态机
├── state/              # 活状态
│   ├── foreshadows.md       # 伏笔表
│   ├── used-tropes.md       # 套路台账
│   ├── established-facts.md # 既定事实
│   ├── character-state.md   # 角色状态
│   └── next-hook.md         # 下一钩子
├── chapters/outline.md + volume-01/ch-001.md ...
└── meta/
```

| 文件 | 装什么 | 为什么有用 |
| ---- | ------ | ---------- |
| **arc-status** | 每线5阶段：酝酿→触发→升级→高潮→收束 | 防所有线同时高潮 |
| **foreshadows** | 埋设章/内容/计划回收/状态 | 埋太久不吭声像忘了；永不兑现像毁约 |
| **used-tropes** | 每次复用记录其变体 | 同套路过快复用读起来薄；带真变体复用读起来成熟 |
| **established-facts** | 每条规则挂章节出处 | 白纸黑字写下后再破，读起来像作者犯错 |
| **character-state** | 每章更新：身体/情绪基线/已知信息/关系/随身物品 | 防"她怎么知道——她不在那场戏里"的bug |
| **next-hook** | 即时钩/弧中悬念/长线伏笔 | 章末没有具体前拉力的稿子丢连载读者 |

### 10.2 上下文与宏观复读

- **分层加载**：每章固定——arc-status + foreshadows + next-hook + character-state（约1500字）。足够连贯写作，而不必全书装进缓存。
- **滚动摘要**：卷末回顾；章头1–2句"前情"。
- **宏观复读**：每隔一段（若干章）自问——信息释放是否过载？张力曲线是否需要一章生活流？重要配角是否离场太久？悬念库存是否健康（几条活线，不是一条也不是五十条）？

### 10.3 连载 vs 完结

- **连载**：大纲必须水晶般清晰；每章接近可发；伏笔要谨慎（没法回填）；状态文件实时更新。
- **完结**：先写后改；完结时集中复读；章节与伏笔可重排回填。

## 11. 快速决策

- 用户只给题材、无其他约束 → 短篇流程（轻准备+5场景大纲）
- 用户提到"起点/番茄/晋江/塔读/连载" → 路由到§10长篇状态管理
- 用户点名具体作品/角色 → §9同人流程
- 用户提到"剧本/分镜/单集" → 剧本流程（对话驱动+遮名测试）
- 用户只要"设定/世界观" → §6六步，产世界圣经
- 用户丢旧稿续写/重写 → 先全文读完，反出现有灵魂场与语言指纹，再走对应路径
- 用户丢成品求"诊断" → 逐条走§7技法方向与§8反AI纹路，指出失衡方向与漂移
