## 0. 一句话卖点

**popwave 的力量体系不是一个"等级表"，而是"四层结构 + 动力引擎六组成"的完整宇宙引擎——成长线、敌人线、爽点线、世界观线四线同源，11 文件按因果单向生成，世界是活的而不是设定集。**

## 1. 用户痛点：大多数世界设定，写着写着就崩

| 痛点 | 表现 | 后果 |
|---|---|---|
| **力量体系悬空** | 写了个"练气→筑基→金丹"等级表，但不知升级凭什么、代价是什么 | 主角突然变强读者觉得假 |
| **世界只是背景板** | 势力/地理/民俗和主线脱节，设定像百科词条 | 剧情和世界两张皮 |
| **前后矛盾** | 后面写的新设定跟前文冲突 | 崩设定、崩世界观 |
| **等级没用** | 敌人强度和主角成长对不上，爽点全靠硬编 | 战斗无聊、成长没反馈 |

> 核心难点不是"想设定"，是"想让设定的每一块都长在同一棵因果树上、并能被剧情/战斗/成长消费"。popwave 用"力量体系四层 + 动力引擎六组成 + 11 文件因果链"把世界做成"活的引擎"。

## 2. 关键认知：力量体系≠等级数字，它是"四层引擎"

| 层 | 是什么 | 回答了问题 |
|---|---|---|
| **世界源力量** | 力量从哪来、怎么转化/晋级、敌分级标准 | 力量为什么存在 |
| **主养成线** | 主角 5-7 阶段位、每阶怎么升、代价是什么 | 成长快慢、爽点节奏 |
| **子养成线** | 3-5 条辅助路线（炼器/炼丹/血脉…） | 丰富玩法、分布式成长 |
| **交叉规则** | 协同/制约/等价交换/涌现等 ≥5 条 | 力量体系的博弈张力 |

> 卖点：力量体系 = **成长线 + 敌人线 + 爽点线 + 世界观线的交汇点**，不是单独一张说明书。第 3 节是反面教材。

## 3. 反面教材：为什么"等级表"最难看（我们敢说这是坑）

- **只有层级没代价**："练气→筑基"写好大境界，但升级没有规则、代价、前置资源。→ 主角想升级就升级=开挂，无张力。
- **只有主角没世界**：力量体系只服务主角，其他角色/反派/众生怎么变强一片空白。→ 世界失衡，反派像纸片。
- **文件零散互相矛盾**：设定散落多个文件，无因果顺序、无引用约束。→ 后面写得越多，前面越容易穿帮。

## 4. 机制：把"宇宙"做成一棵因果树（test-world · 工程级）

### 4.1 力量体系四层结构 + 颗粒度 8 项硬约束
- **表 3 颗粒度 8 项**（红线硬门槛）：主养成线三层结构 + 升级代价 + 敌分级 + 数值锚密度 + 子养成线 + 交叉规则 + 进阶仪式 + 双线机制。少一项=力量体系不合格。
- 具体量化：主养成线"凡人 N 阶 + 超凡 M 档 + 3 大质变点"；升级代价**经验指数增长**；子养成线 3-5 条；交叉规则≥5 条。
- **小巧思**：升级不是"刷怪涨经验"，而是"资源 + 代价 + 规则 + 世界观交互"——主角必须通过世界内资源、代价、约束才能变强，杜绝无限膨胀。

### 4.2 动力引擎六组成：世界为什么"自动运转"
- 六组成：驱动逻辑 / 运转机制 / 众生攀登四群体 / 代价结构 / 范式归类 / 演化节点。
- **引擎是世界级的，不是主角独有**；掉落机制必设；非主角变强路径≥5 条。→ 势力、反派、配角、众生都从同一引擎生长，世界有活在动，不是围着主角转。
- **小巧思**：四群体(众生攀登)让"别人也在成长"，主角不是唯一变量—世界存在共生、竞争者、威胁。

### 4.3 11 文件因果顺序：世界按因果单向生长
- 物理规则 → 战斗系统 → 政治经济 → 民风民俗 → 地理建筑 → 势力人物 → 危机敌人矛盾 → 世界规则表 → 世界设计原则 → 类型风味基线 → 各卷切片。
- **铁律**：后文件可引用前文件，**禁止反向**。→ 世界是逐层生长出来的，不是补丁拼的。

### 4.4 类型风味锁死：不让世界"串味"
- PRD 声明的类型/风味基调是命名、器物、社会符号的唯一参考系，5 类文件逐文件检查偏离。→ 西幻不混入仙侠词、末世不串修真味。

## 5. 可测量 / 门禁：世界合格有量化线

| 门禁 | 口径 |
|---|---|
| **表3颗粒度8项** | 全达标，少一项不合格 |
| **主养成线** | 凡人N阶+超凡M档+3质变点，升级代价指数增长 |
| **子养成线** | 3-5 条 |
| **交叉规则** | ≥5 条（协同/制约/等价交换/涌现） |
| **非主角变强路径** | ≥5 条（动力引擎） |
| **11文件因果单向** | 后引用前，禁反向 |
| **类型风味锁定** | 逐文件检查不串味 |

## 6. 深度：世界只管"棋盘"，人物卡留给角色库
- **红线**：world 只管世界不管人——势力文件只写组织棋盘和一句话人物锚（谁当家/谁代表），完整人物卡是 character 的职责。→ 分工干净，不重复建角色，世界层保持唯一来源。

## 7. 操作顺序
先定力量体系四层 + 颗粒度 8 项（**攻克成长与代价**）→ 建动力引擎六组成（**让世界自己动**）→ 按 11 文件因果顺序长世界 → 全库类型风味自检。**不是先想一堆地名，而是先让引擎转起来。**
