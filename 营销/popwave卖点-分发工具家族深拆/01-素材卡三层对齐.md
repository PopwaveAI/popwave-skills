## 0. 一句话卖点

**popwave 把素材卡做成"读者会收藏"的卡片：三层×三维度对齐保证内容价值不衰减（可截图×可套用×可回看），68 字段 JSON 一一对应 HTML 母版、8 项自检门禁，四素材类型×四套 5 页结构、6 套锁死色板，单页占比 75-85%、字号服务手机阅读。不是字段齐全就完事——是"值得收藏"作为唯一验收标准。**

## 1. 用户痛点：素材卡"字段齐全但没人收藏"

| 痛点 | 表现 | 后果 |
|---|---|---|
| **只堆字段** | 打个卡看起来信息很多，但不可截图/套用 | 读者划走不收藏 |
| **手写HTML易漏** | 占位符残留、字段缺失 | 渲染出错 |
| **素材句空泛** | 只会堆形容词，没有具象载体 | 无保存价值 |
| **排版失控** | 太密看不清 / 太空不显内容 | 手机阅读体验崩 |

> 核心焦虑：内容卡的核心不是"做了张图"，而是"读者愿不愿意保存/转发/套用"——每一层设计都要服务这个行为。

## 2. 关键认知：让"内容价值"成为验收的唯一标准

高质量内容卡 = 三层同构（内容方法论"三可" → 信息架构 68 字段 → 视觉模板）保证价值不衰减；**任何脱离三可的工程检查（字段数对但不可截图）都不通过**。每个模块绑定读者可截图/套用/回看的行为。

## 3. 反面教材：把"信息全"当"内容好"

- **字段数对但不可截图**：满足所有字段校验，但读者看到的是不可存的废料。
- **堆形容词**：素材句是"她很难过"，没有物件/动作/感官——无法套用。
- **手写模板漂移**：每次从空白写 HTML，结构逐渐乱、占位符残留。
> 正确做法：见第 4 节——三可验收 + 68字段母版 + 素材句三层 + 密度门禁。

## 4. 机制：三层对齐 + 68字段 + 四类型5页 + 色板 + 8项门禁 + 密度/字号

### 4.1 三层×三维度对齐（核心）
**内容方法论（三可）→ 信息架构（68字段×8项校验）→ 视觉模板（0.5秒可感知版式）**。三层同构，任何脱离三可的工程检查都不通过——内容价值不衰减。

### 4.2 68 字段 JSON 模板，一一对应 HTML 母版
桥段型 JSON = 60 内容字段 + 8 账号字段，字段名与 HTML 母版占位符 `{{...}}` 一一对应。生产后先校验字段完整性/非空/素材句三层/正误对照/名场面/封面钩子/结局/感官覆盖，任一不通过不得进 Step2。

### 4.3 四素材类型 × 四套 5 页结构
桥段型（封面→公式+素材句→正误对照→名场面→收束地图）/ 字句型（封面→清单A/B/C→使用指南）/ 人设型（封面→公式→素材句→正误对照→弧光+收束）/ 写法型（封面→原理→对照→示范→清单）——输入主题自动匹配类型与结构。

### 4.4 6 套锁死色板（小巧思）
默认 `theme-warm` + 墨韵/青碧/赤金/暮紫/极夜；**切 `<body>` class 换风格，禁止手改 `:root` 变量**——风格池保证色彩一致。

### 4.5 8 项自检门禁
字段完整性/非空(每value≥5字)/素材句三层(物件动作+感官+情绪暗示)/正误对照差异(好例比坏例多一层细节)/名场面三要素(选择+代价+情绪反差)/封面钩子句/结局可套用/感官覆盖(≥3种通道)——任一不过回 Step1。

### 4.6 素材句三层结构 + 正误对照标准（小巧思）
好素材句 = 物件/动作（具象载体）+ 感官细节（让读者看到）+ 情绪暗示（不直说但能感觉到）。正误对照：坏例停概念（"心跳好快手发抖"），好例多一层物件细节（"指甲陷入掌心，疼意让他回过神来"）。

### 4.7 手机可读：竖版5页 + 密度 + 字号
1080×1920 竖版 5 页长图，打印可导出 PDF。单页主内容占比 75-85%（<70空 / >90贴底）。字号体系服务手机：封面核心词140-156px/主标题56-58px/正文28-30px/标签21-22px。

### 4.8 模块复用（小巧思）
8 种模块各对应不同"可"：公式卡=可套用、引用栈=可截图、正误对照=可套用、场景纸=可回看、清单网格=可截图、结局卡=可套用+可回看、收尾卡=可回看——**模块不是装饰，是读者行为路径**。

### 4.9 模板母版
必须复制 `master-template.html` 改槽位，禁止从空白写；禁止增删页面/改CSS/加模块；只用 `{{...}}` 占位符替换，填充后查无残留/页脚安全区/密度达标——防结构漂移。

## 5. 可测量 / 门禁

| 门禁 | 口径 |
|---|---|
| **三可验收** | 可截图×可套用×可回看，不可存即不过 |
| **68字段** | 60内容+8账号，与母版占位符一一对应 |
| **8项自检** | 句子三层/正误多一层/名场面三要素/感官≥3等 |
| **密度** | 单页75-85%，避免空页贴底 |
| **母版** | 复制母版改槽位，禁手写/漂移 |

## 6. 深度：内容卡是"素材→传播"的转化层
被视觉/短篇/番茄等写作家族的素材产出消费，出可收藏长图。**营销价值**：它把"做素材/写内容"升级成"每层都服务于读者愿收藏的行为"，是内容分发家族离读者最近的一环。

---

## 7. 操作顺序（先内容，再视觉，再自检）
确认主题→定素材类型（4种）→ Step1 内容（68字段JSON + 8项自检必过）→ Step2 视觉（复制母版 + 6色板 + 密度/字号）→ 校验无占位符残留 → 交付可导出PDF长图。
