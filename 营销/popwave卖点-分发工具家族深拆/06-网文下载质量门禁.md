## 0. 一句话卖点

**popwave 把"下本网文"做成质量可追踪的工具：三阶段 SOP 脚本失败强制 web 搜索兜底、三级质量状态（success/success_with_warnings/poor_quality）驱动换源或补爬、内容污染自动截断 + 防盗占位符/章节缺失自动统计、默认排除付费墙网站、UA 轮换池降反爬、断点续爬失败章节单独恢复、9 个 JSON 状态字段让下载过程可审计——不是"下完不管"，是"每本书下载质量可判断、可补、可追溯"。**

## 1. 用户痛点：下载"搜不到就放弃、质量不知、夹杂垃圾"

| 痛点 | 表现 | 后果 |
|---|---|---|
| **搜不到就放弃** | 脚本失败直接结束 | 白跑 |
| **质量黑盒** | 下完不知道缺没缺、脏不脏 | 无法交付决策 |
| **夹杂垃圾** | 广告/其他小说混入正文 | 文本不能直接用 |
| **章节残缺** | 防盗占位符/断档缺章 | 整本不完整 |
| **误搜付费墙** | 下到残缺照还要重跑 | 浪费算力 |

> 核心焦虑：下载是整条产线的源头——文件脏/缺/不全，后面拆书、DNA、挖掘全部失真。

## 2. 关键认知：下载交付的本质是"质量可追踪"

高质量下载 = 三阶段兜底提成功率 + 三级质量状态驱动决策 + 污染/占位符/断档自动检测统计 + 合规门禁（默认排除付费墙）+ 断点续爬降重试成本 + 9 字段 JSON 可审计——**下完不黑盒，缺啥脏啥都能量化**。

## 3. 反面教材：一键下载后不管质量

- **搜不到直接放弃**：脚本 error 就结束，不带 web 兜底。
- **交付无质量状态**：拿到的是脏的还是缺的都不知道。
- **污染不清理**：正文混着别的书/广告直接进拆书，整条链失真。
- **整本重跑**：一节失败就要从头来，白烧算力。
> 正确做法：见第 4 节——三阶段兜底 + 三级状态 + 检测统计 + 断点续爬 + 9 字段审计。

## 4. 机制：三阶段SOP + 三级质量状态 + 检测 + 合规门禁 + 断点续爬

### 4.1 三阶段 SOP，失败强制兜底（核心）
Phase1 脚本自动搜索 `python3 scripts/download_novel.py`；status=error 强制进 Phase2——web 搜索至少 3 组关键词（`{书名}{作者}笔趣阁`、`{书名} txt 下载`、`{书名别名}`），找章节列表页/直链后用 `--source-url` 重新下载；Phase3 验证 JSON status/warnings/preview/poor_quality。

### 4.2 三级质量状态（核心，小巧思）
`success`（warnings=[] 直接交付）/ `success_with_warnings`（检查 preview 正文正确后交付）/ `poor_quality`（查 contamination_found/chapters_missing/chapters_truncated，决定换源重下或 `--resume` 补爬）——**交付决策可执行**。

### 4.3 内容污染检测（小巧思）
下载后自动扫描并截断尾部垃圾；FOREIGN_CONTENT_MARKERS 检测其他小说混入（如与本目标书无关的人名/概念），跨书污染自动标记。

### 4.4 防盗占位符 + 章节连续性检测（小巧思）
ANTILEECH_MARKERS 检测「正在手打中」「请稍后刷新」等，统计 chapters_truncated；章节编号连续性检测 chapters_missing——**缺失信息可量化，不靠猜**。

### 4.5 合规门禁：默认排除付费墙（小巧思）
PAYWALL_DOMAINS 含 qidian/jjwxc/zongheng/17k/kanshu/zhulang 等 12+ 域名，默认排除；可用 `--include-paywall` 显式放开——**质量+合规门禁内置**。

### 4.6 反爬稳定性 + 断点续爬（小巧思）
USER_AGENTS 5 个主流浏览器 UA 轮换降封禁；JSON 含 chapters_failed，HTTP 失败章节可 `--resume` 单独补抓，不重跑整本。

### 4.7 多策略下载 + 可控参数（小巧思）
统一入口 `download_novel.py` 覆盖搜索/`--source-url` 直用 URL/`--direct` 直链 TXT/ZIP/`--workers 16` 并发；`crawl_novel.py` 列表页+逐章爬取；`download_text.py` 本地导入+网页提取转 UTF-8 TXT。参数含 `--author/--reverse/--limit N/--content-selector`（手动指正文 CSS 选择器）`/ --chapter-selector`。

### 4.8 9 个 JSON 状态字段，下载可审计
status / chapters_crawled / chapters_failed / chapters_truncated / chapters_missing / contamination_found / paywall_warnings / warnings——覆盖成功、失败、防盗、断档、污染、付费墙、警告，全过程可追踪。

## 5. 可测量 / 门禁

| 门禁 | 口径 |
|---|---|
| **Phase2 兜底** | 脚本 error 强制 web 搜索 ≥3 组关键词 |
| **三级状态** | success/success_with_warnings/poor_quality 驱动决策 |
| **污染检测** | 尾部垃圾截断 + FOREIGN_CONTENT_MARKERS |
| **残缺量化** | chapters_truncated + chapters_missing 自动统计 |
| **合规门禁** | 默认排除 12+ 付费墙域名 |
| **断点续爬** | chapters_failed→--resume 单节补抓 |
| **可审计** | 9 JSON 状态字段 |

## 6. 深度：网文下载是"拆书/DNA/挖掘"的源头
工具从 `scripts/` 提供 search/crawl/batch/download_text 四入口。**营销价值**：它把"下本网文"升级成"质量可追踪、失败可兜底、缺失可量化、过程可审计"的工程动作——保证产线第一道工序不脏、不缺、不黑盒。

## 7. 操作顺序（先脚本，失败兜底，再验证）
`download_novel.py "书名"`→ 看 status；error→ web 搜索 3 组关键词 + `--source-url` 重下；完成后验 JSON 三级状态（污染/占位符/断档）；poor_quality→ 换源重下或 `--resume` 补爬 → 交付干净 TXT。
