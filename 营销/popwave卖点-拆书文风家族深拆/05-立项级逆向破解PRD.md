## 0. 一句话卖点

**popwave 把"一本爆款书为什么成立"逆向破解成语用的立项 PRD：核心假说/赛道判定/卖点读者承诺全部要 chXX 证据支撑，逆推出全书结构、主角驱动、读者体验曲线、商业可行性（市场+竞品+风险预警），末尾附开写前启动检查清单与可复用资产清单。不是"这本书讲了什么"，是"为什么成立、怎么写出来"。**

## 1. 用户痛点：看到爆款书"只羡慕，拆不出方法"

| 痛点 | 表现 | 后果 |
|---|---|---|
| **只能当读者** | 知道好看，说不清"好看在哪、怎么成立" | 无法迁移到自己书 |
| **结论靠书名** | 按书名/直觉判断赛道，不拆数据 | 判断失真 |
| **设定会乱** | 等级/数值/代价靠记忆复述 | 力量体系失真 |
| **立项无检查** | 拆完不知道开写前还缺什么 | 落地卡壳 |

> 核心焦虑：立项级拆解的价值在"把爆款逆向成一张带证据、能直接开写的施工图"，而不是内容概括。

## 2. 关键认知：逆向破解 ≠ 内容概括，结论必须有 chXX 证据

高质量立项 PRD = **逆向破解总结**（核心假说/赛道判定/卖点读者承诺 → 全 chXX 可溯）+ 结构/主角/读者体验/商业可行性推断 + 启动检查 + 可复用资产清单。**红线**：禁止凭书名/直觉编造核心假说、禁止凭书名猜测赛道。

## 3. 反面教材：把立项 PRD 写成"读后感"

- **只概括**：写满剧情梗概、人物表，没有"为什么成立"与"怎么写"。
- **拍脑袋判赛道**："这书是玄幻，因为书名带'圣'"——不拆力量体系/世界基调/爽感公式。
- **核心假说靠编**：不引用故事机制 DNA 与有效事件清单，凭书名臆测。
- **卖了不落地**：PRD 读完是份报告，没有"开写前还差什么"的检查。
> 正确做法：见第 4 节——逆向破解 + 商业可行性 + 启动检查 + 资产清单，全证据化。

---

## 4. 机制：逆向破解 + 结构/主角/体验推断 + 商业分析 + 启动检查 + 资产清单

### 4.1 逆向破解总结（第一部分）
核心假说 / 赛道判定 / 卖点与读者承诺 / 目标读者——**每个结论都必须可追溯到期维度产出中的 chXX 证据**。帮助用户理解"这本书为什么成立"。

### 4.2 核心假说必须 chXX 支撑
核心假说来源于故事机制 DNA 的**核心矛盾链**，由故事 DNA 的有效事件清单提供 chXX 证据——红线禁止凭书名或直觉编造。

### 4.3 赛道判定基于实际拆解
基于力量体系类型 + 世界基调 + 名场面库爽感公式**交叉判定**——红线禁止凭书名猜测赛道。

### 4.4 全书结构设计
从故事 DNA 按幕拆解 + 卷纲推断：预估卷数/章数/力量体系代际数/核心矛盾/卷次划分/金手指阶段/主角状态变化——把拆书转成可写结构蓝图。

### 4.5 主角驱动设计
主角初始/终点状态、核心驱动事件、表层欲望、深层需要、致命缺陷、金手指关联——从角色弧线和成长曲线提取；成长曲线缺失标"数据不足"。

### 4.6 读者体验分析
基于读者体验曲线：爽点总数/密度、高频爽感公式、压力机制、情绪曲线特征、信息释放节奏、追读驱动力——**红线：卖点必须有曲线数据支撑**。把"这本书爽在哪"翻译成连载节奏。

### 4.7 商业可行性分析
市场定位 + 竞品对标（相同点/差异点/可借鉴/需规避）+ 风险预警（金手指后期乏力/赛道竞争激烈/人设争议/节奏拖沓及应对）——不只文学拆解，面向商业连载。

### 4.8 开写前启动检查清单（小巧思）
力量体系设定完成/血肉层设定/主要角色卡/角色弧线/伏笔悬念追踪/卷1卷纲/文风DNA部署/读者体验曲线/前3章大纲/竞品分析——用户拿到 PRD 直接进入开写前检查。

### 4.9 可复用资产清单
统计故事机制DNA/名场面/读者体验曲线/卷纲/设定文件/角色弧线/文风DNA，每条**引用已产出具体文件**——让用户看清"拆书已留下哪些可直接用的料"。

## 5. 可测量 / 门禁

| 门禁 | 口径 |
|---|---|
| **结论chXX可溯** | 逆向破解各结论有章节证据 |
| **假说不靠编** | 禁凭书名/直觉编核心假说 |
| **赛道不靠猜** | 禁凭书名猜赛道，须交叉判定 |
| **卖点有曲线** | 读者体验卖点须有曲线数据支撑 |
| **检查清单** | 启动前工序齐，可落地 |

## 6. 深度：立项 PRD 是拆书引擎的"终产物"
消费 dimension 各维拆解 + design-pack，产出可直接指导 world/character/plot/write 的立项文档。**营销价值**：它把"这本书为什么火"翻译成"我照着这套证据施工图怎么写出来"，是拆书整套能力的收口与变现。

---

## 7. 操作顺序（先收集，再逆向，再推断，再开写检查）
收集各维拆解产出 → 逆向破解总结（核心假说/赛道/卖点/读者，chXX）→ 全书结构 → 主角驱动 → 读者体验曲线 → 商业可行性 → 启动检查清单 → 可复用资产清单 → 交 world/character/plot 立项。
