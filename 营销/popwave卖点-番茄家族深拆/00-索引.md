## 营销选词铁律（番茄家族特有的口径边界）

1. **"读者模型驱动"是番茄最硬的招牌**——12 岁滑动模型、冲刺密度、爽感公式这些**有明确数字**的参数可直接对外承诺；但仍需注明"模型是写作指导，非平台转发算法承诺"。
2. **硬卡口可直接主打**：字数 2000-2500（>2500 裁 / >3000 废）、章末钩子主动决策型、节奏 8-12 事件/章、爽感触发 ≤3 行、靠脚本 API 自动裁剪——"不是建议，是卡口"是差异化杀招。
3. **番茄与起点同源共享**"双文件记忆 + 不写崩"机制，但番茄的差异化在**量化程度更高**（节拍、密度、爽感引擎、字数全带数字）。营销时强调番茄="把爽文写法的每个环节都量化到能检查"。
4. **成熟度如实标注**：番茄 seed 需"世界类型+风味基线"，world 为骨架；管道 Phase 进度 HTML 可视化、scripts 脚本（wordcount/state-html）已实装可主打"真脚本、可复现、可审计"。
