## 0. 一句话卖点

**popwave 番茄角色工程：不要预设定量角色库，而是"剧情分幕设计里出场了谁，就塑谁"——每个角色按"攀登方式"（有资源的/没资源的/爬到顶的/掉下来的）从世界势力生存逻辑长出来，再用角色三问消灭工具人，配关系网三张表让角色关系直接变成剧情冲突。**

## 1. 用户痛点：设定了一堆角色，一半用不上、一半是工具人

| 痛点 | 表现 | 后果 |
|---|---|---|
| **角色库臃肿** | 一次性生成几十张角色卡，出场才用到几个 | 设定了不用=浪费，且前后矛盾 |
| **工具人配角** | 配角只为传设定/送情报出现，没有自己的欲望 | 读者无感 |
| **性格凭空编** | 人设词堆出来的角色，和世界观/势力没关系 | 行为生硬、容易崩 |

> 核心焦虑：番茄爽文的读者记不住"设定完整"的角色，只记得住**有行为逻辑、有冲突必然性的角色**。角色建设要按需、有根、能自动产出剧情。

## 2. 关键认知：角色要"从世界势力生态里长出来",不是"人设词堆出来"

番茄的角色（主角/配角/反派）**必须回溯所在势力的生存逻辑**——"这个势力的人靠什么活、怎么往上爬"，决定了这个角色会怎么选、怎么动。配合三问校验与关系网，角色才既贴合世界、又有自主行为、能直接转成冲突。

## 3. 反面教材："卡牌式人设"为什么撑不起番茄爽文

- **预设定量**：不管剧情要不要,先造 20 张卡——出场率低、还和后写的分幕冲突。
- **工具人**：一个角色只有"给主角送消息"的功能，没独立欲望——读者一眼看穿、弃书。
- **性格悬空**：标签写"腹黑忠犬"，但没说他从哪个势力、靠什么活着——行为没根，写不出张力。
> 正确做法：看第 4 节——分幕驱动建库 + 攀登方式 + 三问自检 + 关系网。

## 4. 机制：分幕驱动 + 攀登方式 + 三问 + 关系网，四步把角色做"有根的活人"

### 4.1 分幕驱动建角色库：出场谁就塑谁，不预设数量
- 从 `设计/第一卷剧情/剧情白描.md` 的 **2c 分幕设计**提取出场角色清单，去重后建角色库。
- **小巧思**：建库规模由分幕设计驱动，**不预设数量**——不会凭空造一堆不用的角色卡，也不漏剧情要用的关键角色。

### 4.2 攀登方式类型：行为逻辑从势力生存逻辑推导
- 每个角色标注**攀登方式类型**：有资源型 / 没资源型 / 爬到顶层型 / 掉下来型。
- 主角、配角、反派都必须**回溯所在势力的生存逻辑**，不凭空编性格。
- 卖点："角色不是人设词堆出来，是从世界势力生态中长出来的。"（与 world 的势力攀登方式同源）

### 4.3 角色三问自检：消灭工具人
每个角色必须通过三问：
1. **有独立欲望吗？**
2. **行为逻辑由攀登方式推导吗？**
3. **和主角有冲突必然性吗？**
- **任一不过必须重做该角色卡**——角色库不是填充任务，确保每个出场角色都有自主行为和冲突。

### 4.4 角色关系网三张表：关系是剧情冲突的地基
- **纵向关系**：跨阶层/跨势力（剥削/依附/反叛）。
- **横向关系**：同阶层/同势力（竞争/联盟/暗合作）。
- **主角关系图谱**：盟友/对手/羁绊/利用。
- **小巧思**：角色不是孤立卡片，而是能**直接转化为剧情冲突的关系网**——给 plot 抽线、给 write 写关系张力。

---

## 5. 可测量 / 门禁：角色可验收，不是"这角色不错"

| 门禁/参数 | 口径 | 意义 |
|---|---|---|
| **分幕驱动** | 从分幕出场清单建库，不预设数量 | 防臃肿/防漏角 |
| **攀登方式回溯** | 每角回溯势力生存逻辑 | 行为有根 |
| **三问全过** | 欲望 + 逻辑推导 + 冲突必然性 | 灭工具人 |
| **关系网三表** | 纵/横/主角图谱齐全 | 关系可转冲突 |

## 6. 深度：角色是 plot 的"抽线源"、write 的"行为源"
- world 的势力攀登方式 → character 的角色攀登方式（同源联动）；character 的关系网 → plot 的分幕冲突线 → write 的对话/决策；review 用状态表校验角色关系不矛盾。
- **营销价值**：番茄角色按需生成、有行为根、能自动产冲突——"不写空角色，写一个就是一个能推动剧情的活人"。

---

## 7. 操作顺序（先按需，再扎根，后联网）
从分幕出场清单提取 → 标记攀登方式（回溯势力）→ 三问自检（不过重做）→ 建关系网三表 → 交 plot/write 消费。**角色是为剧情长的，不是先造好再硬塞进剧情的。**

## 9. 竞品差异锚（一句话）
市面人设工具= 预设定量卡牌 + 标签堆砌 + 工具人（与剧情脱节)；popwave 番茄角色工程 = **分幕驱动建库 + 攀登方式回溯势力 + 三问灭工具人 + 关系网三表转冲突**，让角色按需生长、行为有根、直接推动剧情。
