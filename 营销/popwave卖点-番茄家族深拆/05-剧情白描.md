## 0. 一句话卖点

**popwave 番茄剧情白描：不一次性甩整卷大纲，而是按幕逐个推演（每幕 8-12 章）、每卷铺 ≥6 条分支剧情线、用"起承转合四段式"拒绝标签化幕纲、多弧线多视角交织——最后一过"卷纲精彩度五问"才落盘，并按幕产出写给 write 的轻量结构要素表。**

## 1. 用户痛点：大纲越写越长，剧情越来越水

| 痛点 | 表现 | 后果 |
|---|---|---|
| **整卷一次生成** | 一次性写完整本大纲，越到后面密度越稀 | 中期注水、节奏崩 |
| **单线推进** | 只有主线一条线，信息量小、推不动 | 平、闷、没层次 |
| **幕纲是标题** | 只写"主角去秘境/遇圣女/拿神器"，没有冲突与反转 | write 没料可写 |

> 核心焦虑：番茄爽文密度高（8-12 事件/章），大纲若不能**逐幕保鲜、多线给料、具体到可写**，就会变成 write 也救不了的"水账"。剧情白描要当"能给 write 逐章下料的实地图"，不是标题集。

## 2. 关键认知：剧情要"逐幕推演 + 多线给料 + 结构具体"

- **按幕推演**保证每幕独立完整、密度不稀（防止整卷后段乏力）。
- **多线交织**（主线/支线/暗线 ≥6 条）让每章有多个推力源。
- **四段式 + 结构要素表**把幕纲从"标题"升级成"有冲突/反转/爽点的故事单元，且直接告诉 write 这幕核心地点/人物/战斗怎么写"。

## 3. 反面教材：整卷流水账式大纲为什么必水

- **一次性生成整卷**：前紧后松，中期注水，读者划走。
- **只推主线**：信息量单一，缺支线/暗线推动力和悬念。
- **幕纲=标题**："第 3 幕主角变强+打脸对手"——没有四段式冲突、没有具体场景料，write 拿到也写出流水账。
> 正确做法：看第 4 节——按幕、多线、四段式、五问、结构要素表。

## 4. 机制：按幕 + 快照 + 多线 + 四段式 + 多视角 + 五问 + 结构要素表

### 4.1 按幕白描：推演密度高于推演整卷
- 每幕 **8-12 章**，产出：五段式叙事梗概 / 非主角视角段落 / 场景表 / 幕末钩子 / 分支线标注 / 主角力量成长线 / 本幕结构要素表。
- 卖点：剧情**逐幕保鲜**，防止中后期密度下降。

### 4.2 本卷设定快照：把骨架设定改成可写地图
- 先从 world 的 `各卷切片.md` 圈出本卷范围，再充实为本卷设定快照。
- 地图区域必须填：盘踞势力、内部矛盾、区域间矛盾；角色必须标：核心欲望、势力归属、关系张力。
- 卖点：写剧情时不空读设定，拿一份**可直接写白描的实地图**。

### 4.3 ≥6 条分支剧情线：主线+支线+暗线网状推进
- 每卷至少 6 条：**主线 1-2 + 支线 3-4 + 暗线 1-2**。
- 每条线有起、止、涉及势力、涉及地图；支线还须标注和主线的关系。
- 卖点：剧情不是单线推进，多线交织、推动力和信息量更强。

### 4.4 四段式起承转合：拒绝标签化幕纲
- **起**（起始状态 + 打破事件 + 新危机 + 读者钩子）→ **承**（手段 + 阻力 + 中途获得）→ **转**（方案打破 + 意外反转 + 被迫新决策）→ **合**（破局 + 大爽点 + 幕末质变 + 新危机钩子）。
- 卖点：幕纲不是标题，而是**有冲突、反转和爽点的具体故事单元**。

### 4.5 多弧线交织 + 多视角叙事：每章多个推力源
- 每幕 **2-4 条故事弧线**交织：主线弧线 / 情感关系弧线 / 战斗成长弧线，各自有独立核心事件和爽点。
- 每幕**至少 1 个非主角视角段落**（敌人/旁观者切入）制造信息差、展现压迫感、增加情感层次；自检"不是主角猜到，而是有明确切镜头安排"。
- 卖点：一章节奏不靠单线强撑，多线共同产生爽感和压力；多视角不是炫技，是让读者看到主角看不到的信息。

### 4.6 卷纲精彩度五问（落盘前必须自评）
1. **追读理由 ≥2 个**
2. **意外性 ≥2 个转折**
3. **情感投入 ≥1 个锚点角色**
4. **爽感密度 ≥60%** 章节有爽点
5. **卷末高潮最精彩**
- **5 问全部通过才落盘**——plot 不只"搭结构"，还保证结构好看。

### 4.7 本幕结构要素表：给 write 的轻量导航
- 每幕白描中产出：核心地点（≤3 个）/ 核心出场人物（≤6 个）/ 核心战斗 / 成长节点 / 资源获取 / 关系变化 / 伏笔回收·埋。
- 卖点：白描不虚，**能直接指导正文章节写什么**。

---

## 5. 可测量 / 门禁：卷纲好看，不止是"编完"

| 门禁/参数 | 口径 | 意义 |
|---|---|---|
| **分支线 ≥6 条** | 主线1-2 + 支线3-4 + 暗线1-2，有起止/势力/地图 | 防单线平推进 |
| **四段式完整** | 起承转合四段齐全，含反转与爽点 | 防标题化幕纲 |
| **多弧线 2-4 条** | 弧线各有独立事件与爽点 | 防单线强撑 |
| **多视角 ≥1** | 每幕非主角视角段，明确切镜头 | 制造信息差 |
| **精彩度五问全过** | 追读/意外/情感/爽感≥60%/高潮 | 卷纲可质检 |
| **结构要素表** | 地点≤3/人物≤6/战斗/成长/关系/伏笔 | 直接喂 write |

## 6. 深度：白描是 write/review 的"逐章下料机"
- plot 白描 → write 按结构要素表写正文（增 06、07) → review 倒查 plot 纲是否兑现（见 07)；分支线/钩子挂在 state 台账追踪（见 07）。
- **营销价值**：番茄剧情不是"写一个大纲就完"，是**逐幕逐章都在给后面的写作/审核下料**——"剧情白描不是标题集，是要能逐章指导正文怎么写的实地图"。

---

## 7. 操作顺序（先按幕，再给料）
按幕推进 8-12 章 → 本卷设定快照 → 铺 ≥6 分支线 → 四段式起承转合 + 多视角 → 多弧线交织 → 五问自检 → 产结构要素表 → 交 write/review。**一卷一卷推，每幕都过五问，不一次性甩整本。**

## 9. 竞品差异锚（一句话）
市面大纲工具= 整卷一次生成 + 单线 + 标题化幕纲（中期注水/write 没料)；popwave 番茄剧情白描 = **按幕推演 + 本卷快照 + ≥6 分支线 + 四段式 + 多视角 + 精彩度五问 + 结构要素表**，把剧情做成逐幕逐章都能指导写作的下料机。
