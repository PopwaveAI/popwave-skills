## 0. 一句话卖点

**popwave 番茄管线：一次对话自包含推进（读 project-state → 对照 Phase 调度表路由 → 按 state 更新落盘，零跳转）；7 阶段流水线 + 底牌就绪机制让你"准备好再写"；旧稿/笔记/碎片设定都能导入（16 类标准结构自动标准化，缺节标"待补"不编造）；项目状态还能生成一张可打开的 HTML 可视化仪表盘。**

## 1. 用户痛点：工具要在一堆 skill 里来回切，项目状态靠记忆

| 痛点 | 表现 | 后果 |
|---|---|---|
| **切换认知负担** | 立项/世界/剧情/写作/审核各开一个工具/会话 | 上下文丢、状态乱、还要自己记"写到哪" |
| **从零起步门槛高** | 每次都从空白开始，旧稿/笔记用不上 | 不敢动笔、冷启动难 |
| **状态是黑箱** | 说不清现在到哪、下一步干嘛、哪些准备还没就绪 | 盲目推进、撞墙返工 |

> 核心焦虑：长篇创作的价值在"连续推进"，而工具碎片化会杀死连续性。pipeline 要解决"启动快 + 推进连续 + 状态可见"。

## 2. 关键认知：管线要"自包含推进"，用户别管调度细节

把"现在要做什么、读什么、写什么、更新什么"都收进 **project-state + Phase 调度表**——用户只有一个念头，剩下的路由、落盘、进度由管线完成。对用户是"写书的进度条",对系统是"状态机的自动推进"。

## 3. 反面教材：无管线的"多工具写作"为什么累

- **来回切换**：设定在 A、正文在 B、审核在 C，状态全在脑内——30 章后一片混乱。
- **冷启动**：旧稿/笔记/碎片设定不能复用，只能"从头再来"，最耗作者胆量。
- **瞎试跑**：不知道前置资源（赛道调查/参考书/DNA）是否就绪就开写——写着写着发现地基是虚的。
> 正确做法：看第 4 节——路由循环 + 导入模式 + 底牌就绪 + 状态可视化。

---

## 4. 机制：四板斧把"创作推进"做成"连续 + 可见 + 可导入"

### 4.1 Phase 调度 + 路由循环：一次对话自包含推进
- Phase 调度表把用户意图/Seed/World/Plot/Character/Write/Review 串起来。
- **路由循环（v3.13）**：读 `project-state.md` → 对照 Phase 调度表路由 → 按 state 更新方法落盘；调度表与 state 更新法合入 SKILL.md，**每次对话零跳转**。
- 卖点：用户不在多个 skill 间反复切换，对话里自动推进项目。

### 4.2 导入 / 续写模式：旧稿、笔记、碎片设定都能进
- `step0-import` 处理已有项目/用户笔记/自由格式输入，可继续已有项目。
- **16 类标准文件结构**（用户意图/赛道调研/文风锚定/创意/力量体系/地图/势力/危机/角色库/剧情白描/状态快照等）把自由输入转成标准结构；**缺失分节标注"⏳待补"，不编造**。
- 节省 pipo：非 md 文件先读内容再按标准格式写入 md。
- 卖点：**降低"从空白开始"门槛**，旧稿/笔记也能重建管线。

### 4.3 7 阶段 Phase 流水线 + 底牌就绪：准备好再写
- Phase 0 意图 → 1 Seed → 2 World → 3 Plot → 3.5 Character → 4 Write → 5 Review。
- **project-state 追踪**：项目名/创建·更新时间/phase/mode/current_chapter/阶段完成/底牌就绪/创意摘要/最近产出/下一步。
- **底牌就绪机制**：追踪 用户意图 / 赛道调研 / 参考书下载 / 笔触 DNA / decon-lite 等前置资源 —— ready / skipped / not-ready。
- **小巧思**：不是"开始写"，而是"**准备好了再写**"——降低设定混乱和写崩概率。

### 4.4 Phase 进度 HTML 可视化仪表盘（真脚本，可打开）
- `scripts/generate-state-html.py` 从 `project-state.md` 解析字段，替换 `templates/project-state.html.tpl` 占位符，生成 `project-state.html`。
- 页面含：阶段进度条 / 底牌就绪卡片 / 创意摘要 / 最近产出表格 / 下一步操作。
- 卖点：项目状态不是文本，而是**一份可打开的可视化仪表盘**（有实装脚本，可复现）。

### 4.5 管道亲和认知引导 + 轻量沉淀
- `onboarding-guide.md`：引导语强调"你只要有个'想写什么'的念头"，提供"从零立项/搭世界观/逐章成文/自查把关"四个玩法入口。
- **剧情沉淀轻量化（v3.12）**：Phase5 只产出 双文件——`审核/剧情白描流水账.md`（append·存"发生"）+ `审核/状态快照.md`（replace·存"状态"），审核结论只在对话内输出。

---

## 5. 可测量 / 门禁：状态可见、地基就绪，不是黑箱

| 门禁/参数 | 口径 | 意义 |
|---|---|---|
| **路由循环** | 读 state→调度→落盘，一次对话零跳转 | 连续推进 |
| **16 类结构** | 缺节标"⏳待补"不编造 | 导入不造假 |
| **底牌就绪** | ready/skipped/not-ready 三态 | 开写前查地基 |
| **HTML 仪表盘** | 解析 md→填模板→生成 html | 状态可视化（实装） |

## 6. 深度：管线是番茄 7 skill 的"总调度 + 状态面"
- 它调度 seed/world/plot/character/write/review，消费 review 双文件跟踪连续记忆，回写 project-state 供续写续行。
- **营销价值**："一个念头启动、旧稿能导入、状态有仪表盘、准备好了再写"——把"长跑"变成"每一步都知道自己到哪、下步干嘛"的连续推进。

---

## 7. 操作顺序（先迁，再路由，后落盘）
初始化/导入 → 读 project-state → 对照 Phase 调度表路由 → 执行对应 skill → 按 state 更新落盘 → 回写 project-state。**需要续写时从 state 续行，不从头再来。**

## 9. 竞品差异锚（一句话）
市面写作工具= 多会话切换、冷启动、状态黑箱；popwave 番茄管线 = **Phase 路由循环（零跳转）+ 导入/续写模式（16 类结构不造假）+ 底牌就绪 + HTML 可视化仪表盘**，让长篇创作变成"连续 + 可见 + 可导入"的推进过程。
