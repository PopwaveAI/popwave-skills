## 0. 一句话卖点

**popwave 给短篇作者一张"选平台不靠猜"的地图：6 大平台内置性质表 + 每个平台可展开 8 维深度对比 + 开篇铁律精确到字/句数 + 品类赛道数据到百分比。3 问摸底，有明确意向就一步到位。它不是替你做决定，是告诉你每个选择的底牌。**

## 1. 用户痛点："选平台两眼一抹黑"

| 痛点 | 表现 | 后果 |
|---|---|---|
| **平台调性靠猜** | 不知道番茄/知乎/豆瓣各自适合什么题材 | 选题投错，过签率低 |
| **开篇规则不透明** | 不知道每个平台开篇铁律、付费钩子怎么断 | 写了不合规，白写 |
| **一问一答太累** | 平台定向工具逼用户填一堆信息 | 还没开始就被劝退 |
| **数据不可靠** | 平台规则道听途说 | 决策失真 |

> 核心焦虑：短篇的"平台适配"直接决定过签率和收益，但行业规则不透明、分散——用户要的是知识库级的可靠数据。

## 2. 关键认知：平台定向不是"推荐个平台"，而是"把底牌摊给用户"

高质量平台定向 = **辅助决策不替代决策**。给作者一份可落地的决策报告（每个平台的性格、开篇铁律、付费钩子、改编潜力、风险），让作者自己选。红线 #4：遇到实时性政策问题如实告知——不越权、不背锅。

## 3. 反面教材：把"推荐"当"命令"，或做成通稿

- **替作者拍板**：AI 直接"你投番茄"，作者不知道自己为什么选、选错了怪 AI。
- **跨平台通稿**：把所有平台浅显地各说一遍，每个都像没说过（红线 #1 禁止）。
- **规则靠编**：平台数据没有权威依据，乱标分成比例（红线 #3 以 references 为准）。
> 正确做法：见第 4 节——只深度展开 1-2 个最适合的 + 把数据摊给用户 + 规则以知识库为准。

## 4. 机制：6平台性质表 + 3问摸底 + 8维对比 + 品类指南 + 项目总览

### 4.1 6 大平台自动性质推导表
| 平台 | 一句话性质 |
|---|---|
| 番茄短故事 | 快节奏爽文/网感强/下沉市场 |
| 知乎盐言故事 | 知性深度/社会洞察/反转导向 |
| 每天读点故事 | 情感治愈/暖甜/短剧感 |
| 豆瓣阅读 | 文学质感/慢热/长尾品质 |
| 小程序生态 | 信息流钩子/极致快节奏 |
| 七猫 | 精品网文/保底导向 |

### 4.2 3 问摸底 + 智能跳过（小巧思）
只需 3 问——题材倾向/核心目标/现有素材。三种跳过：已说平台+题材→直接匹配；已说题材没平台→跨平台对比；什么都没说→进入摸底。**极简交互，已有意向用户 1 步到位。**

### 4.3 平台深度匹配 8 维
对被选中的 1-2 个平台展开：**签约门槛与速度 / 目标读者画像 / 该题材在平台表现 / 子方向推荐 / 开篇铁律 / 付费钩子模式 / 改编潜力 / 风险和注意**。最终输出 2 平台对比表 + 其余平台一句话简述。

### 4.4 完整规则库（知识库级数据）
每个平台含：基础参数（字数要求/付费模式/分成比例）、读者画像、调性要求、热门品类、**开篇铁律（精确到字/句数）**、付费钩子断点、格式注意。例：番茄 100% 收益、60-70% 过签率、最快 1 小时出结果；知乎 50% 分成、千字 30-100 元；每天读点故事 VIP 保底 1000 元/篇。

### 4.5 品类写作指南（5 大品类×子方向）
悬疑惊悚/现代言情/玄幻仙侠/都市现实年代/脑洞规则怪谈。含赛道增长数据（悬疑男频+194%、玄幻言情+109%、纯年代文-56%）+ 热门子方向 + 陷阱警告 + 范例脑洞。规则怪谈被称为"2026 年增长最快的交叉品类"。

### 4.6 项目总览.md 状态表（小巧思）
Step 3 输出含 S1-S6 六步状态追踪表（⬜未开始/🟡进行中/✅完成），**严格"有且仅有 1 个 Step 为 🟡"**，跨 skill 流转全程可追踪。

## 5. 可测量 / 门禁

| 门禁 | 口径 |
|---|---|
| **只深展1-2平台** | 不做跨平台通稿（红线1） |
| **不替用户决定** | 展示优劣让用户选（红线2） |
| **数据有据** | 以 references/platform-rules.md 为准（红线3） |
| **政策如实** | 实时性政策问题如实告知（红线4） |

## 6. 深度：平台定向是整条短篇产线的"地基"
定位卡片 + 流转上下文（6字段+5字段）双输出，被 idea-refiner / opening-designer / plot-structurer 无缝消费——后续每个 skill 都拿到平台的性格约束。**营销价值**：平台选对，后面的开篇/结构/正文少返工一大半。

---

## 7. 操作顺序（先定向，再写）
问3题/智能跳过 → 锁定1-2平台 → 8维深度对比 → 品类赛道匹配 → 输出定位卡片+流转上下文 → 交给下游 skill。**平台性格先锁死，开篇/结构/正文才有据可依。**
