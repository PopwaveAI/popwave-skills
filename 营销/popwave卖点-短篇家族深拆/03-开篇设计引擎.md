## 0. 一句话卖点

**popwave 把"开篇怎么写"拆成可判定的工程：先定卖点主轴（悬疑/情感/爽/反转/身份共鸣/猎奇），再套 6 种导语公式（每种带平台匹配表），用"黄金三句"（甩冲突→拉近距→留钩子）产出 100-200 字导语，最后按 4 种付费钩子类型对接平台断点。导语是广告语，不是正文第一句。**

## 1. 用户痛点："开篇写偏了""不知道怎么抓人"

| 痛点 | 表现 | 后果 |
|---|---|---|
| **卖点不清** | 不知道这篇到底卖什么 | 越写越散、写飞 |
| **导语公式不明** | 开篇不知道用什么套路 | 抓不住眼球、过签率低 |
| **黄金三句冗余** | 三句都在铺垫，没有钩子 | 读者 3 秒划走 |
| **付费断点乱切** | 断在不对的地方 / 类型不匹配平台 | 转化差 |

> 核心焦虑：短篇的开篇 = 平台展示页上的"第一广告"，它决定读者点不点、平台过不过签，但多数作者把正文开篇当导语写。

## 2. 关键认知：导语是"展示页广告"，不是正文第一句

高质量开篇设计 = 先定卖点（为什么看）→ 再用公式写导语（0.3 秒抓人）→ 用黄金三句撑住前 100-200 字 → 用付费钩子定断点。三个致命禁忌：交代背景 / 抒情议论 / 解释说明。红线：导语最后一句话必须是最强悬念或钩子。

## 3. 反面教材：把开篇写成"背景说明书"

- **卖点缺失**：没想清楚卖什么，开篇平铺直叙，读者无感。
- **导语当正文**：第一段变成世界观介绍/抒情，平台展示页毫无钩子。
- **黄金三句都能省**：三句之间没有功能递进，信息缺、情绪平。
> 正确做法：见第 4 节——卖点主轴 + 公式化导语 + 黄金三句功能分区。

---

## 4. 机制：卖点主轴 + 6导语公式 + 黄金三句 + 字数约束 + 付费钩子

### 4.1 卖点主轴 6 种候选 + 优先级
先确认"卖什么"而非"怎么写"：悬疑（我要知道真相）/ 情感（我会心疼）/ 爽（看得解气）/ 反转（没想到是这样）/ 身份共鸣（这不就是我吗）/ 猎奇（还有这种事）。每个标优先级（⭐1-5），用户确认后形成主轴。

### 4.2 6 种导语公式 + 平台匹配表
| 公式 | 口径 | 适配平台 |
|---|---|---|
| 悬念前置 | 惊人结果+"但没这么简单"+更大疑问 | 知乎⭐⭐⭐⭐⭐ |
| 情绪爆发 | 强情绪词+具体事件+"那一刻我明白了" | 每天读点故事⭐⭐⭐⭐⭐ |
| 对话开头 | 引号对话+谁说的+后果 | 知乎/每天 |
| 身份共鸣 | 精准身份+扎心困境+"你是不是也" | 番茄⭐⭐⭐⭐⭐ |
| 反转 | 常规认知+"但我发现"+反真相 | 知乎⭐⭐⭐⭐⭐ |
| 画面切入 | 具体画面/动作+时间地点+"不对劲" | 每天/豆瓣⭐⭐⭐⭐⭐ |

> 自动匹配表：5 平台 × 3 优先公式，开箱即用。

### 4.3 黄金三句三要素法（小巧思）
| 句 | 功能 | 要求 |
|---|---|---|
| 句1甩冲突 | 反常事件/绝境/强情绪/身份反差/亮结果 | 一上来就是冲突 |
| 句2拉近距 | 具体感官细节（动作/触感/声音/气味） | 必须是"摄像机能拍到的" |
| 句3留钩子 | 暗示走向+最强未解谜题 | 让人放不下 |

> 生成 2-3 组，每组标注公式/读者心理/平台适配度。

### 4.4 字数约束 + 补句禁忌
最小 100 字/最大 200 字，黄金三句占比 60-80%。补句规则：知乎/番茄可选（三句够），每天/豆瓣建议加一句。三类绝对禁忌：交代背景/抒情议论/解释说明。

### 4.5 付费钩子 4 类型 + 平台差异化（小巧思）
① 信息缺口（刚抛大悬念不让知答案）→悬疑/猎奇；② 情绪最高点（情感投入达顶戛然止）→情感/虐；③ 决策时刻（重大选择前停）→反转/身份共鸣；④ 反转预告（暗示不透露）。
平台差异化：知乎=信息缺口/反转预告；番茄=爽点预告/决策时刻；每天=情绪最高点。

## 5. 可测量 / 门禁

| 门禁 | 口径 |
|---|---|
| **导语是广告** | 非正文第一句，是展示页简介（红线1） |
| **三禁忌** | 不交代背景/抒情/解释（红线2） |
| **末句最强钩** | 导语末句最强悬念（红线3） |
| **字数** | 100-200字，黄金三句占60-80% |
| **钩子对齐** | 付费钩子断点与平台策略对齐（红线4/5） |

## 6. 深度：开篇定调，直接决定正文和结构
卖点主轴喂养 plot-structurer 的结构选择，付费钩子位置由 body-generator 对齐校验。**营销价值**：开篇阶段把"卖什么 + 怎么抓 + 断在哪"一次钉死，正文生成不跑偏、转化断点不脱节。

---

## 7. 操作顺序（先定卖点，再写导语，再定钩子）
列卖点候选→用户定主轴 → 套6导语公式（平台匹配）→ 写黄金三句（甩冲突/拉近距/留钩子）→ 100-200字成稿 + 验三禁忌 → 定付费钩子类型+断点 → 交 structure 阶段。

- "开篇不是'正文第一句'，是平台展示页上的广告——我们先把'这篇卖什么'钉死，再谈怎么写。"

- "黄金三句各干一件事：甩冲突、拉近距、留钩子；第二句必须是'摄像机能拍到的东西'，不许抽象。"

## 9. 竞品差异锚（一句话）
市面开篇工具 = 凭手感/公式无平台匹配/断点乱切；popwave 开篇引擎 = **卖点主轴 + 6导语公式匹配表 + 黄金三句功能分区 + 100-200字硬约束 + 付费钩子4型×平台**。
