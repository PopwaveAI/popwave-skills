## 0. 一句话卖点

**popwave 美术设定集（Art Bible）是"美术语言的唯一真源"：一次设计，封面/OC/漫画/世界观物料全家复用，视觉任务不再重新发明设定；风格被 style 冻结引用、内容层做扩展，从源头上杜绝"每张图长不一样、跨章崩脸"。**

## 1. 用户痛点："视觉新品三天打鱼两天晒网"的原因

| 痛点 | 表现 | 后果 |
|---|---|---|
| **每张图重画设定** | 封面一套画风、OC 一套画风、漫画又一套 | 全 IP 视觉不统一，一眼假 |
| **跨章崩脸** | 同一个人这几章长得不一样 | 长线连载口碑崩 |
| **设定重复劳动** | 每做一个物料都把角色/场景/画风重设一遍 | 时间翻倍，产出翻不了倍 |
| **AI 自作主张漂移** | 明明给过画风参考，AI 还是自己"发明"新的 | 风格不可控、不可复用 |

> 核心焦虑：视觉工作 90% 的时间浪费在"重新定义"而非"产出新品"上——用户要的是"一次定稿、无限复用"。

## 2. 关键认知：美术设定集不是"一本设定册"，而是"管线真源"

高质量视觉管线 = 把画风、人物、场景、符号、势力、地理、规则**一次性冻结成唯一真源**，供所有下游 skill 引用。下游不重新发明设定，只看真源取料。真源决定了整条视觉产线的**一致性下限**——它不是结局产物，而是生产前置的数据层。

## 3. 反面教材：把设定集当"成立了"的装饰

- **空壳设定集**：只写了"主角白发红衣"，下游每个 skill 各自脑补补全，最后画出来的四张图四个人。
- **设定集与产出脱节**：做了一套好看设定集，但 cover/comic/oc 根本不引用它。
> 正确做法：见第 4 节——真源 + 下游强制引用才是关键。

## 4. 机制：八篇合一 + 四档输出 + 风格内容解耦

### 4.1 八篇合一的完整闭环
美术设定集按八篇组织：**画风篇 / 人物篇 / 场景篇 / 符号篇 / 势力篇 / 地理篇 / 规则篇 / IP 视觉 DNA 篇**。不是单张图，而是一套"世界观视觉说明书"，覆盖从画风到规则可视化的全部维度。

### 4.2 四档输出，按用户意图精准点亮（小巧思）
根据用户一句话，系统自动判断点亮哪些篇章，不硬出全套：
| 用户意图 | 点亮的篇章 |
|---|---|
| 封面 `cover` | 画风篇 + 场景篇（局部）+ 封面相关人物篇 |
| `oc` | 画风篇 + 人物篇 |
| `comic` | 画风篇 + 人物篇 + 场景篇 + 符号篇 |
| `world` | 画风篇 + 势力篇 + 地理篇 + 规则篇 |
| `full` | 全部八篇 |

> 卖点：用户不需要懂"我该建哪些设定"，说一句意图，系统按档位点亮对应篇章，降低选择成本。

### 4.3 风格引用 + 内容解耦：AI 不发明风格
- **风格层（冻结）**：画风 DNA、提示词模板、视觉规范——由 style 冻结引用。
- **内容层（扩展）**：人物、场景、符号、势力、地理、规则的具体视觉形象——art-bible 只做内容层面的扩展与复现。
> 小巧思：**风格不是重新发明**，而是引用了冻结的画风 DNA 后锁定；这样画风可跨项目复用到 OC/封面/漫画，永不漂移。

### 4.4 四阶段管线，全程可回看
Step0 读输入建档位 → Step1 拆资产建美学基调 → Step2 确认冻结落盘真源 → Step3 基于冻结设定生成复现图。从"读原文"到"复现"全标准化，每阶段有产出和门禁。

---

## 5. 可测量 / 门禁：设定集有验收红线

| 门禁 | 口径 | 意义 |
|---|---|---|
| **画风引用冻结** | 画风是否引用 style 冻结层，禁止自创 | 防风格漂移 |
| **0.3秒人物辨识** | 人物是否 0.3 秒能认出 | 不靠"好看"，靠辨识度 |
| **忠于原著处境** | 人物/场景/符号是否来自 asset 原文而非编造 | 防 AI 捏造 |
| **规则可视化有据** | 规则可视化是否有原文视觉外显依据 | 防凭空符号 |
| **一致性仲裁** | 无撞色/撞剪影/画风漂移 | 防内部冲突 |

## 6. 深度：美术设定集是整条视觉产线的"头"
- 被 cover（封面）、oc（立绘/设定卡）、comic（漫画）、comic-content/video（漫画素材）多路消费。
- **营销价值**：设定集的深度决定后四层不返工——"一次 1-2 小时的美术设定集，省后面几十张图的返工重画"。

---

## 7. 操作顺序（先锁风格，再扩内容）
读输入定档位 → style 冻结画风 → asset 拆资产 → 建八篇/按档点亮 → 确认冻结落盘真源 → 生成复现图 → 交给 cover/oc/comic 接力。**画风必须先冻结，内容扩展才有地基；真源必须先落盘，下游才有料可取。**
