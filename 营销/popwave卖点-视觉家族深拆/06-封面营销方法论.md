## 0. 一句话卖点

**popwave 把封面重新定义为"广告"而非"插画"：唯一目标是让目标读者 0.3 秒识别赛道、产生点击欲望。四层信息架构 + 6 种视觉钩子 + 6 种构图 + 赛道速查 + 参考点六维拆解，把"封面能不能让人点进来"做成可复用的方法。**

## 1. 用户痛点：封面"好看"但"没人点"

| 痛点 | 表现 | 后果 |
|---|---|---|
| **当插画做** | 一味画得精美，忽略营销目标 | 流量转化差 |
| **书名看不出来** | 书名做小、被画面吃掉 | 读者不知道是什么书 |
| **赛道识别弱** | 玄幻/仙侠/都市视觉不区分 | 受众不匹配 |
| **每次从零想** | 封面连接钩子和构图都没有参考 | 无效率、无沉淀 |

> 核心焦虑：封面是"书架上的广告位"——0.3 秒决定点不点，好看不是目的，识别和点击才是。

## 2. 关键认知：封面是 0.3 秒的广告，不是画廊展品

高质量封面 = **让目标读者 0.3 秒识别赛道、感知独特性、产生点击欲望**。书名是主角之一、必须有赛道辨识度；画面服务于"让读者停下来"。封面是营销信息架构，不是纯艺术。

## 3. 反面教材：把封面当成果图

- **画面为王、书名被吞**：主角画很美，书名缩在角落——读者扫一眼不知道是什么赛道。
- **无定位的堆砌**：把一堆元素塞进去，没有信息层级，0.3 秒抓不到重点。
- **全类型一张脸**：玄幻封面长得像都市封面，靶向读者认不出。
> 正确做法：见第 4 节——四层信息架构 + 赛道识别优先。

---

## 4. 机制：四层架构 + 6钩子 + 6构图 + 赛道速查 + 参考点六维

### 4.1 四层信息架构（信息优先）
| 层 | 位置 |
|---|---|
| 标题区 | 上 1/4 |
| 主视觉 | 中 1/2 |
| 赛道符号 | 中下部 |
| 作者区 | 下 1/4 |

### 4.2 6 种视觉钩子 + 6 种构图
- 钩子：人物特写+关键道具 / 场景氛围+赛道符号 / 战斗瞬间 / 成长蜕变 / 悬念钩子 / 势力门派标识。
- 构图：居中对称 / 三分法 / 对角线 / 三角稳定 / 框架构图 / 极简留白。

### 4.3 赛道视觉速查（小巧思）
玄幻（仙人/法宝/符文）、仙侠（剑/山/云气）、都市（霓虹/西装/街景）、悬疑（阴影/密码/裂痕）、科幻（粒子/机械/星图）——打开类型即匹配封面方向。配色调为**基调色 + 强调色 + 辅助色**，光影按戏剧光/氛围光/赛博霓虹/自然光分档，文化元素库含定场诗/印章/小篆/古籍版式。

### 4.4 参考点六维拆解（小巧思）
参考不是一次性抄图，而是拆成可复用维度：**全面参考 / 色系参考 / 构图参考 / 画风参考 / 光影参考 / 字体参考**——从一张好封面提取能复用的设计维度。

### 4.5 提示词骨架 + 书名融入画面
提示词结构：整体氛围框架 → 画面内容（远→近）→ 书名文字（融入画面）→ 风格。书名用双引号包裹、有材质质感、被前景遮挡/与雾气融合——**不形成独立文字区，参与画面构图**。

---

## 5. 可测量 / 门禁

| 门禁 | 口径 |
|---|---|
| **0.3秒识别** | 目标读者扫一眼能认出赛道 |
| **四层信息齐** | 标题/主视觉/赛道符号/作者齐备 |
| **书名可读+有辨识度** | 书名必须大、可读、有赛道感 |
| **参考点可复用** | 参考被结构化为设计维度，非整图抄 |

## 6. 深度：封面是视觉 IP 的"流量入口"
被用户第一眼接触，决定点不点开看 OC/漫画。**营销价值**：它把"封面好不好"从主观欣赏变成"0.3 秒识别 + 点击欲"的可测目标，是整套视觉资产变现的第一环。

---

## 7. 操作顺序（先定营销目标，再定视觉）
定位读者+赛道 → 选视觉钩子 → 搭四层信息架构 → 定构图/配色/光影 → 放书名融入画面 → 参考点六维对齐。**先营销目标后视觉表现，否则越画越漂亮越没人点。**

## 9. 竞品差异锚（一句话）
市面封面 = 画得好看当成果（点开率低）；popwave 封面 = **四层信息架构 + 6钩子 + 6构图 + 赛道速查 + 参考点六维 + 书名融画面**，把封面从"艺术"变成"可测的营销漏斗第一环"。
