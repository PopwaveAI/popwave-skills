## 0. 一句话卖点

**popwave 给视觉项目一条不迷路的流水线：Phase 0→6 总控调度（初始化→配置→提资→美术设定集→衍生品→审核→归档），Progress 文件让状态可视化、可导航，三态落盘隔离成品/测试/过程，一键批量导出漫画任务清单。用户不需要想"下一步干什么"，管线按阶段推。**

## 1. 用户痛点：视觉项目做到一半"不知道走到哪"

| 痛点 | 表现 | 后果 |
|---|---|---|
| **阶段无头绪** | 不知道该先建设定还是先出图 | 卡在中间，返工多 |
| **进度靠记忆** | 做到第几步全凭脑内追踪 | 漏步、重复做 |
| **文件一团乱** | 成品/草稿/测试混在一起 | 找不到最终文件 |
| **批量靠手输** | 多章漫画任务一条条手动录入 | 慢、易错 |

> 核心焦虑：复杂视觉项目（尤其是一本书的多章漫画）需要**可导航、可状态化、可落盘**的编排，否则会因阶段跳跃而遗漏。

## 2. 关键认知：视觉管线是"路由总控"，子 skill 各司其职

高质量视觉编排 = pipeline 只做路由调度，把 Phase 0-6 串成状态机，子 skill（asset/style/art-bible/cover/oc/comic）干具体活。用户看到的是"进度文件 + 下一步建议"，而不是一堆散乱的工具。

## 3. 反面教材：把视觉工具当成"一次性命令"

- **不排阶段的硬跑**：跳过设定集直接出漫画，画风/人物全崩。
- **进度靠口述**：做到 Phase 4 了还说"刚提完资产"，重跑浪费。
- **文件混放**：最终成品和草稿同目录，误删/混淆。
> 正确做法：见第 4 节——Phase 状态机 + Progress 文件 + 三态落盘 + 批量导出。

---

## 4. 机制：Phase0-6 + 三步诊断 + Progress + 三态落盘 + 批量导出

### 4.1 Phase 0→6 全链路
| Phase | 内容 |
|---|---|
| 0 | 项目初始化 |
| 1 | 项目配置 |
| 2 | 视觉资产提取 |
| 3 | 美术设定集 |
| 4 | 衍生视觉产品（OC/封面/漫画） |
| 5 | 品质审核 |
| 6 | 项目归档 |

### 4.2 Phase 0 三步诊断（小巧思）
1. 用户目的诊断 → 2. 当前状态诊断 → 3. 下一步推荐。
> 用户即使没想清楚，系统也能判断下一步该走哪条路。

### 4.3 Progress 文件：状态可视化 + 阶段导航（小巧思）
维护包含 Phase 0-6 实时状态、可执行步骤、用户指令解析、路径选择的 Progress 文件——进度不是口头进度，而是**文件化、可视化、可导航**。

### 4.4 落盘三态隔离
- 成品 → `/成品/`（项目最终交付物）
- 测试 → `/测试/`（阶段测试文件）
- `_过程` → `/_过程/`（临时文件、中间产物）
> 文件结构清晰，项目文件不会混乱、不会误删成品。

### 4.5 批量导出脚本
`export_comic_tasks.py` 把多章漫画任务导出为结构化清单（章节/角色/场景/风格/提示词/格式字段）——批量漫画生产不再是手动逐条输入，而是**先生成任务清单再执行**。

---

## 5. 可测量 / 门禁

| 门禁 | 口径 |
|---|---|
| **Phase 有序** | 先设定集后衍生品，不可跳级 |
| **Progress 可导航** | 状态/步骤/路径文件化 |
| **三态落盘** | 成品/测试/过程分离 |
| **任务清单完整** | 批量导出含章节/角色/场景/风格/提示词 |

## 6. 深度：管线编排是视觉家族高效产出的"总调度"
被 asset/art-bible/cover/oc/comic/style 全部技能消费。**营销价值**：它让"做完一本漫画/一套 IP 视觉"成为可导航、可追溯、可批量推进的过程，而不是一堆孤立的生图命令。

---

## 7. 操作顺序（总控只路由，子skill干活）
Phase0 三步诊断 → Phase1 配置 → Phase2 提资（asset）→ Phase3 美术设定集（art-bible/style）→ Phase4 衍生品（cover/oc/comic）→ Phase5 审核 → Phase6 归档。**pipeline 只调度，asset/style/art-bible 等子 skill 负责产出。**

## 9. 竞品差异锚（一句话）
市面视觉生图 = 一次性命令/无阶段/文件混放；popwave 视觉管线 = **Phase0-6 + 三步诊断 + Progress 文件 + 三态落盘 + 批量导出**，把视觉项目做成可导航、可追溯的流水线。
