## 一句话定位

**视频家族不碰 AI 视频生成，走"确定性渲染"：HTML 动效时间线 → Playwright 逐帧 → ffmpeg 合成 MP4 → 火山 TTS 口播配音。文字与 UI 精确可控、可审计可复现。品牌片有预览闸门防返工，漫画片走"先脚本后出片 + 读图理解"。要的是可商用的成品，不是抽卡的画面。**

## 营销选词铁律（视频家族特有的口径边界）

1. **"确定性渲染"是主线卖点，不是"AI 一键出视频"**——对外突出"文字不扭曲、版式不失控、成本可算、品牌合规、可审计可复用"，**不承诺 AI 视频的抽象场景**。视频要的是可控成品，不是抽卡。
2. **最硬的几张牌可主打**：确定性渲染管线、preview→full 预览闸门防返工、品牌"一个价值点3-4张截图 + 五场景结构"、漫画"先脚本后出片"。
3. **可量化项优先上桌**：5场景结构/30-40s、口播≤30字/句、预览8-12帧、1920×1080/30fps/H.264、BGM音量0.3-0.5/淡入0.8s淡出2.5s、漫画60s/240-300字、Ken Burns缩放1.0→1.15。
4. **跨家族协同**：视频家族消费视觉家族成品（漫画页/OC/封面转视频）；去AI味/文风家族管脚本文字质感。营销时突出"确定性 + 可商用 + 漫画/品牌双管线"，其它家族没有的确定性。
