## 0. 一句话卖点

**popwave 的视频不走 AI 视频生成，走"确定性渲染"：品牌素材包 → 叙事脚本 → HTML 动效时间线 → Playwright 逐帧渲染 → ffmpeg 合成 H.264 MP4 → 火山 TTS 口播 + BGM 混音。全程 HTML 元素驱动，文字与 UI 精确可控、可审计、可复现、品牌合规。要的是能直接商用的片，不是撞运气的画面。**

## 1. 用户痛点：AI 视频"不靠谱又不可控"

| 痛点 | 表现 | 后果 |
|---|---|---|
| **文字扭曲** | AI 生成的视频里文字乱花非读 | 品牌信息出错 |
| **版式失控** | AI 视频排版随缘 | 品牌形象崩塌 |
| **成本不可算** | AI 出片按秒烧钱、结果不可控 | 预算黑洞 |
| **不可审计** | 不知道某个字/框是怎么出来的 | 品牌合规失败 |

> 核心焦虑：品牌/产品视频要的是"每个字、每个框都可控可复现"，AI 抽卡式生成满足不了合规与审计需求。

## 2. 关键认知："确定性"比"惊艳"更重要

高质量品宣视频 = **每一个像素都是 HTML 决定、可回查、可复现**。HTML 元素驱动文字与 UI，Playwright 逐帧截取，ffmpeg 合成——出片前能预览、出片后能审计，品牌信息（色板/文案口径）直接锁进渲染管线。

## 3. 反面教材：把 AI 视频当成品工具

- **文字扭曲**：用 AI 生成，口播词和字幕错乱、字体变形，品牌信息失真。
- **不可复用**：这次运气好出个爆款，下次同素材再生成又变样——无法稳定交付。
- **合规失控**：色板/文案被 AI 自由发挥，品牌识别不一致、法务紧张。
> 正确做法：见第 4 节——HTML 确定性渲染全链路 + 品牌色板/口径锁死。

## 4. 机制：确定性渲染全链路 + 品牌合规锁死 + 混音

### 4.1 确定性渲染管线（核心机制）
品牌素材包（规范+截图+logo/吉祥物）→ 叙事脚本 → **HTML 动效时间线** → **Playwright 逐帧渲染** → **ffmpeg 合成 H.264 MP4** → 火山 TTS 口播配音 + BGM 混音。
> 小巧思：全程 HTML 元素驱动，文字与 UI **精确可控**，不依赖 Seedance/GenerateVideo 等 AI 视频生成——从根上杜绝文字扭曲/版式失控。

### 4.2 Sky Bubble 品牌色板与文案口径速查（小巧思）
- 色板锁死 Sky Bubble CSS 变量：主蓝 `#2F64FF`、泡泡青 `#26D7E8`、波浪紫 `#7B59FF`、主墨 `#141824`、正文 `#343B4D`、画布白 `#FBFDFF`、线框 `#DCE8F2`。
- 文案口径速查：品牌定位、核心条、功能链、禁用对照。
> 禁止自创配色或夸大文案——把品牌识别直接锁进渲染管线。

### 4.3 一个价值点、3-4 张截图（信息过载门禁）
Step 0 盘素材按"每支视频只讲一个价值点、最多 3-4 张界面图"铁律，圈定主价值点/截图清单/是否用团队故事图。Tag 服务一个卖点，不把所有截图塞进一支片。

### 4.4 含 BGM 的可选混音管线
ffmpeg 将配音轨与可选 BGM 混入无音轨版：口播 1.0、BGM 0.3-0.5 不压人声；BGM 淡入淡出（开头 0.8s 淡入/结尾 2.5s 淡出）；需精确对齐可用 `adelay`/`amix` 逐句定位。

### 4.5 imageio-ffmpeg 保证编码稳定
用 imageio-ffmpeg 自带完整版 ffmpeg（含 libx264）处理标准 PNG→H.264 MP4；系统精简版 ffmpeg 仅能处理 scale/fps，不够用。encode 脚本默认 30fps、CRF 18、libx264、yuv420p、faststart——降低"ffmpeg 环境差异导致合成失败"的风险。

### 4.6 成品规格
1920×1080、30fps、H.264 + yuv420p，`ffmpeg probe` 核对分辨率/时长/fps/编码；时长对不上说明 timeline 边界有误需回查 Step 2。

## 5. 可测量 / 门禁

| 门禁 | 口径 |
|---|---|
| **确定性渲染** | 禁止 Seedance/GenerateVideo 等 AI 视频 |
| **品牌合规** | 必须读品牌规范、色板严格 Sky Bubble、文案用品牌口径 |
| **单价值点** | 一支片一个价值点、最多3-4张截图 |
| **成品规格** | 1920×1080/30fps/H.264 |

## 6. 深度：确定性管线是"可商用"的底盘
出片前提帧审查（见 03）、编码规格、混音多层门禁共同保证"能直接用、能对上品牌、能审计"。**营销价值**：它把"做条品宣片"从"烧钱的 AI 赌博"变成"可复核、可复用、可商用的工程"。
