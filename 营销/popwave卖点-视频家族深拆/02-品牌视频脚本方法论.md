## 0. 一句话卖点

**popwave 把品牌视频脚本做成"先想清楚再写分镜"的方法：6 步素材驱动（提炼真相→立意→选角度→铺结构→逐镜写→闸门自检），标准五场景结构（30-40s 可拆），口播**≤30字/句、像人说话**。写完删掉画面只留文字也能成立才通过——不是套模板，是从素材里提炼品牌核心主张。**

## 1. 用户痛点：品牌视频"结构散、卖点不集中"

| 痛点 | 表现 | 后果 |
|---|---|---|
| **套模板出片** | 拿素材塞进模板，没有立意 | 视频无叙事方向 |
| **结构散** | 场景乱堆，卖点不集中 | 观众抓不住重点 |
| **口播像说明书** | 字句太长、念产品参数 | 不像人说话、无感染力 |
| **分镜花哨但空** | 画面很美，叙事空泛 | 看完没记住 |

> 核心焦虑：品牌视频最怕"看起来精致、讲不清一句话"——脚本必须自己立得住，不靠画面充数。

## 2. 关键认知：脚本是"从素材反推品牌主张"，不是"素材模板填空"

高质量脚本 = 从素材提炼用户痛点 → 立定立意 → 选择角度 → 铺设结构 → 逐镜写作 → 闸门自检。核心信条"**先想清楚，再写分镜**"。每个镜头三件套（画面+口播+字幕），口播承担叙事主线，像人说话。

## 3. 反面教材：把"堆素材"当"写脚本"

- **无立意**：把 logo、几张截图、团队照塞一起，没有一句品牌主张。
- **口播念参数**："本品支持 XX 功能，采用 XX 架构"——不像人在和你说话。
- **只会用画面撑**：分镜很漂亮，但删掉画面后文字根本讲不成一个故事。
> 正确做法：见第 4 节——6 步立意法 + 五场景结构 + 闸门自检（只留文字也成立）。

---

## 4. 机制：6步脚本 + 五场景结构 + 口播约束 + 闸门自检

### 4.1 6 步素材驱动脚本创作法（94% 时间花在"想"）
提炼真相 → 立定立意 → 选择角度 → 铺设结构 → 逐镜写作（画面+口播+字幕）→ 闸门自检。
> 小巧思：脚本不是素材模板填空，而是从素材**反推用户痛点、证据点、差异化**，保证视频有明确叙事方向。

### 4.2 标准五场景结构（30-40s 可拆，小巧思）
| 场景 | 时长 | 功能 |
|---|---|---|
| 开场 A | 4-5s | 建立共鸣 |
| 产品核心 B | 6-7s | 亮主价值 |
| 证据/闭环 C | 6s | 截图证明 |
| 扩展差异 D | 6s | 拉开差距 |
| 收尾 CTA E | 6-8s | 品牌+转化 |

> 每场景只服务立意，不推进立意的功能位直接砍掉。

### 4.3 口播 ≤30字/句，像人说话
镜头三件套：画面、口播、字幕。口播承担叙事主线，要求**口语化、≤30字/句**；TTS 默认知性灿灿 2.0（`zh_female_cancan_uranus_bigtts`，火山语音「豆包语音合成大模型」），支持语速/响度/音调微调——不是念说明书。

### 4.4 闸门自检：删掉画面，仅文字也要能讲清一支视频
写完脚本后，删掉所有画面描述和动效说明，只看字幕+口播稿件，逐条核对：①开头 3 秒是否有钩子；②每句是否推进立意；③文案是否全部来自品牌口径；④删掉品牌名后是否还像真人说话；⑤收尾是否有明确 CTA。**任一为否，回对应小节重写。**

---

## 5. 可测量 / 门禁

| 门禁 | 口径 |
|---|---|
| **五场景齐** | 每场景只服务立意，无功能的砍掉 |
| **口播≤30字** | 每句像人说话、口语化 |
| **闸门自检** | 删画面仅文字能讲清（钩子/立意/口径/人味/CTA） |
| **品牌口径** | 文案全部来自品牌口径，不夸大 |

## 6. 深度：脚本是整条渲染管线的"纲"
脚本（画面/口播/字幕）直接喂养 HTML 时间线（Step2）和 TTS（Step5）。**营销价值**：脚本定得好，后面的动效/渲染/配音才不返工——用"仅文字成立"这一关前置卡掉空泛叙事。

---

## 7. 操作顺序（先立意，再结构，再逐镜，再自检）
提炼真相→立立意→选角度→铺五场景→逐镜写三件套→闸门自检（删画面看文字）→ 任一否回改 → 交接渲染。

## 9. 竞品差异锚（一句话）
市面品牌脚本 = 素材塞模板/口播念参数/分镜充叙事；popwave 脚本 = **6步立意法 + 五场景结构 + 口播≤30字 + 删画面仅文字自检**，保证"先讲清，再拍美"。
