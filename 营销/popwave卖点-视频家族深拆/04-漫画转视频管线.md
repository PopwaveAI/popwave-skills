## 0. 一句话卖点

**popwave 把"一章漫画"做成"一条 60 秒短视频"：模型读图自理解漫画页（配文字锚点兜底）→ 口播脚本（每句绑 page{N}、钩子先行）→ edge-tts 免费配音（无需 API Key）→ Ken Burns 推拉 + 中文字体显式设置 → 版本化输出。先脚本后出片、读图为主配置兜底，方向跑偏和画面错位都被闸门拦住。**

## 1. 用户痛点：漫画改视频"方向跑偏、口播错位"

| 痛点 | 表现 | 后果 |
|---|---|---|
| **方向跑偏** | 脚本不确认直接配音，最后方向错了 | 白配音白合成 |
| **口播与画面错位** | 旁白不知道对应哪页 | 对不上、观感乱 |
| **配音要充值** | 商用 TTS 要 API Key | 门槛高 |
| **静态像 PPT** | 漫画页硬切，僵化 | 观感差 |
| **字幕乱码** | 中文字体没显式设 | 系统差异显示异常 |

> 核心焦虑：漫画转视频的"节奏 + 对齐 + 低成本"是命门——不能脚本不把关、口播不绑页、静态硬切。

## 2. 关键认知：先脚本后出片，每句口播绑定页面

高质量漫画视频 = **读图理解漫画内容 → 口播脚本（先出、需确认）→ 每句标 page{N} → 配音 → 合成**。脚本确认是闸门；读图为主、配置文字兜底保证断页不断片；Ken Burns 让静态页动起来；中文字体显式设置保证可读。

## 3. 反面教材：把漫画转视频做成"硬拼"

- **脚本不过关**：不确认脚本直接配音合成，口播方向跑偏、白烧成本。
- **口播不绑页**：一句话不知道配哪个画面，错位成"音画不同步"。
- **静图硬切**：每页一张静止图堆叠，60 秒看得昏昏欲睡。
- **字幕乱码**：没显式设中文字体，这台电脑正常那台乱码。
> 正确做法：见第 4 节——先脚本后出片 + 绑页 + Ken Burns + 字体显式。

## 4. 机制：读图理解 + 先脚本后出片 + 绑页 + 免费TTS + Ken Burns + 版本化

### 4.1 读图为主、配置文字兜底（小巧思）
模型直接 Read 漫画页，产出每页画面白描/氛围标签/镜头感；**若单页被安全审查拦截，用 `页面配置.json` 该页文字锚点补全画面理解，标注 `[读图被拦截，配置文字兜底]`**——禁止因读图失败中断管线（拦截页不断管）。

### 4.2 先脚本后出片（闸门）
漫画页(page1~N.png)+`页面配置.json` → 读图自理解 → **口播脚本.md → 停下等老板确认 → 确认后才进配音与合成**。脚本确认做成闸门，方向跑偏在倒贴成本前被拦下。

### 4.3 每句口播绑定 page{N}（小巧思）
脚本每句标注 `seq/page/text/emotion/est_sec`，估算时长按约 4-5 字/秒——配音/字幕/画面逐页对齐，杜绝口播与漫画页错位。

### 4.4 场景化 60 秒结构，钩子先行
[钩子0-5s] 开场1-2句抓注意力（设问/悬念/反差）→ [展开5-50s] 按页推进、每页1-2句、情绪递进 → [收尾50-60s] 钩子留白/悬念引导追读。目标总时长约 60s、总字数约 240-300 字。

### 4.5 免费 edge-tts 配音，无需 API Key
按口播脚本逐句生成人声，支持 `zh-CN-YunxiNeural`（男）/`zh-CN-XiaoxiaoNeural`（女）等中文音色；解析口播句格式，输出 `时长清单.json` 供合成对齐——降低漫画短视频批量生产门槛。

### 4.6 Ken Burns 推拉规则（小巧思）
每帧从"起始缩放/位移"缓动到"结束缩放/位移"；竖屏图缓慢推近(zoom in)或平移(pan)，避免静止；**缩放控制在 1.0→1.15 内**，避免观感怪异。

### 4.7 中文字体强制显式 + 版本化输出
显式设中文字体（`Noto Sans CJK SC`/`WenQuanYi Micro Hei`），禁止默认字体；字幕叠加在图片下方/底部不遮挡关键信息。成品命名 `第{N}章-v{版本}-final.mp4`，`preview/frames/audio/` 为过程文件——天然可追溯、不混淆。

## 5. 可测量 / 门禁

| 门禁 | 口径 |
|---|---|
| **先脚本后出片** | 脚本确认前禁止配音/合成 |
| **每句绑页** | seq/page/text/emotion/est_sec 齐全 |
| **读图兜底** | 拦截页用配置文字补全，不断管 |
| **60s结构** | 钩子/展开/收尾三段，240-300字 |
| **字体显式+版本化** | 中文可读、成品-final可追溯 |

## 6. 深度：管线把漫画"可消费化"
消费视觉家族产出的漫画页/OC/封面，产出一条可投放的竖屏短视频。**营销价值**：它让"一本漫画"天然带"一条能发出去的短视频"，读图自理解 + 脚本闸门 + 免费 TTS 管住静图僵化、错位和门槛三座大山。
