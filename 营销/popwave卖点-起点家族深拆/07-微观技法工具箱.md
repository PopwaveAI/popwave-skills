## 0. 一句话卖点

**popwave 微观技法工具箱：一整套"能落地到具体某一句/某一战/某一幕"的写作技法库——战斗细到关节级、对话细到潜台词、位阶细到外部反应、大场面用旁观者侧面定级不用硬吹——正文从"有剧情"升级到"有质感、可跟、可感"。**

## 1. 用户痛点：剧情有了，质感跟不上

| 痛点 | 表现 | 后果 |
|---|---|---|
| **战斗像报技能名** | 出手就是"一拳轰出、剑光一闪"，没有打击感 | 读者看不进去,爽不起来 |
| **大场面靠硬吹** | "他很强/天地变色"，空洞 | 格局感全靠作者嘴，出戏 |
| **升级只剩数值** | 突破就是面板数字 +1 | 读者无感，成长没记忆点 |

> 核心焦虑：网文正文的差距在"执行细节"。同样一个情节,高手写出来有画面、有节奏、有情绪;工具写出来平铺直叙。用户缺的不是"剧情创意",是**把剧情"写得有质感"的方法**。

## 2. 关键认知：质感 = 每个场景都被拆成"可执行动作"

写作技法的价值 = 把"写得好"这种模糊目标，拆成**具体场景里该做什么动作**。战斗有规划卡、对话有六要素、位阶有三维、大场面走间接手法——每一项都告诉你在"这个场景"怎么下手，而不是给你一句飘的写作建议。

## 3. 反面教材："写得好一点"为什么没用

- **虚泛建议**："这里要写得更生动/更有冲击力"——无法执行。
- **能力展示式战斗**：堆招式名和特效，但战斗不推进成长/资源/关系/信息，好看但无意义。
> 正确做法：看第 4 节——每一项技法都落到具体动作、具体分寸。

## 4. 机制：六大技法簇，把质感拆成可执行动作

### 4.1 重写 11 项微观技法：把"建议"变成"动作"
开局钩子设计 / 冲突升级放大 / 感官细节强化 / 行动链编排 / 视角切换节奏 / 信息差利用 / 节奏变化控制 / 情绪积累释放 / 动作描写增强 / 场景氛围烘托 / 人物对话差异化。
**小巧思**：每项有具体执行动作——用感官细节替换空泛形容、用行动链替代总结式叙述。

### 4.2 局势掌控 10 项：大场面不用硬吹
- 侧面定级 / 多维信息差 / 资源错位 / 因果链揭示 / 全景展开 / 多线并行 / 情感锚点插入 / 倒计时压迫 / 旁观者反应放大 / 层级结构呈现。
- **小巧思（关键）**：侧面定级不直接写"强者多强"，而是写**远处人群反应、建筑震动、旁观者震惊**，让读者自己补强——格局感来自间接，不是作者嘴。

### 4.3 3 维位阶表达工具箱：升级不枯燥
- 本体特征（是什么）→ 动态变化（怎么变）→ 外部反应（别人怎么看）。
- 境界提升不只写数值，**还写身体变化、他人认知变化、环境/规则反应**。升级是"可感知的剧情变化"，不是面板数字。

### 4.4 战斗规划 8 维卡 + 战斗六要素：每场战斗都有目的 + 写得可感
- **规划卡（先设计再写）**：战斗功能 / 双方目标 / 胜负条件 / 信息差布局 / 攻防节奏 / 代价递进 / 转折点 / 读者情绪曲线。先答"打完后什么变了",再设计节奏与转折；小规模战只填核心 4-5 项。
- **六要素（解决动作质量）**：动作 / 招式名 / 画面维度 / 内心判断 / 路人生理反应 / 环境匹配。
- **小巧思（打击感核心）**：动作描写从事件级写到姿态级——枪械拆到**机械操作级**、法术拆到**施法动作级**、格斗拆到**关节级**。写后果不写能力名。

### 4.5 对话六要素：对话不是传声筒
- 信息密度 / 潜台词 / 节奏 / 动作插入 / 功能复合 / 个性区分。
- 重要对话不只传信息，还要有情绪、伏笔、性格差异、关系变化。**每句话都承担信息、个性、伏笔或关系推进**，不是为讲设定而说话。

### 4.6 情境与流派技法簇（情感/世界观/恐怖/梗/博弈/面板/科普/仪式/视角）
- **情感锚点 6 种**：弱者牵引 / 反差依赖 / 共患难 / 牺牲献祭 / 愧疚补偿 / 关系裂痕——"情感不是喊出来，是场景里长出来"。
- **世界观渐进揭示**：展示→误解→揭示→影响，只给一部分、保留更大悬念，载体自然（回忆/对话/事件/场景），禁大段百科，每次揭示产生行动后果。
- **恐怖奇观美学化**：视觉奇观/心理压迫/规则异化/美学升华四层——"美得不正常"的持续张力，而非单纯吓人。
- **社会梗融入**：隐性植入/剧情反转/文化致敬/桥段借用/类型梗——风格统一、不生硬，有时代感但不网感过重。
- **规则博弈与限制创意**：全章冲突围绕明确可验证、对所有人公平的规则——限制变成智斗、反杀、反转的来源。
- **数值面板叙事**：面板不只是数据，要产生决策/反应/误用/剧情推进；弹出时机配合爽感（首杀/升级/获得能力/遇强敌/完成成就），属"行动→结果→反馈"循环的一环。
- **知识降维科普**：类比/拆解/对比/场景化/递进/反馈六法，把复杂设定翻译成叙事信息，知识在行动/误会/冲突中带出。
- **仪式感叙事**：固定程序/象征物/集体见证/时间节奏/仪式反转——重要事件有纪念感、是读者记忆点。
- **非人视角参与**：物品/动物/NPC/系统/世界规则视角——必须承担信息、情绪或节奏功能，不纯炫技。

### 4.7 DND「类型档」-战斗模式库（按境界/类型复用）
- **凡人期 5 类**：暗杀流（踩点/潜行/翻盘/面板结算/翻尸体）、遭遇战、游击消耗战、正面遭遇战、终结技爆发。
- **超凡期 7 类**：魔法异能对抗/形态转换/神器法宝/法术连击/范围破坏/结界领域战/组合技爆发——超凡不是"普通战斗加特效"，是机制/代价/范围/规则变化。
- **神明级 7 类**：神性威压/概念对抗/法则重塑/神战降临/神器概念碰撞/信仰教义对抗/因果律武器——从个人胜负升级为世界结构变化。
- **特殊条件战 6 类**：盲战（信息差+方向感）/追逐战（目标+限制）/阵地战（防御+消耗）/水下战（行动限制）/环境战/规则战（规则博弈）。
- **配套**：多线叙事+场景卡（统一时间/地点/人物/事件/状态/线索，各线必须汇合或因果影响）+ 数据化分析（追踪行为/资源/状态/面板/规则/伏笔，检查承诺是否兑现）+ One Piece 战斗体系（无霸气/果实/霸气阶段 + 海上战斗 + 金手指触发判断表）。

### 4.8 文风兜底库：风格可参考、可继承
- 按作品提取 DNA 特征（句式/叙事距离/感官顺序/情绪外化/对话引导词/章名/章末钩子/系统面板格式）。
- 覆盖《深渊主宰》《夜无疆》《诡秘之主》《捞尸人》《东京医途》等。把"文风"从感觉变成**可执行写作规范**。

## 5. 可测量 / 门禁：质感有分寸，不是玄学

| 技法 | 口径 | 意义 |
|---|---|---|
| **战斗六要素** | 拆到关节级/施法动作级 | 打击感可落地 |
| **对话六要素** | 6 项逐项检查，1-2 项偏失给方向，3 项以上建议重写 | 对话可质检 |
| **低压区/旁观者** | 低压≥1 段、旁观者放大必现 | 爽感结构可控 |
| **位阶三维** | 本体+动态+外部反应缺一即空 | 升级不落数值 |

## 6. 深度：技法库是 write 的"弹药库"，被 review/审核复用
- 同类技法（对话六要素/战斗三查/好看度）在 write 执行、review 复审两侧共用，口径一致。
- **营销价值**：用户能拿到**按境界/流派/情境分类的成套成系列的"怎么写"方法**，叙事从"平铺"到"可跟、可感、有记忆点"。

## 7. 操作顺序（先规划，再写法，后自检）
战斗先填规划 8 维卡再写 → 位阶走三维 → 对话过六要素 → 大场面用旁观者侧面定级 → 按 DND/OP 流派档选战斗模式 → write 自检。**写之前先想清楚"这一场景要完成什么、读者该有什么反应"。**
