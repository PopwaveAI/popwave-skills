# 拉片02 · 拆书引擎：「把爆款拆成能复用的图纸」

> 性质：原材料，非对外稿。颗粒度对标「去AI味」样板。
> 依据：pop-decon / design-pack / dimension / prd / dna-style 深读。

---

## 0. 一句话卖点

**popwave 的"拆书"不是读后感，是把一本爆款逆向破解成工程图纸——7 个维度联合提取、每个结论都能回溯到原文章节，最终产出"立项级蓝图"，让你站在爆款肩膀上仿写其机制而不抄其内容。**

## 1. 用户痛点：模仿爆款的三难

| 痛点 | 传统做法 | 后果 |
|---|---|---|
| 看不懂好在哪 | 凭感觉读 | 学不到可复制的机制 |
| 抄了侵权 | 直接套设定/剧情 | 版权风险 + 读者反感 |
| 拆了记不住 | 零散笔记 | 拆完即忘，无法落地 |

> 卖点本质：**把"读作品"变成"提取可复用机制"，逆向破解而非照搬。**

## 2. 核心认知：拆书 = 逆向破解

- pop-decon-prd 的哲学——**"拆书=逆向破解"，PRD 是总结报告，不产生新数据，只综合已有数据**。
- 区别市面"AI 帮你总结这本书"：popwave 拆的是**机制**（节奏/爽点/世界观引擎/金手指），不是剧情梗概。

## 3. 省算力的独创机制：7 维联合 Grep 锚点池（差异化杀手锏）

**这是整套引擎最有"巧思"的一处：**

- 拆书要 7 个维度（剧情/情感/人物/力量/世界观/爽点/文风），naive 做法是每维读一遍全文 → **7 倍开销**。
- popwave 的做法：**把所有维度的检索词合并成一次 Grep** → 命中章节去重 → 形成**联合锚点池** → **每章只精读一次**，同时提取全部 7 维设定。
- 小巧思：**style 维度走场景定向采样，不参与联合 Grep，但复用同一批精读章**——既保文风采样质量，又不再多读一遍。
- 卖点翻译：**"拆一本书，只付出读一遍的算力，却拿到 7 个维度的图纸。"** 直接对"省算力/省时间"负责。

## 4. 输出格式的聪明取舍：双维度可选

拆书工作量可大可小，popwave 让你选档（design-pack）：

| 取舍轴 | 选项 | 适用 |
|---|---|---|
| 输出格式 | `precision`（v4 设计包 3 层+1 区） | 要深拆、逐章白描卡 |
| | `fast`（瘦身白描卡 4 段式） | 只要骨架/节奏 |
| 处理方式 | `quality`（每章 1 子agent） | 精度优先 |
| | `performance`（每 30 章 1 子agent 合并） | 速度/成本优先 |

- 小巧思：**任务开启前强制确认模式**——不擅自替你定深度，避免误跑整本。

## 5. 严谨到能审计：每条结论带原文锚点

- **无 chXX 证据且未标"原文未展开"= 编造**（红线）——拆书结果可回溯、可审计，不是 AI 幻觉。
- 关键数值必须 🔒 锁死（防下游取值漂移）。
- 前 N 章不能产出全书级文件（范围诚实）。

## 6. 终点产出：立项级全文设计 PRD

- dimension 各维度 → prd 交叉验证 → 产出 `全书立项设计.md`，含：
  - **逆向破解总结**（mechanism 提取）
  - 全书结构（三幕/卷级）
  - **商业可行性**（为什么这本能火）
  - 连载规划
  - **风险预警**（哪些不能学/会翻车）
- 红线：核心假说必须有 chXX 证据；赛道判定不凭书名猜；PRD 与各维度数据不得矛盾。

## 7. 边界诚实（为何敢信）

- decon 入口：**下载 txt→征询"拆什么范围？拆哪些维度?"→才路由**，禁止未征询就全量跑（不浪费算力、尊重作者意图）。
- 无源文件禁启动（pop-dna-style 原文存在性前置门禁：参考书 txt 必须存在）。
- 提醒"先第一卷少量测试再拓展全书"，不一次拆爆。

## 8. 连通闭环：拆书 → 立项 → 开写

拆书不是终点——pop-decon-prd 产出的立项蓝图，可直接喂给创作产线（seed/world/character/plot）**仿写机制、原创内容**。这就把"学别人"和"写自己"接起来了。

## 9. 对外话术种子

- "别人给你读书笔记，popwave 给你拆成能用的图纸。"
- "一本书只读一遍，7 个维度的套路全给你挖出来，每条都标着原文章节。"
- "学的是机制，不是剧情——想抄的都还在，想避的都躲开。"

## 10. 竞品差异锚

- 通用 AI 拆书 = 剧情概括/读后感；popwave = **逆向破解 + 原文锚点 + 立项 PRD**，从"读懂"升级为"能开始写"。
