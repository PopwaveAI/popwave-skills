# 拉片03 · 长线不写崩：「起点卷纲的债务管理哲学」

> 性质：原材料，非对外稿。颗粒度对标「去AI味」样板。
> 依据：pop-qidian-plot + 用户实战决策（记忆库 + 当前项目红线）。

---

## 0. 一句话卖点

**长篇小说最大死因不是"写不下去"，是"埋的线收不回来、高潮透支、节点崩盘"。popwave 的卷纲不是剧情大纲，而是一套「战略 + 债务 + 收益保护」的工程：每幕只干一件事，每根线都记账，绝不提前消费后面的大高潮。**

## 1. 用户痛点：长线写作的 5 条死法

| 死法 | 现象 |
|---|---|
| 崩在前面 | 前置幕太爽，透支后续大高潮 → 后面没爆点 |
| 线淹死 | 埋了太多支线，自己都忘了收 |
| 节点失衡 | 每章/每幕权重一样 → 该爽的不爽，该略的拖沓 |
| 张力涣散 | 一集塞十件事，观众记不住 |
| 灵感崩盘 | 剧情靠灵感硬挤，白描不扎实 → 转折生硬 |

> 卖点本质：**把"写小说"当成"运营一个连载产品"来管理。**

## 2. 第一原理：卷纲 = 战略，不是目录

- **卷纲定战略、定范围、定方向，具体剧情交给幕纲**——职责边界清晰，避免"画大饼式大纲"。
- 卷纲内含**本卷定位 + 剧情 brief（3-5 句话框选大致走向）**——给方向但不锁死，幕纲有发挥空间。

## 3. 核心机制①：以「幕功能位」为轴（每幕只干一件事）

- 每幕只有 **1 个功能位 + 1 条主压力 + 1 个主收益**。
- 剧情线服务于幕功能——所有支线都为这一幕的"大目标"服务，不各自为政。
- **小巧思（防"不能抢的后续收益"）**：卷纲专门设**「不能抢的后续收益」列**——明确标注哪一幕**禁止提前透支**后面的高潮爽点。这是防止"前置幕写太爽"的硬护栏。

## 4. 核心机制②：长线债务管理（埋线/还线台账）

- 卷纲统一管理**长线债务**：**埋下的线（欠的） + 偿还的线（还的）**，每根线标注**触发条件**。
- 小巧思：像记账一样管理剧情线——不怕埋得多，怕忘了还；每根线都是"借出去的情绪"必须"还回来"（对应元素卡收线族："线是情绪结账"）。

## 5. 核心机制③：事件种子池（量大定小）

- 剧情子线改为**事件种子池**：主线 / 支线暗线 / 世界观设定 三类，每条**一句话**，**量大但 brief**。
- 小巧思：**让幕纲自由选择发挥**，而不是被死命令绑死——战略层给资源，执行层自选取。

## 6. 核心机制④：幕纲白描扎实（承接拉片02 的白描哲学）

- 幕纲章行须**从目录化升级为清单化**——每条标准章行展开为**可实例化清单条目（含数字/对象/后果）**，能直接找到落点节拍。
- 自检用**"领料充足自检法"**：信息条数/节拍数/可实例化密度——验证幕纲能不能撑起章纲质量。
- 幕纲负责给**充足的"料"**（面板数字、世界观设定块、阴谋线、情感爆点），章纲负责**编排**（怎么排），渲染层负责**写作**（怎么写）——**职责三层分离，各管一段**。

## 7. 快爽密度红线（能落到输出的硬约束，来自 plot 快爽门禁）

- 战斗按**场次**计（一场=独立对手+独立目的+独立空间），一章多战分别计数。
- 战斗密度两级制：硬底线 **1 场/5 章**（阻断）/ 目标线 **1 场/3 章**（黄灯需显式理由）。
- 冲突：**禁连续 2 章零冲突**。
- 成长收获：3 章滑窗 ≥1 成长。
- 钩子：**每幕 ≥2 个 L4+**。
- 节奏：首杀 ≤ch4、铺垫 ≤3 章爆。

## 8. 长线质量标准的元层（这套机制的价值）

- **结构化保证长线**：卷纲管战略和方向 → 幕纲管功能位和料 → 章纲管编排 → write 渲染。四层职责不混，长线才不崩。
- **可追溯**：章锚点表 / 章白描卡 150-250 字/章，write 读 3 段不读全卷——聚焦、可回溯。

## 9. 对外话术种子

- "写长篇最怕写崩。popwave 把卷纲做成账本：埋的线、要还的情绪、不能提前透支的高潮，全记账。"
- "每幕只干一件事，每根线都收得回来——长线不是堆字数，是运营。"
- "大纲不锁死你的创作，它只在方向、债务、收益上把关。"

## 10. 竞品差异锚

- 通用 AI 给"剧情大纲"；popwave 给**战略 + 债务台账 + 收益保护 + 可实例化的幕纲料**——把"写长篇"变成可管理的连载产品。
- 核心护城河：**"不能抢的后续收益"列 + 长线债务触发条件**——这是从"会写"到"不会写崩"的关键工程。
