# 拉片04 · 文风 DNA 可复刻：「学笔触，不学腔调」

> 性质：原材料，非对外稿。颗粒度对标「去AI味」样板。
> 依据：pop-dna-style + 文风DNA槽位协议 + library 深读。

---

## 0. 一句话卖点

**想让 AI"模仿某本书的文风"，市面做法是一场玄学赌博。popwave 把"某个作者的笔触"提取成可搬移的 DNA——三段式结构（怎么写 + 原样段落 + 反面教材），还能在长篇里分段调度、自动防单调。仿的是笔触，不是腔调。**

## 1. 用户痛点：为什么"AI 模仿文风"总是翻车

| 痛点 | 现象 |
|---|---|
| 玄学 | 丢一句"按 XX 的文笔写"，AI 学了个寂寞 |
| 学腔不学笔 | 模仿到的是"很像 AI"的腔调，不是作者的结构/节奏/感官习惯 |
| 难迁移 | 会在参考书里像，换个题材就不会 |
| 越写越单调 | 同一套文风堆满全篇 → 读者疲劳 |

> 卖点本质：**把"文风"从玄学变成可提取、可迁移、可调度的资产。**

## 2. 第一原理：学"怎么写"，不是学"写什么词"

- **三级分离铁律**：文风 DNA 管"怎么写"（句式/感官/节奏），赛道特色管"写什么词"（名词/术语/世界观词），**物理不融合、只逻辑挂接**。
- 为什么这么做：若两者融合，write 会**被名词带偏句式**——"学句式"被"抄名词"干扰。
- 对应拆书族的 DNA style 提取：**只学笔触，不学内容**。

## 3. 核心机制①：三段式 DNA 产出（可落地、可复现）

不再用玄学描述，而是结构化三件套：
1. **操作特征**：条件式指令（"当……时候，用……句式/动词/感官"）——明确"怎么用"。
2. **完整段落**：1-3 段原文 blockquote——**给"长什么样子"的样本**。
3. **反面教材**：AI 味护栏——**明确"不能这么写"**（禁导演式点题/数据文艺包装/情绪直书/能力科普）。

- **AB 测试实证**：v1.7.0 淘汰"金句碎片化"，**完整段落 + 反面教材 优于 原文直灌**——不只是经验，是被测出来的。这是把"文风方法"从玄学拉到工程级的证据。

## 4. 核心机制②：三层画笔库（按需取用，不一次全背）

文风 DNA 仓库不是一坨文本，是组件池：
1. **笔触基底**：通用笔触，跨书复用。
2. **场景卡分档**：按事件分量分档，匹配战斗密度（对应元素卡 25 场景公式复用）。
3. **卷级演变曲线**：**同类场景按剧情分量给不同笔触强度**——遭遇战碎段快杀、决死战长句铺陈，避免同场景同频率。

- **小巧思**：战斗等同类场景按分量分级，卷级曲线让笔触有"呼吸"，不是每场一个调。

## 5. 核心机制③：5 章滑窗去重（防"越写越一个调"）

- write 渲染时**回看最近 5 章已用的笔触特征**（喻体/独句段/数据句式/场景卡）。
- **高频出现者本章自动规避，强制换气**——从源头杜绝长篇单调。

## 6. write 消费协议（怎么按时取用）

- 读本章命中场景卡三段式 → 读本卷演变曲线 → 按本章事件分量选档 → **5 章滑窗去重**。
- 每章只取"本地需要"的 DNA，不强载全书文风 → 聚焦 + 省算力。

## 7. 严谨门禁

- 三段式不可缺；GB-R采样场景定向覆盖 ≥8 种才有效。
- **原文存在性前置门禁**：参考书 txt 必须存在，否则中止——不凭空造文风。
- 单文件落盘 `素材/文风锚定.md`（Stage1 v1 → Stage2 v2），单一真源。

## 8. 对外话术种子

- "别人让你丢一句'学XX的文风'，popwave 把文风拆成三件套：怎么写、长啥样、不能怎么写。"
- "学的是笔触不是腔调——同样的文风，换个题材照样用得上。"
- "写 500 章也不单调：每 5 章自动避开用腻的表达，笔触有呼吸。"

## 9. 竞品差异锚

- 通用 AI：文风=提示词里一句话（玄学、单调、难迁移）。
- popwave：**三段式 DNA + 场景卡分档 + 卷级曲线 + 5 章滑窗去重**，文风可提取、可迁移、可防单调。
- **AB 测试实证（完整段落+反面教材优于原文直灌）**是"证实非猜测"的护城河证据。
