# 拉片06 · 视频确定性渲染：「文字精确可控，可商用」

> 性质：原材料，非对外稿。颗粒度对标「去AI味」样板。
> 依据：pop-video-brand + pop-video-comic 深读。

---

## 0. 一句话卖点

**popwave 做视频不依赖"AI 视频生成"，走的是「HTML 动效时间线 + Playwright 逐帧 + ffmpeg 合成」的确定性渲染——于是画面里的字一个都不错、UI 精确可控、可复现、可修改、可商用。先脚本后出片，脚本不改就不重拍。**

## 1. 用户痛点：AI 视频的发展硬伤

| 痛点 | 现象 |
|---|---|
| 字乱 | AI视频里字幕/标题/文字经常错字、乱码、变形 |
| 不可控 | 画面随机，用户没法精确要求某个字/某个元素 |
| 不可改 | 生成一次不满意要重新生成，没法微调 |
| 本事不过关 | 时长/尺寸/配音不可控，难用于正式投放 |
| 商用风险 | 无法保证字体/画面合规，不敢用于品牌 |

> 卖点本质：**视频也可控到"帧"和"字"，便敢于商用。**

## 2. 第一原理：确定性 > 随机生成

- 当画面需要"精确的文字、可控的 UI、确定的版式"时，**随机生成是敌人**，**确定性渲染才是正确的工具**。
- 因此 popwave 明确 **不走 Seedance/GenerateVideo**，改走可计算、可复现的合成管线。

## 3. 品牌宣传片管线（pop-video-brand）

1. **读品牌素材包**：规范 + 截图 + logo（先有品牌资产）。
2. **定叙事脚本**：6 步法（品牌宣传片叙事套路）。
3. **HTML 动效时间线**：把每一帧画面、动效、文字用 HTML/CSS/JS 写好——**文字精确可控的原因**。
4. **Playwright 逐帧**：无头浏览器按时间线截图每一帧——**确定性**来源（同样的代码出同样的帧）。
5. **ffmpeg 合成 H.264**：把帧合成为 1920×1080 30fps MP4。
6. **火山 TTS 口播配音（知性灿灿 2.0）+ 混音**：画面 + 人声 + 音乐同步。
- 小巧思：HD D（音画同步）由同一条时间线驱动，不会音画错位。

## 4. 漫画转短视频管线（pop-video-comic）

1. **收集素材**：漫画页 output/page1~N + 页面配置.json + OC/封面 → 提取每页文字锚点 → 记录图片尺寸（供 Ken Burns 与画布规划）。
2. **理解 → 脚本**：产出口播脚本。
3. **口播脚本确认闸门**：**脚本未确认不进入配音/合成**（老板/客户先拍板）。
4. **TTS 配音**（edge-tts）。
5. **HTML + ffmpeg 合成**：竖版 PPT 放映式短视频，图 + 字幕 + 人声 + Ken Burns 运镜。
- 小巧思：**先脚本后出片、脚本确认闸门**——避免"合成完才发现不是要的"浪费。

## 5. 确定性渲染的商用价值

| 优势 | 说明 |
|---|---|
| 字/UI 精确 | 文字由 HTML 渲染，零错字、可控字体/排版 |
| 可复现 | 相同输入 → 相同输出，可批量/可更新 |
| 可修改 | 改一行 HTML 重新合成即可，不用"重新生成" |
| 合规可商用 | 内容可控，可用于发布会/投流/官网 |

## 6. 对外话术种子

- "AI 视频的字是飘的，popwave 视频的字是报出来的——因为每一帧都是代码画的。"
- "先出脚本、你拍板、再合成——不是生成完了让你将就。"
- "PR 片、条漫短视频，一条产线自己出，文字一个错没有，能直接拿去投放。"

## 7. 竞品差异锚

- 通用 AI 视频 = 随机生成（字乱、不可控、不能改、商用风险）。
- popwave = **确定性渲染**（HTML+Playwright+ffmpeg）→ 文字可控、可复现、可商用。
