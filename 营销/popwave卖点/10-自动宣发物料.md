# 拉片09 · 自动宣发：「你的作品自己会推自己」

> 性质：原材料，非对外稿。颗粒度对标「去AI味」样板。
> 依据：pop-recommend + pop-comic-content + pop-content-card 深读。

---

## 0. 一句话卖点

**写完不是终点，能被推出去才是。popwave 有一整套"宣发物料自动化"：从你的作品（小说正文/漫画页）直接产出推书卡、种草笔记、口播脚本、短视频文案、素材长图——还能就近导出短视频。作品自己会"安利"自己，你不用一字一句写推广文案。**

## 1. 用户痛点：会写不会推

| 痛点 | 现象 |
|---|---|
| 没时间 | 码字已经耗光精力，没空写推广 |
| 不会写文案 | 不知道卖点在哪、话术怎么写 |
| 素材重复劳动 | 每本书都要重写一套推广语 |
| 缺视觉物料 | 不会做图/卡/视频 |

> 卖点本质：**推广 = 内容消费，不占用你的一秒创作精力。**

## 2. 多维宣发物料矩阵（一套作品 → N 种物料）

| 来源 | 物料 | 产出 |
|---|---|---|
| 小说正文 | 推书卡（pop-recommend） | HTML 推书卡，9 页式 |
| 漫画页 | 内容种草三件套（pop-comic-content） | 口播脚本 + 种草/安利笔记 + 短视频文案 + 可选出片 |
| 网文写作素材 | 素材图文卡（pop-content-card） | 5 页手机可读 HTML 长图 |

## 3. 推书卡（pop-recommend）：100 章只精读 30-40 章

- **三阶段价值扫描**：骨架扫描 → 锚点深读 → 阅感采样。
- 小巧思：**100 章不每章读完，只精读 30-40 章价值章**——省时间/省钱，又能抓到全书真正的卖点。
- 产出：9 页式 HTML 推书卡（可直接发给读者/发平台）。
- 红线：**必须从小说原文出发**，不能脱离原文凭空生成。

## 4. 漫画推广三件套 + 可选出片（pop-comic-content）

- **读图自理解漫画页与 OC/封面** → 一键产出三件套：
  1. **口播脚本**
  2. **种草/安利笔记**
  3. **短视频推广文案**
- **可选出片**：整页顺序播放 + 章节封面信息页 + xfade 淡入淡出 + **整段火山灿灿配音 + 情绪指令 + 不烧字幕**。
- 小巧思：**图片优先用分享成品图（有字/水印版），无图才回退生图**——保留原版权与画风；读图为主、页面配置/导演卡文字兜底。
- 红线：内容传播以漫画页/OC/封面/文字锚点为核。

## 5. 网文素材图文卡（pop-content-card）

- 把网文写作素材做成 **5 页手机可读 HTML 长图**。
- 小巧思：**母版模板统一版式 + 锁死色板**——批量产卡风格统一，不越做越乱。

## 6. 为什么"自动宣发"能成立（工程底子）

- 复用同一批**内容资产的唯一真源**（漫画页/OC/原文），多物料不同消费者 → 版本不打架。
- 复用**确定性渲染**（可出短视频）与 **单源内容理解**（读图读文），物料质量一致。

## 7. 对外话术种子

- "你负责写，popwave 负责让读者看见你。"
- "一本书/漫画，一次生成推书卡、种草笔记、口播脚本、短视频文案——素材不重写、不重画。"
- "100 章只精读 30-40 章，抓到真卖点，不是罗列剧情。"

## 8. 竞品差异锚

- 通用 AI 写推文 = 空泛"这本小说很好看"。
- popwave = **从原文价值扫描 + 素材一次性产出矩阵 + 可出片**，内容绑定真卖点、物料成体系。
