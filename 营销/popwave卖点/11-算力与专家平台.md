# 拉片10 · 算力 + 专家平台体验：「按需买能力，用多少付多少」

> 依据：002-商业化与变现模式 + 产品截图（三栏工作台 / 技能&专家 / 获取算力）+ 老板验收。

## 0. 一句话卖点

**popwave 把"AI 能力"做成了一套看得见、算得清的商品：专家（Agent）分类可选、算力按档购买、文档与对话双向打通、成果自动进文件——你点选一个专家，把整条创作管线跑到底，为真正用到的高级能力付费。**

## 1. 用户痛点：AI 付费的"糊涂账"

| 痛点 | 现象 |
|---|---|
| 年费无感 | 包月但用不到，价格全靠赌 |
| 能力看不清 | 钱交了，不知道解锁了啥 |
| 割裂 | 对话产物是气泡，管不了/复不了 |
| 无从选型 | 一堆功能却不知道用哪个 |

> 卖点本质：**让"买的到底是什么、花多少、值不值"全程透明可感知。**

## 2. 三栏工作台：产品形态即卖点

| 栏 | 角色 | 承载体验 |
|---|---|---|
| 左栏 | 资源层 | 项目即知识资产；主导航「获取算力」（带红点待处理） |
| 中栏 | 交互层 | 对话驱动；**专家角色下拉**（如"番茄长篇网文专家（中消耗）"）；快捷推进按钮 |
| 右栏 | 产出层 | Markdown 阅读/编辑 + ✓自动保存；悬浮工具「添加到对话/AI润色/去AI味」 |

- 小巧思：**文档-对话双向打通**——产物沉淀为文件，随手回投给 AI 继续；「继续下一步」让管线衔接顺畅。

## 3. 专家（Agent）体系：分类即能力心智

- 技能 & 专家按**分类标签**组织：拆书与分析 / 短篇 / 番茄长篇 / 起点长篇 / 推书IP化 / 视觉…（卡片化）。
- 对话区：**专家下拉可选**，不同专家能力侧重（番茄 vs 起点 vs 短篇 различия）。
- **小巧思**：想用谁的点名即用——降低"一堆 skill 不知道选啥"的认知成本；分类即性价比展示（哪些专家更贵、更重）。

## 4. 算力经济：按档订阅、用算力计费

| 档 | 价格 | 每月算力 | 解锁 |
|---|---|---|---|
| basic | 18 元/月 | 1800 | 基础 agent |
| pro | 38 元/月 | 4000 | — |
| promax | 68 元/月 | 7200 | — |
| ultra | 128 元/月 | 13500 | **全部会员 agent** |

- 专家标注消耗档（**低/中/高**，如"番茄长篇网文专家（中消耗）"）→ 付费可预期。
- 小巧思：**按需买、用多少付多少**；付费理由（高级 agent + 算力）可量化、分档清晰（轻18~重128全覆盖）。

## 5. 会话级体验细节（截图实证）

- AI 回复带「已处理 13s」耗时（可展开）→ 等待透明可预期。
- 快捷推进按钮：**继续下一步 / 整理项目空间 / 汇报当前情况 / 小说漫改** → 用完即走、成果可续。
- 悬浮工具栏：**添加到对话 / 评论到对话 / AI润色 / 去AI味** → 选区政府圈交互，编辑/润色随手触发。

## 6. 对外话术种子

- "想用谁的能力，点名即用；真用到的能力才付钱。"
- "免费也能体验，进阶按算力买——轻 18、重 128，总有一档配你。"
- "你的产出是文件不是气泡，永远是自己的资产，还能接回去继续写。"

## 7. 竞品差异锚

- 通用 AI 付费 = 不透明订阅 / 产物气泡 / 无从选型。
- popwave = **专家分类可选 + 算力分档计费 + 文档对话双向 + 成果沉淀为文件资产**，把"付费"和"能力"对齐。
