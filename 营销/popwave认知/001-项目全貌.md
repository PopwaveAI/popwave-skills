## 一、popwave 是什么

**popwave 是一个面向网文/小说创作的 AI 生产型 SaaS 产品**——不是单纯的大模型对话助手，而是一套把「AI 从"聊天"升级为"产出"」的创作系统。用户可以在其中立项、拆书、建世界、塑角色、写正文、审稿，并配套 AI 润色/续写/降 AI 味、漫画/封面/视频等视觉化能力。

核心资产是一整套 `skill` 体系——产品里称为「agent / 专家」。用户在编辑器里选中文字、发起任务，由不同的 agent 接管并交付成品。

**产品形态（老板确认，2026-08-22 + 真实截图核实）**：类 Codex / 三栏式 AI 协作界面——
- **左栏（资源层）**：Popwave 品牌 + 更新按钮；主导航（新项目/搜索/技能&专家/使用教程/**获取算力**，算力有红点待处理提示）；工作空间项目列表（时间排序 + 活跃/免费标记）；底部用户栏。
- **中栏（交互层）**：对话区——支持自然语言命令（"查一下多少字"）、**专家角色下拉选择**（如"番茄长篇网文专家（中消耗）"）、AI 回复带"已处理 13s"耗时、快捷推进按钮（**继续下一步 / 整理项目空间 / 汇报当前情况 / 小说漫改**）。
- **右栏（产出层）**：文件阅读 + **Markdown 编辑**区（README.md 标签页 + 面包屑 + **✓已自动保存**）；悬浮工具栏：**添加到对话 / 评论到对话 / AI润色 / 去AI味**。

**界面承载的三大产品机制**（营销可直接借用）：
1. **专家(Agent)角色体系**——不同专家能力侧重 + 算力消耗分级（低/中/高）。
2. **算力经济系统**——"获取算力"入口 + 免费标签 + 专家消耗标注，用量即付费心智。
3. **文档-对话双向打通**——选区→AI浮窗/AI润色/去AI味，成果可"继续下一步"推进管线。

## 三、产品能力全景

### 3.1 编辑器核心交互
- **选中 → AI 浮窗**：选中文本后浮窗悬浮于选区上方，提供 **AI 润色 / AI 扩写 / 降 AI 味** 三个动作，本质是预设 prompt + 框选文字投递到对话/agent。
- 与评论、对话打通，可跨草稿页/对话页/编辑页复用。

### 3.2 Agent / 专家体系（skill 层）
内容创作全流水线，按平台分两套产线 + 支撑件 + 视觉件：

**起点产线（pop-qidian-\*）**：立项 seed → 世界构筑 world → 角色库 character → 剧情白描 plot → 正文写作 write → 章节审核 review。
**番茄产线（pop-fanqie-\*）**：seed / world / plot / write / review，快节奏连载优先。

**支撑件**：decon 拆书、dna-style 文风提取、research 调研、recommend 推书卡、short 短篇创作四件套、tool-download-webnovel 网文下载。

**视觉/视频件（pop-visual-\*）**：asset 资产提取 → art-bible 美术设定集 → style 画风层（37 种画风 DNA）→ cover 封面 / oc 立绘 / comic 漫画 / video 视频、品牌宣传片。

### 3.3 云端知识库系统（对标 A1 模板）
- 定位：**官方预制知识 → 云端存储 → 用户按需下载到项目空间**，让用户跳过准备阶段、快速进入正文写作。
- 两级分类：「赛道设定合集」「写作素材技法」；一级 tag。
- 卡片化展示（readme/changelog/skill.json 驱动前端卡片），用户可下载到项目空间，设下载权限（vip / 算力）。

### 3.4 项目空间与管线
- 项目有明确目录结构（素材/调研与反馈/角色设定…）+ 管线说明，可在项目空间内查看状态、下发「下载 txt / 生成第二章 / 检查当前专家」等任务。
- 项目状态可视化（project-state），支持端到端自主化推进。

### 3.5 其它产品议题（产品层其余文档）
- Popwave 图片功能升级、对话流悬浮条、专家页重构、Markdown 表格渲染优化、签到和社区功能强化、移动端方案、订阅与裂变 PRD。

## 四、商业化形态（详见 002）

- **订阅制 4 档**：Pop basic / Pro / Promax / Ultra（18 / 38 / 68 / 128 元/月），核心权益 = **每月算力配额（1800 / 4000 / 7200 / 13500）+ 解锁全部会员 agent**。
- 变现杠杆 = 算力（生成用量）+ 高级 agent（能力）。

## 五、对营销的意义（初步）

- 卖点是「**系统本身**」：不是单个 AI 功能，而是**整条工业化创作产线 + 可消费的知识资产底座**。
- 三条可切入的卖点主线（待 005 展开）：
  1. **产出即成品**：从脑洞到可发布正文的端到端 pipeline。
  2. **专业降 AI 味**：editor 三件套 + 文风 DNA，解决"AI 写不出人味"。
  3. **知识资产护城河**：17 赛道设定包 + 元素卡库，改写同类"纯工具"。
